# Flatten PDF with XSS PDF Solutions

Creates a flattened PDF in XSS PDF Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/41`
- **Base URL:** `https://api.xss-cross-service-solutions.com/solutions/solutions`
- **Official documentation:** [Flatten PDF](https://learn.microsoft.com/en-us/connectors/xsspdfsolutionsinteg/#flatten-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The PDF file to be flattened. |
