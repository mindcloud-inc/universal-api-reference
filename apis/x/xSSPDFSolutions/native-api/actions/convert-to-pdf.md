# Convert to PDF with XSS PDF Solutions

Creates a PDF in XSS PDF Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/31`
- **Base URL:** `https://api.xss-cross-service-solutions.com/solutions/solutions`
- **Official documentation:** [Convert to PDF](https://learn.microsoft.com/en-us/connectors/xsspdfsolutionsinteg/#convert-to-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The file to convert to PDF. |
