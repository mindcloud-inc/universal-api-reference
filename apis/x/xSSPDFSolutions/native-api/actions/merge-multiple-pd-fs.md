# Merge Multiple PDFs with XSS PDF Solutions

Creates a merged PDF in XSS PDF Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/30`
- **Base URL:** `https://api.xss-cross-service-solutions.com/solutions/solutions`
- **Official documentation:** [Merge Multiple PDFs](https://learn.microsoft.com/en-us/connectors/xsspdfsolutionsinteg/#merge-multiple-pdfs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file1` | body | `file` | yes | The first PDF file to merge. |
| `file2` | body | `file` | yes | The second PDF file to merge. |
| `file3` | body | `file` | no | Optional PDF file to merge. |
| `file4` | body | `file` | no | Optional PDF file to merge. |
| `file5` | body | `file` | no | Optional PDF file to merge. |
| `file6` | body | `file` | no | Optional PDF file to merge. |
| `file7` | body | `file` | no | Optional PDF file to merge. |
| `file8` | body | `file` | no | Optional PDF file to merge. |
| `file9` | body | `file` | no | Optional PDF file to merge. |
| `file10` | body | `file` | no | Optional PDF file to merge. |
