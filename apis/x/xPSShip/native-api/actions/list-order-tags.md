# List Order Tags with XPS Ship

Retrieves order tags from XPS Ship.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v1/customers/:customerId/list-tags`
- **Base URL:** `https://xpsshipper.com`
- **Official documentation:** [List Order Tags](https://xpsshipper.com/restapi/docs/v1-ecommerce/endpoints/list-order-tags/)
