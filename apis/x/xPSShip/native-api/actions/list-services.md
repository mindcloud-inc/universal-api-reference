# List Services with XPS Ship

Retrieves shipping services from XPS Ship.

## Endpoint

- **Method:** `GET`
- **Path:** `/restapi/v1/customers/:customerId/services`
- **Base URL:** `https://xpsshipper.com`
- **Official documentation:** [List Services](https://xpsshipper.com/restapi/docs/v1-ecommerce/endpoints/list-services/)
