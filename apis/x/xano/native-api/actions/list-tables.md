# List Tables with Xano

Finds tables in a Xano workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api%3Ameta/workspace/:workspace_id/table`
- **Base URL:** `https://x8ki-letl-twmt.n7.xano.io`
- **Official documentation:** [List Tables](https://docs.xano.com/xano-features/metadata-api/tables-and-schema)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes |
