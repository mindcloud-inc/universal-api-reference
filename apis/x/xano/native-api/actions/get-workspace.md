# Get Workspace with Xano

Retrieves a workspace from Xano by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api%3Ameta/workspace/:workspace_id`
- **Base URL:** `https://x8ki-letl-twmt.n7.xano.io`
- **Official documentation:** [Get Workspace](https://docs.xano.com/xano-features/metadata-api/instance_api/retrieve_detailed_information_about_a_specific_workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes | The Xano workspace ID. |
