# Delete Workspace with Xano

Deletes an existing workspace from Xano.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api%3Ameta/workspace/:workspace_id`
- **Base URL:** `https://x8ki-letl-twmt.n7.xano.io`
- **Official documentation:** [Delete Workspace](https://docs.xano.com/xano-features/metadata-api/instance_api/delete_a_workspace_permanently)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes | The Xano workspace ID. |
