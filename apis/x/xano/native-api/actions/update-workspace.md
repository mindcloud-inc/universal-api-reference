# Update Workspace with Xano

Updates an existing workspace in Xano.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api%3Ameta/workspace/:workspace_id`
- **Base URL:** `https://x8ki-letl-twmt.n7.xano.io`
- **Official documentation:** [Update Workspace](https://docs.xano.com/xano-features/metadata-api/instance_api/update_an_existing_workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | path | `number` | yes | The Xano workspace ID. |
