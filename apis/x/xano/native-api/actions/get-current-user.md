# Get Current User with Xano

Retrieves the authenticated user from Xano.

## Endpoint

- **Method:** `GET`
- **Path:** `/api%3Ameta/auth/me`
- **Base URL:** `https://x8ki-letl-twmt.n7.xano.io`
- **Official documentation:** [Get Current User](https://docs.xano.com/xano-features/metadata-api/instance_api/retrieve_information_about_the_authenticated_user_including_id_name_and_email_address)
