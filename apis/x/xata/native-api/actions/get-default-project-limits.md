# Get project resource limits with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/projects/limits`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [Get project resource limits](https://xata.io/docs/api-reference/projects/get-project-resource-limits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier of the organization to get project limits for |
