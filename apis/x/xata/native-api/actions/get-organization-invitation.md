# Get details of a specific invitation with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/invitations/:invitationID`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [Get details of a specific invitation](https://xata.io/docs/api-reference/organizations/get-details-of-a-specific-invitation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier for a specific organization |
| `invitationID` | path | `string` | yes | Unique identifier for an invitation |
