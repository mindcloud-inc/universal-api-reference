# Get organization details with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [Get organization details](https://xata.io/docs/api-reference/organizations/get-organization-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier for a specific organization |
