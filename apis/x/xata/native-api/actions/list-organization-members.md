# List members of an organization with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/members`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [List members of an organization](https://xata.io/docs/api-reference/organizations/list-members-of-an-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier for a specific organization |
