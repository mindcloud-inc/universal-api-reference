# List GitHub App installations for organization with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/githubapp/installations`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [List GitHub App installations for organization](https://xata.io/docs/api-reference/github-app/list-github-app-installations-for-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier of the organization |
