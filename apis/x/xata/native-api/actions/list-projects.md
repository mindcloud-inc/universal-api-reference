# List all projects with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/projects`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [List all projects](https://xata.io/docs/api-reference/projects/list-all-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier of the organization to list projects from |
