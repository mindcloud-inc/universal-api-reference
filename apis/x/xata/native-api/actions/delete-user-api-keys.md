# Bulk delete API Keys for the authenticated user with Xata

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-keys`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [Bulk delete API Keys for the authenticated user](https://xata.io/docs/api-reference/api-keys/bulk-delete-api-keys-for-the-authenticated-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids[]` | body | `array` | yes | Array of API key IDs to delete (maximum 50 keys per request) |
| `ids[]` | body | `array` | yes | Array of API key IDs to delete (maximum 50 keys per request) |
