# Get available regions with Xata

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationID/regions`
- **Base URL:** `https://api.xata.tech`
- **Official documentation:** [Get available regions](https://xata.io/docs/api-reference/projects/get-available-regions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationID` | path | `string` | yes | Unique identifier of the organization to check region availability for |
