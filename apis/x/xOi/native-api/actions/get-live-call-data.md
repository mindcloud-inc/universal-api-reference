# Get Live Call Data with XOi

## Endpoint

- **Method:** `POST`
- **Path:** `https://gql-live-external.xoi.io/graphql`
- **Base URL:** `https://gql-jobs-external.xoi.io/graphql`
- **Official documentation:** [Get Live Call Data](https://integration-docs.xoi.io/guides/live/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | XOi live call id input. |
