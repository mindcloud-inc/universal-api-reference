# Authenticate with XOi

## Endpoint

- **Method:** `POST`
- **Path:** `https://api-users-external.xoi.io/prod/token`
- **Base URL:** `https://gql-jobs-external.xoi.io/graphql`
- **Official documentation:** [Authenticate](https://integration-docs.xoi.io/guides/authentication/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
