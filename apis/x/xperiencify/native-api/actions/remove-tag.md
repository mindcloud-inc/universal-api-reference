# Remove Tag with Xperiencify

Deletes tags from Xperiencify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/public/coach/tag/`
- **Base URL:** `https://api.xperiencify.io`
- **Official documentation:** [Remove Tag](https://intercom.help/xperiencify/en/articles/9888509-integrating-with-the-api#h_14c30a3daa)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagname` | body | `string` | yes | One or more tag names separated by commas. |
