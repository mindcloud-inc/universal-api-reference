# Add New Tag with Xperiencify

Creates new tags in Xperiencify.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/coach/tag/`
- **Base URL:** `https://api.xperiencify.io`
- **Official documentation:** [Add New Tag](https://intercom.help/xperiencify/en/articles/9888509-integrating-with-the-api#h_6efc54fbe5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagname` | body | `string` | yes | One or more tag names separated by commas. |
