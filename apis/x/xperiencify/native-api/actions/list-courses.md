# List Courses with Xperiencify

Retrieves courses from Xperiencify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/coach/courses/`
- **Base URL:** `https://api.xperiencify.io`
- **Official documentation:** [List Courses](https://intercom.help/xperiencify/en/articles/9888509-integrating-with-the-api#h_64e0180278)
