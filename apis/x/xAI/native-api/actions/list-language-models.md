# List Language Models with xAI

Retrieves language models from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/language-models`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [List Language Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-language-models)
