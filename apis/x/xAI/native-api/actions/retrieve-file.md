# Retrieve File with xAI

Retrieves a file from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Retrieve File](https://docs.x.ai/developers/rest-api-reference/files/manage#retrieve-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | no | File identifier returned by upload or list files. |
