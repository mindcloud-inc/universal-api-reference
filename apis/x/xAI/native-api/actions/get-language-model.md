# Get Language Model with xAI

Retrieves a language model from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/language-models/:model_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Get Language Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-language-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | no | ID of the language model to retrieve. |
