# Delete File with xAI

Deletes a file from the xAI API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Delete File](https://docs.x.ai/developers/rest-api-reference/files/manage#delete-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | no | File identifier to delete. |
