# List TTS Voices with xAI

Retrieves text-to-speech voices from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/tts/voices`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [List TTS Voices](https://docs.x.ai/developers/rest-api-reference/inference/voice#list-tts-voices)
