# List Image Generation Models with xAI

Retrieves image generation models from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/image-generation-models`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [List Image Generation Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-image-generation-models)
