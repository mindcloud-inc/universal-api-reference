# Get Video Generation Model with xAI

Retrieves a video generation model from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/video-generation-models/:model_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Get Video Generation Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-video-generation-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | no | ID of the video generation model to retrieve. |
