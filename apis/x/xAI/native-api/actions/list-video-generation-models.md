# List Video Generation Models with xAI

Retrieves video generation models from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/video-generation-models`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [List Video Generation Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-video-generation-models)
