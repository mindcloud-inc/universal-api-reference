# Download File Content with xAI

Downloads file content from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_id/content`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Download File Content](https://docs.x.ai/developers/rest-api-reference/files/download#download-file-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | no | File identifier whose content should be downloaded. |
