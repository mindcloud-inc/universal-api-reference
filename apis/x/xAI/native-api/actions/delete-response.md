# Delete Response with xAI

Deletes a response from the xAI API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/responses/:response_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Delete Response](https://docs.x.ai/developers/rest-api-reference/inference/chat#delete-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `response_id` | path | `string` | no | Response ID to delete. |
