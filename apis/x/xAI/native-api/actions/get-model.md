# Get Model with xAI

Retrieves a model from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/models/:model_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Get Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | no | ID of the model to retrieve. |
