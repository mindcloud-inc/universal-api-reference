# Get Batch with xAI

Retrieves a batch from the xAI API.

## Endpoint

- **Method:** `GET`
- **Path:** `/batches/:batch_id`
- **Base URL:** `https://api.x.ai/v1`
- **Official documentation:** [Get Batch](https://docs.x.ai/developers/rest-api-reference/inference/batches#get-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch_id` | path | `string` | no | Unique batch identifier. |
