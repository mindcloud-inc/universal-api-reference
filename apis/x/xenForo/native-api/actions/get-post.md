# Get Post with XenForo

Retrieves the specified post from XenForo.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/:id/`
- **Base URL:** `{baseUrl}/2310/api`
- **Official documentation:** [Get Post](https://docs.xenforo.com/api/get-posts-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the post to retrieve. |
