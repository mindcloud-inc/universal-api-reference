# Get Node with XenForo

Retrieves the specified node from XenForo.

## Endpoint

- **Method:** `GET`
- **Path:** `/nodes/:id/`
- **Base URL:** `{baseUrl}/2310/api`
- **Official documentation:** [Get Node](https://docs.xenforo.com/api/get-nodes-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the node to retrieve. |
