# Get Forum with XenForo

Retrieves the specified forum from XenForo.

## Endpoint

- **Method:** `GET`
- **Path:** `/forums/:id/`
- **Base URL:** `{baseUrl}/2310/api`
- **Official documentation:** [Get Forum](https://docs.xenforo.com/api/get-forums-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the forum to retrieve. |
