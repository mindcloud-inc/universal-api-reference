# Get Alert with XenForo

Retrieves the specified alert from XenForo.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/:id/`
- **Base URL:** `{baseUrl}/2310/api`
- **Official documentation:** [Get Alert](https://docs.xenforo.com/api/get-alerts-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the alert to retrieve. |
