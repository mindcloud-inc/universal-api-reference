# Get scenario sender permissions with xMatters

Retrieves scenario sender permissions from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `scenarios/{scenarioId}/sender-permissions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get scenario sender permissions](https://help.xmatters.com/xmapi/index.html#get-scenario-sender-permissions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scenarioId` | path | `string` | no |
