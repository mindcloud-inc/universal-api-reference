# Get devices with xMatters

Retrieves devices from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `devices`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get devices](https://help.xmatters.com/xmapi/index.html#get-devices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
