# Create a shift with xMatters

Creates a shift in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `groups/{groupId}/shifts`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a shift](https://help.xmatters.com/xmapi/index.html#create-a-shift)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
