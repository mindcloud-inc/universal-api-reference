# Get a group with xMatters

Retrieves a group from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a group](https://help.xmatters.com/xmapi/index.html#get-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `groupId` | path | `string` | no |
