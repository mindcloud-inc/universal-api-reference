# Modify a form message template with xMatters

Updates a form message template in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `forms/{formId}/message-templates`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a form message template](https://help.xmatters.com/xmapi/index.html#modify-a-form-message-template)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
