# Modify an incident with xMatters

Updates an incident in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `incidents`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify an incident](https://help.xmatters.com/xmapi/index.html#modify-an-incident)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `severity` | body | `string` | no |
| `status` | body | `string` | no |
