# Modify an Integration with xMatters

Updates an Integration in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `plans/{planId}/integrations`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify an Integration](https://help.xmatters.com/xmapi/index.html#modify-an-integration)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deployed` | body | `boolean` | no |
| `id` | body | `string` | no |
| `planId` | path | `string` | no |
