# Get import jobs with xMatters

Retrieves import jobs from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `imports`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get import jobs](https://help.xmatters.com/xmapi/index.html#get-import-jobs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
