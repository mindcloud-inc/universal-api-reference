# Get sites with xMatters

Retrieves sites from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `sites`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get sites](https://help.xmatters.com/xmapi/index.html#get-sites)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
