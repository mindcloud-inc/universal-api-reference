# Create a service dependency with xMatters

Creates a service dependency in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `service-dependencies`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a service dependency](https://help.xmatters.com/xmapi/index.html#create-a-service-dependency)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dependentServiceId` | body | `string` | no |
| `serviceId` | body | `string` | no |
