# Get a person (by id) with xMatters

Retrieves a person by ID from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `people/{personId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a person (by id)](https://help.xmatters.com/xmapi/index.html#get-a-person-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `personId` | path | `string` | no |
