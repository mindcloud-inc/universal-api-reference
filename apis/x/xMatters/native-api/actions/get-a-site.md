# Get a site with xMatters

Retrieves a site from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `sites/{siteId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a site](https://help.xmatters.com/xmapi/index.html#get-a-site)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `string` | no |
