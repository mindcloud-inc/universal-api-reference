# Get shift occurrences with xMatters

Retrieves shift occurrences from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/occurrences`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get shift occurrences](https://help.xmatters.com/xmapi/index.html#get-shift-occurrences)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
