# Delete a group with xMatters

Deletes a group from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `groups/{groupId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a group](https://help.xmatters.com/xmapi/index.html#delete-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
