# Get an event annotation with xMatters

Retrieves an event annotation from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `events/{eventId}/annotations/{annotationId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an event annotation](https://help.xmatters.com/xmapi/index.html#get-an-event-annotation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `annotationId` | path | `string` | no |
| `eventId` | path | `string` | no |
