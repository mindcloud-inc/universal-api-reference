# Upload an EPIC ZipSync file with xMatters

Uploads an EPIC ZipSync file to your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `uploads/{uploadId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Upload an EPIC ZipSync file](https://help.xmatters.com/xmapi/index.html#upload-an-epic-zipsync-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uploadId` | path | `string` | no |
