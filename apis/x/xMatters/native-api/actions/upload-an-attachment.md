# Upload an attachment with xMatters

Uploads an attachment to your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `attachments`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Upload an attachment](https://help.xmatters.com/xmapi/index.html#upload-an-attachment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `string` | no |
| `fileName` | body | `string` | no |
