# Get a shift with xMatters

Retrieves a shift from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/shifts/{shiftId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a shift](https://help.xmatters.com/xmapi/index.html#get-a-shift)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
| `shiftId` | path | `string` | no |
