# Get group members with xMatters

Retrieves group members from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/members`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get group members](https://help.xmatters.com/xmapi/index.html#get-group-members)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
