# Modify a site with xMatters

Updates a site in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `sites`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a site](https://help.xmatters.com/xmapi/index.html#modify-a-site)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `country` | body | `string` | no |
| `id` | body | `string` | no |
| `language` | body | `string` | no |
| `name` | body | `string` | no |
| `timezone` | body | `string` | no |
