# Get forms with xMatters

Retrieves forms from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `forms`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get forms](https://help.xmatters.com/xmapi/index.html#get-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
