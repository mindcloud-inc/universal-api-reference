# Get subscribers with xMatters

Retrieves subscribers from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions/{subscriptionId}/subscribers`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get subscribers](https://help.xmatters.com/xmapi/index.html#get-subscribers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | no |
