# Create a device name with xMatters

Creates a device name in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `deviceName`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a device name](https://help.xmatters.com/xmapi/index.html#create-a-device-name)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `deviceType` | body | `string` | no |
| `name` | body | `string` | no |
| `privileged` | body | `boolean` | no |
