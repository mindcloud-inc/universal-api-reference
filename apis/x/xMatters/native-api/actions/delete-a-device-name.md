# Delete a device name with xMatters

Deletes a device name from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `device-names/{deviceNameId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a device name](https://help.xmatters.com/xmapi/index.html#delete-a-device-name)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceNameId` | path | `string` | no |
