# Get group license quotas with xMatters

Retrieves group license quotas from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/license-quotas`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get group license quotas](https://help.xmatters.com/xmapi/index.html#get-group-license-quotas)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
