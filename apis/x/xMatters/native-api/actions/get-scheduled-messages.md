# Get scheduled messages with xMatters

Retrieves scheduled messages from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `scheduled-messages`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get scheduled messages](https://help.xmatters.com/xmapi/index.html#get-scheduled-messages)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
