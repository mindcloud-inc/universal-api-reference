# Get signals with xMatters

Retrieves signals from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/signals`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get signals](https://help.xmatters.com/xmapi/index.html#get-signals)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
