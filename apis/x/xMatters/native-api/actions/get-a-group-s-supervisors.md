# Get a group's supervisors with xMatters

Retrieves a group's supervisors from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/supervisors`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a group's supervisors](https://help.xmatters.com/xmapi/index.html#get-a-group-39-s-supervisors)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
