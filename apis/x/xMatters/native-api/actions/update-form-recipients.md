# Update form recipients with xMatters

Updates form recipients in your xMatters instance.

## Endpoint

- **Method:** `PUT`
- **Path:** `forms/{formId}/recipients`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Update form recipients](https://help.xmatters.com/xmapi/index.html#update-form-recipients)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
