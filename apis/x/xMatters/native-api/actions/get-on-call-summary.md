# Get on-call summary with xMatters

Retrieves on-call summary from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `on-call-summary`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get on-call summary](https://help.xmatters.com/xmapi/index.html#get-on-call-summary)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groups` | query | `string` | no |
