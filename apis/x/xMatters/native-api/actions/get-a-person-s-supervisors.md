# Get a person's supervisors with xMatters

Retrieves a person's supervisors from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `people/{personId}/supervisors`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a person's supervisors](https://help.xmatters.com/xmapi/index.html#get-a-person-39-s-supervisors)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `personId` | path | `string` | no |
