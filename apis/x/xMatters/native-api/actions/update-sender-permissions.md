# Update sender permissions with xMatters

Updates sender permissions in your xMatters instance.

## Endpoint

- **Method:** `PUT`
- **Path:** `forms/{formId}/sender-permissions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Update sender permissions](https://help.xmatters.com/xmapi/index.html#update-sender-permissions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
