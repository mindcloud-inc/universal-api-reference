# Modify a group with xMatters

Updates a group in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `groups`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a group](https://help.xmatters.com/xmapi/index.html#modify-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `id` | body | `string` | no |
| `recipientType` | body | `string` | no |
