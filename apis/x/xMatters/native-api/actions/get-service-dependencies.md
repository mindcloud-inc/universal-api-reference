# Get service dependencies with xMatters

Retrieves service dependencies from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `service-dependencies`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get service dependencies](https://help.xmatters.com/xmapi/index.html#get-service-dependencies)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
