# Create form response options with xMatters

Creates form response options in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `forms/{formId}/response-options`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create form response options](https://help.xmatters.com/xmapi/index.html#create-form-response-options)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
