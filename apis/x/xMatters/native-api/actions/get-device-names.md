# Get device names with xMatters

Retrieves device names from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `device-names`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get device names](https://help.xmatters.com/xmapi/index.html#get-device-names)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
