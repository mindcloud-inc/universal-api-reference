# Set scenario sender permissions with xMatters

Sets scenario sender permissions in your xMatters instance.

## Endpoint

- **Method:** `PUT`
- **Path:** `scenarios/{scenarioId}/sender-permissions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Set scenario sender permissions](https://help.xmatters.com/xmapi/index.html#set-scenario-sender-permissions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scenarioId` | path | `string` | no |
