# Delete a plan endpoint with xMatters

Deletes a plan endpoint from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `plans/{planId}/endpoints/{endpointId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a plan endpoint](https://help.xmatters.com/xmapi/index.html#delete-a-plan-endpoint)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endpointId` | path | `string` | no |
| `planId` | path | `string` | no |
