# Get an integration with xMatters

Retrieves an integration from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/integrations/{integrationId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an integration](https://help.xmatters.com/xmapi/index.html#get-an-integration)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `integrationId` | path | `string` | no |
| `planId` | path | `string` | no |
