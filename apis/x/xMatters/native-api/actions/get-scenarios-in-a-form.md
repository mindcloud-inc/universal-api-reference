# Get scenarios in a form with xMatters

Retrieves scenarios in a form from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/forms/{formId}/scenarios`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get scenarios in a form](https://help.xmatters.com/xmapi/index.html#get-scenarios-in-a-form)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
| `planId` | path | `string` | no |
