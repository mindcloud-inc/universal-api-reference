# Modify a service dependency with xMatters

Updates a service dependency in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `service-dependencies`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a service dependency](https://help.xmatters.com/xmapi/index.html#modify-a-service-dependency)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dependentServiceId` | body | `string` | no |
| `id` | body | `string` | no |
| `serviceId` | body | `string` | no |
