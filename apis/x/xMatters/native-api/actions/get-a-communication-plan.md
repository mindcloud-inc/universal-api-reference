# Get a communication plan with xMatters

Retrieves a communication plan from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a communication plan](https://help.xmatters.com/xmapi/index.html#get-a-communication-plan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `planId` | path | `string` | no |
