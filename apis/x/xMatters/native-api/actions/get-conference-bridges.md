# Get conference bridges with xMatters

Retrieves conference bridges from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `conference-bridges`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get conference bridges](https://help.xmatters.com/xmapi/index.html#get-conference-bridges)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
