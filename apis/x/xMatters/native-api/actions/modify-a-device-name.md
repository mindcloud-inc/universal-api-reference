# Modify a device name with xMatters

Updates a device name in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `device-names`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a device name](https://help.xmatters.com/xmapi/index.html#modify-a-device-name)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceType` | body | `string` | no |
| `id` | body | `string` | no |
| `phoneNumber` | body | `string` | no |
