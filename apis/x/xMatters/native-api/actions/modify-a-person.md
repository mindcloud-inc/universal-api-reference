# Modify a person with xMatters

Updates a person in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `people`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a person](https://help.xmatters.com/xmapi/index.html#modify-a-person)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `status` | body | `string` | no |
