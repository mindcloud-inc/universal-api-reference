# Delete a site with xMatters

Deletes a site from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `sites/{siteId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a site](https://help.xmatters.com/xmapi/index.html#delete-a-site)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `string` | no |
