# Delete a shared library with xMatters

Deletes a shared library from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `shared-libraries/{sharedLibraryId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a shared library](https://help.xmatters.com/xmapi/index.html#delete-a-shared-library)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharedLibraryId` | path | `string` | no |
