# Get an event with xMatters

Retrieves an event from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `events/{eventId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an event](https://help.xmatters.com/xmapi/index.html#get-an-event)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `eventId` | path | `string` | no |
