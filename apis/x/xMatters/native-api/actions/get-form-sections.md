# Get form sections with xMatters

Retrieves form sections from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `forms/{formId}/sections`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get form sections](https://help.xmatters.com/xmapi/index.html#get-form-sections)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
