# Get groups with xMatters

Retrieves groups from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get groups](https://help.xmatters.com/xmapi/index.html#get-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
