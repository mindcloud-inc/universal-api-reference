# Update a shift with xMatters

Updates a shift in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `groups/{groupId}/shifts/{shiftId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Update a shift](https://help.xmatters.com/xmapi/index.html#update-a-shift)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
| `shiftId` | path | `string` | no |
