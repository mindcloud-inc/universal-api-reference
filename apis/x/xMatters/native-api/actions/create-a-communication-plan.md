# Create a communication plan with xMatters

Creates a communication plan in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `plans`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a communication plan](https://help.xmatters.com/xmapi/index.html#create-a-communication-plan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessibleByAll` | body | `boolean` | no |
| `enabled` | body | `boolean` | no |
| `floodControl` | body | `boolean` | no |
| `name` | body | `string` | no |
| `position` | body | `number` | no |
