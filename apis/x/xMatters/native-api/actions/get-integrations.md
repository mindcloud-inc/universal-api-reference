# Get integrations with xMatters

Retrieves integrations from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/integrations`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get integrations](https://help.xmatters.com/xmapi/index.html#get-integrations)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
