# Create a temporary absence with xMatters

Creates a temporary absence in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `temporary-absences`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a temporary absence](https://help.xmatters.com/xmapi/index.html#create-a-temporary-absence)
