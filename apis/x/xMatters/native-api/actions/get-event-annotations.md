# Get event annotations with xMatters

Retrieves event annotations from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `events/{eventId}/annotations`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get event annotations](https://help.xmatters.com/xmapi/index.html#get-event-annotations)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eventId` | path | `string` | no |
