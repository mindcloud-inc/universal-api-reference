# Get a signal with xMatters

Retrieves a signal from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `signals/{signalId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a signal](https://help.xmatters.com/xmapi/index.html#get-a-signal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signalId` | path | `string` | no |
