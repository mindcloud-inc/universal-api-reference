# Create form message templates with xMatters

Creates form message templates in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `forms/{formId}/message-templates`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create form message templates](https://help.xmatters.com/xmapi/index.html#create-form-message-templates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
