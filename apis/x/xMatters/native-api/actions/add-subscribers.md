# Add subscribers with xMatters

Adds subscribers in your xMatters instance.

## Endpoint

- **Method:** `PUT`
- **Path:** `subscriptions/{subscriptionId}/subscribers`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Add subscribers](https://help.xmatters.com/xmapi/index.html#add-subscribers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | no |
