# Get form response options with xMatters

Retrieves form response options from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/forms/{formId}/response-options`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get form response options](https://help.xmatters.com/xmapi/index.html#get-form-response-options)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
| `planId` | path | `string` | no |
