# Get an event attachment with xMatters

Retrieves an event attachment from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `events/{eventId}/attachments/{attachmentId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an event attachment](https://help.xmatters.com/xmapi/index.html#get-an-event-attachment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachmentId` | path | `string` | no |
| `eventId` | path | `string` | no |
