# Delete a service dependency with xMatters

Deletes a service dependency from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `service-dependencies/{serviceDependencyId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a service dependency](https://help.xmatters.com/xmapi/index.html#delete-a-service-dependency)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `serviceDependencyId` | path | `string` | no |
