# Get communication plans with xMatters

Retrieves communication plans from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get communication plans](https://help.xmatters.com/xmapi/index.html#get-communication-plans)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `planType` | query | `string` | no |
| `search` | query | `string` | no |
