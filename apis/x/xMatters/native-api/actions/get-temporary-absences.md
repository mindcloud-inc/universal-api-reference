# Get temporary absences with xMatters

Retrieves temporary absences from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `temporary-absences`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get temporary absences](https://help.xmatters.com/xmapi/index.html#get-temporary-absences)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groups` | query | `string` | no |
| `member` | query | `string` | no |
