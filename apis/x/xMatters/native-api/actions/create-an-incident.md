# Create an incident with xMatters

Creates an incident in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `incidents`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create an incident](https://help.xmatters.com/xmapi/index.html#create-an-incident)
