# Get a change with xMatters

Retrieves a change from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `changes/{changeId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a change](https://help.xmatters.com/xmapi/index.html#get-a-change)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `changeId` | path | `string` | no |
