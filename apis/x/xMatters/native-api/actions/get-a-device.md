# Get a device with xMatters

Retrieves a device from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `devices/{deviceId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a device](https://help.xmatters.com/xmapi/index.html#get-a-device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | no |
| `embed` | query | `string` | no |
