# Delete a subscription with xMatters

Deletes a subscription from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `subscriptions/{subscriptionId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a subscription](https://help.xmatters.com/xmapi/index.html#delete-a-subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | no |
