# Get import job messages with xMatters

Retrieves import job messages from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `imports/{importId}/import-messages`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get import job messages](https://help.xmatters.com/xmapi/index.html#get-import-job-messages)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `importId` | path | `string` | no |
