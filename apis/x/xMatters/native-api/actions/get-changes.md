# Get changes with xMatters

Retrieves changes from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `changes`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get changes](https://help.xmatters.com/xmapi/index.html#get-changes)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
