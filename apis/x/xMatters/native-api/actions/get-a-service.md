# Get a service with xMatters

Retrieves a service from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `services/{serviceId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a service](https://help.xmatters.com/xmapi/index.html#get-a-service)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `serviceId` | path | `string` | no |
