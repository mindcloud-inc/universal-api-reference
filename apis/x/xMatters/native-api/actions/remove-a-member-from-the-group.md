# Remove a member from the group with xMatters

Removes a member from the group from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `groups/{groupId}/members/{memberId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Remove a member from the group](https://help.xmatters.com/xmapi/index.html#remove-a-member-from-the-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
| `memberId` | path | `string` | no |
