# Get shifts with xMatters

Retrieves shifts from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/shifts`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get shifts](https://help.xmatters.com/xmapi/index.html#get-shifts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
