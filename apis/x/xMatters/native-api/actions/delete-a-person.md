# Delete a person with xMatters

Deletes a person from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `people/{personId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a person](https://help.xmatters.com/xmapi/index.html#delete-a-person)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `personId` | path | `string` | no |
