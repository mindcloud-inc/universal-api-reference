# Change the status of an event with xMatters

Changes the status of an event in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `events`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Change the status of an event](https://help.xmatters.com/xmapi/index.html#change-the-status-of-an-event)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `status` | body | `string` | no |
