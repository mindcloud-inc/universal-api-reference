# Get roles with xMatters

Retrieves roles from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `roles`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get roles](https://help.xmatters.com/xmapi/index.html#get-roles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
