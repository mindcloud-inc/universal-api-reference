# Modify a shared library with xMatters

Updates a shared library in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `shared-libraries`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a shared library](https://help.xmatters.com/xmapi/index.html#modify-a-shared-library)
