# Get shared libraries with xMatters

Retrieves shared libraries from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/shared-libraries`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get shared libraries](https://help.xmatters.com/xmapi/index.html#get-shared-libraries)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
