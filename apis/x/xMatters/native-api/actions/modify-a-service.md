# Modify a service with xMatters

Updates a service in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `services`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a service](https://help.xmatters.com/xmapi/index.html#modify-a-service)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `ownedBy` | body | `string` | no |
