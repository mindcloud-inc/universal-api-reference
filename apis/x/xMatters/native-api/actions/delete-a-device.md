# Delete a device with xMatters

Deletes a device from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `devices/{deviceId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a device](https://help.xmatters.com/xmapi/index.html#delete-a-device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | no |
