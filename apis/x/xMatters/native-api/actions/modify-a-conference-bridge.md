# Modify a conference bridge with xMatters

Updates a conference bridge in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `conference-bridges`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a conference bridge](https://help.xmatters.com/xmapi/index.html#modify-a-conference-bridge)
