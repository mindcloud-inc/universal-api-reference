# Create an external conference bridge with xMatters

Creates an external conference bridge in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `conference-bridges`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create an external conference bridge](https://help.xmatters.com/xmapi/index.html#create-an-external-conference-bridge)
