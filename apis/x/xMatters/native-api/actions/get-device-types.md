# Get device types with xMatters

Retrieves device types from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `device-types`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get device types](https://help.xmatters.com/xmapi/index.html#get-device-types)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
