# Get a form in a plan with xMatters

Retrieves a form in a plan from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/forms/{formId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a form in a plan](https://help.xmatters.com/xmapi/index.html#get-a-form-in-a-plan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `embed` | query | `string` | no |
| `formId` | path | `string` | no |
| `planId` | path | `string` | no |
