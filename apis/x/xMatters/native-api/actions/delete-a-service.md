# Delete a service with xMatters

Deletes a service from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `services/{serviceId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a service](https://help.xmatters.com/xmapi/index.html#delete-a-service)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `serviceId` | path | `string` | no |
