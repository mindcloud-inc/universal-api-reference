# Upload a User Upload file with xMatters

Uploads a User Upload file to your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `uploads/{uploadId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Upload a User Upload file](https://help.xmatters.com/xmapi/index.html#upload-a-user-upload-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uploadId` | path | `string` | no |
