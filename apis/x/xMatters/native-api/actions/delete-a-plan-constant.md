# Delete a plan constant with xMatters

Deletes a plan constant from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `plans/{planId}/constants/{constantId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a plan constant](https://help.xmatters.com/xmapi/index.html#delete-a-plan-constant)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `constantId` | path | `string` | no |
| `planId` | path | `string` | no |
