# Create an integration with xMatters

Creates an integration in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `plans/{planId}/integrations`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create an integration](https://help.xmatters.com/xmapi/index.html#create-an-integration)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
