# Create a shared library with xMatters

Creates a shared library in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `shared-libraries`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Create a shared library](https://help.xmatters.com/xmapi/index.html#create-a-shared-library)
