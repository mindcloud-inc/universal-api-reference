# Modify a device with xMatters

Updates a device in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `devices`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a device](https://help.xmatters.com/xmapi/index.html#modify-a-device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceType` | body | `string` | no |
| `id` | body | `string` | no |
| `phoneNumber` | body | `string` | no |
