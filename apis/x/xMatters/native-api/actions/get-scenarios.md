# Get scenarios with xMatters

Retrieves scenarios from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `scenarios`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get scenarios](https://help.xmatters.com/xmapi/index.html#get-scenarios)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
