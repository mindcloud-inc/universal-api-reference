# Get suppressed events with xMatters

Retrieves suppressed events from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `event-suppressions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get suppressed events](https://help.xmatters.com/xmapi/index.html#get-suppressed-events)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `event` | query | `string` | no |
