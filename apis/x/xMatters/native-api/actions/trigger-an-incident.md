# Trigger an incident with xMatters

Triggers an incident in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `forms/{formId}/triggers`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Trigger an incident](https://help.xmatters.com/xmapi/index.html#trigger-an-incident)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | no |
