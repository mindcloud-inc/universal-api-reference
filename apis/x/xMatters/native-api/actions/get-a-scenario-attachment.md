# Get a scenario attachment with xMatters

Retrieves a scenario attachment from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `scenarios/{scenarioId}/attachments/{attachmentId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a scenario attachment](https://help.xmatters.com/xmapi/index.html#get-a-scenario-attachment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachmentId` | path | `string` | no |
| `scenarioId` | path | `string` | no |
