# Get user license quotas with xMatters

Retrieves user license quotas from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `people/license-quotas`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get user license quotas](https://help.xmatters.com/xmapi/index.html#get-user-license-quotas)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
