# Get a scenario with xMatters

Retrieves a scenario from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `scenarios/{scenarioId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a scenario](https://help.xmatters.com/xmapi/index.html#get-a-scenario)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scenarioId` | path | `string` | no |
