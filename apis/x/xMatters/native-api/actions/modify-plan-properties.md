# Modify plan properties with xMatters

Updates plan properties in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `plans/{planId}/property-definitions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify plan properties](https://help.xmatters.com/xmapi/index.html#modify-plan-properties)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
