# Unsubscribe a user with xMatters

Unsubscribes a user from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `subscriptions/{subscriptionId}/subscribers/{subscriberId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Unsubscribe a user](https://help.xmatters.com/xmapi/index.html#unsubscribe-a-user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriberId` | path | `string` | no |
| `subscriptionId` | path | `string` | no |
