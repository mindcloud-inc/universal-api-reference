# Get a shared library with xMatters

Retrieves a shared library from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `shared-libraries/{sharedLibraryId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a shared library](https://help.xmatters.com/xmapi/index.html#get-a-shared-library)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharedLibraryId` | path | `string` | no |
