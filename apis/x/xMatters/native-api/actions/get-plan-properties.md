# Get plan properties with xMatters

Retrieves plan properties from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `plans/{planId}/property-definitions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get plan properties](https://help.xmatters.com/xmapi/index.html#get-plan-properties)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
