# Get an import job with xMatters

Retrieves an import job from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `imports/{importId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an import job](https://help.xmatters.com/xmapi/index.html#get-an-import-job)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `importId` | path | `string` | no |
