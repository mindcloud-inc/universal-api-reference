# Delete a plan with xMatters

Deletes a plan from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `plans/{planId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a plan](https://help.xmatters.com/xmapi/index.html#delete-a-plan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
