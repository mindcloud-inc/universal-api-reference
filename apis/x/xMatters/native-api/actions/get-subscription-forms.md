# Get subscription forms with xMatters

Retrieves subscription forms from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `subscription-forms`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get subscription forms](https://help.xmatters.com/xmapi/index.html#get-subscription-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
