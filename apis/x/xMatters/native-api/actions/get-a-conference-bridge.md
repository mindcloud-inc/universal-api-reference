# Get a conference bridge with xMatters

Retrieves a conference bridge from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `conference-bridges/{conferenceBridgeId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a conference bridge](https://help.xmatters.com/xmapi/index.html#get-a-conference-bridge)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conferenceBridgeId` | path | `string` | no |
