# Get integration logs with xMatters

Retrieves integration logs from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `integrations/{integrationId}/logs`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get integration logs](https://help.xmatters.com/xmapi/index.html#get-integration-logs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `integrationId` | path | `string` | no |
