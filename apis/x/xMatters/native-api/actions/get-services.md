# Get services with xMatters

Retrieves services from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `services`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get services](https://help.xmatters.com/xmapi/index.html#get-services)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
