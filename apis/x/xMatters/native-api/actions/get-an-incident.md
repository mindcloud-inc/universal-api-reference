# Get an incident with xMatters

Retrieves an incident from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `incidents/{incidentId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get an incident](https://help.xmatters.com/xmapi/index.html#get-an-incident)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `incidentId` | path | `string` | no |
