# Modify a plan form with xMatters

Updates a plan form in your xMatters instance.

## Endpoint

- **Method:** `POST`
- **Path:** `plans/{planId}/forms`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Modify a plan form](https://help.xmatters.com/xmapi/index.html#modify-a-plan-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | path | `string` | no |
