# Get incidents with xMatters

Retrieves incidents from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `incidents`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get incidents](https://help.xmatters.com/xmapi/index.html#get-incidents)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
