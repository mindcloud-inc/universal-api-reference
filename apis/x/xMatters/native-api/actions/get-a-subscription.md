# Get a subscription with xMatters

Retrieves a subscription from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions/{subscriptionId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get a subscription](https://help.xmatters.com/xmapi/index.html#get-a-subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | no |
