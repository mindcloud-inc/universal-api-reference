# Delete a temporary absence with xMatters

Deletes a temporary absence from your xMatters instance.

## Endpoint

- **Method:** `DELETE`
- **Path:** `temporary-absences/{temporaryAbsenceId}`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Delete a temporary absence](https://help.xmatters.com/xmapi/index.html#delete-a-temporary-absence)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `temporaryAbsenceId` | path | `string` | no |
