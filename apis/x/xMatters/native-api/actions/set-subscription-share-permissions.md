# Set subscription share permissions with xMatters

Sets subscription share permissions in your xMatters instance.

## Endpoint

- **Method:** `PUT`
- **Path:** `subscriptions/{subscriptionId}/share-permissions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Set subscription share permissions](https://help.xmatters.com/xmapi/index.html#set-subscription-share-permissions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | no |
