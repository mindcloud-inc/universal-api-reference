# Get deleted shift occurrences with xMatters

Retrieves deleted shift occurrences from your xMatters instance.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/{groupId}/shifts/{shiftId}/exclusions`
- **Base URL:** `https://mindcloud.xmatters.com/api/xm/1`
- **Official documentation:** [Get deleted shift occurrences](https://help.xmatters.com/xmapi/index.html#get-deleted-shift-occurrences)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | no |
| `shiftId` | path | `string` | no |
