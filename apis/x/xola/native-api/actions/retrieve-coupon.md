# Retrieve Coupon with Xola

Retrieves a coupon from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Coupon](https://developers.xola.com/reference/retrieve-a-coupon)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Coupon identifier from Xola. |
