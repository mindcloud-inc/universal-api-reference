# List Guides with Xola

Finds guides for a seller in Xola.

## Endpoint

- **Method:** `GET`
- **Path:** `/sellers/{id}/guides`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [List Guides](https://developers.xola.com/reference/list-all-guides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Seller identifier from Xola. |
