# Retrieve Demographic with Xola

Retrieves a demographic from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/demographics/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Demographic](https://developers.xola.com/reference/retrieve-a-demographic)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Demographic identifier from Xola. |
