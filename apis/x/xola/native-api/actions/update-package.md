# Update Package with Xola

Updates an existing package in Xola.

## Endpoint

- **Method:** `PUT`
- **Path:** `/packages/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Update Package](https://developers.xola.com/reference/r-create-a-package-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Package identifier from Xola. |
