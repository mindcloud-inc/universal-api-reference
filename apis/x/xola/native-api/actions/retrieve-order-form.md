# Retrieve Order Form with Xola

Retrieves the form for an order in Xola.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}/questions`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Order Form](https://developers.xola.com/reference/retrieve-the-form-for-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order identifier from Xola. |
