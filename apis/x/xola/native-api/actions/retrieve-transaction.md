# Retrieve Transaction with Xola

Retrieves a transaction from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Transaction](https://developers.xola.com/reference/retrieve-a-transansaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Transaction identifier from Xola. |
