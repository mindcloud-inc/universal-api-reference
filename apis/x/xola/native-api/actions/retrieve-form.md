# Retrieve Form with Xola

Retrieves a form from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Form](https://developers.xola.com/reference/retrieve-a-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Form identifier from Xola. |
