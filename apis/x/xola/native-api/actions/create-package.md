# Create Package with Xola

Creates a new package in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/packages`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Package](https://developers.xola.com/reference/create-a-package)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `desc` | body | `string` | yes |
| `excerpt` | body | `string` | yes |
| `name` | body | `string` | yes |
| `rewards` | body | `string` | yes |
| `seller` | body | `string` | yes |
| `triggers` | body | `string` | yes |
