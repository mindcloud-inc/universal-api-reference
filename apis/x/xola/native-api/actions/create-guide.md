# Create Guide with Xola

Creates a new guide for a seller in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/sellers/{id}/guides`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Guide](https://developers.xola.com/reference/create-a-guide)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Seller identifier from Xola. |
