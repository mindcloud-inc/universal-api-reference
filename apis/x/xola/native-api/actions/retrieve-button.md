# Retrieve Button with Xola

Retrieves a button from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/buttons/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Button](https://developers.xola.com/reference/get-button)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Button identifier from Xola. |
