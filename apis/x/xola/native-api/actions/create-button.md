# Create Button with Xola

Creates a new button in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/buttons`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Button](https://developers.xola.com/reference/create-a-button)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `seller` | query | `string` | yes |
| `type` | body | `string` | yes |
