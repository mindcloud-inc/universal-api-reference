# Create Experience with Xola

Creates a new experience in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/experiences`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Experience](https://developers.xola.com/reference/create-an-experience)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `demographics` | body | `string` | yes |
| `desc` | body | `string` | yes |
| `duration` | body | `string` | yes |
| `excerpt` | body | `string` | yes |
| `name` | body | `string` | yes |
| `priceSchemes` | body | `string` | yes |
| `seller` | body | `string` | yes |
