# Create Form with Xola

Creates a new form in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/forms`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Form](https://developers.xola.com/reference/create-a-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields` | body | `string` | yes |
| `seller` | body | `string` | yes |
