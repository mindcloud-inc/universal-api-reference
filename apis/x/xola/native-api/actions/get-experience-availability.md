# Get Experience Availability with Xola

Retrieves availability for an experience from Xola.

## Endpoint

- **Method:** `GET`
- **Path:** `/experiences/{id}/availability`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Get Experience Availability](https://developers.xola.com/reference/experiencesidavailability)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Experience identifier from Xola. |
