# Create Event with Xola

Creates a new event in Xola.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Create Event](https://developers.xola.com/reference/create-an-event)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `experience.id` | body | `string` | yes |
| `start` | body | `string` | yes |
