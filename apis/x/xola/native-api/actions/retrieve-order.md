# Retrieve Order with Xola

Retrieves an order from Xola by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://sandbox.xola.com/api`
- **Official documentation:** [Retrieve Order](https://developers.xola.com/reference/retrieve-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order identifier from Xola. |
