# Convert PDF URL to HTML with PDFCrowd

Creates HTML from a PDF URL in PDFCrowd.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.pdfcrowd.com/convert/24.04/`
- **Base URL:** `https://api.pdfcrowd.com/convert/24.04/`
- **Official documentation:** [Convert PDF URL to HTML](https://pdfcrowd.com/api/pdf-to-html-http/ref/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public PDF URL to convert into HTML output. |
