# Convert PDF URL to Text with PDFCrowd

Creates text from a PDF URL in PDFCrowd.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.pdfcrowd.com/convert/24.04/`
- **Base URL:** `https://api.pdfcrowd.com/convert/24.04/`
- **Official documentation:** [Convert PDF URL to Text](https://pdfcrowd.com/api/pdf-to-text-http/ref/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public PDF URL to convert into plain text output. |
