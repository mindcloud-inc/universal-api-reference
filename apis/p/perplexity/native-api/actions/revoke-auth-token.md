# Revoke Auth Token with Perplexity

Revokes an auth token in Perplexity.

## Endpoint

- **Method:** `POST`
- **Path:** `/revoke_auth_token`
- **Base URL:** `https://api.perplexity.ai`
- **Official documentation:** [Revoke Auth Token](https://docs.perplexity.ai/api-reference/revoke-auth-token-post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `auth_token` | body | `string` | yes |
