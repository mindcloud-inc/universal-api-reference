# List Async Chat Completions with Perplexity

Retrieves async chat completions from Perplexity.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/async/sonar`
- **Base URL:** `https://api.perplexity.ai`
- **Official documentation:** [List Async Chat Completions](https://docs.perplexity.ai/api-reference/async-sonar-get)
