# Generate Auth Token with Perplexity

Creates an auth token in Perplexity.

## Endpoint

- **Method:** `POST`
- **Path:** `/generate_auth_token`
- **Base URL:** `https://api.perplexity.ai`
- **Official documentation:** [Generate Auth Token](https://docs.perplexity.ai/api-reference/generate-auth-token-post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token_name` | body | `string` | no |
