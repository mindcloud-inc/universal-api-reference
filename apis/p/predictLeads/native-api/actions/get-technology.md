# Get Technology with PredictLeads

Retrieves a technology from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/technologies/:id_or_fuzzy_name`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Get Technology](https://docs.predictleads.com/api_endpoints/technologies_dataset/retrieve_a_single_technology_by_id_or_fuzzy_name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_or_fuzzy_name` | path | `string` | yes | Technology ID or fuzzy name. |
