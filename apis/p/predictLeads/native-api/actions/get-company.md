# Get Company with PredictLeads

Retrieves a company from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id_or_domain`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Get Company](https://docs.predictleads.com/api_endpoints/companies_dataset/retrieve_company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_or_domain` | path | `string` | yes | Company's ID or domain. |
