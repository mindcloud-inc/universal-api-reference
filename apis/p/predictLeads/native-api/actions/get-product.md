# Get Product with PredictLeads

Retrieves a product from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Get Product](https://docs.predictleads.com/api_endpoints/products_dataset/retrieve_a_single_product_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID. |
