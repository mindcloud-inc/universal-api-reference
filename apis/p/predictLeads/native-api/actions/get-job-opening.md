# Get Job Opening with PredictLeads

Retrieves a job opening from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_openings/:id`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Get Job Opening](https://docs.predictleads.com/api_endpoints/job_openings_dataset/retrieve_a_single_job_opening_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Job opening ID. |
