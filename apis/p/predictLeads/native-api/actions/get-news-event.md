# Get News Event with PredictLeads

Retrieves a news event from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/news_events/:id`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Get News Event](https://docs.predictleads.com/api_endpoints/news_events_dataset/retrieve_a_single_news_event_by_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | News event ID. |
