# Retrieve API Subscription Information with PredictLeads

Retrieves API subscription details from the PredictLeads API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api_subscription`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Retrieve API Subscription Information](https://docs.predictleads.com/api_endpoints/api_subscription/retrieve_api_subscription_information)
