# Unfollow Company with PredictLeads

Unfollows a company in the PredictLeads API.

## Endpoint

- **Method:** `POST`
- **Path:** `/companies/:company_id_or_domain/unfollow`
- **Base URL:** `https://predictleads.com/api/v3`
- **Official documentation:** [Unfollow Company](https://docs.predictleads.com/api_endpoints/follow_companies/unfollow_the_company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id_or_domain` | path | `string` | yes | Company ID or domain. |
