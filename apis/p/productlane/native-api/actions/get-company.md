# Get Company with Productlane

Retrieves a company from your Productlane workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Get Company](https://productlane.mintlify.dev/docs/api/companies/get-company)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `groupUpvotes` | query | `boolean` | no |
