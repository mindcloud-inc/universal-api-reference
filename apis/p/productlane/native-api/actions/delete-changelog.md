# Delete Changelog with Productlane

Deletes an existing changelog from Productlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/changelogs/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Delete Changelog](https://productlane.mintlify.dev/docs/api/changelogs/delete-changelog)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
