# List Changelog Tags with Productlane

Retrieves changelog tags from your Productlane workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/changelog-tags/:workspaceId`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [List Changelog Tags](https://productlane.mintlify.dev/docs/api/changelogs/list-changelog-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes |
