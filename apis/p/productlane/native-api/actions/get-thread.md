# Get Thread with Productlane

Retrieves a thread from your Productlane workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Get Thread](https://productlane.mintlify.dev/docs/api/threads/get-thread)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
