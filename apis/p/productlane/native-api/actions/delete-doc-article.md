# Delete Doc Article with Productlane

Deletes a help center article from Productlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/articles/{id}`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Delete Doc Article](https://productlane.mintlify.dev/docs/api/docs/delete-doc-article)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Doc article ID to delete. |
