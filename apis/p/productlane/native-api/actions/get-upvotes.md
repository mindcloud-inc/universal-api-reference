# Get Upvotes with Productlane

Retrieves project upvotes from the Productlane portal.

## Endpoint

- **Method:** `GET`
- **Path:** `/portal/upvotes`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Get Upvotes](https://productlane.mintlify.dev/docs/api/portal/get-upvotes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `string` | no | Optional project ID filter. |
| `issueId` | query | `string` | no | Optional issue ID filter. |
