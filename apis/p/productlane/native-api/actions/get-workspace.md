# Get Workspace with Productlane

Retrieves a workspace from your Productlane account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/{id}`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Get Workspace](https://productlane.mintlify.dev/docs/api/workspaces/get-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workspace ID. |
