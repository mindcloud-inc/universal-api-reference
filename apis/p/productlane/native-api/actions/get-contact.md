# Get Contact with Productlane

Retrieves a contact from your Productlane workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Get Contact](https://productlane.mintlify.dev/docs/api/contacts/get-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
