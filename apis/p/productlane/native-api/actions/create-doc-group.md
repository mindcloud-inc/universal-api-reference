# Create Doc Group with Productlane

Creates a doc group in your Productlane help center.

## Endpoint

- **Method:** `POST`
- **Path:** `/docs/groups`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Create Doc Group](https://productlane.mintlify.dev/docs/api/docs/create-doc-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Docs group name. |
