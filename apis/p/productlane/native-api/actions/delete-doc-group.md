# Delete Doc Group with Productlane

Deletes a doc group from your Productlane help center.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/groups/{id}`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Delete Doc Group](https://productlane.mintlify.dev/docs/api/docs/delete-doc-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Doc group ID to delete. |
