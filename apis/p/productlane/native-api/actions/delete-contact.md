# Delete Contact with Productlane

Deletes an existing contact from Productlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Delete Contact](https://productlane.mintlify.dev/docs/api/contacts/delete-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
