# Delete Company with Productlane

Deletes an existing company from Productlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/:id`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [Delete Company](https://productlane.mintlify.dev/docs/api/companies/delete-company)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
