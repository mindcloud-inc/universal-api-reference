# List Contacts with Productlane

Retrieves contacts from your Productlane workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://productlane.com/api/v1`
- **Official documentation:** [List Contacts](https://productlane.mintlify.dev/docs/api/contacts/get-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
| `companyId` | query | `string` | no |
