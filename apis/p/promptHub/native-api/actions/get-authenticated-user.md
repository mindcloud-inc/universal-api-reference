# Get Authenticated User with PromptHub

Retrieves the authenticated user from PromptHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://app.prompthub.us/api/v1`
- **Official documentation:** [Get Authenticated User](https://intercom.help/prompthub/en/articles/8541389-prompthub-api-documentation)
