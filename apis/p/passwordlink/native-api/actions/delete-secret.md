# Delete Secret with Password.link

## Endpoint

- **Method:** `DELETE`
- **Path:** `/secrets/:id`
- **Base URL:** `https://password.link/api`
- **Official documentation:** [Delete Secret](https://password.link/en/p/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Password.link secret identifier. |
