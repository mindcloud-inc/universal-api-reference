# Suggest Tags For URL with Pinboard

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/suggest`
- **Base URL:** `https://api.pinboard.in/v1`
- **Official documentation:** [Suggest Tags For URL](https://pinboard.in/api/#posts_suggest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to suggest tags for. |
