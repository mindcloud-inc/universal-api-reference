# Get Note with Pinboard

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.pinboard.in/v1`
- **Official documentation:** [Get Note](https://pinboard.in/api/#notes_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Pinboard note ID. |
