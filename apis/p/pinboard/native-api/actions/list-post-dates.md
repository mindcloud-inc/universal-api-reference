# List Post Dates with Pinboard

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/dates`
- **Base URL:** `https://api.pinboard.in/v1`
- **Official documentation:** [List Post Dates](https://pinboard.in/api/#posts_dates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter by up to three tags. |
