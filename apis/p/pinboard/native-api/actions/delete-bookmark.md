# Delete Bookmark with Pinboard

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/delete`
- **Base URL:** `https://api.pinboard.in/v1`
- **Official documentation:** [Delete Bookmark](https://pinboard.in/api/#posts_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Bookmark URL to delete. |
