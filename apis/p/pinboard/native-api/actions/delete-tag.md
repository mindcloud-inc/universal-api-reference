# Delete Tag with Pinboard

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/delete`
- **Base URL:** `https://api.pinboard.in/v1`
- **Official documentation:** [Delete Tag](https://pinboard.in/api/#tags_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | yes | Tag to delete. |
