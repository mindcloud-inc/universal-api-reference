# Get PyPI Stats with PyPI

Retrieves package size statistics from PyPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/`
- **Base URL:** `https://pypi.org`
- **Official documentation:** [Get PyPI Stats](https://docs.pypi.org/api/stats/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
