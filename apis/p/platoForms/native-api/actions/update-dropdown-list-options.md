# Update Dropdown List Options with PlatoForms

Updates dropdown list options for a form in PlatoForms.

## Endpoint

- **Method:** `POST`
- **Path:** `/form/{{form_identifier}}/field/dropdown/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Update Dropdown List Options](https://apidocs.platoforms.com/#operation/form_field_dropdown_create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_identifier` | path | `string` | yes |
