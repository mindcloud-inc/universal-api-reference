# Create Form with PlatoForms

Creates a new form in PlatoForms.

## Endpoint

- **Method:** `POST`
- **Path:** `/form/{{form_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Create Form](https://apidocs.platoforms.com/#operation/form_create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_identifier` | path | `string` | yes |
