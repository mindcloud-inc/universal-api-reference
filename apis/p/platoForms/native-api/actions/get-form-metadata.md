# Get Form Metadata with PlatoForms

Retrieves metadata for a form from PlatoForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/{{form_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Get Form Metadata](https://apidocs.platoforms.com/#operation/form_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_identifier` | path | `string` | yes |
