# Update Form with PlatoForms

Updates an existing form in PlatoForms.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/form/{{form_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Update Form](https://apidocs.platoforms.com/#operation/form_partial_update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_identifier` | path | `string` | yes |
