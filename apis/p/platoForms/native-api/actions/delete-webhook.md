# Delete Webhook with PlatoForms

Deletes an existing webhook from PlatoForms.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{{web_hooks_id}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Delete Webhook](https://apidocs.platoforms.com/#operation/webhooks_delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `web_hooks_id` | path | `string` | yes |
