# Update Form Fields with PlatoForms

Updates form field definitions in PlatoForms.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/form/{{form_identifier}}/fields/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Update Form Fields](https://apidocs.platoforms.com/#operation/form_fields_partial_update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_identifier` | path | `string` | yes |
