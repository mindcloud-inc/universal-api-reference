# Get API User Information with PlatoForms

Retrieves the current API user's details from PlatoForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/me/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Get API User Information](https://apidocs.platoforms.com/#operation/me_list)
