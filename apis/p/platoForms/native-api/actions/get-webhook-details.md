# Get Webhook Details with PlatoForms

Retrieves webhook subscription details from PlatoForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{{web_hooks_id}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Get Webhook Details](https://apidocs.platoforms.com/#operation/webhooks_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `web_hooks_id` | path | `string` | yes |
