# Get Submission Revision History with PlatoForms

Retrieves submission revision history from PlatoForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/submission/rev/{{submission_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Get Submission Revision History](https://apidocs.platoforms.com/#operation/submission_rev_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `submission_identifier` | path | `string` | yes |
