# Delete Submission with PlatoForms

Deletes an existing submission from PlatoForms.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/submission/{{submission_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Delete Submission](https://apidocs.platoforms.com/#operation/submission_delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `submission_identifier` | path | `string` | yes |
