# Get Draft Submission Detail with PlatoForms

Retrieves draft submission details from PlatoForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/submission/draft/{{submission_identifier}}/`
- **Base URL:** `https://api.platoforms.com/v4`
- **Official documentation:** [Get Draft Submission Detail](https://apidocs.platoforms.com/#operation/submission_draft_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `submission_identifier` | path | `string` | yes |
