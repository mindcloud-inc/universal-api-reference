# Get Version Group with PokéAPI

Retrieves details for a version group from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version-group/:versionGroupId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Version Group](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionGroupId` | path | `string` | yes | Identifier for the requested Version Group record. |
