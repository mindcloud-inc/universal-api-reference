# List Pal Park Area with PokéAPI

Retrieves pal park areas from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pal-park-area`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pal Park Area](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
