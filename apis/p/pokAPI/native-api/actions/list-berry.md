# List Berry with PokéAPI

Retrieves berries from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Berry](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
