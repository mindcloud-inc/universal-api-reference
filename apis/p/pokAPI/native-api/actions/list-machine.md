# List Machine with PokéAPI

Retrieves machines from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `machine`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Machine](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
