# List Item with PokéAPI

Retrieves items from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Item](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
