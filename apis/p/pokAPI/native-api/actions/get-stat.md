# Get Stat with PokéAPI

Retrieves details for a stat from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `stat/:statId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Stat](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statId` | path | `string` | yes | Identifier for the requested Stat record. |
