# Get Move Learn Method with PokéAPI

Retrieves details for a move learn method from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-learn-method/:moveLearnMethodId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Learn Method](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveLearnMethodId` | path | `string` | yes | Identifier for the requested Move Learn Method record. |
