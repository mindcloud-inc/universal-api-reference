# List Generation with PokéAPI

Retrieves generations from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `generation`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Generation](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
