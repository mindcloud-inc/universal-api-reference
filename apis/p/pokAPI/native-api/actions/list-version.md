# List Version with PokéAPI

Retrieves versions from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Version](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
