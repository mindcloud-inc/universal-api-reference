# Get Pokemon Habitat with PokéAPI

Retrieves details for a pokemon habitat from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-habitat/:pokemonHabitatId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Habitat](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonHabitatId` | path | `string` | yes | Identifier for the requested Pokemon Habitat record. |
