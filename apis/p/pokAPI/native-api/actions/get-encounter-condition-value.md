# Get Encounter Condition Value with PokéAPI

Retrieves details for an encounter condition value from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-condition-value/:encounterConditionValueId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Encounter Condition Value](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `encounterConditionValueId` | path | `string` | yes | Identifier for the requested Encounter Condition Value record. |
