# Get Item Category with PokéAPI

Retrieves details for an item category from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-category/:itemCategoryId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item Category](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemCategoryId` | path | `string` | yes | Identifier for the requested Item Category record. |
