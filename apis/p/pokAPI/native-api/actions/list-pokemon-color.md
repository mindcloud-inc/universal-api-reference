# List Pokemon Color with PokéAPI

Retrieves pokemon colors from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-color`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon Color](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
