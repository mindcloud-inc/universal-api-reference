# List Item Category with PokéAPI

Retrieves item categories from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-category`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Item Category](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
