# List Item Pocket with PokéAPI

Retrieves item pockets from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-pocket`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Item Pocket](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
