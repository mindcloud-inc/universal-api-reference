# List Contest Effect with PokéAPI

Retrieves contest effects from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `contest-effect`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Contest Effect](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
