# Get Move Battle Style with PokéAPI

Retrieves details for a move battle style from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-battle-style/:moveBattleStyleId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Battle Style](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveBattleStyleId` | path | `string` | yes | Identifier for the requested Move Battle Style record. |
