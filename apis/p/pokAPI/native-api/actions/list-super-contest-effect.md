# List Super Contest Effect with PokéAPI

Retrieves super contest effects from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `super-contest-effect`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Super Contest Effect](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
