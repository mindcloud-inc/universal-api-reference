# List Move with PokéAPI

Retrieves moves from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
