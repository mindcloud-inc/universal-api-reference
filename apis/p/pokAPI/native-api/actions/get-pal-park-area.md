# Get Pal Park Area with PokéAPI

Retrieves details for a pal park area from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pal-park-area/:palParkAreaId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pal Park Area](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `palParkAreaId` | path | `string` | yes | Identifier for the requested Pal Park Area record. |
