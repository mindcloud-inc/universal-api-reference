# List Characteristic with PokéAPI

Retrieves characteristics from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `characteristic`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Characteristic](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
