# List Language with PokéAPI

Retrieves languages from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `language`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Language](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
