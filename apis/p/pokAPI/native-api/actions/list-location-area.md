# List Location Area with PokéAPI

Retrieves location areas from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `location-area`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Location Area](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
