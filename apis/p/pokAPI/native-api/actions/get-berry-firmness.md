# Get Berry Firmness with PokéAPI

Retrieves details for a berry firmness from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry-firmness/:berryFirmnessId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Berry Firmness](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `berryFirmnessId` | path | `string` | yes | Identifier for the requested Berry Firmness record. |
