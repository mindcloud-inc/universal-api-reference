# List Version Group with PokéAPI

Retrieves version groups from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version-group`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Version Group](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
