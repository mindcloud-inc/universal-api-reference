# List Item Fling Effect with PokéAPI

Retrieves item fling effects from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-fling-effect`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Item Fling Effect](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
