# List Berry Flavor with PokéAPI

Retrieves berry flavors from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry-flavor`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Berry Flavor](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
