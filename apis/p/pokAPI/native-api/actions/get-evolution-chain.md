# Get Evolution Chain with PokéAPI

Retrieves details for an evolution chain from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `evolution-chain/:evolutionChainId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Evolution Chain](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `evolutionChainId` | path | `string` | yes | Identifier for the requested Evolution Chain record. |
