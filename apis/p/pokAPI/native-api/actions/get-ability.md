# Get Ability with PokéAPI

Retrieves details for an ability from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `ability/:abilityId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Ability](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `abilityId` | path | `string` | yes | Identifier for the requested Ability record. |
