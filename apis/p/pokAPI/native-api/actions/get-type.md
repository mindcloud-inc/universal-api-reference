# Get Type with PokéAPI

Retrieves details for a type from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `type/:typeId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Type](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | Identifier for the requested Type record. |
