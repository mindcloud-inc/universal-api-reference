# Get Encounter Condition with PokéAPI

Retrieves details for an encounter condition from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-condition/:encounterConditionId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Encounter Condition](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `encounterConditionId` | path | `string` | yes | Identifier for the requested Encounter Condition record. |
