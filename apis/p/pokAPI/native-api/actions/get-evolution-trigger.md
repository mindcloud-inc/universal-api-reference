# Get Evolution Trigger with PokéAPI

Retrieves details for an evolution trigger from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `evolution-trigger/:evolutionTriggerId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Evolution Trigger](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `evolutionTriggerId` | path | `string` | yes | Identifier for the requested Evolution Trigger record. |
