# Get Item with PokéAPI

Retrieves details for an item from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item/:itemId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Identifier for the requested Item record. |
