# Get Pokeathlon Stat with PokéAPI

Retrieves details for a pokeathlon stat from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokeathlon-stat/:pokeathlonStatId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokeathlon Stat](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokeathlonStatId` | path | `string` | yes | Identifier for the requested Pokeathlon Stat record. |
