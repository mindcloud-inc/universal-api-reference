# List Nature with PokéAPI

Retrieves natures from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `nature`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Nature](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
