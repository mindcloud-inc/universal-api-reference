# Get Move Category with PokéAPI

Retrieves details for a move category from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-category/:moveCategoryId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Category](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveCategoryId` | path | `string` | yes | Identifier for the requested Move Category record. |
