# List Move Damage Class with PokéAPI

Retrieves move damage classes from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-damage-class`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Damage Class](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
