# List Type with PokéAPI

Retrieves types from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `type`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Type](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
