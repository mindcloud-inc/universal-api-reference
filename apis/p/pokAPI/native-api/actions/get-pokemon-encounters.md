# Get Pokemon Encounters with PokéAPI

Retrieves pokemon encounter locations from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon/:pokemonId/encounters`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Encounters](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonId` | path | `string` | yes | The Pokemon identifier or name. |
