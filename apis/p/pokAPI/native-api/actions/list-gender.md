# List Gender with PokéAPI

Retrieves genders from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `gender`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Gender](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
