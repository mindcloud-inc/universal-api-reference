# List Pokeathlon Stat with PokéAPI

Retrieves pokeathlon stats from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokeathlon-stat`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokeathlon Stat](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
