# List Pokemon with PokéAPI

Retrieves pokemon from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
