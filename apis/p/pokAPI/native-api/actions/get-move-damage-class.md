# Get Move Damage Class with PokéAPI

Retrieves details for a move damage class from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-damage-class/:moveDamageClassId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Damage Class](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveDamageClassId` | path | `string` | yes | Identifier for the requested Move Damage Class record. |
