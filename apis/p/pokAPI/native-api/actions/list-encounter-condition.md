# List Encounter Condition with PokéAPI

Retrieves encounter conditions from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-condition`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Encounter Condition](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
