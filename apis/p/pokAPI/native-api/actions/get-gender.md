# Get Gender with PokéAPI

Retrieves details for a gender from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `gender/:genderId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Gender](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `genderId` | path | `string` | yes | Identifier for the requested Gender record. |
