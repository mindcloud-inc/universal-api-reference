# Get Pokemon with PokéAPI

Retrieves details for a pokemon from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon/:pId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pId` | path | `string` | yes | Identifier for the requested Pokemon record. |
