# Get Nature with PokéAPI

Retrieves details for a nature from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `nature/:natureId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Nature](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `natureId` | path | `string` | yes | Identifier for the requested Nature record. |
