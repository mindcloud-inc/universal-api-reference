# List Move Battle Style with PokéAPI

Retrieves move battle styles from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-battle-style`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Battle Style](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
