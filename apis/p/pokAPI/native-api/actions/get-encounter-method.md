# Get Encounter Method with PokéAPI

Retrieves details for an encounter method from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-method/:encounterMethodId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Encounter Method](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `encounterMethodId` | path | `string` | yes | Identifier for the requested Encounter Method record. |
