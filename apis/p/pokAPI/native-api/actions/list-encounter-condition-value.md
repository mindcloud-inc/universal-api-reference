# List Encounter Condition Value with PokéAPI

Retrieves encounter condition values from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-condition-value`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Encounter Condition Value](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
