# List Pokemon Species with PokéAPI

Retrieves pokemon species from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-species`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon Species](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
