# List Move Learn Method with PokéAPI

Retrieves move learn methods from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-learn-method`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Learn Method](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
