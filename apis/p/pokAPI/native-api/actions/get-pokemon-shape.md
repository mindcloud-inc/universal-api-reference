# Get Pokemon Shape with PokéAPI

Retrieves details for a pokemon shape from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-shape/:pokemonShapeId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Shape](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonShapeId` | path | `string` | yes | Identifier for the requested Pokemon Shape record. |
