# Get Pokemon Color with PokéAPI

Retrieves details for a pokemon color from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-color/:pokemonColorId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Color](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonColorId` | path | `string` | yes | Identifier for the requested Pokemon Color record. |
