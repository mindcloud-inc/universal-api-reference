# List Pokemon Habitat with PokéAPI

Retrieves pokemon habitats from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-habitat`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon Habitat](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
