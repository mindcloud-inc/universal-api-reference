# Get Location Area with PokéAPI

Retrieves details for a location area from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `location-area/:locationAreaId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Location Area](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationAreaId` | path | `string` | yes | Identifier for the requested Location Area record. |
