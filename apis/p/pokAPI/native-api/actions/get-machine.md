# Get Machine with PokéAPI

Retrieves details for a machine from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `machine/:machineId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Machine](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `machineId` | path | `string` | yes | Identifier for the requested Machine record. |
