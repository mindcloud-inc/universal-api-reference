# List Pokemon Shape with PokéAPI

Retrieves pokemon shapes from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-shape`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon Shape](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
