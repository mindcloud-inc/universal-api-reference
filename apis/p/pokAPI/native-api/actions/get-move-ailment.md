# Get Move Ailment with PokéAPI

Retrieves details for a move ailment from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-ailment/:moveAilmentId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Ailment](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveAilmentId` | path | `string` | yes | Identifier for the requested Move Ailment record. |
