# Get Pokemon Species with PokéAPI

Retrieves details for a pokemon species from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-species/:pokemonSpeciesId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Species](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonSpeciesId` | path | `string` | yes | Identifier for the requested Pokemon Species record. |
