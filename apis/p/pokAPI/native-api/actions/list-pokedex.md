# List Pokedex with PokéAPI

Retrieves pokedexes from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokedex`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokedex](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
