# List Evolution Trigger with PokéAPI

Retrieves evolution triggers from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `evolution-trigger`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Evolution Trigger](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
