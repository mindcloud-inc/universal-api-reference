# Get Growth Rate with PokéAPI

Retrieves details for a growth rate from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `growth-rate/:growthRateId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Growth Rate](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `growthRateId` | path | `string` | yes | Identifier for the requested Growth Rate record. |
