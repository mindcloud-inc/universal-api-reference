# Get Berry Flavor with PokéAPI

Retrieves details for a berry flavor from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry-flavor/:berryFlavorId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Berry Flavor](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `berryFlavorId` | path | `string` | yes | Identifier for the requested Berry Flavor record. |
