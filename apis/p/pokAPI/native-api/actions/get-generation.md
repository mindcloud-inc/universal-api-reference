# Get Generation with PokéAPI

Retrieves details for a generation from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `generation/:generationId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Generation](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generationId` | path | `string` | yes | Identifier for the requested Generation record. |
