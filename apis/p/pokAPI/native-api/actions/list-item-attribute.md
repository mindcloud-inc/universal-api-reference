# List Item Attribute with PokéAPI

Retrieves item attributes from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-attribute`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Item Attribute](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
