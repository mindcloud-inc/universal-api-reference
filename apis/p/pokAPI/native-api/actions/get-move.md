# Get Move with PokéAPI

Retrieves details for a move from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move/:moveId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveId` | path | `string` | yes | Identifier for the requested Move record. |
