# List Pokemon Form with PokéAPI

Retrieves pokemon forms from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-form`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon Form](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
