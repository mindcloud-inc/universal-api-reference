# Get Contest Type with PokéAPI

Retrieves details for a contest type from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `contest-type/:contestTypeId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Contest Type](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contestTypeId` | path | `string` | yes | Identifier for the requested Contest Type record. |
