# Get Pokedex with PokéAPI

Retrieves details for a pokedex from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokedex/:pokedexId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokedex](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokedexId` | path | `string` | yes | Identifier for the requested Pokedex record. |
