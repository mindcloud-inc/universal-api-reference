# List Encounter Method with PokéAPI

Retrieves encounter methods from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `encounter-method`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Encounter Method](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
