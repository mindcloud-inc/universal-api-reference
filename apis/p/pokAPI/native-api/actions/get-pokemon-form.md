# Get Pokemon Form with PokéAPI

Retrieves details for a pokemon form from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-form/:pokemonFormId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Form](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonFormId` | path | `string` | yes | Identifier for the requested Pokemon Form record. |
