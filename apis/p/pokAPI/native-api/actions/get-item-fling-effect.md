# Get Item Fling Effect with PokéAPI

Retrieves details for an item fling effect from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-fling-effect/:itemFlingEffectId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item Fling Effect](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemFlingEffectId` | path | `string` | yes | Identifier for the requested Item Fling Effect record. |
