# Get Language with PokéAPI

Retrieves details for a language from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `language/:languageId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Language](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `languageId` | path | `string` | yes | Identifier for the requested Language record. |
