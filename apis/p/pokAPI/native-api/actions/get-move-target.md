# Get Move Target with PokéAPI

Retrieves details for a move target from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-target/:moveTargetId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Move Target](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moveTargetId` | path | `string` | yes | Identifier for the requested Move Target record. |
