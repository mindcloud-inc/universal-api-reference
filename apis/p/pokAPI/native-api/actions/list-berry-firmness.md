# List Berry Firmness with PokéAPI

Retrieves berry firmnesses from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry-firmness`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Berry Firmness](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
