# List Move Ailment with PokéAPI

Retrieves move ailments from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-ailment`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Ailment](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
