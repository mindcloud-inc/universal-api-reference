# Get Super Contest Effect with PokéAPI

Retrieves details for a super contest effect from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `super-contest-effect/:superContestEffectId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Super Contest Effect](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `superContestEffectId` | path | `string` | yes | Identifier for the requested Super Contest Effect record. |
