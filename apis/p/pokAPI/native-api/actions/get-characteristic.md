# Get Characteristic with PokéAPI

Retrieves details for a characteristic from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `characteristic/:characteristicId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Characteristic](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `characteristicId` | path | `string` | yes | Identifier for the requested Characteristic record. |
