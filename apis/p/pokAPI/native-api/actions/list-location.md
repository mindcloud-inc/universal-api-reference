# List Location with PokéAPI

Retrieves locations from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `location`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Location](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
