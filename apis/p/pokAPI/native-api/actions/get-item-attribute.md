# Get Item Attribute with PokéAPI

Retrieves details for an item attribute from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-attribute/:itemAttributeId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item Attribute](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemAttributeId` | path | `string` | yes | Identifier for the requested Item Attribute record. |
