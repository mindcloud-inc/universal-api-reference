# List Move Category with PokéAPI

Retrieves move categories from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-category`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Category](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
