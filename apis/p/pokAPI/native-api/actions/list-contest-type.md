# List Contest Type with PokéAPI

Retrieves contest types from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `contest-type`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Contest Type](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
