# List Egg Group with PokéAPI

Retrieves egg groups from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `egg-group`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Egg Group](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
