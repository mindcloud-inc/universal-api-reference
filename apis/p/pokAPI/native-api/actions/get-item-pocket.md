# Get Item Pocket with PokéAPI

Retrieves details for an item pocket from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item-pocket/:itemPocketId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item Pocket](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemPocketId` | path | `string` | yes | Identifier for the requested Item Pocket record. |
