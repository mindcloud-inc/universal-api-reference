# List Ability with PokéAPI

Retrieves abilities from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `ability`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Ability](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
