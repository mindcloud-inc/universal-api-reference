# List Evolution Chain with PokéAPI

Retrieves evolution chains from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `evolution-chain`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Evolution Chain](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
