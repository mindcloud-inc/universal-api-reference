# List Stat with PokéAPI

Retrieves stats from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `stat`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Stat](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
