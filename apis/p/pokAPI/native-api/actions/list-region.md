# List Region with PokéAPI

Retrieves regions from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `region`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Region](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
