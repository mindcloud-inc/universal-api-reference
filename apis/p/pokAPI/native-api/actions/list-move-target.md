# List Move Target with PokéAPI

Retrieves move targets from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `move-target`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Move Target](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
