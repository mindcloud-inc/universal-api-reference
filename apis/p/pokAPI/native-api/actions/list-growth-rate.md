# List Growth Rate with PokéAPI

Retrieves growth rates from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `growth-rate`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Growth Rate](https://pokeapi.co/docs/v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
