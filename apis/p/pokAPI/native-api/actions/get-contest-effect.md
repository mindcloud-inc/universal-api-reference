# Get Contest Effect with PokéAPI

Retrieves details for a contest effect from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `contest-effect/:contestEffectId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Contest Effect](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contestEffectId` | path | `string` | yes | Identifier for the requested Contest Effect record. |
