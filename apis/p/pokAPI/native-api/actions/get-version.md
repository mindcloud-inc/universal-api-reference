# Get Version with PokéAPI

Retrieves details for a version from PokéAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version/:versionId`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Version](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Identifier for the requested Version record. |
