# Delete Item with Plasmic

Deletes an item from Plasmic CMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rows/:rowId`
- **Base URL:** `https://data.plasmic.app/api/v1/cms`
- **Official documentation:** [Delete Item](https://docs.plasmic.app/learn/plasmic-cms-api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowId` | path | `string` | yes | The Plasmic row identifier to delete. |
