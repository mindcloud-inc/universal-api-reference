# Publish Item with Plasmic

Publishes an item in Plasmic CMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/rows/:rowId/publish`
- **Base URL:** `https://data.plasmic.app/api/v1/cms`
- **Official documentation:** [Publish Item](https://docs.plasmic.app/learn/plasmic-cms-api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowId` | path | `string` | yes | The Plasmic row identifier to publish. |
