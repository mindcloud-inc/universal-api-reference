# Get Project with Pushpad

Retrieves a specific project from Pushpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://pushpad.xyz/api/v1`
- **Official documentation:** [Get Project](https://pushpad.xyz/docs/rest_api#projects_api_docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
