# Delete Project with Pushpad

Deletes an existing project from Pushpad asynchronously.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://pushpad.xyz/api/v1`
- **Official documentation:** [Delete Project](https://pushpad.xyz/docs/rest_api#projects_api_docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
