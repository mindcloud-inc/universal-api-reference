# Get Notification with Pushpad

Retrieves a Pushpad notification and its stats.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/:notification_id`
- **Base URL:** `https://pushpad.xyz/api/v1`
- **Official documentation:** [Get Notification](https://pushpad.xyz/docs/rest_api#notifications_api_docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `notification_id` | path | `number` | yes |
