# Cancel Scheduled Notification with Pushpad

Cancels a scheduled notification in Pushpad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/notifications/:notification_id/cancel`
- **Base URL:** `https://pushpad.xyz/api/v1`
- **Official documentation:** [Cancel Scheduled Notification](https://pushpad.xyz/docs/rest_api#notifications_api_docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `notification_id` | path | `number` | yes |
