# Delete Sender with Pushpad

Deletes an existing sender from Pushpad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/senders/:sender_id`
- **Base URL:** `https://pushpad.xyz/api/v1`
- **Official documentation:** [Delete Sender](https://pushpad.xyz/docs/rest_api#senders_api_docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sender_id` | path | `number` | yes |
