# Get Campaign with Peach

Retrieves a campaign from Peach.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://api.peach-in.com/v4`
- **Official documentation:** [Get Campaign](https://peach-organization.gitbook.io/peach/api-reference/campaigns/get-campiagn)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique identifier of the campaign to retrieve. |
