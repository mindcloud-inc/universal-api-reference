# Delete Contact with Peach

Deletes an existing contact from Peach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deleteContact`
- **Base URL:** `https://api.peach-in.com/v4`
- **Official documentation:** [Delete Contact](https://peach-organization.gitbook.io/peach/api-reference/contacts/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | body | `string` | yes | The contact ID to delete. |
