# Get Contact By ID with Peach

Retrieves a contact from Peach by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/getContact`
- **Base URL:** `https://api.peach-in.com/v4`
- **Official documentation:** [Get Contact By ID](https://peach-organization.gitbook.io/peach/api-reference/contacts/get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | body | `string` | yes | The contact ID to look up. |
