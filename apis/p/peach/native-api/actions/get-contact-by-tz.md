# Get Contact By Tz with Peach

Retrieves a contact from Peach by tz identifier.

## Endpoint

- **Method:** `POST`
- **Path:** `/getContact`
- **Base URL:** `https://api.peach-in.com/v4`
- **Official documentation:** [Get Contact By Tz](https://peach-organization.gitbook.io/peach/api-reference/contacts/get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tz` | body | `string` | yes | The tz identifier to look up. |
