# List Board Section Pins with Pinterest

Retrieves pins from a Pinterest board section.

## Endpoint

- **Method:** `GET`
- **Path:** `boards/:boardId/sections/:sectionId/pins`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Board Section Pins](https://developers.pinterest.com/docs/api/v5/#operation/board_sections/list_pins)

## Capabilities

This operation supports [pagination](../README.md#pagination).
