# List Boards with Pinterest

Retrieves the current user's boards from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `boards`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Boards](https://developers.pinterest.com/docs/api/v5/#operation/boards/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
