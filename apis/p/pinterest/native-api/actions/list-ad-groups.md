# List Ad Groups with Pinterest

Retrieves ad groups from a Pinterest ad account.

## Endpoint

- **Method:** `GET`
- **Path:** `ad_accounts/:adAccountId/ad_groups`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Ad Groups](https://developers.pinterest.com/docs/api/v5/#operation/ad_groups/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
