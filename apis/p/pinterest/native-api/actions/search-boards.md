# Search Boards with Pinterest

Finds boards in Pinterest by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `search/boards`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [Search Boards](https://developers.pinterest.com/docs/api/v5/#operation/search_user_boards/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
