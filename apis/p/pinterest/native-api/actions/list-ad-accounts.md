# List Ad Accounts with Pinterest

Retrieves ad accounts from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `ad_accounts`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Ad Accounts](https://developers.pinterest.com/docs/api/v5/#operation/ad_accounts/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
