# List Board Pins with Pinterest

Retrieves pins from a Pinterest board.

## Endpoint

- **Method:** `GET`
- **Path:** `boards/:boardId/pins`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Board Pins](https://developers.pinterest.com/docs/api/v5/#operation/boards/list_pins)

## Capabilities

This operation supports [pagination](../README.md#pagination).
