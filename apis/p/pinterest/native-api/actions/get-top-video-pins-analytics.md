# Get Top Video Pins Analytics with Pinterest

Retrieves top video pin analytics from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `user_account/analytics/top_video_pins`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [Get Top Video Pins Analytics](https://developers.pinterest.com/docs/api/v5/#operation/user_account/analytics/top_video_pins)
