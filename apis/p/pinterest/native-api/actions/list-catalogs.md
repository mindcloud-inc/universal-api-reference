# List Catalogs with Pinterest

Retrieves catalogs from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `catalogs`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Catalogs](https://developers.pinterest.com/docs/api/v5/#operation/catalogs/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
