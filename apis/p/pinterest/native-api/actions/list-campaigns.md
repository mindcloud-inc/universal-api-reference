# List Campaigns with Pinterest

Retrieves campaigns from a Pinterest ad account.

## Endpoint

- **Method:** `GET`
- **Path:** `ad_accounts/:adAccountId/campaigns`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Campaigns](https://developers.pinterest.com/docs/api/v5/#operation/campaigns/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
