# Create Catalog with Pinterest

Creates a new catalog in Pinterest.

## Endpoint

- **Method:** `POST`
- **Path:** `catalogs`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [Create Catalog](https://developers.pinterest.com/docs/api/v5/#operation/catalogs/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ad_account_id` | query | `string` | no |
| `catalog_type` | body | `list` | no |
| `name` | body | `string` | no |
