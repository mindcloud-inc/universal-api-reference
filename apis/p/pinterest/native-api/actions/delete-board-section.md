# Delete Board Section with Pinterest

Deletes an existing board section from Pinterest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `boards/:boardId/sections/:sectionId`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [Delete Board Section](https://developers.pinterest.com/docs/api/v5/#operation/board_sections/delete)
