# List Pins with Pinterest

Retrieves the current user's pins from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `pins`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Pins](https://developers.pinterest.com/docs/api/v5/#operation/pins/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
