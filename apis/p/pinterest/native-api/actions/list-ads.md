# List Ads with Pinterest

Retrieves ads from a Pinterest ad account.

## Endpoint

- **Method:** `GET`
- **Path:** `ad_accounts/:adAccountId/ads`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Ads](https://developers.pinterest.com/docs/api/v5/#operation/ads/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
