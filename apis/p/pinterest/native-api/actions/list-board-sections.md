# List Board Sections with Pinterest

Retrieves board sections from a Pinterest board.

## Endpoint

- **Method:** `GET`
- **Path:** `boards/:boardId/sections`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Board Sections](https://developers.pinterest.com/docs/api/v5/#operation/board_sections/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
