# Get Catalog Item Batch Status with Pinterest

Retrieves the status of a Pinterest catalog item batch.

## Endpoint

- **Method:** `GET`
- **Path:** `catalogs/items/batch/:batchId`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [Get Catalog Item Batch Status](https://developers.pinterest.com/docs/api/v5/#operation/items_batch/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
