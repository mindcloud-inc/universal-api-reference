# List Product Groups with Pinterest

Retrieves product groups from a Pinterest catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `catalogs/product_groups`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Product Groups](https://developers.pinterest.com/docs/api/v5/#operation/catalogs_product_groups/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
