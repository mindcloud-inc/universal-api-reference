# List Followers with Pinterest

Retrieves the current user's followers from Pinterest.

## Endpoint

- **Method:** `GET`
- **Path:** `user_account/followers`
- **Base URL:** `https://api.pinterest.com/v5`
- **Official documentation:** [List Followers](https://developers.pinterest.com/docs/api/v5/#operation/followers/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
