# Get Run with ParseHub

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/{run_token}`
- **Base URL:** `https://www.parsehub.com/api/v2`
- **Official documentation:** [Get Run](https://www.parsehub.com/docs/ref/api/v2/#get-a-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_token` | path | `string` | yes | The ParseHub token of the run to fetch. |
