# Get Last Ready Data (JSON) with ParseHub

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_token}/last_ready_run/data`
- **Base URL:** `https://www.parsehub.com/api/v2`
- **Official documentation:** [Get Last Ready Data (JSON)](https://www.parsehub.com/docs/ref/api/v2/#get-last-ready-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_token` | path | `string` | yes | The ParseHub token of the project whose latest ready data you want. |
