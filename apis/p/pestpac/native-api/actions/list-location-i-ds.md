# List Location IDs with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `Locations/LocationIDList`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `branchId` | query | `string` | no |
| `skip` | query | `string` | no |
