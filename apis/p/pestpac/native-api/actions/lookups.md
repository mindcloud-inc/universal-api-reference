# Lookups with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `/lookups/:lookupKey`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `lookupKey` | path | `string` | no |
| `branchId` | query | `string` | no |
