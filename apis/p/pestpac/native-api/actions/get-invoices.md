# Get Invoices with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `Invoices`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderNumber` | query | `string` | no |
| `orderId` | query | `string` | no |
| `invoiceNumber` | query | `string` | no |
