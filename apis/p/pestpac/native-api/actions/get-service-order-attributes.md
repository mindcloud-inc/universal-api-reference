# Get Service Order Attributes with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `ServiceOrders/:orderId/attributes`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | no |
