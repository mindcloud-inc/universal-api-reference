# Get Documents by Location ID with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `Locations/:locationId/documents`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`
- **Official documentation:** [Get Documents by Location ID](https://developer.workwave.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `number` | yes | PestPac Location ID to list documents for. |
