# List Service Orders with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `ServiceOrders`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `startWorkDate` | query | `string` | no |
| `endWorkDate` | query | `string` | no |
| `posted` | query | `boolean` | no |
