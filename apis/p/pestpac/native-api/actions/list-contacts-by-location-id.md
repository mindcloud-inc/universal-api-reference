# List Contacts by Location Id with PestPac

## Endpoint

- **Method:** `GET`
- **Path:** `Locations/{{locationId}}/contacts`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locationId` | path | `string` | no |
