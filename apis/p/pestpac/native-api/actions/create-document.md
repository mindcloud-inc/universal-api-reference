# Create Document with PestPac

## Endpoint

- **Method:** `POST`
- **Path:** `Documents`
- **Base URL:** `https://api.workwave.com/pestpac/v1/`
- **Official documentation:** [Create Document](https://developer.workwave.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `LocationID` | body | `number` | yes |
| `Name` | body | `string` | yes |
| `URL` | body | `string` | no |
| `Date` | body | `date` | yes |
| `Tags` | body | `string` | no |
