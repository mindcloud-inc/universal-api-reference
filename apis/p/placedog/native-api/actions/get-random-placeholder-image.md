# Get Random Placeholder Image with Placedog

Retrieves a random placeholder dog image from Placedog.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:width]/[:height]`
- **Base URL:** `https://placedog.net`
- **Official documentation:** [Get Random Placeholder Image](https://placedog.net/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `width` | path | `number` | yes |
| `height` | path | `number` | yes |
