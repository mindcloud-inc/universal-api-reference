# Get Placeholder Image By X Dimensions with Placedog

Retrieves a placeholder dog image from Placedog using x dimensions.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:width]x[:height]`
- **Base URL:** `https://placedog.net`
- **Official documentation:** [Get Placeholder Image By X Dimensions](https://placedog.net/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `width` | path | `number` | yes |
| `height` | path | `number` | yes |
