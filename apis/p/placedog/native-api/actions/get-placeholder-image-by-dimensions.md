# Get Placeholder Image By Dimensions with Placedog

Retrieves a placeholder dog image from Placedog by width and height.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:width]/[:height]`
- **Base URL:** `https://placedog.net`
- **Official documentation:** [Get Placeholder Image By Dimensions](https://placedog.net/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `width` | path | `number` | yes |
| `height` | path | `number` | yes |
