# Get Placeholder Image with Placedog

Retrieves a placeholder dog image from Placedog by width.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:width]`
- **Base URL:** `https://placedog.net`
- **Official documentation:** [Get Placeholder Image](https://placedog.net/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `width` | path | `number` | yes | Image width from 1 to 1000. |
