# List Presentations with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/presentation/all`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [List Presentations](https://docs.presenton.ai/api-reference/presentation/get-all-user-presentations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `page_size` | query | `number` | no | Number of presentations to return per page. |
