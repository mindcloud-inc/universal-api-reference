# Get Presentation Editor View with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/presentation/:id/ui`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Presentation Editor View](https://docs.presenton.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The presentation ID to retrieve in editor view. |
