# Get Async Presentation Generation Status with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/presentation/status/:id`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Async Presentation Generation Status](https://docs.presenton.ai/api-reference/presentation/check-async-presentation-generation-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The async task ID to check. |
