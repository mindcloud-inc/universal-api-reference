# Unsubscribe from Webhook V3 with Presenton

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/webhook/unsubscribe`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Unsubscribe from Webhook V3](https://docs.presenton.ai/api-reference/v3-webhook/unsubscribe-to-webhook-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Webhook subscription ID to remove. |
