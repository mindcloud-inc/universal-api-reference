# Get Template with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/template/:id`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Template](https://docs.presenton.ai/api-reference/template/get-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template ID to retrieve. |
