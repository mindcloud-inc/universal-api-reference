# Get Standard Template Example with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/standard-template/:id/example`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Standard Template Example](https://docs.presenton.ai/api-reference/v3-standard-template/get-standard-template-example)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The standard template ID to use for the example. |
