# Get Standard Template with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/standard-template/:id`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Standard Template](https://docs.presenton.ai/api-reference/v3-standard-template/get-standard-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The standard template ID to retrieve. |
