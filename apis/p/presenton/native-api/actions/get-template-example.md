# Get Template Example with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/template/:id/example`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Template Example](https://docs.presenton.ai/api-reference/template/get-template-example)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template ID to use for the example. |
