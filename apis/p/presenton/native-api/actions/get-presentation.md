# Get Presentation with Presenton

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ppt/presentation/:id`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Get Presentation](https://docs.presenton.ai/api-reference/presentation/get-presentation-and-slides-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The presentation ID to retrieve. |
