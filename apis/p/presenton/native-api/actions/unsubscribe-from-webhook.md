# Unsubscribe from Webhook with Presenton

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/webhook/unsubscribe`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Unsubscribe from Webhook](https://docs.presenton.ai/api-reference/webhook/unsubscribe-to-webhook-v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Webhook subscription ID to remove. |
