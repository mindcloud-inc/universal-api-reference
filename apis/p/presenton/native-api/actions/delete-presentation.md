# Delete Presentation with Presenton

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/ppt/presentation/:id`
- **Base URL:** `https://api.presenton.ai`
- **Official documentation:** [Delete Presentation](https://docs.presenton.ai/api-reference/presentation/delete-presentation-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The presentation ID to delete. |
