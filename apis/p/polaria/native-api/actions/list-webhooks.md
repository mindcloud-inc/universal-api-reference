# List Webhooks with Polaria

Retrieves webhooks from a Polaria brand.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/[:api_key]/webhooks`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [List Webhooks](https://help.polaria.ai/hc/rest-api-webhooks/get-widgets-api_key-webhooks-list-webhooks-2?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | path | `string` | yes | The Polaria widget API key for the target brand. |
