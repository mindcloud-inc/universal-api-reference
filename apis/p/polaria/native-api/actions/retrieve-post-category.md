# Retrieve Post Category with Polaria

Retrieves a post category from Polaria.

## Endpoint

- **Method:** `GET`
- **Path:** `/faq_categories/[:id]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Retrieve Post Category](https://help.polaria.ai/hc/rest-api-post-categories/get-faq_categories-id-retrieve-a-post-category?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the post category to retrieve. |
