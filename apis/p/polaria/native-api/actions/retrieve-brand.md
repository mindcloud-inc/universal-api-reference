# Retrieve Brand with Polaria

Retrieves a brand from Polaria by API key.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/[:api_key]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Retrieve Brand](https://help.polaria.ai/hc/rest-api-brands/get-widgets-api_key-retrieve-a-brand?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | path | `string` | yes | The Polaria widget API key for the target brand. |
