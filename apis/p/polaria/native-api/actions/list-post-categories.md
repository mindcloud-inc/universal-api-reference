# List Post Categories with Polaria

Retrieves post categories from Polaria.

## Endpoint

- **Method:** `GET`
- **Path:** `/faq_categories`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [List Post Categories](https://help.polaria.ai/hc/rest-api-post-categories/get-faq_categories-list-post-categories?lang=en)
