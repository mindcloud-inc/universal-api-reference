# Delete Contact with Polaria

Deletes a contact from Polaria.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/widgets/[:api_key]/contacts/[:id]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Delete Contact](https://help.polaria.ai/hc/rest-api-contacts/del-widgets-api_key-contacts-id-delete-a-contact?lang=en)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `api_key` | path | `string` | yes |
| `id` | path | `string` | yes |
