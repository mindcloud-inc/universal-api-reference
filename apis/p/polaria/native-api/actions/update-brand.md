# Update Brand with Polaria

Updates an existing brand in Polaria.

## Endpoint

- **Method:** `PUT`
- **Path:** `/widgets/[:api_key]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Update Brand](https://help.polaria.ai/hc/rest-api-brands/put-widgets-api_key-update-a-brand?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | path | `string` | yes | The Polaria widget API key for the target brand. |
| `name` | body | `string` | no | — |
