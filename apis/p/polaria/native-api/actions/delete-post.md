# Delete Post with Polaria

Deletes a post from Polaria.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/faqs/[:id]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Delete Post](https://help.polaria.ai/hc/rest-api-posts/del-faqs-id-delete-a-post?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the post to delete. |
