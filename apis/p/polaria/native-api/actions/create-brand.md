# Create Brand with Polaria

Creates a new brand in Polaria.

## Endpoint

- **Method:** `POST`
- **Path:** `/widgets`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Create Brand](https://help.polaria.ai/hc/rest-api-brands/post-widgets-create-a-brand?lang=en)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
