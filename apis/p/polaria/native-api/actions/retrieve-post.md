# Retrieve Post with Polaria

Retrieves a post from Polaria.

## Endpoint

- **Method:** `GET`
- **Path:** `/faqs/[:id]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Retrieve Post](https://help.polaria.ai/hc/rest-api-posts/get-faqs-id-retrieve-a-post?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the post to retrieve. |
