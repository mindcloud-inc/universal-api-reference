# Delete Brand with Polaria

Deletes a brand from Polaria.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/widgets/[:api_key]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Delete Brand](https://help.polaria.ai/hc/rest-api-brands/del-widgets-api_key-delete-a-brand?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | path | `string` | yes | The Polaria widget API key for the target brand. |
