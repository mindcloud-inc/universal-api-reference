# List Contacts with Polaria

Retrieves contacts from a Polaria brand.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/[:api_key]/contacts`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [List Contacts](https://help.polaria.ai/hc/rest-api-contacts/get-widgets-api_key-contacts-list-contacts?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | path | `string` | yes | The Polaria widget API key for the target brand. |
