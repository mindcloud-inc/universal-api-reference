# Delete Post Category with Polaria

Deletes a post category from Polaria.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/faq_categories/[:id]`
- **Base URL:** `https://app.polaria.ai/rest/v2`
- **Official documentation:** [Delete Post Category](https://help.polaria.ai/hc/rest-api-post-categories/del-faq_categories-id-delete-a-post?lang=en)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the post category to delete. |
