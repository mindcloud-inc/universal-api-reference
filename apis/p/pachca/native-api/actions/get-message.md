# Get message with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get message](https://dev.pachca.com/reference/messages-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca message ID. |
