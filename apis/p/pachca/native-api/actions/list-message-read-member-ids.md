# List message read member IDs with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/{id}/read_member_ids`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [List message read member IDs](https://dev.pachca.com/reference/messages-id-read-member-ids)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca message ID. |
