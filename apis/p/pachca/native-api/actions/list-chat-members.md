# List chat members with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/{id}/members`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [List chat members](https://dev.pachca.com/reference/chats-id-members)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca chat ID. |
