# Get group tag with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/group_tags/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get group tag](https://dev.pachca.com/reference/group-tags-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca group tag ID. |
