# Get user with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get user](https://dev.pachca.com/reference/users-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca user ID. |
