# Delete message with Pachca

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messages/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Delete message](https://dev.pachca.com/reference/messages-id-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca message ID. |
