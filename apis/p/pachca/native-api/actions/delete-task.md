# Delete task with Pachca

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Delete task](https://dev.pachca.com/reference/tasks-id-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca task ID. |
