# Get thread with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get thread](https://dev.pachca.com/reference/threads-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca thread ID. |
