# Get chat with Pachca

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/{id}`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get chat](https://dev.pachca.com/reference/chats-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pachca chat ID. |
