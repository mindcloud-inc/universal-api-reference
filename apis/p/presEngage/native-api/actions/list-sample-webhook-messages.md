# List Sample Webhook Messages with PresEngage

Retrieves sample webhook message data from PresEngage for setup.

## Endpoint

- **Method:** `GET`
- **Path:** `/hooks/performList`
- **Base URL:** `https://shared.presengage.com/functions/v1/presengage-api`
- **Official documentation:** [List Sample Webhook Messages](https://developer.presengage.com/)
