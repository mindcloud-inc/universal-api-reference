# List Department Employees with Planday

Retrieves employees in a Planday department.

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/v1.0/departments/:id/employees`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [List Department Employees](https://openapi.planday.com/api/hr/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
