# List Shift Statuses with Planday

Retrieves a list of shift statuses from Planday.

## Endpoint

- **Method:** `GET`
- **Path:** `/scheduling/v1.0/shifts/shiftstatus/all`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [List Shift Statuses](https://openapi.planday.com/api/schedule/)
