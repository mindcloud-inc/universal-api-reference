# List Today's Employee Shifts with Planday

Retrieves today's employee shifts from Planday.

## Endpoint

- **Method:** `GET`
- **Path:** `/punchclock/v1.0/employeeshifts/today`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [List Today's Employee Shifts](https://openapi.planday.com/api/punchclock/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeId` | query | `number` | no |
