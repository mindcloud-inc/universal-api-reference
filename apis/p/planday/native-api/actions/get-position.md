# Get Position with Planday

Retrieves an existing position from Planday.

## Endpoint

- **Method:** `GET`
- **Path:** `/scheduling/v1.0/positions/:positionId`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [Get Position](https://openapi.planday.com/api/schedule/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `positionId` | path | `number` | yes |
