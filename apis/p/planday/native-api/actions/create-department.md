# Create Department with Planday

Creates a new department in Planday.

## Endpoint

- **Method:** `POST`
- **Path:** `/hr/v1.0/departments`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [Create Department](https://openapi.planday.com/api/hr/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `number` | body | `string` | no |
