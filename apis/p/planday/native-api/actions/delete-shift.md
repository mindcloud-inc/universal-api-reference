# Delete Shift with Planday

Deletes an existing shift from Planday.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/scheduling/v1.0/shifts/:shiftId`
- **Base URL:** `https://openapi.planday.com`
- **Official documentation:** [Delete Shift](https://openapi.planday.com/api/schedule/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shiftId` | path | `number` | yes |
