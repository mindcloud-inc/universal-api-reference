# List Subscriptions with Payfunnels

Retrieves a list of subscriptions from Payfunnels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriptions`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [List Subscriptions](https://api.payfunnels.com/api/docs/#returns-list-of-subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
