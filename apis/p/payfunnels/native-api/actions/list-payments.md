# List Payments with Payfunnels

Retrieves a list of payments from Payfunnels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payments`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [List Payments](https://api.payfunnels.com/api/docs/#returns-list-of-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
