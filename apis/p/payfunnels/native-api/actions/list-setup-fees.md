# List Setup Fees with Payfunnels

Retrieves a list of setup fees from Payfunnels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fees/setup`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [List Setup Fees](https://api.payfunnels.com/api/docs/#list-one-time-setup-fees)

## Capabilities

This operation supports [pagination](../README.md#pagination).
