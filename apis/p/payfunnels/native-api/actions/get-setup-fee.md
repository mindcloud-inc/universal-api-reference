# Get Setup Fee with Payfunnels

Retrieves a setup fee from Payfunnels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fees/setup/{id}`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [Get Setup Fee](https://api.payfunnels.com/api/docs/#get-one-time-setup-fees-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the setup fee to retrieve. |
