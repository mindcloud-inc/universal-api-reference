# Get Subscription with Payfunnels

Retrieves a subscription from Payfunnels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriptions/{id}`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [Get Subscription](https://api.payfunnels.com/api/docs/#returns-subscription-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the subscription to retrieve. |
