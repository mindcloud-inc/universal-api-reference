# Get Payment with Payfunnels

Retrieves a payment from Payfunnels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payments/{id}`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [Get Payment](https://api.payfunnels.com/api/docs/#returns-payment-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the payment to retrieve. |
