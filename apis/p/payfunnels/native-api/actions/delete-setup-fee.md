# Delete Setup Fee with Payfunnels

Deletes an existing setup fee from Payfunnels.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/fees/setup/{id}`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [Delete Setup Fee](https://api.payfunnels.com/api/docs/#delete-one-time-setup-fees)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the setup fee to delete. |
