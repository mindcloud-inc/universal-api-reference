# Get Payment Link with Payfunnels

Retrieves a payment link from Payfunnels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/paymentlinks/{id}`
- **Base URL:** `https://api.payfunnels.com`
- **Official documentation:** [Get Payment Link](https://api.payfunnels.com/api/docs/#returns-payment-link-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the payment link to retrieve. |
