# Get Balances with PostcardMania

Retrieves account balances from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/balance`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Balances](https://docs.pcmintegrations.com/docs/directmail-api/wb42dvrda7mdq)
