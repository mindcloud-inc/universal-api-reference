# List Favorites with PostcardMania

Retrieves favorite designs from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/favorites`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Favorites](https://docs.pcmintegrations.com/docs/directmail-api/scurf2n9nkaly)
