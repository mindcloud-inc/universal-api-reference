# Place Greeting Card Order with PostcardMania

Creates a new greeting card order in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/greeting-card`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Greeting Card Order](https://docs.pcmintegrations.com/docs/directmail-api/32c5b9fdoseh0)
