# Get Order Mail Tracking with PostcardMania

Retrieves mail tracking for a PostcardMania order.

## Endpoint

- **Method:** `GET`
- **Path:** `/order/{{orderID}}/mail-tracking`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Order Mail Tracking](https://docs.pcmintegrations.com/docs/directmail-api/92547af449aa8-direct-mail-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderID` | path | `string` | no | Internal order identifier. |
