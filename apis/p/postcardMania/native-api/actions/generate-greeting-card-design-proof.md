# Generate Greeting Card Design Proof with PostcardMania

Creates a greeting card design proof in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/design/generate-proof/greeting-card`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Generate Greeting Card Design Proof](https://docs.pcmintegrations.com/docs/directmail-api/tvfmzffl7dxcr)
