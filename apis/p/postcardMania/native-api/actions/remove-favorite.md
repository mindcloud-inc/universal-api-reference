# Remove Favorite with PostcardMania

Deletes an existing favorite from PostcardMania.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/gallery/favorites`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Remove Favorite](https://docs.pcmintegrations.com/docs/directmail-api/ftr8buwowrb01)
