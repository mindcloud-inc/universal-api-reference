# List Design Tags with PostcardMania

Retrieves tags for a PostcardMania design.

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/tags/{{designID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Design Tags](https://docs.pcmintegrations.com/docs/directmail-api/taolgqq6tv5wx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | no | Internal design identifier. |
