# List Demographic Options (Beta) with PostcardMania

Retrieves beta demographic options from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/demographics`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Demographic Options (Beta)](https://docs.pcmintegrations.com/docs/directmail-api/9wms32o8hwei3-get-list-demographics-beta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listType` | query | `string` | no | Recipient list type key from Get List Types (BETA). Example: IRL. |
