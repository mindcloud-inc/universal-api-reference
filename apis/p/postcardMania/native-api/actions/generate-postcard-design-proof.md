# Generate Postcard Design Proof with PostcardMania

Creates a postcard design proof in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/design/generate-proof/postcard`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Generate Postcard Design Proof](https://docs.pcmintegrations.com/docs/directmail-api/lbgea1ignycjv)
