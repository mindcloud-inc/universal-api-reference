# Place Brochure Order with List Count with PostcardMania

Creates a brochure order from a list count in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/brochure/with-list-count`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Brochure Order with List Count](https://docs.pcmintegrations.com/docs/directmail-api/ia3y208ptnvzr)
