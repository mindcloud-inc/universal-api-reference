# List Suppressed Addresses with PostcardMania

Retrieves suppressed addresses from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppression-list`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Suppressed Addresses](https://docs.pcmintegrations.com/docs/directmail-api/953lez0oqsza9)
