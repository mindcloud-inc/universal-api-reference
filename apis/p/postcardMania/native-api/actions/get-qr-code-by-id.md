# Get QR Code by Id with PostcardMania

Retrieves a QR code from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr-code/{{qrCodeID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get QR Code by Id](https://docs.pcmintegrations.com/docs/directmail-api/q1wjlwbbt9lrh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrCodeID` | path | `string` | no | Internal QR code identifier. |
