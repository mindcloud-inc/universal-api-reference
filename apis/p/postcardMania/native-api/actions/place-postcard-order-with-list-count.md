# Place Postcard Order with List Count with PostcardMania

Creates a postcard order from a list count in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/postcard/with-list-count`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Postcard Order with List Count](https://docs.pcmintegrations.com/docs/directmail-api/f9c7a78b2bb20)
