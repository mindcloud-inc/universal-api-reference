# List Gallery Designs with PostcardMania

Retrieves gallery designs from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/designs`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Gallery Designs](https://docs.pcmintegrations.com/docs/directmail-api/4l1p7s1ecfdzr)
