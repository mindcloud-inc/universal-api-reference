# Get Order with PostcardMania

Retrieves an order from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/order/{{orderID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Order](https://docs.pcmintegrations.com/docs/directmail-api/70eb9283f87ef)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderID` | path | `string` | no | Numeric PostcardMania order identifier. |
| `orderID` | path | `string` | no | The order identifier. |
