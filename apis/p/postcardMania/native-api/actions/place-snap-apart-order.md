# Place Snap-Apart Order with PostcardMania

Creates a new snap-apart order in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/snap-apart`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Snap-Apart Order](https://docs.pcmintegrations.com/docs/directmail-api/xclc333y2rd0a)
