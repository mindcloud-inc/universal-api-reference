# Get Detailed Batch Mail Tracking with PostcardMania

Retrieves detailed mail tracking for a PostcardMania batch.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch/{{batchID}}/mail-tracking-detailed`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Detailed Batch Mail Tracking](https://docs.pcmintegrations.com/docs/directmail-api/92547af449aa8-direct-mail-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchID` | path | `string` | no | Internal batch identifier. |
