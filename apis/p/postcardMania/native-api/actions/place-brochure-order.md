# Place Brochure Order with PostcardMania

Creates a new brochure order in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/brochure`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Brochure Order](https://docs.pcmintegrations.com/docs/directmail-api/0lk4yl0coc1e6)
