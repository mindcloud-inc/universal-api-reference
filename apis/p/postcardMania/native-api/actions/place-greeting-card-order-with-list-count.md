# Place Greeting Card Order with List Count with PostcardMania

Creates a greeting card order from a list count in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/greeting-card/with-list-count`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Greeting Card Order with List Count](https://docs.pcmintegrations.com/docs/directmail-api/vieoc2kdskeeh)
