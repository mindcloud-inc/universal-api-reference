# List Undeliverable Recipients with PostcardMania

Retrieves undeliverable recipients from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipient/undeliverable`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Undeliverable Recipients](https://docs.pcmintegrations.com/docs/directmail-api/wg1e1306pkidh)
