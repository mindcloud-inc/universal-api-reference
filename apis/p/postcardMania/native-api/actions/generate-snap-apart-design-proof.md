# Generate Snap Apart Design Proof with PostcardMania

Creates a snap-apart design proof in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/design/generate-proof/snap-apart`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Generate Snap Apart Design Proof](https://docs.pcmintegrations.com/docs/directmail-api/q9blg22vnn4s2)
