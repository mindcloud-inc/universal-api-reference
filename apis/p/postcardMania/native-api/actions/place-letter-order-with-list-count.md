# Place Letter Order with List Count with PostcardMania

Creates a letter order from a list count in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/letter/with-list-count`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Letter Order with List Count](https://docs.pcmintegrations.com/docs/directmail-api/04960fa178488)
