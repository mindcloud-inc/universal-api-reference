# Place Snap-Apart Order with List Count with PostcardMania

Creates a snap-apart order from a list count in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/order/snap-apart/with-list-count`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Place Snap-Apart Order with List Count](https://docs.pcmintegrations.com/docs/directmail-api/352wuxnk4nib3)
