# Verify Recipients with PostcardMania

Verifies mailing recipients in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/recipient/verify`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Verify Recipients](https://docs.pcmintegrations.com/docs/directmail-api/k49y925eo4waw)
