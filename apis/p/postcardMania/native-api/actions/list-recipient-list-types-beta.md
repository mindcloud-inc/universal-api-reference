# List Recipient List Types (Beta) with PostcardMania

Retrieves beta recipient list types from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/types`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [List Recipient List Types (Beta)](https://docs.pcmintegrations.com/docs/directmail-api/455f0d2caecd4-get-list-types-beta)
