# Edit Designer Design with PostcardMania

Retrieves an edit session for a PostcardMania design.

## Endpoint

- **Method:** `GET`
- **Path:** `/design/{{designID}}/edit`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Edit Designer Design](https://docs.pcmintegrations.com/docs/directmail-api/wys5o1p1fiq6g)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `number` | yes | Internal design identifier. |
