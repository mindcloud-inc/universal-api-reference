# Get Batch with PostcardMania

Retrieves a batch from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch/{{batchID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Batch](https://docs.pcmintegrations.com/docs/directmail-api/b84f873587f9b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchID` | path | `string` | no | Numeric PostcardMania batch identifier. |
| `batchID` | path | `string` | no | The batch identifier. |
