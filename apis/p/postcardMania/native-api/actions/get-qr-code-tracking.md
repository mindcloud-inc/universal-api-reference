# Get QR Code Tracking with PostcardMania

Retrieves tracking for a PostcardMania QR code.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr-code/{{qrCodeID}}/tracking`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get QR Code Tracking](https://docs.pcmintegrations.com/docs/directmail-api/3u34crunm2sdh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrCodeID` | path | `string` | no | Internal QR code identifier. |
