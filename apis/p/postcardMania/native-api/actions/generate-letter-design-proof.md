# Generate Letter Design Proof with PostcardMania

Creates a letter design proof in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/design/generate-proof/letter`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Generate Letter Design Proof](https://docs.pcmintegrations.com/docs/directmail-api/mxy7r9t0zn812)
