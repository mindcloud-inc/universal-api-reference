# Create Designer Design with PostcardMania

Creates a new designer design in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/design/custom`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Create Designer Design](https://docs.pcmintegrations.com/docs/directmail-api/76to9yvq9gav1)
