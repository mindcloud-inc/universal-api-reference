# Get Design with PostcardMania

Retrieves a design from PostcardMania.

## Endpoint

- **Method:** `GET`
- **Path:** `/design/{{designID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Get Design](https://docs.pcmintegrations.com/docs/directmail-api/7fc283678ad23)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | no | Numeric PostcardMania design identifier. |
