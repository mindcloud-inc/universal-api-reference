# Add Favorite with PostcardMania

Creates a new favorite design in PostcardMania.

## Endpoint

- **Method:** `POST`
- **Path:** `/gallery/favorites`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Add Favorite](https://docs.pcmintegrations.com/docs/directmail-api/puwo0pmljutyt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | body | `number` | yes | Internal design identifier to favorite. |
