# Remove Design with PostcardMania

Deletes an existing design from PostcardMania.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/design/{{designID}}`
- **Base URL:** `https://v3.pcmintegrations.com`
- **Official documentation:** [Remove Design](https://docs.pcmintegrations.com/docs/directmail-api/cy77m4nleab57)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | no | The design identifier to delete. |
