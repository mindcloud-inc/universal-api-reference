# Create Userflow Sign with Prerender.io

Creates a Userflow signature in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/userflow/sign`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Userflow Sign](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | body | `list<string>` | yes |
