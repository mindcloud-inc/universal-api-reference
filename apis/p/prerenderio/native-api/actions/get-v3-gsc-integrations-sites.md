# List Gsc Integrations Sites with Prerender.io

Retrieves GSC integration sites from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/gsc-integrations/sites`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Gsc Integrations Sites](https://api.prerender.io/v3/api)
