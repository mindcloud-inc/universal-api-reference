# List Gsc Integrations Status with Prerender.io

Retrieves GSC integration status from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/gsc-integrations/status`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Gsc Integrations Status](https://api.prerender.io/v3/api)
