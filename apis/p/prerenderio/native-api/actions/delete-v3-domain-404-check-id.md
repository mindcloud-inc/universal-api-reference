# Delete Domain 404 Check with Prerender.io

Deletes a domain 404 check from Prerender.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/domain-404-check/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Delete Domain 404 Check](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
