# Create Ai Insights Diagnostics with Prerender.io

Creates an AI insights diagnostics report in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/ai-insights/diagnostics`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Ai Insights Diagnostics](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | body | `string` | yes |
