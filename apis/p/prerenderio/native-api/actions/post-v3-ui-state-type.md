# Create Ui State with Prerender.io

Creates a UI state entry in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/ui-state/{type}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Ui State](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `state` | body | `object` | yes |
| `type` | path | `string` | yes |
