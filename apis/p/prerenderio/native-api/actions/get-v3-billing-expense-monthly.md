# List Billing Expense Monthly with Prerender.io

Retrieves monthly billing expenses from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/billing/expense/monthly`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Billing Expense Monthly](https://api.prerender.io/v3/api)
