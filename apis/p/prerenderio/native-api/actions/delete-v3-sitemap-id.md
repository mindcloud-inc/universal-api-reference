# Delete Sitemap with Prerender.io

Deletes a sitemap entry from Prerender.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/sitemap/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Delete Sitemap](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
