# List Referrals with Prerender.io

Retrieves referrals from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/referrals`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Referrals](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
| `sort` | query | `string` | no |
| `sortDirection` | query | `string` | no |
