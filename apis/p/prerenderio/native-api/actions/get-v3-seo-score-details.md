# List Seo Score Details with Prerender.io

Retrieves SEO score details from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/seo/score/details`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Seo Score Details](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `adaptive_type` | query | `string` | yes |
| `url` | query | `string` | yes |
