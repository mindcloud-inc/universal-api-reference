# List Sitemap with Prerender.io

Retrieves sitemap entries from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/sitemap`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Sitemap](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | yes |
