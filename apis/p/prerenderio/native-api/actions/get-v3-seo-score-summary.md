# List Seo Score Summary with Prerender.io

Retrieves an SEO score summary from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/seo/score/summary`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Seo Score Summary](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domainId` | query | `string` | yes |
