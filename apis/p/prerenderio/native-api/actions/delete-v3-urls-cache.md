# Delete Urls Cache with Prerender.io

Deletes cached URLs from Prerender.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/urls/cache`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Delete Urls Cache](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `wildcard` | body | `string` | yes |
