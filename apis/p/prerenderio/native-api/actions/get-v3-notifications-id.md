# Get Notifications with Prerender.io

Retrieves a notification from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/notifications/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Notifications](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
