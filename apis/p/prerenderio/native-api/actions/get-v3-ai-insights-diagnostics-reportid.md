# Get Ai Insights Diagnostics with Prerender.io

Retrieves an AI insights diagnostics report from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/ai-insights/diagnostics/{reportId}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Ai Insights Diagnostics](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reportId` | path | `string` | yes |
