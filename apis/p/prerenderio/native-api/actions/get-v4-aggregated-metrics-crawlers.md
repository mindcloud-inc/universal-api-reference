# List Aggregated Metrics Crawlers with Prerender.io

Retrieves crawler metrics from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/aggregated-metrics/crawlers`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Aggregated Metrics Crawlers](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | no |
