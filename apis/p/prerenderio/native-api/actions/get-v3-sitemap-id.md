# Get Sitemap with Prerender.io

Retrieves a sitemap entry from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/sitemap/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Sitemap](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
