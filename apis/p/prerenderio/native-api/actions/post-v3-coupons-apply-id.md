# Create Coupons Apply with Prerender.io

Applies a coupon in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/coupons/apply/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Coupons Apply](https://api.prerender.io/v3/api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `user-agent` | `MindCloud` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
