# Create Gsc Integrations Sitemaps Imports with Prerender.io

Creates a GSC sitemap import in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/gsc-integrations/sitemaps/imports`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Gsc Integrations Sitemaps Imports](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | yes |
