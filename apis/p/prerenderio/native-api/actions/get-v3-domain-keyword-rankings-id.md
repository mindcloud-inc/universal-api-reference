# Get Domain Keyword Rankings with Prerender.io

Retrieves a domain keyword ranking from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/domain-keyword-rankings/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Domain Keyword Rankings](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
