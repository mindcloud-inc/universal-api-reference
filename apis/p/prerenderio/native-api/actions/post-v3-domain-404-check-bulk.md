# Create Domain 404 Check Bulk with Prerender.io

Creates bulk domain 404 checks in Prerender.io.

- **Path:** `/v3/domain-404-check/bulk`
- **Base URL:** `https://api.prerender.io`

| --- | --- | --- | --- |
