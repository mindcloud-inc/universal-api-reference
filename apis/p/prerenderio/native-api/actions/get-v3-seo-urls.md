# List Seo Urls with Prerender.io

Retrieves SEO URLs from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/seo/urls`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Seo Urls](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `adaptive_type` | query | `string` | no |
| `domain` | query | `string` | no |
| `domainId` | query | `string` | no |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
| `q` | query | `string` | no |
| `sort` | query | `string` | no |
| `sortDirection` | query | `string` | no |
