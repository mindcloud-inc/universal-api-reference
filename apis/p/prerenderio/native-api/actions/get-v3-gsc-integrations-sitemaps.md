# List Gsc Integrations Sitemaps with Prerender.io

Retrieves GSC integration sitemaps from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/gsc-integrations/sitemaps`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Gsc Integrations Sitemaps](https://api.prerender.io/v3/api)
