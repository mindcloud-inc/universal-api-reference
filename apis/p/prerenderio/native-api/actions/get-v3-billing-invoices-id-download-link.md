# Get Billing Invoices Download Link with Prerender.io

Retrieves an invoice download link from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/billing/invoices/{id}/download-link`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Billing Invoices Download Link](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
