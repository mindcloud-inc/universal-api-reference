# Create Coupons Deactivate with Prerender.io

Deactivates a coupon in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/coupons/deactivate/{id}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Coupons Deactivate](https://api.prerender.io/v3/api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `user-agent` | `MindCloud` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
