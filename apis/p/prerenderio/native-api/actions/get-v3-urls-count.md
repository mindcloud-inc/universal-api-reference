# List Urls Count with Prerender.io

Retrieves a URL count from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/urls/count`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Urls Count](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `wildcard` | query | `string` | yes |
| `wildcard_type` | query | `string` | yes |
