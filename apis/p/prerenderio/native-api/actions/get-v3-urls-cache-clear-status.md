# List Urls Cache Clear Status with Prerender.io

Retrieves URL cache clear status from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/urls/cache-clear-status`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Urls Cache Clear Status](https://api.prerender.io/v3/api)
