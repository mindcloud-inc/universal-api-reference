# Create Urls with Prerender.io

Creates a URL in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/urls`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Urls](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `urls` | body | `list<object>` | yes |
