# Create Referrals with Prerender.io

Creates a referral in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/referrals`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Referrals](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | yes |
| `name` | body | `string` | yes |
