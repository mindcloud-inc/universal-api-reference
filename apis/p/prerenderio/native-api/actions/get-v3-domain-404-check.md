# List Domain 404 Check with Prerender.io

Retrieves domain 404 checks from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/domain-404-check`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Domain 404 Check](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | yes |
