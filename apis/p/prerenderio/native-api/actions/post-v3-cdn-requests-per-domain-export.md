# Create Cdn Requests Per Domain Export with Prerender.io

Creates a CDN requests-per-domain export in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/cdn-requests-per-domain-export`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Cdn Requests Per Domain Export](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `from` | query | `string` | yes |
| `to` | query | `string` | yes |
