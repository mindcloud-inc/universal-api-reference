# Update Sitemap Toggle All with Prerender.io

Updates all sitemap entries in Prerender.io.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v3/sitemap/toggle-all/{enabled}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Update Sitemap Toggle All](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `enabled` | path | `boolean` | yes |
