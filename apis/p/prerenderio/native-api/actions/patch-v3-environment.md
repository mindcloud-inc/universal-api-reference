# Update Environment with Prerender.io

Updates environment settings in Prerender.io.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v3/environment`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Update Environment](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ignoreAllQueryParams` | body | `boolean` | no |
| `queryParamsWhitelist` | body | `boolean` | no |
