# List Aggregated Metrics Trial Overview with Prerender.io

Retrieves a trial overview from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/aggregated-metrics/trial-overview`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Aggregated Metrics Trial Overview](https://api.prerender.io/v3/api)
