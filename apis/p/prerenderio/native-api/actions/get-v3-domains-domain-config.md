# Get Domains Config with Prerender.io

Retrieves config for a domain from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/domains/{domain}/config`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Get Domains Config](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | path | `string` | yes |
