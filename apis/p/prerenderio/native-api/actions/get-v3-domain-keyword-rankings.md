# List Domain Keyword Rankings with Prerender.io

Retrieves domain keyword rankings from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/domain-keyword-rankings`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Domain Keyword Rankings](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
