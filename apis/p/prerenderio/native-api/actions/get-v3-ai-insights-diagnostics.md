# List Ai Insights Diagnostics with Prerender.io

Retrieves AI insights diagnostics from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/ai-insights/diagnostics`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Ai Insights Diagnostics](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | yes |
| `pageSize` | query | `number` | yes |
| `sortBy` | query | `string` | no |
| `sortDirection` | query | `string` | no |
