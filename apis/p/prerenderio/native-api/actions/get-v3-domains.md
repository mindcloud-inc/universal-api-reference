# List Domains with Prerender.io

Retrieves domains from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/domains`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Domains](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | yes |
