# Update Domain 404 Check Toggle All with Prerender.io

Updates all domain 404 checks in Prerender.io.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v3/domain-404-check/toggle-all/{enabled}`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Update Domain 404 Check Toggle All](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `enabled` | path | `boolean` | yes |
