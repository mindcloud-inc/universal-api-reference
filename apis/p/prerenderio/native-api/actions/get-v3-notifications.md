# List Notifications with Prerender.io

Retrieves notifications from Prerender.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/notifications`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [List Notifications](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `category` | query | `string` | no |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
| `unread` | query | `boolean` | no |
