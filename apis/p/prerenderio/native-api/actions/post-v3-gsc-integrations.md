# Create Gsc Integrations with Prerender.io

Creates a GSC integration in Prerender.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/gsc-integrations`
- **Base URL:** `https://api.prerender.io`
- **Official documentation:** [Create Gsc Integrations](https://api.prerender.io/v3/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `code` | body | `string` | yes |
