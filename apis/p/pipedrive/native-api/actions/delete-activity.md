# Delete Activity with Pipedrive

Deletes an existing activity from Pipedrive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v2/activities/:id`
- **Base URL:** `{api_domain}/api`
- **Official documentation:** [Delete Activity](https://developers.pipedrive.com/docs/api/v1/Activities#deleteActivity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique ID of the activity to delete. |
