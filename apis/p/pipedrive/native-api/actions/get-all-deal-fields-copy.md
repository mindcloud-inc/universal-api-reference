# Get All Product Fields with Pipedrive

Retrieves product fields from Pipedrive.

## Endpoint

- **Method:** `GET`
- **Path:** `v2/productFields`
- **Base URL:** `{api_domain}/api`
- **Official documentation:** [Get All Product Fields](https://developers.pipedrive.com/docs/api/v1/DealFields#getDealFields)

## Capabilities

This operation supports [pagination](../README.md#pagination).
