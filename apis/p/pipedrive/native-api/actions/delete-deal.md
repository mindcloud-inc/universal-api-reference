# Delete Deal with Pipedrive

Deletes an existing deal from Pipedrive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v2/deals/:id`
- **Base URL:** `{api_domain}/api`
- **Official documentation:** [Delete Deal](https://developers.pipedrive.com/docs/api/v1/Deals#deleteDeal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique ID of the deal to delete. |
