# Get Bear Image with PlaceBear

## Endpoint

- **Method:** `GET`
- **Path:** `/:width/:height`
- **Base URL:** `https://placebear.com`
- **Official documentation:** [Get Bear Image](https://placebear.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `width` | path | `number` | yes | Requested image width in pixels. |
| `height` | path | `number` | yes | Requested image height in pixels. |
