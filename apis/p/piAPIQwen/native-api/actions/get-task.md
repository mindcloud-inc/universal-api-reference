# Get Task with PiAPI/Qwen

Retrieves task status details from PiAPI/Qwen.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/{task_id}`
- **Base URL:** `https://api.piapi.ai/api/v1`
- **Official documentation:** [Get Task](https://piapi.ai/docs/qwen-image-api/get-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
