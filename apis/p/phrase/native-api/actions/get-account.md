# Get Account with Phrase

Retrieves a single account from Phrase.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/{id}`
- **Base URL:** `https://api.phrase.com/v2`
- **Official documentation:** [Get Account](https://developers.phrase.com/en/api/strings/accounts/get-a-single-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Phrase account id to fetch. |
