# Get Project with Phrase

Retrieves a single project from Phrase.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{id}`
- **Base URL:** `https://api.phrase.com/v2`
- **Official documentation:** [Get Project](https://developers.phrase.com/en/api/strings/projects/get-a-single-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Phrase project id to fetch. |
