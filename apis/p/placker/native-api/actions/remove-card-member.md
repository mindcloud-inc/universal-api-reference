# Remove Card Member with Placker

## Endpoint

- **Method:** `DELETE`
- **Path:** `/card/:card/member/:member`
- **Base URL:** `https://api.placker.com`
- **Official documentation:** [Remove Card Member](https://placker.com/docs/api/paths/card.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card` | path | `number` | yes | Card ID. |
| `member` | path | `number` | yes | Member ID. |
