# List Card Checklists with Placker

## Endpoint

- **Method:** `GET`
- **Path:** `/card/:card/checklist`
- **Base URL:** `https://api.placker.com`
- **Official documentation:** [List Card Checklists](https://placker.com/docs/api/paths/card.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card` | path | `number` | yes | Card ID. |
