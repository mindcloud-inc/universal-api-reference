# List Card Comments with Placker

## Endpoint

- **Method:** `GET`
- **Path:** `/card/:card/comment`
- **Base URL:** `https://api.placker.com`
- **Official documentation:** [List Card Comments](https://placker.com/docs/api/paths/card.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card` | path | `number` | yes | Card ID. |
