# List Computer Scales with PrintNode

Retrieves scales for a specific computer from PrintNode.

## Endpoint

- **Method:** `GET`
- **Path:** `/computer/:computerId/scales`
- **Base URL:** `https://api.printnode.com`
- **Official documentation:** [List Computer Scales](https://www.printnode.com/en/docs/api/curl#scales-http)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `computerId` | path | `string` | yes | PrintNode computer ID. |
