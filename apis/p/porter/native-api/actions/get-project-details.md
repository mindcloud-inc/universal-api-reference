# Get Project Details with Porter

Retrieves project details from Porter.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/projects/:projectId`
- **Base URL:** `https://dashboard.porter.run`
- **Official documentation:** [Get Project Details](https://docs.porter.run/standard/cli/command-reference/porter-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The Porter project ID to inspect. |
