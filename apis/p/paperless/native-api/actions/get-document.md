# Get Document with Paperless

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://app.paperless.io/api/v1`
- **Official documentation:** [Get Document](https://developers.paperless.io/docs/api/529adde2f023e-create-and-send-your-first-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Paperless document ID. |
