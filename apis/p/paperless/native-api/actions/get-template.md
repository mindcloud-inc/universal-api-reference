# Get Template with Paperless

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://app.paperless.io/api/v1`
- **Official documentation:** [Get Template](https://developers.paperless.io/docs/api/95ee69b4b848f-using-templates-with-the-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Paperless template ID. |
