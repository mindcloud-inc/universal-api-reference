# Get Reservation Payment Amount with Planyo

Retrieves a reservation payment amount from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [Get Reservation Payment Amount](https://www.planyo.com/api.php?topic=get_reservation_payment_amount)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reservation_id` | query | `number` | yes |
