# List Reservation Payments with Planyo

Retrieves reservation payments from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [List Reservation Payments](https://www.planyo.com/api.php?topic=list_reservation_payments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reservation_id` | query | `number` | yes |
