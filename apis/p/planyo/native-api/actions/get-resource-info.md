# Get Resource Info with Planyo

Retrieves resource information from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [Get Resource Info](https://www.planyo.com/api.php?topic=get_resource_info)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `resource_id` | query | `number` | yes |
