# Get Site Info with Planyo

Retrieves site information from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [Get Site Info](https://www.planyo.com/api.php?topic=get_site_info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | query | `number` | no | Optional site ID for metasite API keys. |
