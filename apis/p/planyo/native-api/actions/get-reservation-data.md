# Get Reservation Data with Planyo

Retrieves reservation data from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [Get Reservation Data](https://www.planyo.com/api.php?topic=get_reservation_data)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reservation_id` | query | `number` | yes |
