# Get User Data with Planyo

Retrieves user data from Planyo.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://www.planyo.com/rest`
- **Official documentation:** [Get User Data](https://www.planyo.com/api.php?topic=get_user_data)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | query | `number` | no |
| `email` | query | `string` | no |
| `site_id` | query | `number` | no |
| `detail_level` | query | `number` | no |
