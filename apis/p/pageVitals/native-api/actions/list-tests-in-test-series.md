# List Tests in Test Series with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/testseries/:seriesId`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Tests in Test Series](https://pagevitals.com/docs/rest-api/reference/tests/test-series/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `seriesId` | path | `string` | yes |
