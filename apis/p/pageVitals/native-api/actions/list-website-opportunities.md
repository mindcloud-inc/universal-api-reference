# List Website Opportunities with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/opportunities`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Website Opportunities](https://pagevitals.com/docs/rest-api/reference/opportunities/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
