# List Pages with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/pages`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Pages](https://pagevitals.com/docs/rest-api/reference/pages/page-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | The internal ID of the website. |
