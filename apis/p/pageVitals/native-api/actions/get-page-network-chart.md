# Get Page Network Chart with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/pages/:pageId/network`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Get Page Network Chart](https://pagevitals.com/docs/rest-api/reference/pages/network/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `pageId` | path | `string` | yes |
| `device` | query | `string` | yes |
