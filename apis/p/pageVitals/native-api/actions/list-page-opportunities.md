# List Page Opportunities with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/pages/:pageId/opportunities`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Page Opportunities](https://pagevitals.com/docs/rest-api/reference/pages/opportunities/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `pageId` | path | `string` | yes |
| `device` | query | `string` | yes |
