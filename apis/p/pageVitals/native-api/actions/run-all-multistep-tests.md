# Run All Multistep Tests with PageVitals

## Endpoint

- **Method:** `POST`
- **Path:** `/:websiteId/multistep/run-all`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Run All Multistep Tests](https://pagevitals.com/docs/rest-api/reference/multistep/list/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
