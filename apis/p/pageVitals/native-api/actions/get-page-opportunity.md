# Get Page Opportunity with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/pages/:pageId/opportunities/:opportunityId`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Get Page Opportunity](https://pagevitals.com/docs/rest-api/reference/pages/opportunities/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `pageId` | path | `string` | yes |
| `opportunityId` | path | `string` | yes |
| `device` | query | `string` | yes |
