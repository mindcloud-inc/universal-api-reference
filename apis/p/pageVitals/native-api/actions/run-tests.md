# Run Tests with PageVitals

## Endpoint

- **Method:** `POST`
- **Path:** `/:websiteId/testseries`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Run Tests](https://pagevitals.com/docs/rest-api/reference/tests/test-series/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
