# List Field Testing Resources with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/field-testing/resources`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Field Testing Resources](https://pagevitals.com/docs/rest-api/reference/field-testing/resources/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
