# Get Test Waterfall with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/tests/:testId/waterfall`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Get Test Waterfall](https://pagevitals.com/docs/rest-api/reference/tests/test-detail/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `testId` | path | `string` | yes |
