# List Budgets with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/budgets`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Budgets](https://pagevitals.com/docs/rest-api/reference/budgets/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
