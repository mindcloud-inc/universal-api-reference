# List Multistep Test Runs with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/multistep/:testId/runs`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Multistep Test Runs](https://pagevitals.com/docs/rest-api/reference/multistep/runs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `testId` | path | `string` | yes |
