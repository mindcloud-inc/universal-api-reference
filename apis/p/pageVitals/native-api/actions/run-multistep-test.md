# Run Multistep Test with PageVitals

## Endpoint

- **Method:** `POST`
- **Path:** `/:websiteId/multistep/:testId/runs`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Run Multistep Test](https://pagevitals.com/docs/rest-api/reference/multistep/runs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `testId` | path | `string` | yes |
