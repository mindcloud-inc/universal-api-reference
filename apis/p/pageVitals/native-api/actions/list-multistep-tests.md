# List Multistep Tests with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/multistep`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [List Multistep Tests](https://pagevitals.com/docs/rest-api/reference/multistep/list/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
