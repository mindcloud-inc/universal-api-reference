# Get Page CrUX Timeline with PageVitals

## Endpoint

- **Method:** `GET`
- **Path:** `/:websiteId/pages/:pageId/crux`
- **Base URL:** `https://api.pagevitals.com`
- **Official documentation:** [Get Page CrUX Timeline](https://pagevitals.com/docs/rest-api/reference/pages/crux/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `websiteId` | path | `string` | yes |
| `pageId` | path | `string` | yes |
| `device` | query | `string` | yes |
