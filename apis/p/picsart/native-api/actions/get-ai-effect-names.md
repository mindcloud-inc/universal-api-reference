# Get AI Effect Names with Picsart

Retrieves supported AI effect names from Picsart.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/1.0/effects/ai`
- **Base URL:** `https://api.picsart.io`
- **Official documentation:** [Get AI Effect Names](https://docs.picsart.io/reference/image-list-ai-effect-names)
