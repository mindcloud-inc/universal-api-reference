# Get Event with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [Get Event](https://api.pencilspaces.com/guide/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The Pencil eventId of the event to retrieve. |
