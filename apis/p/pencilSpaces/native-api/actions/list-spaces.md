# List Spaces with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [List Spaces](https://api.pencilspaces.com/guide/spaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | query | `string` | no | Base64-encoded Pencil spaces filter payload. |
