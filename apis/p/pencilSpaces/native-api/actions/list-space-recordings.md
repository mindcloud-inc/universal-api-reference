# List Space Recordings with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/recordings/:spaceId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [List Space Recordings](https://api.pencilspaces.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | The Space whose recordings you want to list. |
