# End Ongoing Session with Pencil Spaces

## Endpoint

- **Method:** `POST`
- **Path:** `/spaces/:spaceId/endOngoingSession`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [End Ongoing Session](https://api.pencilspaces.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | The Space with an ongoing session to end. |
