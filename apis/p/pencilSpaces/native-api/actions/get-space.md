# Get Space with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [Get Space](https://api.pencilspaces.com/guide/spaces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | The Pencil spaceId of the Space to retrieve. |
