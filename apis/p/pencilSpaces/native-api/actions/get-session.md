# Get Session with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/sessions/:sessionId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [Get Session](https://api.pencilspaces.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | The session to retrieve. |
