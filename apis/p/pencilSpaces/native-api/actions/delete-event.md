# Delete Event with Pencil Spaces

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/:eventId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [Delete Event](https://api.pencilspaces.com/guide/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The Pencil eventId of the event to delete. |
