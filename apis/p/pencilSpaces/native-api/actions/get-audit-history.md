# Get Audit History with Pencil Spaces

## Endpoint

- **Method:** `GET`
- **Path:** `/audit/:documentId`
- **Base URL:** `https://apis.pencilapp.com/public/api`
- **Official documentation:** [Get Audit History](https://api.pencilspaces.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The audited document to inspect. |
