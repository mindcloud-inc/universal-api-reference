# Get Hourly Time Labels with Plausible Analytics

Retrieves hourly time-series metrics with labels from Plausible Analytics.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/query`
- **Base URL:** `https://plausible.io`
- **Official documentation:** [Get Hourly Time Labels](https://plausible.io/docs/stats-api)
