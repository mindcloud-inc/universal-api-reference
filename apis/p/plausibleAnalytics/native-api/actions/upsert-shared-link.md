# Upsert Shared Link with Plausible Analytics

Finds or creates a shared dashboard link in Plausible Analytics.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/sites/shared-links`
- **Base URL:** `https://plausible.io`
- **Official documentation:** [Upsert Shared Link](https://plausible.io/docs/sites-api)
