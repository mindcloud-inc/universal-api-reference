# Filter Case Insensitively with Plausible Analytics

Retrieves filtered stats from Plausible Analytics using case-insensitive matching.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/query`
- **Base URL:** `https://plausible.io`
- **Official documentation:** [Filter Case Insensitively](https://plausible.io/docs/stats-api)
