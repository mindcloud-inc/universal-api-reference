# Get Product with Productboard

Retrieves a product from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [Get Product](https://developer.productboard.com/reference/getproduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID from Productboard. |
