# List All Users with Productboard

Retrieves users from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [List All Users](https://developer.productboard.com/reference/getusers)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
