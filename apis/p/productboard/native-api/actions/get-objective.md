# Get Objective with Productboard

Retrieves an objective from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives/:id`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [Get Objective](https://developer.productboard.com/reference/getobjective)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Objective ID from Productboard. |
