# Get Component with Productboard

Retrieves a component from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/components/:id`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [Get Component](https://developer.productboard.com/reference/getcomponent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Component ID from Productboard. |
