# Get Release with Productboard

Retrieves a release from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/releases/:id`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [Get Release](https://developer.productboard.com/reference/getrelease)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Release ID from Productboard. |
