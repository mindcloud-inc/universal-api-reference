# Get Feature with Productboard

Retrieves a feature from your Productboard workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/features/:id`
- **Base URL:** `https://api.productboard.com`
- **Official documentation:** [Get Feature](https://developer.productboard.com/reference/getfeature)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Feature ID from Productboard. |
