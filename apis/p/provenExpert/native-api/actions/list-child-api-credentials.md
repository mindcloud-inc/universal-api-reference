# List Child API Credentials with ProvenExpert

Lists API credentials for child profiles in ProvenExpert.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/api/children`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [List Child API Credentials](https://developer.provenexpert.com/index_en.html#auth-api-children)
