# Get Profile Settings with ProvenExpert

Retrieves your profile settings from ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/profile/settings/get`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Get Profile Settings](https://developer.provenexpert.com/index_en.html#profile-settings-get)
