# Get API Credentials with ProvenExpert

Retrieves your ProvenExpert API credentials.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/api/get`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Get API Credentials](https://developer.provenexpert.com/index_en.html#auth-api-get)
