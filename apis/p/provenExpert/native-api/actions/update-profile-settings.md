# Update Profile Settings with ProvenExpert

Updates your profile settings in ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/profile/settings/update`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Update Profile Settings](https://developer.provenexpert.com/index_en.html#profile-settings-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data.public` | body | `number` | no | Whether the profile should be public after the settings update. |
