# List Child Rating Summaries with ProvenExpert

Lists child profile rating summaries in ProvenExpert.

## Endpoint

- **Method:** `GET`
- **Path:** `/rating/summary/children`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [List Child Rating Summaries](https://developer.provenexpert.com/index_en.html#rating-summary-children)
