# List Child Profiles with ProvenExpert

Lists child profiles in ProvenExpert.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/children`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [List Child Profiles](https://developer.provenexpert.com/index_en.html#profile-children)
