# Update Profile with ProvenExpert

Updates your profile in ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/profile/update`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Update Profile](https://developer.provenexpert.com/index_en.html#profile-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data.public` | body | `number` | no | Whether the profile should be public after the update. |
