# Get Login URL with ProvenExpert

Retrieves a single sign-on login URL from ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/url/get`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Get Login URL](https://developer.provenexpert.com/index_en.html#auth-url-get)
