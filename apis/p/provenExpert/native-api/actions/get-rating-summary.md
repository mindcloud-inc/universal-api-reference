# Get Rating Summary with ProvenExpert

Retrieves your profile rating summary from ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/rating/summary/get`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [Get Rating Summary](https://developer.provenexpert.com/index_en.html#rating-summary-get)
