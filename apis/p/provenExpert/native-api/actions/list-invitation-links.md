# List Invitation Links with ProvenExpert

Lists survey invitation links in ProvenExpert.

## Endpoint

- **Method:** `POST`
- **Path:** `/invite/url/get`
- **Base URL:** `https://www.provenexpert.com/api/v1`
- **Official documentation:** [List Invitation Links](https://developer.provenexpert.com/index_en.html#invite-url-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data.code` | body | `string` | yes | Survey code whose invitation links should be listed. |
