# ProvenExpert: Get Rich Snippet

Retrieves rich snippet HTML for ProvenExpert ratings.

```
GET https://connect.mindcloud.co/v1/universal/provenExpert/latest/actions/get-rich-snippet
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ProvenExpert `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/provenExpert/latest/actions/get-rich-snippet?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/provenExpert/latest/actions/get-rich-snippet?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `data.version` | number | no | Display mode for the stars. Example: `2`. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `data.strokeColor` | string | no | Line color of the stars as a hex string. Example: `AB9044`. |
| `data.fillColor` | string | no | Fill color of the stars as a hex string. Example: `FFFFFF`. |
| `data.fontColor` | string | no | Text color as a hex string. Example: `726542`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "css": "string",
      "html": "string",
      "ratingValue": 1,
      "reviewCount": 1
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `css` | string | Embeddable CSS snippet generated by ProvenExpert. |
| `html` | string | Embeddable HTML snippet generated by ProvenExpert. |
| `ratingValue` | number | Average rating value included in the rich snippet response. |
| `reviewCount` | number | Number of reviews included in the rich snippet response. |

## Native endpoint

Through the native ProvenExpert API, this operation is `POST /rating/summary/richsnippet` (base URL `https://www.provenexpert.com/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-rich-snippet.md) for the provider-specific parameters and requirements.
