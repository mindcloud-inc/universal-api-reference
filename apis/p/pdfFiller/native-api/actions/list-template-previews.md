# List Template Previews with PdfFiller

Retrieves previews for a PdfFiller template.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId/previews`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [List Template Previews](https://pdffiller.readme.io/reference/get_v2-templates-template-id-previews)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
