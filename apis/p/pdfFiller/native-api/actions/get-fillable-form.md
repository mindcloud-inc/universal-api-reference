# Get Fillable Form with PdfFiller

Retrieves a fillable form from PdfFiller.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/fillable_forms/:linkToFillId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Get Fillable Form](https://pdffiller.readme.io/reference/get_v2-fillable-forms-link-to-fill-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `link_to_fill_id` | path | `string` | yes |
