# Create Fillable Form with PdfFiller

Creates a fillable form in PdfFiller.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/fillable_forms`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Create Fillable Form](https://pdffiller.readme.io/reference/post_v2-fillable-forms)
