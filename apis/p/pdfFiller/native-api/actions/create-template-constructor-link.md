# Create Template Constructor Link with PdfFiller

Creates a constructor link for a PdfFiller template.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/templates/:templateId/constructor`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Create Template Constructor Link](https://pdffiller.readme.io/reference/post_v2-templates-template-id-constructor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The document template identifier. |
