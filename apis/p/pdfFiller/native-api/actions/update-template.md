# Update Template with PdfFiller

Updates an existing template in PdfFiller.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/templates/:templateId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Update Template](https://pdffiller.readme.io/reference/put_v2-templates-template-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
