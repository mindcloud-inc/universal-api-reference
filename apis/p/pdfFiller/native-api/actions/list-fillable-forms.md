# List Fillable Forms with PdfFiller

Retrieves fillable forms from PdfFiller.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/fillable_forms`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [List Fillable Forms](https://pdffiller.readme.io/reference/get_v2-fillable-forms)
