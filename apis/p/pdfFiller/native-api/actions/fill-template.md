# Fill Template with PdfFiller

Creates a filled document from a PdfFiller template.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/templates/:templateId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Fill Template](https://pdffiller.readme.io/reference/post_v2-templates-template-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
