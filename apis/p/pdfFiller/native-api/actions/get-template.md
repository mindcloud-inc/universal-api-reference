# Get Template with PdfFiller

Retrieves a template from PdfFiller.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Get Template](https://pdffiller.readme.io/reference/get_v2-templates-template-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
