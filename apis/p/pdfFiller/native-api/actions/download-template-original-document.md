# Download Template Original Document with PdfFiller

Downloads the original document for a PdfFiller template.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId/original_document`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Download Template Original Document](https://pdffiller.readme.io/reference/get_v2-templates-template-id-original-document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
