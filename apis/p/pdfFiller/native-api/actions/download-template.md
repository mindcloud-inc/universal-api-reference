# Download Template with PdfFiller

Downloads a template from PdfFiller.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId/download`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Download Template](https://pdffiller.readme.io/reference/get_v2-templates-template-id-download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
