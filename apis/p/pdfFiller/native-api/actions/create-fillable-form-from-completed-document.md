# Create Fillable Form From Completed Document with PdfFiller

Creates a fillable form in PdfFiller from a completed document.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/fillable_forms`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Create Fillable Form From Completed Document](https://pdffiller.readme.io/reference/post_v2-fillable-forms)
