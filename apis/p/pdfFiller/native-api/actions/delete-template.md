# Delete Template with PdfFiller

Deletes an existing template from PdfFiller.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/templates/:templateId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Delete Template](https://pdffiller.readme.io/reference/delete_v2-templates-template-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
