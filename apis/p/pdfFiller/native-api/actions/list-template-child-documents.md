# List Template Child Documents with PdfFiller

Retrieves filled documents for a PdfFiller template.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId/filled_documents`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [List Template Child Documents](https://pdffiller.readme.io/reference/get_v2-templates-template-id-filled-documents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
