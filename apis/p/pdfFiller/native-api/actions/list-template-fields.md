# List Template Fields with PdfFiller

Retrieves fields for a PdfFiller template.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/:templateId/fields`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [List Template Fields](https://pdffiller.readme.io/reference/get_v2-templates-template-id-fields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
