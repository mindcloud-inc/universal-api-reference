# Delete Fillable Form with PdfFiller

Deletes an existing fillable form from PdfFiller.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/fillable_forms/:linkToFillId`
- **Base URL:** `https://api.pdffiller.com`
- **Official documentation:** [Delete Fillable Form](https://pdffiller.readme.io/reference/delete_v2-fillable-forms-link-to-fill-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `link_to_fill_id` | path | `string` | yes |
