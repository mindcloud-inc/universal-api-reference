# Retrieve Contact with PhoneBurner

Retrieves a specific contact from PhoneBurner.

## Endpoint

- **Method:** `GET`
- **Path:** `rest/1/contacts/{{contactId}}`
- **Base URL:** `https://www.phoneburner.com/`
- **Official documentation:** [Retrieve Contact](https://www.phoneburner.com/developer/route_list#contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The PhoneBurner contact id. |
