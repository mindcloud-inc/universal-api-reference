# Update Store Product with Printful

Updates a sync product in a Printful store.

## Endpoint

- **Method:** `PUT`
- **Path:** `/store/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Update Store Product](https://developers.printful.com/docs/#tag/Products-API/operation/updateSyncProduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync product id. |
