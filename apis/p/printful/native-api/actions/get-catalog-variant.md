# Get Catalog Variant with Printful

Retrieves a catalog variant from Printful.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/variant/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Catalog Variant](https://developers.printful.com/docs/#tag/Catalog-API/operation/getVariantById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful catalog variant id. |
