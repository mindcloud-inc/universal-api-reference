# Get Product Template with Printful

Retrieves a product template from your Printful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/product-templates/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Product Template](https://developers.printful.com/docs/#tag/Product-Templates-API/operation/getProductTemplateById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product template id. |
