# Delete Product Template with Printful

Deletes a product template from Printful.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product-templates/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Delete Product Template](https://developers.printful.com/docs/#tag/Product-Templates-API/operation/deleteProductTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product template id. |
