# Get Store Variant with Printful

Retrieves a sync variant from a Printful store.

## Endpoint

- **Method:** `GET`
- **Path:** `/store/variants/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Store Variant](https://developers.printful.com/docs/#tag/Products-API/operation/getSyncVariantById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync variant id. |
