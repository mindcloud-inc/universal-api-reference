# Get File with Printful

Retrieves a file from the Printful library.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get File](https://developers.printful.com/docs/#tag/File-Library-API/operation/getFile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful file id. |
