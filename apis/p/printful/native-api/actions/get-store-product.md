# Get Store Product with Printful

Retrieves a sync product from a Printful store.

## Endpoint

- **Method:** `GET`
- **Path:** `/store/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Store Product](https://developers.printful.com/docs/#tag/Products-API/operation/getSyncProductById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync product id. |
