# List Warehouse Products with Printful

Retrieves warehouse products from your Printful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/warehouse/products`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [List Warehouse Products](https://developers.printful.com/docs/#tag/Warehouse-Products-API/operation/getWarehouseProducts)
