# Calculate Shipping Rates with Printful

Calculates shipping rates for a Printful shipment.

## Endpoint

- **Method:** `POST`
- **Path:** `/shipping/rates`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Calculate Shipping Rates](https://developers.printful.com/docs/#tag/Shipping-Rate-API/operation/calculateShippingRates)
