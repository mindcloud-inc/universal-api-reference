# Create Store Variant with Printful

Creates a new sync variant in a Printful store.

## Endpoint

- **Method:** `POST`
- **Path:** `/store/products/{id}/variants`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Create Store Variant](https://developers.printful.com/docs/#tag/Products-API/operation/createSyncVariant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync product id. |
