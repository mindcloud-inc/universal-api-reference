# Estimate Order Costs with Printful

Estimates costs for a Printful order draft.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/estimate-costs`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Estimate Order Costs](https://developers.printful.com/docs/#tag/Orders-API/operation/estimateOrderCosts)
