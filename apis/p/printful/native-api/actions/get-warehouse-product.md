# Get Warehouse Product with Printful

Retrieves a warehouse product from your Printful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/warehouse/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Warehouse Product](https://developers.printful.com/docs/#tag/Warehouse-Products-API/operation/getWarehouseProduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful warehouse product id. |
