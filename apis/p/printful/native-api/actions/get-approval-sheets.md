# Get Approval Sheets with Printful

Retrieves approval sheets from your Printful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/approval-sheets`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Approval Sheets](https://developers.printful.com/docs/#tag/Approval-Sheets-API/operation/getApprovalSheets)
