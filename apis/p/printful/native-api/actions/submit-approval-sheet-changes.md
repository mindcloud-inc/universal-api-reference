# Submit Approval Sheet Changes with Printful

Submits changes to a Printful approval sheet.

## Endpoint

- **Method:** `POST`
- **Path:** `/approval-sheets/changes`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Submit Approval Sheet Changes](https://developers.printful.com/docs/#tag/Approval-Sheets-API/operation/submitApprovalSheetChanges)
