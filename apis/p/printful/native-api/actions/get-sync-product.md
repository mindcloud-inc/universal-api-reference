# Get Sync Product with Printful

Retrieves a synced product from your Printful integrations.

## Endpoint

- **Method:** `GET`
- **Path:** `/sync/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Sync Product](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/getStoreSyncProductById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful ecommerce platform sync product id. |
