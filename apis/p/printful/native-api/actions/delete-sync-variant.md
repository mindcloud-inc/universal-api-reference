# Delete Sync Variant with Printful

Deletes a synced variant from your Printful integrations.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sync/variant/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Delete Sync Variant](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/deleteStoreSyncVariant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful ecommerce platform sync variant id. |
