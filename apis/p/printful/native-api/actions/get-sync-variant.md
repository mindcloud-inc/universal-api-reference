# Get Sync Variant with Printful

Retrieves a synced variant from your Printful integrations.

## Endpoint

- **Method:** `GET`
- **Path:** `/sync/variant/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Sync Variant](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/getStoreSyncVariantById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful ecommerce platform sync variant id. |
