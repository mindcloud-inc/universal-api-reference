# Delete Sync Product with Printful

Deletes a synced product from your Printful integrations.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sync/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Delete Sync Product](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/deleteStoreSyncProduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful ecommerce platform sync product id. |
