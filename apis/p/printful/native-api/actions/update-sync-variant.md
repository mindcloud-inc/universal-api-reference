# Update Sync Variant with Printful

Updates a synced variant in your Printful integrations.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sync/variant/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Update Sync Variant](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/updateStoreSyncVariant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful ecommerce platform sync variant id. |
