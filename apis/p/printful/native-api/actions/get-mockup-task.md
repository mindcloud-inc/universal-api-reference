# Get Mockup Task with Printful

Retrieves a Printful mockup generation task result.

## Endpoint

- **Method:** `GET`
- **Path:** `/mockup-generator/task`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Mockup Task](https://developers.printful.com/docs/#tag/Mockup-Generator-API/operation/getTask)
