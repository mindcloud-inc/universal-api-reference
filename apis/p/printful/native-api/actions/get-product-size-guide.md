# Get Product Size Guide with Printful

Retrieves a size guide for a Printful catalog product.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}/sizes`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Product Size Guide](https://developers.printful.com/docs/#tag/Catalog-API/operation/getProductSizeGuideById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product id. |
