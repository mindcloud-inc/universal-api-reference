# Get Category with Printful

Retrieves a product category from the Printful catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Category](https://developers.printful.com/docs/#tag/Catalog-API/operation/getCategoryById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful category id. |
