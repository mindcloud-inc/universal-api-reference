# Calculate Tax Rates with Printful

Calculates tax rates for a Printful order.

## Endpoint

- **Method:** `POST`
- **Path:** `/tax/rates`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Calculate Tax Rates](https://developers.printful.com/docs/#tag/Tax-Rate-API/operation/calculateTaxRates)
