# Get Catalog Product with Printful

Retrieves a product from the Printful catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Catalog Product](https://developers.printful.com/docs/#tag/Catalog-API/operation/getProductById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product id. |
