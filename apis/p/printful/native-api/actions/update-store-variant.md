# Update Store Variant with Printful

Updates a sync variant in a Printful store.

## Endpoint

- **Method:** `PUT`
- **Path:** `/store/variants/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Update Store Variant](https://developers.printful.com/docs/#tag/Products-API/operation/updateSyncVariant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync variant id. |
