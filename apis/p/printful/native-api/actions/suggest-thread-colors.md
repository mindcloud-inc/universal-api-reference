# Suggest Thread Colors with Printful

Retrieves suggested thread colors from an image in Printful.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/thread-colors`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Suggest Thread Colors](https://developers.printful.com/docs/#tag/File-Library-API/operation/threadColors)
