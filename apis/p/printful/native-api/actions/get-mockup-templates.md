# Get Mockup Templates with Printful

Retrieves layout templates for Printful mockup generation.

## Endpoint

- **Method:** `GET`
- **Path:** `/mockup-generator/templates/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Mockup Templates](https://developers.printful.com/docs/#tag/Mockup-Generator-API/operation/getTemplates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product variant id. |
