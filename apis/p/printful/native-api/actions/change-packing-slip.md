# Change Packing Slip with Printful

Updates the packing slip for a Printful store.

## Endpoint

- **Method:** `POST`
- **Path:** `/store/packing-slip`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Change Packing Slip](https://developers.printful.com/docs/#tag/Store-Information-API/operation/changePackingSlip)
