# List Sync Products with Printful

Retrieves synced products from your Printful integrations.

## Endpoint

- **Method:** `GET`
- **Path:** `/sync/products`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [List Sync Products](https://developers.printful.com/docs/#tag/Ecommerce-Platform-Sync-API/operation/getStoreSyncProducts)
