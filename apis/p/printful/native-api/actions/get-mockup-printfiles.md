# Get Mockup Printfiles with Printful

Retrieves variant printfiles for Printful mockup generation.

## Endpoint

- **Method:** `GET`
- **Path:** `/mockup-generator/printfiles/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Mockup Printfiles](https://developers.printful.com/docs/#tag/Mockup-Generator-API/operation/getPrintfiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful product variant id. |
