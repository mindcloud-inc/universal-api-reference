# List OAuth Scopes with Printful

Retrieves available OAuth scopes for a Printful token.

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth/scopes`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [List OAuth Scopes](https://developers.printful.com/docs/#tag/OAuth-API/operation/getScopes)
