# Create Approval Sheet with Printful

Approves a design by creating a Printful approval sheet.

## Endpoint

- **Method:** `POST`
- **Path:** `/approval-sheets`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Create Approval Sheet](https://developers.printful.com/docs/#tag/Approval-Sheets-API/operation/approveDesign)
