# Delete Store Product with Printful

Deletes a sync product from a Printful store.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/store/products/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Delete Store Product](https://developers.printful.com/docs/#tag/Products-API/operation/deleteSyncProduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful sync product id. |
