# Get Store with Printful

Retrieves a store from your Printful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stores/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Get Store](https://developers.printful.com/docs/#tag/Store-Information-API/operation/getStore)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful store id. |
