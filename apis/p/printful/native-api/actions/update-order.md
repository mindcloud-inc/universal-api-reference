# Update Order with Printful

Updates an existing order in Printful.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}`
- **Base URL:** `https://api.printful.com`
- **Official documentation:** [Update Order](https://developers.printful.com/docs/#tag/Orders-API/operation/updateOrderById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Printful order id or external id prefixed with @. |
