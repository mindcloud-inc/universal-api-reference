# Delete Object with Pipeless Recommendations

Deletes an object and its related data from Pipeless Recommendations.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/apps/:appId/objects`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Delete Object](https://docs.pipeless.io/reference/delete-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
