# Delete All Objects By Type with Pipeless Recommendations

Deletes all objects of one type from Pipeless Recommendations.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/apps/:appId/objects/all`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Delete All Objects By Type](https://docs.pipeless.io/reference/delete-all-objects-by-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
