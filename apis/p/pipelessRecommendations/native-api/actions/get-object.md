# Get Object with Pipeless Recommendations

Retrieves a single object from Pipeless Recommendations.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/apps/:appId/objects`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Get Object](https://docs.pipeless.io/reference/get-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
