# Create Events Batch with Pipeless Recommendations

Creates up to 10 events in Pipeless Recommendations.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/apps/:appId/events/batch`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Create Events Batch](https://docs.pipeless.io/reference/create-events-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
