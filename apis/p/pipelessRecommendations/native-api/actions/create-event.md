# Create Event with Pipeless Recommendations

Creates a new event in Pipeless Recommendations.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/apps/:appId/events`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Create Event](https://docs.pipeless.io/reference/create-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
