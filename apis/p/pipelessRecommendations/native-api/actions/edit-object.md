# Edit Object with Pipeless Recommendations

Updates an existing object in Pipeless Recommendations.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/apps/:appId/objects`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Edit Object](https://docs.pipeless.io/reference/edit-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
