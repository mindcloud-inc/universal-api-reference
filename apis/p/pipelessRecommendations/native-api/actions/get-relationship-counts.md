# Get Relationship Counts with Pipeless Recommendations

Retrieves relationship counts for an object in Pipeless Recommendations.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/apps/:appId/relationship-counts`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Get Relationship Counts](https://docs.pipeless.io/reference/get-relationship-counts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
