# Delete Event with Pipeless Recommendations

Deletes one or more events from Pipeless Recommendations.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/apps/:appId/events`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Delete Event](https://docs.pipeless.io/reference/delete-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
