# Get Relationship Exists with Pipeless Recommendations

Checks whether a relationship exists in Pipeless Recommendations.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/apps/:appId/relationship-exists`
- **Base URL:** `https://api.pipeless.io`
- **Official documentation:** [Get Relationship Exists](https://docs.pipeless.io/reference/get-relationship-exists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Numeric Pipeless app ID. |
