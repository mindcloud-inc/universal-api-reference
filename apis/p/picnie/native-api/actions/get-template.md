# Get Template with Picnie

Retrieves a template and its fields from Picnie.

## Endpoint

- **Method:** `POST`
- **Path:** `/get-template`
- **Base URL:** `https://picnie.com/api/v1`
- **Official documentation:** [Get Template](https://documenter.getpostman.com/view/25712226/2s93CGRvy6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | body | `string` | yes | Picnie template identifier. |
