# Create Project with Picnie

Creates a new project in Picnie.

## Endpoint

- **Method:** `POST`
- **Path:** `/create-project`
- **Base URL:** `https://picnie.com/api/v1`
- **Official documentation:** [Create Project](https://documenter.getpostman.com/view/25712226/2s93CGRvy6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the project to create. |
