# Get Task with Podio

Retrieves an existing task from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:task_id`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [Get Task](https://developers.podio.com/doc/tasks/get-task-22413)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | The id of the task. |
