# List Top Spaces with Podio

Retrieves top spaces from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/top/`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [List Top Spaces](https://developers.podio.com/doc/spaces/get-top-spaces-22477)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | The max number of spaces to be returned. |
