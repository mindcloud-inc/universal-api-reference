# List Organization Workspaces with Podio

Retrieves organization workspaces from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/org/:org_id/`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [List Organization Workspaces](https://developers.podio.com/doc/spaces/get-list-of-organization-workspaces-238875316)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `number` | yes | The organization ID. |
