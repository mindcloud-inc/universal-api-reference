# Get App with Podio

Retrieves an existing app from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/:app_id`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [Get App](https://developers.podio.com/doc/applications/get-app-22349)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `number` | yes | The app ID. |
