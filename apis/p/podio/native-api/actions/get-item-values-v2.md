# Get Item Values v2 with Podio

Retrieves item values from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/item/:item_id/value/v2`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [Get Item Values v2](https://developers.podio.com/doc/items/get-item-values-v2-144280791)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `number` | yes | The id of the item. |
