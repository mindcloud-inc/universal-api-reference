# Get Space with Podio

Retrieves an existing space from Podio.

## Endpoint

- **Method:** `GET`
- **Path:** `/space/:space_id`
- **Base URL:** `https://api.podio.com`
- **Official documentation:** [Get Space](https://developers.podio.com/doc/spaces/get-space-22389)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `number` | yes | The space ID. |
