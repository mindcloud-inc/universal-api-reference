# Get Content with Pling

Retrieves public content details from Pling.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/data/:contentId`
- **Base URL:** `https://api.pling.com/ocs/v1`
- **Official documentation:** [Get Content](https://www.opendesktop.org/ocs-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contentId` | path | `string` | yes | Pling content identifier to retrieve. |
