# List Recent Episodes with Pop Culture Happy Hour Podcast

Retrieves recent podcast episodes from Pop Culture Happy Hour Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcast.xml`
- **Base URL:** `https://feeds.npr.org/510282/`
- **Official documentation:** [List Recent Episodes](https://www.npr.org/podcasts/510282/pop-culture-happy-hour)
