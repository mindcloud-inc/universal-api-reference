# Delete Check with Pingdom

## Endpoint

- **Method:** `DELETE`
- **Path:** `/checks/:checkid`
- **Base URL:** `https://api.pingdom.com/api/3.1`
- **Official documentation:** [Delete Check](https://docs.pingdom.com/api/#tag/Checks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkid` | path | `number` | yes | Identifier of the check to delete. |
