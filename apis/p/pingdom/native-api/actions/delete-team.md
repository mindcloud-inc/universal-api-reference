# Delete Team with Pingdom

## Endpoint

- **Method:** `DELETE`
- **Path:** `/alerting/teams/:teamid`
- **Base URL:** `https://api.pingdom.com/api/3.1`
- **Official documentation:** [Delete Team](https://docs.pingdom.com/api/#tag/Teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamid` | path | `number` | yes | Identifier of the team. |
