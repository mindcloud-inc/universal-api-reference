# Get Maintenance Window with Pingdom

## Endpoint

- **Method:** `GET`
- **Path:** `/maintenance/:id`
- **Base URL:** `https://api.pingdom.com/api/3.1`
- **Official documentation:** [Get Maintenance Window](https://docs.pingdom.com/api/#tag/Maintenance)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier of the maintenance window. |
