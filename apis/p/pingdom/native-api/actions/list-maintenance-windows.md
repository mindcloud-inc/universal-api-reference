# List Maintenance Windows with Pingdom

## Endpoint

- **Method:** `GET`
- **Path:** `/maintenance`
- **Base URL:** `https://api.pingdom.com/api/3.1`
- **Official documentation:** [List Maintenance Windows](https://docs.pingdom.com/api/#tag/Maintenance)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderby` | query | `string` | no | Order by the selected maintenance field. |
| `order` | query | `string` | no | Sort direction. |
