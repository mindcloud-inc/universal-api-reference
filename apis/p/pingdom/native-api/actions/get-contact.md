# Get Contact with Pingdom

## Endpoint

- **Method:** `GET`
- **Path:** `/alerting/contacts/:contactid`
- **Base URL:** `https://api.pingdom.com/api/3.1`
- **Official documentation:** [Get Contact](https://docs.pingdom.com/api/#tag/Contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactid` | path | `number` | yes | Identifier of the contact. |
