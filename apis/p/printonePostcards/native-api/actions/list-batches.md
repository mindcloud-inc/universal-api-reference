# List Batches with Print.one Postcards

Retrieves batches from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [List Batches](https://api.print.one/docs/v2#operation/Batch/getBatchList)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
