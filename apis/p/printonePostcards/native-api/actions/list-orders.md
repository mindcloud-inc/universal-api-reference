# List Orders with Print.one Postcards

Retrieves orders from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [List Orders](https://api.print.one/docs/v2#operation/Order/getOrderList)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
