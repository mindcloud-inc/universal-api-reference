# Archive Batch with Print.one Postcards

Archives an existing batch in Print.one Postcards.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/batches/:batchId/archive`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Archive Batch](https://api.print.one/docs/v2#operation/Batch/archiveBatch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | path | `string` | yes | The batch ID. |
