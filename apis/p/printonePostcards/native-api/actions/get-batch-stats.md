# Get Batch Stats with Print.one Postcards

Retrieves batch statistics from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches/:batchId/stats`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Get Batch Stats](https://api.print.one/docs/v2#operation/Batch/getBatchStats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | path | `string` | yes | Batch ID to inspect |
