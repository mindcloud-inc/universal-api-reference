# Get Batch with Print.one Postcards

Retrieves a batch from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches/:batchId`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Get Batch](https://api.print.one/docs/v2#operation/Batch/getBatch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | path | `string` | yes | Batch ID to retrieve |
