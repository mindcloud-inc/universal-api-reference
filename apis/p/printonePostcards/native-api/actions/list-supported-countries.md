# List Supported Countries with Print.one Postcards

Retrieves supported countries from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/countries`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [List Supported Countries](https://api.print.one/docs/v2#operation/Country/getSupportedCountries)
