# Duplicate Template with Print.one Postcards

Creates a duplicate template in Print.one Postcards.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/templates/duplicate/[:id]`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Duplicate Template](https://api.print.one/docs/v2#operation/Template/duplicateTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID |
