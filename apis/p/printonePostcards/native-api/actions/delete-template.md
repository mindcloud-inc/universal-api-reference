# Delete Template with Print.one Postcards

Deletes an existing template from Print.one Postcards.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/templates/[:id]`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Delete Template](https://api.print.one/docs/v2#operation/Template/deleteTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID |
