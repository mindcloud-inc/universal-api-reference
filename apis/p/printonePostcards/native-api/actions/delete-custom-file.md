# Delete Custom File with Print.one Postcards

Deletes an existing custom file from Print.one Postcards.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/customfiles/[:fileId]`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Delete Custom File](https://api.print.one/docs/v2#operation/CustomFiles/deleteCustomFile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The ID of the custom file |
