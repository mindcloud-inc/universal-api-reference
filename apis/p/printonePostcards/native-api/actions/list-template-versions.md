# List Template Versions with Print.one Postcards

Retrieves template versions from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/templates/[:id]/versions`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [List Template Versions](https://api.print.one/docs/v2#operation/Template/getTemplateVersions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID. |
