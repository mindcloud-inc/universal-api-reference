# Get Order with Print.one Postcards

Retrieves an order from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/:id`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Get Order](https://api.print.one/docs/v2#operation/Order/getOrder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order ID to retrieve |
