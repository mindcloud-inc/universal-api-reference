# Download Custom File with Print.one Postcards

Downloads a custom file from Print.one Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customfiles/[:fileId]/download`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Download Custom File](https://api.print.one/docs/v2#operation/CustomFiles/downloadCustomFile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The ID of the custom file |
