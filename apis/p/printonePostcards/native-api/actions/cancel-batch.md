# Cancel Batch with Print.one Postcards

Cancels an existing batch in Print.one Postcards.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/batches/:batchId/cancel`
- **Base URL:** `https://api.print.one`
- **Official documentation:** [Cancel Batch](https://api.print.one/docs/v2#operation/Batch/cancelBatch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | path | `string` | yes | The batch ID. |
