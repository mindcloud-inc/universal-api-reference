# Get Video by ID with Pixabay

Finds a video in Pixabay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/videos/`
- **Base URL:** `https://pixabay.com`
- **Official documentation:** [Get Video by ID](https://pixabay.com/api/docs/)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Numeric Pixabay video ID. |
