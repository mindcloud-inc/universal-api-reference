# Get Image by ID with Pixabay

Finds an image in Pixabay by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/`
- **Base URL:** `https://pixabay.com`
- **Official documentation:** [Get Image by ID](https://pixabay.com/api/docs/)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Numeric Pixabay image ID. |
