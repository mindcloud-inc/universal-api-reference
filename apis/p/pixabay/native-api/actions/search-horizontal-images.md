# Search Horizontal Images with Pixabay

Finds horizontal images in Pixabay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/`
- **Base URL:** `https://pixabay.com`
- **Official documentation:** [Search Horizontal Images](https://pixabay.com/api/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search term to match against horizontal images. |
