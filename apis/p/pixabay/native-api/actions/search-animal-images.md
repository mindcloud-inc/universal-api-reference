# Search Animal Images with Pixabay

Finds animal images in Pixabay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/`
- **Base URL:** `https://pixabay.com`
- **Official documentation:** [Search Animal Images](https://pixabay.com/api/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
