# Search Industry Videos with Pixabay

Finds industry videos in Pixabay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/videos/`
- **Base URL:** `https://pixabay.com`
- **Official documentation:** [Search Industry Videos](https://pixabay.com/api/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
