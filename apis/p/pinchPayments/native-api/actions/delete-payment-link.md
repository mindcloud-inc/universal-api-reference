# Delete Payment Link with Pinch Payments

Deletes a payment link from Pinch Payments.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payment-links/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Delete Payment Link](https://docs.getpinch.com.au/reference/delete-payment-link)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
