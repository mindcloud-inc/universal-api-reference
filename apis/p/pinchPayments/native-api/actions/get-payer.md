# Get Payer with Pinch Payments

Retrieves a payer from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payers/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Get Payer](https://docs.getpinch.com.au/reference/get-payer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Payer ID in pyr_XXXXXXXXXXXXX format. |
