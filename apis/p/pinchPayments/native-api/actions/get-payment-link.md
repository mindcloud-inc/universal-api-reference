# Get Payment Link with Pinch Payments

Retrieves a payment link from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-links/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Get Payment Link](https://docs.getpinch.com.au/reference/get-payment-link)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
