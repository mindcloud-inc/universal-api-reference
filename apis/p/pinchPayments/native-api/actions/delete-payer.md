# Delete Payer with Pinch Payments

Deletes an existing payer from Pinch Payments.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payers/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Delete Payer](https://docs.getpinch.com.au/reference/delete-payer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Payer ID in pyr_XXXXXXXXXXXXXX format. |
