# List Payments for Payer with Pinch Payments

Retrieves payments for a payer from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/payer/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [List Payments for Payer](https://docs.getpinch.com.au/reference/list-payments-for-payer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
