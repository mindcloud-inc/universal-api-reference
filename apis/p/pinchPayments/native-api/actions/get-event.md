# Get Event with Pinch Payments

Retrieves an event from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Get Event](https://docs.getpinch.com.au/reference/get-event)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
