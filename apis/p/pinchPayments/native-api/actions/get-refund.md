# Get Refund with Pinch Payments

Retrieves a refund from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/refund/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Get Refund](https://docs.getpinch.com.au/reference/get-refund)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
