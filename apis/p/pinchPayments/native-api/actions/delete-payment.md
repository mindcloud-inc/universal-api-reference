# Delete Payment with Pinch Payments

Deletes an existing payment from Pinch Payments.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payments/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Delete Payment](https://docs.getpinch.com.au/reference/delete-payment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
