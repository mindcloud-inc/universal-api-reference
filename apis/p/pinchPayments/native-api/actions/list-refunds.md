# List Refunds with Pinch Payments

Retrieves refunds from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/refunds`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [List Refunds](https://docs.getpinch.com.au/reference/list-refunds)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endDate` | query | `date` | no |
| `startDate` | query | `date` | no |
