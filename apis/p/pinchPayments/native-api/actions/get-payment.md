# Get Payment with Pinch Payments

Retrieves a payment from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/[:id]`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [Get Payment](https://docs.getpinch.com.au/reference/get-payment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
