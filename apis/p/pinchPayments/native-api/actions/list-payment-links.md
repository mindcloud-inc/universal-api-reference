# List Payment Links with Pinch Payments

Retrieves payment links from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-links`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [List Payment Links](https://docs.getpinch.com.au/reference/get-payment-links)

## Capabilities

This operation supports [pagination](../README.md#pagination).
