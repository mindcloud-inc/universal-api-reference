# List Scheduled Payments with Pinch Payments

Retrieves scheduled payments from Pinch Payments.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/scheduled`
- **Base URL:** `https://api.getpinch.com.au/live`
- **Official documentation:** [List Scheduled Payments](https://docs.getpinch.com.au/reference/list-scheduled-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
