# Delete Folder with Pabbly Hook

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/folders/:folderId`
- **Base URL:** `https://hook.pabbly.com`
- **Official documentation:** [Delete Folder](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Folder ID to delete. |
