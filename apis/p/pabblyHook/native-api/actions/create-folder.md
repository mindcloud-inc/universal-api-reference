# Create Folder with Pabbly Hook

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/folders`
- **Base URL:** `https://hook.pabbly.com`
- **Official documentation:** [Create Folder](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Folder name. |
