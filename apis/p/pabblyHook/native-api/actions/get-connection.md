# Get Connection with Pabbly Hook

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/connections/:connectionId`
- **Base URL:** `https://hook.pabbly.com`
- **Official documentation:** [Get Connection](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Connection ID to retrieve. |
