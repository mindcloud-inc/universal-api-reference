# Get Transformation with Pabbly Hook

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/transformations/:transformationId`
- **Base URL:** `https://hook.pabbly.com`
- **Official documentation:** [Get Transformation](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transformationId` | path | `string` | yes | Transformation ID to retrieve. |
