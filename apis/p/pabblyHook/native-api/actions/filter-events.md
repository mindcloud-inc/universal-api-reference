# Filter Events with Pabbly Hook

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/events`
- **Base URL:** `https://hook.pabbly.com`
- **Official documentation:** [Filter Events](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | query | `string` | no | Request ID selector. |
| `status` | query | `string` | no | Event status selector. |
