# List Tenants with Polycom

Lists Poly Lens tenants with member, device, and room totals.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.silica-prod01.io.lens.poly.com`
- **Official documentation:** [List Tenants](https://api.lens.poly.com/docs/graphql/Example%20Queries/platform-management-queries)
