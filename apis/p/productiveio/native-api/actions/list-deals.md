# List Deals with Productive.io

Retrieves deals from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Deals](https://developer.productive.io/deals.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
