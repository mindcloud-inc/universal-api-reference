# Get Deal with Productive.io

Retrieves a deal from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Deal](https://developer.productive.io/deals.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
