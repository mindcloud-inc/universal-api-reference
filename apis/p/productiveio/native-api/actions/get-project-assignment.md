# Get Project Assignment with Productive.io

Retrieves a project assignment from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/project_assignments/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Project Assignment](https://developer.productive.io/project_assignments.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
