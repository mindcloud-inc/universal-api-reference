# List Expenses with Productive.io

Retrieves expenses from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Expenses](https://developer.productive.io/expenses.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
