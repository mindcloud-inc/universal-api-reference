# List Users with Productive.io

Retrieves users from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Users](https://developer.productive.io/users.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
