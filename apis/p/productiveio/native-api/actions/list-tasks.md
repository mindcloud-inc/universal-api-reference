# List Tasks with Productive.io

Retrieves tasks from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Tasks](https://developer.productive.io/tasks.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
