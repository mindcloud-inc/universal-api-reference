# Get Contact Entry with Productive.io

Retrieves a contact entry from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_entries/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Contact Entry](https://developer.productive.io/contact_entries.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
