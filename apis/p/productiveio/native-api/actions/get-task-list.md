# Get Task List with Productive.io

Retrieves a task list from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_lists/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Task List](https://developer.productive.io/task_lists.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
