# List Projects with Productive.io

Retrieves projects from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Projects](https://developer.productive.io/projects.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
