# List Invoices with Productive.io

Retrieves invoices from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Invoices](https://developer.productive.io/invoices.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
