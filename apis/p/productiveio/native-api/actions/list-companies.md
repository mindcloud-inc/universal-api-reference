# List Companies with Productive.io

Retrieves companies from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Companies](https://developer.productive.io/companies.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
