# List Task Lists with Productive.io

Retrieves task lists from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_lists`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Task Lists](https://developer.productive.io/task_lists.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
