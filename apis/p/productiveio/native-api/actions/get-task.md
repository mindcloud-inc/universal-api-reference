# Get Task with Productive.io

Retrieves a task from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Task](https://developer.productive.io/tasks.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
