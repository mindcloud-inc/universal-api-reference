# Get Organization with Productive.io

Retrieves an organization from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Organization](https://developer.productive.io/organizations.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
