# Get Booking with Productive.io

Retrieves a booking from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Booking](https://developer.productive.io/bookings.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
