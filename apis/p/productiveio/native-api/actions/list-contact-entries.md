# List Contact Entries with Productive.io

Retrieves contact entries from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_entries`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Contact Entries](https://developer.productive.io/contact_entries.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
