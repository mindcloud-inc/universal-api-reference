# List Workflow Statuses with Productive.io

Retrieves workflow statuses from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow_statuses`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Workflow Statuses](https://developer.productive.io/workflow_statuses.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
