# List Timers with Productive.io

Retrieves timers from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/timers`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Timers](https://developer.productive.io/timers.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
