# List Bookings with Productive.io

Retrieves bookings from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Bookings](https://developer.productive.io/bookings.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
