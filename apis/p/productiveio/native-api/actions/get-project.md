# Get Project with Productive.io

Retrieves a project from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Project](https://developer.productive.io/projects.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
