# Get User with Productive.io

Retrieves a user from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get User](https://developer.productive.io/users.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
