# List People with Productive.io

Retrieves people from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List People](https://developer.productive.io/people.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
