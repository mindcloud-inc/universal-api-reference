# Get Workflow with Productive.io

Retrieves a workflow from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Workflow](https://developer.productive.io/workflows.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
