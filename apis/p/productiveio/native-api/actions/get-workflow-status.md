# Get Workflow Status with Productive.io

Retrieves a workflow status from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow_statuses/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Workflow Status](https://developer.productive.io/workflow_statuses.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
