# List Organizations with Productive.io

Retrieves organizations from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Organizations](https://developer.productive.io/organizations.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
