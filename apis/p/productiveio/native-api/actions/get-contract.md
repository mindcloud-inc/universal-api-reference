# Get Contract with Productive.io

Retrieves a contract from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Contract](https://developer.productive.io/contracts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
