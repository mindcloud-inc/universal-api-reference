# List Time Entries with Productive.io

Retrieves time entries from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/time_entries`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Time Entries](https://developer.productive.io/time_entries.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
