# List Teams with Productive.io

Retrieves teams from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Teams](https://developer.productive.io/teams.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
