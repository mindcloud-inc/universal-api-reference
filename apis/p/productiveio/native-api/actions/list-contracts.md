# List Contracts with Productive.io

Retrieves contracts from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Contracts](https://developer.productive.io/contracts.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
