# Get Timer with Productive.io

Retrieves a timer from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/timers/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Timer](https://developer.productive.io/timers.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
