# Get Timesheet with Productive.io

Retrieves a timesheet from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/timesheets/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Timesheet](https://developer.productive.io/timesheets.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
