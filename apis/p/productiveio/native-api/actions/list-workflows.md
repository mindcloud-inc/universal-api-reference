# List Workflows with Productive.io

Retrieves workflows from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Workflows](https://developer.productive.io/workflows.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
