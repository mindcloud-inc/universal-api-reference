# Get Expense with Productive.io

Retrieves an expense from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Expense](https://developer.productive.io/expenses.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
