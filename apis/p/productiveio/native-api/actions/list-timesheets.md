# List Timesheets with Productive.io

Retrieves timesheets from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/timesheets`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [List Timesheets](https://developer.productive.io/timesheets.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
