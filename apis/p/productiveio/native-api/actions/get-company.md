# Get Company with Productive.io

Retrieves a company from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Company](https://developer.productive.io/companies.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
