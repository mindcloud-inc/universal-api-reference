# Get Team with Productive.io

Retrieves a team from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Team](https://developer.productive.io/teams.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
