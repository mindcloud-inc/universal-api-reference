# Get Invoice with Productive.io

Retrieves an invoice from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Invoice](https://developer.productive.io/invoices.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
