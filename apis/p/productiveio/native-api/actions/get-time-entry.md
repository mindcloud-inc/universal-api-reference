# Get Time Entry with Productive.io

Retrieves a time entry from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/time_entries/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Time Entry](https://developer.productive.io/time_entries.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
