# Get Person with Productive.io

Retrieves a person from your Productive.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}`
- **Base URL:** `https://api.productive.io/api/v2`
- **Official documentation:** [Get Person](https://developer.productive.io/people.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Productive resource ID. |
