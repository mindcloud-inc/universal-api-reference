# Get Courses By Field with Poodll

Finds courses in Poodll by a specific field.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Courses By Field](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/course/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `field` | body | `string` | no |
| `value` | body | `string` | no |
