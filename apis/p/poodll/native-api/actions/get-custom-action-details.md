# Get Custom Action Details with Poodll

Retrieves custom action field details from Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Custom Action Details](https://github.com/justinhunt/moodle-local_trigger/blob/master/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customaction` | body | `string` | yes |
