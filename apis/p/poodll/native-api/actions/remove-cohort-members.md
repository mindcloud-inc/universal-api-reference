# Remove Cohort Members with Poodll

Removes members from a cohort in Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Remove Cohort Members](https://github.com/justinhunt/moodle-local_trigger/blob/master/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `members[]` | body | `array<object>` | yes |
