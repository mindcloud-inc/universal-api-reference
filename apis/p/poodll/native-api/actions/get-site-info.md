# Get Site Info with Poodll

Retrieves site information and services from Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Site Info](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/webservice/externallib.php)
