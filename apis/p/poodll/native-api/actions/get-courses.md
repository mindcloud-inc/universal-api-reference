# Get Courses with Poodll

Retrieves course records from Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Courses](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/course/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `options` | body | `object` | no |
