# Search Users with Poodll

Finds users in Poodll by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Search Users](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/user/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `criteria[]` | body | `array<object>` | yes |
