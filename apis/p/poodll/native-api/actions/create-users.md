# Create Users with Poodll

Creates new user accounts in Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Create Users](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/user/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `users[]` | body | `array<object>` | yes |
