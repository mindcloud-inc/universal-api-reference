# Get Custom Actions with Poodll

Retrieves available custom actions from Poodll.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Custom Actions](https://github.com/justinhunt/moodle-local_trigger/blob/master/externallib.php)
