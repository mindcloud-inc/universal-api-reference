# Get Course Groups with Poodll

Retrieves groups from a Poodll course.

## Endpoint

- **Method:** `POST`
- **Path:** `{baseUrl}/webservice/rest/server.php`
- **Base URL:** `{baseUrl}/webservice/rest/server.php`
- **Official documentation:** [Get Course Groups](https://github.com/moodle/moodle/blob/MOODLE_405_STABLE/group/externallib.php)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `courseid` | body | `number` | yes |
