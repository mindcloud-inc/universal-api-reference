# Get Receipt Status with Pushover

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/:receipt.json`
- **Base URL:** `https://api.pushover.net/1`
- **Official documentation:** [Get Receipt Status](https://pushover.net/api/receipts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `receipt` | path | `string` | yes | Emergency notification receipt to inspect. |
