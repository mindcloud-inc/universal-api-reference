# Get Group with Pushover

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group.json`
- **Base URL:** `https://api.pushover.net/1`
- **Official documentation:** [Get Group](https://pushover.net/api/groups#show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `string` | yes | Key of the group to retrieve. |
