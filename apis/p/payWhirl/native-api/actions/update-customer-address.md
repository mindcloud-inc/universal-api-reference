# Update Customer Address with PayWhirl

Updates an existing customer address in PayWhirl.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/customer/address/{address_id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Update Customer Address](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address_id` | path | `number` | yes | The PayWhirl address ID. |
