# Get Charge with PayWhirl

Retrieves a charge from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Charge](https://api.paywhirl.com/#charges)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl charge ID. |
