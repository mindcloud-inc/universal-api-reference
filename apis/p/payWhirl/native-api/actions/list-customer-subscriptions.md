# List Customer Subscriptions with PayWhirl

Retrieves a customer's subscriptions from PayWhirl.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [List Customer Subscriptions](https://api.paywhirl.com/#subscriptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl customer ID. |
