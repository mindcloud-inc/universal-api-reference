# Delete Customer Address with PayWhirl

Deletes an existing customer address from PayWhirl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customer/address/{address_id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Delete Customer Address](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address_id` | path | `number` | yes | The PayWhirl address ID. |
