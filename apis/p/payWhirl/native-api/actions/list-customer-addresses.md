# List Customer Addresses with PayWhirl

Retrieves a customer's addresses from PayWhirl.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/addresses/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [List Customer Addresses](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl customer ID. |
