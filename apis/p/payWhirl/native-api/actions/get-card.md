# Get Card with PayWhirl

Retrieves a card from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/card/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Card](https://api.paywhirl.com/#charges)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl card ID. |
