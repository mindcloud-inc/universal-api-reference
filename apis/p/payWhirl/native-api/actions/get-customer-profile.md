# Get Customer Profile with PayWhirl

Retrieves a customer's profile from PayWhirl.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/profile/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Customer Profile](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl customer ID. |
