# Get Plan with PayWhirl

Retrieves a subscription plan from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/plan/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Plan](https://api.paywhirl.com/#plans)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl plan ID. |
