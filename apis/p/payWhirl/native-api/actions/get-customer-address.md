# Get Customer Address with PayWhirl

Retrieves a customer address from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/address/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Customer Address](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl address ID. |
