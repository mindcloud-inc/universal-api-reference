# Get Subscription with PayWhirl

Retrieves a subscription from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Subscription](https://api.paywhirl.com/#subscriptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl subscription ID. |
