# Get Invoice with PayWhirl

Retrieves an invoice from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Invoice](https://api.paywhirl.com/#invoices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl invoice ID. |
