# Get Customer with PayWhirl

Retrieves a customer from PayWhirl by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/{id}`
- **Base URL:** `https://api.paywhirl.com`
- **Official documentation:** [Get Customer](https://api.paywhirl.com/#customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The PayWhirl customer ID. |
