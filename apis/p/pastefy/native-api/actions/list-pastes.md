# List Pastes with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/paste`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [List Pastes](https://docs.pastefy.app/api/spec/get-paste.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter_tags` | query | `string` | no |
| `page` | query | `number` | no |
| `page_limit` | query | `number` | no |
| `user_id` | query | `string` | no |
