# List User Pastes with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/user/pastes`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [List User Pastes](https://docs.pastefy.app/api/spec/get-user-pastes.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter_tags` | query | `string` | no |
| `page` | query | `number` | no |
