# Delete API Key with Pastefy

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/keys/:id`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [Delete API Key](https://docs.pastefy.app/api/spec/delete-user-keys-%7Bid%7D.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
