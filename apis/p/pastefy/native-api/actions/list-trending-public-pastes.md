# List Trending Public Pastes with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/public-pastes/trending`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [List Trending Public Pastes](https://docs.pastefy.app/api/spec/get-public-pastes-trending.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter_tags` | query | `string` | no |
| `trending` | query | `boolean` | no |
