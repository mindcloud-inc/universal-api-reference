# List Starred Pastes with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/user/starred-pastes`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [List Starred Pastes](https://docs.pastefy.app/api/spec/get-user-starred-pastes.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
