# Get Paste with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/paste/:id`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [Get Paste](https://docs.pastefy.app/api/spec/get-paste-%7Bid%7D.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
