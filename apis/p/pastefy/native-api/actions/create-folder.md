# Create Folder with Pastefy

## Endpoint

- **Method:** `POST`
- **Path:** `/folder`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [Create Folder](https://docs.pastefy.app/api/spec/post-folder.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `parent` | body | `string` | no |
