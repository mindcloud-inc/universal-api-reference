# Delete Paste with Pastefy

## Endpoint

- **Method:** `DELETE`
- **Path:** `/paste/:id`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [Delete Paste](https://docs.pastefy.app/api/spec/delete-paste-%7Bid%7D.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
