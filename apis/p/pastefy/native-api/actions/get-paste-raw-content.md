# Get Paste Raw Content with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `https://pastefy.app/:id/raw`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [Get Paste Raw Content](https://docs.pastefy.app/api/spec/get-paste-%7Bid%7D-raw.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
