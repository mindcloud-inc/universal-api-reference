# List Folders with Pastefy

## Endpoint

- **Method:** `GET`
- **Path:** `/folder`
- **Base URL:** `https://pastefy.app/api/v2`
- **Official documentation:** [List Folders](https://docs.pastefy.app/api/spec/get-folder.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `page_limit` | query | `number` | no |
| `search` | query | `string` | no |
