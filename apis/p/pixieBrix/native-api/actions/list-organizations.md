# List Organizations with PixieBrix

Retrieves the current user's organizations from PixieBrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/organizations/`
- **Base URL:** `https://app.pixiebrix.com`
- **Official documentation:** [List Organizations](https://app.pixiebrix.com/api/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
