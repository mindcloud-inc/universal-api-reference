# Health Check with PixieBrix

Retrieves the PixieBrix API health status.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/health/`
- **Base URL:** `https://app.pixiebrix.com`
- **Official documentation:** [Health Check](https://docs.pixiebrix.com/developer-api/health-check-apis)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
