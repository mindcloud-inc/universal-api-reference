# Get Current User with PixieBrix

Retrieves the current user from PixieBrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/me/`
- **Base URL:** `https://app.pixiebrix.com`
- **Official documentation:** [Get Current User](https://app.pixiebrix.com/api/docs/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
