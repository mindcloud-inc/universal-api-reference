# Get Organization with PixieBrix

Retrieves an organization from PixieBrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/organizations/:organization_pk/`
- **Base URL:** `https://app.pixiebrix.com`
- **Official documentation:** [Get Organization](https://app.pixiebrix.com/api/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_pk` | path | `string` | yes | PixieBrix organization identifier. |
