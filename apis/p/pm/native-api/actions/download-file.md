# Download File with 5pm

Downloads an activity file from 5pm.

## Endpoint

- **Method:** `POST`
- **Path:** `/service/post/activity/downloadFile`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Download File](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Unique identifier of the file. |
