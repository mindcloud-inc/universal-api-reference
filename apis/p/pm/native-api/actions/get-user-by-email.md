# Get User By Email with 5pm

Retrieves a user from 5pm by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/get/users/getByEmail`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Get User By Email](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address of the user. |
