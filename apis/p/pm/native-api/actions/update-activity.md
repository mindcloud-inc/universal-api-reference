# Update Activity with 5pm

Updates an existing activity in 5pm.

## Endpoint

- **Method:** `POST`
- **Path:** `/service/post/activity/update`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Update Activity](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity[id]` | query | `string` | yes | Unique identifier of the activity. |
