# Update Project with 5pm

Updates an existing project in 5pm.

## Endpoint

- **Method:** `POST`
- **Path:** `/service/post/projects/update`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Update Project](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project[id]` | query | `string` | yes | Unique identifier of the project. |
