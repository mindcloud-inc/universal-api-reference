# Get Project By Id with 5pm

Retrieves a project from 5pm by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/get/projects/getById`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Get Project By Id](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Unique identifier of the project. |
