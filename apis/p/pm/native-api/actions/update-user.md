# Update User with 5pm

Updates an existing user in 5pm.

## Endpoint

- **Method:** `POST`
- **Path:** `/service/post/users/update`
- **Base URL:** `{workspaceUrl}/api/v2`
- **Official documentation:** [Update User](https://www.5pmweb.com/help/api_docs.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user[id]` | query | `string` | yes | Unique identifier of the user. |
