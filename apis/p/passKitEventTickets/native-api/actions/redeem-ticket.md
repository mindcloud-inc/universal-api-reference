# Redeem Ticket with PassKit Event Tickets

Redeems an existing ticket in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/ticket/redeem`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Redeem Ticket](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_redeemTicket)
