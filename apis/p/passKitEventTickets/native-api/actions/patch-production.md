# Patch Production with PassKit Event Tickets

Partially updates an existing production in PassKit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/eventTickets/production`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Patch Production](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_patchProduction)
