# Update Production with PassKit Event Tickets

Fully updates an existing production in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/production`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Update Production](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_updateProduction)
