# Delete Venue with PassKit Event Tickets

Deletes an existing venue from PassKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/eventTickets/venue`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Delete Venue](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_deleteVenue)
