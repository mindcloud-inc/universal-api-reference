# Create Ticket Type with PassKit Event Tickets

Creates a new ticket type in PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/ticketType`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Create Ticket Type](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_createTicketType)
