# Patch Venue with PassKit Event Tickets

Partially updates an existing venue in PassKit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/eventTickets/venue`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Patch Venue](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_patchVenue)
