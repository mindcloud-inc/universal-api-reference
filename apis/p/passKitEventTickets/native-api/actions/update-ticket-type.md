# Update Ticket Type with PassKit Event Tickets

Updates an existing ticket type in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/ticketType`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Update Ticket Type](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_updateTicketType)
