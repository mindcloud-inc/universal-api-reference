# Get User Profile with PassKit Event Tickets

Retrieves your user profile from PassKit.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/profile`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Get User Profile](https://help.passkit.com/en/articles/4138220-2-steps-to-call-passkit-api-from-google-app-script)
