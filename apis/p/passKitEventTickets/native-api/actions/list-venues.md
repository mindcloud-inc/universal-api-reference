# List Venues with PassKit Event Tickets

Retrieves venues from PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/venues`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [List Venues](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_listVenues)
