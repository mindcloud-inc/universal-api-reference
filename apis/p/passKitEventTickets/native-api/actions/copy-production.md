# Copy Production with PassKit Event Tickets

Creates a copy of a production in PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/production/copy`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Copy Production](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_copyProduction)
