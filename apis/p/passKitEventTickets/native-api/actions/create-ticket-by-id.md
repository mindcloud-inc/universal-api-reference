# Create Ticket By Id with PassKit Event Tickets

Creates a new ticket in PassKit by user-defined IDs.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/ticket/id`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Create Ticket By Id](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_issueTicketById)
