# Update Venue with PassKit Event Tickets

Fully updates an existing venue in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/venue`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Update Venue](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_updateVenue)
