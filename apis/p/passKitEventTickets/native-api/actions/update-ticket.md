# Update Ticket with PassKit Event Tickets

Updates an existing ticket in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/ticket`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Update Ticket](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_updateTicket)
