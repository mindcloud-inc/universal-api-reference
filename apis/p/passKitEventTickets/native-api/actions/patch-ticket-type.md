# Patch Ticket Type with PassKit Event Tickets

Partially updates an existing ticket type in PassKit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/eventTickets/ticketType`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Patch Ticket Type](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_patchTicketType)
