# Create Venue with PassKit Event Tickets

Creates a new venue in PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/venue`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Create Venue](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_createVenue)
