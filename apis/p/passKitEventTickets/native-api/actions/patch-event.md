# Patch Event with PassKit Event Tickets

Partially updates an existing event in PassKit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/eventTickets/event`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Patch Event](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_patchEvent)
