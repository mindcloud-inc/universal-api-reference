# Create Ticket Pass with PassKit Event Tickets

Retrieves event ticket passes from PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/pass`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Create Ticket Pass](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_getEventTicketPass)
