# Validate Ticket with PassKit Event Tickets

Validates an existing ticket in PassKit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/eventTickets/ticket/validate`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Validate Ticket](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_validateTicket)
