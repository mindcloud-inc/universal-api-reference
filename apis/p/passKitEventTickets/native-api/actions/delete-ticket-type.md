# Delete Ticket Type with PassKit Event Tickets

Deletes an existing ticket type from PassKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/eventTickets/ticketType`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Delete Ticket Type](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_deleteTicketType)
