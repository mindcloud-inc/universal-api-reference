# Update Ticket Person with PassKit Event Tickets

Updates ticket holder information in PassKit.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/eventTickets/ticket/person`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Update Ticket Person](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_patchPerson)
