# Delete Production with PassKit Event Tickets

Deletes an existing production from PassKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/eventTickets/production`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Delete Production](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_deleteProduction)
