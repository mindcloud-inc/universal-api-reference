# Bulk Delete Tickets with PassKit Event Tickets

Deletes multiple tickets from PassKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/eventTickets/bulk`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Bulk Delete Tickets](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_bulkDeleteTickets)
