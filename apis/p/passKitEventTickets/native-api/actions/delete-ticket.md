# Delete Ticket with PassKit Event Tickets

Deletes an existing ticket from PassKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/eventTickets/ticket`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Delete Ticket](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_deleteTicket)
