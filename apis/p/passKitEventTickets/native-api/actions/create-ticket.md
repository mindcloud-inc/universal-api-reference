# Create Ticket with PassKit Event Tickets

Creates a new ticket in PassKit.

## Endpoint

- **Method:** `POST`
- **Path:** `/eventTickets/ticket`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Create Ticket](https://docs.passkit.io/protocols/event-tickets/#operation/EventTickets_issueTicket)
