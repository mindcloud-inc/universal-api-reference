# Formatting - [Data] Convert JSON to String with Pipedream Utils

Converts JSON data to a string in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Data] Convert JSON to String](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/convert-json-to-string/convert-json-to-string.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `object` | yes | An object to be serialized to a JSON format string. |
