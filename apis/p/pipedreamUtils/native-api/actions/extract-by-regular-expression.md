# Formatting - [Text] Extract by Regular Expression with Pipedream Utils

Extracts regex matches from text in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Text] Extract by Regular Expression](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/extract-by-regular-expression/extract-by-regular-expression.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | Text you would like to find a pattern from |
| `regExpString` | body | `string` | yes | Enter a string representing a [Regular Expression](https://www.w3schools.com/js/js_regexp.asp) |
