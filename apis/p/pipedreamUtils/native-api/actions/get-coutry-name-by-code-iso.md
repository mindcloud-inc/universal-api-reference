# Helper Functions - Country name, given code (2-letter) with Pipedream Utils

Retrieves a country name from a two-letter code in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Helper Functions - Country name, given code (2-letter)](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/get-coutry-name-by-code-iso/get-coutry-name-by-code-iso.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `countryCode` | body | `string` | yes | The 2 letter capitalized country code |
