# Formatting - [Text] Convert HTML to Markdown with Pipedream Utils

Converts HTML to Markdown in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Text] Convert HTML to Markdown](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/convert-html-to-markdown/convert-html-to-markdown.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | HTML string to be converted to Markdown |
