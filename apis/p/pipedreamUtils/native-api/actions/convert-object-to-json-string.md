# Helper Functions - Convert JavaScript Object to JSON String with Pipedream Utils

Converts a JavaScript object to JSON in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Helper Functions - Convert JavaScript Object to JSON String](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/convert-object-to-json-string/convert-object-to-json-string.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object` | body | `string` | yes | The JavaScript object you'd like to convert to a JSON string |
