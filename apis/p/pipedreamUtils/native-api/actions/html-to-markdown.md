# Helper Functions - HTML to Markdown with Pipedream Utils

Converts HTML to Markdown with formatting options in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Helper Functions - HTML to Markdown](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/html-to-markdown/html-to-markdown.mjs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | body | `string` | yes |
| `headingStyle` | body | `string` | no |
| `hr` | body | `string` | no |
| `bulletListMarker` | body | `string` | no |
| `codeBlockStyle` | body | `string` | no |
| `fence` | body | `string` | no |
| `emDelimiter` | body | `string` | no |
| `strongDelimiter` | body | `string` | no |
| `linkStyle` | body | `string` | no |
| `linkReferenceStyle` | body | `string` | no |
