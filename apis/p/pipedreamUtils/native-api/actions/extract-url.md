# Formatting - [Text] Extract URL with Pipedream Utils

Extracts the first URL in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Text] Extract URL](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/extract-url/extract-url.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | String from which you'd like to extract a URL |
