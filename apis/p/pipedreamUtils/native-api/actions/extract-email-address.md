# Formatting - [Text] Extract Email Address with Pipedream Utils

Extracts the first email address in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Text] Extract Email Address](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/extract-email-address/extract-email-address.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | String from which you'd like to extract an email address |
