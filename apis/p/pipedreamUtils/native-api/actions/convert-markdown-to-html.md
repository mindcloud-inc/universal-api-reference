# Formatting - [Text] Convert Markdown to HTML with Pipedream Utils

Converts Markdown to HTML in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Formatting - [Text] Convert Markdown to HTML](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/convert-markdown-to-html/convert-markdown-to-html.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | Markdown string to be converted to HTML |
