# Helper Functions - Export Variables with Pipedream Utils

Exports variables for later workflow steps in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Helper Functions - Export Variables](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/export-variables/export-variables.mjs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `config` | body | `object` | yes | Enter key-value pairs that you'd like to reference throughout your workflow. |
