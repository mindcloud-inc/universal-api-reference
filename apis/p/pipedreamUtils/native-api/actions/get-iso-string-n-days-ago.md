# Helper Functions - Get ISO String N Days Ago with Pipedream Utils

Retrieves a UTC ISO timestamp from N days ago in Pipedream Utils.

## Endpoint

- **Method:** `GET`
- **Base URL:** `https://pipedream.com`
- **Official documentation:** [Helper Functions - Get ISO String N Days Ago](https://raw.githubusercontent.com/PipedreamHQ/pipedream/master/components/pipedream_utils/actions/get-iso-string-n-days-ago/get-iso-string-n-days-ago.mjs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `days` | body | `string` | yes |
