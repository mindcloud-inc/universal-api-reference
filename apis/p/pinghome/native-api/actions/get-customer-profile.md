# Get Customer Profile with Pinghome

Retrieves customer profile information from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-query/v1/customer`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Customer Profile](https://docs.pinghome.io/customer-account-management/account-settings/get-customer-profile/)
