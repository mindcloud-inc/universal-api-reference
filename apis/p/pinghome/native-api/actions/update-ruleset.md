# Update Ruleset with Pinghome

Updates an existing ruleset in Pinghome.

## Endpoint

- **Method:** `PUT`
- **Path:** `/incident-cmd/v1/ruleset/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Update Ruleset](https://docs.pinghome.io/incident-management/ruleset-management-and-event-handling/update-ruleset/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The ruleset ID to update. |
