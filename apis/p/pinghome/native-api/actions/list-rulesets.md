# List Rulesets with Pinghome

Retrieves rulesets from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/incident-query/v1/rulesets`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Rulesets](https://docs.pinghome.io/incident-management/ruleset-management-and-event-handling/get-rulesets/)
