# Get Organisation Usage with Pinghome

Retrieves organisation usage from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-query/v1/org/usage`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Organisation Usage](https://docs.pinghome.io/billing-operations-management/get-organisation-usage/)
