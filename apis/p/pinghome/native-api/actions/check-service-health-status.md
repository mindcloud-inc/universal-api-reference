# Check Service Health Status with Pinghome

Retrieves service health status from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/incident-query/v1/health-check`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Check Service Health Status](https://docs.pinghome.io/incident-management/incident-tracking/check-service-health-status/)
