# List Webhooks with Pinghome

Retrieves webhooks from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/incident-query/v1/webhooks`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Webhooks](https://docs.pinghome.io/incident-management/ruleset-management-and-event-handling/get-webhooks/)
