# Get Comprehensive Statuspage Details with Pinghome

Retrieves comprehensive statuspage details from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/statuspage/:id/unified`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Comprehensive Statuspage Details](https://docs.pinghome.io/statuspages/get-comprehensive-statuspage-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The unique ID of the statuspage. |
