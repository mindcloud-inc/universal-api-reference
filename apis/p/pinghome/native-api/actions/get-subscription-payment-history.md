# Get Subscription Payment History with Pinghome

Retrieves subscription payment history from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-query/v1/subscription/:id/payments`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Subscription Payment History](https://docs.pinghome.io/billing-operations-management/get-subscription-payment-history/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The subscription ID. |
