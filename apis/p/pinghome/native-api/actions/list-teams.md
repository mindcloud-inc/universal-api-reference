# List Teams with Pinghome

Retrieves teams from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-query/v1/teams`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Teams](https://docs.pinghome.io/customer-account-management/team-organization-and-role-setup/get-teams/)
