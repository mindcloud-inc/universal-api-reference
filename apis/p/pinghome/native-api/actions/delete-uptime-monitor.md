# Delete Uptime Monitor with Pinghome

Deletes an existing uptime monitor from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/resource-cmd/v1/resource/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Uptime Monitor](https://docs.pinghome.io/monitoring/uptime-monitoring/delete-uptime-monitor/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
