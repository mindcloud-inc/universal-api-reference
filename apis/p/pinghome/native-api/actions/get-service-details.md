# Get Service Details with Pinghome

Retrieves service details from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource-query/v1/team-service/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Service Details](https://docs.pinghome.io/customer-account-management/team-organization-and-role-setup/get-service-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The team id whose services should be returned. |
