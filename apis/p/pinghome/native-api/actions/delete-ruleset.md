# Delete Ruleset with Pinghome

Deletes an existing ruleset from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/incident-cmd/v1/ruleset/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Ruleset](https://docs.pinghome.io/incident-management/ruleset-management-and-event-handling/delete-ruleset/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The ruleset ID to delete. |
