# Delete Statuspage Subscription with Pinghome

Deletes an existing statuspage subscription from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/statuspage-cmd/v1/subscription/:token`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Statuspage Subscription](https://docs.pinghome.io/statuspages/delete-statuspage-subscription/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | no | The subscription token to delete. |
