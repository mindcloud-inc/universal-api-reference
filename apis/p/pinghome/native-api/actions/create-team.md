# Create Team with Pinghome

Creates a new team in Pinghome.

## Endpoint

- **Method:** `POST`
- **Path:** `/customer-cmd/v1/team`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Create Team](https://docs.pinghome.io/customer-account-management/team-organization-and-role-setup/create-team/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the team to create. |
