# List Statuspages For Organisation with Pinghome

Retrieves organisation statuspages from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/statuspages`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Statuspages For Organisation](https://docs.pinghome.io/statuspages/get-statuspages-for-organisation/)
