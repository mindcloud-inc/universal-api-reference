# Get Statistics For Statuspage Component with Pinghome

Retrieves statuspage component statistics from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/component/:id/statistics`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Statistics For Statuspage Component](https://docs.pinghome.io/statuspages/get-statistics-for-statuspage-component/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The statuspage component ID. |
