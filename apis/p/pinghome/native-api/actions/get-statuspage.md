# Get Statuspage with Pinghome

Retrieves a statuspage from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/statuspage/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Statuspage](https://docs.pinghome.io/statuspages/get-statuspage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Statuspage ID to retrieve. |
