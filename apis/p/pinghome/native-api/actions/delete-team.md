# Delete Team with Pinghome

Deletes an existing team from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customer-cmd/v1/team/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Team](https://docs.pinghome.io/customer-account-management/team-organization-and-role-setup/delete-team/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
