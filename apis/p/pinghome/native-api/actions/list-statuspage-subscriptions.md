# List Statuspage Subscriptions with Pinghome

Retrieves statuspage subscriptions from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/statuspage/:id/subscriptions`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Statuspage Subscriptions](https://docs.pinghome.io/statuspages/get-statuspage-subscriptions/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The unique ID of the statuspage. |
