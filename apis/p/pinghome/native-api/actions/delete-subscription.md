# Delete Subscription with Pinghome

Deletes an existing subscription from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payment-cmd/v1/subscription/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Subscription](https://docs.pinghome.io/billing-operations-management/delete-subscription/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The subscription ID to delete. |
