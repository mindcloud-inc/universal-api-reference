# List Statuspage Components with Pinghome

Retrieves statuspage components from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuspage-query/v1/statuspage/:id/components`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [List Statuspage Components](https://docs.pinghome.io/statuspages/get-statuspage-components/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The unique ID of the statuspage. |
