# Update Organisation Plan with Pinghome

Updates the organisation plan in Pinghome.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customer-cmd/v1/organisation/plan`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Update Organisation Plan](https://docs.pinghome.io/billing-operations-management/update-organisation-plan/)
