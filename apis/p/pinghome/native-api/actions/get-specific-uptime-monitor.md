# Get Specific Uptime Monitor with Pinghome

Retrieves a specific uptime monitor from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource-query/v1/resource/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Specific Uptime Monitor](https://docs.pinghome.io/monitoring/uptime-monitoring/get-specific-uptime-monitor/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the uptime monitor. |
