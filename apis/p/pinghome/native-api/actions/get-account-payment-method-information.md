# Get Account Payment Method Information with Pinghome

Retrieves account payment method information from Pinghome.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-query/v1/payment-methods`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Get Account Payment Method Information](https://docs.pinghome.io/billing-operations-management/get-account-payment-method-information/)
