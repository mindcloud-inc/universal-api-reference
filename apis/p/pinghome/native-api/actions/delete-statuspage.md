# Delete Statuspage with Pinghome

Deletes an existing statuspage from Pinghome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/statuspage-cmd/v1/statuspage/:id`
- **Base URL:** `https://api.pinghome.io`
- **Official documentation:** [Delete Statuspage](https://docs.pinghome.io/statuspages/delete-statuspage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Statuspage ID to delete. |
