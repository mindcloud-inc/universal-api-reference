# Get Project with Prisma Postgres

Retrieves a project from Prisma Postgres.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{id}`
- **Base URL:** `https://api.prisma.io/v1`
- **Official documentation:** [Get Project](https://api.prisma.io/v1/swagger-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project identifier. |
