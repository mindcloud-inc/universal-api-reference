# Get Database with Prisma Postgres

Retrieves a database from Prisma Postgres.

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/{databaseId}`
- **Base URL:** `https://api.prisma.io/v1`
- **Official documentation:** [Get Database](https://api.prisma.io/v1/swagger-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | Database identifier. |
