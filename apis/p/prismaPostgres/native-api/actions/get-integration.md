# Get Integration with Prisma Postgres

Retrieves an integration from Prisma Postgres.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/{id}`
- **Base URL:** `https://api.prisma.io/v1`
- **Official documentation:** [Get Integration](https://api.prisma.io/v1/swagger-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Integration identifier. |
