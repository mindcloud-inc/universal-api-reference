# List Regions with Prisma Postgres

Retrieves regions from Prisma Postgres.

## Endpoint

- **Method:** `GET`
- **Path:** `/regions`
- **Base URL:** `https://api.prisma.io/v1`
- **Official documentation:** [List Regions](https://api.prisma.io/v1/swagger-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product` | query | `list` | no | Optional product filter for regions. |
