# Get Connection with Prisma Postgres

Retrieves a connection from Prisma Postgres.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/{id}`
- **Base URL:** `https://api.prisma.io/v1`
- **Official documentation:** [Get Connection](https://api.prisma.io/v1/swagger-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Connection identifier. |
