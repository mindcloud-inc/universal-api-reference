# Get Institution with PocketSmith

Retrieves a PocketSmith institution.

## Endpoint

- **Method:** `GET`
- **Path:** `/institutions/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Get Institution](https://developers.pocketsmith.com/reference/get_institutions-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith institution. |
