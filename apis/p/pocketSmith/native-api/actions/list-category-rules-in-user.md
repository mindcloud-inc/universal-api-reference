# List Category Rules In User with PocketSmith

Retrieves category rules for a PocketSmith user.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id/category_rules`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [List Category Rules In User](https://developers.pocketsmith.com/reference/get_users-id-category-rules-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith user. |
