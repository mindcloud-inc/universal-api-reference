# Get User with PocketSmith

Retrieves a PocketSmith user.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Get User](https://developers.pocketsmith.com/reference/get_users-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith user. |
