# List Budget For User with PocketSmith

Retrieves budget entries for a PocketSmith user.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id/budget`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [List Budget For User](https://developers.pocketsmith.com/reference/get_users-id-budget-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith user. |
