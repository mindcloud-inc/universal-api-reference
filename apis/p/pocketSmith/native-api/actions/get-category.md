# Get Category with PocketSmith

Retrieves a PocketSmith category.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Get Category](https://developers.pocketsmith.com/reference/get_categories-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith category. |
