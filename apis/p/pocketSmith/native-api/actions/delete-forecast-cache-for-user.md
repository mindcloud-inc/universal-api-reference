# Delete Forecast Cache For User with PocketSmith

Deletes the forecast cache for a PocketSmith user.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id/forecast_cache`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Delete Forecast Cache For User](https://developers.pocketsmith.com/reference/delete_users-id-forecast-cache)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith user. |
