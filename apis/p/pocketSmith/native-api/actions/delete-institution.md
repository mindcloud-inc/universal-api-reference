# Delete Institution with PocketSmith

Deletes a PocketSmith institution.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/institutions/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Delete Institution](https://developers.pocketsmith.com/reference/delete_institutions-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith institution. |
