# Delete Category with PocketSmith

Deletes a PocketSmith category.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Delete Category](https://developers.pocketsmith.com/reference/delete_categories-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the PocketSmith category. |
