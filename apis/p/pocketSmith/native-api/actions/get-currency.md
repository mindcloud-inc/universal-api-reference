# Get Currency with PocketSmith

Retrieves a PocketSmith currency.

## Endpoint

- **Method:** `GET`
- **Path:** `/currencies/:id`
- **Base URL:** `https://api.pocketsmith.com/v2`
- **Official documentation:** [Get Currency](https://developers.pocketsmith.com/reference/get_currencies-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the PocketSmith currency. |
