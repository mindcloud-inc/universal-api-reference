# Get Task with Paymo

Retrieves a task from Paymo.

## Endpoint

- **Method:** `GET`
- **Path:** `tasks/:taskId`
- **Base URL:** `https://app.paymoapp.com/api/`
- **Official documentation:** [Get Task](https://github.com/paymo-org/api/blob/master/sections/tasks.md#getting-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `number` | yes | The Paymo task id. |
