# Get Client with Paymo

Retrieves a client from Paymo.

## Endpoint

- **Method:** `GET`
- **Path:** `clients/:clientId`
- **Base URL:** `https://app.paymoapp.com/api/`
- **Official documentation:** [Get Client](https://github.com/paymo-org/api/blob/master/sections/clients.md#getting-a-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `number` | yes | The Paymo client ID. |
