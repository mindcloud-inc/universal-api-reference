# Get Task List with Paymo

Retrieves a task list from Paymo.

## Endpoint

- **Method:** `GET`
- **Path:** `tasklists/:tasklistId`
- **Base URL:** `https://app.paymoapp.com/api/`
- **Official documentation:** [Get Task List](https://github.com/paymo-org/api/blob/master/sections/tasklists.md#getting-a-task-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tasklistId` | path | `number` | yes | The Paymo task list id. |
