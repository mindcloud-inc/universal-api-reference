# Get Project with Paymo

Retrieves a project from Paymo.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId`
- **Base URL:** `https://app.paymoapp.com/api/`
- **Official documentation:** [Get Project](https://github.com/paymo-org/api/blob/master/sections/projects.md#getting-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The Paymo project id. |
