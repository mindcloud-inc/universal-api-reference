# Get Time Entry with Paymo

Retrieves a time entry from Paymo.

## Endpoint

- **Method:** `GET`
- **Path:** `entries/:entryId`
- **Base URL:** `https://app.paymoapp.com/api/`
- **Official documentation:** [Get Time Entry](https://github.com/paymo-org/api/blob/master/sections/entries.md#getting-a-time-entry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entryId` | path | `number` | yes | The Paymo time entry id. |
