# Get Transaction with Paddle

Retrieves a transaction from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `transactions/{transaction_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Transaction](https://developer.paddle.com/api-reference/transactions/get-transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transaction_id` | path | `string` | no |
