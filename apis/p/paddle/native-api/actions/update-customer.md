# Update Customer with Paddle

Updates an existing customer in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `customers/{customer_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Customer](https://developer.paddle.com/api-reference/customers/update-customer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | no |
