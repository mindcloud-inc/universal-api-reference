# List Products with Paddle

Retrieves a list of products from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `products`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Products](https://developer.paddle.com/api-reference/products/list-products)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
