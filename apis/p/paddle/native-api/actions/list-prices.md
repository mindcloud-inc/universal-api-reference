# List Prices with Paddle

Retrieves a list of prices from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `prices`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Prices](https://developer.paddle.com/api-reference/prices/list-prices)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
