# Cancel Subscription with Paddle

Cancels an existing subscription in Paddle.

## Endpoint

- **Method:** `POST`
- **Path:** `subscriptions/{subscription_id}/cancel`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Cancel Subscription](https://developer.paddle.com/api-reference/subscriptions/cancel-subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | no |
