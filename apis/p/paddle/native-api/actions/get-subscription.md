# Get Subscription with Paddle

Retrieves a subscription from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions/{subscription_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Subscription](https://developer.paddle.com/api-reference/subscriptions/get-subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | no |
