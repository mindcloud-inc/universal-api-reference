# Get Price with Paddle

Retrieves a price from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `prices/{price_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Price](https://developer.paddle.com/api-reference/prices/get-price)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `price_id` | path | `string` | no |
