# List Discounts with Paddle

Retrieves a list of discounts from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `discounts`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Discounts](https://developer.paddle.com/api-reference/discounts/list-discounts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
