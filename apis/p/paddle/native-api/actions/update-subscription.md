# Update Subscription with Paddle

Updates an existing subscription in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `subscriptions/{subscription_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Subscription](https://developer.paddle.com/api-reference/subscriptions/update-subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | no |
