# Create Customer Portal Session with Paddle

Creates a customer portal session in Paddle.

## Endpoint

- **Method:** `POST`
- **Path:** `customers/{customer_id}/portal-sessions`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Create Customer Portal Session](https://developer.paddle.com/api-reference/customer-portals/create-customer-portal-session)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | no |
