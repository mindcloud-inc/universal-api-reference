# Get Product with Paddle

Retrieves a product from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `products/{product_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Product](https://developer.paddle.com/api-reference/products/get-product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | no |
