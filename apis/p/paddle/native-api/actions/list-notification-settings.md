# List Notification Settings with Paddle

Retrieves a list of notification settings from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `notification-settings`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Notification Settings](https://developer.paddle.com/api-reference/notification-settings/list-notification-settings)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
