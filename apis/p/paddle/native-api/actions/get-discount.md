# Get Discount with Paddle

Retrieves a discount from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `discounts/{discount_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Discount](https://developer.paddle.com/api-reference/discounts/get-discount)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `discount_id` | path | `string` | no |
