# Update Discount with Paddle

Updates an existing discount in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `discounts/{discount_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Discount](https://developer.paddle.com/api-reference/discounts/update-discount)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `discount_id` | path | `string` | no |
