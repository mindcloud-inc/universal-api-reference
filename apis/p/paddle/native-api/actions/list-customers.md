# List Customers with Paddle

Retrieves a list of customers from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `customers`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Customers](https://developer.paddle.com/api-reference/customers/list-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
