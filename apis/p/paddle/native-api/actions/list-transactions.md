# List Transactions with Paddle

Retrieves a list of transactions from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `transactions`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Transactions](https://developer.paddle.com/api-reference/transactions/list-transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
