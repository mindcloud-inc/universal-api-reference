# Update Product with Paddle

Updates an existing product in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `products/{product_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Product](https://developer.paddle.com/api-reference/products/update-product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | no |
