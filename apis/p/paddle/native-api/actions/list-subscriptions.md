# List Subscriptions with Paddle

Retrieves a list of subscriptions from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Subscriptions](https://developer.paddle.com/api-reference/subscriptions/list-subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
