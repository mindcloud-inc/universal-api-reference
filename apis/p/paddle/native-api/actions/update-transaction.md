# Update Transaction with Paddle

Updates an existing transaction in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `transactions/{transaction_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Transaction](https://developer.paddle.com/api-reference/transactions/update-transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transaction_id` | path | `string` | no |
