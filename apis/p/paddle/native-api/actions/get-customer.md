# Get Customer with Paddle

Retrieves a customer from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `customers/{customer_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Get Customer](https://developer.paddle.com/api-reference/customers/get-customer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | no |
