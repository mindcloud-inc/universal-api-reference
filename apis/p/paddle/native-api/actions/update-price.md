# Update Price with Paddle

Updates an existing price in Paddle.

## Endpoint

- **Method:** `PATCH`
- **Path:** `prices/{price_id}`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [Update Price](https://developer.paddle.com/api-reference/prices/update-price)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `price_id` | path | `string` | no |
