# List Notifications with Paddle

Retrieves a list of notifications from Paddle.

## Endpoint

- **Method:** `GET`
- **Path:** `notifications`
- **Base URL:** `https://api.paddle.com`
- **Official documentation:** [List Notifications](https://developer.paddle.com/api-reference/notifications/list-notifications)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
