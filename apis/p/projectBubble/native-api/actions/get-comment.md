# Get Comment with Project Bubble

Retrieves a comment from Project Bubble by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/:comment_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Comment](https://help.proprofsproject.com/managing-comments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `comment_id` | path | `string` | yes |
