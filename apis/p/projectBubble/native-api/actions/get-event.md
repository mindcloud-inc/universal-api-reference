# Get Event with Project Bubble

Retrieves a Project Bubble event by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:event_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Event](https://help.proprofsproject.com/events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `event_id` | path | `string` | yes |
