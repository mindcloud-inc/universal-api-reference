# Create Project with Project Bubble

Creates a new project in Project Bubble.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Create Project](https://help.proprofsproject.com/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_name` | body | `string` | yes | The name of the project to create. |
