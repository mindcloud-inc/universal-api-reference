# Delete Contact with Project Bubble

Deletes an existing contact from Project Bubble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Delete Contact](https://help.proprofsproject.com/managing-contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
