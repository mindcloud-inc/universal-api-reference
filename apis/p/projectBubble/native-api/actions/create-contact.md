# Create Contact with Project Bubble

Creates a new contact in Project Bubble.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Create Contact](https://help.proprofsproject.com/managing-contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_name` | body | `string` | yes |
