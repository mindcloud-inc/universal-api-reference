# Delete Event with Project Bubble

Deletes an existing event from Project Bubble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/:event_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Delete Event](https://help.proprofsproject.com/events)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `event_id` | path | `string` | yes |
