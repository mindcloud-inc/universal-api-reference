# Get Contact with Project Bubble

Retrieves a Project Bubble contact by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Contact](https://help.proprofsproject.com/managing-contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
