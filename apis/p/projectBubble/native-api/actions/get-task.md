# Get Task with Project Bubble

Retrieves a Project Bubble task by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:task_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Task](https://help.proprofsproject.com/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The Project Bubble task ID to fetch. |
