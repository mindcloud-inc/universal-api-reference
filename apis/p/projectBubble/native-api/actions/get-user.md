# Get User with Project Bubble

Retrieves a Project Bubble user by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get User](https://help.proprofsproject.com/company-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The Project Bubble user ID to fetch. |
