# Get Project with Project Bubble

Retrieves a Project Bubble project by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Project](https://help.proprofsproject.com/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Project Bubble project ID to fetch. |
