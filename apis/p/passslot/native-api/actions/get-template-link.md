# Get Template Link with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `templates/:id/url`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Get Template Link](https://www.passslot.com/developer/api/resources/showTemplateURL)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot template ID. |
