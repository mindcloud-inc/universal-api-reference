# Get Template Distribution Restrictions with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `templates/:id/restrictions`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Get Template Distribution Restrictions](https://www.passslot.com/developer/api/resources/showTemplateRestrictions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot template ID. |
