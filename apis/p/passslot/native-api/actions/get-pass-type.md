# Get Pass Type with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `passtypes/:id`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Get Pass Type](https://www.passslot.com/developer/api/resources/showPassType)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot pass type ID. |
