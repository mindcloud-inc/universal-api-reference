# Get Template with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `templates/:id`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Get Template](https://www.passslot.com/developer/api/resources/showTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot template ID. |
