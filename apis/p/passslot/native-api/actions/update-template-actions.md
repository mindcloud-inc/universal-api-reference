# Update Template Actions with Passslot

## Endpoint

- **Method:** `PUT`
- **Path:** `templates/:id/actions`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Update Template Actions](https://www.passslot.com/developer/api/resources/updateTemplateActions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot template ID. |
