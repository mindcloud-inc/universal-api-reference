# List Passes By Pass Type with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `passes/:passTypeIdentifier`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [List Passes By Pass Type](https://www.passslot.com/developer/api/resources/listPassesByPassType)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `passTypeIdentifier` | path | `string` | yes | Passslot pass type identifier, for example pass.example.id1. |
