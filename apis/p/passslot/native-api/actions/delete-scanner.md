# Delete Scanner with Passslot

## Endpoint

- **Method:** `DELETE`
- **Path:** `scanners/:id`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Delete Scanner](https://www.passslot.com/developer/api/resources/deleteScanner)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot scanner ID. |
