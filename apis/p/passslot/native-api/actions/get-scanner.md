# Get Scanner with Passslot

## Endpoint

- **Method:** `GET`
- **Path:** `scanners/:id`
- **Base URL:** `https://api.passslot.com/v1`
- **Official documentation:** [Get Scanner](https://www.passslot.com/developer/api/resources/showScanner)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Passslot scanner ID. |
