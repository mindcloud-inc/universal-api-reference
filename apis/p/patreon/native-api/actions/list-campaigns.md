# List Campaigns with Patreon

Retrieves campaigns owned by the authorized user from Patreon.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://www.patreon.com/api/oauth2/v2`
- **Official documentation:** [List Campaigns](https://docs.patreon.com#get-api-oauth2-v2-campaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination).
