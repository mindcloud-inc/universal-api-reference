# List Webhooks with Patreon

Retrieves webhooks created by your client from Patreon.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://www.patreon.com/api/oauth2/v2`
- **Official documentation:** [List Webhooks](https://docs.patreon.com#get-api-oauth2-v2-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
