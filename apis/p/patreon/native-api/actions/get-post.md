# Get Post with Patreon

Retrieves a post by ID from Patreon.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/:postId`
- **Base URL:** `https://www.patreon.com/api/oauth2/v2`
- **Official documentation:** [Get Post](https://docs.patreon.com#get-api-oauth2-v2-posts-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postId` | path | `string` | yes | The Patreon post ID. |
