# Create Project with PickFu

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [Create Project](https://www.pickfu.com/docs/api-reference/projects/create-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Project name. |
| `description` | body | `string` | no | Project description. |
