# Search Help Articles with PickFu

## Endpoint

- **Method:** `GET`
- **Path:** `/help/search`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [Search Help Articles](https://www.pickfu.com/docs/api-reference/help/search-help-articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for help articles. |
| `page` | query | `number` | no | Page number for help article results. |
| `per_page` | query | `number` | no | Number of help article results per page. |
