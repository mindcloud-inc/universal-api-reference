# Delete Survey with PickFu

## Endpoint

- **Method:** `DELETE`
- **Path:** `/surveys/[:id]`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [Delete Survey](https://www.pickfu.com/docs/api-reference/surveys/delete-survey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Survey GUID. |
