# Get Project with PickFu

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/[:id]`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [Get Project](https://www.pickfu.com/docs/api-reference/projects/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project GUID. |
