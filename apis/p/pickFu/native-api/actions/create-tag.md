# Create Tag with PickFu

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [Create Tag](https://www.pickfu.com/docs/api-reference/tags/create-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name. |
