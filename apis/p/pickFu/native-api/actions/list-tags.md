# List Tags with PickFu

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.pickfu.com/v1`
- **Official documentation:** [List Tags](https://www.pickfu.com/docs/api-reference/tags/list-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Search filter for tag names. |
