# List Servers with Postmark

Retrieves servers from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/servers`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [List Servers](https://postmarkapp.com/developer/api/servers-api#list-servers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
