# List Domains with Postmark

Retrieves domains from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [List Domains](https://postmarkapp.com/developer/api/domains-api#list-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
