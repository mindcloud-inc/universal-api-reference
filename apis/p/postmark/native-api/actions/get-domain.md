# Get Domain with Postmark

Retrieves a domain from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domainId`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Get Domain](https://postmarkapp.com/developer/api/domains-api#domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainId` | path | `string` | yes | The Postmark domain ID. |
