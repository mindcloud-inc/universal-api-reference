# Search Outbound Messages with Postmark

Searches outbound messages in Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/outbound`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Search Outbound Messages](https://postmarkapp.com/developer/api/messages-api#outbound-message-search)

## Capabilities

This operation supports [pagination](../README.md#pagination).
