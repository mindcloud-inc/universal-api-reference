# List Sender Signatures with Postmark

Retrieves sender signatures from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/senders`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [List Sender Signatures](https://postmarkapp.com/developer/api/signatures-api#list-sender-signatures)

## Capabilities

This operation supports [pagination](../README.md#pagination).
