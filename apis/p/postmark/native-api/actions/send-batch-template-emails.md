# Send Batch Template Emails with Postmark

Sends batch template emails through Postmark.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/batchWithTemplates`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Send Batch Template Emails](https://postmarkapp.com/developer/api/templates-api#send-batch-with-templates)
