# Get Server with Postmark

Retrieves a server from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/servers/:serverId`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Get Server](https://postmarkapp.com/developer/api/servers-api#get-server)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | The Postmark server ID. |
