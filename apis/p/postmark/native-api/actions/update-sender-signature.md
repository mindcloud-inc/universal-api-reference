# Update Sender Signature with Postmark

Updates a sender signature in Postmark.

## Endpoint

- **Method:** `PUT`
- **Path:** `/senders/:signatureId`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Update Sender Signature](https://postmarkapp.com/developer/api/signatures-api#edit-signature)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signatureId` | path | `string` | yes | The Postmark sender signature ID. |
