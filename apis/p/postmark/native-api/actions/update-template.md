# Update Template with Postmark

Updates a template in Postmark.

## Endpoint

- **Method:** `PUT`
- **Path:** `/templates/:templateIdOrAlias`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Update Template](https://postmarkapp.com/developer/api/templates-api#edit-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateIdOrAlias` | path | `string` | yes | The Postmark template ID or alias. |
