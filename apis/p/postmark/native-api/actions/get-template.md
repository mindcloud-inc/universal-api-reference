# Get Template with Postmark

Retrieves a template from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateIdOrAlias`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Get Template](https://postmarkapp.com/developer/api/templates-api#get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateIdOrAlias` | path | `string` | yes | The Postmark template ID or alias. |
