# List Bounces with Postmark

Retrieves bounces from Postmark.

## Endpoint

- **Method:** `GET`
- **Path:** `/bounces`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [List Bounces](https://postmarkapp.com/developer/api/bounce-api#bounces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
