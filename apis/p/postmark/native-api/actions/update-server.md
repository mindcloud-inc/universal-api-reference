# Update Server with Postmark

Updates a server in Postmark.

## Endpoint

- **Method:** `PUT`
- **Path:** `/servers/:serverId`
- **Base URL:** `https://api.postmarkapp.com`
- **Official documentation:** [Update Server](https://postmarkapp.com/developer/api/servers-api#edit-server)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | The Postmark server ID. |
