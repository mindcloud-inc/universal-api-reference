# Get Search with Powrbot

Retrieves a bulk search job from Powrbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/:searchId/`
- **Base URL:** `https://powrbot.com/api/v1`
- **Official documentation:** [Get Search](https://powrbot.com/cpages/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchId` | path | `number` | yes | Numeric search job identifier. |
