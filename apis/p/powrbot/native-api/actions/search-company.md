# Search Company with Powrbot

Finds a company in Powrbot by company name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/single/`
- **Base URL:** `https://powrbot.com/api/v1`
- **Official documentation:** [Search Company](https://powrbot.com/cpages/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | query | `string` | yes | Company name to search for. |
