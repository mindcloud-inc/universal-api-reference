# Fetch All Transactions with Poof

Retrieves all transaction records from Poof.

## Endpoint

- **Method:** `POST`
- **Path:** `https://www.poof.io/api/v1/fetch_transactions`
- **Base URL:** `https://www.poof.io/api/v2`
- **Official documentation:** [Fetch All Transactions](https://docs.poof.io/reference/fetch-transaction-list)
