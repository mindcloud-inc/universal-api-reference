# Fetch Product with Poof

Retrieves product details from the Poof API.

## Endpoint

- **Method:** `POST`
- **Path:** `/fetch_product`
- **Base URL:** `https://www.poof.io/api/v2`
- **Official documentation:** [Fetch Product](https://docs.poof.io/reference/fetchproduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Product identifier. |
