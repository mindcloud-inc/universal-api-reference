# Fetch Transaction with Poof

Retrieves a transaction record from Poof.

## Endpoint

- **Method:** `POST`
- **Path:** `https://www.poof.io/api/v1/transaction`
- **Base URL:** `https://www.poof.io/api/v2`
- **Official documentation:** [Fetch Transaction](https://docs.poof.io/reference/fetch-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transaction` | body | `string` | yes | Transaction identifier. |
