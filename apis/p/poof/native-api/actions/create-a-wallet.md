# Create Wallet with Poof

Creates a new wallet in Poof.

## Endpoint

- **Method:** `POST`
- **Path:** `https://www.poof.io/api/v2/create_wallet`
- **Base URL:** `https://www.poof.io/api/v2`
- **Official documentation:** [Create Wallet](https://docs.poof.io/reference/crypto-wallet-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `currency` | body | `string` | yes | Wallet currency or chain. |
