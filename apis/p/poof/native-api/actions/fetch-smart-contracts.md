# Fetch Smart Contracts with Poof

## Endpoint

- **Method:** `POST`
- **Path:** `/gas_price`
- **Base URL:** `https://www.poof.io/api/v2`
- **Official documentation:** [Fetch Smart Contracts](https://docs.poof.io/reference/fetchsmartcontracts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `crypto` | body | `string` | yes | Crypto asset code. |
