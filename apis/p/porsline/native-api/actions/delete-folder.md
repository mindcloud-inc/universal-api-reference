# Delete Folder with Porsline

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/folders/:folder_id/`
- **Base URL:** `https://survey.porsline.com`
- **Official documentation:** [Delete Folder](https://developers.porsline.com/#tag/Folders/paths/~1api~1folders~1{folder_id}~1/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `number` | yes | Selected folder id. |
