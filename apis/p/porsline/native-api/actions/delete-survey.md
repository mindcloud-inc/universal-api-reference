# Delete Survey with Porsline

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/surveys/:survey_id/`
- **Base URL:** `https://survey.porsline.com`
- **Official documentation:** [Delete Survey](https://developers.porsline.com/#tag/Survey/paths/~1api~1v2~1surveys~1{survey_id}~1/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | path | `number` | yes | The id of the target survey. |
