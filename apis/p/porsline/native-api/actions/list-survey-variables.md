# List Survey Variables with Porsline

## Endpoint

- **Method:** `GET`
- **Path:** `/api/surveys/:survey_id/variables/`
- **Base URL:** `https://survey.porsline.com`
- **Official documentation:** [List Survey Variables](https://developers.porsline.com/#tag/Variables/paths/~1api~1surveys~1{survey_id}~1variables~1/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | path | `number` | yes | The id of the target survey. |
