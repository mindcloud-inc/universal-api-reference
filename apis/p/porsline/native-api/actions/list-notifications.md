# List Notifications with Porsline

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/surveys/:survey_id/notifications/`
- **Base URL:** `https://survey.porsline.com`
- **Official documentation:** [List Notifications](https://developers.porsline.com/#tag/Notifications/paths/~1api~1v2~1surveys~1{survey_id}~1notifications~1/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | path | `number` | yes | The id of the target survey. |
