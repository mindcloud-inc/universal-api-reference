# Porsline: Hash Hidden Fields



```
POST https://connect.mindcloud.co/v1/universal/porsline/latest/actions/hash-hidden-fields
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Porsline `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/porsline/latest/actions/hash-hidden-fields" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "survey_id": 1,
  "values": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/porsline/latest/actions/hash-hidden-fields', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "survey_id": 1,
    "values": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `survey_id` | number | yes | The id of the target survey. |
| `values` | string | yes | JSON array of respondent value maps to encrypt, for example [{"mc_stage3_var_1640":"alice@example.com"}] or [{"mc_stage3_var_1640":"alice@example.com","is_unique":true}]. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "urls": [
        "https://example.com"
      ]
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `urls` | array<string> | Encrypted survey URLs generated by Porsline. |

## Native endpoint

Through the native Porsline API, this operation is `POST /api/surveys/:survey_id/variables/hashes/` (base URL `https://survey.porsline.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/hash-hidden-fields.md) for the provider-specific parameters and requirements.
