# Get Location with PokeAPI Core

Retrieves a location from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/location/[:idOrName]/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Location](https://pokeapi.co/docs/v2#locations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idOrName` | path | `string` | yes | Location numeric ID or exact PokeAPI location name. |
