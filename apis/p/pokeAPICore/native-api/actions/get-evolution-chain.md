# Get Evolution Chain with PokeAPI Core

Retrieves an evolution chain from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/evolution-chain/[:id]/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Evolution Chain](https://pokeapi.co/docs/v2#evolution-chains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Evolution chain numeric ID. |
