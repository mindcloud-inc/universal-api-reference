# List Berries with PokeAPI Core

Retrieves a page of berries from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/berry/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Berries](https://pokeapi.co/docs/v2#berries)

## Capabilities

This operation supports [pagination](../README.md#pagination).
