# List Pokedexes with PokeAPI Core

Retrieves a page of Pokedexes from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/pokedex/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokedexes](https://pokeapi.co/docs/v2#pokedexes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
