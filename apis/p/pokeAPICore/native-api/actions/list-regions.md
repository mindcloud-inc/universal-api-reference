# List Regions with PokeAPI Core

Retrieves a page of regions from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/region/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Regions](https://pokeapi.co/docs/v2#regions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
