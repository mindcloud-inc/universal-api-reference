# List Types with PokeAPI Core

Retrieves a page of types from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/type/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Types](https://pokeapi.co/docs/v2#types)

## Capabilities

This operation supports [pagination](../README.md#pagination).
