# List Moves with PokeAPI Core

Retrieves a page of moves from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/move/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Moves](https://pokeapi.co/docs/v2#moves)

## Capabilities

This operation supports [pagination](../README.md#pagination).
