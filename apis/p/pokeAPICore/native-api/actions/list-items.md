# List Items with PokeAPI Core

Retrieves a page of items from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/item/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Items](https://pokeapi.co/docs/v2#items)

## Capabilities

This operation supports [pagination](../README.md#pagination).
