# List Evolution Chains with PokeAPI Core

Retrieves a page of evolution chains from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/evolution-chain/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Evolution Chains](https://pokeapi.co/docs/v2#evolution-chains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
