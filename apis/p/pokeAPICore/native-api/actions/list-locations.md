# List Locations with PokeAPI Core

Retrieves a page of locations from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/location/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Locations](https://pokeapi.co/docs/v2#locations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
