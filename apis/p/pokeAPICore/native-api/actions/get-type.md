# Get Type with PokeAPI Core

Retrieves a type from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/type/[:idOrName]/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Type](https://pokeapi.co/docs/v2#types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idOrName` | path | `string` | yes | Type numeric ID or exact PokeAPI type name. |
