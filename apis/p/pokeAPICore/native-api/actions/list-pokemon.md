# List Pokemon with PokeAPI Core

Retrieves a page of Pokemon from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/pokemon/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Pokemon](https://pokeapi.co/docs/v2#pokemon)

## Capabilities

This operation supports [pagination](../README.md#pagination).
