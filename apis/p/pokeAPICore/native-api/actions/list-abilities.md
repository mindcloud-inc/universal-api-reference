# List Abilities with PokeAPI Core

Retrieves a page of abilities from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/ability/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Abilities](https://pokeapi.co/docs/v2#abilities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
