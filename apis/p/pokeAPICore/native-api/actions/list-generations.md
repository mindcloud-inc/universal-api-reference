# List Generations with PokeAPI Core

Retrieves a page of generations from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/generation/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [List Generations](https://pokeapi.co/docs/v2#generations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
