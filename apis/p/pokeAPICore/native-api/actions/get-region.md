# Get Region with PokeAPI Core

Retrieves a region from PokeAPI Core.

## Endpoint

- **Method:** `GET`
- **Path:** `/region/[:idOrName]/`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Region](https://pokeapi.co/docs/v2#regions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idOrName` | path | `string` | yes | Region numeric ID or exact PokeAPI region name. |
