# Get Workflow Fields with PlumDocs

Retrieves workflow field definitions from PlumDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:id/fields`
- **Base URL:** `https://plumdocs.com/api/zapier`
- **Official documentation:** [Get Workflow Fields](https://plumdocs.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PlumDocs workflow id. |
