# Generate Document with PlumDocs

Generates a document from a PlumDocs workflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/workflows/:id/run`
- **Base URL:** `https://plumdocs.com/api/zapier`
- **Official documentation:** [Generate Document](https://plumdocs.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PlumDocs workflow id. |
