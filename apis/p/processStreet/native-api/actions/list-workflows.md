# List Workflows with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Workflows](https://public-api.process.st/api/v1.1/docs/index.html#tag/workflows/GET/workflows)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Filter workflows by partial name. |
