# List Workflow Run Form Field Values with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow-runs/:workflowRunId/form-fields`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Workflow Run Form Field Values](https://public-api.process.st/api/v1.1/docs/index.html#tag/form-field-values/GET/workflow-runs/{workflowRunId}/form-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowRunId` | path | `string` | yes | The ID of the workflow run. |
