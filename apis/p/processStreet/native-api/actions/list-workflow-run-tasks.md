# List Workflow Run Tasks with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow-runs/:workflowRunId/tasks`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Workflow Run Tasks](https://public-api.process.st/api/v1.1/docs/index.html#tag/tasks/GET/workflow-runs/{workflowRunId}/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowRunId` | path | `string` | yes | The ID of the workflow run. |
