# List Form Field Options with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflowId/form-fields/:formFieldId/options`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Form Field Options](https://public-api.process.st/api/v1.1/docs/index.html#tag/form-fields/GET/workflows/{workflowId}/form-fields/{formFieldId}/options)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | The ID of the workflow. |
| `formFieldId` | path | `string` | yes | The ID of the form field. |
