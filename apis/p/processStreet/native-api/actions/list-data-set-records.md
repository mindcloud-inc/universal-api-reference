# List Data Set Records with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/data-sets/:dataSetId/records`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Data Set Records](https://public-api.process.st/api/v1.1/docs/index.html#tag/data-sets/GET/data-sets/{dataSetId}/records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSetId` | path | `string` | yes | The ID of the data set. |
