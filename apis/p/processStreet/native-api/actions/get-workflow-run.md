# Get Workflow Run with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow-runs/:workflowRunId`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [Get Workflow Run](https://public-api.process.st/api/v1.1/docs/index.html#tag/workflow-runs/GET/workflow-runs/{workflowRunId})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowRunId` | path | `string` | yes | The ID of the workflow run. |
