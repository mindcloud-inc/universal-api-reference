# List Form Fields with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflowId/form-fields`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [List Form Fields](https://public-api.process.st/api/v1.1/docs/index.html#tag/form-fields/GET/workflows/{workflowId}/form-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | The ID of the workflow. |
