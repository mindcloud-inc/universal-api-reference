# Get Data Set Record with Process Street

## Endpoint

- **Method:** `GET`
- **Path:** `/data-sets/:dataSetId/records/:dataSetRecordId`
- **Base URL:** `https://public-api.process.st/api/v1.1`
- **Official documentation:** [Get Data Set Record](https://public-api.process.st/api/v1.1/docs/index.html#tag/data-sets/GET/data-sets/{dataSetId}/records/{dataSetRecordId})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSetId` | path | `string` | yes | The ID of the data set. |
| `dataSetRecordId` | path | `string` | yes | The ID of the data set record. |
