# Get Current User with PDFMonkey

Retrieves the current user from PDFMonkey.

## Endpoint

- **Method:** `GET`
- **Path:** `/current_user`
- **Base URL:** `https://api.pdfmonkey.io/api/v1`
- **Official documentation:** [Get Current User](https://pdfmonkey.io/docs/api/authentication/#make-a-test-api-call)
