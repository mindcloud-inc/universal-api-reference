# Delete Template with PDFMonkey

Deletes an existing template from PDFMonkey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/document_templates/:id`
- **Base URL:** `https://api.pdfmonkey.io/api/v1`
- **Official documentation:** [Delete Template](https://pdfmonkey.io/docs/api/templates/#delete-a-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the template to delete. |
