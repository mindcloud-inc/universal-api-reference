# Get Document with PDFMonkey

Retrieves a document from PDFMonkey.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.pdfmonkey.io/api/v1`
- **Official documentation:** [Get Document](https://pdfmonkey.io/docs/api/documents/#get-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Document to fetch. |
