# Delete Document with PDFMonkey

Deletes an existing document from PDFMonkey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.pdfmonkey.io/api/v1`
- **Official documentation:** [Delete Document](https://pdfmonkey.io/docs/api/documents/#delete-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Document to delete. |
