# Get Template with PDFMonkey

Retrieves a template from PDFMonkey.

## Endpoint

- **Method:** `GET`
- **Path:** `/document_templates/:id`
- **Base URL:** `https://api.pdfmonkey.io/api/v1`
- **Official documentation:** [Get Template](https://pdfmonkey.io/docs/api/templates/#get-a-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the template to fetch. |
