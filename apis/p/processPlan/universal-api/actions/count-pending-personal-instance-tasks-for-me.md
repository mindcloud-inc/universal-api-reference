# Process Plan: Count Pending Personal Instance Tasks for Me



```
GET https://connect.mindcloud.co/v1/universal/processPlan/latest/actions/count-pending-personal-instance-tasks-for-me
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Process Plan `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/processPlan/latest/actions/count-pending-personal-instance-tasks-for-me?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/processPlan/latest/actions/count-pending-personal-instance-tasks-for-me?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```



## Response

```json
{
  "success": true,
  "data": [
    {
      "count": 1
    }
  ],
  "meta": {}
}
```

## Native endpoint

Through the native Process Plan API, this operation is `GET /user/me/personal_instance_task/list/pending/count` (base URL `https://apius0.processplan.com/api/v4`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/count-pending-personal-instance-tasks-for-me.md) for the provider-specific parameters and requirements.
