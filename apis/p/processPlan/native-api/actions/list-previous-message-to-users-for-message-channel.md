# List Previous Message to Users for Message Channel with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/message_channel/:messageChannelId/previous_message_to_user/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Previous Message to Users for Message Channel](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageChannelId` | path | `string` | no | Message channel ID. |
