# Delete Text Block with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/text_block/:textBlockId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Text Block](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `textBlockId` | path | `string` | no | Text block ID. |
