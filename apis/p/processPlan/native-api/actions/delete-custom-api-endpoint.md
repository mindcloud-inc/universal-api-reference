# Delete Custom API Endpoint with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/custom_api_endpoint/:customAPIEndpointId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Custom API Endpoint](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customAPIEndpointId` | path | `string` | no | Custom API endpoint ID. |
