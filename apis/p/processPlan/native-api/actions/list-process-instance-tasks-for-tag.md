# List Process Instance Tasks for Tag with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/:tagId/process_instance_task/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Process Instance Tasks for Tag](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | no | Tag ID. |
