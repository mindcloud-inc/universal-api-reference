# Get Test Connection for Custom API Connection with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/custom_api_connection/:customAPIConnectionId/test_connection`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Test Connection for Custom API Connection](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customAPIConnectionId` | path | `string` | no | Custom API connection ID. |
