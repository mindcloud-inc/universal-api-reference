# Get Process Template Connector for Process Template Header with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_header/:processTemplateHeaderId/process_template_connector/:processTemplateConnectorId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Template Connector for Process Template Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateConnectorId` | path | `string` | no | Process template connector ID. |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
