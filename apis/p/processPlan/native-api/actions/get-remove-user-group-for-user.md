# Get Remove User Group for User with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user/:userId/remove_user_group/:removeUserGroupId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Remove User Group for User](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `removeUserGroupId` | path | `string` | no | Remove user group ID. |
| `userId` | path | `string` | no | User ID. |
