# Update Work Schedule with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/work_schedule/:workScheduleId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Work Schedule](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workScheduleId` | path | `string` | no | Work schedule ID. |
