# Get Process Template Field with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_field/:processTemplateFieldId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Template Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateFieldId` | path | `string` | no | Process template field ID. |
