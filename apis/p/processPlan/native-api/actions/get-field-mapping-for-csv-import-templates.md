# Get Field Mapping for CSV Import Templates with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/csv_import_template/field_map/:fieldMapId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Field Mapping for CSV Import Templates](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldMapId` | path | `string` | no | Field map ID. |
