# Update Automated Action Property with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/automated_action_property/:automatedActionPropertyId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Automated Action Property](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automatedActionPropertyId` | path | `string` | no | Automated action property ID. |
