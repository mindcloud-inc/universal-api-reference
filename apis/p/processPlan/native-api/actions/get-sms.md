# Get SMS with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/:smsId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get SMS](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smsId` | path | `string` | no | SMS ID. |
