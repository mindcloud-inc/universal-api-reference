# Get Process Template Header for Applies in Standard Operation Procedure Template with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/sop_template/:sopTemplateId/apply/process_template_header/:processTemplateHeaderId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Template Header for Applies in Standard Operation Procedure Template](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
| `sopTemplateId` | path | `string` | no | Sop template ID. |
