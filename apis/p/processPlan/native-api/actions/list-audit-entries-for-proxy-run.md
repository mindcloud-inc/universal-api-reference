# List Audit Entries for Proxy Run with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/proxy_run/:proxyRunId/audit_entry/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Audit Entries for Proxy Run](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `proxyRunId` | path | `string` | no | Proxy run ID. |
