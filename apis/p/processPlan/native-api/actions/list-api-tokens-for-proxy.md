# List API Tokens for Proxy with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/proxy/:proxyId/api_token/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List API Tokens for Proxy](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `proxyId` | path | `string` | no | Proxy ID. |
