# Get Remove User for User Group with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user_group/:userGroupId/remove_user/:removeUserId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Remove User for User Group](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `removeUserId` | path | `string` | no | Remove user ID. |
| `userGroupId` | path | `string` | no | User group ID. |
