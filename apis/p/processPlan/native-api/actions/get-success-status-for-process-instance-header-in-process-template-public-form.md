# Get Success Status for Process Instance Header in Process Template Public Form with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_public_form/:processTemplatePublicFormId/process_instance_header/:processInstanceHeaderId/success`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Success Status for Process Instance Header in Process Template Public Form](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
| `processTemplatePublicFormId` | path | `string` | no | Process template public form ID. |
