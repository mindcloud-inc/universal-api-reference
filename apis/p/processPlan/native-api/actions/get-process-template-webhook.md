# Get Process Template Webhook with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_webhook/:processTemplateWebhookId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Template Webhook](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateWebhookId` | path | `string` | no | Process template webhook ID. |
