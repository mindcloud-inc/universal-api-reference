# Get File for Process Template Header with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_header/:processTemplateHeaderId/file/:fileId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get File for Process Template Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | no | File ID. |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
