# Get User Custom Field with Process Plan

- **Method:** `GET`
- **Path:** `/user_custom_field/:userCustomFieldId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get User Custom Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userCustomFieldId` | path | `string` | no | User custom field ID. |
