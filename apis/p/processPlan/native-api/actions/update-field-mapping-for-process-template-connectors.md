# Update Field Mapping for Process Template Connectors with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_connector/field_map/:fieldMapId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Field Mapping for Process Template Connectors](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldMapId` | path | `string` | no | Field map ID. |
