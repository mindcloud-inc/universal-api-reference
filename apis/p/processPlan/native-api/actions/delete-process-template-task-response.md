# Delete Process Template Task Response with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_response/:processTemplateResponseId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Process Template Task Response](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateResponseId` | path | `string` | no | Process template response ID. |
