# Delete Message for Me with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user/me/message/:messageId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Message for Me](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | no | Message ID. |
