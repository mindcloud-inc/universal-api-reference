# Get Set Reminder for Message in Me with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user/me/message/:messageId/set_reminder/:setReminderId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Set Reminder for Message in Me](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | no | Message ID. |
| `setReminderId` | path | `string` | no | Set reminder ID. |
