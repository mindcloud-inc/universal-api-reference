# Count Process Instance Fields with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_instance_header/:processInstanceHeaderId/process_instance_field/count`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Count Process Instance Fields](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
