# Update File with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/file/:fileId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update File](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | no | File ID. |
