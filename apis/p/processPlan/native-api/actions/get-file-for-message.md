# Get File for Message with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/message/:messageId/file/:fileId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get File for Message](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | no | File ID. |
| `messageId` | path | `string` | no | Message ID. |
