# Store Purchase for Process Template Header for Process Template Category with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_category/:processTemplateCategoryId/process_template_header/:processTemplateHeaderId/store_purchase`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Store Purchase for Process Template Header for Process Template Category](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateCategoryId` | path | `string` | no | Process template category ID. |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
