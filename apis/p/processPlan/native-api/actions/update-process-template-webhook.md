# Update Process Template Webhook with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_webhook/:processTemplateWebhookId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Process Template Webhook](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateWebhookId` | path | `string` | no | Process template webhook ID. |
