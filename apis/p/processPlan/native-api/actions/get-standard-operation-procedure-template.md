# Get Standard Operation Procedure Template with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/sop_template/:sopTemplateId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Standard Operation Procedure Template](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sopTemplateId` | path | `string` | no | Sop template ID. |
