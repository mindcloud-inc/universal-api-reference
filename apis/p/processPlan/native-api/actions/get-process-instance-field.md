# Get Process Instance Field with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_instance_header/:processInstanceHeaderId/process_instance_field/:processInstanceFieldId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Instance Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceFieldId` | path | `string` | no | Process instance field ID. |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
