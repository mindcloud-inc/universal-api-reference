# Cancel Process Instance Header with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_instance_header/:processInstanceHeaderId/cancel`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Cancel Process Instance Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
