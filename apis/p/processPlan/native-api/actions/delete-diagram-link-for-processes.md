# Delete Diagram Link for Processes with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process/diagram_link/:diagramLinkId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Diagram Link for Processes](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `diagramLinkId` | path | `string` | no | Diagram link ID. |
