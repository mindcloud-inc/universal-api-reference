# List Files for Process Instance Field with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_instance_field/:processInstanceFieldId/file/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Files for Process Instance Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceFieldId` | path | `string` | no | Process instance field ID. |
