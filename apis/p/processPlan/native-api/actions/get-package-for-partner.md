# Get Package for Partner with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/partner/:partnerId/package/:packageId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Package for Partner](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `packageId` | path | `string` | no | Package ID. |
| `partnerId` | path | `string` | no | Partner ID. |
