# Get Tag for Process Template Task with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_task/:processTemplateTaskId/tag/:tagId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Tag for Process Template Task](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateTaskId` | path | `string` | no | Process template task ID. |
| `tagId` | path | `string` | no | Tag ID. |
