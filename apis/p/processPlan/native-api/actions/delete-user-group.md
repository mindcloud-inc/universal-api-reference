# Delete User Group with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user_group/:userGroupId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete User Group](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userGroupId` | path | `string` | no | User group ID. |
