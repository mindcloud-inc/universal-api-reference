# Delete Process Template Field Option with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_field_option/:processTemplateFieldOptionId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Process Template Field Option](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateFieldOptionId` | path | `string` | no | Process template field option ID. |
