# Remove File for Process Template Field with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_field/:processTemplateFieldId/file/:fileId/remove`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Remove File for Process Template Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | no | File ID. |
| `processTemplateFieldId` | path | `string` | no | Process template field ID. |
