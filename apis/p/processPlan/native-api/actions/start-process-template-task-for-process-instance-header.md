# Start Process Template Task for Process Instance Header with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_instance_header/:processInstanceHeaderId/process_template_task/:processTemplateTaskId/start`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Start Process Template Task for Process Instance Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
| `processTemplateTaskId` | path | `string` | no | Process template task ID. |
