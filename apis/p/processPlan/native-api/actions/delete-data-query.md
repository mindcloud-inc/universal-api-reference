# Delete Data Query with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/data_query/:dataQueryId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Data Query](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataQueryId` | path | `string` | no | Data query ID. |
