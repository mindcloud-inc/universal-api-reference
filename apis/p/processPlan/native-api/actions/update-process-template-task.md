# Update Process Template Task with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_task/:processTemplateTaskId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Process Template Task](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateTaskId` | path | `string` | no | Process template task ID. |
