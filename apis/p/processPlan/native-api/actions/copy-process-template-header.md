# Copy Process Template Header with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_header/:processTemplateHeaderId/copy`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Copy Process Template Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
