# Count Unread Messages for Message Thread with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/message_thread/:messageThreadId/message/list/unread/count`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Count Unread Messages for Message Thread](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageThreadId` | path | `string` | no | Message thread ID. |
