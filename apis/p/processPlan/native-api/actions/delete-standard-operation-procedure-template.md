# Delete Standard Operation Procedure Template with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/sop_template/:sopTemplateId/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete Standard Operation Procedure Template](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sopTemplateId` | path | `string` | no | Sop template ID. |
