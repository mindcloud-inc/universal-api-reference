# Update Tag with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/tag/:tagId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Tag](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | no | Tag ID. |
