# Update Automated Action Condition with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/automated_action_condition/:automatedActionConditionId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Automated Action Condition](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automatedActionConditionId` | path | `string` | no | Automated action condition ID. |
