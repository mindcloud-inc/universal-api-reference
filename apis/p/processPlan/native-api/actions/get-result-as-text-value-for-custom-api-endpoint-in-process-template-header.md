- **Method:** `GET`

- **Base URL:** `https://apius0.processplan.com/api/v4`

| --- | --- | --- | --- | --- |
| `customAPIEndpointId` | path | `string` | no | Custom API endpoint ID. |
| `processTemplateHeaderId` | path | `string` | no | Process template header ID. |
