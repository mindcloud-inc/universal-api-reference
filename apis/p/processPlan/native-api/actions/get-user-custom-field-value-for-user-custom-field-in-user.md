# Get User Custom Field Value for User Custom Field in User with Process Plan

- **Method:** `GET`
- **Path:** `/user/:userId/user_custom_field/:userCustomFieldId/user_custom_value`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get User Custom Field Value for User Custom Field in User](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userCustomFieldId` | path | `string` | no | User custom field ID. |
| `userId` | path | `string` | no | User ID. |
