# Update CSV Import Template with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/csv_import_template/:csvImportTemplateId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update CSV Import Template](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `csvImportTemplateId` | path | `string` | no | CSV import template ID. |
