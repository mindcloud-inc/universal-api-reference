# Update Message Thread with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/message_thread/:messageThreadId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Message Thread](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageThreadId` | path | `string` | no | Message thread ID. |
