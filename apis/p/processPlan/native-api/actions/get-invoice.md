# Get Invoice with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:invoiceId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Invoice](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | path | `string` | no | Invoice ID. |
