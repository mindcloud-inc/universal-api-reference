# List Audit Entries for Proxy Job with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/proxy_job/:proxyJobId/audit_entry/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Audit Entries for Proxy Job](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `proxyJobId` | path | `string` | no | Proxy job ID. |
