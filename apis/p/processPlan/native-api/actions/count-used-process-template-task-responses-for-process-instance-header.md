# Count Used Process Template Task Responses for Process Instance Header with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_instance_header/:processInstanceHeaderId/process_template_response/:processTemplateResponseId/used/count`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Count Used Process Template Task Responses for Process Instance Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
| `processTemplateResponseId` | path | `string` | no | Process template response ID. |
