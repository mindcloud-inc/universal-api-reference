# Get Add User Group for User with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user/:userId/add_user_group/:addUserGroupId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Add User Group for User](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `addUserGroupId` | path | `string` | no | Add user group ID. |
| `userId` | path | `string` | no | User ID. |
