# List Process Template Tasks for Process Template Connector in Process Instance Header with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_instance_header/:processInstanceHeaderId/process_template_connector/:processTemplateConnectorId/process_template_task/list`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [List Process Template Tasks for Process Template Connector in Process Instance Header](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processInstanceHeaderId` | path | `string` | no | Process instance header ID. |
| `processTemplateConnectorId` | path | `string` | no | Process template connector ID. |
