# Get Field Mapping for CSV Import Templates in Process Template Field in CSV Import Template with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/csv_import_template/:csvImportTemplateId/process_template_field/:processTemplateFieldId/csv_import_template/field_map`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Field Mapping for CSV Import Templates in Process Template Field in CSV Import Template](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `csvImportTemplateId` | path | `string` | no | CSV import template ID. |
| `processTemplateFieldId` | path | `string` | no | Process template field ID. |
