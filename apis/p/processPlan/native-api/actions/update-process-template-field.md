# Update Process Template Field with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/process_template_field/:processTemplateFieldId/update`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Update Process Template Field](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateFieldId` | path | `string` | no | Process template field ID. |
