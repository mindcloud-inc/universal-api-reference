# Get Process Template Group with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/process_template_group/:processTemplateGroupId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Process Template Group](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processTemplateGroupId` | path | `string` | no | Process template group ID. |
