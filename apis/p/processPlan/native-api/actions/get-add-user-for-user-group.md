# Get Add User for User Group with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/user_group/:userGroupId/add_user/:addUserId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get Add User for User Group](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `addUserId` | path | `string` | no | Add user ID. |
| `userGroupId` | path | `string` | no | User group ID. |
