# Delete API Token for Proxy with Process Plan

## Endpoint

- **Method:** `POST`
- **Path:** `/proxy/:proxyId/api_token/delete`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Delete API Token for Proxy](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `proxyId` | path | `string` | no | Proxy ID. |
