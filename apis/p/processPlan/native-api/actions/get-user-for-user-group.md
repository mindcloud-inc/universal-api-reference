# Get User for User Group with Process Plan

## Endpoint

- **Method:** `GET`
- **Path:** `/user_group/:userGroupId/user/:userId`
- **Base URL:** `https://apius0.processplan.com/api/v4`
- **Official documentation:** [Get User for User Group](https://answers.processplan.com/c/api/api-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userGroupId` | path | `string` | no | User group ID. |
| `userId` | path | `string` | no | User ID. |
