# Process Plan: Native API Reference

A consolidated summary of Process Plan's API configuration and 661 documented operations, with links to official documentation.

- **Official docs:** https://answers.processplan.com/c/api
- **API base URL:** `https://apius0.processplan.com/api/v4`

## Authentication

### API Token

Use a ProcessPlan API token sent in the tkn_id header.

### Credentials

- **API Key:** `apiKey` · required · ProcessPlan API token.

[Official authentication documentation](https://answers.processplan.com/c/api/authentication)

## API conventions

Request bodies use JSON.

Shared headers:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Filtering

Send filters in the query string. Supported operators: `eq`.
