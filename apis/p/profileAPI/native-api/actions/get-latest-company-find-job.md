# Get Latest Company Find Job with profileAPI

Retrieves the latest company search job from profileAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/find/jobs/latest`
- **Base URL:** `https://api.profileapi.com/2024-03-01`
- **Official documentation:** [Get Latest Company Find Job](https://documentation.profileapi.com/api-reference/get-latest-company-find-job/)
