# Lookup Domain Whois with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/whois`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Lookup Domain Whois](https://docs.piloterr.com/domain-whois)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Domain to look up. |
