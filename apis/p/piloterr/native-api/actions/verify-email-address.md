# Verify Email Address with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/email/verify`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Verify Email Address](https://docs.piloterr.com/email-verify)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Email address to verify. |
