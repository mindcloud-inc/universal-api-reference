# Search LinkedIn Jobs with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/job/search`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Search LinkedIn Jobs](https://docs.piloterr.com/linkedin-job-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `geo_id` | query | `string` | no | LinkedIn geo identifier. |
| `keyword` | query | `string` | no | LinkedIn jobs keyword. |
| `page` | query | `string` | no | Results page number. |
