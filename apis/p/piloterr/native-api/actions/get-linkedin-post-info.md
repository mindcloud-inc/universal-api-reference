# Get LinkedIn Post Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/post/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get LinkedIn Post Info](https://docs.piloterr.com/linkedin-post-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | LinkedIn post URL or post ID. |
