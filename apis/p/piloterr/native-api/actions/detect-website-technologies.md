# Detect Website Technologies with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/website/technology`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Detect Website Technologies](https://docs.piloterr.com/website-technology)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Public website URL to analyze for detected technologies. |
