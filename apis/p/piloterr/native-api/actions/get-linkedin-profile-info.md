# Get LinkedIn Profile Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/profile/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get LinkedIn Profile Info](https://docs.piloterr.com/linkedin-profile-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | LinkedIn profile URL, slug, or member ID. |
