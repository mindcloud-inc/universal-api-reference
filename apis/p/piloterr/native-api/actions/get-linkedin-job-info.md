# Get LinkedIn Job Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/job/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get LinkedIn Job Info](https://docs.piloterr.com/linkedin-job-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | LinkedIn job URL or job ID. |
