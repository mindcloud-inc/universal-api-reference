# Check Domain DNSBL with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/dnsbl`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Check Domain DNSBL](https://docs.piloterr.com/domain-dnsbl)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Domain or IP address to check against DNSBL providers. |
