# Get Similarweb Domain with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/similarweb/domain`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get Similarweb Domain](https://docs.piloterr.com/similarweb-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Domain to inspect with Similarweb. |
