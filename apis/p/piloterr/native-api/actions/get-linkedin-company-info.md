# Get LinkedIn Company Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/company/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get LinkedIn Company Info](https://docs.piloterr.com/linkedin-company-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Domain for LinkedIn reverse company lookup. |
| `query` | query | `string` | no | LinkedIn company URL, slug, or numeric ID. |
