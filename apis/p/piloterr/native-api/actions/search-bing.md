- **Method:** `GET`
- **Path:** `/bing/search`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Search Bing](https://docs.piloterr.com/bing-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Bing search query. |
