# Search Google Jobs with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/google/jobs`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Search Google Jobs](https://docs.piloterr.com/google-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Job search term for Google Jobs. |
