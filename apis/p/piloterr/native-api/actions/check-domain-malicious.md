# Check Domain Malicious with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/malicious`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Check Domain Malicious](https://docs.piloterr.com/domain-malicious)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Domain or IP address to check for malicious reports. |
