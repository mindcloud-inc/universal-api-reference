# Search Crunchbase with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/crunchbase/search`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Search Crunchbase](https://docs.piloterr.com/crunchbase-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Crunchbase search keyword. |
