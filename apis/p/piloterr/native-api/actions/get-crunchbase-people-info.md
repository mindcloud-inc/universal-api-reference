# Get Crunchbase People Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/crunchbase/people/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get Crunchbase People Info](https://docs.piloterr.com/crunchbase-people-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Crunchbase person slug, name, or URL. |
