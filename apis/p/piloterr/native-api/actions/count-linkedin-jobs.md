# Count LinkedIn Jobs with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/linkedin/job/count`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Count LinkedIn Jobs](https://docs.piloterr.com/linkedin-job-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `geo_id` | query | `string` | no | LinkedIn geo identifier. |
| `keyword` | query | `string` | no | LinkedIn jobs keyword to count. |
