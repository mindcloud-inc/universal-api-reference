# Get Crunchbase Company Info with Piloterr

## Endpoint

- **Method:** `GET`
- **Path:** `/crunchbase/company/info`
- **Base URL:** `https://api.piloterr.com/v2`
- **Official documentation:** [Get Crunchbase Company Info](https://docs.piloterr.com/crunchbase-company-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | Domain for Crunchbase reverse company lookup. |
| `query` | query | `string` | no | Crunchbase company name, UUID, or URL. |
