# Search Companies with Prospeo

Finds companies in Prospeo.

## Endpoint

- **Method:** `POST`
- **Path:** `/search-company`
- **Base URL:** `https://api.prospeo.io`
- **Official documentation:** [Search Companies](https://prospeo.io/api-docs/search-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | Complete company search filter configuration. |
