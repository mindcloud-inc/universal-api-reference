# Search Persons by Department with Prospeo

Finds persons in Prospeo by department.

## Endpoint

- **Method:** `POST`
- **Path:** `/search-person`
- **Base URL:** `https://api.prospeo.io`
- **Official documentation:** [Search Persons by Department](https://prospeo.io/api-docs/search-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | Person department search filters. |
