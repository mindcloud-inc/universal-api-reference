# Search Persons with Prospeo

Finds persons in Prospeo.

## Endpoint

- **Method:** `POST`
- **Path:** `/search-person`
- **Base URL:** `https://api.prospeo.io`
- **Official documentation:** [Search Persons](https://prospeo.io/api-docs/search-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | Complete person search filter configuration. |
