# Search Companies by Technology with Prospeo

Finds companies in Prospeo by technology.

## Endpoint

- **Method:** `POST`
- **Path:** `/search-company`
- **Base URL:** `https://api.prospeo.io`
- **Official documentation:** [Search Companies by Technology](https://prospeo.io/api-docs/search-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | Company technology filters. |
