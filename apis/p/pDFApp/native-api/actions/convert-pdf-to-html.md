# Convert PDF To HTML with PDF-app

Creates HTML from a PDF in PDF-app.

## Endpoint

- **Method:** `POST`
- **Path:** `/pdf_to_html`
- **Base URL:** `https://api.pdf-app.net`
- **Official documentation:** [Convert PDF To HTML](https://pdf-app.net/apidocumentation?type=pdf_to_html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pdf_url` | body | `string` | yes | Public URL of the PDF file to convert to HTML. |
