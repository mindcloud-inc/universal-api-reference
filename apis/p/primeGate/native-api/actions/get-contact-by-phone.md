# Get Contact by Phone with PrimeGate

## Endpoint

- **Method:** `POST`
- **Path:** `contact/get`
- **Base URL:** `https://api.primegate.io/v2`
- **Official documentation:** [Get Contact by Phone](https://www.primegate.io/support/metody-dlya-polucheniya-spiska-sushchnostey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query[phone]` | body | `string` | yes |
