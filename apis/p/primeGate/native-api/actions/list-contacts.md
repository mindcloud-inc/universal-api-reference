# List Contacts with PrimeGate

## Endpoint

- **Method:** `POST`
- **Path:** `contact/get`
- **Base URL:** `https://api.primegate.io/v2`
- **Official documentation:** [List Contacts](https://www.primegate.io/support/metody-dlya-polucheniya-spiska-sushchnostey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | body | `number` | no |
| `offset` | body | `number` | no |
| `select` | body | `string` | no |
