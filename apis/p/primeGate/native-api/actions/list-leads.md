# List Leads with PrimeGate

## Endpoint

- **Method:** `POST`
- **Path:** `lead/get`
- **Base URL:** `https://api.primegate.io/v2`
- **Official documentation:** [List Leads](https://www.primegate.io/support/metody-dlya-polucheniya-spiska-sushchnostey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | — |
| `offset` | body | `number` | no | — |
| `select` | body | `string` | no | Comma-separated list of lead fields to return. |
