# Create Template with Pirsonal

Creates a new template in Pirsonal.

## Endpoint

- **Method:** `POST`
- **Path:** `/api`
- **Base URL:** `https://app.pirsonal.com`
- **Official documentation:** [Create Template](https://app.pirsonal.com/docAPI#Template_New)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template` | body | `object` | yes | TemplateNew_t object to create. |
