# List Template Videos with Pirsonal

Retrieves videos created from a Pirsonal template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api`
- **Base URL:** `https://app.pirsonal.com`
- **Official documentation:** [List Template Videos](https://app.pirsonal.com/docAPI#Template_Video_List)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | body | `string` | yes | Template ID whose videos should be listed. |
