# List Video Links with Pirsonal

Retrieves downloadable links for a Pirsonal video.

## Endpoint

- **Method:** `POST`
- **Path:** `/api`
- **Base URL:** `https://app.pirsonal.com`
- **Official documentation:** [List Video Links](https://app.pirsonal.com/docAPI#Video_Get_Links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoID` | body | `string` | yes | ID of the video whose links should be listed. |
