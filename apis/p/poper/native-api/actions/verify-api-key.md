# Verify API Key with Poper

Verifies a Poper API key and retrieves the account email.

## Endpoint

- **Method:** `POST`
- **Path:** `/ping`
- **Base URL:** `https://api.poper.ai/general/v1`
- **Official documentation:** [Verify API Key](https://support.poper.ai/en/articles/10095373-setting-up-and-authenticating-your-api-key)
