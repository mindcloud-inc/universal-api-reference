# List Applications with Peliqan

Retrieves applications from Peliqan.

## Endpoint

- **Method:** `GET`
- **Path:** `/applications/`
- **Base URL:** `https://app.eu.peliqan.io/api`
- **Official documentation:** [List Applications](https://app.eu.peliqan.io/api/redoc/#tag/Databases/operation/list_all_applications)
