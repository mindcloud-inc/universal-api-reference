# Delete Bin with PostBin

Deletes a PostBin bin and its requests.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bin/:binId`
- **Base URL:** `https://www.postb.in/api/`
- **Official documentation:** [Delete Bin](https://www.postb.in/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `binId` | path | `string` | yes | The PostBin bin identifier. |
