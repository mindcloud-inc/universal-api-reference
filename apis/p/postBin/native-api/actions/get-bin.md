# Get Bin with PostBin

Retrieves a PostBin bin by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/bin/:binId`
- **Base URL:** `https://www.postb.in/api/`
- **Official documentation:** [Get Bin](https://www.postb.in/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `binId` | path | `string` | yes | The PostBin bin identifier. |
