# Get Website Domain Research Job Status with PagePixels

## Endpoint

- **Method:** `GET`
- **Path:** `/api/domain_research_requests/:job_id/status`
- **Base URL:** `https://api.pagepixels.com`
- **Official documentation:** [Get Website Domain Research Job Status](https://pagepixels.com/app/screenshots-api-documentation#domain-research-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The PagePixels domain research job ID. |
