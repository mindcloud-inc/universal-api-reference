# Delete Screenshot Configuration with PagePixels

## Endpoint

- **Method:** `DELETE`
- **Path:** `/screenshot_configs/:screenshot_config_id`
- **Base URL:** `https://api.pagepixels.com`
- **Official documentation:** [Delete Screenshot Configuration](https://pagepixels.com/app/screenshots-api-documentation#scheduled-screenshots-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `screenshot_config_id` | path | `string` | yes | The screenshot configuration ID to delete. |
