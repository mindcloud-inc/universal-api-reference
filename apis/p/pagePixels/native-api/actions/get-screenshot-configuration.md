# Get Screenshot Configuration with PagePixels

## Endpoint

- **Method:** `GET`
- **Path:** `/screenshot_configs/:screenshot_configuration_id`
- **Base URL:** `https://api.pagepixels.com`
- **Official documentation:** [Get Screenshot Configuration](https://pagepixels.com/app/screenshots-api-documentation#scheduled-screenshots-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `screenshot_configuration_id` | path | `string` | yes | The screenshot configuration ID returned by PagePixels. |
