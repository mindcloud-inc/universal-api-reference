# Capture Screenshot with PagePixels

## Endpoint

- **Method:** `GET`
- **Path:** `/snap`
- **Base URL:** `https://api.pagepixels.com`
- **Official documentation:** [Capture Screenshot](https://pagepixels.com/app/screenshots-api-documentation#quick-snap)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The web page URL to capture. |
