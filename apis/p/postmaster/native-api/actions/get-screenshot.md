# Get Screenshot with Postmaster+

Retrieves a screenshot from the Postmaster+ API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/screenshot/:id`
- **Base URL:** `https://postmasterplus.app`
- **Official documentation:** [Get Screenshot](https://postmasterplus.app/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ULID of the screenshot. |
