# Retrieve Domains with Postmaster+

Retrieves available domains from the Postmaster+ API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/domains`
- **Base URL:** `https://postmasterplus.app`
- **Official documentation:** [Retrieve Domains](https://postmasterplus.app/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
