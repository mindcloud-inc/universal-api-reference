# Retrieve Single Email with Postmaster+

Retrieves single email intelligence from Postmaster+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/intelligence/single-emails/:email`
- **Base URL:** `https://postmasterplus.app`
- **Official documentation:** [Retrieve Single Email](https://postmasterplus.app/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email address to retrieve. |
