# Delete Single Email with Postmaster+

Deletes single email intelligence from Postmaster+.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/intelligence/single-emails/:email`
- **Base URL:** `https://postmasterplus.app`
- **Official documentation:** [Delete Single Email](https://postmasterplus.app/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email address to delete. |
