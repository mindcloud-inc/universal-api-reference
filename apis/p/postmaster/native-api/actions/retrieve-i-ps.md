# Retrieve IPs with Postmaster+

Retrieves IP records from the Postmaster+ API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ips`
- **Base URL:** `https://postmasterplus.app`
- **Official documentation:** [Retrieve IPs](https://postmasterplus.app/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
