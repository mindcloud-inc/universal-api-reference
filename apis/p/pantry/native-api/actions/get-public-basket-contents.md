# Get Public Basket Contents with Pantry

Retrieves public basket contents from Pantry.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/:publicBasketId`
- **Base URL:** `https://getpantry.cloud/apiv1`
- **Official documentation:** [Get Public Basket Contents](https://documenter.getpostman.com/view/3281832/SzmZeMLC)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publicBasketId` | path | `string` | yes | Public basket ID returned by Get Public Basket ID. |
