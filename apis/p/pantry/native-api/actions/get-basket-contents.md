# Get Basket Contents with Pantry

Retrieves basket contents from Pantry.

## Endpoint

- **Method:** `GET`
- **Path:** `/pantry/:pantryId/basket/:basketName`
- **Base URL:** `https://getpantry.cloud/apiv1`
- **Official documentation:** [Get Basket Contents](https://documenter.getpostman.com/view/3281832/SzmZeMLC)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `basketName` | path | `string` | yes | Name of the basket to retrieve. |
