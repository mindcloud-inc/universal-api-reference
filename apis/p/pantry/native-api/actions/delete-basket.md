# Delete Basket with Pantry

Deletes an existing basket from Pantry.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pantry/:pantryId/basket/:basketName`
- **Base URL:** `https://getpantry.cloud/apiv1`
- **Official documentation:** [Delete Basket](https://documenter.getpostman.com/view/3281832/SzmZeMLC)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `basketName` | path | `string` | yes | Name of the basket to delete. |
