# Update Pantry Details with Pantry

Updates pantry details in Pantry.

## Endpoint

- **Method:** `PUT`
- **Path:** `/pantry/:pantryId`
- **Base URL:** `https://getpantry.cloud/apiv1`
- **Official documentation:** [Update Pantry Details](https://documenter.getpostman.com/view/3281832/SzmZeMLC)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Updated pantry name. |
| `description` | body | `string` | no | Updated pantry description. |
