# Clean School with People Data Labs

## Endpoint

- **Method:** `GET`
- **Path:** `/school/clean`
- **Base URL:** `https://api.peopledatalabs.com/v5`
- **Official documentation:** [Clean School](https://docs.peopledatalabs.com/docs/cleaner-apis-reference#school-cleaner-api-schoolclean)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | School name to standardize into canonical school data. |
