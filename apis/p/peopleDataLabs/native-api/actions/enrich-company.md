# Enrich Company with People Data Labs

## Endpoint

- **Method:** `GET`
- **Path:** `/company/enrich`
- **Base URL:** `https://api.peopledatalabs.com/v5`
- **Official documentation:** [Enrich Company](https://docs.peopledatalabs.com/docs/reference-company-enrichment-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile` | query | `string` | yes | LinkedIn company profile URL used for deterministic company enrichment. |
