# Clean Location with People Data Labs

## Endpoint

- **Method:** `GET`
- **Path:** `/location/clean`
- **Base URL:** `https://api.peopledatalabs.com/v5`
- **Official documentation:** [Clean Location](https://docs.peopledatalabs.com/docs/cleaner-apis-reference#location-cleaner-api-locationclean)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `location` | query | `string` | yes | Unformatted location string to standardize into canonical location data. |
