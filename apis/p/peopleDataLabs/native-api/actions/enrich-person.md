# Enrich Person with People Data Labs

## Endpoint

- **Method:** `GET`
- **Path:** `/person/enrich`
- **Base URL:** `https://api.peopledatalabs.com/v5`
- **Official documentation:** [Enrich Person](https://docs.peopledatalabs.com/docs/reference-person-enrichment-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile` | query | `string` | yes | A social profile that the person has used. |
