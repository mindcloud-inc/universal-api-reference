# Clean Company with People Data Labs

## Endpoint

- **Method:** `GET`
- **Path:** `/company/clean`
- **Base URL:** `https://api.peopledatalabs.com/v5`
- **Official documentation:** [Clean Company](https://docs.peopledatalabs.com/docs/cleaner-apis-reference#company-cleaner-api-companyclean)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile` | query | `string` | yes | Company profile URL to standardize into canonical company data. |
