# Get Upload with Printify

Retrieves an upload from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/:image_id.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [Get Upload](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | Printify upload image id. |
