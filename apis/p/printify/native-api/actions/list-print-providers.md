# List Print Providers with Printify

Retrieves print providers from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/print_providers.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [List Print Providers](https://developers.printify.com/API-Doc-RREdits.html/1000)
