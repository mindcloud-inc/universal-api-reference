# List Uploads with Printify

Retrieves uploads from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [List Uploads](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of uploads to return. |
| `page` | query | `number` | no | Result page to fetch. |
