# List Blueprints with Printify

Retrieves blueprints from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/blueprints.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [List Blueprints](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of blueprints to return. |
| `page` | query | `number` | no | Result page to fetch. |
