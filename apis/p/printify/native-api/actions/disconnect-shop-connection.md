# Disconnect Shop Connection with Printify

Disconnects a Printify shop connection.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shops/:shop_id/connection.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [Disconnect Shop Connection](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shop_id` | path | `number` | yes | Printify shop id. |
