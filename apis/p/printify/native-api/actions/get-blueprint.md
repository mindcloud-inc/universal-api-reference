# Get Blueprint with Printify

Retrieves a blueprint from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/blueprints/:blueprint_id.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [Get Blueprint](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blueprint_id` | path | `number` | yes | Printify blueprint id. |
