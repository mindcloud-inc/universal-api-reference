# Get Print Provider with Printify

Retrieves a print provider from Printify.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/print_providers/:print_provider_id.json`
- **Base URL:** `https://api.printify.com/v1/`
- **Official documentation:** [Get Print Provider](https://developers.printify.com/API-Doc-RREdits.html/1000)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `print_provider_id` | path | `number` | yes | Printify print provider id. |
