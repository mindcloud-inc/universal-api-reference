# Describe Index with Pinecone

Retrieves details for an index from Pinecone.

## Endpoint

- **Method:** `GET`
- **Path:** `/indexes/:index_name`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [Describe Index](https://docs.pinecone.io/reference/api/2025-10/control-plane/describe_index)
