# List Imports with Pinecone

Retrieves imports from a Pinecone index.

## Endpoint

- **Method:** `GET`
- **Path:** `{indexHost}/bulk/imports`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [List Imports](https://docs.pinecone.io/reference/api/2025-10/data-plane/list_imports)

## Capabilities

This operation supports [pagination](../README.md#pagination).
