# Describe Namespace with Pinecone

Retrieves details for a namespace from Pinecone.

## Endpoint

- **Method:** `GET`
- **Path:** `{indexHost}/namespaces/:namespace`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [Describe Namespace](https://docs.pinecone.io/reference/api/2025-10/data-plane/describenamespace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `namespace` | path | `string` | yes | The name of the namespace. |
