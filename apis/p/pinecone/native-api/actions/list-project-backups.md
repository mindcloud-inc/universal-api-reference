# List Project Backups with Pinecone

Retrieves backups for all indexes in Pinecone.

## Endpoint

- **Method:** `GET`
- **Path:** `/backups`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [List Project Backups](https://docs.pinecone.io/reference/api/2025-10/control-plane/list_project_backups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
