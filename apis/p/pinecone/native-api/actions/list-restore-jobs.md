# List Restore Jobs with Pinecone

Retrieves restore jobs for Pinecone backups.

## Endpoint

- **Method:** `GET`
- **Path:** `/restore-jobs`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [List Restore Jobs](https://docs.pinecone.io/reference/api/2025-10/control-plane/list_restore_jobs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
