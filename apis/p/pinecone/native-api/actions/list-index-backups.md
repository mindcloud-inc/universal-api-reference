# List Index Backups with Pinecone

Retrieves backups for a Pinecone index.

## Endpoint

- **Method:** `GET`
- **Path:** `/indexes/:index_name/backups`
- **Base URL:** `https://api.pinecone.io`
- **Official documentation:** [List Index Backups](https://docs.pinecone.io/reference/api/2025-10/control-plane/list_index_backups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
