# Get Bucket with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/bucket`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Bucket](https://api.pilvio.com/#get-bucket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of the bucket to retrieve. |
