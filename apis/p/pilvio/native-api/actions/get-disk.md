# Get Disk with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/disks/{disk_uuid}`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Disk](https://api.pilvio.com/#get-disk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disk_uuid` | path | `string` | yes | UUID of the disk to retrieve. |
