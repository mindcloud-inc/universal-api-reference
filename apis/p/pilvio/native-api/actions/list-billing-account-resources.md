# List Billing Account Resources with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/user-resource/billing_resources`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [List Billing Account Resources](https://api.pilvio.com/#list-billing-account-39-s-resources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Billing account ID whose resources should be listed. |
