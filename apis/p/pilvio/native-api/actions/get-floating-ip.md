# Get Floating IP with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/network/ip_addresses/{public_ipv4_address}`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Floating IP](https://api.pilvio.com/#get-floating-ip)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `public_ipv4_address` | path | `string` | yes | Public IPv4 address to retrieve. |
