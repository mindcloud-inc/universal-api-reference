# Get Network Data with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/network/network/{network_uuid}`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Network Data](https://api.pilvio.com/#get-network-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `network_uuid` | path | `string` | yes | UUID of the private network to retrieve. |
