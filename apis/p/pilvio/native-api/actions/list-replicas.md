# List Replicas with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/user-resource/vm/replica`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [List Replicas](https://api.pilvio.com/#list-replicas)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | query | `string` | yes | UUID of the VM whose replicas should be listed. |
