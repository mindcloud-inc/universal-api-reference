# Get Billing Account Details with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/billing_account`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Billing Account Details](https://api.pilvio.com/#billing-account-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `billing_account_id` | query | `string` | yes | Billing account ID to retrieve. |
