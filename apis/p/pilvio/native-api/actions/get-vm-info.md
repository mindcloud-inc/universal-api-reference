# Get VM Info with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/user-resource/vm`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get VM Info](https://api.pilvio.com/#get-vm-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | query | `string` | yes | UUID of the VM to retrieve. |
