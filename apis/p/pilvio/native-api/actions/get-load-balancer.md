# Get Load Balancer with Pilvio

## Endpoint

- **Method:** `GET`
- **Path:** `/network/load_balancers/{load_balancer_uuid}`
- **Base URL:** `https://api.pilvio.com/v1`
- **Official documentation:** [Get Load Balancer](https://api.pilvio.com/#get-user-load-balancer-by-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `load_balancer_uuid` | path | `string` | yes | UUID of the load balancer to retrieve. |
