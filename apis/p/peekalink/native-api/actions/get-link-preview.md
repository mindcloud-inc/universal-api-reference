# Get a Link Preview with Peekalink

Retrieves a link preview from Peekalink.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.peekalink.io`
- **Official documentation:** [Get a Link Preview](https://docs.peekalink.io/api-reference/link-preview/get-a-link-preview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link` | body | `string` | yes | The URL to preview. |
