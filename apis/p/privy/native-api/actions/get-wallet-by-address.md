# Get Wallet By Address with Privy

Finds a wallet in Privy by address.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/wallets/address`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get Wallet By Address](https://api.privy.io/v1/openapi.json#/paths/~1v1~1wallets~1address/post)
