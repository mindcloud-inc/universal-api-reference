# Create Wallets In Batch with Privy

Creates multiple new wallets in Privy.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/wallets/batch`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Create Wallets In Batch](https://api.privy.io/v1/openapi.json#/paths/~1v1~1wallets~1batch/post)
