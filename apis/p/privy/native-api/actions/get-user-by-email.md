# Get User By Email with Privy

Finds a user in Privy by email address.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/email/address`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get User By Email](https://api.privy.io/v1/openapi.json#/paths/~1v1~1users~1email~1address/post)
