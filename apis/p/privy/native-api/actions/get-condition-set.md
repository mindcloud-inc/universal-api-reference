# Get Condition Set with Privy

Retrieves a condition set from Privy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/condition_sets/{{conditionSetId}}`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get Condition Set](https://api.privy.io/v1/openapi.json#/paths/~1v1~1condition_sets~1{condition_set_id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `condition_set_id` | path | `string` | yes | Privy condition set ID. |
