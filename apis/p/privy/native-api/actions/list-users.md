# List Users with Privy

Retrieves a list of users from Privy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [List Users](https://docs.privy.io/api-reference/users/get-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
