# Get User By Phone Number with Privy

Finds a user in Privy by phone number.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/phone/number`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get User By Phone Number](https://api.privy.io/v1/openapi.json#/paths/~1v1~1users~1phone~1number/post)
