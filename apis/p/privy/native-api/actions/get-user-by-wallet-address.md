# Get User By Wallet Address with Privy

Finds a user in Privy by wallet address.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/wallet/address`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get User By Wallet Address](https://api.privy.io/v1/openapi.json#/paths/~1v1~1users~1wallet~1address/post)
