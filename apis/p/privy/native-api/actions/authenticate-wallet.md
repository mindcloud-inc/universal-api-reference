# Authenticate Wallet with Privy

Authenticates a wallet session in Privy.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/wallets/authenticate`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Authenticate Wallet](https://api.privy.io/v1/openapi.json#/paths/~1v1~1wallets~1authenticate/post)
