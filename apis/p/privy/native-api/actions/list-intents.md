# List Intents with Privy

Retrieves a list of intents from Privy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/intents`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [List Intents](https://api.privy.io/v1/openapi.json#/paths/~1v1~1intents/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
