# Get User By Custom Auth ID with Privy

Finds a user in Privy by custom auth ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/custom_auth/id`
- **Base URL:** `https://api.privy.io`
- **Official documentation:** [Get User By Custom Auth ID](https://api.privy.io/v1/openapi.json#/paths/~1v1~1users~1custom_auth~1id/post)
