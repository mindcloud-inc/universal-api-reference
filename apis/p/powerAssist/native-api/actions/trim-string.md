# Trim String with Power Assist

Trims a string with Power Assist.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/string/trim`
- **Base URL:** `https://power-assist.p.rapidapi.com`
- **Official documentation:** [Trim String](https://rapidapi.com/elevate-digital-elevate-digital-default/api/power-assist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `string` | body | `string` | yes | The string to trim. |
| `characters` | body | `string` | no | Optional characters to remove from the start and end instead of whitespace. |
