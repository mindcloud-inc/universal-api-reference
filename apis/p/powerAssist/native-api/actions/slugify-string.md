# Slugify String with Power Assist

Converts a string into a slug with Power Assist.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/string/slugify`
- **Base URL:** `https://power-assist.p.rapidapi.com`
- **Official documentation:** [Slugify String](https://rapidapi.com/elevate-digital-elevate-digital-default/api/power-assist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `string` | body | `string` | yes | The text to transform into a URL-safe slug. |
