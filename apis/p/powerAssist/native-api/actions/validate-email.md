# Validate Email with Power Assist

Validates an email address with Power Assist.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/validate/email`
- **Base URL:** `https://power-assist.p.rapidapi.com`
- **Official documentation:** [Validate Email](https://rapidapi.com/elevate-digital-elevate-digital-default/api/power-assist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The email address to validate. |
