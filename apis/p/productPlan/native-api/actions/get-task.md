# Get Task with ProductPlan

Retrieves a task from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/launches/:launch_id/tasks/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Task](https://productplan.readme.io/reference/get_api-v2-launches-launch-id-tasks-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `launch_id` | path | `string` | yes |
