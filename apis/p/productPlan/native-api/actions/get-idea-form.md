# Get Idea Form with ProductPlan

Retrieves an idea form from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/idea_forms/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Idea Form](https://productplan.readme.io/reference/get_api-v2-discovery-idea-forms-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
