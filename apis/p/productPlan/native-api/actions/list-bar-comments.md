# List Bar Comments with ProductPlan

Lists comments for a bar in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/bars/:id/comments`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Bar Comments](https://productplan.readme.io/reference/get_api-v2-bars-id-comments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
