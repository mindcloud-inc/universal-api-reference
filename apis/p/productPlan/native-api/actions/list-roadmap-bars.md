# List Roadmap Bars with ProductPlan

Lists bars for a roadmap in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:id/bars`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Roadmap Bars](https://productplan.readme.io/reference/get_api-v2-roadmaps-id-bars)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
