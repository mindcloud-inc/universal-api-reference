# List Child Bars with ProductPlan

Lists child bars for a bar in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/bars/:id/child_bars`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Child Bars](https://productplan.readme.io/reference/get_api-v2-bars-id-child-bars)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
