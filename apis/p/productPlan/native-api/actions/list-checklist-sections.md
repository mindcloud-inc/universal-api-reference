# List Checklist Sections with ProductPlan

Lists checklist sections for a launch in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/launches/:launch_id/checklist_sections`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Checklist Sections](https://productplan.readme.io/reference/get_api-v2-launches-launch-id-checklist-sections)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `launch_id` | path | `string` | yes |
