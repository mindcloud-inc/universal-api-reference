# List Tasks with ProductPlan

Lists tasks for a launch in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/launches/:launch_id/tasks`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Tasks](https://productplan.readme.io/reference/get_api-v2-launches-launch-id-tasks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `launch_id` | path | `string` | yes |
