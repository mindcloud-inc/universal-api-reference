# List Opportunities with ProductPlan

Lists all opportunities accessible in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/opportunities`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Opportunities](https://productplan.readme.io/reference/get_api-v2-discovery-opportunities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number for paginated results. |
| `per_page` | query | `number` | no | Maximum number of records to return per page. |
