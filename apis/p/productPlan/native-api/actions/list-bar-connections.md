# List Bar Connections with ProductPlan

Lists connections for a bar in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/bars/:bar_id/connections`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Bar Connections](https://productplan.readme.io/reference/get_api-v2-bars-bar-id-connections)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bar_id` | path | `string` | yes |
