# Get Bar with ProductPlan

Retrieves a bar from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/bars/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Bar](https://productplan.readme.io/reference/get_api-v2-bars-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
