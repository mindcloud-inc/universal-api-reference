# Get Launch with ProductPlan

Retrieves a launch from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/launches/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Launch](https://productplan.readme.io/reference/get_api-v2-launches-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
