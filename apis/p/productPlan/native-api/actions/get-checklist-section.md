# Get Checklist Section with ProductPlan

Retrieves a checklist section from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/launches/:launch_id/checklist_sections/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Checklist Section](https://productplan.readme.io/reference/get_api-v2-launches-launch-id-checklist-sections-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `launch_id` | path | `string` | yes |
