# Get Opportunity with ProductPlan

Retrieves an opportunity from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/opportunities/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Opportunity](https://productplan.readme.io/reference/get_api-v2-discovery-opportunities-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
