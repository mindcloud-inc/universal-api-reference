# Get Key Result with ProductPlan

Retrieves a key result from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/strategy/objectives/:objective_id/key_results/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Key Result](https://productplan.readme.io/reference/get_api-v2-strategy-objectives-objective-id-key-results-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `objective_id` | path | `string` | yes |
