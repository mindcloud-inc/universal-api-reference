# List Roadmap Lanes with ProductPlan

Lists lanes for a roadmap in ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:roadmap_id/lanes`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [List Roadmap Lanes](https://productplan.readme.io/reference/get_api-v2-roadmaps-roadmap-id-lanes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `roadmap_id` | path | `string` | yes |
