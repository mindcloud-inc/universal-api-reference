# Get Objective with ProductPlan

Retrieves an objective from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/strategy/objectives/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Objective](https://productplan.readme.io/reference/get_api-v2-strategy-objectives-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
