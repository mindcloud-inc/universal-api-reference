# Get Roadmap with ProductPlan

Retrieves a roadmap from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Roadmap](https://productplan.readme.io/reference/get_api-v2-roadmaps-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
