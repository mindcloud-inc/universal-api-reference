# Get Idea with ProductPlan

Retrieves an idea from ProductPlan.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/ideas/:id`
- **Base URL:** `https://app.productplan.com/api/v2`
- **Official documentation:** [Get Idea](https://productplan.readme.io/reference/get_api-v2-discovery-ideas-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
