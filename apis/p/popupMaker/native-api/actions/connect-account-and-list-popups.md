# Connect Account and List Popups with Popup Maker

Retrieves connected account details and popups from Popup Maker.

## Endpoint

- **Method:** `POST`
- **Path:** `app/connect`
- **Base URL:** `https://popupmaker.com/`
- **Official documentation:** [Connect Account and List Popups](https://help.popupmaker.com/en/article/how-to-use-the-popup-maker-plugin-in-wordpress-gnf4a7/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
