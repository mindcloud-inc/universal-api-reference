# Get Contact Info by LinkedIn ID with PeopleDB

Retrieves contact info from PeopleDB by LinkedIn ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://peopledb.co/api/v1`
- **Official documentation:** [Get Contact Info by LinkedIn ID](https://docs.peopledb.co/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedin_id` | query | `number` | yes | LinkedIn numeric ID to search by. |
