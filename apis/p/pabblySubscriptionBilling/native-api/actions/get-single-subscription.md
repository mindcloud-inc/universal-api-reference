# Get Single Subscription with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscription/:subscriptionId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Get Single Subscription](https://apidocs.pabbly.com/#98302eb8-a3ff-4cd2-99ea-8c77fd27dbe7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | no | Pabbly Subscription ID. |
