# Get Single Customer via Customer ID with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customer/:customerId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Get Single Customer via Customer ID](https://apidocs.pabbly.com/#4ac6de74-d5dc-4ea6-89eb-b00fd52a05b8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Pabbly customer ID. |
