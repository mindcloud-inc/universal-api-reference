# List All Payment Methods By Customer Id with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/paymentmethods/:customerId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [List All Payment Methods By Customer Id](https://apidocs.pabbly.com/#771ac2ca-ad84-4eb8-9fae-9a493d53a44c)

## Capabilities

This operation supports [pagination](../README.md#pagination).

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | no |
