# Get License Codes with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:productId/licenses/:licenseId/codes`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Get License Codes](https://apidocs.pabbly.com/#49bd15f3-baf4-4e4f-8590-1ef0d4f0d3e2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
