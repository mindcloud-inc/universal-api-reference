# Create Metered Invoice with Pabbly Subscription Billing

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/create-metered/:subscriptionId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Create Metered Invoice](https://apidocs.pabbly.com/#bbd62eae-1f32-4e94-8284-7c4e005de6dd)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | no |
