# List All Invoices with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoices`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [List All Invoices](https://apidocs.pabbly.com/#30ee5ad3-c165-4bb9-a60f-88eadff66acd)
