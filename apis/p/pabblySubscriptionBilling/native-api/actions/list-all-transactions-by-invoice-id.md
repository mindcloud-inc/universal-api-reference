# List All Transactions By Invoice Id with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoices/transactions/:invoiceId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [List All Transactions By Invoice Id](https://apidocs.pabbly.com/#a80c6515-92a8-44bd-8b25-8bcce09cce99)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice_id` | path | `string` | no |
