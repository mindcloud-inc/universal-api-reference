# Get Scheduled Subscription with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scheduledchanges/:subscriptionId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Get Scheduled Subscription](https://apidocs.pabbly.com/#b63826e4-4328-457b-b450-c5b7cb53d43d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `suscription_id` | path | `string` | no | Pabbly Subscription ID. |
