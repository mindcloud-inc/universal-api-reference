# List All Coupons By Product with Pabbly Subscription Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/coupon/:productId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [List All Coupons By Product](https://apidocs.pabbly.com/#c5c5010c-104b-4c7c-bbad-7da44f37c787)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | no |
