# Update Product with Pabbly Subscription Billing

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/product/update/:productId`
- **Base URL:** `https://payments.pabbly.com/api`
- **Official documentation:** [Update Product](https://apidocs.pabbly.com/#a422de7b-b4db-44f3-ae53-ef05414cbacb)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | no |
| `product_name` | body | `string` | no |
