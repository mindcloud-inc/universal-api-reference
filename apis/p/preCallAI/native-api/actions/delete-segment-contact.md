# Delete Segment Contact with PreCallAI

Deletes an existing segment contact from PreCallAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segment/contact/delete`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Delete Segment Contact](https://docs.precallai.com/api-reference/segments/deleteAudience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
