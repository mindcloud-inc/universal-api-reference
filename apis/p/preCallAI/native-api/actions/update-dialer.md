# Update Dialer with PreCallAI

Updates an existing dialer in PreCallAI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/dialer/update`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Update Dialer](https://docs.precallai.com/api-reference/dialers/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The dialer ID. |
