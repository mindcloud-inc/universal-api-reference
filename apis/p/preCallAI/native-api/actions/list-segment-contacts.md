# List Segment Contacts with PreCallAI

Retrieves segment contacts from PreCallAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/segment/contact/list`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [List Segment Contacts](https://docs.precallai.com/api-reference/segments/audienceList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
