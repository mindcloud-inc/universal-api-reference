# Create Segment Contact with PreCallAI

Creates a new segment contact in PreCallAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/segment/contact/create`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Create Segment Contact](https://docs.precallai.com/api-reference/segments/createAudience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
