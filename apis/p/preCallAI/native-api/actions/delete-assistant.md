# Delete Assistant with PreCallAI

Deletes an existing assistant from PreCallAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/deleteassistant`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Delete Assistant](https://docs.precallai.com/api-reference/assistants/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The assistant ID. |
