# List Campaign Contacts with PreCallAI

Retrieves campaign contacts from PreCallAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign/audiences`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [List Campaign Contacts](https://docs.precallai.com/api-reference/campaigns/audienceList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The campaign ID. |
