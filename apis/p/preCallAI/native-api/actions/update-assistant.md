# Update Assistant with PreCallAI

Updates an existing assistant in PreCallAI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/user/updateAssistant`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Update Assistant](https://docs.precallai.com/api-reference/assistants/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The assistant ID. |
