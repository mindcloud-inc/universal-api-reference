# Update Segment with PreCallAI

Updates an existing segment in PreCallAI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/segment/update`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Update Segment](https://docs.precallai.com/api-reference/segments/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
