# Delete Dialer with PreCallAI

Deletes an existing dialer from PreCallAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dialer/delete`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Delete Dialer](https://docs.precallai.com/api-reference/dialers/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The dialer ID. |
