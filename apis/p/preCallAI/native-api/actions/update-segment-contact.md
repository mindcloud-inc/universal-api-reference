# Update Segment Contact with PreCallAI

Updates an existing segment contact in PreCallAI.

## Endpoint

- **Method:** `PUT`
- **Path:** `/segment/contact/update`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Update Segment Contact](https://docs.precallai.com/api-reference/segments/updateAudience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
