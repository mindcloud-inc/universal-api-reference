# Bulk Upload Segment Contacts with PreCallAI

Bulk uploads segment contacts in PreCallAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/segment/contact/bulk-upload`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Bulk Upload Segment Contacts](https://docs.precallai.com/api-reference/segments/bulkUpload)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
