# Delete Segment with PreCallAI

Deletes an existing segment from PreCallAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segment/delete`
- **Base URL:** `https://api.precallai.com/api/v1`
- **Official documentation:** [Delete Segment](https://docs.precallai.com/api-reference/segments/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The segment ID. |
