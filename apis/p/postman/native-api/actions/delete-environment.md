# Delete Environment with Postman

Deletes an existing environment from Postman.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/environments/:environmentId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Delete Environment](https://www.postman.com/postman/postman-public-workspace/request/99bqfuh/delete-an-environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environmentId` | path | `string` | yes | The environment's ID. |
