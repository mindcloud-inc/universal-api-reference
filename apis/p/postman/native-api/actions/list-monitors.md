# List Monitors with Postman

Retrieves all available monitors from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/monitors`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [List Monitors](https://www.postman.com/postman/postman-public-workspace/request/fahs921/get-all-monitors)
