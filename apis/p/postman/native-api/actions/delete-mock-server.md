# Delete Mock Server with Postman

Deletes an existing mock server from Postman.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mocks/:mockId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Delete Mock Server](https://www.postman.com/postman/postman-public-workspace/request/qobpu42/delete-a-mock-server)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mockId` | path | `string` | yes | The mock server's ID. |
