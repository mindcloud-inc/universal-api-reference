# List Workspaces with Postman

Retrieves all accessible workspaces from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [List Workspaces](https://www.postman.com/postman/postman-public-workspace/request/mes2rzs/get-all-workspaces)
