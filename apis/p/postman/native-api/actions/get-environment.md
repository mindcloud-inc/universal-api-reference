# Get Environment with Postman

Retrieves details for an environment from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments/:environmentId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Get Environment](https://www.postman.com/postman/postman-public-workspace/request/rdrxdqi/get-an-environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environmentId` | path | `string` | yes | The environment's ID. |
