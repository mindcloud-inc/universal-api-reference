# Get Authenticated User with Postman

Retrieves authenticated user details and usage limits from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Get Authenticated User](https://www.postman.com/postman/postman-public-workspace/request/ay0ymqy/get-authenticated-user)
