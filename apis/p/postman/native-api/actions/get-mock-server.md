# Get Mock Server with Postman

Retrieves details for a mock server from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/mocks/:mockId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Get Mock Server](https://www.postman.com/postman/postman-public-workspace/request/nzbzzq9/get-a-mock-server)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mockId` | path | `string` | yes | The mock server's ID. |
