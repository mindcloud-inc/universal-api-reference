# Delete Monitor with Postman

Deletes an existing monitor from Postman.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/monitors/:monitorId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Delete Monitor](https://www.postman.com/postman/postman-public-workspace/request/mg98tih/delete-a-monitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `monitorId` | path | `string` | yes | The monitor's ID. |
