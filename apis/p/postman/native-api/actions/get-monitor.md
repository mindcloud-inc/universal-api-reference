# Get Monitor with Postman

Retrieves details for a monitor from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/monitors/:monitorId`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Get Monitor](https://www.postman.com/postman/postman-public-workspace/request/7izaj6c/get-a-monitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `monitorId` | path | `string` | yes | The monitor's ID. |
