# List Environments with Postman

Retrieves all accessible environments from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [List Environments](https://www.postman.com/postman/postman-public-workspace/request/bqbz8iw/get-all-environments)
