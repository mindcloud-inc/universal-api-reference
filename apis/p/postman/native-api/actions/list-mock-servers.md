# List Mock Servers with Postman

Retrieves all mock servers from Postman.

## Endpoint

- **Method:** `GET`
- **Path:** `/mocks`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [List Mock Servers](https://www.postman.com/postman/postman-public-workspace/request/6v89u2r/get-all-mock-servers)
