# Publish Mock Server with Postman

Sets a mock server to public in Postman.

## Endpoint

- **Method:** `POST`
- **Path:** `/mocks/:mockId/publish`
- **Base URL:** `https://api.getpostman.com`
- **Official documentation:** [Publish Mock Server](https://www.postman.com/postman/postman-public-workspace/request/7mglglo/publish-a-mock-server)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mockId` | path | `string` | yes | The mock server's ID. |
