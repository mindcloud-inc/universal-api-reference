# Delete Secret with Particle

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/secrets/:secretName`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Delete Secret](https://docs.particle.io/reference/cloud-apis/api/#delete-a-cloud-secret)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `secretName` | path | `string` | yes |
