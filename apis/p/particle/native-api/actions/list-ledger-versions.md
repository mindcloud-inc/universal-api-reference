# List Ledger Versions with Particle

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ledgers/:ledgerName/instances/:scopeValue/versions`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [List Ledger Versions](https://docs.particle.io/reference/cloud-apis/api/#list-ledger-instance-versions)
