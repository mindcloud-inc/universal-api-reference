# Ping Device with Particle

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/devices/:deviceId/ping`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Ping Device](https://docs.particle.io/reference/cloud-apis/api/#ping-a-device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
