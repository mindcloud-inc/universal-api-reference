# Update Ledger with Particle

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/ledgers/:ledgerName`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Update Ledger](https://docs.particle.io/reference/cloud-apis/api/#update-ledger-definition)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ledger` | body | `object` | yes |
| `ledgerName` | path | `string` | yes |
