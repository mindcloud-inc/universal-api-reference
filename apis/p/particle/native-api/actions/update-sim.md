# Update SIM with Particle

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/sims/:iccid`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Update SIM](https://docs.particle.io/reference/cloud-apis/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `action` | body | `string` | yes |
| `iccid` | path | `string` | yes |
