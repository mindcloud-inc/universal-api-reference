# Get Ledger Version with Particle

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ledgers/:ledgerName/instances/:scopeValue/versions/:version`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Get Ledger Version](https://docs.particle.io/reference/cloud-apis/api/#get-ledger-instance-version)
