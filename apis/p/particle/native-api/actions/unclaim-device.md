# Unclaim Device with Particle

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/devices/:deviceId`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Unclaim Device](https://docs.particle.io/reference/cloud-apis/api/#unclaim-device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
