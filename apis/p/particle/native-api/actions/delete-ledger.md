# Delete Ledger with Particle

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/ledgers/:ledgerName`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Delete Ledger](https://docs.particle.io/reference/cloud-apis/api/#archive-a-ledger-definition)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ledgerName` | path | `string` | yes |
