# Delete Ledger Instance with Particle

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/ledgers/:ledgerName/instances/:scopeValue`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Delete Ledger Instance](https://docs.particle.io/reference/cloud-apis/api/#delete-ledger-instance)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ledgerName` | path | `string` | yes |
| `scopeValue` | path | `string` | yes |
