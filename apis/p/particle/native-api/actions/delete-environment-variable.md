# Delete Environment Variable with Particle

- **Method:** `DELETE`
- **Path:** `/v1/env/:key`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Delete Environment Variable](https://docs.particle.io/reference/cloud-apis/api/#delete-environment-variable)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
