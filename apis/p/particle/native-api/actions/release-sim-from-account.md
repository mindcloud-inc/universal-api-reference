# Release SIM from Account with Particle

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/sims/:iccid`
- **Base URL:** `https://api.particle.io`
- **Official documentation:** [Release SIM from Account](https://docs.particle.io/reference/cloud-apis/api/#release-sim-from-account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `iccid` | path | `string` | yes |
