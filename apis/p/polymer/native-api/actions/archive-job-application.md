# Archive Job Application with Polymer

Archives a job application in Polymer.

## Endpoint

- **Method:** `POST`
- **Path:** `/job_applications/:job_application_id/archive`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Archive Job Application](https://developer.polymer.co/#archive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
