# Get Hiring Stages with Polymer

Retrieves hiring stages for a job in Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/hiring_stages`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Hiring Stages](https://developer.polymer.co/#get-hiring-stages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | no | Numeric Polymer job ID. |
