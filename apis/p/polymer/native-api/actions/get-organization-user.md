# Get Organization User with Polymer

Retrieves an organization user from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization_users/:organization_user_id`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Organization User](https://developer.polymer.co/#get-an-organization-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_user_id` | path | `number` | yes | Numeric Polymer organization user ID. |
