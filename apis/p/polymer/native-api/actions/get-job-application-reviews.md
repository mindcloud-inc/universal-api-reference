# Get Job Application Reviews with Polymer

Retrieves reviews for a job application in Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications/:job_application_id/reviews`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Job Application Reviews](https://developer.polymer.co/#get-job-application-reviews)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
