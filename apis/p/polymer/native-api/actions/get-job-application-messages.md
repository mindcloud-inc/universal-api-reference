# Get Job Application Messages with Polymer

Retrieves messages for a job application in Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications/:job_application_id/messages`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Job Application Messages](https://developer.polymer.co/#get-job-application-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
