# List Active Users with Polymer

Retrieves active organization users from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization_users/active`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [List Active Users](https://developer.polymer.co/#list-active-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
