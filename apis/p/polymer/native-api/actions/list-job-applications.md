# List Job Applications with Polymer

Retrieves job applications from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [List Job Applications](https://developer.polymer.co/#list-job-applications)

## Capabilities

This operation supports [pagination](../README.md#pagination).
