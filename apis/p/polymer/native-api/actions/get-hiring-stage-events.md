# Get Hiring Stage Events with Polymer

Retrieves hiring stage events for a job application in Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications/:job_application_id/hiring_stage_events`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Hiring Stage Events](https://developer.polymer.co/#get-hiring-stage-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
