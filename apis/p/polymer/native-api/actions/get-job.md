# Get Job with Polymer

Retrieves a job from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Job](https://developer.polymer.co/#get-a-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | no | Numeric Polymer job ID. |
