# List Deactivated Users with Polymer

Retrieves deactivated organization users from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization_users/deactivated`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [List Deactivated Users](https://developer.polymer.co/#list-deactivated-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
