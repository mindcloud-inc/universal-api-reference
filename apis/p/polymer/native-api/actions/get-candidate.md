# Get Candidate with Polymer

Retrieves a candidate from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/:candidate_id`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Candidate](https://developer.polymer.co/#get-a-candidate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `candidate_id` | path | `string` | no | Numeric Polymer candidate ID. |
