# Get Job Application Comments with Polymer

Retrieves comments for a job application in Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications/:job_application_id/comments`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Job Application Comments](https://developer.polymer.co/#get-job-application-comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
