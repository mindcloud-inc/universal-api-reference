# Get Job Application with Polymer

Retrieves a job application from Polymer.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_applications/:job_application_id`
- **Base URL:** `https://api.polymer.co/v1/hire`
- **Official documentation:** [Get Job Application](https://developer.polymer.co/#get-a-job-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_application_id` | path | `string` | no | Numeric Polymer job application ID. |
