# Toggle Campaign with Proofly

Toggles a campaign between active and inactive in Proofly.

## Endpoint

- **Method:** `PUT`
- **Path:** `/campaign/:campaignId`
- **Base URL:** `https://proofly.io/api`
- **Official documentation:** [Toggle Campaign](https://proofly.io/developers#api-method-campaign-toggle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The campaign ID from List Campaigns. |
