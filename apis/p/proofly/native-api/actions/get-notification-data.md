# Get Notification Data with Proofly

Retrieves notification data from your Proofly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/:notificationId`
- **Base URL:** `https://proofly.io/api`
- **Official documentation:** [Get Notification Data](https://proofly.io/developers#api-method-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification_id` | path | `string` | yes | The notification ID from Get Campaign. |
