# Get Campaign with Proofly

Retrieves a campaign from your Proofly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:campaignId`
- **Base URL:** `https://proofly.io/api`
- **Official documentation:** [Get Campaign](https://proofly.io/developers#api-method-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The campaign ID from List Campaigns. |
