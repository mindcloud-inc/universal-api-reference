# Get Design with Payrexx

Retrieves a design from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `Design/:uuid/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Get Design](https://developers.payrexx.com/reference/retrieve-a-design)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Design UUID. |
