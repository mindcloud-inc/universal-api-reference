# Delete Paylink with Payrexx

Deletes a paylink from Payrexx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Invoice/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Delete Paylink](https://developers.payrexx.com/reference/remove-a-paylink)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paylink id. |
