# Get Gateway with Payrexx

Retrieves a gateway from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `Gateway/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Get Gateway](https://developers.payrexx.com/reference/retrieve-a-gateway)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of gateway payment to retrieve. |
