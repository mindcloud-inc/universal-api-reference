# Helper Create Design with Payrexx

Creates a design in Payrexx.

## Endpoint

- **Method:** `POST`
- **Path:** `Design/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Helper Create Design](https://developers.payrexx.com/reference/create-a-design)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
