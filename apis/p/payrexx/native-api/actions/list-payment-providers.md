# List Payment Providers with Payrexx

Retrieves payment providers from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `PaymentProvider/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [List Payment Providers](https://developers.payrexx.com/reference/retrieve-all-payment-providers)
