# Delete Gateway with Payrexx

Deletes a gateway from Payrexx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Gateway/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Delete Gateway](https://developers.payrexx.com/reference/delete-a-gateway)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of gateway payment to delete. |
