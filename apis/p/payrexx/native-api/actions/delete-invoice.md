# Delete Invoice with Payrexx

Deletes an invoice from Payrexx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Bill/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Delete Invoice](https://developers.payrexx.com/reference/delete-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice id. |
