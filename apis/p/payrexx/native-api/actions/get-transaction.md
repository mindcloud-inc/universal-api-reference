# Get Transaction with Payrexx

Retrieves a transaction from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `Transaction/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Get Transaction](https://developers.payrexx.com/reference/retrieve-a-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of transaction to retrieve. |
