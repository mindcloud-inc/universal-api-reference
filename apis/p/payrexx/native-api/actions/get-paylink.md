# Get Paylink with Payrexx

Retrieves a paylink from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `Invoice/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Get Paylink](https://developers.payrexx.com/reference/retrieve-a-paylink)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paylink id. |
