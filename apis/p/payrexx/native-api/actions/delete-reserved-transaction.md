# Delete Reserved Transaction with Payrexx

Deletes a reserved transaction from Payrexx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Transaction/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Delete Reserved Transaction](https://developers.payrexx.com/reference/delete-a-reserved-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of reserved transaction to cancel/delete. |
