# Get Invoice with Payrexx

Retrieves an invoice from Payrexx.

## Endpoint

- **Method:** `GET`
- **Path:** `Bill/:id/`
- **Base URL:** `https://api.payrexx.com/v1.14/`
- **Official documentation:** [Get Invoice](https://developers.payrexx.com/reference/retrieve-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice id. |
