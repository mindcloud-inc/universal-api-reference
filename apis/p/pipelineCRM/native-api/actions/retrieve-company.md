# Retrieve Company with Pipeline CRM

Retrieves a company from Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Retrieve Company](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Company ID |
