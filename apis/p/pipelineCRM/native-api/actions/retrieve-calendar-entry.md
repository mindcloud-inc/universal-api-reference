# Retrieve Calendar Entry with Pipeline CRM

Retrieves a calendar entry from Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar_entries/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Retrieve Calendar Entry](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Calendar entry ID |
