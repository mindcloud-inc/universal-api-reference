# List Deals with Pipeline CRM

Finds deals in Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [List Deals](https://app.pipelinecrm.com/openapi.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
