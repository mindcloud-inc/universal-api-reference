# List Companies with Pipeline CRM

Finds companies in Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [List Companies](https://app.pipelinecrm.com/openapi.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
