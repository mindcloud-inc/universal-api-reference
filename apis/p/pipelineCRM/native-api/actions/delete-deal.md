# Delete Deal with Pipeline CRM

Deletes an existing deal from Pipeline CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deals/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Delete Deal](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Deal ID |
