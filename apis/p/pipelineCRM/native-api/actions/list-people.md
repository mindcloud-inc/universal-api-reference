# List People with Pipeline CRM

Finds people in Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [List People](https://app.pipelinecrm.com/openapi.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
