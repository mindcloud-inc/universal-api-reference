# Retrieve Person with Pipeline CRM

Retrieves a person from Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Retrieve Person](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Person ID |
