# Delete Calendar Entry with Pipeline CRM

Deletes an existing calendar entry from Pipeline CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendar_entries/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Delete Calendar Entry](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Calendar entry ID |
