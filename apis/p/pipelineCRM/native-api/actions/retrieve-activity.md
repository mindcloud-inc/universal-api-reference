# Retrieve Activity with Pipeline CRM

Retrieves an activity note from Pipeline CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Retrieve Activity](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Activity ID |
