# Delete Person with Pipeline CRM

Deletes an existing person from Pipeline CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/:id`
- **Base URL:** `https://api.pipelinecrm.com/api/v3`
- **Official documentation:** [Delete Person](https://app.pipelinecrm.com/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Person ID |
