# List Coupon Campaigns with PassKit Coupons

## Endpoint

- **Method:** `POST`
- **Path:** `/coupon/singleUse/campaigns/list`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [List Coupon Campaigns](https://docs.passkit.io/protocols/coupon/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
