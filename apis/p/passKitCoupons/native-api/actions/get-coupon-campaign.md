# Get Coupon Campaign with PassKit Coupons

## Endpoint

- **Method:** `GET`
- **Path:** `/coupon/singleUse/campaign/:id`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Get Coupon Campaign](https://docs.passkit.io/protocols/coupon/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Coupon campaign ID. |
