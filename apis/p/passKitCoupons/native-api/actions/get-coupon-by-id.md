# Get Coupon by ID with PassKit Coupons

## Endpoint

- **Method:** `GET`
- **Path:** `/coupon/singleUse/coupon/:id`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Get Coupon by ID](https://docs.passkit.io/protocols/coupon/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | PassKit coupon ID. |
