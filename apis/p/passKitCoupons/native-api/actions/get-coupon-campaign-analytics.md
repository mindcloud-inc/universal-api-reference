# Get Coupon Campaign Analytics with PassKit Coupons

## Endpoint

- **Method:** `GET`
- **Path:** `/coupon/singleUse/campaign/:classId/analytics`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Get Coupon Campaign Analytics](https://docs.passkit.io/protocols/coupon/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `classId` | path | `string` | yes | Coupon campaign ID. |
