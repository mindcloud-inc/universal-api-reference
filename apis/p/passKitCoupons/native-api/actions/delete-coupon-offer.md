# Delete Coupon Offer with PassKit Coupons

## Endpoint

- **Method:** `DELETE`
- **Path:** `/coupon/singleUse/offer/:id`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [Delete Coupon Offer](https://docs.passkit.io/protocols/coupon/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Coupon offer ID. |
