# PDF to JSON with AI with PDF.co

Converts a PDF to JSON with AI in PDF.co.

## Endpoint

- **Method:** `POST`
- **Path:** `/pdf/convert/to/json-meta`
- **Base URL:** `https://api.pdf.co/v1`
- **Official documentation:** [PDF to JSON with AI](https://docs.pdf.co/api-reference/pdf-to-json/with-ai)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of PDF/image document to convert to JSON with AI. |
