# Classify Document with PDF.co

Classifies a document in PDF.co.

## Endpoint

- **Method:** `POST`
- **Path:** `/pdf/classifier`
- **Base URL:** `https://api.pdf.co/v1`
- **Official documentation:** [Classify Document](https://docs.pdf.co/api-tester/document-classifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of PDF/image document to classify. |
