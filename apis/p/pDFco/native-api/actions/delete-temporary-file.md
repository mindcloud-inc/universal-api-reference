# Delete Temporary File with PDF.co

Deletes a temporary file from PDF.co.

## Endpoint

- **Method:** `POST`
- **Path:** `/file/delete`
- **Base URL:** `https://api.pdf.co/v1`
- **Official documentation:** [Delete Temporary File](https://docs.pdf.co/api-reference/file-upload/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | The temporary PDF.co file URL to delete. |
