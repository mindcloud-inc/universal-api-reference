# Watermark PDF with PDF API Hub

## Endpoint

- **Method:** `POST`
- **Path:** `/watermark`
- **Base URL:** `https://api.prefillpdf.com`
- **Official documentation:** [Watermark PDF](https://api.prefillpdf.com/docs#/PDF%20Tools/watermark_endpoint_watermark_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_url` | body | `string` | yes | Public or signed PDF URL to download |
