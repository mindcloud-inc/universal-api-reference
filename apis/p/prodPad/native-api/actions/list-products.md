# List Products with ProdPad

Retrieves products from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [List Products](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Products/GetProducts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `boolean` | no |
