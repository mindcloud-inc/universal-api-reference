# Get Idea with ProdPad

Retrieves an idea from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/ideas/:id`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [Get Idea](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Ideas/GetIdeaByID)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
