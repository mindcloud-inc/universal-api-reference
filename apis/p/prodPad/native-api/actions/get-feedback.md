# Get Feedback with ProdPad

Retrieves feedback from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedbacks/:id`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [Get Feedback](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Feedback/GetFeedback)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
