# Get Product with ProdPad

Retrieves a product from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [Get Product](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Products/GetProduct)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
