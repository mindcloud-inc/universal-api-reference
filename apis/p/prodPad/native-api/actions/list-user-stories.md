# List User Stories with ProdPad

Retrieves user stories from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/userstories`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [List User Stories](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Ideas/GetUserStories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `external_id` | query | `string` | no |
| `external_url` | query | `string` | no |
| `status` | query | `string` | no |
