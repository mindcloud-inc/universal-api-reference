# Get Objective with ProdPad

Retrieves an objective from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives/:id`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [Get Objective](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Products/GetObjective)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
