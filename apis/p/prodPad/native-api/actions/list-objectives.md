# List Objectives with ProdPad

Retrieves objectives from ProdPad.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [List Objectives](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Products/GetObjectives)
