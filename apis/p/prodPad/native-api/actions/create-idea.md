# Create Idea with ProdPad

Creates a new idea in ProdPad.

## Endpoint

- **Method:** `POST`
- **Path:** `/ideas`
- **Base URL:** `https://api.prodpad.com/v1`
- **Official documentation:** [Create Idea](https://app.swaggerhub.com/apis-docs/ProdPad/prodpad/1.1.4#/Ideas/PostIdeas)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | no |
| `description` | body | `string` | no |
| `state` | body | `string` | no |
