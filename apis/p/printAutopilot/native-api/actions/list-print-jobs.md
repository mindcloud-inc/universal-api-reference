# List Print Jobs with Print Autopilot

Retrieves print jobs from Print Autopilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/print-jobs`
- **Base URL:** `https://printautopilot.com/api`
- **Official documentation:** [List Print Jobs](https://documenter.getpostman.com/view/1334461/TW6wJonb#387ef982-0730-46fb-a826-340e86ce23a2)
