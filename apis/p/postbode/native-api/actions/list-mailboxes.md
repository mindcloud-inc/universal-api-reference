# List Mailboxes with Postbode

Retrieves available mailboxes from the Postbode API.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailbox`
- **Base URL:** `https://app.postbode.nu/api`
- **Official documentation:** [List Mailboxes](https://github.com/postbode/postbode-api#list-all-available-mailboxes)
