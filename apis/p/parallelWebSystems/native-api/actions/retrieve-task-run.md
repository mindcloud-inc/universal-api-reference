# Retrieve Task Run with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tasks/runs/:run_id`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Retrieve Task Run](https://docs.parallel.ai/api-reference/tasks-v1/retrieve-task-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Parallel task run ID. |
