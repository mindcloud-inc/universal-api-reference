# Retrieve FindAll Run Result with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/findall/runs/:findall_id/result`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Retrieve FindAll Run Result](https://docs.parallel.ai/api-reference/findall-api-beta/findall-run-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `findall_id` | path | `string` | yes | The Parallel FindAll run ID. |
