# Get FindAll Run Schema with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/findall/runs/:findall_id/schema`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Get FindAll Run Schema](https://docs.parallel.ai/api-reference/findall-api-beta/get-findall-run-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `findall_id` | path | `string` | yes | The Parallel FindAll run ID. |
