# Stream Task Run Events Beta with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/tasks/runs/:run_id/events`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Stream Task Run Events Beta](https://docs.parallel.ai/api-reference/tasks-v1/stream-task-run-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Parallel task run ID. |
