# Retrieve FindAll Run Status with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/findall/runs/:findall_id`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Retrieve FindAll Run Status](https://docs.parallel.ai/api-reference/findall-api-beta/retrieve-findall-run-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `findall_id` | path | `string` | yes | The Parallel FindAll run ID. |
