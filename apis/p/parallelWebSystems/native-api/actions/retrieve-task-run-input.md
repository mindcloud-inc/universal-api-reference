# Retrieve Task Run Input with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tasks/runs/:run_id/input`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Retrieve Task Run Input](https://docs.parallel.ai/api-reference/tasks-v1/retrieve-task-run-input)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Parallel task run ID. |
