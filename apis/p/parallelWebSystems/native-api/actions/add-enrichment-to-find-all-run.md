# Add Enrichment to FindAll Run with Parallel Web Systems

## Endpoint

- **Method:** `POST`
- **Path:** `/v1beta/findall/runs/:findall_id/enrich`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Add Enrichment to FindAll Run](https://docs.parallel.ai/api-reference/findall-api-beta/add-enrichment-to-findall-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `findall_id` | path | `string` | yes | The Parallel FindAll run ID. |
