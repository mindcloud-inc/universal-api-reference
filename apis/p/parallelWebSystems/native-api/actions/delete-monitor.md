# Delete Monitor with Parallel Web Systems

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1alpha/monitors/:monitor_id`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Delete Monitor](https://docs.parallel.ai/api-reference/monitor/delete-monitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `monitor_id` | path | `string` | yes | The Parallel monitor ID. |
