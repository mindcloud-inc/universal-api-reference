# Retrieve Task Group with Parallel Web Systems

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta/tasks/groups/:taskgroup_id`
- **Base URL:** `https://api.parallel.ai`
- **Official documentation:** [Retrieve Task Group](https://docs.parallel.ai/api-reference/task-groups-beta/retrieve-task-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskgroup_id` | path | `string` | yes | The Parallel task group ID. |
