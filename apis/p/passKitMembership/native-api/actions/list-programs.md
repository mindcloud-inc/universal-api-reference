# List Programs with PassKit Membership

Retrieves membership programs from PassKit Membership.

## Endpoint

- **Method:** `POST`
- **Path:** `/members/programs/list`
- **Base URL:** `https://api.pub2.passkit.io`
- **Official documentation:** [List Programs](https://help.passkit.com/en/articles/4133757-membership-protocol-filtering-listing-and-counting-by-api)
