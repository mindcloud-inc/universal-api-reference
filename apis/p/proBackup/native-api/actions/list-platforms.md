# List Platforms with ProBackup

Retrieves active backup platforms from ProBackup.

## Endpoint

- **Method:** `GET`
- **Path:** `/backups/v1/platforms`
- **Base URL:** `https://api.probackup.io`
- **Official documentation:** [List Platforms](https://support.probackup.io/en/articles/13250957-supported-features-for-the-make-com-integration)
