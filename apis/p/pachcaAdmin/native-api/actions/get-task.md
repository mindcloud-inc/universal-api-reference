# Get Task with Pachca (Admin)

Retrieves a task from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Task](https://dev.pachca.com/api/tasks/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca task ID. |
