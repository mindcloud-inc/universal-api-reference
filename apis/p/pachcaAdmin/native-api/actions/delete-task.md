# Delete Task with Pachca (Admin)

Deletes a task from the Pachca Admin API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Delete Task](https://dev.pachca.com/api/tasks/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca task ID. |
