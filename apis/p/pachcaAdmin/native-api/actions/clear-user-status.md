# Clear Current Status with Pachca (Admin)

Deletes your current status from the Pachca Admin API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/profile/status`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Clear Current Status](https://dev.pachca.com/api/profile/delete-status)
