# Create Group Tag with Pachca (Admin)

Creates a new group tag in the Pachca Admin API.

## Endpoint

- **Method:** `POST`
- **Path:** `/group_tags`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Create Group Tag](https://dev.pachca.com/api/group-tags/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
