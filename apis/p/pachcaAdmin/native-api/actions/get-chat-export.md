# Get Chat Export with Pachca (Admin)

Retrieves a chat export from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/exports/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Chat Export](https://dev.pachca.com/api/common/request-export)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca export ID. |
