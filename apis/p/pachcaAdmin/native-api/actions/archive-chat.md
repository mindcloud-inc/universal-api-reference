# Archive Chat with Pachca (Admin)

Archives a chat in the Pachca Admin API.

## Endpoint

- **Method:** `PUT`
- **Path:** `/chats/:id/archive`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Archive Chat](https://dev.pachca.com/api/chats/archive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca chat ID. |
