# Get Message with Pachca (Admin)

Retrieves a message from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Message](https://dev.pachca.com/api/messages/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca message ID. |
