# Get User with Pachca (Admin)

Retrieves a user from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get User](https://dev.pachca.com/api/users/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca user ID. |
