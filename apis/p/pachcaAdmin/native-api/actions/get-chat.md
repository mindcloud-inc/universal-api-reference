# Get Chat with Pachca (Admin)

Retrieves a chat from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Chat](https://dev.pachca.com/api/chats/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca chat ID. |
