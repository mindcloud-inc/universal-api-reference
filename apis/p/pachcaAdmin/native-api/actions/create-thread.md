# Create Thread with Pachca (Admin)

Creates a new thread in the Pachca Admin API.

## Endpoint

- **Method:** `POST`
- **Path:** `/messages/:id/thread`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Create Thread](https://dev.pachca.com/api/threads/add)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca message ID. |
