# Get Thread with Pachca (Admin)

Retrieves a thread from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Thread](https://dev.pachca.com/api/threads/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca thread ID. |
