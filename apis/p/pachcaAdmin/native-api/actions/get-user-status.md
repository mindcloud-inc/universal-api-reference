# Get Current Status with Pachca (Admin)

Retrieves your current status from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/status`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Current Status](https://dev.pachca.com/api/profile/get-status)
