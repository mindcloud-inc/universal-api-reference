# Delete Group Tag with Pachca (Admin)

Deletes a group tag from the Pachca Admin API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group_tags/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Delete Group Tag](https://dev.pachca.com/api/group-tags/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca group tag ID. |
