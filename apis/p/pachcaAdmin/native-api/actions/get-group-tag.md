# Get Group Tag with Pachca (Admin)

Retrieves a group tag from the Pachca Admin API.

## Endpoint

- **Method:** `GET`
- **Path:** `/group_tags/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Get Group Tag](https://dev.pachca.com/api/group-tags/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca group tag ID. |
