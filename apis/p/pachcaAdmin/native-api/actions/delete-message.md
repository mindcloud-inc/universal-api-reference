# Delete Message with Pachca (Admin)

Deletes a message from the Pachca Admin API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messages/:id`
- **Base URL:** `https://api.pachca.com/api/shared/v1`
- **Official documentation:** [Delete Message](https://dev.pachca.com/api/messages/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Pachca message ID. |
