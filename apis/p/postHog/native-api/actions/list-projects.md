# List Projects with PostHog

Retrieves projects from a PostHog organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/projects`
- **Base URL:** `https://us.posthog.com/api`
- **Official documentation:** [List Projects](https://posthog.com/docs/api/projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `list` | no |
