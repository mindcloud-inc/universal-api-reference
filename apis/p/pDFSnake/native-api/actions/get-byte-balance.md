# Get Byte Balance with PDF Snake

Retrieves your current byte balance from PDF Snake.

## Endpoint

- **Method:** `POST`
- **Path:** `/balance`
- **Base URL:** `https://api2.pdfsnake.app/api/v2`
- **Official documentation:** [Get Byte Balance](https://api.swaggerhub.com/apis/R7274/PDFSnakeWebApi/6.227.0?resolved=true)
