# Search Pin Requests with Pinata

Finds matching pin requests in Pinata.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/files/public/pin_by_cid`
- **Base URL:** `https://api.pinata.cloud`
- **Official documentation:** [Search Pin Requests](https://docs.pinata.cloud/api-reference/endpoint/query-pin-requests)
