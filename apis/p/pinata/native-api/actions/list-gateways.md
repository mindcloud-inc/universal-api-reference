# List Gateways with Pinata

Retrieves gateways from Pinata for the current account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/gateways`
- **Base URL:** `https://api.pinata.cloud`
- **Official documentation:** [List Gateways](https://docs.pinata.cloud/api-reference/endpoint/ipfs/list-gateways)
