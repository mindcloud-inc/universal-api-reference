# Get Gateway Details with Pinata

Retrieves gateway details from Pinata.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/gateways/:id`
- **Base URL:** `https://api.pinata.cloud`
- **Official documentation:** [Get Gateway Details](https://docs.pinata.cloud/api-reference/endpoint/ipfs/gateway-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the target gateway. |
