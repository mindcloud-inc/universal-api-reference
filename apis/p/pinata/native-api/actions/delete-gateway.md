# Delete Gateway with Pinata

Deletes an existing gateway from Pinata.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/gateways/:id`
- **Base URL:** `https://api.pinata.cloud`
- **Official documentation:** [Delete Gateway](https://docs.pinata.cloud/api-reference/endpoint/ipfs/delete-gateway)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the target gateway. |
