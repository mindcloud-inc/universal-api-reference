# Upload File with Proofy

## Endpoint

- **Method:** `POST`
- **Path:** `/verify/file/upload`
- **Base URL:** `https://apis.proofy.io/v1`
- **Official documentation:** [Upload File](https://docs.proofy.io/api-reference/endpoint/verify-file-upload)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | CSV or TXT file containing email addresses to verify. |
