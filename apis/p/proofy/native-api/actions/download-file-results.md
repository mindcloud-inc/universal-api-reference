# Download File Results with Proofy

## Endpoint

- **Method:** `GET`
- **Path:** `/verify/file/:id/download`
- **Base URL:** `https://apis.proofy.io/v1`
- **Official documentation:** [Download File Results](https://docs.proofy.io/api-reference/endpoint/verify-file-download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | File request identifier. |
