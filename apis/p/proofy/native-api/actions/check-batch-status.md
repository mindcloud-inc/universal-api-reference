# Check Batch Status with Proofy

- **Method:** `GET`
- **Path:** `/verify/batch/:id`
- **Base URL:** `https://apis.proofy.io/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Batch request identifier. |
