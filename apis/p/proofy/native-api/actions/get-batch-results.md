# Get Batch Results with Proofy

## Endpoint

- **Method:** `GET`
- **Path:** `/verify/batch/:id/download`
- **Base URL:** `https://apis.proofy.io/v1`
- **Official documentation:** [Get Batch Results](https://docs.proofy.io/api-reference/endpoint/verify-batch-download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Batch request identifier. |
