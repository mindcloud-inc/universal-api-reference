# Check File Status with Proofy

## Endpoint

- **Method:** `GET`
- **Path:** `/verify/file/:id`
- **Base URL:** `https://apis.proofy.io/v1`
- **Official documentation:** [Check File Status](https://docs.proofy.io/api-reference/endpoint/verify-file-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | File request identifier. |
