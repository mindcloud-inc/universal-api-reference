# Get Raw Public Or Unlisted Paste with Pastebin

Retrieves raw content for a public or unlisted Pastebin paste.

## Endpoint

- **Method:** `GET`
- **Path:** `https://pastebin.com/raw/:pasteKey`
- **Base URL:** `https://pastebin.com/api`
- **Official documentation:** [Get Raw Public Or Unlisted Paste](https://pastebin.com/doc_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pasteKey` | path | `string` | yes | The Pastebin key for the public or unlisted paste. |
