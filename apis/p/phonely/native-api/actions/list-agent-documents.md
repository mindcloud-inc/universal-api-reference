# List Agent Documents with Phonely

Retrieves agent documents from Phonely.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/agent-documents`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [List Agent Documents](https://docs.phonely.ai/api-reference/endpoint/agent-documents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uid` | query | `string` | yes |
| `agentId` | query | `string` | yes |
