# List Agent Websites with Phonely

Retrieves agent websites from Phonely.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/agent-websites`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [List Agent Websites](https://docs.phonely.ai/api-reference/endpoint/agent-websites)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uid` | query | `string` | yes |
| `agentId` | query | `string` | yes |
