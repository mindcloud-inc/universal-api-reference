# List Organizations with Phonely

Retrieves organizations from Phonely.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get-orgs`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [List Organizations](https://docs.phonely.ai/api-reference/endpoint/get-orgs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | query | `string` | yes | Your user ID. |
