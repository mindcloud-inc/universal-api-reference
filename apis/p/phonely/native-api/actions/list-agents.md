# List Agents with Phonely

Retrieves agents from Phonely.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/get-agents`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [List Agents](https://docs.phonely.ai/api-reference/endpoint/get-agents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | body | `string` | yes | Your user ID. |
