# List Block List with Phonely

Retrieves blocked phone numbers from Phonely.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/agent-block-list`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [List Block List](https://docs.phonely.ai/api-reference/endpoint/block-list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uid` | query | `string` | yes |
| `agentId` | query | `string` | yes |
