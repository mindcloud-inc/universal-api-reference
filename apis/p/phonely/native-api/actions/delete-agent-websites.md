# Delete Agent Websites with Phonely

Deletes agent websites from Phonely.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/agent-websites`
- **Base URL:** `https://app.phonely.ai`
- **Official documentation:** [Delete Agent Websites](https://docs.phonely.ai/api-reference/endpoint/delete-agent-websites)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uid` | query | `string` | yes |
| `agentId` | query | `string` | yes |
| `websiteId` | query | `string` | yes |
