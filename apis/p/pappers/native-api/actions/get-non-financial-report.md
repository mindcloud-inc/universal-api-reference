# Get Non-Financial Report with Pappers

## Endpoint

- **Method:** `GET`
- **Path:** `/document/rapport_non_financier`
- **Base URL:** `https://api.pappers.fr/v2`
- **Official documentation:** [Get Non-Financial Report](https://www.pappers.fr/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siren` | query | `string` | yes | French company SIREN identifier. |
