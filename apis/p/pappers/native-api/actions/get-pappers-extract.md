# Get Pappers Extract with Pappers

## Endpoint

- **Method:** `GET`
- **Path:** `/document/extrait_pappers`
- **Base URL:** `https://api.pappers.fr/v2`
- **Official documentation:** [Get Pappers Extract](https://www.pappers.fr/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siren` | query | `string` | yes | Company SIREN number. |
