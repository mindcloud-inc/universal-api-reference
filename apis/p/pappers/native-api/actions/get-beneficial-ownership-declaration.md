# Get Beneficial Ownership Declaration with Pappers

## Endpoint

- **Method:** `GET`
- **Path:** `/document/declaration_beneficiaires_effectifs`
- **Base URL:** `https://api.pappers.fr/v2`
- **Official documentation:** [Get Beneficial Ownership Declaration](https://www.pappers.fr/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siren` | query | `string` | yes | French company SIREN identifier. |
