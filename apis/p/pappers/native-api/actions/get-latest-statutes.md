# Get Latest Statutes with Pappers

## Endpoint

- **Method:** `GET`
- **Path:** `/document/statuts`
- **Base URL:** `https://api.pappers.fr/v2`
- **Official documentation:** [Get Latest Statutes](https://www.pappers.fr/api/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siren` | query | `string` | yes | Company SIREN number. |
