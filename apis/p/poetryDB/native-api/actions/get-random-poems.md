# Get Random Poems with PoetryDB

## Endpoint

- **Method:** `GET`
- **Path:** `/random/:count`
- **Base URL:** `https://poetrydb.org`
- **Official documentation:** [Get Random Poems](https://poetrydb.org/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | path | `number` | yes | Required random poem count. |
