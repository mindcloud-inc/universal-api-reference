# Get Poems by Title with PoetryDB

## Endpoint

- **Method:** `GET`
- **Path:** `/title/:title`
- **Base URL:** `https://poetrydb.org`
- **Official documentation:** [Get Poems by Title](https://poetrydb.org/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | path | `string` | yes | Required poem title. |
