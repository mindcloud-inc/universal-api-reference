# Get Poems by Author with PoetryDB

## Endpoint

- **Method:** `GET`
- **Path:** `/author/:author`
- **Base URL:** `https://poetrydb.org`
- **Official documentation:** [Get Poems by Author](https://poetrydb.org/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `author` | path | `string` | yes | Required author name. |
