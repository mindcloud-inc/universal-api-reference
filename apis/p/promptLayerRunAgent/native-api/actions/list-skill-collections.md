# List Skill Collections with PromptLayer Run Agent

Retrieves skill collections from PromptLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v2/skill-collections`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [List Skill Collections](https://docs.promptlayer.com/reference/list-skill-collections)
