# Get Trace with PromptLayer Run Agent

Retrieves a trace from PromptLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v2/traces/:trace_id`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [Get Trace](https://docs.promptlayer.com/reference/get-trace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trace_id` | path | `string` | yes | PromptLayer trace ID to retrieve. |
