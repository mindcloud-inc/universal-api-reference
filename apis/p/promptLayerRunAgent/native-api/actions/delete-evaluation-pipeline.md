# Delete Evaluation Pipeline with PromptLayer Run Agent

Deletes a PromptLayer evaluation pipeline.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/reports/:reportId`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [Delete Evaluation Pipeline](https://docs.promptlayer.com/reference/delete-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `number` | yes | ID of the evaluation pipeline report to archive. |
