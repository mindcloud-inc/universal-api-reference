# List Agents with PromptLayer Run Agent

Retrieves a list of workflows from PromptLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [List Agents](https://docs.promptlayer.com/reference/list-workflows)

## Capabilities

This operation supports [pagination](../README.md#pagination).
