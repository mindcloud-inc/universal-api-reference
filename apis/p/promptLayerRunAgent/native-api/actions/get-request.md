# Get Request with PromptLayer Run Agent

Retrieves a request from PromptLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v2/requests/:request_id`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [Get Request](https://docs.promptlayer.com/reference/get-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `number` | yes | PromptLayer request ID to retrieve. |
