# Get Evaluation with PromptLayer Run Agent

Retrieves a PromptLayer evaluation.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:reportId`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [Get Evaluation](https://docs.promptlayer.com/reference/get-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `number` | yes | ID of the report to retrieve. |
