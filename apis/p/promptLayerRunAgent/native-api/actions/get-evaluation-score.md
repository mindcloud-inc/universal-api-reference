# Get Evaluation Score with PromptLayer Run Agent

Retrieves the score for a PromptLayer evaluation.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:reportId/score`
- **Base URL:** `https://api.promptlayer.com`
- **Official documentation:** [Get Evaluation Score](https://docs.promptlayer.com/reference/get-report-score)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `number` | yes | ID of the evaluation report to retrieve score details for. |
