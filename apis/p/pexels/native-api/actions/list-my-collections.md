# List My Collections with Pexels

Retrieves your saved collections from Pexels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/collections`
- **Base URL:** `https://api.pexels.com`
- **Official documentation:** [List My Collections](https://www.pexels.com/api/documentation/#collections-mine)

## Capabilities

This operation supports [pagination](../README.md#pagination).
