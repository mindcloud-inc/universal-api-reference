# List Featured Collections with Pexels

Retrieves featured collections available in Pexels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/collections/featured`
- **Base URL:** `https://api.pexels.com`
- **Official documentation:** [List Featured Collections](https://www.pexels.com/api/documentation/#collections-featured)

## Capabilities

This operation supports [pagination](../README.md#pagination).
