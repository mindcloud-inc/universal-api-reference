# Get Photo with Pexels

Retrieves a photo from Pexels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/photos/:id`
- **Base URL:** `https://api.pexels.com`
- **Official documentation:** [Get Photo](https://www.pexels.com/api/documentation/#photos-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Pexels photo ID. |
