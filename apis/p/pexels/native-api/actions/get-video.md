# Get Video with Pexels

Retrieves a video from Pexels by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/videos/:id`
- **Base URL:** `https://api.pexels.com`
- **Official documentation:** [Get Video](https://www.pexels.com/api/documentation/#videos-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Pexels video ID. |
