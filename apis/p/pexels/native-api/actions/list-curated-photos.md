# List Curated Photos with Pexels

Retrieves curated photo results from Pexels.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/curated`
- **Base URL:** `https://api.pexels.com`
- **Official documentation:** [List Curated Photos](https://www.pexels.com/api/documentation/#photos-curated)

## Capabilities

This operation supports [pagination](../README.md#pagination).
