# Authorize API Key with Peggy Pay

Retrieves an access token from Peggy Pay.

## Endpoint

- **Method:** `GET`
- **Path:** `Framework.authorize`
- **Base URL:** `https://www.peggypay.com/api`
- **Official documentation:** [Authorize API Key](https://github.com/peggyforms/php-sdk/blob/master/src/Api.php)
