# Create Candidate Request with Prembly

Creates a candidate request in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/api/bgc/requests/candidates/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Create Candidate Request](https://docs.prembly.com/reference/create-candidate-request)
