# List Check Types by Country with Prembly

Retrieves check types by country from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/country/check-types/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [List Check Types by Country](https://docs.prembly.com/reference/list-check-types-by-country)
