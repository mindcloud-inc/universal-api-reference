# Delete Custom Package with Prembly

Deletes a custom package from Prembly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/api/bgc/packages/:packageId/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Delete Custom Package](https://docs.prembly.com/reference/delete-custom-package)
