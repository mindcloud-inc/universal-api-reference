# Document Verification with Face with Prembly

Creates document verification with face in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/document_w_face`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Document Verification with Face](https://docs.prembly.com/reference/document-verification-with-face)
