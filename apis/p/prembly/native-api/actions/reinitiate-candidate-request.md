# Reinitiate Candidate Request with Prembly

Reinitiates a candidate request in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/candidates/:reference/reinitiate/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Reinitiate Candidate Request](https://docs.prembly.com/reference/reinitiate-candidate-request)
