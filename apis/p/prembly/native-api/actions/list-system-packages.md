# List System Packages with Prembly

Retrieves system packages from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/system-packages/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [List System Packages](https://docs.prembly.com/reference/get-system-package-detail)
