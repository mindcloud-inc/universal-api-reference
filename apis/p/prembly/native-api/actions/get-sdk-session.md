# Get SDK Session with Prembly

Retrieves SDK sessions from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/checker-widget/sdk/sessions/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get SDK Session](https://docs.prembly.com/reference/sdk-session-retrieval)
