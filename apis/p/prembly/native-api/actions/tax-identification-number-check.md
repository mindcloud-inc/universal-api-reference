# Tax Identification Number Check with Prembly

Creates a tax identification number check in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/global/tin-check`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Tax Identification Number Check](https://docs.prembly.com/reference/tax-identification-number)
