# List All Check Types with Prembly

Retrieves all check types from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/check-types/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [List All Check Types](https://docs.prembly.com/reference/list-all-check-types)
