# Account with Name Comparism with Prembly

Creates account name comparism verification in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/bank_account/comparism`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Account with Name Comparism](https://docs.prembly.com/reference/account-with-name-comparism)
