# Update Custom Package with Prembly

Updates a custom package in Prembly.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/api/bgc/packages/:packageId/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Update Custom Package](https://docs.prembly.com/reference/update-custom-package)
