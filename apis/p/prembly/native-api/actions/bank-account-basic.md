# Bank Account (Basic) with Prembly

Creates a basic bank account verification in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/bank_account/basic`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Bank Account (Basic)](https://docs.prembly.com/reference/account-number-10-1)
