# Transaction Monitoring Screen Transaction with Prembly

Screens a transaction with Prembly monitoring.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/fraud/transaction-monitoring/screen-transaction`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Transaction Monitoring Screen Transaction](https://docs.prembly.com/reference/tm-transaction-monitoring)
