# Get Fraud Report Detail with Prembly

Retrieves a fraud report from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/fraud/reports/:reportId/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get Fraud Report Detail](https://docs.prembly.com/reference/check-status)
