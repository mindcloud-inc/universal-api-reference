# Company Search With Registration Number with Prembly

Creates a company search by registration number in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/global/company`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Company Search With Registration Number](https://docs.prembly.com/reference/company-search-with-registration-number-1)
