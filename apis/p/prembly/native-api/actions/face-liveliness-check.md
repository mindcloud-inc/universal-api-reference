# Face Liveliness Check with Prembly

Creates a face liveliness check in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/biometrics/face/liveliness_check`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Face Liveliness Check](https://docs.prembly.com/reference/face-liveliness-check)
