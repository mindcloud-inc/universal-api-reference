# Get System Package Detail with Prembly

Retrieves a system package from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/system-packages/:packageId`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get System Package Detail](https://docs.prembly.com/reference/list-system-package)
