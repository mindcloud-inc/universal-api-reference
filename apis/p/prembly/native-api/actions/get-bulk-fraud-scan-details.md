# Get Bulk Fraud Scan Details with Prembly

Retrieves a bulk fraud scan from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/fraud/bulk-scan/:bulkId/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get Bulk Fraud Scan Details](https://docs.prembly.com/reference/check-status)
