# List Custom Packages with Prembly

Retrieves custom packages from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/packages/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [List Custom Packages](https://docs.prembly.com/reference/list-custom-packages)
