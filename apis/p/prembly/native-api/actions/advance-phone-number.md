# Advance Phone Number with Prembly

Creates an advanced phone number verification in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/phone_number/advance`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Advance Phone Number](https://docs.prembly.com/reference/advance-phone-number-1)
