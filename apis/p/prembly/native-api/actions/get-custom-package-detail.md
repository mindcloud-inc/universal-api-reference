# Get Custom Package Detail with Prembly

Retrieves a custom package from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/packages/:packageId`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get Custom Package Detail](https://docs.prembly.com/reference/get-custom-package-detail)
