# Submit Fraud Report with Prembly

Submits a fraud report to Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/fraud/reports/submit/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Submit Fraud Report](https://docs.prembly.com/reference/submit-fraud-report)
