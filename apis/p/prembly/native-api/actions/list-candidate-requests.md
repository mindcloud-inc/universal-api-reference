# List Candidate Requests with Prembly

Retrieves candidate requests from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api/bgc/requests/candidates/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [List Candidate Requests](https://docs.prembly.com/reference/list-candidate-requests)
