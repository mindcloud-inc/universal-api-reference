# Get Candidate Request Detail with Prembly

Retrieves a candidate request from Prembly.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/candidates/:reference/`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Get Candidate Request Detail](https://docs.prembly.com/reference/get-candidate-request-detail)
