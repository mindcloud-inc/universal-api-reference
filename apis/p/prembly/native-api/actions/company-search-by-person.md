# Company Search By Person with Prembly

Creates a company search by person in Prembly.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/global/company/search_with_string`
- **Base URL:** `https://api.prembly.com`
- **Official documentation:** [Company Search By Person](https://docs.prembly.com/reference/company-search-by-person)
