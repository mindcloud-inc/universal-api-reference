# Get Submission with Paperform

Retrieves a submission from Paperform.

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:id`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Get Submission](https://paperform.readme.io/reference/getsubmission)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
