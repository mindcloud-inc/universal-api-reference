# List Form Products with Paperform

Retrieves products from a Paperform form.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:slug_or_id/products`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [List Form Products](https://paperform.readme.io/reference/listformproducts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug_or_id` | path | `list<string>` | yes |
