# List Forms with Paperform

Retrieves forms from Paperform.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [List Forms](https://paperform.readme.io/reference/listforms)

## Capabilities

This operation supports [pagination](../README.md#pagination).
