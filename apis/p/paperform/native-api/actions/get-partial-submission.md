# Get Partial Submission with Paperform

Retrieves a partial submission from Paperform.

## Endpoint

- **Method:** `GET`
- **Path:** `/partial-submissions/:id`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Get Partial Submission](https://paperform.readme.io/reference/getpartialsubmission)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
