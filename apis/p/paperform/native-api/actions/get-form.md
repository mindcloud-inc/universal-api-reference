# Get Form with Paperform

Retrieves a form from Paperform.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:slug_or_id`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Get Form](https://paperform.readme.io/reference/getform)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug_or_id` | path | `list<string>` | yes | Paperform form slug or numeric ID. |
