# List Form Webhooks with Paperform

Retrieves webhooks from a Paperform form.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:slug_or_id/webhooks`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [List Form Webhooks](https://paperform.readme.io/reference/listformwebhooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug_or_id` | path | `list<string>` | yes |
