# List Form Coupons with Paperform

Retrieves coupons from a Paperform form.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:slug_or_id/coupons`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [List Form Coupons](https://paperform.readme.io/reference/listformcoupons)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug_or_id` | path | `list<string>` | yes |
