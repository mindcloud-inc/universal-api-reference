# List Agents with PhantomBuster

Retrieves agents from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/fetch-all`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [List Agents](https://hub.phantombuster.com/reference/get_agents-fetch-all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentIds` | query | `string` | no |
| `inputTypes` | query | `string` | no |
| `outputTypes` | query | `string` | no |
| `withAgentSlotsFactor` | query | `string` | no |
| `withArgument` | query | `string` | no |
