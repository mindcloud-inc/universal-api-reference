# Get IP Location with PhantomBuster

Retrieves IP location details from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/location/ip`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [Get IP Location](https://hub.phantombuster.com/reference/get_location-ip)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ip` | query | `string` | yes |
