# List Deleted Agents with PhantomBuster

Retrieves deleted agents from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/fetch-deleted`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [List Deleted Agents](https://hub.phantombuster.com/reference/get_agents-fetch-deleted)
