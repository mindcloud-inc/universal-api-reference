# List Branches with PhantomBuster

Retrieves branches from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/branches/fetch-all`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [List Branches](https://hub.phantombuster.com/reference/get_branches-fetch-all)
