# Get Organization Agent Groups with PhantomBuster

Retrieves organization agent groups from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/fetch-agent-groups`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [Get Organization Agent Groups](https://hub.phantombuster.com/reference/get_orgs-fetch-agent-groups)
