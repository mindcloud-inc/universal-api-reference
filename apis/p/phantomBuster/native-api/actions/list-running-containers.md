# List Running Containers with PhantomBuster

Retrieves running containers from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/fetch-running-containers`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [List Running Containers](https://hub.phantombuster.com/reference/get_orgs-fetch-running-containers)
