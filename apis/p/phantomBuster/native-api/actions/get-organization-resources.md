# Get Organization Resources with PhantomBuster

Retrieves organization resources from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/fetch-resources`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [Get Organization Resources](https://hub.phantombuster.com/reference/get_orgs-fetch-resources)
