# Get Organization with PhantomBuster

Retrieves organization details from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/fetch`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [Get Organization](https://hub.phantombuster.com/reference/get_orgs-fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `withCrmIntegrations` | query | `string` | no |
| `withCustomPrompts` | query | `string` | no |
| `withGlobalObject` | query | `string` | no |
| `withProxies` | query | `string` | no |
