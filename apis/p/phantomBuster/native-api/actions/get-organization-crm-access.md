# Get Organization CRM Access with PhantomBuster

Retrieves organization CRM access from PhantomBuster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/fetch-crm-access`
- **Base URL:** `https://api.phantombuster.com/api/v2`
- **Official documentation:** [Get Organization CRM Access](https://hub.phantombuster.com/reference/get_orgs-fetch-crm-access)
