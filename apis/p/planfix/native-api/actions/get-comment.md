# Get Comment with Planfix

Retrieves a comment from Planfix.

## Endpoint

- **Method:** `GET`
- **Path:** `/comment/:id`
- **Base URL:** `{accountBaseUrl}/rest`
- **Official documentation:** [Get Comment](https://help.planfix.com/restapidocs/#/Comments/get-comment-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Planfix comment identifier. |
