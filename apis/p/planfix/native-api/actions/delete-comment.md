# Delete Comment with Planfix

Deletes a comment from Planfix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/comment/:id`
- **Base URL:** `{accountBaseUrl}/rest`
- **Official documentation:** [Delete Comment](https://help.planfix.com/restapidocs/#/Comments/delete-comment-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Planfix comment identifier. |
