# Get Latest Podcast Sponsor with Podscan

Retrieves the latest podcast sponsor from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}/latest/sponsor`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Latest Podcast Sponsor](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
