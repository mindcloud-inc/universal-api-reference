# List Topic Episodes with Podscan

Retrieves episodes for a topic from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/{topicId}/episodes`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Topic Episodes](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | The topic ID. |
