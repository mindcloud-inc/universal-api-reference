# Get Episode Demographics with Podscan

Retrieves episode demographics data from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/{episode}/demographics`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Episode Demographics](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episode` | path | `string` | yes | The episode ID. |
