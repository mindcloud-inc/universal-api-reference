# Get Topic Demographics with Podscan

Retrieves topic demographics data from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/{topicId}/demographics`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Topic Demographics](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | The topic ID. |
