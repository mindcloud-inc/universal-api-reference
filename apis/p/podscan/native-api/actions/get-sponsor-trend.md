# Get Sponsor Trend with Podscan

Retrieves sponsor trend data from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/sponsors/{sponsor}/trend`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Sponsor Trend](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sponsor` | path | `string` | yes | The sponsor ID. |
