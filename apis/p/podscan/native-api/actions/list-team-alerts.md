# List Team Alerts with Podscan

Retrieves alerts for a team from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{team}/alerts`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Team Alerts](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team` | path | `string` | yes | The team ID. |
