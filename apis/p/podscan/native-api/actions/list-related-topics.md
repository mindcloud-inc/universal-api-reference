# List Related Topics with Podscan

Retrieves related topic matches from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/{topicId}/related`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Related Topics](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | The topic ID. |
