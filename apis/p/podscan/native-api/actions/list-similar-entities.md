# List Similar Entities with Podscan

Retrieves similar entity matches from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/{entityId}/similar`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Similar Entities](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | The entity ID. |
