# Search Publishers with Podscan

Finds publishers in Podscan by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/publishers/search`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Search Publishers](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | The publisher search query. |
