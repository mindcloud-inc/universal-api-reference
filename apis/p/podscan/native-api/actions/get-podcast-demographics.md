# Get Podcast Demographics with Podscan

Retrieves podcast demographics data from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}/demographics`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Podcast Demographics](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
