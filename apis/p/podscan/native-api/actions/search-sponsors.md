# Search Sponsors with Podscan

Finds sponsors in Podscan by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/sponsors/search`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Search Sponsors](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The sponsor search query. |
