# List Entity Appearances with Podscan

Retrieves entity appearance records from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/{entityId}/appearances`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Entity Appearances](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | The entity ID. |
