# Get Podcast Brand Safety with Podscan

Retrieves podcast brand safety details from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}/brand-safety`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Podcast Brand Safety](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
