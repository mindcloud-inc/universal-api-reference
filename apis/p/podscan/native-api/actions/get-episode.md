# Get Episode with Podscan

Retrieves an episode record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/{episode}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Episode](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episode` | path | `string` | yes | The episode ID. |
