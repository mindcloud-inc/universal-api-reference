# Get Episode Brand Safety with Podscan

Retrieves episode brand safety details from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/{episode}/brand-safety`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Episode Brand Safety](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episode` | path | `string` | yes | The episode ID. |
