# Search Topics with Podscan

Finds topics in Podscan by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/search`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Search Topics](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The topic search query. |
