# Get Topic with Podscan

Retrieves a topic record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics/{topicId}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Topic](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | The topic ID. |
