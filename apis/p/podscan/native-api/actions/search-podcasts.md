# Search Podcasts with Podscan

Finds podcasts in Podscan by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/search`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Search Podcasts](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The podcast search query. |
