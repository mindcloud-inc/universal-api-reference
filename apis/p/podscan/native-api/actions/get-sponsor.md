# Get Sponsor with Podscan

Retrieves a sponsor record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/sponsors/{sponsor}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Sponsor](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sponsor` | path | `string` | yes | The sponsor ID. |
