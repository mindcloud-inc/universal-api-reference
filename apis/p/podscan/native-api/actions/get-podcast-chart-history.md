# Get Podcast Chart History with Podscan

Retrieves podcast chart history from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}/chart-history`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Podcast Chart History](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
