# Get Topic Collection with Podscan

Retrieves a topic collection from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/topic-collections/{slug}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Topic Collection](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The topic collection slug. |
