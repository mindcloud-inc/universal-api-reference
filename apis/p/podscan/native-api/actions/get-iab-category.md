# Get IAB Category with Podscan

Retrieves an IAB category from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/iab-categories/{id}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get IAB Category](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The IAB category ID. |
