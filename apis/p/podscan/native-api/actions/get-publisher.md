# Get Publisher with Podscan

Retrieves a publisher record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/publishers/{publisherId}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Publisher](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publisherId` | path | `string` | yes | The publisher ID. |
