# Get Episode Engagement with Podscan

Retrieves episode engagement details from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/{episode}/engagement`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Episode Engagement](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episode` | path | `string` | yes | The episode ID. |
