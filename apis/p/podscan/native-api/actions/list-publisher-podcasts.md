# List Publisher Podcasts with Podscan

Retrieves podcasts for a publisher from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/publishers/{publisherId}/podcasts`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [List Publisher Podcasts](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publisherId` | path | `string` | yes | The publisher ID. |
| `publisherId` | path | `string` | yes | The publisher ID. |
