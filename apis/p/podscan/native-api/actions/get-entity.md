# Get Entity with Podscan

Retrieves an entity record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/{entityId}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Entity](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | The entity ID. |
