# Get Podcast with Podscan

Retrieves a podcast record from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Podcast](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
