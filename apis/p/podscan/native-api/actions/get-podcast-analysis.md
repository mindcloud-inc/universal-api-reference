# Get Podcast Analysis with Podscan

Retrieves podcast analysis data from Podscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/{podcast}/analysis`
- **Base URL:** `https://podscan.fm/api/v1`
- **Official documentation:** [Get Podcast Analysis](https://podscan.fm/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast` | path | `string` | yes | The podcast ID. |
