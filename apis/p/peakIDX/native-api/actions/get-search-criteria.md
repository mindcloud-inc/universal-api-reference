# Get Search Criteria with PeakIDX

Retrieves configured search criteria from PeakIDX.

## Endpoint

- **Method:** `GET`
- **Path:** `https://{siteName}.peakidxsites.com/search-criteria/`
- **Base URL:** `https://account.peakidxsites.com`
- **Official documentation:** [Get Search Criteria](https://docs.peakidx.com/api/search-criteria-api)
