# Get Resource Work Week Hours with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/resourcecalendar/:id/workweekhours`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Resource Work Week Hours](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The resource calendar ID to fetch. |
