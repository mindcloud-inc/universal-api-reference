# Get Project Deliverable with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/projects/:projectId/deliverables/:deliverableId`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Project Deliverable](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `deliverableId` | path | `string` | yes |
