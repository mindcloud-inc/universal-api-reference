# Get Idea with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/ideas/:id`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Idea](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The idea ID to fetch. |
