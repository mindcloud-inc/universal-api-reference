# Get Project Task with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/projects/:projectId/tasks/:taskId`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Project Task](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `taskId` | path | `string` | yes |
