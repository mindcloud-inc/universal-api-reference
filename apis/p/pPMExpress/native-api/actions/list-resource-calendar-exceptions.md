# List Resource Calendar Exceptions with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/resourcecalendar/:id/exceptions`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [List Resource Calendar Exceptions](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The resource calendar ID whose exceptions to list. |
