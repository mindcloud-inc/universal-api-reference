# Get Project Key Date with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/projects/:projectId/keydates/:keyDateId`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Project Key Date](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `keyDateId` | path | `string` | yes |
