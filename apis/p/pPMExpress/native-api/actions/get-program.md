# Get Program with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/programs/:id`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get Program](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The program ID to fetch. |
