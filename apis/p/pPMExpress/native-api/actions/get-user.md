# Get User with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/users/:id`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [Get User](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The user ID to fetch. |
