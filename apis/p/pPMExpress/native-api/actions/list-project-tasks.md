# List Project Tasks with PPM Express

## Endpoint

- **Method:** `GET`
- **Path:** `/@:tenantName/v1.0/projects/:projectId/tasks`
- **Base URL:** `https://api-us.ppm.express`
- **Official documentation:** [List Project Tasks](https://help.ppm.express/public-api/1177822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The project ID whose tasks to list. |
