# Delete Suppression List with Postalytics

Deletes a suppression list from Postalytics.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/lists/suppression/:id`
- **Base URL:** `https://api.postalytics.com`
- **Official documentation:** [Delete Suppression List](https://docs.postalytics.com/references/postalytics-rest-api/delete-suppression-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Suppression list ID. |
