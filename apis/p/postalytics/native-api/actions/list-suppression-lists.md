# List Suppression Lists with Postalytics

Retrieves suppression lists from Postalytics.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/lists/suppression`
- **Base URL:** `https://api.postalytics.com`
- **Official documentation:** [List Suppression Lists](https://docs.postalytics.com/references/postalytics-rest-api/get-suppression-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | no | Suppression list ID. |
