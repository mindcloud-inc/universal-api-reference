# Get Organisation with 24 Pull Requests

Retrieves an organisation from 24 Pull Requests.

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:login.json`
- **Base URL:** `https://24pullrequests.com`
- **Official documentation:** [Get Organisation](https://24pullrequests.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `login` | path | `string` | yes | Organisation login from the 24 Pull Requests organisation URL. |
