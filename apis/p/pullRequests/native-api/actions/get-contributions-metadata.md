# Get Contributions Metadata with 24 Pull Requests

Retrieves contribution counts and total pages from 24 Pull Requests.

## Endpoint

- **Method:** `GET`
- **Path:** `/pull_requests/meta.json`
- **Base URL:** `https://24pullrequests.com`
- **Official documentation:** [Get Contributions Metadata](https://24pullrequests.com/api)
