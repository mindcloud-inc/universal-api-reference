# Get User with 24 Pull Requests

Retrieves a user from 24 Pull Requests.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:nickname.json`
- **Base URL:** `https://24pullrequests.com`
- **Official documentation:** [Get User](https://24pullrequests.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nickname` | path | `string` | yes | 24 Pull Requests user nickname from the user URL. |
