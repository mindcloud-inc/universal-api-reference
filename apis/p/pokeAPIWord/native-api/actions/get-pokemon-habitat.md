# Get Pokemon Habitat with PokeAPI Word

Retrieves Pokemon habitat details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-habitat/[:pokemonHabitatId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Habitat](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonHabitatId` | path | `string` | yes | Identifier for the requested Pokemon habitat. Use an ID or name. |
