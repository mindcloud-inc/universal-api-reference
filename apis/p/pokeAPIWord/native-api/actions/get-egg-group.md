# Get Egg Group with PokeAPI Word

Retrieves egg group details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `egg-group/[:eggGroupId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Egg Group](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eggGroupId` | path | `string` | yes | Identifier for the requested egg group. Use an ID or name. |
