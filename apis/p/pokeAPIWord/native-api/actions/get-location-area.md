# Get Location Area with PokeAPI Word

Retrieves location area details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `location-area/[:locationAreaId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Location Area](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationAreaId` | path | `string` | yes | Identifier for the requested location area. Use an ID or name. |
