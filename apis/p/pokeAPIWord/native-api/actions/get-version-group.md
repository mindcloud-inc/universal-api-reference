# Get Version Group with PokeAPI Word

Retrieves version group details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version-group/[:versionGroupId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Version Group](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionGroupId` | path | `string` | yes | Identifier for the requested version group. Use an ID or name. |
