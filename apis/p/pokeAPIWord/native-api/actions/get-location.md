# Get Location with PokeAPI Word

Retrieves details for a location from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `location/[:locationId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Location](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `string` | yes | Identifier for the requested location. Use an ID or name. |
