# Get Berry with PokeAPI Word

Retrieves details for a berry from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `berry/[:berryId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Berry](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `berryId` | path | `string` | yes | Identifier for the requested berry. Use an ID or name. |
