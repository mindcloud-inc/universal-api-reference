# Get Nature with PokeAPI Word

Retrieves details for a nature from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `nature/[:natureId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Nature](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `natureId` | path | `string` | yes | Identifier for the requested nature. Use an ID or name. |
