# Get Region with PokeAPI Word

Retrieves details for a region from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `region/[:regionId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Region](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `regionId` | path | `string` | yes | Identifier for the requested region. Use an ID or name. |
