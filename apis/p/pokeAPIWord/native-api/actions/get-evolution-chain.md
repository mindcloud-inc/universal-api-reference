# Get Evolution Chain with PokeAPI Word

Retrieves evolution chain details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `evolution-chain/[:evolutionChainId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Evolution Chain](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `evolutionChainId` | path | `string` | yes | Identifier for the requested evolution chain. Use an ID. |
