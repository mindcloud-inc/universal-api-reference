# Get Pokemon Form with PokeAPI Word

Retrieves Pokemon form details from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `pokemon-form/[:pokemonFormId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Pokemon Form](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pokemonFormId` | path | `string` | yes | Identifier for the requested Pokemon form. Use an ID or name. |
