# Get Item with PokeAPI Word

Retrieves details for an item from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `item/[:itemId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Item](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Identifier for the requested item. Use an ID or name. |
