# Get Generation with PokeAPI Word

Retrieves details for a generation from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `generation/[:generationId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Generation](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `generationId` | path | `string` | yes | Identifier for the requested generation. Use an ID or name. |
