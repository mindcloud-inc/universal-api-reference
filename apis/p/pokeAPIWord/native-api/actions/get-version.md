# Get Version with PokeAPI Word

Retrieves details for a version from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `version/[:versionId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Version](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Identifier for the requested game version. Use an ID or name. |
