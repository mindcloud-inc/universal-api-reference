# Get Ability with PokeAPI Word

Retrieves details for an ability from PokeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `ability/[:abilityId]`
- **Base URL:** `https://pokeapi.co/api/v2`
- **Official documentation:** [Get Ability](https://pokeapi.co/docs/v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `abilityId` | path | `string` | yes | Identifier for the requested ability. Use an ID or name. |
