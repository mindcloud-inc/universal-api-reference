# Get Notification Info with PushAlert

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v2/web-push/info/:id`
- **Base URL:** `https://api.pushalert.co`
- **Official documentation:** [Get Notification Info](https://pushalert.co/documentation/rest-api-v2/web-push#rest-api-notification-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | PushAlert notification ID. |
