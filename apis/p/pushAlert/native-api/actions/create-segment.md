# Create Segment with PushAlert

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/web-push/segment/create`
- **Base URL:** `https://api.pushalert.co`
- **Official documentation:** [Create Segment](https://pushalert.co/documentation/rest-api-v2/web-push#rest-api-segment-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the segment to create. |
