# Delete Scheduled Notification with PushAlert

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/web-push/delete/:id`
- **Base URL:** `https://api.pushalert.co`
- **Official documentation:** [Delete Scheduled Notification](https://pushalert.co/documentation/rest-api-v2/web-push#rest-api-notification-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | PushAlert scheduled notification ID. |
