# Delete Segment with PushAlert

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/web-push/segment/delete`
- **Base URL:** `https://api.pushalert.co`
- **Official documentation:** [Delete Segment](https://pushalert.co/documentation/rest-api-v2/web-push#rest-api-segment-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | PushAlert segment ID to delete. |
