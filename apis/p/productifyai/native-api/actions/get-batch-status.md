# Get Batch Status with Productify.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/Batch/Status`
- **Base URL:** `https://api.productify.ai`
- **Official documentation:** [Get Batch Status](https://api.productify.ai/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchId` | query | `number` | yes | Batch identifier returned by a Productify.ai batch creation endpoint. |
