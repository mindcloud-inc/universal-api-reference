# Get Company Shifts with Paylocity

## Endpoint

- **Method:** `GET`
- **Path:** `https://dc1demogwext.paylocity.com/apiHub/scheduling/v1/companies/:companyId/shifts`
- **Base URL:** `{connection}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `string` | no |
