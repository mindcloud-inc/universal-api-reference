# Get Episode Transcript with Planet Money Podcast

Retrieves a Planet Money episode transcript page from NPR.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.npr.org/transcripts/:storyId`
- **Base URL:** `https://feeds.npr.org/510289`
- **Official documentation:** [Get Episode Transcript](https://www.npr.org/transcripts/nx-s1-5751177)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyId` | path | `string` | yes | NPR transcript story identifier. |
