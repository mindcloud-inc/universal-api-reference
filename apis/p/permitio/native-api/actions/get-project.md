# Get Project with Permit.io

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projId`
- **Base URL:** `https://api.permit.io`
- **Official documentation:** [Get Project](https://api.permit.io/scalar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projId` | path | `string` | yes | Permit project identifier or key. |
