# Get OCR Statistics with Platerecognizer

Retrieves your Plate Recognizer OCR usage statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocr/statistics/`
- **Base URL:** `https://api.platerecognizer.com/v1`
- **Official documentation:** [Get OCR Statistics](https://guides.platerecognizer.com/docs/other-apps/ocr/api-reference/#statistics)
