# Get VIN Statistics with Platerecognizer

Retrieves your Plate Recognizer VIN ID usage statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/vin/statistics/`
- **Base URL:** `https://api.platerecognizer.com/v1`
- **Official documentation:** [Get VIN Statistics](https://guides.platerecognizer.com/docs/other-apps/vin-id/api-reference/#statistics)
