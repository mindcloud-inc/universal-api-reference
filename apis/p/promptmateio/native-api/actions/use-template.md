# Use Template with Promptmate.io

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/use`
- **Base URL:** `https://api.promptmate.io/v1`
- **Official documentation:** [Use Template](https://apidoc.promptmate.io/api-4935448)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | body | `string` | yes | The Promptmate template ID to use. |
