# Get Template with PDF-API.io

Retrieves a specific template from PDF-API.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template`
- **Base URL:** `https://pdf-api.io/api`
- **Official documentation:** [Get Template](https://pdf-api.io/en/docs/api/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template` | path | `list<number>` | yes | The unique identifier of the template you want to retrieve. |
