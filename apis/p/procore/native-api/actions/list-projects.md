# List Projects with Procore

Retrieves projects from Procore.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v1.0/projects`
- **Base URL:** `https://api.procore.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `string` | yes | Unique identifier for the company. |
