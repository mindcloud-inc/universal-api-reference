# List Companies with Procore

Retrieves companies from Procore.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v1.0/companies`
- **Base URL:** `https://api.procore.com`
- **Official documentation:** [List Companies](https://developers.procore.com/reference/rest/companies#list-companies)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `include_free_companies` | query | `string` | no |
| `page` | query | `string` | no |
| `per_page` | query | `string` | no |
