# List Observations with Procore

Retrieves observation items from Procore.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v1.0/observations/items`
- **Base URL:** `https://api.procore.com`
- **Official documentation:** [List Observations](https://developers.procore.com/reference/rest/observations#list-observation-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | query | `string` | yes | Unique identifier for the project. |
