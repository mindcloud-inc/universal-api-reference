# List Company Vendors with Procore

Retrieves company vendors from Procore.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v1.0/vendors`
- **Base URL:** `https://api.procore.com`
- **Official documentation:** [List Company Vendors](https://developers.procore.com/reference/rest/company-vendors#list-company-vendors)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_id` | query | `string` | no |
| `page` | query | `string` | no |
| `per_page` | query | `string` | no |
