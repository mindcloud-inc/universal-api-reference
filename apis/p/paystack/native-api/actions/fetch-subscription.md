# Fetch Subscription with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription/:subscriptionIdOrCode`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Subscription](https://paystack.com/docs/api/subscription/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionIdOrCode` | path | `string` | yes |
