# Fetch Transaction with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/:transactionId`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Transaction](https://paystack.com/docs/api/transaction/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transactionId` | path | `number` | yes |
