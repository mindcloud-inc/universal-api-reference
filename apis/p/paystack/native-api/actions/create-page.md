# Create Page with Paystack

## Endpoint

- **Method:** `POST`
- **Path:** `/page`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Create Page](https://paystack.com/docs/api/page/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
| `amount` | body | `number` | no |
