# Fetch Customer with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:customerCode`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Customer](https://paystack.com/docs/api/customer/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerCode` | path | `string` | yes |
