# List Banks with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/bank`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [List Banks](https://paystack.com/docs/api/miscellaneous/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `country` | query | `string` | no |
| `currency` | query | `string` | no |
