# Fetch Payment Request with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentrequest/:paymentRequestIdOrCode`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Payment Request](https://paystack.com/docs/api/payment-request/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `paymentRequestIdOrCode` | path | `string` | yes |
