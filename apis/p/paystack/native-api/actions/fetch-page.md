# Fetch Page with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/page/:pageIdOrSlug`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Page](https://paystack.com/docs/api/page/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pageIdOrSlug` | path | `string` | yes |
