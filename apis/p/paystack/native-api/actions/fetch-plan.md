# Fetch Plan with Paystack

## Endpoint

- **Method:** `GET`
- **Path:** `/plan/:planIdOrCode`
- **Base URL:** `https://api.paystack.co`
- **Official documentation:** [Fetch Plan](https://paystack.com/docs/api/plan/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planIdOrCode` | path | `string` | yes |
