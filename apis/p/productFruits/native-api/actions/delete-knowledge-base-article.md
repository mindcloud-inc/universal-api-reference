# Delete Knowledge Base Article with Product Fruits

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/knowledgebase/articles/:correlationId`
- **Base URL:** `https://api.productfruits.com`
- **Official documentation:** [Delete Knowledge Base Article](https://help.productfruits.com/en/article/knowledge-base-api-delete-article-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `correlationId` | path | `string` | yes | The correlation ID of the article to delete. |
