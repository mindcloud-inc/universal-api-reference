# Delete User with Product Fruits

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/users/:username`
- **Base URL:** `https://api.productfruits.com`
- **Official documentation:** [Delete User](https://help.productfruits.com/en/article/restp-api-users-management)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Username of the tracked user to delete. |
