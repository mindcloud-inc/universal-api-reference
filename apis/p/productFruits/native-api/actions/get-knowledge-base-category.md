# Get Knowledge Base Category with Product Fruits

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/knowledgebase/categories/:correlationId`
- **Base URL:** `https://api.productfruits.com`
- **Official documentation:** [Get Knowledge Base Category](https://help.productfruits.com/en/article/knowledge-base-api-get-specific-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `correlationId` | path | `string` | yes | The correlation ID of the category. Use a custom ID or an internal ID prefixed with pf_. |
