# Get Employee Sensitive with Paycom

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/employee/:eecode/sensitive`
- **Base URL:** `https://api.paycomonline.net/v4/rest/index.php/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eecode` | path | `string` | yes |
