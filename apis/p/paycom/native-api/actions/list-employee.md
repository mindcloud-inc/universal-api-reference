# List Employee Changed with Paycom

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/employee/:eecode/change`
- **Base URL:** `https://api.paycomonline.net/v4/rest/index.php/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eecode` | path | `string` | no |
| `startdate` | query | `string` | no |
| `enddate` | query | `string` | no |
