# Get Plan IDs with ProfitWell

Retrieves plan IDs from ProfitWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/metrics/plans`
- **Base URL:** `https://api.profitwell.com`
- **Official documentation:** [Get Plan IDs](https://classic.paddle.com/profitwell/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Optionally return up to this many plan IDs. Maximum and default are 150. |
