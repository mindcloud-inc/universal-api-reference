# Retrieve Customer By ID with ProfitWell

Retrieves a customer from ProfitWell by customer ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customers/:customer_id/`
- **Base URL:** `https://api.profitwell.com`
- **Official documentation:** [Retrieve Customer By ID](https://classic.paddle.com/profitwell/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | The data-provider specific customer ID. |
