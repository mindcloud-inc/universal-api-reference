# Get Customer Traits with ProfitWell

Retrieves customer traits from ProfitWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customer_traits/customer/:customer_id/`
- **Base URL:** `https://api.profitwell.com`
- **Official documentation:** [Get Customer Traits](https://classic.paddle.com/profitwell/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | The customer ID to retrieve traits for. |
