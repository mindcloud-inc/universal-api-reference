# Verify Single Email with Pabbly Email Verification

## Endpoint

- **Method:** `POST`
- **Path:** `/email-lists/verify-single`
- **Base URL:** `https://verify.pabbly.com/api/v1`
- **Official documentation:** [Verify Single Email](https://apidocs.pabbly.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to verify. |
