# List Key Logs with Parklio

Retrieves key logs from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/key-logs`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Key Logs](https://api.parklio.com/api#/KEY%20LOGS/KeyLogsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
