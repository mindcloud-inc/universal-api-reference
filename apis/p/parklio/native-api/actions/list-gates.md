# List Gates with Parklio

Retrieves gates from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/gates`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Gates](https://api.parklio.com/api#/GATES/GatesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
