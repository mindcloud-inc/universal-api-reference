# List Parking Places with Parklio

Retrieves parking places from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/parking-places`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Parking Places](https://api.parklio.com/api#/PARKING%20PLACES/ParkingPlacesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
