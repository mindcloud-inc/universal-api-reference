# List Tariffs with Parklio

Retrieves tariffs from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tariffs`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Tariffs](https://api.parklio.com/api#/TARIFFS/TariffsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
