# List Lot Entries with Parklio

Retrieves lot entries from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/lot-entries`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Lot Entries](https://api.parklio.com/api#/LOT%20ENTRIES/LotEntriesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
