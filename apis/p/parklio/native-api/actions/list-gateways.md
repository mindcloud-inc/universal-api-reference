# List Gateways with Parklio

Retrieves gateways from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/gateways`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Gateways](https://api.parklio.com/api#/GATEWAYS/GatewaysController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
