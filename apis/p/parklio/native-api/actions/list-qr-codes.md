# List QR Codes with Parklio

Retrieves QR codes from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/qr-codes`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List QR Codes](https://api.parklio.com/api#/QR%20CODES/QrCodesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
