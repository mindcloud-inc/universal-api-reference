# List Weblinks with Parklio

Retrieves weblinks from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/weblinks`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Weblinks](https://api.parklio.com/api#/WEBLINKS/WeblinksController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
