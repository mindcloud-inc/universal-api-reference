# List Zones with Parklio

Retrieves zones from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/zones`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Zones](https://api.parklio.com/api#/ZONES/ZonesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
