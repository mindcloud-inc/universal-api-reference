# List Products with Parklio

Retrieves products from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/products`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Products](https://api.parklio.com/api#/PRODUCTS/ProductsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
