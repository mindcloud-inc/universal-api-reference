# List Groups with Parklio

Retrieves groups from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/groups`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Groups](https://api.parklio.com/api#/GROUPS/GroupsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
