# Get Lot with Parklio

Retrieves a lot from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/lots/:id`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [Get Lot](https://api.parklio.com/api#/LOTS/LotsController_findOne)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Parklio lot ID. |
