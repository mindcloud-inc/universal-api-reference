# List Devices with Parklio

Retrieves devices from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/devices`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Devices](https://api.parklio.com/api#/DEVICES/DevicesController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
