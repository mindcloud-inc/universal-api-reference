# Get Zone with Parklio

Retrieves a zone from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/zones/:id`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [Get Zone](https://api.parklio.com/api#/ZONES/ZonesController_findOne)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Parklio zone ID. |
