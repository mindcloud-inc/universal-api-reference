# List Terminals with Parklio

Retrieves terminals from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/terminals`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Terminals](https://api.parklio.com/api#/TERMINALS/TerminalsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
