# List Lots with Parklio

Retrieves lots from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/lots`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Lots](https://api.parklio.com/api#/LOTS/LotsController_findAll)

## Capabilities

This operation supports [pagination](../README.md#pagination).
