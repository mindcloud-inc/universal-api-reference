# List Product Errors with Parklio

Retrieves product errors from Parklio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/products/errors`
- **Base URL:** `https://api.parklio.com`
- **Official documentation:** [List Product Errors](https://api.parklio.com/api#/PRODUCTS/ProductsController_findAllProductErrors)

## Capabilities

This operation supports [pagination](../README.md#pagination).
