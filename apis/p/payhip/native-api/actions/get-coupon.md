# Get Coupon with Payhip

Retrieves a coupon from Payhip by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/:coupon_id`
- **Base URL:** `https://payhip.com/api/v2`
- **Official documentation:** [Get Coupon](https://payhip.com/api-reference/coupons/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coupon_id` | path | `number` | yes | The Payhip coupon ID to retrieve. |
