# List Coupons with Payhip

Retrieves a paginated list of coupons from Payhip.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons`
- **Base URL:** `https://payhip.com/api/v2`
- **Official documentation:** [List Coupons](https://payhip.com/api-reference/coupons/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
