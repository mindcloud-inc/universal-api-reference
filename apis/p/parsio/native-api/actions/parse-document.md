# Parse Document with Parsio

## Endpoint

- **Method:** `POST`
- **Path:** `/docs/:document_id/parse`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Parse Document](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Parsio document ID. |
