# Create Mailbox with Parsio

## Endpoint

- **Method:** `POST`
- **Path:** `/mailboxes/create`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Create Mailbox](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Mailbox name. |
