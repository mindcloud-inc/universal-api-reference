# Get Webhook with Parsio

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhook_id`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Get Webhook](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | Parsio webhook ID. |
