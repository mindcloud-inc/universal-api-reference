# Delete Templates with Parsio

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Delete Templates](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids[]` | body | `array<string>` | yes | Template IDs to delete. |
