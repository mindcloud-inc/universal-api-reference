# List Collected Emails with Parsio

## Endpoint

- **Method:** `GET`
- **Path:** `/mailboxes/:mailbox_id/emails`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [List Collected Emails](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailbox_id` | path | `string` | yes | Parsio mailbox ID. |
