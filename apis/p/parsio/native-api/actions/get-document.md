# Get Document with Parsio

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:document_id`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Get Document](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Parsio document ID. |
