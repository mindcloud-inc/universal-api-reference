# Get Template with Parsio

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.parsio.io`
- **Official documentation:** [Get Template](https://help.parsio.io/public-api/parsio-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Parsio template ID. |
