# List Organizers with pretix

Retrieves organizers from pretix.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizers/`
- **Base URL:** `https://pretix.eu/api/v1`
- **Official documentation:** [List Organizers](https://docs.pretix.eu/dev/api/resources/organizers.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
