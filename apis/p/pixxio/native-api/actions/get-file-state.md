# Get File State with pixx.io

Retrieves a file state from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/fileStates/:file_state_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get File State](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_state_id` | path | `number` | yes | The pixx.io file state ID. |
