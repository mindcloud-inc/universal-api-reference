# Get Collection with pixx.io

Retrieves a collection from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collection_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Collection](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `number` | yes | The pixx.io collection ID. |
