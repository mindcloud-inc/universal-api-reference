# Download Synonyms CSV with pixx.io

Downloads synonyms as a CSV from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/synonyms/csv`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Download Synonyms CSV](https://api.pixxio.com/docs/openapi)

## Capabilities

This operation supports [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `csvFieldDelimiter` | query | `string` | no | CSV field delimiter for synonym export. |
