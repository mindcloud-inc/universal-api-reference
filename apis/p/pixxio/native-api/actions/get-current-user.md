# Get Current User with pixx.io

Retrieves the current user from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Current User](https://api.pixxio.com/docs/openapi)
