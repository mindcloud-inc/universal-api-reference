# List Portals with pixx.io

Retrieves portals from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/portals`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Portals](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | query | `string` | no | Language code for portal translations. |
| `name` | query | `string` | no | Filter portals by name. |
