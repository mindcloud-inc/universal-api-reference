# Get Direct Link with pixx.io

Retrieves a direct link from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/directLinks/:id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Direct Link](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The direct link ID. |
