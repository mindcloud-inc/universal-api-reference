# Get Upload Link Basic Info with pixx.io

Retrieves basic upload link info from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploadLinks/basicInfo`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Upload Link Basic Info](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shareKey` | query | `string` | yes | The upload link share key. |
