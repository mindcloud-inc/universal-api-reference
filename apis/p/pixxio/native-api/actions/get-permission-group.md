# Get Permission Group with pixx.io

Retrieves a permission group from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/permissionGroups/:permission_group_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Permission Group](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `permission_group_id` | path | `number` | yes | The pixx.io permission group ID. |
