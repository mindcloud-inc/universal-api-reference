# List Internal Metadata with pixx.io

Retrieves internal metadata from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata/internal`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Internal Metadata](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | no | Search internal metadata fields by term. |
