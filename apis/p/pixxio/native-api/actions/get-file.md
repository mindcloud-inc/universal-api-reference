# Get File with pixx.io

Retrieves a file from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get File](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pixx.io file ID. |
