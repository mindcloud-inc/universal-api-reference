# List Synonyms with pixx.io

Retrieves synonyms from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/synonyms`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Synonyms](https://api.pixxio.com/docs/openapi)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | no | Search synonyms by term. |
