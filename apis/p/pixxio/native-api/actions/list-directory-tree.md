# List Directory Tree with pixx.io

Retrieves the directory tree from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/directories/tree`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Directory Tree](https://api.pixxio.com/docs/openapi)

## Capabilities

This operation supports [sorting](../README.md#sorting).
