# List Important Metadata with pixx.io

Retrieves important metadata from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata/important`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Important Metadata](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `isSearchable` | query | `boolean` | no | Filter important metadata by searchable status. |
