# Get Directory with pixx.io

Retrieves a directory from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/directories/:directory_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Directory](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `directory_id` | path | `number` | yes | The pixx.io directory ID. |
