# Get Custom Metadata with pixx.io

Retrieves a custom metadata field from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata/custom/:custom_metadata_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Custom Metadata](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custom_metadata_id` | path | `number` | yes | The custom metadata ID. |
