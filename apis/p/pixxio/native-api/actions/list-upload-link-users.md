# List Upload Link Users with pixx.io

Retrieves upload link users from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploadLinkUsers`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Upload Link Users](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | query | `string` | no | Search upload link guest users by term. |
