# Get External Share with pixx.io

Retrieves an external share from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/externalShares/:id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get External Share](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The external share ID. |
