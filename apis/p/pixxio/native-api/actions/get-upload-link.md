# Get Upload Link with pixx.io

Retrieves an upload link from your pixx.io workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploadLinks/:uploadlink_id`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [Get Upload Link](https://api.pixxio.com/docs/openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadlink_id` | path | `number` | yes | The upload link ID. |
