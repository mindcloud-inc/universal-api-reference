# List Synonym Columns with pixx.io

Retrieves synonym columns from your pixx.io workspace.

- **Method:** `GET`
- **Path:** `/synonymColumns`
- **Base URL:** `https://mindcloudpixx260413.px.media/api/v1`
- **Official documentation:** [List Synonym Columns](https://api.pixxio.com/docs/openapi)
