# List active workers with Platrum

Retrieves active worker positions from Platrum.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgschema/api/worker/list-active`
- **Base URL:** `https://3e8e7be.platrum.com`
- **Official documentation:** [List active workers](http://api.docs.platrum.ru/modules/orgschema/)
