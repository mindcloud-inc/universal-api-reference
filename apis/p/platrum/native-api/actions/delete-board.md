# Delete board with Platrum

Deletes a board from Platrum.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks/api/board/delete`
- **Base URL:** `https://3e8e7be.platrum.com`
- **Official documentation:** [Delete board](http://api.docs.platrum.ru/modules/tasks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board` | body | `number` | yes | Board ID to delete. |
