# Delete article with Platrum

Deletes a knowledge article from Platrum.

## Endpoint

- **Method:** `POST`
- **Path:** `/wiki/api/article/delete`
- **Base URL:** `https://3e8e7be.platrum.com`
- **Official documentation:** [Delete article](http://api.docs.platrum.ru/modules/wiki/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Article ID to delete. |
