# List articles with Platrum

Retrieves knowledge articles from Platrum.

## Endpoint

- **Method:** `POST`
- **Path:** `/wiki/api/article/list`
- **Base URL:** `https://3e8e7be.platrum.com`
- **Official documentation:** [List articles](http://api.docs.platrum.ru/modules/wiki/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | body | `number` | no | Filter articles by space ID. |
