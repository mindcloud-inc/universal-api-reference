# Get task with Platrum

Retrieves a task from Platrum by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks/api/task/get`
- **Base URL:** `https://3e8e7be.platrum.com`
- **Official documentation:** [Get task](http://api.docs.platrum.ru/modules/tasks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Task ID. |
