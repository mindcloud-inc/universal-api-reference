# Delete Chat with Pushbullet

Deletes an existing chat from Pushbullet.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/chats/:chat_iden`
- **Base URL:** `https://api.pushbullet.com/v2`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chat_iden` | path | `string` | yes | Chat identifier to delete. |
