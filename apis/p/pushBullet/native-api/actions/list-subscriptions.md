# List Subscriptions with Pushbullet

Retrieves subscriptions from your Pushbullet account.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.pushbullet.com/v2`
- **Official documentation:** [List Subscriptions](https://docs.pushbullet.com/v8/#subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
