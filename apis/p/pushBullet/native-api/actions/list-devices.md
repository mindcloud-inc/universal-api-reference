# List Devices with Pushbullet

Retrieves devices from your Pushbullet account.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices`
- **Base URL:** `https://api.pushbullet.com/v2`
- **Official documentation:** [List Devices](https://docs.pushbullet.com/v8/#devices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
