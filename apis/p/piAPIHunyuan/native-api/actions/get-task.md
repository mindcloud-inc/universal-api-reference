# Get Task with PiAPI/Hunyuan

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/task/:taskId`
- **Base URL:** `https://api.piapi.ai`
- **Official documentation:** [Get Task](https://piapi.ai/docs/hunyuan-api/get-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | PiAPI task identifier returned when a Hunyuan task is created. |
