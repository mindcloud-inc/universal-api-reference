# List Pinterest Submissions with Postpone

Retrieves Pinterest submissions from Postpone.

## Endpoint

- **Method:** `POST`
- **Path:** `/gql`
- **Base URL:** `https://api.postpone.app`
- **Official documentation:** [List Pinterest Submissions](https://developers.postpone.app/scheduling-posts/retrieving-posts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.page` | body | `number` | no |
| `variables.limit` | body | `number` | no |
