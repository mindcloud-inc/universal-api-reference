# List Twitter Submissions with Postpone

Retrieves X/Twitter submissions from Postpone.

## Endpoint

- **Method:** `POST`
- **Path:** `/gql`
- **Base URL:** `https://api.postpone.app`
- **Official documentation:** [List Twitter Submissions](https://developers.postpone.app/scheduling-posts/retrieving-posts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.page` | body | `number` | no |
| `variables.limit` | body | `number` | no |
