# List Social Accounts with Postpone

Retrieves social accounts from Postpone.

## Endpoint

- **Method:** `POST`
- **Path:** `/gql`
- **Base URL:** `https://api.postpone.app`
- **Official documentation:** [List Social Accounts](https://developers.postpone.app/examples/example-queries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.platform` | body | `string` | no | Optional platform filter such as reddit, twitter, instagram, facebook, threads, bluesky, linkedin, or pinterest. |
