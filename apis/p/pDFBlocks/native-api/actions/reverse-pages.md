# Reverse Pages with PDF Blocks

Updates a PDF document by reversing page order in PDF Blocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/reverse_pages`
- **Base URL:** `https://api.pdfblocks.com`
- **Official documentation:** [Reverse Pages](https://www.pdfblocks.com/docs/api/reverse-pages-of-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The input PDF document. |
