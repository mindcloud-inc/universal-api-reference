# Remove Restrictions with PDF Blocks

Updates a PDF document by removing restrictions in PDF Blocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/remove_restrictions`
- **Base URL:** `https://api.pdfblocks.com`
- **Official documentation:** [Remove Restrictions](https://www.pdfblocks.com/docs/api/remove-restrictions-from-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The input PDF document. |
