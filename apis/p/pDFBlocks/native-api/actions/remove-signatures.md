# Remove Signatures with PDF Blocks

Updates a PDF document by removing signatures in PDF Blocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/remove_signatures`
- **Base URL:** `https://api.pdfblocks.com`
- **Official documentation:** [Remove Signatures](https://www.pdfblocks.com/docs/api/remove-signatures-from-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | The input PDF document. |
