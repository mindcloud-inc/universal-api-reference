# Get Webhook Endpoint with Pledge

Retrieves a webhook endpoint from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Get Webhook Endpoint](https://developer.pledge.to/api/#tag/Webhook%20Endpoints/operation/getWebhookEndpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint ID. |
