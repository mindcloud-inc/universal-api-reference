# List Donations with Pledge

Retrieves donations from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/donations`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [List Donations](https://developer.pledge.to/api/#tag/Donations/operation/getAllDonations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
