# Get Fundraiser with Pledge

Retrieves a fundraiser from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/fundraisers/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Get Fundraiser](https://developer.pledge.to/api/#tag/Fundraisers/operation/getFundraiser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Fundraiser ID. |
