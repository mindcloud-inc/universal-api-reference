# Get Donation with Pledge

Retrieves a donation from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/donations/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Get Donation](https://developer.pledge.to/api/#tag/Donations/operation/getDonation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Donation ID. |
