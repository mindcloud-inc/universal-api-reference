# List Impact Calculators with Pledge

Retrieves impact calculators from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/impact_calculators`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [List Impact Calculators](https://developer.pledge.to/api/#tag/Impact%20Calculators/operation/getAllImpactCalculators)

## Capabilities

This operation supports [pagination](../README.md#pagination).
