# Get Organization with Pledge

Retrieves an organization from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Get Organization](https://developer.pledge.to/api/#tag/Organizations/operation/getOrganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Organization ID. |
