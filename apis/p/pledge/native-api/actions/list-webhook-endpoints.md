# List Webhook Endpoints with Pledge

Retrieves webhook endpoints from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [List Webhook Endpoints](https://developer.pledge.to/api/#tag/Webhook%20Endpoints/operation/getAllWebhookEndpoints)

## Capabilities

This operation supports [pagination](../README.md#pagination).
