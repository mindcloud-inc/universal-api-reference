# Delete Webhook Endpoint with Pledge

Deletes a webhook endpoint from Pledge.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Delete Webhook Endpoint](https://developer.pledge.to/api/#tag/Webhook%20Endpoints/operation/deleteWebhookEndpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint ID. |
