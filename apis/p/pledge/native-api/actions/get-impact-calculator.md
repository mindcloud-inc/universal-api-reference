# Get Impact Calculator with Pledge

Retrieves an impact calculator from Pledge.

## Endpoint

- **Method:** `GET`
- **Path:** `/impact_calculators/[:id]`
- **Base URL:** `https://api.pledge.to/v1`
- **Official documentation:** [Get Impact Calculator](https://developer.pledge.to/api/#tag/Impact%20Calculators/operation/getImpactCalculator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Impact calculator ID. |
