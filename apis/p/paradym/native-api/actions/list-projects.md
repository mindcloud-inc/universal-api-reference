# List Projects with Paradym

Retrieves a list of projects from Paradym.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [List Projects](https://paradym.id/reference#tag/projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
