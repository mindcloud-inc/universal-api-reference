# Archive Sd-Jwt Vc Credential Template with Paradym

Archives an SD-JWT VC credential template in Paradym.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId/templates/credentials/sd-jwt-vc/:credentialTemplateId`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [Archive Sd-Jwt Vc Credential Template](https://paradym.id/reference#tag/sd-jwt-vc-credential-templates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `credentialTemplateId` | path | `string` | yes |
