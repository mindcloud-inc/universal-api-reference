# Archive Mdoc Credential Template with Paradym

Archives an mdoc credential template in Paradym.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId/templates/credentials/mdoc/:credentialTemplateId`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [Archive Mdoc Credential Template](https://paradym.id/reference#tag/mdoc-credential-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `credentialTemplateId` | path | `string` | yes | Template to archive. |
