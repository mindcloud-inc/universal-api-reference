# Archive Presentation Template with Paradym

Archives a presentation template in Paradym.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId/templates/presentations/:presentationTemplateId`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [Archive Presentation Template](https://paradym.id/reference#tag/presentation-templates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `presentationTemplateId` | path | `string` | yes |
