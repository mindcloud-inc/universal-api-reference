# List Sd-Jwt Vc Credential Templates with Paradym

Retrieves SD-JWT VC credential templates from Paradym.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/templates/credentials/sd-jwt-vc`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [List Sd-Jwt Vc Credential Templates](https://paradym.id/reference#tag/sd-jwt-vc-credential-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search[name]` | query | `string` | no | Search credential templates by name. |
