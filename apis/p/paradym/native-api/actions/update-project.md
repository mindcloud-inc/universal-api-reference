# Update Project with Paradym

Updates an existing project in Paradym.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [Update Project](https://paradym.id/reference#tag/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The project name. |
