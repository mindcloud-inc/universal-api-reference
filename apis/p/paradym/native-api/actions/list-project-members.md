# List Project Members with Paradym

Retrieves project members from Paradym.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/members`
- **Base URL:** `https://api.paradym.id/v1`
- **Official documentation:** [List Project Members](https://paradym.id/reference#tag/projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
