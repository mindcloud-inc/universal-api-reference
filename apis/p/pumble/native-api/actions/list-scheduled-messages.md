# List Scheduled Messages with Pumble

Retrieves scheduled messages from Pumble.

## Endpoint

- **Method:** `GET`
- **Path:** `/fetchScheduledMessages`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [List Scheduled Messages](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channelId` | query | `string` | no |
| `cursor` | query | `string` | no |
| `limit` | query | `number` | no |
