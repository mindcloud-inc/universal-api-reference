# List Channel Messages with Pumble

Retrieves messages from a Pumble channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/listMessages`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [List Channel Messages](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel` | query | `string` | no |
| `channelId` | query | `string` | no |
| `cursor` | query | `string` | no |
| `limit` | query | `number` | no |
| `strategy` | query | `string` | no |
