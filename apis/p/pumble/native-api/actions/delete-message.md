# Delete Message with Pumble

Deletes a message from Pumble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deleteMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Delete Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel` | query | `string` | no |
| `channelId` | query | `string` | no |
| `messageId` | query | `string` | yes |
