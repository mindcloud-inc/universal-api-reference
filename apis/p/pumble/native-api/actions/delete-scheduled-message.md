# Delete Scheduled Message with Pumble

Deletes a scheduled message from Pumble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deleteScheduledMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Delete Scheduled Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scheduledMessageId` | query | `string` | yes |
