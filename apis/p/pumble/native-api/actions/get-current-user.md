# Get Current User with Pumble

Retrieves current user details from Pumble.

## Endpoint

- **Method:** `GET`
- **Path:** `/myInfo`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Get Current User](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)
