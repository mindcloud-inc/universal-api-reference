# Get Scheduled Message with Pumble

Retrieves a scheduled message from Pumble by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/fetchScheduledMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Get Scheduled Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scheduledMessageId` | query | `string` | yes |
