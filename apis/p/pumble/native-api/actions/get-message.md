# Get Message with Pumble

Retrieves a message from Pumble by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/fetchMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Get Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel` | query | `string` | no |
| `channelId` | query | `string` | no |
| `messageId` | query | `string` | yes |
