# Update Message with Pumble

Updates the text of a Pumble message.

## Endpoint

- **Method:** `POST`
- **Path:** `/editMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Update Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channelId` | body | `string` | no |
| `messageId` | body | `string` | no |
| `text` | body | `string` | no |
