# Get Channel with Pumble

Retrieves a channel from Pumble by ID or name.

## Endpoint

- **Method:** `GET`
- **Path:** `/getChannel`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Get Channel](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel` | query | `string` | no |
| `channelId` | query | `string` | no |
