# List User Groups with Pumble

Retrieves user groups from a Pumble workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/listUserGroups`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [List User Groups](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)
