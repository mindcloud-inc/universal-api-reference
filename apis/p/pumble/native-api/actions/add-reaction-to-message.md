# Add Reaction to Message with Pumble

Adds a reaction to a Pumble message.

## Endpoint

- **Method:** `POST`
- **Path:** `/addReaction`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Add Reaction to Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `messageId` | body | `string` | no |
| `reaction` | body | `string` | no |
