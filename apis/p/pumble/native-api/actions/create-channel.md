# Create Channel with Pumble

Creates a new channel in Pumble.

## Endpoint

- **Method:** `POST`
- **Path:** `/createChannel`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Create Channel](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `name` | body | `string` | no |
| `type` | body | `string` | no |
