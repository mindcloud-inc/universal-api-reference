# Reply to Message with Pumble

Creates a reply to a Pumble channel message.

## Endpoint

- **Method:** `POST`
- **Path:** `/sendReply`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Reply to Message](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `asBot` | body | `boolean` | no |
| `channel` | body | `string` | no |
| `channelId` | body | `string` | no |
| `messageId` | body | `string` | no |
| `text` | body | `string` | no |
