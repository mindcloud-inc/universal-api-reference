# List Channels with Pumble

Retrieves channels from Pumble.

## Endpoint

- **Method:** `GET`
- **Path:** `/listChannels`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [List Channels](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)
