# Remove User from Channel with Pumble

Removes a user from a Pumble channel.

## Endpoint

- **Method:** `POST`
- **Path:** `/removeUserFromChannel`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Remove User from Channel](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channelId` | body | `string` | no |
| `userId` | body | `string` | no |
