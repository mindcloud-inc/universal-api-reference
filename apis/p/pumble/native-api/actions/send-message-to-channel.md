# Send Message to Channel with Pumble

Creates a new message in a Pumble channel.

## Endpoint

- **Method:** `POST`
- **Path:** `/sendMessage`
- **Base URL:** `https://pumble-api-keys.addons.marketplace.cake.com`
- **Official documentation:** [Send Message to Channel](https://pumble-api-keys.addons.marketplace.cake.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `asBot` | body | `boolean` | no |
| `channel` | body | `string` | no |
| `channelId` | body | `string` | no |
| `text` | body | `string` | no |
