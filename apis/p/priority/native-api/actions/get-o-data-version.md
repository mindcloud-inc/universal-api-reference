# Get OData Version with Priority

Retrieves the OData version from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetODataVersion()`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get OData Version](https://prioritysoftware.github.io/restapi/request/#Request_Priority_Version)
