# Get Document Type with Priority

Retrieves a document type from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/DOCTYPES(TYPE=':type')`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Document Type](https://prioritysoftware.github.io/restapi/request/#Requesting_an_Individual_Entity_by_ID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TYPE` | path | `string` | yes | Priority document type key. |
