# Get Part with Priority

Retrieves a part from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/PART(PARTNAME=':partName')`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Part](https://prioritysoftware.github.io/restapi/request/#Requesting_an_Individual_Entity_by_ID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PARTNAME` | path | `string` | yes | Priority part key. |
