# Get Country with Priority

Retrieves a country from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/COUNTRIES(COUNTRYNAME=':countryName')`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Country](https://prioritysoftware.github.io/restapi/request/#Requesting_an_Individual_Entity_by_ID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `COUNTRYNAME` | path | `string` | yes | Priority country key. |
