# List Document Types with Priority

Retrieves document types from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/DOCTYPES`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [List Document Types](https://prioritysoftware.github.io/restapi/request/#Requesting_Entity_Collections)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
