# Get Tenant Details with Priority

Retrieves tenant details from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetTenantDetails()`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Tenant Details](https://prioritysoftware.github.io/restapi/request/)
