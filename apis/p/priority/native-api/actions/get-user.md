# Get User with Priority

Retrieves a user from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/USERS(USERLOGIN=':userLogin')`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get User](https://prioritysoftware.github.io/restapi/request/#Requesting_an_Individual_Entity_by_ID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `USERLOGIN` | path | `string` | yes | Priority user login key. |
