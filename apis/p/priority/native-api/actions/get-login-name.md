# Get Login Name with Priority

Retrieves the current login name from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetLoginName()`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Login Name](https://prioritysoftware.github.io/restapi/request/)
