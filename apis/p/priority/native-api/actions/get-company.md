# Get Company with Priority

Retrieves a company from Priority.

## Endpoint

- **Method:** `GET`
- **Path:** `/COMPANIES(COMPANYNAME=':companyName')`
- **Base URL:** `https://t.eu.priority-connect.online/odata/Priority/tabbtd38.ini/usdemo`
- **Official documentation:** [Get Company](https://prioritysoftware.github.io/restapi/request/#Requesting_an_Individual_Entity_by_ID)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `COMPANYNAME` | path | `string` | yes | Priority company key. |
