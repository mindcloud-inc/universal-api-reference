# Get Contact By Id with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/:id`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Get Contact By Id](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Pitchbox contact identifier |
