# Get Campaign Outreach Settings with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/campaigns/:campaignId/outreach_settings`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Get Campaign Outreach Settings](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Pitchbox campaign identifier |
