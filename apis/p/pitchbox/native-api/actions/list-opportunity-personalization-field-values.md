# List Opportunity Personalization Field Values with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/opportunities/:opportunityId/personalization`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [List Opportunity Personalization Field Values](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `opportunityId` | path | `number` | yes | The opportunity id. |
