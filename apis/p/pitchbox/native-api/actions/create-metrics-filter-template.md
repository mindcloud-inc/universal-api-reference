# Create Metrics Filter Template with Pitchbox

## Endpoint

- **Method:** `POST`
- **Path:** `/api/metric_filter_templates`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Create Metrics Filter Template](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The metrics filter template name. |
| `visibility` | body | `string` | no | The metrics filter template visibility. |
