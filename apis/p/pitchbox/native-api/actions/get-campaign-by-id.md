# Get Campaign By Id with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/campaigns/:id`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Get Campaign By Id](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The campaign id. |
