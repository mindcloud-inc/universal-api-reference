# List Personalization Fields with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/personalization`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [List Personalization Fields](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project.id` | query | `number` | yes | Filtering by project.id |
| `campaign.id` | query | `number` | no | Filtering by campaign.id |
