# List Opportunities with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/opportunities`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [List Opportunities](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign.id` | query | `string` | no | Filter by campaign.id. |
| `include_contacts` | query | `string` | no | Include opportunity contacts in the response. |
| `project.id` | query | `string` | no | Filter by project.id. |
