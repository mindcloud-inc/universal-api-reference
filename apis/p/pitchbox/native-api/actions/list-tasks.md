# List Tasks with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tasks`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [List Tasks](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project.id` | query | `string` | yes | Filter tasks by Pitchbox project identifier |
