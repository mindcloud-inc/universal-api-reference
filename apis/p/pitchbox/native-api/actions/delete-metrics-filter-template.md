# Delete Metrics Filter Template with Pitchbox

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/metric_filter_templates/:id`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Delete Metrics Filter Template](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The metrics filter template id. |
