# Get Opportunity By Id with Pitchbox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/opportunities/:id`
- **Base URL:** `https://apiv2.pitchbox.com`
- **Official documentation:** [Get Opportunity By Id](https://apiv2.pitchbox.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The opportunity id. |
