# Unread Notification Count with ProjectManager

Retrieves unread notification count from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/notifications/unreadcount`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Unread Notification Count](https://developer.projectmanager.com/api-reference/notification/unread-notification-count)
