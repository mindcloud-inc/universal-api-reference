# Retrieve Resource with ProjectManager

Retrieves a resource from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/resources/:resourceId`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Retrieve Resource](https://developer.projectmanager.com/api-reference/resource/retrieve-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | The id of the Resource |
