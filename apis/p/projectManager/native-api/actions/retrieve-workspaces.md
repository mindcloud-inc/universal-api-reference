# Retrieve Workspaces with ProjectManager

Retrieves workspaces from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/workspaces`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Retrieve Workspaces](https://developer.projectmanager.com/api-reference/work-space/retrieve-workspaces)
