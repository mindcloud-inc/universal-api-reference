# Get Meeting with ProjectManager

Retrieves a meeting from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/meetings/:meetingId`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Get Meeting](https://developer.projectmanager.com/api-reference/meetings/get-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | the id of the meeting |
