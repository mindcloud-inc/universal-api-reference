# Create Or Update TaskAssignee with ProjectManager

Creates or updates task assignees in ProjectManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/data/tasks/:taskId/assignees`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Create Or Update TaskAssignee](https://developer.projectmanager.com/api-reference/task-assignee/create-or-update-task-assignee)
