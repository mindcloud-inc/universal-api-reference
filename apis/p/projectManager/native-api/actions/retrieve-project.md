# Retrieve Project with ProjectManager

Retrieves a project from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/projects/:projectId`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Retrieve Project](https://developer.projectmanager.com/api-reference/project/retrieve-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The unique identifier of the Project to retrieve. |
