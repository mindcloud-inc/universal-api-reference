# Retrieve Task with ProjectManager

Retrieves a task from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/tasks/:taskId`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Retrieve Task](https://developer.projectmanager.com/api-reference/task/retrieve-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The unique identifier or short ID of the Task to retrieve |
