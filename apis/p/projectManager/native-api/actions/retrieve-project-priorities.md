# Retrieve Project Priorities with ProjectManager

Retrieves project priorities from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/projects/priorities`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Retrieve Project Priorities](https://developer.projectmanager.com/api-reference/project-priority/retrieve-project-priorities)
