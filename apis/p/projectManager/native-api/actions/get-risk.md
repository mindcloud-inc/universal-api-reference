# Get Risk with ProjectManager

Retrieves a risk from ProjectManager.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/risks/:riskId`
- **Base URL:** `https://api.projectmanager.com`
- **Official documentation:** [Get Risk](https://developer.projectmanager.com/api-reference/risk/get-risk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `riskId` | path | `string` | yes | The id of the risk |
