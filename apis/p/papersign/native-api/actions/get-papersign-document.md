# Get Papersign Document with Papersign

## Endpoint

- **Method:** `GET`
- **Path:** `/papersign/documents/:id`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Get Papersign Document](https://paperform.readme.io/reference/getpapersigndocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Papersign document ID. |
