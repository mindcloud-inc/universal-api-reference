# Copy Papersign Document with Papersign

## Endpoint

- **Method:** `POST`
- **Path:** `/papersign/documents/:id/copy`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Copy Papersign Document](https://paperform.readme.io/reference/papersigncopydocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Papersign document ID. |
