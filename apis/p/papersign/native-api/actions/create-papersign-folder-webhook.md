# Create Papersign Folder Webhook with Papersign

## Endpoint

- **Method:** `POST`
- **Path:** `/papersign/folders/:id/webhooks`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Create Papersign Folder Webhook](https://paperform.readme.io/reference/postpapersignfolderwebhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Papersign folder ID. |
