# Update Papersign Folder Webhook with Papersign

## Endpoint

- **Method:** `PUT`
- **Path:** `/papersign/webhooks/:id`
- **Base URL:** `https://api.paperform.co/v1`
- **Official documentation:** [Update Papersign Folder Webhook](https://paperform.readme.io/reference/putpapersignfolderwebhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Papersign webhook ID. |
