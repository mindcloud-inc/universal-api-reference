# Get Action Automation with Port API AI

Retrieves an action automation from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/:action_identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Action Automation](https://docs.port.io/api-reference/get-an-action-automation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_identifier` | path | `string` | yes | The action identifier. |
