# Update Integration with Port API AI

Updates an integration in Port.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/integration/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Update Integration](https://docs.port.io/api-reference/update-an-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port integration identifier. |
