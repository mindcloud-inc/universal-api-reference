# Get Webhook with Port API AI

Retrieves a webhook from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Webhook](https://docs.port.io/api-reference/get-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port webhook identifier. |
