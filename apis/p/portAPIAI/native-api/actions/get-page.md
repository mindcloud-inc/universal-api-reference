# Get Page with Port API AI

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Page](https://docs.port.io/api-reference/get-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port page identifier. |
