# Get Default LLM Provider with Port API AI

Retrieves the default LLM provider from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/llm-providers/defaults`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Default LLM Provider](https://docs.port.io/api-reference/get-default-llm-provider-and-model)
