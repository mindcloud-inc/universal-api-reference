# List MCP User Servers with Port API AI

Retrieves MCP user servers from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/mcp/user/servers`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [List MCP User Servers](https://docs.port.io/api-reference/get-mcp-servers-for-user)
