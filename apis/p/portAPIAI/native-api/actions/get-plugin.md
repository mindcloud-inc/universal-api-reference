# Get Plugin with Port API AI

Retrieves a plugin from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugins/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Plugin](https://docs.port.io/api-reference/get-a-plugin-by-identifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port plugin identifier. |
