# Get Action Permissions with Port API AI

Retrieves action permissions from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/:action_identifier/permissions`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Action Permissions](https://docs.port.io/api-reference/get-an-actions-permissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_identifier` | path | `string` | yes | The action identifier. |
