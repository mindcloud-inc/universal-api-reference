# Create LLM Provider with Port API AI

Creates an LLM provider in Port.

## Endpoint

- **Method:** `POST`
- **Path:** `/llm-providers`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Create LLM Provider](https://docs.port.io/api-reference/create-or-connect-an-llm-provider)
