# Get Page Permissions with Port API AI

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:page_identifier/permissions`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Page Permissions](https://docs.port.io/api-reference/get-a-pages-permissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_identifier` | path | `string` | yes | The Port page identifier. |
