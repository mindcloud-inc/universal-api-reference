# Delete Plugin with Port API AI

Deletes a plugin from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/plugins/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Plugin](https://docs.port.io/api-reference/delete-a-plugin-by-identifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port plugin identifier. |
