# Get MCP OAuth2 Session Token with Port API AI

## Endpoint

- **Method:** `GET`
- **Path:** `/mcp/oauth2/servers/:server_id/session-token`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get MCP OAuth2 Session Token](https://docs.port.io/api-reference/get-mcp-oauth2-session-token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `server_id` | path | `string` | yes | The MCP server identifier. |
