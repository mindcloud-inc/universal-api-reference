# Delete Team with Port API AI

Deletes a team from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:name`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Team](https://docs.port.io/api-reference/delete-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The Port team name. |
