# Delete Blueprint with Port API AI

Deletes a blueprint from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/blueprints/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Blueprint](https://docs.port.io/api-reference/delete-a-blueprint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port blueprint identifier. |
