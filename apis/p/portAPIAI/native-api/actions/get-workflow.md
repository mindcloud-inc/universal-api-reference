# Get Workflow with Port API AI

Retrieves a workflow from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflow_identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Workflow](https://docs.port.io/api-reference/get-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_identifier` | path | `string` | yes | The Port workflow identifier. |
