# Update User with Port API AI

Updates a user in Port.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/users/:user_email`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Update User](https://docs.port.io/api-reference/update-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_email` | path | `string` | yes | The Port user email. |
