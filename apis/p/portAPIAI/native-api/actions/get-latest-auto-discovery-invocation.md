# Get Latest Auto Discovery Invocation with Port API AI

## Endpoint

- **Method:** `GET`
- **Path:** `/ai/entities-auto-discovery/blueprint/:blueprint_identifier/latest`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Latest Auto Discovery Invocation](https://docs.port.io/api-reference/get-latest-auto-discovery-invocation-for-a-blueprint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blueprint_identifier` | path | `string` | yes | The blueprint identifier. |
