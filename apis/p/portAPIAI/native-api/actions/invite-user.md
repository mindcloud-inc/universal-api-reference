# Invite User with Port API AI

Invites a user to Port.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/invite`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Invite User](https://docs.port.io/api-reference/invite-a-user-to-your-organization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invitee` | body | `object` | yes |
