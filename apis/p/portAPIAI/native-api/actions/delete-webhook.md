# Delete Webhook with Port API AI

Deletes a webhook from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Webhook](https://docs.port.io/api-reference/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port webhook identifier. |
