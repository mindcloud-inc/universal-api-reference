# Delete Page with Port API AI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pages/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Page](https://docs.port.io/api-reference/delete-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port page identifier. |
