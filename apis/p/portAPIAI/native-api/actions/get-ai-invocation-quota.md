# Get AI Invocation Quota with Port API AI

Retrieves AI invocation quota usage from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/quota/ai-invocations`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get AI Invocation Quota](https://docs.port.io/api-reference/get-monthly-ai-invocations-quota-usage)
