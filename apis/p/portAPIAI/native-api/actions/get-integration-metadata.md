# Get Integration Metadata with Port API AI

Retrieves integration metadata from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/metadata`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Integration Metadata](https://www.docs.port.io/api-reference/get-all-integrations-meta-data-member-view)
