# Delete Page Widget with Port API AI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pages/:page_identifier/widgets/:widget_id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Page Widget](https://docs.port.io/api-reference/delete-a-widget/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_identifier` | path | `string` | yes | The page identifier. |
| `widget_id` | path | `string` | yes | The widget identifier. |
