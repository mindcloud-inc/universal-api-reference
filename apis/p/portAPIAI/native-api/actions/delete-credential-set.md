# Delete Credential Set with Port API AI

Deletes a credential set from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/:id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Credential Set](https://docs.port.io/api-reference/delete-credentials)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Port credential set identifier. |
