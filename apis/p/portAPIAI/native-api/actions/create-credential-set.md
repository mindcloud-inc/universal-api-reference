# Create Credential Set with Port API AI

## Endpoint

- **Method:** `POST`
- **Path:** `/apps`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Create Credential Set](https://docs.port.io/api-reference/create-credentials)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Credential set name |
