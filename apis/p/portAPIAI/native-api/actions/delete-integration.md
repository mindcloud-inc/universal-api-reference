# Delete Integration with Port API AI

Deletes an integration from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/integration/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete Integration](https://docs.port.io/api-reference/delete-an-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The integration identifier. |
