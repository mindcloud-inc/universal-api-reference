# Get Auto Discovery Suggestions with Port API AI

## Endpoint

- **Method:** `GET`
- **Path:** `/ai/entities-auto-discovery/:invocation_id/suggestions`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Auto Discovery Suggestions](https://docs.port.io/api-reference/get-auto-discovery-invocation-suggestions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invocation_id` | path | `string` | yes | The auto-discovery invocation identifier. |
