# Get Blueprint with Port API AI

Retrieves a blueprint from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/blueprints/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Blueprint](https://docs.port.io/api-reference/get-a-blueprint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port blueprint identifier. |
