# Get Organization Secret with Port API AI

Retrieves organization secret metadata from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/secrets/:secret_name`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Organization Secret](https://docs.port.io/api-reference/get-an-organization-secrets-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `secret_name` | path | `string` | no | The Port organization secret name. |
