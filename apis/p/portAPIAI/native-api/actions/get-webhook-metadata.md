# Get Webhook Metadata with Port API AI

Retrieves webhook metadata from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/metadata`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Webhook Metadata](https://docs.port.io/api-reference/get-all-webhooks-meta-data-member-view)
