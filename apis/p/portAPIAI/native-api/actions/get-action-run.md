# Get Action Run with Port API AI

Retrieves an action run from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/runs/:run_id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Action Run](https://docs.port.io/api-reference/get-an-action-runs-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Port action run identifier. |
