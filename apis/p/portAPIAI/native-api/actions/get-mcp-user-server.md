# Get MCP User Server with Port API AI

Retrieves an MCP user server from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/mcp/user/servers/:server_id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get MCP User Server](https://docs.port.io/api-reference/get-mcp-server-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `server_id` | path | `string` | yes | The Port MCP server identifier. |
