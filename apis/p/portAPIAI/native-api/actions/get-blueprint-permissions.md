# Get Blueprint Permissions with Port API AI

Retrieves blueprint permissions from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/blueprints/:blueprint_identifier/permissions`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Blueprint Permissions](https://docs.port.io/api-reference/get-a-blueprints-permissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blueprint_identifier` | path | `string` | yes | The blueprint identifier. |
