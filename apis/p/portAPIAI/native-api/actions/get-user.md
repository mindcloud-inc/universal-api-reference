# Get User with Port API AI

Retrieves a user from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_email`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get User](https://docs.port.io/api-reference/get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_email` | path | `string` | yes | The Port user email. |
