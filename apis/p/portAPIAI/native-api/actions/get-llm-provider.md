# Get LLM Provider with Port API AI

Retrieves an LLM provider from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/llm-providers/:provider`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get LLM Provider](https://docs.port.io/api-reference/get-a-specific-provider-configuration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider` | path | `string` | yes | The LLM provider identifier. |
