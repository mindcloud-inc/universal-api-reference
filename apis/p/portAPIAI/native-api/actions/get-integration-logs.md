# Get Integration Logs with Port API AI

Retrieves integration logs from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/:identifier/logs`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Integration Logs](https://docs.port.io/api-reference/get-an-integrations-event-logs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The integration identifier. |
