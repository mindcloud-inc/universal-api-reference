# Update Action Run with Port API AI

Updates an action run in Port.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/actions/runs/:run_id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Update Action Run](https://docs.port.io/api-reference/update-an-action-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Port action run identifier. |
