# Create Auto Discovery Invocation with Port API AI

Creates an auto-discovery invocation in Port.

## Endpoint

- **Method:** `POST`
- **Path:** `/ai/entities-auto-discovery`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Create Auto Discovery Invocation](https://docs.port.io/api-reference/create-an-auto-discovery-invocation)
