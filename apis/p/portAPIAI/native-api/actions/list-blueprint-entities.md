# List Blueprint Entities with Port API AI

Retrieves entities from a Port blueprint.

## Endpoint

- **Method:** `GET`
- **Path:** `/blueprints/:blueprint_identifier/entities`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [List Blueprint Entities](https://docs.port.io/api-reference/get-all-entities-of-a-blueprint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blueprint_identifier` | path | `string` | no | The Port blueprint identifier. |
