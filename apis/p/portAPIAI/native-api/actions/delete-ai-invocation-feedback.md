- **Method:** `DELETE`
- **Path:** `/ai/invoke/:invocation_identifier/feedback`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete AI Invocation Feedback](https://docs.port.io/api-reference/delete-ai-invocation-feedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invocation_identifier` | path | `string` | yes | The AI invocation identifier. |
