# Get AI Invocation with Port API AI

Retrieves an AI invocation from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai/invoke/:invocation_identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get AI Invocation](https://docs.port.io/api-reference/get-an-invocations-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invocation_identifier` | path | `string` | yes | The AI invocation identifier. |
