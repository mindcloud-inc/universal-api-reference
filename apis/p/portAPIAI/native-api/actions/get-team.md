# Get Team with Port API AI

Retrieves a team from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:name`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Team](https://docs.port.io/api-reference/get-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The Port team name. |
