# Get Plugin Upload URL with Port API AI

Retrieves a plugin upload URL from Port.

## Endpoint

- **Method:** `POST`
- **Path:** `/plugins/upload-url`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Plugin Upload URL](https://docs.port.io/api-reference/get-a-presigned-url-for-uploading-a-plugin)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
