# Get Migration with Port API AI

Retrieves a migration from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/migrations/:migration_id`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Migration](https://docs.port.io/api-reference/get-a-migration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `migration_id` | path | `string` | yes | The Port migration identifier. |
