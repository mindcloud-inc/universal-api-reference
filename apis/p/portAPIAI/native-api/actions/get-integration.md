# Get Integration with Port API AI

Retrieves an integration from Port.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/:identifier`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Get Integration](https://docs.port.io/api-reference/get-an-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Port integration identifier. |
