# Delete LLM Provider with Port API AI

Deletes an LLM provider from Port.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/llm-providers/:provider`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Delete LLM Provider](https://docs.port.io/api-reference/delete-a-specific-provider-configuration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider` | path | `string` | yes | The LLM provider identifier. |
