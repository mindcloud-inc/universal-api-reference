# Update Action Permissions with Port API AI

Updates action permissions in Port.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/actions/:action_identifier/permissions`
- **Base URL:** `https://api.port.io/v1`
- **Official documentation:** [Update Action Permissions](https://docs.port.io/api-reference/update-an-actions-permissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action_identifier` | path | `string` | yes | The action identifier. |
