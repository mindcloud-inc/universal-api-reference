# List Webhooks with Pixela

Retrieves all webhook definitions from Pixela.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:username/webhooks`
- **Base URL:** `https://pixe.la`
- **Official documentation:** [List Webhooks](https://docs.pixe.la/entry/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Pixela username in the request path. |
