# Get User with ProProfs Project

Retrieves a user from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{{user_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get User](https://help.proprofsproject.com/company-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID to fetch. |
