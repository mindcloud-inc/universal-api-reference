# Get Task with ProProfs Project

Retrieves a task from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/{{task_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Task](https://help.proprofsproject.com/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The task ID to fetch. |
