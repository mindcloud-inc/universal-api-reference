# Delete Project with ProProfs Project

Deletes an existing project from ProProfs Project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{{project_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Delete Project](https://help.proprofsproject.com/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The project ID to delete. |
