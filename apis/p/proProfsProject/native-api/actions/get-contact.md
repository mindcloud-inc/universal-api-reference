# Get Contact with ProProfs Project

Retrieves a contact from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{{contact_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Contact](https://help.proprofsproject.com/managing-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The contact ID to fetch. |
