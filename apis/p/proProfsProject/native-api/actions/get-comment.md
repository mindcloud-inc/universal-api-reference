# Get Comment with ProProfs Project

Retrieves a comment from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/{{comment_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Comment](https://help.proprofsproject.com/managing-comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `comment_id` | path | `string` | yes | The comment ID to fetch. |
