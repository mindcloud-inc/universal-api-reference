# Delete Contact with ProProfs Project

Deletes an existing contact from ProProfs Project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{contact_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Delete Contact](https://help.proprofsproject.com/managing-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The contact ID to delete. |
