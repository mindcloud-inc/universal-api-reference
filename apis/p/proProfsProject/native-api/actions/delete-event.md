# Delete Event with ProProfs Project

Deletes an existing event from ProProfs Project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/{{event_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Delete Event](https://help.proprofsproject.com/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | The event ID to delete. |
