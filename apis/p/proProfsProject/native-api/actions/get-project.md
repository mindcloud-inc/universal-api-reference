# Get Project with ProProfs Project

Retrieves a project from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{{project_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Project](https://help.proprofsproject.com/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The project ID to fetch. |
