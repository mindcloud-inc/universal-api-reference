# Get Subtask with ProProfs Project

Retrieves a subtask from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/subtasks/{{subtask_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Subtask](https://help.proprofsproject.com/subtasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subtask_id` | path | `string` | yes | The subtask ID to fetch. |
