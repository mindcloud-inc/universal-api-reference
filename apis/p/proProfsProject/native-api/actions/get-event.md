# Get Event with ProProfs Project

Retrieves an event from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{{event_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Event](https://help.proprofsproject.com/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | The event ID to fetch. |
