# Get Client with ProProfs Project

Retrieves a client from ProProfs Project.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{{client_id}}`
- **Base URL:** `https://api.projectbubble.com/v2`
- **Official documentation:** [Get Client](https://help.proprofsproject.com/clients-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | The client ID to fetch. |
