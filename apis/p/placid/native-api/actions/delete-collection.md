# Delete Collection with Placid

Deletes an existing collection from Placid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/rest/collections/:collectionId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Delete Collection](https://placid.app/docs/2.0/rest/collections#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | ID of the collection to delete. |
