# Delete PDF with Placid

Deletes a PDF render from Placid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/rest/pdfs/:pdfId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Delete PDF](https://placid.app/docs/2.0/rest/pdfs#delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pdfId` | path | `number` | yes |
