# Delete Template with Placid

Deletes an existing template from Placid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/rest/templates/:templateUuid`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Delete Template](https://placid.app/docs/2.0/rest/templates#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateUuid` | path | `string` | yes | UUID of the template to delete. |
