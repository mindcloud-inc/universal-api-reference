# Get Collection with Placid

Retrieves a collection from Placid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/collections/:collectionId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Get Collection](https://placid.app/docs/2.0/rest/collections#show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | ID of the collection to retrieve. |
