# Get PDF with Placid

Retrieves a PDF render from Placid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/pdfs/:pdfId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Get PDF](https://placid.app/docs/2.0/rest/pdfs#show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pdfId` | path | `number` | yes |
