# Get Video with Placid

Retrieves a video render from Placid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/videos/:videoId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Get Video](https://placid.app/docs/2.0/rest/videos#show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `videoId` | path | `number` | yes |
