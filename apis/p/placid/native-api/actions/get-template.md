# Get Template with Placid

Retrieves a template from Placid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/templates/:templateUuid`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Get Template](https://placid.app/docs/2.0/rest/templates#show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateUuid` | path | `string` | yes | UUID of the template to retrieve. |
