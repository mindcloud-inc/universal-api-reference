# Get Image with Placid

Retrieves an image render from Placid.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/images/:imageId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Get Image](https://placid.app/docs/2.0/rest/images#show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `imageId` | path | `number` | yes |
