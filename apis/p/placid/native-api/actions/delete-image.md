# Delete Image with Placid

Deletes an image render from Placid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/rest/images/:imageId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Delete Image](https://placid.app/docs/2.0/rest/images#delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `imageId` | path | `number` | yes |
