# Delete Video with Placid

Deletes a video render from Placid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/rest/videos/:videoId`
- **Base URL:** `https://api.placid.app`
- **Official documentation:** [Delete Video](https://placid.app/docs/2.0/rest/videos#delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `videoId` | path | `number` | yes |
