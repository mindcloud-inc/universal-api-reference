# Get Transformation Context with PixelBin.io

Retrieves transformation context from a PixelBin.io URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/transformation/context`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Transformation Context](https://www.pixelbin.io/docs/context/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | no | PixelBin CDN URL with transformation steps applied. |
