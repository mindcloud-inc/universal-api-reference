# Get Current Usage with PixelBin.io

Retrieves current usage details from PixelBin.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/payment/v1.0/usage`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Current Usage](https://www.pixelbin.io/docs/billing-and-payments/)
