# Delete Transformation Module Credentials with PixelBin.io

Deletes transformation module credentials from PixelBin.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service/platform/assets/v1.0/credentials/:pluginId`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Delete Transformation Module Credentials](https://www.pixelbin.io/docs/playground/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pluginId` | path | `string` | yes | Transformation module identifier whose credentials you want to delete. |
