# Create Folder with PixelBin.io

Creates a new folder in PixelBin.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/service/platform/assets/v1.0/folders`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Create Folder](https://www.pixelbin.io/docs/storage/miscellaneous/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `path` | body | `string` | yes |
