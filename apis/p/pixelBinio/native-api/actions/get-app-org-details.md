# Get App Org Details with PixelBin.io

Retrieves app and organization details from PixelBin.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/organization/v1.0/apps/info`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get App Org Details](https://www.pixelbin.io/docs/organization/)
