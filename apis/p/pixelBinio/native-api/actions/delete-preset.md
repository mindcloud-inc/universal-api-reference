# Delete Preset with PixelBin.io

Deletes an existing preset from PixelBin.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service/platform/assets/v1.0/presets/:presetName`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Delete Preset](https://www.pixelbin.io/docs/presets/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `presetName` | path | `string` | yes |
