# Delete Folder with PixelBin.io

Deletes an existing folder from PixelBin.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service/platform/assets/v1.0/folders/:_id`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Delete Folder](https://www.pixelbin.io/docs/storage/miscellaneous/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `_id` | path | `string` | yes |
