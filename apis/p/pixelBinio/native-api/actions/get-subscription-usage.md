# Get Subscription Usage with PixelBin.io

Retrieves subscription usage details from PixelBin.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/payment/v1.0/usage/subscription`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Subscription Usage](https://www.pixelbin.io/docs/billing-and-payments/)
