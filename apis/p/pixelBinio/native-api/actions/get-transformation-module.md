# Get Transformation Module with PixelBin.io

Retrieves a transformation module from PixelBin.io playground.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/assets/v1.0/playground/plugins/:identifier`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Transformation Module](https://www.pixelbin.io/docs/playground/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Transformation module identifier returned by List Transformation Modules. |
