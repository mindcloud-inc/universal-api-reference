# List Transformation Modules with PixelBin.io

Retrieves transformation modules from the PixelBin.io playground.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/assets/v1.0/playground/plugins`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [List Transformation Modules](https://www.pixelbin.io/docs/playground/)
