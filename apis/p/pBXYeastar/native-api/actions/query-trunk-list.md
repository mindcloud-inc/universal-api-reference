# Query Trunk List with PBX Yeastar

Retrieves a list of trunks from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/trunk/list`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query Trunk List](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-trunk-list.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
