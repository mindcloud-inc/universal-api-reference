# Query Company Contact List with PBX Yeastar

Retrieves a list of company contacts from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/company_contact/list`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query Company Contact List](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-company-contacts-list.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
