# Query Extension List with PBX Yeastar

Retrieves a list of extensions from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/extension/list`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query Extension List](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-extension-list.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
