# Query PBX Information with PBX Yeastar

Retrieves PBX information from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/system/information`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query PBX Information](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-pbx-information.html)
