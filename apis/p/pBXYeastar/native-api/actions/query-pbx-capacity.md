# Query PBX Capacity with PBX Yeastar

Retrieves PBX capacity details from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/system/capacity`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query PBX Capacity](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-pbx-capacity.html)
