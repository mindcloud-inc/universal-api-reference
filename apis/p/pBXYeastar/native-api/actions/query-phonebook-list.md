# Query Phonebook List with PBX Yeastar

Retrieves a list of phonebooks from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonebook/list`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query Phonebook List](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-phonebook-list.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
