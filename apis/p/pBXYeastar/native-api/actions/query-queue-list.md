# Query Queue List with PBX Yeastar

Retrieves a list of queues from PBX Yeastar.

## Endpoint

- **Method:** `GET`
- **Path:** `/queue/list`
- **Base URL:** `{baseUrl}/openapi/v1.0`
- **Official documentation:** [Query Queue List](https://help.yeastar.com/en/p-series-cloud-edition/developer-guide/query-queue-list.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
