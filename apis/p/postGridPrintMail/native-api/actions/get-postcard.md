# Get Postcard with PostGrid Print & Mail

Retrieves a postcard from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/postcards/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Postcard](https://postgrid.readme.io/reference/postcards_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
