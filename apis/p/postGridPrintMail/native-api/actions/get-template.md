# Get Template with PostGrid Print & Mail

Retrieves a template from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Template](https://postgrid.readme.io/reference/templates_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
