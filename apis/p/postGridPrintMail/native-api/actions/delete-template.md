# Delete Template with PostGrid Print & Mail

Deletes a template from PostGrid Print & Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Delete Template](https://postgrid.readme.io/reference/templates_delete-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
