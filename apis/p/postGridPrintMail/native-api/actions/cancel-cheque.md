# Cancel Cheque with PostGrid Print & Mail

Cancels a cheque in PostGrid Print & Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cheques/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Cancel Cheque](https://postgrid.readme.io/reference/cheques_delete-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
