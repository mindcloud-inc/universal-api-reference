# List Bank Accounts with PostGrid Print & Mail

Retrieves bank accounts from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/bank_accounts`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [List Bank Accounts](https://postgrid.readme.io/reference/bankaccounts_list-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter results by a free-text search string. |
