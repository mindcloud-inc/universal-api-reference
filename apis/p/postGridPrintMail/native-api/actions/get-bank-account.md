# Get Bank Account with PostGrid Print & Mail

Retrieves a bank account from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/bank_accounts/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Bank Account](https://postgrid.readme.io/reference/bankaccounts_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
