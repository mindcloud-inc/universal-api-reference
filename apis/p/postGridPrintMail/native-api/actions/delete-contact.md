# Delete Contact with PostGrid Print & Mail

Deletes a contact from PostGrid Print & Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Delete Contact](https://postgrid.readme.io/reference/contacts_delete-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
