# Cancel Letter with PostGrid Print & Mail

Cancels a letter in PostGrid Print & Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/letters/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Cancel Letter](https://postgrid.readme.io/reference/letters_delete-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
