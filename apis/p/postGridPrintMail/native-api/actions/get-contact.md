# Get Contact with PostGrid Print & Mail

Retrieves a contact from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Contact](https://postgrid.readme.io/reference/contacts_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
