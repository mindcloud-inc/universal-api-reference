# Get Cheque with PostGrid Print & Mail

Retrieves a cheque from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/cheques/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Cheque](https://postgrid.readme.io/reference/cheques_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
