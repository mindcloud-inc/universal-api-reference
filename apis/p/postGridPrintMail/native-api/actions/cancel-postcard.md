# Cancel Postcard with PostGrid Print & Mail

Cancels a postcard in PostGrid Print & Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/postcards/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Cancel Postcard](https://postgrid.readme.io/reference/postcards_delete-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
