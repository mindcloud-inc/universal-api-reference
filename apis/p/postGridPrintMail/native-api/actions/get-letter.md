# Get Letter with PostGrid Print & Mail

Retrieves a letter from PostGrid Print & Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/letters/{{id}}`
- **Base URL:** `https://api.postgrid.com/print-mail/v1`
- **Official documentation:** [Get Letter](https://postgrid.readme.io/reference/letters_get-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
