# Authenticate With Username And Password with ProxiedMail

## Endpoint

- **Method:** `POST`
- **Path:** `/auth`
- **Base URL:** `https://proxiedmail.com/api/v1`
- **Official documentation:** [Authenticate With Username And Password](https://docs.proxiedmail.com/docs/endpoints/login/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `username` | body | `string` | yes |
| `password` | body | `string` | yes |
