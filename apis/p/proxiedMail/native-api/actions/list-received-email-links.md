# List Received Email Links with ProxiedMail

## Endpoint

- **Method:** `GET`
- **Path:** `/received-emails-links/:proxyBindingId`
- **Base URL:** `https://proxiedmail.com/api/v1`
- **Official documentation:** [List Received Email Links](https://docs.proxiedmail.com/docs/endpoints/receivedemailslinks/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `proxyBindingId` | path | `string` | yes |
