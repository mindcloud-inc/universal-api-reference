# Get Received Email Details with ProxiedMail

## Endpoint

- **Method:** `GET`
- **Path:** `/received-emails/:receivedEmailId`
- **Base URL:** `https://proxiedmail.com/api/v1`
- **Official documentation:** [Get Received Email Details](https://docs.proxiedmail.com/docs/endpoints/getreceivedemails/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `receivedEmailId` | path | `string` | yes |
