# Delete Page with Papyrs

## Endpoint

- **Method:** `POST`
- **Path:** `/pages/delete/:page_id/`
- **Base URL:** `https://{subdomain}.papyrs.com/api/v1`
- **Official documentation:** [Delete Page](https://papyrs.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | The Papyrs page ID. |
