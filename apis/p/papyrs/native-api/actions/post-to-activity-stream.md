# Post To Activity Stream with Papyrs

## Endpoint

- **Method:** `POST`
- **Path:** `/feed/post/`
- **Base URL:** `https://{subdomain}.papyrs.com/api/v1`
- **Official documentation:** [Post To Activity Stream](https://papyrs.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `msg` | body | `string` | yes | The message to post to the activity stream. |
