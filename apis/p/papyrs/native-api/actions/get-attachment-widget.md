# Get Attachment Widget with Papyrs

## Endpoint

- **Method:** `GET`
- **Path:** `/page/:page_id/attachment/get/:widget_id/`
- **Base URL:** `https://{subdomain}.papyrs.com/api/v1`
- **Official documentation:** [Get Attachment Widget](https://papyrs.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | The Papyrs page ID. |
| `widget_id` | path | `string` | yes | The Papyrs widget ID on the page. |
