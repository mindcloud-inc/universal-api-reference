# Search Results with Papyrs

## Endpoint

- **Method:** `GET`
- **Path:** `/search/query/`
- **Base URL:** `https://{subdomain}.papyrs.com/api/v1`
- **Official documentation:** [Search Results](https://papyrs.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The Papyrs search query. |
