# Delete User with Papyrs

## Endpoint

- **Method:** `POST`
- **Path:** `/people/delete/:user_id/`
- **Base URL:** `https://{subdomain}.papyrs.com/api/v1`
- **Official documentation:** [Delete User](https://papyrs.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The Papyrs user ID. |
