# Get Organization Details with Paycove

Retrieves an organization from Paycove.

## Endpoint

- **Method:** `GET`
- **Path:** `organizations/:id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Get Organization Details](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paycove CRMOrganization ID. |
