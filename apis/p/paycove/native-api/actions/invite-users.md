# Invite Users with Paycove

Invites users to a Paycove account.

## Endpoint

- **Method:** `POST`
- **Path:** `accounts/invite-users`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Invite Users](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emails` | body | `string` | no | Comma-separated email addresses to invite. |
