# Get Application Status with Paycove

Retrieves a gateway application status from Paycove.

## Endpoint

- **Method:** `GET`
- **Path:** `https://paycove.io/gateway-application-status/:unique_account_id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Get Application Status](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `unique_account_id` | path | `string` | yes | Paycove account unique_id. |
