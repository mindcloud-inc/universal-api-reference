# Delete Deal with Paycove

Deletes a deal from Paycove.

## Endpoint

- **Method:** `DELETE`
- **Path:** `deals/:id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Delete Deal](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paycove deal id. |
