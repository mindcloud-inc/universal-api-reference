# Get Contact Details with Paycove

Retrieves a contact from Paycove.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/:id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Get Contact Details](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paycove CRMContact ID. |
