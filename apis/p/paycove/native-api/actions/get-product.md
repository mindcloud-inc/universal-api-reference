# Get Product with Paycove

Retrieves a product from Paycove.

## Endpoint

- **Method:** `GET`
- **Path:** `products/:product_id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Get Product](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | yes | Product ID. |
