# Delete Organization with Paycove

Deletes an organization from Paycove.

## Endpoint

- **Method:** `DELETE`
- **Path:** `organizations/:id`
- **Base URL:** `https://paycove.io/api/v1`
- **Official documentation:** [Delete Organization](https://docs.paycove.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Paycove CRMOrganization ID. |
