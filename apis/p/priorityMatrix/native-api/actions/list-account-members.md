# List Account Members with Priority Matrix

Retrieves account members from Priority Matrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/account/users/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Account Members](https://sync.appfluence.com/developer/guide/#common-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
