# List Inbox Items with Priority Matrix

Retrieves inbox items from Priority Matrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/inbox/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Inbox Items](https://sync.appfluence.com/developer/guide/#common-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
