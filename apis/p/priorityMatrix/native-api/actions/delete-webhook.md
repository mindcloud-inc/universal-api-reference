# Delete Webhook with Priority Matrix

Deletes an existing webhook from Priority Matrix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/hook/:id/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [Delete Webhook](https://sync.appfluence.com/developer/guide/#webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Priority Matrix webhook ID. |
