# List Items with Priority Matrix

Retrieves items from your Priority Matrix workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/item/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Items](https://sync.appfluence.com/api/v1/docs/#!/item)

## Capabilities

This operation supports [pagination](../README.md#pagination).
