# List Collaborators with Priority Matrix

Retrieves Priority Matrix collaborators for the current user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/collaborators/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Collaborators](https://sync.appfluence.com/developer/guide/#common-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
