# List Project Owners with Priority Matrix

Retrieves owners for a Priority Matrix project.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/:idd/owners/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Project Owners](https://sync.appfluence.com/developer/guide/#common-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idd` | path | `number` | yes | Project IDD. |
