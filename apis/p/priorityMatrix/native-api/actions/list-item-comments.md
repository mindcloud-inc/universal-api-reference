# List Item Comments with Priority Matrix

Retrieves comments for a Priority Matrix item.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/item/:id/comments`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Item Comments](https://sync.appfluence.com/developer/guide/#concrete-examples)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Priority Matrix item ID. |
