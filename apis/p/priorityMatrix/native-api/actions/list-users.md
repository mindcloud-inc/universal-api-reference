# List Users with Priority Matrix

Retrieves user records from Priority Matrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Users](https://sync.appfluence.com/api/v1/docs/#!/user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
