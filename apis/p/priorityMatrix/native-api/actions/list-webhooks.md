# List Webhooks with Priority Matrix

Retrieves configured webhooks from Priority Matrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/hook/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Webhooks](https://sync.appfluence.com/developer/guide/#webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
