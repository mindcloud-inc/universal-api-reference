# List Item Followers with Priority Matrix

Retrieves followers for a Priority Matrix item.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/item/:id/followers`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Item Followers](https://sync.appfluence.com/developer/guide/#common-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Priority Matrix item ID. |
