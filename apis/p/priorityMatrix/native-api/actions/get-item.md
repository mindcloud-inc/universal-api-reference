# Get Item with Priority Matrix

Retrieves a Priority Matrix item by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/item/:id/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [Get Item](https://sync.appfluence.com/api/v1/docs/#!/item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Priority Matrix item ID. |
