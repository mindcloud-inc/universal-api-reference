# List Project Tags with Priority Matrix

Retrieves tags for a Priority Matrix project.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/:idd/tags`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Project Tags](https://sync.appfluence.com/developer/guide/#common-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idd` | path | `number` | yes | Project IDD. |
