# Get User with Priority Matrix

Retrieves a user from Priority Matrix by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/:id/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [Get User](https://sync.appfluence.com/api/v1/docs/#!/user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
