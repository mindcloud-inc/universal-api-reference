# List Active Projects with Priority Matrix

Retrieves active projects from Priority Matrix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [List Active Projects](https://sync.appfluence.com/api/v1/docs/#!/project)

## Capabilities

This operation supports [pagination](../README.md#pagination).
