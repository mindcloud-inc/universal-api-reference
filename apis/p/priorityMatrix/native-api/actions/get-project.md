# Get Project with Priority Matrix

Retrieves a project from Priority Matrix by IDD.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/:idd/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [Get Project](https://sync.appfluence.com/api/v1/docs/#!/project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idd` | path | `number` | yes | Project IDD. |
