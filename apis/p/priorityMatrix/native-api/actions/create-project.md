# Create Project with Priority Matrix

Creates a new project in Priority Matrix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/project/`
- **Base URL:** `https://sync.appfluence.com`
- **Official documentation:** [Create Project](https://sync.appfluence.com/developer/guide/#common-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Project name. |
