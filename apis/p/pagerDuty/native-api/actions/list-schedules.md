# List Schedules with PagerDuty

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [List Schedules](https://developer.pagerduty.com/api-reference/listSchedules)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter schedules by a free-text search query. |
