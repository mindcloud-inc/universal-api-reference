# List Escalation Policies with PagerDuty

## Endpoint

- **Method:** `GET`
- **Path:** `/escalation_policies`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [List Escalation Policies](https://developer.pagerduty.com/api-reference/listEscalationPolicies)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter escalation policies by a free-text search query. |
