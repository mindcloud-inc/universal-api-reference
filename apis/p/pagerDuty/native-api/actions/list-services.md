# List Services with PagerDuty

## Endpoint

- **Method:** `GET`
- **Path:** `/services`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [List Services](https://developer.pagerduty.com/api-reference/listServices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter services by a free-text search query. |
