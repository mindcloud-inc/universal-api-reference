# Delete Service with PagerDuty

## Endpoint

- **Method:** `DELETE`
- **Path:** `/services/:id`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [Delete Service](https://developer.pagerduty.com/api-reference/deleteService)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PagerDuty service ID to delete. |
