# List Users with PagerDuty

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [List Users](https://developer.pagerduty.com/api-reference/listUsers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter users by a free-text search query. |
