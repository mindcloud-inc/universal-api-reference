# List Teams with PagerDuty

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api.pagerduty.com`
- **Official documentation:** [List Teams](https://developer.pagerduty.com/api-reference/listTeams)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter teams by a free-text search query. |
