# Delete Client with Pingueen

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clients/:id`
- **Base URL:** `https://api.pingueen.it/ext/v2/{businessname}`
- **Official documentation:** [Delete Client](https://etinet.gitbook.io/pingueen/api-reference/clients/remove-a-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the client to delete. |
