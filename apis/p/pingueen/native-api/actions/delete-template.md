# Delete Template with Pingueen

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/templates/:template_name`
- **Base URL:** `https://api.pingueen.it/ext/v2/{businessname}`
- **Official documentation:** [Delete Template](https://etinet.gitbook.io/pingueen/api-reference/messages/templates/remove-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_name` | path | `string` | yes | Name of the template to delete. |
