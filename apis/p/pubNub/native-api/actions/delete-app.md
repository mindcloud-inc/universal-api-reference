# Delete App with PubNub

Deletes an existing app from PubNub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/:id`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Delete App](https://www.pubnub.com/docs/admin-api/delete-an-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PubNub app ID. |
