# Get Customer By Keyset with PubNub

Retrieves a PubNub customer by keyset.

## Endpoint

- **Method:** `GET`
- **Path:** `/oem/keysets/:keysetId/customer`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get Customer By Keyset](https://www.pubnub.com/docs/admin-api/get-customer-by-keyset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keysetId` | path | `string` | no | PubNub keyset ID. |
