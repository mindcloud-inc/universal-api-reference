# Get Keyset with PubNub

Retrieves a keyset from PubNub.

## Endpoint

- **Method:** `GET`
- **Path:** `/keysets/:id`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get Keyset](https://www.pubnub.com/docs/admin-api/get-keyset-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PubNub keyset ID. |
