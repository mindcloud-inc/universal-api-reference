# Get Top N Insights Data with PubNub

Retrieves top N insights data from PubNub.

## Endpoint

- **Method:** `GET`
- **Path:** `/insights/top`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get Top N Insights Data](https://www.pubnub.com/docs/admin-api/get-top-n-data)
