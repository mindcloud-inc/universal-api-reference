# Get Customer with PubNub

Retrieves a customer from PubNub.

## Endpoint

- **Method:** `GET`
- **Path:** `/oem/customers/:customerId`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get Customer](https://www.pubnub.com/docs/admin-api/get-customer-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | no | PubNub customer ID. |
