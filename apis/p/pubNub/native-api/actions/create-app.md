# Create App with PubNub

Creates an app in PubNub.

## Endpoint

- **Method:** `POST`
- **Path:** `/apps`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Create App](https://www.pubnub.com/docs/admin-api/create-a-new-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The PubNub app name. |
