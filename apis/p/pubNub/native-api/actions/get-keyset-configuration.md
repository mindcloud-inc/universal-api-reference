# Get Keyset Configuration with PubNub

Retrieves keyset configuration from PubNub.

## Endpoint

- **Method:** `GET`
- **Path:** `/keysets/:id/config`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get Keyset Configuration](https://www.pubnub.com/docs/admin-api/get-keyset-configuration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PubNub keyset ID. |
