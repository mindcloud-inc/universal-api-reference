# List Dashboards with PubNub

Retrieves dashboards from PubNub Illuminate.

## Endpoint

- **Method:** `GET`
- **Path:** `/illuminate/dashboards`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [List Dashboards](https://www.pubnub.com/docs/illuminate/illuminate-rest-api)
