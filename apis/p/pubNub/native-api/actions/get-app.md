# Get App with PubNub

Retrieves an app from PubNub.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:id`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Get App](https://www.pubnub.com/docs/admin-api/get-app-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PubNub app ID. |
