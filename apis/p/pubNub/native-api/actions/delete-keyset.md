# Delete Keyset with PubNub

Deletes an existing keyset from PubNub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/keysets/:id`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [Delete Keyset](https://www.pubnub.com/docs/admin-api/delete-a-keyset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The PubNub keyset ID. |
