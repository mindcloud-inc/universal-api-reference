# List Applications For Customer with PubNub

Retrieves applications for a PubNub customer.

## Endpoint

- **Method:** `GET`
- **Path:** `/oem/customers/:customerId/applications`
- **Base URL:** `https://admin-api.pubnub.com/v2`
- **Official documentation:** [List Applications For Customer](https://www.pubnub.com/docs/admin-api/list-applications-for-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | no | PubNub customer ID. |
