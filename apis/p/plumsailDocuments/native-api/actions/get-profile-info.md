# Get Profile Info with Plumsail Documents

Retrieves profile information from Plumsail Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/user/Profiles/me`
- **Base URL:** `https://us-api.plumsail.com`
- **Official documentation:** [Get Profile Info](https://us-api.plumsail.com/swagger/index.html?urls.primaryName=Documents%20V2%20(US)#/UserAPI)
