# Get Task with PiAPI/Veo

Retrieves a Veo task from PiAPI/Veo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/task/:taskId`
- **Base URL:** `https://api.piapi.ai`
- **Official documentation:** [Get Task](https://piapi.ai/docs/veo3-api/get-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
