# Retrieve Video with Pipio

Retrieves a generated video from Pipio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://generate.pipio.ai/single-clip/:id`
- **Base URL:** `https://avatar.pipio.ai`
- **Official documentation:** [Retrieve Video](https://docs.pipio.ai/get-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for your video. |
