# Get Journalist By ID with Perigon

Retrieves a journalist profile from Perigon by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/journalists/{id}`
- **Base URL:** `https://api.perigon.io/v1`
- **Official documentation:** [Get Journalist By ID](https://docs.perigon.io/docs/journalist-data)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
