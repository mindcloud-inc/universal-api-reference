# List Service Agreements with Previsto

Retrieves service agreements from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/agreements`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [List Service Agreements](https://developer.previsto.com/service-agreements/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
