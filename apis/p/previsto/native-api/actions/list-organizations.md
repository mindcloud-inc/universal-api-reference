# List Organizations with Previsto

Retrieves organizations from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [List Organizations](https://developer.previsto.com/organization/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
