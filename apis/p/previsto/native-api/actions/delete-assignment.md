# Delete Assignment with Previsto

Deletes an existing assignment from Previsto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assignments/:id`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [Delete Assignment](https://developer.previsto.com/assignments/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Previsto assignment ID. |
