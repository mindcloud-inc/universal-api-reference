# List Assignments with Previsto

Retrieves assignments from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/assignments`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [List Assignments](https://developer.previsto.com/assignments/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
