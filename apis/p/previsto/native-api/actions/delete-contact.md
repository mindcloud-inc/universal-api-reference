# Delete Contact with Previsto

Deletes an existing contact from Previsto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [Delete Contact](https://developer.previsto.com/contacts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Previsto contact ID |
