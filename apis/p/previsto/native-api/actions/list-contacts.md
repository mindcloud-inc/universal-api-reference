# List Contacts with Previsto

Retrieves contacts from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [List Contacts](https://developer.previsto.com/contacts/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
