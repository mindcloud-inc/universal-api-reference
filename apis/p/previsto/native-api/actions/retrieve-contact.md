# Retrieve Contact with Previsto

Retrieves a contact from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [Retrieve Contact](https://developer.previsto.com/contacts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Previsto contact ID. |
