# Retrieve Service Agreement with Previsto

Retrieves a service agreement from Previsto.

## Endpoint

- **Method:** `GET`
- **Path:** `/agreements/:id`
- **Base URL:** `https://api.previsto.io`
- **Official documentation:** [Retrieve Service Agreement](https://developer.previsto.com/service-agreements/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Previsto service agreement ID. |
