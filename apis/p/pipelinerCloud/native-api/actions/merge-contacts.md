# Merge Contacts with Pipeliner Cloud

Merges existing contacts in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Contacts/merge`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Merge Contacts](https://pipelinercrm.eu.apidog.com/contacts-merge-3640867e0)
