# Delete Opportunity with Pipeliner Cloud

Deletes an existing opportunity from Pipeliner Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/entities/Opportunities/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Delete Opportunity](https://pipelinercrm.eu.apidog.com/opportunities-delete-3641328e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner opportunity ID. |
