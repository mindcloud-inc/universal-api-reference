# Update Product with Pipeliner Cloud

Updates an existing product in Pipeliner Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/entities/Products/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Update Product](https://pipelinercrm.eu.apidog.com/products-update-3641553e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner product ID. |
