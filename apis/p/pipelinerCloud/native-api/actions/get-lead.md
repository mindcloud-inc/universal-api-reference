# Get Lead with Pipeliner Cloud

Retrieves a lead from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Leads/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Lead](https://pipelinercrm.eu.apidog.com/leads-get-3641235e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner lead ID. |
