# Delete Lead with Pipeliner Cloud

Deletes an existing lead from Pipeliner Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/entities/Leads/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Delete Lead](https://pipelinercrm.eu.apidog.com/leads-delete-3641236e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner lead ID. |
