# Create Product with Pipeliner Cloud

Creates a new product in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Products`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Create Product](https://pipelinercrm.eu.apidog.com/products-create-3641555e0)
