# Create Contact with Pipeliner Cloud

Creates a new contact in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Contacts`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Create Contact](https://pipelinercrm.eu.apidog.com/contacts-create-3640866e0)
