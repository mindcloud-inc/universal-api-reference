# Merge Accounts with Pipeliner Cloud

Merges existing accounts in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Accounts/merge`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Merge Accounts](https://pipelinercrm.eu.apidog.com/accounts-merge-3640462e0)
