# Update Opportunity with Pipeliner Cloud

Updates an existing opportunity in Pipeliner Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/entities/Opportunities/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Update Opportunity](https://pipelinercrm.eu.apidog.com/opportunities-update-3641329e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner opportunity ID. |
