# Update Contact with Pipeliner Cloud

Updates an existing contact in Pipeliner Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/entities/Contacts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Update Contact](https://pipelinercrm.eu.apidog.com/contacts-update-3640864e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner contact ID. |
