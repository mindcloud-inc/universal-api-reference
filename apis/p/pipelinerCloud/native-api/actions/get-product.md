# Get Product with Pipeliner Cloud

Retrieves a product from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Products/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Product](https://pipelinercrm.eu.apidog.com/products-get-3641551e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner product ID. |
