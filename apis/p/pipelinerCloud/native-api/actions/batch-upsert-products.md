# Batch Upsert Products with Pipeliner Cloud

Creates or updates products in Pipeliner Cloud in batches.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Products/batch-modify`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Batch Upsert Products](https://pipelinercrm.eu.apidog.com/products-batch-create-or-update-3641557e0)
