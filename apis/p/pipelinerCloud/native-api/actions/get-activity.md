# Get Activity with Pipeliner Cloud

Retrieves an activity from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Activities/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Activity](https://pipelinercrm.eu.apidog.com/activities-get-3640556e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner activity ID. |
