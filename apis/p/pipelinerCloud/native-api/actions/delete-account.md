# Delete Account with Pipeliner Cloud

Deletes an existing account from Pipeliner Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/entities/Accounts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Delete Account](https://pipelinercrm.eu.apidog.com/accounts-delete-3640458e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner account ID. |
