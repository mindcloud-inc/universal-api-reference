# Update Lead with Pipeliner Cloud

Updates an existing lead in Pipeliner Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/entities/Leads/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Update Lead](https://pipelinercrm.eu.apidog.com/leads-update-3641237e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner lead ID. |
