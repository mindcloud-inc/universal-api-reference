# Create Lead with Pipeliner Cloud

Creates a new lead in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Leads`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Create Lead](https://pipelinercrm.eu.apidog.com/leads-create-3641239e0)
