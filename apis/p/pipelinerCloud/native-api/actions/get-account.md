# Get Account with Pipeliner Cloud

Retrieves an account from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Accounts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Account](https://pipelinercrm.eu.apidog.com/accounts-get-3640457e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner account ID. |
