# Delete Contact with Pipeliner Cloud

Deletes an existing contact from Pipeliner Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/entities/Contacts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Delete Contact](https://pipelinercrm.eu.apidog.com/contacts-delete-3640863e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner contact ID. |
