# Update Account with Pipeliner Cloud

Updates an existing account in Pipeliner Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/entities/Accounts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Update Account](https://pipelinercrm.eu.apidog.com/accounts-update-3640459e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner account ID. |
