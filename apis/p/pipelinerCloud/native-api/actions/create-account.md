# Create Account with Pipeliner Cloud

Creates a new account in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Accounts`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Create Account](https://pipelinercrm.eu.apidog.com/accounts-create-3640461e0)
