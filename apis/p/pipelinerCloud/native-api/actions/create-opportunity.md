# Create Opportunity with Pipeliner Cloud

Creates a new opportunity in Pipeliner Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/Opportunities`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Create Opportunity](https://pipelinercrm.eu.apidog.com/opportunities-create-3641331e0)
