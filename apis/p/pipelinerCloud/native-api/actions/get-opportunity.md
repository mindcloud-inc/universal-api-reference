# Get Opportunity with Pipeliner Cloud

Retrieves an opportunity from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Opportunities/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Opportunity](https://pipelinercrm.eu.apidog.com/opportunities-get-3641327e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner opportunity ID. |
