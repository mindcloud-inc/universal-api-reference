# Get Contact with Pipeliner Cloud

Retrieves a contact from Pipeliner Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/Contacts/{{id}}`
- **Base URL:** `{serviceUrl}/api/v100/rest/spaces/{spaceId}`
- **Official documentation:** [Get Contact](https://pipelinercrm.eu.apidog.com/contacts-get-3640862e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Pipeliner contact ID. |
