# Revoke an access token with Pipedream

Revokes an OAuth access token in Pipedream.

## Endpoint

- **Method:** `POST`
- **Path:** `/oauth/revoke`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Revoke an access token](https://pipedream.com/docs/rest-api/api-reference/oauth/revoke-an-access-token)
