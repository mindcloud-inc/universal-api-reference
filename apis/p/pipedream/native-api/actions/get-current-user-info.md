# Get current user info with Pipedream

Retrieves the current user's details from Pipedream.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get current user info](https://pipedream.com/docs/rest-api/api-reference/users/get-current-user-info)
