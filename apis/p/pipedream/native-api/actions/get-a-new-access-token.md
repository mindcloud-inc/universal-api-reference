# Get a new access token with Pipedream

Creates a new OAuth access token in Pipedream.

## Endpoint

- **Method:** `POST`
- **Path:** `/oauth/token`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get a new access token](https://pipedream.com/docs/rest-api/api-reference/oauth/get-a-new-access-token)
