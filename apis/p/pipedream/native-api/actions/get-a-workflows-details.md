# Get a workflow's details with Pipedream

Retrieves details for a workflow from Pipedream.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/{workflow_id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get a workflow's details](https://pipedream.com/docs/rest-api/api-reference/workflows/get-a-workflows-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | The workflow identifier. |
