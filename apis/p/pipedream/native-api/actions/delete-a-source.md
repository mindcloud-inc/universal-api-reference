# Delete a source with Pipedream

Deletes an existing source from Pipedream.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sources/{id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Delete a source](https://pipedream.com/docs/rest-api/api-reference/sources/delete-a-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The source identifier. |
