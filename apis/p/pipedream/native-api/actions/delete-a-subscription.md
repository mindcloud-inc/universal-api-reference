# Delete a subscription with Pipedream

Deletes an existing subscription from Pipedream.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Delete a subscription](https://pipedream.com/docs/rest-api/api-reference/subscription/delete-a-subscription)
