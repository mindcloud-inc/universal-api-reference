# Get a component with Pipedream

Retrieves a component from Pipedream by ID or key.

## Endpoint

- **Method:** `GET`
- **Path:** `/components/{key|id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get a component](https://pipedream.com/docs/rest-api/api-reference/components/get-a-component)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key\|id` | path | `string` | yes | The component ID or key. |
