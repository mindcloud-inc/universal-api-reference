# Listen for events from another source or workflow with Pipedream

Creates a subscription to source or workflow events in Pipedream.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Listen for events from another source or workflow](https://pipedream.com/docs/rest-api/api-reference/subscription/listen-for-events-from-another-source-or-workflow)
