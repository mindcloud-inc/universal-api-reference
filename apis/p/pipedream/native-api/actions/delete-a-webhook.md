# Delete a webhook with Pipedream

Deletes an existing webhook from Pipedream.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Delete a webhook](https://pipedream.com/docs/rest-api/api-reference/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook identifier. |
