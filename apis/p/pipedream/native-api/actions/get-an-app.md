# Get an app with Pipedream

Retrieves details for an app from Pipedream.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/{app_id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get an app](https://pipedream.com/docs/rest-api/api-reference/apps/get-an-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | The Pipedream app identifier. |
