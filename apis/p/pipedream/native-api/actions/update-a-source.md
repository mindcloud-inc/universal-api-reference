# Update a source with Pipedream

Updates an existing source in Pipedream.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sources/{id}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Update a source](https://pipedream.com/docs/rest-api/api-reference/sources/update-a-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The source identifier. |
