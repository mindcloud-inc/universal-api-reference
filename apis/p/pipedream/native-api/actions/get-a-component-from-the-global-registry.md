# Get a component from the global registry with Pipedream

Retrieves a registry component from Pipedream by key.

## Endpoint

- **Method:** `GET`
- **Path:** `/components/registry/{key}`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Get a component from the global registry](https://pipedream.com/docs/rest-api/api-reference/components/get-a-component-from-the-global-registry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The registry component key. |
