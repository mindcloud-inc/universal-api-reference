# Automatically subscribe a listener to events from new workflows / sources with Pipedream

Creates an auto-subscription for new workflow or source events in Pipedream.

## Endpoint

- **Method:** `POST`
- **Path:** `/auto_subscriptions`
- **Base URL:** `https://api.pipedream.com/v1`
- **Official documentation:** [Automatically subscribe a listener to events from new workflows / sources](https://pipedream.com/docs/rest-api/api-reference/subscription/automatically-subscribe-a-listener-to-events-from-new-workflows-sources)
