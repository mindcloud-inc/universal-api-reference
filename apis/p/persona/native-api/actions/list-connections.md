# List Connections with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/connect/connections`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List Connections](https://docs.withpersona.com/api-reference/connect/connections/list-all-connect-connections)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
