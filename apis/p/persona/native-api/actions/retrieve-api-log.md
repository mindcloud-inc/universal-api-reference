# Retrieve API Log with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/api-logs/[:api-log-id]`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [Retrieve API Log](https://docs.withpersona.com/api-reference/api-logs/retrieve-an-api-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api-log-id` | path | `string` | yes | API Log ID |
