# List Lists with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List Lists](https://docs.withpersona.com/api-reference/lists/list-all-lists)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
