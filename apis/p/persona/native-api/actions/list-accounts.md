# List Accounts with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List Accounts](https://docs.withpersona.com/api-reference/accounts/list-all-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
