# List Cases with Persona

- **Method:** `GET`
- **Path:** `/cases`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List Cases](https://docs.withpersona.com/api-reference/cases/list-all-cases)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
