# Retrieve Event with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/events/[:event-id]`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [Retrieve Event](https://docs.withpersona.com/api-reference/events/retrieve-an-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event-id` | path | `string` | yes | Event ID |
