# List Share Tokens with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/connect/share-tokens`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List Share Tokens](https://docs.withpersona.com/api-reference/share-tokens/list-all-share-tokens)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
