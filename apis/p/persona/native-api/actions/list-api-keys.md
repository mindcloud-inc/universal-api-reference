# List API keys with Persona

## Endpoint

- **Method:** `GET`
- **Path:** `/api-keys`
- **Base URL:** `https://api.withpersona.com/api/v1`
- **Official documentation:** [List API keys](https://docs.withpersona.com/api-reference/api-keys/list-all-api-keys)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
