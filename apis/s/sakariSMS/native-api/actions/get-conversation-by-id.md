# Get Conversation by ID with Sakari SMS

Retrieves a conversation from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/conversations/:conversationId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Conversation by ID](https://developer.sakari.io/api-reference/conversations/fetch-conversation-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
