# Get Contact by ID with Sakari SMS

Retrieves a contact from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/contacts/:contactId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Contact by ID](https://developer.sakari.io/api-reference/contacts/fetch-contact-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
