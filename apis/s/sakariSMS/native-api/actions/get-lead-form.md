# Get Lead Form with Sakari SMS

Retrieves a lead form from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/forms/:formId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Lead Form](https://developer.sakari.io/api-reference/forms/fetch-lead-form-info)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
