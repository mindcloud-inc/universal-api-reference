# Delete Template with Sakari SMS

Deletes an existing template from Sakari SMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/accounts/:accountId/templates/:templateId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Delete Template](https://developer.sakari.io/api-reference/templates/deletes-a-template)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateId` | path | `string` | yes |
