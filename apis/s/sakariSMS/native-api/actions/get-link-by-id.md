# Get Link by ID with Sakari SMS

Retrieves a link from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/links/:linkId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Link by ID](https://developer.sakari.io/api-reference/links/fetch-link-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `linkId` | path | `string` | yes |
