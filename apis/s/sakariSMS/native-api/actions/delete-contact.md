# Delete Contact with Sakari SMS

Deletes an existing contact from Sakari SMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/accounts/:accountId/contacts/:contactId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Delete Contact](https://developer.sakari.io/api-reference/contacts/deletes-a-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
