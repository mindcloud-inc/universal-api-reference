# List Links with Sakari SMS

Retrieves account links from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/links`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [List Links](https://developer.sakari.io/api-reference/links/fetch-links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | General search term that searchs accross multiple fields |
