# List Active Webhooks with Sakari SMS

Retrieves active webhooks from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/webhooks`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [List Active Webhooks](https://developer.sakari.io/api-reference/webhooks/fetch-active-webhooks)
