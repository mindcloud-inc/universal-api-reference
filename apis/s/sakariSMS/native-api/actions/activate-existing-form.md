# Activate Existing Form with Sakari SMS

Activates an existing lead form in Sakari SMS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/accounts/:accountId/forms/:formId/activate`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Activate Existing Form](https://developer.sakari.io/api-reference/forms/activate-an-existing-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
