# Get Campaign by ID with Sakari SMS

Retrieves a campaign from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/campaigns/:campaignId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Campaign by ID](https://developer.sakari.io/api-reference/campaigns/fetch-campaign-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
