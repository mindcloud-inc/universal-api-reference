# Delete Lead Form with Sakari SMS

Deletes an existing lead form from Sakari SMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/accounts/:accountId/forms/:formId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Delete Lead Form](https://developer.sakari.io/api-reference/forms/delete-a-lead-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
