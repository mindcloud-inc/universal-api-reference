# Get Template by ID with Sakari SMS

Retrieves a template from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/templates/:templateId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Template by ID](https://developer.sakari.io/api-reference/templates/fetch-template-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateId` | path | `string` | yes |
