# Close Conversation with Sakari SMS

Closes a conversation in Sakari SMS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/accounts/:accountId/conversations/:conversationId/close`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Close Conversation](https://developer.sakari.io/api-reference/conversations/closes-a-conversation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
