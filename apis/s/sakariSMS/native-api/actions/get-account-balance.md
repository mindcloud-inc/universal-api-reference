# Get Account Balance with Sakari SMS

Retrieves an account balance from Sakari SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/balance`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Get Account Balance](https://developer.sakari.io/api-reference/accounts/fetch-account-balance)
