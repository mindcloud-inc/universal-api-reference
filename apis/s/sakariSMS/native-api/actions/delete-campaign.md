# Delete Campaign with Sakari SMS

Deletes an existing campaign from Sakari SMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/accounts/:accountId/campaigns/:campaignId`
- **Base URL:** `https://api.sakari.io`
- **Official documentation:** [Delete Campaign](https://developer.sakari.io/api-reference/campaigns/deletes-a-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
