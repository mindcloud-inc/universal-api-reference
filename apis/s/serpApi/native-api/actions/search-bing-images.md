# Search Bing Images with SerpApi

Retrieves Bing image results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search Bing Images](https://serpapi.com/bing-images-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
