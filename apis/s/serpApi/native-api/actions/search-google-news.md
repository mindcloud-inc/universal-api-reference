# Search Google News with SerpApi

Retrieves Google News results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search Google News](https://serpapi.com/google-news-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
