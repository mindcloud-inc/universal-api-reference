# Autocomplete Google with SerpApi

Retrieves Google autocomplete suggestions from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Autocomplete Google](https://serpapi.com/google-autocomplete-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
