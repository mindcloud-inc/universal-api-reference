# Search Google AI Mode with SerpApi

Retrieves Google AI Mode results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search Google AI Mode](https://serpapi.com/google-ai-mode-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
