# Search Google AI Overview with SerpApi

Retrieves Google AI Overview results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search Google AI Overview](https://serpapi.com/google-ai-overview-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_token` | query | `string` | yes | Google AI Overview page token from a prior Google results page. |
