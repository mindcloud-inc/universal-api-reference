# Search DuckDuckGo Web with SerpApi

Retrieves DuckDuckGo web search results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search DuckDuckGo Web](https://serpapi.com/duckduckgo-search-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
