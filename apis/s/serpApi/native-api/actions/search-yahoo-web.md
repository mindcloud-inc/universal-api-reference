# Search Yahoo Web with SerpApi

Retrieves Yahoo web search results from SerpApi.

## Endpoint

- **Method:** `GET`
- **Path:** `/search.json`
- **Base URL:** `https://serpapi.com`
- **Official documentation:** [Search Yahoo Web](https://serpapi.com/yahoo-search-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `p` | query | `string` | yes |
