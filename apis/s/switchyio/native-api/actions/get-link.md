# Get Link with Switchy.io

Retrieves a link from Switchy.io by domain and ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/graphql`
- **Base URL:** `https://graphql.switchy.io`
- **Official documentation:** [Get Link](https://developers.switchy.io/docs/guides/how-to-query)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | body | `string` | yes |
| `id` | body | `string` | yes |
