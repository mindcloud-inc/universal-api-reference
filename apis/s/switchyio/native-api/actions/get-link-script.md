# Get Link Script with Switchy.io

Retrieves a link script from Switchy.io by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/graphql`
- **Base URL:** `https://graphql.switchy.io`
- **Official documentation:** [Get Link Script](https://developers.switchy.io/docs/guides/how-to-query)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
