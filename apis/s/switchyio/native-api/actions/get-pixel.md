# Get Pixel with Switchy.io

Retrieves a pixel from Switchy.io by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/graphql`
- **Base URL:** `https://graphql.switchy.io`
- **Official documentation:** [Get Pixel](https://developers.switchy.io/docs/guides/how-to-query)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
