# List Domains with Switchy.io

Retrieves domains from Switchy.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/graphql`
- **Base URL:** `https://graphql.switchy.io`
- **Official documentation:** [List Domains](https://developers.switchy.io/docs/guides/how-to-query)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
