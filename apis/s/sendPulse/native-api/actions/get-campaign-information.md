# Get Campaign Information with SendPulse

Retrieves a campaign from SendPulse by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Get Campaign Information](https://sendpulse.com/integrations/api/bulk-email#campaign-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The SendPulse campaign identifier. |
