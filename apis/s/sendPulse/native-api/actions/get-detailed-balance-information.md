# Get Detailed Balance Information with SendPulse

Retrieves detailed account balance information from SendPulse.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/balance/detail`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Get Detailed Balance Information](https://sendpulse.com/integrations/api/bulk-email#get-balance-details)
