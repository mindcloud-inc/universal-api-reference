# Get Template Information with SendPulse

Retrieves a template from SendPulse by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:templateId`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Get Template Information](https://sendpulse.com/integrations/api/bulk-email#template-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The SendPulse template identifier. |
