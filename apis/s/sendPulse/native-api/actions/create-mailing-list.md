# Create Mailing List with SendPulse

Creates a new mailing list in SendPulse.

## Endpoint

- **Method:** `POST`
- **Path:** `/addressbooks`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Create Mailing List](https://sendpulse.com/integrations/api/bulk-email#create-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookName` | body | `string` | yes | Name of the new mailing list. |
