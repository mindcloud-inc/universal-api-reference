# Get Mailing List Information with SendPulse

Retrieves a mailing list from SendPulse by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:mailingListId`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Get Mailing List Information](https://sendpulse.com/integrations/api/bulk-email#list-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailingListId` | path | `string` | yes | The SendPulse mailing list identifier. |
