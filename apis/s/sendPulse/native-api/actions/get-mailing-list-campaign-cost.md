# Get Mailing List Campaign Cost with SendPulse

Retrieves campaign cost for a SendPulse mailing list.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks/:mailingListId/cost`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [Get Mailing List Campaign Cost](https://sendpulse.com/integrations/api/bulk-email#campaign-cost)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailingListId` | path | `string` | yes | The SendPulse mailing list identifier. |
