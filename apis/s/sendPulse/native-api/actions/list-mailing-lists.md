# List Mailing Lists with SendPulse

Retrieves a list of mailing lists from SendPulse.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbooks`
- **Base URL:** `https://api.sendpulse.com`
- **Official documentation:** [List Mailing Lists](https://sendpulse.com/integrations/api/bulk-email#lists-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of mailing lists to return. |
| `offset` | query | `number` | no | Number of mailing lists to skip before returning results. |
