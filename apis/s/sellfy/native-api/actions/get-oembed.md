# Get oEmbed with Sellfy

Retrieves oEmbed data from Sellfy for a store or product URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/oembed/`
- **Base URL:** `https://sellfy.com`
- **Official documentation:** [Get oEmbed](https://docs.sellfy.com/article/348-oembed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The product or store page URL to convert into oEmbed data. |
