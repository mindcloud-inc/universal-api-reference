# List Conversation Fields with SparrowDesk

Retrieves conversation fields from SparrowDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/fields`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [List Conversation Fields](https://developer.sparrowdesk.com/rest-api/endpoints/conversations/fields/get)
