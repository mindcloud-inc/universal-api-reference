# Delete Contact with SparrowDesk

Deletes an existing contact from SparrowDesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Delete Contact](https://developer.sparrowdesk.com/rest-api/endpoints/contacts/id/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SparrowDesk contact ID. |
