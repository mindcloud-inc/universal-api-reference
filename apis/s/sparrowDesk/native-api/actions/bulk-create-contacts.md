# Bulk Create Contacts with SparrowDesk

Creates contacts in bulk in SparrowDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/bulk/contacts`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Bulk Create Contacts](https://developer.sparrowdesk.com/rest-api/endpoints/bulk/contacts/post)
