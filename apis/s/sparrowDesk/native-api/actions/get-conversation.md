# Get Conversation with SparrowDesk

Retrieves a conversation from SparrowDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/{{id}}`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Get Conversation](https://developer.sparrowdesk.com/rest-api/endpoints/conversations/id/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SparrowDesk conversation ID. |
