# Delete Conversation with SparrowDesk

Deletes an existing conversation from SparrowDesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversations/{{id}}`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Delete Conversation](https://developer.sparrowdesk.com/rest-api/endpoints/conversations/id/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SparrowDesk conversation ID. |
