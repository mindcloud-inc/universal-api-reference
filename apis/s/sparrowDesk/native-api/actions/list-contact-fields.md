# List Contact Fields with SparrowDesk

Retrieves contact fields from SparrowDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-fields`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [List Contact Fields](https://developer.sparrowdesk.com/rest-api/endpoints/contact-fields/get)
