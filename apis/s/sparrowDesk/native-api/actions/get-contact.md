# Get Contact with SparrowDesk

Retrieves a contact from SparrowDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Get Contact](https://developer.sparrowdesk.com/rest-api/endpoints/contacts/id/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SparrowDesk contact ID. |
