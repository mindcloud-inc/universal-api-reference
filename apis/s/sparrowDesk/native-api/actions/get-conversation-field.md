# Get Conversation Field with SparrowDesk

Retrieves a conversation field from SparrowDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/fields/{{id}}`
- **Base URL:** `https://api.sparrowdesk.com/v1`
- **Official documentation:** [Get Conversation Field](https://developer.sparrowdesk.com/rest-api/endpoints/conversations/fields/id/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SparrowDesk conversation field ID. |
