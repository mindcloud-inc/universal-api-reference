# List Services with STEL Order

Retrieves a list of services from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/services`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Services](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
