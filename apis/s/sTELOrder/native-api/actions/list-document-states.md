# List Document States with STEL Order

Retrieves a list of document states from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/documentStates`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Document States](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
