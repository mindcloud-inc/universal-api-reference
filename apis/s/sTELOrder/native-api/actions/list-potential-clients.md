# List Potential Clients with STEL Order

Retrieves a list of potential clients from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/potentialClients`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Potential Clients](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
