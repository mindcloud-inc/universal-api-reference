# List Ordinary Invoice Receipts with STEL Order

Retrieves a list of ordinary invoice receipts from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/ordinaryInvoiceReceipts`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Ordinary Invoice Receipts](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
