# List Product Categories with STEL Order

Retrieves a list of product categories from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/productCategories`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Product Categories](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
