# List Refund Invoices with STEL Order

Retrieves a list of refund invoices from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/refundInvoices`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Refund Invoices](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
