# List Ordinary Invoices with STEL Order

Retrieves a list of ordinary invoices from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/ordinaryInvoices`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Ordinary Invoices](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
