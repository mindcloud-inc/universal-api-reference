# List Payment Options with STEL Order

Retrieves a list of payment options from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentOptions`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Payment Options](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
