# List Sales Orders with STEL Order

Retrieves a list of sales orders from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/salesOrders`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Sales Orders](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
