# List Product Warehouses with STEL Order

Retrieves a list of product warehouses from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/productWarehouses`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Product Warehouses](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
