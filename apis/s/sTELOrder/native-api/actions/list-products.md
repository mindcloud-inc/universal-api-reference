# List Products with STEL Order

Retrieves a list of products from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Products](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
