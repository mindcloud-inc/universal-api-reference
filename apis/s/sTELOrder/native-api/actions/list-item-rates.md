# List Item Rates with STEL Order

Retrieves a list of item rates from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/itemRates`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Item Rates](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
