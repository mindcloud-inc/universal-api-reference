# List Addresses with STEL Order

Retrieves a list of addresses from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Addresses](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
