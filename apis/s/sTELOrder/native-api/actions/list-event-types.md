# List Event Types with STEL Order

Retrieves a list of event types from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventTypes`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Event Types](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
