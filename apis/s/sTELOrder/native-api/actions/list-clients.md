# List Clients with STEL Order

Retrieves a list of clients from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Clients](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
