# List Bank Accounts with STEL Order

Retrieves a list of bank accounts from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/bankAccounts`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Bank Accounts](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
