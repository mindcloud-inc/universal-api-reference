# List Work Orders with STEL Order

Retrieves a list of work orders from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/workOrders`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Work Orders](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
