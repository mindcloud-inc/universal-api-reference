# List Item Images with STEL Order

Retrieves a list of item images from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/itemImages`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Item Images](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
