# List Contacts with STEL Order

Retrieves a list of contacts from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Contacts](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
