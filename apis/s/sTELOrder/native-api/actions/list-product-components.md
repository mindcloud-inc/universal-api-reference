# List Product Components with STEL Order

Retrieves a list of product components from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/productComponents`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Product Components](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
