# List Expenses with STEL Order

Retrieves a list of expenses from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Expenses](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
