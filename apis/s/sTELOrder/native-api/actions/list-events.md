# List Events with STEL Order

Retrieves a list of events from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Events](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
