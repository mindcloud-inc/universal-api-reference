# List Payment Terms with STEL Order

Retrieves a list of payment terms from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentTerms`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Payment Terms](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
