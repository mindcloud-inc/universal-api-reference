# List Expense Categories with STEL Order

Retrieves a list of expense categories from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenseCategories`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Expense Categories](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
