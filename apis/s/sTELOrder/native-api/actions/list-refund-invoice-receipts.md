# List Refund Invoice Receipts with STEL Order

Retrieves a list of refund invoice receipts from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/refundInvoiceReceipts`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Refund Invoice Receipts](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
