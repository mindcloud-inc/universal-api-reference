# List Calendars with STEL Order

Retrieves a list of calendars from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Calendars](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
