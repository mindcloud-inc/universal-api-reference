# List Account Categories with STEL Order

Retrieves a list of account categories from STEL Order.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountCategories`
- **Base URL:** `https://app.stelorder.com/app`
- **Official documentation:** [List Account Categories](https://app.stelorder.com/app/indexapi.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
