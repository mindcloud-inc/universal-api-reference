# List Stream Event Types with Svix

Retrieves stream event types from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/event-type`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Stream Event Types](https://api.svix.com/docs#operation/v1.streaming.event-type.list)
