# List Attempted Messages with Svix

Retrieves attempted messages for a specific Svix endpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/msg`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Attempted Messages](https://api.svix.com/docs#operation/v1.message-attempt.list-attempted-messages)
