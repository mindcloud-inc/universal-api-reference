# Update Operational Webhook Endpoint Headers with Svix

Updates operational webhook endpoint headers in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Operational Webhook Endpoint Headers](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.update-headers)
