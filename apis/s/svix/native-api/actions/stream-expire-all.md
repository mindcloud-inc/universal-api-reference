# Stream Expire All with Svix

Expires all stream tokens in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/auth/stream/{stream_id}/expire-all`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Stream Expire All](https://api.svix.com/docs#operation/v1.authentication.stream-expire-all)
