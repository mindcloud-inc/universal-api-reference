# Get Consumer App Portal Access with Svix

Retrieves consumer app portal access from Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/auth/app-portal-access/{app_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Consumer App Portal Access](https://api.svix.com/docs#operation/v1.authentication.app-portal-access)
