# Rotate Sink Secret with Svix

Rotates a sink secret in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/secret/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Sink Secret](https://api.svix.com/docs#operation/v1.streaming.sink.rotate-secret)
