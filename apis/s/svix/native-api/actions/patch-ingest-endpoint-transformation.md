# Patch Ingest Endpoint Transformation with Svix

Updates an ingest endpoint transformation in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Ingest Endpoint Transformation](https://api.svix.com/docs#operation/v1.ingest.endpoint.set-transformation)
