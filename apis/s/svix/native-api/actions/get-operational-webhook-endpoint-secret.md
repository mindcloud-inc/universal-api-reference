# Get Operational Webhook Endpoint Secret with Svix

Retrieves an operational webhook endpoint secret from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}/secret`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Operational Webhook Endpoint Secret](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.get-secret)
