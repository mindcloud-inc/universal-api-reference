# Update Operational Webhook Endpoint with Svix

Updates an operational webhook endpoint in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Operational Webhook Endpoint](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.update)
