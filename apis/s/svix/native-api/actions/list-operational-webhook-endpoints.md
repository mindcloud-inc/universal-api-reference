# List Operational Webhook Endpoints with Svix

Retrieves operational webhook endpoints from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/operational-webhook/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Operational Webhook Endpoints](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.list)
