# Delete Attempt Response Body with Svix

Deletes an attempt response body from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/app/{app_id}/msg/{msg_id}/attempt/{attempt_id}/content`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Attempt Response Body](https://api.svix.com/docs#operation/v1.message-attempt.expunge-content)
