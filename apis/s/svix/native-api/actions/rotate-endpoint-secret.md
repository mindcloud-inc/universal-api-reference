# Rotate Endpoint Secret with Svix

Rotates an endpoint secret in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/secret/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Endpoint Secret](https://api.svix.com/docs#operation/v1.endpoint.rotate-secret)
