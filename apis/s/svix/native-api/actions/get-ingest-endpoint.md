# Get Ingest Endpoint with Svix

Retrieves an ingest endpoint from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Ingest Endpoint](https://api.svix.com/docs#operation/v1.ingest.endpoint.get)
