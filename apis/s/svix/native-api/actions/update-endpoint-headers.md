# Update Endpoint Headers with Svix

Updates endpoint headers in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Endpoint Headers](https://api.svix.com/docs#operation/v1.endpoint.update-headers)
