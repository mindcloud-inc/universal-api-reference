# Get Sink Secret with Svix

Retrieves a sink secret from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/secret`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Sink Secret](https://api.svix.com/docs#operation/v1.streaming.sink.get-secret)
