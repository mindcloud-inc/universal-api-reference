# List Ingest Endpoints with Svix

Retrieves ingest endpoints from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Ingest Endpoints](https://api.svix.com/docs#operation/v1.ingest.endpoint.list)
