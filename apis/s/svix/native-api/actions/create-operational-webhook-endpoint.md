# Create Operational Webhook Endpoint with Svix

Creates an operational webhook endpoint in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/operational-webhook/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Create Operational Webhook Endpoint](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.create)
