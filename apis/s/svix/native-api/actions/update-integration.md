# Update Integration with Svix

Updates an integration in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/app/{app_id}/integration/{integ_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Integration](https://api.svix.com/docs#operation/v1.integration.update)
