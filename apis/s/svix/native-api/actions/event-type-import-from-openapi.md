# Event Type Import From Openapi with Svix

Imports event types from an OpenAPI spec into Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/event-type/import/openapi`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Event Type Import From Openapi](https://api.svix.com/docs#operation/v1.event-type.import-openapi)
