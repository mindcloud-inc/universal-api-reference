# Delete Ingest Source with Svix

Deletes an ingest source from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ingest/api/v1/source/{source_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Ingest Source](https://api.svix.com/docs#operation/v1.ingest.source.delete)
