# Rotate Poller Token with Svix

Rotates the current Svix poller token.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/auth/stream/{stream_id}/sink/{sink_id}/poller/token/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Poller Token](https://api.svix.com/docs#operation/v1.authentication.rotate-stream-poller-token)
