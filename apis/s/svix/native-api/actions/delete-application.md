# Delete Application with Svix

Deletes an application from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/app/{app_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Application](https://api.svix.com/docs#operation/v1.application.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | The application's ID or UID. |
