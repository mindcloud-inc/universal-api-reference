# Get Ingest Endpoint Headers with Svix

Retrieves ingest endpoint headers from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Ingest Endpoint Headers](https://api.svix.com/docs#operation/v1.ingest.endpoint.get-headers)
