# Update Ingest Endpoint with Svix

Updates an ingest endpoint in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Ingest Endpoint](https://api.svix.com/docs#operation/v1.ingest.endpoint.update)
