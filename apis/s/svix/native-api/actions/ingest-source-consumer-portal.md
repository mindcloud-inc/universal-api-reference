# Ingest Source Consumer Portal with Svix

Retrieves ingest source portal access from Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/ingest/api/v1/source/{source_id}/dashboard`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Ingest Source Consumer Portal](https://api.svix.com/docs#operation/v1.ingest.dashboard)
