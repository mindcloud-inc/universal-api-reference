# Delete Integration with Svix

Deletes an integration from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/app/{app_id}/integration/{integ_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Integration](https://api.svix.com/docs#operation/v1.integration.delete)
