# List Attempts By Msg with Svix

Retrieves delivery attempts for a specific Svix message.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/attempt/msg/{msg_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Attempts By Msg](https://api.svix.com/docs#operation/v1.message-attempt.list-by-msg)
