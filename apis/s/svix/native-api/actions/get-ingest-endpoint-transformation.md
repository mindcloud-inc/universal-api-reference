# Get Ingest Endpoint Transformation with Svix

Retrieves an ingest endpoint transformation from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Ingest Endpoint Transformation](https://api.svix.com/docs#operation/v1.ingest.endpoint.get-transformation)
