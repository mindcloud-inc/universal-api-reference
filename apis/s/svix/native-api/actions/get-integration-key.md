# Get Integration Key with Svix

Retrieves an integration key from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/integration/{integ_id}/key`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Integration Key](https://api.svix.com/docs#operation/v1.integration.get-key)
