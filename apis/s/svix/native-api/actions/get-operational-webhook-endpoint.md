# Get Operational Webhook Endpoint with Svix

Retrieves an operational webhook endpoint from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Operational Webhook Endpoint](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.get)
