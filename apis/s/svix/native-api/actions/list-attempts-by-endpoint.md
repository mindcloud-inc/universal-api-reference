# List Attempts By Endpoint with Svix

Retrieves delivery attempts for a specific Svix endpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/attempt/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Attempts By Endpoint](https://api.svix.com/docs#operation/v1.message-attempt.list-by-endpoint)
