# Create Stream Event Type with Svix

Creates a stream event type in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/stream/event-type`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Create Stream Event Type](https://api.svix.com/docs#operation/v1.streaming.event-type.create)
