# Delete Event Type with Svix

Archives an event type in Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/event-type/{event_type_name}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Event Type](https://api.svix.com/docs#operation/v1.event-type.delete)
