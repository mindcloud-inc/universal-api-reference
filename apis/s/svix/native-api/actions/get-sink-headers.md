# Get Sink Headers with Svix

Retrieves sink headers from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Sink Headers](https://api.svix.com/docs#operation/v1.streaming.sink-headers-get)
