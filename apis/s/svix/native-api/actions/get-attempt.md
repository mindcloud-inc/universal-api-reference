# Get Attempt with Svix

Retrieves a specific delivery attempt from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/msg/{msg_id}/attempt/{attempt_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Attempt](https://api.svix.com/docs#operation/v1.message-attempt.get)
