# Get Integration with Svix

Retrieves an integration from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/integration/{integ_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Integration](https://api.svix.com/docs#operation/v1.integration.get)
