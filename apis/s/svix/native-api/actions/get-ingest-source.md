# Get Ingest Source with Svix

Retrieves an ingest source from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Ingest Source](https://api.svix.com/docs#operation/v1.ingest.source.get)
