# Set Sink Transformation with Svix

Updates transformation code for a Svix sink.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Set Sink Transformation](https://api.svix.com/docs#operation/v1.streaming.sink.transformation-partial-update)
