# Poller Sink Stream Events with Svix

Retrieves stream events from a Svix sink.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/events`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Poller Sink Stream Events](https://api.svix.com/docs#operation/v1.streaming.events.get)
