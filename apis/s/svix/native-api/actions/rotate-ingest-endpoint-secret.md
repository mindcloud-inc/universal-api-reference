# Rotate Ingest Endpoint Secret with Svix

Rotates an ingest endpoint secret in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/secret/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Ingest Endpoint Secret](https://api.svix.com/docs#operation/v1.ingest.endpoint.rotate-secret)
