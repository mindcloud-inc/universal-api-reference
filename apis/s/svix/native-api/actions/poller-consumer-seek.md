# Poller Consumer Seek with Svix

Sets a Svix sink consumer poller offset.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/poller/{sink_id}/consumer/{consumer_id}/seek`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Poller Consumer Seek](https://api.svix.com/docs#operation/v1.message.poller.consumer-seek)
