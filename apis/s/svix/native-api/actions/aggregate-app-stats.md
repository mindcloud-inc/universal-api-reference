# Aggregate App Stats with Svix

Starts background aggregation of Svix application statistics.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/stats/usage/app`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Aggregate App Stats](https://api.svix.com/docs#operation/v1.statistics.aggregate-app-stats)
