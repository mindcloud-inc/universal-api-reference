# Update Stream Event Type with Svix

Creates or updates a stream event type in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/stream/event-type/{name}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Stream Event Type](https://api.svix.com/docs#operation/v1.streaming.event-type.update)
