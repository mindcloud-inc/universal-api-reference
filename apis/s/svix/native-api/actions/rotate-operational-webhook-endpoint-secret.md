# Rotate Operational Webhook Endpoint Secret with Svix

Rotates an operational webhook endpoint secret in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}/secret/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Operational Webhook Endpoint Secret](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.rotate-secret)
