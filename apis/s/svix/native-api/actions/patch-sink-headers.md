# Patch Sink Headers with Svix

Updates sink headers in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Sink Headers](https://api.svix.com/docs#operation/v1.streaming.sink-headers-patch)
