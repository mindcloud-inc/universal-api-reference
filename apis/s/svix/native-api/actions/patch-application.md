# Patch Application with Svix

Updates an application in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/app/{app_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Application](https://api.svix.com/docs#operation/v1.application.patch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | The application's ID or UID. |
