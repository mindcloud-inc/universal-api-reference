# Create Message Precheck with Svix

Checks active Svix endpoints before creating a message.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/msg/precheck/active`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Create Message Precheck](https://api.svix.com/docs#operation/v1.message.precheck)
