# Rotate Ingest Token with Svix

Rotates an ingest source token in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/ingest/api/v1/source/{source_id}/token/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Ingest Token](https://api.svix.com/docs#operation/v1.ingest.source.rotate-token)
