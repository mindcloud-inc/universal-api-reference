# Delete Ingest Endpoint with Svix

Deletes an ingest endpoint from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Ingest Endpoint](https://api.svix.com/docs#operation/v1.ingest.endpoint.delete)
