# Delete Stream Event Type with Svix

Deletes a stream event type from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/stream/event-type/{name}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Stream Event Type](https://api.svix.com/docs#operation/v1.streaming.event-type.delete)
