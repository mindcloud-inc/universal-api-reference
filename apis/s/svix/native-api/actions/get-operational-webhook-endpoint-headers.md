# Get Operational Webhook Endpoint Headers with Svix

Retrieves operational webhook endpoint headers from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Operational Webhook Endpoint Headers](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.get-headers)
