# Get Ingest Endpoint Secret with Svix

Retrieves an ingest endpoint secret from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/secret`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Ingest Endpoint Secret](https://api.svix.com/docs#operation/v1.ingest.endpoint.get-secret)
