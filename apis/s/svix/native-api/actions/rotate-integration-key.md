# Rotate Integration Key with Svix

Rotates an integration key in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/integration/{integ_id}/key/rotate`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Rotate Integration Key](https://api.svix.com/docs#operation/v1.integration.rotate-key)
