# Delete Message Payload with Svix

Deletes a message payload from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/app/{app_id}/msg/{msg_id}/content`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Message Payload](https://api.svix.com/docs#operation/v1.message.expunge-content)
