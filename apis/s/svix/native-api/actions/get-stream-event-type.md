# Get Stream Event Type with Svix

Retrieves a stream event type from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/event-type/{name}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Stream Event Type](https://api.svix.com/docs#operation/v1.streaming.event-type.get)
