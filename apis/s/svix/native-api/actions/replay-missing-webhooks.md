# Replay Missing Webhooks with Svix

Replays missing webhooks to a specific Svix endpoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/replay-missing`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Replay Missing Webhooks](https://api.svix.com/docs#operation/v1.endpoint.replay-missing)
