# Patch Endpoint Transformation with Svix

Updates an endpoint transformation in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Endpoint Transformation](https://api.svix.com/docs#operation/v1.endpoint.patch-transformation)
