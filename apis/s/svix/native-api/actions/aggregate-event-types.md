# Aggregate Event Types with Svix

Starts background aggregation of Svix event types.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/stats/usage/event-types`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Aggregate Event Types](https://api.svix.com/docs#operation/v1.statistics.aggregate-event-types)
