# Get Sink Transformation with Svix

Retrieves a sink transformation from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/stream/{stream_id}/sink/{sink_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Sink Transformation](https://api.svix.com/docs#operation/v1.streaming.sink-transformation-get)
