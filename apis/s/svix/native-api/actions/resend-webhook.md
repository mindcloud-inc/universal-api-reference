# Resend Webhook with Svix

Resends a webhook to a specific Svix endpoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/msg/{msg_id}/endpoint/{endpoint_id}/resend`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Resend Webhook](https://api.svix.com/docs#operation/v1.message-attempt.resend)
