# Expire All with Svix

Expires all application tokens in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/auth/app/{app_id}/expire-all`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Expire All](https://api.svix.com/docs#operation/v1.authentication.expire-all)
