# Patch Stream Event Type with Svix

Updates a stream event type in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/stream/event-type/{name}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Stream Event Type](https://api.svix.com/docs#operation/v1.streaming.event-type.patch)
