# Create Ingest Endpoint with Svix

Creates an ingest endpoint in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Create Ingest Endpoint](https://api.svix.com/docs#operation/v1.ingest.endpoint.create)
