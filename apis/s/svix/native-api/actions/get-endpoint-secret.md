# Get Endpoint Secret with Svix

Retrieves an endpoint secret from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/secret`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Endpoint Secret](https://api.svix.com/docs#operation/v1.endpoint.get-secret)
