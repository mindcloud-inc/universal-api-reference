# Get Endpoint Transformation with Svix

Retrieves an endpoint transformation from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/transformation`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Endpoint Transformation](https://api.svix.com/docs#operation/v1.endpoint.transformation-get)
