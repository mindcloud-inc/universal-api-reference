# Get Stream Portal Access with Svix

Retrieves stream portal access from Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/auth/stream-portal-access/{stream_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Stream Portal Access](https://api.svix.com/docs#operation/v1.authentication.stream-portal-access)
