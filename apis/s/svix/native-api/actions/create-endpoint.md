# Create Endpoint with Svix

Creates an endpoint in Svix.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Create Endpoint](https://api.svix.com/docs#operation/v1.endpoint.create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | The application's ID or UID. |
