# Recover Failed Webhooks with Svix

Recovers failed webhooks for a specific Svix endpoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/recover`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Recover Failed Webhooks](https://api.svix.com/docs#operation/v1.endpoint.recover)
