# List Attempted Destinations with Svix

Retrieves attempted destinations for a specific Svix message.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/msg/{msg_id}/endpoint`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [List Attempted Destinations](https://api.svix.com/docs#operation/v1.message-attempt.list-attempted-destinations)
