# Send Event Type Example Message with Svix

Sends an example event message to a Svix endpoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/send-example`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Send Event Type Example Message](https://api.svix.com/docs#operation/v1.endpoint.send-example)
