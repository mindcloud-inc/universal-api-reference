# Get Application with Svix

Retrieves an application from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Application](https://api.svix.com/docs#operation/v1.application.get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | The application's ID or UID. |
