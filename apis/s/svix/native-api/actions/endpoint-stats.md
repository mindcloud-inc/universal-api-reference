# Endpoint Stats with Svix

Retrieves statistics for a specific Svix endpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/stats`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Endpoint Stats](https://api.svix.com/docs#operation/v1.endpoint.get-stats)
