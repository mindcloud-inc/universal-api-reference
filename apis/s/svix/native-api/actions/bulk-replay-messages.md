# Bulk Replay Messages with Svix

Replays messages for a specific Svix endpoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/bulk-replay`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Bulk Replay Messages](https://api.svix.com/docs#operation/v1.endpoint.bulk-replay)
