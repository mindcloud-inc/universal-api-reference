# Get Background Task with Svix

Retrieves a background task from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/background-task/{task_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Background Task](https://api.svix.com/docs#operation/v1.background-task.get)
