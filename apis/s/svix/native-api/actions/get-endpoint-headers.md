# Get Endpoint Headers with Svix

Retrieves endpoint headers from Svix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Endpoint Headers](https://api.svix.com/docs#operation/v1.endpoint.get-headers)
