# Expunge All Message Contents with Svix

Deletes all message payloads from a Svix application.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/app/{app_id}/msg/expunge-all-contents`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Expunge All Message Contents](https://api.svix.com/docs#operation/v1.message.expunge-all-contents)
