# Update Ingest Endpoint Headers with Svix

Updates ingest endpoint headers in Svix.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ingest/api/v1/source/{source_id}/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Update Ingest Endpoint Headers](https://api.svix.com/docs#operation/v1.ingest.endpoint.update-headers)
