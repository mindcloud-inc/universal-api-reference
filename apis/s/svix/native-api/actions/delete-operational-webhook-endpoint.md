# Delete Operational Webhook Endpoint with Svix

Deletes an operational webhook endpoint from Svix.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/operational-webhook/endpoint/{endpoint_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Delete Operational Webhook Endpoint](https://api.svix.com/docs#operation/v1.operational-webhook.endpoint.delete)
