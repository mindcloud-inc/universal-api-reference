# Patch Endpoint Headers with Svix

Updates endpoint headers in Svix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/app/{app_id}/endpoint/{endpoint_id}/headers`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Patch Endpoint Headers](https://api.svix.com/docs#operation/v1.endpoint.patch-headers)
