# Get Poller Token with Svix

Retrieves the current Svix poller token.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/auth/stream/{stream_id}/sink/{sink_id}/poller/token`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Get Poller Token](https://api.svix.com/docs#operation/v1.authentication.get-stream-poller-token)
