# Poller Consumer Poll with Svix

Retrieves polled messages for a Svix sink consumer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/poller/{sink_id}/consumer/{consumer_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Poller Consumer Poll](https://api.svix.com/docs#operation/v1.message.poller.consumer-poll)
