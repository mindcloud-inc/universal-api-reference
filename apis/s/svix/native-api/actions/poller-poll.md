# Poller Poll with Svix

Retrieves polled messages from a Svix sink.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/app/{app_id}/poller/{sink_id}`
- **Base URL:** `https://api.us.svix.com`
- **Official documentation:** [Poller Poll](https://api.svix.com/docs#operation/v1.message.poller.poll)
