# Send Portal Invitation Email with Superglue

## Endpoint

- **Method:** `POST`
- **Path:** `/end-users/:endUserId/invite`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [Send Portal Invitation Email](https://docs.superglue.cloud/api-reference/end-users-enterprise/send-portal-invitation-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endUserId` | path | `string` | yes | Internal Superglue end-user ID. |
