# Generate Portal Link with Superglue

## Endpoint

- **Method:** `POST`
- **Path:** `/end-users/:endUserId/portal-token`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [Generate Portal Link](https://docs.superglue.cloud/api-reference/end-users-enterprise/generate-portal-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endUserId` | path | `string` | yes | Internal Superglue end-user ID. |
