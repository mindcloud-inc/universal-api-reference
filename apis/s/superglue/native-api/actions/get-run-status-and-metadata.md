# Get Run Status and Metadata with Superglue

Retrieves run status and metadata from Superglue.

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/:runId`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [Get Run Status and Metadata](https://docs.superglue.cloud/api-reference/runs/get-run-status-and-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `runId` | path | `string` | yes | ID of the Superglue run. |
