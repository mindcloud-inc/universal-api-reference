# List Tools with Superglue

Retrieves tools from Superglue.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [List Tools](https://docs.superglue.cloud/api-reference/tools/list-tools)

## Capabilities

This operation supports [pagination](../README.md#pagination).
