- **Method:** `DELETE`
- **Path:** `/end-users/:endUserId`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [Delete End User](https://docs.superglue.cloud/api-reference/end-users-enterprise/delete-end-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endUserId` | path | `string` | yes | Internal Superglue end-user ID. |
