# Get End User Details with Superglue

## Endpoint

- **Method:** `GET`
- **Path:** `/end-users/:endUserId`
- **Base URL:** `https://api.superglue.ai/v1`
- **Official documentation:** [Get End User Details](https://docs.superglue.cloud/api-reference/end-users-enterprise/get-end-user-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endUserId` | path | `string` | yes | Internal Superglue end-user ID. |
