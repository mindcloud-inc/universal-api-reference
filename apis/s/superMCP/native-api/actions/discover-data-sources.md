# Discover Data Sources with SuperMCP

## Endpoint

- **Method:** `POST`
- **Path:** `/mcp/data_source_discovery`
- **Base URL:** `https://mcp.supermetrics.com`
- **Official documentation:** [Discover Data Sources](https://mcp.supermetrics.com/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `compress` | body | `boolean` | no | Return a compact TOON response instead of JSON when supported. |
