# Delete Email List with Sendcrux

Deletes an email list from Sendcrux.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/lists`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Delete Email List](https://api.sendbound.com/email-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | query | `string` | yes | The unique identifier of the list to delete. |
