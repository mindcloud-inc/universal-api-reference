# Get Email List with Sendcrux

Retrieves an email list from Sendcrux by UID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/lists/:uid`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Get Email List](https://api.sendbound.com/email-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique identifier of the list. |
