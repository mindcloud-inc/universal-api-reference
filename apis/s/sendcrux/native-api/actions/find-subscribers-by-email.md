# Find Subscribers By Email with Sendcrux

Finds subscribers in Sendcrux by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/subscribers/email/:email`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Find Subscribers By Email](https://api.sendbound.com/subscribers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email address used to find matching subscribers. |
