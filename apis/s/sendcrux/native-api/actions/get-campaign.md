# Get Campaign with Sendcrux

Retrieves a campaign from Sendcrux by UID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaigns/:uid`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Get Campaign](https://api.sendbound.com/campaign/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique identifier of the campaign. |
