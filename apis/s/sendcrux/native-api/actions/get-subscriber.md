# Get Subscriber with Sendcrux

Retrieves a subscriber from Sendcrux by UID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/subscribers/:uid`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Get Subscriber](https://api.sendbound.com/subscribers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique identifier of the subscriber. |
