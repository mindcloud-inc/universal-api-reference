# Delete Subscriber with Sendcrux

Deletes an existing subscriber from Sendcrux.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/subscribers/:uid`
- **Base URL:** `https://sendcrux.com`
- **Official documentation:** [Delete Subscriber](https://api.sendbound.com/subscribers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The unique identifier of the subscriber to delete. |
