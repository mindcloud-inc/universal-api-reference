# Get Sign Request by Key with Stiply

Retrieves a Stiply sign request by key.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sign_requests/by_key/:sign_request_key`
- **Base URL:** `https://api.stiply.nl`
- **Official documentation:** [Get Sign Request by Key](https://app.stiply.nl/api-documentation/v2#tag/sign-requests/operation/GetSignRequestByKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sign_request_key` | path | `string` | yes | Key of the signrequest. |
