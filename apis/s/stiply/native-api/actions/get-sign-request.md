# Get Sign Request with Stiply

Retrieves a sign request from Stiply by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sign_requests/:sign_request`
- **Base URL:** `https://api.stiply.nl`
- **Official documentation:** [Get Sign Request](https://app.stiply.nl/api-documentation/v2#tag/sign-requests/operation/GetSignRequest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sign_request` | path | `number` | yes | Id of the signrequest. |
