# Get Sign Request by External Key with Stiply

Retrieves a Stiply sign request by external key.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sign_requests/by_key/:external_key`
- **Base URL:** `https://api.stiply.nl`
- **Official documentation:** [Get Sign Request by External Key](https://app.stiply.nl/api-documentation/v2#tag/sign-requests/operation/GetSignRequestByExternalKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `external_key` | path | `string` | yes | External key. |
