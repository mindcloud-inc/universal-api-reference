# Delete Sign Request with Stiply

Deletes an existing sign request from Stiply.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/sign_requests/:sign_request`
- **Base URL:** `https://api.stiply.nl`
- **Official documentation:** [Delete Sign Request](https://app.stiply.nl/api-documentation/v2#tag/sign-requests/operation/DeleteSignRequest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sign_request` | path | `number` | yes | Id of the signrequest. |
