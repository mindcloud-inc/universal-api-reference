# Get Ticket with Syncro

Retrieves a ticket from Syncro by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:id`
- **Base URL:** `https://mindcloud.syncromsp.com/api/v1`
- **Official documentation:** [Get Ticket](https://api-docs.syncromsp.com/#/Ticket/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Syncro ticket ID. |
