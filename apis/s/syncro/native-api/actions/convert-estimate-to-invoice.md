# Convert Estimate To Invoice with Syncro

Creates an invoice from an estimate in Syncro.

## Endpoint

- **Method:** `POST`
- **Path:** `/estimates/:id/convert_to_invoice`
- **Base URL:** `https://mindcloud.syncromsp.com/api/v1`
- **Official documentation:** [Convert Estimate To Invoice](https://api-docs.syncromsp.com/#/Estimate/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
