# List Payments with Syncro

Retrieves a list of payments from Syncro.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments`
- **Base URL:** `https://mindcloud.syncromsp.com/api/v1`
- **Official documentation:** [List Payments](https://api-docs.syncromsp.com/#/Payment/)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | no |
| `page` | query | `number` | no |
