# Move Rows To Big Data Backend with SeaTable

Moves rows to a SeaTable big data backend.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/archive-view/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Move Rows To Big Data Backend](https://api.seatable.com/reference/moverowstobigdata)
