# Get Base Big Data Operations with SeaTable

Retrieves big data operations for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/db-operations/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Base Big Data Operations](https://api.seatable.com/reference/getbasebigdataoperations)
