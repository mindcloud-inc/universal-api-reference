# Delete Column with SeaTable

Deletes a column from a SeaTable base.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/columns/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Column](https://api.seatable.com/reference/deletecolumn-1)
