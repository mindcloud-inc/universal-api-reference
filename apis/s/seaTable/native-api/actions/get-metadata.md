# Get Metadata with SeaTable

Retrieves metadata for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/metadata/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Metadata](https://api.seatable.com/reference/getmetadata)
