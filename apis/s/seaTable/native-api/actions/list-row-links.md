# List Row Links with SeaTable

Lists row links in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/query-links/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Row Links](https://api.seatable.com/reference/listrowlinks)
