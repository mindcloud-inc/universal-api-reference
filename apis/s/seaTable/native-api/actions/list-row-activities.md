# List Row Activities with SeaTable

Lists row activities in a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/activities/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Row Activities](https://api.seatable.com/reference/listrowactivities-1)
