# Query SeaTable With SQL with SeaTable

Queries a SeaTable base with SQL.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/sql/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Query SeaTable With SQL](https://api.seatable.com/reference/querysql)
