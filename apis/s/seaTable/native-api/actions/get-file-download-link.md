# Get File Download Link with SeaTable

Retrieves a download link for a SeaTable file.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/app-download-link/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get File Download Link](https://api.seatable.com/reference/getfiledownloadlink)
