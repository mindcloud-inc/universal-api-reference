# Delete Single/Multiple Select Options with SeaTable

Deletes single or multiple select options from SeaTable.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/column-options/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Single/Multiple Select Options](https://api.seatable.com/reference/deleteselectoption-1)
