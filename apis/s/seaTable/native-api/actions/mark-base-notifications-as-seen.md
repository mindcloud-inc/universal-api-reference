# Mark Base Notifications as Seen with SeaTable

Marks all notifications as seen in a SeaTable base.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/notifications/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Mark Base Notifications as Seen](https://api.seatable.com/reference/markbasenotificationsasseen-1)
