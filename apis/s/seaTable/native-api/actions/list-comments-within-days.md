# List Comments Within Days with SeaTable

Lists comments from a SeaTable base within specific days.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/comments-within-days/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Comments Within Days](https://api.seatable.com/reference/listcommentswithindays)
