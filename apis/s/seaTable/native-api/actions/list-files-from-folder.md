# List Files from Folder with SeaTable

Lists files from a SeaTable custom folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/custom/app-asset-dir/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Files from Folder](https://api.seatable.com/reference/getcustomfiles)
