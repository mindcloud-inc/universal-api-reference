# Get Number of Comments with SeaTable

Retrieves the number of comments in a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtables/:base_uuid/rows-comments-num/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Number of Comments](https://api.seatable.com/reference/getnumberofcomments)
