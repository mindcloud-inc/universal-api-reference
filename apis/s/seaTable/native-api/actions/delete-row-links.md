# Delete Row Links with SeaTable

Deletes row links from a SeaTable base.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/links/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Row Links](https://api.seatable.com/reference/deleterowlink)
