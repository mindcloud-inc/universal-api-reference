# List Row Comments with SeaTable

Lists row comments in a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/comments/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Row Comments](https://api.seatable.com/reference/listrowcomments)
