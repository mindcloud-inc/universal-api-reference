# Add Rows Into Big Data Backend with SeaTable

Adds rows to a SeaTable big data backend.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/add-archived-rows/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Add Rows Into Big Data Backend](https://api.seatable.com/reference/addbigdatarows)
