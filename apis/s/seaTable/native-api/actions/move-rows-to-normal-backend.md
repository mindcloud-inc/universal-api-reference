# Move Rows To Normal Backend with SeaTable

Moves rows back to a SeaTable normal backend.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/unarchive/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Move Rows To Normal Backend](https://api.seatable.com/reference/moverowstonormalbackend)
