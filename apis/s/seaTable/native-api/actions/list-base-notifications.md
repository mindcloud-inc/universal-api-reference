# List Base Notifications with SeaTable

Lists notifications for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/notifications/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Base Notifications](https://api.seatable.com/reference/listbasenotifications-2)
