# Get Auto Link Task with SeaTable

Retrieves an auto link task from SeaTable.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/auto-link-task/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Auto Link Task](https://api.seatable.com/reference/autolinktask)
