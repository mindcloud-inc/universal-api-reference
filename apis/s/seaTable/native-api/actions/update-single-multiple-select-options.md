# Update Single/Multiple Select Options with SeaTable

Updates single or multiple select options in SeaTable.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/column-options/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Update Single/Multiple Select Options](https://api.seatable.com/reference/updateselectoption-1)
