# Create Row Links with SeaTable

Creates row links in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/links/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Create Row Links](https://api.seatable.com/reference/createrowlink)
