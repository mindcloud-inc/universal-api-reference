# Create Auto Links with SeaTable

Creates automatic row links in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/auto-links/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Create Auto Links](https://api.seatable.com/reference/autolinks)
