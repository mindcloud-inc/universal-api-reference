# Append Columns with SeaTable

Creates multiple columns in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/batch-append-columns/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Append Columns](https://api.seatable.com/reference/appendcolumns-1)
