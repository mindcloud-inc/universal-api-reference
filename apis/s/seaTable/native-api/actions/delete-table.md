# Delete Table with SeaTable

Deletes a table from a SeaTable base.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/tables/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Table](https://api.seatable.com/reference/deletetable)
