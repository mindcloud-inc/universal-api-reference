# Get Custom Folder Download Link with SeaTable

Retrieves a download link for a SeaTable custom folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/custom/app-download-link/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Custom Folder Download Link](https://api.seatable.com/reference/getcustomdownloadlink)
