# Update Row Links with SeaTable

Updates row links in a SeaTable base.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/links/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Update Row Links](https://api.seatable.com/reference/updaterowlink)
