# List Collaborators with SeaTable

Lists collaborators for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/related-users/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [List Collaborators](https://api.seatable.com/reference/listcollaborators)
