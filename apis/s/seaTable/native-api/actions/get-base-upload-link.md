# Get Base Upload Link with SeaTable

Retrieves an upload link for a SeaTable base asset.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/app-upload-link/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Base Upload Link](https://api.seatable.com/reference/getuploadlink)
