# Duplicate Table with SeaTable

Duplicates a table in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/tables/duplicate-table/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Duplicate Table](https://api.seatable.com/reference/duplicatetable)
