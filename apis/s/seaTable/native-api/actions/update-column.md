# Update Column with SeaTable

Updates a column in a SeaTable base.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/columns/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Update Column](https://api.seatable.com/reference/updatecolumn-1)
