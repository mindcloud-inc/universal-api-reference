# Get Custom Folder Upload Link with SeaTable

Retrieves an upload link for a SeaTable custom folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/custom/app-upload-link/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Custom Folder Upload Link](https://api.seatable.com/reference/getcustomuploadlink)
