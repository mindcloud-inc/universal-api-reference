# Delete Base Asset with SeaTable

Deletes an asset from a SeaTable base.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2.1/dtable/app-asset/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Base Asset](https://api.seatable.com/reference/deletebaseasset-2)
