# Delete Base Asset In Custom Folder with SeaTable

Deletes an asset from a SeaTable custom folder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2.1/dtable/custom/app-asset-file/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Base Asset In Custom Folder](https://api.seatable.com/reference/deletebasecustomfolderasset-1)
