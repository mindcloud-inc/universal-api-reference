# Get Base Activity Log with SeaTable

Retrieves the activity log for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/operations/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Base Activity Log](https://api.seatable.com/reference/getbaseactivitylog-1)
