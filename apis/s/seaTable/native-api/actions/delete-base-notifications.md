# Delete Base Notifications with SeaTable

Deletes notifications from a SeaTable base.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/notifications/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Delete Base Notifications](https://api.seatable.com/reference/deletebasenotifications-1)
