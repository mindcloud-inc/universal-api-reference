# Insert Column with SeaTable

Creates a column in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/columns/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Insert Column](https://api.seatable.com/reference/insertcolumn-1)
