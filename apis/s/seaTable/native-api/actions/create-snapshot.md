# Create Snapshot with SeaTable

Creates a snapshot of a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/snapshot/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Create Snapshot](https://api.seatable.com/reference/createsnapshot)
