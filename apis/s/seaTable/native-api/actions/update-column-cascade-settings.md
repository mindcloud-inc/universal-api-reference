# Update Column Cascade Settings with SeaTable

Updates column cascade settings in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/column-cascade-settings/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Update Column Cascade Settings](https://api.seatable.com/reference/updatecolumncascade-1)
