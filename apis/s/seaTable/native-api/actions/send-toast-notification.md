# Send Toast Notification with SeaTable

Sends a toast notification in a SeaTable base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/ui-toasts/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Send Toast Notification](https://api.seatable.com/reference/sendtoastnotification-1)
