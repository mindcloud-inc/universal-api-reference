# Add Single/Multiple Select Options with SeaTable

Creates single or multiple select options in SeaTable.

## Endpoint

- **Method:** `POST`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/column-options/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Add Single/Multiple Select Options](https://api.seatable.com/reference/addselectoption-1)
