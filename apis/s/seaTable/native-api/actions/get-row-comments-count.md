# Get Row Comments Count with SeaTable

Retrieves the row comment count for a SeaTable base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-gateway/api/v2/dtables/:base_uuid/comments-count/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Row Comments Count](https://api.seatable.com/reference/getrowcommentscount)
