# Get File Metadata with SeaTable

Retrieves metadata for a file in a SeaTable custom folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/custom/app-asset-file/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get File Metadata](https://api.seatable.com/reference/getcustomfilemetadata)
