# Get Base Token With API Token with SeaTable

Retrieves a SeaTable base token with an API token.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2.1/dtable/app-access-token/`
- **Base URL:** `https://cloud.seatable.io`
- **Official documentation:** [Get Base Token With API Token](https://api.seatable.com/reference/getbasetokenwithapitoken)
