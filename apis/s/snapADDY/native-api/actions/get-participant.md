# Get Participant with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/participant/:participantId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Participant](https://developers.snapaddy.com/visitreport-rest-api/reference/participant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `participantId` | path | `string` | yes | Participant identifier |
