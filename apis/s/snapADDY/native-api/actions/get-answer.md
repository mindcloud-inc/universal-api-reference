# Get Answer with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/answer/:answerId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Answer](https://developers.snapaddy.com/visitreport-rest-api/reference/answer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `answerId` | path | `string` | yes | Answer identifier |
