# Get Contact List Count with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/grabber/v1/contactlist/:listId/count`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Contact List Count](https://developers.snapaddy.com/dataquality-rest-api/reference/contact-list-size)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Contact list identifier |
