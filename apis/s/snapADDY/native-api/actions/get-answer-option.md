# Get Answer Option with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/answerOption/:answerOptionId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Answer Option](https://developers.snapaddy.com/visitreport-rest-api/reference/answer-option)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `answerOptionId` | path | `string` | yes | Answer option identifier |
