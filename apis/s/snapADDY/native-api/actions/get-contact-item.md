# Get Contact Item with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/grabber/v1/contactitem/:itemId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Contact Item](https://developers.snapaddy.com/dataquality-rest-api/reference/contact-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Contact item identifier |
