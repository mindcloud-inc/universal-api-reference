# Get Questionnaire with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/backend/questionnaires/:questionnaireId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Questionnaire](https://developers.snapaddy.com/visitreport-rest-api/reference/questionnaire)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionnaireId` | path | `string` | yes | Questionnaire identifier |
