# Get Question Option with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/questionOption/:questionOptionId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Question Option](https://developers.snapaddy.com/visitreport-rest-api/reference/question-option)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionOptionId` | path | `string` | yes | Question option identifier |
