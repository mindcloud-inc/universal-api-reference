# Get Contact Item Attachment with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/grabber/v1/attachment/:contactItemId/:attachmentId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Contact Item Attachment](https://developers.snapaddy.com/dataquality-rest-api/reference/contact-item-attachment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactItemId` | path | `string` | yes | Contact item identifier |
| `attachmentId` | path | `string` | yes | Attachment identifier |
