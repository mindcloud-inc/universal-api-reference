- **Method:** `GET`
- **Path:** `/visitreport/v1/group/:groupId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Group](https://developers.snapaddy.com/visitreport-rest-api/reference/group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Group identifier |
