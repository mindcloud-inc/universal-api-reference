# Get Question with snapADDY

## Endpoint

- **Method:** `GET`
- **Path:** `/visitreport/v1/question/:questionId`
- **Base URL:** `https://api.snapaddy.com`
- **Official documentation:** [Get Question](https://developers.snapaddy.com/visitreport-rest-api/reference/question)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionId` | path | `string` | yes | Question identifier |
