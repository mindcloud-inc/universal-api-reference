# List Contacts with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/contact`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [List Contacts](https://docs.sendx.io/api-reference/contact/get-all-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search contacts by first name, last name, or email. |
