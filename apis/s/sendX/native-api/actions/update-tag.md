# Update Tag with SendX

## Endpoint

- **Method:** `PUT`
- **Path:** `/tag/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Update Tag](https://docs.sendx.io/api-reference/tag/update-tag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identifier` | path | `string` | yes |
| `name` | body | `string` | yes |
