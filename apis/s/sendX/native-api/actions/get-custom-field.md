# Get Custom Field with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/customfield/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Custom Field](https://docs.sendx.io/api-reference/custom-field/get-custom-field-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX custom field identifier. |
