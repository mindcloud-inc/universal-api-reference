# Get Tag with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Tag](https://docs.sendx.io/api-reference/tag/get-tag-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX tag identifier. |
