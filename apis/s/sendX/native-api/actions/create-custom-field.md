# Create Custom Field with SendX

## Endpoint

- **Method:** `POST`
- **Path:** `/customfield`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Create Custom Field](https://docs.sendx.io/api-reference/custom-field/create-custom-field)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `type` | body | `number` | yes |
| `description` | body | `string` | yes |
