# Get Template with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/template/email/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Template](https://docs.sendx.io/api-reference/template/get-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX template identifier. |
