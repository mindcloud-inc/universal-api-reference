# Get List with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/list/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get List](https://docs.sendx.io/api-reference/list/get-list-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX list identifier. |
