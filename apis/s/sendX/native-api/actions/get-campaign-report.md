# Get Campaign Report with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/report/campaign/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Campaign Report](https://docs.sendx.io/api-reference/report/get-campaign-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX campaign identifier. |
