# Get Contact with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Contact](https://docs.sendx.io/api-reference/contact/get-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX contact identifier. |
