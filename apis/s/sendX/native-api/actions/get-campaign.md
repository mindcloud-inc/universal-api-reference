# Get Campaign with SendX

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:identifier`
- **Base URL:** `https://api.sendx.io/api/v1/rest`
- **Official documentation:** [Get Campaign](https://docs.sendx.io/api-reference/campaign/get-campaign-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | no | The SendX campaign identifier. |
