# List Job Items with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/job_items`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [List Job Items](https://api.streamtime.net/v2/swagger#/Jobs/listJobItems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `number` | yes | Job ID |
