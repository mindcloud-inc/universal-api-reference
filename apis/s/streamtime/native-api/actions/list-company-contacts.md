# List Company Contacts with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:company_id/contacts`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [List Company Contacts](https://api.streamtime.net/v2/swagger#/Companies/listCompanyContacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `number` | yes | Company ID |
