# List Job Phases with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/job_phases`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [List Job Phases](https://api.streamtime.net/v2/swagger#/Jobs/listJobPhases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `number` | yes | Job ID |
