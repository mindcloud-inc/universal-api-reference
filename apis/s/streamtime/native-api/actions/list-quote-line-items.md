# List Quote Line Items with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/:quote_id/quote_line_items`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [List Quote Line Items](https://api.streamtime.net/v2/swagger#/Quotes/listQuoteLineItems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quote_id` | path | `number` | yes | Quote ID. |
