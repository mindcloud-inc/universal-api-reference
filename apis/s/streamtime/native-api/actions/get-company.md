# Get Company with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [Get Company](https://api.streamtime.net/v2/swagger#/Companies/getCompany)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `number` | yes | Company ID |
