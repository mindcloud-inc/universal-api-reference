# Get User with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [Get User](https://api.streamtime.net/v2/swagger#/Users/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | User ID |
