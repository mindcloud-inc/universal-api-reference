# List Invoice Line Items with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id/invoice_line_items`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [List Invoice Line Items](https://api.streamtime.net/v2/swagger#/Invoices/getInvoiceLineItems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID. |
