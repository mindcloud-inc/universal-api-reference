# Get Invoice with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [Get Invoice](https://api.streamtime.net/v2/swagger#/Invoices/getInvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID. |
