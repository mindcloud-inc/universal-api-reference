# Get Logged Time Entry with Streamtime

## Endpoint

- **Method:** `GET`
- **Path:** `/logged_times/:logged_time_id`
- **Base URL:** `https://api.streamtime.net/v2`
- **Official documentation:** [Get Logged Time Entry](https://api.streamtime.net/v2/swagger#/ToDos/getLoggedTime)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `logged_time_id` | path | `number` | yes | Logged time entry ID. |
