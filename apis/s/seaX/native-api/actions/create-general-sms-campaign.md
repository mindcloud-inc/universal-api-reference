# Create General SMS Campaign with SeaX

Creates a general SMS campaign in SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/general_campaigns/sms`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create General SMS Campaign](https://api.seasalt.ai/seax/)
