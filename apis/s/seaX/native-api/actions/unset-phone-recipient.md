# Unset Phone Recipient with SeaX

Updates a SeaX phone by clearing its recipient.

## Endpoint

- **Method:** `POST`
- **Path:** `/phones/{phone_id}/unset_recipient`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Unset Phone Recipient](https://api.seasalt.ai/seax/)
