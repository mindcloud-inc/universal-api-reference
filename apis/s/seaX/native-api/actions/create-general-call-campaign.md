# Create General Call Campaign with SeaX

Creates a general call campaign in SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/general_campaigns/call`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create General Call Campaign](https://api.seasalt.ai/seax/)
