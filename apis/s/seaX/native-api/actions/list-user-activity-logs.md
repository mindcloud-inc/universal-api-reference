# List User Activity Logs with SeaX

Retrieves user activity logs from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_activity_logs`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List User Activity Logs](https://api.seasalt.ai/seax/)
