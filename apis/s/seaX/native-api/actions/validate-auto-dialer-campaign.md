# Validate Auto Dialer Campaign with SeaX

Validates a SeaX auto dialer campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/validate`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Validate Auto Dialer Campaign](https://api.seasalt.ai/seax/)
