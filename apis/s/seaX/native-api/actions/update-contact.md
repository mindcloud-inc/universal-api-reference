# Update Contact with SeaX

Updates a contact in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update Contact](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact identifier. |
