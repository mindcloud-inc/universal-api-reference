# Unset Verified Caller with SeaX

Updates a SeaX phone by unsetting its verified caller.

## Endpoint

- **Method:** `POST`
- **Path:** `/phones/{phone_id}/unset`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Unset Verified Caller](https://api.seasalt.ai/seax/)
