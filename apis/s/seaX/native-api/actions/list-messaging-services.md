# List Messaging Services with SeaX

Retrieves messaging services from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/messaging_services`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Messaging Services](https://api.seasalt.ai/seax/)
