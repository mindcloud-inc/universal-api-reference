# Get Messaging Service with SeaX

Retrieves a messaging service from SeaX.

## Endpoint

- **Method:** `GET`
- **Path:** `/messaging_services/{messaging_service_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Get Messaging Service](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messaging_service_id` | path | `string` | yes | Messaging service identifier. |
