# Update Contact Label with SeaX

Updates a contact label in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contact_labels/{contact_label_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update Contact Label](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_label_id` | path | `string` | yes | Contact label identifier. |
