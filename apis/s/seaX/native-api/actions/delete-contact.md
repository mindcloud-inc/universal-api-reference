# Delete Contact with SeaX

Deletes a contact from the current SeaX workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Delete Contact](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact identifier. |
