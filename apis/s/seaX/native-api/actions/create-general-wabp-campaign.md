# Create General WABP Campaign with SeaX

Creates a general WhatsApp campaign in SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/general_campaigns/wabp`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create General WABP Campaign](https://api.seasalt.ai/seax/)
