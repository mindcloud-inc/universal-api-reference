# Upsert Messenger Integration with SeaX

Updates Messenger integration settings in SeaX.

## Endpoint

- **Method:** `PUT`
- **Path:** `/messenger`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Upsert Messenger Integration](https://api.seasalt.ai/seax/)
