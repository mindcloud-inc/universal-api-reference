# List Contacts with SeaX

Retrieves contacts from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Contacts](https://api.seasalt.ai/seax/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
