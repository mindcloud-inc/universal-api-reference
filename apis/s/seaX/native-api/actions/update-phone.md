# Update Phone with SeaX

Updates a phone number in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/phones/{phone_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update Phone](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_id` | path | `string` | yes | Phone identifier. |
