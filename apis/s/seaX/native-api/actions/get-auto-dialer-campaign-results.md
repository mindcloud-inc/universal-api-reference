# Get Auto Dialer Campaign Results with SeaX

Retrieves structured results for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/results`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Get Auto Dialer Campaign Results](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auto_dialer_campaign_id` | path | `string` | yes | Auto dialer campaign identifier. |
