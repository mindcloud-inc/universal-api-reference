# Create Auto Dialer Campaign Webhook with SeaX

Creates a webhook for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/webhooks`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create Auto Dialer Campaign Webhook](https://api.seasalt.ai/seax/)
