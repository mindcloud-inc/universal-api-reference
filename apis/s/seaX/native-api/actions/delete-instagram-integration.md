# Delete Instagram Integration with SeaX

Deletes an Instagram integration from SeaX by phone.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/instagram/phone/{phone_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Delete Instagram Integration](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_id` | path | `string` | yes | Phone identifier. |
