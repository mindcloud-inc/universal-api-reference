# Download Auto Dialer Campaign Contact Template with SeaX

Retrieves a contact template for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/download_contact_template`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Download Auto Dialer Campaign Contact Template](https://api.seasalt.ai/seax/)
