# Download Campaign Contact Template with SeaX

Retrieves a contact template for a SeaX campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaign_id}/download_contact_template`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Download Campaign Contact Template](https://api.seasalt.ai/seax/)
