# List Voice Call Sessions with SeaX

Retrieves voice call sessions from SeaX.

## Endpoint

- **Method:** `GET`
- **Path:** `/voice_call_sessions`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Voice Call Sessions](https://api.seasalt.ai/seax/)
