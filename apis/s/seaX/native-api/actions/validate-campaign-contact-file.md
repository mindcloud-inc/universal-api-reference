# Validate Campaign Contact File with SeaX

Validates a contact file for a SeaX campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/{campaign_id}/validate_contact_file`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Validate Campaign Contact File](https://api.seasalt.ai/seax/)
