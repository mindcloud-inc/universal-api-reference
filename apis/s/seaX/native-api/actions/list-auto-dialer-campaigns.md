# List Auto Dialer Campaigns with SeaX

Retrieves auto dialer campaigns from SeaX.

## Endpoint

- **Method:** `GET`
- **Path:** `/auto_dialer_campaigns`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Auto Dialer Campaigns](https://api.seasalt.ai/seax/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
