# Delete Phone with SeaX

Deletes a phone number from the current SeaX workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/phones/{phone_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Delete Phone](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_id` | path | `string` | yes | Phone identifier. |
