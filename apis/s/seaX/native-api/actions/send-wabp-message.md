# Send WABP Message with SeaX

Sends a direct WhatsApp message from SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/messages/wabp`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Send WABP Message](https://api.seasalt.ai/seax/)
