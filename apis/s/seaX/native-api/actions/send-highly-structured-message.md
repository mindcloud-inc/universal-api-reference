# Send Highly Structured Message with SeaX

Sends a structured WhatsApp message from SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/highly_structured_message/message`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Send Highly Structured Message](https://api.seasalt.ai/seax/)
