# Dry Run Auto Dialer Campaign with SeaX

Retrieves a dry run preview for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/auto_dialer_campaigns/dry_run`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Dry Run Auto Dialer Campaign](https://api.seasalt.ai/seax/)
