# Update API Key with SeaX

Updates an API key in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api_keys/{api_key_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update API Key](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key_id` | path | `string` | yes | API key identifier. |
