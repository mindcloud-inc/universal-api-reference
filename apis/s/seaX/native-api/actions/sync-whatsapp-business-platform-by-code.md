# Sync WhatsApp Business Platform By Code with SeaX

Adds a WhatsApp Business Platform account to SeaX by code.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp_business_platform`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Sync WhatsApp Business Platform By Code](https://api.seasalt.ai/seax/)
