# Create Campaign Webhook with SeaX

Creates a webhook for a SeaX campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/{campaign_id}/webhooks`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create Campaign Webhook](https://api.seasalt.ai/seax/)
