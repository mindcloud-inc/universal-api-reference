# Reset API Keys with SeaX

Resets SeaX API keys and creates a replacement.

## Endpoint

- **Method:** `POST`
- **Path:** `/api_keys/reset`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Reset API Keys](https://api.seasalt.ai/seax/)
