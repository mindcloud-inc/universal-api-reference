# Refresh Voice Call Session with SeaX

Updates voice call session statistics in SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/voice_call_sessions/{session_id}/refresh`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Refresh Voice Call Session](https://api.seasalt.ai/seax/)
