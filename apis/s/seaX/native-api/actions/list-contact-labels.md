# List Contact Labels with SeaX

Retrieves contact labels from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_labels`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Contact Labels](https://api.seasalt.ai/seax/)
