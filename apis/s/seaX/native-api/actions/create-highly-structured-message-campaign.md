# Create Highly Structured Message Campaign with SeaX

Creates a WhatsApp template campaign in SeaX.

## Endpoint

- **Method:** `POST`
- **Path:** `/highly_structured_message/campaign`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Create Highly Structured Message Campaign](https://api.seasalt.ai/seax/)
