# Update Conversation with SeaX

Updates a conversation in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/conversations/{conversation_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update Conversation](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | Conversation identifier. |
