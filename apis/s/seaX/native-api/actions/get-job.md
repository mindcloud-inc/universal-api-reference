# Get Job with SeaX

Retrieves a job from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/{job_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Get Job](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | Job identifier. |
