# Delete Campaign with SeaX

Deletes a campaign from the current SeaX workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/{campaign_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Delete Campaign](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | Campaign identifier. |
