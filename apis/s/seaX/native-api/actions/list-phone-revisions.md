# List Phone Revisions with SeaX

Retrieves revisions for a SeaX phone number.

## Endpoint

- **Method:** `GET`
- **Path:** `/phones/{phone_id}/revisions`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Phone Revisions](https://api.seasalt.ai/seax/)
