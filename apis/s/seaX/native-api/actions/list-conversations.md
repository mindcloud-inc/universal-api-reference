# List Conversations with SeaX

Retrieves conversations from the current SeaX workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [List Conversations](https://api.seasalt.ai/seax/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
