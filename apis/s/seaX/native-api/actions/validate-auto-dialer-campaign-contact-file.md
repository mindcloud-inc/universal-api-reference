# Validate Auto Dialer Campaign Contact File with SeaX

Validates a contact file for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/validate_contact_file`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Validate Auto Dialer Campaign Contact File](https://api.seasalt.ai/seax/)
