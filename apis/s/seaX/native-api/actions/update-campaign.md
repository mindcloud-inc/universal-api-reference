# Update Campaign with SeaX

Updates a campaign in the current SeaX workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/campaigns/{campaign_id}`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Update Campaign](https://api.seasalt.ai/seax/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | Campaign identifier. |
