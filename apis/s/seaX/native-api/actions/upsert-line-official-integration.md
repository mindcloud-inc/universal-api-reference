# Upsert LINE Official Integration with SeaX

Updates LINE Official integration settings in SeaX.

## Endpoint

- **Method:** `PUT`
- **Path:** `/line_official`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Upsert LINE Official Integration](https://api.seasalt.ai/seax/)
