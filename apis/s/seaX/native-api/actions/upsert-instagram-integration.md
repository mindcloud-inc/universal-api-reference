# Upsert Instagram Integration with SeaX

Updates Instagram integration settings in SeaX.

## Endpoint

- **Method:** `PUT`
- **Path:** `/instagram`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Upsert Instagram Integration](https://api.seasalt.ai/seax/)
