# Download Auto Dialer Campaign Logs with SeaX

Retrieves a log download for a SeaX auto dialer campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/auto_dialer_campaigns/{auto_dialer_campaign_id}/download_logs`
- **Base URL:** `https://seax.seasalt.ai/seax-api/api/v1/workspace/{workspaceId}`
- **Official documentation:** [Download Auto Dialer Campaign Logs](https://api.seasalt.ai/seax/)
