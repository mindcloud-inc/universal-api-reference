# Delete Personal Data By Email with Survicate

Deletes personal data by email from Survicate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/personal-data`
- **Base URL:** `https://data-api.survicate.com/v2`
- **Official documentation:** [Delete Personal Data By Email](https://developers.survicate.com/data-export/personal-data/#delete-personal-data-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address for which to delete all associated data. |
