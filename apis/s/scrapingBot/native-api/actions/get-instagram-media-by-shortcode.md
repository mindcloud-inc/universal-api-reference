# Get Instagram Media by Shortcode with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/instagram`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [Get Instagram Media by Shortcode](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shortcode` | body | `string` | yes | Instagram media shortcode. |
