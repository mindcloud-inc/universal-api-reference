# Convert Amazon ASIN to GTIN with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/amazon`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [Convert Amazon ASIN to GTIN](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `asin` | body | `string` | yes | Amazon product ASIN. |
