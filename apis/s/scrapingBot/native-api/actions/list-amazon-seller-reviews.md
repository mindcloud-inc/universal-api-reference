# List Amazon Seller Reviews with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/amazon`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [List Amazon Seller Reviews](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `seller_id` | body | `string` | yes | Amazon seller identifier. |
