# List Amazon Products by Category with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/amazon`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [List Amazon Products by Category](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | body | `string` | yes | Amazon category identifier. |
