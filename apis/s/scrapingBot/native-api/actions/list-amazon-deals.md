# List Amazon Deals with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/amazon`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [List Amazon Deals](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country` | body | `string` | no | Amazon marketplace country code. |
