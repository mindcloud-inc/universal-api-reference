# Generate ChatGPT Response with ScrapingBot

## Endpoint

- **Method:** `POST`
- **Path:** `/chatgpt`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [Generate ChatGPT Response](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt` | body | `string` | yes | Prompt to send to the ChatGPT endpoint. |
