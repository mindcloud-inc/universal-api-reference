# Scrape Website with ScrapingBot

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape`
- **Base URL:** `https://scrapingbot.io/api/v1`
- **Official documentation:** [Scrape Website](https://scraping-bot.io/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Website URL to scrape. |
