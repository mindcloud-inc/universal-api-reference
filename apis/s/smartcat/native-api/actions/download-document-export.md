# Download Document Export with Smartcat

Retrieves document export results from Smartcat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/v1/document/export/:taskId`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Download Document Export](https://developers.smartcat.com/api/#download-the-export-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Smartcat export task ID |
