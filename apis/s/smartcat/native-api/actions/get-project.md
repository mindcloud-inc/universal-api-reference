# Get Project with Smartcat

Retrieves project details from the Smartcat account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/v1/project/:projectId`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Get Project](https://developers.smartcat.com/api/#receive-the-project-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Smartcat project ID |
