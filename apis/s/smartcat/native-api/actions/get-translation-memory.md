# Get Translation Memory with Smartcat

Retrieves translation memory details from Smartcat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/v1/translationmemory/:tmId`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Get Translation Memory](https://developers.smartcat.com/api/#fetch-information-about-the-tm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tmId` | path | `string` | yes | Smartcat translation memory ID |
