# List Glossaries with Smartcat

Retrieves glossaries from the current Smartcat account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/v1/glossaries`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [List Glossaries](https://developers.smartcat.com/api/#fetch-glossaries-from-the-current-account)
