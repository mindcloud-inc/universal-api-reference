# Delete Project with Smartcat

Deletes an existing project from Smartcat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/integration/v1/project/:projectId`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Delete Project](https://developers.smartcat.com/api/#delete-the-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Smartcat project ID |
