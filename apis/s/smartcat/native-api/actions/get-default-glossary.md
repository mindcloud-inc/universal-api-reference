# Get Default Glossary with Smartcat

Retrieves the default glossary from the Smartcat account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/v1/glossaries/default`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Get Default Glossary](https://developers.smartcat.com/api/#fetch-default-glossary-from-the-current-account)
