# Delete Translation Memory with Smartcat

Deletes a translation memory from Smartcat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/integration/v1/translationmemory/:tmId`
- **Base URL:** `https://smartcat.ai`
- **Official documentation:** [Delete Translation Memory](https://developers.smartcat.com/api/#delete-a-tm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tmId` | path | `string` | yes | Smartcat translation memory ID. |
