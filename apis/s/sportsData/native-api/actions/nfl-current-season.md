# NFL Current Season with SportsData

Retrieves the current NFL season from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nfl/scores/json/CurrentSeason`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NFL Current Season](https://cdn.sportsdata.io/openapi/NFL-openapi-3.1.json)
