# NFL Free Agents with SportsData

Retrieves NFL free agents from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nfl/scores/json/FreeAgents`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NFL Free Agents](https://cdn.sportsdata.io/openapi/NFL-openapi-3.1.json)
