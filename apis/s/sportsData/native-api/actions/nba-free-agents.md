# NBA Free Agents with SportsData

Retrieves NBA free agents from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nba/scores/json/PlayersByFreeAgents`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NBA Free Agents](https://cdn.sportsdata.io/openapi/NBA-openapi-3.1.json)
