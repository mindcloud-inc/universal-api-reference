# NFL Current Week with SportsData

Retrieves the current NFL week from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nfl/scores/json/CurrentWeek`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NFL Current Week](https://cdn.sportsdata.io/openapi/NFL-openapi-3.1.json)
