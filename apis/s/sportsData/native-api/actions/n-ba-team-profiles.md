# NBA Team Profiles with SportsData

Retrieves active NBA team profiles from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nba/scores/json/teams`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NBA Team Profiles](https://cdn.sportsdata.io/openapi/NBA-openapi-3.1.json)
