# NBA Players with SportsData

Retrieves active NBA player details from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nba/scores/json/Players`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NBA Players](https://cdn.sportsdata.io/openapi/NBA-openapi-3.1.json)
