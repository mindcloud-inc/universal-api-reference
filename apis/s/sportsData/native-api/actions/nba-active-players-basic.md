# NBA Active Players Basic with SportsData

Retrieves active NBA player profiles from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nba/scores/json/PlayersActiveBasic`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NBA Active Players Basic](https://cdn.sportsdata.io/openapi/NBA-openapi-3.1.json)
