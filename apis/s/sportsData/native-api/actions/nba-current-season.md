# NBA Current Season with SportsData

Retrieves the current NBA season from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nba/scores/json/CurrentSeason`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NBA Current Season](https://cdn.sportsdata.io/openapi/NBA-openapi-3.1.json)
