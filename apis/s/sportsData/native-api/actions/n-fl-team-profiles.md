# NFL Team Profiles with SportsData

Retrieves active NFL team profiles from SportsData.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/nfl/scores/json/Teams`
- **Base URL:** `https://api.sportsdata.io`
- **Official documentation:** [NFL Team Profiles](https://cdn.sportsdata.io/openapi/NFL-openapi-3.1.json)
