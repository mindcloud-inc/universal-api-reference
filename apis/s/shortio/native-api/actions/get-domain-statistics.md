# Get Domain Statistics with Short.io

Retrieves domain statistics from Short.io.

## Endpoint

- **Method:** `GET`
- **Path:** `https://statistics.short.io/statistics/domain/:domainId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Domain Statistics](https://developers.short.io/v1.2/reference/getdomaindomainid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainId` | path | `number` | yes | Domain ID. |
