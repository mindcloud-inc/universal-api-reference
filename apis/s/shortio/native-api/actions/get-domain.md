# Get Domain with Short.io

Retrieves domain details from Short.io by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domainId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Domain](https://developers.short.io/reference/get_domains-domainid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domainId` | path | `number` | yes |
