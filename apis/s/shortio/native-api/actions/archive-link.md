# Archive Link with Short.io

Archives an existing link in Short.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/links/archive`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Archive Link](https://developers.short.io/reference/post_links-archive)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `link_id` | body | `string` | yes |
| `domain_id` | body | `string` | no |
