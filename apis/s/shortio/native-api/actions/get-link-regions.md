# Get Link Regions with Short.io

Retrieves link regions from Short.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/link_region/:linkId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Link Regions](https://developers.short.io/reference/get_link-region-linkid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | — |
| `domainId` | query | `string` | no | Domain ID |
