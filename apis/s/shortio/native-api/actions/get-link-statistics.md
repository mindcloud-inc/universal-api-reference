# Get Link Statistics with Short.io

Retrieves link statistics from Short.io.

## Endpoint

- **Method:** `GET`
- **Path:** `https://statistics.short.io/statistics/link/:linkId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Link Statistics](https://developers.short.io/v1.2/reference/getlinklinkid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Link ID. |
