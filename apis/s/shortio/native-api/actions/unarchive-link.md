# Unarchive Link with Short.io

Unarchives an existing link in Short.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/links/unarchive`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Unarchive Link](https://developers.short.io/reference/post_links-unarchive)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `link_id` | body | `string` | yes |
| `domain_id` | body | `string` | no |
