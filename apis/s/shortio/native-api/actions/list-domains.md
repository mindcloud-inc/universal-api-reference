# List Domains with Short.io

Retrieves domains from Short.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/domains`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [List Domains](https://developers.short.io/reference/get_api-domains)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pattern` | query | `string` | no |
| `teamId` | query | `number` | no |
| `noTeamId` | query | `boolean` | no |
