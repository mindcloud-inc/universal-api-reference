# Get Link with Short.io

Retrieves link details from Short.io by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:linkId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Link](https://developers.short.io/reference/get_links-linkid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Link ID. |
| `domainId` | query | `string` | no | Domain ID. |
