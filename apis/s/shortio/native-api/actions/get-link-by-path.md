# Get Link by Path with Short.io

Retrieves link details from Short.io by path.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/expand`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Get Link by Path](https://developers.short.io/reference/get_links-expand)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain hostname. |
| `path` | query | `string` | yes | Link path. |
