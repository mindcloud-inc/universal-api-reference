# Delete Link with Short.io

Deletes an existing link from Short.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:linkId`
- **Base URL:** `https://api.short.io`
- **Official documentation:** [Delete Link](https://developers.short.io/reference/delete_links-link-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Link ID. |
