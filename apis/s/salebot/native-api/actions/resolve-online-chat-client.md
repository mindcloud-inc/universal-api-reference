# Resolve Online Chat Client with Salebot

## Endpoint

- **Method:** `GET`
- **Path:** `/online_chat_client_id`
- **Base URL:** `https://chatter.salebot.pro/api/{apiKey}`
- **Official documentation:** [Resolve Online Chat Client](https://docs.salebot.pro/rabota-s-api/api-konstruktora)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipient` | query | `string` | yes | Online chat recipient identifier from the website integration. |
