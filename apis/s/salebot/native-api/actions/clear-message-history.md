# Clear Message History with Salebot

## Endpoint

- **Method:** `GET`
- **Path:** `/clear_history`
- **Base URL:** `https://chatter.salebot.pro/api/{apiKey}`
- **Official documentation:** [Clear Message History](https://docs.salebot.pro/rabota-s-api/api-konstruktora)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | query | `number` | yes | Existing Salebot client ID. |
