# Get Envelope Document with Sign.Plus

- **Method:** `GET`
- **Path:** `/envelope/:envelope_id/document/:document_id`
- **Base URL:** `https://restapi.sign.plus/v2`
- **Official documentation:** [Get Envelope Document](https://apidoc.sign.plus/api-reference/endpoints/signplus/get-envelope-document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `envelope_id` | path | `string` | yes |
| `document_id` | path | `string` | yes |
