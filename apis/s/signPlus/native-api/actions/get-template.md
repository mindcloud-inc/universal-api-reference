# Get Template with Sign.Plus

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:template_id`
- **Base URL:** `https://restapi.sign.plus/v2`
- **Official documentation:** [Get Template](https://apidoc.sign.plus/api-reference/endpoints/signplus/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | ID of the template |
