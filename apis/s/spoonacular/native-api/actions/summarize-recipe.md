# Summarize Recipe with Spoonacular

Retrieves a recipe summary from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/summary`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Summarize Recipe](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
