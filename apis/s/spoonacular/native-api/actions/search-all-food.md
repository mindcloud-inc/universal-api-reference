# Search All Food with Spoonacular

Searches all food content in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search All Food](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
