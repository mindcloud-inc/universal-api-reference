# Get Menu Item Information with Spoonacular

Retrieves menu item details from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/menuItems/{id}`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Menu Item Information](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
