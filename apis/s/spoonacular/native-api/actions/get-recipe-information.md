# Get Recipe Information with Spoonacular

Retrieves recipe details from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/information`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Recipe Information](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
