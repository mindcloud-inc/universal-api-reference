# Get Similar Recipes with Spoonacular

Retrieves recipes similar to a Spoonacular recipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/similar`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Similar Recipes](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
