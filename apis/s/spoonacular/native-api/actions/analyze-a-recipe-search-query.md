# Analyze a Recipe Search Query with Spoonacular

Analyzes a recipe search query in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/queries/analyze`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Analyze a Recipe Search Query](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Required by the Spoonacular endpoint. |
