# Search Menu Items with Spoonacular

Searches menu items in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/menuItems/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search Menu Items](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
