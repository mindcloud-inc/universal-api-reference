# Conversation Suggests with Spoonacular

Retrieves chatbot suggestions from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/converse/suggest`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Conversation Suggests](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
