# Equipment by ID Image with Spoonacular

Retrieves a recipe equipment image from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/equipmentWidget.png`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Equipment by ID Image](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
