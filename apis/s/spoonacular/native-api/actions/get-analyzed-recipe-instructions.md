# Get Analyzed Recipe Instructions with Spoonacular

Retrieves analyzed instructions for a Spoonacular recipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/analyzedInstructions`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Analyzed Recipe Instructions](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
