# Ingredients by ID Widget with Spoonacular

Retrieves a recipe ingredients widget from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/ingredientWidget`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Ingredients by ID Widget](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
