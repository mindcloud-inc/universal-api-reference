# Get Recipe Card with Spoonacular

Retrieves a recipe card from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/card`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Recipe Card](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
