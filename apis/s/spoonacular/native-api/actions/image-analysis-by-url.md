# Image Analysis by URL with Spoonacular

Analyzes a food image URL with Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/images/analyze`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Image Analysis by URL](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageUrl` | query | `string` | yes | Required by the Spoonacular endpoint. |
