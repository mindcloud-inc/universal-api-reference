# Product Nutrition by ID Widget with Spoonacular

Retrieves a product nutrition widget from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/products/{id}/nutritionWidget`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Product Nutrition by ID Widget](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
