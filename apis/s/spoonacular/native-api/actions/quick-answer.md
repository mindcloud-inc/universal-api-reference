# Quick Answer with Spoonacular

Retrieves a quick food answer from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/quickAnswer`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Quick Answer](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Required by the Spoonacular endpoint. |
