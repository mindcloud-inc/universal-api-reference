# Menu Item Nutrition Label Image with Spoonacular

Retrieves a menu item nutrition label image from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/menuItems/{id}/nutritionLabel.png`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Menu Item Nutrition Label Image](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
