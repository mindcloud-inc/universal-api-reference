# Price Breakdown by ID with Spoonacular

Retrieves price breakdown data for a Spoonacular recipe.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/priceBreakdownWidget.json`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Price Breakdown by ID](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
