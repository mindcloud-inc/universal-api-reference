# Search Food Videos with Spoonacular

Searches food videos in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/videos/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search Food Videos](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
