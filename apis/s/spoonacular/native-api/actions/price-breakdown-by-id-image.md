# Price Breakdown by ID Image with Spoonacular

Retrieves a recipe price image from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/priceBreakdownWidget.png`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Price Breakdown by ID Image](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
