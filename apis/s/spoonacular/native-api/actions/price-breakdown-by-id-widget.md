# Price Breakdown by ID Widget with Spoonacular

Retrieves a recipe price widget from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/priceBreakdownWidget`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Price Breakdown by ID Widget](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
