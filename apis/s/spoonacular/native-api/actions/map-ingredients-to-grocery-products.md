# Map Ingredients to Grocery Products with Spoonacular

Maps ingredients to grocery products in Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/food/ingredients/map`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Map Ingredients to Grocery Products](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | query | `string` | yes | The required request body. |
