# Classify Grocery Product Bulk with Spoonacular

Classifies grocery products in bulk with Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/food/products/classifyBatch`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Classify Grocery Product Bulk](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `string` | yes | The required request body. |
