# Get Recipe Information Bulk with Spoonacular

Retrieves details for multiple Spoonacular recipes.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/informationBulk`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Recipe Information Bulk](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | yes | Required by the Spoonacular endpoint. |
