# Classify Grocery Product with Spoonacular

Classifies a grocery product with Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/food/products/classify`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Classify Grocery Product](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `string` | yes | The required request body. |
