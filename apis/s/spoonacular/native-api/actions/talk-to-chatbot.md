# Talk to Chatbot with Spoonacular

Retrieves a chatbot response from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/converse`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Talk to Chatbot](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | Required by the Spoonacular endpoint. |
