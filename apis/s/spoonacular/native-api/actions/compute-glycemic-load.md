# Compute Glycemic Load with Spoonacular

Computes ingredient glycemic load with Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/food/ingredients/glycemicLoad`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Compute Glycemic Load](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `string` | yes | The required request body. |
