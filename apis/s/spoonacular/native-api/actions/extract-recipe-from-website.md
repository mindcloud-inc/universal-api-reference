# Extract Recipe from Website with Spoonacular

Extracts recipe data from a website with Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/extract`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Extract Recipe from Website](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Required by the Spoonacular endpoint. |
