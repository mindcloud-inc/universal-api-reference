# Connect User with Spoonacular

Connects a user to Spoonacular meal planning.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/connect`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Connect User](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `string` | yes | The required request body. |
