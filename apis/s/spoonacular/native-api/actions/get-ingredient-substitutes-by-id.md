# Get Ingredient Substitutes by ID with Spoonacular

Retrieves substitutes for a Spoonacular ingredient.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/ingredients/{id}/substitutes`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Ingredient Substitutes by ID](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required by the Spoonacular endpoint. |
