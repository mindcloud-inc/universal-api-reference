# Search Grocery Products with Spoonacular

Searches grocery products in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/products/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search Grocery Products](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
