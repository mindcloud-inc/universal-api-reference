# Wine Description with Spoonacular

Retrieves a wine description from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/wine/description`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Wine Description](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `wine` | query | `string` | yes | Required by the Spoonacular endpoint. |
