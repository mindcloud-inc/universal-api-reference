# Search Site Content with Spoonacular

Searches Spoonacular site content by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/site/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search Site Content](https://spoonacular.com/food-api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Required by the Spoonacular endpoint. |
