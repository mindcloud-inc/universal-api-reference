# Get Knowledge Base by ID with Stack AI

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/knowledge-bases/:knowledge_base_id`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Get Knowledge Base by ID](https://docs.stackai.com/api-reference/knowledge-bases#get-v1-knowledge-bases-knowledge_base_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `knowledge_base_id` | path | `string` | yes | The knowledge base identifier. |
