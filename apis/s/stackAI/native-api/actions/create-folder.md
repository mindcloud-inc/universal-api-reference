- **Method:** `PUT`
- **Path:** `/folders`

- **Official documentation:** [Create Folder](https://docs.stackai.com/api-reference/folders#put-folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The folder name. |
