# Synchronize Knowledge Base with Stack AI

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/knowledge-bases/:knowledge_base_id/sync`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Synchronize Knowledge Base](https://docs.stackai.com/api-reference/knowledge-bases#post-v1-knowledge-bases-knowledge_base_id-sync)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `knowledge_base_id` | path | `string` | yes | The knowledge base identifier. |
