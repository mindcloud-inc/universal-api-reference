# Create Knowledge Base with Stack AI

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/knowledge-bases`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Create Knowledge Base](https://docs.stackai.com/api-reference/knowledge-bases#post-v1-knowledge-bases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The knowledge base name. |
| `description` | body | `string` | no | The knowledge base description. |
