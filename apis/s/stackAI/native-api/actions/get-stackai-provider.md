# Get StackAI Provider with Stack AI

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/stackai/providers/:provider_id`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Get StackAI Provider](https://docs.stackai.com/api-reference/tools#get-tools-stackai-providers-provider_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider_id` | path | `string` | yes | The provider identifier. |
