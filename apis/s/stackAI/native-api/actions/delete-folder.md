# Delete Folder with Stack AI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folders/:folder_id`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Delete Folder](https://docs.stackai.com/api-reference/folders#delete-folders-folder_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `string` | yes | The folder identifier. |
