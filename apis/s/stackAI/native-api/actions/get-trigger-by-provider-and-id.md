# Get Trigger by Provider and ID with Stack AI

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/stackai/providers/:provider_id/triggers/:trigger_id`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Get Trigger by Provider and ID](https://docs.stackai.com/api-reference/tools#get-tools-stackai-providers-provider_id-triggers-trigger_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider_id` | path | `string` | yes | The provider identifier. |
| `trigger_id` | path | `string` | yes | The trigger identifier. |
