# Delete Custom Tool with Stack AI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools/custom/:provider_id`
- **Base URL:** `https://api.stack-ai.com`
- **Official documentation:** [Delete Custom Tool](https://docs.stackai.com/api-reference/tools#delete-tools-custom-provider_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider_id` | path | `string` | yes | The provider identifier. |
