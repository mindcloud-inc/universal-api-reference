# SimpleCert: Native API Reference

A consolidated summary of SimpleCert's API configuration and 9 documented operations, with links to official documentation.

- **Official docs:** https://simplecert.readme.io/reference/introduction
- **API base URL:** `https://app.simplecert.net/api`

## Authentication

### Custom API Key

Use the SimpleCert API key exactly as generated by the SimpleCert API key endpoint.

### Credentials

- **API Key:** `apiKey` · required · Paste the SimpleCert API key returned by the official API key endpoint.

Send these headers with each API request:

```http
api-key: <apiKey>
```

[Official authentication documentation](https://simplecert.readme.io/reference/authentication)

## API conventions

Request bodies use JSON.

Shared headers:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |

Responses from this API use JSON.
