# List Project Recipients with SimpleCert

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/recipients`
- **Base URL:** `https://app.simplecert.net/api`
- **Official documentation:** [List Project Recipients](https://simplecert.readme.io/reference/recipients-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | Project identifier. |
