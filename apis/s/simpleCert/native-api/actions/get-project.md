# Get Project with SimpleCert

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/single`
- **Base URL:** `https://app.simplecert.net/api`
- **Official documentation:** [Get Project](https://simplecert.readme.io/reference/projects-single)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | Project identifier. |
