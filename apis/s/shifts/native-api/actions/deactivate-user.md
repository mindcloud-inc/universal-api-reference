# Deactivate User with 7shifts

Deactivates an existing user in 7shifts.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/company/{company_id}/users/{identifier}`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Deactivate User](https://developers.7shifts.com/reference/deactivateuser)
