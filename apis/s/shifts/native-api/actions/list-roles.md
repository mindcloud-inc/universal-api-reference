# List Roles with 7shifts

Lists the role records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/roles`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Roles](https://developers.7shifts.com/reference/listroles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
