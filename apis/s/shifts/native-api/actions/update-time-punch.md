# Update Time Punch with 7shifts

Updates an existing time punch in 7shifts.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/company/{company_id}/time_punches/{time_punch_id}`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Update Time Punch](https://developers.7shifts.com/reference/puttimepunch)
