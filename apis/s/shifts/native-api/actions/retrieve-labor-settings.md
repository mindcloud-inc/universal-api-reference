# Retrieve Labor Settings with 7shifts

Retrieves company labor settings from 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/labor_settings`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Retrieve Labor Settings](https://developers.7shifts.com/reference/retrievecompanylaborsettings)
