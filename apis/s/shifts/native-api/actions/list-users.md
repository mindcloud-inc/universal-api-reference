# List Users with 7shifts

Lists the user records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/users`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Users](https://developers.7shifts.com/reference/listuserslist)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
