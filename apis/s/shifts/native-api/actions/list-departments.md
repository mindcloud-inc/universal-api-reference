# List Departments with 7shifts

Lists the department records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/departments`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Departments](https://developers.7shifts.com/reference/listdepartments)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
