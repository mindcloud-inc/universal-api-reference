# Get User Contacts with 7shifts

Lists the user contacts in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/contacts`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Get User Contacts](https://developers.7shifts.com/reference/listcontacts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
