# Create Role Assignment with 7shifts

Creates a role assignment in 7shifts.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/company/{company_id}/users/{user_id}/role_assignments`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Create Role Assignment](https://developers.7shifts.com/reference/createroleassignment)
