# List Users Authorized Locations with 7shifts

Lists a user's authorized locations in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/users/{user_id}/authorized_locations`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Users Authorized Locations](https://developers.7shifts.com/reference/listusersauthorizedlocations)
