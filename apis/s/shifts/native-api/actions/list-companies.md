# List Companies with 7shifts

Lists the company records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/companies`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Companies](https://developers.7shifts.com/reference/listcompanies)

## Capabilities

This operation supports [filtering](../README.md#filtering).
