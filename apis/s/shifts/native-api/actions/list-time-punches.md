# List Time Punches with 7shifts

Lists the time punches in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/time_punches`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Time Punches](https://developers.7shifts.com/reference/gettimepunches)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
