# Retrieve Time Punch with 7shifts

Retrieves a time punch from 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/time_punches/{time_punch_id}`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Retrieve Time Punch](https://developers.7shifts.com/reference/gettimepunchbyid)
