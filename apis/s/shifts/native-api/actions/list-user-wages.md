# List User Wages with 7shifts

Lists a user's wages in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/users/{user_id}/wages`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List User Wages](https://developers.7shifts.com/reference/getuserwages)
