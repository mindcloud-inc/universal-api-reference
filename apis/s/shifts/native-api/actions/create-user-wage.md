# Create User Wage with 7shifts

Creates a new user wage in 7shifts.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/company/{company_id}/users/{user_id}/wages`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [Create User Wage](https://developers.7shifts.com/reference/createuserwages)
