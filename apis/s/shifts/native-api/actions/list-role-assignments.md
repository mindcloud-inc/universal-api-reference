# List Role Assignments with 7shifts

Lists a user's role assignments in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/users/{user_id}/role_assignments`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Role Assignments](https://developers.7shifts.com/reference/getroleassignments)
