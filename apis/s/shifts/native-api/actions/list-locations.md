# List Locations with 7shifts

Lists the location records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/locations`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Locations](https://developers.7shifts.com/reference/getlocationlistbycompany)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
