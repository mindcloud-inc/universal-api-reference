# List Employment Records with 7shifts

Lists the employment records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/employment_records`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Employment Records](https://developers.7shifts.com/reference/listemploymentrecord)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
