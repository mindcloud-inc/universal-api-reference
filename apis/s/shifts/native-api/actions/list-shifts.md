# List Shifts with 7shifts

Lists the shift records in 7shifts.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company/{company_id}/shifts`
- **Base URL:** `https://api.7shifts.com`
- **Official documentation:** [List Shifts](https://developers.7shifts.com/reference/listshift)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
