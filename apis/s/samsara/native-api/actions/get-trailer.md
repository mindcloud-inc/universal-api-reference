# Get Trailer with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `fleet/trailers/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Trailer](https://developers.samsara.com/reference/gettrailer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara trailer ID. |
