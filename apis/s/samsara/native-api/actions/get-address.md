# Get Address with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `addresses/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Address](https://developers.samsara.com/reference/getaddress)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara address ID or external ID. |
