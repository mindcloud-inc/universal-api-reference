# Get Equipment with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `fleet/equipment/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Equipment](https://developers.samsara.com/reference/getequipment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara equipment ID. |
