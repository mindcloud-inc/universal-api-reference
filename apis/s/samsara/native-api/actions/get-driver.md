# Get Driver with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `fleet/drivers/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Driver](https://developers.samsara.com/reference/getdriver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara driver ID or external ID. |
