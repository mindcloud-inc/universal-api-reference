# Get Tag with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `tags/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Tag](https://developers.samsara.com/reference/gettag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara tag ID or external ID. |
