# Get User with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `users/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get User](https://developers.samsara.com/reference/getuser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara user ID. |
