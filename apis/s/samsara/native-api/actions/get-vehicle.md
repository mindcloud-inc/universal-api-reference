# Get Vehicle with Samsara

## Endpoint

- **Method:** `GET`
- **Path:** `fleet/vehicles/:id`
- **Base URL:** `https://api.samsara.com/`
- **Official documentation:** [Get Vehicle](https://developers.samsara.com/reference/getvehicle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Samsara vehicle ID or external ID. |
