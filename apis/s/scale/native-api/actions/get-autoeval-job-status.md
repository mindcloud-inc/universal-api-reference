# Get Autoeval Job Status with Scale

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/autoevals/{jobId}/status`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Get Autoeval Job Status](https://docs.genai.scale.com/status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The evaluation job identifier. |
