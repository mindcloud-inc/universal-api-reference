# Create Chat Task with Scale

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/task/chat`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Create Chat Task](https://docs.genai.scale.com/v2/task-chat-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_variables` | body | `string` | yes | Template variables supplied to the chat task. |
