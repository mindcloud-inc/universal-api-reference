# Get Autoeval Model Version Config Statuses with Scale

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/autoevals/model_version_configs/{id}/statuses`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Get Autoeval Model Version Config Statuses](https://docs.genai.scale.com/model-statuses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The model version config identifier. |
