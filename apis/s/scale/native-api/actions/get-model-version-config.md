# Get Model Version Config with Scale

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/model_version_configs/{id}`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Get Model Version Config](https://docs.genai.scale.com/model-version-config-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The model version config identifier. |
