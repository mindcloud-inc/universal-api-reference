# Create Batch with Scale

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/batch`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Create Batch](https://docs.genai.scale.com/v2/batch-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new batch. |
