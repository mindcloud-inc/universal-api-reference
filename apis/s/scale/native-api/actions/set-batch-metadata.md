# Set Batch Metadata with Scale

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/batch/metadata`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Set Batch Metadata](https://docs.genai.scale.com/v2/batch-set-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metadata` | body | `string` | yes | Metadata object to store on the batch. |
