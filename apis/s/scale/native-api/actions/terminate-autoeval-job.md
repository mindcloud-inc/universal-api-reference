# Terminate Autoeval Job with Scale

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/autoevals/terminate`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Terminate Autoeval Job](https://docs.genai.scale.com/terminate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | body | `string` | yes | The evaluation job identifier. |
