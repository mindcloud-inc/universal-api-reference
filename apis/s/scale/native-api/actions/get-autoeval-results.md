# Get Autoeval Results with Scale

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/autoevals/{jobId}/results`
- **Base URL:** `https://api.scale.com`
- **Official documentation:** [Get Autoeval Results](https://docs.genai.scale.com/results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The evaluation job identifier. |
