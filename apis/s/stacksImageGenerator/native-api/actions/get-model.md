# Get Model with 88stacks Image Generator

Retrieves an image generation model from 88stacks Image Generator.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/models/:id`
- **Base URL:** `https://api.88stacks.com`
- **Official documentation:** [Get Model](https://88stacks.com/docs/1.0/models/show.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the model to retrieve. |
