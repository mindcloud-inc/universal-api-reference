# Get Current User with Sprintful

Retrieves the current user from Sprintful.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me`
- **Base URL:** `https://app.sprintful.com/api/v1`
- **Official documentation:** [Get Current User](https://support.sprintful.com/article/95-how-can-i-access-sprintful-via-apis)
