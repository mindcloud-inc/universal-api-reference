# List Items with Syften

Retrieves matching mention items from Syften.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/0.0/items/get`
- **Base URL:** `https://syften.com`
- **Official documentation:** [List Items](https://github.com/syften/syften-examples/blob/master/curl/items_get.sh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | Maximum number of items to return |
