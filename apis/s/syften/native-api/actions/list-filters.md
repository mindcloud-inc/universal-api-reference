# List Filters with Syften

Retrieves saved keyword filters from Syften.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/0.0/filters/get`
- **Base URL:** `https://syften.com`
- **Official documentation:** [List Filters](https://github.com/syften/syften-examples/blob/master/curl/filters_get.sh)
