# Get Settings with Syften

Retrieves keyword alert settings from Syften.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/0.0/settings/get`
- **Base URL:** `https://syften.com`
- **Official documentation:** [Get Settings](https://github.com/syften/syften-examples/blob/master/curl/settings_get.sh)
