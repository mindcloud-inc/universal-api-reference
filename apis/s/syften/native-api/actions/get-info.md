# Get Info with Syften

Retrieves account details and plan information from Syften.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/0.0/info/get`
- **Base URL:** `https://syften.com`
- **Official documentation:** [Get Info](https://github.com/syften/syften-examples/blob/master/curl/info_get.sh)
