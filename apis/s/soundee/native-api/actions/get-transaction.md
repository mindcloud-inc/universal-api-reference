# Get Transaction with Soundee

Retrieves a transaction record from Soundee.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/:id`
- **Base URL:** `https://api.soundee.com/me`
- **Official documentation:** [Get Transaction](https://soundee.readme.io/reference/get-by-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The transaction ID. |
