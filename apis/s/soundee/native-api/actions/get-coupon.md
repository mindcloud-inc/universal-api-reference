# Get Coupon with Soundee

Retrieves a coupon code from Soundee.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/:id`
- **Base URL:** `https://api.soundee.com/me`
- **Official documentation:** [Get Coupon](https://soundee.readme.io/reference/get-transaction-object)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the coupon. |
