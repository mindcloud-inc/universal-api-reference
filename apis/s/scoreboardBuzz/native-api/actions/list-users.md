# List Users with Scoreboard Buzz

Retrieves users from Scoreboard Buzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.scoreboardbuzz.com/api/v1`
- **Official documentation:** [List Users](https://docs.scoreboardbuzz.com/#/Users/listUsers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Filter users by exact email address. |
