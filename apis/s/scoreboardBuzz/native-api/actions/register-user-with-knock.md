# Register User With Knock with Scoreboard Buzz

Creates a Knock registration for the authenticated user in Scoreboard Buzz.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/knock`
- **Base URL:** `https://api.scoreboardbuzz.com/api/v1`
- **Official documentation:** [Register User With Knock](https://docs.scoreboardbuzz.com/#/Users/registerUserKnock)
