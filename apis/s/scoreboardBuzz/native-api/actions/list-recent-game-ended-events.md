# List Recent Game Ended Events with Scoreboard Buzz

Retrieves recent game-ended events from Scoreboard Buzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/game-ended/recent`
- **Base URL:** `https://api.scoreboardbuzz.com/api/v1`
- **Official documentation:** [List Recent Game Ended Events](https://docs.scoreboardbuzz.com/#/Webhooks/getRecentGameEndedEvents)
