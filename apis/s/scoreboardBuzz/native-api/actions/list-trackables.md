# List Trackables with Scoreboard Buzz

Retrieves trackables from Scoreboard Buzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackables`
- **Base URL:** `https://api.scoreboardbuzz.com/api/v1`
- **Official documentation:** [List Trackables](https://docs.scoreboardbuzz.com/#/Trackables/listTrackables)
