# List Webhook Subscriptions with Scoreboard Buzz

Retrieves webhook subscriptions from Scoreboard Buzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/subscriptions`
- **Base URL:** `https://api.scoreboardbuzz.com/api/v1`
- **Official documentation:** [List Webhook Subscriptions](https://docs.scoreboardbuzz.com/#/Webhooks/listWebhookSubscriptions)
