# Delete Webhook with Seam

Deletes an existing webhook from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhooks/delete`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [Delete Webhook](https://docs.seam.co/latest/api/webhooks/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_id` | body | `string` | yes |
