# List Devices with Seam

Retrieves a list of devices from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/devices/list`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [List Devices](https://docs.seam.co/latest/api/devices/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
