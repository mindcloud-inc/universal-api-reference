# List Device Providers with Seam

Retrieves a list of device providers from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/devices/list_device_providers`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [List Device Providers](https://docs.seam.co/latest/api/devices/list_device_providers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider_category` | body | `string` | no | Category for which you want to list providers. |
