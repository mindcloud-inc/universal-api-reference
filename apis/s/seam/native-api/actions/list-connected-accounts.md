# List Connected Accounts with Seam

Retrieves a list of connected accounts from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/connected_accounts/list`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [List Connected Accounts](https://docs.seam.co/latest/api/connected_accounts/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
