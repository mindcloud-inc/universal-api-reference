# Get Connect Webview with Seam

Retrieves a connect webview from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/connect_webviews/get`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [Get Connect Webview](https://docs.seam.co/latest/api/connect_webviews/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `connect_webview_id` | body | `string` | yes |
