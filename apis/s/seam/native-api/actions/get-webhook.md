# Get Webhook with Seam

Retrieves a webhook from Seam.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhooks/get`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [Get Webhook](https://docs.seam.co/latest/api/webhooks/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_id` | body | `string` | yes |
