# Get Thermostat with Seam

## Endpoint

- **Method:** `POST`
- **Path:** `/thermostats/get`
- **Base URL:** `https://connect.getseam.com`
- **Official documentation:** [Get Thermostat](https://docs.seam.co/latest/api/thermostats/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_id` | body | `string` | no | ID of the thermostat device that you want to get. |
| `name` | body | `string` | no | Name of the thermostat device that you want to retrieve. |
