# Get TikTok Trending Feed with Scrape Creators

Retrieves TikTok trending feed items from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tiktok/get-trending-feed`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get TikTok Trending Feed](https://docs.scrapecreators.com/v1/tiktok/get-trending-feed/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `region` | query | `string` | yes | Region code |
| `trim` | query | `boolean` | no | Return a trimmed response |
