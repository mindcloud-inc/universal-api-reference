# Get Instagram Basic Profile with Scrape Creators

Retrieves an Instagram basic profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/instagram/basic-profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Instagram Basic Profile](https://docs.scrapecreators.com/v1/instagram/basic-profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | query | `string` | no | Instagram user id |
