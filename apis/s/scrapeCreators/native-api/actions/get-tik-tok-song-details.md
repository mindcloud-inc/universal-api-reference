# Get TikTok Song Details with Scrape Creators

Retrieves TikTok song details from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tiktok/song`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get TikTok Song Details](https://docs.scrapecreators.com/v1/tiktok/song/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clipId` | query | `string` | yes | TikTok sound clip id |
