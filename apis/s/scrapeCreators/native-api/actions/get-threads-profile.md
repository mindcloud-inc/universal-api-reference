# Get Threads Profile with Scrape Creators

Retrieves a Threads profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/threads/profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Threads Profile](https://docs.scrapecreators.com/v1/threads/profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | query | `string` | yes | Threads handle |
