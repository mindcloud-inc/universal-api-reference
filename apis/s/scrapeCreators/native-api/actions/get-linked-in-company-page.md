# Get LinkedIn Company Page with Scrape Creators

Retrieves a LinkedIn company page from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/linkedin/company`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get LinkedIn Company Page](https://docs.scrapecreators.com/v1/linkedin/company/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | LinkedIn company URL |
