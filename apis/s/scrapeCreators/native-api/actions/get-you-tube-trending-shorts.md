# Get YouTube Trending Shorts with Scrape Creators

Retrieves trending YouTube Shorts from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/youtube/shorts/trending`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get YouTube Trending Shorts](https://docs.scrapecreators.com/v1/youtube/shorts/trending/)
