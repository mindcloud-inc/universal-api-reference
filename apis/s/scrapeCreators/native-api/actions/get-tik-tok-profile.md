# Get TikTok Profile with Scrape Creators

Retrieves a TikTok profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tiktok/profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get TikTok Profile](https://docs.scrapecreators.com/v1/tiktok/profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | query | `string` | yes | TikTok handle |
