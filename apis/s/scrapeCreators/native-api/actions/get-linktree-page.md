# Get Linktree Page with Scrape Creators

Retrieves a Linktree page from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/linktree`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Linktree Page](https://docs.scrapecreators.com/v1/linktree/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Linktree URL |
