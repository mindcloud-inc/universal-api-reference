# Get Linkme Profile with Scrape Creators

Retrieves a Linkme profile by URL from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/linkme`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Linkme Profile](https://docs.scrapecreators.com/v1/linkme/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Linkme URL |
