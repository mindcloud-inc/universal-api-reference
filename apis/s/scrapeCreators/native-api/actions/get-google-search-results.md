# Get Google Search Results with Scrape Creators

Retrieves Google search results from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/google/search`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Google Search Results](https://docs.scrapecreators.com/v1/google/search/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query |
| `region` | query | `string` | no | Search region |
