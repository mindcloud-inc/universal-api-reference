# Get Twitter Profile with Scrape Creators

Retrieves a Twitter profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/twitter/profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Twitter Profile](https://docs.scrapecreators.com/v1/twitter/profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | query | `string` | yes | Twitter handle |
