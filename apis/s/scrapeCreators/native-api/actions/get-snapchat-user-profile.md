# Get Snapchat User Profile with Scrape Creators

Retrieves a Snapchat user profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/snapchat/profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get Snapchat User Profile](https://docs.scrapecreators.com/v1/snapchat/profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | query | `string` | yes | Snapchat handle |
