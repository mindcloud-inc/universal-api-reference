# Get LinkedIn Profile with Scrape Creators

Retrieves a LinkedIn profile from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/linkedin/profile`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get LinkedIn Profile](https://docs.scrapecreators.com/v1/linkedin/profile/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | LinkedIn profile URL |
