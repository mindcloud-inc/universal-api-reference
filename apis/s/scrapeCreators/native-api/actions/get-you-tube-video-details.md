# Get YouTube Video Details with Scrape Creators

Retrieves YouTube video or Short details from Scrape Creators.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/youtube/video`
- **Base URL:** `https://api.scrapecreators.com`
- **Official documentation:** [Get YouTube Video Details](https://docs.scrapecreators.com/v1/youtube/video/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | YouTube video or short URL |
