# Create Unsubscribed Subscriber with Sequenzy

Creates an unsubscribed subscriber in Sequenzy.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribers`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Create Unsubscribed Subscriber](https://docs.sequenzy.com/api-reference/subscribers/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Subscriber email address. |
