# Get Account Metrics (30d) with Sequenzy

Retrieves 30-day account engagement metrics from Sequenzy.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Account Metrics (30d)](https://docs.sequenzy.com/api-reference/analytics/metrics)
