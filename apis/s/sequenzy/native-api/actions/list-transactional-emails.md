# List Transactional Emails with Sequenzy

Retrieves a list of transactional emails from Sequenzy.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactional`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [List Transactional Emails](https://docs.sequenzy.com/api-reference/transactional/list)
