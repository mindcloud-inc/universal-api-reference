# Create Subscriber Without Lists with Sequenzy

Creates a new subscriber in Sequenzy without assigning lists.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribers`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Create Subscriber Without Lists](https://docs.sequenzy.com/api-reference/subscribers/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Subscriber email address. |
