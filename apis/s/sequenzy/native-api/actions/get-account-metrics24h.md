# Get Account Metrics (24h) with Sequenzy

Retrieves 24-hour account engagement metrics from Sequenzy.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Account Metrics (24h)](https://docs.sequenzy.com/api-reference/analytics/metrics)
