# Get Recipient Metrics by Email with Sequenzy

Retrieves recipient engagement metrics from Sequenzy by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/recipients`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Recipient Metrics by Email](https://docs.sequenzy.com/api-reference/analytics/recipients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Filter to a single recipient by email address. |
