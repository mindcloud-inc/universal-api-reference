# Get Recipient Metrics by Sequence with Sequenzy

Retrieves recipient engagement metrics from Sequenzy for a sequence.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/recipients`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Recipient Metrics by Sequence](https://docs.sequenzy.com/api-reference/analytics/recipients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sequenceId` | query | `string` | no | Sequence ID to filter recipient metrics. |
