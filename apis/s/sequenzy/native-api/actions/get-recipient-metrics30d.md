# Get Recipient Metrics (30d) with Sequenzy

Retrieves 30-day recipient engagement metrics from Sequenzy.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/recipients`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Recipient Metrics (30d)](https://docs.sequenzy.com/api-reference/analytics/recipients)
