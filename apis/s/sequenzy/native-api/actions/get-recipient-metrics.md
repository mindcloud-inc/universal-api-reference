# Get Recipient Metrics with Sequenzy

Retrieves recipient engagement metrics from Sequenzy.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/recipients`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Recipient Metrics](https://docs.sequenzy.com/api-reference/analytics/recipients)
