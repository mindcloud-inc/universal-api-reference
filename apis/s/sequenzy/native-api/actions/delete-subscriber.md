# Delete Subscriber with Sequenzy

Deletes an existing subscriber from Sequenzy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/:email`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Delete Subscriber](https://docs.sequenzy.com/api-reference/subscribers/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Subscriber email address. |
