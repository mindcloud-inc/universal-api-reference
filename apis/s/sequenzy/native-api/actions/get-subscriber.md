# Get Subscriber with Sequenzy

Retrieves a subscriber from Sequenzy by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:email`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Subscriber](https://docs.sequenzy.com/api-reference/subscribers/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Subscriber email address. |
