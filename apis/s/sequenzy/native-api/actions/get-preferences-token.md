# Get Preferences Token with Sequenzy

Creates a preferences token in Sequenzy.

## Endpoint

- **Method:** `POST`
- **Path:** `/widgets/preferences/token`
- **Base URL:** `https://api.sequenzy.com/api/v1`
- **Official documentation:** [Get Preferences Token](https://docs.sequenzy.com/api-reference/widgets/preferences-token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Existing subscriber email address. |
