# List Servers with ServerAvatar

Retrieves servers from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/servers`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Servers](https://serveravatar.com/api-docs/endpoint/server/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
