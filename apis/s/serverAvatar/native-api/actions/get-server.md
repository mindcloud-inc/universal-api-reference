# Get Server with ServerAvatar

Retrieves a server from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/servers/{{server}}`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [Get Server](https://serveravatar.com/api-docs/endpoint/server/show.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
| `server` | path | `string` | yes |
