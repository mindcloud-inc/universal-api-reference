# List Organization Members with ServerAvatar

Retrieves organization members from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/members`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Organization Members](https://serveravatar.com/api-docs/endpoint/organization/member.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
