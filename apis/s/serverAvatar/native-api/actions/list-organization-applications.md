# List Organization Applications with ServerAvatar

Retrieves organization applications from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/applications`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Organization Applications](https://serveravatar.com/api-docs/endpoint/application/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
