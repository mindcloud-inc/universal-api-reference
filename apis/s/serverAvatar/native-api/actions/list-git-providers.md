# List Git Providers with ServerAvatar

Retrieves Git providers from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/git-providers`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Git Providers](https://serveravatar.com/api-docs/endpoint/git-provider/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
