# List Connected Server Providers with ServerAvatar

Retrieves connected server providers from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/cloud-server-providers`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Connected Server Providers](https://serveravatar.com/api-docs/endpoint/server-provider/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
