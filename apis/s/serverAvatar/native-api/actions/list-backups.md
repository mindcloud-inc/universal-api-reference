# List Backups with ServerAvatar

Retrieves backups from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/backups`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Backups](https://serveravatar.com/api-docs/endpoint/backup/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
