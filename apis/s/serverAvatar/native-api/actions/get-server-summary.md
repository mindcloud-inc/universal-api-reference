# Get Server Summary with ServerAvatar

Retrieves a server summary from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/servers/{{server}}/summary`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [Get Server Summary](https://serveravatar.com/api-docs/endpoint/server/summary.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
| `server` | path | `string` | yes |
