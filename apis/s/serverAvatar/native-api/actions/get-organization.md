# Get Organization with ServerAvatar

Retrieves an organization from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [Get Organization](https://serveravatar.com/api-docs/endpoint/organization/show.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
