# List Organization Databases with ServerAvatar

Retrieves organization databases from ServerAvatar.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{{organization}}/databases`
- **Base URL:** `https://api.serveravatar.com`
- **Official documentation:** [List Organization Databases](https://serveravatar.com/api-docs/endpoint/database/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization` | path | `string` | yes |
