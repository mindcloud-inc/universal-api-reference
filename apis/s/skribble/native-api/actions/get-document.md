# Get Document with Skribble

Retrieves document metadata from Skribble.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/documents/:documentId`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Get Document](https://api-doc.skribble.com/#7178df86-708e-44ca-a064-cf4f049a291d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Skribble document ID. |
