# Download Document Content with Skribble

Retrieves a document's PDF content from Skribble.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/documents/:documentId/content`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Download Document Content](https://api-doc.skribble.com/#c11a7ec0-8251-456c-9ac8-e2b89b505fc3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Skribble document ID. |
