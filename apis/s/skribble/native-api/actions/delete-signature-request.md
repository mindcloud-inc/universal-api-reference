# Delete Signature Request with Skribble

Deletes a signature request from Skribble or removes your access.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/signature-requests/:signatureRequestId`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Delete Signature Request](https://api-doc.skribble.com/#beedd756-f48a-4a59-920a-09cad1226c0a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signatureRequestId` | path | `string` | no | The signature request ID. |
