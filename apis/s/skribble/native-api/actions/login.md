# Login with Skribble

Creates an API access token in Skribble.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/access/login`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Login](https://api-doc.skribble.com/#4faa3dbc-6b67-450c-a592-d93add26d56a)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
