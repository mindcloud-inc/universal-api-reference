# Get System Health with Skribble

Retrieves the Skribble system health status.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/health`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Get System Health](https://api-doc.skribble.com/#75d22845-3e7f-4bb6-af19-91766da7b3a9)
