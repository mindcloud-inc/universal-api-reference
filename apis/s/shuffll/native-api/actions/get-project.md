# Get Project with Shuffll

Retrieves a project from Shuffll by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/project/:projectId`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Get Project](https://api-docs.shuffll.com/apis/projects/getprojectbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
