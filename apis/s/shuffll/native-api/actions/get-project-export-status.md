# Get Project Export Status with Shuffll

Retrieves project export status from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/project/:projectId/edit/status/export`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Get Project Export Status](https://api-docs.shuffll.com/apis/export/getexportstatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
