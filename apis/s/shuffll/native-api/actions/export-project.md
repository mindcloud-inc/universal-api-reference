# Export Project with Shuffll

Creates a project export in Shuffll.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/project/:projectId/edit/export`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Export Project](https://api-docs.shuffll.com/apis/export/exportproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
