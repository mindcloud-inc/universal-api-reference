# Get Organization with Shuffll

Retrieves an organization from Shuffll by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/organization/:organizationId`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Get Organization](https://api-docs.shuffll.com/apis/organizations/getorganizationbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | Shuffll organization id. |
