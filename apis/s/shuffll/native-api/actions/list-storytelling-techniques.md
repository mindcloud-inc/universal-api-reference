# List Storytelling Techniques with Shuffll

Retrieves storytelling techniques from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/config/storytelling_techniques`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [List Storytelling Techniques](https://api-docs.shuffll.com/apis/configuration/getstorytellingtechniques)
