# List Music Library with Shuffll

Retrieves music library items from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/config/music-library`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [List Music Library](https://api-docs.shuffll.com/apis/configuration/getmusiclibrary)
