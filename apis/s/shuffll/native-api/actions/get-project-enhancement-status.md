# Get Project Enhancement Status with Shuffll

Retrieves project enhancement status from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/project/:projectId/edit/status/enhance`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Get Project Enhancement Status](https://api-docs.shuffll.com/apis/enhance/getenhancestatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
