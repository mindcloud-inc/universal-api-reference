# List AI Avatar Options with Shuffll

Retrieves AI avatar options from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/config/ai_avatar_options`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [List AI Avatar Options](https://api-docs.shuffll.com/apis/configuration/getaiavataroptions)
