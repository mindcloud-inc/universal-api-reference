# List AI Voice Options with Shuffll

Retrieves AI voice options from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/config/ai_voice_options`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [List AI Voice Options](https://api-docs.shuffll.com/apis/configuration/getaivoiceoptions)
