# Delete Project with Shuffll

Deletes an existing project from Shuffll.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/auth/project/:projectId`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Delete Project](https://api-docs.shuffll.com/apis/projects/deleteproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
