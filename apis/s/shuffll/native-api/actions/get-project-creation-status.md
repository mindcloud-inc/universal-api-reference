# Get Project Creation Status with Shuffll

Retrieves project creation status from Shuffll.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/project/:projectId/create/status`
- **Base URL:** `https://api.shuffll.com/api/v1`
- **Official documentation:** [Get Project Creation Status](https://api-docs.shuffll.com/apis/projects/getprojectcreatestatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Shuffll project id. |
