# Get Contact Property with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-properties/:contactPropertyId`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Contact Property](https://docs.swipeone.com/en/articles/10540803-contact-properties#h_1071d9b27a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactPropertyId` | path | `string` | yes | Contact property to retrieve. |
