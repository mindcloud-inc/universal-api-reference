# Get Task with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Task](https://docs.swipeone.com/en/articles/10546025-tasks#h_84c0b2fe74)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Task to retrieve. |
