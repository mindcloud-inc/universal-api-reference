# List Tag Contacts with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tagId/contacts`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Tag Contacts](https://docs.swipeone.com/en/articles/10545829-tags#h_884fb7b948)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `string` | yes |
