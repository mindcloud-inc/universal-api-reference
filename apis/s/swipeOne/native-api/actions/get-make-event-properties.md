# Get Make Event Properties with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/make/events/:event`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Make Event Properties](https://docs.swipeone.com/en/articles/10429345-swipeone-make-com-apis#h_2646912b4c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event` | path | `string` | yes | Event identifier to retrieve properties for. |
