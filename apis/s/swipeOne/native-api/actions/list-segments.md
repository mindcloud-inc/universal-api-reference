# List Segments with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/segments`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Segments](https://docs.swipeone.com/en/articles/10545714-segments#h_23fd090102)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes |
