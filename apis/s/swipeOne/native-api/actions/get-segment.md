- **Method:** `GET`
- **Path:** `/segments/:segmentId`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Segment](https://docs.swipeone.com/en/articles/10545714-segments#h_195dca80d5)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | path | `string` | yes |
