# List Contact Properties with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/contact-properties`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Contact Properties](https://docs.swipeone.com/en/articles/10540803-contact-properties#h_1db197abb9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | Workspace to list contact properties from. |
| `page` | query | `number` | no | Page number. |
| `limit` | query | `number` | no | Number of records per page. |
