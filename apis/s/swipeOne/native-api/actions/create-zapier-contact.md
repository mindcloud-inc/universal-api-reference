# Create Zapier Contact with Swipe One

## Endpoint

- **Method:** `POST`
- **Path:** `/zapier/contact`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Create Zapier Contact](https://docs.swipeone.com/en/articles/10420029-swipeone-apis#h_4cf47da0d8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | Email address of the contact. |
| `phone` | body | `string` | no | Phone number of the contact. |
| `tags` | body | `string` | no | Comma-separated tags to assign to the contact. |
