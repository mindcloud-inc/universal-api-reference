# Get Note with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:noteId`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Note](https://docs.swipeone.com/en/articles/10546101-notes#h_c6e1bb09a1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | Note to retrieve. |
