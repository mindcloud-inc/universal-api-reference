# List Tags with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/tags`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Tags](https://docs.swipeone.com/en/articles/10545829-tags#h_db0e65aea0)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes |
