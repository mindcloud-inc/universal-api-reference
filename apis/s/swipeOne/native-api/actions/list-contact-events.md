# List Contact Events with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/events`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Contact Events](https://docs.swipeone.com/en/articles/10545660-events#h_3579944cc9)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
