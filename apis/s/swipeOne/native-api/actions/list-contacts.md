# List Contacts with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/contacts`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Contacts](https://docs.swipeone.com/en/articles/10545314-contacts#h_8aa63bed28)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes |
| `searchText` | query | `string` | no |
