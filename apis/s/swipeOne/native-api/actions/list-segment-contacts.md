# List Segment Contacts with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:segmentId/contacts`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [List Segment Contacts](https://docs.swipeone.com/en/articles/10545714-segments#h_8dc591aa4e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | path | `string` | yes |
