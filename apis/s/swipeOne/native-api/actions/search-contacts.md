# Search Contacts with Swipe One

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces/:workspaceId/contacts/search`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Search Contacts](https://docs.swipeone.com/en/articles/10545314-contacts#h_52c6526aef)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes |
| `filter` | body | `object` | no |
