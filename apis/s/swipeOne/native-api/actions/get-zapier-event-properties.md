# Get Zapier Event Properties with Swipe One

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/events/:event`
- **Base URL:** `https://api.swipeone.com/api`
- **Official documentation:** [Get Zapier Event Properties](https://docs.swipeone.com/en/articles/10420029-swipeone-apis#h_4692d52af5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event` | path | `string` | yes | Event identifier to retrieve properties for. |
