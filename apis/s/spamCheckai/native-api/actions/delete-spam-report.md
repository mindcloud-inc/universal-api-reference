# Delete Spam Report with SpamCheck.ai

Deletes a spam report from SpamCheck.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/spam_reports/:id`
- **Base URL:** `https://api.spamcheck.ai/api/v1`
- **Official documentation:** [Delete Spam Report](https://app.spamcheck.ai/api_docs/index.html#/default/delete_spam_reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Spam report ID to delete. |
