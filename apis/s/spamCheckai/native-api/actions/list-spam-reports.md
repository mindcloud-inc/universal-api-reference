# List Spam Reports with SpamCheck.ai

Retrieves saved spam reports from SpamCheck.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/spam_reports`
- **Base URL:** `https://api.spamcheck.ai/api/v1`
- **Official documentation:** [List Spam Reports](https://app.spamcheck.ai/api_docs/index.html#/default/get_spam_reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number of spam reports to return. |
