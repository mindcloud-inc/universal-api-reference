# List Survey Codes with SurveyMethods

## Endpoint

- **Method:** `GET`
- **Path:** `/:loginId/:apiKey/integrations/surveycodes/`
- **Base URL:** `https://api.surveymethods.com/v1`
- **Official documentation:** [List Survey Codes](https://surveymethods.com/images/pdfs/surveymethodsapidocumentv1.pdf)
