# List Newsletter Codes with SurveyMethods

## Endpoint

- **Method:** `GET`
- **Path:** `/:loginId/:apiKey/newsletters/codes/`
- **Base URL:** `https://api.surveymethods.com/v1`
- **Official documentation:** [List Newsletter Codes](https://surveymethods.com/images/pdfs/surveymethodsapidocumentv1.pdf)
