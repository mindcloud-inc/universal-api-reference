# List Email List Contacts with SurveyMethods

## Endpoint

- **Method:** `GET`
- **Path:** `/:loginId/:apiKey/emaillists/:emailListCode/`
- **Base URL:** `https://api.surveymethods.com/v1`
- **Official documentation:** [List Email List Contacts](https://surveymethods.com/images/pdfs/surveymethodsapidocumentv1.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailListCode` | path | `string` | yes | SurveyMethods email list code. |
