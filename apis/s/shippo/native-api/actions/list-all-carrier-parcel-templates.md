# List All Carrier Parcel Templates with Shippo - Legacy

Retrieves carrier parcel templates from Shippo.

## Endpoint

- **Method:** `GET`
- **Path:** `/parcel-templates`
- **Base URL:** `https://api.goshippo.com`
- **Official documentation:** [List All Carrier Parcel Templates](https://docs.goshippo.com/shippoapi/public-api/parcel-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiKey` | path | `string` | no | Override the authentication API key here |
| `include` | query | `string` | no | — |
