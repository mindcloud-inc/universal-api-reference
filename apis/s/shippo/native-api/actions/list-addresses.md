# List Addresses with Shippo - Legacy

Retrieves saved shipping addresses from Shippo.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses`
- **Base URL:** `https://api.goshippo.com`
- **Official documentation:** [List Addresses](https://docs.goshippo.com/shippoapi/public-api/addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiKey` | path | `string` | no | Override the authentication API key here |
