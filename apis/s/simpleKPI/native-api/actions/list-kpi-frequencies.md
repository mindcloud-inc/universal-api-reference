# List KPI Frequencies with SimpleKPI

Retrieves KPI frequency records from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpifrequencies`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List KPI Frequencies](https://support.simplekpi.com/Developers/KPIFrequencies)
