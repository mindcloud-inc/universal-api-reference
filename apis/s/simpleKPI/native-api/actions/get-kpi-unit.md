# Get KPI Unit with SimpleKPI

Retrieves a KPI unit from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpiunits/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get KPI Unit](https://support.simplekpi.com/Developers/KPIUnits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI KPI unit ID. |
