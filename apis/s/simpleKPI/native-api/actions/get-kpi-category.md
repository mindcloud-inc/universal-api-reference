# Get KPI Category with SimpleKPI

Retrieves a KPI category from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpicategories/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get KPI Category](https://support.simplekpi.com/Developers/KPICategories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI KPI category ID. |
