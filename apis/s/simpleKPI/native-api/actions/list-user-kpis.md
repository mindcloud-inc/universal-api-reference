# List User KPIs with SimpleKPI

Retrieves KPIs assigned to a SimpleKPI user.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId/kpis`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List User KPIs](https://support.simplekpi.com/Developers/UsersKPIs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | SimpleKPI user ID. |
