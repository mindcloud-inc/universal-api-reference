# Delete KPI Entry with SimpleKPI

Deletes an existing KPI entry from SimpleKPI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `kpientries/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Delete KPI Entry](https://support.simplekpi.com/Developers/KPIEntries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | The KPI entry ID. |
