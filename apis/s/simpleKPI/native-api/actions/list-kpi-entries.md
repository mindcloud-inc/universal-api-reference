# List KPI Entries with SimpleKPI

Retrieves KPI entries from a SimpleKPI account.

## Endpoint

- **Method:** `GET`
- **Path:** `kpientries`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List KPI Entries](https://support.simplekpi.com/Developers/KPIEntries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kpiId` | query | `number` | no | Optional SimpleKPI KPI ID filter. |
