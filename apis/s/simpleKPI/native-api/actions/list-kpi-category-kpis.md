# List KPI Category KPIs with SimpleKPI

Retrieves KPIs from a SimpleKPI KPI category.

## Endpoint

- **Method:** `GET`
- **Path:** `kpicategories/:categoryId/kpis`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List KPI Category KPIs](https://support.simplekpi.com/Developers/KPICategoriesKPIs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `number` | yes | SimpleKPI KPI category ID. |
