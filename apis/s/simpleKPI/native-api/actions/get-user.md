# Get User with SimpleKPI

Retrieves a user record from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get User](https://support.simplekpi.com/Developers/Users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI user ID. |
