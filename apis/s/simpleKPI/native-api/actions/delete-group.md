# Delete Group with SimpleKPI

Deletes an existing group from SimpleKPI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `groups/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Delete Group](https://support.simplekpi.com/Developers/Groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | The group ID. |
