# List Group Items with SimpleKPI

Retrieves group items from a SimpleKPI group.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/:groupId/items`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List Group Items](https://support.simplekpi.com/Developers/GroupsGroupItems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | SimpleKPI group ID. |
