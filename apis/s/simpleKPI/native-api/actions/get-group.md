# Get Group with SimpleKPI

Retrieves a group record from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get Group](https://support.simplekpi.com/Developers/Groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI group ID. |
