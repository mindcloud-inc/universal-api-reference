# Get KPI Icon with SimpleKPI

Retrieves a KPI icon from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpiicons/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get KPI Icon](https://support.simplekpi.com/Developers/KPIIcons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI KPI icon ID. |
