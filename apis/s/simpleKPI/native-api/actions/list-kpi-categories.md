# List KPI Categories with SimpleKPI

Retrieves KPI category records from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpicategories`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List KPI Categories](https://support.simplekpi.com/Developers/KPICategories)
