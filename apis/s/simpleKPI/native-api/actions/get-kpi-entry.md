# Get KPI Entry with SimpleKPI

Retrieves a KPI entry from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpientries/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get KPI Entry](https://support.simplekpi.com/Developers/KPIEntries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SimpleKPI KPI entry ID. |
