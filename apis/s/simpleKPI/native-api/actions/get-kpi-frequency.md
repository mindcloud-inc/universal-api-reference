# Get KPI Frequency with SimpleKPI

Retrieves a KPI frequency from SimpleKPI.

## Endpoint

- **Method:** `GET`
- **Path:** `kpifrequencies/:id`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [Get KPI Frequency](https://support.simplekpi.com/Developers/KPIFrequencies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SimpleKPI KPI frequency ID. |
