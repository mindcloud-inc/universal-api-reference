# List User Group Items with SimpleKPI

Retrieves group items assigned to a SimpleKPI user.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId/groupitems`
- **Base URL:** `https://{subdomain}.simplekpi.com/api/`
- **Official documentation:** [List User Group Items](https://support.simplekpi.com/Developers/UsersGroupItems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | SimpleKPI user ID. |
