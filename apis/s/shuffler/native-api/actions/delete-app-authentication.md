# Delete App Authentication with Shuffler

Deletes an app authentication from Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/authentication/{authenticationId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete App Authentication](https://shuffler.io/docs/API#delete-app-authentication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `authenticationId` | path | `string` | yes | Authentication Id path parameter. |
