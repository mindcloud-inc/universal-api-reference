# Increment Custom Stat with Shuffler

Increments a custom stat in Shuffler.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/{orgId}/stats`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Increment Custom Stat](https://shuffler.io/docs/API#count-stats-for-custom-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Org Id path parameter. |
