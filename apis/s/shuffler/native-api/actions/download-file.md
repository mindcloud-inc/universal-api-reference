# Download File with Shuffler

Retrieves file content from Shuffler.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}/content`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Download File](https://shuffler.io/docs/API#download-a-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id path parameter. |
