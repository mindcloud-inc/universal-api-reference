# Get File Metadata with Shuffler

Retrieves file metadata from Shuffler.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Get File Metadata](https://shuffler.io/docs/API#get-file-meta-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id path parameter. |
