# Get Organization with Shuffler

Retrieves an organization from Shuffler.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/{orgId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Get Organization](https://shuffler.io/docs/API#get-an-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Org Id path parameter. |
