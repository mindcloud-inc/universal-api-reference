# List Notifications with Shuffler

Retrieves notifications from Shuffler.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [List Notifications](https://shuffler.io/docs/API#get-all-notifications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional notification status filter. |
