# List Datastore Keys with Shuffler

Retrieves datastore keys from Shuffler.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/{orgId}/list_cache`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [List Datastore Keys](https://shuffler.io/docs/API#list-all-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Org Id path parameter. |
