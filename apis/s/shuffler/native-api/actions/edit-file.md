# Edit File with Shuffler

Updates an existing file in Shuffler.

## Endpoint

- **Method:** `PUT`
- **Path:** `/files/{fileId}/edit`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Edit File](https://shuffler.io/docs/API#edit-an-existing-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id path parameter. |
