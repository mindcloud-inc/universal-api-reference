# Update Workflow with Shuffler

Updates an existing workflow in Shuffler.

## Endpoint

- **Method:** `PUT`
- **Path:** `/workflows/{workflowId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Update Workflow](https://shuffler.io/docs/API#save-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow Id path parameter. |
