# Get Workflow with Shuffler

Retrieves a workflow from Shuffler.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/{workflowId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Get Workflow](https://shuffler.io/docs/API#get-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow Id path parameter. |
