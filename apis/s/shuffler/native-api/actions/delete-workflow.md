# Delete Workflow with Shuffler

Deletes an existing workflow from Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workflows/{workflowId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete Workflow](https://shuffler.io/docs/API#delete-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow Id path parameter. |
