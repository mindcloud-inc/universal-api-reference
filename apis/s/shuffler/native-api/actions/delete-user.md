# Delete User with Shuffler

Deactivates an existing user in Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{userId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete User](https://shuffler.io/docs/API#deactivates-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User Id path parameter. |
