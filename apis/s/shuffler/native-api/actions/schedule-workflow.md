# Schedule Workflow with Shuffler

Creates a workflow schedule in Shuffler.

## Endpoint

- **Method:** `POST`
- **Path:** `/workflows/{workflowId}/schedule`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Schedule Workflow](https://shuffler.io/docs/API#schedule-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow Id path parameter. |
