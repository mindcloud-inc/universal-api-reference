# Update Organization with Shuffler

Updates an existing organization in Shuffler.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/{orgId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Update Organization](https://shuffler.io/docs/API#edit-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Org Id path parameter. |
