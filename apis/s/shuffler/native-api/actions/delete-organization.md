# Delete Organization with Shuffler

Deletes an existing organization from Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orgs/{orgId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete Organization](https://shuffler.io/docs/API#delete-organizations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Org Id path parameter. |
