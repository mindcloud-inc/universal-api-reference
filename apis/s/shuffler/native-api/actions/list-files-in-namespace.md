# List Files in Namespace with Shuffler

Retrieves files in a Shuffler namespace.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/namespaces/{category}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [List Files in Namespace](https://shuffler.io/docs/API#get-file-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | path | `string` | yes | Category path parameter. |
