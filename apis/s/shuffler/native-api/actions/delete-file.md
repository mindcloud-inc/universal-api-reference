# Delete File with Shuffler

Deletes a file from Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete File](https://shuffler.io/docs/API#delete-a-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id path parameter. |
