# Delete Webhook with Shuffler

Deletes a webhook from Shuffler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hooks/{webhookId}`
- **Base URL:** `https://shuffler.io/api/v1`
- **Official documentation:** [Delete Webhook](https://shuffler.io/docs/API#delete-and-stop-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook Id path parameter. |
