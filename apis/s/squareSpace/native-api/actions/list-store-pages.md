# List Store Pages with SquareSpace

Retrieves store pages from Squarespace.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.0/commerce/store_pages`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [List Store Pages](https://developers.squarespace.com/commerce-apis/websites#list-store-pages)
