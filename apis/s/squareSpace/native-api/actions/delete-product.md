# Delete Product with SquareSpace

Deletes a product from Squarespace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/commerce/products/:id`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [Delete Product](https://developers.squarespace.com/commerce-apis/products#delete-specified-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<string>` | yes | Product ID. |
