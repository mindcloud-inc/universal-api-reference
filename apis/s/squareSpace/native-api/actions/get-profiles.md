# Get Profiles with SquareSpace

Retrieves customer profiles from Squarespace by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.0/profiles/:ids`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [Get Profiles](https://developers.squarespace.com/commerce-apis/profiles#get-profiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | path | `string` | yes | Profile IDs (comma-separated). |
