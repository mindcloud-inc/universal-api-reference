# Get Order with SquareSpace

Retrieves an order from Squarespace.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.0/commerce/orders/:id`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [Get Order](https://developers.squarespace.com/commerce-apis/orders#get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<string>` | yes | Order ID to retrieve. |
