# Get Products with SquareSpace

Retrieves products from Squarespace by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/commerce/products/:ids`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [Get Products](https://developers.squarespace.com/commerce-apis/products#get-products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | path | `string` | yes | Product IDs (comma-separated). |
