# Update Product with SquareSpace

Updates a product in Squarespace.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/commerce/products/:id`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [Update Product](https://developers.squarespace.com/commerce-apis/products#update-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<string>` | yes | Product ID. |
