# List Profiles with SquareSpace

Retrieves customer profiles from Squarespace.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.0/profiles`
- **Base URL:** `https://api.squarespace.com`
- **Official documentation:** [List Profiles](https://developers.squarespace.com/commerce-apis/profiles#list-profiles)

## Capabilities

This operation supports [filtering](../README.md#filtering).
