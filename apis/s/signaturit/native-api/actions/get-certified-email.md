# Get Certified Email with Signaturit

Retrieves a certified email from Signaturit.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:id.json`
- **Base URL:** `https://api.sandbox.signaturit.com/v3`
- **API:** rest
- **Official documentation:** [Get Certified Email](https://docs.signaturit.com/api/latest#emails_get_email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Certified email identifier. |
