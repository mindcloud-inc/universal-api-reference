# Get Credits with Signaturit

Retrieves account credits from Signaturit.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/credits.json`
- **Base URL:** `https://api.sandbox.signaturit.com/v3`
- **API:** rest
- **Official documentation:** [Get Credits](https://docs.signaturit.com/api/latest#credits_get_credits)
