# Get Contact with Signaturit

Retrieves a contact from Signaturit.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id.json`
- **Base URL:** `https://api.sandbox.signaturit.com/v3`
- **API:** rest
- **Official documentation:** [Get Contact](https://docs.signaturit.com/api/latest#contacts_get_contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact identifier. |
