# Get Signature with Signaturit

Retrieves a signature from Signaturit.

## Endpoint

- **Method:** `GET`
- **Path:** `/signatures/:id.json`
- **Base URL:** `https://api.sandbox.signaturit.com/v3`
- **API:** rest
- **Official documentation:** [Get Signature](https://docs.signaturit.com/api/latest#signatures_get_signature)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Signature request identifier. |
