# List Templates V4 with Signaturit

Retrieves templates from Signaturit V4 API.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.sandbox.signaturit.com/v4/templates`
- **Base URL:** `https://api.sandbox.signaturit.com/v3`
- **API:** rest
- **Official documentation:** [List Templates V4](https://docs.signaturit.com/api/latest#templates_get_templates_v4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Max number of templates to retrieve. |
| `page` | query | `number` | no | Results page number. |
