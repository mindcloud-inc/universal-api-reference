# Get Unsubscribed Numbers with SMSEdge

Retrieves unsubscribed phone numbers from SMSEdge.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers/unsubscribers/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get Unsubscribed Numbers](https://developers.smsedge.io/reference/numbers-unsubscribers)
