# Get Automations with SMSEdge

Retrieves automation records and details from SMSEdge.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/getall`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get Automations](https://developers.smsedge.io/reference/get-all-automations-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Current page number. |
