# Get List Details with SMSEdge

Retrieves details for a list in SMSEdge.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/info/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get List Details](https://developers.smsedge.io/reference/lists-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of requested list |
