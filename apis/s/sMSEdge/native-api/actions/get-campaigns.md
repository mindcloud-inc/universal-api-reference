# Get Campaigns with SMSEdge

Retrieves campaign records and details from SMSEdge.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/getall`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get Campaigns](https://developers.smsedge.io/reference/list-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Current page number. |
