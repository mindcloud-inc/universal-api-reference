# Delete List with SMSEdge

Deletes an existing list from SMSEdge.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/delete/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Delete List](https://developers.smsedge.io/reference/lists-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of list to be deleted |
