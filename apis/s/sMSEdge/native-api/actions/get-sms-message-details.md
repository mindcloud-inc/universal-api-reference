# Get SMS Message Details with SMSEdge

Retrieves sent SMS details from SMSEdge.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/get/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get SMS Message Details](https://developers.smsedge.io/reference/sms-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | yes | Comma-separated SMS ids. |
