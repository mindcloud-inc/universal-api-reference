# Create List with SMSEdge

Creates a new list in SMSEdge.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/create/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Create List](https://developers.smsedge.io/reference/lists-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of new list |
