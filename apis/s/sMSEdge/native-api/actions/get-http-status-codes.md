# Get HTTP Status Codes with SMSEdge

Retrieves HTTP status codes from SMSEdge.

## Endpoint

- **Method:** `POST`
- **Path:** `/references/statuses/`
- **Base URL:** `https://api.smsedge.com/v1`
- **Official documentation:** [Get HTTP Status Codes](https://developers.smsedge.io/reference/references-statuses)
