# Get Prefix Pricing with SMSup

## Endpoint

- **Method:** `POST`
- **Path:** `/api/3.0/account/pricing/sms/get-prefix-pricing`
- **Base URL:** `https://api.gateway360.com`
- **Official documentation:** [Get Prefix Pricing](https://app.smsup.es/api/3.0/docs/account/get-pricing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prefix` | body | `string` | yes | An international dialing code, for example 34. |
