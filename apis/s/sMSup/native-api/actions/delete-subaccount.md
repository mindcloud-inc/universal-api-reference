# Delete Subaccount with SMSup

## Endpoint

- **Method:** `POST`
- **Path:** `/api/3.0/subaccount/delete`
- **Base URL:** `https://api.gateway360.com`
- **Official documentation:** [Delete Subaccount](https://app.smsup.es/api/3.0/docs/subaccount/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_name` | body | `string` | yes | Username of the subaccount. |
