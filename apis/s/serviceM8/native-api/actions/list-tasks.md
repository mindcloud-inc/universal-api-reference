# List Tasks with ServiceM8

## Endpoint

- **Method:** `GET`
- **Path:** `/api_1.0/task.json`
- **Base URL:** `https://api.servicem8.com`
- **Official documentation:** [List Tasks](https://developer.servicem8.com/reference/listtasks)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
