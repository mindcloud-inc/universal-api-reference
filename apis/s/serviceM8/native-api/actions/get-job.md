# Get Job with ServiceM8

## Endpoint

- **Method:** `GET`
- **Path:** `/api_1.0/job/:uuid.json`
- **Base URL:** `https://api.servicem8.com`
- **Official documentation:** [Get Job](https://developer.servicem8.com/reference/getjobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Record UUID of the job to retrieve. |
