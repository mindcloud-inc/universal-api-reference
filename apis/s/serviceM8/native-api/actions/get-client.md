# Get Client with ServiceM8

## Endpoint

- **Method:** `GET`
- **Path:** `/api_1.0/company/:uuid.json`
- **Base URL:** `https://api.servicem8.com`
- **Official documentation:** [Get Client](https://developer.servicem8.com/reference/getclients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Record UUID of the client to retrieve. |
