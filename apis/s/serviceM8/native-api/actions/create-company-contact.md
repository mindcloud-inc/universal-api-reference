# Create Company Contact with ServiceM8

## Endpoint

- **Method:** `POST`
- **Path:** `/api_1.0/companycontact.json`
- **Base URL:** `https://api.servicem8.com`
- **Official documentation:** [Create Company Contact](https://developer.servicem8.com/reference/createcompanycontacts)

| Parameter | Location | Type | Required |

| `last` | body | `string` | no |
| `phone` | body | `string` | no |

| `email` | body | `string` | no |
| `type` | body | `string` | no |
| `is_primary_contact` | body | `boolean` | no |
