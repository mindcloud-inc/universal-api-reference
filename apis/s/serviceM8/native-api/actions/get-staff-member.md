# Get Staff Member with ServiceM8

## Endpoint

- **Method:** `GET`
- **Path:** `/api_1.0/staff/:uuid.json`
- **Base URL:** `https://api.servicem8.com`
- **Official documentation:** [Get Staff Member](https://developer.servicem8.com/reference/getstaffmembers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the Staff Member |
