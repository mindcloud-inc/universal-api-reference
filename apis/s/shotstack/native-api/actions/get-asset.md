# Get Asset with Shotstack

## Endpoint

- **Method:** `GET`
- **Path:** `/serve/v1/assets/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Get Asset](https://shotstack.io/docs/api/#get-asset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack asset ID. |
