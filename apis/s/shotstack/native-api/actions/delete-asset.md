# Delete Asset with Shotstack

## Endpoint

- **Method:** `DELETE`
- **Path:** `/serve/v1/assets/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Delete Asset](https://shotstack.io/docs/api/#delete-asset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack asset ID. |
