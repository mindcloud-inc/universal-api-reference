# Inspect Media with Shotstack

## Endpoint

- **Method:** `GET`
- **Path:** `/edit/v1/probe/:url`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Inspect Media](https://shotstack.io/docs/api/#inspect-media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | path | `string` | yes | The public URL of the media file to inspect. |
