# Update Template with Shotstack

## Endpoint

- **Method:** `PUT`
- **Path:** `/edit/v1/templates/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Update Template](https://shotstack.io/docs/api/#update-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The Shotstack request body. |
| `id` | path | `string` | yes | The Shotstack template ID. |
