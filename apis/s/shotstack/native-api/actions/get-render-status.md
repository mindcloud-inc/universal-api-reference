# Get Render Status with Shotstack

## Endpoint

- **Method:** `GET`
- **Path:** `/edit/v1/render/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Get Render Status](https://shotstack.io/docs/api/#get-render-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack render ID. |
