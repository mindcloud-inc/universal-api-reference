# Delete Source with Shotstack

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ingest/v1/sources/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Delete Source](https://shotstack.io/docs/api/#delete-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack source ID. |
