# Delete Template with Shotstack

## Endpoint

- **Method:** `DELETE`
- **Path:** `/edit/v1/templates/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Delete Template](https://shotstack.io/docs/api/#delete-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack template ID. |
