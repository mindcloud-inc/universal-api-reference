# Get Asset by Render ID with Shotstack

## Endpoint

- **Method:** `GET`
- **Path:** `/serve/v1/assets/render/:id`
- **Base URL:** `https://api.shotstack.io`
- **Official documentation:** [Get Asset by Render ID](https://shotstack.io/docs/api/#get-asset-by-render-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shotstack render ID. |
