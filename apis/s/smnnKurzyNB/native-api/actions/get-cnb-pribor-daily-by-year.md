# Get CNB PRIBOR Daily by Year with Směnné kurzy ČNB

Retrieves PRIBOR data for a year from Směnné kurzy ČNB.

## Endpoint

- **Method:** `GET`
- **Path:** `/pribor/daily-year`
- **Base URL:** `https://api.cnb.cz/cnbapi`
- **Official documentation:** [Get CNB PRIBOR Daily by Year](https://api.cnb.cz/cnbapi/swagger-ui.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `year` | body | `number` | no |
