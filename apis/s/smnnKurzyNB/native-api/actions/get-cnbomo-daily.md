# Get CNB OMO Daily with Směnné kurzy ČNB

Retrieves the last valid OMO data from Směnné kurzy ČNB.

## Endpoint

- **Method:** `GET`
- **Path:** `/omo/daily`
- **Base URL:** `https://api.cnb.cz/cnbapi`
- **Official documentation:** [Get CNB OMO Daily](https://api.cnb.cz/cnbapi/swagger-ui.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `date` | body | `date` | no |
