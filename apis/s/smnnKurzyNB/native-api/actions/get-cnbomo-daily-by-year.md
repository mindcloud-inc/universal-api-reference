# Get CNB OMO Daily by Year with Směnné kurzy ČNB

Retrieves OMO data for a year from Směnné kurzy ČNB.

## Endpoint

- **Method:** `GET`
- **Path:** `/omo/daily-year`
- **Base URL:** `https://api.cnb.cz/cnbapi`
- **Official documentation:** [Get CNB OMO Daily by Year](https://api.cnb.cz/cnbapi/swagger-ui.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `year` | body | `number` | no |
