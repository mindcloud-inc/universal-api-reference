# List Transcription Jobs with 3Scribe

Retrieves transcription jobs from your 3Scribe account.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs`
- **Base URL:** `https://api.3scri.be`
- **Official documentation:** [List Transcription Jobs](https://helpcentre.3scri.be/developers/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
