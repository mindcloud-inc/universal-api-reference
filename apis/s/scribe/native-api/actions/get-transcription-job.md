# Get Transcription Job with 3Scribe

Retrieves a transcription job from 3Scribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobid`
- **Base URL:** `https://api.3scri.be`
- **Official documentation:** [Get Transcription Job](https://helpcentre.3scri.be/developers/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobid` | path | `string` | yes | The unique identifying code for the transcription job. |
