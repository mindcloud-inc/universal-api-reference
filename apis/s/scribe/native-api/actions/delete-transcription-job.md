# Delete Transcription Job with 3Scribe

Deletes an existing transcription job from 3Scribe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:jobid`
- **Base URL:** `https://api.3scri.be`
- **Official documentation:** [Delete Transcription Job](https://helpcentre.3scri.be/developers/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobid` | path | `string` | yes | The unique identifying code for the transcription job. |
