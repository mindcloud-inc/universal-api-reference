# Delete webhook with Sign

Deletes a webhook from CM.com Sign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clients/{kid}/webhooks/{webhookId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Delete webhook](https://developers.cm.com/sign/reference/delete_clients-kid-webhooks-webhookid)
