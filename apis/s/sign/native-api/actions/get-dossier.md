# Get dossier with Sign

Retrieves a dossier from CM.com Sign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/dossiers/{dossierId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Get dossier](https://developers.cm.com/sign/reference/get_dossiers-dossierid)
