# Get invite with Sign

Retrieves a dossier invite from CM.com Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/dossiers/{dossierId}/invites/{inviteId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Get invite](https://developers.cm.com/sign/reference/get_dossiers-dossierid-invites-inviteid)
