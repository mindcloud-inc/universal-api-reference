# Update invitee with Sign

Updates a dossier invitee in CM.com Sign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/dossiers/{dossierId}/invitees/{inviteeId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Update invitee](https://developers.cm.com/sign/reference/put_dossiers-dossierid-invitees-inviteeid)
