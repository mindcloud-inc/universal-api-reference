# Update webhook with Sign

Updates a webhook in CM.com Sign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/clients/{kid}/webhooks/{webhookId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Update webhook](https://developers.cm.com/sign/reference/put_clients-kid-webhooks-webhookid)
