# Create invites with Sign

Creates signing invites for a dossier in CM.com Sign.

## Endpoint

- **Method:** `POST`
- **Path:** `/dossiers/{dossierId}/invites`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Create invites](https://developers.cm.com/sign/reference/post_dossiers-dossierid-invites)
