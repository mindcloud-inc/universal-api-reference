# Get webhook with Sign

Retrieves a webhook from CM.com Sign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{kid}/webhooks/{webhookId}`
- **Base URL:** `https://api.cm.com/sign-sandbox/v1`
- **Official documentation:** [Get webhook](https://developers.cm.com/sign/reference/get_clients-kid-webhooks-webhookid)
