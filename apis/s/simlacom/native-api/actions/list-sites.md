# List Sites with Simla.com

Retrieves site reference records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/sites`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Sites](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-sites)
