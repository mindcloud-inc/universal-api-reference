# List Payment Statuses with Simla.com

Retrieves payment status records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/payment-statuses`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Payment Statuses](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-payment-statuses)
