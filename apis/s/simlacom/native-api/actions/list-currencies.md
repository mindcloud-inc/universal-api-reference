# List Currencies with Simla.com

Retrieves currency reference records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/currencies`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Currencies](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-currencies)
