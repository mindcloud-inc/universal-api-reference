# List Countries with Simla.com

Retrieves available country codes from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/countries`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Countries](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-countries)
