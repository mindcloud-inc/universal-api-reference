# List Delivery Services with Simla.com

Retrieves delivery service records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/delivery-services`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Delivery Services](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-delivery-services)
