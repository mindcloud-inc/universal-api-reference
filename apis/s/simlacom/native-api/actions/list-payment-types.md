# List Payment Types with Simla.com

Retrieves payment type records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/payment-types`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Payment Types](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-payment-types)
