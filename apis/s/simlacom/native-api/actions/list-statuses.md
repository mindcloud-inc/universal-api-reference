# List Statuses with Simla.com

Retrieves order status records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/statuses`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Statuses](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-statuses)
