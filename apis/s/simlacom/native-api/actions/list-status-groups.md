# List Status Groups with Simla.com

Retrieves order status groups from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/status-groups`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Status Groups](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-status-groups)
