# List Stores with Simla.com

Retrieves warehouse reference records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/stores`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Stores](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-stores)
