# List Units with Simla.com

Retrieves unit reference records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/units`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Units](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-units)
