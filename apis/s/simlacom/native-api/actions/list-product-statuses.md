# List Product Statuses with Simla.com

Retrieves order item statuses from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/product-statuses`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Product Statuses](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-product-statuses)
