# List Order Types with Simla.com

Retrieves order type records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/order-types`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Order Types](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-order-types)
