# List Order Methods with Simla.com

Retrieves order method records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/order-methods`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Order Methods](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-order-methods)
