# Get Current API Credentials with Simla.com

Retrieves current API access details from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/credentials`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [Get Current API Credentials](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-credentials)
