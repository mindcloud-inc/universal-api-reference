# List Delivery Types with Simla.com

Retrieves delivery type records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/delivery-types`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Delivery Types](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-delivery-types)
