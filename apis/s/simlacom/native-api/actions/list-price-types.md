# List Price Types with Simla.com

Retrieves price type records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/price-types`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Price Types](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-price-types)
