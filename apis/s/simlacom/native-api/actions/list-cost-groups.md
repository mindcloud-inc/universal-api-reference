# List Cost Groups with Simla.com

Retrieves cost group records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/cost-groups`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Cost Groups](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-cost-groups)
