# List Cost Items with Simla.com

Retrieves cost item records from Simla.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v5/reference/cost-items`
- **Base URL:** `https://apps2.simla.com`
- **Official documentation:** [List Cost Items](https://docs.simla.com/api/en/RetailCRM/apiMethods/v5#get--api-v5-reference-cost-items)
