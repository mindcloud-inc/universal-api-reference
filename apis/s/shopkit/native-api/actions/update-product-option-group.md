# Update Product Option Group with Shopkit

Updates an existing product option group in Shopkit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/product/:id/option_group/:id_option_group`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Update Product Option Group](https://shopk.it/developers/api#product-option-groups-put-product-option-group-put)
