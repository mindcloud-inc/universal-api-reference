# List Clients with Shopkit

Retrieves clients from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/client`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Clients](https://shopk.it/developers/api#client-get-client-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
