# List Categories with Shopkit

Retrieves categories from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/category`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Categories](https://shopk.it/developers/api#categories-get-category-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
