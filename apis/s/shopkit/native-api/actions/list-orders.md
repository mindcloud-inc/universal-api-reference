# List Orders with Shopkit

Retrieves orders from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/order`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Orders](https://shopk.it/developers/api#orders-get-order-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
