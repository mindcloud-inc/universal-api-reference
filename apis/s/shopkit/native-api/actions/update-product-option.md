# Update Product Option with Shopkit

Updates an existing product option in Shopkit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/product/:id/option/:id_option`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Update Product Option](https://shopk.it/developers/api#product-options-put-product-option-put)
