# Delete Product Option Group with Shopkit

Deletes an existing product option group from Shopkit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product/:id/option_group/:id_option_group`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Delete Product Option Group](https://shopk.it/developers/api#product-option-groups-delete-product-option-group-delete)
