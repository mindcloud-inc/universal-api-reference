# Create Product Option Group with Shopkit

Creates a new product option group in Shopkit.

## Endpoint

- **Method:** `POST`
- **Path:** `/product/:id/option_group`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Create Product Option Group](https://shopk.it/developers/api#product-option-groups-post-product-option-group-post)
