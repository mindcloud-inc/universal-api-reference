# List Shipments with Shopkit

Retrieves shipments from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipment`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Shipments](https://shopk.it/developers/api#shipment-get-shipment-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
