# List Media with Shopkit

Retrieves media from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/media`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Media](https://shopk.it/developers/api#media-get-media-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
