# List Brands with Shopkit

Retrieves brands from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Brands](https://shopk.it/developers/api#brands-get-brand-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
