# Search Products with Shopkit

Finds products in Shopkit by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/search`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Search Products](https://shopk.it/developers/api#products-get-product-search-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
