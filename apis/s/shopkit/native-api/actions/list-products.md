# List Products with Shopkit

Retrieves products from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/product`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Products](https://shopk.it/developers/api#products-get-product-get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
