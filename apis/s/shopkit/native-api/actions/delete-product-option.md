# Delete Product Option with Shopkit

Deletes an existing product option from Shopkit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product/:id/option/:id_option`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [Delete Product Option](https://shopk.it/developers/api#product-options-delete-product-option-delete)
