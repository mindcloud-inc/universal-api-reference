# List Product Option Groups with Shopkit

Retrieves product option groups from Shopkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/:id/option_group`
- **Base URL:** `https://api.shopk.it/v1`
- **Official documentation:** [List Product Option Groups](https://shopk.it/developers/api#product-option-groups-get-product-option-group-get)
