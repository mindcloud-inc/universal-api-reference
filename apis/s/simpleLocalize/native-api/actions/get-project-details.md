# Get Project Details with SimpleLocalize

Retrieves project details from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/project`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Project Details](https://api.simplelocalize.io/openapi/ui#/Projects/getProjectDetailsV2)
