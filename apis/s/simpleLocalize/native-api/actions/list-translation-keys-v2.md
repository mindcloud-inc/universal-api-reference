# List Translation Keys V2 with SimpleLocalize

Retrieves translation keys from SimpleLocalize without metadata.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/translation-keys/list`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [List Translation Keys V2](https://api.simplelocalize.io/openapi/ui#/Translation%20keys/getAllTranslationKeysV2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | no |
