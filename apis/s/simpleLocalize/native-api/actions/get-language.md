# Get Language with SimpleLocalize

Retrieves a language from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/languages/{languageKey}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Language](https://api.simplelocalize.io/openapi/ui#/Languages/getLanguage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `languageKey` | path | `string` | yes |
