# Delete Language with SimpleLocalize

Deletes an existing language from SimpleLocalize.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/languages/{languageKey}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Delete Language](https://api.simplelocalize.io/openapi/ui#/Languages/deleteLanguage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `languageKey` | path | `string` | yes |
