# Delete Translation Key with SimpleLocalize

Deletes a translation key from SimpleLocalize.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/translation-keys`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Delete Translation Key](https://api.simplelocalize.io/openapi/ui#/Translation%20keys/deleteTranslationKey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | query | `string` | yes |
| `namespace` | query | `string` | no |
