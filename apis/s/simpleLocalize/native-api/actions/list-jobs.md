# List Jobs with SimpleLocalize

Retrieves jobs from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/jobs`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [List Jobs](https://api.simplelocalize.io/openapi/ui#/Auto-translation/getJobs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `status` | query | `string` | no |
