# Get Job with SimpleLocalize

Retrieves a job from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/jobs/{jobId}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Job](https://api.simplelocalize.io/openapi/ui#/Auto-translation/getJob)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
