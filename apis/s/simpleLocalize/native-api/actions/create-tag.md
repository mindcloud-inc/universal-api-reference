# Create Tag with SimpleLocalize

Creates a new tag in SimpleLocalize.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tags`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Create Tag](https://api.simplelocalize.io/openapi/ui#/Tags/createTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Tag name |
| `color` | body | `string` | no | Tag color |
