# List Project Activity with SimpleLocalize

Retrieves project activity from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [List Project Activity](https://api.simplelocalize.io/openapi/ui#/Activity/getActivity)

## Capabilities

This operation supports [pagination](../README.md#pagination).
