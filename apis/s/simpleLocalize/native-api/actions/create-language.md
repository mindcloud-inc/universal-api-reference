# Create Language with SimpleLocalize

Creates a new language in SimpleLocalize.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/languages`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Create Language](https://api.simplelocalize.io/openapi/ui#/Languages/createLanguage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | body | `string` | yes |
| `name` | body | `string` | no |
