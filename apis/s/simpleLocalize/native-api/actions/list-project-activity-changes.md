# List Project Activity Changes with SimpleLocalize

Retrieves project activity changes from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/{activityId}/changes`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [List Project Activity Changes](https://api.simplelocalize.io/openapi/ui#/Activity/getActivityChanges)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
