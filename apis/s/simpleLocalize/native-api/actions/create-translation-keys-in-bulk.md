# Create Translation Keys in Bulk with SimpleLocalize

Creates translation keys in bulk in SimpleLocalize.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/translation-keys/bulk`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Create Translation Keys in Bulk](https://api.simplelocalize.io/openapi/ui#/Translation%20keys/createTranslationKeyBulk)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `translationKeys[]` | body | `array<object>` | no |
