# Delete Customer with SimpleLocalize

Deletes an existing customer from SimpleLocalize.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/customers/{customerKey}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Delete Customer](https://api.simplelocalize.io/openapi/ui#/Customers/deleteCustomer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerKey` | path | `string` | yes |
