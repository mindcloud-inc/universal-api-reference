# Get Translation Key Details with SimpleLocalize

Retrieves translation key details from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/translation-keys/details`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Translation Key Details](https://api.simplelocalize.io/openapi/ui#/Translation%20keys/getTranslationKeyDetails)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | query | `string` | yes |
| `namespace` | query | `string` | no |
