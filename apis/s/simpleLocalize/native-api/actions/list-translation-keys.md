# List Translation Keys with SimpleLocalize

Retrieves translation keys from SimpleLocalize without metadata.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/translation-keys/list`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [List Translation Keys](https://api.simplelocalize.io/openapi/ui#/Translation%20keys/getAllTranslationKeys)
