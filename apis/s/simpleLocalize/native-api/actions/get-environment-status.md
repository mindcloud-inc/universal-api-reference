# Get Environment Status with SimpleLocalize

Retrieves environment status from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/environments/{environmentKey}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Environment Status](https://api.simplelocalize.io/openapi/ui#/Hosting/getEnvironmentStatus)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentKey` | path | `string` | yes |
