# Get Customer with SimpleLocalize

Retrieves a customer from SimpleLocalize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/customers/{customerKey}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Get Customer](https://api.simplelocalize.io/openapi/ui#/Customers/getCustomer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerKey` | path | `string` | yes |
