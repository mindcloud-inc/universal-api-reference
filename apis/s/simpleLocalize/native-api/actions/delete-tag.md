# Delete Tag with SimpleLocalize

Deletes an existing tag from SimpleLocalize.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/tags/{tagName}`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Delete Tag](https://api.simplelocalize.io/openapi/ui#/Tags/deleteTag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagName` | path | `string` | yes |
