# Update Translations in Bulk with SimpleLocalize

Updates translations in bulk in SimpleLocalize.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/translations/bulk`
- **Base URL:** `https://api.simplelocalize.io`
- **Official documentation:** [Update Translations in Bulk](https://api.simplelocalize.io/openapi/ui#/Translations/updateTranslationsBulk)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `translations[]` | body | `array<object>` | no |
