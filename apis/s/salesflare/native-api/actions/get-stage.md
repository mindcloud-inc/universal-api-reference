# Get Stage with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `stages`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Get Stage](https://api.salesflare.com/docs#/Pipelines/getStagesStage_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Salesflare stage ID. |
