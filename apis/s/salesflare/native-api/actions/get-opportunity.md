# Get Opportunity with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `opportunities`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Get Opportunity](https://api.salesflare.com/docs#/Opportunities/getOpportunitiesId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Salesflare opportunity ID. |
