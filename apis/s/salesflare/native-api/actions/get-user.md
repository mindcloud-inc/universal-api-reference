# Get User with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `users`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Get User](https://api.salesflare.com/docs#/Users/getUsersId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Salesflare user ID. |
