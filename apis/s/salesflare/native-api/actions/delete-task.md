# Delete Task with Salesflare

## Endpoint

- **Method:** `DELETE`
- **Path:** `tasks/:id`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Delete Task](https://api.salesflare.com/docs#/Tasks/deleteTasksId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Salesflare task ID. |
