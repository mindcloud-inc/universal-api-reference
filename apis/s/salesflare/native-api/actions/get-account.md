# Get Account with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `accounts`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Get Account](https://api.salesflare.com/docs#/Accounts/getAccountsAccount_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Salesflare account ID. |
