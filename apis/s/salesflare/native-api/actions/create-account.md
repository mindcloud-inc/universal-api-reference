# Create Account with Salesflare

## Endpoint

- **Method:** `POST`
- **Path:** `accounts`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Create Account](https://api.salesflare.com/docs#/Accounts/postAccounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The account name. |
