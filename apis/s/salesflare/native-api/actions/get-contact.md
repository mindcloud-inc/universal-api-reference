# Get Contact with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `contacts`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Get Contact](https://api.salesflare.com/docs#/Contacts/getContactsContact_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Salesflare contact ID. |
