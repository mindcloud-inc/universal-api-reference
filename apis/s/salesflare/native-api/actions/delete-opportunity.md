# Delete Opportunity with Salesflare

## Endpoint

- **Method:** `DELETE`
- **Path:** `opportunities/:id`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Delete Opportunity](https://api.salesflare.com/docs#/Opportunities/deleteOpportunitiesId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Salesflare opportunity ID. |
