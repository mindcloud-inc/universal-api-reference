# Delete Account with Salesflare

## Endpoint

- **Method:** `DELETE`
- **Path:** `accounts/:account_id`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Delete Account](https://api.salesflare.com/docs#/Accounts/deleteAccountsAccount_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | The Salesflare account ID. |
