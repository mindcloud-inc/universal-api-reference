# List Stages with Salesflare

## Endpoint

- **Method:** `GET`
- **Path:** `stages`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [List Stages](https://api.salesflare.com/docs#/Pipelines/getStages)

## Capabilities

This operation supports [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_by` | query | `string` | no | Sort expression for stages. |
