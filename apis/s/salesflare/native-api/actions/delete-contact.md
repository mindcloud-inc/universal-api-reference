# Delete Contact with Salesflare

## Endpoint

- **Method:** `DELETE`
- **Path:** `contacts/:contact_id`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Delete Contact](https://api.salesflare.com/docs#/Contacts/deleteContactsContact_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The Salesflare contact ID. |
