# Create Contact with Salesflare

## Endpoint

- **Method:** `POST`
- **Path:** `contacts`
- **Base URL:** `https://api.salesflare.com`
- **Official documentation:** [Create Contact](https://api.salesflare.com/docs#/Contacts/postContacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | The contact email address. |
| `name` | body | `string` | no | The full name of the contact. |
