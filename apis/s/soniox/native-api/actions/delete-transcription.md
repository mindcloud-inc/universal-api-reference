# Delete transcription with Soniox

Deletes an existing transcription from Soniox.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/transcriptions/:transcription_id`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Delete transcription](https://soniox.com/docs/stt/api-reference/transcriptions/delete_transcription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcription_id` | path | `string` | yes | Unique identifier of the transcription. |
