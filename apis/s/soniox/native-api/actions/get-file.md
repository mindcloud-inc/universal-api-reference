# Get file with Soniox

Retrieves a file from Soniox.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Get file](https://soniox.com/docs/stt/api-reference/files/get_file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | Unique identifier of the file. |
