# Get files with Soniox

Retrieves uploaded files from Soniox.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Get files](https://soniox.com/docs/stt/api-reference/files/get_files)

## Capabilities

This operation supports [pagination](../README.md#pagination).
