# Get transcriptions with Soniox

Retrieves transcriptions from Soniox.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcriptions`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Get transcriptions](https://soniox.com/docs/stt/api-reference/transcriptions/get_transcriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
