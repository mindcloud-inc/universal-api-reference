# Get transcription with Soniox

Retrieves a transcription from Soniox.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcriptions/:transcription_id`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Get transcription](https://soniox.com/docs/stt/api-reference/transcriptions/get_transcription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcription_id` | path | `string` | yes | Unique identifier of the transcription. |
