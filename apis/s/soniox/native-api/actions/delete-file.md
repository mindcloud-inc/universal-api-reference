# Delete file with Soniox

Deletes an existing file from Soniox.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.soniox.com/v1`
- **Official documentation:** [Delete file](https://soniox.com/docs/stt/api-reference/files/delete_file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | Unique identifier of the file. |
