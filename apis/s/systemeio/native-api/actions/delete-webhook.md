# Delete Webhook with Systeme.io

Deletes an existing webhook from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/webhooks/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Webhook](https://developer.systeme.io/reference/api_webhooks_id_delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID |
