# Get Contact with Systeme.io

Retrieves a contact resource from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Get Contact](https://developer.systeme.io/reference/api_contacts_id_get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact identifier |
