# Delete Contact with Systeme.io

Deletes an existing contact from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/contacts/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Contact](https://developer.systeme.io/reference/delete_contact-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact identifier |
