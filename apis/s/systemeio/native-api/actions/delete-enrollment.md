# Delete Enrollment with Systeme.io

Deletes an existing enrollment from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/school/enrollments/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Enrollment](https://developer.systeme.io/reference/api_schoolenrollments_id_delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Enrollment identifier. |
