# List Webhooks with Systeme.io

Retrieves the collection of webhooks from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhooks`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [List Webhooks](https://developer.systeme.io/reference/api_webhooks_get_collection-1)
