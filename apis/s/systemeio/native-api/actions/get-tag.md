# Get Tag with Systeme.io

Retrieves a tag resource from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tags/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Get Tag](https://developer.systeme.io/reference/api_tags_id_get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tag identifier. |
