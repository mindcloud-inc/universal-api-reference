# List Communities with Systeme.io

Retrieves the collection of communities from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/community/communities`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [List Communities](https://developer.systeme.io/reference/api_communitycommunities_get_collection-1)
