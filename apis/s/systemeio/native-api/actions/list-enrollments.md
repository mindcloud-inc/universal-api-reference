# List Enrollments with Systeme.io

Retrieves the collection of enrollments from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/school/enrollments`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [List Enrollments](https://developer.systeme.io/reference/api_schoolenrollments_get_collection-1)
