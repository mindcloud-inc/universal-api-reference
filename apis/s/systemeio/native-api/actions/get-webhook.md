# Get Webhook with Systeme.io

Retrieves a webhook resource from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhooks/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Get Webhook](https://developer.systeme.io/reference/api_webhooks_id_get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook identifier. |
