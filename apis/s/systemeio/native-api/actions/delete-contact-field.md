# Delete Contact Field with Systeme.io

Deletes an existing contact field from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/contact_fields/:slug`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Contact Field](https://developer.systeme.io/reference/api_contact_fields_slug_delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Contact field slug. |
