# Create Tag with Systeme.io

Creates a new tag in Systeme.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/tags`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Create Tag](https://developer.systeme.io/reference/api_tags_post-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name. |
