# Delete Community Membership with Systeme.io

Deletes an existing community membership from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/community/memberships/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Community Membership](https://developer.systeme.io/reference/api_communitymemberships_id_delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Membership identifier. |
