# Delete Tag with Systeme.io

Deletes an existing tag from Systeme.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/tags/:id`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [Delete Tag](https://developer.systeme.io/reference/api_tags_id_delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tag identifier. |
