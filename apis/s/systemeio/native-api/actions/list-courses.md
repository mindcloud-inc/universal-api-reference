# List Courses with Systeme.io

Retrieves the collection of courses from Systeme.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/school/courses`
- **Base URL:** `https://api.systeme.io`
- **Official documentation:** [List Courses](https://developer.systeme.io/reference/api_schoolcourses_get_collection-1)
