# Get Campaign Delivery Stats with Selzy

Retrieves campaign delivery stats from Selzy.

## Endpoint

- **Method:** `POST`
- **Path:** `getCampaignDeliveryStats`
- **Base URL:** `https://api.selzy.com/en/api`
- **Official documentation:** [Get Campaign Delivery Stats](https://selzy.com/en/support/api/statistics/getcampaigndeliverystats/)
