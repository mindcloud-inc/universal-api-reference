# Get Campaign Common Stats with Selzy

Retrieves common campaign stats from Selzy.

## Endpoint

- **Method:** `POST`
- **Path:** `getCampaignCommonStats`
- **Base URL:** `https://api.selzy.com/en/api`
- **Official documentation:** [Get Campaign Common Stats](https://selzy.com/en/support/api/statistics/get-campaign-common-stats/)
