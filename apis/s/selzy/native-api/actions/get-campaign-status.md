# Get Campaign Status with Selzy

Retrieves the status of a Selzy campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `getCampaignStatus`
- **Base URL:** `https://api.selzy.com/en/api`
- **Official documentation:** [Get Campaign Status](https://selzy.com/en/support/api/statistics/getcampaignstatus/)
