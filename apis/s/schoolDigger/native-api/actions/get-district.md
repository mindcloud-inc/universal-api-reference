# Get District with SchoolDigger

Retrieves a district from SchoolDigger.

## Endpoint

- **Method:** `GET`
- **Path:** `/districts/:id`
- **Base URL:** `https://api.schooldigger.com/v2.3`
- **Official documentation:** [Get District](https://developer.schooldigger.com/llms-full.txt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Seven-digit SchoolDigger district ID. |
