# Get School with SchoolDigger

Retrieves a school from SchoolDigger.

## Endpoint

- **Method:** `GET`
- **Path:** `/schools/:id`
- **Base URL:** `https://api.schooldigger.com/v2.3`
- **Official documentation:** [Get School](https://developer.schooldigger.com/llms-full.txt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Twelve-digit SchoolDigger school ID. |
