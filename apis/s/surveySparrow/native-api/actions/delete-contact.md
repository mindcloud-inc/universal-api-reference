# Delete Contact with SurveySparrow

Deletes an existing contact from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Contact](https://developers.surveysparrow.com/rest-apis/delete-v-3-contacts-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the contact. |
