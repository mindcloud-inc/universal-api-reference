# Get Survey with SurveySparrow

Retrieves a survey from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get Survey](https://developers.surveysparrow.com/rest-apis/get-v-3-surveys-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the survey. |
