# Delete Variable with SurveySparrow

Deletes a survey variable from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/variables/{{variableId}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Variable](https://developers.surveysparrow.com/rest-apis/delete-v-3-variables-variable-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variable_id` | path | `number` | yes | Variable ID |
