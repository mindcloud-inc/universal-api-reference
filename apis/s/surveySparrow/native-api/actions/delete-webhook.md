# Delete Webhook with SurveySparrow

Deletes an existing webhook from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Webhook](https://developers.surveysparrow.com/rest-apis/delete-v-3-webhooks-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Webhook ID |
