# Delete Contact List with SurveySparrow

Deletes an existing contact list from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact_lists/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Contact List](https://developers.surveysparrow.com/rest-apis/delete-v-3-contact-lists-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the contact list. |
