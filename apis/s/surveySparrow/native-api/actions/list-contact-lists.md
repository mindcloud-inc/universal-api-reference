# List Contact Lists with SurveySparrow

Retrieves all contact lists from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_lists`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Contact Lists](https://developers.surveysparrow.com/rest-apis/get-v-3-contact-lists/)
