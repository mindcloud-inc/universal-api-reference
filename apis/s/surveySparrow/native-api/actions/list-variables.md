# List Variables with SurveySparrow

Retrieves survey variables from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/variables`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Variables](https://developers.surveysparrow.com/rest-apis/get-v-3-variables/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | query | `number` | yes | ID of survey |
