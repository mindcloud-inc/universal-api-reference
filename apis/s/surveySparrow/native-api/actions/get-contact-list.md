# Get Contact List with SurveySparrow

Retrieves a contact list from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_lists/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get Contact List](https://developers.surveysparrow.com/rest-apis/get-v-3-contact-lists-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the contact list. |
