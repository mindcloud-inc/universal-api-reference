# Delete Contact Property with SurveySparrow

Deletes an existing contact property from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact_properties/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Contact Property](https://developers.surveysparrow.com/rest-apis/delete-v-3-contact-properties-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the contact property |
