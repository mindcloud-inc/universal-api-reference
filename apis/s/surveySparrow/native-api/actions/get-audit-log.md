# Get Audit Log with SurveySparrow

Retrieves an audit log from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/audit_logs/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get Audit Log](https://developers.surveysparrow.com/rest-apis/get-v-3-audit-logs-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the audit log |
