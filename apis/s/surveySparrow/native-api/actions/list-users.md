# List Users with SurveySparrow

Retrieves all users from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Users](https://developers.surveysparrow.com/rest-apis/get-v-3-users/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
