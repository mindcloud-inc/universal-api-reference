# Get Contact with SurveySparrow

Retrieves a contact from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get Contact](https://developers.surveysparrow.com/rest-apis/get-v-3-contacts-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the contact. |
