# List Survey Folders with SurveySparrow

Retrieves all survey folders from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/survey_folders`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Survey Folders](https://developers.surveysparrow.com/rest-apis/get-v-3-survey-folders/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
