# List Expressions with SurveySparrow

Retrieves survey expressions from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/expressions`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Expressions](https://developers.surveysparrow.com/rest-apis/get-v-3-expressions/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | query | `number` | yes | ID of the survey |
