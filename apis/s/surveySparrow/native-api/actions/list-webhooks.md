# List Webhooks with SurveySparrow

Retrieves all webhooks from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Webhooks](https://developers.surveysparrow.com/rest-apis/get-v-3-webhooks/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | query | `number` | no | ID of the survey |
