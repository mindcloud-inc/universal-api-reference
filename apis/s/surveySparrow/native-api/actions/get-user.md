# Get User with SurveySparrow

Retrieves a user from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get User](https://developers.surveysparrow.com/rest-apis/get-v-3-users-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the user |
