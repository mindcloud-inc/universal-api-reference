# Delete Survey Folder with SurveySparrow

Deletes an existing survey folder from SurveySparrow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/survey_folders/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Delete Survey Folder](https://developers.surveysparrow.com/rest-apis/delete-v-3-survey-folders-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the survey folder |
