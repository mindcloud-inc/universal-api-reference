# Get Survey Folder with SurveySparrow

Retrieves a survey folder from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/survey_folders/{{id}}`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [Get Survey Folder](https://developers.surveysparrow.com/rest-apis/get-v-3-survey-folders-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the survey folder |
