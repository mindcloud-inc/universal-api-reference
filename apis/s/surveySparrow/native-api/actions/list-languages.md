# List Languages with SurveySparrow

Retrieves translation languages from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/languages`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Languages](https://developers.surveysparrow.com/rest-apis/get-v-3-languages/)
