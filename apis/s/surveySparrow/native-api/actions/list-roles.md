# List Roles with SurveySparrow

Retrieves all roles from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Roles](https://developers.surveysparrow.com/rest-apis/get-v-3-roles/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
