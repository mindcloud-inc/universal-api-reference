# List Teams with SurveySparrow

Retrieves all teams from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Teams](https://developers.surveysparrow.com/rest-apis/get-v-3-teams/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `list` | no | Type of team |
