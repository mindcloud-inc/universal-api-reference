# List Contact Properties with SurveySparrow

Retrieves all contact properties from SurveySparrow.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_properties`
- **Base URL:** `https://api.surveysparrow.com/v3`
- **Official documentation:** [List Contact Properties](https://developers.surveysparrow.com/rest-apis/get-v-3-contact-properties/)
