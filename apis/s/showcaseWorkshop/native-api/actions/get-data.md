# Get Data with Showcase Workshop

Retrieves a data item from Showcase Workshop.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/{guid}`
- **Base URL:** `https://app.showcaseworkshop.com/api/v1`
- **Official documentation:** [Get Data](https://github.com/ShowcaseSoftwareLtd/showcase-workshop-apis/blob/main/rest-api/README.md#get-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | Unique GUID of the data item to retrieve. |
