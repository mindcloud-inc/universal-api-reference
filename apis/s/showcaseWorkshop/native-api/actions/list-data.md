# List Data with Showcase Workshop

Retrieves data items from Showcase Workshop.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/`
- **Base URL:** `https://app.showcaseworkshop.com/api/v1`
- **Official documentation:** [List Data](https://github.com/ShowcaseSoftwareLtd/showcase-workshop-apis/blob/main/rest-api/README.md#list-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `from_date` | query | `date` | no | Return data added after this ISO 8601 date/time. |
