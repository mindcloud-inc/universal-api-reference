# Delete Data with Showcase Workshop

Deletes a data item from Showcase Workshop.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/data/{guid}`
- **Base URL:** `https://app.showcaseworkshop.com/api/v1`
- **Official documentation:** [Delete Data](https://github.com/ShowcaseSoftwareLtd/showcase-workshop-apis/blob/main/rest-api/README.md#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | Unique GUID of the data item to delete. |
