# Delete Resource with Schedule It

Deletes an existing resource from Schedule It.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/resources/:id`
- **Base URL:** `https://www.scheduleit.com/api`
- **Official documentation:** [Delete Resource](https://www.scheduleit.com/faq/10640/is-there-a-rest-api-or-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The resource ID. |
