# List Groups with Schedule It

Retrieves groups from Schedule It.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://www.scheduleit.com/api`
- **Official documentation:** [List Groups](https://www.scheduleit.com/faq/10640/is-there-a-rest-api-or-webhooks)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated fields to return for each group. |
