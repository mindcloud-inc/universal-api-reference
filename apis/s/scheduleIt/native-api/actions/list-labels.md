# List Labels with Schedule It

Retrieves labels from Schedule It.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://www.scheduleit.com/api`
- **Official documentation:** [List Labels](https://www.scheduleit.com/faq/10640/is-there-a-rest-api-or-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of fields to return. |
