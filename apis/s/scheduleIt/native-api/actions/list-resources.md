# List Resources with Schedule It

Retrieves resources from Schedule It.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://www.scheduleit.com/api`
- **Official documentation:** [List Resources](https://www.scheduleit.com/faq/10640/is-there-a-rest-api-or-webhooks)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of resource fields to return. |
