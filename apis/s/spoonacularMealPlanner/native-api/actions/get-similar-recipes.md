# Get Similar Recipes with Spoonacular Meal Planner

Retrieves similar recipes from Spoonacular Meal Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/{id}/similar`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Similar Recipes](https://spoonacular.com/food-api/docs#Get-Similar-Recipes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Recipe ID. |
