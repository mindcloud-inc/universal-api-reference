# Get Random Recipes with Spoonacular Meal Planner

Retrieves random recipes from Spoonacular Meal Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/random`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Random Recipes](https://spoonacular.com/food-api/docs#Get-Random-Recipes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tags` | query | `string` | no | Comma-separated tags to narrow random recipes. |
