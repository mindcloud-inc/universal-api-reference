# Get All Event Data with Sessionize

Retrieves all event data from Sessionize.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/:endpointId/view/All`
- **Base URL:** `https://sessionize.com`
- **Official documentation:** [Get All Event Data](https://sessionize.com/playbook/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endpointId` | path | `string` | yes | Sessionize event API endpoint ID from URLs like https://sessionize.com/api/v2/{endpointId}/view/All. |
