# Get Conversation with Sunshine Conversations

Retrieves a conversation from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/conversations/:conversationId`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [Get Conversation](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
| `conversationId` | path | `string` | no | Conversation id. |
