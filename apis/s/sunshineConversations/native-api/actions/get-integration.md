# Get Integration with Sunshine Conversations

Retrieves an integration from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/integrations/:integrationId`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [Get Integration](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
| `integrationId` | path | `string` | no | Integration id. |
