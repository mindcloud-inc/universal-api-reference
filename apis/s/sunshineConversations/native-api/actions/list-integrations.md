# List Integrations with Sunshine Conversations

Retrieves configured integrations from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/integrations`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [List Integrations](https://developer.zendesk.com/api-reference/conversations/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
