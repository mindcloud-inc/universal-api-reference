# List App Keys with Sunshine Conversations

Retrieves app API keys from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/keys`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [List App Keys](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
