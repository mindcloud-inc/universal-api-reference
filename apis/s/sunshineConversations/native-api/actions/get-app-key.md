# Get App Key with Sunshine Conversations

Retrieves an app API key from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/keys/:keyId`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [Get App Key](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
| `keyId` | path | `string` | no | Sunshine Conversations API key id. |
