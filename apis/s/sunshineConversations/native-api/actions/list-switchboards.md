# List Switchboards with Sunshine Conversations

Retrieves app switchboards from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/switchboards`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [List Switchboards](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
