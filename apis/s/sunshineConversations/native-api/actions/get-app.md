# Get App with Sunshine Conversations

Retrieves app details from Sunshine Conversations.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId`
- **Base URL:** `https://api.smooch.io/v2`
- **Official documentation:** [Get App](https://developer.zendesk.com/api-reference/conversations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Sunshine Conversations app id. |
