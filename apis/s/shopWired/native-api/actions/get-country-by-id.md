# Get a specific country with ShopWired

Retrieves a country from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/countries/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a specific country](https://shopwired.readme.io/reference/getcountrybyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the country to return. |
