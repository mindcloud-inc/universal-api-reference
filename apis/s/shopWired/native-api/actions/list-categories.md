# List categories with ShopWired

Retrieves categories from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List categories](https://shopwired.readme.io/reference/listcategories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
