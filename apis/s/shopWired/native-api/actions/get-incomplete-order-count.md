# Get total incomplete order count with ShopWired

Retrieves the total incomplete order count from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/incomplete-orders/count`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get total incomplete order count](https://shopwired.readme.io/reference/getincompleteordercount)
