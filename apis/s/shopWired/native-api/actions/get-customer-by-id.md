# Get a specific customer with ShopWired

Retrieves a customer from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a specific customer](https://shopwired.readme.io/reference/getcustomerbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the customer to return. |
