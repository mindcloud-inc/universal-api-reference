# List newsletter subscribers with ShopWired

Retrieves newsletter subscribers from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/newsletter-subscribers`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List newsletter subscribers](https://shopwired.readme.io/reference/listnewslettersubscribers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
