# List filter groups with ShopWired

Retrieves filter groups from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/filter-groups`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List filter groups](https://shopwired.readme.io/reference/listfiltergroups)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
