# List product variations with ShopWired

Retrieves variations for a product from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{product_id}/variations`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List product variations](https://shopwired.readme.io/reference/listproductvariations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | The unique identifier of the product. |
