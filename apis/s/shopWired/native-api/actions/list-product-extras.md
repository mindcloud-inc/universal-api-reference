# List product extras with ShopWired

Retrieves extras for a product from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{product_id}/extras`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List product extras](https://shopwired.readme.io/reference/listproductextras)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | ID of the product which the extras are assigned to. |
