# Get a specific brand with ShopWired

Retrieves a brand from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a specific brand](https://shopwired.readme.io/reference/getbrandbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the brand. |
