# List order statuses with ShopWired

Retrieves order statuses from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/order-statuses`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List order statuses](https://shopwired.readme.io/reference/listorderstatuses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
