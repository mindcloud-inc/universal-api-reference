# List product options with ShopWired

Retrieves options for a product from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{product_id}/options`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List product options](https://shopwired.readme.io/reference/listproductoptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | ID of the product which the options are assigned to. |
