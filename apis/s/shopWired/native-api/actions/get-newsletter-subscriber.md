# Get a specific newsletter subscriber with ShopWired

Retrieves a newsletter subscriber from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/newsletter-subscribers/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a specific newsletter subscriber](https://shopwired.readme.io/reference/getnewslettersubscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the subscriber. |
