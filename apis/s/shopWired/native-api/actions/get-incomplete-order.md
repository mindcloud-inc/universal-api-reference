# Get an incomplete order by ID with ShopWired

Retrieves an incomplete order from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/incomplete-orders/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get an incomplete order by ID](https://shopwired.readme.io/reference/getincompleteorder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the incomplete order. |
