# Get a specific category with ShopWired

Retrieves a category from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a specific category](https://shopwired.readme.io/reference/getcategorybyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The unique identifier of the category. |
