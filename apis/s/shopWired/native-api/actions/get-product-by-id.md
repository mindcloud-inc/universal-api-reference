# Get a single product with ShopWired

Retrieves a product from ShopWired by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get a single product](https://shopwired.readme.io/reference/getproductbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the product to return. |
