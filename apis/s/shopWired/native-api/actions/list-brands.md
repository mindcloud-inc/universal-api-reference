# List active brands with ShopWired

Retrieves active brands from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List active brands](https://shopwired.readme.io/reference/listbrands)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
