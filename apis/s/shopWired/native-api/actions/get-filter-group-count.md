# Get total filter group count with ShopWired

Retrieves the total filter group count from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/filter-groups/count`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [Get total filter group count](https://shopwired.readme.io/reference/getfiltergroupcount)
