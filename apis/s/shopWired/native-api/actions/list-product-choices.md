# List product choices with ShopWired

Retrieves choices for a product from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{product_id}/choices`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List product choices](https://shopwired.readme.io/reference/listproductchoices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | ID of the product. |
