# List external payment methods with ShopWired

Retrieves external payment methods from ShopWired.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-methods`
- **Base URL:** `https://api.ecommerceapi.uk/v1`
- **Official documentation:** [List external payment methods](https://shopwired.readme.io/reference/listpaymentmethods)
