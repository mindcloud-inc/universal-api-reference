# Get List with SendMails

Retrieves a list from SendMails by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:uid`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Get List](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#3-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | List UID from SendMails. |
