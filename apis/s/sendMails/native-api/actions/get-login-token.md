# Get Login Token with SendMails

Generates a one-time login token in SendMails.

## Endpoint

- **Method:** `POST`
- **Path:** `/login-token`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Get Login Token](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#2-toc-title)
