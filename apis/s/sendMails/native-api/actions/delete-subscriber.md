# Delete Subscriber with SendMails

Deletes an existing subscriber from SendMails.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/:uid`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Delete Subscriber](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#5-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | Subscriber UID from SendMails. |
