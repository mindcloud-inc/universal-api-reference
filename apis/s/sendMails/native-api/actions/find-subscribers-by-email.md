# Find Subscribers By Email with SendMails

Finds subscribers in SendMails by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/email/:email`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Find Subscribers By Email](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#5-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Subscriber email address. |
