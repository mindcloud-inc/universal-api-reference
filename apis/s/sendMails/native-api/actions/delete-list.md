# Delete List with SendMails

Deletes an existing list from SendMails.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:uid`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Delete List](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#3-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | List UID from SendMails. |
