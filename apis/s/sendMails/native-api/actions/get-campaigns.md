# Get Campaigns with SendMails

Retrieves a list of campaigns from SendMails.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Get Campaigns](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#4-toc-title)
