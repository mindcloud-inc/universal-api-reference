# Get Subscriber with SendMails

Retrieves a subscriber from SendMails by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:uid`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Get Subscriber](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#5-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | Subscriber UID from SendMails. |
