# Get Subscribers with SendMails

Retrieves a list of subscribers from SendMails.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers`
- **Base URL:** `https://app.sendmails.io/api/v1`
- **Official documentation:** [Get Subscribers](https://sendmails.io/docs/campaigns-apis-by-sendmails-io/#5-toc-title)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_uid` | query | `string` | yes | List UID from SendMails. |
