# Store Rendered Asset with ScreenshotOne

## Endpoint

- **Method:** `GET`
- **Path:** `/take`
- **Base URL:** `https://api.screenshotone.com`
- **Official documentation:** [Store Rendered Asset](https://screenshotone.com/docs/options/#store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | yes |
| `storage_path` | query | `string` | yes |
