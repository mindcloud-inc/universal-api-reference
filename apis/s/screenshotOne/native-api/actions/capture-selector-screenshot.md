# Capture Selector Screenshot with ScreenshotOne

## Endpoint

- **Method:** `GET`
- **Path:** `/take`
- **Base URL:** `https://api.screenshotone.com`
- **Official documentation:** [Capture Selector Screenshot](https://screenshotone.com/docs/options/#selector)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | yes |
| `selector` | query | `string` | yes |
