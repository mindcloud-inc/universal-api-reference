# Extract Page Content with ScreenshotOne

## Endpoint

- **Method:** `GET`
- **Path:** `/take`
- **Base URL:** `https://api.screenshotone.com`
- **Official documentation:** [Extract Page Content](https://screenshotone.com/docs/options/#metadata_content)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | yes |
| `metadata_content_format` | query | `string` | no |
