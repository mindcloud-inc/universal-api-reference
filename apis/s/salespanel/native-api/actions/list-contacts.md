# List Contacts with Salespanel

Retrieves contacts from your Salespanel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/`
- **Base URL:** `https://salespanel.io/api/v1`
- **Official documentation:** [List Contacts](https://salespanel.io/docs/#get-all-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
