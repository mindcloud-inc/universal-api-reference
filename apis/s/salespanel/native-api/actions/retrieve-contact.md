# Retrieve Contact with Salespanel

Retrieves a contact from your Salespanel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id/`
- **Base URL:** `https://salespanel.io/api/v1`
- **Official documentation:** [Retrieve Contact](https://salespanel.io/docs/#retrieve-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The unique ID of the contact to retrieve. |
