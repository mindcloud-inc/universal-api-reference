# Get Node with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/node/:nodeId`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get Node](https://api.smugmug.com/api/v2/doc/reference/node.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nodeId` | path | `string` | yes | SmugMug node identifier. |
