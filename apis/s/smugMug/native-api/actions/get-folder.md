# Get Folder with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/folder/user/:nickname`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get Folder](https://api.smugmug.com/api/v2/doc/reference/folder.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nickname` | path | `string` | yes | SmugMug account nickname. |
