# Get Folder By ID with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/folder/id/:folderId`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get Folder By ID](https://api.smugmug.com/api/v2/doc/reference/folder.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | SmugMug folder identifier. |
