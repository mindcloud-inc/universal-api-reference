# Get User with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:nickname`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get User](https://api.smugmug.com/api/v2/doc/reference/user.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nickname` | path | `string` | yes | SmugMug account nickname. |
