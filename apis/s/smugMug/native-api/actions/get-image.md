# Get Image with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/image/:imageUriId`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get Image](https://api.smugmug.com/api/v2/doc/reference/image.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageUriId` | path | `string` | yes | SmugMug image identifier including any URI suffix. |
