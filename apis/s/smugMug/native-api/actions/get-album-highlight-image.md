# Get Album Highlight Image with SmugMug

## Endpoint

- **Method:** `GET`
- **Path:** `/album/:albumKey!highlightimage`
- **Base URL:** `https://api.smugmug.com/api/v2`
- **Official documentation:** [Get Album Highlight Image](https://api.smugmug.com/api/v2/doc/reference/album.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `albumKey` | path | `string` | yes | SmugMug album key. |
