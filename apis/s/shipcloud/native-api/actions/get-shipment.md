# Get Shipment with Shipcloud

Retrieves a shipment from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Shipment](https://developers.shipcloud.io/swagger-ui/#/default/get_shipments__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud shipment identifier. |
