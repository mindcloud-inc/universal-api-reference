# Delete Shipment with Shipcloud

Deletes an existing shipment from Shipcloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shipments/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Delete Shipment](https://developers.shipcloud.io/swagger-ui/#/default/delete_shipments__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud shipment identifier. |
