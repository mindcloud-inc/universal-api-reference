# Delete Webhook with Shipcloud

Deletes an existing webhook from Shipcloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Delete Webhook](https://developers.shipcloud.io/swagger-ui/#/default/delete_webhooks__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud webhook identifier. |
