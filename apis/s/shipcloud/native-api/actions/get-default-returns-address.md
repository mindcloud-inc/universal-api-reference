# Get Default Returns Address with Shipcloud

Retrieves the default returns address from Shipcloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/default_returns_address`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Default Returns Address](https://developers.shipcloud.io/swagger-ui/#/default/get_default_returns_address)
