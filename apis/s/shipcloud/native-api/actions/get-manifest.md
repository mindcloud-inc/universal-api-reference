# Get Manifest with Shipcloud

Retrieves a manifest from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/manifests/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Manifest](https://developers.shipcloud.io/swagger-ui/#/default/get_manifests__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud manifest identifier. |
