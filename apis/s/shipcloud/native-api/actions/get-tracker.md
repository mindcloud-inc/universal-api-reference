# Get Tracker with Shipcloud

Retrieves a tracker from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackers/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Tracker](https://developers.shipcloud.io/swagger-ui/#/default/get_trackers__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud tracker identifier. |
