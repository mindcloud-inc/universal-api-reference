# Get Order with Shipcloud

Retrieves an order from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Order](https://developers.shipcloud.io/swagger-ui/#/default/get_orders__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud order identifier. |
