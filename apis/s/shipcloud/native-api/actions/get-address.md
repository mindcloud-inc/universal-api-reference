# Get Address with Shipcloud

Retrieves an address from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Address](https://developers.shipcloud.io/swagger-ui/#/default/get_addresses__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud address identifier. |
