# Get Default Shipping Address with Shipcloud

Retrieves the default shipping address from Shipcloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/default_shipping_address`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Default Shipping Address](https://developers.shipcloud.io/swagger-ui/#/default/get_default_shipping_address)
