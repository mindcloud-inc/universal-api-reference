# Get Pickup Request with Shipcloud

Retrieves a pickup request from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/pickup_requests/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Pickup Request](https://developers.shipcloud.io/swagger-ui/#/default/get_pickup_requests__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud pickup request identifier. |
