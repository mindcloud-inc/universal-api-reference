# Update Shipment with Shipcloud

Updates an existing shipment in Shipcloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/shipments/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Update Shipment](https://developers.shipcloud.io/swagger-ui/#/default/put_shipments__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud shipment identifier. |
