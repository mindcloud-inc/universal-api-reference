# Create Shipment Quote with Shipcloud

Creates a new shipment quote in Shipcloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/shipment_quotes`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Create Shipment Quote](https://developers.shipcloud.io/swagger-ui/#/default/post_shipment_quotes)
