# Get Webhook with Shipcloud

Retrieves a webhook from Shipcloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.shipcloud.io/v1`
- **Official documentation:** [Get Webhook](https://developers.shipcloud.io/swagger-ui/#/default/get_webhooks__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Shipcloud webhook identifier. |
