# Enable Gate with Statsig

Enables a gate in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/gates/{id}/enable`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Enable Gate](https://docs.statsig.com/api-reference/gates/enable-gate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
