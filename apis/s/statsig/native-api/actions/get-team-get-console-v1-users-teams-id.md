# Get Team with Statsig

Retrieves a team from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/users/teams/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Team](https://docs.statsig.com/api-reference/users/get-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
