# Enable Dynamic Config with Statsig

Enables a dynamic config in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/dynamic_configs/{id}/enable`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Enable Dynamic Config](https://docs.statsig.com/api-reference/dynamic-configs/enable-dynamic-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
