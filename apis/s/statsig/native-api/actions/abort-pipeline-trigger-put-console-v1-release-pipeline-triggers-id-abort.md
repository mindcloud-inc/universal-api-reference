# Abort Pipeline Trigger with Statsig

Aborts a pipeline trigger in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/release_pipeline_triggers/{id}/abort`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Abort Pipeline Trigger](https://docs.statsig.com/api-reference/release-pipelines/abort-pipeline-trigger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
