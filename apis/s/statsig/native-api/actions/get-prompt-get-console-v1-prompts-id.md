# Get Prompt with Statsig

Retrieves a prompt from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/prompts/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Prompt](https://docs.statsig.com/api-reference/prompts/get-prompt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
