# Get Reviews Settings with Statsig

Retrieves reviews settings from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/settings/reviews`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Reviews Settings](https://docs.statsig.com/api-reference/settings/get-reviews-settings)
