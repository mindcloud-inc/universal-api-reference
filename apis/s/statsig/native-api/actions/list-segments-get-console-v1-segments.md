# List Segments with Statsig

Retrieves segments from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/segments`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Segments](https://docs.statsig.com/api-reference/segments/list-segments)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
