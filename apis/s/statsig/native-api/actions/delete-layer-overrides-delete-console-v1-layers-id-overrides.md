# Delete Layer Overrides with Statsig

Deletes layer overrides from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/layers/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Layer Overrides](https://docs.statsig.com/api-reference/layers/delete-layer-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
