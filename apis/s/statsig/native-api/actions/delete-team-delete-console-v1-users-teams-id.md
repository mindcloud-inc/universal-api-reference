# Delete Team with Statsig

Deletes a team from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/users/teams/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Team](https://docs.statsig.com/api-reference/users/delete-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
