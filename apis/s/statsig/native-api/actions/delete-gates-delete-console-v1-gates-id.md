# Delete Gates with Statsig

Deletes gates from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/gates/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Gates](https://docs.statsig.com/api-reference/gates/delete-gates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
