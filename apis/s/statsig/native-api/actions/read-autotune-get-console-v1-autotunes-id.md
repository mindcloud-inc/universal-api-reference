# Read Autotune with Statsig

Retrieves an autotune from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/autotunes/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Autotune](https://docs.statsig.com/api-reference/autotunes/read-autotune)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
