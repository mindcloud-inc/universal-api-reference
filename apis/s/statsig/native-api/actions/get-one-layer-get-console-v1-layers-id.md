# Get one layer with Statsig

Retrieves a layer from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/layers/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get one layer](https://docs.statsig.com/api-reference/layers/get-one-layer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
