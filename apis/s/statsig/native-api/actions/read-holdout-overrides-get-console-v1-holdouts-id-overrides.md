# Read Holdout Overrides with Statsig

Retrieves holdout overrides from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/holdouts/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Holdout Overrides](https://docs.statsig.com/api-reference/holdouts/read-holdout-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
