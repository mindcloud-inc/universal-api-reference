# Delete Autotune with Statsig

Deletes an autotune from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/autotunes/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Autotune](https://docs.statsig.com/api-reference/autotunes/delete-autotune)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
