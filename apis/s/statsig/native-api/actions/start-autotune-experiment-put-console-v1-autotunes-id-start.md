# Start Autotune Experiment with Statsig

Starts an autotune experiment in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/autotunes/{id}/start`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Start Autotune Experiment](https://docs.statsig.com/api-reference/autotunes/start-autotune-experiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
