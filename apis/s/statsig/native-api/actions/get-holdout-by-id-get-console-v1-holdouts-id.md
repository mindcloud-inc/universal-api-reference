# Get holdout by id with Statsig

Retrieves a holdout from Statsig by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/holdouts/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get holdout by id](https://docs.statsig.com/api-reference/holdouts/get-holdout-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
