# Delete Gate Overrides with Statsig

Deletes gate overrides from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/gates/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Gate Overrides](https://docs.statsig.com/api-reference/gates/delete-gate-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
