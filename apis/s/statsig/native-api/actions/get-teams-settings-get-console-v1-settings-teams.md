# Get Teams Settings with Statsig

Retrieves teams settings from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/settings/teams`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Teams Settings](https://docs.statsig.com/api-reference/settings/get-teams-settings)
