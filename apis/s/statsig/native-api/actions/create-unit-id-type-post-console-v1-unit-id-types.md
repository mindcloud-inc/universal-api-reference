# Create Unit ID Type with Statsig

Creates a unit ID type in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/unit_id_types`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Create Unit ID Type](https://docs.statsig.com/api-reference/unit-id-types/create-unit-id-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Request body field. |
| `description` | body | `string` | no | Request body field. |
