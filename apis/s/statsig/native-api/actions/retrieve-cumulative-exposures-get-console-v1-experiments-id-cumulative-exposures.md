# Retrieve cumulative exposures with Statsig

Retrieves cumulative exposures from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/{id}/cumulative_exposures`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Retrieve cumulative exposures](https://docs.statsig.com/api-reference/experiments/retrieve-cumulative-exposures)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
