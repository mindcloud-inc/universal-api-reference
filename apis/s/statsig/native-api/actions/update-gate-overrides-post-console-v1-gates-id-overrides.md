# Update Gate Overrides with Statsig

Updates gate overrides in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/gates/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Gate Overrides](https://docs.statsig.com/api-reference/gates/update-gate-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
