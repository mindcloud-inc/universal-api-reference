# Get Roles Settings with Statsig

Retrieves roles settings from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/settings/roles`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Roles Settings](https://docs.statsig.com/api-reference/settings/get-roles-settings)
