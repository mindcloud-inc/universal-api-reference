# List Target Apps with Statsig

Retrieves target apps from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/target_app`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Target Apps](https://docs.statsig.com/api-reference/target-app/list-target-apps)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
