# Read Ingestion Schedule with Statsig

Retrieves an ingestion schedule from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/ingestion/schedule`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Ingestion Schedule](https://docs.statsig.com/api-reference/ingestions/read-ingestion-schedule)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataset` | query | `string` | yes |
