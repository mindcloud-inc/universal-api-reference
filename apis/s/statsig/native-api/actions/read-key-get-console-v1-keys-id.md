# Read Key with Statsig

Retrieves a key from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/keys/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Key](https://docs.statsig.com/api-reference/keys/read-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
