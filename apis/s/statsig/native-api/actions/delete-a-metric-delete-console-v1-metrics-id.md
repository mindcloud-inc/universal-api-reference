# Delete a metric with Statsig

Deletes a metric from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/metrics/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete a metric](https://docs.statsig.com/api-reference/metrics/delete-a-metric)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
