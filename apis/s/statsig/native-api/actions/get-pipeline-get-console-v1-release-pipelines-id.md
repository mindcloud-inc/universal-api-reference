# Get Pipeline with Statsig

Retrieves a pipeline from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/release_pipelines/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Pipeline](https://docs.statsig.com/api-reference/release-pipelines/get-pipeline)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
