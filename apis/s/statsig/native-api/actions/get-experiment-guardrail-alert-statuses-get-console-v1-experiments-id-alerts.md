# Get Experiment Guardrail Alert Statuses with Statsig

Retrieves experiment guardrail alert statuses from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/{id}/alerts`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Experiment Guardrail Alert Statuses](https://docs.statsig.com/api-reference/experiments/get-experiment-guardrail-alert-statuses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
