# Update Ingestion Source with Statsig

Updates an ingestion source in Statsig.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/console/v1/ingestion`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Ingestion Source](https://docs.statsig.com/api-reference/ingestions/update-ingestion-source)
