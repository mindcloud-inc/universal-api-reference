# Delete Key with Statsig

Deletes a key from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/keys/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Key](https://docs.statsig.com/api-reference/keys/delete-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
