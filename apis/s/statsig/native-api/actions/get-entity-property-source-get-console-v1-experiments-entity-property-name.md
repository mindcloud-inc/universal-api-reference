# Get Entity Property Source with Statsig

Retrieves an entity property source from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/entity_property/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Entity Property Source](https://docs.statsig.com/api-reference/experiments/get-entity-property-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Name of entity property source |
