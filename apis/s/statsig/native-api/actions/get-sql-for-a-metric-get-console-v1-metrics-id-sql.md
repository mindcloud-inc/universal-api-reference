# Get SQL for a metric with Statsig

Retrieves SQL for a Statsig metric.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/metrics/{id}/sql`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get SQL for a metric](https://docs.statsig.com/api-reference/metrics/get-sql-for-a-metric)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
