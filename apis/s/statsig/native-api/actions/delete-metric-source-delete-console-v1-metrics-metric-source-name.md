# Delete Metric Source with Statsig

Deletes a metric source from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/metrics/metric_source/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Metric Source](https://docs.statsig.com/api-reference/metrics/delete-metric-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | name |
