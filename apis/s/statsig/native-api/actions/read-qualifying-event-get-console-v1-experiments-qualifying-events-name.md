# Read Qualifying Event with Statsig

Retrieves a qualifying event from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/qualifying_events/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Qualifying Event](https://docs.statsig.com/api-reference/experiments-warehouse-native/read-qualifying-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | name |
