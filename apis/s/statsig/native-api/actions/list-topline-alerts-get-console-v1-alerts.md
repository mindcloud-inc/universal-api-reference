# List Topline Alerts with Statsig

Retrieves topline alerts from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/alerts`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Topline Alerts](https://docs.statsig.com/api-reference/alerts/list-topline-alerts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
