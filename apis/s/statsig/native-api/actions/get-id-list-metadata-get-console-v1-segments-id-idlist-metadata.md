# Get ID List Metadata with Statsig

Retrieves an id list metadata from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/segments/{id}/idlist_metadata`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get ID List Metadata](https://docs.statsig.com/api-reference/segments/get-id-list-metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
