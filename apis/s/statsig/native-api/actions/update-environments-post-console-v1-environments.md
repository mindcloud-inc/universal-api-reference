# Update Environments with Statsig

Updates environments in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/environments`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Environments](https://docs.statsig.com/api-reference/environments/update-environments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environments` | body | `list` | yes | Request body field. |
