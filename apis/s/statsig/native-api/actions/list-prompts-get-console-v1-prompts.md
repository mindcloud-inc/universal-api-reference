# List Prompts with Statsig

Retrieves prompts from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/prompts`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Prompts](https://docs.statsig.com/api-reference/prompts/list-prompts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
