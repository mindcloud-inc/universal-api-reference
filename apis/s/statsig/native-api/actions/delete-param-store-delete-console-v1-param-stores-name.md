# Delete Param Store with Statsig

Deletes a param store from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/param_stores/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Param Store](https://docs.statsig.com/api-reference/param-store/delete-param-store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
