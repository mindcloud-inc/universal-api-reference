# Delete Unit ID Type with Statsig

Deletes a unit ID type from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/unit_id_types/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Unit ID Type](https://docs.statsig.com/api-reference/unit-id-types/delete-unit-id-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
