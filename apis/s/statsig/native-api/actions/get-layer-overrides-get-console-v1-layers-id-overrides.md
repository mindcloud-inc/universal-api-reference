# Get Layer Overrides with Statsig

Retrieves layer overrides from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/layers/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Layer Overrides](https://docs.statsig.com/api-reference/layers/get-layer-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
