# Disable Gate with Statsig

Disables a gate in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/gates/{id}/disable`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Disable Gate](https://docs.statsig.com/api-reference/gates/disable-gate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
