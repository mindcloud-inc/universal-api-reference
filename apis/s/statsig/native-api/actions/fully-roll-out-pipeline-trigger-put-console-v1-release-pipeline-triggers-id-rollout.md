# Fully Roll Out Pipeline Trigger with Statsig

Fully rolls out a pipeline trigger in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/release_pipeline_triggers/{id}/rollout`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Fully Roll Out Pipeline Trigger](https://docs.statsig.com/api-reference/release-pipelines/fully-roll-out-pipeline-trigger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
