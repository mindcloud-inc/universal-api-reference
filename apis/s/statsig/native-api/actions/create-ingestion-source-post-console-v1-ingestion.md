# Create Ingestion Source with Statsig

Creates an ingestion source in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/ingestion`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Create Ingestion Source](https://docs.statsig.com/api-reference/ingestions/create-ingestion-source)
