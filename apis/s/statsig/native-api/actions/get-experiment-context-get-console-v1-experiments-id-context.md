# Get Experiment Context with Statsig

Retrieves experiment context from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/{id}/context`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Experiment Context](https://docs.statsig.com/api-reference/experiments/get-experiment-context)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
