# Add Holdout Overrides with Statsig

Adds holdout overrides in Statsig.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/console/v1/holdouts/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Add Holdout Overrides](https://docs.statsig.com/api-reference/holdouts/add-holdout-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
