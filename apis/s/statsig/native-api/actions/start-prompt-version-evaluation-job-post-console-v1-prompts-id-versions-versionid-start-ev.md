# Start Prompt Version Evaluation Job with Statsig

Starts a prompt version evaluation job in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/prompts/{id}/versions/{versionId}/start_evals`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Start Prompt Version Evaluation Job](https://docs.statsig.com/api-reference/prompts/start-prompt-version-evaluation-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | — |
| `id` | path | `string` | yes | id |
