# Read Gate Rules with Statsig

Retrieves gate rules from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/gates/{id}/rules`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Gate Rules](https://docs.statsig.com/api-reference/gates/read-gate-rules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
