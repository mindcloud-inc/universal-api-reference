# Remove Holdout Overrides with Statsig

Removes holdout overrides in Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/holdouts/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Remove Holdout Overrides](https://docs.statsig.com/api-reference/holdouts/remove-holdout-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
