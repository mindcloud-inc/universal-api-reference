# List Tags with Statsig

Retrieves tags from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/tags`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Tags](https://docs.statsig.com/api-reference/tags/list-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
