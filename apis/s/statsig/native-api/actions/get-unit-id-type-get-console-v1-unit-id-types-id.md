# Get Unit ID Type with Statsig

Retrieves a unit ID type from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/unit_id_types/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Unit ID Type](https://docs.statsig.com/api-reference/unit-id-types/get-unit-id-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
