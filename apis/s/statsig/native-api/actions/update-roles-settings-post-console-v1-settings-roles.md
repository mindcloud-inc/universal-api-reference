# Update Roles Settings with Statsig

Updates role settings in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/settings/roles`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Roles Settings](https://docs.statsig.com/api-reference/settings/update-roles-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `default_project_role` | body | `string` | yes | Request body field. |
