# Deactivate Key with Statsig

Deactivates a key in Statsig.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/console/v1/keys/{id}/deactivate`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Deactivate Key](https://docs.statsig.com/api-reference/keys/deactivate-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
