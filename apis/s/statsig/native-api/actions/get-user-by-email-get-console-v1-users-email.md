# Get user by email with Statsig

Retrieves a user from Statsig by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/users/{email}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get user by email](https://docs.statsig.com/api-reference/users/get-user-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | email |
