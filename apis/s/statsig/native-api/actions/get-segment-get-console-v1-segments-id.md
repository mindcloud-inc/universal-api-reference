# Get Segment with Statsig

Retrieves a segment from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/segments/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Segment](https://docs.statsig.com/api-reference/segments/get-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
