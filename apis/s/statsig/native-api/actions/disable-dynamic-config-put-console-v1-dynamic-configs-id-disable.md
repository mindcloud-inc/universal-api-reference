# Disable Dynamic Config with Statsig

Disables a dynamic config in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/dynamic_configs/{id}/disable`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Disable Dynamic Config](https://docs.statsig.com/api-reference/dynamic-configs/disable-dynamic-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
