# List Unit ID Types with Statsig

Retrieves unit id types from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/unit_id_types`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Unit ID Types](https://docs.statsig.com/api-reference/unit-id-types/list-unit-id-types)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
