# Get Project Settings with Statsig

Retrieves project settings from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/settings/project`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Project Settings](https://docs.statsig.com/api-reference/settings/get-project-settings)
