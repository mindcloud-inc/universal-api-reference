# Start Experiment Code Cleanup with Statsig

Starts experiment code cleanup in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/experiments/{id}/code_cleanup`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Start Experiment Code Cleanup](https://docs.statsig.com/api-reference/experiments/start-experiment-code-cleanup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
