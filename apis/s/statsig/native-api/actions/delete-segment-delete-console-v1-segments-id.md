# Delete Segment with Statsig

Deletes a segment from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/segments/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Segment](https://docs.statsig.com/api-reference/segments/delete-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
