# Update Holdout Overrides with Statsig

Updates holdout overrides in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/holdouts/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Holdout Overrides](https://docs.statsig.com/api-reference/holdouts/update-holdout-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
