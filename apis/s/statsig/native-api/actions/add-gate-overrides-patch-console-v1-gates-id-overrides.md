# Add Gate Overrides with Statsig

Adds gate overrides in Statsig.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/console/v1/gates/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Add Gate Overrides](https://docs.statsig.com/api-reference/gates/add-gate-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
