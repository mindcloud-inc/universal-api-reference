# Update Teams Settings with Statsig

Updates team settings in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/settings/teams`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Teams Settings](https://docs.statsig.com/api-reference/settings/update-teams-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `require_teams_on_configs` | body | `boolean` | yes | Request body field. |
