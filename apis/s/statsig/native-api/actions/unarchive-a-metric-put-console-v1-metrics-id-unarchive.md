# Unarchive a metric with Statsig

Unarchives a metric in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/metrics/{id}/unarchive`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Unarchive a metric](https://docs.statsig.com/api-reference/metrics/unarchive-a-metric)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
