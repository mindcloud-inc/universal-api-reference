# Read Gate Checks with Statsig

Retrieves gate checks from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/gates/{id}/checks`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Gate Checks](https://docs.statsig.com/api-reference/gates/read-gate-checks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
