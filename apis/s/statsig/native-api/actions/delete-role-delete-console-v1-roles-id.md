# Delete Role with Statsig

Deletes a role from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/roles/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Role](https://docs.statsig.com/api-reference/roles/delete-role)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
