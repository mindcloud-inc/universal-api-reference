# Rotate Key with Statsig

Rotates a key in Statsig.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/console/v1/keys/{id}/rotate`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Rotate Key](https://docs.statsig.com/api-reference/keys/rotate-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
