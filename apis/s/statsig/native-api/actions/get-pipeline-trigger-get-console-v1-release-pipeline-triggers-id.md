# Get Pipeline Trigger with Statsig

Retrieves a pipeline trigger from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/release_pipeline_triggers/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Pipeline Trigger](https://docs.statsig.com/api-reference/release-pipelines/get-pipeline-trigger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
