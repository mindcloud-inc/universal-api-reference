# Start Gate Code Cleanup with Statsig

Starts gate code cleanup in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/gates/{id}/code_cleanup`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Start Gate Code Cleanup](https://docs.statsig.com/api-reference/gates/start-gate-code-cleanup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
