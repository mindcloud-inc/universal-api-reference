# Get Role with Statsig

Retrieves a role from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/roles/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Role](https://docs.statsig.com/api-reference/roles/get-role)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
