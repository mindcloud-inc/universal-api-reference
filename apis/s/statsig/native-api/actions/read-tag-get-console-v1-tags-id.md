# Read Tag with Statsig

Retrieves a tag from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/tags/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Tag](https://docs.statsig.com/api-reference/tags/read-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
