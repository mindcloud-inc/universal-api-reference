# Get Param Store with Statsig

Retrieves a param store from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/param_stores/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Param Store](https://docs.statsig.com/api-reference/param-store/get-param-store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
