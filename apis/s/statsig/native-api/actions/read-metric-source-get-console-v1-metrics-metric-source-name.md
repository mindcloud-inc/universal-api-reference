# Read Metric Source with Statsig

Retrieves a metric source from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/metrics/metric_source/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Metric Source](https://docs.statsig.com/api-reference/metrics/read-metric-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | name |
