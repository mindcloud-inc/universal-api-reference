# Read Target App with Statsig

Retrieves a target app from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/target_app/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Target App](https://docs.statsig.com/api-reference/target-app/read-target-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
