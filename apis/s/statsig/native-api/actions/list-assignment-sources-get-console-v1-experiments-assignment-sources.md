# List Assignment Sources with Statsig

Retrieves assignment sources from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/experiments/assignment_sources`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Assignment Sources](https://docs.statsig.com/api-reference/experiments/list-assignment-sources)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
