# Launch Gate with Statsig

Launches a gate in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/gates/{id}/launch`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Launch Gate](https://docs.statsig.com/api-reference/gates/launch-gate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
