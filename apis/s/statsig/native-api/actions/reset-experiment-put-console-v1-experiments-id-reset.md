# Reset Experiment with Statsig

Resets an experiment in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/experiments/{id}/reset`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Reset Experiment](https://docs.statsig.com/api-reference/experiments/reset-experiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
