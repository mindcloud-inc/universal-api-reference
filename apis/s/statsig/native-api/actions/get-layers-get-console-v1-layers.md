# Get Layers with Statsig

Retrieves layers from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/layers`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Layers](https://docs.statsig.com/api-reference/layers/get-layers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
