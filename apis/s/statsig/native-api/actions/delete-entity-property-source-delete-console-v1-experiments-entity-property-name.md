# Delete Entity Property Source with Statsig

Deletes an entity property source from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/experiments/entity_property/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Entity Property Source](https://docs.statsig.com/api-reference/experiments/delete-entity-property-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | name |
