# List Events with Statsig

Retrieves events from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/events`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Events](https://docs.statsig.com/api-reference/events/list-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
