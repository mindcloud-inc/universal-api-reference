# Delete Assignment Source with Statsig

Deletes an assignment source from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/experiments/assignment_source/{name}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Assignment Source](https://docs.statsig.com/api-reference/experiments/delete-assignment-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Name of the assignment source |
