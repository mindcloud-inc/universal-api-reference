# Get Dynamic Config Rules with Statsig

Retrieves dynamic config rules from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/dynamic_configs/{id}/rules`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get Dynamic Config Rules](https://docs.statsig.com/api-reference/dynamic-configs/get-dynamic-config-rules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
