# Delete Tag with Statsig

Deletes a tag from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/tags/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Tag](https://docs.statsig.com/api-reference/tags/delete-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
