# List Param Stores with Statsig

Retrieves param stores from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/param_stores`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Param Stores](https://docs.statsig.com/api-reference/param-store/list-param-stores)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
