# List Roles with Statsig

Retrieves roles from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/roles`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Roles](https://docs.statsig.com/api-reference/roles/list-roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
