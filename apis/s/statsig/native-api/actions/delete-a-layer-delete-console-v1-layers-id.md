# Delete a layer with Statsig

Deletes a layer from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/layers/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete a layer](https://docs.statsig.com/api-reference/layers/delete-a-layer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
