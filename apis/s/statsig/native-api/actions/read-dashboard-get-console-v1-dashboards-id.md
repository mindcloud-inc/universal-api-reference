# Read Dashboard with Statsig

Retrieves a dashboard from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/dashboards/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Dashboard](https://docs.statsig.com/api-reference/dashboards/read-dashboard)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
