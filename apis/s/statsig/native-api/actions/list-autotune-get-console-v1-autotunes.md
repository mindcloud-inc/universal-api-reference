# List Autotune with Statsig

Retrieves autotunes from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/autotunes`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Autotune](https://docs.statsig.com/api-reference/autotunes/list-autotune)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
