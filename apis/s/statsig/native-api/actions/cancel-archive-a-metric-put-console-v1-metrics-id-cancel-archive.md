# Cancel archive a metric with Statsig

Cancels a metric archive in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/metrics/{id}/cancel_archive`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Cancel archive a metric](https://docs.statsig.com/api-reference/metrics/cancel-archive-a-metric)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
