# Read Topline Alert with Statsig

Retrieves a topline alert from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/alerts/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Topline Alert](https://docs.statsig.com/api-reference/alerts/read-topline-alert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
