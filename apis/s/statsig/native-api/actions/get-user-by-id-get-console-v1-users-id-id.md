# Get user by ID with Statsig

Retrieves a user from Statsig by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/users/id/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Get user by ID](https://docs.statsig.com/api-reference/users/get-user-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
