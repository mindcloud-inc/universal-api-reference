# List Teams with Statsig

Retrieves teams from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/users/teams`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Teams](https://docs.statsig.com/api-reference/users/list-teams)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
