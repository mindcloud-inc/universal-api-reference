# Deleted Experiment with Statsig

Deletes an experiment from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/experiments/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Deleted Experiment](https://docs.statsig.com/api-reference/experiments/deleted-experiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
