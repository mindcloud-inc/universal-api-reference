# Delete Dynamic Config with Statsig

Deletes a dynamic config from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/dynamic_configs/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Dynamic Config](https://docs.statsig.com/api-reference/dynamic-configs/delete-dynamic-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
