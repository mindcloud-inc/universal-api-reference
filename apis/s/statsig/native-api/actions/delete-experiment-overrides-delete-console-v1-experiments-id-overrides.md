# Delete Experiment Overrides with Statsig

Deletes experiment overrides from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/experiments/{id}/overrides`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Experiment Overrides](https://docs.statsig.com/api-reference/experiments/delete-experiment-overrides)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
