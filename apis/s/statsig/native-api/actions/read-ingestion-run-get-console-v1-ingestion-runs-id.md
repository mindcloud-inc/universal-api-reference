# Read Ingestion Run with Statsig

Retrieves an ingestion run from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/ingestion/runs/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Ingestion Run](https://docs.statsig.com/api-reference/ingestions/read-ingestion-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
