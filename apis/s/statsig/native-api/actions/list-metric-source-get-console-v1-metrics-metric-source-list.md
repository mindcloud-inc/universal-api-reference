# List metric source with Statsig

Retrieves metric sources from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/metrics/metric_source/list`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List metric source](https://docs.statsig.com/api-reference/metrics/list-metric-source)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Results per page |
| `page` | query | `number` | no | Page number |
