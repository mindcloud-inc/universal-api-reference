# Update Segment Rules with Statsig

Updates segment rules in Statsig.

## Endpoint

- **Method:** `POST`
- **Path:** `/console/v1/segments/{id}/conditional`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Update Segment Rules](https://docs.statsig.com/api-reference/segments/update-segment-rules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
