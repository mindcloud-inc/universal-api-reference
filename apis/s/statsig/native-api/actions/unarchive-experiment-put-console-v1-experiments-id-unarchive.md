# Unarchive Experiment with Statsig

Unarchives an experiment in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/experiments/{id}/unarchive`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Unarchive Experiment](https://docs.statsig.com/api-reference/experiments/unarchive-experiment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
