# Read Gate with Statsig

Retrieves a gate from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/gates/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Gate](https://docs.statsig.com/api-reference/gates/read-gate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
