# Schedule a metric archive with Statsig

Schedules a metric archive in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/metrics/{id}/schedule_archive`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Schedule a metric archive](https://docs.statsig.com/api-reference/metrics/schedule-a-metric-archive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
