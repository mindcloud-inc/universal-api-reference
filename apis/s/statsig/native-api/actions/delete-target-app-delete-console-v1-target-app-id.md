# Delete Target App with Statsig

Deletes a target app from Statsig.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/console/v1/target_app/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Delete Target App](https://docs.statsig.com/api-reference/target-app/delete-target-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id of target app |
