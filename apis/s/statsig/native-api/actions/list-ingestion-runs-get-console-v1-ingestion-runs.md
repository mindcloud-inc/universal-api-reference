# List Ingestion Runs with Statsig

Retrieves ingestion runs from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/ingestion/runs`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [List Ingestion Runs](https://docs.statsig.com/api-reference/ingestions/list-ingestion-runs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `string` | no |
