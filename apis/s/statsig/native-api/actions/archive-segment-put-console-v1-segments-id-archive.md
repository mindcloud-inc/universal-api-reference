# Archive Segment with Statsig

Archives a segment in Statsig.

## Endpoint

- **Method:** `PUT`
- **Path:** `/console/v1/segments/{id}/archive`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Archive Segment](https://docs.statsig.com/api-reference/segments/archive-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
