# Read Metric Definition with Statsig

Retrieves a metric definition from Statsig.

## Endpoint

- **Method:** `GET`
- **Path:** `/console/v1/metrics/{id}`
- **Base URL:** `https://statsigapi.net`
- **API:** rest
- **Official documentation:** [Read Metric Definition](https://docs.statsig.com/api-reference/metrics/read-metric-definition)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
