# Get SignRequest with SignRequest

## Endpoint

- **Method:** `GET`
- **Path:** `/signrequests/:uuid/`
- **Base URL:** `https://signrequest.com/api/v1`
- **Official documentation:** [Get SignRequest](https://signrequest.com/api/v1/docs/#operation/signrequests_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the SignRequest to retrieve |
