# List Document Attachments with SignRequest

## Endpoint

- **Method:** `GET`
- **Path:** `/document-attachments/`
- **Base URL:** `https://signrequest.com/api/v1`
- **Official documentation:** [List Document Attachments](https://signrequest.com/api/v1/docs/#operation/document-attachments_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document__uuid` | query | `string` | no |
| `document__external_id` | query | `string` | no |
