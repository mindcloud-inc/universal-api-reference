# Get Extract Security Rules For Dimension with Sisense

Retrieves extract security rules for a Sisense dimension.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/elasticubes/:server/:elasticube/datasecurity/:table/:column`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Get Extract Security Rules For Dimension](https://developer.sisense.com/guides/restApi/data-security.html#endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `server` | path | `string` | yes |
| `elasticube` | path | `string` | yes |
| `table` | path | `string` | yes |
| `column` | path | `string` | yes |
