# Get Build Task Status with Sisense

Retrieves build task status from Sisense.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/builds/:buildId`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Get Build Task Status](https://developer.sisense.com/guides/restApi/datamodels.v2.html#building-extract-datamodels)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `buildId` | path | `string` | yes |
