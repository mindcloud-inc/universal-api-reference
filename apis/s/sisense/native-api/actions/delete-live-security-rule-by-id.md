# Delete Live Security Rule By Id with Sisense

Deletes a live security rule from Sisense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/elasticubes/live/datasecurity/:dataSecurityId`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Delete Live Security Rule By Id](https://developer.sisense.com/guides/restApi/data-security.html#endpoints-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSecurityId` | path | `string` | no | The 24-character data security rule id. |
