# List Live Datamodel Security Rules with Sisense

Retrieves live datamodel security rules from Sisense.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/elasticubes/live/:title/datasecurity`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Live Datamodel Security Rules](https://developer.sisense.com/guides/restApi/data-security.html#endpoints-2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | path | `string` | yes |
