# Get Datamodel with Sisense

Retrieves a datamodel from a Sisense instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/datamodels/:datamodelId`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Get Datamodel](https://developer.sisense.com/guides/restApi/datamodels.v2.html#endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datamodelId` | path | `string` | yes | Datamodel OID. |
