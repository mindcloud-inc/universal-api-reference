# Cancel Build Task with Sisense

Cancels an existing Sisense build task.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/builds/:buildId`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Cancel Build Task](https://developer.sisense.com/guides/restApi/datamodels.v2.html#api-structure)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `buildId` | path | `string` | no | The build task identifier. |
