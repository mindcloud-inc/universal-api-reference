# List Build Tasks with Sisense

Retrieves build tasks from a Sisense instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/builds`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Build Tasks](https://developer.sisense.com/guides/restApi/datamodels.v2.html#api-structure)
