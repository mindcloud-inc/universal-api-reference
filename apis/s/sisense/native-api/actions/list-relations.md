# List Relations with Sisense

Retrieves relations from a Sisense datamodel.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/datamodels/:datamodelId/relations`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Relations](https://developer.sisense.com/guides/restApi/datamodels.v2.html#endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datamodelId` | path | `string` | yes |
