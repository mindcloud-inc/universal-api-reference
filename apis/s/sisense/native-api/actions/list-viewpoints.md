# List Viewpoints with Sisense

Retrieves viewpoints from a Sisense instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/infusion/viewpoints`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Viewpoints](https://developer.sisense.com/guides/restApi/infusion-api.html#get-infusion-viewpoints)
