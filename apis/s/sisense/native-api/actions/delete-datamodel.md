# Delete Datamodel with Sisense

Deletes an existing datamodel from Sisense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/datamodels/:datamodelId`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Delete Datamodel](https://developer.sisense.com/guides/restApi/datamodels.v2.html#deleting-an-entire-datamodel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datamodelId` | path | `string` | no | The Datamodel oid. |
