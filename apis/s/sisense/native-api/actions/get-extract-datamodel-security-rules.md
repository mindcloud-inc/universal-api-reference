# Get Extract Datamodel Security Rules with Sisense

Retrieves extract datamodel security rules from Sisense.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/elasticubes/:server/:elasticube/datasecurity`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [Get Extract Datamodel Security Rules](https://developer.sisense.com/guides/restApi/data-security.html#endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `server` | path | `string` | yes |
| `elasticube` | path | `string` | yes |
