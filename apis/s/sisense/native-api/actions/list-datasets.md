# List Datasets with Sisense

Retrieves datasets from a Sisense datamodel.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/datamodels/:datamodelId/datasets`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Datasets](https://developer.sisense.com/guides/restApi/datamodels.v2.html#endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datamodelId` | path | `string` | yes |
