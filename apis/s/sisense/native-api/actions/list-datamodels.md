# List Datamodels with Sisense

Retrieves datamodels from a Sisense instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/datamodels`
- **Base URL:** `https://signup-126940n0.sisense.com`
- **Official documentation:** [List Datamodels](https://developer.sisense.com/guides/restApi/datamodels.v2.html#endpoints)
