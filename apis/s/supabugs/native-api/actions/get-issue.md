# Get Issue with Supabugs

Retrieves an issue from Supabugs by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues/:id`
- **Base URL:** `https://api.supabugs.io/api/public/v1`
- **Official documentation:** [Get Issue](https://api.supabugs.io/api/public/v1/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Supabugs issue id. |
