# Delete Issue with Supabugs

Deletes an existing issue from Supabugs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/issues/:id`
- **Base URL:** `https://api.supabugs.io/api/public/v1`
- **Official documentation:** [Delete Issue](https://api.supabugs.io/api/public/v1/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Supabugs issue id. |
