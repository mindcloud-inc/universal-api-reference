# Get Customer with Simplesat

Retrieves a customer from Simplesat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/customers/:customer_id`
- **Base URL:** `https://api.simplesat.io`
- **Official documentation:** [Get Customer](https://developer.simplesat.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | The ID of the customer to retrieve |
