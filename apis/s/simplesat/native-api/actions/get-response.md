# Get Response with Simplesat

Retrieves a response from Simplesat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/responses/:response_id`
- **Base URL:** `https://api.simplesat.io`
- **Official documentation:** [Get Response](https://developer.simplesat.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `response_id` | path | `string` | yes | The ID of the response to retrieve |
