# Get Answer with Simplesat

Retrieves an answer from Simplesat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/answers/:answer_id`
- **Base URL:** `https://api.simplesat.io`
- **Official documentation:** [Get Answer](https://developer.simplesat.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `answer_id` | path | `string` | yes | The ID of the answer to retrieve |
