# Get Team Member with Simplesat

Retrieves a team member from Simplesat.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/team-members/:team_member_id`
- **Base URL:** `https://api.simplesat.io`
- **Official documentation:** [Get Team Member](https://developer.simplesat.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_member_id` | path | `string` | yes | The ID of the team member to retrieve |
