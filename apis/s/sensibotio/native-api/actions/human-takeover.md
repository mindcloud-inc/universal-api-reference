# Human Takeover with Sensibot.io

Updates human takeover mode in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/human_takeover`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Human Takeover](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `human_takeover` | body | `string` | no |
| `recipient` | body | `string` | no |
