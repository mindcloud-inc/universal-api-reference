# Assistant Welcome Message with Sensibot.io

Updates the assistant welcome message in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/welcome_message`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Assistant Welcome Message](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `assistant_id` | body | `string` | no |
| `welcome_message` | body | `string` | no |
