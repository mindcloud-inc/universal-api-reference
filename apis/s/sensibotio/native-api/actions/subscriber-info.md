# Subscriber Info with Sensibot.io

Retrieves subscriber details from Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/subscriber_info`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Subscriber Info](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriber` | body | `string` | no |
