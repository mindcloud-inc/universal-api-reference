# Subscriber Variables with Sensibot.io

Retrieves subscriber variables from Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/get_variables/:subscriber`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Subscriber Variables](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriber` | path | `string` | no |
