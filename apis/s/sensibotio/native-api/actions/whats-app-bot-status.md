# WhatsApp Bot Status with Sensibot.io

Updates the WhatsApp beta bot status in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsappbeta/bot_status`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [WhatsApp Bot Status](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botstatus` | body | `string` | no |
| `wa_number` | body | `string` | no |
