# Assistant Bot Type with Sensibot.io

Updates the assistant bot type in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/bot_type`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Assistant Bot Type](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `assistant_id` | body | `string` | no |
| `bottype` | body | `string` | no |
