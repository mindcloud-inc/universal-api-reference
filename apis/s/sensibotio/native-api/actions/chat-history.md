# Chat History with Sensibot.io

Retrieves chat history for a recipient from Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/assistant/chathistory`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Chat History](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recipient` | body | `string` | no |
