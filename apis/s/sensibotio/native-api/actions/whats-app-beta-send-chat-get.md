# WhatsApp beta Send Chat [GET] with Sensibot.io

Sends a WhatsApp beta chat message through Sensibot.io using GET.

## Endpoint

- **Method:** `GET`
- **Path:** `/whatsappbeta/send_get`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [WhatsApp beta Send Chat [GET]](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `is_group` | query | `string` | no |
| `message` | query | `string` | no |
| `recipient` | query | `string` | no |
| `token` | query | `string` | no |
| `type` | query | `string` | no |
| `wa_number` | query | `string` | no |
