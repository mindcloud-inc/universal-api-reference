# Create Customer List with Sensibot.io

Creates a new customer list in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsappcloud/create_customerlist`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [Create Customer List](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listname` | body | `string` | no |
