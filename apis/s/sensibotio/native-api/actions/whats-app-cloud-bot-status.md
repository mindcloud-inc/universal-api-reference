# WhatsApp Cloud Bot Status with Sensibot.io

Updates the WhatsApp Cloud bot status in Sensibot.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsappcloud/bot_status`
- **Base URL:** `https://api.sensibot.io`
- **Official documentation:** [WhatsApp Cloud Bot Status](https://api.sensibot.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botstatus` | body | `string` | no |
| `cloud_wa_number` | body | `string` | no |
