# Get Consumption with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `commons/v1/channels/:channelId/consumptions/:consumptionId`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [Get Consumption](https://dev.smsmode.com/commons/v1/#tag/Consumption/operation/consumption-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Channel ID path parameter from the smsmode API route. |
| `consumptionId` | path | `string` | yes | Consumption ID path parameter from the smsmode API route. |
