# Get Transfer with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `commons/v1/organisations/:organisationId/transfers/:transferId`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [Get Transfer](https://dev.smsmode.com/commons/v1/#tag/Transfer/operation/transfer-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organisationId` | path | `string` | yes | Organisation ID path parameter from the smsmode API route. |
| `transferId` | path | `string` | yes | Transfer ID path parameter from the smsmode API route. |
