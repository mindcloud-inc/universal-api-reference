# Get Organisation with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `commons/v1/organisations/:organisationId`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [Get Organisation](https://dev.smsmode.com/commons/v1/#tag/Organisation/operation/organisation-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organisationId` | path | `string` | yes | Organisation ID path parameter from the smsmode API route. |
