# List Credentials with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `commons/v1/channels/:channelId/credentials`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [List Credentials](https://dev.smsmode.com/commons/v1/#tag/Credential/operation/credentials-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Channel ID path parameter from the smsmode API route. |
