# Lookup Number with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `commons/v1/lookup/:msisdn`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [Lookup Number](https://dev.smsmode.com/commons/v1/#tag/Lookup/operation/number-lookup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `msisdn` | path | `string` | yes | MSISDN path parameter from the smsmode API route. |
