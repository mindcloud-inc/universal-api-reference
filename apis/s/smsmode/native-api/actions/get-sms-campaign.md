# Get SMS Campaign with smsmode

## Endpoint

- **Method:** `GET`
- **Path:** `sms/v1/channels/:channelId/campaigns/:campaignId`
- **Base URL:** `https://rest.smsmode.com/`
- **Official documentation:** [Get SMS Campaign](https://dev.smsmode.com/sms/v1/#tag/Campaign/operation/campaign-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Channel ID path parameter from the smsmode API route. |
| `campaignId` | path | `string` | yes | Campaign ID path parameter from the smsmode API route. |
