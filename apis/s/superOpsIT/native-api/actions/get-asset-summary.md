# Get Asset Summary with SuperOps IT

## Endpoint

- **Method:** `POST`
- **Path:** `/it`
- **Base URL:** `https://api.superops.ai`
- **Official documentation:** [Get Asset Summary](https://developer.superops.com/it#query-getAssetSummary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | body | `string` | yes | The SuperOps asset ID. |
