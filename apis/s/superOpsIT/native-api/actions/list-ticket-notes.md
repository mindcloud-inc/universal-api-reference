# List Ticket Notes with SuperOps IT

## Endpoint

- **Method:** `POST`
- **Path:** `/it`
- **Base URL:** `https://api.superops.ai`
- **Official documentation:** [List Ticket Notes](https://developer.superops.com/it#query-getTicketNoteList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | body | `string` | yes | The SuperOps ticket ID. |
