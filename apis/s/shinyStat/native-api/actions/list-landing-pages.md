# List Landing Pages with ShinyStat

Retrieves landing page metrics from ShinyStat.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/enter`
- **Base URL:** `https://report.shinystat.com`
- **Official documentation:** [List Landing Pages](https://www.shinystat.com/it/guida-elemento_report-pagine-pagine-di-ingresso.html)
