# Sign In with ShinyStat

Retrieves an authenticated session from ShinyStat.

## Endpoint

- **Method:** `POST`
- **Path:** `/login-ex`
- **Base URL:** `https://report.shinystat.com`
- **Official documentation:** [Sign In](https://www.shinystat.com/en/guida_integrazione_looker_studio_configurazione.html)
