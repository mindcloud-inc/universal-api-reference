# Get Story Details with Storydoc

Retrieves story details from Storydoc.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/stories/:storyId`
- **Base URL:** `https://api.storydoc.com`
- **Official documentation:** [Get Story Details](https://docs.storydoc.com/operation/operation-getstory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyId` | path | `string` | yes | The ID of the story to retrieve. |
