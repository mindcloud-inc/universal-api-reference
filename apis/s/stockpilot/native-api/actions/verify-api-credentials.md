# Verify API Credentials with Stockpilot

Retrieves organization details for the current Stockpilot credentials.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/who-is`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Verify API Credentials](https://api.stockpilot.dev/redoc#operation/who_is_auth_who_is_get)
