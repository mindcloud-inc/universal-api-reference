# Get Sales Summary with Stockpilot

Retrieves sales summary analytics from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/sales-summary`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Get Sales Summary](https://api.stockpilot.dev/redoc#operation/get_sales_summary_analytics_sales_summary_get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `range` | query | `number` | no |
| `top_items` | query | `number` | no |
