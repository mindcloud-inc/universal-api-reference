# Create Category with Stockpilot

Creates a new category in Stockpilot.

## Endpoint

- **Method:** `POST`
- **Path:** `/categories/create`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Create Category](https://api.stockpilot.dev/redoc#operation/create_category_categories_create_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Category name |
