# List Orders with Cancellation Requests with Stockpilot

Retrieves orders with cancellation requests from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/cancellation-requests`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [List Orders with Cancellation Requests](https://api.stockpilot.dev/redoc#operation/get_cancellation_requests_orders_cancellation_requests_get)
