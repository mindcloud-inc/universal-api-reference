# Get Label Suggestion with Stockpilot

Retrieves shipping label suggestions from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping/label-suggestion`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Get Label Suggestion](https://api.stockpilot.dev/redoc#operation/get_shipping_label_suggestion_shipping_label_suggestion_get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_pk` | query | `number` | yes |
