# List Shipping Integrations with Stockpilot

Retrieves shipping integrations from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping/integrations`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [List Shipping Integrations](https://api.stockpilot.dev/redoc#operation/get_shipping_integrations_shipping_integrations_get)
