# Create Brand with Stockpilot

Creates a new brand in Stockpilot.

## Endpoint

- **Method:** `POST`
- **Path:** `/brands/create`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Create Brand](https://api.stockpilot.dev/redoc#operation/create_brand_brands_create_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Brand name |
