# Get Fulfillment Details with Stockpilot

Retrieves fulfillment details for an order in Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/fulfillment`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Get Fulfillment Details](https://api.stockpilot.dev/redoc#operation/get_fulfillment_details_orders_fulfillment_get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_pk` | query | `number` | yes |
