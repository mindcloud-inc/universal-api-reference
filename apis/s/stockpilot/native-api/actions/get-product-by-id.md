# Get Product by ID with Stockpilot

Retrieves a product from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/get`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Get Product by ID](https://api.stockpilot.dev/redoc#operation/get_product_products_get_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Internal product ID |
