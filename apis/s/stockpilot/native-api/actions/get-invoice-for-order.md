# Get Invoice for Order with Stockpilot

Retrieves an invoice for an order in Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/get/:order_pk`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [Get Invoice for Order](https://api.stockpilot.dev/redoc#operation/get_invoice_invoices_get__order_pk__get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_pk` | path | `number` | yes |
