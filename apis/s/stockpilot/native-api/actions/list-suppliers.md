# List Suppliers with Stockpilot

Retrieves suppliers from Stockpilot.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchase-orders/suppliers/list`
- **Base URL:** `https://api.stockpilot.dev`
- **Official documentation:** [List Suppliers](https://api.stockpilot.dev/redoc#operation/get_suppliers_list_purchase_orders_suppliers_list_get)
