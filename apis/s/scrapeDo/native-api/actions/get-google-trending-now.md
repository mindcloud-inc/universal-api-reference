# Get Google trending now with Scrape do

Retrieves Google trending searches with Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/google/trending`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Get Google trending now](https://scrape.do/documentation/google-trends-api/trending/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `geo` | query | `string` | yes | Country code for Google Trending Now. |
