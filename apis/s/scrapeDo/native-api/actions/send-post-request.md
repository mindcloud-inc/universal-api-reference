# Send POST request with Scrape do

Sends a POST request with Scrape do.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Send POST request](https://scrape.do/documentation/api-response/post-put-request/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The target URL that will receive the POST request. |
