# Get Google trends data with Scrape do

Retrieves Google Trends data with Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/google/trends`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Get Google trends data](https://scrape.do/documentation/google-trends-api/trends/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The Google Trends keyword. |
