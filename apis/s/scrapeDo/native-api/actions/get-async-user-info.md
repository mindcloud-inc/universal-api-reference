# Get async user info with Scrape do

Retrieves async user information from Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `https://q.scrape.do/api/v1/me`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Get async user info](https://scrape.do/documentation/async-api/get-me/)
