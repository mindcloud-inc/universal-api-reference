# Use Google AI mode with Scrape do

Retrieves Google AI Mode results with Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/google/search/ai-mode`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Use Google AI mode](https://scrape.do/documentation/google-search-api/ai-mode/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The Google AI mode query. |
