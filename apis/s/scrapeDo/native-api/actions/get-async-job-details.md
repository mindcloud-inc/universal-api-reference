# Get async job details with Scrape do

Retrieves async job details from Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `https://q.scrape.do/api/v1/jobs/:jobID`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Get async job details](https://scrape.do/documentation/async-api/get-job/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobID` | path | `string` | yes | The async job identifier. |
