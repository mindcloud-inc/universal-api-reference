# Search Google with Scrape do

Finds Google search results with Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/google/search`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Search Google](https://scrape.do/documentation/google-search-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The Google search query. |
