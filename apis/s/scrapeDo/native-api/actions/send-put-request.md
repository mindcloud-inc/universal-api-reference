# Send PUT request with Scrape do

Sends a PUT request with Scrape do.

## Endpoint

- **Method:** `PUT`
- **Path:** `/`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Send PUT request](https://scrape.do/documentation/api-response/post-put-request/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The target URL that will receive the PUT request. |
