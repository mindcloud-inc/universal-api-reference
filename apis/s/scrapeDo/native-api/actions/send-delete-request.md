# Send DELETE request with Scrape do

Sends a DELETE request with Scrape do.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Send DELETE request](https://scrape.do/documentation/api-response/post-put-request/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The target URL that will receive the DELETE request. |
