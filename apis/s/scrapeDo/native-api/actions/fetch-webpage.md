# Fetch webpage with Scrape do

Retrieves webpage content with Scrape do.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.scrape.do`
- **Official documentation:** [Fetch webpage](https://scrape.do/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The target URL to fetch. |
