# Get Script with Skyvern

Retrieves a script by ID from Skyvern.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scripts/:script_id`
- **Base URL:** `https://api.skyvern.com`
- **Official documentation:** [Get Script](https://www.skyvern.com/docs/api-reference/scripts/get-script-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `script_id` | path | `string` | yes | The unique identifier of the script |
