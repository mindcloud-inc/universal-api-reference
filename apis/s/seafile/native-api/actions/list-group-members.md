# List Group Members with Seafile

Retrieves members of a Seafile group.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/groups/{groupId}/members/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Group Members](https://seafile-api.readme.io/reference/get_api-v2-1-groups-group-id-members)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
