# List Starred Items with Seafile

Retrieves the starred items in Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/starred-items/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Starred Items](https://seafile-api.readme.io/reference/get_api-v2-1-starred-items)
