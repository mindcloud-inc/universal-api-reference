# Get User Profile with Seafile

Retrieves the current user profile from Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/user/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get User Profile](https://seafile-api.readme.io/reference/get_api-v2-1-user)
