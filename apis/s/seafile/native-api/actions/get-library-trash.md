# Get Library Trash with Seafile

Retrieves trash contents for a Seafile library.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/repos/{repoId}/trash/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Library Trash](https://seafile-api.readme.io/reference/get_api-v2-1-repos-repo-id-trash)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | path | `string` | no |
