# Search Files by Name in Library with Seafile

Finds files in a Seafile library by name.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/search-file/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Search Files by Name in Library](https://seafile-api.readme.io/reference/get_api-v2-1-search-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | query | `string` | no |
| `q` | query | `string` | no |
