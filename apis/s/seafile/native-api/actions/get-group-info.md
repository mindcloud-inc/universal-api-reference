# Get Group Info with Seafile

Retrieves details for a Seafile group.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/groups/{groupId}/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Group Info](https://seafile-api.readme.io/reference/get_api-v2-1-groups-group-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
