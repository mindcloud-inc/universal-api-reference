# List Items in Directory with Seafile

Retrieves items in a Seafile library directory.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/repos/{repoId}/dir/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Items in Directory](https://seafile-api.readme.io/reference/get_api2-repos-repo-id-dir)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `p` | query | `string` | no |
| `repo_id` | path | `string` | no |
