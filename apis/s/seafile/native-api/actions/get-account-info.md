# Get Account Info with Seafile

Retrieves the current account information from Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/account/info/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Account Info](https://seafile-api.readme.io/reference/get_api2-account-info)
