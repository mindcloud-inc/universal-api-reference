# Get Invitation with Seafile

Retrieves a Seafile invitation by token.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/invitations/{invitationToken}/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Invitation](https://seafile-api.readme.io/reference/get_api-v2-1-invitations-invitation-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invitation_token` | path | `string` | no |
