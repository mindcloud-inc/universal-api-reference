# Get File Activities with Seafile

Retrieves recent file activity events from Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/activities/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get File Activities](https://seafile-api.readme.io/reference/get_api-v2-1-activities)
