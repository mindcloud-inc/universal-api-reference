# Get Library Info with Seafile

Retrieves details for a Seafile library.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/repos/{repo_id}/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Library Info](https://seafile-api.readme.io/reference/get_api2-repos-repo-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | path | `string` | no |
