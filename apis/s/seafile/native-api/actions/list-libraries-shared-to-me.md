# List Libraries Shared to Me with Seafile

Retrieves Seafile libraries shared with the current user.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/beshared-repos/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Libraries Shared to Me](https://seafile-api.readme.io/reference/get_api2-beshared-repos)
