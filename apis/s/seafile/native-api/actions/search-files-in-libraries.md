# Search Files in Libraries with Seafile

Finds files across Seafile libraries by keyword.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/search/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Search Files in Libraries](https://seafile-api.readme.io/reference/get_api2-search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | no |
