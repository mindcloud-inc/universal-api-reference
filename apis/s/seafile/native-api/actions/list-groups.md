# List Groups with Seafile

Retrieves the groups available in Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/groups/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Groups](https://seafile-api.readme.io/reference/get_api2-groups)
