# List Libraries with Seafile

Retrieves libraries from Seafile, optionally filtered by name.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/repos/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Libraries](https://seafile-api.readme.io/reference/get_api2-repos)
