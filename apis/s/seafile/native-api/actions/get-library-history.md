# Get Library History with Seafile

Retrieves the history of a Seafile library.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/repos/{repoId}/history/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Library History](https://seafile-api.readme.io/reference/get_api-v2-1-repos-repo-id-history)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | path | `string` | no |
