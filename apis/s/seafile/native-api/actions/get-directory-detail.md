# Get Directory Detail with Seafile

Retrieves details for a directory in Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/repos/{repoId}/dir/detail/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Directory Detail](https://seafile-api.readme.io/reference/get_api-v2-1-repos-repo-id-dir-detail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `p` | query | `string` | no |
| `repo_id` | path | `string` | no |
