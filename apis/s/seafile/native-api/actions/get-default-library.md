# Get Default Library with Seafile

Retrieves the default library from Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/default-repo/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Default Library](https://seafile-api.readme.io/reference/get_api2-default-repo)
