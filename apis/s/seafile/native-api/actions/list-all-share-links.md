# List All Share Links with Seafile

Retrieves all share links from Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/share-links/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List All Share Links](https://seafile-api.readme.io/reference/get_api-v2-1-share-links)
