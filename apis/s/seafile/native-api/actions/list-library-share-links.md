# List Library Share Links with Seafile

Retrieves share links for a Seafile library.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/share-links/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Library Share Links](https://seafile-api.readme.io/reference/get_api-v2-1-share-links-repo-id-repo-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | query | `string` | no |
| `repo_id` | query | `string` | no |
