# Get Server Information with Seafile

Retrieves the current Seafile server information.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/server-info/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Server Information](https://seafile-api.readme.io/reference/get_api2-server-info)
