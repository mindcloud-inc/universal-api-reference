# List Folder Download Items with Seafile

Retrieves items from a Seafile folder download link.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/d/{token}/dir/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Folder Download Items](https://seafile-api.readme.io/reference/get_api2-d-token-dir)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token` | path | `string` | no |
