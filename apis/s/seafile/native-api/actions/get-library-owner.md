# Get Library Owner with Seafile

Retrieves the owner of a Seafile library.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/repos/{repoId}/owner/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get Library Owner](https://seafile-api.readme.io/reference/get_api2-repos-repo-id-owner)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `repo_id` | path | `string` | no |
