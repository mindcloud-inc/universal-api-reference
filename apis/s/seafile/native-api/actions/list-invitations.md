# List Invitations with Seafile

Retrieves the current invitations in Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api/v2.1/invitations/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Invitations](https://seafile-api.readme.io/reference/get_api-v2-1-invitations)
