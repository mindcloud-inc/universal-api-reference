# List Devices with Seafile

Retrieves the current devices connected to Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/devices/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [List Devices](https://seafile-api.readme.io/reference/get_api2-devices)
