# Get File Detail with Seafile

Retrieves details for a file in Seafile.

## Endpoint

- **Method:** `GET`
- **Path:** `https://plus.seafile.com/api2/repos/{repoId}/file/detail/`
- **Base URL:** `https://plus.seafile.com/api2`
- **Official documentation:** [Get File Detail](https://seafile-api.readme.io/reference/get_api2-repos-repo-id-file-detail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `p` | query | `string` | no |
| `repo_id` | path | `string` | no |
