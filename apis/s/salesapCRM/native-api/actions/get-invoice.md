# Get Invoice with SalesapCRM

Retrieves an invoice from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Get Invoice](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM invoice record ID from the path. |
