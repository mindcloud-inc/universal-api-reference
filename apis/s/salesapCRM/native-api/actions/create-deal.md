# Create Deal with SalesapCRM

Creates a deal in SalesapCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/deals`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Create Deal](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | JSON:API data object for a deal, including type, attributes, and optional relationships. |
