# List Diary Events with SalesapCRM

Retrieves diary events from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/diary-events`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Diary Events](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
