# Delete Product with SalesapCRM

Deletes a product from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Product](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM product record ID from the path. |
