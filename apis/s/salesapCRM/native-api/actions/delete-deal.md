# Delete Deal with SalesapCRM

Deletes a deal from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deals/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Deal](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM deal record ID from the path. |
