# Get Order with SalesapCRM

Retrieves an order from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Get Order](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM order record ID from the path. |
