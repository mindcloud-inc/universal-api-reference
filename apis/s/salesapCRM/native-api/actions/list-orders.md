# List Orders with SalesapCRM

Retrieves orders from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Orders](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
