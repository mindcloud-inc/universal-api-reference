# Delete Diary Task with SalesapCRM

Deletes a diary task from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/diary-tasks/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Diary Task](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM diary task record ID from the path. |
