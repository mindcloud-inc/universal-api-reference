# List Invoices with SalesapCRM

Retrieves invoices from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Invoices](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
