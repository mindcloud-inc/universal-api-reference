# List Contacts with SalesapCRM

Retrieves contacts from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Contacts](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
