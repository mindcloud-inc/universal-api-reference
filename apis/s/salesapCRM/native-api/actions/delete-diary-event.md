# Delete Diary Event with SalesapCRM

Deletes a diary event from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/diary-events/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Diary Event](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM diary event record ID from the path. |
