# Delete Contact with SalesapCRM

Deletes a contact from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Contact](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM contact record ID from the path. |
