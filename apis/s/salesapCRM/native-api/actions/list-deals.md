# List Deals with SalesapCRM

Retrieves deals from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Deals](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
