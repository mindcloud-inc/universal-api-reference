# List Products with SalesapCRM

Retrieves products from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Products](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
