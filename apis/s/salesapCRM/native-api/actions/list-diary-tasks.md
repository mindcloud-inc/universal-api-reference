# List Diary Tasks with SalesapCRM

Retrieves diary tasks from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/diary-tasks`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Diary Tasks](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
