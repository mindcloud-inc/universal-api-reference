# Delete Order with SalesapCRM

Deletes an order from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Order](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM order record ID from the path. |
