# List Companies with SalesapCRM

Retrieves companies from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [List Companies](https://api.salesap.ru/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
