# Get Diary Task with SalesapCRM

Retrieves a diary task from SalesapCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/diary-tasks/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Get Diary Task](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM diary task record ID from the path. |
