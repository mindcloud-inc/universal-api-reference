# Delete Company with SalesapCRM

Deletes a company from SalesapCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/{id}`
- **Base URL:** `https://app.salesap.ru/api/v1`
- **Official documentation:** [Delete Company](https://api.salesap.ru/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | SalesapCRM company record ID from the path. |
