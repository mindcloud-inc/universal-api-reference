# Get Repository Label with Socket

Retrieves a repository label from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/repos/labels/:label_id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Repository Label](https://docs.socket.dev/reference/getorgrepolabel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `label_id` | path | `string` | yes |
