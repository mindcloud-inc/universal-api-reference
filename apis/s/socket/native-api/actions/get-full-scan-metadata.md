# Get Full Scan Metadata with Socket

Retrieves full scan metadata from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/full-scans/:full_scan_id/metadata`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Full Scan Metadata](https://docs.socket.dev/reference/getorgfullscanmetadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `full_scan_id` | path | `string` | yes |
