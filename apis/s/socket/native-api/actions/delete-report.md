# Delete Report with Socket

Deletes an existing report from Socket.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/report/delete/:id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Delete Report](https://docs.socket.dev/reference/deletereport)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
