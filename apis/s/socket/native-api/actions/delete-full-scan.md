# Delete Full Scan with Socket

Deletes an existing full scan from Socket.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orgs/:org_slug/full-scans/:full_scan_id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Delete Full Scan](https://docs.socket.dev/reference/deleteorgfullscan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `full_scan_id` | path | `string` | yes |
