# Get Organization License Policy with Socket

Retrieves a deprecated organization license policy from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/settings/license-policy`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Organization License Policy](https://docs.socket.dev/reference/getorglicensepolicy)
