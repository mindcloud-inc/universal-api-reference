# Get Full Scan Diff GFM with Socket

Retrieves a full scan diff as GitHub Flavored Markdown from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/full-scans/diff/gfm`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Full Scan Diff GFM](https://docs.socket.dev/reference/getorgfullscandiffgfm)
