# Update Webhook with Socket

Updates an existing webhook in Socket.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orgs/:org_slug/webhooks/:webhook_id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Update Webhook](https://docs.socket.dev/reference/updateorgwebhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes |
