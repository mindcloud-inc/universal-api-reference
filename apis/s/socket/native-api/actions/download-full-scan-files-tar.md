# Download Full Scan Files Tar with Socket

Downloads a full scan tarball from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/full-scans/:full_scan_id/files/tar`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Download Full Scan Files Tar](https://docs.socket.dev/reference/downloadorgfullscanfilesastar)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `full_scan_id` | path | `string` | yes |
