# Update Repository Label with Socket

Updates an existing repository label in Socket.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orgs/:org_slug/repos/labels/:label_id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Update Repository Label](https://docs.socket.dev/reference/updateorgrepolabel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `label_id` | path | `string` | yes |
