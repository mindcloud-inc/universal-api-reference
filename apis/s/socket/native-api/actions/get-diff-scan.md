# Get Diff Scan with Socket

Retrieves a diff scan from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/diff-scans/:diff_scan_id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Diff Scan](https://docs.socket.dev/reference/getdiffscanbyid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `diff_scan_id` | path | `string` | yes |
