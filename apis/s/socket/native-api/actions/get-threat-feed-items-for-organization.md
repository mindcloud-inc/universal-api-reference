# Get Threat Feed Items for Organization with Socket

Retrieves organization threat feed items from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/threat-feed`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Threat Feed Items for Organization](https://docs.socket.dev/reference/getorgthreatfeeditems)
