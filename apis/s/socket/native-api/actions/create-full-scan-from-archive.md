# Create Full Scan from Archive with Socket

Creates a full scan in Socket from an archive.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/:org_slug/full-scans/archive`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Create Full Scan from Archive](https://docs.socket.dev/reference/createorgfullscanarchive)
