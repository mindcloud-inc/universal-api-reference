# List Historical Snapshots with Socket

Retrieves historical organization snapshots from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/historical/snapshots`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [List Historical Snapshots](https://docs.socket.dev/reference/historicalsnapshotslist)
