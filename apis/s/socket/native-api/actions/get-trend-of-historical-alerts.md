# Get Trend of Historical Alerts with Socket

Retrieves historical alert trends from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/historical/alerts/trend`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Trend of Historical Alerts](https://docs.socket.dev/reference/historicalalertstrend)
