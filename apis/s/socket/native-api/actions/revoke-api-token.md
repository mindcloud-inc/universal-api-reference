# Revoke API Token with Socket

Revokes an existing API token in Socket.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/:org_slug/api-tokens/revoke`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Revoke API Token](https://docs.socket.dev/reference/postapitokensrevoke)
