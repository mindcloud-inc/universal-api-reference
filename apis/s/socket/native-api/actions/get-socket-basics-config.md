# Get Socket Basics Config with Socket

Retrieves Socket Basics configuration from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/settings/socket-basics`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Socket Basics Config](https://docs.socket.dev/reference/getsocketbasicsconfig)
