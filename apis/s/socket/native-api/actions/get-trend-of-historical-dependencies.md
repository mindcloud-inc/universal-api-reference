# Get Trend of Historical Dependencies with Socket

Retrieves historical dependency trends from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/historical/dependencies/trend`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Trend of Historical Dependencies](https://docs.socket.dev/reference/historicaldependenciestrend)
