# Get Telemetry Config with Socket

Retrieves an organization telemetry configuration from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/telemetry/config`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Telemetry Config](https://docs.socket.dev/reference/getorgtelemetryconfig)
