# Update Telemetry Config with Socket

Updates an organization telemetry configuration in Socket.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orgs/:org_slug/telemetry/config`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Update Telemetry Config](https://docs.socket.dev/reference/updateorgtelemetryconfig)
