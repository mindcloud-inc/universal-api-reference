# Get Packages by PURL for Organization with Socket

Retrieves packages by PURL for a Socket organization.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/:org_slug/purl`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Get Packages by PURL for Organization](https://docs.socket.dev/reference/batchpackagefetchbyorg)
