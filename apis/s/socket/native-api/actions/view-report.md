# View Report with Socket

Retrieves an uploaded report from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/view/:id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [View Report](https://docs.socket.dev/reference/getreport)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
