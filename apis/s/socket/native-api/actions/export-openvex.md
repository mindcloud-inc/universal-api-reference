# Export OpenVEX with Socket

Exports OpenVEX vulnerability data from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/export/openvex/:id`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Export OpenVEX](https://docs.socket.dev/reference/exportopenvex)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
