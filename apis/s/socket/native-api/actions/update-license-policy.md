# Update License Policy with Socket

Updates an organization license policy in Socket.

## Endpoint

- **Method:** `POST`
- **Path:** `/orgs/:org_slug/settings/license-policy`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [Update License Policy](https://docs.socket.dev/reference/updateorglicensepolicy)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `allow` | body | `string` | no |
| `options` | body | `string` | no |
| `warn` | body | `string` | no |
