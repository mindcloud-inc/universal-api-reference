# List Alert Triage with Socket

Retrieves organization alert triage rules from Socket.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_slug/triage/alerts`
- **Base URL:** `https://api.socket.dev/v0`
- **Official documentation:** [List Alert Triage](https://docs.socket.dev/reference/getorgtriage)
