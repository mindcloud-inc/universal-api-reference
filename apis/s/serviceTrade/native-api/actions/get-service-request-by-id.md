# Get Service Request by ID with ServiceTrade

Retrieves a service request from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `servicerequest/:serviceRequestId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Service Request by ID](https://api.servicetrade.com/api/docs#resource-servicerequest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceRequestId` | path | `number` | yes | ID of the service request to retrieve |
