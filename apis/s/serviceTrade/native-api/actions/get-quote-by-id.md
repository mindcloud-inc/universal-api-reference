# Get Quote by ID with ServiceTrade

Retrieves a quote from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `quote/:quoteId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Quote by ID](https://api.servicetrade.com/api/docs#resource-quote)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quoteId` | path | `number` | yes | ID of the quote to retrieve |
