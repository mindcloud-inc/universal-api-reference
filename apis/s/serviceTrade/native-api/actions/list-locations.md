# List Locations with ServiceTrade

Retrieves all locations from ServiceTrade.

## Endpoint

- **Method:** `GET`
- **Path:** `location`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [List Locations](https://api.servicetrade.com/api/docs#resource-location)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | no |
| `refNumber` | query | `string` | no |
| `companyId` | query | `number` | no |
| `status` | query | `string` | no |
| `limit` | query | `number` | no |
