# Get Contact by ID with ServiceTrade

Retrieves a contact from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `contact/:contactId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Contact by ID](https://api.servicetrade.com/api/docs#resource-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | ID of the contact to retrieve |
