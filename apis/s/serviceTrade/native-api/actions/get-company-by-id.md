# Get Company by ID with ServiceTrade

Retrieves a company from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `company/:companyId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Company by ID](https://api.servicetrade.com/api/docs#resource-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | ID of the company to retrieve |
