# Get Location by ID with ServiceTrade

Retrieves a location from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `location/:locationId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Location by ID](https://api.servicetrade.com/api/docs#resource-location)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locationId` | path | `number` | yes |
