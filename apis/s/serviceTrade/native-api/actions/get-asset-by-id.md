# Get Asset by ID with ServiceTrade

Retrieves an asset from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `asset/:assetId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Asset by ID](https://api.servicetrade.com/api/docs#resource-asset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `number` | yes | ID of the asset to retrieve |
