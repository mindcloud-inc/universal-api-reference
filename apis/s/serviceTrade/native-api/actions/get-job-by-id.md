# Get Job by ID with ServiceTrade

Retrieves a job from ServiceTrade by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `job/:jobId`
- **Base URL:** `https://api.servicetrade.com/api`
- **Official documentation:** [Get Job by ID](https://api.servicetrade.com/api/docs#resource-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `number` | yes | ID of the job to retrieve |
