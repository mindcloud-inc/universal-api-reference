# Get User Signature Qualities Detail with Skribble Sign

Retrieves detailed user signature qualities from Skribble Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/signature-qualities-detail`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Get User Signature Qualities Detail](https://api-doc.skribble.com/#8de1cfa7-e5ed-423a-8c5d-40ba3efc5f2b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | query | `string` | yes | The Skribble username to inspect. |
