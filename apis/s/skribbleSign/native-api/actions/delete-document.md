# Delete Document with Skribble Sign

Deletes an existing document from Skribble Sign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/documents/:documentId`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Delete Document](https://api-doc.skribble.com/#294578e1-93f2-4d41-bc55-2850bfd7c4c1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The document ID. |
