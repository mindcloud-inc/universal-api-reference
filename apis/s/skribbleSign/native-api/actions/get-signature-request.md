# Get Signature Request with Skribble Sign

Retrieves a signature request from Skribble Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/signature-requests/:signatureRequestId`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Get Signature Request](https://api-doc.skribble.com/#874d9e77-5bb4-4381-9252-925f538c5dbc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signatureRequestId` | path | `string` | yes | The signature request ID. |
