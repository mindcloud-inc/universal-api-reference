# Get User Signature Qualities with Skribble Sign

Retrieves user signature qualities from Skribble Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/signature-qualities`
- **Base URL:** `https://api.skribble.com`
- **Official documentation:** [Get User Signature Qualities](https://api-doc.skribble.com/#b4605fb0-ef85-4d0f-9bd3-2a6db9b0f2e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | query | `string` | yes | The Skribble username to inspect. |
