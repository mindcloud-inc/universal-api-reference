# Get Map Reviews with SearchApi

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://www.searchapi.io/api/v1`
- **Official documentation:** [Get Map Reviews](https://www.searchapi.io/docs/google-maps-reviews)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `place_id` | query | `string` | yes | Google Maps place ID. |
