- **Method:** `GET`

- **Base URL:** `https://www.searchapi.io/api/v1`
- **Official documentation:** [Search Web](https://www.searchapi.io/docs/google)

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Search query. |
