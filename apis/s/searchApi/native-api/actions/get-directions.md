# Get Directions with SearchApi

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://www.searchapi.io/api/v1`
- **Official documentation:** [Get Directions](https://www.searchapi.io/docs/google-maps-directions-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `from` | query | `string` | yes | Departure location. |
| `to` | query | `string` | yes | Arrival location. |
