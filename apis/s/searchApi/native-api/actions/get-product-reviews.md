# Get Product Reviews with SearchApi

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://www.searchapi.io/api/v1`
- **Official documentation:** [Get Product Reviews](https://www.searchapi.io/docs/google-product-reviews)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_token` | query | `string` | yes | Google Shopping product token. |
