# Search Hotels with SearchApi

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://www.searchapi.io/api/v1`
- **Official documentation:** [Search Hotels](https://www.searchapi.io/docs/google-hotels-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
| `check_in_date` | query | `string` | yes |
| `check_out_date` | query | `string` | yes |
