# Create File with Simpleen Translation

Creates a new file in Simpleen Translation.

## Endpoint

- **Method:** `POST`
- **Path:** `/files`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Create File](https://simpleen.io/documentation/api-reference#file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `dataformat` | body | `string` | yes |
