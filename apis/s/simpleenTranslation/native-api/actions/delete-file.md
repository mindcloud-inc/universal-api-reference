# Delete File with Simpleen Translation

Deletes an existing file from Simpleen Translation.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Delete File](https://simpleen.io/documentation/api-reference#postputdelete-filesid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
