# Delete Segment with Simpleen Translation

Deletes an existing segment from Simpleen Translation.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segments/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Delete Segment](https://simpleen.io/documentation/api-reference#putdelete-segmentsid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
