# Get Segment with Simpleen Translation

Retrieves a segment from Simpleen Translation.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Get Segment](https://simpleen.io/documentation/api-reference#get-segmentsid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the segment to retrieve. |
