# Get Language with Simpleen Translation

Retrieves a language from Simpleen Translation.

## Endpoint

- **Method:** `GET`
- **Path:** `/languages/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Get Language](https://simpleen.io/documentation/api-reference#language)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the language to retrieve. |
