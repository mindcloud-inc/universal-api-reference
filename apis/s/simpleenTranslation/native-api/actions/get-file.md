# Get File with Simpleen Translation

Retrieves a file from Simpleen Translation.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Get File](https://simpleen.io/documentation/api-reference#get-filesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the file to retrieve. |
