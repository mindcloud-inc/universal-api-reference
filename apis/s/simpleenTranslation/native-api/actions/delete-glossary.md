# Delete Glossary with Simpleen Translation

Deletes an existing glossary from Simpleen Translation.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/glossaries/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Delete Glossary](https://simpleen.io/documentation/api-reference#postputdelete-glossariesid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
