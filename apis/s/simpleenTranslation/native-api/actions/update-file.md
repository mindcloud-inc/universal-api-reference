# Update File with Simpleen Translation

Updates an existing file in Simpleen Translation.

## Endpoint

- **Method:** `PUT`
- **Path:** `/files/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Update File](https://simpleen.io/documentation/api-reference#postputdelete-filesid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `name` | body | `string` | yes |
