# Get Glossary with Simpleen Translation

Retrieves a glossary from Simpleen Translation.

## Endpoint

- **Method:** `GET`
- **Path:** `/glossaries/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Get Glossary](https://simpleen.io/documentation/api-reference#get-glossariesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the glossary to retrieve. |
