# Update Glossary with Simpleen Translation

Updates an existing glossary in Simpleen Translation.

## Endpoint

- **Method:** `PUT`
- **Path:** `/glossaries/:id`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Update Glossary](https://simpleen.io/documentation/api-reference#postputdelete-glossariesid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `name` | body | `string` | yes |
