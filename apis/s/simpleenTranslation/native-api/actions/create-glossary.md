# Create Glossary with Simpleen Translation

Creates a new glossary in Simpleen Translation.

## Endpoint

- **Method:** `POST`
- **Path:** `/glossaries`
- **Base URL:** `https://api.simpleen.io`
- **Official documentation:** [Create Glossary](https://simpleen.io/documentation/api-reference#glossary)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
