# Send Promotional Flash SMS with SMSINDIAHUB

Sends a promotional flash SMS in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendorsms/pushsms.aspx`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send Promotional Flash SMS](https://www.smsindiahub.in/assets/pdf/Http-API-Document.pdf)
