# Check Balance with SMSINDIAHUB

Retrieves your SMS credit balance from SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendorsms/CheckBalance.aspx`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Check Balance](https://www.smsindiahub.in/assets/pdf/Http-API-Document.pdf)
