# Send International WAP Push SMS with SMSINDIAHUB

Sends an international WAP Push SMS in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `http://international.smsindiahub.in/bulksms/bulksms`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send International WAP Push SMS](https://www.smsindiahub.in/assets/pdf/Int-API-Doc.pdf)
