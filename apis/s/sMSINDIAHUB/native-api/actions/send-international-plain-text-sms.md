# Send International Plain Text SMS with SMSINDIAHUB

Sends an international plain text SMS in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `http://international.smsindiahub.in/bulksms/bulksms`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send International Plain Text SMS](https://www.smsindiahub.in/assets/pdf/Int-API-Doc.pdf)
