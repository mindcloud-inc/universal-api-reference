# Verify 2FA OTP with SMSINDIAHUB

Retrieves SMS OTP verification results from SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify.php/API/V1/{apiKey}/SMS/VERIFY/{otpTokenId}/{otp}`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Verify 2FA OTP](https://www.smsindiahub.in/free-sms-gateway-developer-api/)
