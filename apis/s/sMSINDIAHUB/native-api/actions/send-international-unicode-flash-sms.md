# Send International Unicode Flash SMS with SMSINDIAHUB

Sends an international Unicode flash SMS in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `http://international.smsindiahub.in/bulksms/bulksms`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send International Unicode Flash SMS](https://www.smsindiahub.in/assets/pdf/Int-API-Doc.pdf)
