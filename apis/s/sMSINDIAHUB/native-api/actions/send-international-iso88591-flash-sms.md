# Send International ISO-8859-1 Flash SMS with SMSINDIAHUB

Sends an international ISO-8859-1 flash SMS in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `http://international.smsindiahub.in/bulksms/bulksms`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send International ISO-8859-1 Flash SMS](https://www.smsindiahub.in/assets/pdf/Int-API-Doc.pdf)
