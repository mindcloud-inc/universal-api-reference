# Send 2FA OTP with SMSINDIAHUB

Sends an auto-generated SMS OTP in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `/api1.php/v1/{apiKey}/sms/{contactNo}/{emailId}`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Send 2FA OTP](https://www.smsindiahub.in/free-sms-gateway-developer-api/)
