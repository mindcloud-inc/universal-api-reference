# Schedule Transactional SMS with SMSINDIAHUB

Schedules a transactional SMS message in SMSINDIAHUB.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendorsms/pushsms.aspx`
- **Base URL:** `https://cloud.smsindiahub.in`
- **Official documentation:** [Schedule Transactional SMS](https://www.smsindiahub.in/assets/pdf/Http-API-Document.pdf)
