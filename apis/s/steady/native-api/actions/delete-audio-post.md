# Delete Audio Post with Steady

Deletes an existing audio post from Steady.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/posts/audio_posts/:post_id`
- **Base URL:** `https://steadyhq.com/api/v1`
- **Official documentation:** [Delete Audio Post](https://developers.steadyhq.com/#deleting-a-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `post_id` | path | `string` | yes | The ID of the audio post to delete. |
