# List Plans for Access Control with Steady

Retrieves plans for post access control in Steady.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/plans_for_access_control`
- **Base URL:** `https://steadyhq.com/api/v1`
- **Official documentation:** [List Plans for Access Control](https://developers.steadyhq.com/#listing-plans-with-access)
