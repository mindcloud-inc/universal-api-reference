# List Group Channel Custom Types with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/group_channels/custom_types`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Group Channel Custom Types](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-application-settings/list-custom-channel-types)
