# Delete Group Channel with Sendbird

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group_channels/:channelUrl`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Delete Group Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/delete-a-group-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
