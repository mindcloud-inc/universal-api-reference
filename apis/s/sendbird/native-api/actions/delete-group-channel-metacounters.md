# Delete Group Channel Metacounters with Sendbird

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group_channels/:channelUrl/metacounter`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Delete Group Channel Metacounters](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-channel-metacounter/delete-channel-metacounters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
