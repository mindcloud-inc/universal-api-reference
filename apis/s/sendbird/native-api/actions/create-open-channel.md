# Create Open Channel with Sendbird

## Endpoint

- **Method:** `POST`
- **Path:** `/open_channels`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Create Open Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/creating-a-channel/create-an-open-channel)
