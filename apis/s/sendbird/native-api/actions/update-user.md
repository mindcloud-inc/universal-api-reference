# Update User with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:userId`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Update User](https://docs.sendbird.com/docs/chat/platform-api/v3/user/managing-users/update-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID. |
