# Create Group Channel with Sendbird

## Endpoint

- **Method:** `POST`
- **Path:** `/group_channels`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Create Group Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/creating-a-channel/create-a-group-channel)
