# List Open Channel Participants with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/open_channels/:channelUrl/participants`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Open Channel Participants](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/listing-participants/list-participants-of-an-open-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The open channel URL. |
