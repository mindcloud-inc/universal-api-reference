# Update Group Channel Custom Type with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/custom_types/:customType`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Update Group Channel Custom Type](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-application-settings/update-channel-settings-for-a-custom-channel-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custom_type` | path | `string` | yes | The group channel custom type. |
