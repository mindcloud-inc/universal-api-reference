# List Group Channel Members with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/group_channels/:channelUrl/members`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Group Channel Members](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-members/list-members-of-a-group-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
