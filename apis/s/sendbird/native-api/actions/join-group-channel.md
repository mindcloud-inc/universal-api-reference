# Join Group Channel with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/join`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Join Group Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/joining-and-leaving-a-channel/join-a-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
