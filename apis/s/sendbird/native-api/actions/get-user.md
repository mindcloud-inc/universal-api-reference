# Get User with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get User](https://docs.sendbird.com/docs/chat/platform-api/v3/user/listing-users/get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID. |
