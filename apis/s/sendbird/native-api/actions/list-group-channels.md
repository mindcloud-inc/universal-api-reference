# List Group Channels with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/group_channels`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Group Channels](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/listing-channels-in-an-application/list-group-channels)
