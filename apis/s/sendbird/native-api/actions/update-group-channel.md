# Update Group Channel with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Update Group Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/update-a-group-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
