# Get Announcement with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/announcements/:uniqueId`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get Announcement](https://docs.sendbird.com/docs/chat/platform-api/v3/message/announcements/announcement-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `unique_id` | path | `string` | yes | The unique ID of the announcement. |
