# Get Poll with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/polls/:pollId`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get Poll](https://docs.sendbird.com/docs/chat/platform-api/v3/message/polls/polls-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `poll_id` | path | `string` | yes | The poll ID. |
