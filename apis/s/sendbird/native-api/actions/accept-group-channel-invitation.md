# Accept Group Channel Invitation with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/accept`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Accept Group Channel Invitation](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-members/accept-an-invitation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
