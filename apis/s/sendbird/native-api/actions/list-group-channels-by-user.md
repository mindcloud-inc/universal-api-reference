# List Group Channels By User with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/my_group_channels`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Group Channels By User](https://docs.sendbird.com/docs/chat/platform-api/v3/user/managing-joined-group-channels/list-group-channels-by-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID. |
