# Reset Group Channel User History with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/reset_user_history`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Reset Group Channel User History](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/reset-chat-history)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
