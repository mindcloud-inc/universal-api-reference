# Decline Group Channel Invitation with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/decline`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Decline Group Channel Invitation](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-members/decline-an-invitation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
