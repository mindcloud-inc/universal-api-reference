# Update Group Channel Metadata with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/metadata`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Update Group Channel Metadata](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-channel-metadata/update-channel-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
