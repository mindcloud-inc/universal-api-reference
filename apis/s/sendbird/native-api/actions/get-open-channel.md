# Get Open Channel with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/open_channels/:channelUrl`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get Open Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/channel-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The open channel URL. |
