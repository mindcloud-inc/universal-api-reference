# Delete Open Channel with Sendbird

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open_channels/:channelUrl`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Delete Open Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/delete-an-open-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The open channel URL. |
