# Create Group Channel Custom Type with Sendbird

## Endpoint

- **Method:** `POST`
- **Path:** `/group_channels/custom_types`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Create Group Channel Custom Type](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-application-settings/create-a-custom-channel-type)
