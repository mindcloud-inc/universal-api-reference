# Hide Group Channel with Sendbird

## Endpoint

- **Method:** `PUT`
- **Path:** `/group_channels/:channelUrl/hide`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Hide Group Channel](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/hide-a-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
