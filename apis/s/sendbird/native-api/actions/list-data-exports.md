# List Data Exports with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/export/:dataType`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [List Data Exports](https://docs.sendbird.com/docs/chat/platform-api/v3/data-export/data-export-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data_type` | path | `string` | yes | The export data type. |
