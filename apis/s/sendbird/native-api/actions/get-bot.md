# Get Bot with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botUserid`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get Bot](https://docs.sendbird.com/docs/chat/platform-api/v3/bot/bot-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_userid` | path | `string` | yes | The bot's user ID. |
