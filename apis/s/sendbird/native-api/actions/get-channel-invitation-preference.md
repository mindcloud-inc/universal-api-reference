# Get Channel Invitation Preference with Sendbird

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/channel_invitation_preference`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Get Channel Invitation Preference](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-a-channel/get-channel-invitation-preference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID. |
