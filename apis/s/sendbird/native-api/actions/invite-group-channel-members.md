# Invite Group Channel Members with Sendbird

## Endpoint

- **Method:** `POST`
- **Path:** `/group_channels/:channelUrl/invite`
- **Base URL:** `https://api-{applicationId}.sendbird.com/v3`
- **Official documentation:** [Invite Group Channel Members](https://docs.sendbird.com/docs/chat/platform-api/v3/channel/managing-members/invite-as-members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_url` | path | `string` | yes | The group channel URL. |
