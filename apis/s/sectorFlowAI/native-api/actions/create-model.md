# Create Model with SectorFlow.AI

## Endpoint

- **Method:** `POST`
- **Path:** `/models`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [Create Model](https://docs.sectorflowai.com/reference/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelRequest` | body | `object` | yes | The model details documented by SectorFlow as ModelRequest. |
