# Update Chat Thread Title with SectorFlow.AI

## Endpoint

- **Method:** `POST`
- **Path:** `/chat/{workspaceId}/history/{threadId}`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [Update Chat Thread Title](https://docs.sectorflowai.com/reference/chat)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `threadId` | path | `string` | no | The chat thread UUID. |
| `workspaceId` | path | `string` | no | The workspace UUID. |
