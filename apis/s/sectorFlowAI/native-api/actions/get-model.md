# Get Model with SectorFlow.AI

## Endpoint

- **Method:** `GET`
- **Path:** `/models/{modelId}`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [Get Model](https://docs.sectorflowai.com/reference/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `string` | yes | The model UUID. |
