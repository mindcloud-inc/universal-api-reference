# Update Workspace with SectorFlow.AI

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces/{workspaceId}`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [Update Workspace](https://docs.sectorflowai.com/reference/getting-started-with-your-api-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Workspace name. |
| `workspaceId` | path | `string` | no | The workspace UUID. |
