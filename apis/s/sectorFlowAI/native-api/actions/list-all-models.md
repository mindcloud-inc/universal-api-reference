# List All Models with SectorFlow.AI

## Endpoint

- **Method:** `GET`
- **Path:** `/models/all`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [List All Models](https://docs.sectorflowai.com/reference/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeSystem` | query | `boolean` | no | Whether to include system models. |
