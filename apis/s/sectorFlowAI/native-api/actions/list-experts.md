# List Experts with SectorFlow.AI

## Endpoint

- **Method:** `GET`
- **Path:** `/plus`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [List Experts](https://docs.sectorflowai.com/reference/sectorplus-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `showPublic` | query | `string` | no | Whether to show public expert entries. Defaults to true. |
