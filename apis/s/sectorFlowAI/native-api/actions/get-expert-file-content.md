# Get Expert File Content with SectorFlow.AI

## Endpoint

- **Method:** `GET`
- **Path:** `/plus/file/{fileId}/content`
- **Base URL:** `https://platform.sectorflow.ai/api/v1`
- **Official documentation:** [Get Expert File Content](https://docs.sectorflowai.com/reference/sectorplus-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The expert file UUID. |
