# Get Project with SynergyCRM

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.synergycrm.ru/api/v1`
- **Official documentation:** [Get Project](https://api.synergycrm.ru/#projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Record ID |
