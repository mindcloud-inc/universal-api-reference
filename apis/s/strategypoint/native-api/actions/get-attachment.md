# Get Attachment with Strategypoint

Retrieves an attachment from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments/{attachmentId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Attachment](https://developer.clearpointstrategy.com/reference/getattachment-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attachmentId` | path | `number` | yes | The unique attachment identifier. |
