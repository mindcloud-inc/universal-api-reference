# Get Group with Strategypoint

Retrieves a group from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{groupId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Group](https://developer.clearpointstrategy.com/reference/getgroup-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | The unique group identifier. |
