# Get Action Item with Strategypoint

Retrieves an action item from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/actionItems/{actionItemId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Action Item](https://developer.clearpointstrategy.com/reference/getactionitem-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actionItemId` | path | `number` | yes | The unique action item identifier. |
