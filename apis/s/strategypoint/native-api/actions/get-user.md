# Get User with Strategypoint

Retrieves a user from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get User](https://developer.clearpointstrategy.com/reference/getuser-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | The unique user identifier. |
