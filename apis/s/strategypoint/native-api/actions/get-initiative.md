# Get Initiative with Strategypoint

Retrieves an initiative from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/initiatives/{initiativeId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Initiative](https://developer.clearpointstrategy.com/reference/getinitiative-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `initiativeId` | path | `number` | yes | The unique initiative identifier. |
