# Get Risk with Strategypoint

Retrieves a risk from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/risks/{riskId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Risk](https://developer.clearpointstrategy.com/reference/getrisk-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `riskId` | path | `number` | yes | The unique risk identifier. |
