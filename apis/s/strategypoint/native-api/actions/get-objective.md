# Get Objective with Strategypoint

Retrieves an objective from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives/{objectiveId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Objective](https://developer.clearpointstrategy.com/reference/getobjective-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `objectiveId` | path | `number` | yes | The unique objective identifier. |
