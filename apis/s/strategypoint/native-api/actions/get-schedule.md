# Get Schedule with Strategypoint

Retrieves a schedule from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/{scheduleId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Schedule](https://developer.clearpointstrategy.com/reference/getschedule-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scheduleId` | path | `number` | yes | The unique schedule identifier. |
