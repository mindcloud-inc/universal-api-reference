# Get Goal with Strategypoint

Retrieves a goal from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/goals/{goalId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Goal](https://developer.clearpointstrategy.com/reference/getgoal-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `goalId` | path | `number` | yes | The unique goal identifier. |
