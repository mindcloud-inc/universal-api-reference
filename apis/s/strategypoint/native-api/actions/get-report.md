# Get Report with Strategypoint

Retrieves a report from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/{reportId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Report](https://developer.clearpointstrategy.com/reference/getreport-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `number` | yes | The unique report identifier. |
