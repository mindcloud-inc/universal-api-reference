# Get Scorecard with Strategypoint

Retrieves a scorecard from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/scorecards/{scorecardId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Scorecard](https://developer.clearpointstrategy.com/reference/getscorecard-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scorecardId` | path | `number` | yes | The unique ClearPoint scorecard identifier. |
