# Get Measure with Strategypoint

Retrieves a measure from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/measures/{measureId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get Measure](https://developer.clearpointstrategy.com/reference/getmeasure-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `measureId` | path | `number` | yes | The unique measure identifier. |
