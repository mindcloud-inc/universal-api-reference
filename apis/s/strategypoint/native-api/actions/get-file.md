# Get File with Strategypoint

Retrieves a file from Strategypoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://app.clearpointstrategy.com/api/v1`
- **Official documentation:** [Get File](https://developer.clearpointstrategy.com/reference/getfile-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `number` | yes | The unique file identifier. |
