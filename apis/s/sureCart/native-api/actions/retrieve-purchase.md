# Retrieve Purchase with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/purchases/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Purchase](https://developer.surecart.com/api-reference/purchases/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The purchase ID to retrieve. |
