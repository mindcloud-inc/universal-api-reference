# Retrieve Price with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/prices/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Price](https://developer.surecart.com/api-reference/prices/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The price ID to retrieve. |
