# List Refunds with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/refunds`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [List Refunds](https://developer.surecart.com/api-reference/refunds/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
