# Delete Product with SureCart

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/products/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Delete Product](https://developer.surecart.com/api-reference/products/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID to delete. |
