# List Purchases with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/purchases`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [List Purchases](https://developer.surecart.com/api-reference/purchases/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
