# Create Product with SureCart

## Endpoint

- **Method:** `POST`
- **Path:** `v1/products`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Create Product](https://developer.surecart.com/api-reference/products/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product.name` | body | `string` | yes | The product display name. |
