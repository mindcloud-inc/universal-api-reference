# Retrieve Order with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/orders/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Order](https://developer.surecart.com/api-reference/orders/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The order ID to retrieve. |
