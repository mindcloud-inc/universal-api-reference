# Delete Price with SureCart

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/prices/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Delete Price](https://developer.surecart.com/api-reference/prices/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The price ID to delete. |
