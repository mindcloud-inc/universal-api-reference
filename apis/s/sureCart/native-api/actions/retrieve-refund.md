# Retrieve Refund with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/refunds/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Refund](https://developer.surecart.com/api-reference/refunds/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The refund ID to retrieve. |
