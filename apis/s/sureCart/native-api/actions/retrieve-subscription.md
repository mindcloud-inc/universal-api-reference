# Retrieve Subscription with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/subscriptions/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Subscription](https://developer.surecart.com/api-reference/subscriptions/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The subscription ID to retrieve. |
