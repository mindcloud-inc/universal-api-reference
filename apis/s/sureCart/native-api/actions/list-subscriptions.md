# List Subscriptions with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/subscriptions`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [List Subscriptions](https://developer.surecart.com/api-reference/subscriptions/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
