# Create Checkout with SureCart

## Endpoint

- **Method:** `POST`
- **Path:** `v1/checkouts`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Create Checkout](https://developer.surecart.com/api-reference/checkouts/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkout.email` | body | `string` | yes | The customer email used for the checkout. |
