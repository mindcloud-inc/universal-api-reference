# Delete Customer with SureCart

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/customers/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Delete Customer](https://developer.surecart.com/api-reference/customers/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The customer ID to delete. |
