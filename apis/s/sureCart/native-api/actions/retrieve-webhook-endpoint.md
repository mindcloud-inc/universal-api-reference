# Retrieve Webhook Endpoint with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/webhook_endpoints/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Webhook Endpoint](https://developer.surecart.com/api-reference/webhook-endpoints/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook endpoint ID to retrieve. |
