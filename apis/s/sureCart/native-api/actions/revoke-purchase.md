# Revoke Purchase with SureCart

## Endpoint

- **Method:** `PATCH`
- **Path:** `v1/purchases/:id/revoke`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Revoke Purchase](https://developer.surecart.com/api-reference/purchases/revoke)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The purchase ID to revoke. |
