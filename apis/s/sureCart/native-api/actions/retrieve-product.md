# Retrieve Product with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/products/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Product](https://developer.surecart.com/api-reference/products/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID or slug to retrieve. |
