# Retrieve Checkout with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/checkouts/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Checkout](https://developer.surecart.com/api-reference/checkouts/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The checkout ID to retrieve. |
