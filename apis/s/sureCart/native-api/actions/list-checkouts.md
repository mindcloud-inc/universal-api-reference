# List Checkouts with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/checkouts`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [List Checkouts](https://developer.surecart.com/api-reference/checkouts/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
