# Retrieve Customer with SureCart

## Endpoint

- **Method:** `GET`
- **Path:** `v1/customers/:id`
- **Base URL:** `https://api.surecart.com`
- **Official documentation:** [Retrieve Customer](https://developer.surecart.com/api-reference/customers/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The customer ID to retrieve. |
