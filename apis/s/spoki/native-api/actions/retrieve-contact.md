# Retrieve Contact with Spoki

Retrieves a contact by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{{id}}/`
- **Base URL:** `https://api.spoki.com/api/1`
- **Official documentation:** [Retrieve Contact](https://documenter.getpostman.com/view/21611004/UzBqnPvF)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact ID. |
