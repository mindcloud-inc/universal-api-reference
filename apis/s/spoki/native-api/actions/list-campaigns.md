# List Campaigns with Spoki

Lists campaigns for the authenticated account, including status and delivery metrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/`
- **Base URL:** `https://api.spoki.com/api/1`
- **Official documentation:** [List Campaigns](https://documenter.getpostman.com/view/21611004/UzBqnPvF)
