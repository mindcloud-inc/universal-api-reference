# List Automations with Spoki

Lists and searches automations for the authenticated account.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/`
- **Base URL:** `https://api.spoki.com/api/1`
- **Official documentation:** [List Automations](https://documenter.getpostman.com/view/21611004/UzBqnPvF)
