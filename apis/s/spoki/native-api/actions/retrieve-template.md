# Retrieve Template with Spoki

Retrieves a template by ID, with optional channel scoping for multi-WABA accounts.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{{id}}/`
- **Base URL:** `https://api.spoki.com/api/1`
- **Official documentation:** [Retrieve Template](https://documenter.getpostman.com/view/21611004/UzBqnPvF)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The template ID. |
