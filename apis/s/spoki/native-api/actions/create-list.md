# Create List with Spoki

Creates a new contact list.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/`
- **Base URL:** `https://api.spoki.com/api/1`
- **Official documentation:** [Create List](https://documenter.getpostman.com/view/21611004/UzBqnPvF)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The list name. |
