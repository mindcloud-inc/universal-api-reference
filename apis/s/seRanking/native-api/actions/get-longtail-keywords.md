# Get longtail keywords with SE Ranking Data

Retrieves longtail keywords from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/keywords/longtail`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get longtail keywords](https://seranking.com/api/data/keyword-research/#longtail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | yes | Keyword phrase (for example: seo tools). |
| `source` | query | `string` | yes | Regional database code (for example: us). |
