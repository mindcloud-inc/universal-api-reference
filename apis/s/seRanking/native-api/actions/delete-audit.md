# Delete audit with SE Ranking Data

Deletes an audit from SE Ranking Data.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/site-audit/audits`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Delete audit](https://seranking.com/api/data/website-audit/#delete-audit)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
