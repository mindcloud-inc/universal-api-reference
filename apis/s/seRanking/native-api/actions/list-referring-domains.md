# List referring domains with SE Ranking Data

Retrieves referring domains from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/refdomains`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [List referring domains](https://seranking.com/api/data/backlinks/#refdomains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
