# Get backlink metrics with SE Ranking Data

Retrieves backlink metrics from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/metrics`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get backlink metrics](https://seranking.com/api/data/backlinks/#metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
