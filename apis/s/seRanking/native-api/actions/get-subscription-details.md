# Get Subscription Details with SE Ranking Data

Retrieves subscription details from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/subscription`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get Subscription Details](https://seranking.com/api/data/get-data/account/subscription.html)
