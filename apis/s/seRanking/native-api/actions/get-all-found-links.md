# Get all found links with SE Ranking Data

Retrieves all found links from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-audit/audits/links`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get all found links](https://seranking.com/api/data/website-audit/#get-all-found-links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
