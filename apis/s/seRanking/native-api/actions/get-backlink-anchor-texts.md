# Get backlink anchor texts with SE Ranking Data

Retrieves backlink anchor texts from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/anchors`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get backlink anchor texts](https://seranking.com/api/data/backlinks/#anchors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
