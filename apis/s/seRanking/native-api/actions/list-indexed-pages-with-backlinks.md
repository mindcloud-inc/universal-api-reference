# List indexed pages with backlinks with SE Ranking Data

Retrieves indexed pages with backlinks from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/indexed-pages`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [List indexed pages with backlinks](https://seranking.com/api/data/backlinks/#indexed-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
