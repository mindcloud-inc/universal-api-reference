# Recheck advanced audit with SE Ranking Data

Rechecks an advanced audit in SE Ranking Data.

## Endpoint

- **Method:** `POST`
- **Path:** `/site-audit/audits/recheck/advanced`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Recheck advanced audit](https://seranking.com/api/data/website-audit/#recheck-audit-advanced)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
