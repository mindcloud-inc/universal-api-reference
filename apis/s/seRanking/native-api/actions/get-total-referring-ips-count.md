# Get total referring IPs count with SE Ranking Data

Retrieves the total referring IPs count from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/referring-ips/count`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get total referring IPs count](https://seranking.com/api/data/backlinks/#referring-ips-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
