# Get domain authority distribution with SE Ranking Data

Retrieves domain authority distribution from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/authority/domain/distribution`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get domain authority distribution](https://seranking.com/api/data/backlinks/#authority-domain-distribution)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
