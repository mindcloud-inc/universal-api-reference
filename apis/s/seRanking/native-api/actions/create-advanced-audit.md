# Create advanced audit with SE Ranking Data

Creates an advanced website audit in SE Ranking Data.

## Endpoint

- **Method:** `POST`
- **Path:** `/site-audit/audits/advanced`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Create advanced audit](https://seranking.com/api/data/website-audit/#create-audit-advanced)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain to audit (for example: seranking.com). |
