# Export backlinks data with SE Ranking Data

Exports backlink data from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/export`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Export backlinks data](https://seranking.com/api/data/backlinks/#export)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
