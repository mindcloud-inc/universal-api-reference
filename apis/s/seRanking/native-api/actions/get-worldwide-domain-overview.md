# Get Worldwide Domain Overview with SE Ranking Data

Retrieves a worldwide domain overview from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain/overview/worldwide`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get Worldwide Domain Overview](https://seranking.com/api/data/domain-analysis/#worldwide-aggregate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain to analyze worldwide (for example: seranking.com). |
