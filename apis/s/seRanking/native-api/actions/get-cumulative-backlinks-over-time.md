# Get cumulative backlinks over time with SE Ranking Data

Retrieves cumulative backlinks over time from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/history/cumulative`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get cumulative backlinks over time](https://seranking.com/api/data/backlinks/#history-cumulative)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
