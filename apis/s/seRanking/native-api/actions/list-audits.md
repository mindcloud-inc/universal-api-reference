# List audits with SE Ranking Data

Retrieves a list of audits from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-audit/audits`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [List audits](https://seranking.com/api/data/website-audit/#list-audits)
