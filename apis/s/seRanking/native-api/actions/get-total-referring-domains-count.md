# Get total referring domains count with SE Ranking Data

Retrieves the total referring domains count from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/refdomains/count`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get total referring domains count](https://seranking.com/api/data/backlinks/#refdomains-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
