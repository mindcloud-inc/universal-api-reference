# Get audit status with SE Ranking Data

Retrieves audit status from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-audit/audits/status`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get audit status](https://seranking.com/api/data/website-audit/#get-audit-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
