# Get all crawled pages with SE Ranking Data

Retrieves all crawled pages from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-audit/audits/pages`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get all crawled pages](https://seranking.com/api/data/website-audit/#get-all-crawled-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
