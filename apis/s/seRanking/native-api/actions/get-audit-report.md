# Get audit report with SE Ranking Data

Retrieves an audit report from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/site-audit/audits/report`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get audit report](https://seranking.com/api/data/website-audit/#get-audit-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audit_id` | query | `list<string>` | yes | Audit identifier. |
