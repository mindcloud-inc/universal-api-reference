# Get total backlinks count with SE Ranking Data

Retrieves the total backlinks count from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/count`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get total backlinks count](https://seranking.com/api/data/backlinks/#count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
