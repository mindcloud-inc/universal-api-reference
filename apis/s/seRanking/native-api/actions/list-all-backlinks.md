# List all backlinks with SE Ranking Data

Retrieves all backlinks from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/all`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [List all backlinks](https://seranking.com/api/data/backlinks/#all)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
