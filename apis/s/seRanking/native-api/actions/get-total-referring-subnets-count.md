# Get total referring subnets count with SE Ranking Data

Retrieves the total referring subnets count from SE Ranking Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/backlinks/referring-subnets/count`
- **Base URL:** `https://api.seranking.com/v1`
- **Official documentation:** [Get total referring subnets count](https://seranking.com/api/data/backlinks/#referring-subnets-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target` | query | `string` | yes | Target domain or URL to analyze (for example: seranking.com). |
