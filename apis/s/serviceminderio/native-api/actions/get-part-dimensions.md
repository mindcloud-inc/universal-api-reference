# Get Part Dimensions with serviceminder.io

Retrieves part dimensions from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/part/getpartdimensions`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Part Dimensions](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PartId` | body | `number` | yes | Part identifier. |
