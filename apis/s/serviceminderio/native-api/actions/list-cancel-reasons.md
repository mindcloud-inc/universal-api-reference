# List Cancel Reasons with serviceminder.io

Retrieves cancel reasons from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/cancelreasons/all`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [List Cancel Reasons](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IncludeInactive` | body | `string` | no | Whether to include inactive cancel reasons. |
