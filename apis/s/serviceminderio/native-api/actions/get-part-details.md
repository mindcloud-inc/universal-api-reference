# Get Part Details with serviceminder.io

Retrieves part details from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/part/details`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Part Details](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Part identifier. |
