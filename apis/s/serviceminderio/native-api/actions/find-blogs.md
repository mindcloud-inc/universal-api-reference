# Find Blogs with serviceminder.io

Finds blogs in ServiceMinder by search term.

## Endpoint

- **Method:** `POST`
- **Path:** `/blogs/find`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Find Blogs](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Search` | body | `string` | no | Blog search text. |
