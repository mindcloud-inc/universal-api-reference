# Get Proposal Details with serviceminder.io

Retrieves proposal details from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/proposal/details`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Proposal Details](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Proposal identifier. |
