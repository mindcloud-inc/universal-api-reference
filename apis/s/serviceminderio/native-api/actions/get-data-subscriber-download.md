# Get Data Subscriber Download with serviceminder.io

Retrieves a data subscriber download from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/datasubscriber/getdownload`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Data Subscriber Download](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `DownloadId` | body | `number` | yes | Data subscriber download identifier. |
