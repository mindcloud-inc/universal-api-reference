# Get Organization Details with serviceminder.io

Retrieves organization details from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/details`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Organization Details](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `OrganizationId` | body | `number` | yes | Organization identifier. |
