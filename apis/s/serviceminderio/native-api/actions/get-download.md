# Get Download with serviceminder.io

Retrieves a download from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/download/getdownload`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Download](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `DownloadId` | body | `number` | yes | Download identifier. |
