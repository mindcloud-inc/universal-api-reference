# Get Blog with serviceminder.io

Retrieves a blog from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/blogs/get`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [Get Blog](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Blog identifier. |
