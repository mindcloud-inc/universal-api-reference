# List Services with serviceminder.io

Retrieves services from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/services/all`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [List Services](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IncludeInactive` | body | `boolean` | no | Whether to include inactive services. |
