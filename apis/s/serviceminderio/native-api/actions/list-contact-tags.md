# List Contact Tags with serviceminder.io

Retrieves tags for a contact from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/listtags`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [List Contact Tags](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ContactId` | body | `number` | yes | Contact identifier. |
