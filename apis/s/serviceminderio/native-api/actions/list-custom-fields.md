# List Custom Fields with serviceminder.io

Retrieves custom fields from ServiceMinder.

## Endpoint

- **Method:** `POST`
- **Path:** `/customfields/all`
- **Base URL:** `https://serviceminder.com/api`
- **Official documentation:** [List Custom Fields](https://serviceminder.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IncludeInactive` | body | `boolean` | no | Whether to include inactive custom fields. |
