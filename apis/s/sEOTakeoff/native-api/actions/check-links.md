# Check Links with SEOTakeoff

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tools/check-links`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [Check Links](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urls[]` | body | `array<string>` | yes | List of URLs to check. |
