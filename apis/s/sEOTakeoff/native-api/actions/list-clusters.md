# List Clusters with SEOTakeoff

## Endpoint

- **Method:** `GET`
- **Path:** `/api/zapier/clusters`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [List Clusters](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `since` | query | `date` | no | Only return clusters created after this ISO timestamp. |
