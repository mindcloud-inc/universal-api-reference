# Search Websites with SEOTakeoff

- **Method:** `GET`
- **Path:** `/api/zapier/websites/search`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [Search Websites](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Website search text. |
