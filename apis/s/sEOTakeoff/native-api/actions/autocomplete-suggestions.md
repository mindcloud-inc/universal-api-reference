# Autocomplete Suggestions with SEOTakeoff

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tools/autocomplete`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [Autocomplete Suggestions](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Suggestion query text. |
