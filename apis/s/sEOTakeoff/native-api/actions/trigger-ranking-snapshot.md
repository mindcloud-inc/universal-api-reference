# Trigger Ranking Snapshot with SEOTakeoff

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/rankings/snapshot`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [Trigger Ranking Snapshot](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tenant_id` | query | `string` | yes | Tenant slug to snapshot. |
