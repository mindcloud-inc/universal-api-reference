# Search Articles with SEOTakeoff

## Endpoint

- **Method:** `GET`
- **Path:** `/api/zapier/articles/search`
- **Base URL:** `https://api.seotakeoff.com`
- **Official documentation:** [Search Articles](https://api.seotakeoff.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Article title or keyword search text. |
