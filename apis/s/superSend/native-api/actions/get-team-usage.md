# Get Team Usage with SuperSend

Retrieves team usage from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{id}/usage`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Team Usage](https://docs.supersend.io/docs/team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
