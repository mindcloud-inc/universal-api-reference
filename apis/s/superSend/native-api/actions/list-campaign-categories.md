# List Campaign Categories with SuperSend

Retrieves campaign categories from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign-categories`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [List Campaign Categories](https://docs.supersend.io/docs/campaign-category)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | query | `string` | yes |
