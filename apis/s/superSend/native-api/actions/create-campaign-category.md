# Create Campaign Category with SuperSend

Creates a new campaign category in SuperSend.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign-categories`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Create Campaign Category](https://docs.supersend.io/docs/campaign-category)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `TeamId` | body | `string` | yes |
| `name` | body | `string` | yes |
