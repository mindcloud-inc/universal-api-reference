# Get Campaign with SuperSend

Retrieves a campaign from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Campaign](https://docs.supersend.io/docs/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
