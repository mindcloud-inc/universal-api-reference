# Get Domain Health Summary with SuperSend

Retrieves the domain health summary from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/intelligence/domain-health-summary`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Domain Health Summary](https://api.supersend.io/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `string` | yes | Team UUID (from list teams) |
