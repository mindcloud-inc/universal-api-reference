# Delete Campaign Category with SuperSend

Deletes an existing campaign category from SuperSend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaign-categories/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Delete Campaign Category](https://docs.supersend.io/docs/campaign-category)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `teamId` | query | `string` | yes |
