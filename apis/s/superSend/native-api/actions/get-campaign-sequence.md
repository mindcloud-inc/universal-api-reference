# Get Campaign Sequence with SuperSend

Retrieves a campaign sequence from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{id}/sequence`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Campaign Sequence](https://docs.supersend.io/docs/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
