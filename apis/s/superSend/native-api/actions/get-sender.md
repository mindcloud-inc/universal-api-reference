# Get Sender with SuperSend

Retrieves a sender from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/senders/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Sender](https://docs.supersend.io/docs/sender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
