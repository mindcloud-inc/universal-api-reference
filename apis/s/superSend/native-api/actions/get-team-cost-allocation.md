# Get Team Cost Allocation with SuperSend

Retrieves team cost allocation from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/team-usage`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Team Cost Allocation](https://docs.supersend.io/docs/v2-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `period` | query | `number` | no | Default: 0. Range: 0 to 6. |
