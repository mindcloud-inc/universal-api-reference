# Get Team with SuperSend

Retrieves a team from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Team](https://docs.supersend.io/docs/team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
