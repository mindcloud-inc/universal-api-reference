# Get Placement Test with SuperSend

Retrieves a placement test from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/placement-tests/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Placement Test](https://docs.supersend.io/docs/placement-test)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
