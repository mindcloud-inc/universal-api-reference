# Get Event with SuperSend

Retrieves an event from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Event](https://docs.supersend.io/docs/event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
