# Get Contact with SuperSend

Retrieves a contact from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Contact](https://docs.supersend.io/docs/contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID (UUID) |
