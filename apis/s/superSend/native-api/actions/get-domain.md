# Get Domain with SuperSend

Retrieves a domain from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Domain](https://docs.supersend.io/docs/managed-domain)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
