# Get Conversation with SuperSend

Retrieves a conversation from SuperSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/{id}`
- **Base URL:** `https://api.supersend.io/v2`
- **Official documentation:** [Get Conversation](https://docs.supersend.io/docs/conversation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
