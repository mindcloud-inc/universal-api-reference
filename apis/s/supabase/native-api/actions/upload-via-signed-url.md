# Upload Via Signed URL with Supabase

Uploads an object to Supabase using a signed URL.

## Endpoint

- **Method:** `PUT`
- **Path:** `/storage/v1/object/upload/sign/:bucketName/:objectPath`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Upload Via Signed URL](https://supabase.com/docs/reference/javascript/storage-from-uploadtosignedurl)
