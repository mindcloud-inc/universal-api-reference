# Get Object Info with Supabase

Retrieves object details from a Supabase storage bucket.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/v1/object/info/:bucketName/:objectPath`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Get Object Info](https://supabase.com/docs/reference/javascript/storage-from-info)
