# Create Signed Upload URL with Supabase

Creates a signed upload URL for a Supabase object.

## Endpoint

- **Method:** `POST`
- **Path:** `/storage/v1/object/upload/sign/:bucketName/:objectPath`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Create Signed Upload URL](https://supabase.com/docs/reference/javascript/storage-from-createsigneduploadurl)
