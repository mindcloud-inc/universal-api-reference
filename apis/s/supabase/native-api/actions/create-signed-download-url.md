# Create Signed Download URL with Supabase

Creates a signed download URL for a Supabase object.

## Endpoint

- **Method:** `POST`
- **Path:** `/storage/v1/object/sign/:bucketName/:objectPath`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Create Signed Download URL](https://supabase.com/docs/reference/javascript/storage-from-createsignedurl)
