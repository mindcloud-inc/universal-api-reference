# List User MFA Factors with Supabase

Retrieves a user's MFA factors from Supabase Auth.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/v1/admin/users/:userId/factors`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [List User MFA Factors](https://supabase.com/docs/reference/javascript/auth-admin-mfa-listfactors-admin)
