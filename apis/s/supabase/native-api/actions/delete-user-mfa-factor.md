# Delete User MFA Factor with Supabase

Deletes a user's MFA factor from Supabase Auth.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/auth/v1/admin/users/:userId/factors/:factorId`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Delete User MFA Factor](https://supabase.com/docs/reference/javascript/auth-admin-mfa-deletefactor)
