# Create Signed Download URLs with Supabase

Creates signed download URLs for Supabase objects.

## Endpoint

- **Method:** `POST`
- **Path:** `/storage/v1/object/sign/:bucketName`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Create Signed Download URLs](https://supabase.com/docs/reference/javascript/storage-from-createsignedurls)
