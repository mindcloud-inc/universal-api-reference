# Get Public Object with Supabase

Retrieves the public URL for a Supabase object.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage/v1/object/public/:bucketName/:objectPath`
- **Base URL:** `{projectUrl}`
- **Official documentation:** [Get Public Object](https://supabase.com/docs/reference/javascript/storage-from-getpublicurl)
