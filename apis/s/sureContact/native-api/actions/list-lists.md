# List Lists with SureContact

Retrieves available contact lists from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/lists`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [List Lists](https://api.surecontact.com/docs#list-management-GETapi-v1-public-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `archived` | query | `string` | no | Filter by archive status: false, true, or all. |
