# Get Reports Overview with SureContact

Retrieves high-level reporting metrics from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/reports/overview`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Get Reports Overview](https://api.surecontact.com/docs#reports-GETapi-v1-public-reports-overview)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `compare_end_date` | body | `string` | no |
| `compare_start_date` | body | `string` | no |
| `compare_with` | body | `string` | no |
| `date_range` | body | `string` | no |
| `end_date` | body | `string` | no |
| `group_by` | body | `string` | no |
| `start_date` | body | `string` | no |
