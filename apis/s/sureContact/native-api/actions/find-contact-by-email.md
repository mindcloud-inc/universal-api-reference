# Find Contact by Email with SureContact

Finds a contact in SureContact by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/contacts/email/:email`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Find Contact by Email](https://api.surecontact.com/docs#contact-management-GETapi-v1-public-contacts-email--email-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email address to search for. |
