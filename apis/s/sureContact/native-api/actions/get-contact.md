# Get Contact with SureContact

Retrieves a specific contact from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/contacts/:contact_uuid`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Get Contact](https://api.surecontact.com/docs#contact-management-GETapi-v1-public-contacts--contact_uuid-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_uuid` | path | `string` | yes | The UUID of the contact. |
