# Get List with SureContact

Retrieves a specific list from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/lists/:list_uuid`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Get List](https://api.surecontact.com/docs#list-management-GETapi-v1-public-lists--list_uuid-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_uuid` | path | `string` | yes | The UUID of the list. |
