# List Campaigns with SureContact

Retrieves campaign records from your SureContact account.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/campaigns`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [List Campaigns](https://api.surecontact.com/docs#endpoints-GETapi-v1-public-campaigns)
