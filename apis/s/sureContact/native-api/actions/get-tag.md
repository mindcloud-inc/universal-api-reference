# Get Tag with SureContact

Retrieves a specific tag from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/tags/:tag_uuid`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Get Tag](https://api.surecontact.com/docs#tag-management-GETapi-v1-public-tags--tag_uuid-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tag_uuid` | path | `string` | yes |
