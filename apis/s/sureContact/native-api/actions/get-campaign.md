# Get Campaign with SureContact

Retrieves a specific campaign from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/campaigns/:campaign_uuid`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [Get Campaign](https://api.surecontact.com/docs#endpoints-GETapi-v1-public-campaigns--campaign_uuid-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_uuid` | path | `string` | yes |
