# List Contacts with SureContact

Retrieves saved contact records from SureContact.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v1/public/contacts`
- **Base URL:** `https://api.surecontact.com`
- **Official documentation:** [List Contacts](https://api.surecontact.com/docs#contact-management-GETapi-v1-public-contacts)
