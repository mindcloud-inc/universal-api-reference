# Get Account with ShareFile

## Endpoint

- **Method:** `GET`
- **Path:** `/Accounts({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Get Account](https://api.sharefile.com/html/docs/Accounts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile account identifier. |
