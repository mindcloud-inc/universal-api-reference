# Create Group with ShareFile

## Endpoint

- **Method:** `POST`
- **Path:** `/Groups`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Create Group](https://api.sharefile.com/html/docs/Groups.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Group` | body | `object` | yes | The ShareFile group object to create. |
