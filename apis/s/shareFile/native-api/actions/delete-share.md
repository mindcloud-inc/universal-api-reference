# Delete Share with ShareFile

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Shares({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Delete Share](https://api.sharefile.com/html/docs/Shares.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile share identifier to delete. |
