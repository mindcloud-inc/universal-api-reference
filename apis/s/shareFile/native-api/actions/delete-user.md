# Delete User with ShareFile

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Users({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Delete User](https://api.sharefile.com/html/docs/Users.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile user identifier to delete. |
