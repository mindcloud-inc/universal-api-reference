# Get User with ShareFile

## Endpoint

- **Method:** `GET`
- **Path:** `/Users({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Get User](https://api.sharefile.com/html/docs/Users.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile user identifier. |
