# Delete Item with ShareFile

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Items({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Delete Item](https://api.sharefile.com/html/docs/Items.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile item identifier to delete. |
