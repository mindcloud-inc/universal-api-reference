# Get Zone with ShareFile

## Endpoint

- **Method:** `GET`
- **Path:** `/Zones({{id}})`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Get Zone](https://api.sharefile.com/html/docs/Zones.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ShareFile zone identifier. |
