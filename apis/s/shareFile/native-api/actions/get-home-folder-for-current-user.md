# Get Home Folder for Current User with ShareFile

## Endpoint

- **Method:** `GET`
- **Path:** `/Items`
- **Base URL:** `https://{subdomain}.{apicp}/sf/v3`
- **Official documentation:** [Get Home Folder for Current User](https://api.sharefile.com/html/docs/Items.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
