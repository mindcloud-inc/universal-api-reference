# Get Services by Tags with Skyfire

Retrieves Skyfire services by tags.

## Endpoint

- **Method:** `GET`
- **Path:** `/directory/services/search`
- **Base URL:** `https://api.skyfire.xyz/api/v1`
- **Official documentation:** [Get Services by Tags](https://docs.skyfire.xyz/reference/get-services-by-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `commaDelimitedTags` | query | `string` | yes | Comma delimited list of tags. |
