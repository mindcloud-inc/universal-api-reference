# Get Agent Wallet Balance with Skyfire

Retrieves an agent wallet balance from Skyfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/balance`
- **Base URL:** `https://api.skyfire.xyz/api/v1`
- **Official documentation:** [Get Agent Wallet Balance](https://docs.skyfire.xyz/reference/get-agents-wallet-balance)
