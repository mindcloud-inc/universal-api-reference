# Get Service with Skyfire

Retrieves a service from Skyfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/directory/services/:serviceId`
- **Base URL:** `https://api.skyfire.xyz/api/v1`
- **Official documentation:** [Get Service](https://docs.skyfire.xyz/reference/get-service)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceId` | path | `string` | yes | ID of the service to get. |
