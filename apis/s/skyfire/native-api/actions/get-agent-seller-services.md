# Get Agent Seller Services with Skyfire

Retrieves an agent's seller services from Skyfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/seller-services`
- **Base URL:** `https://api.skyfire.xyz/api/v1`
- **Official documentation:** [Get Agent Seller Services](https://docs.skyfire.xyz/reference/get-agents-seller-services-all)
