# List Planeswalker Types with Scryfall

Retrieves the planeswalker type catalog from Scryfall.

## Endpoint

- **Method:** `GET`
- **Path:** `catalog/planeswalker-types`
- **Base URL:** `https://api.scryfall.com/`
- **Official documentation:** [List Planeswalker Types](https://scryfall.com/docs/api/catalogs)
