# List Enchantment Types with Scryfall

Retrieves the enchantment type catalog from Scryfall.

## Endpoint

- **Method:** `GET`
- **Path:** `catalog/enchantment-types`
- **Base URL:** `https://api.scryfall.com/`
- **Official documentation:** [List Enchantment Types](https://scryfall.com/docs/api/catalogs)
