# Get Card By Multiverse ID with Scryfall

Retrieves a card from Scryfall by Multiverse ID.

## Endpoint

- **Method:** `GET`
- **Path:** `cards/multiverse/:id`
- **Base URL:** `https://api.scryfall.com/`
- **Official documentation:** [Get Card By Multiverse ID](https://scryfall.com/docs/api/cards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Wizards of the Coast Multiverse ID. |
