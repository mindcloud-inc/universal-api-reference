# Get Card By Scryfall ID with Scryfall

Retrieves a card from Scryfall by Scryfall ID.

## Endpoint

- **Method:** `GET`
- **Path:** `cards/:id`
- **Base URL:** `https://api.scryfall.com/`
- **Official documentation:** [Get Card By Scryfall ID](https://scryfall.com/docs/api/cards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Scryfall card UUID. |
