# Get Vehicle with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/vehicles/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Vehicle](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric vehicle identifier. |
