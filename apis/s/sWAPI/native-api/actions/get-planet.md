# Get Planet with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/planets/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Planet](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric planet identifier. |
