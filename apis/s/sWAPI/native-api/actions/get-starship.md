# Get Starship with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/starships/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Starship](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric starship identifier. |
