# List Vehicles with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/vehicles/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [List Vehicles](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search vehicles by name. |
