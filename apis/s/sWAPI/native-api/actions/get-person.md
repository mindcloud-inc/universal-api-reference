# Get Person with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Person](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric person identifier. |
