# List Starships with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/starships/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [List Starships](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search starships by name. |
