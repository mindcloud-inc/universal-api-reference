# Get Film with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/films/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Film](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric film identifier. |
