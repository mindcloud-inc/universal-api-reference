# Get Species with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/species/:id/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [Get Species](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric species identifier. |
