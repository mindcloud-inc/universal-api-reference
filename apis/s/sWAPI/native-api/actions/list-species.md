# List Species with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/species/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [List Species](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search species by name. |
