# List Films with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/films/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [List Films](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search films by title. |
