# List Planets with SWAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/planets/`
- **Base URL:** `https://swapi.dev/api`
- **Official documentation:** [List Planets](https://swapi.dev/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search planets by name. |
