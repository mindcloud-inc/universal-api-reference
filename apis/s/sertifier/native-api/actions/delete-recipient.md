# Delete Recipient with Sertifier

Deletes an existing recipient from Sertifier.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/recipient/:recipient_id`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Delete Recipient](https://sertifier.docs.apiary.io/reference/recipient/delete-recipient)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recipient_id` | path | `string` | yes |
