# Get Campaign with Sertifier

Retrieves a campaign from a Sertifier workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:campaign_id`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Get Campaign](https://sertifier.docs.apiary.io/reference/campaign/get-update-delete-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes |
