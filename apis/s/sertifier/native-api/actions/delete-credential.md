# Delete Credential with Sertifier

Deletes an existing credential from Sertifier.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/credential/:credential_id`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Delete Credential](https://sertifier.docs.apiary.io/reference/credential/get-update-delete-credential)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `credential_id` | path | `string` | yes |
