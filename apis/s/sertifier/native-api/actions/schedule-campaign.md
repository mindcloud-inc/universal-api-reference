# Schedule Campaign with Sertifier

Schedules an existing campaign in Sertifier.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign/schedule`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Schedule Campaign](https://sertifier.docs.apiary.io/reference/campaign/schedule)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
| `publishDate` | body | `string` | yes |
