# Get Credential with Sertifier

Retrieves a credential from a Sertifier workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/credential/:credential_id`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Get Credential](https://sertifier.docs.apiary.io/reference/credential/get-update-delete-credential)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `credential_id` | path | `string` | yes |
