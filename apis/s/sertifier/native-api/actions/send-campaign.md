# Send Campaign with Sertifier

Sends an existing campaign in Sertifier.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign/send`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Send Campaign](https://sertifier.docs.apiary.io/reference/campaign/send)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
