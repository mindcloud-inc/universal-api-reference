# Delete Campaign with Sertifier

Deletes an existing campaign from Sertifier.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaign/:campaign_id`
- **Base URL:** `https://b2b.sertifier.com`
- **Official documentation:** [Delete Campaign](https://sertifier.docs.apiary.io/reference/campaign/get-update-delete-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes |
