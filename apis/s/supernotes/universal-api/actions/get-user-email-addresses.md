# Supernotes: Get User Email Addresses

Retrieves your email addresses from Supernotes.

```
GET https://connect.mindcloud.co/v1/universal/supernotes/latest/actions/get-user-email-addresses
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Supernotes `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/supernotes/latest/actions/get-user-email-addresses?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/supernotes/latest/actions/get-user-email-addresses?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```



## Response

```json
{
  "success": true,
  "data": [
    {
      "email": "ava@example.com",
      "id": "string",
      "primary": true,
      "verifiedWhen": "2026-05-07T12:00:00.000Z"
    }

  "meta": {}
}
```

## Native endpoint

Through the native Supernotes API, this operation is `GET /user/emails` (base URL `https://api.supernotes.app/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-user-email-addresses.md) for the provider-specific parameters and requirements.
