# Get Other User Profile with Supernotes

Retrieves another user profile from Supernotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/:user_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Other User Profile](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
