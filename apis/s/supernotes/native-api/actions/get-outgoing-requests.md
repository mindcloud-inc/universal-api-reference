# Get Outgoing Requests with Supernotes

Retrieves outgoing friend requests from Supernotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/friends/outgoing`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Outgoing Requests](https://developer.supernotes.app/api-reference/introduction)
