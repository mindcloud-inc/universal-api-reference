# Check If Fresh Access Token with Supernotes

Checks whether your Supernotes access token is fresh.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/token/fresh`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Check If Fresh Access Token](https://developer.supernotes.app/api-reference/introduction)
