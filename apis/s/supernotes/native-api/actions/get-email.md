# Get Email with Supernotes

Retrieves an email address from Supernotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/emails/:email_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Email](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email_id` | path | `string` | yes |
