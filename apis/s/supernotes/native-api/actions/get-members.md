# Get Members with Supernotes

Retrieves members for a Supernotes card.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:card_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Members](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `card_id` | path | `string` | yes |
