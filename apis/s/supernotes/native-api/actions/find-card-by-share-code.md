# Find Card By Share Code with Supernotes

Retrieves a Supernotes card by share code.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharing/code/:code`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Find Card By Share Code](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `code` | path | `string` | yes |
