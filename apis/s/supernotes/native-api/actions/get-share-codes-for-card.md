# Get Share Codes For Card with Supernotes

Retrieves share codes for a Supernotes card.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharing/:card_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Share Codes For Card](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `card_id` | path | `string` | yes |
