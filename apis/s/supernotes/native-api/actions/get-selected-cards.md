# Get Selected Cards with Supernotes

Retrieves selected Supernotes cards using filters and ordering criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/cards/get/select`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Selected Cards](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | body | `number` | no |
