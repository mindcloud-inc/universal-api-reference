# Get Collection with Supernotes

Retrieves a specific collection from Supernotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collection_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Collection](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `collection_id` | path | `string` | yes |
