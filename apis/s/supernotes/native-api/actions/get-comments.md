# Get Comments with Supernotes

Retrieves comments for a Supernotes card.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/:card_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Comments](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `card_id` | path | `string` | yes |
