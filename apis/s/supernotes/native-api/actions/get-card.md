# Get Card with Supernotes

Retrieves a specific card from Supernotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:card_id`
- **Base URL:** `https://api.supernotes.app/v1`
- **Official documentation:** [Get Card](https://developer.supernotes.app/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `card_id` | path | `string` | yes |
