# Retrieve Subscriber with SimpleCirc

Retrieves details for a subscriber from SimpleCirc.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.2/subscribers/:account_id`
- **Base URL:** `https://simplecirc.com`
- **Official documentation:** [Retrieve Subscriber](https://simplecirc.com/docs/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | yes |
