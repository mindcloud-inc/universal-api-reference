# Get Report Info with SeekTable

Retrieves a SeekTable report by report ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/report/:report_id`
- **Base URL:** `https://www.seektable.com`
- **Official documentation:** [Get Report Info](https://www.seektable.com/help/web-api-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `report_id` | path | `string` | yes | GUID of the report saved in your SeekTable account. |
