# Get Cube Info with SeekTable

Retrieves a SeekTable cube by cube ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/cube/:cube_id`
- **Base URL:** `https://www.seektable.com`
- **Official documentation:** [Get Cube Info](https://www.seektable.com/help/web-api-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cube_id` | path | `string` | yes | GUID of the cube in your SeekTable account. |
