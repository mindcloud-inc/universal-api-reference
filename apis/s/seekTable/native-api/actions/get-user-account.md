# Get User Account with SeekTable

Retrieves a SeekTable user account by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/account/:id`
- **Base URL:** `https://www.seektable.com`
- **Official documentation:** [Get User Account](https://www.seektable.com/help/self-hosted-admin-accounts-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the user account to retrieve. |
