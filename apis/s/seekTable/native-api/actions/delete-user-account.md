# Delete User Account with SeekTable

Deletes an existing user account from SeekTable.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/account/:id`
- **Base URL:** `https://www.seektable.com`
- **Official documentation:** [Delete User Account](https://www.seektable.com/help/self-hosted-admin-accounts-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the user account to delete. |
