# Get Capability with Strale

Retrieves a capability from Strale.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/capabilities/:slug`
- **Base URL:** `https://api.strale.io`
- **Official documentation:** [Get Capability](https://strale.dev/docs#api-capabilities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Capability slug. |
