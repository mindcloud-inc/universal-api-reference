# List Solutions with Strale

Retrieves solutions from Strale.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/solutions`
- **Base URL:** `https://api.strale.io`
- **Official documentation:** [List Solutions](https://strale.dev/docs#api-solutions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Filter by solution category slug. |
