# Get Transaction with Strale

Retrieves a transaction from Strale.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactions/:id`
- **Base URL:** `https://api.strale.io`
- **Official documentation:** [Get Transaction](https://api.strale.io/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Transaction ID. |
