# Get Solution with Strale

Retrieves a solution from Strale.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/solutions/:slug`
- **Base URL:** `https://api.strale.io`
- **Official documentation:** [Get Solution](https://strale.dev/docs#api-solutions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Solution slug. |
