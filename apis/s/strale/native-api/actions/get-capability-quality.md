# Get Capability Quality with Strale

Retrieves a capability quality score from Strale.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/quality/:slug`
- **Base URL:** `https://api.strale.io`
- **Official documentation:** [Get Capability Quality](https://strale.dev/docs#api-quality)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Capability slug. |
