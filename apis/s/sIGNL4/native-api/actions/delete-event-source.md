# Delete Event Source with SIGNL4

Deletes an event source from SIGNL4.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/eventsources/{eventSourceId}`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Delete Event Source](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventSourceId` | path | `string` | yes | ID of event source |
