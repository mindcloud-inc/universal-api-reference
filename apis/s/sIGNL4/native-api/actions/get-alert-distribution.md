# Get Alert Distribution with SIGNL4

Retrieves alert distribution details from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/alerts/{alertId}/distribution`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Alert Distribution](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `string` | yes | Alert you want to get the infos from |
