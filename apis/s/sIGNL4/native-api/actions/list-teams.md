# List Teams with SIGNL4

Retrieves teams from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [List Teams](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId[]` | query | `array<string>` | no |
