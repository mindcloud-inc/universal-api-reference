# Get Alert Parameters with SIGNL4

Retrieves alert parameters from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/alerts/{alertId}/parameters`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Alert Parameters](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `string` | yes | Id of the requested Alert. |
