# Get Team Setup Progress with SIGNL4

Retrieves team setup progress from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/{teamId}/setupProgress`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Team Setup Progress](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | SIGNL4 team ID. |
