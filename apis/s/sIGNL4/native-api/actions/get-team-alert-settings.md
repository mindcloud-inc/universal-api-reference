# Get Team Alert Settings with SIGNL4

Retrieves alert settings for a team from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/{teamId}/alertSettings`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Team Alert Settings](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | SIGNL4 team ID. |
