# List Subscription Teams with SIGNL4

Retrieves teams for a subscription from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/subscriptions/{subscriptionId}/teams`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [List Subscription Teams](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | SIGNL4 subscription ID. |
