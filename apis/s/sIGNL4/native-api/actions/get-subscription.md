# Get Subscription with SIGNL4

Retrieves a subscription from SIGNL4 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/subscriptions/{subscriptionId}`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Subscription](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | SIGNL4 subscription ID. |
