# List Team Memberships with SIGNL4

Retrieves team memberships from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/{teamId}/memberships`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [List Team Memberships](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team ID of team you want to access. |
