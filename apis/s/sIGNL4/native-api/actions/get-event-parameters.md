# Get Event Parameters with SIGNL4

Retrieves event parameters from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/events/{eventId}/parameters`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Event Parameters](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Event Id of the requested Alert. |
