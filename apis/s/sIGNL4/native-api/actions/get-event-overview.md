# Get Event Overview with SIGNL4

Retrieves an event overview from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/events/{eventId}/overview`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Event Overview](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Id of event to get. |
