# Get Team with SIGNL4

Retrieves a team from SIGNL4 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/{teamId}`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [Get Team](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | ID of the team that should be retrieved. |
