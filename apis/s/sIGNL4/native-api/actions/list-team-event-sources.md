# List Team Event Sources with SIGNL4

Retrieves event sources for a team from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/teams/{teamId}/eventSources`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [List Team Event Sources](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | SIGNL4 team ID. |
