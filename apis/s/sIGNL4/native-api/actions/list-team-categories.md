# List Team Categories with SIGNL4

Retrieves categories for a team from SIGNL4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/categories/{teamId}`
- **Base URL:** `https://connect.signl4.com/api`
- **Official documentation:** [List Team Categories](https://connect.signl4.com/api/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | ID of the team the categories belong to |
