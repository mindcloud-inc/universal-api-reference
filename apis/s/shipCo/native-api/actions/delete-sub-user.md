# Delete Sub User with Ship&Co

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sub-users/:id`
- **Base URL:** `https://api.shipandco.com/v1`
- **Official documentation:** [Delete Sub User](https://developer.shipandco.com/en/#sub-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ship&Co sub-user ID to delete. Ship&Co requires a 32-character sub-user ID. Maximum length: 32. |
