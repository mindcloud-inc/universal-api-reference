# Delete Order with Ship&Co

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.shipandco.com/v1`
- **Official documentation:** [Delete Order](https://developer.shipandco.com/en/#order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ship&Co order ID to delete. |
