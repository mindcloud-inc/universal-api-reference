# Get Shipment with Ship&Co

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:id`
- **Base URL:** `https://api.shipandco.com/v1`
- **Official documentation:** [Get Shipment](https://developer.shipandco.com/en/#shipment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ship&Co shipment ID. |
