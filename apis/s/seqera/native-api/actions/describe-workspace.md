# Describe Workspace with Seqera

Retrieves workspace details from Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:orgId/workspaces/:workspaceId`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Describe Workspace](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orgId` | path | `number` | yes |
| `workspaceId` | path | `number` | yes |
