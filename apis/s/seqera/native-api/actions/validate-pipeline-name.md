# Validate Pipeline Name with Seqera

Validates a pipeline name in Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/validate`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Validate Pipeline Name](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
