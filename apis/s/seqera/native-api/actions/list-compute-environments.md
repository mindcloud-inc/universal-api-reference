# List Compute Environments with Seqera

Retrieves compute environments from Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/compute-envs`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [List Compute Environments](https://cloud.seqera.io/openapi/seqera-api-latest.yml)
