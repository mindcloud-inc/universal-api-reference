# List Datasets with Seqera

Retrieves datasets from a Seqera workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/datasets`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [List Datasets](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `number` | yes |
