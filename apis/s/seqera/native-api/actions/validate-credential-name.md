# Validate Credential Name with Seqera

Validates a credential name in Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials/validate`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Validate Credential Name](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
