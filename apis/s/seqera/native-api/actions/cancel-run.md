# Cancel Run with Seqera

Cancels a workflow run in Seqera.

## Endpoint

- **Method:** `POST`
- **Path:** `/ga4gh/wes/v1/runs/:run_id/cancel`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Cancel Run](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `run_id` | path | `string` | yes |
