# List Organization Workspaces with Seqera

Retrieves organization workspaces from Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:orgId/workspaces`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [List Organization Workspaces](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orgId` | path | `number` | yes |
