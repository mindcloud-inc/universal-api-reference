# Validate Compute Environment Name with Seqera

Validates a compute environment name in Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/compute-envs/validate`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Validate Compute Environment Name](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
