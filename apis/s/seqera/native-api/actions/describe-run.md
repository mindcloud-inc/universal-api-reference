# Describe Run with Seqera

Retrieves workflow run details from Seqera.

## Endpoint

- **Method:** `GET`
- **Path:** `/ga4gh/wes/v1/runs/:run_id`
- **Base URL:** `https://api.cloud.seqera.io`
- **Official documentation:** [Describe Run](https://cloud.seqera.io/openapi/seqera-api-latest.yml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `run_id` | path | `string` | yes |
