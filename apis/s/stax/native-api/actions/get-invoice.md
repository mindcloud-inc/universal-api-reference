# Get Invoice with Stax

Retrieves an invoice from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Invoice](https://docs.staxpayments.com/reference/get-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Invoice identifier |
