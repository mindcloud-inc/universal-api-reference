# Get Statement Volumes by Card Type with Stax

Retrieves statement volumes by card type from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/statement/v3/volumes/card-type`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Statement Volumes by Card Type](https://docs.staxpayments.com/reference/volumes-by-card-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endDate` | query | `string` | no | Report interval end date |
| `startDate` | query | `string` | no | Report interval start date |
