# Get Payment Link with Stax

Retrieves a payment link from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/payment-links/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Payment Link](https://docs.staxpayments.com/reference/get-a-payment-links-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment link identifier |
