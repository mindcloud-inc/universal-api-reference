# List Payment Links with Stax

Retrieves payment links from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/payment-links`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [List Payment Links](https://docs.staxpayments.com/reference/list-and-filter-all-payment-links)
