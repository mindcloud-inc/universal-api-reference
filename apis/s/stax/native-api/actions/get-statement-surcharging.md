# Get Statement Surcharging with Stax

Retrieves statement surcharging totals from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/statement/v3/surcharges`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Statement Surcharging](https://docs.staxpayments.com/reference/surcharging-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endDate` | query | `string` | no | Report interval end date |
| `startDate` | query | `string` | no | Report interval start date |
