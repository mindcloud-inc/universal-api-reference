# Get Related Transactions with Stax

Retrieves related transactions for a transaction in Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/:id/related`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Related Transactions](https://docs.staxpayments.com/reference/get-a-related-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Transaction identifier |
