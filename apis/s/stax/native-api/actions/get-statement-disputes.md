# Get Statement Disputes with Stax

Retrieves statement disputes from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/statement/v3/disputes`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Statement Disputes](https://docs.staxpayments.com/reference/disputes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endDate` | query | `string` | no | Report interval end date |
| `startDate` | query | `string` | no | Report interval start date |
