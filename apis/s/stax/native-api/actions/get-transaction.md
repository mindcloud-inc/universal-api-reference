# Get Transaction with Stax

Retrieves a transaction from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Transaction](https://docs.staxpayments.com/reference/get-a-transactions-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Transaction identifier |
