# Get Payment Method with Stax

Retrieves a payment method from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-method/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Payment Method](https://docs.staxpayments.com/reference/get-a-payment-method-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment method identifier |
