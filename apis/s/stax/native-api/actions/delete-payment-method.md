# Delete Payment Method with Stax

Deletes a payment method from Stax.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/payment-method/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Delete Payment Method](https://docs.staxpayments.com/reference/delete-a-payment-method)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment method identifier |
