# List Merchant Payment Methods with Stax

Retrieves merchant payment methods from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-method`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [List Merchant Payment Methods](https://docs.staxpayments.com/reference/get-all-payment-methods-for-a-merchant)
