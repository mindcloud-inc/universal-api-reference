# Update Payment Link with Stax

Updates or deactivates a payment link in Stax.

## Endpoint

- **Method:** `PUT`
- **Path:** `/query/payment-links/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Update Payment Link](https://docs.staxpayments.com/reference/update-or-deactivate-a-payment-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment link identifier |
