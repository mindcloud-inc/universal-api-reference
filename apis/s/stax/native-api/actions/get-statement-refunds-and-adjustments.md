# Get Statement Refunds and Adjustments with Stax

Retrieves statement refunds and adjustments from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/statement/v3/adjustments`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Statement Refunds and Adjustments](https://docs.staxpayments.com/reference/refund-and-adjustments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endDate` | query | `string` | no | Report interval end date |
| `startDate` | query | `string` | no | Report interval start date |
