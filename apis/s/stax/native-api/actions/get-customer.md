# Get Customer with Stax

Retrieves a customer from Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Customer](https://docs.staxpayments.com/reference/get-a-customers-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Customer identifier |
