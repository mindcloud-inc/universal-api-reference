# Delete Customer with Stax

Soft deletes a customer from Stax.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customer/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Delete Customer](https://docs.staxpayments.com/reference/delete-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Customer identifier |
