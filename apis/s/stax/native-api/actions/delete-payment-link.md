# Delete Payment Link with Stax

Deletes a payment link from Stax.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/query/payment-links/:id`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Delete Payment Link](https://docs.staxpayments.com/reference/delete-a-payment-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment link identifier |
