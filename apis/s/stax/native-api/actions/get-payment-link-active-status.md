# Get Payment Link Active Status with Stax

Retrieves a payment link's active status in Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/payment-links/:id/is-active`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Payment Link Active Status](https://docs.staxpayments.com/reference/get-a-payment-links-active-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Payment link identifier |
