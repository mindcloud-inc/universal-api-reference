# Get Transaction Funding Instructions with Stax

Retrieves funding instructions for a transaction in Stax.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/:id/funding`
- **Base URL:** `https://apiprod.fattlabs.com`
- **Official documentation:** [Get Transaction Funding Instructions](https://docs.staxpayments.com/reference/get-a-transactions-funding-instructions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Transaction identifier |
