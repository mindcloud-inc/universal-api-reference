# Get Product Information with Spoonacular Food

Retrieves grocery product information from Spoonacular Food.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/products/:id`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Product Information](https://spoonacular.com/food-api/docs#Get-Product-Information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Spoonacular product ID. |
