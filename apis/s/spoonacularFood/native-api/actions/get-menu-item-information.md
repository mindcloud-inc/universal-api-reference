# Get Menu Item Information with Spoonacular Food

Retrieves menu item information from Spoonacular Food.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/menuItems/:id`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Menu Item Information](https://spoonacular.com/food-api/docs#Get-Menu-Item-Information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Spoonacular menu item ID. |
