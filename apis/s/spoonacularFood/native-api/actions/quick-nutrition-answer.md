# Quick Nutrition Answer with Spoonacular Food

Retrieves a nutrition answer from Spoonacular Food.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/quickAnswer`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Quick Nutrition Answer](https://spoonacular.com/food-api/docs#Quick-Answer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Nutrition-related natural language question. |
