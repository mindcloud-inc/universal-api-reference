# Search Menu Items with Spoonacular Food

Finds menu items in Spoonacular Food by keyword.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/menuItems/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search Menu Items](https://spoonacular.com/food-api/docs#Search-Menu-Items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Menu item search query. |
