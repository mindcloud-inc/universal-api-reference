# Search All Food with Spoonacular Food

Finds food content in Spoonacular Food by keyword.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Search All Food](https://spoonacular.com/food-api/docs#Search-All-Food)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Food search query. |
