# Get Location with Storerocket

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/locations/:locationId`
- **Base URL:** `https://storerocket.io/api/v2`
- **Official documentation:** [Get Location](https://storerocket.io/api/v2/projects/:projectId/locations/:locationId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The StoreRocket project ID that owns the location. |
| `locationId` | path | `string` | yes | The StoreRocket location ID. |
