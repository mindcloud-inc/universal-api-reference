# List Taxes with Sumtracker

Retrieves tax rates from Sumtracker.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/version/2025-03/settings/taxes/`
- **Base URL:** `https://inventory-api.sumtracker.com`
- **API:** REST - Page Based
- **Official documentation:** [List Taxes](https://developers.sumtracker.com/reference/taxlist)
