# Delete Stock Adjustment Document with Sumtracker

Deletes a stock adjustment document from Sumtracker.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/version/2025-03/stock/adjustment/documents/:id/`
- **Base URL:** `https://inventory-api.sumtracker.com`
- **API:** REST - Page Based
- **Official documentation:** [Delete Stock Adjustment Document](https://developers.sumtracker.com/reference/stockadjustmentdocumentdelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Stock adjustment document ID. |
