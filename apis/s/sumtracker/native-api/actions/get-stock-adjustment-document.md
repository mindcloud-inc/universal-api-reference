# Get Stock Adjustment Document with Sumtracker

Retrieves a stock adjustment document from Sumtracker.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/version/2025-03/stock/adjustment/documents/:id/`
- **Base URL:** `https://inventory-api.sumtracker.com`
- **API:** REST - Page Based
- **Official documentation:** [Get Stock Adjustment Document](https://developers.sumtracker.com/reference/stockadjustmentdocumentget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Stock adjustment document ID. |
