# List Warehouses with Sumtracker

Retrieves warehouses from Sumtracker.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/version/2025-03/settings/warehouses/`
- **Base URL:** `https://inventory-api.sumtracker.com`
- **API:** REST - Page Based
- **Official documentation:** [List Warehouses](https://developers.sumtracker.com/reference/warehouselist)
