# Delete Calendar Event with Scoro

Deletes an existing calendar event from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `calendar/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Calendar Event](https://api.scoro.com/api/v2#calendarApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro calendar event ID. |
