# View Task with Scoro

Retrieves task details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `tasks/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Task](https://api.scoro.com/api/v2#tasksApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro task ID. |
