# View Price List with Scoro

Retrieves price list details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `priceLists/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Price List](https://api.scoro.com/api/v2#priceListsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro price list ID. |
