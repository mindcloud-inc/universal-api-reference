# View Calendar Event with Scoro

Retrieves calendar event details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `calendar/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Calendar Event](https://api.scoro.com/api/v2#calendarApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro calendar event ID. |
