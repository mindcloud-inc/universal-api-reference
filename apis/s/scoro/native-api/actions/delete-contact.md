# Delete Contact with Scoro

Deletes an existing contact from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `contacts/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Contact](https://api.scoro.com/api/v2#contactsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro contact ID. |
