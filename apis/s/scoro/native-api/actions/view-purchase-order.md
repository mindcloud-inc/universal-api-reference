# View Purchase Order with Scoro

Retrieves purchase order details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `purchaseOrders/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Purchase Order](https://api.scoro.com/api/v2#purchaseOrdersApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro purchase order ID. |
