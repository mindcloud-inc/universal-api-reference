# View Finance Account with Scoro

Retrieves finance account details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `financeAccounts/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Finance Account](https://api.scoro.com/api/v2#financeAccountsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro finance account ID. |
