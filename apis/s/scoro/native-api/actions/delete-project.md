# Delete Project with Scoro

Deletes an existing project from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Project](https://api.scoro.com/api/v2#projectsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro project ID. |
