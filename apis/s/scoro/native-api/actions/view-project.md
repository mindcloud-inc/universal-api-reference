# View Project with Scoro

Retrieves project details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Project](https://api.scoro.com/api/v2#projectsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro project ID. |
