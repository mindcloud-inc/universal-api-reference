# View Price List Variant with Scoro

Retrieves price list variant details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `localPriceLists/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Price List Variant](https://api.scoro.com/api/v2#localPriceListsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro local price list ID. |
