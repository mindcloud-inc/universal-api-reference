# Update Task with Scoro

Updates an existing task in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `tasks/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Task](https://api.scoro.com/api/v2#tasksApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro task ID. |
