# Delete File with Scoro

Deletes an existing file from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `files/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete File](https://api.scoro.com/api/v2#filesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro file ID. |
