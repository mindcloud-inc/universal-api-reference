# Delete Purchase Order with Scoro

Deletes an existing purchase order from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `purchaseOrders/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Purchase Order](https://api.scoro.com/api/v2#purchaseOrdersApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro purchase order ID. |
