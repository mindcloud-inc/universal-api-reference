# Update Calendar Event with Scoro

Updates an existing calendar event in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `calendar/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Calendar Event](https://api.scoro.com/api/v2#calendarApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro calendar event ID. |
