# Update Contact with Scoro

Updates an existing contact in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `contacts/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Contact](https://api.scoro.com/api/v2#contactsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro contact ID. |
