# Delete Task with Scoro

Deletes an existing task from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `tasks/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Task](https://api.scoro.com/api/v2#tasksApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro task ID. |
