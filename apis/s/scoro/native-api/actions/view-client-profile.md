# View Client Profile with Scoro

Retrieves client profile details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `clientProfiles/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Client Profile](https://api.scoro.com/api/v2#clientProfilesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro client profile ID. |
