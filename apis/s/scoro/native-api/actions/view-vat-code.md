# View VAT Code with Scoro

Retrieves VAT code details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `vatCodes/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View VAT Code](https://api.scoro.com/api/v2#vatCodesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro VAT code ID. |
