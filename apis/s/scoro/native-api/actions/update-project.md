# Update Project with Scoro

Updates an existing project in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Project](https://api.scoro.com/api/v2#projectsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro project ID. |
