# View Permission Set with Scoro

Retrieves permission set details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `userRoles/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Permission Set](https://api.scoro.com/api/v2#userRolesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro permission set ID. |
