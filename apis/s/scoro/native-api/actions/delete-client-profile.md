# Delete Client Profile with Scoro

Deletes an existing client profile from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `clientProfiles/delete/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Delete Client Profile](https://api.scoro.com/api/v2#clientProfilesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro client profile ID. |
