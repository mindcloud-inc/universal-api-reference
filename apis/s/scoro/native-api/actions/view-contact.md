# View Contact with Scoro

Retrieves contact details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `contacts/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Contact](https://api.scoro.com/api/v2#contactsApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro contact ID. |
