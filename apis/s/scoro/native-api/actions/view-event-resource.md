# View Event Resource with Scoro

Retrieves event resource details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `eventsResources/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View Event Resource](https://api.scoro.com/api/v2#eventsResourcesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro event resource ID. |
