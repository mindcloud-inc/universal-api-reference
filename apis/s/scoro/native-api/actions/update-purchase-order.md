# Update Purchase Order with Scoro

Updates an existing purchase order in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `purchaseOrders/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Purchase Order](https://api.scoro.com/api/v2#purchaseOrdersApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro purchase order ID. |
