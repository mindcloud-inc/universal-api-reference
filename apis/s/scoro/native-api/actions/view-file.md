# View File with Scoro

Retrieves file details from Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `files/view/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [View File](https://api.scoro.com/api/v2#filesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro file ID. |
