# Update Client Profile with Scoro

Updates an existing client profile in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `clientProfiles/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update Client Profile](https://api.scoro.com/api/v2#clientProfilesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro client profile ID. |
