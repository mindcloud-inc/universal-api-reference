# Update File with Scoro

Updates an existing file in Scoro.

## Endpoint

- **Method:** `POST`
- **Path:** `files/modify/:id`
- **Base URL:** `{subdomain}`
- **Official documentation:** [Update File](https://api.scoro.com/api/v2#filesApiV2Docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Scoro file ID. |
