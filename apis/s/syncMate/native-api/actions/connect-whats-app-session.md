# Connect WhatsApp Session with SyncMate

## Endpoint

- **Method:** `POST`
- **Path:** `/api/wapushplus/getqr`
- **Base URL:** `https://app.assistro.co`
- **Official documentation:** [Connect WhatsApp Session](https://www.postman.com/syncmate/request/52527883-50722693-5150-4448-bef1-8e19a4f9bf0c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `whatsapp_number` | body | `string` | yes | WhatsApp number to connect, without the leading plus sign. |
