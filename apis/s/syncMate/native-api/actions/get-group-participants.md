# Get Group Participants with SyncMate

## Endpoint

- **Method:** `GET`
- **Path:** `/api/group/:groupId`
- **Base URL:** `https://app.assistro.co`
- **Official documentation:** [Get Group Participants](https://www.postman.com/syncmate/request/52527883-339e4251-8202-44a9-9435-4ee8112eeb7f)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Full WhatsApp group identifier ending in @g.us. |
