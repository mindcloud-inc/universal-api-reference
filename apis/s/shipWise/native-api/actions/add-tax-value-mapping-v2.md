# Add Tax Value Mapping V2 with ShipWise

Creates a tax value mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/TaxValueMappings/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Tax Value Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
