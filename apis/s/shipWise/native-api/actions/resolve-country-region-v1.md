# Resolve Country Region V1 with ShipWise

Finds a country region in ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Profiles/Regions/Resolve/Country`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Resolve Country Region V1](https://api.shipwise.com/swagger/v1/swagger.json)
