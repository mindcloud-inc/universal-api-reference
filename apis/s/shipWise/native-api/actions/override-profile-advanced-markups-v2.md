# Override Profile Advanced Markups V2 with ShipWise

Replaces profile advanced markups in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/V2Profiles/AdvancedMarkups/Override`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Override Profile Advanced Markups V2](https://api.shipwise.com/swagger/v2/swagger.json)
