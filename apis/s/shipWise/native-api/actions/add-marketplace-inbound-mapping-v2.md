# Add Marketplace Inbound Mapping V2 with ShipWise

Creates a marketplace inbound mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/InboundMappings/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Marketplace Inbound Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
