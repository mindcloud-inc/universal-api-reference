# Create Profile Mapping V1 with ShipWise

Creates a profile mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Profiles/Mapping`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Create Profile Mapping V1](https://api.shipwise.com/swagger/v1/swagger.json)
