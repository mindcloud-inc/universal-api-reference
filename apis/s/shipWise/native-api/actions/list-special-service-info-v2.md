# List Special Service Info V2 with ShipWise

Retrieves special service info from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/CarrierServices/SpecialServiceInfo`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Special Service Info V2](https://api.shipwise.com/swagger/v2/swagger.json)
