# Add Package To Order V2 with ShipWise

Adds a package to an order in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Order/AddPackageToOrder`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Package To Order V2](https://api.shipwise.com/swagger/v2/swagger.json)
