# List Profile Linked Carrier Accounts V2 with ShipWise

Retrieves profile linked carrier accounts from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/V2Profiles/LinkedCarrierAccounts`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Profile Linked Carrier Accounts V2](https://api.shipwise.com/swagger/v2/swagger.json)
