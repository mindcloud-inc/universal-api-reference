# Query Single Order V1 with ShipWise

Finds an order in ShipWise by query.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Order/QuerySingle`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Query Single Order V1](https://api.shipwise.com/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `marketOrderId` | body | `string` | no |
