# List Ready Close Carriers V1 with ShipWise

Retrieves ready close carriers from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/Close`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Ready Close Carriers V1](https://api.shipwise.com/swagger/v1/swagger.json)
