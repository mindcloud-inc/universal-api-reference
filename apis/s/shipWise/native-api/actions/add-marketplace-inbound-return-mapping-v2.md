# Add Marketplace Inbound Return Mapping V2 with ShipWise

Creates a marketplace inbound return mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/InboundReturnMappings/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Marketplace Inbound Return Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
