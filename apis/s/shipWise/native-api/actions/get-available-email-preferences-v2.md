# Get Available Email Preferences V2 with ShipWise

Retrieves available email preferences from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Settings/GetAvailableEmailPreferences`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Available Email Preferences V2](https://api.shipwise.com/swagger/v2/swagger.json)
