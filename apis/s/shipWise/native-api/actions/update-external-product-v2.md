# Update External Product V2 with ShipWise

Updates an external product in ShipWise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v2/Product/UpdateExternal`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Update External Product V2](https://api.shipwise.com/swagger/v2/swagger.json)
