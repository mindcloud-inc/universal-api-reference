# Verify Address For Rate V1 with ShipWise

Verifies an address for rating in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Rate/AddressVerify`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Verify Address For Rate V1](https://api.shipwise.com/swagger/v1/swagger.json)
