# Verify Address For Rate V2 with ShipWise

Verifies an address for rating in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/V2Rate/AddressVerify`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Verify Address For Rate V2](https://api.shipwise.com/swagger/v2/swagger.json)
