# Add Marketplace Outbound Mapping V2 with ShipWise

Creates a marketplace outbound mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/OutboundMappings/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Marketplace Outbound Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
