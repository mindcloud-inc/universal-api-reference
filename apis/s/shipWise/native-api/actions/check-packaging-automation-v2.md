# Check Packaging Automation V2 with ShipWise

Checks packaging automation in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Packaging/CheckForPackagingAutomation`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Check Packaging Automation V2](https://api.shipwise.com/swagger/v2/swagger.json)
