# Get Packaging Solution V2 with ShipWise

Retrieves a packaging solution from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Packaging/PackagingSolution`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Packaging Solution V2](https://api.shipwise.com/swagger/v2/swagger.json)
