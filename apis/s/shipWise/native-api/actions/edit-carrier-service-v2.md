# Edit Carrier Service V2 with ShipWise

Updates a carrier service in ShipWise.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/CarrierServices/Edit`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Edit Carrier Service V2](https://api.shipwise.com/swagger/v2/swagger.json)
