# List Marketplace Inbound Mappings V2 with ShipWise

Retrieves marketplace inbound mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Marketplace/InboundMappings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Marketplace Inbound Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)
