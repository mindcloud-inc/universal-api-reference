# Get Packing Slip V1 with ShipWise

Retrieves a packing slip from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Print/GetPackingslip`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Packing Slip V1](https://api.shipwise.com/swagger/v1/swagger.json)
