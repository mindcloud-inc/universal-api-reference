# List Profile Advanced Markups V2 with ShipWise

Retrieves profile advanced markups from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/V2Profiles/AdvancedMarkups`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Profile Advanced Markups V2](https://api.shipwise.com/swagger/v2/swagger.json)
