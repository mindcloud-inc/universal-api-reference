# List Third Party Billing Mappings V2 with ShipWise

Retrieves third party billing mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/ThirdPartyBilling`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Third Party Billing Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)
