# List Carrier Service Info V2 with ShipWise

Retrieves carrier service info from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/CarrierServices/CarrierServiceInfo`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Carrier Service Info V2](https://api.shipwise.com/swagger/v2/swagger.json)
