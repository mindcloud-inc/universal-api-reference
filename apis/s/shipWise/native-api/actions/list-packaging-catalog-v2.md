# List Packaging Catalog V2 with ShipWise

Retrieves packaging catalog from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/V2Packaging`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Packaging Catalog V2](https://api.shipwise.com/swagger/v2/swagger.json)
