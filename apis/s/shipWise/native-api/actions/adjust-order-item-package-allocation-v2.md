# Adjust Order Item Package Allocation V2 with ShipWise

Updates order item package allocation in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Order/AdjustItemPackageAllocation`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Adjust Order Item Package Allocation V2](https://api.shipwise.com/swagger/v2/swagger.json)
