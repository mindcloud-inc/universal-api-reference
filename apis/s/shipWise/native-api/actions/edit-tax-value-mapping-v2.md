# Edit Tax Value Mapping V2 with ShipWise

Updates a tax value mapping in ShipWise.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/TaxValueMappings/Edit`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Edit Tax Value Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
