# Reprint Close V1 with ShipWise

Retrieves a printable close document from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/Close/Reprint`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Reprint Close V1](https://api.shipwise.com/swagger/v1/swagger.json)
