# Get Batch Summary V1 with ShipWise

Retrieves batch summary details from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Batch/Summary`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Batch Summary V1](https://api.shipwise.com/swagger/v1/swagger.json)
