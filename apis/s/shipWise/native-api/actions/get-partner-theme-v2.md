# Get Partner Theme V2 with ShipWise

Retrieves the partner theme from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/GlobalSettings/PartnerTheme`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Partner Theme V2](https://api.shipwise.com/swagger/v2/swagger.json)
