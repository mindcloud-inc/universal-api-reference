# Create Packaging Automation V2 with ShipWise

Creates a packaging automation in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Packaging/CreatePackagingAutomation`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Create Packaging Automation V2](https://api.shipwise.com/swagger/v2/swagger.json)
