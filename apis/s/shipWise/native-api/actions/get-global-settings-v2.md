# Get Global Settings V2 with ShipWise

Retrieves global settings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/GlobalSettings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Global Settings V2](https://api.shipwise.com/swagger/v2/swagger.json)
