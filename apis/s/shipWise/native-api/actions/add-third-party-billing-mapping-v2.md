# Add Third Party Billing Mapping V2 with ShipWise

Creates a third party billing mapping in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/ThirdPartyBilling/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Third Party Billing Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
