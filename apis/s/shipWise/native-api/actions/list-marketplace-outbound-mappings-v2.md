# List Marketplace Outbound Mappings V2 with ShipWise

Retrieves marketplace outbound mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Marketplace/OutboundMappings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Marketplace Outbound Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)
