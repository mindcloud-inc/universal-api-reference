# Delete Marketplace Inbound Mapping V2 with ShipWise

Deletes a marketplace inbound mapping from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/InboundMappings/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Marketplace Inbound Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
