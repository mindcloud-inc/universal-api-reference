# Get Best Email Preference IDs V2 with ShipWise

Retrieves recommended email preference IDs from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Settings/GetBestEmailPreferenceIds`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Best Email Preference IDs V2](https://api.shipwise.com/swagger/v2/swagger.json)
