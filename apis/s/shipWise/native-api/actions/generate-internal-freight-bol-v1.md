# Generate Internal Freight BOL V1 with ShipWise

Retrieves an internal freight BOL from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Freight/InternalBOL`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Generate Internal Freight BOL V1](https://api.shipwise.com/swagger/v1/swagger.json)
