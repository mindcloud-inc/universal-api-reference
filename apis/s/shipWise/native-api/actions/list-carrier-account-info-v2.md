# List Carrier Account Info V2 with ShipWise

Retrieves carrier account info from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/CarrierServices/CarrierAccountInfo`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Carrier Account Info V2](https://api.shipwise.com/swagger/v2/swagger.json)
