# Get Product V2 with ShipWise

Retrieves a product from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Product/:id`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Product V2](https://api.shipwise.com/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ShipWise product ID. |
