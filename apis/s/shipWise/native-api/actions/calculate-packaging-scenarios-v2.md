# Calculate Packaging Scenarios V2 with ShipWise

Retrieves packaging scenarios from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Packaging`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Calculate Packaging Scenarios V2](https://api.shipwise.com/swagger/v2/swagger.json)
