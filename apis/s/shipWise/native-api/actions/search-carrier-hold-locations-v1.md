# Search Carrier Hold Locations V1 with ShipWise

Finds carrier hold locations in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Rate/SearchCarrierHoldLocations`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Search Carrier Hold Locations V1](https://api.shipwise.com/swagger/v1/swagger.json)
