# Delete Service Group V2 with ShipWise

Deletes a service group from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/ServiceGroups/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Service Group V2](https://api.shipwise.com/swagger/v2/swagger.json)
