# Upsert Order Client Reference V2 with ShipWise

Creates or updates an order client reference in ShipWise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v2/Order/ClientReference`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Upsert Order Client Reference V2](https://api.shipwise.com/swagger/v2/swagger.json)
