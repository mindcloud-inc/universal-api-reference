# Delete Marketplace Outbound Mapping V2 with ShipWise

Deletes a marketplace outbound mapping from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/OutboundMappings/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Marketplace Outbound Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
