# Upsert Package Reference V2 with ShipWise

Creates or updates a package reference in ShipWise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v2/Reference`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Upsert Package Reference V2](https://api.shipwise.com/swagger/v2/swagger.json)
