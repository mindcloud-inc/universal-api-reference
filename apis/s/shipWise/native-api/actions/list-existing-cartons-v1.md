# List Existing Cartons V1 with ShipWise

Retrieves existing cartons from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/Carton/Existing`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Existing Cartons V1](https://api.shipwise.com/swagger/v1/swagger.json)
