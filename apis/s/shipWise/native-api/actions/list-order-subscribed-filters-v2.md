# List Order Subscribed Filters V2 with ShipWise

Retrieves order subscribed filters from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Order/SubscribedFilters`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Order Subscribed Filters V2](https://api.shipwise.com/swagger/v2/swagger.json)
