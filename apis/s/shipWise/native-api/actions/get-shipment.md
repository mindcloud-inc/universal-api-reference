# Get Shipment with ShipWise

Retrieves a shipment from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/:id`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Shipment](https://api.shipwise.com/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ShipWise shipment ID. |
