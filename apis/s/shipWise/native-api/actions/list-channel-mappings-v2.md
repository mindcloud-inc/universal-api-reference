# List Channel Mappings V2 with ShipWise

Retrieves channel mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Channel/:channelId/mappings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Channel Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | ShipWise channel ID. |
