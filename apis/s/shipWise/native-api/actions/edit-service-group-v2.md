# Edit Service Group V2 with ShipWise

Updates a service group in ShipWise.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/ServiceGroups/Edit`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Edit Service Group V2](https://api.shipwise.com/swagger/v2/swagger.json)
