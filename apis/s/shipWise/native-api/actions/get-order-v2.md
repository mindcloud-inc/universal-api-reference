# Get Order V2 with ShipWise

Retrieves an order from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Order/:id`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Order V2](https://api.shipwise.com/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ShipWise order ID. |
