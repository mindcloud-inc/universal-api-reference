# Delete Third Party Billing Mapping V2 with ShipWise

Deletes a third party billing mapping from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/ThirdPartyBilling/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Third Party Billing Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
