# Create Or Update Product V2 with ShipWise

Creates or updates a product in ShipWise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v2/Product/Create`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Create Or Update Product V2](https://api.shipwise.com/swagger/v2/swagger.json)
