# Query Profile Mapping V1 with ShipWise

Finds profile mapping in ShipWise by query.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Profiles/Mapping/Query`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Query Profile Mapping V1](https://api.shipwise.com/swagger/v1/swagger.json)
