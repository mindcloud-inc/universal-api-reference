# Override Profile Linked Integrations V2 with ShipWise

Replaces profile linked integrations in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/V2Profiles/LinkedIntegrations/Override`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Override Profile Linked Integrations V2](https://api.shipwise.com/swagger/v2/swagger.json)
