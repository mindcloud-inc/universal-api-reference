# Override Profile Linked Carrier Accounts V2 with ShipWise

Replaces profile linked carrier accounts in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/V2Profiles/LinkedCarrierAccounts/Override`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Override Profile Linked Carrier Accounts V2](https://api.shipwise.com/swagger/v2/swagger.json)
