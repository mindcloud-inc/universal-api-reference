# Get Channel Settings By Link V2 with ShipWise

Retrieves channel settings by link from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Channel/:linkId/settings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Channel Settings By Link V2](https://api.shipwise.com/swagger/v2/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | ShipWise channel link ID. |
