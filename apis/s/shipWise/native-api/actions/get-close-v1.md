# Get Close V1 with ShipWise

Retrieves a close from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/Close/:closeId`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Close V1](https://api.shipwise.com/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `closeId` | path | `string` | yes | ShipWise close ID. |
