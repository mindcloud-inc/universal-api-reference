# List Marketplace Inbound Return Mappings V2 with ShipWise

Retrieves marketplace inbound return mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Marketplace/InboundReturnMappings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Marketplace Inbound Return Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)
