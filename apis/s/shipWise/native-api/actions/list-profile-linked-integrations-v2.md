# List Profile Linked Integrations V2 with ShipWise

Retrieves profile linked integrations from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/V2Profiles/LinkedIntegrations`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Profile Linked Integrations V2](https://api.shipwise.com/swagger/v2/swagger.json)
