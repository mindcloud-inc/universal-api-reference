# Edit Global Settings V2 with ShipWise

Updates global settings in ShipWise.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/GlobalSettings/Edit`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Edit Global Settings V2](https://api.shipwise.com/swagger/v2/swagger.json)
