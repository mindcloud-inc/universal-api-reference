# List Tax Value Mappings V2 with ShipWise

Retrieves tax value mappings from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/TaxValueMappings`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Tax Value Mappings V2](https://api.shipwise.com/swagger/v2/swagger.json)
