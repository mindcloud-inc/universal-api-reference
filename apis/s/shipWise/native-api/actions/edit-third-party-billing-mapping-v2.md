# Edit Third Party Billing Mapping V2 with ShipWise

Updates a third party billing mapping in ShipWise.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/ThirdPartyBilling/Edit`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Edit Third Party Billing Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
