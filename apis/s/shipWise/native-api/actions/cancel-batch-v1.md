# Cancel Batch V1 with ShipWise

Cancels a batch in ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Batch/:id/Cancel`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Cancel Batch V1](https://api.shipwise.com/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ShipWise batch ID. |
