# List Close History V1 with ShipWise

Retrieves close history from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Ship/Close/History`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Close History V1](https://api.shipwise.com/swagger/v1/swagger.json)
