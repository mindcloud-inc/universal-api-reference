# Delete Marketplace Inbound Return Mapping V2 with ShipWise

Deletes a marketplace inbound return mapping from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/Marketplace/InboundReturnMappings/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Marketplace Inbound Return Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
