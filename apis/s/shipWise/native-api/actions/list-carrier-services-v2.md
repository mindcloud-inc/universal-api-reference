# List Carrier Services V2 with ShipWise

Retrieves carrier services from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/CarrierServices`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Carrier Services V2](https://api.shipwise.com/swagger/v2/swagger.json)
