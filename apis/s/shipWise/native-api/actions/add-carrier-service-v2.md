# Add Carrier Service V2 with ShipWise

Creates a carrier service in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/CarrierServices/Add`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Carrier Service V2](https://api.shipwise.com/swagger/v2/swagger.json)
