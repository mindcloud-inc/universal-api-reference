# Add Profile Resolver V1 with ShipWise

Creates a profile resolver in ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Profiles/AddResolver`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Add Profile Resolver V1](https://api.shipwise.com/swagger/v1/swagger.json)
