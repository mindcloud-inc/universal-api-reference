# Get Partner Logo V2 with ShipWise

Retrieves the partner logo from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/GlobalSettings/PartnerLogo`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Partner Logo V2](https://api.shipwise.com/swagger/v2/swagger.json)
