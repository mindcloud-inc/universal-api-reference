# List Freight Services V1 with ShipWise

Retrieves freight services from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Freight/GetServices`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [List Freight Services V1](https://api.shipwise.com/swagger/v1/swagger.json)
