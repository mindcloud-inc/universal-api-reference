# Delete Tax Value Mapping V2 with ShipWise

Deletes a tax value mapping from ShipWise.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/TaxValueMappings/Delete`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Delete Tax Value Mapping V2](https://api.shipwise.com/swagger/v2/swagger.json)
