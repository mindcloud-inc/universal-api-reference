# Get WMS Configuration V2 with ShipWise

Retrieves WMS configuration from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/GlobalSettings/WMSConfiguration`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get WMS Configuration V2](https://api.shipwise.com/swagger/v2/swagger.json)
