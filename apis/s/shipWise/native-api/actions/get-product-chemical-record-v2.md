# Get Product Chemical Record V2 with ShipWise

Retrieves a product chemical record from ShipWise.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/Product/ChemicalRecord`
- **Base URL:** `https://api.shipwise.com/`
- **Official documentation:** [Get Product Chemical Record V2](https://api.shipwise.com/swagger/v2/swagger.json)
