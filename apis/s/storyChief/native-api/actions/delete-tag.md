# Delete Tag with StoryChief

Deletes a tag from StoryChief.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tagId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Delete Tag](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-d958b83b-bfbc-4350-9d63-7663a373e320)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `number` | yes | Tag identifier from the path. |
