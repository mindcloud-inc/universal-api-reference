# Get Destination with StoryChief

Retrieves a destination from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/:destinationId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Destination](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-8f080722-238f-4ac0-bc5f-809660e09f01)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destinationId` | path | `number` | yes | Destination identifier from the path. |
