# Get Current User with StoryChief

Retrieves the current user from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Current User](https://developers.storychief.io/api/collections/3269417/SVmwvHwN?environment=3269417-81fe7caa-52c9-4f28-a4a5-a8a9fd480a8f&segregateAuth=true&versionTag=latest)
