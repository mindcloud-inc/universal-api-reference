# Get Tag with StoryChief

Retrieves a tag from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tagId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Tag](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-1ae64576-35c1-42f9-be32-f0f3b59c3093)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `number` | yes | Tag identifier from the path. |
