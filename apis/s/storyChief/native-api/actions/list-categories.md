# List Categories with StoryChief

Retrieves categories from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Categories](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-ceb18e33-66c3-4efc-979a-9e7a1b967c9c)

## Capabilities

This operation supports [pagination](../README.md#pagination).
