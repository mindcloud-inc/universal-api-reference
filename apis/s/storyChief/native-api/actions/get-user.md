# Get User with StoryChief

Retrieves a user from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get User](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-b694f5e4-7154-4396-a120-d481201bb769)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | User identifier from the path. |
