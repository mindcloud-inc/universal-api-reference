# List Tags with StoryChief

Retrieves tags from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Tags](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-a4b6b123-02eb-4d3c-b9dc-de4d0fe6c366)

## Capabilities

This operation supports [pagination](../README.md#pagination).
