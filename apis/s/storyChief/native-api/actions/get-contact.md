# Get Contact with StoryChief

Retrieves a contact from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Contact](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-52046e84-21fb-4516-9c51-2013f72020b8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Contact identifier from the path. |
