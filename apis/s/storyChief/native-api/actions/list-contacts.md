# List Contacts with StoryChief

Retrieves contacts from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Contacts](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-bd3f5551-d685-45a7-9615-640beb300217)

## Capabilities

This operation supports [pagination](../README.md#pagination).
