# Get Author with StoryChief

Retrieves an author from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/authors/:authorId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Author](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-5fc1a2a7-c718-4c2e-85f0-bf028cb694ed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `authorId` | path | `number` | yes | Author identifier from the path. |
