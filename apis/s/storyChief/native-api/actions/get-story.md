# Get Story with StoryChief

Retrieves a story from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/stories/:storyId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Story](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-7fe70109-f48c-499a-9b66-b198d456096e)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyId` | path | `number` | yes | Story identifier from the path. |
