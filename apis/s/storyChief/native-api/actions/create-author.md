# Create Author with StoryChief

Creates a new author in StoryChief.

## Endpoint

- **Method:** `POST`
- **Path:** `/authors`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Create Author](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-2c7072d9-b879-4088-b96d-7fd94ccbdb98)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bio` | body | `string` | no | Author biography. |
| `email` | body | `string` | no | Author email address. |
| `firstname` | body | `string` | no | Author first name. |
| `lastname` | body | `string` | no | Author last name. |
