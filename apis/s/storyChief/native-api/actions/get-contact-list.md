# Get Contact List with StoryChief

Retrieves a contact list from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:contactListId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Contact List](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-1958d0cf-b5b4-48b0-bb0f-494f48a1e4e5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactListId` | path | `number` | yes | Contact list identifier from the path. |
