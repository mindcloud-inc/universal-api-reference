# List Users with StoryChief

Retrieves users from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Users](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-df5d5eb4-bc3c-4228-bb67-540c4eb328e4)

## Capabilities

This operation supports [pagination](../README.md#pagination).
