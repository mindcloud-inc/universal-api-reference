# Create Tag with StoryChief

Creates a new tag in StoryChief.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Create Tag](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-17ed9b0a-a92e-4379-961c-65fc30c24f8a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Tag name. |
