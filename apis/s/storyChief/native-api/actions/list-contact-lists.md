# List Contact Lists with StoryChief

Retrieves contact lists from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Contact Lists](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-ea1e11e1-bd45-42a5-94c0-7b8f858e8762)

## Capabilities

This operation supports [pagination](../README.md#pagination).
