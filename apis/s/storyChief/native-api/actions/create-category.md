# Create Category with StoryChief

Creates a new category in StoryChief.

## Endpoint

- **Method:** `POST`
- **Path:** `/categories`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Create Category](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-0b239be8-2419-428a-944a-c9dbb10c3013)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Category name. |
