# List Destinations with StoryChief

Retrieves destinations from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Destinations](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-cb37ebb5-7c32-4b11-8e0e-606589a25319)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destination_type` | query | `string` | no | Destination type selector. |
