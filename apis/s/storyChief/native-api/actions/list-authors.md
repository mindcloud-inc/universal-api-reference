# List Authors with StoryChief

Retrieves authors from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/authors`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [List Authors](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-558eaa32-715c-4e1c-a2b1-bfadf909f7cc)

## Capabilities

This operation supports [pagination](../README.md#pagination).
