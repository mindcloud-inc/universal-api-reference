# Get Post with StoryChief

Retrieves a post from StoryChief.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/:postId`
- **Base URL:** `https://api.storychief.io/1.0`
- **Official documentation:** [Get Post](https://www.postman.com/storychief/storychief-s-public-workspace/documentation/bvzysnr/storychief-api?entity=request-3269417-4b7c9bbd-7979-485f-944a-aad9af869838)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postId` | path | `number` | yes | Post identifier from the path. |
