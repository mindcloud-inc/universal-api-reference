# Trigger Airtable Image Generation with Stencil

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/airtables/:id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Trigger Airtable Image Generation](https://docs.usestencil.com/api/endpoints/airtable#trigger-airtable-image-generation-from-the-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Airtable action ID. |
