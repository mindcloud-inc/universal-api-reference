# List Templates with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/templates`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [List Templates](https://docs.usestencil.com/api/endpoints/templates#list-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project ID from Stencil. |
