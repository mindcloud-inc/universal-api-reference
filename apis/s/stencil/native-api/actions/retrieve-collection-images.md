# Retrieve Collection Images with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/collections/:id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Retrieve Collection Images](https://docs.usestencil.com/api/endpoints/collections#retrieve-images-from-template-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Collection request ID. |
