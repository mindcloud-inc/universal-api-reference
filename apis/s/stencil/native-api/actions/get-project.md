# Get Project with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Get Project](https://docs.usestencil.com/api/endpoints/projects#get-specific-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID from Stencil. |
