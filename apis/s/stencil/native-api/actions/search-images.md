# Search Images with Stencil

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/images/search`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Search Images](https://docs.usestencil.com/api/endpoints/image#search-generated-images)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Case-insensitive search query. |
