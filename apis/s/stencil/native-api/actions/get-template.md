# Get Template with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Get Template](https://docs.usestencil.com/api/endpoints/templates#get-specific-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template ID from Stencil. |
