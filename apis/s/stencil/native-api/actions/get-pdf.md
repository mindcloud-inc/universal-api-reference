# Get PDF with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pdfs/:pdf_id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Get PDF](https://docs.usestencil.com/api/endpoints/pdfs#get-the-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pdf_id` | path | `string` | yes | PDF generation ID. |
