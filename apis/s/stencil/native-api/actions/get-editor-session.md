# Get Editor Session with Stencil

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/editor/sessions/:session_id`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Get Editor Session](https://docs.usestencil.com/api/endpoints/editor-session#get-a-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | Editor session ID. |
