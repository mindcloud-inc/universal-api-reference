# Search PDFs with Stencil

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/pdfs/search`
- **Base URL:** `https://api.usestencil.com`
- **Official documentation:** [Search PDFs](https://docs.usestencil.com/api/endpoints/pdfs#search-generated-pdfs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Case-insensitive search query. |
