# List Contacts with Startquestion

Retrieves contacts from Startquestion.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [List Contacts](https://help.startquestion.com/en/articles/5810000-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
