# Get Respondent Patch with Startquestion

Retrieves a Startquestion respondent patch by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/respondents/patch`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [Get Respondent Patch](https://help.startquestion.com/en/articles/5810169-respondents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `patch_id` | query | `string` | yes | Patch ID. |
