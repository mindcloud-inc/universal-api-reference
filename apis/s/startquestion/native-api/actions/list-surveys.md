# List Surveys with Startquestion

Retrieves surveys from Startquestion.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [List Surveys](https://help.startquestion.com/en/articles/5810076-surveys)

## Capabilities

This operation supports [pagination](../README.md#pagination).
