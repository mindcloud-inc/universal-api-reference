# Create Respondent Batch with Startquestion

Creates a respondent batch for a Startquestion survey.

## Endpoint

- **Method:** `POST`
- **Path:** `/respondents/batch`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [Create Respondent Batch](https://help.startquestion.com/en/articles/5810169-respondents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `survey_id` | body | `number` | yes | Survey ID. |
