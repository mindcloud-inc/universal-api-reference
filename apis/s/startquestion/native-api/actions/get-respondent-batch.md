# Get Respondent Batch with Startquestion

Retrieves a Startquestion respondent batch by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/respondents/batch`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [Get Respondent Batch](https://help.startquestion.com/en/articles/5810169-respondents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch_id` | query | `string` | yes | Batch ID. |
