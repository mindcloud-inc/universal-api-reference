# List Mailing Templates with Startquestion

Retrieves mailing templates from Startquestion.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing/templates`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [List Mailing Templates](https://help.startquestion.com/en/articles/5810255-mailing)
