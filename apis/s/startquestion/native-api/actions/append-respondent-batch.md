# Append Respondent Batch with Startquestion

Adds respondents to a Startquestion batch.

## Endpoint

- **Method:** `POST`
- **Path:** `/respondents/patch`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [Append Respondent Batch](https://help.startquestion.com/en/articles/5810169-respondents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch_id` | body | `string` | yes | Batch ID. |
