# Get Survey with Startquestion

Retrieves a survey from Startquestion by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/:id`
- **Base URL:** `https://www.startquestion.com/api/v2`
- **Official documentation:** [Get Survey](https://help.startquestion.com/en/articles/5810076-surveys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Survey ID. |
