# List Box Tasks with Streak

Retrieves tasks for a box in Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/boxes/:boxKey/tasks`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [List Box Tasks](https://streak.readme.io/reference/read-tasks-on-a-box)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boxKey` | path | `string` | yes |
