# Get Contact with Streak

Retrieves a contact from Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/contacts/:contactKey`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [Get Contact](https://streak.readme.io/reference/read-a-contact-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactKey` | path | `string` | yes | Contact key. |
