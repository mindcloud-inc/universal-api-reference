# Get Organization with Streak

Retrieves an organization from Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/organizations/:organizationKey`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [Get Organization](https://streak.readme.io/reference/get-an-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationKey` | path | `string` | yes | Organization key. |
