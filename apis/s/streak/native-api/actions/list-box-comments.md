# List Box Comments with Streak

Retrieves comments for a box in Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/boxes/:boxKey/comments`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [List Box Comments](https://streak.readme.io/reference/get-all-comments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boxKey` | path | `string` | yes |
