# List Box Threads with Streak

Retrieves threads for a box in Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/boxes/:boxKey/threads`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [List Box Threads](https://streak.readme.io/reference/get-threads-in-a-box)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boxKey` | path | `string` | yes |
