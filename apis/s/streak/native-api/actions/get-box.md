# Get Box with Streak

Retrieves a box from Streak.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/boxes/:boxKey`
- **Base URL:** `https://api.streak.com`
- **Official documentation:** [Get Box](https://streak.readme.io/reference/get-a-box)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `boxKey` | path | `string` | yes | The key of the box to retrieve. |
