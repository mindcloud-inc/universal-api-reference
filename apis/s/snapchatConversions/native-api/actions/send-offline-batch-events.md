# Send Offline Batch Events with Snapchat Conversions

Creates a batch of offline conversion events in Snapchat Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `https://tr.snapchat.com/v3/:pixel_id/events`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send Offline Batch Events](https://developers.snap.com/api/marketing-api/Conversions-API/OfflineEvents)
