# Send App Batch Events with Snapchat Conversions

Creates a batch of app conversion events in Snapchat Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `https://tr.snapchat.com/v3/:snap_app_id/events`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send App Batch Events](https://developers.snap.com/api/marketing-api/Conversions-API/UsingTheAPI)
