# Send Level Complete Event with Snapchat Conversions

Creates a level complete conversion event in Snapchat Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `https://tr.snapchat.com/v3/:asset_id/events`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send Level Complete Event](https://developers.snap.com/api/marketing-api/Conversions-API/Parameters)
