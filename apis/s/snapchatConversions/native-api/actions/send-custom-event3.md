# Send Custom Event 3 with Snapchat Conversions

Creates a CUSTOM_EVENT_3 conversion event in Snapchat Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `https://tr.snapchat.com/v3/:asset_id/events`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send Custom Event 3](https://developers.snap.com/api/marketing-api/Conversions-API/Parameters)
