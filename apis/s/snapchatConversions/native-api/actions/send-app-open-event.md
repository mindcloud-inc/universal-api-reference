# Send App Open Event with Snapchat Conversions

Creates an app open conversion event in Snapchat Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `https://tr.snapchat.com/v3/:asset_id/events`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send App Open Event](https://developers.snap.com/api/marketing-api/Conversions-API/Parameters)
