# Get Review Aggregate Statistics with Shopper Approved

Retrieves review aggregate statistics from Shopper Approved.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregates/reviews/:siteid`
- **Base URL:** `https://api.shopperapproved.com/`
- **Official documentation:** [Get Review Aggregate Statistics](https://help.shopperapproved.com/en/articles/9796973-how-to-use-our-api#h_d0b7f623ee)
