# Bulk Bookings with Sonderplan

## Endpoint

- **Method:** `POST`
- **Path:** `/booking/bulk`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Bulk Bookings](https://docs.sonderplan.com/api-reference/booking/bulk-bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Bulk booking request payload. |
