# Stop Time Entry with Sonderplan

## Endpoint

- **Method:** `PATCH`
- **Path:** `/time-entry/stop`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Stop Time Entry](https://docs.sonderplan.com/api-reference/time-entry/stop-time-entry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Time entry ID to stop. |
