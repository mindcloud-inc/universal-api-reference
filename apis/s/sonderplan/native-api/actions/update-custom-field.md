# Update Custom Field with Sonderplan

## Endpoint

- **Method:** `PUT`
- **Path:** `/custom-field`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Update Custom Field](https://docs.sonderplan.com/api-reference/custom-field/update-custom-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Custom field payload. |
| `id` | query | `string` | yes | Custom field ID. |
