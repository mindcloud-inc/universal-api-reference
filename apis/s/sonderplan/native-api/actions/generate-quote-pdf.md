# Generate Quote PDF with Sonderplan

## Endpoint

- **Method:** `GET`
- **Path:** `/quote/pdf`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Generate Quote PDF](https://docs.sonderplan.com/api-reference/quote/generate-quote-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Quote ID to generate a PDF for. |
