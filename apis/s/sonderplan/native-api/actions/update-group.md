- **Method:** `PUT`
- **Path:** `/group`

- **Official documentation:** [Update Group](https://docs.sonderplan.com/api-reference/group/update-group)

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Group payload. |
