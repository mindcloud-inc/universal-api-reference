# Duplicate Invoice with Sonderplan

## Endpoint

- **Method:** `POST`
- **Path:** `/invoice/duplicate`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Duplicate Invoice](https://docs.sonderplan.com/api-reference/invoice/duplicate-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Invoice ID to duplicate. |
