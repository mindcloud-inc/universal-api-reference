# Duplicate Quote with Sonderplan

## Endpoint

- **Method:** `POST`
- **Path:** `/quote/duplicate`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Duplicate Quote](https://docs.sonderplan.com/api-reference/quote/duplicate-quote)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Quote ID to duplicate. |
