# Update Contact with Sonderplan

## Endpoint

- **Method:** `PUT`
- **Path:** `/contact`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Update Contact](https://docs.sonderplan.com/api-reference/contact/update-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Contact payload. |
| `uuid` | query | `string` | yes | Contact UUID. |
