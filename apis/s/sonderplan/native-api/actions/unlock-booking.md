# Unlock Booking with Sonderplan

## Endpoint

- **Method:** `PUT`
- **Path:** `/booking/unlock`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Unlock Booking](https://docs.sonderplan.com/api-reference/booking/unlock-booking)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Booking ID to unlock. |
