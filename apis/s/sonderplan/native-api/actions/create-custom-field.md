# Create Custom Field with Sonderplan

- **Method:** `POST`
- **Path:** `/custom-field`
- **Base URL:** `https://api.sonderplan.com/v2`
- **Official documentation:** [Create Custom Field](https://docs.sonderplan.com/api-reference/custom-field/create-custom-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Custom field payload. |
