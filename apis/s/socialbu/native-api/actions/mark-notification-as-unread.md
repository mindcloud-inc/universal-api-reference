# Mark Notification as Unread with Socialbu

Marks a notification as unread in SocialBu.

## Endpoint

- **Method:** `POST`
- **Path:** `/notifications/{id}/mark_unread`
- **Base URL:** `https://socialbu.com/api/v1`
- **Official documentation:** [Mark Notification as Unread](https://socialbu.com/developers/docs)
