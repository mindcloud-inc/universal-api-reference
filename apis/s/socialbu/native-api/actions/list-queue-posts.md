# List Queue Posts with Socialbu

Retrieves posts in a specific SocialBu queue.

## Endpoint

- **Method:** `GET`
- **Path:** `/queues/{id}/posts`
- **Base URL:** `https://socialbu.com/api/v1`
- **Official documentation:** [List Queue Posts](https://socialbu.com/developers/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the queue. |
