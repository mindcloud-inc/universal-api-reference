# Search Contacts with Sunwise

Finds contacts in Sunwise by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts-search/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Search Contacts](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | Search term for matching contacts |
