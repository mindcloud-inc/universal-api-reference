# Download Proposals Csv with Sunwise

Retrieves a proposal CSV export from Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/proposals/csv/:proposal_id`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Download Proposals Csv](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `proposal_id` | path | `string` | yes |
