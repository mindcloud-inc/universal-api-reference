# Get Project with Sunwise

Retrieves a project from Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Get Project](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Sunwise project identifier |
