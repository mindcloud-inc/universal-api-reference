# Project Search with Sunwise

Finds projects in Sunwise by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/project-search/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Project Search](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | Search term for matching projects |
