# Get Contact with Sunwise

Retrieves a contact from Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Get Contact](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Sunwise contact identifier |
