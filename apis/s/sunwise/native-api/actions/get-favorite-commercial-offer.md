# Get Favorite Commercial Offer with Sunwise

Retrieves a project's favorite commercial offer in Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/favorite-commercial-offer/:project_id`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Get Favorite Commercial Offer](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
