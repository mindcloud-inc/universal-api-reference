# Download Report Csv with Sunwise

Retrieves a report CSV export from Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/csv/:report_id/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Download Report Csv](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `report_id` | path | `string` | yes |
