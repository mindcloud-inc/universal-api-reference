# Contact Projects with Sunwise

Retrieves projects for a contact in Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/contact-projects/:contact_id/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Contact Projects](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Sunwise contact identifier |
