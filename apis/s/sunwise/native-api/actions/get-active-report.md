# Get Active Report with Sunwise

Retrieves an active report from Sunwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/active-report/:report_id/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Get Active Report](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `report_id` | path | `string` | yes |
