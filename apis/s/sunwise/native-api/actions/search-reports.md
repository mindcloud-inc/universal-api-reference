# Search Reports with Sunwise

Finds reports in Sunwise by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/report-search/`
- **Base URL:** `https://production.sunwise.ai/boty/api/v1`
- **Official documentation:** [Search Reports](https://production.sunwise.ai/boty/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | yes |
