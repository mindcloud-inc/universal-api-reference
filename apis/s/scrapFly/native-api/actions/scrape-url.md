# Scrape URL with ScrapFly

Retrieves a scraped page from ScrapFly.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape`
- **Base URL:** `https://api.scrapfly.io`
- **Official documentation:** [Scrape URL](https://scrapfly.io/docs/scrape-api/getting-started)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Target URL to scrape. |
