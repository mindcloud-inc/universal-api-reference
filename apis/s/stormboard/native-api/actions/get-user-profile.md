# Get User Profile with Stormboard

Retrieves your Stormboard user profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/profile`
- **Base URL:** `https://api.stormboard.com`
- **Official documentation:** [Get User Profile](https://api.stormboard.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | Updated email address. |
| `firstname` | body | `string` | no | Updated first name. |
| `lastname` | body | `string` | no | Updated last name. |
| `username` | body | `string` | no | Updated username. |
