# Delete Idea with Stormboard

Deletes an idea from Stormboard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ideas/:idea_id`
- **Base URL:** `https://api.stormboard.com`
- **Official documentation:** [Delete Idea](https://api.stormboard.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idea_id` | path | `number` | yes | Idea ID from a Stormboard idea record. |
