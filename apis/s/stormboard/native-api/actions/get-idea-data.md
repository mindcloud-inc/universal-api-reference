# Get Idea Data with Stormboard

Retrieves idea data from Stormboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/ideas/:idea_id`
- **Base URL:** `https://api.stormboard.com`
- **Official documentation:** [Get Idea Data](https://api.stormboard.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idea_id` | path | `number` | yes | Idea ID from a Stormboard idea record. |
