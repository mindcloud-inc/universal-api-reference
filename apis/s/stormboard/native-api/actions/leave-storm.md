# Leave Storm with Stormboard

Leaves a Storm in Stormboard.

## Endpoint

- **Method:** `POST`
- **Path:** `/storms/:storm_id/leave`
- **Base URL:** `https://api.stormboard.com`
- **Official documentation:** [Leave Storm](https://api.stormboard.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storm_id` | path | `number` | yes | Storm ID from the Stormboard share dialog or related storm record. |
