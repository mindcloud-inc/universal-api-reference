# Get Transaction Type with Spondyr

Retrieves a transaction type from Spondyr.

## Endpoint

- **Method:** `GET`
- **Path:** `/TransactionType`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [Get Transaction Type](https://client.spondyr.io/Public/Public/APIDocumentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TransactionType` | query | `string` | yes | The transaction type name to retrieve. |
