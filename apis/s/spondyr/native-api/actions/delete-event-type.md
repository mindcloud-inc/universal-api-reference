# Delete Event Type with Spondyr

Deletes an existing event type for a transaction type from Spondyr.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/EventType`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [Delete Event Type](https://client.spondyr.io/Public/Public/APIDocumentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `EventType` | query | `string` | yes | The event type name to delete. |
