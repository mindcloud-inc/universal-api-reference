# List Transaction Types with Spondyr

Retrieves transaction types from Spondyr.

## Endpoint

- **Method:** `GET`
- **Path:** `/TransactionTypes`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [List Transaction Types](https://client.spondyr.io/Public/Public/APIDocumentation)
