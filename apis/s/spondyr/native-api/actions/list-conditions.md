# List Conditions with Spondyr

Retrieves conditions for a transaction type in Spondyr.

## Endpoint

- **Method:** `GET`
- **Path:** `/Conditions`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [List Conditions](https://client.spondyr.io/Public/Public/APIDocumentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TransactionType` | query | `string` | no | Optional transaction type filter. |
