# Get Event Type with Spondyr

Retrieves an event type for a transaction type in Spondyr.

## Endpoint

- **Method:** `GET`
- **Path:** `/EventType`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [Get Event Type](https://client.spondyr.io/Public/Public/APIDocumentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `EventType` | query | `string` | yes | The event type name to retrieve. |
