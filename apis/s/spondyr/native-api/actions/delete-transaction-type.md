# Delete Transaction Type with Spondyr

Deletes an existing transaction type from Spondyr.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/TransactionType`
- **Base URL:** `https://client.spondyr.io/api/v1.0.0/`
- **Official documentation:** [Delete Transaction Type](https://client.spondyr.io/Public/Public/APIDocumentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TransactionType` | query | `string` | yes | The transaction type name to delete. |
