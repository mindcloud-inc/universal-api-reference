# Remove User with Smartcar

Deletes an existing user from Smartcar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Remove User](https://smartcar.com/docs/api-reference/remove-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The Smartcar user ID to delete. |
