# Remove Subscription with Smartcar

Deletes an existing subscription from Smartcar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://management.api.smartcar.com/v3/subscriptions/:subscriptionId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Remove Subscription](https://smartcar.com/docs/api-reference/remove-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | The unique identifier for the subscription to remove. |
