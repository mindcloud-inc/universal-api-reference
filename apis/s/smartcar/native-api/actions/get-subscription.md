# Get Subscription with Smartcar

Retrieves a subscription from Smartcar.

## Endpoint

- **Method:** `GET`
- **Path:** `https://management.api.smartcar.com/v3/subscriptions/:subscriptionId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Get Subscription](https://smartcar.com/docs/api-reference/get-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | The unique identifier for the subscription. |
