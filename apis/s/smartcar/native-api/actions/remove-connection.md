# Remove Connection with Smartcar

Deletes an existing connection from Smartcar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/connections/:connectionId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Remove Connection](https://smartcar.com/docs/api-reference/remove-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | The unique identifier for the connection to remove. |
