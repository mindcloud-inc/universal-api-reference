# Get Connection with Smartcar

Retrieves a connection from Smartcar.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/:connectionId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Get Connection](https://smartcar.com/docs/api-reference/get-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | The unique identifier for the connection. |
