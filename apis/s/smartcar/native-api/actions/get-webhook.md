# Get Webhook with Smartcar

Retrieves a webhook endpoint from Smartcar.

## Endpoint

- **Method:** `GET`
- **Path:** `https://management.api.smartcar.com/v3/webhooks/:webhookId`
- **Base URL:** `https://vehicle.api.smartcar.com/v3`
- **API:** rest
- **Official documentation:** [Get Webhook](https://smartcar.com/docs/api-reference/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The unique identifier for the webhook. |
