# Delete Product with Sellty

## Endpoint

- **Method:** `POST`
- **Path:** `/seller/api/v-1-0/delete-product`
- **Base URL:** `https://my.sellty.ru`
- **Official documentation:** [Delete Product](https://my.sellty.ru/seller/docs/api-docs.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendor_code` | body | `string` | yes | Product SKU/vendor code to delete. |
