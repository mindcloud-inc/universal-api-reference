# Get Batch Scrape Job Errors with Scrapeless

Retrieves batch scrape job errors from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/crawler/scrape/batch/:id/errors`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Batch Scrape Job Errors](https://apidocs.scrapeless.com/api-17509006)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
