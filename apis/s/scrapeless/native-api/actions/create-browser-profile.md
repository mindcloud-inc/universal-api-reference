# Create Browser Profile with Scrapeless

Creates a new browser profile in Scrapeless.

## Endpoint

- **Method:** `POST`
- **Path:** `/browser/profiles`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Create Browser Profile](https://apidocs.scrapeless.com/api-19188049)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
