# Update Browser Profile with Scrapeless

Updates an existing browser profile in Scrapeless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/browser/profiles/:profileId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Update Browser Profile](https://apidocs.scrapeless.com/api-19188050)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | profile id |
| `name` | body | `string` | yes | — |
