# Get Crawl Job Status with Scrapeless

Retrieves a crawl job status from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/crawler/crawl/:id`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Crawl Job Status](https://apidocs.scrapeless.com/api-17509007)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
