# Get Scrape Job Status with Scrapeless

Retrieves a scrape job status from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/crawler/scrape/:id`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Scrape Job Status](https://apidocs.scrapeless.com/api-17644667)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
