# Get Batch Scrape Job Status with Scrapeless

Retrieves a batch scrape job status from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/crawler/scrape/batch/:id`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Batch Scrape Job Status](https://apidocs.scrapeless.com/api-17509004)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
