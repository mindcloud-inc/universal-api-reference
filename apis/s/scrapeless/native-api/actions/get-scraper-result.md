# Get Scraper Result with Scrapeless

Retrieves a scraper result from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/scraper/result/:taskId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Scraper Result](https://apidocs.scrapeless.com/api-11949853)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `taskId` | path | `string` | yes |
