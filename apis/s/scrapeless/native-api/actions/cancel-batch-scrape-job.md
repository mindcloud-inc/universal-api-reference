# Cancel Batch Scrape Job with Scrapeless

Deletes a batch scrape job from Scrapeless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/crawler/scrape/batch/:id`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Cancel Batch Scrape Job](https://apidocs.scrapeless.com/api-17509005)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
