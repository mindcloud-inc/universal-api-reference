# Get Browser Profile with Scrapeless

Retrieves a browser profile from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser/profiles/:profileId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Browser Profile](https://apidocs.scrapeless.com/api-19188052)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | profile id |
