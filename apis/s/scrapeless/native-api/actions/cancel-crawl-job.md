# Cancel Crawl Job with Scrapeless

Deletes a crawl job from Scrapeless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/crawler/crawl/:id`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Cancel Crawl Job](https://apidocs.scrapeless.com/api-17509008)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
