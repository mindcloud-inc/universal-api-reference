# Delete Browser Profile with Scrapeless

Deletes a browser profile from Scrapeless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/browser/profiles/:profileId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Delete Browser Profile](https://apidocs.scrapeless.com/api-19188051)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | profile id |
