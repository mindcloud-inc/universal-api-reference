# Get Browser Extension with Scrapeless

Retrieves a browser extension from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser/extensions/:extensionId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Browser Extension](https://apidocs.scrapeless.com/api-18350563)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `extensionId` | path | `string` | yes |
