# Get Crawl Job Errors with Scrapeless

Retrieves crawl job errors from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/crawler/crawl/:id/errors`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Crawl Job Errors](https://apidocs.scrapeless.com/api-17509009)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
