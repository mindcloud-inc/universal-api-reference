# Revoke 1Password Authorization with Scrapeless

Deletes the 1Password authorization from Scrapeless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/browser/one-password/token`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Revoke 1Password Authorization](https://apidocs.scrapeless.com/api-23850712)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `x-api-token` | query | `string` | no | API key for authentication |
