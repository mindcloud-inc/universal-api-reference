# Delete Browser Extension with Scrapeless

Deletes a browser extension from Scrapeless.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/browser/extensions/:extensionId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Delete Browser Extension](https://apidocs.scrapeless.com/api-18350374)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `extensionId` | path | `string` | yes |
