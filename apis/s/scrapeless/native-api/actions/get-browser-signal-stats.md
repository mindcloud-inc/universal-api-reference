# Get Browser Signal Stats with Scrapeless

Retrieves browser signal stats from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser/:taskId/signal/stats`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Browser Signal Stats](https://apidocs.scrapeless.com/api-24795289)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | — |
| `x-api-token` | query | `string` | no | API Key |
