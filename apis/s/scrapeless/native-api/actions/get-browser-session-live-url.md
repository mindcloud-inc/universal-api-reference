# Get Browser Session Live URL with Scrapeless

Retrieves a browser session live URL from Scrapeless.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser/:taskId/live`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Get Browser Session Live URL](https://apidocs.scrapeless.com/api-16891208)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `taskId` | path | `string` | yes |
