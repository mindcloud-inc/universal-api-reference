# Update Browser Extension with Scrapeless

Updates an existing browser extension in Scrapeless.

## Endpoint

- **Method:** `PUT`
- **Path:** `/browser/extensions/:extensionId`
- **Base URL:** `https://api.scrapeless.com`
- **Official documentation:** [Update Browser Extension](https://apidocs.scrapeless.com/api-18350271)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `extensionId` | path | `string` | yes |
