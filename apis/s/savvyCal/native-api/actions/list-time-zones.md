# List Time Zones with SavvyCal

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/time_zones`
- **Base URL:** `https://api.savvycal.com`
- **Official documentation:** [List Time Zones](https://developers.savvycal.com/api/list-time-zones)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `instant` | query | `date` | no |
| `include_legacy` | query | `boolean` | no |
