# Get Time Zone with SavvyCal

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/time_zones/:segments`
- **Base URL:** `https://api.savvycal.com`
- **Official documentation:** [Get Time Zone](https://developers.savvycal.com/api/get-time-zone)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segments` | path | `string` | yes |
| `instant` | query | `date` | no |
