# Get Webhook with SavvyCal

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:webhook_id`
- **Base URL:** `https://api.savvycal.com`
- **Official documentation:** [Get Webhook](https://developers.savvycal.com/api/get-webhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes |
