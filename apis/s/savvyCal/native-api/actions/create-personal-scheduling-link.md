# Create Personal Scheduling Link with SavvyCal

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/links`
- **Base URL:** `https://api.savvycal.com`
- **Official documentation:** [Create Personal Scheduling Link](https://developers.savvycal.com/api/create-personal-scheduling-link)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
| `private_name` | body | `string` | no |
| `type` | body | `string` | no |
