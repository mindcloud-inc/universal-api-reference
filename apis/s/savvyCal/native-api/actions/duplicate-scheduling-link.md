# Duplicate Scheduling Link with SavvyCal

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/links/:link_id/duplicate`
- **Base URL:** `https://api.savvycal.com`
- **Official documentation:** [Duplicate Scheduling Link](https://developers.savvycal.com/api/duplicate-scheduling-link)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `link_id` | path | `string` | yes |
