# List Products with Smart Sender

Retrieves project products from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [List Products](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/97255432)

## Capabilities

This operation supports [pagination](../README.md#pagination).
