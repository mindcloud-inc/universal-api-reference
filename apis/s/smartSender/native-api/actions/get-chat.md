# Get Chat with Smart Sender

Retrieves a chat from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/chats/:chatId`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Get Chat](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676542648/Chats%2BAPI%2B-%2Ben)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | The Smart Sender chat ID. |
