# Get Channel with Smart Sender

Retrieves a channel from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/channels/:channelId`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Get Channel](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676444598/Channels%2BAPI%2B-%2Ben)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The Smart Sender channel ID. |
