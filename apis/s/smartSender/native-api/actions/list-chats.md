# List Chats with Smart Sender

Retrieves project chats from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/chats`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [List Chats](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676542648/Chats%2BAPI%2B-%2Ben)

## Capabilities

This operation supports [pagination](../README.md#pagination).
