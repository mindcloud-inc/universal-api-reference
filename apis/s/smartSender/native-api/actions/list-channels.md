# List Channels with Smart Sender

Retrieves project channels from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/channels`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [List Channels](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676444598/Channels%2BAPI%2B-%2Ben)

## Capabilities

This operation supports [pagination](../README.md#pagination).
