# Get Contact Info with Smart Sender

Retrieves simplified contact details from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:contactId/info`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Get Contact Info](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676444281/Contacts%2BAPI%2B-%2Ben)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Smart Sender contact ID. |
