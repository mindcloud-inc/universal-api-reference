# List Variables with Smart Sender

Retrieves project variables from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/variables`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [List Variables](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676575629/Variables%2BAPI%2B-%2Ben)

## Capabilities

This operation supports [pagination](../README.md#pagination).
