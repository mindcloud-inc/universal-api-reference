# Close Chat with Smart Sender

Closes a chat in Smart Sender.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/chats/:chatId/close`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Close Chat](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676542648/Chats%2BAPI%2B-%2Ben)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | The Smart Sender chat ID. |
