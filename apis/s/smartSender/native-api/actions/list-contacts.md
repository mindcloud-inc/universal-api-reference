# List Contacts with Smart Sender

Retrieves project contacts from Smart Sender.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [List Contacts](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676444281/Contacts%2BAPI%2B-%2Ben)

## Capabilities

This operation supports [pagination](../README.md#pagination).
