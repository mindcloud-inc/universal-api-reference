# Delete Variable with Smart Sender

Deletes an existing variable from Smart Sender.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/variables/:variableId`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Delete Variable](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/1676575629/Variables%2BAPI%2B-%2Ben)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variableId` | path | `string` | yes | The Smart Sender variable ID. |
