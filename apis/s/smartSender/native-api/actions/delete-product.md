# Delete Product with Smart Sender

Deletes an existing product from Smart Sender.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/products/:productId`
- **Base URL:** `https://api.smartsender.com`
- **Official documentation:** [Delete Product](https://smartsendereu.atlassian.net/wiki/spaces/docsru/pages/97255432)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The Smart Sender product ID. |
