# Generate SEO Title with SEO GPT

## Endpoint

- **Method:** `GET`
- **Path:** `/gpt-get-chrome.php`
- **Base URL:** `https://ai.seovendor.co`
- **Official documentation:** [Generate SEO Title](https://chromewebstore.google.com/detail/seo-gpt/cohpigckifhbbggfedenhafihmmpidkm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kw` | query | `string` | yes | Keyword or phrase to use for title generation. |
| `web` | query | `string` | no | Optional page URL to analyze before generating the title. |
| `brand` | query | `string` | no | Optional brand name to include in the generated title. |
