# Generate Product Description with SEO GPT

## Endpoint

- **Method:** `GET`
- **Path:** `/gpt-get-chrome.php`
- **Base URL:** `https://ai.seovendor.co`
- **Official documentation:** [Generate Product Description](https://seovendor.co/seo-gpt-content-manual-the-complete-guide-free/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kw` | query | `string` | yes | Keyword or phrase to use for the generated copy. |
| `web` | query | `string` | no | Optional page URL to analyze before generating the copy. |
| `brand` | query | `string` | no | Optional brand name to include in the generated copy. |
