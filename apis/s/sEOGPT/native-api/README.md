# SEO GPT: Native API Reference

A consolidated summary of SEO GPT's API configuration and 20 documented operations, with links to official documentation.

- **API base URL:** `https://ai.seovendor.co`

## Authentication

### API Key

Connect with the API KEY from your SEO Vendor Profile Settings page.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
Authorization: Bearer <apiKey>
```

[Official authentication documentation](https://seovendor.co/new-seo-gpt-chrome-plugin-released/)
