# Delete Team with SweetProcess

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:id/`
- **Base URL:** `https://www.sweetprocess.com/api/v1`
- **Official documentation:** [Delete Team](https://www.sweetprocess.com/kb/8LBTequD/article/L4CaqHMav/interim-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric SweetProcess team ID. |
