# List Users with SweetProcess

Retrieves users from SweetProcess.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/`
- **Base URL:** `https://www.sweetprocess.com/api/v1`
- **Official documentation:** [List Users](https://www.sweetprocess.com/kb/8LBTequD/article/L4CaqHMav/interim-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | no | Filter users by the numeric SweetProcess user ID. |
