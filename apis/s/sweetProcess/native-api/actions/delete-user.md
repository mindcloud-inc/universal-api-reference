# Delete User with SweetProcess

Deletes an existing teammate from SweetProcess.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id/`
- **Base URL:** `https://www.sweetprocess.com/api/v1`
- **Official documentation:** [Delete User](https://www.sweetprocess.com/kb/8LBTequD/article/L4CaqHMav/interim-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric SweetProcess user ID. |
