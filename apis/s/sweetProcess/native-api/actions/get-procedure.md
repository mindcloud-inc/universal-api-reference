# Get Procedure with SweetProcess

Retrieves a procedure from SweetProcess.

## Endpoint

- **Method:** `GET`
- **Path:** `/procedures/:id/`
- **Base URL:** `https://www.sweetprocess.com/api/v1`
- **Official documentation:** [Get Procedure](https://www.sweetprocess.com/kb/8LBTequD/article/y9C9fKdyD/integrating-sweetprocess-with-chatgpt-via-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The numeric SweetProcess procedure ID. |
