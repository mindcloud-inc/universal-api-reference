# Create Team with SweetProcess

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/`
- **Base URL:** `https://www.sweetprocess.com/api/v1`
- **Official documentation:** [Create Team](https://www.sweetprocess.com/kb/8LBTequD/article/L4CaqHMav/interim-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The SweetProcess team name. |
| `description` | body | `string` | no | Optional team description. |
