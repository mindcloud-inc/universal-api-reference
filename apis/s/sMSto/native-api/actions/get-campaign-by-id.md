# Get Campaign by ID with SMS.to

Retrieves a campaign by ID from SMS.to.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/campaigns/:id`
- **Base URL:** `https://api.sms.to`
- **Official documentation:** [Get Campaign by ID](https://developers.sms.to/#6325eaae-8d7c-434d-aca4-0ba43e04dbc6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign identifier. |
