# Get Message by ID with SMS.to

Retrieves a sent message by ID from SMS.to.

## Endpoint

- **Method:** `GET`
- **Path:** `/message/:id`
- **Base URL:** `https://api.sms.to`
- **Official documentation:** [Get Message by ID](https://developers.sms.to/#eb39c6ad-e1c8-4a6a-8d2d-f04122315fb3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Message identifier. |
