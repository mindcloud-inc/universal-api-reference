# Get Last Message with SMS.to

Retrieves the most recent sent message from SMS.to.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/last/message`
- **Base URL:** `https://api.sms.to`
- **Official documentation:** [Get Last Message](https://developers.sms.to/#f168467f-e0fe-463f-a949-34801631fcc5)
