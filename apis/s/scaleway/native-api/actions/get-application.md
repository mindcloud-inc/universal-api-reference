# Get Application with Scaleway

Retrieves an application from Scaleway.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v1alpha1/applications/:application_id`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [Get Application](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `application_id` | path | `string` | yes |
