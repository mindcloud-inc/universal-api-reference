# List Projects with Scaleway

Retrieves projects from Scaleway for an organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/v3/projects`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [List Projects](https://www.scaleway.com/en/developers/api/account/project-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | query | `string` | yes | Organization ID to list projects for. |
