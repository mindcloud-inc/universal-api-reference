# List Groups with Scaleway

Retrieves groups from Scaleway for an organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v1alpha1/groups`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [List Groups](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization_id` | query | `string` | no |
