# Get Group with Scaleway

Retrieves a group from Scaleway.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v1alpha1/groups/:group_id`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [Get Group](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | yes |
