# Get SSH Key with Scaleway

Retrieves an SSH key from Scaleway.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v1alpha1/ssh-keys/:ssh_key_id`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [Get SSH Key](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ssh_key_id` | path | `string` | yes |
