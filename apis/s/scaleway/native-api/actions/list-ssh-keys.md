# List SSH Keys with Scaleway

Retrieves SSH keys from Scaleway for a project.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v1alpha1/ssh-keys`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [List SSH Keys](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | query | `string` | no |
