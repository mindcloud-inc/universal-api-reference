# Delete Group with Scaleway

Deletes an existing group from Scaleway.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/iam/v1alpha1/groups/:group_id`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [Delete Group](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | yes |
