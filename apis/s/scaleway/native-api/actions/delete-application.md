# Delete Application with Scaleway

Deletes an existing application from Scaleway.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/iam/v1alpha1/applications/:application_id`
- **Base URL:** `https://api.scaleway.com`
- **Official documentation:** [Delete Application](https://www.scaleway.com/en/developers/api/iam/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `application_id` | path | `string` | yes |
