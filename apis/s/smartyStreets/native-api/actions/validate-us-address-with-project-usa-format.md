# Validate US Address With Project USA Format with Smarty-streets

Retrieves a validated US address from Smarty-streets in Project USA format.

## Endpoint

- **Method:** `GET`
- **Path:** `https://us-street.api.smarty.com/street-address`
- **Base URL:** `https://us-street.api.smarty.com`
- **Official documentation:** [Validate US Address With Project USA Format](https://www.smarty.com/docs/apis/us-street-api/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `street` | query | `string` | yes | Address text to verify. |
