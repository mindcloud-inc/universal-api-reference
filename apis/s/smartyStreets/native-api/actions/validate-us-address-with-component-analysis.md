# Validate US Address With Component Analysis with Smarty-streets

Retrieves US address validation details from Smarty-streets with component analysis.

## Endpoint

- **Method:** `GET`
- **Path:** `https://us-street.api.smarty.com/street-address`
- **Base URL:** `https://us-street.api.smarty.com`
- **Official documentation:** [Validate US Address With Component Analysis](https://www.smarty.com/docs/apis/us-street-api/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `street` | query | `string` | yes | Address text to verify and inspect component analysis. |
