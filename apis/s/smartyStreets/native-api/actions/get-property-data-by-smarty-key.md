# Get Property Data By SmartyKey with Smarty-streets

Retrieves property data from Smarty-streets by SmartyKey.

## Endpoint

- **Method:** `GET`
- **Path:** `https://us-enrichment.api.smarty.com/lookup/{smartyKey}/property`
- **Base URL:** `https://us-street.api.smarty.com`
- **Official documentation:** [Get Property Data By SmartyKey](https://www.smarty.com/docs/apis/us-enrichment-api/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smartyKey` | path | `string` | yes | SmartyKey for the address record. |
