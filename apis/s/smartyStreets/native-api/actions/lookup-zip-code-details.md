# Lookup ZIP Code Details with Smarty-streets

Retrieves ZIP Code details from Smarty-streets.

## Endpoint

- **Method:** `GET`
- **Path:** `https://us-zipcode.api.smarty.com/lookup`
- **Base URL:** `https://us-street.api.smarty.com`
- **Official documentation:** [Lookup ZIP Code Details](https://www.smarty.com/docs/apis/us-zipcode-api/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `zipcode` | query | `string` | yes | ZIP Code to look up. |
