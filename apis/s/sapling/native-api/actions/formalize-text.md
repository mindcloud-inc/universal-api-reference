# Formalize Text with Sapling

Rewrites text in a more formal style with Sapling.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/rephrase`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Formalize Text](https://sapling.ai/docs/api/rephrase/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Input text to formalize. |
