# Remove Custom Mapping with Sapling

Deletes a custom mapping from Sapling.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/custom_mapping/:customMappingId`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Remove Custom Mapping](https://sapling.ai/docs/api/custom-mappings/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customMappingId` | path | `string` | yes | ID of the custom mapping to delete. |
