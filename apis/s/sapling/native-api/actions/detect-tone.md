# Detect Tone with Sapling

Detects tone in text with Sapling.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tone`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Detect Tone](https://sapling.ai/docs/api/tone/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Text to analyze the tone for. |
