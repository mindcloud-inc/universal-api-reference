# Rewrite in Active Voice with Sapling

Rewrites text in active voice with Sapling.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/rephrase`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Rewrite in Active Voice](https://sapling.ai/docs/api/rephrase/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Input text to rewrite in active voice. |
