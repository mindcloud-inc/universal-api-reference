# Analyze Sentiment with Sapling

Analyzes sentiment in text with Sapling.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/sentiment`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Analyze Sentiment](https://sapling.ai/docs/api/sentiment/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Text to analyze the sentiment for. |
