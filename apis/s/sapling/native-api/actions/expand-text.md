# Expand Text with Sapling

Expands text with additional detail using Sapling.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/rephrase`
- **Base URL:** `https://api.sapling.ai`
- **Official documentation:** [Expand Text](https://sapling.ai/docs/api/rephrase/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Input text to expand. |
