# Download China annual as reported bank derived fundamentals dataset with SimFin

Retrieves the China annual as reported bank derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-banks&variant=annual-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual as reported bank derived fundamentals dataset](https://github.com/SimFin/simfin)
