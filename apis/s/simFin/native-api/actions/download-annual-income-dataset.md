# Download annual income dataset with SimFin

Retrieves the annual income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download annual income dataset](https://github.com/SimFin/simfin)
