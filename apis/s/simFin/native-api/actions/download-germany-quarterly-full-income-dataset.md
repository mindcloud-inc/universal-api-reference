# Download Germany quarterly full income dataset with SimFin

Retrieves the Germany quarterly full income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly full income dataset](https://github.com/SimFin/simfin)
