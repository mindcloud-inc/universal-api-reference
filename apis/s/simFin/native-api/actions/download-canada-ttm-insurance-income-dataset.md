# Download Canada TTM insurance income dataset with SimFin

Retrieves the Canada TTM insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM insurance income dataset](https://github.com/SimFin/simfin)
