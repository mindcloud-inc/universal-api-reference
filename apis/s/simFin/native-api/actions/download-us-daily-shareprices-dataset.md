# Download US daily shareprices dataset with SimFin

Retrieves the US daily shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US daily shareprices dataset](https://github.com/SimFin/simfin)
