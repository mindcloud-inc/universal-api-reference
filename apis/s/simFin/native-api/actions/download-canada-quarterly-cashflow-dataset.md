# Download Canada quarterly cashflow dataset with SimFin

Retrieves the Canada quarterly cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=quarterly&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly cashflow dataset](https://github.com/SimFin/simfin)
