# Download Germany annual full cashflow dataset with SimFin

Retrieves the Germany annual full cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual full cashflow dataset](https://github.com/SimFin/simfin)
