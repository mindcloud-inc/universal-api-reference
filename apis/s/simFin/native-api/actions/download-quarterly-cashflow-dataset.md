# Download quarterly cashflow dataset with SimFin

Retrieves the quarterly cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly cashflow dataset](https://github.com/SimFin/simfin)
