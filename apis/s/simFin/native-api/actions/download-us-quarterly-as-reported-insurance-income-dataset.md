# Download US quarterly as reported insurance income dataset with SimFin

Retrieves the US quarterly as reported insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=quarterly-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US quarterly as reported insurance income dataset](https://github.com/SimFin/simfin)
