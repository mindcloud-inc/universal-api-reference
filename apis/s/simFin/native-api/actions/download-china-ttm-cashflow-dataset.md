# Download China TTM cashflow dataset with SimFin

Retrieves the China TTM cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM cashflow dataset](https://github.com/SimFin/simfin)
