# Download Germany annual balance dataset with SimFin

Retrieves the Germany annual balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual balance dataset](https://github.com/SimFin/simfin)
