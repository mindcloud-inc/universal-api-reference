# Download Germany companies dataset with SimFin

Retrieves the Germany companies dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=companies&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany companies dataset](https://github.com/SimFin/simfin)
