# Download quarterly bank income dataset with SimFin

Retrieves the quarterly bank income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-banks&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly bank income dataset](https://github.com/SimFin/simfin)
