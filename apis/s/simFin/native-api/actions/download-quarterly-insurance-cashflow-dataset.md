# Download quarterly insurance cashflow dataset with SimFin

Retrieves the quarterly insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly insurance cashflow dataset](https://github.com/SimFin/simfin)
