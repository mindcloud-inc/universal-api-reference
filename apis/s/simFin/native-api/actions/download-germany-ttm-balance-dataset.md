# Download Germany TTM balance dataset with SimFin

Retrieves the Germany TTM balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=ttm&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM balance dataset](https://github.com/SimFin/simfin)
