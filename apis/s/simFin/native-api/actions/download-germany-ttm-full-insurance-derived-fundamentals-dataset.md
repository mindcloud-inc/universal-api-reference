# Download Germany TTM full insurance derived fundamentals dataset with SimFin

Retrieves the Germany TTM full insurance derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-insurance&variant=ttm-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM full insurance derived fundamentals dataset](https://github.com/SimFin/simfin)
