# Download Canada daily derived shareprices dataset with SimFin

Retrieves the Canada daily derived shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-shareprices&variant=daily&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada daily derived shareprices dataset](https://github.com/SimFin/simfin)
