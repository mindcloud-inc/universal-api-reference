# Download Canada TTM full insurance balance dataset with SimFin

Retrieves the Canada TTM full insurance balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-insurance&variant=ttm-full&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM full insurance balance dataset](https://github.com/SimFin/simfin)
