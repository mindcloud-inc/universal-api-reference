# Download TTM bank balance dataset with SimFin

Retrieves the TTM bank balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-banks&variant=ttm&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download TTM bank balance dataset](https://github.com/SimFin/simfin)
