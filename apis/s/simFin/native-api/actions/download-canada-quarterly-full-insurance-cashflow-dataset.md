# Download Canada quarterly full insurance cashflow dataset with SimFin

Retrieves the Canada quarterly full insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=quarterly-full&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly full insurance cashflow dataset](https://github.com/SimFin/simfin)
