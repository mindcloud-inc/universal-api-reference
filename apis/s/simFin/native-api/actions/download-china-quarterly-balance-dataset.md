# Download China quarterly balance dataset with SimFin

Retrieves the China quarterly balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=quarterly&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China quarterly balance dataset](https://github.com/SimFin/simfin)
