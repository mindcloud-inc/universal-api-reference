# Download Germany TTM bank income dataset with SimFin

Retrieves the Germany TTM bank income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-banks&variant=ttm&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM bank income dataset](https://github.com/SimFin/simfin)
