# Download Canada TTM full income dataset with SimFin

Retrieves the Canada TTM full income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=ttm-full&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM full income dataset](https://github.com/SimFin/simfin)
