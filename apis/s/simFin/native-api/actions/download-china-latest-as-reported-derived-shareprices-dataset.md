# Download China latest as reported derived shareprices dataset with SimFin

Retrieves the China latest as reported derived shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-shareprices&variant=latest-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China latest as reported derived shareprices dataset](https://github.com/SimFin/simfin)
