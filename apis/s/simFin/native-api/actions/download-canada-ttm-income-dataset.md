# Download Canada TTM income dataset with SimFin

Retrieves the Canada TTM income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM income dataset](https://github.com/SimFin/simfin)
