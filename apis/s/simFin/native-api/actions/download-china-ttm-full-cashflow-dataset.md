# Download China TTM full cashflow dataset with SimFin

Retrieves the China TTM full cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm-full&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM full cashflow dataset](https://github.com/SimFin/simfin)
