# Download annual bank balance dataset with SimFin

Retrieves the annual bank balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-banks&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download annual bank balance dataset](https://github.com/SimFin/simfin)
