# Download China TTM bank derived fundamentals dataset with SimFin

Retrieves the China TTM bank derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-banks&variant=ttm&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM bank derived fundamentals dataset](https://github.com/SimFin/simfin)
