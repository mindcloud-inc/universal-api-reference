# Download quarterly bank cashflow dataset with SimFin

Retrieves the quarterly bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly bank cashflow dataset](https://github.com/SimFin/simfin)
