# Download US quarterly derived fundamentals dataset with SimFin

Retrieves the US quarterly derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US quarterly derived fundamentals dataset](https://github.com/SimFin/simfin)
