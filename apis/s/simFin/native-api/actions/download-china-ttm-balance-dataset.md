# Download China TTM balance dataset with SimFin

Retrieves the China TTM balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=ttm&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM balance dataset](https://github.com/SimFin/simfin)
