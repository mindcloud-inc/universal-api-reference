# Download Germany TTM full as reported insurance cashflow dataset with SimFin

Retrieves the Germany TTM full as reported insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=ttm-full-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM full as reported insurance cashflow dataset](https://github.com/SimFin/simfin)
