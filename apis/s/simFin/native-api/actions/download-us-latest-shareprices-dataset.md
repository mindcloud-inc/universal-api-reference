# Download US latest shareprices dataset with SimFin

Retrieves the US latest shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=latest&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US latest shareprices dataset](https://github.com/SimFin/simfin)
