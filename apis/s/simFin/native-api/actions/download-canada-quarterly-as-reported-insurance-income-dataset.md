# Download Canada quarterly as reported insurance income dataset with SimFin

Retrieves the Canada quarterly as reported insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=quarterly-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly as reported insurance income dataset](https://github.com/SimFin/simfin)
