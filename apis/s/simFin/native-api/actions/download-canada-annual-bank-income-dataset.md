# Download Canada annual bank income dataset with SimFin

Retrieves the Canada annual bank income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-banks&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual bank income dataset](https://github.com/SimFin/simfin)
