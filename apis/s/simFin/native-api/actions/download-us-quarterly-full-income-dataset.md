# Download US quarterly full income dataset with SimFin

Retrieves the US quarterly full income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly-full&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US quarterly full income dataset](https://github.com/SimFin/simfin)
