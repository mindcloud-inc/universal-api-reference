# Download Canada TTM bank cashflow dataset with SimFin

Retrieves the Canada TTM bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM bank cashflow dataset](https://github.com/SimFin/simfin)
