# Download China daily shareprices dataset with SimFin

Retrieves the China daily shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China daily shareprices dataset](https://github.com/SimFin/simfin)
