# Download China TTM full insurance derived fundamentals dataset with SimFin

Retrieves the China TTM full insurance derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-insurance&variant=ttm-full&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM full insurance derived fundamentals dataset](https://github.com/SimFin/simfin)
