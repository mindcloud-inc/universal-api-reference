# Download Canada annual insurance income dataset with SimFin

Retrieves the Canada annual insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual insurance income dataset](https://github.com/SimFin/simfin)
