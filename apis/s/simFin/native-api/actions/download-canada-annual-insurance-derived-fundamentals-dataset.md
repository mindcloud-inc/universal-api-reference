# Download Canada annual insurance derived fundamentals dataset with SimFin

Retrieves the Canada annual insurance derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-insurance&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual insurance derived fundamentals dataset](https://github.com/SimFin/simfin)
