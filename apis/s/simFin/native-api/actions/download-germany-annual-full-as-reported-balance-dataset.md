# Download Germany annual full as reported balance dataset with SimFin

Retrieves the Germany annual full as reported balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual-full-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual full as reported balance dataset](https://github.com/SimFin/simfin)
