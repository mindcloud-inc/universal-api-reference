# Download US TTM full cashflow dataset with SimFin

Retrieves the US TTM full cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm-full&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US TTM full cashflow dataset](https://github.com/SimFin/simfin)
