# Download Canada TTM full cashflow dataset with SimFin

Retrieves the Canada TTM full cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm-full&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM full cashflow dataset](https://github.com/SimFin/simfin)
