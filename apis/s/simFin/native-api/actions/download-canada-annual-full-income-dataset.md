# Download Canada annual full income dataset with SimFin

Retrieves the Canada annual full income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=annual-full&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual full income dataset](https://github.com/SimFin/simfin)
