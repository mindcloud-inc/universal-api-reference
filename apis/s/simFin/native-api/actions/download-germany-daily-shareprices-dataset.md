# Download Germany daily shareprices dataset with SimFin

Retrieves the Germany daily shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany daily shareprices dataset](https://github.com/SimFin/simfin)
