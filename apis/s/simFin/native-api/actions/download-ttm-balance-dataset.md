# Download TTM balance dataset with SimFin

Retrieves the TTM balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=ttm&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download TTM balance dataset](https://github.com/SimFin/simfin)
