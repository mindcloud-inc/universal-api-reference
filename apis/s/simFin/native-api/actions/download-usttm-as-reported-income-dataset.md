# Download US TTM as reported income dataset with SimFin

Retrieves the US TTM as reported income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=ttm-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US TTM as reported income dataset](https://github.com/SimFin/simfin)
