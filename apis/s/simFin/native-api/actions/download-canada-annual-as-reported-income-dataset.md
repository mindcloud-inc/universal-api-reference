# Download Canada annual as reported income dataset with SimFin

Retrieves the Canada annual as reported income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=annual-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual as reported income dataset](https://github.com/SimFin/simfin)
