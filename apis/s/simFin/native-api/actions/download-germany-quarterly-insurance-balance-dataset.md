# Download Germany quarterly insurance balance dataset with SimFin

Retrieves the Germany quarterly insurance balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-insurance&variant=quarterly&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly insurance balance dataset](https://github.com/SimFin/simfin)
