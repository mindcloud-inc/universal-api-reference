# Download Canada latest shareprices dataset with SimFin

Retrieves the Canada latest shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=latest&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada latest shareprices dataset](https://github.com/SimFin/simfin)
