# Download Germany quarterly as reported insurance derived fundamentals dataset with SimFin

Retrieves the Germany quarterly as reported insurance derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-insurance&variant=quarterly-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly as reported insurance derived fundamentals dataset](https://github.com/SimFin/simfin)
