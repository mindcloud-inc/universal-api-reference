# Download Canada TTM balance dataset with SimFin

Retrieves the Canada TTM balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM balance dataset](https://github.com/SimFin/simfin)
