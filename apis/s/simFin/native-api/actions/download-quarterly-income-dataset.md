# Download quarterly income dataset with SimFin

Retrieves the quarterly income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly income dataset](https://github.com/SimFin/simfin)
