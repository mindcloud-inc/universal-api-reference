# Download China annual balance dataset with SimFin

Retrieves the China annual balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual balance dataset](https://github.com/SimFin/simfin)
