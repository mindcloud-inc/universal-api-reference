# Download Canada quarterly full as reported income dataset with SimFin

Retrieves the Canada quarterly full as reported income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly-full-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly full as reported income dataset](https://github.com/SimFin/simfin)
