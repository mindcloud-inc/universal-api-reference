# Download annual cashflow dataset with SimFin

Retrieves the annual cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download annual cashflow dataset](https://github.com/SimFin/simfin)
