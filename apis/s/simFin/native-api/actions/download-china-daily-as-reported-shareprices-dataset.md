# Download China daily as reported shareprices dataset with SimFin

Retrieves the China daily as reported shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China daily as reported shareprices dataset](https://github.com/SimFin/simfin)
