# Download Germany TTM cashflow dataset with SimFin

Retrieves the Germany TTM cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM cashflow dataset](https://github.com/SimFin/simfin)
