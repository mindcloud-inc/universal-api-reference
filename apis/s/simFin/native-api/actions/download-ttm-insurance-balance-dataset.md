# Download TTM insurance balance dataset with SimFin

Retrieves the TTM insurance balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-insurance&variant=ttm&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download TTM insurance balance dataset](https://github.com/SimFin/simfin)
