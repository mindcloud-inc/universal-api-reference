# Download US latest as reported shareprices dataset with SimFin

Retrieves the US latest as reported shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=latest-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US latest as reported shareprices dataset](https://github.com/SimFin/simfin)
