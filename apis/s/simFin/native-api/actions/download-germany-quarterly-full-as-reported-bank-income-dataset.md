# Download Germany quarterly full as reported bank income dataset with SimFin

Retrieves the Germany quarterly full as reported bank income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-banks&variant=quarterly-full-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly full as reported bank income dataset](https://github.com/SimFin/simfin)
