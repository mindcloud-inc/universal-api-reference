# Download China annual as reported balance dataset with SimFin

Retrieves the China annual as reported balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual as reported balance dataset](https://github.com/SimFin/simfin)
