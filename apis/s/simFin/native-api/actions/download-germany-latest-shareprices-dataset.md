# Download Germany latest shareprices dataset with SimFin

Retrieves the Germany latest shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=latest&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany latest shareprices dataset](https://github.com/SimFin/simfin)
