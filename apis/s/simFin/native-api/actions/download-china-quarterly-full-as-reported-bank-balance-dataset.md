# Download China quarterly full as reported bank balance dataset with SimFin

Retrieves the China quarterly full as reported bank balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-banks&variant=quarterly-full-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China quarterly full as reported bank balance dataset](https://github.com/SimFin/simfin)
