# Download US companies dataset with SimFin

Retrieves the US companies dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=companies&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US companies dataset](https://github.com/SimFin/simfin)
