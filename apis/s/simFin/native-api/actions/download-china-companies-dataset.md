# Download China companies dataset with SimFin

Retrieves the China companies dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=companies&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China companies dataset](https://github.com/SimFin/simfin)
