# Download US annual derived fundamentals dataset with SimFin

Retrieves the US annual derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US annual derived fundamentals dataset](https://github.com/SimFin/simfin)
