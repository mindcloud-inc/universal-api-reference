# Download annual insurance income dataset with SimFin

Retrieves the annual insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download annual insurance income dataset](https://github.com/SimFin/simfin)
