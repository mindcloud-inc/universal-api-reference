# Download China annual insurance cashflow dataset with SimFin

Retrieves the China annual insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=annual&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual insurance cashflow dataset](https://github.com/SimFin/simfin)
