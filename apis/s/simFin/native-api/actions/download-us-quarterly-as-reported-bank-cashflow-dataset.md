# Download US quarterly as reported bank cashflow dataset with SimFin

Retrieves the US quarterly as reported bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=quarterly-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US quarterly as reported bank cashflow dataset](https://github.com/SimFin/simfin)
