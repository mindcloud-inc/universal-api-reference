# Download China annual income dataset with SimFin

Retrieves the China annual income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=annual&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual income dataset](https://github.com/SimFin/simfin)
