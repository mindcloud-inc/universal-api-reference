# Download China TTM insurance income dataset with SimFin

Retrieves the China TTM insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=ttm&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM insurance income dataset](https://github.com/SimFin/simfin)
