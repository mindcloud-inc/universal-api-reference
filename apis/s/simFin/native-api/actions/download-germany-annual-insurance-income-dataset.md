# Download Germany annual insurance income dataset with SimFin

Retrieves the Germany annual insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=annual&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual insurance income dataset](https://github.com/SimFin/simfin)
