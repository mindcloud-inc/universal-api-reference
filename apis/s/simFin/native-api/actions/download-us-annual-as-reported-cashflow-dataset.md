# Download US annual as reported cashflow dataset with SimFin

Retrieves the US annual as reported cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US annual as reported cashflow dataset](https://github.com/SimFin/simfin)
