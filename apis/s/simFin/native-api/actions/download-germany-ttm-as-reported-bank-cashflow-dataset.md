# Download Germany TTM as reported bank cashflow dataset with SimFin

Retrieves the Germany TTM as reported bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=ttm-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM as reported bank cashflow dataset](https://github.com/SimFin/simfin)
