# Download annual bank cashflow dataset with SimFin

Retrieves the annual bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=annual&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download annual bank cashflow dataset](https://github.com/SimFin/simfin)
