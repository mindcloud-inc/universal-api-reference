# Download Canada daily shareprices dataset with SimFin

Retrieves the Canada daily shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada daily shareprices dataset](https://github.com/SimFin/simfin)
