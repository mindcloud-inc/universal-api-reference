# Download Germany annual cashflow dataset with SimFin

Retrieves the Germany annual cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual cashflow dataset](https://github.com/SimFin/simfin)
