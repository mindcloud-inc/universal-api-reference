# Download China TTM as reported cashflow dataset with SimFin

Retrieves the China TTM as reported cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM as reported cashflow dataset](https://github.com/SimFin/simfin)
