# Download Canada TTM full as reported bank income dataset with SimFin

Retrieves the Canada TTM full as reported bank income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-banks&variant=ttm-full-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM full as reported bank income dataset](https://github.com/SimFin/simfin)
