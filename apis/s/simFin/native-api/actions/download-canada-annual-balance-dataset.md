# Download Canada annual balance dataset with SimFin

Retrieves the Canada annual balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual balance dataset](https://github.com/SimFin/simfin)
