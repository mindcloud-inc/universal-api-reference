# List SimFin bulk dataset metadata with SimFin

Retrieves SimFin bulk dataset metadata.

## Endpoint

- **Method:** `GET`
- **Path:** `info?type=datasets`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [List SimFin bulk dataset metadata](https://github.com/SimFin/simfin)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
