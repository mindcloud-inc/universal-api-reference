# Download China quarterly income dataset with SimFin

Retrieves the China quarterly income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China quarterly income dataset](https://github.com/SimFin/simfin)
