# Download China annual full derived fundamentals dataset with SimFin

Retrieves the China annual full derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=annual-full&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual full derived fundamentals dataset](https://github.com/SimFin/simfin)
