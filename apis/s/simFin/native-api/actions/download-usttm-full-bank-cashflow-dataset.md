# Download US TTM full bank cashflow dataset with SimFin

Retrieves the US TTM full bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=ttm-full&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US TTM full bank cashflow dataset](https://github.com/SimFin/simfin)
