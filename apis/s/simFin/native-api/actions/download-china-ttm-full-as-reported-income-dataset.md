# Download China TTM full as reported income dataset with SimFin

Retrieves the China TTM full as reported income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=ttm-full-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM full as reported income dataset](https://github.com/SimFin/simfin)
