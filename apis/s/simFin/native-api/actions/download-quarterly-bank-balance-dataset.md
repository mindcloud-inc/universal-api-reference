# Download quarterly bank balance dataset with SimFin

Retrieves the quarterly bank balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-banks&variant=quarterly&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download quarterly bank balance dataset](https://github.com/SimFin/simfin)
