# Download China annual insurance balance dataset with SimFin

Retrieves the China annual insurance balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-insurance&variant=annual&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual insurance balance dataset](https://github.com/SimFin/simfin)
