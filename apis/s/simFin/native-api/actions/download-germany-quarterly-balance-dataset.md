# Download Germany quarterly balance dataset with SimFin

Retrieves the Germany quarterly balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=quarterly&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly balance dataset](https://github.com/SimFin/simfin)
