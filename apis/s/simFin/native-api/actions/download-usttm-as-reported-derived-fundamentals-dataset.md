# Download US TTM as reported derived fundamentals dataset with SimFin

Retrieves the US TTM as reported derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=ttm-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US TTM as reported derived fundamentals dataset](https://github.com/SimFin/simfin)
