# Download TTM insurance cashflow dataset with SimFin

Retrieves the TTM insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=ttm&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download TTM insurance cashflow dataset](https://github.com/SimFin/simfin)
