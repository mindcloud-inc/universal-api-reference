# Download Germany TTM as reported income dataset with SimFin

Retrieves the Germany TTM as reported income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=ttm-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany TTM as reported income dataset](https://github.com/SimFin/simfin)
