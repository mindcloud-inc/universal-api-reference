# Download China TTM derived fundamentals dataset with SimFin

Retrieves the China TTM derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=ttm&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China TTM derived fundamentals dataset](https://github.com/SimFin/simfin)
