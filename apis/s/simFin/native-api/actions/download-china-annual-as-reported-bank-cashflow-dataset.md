# Download China annual as reported bank cashflow dataset with SimFin

Retrieves the China annual as reported bank cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-banks&variant=annual-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual as reported bank cashflow dataset](https://github.com/SimFin/simfin)
