# List SimFin bulk column metadata with SimFin

Retrieves SimFin bulk column metadata.

## Endpoint

- **Method:** `GET`
- **Path:** `info?type=columns`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [List SimFin bulk column metadata](https://github.com/SimFin/simfin)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
