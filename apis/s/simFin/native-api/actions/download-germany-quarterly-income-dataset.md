# Download Germany quarterly income dataset with SimFin

Retrieves the Germany quarterly income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly income dataset](https://github.com/SimFin/simfin)
