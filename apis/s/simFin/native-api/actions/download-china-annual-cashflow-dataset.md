# Download China annual cashflow dataset with SimFin

Retrieves the China annual cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual cashflow dataset](https://github.com/SimFin/simfin)
