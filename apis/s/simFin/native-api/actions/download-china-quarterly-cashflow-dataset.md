# Download China quarterly cashflow dataset with SimFin

Retrieves the China quarterly cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=quarterly&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China quarterly cashflow dataset](https://github.com/SimFin/simfin)
