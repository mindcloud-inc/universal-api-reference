# Download Canada companies dataset with SimFin

Retrieves the Canada companies dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=companies&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada companies dataset](https://github.com/SimFin/simfin)
