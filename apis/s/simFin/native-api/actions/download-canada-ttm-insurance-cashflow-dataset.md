# Download Canada TTM insurance cashflow dataset with SimFin

Retrieves the Canada TTM insurance cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow-insurance&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM insurance cashflow dataset](https://github.com/SimFin/simfin)
