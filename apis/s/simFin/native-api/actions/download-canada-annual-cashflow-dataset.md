# Download Canada annual cashflow dataset with SimFin

Retrieves the Canada annual cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual cashflow dataset](https://github.com/SimFin/simfin)
