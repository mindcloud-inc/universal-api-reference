# Download China latest shareprices dataset with SimFin

Retrieves the China latest shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=latest&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China latest shareprices dataset](https://github.com/SimFin/simfin)
