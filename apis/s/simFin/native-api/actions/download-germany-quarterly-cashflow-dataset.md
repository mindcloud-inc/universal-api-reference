# Download Germany quarterly cashflow dataset with SimFin

Retrieves the Germany quarterly cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=quarterly&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly cashflow dataset](https://github.com/SimFin/simfin)
