# Download Germany daily as reported shareprices dataset with SimFin

Retrieves the Germany daily as reported shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=shareprices&variant=daily-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany daily as reported shareprices dataset](https://github.com/SimFin/simfin)
