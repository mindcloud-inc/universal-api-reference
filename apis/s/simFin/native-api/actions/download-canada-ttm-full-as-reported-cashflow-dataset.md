# Download Canada TTM full as reported cashflow dataset with SimFin

Retrieves the Canada TTM full as reported cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm-full-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM full as reported cashflow dataset](https://github.com/SimFin/simfin)
