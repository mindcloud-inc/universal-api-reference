# Download Germany annual derived fundamentals dataset with SimFin

Retrieves the Germany annual derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived&variant=annual&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual derived fundamentals dataset](https://github.com/SimFin/simfin)
