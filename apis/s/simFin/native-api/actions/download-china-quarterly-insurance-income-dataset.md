# Download China quarterly insurance income dataset with SimFin

Retrieves the China quarterly insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=quarterly&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China quarterly insurance income dataset](https://github.com/SimFin/simfin)
