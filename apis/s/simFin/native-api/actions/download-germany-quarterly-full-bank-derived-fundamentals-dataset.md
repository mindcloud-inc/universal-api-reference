# Download Germany quarterly full bank derived fundamentals dataset with SimFin

Retrieves the Germany quarterly full bank derived fundamentals dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-banks&variant=quarterly-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly full bank derived fundamentals dataset](https://github.com/SimFin/simfin)
