# Download Canada quarterly full as reported insurance balance dataset with SimFin

Retrieves the Canada quarterly full as reported insurance balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-insurance&variant=quarterly-full-asreported&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly full as reported insurance balance dataset](https://github.com/SimFin/simfin)
