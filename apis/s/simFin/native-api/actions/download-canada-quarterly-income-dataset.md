# Download Canada quarterly income dataset with SimFin

Retrieves the Canada quarterly income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=quarterly&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada quarterly income dataset](https://github.com/SimFin/simfin)
