# Download Germany quarterly full cashflow dataset with SimFin

Retrieves the Germany quarterly full cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=quarterly-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly full cashflow dataset](https://github.com/SimFin/simfin)
