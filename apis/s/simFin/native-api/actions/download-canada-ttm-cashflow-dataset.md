# Download Canada TTM cashflow dataset with SimFin

Retrieves the Canada TTM cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada TTM cashflow dataset](https://github.com/SimFin/simfin)
