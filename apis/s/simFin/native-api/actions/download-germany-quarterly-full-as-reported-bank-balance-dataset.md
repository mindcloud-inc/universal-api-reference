# Download Germany quarterly full as reported bank balance dataset with SimFin

Retrieves the Germany quarterly full as reported bank balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance-banks&variant=quarterly-full-asreported&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany quarterly full as reported bank balance dataset](https://github.com/SimFin/simfin)
