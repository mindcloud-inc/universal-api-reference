# Download China annual as reported insurance income dataset with SimFin

Retrieves the China annual as reported insurance income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income-insurance&variant=annual-asreported&market=cn`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download China annual as reported insurance income dataset](https://github.com/SimFin/simfin)
