# Download Germany annual full balance dataset with SimFin

Retrieves the Germany annual full balance dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=balance&variant=annual-full&market=de`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Germany annual full balance dataset](https://github.com/SimFin/simfin)
