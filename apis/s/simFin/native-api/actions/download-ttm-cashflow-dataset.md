# Download TTM cashflow dataset with SimFin

Retrieves the TTM cashflow dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=cashflow&variant=ttm&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download TTM cashflow dataset](https://github.com/SimFin/simfin)
