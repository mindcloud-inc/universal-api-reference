# Download Canada annual income dataset with SimFin

Retrieves the Canada annual income dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=income&variant=annual&market=ca`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download Canada annual income dataset](https://github.com/SimFin/simfin)
