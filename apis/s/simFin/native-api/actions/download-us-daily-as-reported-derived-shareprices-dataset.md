# Download US daily as reported derived shareprices dataset with SimFin

Retrieves the US daily as reported derived shareprices dataset from SimFin.

## Endpoint

- **Method:** `GET`
- **Path:** `s3?dataset=derived-shareprices&variant=daily-asreported&market=us`
- **Base URL:** `https://prod.simfin.com/api/bulk-download`
- **Official documentation:** [Download US daily as reported derived shareprices dataset](https://github.com/SimFin/simfin)
