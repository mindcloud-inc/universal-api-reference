# SimFin: Native API Reference

A consolidated summary of SimFin's API configuration and 616 documented operations, with links to official documentation.

- **Official docs:** https://github.com/SimFin/simfin
- **API base URL:** `https://prod.simfin.com/api/bulk-download`

## Authentication

### API Key

SimFin API key used in the Authorization header with the provider-required api-key prefix.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
Authorization: Bearer <apiKey>
```

[Official authentication documentation](https://github.com/SimFin/simfin)

## API conventions

Shared headers:

| Header | Value |
| --- | --- |
| `Accept` | `application/zip, text/csv, application/octet-stream` |

## Retry behavior

Retry responses with status codes `429,500,502,503,504`. Wait 1000 ms before the first retry. Stop after 2 attempts. Multiply the delay by 2 after each failed attempt.
