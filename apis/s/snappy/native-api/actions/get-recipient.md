# Get Recipient with Snappy

Retrieves a recipient from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipients/{recipientId}`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [Get Recipient](https://docs.snappy.com/reference/getrecipient)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
| `recipientId` | path | `string` | yes |
