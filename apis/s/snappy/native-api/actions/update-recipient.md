# Update Recipient with Snappy

Updates an existing recipient in Snappy.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/recipients/{recipientId}`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [Update Recipient](https://docs.snappy.com/reference/updaterecipient)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
| `recipientId` | path | `string` | yes |
