# List Campaigns with Snappy

Retrieves campaigns from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [List Campaigns](https://docs.snappy.com/reference/getcampaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
