# Get Gift with Snappy

Retrieves a gift from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/gifts/{giftId}`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [Get Gift](https://docs.snappy.com/reference/getgift)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
| `giftId` | path | `string` | yes |
