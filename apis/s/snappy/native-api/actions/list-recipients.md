# List Recipients with Snappy

Retrieves recipients from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipients`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [List Recipients](https://docs.snappy.com/reference/getrecipients)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
