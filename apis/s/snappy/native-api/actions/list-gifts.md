# List Gifts with Snappy

Retrieves gifts from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/gifts`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [List Gifts](https://docs.snappy.com/reference/getgifts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | query | `string` | yes |
