# Update Campaign with Snappy

Updates an existing campaign in Snappy.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [Update Campaign](https://docs.snappy.com/reference/updatecampaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
| `companyId` | query | `string` | yes |
