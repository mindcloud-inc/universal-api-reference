# Get Campaign with Snappy

Retrieves a campaign from Snappy.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.snappy.com/public-api/v2`
- **Official documentation:** [Get Campaign](https://docs.snappy.com/reference/getcampaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
| `companyId` | query | `string` | yes |
