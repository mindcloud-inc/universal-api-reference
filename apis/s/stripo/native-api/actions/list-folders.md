# List Folders with Stripo

Retrieves folders from Stripo by type.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:type`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [List Folders](https://api.stripo.email/reference/getfolders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | Folder type. |
