# Delete Template with Stripo

Deletes a template from Stripo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:id`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Delete Template](https://api.stripo.email/reference/deletetemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The template ID. |
