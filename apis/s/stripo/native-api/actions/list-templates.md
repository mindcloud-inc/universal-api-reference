# List Templates with Stripo

Retrieves templates from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [List Templates](https://api.stripo.email/reference/findtemplates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchParameters` | query | `string` | yes | JSON object string for the documented template search parameters. |
