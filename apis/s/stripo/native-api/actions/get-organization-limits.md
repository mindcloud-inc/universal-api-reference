# Get Organization Limits with Stripo

Retrieves organization limits from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizationLimits`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Get Organization Limits](https://api.stripo.email/reference/getorganizationlimits)
