# List SRT Transformers with Stripo

Retrieves SRT transformers from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/srtnames`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [List SRT Transformers](https://api.stripo.email/reference/getsrtconfignames)
