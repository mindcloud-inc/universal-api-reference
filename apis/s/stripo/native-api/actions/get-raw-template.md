# Get Raw Template with Stripo

Retrieves raw HTML and CSS for a template from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/raw-template/:id`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Get Raw Template](https://api.stripo.email/reference/getrawtemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The template ID. |
