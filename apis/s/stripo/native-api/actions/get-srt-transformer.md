# Get SRT Transformer with Stripo

Retrieves an SRT transformer configuration from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/srt`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Get SRT Transformer](https://api.stripo.email/reference/getsrtconfig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | The name of an SRT config. |
