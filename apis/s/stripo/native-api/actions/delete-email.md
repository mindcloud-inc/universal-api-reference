# Delete Email with Stripo

Deletes an email from Stripo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/emails/:id`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Delete Email](https://api.stripo.email/reference/deleteemail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The email ID. |
