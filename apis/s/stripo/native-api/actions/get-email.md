# Get Email with Stripo

Retrieves an email from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:id`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Get Email](https://api.stripo.email/reference/getemailbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The email ID. |
