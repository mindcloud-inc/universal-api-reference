# List Modules with Stripo

Retrieves saved modules from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/modules`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [List Modules](https://api.stripo.email/reference/findmodules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `parameters` | query | `string` | yes | JSON object string for the documented module search parameters. |
