# Get Raw Email with Stripo

Retrieves raw HTML and CSS for an email from Stripo.

## Endpoint

- **Method:** `GET`
- **Path:** `/raw-email/:id`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Get Raw Email](https://api.stripo.email/reference/getrawemail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The email ID. |
