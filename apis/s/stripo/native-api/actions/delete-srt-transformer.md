# Delete SRT Transformer with Stripo

Deletes an SRT transformer from Stripo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/srt`
- **Base URL:** `https://my.stripo.email/emailgeneration/v1`
- **Official documentation:** [Delete SRT Transformer](https://api.stripo.email/reference/deletesrtconfig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | The name of the SRT rule to delete. |
