# List Tags with Storyblok

Retrieves tags used in the current Storyblok space.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.storyblok.com/v2/cdn`
- **Official documentation:** [List Tags](https://www.storyblok.com/docs/api/content-delivery/v2/tags/retrieve-multiple-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `version` | query | `string` | no | Whether to read draft or published content. |
