# Get Datasource with Storyblok

Retrieves a Storyblok datasource by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasource/:datasourceId`
- **Base URL:** `https://api.storyblok.com/v2/cdn`
- **Official documentation:** [Get Datasource](https://www.storyblok.com/docs/api/content-delivery/v2/datasources/retrieve-a-single-datasource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasourceId` | path | `string` | yes | The datasource slug. |
