# List Datasources with Storyblok

Retrieves datasources from the current Storyblok space.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources`
- **Base URL:** `https://api.storyblok.com/v2/cdn`
- **Official documentation:** [List Datasources](https://www.storyblok.com/docs/api/content-delivery/v2/datasources/retrieve-multiple-datasources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
