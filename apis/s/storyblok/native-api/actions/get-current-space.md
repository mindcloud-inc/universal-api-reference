# Get Current Space with Storyblok

Retrieves the current space from Storyblok.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/me`
- **Base URL:** `https://api.storyblok.com/v2/cdn`
- **Official documentation:** [Get Current Space](https://www.storyblok.com/docs/api/content-delivery/v2/spaces/retrieve-current-space)
