# List Webhooks with SafetyCulture

Retrieves webhooks from SafetyCulture.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/v1/webhooks`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [List Webhooks](https://developer.safetyculture.com/reference/webhooksservice_listwebhooks)
