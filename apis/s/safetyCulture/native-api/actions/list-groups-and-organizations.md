# List Groups and Organizations with SafetyCulture

Retrieves groups and organizations from SafetyCulture.

## Endpoint

- **Method:** `GET`
- **Path:** `/share/connections`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [List Groups and Organizations](https://developer.safetyculture.com/reference/thepubservice_getusergroups)
