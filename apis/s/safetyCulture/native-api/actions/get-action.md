# Get Action with SafetyCulture

Retrieves an action from SafetyCulture.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/v1/actions/{id}`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [Get Action](https://developer.safetyculture.com/reference/actionsservice_getaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID to query data for |
