# Get Inspection with SafetyCulture

Retrieves an inspection from SafetyCulture.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/v1/inspections/{id}`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [Get Inspection](https://developer.safetyculture.com/reference/inspectionservice_getinspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID for the inspection. |
