# Get Inspection Answers with SafetyCulture

Retrieves inspection answers from SafetyCulture.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/v1/answers/{id}`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [Get Inspection Answers](https://developer.safetyculture.com/reference/answerservice_getanswersforinspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the inspection |
