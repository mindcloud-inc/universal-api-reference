# Complete Inspection with SafetyCulture

Completes an inspection in SafetyCulture.

## Endpoint

- **Method:** `POST`
- **Path:** `/inspections/integration/v1/inspections/{inspection_id}/complete`
- **Base URL:** `https://api.safetyculture.io`
- **Official documentation:** [Complete Inspection](https://developer.safetyculture.com/reference/inspectionservice_completeinspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspection_id` | path | `string` | yes | The unique identifier for the inspection to complete. |
