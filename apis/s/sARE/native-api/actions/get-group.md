# Get Group with SARE

Retrieves a specific group from SARE.

## Endpoint

- **Method:** `GET`
- **Path:** `/group/get/:group`
- **Base URL:** `https://s.enewsletter.pl/api/v1/{uid}`
- **Official documentation:** [Get Group](https://dev.sare.pl/rest-api/other/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `number` | yes | Group identifier from the SARE account. |
