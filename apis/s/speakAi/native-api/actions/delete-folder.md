# Delete Folder with Speak Ai

Deletes an existing folder from Speak Ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folder/:folderId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Delete Folder](https://docs.speakai.co/#837cd417-49be-4af0-9249-bfc417ae1a40)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Speak Ai folder identifier. |
