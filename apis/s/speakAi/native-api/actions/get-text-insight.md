# Get Text Insight with Speak Ai

Retrieves text insights from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/text/insight/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Text Insight](https://docs.speakai.co/#d65573c9-98ad-4089-93ad-9d0a173fdeea)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai text note media identifier. |
