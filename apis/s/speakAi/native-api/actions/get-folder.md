# Get Folder with Speak Ai

Retrieves folder details from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/folder/:folderId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Folder](https://docs.speakai.co/#f8daf40d-c996-46ca-8767-ec49e68bf0a4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Speak Ai folder identifier. |
