# Get Recorder with Speak Ai

Retrieves recorder details from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/recorder/:recorderId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Recorder](https://docs.speakai.co/#9de4ec29-7bcc-438c-96e5-f8a7f7566b74)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recorderId` | path | `string` | yes | Speak Ai recorder identifier. |
