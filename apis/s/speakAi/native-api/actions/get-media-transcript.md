# Get Media Transcript with Speak Ai

Retrieves a media transcript from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/transcript/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Media Transcript](https://docs.speakai.co/#1bb23cc2-457d-4798-b914-e85b94a9289c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai media identifier. |
