# Delete Media with Speak Ai

Deletes an existing media item from Speak Ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/media/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Delete Media](https://docs.speakai.co/#e7f7950f-6f2d-4d36-88d6-d65fc694151a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai media identifier. |
