# Reanalyze Text with Speak Ai

## Endpoint

- **Method:** `GET`
- **Path:** `/media/reanalyze/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Reanalyze Text](https://docs.speakai.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai text note media identifier. |
