# Delete Text Note with Speak Ai

Deletes an existing text note from Speak Ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/text/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Delete Text Note](https://docs.speakai.co/#3f934551-d437-4d80-9041-cd6b348ae92e)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai text note media identifier. |
