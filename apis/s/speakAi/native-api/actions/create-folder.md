# Create Folder with Speak Ai

Creates a folder in Speak Ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/folder`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Create Folder](https://docs.speakai.co/#4022c583-e3ef-4615-b181-083c6ccc1272)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Folder name. |
