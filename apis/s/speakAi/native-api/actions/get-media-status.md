# Get Media Status with Speak Ai

Retrieves media status details from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/status/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Media Status](https://docs.speakai.co/#c4bb2b6b-cd0a-44ec-9afb-9e253bcfeff1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai media identifier. |
