# Get Media Insight with Speak Ai

Retrieves media insights from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/insight/:mediaId`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Get Media Insight](https://docs.speakai.co/#0b586e5b-6e0a-4b79-b440-e6889a803ccd)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | Speak Ai media identifier. |
