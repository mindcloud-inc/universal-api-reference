# List Recorders with Speak Ai

Retrieves recorders from Speak Ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/recorder`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [List Recorders](https://docs.speakai.co/#cfd4b7ea-0b58-4719-b5a9-213954d1da44)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filterName` | query | `string` | no | Filter recorders by name. |
