# Request Access Token with Speak Ai

Requests an access token from Speak Ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/accessToken`
- **Base URL:** `https://api.speakai.co/v1`
- **Official documentation:** [Request Access Token](https://docs.speakai.co/#d6e01d83-dff8-4b05-b282-2627feac9525)
