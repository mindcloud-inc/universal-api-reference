# Send Job with Synchroteam

Creates or updates a job in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/Jobs/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Job](https://api.synchroteam.com/v2/#send-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating a job (per docs). |
