# Send Site with Synchroteam

Creates or updates a site in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/Site/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Site](https://api.synchroteam.com/v2/#send-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating a site (per docs). |
