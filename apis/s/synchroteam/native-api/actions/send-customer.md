# Send Customer with Synchroteam

Creates or updates a customer in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/Customer/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Customer](https://api.synchroteam.com/v2/#send-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating a customer (per docs). |
