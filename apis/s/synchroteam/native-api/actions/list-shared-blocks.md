# List Shared Blocks with Synchroteam

Retrieves a list of shared blocks from Synchroteam.

## Endpoint

- **Method:** `GET`
- **Path:** `/Api/v2/SharedBlocks/List`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [List Shared Blocks](https://api.synchroteam.com/v2/#list-shared-blocks)
