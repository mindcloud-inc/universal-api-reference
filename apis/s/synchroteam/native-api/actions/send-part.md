# Send Part with Synchroteam

Creates or updates a part in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/Part/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Part](https://api.synchroteam.com/v2/#send-part)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating a part (per docs). |
