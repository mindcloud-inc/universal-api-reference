# Send Equipment with Synchroteam

Creates or updates equipment in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/Equipment/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Equipment](https://api.synchroteam.com/v2/#send-equipment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating equipment (per docs). |
