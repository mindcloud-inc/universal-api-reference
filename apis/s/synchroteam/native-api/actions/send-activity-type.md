# Send Activity Type with Synchroteam

Creates or updates an activity type in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/V2/ActivityType/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send Activity Type](https://api.synchroteam.com/v2/#send-activity-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating an activity type (per docs). |
