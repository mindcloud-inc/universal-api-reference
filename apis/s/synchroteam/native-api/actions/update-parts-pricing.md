# Update Parts Pricing with Synchroteam

Updates pricing for parts in Synchroteam.

## Endpoint

- **Method:** `PUT`
- **Path:** `/Api/v2/Part/Prices`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Update Parts Pricing](https://api.synchroteam.com/v2/#update-parts-pricing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for updating part prices (per docs). |
