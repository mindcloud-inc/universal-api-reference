# Send User with Synchroteam

Creates or updates a user in Synchroteam.

## Endpoint

- **Method:** `POST`
- **Path:** `/Api/v2/User/Send`
- **Base URL:** `https://ws.synchroteam.com`
- **Official documentation:** [Send User](https://api.synchroteam.com/v2/#send-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Request body payload for creating or updating a user (per docs). |
