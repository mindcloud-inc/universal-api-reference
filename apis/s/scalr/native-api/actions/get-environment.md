# Get Environment with Scalr

Retrieves an environment from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments/:environment`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Get Environment](https://docs.scalr.io/reference/get_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment` | path | `string` | yes | Scalr environment ID. |
