# Get Account Metrics with Scalr

Retrieves account metrics from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account/metrics`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Get Account Metrics](https://docs.scalr.io/reference/get_metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account` | path | `string` | yes | Scalr account ID. |
