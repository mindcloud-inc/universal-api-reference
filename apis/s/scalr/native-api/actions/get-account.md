# Get Account with Scalr

Retrieves an account from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Get Account](https://docs.scalr.io/reference/get_account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account` | path | `string` | yes | Scalr account ID. |
