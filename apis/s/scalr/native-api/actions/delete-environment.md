# Delete Environment with Scalr

Deletes an environment from Scalr.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/environments/:environment`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Delete Environment](https://docs.scalr.io/reference/delete_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment` | path | `string` | yes | Scalr environment ID. |
