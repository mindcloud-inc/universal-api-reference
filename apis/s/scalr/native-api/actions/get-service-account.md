# Get Service Account with Scalr

Retrieves a service account from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/service-accounts/:service_account`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Get Service Account](https://docs.scalr.io/reference/get_service_account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_account` | path | `string` | yes | Scalr service account ID. |
