# List Accounts with Scalr

Retrieves accounts from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [List Accounts](https://docs.scalr.io/reference/get_accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
