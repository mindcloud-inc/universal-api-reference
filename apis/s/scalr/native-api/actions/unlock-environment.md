# Unlock Environment with Scalr

Unlocks an environment in Scalr.

## Endpoint

- **Method:** `POST`
- **Path:** `/environments/:environment/actions/unlock`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Unlock Environment](https://docs.scalr.io/reference/unlock_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment` | path | `string` | yes | Scalr environment ID. |
