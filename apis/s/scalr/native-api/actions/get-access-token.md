# Get Access Token with Scalr

Retrieves an access token from Scalr.

## Endpoint

- **Method:** `GET`
- **Path:** `/access-tokens/:access_token`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Get Access Token](https://docs.scalr.io/reference/get_access_token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_token` | path | `string` | yes | Scalr access token ID. |
