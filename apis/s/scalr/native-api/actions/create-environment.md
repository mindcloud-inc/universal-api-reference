# Create Environment with Scalr

Creates a new environment in Scalr.

## Endpoint

- **Method:** `POST`
- **Path:** `/environments`
- **Base URL:** `https://mindcloud.scalr.io/api/iacp/v3`
- **Official documentation:** [Create Environment](https://docs.scalr.io/reference/create_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data.attributes.name` | body | `string` | yes | Environment name. |
