# List Funding Sources with Snapchat Ads

Retrieves funding sources from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/fundingsources`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [List Funding Sources](https://developers.snap.com/api/marketing-api/Ads-API/funding-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | The Snapchat Organization ID that owns the funding sources. |
