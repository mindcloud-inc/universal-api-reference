# Get Ad with Snapchat Ads

Retrieves an ad from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/ads/:adId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Ad](https://developers.snap.com/api/marketing-api/Ads-API/ads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adId` | path | `string` | yes | The Snapchat Ad ID to retrieve. |
