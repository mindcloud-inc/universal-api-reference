# Delete Ad with Snapchat Ads

Deletes an existing ad from Snapchat Ads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ads/:adId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Delete Ad](https://developers.snap.com/api/marketing-api/Ads-API/ads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adId` | path | `string` | yes | The Snapchat Ad ID to delete. |
