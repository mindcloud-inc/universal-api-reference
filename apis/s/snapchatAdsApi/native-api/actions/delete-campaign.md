# Delete Campaign with Snapchat Ads

Deletes an existing campaign from Snapchat Ads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Delete Campaign](https://developers.snap.com/api/marketing-api/Ads-API/campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The Snapchat Campaign ID to delete. |
