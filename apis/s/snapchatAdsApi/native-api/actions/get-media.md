# Get Media with Snapchat Ads

Retrieves a media asset from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/:mediaId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Media](https://developers.snap.com/api/marketing-api/Ads-API/media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `string` | yes | The Snapchat Media ID to retrieve. |
