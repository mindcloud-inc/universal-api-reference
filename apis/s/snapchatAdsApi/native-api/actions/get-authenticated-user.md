# Get Authenticated User with Snapchat Ads

Retrieves the authenticated Snapchat Ads user.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Authenticated User](https://developers.snap.com/api/marketing-api/Ads-API/user)
