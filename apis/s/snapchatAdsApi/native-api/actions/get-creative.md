# Get Creative with Snapchat Ads

Retrieves a creative from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/creatives/:creativeId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Creative](https://developers.snap.com/api/marketing-api/Ads-API/creatives)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `creativeId` | path | `string` | yes | The Snapchat Creative ID to retrieve. |
