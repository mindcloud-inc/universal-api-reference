# Get Funding Source with Snapchat Ads

Retrieves a funding source from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/fundingsources/:fundingSourceId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Funding Source](https://developers.snap.com/api/marketing-api/Ads-API/funding-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fundingSourceId` | path | `string` | yes | The Snapchat Funding Source ID to retrieve. |
