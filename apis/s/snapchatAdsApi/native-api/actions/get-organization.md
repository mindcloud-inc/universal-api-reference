# Get Organization with Snapchat Ads

Retrieves an organization from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Organization](https://developers.snap.com/api/marketing-api/Ads-API/organizations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | The Snapchat Organization ID to retrieve. |
