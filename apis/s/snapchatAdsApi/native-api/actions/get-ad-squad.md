# Get Ad Squad with Snapchat Ads

Retrieves an ad squad from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/adsquads/:adSquadId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Ad Squad](https://developers.snap.com/api/marketing-api/Ads-API/ad-squads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adSquadId` | path | `string` | yes | The Snapchat Ad Squad ID to retrieve. |
