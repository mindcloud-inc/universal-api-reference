# List Organizations with Snapchat Ads

Retrieves organizations from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/me/organizations`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [List Organizations](https://developers.snap.com/api/marketing-api/Ads-API/organizations)
