# Get Campaign with Snapchat Ads

Retrieves a campaign from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Campaign](https://developers.snap.com/api/marketing-api/Ads-API/campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The Snapchat Campaign ID to retrieve. |
