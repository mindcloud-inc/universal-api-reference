# Get Billing Center with Snapchat Ads

Retrieves a billing center from Snapchat Ads.

## Endpoint

- **Method:** `GET`
- **Path:** `/billingcenters/:billingCenterId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Billing Center](https://developers.snap.com/api/marketing-api/Ads-API/billing-centers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `billingCenterId` | path | `string` | yes | The Snapchat Billing Center ID to retrieve. |
