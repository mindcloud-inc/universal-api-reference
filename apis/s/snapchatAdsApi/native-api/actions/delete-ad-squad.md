# Delete Ad Squad with Snapchat Ads

Deletes an existing ad squad from Snapchat Ads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/adsquads/:adSquadId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Delete Ad Squad](https://developers.snap.com/api/marketing-api/Ads-API/ad-squads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adSquadId` | path | `string` | yes | The Snapchat Ad Squad ID to delete. |
