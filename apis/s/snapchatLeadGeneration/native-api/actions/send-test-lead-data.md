# Send Test Lead Data with Snapchat Lead Generation

Sends test lead data in Snapchat Lead Generation.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead_gen/integrations/:integrationId/test`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Send Test Lead Data](https://developers.snap.com/api/marketing-api/Ads-API/lead-generation-ads#send-test-lead-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `string` | yes | The Snapchat webhook integration ID to send test lead data through. |
