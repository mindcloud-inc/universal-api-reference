# Delete Webhook Integration with Snapchat Lead Generation

Deletes a webhook integration from Snapchat Lead Generation.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lead_gen/integrations/:integrationId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Delete Webhook Integration](https://developers.snap.com/api/marketing-api/Ads-API/lead-generation-ads#delete-a-webhook-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `string` | yes | The Snapchat webhook integration ID to delete. |
