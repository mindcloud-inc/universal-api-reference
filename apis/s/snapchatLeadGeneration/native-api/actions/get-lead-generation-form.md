# Get Lead Generation Form with Snapchat Lead Generation

Retrieves a lead generation form from Snapchat Lead Generation.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead_generation_forms/:leadGenerationFormId`
- **Base URL:** `https://adsapi.snapchat.com/v1`
- **Official documentation:** [Get Lead Generation Form](https://developers.snap.com/api/marketing-api/Ads-API/lead-generation-ads#get-lead-generation-form-using-lead-generation-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadGenerationFormId` | path | `string` | yes | The Snapchat lead generation form ID to retrieve. |
