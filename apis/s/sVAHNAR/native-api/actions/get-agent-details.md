# Get Agent Details with SVAHNAR

Retrieves agent details from SVAHNAR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/get-agent/:agent_id`
- **Base URL:** `https://api.svahnar.com`
- **Official documentation:** [Get Agent Details](https://docs.svahnar.com/docs/Agents/get_agent_details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The unique identifier of the agent. |
