# List All Agents with SVAHNAR

Retrieves all agents from SVAHNAR.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/list-agents`
- **Base URL:** `https://api.svahnar.com`
- **Official documentation:** [List All Agents](https://docs.svahnar.com/docs/Agents/list_agents/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
