# Login with SVAHNAR

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/auth/login`
- **Base URL:** `https://api.svahnar.com`
- **Official documentation:** [Login](https://docs.svahnar.com/docs/GetStarted/Quickstart/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_ids` | query | `boolean` | no | Whether to include user IDs in the login response. |
