# Permanently Delete QR Code with Scanova

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qrcode/trash/{qrid}/permanent-delete/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Permanently Delete QR Code](https://docs.scanova.io/api-reference/endpoint/qr_manager/trash)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrid` | path | `string` | yes | QR Code ID |
