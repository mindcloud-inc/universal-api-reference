# Get QR Code Categories with Scanova

## Endpoint

- **Method:** `GET`
- **Path:** `/qr/category/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Get QR Code Categories](https://docs.scanova.io/api-reference/endpoint/qr_manager/categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `view_type` | query | `list` | no | Filter categories by view type Accepted values: `all`, `content_type`, `favourite`, `recommended`, `use_case`. |
