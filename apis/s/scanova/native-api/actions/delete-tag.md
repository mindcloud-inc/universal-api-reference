- **Method:** `DELETE`

- **Official documentation:** [Delete Tag](https://docs.scanova.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `number` | yes | Tag ID |
