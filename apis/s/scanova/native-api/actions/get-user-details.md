# Get User Details with Scanova

## Endpoint

- **Method:** `GET`
- **Path:** `/multi-users/{shared-user-id}/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Get User Details](https://docs.scanova.io/api-reference/endpoint/user_management/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shared-user-id` | path | `number` | yes | ID of the shared user |
