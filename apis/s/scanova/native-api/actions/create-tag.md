# Create Tag with Scanova

## Endpoint

- **Method:** `POST`
- **Path:** `/tag/list/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Create Tag](https://docs.scanova.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name |
| `color` | body | `string` | no | Tag color (hex code) |
