# Delete QR Code with Scanova

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qr/{qrid}/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Delete QR Code](https://docs.scanova.io/api-reference/endpoint/qr_manager/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrid` | path | `string` | yes | QR Code ID |
