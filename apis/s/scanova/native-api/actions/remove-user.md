# Remove User with Scanova

## Endpoint

- **Method:** `DELETE`
- **Path:** `/multi-users/{shared-user-id}/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Remove User](https://docs.scanova.io/api-reference/endpoint/user_management/remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shared-user-id` | path | `number` | yes | ID of the shared user to remove |
