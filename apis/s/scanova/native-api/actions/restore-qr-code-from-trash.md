# Restore QR Code From Trash with Scanova

## Endpoint

- **Method:** `POST`
- **Path:** `/qrcode/trash/{qrid}/restore/`
- **Base URL:** `https://management.scanova.io`
- **Official documentation:** [Restore QR Code From Trash](https://docs.scanova.io/api-reference/endpoint/qr_manager/trash)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrid` | path | `string` | yes | QR Code ID |
