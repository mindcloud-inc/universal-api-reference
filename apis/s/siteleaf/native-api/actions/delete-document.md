# Delete Document with Siteleaf

Deletes an existing document from Siteleaf.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:document_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Delete Document](https://learn.siteleaf.com/api/documents/#delete-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | no | Siteleaf document identifier |
