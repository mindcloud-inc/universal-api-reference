# Publish Site with Siteleaf

Publishes a site in Siteleaf.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/:site_id/publish`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Publish Site](https://learn.siteleaf.com/api/sites/#publish-a-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
