# Delete Page with Siteleaf

Deletes an existing page from Siteleaf.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pages/:page_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Delete Page](https://learn.siteleaf.com/api/pages/#delete-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | no | Siteleaf page identifier |
