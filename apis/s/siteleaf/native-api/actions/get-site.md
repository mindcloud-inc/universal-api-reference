# Get Site with Siteleaf

Retrieves a site from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Get Site](https://learn.siteleaf.com/api/sites/#get-a-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
