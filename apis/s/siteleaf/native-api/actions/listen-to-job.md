# Listen to Job with Siteleaf

Retrieves a job status stream from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Listen to Job](https://learn.siteleaf.com/api/jobs/#listen-to-a-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | no | Siteleaf job identifier |
