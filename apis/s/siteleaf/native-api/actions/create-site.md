# Create Site with Siteleaf

Creates a new site in Siteleaf.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Create Site](https://learn.siteleaf.com/api/sites/#create-a-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | no | Site domain |
| `title` | body | `string` | no | Site title |
