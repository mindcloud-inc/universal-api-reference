# List Pages with Siteleaf

Retrieves pages from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/pages`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [List Pages](https://learn.siteleaf.com/api/pages/#list-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
