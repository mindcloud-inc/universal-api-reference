# List Collections with Siteleaf

Retrieves collections from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/collections`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [List Collections](https://learn.siteleaf.com/api/collections/#list-collections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
