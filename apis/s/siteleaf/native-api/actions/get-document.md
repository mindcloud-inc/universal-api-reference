# Get Document with Siteleaf

Retrieves a document from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Get Document](https://learn.siteleaf.com/api/documents/#get-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | no | Siteleaf document identifier |
