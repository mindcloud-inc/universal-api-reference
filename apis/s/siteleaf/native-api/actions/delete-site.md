# Delete Site with Siteleaf

Deletes an existing site from Siteleaf.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Delete Site](https://learn.siteleaf.com/api/sites/#delete-a-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
