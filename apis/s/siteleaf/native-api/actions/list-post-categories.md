# List Post Categories with Siteleaf

Retrieves post categories from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/categories`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [List Post Categories](https://learn.siteleaf.com/api/sites/#list-post-categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
