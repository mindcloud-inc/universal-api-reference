# List Users with Siteleaf

Retrieves users from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/users`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [List Users](https://learn.siteleaf.com/api/users/#list-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
