# Get Page with Siteleaf

Retrieves a page from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/pages/:page_id`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [Get Page](https://learn.siteleaf.com/api/pages/#get-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | no | Siteleaf page identifier |
