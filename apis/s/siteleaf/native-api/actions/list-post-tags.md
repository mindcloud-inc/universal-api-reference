# List Post Tags with Siteleaf

Retrieves post tags from Siteleaf.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/tags`
- **Base URL:** `https://api.siteleaf.com/v2`
- **Official documentation:** [List Post Tags](https://learn.siteleaf.com/api/sites/#list-post-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | no | Siteleaf site identifier |
