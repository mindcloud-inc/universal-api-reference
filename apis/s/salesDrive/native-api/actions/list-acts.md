# List Acts with SalesDrive

Retrieves a list of act documents from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/act/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Acts](https://api.salesdrive.me/api/docs/#/document/act-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
