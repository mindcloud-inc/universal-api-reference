# List Product Arrivals with SalesDrive

Retrieves product arrival records from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/arrival-product/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Product Arrivals](https://api.salesdrive.me/api/docs/#/document/arrival-product-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
