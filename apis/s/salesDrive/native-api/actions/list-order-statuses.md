# List Order Statuses with SalesDrive

Retrieves available order statuses from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/statuses/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Order Statuses](https://api.salesdrive.me/api/docs/#/order-field/status-list)
