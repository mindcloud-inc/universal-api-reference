# List Payment Methods with SalesDrive

Retrieves available payment methods from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/payment-methods/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Payment Methods](https://api.salesdrive.me/api/docs/#/order-field/payment-method-list)
