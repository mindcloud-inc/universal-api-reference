# List Sales Invoices with SalesDrive

Retrieves a list of sales invoices from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/sales-invoice/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Sales Invoices](https://api.salesdrive.me/api/docs/#/document/sales-invoice-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
