# List Cash Orders with SalesDrive

Retrieves a list of cash orders from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/cash-order/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Cash Orders](https://api.salesdrive.me/api/docs/#/document/cash-order-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
