# List Payments with SalesDrive

Retrieves a list of payments from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/payment/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Payments](https://api.salesdrive.me/api/docs/#/document/payment-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
