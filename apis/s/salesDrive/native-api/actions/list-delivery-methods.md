# List Delivery Methods with SalesDrive

Retrieves available delivery methods from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/delivery-methods/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Delivery Methods](https://api.salesdrive.me/api/docs/#/order-field/delivery-method-list)
