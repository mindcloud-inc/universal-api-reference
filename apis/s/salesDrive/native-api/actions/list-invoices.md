# List Invoices with SalesDrive

Retrieves a list of invoices from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/invoice/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Invoices](https://api.salesdrive.me/api/docs/#/document/invoice-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
