# List Contracts with SalesDrive

Retrieves a list of contracts from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contract/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Contracts](https://api.salesdrive.me/api/docs/#/document/contract-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
