# List Checks with SalesDrive

Retrieves a list of checks from SalesDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/check/list/`
- **Base URL:** `https://{account}.salesdrive.me`
- **Official documentation:** [List Checks](https://api.salesdrive.me/api/docs/#/document/check-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
