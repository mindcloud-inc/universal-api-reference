# Get Campaign with Sendloop

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign.get/json`
- **Base URL:** `https://{subdomain}.sendloop.com/api/v3`
- **Official documentation:** [Get Campaign](https://chmyos.notion.site/Get-a-Campaign-f97ba801912044c0bf02cc46ba11d3ee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CampaignID` | body | `number` | yes | Target campaign ID |
