# Create List with Sendloop

## Endpoint

- **Method:** `POST`
- **Path:** `/list.create/json`
- **Base URL:** `https://{subdomain}.sendloop.com/api/v3`
- **Official documentation:** [Create List](https://chmyos.notion.site/Create-a-List-84fdbbb13cfc4a21a65def3e4ea372c9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Name of the new list |
| `OptInMode` | body | `string` | yes | Pass Single or Double |
