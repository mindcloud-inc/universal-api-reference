# Get Signature Settings with SigningHub

Retrieves signature settings from SigningHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/settings/signatures`
- **Base URL:** `https://api.signinghub.com`
- **Official documentation:** [Get Signature Settings](https://manuals.nsignhub.com/latest/Api/#tag/Personal-Settings/operation/V4_Settings_GetSignatureSettings)
