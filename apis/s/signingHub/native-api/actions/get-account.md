# Get Account with SigningHub

Retrieves account details from SigningHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/account`
- **Base URL:** `https://api.signinghub.com`
- **Official documentation:** [Get Account](https://manuals.nsignhub.com/latest/Api/#tag/Account-Management/operation/V4_Account_GetAccountInformation)
