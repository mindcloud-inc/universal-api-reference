# Delete Package with SigningHub

Deletes a package from SigningHub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/packages/:packageId`
- **Base URL:** `https://api.signinghub.com`
- **Official documentation:** [Delete Package](https://manuals.nsignhub.com/latest/Api/#tag/Document-Package/operation/V4_Package_DeletePackage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `packageId` | path | `number` | yes | The document package to delete. |
