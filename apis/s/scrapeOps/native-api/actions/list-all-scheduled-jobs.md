# List All Scheduled Jobs with ScrapeOps

Retrieves scheduled jobs from ScrapeOps.

## Endpoint

- **Method:** `GET`
- **Path:** `https://backend.scrapeops.io/v1/client/scheduled-jobs`
- **Base URL:** `http://headers.scrapeops.io/v1`
- **Official documentation:** [List All Scheduled Jobs](https://scrapeops.io/docs/servers-scheduling/rest-api/)
