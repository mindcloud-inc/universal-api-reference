# List Walmart Shop Results with ScrapeOps

Retrieves Walmart shop results from ScrapeOps.

## Endpoint

- **Method:** `GET`
- **Path:** `https://proxy.scrapeops.io/v1/structured-data/walmart/shop`
- **Base URL:** `http://headers.scrapeops.io/v1`
- **Official documentation:** [List Walmart Shop Results](https://scrapeops.io/docs/data-api/walmart-shop-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country` | query | `string` | no | — |
| `tld` | query | `string` | no | — |
| `url` | query | `string` | no | Full Walmart shop URL to fetch. |
