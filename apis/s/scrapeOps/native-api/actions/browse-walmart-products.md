# Browse Walmart Products with ScrapeOps

Retrieves Walmart browse results from ScrapeOps.

## Endpoint

- **Method:** `GET`
- **Path:** `https://proxy.scrapeops.io/v1/structured-data/walmart/browse`
- **Base URL:** `http://headers.scrapeops.io/v1`
- **Official documentation:** [Browse Walmart Products](https://scrapeops.io/docs/data-api/walmart-browse-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country` | query | `string` | no | — |
| `tld` | query | `string` | no | — |
| `url` | query | `string` | no | Full Walmart browse URL to fetch. |
