# List Walmart Categories with ScrapeOps

Retrieves Walmart category data from ScrapeOps.

## Endpoint

- **Method:** `GET`
- **Path:** `https://proxy.scrapeops.io/v1/structured-data/walmart/category`
- **Base URL:** `http://headers.scrapeops.io/v1`
- **Official documentation:** [List Walmart Categories](https://scrapeops.io/docs/data-api/walmart-category-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country` | query | `string` | no | — |
| `tld` | query | `string` | no | — |
| `url` | query | `string` | no | Full Walmart category URL to fetch. |
