# List Servers with ScrapeOps

Retrieves scraper servers from ScrapeOps.

## Endpoint

- **Method:** `GET`
- **Path:** `https://backend.scrapeops.io/v1/client/servers`
- **Base URL:** `http://headers.scrapeops.io/v1`
- **Official documentation:** [List Servers](https://scrapeops.io/docs/servers-scheduling/rest-api/)
