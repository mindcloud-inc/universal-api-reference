# Get Destination Database Details with SingleStore

Retrieves destination database details from SingleStore.

## Endpoint

- **Method:** `GET`
- **Path:** `/conn-dst`
- **Base URL:** `https://{flowEndpoint}:30081/ingest/api/ingest`
- **Official documentation:** [Get Destination Database Details](https://docs.singlestore.com/cloud/load-data/load-data-with-singlestore-flow-on-helios/flow-on-helios-api/flow-on-helios-ingest-api/#get-destination-database-details)
