# Get Schedule Settings with SingleStore

Retrieves schedule settings from SingleStore.

## Endpoint

- **Method:** `GET`
- **Path:** `/config-sched`
- **Base URL:** `https://{flowEndpoint}:30081/ingest/api/ingest`
- **Official documentation:** [Get Schedule Settings](https://docs.singlestore.com/cloud/load-data/load-data-with-singlestore-flow-on-helios/flow-on-helios-api/flow-on-helios-ingest-api/#get-schedule-settings)
