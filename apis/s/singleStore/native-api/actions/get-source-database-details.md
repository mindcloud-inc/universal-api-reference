# Get Source Database Details with SingleStore

Retrieves source database details from SingleStore.

## Endpoint

- **Method:** `GET`
- **Path:** `/conn-src`
- **Base URL:** `https://{flowEndpoint}:30081/ingest/api/ingest`
- **Official documentation:** [Get Source Database Details](https://docs.singlestore.com/cloud/load-data/load-data-with-singlestore-flow-on-helios/flow-on-helios-api/flow-on-helios-ingest-api/#get-source-database-details)
