# Search Directory Member Suggestions with Satori Cyber

Finds directory member suggestions in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/directory/ui/members/suggestions`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Search Directory Member Suggestions](https://app.satoricyber.com/docs/api)
