# Get Account Attributes with Satori Cyber

Retrieves attributes for an account in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/accounts/:accountId/attributes`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Account Attributes](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Satori account ID. |
