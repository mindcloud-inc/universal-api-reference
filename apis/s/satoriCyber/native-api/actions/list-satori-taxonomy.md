# List Satori Taxonomy with Satori Cyber

Retrieves Satori taxonomy terms from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/taxonomy/satori`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Satori Taxonomy](https://app.satoricyber.com/docs/api)
