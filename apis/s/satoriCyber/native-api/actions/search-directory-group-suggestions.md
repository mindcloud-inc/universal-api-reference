# Search Directory Group Suggestions with Satori Cyber

Finds directory group suggestions in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/directory/ui/groups/suggestions`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Search Directory Group Suggestions](https://app.satoricyber.com/docs/api)
