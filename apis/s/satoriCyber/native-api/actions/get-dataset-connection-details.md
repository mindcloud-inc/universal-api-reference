# Get Dataset Connection Details with Satori Cyber

Retrieves dataset connection details from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/dataset/:datasetId/connection-details`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Dataset Connection Details](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | Dataset identifier. |
