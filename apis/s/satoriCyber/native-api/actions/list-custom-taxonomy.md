# List Custom Taxonomy with Satori Cyber

Retrieves custom taxonomy terms from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/taxonomy/custom`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Custom Taxonomy](https://app.satoricyber.com/docs/api)
