# Get Discovered Datastore Count with Satori Cyber

Retrieves the discovered datastore count from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/discovered-data-stores/count`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Discovered Datastore Count](https://app.satoricyber.com/docs/api)
