# Get Authorization Analytics Metrics with Satori Cyber

Retrieves authorization analytics metrics from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/authorization-analytics/:accountId/metrics`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Authorization Analytics Metrics](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Satori account ID. |
