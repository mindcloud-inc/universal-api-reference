# Get Alert with Satori Cyber

Retrieves alert details from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/alert/:id`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Alert](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Alert identifier. |
