# Search AWS Accounts with Satori Cyber

Finds AWS accounts in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/authorization-analytics/search-aws-accounts`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Search AWS Accounts](https://app.satoricyber.com/docs/api)
