# Search GCP Projects with Satori Cyber

Finds GCP projects in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/authorization-analytics/search-gcp-projects`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Search GCP Projects](https://app.satoricyber.com/docs/api)
