# List Data Access Rules Overview with Satori Cyber

Retrieves data access rule overviews from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/data-access-rule/overview`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Data Access Rules Overview](https://app.satoricyber.com/docs/api)
