# Get Dataset Access Details with Satori Cyber

Retrieves dataset access details from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/dataset/:datasetId/access-details`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Dataset Access Details](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | Dataset identifier. |
