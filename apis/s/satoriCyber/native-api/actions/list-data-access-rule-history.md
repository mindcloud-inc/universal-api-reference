# List Data Access Rule History with Satori Cyber

Retrieves data access rule history from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/data-access-rule/history`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Data Access Rule History](https://app.satoricyber.com/docs/api)
