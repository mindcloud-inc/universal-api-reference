# Get Datastore State with Satori Cyber

Retrieves the state of a datastore in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datastore/:accountId/state`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Datastore State](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Satori account ID. |
