# List Account Roles with Satori Cyber

Retrieves roles for an account in Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/accounts/:accountId/roles`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Account Roles](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Satori account ID. |
