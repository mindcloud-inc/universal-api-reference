# Get Security Policy Statistics with Satori Cyber

Retrieves security policy statistics from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/security-policies/statistics`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [Get Security Policy Statistics](https://app.satoricyber.com/docs/api)
