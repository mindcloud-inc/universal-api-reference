# List Datastores with Satori Cyber

Retrieves datastore records from Satori Cyber.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datastore`
- **Base URL:** `https://app.satoricyber.com`
- **Official documentation:** [List Datastores](https://app.satoricyber.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | query | `string` | yes | Satori account ID. |
