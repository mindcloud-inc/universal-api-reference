# Get OData V4 Metadata with Statistics Netherlands CBS

Retrieves OData V4 metadata from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datasets.cbs.nl/odata/v1/CBS/$metadata`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [Get OData V4 Metadata](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/xml` |
