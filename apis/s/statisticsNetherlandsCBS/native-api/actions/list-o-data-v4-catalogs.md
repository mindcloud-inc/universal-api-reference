# List OData V4 Catalogs with Statistics Netherlands CBS

Retrieves OData V4 catalogs from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datasets.cbs.nl/odata/v1/CBS/Catalogs`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [List OData V4 Catalogs](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)

## Capabilities

This operation supports [filtering](../README.md#filtering).
