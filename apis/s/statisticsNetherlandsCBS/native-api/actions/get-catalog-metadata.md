# Get Catalog Metadata with Statistics Netherlands CBS

Retrieves catalog metadata from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ODataCatalog/$metadata`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [Get Catalog Metadata](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/xml` |
