# List Tables with Statistics Netherlands CBS

Retrieves tables from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ODataCatalog/Tables`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [List Tables](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
