# List OData V4 Collections with Statistics Netherlands CBS

Retrieves OData V4 collections from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datasets.cbs.nl/odata/v1/CBS`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [List OData V4 Collections](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)
