# List Catalog Collections with Statistics Netherlands CBS

Retrieves catalog collections from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ODataCatalog`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [List Catalog Collections](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)
