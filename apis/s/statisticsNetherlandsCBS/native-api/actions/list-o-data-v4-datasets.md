# List OData V4 Datasets with Statistics Netherlands CBS

Retrieves OData V4 datasets from Statistics Netherlands CBS.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datasets.cbs.nl/odata/v1/CBS/Datasets`
- **Base URL:** `https://opendata.cbs.nl`
- **Official documentation:** [List OData V4 Datasets](https://www.cbs.nl/en-gb/onze-diensten/open-data/statline-as-open-data)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
