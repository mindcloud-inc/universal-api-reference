# List Group SSO Connections with Snyk

Retrieves SSO connections from a Snyk group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/sso_connections`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Group SSO Connections](https://docs.snyk.io/snyk-api/reference)
