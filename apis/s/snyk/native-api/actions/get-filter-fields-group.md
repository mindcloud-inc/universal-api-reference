# Get Group Asset Filter Fields with Snyk

Retrieves asset filter fields from a Snyk group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/inventory/assets/filters`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [Get Group Asset Filter Fields](https://docs.snyk.io/snyk-api/reference)
