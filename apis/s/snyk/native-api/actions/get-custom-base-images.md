# List Custom Base Images with Snyk

Retrieves custom base images from Snyk.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_base_images`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Custom Base Images](https://docs.snyk.io/snyk-api/reference)

## Capabilities

This operation supports [pagination](../README.md#pagination).
