# Get Custom Base Image with Snyk

Retrieves a custom base image from Snyk.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_base_images/:custombaseimage_id`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [Get Custom Base Image](https://docs.snyk.io/snyk-api/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custombaseimage_id` | path | `string` | yes | Custom base image ID for the request path. |
