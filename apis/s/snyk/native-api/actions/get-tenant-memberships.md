# List Tenant Memberships with Snyk

Retrieves tenant memberships from the Snyk API.

## Endpoint

- **Method:** `GET`
- **Path:** `/tenants/:tenant_id/memberships`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Tenant Memberships](https://docs.snyk.io/snyk-api/reference)
