# List Group Memberships with Snyk

Retrieves group memberships from the Snyk API.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/memberships`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Group Memberships](https://docs.snyk.io/snyk-api/reference)
