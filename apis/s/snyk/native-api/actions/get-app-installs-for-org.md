# List Organization App Installs with Snyk

Retrieves app installs from a Snyk organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_id/apps/installs`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Organization App Installs](https://docs.snyk.io/snyk-api/reference)
