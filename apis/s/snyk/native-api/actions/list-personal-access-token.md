# List Personal Access Tokens with Snyk

Retrieves personal access tokens for the current Snyk user.

## Endpoint

- **Method:** `GET`
- **Path:** `/self/personal_access_tokens`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Personal Access Tokens](https://docs.snyk.io/snyk-api/reference)
