# Get Group Asset Group Fields with Snyk

Retrieves asset group fields from a Snyk group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/inventory/assets/groups`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [Get Group Asset Group Fields](https://docs.snyk.io/snyk-api/reference)
