# List Group Inventory Assets with Snyk

Retrieves inventory assets from a Snyk group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/inventory/assets`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Group Inventory Assets](https://docs.snyk.io/snyk-api/reference)

## Capabilities

This operation supports [pagination](../README.md#pagination).
