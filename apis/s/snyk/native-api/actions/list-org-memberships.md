# List Organization Memberships with Snyk

Retrieves organization memberships from the Snyk API.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_id/memberships`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Organization Memberships](https://docs.snyk.io/snyk-api/reference)
