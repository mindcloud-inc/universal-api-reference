# List Organization App Creations with Snyk

Retrieves created apps from a Snyk organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_id/apps/creations`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Organization App Creations](https://docs.snyk.io/snyk-api/reference)
