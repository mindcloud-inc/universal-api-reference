# List Organization Service Accounts with Snyk

Retrieves service accounts from a Snyk organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org_id/service_accounts`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Organization Service Accounts](https://docs.snyk.io/snyk-api/reference)
