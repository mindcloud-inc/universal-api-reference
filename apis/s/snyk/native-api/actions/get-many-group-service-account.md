# List Group Service Accounts with Snyk

Retrieves service accounts from a Snyk group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group_id/service_accounts`
- **Base URL:** `https://api.snyk.io/rest`
- **Official documentation:** [List Group Service Accounts](https://docs.snyk.io/snyk-api/reference)
