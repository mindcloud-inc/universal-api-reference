# Add Project with SE Ranking Project

Creates a new project in SE Ranking.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Add Project](https://seranking.com/api/project/project-management/#adding-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Project website URL. |
| `title` | body | `string` | yes | Project name. |
