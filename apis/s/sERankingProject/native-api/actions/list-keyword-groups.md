# List Keyword Groups with SE Ranking Project

Retrieves keyword groups from SE Ranking.

## Endpoint

- **Method:** `GET`
- **Path:** `/keyword-groups/:site_id`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [List Keyword Groups](https://seranking.com/api/project/keyword-groups/#list-keyword-groups)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes |
