# Get Keyword Statistics with SE Ranking Project

Retrieves keyword ranking statistics from SE Ranking.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/positions`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Get Keyword Statistics](https://seranking.com/api/project/project-management/#keyword-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes | Project site identifier from SE Ranking. |
