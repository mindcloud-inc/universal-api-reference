# Delete Competitor with SE Ranking Project

Deletes an existing competitor from SE Ranking.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/competitors/:competitor_id`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Delete Competitor](https://seranking.com/api/project/competitors/#delete-competitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `competitor_id` | path | `number` | yes | Competitor identifier. |
