# Rename Keyword Group with SE Ranking Project

Updates an existing keyword group in SE Ranking.

## Endpoint

- **Method:** `PUT`
- **Path:** `/keyword-groups/:group_id`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Rename Keyword Group](https://seranking.com/api/project/keyword-groups/#rename-keyword-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `list<string>` | yes |
| `name` | body | `string` | yes |
