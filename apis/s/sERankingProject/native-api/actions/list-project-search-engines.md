# List Project Search Engines with SE Ranking Project

Retrieves search engine configurations for a project in SE Ranking.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/search-engines`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [List Project Search Engines](https://seranking.com/api/project/project-management/#list-project-search-engines)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes | Project site identifier from SE Ranking. |
