# Delete Project with SE Ranking Project

Deletes an existing project from SE Ranking.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Delete Project](https://seranking.com/api/project/project-management/#delete-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes | Project site identifier from SE Ranking. |
