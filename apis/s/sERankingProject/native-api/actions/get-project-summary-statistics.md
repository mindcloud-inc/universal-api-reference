# Get Project Summary Statistics with SE Ranking Project

Retrieves project summary statistics from SE Ranking.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/stat`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Get Project Summary Statistics](https://seranking.com/api/project/project-management/#summary-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes | Project site identifier from SE Ranking. |
