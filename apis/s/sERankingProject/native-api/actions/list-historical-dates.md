# List Historical Dates with SE Ranking Project

Retrieves historical ranking dates from SE Ranking.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/historicalDates`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [List Historical Dates](https://seranking.com/api/project/project-management/#historical-dates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `site_id` | path | `list<number>` | yes |
