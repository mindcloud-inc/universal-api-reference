# Add Keyword Group with SE Ranking Project

Creates a new keyword group in SE Ranking.

## Endpoint

- **Method:** `POST`
- **Path:** `/keyword-groups`
- **Base URL:** `https://api4.seranking.com`
- **Official documentation:** [Add Keyword Group](https://seranking.com/api/project/keyword-groups/#add-keyword-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `site_id` | body | `number` | yes |
