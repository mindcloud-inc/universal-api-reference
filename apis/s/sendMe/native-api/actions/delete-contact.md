# Delete Contact with SendMe

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/contacts/:id`
- **Base URL:** `https://app.sendme123.com`
- **Official documentation:** [Delete Contact](https://docs.sendme123.com/en/api/contacts/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique contact ID. |
