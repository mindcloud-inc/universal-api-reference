# Get Contact with SendMe

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/:id`
- **Base URL:** `https://app.sendme123.com`
- **Official documentation:** [Get Contact](https://docs.sendme123.com/en/api/contacts/get-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique contact ID. |
