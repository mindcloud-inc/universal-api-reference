# Delete Asset with Screenly

Deletes an existing asset from Screenly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assets/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Delete Asset](https://developer.screenly.io/api/#assets_delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
