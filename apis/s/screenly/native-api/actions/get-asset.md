# Get Asset with Screenly

Retrieves an asset from Screenly.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Get Asset](https://developer.screenly.io/api/#assets_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
