# Create Playlist with Screenly

Creates a new playlist in Screenly.

## Endpoint

- **Method:** `POST`
- **Path:** `/playlists/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Create Playlist](https://developer.screenly.io/api/#playlists_create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `is_enabled` | body | `boolean` | no |
| `predicate` | body | `string` | no |
| `priority` | body | `number` | no |
| `title` | body | `string` | no |
