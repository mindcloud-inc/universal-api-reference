# Create Group with Screenly

Creates a new group in Screenly.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Create Group](https://developer.screenly.io/api/#groups_create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
