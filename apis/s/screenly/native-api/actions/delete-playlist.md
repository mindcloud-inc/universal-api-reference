# Delete Playlist with Screenly

Deletes an existing playlist from Screenly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/playlists/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Delete Playlist](https://developer.screenly.io/api/#playlists_delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
