# Get Playlist with Screenly

Retrieves a playlist from Screenly.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlists/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Get Playlist](https://developer.screenly.io/api/#playlists_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
