# Get Group with Screenly

Retrieves a group from Screenly.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Get Group](https://developer.screenly.io/api/#groups_read)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
