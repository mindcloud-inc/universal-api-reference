# Delete Group with Screenly

Deletes an existing group from Screenly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:id/`
- **Base URL:** `https://api.screenlyapp.com/api/v3`
- **Official documentation:** [Delete Group](https://developer.screenly.io/api/#groups_delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
