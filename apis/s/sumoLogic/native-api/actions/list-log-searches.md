# List Log Searches with Sumo Logic

Retrieves saved log searches from Sumo Logic.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/logSearches`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Log Searches](https://api.sumologic.com/docs/#/logSearchesManagement/listLogSearches)

## Capabilities

This operation supports [pagination](../README.md#pagination).
