# List Data Masking Rules with Sumo Logic

Retrieves data masking rules from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dataMaskingRules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Data Masking Rules](https://api.sumologic.com/docs/#/dataMaskingManagement/listDataMaskingRules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
