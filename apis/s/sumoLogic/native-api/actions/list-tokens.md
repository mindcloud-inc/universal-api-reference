# List Tokens with Sumo Logic

Retrieves tokens from your Sumo Logic token library.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tokens`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Tokens](https://api.sumologic.com/docs/#/tokensLibraryManagement/listTokens)
