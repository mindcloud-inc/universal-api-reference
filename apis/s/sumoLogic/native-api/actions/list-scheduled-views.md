# List Scheduled Views with Sumo Logic

Retrieves scheduled views from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scheduledViews`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Scheduled Views](https://api.sumologic.com/docs/#/scheduledViewManagement/listScheduledViews)

## Capabilities

This operation supports [pagination](../README.md#pagination).
