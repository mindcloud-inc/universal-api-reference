# List Built-In Fields with Sumo Logic

Retrieves built-in fields from your Sumo Logic account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fields/builtin`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Built-In Fields](https://api.sumologic.com/docs/#/fieldManagementV1/listBuiltInFields)
