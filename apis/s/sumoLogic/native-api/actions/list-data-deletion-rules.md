# List Data Deletion Rules with Sumo Logic

Retrieves data deletion rules from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dataDeletionRules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Data Deletion Rules](https://api.sumologic.com/docs/#/dataDeletionRules/listDeletionRules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
