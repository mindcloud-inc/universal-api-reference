# List Log Data Forwarding Rules with Sumo Logic

Retrieves S3 data forwarding rules from Sumo Logic.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/logsDataForwarding/rules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Log Data Forwarding Rules](https://api.sumologic.com/docs/#/logsDataForwardingManagement/getRulesAndBuckets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
