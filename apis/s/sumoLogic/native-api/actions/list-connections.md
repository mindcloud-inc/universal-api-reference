# List Connections with Sumo Logic

Retrieves connections from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/connections`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Connections](https://api.sumologic.com/docs/#/connectionManagement/listConnections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
