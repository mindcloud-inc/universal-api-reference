# List Field Extraction Rules with Sumo Logic

Retrieves field extraction rules from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/extractionRules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Field Extraction Rules](https://api.sumologic.com/docs/#/extractionRuleManagement/listExtractionRules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
