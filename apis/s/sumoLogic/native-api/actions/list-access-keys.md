# List Access Keys with Sumo Logic

Retrieves access keys from your Sumo Logic account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accessKeys`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Access Keys](https://api.sumologic.com/docs/#/accessKeyManagement/listAccessKeys)

## Capabilities

This operation supports [pagination](../README.md#pagination).
