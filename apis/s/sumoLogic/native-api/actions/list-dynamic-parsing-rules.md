# List Dynamic Parsing Rules with Sumo Logic

Retrieves dynamic parsing rules from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/dynamicParsingRules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Dynamic Parsing Rules](https://api.sumologic.com/docs/#/dynamicParsingRuleManagement/listDynamicParsingRules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
