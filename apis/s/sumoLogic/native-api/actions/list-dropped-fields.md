# List Dropped Fields with Sumo Logic

Retrieves dropped fields from your Sumo Logic account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fields/dropped`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Dropped Fields](https://api.sumologic.com/docs/#/fieldManagementV1/listDroppedFields)
