# List Ingest Budgets with Sumo Logic

Retrieves ingest budgets from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/ingestBudgets`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Ingest Budgets](https://api.sumologic.com/docs/#/ingestBudgetManagementV2/listIngestBudgetsV2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
