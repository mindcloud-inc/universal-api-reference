# List Service Accounts with Sumo Logic

Retrieves service accounts from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/serviceAccounts`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Service Accounts](https://api.sumologic.com/docs/#/serviceAccountManagement/listServiceAccounts)
