# List Personal Access Keys with Sumo Logic

Retrieves access keys owned by your Sumo Logic user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accessKeys/personal`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Personal Access Keys](https://api.sumologic.com/docs/#/accessKeyManagement/listPersonalAccessKeys)
