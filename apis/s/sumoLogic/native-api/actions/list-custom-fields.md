# List Custom Fields with Sumo Logic

Retrieves custom fields from your Sumo Logic account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fields`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Custom Fields](https://api.sumologic.com/docs/#/fieldManagementV1/listCustomFields)
