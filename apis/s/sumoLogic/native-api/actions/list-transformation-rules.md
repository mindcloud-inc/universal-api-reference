# List Transformation Rules with Sumo Logic

Retrieves transformation rules from your Sumo Logic organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transformationRules`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Transformation Rules](https://api.sumologic.com/docs/#/transformationRuleManagement/getTransformationRules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
