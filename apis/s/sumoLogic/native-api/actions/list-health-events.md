# List Health Events with Sumo Logic

Retrieves unresolved health events from your Sumo Logic account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/healthEvents`
- **Base URL:** `https://api.sumologic.com/api`
- **Official documentation:** [List Health Events](https://api.sumologic.com/docs/#/healthEvents/listAllHealthEvents)

## Capabilities

This operation supports [pagination](../README.md#pagination).
