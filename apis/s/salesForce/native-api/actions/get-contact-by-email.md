# Get Contact by Email with Salesforce

## Endpoint

- **Method:** `GET`
- **Path:** `services/data/v61.0/query`
- **Base URL:** `https://{companyDomainName}.my.salesforce.com`
- **API:** REST

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
