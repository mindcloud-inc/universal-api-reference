# Create Record with Salesforce

## Endpoint

- **Method:** `POST`
- **Path:** `services/data/v61.0/sobjects/:objectId/`
- **Base URL:** `https://{companyDomainName}.my.salesforce.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `objectId` | path | `string` | no | The API name of the object to create. (i.e. Custom_Product_1) |
