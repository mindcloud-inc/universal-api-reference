# Shout Text with SHOUTCLOUD

## Endpoint

- **Method:** `POST`
- **Path:** `/V1/SHOUT`
- **Base URL:** `http://API.SHOUTCLOUD.IO`
- **Official documentation:** [Shout Text](https://github.com/SHOUTCLOUD/SHOUTCLOUD_NODE/blob/master/SHOUTCLOUD.js)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `INPUT` | body | `string` | yes | Text to transform. The original SHOUTCLOUD contract requires this exact uppercase JSON body key. |
