# Get Page with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/pages/:page_id`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Page](https://superthread.com/docs/api-docs/pages/get-a-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | Page ID to retrieve. |
| `team_id` | path | `string` | yes | Workspace ID for the Superthread workspace. |
