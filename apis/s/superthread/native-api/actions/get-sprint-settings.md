# Get Sprint Settings with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/sprints/settings`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Sprint Settings](https://superthread.com/docs/api-docs/sprints/get-sprint-settings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `string` | yes |
| `project_id` | query | `string` | yes |
