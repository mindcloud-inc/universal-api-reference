# Get Sprint with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/sprints/:sprint_id`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Sprint](https://superthread.com/docs/api-docs/sprints/get-a-sprint)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `string` | yes |
| `sprint_id` | path | `string` | yes |
