# List Spaces with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/projects`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [List Spaces](https://superthread.com/docs/api-docs/spaces/get-spaces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | yes | Workspace ID for the Superthread workspace. |
