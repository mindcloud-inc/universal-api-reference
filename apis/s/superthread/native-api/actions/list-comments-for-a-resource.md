# List Comments for a Resource with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/comments`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [List Comments for a Resource](https://superthread.com/docs/api-docs/comments/get-comments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `string` | yes |
| `page_id` | query | `string` | no |
| `card_id` | query | `string` | no |
| `filter` | query | `string` | no |
