# Get Card with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/cards/:card_id`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Card](https://superthread.com/docs/api-docs/cards/get-a-card)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card_id` | path | `string` | yes | Card ID to retrieve. |
| `team_id` | path | `string` | yes | Workspace ID for the Superthread workspace. |
