# List Team Members with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id/members`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [List Team Members](https://superthread.com/docs/api-docs/users/get-team-members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | yes | Workspace ID for the Superthread workspace. |
