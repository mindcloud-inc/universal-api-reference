# Get Comment with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/comments/:comment_id`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Comment](https://superthread.com/docs/api-docs/comments/get-a-comment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `string` | yes |
| `comment_id` | path | `string` | yes |
