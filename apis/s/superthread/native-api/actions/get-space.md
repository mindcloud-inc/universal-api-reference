# Get Space with Superthread

## Endpoint

- **Method:** `GET`
- **Path:** `/:team_id/projects/:project_id`
- **Base URL:** `https://api.superthread.com/v1`
- **Official documentation:** [Get Space](https://superthread.com/docs/api-docs/spaces/get-a-space)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Space ID to retrieve. |
| `team_id` | path | `string` | yes | Workspace ID for the Superthread workspace. |
