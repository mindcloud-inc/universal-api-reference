# List Hours with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/hours/hours`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Hours](https://developer.simplicate.com/docs/api/v2/reference/get-hours-hours/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
