# Get Person with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/person/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Person](https://developer.simplicate.com/docs/api/v2/reference/get-crm-person-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The person's id |
