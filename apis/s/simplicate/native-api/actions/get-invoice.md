# Get Invoice with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/invoice/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Invoice](https://developer.simplicate.com/docs/api/v2/reference/get-invoices-invoice-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice identifier. |
