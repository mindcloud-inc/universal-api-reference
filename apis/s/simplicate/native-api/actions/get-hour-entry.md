# Get Hour Entry with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/hours/hours/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Hour Entry](https://developer.simplicate.com/docs/api/v2/reference/get-hours-hours-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Hour entry identifier. |
