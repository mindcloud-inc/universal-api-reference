# List Organizations with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/organization`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Organizations](https://developer.simplicate.com/docs/api/v2/reference/get-crm-organization/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
