# List Payments with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/payment`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Payments](https://developer.simplicate.com/docs/api/v2/reference/get-invoices-payment/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
