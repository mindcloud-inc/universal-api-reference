# List Services with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/service`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Services](https://developer.simplicate.com/docs/api/v2/reference/get-projects-service/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
