# Get Project with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/project/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Project](https://developer.simplicate.com/docs/api/v2/reference/get-projects-project-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project id |
