# List Invoices with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/invoice`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Invoices](https://developer.simplicate.com/docs/api/v2/reference/get-invoices-invoice/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
