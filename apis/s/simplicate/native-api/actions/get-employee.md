# Get Employee with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/hrm/employee/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Employee](https://developer.simplicate.com/docs/api/v2/reference/get-hrm-employee-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Employee identifier. |
