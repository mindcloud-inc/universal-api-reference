# Get Service with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/service/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Service](https://developer.simplicate.com/docs/api/v2/reference/get-projects-service-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Project service identifier. |
