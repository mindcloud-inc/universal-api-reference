# Get Organization with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/organization/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Organization](https://developer.simplicate.com/docs/api/v2/reference/get-crm-organization-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Organization id path parameter from the Simplicate get organization by id endpoint. |
