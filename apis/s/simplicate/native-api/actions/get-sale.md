# Get Sale with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/sales/sales/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Sale](https://developer.simplicate.com/docs/api/v2/reference/get-sales-sales-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The sale id |
