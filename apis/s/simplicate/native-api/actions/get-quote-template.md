# Get Quote Template with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/sales/quote/:id`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [Get Quote Template](https://developer.simplicate.com/docs/api/v2/reference/get-sales-quote-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The quote template id |
