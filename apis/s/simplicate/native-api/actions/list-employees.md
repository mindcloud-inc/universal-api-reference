# List Employees with Simplicate

## Endpoint

- **Method:** `GET`
- **Path:** `/hrm/employee`
- **Base URL:** `https://{subdomain}/api/v2`
- **Official documentation:** [List Employees](https://developer.simplicate.com/docs/api/v2/reference/get-hrm-employee/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
