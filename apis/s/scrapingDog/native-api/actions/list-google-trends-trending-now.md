# List Google Trends Trending Now with ScrapingDog

Retrieves trending-now topics from Google Trends through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_trends/trending_now`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [List Google Trends Trending Now](https://docs.scrapingdog.com/google-trends-api/google-trends-trending-now-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `geo` | query | `string` | no | Geographic origin for trending-now results, such as US. |
