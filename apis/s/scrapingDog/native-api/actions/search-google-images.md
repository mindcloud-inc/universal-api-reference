# Search Google Images with ScrapingDog

Retrieves Google Images search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_images`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Images](https://docs.scrapingdog.com/google-images-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Images. |
