# Get Google News Headlines with ScrapingDog

Retrieves Google News headlines through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_news/v2`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google News Headlines](https://docs.scrapingdog.com/google-news-scraper-apis/google-news-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Query to filter Google News headline results. |
