# Search Google with ScrapingDog

Retrieves Google search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google](https://docs.scrapingdog.com/google-search-scraper-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query to run on Google. |
