# Search Google Jobs with ScrapingDog

Retrieves Google Jobs search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_jobs`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Jobs](https://docs.scrapingdog.com/google-jobs-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Jobs. |
