# Capture Screenshot with ScrapingDog

Captures a webpage screenshot through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/screenshot`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Capture Screenshot](https://docs.scrapingdog.com/screenshot-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Target URL to capture as a screenshot. |
