# Search DuckDuckGo with ScrapingDog

Retrieves DuckDuckGo search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/duckduckgo/search`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search DuckDuckGo](https://docs.scrapingdog.com/duckduckgo-scraper-api/duckduckgo-search-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for DuckDuckGo. |
