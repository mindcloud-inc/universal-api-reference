# Get Google AI Overview with ScrapingDog

Retrieves Google AI Overview results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google/ai_overview`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google AI Overview](https://docs.scrapingdog.com/google-ai-overview-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query to run for Google AI Overview. |
