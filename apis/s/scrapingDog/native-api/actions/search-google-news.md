# Search Google News with ScrapingDog

Retrieves Google News search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_news`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google News](https://docs.scrapingdog.com/google-news-scraper-apis/google-news-search-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google News. |
