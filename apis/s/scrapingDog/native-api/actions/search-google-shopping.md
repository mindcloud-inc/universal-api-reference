# Search Google Shopping with ScrapingDog

Retrieves Google Shopping search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_shopping`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Shopping](https://docs.scrapingdog.com/google-shopping-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Shopping. |
