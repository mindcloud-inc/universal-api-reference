# Autocomplete Google with ScrapingDog

Retrieves Google autocomplete suggestions through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_autocomplete`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Autocomplete Google](https://docs.scrapingdog.com/google-autocomplete-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google autocomplete suggestions. |
