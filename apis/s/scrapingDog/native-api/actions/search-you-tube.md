# Search YouTube with ScrapingDog

Retrieves YouTube search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/youtube/search`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search YouTube](https://docs.scrapingdog.com/youtube-scraper-api/youtube-search-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search_query` | query | `string` | yes | Search query for YouTube. |
