# Get YouTube Transcripts with ScrapingDog

Retrieves YouTube transcripts through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/youtube/transcripts`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get YouTube Transcripts](https://docs.scrapingdog.com/youtube-scraper-api/youtube-transcripts-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `v` | query | `string` | yes | YouTube video identifier. |
