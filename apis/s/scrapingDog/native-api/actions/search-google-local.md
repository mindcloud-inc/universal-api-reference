# Search Google Local with ScrapingDog

Retrieves Google Local search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_local`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Local](https://docs.scrapingdog.com/google-local-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Local. |
