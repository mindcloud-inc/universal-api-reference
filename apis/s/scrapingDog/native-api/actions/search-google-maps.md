# Search Google Maps with ScrapingDog

Retrieves Google Maps search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_maps`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Maps](https://docs.scrapingdog.com/google-maps-api/google-maps-search-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query to run on Google Maps. |
