# Get Google Finance with ScrapingDog

Retrieves Google Finance data through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_finance`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google Finance](https://docs.scrapingdog.com/google-finance-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Ticker or finance query to search on Google Finance. |
