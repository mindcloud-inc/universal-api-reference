# Scrape Web Page with ScrapingDog

Retrieves webpage content through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Scrape Web Page](https://docs.scrapingdog.com/web-scraping-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Target URL to scrape. |
