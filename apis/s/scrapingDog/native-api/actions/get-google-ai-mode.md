# Get Google AI Mode with ScrapingDog

Retrieves Google AI Mode results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google/ai_mode`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google AI Mode](https://docs.scrapingdog.com/google-ai-mode-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query to run for Google AI Mode. |
