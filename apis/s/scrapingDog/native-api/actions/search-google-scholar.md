# Search Google Scholar with ScrapingDog

Retrieves Google Scholar search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_scholar`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Scholar](https://docs.scrapingdog.com/google-scholar-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Scholar. |
