# Search Google Videos with ScrapingDog

Retrieves Google Videos search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_videos`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Google Videos](https://docs.scrapingdog.com/google-videos-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Google Videos. |
