# List Google Maps Photos with ScrapingDog

Retrieves Google Maps photos through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_maps/photos`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [List Google Maps Photos](https://docs.scrapingdog.com/google-maps-api/google-maps-photos-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data_id` | query | `string` | yes | Google Maps data_id value for the business or place. |
