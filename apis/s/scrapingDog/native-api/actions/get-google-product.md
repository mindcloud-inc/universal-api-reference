# Get Google Product with ScrapingDog

Retrieves Google product details through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_product`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google Product](https://docs.scrapingdog.com/google-product-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | query | `string` | yes | Google Shopping product ID to retrieve. |
