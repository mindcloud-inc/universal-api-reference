# Get Google Scholar Citation Formats with ScrapingDog

Retrieves Google Scholar citation formats through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_scholar/cite`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Get Google Scholar Citation Formats](https://docs.scrapingdog.com/google-scholar-api/google-scholar-cite-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Citation identifier or query token to retrieve Google Scholar citation formats. |
