# Run Universal Search with ScrapingDog

Retrieves universal search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Run Universal Search](https://docs.scrapingdog.com/universal-search-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Universal Search. |
