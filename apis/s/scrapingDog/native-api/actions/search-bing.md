# Search Bing with ScrapingDog

Retrieves Bing search results through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/bing/search`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [Search Bing](https://docs.scrapingdog.com/bing-search-scraper-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query for Bing. |
