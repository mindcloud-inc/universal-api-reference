# List Google Maps Posts with ScrapingDog

Retrieves Google Maps posts through ScrapingDog.

## Endpoint

- **Method:** `GET`
- **Path:** `/google_maps/posts`
- **Base URL:** `https://api.scrapingdog.com`
- **Official documentation:** [List Google Maps Posts](https://docs.scrapingdog.com/google-maps-api/google-maps-posts-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data_id` | query | `string` | yes | Google Maps data_id value for the business or place. |
