# Get Journal Entries Summary with ServiceTitan

Gets a list of journal entry items aggregated by account and business unit.

## Endpoint

- **Method:** `GET`
- **Path:** `accounting/v2/tenant/{tenant}/journal-entries/:id/details`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [Get Journal Entries Summary](https://developer.servicetitan.io/docs/apis/tenant-accounting-v2/endpoints/JournalEntries_GetSummary)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
