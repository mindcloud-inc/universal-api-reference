# Add Customer Tag with ServiceTitan

## Endpoint

- **Method:** `POST`
- **Path:** `crm/v2/tenant/{tenant}/customers/:customerId/tags/:tagTypeId`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `string` | no |
| `tagTypeId` | path | `string` | no |
