# Get Payment Terms with ServiceTitan

Retrieves payment terms from ServiceTitan.

## Endpoint

- **Method:** `GET`
- **Path:** `accounting/v2/tenant/{tenant}/payment-terms`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [Get Payment Terms](https://developer.servicetitan.io/docs/apis/tenant-accounting-v2/endpoints/PaymentTerms_GetList)
