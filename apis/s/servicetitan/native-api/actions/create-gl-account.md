# Create GL Account with ServiceTitan

## Endpoint

- **Method:** `POST`
- **Path:** `accounting/v2/tenant/{tenant}/gl-accounts`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `number` | body | `string` | no |
| `description` | body | `string` | no |
| `type` | body | `string` | no |
| `subtype` | body | `string` | no |
