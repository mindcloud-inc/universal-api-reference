# Get Journal Entries Details with ServiceTitan

Gets a list of journal entry items aggregated by account, business unit, transaction and pricebook item.

## Endpoint

- **Method:** `GET`
- **Path:** `accounting/v2/tenant/{tenant}/journal-entries/:id/details`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [Get Journal Entries Details](https://developer.servicetitan.io/docs/apis/tenant-accounting-v2/endpoints/JournalEntries_GetDetails)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
