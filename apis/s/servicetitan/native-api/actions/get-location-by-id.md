# Get Location By Id with ServiceTitan

Retrieves a location from ServiceTitan by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `crm/v2/tenant/{tenant}/locations/:id`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
