# Update GL Account with ServiceTitan

## Endpoint

- **Method:** `PATCH`
- **Path:** `accounting/v2/tenant/{tenant}/gl-accounts/:id`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `number` | body | `string` | no |
| `description` | body | `string` | no |
| `type` | body | `string` | no |
| `subtype` | body | `string` | no |
| `id` | path | `string` | no |
