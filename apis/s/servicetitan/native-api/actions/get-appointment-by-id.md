# Get Appointment by Id with ServiceTitan

Retrieves an appointment from ServiceTitan by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.servicetitan.io/jpm/v2/tenant/{tenant}/appointments/:id`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | no |
