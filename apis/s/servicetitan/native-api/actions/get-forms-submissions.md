# Get Forms Submissions with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `forms/v2/tenant/{tenant}/submissions`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `submittedOnOrAfter` | query | `string` | no |
| `formIds` | query | `string` | no |
