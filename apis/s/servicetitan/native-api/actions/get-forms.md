# Get Forms with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `forms/v2/tenant/{tenant}/forms?:from&:includeRecentChanges`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `from` | path | `string` | no |
| `includeRecentChanges` | path | `boolean` | no |
