# Update Purchase Order with ServiceTitan

## Endpoint

- **Method:** `PATCH`
- **Path:** `accounting/v2/tenant/{tenant}/purchase-orders/:id`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Purchase Order ID |
| `customFields[]` | body | `array` | no | — |
