# Get Project with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `/jpm/v2/tenant/{tenant}/projects/:id`
- **Base URL:** `https://{baseUrl}/`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
