# List Customers Contacts with ServiceTitan

Retrieves customer contacts from ServiceTitan.

## Endpoint

- **Method:** `GET`
- **Path:** `crm/v2/tenant/{tenant}/customers/contacts`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [List Customers Contacts](https://developer.servicetitan.io/api-details/#api=tenant-crm-v2&operation=Customers_GetContactList)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `modifiedOnOrAfter` | query | `string` | no |
