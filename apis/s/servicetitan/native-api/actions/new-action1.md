# Update Location Tags with ServiceTitan

## Endpoint

- **Method:** `PATCH`
- **Path:** `crm/v2/tenant/{tenant}/locations/:id`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `body` | body | `string` | no |
| `id` | path | `string` | yes |
