# Export Purchase Orders with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `inventory/v2/tenant/{tenant}/export/purchase-orders?:from&:includeRecentChanges`
- **Base URL:** `https://{baseUrl}/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `from` | path | `string` | no |
| `includeRecentChanges` | path | `boolean` | no |
