# Get Projects with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `/jpm/v2/tenant/{tenant}/projects`
- **Base URL:** `https://{baseUrl}/`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | query | `string` | no |
| `locationId` | query | `string` | no |
| `projectTypeId` | query | `string` | no |
| `jobId` | query | `string` | no |
