# Get Campaigns with ServiceTitan

Gets a paginated list of campaigns

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.servicetitan.io/marketing/v2/tenant/{tenant}/campaigns`
- **Base URL:** `https://{baseUrl}/`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | no |
| `campaignPhoneNumber` | query | `string` | no |
