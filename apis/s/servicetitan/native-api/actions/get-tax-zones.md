# Get Tax Zones with ServiceTitan

Retrieves tax zones from ServiceTitan.

## Endpoint

- **Method:** `GET`
- **Path:** `accounting/v2/tenant/{tenant}/tax-zones`
- **Base URL:** `https://{baseUrl}/`
- **Official documentation:** [Get Tax Zones](https://developer.servicetitan.io/docs/api-resources-accounting/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
