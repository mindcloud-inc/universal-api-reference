# Get Services by Id with ServiceTitan

## Endpoint

- **Method:** `GET`
- **Path:** `pricebook/v2/tenant/{tenant}/services/:id`
- **Base URL:** `https://{baseUrl}/`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
