# Rename favorite widget's title with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/favorite-widgets/{id}/rename`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Rename favorite widget's title](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of entity |
