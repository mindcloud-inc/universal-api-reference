# Translate widget values with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/translate`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Translate widget values](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text[]` | body | `array<string>` | no | Values to translate |
| `text[]` | body | `array<string>` | no | Values to translate |
| `languages[]` | body | `array<string>` | no | Target languages |
| `languages[]` | body | `array<string>` | no | Target languages |
