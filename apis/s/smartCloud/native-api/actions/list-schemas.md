# All products (in production status) schemas with 2Smart Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/schemas`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [All products (in production status) schemas](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendor_id[]` | query | `array<number>` | no | ID of vendor |
| `product_id[]` | query | `array<number>` | no | IDs of products |
