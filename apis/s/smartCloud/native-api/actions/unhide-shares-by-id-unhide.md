# Unhide share with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/shares/{id}/unhide`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Unhide share](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Share identifier |
| `data` | body | `object` | yes | Share unhide payload |
