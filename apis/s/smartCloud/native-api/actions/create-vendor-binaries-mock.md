# Binary mock upload with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/binaries-mock`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Binary mock upload](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_version_id` | query | `number` | yes | Id of a product version for which build is uploading |
