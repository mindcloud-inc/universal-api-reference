# Show share link with 2Smart Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/share-links/{id}`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Show share link](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Share link identifier |
