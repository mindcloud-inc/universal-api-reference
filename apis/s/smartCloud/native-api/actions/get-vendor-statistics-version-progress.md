# Pie statistics with 2Smart Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/vendor/statistics/version-progress`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Pie statistics](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | query | `number` | yes | ID of product |
| `version` | query | `number` | yes | Version of firmware |
