# Update notification config with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/notification-configs/{id}/update`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Update notification config](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of entity |
| `data` | body | `object` | yes | — |
