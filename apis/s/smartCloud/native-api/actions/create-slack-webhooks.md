# Add slack webhook with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/slack-webhooks`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Add slack webhook](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Slack webhook payload |
