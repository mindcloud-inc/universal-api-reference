# Login vendor with Google with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/login/google`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Login vendor with Google](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idToken` | body | `string` | yes | Google ID token |
