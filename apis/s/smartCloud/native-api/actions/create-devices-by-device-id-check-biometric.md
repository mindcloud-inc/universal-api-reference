# Check if there is biometric keys for this device with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/devices/{device_id}/check-biometric`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Check if there is biometric keys for this device](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_id` | path | `string` | yes | Device ID in broker |
