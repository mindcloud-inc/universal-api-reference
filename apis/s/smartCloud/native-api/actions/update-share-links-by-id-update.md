# Update share link with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/share-links/{id}/update`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Update share link](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Share link identifier |
| `data` | body | `object` | yes | Share link update payload |
