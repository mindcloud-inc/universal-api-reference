# Request vendor reset password with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/request-reset-password`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Request vendor reset password](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | User login email |
