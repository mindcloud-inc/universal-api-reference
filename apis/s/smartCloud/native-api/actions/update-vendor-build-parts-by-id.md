- **Method:** `POST`

- **Official documentation:** [Update build part](https://cloud.2smart.com/swagger/)

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of entity |
