# Create favorite widget group with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/devices/{device_id}/credentials`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Create favorite widget group](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_id` | path | `string` | yes | Device ID in broker |
