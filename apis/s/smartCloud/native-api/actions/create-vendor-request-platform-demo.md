# Request platform demo with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/request-platform-demo`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Request platform demo](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | user name |
| `message` | body | `string` | yes | Message describing request |
