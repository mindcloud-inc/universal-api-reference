# Reset mobile password with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/users/reset-password`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Reset mobile password](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data` | body | `object` | no |
| `required` | body | `string` | no |
