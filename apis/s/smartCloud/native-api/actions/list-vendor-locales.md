# List locales with 2Smart Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/vendor/locales`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [List locales](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity_id` | query | `number` | no | ID of product version |
| `language` | query | `string` | no | Language of locale |
| `type` | query | `string` | no | Type of locale |
