# Link vendor account to mobile with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/link-mobile`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Link vendor account to mobile](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | body | `string` | yes | JWT token from email to link account |
