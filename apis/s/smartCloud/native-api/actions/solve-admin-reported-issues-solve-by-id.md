# Set report as solved with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/reported-issues/solve/{id}`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Set report as solved](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of entity |
