# Login vendor with Apple with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/login/apple`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Login vendor with Apple](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identityToken` | body | `string` | yes | Apple identity token |
