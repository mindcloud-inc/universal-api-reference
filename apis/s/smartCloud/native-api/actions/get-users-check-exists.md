# Register mobile user with 2Smart Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/users/check-exists`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Register mobile user](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | User email |
