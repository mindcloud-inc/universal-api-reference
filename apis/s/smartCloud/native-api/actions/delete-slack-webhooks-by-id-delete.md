# Delete slack webhook with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/slack-webhooks/{id}/delete`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Delete slack webhook](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Slack webhook identifier |
