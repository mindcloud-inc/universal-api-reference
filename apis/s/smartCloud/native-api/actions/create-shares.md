# Create share with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/shares`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Create share](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data[]` | body | `array<object>` | yes | Share payload list |
