# Create api token with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/api-tokens`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Create api token](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Api Token name |
