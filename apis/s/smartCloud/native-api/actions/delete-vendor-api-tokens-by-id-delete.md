# Delete api token with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/api-tokens/{id}/delete`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Delete api token](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of entity |
