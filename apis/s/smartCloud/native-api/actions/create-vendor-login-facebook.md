# Login vendor with Facebook with 2Smart Cloud

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor/login/facebook`
- **Base URL:** `https://cloud.2smart.com/robot/v1`
- **Official documentation:** [Login vendor with Facebook](https://cloud.2smart.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accessToken` | body | `string` | yes | Facebook access token |
