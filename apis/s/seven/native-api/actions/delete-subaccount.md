# Delete Subaccount with Seven

Deletes a subaccount from Seven.

## Endpoint

- **Method:** `POST`
- **Path:** `/subaccounts?action=delete`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Delete Subaccount](https://docs.seven.io/en/rest-api/endpoints/subaccounts#deleting-subaccounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | ID of the subaccount. |
