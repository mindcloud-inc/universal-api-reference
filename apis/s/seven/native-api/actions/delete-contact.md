# Delete Contact with Seven

Deletes a contact from Seven.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Delete Contact](https://docs.seven.io/en/rest-api/endpoints/contacts#delete-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
