# Update Contact with Seven

Updates an existing contact in Seven.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts/:id`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Update Contact](https://docs.seven.io/en/rest-api/endpoints/contacts#update-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
