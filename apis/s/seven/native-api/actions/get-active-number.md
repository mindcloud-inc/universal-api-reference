# Get Active Number with Seven

Retrieves an active number from Seven.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers/active/:number`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Get Active Number](https://docs.seven.io/en/rest-api/endpoints/numbers#get-single-active-number)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | path | `string` | yes | The phone number to get details for. |
