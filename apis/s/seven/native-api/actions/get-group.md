# Get Group with Seven

Retrieves a group from Seven.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Get Group](https://docs.seven.io/en/rest-api/endpoints/groups#retrieve-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
