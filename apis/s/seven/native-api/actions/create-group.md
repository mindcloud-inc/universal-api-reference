# Create Group with Seven

Creates a new group in Seven.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Create Group](https://docs.seven.io/en/rest-api/endpoints/groups#create-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the group |
