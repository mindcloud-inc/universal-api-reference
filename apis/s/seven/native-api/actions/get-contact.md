# Get Contact with Seven

Retrieves a contact from Seven.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://gateway.seven.io/api`
- **Official documentation:** [Get Contact](https://docs.seven.io/en/rest-api/endpoints/contacts#retrieve-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
