# Get Plan with SmartRoutes

## Endpoint

- **Method:** `GET`
- **Path:** `/plans/:id`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [Get Plan](https://api.smartroutes.io/v2/docs/api/#tag/Plans/paths/~1plans~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the plan to retrieve. |
