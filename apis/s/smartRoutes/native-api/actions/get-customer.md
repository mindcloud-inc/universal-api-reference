- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [Get Customer](https://api.smartroutes.io/v2/docs/api/#tag/Customers/paths/~1customers~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the customer to retrieve. |
