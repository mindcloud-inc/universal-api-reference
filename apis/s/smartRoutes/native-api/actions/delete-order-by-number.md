# Delete Order By Number with SmartRoutes

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/order-number/:order_number`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [Delete Order By Number](https://api.smartroutes.io/v2/docs/api/#tag/Orders/paths/~1orders~1order-number~1{order_number}/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_number` | path | `string` | yes | Order number of the order to delete. |
