# Get Vehicle with SmartRoutes

## Endpoint

- **Method:** `GET`
- **Path:** `/vehicles/:id`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [Get Vehicle](https://api.smartroutes.io/v2/docs/api/#tag/Vehicles/paths/~1vehicles~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the vehicle to retrieve. |
