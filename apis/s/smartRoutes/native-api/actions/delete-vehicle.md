# Delete Vehicle with SmartRoutes

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vehicles/:id`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [Delete Vehicle](https://api.smartroutes.io/v2/docs/api/#tag/Vehicles/paths/~1vehicles~1{id}/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the vehicle to delete. |
