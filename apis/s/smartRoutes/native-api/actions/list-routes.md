# List Routes with SmartRoutes

## Endpoint

- **Method:** `GET`
- **Path:** `/routes`
- **Base URL:** `https://api.smartroutes.io/v2`
- **Official documentation:** [List Routes](https://api.smartroutes.io/v2/docs/api/#tag/Routes/paths/~1routes/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `updated_at_min` | query | `date` | no | Minimum updated date and time for filtering. |
