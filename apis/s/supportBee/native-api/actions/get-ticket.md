# Get Ticket with SupportBee

Retrieves a ticket from SupportBee.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:id`
- **Base URL:** `https://{company}.supportbee.com`
- **Official documentation:** [Get Ticket](https://supportbee.com/docs/api/reference#tag/Tickets/paths/~1tickets~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SupportBee ticket ID. |
