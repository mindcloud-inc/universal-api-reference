# Archive Ticket with SupportBee

Archives a ticket in SupportBee.

## Endpoint

- **Method:** `POST`
- **Path:** `/tickets/:id/archive`
- **Base URL:** `https://{company}.supportbee.com`
- **Official documentation:** [Archive Ticket](https://supportbee.com/docs/api/reference#tag/Tickets/paths/~1tickets~1{id}~1archive/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SupportBee ticket ID. |
