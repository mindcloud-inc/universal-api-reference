# Mark Ticket Answered with SupportBee

Marks a SupportBee ticket as answered.

## Endpoint

- **Method:** `POST`
- **Path:** `/tickets/:id/answered`
- **Base URL:** `https://{company}.supportbee.com`
- **Official documentation:** [Mark Ticket Answered](https://supportbee.com/docs/api/reference#tag/Tickets/paths/~1tickets~1{id}~1answered/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | SupportBee ticket ID. |
