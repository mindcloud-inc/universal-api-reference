# Get API Usage with SelectPdf

## Endpoint

- **Method:** `GET`
- **Path:** `/usage/`
- **Base URL:** `https://selectpdf.com/api2`
- **Official documentation:** [Get API Usage](https://selectpdf.com/html-to-pdf-api/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `get_history` | query | `boolean` | no | Include monthly conversion history in the response. |
