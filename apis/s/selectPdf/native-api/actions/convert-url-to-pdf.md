# Convert URL to PDF with SelectPdf

## Endpoint

- **Method:** `GET`
- **Path:** `/convert/`
- **Base URL:** `https://selectpdf.com/api2`
- **Official documentation:** [Convert URL to PDF](https://selectpdf.com/html-to-pdf-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The public web page URL to convert into a PDF. |
