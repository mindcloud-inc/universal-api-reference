# Delete Vehicle with SimpliRoute

Deletes an existing vehicle from SimpliRoute.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/routes/vehicles/:vehicle_id/`
- **Base URL:** `https://api.simpliroute.com`
- **Official documentation:** [Delete Vehicle](https://documentation.simpliroute.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicle_id` | path | `number` | yes | The SimpliRoute vehicle ID. |
