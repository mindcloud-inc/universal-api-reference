# Delete User with SimpliRoute

Deletes an existing driver from SimpliRoute.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/accounts/drivers/:user_id/`
- **Base URL:** `https://api.simpliroute.com`
- **Official documentation:** [Delete User](https://documentation.simpliroute.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | The SimpliRoute driver ID. |
