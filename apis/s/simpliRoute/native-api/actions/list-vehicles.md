# List Vehicles with SimpliRoute

Retrieves vehicles from SimpliRoute.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/routes/vehicles/`
- **Base URL:** `https://api.simpliroute.com`
- **Official documentation:** [List Vehicles](https://documentation.simpliroute.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_extra_properties` | query | `boolean` | no | When true, include the extraProperties object in the response. |
