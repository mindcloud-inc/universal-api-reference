# Get User with SimpliRoute

Retrieves a driver from SimpliRoute by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/drivers/:user_id/`
- **Base URL:** `https://api.simpliroute.com`
- **Official documentation:** [Get User](https://documentation.simpliroute.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | The SimpliRoute driver ID. |
