# Get datasource with smapOne

Retrieves a data source from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/intern/DataSource/{dataSourceId}`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [Get datasource](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSourceId` | path | `string` | yes | The datasource id. |
