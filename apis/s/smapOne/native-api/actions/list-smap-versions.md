# List smap versions with smapOne

Retrieves smap versions from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/Smaps/{smapId}/Versions`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [List smap versions](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smapId` | path | `string` | yes | The smap id. |
