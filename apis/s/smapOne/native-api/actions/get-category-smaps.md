# Get category smaps with smapOne

Retrieves smaps in a category from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/smaps/overview/categories/{categoryId}`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [Get category smaps](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `string` | yes | The category id. |
