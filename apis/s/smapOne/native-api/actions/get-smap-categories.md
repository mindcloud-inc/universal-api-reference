# Get smap categories with smapOne

Retrieves categories for a smap from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/smaps/overview/{smapId}/categories`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [Get smap categories](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smapId` | path | `string` | yes | The smap id. |
