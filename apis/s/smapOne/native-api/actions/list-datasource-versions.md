# List datasource versions with smapOne

Retrieves data source versions from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/intern/DataSource/{dataSourceId}/Versions`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [List datasource versions](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSourceId` | path | `string` | yes | The datasource id. |
