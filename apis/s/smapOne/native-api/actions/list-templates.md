# List templates with smapOne

Retrieves smap templates from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/intern/Templates/Smaps`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [List templates](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | no | Optional template filter text. |
