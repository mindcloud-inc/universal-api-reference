# Get smap with smapOne

Retrieves a smap from smapOne.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/Smaps/{smapId}`
- **Base URL:** `https://platform.smapone.com/Backend`
- **Official documentation:** [Get smap](https://platform.smapone.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smapId` | path | `string` | yes | The smap id. |
