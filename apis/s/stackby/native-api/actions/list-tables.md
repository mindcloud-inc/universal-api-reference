# List Tables with Stackby

Retrieves tables from a Stackby stack.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/tablelist/{{stackId}}`
- **Base URL:** `https://stackby.com/api`
- **Official documentation:** [List Tables](https://www.postman.com/lively-equinox-180638/stackby-s-public-workspace/documentation/d7webc7/stackby-extensive-developer-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stackId` | path | `string` | yes | Stack identifier from Stackby. |
