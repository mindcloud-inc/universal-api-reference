# List Workspaces with Stackby

Retrieves workspaces from Stackby.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/workspacelist`
- **Base URL:** `https://stackby.com/api`
- **Official documentation:** [List Workspaces](https://www.postman.com/lively-equinox-180638/stackby-s-public-workspace/documentation/d7webc7/stackby-extensive-developer-api)
