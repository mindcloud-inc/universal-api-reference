# Get service account with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/serviceAccount/{serviceAccountId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get service account](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceAccountId` | path | `string` | yes | Starburst Galaxy service account ID. |
