# Get data product with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/dataProduct/{dataProductId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get data product](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataProductId` | path | `string` | yes | Starburst Galaxy data product ID. |
