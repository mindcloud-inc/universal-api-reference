# Get user with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/user/{userId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get user](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | Starburst Galaxy user ID. Docs also support URL-encoded lookup expressions such as email=value. |
