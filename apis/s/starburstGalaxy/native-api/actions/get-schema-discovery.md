# Get schema discovery with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/schemaDiscovery/{schemaDiscoveryId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get schema discovery](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemaDiscoveryId` | path | `string` | yes | Starburst Galaxy schema discovery ID. |
