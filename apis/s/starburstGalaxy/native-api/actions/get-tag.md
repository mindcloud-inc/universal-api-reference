# Get tag with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/tag/{tagId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get tag](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Starburst Galaxy tag ID. Docs also support URL-encoded lookup expressions such as name=value. |
