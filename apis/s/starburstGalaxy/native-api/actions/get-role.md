# Get role with Starburst Galaxy

## Endpoint

- **Method:** `GET`
- **Path:** `/public/api/v1/role/{roleId}`
- **Base URL:** `https://mindcloud.galaxy.starburst.io`
- **Official documentation:** [Get role](https://galaxy.starburst.io/public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | yes | Starburst Galaxy role ID. Docs also support URL-encoded lookup expressions such as name=value. |
