# List Related Accounts with Sage Sales Management

Retrieves related accounts from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountsRelated`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Related Accounts](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
