# Get Accounts Schema with Sage Sales Management

Retrieves the accounts schema from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/schema`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Get Accounts Schema](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
