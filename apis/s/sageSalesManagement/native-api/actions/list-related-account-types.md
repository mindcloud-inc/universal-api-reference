# List Related Account Types with Sage Sales Management

Retrieves related account types from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountsRelations`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Related Account Types](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
