# List Activity Types with Sage Sales Management

Retrieves activity types from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/activityTypes`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Activity Types](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
