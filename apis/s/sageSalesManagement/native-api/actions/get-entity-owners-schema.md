# Get Entity Owners Schema with Sage Sales Management

Retrieves the entity owners schema from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/entityOwners/schema`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Get Entity Owners Schema](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
