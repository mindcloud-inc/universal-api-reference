# List Sales Orders with Sage Sales Management

Retrieves sales orders from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/salesorders`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Sales Orders](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
