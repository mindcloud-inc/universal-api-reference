# List Currencies with Sage Sales Management

Retrieves currencies from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/currencies`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Currencies](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
