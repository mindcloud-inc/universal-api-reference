# Get Resources with Sage Sales Management

Retrieves a resources from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Get Resources](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
