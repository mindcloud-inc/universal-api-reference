# List Time Zones with Sage Sales Management

Retrieves time zones from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/timezones`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Time Zones](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
