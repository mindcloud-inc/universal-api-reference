# List Account Addresses with Sage Sales Management

Retrieves account addresses from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountAddresses`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Account Addresses](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
