# List Campaign Questions with Sage Sales Management

Retrieves campaign questions from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaignQuestions`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Campaign Questions](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
