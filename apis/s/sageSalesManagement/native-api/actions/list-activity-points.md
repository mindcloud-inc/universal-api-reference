# List Activity Points with Sage Sales Management

Retrieves activity points from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/activity/points`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Activity Points](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
