# Get Account Types Schema with Sage Sales Management

Retrieves the account types schema from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/accountTypes/schema`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Get Account Types Schema](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
