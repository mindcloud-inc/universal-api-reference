# List Order Lines with Sage Sales Management

Retrieves order lines from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/salesordersLines`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Order Lines](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
