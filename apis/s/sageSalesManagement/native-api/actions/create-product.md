# Create Product with Sage Sales Management

Creates a product in Sage Sales Management.

## Endpoint

- **Method:** `POST`
- **Path:** `/products`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Create Product](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
