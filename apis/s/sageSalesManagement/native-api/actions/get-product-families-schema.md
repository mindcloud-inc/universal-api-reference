# Get Product Families Schema with Sage Sales Management

Retrieves the product families schema from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/productFamilies/schema`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [Get Product Families Schema](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
