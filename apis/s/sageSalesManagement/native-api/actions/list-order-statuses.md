# List Order Statuses with Sage Sales Management

Retrieves order statuses from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/salesorderStatuses`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Order Statuses](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
