# List Product Families with Sage Sales Management

Retrieves product families from Sage Sales Management.

## Endpoint

- **Method:** `GET`
- **Path:** `/productFamilies`
- **Base URL:** `https://api.forcemanager.com/api/v4`
- **Official documentation:** [List Product Families](https://developer.forcemanager.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
