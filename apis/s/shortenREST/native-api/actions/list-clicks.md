# List Clicks with Shorten.REST

Retrieves raw click data from Shorten.REST.

## Endpoint

- **Method:** `GET`
- **Path:** `/clicks`
- **Base URL:** `https://api.shorten.rest`
- **Official documentation:** [List Clicks](https://docs.shorten.rest/#GET--clicks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
