# Get Project with Sifter

Retrieves a specific project from Sifter.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://{subdomain}.sifterapp.com/api`
- **Official documentation:** [Get Project](https://sifterapp.com/developer/documentation/projects/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Sifter project ID. |
