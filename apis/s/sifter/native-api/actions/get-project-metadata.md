# Get Project Metadata with Sifter

Retrieves detailed project metadata from Sifter.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://{subdomain}.sifterapp.com/api`
- **Official documentation:** [Get Project Metadata](https://sifterapp.com/developer/documentation/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
