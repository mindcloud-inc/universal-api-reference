# List Groups with Splitwise

Retrieves the current user's groups from Splitwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_groups`
- **Base URL:** `https://secure.splitwise.com/api/v3.0`
- **Official documentation:** [List Groups](https://dev.splitwise.com/#tag/groups/paths/~1get_groups/get)
