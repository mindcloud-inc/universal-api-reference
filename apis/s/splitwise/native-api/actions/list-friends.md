# List Friends with Splitwise

Retrieves the current user's friends from Splitwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_friends`
- **Base URL:** `https://secure.splitwise.com/api/v3.0`
- **Official documentation:** [List Friends](https://dev.splitwise.com/#tag/friends/paths/~1get_friends/get)
