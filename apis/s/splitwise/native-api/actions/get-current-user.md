# Get Current User with Splitwise

Retrieves the current user's details from Splitwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_current_user`
- **Base URL:** `https://secure.splitwise.com/api/v3.0`
- **Official documentation:** [Get Current User](https://dev.splitwise.com/#tag/users/paths/~1get_current_user/get)
