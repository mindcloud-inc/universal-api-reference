# List Supported Currencies with Splitwise

Retrieves supported currencies from Splitwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_currencies`
- **Base URL:** `https://secure.splitwise.com/api/v3.0`
- **Official documentation:** [List Supported Currencies](https://dev.splitwise.com/#tag/other/paths/~1get_currencies/get)
