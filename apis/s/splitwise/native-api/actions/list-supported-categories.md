# List Supported Categories with Splitwise

Retrieves supported categories from Splitwise.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_categories`
- **Base URL:** `https://secure.splitwise.com/api/v3.0`
- **Official documentation:** [List Supported Categories](https://dev.splitwise.com/#tag/other/paths/~1get_categories/get)
