# Get File with Superchat

Retrieves a file from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{file_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get File](https://developers.superchat.com/reference/getfile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The unique identifier of the file |
