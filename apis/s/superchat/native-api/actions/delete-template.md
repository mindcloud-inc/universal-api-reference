# Delete Template with Superchat

Deletes an existing template from Superchat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/{template_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Delete Template](https://developers.superchat.com/reference/deletetemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The unique identifier of the template |
