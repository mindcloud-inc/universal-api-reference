# Get Contact with Superchat

Retrieves a contact from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Contact](https://developers.superchat.com/reference/getcontact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The unique identifier of the contact |
