# List Template Folders with Superchat

Retrieves all template folders from Superchat.

## Endpoint

- **Method:** `GET`
- **Path:** `/template-folders`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [List Template Folders](https://developers.superchat.com/reference/listtemplatefolders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
