# Get Label with Superchat

Retrieves a label from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/{label_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Label](https://developers.superchat.com/reference/getlabel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label_id` | path | `string` | yes | The ID of the label. |
