# List Labels with Superchat

Retrieves all conversation labels from Superchat.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [List Labels](https://developers.superchat.com/reference/listlabels)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `before` | query | `string` | no | Specify the cursor before which objects should be returned. |
