# Search Contacts with Superchat

Finds contacts in Superchat by any field.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/search`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Search Contacts](https://developers.superchat.com/reference/searchcontact)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `object` | no |
