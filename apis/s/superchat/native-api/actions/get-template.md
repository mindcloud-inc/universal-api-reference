# Get Template with Superchat

Retrieves a template from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{template_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Template](https://developers.superchat.com/reference/gettemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The unique identifier of the template |
