# Get Conversation with Superchat

Retrieves a conversation from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/{conversation_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Conversation](https://developers.superchat.com/reference/getconversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | The `id` of the conversation |
