# Delete Contact with Superchat

Deletes an existing contact from Superchat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Delete Contact](https://developers.superchat.com/reference/deletecontact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The unique identifier of the contact |
