# Get Channel with Superchat

Retrieves a channel from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/{channel_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Channel](https://developers.superchat.com/reference/getchannel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel_id` | path | `string` | yes |
