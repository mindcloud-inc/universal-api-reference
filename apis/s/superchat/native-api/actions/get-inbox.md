# Get Inbox with Superchat

Retrieves an inbox from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxes/{inbox_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Inbox](https://developers.superchat.com/reference/getinbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inbox_id` | path | `string` | yes | The id of the inbox. |
