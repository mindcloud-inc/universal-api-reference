# Get User with Superchat

Retrieves a user from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get User](https://developers.superchat.com/reference/getuser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The unique identifier of the user |
