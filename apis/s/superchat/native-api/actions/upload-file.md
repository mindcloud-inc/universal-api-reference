# Upload File with Superchat

Uploads a new file to Superchat.

## Endpoint

- **Method:** `POST`
- **Path:** `/files`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Upload File](https://developers.superchat.com/reference/createfile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | no | The file to upload |
