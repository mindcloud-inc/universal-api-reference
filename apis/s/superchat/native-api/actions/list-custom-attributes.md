# List Custom Attributes with Superchat

Retrieves custom contact attributes from Superchat.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-attributes`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [List Custom Attributes](https://developers.superchat.com/reference/listcontactattributes)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `before` | query | `string` | no | Specify the cursor before which objects should be returned. |
