# Get Contact List with Superchat

Retrieves a contact list from Superchat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-lists/{contact_list_id}`
- **Base URL:** `https://api.superchat.com/v1.0`
- **Official documentation:** [Get Contact List](https://developers.superchat.com/reference/getcontactlist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_list_id` | path | `string` | yes | The unique identifier of the contact |
