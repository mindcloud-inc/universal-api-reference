# List Upcoming Patient Appointments with Samedi

Retrieves upcoming patient appointments from Samedi.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking/v3/events/upcoming`
- **Base URL:** `https://patient.samedi.de/api`
- **Official documentation:** [List Upcoming Patient Appointments](https://api-docs.samedi.de/booking-api/patient-appointments/)
