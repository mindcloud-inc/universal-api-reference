# Upload Media Object with Sendblue

Uploads a media object to Sendblue.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/upload-media-object`
- **Base URL:** `https://api.sendblue.co`
- **Official documentation:** [Upload Media Object](https://docs.sendblue.com/api/resources/media_objects/methods/upload/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `media_url` | body | `string` | yes | Public URL of the media to upload. |
