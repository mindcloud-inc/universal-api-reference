# Get Message with Sendblue

Retrieves a message from Sendblue by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/messages/:message_id`
- **Base URL:** `https://api.sendblue.co`
- **Official documentation:** [Get Message](https://docs.sendblue.com/api/resources/messages/methods/retrieve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `message_id` | path | `string` | yes | Message handle or ID. |
