# Get Contact with Sendblue

Retrieves a contact from Sendblue by phone number.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/contacts/:phone_number`
- **Base URL:** `https://api.sendblue.co`
- **Official documentation:** [Get Contact](https://docs.sendblue.com/api/resources/contacts/methods/retrieve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_number` | path | `string` | yes | Phone number in E.164 format. |
