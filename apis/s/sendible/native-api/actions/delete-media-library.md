# Delete Media Library with Sendible

## Endpoint

- **Method:** `DELETE`
- **Path:** `0.1/tw/media_libraries`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Delete Media Library](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaLibraryId` | query | `string` | yes | The media library ID to delete. |
