# List Accounts with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/accounts.json`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [List Accounts](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_id` | query | `number` | no | Optional service filter for account results. |
