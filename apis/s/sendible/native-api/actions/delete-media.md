# Delete Media with Sendible

## Endpoint

- **Method:** `DELETE`
- **Path:** `0.2/tw/media`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Delete Media](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | query | `string` | yes | The media ID to delete. |
