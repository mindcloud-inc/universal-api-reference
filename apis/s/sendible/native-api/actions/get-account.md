# Get Account with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `api/v3/account`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Get Account](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | query | `number` | yes | Sendible account ID. |
