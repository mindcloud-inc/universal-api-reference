# Create Media Library with Sendible

## Endpoint

- **Method:** `POST`
- **Path:** `0.1/tw/media_libraries`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Create Media Library](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Media library name. |
