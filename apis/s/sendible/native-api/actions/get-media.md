# Get Media with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `0.2/tw/media`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Get Media](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | yes | Comma-separated media IDs to fetch. |
| `sessionId` | query | `string` | no | Optional session ID. |
