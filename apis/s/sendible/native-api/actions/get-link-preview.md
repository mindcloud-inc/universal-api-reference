# Get Link Preview with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `api/v0/linkpreview.json`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Get Link Preview](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The link to preview. |
