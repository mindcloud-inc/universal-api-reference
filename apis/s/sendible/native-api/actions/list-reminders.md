# List Reminders with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `1.0/tw/reminders`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [List Reminders](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | query | `number` | yes | Sendible account ID. |
