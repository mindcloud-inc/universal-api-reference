# Get Calendar Message with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.prd-tw.sendible.com/v1.0/messages/{{messageId}}`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [Get Calendar Message](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | yes | The Sendible message ID. |
