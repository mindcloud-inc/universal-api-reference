# List Holidays with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.prd-tw.sendible.com/v1.0/holidays`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [List Holidays](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `from` | query | `string` | yes | Start date in YYYY-MM-DD format. |
| `to` | query | `string` | yes | End date in YYYY-MM-DD format. |
