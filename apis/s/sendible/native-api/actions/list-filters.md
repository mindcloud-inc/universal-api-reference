# List Filters with Sendible

## Endpoint

- **Method:** `GET`
- **Path:** `0.1/tw/filters`
- **Base URL:** `https://api.sendible.com`
- **Official documentation:** [List Filters](https://support.sendible.com/hc/en-us)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filterTypes` | query | `string` | no | Optional comma-separated filter groups such as User. |
