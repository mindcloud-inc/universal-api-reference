# Search Standard Entities By Primary Key Prefix with Sprinklr

Finds standard entities in Sprinklr by primary key prefix.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/standard-entity/entity/byPrimaryKeyPrefix/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Search Standard Entities By Primary Key Prefix](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Fentity%2FbyPrimaryKeyPrefix%2F%7BentityType%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
