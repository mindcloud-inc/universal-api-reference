# Update Account Participant with Sprinklr

Updates an existing account participant in Sprinklr.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/account/update-account-participant`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Update Account Participant](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Faccount%2Fupdate-account-participant/post)
