# Get Standard Entity Definition with Sprinklr

Retrieves a standard entity definition from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/standard-entity/definition/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Standard Entity Definition](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Fdefinition%2F%7BentityType%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
