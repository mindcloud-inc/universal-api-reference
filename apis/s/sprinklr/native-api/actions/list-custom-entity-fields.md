# List Custom Entity Fields with Sprinklr

Retrieves custom entity fields from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/custom-entity/fields/{entityDefinitionId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Custom Entity Fields](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fcustom-entity%2Ffields%2F%7BentityDefinitionId%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityDefinitionId` | path | `string` | yes |
