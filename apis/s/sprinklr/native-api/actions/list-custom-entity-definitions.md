# List Custom Entity Definitions with Sprinklr

Retrieves custom entity definitions from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/custom-entity/definitions`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Custom Entity Definitions](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fcustom-entity%2Fdefinitions/get)
