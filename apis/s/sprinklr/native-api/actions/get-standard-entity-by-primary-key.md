# Get Standard Entity By Primary Key with Sprinklr

Retrieves a standard entity from Sprinklr by primary key.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/standard-entity/entity/byPrimaryKey/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Standard Entity By Primary Key](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Fentity%2FbyPrimaryKey%2F%7BentityType%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
