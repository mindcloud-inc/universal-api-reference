# Get Case with Sprinklr

Retrieves a case from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/case/{caseId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Case](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fcase%2F%7BcaseId%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `caseId` | path | `string` | yes |
