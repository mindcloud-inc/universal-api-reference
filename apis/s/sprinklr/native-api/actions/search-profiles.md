# Search Profiles with Sprinklr

Finds profiles in Sprinklr by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/profile/search`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Search Profiles](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fprofile%2Fsearch/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `snType` | query | `string` | no |
| `userName` | query | `string` | no |
