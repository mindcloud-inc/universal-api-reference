# List Standard Entity Fields with Sprinklr

Retrieves standard entity fields from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/standard-entity/fields/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Standard Entity Fields](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Ffields%2F%7BentityType%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
