# Delete Task with Sprinklr

Deletes an existing task from Sprinklr.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/v2/task/{taskId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Delete Task](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Ftask%2F%7BtaskId%7D/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `taskId` | path | `string` | yes |
