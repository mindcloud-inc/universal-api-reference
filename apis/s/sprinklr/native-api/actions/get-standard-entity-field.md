# Get Standard Entity Field with Sprinklr

Retrieves a standard entity field from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/standard-entity/field/{entityType}/{fieldName}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Standard Entity Field](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Ffield%2F%7BentityType%7D%2F%7BfieldName%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
| `fieldName` | path | `string` | yes |
