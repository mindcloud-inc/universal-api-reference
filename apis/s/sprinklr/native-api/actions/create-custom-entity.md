# Create Custom Entity with Sprinklr

Creates a custom entity in Sprinklr.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/custom-entity/entity`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Create Custom Entity](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fcustom-entity%2Fentity/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestBody` | body | `object` | yes |
