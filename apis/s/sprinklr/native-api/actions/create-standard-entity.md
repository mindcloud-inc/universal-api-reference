# Create Standard Entity with Sprinklr

Creates a standard entity in Sprinklr.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/standard-entity/entity/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Create Standard Entity](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Fentity%2F%7BentityType%7D/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
