# Get Task with Sprinklr

Retrieves a task from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/task/{taskId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Task](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Ftask%2F%7BtaskId%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `taskId` | path | `string` | yes |
