# Update Standard Entity with Sprinklr

Updates an existing standard entity in Sprinklr.

## Endpoint

- **Method:** `PUT`
- **Path:** `api/v2/standard-entity/entity/{entityType}/{entityId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Update Standard Entity](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fstandard-entity%2Fentity%2F%7BentityType%7D%2F%7BentityId%7D/put)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
| `entityType` | path | `string` | yes |
