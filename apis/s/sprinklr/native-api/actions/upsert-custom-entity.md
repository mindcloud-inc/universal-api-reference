# Upsert Custom Entity with Sprinklr

Updates or creates a custom entity in Sprinklr.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/custom-entity/entity/upsert`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Upsert Custom Entity](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fcustom-entity%2Fentity%2Fupsert/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestBody` | body | `object` | yes |
