# Get Message with Sprinklr

Retrieves a message from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/message`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Message](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fmessage/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
