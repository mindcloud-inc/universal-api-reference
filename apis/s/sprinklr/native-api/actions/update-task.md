# Update Task with Sprinklr

Updates an existing task in Sprinklr.

## Endpoint

- **Method:** `PUT`
- **Path:** `api/v2/task/{taskId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Update Task](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Ftask%2F%7BtaskId%7D/put)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestBody` | body | `object` | yes |
| `taskId` | path | `string` | yes |
