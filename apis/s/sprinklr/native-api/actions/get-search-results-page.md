# Get Search Results Page with Sprinklr

Retrieves a search results page from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/search/{entityType}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Search Results Page](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fsearch%2F%7BentityType%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityType` | path | `string` | yes |
| `id` | query | `string` | no |
