# Perform Message Action with Sprinklr

Updates a message in Sprinklr by performing an action.

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/message/action`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Perform Message Action](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Fmessage%2Faction/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestBody` | body | `object` | yes |
