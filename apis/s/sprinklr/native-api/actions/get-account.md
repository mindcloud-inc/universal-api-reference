# Get Account with Sprinklr

Retrieves an account from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/account/{accountId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Account](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Faccount%2F%7BaccountId%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
