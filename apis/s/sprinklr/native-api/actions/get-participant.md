# Get Participant with Sprinklr

Retrieves a participant from Sprinklr.

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/account/get-participant/{participantId}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Participant](https://dev.sprinklr.com/docs/prod4/1/routes/api%2Fv2%2Faccount%2Fget-participant%2F%7BparticipantId%7D/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | query | `string` | yes |
| `participantId` | path | `string` | yes |
