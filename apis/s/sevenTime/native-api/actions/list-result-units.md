# List Result Units with Seven Time

Retrieves result units from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/resultUnits`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Result Units](https://docs.seventime.se/#get-result-units)

## Capabilities

This operation supports [sorting](../README.md#sorting).
