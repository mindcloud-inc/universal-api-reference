# List User Roles with Seven Time

Retrieves user roles from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/userRoles`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List User Roles](https://docs.seventime.se/#get-user-roles)

## Capabilities

This operation supports [sorting](../README.md#sorting).
