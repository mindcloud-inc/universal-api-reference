# List Project Tags with Seven Time

Retrieves project tags from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/projectTags`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Project Tags](https://docs.seventime.se/#get-project-tags)

## Capabilities

This operation supports [sorting](../README.md#sorting).
