# List Work Order Tags with Seven Time

Retrieves work order tags from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/workOrderTags`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Work Order Tags](https://docs.seventime.se/#get-work-order-tags)

## Capabilities

This operation supports [sorting](../README.md#sorting).
