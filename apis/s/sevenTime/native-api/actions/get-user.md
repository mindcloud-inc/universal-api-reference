# Get User with Seven Time

Retrieves a user from a Seven Time workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:_id`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [Get User](https://docs.seventime.se/#get-a-specific-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `_id` | path | `string` | yes | The _id of the user to retrieve. |
