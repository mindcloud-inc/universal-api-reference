# List Time Categories with Seven Time

Retrieves time categories from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeCategories`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Time Categories](https://docs.seventime.se/#get-time-categories)

## Capabilities

This operation supports [sorting](../README.md#sorting).
