# List Departments with Seven Time

Retrieves departments from a Seven Time workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/departments`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Departments](https://docs.seventime.se/#get-departments)

## Capabilities

This operation supports [sorting](../README.md#sorting).
