# List Quote Categories with Seven Time

Retrieves quote categories from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/quoteCategories`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Quote Categories](https://docs.seventime.se/#get-quote-categories)

## Capabilities

This operation supports [sorting](../README.md#sorting).
