# List User Salary Types with Seven Time

Retrieves user salary types from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/defaultSalaryTypes`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List User Salary Types](https://docs.seventime.se/#get-user-salary-types)

## Capabilities

This operation supports [sorting](../README.md#sorting).
