# List Machine Types with Seven Time

Retrieves machine types from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/machineTypes`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Machine Types](https://docs.seventime.se/#get-machine-types)

## Capabilities

This operation supports [sorting](../README.md#sorting).
