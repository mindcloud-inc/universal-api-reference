# List User Skills with Seven Time

Retrieves user skills from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/userSkills`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List User Skills](https://docs.seventime.se/#get-user-skills)

## Capabilities

This operation supports [sorting](../README.md#sorting).
