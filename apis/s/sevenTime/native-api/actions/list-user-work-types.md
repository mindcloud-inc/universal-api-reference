# List User Work Types with Seven Time

Retrieves user work types from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/userWorkTypes`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List User Work Types](https://docs.seventime.se/#get-user-work-types)

## Capabilities

This operation supports [sorting](../README.md#sorting).
