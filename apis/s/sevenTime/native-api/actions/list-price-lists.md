# List Price Lists with Seven Time

Retrieves price lists from Seven Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/priceLists`
- **Base URL:** `https://app.seventime.se/api/2`
- **Official documentation:** [List Price Lists](https://docs.seventime.se/#get-price-lists)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
