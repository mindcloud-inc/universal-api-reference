# Get Survey Owner Information with SmartSurvey

Retrieves survey owner information and metadata from SmartSurvey.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/{surveyId}/ownerinfo`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [Get Survey Owner Information](https://docs.smartsurvey.io/reference/get_surveys-surveyid-ownerinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The survey id of the survey to fetch |
