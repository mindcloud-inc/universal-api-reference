# List Surveys with SmartSurvey

Retrieves all surveys in your SmartSurvey account.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [List Surveys](https://docs.smartsurvey.io/reference/get_surveys)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
