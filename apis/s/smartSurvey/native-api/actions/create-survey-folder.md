# Create Survey Folder with SmartSurvey

Creates a new survey folder in SmartSurvey.

## Endpoint

- **Method:** `POST`
- **Path:** `/surveyfolders`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [Create Survey Folder](https://docs.smartsurvey.io/reference/post_surveyfolders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | The title for the folder |
