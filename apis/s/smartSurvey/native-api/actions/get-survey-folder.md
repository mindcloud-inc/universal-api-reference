# Get Survey Folder with SmartSurvey

Retrieves a survey folder from SmartSurvey.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveyfolders/{id}`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [Get Survey Folder](https://docs.smartsurvey.io/reference/get_surveyfolders-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the folder to get details for |
