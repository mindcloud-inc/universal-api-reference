# Get Survey Folder Details with SmartSurvey

Retrieves a survey folder with its surveys from SmartSurvey.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveyfolders/{id}/detailed`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [Get Survey Folder Details](https://docs.smartsurvey.io/reference/get_surveyfolders-id-detailed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the folder to get details for |
