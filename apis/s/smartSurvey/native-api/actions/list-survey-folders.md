# List Survey Folders with SmartSurvey

Retrieves all survey folders from SmartSurvey.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveyfolders`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [List Survey Folders](https://docs.smartsurvey.io/reference/get_surveyfolders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
