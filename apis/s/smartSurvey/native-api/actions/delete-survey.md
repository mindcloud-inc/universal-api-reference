# Delete Survey with SmartSurvey

Deletes an existing survey from SmartSurvey.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/surveys/{surveyId}`
- **Base URL:** `https://api.smartsurvey.io/v2`
- **Official documentation:** [Delete Survey](https://docs.smartsurvey.io/reference/delete_surveys-surveyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The survey id that you want to delete |
