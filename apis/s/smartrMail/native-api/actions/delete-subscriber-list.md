# Delete Subscriber List with SmartrMail

Deletes an existing subscriber list from SmartrMail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:list_id`
- **Base URL:** `https://go.smartrmail.com/api/v1`
- **Official documentation:** [Delete Subscriber List](https://docs.smartrmail.com/en/articles/636612-manage-subscriber-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | The ID of the requested list. |
