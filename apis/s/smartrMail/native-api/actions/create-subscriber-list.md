# Create Subscriber List with SmartrMail

Creates a new subscriber list in SmartrMail.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists`
- **Base URL:** `https://go.smartrmail.com/api/v1`
- **Official documentation:** [Create Subscriber List](https://docs.smartrmail.com/en/articles/636612-manage-subscriber-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the subscriber list. |
