# List Subscriber Lists with SmartrMail

Retrieves subscriber lists from your SmartrMail account.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://go.smartrmail.com/api/v1`
- **Official documentation:** [List Subscriber Lists](https://docs.smartrmail.com/en/articles/636612-manage-subscriber-lists)
