# Deactivate Quality Profile Rules with SonarQube

Updates multiple quality profile rules in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/deactivate_rules`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Deactivate Quality Profile Rules](https://sonarcloud.io/web_api/api/qualityprofiles/deactivate_rules)
