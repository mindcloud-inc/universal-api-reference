# Get AI Code Assurance Badge with SonarQube

Retrieves an AI code assurance badge from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/project_badges/ai_code_assurance`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get AI Code Assurance Badge](https://sonarcloud.io/web_api/api/project_badges/ai_code_assurance)
