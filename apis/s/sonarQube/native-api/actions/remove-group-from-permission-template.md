# Remove Group From Permission Template with SonarQube

Removes a group from a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/remove_group_from_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Remove Group From Permission Template](https://sonarcloud.io/web_api/api/permissions/remove_group_from_template)
