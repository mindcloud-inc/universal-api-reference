# Delete Quality Profile with SonarQube

Deletes a quality profile from SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/delete`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Delete Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/delete)
