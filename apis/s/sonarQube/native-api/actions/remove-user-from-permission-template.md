# Remove User From Permission Template with SonarQube

Removes a user from a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/remove_user_from_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Remove User From Permission Template](https://sonarcloud.io/web_api/api/permissions/remove_user_from_template)
