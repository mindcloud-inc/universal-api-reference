# Add Group To Permission Template with SonarQube

Adds a group to a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/add_group_to_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Add Group To Permission Template](https://sonarcloud.io/web_api/api/permissions/add_group_to_template)
