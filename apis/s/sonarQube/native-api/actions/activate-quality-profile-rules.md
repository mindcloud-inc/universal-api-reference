# Activate Quality Profile Rules with SonarQube

Updates multiple quality profile rules in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/activate_rules`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Activate Quality Profile Rules](https://sonarcloud.io/web_api/api/qualityprofiles/activate_rules)
