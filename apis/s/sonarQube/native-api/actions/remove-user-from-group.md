# Remove User From Group with SonarQube

Removes a user from a SonarQube user group.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/user_groups/remove_user`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Remove User From Group](https://sonarcloud.io/web_api/api/user_groups/remove_user)
