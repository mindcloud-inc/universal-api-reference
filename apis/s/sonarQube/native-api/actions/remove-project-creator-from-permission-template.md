# Remove Project Creator From Permission Template with SonarQube

Removes a project creator from a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/remove_project_creator_from_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Remove Project Creator From Permission Template](https://sonarcloud.io/web_api/api/permissions/remove_project_creator_from_template)
