# Update Project Analysis Event with SonarQube

Updates a project analysis event in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project_analyses/update_event`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Update Project Analysis Event](https://sonarcloud.io/web_api/api/project_analyses/update_event)
