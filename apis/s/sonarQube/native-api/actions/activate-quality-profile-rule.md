# Activate Quality Profile Rule with SonarQube

Updates a quality profile rule in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/activate_rule`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Activate Quality Profile Rule](https://sonarcloud.io/web_api/api/qualityprofiles/activate_rule)
