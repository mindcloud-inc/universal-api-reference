# Delete Project Analysis Event with SonarQube

Deletes a project analysis event from SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project_analyses/delete_event`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Delete Project Analysis Event](https://sonarcloud.io/web_api/api/project_analyses/delete_event)
