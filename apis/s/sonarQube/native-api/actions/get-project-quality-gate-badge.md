# Get Project Quality Gate Badge with SonarQube

Retrieves a project quality gate badge from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/project_badges/quality_gate`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Project Quality Gate Badge](https://sonarcloud.io/web_api/api/project_badges/quality_gate)
