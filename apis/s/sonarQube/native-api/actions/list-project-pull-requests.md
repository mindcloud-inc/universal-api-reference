# List Project Pull Requests with SonarQube

Retrieves project pull requests from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/project_pull_requests/list`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [List Project Pull Requests](https://sonarcloud.io/web_api/api/project_pull_requests/list)
