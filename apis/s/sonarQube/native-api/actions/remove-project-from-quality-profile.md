# Remove Project From Quality Profile with SonarQube

Removes a project from a SonarQube quality profile.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/remove_project`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Remove Project From Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/remove_project)
