# Set Default Quality Profile with SonarQube

Updates the default quality profile in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/set_default`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Set Default Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/set_default)
