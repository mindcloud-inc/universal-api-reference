# Rename Quality Profile with SonarQube

Updates a quality profile name in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/rename`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Rename Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/rename)
