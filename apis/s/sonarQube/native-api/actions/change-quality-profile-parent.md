# Change Quality Profile Parent with SonarQube

Updates a quality profile parent in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/change_parent`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Change Quality Profile Parent](https://sonarcloud.io/web_api/api/qualityprofiles/change_parent)
