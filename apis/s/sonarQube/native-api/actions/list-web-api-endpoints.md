# List Web API Endpoints with SonarQube

Retrieves Web API endpoints from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webservices/list`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [List Web API Endpoints](https://sonarcloud.io/web_api/api/webservices/list)
