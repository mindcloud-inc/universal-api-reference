# Get Web API Response Example with SonarQube

Retrieves a Web API response example from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webservices/response_example`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Web API Response Example](https://sonarcloud.io/web_api/api/webservices/response_example)
