# Set Default Permission Template with SonarQube

Updates the default permission template in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/set_default_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Set Default Permission Template](https://sonarcloud.io/web_api/api/permissions/set_default_template)
