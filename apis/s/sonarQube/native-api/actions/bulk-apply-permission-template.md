# Bulk Apply Permission Template with SonarQube

Updates multiple SonarQube projects with a permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/bulk_apply_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Bulk Apply Permission Template](https://sonarcloud.io/web_api/api/permissions/bulk_apply_template)
