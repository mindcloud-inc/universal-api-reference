# Change Security Hotspot Status with SonarQube

Updates a security hotspot status in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/hotspots/change_status`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Change Security Hotspot Status](https://sonarcloud.io/web_api/api/hotspots/change_status)
