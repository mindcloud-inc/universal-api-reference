# Add Project Creator To Permission Template with SonarQube

Adds a project creator to a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/add_project_creator_to_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Add Project Creator To Permission Template](https://sonarcloud.io/web_api/api/permissions/add_project_creator_to_template)
