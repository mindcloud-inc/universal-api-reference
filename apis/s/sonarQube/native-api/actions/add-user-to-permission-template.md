# Add User To Permission Template with SonarQube

Adds a user to a SonarQube permission template.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/permissions/add_user_to_template`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Add User To Permission Template](https://sonarcloud.io/web_api/api/permissions/add_user_to_template)
