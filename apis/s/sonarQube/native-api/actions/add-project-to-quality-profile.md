# Add Project To Quality Profile with SonarQube

Adds a project to a SonarQube quality profile.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/add_project`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Add Project To Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/add_project)
