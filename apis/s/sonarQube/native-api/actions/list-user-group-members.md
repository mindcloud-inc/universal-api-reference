# List User Group Members with SonarQube

Retrieves members of a SonarQube user group.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/user_groups/users`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [List User Group Members](https://sonarcloud.io/web_api/api/user_groups/users)
