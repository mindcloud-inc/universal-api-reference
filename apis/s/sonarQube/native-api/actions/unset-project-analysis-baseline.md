# Unset Project Analysis Baseline with SonarQube

Updates a project analysis baseline in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project_analyses/unset_baseline`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Unset Project Analysis Baseline](https://sonarcloud.io/web_api/api/project_analyses/unset_baseline)
