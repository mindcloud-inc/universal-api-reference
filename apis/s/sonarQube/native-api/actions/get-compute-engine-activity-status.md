# Get Compute Engine Activity Status with SonarQube

Retrieves compute engine activity status from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ce/activity_status`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Compute Engine Activity Status](https://sonarcloud.io/web_api/api/ce/activity_status)
