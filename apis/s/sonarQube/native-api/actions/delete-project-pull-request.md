# Delete Project Pull Request with SonarQube

Deletes a project pull request from SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project_pull_requests/delete`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Delete Project Pull Request](https://sonarcloud.io/web_api/api/project_pull_requests/delete)
