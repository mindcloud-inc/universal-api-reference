# Deactivate Quality Profile Rule with SonarQube

Updates a quality profile rule in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/qualityprofiles/deactivate_rule`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Deactivate Quality Profile Rule](https://sonarcloud.io/web_api/api/qualityprofiles/deactivate_rule)
