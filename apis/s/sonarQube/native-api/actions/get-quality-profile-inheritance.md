# Get Quality Profile Inheritance with SonarQube

Retrieves quality profile inheritance from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/qualityprofiles/inheritance`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Quality Profile Inheritance](https://sonarcloud.io/web_api/api/qualityprofiles/inheritance)
