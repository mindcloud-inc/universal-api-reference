# Get Quality Profile Changelog with SonarQube

Retrieves a quality profile changelog from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/qualityprofiles/changelog`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Quality Profile Changelog](https://sonarcloud.io/web_api/api/qualityprofiles/changelog)
