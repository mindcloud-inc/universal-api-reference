# Backup Quality Profile with SonarQube

Retrieves a quality profile backup from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/qualityprofiles/backup`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Backup Quality Profile](https://sonarcloud.io/web_api/api/qualityprofiles/backup)
