# List Webhook Deliveries with SonarQube

Retrieves webhook deliveries from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhooks/deliveries`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [List Webhook Deliveries](https://sonarcloud.io/web_api/api/webhooks/deliveries)
