# Create Project Analysis Event with SonarQube

Creates a project analysis event in SonarQube.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/project_analyses/create_event`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Create Project Analysis Event](https://sonarcloud.io/web_api/api/project_analyses/create_event)
