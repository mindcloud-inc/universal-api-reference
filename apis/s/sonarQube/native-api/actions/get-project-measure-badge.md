# Get Project Measure Badge with SonarQube

Retrieves a project measure badge from SonarQube.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/project_badges/measure`
- **Base URL:** `https://sonarcloud.io`
- **Official documentation:** [Get Project Measure Badge](https://sonarcloud.io/web_api/api/project_badges/measure)
