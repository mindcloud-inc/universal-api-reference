# Delete SMS with SMSVio

## Endpoint

- **Method:** `POST`
- **Path:** `/services/send/`
- **Base URL:** `https://gate.smsvio.cz`
- **Official documentation:** [Delete SMS](https://www.smsvio.cz/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
