# Rename Directory with SendSafely

## Endpoint

- **Method:** `POST`
- **Path:** `/package/:packageId/directory/:directoryId`
- **Base URL:** `https://app.sendsafely.com/api/v2.0`
- **Official documentation:** [Rename Directory](https://rest-api-docs.sendsafely.com/#ae3cb3dc-955e-45c6-a947-9aebc3c09135)
