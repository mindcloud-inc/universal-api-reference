# Move Directory with SendSafely

## Endpoint

- **Method:** `POST`
- **Path:** `/package/:packageId/move/:sourcedirectoryId/:targetdirectoryId/`
- **Base URL:** `https://app.sendsafely.com/api/v2.0`
- **Official documentation:** [Move Directory](https://rest-api-docs.sendsafely.com/#e3a8573c-379c-4ce1-a958-b34d4c04f96e)
