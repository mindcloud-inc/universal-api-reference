# Delete Product with Swell

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Delete Product](https://developers.swell.is/backend-api/products/delete-a-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell product ID. |
