# List Carts with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/carts`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Carts](https://developers.swell.is/backend-api/carts/list-all-carts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
