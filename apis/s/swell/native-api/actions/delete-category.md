# Delete Category with Swell

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Delete Category](https://developers.swell.is/backend-api/categories/delete-a-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell category ID. |
