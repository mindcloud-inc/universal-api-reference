# List Orders with Swell

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Orders](https://developers.swell.is/backend-api/orders/list-all-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
