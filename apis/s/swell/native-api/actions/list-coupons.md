# List Coupons with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Coupons](https://developers.swell.is/backend-api/coupons/list-all-coupons)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
