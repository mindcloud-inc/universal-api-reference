# List Accounts with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Accounts](https://developers.swell.is/backend-api/accounts/list-all-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
