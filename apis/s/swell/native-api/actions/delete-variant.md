# Delete Variant with Swell

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products\:variants/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Delete Variant](https://developers.swell.is/backend-api/variants/delete-a-variant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell variant ID. |
