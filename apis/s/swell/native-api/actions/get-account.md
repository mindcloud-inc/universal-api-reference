# Get Account with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Get Account](https://developers.swell.is/backend-api/accounts/retrieve-an-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell account ID. |
