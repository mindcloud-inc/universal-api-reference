# List Products with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Products](https://developers.swell.is/backend-api/products/list-all-products)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
