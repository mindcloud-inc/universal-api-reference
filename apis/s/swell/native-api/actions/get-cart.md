# Get Cart with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/carts/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Get Cart](https://developers.swell.is/backend-api/carts/retrieve-a-cart)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell cart ID. |
