# Get Product with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Get Product](https://developers.swell.is/backend-api/products/retrieve-a-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell product ID. |
