# Create Category with Swell

## Endpoint

- **Method:** `POST`
- **Path:** `/categories`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Create Category](https://developers.swell.is/backend-api/categories/create-a-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The category name. |
| `active` | body | `boolean` | no | Whether the category is active. |
