# Delete Order with Swell

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Delete Order](https://developers.swell.is/backend-api/orders/delete-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell order ID. |
