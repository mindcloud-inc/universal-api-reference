# Get Promotion with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/promotions/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Get Promotion](https://developers.swell.is/backend-api/promotions/retrieve-a-promotion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell promotion ID. |
