# Get Coupon with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/:id`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [Get Coupon](https://developers.swell.is/backend-api/coupons/retrieve-a-coupon)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Swell coupon ID. |
