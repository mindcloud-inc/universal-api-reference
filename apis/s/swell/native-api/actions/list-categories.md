# List Categories with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Categories](https://developers.swell.is/backend-api/categories/list-all-categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
