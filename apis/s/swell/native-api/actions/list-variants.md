# List Variants with Swell

## Endpoint

- **Method:** `GET`
- **Path:** `/products\:variants`
- **Base URL:** `https://api.swell.store`
- **Official documentation:** [List Variants](https://developers.swell.is/backend-api/variants/list-all-variants)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
