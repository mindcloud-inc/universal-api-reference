# List Users with SignalZen

Retrieves users from SignalZen.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.signalzen.com/external`
- **Official documentation:** [List Users](https://docs.signalzen.com/docs/api/users/#get-all-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
