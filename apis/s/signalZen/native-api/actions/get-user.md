# Get User with SignalZen

Retrieves a user from SignalZen.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}`
- **Base URL:** `https://api.signalzen.com/external`
- **Official documentation:** [Get User](https://docs.signalzen.com/docs/api/users/#get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | The ID of the user to retrieve. |
