# Completed PDF with SignWell

Retrieves a completed document PDF from SignWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/completed_pdf`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Completed PDF](https://developers.signwell.com/reference/get_api-v1-documents-id-completed-pdf-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
