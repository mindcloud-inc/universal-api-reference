# Update and Send Document with SignWell

Updates and sends a draft document in SignWell.

## Endpoint

- **Method:** `POST`
- **Path:** `/documents/:id/send`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Update and Send Document](https://developers.signwell.com/reference/post_api-v1-documents-id-send)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
