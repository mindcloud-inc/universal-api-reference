# Delete Template with SignWell

Deletes an existing template from SignWell.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/document_templates/:id`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Delete Template](https://developers.signwell.com/reference/delete_api-v1-document-templates-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
