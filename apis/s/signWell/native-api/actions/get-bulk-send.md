# Get Bulk Send with SignWell

Retrieves details for a bulk send in SignWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk_sends/:id`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Get Bulk Send](https://developers.signwell.com/reference/get_api-v1-bulk-sends-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for a bulk send. |
