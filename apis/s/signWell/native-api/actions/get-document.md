# Get Document with SignWell

Retrieves document details and recipients from SignWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Get Document](https://developers.signwell.com/reference/get_api-v1-documents-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
