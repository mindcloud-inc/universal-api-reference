# Delete Document with SignWell

Deletes an existing document from SignWell.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:id`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Delete Document](https://developers.signwell.com/reference/delete_api-v1-documents-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
