# Get Template with SignWell

Retrieves template details and fields from SignWell.

## Endpoint

- **Method:** `GET`
- **Path:** `/document_templates/:id`
- **Base URL:** `https://www.signwell.com/api/v1`
- **Official documentation:** [Get Template](https://developers.signwell.com/reference/get_api-v1-document-templates-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
