# Delete Webhook with SMSGatewayCenter SMS

## Endpoint

- **Method:** `POST`
- **Path:** `/SMSApi/webhook/delete`
- **Base URL:** `https://unify.smsgateway.center`
- **Official documentation:** [Delete Webhook](https://www.smsgatewaycenter.com/developer-api/delete-webhook/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |
