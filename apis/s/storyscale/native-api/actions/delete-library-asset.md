# Delete Library Asset with Storyscale

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/library/delete/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Delete Library Asset](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale library asset ID. |
