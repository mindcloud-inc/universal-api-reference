# Get Experience with Storyscale

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/experience/view/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Get Experience](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale experience ID. |
