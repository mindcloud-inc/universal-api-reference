# Search Experiences, Sequences, and Assets with Storyscale

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/search`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Search Experiences, Sequences, and Assets](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search term used to find experiences, sequences, and assets. |
