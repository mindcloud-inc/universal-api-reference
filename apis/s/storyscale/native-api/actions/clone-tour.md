# Clone Tour with Storyscale

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/tour/clone/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Clone Tour](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale tour ID. |
