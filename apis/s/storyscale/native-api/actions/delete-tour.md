# Delete Tour with Storyscale

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/tour/delete/{tour_id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Delete Tour](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tour_id` | path | `string` | yes | The Storyscale tour ID. |
