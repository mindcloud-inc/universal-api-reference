# Delete Style Guide with Storyscale

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/style-guide/delete/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Delete Style Guide](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale style guide ID. |
