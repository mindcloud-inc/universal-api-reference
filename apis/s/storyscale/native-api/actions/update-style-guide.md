# Update Style Guide with Storyscale

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/style-guide/update/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [Update Style Guide](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale style guide ID. |
