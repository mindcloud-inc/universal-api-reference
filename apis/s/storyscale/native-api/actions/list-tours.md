# List Tours with Storyscale

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tour/show-all`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [List Tours](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order` | query | `string` | no | Sort direction for the tour list. |
| `sort` | query | `string` | no | Sort field for the tour list. |
