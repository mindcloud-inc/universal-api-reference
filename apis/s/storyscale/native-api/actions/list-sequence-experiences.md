# List Sequence Experiences with Storyscale

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sequence/experiences/{id}`
- **Base URL:** `https://prodapi.storyscale.com/api`
- **Official documentation:** [List Sequence Experiences](https://prodapi.storyscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Storyscale sequence ID. |
