# Delete a Document with SignalWire

Deletes an existing document from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datasphere/documents/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete a Document](https://signalwire.com/docs/apis/rest/documents/delete-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Document. |
