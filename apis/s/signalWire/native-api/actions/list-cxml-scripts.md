# List cXML Scripts with SignalWire

Retrieves cXML scripts from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_scripts`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List cXML Scripts](https://signalwire.com/docs/apis/rest/cxml-scripts/list-cxml-scripts)
