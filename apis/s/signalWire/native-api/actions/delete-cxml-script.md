# Delete cXML Script with SignalWire

Deletes an existing cXML script from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/cxml_scripts/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete cXML Script](https://signalwire.com/docs/apis/rest/cxml-scripts/delete-cxml-script)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a cXML Script. |
