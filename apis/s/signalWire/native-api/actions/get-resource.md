# Get Resource with SignalWire

Retrieves a resource from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Resource](https://signalwire.com/docs/apis/rest/resources/get-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Resource. |
