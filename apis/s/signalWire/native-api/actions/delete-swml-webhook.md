# Delete SWML Webhook with SignalWire

Deletes an existing SWML webhook from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/swml_webhooks/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete SWML Webhook](https://signalwire.com/docs/apis/rest/swml-webhook/delete-swml-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SWML Webhook. |
