# Get SIP Endpoint with SignalWire

Retrieves a SIP endpoint from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/sip_endpoints/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get SIP Endpoint](https://signalwire.com/docs/apis/rest/sip-credentials/get-sip-credential)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SIP Endpoint. |
