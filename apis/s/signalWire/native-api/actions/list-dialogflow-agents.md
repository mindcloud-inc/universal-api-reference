# List Dialogflow Agents with SignalWire

Retrieves Dialogflow agents from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/dialogflow_agents`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Dialogflow Agents](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-dialogflow/list-dialogflow-agents)
