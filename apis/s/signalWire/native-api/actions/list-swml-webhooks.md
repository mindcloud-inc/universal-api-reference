# List SWML Webhooks with SignalWire

Retrieves SWML webhooks from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/swml_webhooks`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List SWML Webhooks](https://signalwire.com/docs/apis/rest/swml-webhook/list-swml-webhooks)
