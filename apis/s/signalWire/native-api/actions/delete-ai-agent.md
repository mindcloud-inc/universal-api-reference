# Delete AI Agent with SignalWire

Deletes an existing AI agent from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/ai_agents/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete AI Agent](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-custom/delete-ai-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of an AI Agent. |
