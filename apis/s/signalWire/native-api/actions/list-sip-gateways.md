# List SIP Gateways with SignalWire

Retrieves SIP gateways from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/sip_gateways`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List SIP Gateways](https://signalwire.com/docs/apis/rest/sip-gateway/list-sip-gateways)
