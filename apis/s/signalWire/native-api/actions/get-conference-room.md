# Get Conference Room with SignalWire

Retrieves a conference room from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/conference_rooms/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Conference Room](https://signalwire.com/docs/apis/rest/conference-rooms/get-conference-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Conference Room. |
