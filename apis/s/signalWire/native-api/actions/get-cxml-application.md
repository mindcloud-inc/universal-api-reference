# Get cXML Application with SignalWire

Retrieves a cXML application from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_applications/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get cXML Application](https://signalwire.com/docs/apis/rest/cxml-applications/get-cxml-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a cXML Application. |
