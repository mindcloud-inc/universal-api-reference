# List SIP Endpoints with SignalWire

Retrieves SIP endpoints from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/sip_endpoints`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List SIP Endpoints](https://signalwire.com/docs/apis/rest/sip-credentials/list-sip-credentials)
