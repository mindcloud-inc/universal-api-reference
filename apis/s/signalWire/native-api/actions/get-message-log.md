# Get Message Log with SignalWire

Retrieves a message log from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/messaging/logs/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Message Log](https://signalwire.com/docs/apis/rest/message-logs/get-message-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of the log. |
