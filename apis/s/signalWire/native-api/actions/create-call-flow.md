# Create Call Flow with SignalWire

Creates a new call flow in SignalWire.

## Endpoint

- **Method:** `POST`
- **Path:** `/fabric/resources/call_flows`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Create Call Flow](https://signalwire.com/docs/apis/rest/call-flows/create-call-flow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | The name of the Call Flow |
