# Get Dialogflow Agent with SignalWire

Retrieves a Dialogflow agent from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/dialogflow_agents/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Dialogflow Agent](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-dialogflow/get-dialogflow-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Dialogflow Agent. |
