# List FreeSWITCH Connectors with SignalWire

Retrieves FreeSWITCH connectors from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/freeswitch_connectors`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List FreeSWITCH Connectors](https://signalwire.com/docs/apis/rest/freeswitch-connector/list-freeswitch-connectors)
