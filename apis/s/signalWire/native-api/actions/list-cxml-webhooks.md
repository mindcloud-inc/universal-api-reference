# List cXML Webhooks with SignalWire

Retrieves cXML webhooks from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_webhooks`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List cXML Webhooks](https://signalwire.com/docs/apis/rest/cxml-webhook/list-cxml-webhooks)
