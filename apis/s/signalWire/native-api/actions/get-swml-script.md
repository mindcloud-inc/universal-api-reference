# Get SWML Script with SignalWire

Retrieves a SWML script from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/swml_scripts/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get SWML Script](https://signalwire.com/docs/apis/rest/swml-scripts/get-swml-script)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SWML Script. |
