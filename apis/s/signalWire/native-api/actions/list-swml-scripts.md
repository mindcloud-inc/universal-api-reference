# List SWML Scripts with SignalWire

Retrieves SWML scripts from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/swml_scripts`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List SWML Scripts](https://signalwire.com/docs/apis/rest/swml-scripts/list-swml-scripts)
