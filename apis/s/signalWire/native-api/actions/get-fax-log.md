# Get Fax Log with SignalWire

Retrieves a fax log from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fax/logs/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Fax Log](https://signalwire.com/docs/apis/rest/fax-logs/get-fax-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of the log |
