# List cXML Application Addresses with SignalWire

Retrieves cXML application addresses from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_applications/{id}/addresses`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List cXML Application Addresses](https://signalwire.com/docs/apis/rest/cxml-applications/list-cxml-application-addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the cXML Application. |
