# Delete Call Flow with SignalWire

Deletes an existing call flow from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/call_flows/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete Call Flow](https://signalwire.com/docs/apis/rest/call-flows/delete-call-flow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Call Flow. |
