# List AI Agents with SignalWire

Retrieves AI agents from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/ai_agents`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List AI Agents](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-custom/list-ai-agents)
