# Get FreeSWITCH Connector with SignalWire

Retrieves a FreeSWITCH connector from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/freeswitch_connectors/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get FreeSWITCH Connector](https://signalwire.com/docs/apis/rest/freeswitch-connector/get-freeswitch-connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a FreeSWITCH Connector. |
