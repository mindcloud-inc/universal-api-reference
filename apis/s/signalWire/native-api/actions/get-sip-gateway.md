# Get SIP Gateway with SignalWire

Retrieves a SIP gateway from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/sip_gateways/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get SIP Gateway](https://signalwire.com/docs/apis/rest/sip-gateway/get-sip-gateway)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SIP Gateway. |
