# List Chunks with SignalWire

Retrieves chunks from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasphere/documents/{documentId}/chunks`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Chunks](https://signalwire.com/docs/apis/rest/chunks/list-document-chunks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Unique ID of the Document. |
