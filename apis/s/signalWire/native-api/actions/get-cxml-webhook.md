# Get cXML Webhook with SignalWire

Retrieves a cXML webhook from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_webhooks/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get cXML Webhook](https://signalwire.com/docs/apis/rest/cxml-webhook/get-cxml-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a CXML Webhook. |
