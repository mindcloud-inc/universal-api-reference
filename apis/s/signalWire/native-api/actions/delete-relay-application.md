# Delete Relay Application with SignalWire

Deletes an existing relay application from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/relay_applications/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete Relay Application](https://signalwire.com/docs/apis/rest/relay-application/delete-relay-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Relay Application. |
