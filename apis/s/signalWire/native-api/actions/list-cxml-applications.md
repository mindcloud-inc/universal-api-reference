# List cXML Applications with SignalWire

Retrieves cXML applications from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/cxml_applications`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List cXML Applications](https://signalwire.com/docs/apis/rest/cxml-applications/list-cxml-applications)
