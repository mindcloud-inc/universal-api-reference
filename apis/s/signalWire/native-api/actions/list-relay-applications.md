# List Relay Applications with SignalWire

Retrieves relay applications from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/relay_applications`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Relay Applications](https://signalwire.com/docs/apis/rest/relay-application/list-relay-applications)
