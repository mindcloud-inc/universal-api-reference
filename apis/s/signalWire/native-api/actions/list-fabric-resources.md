# List Fabric Resources with SignalWire

Retrieves Fabric resources from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Fabric Resources](https://signalwire.com/docs/apis/rest/resources/list-resources)
