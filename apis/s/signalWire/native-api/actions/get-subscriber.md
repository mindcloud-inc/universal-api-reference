# Get Subscriber with SignalWire

Retrieves a subscriber from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/subscribers/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get Subscriber](https://signalwire.com/docs/apis/rest/subscribers/get-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Subscriber. |
