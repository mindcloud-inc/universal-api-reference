# List Subscriber Addresses with SignalWire

Retrieves subscriber addresses from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/subscribers/{id}/addresses`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Subscriber Addresses](https://signalwire.com/docs/apis/rest/subscribers/list-subscriber-addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Subscriber Address. |
