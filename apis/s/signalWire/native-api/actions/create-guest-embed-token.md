# Create Guest Embed Token with SignalWire

Creates a new guest embed token in SignalWire.

## Endpoint

- **Method:** `POST`
- **Path:** `/fabric/embeds/tokens`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Create Guest Embed Token](https://signalwire.com/docs/apis/rest/subscribers/tokens/create-guest-embed-token)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | body | `string` | yes | Click to Call Token |
