# Delete Subscriber with SignalWire

Deletes an existing subscriber from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/subscribers/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete Subscriber](https://signalwire.com/docs/apis/rest/subscribers/delete-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Subscriber. |
