# List Call Flows with SignalWire

Retrieves call flows from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/call_flows`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Call Flows](https://signalwire.com/docs/apis/rest/call-flows/list-call-flows)
