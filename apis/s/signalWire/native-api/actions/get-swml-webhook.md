# Get SWML Webhook with SignalWire

Retrieves a SWML webhook from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/swml_webhooks/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get SWML Webhook](https://signalwire.com/docs/apis/rest/swml-webhook/get-swml-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SWML Webhook. |
