# List Conference Rooms with SignalWire

Retrieves conference rooms from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/conference_rooms`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Conference Rooms](https://signalwire.com/docs/apis/rest/conference-rooms/list-conference-rooms)
