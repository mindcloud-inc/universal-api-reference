# Get AI Agent with SignalWire

Retrieves an AI agent from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/ai_agents/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Get AI Agent](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-custom/get-ai-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of an AI Agent. |
