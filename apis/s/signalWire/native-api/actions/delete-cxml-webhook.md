# Delete cXML Webhook with SignalWire

Deletes an existing cXML webhook from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/cxml_webhooks/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete cXML Webhook](https://signalwire.com/docs/apis/rest/cxml-webhook/delete-cxml-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a CXML Webhook. |
