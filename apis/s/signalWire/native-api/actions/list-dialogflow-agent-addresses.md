# List Dialogflow Agent Addresses with SignalWire

Retrieves Dialogflow agent addresses from SignalWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/fabric/resources/dialogflow_agents/{id}/addresses`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [List Dialogflow Agent Addresses](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-dialogflow/list-dialogflow-agent-addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the Dialogflow Agent Address. |
