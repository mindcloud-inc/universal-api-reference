# Delete cXML Application with SignalWire

Deletes an existing cXML application from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/cxml_applications/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete cXML Application](https://signalwire.com/docs/apis/rest/cxml-applications/delete-cxml-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a cXML Application. |
