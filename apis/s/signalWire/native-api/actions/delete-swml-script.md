# Delete SWML Script with SignalWire

Deletes an existing SWML script from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/swml_scripts/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete SWML Script](https://signalwire.com/docs/apis/rest/swml-scripts/delete-swml-script)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a SWML Script. |
