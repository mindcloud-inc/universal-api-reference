# Delete Resource with SignalWire

Deletes an existing resource from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete Resource](https://signalwire.com/docs/apis/rest/resources/delete-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Resource. |
