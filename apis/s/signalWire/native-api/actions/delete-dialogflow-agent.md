# Delete Dialogflow Agent with SignalWire

Deletes an existing Dialogflow agent from SignalWire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fabric/resources/dialogflow_agents/{id}`
- **Base URL:** `https://mindcloud.signalwire.com/api`
- **Official documentation:** [Delete Dialogflow Agent](https://signalwire.com/docs/apis/rest/ai-agents/ai-agents-dialogflow/delete-dialogflow-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of a Dialogflow Agent. |
