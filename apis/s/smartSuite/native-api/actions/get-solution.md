# Get Solution with SmartSuite

Retrieves a solution from SmartSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/solutions/:solutionId/`
- **Base URL:** `https://app.smartsuite.com/api/v1`
- **Official documentation:** [Get Solution](https://developers.smartsuite.com/docs/solution-data/solutions/get-solution)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `solutionId` | path | `string` | yes | The SmartSuite solution ID to fetch. |
