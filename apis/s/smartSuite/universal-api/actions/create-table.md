# SmartSuite: Create Table

Creates a new table in SmartSuite.

```
POST https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-table
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a SmartSuite `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-table" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "solutionId": "69b45da87cb40fc74dbb4b83",
  "name": "MC Test Records 20260316",
  "structure[]": "[object Object]"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-table', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "solutionId": "69b45da87cb40fc74dbb4b83",
    "name": "MC Test Records 20260316",
    "structure[]": "[object Object]"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `solutionId` | string | yes | The SmartSuite solution ID that will own the new table. Example: `69b45da87cb40fc74dbb4b83`. |
| `name` | string | yes | The display name for the new SmartSuite table. Example: `MC Test Records 20260316`. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `structure[]` | array<object> | yes | An array of SmartSuite field definitions to create with the new table. Example: `[object Object]`. |

## Native endpoint

Through the native SmartSuite API, this operation is `POST /applications/` (base URL `https://app.smartsuite.com/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/create-table.md) for the provider-specific parameters and requirements.
