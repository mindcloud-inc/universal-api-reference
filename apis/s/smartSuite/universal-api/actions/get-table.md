# SmartSuite: Get Table

Retrieves a table from SmartSuite.

```
GET https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/get-table
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a SmartSuite `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/get-table?connectionId=$CONNECTION_ID&tableId=69b45da87cb40fc74dbb4b84" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId,
  "tableId": "69b45da87cb40fc74dbb4b84"
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/get-table?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `tableId` | string | yes | The SmartSuite table ID to fetch. Example: `69b45da87cb40fc74dbb4b84`. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `fields` | string<string> | no | Repeat this query argument to request specific table properties from SmartSuite. Accepts multiple values as an array. Example: `name`. |

## Native endpoint

Through the native SmartSuite API, this operation is `GET /applications/:table_id/` (base URL `https://app.smartsuite.com/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-table.md) for the provider-specific parameters and requirements.
