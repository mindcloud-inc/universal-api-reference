# SmartSuite: Create Solution

Creates a new solution in SmartSuite.

```
POST https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-solution
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a SmartSuite `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-solution" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "name": "MC Test Solution 20260316"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/smartSuite/latest/actions/create-solution', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "name": "MC Test Solution 20260316"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | yes | The display name for the new SmartSuite solution. Example: `MC Test Solution 20260316`. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `logoColor` | string | no | Optional hex color for the solution logo. Example: `#3A86FF`. |
| `logoIcon` | string | no | Optional SmartSuite icon name for the solution logo. Example: `briefcase`. |

## Native endpoint

Through the native SmartSuite API, this operation is `POST /solutions/` (base URL `https://app.smartsuite.com/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/create-solution.md) for the provider-specific parameters and requirements.
