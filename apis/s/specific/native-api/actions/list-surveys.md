# List Surveys with Specific

Retrieves a list of surveys from Specific.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [List Surveys](https://public-api.specific.app/docs/queries/surveys)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
