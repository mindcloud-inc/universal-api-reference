# Search Companies By Name Starts With with Specific

Finds companies in Specific by name prefix.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [Search Companies By Name Starts With](https://public-api.specific.app/docs/queries/companies)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.name` | body | `string` | yes |
