# List Sources with Specific

Retrieves a list of sources from Specific.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [List Sources](https://public-api.specific.app/docs/queries/sources)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
