# Get Workspace with Specific

Retrieves the current workspace from Specific.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [Get Workspace](https://public-api.specific.app/docs/queries/myWorkspace)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
