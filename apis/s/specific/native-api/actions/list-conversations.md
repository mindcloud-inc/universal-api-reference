# List Conversations with Specific

Retrieves a list of conversations from Specific.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [List Conversations](https://public-api.specific.app/docs/queries/conversations)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
