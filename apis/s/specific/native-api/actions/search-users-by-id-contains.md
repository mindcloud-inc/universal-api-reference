# Search Users By ID Contains with Specific

Finds users in Specific by partial ID.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [Search Users By ID Contains](https://public-api.specific.app/docs/queries/users)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.id` | body | `string` | yes |
