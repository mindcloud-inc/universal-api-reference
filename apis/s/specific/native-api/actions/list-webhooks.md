# List Webhooks with Specific

Retrieves a list of webhooks from Specific.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://public-api.specific.app/graphql`
- **Official documentation:** [List Webhooks](https://public-api.specific.app/docs/queries/webhooks)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
