# Get Group with Sender

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [Get Group](https://api.sender.net/groups/get-group/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID. |
