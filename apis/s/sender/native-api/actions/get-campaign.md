# Get Campaign with Sender

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [Get Campaign](https://api.sender.net/campaigns/get-one/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID. |
