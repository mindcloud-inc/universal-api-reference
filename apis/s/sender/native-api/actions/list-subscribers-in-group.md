# List Subscribers in Group with Sender

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id/subscribers`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [List Subscribers in Group](https://api.sender.net/groups/subscribers/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID. |
