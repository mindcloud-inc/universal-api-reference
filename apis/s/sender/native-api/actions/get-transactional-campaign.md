# Get Transactional Campaign with Sender

## Endpoint

- **Method:** `GET`
- **Path:** `/transactional/:id`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [Get Transactional Campaign](https://api.sender.net/transactional_campaigns/get-one/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Transactional campaign ID. |
