# Send Campaign with Sender

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:id/send`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [Send Campaign](https://api.sender.net/campaigns/send/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The campaign id you want to send. |
