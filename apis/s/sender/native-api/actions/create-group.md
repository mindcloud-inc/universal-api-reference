# Create Group with Sender

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.sender.net/v2`
- **Official documentation:** [Create Group](https://api.sender.net/groups/create-group/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Give a name to your new group. |
