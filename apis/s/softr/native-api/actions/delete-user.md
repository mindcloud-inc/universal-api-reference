# Delete User with Softr

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://studio-api.softr.io/v1/api/users/:email`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [Delete User](https://docs.softr.io/softr-api/api-setup-and-endpoints#delete-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email address of the Softr user to delete. |
