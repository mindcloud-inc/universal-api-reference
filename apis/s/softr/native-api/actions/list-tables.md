# List Tables with Softr

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:databaseId/tables`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [List Tables](https://docs.softr.io/softr-api/softr-database-api/tables/get-tables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The ID of the database. |
