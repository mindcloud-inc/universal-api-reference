# Get Table Field with Softr

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:databaseId/tables/:tableId/fields/:fieldId`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [Get Table Field](https://docs.softr.io/softr-api/softr-database-api/table-fields/get-table-field)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `databaseId` | path | `string` | yes |
| `tableId` | path | `string` | yes |
| `fieldId` | path | `string` | yes |
