# Get Table with Softr

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:databaseId/tables/:tableId`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [Get Table](https://docs.softr.io/softr-api/softr-database-api/tables/get-single-table)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The ID of the database. |
| `tableId` | path | `string` | yes | The ID of the table. |
