# Get Database with Softr

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:databaseId`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [Get Database](https://docs.softr.io/softr-api/softr-database-api/databases/get-single-database)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The ID of the database. |
