# List Table Views with Softr

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:databaseId/tables/:tableId/views`
- **Base URL:** `https://tables-api.softr.io/api/v1`
- **Official documentation:** [List Table Views](https://docs.softr.io/softr-api/softr-database-api/tables/get-table-views)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `databaseId` | path | `string` | yes |
| `tableId` | path | `string` | yes |
