# Create Workspace with Salesforge

Creates a workspace in Salesforge.

## Endpoint

- **Method:** `POST`
- **Path:** `/public/v2/workspaces`
- **Base URL:** `https://api.salesforge.ai`
- **Official documentation:** [Create Workspace](https://api.salesforge.ai/public/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
