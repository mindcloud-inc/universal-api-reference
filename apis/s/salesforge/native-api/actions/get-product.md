# Get Product with Salesforge

Retrieves a product from Salesforge.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v2/workspaces/:workspaceID/products/:productID`
- **Base URL:** `https://api.salesforge.ai`
- **Official documentation:** [Get Product](https://api.salesforge.ai/public/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceID` | path | `string` | yes |
| `productID` | path | `string` | yes |
