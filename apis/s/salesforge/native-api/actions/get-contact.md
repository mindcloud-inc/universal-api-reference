# Get Contact with Salesforge

Retrieves a contact from Salesforge.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v2/workspaces/:workspaceID/contacts/:contactID`
- **Base URL:** `https://api.salesforge.ai`
- **Official documentation:** [Get Contact](https://api.salesforge.ai/public/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceID` | path | `string` | yes |
| `contactID` | path | `string` | yes |
