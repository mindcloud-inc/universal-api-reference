# Get Workspace with Salesforge

Retrieves a workspace from Salesforge.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v2/workspaces/:workspaceID`
- **Base URL:** `https://api.salesforge.ai`
- **Official documentation:** [Get Workspace](https://api.salesforge.ai/public/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceID` | path | `string` | yes |
