# Create or Update Vote with Sleekplan

## Endpoint

- **Method:** `POST`
- **Path:** `/post/:postid/vote`
- **Base URL:** `https://api.sleekplan.com/v1`
- **Official documentation:** [Create or Update Vote](https://sleekplan.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `postid` | path | `string` | yes |
