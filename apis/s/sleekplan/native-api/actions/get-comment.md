# Get Comment with Sleekplan

## Endpoint

- **Method:** `GET`
- **Path:** `/post/:postid/comment/:commentid`
- **Base URL:** `https://api.sleekplan.com/v1`
- **Official documentation:** [Get Comment](https://sleekplan.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `commentid` | path | `string` | yes |
| `postid` | path | `string` | yes |
