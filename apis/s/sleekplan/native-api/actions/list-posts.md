# List Posts with Sleekplan

## Endpoint

- **Method:** `GET`
- **Path:** `/posts`
- **Base URL:** `https://api.sleekplan.com/v1`
- **Official documentation:** [List Posts](https://sleekplan.com/docs/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
