# Get Unread Notification Count with Sleekplan

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userid/notifications/count`
- **Base URL:** `https://api.sleekplan.com/v1`
- **Official documentation:** [Get Unread Notification Count](https://sleekplan.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userid` | path | `string` | yes |
