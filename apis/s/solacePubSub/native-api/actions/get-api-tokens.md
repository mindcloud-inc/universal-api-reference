# Get API Tokens with Solace PubSub+

Retrieves API tokens from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/apiTokens`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get API Tokens](https://api.solace.dev/cloud/reference/gettokens)

## Capabilities

This operation supports [pagination](../README.md#pagination).
