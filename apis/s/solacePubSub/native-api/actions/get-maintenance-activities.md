# Get Maintenance Activities with Solace PubSub+

Retrieves maintenance activities from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/maintenanceActivities`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Maintenance Activities](https://api.solace.dev/cloud/reference/maintenance-activities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
