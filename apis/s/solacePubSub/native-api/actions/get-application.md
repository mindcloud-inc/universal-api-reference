# Get Application with Solace PubSub+

Retrieves an application from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/architecture/applications/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Application](https://api.solace.dev/cloud/reference/getapplication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Application identifier. |
