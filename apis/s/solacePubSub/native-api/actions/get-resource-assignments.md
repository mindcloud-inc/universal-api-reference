# Get Resource Assignments with Solace PubSub+

Retrieves resource assignments from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/rrbac/resourceAssignments`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Resource Assignments](https://api.solace.dev/cloud/reference/getresourceassignments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
