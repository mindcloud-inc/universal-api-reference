# Get Application Domains with Solace PubSub+

Retrieves application domains from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/architecture/applicationDomains`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Application Domains](https://api.solace.dev/cloud/reference/getapplicationdomains)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
