# Get User Group with Solace PubSub+

Retrieves a user group from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/userGroups/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get User Group](https://api.solace.dev/cloud/reference/getusergroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User group identifier. |
