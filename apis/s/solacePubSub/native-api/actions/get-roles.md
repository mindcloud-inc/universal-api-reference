# Get Roles with Solace PubSub+

Retrieves roles from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/roles`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Roles](https://api.solace.dev/cloud/reference/getroles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
