# Get Platform Environment with Solace PubSub+

Retrieves a platform environment from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/environments/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Platform Environment](https://api.solace.dev/cloud/reference/getenvironmentbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Environment identifier. |
