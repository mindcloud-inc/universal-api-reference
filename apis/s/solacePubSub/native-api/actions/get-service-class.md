# Get Service Class with Solace PubSub+

Retrieves a service class from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/serviceClasses/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Service Class](https://api.solace.dev/cloud/reference/getserviceclass)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Service class identifier. |
