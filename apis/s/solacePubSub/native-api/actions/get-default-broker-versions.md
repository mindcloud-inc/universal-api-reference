# Get Default Broker Versions with Solace PubSub+

Retrieves default broker versions from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/defaultBrokerVersions`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Default Broker Versions](https://api.solace.dev/cloud/reference/getversions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
