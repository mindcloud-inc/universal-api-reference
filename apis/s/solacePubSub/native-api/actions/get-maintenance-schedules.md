# Get Maintenance Schedules with Solace PubSub+

Retrieves maintenance schedules from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/maintenanceSchedules`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Maintenance Schedules](https://api.solace.dev/cloud/reference/getmaintenanceschedules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
