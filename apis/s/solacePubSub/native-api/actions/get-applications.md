# Get Applications with Solace PubSub+

Retrieves applications from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/architecture/applications`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Applications](https://api.solace.dev/cloud/reference/getapplications)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
