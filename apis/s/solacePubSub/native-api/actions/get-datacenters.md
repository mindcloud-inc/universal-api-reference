# Get Datacenters with Solace PubSub+

Retrieves datacenters from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/datacenters`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Datacenters](https://api.solace.dev/cloud/reference/getdatacenters)

## Capabilities

This operation supports [pagination](../README.md#pagination).
