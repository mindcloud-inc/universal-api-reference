# Get User Groups with Solace PubSub+

Retrieves user groups from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/userGroups`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get User Groups](https://api.solace.dev/cloud/reference/getusergroups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
