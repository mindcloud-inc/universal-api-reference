# Get Datacenter with Solace PubSub+

Retrieves a datacenter from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/datacenters/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Datacenter](https://api.solace.dev/cloud/reference/getdatacenter)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Datacenter identifier. |
