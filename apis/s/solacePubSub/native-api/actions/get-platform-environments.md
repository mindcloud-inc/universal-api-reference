# Get Platform Environments with Solace PubSub+

Retrieves platform environments from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/environments`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Platform Environments](https://api.solace.dev/cloud/reference/searchenvironments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
