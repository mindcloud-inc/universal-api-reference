# Get Organization Contacts with Solace PubSub+

Retrieves organization contacts from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/contacts`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Organization Contacts](https://api.solace.dev/cloud/reference/getmycontacts)
