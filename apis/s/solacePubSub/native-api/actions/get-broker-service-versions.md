# Get Broker Service Versions with Solace PubSub+

Retrieves broker service versions from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/eventBrokerServiceVersions`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Broker Service Versions](https://api.solace.dev/cloud/reference/geteventbrokerserviceversions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
