# Get Application Domain with Solace PubSub+

Retrieves an application domain from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/architecture/applicationDomains/{id}`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Application Domain](https://api.solace.dev/cloud/reference/getapplicationdomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Application domain identifier. |
