# Get Users with Solace PubSub+

Retrieves users from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/platform/users`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Users](https://api.solace.dev/cloud/reference/getusers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
