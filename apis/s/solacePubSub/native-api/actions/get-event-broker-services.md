# Get Event Broker Services with Solace PubSub+

Retrieves event broker services from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/missionControl/eventBrokerServices`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Event Broker Services](https://api.solace.dev/cloud/reference/getservices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
