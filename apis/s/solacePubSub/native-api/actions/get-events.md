# Get Events with Solace PubSub+

Retrieves events from Solace PubSub+.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/architecture/events`
- **Base URL:** `https://api.solace.cloud`
- **Official documentation:** [Get Events](https://api.solace.dev/cloud/reference/getevents)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
