# Delete Invoice with Starfish

Deletes an existing invoice from Starfish.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [Delete Invoice](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID. |
