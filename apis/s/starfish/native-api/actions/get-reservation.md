# Get Reservation with Starfish

Retrieves a specific reservation from Starfish.

## Endpoint

- **Method:** `GET`
- **Path:** `/reservations/:id`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [Get Reservation](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Reservation ID. |
