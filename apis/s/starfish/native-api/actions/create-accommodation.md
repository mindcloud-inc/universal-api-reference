# Create Accommodation with Starfish

Creates a new accommodation in Starfish.

## Endpoint

- **Method:** `POST`
- **Path:** `/accommodations`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [Create Accommodation](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Accommodation name. |
