# Delete Contact with Starfish

Deletes an existing contact from Starfish.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [Delete Contact](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | Contact ID. |
