# List Contacts with Starfish

Retrieves a list of contacts from Starfish.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [List Contacts](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Capabilities

This operation supports [pagination](../README.md#pagination).
