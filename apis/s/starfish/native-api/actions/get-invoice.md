# Get Invoice with Starfish

Retrieves a specific invoice from Starfish.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [Get Invoice](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID. |
