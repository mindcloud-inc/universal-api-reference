# List Accommodations with Starfish

Retrieves a list of accommodations from Starfish.

## Endpoint

- **Method:** `GET`
- **Path:** `/accommodations`
- **Base URL:** `https://api.camping.care/v21`
- **Official documentation:** [List Accommodations](https://documenter.getpostman.com/view/9467805/VUjQkj1d)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
