# Get Highest Snapshot Slot with Solana

Retrieves highest snapshot slots from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Highest Snapshot Slot](https://solana.com/docs/rpc/http/gethighestsnapshotslot)
