# Get Block Production (Draft Variant) with Solana

Retrieves block production details from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Block Production (Draft Variant)](https://solana.com/docs/rpc/http/getblockproduction)
