# Get Recent Performance Samples (Draft Variant) with Solana

Retrieves recent performance samples from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Recent Performance Samples (Draft Variant)](https://solana.com/docs/rpc/http/getrecentperformancesamples)
