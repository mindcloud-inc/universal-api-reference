# Get Recent Prioritization Fees (Draft Variant) with Solana

Retrieves recent prioritization fees from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Recent Prioritization Fees (Draft Variant)](https://solana.com/docs/rpc/http/getrecentprioritizationfees)
