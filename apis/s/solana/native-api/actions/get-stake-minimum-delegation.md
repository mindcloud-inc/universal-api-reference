# Get Stake Minimum Delegation with Solana

Retrieves the minimum stake delegation from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Stake Minimum Delegation](https://solana.com/docs/rpc/http/getstakeminimumdelegation)
