# Get Max Retransmit Slot with Solana

Retrieves the max retransmit slot from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Max Retransmit Slot](https://solana.com/docs/rpc/http/getmaxretransmitslot)
