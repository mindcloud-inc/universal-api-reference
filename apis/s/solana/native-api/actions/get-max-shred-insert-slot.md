# Get Max Shred Insert Slot with Solana

Retrieves the max shred insert slot from Solana.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mainnet-beta.solana.com`
- **Official documentation:** [Get Max Shred Insert Slot](https://solana.com/docs/rpc/http/getmaxshredinsertslot)
