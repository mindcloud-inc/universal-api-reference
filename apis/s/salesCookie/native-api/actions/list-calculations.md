# List Calculations with Sales Cookie

Retrieves calculation records from Sales Cookie.

## Endpoint

- **Method:** `GET`
- **Path:** `/odata/:apiKey/Calculation?$top=1`
- **Base URL:** `https://salescookie.com/app`
- **Official documentation:** [List Calculations](https://support2.salescookie.com/portal/en/kb/articles/kb-how-can-i-access-sales-incentive-data-using-api-calls)
