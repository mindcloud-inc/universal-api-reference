# Get Custom Properties with Sales Cookie

Retrieves custom properties for a Sales Cookie entity.

## Endpoint

- **Method:** `GET`
- **Path:** `/Api/GetCustomProperties`
- **Base URL:** `https://salescookie.com/app`
- **Official documentation:** [Get Custom Properties](https://support2.salescookie.com/portal/en/kb/articles/kb-how-can-i-programmatically-retrieve-or-set-custom-variables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | System user, team, or plan ID. |
