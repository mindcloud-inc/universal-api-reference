# Get Applicant Data with Sumsub

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/applicants/:applicantId/one`
- **Base URL:** `https://api.sumsub.com`
- **Official documentation:** [Get Applicant Data](https://docs.sumsub.com/reference/get-applicant-data)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `applicantId` | path | `string` | yes |
