# Get Applicant Data By External User ID with Sumsub

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/applicants/-;externalUserId=:externalUserId/one`
- **Base URL:** `https://api.sumsub.com`
- **Official documentation:** [Get Applicant Data By External User ID](https://docs.sumsub.com/reference/get-applicant-data-via-externaluserid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `externalUserId` | path | `string` | yes |
