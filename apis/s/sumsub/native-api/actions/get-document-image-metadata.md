# Get Document Image Metadata with Sumsub

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/applicants/:applicantId/metadata/resources`
- **Base URL:** `https://api.sumsub.com`
- **Official documentation:** [Get Document Image Metadata](https://docs.sumsub.com/reference/get-information-about-document-images)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `applicantId` | path | `string` | yes |
