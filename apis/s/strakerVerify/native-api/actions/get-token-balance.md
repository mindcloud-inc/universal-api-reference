# Get Token Balance with Straker Verify

Retrieves your token balance from Straker Verify.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/balance`
- **Base URL:** `https://api-verify.straker.ai`
- **Official documentation:** [Get Token Balance](https://api-verify.straker.ai/docs#/default/get_token_balance_user_balance_get)
