# Retrieve Dispute with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `disputes/:dispute`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Dispute](https://docs.stripe.com/api/disputes/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dispute` | path | `string` | yes |
