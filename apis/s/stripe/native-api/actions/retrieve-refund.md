# Retrieve Refund with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `refunds/:refund`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Refund](https://docs.stripe.com/api/refunds/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `refund` | path | `string` | yes |
