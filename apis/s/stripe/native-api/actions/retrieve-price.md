# Retrieve Price with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `prices/:price`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Price](https://docs.stripe.com/api/prices/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `price` | path | `string` | yes |
