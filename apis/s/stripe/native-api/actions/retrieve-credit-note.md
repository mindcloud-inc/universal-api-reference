# Retrieve Credit Note with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `credit_notes/:creditNote`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Credit Note](https://docs.stripe.com/api/credit_notes/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `creditNote` | path | `string` | yes |
