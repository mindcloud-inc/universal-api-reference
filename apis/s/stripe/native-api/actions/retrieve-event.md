# Retrieve Event with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `events/:event`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Event](https://docs.stripe.com/api/events/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `event` | path | `string` | yes |
