# Retrieve Invoice with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `invoices/:invoice`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Invoice](https://docs.stripe.com/api/invoices/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice` | path | `string` | yes |
