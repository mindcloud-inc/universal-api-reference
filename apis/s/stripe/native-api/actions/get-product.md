# Get Product with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `products/:id`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Get Product](https://docs.stripe.com/api/products/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique Stripe product ID. |
