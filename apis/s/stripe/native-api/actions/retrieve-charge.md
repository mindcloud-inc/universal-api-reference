# Retrieve Charge with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `charges/:charge`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Charge](https://docs.stripe.com/api/charges/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `charge` | path | `string` | yes |
