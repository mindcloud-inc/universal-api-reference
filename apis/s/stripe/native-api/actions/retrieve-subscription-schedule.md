# Retrieve Subscription Schedule with Stripe

## Endpoint

- **Method:** `GET`
- **Path:** `subscription_schedules/:schedule`
- **Base URL:** `https://api.stripe.com/v1`
- **Official documentation:** [Retrieve Subscription Schedule](https://docs.stripe.com/api/subscription_schedules/retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `schedule` | path | `string` | yes |
