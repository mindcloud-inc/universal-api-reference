# Delete Sheet with Smartsheet

Deletes an existing sheet from Smartsheet.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sheets/:sheetId`
- **Base URL:** `https://api.smartsheet.com/2.0`
- **Official documentation:** [Delete Sheet](https://developers.smartsheet.com/api/smartsheet/openapi/sheets/delete-sheet)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sheetId` | path | `number` | yes |
