# List Reports with Smartsheet

Retrieves reports from Smartsheet.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports`
- **Base URL:** `https://api.smartsheet.com/2.0`
- **Official documentation:** [List Reports](https://developers.smartsheet.com/api/smartsheet/openapi/reports/getreports)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `modifiedSince` | query | `date` | no |
