# Delete Webhook with SMASHSEND Email Marketing

Deletes a webhook from SMASHSEND.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Delete Webhook](https://smashsend.com/docs/api/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The SMASHSEND webhook ID to delete. |
