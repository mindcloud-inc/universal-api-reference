# Get Contact Property with SMASHSEND Email Marketing

Retrieves a contact property by ID from SMASHSEND.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact-properties/:propertyId`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Get Contact Property](https://smashsend.com/docs/api/contact-properties)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | The SMASHSEND contact property ID to retrieve. |
