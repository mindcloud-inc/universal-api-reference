# Get Contact with SMASHSEND Email Marketing

Retrieves a contact by ID from SMASHSEND.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:contactId`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Get Contact](https://smashsend.com/docs/api/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The SMASHSEND contact ID to retrieve. |
