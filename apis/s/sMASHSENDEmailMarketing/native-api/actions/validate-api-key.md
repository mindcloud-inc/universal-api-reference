# Validate API Key with SMASHSEND Email Marketing

Validates a SMASHSEND API key and returns its details.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/api-keys/check`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Validate API Key](https://smashsend.com/docs/api/api-keys)
