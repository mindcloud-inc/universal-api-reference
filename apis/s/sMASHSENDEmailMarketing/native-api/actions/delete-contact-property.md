# Delete Contact Property with SMASHSEND Email Marketing

Deletes a contact property from SMASHSEND.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contact-properties/:propertyId`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Delete Contact Property](https://smashsend.com/docs/api/contact-properties)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | The SMASHSEND contact property ID to delete. |
