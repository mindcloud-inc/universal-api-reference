# Create Or Update Contact with SMASHSEND Email Marketing

Creates or updates a contact in SMASHSEND by email.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Create Or Update Contact](https://smashsend.com/docs/api/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `properties` | body | `object` | yes | Contact properties payload wrapped under the documented properties object. |
