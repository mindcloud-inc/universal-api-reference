# Search Contacts with SMASHSEND Email Marketing

Finds a contact in SMASHSEND by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/search`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Search Contacts](https://smashsend.com/docs/api/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to search for. |
