# List Contacts with SMASHSEND Email Marketing

Retrieves contacts from your SMASHSEND workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [List Contacts](https://smashsend.com/docs/api/contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
