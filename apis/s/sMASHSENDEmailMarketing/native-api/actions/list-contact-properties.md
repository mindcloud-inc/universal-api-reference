# List Contact Properties with SMASHSEND Email Marketing

Retrieves contact properties from your SMASHSEND workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact-properties`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [List Contact Properties](https://smashsend.com/docs/api/contact-properties)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
