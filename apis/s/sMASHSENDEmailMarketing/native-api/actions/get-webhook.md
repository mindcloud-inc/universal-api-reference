# Get Webhook with SMASHSEND Email Marketing

Retrieves a webhook by ID from SMASHSEND.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.smashsend.com`
- **Official documentation:** [Get Webhook](https://smashsend.com/docs/api/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The SMASHSEND webhook ID to retrieve. |
