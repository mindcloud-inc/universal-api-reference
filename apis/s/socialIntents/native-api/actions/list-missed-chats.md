# List Missed Chats with Social Intents

Retrieves missed chats from Social Intents.

## Endpoint

- **Method:** `GET`
- **Path:** `/missedchats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Missed Chats](https://www.socialintents.com/docs/integrations/rest-api-overview)
