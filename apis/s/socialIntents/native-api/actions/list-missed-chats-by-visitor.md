# List Missed Chats By Visitor with Social Intents

Retrieves missed chats from Social Intents by visitor ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/missedchats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Missed Chats By Visitor](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `visitor_id` | query | `string` | yes | Filter missed chats by visitor ID. |
