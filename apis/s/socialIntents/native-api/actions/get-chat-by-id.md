# Get Chat By ID with Social Intents

Retrieves a chat from Social Intents by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [Get Chat By ID](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Social Intents chat ID to fetch. |
