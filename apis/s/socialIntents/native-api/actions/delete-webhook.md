# Delete Webhook with Social Intents

Deletes a webhook from Social Intents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook/:webhookId`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [Delete Webhook](https://www.socialintents.com/docs/integrations/webhooks-leads-transcripts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The Social Intents webhook ID to delete. |
