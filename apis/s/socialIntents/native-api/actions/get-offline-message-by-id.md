# Get Offline Message By ID with Social Intents

Retrieves an offline message from Social Intents by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/offlinemessages`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [Get Offline Message By ID](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Social Intents offline message ID to fetch. |
