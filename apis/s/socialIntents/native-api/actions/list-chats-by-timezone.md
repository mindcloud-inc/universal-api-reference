# List Chats By Timezone with Social Intents

Retrieves chats from Social Intents by timezone.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Chats By Timezone](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timezone` | query | `string` | yes | Filter chats by timezone. |
