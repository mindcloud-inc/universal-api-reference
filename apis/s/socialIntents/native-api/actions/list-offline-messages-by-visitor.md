# List Offline Messages By Visitor with Social Intents

Retrieves offline messages from Social Intents by visitor ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/offlinemessages`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Offline Messages By Visitor](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `visitor_id` | query | `string` | yes | Filter offline messages by visitor ID. |
