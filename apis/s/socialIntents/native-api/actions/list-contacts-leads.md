# List Contacts / Leads with Social Intents

Retrieves contacts and leads from Social Intents.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Contacts / Leads](https://www.socialintents.com/docs/integrations/rest-api-overview)
