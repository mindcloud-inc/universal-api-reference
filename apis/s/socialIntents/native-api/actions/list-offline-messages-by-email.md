# List Offline Messages By Email with Social Intents

Retrieves offline messages from Social Intents by visitor email.

## Endpoint

- **Method:** `GET`
- **Path:** `/offlinemessages`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Offline Messages By Email](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Filter offline messages by visitor email. |
