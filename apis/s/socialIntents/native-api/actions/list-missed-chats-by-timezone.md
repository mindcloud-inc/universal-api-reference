# List Missed Chats By Timezone with Social Intents

Retrieves missed chats from Social Intents by timezone.

## Endpoint

- **Method:** `GET`
- **Path:** `/missedchats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Missed Chats By Timezone](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timezone` | query | `string` | yes | Filter missed chats by timezone. |
