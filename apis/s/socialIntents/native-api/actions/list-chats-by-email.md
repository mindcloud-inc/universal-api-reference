# List Chats By Email with Social Intents

Retrieves chats from Social Intents by visitor email.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Chats By Email](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Filter chats by visitor email. |
