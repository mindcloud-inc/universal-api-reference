# List Offline Messages with Social Intents

Retrieves offline messages from Social Intents.

## Endpoint

- **Method:** `GET`
- **Path:** `/offlinemessages`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Offline Messages](https://www.socialintents.com/docs/integrations/rest-api-overview)
