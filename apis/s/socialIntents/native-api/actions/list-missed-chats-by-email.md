# List Missed Chats By Email with Social Intents

Retrieves missed chats from Social Intents by visitor email.

## Endpoint

- **Method:** `GET`
- **Path:** `/missedchats`
- **Base URL:** `https://www.socialintents.com/v1/api`
- **Official documentation:** [List Missed Chats By Email](https://www.socialintents.com/docs/integrations/rest-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Filter missed chats by visitor email. |
