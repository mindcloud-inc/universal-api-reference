# Create Artifact with Survalyzer

- **Method:** `POST`
- **Path:** `/publicapi/Common/v3/CreateArtifact`
- **Base URL:** `https://api.survalyzer-eu.app`
- **Official documentation:** [Create Artifact](https://developer.survalyzer.com/knowledge-base/public-api-eu/)
