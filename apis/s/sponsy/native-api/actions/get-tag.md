# Get Tag with Sponsy

Retrieves a tag from Sponsy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tags/:tagId`
- **Base URL:** `https://api.getsponsy.com`
- **Official documentation:** [Get Tag](https://docs.getsponsy.com/Workspace-Settings-10bb5594716880348de9ce02c29f53f0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `list<string>` | yes | Tag ID from List Tags. |
