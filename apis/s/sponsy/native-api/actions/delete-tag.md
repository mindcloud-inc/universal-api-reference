# Delete Tag with Sponsy

Deletes a tag from Sponsy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/tags/:tagId`
- **Base URL:** `https://api.getsponsy.com`
- **Official documentation:** [Delete Tag](https://docs.getsponsy.com/Workspace-Settings-10bb5594716880348de9ce02c29f53f0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Tag ID from Sponsy. |
