# Get Customer with Sponsy

Retrieves a customer from Sponsy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customerId`
- **Base URL:** `https://api.getsponsy.com`
- **Official documentation:** [Get Customer](https://docs.getsponsy.com/CRM-182b5594716880bd9d7afde179bc1114)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `list<string>` | yes | Customer ID from List Customers. |
