# List Customer Contacts with Sponsy

Retrieves customer contacts from Sponsy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customerId/contacts`
- **Base URL:** `https://api.getsponsy.com`
- **Official documentation:** [List Customer Contacts](https://docs.getsponsy.com/Customer-Portal-184b55947168803c9d21cca09e49f22b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer ID from Sponsy. |
