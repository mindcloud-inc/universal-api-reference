# List Publications with Sponsy

Retrieves publications from Sponsy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/publications`
- **Base URL:** `https://api.getsponsy.com`
- **Official documentation:** [List Publications](https://docs.getsponsy.com/Ad-Inventory-Calendar-10bb55947168808abeb8f73d7a73873e)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
