# Get Season with Simplecast

Retrieves a season from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/seasons/:season_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Season](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `season_id` | path | `string` | yes | Simplecast season identifier. |
