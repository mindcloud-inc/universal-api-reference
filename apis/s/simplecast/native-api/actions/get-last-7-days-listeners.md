# Get Last 7 Days Listeners with Simplecast

Retrieves last 7 days listener analytics from Simplecast.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/listeners/last_7`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Last 7 Days Listeners](https://apidocs.simplecast.com/)
