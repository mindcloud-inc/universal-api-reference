# Get Podcast with Simplecast

Retrieves a podcast from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/:podcast_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Podcast](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast_id` | path | `string` | yes | Simplecast podcast identifier. |
