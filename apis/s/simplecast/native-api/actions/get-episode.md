# Get Episode with Simplecast

Retrieves an episode from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/:episode_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Episode](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `episode_id` | path | `string` | yes | Simplecast episode identifier. |
