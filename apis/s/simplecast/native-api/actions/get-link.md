# Get Link with Simplecast

Retrieves a link from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:link_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Link](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link_id` | path | `string` | yes | Simplecast link identifier. |
