# Get Embed Heatmap Analytics with Simplecast

Retrieves embed heatmap analytics from Simplecast.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/embed/heatmap`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Embed Heatmap Analytics](https://apidocs.simplecast.com/)
