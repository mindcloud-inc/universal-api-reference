# Get Author with Simplecast

Retrieves an author from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/authors/:author_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Author](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `author_id` | path | `string` | yes | Simplecast author identifier. |
