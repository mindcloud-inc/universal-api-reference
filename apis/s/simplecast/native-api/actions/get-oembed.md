# Get OEmbed with Simplecast

Retrieves oEmbed data from Simplecast.

## Endpoint

- **Method:** `GET`
- **Path:** `/oembed`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get OEmbed](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Podcast or episode URL to embed. |
