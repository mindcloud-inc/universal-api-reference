# Get Podcast RSS with Simplecast

Retrieves a podcast RSS feed from Simplecast.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts/:podcast_id/rss`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Podcast RSS](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `podcast_id` | path | `string` | yes | Simplecast podcast identifier. |
