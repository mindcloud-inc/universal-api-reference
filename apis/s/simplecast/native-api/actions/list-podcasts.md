# List Podcasts with Simplecast

Retrieves podcasts from Simplecast.

## Endpoint

- **Method:** `GET`
- **Path:** `/podcasts`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [List Podcasts](https://apidocs.simplecast.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
