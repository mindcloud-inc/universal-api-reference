# Get Keyword with Simplecast

Retrieves a keyword from Simplecast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/keywords/:keyword_id`
- **Base URL:** `https://api.simplecast.com`
- **Official documentation:** [Get Keyword](https://apidocs.simplecast.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword_id` | path | `string` | yes | Simplecast keyword identifier. |
