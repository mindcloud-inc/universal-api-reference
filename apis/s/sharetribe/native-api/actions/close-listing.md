# Close Listing with Sharetribe

Closes an existing listing in Sharetribe.

## Endpoint

- **Method:** `POST`
- **Path:** `listings/close`
- **Base URL:** `https://flex-integ-api.sharetribe.com/v1/integration_api`
- **Official documentation:** [Close Listing](https://www.sharetribe.com/api-reference/integration.html#close-listing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The listing ID. |
