# Show Listing with Sharetribe

Retrieves a listing from Sharetribe.

## Endpoint

- **Method:** `GET`
- **Path:** `listings/show`
- **Base URL:** `https://flex-integ-api.sharetribe.com/v1/integration_api`
- **Official documentation:** [Show Listing](https://www.sharetribe.com/api-reference/integration.html#show-listing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the listing. |
