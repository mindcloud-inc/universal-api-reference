# Show Transaction with Sharetribe

Retrieves a transaction from Sharetribe.

## Endpoint

- **Method:** `GET`
- **Path:** `transactions/show`
- **Base URL:** `https://flex-integ-api.sharetribe.com/v1/integration_api`
- **Official documentation:** [Show Transaction](https://www.sharetribe.com/api-reference/integration.html#show-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the transaction. |
