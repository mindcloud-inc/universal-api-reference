# Approve User with Sharetribe

Approves an existing user in Sharetribe.

## Endpoint

- **Method:** `POST`
- **Path:** `users/approve`
- **Base URL:** `https://flex-integ-api.sharetribe.com/v1/integration_api`
- **Official documentation:** [Approve User](https://www.sharetribe.com/api-reference/integration.html#approve-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The user ID. |
