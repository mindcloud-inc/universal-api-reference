# Get Athlete Zones with Strava

Retrieves the authenticated athlete zones from Strava.

## Endpoint

- **Method:** `GET`
- **Path:** `/athlete/zones`
- **Base URL:** `https://www.strava.com/api/v3`
- **Official documentation:** [Get Athlete Zones](https://developers.strava.com/docs/reference/#api-Athletes-getLoggedInAthleteZones)
