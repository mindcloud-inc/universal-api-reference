# Get Segment with Strava

Retrieves a segment from Strava by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:id`
- **Base URL:** `https://www.strava.com/api/v3`
- **Official documentation:** [Get Segment](https://developers.strava.com/docs/reference/#api-Segments-getSegmentById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier of the segment. |
