# Get Authenticated Athlete with Strava

Retrieves the authenticated athlete profile from Strava.

## Endpoint

- **Method:** `GET`
- **Path:** `/athlete`
- **Base URL:** `https://www.strava.com/api/v3`
- **Official documentation:** [Get Authenticated Athlete](https://developers.strava.com/docs/reference/#api-Athletes-getLoggedInAthlete)
