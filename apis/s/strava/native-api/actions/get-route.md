# Get Route with Strava

Retrieves a route from Strava by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes/:id`
- **Base URL:** `https://www.strava.com/api/v3`
- **Official documentation:** [Get Route](https://developers.strava.com/docs/reference/#api-Routes-getRouteById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier of the route. |
