# Get Survey with SatisMeter

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/projects/:projectId/campaigns/:campaignId`
- **Base URL:** `https://app.satismeter.com`
- **Official documentation:** [Get Survey](https://app.satismeter.com/apidoc#tag/Surveys/paths/~1projects~1{projectId}~1campaigns~1{campaignId}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Survey ID. |
| `projectId` | path | `string` | yes | Project ID. |
