# Delete User with SatisMeter

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/users/:userId`
- **Base URL:** `https://app.satismeter.com`
- **Official documentation:** [Delete User](https://support.satismeter.com/hc/en-us/articles/6980450524179-Delete-user-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | SatisMeter internal user ID. |
