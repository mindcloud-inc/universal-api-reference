# List Users with SatisMeter

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users`
- **Base URL:** `https://app.satismeter.com`
- **Official documentation:** [List Users](https://support.satismeter.com/hc/en-us/articles/6980473872531-List-users-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | Project ID. |
| `userId` | query | `string` | no | Filter by a specific user ID. |
