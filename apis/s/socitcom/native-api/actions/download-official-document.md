# Download Official Document with Société.com

Downloads an official document from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents-officiels/:id/download`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [Download Official Document](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-t&eacute;l&eacute;chargement-des-documents-officiels-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Official document id returned by Société.com. |
