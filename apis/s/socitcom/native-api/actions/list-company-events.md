# List Company Events with Société.com

Retrieves company events from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/entreprise/:numid/evenements`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [List Company Events](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-ev&egrave;nements-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `numid` | path | `string` | no | Company identifier or SIREN. |
