# List Company Official Documents with Société.com

Retrieves company official documents from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/entreprise/:numid/documents-officiels`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [List Company Official Documents](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-documents-officiels-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `numid` | path | `string` | no | Company identifier or SIREN. |
