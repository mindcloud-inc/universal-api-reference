# Get Client Information with Société.com

Retrieves client account information from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/infoclient`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [Get Client Information](https://api.societe.com/apisite/documentations/v1/documentation-api.html#compte-client-informations-client-get)
