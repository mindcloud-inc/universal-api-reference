# List Client Log with Société.com

Retrieves client API usage logs from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/logclient`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [List Client Log](https://api.societe.com/apisite/documentations/v1/documentation-api.html#compte-client-log-client-get)
