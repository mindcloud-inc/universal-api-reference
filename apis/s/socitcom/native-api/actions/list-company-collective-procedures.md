# List Company Collective Procedures with Société.com

Retrieves company collective procedures from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/entreprise/:numid/procedurescollectives`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [List Company Collective Procedures](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-proc&eacute;dures-collectives-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `numid` | path | `string` | no | Company identifier or SIREN. |
