# Get Company Scoring with Société.com

Retrieves company scoring from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/entreprise/:numid/scoring`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [Get Company Scoring](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-scoring-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `numid` | path | `string` | no | Company identifier or SIREN. |
