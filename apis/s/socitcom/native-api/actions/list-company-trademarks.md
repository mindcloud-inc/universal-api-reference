# List Company Trademarks with Société.com

Retrieves company trademarks from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/entreprise/:numid/marques`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [List Company Trademarks](https://api.societe.com/apisite/documentations/v1/documentation-api.html#societe-marques-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `numid` | path | `string` | no | Company identifier or SIREN. |
