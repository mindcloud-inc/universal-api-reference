# Get Officer Mandates with Société.com

Retrieves officer mandates from Société.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/mandats/:dirid`
- **Base URL:** `https://api.societe.com/api/v1`
- **Official documentation:** [Get Officer Mandates](https://api.societe.com/apisite/documentations/v1/documentation-api.html#dirigeant-cartographie-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dirid` | path | `string` | no | Officer id returned by Société.com autocomplete. |
