# Get Simulation Session with Synthflow AI Phone Calling

Retrieves a simulation session from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulation_sessions/:simulation_session_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Simulation Session](https://docs.synthflow.ai/api-reference/platform-api/simulations/get-simulation-session)
