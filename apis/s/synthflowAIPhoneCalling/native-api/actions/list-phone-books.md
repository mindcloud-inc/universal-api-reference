# List Phone Books with Synthflow AI Phone Calling

Retrieves all phone books from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonebooks`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Phone Books](https://docs.synthflow.ai/api-reference/platform-api/phone-books/list-phone-books)
