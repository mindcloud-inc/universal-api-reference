# List Simulations with Synthflow AI Phone Calling

Retrieves all simulation runs from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulations`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Simulations](https://docs.synthflow.ai/api-reference/platform-api/simulations/list-simulations)
