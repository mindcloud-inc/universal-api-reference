# Start Simulation with Synthflow AI Phone Calling

Starts a new simulation in Synthflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/simulations/start`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Start Simulation](https://docs.synthflow.ai/api-reference/platform-api/simulations/start-simulation)
