# Update Simulation Case with Synthflow AI Phone Calling

Updates an existing simulation case in Synthflow.

## Endpoint

- **Method:** `PUT`
- **Path:** `/simulation_cases/:simulation_case_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Update Simulation Case](https://docs.synthflow.ai/api-reference/platform-api/simulations/update-simulation-case)
