# Generate Test Cases with Synthflow AI Phone Calling

Generates new simulation cases in Synthflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/simulation_cases/generate`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Generate Test Cases](https://docs.synthflow.ai/api-reference/platform-api/simulations/generate-test-cases)
