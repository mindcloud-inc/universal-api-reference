# Delete Contact with Synthflow AI Phone Calling

Deletes an existing contact from Synthflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Delete Contact](https://docs.synthflow.ai/api-reference/platform-api/contacts/delete-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The Synthflow contact identifier. |
