# Create Phone Book Entry with Synthflow AI Phone Calling

Creates a new phone book entry in Synthflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/phonebooks/:phone_book_id/entries`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Create Phone Book Entry](https://docs.synthflow.ai/api-reference/platform-api/phone-books/create-a-phone-book-entry)
