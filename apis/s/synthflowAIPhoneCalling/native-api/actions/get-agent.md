# Get Agent with Synthflow AI Phone Calling

Retrieves a voice agent from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/assistants/:model_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Agent](https://docs.synthflow.ai/api-reference/platform-api/agents/get-assistant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The Synthflow agent model identifier. |
