# Update Agent with Synthflow AI Phone Calling

Updates an existing voice agent in Synthflow.

## Endpoint

- **Method:** `PUT`
- **Path:** `/assistants/:model_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Update Agent](https://docs.synthflow.ai/api-reference/platform-api/agents/update-assistant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The Synthflow agent model identifier. |
