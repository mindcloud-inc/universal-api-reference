# List Phone Numbers with Synthflow AI Phone Calling

Retrieves all phone numbers from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Phone Numbers](https://docs.synthflow.ai/api-reference/platform-api/phone-numbers/get-numbers)
