# List Simulation Cases with Synthflow AI Phone Calling

Retrieves all simulation cases from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulation_cases`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Simulation Cases](https://docs.synthflow.ai/api-reference/platform-api/simulations/list-simulation-cases)
