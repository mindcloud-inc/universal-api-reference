# Delete Phone Book with Synthflow AI Phone Calling

Deletes an existing phone book from Synthflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/phonebooks/:phone_book_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Delete Phone Book](https://docs.synthflow.ai/api-reference/platform-api/phone-books/delete-a-phone-book)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_book_id` | path | `string` | yes | The phone book identifier. |
