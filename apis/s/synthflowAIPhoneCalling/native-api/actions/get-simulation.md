# Get Simulation with Synthflow AI Phone Calling

Retrieves a simulation run from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulations/:simulation_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Simulation](https://docs.synthflow.ai/api-reference/platform-api/simulations/get-simulation)
