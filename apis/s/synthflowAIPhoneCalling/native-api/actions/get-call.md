# Get Call with Synthflow AI Phone Calling

Retrieves a phone call from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:call_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Call](https://docs.synthflow.ai/api-reference/platform-api/calls/get-phone-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | The Synthflow call identifier. |
