# List Webhook Logs with Synthflow AI Phone Calling

Retrieves all webhook logs from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/logs`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Webhook Logs](https://docs.synthflow.ai/api-reference/platform-api/webhook-logs/list-webhook-logs)
