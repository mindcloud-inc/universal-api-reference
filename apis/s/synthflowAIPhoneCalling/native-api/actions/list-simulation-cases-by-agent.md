# List Simulation Cases By Agent with Synthflow AI Phone Calling

Retrieves simulation cases for a Synthflow agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulation_cases/by_agent`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Simulation Cases By Agent](https://docs.synthflow.ai/api-reference/platform-api/simulations/list-simulation-cases-by-agent)
