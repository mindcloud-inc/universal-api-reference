# Create Phone Book with Synthflow AI Phone Calling

Creates a new phone book in Synthflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/phonebooks`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Create Phone Book](https://docs.synthflow.ai/api-reference/platform-api/phone-books/create-a-phone-book)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The phone book name. |
