# List Simulation Sessions with Synthflow AI Phone Calling

Retrieves all simulation sessions from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulation_sessions`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Simulation Sessions](https://docs.synthflow.ai/api-reference/platform-api/simulations/list-simulation-sessions)
