# Get Simulation Case with Synthflow AI Phone Calling

Retrieves a simulation case from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/simulation_cases/:simulation_case_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Simulation Case](https://docs.synthflow.ai/api-reference/platform-api/simulations/get-simulation-case)
