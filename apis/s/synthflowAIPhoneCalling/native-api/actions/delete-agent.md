# Delete Agent with Synthflow AI Phone Calling

Deletes an existing voice agent from Synthflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assistants/:model_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Delete Agent](https://docs.synthflow.ai/api-reference/platform-api/agents/delete-assistant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The Synthflow agent model identifier. |
