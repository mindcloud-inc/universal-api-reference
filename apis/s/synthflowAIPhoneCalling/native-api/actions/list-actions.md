# List Actions with Synthflow AI Phone Calling

Retrieves all custom actions from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Actions](https://docs.synthflow.ai/api-reference/platform-api/actions/list-actions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Actions displayed per page. |
| `offset` | query | `number` | no | Index of the first action to return. |
