# Get Webhook Log with Synthflow AI Phone Calling

Retrieves a webhook log from Synthflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/logs/:webhook_log_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Get Webhook Log](https://docs.synthflow.ai/api-reference/platform-api/webhook-logs/get-webhook-log-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_log_id` | path | `string` | yes | The webhook log identifier. |
