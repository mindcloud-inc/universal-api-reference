# Delete Phone Book Entry with Synthflow AI Phone Calling

Deletes an existing phone book entry from Synthflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/phonebooks/:phone_book_id/entries/:entry_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Delete Phone Book Entry](https://docs.synthflow.ai/api-reference/platform-api/phone-books/delete-a-phone-book-entry)
