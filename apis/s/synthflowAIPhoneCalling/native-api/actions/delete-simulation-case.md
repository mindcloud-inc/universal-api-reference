# Delete Simulation Case with Synthflow AI Phone Calling

Deletes an existing simulation case from Synthflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/simulation_cases/:simulation_case_id`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [Delete Simulation Case](https://docs.synthflow.ai/api-reference/platform-api/simulations/delete-simulation-case)
