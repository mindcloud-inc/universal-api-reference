# List Contacts with Synthflow AI Phone Calling

Retrieves all contacts from your Synthflow workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.synthflow.ai/v2`
- **Official documentation:** [List Contacts](https://docs.synthflow.ai/api-reference/platform-api/contacts/list-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contacts by phone number. |
