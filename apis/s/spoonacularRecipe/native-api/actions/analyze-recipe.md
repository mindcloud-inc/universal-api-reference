# Analyze Recipe with Spoonacular Recipe

Analyzes raw recipe data in Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/recipes/analyze`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Analyze Recipe](https://spoonacular.com/food-api/docs#Analyze-Recipe)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
