# Compute Ingredient Amount with Spoonacular Recipe

Computes ingredient amounts for nutrition goals in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/ingredients/{id}/amount`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Compute Ingredient Amount](https://spoonacular.com/food-api/docs#Compute-Ingredient-Amount)
