# Extract Recipe from Website with Spoonacular Recipe

Extracts recipe data from a website in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/extract`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Extract Recipe from Website](https://spoonacular.com/food-api/docs#Extract-Recipe-from-Website)

## Capabilities

This operation supports [filtering](../README.md#filtering).
