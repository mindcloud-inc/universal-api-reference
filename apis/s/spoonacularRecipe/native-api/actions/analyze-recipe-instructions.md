# Analyze Recipe Instructions with Spoonacular Recipe

Analyzes recipe instructions in Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/recipes/analyzeInstructions`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Analyze Recipe Instructions](https://spoonacular.com/food-api/docs#Analyze-Recipe-Instructions)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
