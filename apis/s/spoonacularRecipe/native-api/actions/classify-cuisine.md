# Classify Cuisine with Spoonacular Recipe

Classifies a recipe's cuisine in Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/recipes/cuisine`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Classify Cuisine](https://spoonacular.com/food-api/docs#Classify-Cuisine)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
