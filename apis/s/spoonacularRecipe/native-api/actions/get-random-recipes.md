# Get Random Recipes with Spoonacular Recipe

Retrieves random recipe results from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/random`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Random Recipes](https://spoonacular.com/food-api/docs#Get-Random-Recipes)

## Capabilities

This operation supports [filtering](../README.md#filtering).
