# Get Ingredient Substitutes by ID with Spoonacular Recipe

Finds ingredient substitutes in Spoonacular by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/ingredients/{id}/substitutes`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Ingredient Substitutes by ID](https://spoonacular.com/food-api/docs#Get-Ingredient-Substitutes-by-ID)
