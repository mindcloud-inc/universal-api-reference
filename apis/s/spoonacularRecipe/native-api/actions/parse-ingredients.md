# Parse Ingredients with Spoonacular Recipe

Parses ingredients from plain text in Spoonacular.

## Endpoint

- **Method:** `POST`
- **Path:** `/recipes/parseIngredients`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Parse Ingredients](https://spoonacular.com/food-api/docs#Parse-Ingredients)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
