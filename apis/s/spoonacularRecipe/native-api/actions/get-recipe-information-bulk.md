# Get Recipe Information Bulk with Spoonacular Recipe

Retrieves information for multiple recipes from Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/recipes/informationBulk`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Get Recipe Information Bulk](https://spoonacular.com/food-api/docs#Get-Recipe-Information-Bulk)

## Capabilities

This operation supports [filtering](../README.md#filtering).
