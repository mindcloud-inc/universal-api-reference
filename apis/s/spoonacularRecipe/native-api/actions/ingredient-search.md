# Ingredient Search with Spoonacular Recipe

Finds whole-food ingredients in Spoonacular.

## Endpoint

- **Method:** `GET`
- **Path:** `/food/ingredients/search`
- **Base URL:** `https://api.spoonacular.com`
- **Official documentation:** [Ingredient Search](https://spoonacular.com/food-api/docs#Ingredient-Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
