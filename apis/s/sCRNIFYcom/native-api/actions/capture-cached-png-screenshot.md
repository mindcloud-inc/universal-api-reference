# Capture Cached PNG Screenshot with SCRNIFY.com

Captures or reuses a cached PNG screenshot with SCRNIFY.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/capture`
- **Base URL:** `https://api.scrnify.com`
- **Official documentation:** [Capture Cached PNG Screenshot](https://scrnify.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL of the page to capture. |
