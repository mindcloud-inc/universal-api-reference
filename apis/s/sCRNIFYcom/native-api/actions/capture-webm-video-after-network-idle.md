# Capture WEBM Video After Network Idle with SCRNIFY.com

Captures a WEBM video with SCRNIFY.com after network idle.

## Endpoint

- **Method:** `GET`
- **Path:** `/capture`
- **Base URL:** `https://api.scrnify.com`
- **Official documentation:** [Capture WEBM Video After Network Idle](https://scrnify.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL of the page to capture. |
