# SCRNIFY.com: Native API Reference

A consolidated summary of SCRNIFY.com's API configuration and 30 documented operations, with links to official documentation.

- **Official docs:** https://scrnify.com/docs
- **API base URL:** `https://api.scrnify.com`

## Authentication

### API Key

Authenticate with a Scrnify API key.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
Authorization: Bearer <apiKey>
```

[Official authentication documentation](https://scrnify.com/docs)
