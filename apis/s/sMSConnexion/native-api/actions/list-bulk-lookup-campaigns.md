# List Bulk Lookup Campaigns with SMS Connexion

Retrieves bulk lookup campaigns from SMS Connexion.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers/lookup`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [List Bulk Lookup Campaigns](https://sms.cx/sms-api-documentation/#operation/GetBulkLookupCampaigns)
