# Get Campaign Report with SMS Connexion

Retrieves a campaign report from SMS Connexion.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/campaigns/:campaignId`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Get Campaign Report](https://sms.cx/sms-api-documentation/#operation/GetCampaignReport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Campaign UUID from report campaigns endpoints. |
