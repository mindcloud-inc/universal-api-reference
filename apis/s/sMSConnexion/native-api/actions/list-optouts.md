# List Optouts with SMS Connexion

Retrieves opted-out contacts from SMS Connexion.

## Endpoint

- **Method:** `GET`
- **Path:** `/optouts`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [List Optouts](https://sms.cx/sms-api-documentation/#operation/GetOptoutsList)

## Capabilities

This operation supports [pagination](../README.md#pagination).
