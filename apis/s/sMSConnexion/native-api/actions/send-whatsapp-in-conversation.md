# Send WhatsApp In Conversation with SMS Connexion

Sends a WhatsApp reply in SMS Connexion.

## Endpoint

- **Method:** `POST`
- **Path:** `/conversations/:conversationId/whatsapp`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Send WhatsApp In Conversation](https://sms.cx/sms-api-documentation/#operation/SendConversationReplyWhatsapp)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
