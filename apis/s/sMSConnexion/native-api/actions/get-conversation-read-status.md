# Get Conversation Read Status with SMS Connexion

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId/read`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Get Conversation Read Status](https://sms.cx/sms-api-documentation/#operation/MarkConversationAsRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Conversation UUID. |
