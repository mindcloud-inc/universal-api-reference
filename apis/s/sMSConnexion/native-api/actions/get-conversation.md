# Get Conversation with SMS Connexion

Retrieves a conversation from SMS Connexion.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Get Conversation](https://sms.cx/sms-api-documentation/#operation/GetConversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Conversation UUID. |
