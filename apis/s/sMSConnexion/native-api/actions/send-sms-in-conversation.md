# Send SMS In Conversation with SMS Connexion

Sends an SMS reply in SMS Connexion.

## Endpoint

- **Method:** `POST`
- **Path:** `/conversations/:conversationId/sms`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Send SMS In Conversation](https://sms.cx/sms-api-documentation/#operation/SendConversationReplySms)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
