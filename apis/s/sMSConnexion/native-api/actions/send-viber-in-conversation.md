# Send Viber In Conversation with SMS Connexion

Sends a Viber reply in SMS Connexion.

## Endpoint

- **Method:** `POST`
- **Path:** `/conversations/:conversationId/viber`
- **Base URL:** `https://api.sms.cx`
- **Official documentation:** [Send Viber In Conversation](https://sms.cx/sms-api-documentation/#operation/SendConversationReplyViber)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
