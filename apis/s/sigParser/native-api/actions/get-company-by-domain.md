# Get Company By Domain with SigParser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Companies`
- **Base URL:** `https://ipaas.sigparser.com`
- **Official documentation:** [Get Company By Domain](https://ipaas.sigparser.com/v1#get-api-companies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Lookup a specific company by lowercase email domain. |
