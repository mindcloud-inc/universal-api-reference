# List Emails By Contact with SigParser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Emails/Distinct`
- **Base URL:** `https://ipaas.sigparser.com`
- **Official documentation:** [List Emails By Contact](https://ipaas.sigparser.com/v1#get-api-emails-distinct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailaddress` | query | `string` | yes | Contact email address to filter by. |
