# List Companies with SigParser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Companies`
- **Base URL:** `https://ipaas.sigparser.com`
- **Official documentation:** [List Companies](https://ipaas.sigparser.com/v1#get-api-companies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `take` | query | `number` | no | How many company records to return. Minimum 25, maximum 250. |
