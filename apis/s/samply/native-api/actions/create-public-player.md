# Create Public Player with Samply

## Endpoint

- **Method:** `POST`
- **Path:** `/players`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Create Public Player](https://docs.samply.app/api/players.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Display name of the player. |
