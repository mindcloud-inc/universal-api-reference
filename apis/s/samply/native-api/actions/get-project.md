# Get Project with Samply

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectid`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Get Project](https://docs.samply.app/api/projects.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectid` | path | `string` | yes | The Samply project id. |
