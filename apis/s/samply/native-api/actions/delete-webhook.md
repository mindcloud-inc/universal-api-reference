# Delete Webhook with Samply

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookid`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Delete Webhook](https://docs.samply.app/api/webhooks.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookid` | path | `string` | no | The Samply webhook id. |
