# Add Items To Stack with Samply

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:projectid/files/:fileid`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Add Items To Stack](https://docs.samply.app/api/files.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileid` | path | `string` | no | The Samply file, folder, or stack id. |
| `projectid` | path | `string` | no | The Samply project id. |
