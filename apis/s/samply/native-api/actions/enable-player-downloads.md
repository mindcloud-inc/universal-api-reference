# Enable Player Downloads with Samply

## Endpoint

- **Method:** `POST`
- **Path:** `/players/:playerid`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Enable Player Downloads](https://docs.samply.app/api/players.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `playerid` | path | `string` | no | The Samply player id. |
