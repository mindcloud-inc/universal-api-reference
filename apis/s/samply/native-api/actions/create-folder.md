# Create Folder with Samply

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:projectid/folders`
- **Base URL:** `https://samply.app/api/v0`
- **Official documentation:** [Create Folder](https://docs.samply.app/api/files.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectid` | path | `string` | no | The Samply project id. |
