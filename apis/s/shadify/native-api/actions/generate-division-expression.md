# Generate Division Expression with Shadify

Retrieves a random division expression from Shadify.

## Endpoint

- **Method:** `GET`
- **Path:** `/math/div`
- **Base URL:** `https://shadify.yurace.pro/api`
- **Official documentation:** [Generate Division Expression](https://shadify.yurace.pro/modules/math.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `min-first` | query | `number` | no | Optional minimum value for the first number. Default is 1. |
| `max-first` | query | `number` | no | Optional maximum value for the first number. Default is 99. |
