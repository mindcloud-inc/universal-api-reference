# Update Product (GraphQL) with Shopify

Updates an existing product in Shopify.

## Endpoint

- **Method:** `POST`
- **Path:** `2024-07/graphql.json`
- **Base URL:** `https://{storeName}.myshopify.com/admin/api/`
- **API:** REST
- **Official documentation:** [Update Product (GraphQL)](https://shopify.dev/docs/api/admin-graphql/latest/mutations/productSet)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `string` | no |
