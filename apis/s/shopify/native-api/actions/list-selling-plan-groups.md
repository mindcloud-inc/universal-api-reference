# List Selling Plan Groups with Shopify

Retrieves selling plan groups from Shopify.

## Endpoint

- **Method:** `POST`
- **Path:** `2024-10/graphql.json`
- **Base URL:** `https://{storeName}.myshopify.com/admin/api/`
- **API:** REST
- **Official documentation:** [List Selling Plan Groups](https://shopify.dev/docs/api/admin-graphql/latest/queries/sellingPlanGroups)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | no |
