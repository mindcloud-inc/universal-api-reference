# Search Contacts with Salesmate

## Endpoint

- **Method:** `POST`
- **Path:** `/contact/v4/search`
- **Base URL:** `https://apis.salesmate.io`
- **Official documentation:** [Search Contacts](https://apidocs.salesmate.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filterQuery` | body | `object` | no | Salesmate search filter object. |
