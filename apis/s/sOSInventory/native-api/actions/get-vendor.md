# Get Vendor with SOS Inventory

Retrieves a vendor from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/vendor/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Vendor](https://developer.sosinventory.com/apidoc/Vendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The SOS vendor ID to retrieve. |
