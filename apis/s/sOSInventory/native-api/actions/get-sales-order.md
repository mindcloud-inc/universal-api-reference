# Get Sales Order with SOS Inventory

Retrieves a sales order from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/salesorder/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Sales Order](https://developer.sosinventory.com/apidoc/SalesOrder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier for this record. |
