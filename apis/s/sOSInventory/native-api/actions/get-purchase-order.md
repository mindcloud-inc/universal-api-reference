# Get Purchase Order with SOS Inventory

Retrieves a purchase order from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/purchaseorder/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Purchase Order](https://developer.sosinventory.com/apidoc/PurchaseOrder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Purchase order ID. |
