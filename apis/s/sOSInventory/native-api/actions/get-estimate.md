# Get Estimate with SOS Inventory

Retrieves an estimate from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/estimate/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Estimate](https://developer.sosinventory.com/apidoc/Estimate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier for this record. |
