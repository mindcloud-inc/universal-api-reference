# List Locations with SOS Inventory

Retrieves locations from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/location`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [List Locations](https://developer.sosinventory.com/apidoc/Configuration)

## Capabilities

This operation supports [pagination](../README.md#pagination).
