# Get Customer with SOS Inventory

Retrieves a customer from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customer/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Customer](https://developer.sosinventory.com/apidoc/Customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The SOS customer ID to retrieve. |
