# Get Invoice with SOS Inventory

Retrieves an invoice from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/invoice/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Invoice](https://developer.sosinventory.com/apidoc/Invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Invoice ID. |
