# Get Shipment with SOS Inventory

Retrieves a shipment from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/shipment/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Shipment](https://developer.sosinventory.com/apidoc/Shipment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
