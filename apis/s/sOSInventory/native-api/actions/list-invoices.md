# List Invoices with SOS Inventory

Retrieves invoices from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/invoice`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [List Invoices](https://developer.sosinventory.com/apidoc/Invoice)

## Capabilities

This operation supports [pagination](../README.md#pagination).
