# Get Item Receipt with SOS Inventory

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/itemreceipt/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Item Receipt](https://developer.sosinventory.com/apidoc/ItemReceipt)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `list<number>` | yes |
