# Get Transfer with SOS Inventory

Retrieves a transfer from SOS Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/transfer/:id`
- **Base URL:** `https://api.sosinventory.com`
- **Official documentation:** [Get Transfer](https://developer.sosinventory.com/apidoc/Transfer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
