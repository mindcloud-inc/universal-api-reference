# List No-Answer Questions By User with Stackoverflow

Retrieves questions without answers for specific users from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/questions/no-answers`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List No-Answer Questions By User](https://api.stackexchange.com/docs/no-answer-questions-on-users)
