# List Unaccepted Questions By User with Stackoverflow

Retrieves unaccepted questions for specific users from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/questions/unaccepted`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Unaccepted Questions By User](https://api.stackexchange.com/docs/unaccepted-questions-on-users)
