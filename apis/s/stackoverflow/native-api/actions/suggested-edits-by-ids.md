# Get Suggested Edits with Stackoverflow

Retrieves specific suggested edits from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/suggested-edits/[:ids]`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Get Suggested Edits](https://api.stackexchange.com/docs/suggested-edits-by-ids)
