# Undo Answer Upvote with Stackoverflow

Removes an upvote from an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/upvote/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Answer Upvote](https://api.stackexchange.com/docs/undo-upvote-answer)
