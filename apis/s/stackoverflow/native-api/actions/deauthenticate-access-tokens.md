# Deauthenticate Access Tokens with Stackoverflow

Deauthenticates application access tokens in Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/[:accessTokens]/de-authenticate`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Deauthenticate Access Tokens](https://api.stackexchange.com/docs/application-de-authenticate)

## Capabilities

This operation supports [pagination](../README.md#pagination).
