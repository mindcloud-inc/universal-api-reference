# List Top Question Tags By User with Stackoverflow

Retrieves a user's top question tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/top-question-tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Top Question Tags By User](https://api.stackexchange.com/docs/top-question-tags-on-users)
