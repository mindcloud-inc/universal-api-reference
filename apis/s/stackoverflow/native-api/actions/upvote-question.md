# Upvote Question with Stackoverflow

Adds an upvote to a question in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/questions/[:id]/upvote`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Upvote Question](https://api.stackexchange.com/docs/upvote-question)
