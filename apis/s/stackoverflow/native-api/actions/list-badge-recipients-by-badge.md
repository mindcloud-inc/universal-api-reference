# List Badge Recipients By Badge with Stackoverflow

Retrieves badge recipients for specific badges from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/[:ids]/recipients`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Badge Recipients By Badge](https://api.stackexchange.com/docs/badge-recipients-by-ids)

## Capabilities

This operation supports [pagination](../README.md#pagination).
