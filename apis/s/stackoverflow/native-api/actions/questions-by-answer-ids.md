# List Questions By Answer with Stackoverflow

Retrieves questions for specific answers from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/answers/[:ids]/questions`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Questions By Answer](https://api.stackexchange.com/docs/questions-by-answer-ids)
