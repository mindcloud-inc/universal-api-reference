# List Associated Users with Stackoverflow

Retrieves associated user accounts from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/associated`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Associated Users](https://api.stackexchange.com/docs/associated-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
