# Downvote Answer with Stackoverflow

Adds a downvote to an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/downvote`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Downvote Answer](https://api.stackexchange.com/docs/downvote-answer)
