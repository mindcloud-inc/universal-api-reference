# List Collective Users with Stackoverflow

Retrieves users for collectives from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collectives/[:slugs]/users`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Collective Users](https://api.stackexchange.com/docs/users-by-collective)
