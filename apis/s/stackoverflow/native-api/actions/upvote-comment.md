# Upvote Comment with Stackoverflow

Adds an upvote to a comment in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/comments/[:id]/upvote`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Upvote Comment](https://api.stackexchange.com/docs/upvote-comment)
