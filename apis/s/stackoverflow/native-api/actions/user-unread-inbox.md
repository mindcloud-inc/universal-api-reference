# List User Unread Inbox with Stackoverflow

Retrieves a user's unread inbox items from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/inbox/unread`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List User Unread Inbox](https://api.stackexchange.com/docs/user-unread-inbox)
