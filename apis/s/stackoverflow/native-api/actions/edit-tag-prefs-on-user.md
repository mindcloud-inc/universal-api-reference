# Edit Tag Preferences with Stackoverflow

Updates a user's tag preferences in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/[:id]/tag-preferences/edit`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Edit Tag Preferences](https://api.stackexchange.com/docs/edit-tag-prefs-on-user)
