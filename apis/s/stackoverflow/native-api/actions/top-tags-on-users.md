# List Top Tags By User with Stackoverflow

Retrieves a user's top tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/top-tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Top Tags By User](https://api.stackexchange.com/docs/top-tags-on-users)
