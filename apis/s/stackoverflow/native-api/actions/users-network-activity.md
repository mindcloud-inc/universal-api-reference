# List User Network Activity with Stackoverflow

Retrieves a user's network activity from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/network-activity`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List User Network Activity](https://api.stackexchange.com/docs/users-network-activity)
