# List Collective Answers with Stackoverflow

Retrieves answers for collectives from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collectives/[:slugs]/answers`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Collective Answers](https://api.stackexchange.com/docs/answers-by-collective)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
