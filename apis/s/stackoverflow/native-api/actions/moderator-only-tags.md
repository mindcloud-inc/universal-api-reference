# List Moderator-Only Tags with Stackoverflow

Retrieves moderator-only tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/moderator-only`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Moderator-Only Tags](https://api.stackexchange.com/docs/moderator-only-tags)
