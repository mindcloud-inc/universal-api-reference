# Undo Favorite Question with Stackoverflow

Removes a question from favorites in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/question/[:id]/favorite/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Favorite Question](https://api.stackexchange.com/docs/undo-favorite-question)
