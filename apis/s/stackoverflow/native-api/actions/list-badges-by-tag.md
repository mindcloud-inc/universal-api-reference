# List Badges By Tag with Stackoverflow

Retrieves badges by tag from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Badges By Tag](https://api.stackexchange.com/docs/badges-by-tag)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
