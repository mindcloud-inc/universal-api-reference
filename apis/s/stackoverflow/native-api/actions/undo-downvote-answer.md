# Undo Answer Downvote with Stackoverflow

Removes a downvote from an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/downvote/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Answer Downvote](https://api.stackexchange.com/docs/undo-downvote-answer)
