# List Collective Questions with Stackoverflow

Retrieves questions for collectives from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collectives/[:slugs]/questions`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Collective Questions](https://api.stackexchange.com/docs/questions-by-collective)
