# List Top Answer Tags By User with Stackoverflow

Retrieves a user's top answer tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/top-answer-tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Top Answer Tags By User](https://api.stackexchange.com/docs/top-answer-tags-on-users)
