# Undo Comment Upvote with Stackoverflow

Removes an upvote from a comment in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/comments/[:id]/upvote/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Comment Upvote](https://api.stackexchange.com/docs/undo-upvote-comment)
