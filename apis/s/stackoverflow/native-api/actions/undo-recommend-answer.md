# Undo Answer Recommendation with Stackoverflow

Removes an answer recommendation in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/recommend/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Answer Recommendation](https://api.stackexchange.com/docs/undo-recommend-answer)
