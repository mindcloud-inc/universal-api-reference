# List Post Comments with Stackoverflow

Retrieves comments for posts from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/[:ids]/comments`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Post Comments](https://api.stackexchange.com/docs/comments-on-posts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
