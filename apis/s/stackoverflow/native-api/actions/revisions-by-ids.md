# List Revisions By Post with Stackoverflow

Retrieves revisions for specific posts from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/posts/[:ids]/revisions`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Revisions By Post](https://api.stackexchange.com/docs/revisions-by-ids)
