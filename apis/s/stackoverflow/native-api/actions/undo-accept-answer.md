# Undo Answer Acceptance with Stackoverflow

Removes acceptance from an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/accept/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Answer Acceptance](https://api.stackexchange.com/docs/undo-accept-answer)
