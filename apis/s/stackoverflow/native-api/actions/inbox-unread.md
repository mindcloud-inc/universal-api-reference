# List Unread Inbox Items with Stackoverflow

Retrieves unread inbox items from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/unread`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Unread Inbox Items](https://api.stackexchange.com/docs/inbox-unread)
