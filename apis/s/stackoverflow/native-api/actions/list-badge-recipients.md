# List Badge Recipients with Stackoverflow

Retrieves badge recipients from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/recipients`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Badge Recipients](https://api.stackexchange.com/docs/badge-recipients)

## Capabilities

This operation supports [pagination](../README.md#pagination).
