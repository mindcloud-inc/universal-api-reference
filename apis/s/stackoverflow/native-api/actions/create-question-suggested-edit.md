# Create Question Suggested Edit with Stackoverflow

Creates a suggested edit for a question in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/questions/[:id]/suggested-edit/add`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Create Question Suggested Edit](https://api.stackexchange.com/docs/create-question-suggested-edit)
