# Read Access Tokens with Stackoverflow

Retrieves specific access token details from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/access-tokens/[:accessTokens]`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Read Access Tokens](https://api.stackexchange.com/docs/read-access-tokens)
