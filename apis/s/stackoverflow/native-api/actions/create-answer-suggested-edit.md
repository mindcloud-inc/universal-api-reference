# Create Answer Suggested Edit with Stackoverflow

Creates a suggested edit for an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/suggested-edit/add`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Create Answer Suggested Edit](https://api.stackexchange.com/docs/create-answer-suggested-edit)
