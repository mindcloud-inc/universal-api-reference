# Get Site Info with Stackoverflow

Retrieves specific site information from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/info`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Get Site Info](https://api.stackexchange.com/docs/info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site` | query | `string` | yes | API site parameter, for example stackoverflow. |
