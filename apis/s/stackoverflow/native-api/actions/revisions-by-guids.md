# List Revisions By GUID with Stackoverflow

Retrieves revisions by GUID from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/revisions/[:ids]`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Revisions By GUID](https://api.stackexchange.com/docs/revisions-by-guids)
