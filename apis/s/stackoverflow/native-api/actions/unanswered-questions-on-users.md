# List Unanswered Questions By User with Stackoverflow

Retrieves unanswered questions for specific users from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/questions/unanswered`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Unanswered Questions By User](https://api.stackexchange.com/docs/unanswered-questions-on-users)
