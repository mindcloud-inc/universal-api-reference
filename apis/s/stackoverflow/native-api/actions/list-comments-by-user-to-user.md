# List Comments By User To User with Stackoverflow

Retrieves comments from one user to another from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/comments/[:toid]`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Comments By User To User](https://api.stackexchange.com/docs/comments-by-users-to-user)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
