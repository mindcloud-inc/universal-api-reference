# List User Achievements with Stackoverflow

Retrieves a user's achievements from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/achievements`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List User Achievements](https://api.stackexchange.com/docs/achievements-on-user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
