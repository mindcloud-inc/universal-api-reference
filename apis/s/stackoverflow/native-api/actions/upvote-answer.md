# Upvote Answer with Stackoverflow

Adds an upvote to an answer in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/answers/[:id]/upvote`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Upvote Answer](https://api.stackexchange.com/docs/upvote-answer)
