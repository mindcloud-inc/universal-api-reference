# Invalidate Access Tokens with Stackoverflow

Invalidates existing access tokens in Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/access-tokens/[:accessTokens]/invalidate`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Invalidate Access Tokens](https://api.stackexchange.com/docs/invalidate-access-tokens)
