# Downvote Question with Stackoverflow

Adds a downvote to a question in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/questions/[:id]/downvote`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Downvote Question](https://api.stackexchange.com/docs/downvote-question)
