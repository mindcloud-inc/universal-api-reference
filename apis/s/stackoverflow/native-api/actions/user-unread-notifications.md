# List User Unread Notifications with Stackoverflow

Retrieves a user's unread notifications from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/notifications/unread`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List User Unread Notifications](https://api.stackexchange.com/docs/user-unread-notifications)
