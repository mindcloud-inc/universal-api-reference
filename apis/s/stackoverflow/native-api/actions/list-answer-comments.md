# List Answer Comments with Stackoverflow

Retrieves comments for answers from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/answers/[:ids]/comments`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Answer Comments](https://api.stackexchange.com/docs/comments-on-answers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
