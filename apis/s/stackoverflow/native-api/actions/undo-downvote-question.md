# Undo Question Downvote with Stackoverflow

Removes a downvote from a question in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/questions/[:id]/downvote/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Question Downvote](https://api.stackexchange.com/docs/undo-downvote-question)
