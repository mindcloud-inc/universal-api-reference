# List Collective Tags with Stackoverflow

Retrieves tags for collectives from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collectives/[:slugs]/tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Collective Tags](https://api.stackexchange.com/docs/tags-by-collective)
