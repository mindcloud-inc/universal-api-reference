# List Badges By Name with Stackoverflow

Retrieves badges by name from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/badges/name`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Badges By Name](https://api.stackexchange.com/docs/badges-by-name)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
