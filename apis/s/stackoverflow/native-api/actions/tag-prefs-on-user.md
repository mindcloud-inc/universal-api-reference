# List Tag Preferences with Stackoverflow

Retrieves a user's tag preferences from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/tag-preferences`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Tag Preferences](https://api.stackexchange.com/docs/tag-prefs-on-user)
