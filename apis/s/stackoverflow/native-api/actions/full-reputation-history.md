# List Full Reputation History with Stackoverflow

Retrieves a user's full reputation history from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/reputation-history/full`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Full Reputation History](https://api.stackexchange.com/docs/full-reputation-history)
