# List Unanswered Questions In My Tags with Stackoverflow

Retrieves unanswered questions in your tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/questions/unanswered/my-tags`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Unanswered Questions In My Tags](https://api.stackexchange.com/docs/unanswered-questions-my-tags)
