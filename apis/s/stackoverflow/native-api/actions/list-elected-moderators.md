# List Elected Moderators with Stackoverflow

Retrieves elected moderators from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/moderators/elected`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Elected Moderators](https://api.stackexchange.com/docs/elected-moderators)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
