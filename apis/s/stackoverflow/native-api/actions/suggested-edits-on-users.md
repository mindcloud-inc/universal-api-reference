# List Suggested Edits By User with Stackoverflow

Retrieves suggested edits for specific users from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/suggested-edits`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Suggested Edits By User](https://api.stackexchange.com/docs/suggested-edits-on-users)
