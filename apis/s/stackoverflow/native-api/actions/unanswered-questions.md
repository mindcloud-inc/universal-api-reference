# List Unanswered Questions with Stackoverflow

Retrieves unanswered questions from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/questions/unanswered`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Unanswered Questions](https://api.stackexchange.com/docs/unanswered-questions)
