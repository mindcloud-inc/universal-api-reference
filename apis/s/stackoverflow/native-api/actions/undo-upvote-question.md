# Undo Question Upvote with Stackoverflow

Removes an upvote from a question in Stackoverflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/question/[:id]/upvote/undo`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [Undo Question Upvote](https://api.stackexchange.com/docs/undo-upvote-question)
