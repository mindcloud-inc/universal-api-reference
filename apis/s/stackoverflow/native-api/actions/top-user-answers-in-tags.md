# List Top Answers In Tags By User with Stackoverflow

Retrieves a user's top answers in tags from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:id]/tags/[:tags]/top-answers`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Top Answers In Tags By User](https://api.stackexchange.com/docs/top-user-answers-in-tags)
