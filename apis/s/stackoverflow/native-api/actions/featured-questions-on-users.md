# List Featured Questions By User with Stackoverflow

Retrieves featured questions for specific users from Stackoverflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/[:ids]/questions/featured`
- **Base URL:** `https://api.stackexchange.com/2.3`
- **Official documentation:** [List Featured Questions By User](https://api.stackexchange.com/docs/featured-questions-on-users)
