# Get Tracker By Client Tracker ID with Ship24

Retrieves a tracker by client tracker ID from Ship24.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/trackers/:trackerId`
- **Base URL:** `https://api.ship24.com`
- **Official documentation:** [Get Tracker By Client Tracker ID](https://docs.ship24.com/tracking-api-reference/#/operations/get-tracker-by-trackerId)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trackerId` | path | `string` | yes |
