# Get member with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get member](https://api.statushero.com/#get-a-specific-team-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Status Hero member ID or URL slug. |
