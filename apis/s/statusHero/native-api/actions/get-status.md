# Get status with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/statuses/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get status](https://api.statushero.com/#get-a-specific-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Status Hero status/check-in ID or slug. |
