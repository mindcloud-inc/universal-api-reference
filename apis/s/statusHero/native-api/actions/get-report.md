# Get report with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get report](https://api.statushero.com/#get-a-specific-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The report ID or report date in YYYY-MM-DD format. |
