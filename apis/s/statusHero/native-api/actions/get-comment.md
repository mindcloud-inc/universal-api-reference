# Get comment with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get comment](https://api.statushero.com/#comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Status Hero comment ID. |
