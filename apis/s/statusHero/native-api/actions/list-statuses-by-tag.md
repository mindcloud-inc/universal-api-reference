# List statuses by tag with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [List statuses by tag](https://api.statushero.com/#get-statuses-from-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | The tag to use to retrieve statuses, such as sales or devops. |
