# Get reaction with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/reactions/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get reaction](https://api.statushero.com/#reactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Status Hero reaction ID. |
