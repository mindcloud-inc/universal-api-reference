# Get status activity with Status Hero

## Endpoint

- **Method:** `GET`
- **Path:** `/status_activities/:id`
- **Base URL:** `https://service.statushero.com/api/v1`
- **Official documentation:** [Get status activity](https://api.statushero.com/#get-a-specific-status-activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Status Hero status activity ID. |
