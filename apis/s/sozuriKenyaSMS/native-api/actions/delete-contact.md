# Delete Contact with Sozuri (Kenya) SMS

Deletes an existing contact from Sozuri.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactIdOrMobile`
- **Base URL:** `https://sozuri.net/api/v1`
- **Official documentation:** [Delete Contact](https://sozuri.net/docs/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactIdOrMobile` | path | `string` | yes | The contact ID or mobile number to delete. |
