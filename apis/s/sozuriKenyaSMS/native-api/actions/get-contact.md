# Get Contact with Sozuri (Kenya) SMS

Retrieves a contact from Sozuri.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactIdOrMobile`
- **Base URL:** `https://sozuri.net/api/v1`
- **Official documentation:** [Get Contact](https://sozuri.net/docs/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactIdOrMobile` | path | `string` | yes | The contact ID or mobile number to look up. |
