# Archive Order with Starshipit

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/archive`
- **Base URL:** `https://api.starshipit.com/api`
- **Official documentation:** [Archive Order](https://api-docs.starshipit.com/#011a5cbf-56e3-4e89-b572-18e165e1a861)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | body | `number` | yes | The unique numeric identifier for the order |
