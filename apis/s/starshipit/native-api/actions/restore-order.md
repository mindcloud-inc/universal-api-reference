# Restore Order with Starshipit

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/restore`
- **Base URL:** `https://api.starshipit.com/api`
- **Official documentation:** [Restore Order](https://api-docs.starshipit.com/#7894393b-a88e-41b3-af36-88a257d50c67)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | body | `number` | yes | The unique numeric identifier for the order |
