# List Manifest Files with Starshipit

## Endpoint

- **Method:** `GET`
- **Path:** `/manifests/files/`
- **Base URL:** `https://api.starshipit.com/api`
- **Official documentation:** [List Manifest Files](https://api-docs.starshipit.com/#b6ca5673-49e9-4411-9281-4926b592466f)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `manifest_id` | query | `number` | yes | The unique numeric identifier for the manifest |
