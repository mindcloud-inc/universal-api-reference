# List Manifests with Starshipit

## Endpoint

- **Method:** `GET`
- **Path:** `/manifests`
- **Base URL:** `https://api.starshipit.com/api`
- **Official documentation:** [List Manifests](https://api-docs.starshipit.com/#4961ecec-9175-4e55-ac4d-06cb0567c8ab)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page to show. Default: 1 |
| `limit` | query | `number` | no | Maximum number of records in the result. Default: 50. Maximum: 250 |
