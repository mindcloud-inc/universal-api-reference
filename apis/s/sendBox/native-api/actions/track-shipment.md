# Track Shipment with SendBox

## Endpoint

- **Method:** `POST`
- **Path:** `/shipping/tracking`
- **Base URL:** `https://live.sendbox.co`
- **Official documentation:** [Track Shipment](https://docs.sendbox.co/shipping/track-shipment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | body | `string` | yes | The shipment tracking code. |
