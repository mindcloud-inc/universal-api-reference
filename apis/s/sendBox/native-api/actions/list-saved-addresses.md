# List Saved Addresses with SendBox

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/addresses`
- **Base URL:** `https://live.sendbox.co`
- **Official documentation:** [List Saved Addresses](https://docs.sendbox.co/shipping/saved-addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to fetch. |
