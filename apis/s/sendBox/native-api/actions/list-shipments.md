# List Shipments with SendBox

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping/shipments`
- **Base URL:** `https://live.sendbox.co`
- **Official documentation:** [List Shipments](https://docs.sendbox.co/shipping/get-shipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to fetch. |
