# Get Shipment with SendBox

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping/shipments/:id`
- **Base URL:** `https://live.sendbox.co`
- **Official documentation:** [Get Shipment](https://docs.sendbox.co/shipping/get-shipment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The shipment identifier. |
