# List Virtual Accounts with SendBox

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/virtual_accounts`
- **Base URL:** `https://live.sendbox.co`
- **Official documentation:** [List Virtual Accounts](https://docs.sendbox.co/payment/virtual-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to fetch. |
