# Generate Product Description with SharpAPI

Creates a product description job in SharpAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/ecommerce/product_description`
- **Base URL:** `https://sharpapi.com/api/v1`
- **Official documentation:** [Generate Product Description](https://sharpapi.com/en/catalog/ai/e-commerce/product-description-generator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content` | body | `string` | yes | Provide product information to generate a product description. |
