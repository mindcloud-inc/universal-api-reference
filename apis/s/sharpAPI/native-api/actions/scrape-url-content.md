# Scrape URL Content with SharpAPI

Scrapes content from a URL with SharpAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/utilities/scrape_url`
- **Base URL:** `https://sharpapi.com/api/v1`
- **Official documentation:** [Scrape URL Content](https://sharpapi.com/en/catalog/utility/web-scraping-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Public URL to scrape. |
