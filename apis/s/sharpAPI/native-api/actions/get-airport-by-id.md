# Get Airport By Id with SharpAPI

Retrieves an airport from SharpAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/airports/:id`
- **Base URL:** `https://sharpapi.com/api/v1`
- **Official documentation:** [Get Airport By Id](https://sharpapi.com/en/catalog/utility/airports-database-flight-duration-calculator)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Airport identifier. |
