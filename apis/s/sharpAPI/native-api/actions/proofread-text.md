# Proofread Text with SharpAPI

Creates a proofreading job in SharpAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/content/proofread`
- **Base URL:** `https://sharpapi.com/api/v1`
- **Official documentation:** [Proofread Text](https://sharpapi.com/en/catalog/ai/content-marketing-automation/proofread-grammar-checker)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content` | body | `string` | yes | Content to proofread. |
