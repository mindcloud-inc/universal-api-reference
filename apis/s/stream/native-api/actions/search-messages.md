# Search Messages with Stream

Finds messages in Stream by search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://chat.stream-io-api.com`
- **Official documentation:** [Search Messages](https://getstream.io/chat/docs/javascript/search/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | query | `string` | yes | JSON-encoded search payload. |
