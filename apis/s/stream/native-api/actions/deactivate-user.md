# Deactivate User with Stream

Deactivates a user in Stream.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:user_id/deactivate`
- **Base URL:** `https://chat.stream-io-api.com`
- **Official documentation:** [Deactivate User](https://getstream.io/chat/docs/javascript/update_users/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | User ID to deactivate. |
