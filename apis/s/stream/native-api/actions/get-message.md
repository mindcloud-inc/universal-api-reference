# Get Message with Stream

Retrieves a message from Stream.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id`
- **Base URL:** `https://chat.stream-io-api.com`
- **Official documentation:** [Get Message](https://getstream.io/chat/docs/javascript/send_message/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Message ID. |
