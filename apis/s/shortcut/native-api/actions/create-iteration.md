# Create Iteration with Shortcut

## Endpoint

- **Method:** `POST`
- **Path:** `/iterations`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Create Iteration](https://developer.shortcut.com/api/rest/v3#Create-Iteration)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `start_date` | body | `string` | yes |
| `end_date` | body | `string` | yes |
| `description` | body | `string` | no |
