# List Epic Comments with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/epics/:epicPublicId/comments`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Epic Comments](https://developer.shortcut.com/api/rest/v3#List-Epic-Comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `epicPublicId` | path | `number` | yes | The public ID of the epic. |
