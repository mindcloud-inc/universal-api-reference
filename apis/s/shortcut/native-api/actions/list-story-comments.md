# List Story Comments with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/stories/:storyPublicId/comments`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Story Comments](https://developer.shortcut.com/api/rest/v3#List-Story-Comment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyPublicId` | path | `number` | yes | The public ID of the story. |
