# Get Iteration with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/iterations/:iterationPublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Iteration](https://developer.shortcut.com/api/rest/v3#Get-Iteration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `iterationPublicId` | path | `number` | yes | The public ID of the iteration. |
