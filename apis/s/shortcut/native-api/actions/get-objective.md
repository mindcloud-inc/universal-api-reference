# Get Objective with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives/:objectivePublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Objective](https://developer.shortcut.com/api/rest/v3#Get-Objective)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `objectivePublicId` | path | `number` | yes | The public ID of the objective. |
