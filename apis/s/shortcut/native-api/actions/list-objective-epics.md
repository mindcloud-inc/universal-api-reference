# List Objective Epics with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/objectives/:objectivePublicId/epics`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Objective Epics](https://developer.shortcut.com/api/rest/v3#List-Objective-Epics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `objectivePublicId` | path | `number` | yes | The public ID of the objective. |
