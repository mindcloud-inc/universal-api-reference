# Get Workflow with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflowPublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Workflow](https://developer.shortcut.com/api/rest/v3#Get-Workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowPublicId` | path | `number` | yes | The public ID of the workflow. |
