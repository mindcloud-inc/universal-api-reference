# Update Iteration with Shortcut

## Endpoint

- **Method:** `PUT`
- **Path:** `/iterations/:iterationPublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Update Iteration](https://developer.shortcut.com/api/rest/v3#Update-Iteration)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `iterationPublicId` | path | `number` | yes |
| `name` | body | `string` | no |
| `start_date` | body | `string` | no |
| `end_date` | body | `string` | no |
| `description` | body | `string` | no |
