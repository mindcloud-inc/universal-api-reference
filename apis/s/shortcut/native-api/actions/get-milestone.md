# Get Milestone with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/milestones/:milestonePublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Milestone](https://developer.shortcut.com/api/rest/v3#Get-Milestone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `milestonePublicId` | path | `number` | yes | The public ID of the milestone. |
