# Get Project with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectPublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Project](https://developer.shortcut.com/api/rest/v3#Get-Project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectPublicId` | path | `number` | yes | The public ID of the project. |
