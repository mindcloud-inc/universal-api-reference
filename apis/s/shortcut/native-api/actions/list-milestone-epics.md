# List Milestone Epics with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/milestones/:milestonePublicId/epics`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Milestone Epics](https://developer.shortcut.com/api/rest/v3#List-Milestone-Epics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `milestonePublicId` | path | `number` | yes | The public ID of the milestone. |
