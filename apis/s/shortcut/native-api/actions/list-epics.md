# List Epics with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/epics`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Epics](https://developer.shortcut.com/api/rest/v3#List-Epics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includes_description` | query | `boolean` | no | Whether to include epic descriptions in the response. |
