# Get Story with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/stories/:storyPublicId`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [Get Story](https://developer.shortcut.com/api/rest/v3#Get-Story)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyPublicId` | path | `number` | yes | The public ID of the story. |
