# List Members with Shortcut

## Endpoint

- **Method:** `GET`
- **Path:** `/members`
- **Base URL:** `https://api.app.shortcut.com/api/v3`
- **Official documentation:** [List Members](https://developer.shortcut.com/api/rest/v3#List-Members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org-public-id` | query | `string` | no | Limit members to a specific organization. |
| `disabled` | query | `boolean` | no | Whether to include disabled members. |
