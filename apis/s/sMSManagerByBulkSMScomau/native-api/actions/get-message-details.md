# Get Message Details with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id/details`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [Get Message Details](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Message ID. |
