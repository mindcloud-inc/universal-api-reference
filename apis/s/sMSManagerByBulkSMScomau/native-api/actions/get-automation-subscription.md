# Get Automation Subscription with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/subscriptions/:id`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [Get Automation Subscription](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Automation subscription ID. |
