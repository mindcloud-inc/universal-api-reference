# Get Blocked Number with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/blocked_numbers/:blocked_number_id`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [Get Blocked Number](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blocked_number_id` | path | `string` | yes | Blocked number ID. |
