# List Group Contacts with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id/contacts`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [List Group Contacts](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID whose contacts should be listed. |
