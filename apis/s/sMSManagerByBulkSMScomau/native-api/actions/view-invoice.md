# View Invoice with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/invoice/:invoice_id`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [View Invoice](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes | Invoice ID. |
