# Get Chat Message History with SMS Manager by BulkSMS.com.au

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/history`
- **Base URL:** `https://smsmanager.com.au/v2/api`
- **Official documentation:** [Get Chat Message History](https://smsmanager.com.au/v2/api_docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact` | query | `string` | yes | Contact number to load chat history for. |
