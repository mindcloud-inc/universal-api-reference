# Get User with SmartReach

Retrieves a user from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get User](https://help.smartreach.io/reference/getuserbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | ID of user to return |
