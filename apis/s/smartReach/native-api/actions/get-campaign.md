# Get Campaign with SmartReach

Retrieves a campaign from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaign_id`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Campaign](https://help.smartreach.io/reference/getcampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of campaign to return |
