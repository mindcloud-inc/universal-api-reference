# Get Email Setting with SmartReach

Retrieves an email setting from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_settings/:email_setting_id`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Email Setting](https://help.smartreach.io/reference/get_email-settings-email-setting-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email_setting_id` | path | `string` | yes |
