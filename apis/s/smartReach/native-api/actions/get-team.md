# Get Team with SmartReach

Retrieves a team from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Team](https://help.smartreach.io/reference/getteambyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | yes | Team ID |
