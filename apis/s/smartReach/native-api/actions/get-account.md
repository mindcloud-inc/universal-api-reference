# Get Account with SmartReach

Retrieves an account from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Account](https://help.smartreach.io/reference/get_accounts-account-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | yes |
