# Get Campaign Stats with SmartReach

Retrieves campaign stats from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaign_id/stats`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Campaign Stats](https://help.smartreach.io/reference/getcampaignstats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of campaign |
