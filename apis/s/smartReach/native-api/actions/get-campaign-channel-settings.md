# Get Campaign Channel Settings with SmartReach

Retrieves campaign channel settings from SmartReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaign_id/channel_settings`
- **Base URL:** `https://api.smartreach.io/api/v3`
- **Official documentation:** [Get Campaign Channel Settings](https://help.smartreach.io/reference/channelsettings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of campaign |
