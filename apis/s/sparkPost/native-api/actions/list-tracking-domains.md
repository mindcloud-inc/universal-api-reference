# List Tracking Domains with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/tracking-domains`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [List Tracking Domains](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-get-list-all-tracking-domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `default` | query | `boolean` | no | Filter to default tracking domains. |
| `subaccounts` | query | `boolean` | no | Include tracking domains for subaccounts. |
