# Retrieve Account with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/account`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Retrieve Account](https://developers.sparkpost.com/api/account/#account-get-retrieve-account-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Optional include value. Set to `usage` to include account usage data. |
