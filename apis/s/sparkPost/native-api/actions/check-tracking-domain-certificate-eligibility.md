# Check Tracking Domain Certificate Eligibility with SparkPost

## Endpoint

- **Method:** `POST`
- **Path:** `/tracking-domains/:domain/certificate/check`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Check Tracking Domain Certificate Eligibility](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-post-check-certificate-eligibility)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Tracking domain to check for managed certificate eligibility. |
