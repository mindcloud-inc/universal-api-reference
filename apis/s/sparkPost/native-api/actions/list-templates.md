# List Templates with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [List Templates](https://developers.sparkpost.com/api/templates/#templates-get-list-all-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `draft` | query | `boolean` | no | Whether to list draft versions instead of published templates. |
