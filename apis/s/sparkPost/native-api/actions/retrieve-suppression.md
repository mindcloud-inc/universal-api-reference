# Retrieve Suppression with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/suppression-list/:recipient`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Retrieve Suppression](https://developers.sparkpost.com/api/suppression-list/#suppression-list-get-retrieve-a-suppression)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipient` | path | `string` | yes | Suppressed recipient email address. |
