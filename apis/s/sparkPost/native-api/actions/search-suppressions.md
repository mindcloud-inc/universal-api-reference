# Search Suppressions with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/suppression-list`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Search Suppressions](https://developers.sparkpost.com/api/suppression-list/#suppression-list-get-search-suppressions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Suppression search page number. |
| `per_page` | query | `number` | no | Maximum suppressions to return per page. |
