# Create Tracking Domain with SparkPost

## Endpoint

- **Method:** `POST`
- **Path:** `/tracking-domains`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Create Tracking Domain](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-post-create-a-tracking-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Tracking domain to create. |
