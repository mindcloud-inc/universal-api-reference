# Verify Tracking Domain with SparkPost

## Endpoint

- **Method:** `POST`
- **Path:** `/tracking-domains/:domain/verify`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Verify Tracking Domain](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-post-verify-a-tracking-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Tracking domain to verify. |
