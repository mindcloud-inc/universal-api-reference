# Retrieve Sending Domain with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/sending-domains/:domain`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Retrieve Sending Domain](https://developers.sparkpost.com/api/sending-domains/#sending-domains-get-retrieve-a-sending-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Sending domain to retrieve. |
