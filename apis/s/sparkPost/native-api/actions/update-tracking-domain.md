# Update Tracking Domain with SparkPost

## Endpoint

- **Method:** `PUT`
- **Path:** `/tracking-domains/:domain`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Update Tracking Domain](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-put-update-a-tracking-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Tracking domain to update. |
