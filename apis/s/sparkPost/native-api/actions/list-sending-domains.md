# List Sending Domains with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/sending-domains`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [List Sending Domains](https://developers.sparkpost.com/api/sending-domains/#sending-domains-get-list-all-sending-domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ownership_verified` | query | `boolean` | no | Filter by verified ownership status. |
