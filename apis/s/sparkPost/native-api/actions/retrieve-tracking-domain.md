# Retrieve Tracking Domain with SparkPost

## Endpoint

- **Method:** `GET`
- **Path:** `/tracking-domains/:domain`
- **Base URL:** `https://api.sparkpost.com/api/v1`
- **Official documentation:** [Retrieve Tracking Domain](https://developers.sparkpost.com/api/tracking-domains/#tracking-domains-get-retrieve-a-tracking-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Tracking domain to retrieve. |
