# Get Post Reactions with Swarm

Retrieves reactions for a post from Swarm.

## Endpoint

- **Method:** `GET`
- **Path:** `/social/post/:postUrn/reactions`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Get Post Reactions](https://docs.theswarm.com/docs/on-demand/get-reactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postUrn` | path | `string` | no | LinkedIn post URN used in the route path. |
