# Search Companies with Swarm

Finds companies in Swarm using an OpenSearch query.

## Endpoint

- **Method:** `POST`
- **Path:** `/companies/search`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Search Companies](https://docs.theswarm.com/docs/endpoints/search-companies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
