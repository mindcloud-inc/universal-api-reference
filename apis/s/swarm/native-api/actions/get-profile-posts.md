# Get Profile Posts with Swarm

Retrieves profile posts from Swarm by LinkedIn ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/social/profile/posts`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Get Profile Posts](https://docs.theswarm.com/docs/on-demand/get-posts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedinID` | query | `string` | no | LinkedIn profile slug to retrieve posts for. |
