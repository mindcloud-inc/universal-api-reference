# Find Warm Paths by LinkedIn URL with Swarm

Finds warm paths in Swarm by LinkedIn URL.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/profiles/network-mapper`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Find Warm Paths by LinkedIn URL](https://docs.theswarm.com/docs/endpoints/network-mapper)
