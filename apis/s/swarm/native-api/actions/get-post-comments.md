# Get Post Comments with Swarm

Retrieves comments for a post from Swarm.

## Endpoint

- **Method:** `GET`
- **Path:** `/social/post/:postUrn/comments`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Get Post Comments](https://docs.theswarm.com/docs/on-demand/get-comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postUrn` | path | `string` | no | LinkedIn post URN used in the route path. |
