# Find Warm Paths by Company Website with Swarm

Finds warm paths in Swarm by company website.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/profiles/network-mapper`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Find Warm Paths by Company Website](https://docs.theswarm.com/docs/endpoints/network-mapper)
