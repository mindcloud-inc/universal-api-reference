# Search Profiles with Swarm

Finds profiles in Swarm using an OpenSearch query.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/profiles/search`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Search Profiles](https://docs.theswarm.com/docs/endpoints/search-profiles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
