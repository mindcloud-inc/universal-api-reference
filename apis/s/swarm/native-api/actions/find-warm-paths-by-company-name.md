# Find Warm Paths by Company Name with Swarm

Finds warm paths in Swarm by company name.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/profiles/network-mapper`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Find Warm Paths by Company Name](https://docs.theswarm.com/docs/endpoints/network-mapper)
