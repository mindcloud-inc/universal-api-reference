# Get Post Reshares with Swarm

Retrieves reshares for a post from Swarm.

## Endpoint

- **Method:** `GET`
- **Path:** `/social/post/:postUrn/reshares`
- **Base URL:** `https://bee.theswarm.com`
- **Official documentation:** [Get Post Reshares](https://docs.theswarm.com/docs/on-demand/get-reshares)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postUrn` | path | `string` | no | LinkedIn post URN used in the route path. |
