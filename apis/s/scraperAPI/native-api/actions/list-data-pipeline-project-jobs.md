# List DataPipeline Project Jobs with ScraperAPI

Retrieves DataPipeline project jobs from ScraperAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datapipeline.scraperapi.com/api/projects/:id/jobs`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [List DataPipeline Project Jobs](https://docs.scraperapi.com/data-pipeline/datapipeline-endpoints/endpoints-and-parameters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The DataPipeline project ID. |
