# Scrape Page with ScraperAPI

Retrieves a scraped page from ScraperAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.scraperapi.com`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [Scrape Page](https://docs.scraperapi.com/synchronous-apis/using-the-api-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The absolute URL of the page you want ScraperAPI to fetch. |
