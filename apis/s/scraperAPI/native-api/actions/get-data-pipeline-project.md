# Get DataPipeline Project with ScraperAPI

Retrieves a DataPipeline project from ScraperAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datapipeline.scraperapi.com/api/projects/:id`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [Get DataPipeline Project](https://docs.scraperapi.com/data-pipeline/datapipeline-endpoints/endpoints-and-parameters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The DataPipeline project ID. |
