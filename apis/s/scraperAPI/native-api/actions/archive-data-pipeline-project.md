# Archive DataPipeline Project with ScraperAPI

Archives an existing DataPipeline project in ScraperAPI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://datapipeline.scraperapi.com/api/projects/:id`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [Archive DataPipeline Project](https://docs.scraperapi.com/data-pipeline/datapipeline-endpoints/endpoints-and-parameters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The DataPipeline project ID. |
