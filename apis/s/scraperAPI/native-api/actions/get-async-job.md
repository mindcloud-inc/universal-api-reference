# Get Async Job with ScraperAPI

Retrieves an async scraping job from ScraperAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://async.scraperapi.com/jobs/:jobId`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [Get Async Job](https://docs.scraperapi.com/asynchronous-api/job-handling)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The async job ID. |
