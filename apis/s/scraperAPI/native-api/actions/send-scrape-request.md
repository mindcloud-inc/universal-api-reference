# Send Scrape Request with ScraperAPI

Retrieves a scraped response from ScraperAPI with a POST request.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.scraperapi.com`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [Send Scrape Request](https://docs.scraperapi.com/synchronous-apis/making-post-put-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The target URL to scrape. |
