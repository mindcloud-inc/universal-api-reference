# List DataPipeline Projects with ScraperAPI

Retrieves DataPipeline projects from ScraperAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://datapipeline.scraperapi.com/api/projects`
- **Base URL:** `https://api.scraperapi.com`
- **Official documentation:** [List DataPipeline Projects](https://docs.scraperapi.com/data-pipeline/datapipeline-endpoints/endpoints-and-parameters)
