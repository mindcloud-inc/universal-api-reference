# List Webhooks with Sign Customiser

Retrieves all webhook subscriptions from Sign Customiser.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/webhooks`
- **Base URL:** `https://web.signcustomiser.com`
- **Official documentation:** [List Webhooks](https://www.signcustomiser.com/help/api/get-list-all-webhooks/)
