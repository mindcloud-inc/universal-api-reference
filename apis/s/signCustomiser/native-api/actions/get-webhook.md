# Get Webhook with Sign Customiser

Retrieves a webhook subscription from Sign Customiser.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/webhooks/:webhookId`
- **Base URL:** `https://web.signcustomiser.com`
- **Official documentation:** [Get Webhook](https://www.signcustomiser.com/help/api/get-get-a-single-webhook/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `number` | yes | The ID of the webhook. |
