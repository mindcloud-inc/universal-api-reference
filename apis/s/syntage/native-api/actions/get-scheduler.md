# Get Scheduler with Syntage

Retrieves a scheduler from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedulers/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Scheduler](https://docs.syntage.com/api-reference/schedulers/retrieve-a-scheduler.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The scheduler identifier. |
