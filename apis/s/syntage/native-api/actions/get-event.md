# Get Event with Syntage

Retrieves an event from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Event](https://docs.syntage.com/api-reference/events/retrieve-an-event.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event identifier. |
