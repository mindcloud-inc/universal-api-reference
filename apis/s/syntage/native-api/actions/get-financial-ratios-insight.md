# Get Financial Ratios Insight with Syntage

Retrieves financial ratios insight for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/insights/financial-ratios`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Financial Ratios Insight](https://docs.syntage.com/api-reference/financial-ratios-insight/get-financial-ratios.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
