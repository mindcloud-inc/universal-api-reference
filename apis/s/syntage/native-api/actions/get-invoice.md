# Get Invoice with Syntage

Retrieves an invoice from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Invoice](https://docs.syntage.com/api-reference/ds-mx-sat-invoices/retrieve-an-invoice.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The invoice identifier. |
