# Get Expenditures Insight with Syntage

Retrieves expenditures insight for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/insights/expenditures`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Expenditures Insight](https://docs.syntage.com/api-reference/expenditures-insight/get-expenditures.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
