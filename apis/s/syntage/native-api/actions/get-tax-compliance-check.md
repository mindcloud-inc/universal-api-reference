# Get Tax Compliance Check with Syntage

Retrieves a tax compliance check from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/tax-compliance-checks/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Tax Compliance Check](https://docs.syntage.com/api-reference/ds-mx-sat-tax-compliance-checks/retrieve-a-tax-compliance-check.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tax compliance check identifier. |
