# Get Accounts Payable Insight with Syntage

Retrieves accounts payable insight for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/insights/accounts-payable`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Accounts Payable Insight](https://docs.syntage.com/api-reference/accounts-payable-insight/get-accounts-payable.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | The Syntage entity identifier. |
