# List Entity Invoice Line Items with Syntage

Retrieves invoice line items for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/invoices/line-items`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [List Entity Invoice Line Items](https://docs.syntage.com/api-reference/ds-mx-sat-invoice-line-items/list-all-entity-line-items.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
