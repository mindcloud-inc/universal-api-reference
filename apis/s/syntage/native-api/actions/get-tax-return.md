# Get Tax Return with Syntage

Retrieves a tax return from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/tax-returns/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Tax Return](https://docs.syntage.com/api-reference/ds-mx-sat-tax-returns/retrieve-a-tax-return.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tax return identifier. |
