# List Webhook Endpoints with Syntage

Retrieves webhook endpoints from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-endpoints`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [List Webhook Endpoints](https://docs.syntage.com/api-reference/webhook-endpoints/list-all-webhook-endpoints.md)
