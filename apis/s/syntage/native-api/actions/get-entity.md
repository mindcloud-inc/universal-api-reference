# Get Entity with Syntage

Retrieves an entity from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Entity](https://docs.syntage.com/api-reference/entities/retrieve-an-entity.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | The Syntage entity identifier. |
