# Get Extraction with Syntage

Retrieves an extraction from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/extractions/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Extraction](https://docs.syntage.com/api-reference/extractions/retrieve-an-extraction.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The extraction identifier. |
