# List Webhook Requests with Syntage

Retrieves webhook requests from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-requests`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [List Webhook Requests](https://docs.syntage.com/api-reference/webhook-requests/list-all-webhook-requests.md)
