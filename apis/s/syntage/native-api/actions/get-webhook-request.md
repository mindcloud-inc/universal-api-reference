# Get Webhook Request with Syntage

Retrieves a webhook request from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-requests/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Webhook Request](https://docs.syntage.com/api-reference/webhook-requests/retrieve-a-webhook-request.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook request identifier. |
