# Get Employees Insight with Syntage

Retrieves employee insight for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/insights/employees`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Employees Insight](https://docs.syntage.com/api-reference/employees-insight/get-employees.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
