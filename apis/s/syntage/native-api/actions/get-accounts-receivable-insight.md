# Get Accounts Receivable Insight with Syntage

Retrieves accounts receivable insight for an entity in Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entityId/insights/accounts-receivable`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Accounts Receivable Insight](https://docs.syntage.com/api-reference/accounts-receivable-insight/get-accounts-receivable.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityId` | path | `string` | yes |
