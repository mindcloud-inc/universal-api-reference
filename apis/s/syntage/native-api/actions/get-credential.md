# Get Credential with Syntage

Retrieves a credential from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Credential](https://docs.syntage.com/api-reference/ds-mx-sat-credentials/retrieve-a-credential.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The credential identifier. |
