# Get Invoice Payment with Syntage

Retrieves an invoice payment from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/payments/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Invoice Payment](https://docs.syntage.com/api-reference/ds-mx-sat-invoice-payments/retrieve-an-invoice-payment.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The invoice payment identifier. |
