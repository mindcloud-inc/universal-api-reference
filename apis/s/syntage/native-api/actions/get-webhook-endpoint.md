# Get Webhook Endpoint with Syntage

Retrieves a webhook endpoint from Syntage.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-endpoints/:id`
- **Base URL:** `https://api.sandbox.syntage.com`
- **Official documentation:** [Get Webhook Endpoint](https://docs.syntage.com/api-reference/webhook-endpoints/retrieve-a-webhook-endpoint.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook endpoint identifier. |
