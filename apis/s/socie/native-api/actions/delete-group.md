# Delete Group with Socie

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/groups/:identifier`
- **Base URL:** `https://api.socie.nl`
- **Official documentation:** [Delete Group](https://resources.socie.nl/docs/api/resource_Groups.html#resource_Groups_deleteGroup_context_identifier_key_DELETE)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Socie id or externalId of the group. |
