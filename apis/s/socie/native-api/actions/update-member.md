# Update Member with Socie

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/members/:identifier`
- **Base URL:** `https://api.socie.nl`
- **Official documentation:** [Update Member](https://resources.socie.nl/docs/api/resource_Members.html#resource_Members_updateMember_context_identifier_memberInput_key_PATCH)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Socie id or externalId of the member. |
