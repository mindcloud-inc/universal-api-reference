# Get Member with Socie

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/members/:identifier`
- **Base URL:** `https://api.socie.nl`
- **Official documentation:** [Get Member](https://resources.socie.nl/docs/api/resource_Members.html#resource_Members_getMember_context_identifier_key_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Socie id or externalId of the member. |
