# Update Additional Field with Socie

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/additional_fields/:identifier`
- **Base URL:** `https://api.socie.nl`
- **Official documentation:** [Update Additional Field](https://resources.socie.nl/docs/api/resource_Additional_Fields.html#resource_Additional_Fields_updateAdditionalField_context_identifier_additionalFieldInput_PATCH)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Socie id of the additional field. |
