# Update Group with Socie

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/groups/:identifier`
- **Base URL:** `https://api.socie.nl`
- **Official documentation:** [Update Group](https://resources.socie.nl/docs/api/resource_Groups.html#resource_Groups_updateGroup_context_identifier_groupInput_key_PATCH)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The Socie id or externalId of the group. |
