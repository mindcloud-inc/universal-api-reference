# Get Transaction with SPS Commerce

Retrieve a specific file.

## Endpoint

- **Method:** `GET`
- **Path:** `transactions/v5/data/:filePath`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [Get Transaction](https://developercenter.spscommerce.com/#/docs/transaction-api/v5-getting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filePath` | path | `string` | yes | Full absolute path to the file (case sensitive). |
