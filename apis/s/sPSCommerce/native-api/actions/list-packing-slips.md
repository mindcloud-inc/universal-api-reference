# List Packing Slips with SPS Commerce

## Endpoint

- **Method:** `GET`
- **Path:** `packing-slip/v1/`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [List Packing Slips](https://developercenter.spscommerce.com/#/docs/shipping-doc-api/packing_slips/get_all_packing_slip)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `newest` | query | `boolean` | no |
| `name` | query | `string` | no |
| `limit` | query | `string` | no |
| `offset` | query | `string` | no |
