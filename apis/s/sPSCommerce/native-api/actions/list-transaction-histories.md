# List Transaction Histories with SPS Commerce

## Endpoint

- **Method:** `GET`
- **Path:** `transactions/v5/history/`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [List Transaction Histories](https://developercenter.spscommerce.com/#/docs/transaction-api/v5-reporting)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `string` | no |
| `offset` | query | `string` | no |
| `after` | query | `string` | no |
| `until` | query | `string` | no |
