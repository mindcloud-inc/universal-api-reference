# List Packing Slip with SPS Commerce

## Endpoint

- **Method:** `GET`
- **Path:** `packing-slip/v1/:slipID`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [List Packing Slip](https://developercenter.spscommerce.com/#/docs/shipping-doc-api/packing_slips/get_all_packing_slip)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slipID` | path | `string` | yes |
