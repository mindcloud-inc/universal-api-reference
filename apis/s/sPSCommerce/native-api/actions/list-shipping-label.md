# List Shipping Label by ID with SPS Commerce

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.spscommerce.com/label/v1/:labelID`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [List Shipping Label by ID](https://developercenter.spscommerce.com/#/docs/shipping-doc-api/labels/get_labels_by_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `labelID` | path | `string` | yes |
