# List Forms with SPS Commerce

## Endpoint

- **Method:** `GET`
- **Path:** `v1/forms`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [List Forms](https://developercenter.spscommerce.com/#/docs/shipping-doc-api/packing_slips/get_all_packing_slip)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `canRender` | query | `boolean` | no |
| `name` | query | `string` | no |
| `newest` | query | `boolean` | no |
| `ownerID` | query | `string` | no |
| `ownerName` | query | `string` | no |
