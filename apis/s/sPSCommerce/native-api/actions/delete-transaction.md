# Delete Transaction with SPS Commerce

Delete a specific transaction file.

## Endpoint

- **Method:** `DELETE`
- **Path:** `transactions/v5/data/:filePath`
- **Base URL:** `https://api.spscommerce.com/`
- **Official documentation:** [Delete Transaction](https://developercenter.spscommerce.com/#/docs/transaction-api/v5-deletion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filePath` | path | `string` | no | Full absolute path to the file (case sensitive) |
