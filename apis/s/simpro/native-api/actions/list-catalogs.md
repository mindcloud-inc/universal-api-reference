# List Catalogs with Simpro

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId/catalogs/`
- **Base URL:** `{buildUrl}/api/v1.0`
- **Official documentation:** [List Catalogs](https://developer.simprogroup.com/apidoc/?page=5408c752aea14ba352fc3dad16b268d8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The Simpro company ID. |
