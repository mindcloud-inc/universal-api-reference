# List Invoices with Simpro

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId/invoices/`
- **Base URL:** `{buildUrl}/api/v1.0`
- **Official documentation:** [List Invoices](https://developer.simprogroup.com/apidoc/?page=fce9a6a1bd2a2050eb86d33103f46fd3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The Simpro company ID. |
