# Get Contact with Simpro

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId/contacts/:contactId`
- **Base URL:** `https://mindcloud.simprosuite.com/api/v1.0`
- **Official documentation:** [Get Contact](https://developer.simprogroup.com/apidoc/?page=9aa698f602b1e5694855cee73a683488)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Simpro company ID. Single-company builds usually use 0. |
| `contactId` | path | `number` | yes | Contact ID. |
