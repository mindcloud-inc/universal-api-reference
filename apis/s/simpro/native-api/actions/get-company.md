# Get Company with Simpro

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId`
- **Base URL:** `{buildUrl}/api/v1.0`
- **Official documentation:** [Get Company](https://developer.simprogroup.com/apidoc/?page=edefbda3a2bdd979e42d8944b7325b79)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | The Simpro company ID. |
