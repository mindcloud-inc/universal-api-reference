# List Work Orders / Job Cards with Simpro

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId/jobs/:jobId/jobcards/`
- **Base URL:** `https://mindcloud.simprosuite.com/api/v1.0`
- **Official documentation:** [List Work Orders / Job Cards](https://developer.simprogroup.com/apidoc/?page=401740175cb9b4b5190e6d44cc5478bd)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The Simpro company ID. |
| `jobId` | path | `string` | yes | The Simpro job ID. |
