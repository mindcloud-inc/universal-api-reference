# Get Sitemap Status with ScrapeGraphAI

Retrieves sitemap request status from ScrapeGraphAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/sitemap/:request_id`
- **Base URL:** `https://api.scrapegraphai.com/v1`
- **Official documentation:** [Get Sitemap Status](https://docs.scrapegraphai.com/api-reference/endpoint/sitemap/get-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | Sitemap request ID to retrieve. |
