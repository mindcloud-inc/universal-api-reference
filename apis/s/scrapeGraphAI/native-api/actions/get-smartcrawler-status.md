# Get SmartCrawler Status with ScrapeGraphAI

Retrieves SmartCrawler task status from ScrapeGraphAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/crawl/:task_id`
- **Base URL:** `https://api.scrapegraphai.com/v1`
- **Official documentation:** [Get SmartCrawler Status](https://docs.scrapegraphai.com/api-reference/endpoint/smartcrawler/get-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | SmartCrawler task ID to retrieve. |
