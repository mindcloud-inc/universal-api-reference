# Get SearchScraper Status with ScrapeGraphAI

Retrieves SearchScraper request status from ScrapeGraphAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchscraper/:request_id`
- **Base URL:** `https://api.scrapegraphai.com/v1`
- **Official documentation:** [Get SearchScraper Status](https://docs.scrapegraphai.com/api-reference/endpoint/searchscraper/get-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | SearchScraper request ID to retrieve. |
