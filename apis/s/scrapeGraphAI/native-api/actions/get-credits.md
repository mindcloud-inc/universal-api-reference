# Get Credits with ScrapeGraphAI

Retrieves current credit balance from ScrapeGraphAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/credits`
- **Base URL:** `https://api.scrapegraphai.com/v1`
- **Official documentation:** [Get Credits](https://docs.scrapegraphai.com/api-reference/endpoint/user/get-credits)
