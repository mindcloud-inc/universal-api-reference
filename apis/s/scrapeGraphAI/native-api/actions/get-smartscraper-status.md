# Get SmartScraper Status with ScrapeGraphAI

Retrieves SmartScraper request status from ScrapeGraphAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/smartscraper/:request_id`
- **Base URL:** `https://api.scrapegraphai.com/v1`
- **Official documentation:** [Get SmartScraper Status](https://docs.scrapegraphai.com/api-reference/endpoint/smartscraper/get-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | SmartScraper request ID to retrieve. |
