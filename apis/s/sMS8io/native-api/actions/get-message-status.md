# Get Message Status with SMS8.io

## Endpoint

- **Method:** `GET`
- **Path:** `get-msgs.php`
- **Base URL:** `https://app.sms8.io/services`
- **Official documentation:** [Get Message Status](https://sms8.io/sms8-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Filter messages by delivery status such as Received, Pending, Sent, Failed, Queued, Delivered, or Scheduled. |
