# Get DLR Status with SMS8.io

## Endpoint

- **Method:** `GET`
- **Path:** `dlr/`
- **Base URL:** `https://app.sms8.io/services`
- **Official documentation:** [Get DLR Status](https://sms8.io/sms8-api-documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `smsid` | query | `string` | yes | SMS ID returned by the send endpoint. |
