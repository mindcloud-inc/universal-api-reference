# Get Testimonial with Senja

Retrieves a testimonial from Senja by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/testimonials/:id`
- **Base URL:** `https://api.senja.io/v1`
- **Official documentation:** [Get Testimonial](https://support.senja.io/articles/rest-api-wbnz4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Senja testimonial ID to retrieve. |
