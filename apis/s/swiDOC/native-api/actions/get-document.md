# Get Document with swiDOC

Retrieves a document from swiDOC by document ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://app.swidoc.ch/api/v1`
- **Official documentation:** [Get Document](https://api.docs.swidoc.ch/swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Unique ID of the document to fetch. |
