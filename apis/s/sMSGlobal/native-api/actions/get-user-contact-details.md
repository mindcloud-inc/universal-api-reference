# Get User Contact Details with SMSGlobal

Retrieves contact details for the authenticated SMSGlobal account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/contact-details`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [Get User Contact Details](https://www.smsglobal.com/rest-api/)
