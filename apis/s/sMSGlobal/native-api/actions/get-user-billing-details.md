# Get User Billing Details with SMSGlobal

Retrieves billing details for the authenticated SMSGlobal account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/billing-details`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [Get User Billing Details](https://www.smsglobal.com/rest-api/)
