# List Pending Verified Numbers with SMSGlobal

Retrieves pending verified numbers from the SMSGlobal account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/verified-numbers/pending`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [List Pending Verified Numbers](https://www.smsglobal.com/rest-api/)
