# Get Group with SMSGlobal

Retrieves a contact group from SMSGlobal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/group/:id`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [Get Group](https://www.smsglobal.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact group identifier. |
