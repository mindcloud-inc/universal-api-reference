# List Verified Numbers with SMSGlobal

Retrieves verified numbers from the SMSGlobal account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/verified-numbers`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [List Verified Numbers](https://www.smsglobal.com/rest-api/)
