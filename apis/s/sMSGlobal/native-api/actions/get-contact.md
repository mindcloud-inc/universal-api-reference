# Get Contact with SMSGlobal

Retrieves a contact from SMSGlobal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contact/:id`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [Get Contact](https://www.smsglobal.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contact identifier. |
