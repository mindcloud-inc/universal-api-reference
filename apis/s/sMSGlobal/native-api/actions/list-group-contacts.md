# List Group Contacts with SMSGlobal

Retrieves contacts from an SMSGlobal contact group.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/group/:groupId/contacts`
- **Base URL:** `https://api.smsglobal.com`
- **Official documentation:** [List Group Contacts](https://www.smsglobal.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | The contact group identifier. |
