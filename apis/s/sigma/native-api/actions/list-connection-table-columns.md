# List Connection Table Columns with Sigma

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/connections/tables/{tableId}/columns`
- **Base URL:** `https://aws-api.sigmacomputing.com`
- **Official documentation:** [List Connection Table Columns](https://help.sigmacomputing.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | path | `string` | yes | Sigma tableId. |
