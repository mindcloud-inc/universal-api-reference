# List Connection Grants with Sigma

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/connections/{connectionId}/grants`
- **Base URL:** `https://aws-api.sigmacomputing.com`
- **Official documentation:** [List Connection Grants](https://help.sigmacomputing.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Sigma connectionId. |
