# Get List with Smoove

Retrieves a contact list from Smoove.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/Lists/:id`
- **Base URL:** `https://rest.smoove.io`
- **Official documentation:** [Get List](https://rest.smoove.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `fields` | query | `string` | no |
