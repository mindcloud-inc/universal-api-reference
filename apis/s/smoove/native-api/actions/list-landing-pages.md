# List Landing Pages with Smoove

Retrieves landing pages from Smoove.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/LandingPages`
- **Base URL:** `https://rest.smoove.io`
- **Official documentation:** [List Landing Pages](https://rest.smoove.io)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `list` | no | Accepted values: `ALL`, `Embed`, `Facebook`, `LandingPage`, `Mobile`, `Popup`. |
