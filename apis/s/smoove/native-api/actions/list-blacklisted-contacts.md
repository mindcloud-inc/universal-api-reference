# List Blacklisted Contacts with Smoove

Retrieves blacklisted contacts from Smoove.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/Contacts_Blacklisted`
- **Base URL:** `https://rest.smoove.io`
- **Official documentation:** [List Blacklisted Contacts](https://rest.smoove.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields` | query | `string` | no |
