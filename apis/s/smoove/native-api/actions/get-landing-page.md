# Get Landing Page with Smoove

Retrieves a landing page from Smoove.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/LandingPages/:id`
- **Base URL:** `https://rest.smoove.io`
- **Official documentation:** [Get Landing Page](https://rest.smoove.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
