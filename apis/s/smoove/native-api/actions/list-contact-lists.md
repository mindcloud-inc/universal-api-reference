# List Contact Lists with Smoove

Retrieves contact lists from Smoove.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/Lists`
- **Base URL:** `https://rest.smoove.io`
- **Official documentation:** [List Contact Lists](https://rest.smoove.io)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields` | query | `string` | no |
| `includeContactsCount` | query | `boolean` | no |
