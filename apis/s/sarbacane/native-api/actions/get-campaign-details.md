# Get Campaign Details with Sarbacane

Retrieves campaign details from your Sarbacane account.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Get Campaign Details](https://developers.sarbacane.com/campaigns/#get-campaign-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | Sarbacane campaign ID. |
