# List Teams for List with Sarbacane

Retrieves groups for a list in Sarbacane.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/{listId}/teams`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [List Teams for List](https://developers.sarbacane.com/contacts/#list-groups-related-to-a-list)
