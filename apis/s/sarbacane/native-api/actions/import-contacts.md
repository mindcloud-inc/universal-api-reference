# Import Contacts with Sarbacane

Imports contacts into a Sarbacane list.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/{listId}/contacts/import`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Import Contacts](https://developers.sarbacane.com/contacts/#add-a-block-of-contacts-json)
