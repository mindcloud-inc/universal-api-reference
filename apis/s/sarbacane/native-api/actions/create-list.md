# Create List with Sarbacane

Creates a new list in Sarbacane.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Create List](https://developers.sarbacane.com/contacts/#add-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Display name for the contact list. |
