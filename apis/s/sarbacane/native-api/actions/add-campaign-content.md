# Add Campaign Content with Sarbacane

Imports template content into a campaign in Sarbacane.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/{campaignId}/content`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Add Campaign Content](https://developers.sarbacane.com/campaigns/#import-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | Sarbacane campaign ID. |
