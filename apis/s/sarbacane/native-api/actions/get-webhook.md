# Get Webhook with Sarbacane

Retrieves a webhook from your Sarbacane account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhookId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Get Webhook](https://developers.sarbacane.com/contacts/#get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | no | Sarbacane webhook ID. |
