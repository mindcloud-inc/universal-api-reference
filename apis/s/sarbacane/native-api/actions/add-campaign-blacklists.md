# Add Campaign Blacklists with Sarbacane

Adds blacklist entries to a campaign in Sarbacane.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/{campaignId}/blacklists`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Add Campaign Blacklists](https://developers.sarbacane.com/campaigns/#add-campaigns-blacklist)
