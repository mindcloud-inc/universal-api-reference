# Get Campaign Statistics with Sarbacane

Retrieves campaign statistics from your Sarbacane account.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/{campaignId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Get Campaign Statistics](https://developers.sarbacane.com/campaigns/#get-campaign-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | Sarbacane campaign ID. |
