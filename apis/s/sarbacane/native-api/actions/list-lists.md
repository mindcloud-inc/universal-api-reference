# List Lists with Sarbacane

Retrieves lists from your Sarbacane account.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [List Lists](https://developers.sarbacane.com/contacts/#get-all-lists)

## Capabilities

This operation supports [pagination](../README.md#pagination).
