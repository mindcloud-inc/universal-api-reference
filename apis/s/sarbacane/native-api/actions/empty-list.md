# Empty List with Sarbacane

Empties an existing list in Sarbacane.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/{listId}/empty`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Empty List](https://developers.sarbacane.com/contacts/#empty-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | no | Sarbacane list ID. |
