# Delete Campaign with Sarbacane

Deletes an existing campaign from Sarbacane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/{campaignId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Delete Campaign](https://developers.sarbacane.com/campaigns/#delete-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | Sarbacane campaign ID. |
