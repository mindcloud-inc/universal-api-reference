# Import Campaign Recipients with Sarbacane

Imports recipients into a campaign in Sarbacane.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/{campaignId}/recipients`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Import Campaign Recipients](https://developers.sarbacane.com/campaigns/#import-recipients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | Sarbacane campaign ID. |
