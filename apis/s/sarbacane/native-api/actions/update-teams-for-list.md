# Update Teams for List with Sarbacane

Updates groups for a list in Sarbacane.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lists/{listId}/teams`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Update Teams for List](https://developers.sarbacane.com/contacts/#edit-groups-related-to-a-list)
