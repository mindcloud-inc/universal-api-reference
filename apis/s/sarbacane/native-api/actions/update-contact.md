# Update Contact with Sarbacane

Updates an existing contact in Sarbacane.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lists/{listId}/contacts/{contactId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Update Contact](https://developers.sarbacane.com/contacts/#edit-a-contact)
