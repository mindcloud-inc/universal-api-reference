# Delete List with Sarbacane

Deletes an existing list from Sarbacane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/{listId}`
- **Base URL:** `https://api.sarbacane.com/v1`
- **Official documentation:** [Delete List](https://developers.sarbacane.com/contacts/#delete-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | no | Sarbacane list ID. |
