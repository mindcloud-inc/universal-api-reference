# Get Portal Configuration with SWELLEnterprise

Retrieves portal configuration from SWELLEnterprise.

## Endpoint

- **Method:** `GET`
- **Path:** `/client-portal/config`
- **Base URL:** `https://dashboard.swellsystem.com/api/v1`
- **Official documentation:** [Get Portal Configuration](https://dashboard.swellsystem.com/docs#client-portal-GETapi-v1-client-portal-config)
