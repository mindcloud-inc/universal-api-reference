# List Prospect Tags with Saleshandy

## Endpoint

- **Method:** `GET`
- **Path:** `/prospects/tags`
- **Base URL:** `https://open-api.saleshandy.com/v1`
- **Official documentation:** [List Prospect Tags](https://developer.saleshandy.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Optional prospect tag search string. |
