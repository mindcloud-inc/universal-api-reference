# List DNC Lists with Saleshandy

## Endpoint

- **Method:** `GET`
- **Path:** `/dnc`
- **Base URL:** `https://open-api.saleshandy.com/v1`
- **Official documentation:** [List DNC Lists](https://developer.saleshandy.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Optional DNC list search string. |
