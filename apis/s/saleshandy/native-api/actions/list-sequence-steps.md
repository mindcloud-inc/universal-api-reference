# List Sequence Steps with Saleshandy

## Endpoint

- **Method:** `GET`
- **Path:** `/sequences/[:sequenceId]/steps`
- **Base URL:** `https://open-api.saleshandy.com/v1`
- **Official documentation:** [List Sequence Steps](https://developer.saleshandy.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sequenceId` | path | `string` | yes | Sequence ID to fetch steps for. |
