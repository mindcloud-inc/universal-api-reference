# List Fields with Saleshandy

## Endpoint

- **Method:** `GET`
- **Path:** `/fields`
- **Base URL:** `https://open-api.saleshandy.com/v1`
- **Official documentation:** [List Fields](https://developer.saleshandy.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `systemFields` | query | `boolean` | yes | Whether to return Saleshandy system fields. |
