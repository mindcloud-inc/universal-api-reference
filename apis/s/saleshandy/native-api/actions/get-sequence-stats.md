# Get Sequence Stats with Saleshandy

## Endpoint

- **Method:** `POST`
- **Path:** `/analytics/stats`
- **Base URL:** `https://open-api.saleshandy.com/v1`
- **Official documentation:** [Get Sequence Stats](https://developer.saleshandy.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sequenceId` | body | `string` | yes | Sequence ID to fetch analytics for. |
