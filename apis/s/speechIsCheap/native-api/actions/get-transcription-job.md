# Get Transcription Job with Speech is Cheap

Retrieves a transcription job from Speech is Cheap.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://api.speechischeap.com/v2`
- **Official documentation:** [Get Transcription Job](https://docs.speechischeap.com/jobs-v2/read/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | Speech is Cheap transcription job ID. |
