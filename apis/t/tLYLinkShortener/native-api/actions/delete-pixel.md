# Delete Pixel with TLY Link Shortener

Deletes an existing pixel from TLY Link Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/link/pixel/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Delete Pixel](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pixel ID to delete. |
