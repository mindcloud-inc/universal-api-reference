# Get Pixel with TLY Link Shortener

Retrieves a pixel from TLY Link Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/link/pixel/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Get Pixel](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pixel ID to retrieve. |
