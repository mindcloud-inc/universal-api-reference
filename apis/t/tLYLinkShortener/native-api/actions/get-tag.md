# Get Tag with TLY Link Shortener

Retrieves a tag from TLY Link Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/link/tag/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Get Tag](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The tag ID to retrieve. |
