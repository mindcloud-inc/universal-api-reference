# Delete UTM Preset with TLY Link Shortener

Deletes an existing UTM preset from TLY Link Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/link/utm-preset/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Delete UTM Preset](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The preset ID to delete. |
