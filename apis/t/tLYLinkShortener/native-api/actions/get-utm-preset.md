# Get UTM Preset with TLY Link Shortener

Retrieves a UTM preset from TLY Link Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/link/utm-preset/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Get UTM Preset](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The preset ID to retrieve. |
