# Create Tag with TLY Link Shortener

Creates a new tag in TLY Link Shortener.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/link/tag`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Create Tag](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | body | `string` | yes | The tag name to create. |
