# Delete Tag with TLY Link Shortener

Deletes an existing tag from TLY Link Shortener.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/link/tag/:id`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Delete Tag](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The tag ID to delete. |
