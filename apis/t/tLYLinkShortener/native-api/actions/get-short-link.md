# Get Short Link with TLY Link Shortener

Retrieves a short link from TLY Link Shortener.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/link`
- **Base URL:** `https://api.t.ly`
- **Official documentation:** [Get Short Link](https://t.ly/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `short_url` | query | `string` | yes | The short URL to retrieve. |
