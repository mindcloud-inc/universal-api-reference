# Get Asset Info with ThingsBoard

Retrieves asset info from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/asset/info/:assetId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Asset Info](https://thingsboard.cloud/swagger-ui/index.html#/asset-controller/getAssetInfoById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `string` | yes | The ThingsBoard asset ID. |
