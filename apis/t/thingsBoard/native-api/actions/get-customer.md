# Get Customer with ThingsBoard

Retrieves a customer from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:customerId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Customer](https://thingsboard.cloud/swagger-ui/index.html#/customer-controller/getCustomerById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | The ThingsBoard customer ID. |
