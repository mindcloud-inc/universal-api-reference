# Get Asset with ThingsBoard

Retrieves an asset from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/asset/:assetId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Asset](https://thingsboard.cloud/swagger-ui/index.html#/asset-controller/getAssetById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `string` | yes | The ThingsBoard asset ID. |
