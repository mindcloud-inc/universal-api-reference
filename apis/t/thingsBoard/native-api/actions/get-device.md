# Get Device with ThingsBoard

Retrieves a device from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/:deviceId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Device](https://thingsboard.cloud/swagger-ui/index.html#/device-controller/getDeviceById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deviceId` | path | `string` | yes | The ThingsBoard device ID. |
