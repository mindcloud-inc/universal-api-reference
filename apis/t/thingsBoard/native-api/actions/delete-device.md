# Delete Device with ThingsBoard

Deletes a device from ThingsBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/device/:deviceId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Delete Device](https://thingsboard.cloud/swagger-ui/index.html#/device-controller/deleteDevice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deviceId` | path | `string` | yes | The ThingsBoard device ID to delete. |
