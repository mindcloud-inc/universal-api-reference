# Get Alarm with ThingsBoard

Retrieves an alarm from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/alarm/:alarmId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Alarm](https://thingsboard.cloud/swagger-ui/index.html#/alarm-controller/getAlarmById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alarmId` | path | `string` | yes | The ThingsBoard alarm ID. |
