# Get Customer Info with ThingsBoard

Retrieves customer info from ThingsBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/info/:customerId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Get Customer Info](https://thingsboard.cloud/swagger-ui/index.html#/customer-controller/getCustomerInfoById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | The ThingsBoard customer ID. |
