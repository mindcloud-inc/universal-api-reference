# Delete Asset with ThingsBoard

Deletes an asset from ThingsBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/asset/:assetId`
- **Base URL:** `{baseUrl}/api`
- **Official documentation:** [Delete Asset](https://thingsboard.cloud/swagger-ui/index.html#/asset-controller/deleteAsset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `string` | yes | The ThingsBoard asset ID to delete. |
