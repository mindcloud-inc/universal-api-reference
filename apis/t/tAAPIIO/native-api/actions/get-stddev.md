# Get Standard Deviation with TAAPI.IO

Retrieves Standard Deviation indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/stddev`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Standard Deviation](https://taapi.io/indicators/standard-deviation/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
