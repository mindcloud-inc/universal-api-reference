# Get Ultimate Oscillator with TAAPI.IO

Retrieves Ultimate Oscillator indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/ultosc`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Ultimate Oscillator](https://taapi.io/indicators/ultimate-oscillator/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
