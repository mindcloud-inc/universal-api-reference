# Get Directional Movement Index with TAAPI.IO

Retrieves Directional Movement Index indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/dmi`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Directional Movement Index](https://taapi.io/indicators/directional-movement-index/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
