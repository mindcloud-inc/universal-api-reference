# Get Average True Range with TAAPI.IO

Retrieves Average True Range indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/atr`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Average True Range](https://taapi.io/indicators/average-true-range/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
