# Get Stochastic with TAAPI.IO

Retrieves Stochastic indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/stoch`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Stochastic](https://taapi.io/indicators/stochastic/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
