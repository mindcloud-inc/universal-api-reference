# Get Momentum with TAAPI.IO

Retrieves Momentum indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/mom`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Momentum](https://taapi.io/indicators/momentum/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
