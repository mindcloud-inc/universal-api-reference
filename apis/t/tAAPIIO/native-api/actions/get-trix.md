# Get TRIX with TAAPI.IO

Retrieves TRIX indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/trix`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get TRIX](https://taapi.io/indicators/trix/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
