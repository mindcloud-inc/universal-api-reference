# Get Supertrend with TAAPI.IO

Retrieves Supertrend indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/supertrend`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Supertrend](https://taapi.io/indicators/supertrend/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
