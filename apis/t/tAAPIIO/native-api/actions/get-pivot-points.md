# Get Pivot Points with TAAPI.IO

Retrieves Pivot Points indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/pivotpoints`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Pivot Points](https://taapi.io/indicators/pivot-points/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
