# Get Ichimoku Cloud with TAAPI.IO

Retrieves Ichimoku Cloud indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/ichimoku`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Ichimoku Cloud](https://taapi.io/indicators/ichimoku-cloud/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
