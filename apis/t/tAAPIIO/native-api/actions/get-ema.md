# Get Exponential Moving Average with TAAPI.IO

Retrieves Exponential Moving Average indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/ema`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Exponential Moving Average](https://taapi.io/indicators/exponential-moving-average/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
