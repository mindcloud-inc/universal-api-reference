# Get Parabolic SAR with TAAPI.IO

Retrieves Parabolic SAR indicator data from TAAPI.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/psar`
- **Base URL:** `https://api.taapi.io`
- **Official documentation:** [Get Parabolic SAR](https://taapi.io/indicators/parabolic-sar/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exchange` | query | `string` | yes |
| `symbol` | query | `string` | yes |
| `interval` | query | `string` | yes |
