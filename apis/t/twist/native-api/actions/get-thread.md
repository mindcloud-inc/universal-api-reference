# Get Thread with Twist

Retrieves a thread from Twist by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/getone`
- **Base URL:** `https://api.twist.com/api/v3`
- **Official documentation:** [Get Thread](https://developer.twist.com/v3/#get-thread)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The id of the thread. |
