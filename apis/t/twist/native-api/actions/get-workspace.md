# Get Workspace with Twist

Retrieves a workspace from Twist by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/getone`
- **Base URL:** `https://api.twist.com/api/v3`
- **Official documentation:** [Get Workspace](https://developer.twist.com/v3/#get-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The id of the workspace. |
