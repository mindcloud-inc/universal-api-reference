# List Unread Threads with Twist

Retrieves unread threads from a Twist workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/get_unread`
- **Base URL:** `https://api.twist.com/api/v3`
- **Official documentation:** [List Unread Threads](https://developer.twist.com/v3/#get-unread-threads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | query | `number` | yes | The id of the workspace. |
