# Get Channel with Twist

Retrieves a channel from Twist by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/getone`
- **Base URL:** `https://api.twist.com/api/v3`
- **Official documentation:** [Get Channel](https://developer.twist.com/v3/#get-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The id of the channel. |
