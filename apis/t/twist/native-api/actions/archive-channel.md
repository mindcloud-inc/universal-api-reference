# Archive Channel with Twist

Archives an existing channel in Twist.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/archive`
- **Base URL:** `https://api.twist.com/api/v3`
- **Official documentation:** [Archive Channel](https://developer.twist.com/v3/#archive-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The id of the channel. |
