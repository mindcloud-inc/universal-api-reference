# List Workspaces with Toggl Track

Retrieves workspaces from Toggl Track.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v9/workspaces`
- **Base URL:** `https://api.track.toggl.com`
- **Official documentation:** [List Workspaces](https://engineering.toggl.com/docs/track/api/workspaces/#get-workspaces)
