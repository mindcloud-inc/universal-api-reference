# Get Current User with Toggl Track

Retrieves the current user from Toggl Track.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v9/me`
- **Base URL:** `https://api.track.toggl.com`
- **Official documentation:** [Get Current User](https://engineering.toggl.com/docs/track/api/me/#get-me)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `with_related_data` | query | `boolean` | no |
