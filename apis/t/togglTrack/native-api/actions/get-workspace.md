# Get Workspace with Toggl Track

Retrieves a workspace from Toggl Track.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v9/workspaces/:workspace_id`
- **Base URL:** `https://api.track.toggl.com`
- **Official documentation:** [Get Workspace](https://engineering.toggl.com/docs/track/api/workspaces/#get-get-single-workspace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace_id` | path | `list<number>` | yes |
