# Get Current Time Entry with Toggl Track

Retrieves the current time entry from Toggl Track.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v9/me/time_entries/current`
- **Base URL:** `https://api.track.toggl.com`
- **Official documentation:** [Get Current Time Entry](https://engineering.toggl.com/docs/track/api/time_entries/#get-get-current-time-entry)
