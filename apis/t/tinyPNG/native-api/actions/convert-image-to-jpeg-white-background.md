# Convert Image To JPEG White Background with TinyPNG

Creates a JPEG image with a white background in TinyPNG.

## Endpoint

- **Method:** `POST`
- **Path:** `{{outputPath}}`
- **Base URL:** `https://api.tinify.com`
- **Official documentation:** [Convert Image To JPEG White Background](https://tinify.com/developers/reference/http#converting-images)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `outputPath` | path | `string` | yes | TinyPNG output path returned by a previous action, for example `/output/abc123`. |
