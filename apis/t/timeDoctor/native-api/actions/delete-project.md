# Delete Project with Time Doctor

Deletes an existing project from Time Doctor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/1.0/projects/:projectId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Delete Project](https://api2.timedoctor.com/#operation/deleteProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | ID of the project to delete. |
