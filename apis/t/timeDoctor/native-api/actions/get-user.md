# Get User with Time Doctor

Retrieves a user from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/users/:userId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get User](https://api2.timedoctor.com/#operation/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | ID of the user to retrieve. |
