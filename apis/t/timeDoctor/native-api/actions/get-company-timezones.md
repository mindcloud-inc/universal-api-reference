# Get Company Timezones with Time Doctor

Retrieves company timezones from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/companies/:companyId/timezones`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Company Timezones](https://api2.timedoctor.com/#operation/getCompanyTimezones)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Company or workspace ID. |
