# Create Project with Time Doctor

Creates a new project in Time Doctor.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.0/projects`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Create Project](https://api2.timedoctor.com/#operation/createProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Project name. |
| `description` | body | `string` | no | Project description. |
