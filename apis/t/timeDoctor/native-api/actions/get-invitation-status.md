# Get Invitation Status with Time Doctor

Retrieves invitation status from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/invitations/exists`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Invitation Status](https://api2.timedoctor.com/#operation/getInvitations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
