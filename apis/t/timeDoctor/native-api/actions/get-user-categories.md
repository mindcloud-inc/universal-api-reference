# List User Categories with Time Doctor

Retrieves user categories from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/categories/user/:userId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [List User Categories](https://api2.timedoctor.com/#operation/getUserCategories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
