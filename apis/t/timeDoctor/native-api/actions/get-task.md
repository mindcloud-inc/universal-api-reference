# Get Task with Time Doctor

Retrieves a task from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/tasks/:taskId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Task](https://api2.timedoctor.com/#operation/task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | ID of the task to retrieve. |
