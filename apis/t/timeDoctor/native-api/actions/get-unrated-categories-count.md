# Get Unrated Categories Count with Time Doctor

Retrieves unrated category counts from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/categories/unrated-count`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Unrated Categories Count](https://api2.timedoctor.com/#operation/getCategoriesUnratedCount)
