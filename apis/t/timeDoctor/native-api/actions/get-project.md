# Get Project with Time Doctor

Retrieves a project from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/projects/:projectId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Project](https://api2.timedoctor.com/#operation/project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | ID of the project to retrieve. |
