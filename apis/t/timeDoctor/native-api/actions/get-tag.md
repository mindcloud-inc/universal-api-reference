# Get Tag with Time Doctor

Retrieves a tag from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/tags/:tagId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Tag](https://api2.timedoctor.com/#operation/getTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Unique identifier of the user group (tag). |
