# Get Company with Time Doctor

Retrieves a company from Time Doctor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/1.0/companies/:companyId`
- **Base URL:** `https://api2.timedoctor.com`
- **Official documentation:** [Get Company](https://api2.timedoctor.com/#operation/getCompany)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Company or workspace ID. |
