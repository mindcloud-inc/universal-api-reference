# V2 Show current Tracking with Timeular

Retrieves the current tracking session from the Timeular v2 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tracking`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Show current Tracking](https://developers.early.app/#e3edf286-f246-43a4-ae35-9738170ea5c4)
