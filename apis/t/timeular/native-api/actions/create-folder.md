# Create Folder with Timeular

Creates a new folder in your Timeular workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/folders`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Create Folder](https://developers.early.app/#b80bf1bb-2a8f-4124-91d7-d4a9ed024080)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
