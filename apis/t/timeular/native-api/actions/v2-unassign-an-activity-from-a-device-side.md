# V2 Unassign an Activity from a Device Side with Timeular

Removes an activity from a device side in the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/activities/:activityId/device-side/:deviceSideId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Unassign an Activity from a Device Side](https://developers.early.app/#1a98f995-a61d-4851-a5d9-1c32367e97d2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
| `deviceSideId` | path | `string` | yes |
