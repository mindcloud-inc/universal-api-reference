# List Folder Members with Timeular

Retrieves members for a folder in your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/folders/:folderId/members`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List Folder Members](https://developers.early.app/#2d4b52d1-df46-48c6-9e02-4475fb613793)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
