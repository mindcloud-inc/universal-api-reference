# Unarchive Activity with Timeular

Unarchives an existing activity in your Timeular workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/activities/:activityId/unarchive`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Unarchive Activity](https://developers.early.app/#6f5b8cb5-dc7a-4258-a855-3d160203a893)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
