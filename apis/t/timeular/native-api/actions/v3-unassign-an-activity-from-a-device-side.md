# V3 Unassign an Activity from a Device Side with Timeular

Removes an activity from a device side in the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/activities/:activityId/device-side/:deviceSideId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Unassign an Activity from a Device Side](https://developers.early.app/#583e3518-e1df-4a9f-8af7-83efbdd6e79b)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
| `deviceSideId` | path | `string` | yes |
