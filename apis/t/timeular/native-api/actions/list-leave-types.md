# List Leave Types with Timeular

Retrieves leave types from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/leaves/types`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List Leave Types](https://developers.early.app/#d0bdc2e8-7e8d-47cb-ba40-da3fdf4ff8e5)
