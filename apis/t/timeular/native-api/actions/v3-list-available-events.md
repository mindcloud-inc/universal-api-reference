# V3 List available events with Timeular

Retrieves available webhook events from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/webhooks/event`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 List available events](https://developers.early.app/#8a39dd40-8282-4d1e-9315-1945c3117321)
