# V3 Activate Device with Timeular

Activates a device in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/devices/:deviceId/activate`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Activate Device](https://developers.early.app/#2d3946a1-d112-443b-8058-0b27f3fde396)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
