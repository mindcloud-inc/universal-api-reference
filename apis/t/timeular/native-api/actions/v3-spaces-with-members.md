# V3 Spaces with Members with Timeular

Retrieves spaces with members from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/space`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Spaces with Members](https://developers.early.app/#a5bba235-9229-48cb-a5f9-ee557a0bacf9)
