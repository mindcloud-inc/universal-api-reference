# V3 Fetch Tags & Mentions with Timeular

Retrieves tags and mentions from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/tags-and-mentions`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Fetch Tags & Mentions](https://developers.early.app/#03a2a812-cb0a-45e6-8fc6-74a0ff439909)
