# V2 Sets the status of a Device to active with Timeular

Sets a device as active in the Timeular v2 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/devices/:deviceId/active`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Sets the status of a Device to active](https://developers.early.app/#460bd3cf-8172-4902-aba8-7425263a82c7)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
