# V3 Enable Device with Timeular

Enables a device in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/devices/:deviceId/enable`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Enable Device](https://developers.early.app/#96f1eb5b-5aa6-43eb-9176-fd8b7bd5b16f)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
