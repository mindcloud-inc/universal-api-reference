# V3 Delete a Time Entry with Timeular

Deletes a time entry from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Delete a Time Entry](https://developers.early.app/#a987147c-7c11-4fdc-9ca5-7b03e0999199)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
