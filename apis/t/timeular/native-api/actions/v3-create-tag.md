# V3 Create Tag with Timeular

Creates a new tag in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/tags`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Create Tag](https://developers.early.app/#d62392ca-2eb2-40c9-8d14-834ba581122e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | body | `string` | yes |
| `label` | body | `string` | yes |
| `scope` | body | `string` | yes |
| `spaceId` | body | `string` | no |
