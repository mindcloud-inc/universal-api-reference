# V3 All Data as JSON with Timeular

Retrieves report data as JSON from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/report/data/:start/:end`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 All Data as JSON](https://developers.early.app/#e12c5e47-8f39-4984-b757-798dcbbf2365)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `end` | path | `string` | yes |
| `start` | path | `string` | yes |
