# Archive Folder with Timeular

Archives an existing folder in your Timeular workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/folders/:folderId/archive`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Archive Folder](https://developers.early.app/#2c15cd2d-baca-4e36-936b-377c03ad3081)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
