# V3 Stop Tracking with Timeular

Creates a time entry by stopping tracking in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/tracking/stop`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Stop Tracking](https://developers.early.app/#329c8b25-a27f-41f9-bdd6-8db04627f0ea)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stoppedAt` | body | `string` | no |
