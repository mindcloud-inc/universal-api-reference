# V3 Archive an Activity with Timeular

Deletes an activity from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/activities/:activityId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Archive an Activity](https://developers.early.app/#234c5874-2086-4104-bff7-af9b9efeced8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
