# V3 Find Time Entry by its ID with Timeular

Retrieves a time entry by ID from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Find Time Entry by its ID](https://developers.early.app/#b4c0569e-a8a7-4c11-9b82-d091bf656812)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
