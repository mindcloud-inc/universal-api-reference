# V3 Delete Tag with Timeular

Deletes a tag from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/tags/:tagId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Delete Tag](https://developers.early.app/#c930c6f5-e825-413e-b430-434a05e96e6c)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `string` | yes |
