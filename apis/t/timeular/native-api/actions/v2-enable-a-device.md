# V2 Enable a Device with Timeular

Enables a device in the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/devices/:deviceId/disabled`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Enable a Device](https://developers.early.app/#b40aee81-2f6f-4443-ad55-e1623ae58e15)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
