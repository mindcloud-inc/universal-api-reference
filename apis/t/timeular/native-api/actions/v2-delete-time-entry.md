# V2 Delete Time Entry with Timeular

Deletes a time entry from the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Delete Time Entry](https://developers.early.app/#0719d2e0-e33a-4162-aef7-4b7590201fc5)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
