# V3 Deactivate Device with Timeular

Deactivates a device in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/devices/:deviceId/deactivate`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Deactivate Device](https://developers.early.app/#59928e50-d695-4118-8d71-13079f4ae9d9)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
