# V2 Create an Activity with Timeular

Creates a new activity in the Timeular v2 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/activities`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Create an Activity](https://developers.early.app/#c7afd73f-58ea-4d8f-92b8-ac447aec3ff0)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `color` | body | `string` | no |
| `integration` | body | `string` | no |
| `name` | body | `string` | yes |
