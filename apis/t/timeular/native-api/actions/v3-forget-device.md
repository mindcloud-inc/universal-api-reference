# V3 Forget Device with Timeular

Deletes a device from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/devices/:deviceId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Forget Device](https://developers.early.app/#08024987-8f56-41d4-8653-97cbf1202809)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
