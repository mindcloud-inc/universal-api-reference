# V2 Edit a Device with Timeular

Updates an existing device in the Timeular v2 API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/devices/:deviceId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Edit a Device](https://developers.early.app/#fde0a1f4-eedc-418f-b95d-41cd4e3144ee)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
| `name` | body | `string` | no |
