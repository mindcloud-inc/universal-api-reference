# Get Folder with Timeular

Retrieves a folder from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/folders/:folderId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Folder](https://developers.early.app/#29cb8ee4-ff3b-46d1-aa87-7bb3abe2c0f3)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
