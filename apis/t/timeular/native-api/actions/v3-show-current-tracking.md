# V3 Show current Tracking with Timeular

Retrieves the current tracking session from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/tracking`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Show current Tracking](https://developers.early.app/#13f48c99-bf92-4892-9f5d-ae17f603526a)
