# Get Current User with Timeular

Retrieves the current user from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/me`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Current User](https://developers.early.app/#1e7dfdde-e619-4a82-b9c8-88c5e39c0e95)
