# List available Webhook Events with Timeular

Retrieves available webhook events from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/webhooks/event`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List available Webhook Events](https://developers.early.app/#cc25a42c-45fb-4ba0-a259-0927f00b8b3d)
