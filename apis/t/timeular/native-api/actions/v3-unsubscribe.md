# V3 Unsubscribe with Timeular

Deletes a webhook subscription from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/webhooks/subscription/:subscriptionId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Unsubscribe](https://developers.early.app/#49f4cefd-7e39-437d-b411-469335b6cb15)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes |
