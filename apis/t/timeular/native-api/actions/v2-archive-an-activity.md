# V2 Archive an Activity with Timeular

Deletes an activity from the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/activities/:activityId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Archive an Activity](https://developers.early.app/#22bbcab0-0448-443f-ba64-b640120649cb)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
