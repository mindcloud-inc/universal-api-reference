# V3 Create an Activity with Timeular

Creates a new activity in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/activities`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Create an Activity](https://developers.early.app/#591f7ca0-7ec5-4c0e-b0d0-99b6967ce53e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `color` | body | `string` | no |
| `integration` | body | `string` | no |
| `name` | body | `string` | yes |
| `spaceId` | body | `string` | no |
