# V3 Assign an Activity to Device Side with Timeular

Assigns an activity to a device side in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/activities/:activityId/device-side/:deviceSideId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Assign an Activity to Device Side](https://developers.early.app/#8307c8c6-d1d0-476b-abcf-cf76c3d319c0)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
| `deviceSideId` | path | `string` | yes |
