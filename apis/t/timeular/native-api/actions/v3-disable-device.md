# V3 Disable Device with Timeular

Disables a device in the Timeular v3 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/devices/:deviceId/disable`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Disable Device](https://developers.early.app/#985dae45-b3db-4993-a4b1-5847044388bd)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
