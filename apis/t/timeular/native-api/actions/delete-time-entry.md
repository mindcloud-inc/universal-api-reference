# Delete Time Entry with Timeular

Deletes a time entry from your Timeular workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Time Entry](https://developers.early.app/#ad0986b6-aae6-4b25-acc2-333b6822b6e6)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
