# V2 Disable a Device with Timeular

Disables a device in the Timeular v2 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/devices/:deviceId/disabled`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Disable a Device](https://developers.early.app/#49f9620b-026c-432b-9c27-ae7360141ffe)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
