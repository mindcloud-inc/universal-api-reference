# Delete Webhook Subscriptions for User with Timeular

Deletes current-user webhook subscriptions from your Timeular workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/webhooks/subscription`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Webhook Subscriptions for User](https://developers.early.app/#04443b18-b9e7-468e-8723-192747b28521)
