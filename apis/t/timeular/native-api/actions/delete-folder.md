# Delete Folder with Timeular

Deletes a folder from your Timeular workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/folders/:folderId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Folder](https://developers.early.app/#bc2aaae1-35e9-42ee-be7f-8b07d27c9afd)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
