# V2 Find Time Entry with Timeular

Retrieves a time entry from the Timeular v2 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Find Time Entry](https://developers.early.app/#b7e3d7a2-20fe-4c3a-b1e7-5711911bf062)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
