# V2 Fetch Tags & Mentions with Timeular

Retrieves tags and mentions from the Timeular v2 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tags-and-mentions`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Fetch Tags & Mentions](https://developers.early.app/#6caceffc-7c12-4e81-a7e4-3dbc7b08fca1)
