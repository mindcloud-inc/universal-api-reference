# V3 Delete Mention with Timeular

Deletes a mention from the Timeular v3 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/mentions/:mentionId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Delete Mention](https://developers.early.app/#a7e6b2fa-d879-4368-a4f1-eea14808eef8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mentionId` | path | `string` | yes |
