# V2 Assign an Activity to Device Side with Timeular

Assigns an activity to a device side in the Timeular v2 API.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/activities/:activityId/device-side/:deviceSideId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Assign an Activity to Device Side](https://developers.early.app/#db2dea7b-91a9-43ea-ac8f-8c6e90747093)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activityId` | path | `string` | yes |
| `deviceSideId` | path | `string` | yes |
