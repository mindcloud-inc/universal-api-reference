# Get Folder Member with Timeular

Retrieves a folder member from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/folders/:folderId/members/:memberId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Folder Member](https://developers.early.app/#20a5dd57-d697-4d85-ad19-04b47a500eee)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
| `memberId` | path | `string` | yes |
