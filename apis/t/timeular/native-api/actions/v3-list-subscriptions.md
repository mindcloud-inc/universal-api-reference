# V3 List Subscriptions with Timeular

Retrieves webhook subscriptions from the Timeular v3 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/webhooks/subscription`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 List Subscriptions](https://developers.early.app/#295fadf6-7f50-48b2-8c1b-daa426046e68)
