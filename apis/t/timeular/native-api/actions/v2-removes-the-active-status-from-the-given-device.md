# V2 Removes the active status from the given Device with Timeular

Removes active status from a device in the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/devices/:deviceId/active`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Removes the active status from the given Device](https://developers.early.app/#2a7b6d9b-4adf-4bdb-bf6a-6114a8f2038f)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
