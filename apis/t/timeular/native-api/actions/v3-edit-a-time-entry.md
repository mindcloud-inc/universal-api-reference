# V3 Edit a Time Entry with Timeular

Updates an existing time entry in the Timeular v3 API.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v3/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V3 Edit a Time Entry](https://developers.early.app/#18d45e78-35f7-4dc2-a6c4-edb2405014ed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes |
