# V2 Remove known Device with Timeular

Deletes a device from the Timeular v2 API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/devices/:deviceId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [V2 Remove known Device](https://developers.early.app/#cf4afb22-657f-483b-abc4-51bead8e5f01)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `deviceId` | path | `string` | yes |
