# List Tags and Mentions with Timeular

Retrieves tags and mentions from your Timeular workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/tags-and-mentions`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List Tags and Mentions](https://developers.early.app/#fe2e519d-21bc-45f6-aec7-927635e77d7d)
