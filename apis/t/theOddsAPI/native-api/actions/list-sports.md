# List Sports with The Odds

Retrieves supported sports from The Odds API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/sports/`
- **Base URL:** `https://api.the-odds-api.com`
- **Official documentation:** [List Sports](https://the-odds-api.com/liveapi/guides/v4/#get-sports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `all` | query | `boolean` | no | Set true to include both in-season and out-of-season sports. |
