# List Assessment Specs with Testfuse

Retrieves assessment specs available in Testfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/assess_specs/`
- **Base URL:** `https://gateway.testfuse.com`
- **Official documentation:** [List Assessment Specs](https://api.testfuse.com)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `page` | query | `number` | no |
| `search` | query | `string` | no |
| `sort_by` | query | `string` | no |
| `sort_direction` | query | `string` | no |
| `status` | query | `string` | no |
