# Get Current Unix Timestamp Microseconds with TimeAPI

Retrieves the current Unix timestamp in microseconds from TimeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/time/current/unix_us`
- **Base URL:** `https://www.timeapi.io`
- **Official documentation:** [Get Current Unix Timestamp Microseconds](https://www.timeapi.io/swagger/index.html)
