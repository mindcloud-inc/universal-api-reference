# List Available Time Zones with TimeAPI

Retrieves available IANA time zones from TimeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/timezone/availabletimezones`
- **Base URL:** `https://www.timeapi.io`
- **Official documentation:** [List Available Time Zones](https://www.timeapi.io/swagger/index.html)
