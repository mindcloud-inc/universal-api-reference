# Get Current Unix Timestamp Milliseconds with TimeAPI

Retrieves the current Unix timestamp in milliseconds from TimeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/time/current/unix_ms`
- **Base URL:** `https://www.timeapi.io`
- **Official documentation:** [Get Current Unix Timestamp Milliseconds](https://www.timeapi.io/swagger/index.html)
