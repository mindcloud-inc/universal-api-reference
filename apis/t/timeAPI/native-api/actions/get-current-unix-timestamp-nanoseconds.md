# Get Current Unix Timestamp Nanoseconds with TimeAPI

Retrieves the current Unix timestamp in nanoseconds from TimeAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/time/current/unix_ns`
- **Base URL:** `https://www.timeapi.io`
- **Official documentation:** [Get Current Unix Timestamp Nanoseconds](https://www.timeapi.io/swagger/index.html)
