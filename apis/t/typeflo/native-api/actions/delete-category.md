# Delete Category with Typeflo

Deletes an existing category from Typeflo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/category/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Delete Category](https://typeflo.io/knowledge-base/headless-cms-admin-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the category. |
