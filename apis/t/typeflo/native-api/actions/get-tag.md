# Get Tag with Typeflo

Retrieves a content tag from Typeflo.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/tags/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Tag](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the tag. |
