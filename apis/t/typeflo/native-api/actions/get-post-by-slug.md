# Get Post By Slug with Typeflo

Retrieves a published post from Typeflo by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/posts/:slug`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Post By Slug](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The unique slug of the post. |
