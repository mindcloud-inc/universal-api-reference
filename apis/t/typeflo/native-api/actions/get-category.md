# Get Category with Typeflo

Retrieves a content category from Typeflo.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/category/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Category](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the category. |
