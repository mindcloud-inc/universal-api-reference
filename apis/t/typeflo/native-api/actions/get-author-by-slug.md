# Get Author By Slug with Typeflo

Retrieves an author profile from Typeflo by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/authors/:slug`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Author By Slug](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The unique slug of the author. |
