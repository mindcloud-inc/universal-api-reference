# Get Page By Slug with Typeflo

Retrieves a static page from Typeflo by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/pages/:slug`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Page By Slug](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The unique slug of the page. |
