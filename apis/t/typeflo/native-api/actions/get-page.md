# Get Page with Typeflo

Retrieves a static page from Typeflo.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/pages/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Page](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the page. |
