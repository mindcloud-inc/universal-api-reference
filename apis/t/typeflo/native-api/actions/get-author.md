# Get Author with Typeflo

Retrieves an author profile from Typeflo.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/authors/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Author](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the author. |
