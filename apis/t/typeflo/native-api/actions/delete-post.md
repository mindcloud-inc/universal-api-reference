# Delete Post with Typeflo

Deletes an existing post from Typeflo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/posts/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Delete Post](https://typeflo.io/knowledge-base/headless-cms-admin-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the post. |
