# Get Post with Typeflo

Retrieves a published post from Typeflo.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/posts/:id`
- **Base URL:** `https://{subdomain}.typeflo.io/api/headless`
- **Official documentation:** [Get Post](https://typeflo.io/knowledge-base/headless-cms-content-api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the post. |
