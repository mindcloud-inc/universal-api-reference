# List Site Scripts with Thinkific

Retrieves site script records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/site_scripts`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Site Scripts](https://developers.thinkific.com/api/api-documentation#/paths/~1site_scripts/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
