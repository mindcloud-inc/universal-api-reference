# List Courses with Thinkific

Retrieves course records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Courses](https://developers.thinkific.com/api/api-documentation#/paths/~1courses/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
