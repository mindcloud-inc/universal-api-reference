# List Orders with Thinkific

Retrieves order records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Orders](https://developers.thinkific.com/api/api-documentation#/paths/~1orders/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
