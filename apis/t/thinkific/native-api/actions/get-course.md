# Get Course with Thinkific

Retrieves a course record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Course](https://developers.thinkific.com/api/api-documentation#/paths/~1courses~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Course identifier. |
