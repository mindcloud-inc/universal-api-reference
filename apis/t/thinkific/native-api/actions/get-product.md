# Get Product with Thinkific

Retrieves a product record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Product](https://developers.thinkific.com/api/api-documentation#/paths/~1products~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Product identifier. |
