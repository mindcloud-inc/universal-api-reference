# List Enrollments with Thinkific

Retrieves enrollment records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/enrollments`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Enrollments](https://developers.thinkific.com/api/api-documentation#/paths/~1enrollments/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
