# Get Instructor with Thinkific

Retrieves an instructor record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/instructors/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Instructor](https://developers.thinkific.com/api/api-documentation#/paths/~1instructors~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Instructor identifier. |
