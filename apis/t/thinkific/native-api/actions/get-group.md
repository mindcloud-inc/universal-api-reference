# Get Group with Thinkific

Retrieves a group record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Group](https://developers.thinkific.com/api/api-documentation#/paths/~1groups~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group identifier. |
