# List Groups with Thinkific

Retrieves group records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Groups](https://developers.thinkific.com/api/api-documentation#/paths/~1groups/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
