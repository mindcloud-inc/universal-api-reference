# List Users with Thinkific

Retrieves user records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Users](https://developers.thinkific.com/api/api-documentation#/paths/~1users/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
