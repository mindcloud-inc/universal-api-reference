# Get Order with Thinkific

Retrieves an order record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Order](https://developers.thinkific.com/api/api-documentation#/paths/~1orders~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Order identifier. |
