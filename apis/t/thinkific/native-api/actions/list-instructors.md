# List Instructors with Thinkific

Retrieves instructor records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/instructors`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Instructors](https://developers.thinkific.com/api/api-documentation#/paths/~1instructors/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
