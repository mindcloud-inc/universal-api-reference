# Create Group with Thinkific

Creates a new group in Thinkific.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Create Group](https://developers.thinkific.com/api/api-documentation#/paths/~1groups/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Group name. |
