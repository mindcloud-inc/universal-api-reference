# Get Enrollment with Thinkific

Retrieves an enrollment record from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/enrollments/:id`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [Get Enrollment](https://developers.thinkific.com/api/api-documentation#/paths/~1enrollments~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Enrollment identifier. |
