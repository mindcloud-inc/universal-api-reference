# List Products with Thinkific

Retrieves product records from Thinkific.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.thinkific.com/api/public/v1`
- **Official documentation:** [List Products](https://developers.thinkific.com/api/api-documentation#/paths/~1products/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
