# Retrieve Render with Templated

Retrieves detailed render information from Templated.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/render/:id`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Retrieve Render](https://templated.io/docs/renders/retrieve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The render id of the render that will be retrieved. |
