# Delete Template with Templated

Deletes an existing template from Templated.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/template/:id`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Delete Template](https://templated.io/docs/templates/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template id of the template that will be deleted. |
