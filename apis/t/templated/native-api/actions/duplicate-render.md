# Duplicate Render with Templated

Duplicates an existing render in Templated.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/render/:id/duplicate`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Duplicate Render](https://templated.io/docs/renders/duplicate/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The render id of the render that you want to duplicate. |
