# Delete Render with Templated

Deletes an existing render from Templated.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/render/:id`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Delete Render](https://templated.io/docs/renders/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The render id of the render that will be deleted. |
