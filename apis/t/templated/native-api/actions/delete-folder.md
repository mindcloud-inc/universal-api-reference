# Delete Folder with Templated

Deletes an existing folder from Templated.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/folder/:id`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Delete Folder](https://templated.io/docs/folders/delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the folder you want to delete. |
