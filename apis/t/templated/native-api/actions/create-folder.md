# Create Folder with Templated

Creates a new folder in Templated.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/folder`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Create Folder](https://templated.io/docs/folders/create/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the folder you want to create. |
