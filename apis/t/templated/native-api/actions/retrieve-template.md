# Retrieve Template with Templated

Retrieves detailed template information from Templated.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/template/:id`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Retrieve Template](https://templated.io/docs/templates/retrieve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template id of the template that will be retrieved. |
