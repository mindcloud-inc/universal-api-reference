# Clone Template with Templated

Clones an existing template in Templated.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/template/:id/clone`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [Clone Template](https://templated.io/docs/templates/clone/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template id of the template that you want to clone. |
