# List Template Pages with Templated

Retrieves pages for a template in Templated.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/template/:id/pages`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [List Template Pages](https://templated.io/docs/templates/pages/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template id of the template that you want to retrieve the pages. |
