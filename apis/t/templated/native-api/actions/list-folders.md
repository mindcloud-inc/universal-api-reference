# List Folders with Templated

Retrieves all folder records from Templated.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/folders`
- **Base URL:** `https://api.templated.io`
- **Official documentation:** [List Folders](https://templated.io/docs/folders/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Filter folders by name. |
