# Accept User Invitation with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/settings/users/invitation/{{token}}/accept`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Accept User Invitation](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | The invitation token. |
