# Get Inbox Alias Connection with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/settings/inbox/{{inboxId}}/aliases/{{aliasId}}/connection`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Inbox Alias Connection](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `aliasId` | path | `string` | yes | The alias ID. |
| `inboxId` | path | `string` | yes | The inbox ID. |
