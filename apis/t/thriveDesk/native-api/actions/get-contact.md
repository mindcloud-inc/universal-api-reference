# Get Contact with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/{{contactId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Contact](https://wordpress.org/plugins/thrivedesk/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | ThriveDesk contact ID. |
