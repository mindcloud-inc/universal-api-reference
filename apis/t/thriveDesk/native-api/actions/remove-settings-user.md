# Remove Settings User with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/settings/users/{{userId}}/remove`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Remove Settings User](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
