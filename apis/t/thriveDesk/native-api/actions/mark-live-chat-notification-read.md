# Mark Live Chat Notification Read with ThriveDesk

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/live_chat/notifications/{{notificationId}}/read`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Mark Live Chat Notification Read](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notificationId` | path | `string` | yes | The notification ID. |
