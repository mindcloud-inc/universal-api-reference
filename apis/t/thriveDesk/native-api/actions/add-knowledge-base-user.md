# Add Knowledge Base User with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/knowledgebases/{{knowledgebaseId}}/users`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Add Knowledge Base User](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `knowledgebaseId` | path | `string` | yes | The knowledge base ID. |
