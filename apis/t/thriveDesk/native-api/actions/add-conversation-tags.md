# Add Conversation Tags with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/conversation/{{conversationId}}/tags`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Add Conversation Tags](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | The conversation ID. |
