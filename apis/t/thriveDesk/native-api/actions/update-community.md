# Update Community with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/communities/{{communityId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Update Community](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `communityId` | path | `string` | yes | The community ID. |
