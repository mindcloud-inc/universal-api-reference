# List Customer Conversations with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customer/conversations`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [List Customer Conversations](https://help.thrivedesk.com/en/wpportal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_email` | query | `string` | yes | Customer email address used to find customer-facing conversations. |
