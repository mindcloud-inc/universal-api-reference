# Update Inbox Permissions with ThriveDesk

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/settings/inbox/{{inboxId}}/permissions`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Update Inbox Permissions](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | yes | The inbox ID. |
