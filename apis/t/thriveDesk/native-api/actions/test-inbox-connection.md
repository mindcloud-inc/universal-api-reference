# Test Inbox Connection with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/settings/inbox/{{inboxId}}/connection/test`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Test Inbox Connection](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | yes | The inbox ID. |
