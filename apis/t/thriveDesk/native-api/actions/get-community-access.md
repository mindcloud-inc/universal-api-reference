# Get Community Access with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/communities/{{communityId}}/access`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Community Access](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `communityId` | path | `string` | yes | The community ID. |
