# Get Inbox Automation with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/inboxes/{{inboxId}}/automations/{{automationId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Inbox Automation](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automationId` | path | `string` | yes | The automation ID. |
| `inboxId` | path | `string` | yes | The inbox ID. |
