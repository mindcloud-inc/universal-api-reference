# Update User Role with ThriveDesk

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/settings/users/{{userId}}/role`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Update User Role](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
