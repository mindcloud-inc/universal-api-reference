# Mark Inbox Alias Primary with ThriveDesk

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/settings/inbox/{{inboxId}}/aliases/{{aliasId}}/mark-as-primary`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Mark Inbox Alias Primary](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `aliasId` | path | `string` | yes | The alias ID. |
| `inboxId` | path | `string` | yes | The inbox ID. |
