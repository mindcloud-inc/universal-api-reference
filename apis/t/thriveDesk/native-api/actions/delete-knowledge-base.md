# Delete Knowledge Base with ThriveDesk

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/knowledgebases/{{knowledgebaseId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Delete Knowledge Base](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `knowledgebaseId` | path | `string` | yes | The knowledge base ID. |
