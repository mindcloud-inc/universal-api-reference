# Delete Settings Tag with ThriveDesk

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/settings/tags/{{tagId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Delete Settings Tag](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | The tag ID. |
