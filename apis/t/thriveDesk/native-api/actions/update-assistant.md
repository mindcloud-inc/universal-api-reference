# Update Assistant with ThriveDesk

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/assistants/{{assistantId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Update Assistant](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assistantId` | path | `string` | yes | The assistant ID. |
