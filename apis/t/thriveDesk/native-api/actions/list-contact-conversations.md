# List Contact Conversations with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/{{contactId}}/conversations`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [List Contact Conversations](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The contact ID. |
