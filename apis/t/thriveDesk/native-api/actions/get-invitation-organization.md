# Get Invitation Organization with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/settings/users/invitation/{{token}}/organization`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Invitation Organization](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | The invitation token. |
