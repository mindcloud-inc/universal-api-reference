# Batch Force Delete Inbox Conversations with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/inboxes/{{inboxId}}/batch/force-delete`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Batch Force Delete Inbox Conversations](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | yes | The inbox ID. |
