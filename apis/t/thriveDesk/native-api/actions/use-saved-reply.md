# Use Saved Reply with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/saved-replies/{{savedReplyId}}/use`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Use Saved Reply](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `savedReplyId` | path | `string` | yes | The saved reply ID. |
