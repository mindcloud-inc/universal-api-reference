# Delete Access Token with ThriveDesk

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/settings/access-tokens/{{tokenId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Delete Access Token](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tokenId` | path | `string` | yes | The access token ID. |
