# Delete Organization with ThriveDesk

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/organizations/{{organizationId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Delete Organization](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | The organization ID. |
