# Get Conversation with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/conversation/{{conversationId}}`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get Conversation](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | The conversation ID. |
