# Cancel User Invitation with ThriveDesk

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/settings/users/invitation/{{invitationId}}/cancel`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Cancel User Invitation](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invitationId` | path | `string` | yes | The invitation ID. |
