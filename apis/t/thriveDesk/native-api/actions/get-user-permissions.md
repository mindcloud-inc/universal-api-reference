# Get User Permissions with ThriveDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/settings/users/{{userId}}/permissions`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Get User Permissions](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
