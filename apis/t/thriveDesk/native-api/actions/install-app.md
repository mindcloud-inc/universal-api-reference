# Install App with ThriveDesk

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/apps/{{appNamespace}}/install`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Install App](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appNamespace` | path | `string` | yes | The namespace of the ThriveDesk app to install. |
