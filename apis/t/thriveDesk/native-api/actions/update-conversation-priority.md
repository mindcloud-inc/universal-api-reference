# Update Conversation Priority with ThriveDesk

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/conversation/{{conversationId}}/update/priority`
- **Base URL:** `https://api.thrivedesk.com`
- **Official documentation:** [Update Conversation Priority](https://documenter.getpostman.com/view/13910051/2sB2qUnQcP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | The conversation ID. |
