# Delete Testimonial with Trust

Deletes an existing testimonial from Trust.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/testimonial/:id`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [Delete Testimonial](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The testimonial ID. |
