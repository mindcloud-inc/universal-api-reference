# Remove Testimonial From Widget with Trust

Removes a testimonial from a Trust widget.

## Endpoint

- **Method:** `PUT`
- **Path:** `/testimonial/:id/remove-widget/:widgetId`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [Remove Testimonial From Widget](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The testimonial ID. |
| `widgetId` | path | `string` | yes | The widget ID. |
