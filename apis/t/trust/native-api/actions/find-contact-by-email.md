# Find Contact By Email with Trust

Finds contacts in Trust by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [Find Contact By Email](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address of the contact. |
