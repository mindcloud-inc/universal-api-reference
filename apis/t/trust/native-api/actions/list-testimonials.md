# List Testimonials with Trust

Retrieves testimonials from a Trust workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/testimonial/all/:workspaceId`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [List Testimonials](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | The Trust workspace ID. |
