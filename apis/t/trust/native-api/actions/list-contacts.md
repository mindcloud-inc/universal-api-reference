# List Contacts with Trust

Retrieves contacts from a Trust workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/all/:workspaceId`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [List Contacts](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | The Trust workspace id (typeId). |
