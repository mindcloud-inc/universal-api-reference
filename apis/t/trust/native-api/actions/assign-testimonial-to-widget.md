# Assign Testimonial To Widget with Trust

Assigns a testimonial to a Trust widget.

## Endpoint

- **Method:** `PUT`
- **Path:** `/testimonial/:id/assign-widget/:widgetId`
- **Base URL:** `https://api.usetrust.app/v1`
- **Official documentation:** [Assign Testimonial To Widget](https://api-docs.usetrust.io/api-reference-swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The testimonial ID. |
| `widgetId` | path | `string` | yes | The widget ID. |
