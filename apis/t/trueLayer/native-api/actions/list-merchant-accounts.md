# List Merchant Accounts with TrueLayer

Retrieves merchant accounts from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/merchant-accounts`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [List Merchant Accounts](https://docs.truelayer.com/reference/list-operating-accounts)
