# Get Payment Link with TrueLayer

Retrieves a payment link from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payment-links/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payment Link](https://docs.truelayer.com/reference/get-payment-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payment link ID. |
