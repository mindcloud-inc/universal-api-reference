# Get Merchant Account Sweeping with TrueLayer

Retrieves merchant account sweeping from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/merchant-accounts/:id/sweeping`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Merchant Account Sweeping](https://docs.truelayer.com/reference/merchant-account-get-sweeping)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer merchant account ID. |
