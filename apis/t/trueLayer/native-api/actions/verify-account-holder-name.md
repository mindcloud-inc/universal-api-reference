# Verify Account Holder Name with TrueLayer

Verifies an account holder name in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/verification/v1/verify`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Verify Account Holder Name](https://docs.truelayer.com/reference/get-account-holder-verification)
