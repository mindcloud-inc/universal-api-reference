# Verify France Account Details with TrueLayer

Verifies French account details in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/verification/fr/verify-account-details`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Verify France Account Details](https://docs.truelayer.com/reference/get-account-holder-verification)
