# Disable Merchant Account Sweeping with TrueLayer

Disables merchant account sweeping in TrueLayer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/merchant-accounts/:id/sweeping`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Disable Merchant Account Sweeping](https://docs.truelayer.com/reference/merchant-account-disable-sweeping)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer merchant account ID. |
