# Set Merchant Account Sweeping with TrueLayer

Sets merchant account sweeping in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/merchant-accounts/:id/sweeping`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Set Merchant Account Sweeping](https://docs.truelayer.com/reference/merchant-account-setup-sweeping)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer merchant account ID. |
