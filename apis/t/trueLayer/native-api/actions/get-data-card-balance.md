# Get Data Card Balance with TrueLayer

Retrieves a data card balance from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/v1/cards/:card_id/balance`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Data Card Balance](https://docs.truelayer.com/docs/account-and-card-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card_id` | path | `string` | yes | TrueLayer Data API card ID. |
