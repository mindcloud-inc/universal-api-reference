# Get Merchant Account with TrueLayer

Retrieves a merchant account from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/merchant-accounts/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Merchant Account](https://docs.truelayer.com/reference/get-operating-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer merchant account ID. |
