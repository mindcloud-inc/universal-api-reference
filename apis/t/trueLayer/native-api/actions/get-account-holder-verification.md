# Get Account Holder Verification with TrueLayer

Retrieves an account holder verification from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/account-holder-verifications/requests/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Account Holder Verification](https://docs.truelayer.com/reference/get-account-holder-verification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer account holder verification request ID. |
