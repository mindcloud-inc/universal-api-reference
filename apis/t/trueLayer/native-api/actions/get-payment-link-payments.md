# Get Payment Link Payments with TrueLayer

Retrieves payments for a TrueLayer payment link.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payment-links/:id/payments`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payment Link Payments](https://docs.truelayer.com/reference/get-payment-link-payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payment link ID. |
