# Revoke Mandate with TrueLayer

Revokes a mandate in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/mandates/:id/revoke`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Revoke Mandate](https://docs.truelayer.com/reference/revoke-mandate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
