# Get Merchant Account Payment Sources with TrueLayer

Retrieves merchant account payment sources from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/merchant-accounts/:id/payment-sources`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Merchant Account Payment Sources](https://docs.truelayer.com/reference/get-merchant-account-payment-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer merchant account ID. |
