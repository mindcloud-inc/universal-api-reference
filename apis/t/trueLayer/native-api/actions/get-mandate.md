# Get Mandate with TrueLayer

Retrieves a mandate from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mandates/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Mandate](https://docs.truelayer.com/reference/get-mandate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
