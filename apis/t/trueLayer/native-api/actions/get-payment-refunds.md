# Get Payment Refunds with TrueLayer

Retrieves payment refunds from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payments/:id/refunds`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payment Refunds](https://docs.truelayer.com/reference/get-payment-refunds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payment ID. |
