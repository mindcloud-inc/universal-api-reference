# Get Data Card with TrueLayer

Retrieves a data card from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/v1/cards/:card_id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Data Card](https://docs.truelayer.com/docs/account-and-card-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card_id` | path | `string` | yes | TrueLayer Data API card ID. |
