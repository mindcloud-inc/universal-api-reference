# Get Payment with TrueLayer

Retrieves a payment from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payments/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payment](https://docs.truelayer.com/reference/get-payment-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payment ID. |
