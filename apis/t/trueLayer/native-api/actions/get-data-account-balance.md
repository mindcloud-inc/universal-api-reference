# Get Data Account Balance with TrueLayer

Retrieves a data account balance from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/v1/accounts/:account_id/balance`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Data Account Balance](https://docs.truelayer.com/docs/account-and-card-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | TrueLayer Data API account ID. |
