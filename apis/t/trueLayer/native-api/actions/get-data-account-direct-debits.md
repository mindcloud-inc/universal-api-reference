# Get Data Account Direct Debits with TrueLayer

Retrieves data account direct debits from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/v1/accounts/:account_id/direct_debits`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Data Account Direct Debits](https://docs.truelayer.com/docs/data-api-basics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | TrueLayer Data API account ID. |
