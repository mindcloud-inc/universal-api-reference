# Get Payout Authorization Flow with TrueLayer

Retrieves a payout authorization flow from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payouts/:id/authorization-flow`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payout Authorization Flow](https://docs.truelayer.com/reference/get-payout-authorization-flow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payout ID. |
