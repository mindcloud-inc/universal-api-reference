# Save Payment User Account with TrueLayer

Saves a payment user account in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/payments/:id/actions/save-user-account`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Save Payment User Account](https://docs.truelayer.com/reference/save-user-account-payment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payment ID. |
