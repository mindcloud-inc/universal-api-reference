# Get Signup Plus Mandate Data with TrueLayer

Retrieves Signup+ mandate data from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/signup-plus/mandates`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Signup Plus Mandate Data](https://docs.truelayer.com/docs/variable-recurring-payments-integration)
