# Create Account Holder Verification with TrueLayer

Creates an account holder verification in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/account-holder-verifications/requests`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Create Account Holder Verification](https://docs.truelayer.com/reference/get-account-holder-verification)
