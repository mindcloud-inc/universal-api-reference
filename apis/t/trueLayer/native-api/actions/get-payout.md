# Get Payout with TrueLayer

Retrieves a payout from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/payouts/:id`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Payout](https://docs.truelayer.com/reference/get-payout)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer payout ID. |
