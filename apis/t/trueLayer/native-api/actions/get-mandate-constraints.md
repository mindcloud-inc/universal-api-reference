# Get Mandate Constraints with TrueLayer

Retrieves mandate constraints from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mandates/:id/constraints`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Mandate Constraints](https://docs.truelayer.com/reference/get-constraints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
