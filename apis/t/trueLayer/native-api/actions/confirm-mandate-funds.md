# Confirm Mandate Funds with TrueLayer

Confirms mandate funds in TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mandates/:id/funds`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Confirm Mandate Funds](https://docs.truelayer.com/reference/confirm-mandate-funds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
