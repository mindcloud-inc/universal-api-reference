# Submit Payments Provider Return Parameters with TrueLayer

Submits payment provider return parameters in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/payments-provider-return`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Submit Payments Provider Return Parameters](https://docs.truelayer.com/reference/submit-payments-provider-return-parameters)
