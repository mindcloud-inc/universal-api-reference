# Submit Mandate Provider Selection with TrueLayer

Submits mandate provider selection in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/mandates/:id/authorization-flow/actions/provider-selection`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Submit Mandate Provider Selection](https://docs.truelayer.com/reference/submit-mandate-provider-selection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
