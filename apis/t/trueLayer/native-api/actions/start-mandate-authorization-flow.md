# Start Mandate Authorization Flow with TrueLayer

Starts a mandate authorization flow in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/mandates/:id/authorization-flow`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Start Mandate Authorization Flow](https://docs.truelayer.com/reference/start-mandate-authorization-flow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | TrueLayer mandate ID. |
