# Get Signup Plus Accounts with TrueLayer

Retrieves Signup+ accounts from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/signup-plus/accounts`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Get Signup Plus Accounts](https://docs.truelayer.com/docs/data-only-integration)
