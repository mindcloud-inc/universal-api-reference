# Legacy Initiate Payment with TrueLayer

Initiates a legacy payment in TrueLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/single-immediate-payment-initiation-requests`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Legacy Initiate Payment](https://docs.truelayer.com/reference/get-providers)
