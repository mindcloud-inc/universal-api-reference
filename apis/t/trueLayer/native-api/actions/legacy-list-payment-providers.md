# Legacy List Payment Providers with TrueLayer

Retrieves legacy payment providers from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/single-immediate-payments-providers`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [Legacy List Payment Providers](https://docs.truelayer.com/reference/get-providers)
