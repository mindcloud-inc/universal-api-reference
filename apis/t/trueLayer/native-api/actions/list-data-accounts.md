# List Data Accounts with TrueLayer

Retrieves data accounts from TrueLayer.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/v1/accounts`
- **Base URL:** `https://api.truelayer-sandbox.com`
- **Official documentation:** [List Data Accounts](https://docs.truelayer.com/docs/account-and-card-data)
