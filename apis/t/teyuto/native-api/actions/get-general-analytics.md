# Get General Analytics with Teyuto

Retrieves general analytics from a Teyuto channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/channel`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Get General Analytics](https://apidocs.teyuto.com/api-9259149)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `end_date` | query | `string` | no | Analytics window end |
| `start_date` | query | `string` | no | Analytics window start |
