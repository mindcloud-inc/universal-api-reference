# List Collections with Teyuto

Retrieves all collections from a Teyuto channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [List Collections](https://apidocs.teyuto.com/api-9259096)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Page of collections to return |
