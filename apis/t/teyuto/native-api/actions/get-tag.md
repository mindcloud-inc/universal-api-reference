# Get Tag with Teyuto

Retrieves a specific tag from Teyuto.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Get Tag](https://docs.teyuto.com/api/get-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `string` | yes | The Teyuto tag ID to fetch. |
