# Delete User with Teyuto

Deletes an existing user from Teyuto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:user_id`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Delete User](https://apidocs.teyuto.com/api-9259128)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | no | ID of the user to delete |
