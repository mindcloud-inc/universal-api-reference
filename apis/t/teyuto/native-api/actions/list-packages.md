# List Packages with Teyuto

Retrieves all packages from a Teyuto channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/packages`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [List Packages](https://apidocs.teyuto.com/api-9259109)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Page of packages to return |
