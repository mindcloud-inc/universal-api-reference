# List Videos with Teyuto

Retrieves all videos from a Teyuto channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [List Videos](https://apidocs.teyuto.com/api-9259071)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Filter videos by type |
