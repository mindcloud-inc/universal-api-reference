# Get Collection with Teyuto

Retrieves a specific collection from Teyuto.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collection_id`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Get Collection](https://apidocs.teyuto.com/api-9259098)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `string` | no | ID of the collection to retrieve |
