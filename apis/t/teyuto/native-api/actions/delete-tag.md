# Delete Tag with Teyuto

Deletes an existing tag from Teyuto.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Delete Tag](https://docs.teyuto.com/api/delete-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `string` | yes | The Teyuto tag ID to delete. |
