# Get Video with Teyuto

Retrieves a specific video from Teyuto.

## Endpoint

- **Method:** `GET`
- **Path:** `/videos/:video_id`
- **Base URL:** `https://api.teyuto.tv/v2`
- **Official documentation:** [Get Video](https://apidocs.teyuto.com/api-9259073)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | no | ID of the video to retrieve |
