# Delete Customer with Trafft

Deletes an existing customer from Trafft.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:id`
- **Base URL:** `https://mindcloud.admin.trafft.com/api/v2`
- **Official documentation:** [Delete Customer](https://documenter.getpostman.com/view/1487056/2sAY4x9MRe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Trafft customer ID to delete. |
