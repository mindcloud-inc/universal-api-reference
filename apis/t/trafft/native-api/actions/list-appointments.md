# List Appointments with Trafft

Retrieves appointments from Trafft.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments`
- **Base URL:** `https://mindcloud.admin.trafft.com/api/v2`
- **Official documentation:** [List Appointments](https://documenter.getpostman.com/view/1487056/2sAY4x9MRe)
