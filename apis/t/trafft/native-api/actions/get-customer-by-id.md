# Get Customer by ID with Trafft

Retrieves a customer from Trafft by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://mindcloud.admin.trafft.com/api/v2`
- **Official documentation:** [Get Customer by ID](https://documenter.getpostman.com/view/1487056/2sAY4x9MRe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Trafft customer ID. |
