# Create Customer with Trafft

Creates a new customer in Trafft.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://mindcloud.admin.trafft.com/api/v2`
- **Official documentation:** [Create Customer](https://documenter.getpostman.com/view/1487056/2sAY4x9MRe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `first_name` | body | `string` | yes | Customer first name. |
| `last_name` | body | `string` | yes | Customer last name. |
| `email` | body | `string` | yes | Customer email address. |
