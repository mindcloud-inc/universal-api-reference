# Get Current Admin Profile with Tricentis qTest

Retrieves the current admin profile from Tricentis qTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin-profiles/current`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [Get Current Admin Profile](https://qtest-config.s3.amazonaws.com/api-docs/manager/api-manager-v3.0.yaml)
