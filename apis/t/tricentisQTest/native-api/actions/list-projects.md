# List Projects with Tricentis qTest

Retrieves available projects from Tricentis qTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [List Projects](https://docs.tricentis.com/qtest-saas/content/apis/apis/common_apis.htm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expand` | query | `string` | no | Optional expansion, such as userprofile, to include profile and permission data. |
