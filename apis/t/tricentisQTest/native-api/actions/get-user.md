# Get User with Tricentis qTest

Retrieves a user from Tricentis qTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [Get User](https://qtest-config.s3.amazonaws.com/api-docs/manager/api-manager-v3.0.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | ID of the user. |
