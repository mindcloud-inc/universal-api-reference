# List Authentication Systems with Tricentis qTest

Retrieves authentication systems from Tricentis qTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth-systems`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [List Authentication Systems](https://qtest-config.s3.amazonaws.com/api-docs/manager/api-manager-v3.0.yaml)
