# List User Groups with Tricentis qTest

Retrieves user groups from Tricentis qTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [List User Groups](https://qtest-config.s3.amazonaws.com/api-docs/manager/api-manager-v3.0.yaml)
