# Search Projects with Tricentis qTest

Finds projects in Tricentis qTest by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/search`
- **Base URL:** `https://mindcloudapps.qtestnet.com/api/v3`
- **Official documentation:** [Search Projects](https://qtest-config.s3.amazonaws.com/api-docs/manager/api-manager-v3.0.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Project search condition object. |
