# TerraReach: Native API Reference

A consolidated summary of TerraReach's API configuration, with links to official documentation.

- **Official docs:** https://docs.terrareach.com/api-reference/introduction
- **API base URL:** `https://api.terrareach.com/api`

## Authentication

### API Key

Authenticate with your TerraReach API key. TerraReach requires the key as the `apiKey` query parameter rather than a bearer header.

### Credentials

- **API Key:** `apiKey` · required · TerraReach API key from your TerraReach dashboard.

[Official authentication documentation](https://docs.terrareach.com/api-reference/introduction)

## API conventions

Responses from this API use JSON.
