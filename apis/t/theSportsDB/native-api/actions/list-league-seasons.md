# List League Seasons with TheSportsDB

Retrieves league seasons from TheSportsDB by league ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/search_all_seasons.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List League Seasons](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
