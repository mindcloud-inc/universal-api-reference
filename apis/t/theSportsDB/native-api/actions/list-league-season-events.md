# List League Season Events with TheSportsDB

Retrieves league events in TheSportsDB by season.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventsseason.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List League Season Events](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
| `s` | query | `string` | yes |
