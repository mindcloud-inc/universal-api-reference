# List Event Timeline with TheSportsDB

Retrieves event timeline entries from TheSportsDB by event ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookuptimeline.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Event Timeline](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
