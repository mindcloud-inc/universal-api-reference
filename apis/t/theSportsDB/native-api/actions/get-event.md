# Get Event with TheSportsDB

Retrieves an event from TheSportsDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupevent.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get Event](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
