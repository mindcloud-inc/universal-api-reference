# Get League with TheSportsDB

Retrieves a league from TheSportsDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupleague.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get League](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
