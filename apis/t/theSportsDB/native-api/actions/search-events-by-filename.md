# Search Events By Filename with TheSportsDB

Finds events in TheSportsDB by event filename.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchevents.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Search Events By Filename](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `f` | query | `string` | yes |
