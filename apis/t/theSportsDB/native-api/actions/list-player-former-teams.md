# List Player Former Teams with TheSportsDB

Retrieves former teams for a player in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupformerteams.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Player Former Teams](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
