# Search Players with TheSportsDB

Finds players in TheSportsDB by player name.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchplayers.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Search Players](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `p` | query | `string` | yes |
