# List TV Events with TheSportsDB

Retrieves televised events in TheSportsDB for a specific day.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventstv.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List TV Events](https://www.thesportsdb.com/documentation)
