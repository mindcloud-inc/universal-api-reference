# List Previous Team Events with TheSportsDB

Retrieves recent events for a team in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventslast.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Previous Team Events](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
