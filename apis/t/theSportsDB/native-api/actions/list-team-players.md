# List Team Players with TheSportsDB

Retrieves players for a team in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup_all_players.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Team Players](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
