# Search Events with TheSportsDB

Finds events in TheSportsDB by event name.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchevents.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Search Events](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `e` | query | `string` | yes |
