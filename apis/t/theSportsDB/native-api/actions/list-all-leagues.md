# List All Leagues with TheSportsDB

Retrieves all leagues listed in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/all_leagues.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List All Leagues](https://www.thesportsdb.com/documentation)
