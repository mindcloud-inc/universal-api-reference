# List Teams By League Name with TheSportsDB

Retrieves teams in TheSportsDB by league name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search_all_teams.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Teams By League Name](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `l` | query | `string` | yes |
