# Search Venues with TheSportsDB

Finds venues in TheSportsDB by venue name.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchvenues.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Search Venues](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `v` | query | `string` | yes |
