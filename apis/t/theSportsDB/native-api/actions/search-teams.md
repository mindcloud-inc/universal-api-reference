# Search Teams with TheSportsDB

Finds teams in TheSportsDB by team name.

## Endpoint

- **Method:** `GET`
- **Path:** `/searchteams.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Search Teams](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `t` | query | `string` | yes |
