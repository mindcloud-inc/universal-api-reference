# Get Player with TheSportsDB

Retrieves a player from TheSportsDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupplayer.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get Player](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
