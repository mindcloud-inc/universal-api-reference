# List Event Lineup with TheSportsDB

Retrieves event lineups from TheSportsDB by event ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookuplineup.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Event Lineup](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
