# Get Team with TheSportsDB

Retrieves a team from TheSportsDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupteam.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get Team](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
