# Get League Table with TheSportsDB

Retrieves a league table from TheSportsDB by league and season.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookuptable.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get League Table](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `l` | query | `string` | yes |
| `s` | query | `string` | yes |
