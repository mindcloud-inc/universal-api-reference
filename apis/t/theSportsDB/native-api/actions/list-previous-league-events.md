# List Previous League Events with TheSportsDB

Retrieves recent events for a league in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventspastleague.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Previous League Events](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
