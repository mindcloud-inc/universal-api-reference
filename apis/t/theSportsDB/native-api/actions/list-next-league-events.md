# List Next League Events with TheSportsDB

Retrieves upcoming events for a league in TheSportsDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventsnextleague.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Next League Events](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
