# List Leagues By Country And Sport with TheSportsDB

Retrieves leagues in TheSportsDB by country and sport.

## Endpoint

- **Method:** `GET`
- **Path:** `/search_all_leagues.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Leagues By Country And Sport](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `c` | query | `string` | yes |
| `s` | query | `string` | yes |
