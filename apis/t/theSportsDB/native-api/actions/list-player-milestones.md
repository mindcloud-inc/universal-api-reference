# List Player Milestones with TheSportsDB

Retrieves player milestones from TheSportsDB by player ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupmilestones.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Player Milestones](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
