# List Player Honours with TheSportsDB

Retrieves player honours from TheSportsDB by player ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookuphonours.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Player Honours](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
