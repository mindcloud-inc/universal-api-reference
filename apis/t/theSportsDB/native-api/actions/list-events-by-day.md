# List Events By Day with TheSportsDB

Retrieves events in TheSportsDB for a specific day.

## Endpoint

- **Method:** `GET`
- **Path:** `/eventsday.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [List Events By Day](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `d` | query | `string` | yes |
