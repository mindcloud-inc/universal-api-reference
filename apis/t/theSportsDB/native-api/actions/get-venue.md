# Get Venue with TheSportsDB

Retrieves a venue from TheSportsDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupvenue.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get Venue](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
