# Get Team Equipment with TheSportsDB

Retrieves team equipment from TheSportsDB by team ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookupequipment.php`
- **Base URL:** `https://www.thesportsdb.com/api/v1/json/123`
- **Official documentation:** [Get Team Equipment](https://www.thesportsdb.com/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
