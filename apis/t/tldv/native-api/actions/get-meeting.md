# Get Meeting with tl:dv

Retrieves a meeting from tl:dv.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1alpha1/meetings/:meetingId`
- **Base URL:** `https://pasta.tldv.io`
- **Official documentation:** [Get Meeting](https://doc.tldv.io/index.html#tag/Meetings/operation/GetMeetingById.GetMeetingById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | The tl:dv meeting identifier. |
