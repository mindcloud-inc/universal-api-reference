# Unpublish Typebot with Typebot

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/typebots/:typebotId/unpublish`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Unpublish Typebot](https://docs.typebot.io/api-reference/typebot/unpublish)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | The Typebot ID. |
