# Get Result Transcript with Typebot

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/typebots/:typebotId/results/:resultId/transcript`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Get Result Transcript](https://docs.typebot.io/openapi/builder.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | The Typebot ID. |
| `resultId` | path | `string` | yes | The result ID. |
