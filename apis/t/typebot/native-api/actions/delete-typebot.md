# Delete Typebot with Typebot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/typebots/:typebotId`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Delete Typebot](https://docs.typebot.io/api-reference/typebot/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | Typebot ID to delete. |
