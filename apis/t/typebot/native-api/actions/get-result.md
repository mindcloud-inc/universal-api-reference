# Get Result with Typebot

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/typebots/:typebotId/results/:resultId`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Get Result](https://docs.typebot.io/api-reference/results/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | The Typebot ID. |
| `resultId` | path | `string` | yes | The result ID. |
