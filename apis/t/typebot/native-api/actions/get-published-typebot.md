# Get Published Typebot with Typebot

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/typebots/:typebotId/publishedTypebot`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Get Published Typebot](https://docs.typebot.io/api-reference/typebot/get-published-bot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | The Typebot ID. |
