# Get Typebot with Typebot

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/typebots/:typebotId`
- **Base URL:** `https://app.typebot.io/api`
- **Official documentation:** [Get Typebot](https://docs.typebot.io/api-reference/typebot/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typebotId` | path | `string` | yes | Typebot ID to retrieve. |
