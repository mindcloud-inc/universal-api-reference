# Get Project with Todoist

Retrieves project details from Todoist.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:project_id`
- **Base URL:** `https://api.todoist.com`
- **Official documentation:** [Get Project](https://developer.todoist.com/api/v1/#tag/Projects/operation/get_project_api_v1_projects__project_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project identifier. |
