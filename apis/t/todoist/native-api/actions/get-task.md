# Get Task with Todoist

Retrieves task details from Todoist.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/:task_id`
- **Base URL:** `https://api.todoist.com`
- **Official documentation:** [Get Task](https://developer.todoist.com/api/v1/#tag/Tasks/operation/get_task_api_v1_tasks__task_id__get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
