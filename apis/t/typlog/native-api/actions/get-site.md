# Get Site with Typlog

Retrieves a Typlog site by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/[:id]`
- **Base URL:** `https://api.typlog.com/v3`
- **Official documentation:** [Get Site](https://api.typlog.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Typlog site ID. |
