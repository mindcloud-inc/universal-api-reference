# List Authors with Typlog

Retrieves authors from Typlog.

## Endpoint

- **Method:** `GET`
- **Path:** `/authors`
- **Base URL:** `https://api.typlog.com/v3`
- **Official documentation:** [List Authors](https://api.typlog.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | query | `number` | yes | Typlog site ID used to set the X-Site-Id header. |
