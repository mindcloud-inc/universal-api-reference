# Identify Color By RGB with The Color

Identifies a color in The Color by RGB value.

## Endpoint

- **Method:** `GET`
- **Path:** `/id`
- **Base URL:** `https://www.thecolorapi.com`
- **Official documentation:** [Identify Color By RGB](https://www.thecolorapi.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rgb` | query | `string` | yes | Valid RGB color, such as 0,71,171 or rgb(0,71,171). |
