# Identify Color By Hex with The Color

Identifies a color in The Color by hex code.

## Endpoint

- **Method:** `GET`
- **Path:** `/id`
- **Base URL:** `https://www.thecolorapi.com`
- **Official documentation:** [Identify Color By Hex](https://www.thecolorapi.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hex` | query | `string` | yes | Valid hex color code, such as 0047AB. |
