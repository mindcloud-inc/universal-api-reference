# Identify Color By HSL with The Color

Identifies a color in The Color by HSL value.

## Endpoint

- **Method:** `GET`
- **Path:** `/id`
- **Base URL:** `https://www.thecolorapi.com`
- **Official documentation:** [Identify Color By HSL](https://www.thecolorapi.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hsl` | query | `string` | yes | Valid HSL color, such as 215,100%,34% or hsl(215,100%,34%). |
