# Get Department By External ID with TalentLyft

Retrieves a department in TalentLyft by external ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/departments/:id/external`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Department By External ID](https://developers.talentlyft.com/customer-api-reference/departments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The TalentLyft department external ID. |
