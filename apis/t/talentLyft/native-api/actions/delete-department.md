# Delete Department with TalentLyft

Deletes an existing department from TalentLyft.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/departments/:id`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Delete Department](https://developers.talentlyft.com/customer-api-reference/departments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TalentLyft department ID. |
