# Get Rejection Reasons with TalentLyft

Retrieves rejection reasons from TalentLyft.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/rejection_reasons`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Rejection Reasons](https://developers.talentlyft.com/customer-api-reference/rejection-reasons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contains` | query | `string` | no | Filter rejection reasons whose name contains this value. |
