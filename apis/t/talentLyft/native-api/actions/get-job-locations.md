# Get Job Locations with TalentLyft

Retrieves public job locations from TalentLyft.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/jobs/locations`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Job Locations](https://developers.talentlyft.com/customer-api-reference/jobs)
