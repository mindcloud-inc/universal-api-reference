# Get Department with TalentLyft

Retrieves a department from TalentLyft.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/departments/:id`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Department](https://developers.talentlyft.com/customer-api-reference/departments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TalentLyft department ID. |
