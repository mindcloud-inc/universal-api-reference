# Get Rejection Reason with TalentLyft

Retrieves a rejection reason from TalentLyft.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/rejection_reasons/:id`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Rejection Reason](https://developers.talentlyft.com/customer-api-reference/rejection-reasons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TalentLyft rejection reason ID. |
