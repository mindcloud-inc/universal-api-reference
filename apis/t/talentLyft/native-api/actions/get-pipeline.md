# Get Pipeline with TalentLyft

Retrieves a pipeline from TalentLyft.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/pipelines/:id`
- **Base URL:** `https://api.talentlyft.com`
- **Official documentation:** [Get Pipeline](https://developers.talentlyft.com/customer-api-reference/pipelines)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TalentLyft pipeline ID. |
