# Get Bike Point with Transport for London

Retrieves a bike point from Transport for London.

## Endpoint

- **Method:** `GET`
- **Path:** `/BikePoint/:id`
- **Base URL:** `https://api.tfl.gov.uk`
- **Official documentation:** [Get Bike Point](https://api.tfl.gov.uk/swagger/ui/index.html#!/BikePoint/BikePoint_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bike point ID, such as BikePoints_1. |
