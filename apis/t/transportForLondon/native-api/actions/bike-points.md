# List Bike Points with Transport for London

Retrieves bike points from Transport for London.

## Endpoint

- **Method:** `GET`
- **Path:** `/BikePoint`
- **Base URL:** `https://api.tfl.gov.uk`
- **Official documentation:** [List Bike Points](https://api.tfl.gov.uk/swagger/ui/index.html#!/BikePoint/BikePoint_GetAll)
