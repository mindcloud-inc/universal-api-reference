# List Journey Modes with Transport for London

Retrieves journey planner modes from Transport for London.

## Endpoint

- **Method:** `GET`
- **Path:** `/Journey/Meta/Modes`
- **Base URL:** `https://api.tfl.gov.uk`
- **Official documentation:** [List Journey Modes](https://api.tfl.gov.uk/swagger/ui/index.html#!/Journey/Journey_Meta)
