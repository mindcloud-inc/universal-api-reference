# Search TfL with Transport for London

Finds site results in Transport for London by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/Search`
- **Base URL:** `https://api.tfl.gov.uk`
- **Official documentation:** [Search TfL](https://api.tfl.gov.uk/swagger/ui/index.html#!/Search/Search_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Site search text. |
