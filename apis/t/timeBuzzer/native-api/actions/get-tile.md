# Get Tile with timeBuzzer

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/tiles/:id`
- **Base URL:** `https://my.timebuzzer.com`
- **Official documentation:** [Get Tile](https://my.timebuzzer.com/doc/#api-Tiles-GetTileById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The tile ID. |
