# Delete Webhook Configuration with timeBuzzer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open-api/webhooks/:id`
- **Base URL:** `https://my.timebuzzer.com`
- **Official documentation:** [Delete Webhook Configuration](https://my.timebuzzer.com/doc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The webhook ID. |
