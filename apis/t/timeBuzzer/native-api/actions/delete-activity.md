# Delete Activity with timeBuzzer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open-api/activities/:id`
- **Base URL:** `https://my.timebuzzer.com`
- **Official documentation:** [Delete Activity](https://my.timebuzzer.com/doc/#api-Activities-DeleteActivity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The activity ID. |
