# Delete Driver By Id with Track-POD

Deletes an existing driver from Track-POD by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Driver/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Delete Driver By Id](https://api.track-pod.com/index.html#/Driver/DeleteDriverById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD driver identifier. |
