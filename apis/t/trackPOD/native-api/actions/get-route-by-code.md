# Get Route By Code with Track-POD

Retrieves a route from Track-POD by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/Route/Code/:code`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Route By Code](https://api.track-pod.com/index.html#/Route/GetRouteByCode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Route code |
