# Get Order By Id with Track-POD

Retrieves an order from Track-POD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Order/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Order By Id](https://api.track-pod.com/index.html#/Order/GetOrderById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD unique identifier for the order. |
