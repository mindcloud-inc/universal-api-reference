# Get Order By Number with Track-POD

Retrieves an order from Track-POD by number.

## Endpoint

- **Method:** `GET`
- **Path:** `/Order/Number/:number`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Order By Number](https://api.track-pod.com/index.html#/Order/GetOrderByNumber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | path | `string` | yes | Order number in Track-POD. |
