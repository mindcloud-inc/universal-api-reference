# Delete Route By Id with Track-POD

Deletes an existing route from Track-POD by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Route/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Delete Route By Id](https://api.track-pod.com/index.html#/Route/DeleteRouteById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD route identifier. |
