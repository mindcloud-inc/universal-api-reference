# Get Route Track By Id with Track-POD

Retrieves route tracking details from Track-POD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Route/Track/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Route Track By Id](https://api.track-pod.com/index.html#/Route/GetRouteTrackById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD unique identifier for the route track. |
