# Delete Vehicle By Id with Track-POD

Deletes an existing vehicle from Track-POD by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Vehicle/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Delete Vehicle By Id](https://api.track-pod.com/index.html#/Vehicle/DeleteVehicle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD vehicle identifier. |
