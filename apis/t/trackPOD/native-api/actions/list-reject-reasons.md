# List Reject Reasons with Track-POD

Retrieves reject reasons from Track-POD.

## Endpoint

- **Method:** `GET`
- **Path:** `/RejectReason`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [List Reject Reasons](https://api.track-pod.com/index.html#/RejectReason/GetRejectReasonsList)
