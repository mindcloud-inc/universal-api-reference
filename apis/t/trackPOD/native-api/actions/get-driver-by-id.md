# Get Driver By Id with Track-POD

Retrieves a driver from Track-POD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Driver/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Driver By Id](https://api.track-pod.com/index.html#/Driver/GetDriverById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD unique identifier for the driver. |
