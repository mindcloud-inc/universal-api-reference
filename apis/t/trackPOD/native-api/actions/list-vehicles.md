# List Vehicles with Track-POD

Retrieves vehicles from Track-POD.

## Endpoint

- **Method:** `GET`
- **Path:** `/Vehicle`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [List Vehicles](https://api.track-pod.com/index.html#/Vehicle/GetVehicles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | query | `string` | no | Optional vehicle number to filter the results. |
