# Get Route Track By Code with Track-POD

Retrieves route tracking details from Track-POD by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/Route/Track/Code/:code`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Route Track By Code](https://api.track-pod.com/index.html#/Route/GetRouteTrackByCode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Route code |
