# Get Vehicle By Id with Track-POD

Retrieves a vehicle from Track-POD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Vehicle/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Vehicle By Id](https://api.track-pod.com/index.html#/Vehicle/GetVehicle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Track-POD unique identifier for the vehicle. |
