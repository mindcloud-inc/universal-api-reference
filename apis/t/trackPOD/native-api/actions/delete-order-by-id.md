# Delete Order By Id with Track-POD

Deletes an existing order from Track-POD by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Order/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Delete Order By Id](https://api.track-pod.com/index.html#/Order/DeleteOrderById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD order identifier. |
