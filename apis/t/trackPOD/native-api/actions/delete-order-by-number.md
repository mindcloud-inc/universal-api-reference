# Delete Order By Number with Track-POD

Deletes an existing order from Track-POD by number.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Order/Number/:number`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Delete Order By Number](https://api.track-pod.com/index.html#/Order/DeleteOrderByNumber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | path | `string` | yes | Order number |
