# Get Route By Id with Track-POD

Retrieves a route from Track-POD by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Route/Id/:id`
- **Base URL:** `https://api.track-pod.com`
- **Official documentation:** [Get Route By Id](https://api.track-pod.com/index.html#/Route/GetRouteById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Track-POD unique identifier for the route. |
