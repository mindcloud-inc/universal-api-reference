# Get File with TimelinesAI

Retrieves details for an uploaded TimelinesAI file.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{file_uid}`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [Get File](https://timelinesai.mintlify.app/public-api-reference/get-details-and-temporary-download-url-for-a-specified-uploaded-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_uid` | path | `string` | yes | UID of the uploaded file in the TimelinesAI workspace. |
