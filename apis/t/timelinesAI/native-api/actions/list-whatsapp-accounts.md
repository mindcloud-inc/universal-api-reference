# List WhatsApp Accounts with TimelinesAI

Retrieves WhatsApp accounts connected in TimelinesAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/whatsapp_accounts`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [List WhatsApp Accounts](https://timelinesai.mintlify.app/public-api-reference/list-whatsapp-accounts-connected-in-your-timelinesai-workspace)
