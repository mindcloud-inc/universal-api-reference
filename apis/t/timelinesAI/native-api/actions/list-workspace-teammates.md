# List Workspace Teammates with TimelinesAI

Retrieves teammates from your TimelinesAI workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/teammates`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [List Workspace Teammates](https://timelinesai.mintlify.app/public-api-reference/list-all-teammates-in-the-workspace)
