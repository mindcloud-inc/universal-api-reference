# Get Workspace Quotas with TimelinesAI

Retrieves workspace quotas and usage from TimelinesAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotas`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [Get Workspace Quotas](https://timelinesai.mintlify.app/public-api-reference/all-current-quotas-and-utilization-stats)
