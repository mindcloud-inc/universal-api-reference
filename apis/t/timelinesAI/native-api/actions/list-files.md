# List Files with TimelinesAI

Retrieves uploaded files from your TimelinesAI workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [List Files](https://timelinesai.mintlify.app/public-api-reference/list-files-uploaded-in-your-timelinesai-workspace)
