# List Webhooks with TimelinesAI

Retrieves webhook subscriptions from your TimelinesAI workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [List Webhooks](https://timelinesai.mintlify.app/public-api-reference/list-webhooks)
