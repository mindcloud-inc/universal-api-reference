# Get Message with TimelinesAI

Retrieves details for a TimelinesAI message.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/{message_uid}`
- **Base URL:** `https://app.timelines.ai/integrations/api`
- **Official documentation:** [Get Message](https://timelinesai.mintlify.app/public-api-reference/get-the-details-of-a-message-specified-by-the-messages-uid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `message_uid` | path | `string` | yes | UID of the message in the TimelinesAI workspace. |
