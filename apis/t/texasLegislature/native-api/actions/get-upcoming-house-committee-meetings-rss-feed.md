# Get Upcoming House Committee Meetings RSS Feed with Texas Legislature

Retrieves upcoming House committee meetings from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=upcomingmeetingshouse`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Upcoming House Committee Meetings RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
