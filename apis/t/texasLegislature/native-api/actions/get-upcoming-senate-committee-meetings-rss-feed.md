# Get Upcoming Senate Committee Meetings RSS Feed with Texas Legislature

Retrieves upcoming Senate committee meetings from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=upcomingmeetingssenate`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Upcoming Senate Committee Meetings RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
