# Get Today's Bill Analyses RSS Feed with Texas Legislature

Retrieves today's bill analyses from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=todaysbillanalyses`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Today's Bill Analyses RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
