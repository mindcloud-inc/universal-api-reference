# Get Today's Passed Bills RSS Feed with Texas Legislature

Retrieves today's passed bills from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=todaysbillspassed`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Today's Passed Bills RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
