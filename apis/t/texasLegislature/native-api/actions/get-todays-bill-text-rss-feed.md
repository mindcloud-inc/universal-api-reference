# Get Today's Bill Text RSS Feed with Texas Legislature

Retrieves today's bill text from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=todaysbilltext`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Today's Bill Text RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
