# Get Today's Fiscal Notes RSS Feed with Texas Legislature

Retrieves today's fiscal notes from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=todaysfiscalnotes`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Today's Fiscal Notes RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
