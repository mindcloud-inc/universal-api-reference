# Get Upcoming House Calendars RSS Feed with Texas Legislature

Retrieves upcoming House calendars from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=upcomingcalendarshouse`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Upcoming House Calendars RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
