# Get Today's Senate Filed Bills RSS Feed with Texas Legislature

Retrieves today's Senate-filed bills from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=todaysfiledsenate`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Today's Senate Filed Bills RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
