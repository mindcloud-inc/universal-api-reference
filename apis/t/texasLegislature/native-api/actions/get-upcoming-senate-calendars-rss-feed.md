# Get Upcoming Senate Calendars RSS Feed with Texas Legislature

Retrieves upcoming Senate calendars from Texas Legislature.

## Endpoint

- **Method:** `GET`
- **Path:** `/MyTLO/RSS/RSS.aspx?Type=upcomingcalendarssenate`
- **Base URL:** `https://capitol.texas.gov`
- **Official documentation:** [Get Upcoming Senate Calendars RSS Feed](https://capitol.texas.gov/MyTLO/RSS/rssFeeds.aspx)
