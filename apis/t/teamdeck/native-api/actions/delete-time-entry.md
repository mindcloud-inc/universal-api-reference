# Delete Time Entry with Teamdeck

Deletes an existing time entry from Teamdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/time-entries/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Delete Time Entry](https://teamdeck.io/developers/api#operation/timeEntryDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck time entry ID. |
