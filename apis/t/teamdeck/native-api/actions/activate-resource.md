# Activate Resource with Teamdeck

Activates an existing resource in Teamdeck.

## Endpoint

- **Method:** `PUT`
- **Path:** `/resources/:id/activate`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Activate Resource](https://teamdeck.io/developers/api#operation/activateResource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck resource ID. |
