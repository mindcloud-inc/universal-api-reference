# Delete Vacation with Teamdeck

Deletes an existing vacation from Teamdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vacations/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Delete Vacation](https://teamdeck.io/developers/api#operation/vacationDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck vacation ID. |
