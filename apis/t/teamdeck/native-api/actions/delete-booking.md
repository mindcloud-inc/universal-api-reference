# Delete Booking with Teamdeck

Deletes an existing booking from Teamdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Delete Booking](https://teamdeck.io/developers/api#operation/bookingDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck booking ID. |
