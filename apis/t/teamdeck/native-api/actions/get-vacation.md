# Get Vacation with Teamdeck

Retrieves a vacation from your Teamdeck organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/vacations/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Get Vacation](https://teamdeck.io/developers/api#operation/vacationDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck vacation ID. |
