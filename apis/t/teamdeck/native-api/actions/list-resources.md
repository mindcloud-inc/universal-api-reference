# List Resources with Teamdeck

Retrieves resources from your Teamdeck organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [List Resources](https://teamdeck.io/developers/api#operation/resourcesList)

## Capabilities

This operation supports [sorting](../README.md#sorting).
