# Get Booking with Teamdeck

Retrieves a booking from your Teamdeck organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Get Booking](https://teamdeck.io/developers/api#operation/bookingDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck booking ID. |
