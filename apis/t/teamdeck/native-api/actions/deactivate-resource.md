# Deactivate Resource with Teamdeck

Deactivates an existing resource in Teamdeck.

## Endpoint

- **Method:** `PUT`
- **Path:** `/resources/:id/deactivate`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Deactivate Resource](https://teamdeck.io/developers/api#operation/deactivateResource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck resource ID. |
