# Get Resource with Teamdeck

Retrieves a resource from your Teamdeck organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:id`
- **Base URL:** `https://api.teamdeck.io/v1`
- **Official documentation:** [Get Resource](https://teamdeck.io/developers/api#operation/resourceDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Teamdeck resource ID. |
