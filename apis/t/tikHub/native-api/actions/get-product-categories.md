# Get Product Categories with TikHub

Retrieves TikTok Shop product categories from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/shop/web/fetch_products_category_list`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Product Categories](https://api.tikhub.io/#/TikTok-Shop-Web-API/fetch_products_category_list_api_v1_tiktok_shop_web_fetch_products_category_list_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `region` | query | `string` | no | Region code |
