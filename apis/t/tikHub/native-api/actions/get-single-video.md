# Get Single Video with TikHub

Retrieves a TikTok video from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/app/v3/fetch_one_video`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Single Video](https://api.tikhub.io/#/TikTok-App-V3-API/fetch_one_video_api_v1_tiktok_app_v3_fetch_one_video_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `aweme_id` | query | `string` | yes | Video id |
