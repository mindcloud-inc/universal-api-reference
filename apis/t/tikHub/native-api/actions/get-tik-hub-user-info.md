# Get TikHub User Info with TikHub

Retrieves the current TikHub user info.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tikhub/user/get_user_info`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get TikHub User Info](https://api.tikhub.io/#/TikHub-User-API/get_user_info_api_v1_tikhub_user_get_user_info_get)
