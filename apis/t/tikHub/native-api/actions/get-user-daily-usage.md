# Get User Daily Usage with TikHub

Retrieves daily API usage from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tikhub/user/get_user_daily_usage`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get User Daily Usage](https://api.tikhub.io/#/TikHub-User-API/get_user_daily_usage_api_v1_tikhub_user_get_user_daily_usage_get)
