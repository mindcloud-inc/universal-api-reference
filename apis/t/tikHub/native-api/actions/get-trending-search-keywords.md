# Get Trending Search Keywords with TikHub

Retrieves trending TikTok search keywords from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/web/fetch_trending_searchwords`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Trending Search Keywords](https://api.tikhub.io/#/TikTok-Web-API/fetch_trending_searchwords_api_v1_tiktok_web_fetch_trending_searchwords_get)
