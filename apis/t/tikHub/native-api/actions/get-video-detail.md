# Get Video Detail with TikHub

Retrieves TikTok video details from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/web/fetch_post_detail`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Video Detail](https://api.tikhub.io/#/TikTok-Web-API/fetch_post_detail_api_v1_tiktok_web_fetch_post_detail_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | query | `string` | yes | Video id |
