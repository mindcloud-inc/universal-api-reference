# Get User IDs by Username with TikHub

Retrieves TikTok user IDs from TikHub by username.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/app/v3/get_user_id_and_sec_user_id_by_username`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get User IDs by Username](https://api.tikhub.io/#/TikTok-App-V3-API/get_user_id_and_sec_user_id_by_username_api_v1_tiktok_app_v3_get_user_id_and_sec_user_id_by_username_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | query | `string` | yes | Username |
