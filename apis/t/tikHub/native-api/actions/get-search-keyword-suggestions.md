# Get Search Keyword Suggestions with TikHub

Finds TikTok search keyword suggestions in TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tiktok/web/fetch_search_keyword_suggest`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Search Keyword Suggestions](https://api.tikhub.io/#/TikTok-Web-API/fetch_search_keyword_suggest_api_v1_tiktok_web_fetch_search_keyword_suggest_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | yes | Search keyword |
