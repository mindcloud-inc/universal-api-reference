# Get Tiered Discount Info with TikHub

Retrieves tiered discount information from TikHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tikhub/user/get_tiered_discount_info`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Tiered Discount Info](https://api.tikhub.io/#/TikHub-User-API/get_tiered_discount_info_api_v1_tikhub_user_get_tiered_discount_info_get)
