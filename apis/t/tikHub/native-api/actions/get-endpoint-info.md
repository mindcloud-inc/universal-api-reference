# Get Endpoint Info with TikHub

Retrieves details for a TikHub endpoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tikhub/user/get_endpoint_info`
- **Base URL:** `https://api.tikhub.io`
- **Official documentation:** [Get Endpoint Info](https://api.tikhub.io/#/TikHub-User-API/get_endpoint_info_api_v1_tikhub_user_get_endpoint_info_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endpoint` | query | `string` | yes | Requested endpoint |
