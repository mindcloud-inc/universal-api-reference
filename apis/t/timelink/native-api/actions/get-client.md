# Get Client with Timelink

Retrieves a client from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get Client](https://api.timelink.io/documentation#/Clients/get_api_v1_clients__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
