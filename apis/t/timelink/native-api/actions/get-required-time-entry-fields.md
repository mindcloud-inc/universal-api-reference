# Get Required Time Entry Fields with Timelink

Retrieves required time entry fields from Timelink.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeEntries/fieldsRequired`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get Required Time Entry Fields](https://api.timelink.io/documentation#/Time%20Entries/get_api_v1_timeEntries_fieldsRequired)
