# Search Projects with Timelink

Finds projects in the Timelink workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/search`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Search Projects](https://api.timelink.io/documentation#/Projects/post_api_v1_projects_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `client_id` | body | `string` | no |
| `search` | body | `string` | no |
