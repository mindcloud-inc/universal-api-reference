# List Clients with Timelink

Retrieves clients from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Clients](https://api.timelink.io/documentation#/Clients/get_api_v1_clients)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | query | `string` | no |
