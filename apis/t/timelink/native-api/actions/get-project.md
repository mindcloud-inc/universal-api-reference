# Get Project with Timelink

Retrieves a project from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get Project](https://api.timelink.io/documentation#/Projects/get_api_v1_projects__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
