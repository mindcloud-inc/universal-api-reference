# Get Service with Timelink

Retrieves a service from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get Service](https://api.timelink.io/documentation#/Services/get_api_v1_services__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
