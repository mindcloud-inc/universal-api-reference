# Search Services with Timelink

Finds services in the Timelink workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/services/search`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Search Services](https://api.timelink.io/documentation#/Services/post_api_v1_services_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | body | `string` | no |
