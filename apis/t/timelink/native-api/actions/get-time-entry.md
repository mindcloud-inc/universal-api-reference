# Get Time Entry with Timelink

Retrieves a time entry from Timelink.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeEntries/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get Time Entry](https://api.timelink.io/documentation#/Time%20Entries/get_api_v1_timeEntries__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
