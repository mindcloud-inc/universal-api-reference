# List Time Entry Conflicts with Timelink

Retrieves time entry conflicts from Timelink.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeEntries/conflicts`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Time Entry Conflicts](https://api.timelink.io/documentation#/Time%20Entries/get_api_v1_timeEntries_conflicts)
