# List Services with Timelink

Retrieves services from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/services`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Services](https://api.timelink.io/documentation#/Services/get_api_v1_services)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | query | `string` | no |
