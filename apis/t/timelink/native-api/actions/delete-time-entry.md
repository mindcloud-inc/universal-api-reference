# Delete Time Entry with Timelink

Deletes an existing time entry from Timelink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/timeEntries/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Delete Time Entry](https://api.timelink.io/documentation#/Time%20Entries/delete_api_v1_timeEntries__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
