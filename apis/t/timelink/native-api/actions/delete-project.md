# Delete Project with Timelink

Deletes an existing project from Timelink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Delete Project](https://api.timelink.io/documentation#/Projects/delete_api_v1_projects__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
