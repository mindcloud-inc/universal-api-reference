# Search Time Entries with Timelink

Finds time entries in the Timelink workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/timeEntries/search`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Search Time Entries](https://api.timelink.io/documentation#/Time%20Entries/post_api_v1_timeEntries_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | body | `string` | no |
| `search` | body | `string` | no |
