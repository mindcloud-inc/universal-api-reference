# List Active Time Entries with Timelink

Retrieves active time entries from Timelink.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeEntries/active`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Active Time Entries](https://api.timelink.io/documentation#/Time%20Entries/get_api_v1_timeEntries_active)
