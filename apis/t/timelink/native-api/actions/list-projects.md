# List Projects with Timelink

Retrieves projects from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Projects](https://api.timelink.io/documentation#/Projects/get_api_v1_projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | query | `string` | no |
