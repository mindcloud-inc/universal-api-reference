# Update Company Settings with Timelink

Updates company settings in the Timelink workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/company/settings`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Update Company Settings](https://api.timelink.io/documentation#/Company/patch_api_v1_company_settings)
