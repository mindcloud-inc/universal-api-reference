# List Time Entries with Timelink

Retrieves time entries from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeEntries`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [List Time Entries](https://api.timelink.io/documentation#/Time%20Entries/get_api_v1_timeEntries)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | query | `string` | no |
| `search` | query | `string` | no |
