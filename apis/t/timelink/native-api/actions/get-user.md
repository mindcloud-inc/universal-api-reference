# Get User with Timelink

Retrieves a user from the Timelink workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Get User](https://api.timelink.io/documentation#/Users/get_api_v1_users__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Timelink user ID. |
