# Delete Service with Timelink

Deletes an existing service from Timelink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/services/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Delete Service](https://api.timelink.io/documentation#/Services/delete_api_v1_services__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
