# Search Clients with Timelink

Finds clients in the Timelink workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients/search`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Search Clients](https://api.timelink.io/documentation#/Clients/post_api_v1_clients_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | body | `string` | no |
