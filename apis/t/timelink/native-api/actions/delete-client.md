# Delete Client with Timelink

Deletes an existing client from Timelink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clients/:id`
- **Base URL:** `https://api.timelink.io/api/v1`
- **Official documentation:** [Delete Client](https://api.timelink.io/documentation#/Clients/delete_api_v1_clients__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
