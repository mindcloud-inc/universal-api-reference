# List Prospects with Teach 'n Go

Retrieves prospects from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/globalApis/prospect_list`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Prospects](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
