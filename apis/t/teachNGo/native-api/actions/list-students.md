# List Students with Teach 'n Go

Retrieves students from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/globalApis/student_list`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Students](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
