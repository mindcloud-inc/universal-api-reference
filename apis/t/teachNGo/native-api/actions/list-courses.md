# List Courses with Teach 'n Go

Retrieves courses from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/globalApis/course_list`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Courses](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
