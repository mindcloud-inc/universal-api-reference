# List Payments with Teach 'n Go

Retrieves payments from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/payments`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Payments](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
