# List Student Attendance with Teach 'n Go

Retrieves student attendance records from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/globalApis/students_attendance`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Student Attendance](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
