# List Student Behaviours with Teach 'n Go

Retrieves student behaviour records from Teach 'n Go.

## Endpoint

- **Method:** `POST`
- **Path:** `/globalApis/student_behaviours`
- **Base URL:** `https://app.teachngo.com`
- **Official documentation:** [List Student Behaviours](https://intercom.help/teach-n-go/en/articles/8727904-teach-n-go-api-endpoints)
