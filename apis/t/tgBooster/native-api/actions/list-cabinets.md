# List Cabinets with TgBooster

Retrieves Telegram Ads cabinets from TgBooster.

## Endpoint

- **Method:** `POST`
- **Path:** `/cabinets`
- **Base URL:** `https://api.tgbooster.ru/api`
- **Official documentation:** [List Cabinets](https://tgbooster.gitbook.io/tgbooster/api/api-metody#poluchenie-spiska-kabinetov)
