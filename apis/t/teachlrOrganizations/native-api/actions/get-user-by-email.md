# Get User by Email with Teachlr Organizations

## Endpoint

- **Method:** `GET`
- **Path:** `/users/query`
- **Base URL:** `https://api.teachlr.com/mindcloudteachlr337933/api`
- **Official documentation:** [Get User by Email](https://soporte.teachlr.com/base-de-conocimientos/como-obtener-la-informacion-de-un-usuario-de-una-escuela-usando-el-api-de-teachlr-organizaciones-usando-un-campo-identificador-del-usuario/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address of the Teachlr user to retrieve. |
