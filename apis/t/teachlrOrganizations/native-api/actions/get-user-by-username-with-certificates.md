# Get User By Username With Certificates with Teachlr Organizations

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username`
- **Base URL:** `https://api.teachlr.com/mindcloudteachlr337933/api`
- **Official documentation:** [Get User By Username With Certificates](https://soporte.teachlr.com/base-de-conocimientos/como-obtener-la-informacion-de-un-usuario-de-una-escuela-usando-el-api-de-teachlr-organizaciones/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Teachlr username of the user to retrieve. |
