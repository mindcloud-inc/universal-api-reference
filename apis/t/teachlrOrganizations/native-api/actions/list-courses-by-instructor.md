# List Courses By Instructor with Teachlr Organizations

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/available`
- **Base URL:** `https://api.teachlr.com/mindcloudteachlr337933/api`
- **Official documentation:** [List Courses By Instructor](https://soporte.teachlr.com/base-de-conocimientos/listar-los-cursos-de-una-escuela-usando-el-api-de-teachlr-organizaciones/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instructor` | query | `string` | yes | Username of the instructor whose courses should be listed. |
