# Delete Meeting with Teachlr Organizations

## Endpoint

- **Method:** `DELETE`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://api.teachlr.com/mindcloudteachlr337933/api`
- **Official documentation:** [Delete Meeting](https://soporte.teachlr.com/base-de-conocimientos/creacion-actualizacion-y-eliminacion-de-videoconferencias-para-un-usuario-de-una-escuela-usando-el-api-de-teachlr-organizaciones-2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meeting_id` | path | `string` | yes | Identifier of the meeting to delete. |
