# List Project Updates with Teamwork Projects

Retrieves project updates from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/updates.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Project Updates](https://apidocs.teamwork.com/docs/teamwork/v3/project-updates/get-projects-api-v3-projects-updates-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
