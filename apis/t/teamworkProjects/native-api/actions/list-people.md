# List People with Teamwork Projects

Retrieves all people from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/people.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List People](https://apidocs.teamwork.com/docs/teamwork/v3/people/get-projects-api-v3-people-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
