# List Projects with Teamwork Projects

Retrieves all projects from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Projects](https://apidocs.teamwork.com/docs/teamwork/v3/projects/get-projects-api-v3-projects-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
