# List Messages with Teamwork Projects

Retrieves all messages from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Messages](https://apidocs.teamwork.com/docs/teamwork/v3/messages/get-projects-api-v3-messages-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
