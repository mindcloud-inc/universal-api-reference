# List Task Lists with Teamwork Projects

Retrieves task lists from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasklists`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Task Lists](https://apidocs.teamwork.com/docs/teamwork/v3/task-lists/get-projects-api-v3-tasklists)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
