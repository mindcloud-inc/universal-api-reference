# List Notebooks with Teamwork Projects

Retrieves all notebooks from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/notebooks.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Notebooks](https://apidocs.teamwork.com/docs/teamwork/v3/notebooks/get-projects-api-v3-notebooks-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
