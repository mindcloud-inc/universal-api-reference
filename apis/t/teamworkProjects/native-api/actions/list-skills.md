# List Skills with Teamwork Projects

Retrieves all skills from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/skills.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Skills](https://apidocs.teamwork.com/docs/teamwork/v3/skills/get-projects-api-v3-skills-json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
