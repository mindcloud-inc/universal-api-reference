# Get Notebook with Teamwork Projects

Retrieves detailed notebook information from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/notebooks/{{notebookId}}.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [Get Notebook](https://apidocs.teamwork.com/docs/teamwork/v3/notebooks/get-projects-api-v3-notebooks-notebook-id-json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notebookId` | path | `number` | yes | Teamwork notebook ID. |
