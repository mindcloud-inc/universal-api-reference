# List Companies with Teamwork Projects

Retrieves all companies from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Companies](https://apidocs.teamwork.com/docs/teamwork/v3/companies/get-projects-api-v3-companies-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
