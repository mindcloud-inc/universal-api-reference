# List Tasks with Teamwork Projects

Retrieves all tasks from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Tasks](https://apidocs.teamwork.com/docs/teamwork/v3/tasks/get-projects-api-v3-tasks-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
