# List Milestones with Teamwork Projects

Retrieves all milestones from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/milestones.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Milestones](https://apidocs.teamwork.com/docs/teamwork/v3/milestones/get-projects-api-v3-milestones-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
