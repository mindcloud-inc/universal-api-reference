# List Comments with Teamwork Projects

Retrieves all comments from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Comments](https://apidocs.teamwork.com/docs/teamwork/v3/comments/get-projects-api-v3-comments-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
