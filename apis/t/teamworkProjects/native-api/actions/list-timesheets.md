# List Timesheets with Teamwork Projects

Retrieves all timesheets from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/timesheets.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Timesheets](https://apidocs.teamwork.com/docs/teamwork/v3/timesheets/get-projects-api-v3-timesheets-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
