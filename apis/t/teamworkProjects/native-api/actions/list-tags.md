# List Tags with Teamwork Projects

Retrieves all tags from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Tags](https://apidocs.teamwork.com/docs/teamwork/v3/tags/get-projects-api-v3-tags-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
