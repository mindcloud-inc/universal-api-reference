# List Time Entries with Teamwork Projects

Retrieves time entries from Teamwork Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/time.json`
- **Base URL:** `{apiEndPoint}projects/api/v3`
- **Official documentation:** [List Time Entries](https://apidocs.teamwork.com/docs/teamwork/v3/time-tracking/get-projects-api-v3-time-json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
