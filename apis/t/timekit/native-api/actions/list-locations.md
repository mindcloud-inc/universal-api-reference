# List Locations with Timekit

Lists all available locations in Timekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [List Locations](https://developers.timekit.io/reference/list-all-locations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `include` | query | `string` | no |
| `search` | query | `string` | no |
