# Update Project with Timekit

Updates an existing project in Timekit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Update Project](https://developers.timekit.io/reference/update-a-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `availability` | body | `object` | no |
| `id` | path | `string` | yes |
