# Delete Resource with Timekit

Deletes an existing resource from Timekit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/resources/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Delete Resource](https://developers.timekit.io/reference/delete-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the specific resource. |
