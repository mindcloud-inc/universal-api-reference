# Delete Booking with Timekit

Deletes an existing booking from Timekit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Delete Booking](https://developers.timekit.io/reference/delete-a-booking)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
