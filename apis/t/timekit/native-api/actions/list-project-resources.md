# List Project Resources with Timekit

Lists resources for a project in Timekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id/resources`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [List Project Resources](https://developers.timekit.io/reference/get-a-projects-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
