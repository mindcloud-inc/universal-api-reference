# Get Resource with Timekit

Retrieves details for a resource from Timekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Get Resource](https://developers.timekit.io/reference/resourcesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the specific resource. |
