# Delete Project with Timekit

Deletes an existing project from Timekit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Delete Project](https://developers.timekit.io/reference/projectsid-2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
