# Get Booking with Timekit

Retrieves details for a booking from Timekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [Get Booking](https://developers.timekit.io/reference/bookingsid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `include` | query | `string` | no |
