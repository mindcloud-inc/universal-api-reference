# List Bookings with Timekit

Lists all existing bookings in Timekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://api.timekit.io/v2`
- **Official documentation:** [List Bookings](https://developers.timekit.io/reference/bookings-2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `end` | query | `string` | no |
| `include` | query | `string` | no |
| `limit` | query | `number` | no |
| `orderBy` | query | `string` | no |
| `page` | query | `number` | no |
| `search` | query | `string` | no |
| `sortedBy` | query | `string` | no |
| `start` | query | `string` | no |
