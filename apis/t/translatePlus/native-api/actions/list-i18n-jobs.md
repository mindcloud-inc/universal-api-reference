# List I18n Jobs with TranslatePlus

Retrieves i18n translation jobs from TranslatePlus.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/translate/i18n/jobs`
- **Base URL:** `https://api.translateplus.io`
- **Official documentation:** [List I18n Jobs](https://docs.translateplus.io/reference/v2/i18n/i18n-list-jobs)
