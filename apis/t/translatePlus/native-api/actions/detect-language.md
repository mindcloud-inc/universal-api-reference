# Detect Language with TranslatePlus

Detects the language of provided text in TranslatePlus.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/language_detect`
- **Base URL:** `https://api.translateplus.io`
- **Official documentation:** [Detect Language](https://docs.translateplus.io/reference/v2/language/detect-language)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `text` | body | `string` | yes |
