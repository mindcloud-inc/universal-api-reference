# Get Warehouse List with TikTok Shop

This API retrieves all warehouse information associated with the seller. Warehouse information includes name, status, address, and other details.

## Endpoint

- **Method:** `GET`
- **Path:** `logistics/202309/warehouses`
- **Base URL:** `https://open-api.tiktokglobalshop.com/`
- **Official documentation:** [Get Warehouse List](https://partner.tiktokshop.com/docv2/page/get-warehouse-list-202309)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shop_cipher` | query | `list<string>` | no |
