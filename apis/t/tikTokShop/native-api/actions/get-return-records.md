# Get Return Records with TikTok Shop

## Endpoint

- **Method:** `GET`
- **Path:** `/return_refund/202309/returns/:return_id/records`
- **Base URL:** `https://open-api.tiktokglobalshop.com/`
- **Official documentation:** [Get Return Records](https://partner.tiktokshop.com/docv2/page/get-return-records-202309)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `return_id` | path | `string` | yes |
| `shop_cipher` | query | `string` | yes |
| `locale` | query | `string` | no |
