# List Timeslots with Tailwind

Retrieves publishing timeslots from Tailwind.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/timeslots`
- **Base URL:** `https://api-v1.tailwind.ai`
- **Official documentation:** [List Timeslots](https://api-docs.tailwind.ai/rest-api/operations/v1accountsaccountidtimeslots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Pinterest account ID. |
