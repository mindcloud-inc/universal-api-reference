# Get Post with Tailwind

Retrieves a post from Tailwind.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/posts/:postId`
- **Base URL:** `https://api-v1.tailwind.ai`
- **Official documentation:** [Get Post](https://api-docs.tailwind.ai/rest-api/operations/v1accountsaccountidpostspostid/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Pinterest account ID. |
| `postId` | path | `string` | yes | Tailwind post ID. |
