# List Board Lists with Tailwind

Retrieves board lists from Tailwind.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/board-lists`
- **Base URL:** `https://api-v1.tailwind.ai`
- **Official documentation:** [List Board Lists](https://api-docs.tailwind.ai/rest-api/operations/v1accountsaccountidboard-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Pinterest account ID. |
