# List Boards with Tailwind

Retrieves boards from Tailwind.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:accountId/boards`
- **Base URL:** `https://api-v1.tailwind.ai`
- **Official documentation:** [List Boards](https://api-docs.tailwind.ai/rest-api/operations/v1accountsaccountidboards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Pinterest account ID. |
