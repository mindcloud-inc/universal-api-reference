# Get Question with Testlify

Retrieves a specific question from Testlify by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/question/:questionId`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [Get Question](https://docs.testlify.com/reference/get_question_details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `questionId` | path | `string` | yes | Question identifier. |
