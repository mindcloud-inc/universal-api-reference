# Create Assessment From Template with Testlify

Creates a Testlify assessment from an existing template.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/reseller/assessment`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [Create Assessment From Template](https://docs.testlify.com/reference/create_assessment_from_template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | body | `string` | yes | Template identifier. |
