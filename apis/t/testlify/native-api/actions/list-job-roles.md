# List Job Roles with Testlify

Retrieves job roles from the Testlify workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspace/jobrole`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [List Job Roles](https://docs.testlify.com/reference/get_job_roles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Search text for job roles. |
