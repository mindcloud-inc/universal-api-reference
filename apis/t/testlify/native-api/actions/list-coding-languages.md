# List Coding Languages with Testlify

Retrieves available coding languages from Testlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/assessment/coding/language`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [List Coding Languages](https://docs.testlify.com/reference/get_coding_languages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Search text for coding languages. |
