# List Test Library Types with Testlify

Retrieves available test library types from Testlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/static/testlibrary/type`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [List Test Library Types](https://docs.testlify.com/reference/get_test_library_types)
