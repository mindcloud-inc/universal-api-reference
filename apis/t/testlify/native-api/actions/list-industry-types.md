# List Industry Types with Testlify

Retrieves available industry types from Testlify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/static/testlibrary/industry/types`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [List Industry Types](https://docs.testlify.com/reference/get_industry_types)
