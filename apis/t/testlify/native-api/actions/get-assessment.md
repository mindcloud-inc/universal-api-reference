# Get Assessment with Testlify

Retrieves a specific assessment from Testlify by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/assessment/:assessmentId`
- **Base URL:** `https://api.testlify.com`
- **Official documentation:** [Get Assessment](https://docs.testlify.com/reference/get_single_assessment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assessmentId` | path | `string` | yes | Assessment identifier. |
