# List Workspaces with Teamhood

Retrieves all accessible workspaces from Teamhood.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [List Workspaces](https://api-mindcloud1.teamhood.com/swagger/index.html)
