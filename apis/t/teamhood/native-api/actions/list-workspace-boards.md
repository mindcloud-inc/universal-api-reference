# List Workspace Boards with Teamhood

Retrieves boards for a Teamhood workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/boards`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [List Workspace Boards](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | no | The Teamhood workspace ID. |
