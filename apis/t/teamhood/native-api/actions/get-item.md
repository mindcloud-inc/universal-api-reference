# Get Item with Teamhood

Retrieves item details from Teamhood by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:itemId`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Get Item](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | no | The Teamhood item ID. |
