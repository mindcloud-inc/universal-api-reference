# Update Item with Teamhood

Updates an existing item in Teamhood.

## Endpoint

- **Method:** `PUT`
- **Path:** `/items/:itemId`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Update Item](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | no | The Teamhood item ID. |
