# List Board Rows with Teamhood

Retrieves rows for a Teamhood board.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:boardId/rows`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [List Board Rows](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `boardId` | path | `string` | no | The Teamhood board ID. |
