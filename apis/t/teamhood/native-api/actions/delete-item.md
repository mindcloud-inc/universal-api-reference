# Delete Item with Teamhood

Deletes an existing item from Teamhood.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/items/:itemId`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Delete Item](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | no | The Teamhood item ID. |
