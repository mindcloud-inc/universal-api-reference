# Download Attachment Content with Teamhood

Downloads uploaded attachment content from Teamhood.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments/:id/content`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Download Attachment Content](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Teamhood attachment ID. |
