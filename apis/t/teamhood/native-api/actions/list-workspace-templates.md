# List Workspace Templates with Teamhood

Retrieves available workspace templates from Teamhood.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/workspace`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [List Workspace Templates](https://api-mindcloud1.teamhood.com/swagger/index.html)
