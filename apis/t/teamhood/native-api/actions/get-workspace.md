# Get Workspace with Teamhood

Retrieves workspace details from Teamhood by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Get Workspace](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | no | The Teamhood workspace ID. |
