# Get Attachment with Teamhood

Retrieves attachment metadata from Teamhood by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments/:id`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Get Attachment](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Teamhood attachment ID. |
