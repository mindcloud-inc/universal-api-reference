# Delete Attachment with Teamhood

Deletes an attachment from Teamhood.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attachments/:id`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [Delete Attachment](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Teamhood attachment ID. |
