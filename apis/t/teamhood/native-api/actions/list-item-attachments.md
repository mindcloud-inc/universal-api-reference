# List Item Attachments with Teamhood

Retrieves attachments for a Teamhood item.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:itemId/attachments`
- **Base URL:** `https://api-mindcloud1.teamhood.com/api/v1`
- **Official documentation:** [List Item Attachments](https://api-mindcloud1.teamhood.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | no | The Teamhood item ID. |
