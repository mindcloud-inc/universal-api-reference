# Delete Pixel Event with TikTok Conversions

Deletes an existing Pixel event from TikTok Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `/open_api/v1.3/pixel/event/delete/`
- **Base URL:** `https://business-api.tiktok.com`
- **Official documentation:** [Delete Pixel Event](https://business-api.tiktok.com/portal/docs?id=1740858862104578)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `advertiser_id` | body | `string` | yes |
| `event_id` | body | `string` | yes |
