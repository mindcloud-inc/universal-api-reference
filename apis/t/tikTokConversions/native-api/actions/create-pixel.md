# Create Pixel with TikTok Conversions

Creates a new Pixel in TikTok Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `/open_api/v1.3/pixel/create/`
- **Base URL:** `https://business-api.tiktok.com`
- **Official documentation:** [Create Pixel](https://business-api.tiktok.com/portal/docs?id=1740858779758593)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `advertiser_id` | body | `string` | yes |
| `pixel_name` | body | `string` | yes |
| `pixel_category` | body | `string` | no |
