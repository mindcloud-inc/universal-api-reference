# Delete Offline Event Set with TikTok Conversions

Deletes an existing Offline Event set from TikTok Conversions.

## Endpoint

- **Method:** `POST`
- **Path:** `/open_api/v1.3/offline/delete/`
- **Base URL:** `https://business-api.tiktok.com`
- **Official documentation:** [Delete Offline Event Set](https://business-api.tiktok.com/portal/docs?id=1765596790860802)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `advertiser_id` | body | `string` | yes |
| `event_set_id` | body | `string` | yes |
