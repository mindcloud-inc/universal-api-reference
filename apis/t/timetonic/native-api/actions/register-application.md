# Register Application with Timetonic

Creates a new application in Timetonic.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://timetonic.com/live/api.php`
- **Official documentation:** [Register Application](https://timetonic.com/live/api.php?doc=#createAppkey-doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appname` | body | `string` | yes | Application name to register in TimeTonic. |
