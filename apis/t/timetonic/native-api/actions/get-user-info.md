# Get User Info with Timetonic

Retrieves the current user information from Timetonic.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://timetonic.com/live/api.php`
- **Official documentation:** [Get User Info](https://timetonic.com/live/api.php?doc=#getUserInfo-doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sstamp` | body | `string` | no | Optional sync stamp for incremental reads. |
