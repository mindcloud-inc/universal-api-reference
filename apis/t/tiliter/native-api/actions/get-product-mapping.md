# Get Product Mapping with Tiliter

Retrieves a product mapping from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_mappings/:product_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Product Mapping](https://developer.tiliter.com/reference/get_product_mapping)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
