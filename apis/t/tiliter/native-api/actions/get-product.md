# Get Product with Tiliter

Retrieves a product from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Product](https://developer.tiliter.com/reference/get_product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
