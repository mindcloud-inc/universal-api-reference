# Delete Device with Tiliter

Deletes a device from the Tiliter Recognition API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/devices/:device_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Delete Device](https://developer.tiliter.com/reference/delete_device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `device_id` | path | `string` | yes |
