# List Archetypes with Tiliter

Retrieves archetypes from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/archetypes/`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [List Archetypes](https://developer.tiliter.com/reference/list_archetypes)
