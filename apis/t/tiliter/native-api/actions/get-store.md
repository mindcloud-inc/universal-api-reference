# Get Store with Tiliter

Retrieves a store from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/stores/:store_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Store](https://developer.tiliter.com/reference/get_store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `store_id` | path | `string` | yes |
