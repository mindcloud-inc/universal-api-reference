# Get Store Stock with Tiliter

Retrieves store stock from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/stores/:store_id/stock`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Store Stock](https://developer.tiliter.com/reference/get_store_stock)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `store_id` | path | `string` | yes |
