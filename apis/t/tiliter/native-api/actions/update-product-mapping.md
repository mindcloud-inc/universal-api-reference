# Update Product Mapping with Tiliter

Updates a product mapping in the Tiliter Recognition API.

## Endpoint

- **Method:** `PUT`
- **Path:** `/product_mappings/`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Update Product Mapping](https://developer.tiliter.com/reference/update_product_mapping)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `productId` | body | `string` | yes |
| `archetypeId` | body | `string` | yes |
