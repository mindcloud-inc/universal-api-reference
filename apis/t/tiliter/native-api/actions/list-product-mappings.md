# List Product Mappings with Tiliter

Retrieves product mappings from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_mappings/`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [List Product Mappings](https://developer.tiliter.com/reference/list_product_mappings)
