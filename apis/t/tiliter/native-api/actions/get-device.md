# Get Device with Tiliter

Retrieves a device from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/:device_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Device](https://developer.tiliter.com/reference/get_device)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `device_id` | path | `string` | yes |
