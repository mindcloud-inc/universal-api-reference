# Delete Product with Tiliter

Deletes a product from the Tiliter Recognition API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/:product_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Delete Product](https://developer.tiliter.com/reference/delete_product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
