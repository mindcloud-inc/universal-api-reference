# Get Product Sample with Tiliter

Retrieves a product sample from the Tiliter Recognition API.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id/samples/:sample_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Get Product Sample](https://developer.tiliter.com/reference/get_product_sample)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
| `sample_id` | path | `string` | yes |
