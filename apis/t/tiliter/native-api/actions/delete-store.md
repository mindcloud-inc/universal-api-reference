# Delete Store with Tiliter

Deletes a store from the Tiliter Recognition API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/stores/:store_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Delete Store](https://developer.tiliter.com/reference/delete_store)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `store_id` | path | `string` | yes |
