# Create Or Update Products Batch with Tiliter

Creates or updates products in Tiliter in a batch.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/batch`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Create Or Update Products Batch](https://developer.tiliter.com/reference/create_or_update_products_batch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `products[]` | body | `array<object>` | yes |
