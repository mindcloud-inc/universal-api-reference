# Delete Product Mapping with Tiliter

Deletes a product mapping from the Tiliter Recognition API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product_mappings/:product_id`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Delete Product Mapping](https://developer.tiliter.com/reference/delete_product_mapping)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
