# Create Transaction Events Batch with Tiliter

Creates transaction events in Tiliter in a batch.

## Endpoint

- **Method:** `POST`
- **Path:** `/recognition/transaction_events/batch`
- **Base URL:** `https://recognition.services.tiliter.com/v1/15`
- **Official documentation:** [Create Transaction Events Batch](https://developer.tiliter.com/reference/create_transaction_events_in_batch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transactionEvents[]` | body | `array<object>` | yes |
| `transactionEvents[]` | body | `array<object>` | yes |
