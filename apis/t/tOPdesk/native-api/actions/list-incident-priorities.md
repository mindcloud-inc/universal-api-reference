# List Incident Priorities with TOPdesk

Retrieves available incident priorities from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/priorities`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Priorities](https://developers.topdesk.com/explorer/?page=incident)
