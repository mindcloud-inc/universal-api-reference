# List Incidents with TOPdesk

Retrieves a list of incidents from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incidents](https://developers.topdesk.com/explorer/?page=incident)

## Capabilities

This operation supports [pagination](../README.md#pagination).
