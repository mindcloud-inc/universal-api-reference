# Get Incident by Number with TOPdesk

Retrieves an incident from TOPdesk by number.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/number/:number`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [Get Incident by Number](https://developers.topdesk.com/explorer/?page=incident)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | path | `string` | yes | Incident number. |
