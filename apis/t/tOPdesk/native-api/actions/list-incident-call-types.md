# List Incident Call Types with TOPdesk

Retrieves incident call types from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/call_types`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Call Types](https://developers.topdesk.com/explorer/?page=incident)
