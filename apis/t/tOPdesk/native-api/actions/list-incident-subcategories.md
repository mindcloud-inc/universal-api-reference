# List Incident Subcategories with TOPdesk

Retrieves incident subcategories from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/subcategories`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Subcategories](https://developers.topdesk.com/explorer/?page=incident)
