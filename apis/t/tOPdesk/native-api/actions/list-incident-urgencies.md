# List Incident Urgencies with TOPdesk

Retrieves available incident urgencies from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/urgencies`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Urgencies](https://developers.topdesk.com/explorer/?page=incident)
