# List Escalation Reasons with TOPdesk

Retrieves incident escalation reasons from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/escalation-reasons`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Escalation Reasons](https://developers.topdesk.com/explorer/?page=incident)
