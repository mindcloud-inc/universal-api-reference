# List Incident Statuses with TOPdesk

Retrieves available incident statuses from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/statuses`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Statuses](https://developers.topdesk.com/explorer/?page=incident)
