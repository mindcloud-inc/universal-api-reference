# List Deescalation Reasons with TOPdesk

Retrieves incident deescalation reasons from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/deescalation-reasons`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Deescalation Reasons](https://developers.topdesk.com/explorer/?page=incident)
