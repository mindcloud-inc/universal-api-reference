# List Incident Categories with TOPdesk

Retrieves incident categories from TOPdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/categories`
- **Base URL:** `https://usatopdesktrial2.topdesk.net/tas/api/`
- **Official documentation:** [List Incident Categories](https://developers.topdesk.com/explorer/?page=incident)
