# Get List with Trello

Retrieves a list from Trello.

## Endpoint

- **Method:** `GET`
- **Path:** `lists/:id`
- **Base URL:** `https://api.trello.com/1`
- **Official documentation:** [Get List](https://developer.atlassian.com/cloud/trello/rest/api-group-lists/#api-lists-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List identifier. |
