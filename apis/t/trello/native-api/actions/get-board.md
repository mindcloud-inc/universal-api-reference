# Get Board with Trello

Retrieves a board from Trello.

## Endpoint

- **Method:** `GET`
- **Path:** `boards/:id`
- **Base URL:** `https://api.trello.com/1`
- **Official documentation:** [Get Board](https://developer.atlassian.com/cloud/trello/rest/api-group-boards/#api-boards-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Board identifier. |
