# Get Card with Trello

Retrieves a card from Trello.

## Endpoint

- **Method:** `GET`
- **Path:** `cards/:id`
- **Base URL:** `https://api.trello.com/1`
- **Official documentation:** [Get Card](https://developer.atlassian.com/cloud/trello/rest/api-group-cards/#api-cards-id-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
