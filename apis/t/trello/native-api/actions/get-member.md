# Get Member with Trello

Retrieves a member from Trello.

## Endpoint

- **Method:** `GET`
- **Path:** `members/:id`
- **Base URL:** `https://api.trello.com/1`
- **Official documentation:** [Get Member](https://developer.atlassian.com/cloud/trello/rest/api-group-members/#api-members-id-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
