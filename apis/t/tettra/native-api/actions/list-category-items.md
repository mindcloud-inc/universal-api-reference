# List Category Items with Tettra

Retrieves category items from Tettra.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/85329/categories/:category_id`
- **Base URL:** `https://app.tettra.co/api`
- **Official documentation:** [List Category Items](https://support.tettra.com/categories-and-subcategories/api-endpoint-get-all-category-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | path | `number` | yes | Category ID to read items from. |
