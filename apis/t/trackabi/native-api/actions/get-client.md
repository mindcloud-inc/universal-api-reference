# Get Client with Trackabi

Retrieves a client from Trackabi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/clients/:clientId`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [Get Client](https://trackabi.com/help/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `number` | yes | The unique ID of the client. |
