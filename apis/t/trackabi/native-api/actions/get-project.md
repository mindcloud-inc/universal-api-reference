# Get Project with Trackabi

Retrieves a project from Trackabi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:projectId`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [Get Project](https://trackabi.com/help/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The unique ID of the project. |
