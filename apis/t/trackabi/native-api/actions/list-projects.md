# List Projects with Trackabi

Retrieves projects from Trackabi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [List Projects](https://trackabi.com/help/api-docs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
