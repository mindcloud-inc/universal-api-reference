# Get Time Entry with Trackabi

Retrieves a time entry from Trackabi.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/time-entry/:timeEntryId`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [Get Time Entry](https://trackabi.com/help/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `time_entry_id` | path | `number` | yes | The unique ID of the time entry. |
