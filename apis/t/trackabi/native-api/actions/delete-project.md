# Delete Project with Trackabi

Deletes an existing project from Trackabi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/projects/:projectId`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [Delete Project](https://trackabi.com/help/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The unique ID of the project. |
