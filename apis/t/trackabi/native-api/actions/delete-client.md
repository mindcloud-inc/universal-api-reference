# Delete Client with Trackabi

Deletes an existing client from Trackabi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/clients/:clientId`
- **Base URL:** `https://api.trackabi.com`
- **Official documentation:** [Delete Client](https://trackabi.com/help/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `number` | yes | The unique ID of the client. |
