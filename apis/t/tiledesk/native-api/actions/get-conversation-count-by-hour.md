# Get Conversation Count By Hour with Tiledesk

Retrieves hourly conversation counts from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/aggregate/hours`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count By Hour](https://developer.tiledesk.com/apis/rest-api/analytics)
