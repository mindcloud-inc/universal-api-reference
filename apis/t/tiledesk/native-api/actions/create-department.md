# Create Department with Tiledesk

Creates a department in the current Tiledesk project.

## Endpoint

- **Method:** `POST`
- **Path:** `/{projectId}/departments`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Create Department](https://developer.tiledesk.com/apis/rest-api/management-api/departments)
