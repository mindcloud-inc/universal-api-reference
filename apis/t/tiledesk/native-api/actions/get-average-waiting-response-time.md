# Get Average Waiting Response Time with Tiledesk

Retrieves average waiting response times from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/waiting_time/agents`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Average Waiting Response Time](https://developer.tiledesk.com/apis/rest-api/analytics)
