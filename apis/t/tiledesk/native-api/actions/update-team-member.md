# Update Team Member with Tiledesk

Updates a team member in the current Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/project_users/:projectUserId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Team Member](https://developer.tiledesk.com/apis/rest-api/team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectUserId` | path | `string` | yes | The project user identifier. |
