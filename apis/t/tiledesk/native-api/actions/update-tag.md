# Update Tag with Tiledesk

Updates a tag in the current Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/tags/:id`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Tag](https://developer.tiledesk.com/apis/rest-api/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tag identifier. |
