# Get Tag with Tiledesk

Retrieves a tag from the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/tags/:id`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Tag](https://developer.tiledesk.com/apis/rest-api/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tag identifier. |
