# Create Bot Intent with Tiledesk

Creates a bot intent in the current Tiledesk project.

## Endpoint

- **Method:** `POST`
- **Path:** `/{projectId}/faq`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Create Bot Intent](https://developer.tiledesk.com/apis/rest-api/faq)
