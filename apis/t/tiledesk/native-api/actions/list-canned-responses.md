# List Canned Responses with Tiledesk

Lists canned responses in the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/canned`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [List Canned Responses](https://developer.tiledesk.com/apis/rest-api/canned-response)
