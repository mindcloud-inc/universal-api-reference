# Get Conversation Count By Day with Tiledesk

Retrieves daily conversation counts from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/aggregate/day`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count By Day](https://developer.tiledesk.com/apis/rest-api/analytics)
