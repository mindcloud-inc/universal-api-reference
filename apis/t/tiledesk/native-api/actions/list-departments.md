# List Departments with Tiledesk

Lists active departments in the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/departments`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [List Departments](https://developer.tiledesk.com/apis/rest-api/management-api/departments#get-all-active-departments)
