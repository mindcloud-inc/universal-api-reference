# Get Conversation Count By Week with Tiledesk

Retrieves weekly conversation counts from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/aggregate/week`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count By Week](https://developer.tiledesk.com/apis/rest-api/analytics)
