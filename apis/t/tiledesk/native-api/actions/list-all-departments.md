# List All Departments with Tiledesk

Lists all departments in the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/departments/allstatus`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [List All Departments](https://developer.tiledesk.com/apis/rest-api/management-api/departments#get-all-departments-active-or-hidden)
