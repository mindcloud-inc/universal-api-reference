# Get Conversation Count with Tiledesk

Retrieves the conversation count from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/count`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count](https://developer.tiledesk.com/apis/rest-api/analytics)
