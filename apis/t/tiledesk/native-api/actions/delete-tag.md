# Delete Tag with Tiledesk

Deletes a tag from the current Tiledesk project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{projectId}/tags/:id`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Delete Tag](https://developer.tiledesk.com/apis/rest-api/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tag identifier. |
