# Get Conversation Count By Status with Tiledesk

Retrieves conversation counts by status from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/aggregate/status`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count By Status](https://developer.tiledesk.com/apis/rest-api/analytics)
