# Get Daily Waiting Response Time with Tiledesk

Retrieves daily waiting response times from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/waiting_time/agents/day`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Daily Waiting Response Time](https://developer.tiledesk.com/apis/rest-api/analytics)
