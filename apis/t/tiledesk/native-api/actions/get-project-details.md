# Get Project Details with Tiledesk

Retrieves details for the current project from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Project Details](https://developer.tiledesk.com/apis/rest-api/projects)
