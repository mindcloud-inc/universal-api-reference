# Get Event with Tiledesk

Retrieves an event from the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/events/:id`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Event](https://developer.tiledesk.com/apis/rest-api/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event identifier. |
