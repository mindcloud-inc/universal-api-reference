# Get Group with Tiledesk

Retrieves a group from the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/groups/:groupId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Group](https://developer.tiledesk.com/apis/rest-api/management-api/groups#get-the-group-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The group identifier. |
