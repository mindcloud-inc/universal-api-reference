# Update Current Teammate with Tiledesk

Updates the current teammate in the Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/project_users/`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Current Teammate](https://developer.tiledesk.com/apis/rest-api/team)
