# Delete Canned Response with Tiledesk

Deletes a canned response from the current Tiledesk project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{projectId}/canned/:id`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Delete Canned Response](https://developer.tiledesk.com/apis/rest-api/canned-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The canned response identifier. |
