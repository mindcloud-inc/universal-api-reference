# Create Segment with Tiledesk

Creates a segment in the current Tiledesk project.

## Endpoint

- **Method:** `POST`
- **Path:** `/{projectId}/segments`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Create Segment](https://developer.tiledesk.com/apis/rest-api/segments)
