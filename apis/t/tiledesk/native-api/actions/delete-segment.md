# Delete Segment with Tiledesk

Deletes a segment from the current Tiledesk project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{projectId}/segments/:segmentId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Delete Segment](https://developer.tiledesk.com/apis/rest-api/segments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | The segment identifier. |
