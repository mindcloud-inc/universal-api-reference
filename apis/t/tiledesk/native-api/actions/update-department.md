# Update Department with Tiledesk

Updates a department in the current Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/departments/:depId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Department](https://developer.tiledesk.com/apis/rest-api/management-api/departments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `depId` | path | `string` | yes | The department identifier. |
