# List Available Agents with Tiledesk

Lists available agents in the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/users/availables`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [List Available Agents](https://developer.tiledesk.com/apis/rest-api/projects#return-the-available-agents)
