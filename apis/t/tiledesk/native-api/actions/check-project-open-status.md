# Check Project Open Status with Tiledesk

Retrieves the current project's open status from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/isopen`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Check Project Open Status](https://developer.tiledesk.com/apis/rest-api/projects#return-if-the-project-is-open-regarding-operating-hours)
