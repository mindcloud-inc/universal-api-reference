# Get Bot with Tiledesk

Retrieves a bot from the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/faq_kb/:botId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Bot](https://developer.tiledesk.com/apis/rest-api/bots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | path | `string` | yes | The bot identifier. |
