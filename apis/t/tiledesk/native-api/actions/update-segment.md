# Update Segment with Tiledesk

Updates a segment in the current Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/segments/:segmentId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Segment](https://developer.tiledesk.com/apis/rest-api/segments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | The segment identifier. |
