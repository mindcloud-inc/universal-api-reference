# List Team Members with Tiledesk

Lists team members in the current Tiledesk project.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/project_users`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [List Team Members](https://developer.tiledesk.com/apis/rest-api/team#get-the-team)
