# Get Conversation Count By Month with Tiledesk

Retrieves monthly conversation counts from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/aggregate/month`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Count By Month](https://developer.tiledesk.com/apis/rest-api/analytics)
