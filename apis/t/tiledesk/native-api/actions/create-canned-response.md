# Create Canned Response with Tiledesk

Creates a canned response in the current Tiledesk project.

## Endpoint

- **Method:** `POST`
- **Path:** `/{projectId}/canned`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Create Canned Response](https://developer.tiledesk.com/apis/rest-api/canned-response)
