# Get Customer Satisfaction with Tiledesk

Retrieves customer satisfaction metrics from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/satisfaction`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Customer Satisfaction](https://developer.tiledesk.com/apis/rest-api/analytics)
