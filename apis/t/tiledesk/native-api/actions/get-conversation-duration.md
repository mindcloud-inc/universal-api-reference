# Get Conversation Duration with Tiledesk

Retrieves conversation duration metrics from Tiledesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/{projectId}/analytics/requests/duration`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Get Conversation Duration](https://developer.tiledesk.com/apis/rest-api/analytics)
