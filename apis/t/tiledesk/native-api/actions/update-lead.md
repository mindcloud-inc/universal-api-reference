# Update Lead with Tiledesk

Updates a lead in the current Tiledesk project.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/leads/:leadId`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Lead](https://developer.tiledesk.com/apis/rest-api/leads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | The lead identifier. |
