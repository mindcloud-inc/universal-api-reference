# Update Request Attributes with Tiledesk

Updates a request's attributes in Tiledesk.

## Endpoint

- **Method:** `PUT`
- **Path:** `/{projectId}/requests/:requestId/attributes`
- **Base URL:** `https://api.tiledesk.com/v3`
- **Official documentation:** [Update Request Attributes](https://developer.tiledesk.com/apis/rest-api/requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | The request identifier. |
