# Get Scenario with Tidely

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/open-api/scenarios/:scenarioId`
- **Base URL:** `https://api.tidely.com`
- **Official documentation:** [Get Scenario](https://api.tidely.com/tidely-open-api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scenarioId` | path | `string` | no | Tidely scenario ID to fetch. |
