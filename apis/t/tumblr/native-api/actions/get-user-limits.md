# Get User Limits with Tumblr

Retrieves Tumblr posting limits for the user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/limits`
- **Base URL:** `https://api.tumblr.com`
- **Official documentation:** [Get User Limits](https://www.tumblr.com/docs/en/api/v2#userlimits--get-a-users-limits)
