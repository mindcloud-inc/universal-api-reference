# Get User Information with Tumblr

Retrieves account information for the Tumblr user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/info`
- **Base URL:** `https://api.tumblr.com`
- **Official documentation:** [Get User Information](https://www.tumblr.com/docs/en/api/v2#userinfo--get-a-users-information)
