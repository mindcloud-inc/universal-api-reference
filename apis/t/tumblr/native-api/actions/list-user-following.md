# List User Following with Tumblr

Retrieves blogs followed by the Tumblr user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/following`
- **Base URL:** `https://api.tumblr.com`
- **Official documentation:** [List User Following](https://www.tumblr.com/docs/en/api/v2#userfollowing--retrieve-the-blogs-a-user-is-following)

## Capabilities

This operation supports [pagination](../README.md#pagination).
