# Retrieve Assembly Status with Transloadit

Retrieves an assembly status from Transloadit.

## Endpoint

- **Method:** `GET`
- **Path:** `/assemblies/:assemblyId`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Retrieve Assembly Status](https://transloadit.com/docs/api/assemblies-assembly-id-get/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assemblyId` | path | `string` | yes | The ID of the assembly to retrieve. |
