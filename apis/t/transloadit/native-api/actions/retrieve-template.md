# Retrieve Template with Transloadit

Retrieves a template by ID from Transloadit.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Retrieve Template](https://transloadit.com/docs/api/templates-template-id-get/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The ID of the template to retrieve. |
