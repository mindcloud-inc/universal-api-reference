# Retrieve Template Credential with Transloadit

Retrieves a template credential from Transloadit.

## Endpoint

- **Method:** `GET`
- **Path:** `/template_credentials/:credentialsId`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Retrieve Template Credential](https://transloadit.com/docs/api/template-credentials-credentials-id-or-name-get/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `credentialsId` | path | `string` | yes | The ID or name of the template credential to retrieve. |
