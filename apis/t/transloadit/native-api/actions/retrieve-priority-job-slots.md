# Retrieve currently used priority job slots with Transloadit

Retrieves currently used priority job slots from Transloadit.

## Endpoint

- **Method:** `GET`
- **Path:** `/queues/job_slots`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Retrieve currently used priority job slots](https://transloadit.com/docs/api/queues-job-slots-get/)
