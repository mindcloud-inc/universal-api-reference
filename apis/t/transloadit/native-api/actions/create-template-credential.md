# Create Template Credential with Transloadit

Creates a new template credential in Transloadit.

## Endpoint

- **Method:** `POST`
- **Path:** `/template_credentials`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Create Template Credential](https://transloadit.com/docs/api/template-credentials-post/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params` | body | `string` | yes | JSON string containing the Transloadit template credential definition. |
