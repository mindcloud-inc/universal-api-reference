# Create Template with Transloadit

Creates a new template in Transloadit.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Create Template](https://transloadit.com/docs/api/templates-post/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params` | body | `string` | yes | JSON string containing the Transloadit template definition and metadata. |
