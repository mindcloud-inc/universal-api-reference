# Cancel Assembly with Transloadit

Cancels a running assembly in Transloadit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assemblies/:assemblyId`
- **Base URL:** `https://api2.transloadit.com`
- **Official documentation:** [Cancel Assembly](https://transloadit.com/docs/api/assemblies-assembly-id-delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assemblyId` | path | `string` | yes | The ID of the assembly to cancel. |
