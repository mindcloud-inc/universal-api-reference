# Bulk Delete Suppressions with turboSMTP

Deletes suppressions in bulk from turboSMTP.

## Endpoint

- **Method:** `POST`
- **Path:** `/suppressions/bulk_delete`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Bulk Delete Suppressions](https://serversmtp.com/turbo-api/#/suppressions/bulkDeleteSuppressions)
