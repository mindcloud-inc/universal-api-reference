# List Analytics Data with turboSMTP

Retrieves email analytics data from turboSMTP.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Analytics Data](https://serversmtp.com/turbo-api/#/analytics/getAnalyticsData)
