# List Validated Emails by List with turboSMTP

Retrieves validated emails from a turboSMTP validation list.

## Endpoint

- **Method:** `GET`
- **Path:** `/emailvalidation/lists/{Id}/emails`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Validated Emails by List](https://serversmtp.com/turbo-api/#/email-validator/getValidatedEmailsByList)
