# List Subaccounts with turboSMTP

Retrieves subaccounts from your turboSMTP account.

## Endpoint

- **Method:** `GET`
- **Path:** `/subaccounts/list`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Subaccounts](https://serversmtp.com/turbo-api/#/subaccounts/getSubaccounts)
