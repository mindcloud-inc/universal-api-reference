# Check If Account Email Exists with turboSMTP

Checks whether an account email exists in turboSMTP.

## Endpoint

- **Method:** `GET`
- **Path:** `/subaccounts/email-exists`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Check If Account Email Exists](https://serversmtp.com/turbo-api/#/subaccounts/checkIfAccountEmailExists)
