# Get Email Validation List Summary with turboSMTP

Retrieves an email validation list summary from turboSMTP.

## Endpoint

- **Method:** `GET`
- **Path:** `/emailvalidation/lists/{Id}`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Get Email Validation List Summary](https://serversmtp.com/turbo-api/#/email-validator/getEmailValidationListSummary)
