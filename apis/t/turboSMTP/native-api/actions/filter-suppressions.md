# Filter Suppressions with turboSMTP

Finds suppressions in turboSMTP by custom filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/suppressions`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Filter Suppressions](https://serversmtp.com/turbo-api/#/suppressions/filterSuppressions)
