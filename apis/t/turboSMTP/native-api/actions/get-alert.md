# Get Alert with turboSMTP

Retrieves an alert from your turboSMTP account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/alerts/{Id}`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Get Alert](https://serversmtp.com/turbo-api/#/alerts/getAlert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | path | `number` | yes | Alert identifier. |
