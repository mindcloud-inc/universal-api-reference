# Get Email Validation Subscription with turboSMTP

Retrieves email validation subscription details from turboSMTP.

## Endpoint

- **Method:** `GET`
- **Path:** `/emailvalidation/subscription`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Get Email Validation Subscription](https://serversmtp.com/turbo-api/#/email-validator/getEmailValidationSubscription)
