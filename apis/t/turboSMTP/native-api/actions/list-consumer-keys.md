# List Consumer Keys with turboSMTP

Retrieves consumer keys from your turboSMTP account.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/consumerKeys`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Consumer Keys](https://serversmtp.com/turbo-api/#/consumerkey/listConsumerKeys)
