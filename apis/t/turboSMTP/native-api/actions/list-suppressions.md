# List Suppressions with turboSMTP

Retrieves email suppressions from your turboSMTP account.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppressions`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Suppressions](https://serversmtp.com/turbo-api/#/suppressions/getSuppressions)
