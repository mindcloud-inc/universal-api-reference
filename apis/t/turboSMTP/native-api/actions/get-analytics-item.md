# Get Analytics Item with turboSMTP

Retrieves an analytics item from turboSMTP.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/{Id}`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Get Analytics Item](https://serversmtp.com/turbo-api/#/analytics/getAnalyticsDataByID)
