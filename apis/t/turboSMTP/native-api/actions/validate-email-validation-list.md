# Validate Email Validation List with turboSMTP

Validates an email validation list in turboSMTP.

## Endpoint

- **Method:** `POST`
- **Path:** `/emailvalidation/lists/{Id}/validate`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Validate Email Validation List](https://serversmtp.com/turbo-api/#/email-validator/validateEmailValidatorList)
