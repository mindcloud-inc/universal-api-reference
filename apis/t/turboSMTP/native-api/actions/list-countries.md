# List Countries with turboSMTP

Retrieves available countries from your turboSMTP account.

## Endpoint

- **Method:** `GET`
- **Path:** `/meta/countries`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [List Countries](https://serversmtp.com/turbo-api/#/meta/getCountries)
