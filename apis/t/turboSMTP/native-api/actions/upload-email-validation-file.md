# Upload Email Validation File with turboSMTP

Uploads a file for email validation in turboSMTP.

## Endpoint

- **Method:** `POST`
- **Path:** `/emailvalidation/upload`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Upload Email Validation File](https://serversmtp.com/turbo-api/#/email-validator/uploadEmailValidationFile)
