# Validate Email with turboSMTP

Validates an email address in turboSMTP.

## Endpoint

- **Method:** `POST`
- **Path:** `/emailvalidation/validateEmail`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Validate Email](https://serversmtp.com/turbo-api/#/email-validator/validateEmail)
