# Import Suppressions with turboSMTP

Imports email suppressions into your turboSMTP account.

## Endpoint

- **Method:** `POST`
- **Path:** `/suppressions/import`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Import Suppressions](https://serversmtp.com/turbo-api/#/suppressions/importSuppressions)
