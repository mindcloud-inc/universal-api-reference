# Delete Alert with turboSMTP

Deletes an existing alert from turboSMTP.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools/alerts/{Id}`
- **Base URL:** `https://pro.api.serversmtp.com/api/v2`
- **Official documentation:** [Delete Alert](https://serversmtp.com/turbo-api/#/alerts/deleteAlert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | path | `number` | yes | Alert identifier. |
