# Get Credit Balance with TextingHouse

Retrieves the current TextingHouse credit balance.

## Endpoint

- **Method:** `POST`
- **Path:** `/do`
- **Base URL:** `https://api.textinghouse.com/http/v1`
- **Official documentation:** [Get Credit Balance](https://www.textinghouse.com/en/api-sms-http/api-documentation/#doc-conscred)
