# List Person Crew Credits With Show with TVMaze Schedule

Retrieves TVMaze crew credits with embedded shows.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}/crewcredits`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List Person Crew Credits With Show](https://www.tvmaze.com/api#person-crew-credits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze person ID. |
