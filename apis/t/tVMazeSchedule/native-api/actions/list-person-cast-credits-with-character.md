# List Person Cast Credits With Character with TVMaze Schedule

Retrieves TVMaze cast credits with embedded characters.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}/castcredits`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List Person Cast Credits With Character](https://www.tvmaze.com/api#person-cast-credits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze person ID. |
