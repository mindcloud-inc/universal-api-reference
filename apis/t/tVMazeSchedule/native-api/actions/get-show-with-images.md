# Get Show With Images with TVMaze Schedule

Retrieves a TVMaze show with embedded images.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Show With Images](https://www.tvmaze.com/api#embedding)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze show ID. |
