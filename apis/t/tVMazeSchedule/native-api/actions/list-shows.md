# List Shows with TVMaze Schedule

Retrieves all show records from TVMaze.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List Shows](https://www.tvmaze.com/api#show-index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Optional page number for TVmaze show index; starts at 0. |
