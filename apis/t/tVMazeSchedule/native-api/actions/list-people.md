# List People with TVMaze Schedule

Retrieves all person records from TVMaze.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List People](https://www.tvmaze.com/api#person-index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Optional page number for TVmaze people index; starts at 0. |
