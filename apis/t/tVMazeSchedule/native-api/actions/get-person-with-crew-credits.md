# Get Person With Crew Credits with TVMaze Schedule

Retrieves a TVMaze person with embedded crew credits.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Person With Crew Credits](https://www.tvmaze.com/api#person-main-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze person ID. |
