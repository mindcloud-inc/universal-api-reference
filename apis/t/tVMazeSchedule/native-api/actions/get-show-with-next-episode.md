# Get Show With Next Episode with TVMaze Schedule

Retrieves a TVMaze show with its next episode.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Show With Next Episode](https://www.tvmaze.com/api#embedding)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze show ID. |
