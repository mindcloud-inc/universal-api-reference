# Get Alternate List With Alternate Episodes with TVMaze Schedule

Retrieves a TVMaze alternate list with episodes.

## Endpoint

- **Method:** `GET`
- **Path:** `/alternatelists/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Alternate List With Alternate Episodes](https://www.tvmaze.com/api#show-alternate-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze alternate list ID. |
