# List Person Guest Cast Credits With Character with TVMaze Schedule

Retrieves TVMaze guest cast credits with embedded characters.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}/guestcastcredits`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List Person Guest Cast Credits With Character](https://www.tvmaze.com/api#person-guest-cast-credits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze person ID. |
