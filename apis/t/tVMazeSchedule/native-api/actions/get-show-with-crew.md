# Get Show With Crew with TVMaze Schedule

Retrieves a TVMaze show with embedded crew.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Show With Crew](https://www.tvmaze.com/api#embedding)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze show ID. |
