# Search Shows with TVMaze Schedule

Finds shows in TVMaze by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/shows`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Search Shows](https://www.tvmaze.com/api#show-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Required show search query. |
