# Get Episode With Show with TVMaze Schedule

Retrieves a TVMaze episode with its show.

## Endpoint

- **Method:** `GET`
- **Path:** `/episodes/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Episode With Show](https://www.tvmaze.com/api#episode-main-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze episode ID. |
