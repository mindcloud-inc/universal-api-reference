# Get Show With Cast with TVMaze Schedule

Retrieves a TVMaze show with embedded cast.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Show With Cast](https://www.tvmaze.com/api#show-main-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze show ID. |
