# Get Person With Cast Credits with TVMaze Schedule

Retrieves a TVMaze person with embedded cast credits.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{id}}`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Get Person With Cast Credits](https://www.tvmaze.com/api#person-main-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze person ID. |
