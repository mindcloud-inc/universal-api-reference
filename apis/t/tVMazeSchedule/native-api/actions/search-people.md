# Search People with TVMaze Schedule

Finds people in TVMaze by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/people`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [Search People](https://www.tvmaze.com/api#people-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Required people search query. |
