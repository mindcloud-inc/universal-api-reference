# List Show Episodes With Specials with TVMaze Schedule

Retrieves all TVMaze show episodes including specials.

## Endpoint

- **Method:** `GET`
- **Path:** `/shows/{{id}}/episodes`
- **Base URL:** `https://api.tvmaze.com`
- **Official documentation:** [List Show Episodes With Specials](https://www.tvmaze.com/api#show-episode-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | TVMaze show ID. |
