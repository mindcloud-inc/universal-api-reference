# List Projects Hierarchically with Timing

Retrieves the complete project hierarchy from Timing.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/hierarchy`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [List Projects Hierarchically](https://web.timingapp.com/docs/#projects-GETapi-v1-projects-hierarchy)
