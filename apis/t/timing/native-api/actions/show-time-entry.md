# Show Time Entry with Timing

Retrieves a time entry from Timing.

## Endpoint

- **Method:** `GET`
- **Path:** `/time-entries/:time_entry_id`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Show Time Entry](https://web.timingapp.com/docs/#time-entries-GETapi-v1-time-entries--time_entry_id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `time_entry_id` | path | `string` | yes | The Timing time entry ID to load. |
