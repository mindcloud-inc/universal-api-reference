# Stop Timer with Timing

Stops the currently running timer in Timing.

## Endpoint

- **Method:** `PUT`
- **Path:** `/time-entries/stop`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Stop Timer](https://web.timingapp.com/docs/#time-entries-PUTapi-v1-time-entries-stop)
