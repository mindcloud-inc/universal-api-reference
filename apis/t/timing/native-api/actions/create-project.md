# Create Project with Timing

Creates a new project in Timing.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Create Project](https://web.timingapp.com/docs/#projects-POSTapi-v1-projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | yes |
