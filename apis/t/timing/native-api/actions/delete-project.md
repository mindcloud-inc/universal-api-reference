# Delete Project with Timing

Deletes a project and its children from Timing.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Delete Project](https://web.timingapp.com/docs/#projects-DELETEapi-v1-projects--project_id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Timing project ID to delete. |
