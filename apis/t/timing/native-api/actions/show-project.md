# Show Project with Timing

Retrieves a specific project from Timing.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Show Project](https://web.timingapp.com/docs/#projects-GETapi-v1-projects--project_id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Timing project ID to load. |
