# Show Running Timer with Timing

Retrieves the currently running time entry from Timing.

## Endpoint

- **Method:** `GET`
- **Path:** `/time-entries/running`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Show Running Timer](https://web.timingapp.com/docs/#time-entries-GETapi-v1-time-entries-running)
