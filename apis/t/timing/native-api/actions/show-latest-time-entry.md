# Show Latest Time Entry with Timing

Retrieves the latest time entry from Timing.

## Endpoint

- **Method:** `GET`
- **Path:** `/time-entries/latest`
- **Base URL:** `https://web.timingapp.com/api/v1`
- **Official documentation:** [Show Latest Time Entry](https://web.timingapp.com/docs/#time-entries-GETapi-v1-time-entries-latest)
