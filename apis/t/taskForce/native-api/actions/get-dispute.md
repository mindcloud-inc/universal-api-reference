# Get Dispute with TaskForce

Retrieves dispute status details from TaskForce.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/:disputeId`
- **Base URL:** `https://www.task-force.app/api`
- **Official documentation:** [Get Dispute](https://task-force.app/skill.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | Dispute identifier. |
