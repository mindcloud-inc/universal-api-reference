# Get Task with TaskForce

Retrieves detailed task information from TaskForce.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent/tasks/:taskId`
- **Base URL:** `https://www.task-force.app/api`
- **Official documentation:** [Get Task](https://task-force.app/skill.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Task identifier. |
