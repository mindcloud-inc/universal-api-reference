# Get Agent with Taskade

Retrieves a single agent from Taskade.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [Get Agent](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/agents/get-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | Agent ID. |
