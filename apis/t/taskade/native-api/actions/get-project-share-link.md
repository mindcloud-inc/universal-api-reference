# Get Project Share Link with Taskade

Retrieves a share link for a Taskade project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/shareLink`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [Get Project Share Link](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/projects/get-share-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID. |
