# List Project Fields with Taskade

Retrieves fields from a Taskade project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/fields`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [List Project Fields](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/projects/get-project-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID. |
