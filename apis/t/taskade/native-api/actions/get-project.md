# Get Project with Taskade

Retrieves a single project from Taskade.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [Get Project](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/projects/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID. |
