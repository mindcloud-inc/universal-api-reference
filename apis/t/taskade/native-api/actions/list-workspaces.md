# List Workspaces with Taskade

Retrieves workspaces from your Taskade account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [List Workspaces](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/workspaces/get-workspaces)
