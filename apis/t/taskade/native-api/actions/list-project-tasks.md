# List Project Tasks with Taskade

Retrieves tasks from a Taskade project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/tasks`
- **Base URL:** `https://www.taskade.com/api/v1`
- **Official documentation:** [List Project Tasks](https://docs.taskade.com/docs/apis-and-developer/comprehensive-api-guide/projects/get-project-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID. |
