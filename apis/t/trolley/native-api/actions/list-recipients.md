# List Recipients with Trolley

Retrieves all recipient records from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Recipients](https://developers.trolley.com/api/#list-all-recipients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
| `pageSize` | query | `number` | no | Results per page. |
