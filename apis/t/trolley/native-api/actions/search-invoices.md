# Search Invoices with Trolley

Finds invoices in Trolley using search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/search`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Search Invoices](https://developers.trolley.com/api/#search-invoices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | body | `number` | no | Page number |
| `pageSize` | body | `number` | no | Page size |
