# Get Recipient Account with Trolley

Retrieves a recipient payment account from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients/:id/accounts/:recipientAccountId`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Get Recipient Account](https://developers.trolley.com/api/#retrieve-account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `recipientAccountId` | path | `string` | yes |
