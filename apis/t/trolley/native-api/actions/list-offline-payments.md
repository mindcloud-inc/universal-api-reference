# List Offline Payments with Trolley

Retrieves all offline payments from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/offline-payments`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Offline Payments](https://developers.trolley.com/api/#list-all-offline-payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | Page number |
| `pageSize` | query | `string` | no | Page size |
