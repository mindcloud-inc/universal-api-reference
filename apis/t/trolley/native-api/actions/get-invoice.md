# Get Invoice with Trolley

Retrieves a single invoice from Trolley.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/get`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Get Invoice](https://developers.trolley.com/api/#get-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | body | `string` | no | Invoice ID |
