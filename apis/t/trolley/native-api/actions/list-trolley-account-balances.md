# List Trolley Account Balances with Trolley

Retrieves Trolley account balances from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/balances/paymentrails`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Trolley Account Balances](https://developers.trolley.com/api/#retrieve-trolley-account-balance)
