# Get Country with Trolley

Retrieves a country from Trolley by country code.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/geography/countries/:code`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Get Country](https://developers.trolley.com/api/#retrieve-a-country)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | ISO 3166-1 alpha-2 country code. |
