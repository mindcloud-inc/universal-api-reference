# Delete Recipient with Trolley

Deletes an existing recipient from Trolley.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/recipients/:id`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Delete Recipient](https://developers.trolley.com/api/#delete-a-recipient)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
