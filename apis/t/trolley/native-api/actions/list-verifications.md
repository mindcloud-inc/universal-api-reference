# List Verifications with Trolley

Retrieves all verification records from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/verifications`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Verifications](https://developers.trolley.com/api/#list-all-verifications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `verificationType` | query | `string` | no | Verification type |
