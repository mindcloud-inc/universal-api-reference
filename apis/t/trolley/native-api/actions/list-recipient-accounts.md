# List Recipient Accounts with Trolley

Retrieves recipient payment accounts from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients/:id/accounts`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Recipient Accounts](https://developers.trolley.com/api/#recipients-and-recipient-accounts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
