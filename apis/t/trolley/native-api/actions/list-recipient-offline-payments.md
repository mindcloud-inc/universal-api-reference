# List Recipient Offline Payments with Trolley

Retrieves offline payments for a recipient from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients/:id/offlinePayments`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Recipient Offline Payments](https://developers.trolley.com/api/#retrieve-recipients-offline-payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Recipient ID |
