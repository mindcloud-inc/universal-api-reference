# List Batches with Trolley

Retrieves all payment batches from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Batches](https://developers.trolley.com/api/#list-all-batches)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `pageSize` | query | `number` | no |
