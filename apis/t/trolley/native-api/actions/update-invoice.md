# Update Invoice with Trolley

Updates an existing invoice in Trolley.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/update`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Update Invoice](https://developers.trolley.com/api/#update-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | body | `string` | no | Invoice ID |
