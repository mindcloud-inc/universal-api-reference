# Search Recipients with Trolley

Finds recipients in Trolley using search filters.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Search Recipients](https://developers.trolley.com/api/#search-filter-recipients)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | query | `string` | no |
