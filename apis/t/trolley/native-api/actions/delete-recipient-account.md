# Delete Recipient Account with Trolley

Deletes a recipient payment account from Trolley.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/recipients/:id/accounts/:recipientAccountId`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Delete Recipient Account](https://developers.trolley.com/api/#delete-account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `recipientAccountId` | path | `string` | yes |
