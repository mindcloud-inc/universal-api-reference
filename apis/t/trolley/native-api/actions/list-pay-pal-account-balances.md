# List PayPal Account Balances with Trolley

Retrieves PayPal account balances from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/balances/paypal`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List PayPal Account Balances](https://developers.trolley.com/api/#retrieve-paypal-account-balance)
