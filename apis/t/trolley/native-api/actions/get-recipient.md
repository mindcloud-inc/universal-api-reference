# Get Recipient with Trolley

Retrieves a single recipient from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients/:id`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Get Recipient](https://developers.trolley.com/api/#retrieve-a-recipient)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
