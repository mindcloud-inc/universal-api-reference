# Create Invoice Lines with Trolley

Creates new invoice lines in Trolley.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/create-lines`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Create Invoice Lines](https://developers.trolley.com/api/#create-an-invoice-line)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | body | `string` | no | Invoice ID |
