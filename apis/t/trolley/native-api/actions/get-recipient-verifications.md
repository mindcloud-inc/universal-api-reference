# Get Recipient Verifications with Trolley

Retrieves recipient verification results from Trolley.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/verifications/get`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Get Recipient Verifications](https://developers.trolley.com/api/#getting-verification-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipientId` | body | `string` | no | Recipient ID |
