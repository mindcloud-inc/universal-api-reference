# List Recipient Payments with Trolley

Retrieves payments for a recipient from Trolley.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/recipients/:id/payments`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [List Recipient Payments](https://developers.trolley.com/api/#retrieve-all-payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Recipient ID |
