# Update Invoice Lines with Trolley

Updates existing invoice lines in Trolley.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/invoices/update-lines`
- **Base URL:** `https://api.trolley.com`
- **Official documentation:** [Update Invoice Lines](https://developers.trolley.com/api/#update-invoice-lines)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | body | `string` | no | Invoice ID |
