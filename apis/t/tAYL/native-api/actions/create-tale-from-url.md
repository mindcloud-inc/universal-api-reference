# Create Tale From URL with TAYL

## Endpoint

- **Method:** `POST`
- **Path:** `/submit`
- **Base URL:** `https://x.tayl.app`
- **Official documentation:** [Create Tale From URL](https://my.tayl.app/create/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public webpage URL to convert into a TAYL tale. |
