# Get PDS Blob Storage Usage By DID with Tophhie Cloud

Retrieves PDS blob storage usage by DID from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/blobStorageUsageBytes/{did}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Blob Storage Usage By DID](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `did` | path | `string` | yes | The decentralized identifier for the PDS repository. |
