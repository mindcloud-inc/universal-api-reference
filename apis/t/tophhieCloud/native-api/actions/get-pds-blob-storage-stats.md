# Get PDS Blob Storage Stats with Tophhie Cloud

Retrieves PDS blob storage stats from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/blobStorageStats`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Blob Storage Stats](https://api.tophhie.cloud/swagger/v1/swagger.json)
