# Get PDS Bluesky Heatmap with Tophhie Cloud

Retrieves PDS Bluesky heatmap data from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/blueskyHeatmap`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Bluesky Heatmap](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `forYear` | query | `number` | no | Year to return heatmap data for. |
