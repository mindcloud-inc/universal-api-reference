# Get Redirect with Tophhie Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/redirect/{application}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get Redirect](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application` | path | `string` | yes | Application redirect key. Use index to fetch the redirect index. |
