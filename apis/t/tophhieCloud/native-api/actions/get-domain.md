# Get Domain with Tophhie Cloud

Retrieves domain details from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/{domainName}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get Domain](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | The domain name to retrieve. |
