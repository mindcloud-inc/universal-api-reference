# Get PDS Accessibility Score with Tophhie Cloud

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/accessibilityScore/{did}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Accessibility Score](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `did` | path | `string` | yes | The decentralized identifier for the PDS repository. |
