# Get PDS Uptime Stats with Tophhie Cloud

Retrieves PDS uptime statistics from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/uptimeStats`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Uptime Stats](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `startDate` | query | `date` | no | Optional start date for uptime statistics. |
| `endDate` | query | `date` | no | Optional end date for uptime statistics. |
