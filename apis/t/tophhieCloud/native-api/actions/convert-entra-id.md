# Convert Entra ID with Tophhie Cloud

Converts an Entra ID object ID or SID in Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/entra/convertid/{id}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Convert Entra ID](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Entra Object ID or SID to convert. |
