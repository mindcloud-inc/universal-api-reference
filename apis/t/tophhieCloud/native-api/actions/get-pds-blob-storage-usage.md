# Get PDS Blob Storage Usage with Tophhie Cloud

Retrieves PDS blob storage usage from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/blobStorageUsageBytes`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get PDS Blob Storage Usage](https://api.tophhie.cloud/swagger/v1/swagger.json)
