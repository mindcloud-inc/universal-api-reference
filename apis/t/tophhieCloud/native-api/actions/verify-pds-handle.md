# Verify PDS Handle with Tophhie Cloud

Verifies PDS handle availability in Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/pds/verifyHandle`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Verify PDS Handle](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | query | `string` | yes | Handle to check. |
