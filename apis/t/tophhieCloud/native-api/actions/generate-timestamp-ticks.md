# Generate Timestamp Ticks with Tophhie Cloud

Retrieves UTC timestamp ticks from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/generate/timestamp/ticks`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Generate Timestamp Ticks](https://api.tophhie.cloud/swagger/v1/swagger.json)
