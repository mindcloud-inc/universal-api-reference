# List M365 Message Center Blog Posts with Tophhie Cloud

Retrieves Microsoft 365 Message Center blog posts from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/blog/posts/m365-message-center`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [List M365 Message Center Blog Posts](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Specific page from the results. |
| `limit` | query | `number` | no | Number of posts to return. |
