# Get Blog Post with Tophhie Cloud

Retrieves a blog post from Tophhie Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/blog/posts/{id}`
- **Base URL:** `https://api.tophhie.cloud`
- **Official documentation:** [Get Blog Post](https://api.tophhie.cloud/swagger/v1/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the blog post. |
