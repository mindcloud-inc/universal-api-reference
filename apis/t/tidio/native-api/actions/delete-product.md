# Delete Product with Tidio

Deletes a product from the Tidio product catalog.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/{productId}`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Delete Product](https://developers.tidio.com/reference/delete_products-productid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The Tidio product ID. |
