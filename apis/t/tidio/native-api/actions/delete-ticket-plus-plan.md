# Delete Ticket [Plus plan] with Tidio

Deletes a ticket from the Tidio workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tickets/{ticketId}`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Delete Ticket [Plus plan]](https://developers.tidio.com/reference/delete_tickets-ticketid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | path | `string` | yes | The Tidio ticket ID. |
