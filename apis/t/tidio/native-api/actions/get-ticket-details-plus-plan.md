# Get Ticket Details [Plus plan] with Tidio

Retrieves ticket details from the Tidio workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/{ticketId}`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Get Ticket Details [Plus plan]](https://developers.tidio.com/reference/get_tickets-ticketid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | path | `string` | yes | The Tidio ticket ID. |
