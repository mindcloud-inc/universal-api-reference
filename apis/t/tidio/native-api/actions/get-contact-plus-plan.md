# Get Contact [Plus plan] with Tidio

Retrieves a contact from the Tidio workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contactId}`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Get Contact [Plus plan]](https://developers.tidio.com/reference/get_contacts-contactid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Tidio contact ID. |
