# List Contacts [Plus plan] with Tidio

Retrieves contacts from the Tidio workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [List Contacts [Plus plan]](https://developers.tidio.com/reference/get_contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Filter contacts by email address. |
