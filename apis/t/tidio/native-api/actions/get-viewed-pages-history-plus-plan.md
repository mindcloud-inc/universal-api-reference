# Get Viewed Pages History [Plus plan] with Tidio

Retrieves viewed page history for a contact in Tidio.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contactId}/viewed-pages`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Get Viewed Pages History [Plus plan]](https://developers.tidio.com/reference/get_contacts-contactid-viewed-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Tidio contact ID. |
