# Get Contact Messages [Plus plan] with Tidio

Retrieves messages for a contact from Tidio.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contactId}/messages`
- **Base URL:** `https://api.tidio.com`
- **Official documentation:** [Get Contact Messages [Plus plan]](https://developers.tidio.com/reference/get_contacts-contactid-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Tidio contact ID. |
