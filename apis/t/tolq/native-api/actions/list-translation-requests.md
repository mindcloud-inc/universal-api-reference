# List Translation Requests with Tolq

Retrieves translation requests from Tolq.

## Endpoint

- **Method:** `GET`
- **Path:** `/translations/requests`
- **Base URL:** `https://api.tolq.com/v1`
- **Official documentation:** [List Translation Requests](https://docs.tolq.com/reference/list-all-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination).
