# Get Translation Request with Tolq

Retrieves a translation request from Tolq.

## Endpoint

- **Method:** `GET`
- **Path:** `/translations/requests/:id`
- **Base URL:** `https://api.tolq.com/v1`
- **Official documentation:** [Get Translation Request](https://docs.tolq.com/reference/get-a-translation-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tolq translation request ID. |
