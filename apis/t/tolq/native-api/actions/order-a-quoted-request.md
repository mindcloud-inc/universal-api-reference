# Order a Quoted Request with Tolq

Orders a quoted translation request in Tolq.

## Endpoint

- **Method:** `POST`
- **Path:** `/translations/requests/:id/order`
- **Base URL:** `https://api.tolq.com/v1`
- **Official documentation:** [Order a Quoted Request](https://docs.tolq.com/reference/order-a-quoted-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Quoted Tolq request ID to confirm. |
