# List Messages with Teletype App

Retrieves all messages from Teletype App.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages`
- **Base URL:** `https://api.teletype.app/public/api/v1`
- **Official documentation:** [List Messages](https://teletype.app/help/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
