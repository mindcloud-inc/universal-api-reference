# List Channels with Teletype App

Retrieves all channels from Teletype App.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://api.teletype.app/public/api/v1`
- **Official documentation:** [List Channels](https://teletype.app/help/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
