# List Clients with Teletype App

Retrieves all clients from Teletype App.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://api.teletype.app/public/api/v1`
- **Official documentation:** [List Clients](https://teletype.app/help/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
