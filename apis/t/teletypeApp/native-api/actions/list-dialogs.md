# List Dialogs with Teletype App

Retrieves all dialogs from Teletype App.

## Endpoint

- **Method:** `GET`
- **Path:** `/dialogs`
- **Base URL:** `https://api.teletype.app/public/api/v1`
- **Official documentation:** [List Dialogs](https://teletype.app/help/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
