# List Inactive Projects with Timewax

Retrieves all inactive projects from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `project/list_inactive/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [List Inactive Projects](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231599209)
