# List Clients with Timewax

Retrieves all clients from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `company/list/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [List Clients](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231468145)
