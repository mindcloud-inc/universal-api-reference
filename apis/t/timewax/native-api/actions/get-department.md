# Get Department with Timewax

Retrieves a department from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `department/get/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Get Department](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231370079)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `department` | body | `string` | yes | Required. Code or name of the department. |
