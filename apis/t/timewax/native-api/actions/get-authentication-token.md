# Get Authentication Token with Timewax

Retrieves an authentication token from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `authentication/token/get/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Get Authentication Token](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2230681619)
