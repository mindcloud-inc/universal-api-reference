# List Departments with Timewax

Retrieves all departments from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `department/list/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [List Departments](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2261811201)
