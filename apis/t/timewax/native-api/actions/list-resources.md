# List Resources with Timewax

Retrieves all resource records from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `resource/list/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [List Resources](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231566521)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `isActive` | body | `string` | no | Optional. Yes or No. |
