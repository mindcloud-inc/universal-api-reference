# Update Project with Timewax

Updates an existing project in Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `project/edit/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Update Project](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231599232)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request.project` | body | `string` | yes | Code of the project to update. |
