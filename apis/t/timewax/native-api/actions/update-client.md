# Update Client with Timewax

Updates an existing client in Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `company/edit/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Update Client](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2230878328)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | body | `string` | yes | Required. Code or name of the client. |
