# Get Client with Timewax

Retrieves a client from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `company/get/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Get Client](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231370029)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | body | `string` | yes | Required. Code or name of the client. |
