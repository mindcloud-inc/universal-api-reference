# Get Project with Timewax

Retrieves a project from Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `project/get/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Get Project](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231631941)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | body | `string` | yes | Required. Project code or name. |
