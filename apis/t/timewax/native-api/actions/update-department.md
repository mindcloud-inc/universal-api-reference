# Update Department with Timewax

Updates an existing department in Timewax.

## Endpoint

- **Method:** `POST`
- **Path:** `department/edit/`
- **Base URL:** `https://api.timewax.com/`
- **Official documentation:** [Update Department](https://timewax.atlassian.net/rest/servicedesk/knowledgebase/latest/articles/view/2231370086)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `department` | body | `string` | yes | Required. Code or name of the department to edit. |
