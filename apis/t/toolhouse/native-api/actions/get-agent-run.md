# Get Agent Run with Toolhouse

## Endpoint

- **Method:** `GET`
- **Path:** `/agent-runs/:run_id`
- **Base URL:** `https://api.toolhouse.ai/v1`
- **Official documentation:** [Get Agent Run](https://docs.toolhouse.ai/toolhouse/agent-workers/running-agents-asynchronously/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The agent run ID. |
