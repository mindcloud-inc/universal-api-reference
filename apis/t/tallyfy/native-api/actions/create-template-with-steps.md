# Create Template With Steps with Tallyfy

Creates a new template with steps in Tallyfy.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/:org/checklists-with-steps`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Create Template With Steps](https://tallyfy.com/products/pro/integrations/open-api/code-samples/templates/)
