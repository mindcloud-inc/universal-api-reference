# List Templates with Tallyfy

Retrieves process templates from your Tallyfy organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/checklists`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [List Templates](https://tallyfy.com/products/pro/integrations/open-api/code-samples/templates/)
