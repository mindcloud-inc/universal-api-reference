# Create Task with Tallyfy

Creates a new one-off task in Tallyfy.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/:org/tasks`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Create Task](https://tallyfy.com/products/pro/integrations/open-api/code-samples/tasks/)
