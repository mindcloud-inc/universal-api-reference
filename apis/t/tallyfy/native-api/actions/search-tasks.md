# Search Tasks with Tallyfy

Finds tasks in Tallyfy by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/:org/checklists/search/tasks`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Search Tasks](https://tallyfy.com/products/pro/integrations/open-api/code-samples/templates/)
