# Update Task with Tallyfy

Updates an existing task in Tallyfy.

## Endpoint

- **Method:** `PUT`
- **Path:** `/organizations/:org/tasks/:task_id`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Update Task](https://tallyfy.com/products/pro/integrations/open-api/code-samples/tasks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | Task ID from Tallyfy. |
