# List Checklists with Tallyfy

Retrieves checklist blueprints from your Tallyfy organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/checklists-list`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [List Checklists](https://tallyfy.com/products/pro/integrations/open-api/code-samples/templates/)
