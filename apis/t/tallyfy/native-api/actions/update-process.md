# Update Process with Tallyfy

Updates an existing process in Tallyfy.

## Endpoint

- **Method:** `PUT`
- **Path:** `/organizations/:org/runs/:run_id`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Update Process](https://tallyfy.com/products/pro/integrations/open-api/code-samples/processes/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | Process ID from Tallyfy. |
