# List Processes with Tallyfy

Retrieves processes from your Tallyfy organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/runs`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [List Processes](https://tallyfy.com/products/pro/integrations/open-api/code-samples/processes/)
