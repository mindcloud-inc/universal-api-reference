# List Users with Tallyfy

Retrieves users from your Tallyfy organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/users-list`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [List Users](https://tallyfy.com/products/pro/integrations/open-api/code-samples/members/)
