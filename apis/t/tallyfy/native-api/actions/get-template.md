# Get Template with Tallyfy

Retrieves a template from Tallyfy.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/checklists/:checklist_id`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Get Template](https://tallyfy.com/products/pro/integrations/open-api/code-samples/templates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checklist_id` | path | `string` | yes | Template ID from Tallyfy. |
