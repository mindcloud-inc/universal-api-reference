# List Guests with Tallyfy

Retrieves guests from your Tallyfy organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/guests`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [List Guests](https://tallyfy.com/products/pro/integrations/open-api/code-samples/guests/)
