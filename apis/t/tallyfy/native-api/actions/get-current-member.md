# Get Current Member with Tallyfy

Retrieves the current member from Tallyfy.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org/me`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Get Current Member](https://tallyfy.com/products/pro/integrations/open-api/code-samples/members/)
