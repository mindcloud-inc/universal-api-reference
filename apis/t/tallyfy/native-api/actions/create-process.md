# Create Process with Tallyfy

Creates a new process from a template in Tallyfy.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/:org/runs`
- **Base URL:** `https://api.tallyfy.com`
- **Official documentation:** [Create Process](https://tallyfy.com/products/pro/integrations/open-api/code-samples/processes/)
