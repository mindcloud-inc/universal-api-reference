# Get Survey Information with Trustmary

Retrieves survey details from Trustmary.

## Endpoint

- **Method:** `GET`
- **Path:** `/survey/:surveyId`
- **Base URL:** `https://api.trustmary.io/v1`
- **Official documentation:** [Get Survey Information](https://help.trustmary.com/api#/paths/~1survey~1{surveyId}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Trustmary survey ID. |
