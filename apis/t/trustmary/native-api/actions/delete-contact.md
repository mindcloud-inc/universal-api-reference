# Delete Contact with Trustmary

Deletes an existing contact from Trustmary.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts`
- **Base URL:** `https://api.trustmary.io/v1`
- **Official documentation:** [Delete Contact](https://help.trustmary.com/api#/paths/~1contacts/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Contact email address to delete. |
