# Delete Webhook with Trustmary

Deletes an existing webhook from Trustmary.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.trustmary.io/v1`
- **Official documentation:** [Delete Webhook](https://help.trustmary.com/api#/paths/~1webhooks~1{webhook_id}/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Trustmary webhook ID. |
