# Delete Client with Timizer

Deletes an existing client from Timizer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/app/clients/:id`
- **Base URL:** `https://api.timizer.io`
- **Official documentation:** [Delete Client](https://api-doc.timizer.io)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | ID of the client. |
