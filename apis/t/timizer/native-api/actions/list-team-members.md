# List Team Members with Timizer

Retrieves team members from Timizer.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/admin-teams/:teamId/members`
- **Base URL:** `https://api.timizer.io`
- **Official documentation:** [List Team Members](https://api-doc.timizer.io)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | ID of the team. |
