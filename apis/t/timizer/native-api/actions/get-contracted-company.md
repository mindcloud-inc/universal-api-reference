# Get Contracted Company with Timizer

Retrieves a contracted company from Timizer.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/contracted/:id`
- **Base URL:** `https://api.timizer.io`
- **Official documentation:** [Get Contracted Company](https://api-doc.timizer.io)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | ID of the contracted company. |
