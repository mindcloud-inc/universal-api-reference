# Get Client with Timizer

Retrieves a client from Timizer.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/clients/:id`
- **Base URL:** `https://api.timizer.io`
- **Official documentation:** [Get Client](https://api-doc.timizer.io)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | ID of the client. |
