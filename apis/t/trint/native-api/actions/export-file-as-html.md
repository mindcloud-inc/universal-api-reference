# Export File as HTML with Trint

Exports a file as HTML from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/html/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as HTML](https://dev.trint.com/reference/html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
