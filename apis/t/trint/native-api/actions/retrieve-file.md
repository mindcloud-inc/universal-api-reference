# Retrieve File with Trint

Retrieves a file from your Trint account.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcripts/file/:id`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Retrieve File](https://dev.trint.com/reference/get-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Trint file identifier to retrieve. |
