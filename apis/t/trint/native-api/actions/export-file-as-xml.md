# Export File as XML with Trint

Exports a file as XML from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/xml/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as XML](https://dev.trint.com/reference/xmltrint-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
