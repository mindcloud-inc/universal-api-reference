# Search SCIM Users with Filter with Trint

Finds SCIM users in Trint by filter.

## Endpoint

- **Method:** `POST`
- **Path:** `https://scim.trint.com/v2/Users/.search`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Search SCIM Users with Filter](https://dev.trint.com/reference/searchusersviapost)
