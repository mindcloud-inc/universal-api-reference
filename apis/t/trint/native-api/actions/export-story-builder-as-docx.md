# Export Story Builder as DOCX with Trint

Exports a Story Builder file as DOCX from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/story-builder/docx/:fileId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export Story Builder as DOCX](https://dev.trint.com/reference/story-builder-docx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The story builder file identifier to export. |
