# Export File as Telestream Vantage XML with Trint

Exports a file as Telestream Vantage XML from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/vantage-xml/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as Telestream Vantage XML](https://dev.trint.com/reference/telestream-vantage-xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
