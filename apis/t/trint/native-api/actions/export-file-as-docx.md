# Export File as DOCX with Trint

Exports a file as DOCX from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/docx/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as DOCX](https://dev.trint.com/reference/transcript-docx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
