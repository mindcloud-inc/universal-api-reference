# Deregister Webhook Endpoint with Trint

Deregisters a webhook endpoint from Trint.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/callbacks/transcript/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Deregister Webhook Endpoint](https://dev.trint.com/reference/de-register-webook)
