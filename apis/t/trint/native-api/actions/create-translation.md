# Create Translation with Trint

Creates a new translation in Trint.

## Endpoint

- **Method:** `POST`
- **Path:** `https://translation.api.trint.com/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Create Translation](https://dev.trint.com/reference/create-translation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcriptId` | body | `string` | no | Trint transcript identifier. |
