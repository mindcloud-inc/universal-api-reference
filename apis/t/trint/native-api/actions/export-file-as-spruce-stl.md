# Export File as Spruce STL with Trint

Exports a file as Spruce STL from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/spruce-stl/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as Spruce STL](https://dev.trint.com/reference/spruce-stltrint-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
