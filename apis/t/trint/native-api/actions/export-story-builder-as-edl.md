# Export Story Builder as EDL with Trint

Exports a Story Builder file as EDL from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/story-builder/edl/:fileId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export Story Builder as EDL](https://dev.trint.com/reference/story-builder-edl)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The story builder file identifier to export. |
