# Export File as Premiere XML with Trint

Exports a file as Premiere XML from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/premiere-xml/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as Premiere XML](https://dev.trint.com/reference/premiere-xml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
