# Export Story Builder as Premiere XML with Trint

Exports a Story Builder file as Premiere XML from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/story-builder/project_xml/:fileId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export Story Builder as Premiere XML](https://dev.trint.com/reference/premiere-xml-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The story builder file identifier to export. |
