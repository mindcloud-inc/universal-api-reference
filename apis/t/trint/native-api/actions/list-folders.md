# List Folders with Trint

Retrieves folders from your Trint account.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [List Folders](https://dev.trint.com/reference/folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace-id` | query | `string` | no | Only list folders inside the specified shared drive. |
