# Export File as EDL with Trint

Exports a file as EDL from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/edl/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as EDL](https://dev.trint.com/reference/transcript-edl)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
