# Export File as Text with Trint

Exports a file as text from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/text/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as Text](https://dev.trint.com/reference/text)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
