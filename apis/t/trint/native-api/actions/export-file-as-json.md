# Export File as JSON with Trint

Exports a file as JSON from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/json/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as JSON](https://dev.trint.com/reference/jsontrint-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
