# Start New Realtime Transcript with Trint

Starts a new realtime transcript in Trint.

## Endpoint

- **Method:** `PUT`
- **Path:** `/transcripts/realtime/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Start New Realtime Transcript](https://dev.trint.com/reference/start-new-realtime-transcript)
