# Export File as Avid DS with Trint

Exports a file as Avid DS from Trint.

## Endpoint

- **Method:** `GET`
- **Path:** `/export/avid-ds/:trintId`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Export File as Avid DS](https://dev.trint.com/reference/avid-dstrint-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trintId` | path | `string` | yes | The Trint file identifier to export. |
