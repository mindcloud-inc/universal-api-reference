# Delete Translation with Trint

Deletes an existing translation from Trint.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://translation.api.trint.com/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Delete Translation](https://dev.trint.com/reference/delete-translation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcriptId` | body | `string` | no | Trint transcript identifier. |
