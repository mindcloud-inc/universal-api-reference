# Retrieve Shared Drive with Trint

Retrieves a shared drive from your Trint account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/workspace`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [Retrieve Shared Drive](https://dev.trint.com/reference/retrieve-shared-drive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `string` | yes | The shared drive identifier to retrieve. |
