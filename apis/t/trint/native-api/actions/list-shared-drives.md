# List Shared Drives with Trint

Retrieves shared drives from your Trint account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/`
- **Base URL:** `https://api.trint.com`
- **Official documentation:** [List Shared Drives](https://dev.trint.com/reference/list-workspaces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include-archived` | query | `boolean` | no | Include archived shared drives in the results. |
