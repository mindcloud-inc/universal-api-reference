# Get User with Testmo

Retrieves user details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get User](https://support.testmo.com/hc/en-us/articles/38165363497741-Users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | ID of the user to return. |
