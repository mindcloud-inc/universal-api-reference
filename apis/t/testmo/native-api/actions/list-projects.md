# List Projects with Testmo

Retrieves all accessible projects from Testmo.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Projects](https://support.testmo.com/hc/en-us/articles/38158978447885-Projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
