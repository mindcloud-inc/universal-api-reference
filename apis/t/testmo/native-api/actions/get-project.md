# Get Project with Testmo

Retrieves project details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Project](https://support.testmo.com/hc/en-us/articles/38158978447885-Projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | ID of the project to return. |
