# Get Run with Testmo

Retrieves run details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/{run_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Run](https://support.testmo.com/hc/en-us/articles/38159162797197-Runs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `number` | yes | ID of the run to return. |
