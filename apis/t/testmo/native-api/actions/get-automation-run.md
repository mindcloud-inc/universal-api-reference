# Get Automation Run with Testmo

Retrieves automation run details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/automation/runs/{automation_run_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Automation Run](https://support.testmo.com/hc/en-us/articles/37971158770957-Automation-Runs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automation_run_id` | path | `number` | yes | ID of the automation run to return. |
