# Get Milestone with Testmo

Retrieves milestone details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/milestones/{milestone_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Milestone](https://support.testmo.com/hc/en-us/articles/38157425816717-Milestones)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `milestone_id` | path | `number` | yes | ID of the milestone to return. |
