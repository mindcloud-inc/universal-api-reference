# List Users with Testmo

Retrieves all available users from Testmo.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [List Users](https://support.testmo.com/hc/en-us/articles/38165363497741-Users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
