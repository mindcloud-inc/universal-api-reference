# Get Session with Testmo

Retrieves session details from Testmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{session_id}`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Session](https://support.testmo.com/hc/en-us/articles/38159977518989-Sessions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `number` | yes | ID of the session to return. |
