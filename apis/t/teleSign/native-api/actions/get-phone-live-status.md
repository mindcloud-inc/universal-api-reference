# Get Phone Live Status with TeleSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/phoneid/live/{complete_phone_number}`
- **Base URL:** `https://rest-ww.telesign.com`
- **Official documentation:** [Get Phone Live Status](https://developer.telesign.com/enterprise/reference/submitphonenumberforlivestatus)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `complete_phone_number` | path | `string` | yes |
| `ucid` | query | `string` | yes |
