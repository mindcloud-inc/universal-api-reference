# Get SMS Transaction Status with TeleSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messaging/{reference_id}`
- **Base URL:** `https://rest-ww.telesign.com`
- **Official documentation:** [Get SMS Transaction Status](https://developer.telesign.com/enterprise/reference/getsmsstatus)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reference_id` | path | `string` | yes |
