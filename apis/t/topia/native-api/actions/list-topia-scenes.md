# List Topia Scenes with Topia

Retrieves Topia-provided scenes from the shared library.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scenes/topia-scenes`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Topia Scenes](https://api.topia.io/api-docs/paths/v1/topiaScenes.yaml)
