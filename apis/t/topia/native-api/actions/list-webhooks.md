# List Webhooks with Topia

Retrieves webhooks from a Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/webhooks`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Webhooks](https://api.topia.io/api-docs/paths/v1/webhooks.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | Topia world URL slug. |
