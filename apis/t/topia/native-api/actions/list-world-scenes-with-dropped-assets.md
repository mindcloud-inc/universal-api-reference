# List World Scenes With Dropped Assets with Topia

Retrieves scenes and dropped assets from a Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/scenes-with-dropped-assets`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List World Scenes With Dropped Assets](https://api.topia.io/api-docs/paths/v1/sceneWithDroppedAssets.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | The Topia world slug. |
