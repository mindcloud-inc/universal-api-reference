# Get World Details with Topia

Retrieves details for a specific Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/world-details`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [Get World Details](https://api.topia.io/api-docs/paths/v1/world.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | The Topia world slug. |
