# Get World Data Object with Topia

Retrieves a world's data object from Topia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/get-data-object`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [Get World Data Object](https://api.topia.io/api-docs/paths/v1/getWorldDataObject.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | The Topia world slug. |
