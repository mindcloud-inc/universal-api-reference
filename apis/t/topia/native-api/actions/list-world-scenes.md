# List World Scenes with Topia

Retrieves scenes from a specific Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/scenes`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List World Scenes](https://api.topia.io/api-docs/paths/v1/sceneDropIds.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | The Topia world slug. |
