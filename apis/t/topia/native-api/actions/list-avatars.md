# List Avatars with Topia

Retrieves available avatars from Topia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars/:profileId`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Avatars](https://api.topia.io/api-docs/paths/v1/avatars.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | Identifier for the profile. |
