# List Visitors with Topia

Retrieves visitors from a Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/visitors`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Visitors](https://api.topia.io/api-docs/paths/v1/visitors.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | Topia world URL slug. |
