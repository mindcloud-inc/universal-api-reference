# List Topia Assets with Topia

Retrieves Topia-provided assets from the shared library.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/assets/topia-assets`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Topia Assets](https://api.topia.io/api-docs/paths/v1/topiaAssets.yaml)
