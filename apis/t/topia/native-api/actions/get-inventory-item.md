# Get Inventory Item with Topia

Retrieves an inventory item from Topia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/inventory/:itemId`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [Get Inventory Item](https://api.topia.io/api-docs/paths/v1/getInventoryItem.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | Identifier for the inventory item. |
