# List Interactive Dropped Assets with Topia

Retrieves interactive dropped assets from a Topia world.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/world/:urlSlug/interactive-dropped-assets`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Interactive Dropped Assets](https://api.topia.io/api-docs/paths/v1/interactiveDroppedAssets.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | Topia world URL slug. |
