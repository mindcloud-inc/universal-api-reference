# List Interactive Worlds with Topia

Retrieves worlds with active interactive keys in Topia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user/interactive-worlds`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [List Interactive Worlds](https://api.topia.io/api-docs/paths/v1/interactiveWorlds.yaml)
