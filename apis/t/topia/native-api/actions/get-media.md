# Get Media with Topia

Retrieves media uploaded by a Topia world owner.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/media/:urlSlug`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [Get Media](https://api.topia.io/api-docs/paths/v1/media.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlSlug` | path | `string` | yes | Topia URL slug. |
