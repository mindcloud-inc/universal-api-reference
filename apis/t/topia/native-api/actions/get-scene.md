# Get Scene with Topia

Retrieves a scene from Topia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/scenes/:sceneId`
- **Base URL:** `https://api.topia.io/api`
- **Official documentation:** [Get Scene](https://api.topia.io/api-docs/paths/v1/scene.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sceneId` | path | `string` | yes | Identifier for the scene. |
