# List Contact Groups with Timetoreply

## Endpoint

- **Method:** `GET`
- **Path:** `/api/entities/contact-groups`
- **Base URL:** `https://portal.timetoreply.com`
- **Official documentation:** [List Contact Groups](https://portal.timetoreply.com/api-docs#entities-GETapi-entities-contact-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contact groups by a search term. |
