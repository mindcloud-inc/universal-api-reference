# List Users with Timetoreply

## Endpoint

- **Method:** `GET`
- **Path:** `/api/entities/users`
- **Base URL:** `https://portal.timetoreply.com`
- **Official documentation:** [List Users](https://portal.timetoreply.com/api-docs#tools-GETapi-entities-users)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter users by a search term. |
