# List Group Mailboxes with Timetoreply

## Endpoint

- **Method:** `GET`
- **Path:** `/api/entities/group-mailboxes`
- **Base URL:** `https://portal.timetoreply.com`
- **Official documentation:** [List Group Mailboxes](https://portal.timetoreply.com/api-docs#entities-GETapi-entities-group-mailboxes)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter group mailboxes by a search term. |
