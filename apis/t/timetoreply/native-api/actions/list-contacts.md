# List Contacts with Timetoreply

## Endpoint

- **Method:** `GET`
- **Path:** `/api/entities/contacts`
- **Base URL:** `https://portal.timetoreply.com`
- **Official documentation:** [List Contacts](https://portal.timetoreply.com/api-docs#entities-GETapi-entities-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contacts by a search term. |
