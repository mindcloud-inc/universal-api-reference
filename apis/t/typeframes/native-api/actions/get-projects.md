# Get Projects with Typeframes

Retrieves recent video projects from Typeframes.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects`
- **Base URL:** `https://www.revid.ai/api/public`
- **Official documentation:** [Get Projects](https://www.revid.ai/api/public/v3/render)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of projects to return. |
