# List Academy Learners with TrainerCentral

Retrieves academy learners from TrainerCentral.

## Endpoint

- **Method:** `GET`
- **Path:** `/portalMembers.json`
- **Base URL:** `{academyUrl}/api/v4/{orgId}`
- **Official documentation:** [List Academy Learners](https://help.trainercentral.com/portal/en/kb/articles/get-academy-learners-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
