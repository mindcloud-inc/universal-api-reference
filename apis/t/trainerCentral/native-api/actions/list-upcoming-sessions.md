# List Upcoming Sessions with TrainerCentral

Retrieves upcoming live workshops from TrainerCentral.

## Endpoint

- **Method:** `GET`
- **Path:** `/talks.json`
- **Base URL:** `{academyUrl}/api/v4/{orgId}`
- **Official documentation:** [List Upcoming Sessions](https://help.trainercentral.com/portal/en/kb/articles/view-all-upcoming-sessions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
