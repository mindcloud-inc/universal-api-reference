# List Organization Portals with TrainerCentral

Retrieves organization portals from TrainerCentral.

## Endpoint

- **Method:** `GET`
- **Path:** `{academyUrl}/api/v4/org/portals.json`
- **Base URL:** `{academyUrl}/api/v4/{orgId}`
- **Official documentation:** [List Organization Portals](https://help.trainercentral.com/portal/en/kb/articles/get-the-organization-id-of-your-account-portal)
