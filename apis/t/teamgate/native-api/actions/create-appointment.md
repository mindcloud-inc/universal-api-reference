# Create Appointment with Teamgate

Creates a new appointment in Teamgate.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Create Appointment](https://developers.teamgate.com/#a9a32135-d073-4a29-9f9a-2341531a9039)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Appointment name. |
