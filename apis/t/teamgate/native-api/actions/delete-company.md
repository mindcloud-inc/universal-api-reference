# Delete Company with Teamgate

Deletes a company from Teamgate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/{{companyId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Delete Company](https://developers.teamgate.com/#46a989fe-7c13-4abc-8114-1600cc9e2d41)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Company ID to delete. |
