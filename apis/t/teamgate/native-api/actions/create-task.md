# Create Task with Teamgate

Creates a new task in Teamgate.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Create Task](https://developers.teamgate.com/#85dac403-ccf3-4140-9a43-35f82403cd18)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Task name. |
