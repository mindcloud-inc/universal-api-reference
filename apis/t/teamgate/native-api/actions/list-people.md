# List People with Teamgate

Retrieves people from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List People](https://developers.teamgate.com/#7eb019a9-9168-4056-a507-75bd32c105e0)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
