# Get Activity with Teamgate

Retrieves an activity from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{{eventId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Get Activity](https://developers.teamgate.com/#5b576f18-5b18-4fb0-9cbf-8d02343420d5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Unique key of the activity. |
