# Delete Lead with Teamgate

Deletes a lead from Teamgate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/{{leadId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Delete Lead](https://developers.teamgate.com/#b0581d75-f1f5-49a2-a601-d8d28279ce87)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Lead ID to delete. |
