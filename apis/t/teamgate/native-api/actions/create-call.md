# Create Call with Teamgate

Creates a new call in Teamgate.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Create Call](https://developers.teamgate.com/#54abed6f-fc8e-44f0-bd66-8f0c15186299)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Call name. |
