# List Activities with Teamgate

Retrieves activities from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Activities](https://developers.teamgate.com/#ada4ee7b-a006-4e7c-9dee-a1db57e36755)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
