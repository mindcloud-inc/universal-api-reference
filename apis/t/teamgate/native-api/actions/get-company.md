# Get Company with Teamgate

Retrieves a company from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/{{companyId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Get Company](https://developers.teamgate.com/#480a8a97-aae6-4a18-b545-a69037b88ed1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Company ID to retrieve. |
