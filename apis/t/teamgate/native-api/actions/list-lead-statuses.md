# List Lead Statuses with Teamgate

Retrieves lead statuses from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/leadsStatuses`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Lead Statuses](https://developers.teamgate.com/#a4b61894-5087-4a91-852d-927851333503)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
