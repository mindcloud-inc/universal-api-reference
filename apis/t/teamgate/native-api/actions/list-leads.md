# List Leads with Teamgate

Retrieves leads from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Leads](https://developers.teamgate.com/#4a60be88-9991-41d2-8949-7a0f47319c80)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
