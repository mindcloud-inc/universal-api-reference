# Get Person with Teamgate

Retrieves a person from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/{{personId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Get Person](https://developers.teamgate.com/#c9850d4a-77f9-411f-8652-b924b6160723)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | Person ID to retrieve. |
