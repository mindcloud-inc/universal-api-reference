# Get Lead with Teamgate

Retrieves a lead from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/{{leadId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Get Lead](https://developers.teamgate.com/#ae9b225d-0b86-4d15-9ec4-ddba3764c3cf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Lead ID to retrieve. |
