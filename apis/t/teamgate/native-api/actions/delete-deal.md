# Delete Deal with Teamgate

Deletes a deal from Teamgate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deals/:deal_id`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Delete Deal](https://developers.teamgate.com/#30b15db5-e284-4274-9871-a6fde39fded2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deal_id` | path | `string` | yes | Deal ID to delete. |
