# Delete Person with Teamgate

Deletes a person from Teamgate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/{{personId}}`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Delete Person](https://developers.teamgate.com/#6792ed0c-bdb7-41ae-b298-a205a54a6fbf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | Person ID to delete. |
