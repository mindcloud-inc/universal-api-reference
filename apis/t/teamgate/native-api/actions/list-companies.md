# List Companies with Teamgate

Retrieves companies from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Companies](https://developers.teamgate.com/#cd8d915d-8ba3-4fbc-9932-7e6a3c4dcc08)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
