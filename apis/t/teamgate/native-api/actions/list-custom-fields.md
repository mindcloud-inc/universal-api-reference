# List Custom Fields with Teamgate

Retrieves custom fields from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/customFields`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Custom Fields](https://developers.teamgate.com/#d1ebf1aa-aed5-41df-a8b0-eb36c8221c0d)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
