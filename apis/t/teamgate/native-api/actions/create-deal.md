# Create Deal with Teamgate

Creates a new deal in Teamgate.

## Endpoint

- **Method:** `POST`
- **Path:** `/deals`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Create Deal](https://developers.teamgate.com/#7cf909d7-b66c-4ddb-ac3b-bb800f8b4ae5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Deal name. |
