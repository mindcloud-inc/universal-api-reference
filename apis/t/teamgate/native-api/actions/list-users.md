# List Users with Teamgate

Retrieves users from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Users](https://developers.teamgate.com/#9f5e25bd-ad02-4d73-a912-24216c525cb9)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
