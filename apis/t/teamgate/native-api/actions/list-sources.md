# List Sources with Teamgate

Retrieves sources from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Sources](https://developers.teamgate.com/#1071580d-c1b8-41ef-b1b3-2c73f3bc5723)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
