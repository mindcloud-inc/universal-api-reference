# Get Deal with Teamgate

Retrieves a deal from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/:deal_id`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Get Deal](https://developers.teamgate.com/#b692423c-78f3-449b-bb8b-ad73a240f833)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deal_id` | path | `string` | yes | Deal ID to retrieve. |
