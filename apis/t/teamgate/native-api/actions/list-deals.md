# List Deals with Teamgate

Retrieves deals from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Deals](https://developers.teamgate.com/#8f23eadd-e356-4b45-bdbe-b1122da6f762)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
