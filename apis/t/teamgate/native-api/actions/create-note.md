# Create Note with Teamgate

Creates a new note in Teamgate.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [Create Note](https://developers.teamgate.com/#f7b1d7c0-2c20-4dfc-9e27-39b3d9f6fc59)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | yes | Note text value. |
