# List Pipelines with Teamgate

Retrieves pipelines from Teamgate.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines`
- **Base URL:** `https://api.teamgate.com/v4`
- **Official documentation:** [List Pipelines](https://developers.teamgate.com/#43821ad0-cf31-443b-9392-4c529ab2d3a6)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
