# Get Combined Shipping Groups with Temu

Retrieve combined shipping groups including lists of parent orders that can be combined for shipping.

## Endpoint

- **Method:** `POST`
- **Path:** `/router`
- **Base URL:** `https://openapi-b-us.temu.com/openapi`
- **Official documentation:** [Get Combined Shipping Groups](https://partner-us.temu.com/documentation?menu_code=fb16b05f7a904765aac4af3a24b87d4a&sub_menu_code=67de1544d4ca4a8dbd78f57911a5159b)
