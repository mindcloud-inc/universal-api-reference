# Get Link Analytics with Tny

Retrieves analytics for a short link from Tny.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/analytics/:slug`
- **Base URL:** `https://www.tny.dev`
- **Official documentation:** [Get Link Analytics](https://www.tny.dev/api-docs#get-analytics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The short link slug to inspect. |
