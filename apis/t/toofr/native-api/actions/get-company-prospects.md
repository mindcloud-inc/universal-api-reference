# Get Company Prospects with Toofr

Retrieves prospects for a company from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_prospects`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Get Company Prospects](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_name` | query | `string` | yes | Company name to retrieve prospects for. |
