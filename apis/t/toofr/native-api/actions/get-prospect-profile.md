# Get Prospect Profile with Toofr

Retrieves a prospect profile from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Get Prospect Profile](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Prospect email address. |
| `first_name` | query | `string` | yes | Prospect first name. |
| `last_name` | query | `string` | yes | Prospect last name. |
