# List Owned Email Lists with Toofr

Retrieves owned email lists from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [List Owned Email Lists](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Optional provider page number. |
