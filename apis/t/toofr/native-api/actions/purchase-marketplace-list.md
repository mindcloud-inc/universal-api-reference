# Purchase Marketplace List with Toofr

Purchases a marketplace email list in Toofr.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/:id/purchase`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Purchase Marketplace List](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Marketplace email list ID to purchase. |
