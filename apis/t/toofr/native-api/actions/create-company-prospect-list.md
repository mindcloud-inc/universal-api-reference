# Create Company Prospect List with Toofr

Creates a company prospect list in Toofr.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Create Company Prospect List](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `description` | query | `string` | no | Optional processing list description. |
| `name` | query | `string` | yes | Name for the processing list. |
