# Classify Company with Toofr

Retrieves company classification details from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/classify`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Classify Company](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_name` | query | `string` | yes | Company name to classify. |
