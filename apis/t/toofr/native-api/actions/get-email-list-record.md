# Get Email List Record with Toofr

Retrieves an email list record from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:list_id/list_records/:id`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Get Email List Record](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email list record ID. |
| `list_id` | path | `string` | yes | Email list ID. |
