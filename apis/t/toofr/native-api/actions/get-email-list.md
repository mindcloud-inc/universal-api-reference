# Get Email List with Toofr

Retrieves an email list from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Get Email List](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email list ID. |
