# Get Company Domain with Toofr

Retrieves a company's domain from Toofr.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_domain`
- **Base URL:** `https://www.findemails.com/api/v1`
- **Official documentation:** [Get Company Domain](https://developer.findemails.com/?from=explinks.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_name` | query | `string` | yes | Company name to resolve to a domain. |
