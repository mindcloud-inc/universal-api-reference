# Get Article with Tender Support

Retrieves a knowledge base article from Tender Support.

## Endpoint

- **Method:** `GET`
- **Path:** `/faqs/:faqId`
- **Base URL:** `https://api.tenderapp.com/help`
- **Official documentation:** [Get Article](https://help.tenderapp.com/kb/api/kb-articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `faqId` | path | `number` | yes | The Tender knowledge-base article ID. |
