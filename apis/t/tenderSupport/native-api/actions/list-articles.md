# List Articles with Tender Support

Retrieves knowledge base articles from Tender Support.

## Endpoint

- **Method:** `GET`
- **Path:** `/faqs`
- **Base URL:** `https://api.tenderapp.com/help`
- **Official documentation:** [List Articles](https://help.tenderapp.com/kb/api/kb-articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `section_id` | query | `number` | no | Filter articles to a specific section ID. |
