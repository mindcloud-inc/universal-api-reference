# Get Discussion with Tender Support

Retrieves a discussion from Tender Support.

## Endpoint

- **Method:** `GET`
- **Path:** `/discussions/:discussionId`
- **Base URL:** `https://api.tenderapp.com/help`
- **Official documentation:** [Get Discussion](https://help.tenderapp.com/kb/api/discussions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discussionId` | path | `number` | yes | The Tender discussion ID. |
