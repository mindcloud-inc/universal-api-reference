# Get Category with Tender Support

Retrieves a category from Tender Support.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:categoryId`
- **Base URL:** `https://api.tenderapp.com/help`
- **Official documentation:** [Get Category](https://help.tenderapp.com/kb/api/categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `number` | yes | The Tender category ID. |
