# Export Knowledge Card to PowerPoint with Tako

Exports a Tako knowledge card to PowerPoint.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/powerpoint`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [Export Knowledge Card to PowerPoint](https://docs.tako.com/api-reference/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `card_id` | query | `string` | yes | ID of the knowledge card to export as a PowerPoint deck. |
