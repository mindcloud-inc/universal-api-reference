# Get File with Tako

Retrieves file metadata from Tako.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/beta/files/{file_id}/`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [Get File](https://docs.tako.com/api-reference/files-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | ID of the Tako file to retrieve. |
