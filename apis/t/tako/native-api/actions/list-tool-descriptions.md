# List Tool Descriptions with Tako

Retrieves tool descriptions from Tako.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tako_tools_description`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [List Tool Descriptions](https://docs.tako.com/api-reference/tool-descriptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `index_ids` | query | `string` | no | Optional comma-separated index IDs to scope the returned tool descriptions. |
