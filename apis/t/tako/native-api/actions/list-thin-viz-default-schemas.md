# List Thin-Viz Default Schemas with Tako

Retrieves Thin-Viz default schemas from Tako.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/thin_viz/default_schema/`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [List Thin-Viz Default Schemas](https://docs.tako.com/api-reference/thinviz-default-schema-list)
