# Get Thin-Viz Default Schema with Tako

Retrieves a Thin-Viz default schema from Tako.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/thin_viz/default_schema/{schema_name}/`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [Get Thin-Viz Default Schema](https://docs.tako.com/api-reference/thinviz-default-schema-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schema_name` | path | `string` | yes | Name of the default schema to retrieve. |
