# Get File Upload URL with Tako

Retrieves a file upload URL from Tako.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/beta/file_upload_url`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [Get File Upload URL](https://docs.tako.com/api-reference/file-upload-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_name` | query | `string` | yes | Name of the file you plan to upload. |
