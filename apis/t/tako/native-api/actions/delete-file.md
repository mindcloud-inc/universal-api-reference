# Delete File with Tako

Deletes a file from Tako.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/beta/files/{file_id}/`
- **Base URL:** `https://tako.com/api`
- **Official documentation:** [Delete File](https://docs.tako.com/api-reference/files-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | ID of the Tako file to delete. |
