# Get Document with Tinq.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/documents/:slug`
- **Base URL:** `https://tinq.ai`
- **Official documentation:** [Get Document](https://docs.tinq.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Document slug to fetch. |
