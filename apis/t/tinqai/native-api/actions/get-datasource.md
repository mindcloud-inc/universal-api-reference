# Get Datasource with Tinq.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/datasources/:workspaceId/:datasourceId`
- **Base URL:** `https://tinq.ai`
- **Official documentation:** [Get Datasource](https://docs.tinq.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasourceId` | path | `string` | yes | Datasource ID to fetch. |
