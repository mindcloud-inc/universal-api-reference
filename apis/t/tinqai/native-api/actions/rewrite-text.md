# Rewrite Text with Tinq.ai

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/rewrite`
- **Base URL:** `https://tinq.ai`
- **Official documentation:** [Rewrite Text](https://docs.tinq.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Text to rewrite. |
