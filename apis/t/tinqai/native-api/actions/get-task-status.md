# Get Task Status with Tinq.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tasks/:taskId`
- **Base URL:** `https://tinq.ai`
- **Official documentation:** [Get Task Status](https://docs.tinq.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Task identifier to inspect. |
