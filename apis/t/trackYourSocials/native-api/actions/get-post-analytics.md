# Get Post Analytics with TrackYourSocials

Retrieves engagement metrics for a social media post from TrackYourSocials.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/analytics`
- **Base URL:** `https://trackyoursocials.com`
- **Official documentation:** [Get Post Analytics](https://trackyoursocials.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `media_link` | query | `string` | yes | URL of the social media content to analyze. |
