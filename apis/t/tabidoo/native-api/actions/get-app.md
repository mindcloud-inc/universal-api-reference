# Get App with Tabidoo

Retrieves an application from a Tabidoo workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId`
- **Base URL:** `https://app.tabidoo.cloud/api/v2`
- **Official documentation:** [Get App](https://tabidoo.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The Tabidoo application ID. |
