# List App Tables with Tabidoo

Retrieves tables for an application in Tabidoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:appId/tables`
- **Base URL:** `https://app.tabidoo.cloud/api/v2`
- **Official documentation:** [List App Tables](https://tabidoo.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The Tabidoo application ID. |
