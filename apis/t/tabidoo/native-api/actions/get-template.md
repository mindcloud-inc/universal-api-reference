# Get Template with Tabidoo

Retrieves a template from the Tabidoo marketplace.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId`
- **Base URL:** `https://app.tabidoo.cloud/api/v2`
- **Official documentation:** [Get Template](https://tabidoo.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The Tabidoo template ID. |
