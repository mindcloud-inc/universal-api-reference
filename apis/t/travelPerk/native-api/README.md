# TravelPerk: Native API Reference

A consolidated summary of TravelPerk's API configuration and 20 documented operations, with links to official documentation.

- **Official docs:** https://developers.perk.com/reference
- **REST API base URL:** `https://api.sandbox-travelperk.com`
- **REST API base URL:** `https://app.travelperk.com/api/v2/scim`

## Authentication

### API Key

Use a TravelPerk API key generated by an account admin.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
Authorization: Bearer <apiKey>
```

[Official authentication documentation](https://developers.perk.com/docs/quickstart)

## API conventions

### REST API

Shared headers:

| Header | Value |
| --- | --- |
| `Api-Version` | `1` |

## Pagination

- **REST API:** Use `limit` in the query string to set the page size (default 10). Use `offset` in the query string as the record offset; numbering starts at 0.

## Sorting

- **REST API:** Set the sort field with `sort` in the query string. Only one sort field is accepted.
