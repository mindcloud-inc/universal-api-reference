# List Cost Centers with TravelPerk

Retrieves cost centers from TravelPerk.

## Endpoint

- **Method:** `GET`
- **Path:** `/cost_centers`
- **Base URL:** `https://api.sandbox-travelperk.com`
- **API:** rest
- **Official documentation:** [List Cost Centers](https://developers.perk.com/docs/cost-centers-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Api-Version` | `1` |
