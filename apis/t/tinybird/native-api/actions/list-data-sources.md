# List Data Sources with Tinybird

## Endpoint

- **Method:** `GET`
- **Path:** `v0/datasources`
- **Base URL:** `{apiHost}`
- **Official documentation:** [List Data Sources](https://www.tinybird.co/docs/api-reference/datasource-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attrs` | query | `string` | no | Comma-separated data source attributes to return. |
