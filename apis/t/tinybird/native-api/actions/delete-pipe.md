# Delete Pipe with Tinybird

## Endpoint

- **Method:** `DELETE`
- **Path:** `v0/pipes/:name`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Delete Pipe](https://www.tinybird.co/docs/api-reference/pipe-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The pipe name to target. |
