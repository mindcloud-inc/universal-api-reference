# Truncate Data Source with Tinybird

## Endpoint

- **Method:** `POST`
- **Path:** `v0/datasources/:name/truncate`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Truncate Data Source](https://www.tinybird.co/docs/api-reference/datasource-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The data source name to target. |
