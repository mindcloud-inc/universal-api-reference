# Execute SQL Query (GET) with Tinybird

## Endpoint

- **Method:** `GET`
- **Path:** `v0/sql`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Execute SQL Query (GET)](https://www.tinybird.co/docs/api-reference/query-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The SQL query to execute. |
