# Get Environment Variable with Tinybird

## Endpoint

- **Method:** `GET`
- **Path:** `v0/variables/:name`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Get Environment Variable](https://www.tinybird.co/docs/api-reference/environment-variables-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | The environment variable name. |
