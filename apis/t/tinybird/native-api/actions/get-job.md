# Get Job with Tinybird

## Endpoint

- **Method:** `GET`
- **Path:** `v0/jobs/:id`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Get Job](https://www.tinybird.co/docs/api-reference/jobs-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The job id to target. |
