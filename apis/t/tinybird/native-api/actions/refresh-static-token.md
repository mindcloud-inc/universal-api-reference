# Refresh Static Token with Tinybird

## Endpoint

- **Method:** `POST`
- **Path:** `v0/tokens/:token/refresh`
- **Base URL:** `{apiHost}`
- **Official documentation:** [Refresh Static Token](https://www.tinybird.co/docs/api-reference/token-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | The static token name. |
