# List User Projects with TickTick

Retrieves the user's projects from TickTick.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/project`
- **Base URL:** `https://api.ticktick.com`
- **Official documentation:** [List User Projects](https://developer.ticktick.com/docs/index.html#/openapi?id=get-user-project)
