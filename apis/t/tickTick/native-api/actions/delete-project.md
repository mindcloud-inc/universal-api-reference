# Delete Project with TickTick

Deletes an existing project from TickTick.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open/v1/project/:projectId`
- **Base URL:** `https://api.ticktick.com`
- **Official documentation:** [Delete Project](https://developer.ticktick.com/docs/index.html#/openapi?id=delete-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `list<string>` | yes | Project identifier |
