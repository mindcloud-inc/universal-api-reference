# Get Project By ID with TickTick

Retrieves a project from TickTick by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/project/:projectId`
- **Base URL:** `https://api.ticktick.com`
- **Official documentation:** [Get Project By ID](https://developer.ticktick.com/docs/index.html#/openapi?id=get-project-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `list<string>` | yes | Project identifier |
