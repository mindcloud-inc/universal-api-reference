# Delete Form Translation with Typeform

## Endpoint

- **Method:** `DELETE`
- **Path:** `/forms/:formId/translations/:language`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Delete Form Translation](https://www.typeform.com/developers/create/reference/delete-form-translation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
| `language` | path | `string` | yes | Language code. |
