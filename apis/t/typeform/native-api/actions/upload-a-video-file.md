# Upload a Video File with Typeform

## Endpoint

- **Method:** `POST`
- **Path:** `/media/videos`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Upload a Video File](https://www.typeform.com/developers/create/reference/upload-a-video-file/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | body | `string` | no | Field identifier for the video upload. |
| `form_id` | body | `string` | no | Form identifier for the video upload. |
| `language` | body | `string` | no | Language code for the media asset. |
