# Retrieve Background by Size with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/images/:imageId/background/:size`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Retrieve Background by Size](https://www.typeform.com/developers/create/reference/retrieve-background-by-size/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageId` | path | `string` | yes | Typeform image identifier. |
| `size` | path | `string` | yes | Image size variant. |
