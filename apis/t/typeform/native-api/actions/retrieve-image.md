# Retrieve Image with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/images/:imageId`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Retrieve Image](https://www.typeform.com/developers/create/reference/retrieve-image/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageId` | path | `string` | yes | Typeform image identifier. |
