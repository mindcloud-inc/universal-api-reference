# List Webhooks with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/webhooks`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [List Webhooks](https://www.typeform.com/developers/webhooks/reference/retrieve-webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
