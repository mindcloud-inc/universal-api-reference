# Create Image with Typeform

## Endpoint

- **Method:** `POST`
- **Path:** `/images`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Create Image](https://www.typeform.com/developers/create/reference/create-image/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_name` | body | `string` | no | File name for the uploaded image. |
| `image` | body | `string` | no | Image payload. |
| `url` | body | `string` | no | Public URL of the image. |
