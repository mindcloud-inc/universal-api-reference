# Retrieve Translation Payload with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/translations/main`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Retrieve Translation Payload](https://www.typeform.com/developers/create/reference/retrieve-translation-payload/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
