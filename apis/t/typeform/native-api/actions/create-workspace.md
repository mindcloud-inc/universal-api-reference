# Create Workspace with Typeform

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Create Workspace](https://www.typeform.com/developers/create/reference/create-workspace/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Name of the new workspace. |
