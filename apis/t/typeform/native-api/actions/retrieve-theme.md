# Retrieve Theme with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/themes/:themeId`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Retrieve Theme](https://www.typeform.com/developers/create/reference/retrieve-theme/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `themeId` | path | `string` | yes | Typeform theme identifier. |
