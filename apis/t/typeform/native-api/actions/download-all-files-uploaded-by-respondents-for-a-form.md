# Download All Files Uploaded by Respondents for a Form with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/responses/files`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Download All Files Uploaded by Respondents for a Form](https://www.typeform.com/developers/responses/reference/download-all-files-uploaded-by-respondents-for-a-form/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
