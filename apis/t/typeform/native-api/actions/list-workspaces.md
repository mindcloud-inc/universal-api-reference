# List Workspaces with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [List Workspaces](https://www.typeform.com/developers/create/reference/retrieve-workspaces/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter workspaces by name text. |
