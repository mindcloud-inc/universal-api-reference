# Get Form with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Get Form](https://www.typeform.com/developers/create/reference/retrieve-form/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `list` | yes | Typeform form ID. |
