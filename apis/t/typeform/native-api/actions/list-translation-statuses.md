# List Translation Statuses with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/translations/status`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [List Translation Statuses](https://www.typeform.com/developers/create/reference/retrieve-translation-statuses/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
