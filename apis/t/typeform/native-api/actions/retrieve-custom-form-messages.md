# Retrieve Custom Form Messages with Typeform

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/messages`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Retrieve Custom Form Messages](https://www.typeform.com/developers/create/reference/retrieve-custom-form-messages/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Typeform form identifier. |
