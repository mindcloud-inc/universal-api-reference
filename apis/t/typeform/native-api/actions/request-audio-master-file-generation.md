# Request Audio Master File Generation with Typeform

## Endpoint

- **Method:** `POST`
- **Path:** `/media/audios/:id/master`
- **Base URL:** `https://api.typeform.com`
- **Official documentation:** [Request Audio Master File Generation](https://www.typeform.com/developers/responses/reference/request-audio-master-file-generation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Media identifier. |
