# Query Views for Site with Tableau Cloud

Retrieves site views from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/views`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Views for Site](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_site.htm#query_views_for_site)

## Capabilities

This operation supports [pagination](../README.md#pagination).
