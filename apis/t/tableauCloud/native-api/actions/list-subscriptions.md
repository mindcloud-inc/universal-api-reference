# List Subscriptions with Tableau Cloud

Retrieves a list of subscriptions from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/subscriptions`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [List Subscriptions](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_subscriptions.htm#list_subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
