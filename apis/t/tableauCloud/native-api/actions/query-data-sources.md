# Query Data Sources with Tableau Cloud

Retrieves a list of data sources from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/datasources`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Data Sources](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#query_data_sources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
