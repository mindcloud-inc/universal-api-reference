# Query Projects with Tableau Cloud

Retrieves a list of projects from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/projects`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Projects](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_projects.htm#query_projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
