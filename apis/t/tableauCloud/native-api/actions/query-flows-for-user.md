# Query Flows for User with Tableau Cloud

Retrieves a user's flows from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/users/user-id/flows`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Flows for User](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_flow.htm#query_flows_for_user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
