# Delete Flow with Tableau Cloud

Deletes a flow from Tableau Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/site-id/flows/flow-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Delete Flow](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_flow.htm#delete_flow)
