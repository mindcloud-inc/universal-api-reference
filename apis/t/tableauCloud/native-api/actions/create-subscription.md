# Create Subscription with Tableau Cloud

Creates a new subscription in Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/subscriptions`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Create Subscription](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_subscriptions.htm#create_subscription)
