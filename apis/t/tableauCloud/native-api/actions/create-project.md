# Create Project with Tableau Cloud

Creates a new project in Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/projects`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Create Project](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_projects.htm#create_project)
