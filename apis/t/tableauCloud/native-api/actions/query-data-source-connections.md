# Query Data Source Connections with Tableau Cloud

Retrieves data source connections from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/datasources/datasource-id/connections`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Data Source Connections](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#query_data_source_connections)
