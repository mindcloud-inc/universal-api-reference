# Update Project with Tableau Cloud

Updates an existing project in Tableau Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sites/site-id/projects/project-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Update Project](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_projects.htm#update_project)
