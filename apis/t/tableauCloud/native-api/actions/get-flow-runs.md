# Get Flow Runs with Tableau Cloud

Retrieves flow runs from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/flows/runs`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Get Flow Runs](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_flow.htm#get_flow_runs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
