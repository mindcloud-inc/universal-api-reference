# Publish Data Source with Tableau Cloud

Publishes a data source to Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/datasources`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Publish Data Source](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_publishing.htm#publish_data_source)
