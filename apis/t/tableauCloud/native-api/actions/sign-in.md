# Sign In with Tableau Cloud

Signs in to Tableau Cloud and returns an auth token.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth/signin`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Sign In](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_authentication.htm#sign_in)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
