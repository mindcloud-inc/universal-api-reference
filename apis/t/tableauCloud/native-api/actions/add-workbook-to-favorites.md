# Add Workbook to Favorites with Tableau Cloud

Adds a workbook to favorites in Tableau Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sites/site-id/favorites/user-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Add Workbook to Favorites](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_favorites.htm#add_workbook_to_favorites)
