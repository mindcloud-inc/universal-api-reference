# Publish Workbook with Tableau Cloud

Publishes a workbook to Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/workbooks`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Publish Workbook](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_publishing.htm#publish_workbook)
