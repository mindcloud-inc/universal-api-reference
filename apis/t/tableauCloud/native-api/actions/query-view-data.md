# Query View Data with Tableau Cloud

Retrieves view data from Tableau Cloud as CSV.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/views/view-id/data`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query View Data](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#query_view_data)
