# Download Data Source with Tableau Cloud

Downloads a data source from Tableau Cloud as TDSX.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/datasources/datasource-id/content`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Download Data Source](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#download_data_source)
