# Query Workbook Connections with Tableau Cloud

Retrieves workbook connections from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/workbooks/workbook-id/connections`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Workbook Connections](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#query_workbook_connections)
