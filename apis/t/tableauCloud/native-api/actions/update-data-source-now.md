# Update Data Source Now with Tableau Cloud

Refreshes a data source in Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/datasources/datasource-id/refresh`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Update Data Source Now](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#update_data_source_now)
