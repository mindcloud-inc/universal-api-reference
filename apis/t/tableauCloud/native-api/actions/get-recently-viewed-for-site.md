# Get Recently Viewed for Site with Tableau Cloud

Retrieves recently viewed content from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/content/recent`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Get Recently Viewed for Site](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_site.htm#get_recently_viewed)
