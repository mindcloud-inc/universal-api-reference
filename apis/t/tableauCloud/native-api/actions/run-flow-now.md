# Run Flow Now with Tableau Cloud

Runs a flow in Tableau Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/sites/site-id/flows/flow-id/run`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Run Flow Now](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_flow.htm#run_flow_now)
