# Update Data Source with Tableau Cloud

Updates an existing data source in Tableau Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sites/site-id/datasources/datasource-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Update Data Source](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#update_data_source)
