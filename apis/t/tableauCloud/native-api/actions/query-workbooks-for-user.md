# Query Workbooks for User with Tableau Cloud

Retrieves a user's workbooks from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/users/user-id/workbooks`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Workbooks for User](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#query_workbooks_for_user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
