# Get View with Tableau Cloud

Retrieves a view from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/views/view-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Get View](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#get_view)
