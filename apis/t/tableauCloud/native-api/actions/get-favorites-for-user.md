# Get Favorites for User with Tableau Cloud

Retrieves a user's favorites from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/favorites/user-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Get Favorites for User](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_favorites.htm#get_favorites_for_user)
