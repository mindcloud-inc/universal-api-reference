# Delete Workbook from Favorites with Tableau Cloud

Deletes a workbook from favorites in Tableau Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/site-id/favorites/user-id/workbooks/workbook-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Delete Workbook from Favorites](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_favorites.htm#delete_workbook_from_favorites)
