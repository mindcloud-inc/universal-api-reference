# Query Flow Connections with Tableau Cloud

Retrieves flow connections from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/flows/flow-id/connections`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Flow Connections](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_flow.htm#query_flow_connections)
