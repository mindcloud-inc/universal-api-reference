# Query Views for Workbook with Tableau Cloud

Retrieves workbook views from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/workbooks/workbook-id/views`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Views for Workbook](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#query_views_for_workbook)
