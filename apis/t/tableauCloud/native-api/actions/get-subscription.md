# Get Subscription with Tableau Cloud

Retrieves a subscription from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/subscriptions/subscription-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Get Subscription](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_subscriptions.htm#get_subscription)
