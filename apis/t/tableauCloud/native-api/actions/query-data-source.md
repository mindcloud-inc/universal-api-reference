# Query Data Source with Tableau Cloud

Retrieves a data source from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/datasources/datasource-id`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Data Source](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#query_data_source)
