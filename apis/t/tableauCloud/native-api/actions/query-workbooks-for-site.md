# Query Workbooks for Site with Tableau Cloud

Retrieves site workbooks from Tableau Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/site-id/workbooks`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Query Workbooks for Site](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_workbooks_and_views.htm#query_workbooks_for_site)

## Capabilities

This operation supports [pagination](../README.md#pagination).
