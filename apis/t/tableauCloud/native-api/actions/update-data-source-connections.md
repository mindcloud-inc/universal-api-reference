# Update Data Source Connections with Tableau Cloud

Updates data source connections in Tableau Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sites/site-id/datasources/datasource-id/connections`
- **Base URL:** `https://us-east-1.online.tableau.com/api/3.28`
- **Official documentation:** [Update Data Source Connections](https://help.tableau.com/current/api/rest_api/en-us/REST/rest_api_ref_data_sources.htm#update_data_source_connections)
