# Get ThemeForest Popular Items with Themeforest

Retrieves popular marketplace items from ThemeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/popular::site.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest Popular Items](https://build.envato.com/api/#market_getPopular)
