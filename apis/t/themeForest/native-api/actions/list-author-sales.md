# List Author Sales with Themeforest

Retrieves author sales from Envato Market.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/market/author/sales`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [List Author Sales](https://build.envato.com/api/#market_0_getAuthorSales)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Author sales result page number. |
