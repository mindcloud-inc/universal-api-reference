# Get Catalog Item Version with Themeforest

Retrieves the latest version for an Envato catalog item.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/market/catalog/item-version`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get Catalog Item Version](https://build.envato.com/api/#market_0_getCatalogItemVersion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Envato catalog item ID. |
