# Get ThemeForest Featured Items with Themeforest

Retrieves featured marketplace items from ThemeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/features::site.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest Featured Items](https://build.envato.com/api/#market_getFeatures)
