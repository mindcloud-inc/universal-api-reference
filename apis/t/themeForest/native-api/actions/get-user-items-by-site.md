# Get User Items By Site with Themeforest

Retrieves an Envato user's item counts by site.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/user-items-by-site::username.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get User Items By Site](https://build.envato.com/api/#market_getUserItemsBySite)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Envato username. |
