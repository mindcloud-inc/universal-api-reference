# Get Catalog Item with Themeforest

Retrieves details for an Envato catalog item.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/market/catalog/item`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get Catalog Item](https://build.envato.com/api/#market_0_getCatalogItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Envato catalog item ID. |
