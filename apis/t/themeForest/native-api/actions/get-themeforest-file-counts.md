# Get ThemeForest File Counts with Themeforest

Retrieves marketplace file counts from ThemeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/number-of-files::site.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest File Counts](https://build.envato.com/api/#market_getNumberOfFiles)
