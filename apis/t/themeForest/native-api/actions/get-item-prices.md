# Get Item Prices with Themeforest

Retrieves license prices for an Envato item.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/item-prices::item_id.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get Item Prices](https://build.envato.com/api/#market_getItemPrices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `number` | yes | Envato item ID. |
