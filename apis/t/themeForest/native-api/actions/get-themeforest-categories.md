# Get ThemeForest Categories with Themeforest

Retrieves marketplace category listings from ThemeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/categories::site.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest Categories](https://build.envato.com/api/#market_getCategories)
