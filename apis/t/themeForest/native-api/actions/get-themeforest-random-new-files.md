# Get ThemeForest Random New Files with Themeforest

Retrieves random new marketplace files from ThemeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/random-new-files::site.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest Random New Files](https://build.envato.com/api/#market_getRandomNewFiles)
