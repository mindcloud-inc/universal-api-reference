# Get User Badges with Themeforest

Retrieves badges for an Envato user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/user-badges::username.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get User Badges](https://build.envato.com/api/#market_getUserBadges)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Envato username. |
