# Get User Profile with Themeforest

Retrieves profile details for an Envato user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/user::username.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get User Profile](https://build.envato.com/api/#market_getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Envato username. |
