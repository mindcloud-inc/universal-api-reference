# Get Catalog Collection with Themeforest

Retrieves details for an Envato catalog collection.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/market/catalog/collection`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get Catalog Collection](https://build.envato.com/api/#market_0_getCatalogCollection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Envato catalog collection ID. |
| `page` | query | `number` | no | Collection result page number. |
