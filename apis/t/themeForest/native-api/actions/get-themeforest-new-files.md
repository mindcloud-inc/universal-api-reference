# Get ThemeForest New Files with Themeforest

Retrieves new marketplace files for a ThemeForest category.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/market/new-files::site,:category.json`
- **Base URL:** `https://api.envato.com`
- **Official documentation:** [Get ThemeForest New Files](https://build.envato.com/api/#market_getNewFiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | path | `string` | yes | ThemeForest category slug. |
