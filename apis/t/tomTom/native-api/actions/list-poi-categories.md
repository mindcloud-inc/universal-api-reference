# List POI Categories with TomTom

Retrieves available POI categories from TomTom.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/2/poiCategories.json`
- **Base URL:** `https://api.tomtom.com`
- **Official documentation:** [List POI Categories](https://developer.tomtom.com/search-api/documentation/poi-categories-service/poi-categories)
