# Delete User with TalentLMS

Deletes an existing user from TalentLMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Delete User](https://documenter.getpostman.com/view/31867199/2sAY548Kou#delete-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric user ID. |
