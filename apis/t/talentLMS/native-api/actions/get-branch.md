# Get Branch with TalentLMS

Retrieves a branch from a TalentLMS domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/branches/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Get Branch](https://documenter.getpostman.com/view/31867199/2sAY548Kou#get-a-branch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric branch ID. |
