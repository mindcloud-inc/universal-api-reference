# Get Group with TalentLMS

Retrieves a group from a TalentLMS domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Get Group](https://documenter.getpostman.com/view/31867199/2sAY548Kou#get-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric group ID. |
