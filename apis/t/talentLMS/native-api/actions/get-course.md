# Get Course with TalentLMS

Retrieves a course from a TalentLMS domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Get Course](https://documenter.getpostman.com/view/31867199/2sAY548Kou#get-a-course)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric course ID. |
