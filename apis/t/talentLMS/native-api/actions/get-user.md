# Get User with TalentLMS

Retrieves a user from a TalentLMS domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Get User](https://documenter.getpostman.com/view/31867199/2sAY548Kou#get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric user ID. |
