# Delete Course with TalentLMS

Deletes an existing course from TalentLMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/courses/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Delete Course](https://documenter.getpostman.com/view/31867199/2sAY548Kou#delete-a-course)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric course ID. |
