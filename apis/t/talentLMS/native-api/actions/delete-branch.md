# Delete Branch with TalentLMS

Deletes an existing branch from TalentLMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/branches/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Delete Branch](https://documenter.getpostman.com/view/31867199/2sAY548Kou#delete-a-branch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric branch ID. |
