# Delete Group with TalentLMS

Deletes an existing group from TalentLMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:id`
- **Base URL:** `https://{domain}.talentlms.com/api/v2`
- **Official documentation:** [Delete Group](https://documenter.getpostman.com/view/31867199/2sAY548Kou#delete-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric group ID. |
