# Get Project with Tolstoy

Retrieves a specific project from Tolstoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.gotolstoy.com`
- **Official documentation:** [Get Project](https://developers.gotolstoy.com/api-reference/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project id |
