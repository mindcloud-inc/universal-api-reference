# Delete Webhook with Tolstoy

Deletes an existing webhook from Tolstoy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.gotolstoy.com`
- **Official documentation:** [Delete Webhook](https://developers.gotolstoy.com/webhooks/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook id to delete |
