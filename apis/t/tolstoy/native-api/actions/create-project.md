# Create Project with Tolstoy

Creates a new project in Tolstoy.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/`
- **Base URL:** `https://api.gotolstoy.com`
- **Official documentation:** [Create Project](https://developers.gotolstoy.com/api-reference/create-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | body | `object` | yes | Project details |
