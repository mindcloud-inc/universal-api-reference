# List Languages with Tisane Labs

Retrieves supported languages from Tisane Labs.

## Endpoint

- **Method:** `GET`
- **Path:** `/languages`
- **Base URL:** `https://api.tisane.ai`
- **Official documentation:** [List Languages](https://docs.tisane.ai/apis/tisane-api-short#tag/NLU-/-NLP-Methods/operation/languages)

| --- | --- |
