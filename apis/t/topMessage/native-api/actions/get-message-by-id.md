# Get Message By ID with TopMessage

Retrieves a message by ID from TopMessage.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messages/:Id`
- **Base URL:** `https://api.topmessage.com`
- **Official documentation:** [Get Message By ID](https://topmessage.com/documentation-api/get-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | path | `string` | yes | The unique identifier of the TopMessage message to retrieve. |
