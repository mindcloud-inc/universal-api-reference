# List Holidays with TalentHR

Retrieves holidays from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/holidays`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Holidays](https://apidocs.talenthr.io/#b982bd62-450c-42ea-830d-baad9cdbc681)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | Holiday calendar year. |
