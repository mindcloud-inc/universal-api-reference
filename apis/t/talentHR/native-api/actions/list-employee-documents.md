# List Employee Documents with TalentHR

Retrieves an employee's documents from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/documents`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Employee Documents](https://apidocs.talenthr.io/#25efd277-dc78-4e91-87e5-6110a9ad2afe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
