# Get Benefit Filters with TalentHR

Retrieves benefit filters from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/benefits/filters`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Get Benefit Filters](https://apidocs.talenthr.io/#7ae15e7f-674f-463c-ae36-a264a770c0da)
