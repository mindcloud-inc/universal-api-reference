# Get Employee Job Info with TalentHR

Retrieves employee job details from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/job`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Get Employee Job Info](https://apidocs.talenthr.io/#8b799f5a-3bf1-49de-9596-7c93bb9a0ab1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
