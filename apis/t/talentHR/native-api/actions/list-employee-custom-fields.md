# List Employee Custom Fields with TalentHR

Retrieves an employee's custom fields from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/custom-fields`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Employee Custom Fields](https://apidocs.talenthr.io/#424e3e8c-37f6-4a41-b3a1-b279dbafc300)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
