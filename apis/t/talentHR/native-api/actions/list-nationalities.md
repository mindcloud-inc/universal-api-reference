# List Nationalities with TalentHR

Retrieves supported nationalities from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/nationalities`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Nationalities](https://apidocs.talenthr.io/#e3f3f91b-e2ff-43cc-a9ff-987951f1f92e)
