# List Employee Time Off Budgets with TalentHR

Retrieves an employee's time off budgets from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/time-off-budgets`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Employee Time Off Budgets](https://apidocs.talenthr.io/#91964ca0-2bd4-46f1-ae78-8c7c6a838321)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
