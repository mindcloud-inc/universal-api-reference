# Create Job Title with TalentHR

Creates a new job title in TalentHR.

## Endpoint

- **Method:** `POST`
- **Path:** `/job-titles`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Create Job Title](https://apidocs.talenthr.io/#35b2c197-6086-4711-b067-dbcd01238028)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Job title name. |
