# Get Employee with TalentHR

Retrieves an employee from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Get Employee](https://apidocs.talenthr.io/#43259b6a-44be-49ee-bd12-340bccd764a9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
