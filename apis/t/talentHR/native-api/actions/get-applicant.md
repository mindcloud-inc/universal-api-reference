# Get Applicant with TalentHR

Retrieves an applicant from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/ats-applicants/:objectId`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Get Applicant](https://apidocs.talenthr.io/#833a9f06-2343-4d29-b684-3c54ec780a96)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `objectId` | path | `number` | yes | TalentHR applicant ID. |
