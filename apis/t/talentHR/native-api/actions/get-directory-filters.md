# Get Directory Filters with TalentHR

Retrieves employee directory filters from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/directory/filters`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Get Directory Filters](https://apidocs.talenthr.io/#b25229d2-06f8-45f9-8b23-f14b725b7b77)
