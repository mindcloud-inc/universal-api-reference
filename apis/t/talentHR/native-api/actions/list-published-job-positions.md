# List Published Job Positions with TalentHR

Retrieves published job positions from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/job-positions/published`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Published Job Positions](https://apidocs.talenthr.io/#68ed940e-2ea4-4416-9a35-503afc5bc3a1)
