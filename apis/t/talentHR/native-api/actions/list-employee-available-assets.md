# List Employee Available Assets with TalentHR

Retrieves an employee's available assets from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/available-assets`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Employee Available Assets](https://apidocs.talenthr.io/#50c4f9e6-398e-4476-93c5-539391a77282)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
