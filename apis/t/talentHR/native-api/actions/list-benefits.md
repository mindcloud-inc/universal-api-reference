# List Benefits with TalentHR

Retrieves benefits from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/benefits`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Benefits](https://apidocs.talenthr.io/#228f8389-67b5-4cd7-a3a0-92f8f20c3ab0)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | no | Optional TalentHR benefit filter ID. |
