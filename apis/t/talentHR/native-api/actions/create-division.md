# Create Division with TalentHR

Creates a new division in TalentHR.

## Endpoint

- **Method:** `POST`
- **Path:** `/divisions`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Create Division](https://apidocs.talenthr.io/#0a946c7e-91d6-4d9e-9012-27eebbcbc920)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Division name. |
