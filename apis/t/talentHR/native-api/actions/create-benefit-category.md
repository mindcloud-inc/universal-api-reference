# Create Benefit Category with TalentHR

Creates a new benefit category in TalentHR.

## Endpoint

- **Method:** `POST`
- **Path:** `/benefit-categories`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [Create Benefit Category](https://apidocs.talenthr.io/#a822d72d-d322-4376-b2e2-be3c0e649f08)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Benefit category name. |
