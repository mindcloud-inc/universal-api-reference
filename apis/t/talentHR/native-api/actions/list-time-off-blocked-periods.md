# List Time Off Blocked Periods with TalentHR

Retrieves blocked time off periods from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/blocked-time-offs`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Time Off Blocked Periods](https://apidocs.talenthr.io/#158f3ab3-0da9-426f-a826-611ec58d0113)
