# List Employee Benefits with TalentHR

Retrieves an employee's benefits from TalentHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee/benefits`
- **Base URL:** `https://pubapi.talenthr.io/v1`
- **Official documentation:** [List Employee Benefits](https://apidocs.talenthr.io/#829206cf-5527-4408-9c66-150ac04cb761)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee` | path | `number` | yes | TalentHR employee ID. |
