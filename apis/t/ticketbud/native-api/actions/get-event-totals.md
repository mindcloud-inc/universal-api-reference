# Get Event Totals with Ticketbud

Retrieves event totals from Ticketbud.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id/totals.json`
- **Base URL:** `https://api.ticketbud.com`
- **Official documentation:** [Get Event Totals](https://api.ticketbud.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Ticketbud event ID to retrieve totals for. |
