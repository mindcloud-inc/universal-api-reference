# Get Event with Ticketbud

Retrieves an event from Ticketbud.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id.json`
- **Base URL:** `https://api.ticketbud.com`
- **Official documentation:** [Get Event](https://api.ticketbud.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Ticketbud event ID to retrieve. |
