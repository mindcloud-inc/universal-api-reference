# Check phone number with TPSCheck

## Endpoint

- **Method:** `POST`
- **Path:** `/check`
- **Base URL:** `https://api.tpscheck.uk`
- **Official documentation:** [Check phone number](https://www.tpscheck.uk/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone` | body | `string` | yes | The UK phone number to verify. |
