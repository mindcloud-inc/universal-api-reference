# Talk Python To Me: Native API Reference

A consolidated summary of Talk Python To Me's API configuration and 1 documented operations, with links to official documentation.

- **Official docs:** https://search.talkpython.fm/api/docs
- **API base URL:** `https://search.talkpython.fm/api`

## Authentication

### No Auth

The public Talk Python search API is unauthenticated.

This API does not require request authentication.

[Official authentication documentation](https://search.talkpython.fm/api/docs)

## API conventions

Responses from this API use JSON. Response data is read from `results`.
