# Share Transcript Editor URL with Temi

Creates a shareable transcript editor URL in Temi.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs/:id/share`
- **Base URL:** `https://api.temi.com/v1`
- **Official documentation:** [Share Transcript Editor URL](https://www.temi.com/api/reference/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Temi job identifier. |
