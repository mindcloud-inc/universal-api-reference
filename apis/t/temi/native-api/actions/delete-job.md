# Delete Job with Temi

Deletes a transcription job from Temi.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.temi.com/v1`
- **Official documentation:** [Delete Job](https://www.temi.com/api/reference/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Temi job identifier to delete. |
