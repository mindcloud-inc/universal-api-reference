# List Jobs with Temi

Retrieves transcription jobs from Temi.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs`
- **Base URL:** `https://api.temi.com/v1`
- **Official documentation:** [List Jobs](https://www.temi.com/api/reference/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
