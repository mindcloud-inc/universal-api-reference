# List Revenue Centers with Toast

Retrieves revenue centers configured for the connected restaurant.

## Endpoint

- **Method:** `GET`
- **Path:** `/config/v2/revenueCenters`
- **Base URL:** `{connection}`
- **API:** Configuration
- **Official documentation:** [List Revenue Centers](https://doc.toasttab.com/openapi/configuration/operation/revenueCentersGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lastModified` | query | `date` | no | Return objects created or modified after this date and time. |
