# Get Menus with Toast

Retrieves the fully resolved set of published menus for the connected restaurant.

## Endpoint

- **Method:** `GET`
- **Path:** `/menus/v2/menus`
- **Base URL:** `{connection}`
- **API:** Menus V2
- **Official documentation:** [Get Menus](https://doc.toasttab.com/openapi/menus/operation/menusGet/)
