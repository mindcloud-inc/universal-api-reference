# Get Restaurant with Toast

## Endpoint

- **Method:** `GET`
- **Path:** `/restaurants/v1/restaurants/{restaurantGuid}`
- **Base URL:** `{connection}`
- **API:** Restaurants
- **Official documentation:** [Get Restaurant](https://doc.toasttab.com/openapi/restaurants/operation/restaurantsRestaurantGuidGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeArchived` | query | `boolean` | no | Return the restaurant even when it is archived. |
