# Get Menu Item with Toast

Retrieves one menu item or modifier by Toast GUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/config/v2/menuItems/:guid`
- **Base URL:** `{connection}`
- **API:** Configuration
- **Official documentation:** [Get Menu Item](https://doc.toasttab.com/openapi/configuration/operation/menuItemsGuidGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The Toast GUID of the menu item or modifier. |
