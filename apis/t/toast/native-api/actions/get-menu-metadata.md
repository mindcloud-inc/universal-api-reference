# Get Menu Metadata with Toast

Retrieves the last-modified timestamp for published menu data.

## Endpoint

- **Method:** `GET`
- **Path:** `/menus/v2/metadata`
- **Base URL:** `{connection}`
- **API:** Menus V2
- **Official documentation:** [Get Menu Metadata](https://doc.toasttab.com/openapi/menus/operation/metadataGet/)
