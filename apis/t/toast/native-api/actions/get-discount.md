# Get Discount with Toast

Retrieves one discount by Toast GUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/config/v2/discounts/:guid`
- **Base URL:** `{connection}`
- **API:** Configuration
- **Official documentation:** [Get Discount](https://doc.toasttab.com/openapi/configuration/operation/discountsGuidGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The Toast GUID of the discount. |
