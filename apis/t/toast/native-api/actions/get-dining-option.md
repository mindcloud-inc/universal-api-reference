# Get Dining Option with Toast

Retrieves one dining option by Toast GUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/config/v2/diningOptions/:guid`
- **Base URL:** `{connection}`
- **API:** Configuration
- **Official documentation:** [Get Dining Option](https://doc.toasttab.com/openapi/configuration/operation/diningOptionsGuidGet/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The Toast GUID of the dining option. |
