# List Managed Teams with TMetric

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/teams/managed`
- **Base URL:** `https://app.tmetric.com/api/v3`
- **Official documentation:** [List Managed Teams](https://app.tmetric.com/api-docs/#/Teams/get-accounts-accountId-teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | Workspace identifier. |
