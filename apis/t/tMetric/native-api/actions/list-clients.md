# List Clients with TMetric

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/clients`
- **Base URL:** `https://app.tmetric.com/api/v3`
- **Official documentation:** [List Clients](https://app.tmetric.com/api-docs/#/Clients/get-accounts-accountId-clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | Workspace identifier. |
