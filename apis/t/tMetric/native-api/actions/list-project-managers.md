# List Project Managers with TMetric

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/projects/managers`
- **Base URL:** `https://app.tmetric.com/api/v3`
- **Official documentation:** [List Project Managers](https://app.tmetric.com/api-docs/#/Projects/get-accounts-accountId-projects-managers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `number` | yes | Workspace identifier. |
