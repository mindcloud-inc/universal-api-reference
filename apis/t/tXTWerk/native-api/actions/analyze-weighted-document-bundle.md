# Analyze Weighted Document Bundle with TXT Werk

Analyzes a weighted document bundle in TXT Werk.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/txt/analyzer`
- **Base URL:** `https://api.txtwerk.de`
- **Official documentation:** [Analyze Weighted Document Bundle](https://services.txtwerk.de/ws/documentation/showRequest)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document` | body | `string` | yes |
| `language` | body | `string` | no |
