# Delete User with Tally

## Endpoint

- **Method:** `DELETE`
- **Path:** `organizations/:organizationId/users/:userId`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [Delete User](https://developers.tally.so/api-reference/endpoint/organizations/users/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `list<string>` | yes |
| `userId` | path | `list<string>` | yes |
