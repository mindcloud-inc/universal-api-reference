# List Users with Tally

## Endpoint

- **Method:** `GET`
- **Path:** `organizations/:organizationId/users`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [List Users](https://developers.tally.so/api-reference/endpoint/organizations/users/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `list<string>` | yes |
