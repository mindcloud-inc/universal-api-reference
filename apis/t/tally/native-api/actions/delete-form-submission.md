# Delete Form Submission with Tally

## Endpoint

- **Method:** `DELETE`
- **Path:** `forms/:formId/submissions/:submissionId`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [Delete Form Submission](https://developers.tally.so/api-reference/endpoint/forms/submissions/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `list<string>` | yes |
| `submissionId` | path | `string` | yes |
