# Delete Form with Tally

## Endpoint

- **Method:** `DELETE`
- **Path:** `forms/:formId`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [Delete Form](https://developers.tally.so/api-reference/endpoint/forms/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `list` | yes |
