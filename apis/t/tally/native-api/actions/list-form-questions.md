# List Form Questions with Tally

## Endpoint

- **Method:** `GET`
- **Path:** `forms/:formId/questions`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [List Form Questions](https://developers.tally.so/api-reference/endpoint/forms/questions/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `list<string>` | yes |
