# Get Form with Tally

## Endpoint

- **Method:** `GET`
- **Path:** `forms/:formId`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [Get Form](https://developers.tally.so/api-reference/endpoint/forms/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `list<string>` | yes |
