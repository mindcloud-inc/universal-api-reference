# Get Workspace with Tally

## Endpoint

- **Method:** `GET`
- **Path:** `workspaces/:workspaceId`
- **Base URL:** `https://api.tally.so`
- **Official documentation:** [Get Workspace](https://developers.tally.so/api-reference/endpoint/workspaces/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `list<string>` | yes |
