# List Events with TeamUp

Retrieves events from a TeamUp calendar by date range.

## Endpoint

- **Method:** `GET`
- **Path:** `/:calendarKeyOrId/events`
- **Base URL:** `https://api.teamup.com`
- **Official documentation:** [List Events](https://apidocs.teamup.com/docs/api/0f9f896800ffe-get-events)
