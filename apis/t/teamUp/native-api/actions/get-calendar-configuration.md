# Get Calendar Configuration with TeamUp

Retrieves configuration for a TeamUp calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/:calendarKeyOrId/configuration`
- **Base URL:** `https://api.teamup.com`
- **Official documentation:** [Get Calendar Configuration](https://apidocs.teamup.com/docs/api/1e4f067e212e8-get-the-calendar-configuration)
