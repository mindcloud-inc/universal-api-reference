# Get Language with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/languages/:language_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Language](https://developers.transifex.com/reference/get_languages-language-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language_id` | path | `string` | yes | The Transifex language identifier. |
