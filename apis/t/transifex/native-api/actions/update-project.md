# Update Project with Transifex

## Endpoint

- **Method:** `PATCH`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Update Project](https://developers.transifex.com/reference/patch_projects-project-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Transifex project identifier. |
