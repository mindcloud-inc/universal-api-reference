# Add Project Language with Transifex

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/relationships/languages`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Add Project Language](https://developers.transifex.com/reference/post_projects-project-id-relationships-languages.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Transifex project identifier. |
