# List Project Languages with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/languages`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [List Project Languages](https://developers.transifex.com/reference/get_projects-project-id-languages.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Transifex project identifier. |
