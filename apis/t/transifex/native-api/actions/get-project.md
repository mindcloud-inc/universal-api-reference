# Get Project with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Project](https://developers.transifex.com/reference/get_projects-project-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | The Transifex project identifier. |
