# Get Resource with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:resource_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Resource](https://developers.transifex.com/reference/get_resources-resource-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resource_id` | path | `string` | yes | The Transifex resource identifier. |
