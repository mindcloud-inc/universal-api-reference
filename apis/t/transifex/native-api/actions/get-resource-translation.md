# Get Resource Translation with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/resource_translations/:resource_translation_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Resource Translation](https://developers.transifex.com/reference/get_resource-translations-resource-translation-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resource_translation_id` | path | `string` | yes | The Transifex resource translation identifier. |
