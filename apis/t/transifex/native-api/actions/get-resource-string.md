# Get Resource String with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/resource_strings/:resource_string_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Resource String](https://developers.transifex.com/reference/get_resource-strings-resource-string-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resource_string_id` | path | `string` | yes | The Transifex resource string identifier. |
