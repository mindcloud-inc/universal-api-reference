# Get Organization with Transifex

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organization_id`
- **Base URL:** `https://rest.api.transifex.com`
- **Official documentation:** [Get Organization](https://developers.transifex.com/reference/get_organizations-organization-id.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | The Transifex organization identifier, for example o:mindcloud. |
