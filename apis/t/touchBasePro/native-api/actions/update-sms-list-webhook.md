# Update SMS List Webhook with TouchBasePro

Updates an existing SMS list webhook in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sms/lists/{listId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update SMS List Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
