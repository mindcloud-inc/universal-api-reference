# Suppress Email Addresses with TouchBasePro

Suppresses existing email addresses in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/clients/suppress`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Suppress Email Addresses](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
