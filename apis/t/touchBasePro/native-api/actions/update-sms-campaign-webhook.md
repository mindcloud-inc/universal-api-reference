# Update SMS Campaign Webhook with TouchBasePro

Updates an existing SMS campaign webhook in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sms/campaigns/{campaignId}/webhooks/{webhoookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update SMS Campaign Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
