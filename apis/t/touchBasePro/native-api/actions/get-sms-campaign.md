# Get SMS Campaign with TouchBasePro

Retrieves an SMS campaign from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{campaignId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Campaign](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
