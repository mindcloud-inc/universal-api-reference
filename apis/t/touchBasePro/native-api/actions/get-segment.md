# Get Segment with TouchBasePro

Retrieves a segment from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/segments/{segmentId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
