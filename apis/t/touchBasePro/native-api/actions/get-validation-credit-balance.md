# Get Validation Credit Balance with TouchBasePro

Retrieves validation credit balance from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate/balance`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Validation Credit Balance](https://developer.touchbasepro.com/api-details#api=email-validation)
