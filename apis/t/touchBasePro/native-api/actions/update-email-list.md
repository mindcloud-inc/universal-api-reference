# Update Email List with TouchBasePro

Updates an existing email list in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/lists/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Email List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
