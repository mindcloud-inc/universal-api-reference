# Unschedule Campaign with TouchBasePro

Unschedules an existing campaign in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/campaigns/{campaignId}/unschedule`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Unschedule Campaign](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
