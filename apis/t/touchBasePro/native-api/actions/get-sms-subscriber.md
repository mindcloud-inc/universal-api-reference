# Get SMS Subscriber with TouchBasePro

Retrieves an SMS subscriber from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/lists/{listId}/subscribers/{number}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
