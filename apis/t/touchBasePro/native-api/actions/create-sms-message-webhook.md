# Create SMS Message Webhook with TouchBasePro

Creates a new SMS message webhook in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/message/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create SMS Message Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
