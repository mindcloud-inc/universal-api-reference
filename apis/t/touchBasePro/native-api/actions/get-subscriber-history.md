# Get Subscriber History with TouchBasePro

Retrieves subscriber history details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/subscribers/{listId}/history?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Subscriber History](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
