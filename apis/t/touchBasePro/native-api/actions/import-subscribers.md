# Import Subscribers with TouchBasePro

Imports subscribers into your TouchBasePro account.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/subscribers/{listId}/import`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Import Subscribers](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
