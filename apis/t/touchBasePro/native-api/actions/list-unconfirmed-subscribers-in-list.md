# List Unconfirmed Subscribers in List with TouchBasePro

Retrieves unconfirmed subscribers in a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/unconfirmed`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Unconfirmed Subscribers in List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
