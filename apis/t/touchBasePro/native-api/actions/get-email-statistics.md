# Get Email Statistics with TouchBasePro

Retrieves email statistics details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/statistics`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Email Statistics](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
