# WhatsApp Track User with TouchBasePro

Tracks a WhatsApp user in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/track/users/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Track User](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
