# Get Validation List Status with TouchBasePro

Retrieves validation list status from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate/GetListValidationStatus?RequestId={RequestId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Validation List Status](https://developer.touchbasepro.com/api-details#api=email-validation)
