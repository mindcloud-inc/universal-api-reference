# List Deleted Subscribers in List with TouchBasePro

Retrieves deleted subscribers in a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/deleted`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Deleted Subscribers in List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
