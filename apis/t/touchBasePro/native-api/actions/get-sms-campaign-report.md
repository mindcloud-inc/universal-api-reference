# Get SMS Campaign Report with TouchBasePro

Retrieves an SMS campaign report from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{campaignId}/report`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Campaign Report](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
