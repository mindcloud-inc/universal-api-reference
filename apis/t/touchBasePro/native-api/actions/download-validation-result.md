# Download Validation Result with TouchBasePro

Downloads a validation result from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate/DownloadValidationResult?id={id}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Download Validation Result](https://developer.touchbasepro.com/api-details#api=email-validation)
