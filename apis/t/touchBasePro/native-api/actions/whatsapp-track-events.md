# WhatsApp Track Events with TouchBasePro

Tracks WhatsApp events in your TouchBasePro account.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/track/events/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Track Events](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
