# Delete Email List with TouchBasePro

Deletes an existing email list from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/lists/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Email List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
