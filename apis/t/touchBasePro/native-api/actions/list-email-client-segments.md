# List Email Client Segments with TouchBasePro

Retrieves email client segments from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/segments`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Email Client Segments](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
