# List Campaign Unsubscribers with TouchBasePro

Retrieves campaign unsubscribers from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/unsubscribes`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Unsubscribers](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
