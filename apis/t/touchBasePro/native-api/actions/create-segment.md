# Create Segment with TouchBasePro

Creates a new segment in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/segments/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
