# List Client Templates with TouchBasePro

Retrieves client email templates from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/templates`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Client Templates](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
