# Get List Stats with TouchBasePro

Retrieves statistics for a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/stats`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get List Stats](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
