# Create SMS Campaign Webhook with TouchBasePro

Creates a new SMS campaign webhook in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/campaigns/{campaignId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create SMS Campaign Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
