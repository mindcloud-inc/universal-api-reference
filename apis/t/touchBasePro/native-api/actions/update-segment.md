# Update Segment with TouchBasePro

Updates an existing segment in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/segments/{segmentId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
