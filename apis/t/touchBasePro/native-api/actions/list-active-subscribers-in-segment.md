# List Active Subscribers in Segment with TouchBasePro

Retrieves active subscribers in a segment from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/segments/{segmentId}/active`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Active Subscribers in Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
