# Set SMS Reply Forward with TouchBasePro

Sets SMS reply forwarding in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/message/forward`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Set SMS Reply Forward](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
