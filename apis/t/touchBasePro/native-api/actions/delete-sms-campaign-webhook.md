# Delete SMS Campaign Webhook with TouchBasePro

Deletes an existing SMS campaign webhook from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/campaigns/{campaignId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete SMS Campaign Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
