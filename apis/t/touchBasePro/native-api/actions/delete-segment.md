# Delete Segment with TouchBasePro

Deletes an existing segment from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/segments/{segmentId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
