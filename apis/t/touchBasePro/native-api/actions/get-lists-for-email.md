# Get Lists For Email with TouchBasePro

Retrieves lists for an email address from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/listsforemail?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Lists For Email](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
