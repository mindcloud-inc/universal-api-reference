# Test Webhook with TouchBasePro

Tests an existing webhook in TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/webhooks/{webhookId}/test`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Test Webhook](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
