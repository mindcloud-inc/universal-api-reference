# Update Email Template with TouchBasePro

Updates an existing email template in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/templates/{templateId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Email Template](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
