# Delete Custom Field with TouchBasePro

Deletes an existing custom field from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/lists/{listId}/customfields/{customfieldkey}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Custom Field](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
