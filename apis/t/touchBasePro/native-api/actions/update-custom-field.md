# Update Custom Field with TouchBasePro

Updates an existing custom field in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/lists/{listId}/customfields/{customfieldkey}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Custom Field](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
