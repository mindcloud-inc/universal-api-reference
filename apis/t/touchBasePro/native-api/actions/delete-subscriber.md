# Delete Subscriber with TouchBasePro

Deletes an existing subscriber from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/subscribers/{listId}?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
