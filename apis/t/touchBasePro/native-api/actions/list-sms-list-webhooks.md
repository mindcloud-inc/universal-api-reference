# List SMS List Webhooks with TouchBasePro

Retrieves SMS list webhooks from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/lists/{listId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS List Webhooks](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
