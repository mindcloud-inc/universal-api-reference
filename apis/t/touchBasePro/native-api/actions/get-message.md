# Get Message with TouchBasePro

Retrieves a message from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/messages/{messageID}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Message](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
