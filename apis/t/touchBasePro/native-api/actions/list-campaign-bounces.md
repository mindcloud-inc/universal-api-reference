# List Campaign Bounces with TouchBasePro

Retrieves campaign bounce details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/bounces`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Bounces](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
