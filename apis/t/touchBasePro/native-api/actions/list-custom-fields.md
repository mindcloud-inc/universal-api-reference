# List Custom Fields with TouchBasePro

Retrieves custom fields from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/customfields`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Custom Fields](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
