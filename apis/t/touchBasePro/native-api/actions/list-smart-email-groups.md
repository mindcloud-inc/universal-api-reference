# List Smart Email Groups with TouchBasePro

Retrieves smart email groups from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/classicEmail/groups`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Smart Email Groups](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
