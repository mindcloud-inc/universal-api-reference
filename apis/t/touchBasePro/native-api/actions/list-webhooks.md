# List Webhooks with TouchBasePro

Retrieves configured webhooks from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Webhooks](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
