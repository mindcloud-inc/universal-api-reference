# Delete SMS List with TouchBasePro

Deletes an existing SMS list from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/list/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete SMS List](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
