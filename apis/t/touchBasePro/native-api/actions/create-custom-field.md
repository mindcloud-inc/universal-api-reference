# Create Custom Field with TouchBasePro

Creates a new custom field in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/lists/{listId}/customfields`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create Custom Field](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
