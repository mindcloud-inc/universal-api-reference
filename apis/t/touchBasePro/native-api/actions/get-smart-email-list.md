# Get Smart Email List with TouchBasePro

Retrieves a smart email list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/smartEmail`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Smart Email List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
