# List Draft Campaigns with TouchBasePro

Retrieves draft campaigns from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/drafts`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Draft Campaigns](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
