# WhatsApp Send Text Message with TouchBasePro

Sends a WhatsApp text message in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/message/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Send Text Message](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
