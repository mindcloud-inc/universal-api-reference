# Validate Email List with TouchBasePro

Validates an email list in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/ValidateEmailList`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Validate Email List](https://developer.touchbasepro.com/api-details#api=email-validation)
