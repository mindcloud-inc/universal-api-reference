# Send Draft Campaign with TouchBasePro

Sends a draft campaign in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/campaigns/{campaignId}/send`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Send Draft Campaign](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
