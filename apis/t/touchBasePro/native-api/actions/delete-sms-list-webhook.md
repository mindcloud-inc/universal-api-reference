# Delete SMS List Webhook with TouchBasePro

Deletes an existing SMS list webhook from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/lists/{listId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete SMS List Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
