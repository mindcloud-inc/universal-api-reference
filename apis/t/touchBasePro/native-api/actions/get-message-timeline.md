# Get Message Timeline with TouchBasePro

Retrieves message timeline details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/messages`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Message Timeline](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
