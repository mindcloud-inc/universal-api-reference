# Delete SMS Subscriber with TouchBasePro

Deletes an existing SMS subscriber from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/lists/{listId}/subscribers/{number}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete SMS Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
