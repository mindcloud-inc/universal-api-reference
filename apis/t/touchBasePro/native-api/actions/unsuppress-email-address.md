# Unsuppress Email Address with TouchBasePro

Unsuppresses an email address in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/clients/unsuppress?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Unsuppress Email Address](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
