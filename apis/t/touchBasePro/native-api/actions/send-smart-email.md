# Send Smart Email with TouchBasePro

Sends a smart email in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/transactional/smartEmail/{smartEmailID}/send`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Send Smart Email](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
