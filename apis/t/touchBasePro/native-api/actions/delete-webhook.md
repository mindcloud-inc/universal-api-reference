# Delete Webhook with TouchBasePro

Deletes an existing webhook from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/lists/{listId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Webhook](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
