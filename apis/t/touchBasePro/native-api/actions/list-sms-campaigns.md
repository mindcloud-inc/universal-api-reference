# List SMS Campaigns with TouchBasePro

Retrieves SMS campaigns from your TouchBasePro account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns?page={page}&pageSize={pageSize}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS Campaigns](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
