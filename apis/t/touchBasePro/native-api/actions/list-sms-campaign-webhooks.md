# List SMS Campaign Webhooks with TouchBasePro

Retrieves SMS campaign webhooks from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{campaignId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS Campaign Webhooks](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
