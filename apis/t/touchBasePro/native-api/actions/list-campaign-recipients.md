# List Campaign Recipients with TouchBasePro

Retrieves campaign recipients from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/recipients`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Recipients](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
