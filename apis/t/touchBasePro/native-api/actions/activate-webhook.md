# Activate Webhook with TouchBasePro

Activates an existing webhook in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/lists/{listId}/webhooks/{webhookId}/activate`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Activate Webhook](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
