# List Scheduled Campaigns with TouchBasePro

Retrieves scheduled campaigns from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/scheduled`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Scheduled Campaigns](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
