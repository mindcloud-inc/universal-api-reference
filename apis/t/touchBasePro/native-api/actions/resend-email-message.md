# Resend Email Message with TouchBasePro

Resends an email message in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/transactional/messages/{messageID}/resend`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Resend Email Message](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
