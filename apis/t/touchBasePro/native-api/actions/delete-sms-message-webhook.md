# Delete SMS Message Webhook with TouchBasePro

Deletes an existing SMS message webhook from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms/message/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete SMS Message Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
