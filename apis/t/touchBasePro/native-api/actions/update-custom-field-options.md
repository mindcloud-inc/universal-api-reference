# Update Custom Field Options with TouchBasePro

Updates existing custom field options in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/lists/{listId}/customfields/{customfieldkey}/options`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Custom Field Options](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
