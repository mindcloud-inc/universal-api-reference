# Deactivate Webhook with TouchBasePro

Deactivates an existing webhook in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/lists/{listId}/webhooks/{webhookId}/deactivate`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Deactivate Webhook](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
