# List Bounced Subscribers in List with TouchBasePro

Retrieves bounced subscribers in a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/bounced`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Bounced Subscribers in List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
