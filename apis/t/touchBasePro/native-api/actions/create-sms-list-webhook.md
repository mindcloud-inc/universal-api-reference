# Create SMS List Webhook with TouchBasePro

Creates a new SMS list webhook in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/lists/{listId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create SMS List Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
