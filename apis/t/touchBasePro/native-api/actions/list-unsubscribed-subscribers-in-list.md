# List Unsubscribed Subscribers in List with TouchBasePro

Retrieves unsubscribed subscribers in a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/unsubscribed`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Unsubscribed Subscribers in List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
