# Send Campaign Preview with TouchBasePro

Sends a campaign preview in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/campaigns/{campaignId}/sendpreview`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Send Campaign Preview](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
