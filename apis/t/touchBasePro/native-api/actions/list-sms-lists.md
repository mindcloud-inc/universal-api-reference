# List SMS Lists with TouchBasePro

Retrieves SMS lists from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/lists?page={page}&pageSize={pageSize}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS Lists](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
