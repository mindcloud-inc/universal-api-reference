# List Time Zones with TouchBasePro

Retrieves available time zones from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/timezones`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Time Zones](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
