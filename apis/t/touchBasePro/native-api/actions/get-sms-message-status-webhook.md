# Get SMS Message Status Webhook with TouchBasePro

Retrieves an SMS message status webhook from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/message/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Message Status Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
