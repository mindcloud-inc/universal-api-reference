# List SMS Message Webhooks with TouchBasePro

Retrieves SMS message webhooks from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/message/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS Message Webhooks](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
