# Delete Campaign with TouchBasePro

Deletes an existing campaign from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/campaigns/{campaignId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Campaign](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
