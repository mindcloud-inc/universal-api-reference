# List Campaign Opens with TouchBasePro

Retrieves campaign open details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/opens`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Opens](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
