# List Active Subscribers in List with TouchBasePro

Retrieves active subscribers in a list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/active`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Active Subscribers in List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
