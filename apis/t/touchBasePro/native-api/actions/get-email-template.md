# Get Email Template with TouchBasePro

Retrieves an email template from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/templates/{templateId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Email Template](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
