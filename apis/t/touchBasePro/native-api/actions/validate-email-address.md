# Validate Email Address with TouchBasePro

Validates an email address in TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate/ValidateEmailAddress?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Validate Email Address](https://developer.touchbasepro.com/api-details#api=email-validation)
