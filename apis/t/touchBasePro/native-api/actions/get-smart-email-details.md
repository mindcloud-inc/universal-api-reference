# Get Smart Email Details with TouchBasePro

Retrieves smart email details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/transactional/smartEmail/{smartEmailID}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Smart Email Details](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
