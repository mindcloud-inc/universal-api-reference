# Get Suppression List with TouchBasePro

Retrieves the suppression list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/suppressionlist`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Suppression List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
