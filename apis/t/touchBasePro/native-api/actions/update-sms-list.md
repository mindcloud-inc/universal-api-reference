# Update SMS List with TouchBasePro

Updates an existing SMS list in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sms/lists/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update SMS List](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
