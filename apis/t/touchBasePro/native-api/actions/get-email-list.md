# Get Email List with TouchBasePro

Retrieves an email list from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Email List](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
