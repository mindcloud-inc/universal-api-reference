# Get SMS Campaign Webhook with TouchBasePro

Retrieves an SMS campaign webhook from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{campaignId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Campaign Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
