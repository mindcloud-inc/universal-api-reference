# Import SMS Subscribers with TouchBasePro

Imports SMS subscribers into TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/lists/{listId}/subscribers/import`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Import SMS Subscribers](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
