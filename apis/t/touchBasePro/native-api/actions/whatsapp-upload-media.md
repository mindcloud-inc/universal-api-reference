# WhatsApp Upload Media with TouchBasePro

Uploads WhatsApp media files to TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/track/files/upload_to_fb/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Upload Media](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
