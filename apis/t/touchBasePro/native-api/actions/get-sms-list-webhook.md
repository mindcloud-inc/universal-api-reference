# Get SMS List Webhook with TouchBasePro

Retrieves an SMS list webhook from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/lists/{listId}/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS List Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
