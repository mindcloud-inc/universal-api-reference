# Send Classic Email with TouchBasePro

Sends a classic email in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/transactional/classicEmail/send`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Send Classic Email](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
