# WhatsApp Create Template with TouchBasePro

Creates a new WhatsApp template in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/track/templates/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Create Template](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
