# Delete Email Template with TouchBasePro

Deletes an existing email template from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/templates/{templateId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Email Template](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
