# Get SMS Credit Balance with TouchBasePro

Retrieves SMS credit balance from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/balance`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Credit Balance](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
