# List Segments with TouchBasePro

Retrieves segments from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/{listId}/segments`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Segments](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
