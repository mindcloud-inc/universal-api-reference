# Create Webhook with TouchBasePro

Creates a new webhook in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/lists/{listId}/webhooks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create Webhook](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
