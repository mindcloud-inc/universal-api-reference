# List Campaign Spam Complaints with TouchBasePro

Retrieves campaign spam complaints from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/spam`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Spam Complaints](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
