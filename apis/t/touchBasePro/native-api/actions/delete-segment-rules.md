# Delete Segment Rules with TouchBasePro

Deletes existing segment rules from TouchBasePro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/segments/{segmentId}/rules`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Delete Segment Rules](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
