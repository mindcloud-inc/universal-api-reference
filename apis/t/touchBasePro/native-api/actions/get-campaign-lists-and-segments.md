# Get Campaign Lists And Segments with TouchBasePro

Retrieves campaign lists and segments from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/listsandsegments`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Campaign Lists And Segments](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
