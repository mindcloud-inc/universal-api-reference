# Get Campaign Email Client Usage with TouchBasePro

Retrieves campaign email client usage from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/emailclientusage`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Campaign Email Client Usage](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
