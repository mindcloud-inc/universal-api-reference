# Update SMS Message Webhook with TouchBasePro

Updates an existing SMS message webhook in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sms/message/webhooks/{webhookId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update SMS Message Webhook](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
