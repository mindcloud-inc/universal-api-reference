# Get SMS Reply Forward with TouchBasePro

Retrieves SMS reply forwarding from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/message/forward`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Reply Forward](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
