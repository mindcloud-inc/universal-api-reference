# WhatsApp Get Users with TouchBasePro

Retrieves WhatsApp user records from TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/v1/public/apis/users/`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [WhatsApp Get Users](https://developer.touchbasepro.com/api-details#api=whatsapp-api)
