# List Campaign Clicks with TouchBasePro

Retrieves campaign click details from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/clicks`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Campaign Clicks](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
