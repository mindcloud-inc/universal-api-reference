# Update Subscriber with TouchBasePro

Updates an existing subscriber in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/email/subscribers/{listId}?email={email}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
