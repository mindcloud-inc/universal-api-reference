# List SMS Subscribers with TouchBasePro

Retrieves SMS subscribers from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/lists/{listId}/subscribers?page={page}&pageSize={pageSize}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List SMS Subscribers](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
