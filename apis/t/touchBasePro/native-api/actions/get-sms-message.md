# Get SMS Message with TouchBasePro

Retrieves an SMS message from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/message/{messageId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get SMS Message](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
