# Create Campaign From Template with TouchBasePro

Creates a new campaign from a template in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/campaigns/fromtemplate`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create Campaign From Template](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
