# Create Email Subscriber with TouchBasePro

Creates a new email subscriber in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/subscribers/{listId}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create Email Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
