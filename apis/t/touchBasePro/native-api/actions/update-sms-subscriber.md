# Update SMS Subscriber with TouchBasePro

Updates an existing SMS subscriber in TouchBasePro.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sms/lists/{listId}/subscribers/{number}`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Update SMS Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
