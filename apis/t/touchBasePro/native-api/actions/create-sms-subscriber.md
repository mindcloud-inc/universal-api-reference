# Create SMS Subscriber with TouchBasePro

Creates a new SMS subscriber in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/lists/{listId}/subscribers`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Create SMS Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-sms-api)
