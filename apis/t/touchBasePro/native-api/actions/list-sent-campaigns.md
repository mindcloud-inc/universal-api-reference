# List Sent Campaigns with TouchBasePro

Retrieves sent campaigns from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/clients/campaigns`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [List Sent Campaigns](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
