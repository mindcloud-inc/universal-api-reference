# Unsubscribe Subscriber with TouchBasePro

Unsubscribes a subscriber in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/subscribers/{listId}/unsubscribe`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Unsubscribe Subscriber](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
