# Add Rule Group To Segment with TouchBasePro

Adds a rule group to a segment in TouchBasePro.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/segments/{segmentId}/rules`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Add Rule Group To Segment](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
