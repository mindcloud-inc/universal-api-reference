# Get Campaign Summary with TouchBasePro

Retrieves a campaign summary from TouchBasePro.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/{campaignId}/summary`
- **Base URL:** `https://api.touchbasepro.com`
- **Official documentation:** [Get Campaign Summary](https://developer.touchbasepro.com/api-details#api=tbp-email-api)
