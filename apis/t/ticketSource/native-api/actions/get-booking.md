# Get Booking with TicketSource

Retrieves a booking from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/{BookingId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Booking](https://www.ticketsource.io/working-with-bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `BookingId` | path | `string` | yes | The unique identifier for a Booking record |
