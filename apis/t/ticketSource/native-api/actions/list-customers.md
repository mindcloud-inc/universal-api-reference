# List Customers with TicketSource

Retrieves customers from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [List Customers](https://www.ticketsource.io/working-with-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
