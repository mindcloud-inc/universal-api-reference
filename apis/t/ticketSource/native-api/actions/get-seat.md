# Get Seat with TicketSource

Retrieves a seat from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/seats/{SeatId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Seat](https://www.ticketsource.io/working-with-bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SeatId` | path | `string` | yes | The unique identifier for a Seat record |
