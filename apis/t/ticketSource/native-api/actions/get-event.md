# Get Event with TicketSource

Retrieves an event from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/{EventId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Event](https://www.ticketsource.io/working-with-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `EventId` | path | `string` | yes | The unique identifier for an Event record |
