# Get Venue with TicketSource

Retrieves a venue from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/venues/{VenueId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Venue](https://www.ticketsource.io/working-with-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `VenueId` | path | `string` | yes | The unique identifier for a Venue record |
