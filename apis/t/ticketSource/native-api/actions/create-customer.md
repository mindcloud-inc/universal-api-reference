# Create Customer with TicketSource

Creates a new customer in TicketSource.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Create Customer](https://www.ticketsource.io/working-with-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | no | A Customer including contact details, membership information and marketing consent. |
