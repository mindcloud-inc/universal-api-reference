# Delete Customer with TicketSource

Deletes an existing customer from TicketSource.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/{CustomerId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Delete Customer](https://www.ticketsource.io/working-with-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerId` | path | `string` | yes | The unique identifier for a Customer record |
