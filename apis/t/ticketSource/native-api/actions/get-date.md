# Get Date with TicketSource

Retrieves an event date from TicketSource.

## Endpoint

- **Method:** `GET`
- **Path:** `/dates/{DateId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Date](https://www.ticketsource.io/working-with-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `DateId` | path | `string` | yes | The unique identifier for a Date record |
