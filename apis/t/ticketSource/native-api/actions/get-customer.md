# Get Customer with TicketSource

Retrieves a customer from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{CustomerId}`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [Get Customer](https://www.ticketsource.io/working-with-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerId` | path | `string` | yes | The unique identifier for a Customer record |
