# List Events with TicketSource

Retrieves events from the TicketSource account.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.ticketsource.io`
- **Official documentation:** [List Events](https://www.ticketsource.io/working-with-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).
