# Get Token Prices with Torque

## Endpoint

- **Method:** `GET`
- **Path:** `/token-prices`
- **Base URL:** `https://app.torque.fi/api`
- **Official documentation:** [Get Token Prices](https://docs.torque.fi/business/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbols` | query | `string` | yes | Comma-separated token symbols. |
