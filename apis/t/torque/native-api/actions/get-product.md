# Get Product with Torque

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:productId`
- **Base URL:** `https://app.torque.fi/api`
- **Official documentation:** [Get Product](https://docs.torque.fi/business/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | Torque product ID. |
