# Get Enso Tokens with Torque

## Endpoint

- **Method:** `GET`
- **Path:** `/enso/tokens`
- **Base URL:** `https://app.torque.fi/api`
- **Official documentation:** [Get Enso Tokens](https://docs.torque.fi/business/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chainId` | query | `number` | no | Blockchain chain ID. Defaults to Ethereum mainnet when Torque provides a default. |
