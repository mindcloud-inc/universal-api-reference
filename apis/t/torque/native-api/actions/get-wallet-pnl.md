# Get Wallet PnL with Torque

## Endpoint

- **Method:** `GET`
- **Path:** `/moralis/wallet-pnl`
- **Base URL:** `https://app.torque.fi/api`
- **Official documentation:** [Get Wallet PnL](https://docs.torque.fi/business/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | query | `string` | yes | Wallet address to query. |
| `chain` | query | `string` | no | — |
