# Get Order Status with Torque

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/order-status/:orderId`
- **Base URL:** `https://app.torque.fi/api`
- **Official documentation:** [Get Order Status](https://docs.torque.fi/business/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Torque checkout order ID. |
