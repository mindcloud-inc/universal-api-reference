# Start Training with Typless

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/start-training`
- **Base URL:** `https://developers.typless.com`
- **Official documentation:** [Start Training](https://typless.gitbook.io/typlessapi/methods/start-training)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_type_name` | body | `string` | yes | Typless document type name to train. |
