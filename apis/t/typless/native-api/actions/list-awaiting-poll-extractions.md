# List Awaiting Poll Extractions with Typless

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/awaiting-poll`
- **Base URL:** `https://developers.typless.com`
- **Official documentation:** [List Awaiting Poll Extractions](https://typless.gitbook.io/typlessapi/typless/data-extraction/asynchronous-extraction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer` | query | `string` | no | Optional customer identifier to scope the awaiting poll queue. |
