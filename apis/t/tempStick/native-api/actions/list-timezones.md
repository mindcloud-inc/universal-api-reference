# List Timezones with Temp Stick

Retrieves the list of supported Temp Stick timezones.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/allowed-timezones`
- **Base URL:** `https://tempstickapi.com/api/v1`
- **Official documentation:** [List Timezones](https://tempstickapi.com/docs/#api-User-Get_Timezones)
