# List Sensors with Temp Stick

Retrieves all sensors assigned to the Temp Stick account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sensors/all`
- **Base URL:** `https://tempstickapi.com/api/v1`
- **Official documentation:** [List Sensors](https://tempstickapi.com/docs/#api-Sensors-Get_Sensors)
