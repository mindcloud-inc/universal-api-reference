# Get Alert with Temp Stick

Retrieves a specific alert from Temp Stick.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/:alert_id`
- **Base URL:** `https://tempstickapi.com/api/v1`
- **Official documentation:** [Get Alert](https://tempstickapi.com/docs/#api-Alerts-Get_Alert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alert_id` | path | `number` | yes | The ID of your alert |
