# Update Company with Turis

Updates an existing company in Turis.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/public/v1/companies/:companyId`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Company](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
