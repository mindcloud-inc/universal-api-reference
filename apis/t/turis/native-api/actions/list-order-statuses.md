# List Order Statuses with Turis

Retrieves order statuses from Turis.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/order-statuses`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [List Order Statuses](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
