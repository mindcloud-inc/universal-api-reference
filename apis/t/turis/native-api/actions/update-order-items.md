# Update Order Items with Turis

Updates items in a Turis order.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/public/v1/orders/:orderId/items`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Order Items](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
