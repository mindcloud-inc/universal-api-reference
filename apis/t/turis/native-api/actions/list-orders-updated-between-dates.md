# List Orders Updated Between Dates with Turis

Retrieves Turis orders updated between two dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/orders/updated/:from/:to`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [List Orders Updated Between Dates](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
