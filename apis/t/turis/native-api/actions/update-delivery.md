# Update Delivery with Turis

Updates an existing delivery in Turis.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/public/v1/deliveries/:delivery`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Delivery](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
