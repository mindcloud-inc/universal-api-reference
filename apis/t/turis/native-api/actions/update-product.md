# Update Product with Turis

Updates an existing product in Turis.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/public/v1/products/:productId`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Product](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
