# Update Product Inventory with Turis

Updates product inventory in Turis.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/public/v1/products/bulk/inventory-update`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Product Inventory](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
