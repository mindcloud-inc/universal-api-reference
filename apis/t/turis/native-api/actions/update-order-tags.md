# Update Order Tags with Turis

Updates tags on a Turis order.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/public/v1/orders/:orderId/tags`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Update Order Tags](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
