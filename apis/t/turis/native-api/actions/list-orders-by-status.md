# List Orders by Status with Turis

Retrieves orders in Turis by status.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/orders/status/:statusId`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [List Orders by Status](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
