# Add Products to Order with Turis

Adds products to a Turis order.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/v1/orders/:orderId/products/add`
- **Base URL:** `https://{tenant}.turis.app`
- **Official documentation:** [Add Products to Order](https://documenter.getpostman.com/view/16452985/TzkyP1Er)
