# List Rewards with Tremendous

Retrieves rewards from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [List Rewards](https://developers.tremendous.com/reference/list-rewards)

## Capabilities

This operation supports [pagination](../README.md#pagination).
