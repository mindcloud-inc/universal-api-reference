# Retrieve Funding Source with Tremendous

Retrieves a specific funding source from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/funding_sources/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Funding Source](https://developers.tremendous.com/reference/get-funding-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the funding source to retrieve |
