# Retrieve Order with Tremendous

Retrieves a specific order from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Order](https://developers.tremendous.com/reference/get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the order to retrieve |
