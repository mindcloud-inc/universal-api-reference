# Retrieve Reward with Tremendous

Retrieves a specific reward from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Reward](https://developers.tremendous.com/reference/get-reward)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the reward to retrieve |
