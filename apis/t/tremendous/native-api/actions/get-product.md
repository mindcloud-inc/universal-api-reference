# Retrieve Product with Tremendous

Retrieves a specific product from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Product](https://developers.tremendous.com/reference/get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the product to retrieve |
