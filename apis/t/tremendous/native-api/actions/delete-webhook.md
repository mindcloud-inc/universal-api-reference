# Delete Webhook with Tremendous

Deletes an existing webhook from Tremendous.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Delete Webhook](https://developers.tremendous.com/reference/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the webhook to delete |
