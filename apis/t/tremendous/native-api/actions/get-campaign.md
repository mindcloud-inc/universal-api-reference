# Retrieve Campaign with Tremendous

Retrieves a specific campaign from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Campaign](https://developers.tremendous.com/reference/get-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the campaign to retrieve |
