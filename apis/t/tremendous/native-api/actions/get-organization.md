# Retrieve Organization with Tremendous

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Organization](https://developers.tremendous.com/reference/get-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the organization to retrieve |
