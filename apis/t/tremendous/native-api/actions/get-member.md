# Retrieve Member with Tremendous

Retrieves a specific member from Tremendous.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:id`
- **Base URL:** `https://testflight.tremendous.com/api/v2`
- **Official documentation:** [Retrieve Member](https://developers.tremendous.com/reference/get-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the member to retrieve |
