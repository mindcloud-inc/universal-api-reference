# Create Task with TeamBook

Creates a new task in TeamBook.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Create Task](https://kb.teambookapp.com/en/article/define-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The TeamBook task name. |
