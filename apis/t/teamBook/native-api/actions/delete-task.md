# Delete Task with TeamBook

Deletes an existing task from TeamBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/{taskId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Delete Task](https://kb.teambookapp.com/en/article/define-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The TeamBook task identifier. |
