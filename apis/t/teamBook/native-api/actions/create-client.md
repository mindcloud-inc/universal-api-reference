# Create Client with TeamBook

Creates a new client in TeamBook.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Create Client](https://kb.teambookapp.com/en/article/create-and-edit-clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The TeamBook client name. |
