# Delete Project with TeamBook

Deletes an existing project from TeamBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{projectId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Delete Project](https://kb.teambookapp.com/en/article/create-and-edit-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The TeamBook project identifier. |
