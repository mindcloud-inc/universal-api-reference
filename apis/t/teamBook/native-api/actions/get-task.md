# Get Task with TeamBook

Retrieves detailed task information from TeamBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/{taskId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Get Task](https://kb.teambookapp.com/en/article/define-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The TeamBook task identifier. |
