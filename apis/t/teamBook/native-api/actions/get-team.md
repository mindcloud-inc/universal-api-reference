# Get Team with TeamBook

Retrieves detailed team information from TeamBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{teamId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Get Team](https://kb.teambookapp.com/en/article/teams-why-and-how-to-use)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The TeamBook team identifier. |
