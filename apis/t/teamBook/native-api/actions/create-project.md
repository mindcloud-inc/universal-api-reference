# Create Project with TeamBook

Creates a new project in TeamBook.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Create Project](https://kb.teambookapp.com/en/article/create-and-edit-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The TeamBook project name. |
