# Get Client with TeamBook

Retrieves detailed client information from TeamBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{clientId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Get Client](https://kb.teambookapp.com/en/article/create-and-edit-clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | The TeamBook client identifier. |
