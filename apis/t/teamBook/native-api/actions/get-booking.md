# Get Booking with TeamBook

Retrieves detailed booking information from TeamBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/{bookingId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Get Booking](https://kb.teambookapp.com/en/article/teambook-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookingId` | path | `string` | yes | The TeamBook booking identifier. |
