# Delete User with TeamBook

Deletes an existing user from TeamBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/{userId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Delete User](https://kb.teambookapp.com/en/article/create-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The TeamBook user identifier. |
