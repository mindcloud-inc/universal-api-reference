# Delete Booking with TeamBook

Deletes an existing booking from TeamBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings/{bookingId}`
- **Base URL:** `https://web.teambookapp.com/api/public`
- **Official documentation:** [Delete Booking](https://kb.teambookapp.com/en/article/delete-bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookingId` | path | `string` | yes | The TeamBook booking identifier. |
