# Get Available Number Country with TelTel

Retrieves available number country details from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/dids/new-numbers/countries/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get Available Number Country](https://api.teltel.io/v2/apidoc/paths/dids/new-numbers-country.json)
