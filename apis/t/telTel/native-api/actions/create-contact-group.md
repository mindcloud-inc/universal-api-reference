# Create Contact Group with TelTel

Creates a new contact group in TelTel.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/groups`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Create Contact Group](https://api.teltel.io/v2/apidoc/paths/contacts/contact-groups.json)
