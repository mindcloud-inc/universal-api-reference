# Assign Phone Number To Groups with TelTel

Assigns a phone number to groups in TelTel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/dids/my-numbers/{id}/groups`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Assign Phone Number To Groups](https://api.teltel.io/v2/apidoc/paths/dids/my-number-groups.json)
