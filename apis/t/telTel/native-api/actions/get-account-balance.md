# Get Account Balance with TelTel

Retrieves account balance details from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/balance`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get Account Balance](https://api.teltel.io/v2/apidoc/paths/account/balance.json)
