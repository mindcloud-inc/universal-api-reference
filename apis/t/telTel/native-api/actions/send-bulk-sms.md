# Send Bulk SMS with TelTel

Sends multiple SMS messages in a single TelTel request.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/bulk/text`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Send Bulk SMS](https://api.teltel.io/v2/apidoc/paths/sms-outbox/sms-text-bulk.json)
