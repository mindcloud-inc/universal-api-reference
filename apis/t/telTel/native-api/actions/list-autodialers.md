# List Autodialers with TelTel

Retrieves autodialer campaigns from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/autodialers`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Autodialers](https://api.teltel.io/v2/apidoc/paths/autodialers/autodialers.json)
