# List SMS Reports with TelTel

Retrieves outbound SMS reports from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/reports`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List SMS Reports](https://api.teltel.io/v2/apidoc/paths/sms-outbox/sms-reports.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
