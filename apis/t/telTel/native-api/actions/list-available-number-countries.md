# List Available Number Countries with TelTel

Retrieves available phone number countries from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/dids/new-numbers/countries`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Available Number Countries](https://api.teltel.io/v2/apidoc/paths/dids/new-numbers-countries.json)

## Capabilities

This operation supports [filtering](../README.md#filtering).
