# Get Contact Group with TelTel

Retrieves a contact group from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/groups/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get Contact Group](https://api.teltel.io/v2/apidoc/paths/contacts/contact-group.json)
