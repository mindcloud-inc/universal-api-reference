# Update Contact Group with TelTel

Updates an existing contact group in TelTel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts/groups/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Update Contact Group](https://api.teltel.io/v2/apidoc/paths/contacts/contact-group.json)
