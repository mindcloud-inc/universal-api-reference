# Update SMS Campaign with TelTel

Updates an existing SMS campaign in TelTel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/sms/campaigns/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Update SMS Campaign](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaign.json)
