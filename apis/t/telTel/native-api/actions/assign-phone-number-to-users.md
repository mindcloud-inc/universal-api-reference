# Assign Phone Number To Users with TelTel

Assigns a phone number to users in TelTel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/dids/my-numbers/{id}/users`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Assign Phone Number To Users](https://api.teltel.io/v2/apidoc/paths/dids/my-number-users.json)
