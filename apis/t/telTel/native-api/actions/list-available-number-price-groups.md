# List Available Number Price Groups with TelTel

Retrieves available phone number price groups from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/dids/new-numbers/countries/{id}/price-groups`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Available Number Price Groups](https://api.teltel.io/v2/apidoc/paths/dids/new-numbers-price-groups.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
