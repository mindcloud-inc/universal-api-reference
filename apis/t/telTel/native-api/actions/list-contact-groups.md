# List Contact Groups with TelTel

Retrieves contact groups from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/groups`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Contact Groups](https://api.teltel.io/v2/apidoc/paths/contacts/contact-groups.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
