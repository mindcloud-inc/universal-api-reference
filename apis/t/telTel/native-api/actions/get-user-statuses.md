# Get User Statuses with TelTel

Retrieves user statuses from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-statuses`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get User Statuses](https://api.teltel.io/v2/apidoc/paths/user-statuses/user-statuses.json)
