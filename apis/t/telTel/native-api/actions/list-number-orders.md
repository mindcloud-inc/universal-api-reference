# List Number Orders with TelTel

Retrieves phone number orders from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/dids/orders`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Number Orders](https://api.teltel.io/v2/apidoc/paths/dids/orders.json)

## Capabilities

This operation supports [filtering](../README.md#filtering).
