# Get Inbound SMS Report with TelTel

Retrieves an inbound SMS report from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/inbox/reports/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get Inbound SMS Report](https://api.teltel.io/v2/apidoc/paths/sms-inbox/sms-report.json)
