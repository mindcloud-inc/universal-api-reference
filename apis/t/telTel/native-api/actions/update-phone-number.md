# Update Phone Number with TelTel

Updates an existing phone number in TelTel.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/dids/my-numbers/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Update Phone Number](https://api.teltel.io/v2/apidoc/paths/dids/my-number.json)
