# List Contact Group Contacts with TelTel

Retrieves contacts from a TelTel contact group.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/groups/{id}/contacts`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Contact Group Contacts](https://api.teltel.io/v2/apidoc/paths/contacts/contact-group-contacts.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
