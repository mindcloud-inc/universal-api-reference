# List SMS Campaigns with TelTel

Retrieves SMS campaigns from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List SMS Campaigns](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaigns.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
