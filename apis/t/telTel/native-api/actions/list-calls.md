# List Calls with TelTel

Retrieves calls from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Calls](https://api.teltel.io/v2/apidoc/paths/calls/calls.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
