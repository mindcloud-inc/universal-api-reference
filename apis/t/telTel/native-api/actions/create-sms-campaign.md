# Create SMS Campaign with TelTel

Creates a new SMS campaign in TelTel.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/campaigns`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Create SMS Campaign](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaigns.json)
