# List SMS Campaign Actions with TelTel

Retrieves SMS campaign action history from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{id}/actions`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List SMS Campaign Actions](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaign-actions.json)
