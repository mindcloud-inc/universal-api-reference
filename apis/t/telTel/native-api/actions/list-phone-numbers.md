# List Phone Numbers with TelTel

Retrieves phone numbers from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/dids/my-numbers`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Phone Numbers](https://api.teltel.io/v2/apidoc/paths/dids/my-numbers.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
