# List Contacts with TelTel

Retrieves contacts from your TelTel account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [List Contacts](https://api.teltel.io/v2/apidoc/paths/contacts/contacts.json)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
