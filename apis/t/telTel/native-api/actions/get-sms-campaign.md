# Get SMS Campaign with TelTel

Retrieves an SMS campaign from TelTel.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/campaigns/{id}`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Get SMS Campaign](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaign.json)
