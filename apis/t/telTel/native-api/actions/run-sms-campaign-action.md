# Run SMS Campaign Action with TelTel

Performs an action on an SMS campaign in TelTel.

## Endpoint

- **Method:** `POST`
- **Path:** `/sms/campaigns/{id}/actions`
- **Base URL:** `https://api.teltel.io/v2`
- **Official documentation:** [Run SMS Campaign Action](https://api.teltel.io/v2/apidoc/paths/sms-campaigns/sms-campaign-actions.json)
