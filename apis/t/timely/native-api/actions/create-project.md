# Create Project with Timely

Creates a project in Timely.

## Endpoint

- **Method:** `POST`
- **Path:** `/1.1/{account_id}/projects`
- **Base URL:** `https://api.timelyapp.com`
- **Official documentation:** [Create Project](https://developer.timely.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | Workspace id |
| `project` | body | `object` | yes | — |
