# Delete Tag with Timely

Deletes an existing tag from Timely.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/1.1/{account_id}/labels/{id}`
- **Base URL:** `https://api.timelyapp.com`
- **Official documentation:** [Delete Tag](https://developer.timely.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | Account ID |
| `id` | path | `number` | yes | Label ID |
