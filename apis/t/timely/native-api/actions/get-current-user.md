# Get Current User with Timely

Retrieves the current user from Timely.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.1/{account_id}/users/current`
- **Base URL:** `https://api.timelyapp.com`
- **Official documentation:** [Get Current User](https://developer.timely.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | Workspace id |
