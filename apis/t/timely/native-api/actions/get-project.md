# Get Project with Timely

Retrieves a project from Timely.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.1/{account_id}/projects/{id}`
- **Base URL:** `https://api.timelyapp.com`
- **Official documentation:** [Get Project](https://developer.timely.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | Account ID |
| `id` | path | `number` | yes | Project ID |
