# Get User with Timely

Retrieves a user from Timely.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.1/{account_id}/users/{id}`
- **Base URL:** `https://api.timelyapp.com`
- **Official documentation:** [Get User](https://developer.timely.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `number` | yes | Workspace id |
| `id` | path | `number` | yes | User id |
