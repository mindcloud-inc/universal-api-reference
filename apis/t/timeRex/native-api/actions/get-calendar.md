# Get Calendar with TimeRex

Retrieves a calendar by ID from TimeRex.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:calendarId`
- **Base URL:** `https://timerex.net/api/beta`
- **Official documentation:** [Get Calendar](https://developers.timerex.net/api/reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarId` | path | `string` | yes | The TimeRex calendar identifier. |
