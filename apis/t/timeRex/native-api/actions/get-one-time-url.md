# Get One Time URL with TimeRex

Retrieves a one-time URL from TimeRex.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/one-time-url/:oneTimeUrlId`
- **Base URL:** `https://timerex.net/api/beta`
- **Official documentation:** [Get One Time URL](https://developers.timerex.net/api/reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `oneTimeUrlId` | path | `string` | yes | The TimeRex one-time URL identifier. |
