# Get Team with TimeRex

Retrieves a team by ID from TimeRex.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://timerex.net/api/beta`
- **Official documentation:** [Get Team](https://developers.timerex.net/api/reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The TimeRex team identifier. |
