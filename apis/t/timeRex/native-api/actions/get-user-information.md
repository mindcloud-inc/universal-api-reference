# Get User Information with TimeRex

Retrieves the current user information from TimeRex.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/me`
- **Base URL:** `https://timerex.net/api/beta`
- **Official documentation:** [Get User Information](https://developers.timerex.net/api/reference/5eeff576252d2-get-user-information)
