# List Team Calendars with TimeRex

Retrieves calendars in a team from TimeRex.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/calendars`
- **Base URL:** `https://timerex.net/api/beta`
- **Official documentation:** [List Team Calendars](https://developers.timerex.net/api/reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The TimeRex team identifier. |
