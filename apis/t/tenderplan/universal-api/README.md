# <img src="https://images.mindcloud.co/apps/icons/tenderplan_1776455961921.png" alt="Tenderplan logo" width="28" height="28"> Tenderplan: Universal API

Tenderplan is a procurement management platform. This connector provides read access to tenders, tender documents, organizations, RNP records, marks, keywords, notifications, users, and account context through Tenderplan's documented API.

- **Interactive docs:** https://mindcloud.co/docs/universal/rest/tenderplan/latest
- **Category:** Commerce / Procurement
- **Vendor website:** https://tenderplan.ru
- **Vendor API docs:** https://tenderplan.ru/api/doc/
