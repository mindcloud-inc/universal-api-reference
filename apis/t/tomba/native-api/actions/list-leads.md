# List Leads with Tomba

Retrieves leads from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [List Leads](https://docs.tomba.io/api/leads#retrieve-leads)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | no |
