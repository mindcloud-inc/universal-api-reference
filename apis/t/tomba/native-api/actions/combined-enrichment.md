# Combined Enrichment with Tomba

Retrieves combined enrichment data from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/combined/find`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Combined Enrichment](https://docs.tomba.io/api/enrichment#combined-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
