# Technology with Tomba

Retrieves company technology data from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/technology`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Technology](https://docs.tomba.io/api/~endpoints#technology)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | yes |
