# Email Format with Tomba

Retrieves email format details for a company in Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-format`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Email Format](https://docs.tomba.io/api/finder#email-format)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain to inspect email format patterns for. |
