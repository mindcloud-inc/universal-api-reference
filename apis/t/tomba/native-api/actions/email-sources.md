# Email Sources with Tomba

Retrieves email sources from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-sources`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Email Sources](https://docs.tomba.io/api/~endpoints#email-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to retrieve source evidence for. |
