# Author Finder with Tomba

Finds author contact details in Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/author-finder`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Author Finder](https://docs.tomba.io/api/finder#author-finder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | yes |
