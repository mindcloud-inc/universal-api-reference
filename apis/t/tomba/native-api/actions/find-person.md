# Find Person with Tomba

Retrieves person enrichment data from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/find`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Find Person](https://docs.tomba.io/api/enrichment#person-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
