# Find Company with Tomba

Retrieves company enrichment data from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/find`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Find Company](https://docs.tomba.io/api/enrichment#company-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | yes |
