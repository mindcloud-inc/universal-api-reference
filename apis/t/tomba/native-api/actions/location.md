# Location with Tomba

Retrieves location data from Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/location`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Location](https://docs.tomba.io/api/finder#location)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain to retrieve employee location distribution for. |
