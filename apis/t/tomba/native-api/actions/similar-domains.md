# Similar Domains with Tomba

Finds similar domains in Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/similar`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Similar Domains](https://docs.tomba.io/api/~endpoints#similar)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | yes |
