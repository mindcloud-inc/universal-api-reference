# Get Domain Suggestions with Tomba

Finds domain suggestions in Tomba.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-suggestions`
- **Base URL:** `https://api.tomba.io/v1`
- **Official documentation:** [Get Domain Suggestions](https://docs.tomba.io/api/domain-suggestions#get-domain-suggestions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Company name or domain to find related suggestions for. |
