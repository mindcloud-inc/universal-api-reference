# Get Home Most Viewed with The Guardian

Retrieves home-page most-viewed content from The Guardian.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://content.guardianapis.com`
- **Official documentation:** [Get Home Most Viewed](https://raw.githubusercontent.com/guardian/open-platform-site/gh-pages/documentation/md/item.md)
