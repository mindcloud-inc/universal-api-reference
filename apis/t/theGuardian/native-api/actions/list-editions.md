# List Editions with The Guardian

Finds matching editions in The Guardian.

## Endpoint

- **Method:** `GET`
- **Path:** `/editions`
- **Base URL:** `https://content.guardianapis.com`
- **Official documentation:** [List Editions](https://raw.githubusercontent.com/guardian/open-platform-site/gh-pages/documentation/md/edition.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Return editions matching this query term. |
