# Get Home Editors Picks with The Guardian

Retrieves home-page editors' picks from The Guardian.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://content.guardianapis.com`
- **Official documentation:** [Get Home Editors Picks](https://raw.githubusercontent.com/guardian/open-platform-site/gh-pages/documentation/md/item.md)
