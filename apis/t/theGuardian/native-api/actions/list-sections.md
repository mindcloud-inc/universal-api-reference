# List Sections with The Guardian

Finds matching sections in The Guardian.

## Endpoint

- **Method:** `GET`
- **Path:** `/sections`
- **Base URL:** `https://content.guardianapis.com`
- **Official documentation:** [List Sections](https://raw.githubusercontent.com/guardian/open-platform-site/gh-pages/documentation/md/section.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Return sections matching this query term. |
