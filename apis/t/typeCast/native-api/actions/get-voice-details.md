# Get Voice Details with TypeCast

Retrieves details for a specific voice from TypeCast.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/voices/:voice_id`
- **Base URL:** `https://api.typecast.ai/`
- **Official documentation:** [Get Voice Details](https://typecast.ai/docs/api-reference/voices/get-voice-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `voice_id` | path | `list` | yes | Unique TypeCast voice identifier. |
