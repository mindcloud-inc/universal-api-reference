# Starting project with Testomato

Starts all checks in a Testomato project.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/start`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Starting project](https://help.testomato.com/api/starting-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
