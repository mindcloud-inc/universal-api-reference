# Project permissions with Testomato

Retrieves project permissions from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/permissions`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project permissions](https://help.testomato.com/api/project-permissions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
