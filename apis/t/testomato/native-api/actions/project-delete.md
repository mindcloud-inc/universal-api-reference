# Project delete with Testomato

Deletes an existing project from Testomato.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project/:id`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project delete](https://help.testomato.com/api/project-delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
