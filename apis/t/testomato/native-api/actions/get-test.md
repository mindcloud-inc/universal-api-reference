# Get test with Testomato

Retrieves a test from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/tests/:id`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Get test](https://help.testomato.com/api/get-test)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
