# Simplified project status with Testomato

Retrieves simplified project status from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/simple-status`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Simplified project status](https://help.testomato.com/api/simplified-project-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
