# Project status with Testomato

Retrieves project status from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/status`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project status](https://help.testomato.com/api/project-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
