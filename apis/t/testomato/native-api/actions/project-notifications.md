# Project notifications with Testomato

Retrieves project notification settings from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/notifications`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project notifications](https://help.testomato.com/api/project-notifications)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
