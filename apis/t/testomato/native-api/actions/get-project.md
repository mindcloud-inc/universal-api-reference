# Get project with Testomato

Retrieves a project from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Get project](https://help.testomato.com/api/get-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
