# Project roles with Testomato

Retrieves project roles from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/roles`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project roles](https://help.testomato.com/api/project-roles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
