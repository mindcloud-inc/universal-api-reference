# Project users with Testomato

Retrieves project users from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/users`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project users](https://help.testomato.com/api/project-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
