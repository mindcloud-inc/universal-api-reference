# Project groups with Testomato

Retrieves project groups from Testomato.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/areas`
- **Base URL:** `https://testomato.com/api`
- **Official documentation:** [Project groups](https://help.testomato.com/api/project-groups)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
