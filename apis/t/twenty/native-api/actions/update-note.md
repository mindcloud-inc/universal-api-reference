# Update Note with Twenty

## Endpoint

- **Method:** `PATCH`
- **Path:** `/rest/notes/:id`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Update Note](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `bodyV2` | body | `string` | no |
| `title` | body | `string` | no |
