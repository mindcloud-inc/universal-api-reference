# Create Note with Twenty

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/notes`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Create Note](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bodyV2` | body | `string` | no |
