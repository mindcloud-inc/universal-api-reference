# Create Dashboard with Twenty

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/dashboards`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Create Dashboard](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | no |
| `pageLayoutId` | body | `string` | no |
