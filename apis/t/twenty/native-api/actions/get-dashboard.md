# Get Dashboard with Twenty

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/dashboards/:id`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Get Dashboard](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
