# Delete Object Metadata with Twenty

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rest/metadata/objects/:id`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Delete Object Metadata](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
