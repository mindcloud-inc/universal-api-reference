# Create Task with Twenty

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/tasks`
- **Base URL:** `https://api.twenty.com`
- **Official documentation:** [Create Task](https://docs.twenty.com/developers/extend/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bodyV2` | body | `string` | no |
| `status` | body | `string` | no |
| `title` | body | `string` | no |
| `dueAt` | body | `date` | no |
