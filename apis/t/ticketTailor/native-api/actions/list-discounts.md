# List Discounts with Ticket Tailor

Retrieves discounts from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/discounts`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Discounts](https://developers.tickettailor.com/docs/api/get-discount-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
