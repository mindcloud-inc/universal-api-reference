# List Events with Ticket Tailor

Retrieves box office events from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/events`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Events](https://developers.tickettailor.com/docs/api/get-all-events/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
