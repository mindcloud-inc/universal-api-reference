# Get Order with Ticket Tailor

Retrieves an order from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/:order_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Order](https://developers.tickettailor.com/docs/api/get-order-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | Ticket Tailor order ID. |
