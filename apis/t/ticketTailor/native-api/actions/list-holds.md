# List Holds with Ticket Tailor

Retrieves holds from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/holds`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Holds](https://developers.tickettailor.com/docs/api/get-hold-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
