# Get Hold with Ticket Tailor

Retrieves a hold from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/holds/:hold_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Hold](https://developers.tickettailor.com/docs/api/get-hold-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hold_id` | path | `string` | yes | Ticket Tailor hold ID. |
