# List Orders with Ticket Tailor

Retrieves box office orders from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Orders](https://developers.tickettailor.com/docs/api/get-all-orders/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
