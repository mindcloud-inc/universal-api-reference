# Get Store with Ticket Tailor

Retrieves store information from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stores/:store_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Store](https://developers.tickettailor.com/docs/api/get-store-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store_id` | path | `string` | yes | Ticket Tailor store ID. |
