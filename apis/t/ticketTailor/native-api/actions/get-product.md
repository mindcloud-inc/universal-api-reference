# Get Product with Ticket Tailor

Retrieves a product from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:product_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Product](https://developers.tickettailor.com/docs/api/get-product-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | yes | Ticket Tailor product ID. |
