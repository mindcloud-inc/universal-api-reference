# Get Event with Ticket Tailor

Retrieves an event from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/events/:event_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Event](https://developers.tickettailor.com/docs/api/get-event-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Ticket Tailor event ID. |
