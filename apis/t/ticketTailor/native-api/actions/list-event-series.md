# List Event Series with Ticket Tailor

Retrieves box office event series from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event_series`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Event Series](https://developers.tickettailor.com/docs/api/get-all-event-series/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
