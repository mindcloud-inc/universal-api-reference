# List Products with Ticket Tailor

Retrieves products from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Products](https://developers.tickettailor.com/docs/api/get-product-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
