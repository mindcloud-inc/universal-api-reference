# Get Event Series with Ticket Tailor

Retrieves an event series from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event_series/:event_series_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Event Series](https://developers.tickettailor.com/docs/api/get-event-series-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_series_id` | path | `string` | yes | Ticket Tailor event series ID. |
