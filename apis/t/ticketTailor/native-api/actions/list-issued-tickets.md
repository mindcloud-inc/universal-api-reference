# List Issued Tickets with Ticket Tailor

Retrieves issued tickets from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/issued_tickets`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Issued Tickets](https://developers.tickettailor.com/docs/api/get-all-issued-tickets/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
