# List Checkout Forms with Ticket Tailor

Retrieves checkout forms from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/checkout_forms`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Checkout Forms](https://developers.tickettailor.com/docs/api/get-checkout-form-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
