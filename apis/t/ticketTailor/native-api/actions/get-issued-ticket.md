# Get Issued Ticket with Ticket Tailor

Retrieves an issued ticket from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/issued_tickets/:issued_ticket_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Issued Ticket](https://developers.tickettailor.com/docs/api/get-issued-ticket-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issued_ticket_id` | path | `string` | yes | Ticket Tailor issued ticket ID. |
