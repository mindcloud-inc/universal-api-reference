# List Stores with Ticket Tailor

Retrieves stores from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stores`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Stores](https://developers.tickettailor.com/docs/api/get-store-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
