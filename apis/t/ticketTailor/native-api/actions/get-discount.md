# Get Discount with Ticket Tailor

Retrieves a discount from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/discounts/:discount_id`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [Get Discount](https://developers.tickettailor.com/docs/api/get-discount-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discount_id` | path | `string` | yes | Ticket Tailor discount ID. |
