# List Check Ins with Ticket Tailor

Retrieves box office check-ins from Ticket Tailor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/check_ins`
- **Base URL:** `https://api.tickettailor.com`
- **Official documentation:** [List Check Ins](https://developers.tickettailor.com/docs/api/get-check-in-list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
