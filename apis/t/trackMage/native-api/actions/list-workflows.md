# List Workflows with TrackMage

Retrieves workflows from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Workflows](https://docs.trackmage.com/docs/workflow/workflow.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
