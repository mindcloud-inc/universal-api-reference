# Get Product Variant with TrackMage

Retrieves a product variant from TrackMage.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_variants/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Product Variant](https://docs.trackmage.com/docs/product/product-variant.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
