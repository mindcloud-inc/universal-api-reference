# List Shipments with TrackMage

Retrieves shipments from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Shipments](https://docs.trackmage.com/docs/shipment/shipment.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
