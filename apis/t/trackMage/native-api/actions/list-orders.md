# List Orders with TrackMage

Retrieves orders from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Orders](https://docs.trackmage.com/docs/order/order.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
