# Get Workspace with TrackMage

Retrieves a workspace from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Workspace](https://docs.trackmage.com/docs/workspaces.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
