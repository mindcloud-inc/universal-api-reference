# Get Product with TrackMage

Retrieves a product from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Product](https://docs.trackmage.com/docs/product/product.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
