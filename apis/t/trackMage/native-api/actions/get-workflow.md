# Get Workflow with TrackMage

Retrieves a workflow from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Workflow](https://docs.trackmage.com/docs/workflow/workflow.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
