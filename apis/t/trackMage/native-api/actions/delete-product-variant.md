# Delete Product Variant with TrackMage

Deletes an existing product variant from TrackMage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product_variants/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Delete Product Variant](https://docs.trackmage.com/docs/product/product-variant.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
