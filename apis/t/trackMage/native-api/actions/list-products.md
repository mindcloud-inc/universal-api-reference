# List Products with TrackMage

Retrieves products from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Products](https://docs.trackmage.com/docs/product/product.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
