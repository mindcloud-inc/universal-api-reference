# List Product Variants with TrackMage

Retrieves product variants from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_variants`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Product Variants](https://docs.trackmage.com/docs/product/product-variant.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
