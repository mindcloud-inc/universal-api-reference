# List Workspaces with TrackMage

Retrieves workspaces from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Workspaces](https://docs.trackmage.com/docs/workspaces.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
