# Delete Order with TrackMage

Deletes an existing order from TrackMage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Delete Order](https://docs.trackmage.com/docs/order/order.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
