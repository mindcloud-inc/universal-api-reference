# Get Shipment with TrackMage

Retrieves a shipment from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Shipment](https://docs.trackmage.com/docs/shipment/shipment.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
