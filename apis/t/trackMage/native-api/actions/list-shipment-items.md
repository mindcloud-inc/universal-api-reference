# List Shipment Items with TrackMage

Retrieves shipment items from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipment_items`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [List Shipment Items](https://docs.trackmage.com/docs/shipment/shipment-item.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The collection page number |
| `itemsPerPage` | query | `number` | no | The number of items per page |
