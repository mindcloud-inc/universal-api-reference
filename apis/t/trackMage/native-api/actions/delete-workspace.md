# Delete Workspace with TrackMage

Deletes an existing workspace from TrackMage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Delete Workspace](https://docs.trackmage.com/docs/workspaces.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
