# Delete Product with TrackMage

Deletes an existing product from TrackMage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Delete Product](https://docs.trackmage.com/docs/product/product.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
