# Delete Shipment with TrackMage

Deletes an existing shipment from TrackMage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shipments/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Delete Shipment](https://docs.trackmage.com/docs/shipment/shipment.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
