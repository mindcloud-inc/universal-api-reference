# Get Shipment Item with TrackMage

Retrieves a shipment item from TrackMage.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipment_items/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Shipment Item](https://docs.trackmage.com/docs/shipment/shipment-item.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
