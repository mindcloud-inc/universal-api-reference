# Get Order with TrackMage

Retrieves an order from your TrackMage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://api.trackmage.com/`
- **Official documentation:** [Get Order](https://docs.trackmage.com/docs/order/order.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource identifier |
