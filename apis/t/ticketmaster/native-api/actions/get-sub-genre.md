# Get Sub-Genre with Ticketmaster

Retrieves details for a specific sub-genre from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/classifications/subgenres/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Sub-Genre](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#search-subgenres-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the sub-genre. |
