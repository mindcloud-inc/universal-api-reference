# Get Genre with Ticketmaster

Retrieves details for a specific genre from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/classifications/genres/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Genre](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#search-genres-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the genre. |
