# Get Venue with Ticketmaster

Retrieves details for a specific venue from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/venues/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Venue](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#search-venues-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the venue. |
