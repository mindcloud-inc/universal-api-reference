# Get Classification with Ticketmaster

Retrieves details for a specific classification from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/classifications/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Classification](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#search-classifications-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the classification. |
