# Get Segment with Ticketmaster

Retrieves details for a specific segment from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/classifications/segments/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Segment](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#segment-details-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the segment. |
