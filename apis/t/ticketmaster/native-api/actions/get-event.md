# Get Event with Ticketmaster

Retrieves details for a specific event from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/events/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Event](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#event-details-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the event. |
