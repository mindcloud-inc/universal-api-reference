# Get Attraction with Ticketmaster

Retrieves details for a specific attraction from Ticketmaster.

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/v2/attractions/:id`
- **Base URL:** `https://app.ticketmaster.com`
- **Official documentation:** [Get Attraction](https://developer.ticketmaster.com/products-and-docs/apis/discovery-api/v2/#search-attractions-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the attraction. |
