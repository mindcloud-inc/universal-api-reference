# Create Messaging Service with Twilio

Creates a new messaging service in Twilio.

## Endpoint

- **Method:** `POST`
- **Path:** `https://messaging.twilio.com/v1/Services`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [Create Messaging Service](https://www.twilio.com/docs/messaging/api/service-resource#create-a-service)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `FriendlyName` | body | `string` | yes |
