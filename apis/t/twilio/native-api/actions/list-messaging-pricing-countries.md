# List Messaging Pricing Countries with Twilio

Retrieves messaging country pricing from Twilio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://pricing.twilio.com/v1/Messaging/Countries`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [List Messaging Pricing Countries](https://www.twilio.com/docs/messaging/api/pricing#read-multiple-countries-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
