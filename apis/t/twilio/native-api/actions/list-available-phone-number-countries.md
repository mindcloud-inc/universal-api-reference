# List Available Phone Number Countries with Twilio

Retrieves available phone number countries from Twilio.

## Endpoint

- **Method:** `GET`
- **Path:** `/Accounts/:AccountSid/AvailablePhoneNumbers.json`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [List Available Phone Number Countries](https://www.twilio.com/docs/phone-numbers/api/availablephonenumber-resource#read-a-list-of-countries)

## Capabilities

This operation supports [pagination](../README.md#pagination).
