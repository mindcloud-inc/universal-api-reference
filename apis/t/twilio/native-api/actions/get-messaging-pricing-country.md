# Get Messaging Pricing Country with Twilio

Retrieves messaging pricing for a country from Twilio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://pricing.twilio.com/v1/Messaging/Countries/:IsoCountry`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [Get Messaging Pricing Country](https://www.twilio.com/docs/messaging/api/pricing#fetch-a-countries-resource)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `IsoCountry` | path | `string` | yes |
