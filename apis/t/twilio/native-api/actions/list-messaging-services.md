# List Messaging Services with Twilio

Retrieves messaging services from Twilio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://messaging.twilio.com/v1/Services`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [List Messaging Services](https://www.twilio.com/docs/messaging/api/service-resource#retrieve-a-list-of-services)

## Capabilities

This operation supports [pagination](../README.md#pagination).
