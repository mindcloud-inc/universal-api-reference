# Get Messaging Service with Twilio

Retrieves a messaging service from Twilio.

## Endpoint

- **Method:** `GET`
- **Path:** `https://messaging.twilio.com/v1/Services/:Sid`
- **Base URL:** `https://api.twilio.com/2010-04-01`
- **Official documentation:** [Get Messaging Service](https://www.twilio.com/docs/messaging/api/service-resource#retrieve-a-service)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Sid` | path | `string` | yes |
