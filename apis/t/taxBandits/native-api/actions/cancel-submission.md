# Cancel Submission with TaxBandits

Cancels an existing submission in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `Utility/CancelSubmission`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Cancel Submission](https://developer.taxbandits.com/docs/utility/cancelsubmission/)
