# Request W-9 by Email with TaxBandits

Creates a W-9 request by email in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `FormW9/RequestByEmail`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Request W-9 by Email](https://developer.taxbandits.com/docs/formw9/requestbyemail/)
