# List Submission IDs by Business with TaxBandits

Retrieves submission IDs for a business in TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/GetSubmissionIdByBusiness`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List Submission IDs by Business](https://developer.taxbandits.com/docs/utility/getsubmissionidbybusiness/)
