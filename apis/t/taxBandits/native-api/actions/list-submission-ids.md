# List Submission IDs with TaxBandits

Retrieves submission IDs from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/GetAllSubmissionId`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List Submission IDs](https://developer.taxbandits.com/docs/utility/getallsubmissionid/)
