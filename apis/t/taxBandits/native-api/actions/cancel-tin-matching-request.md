# Cancel TIN Matching Request with TaxBandits

Cancels a TIN matching request in TaxBandits.

## Endpoint

- **Method:** `PUT`
- **Path:** `TINMatchingRecipients/CancelRequest`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Cancel TIN Matching Request](https://developer.taxbandits.com/docs/tinmatchingrecipients/cancel/)
