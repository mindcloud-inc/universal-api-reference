# Request WH Certificate by URL with TaxBandits

Creates a withholding certificate request URL in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `WhCertificate/RequestByUrl`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Request WH Certificate by URL](https://developer.taxbandits.com/docs/whcertificate/requestbyurl/)
