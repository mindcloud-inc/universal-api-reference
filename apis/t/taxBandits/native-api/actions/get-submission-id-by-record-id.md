# Get Submission ID by Record ID with TaxBandits

Retrieves a submission ID by record ID in TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/GetSubmissionIdByRecordId`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Get Submission ID by Record ID](https://developer.taxbandits.com/docs/utility/getsubmissionidbyrecordid/)
