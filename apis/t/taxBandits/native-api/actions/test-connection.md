# Test Connection with TaxBandits

Retrieves TaxBandits API connection status and version details.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/Ping`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Test Connection](https://developer.taxbandits.com/docs/utility/ping/)
