# List TIN Matching Requests with TaxBandits

Retrieves TIN matching requests from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `TINMatchingRecipients/List`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List TIN Matching Requests](https://developer.taxbandits.com/docs/tinmatchingrecipients/list/)
