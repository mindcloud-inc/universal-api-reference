# Request WH Certificate by Email with TaxBandits

Creates a withholding certificate request by email in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `WhCertificate/RequestByEmail`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Request WH Certificate by Email](https://developer.taxbandits.com/docs/whcertificate/requestbyemail/)
