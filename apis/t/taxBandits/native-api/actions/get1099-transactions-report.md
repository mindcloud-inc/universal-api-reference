# Get 1099 Transactions Report with TaxBandits

Retrieves a 1099 transactions report from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Reports/Form1099Transactions`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Get 1099 Transactions Report](https://developer.taxbandits.com/docs/form1099transactions/report/)
