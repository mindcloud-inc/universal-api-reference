# Request TIN Matching with TaxBandits

Creates a TIN matching request in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `TINMatchingRecipients/Request`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Request TIN Matching](https://developer.taxbandits.com/docs/tinmatchingrecipients/request/)
