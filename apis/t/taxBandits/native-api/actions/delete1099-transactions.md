# Delete 1099 Transactions with TaxBandits

Deletes 1099 transactions from TaxBandits.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Form1099Transactions`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Delete 1099 Transactions](https://developer.taxbandits.com/docs/form1099transactions/delete/)
