# Get TIN Matching Status with TaxBandits

Retrieves TIN matching request status from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `TINMatchingRecipients/Status`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Get TIN Matching Status](https://developer.taxbandits.com/docs/tinmatchingrecipients/status/)
