# Create 1099 Transactions with TaxBandits

Creates 1099 transactions in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `Form1099Transactions`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Create 1099 Transactions](https://developer.taxbandits.com/docs/form1099transactions/post/)
