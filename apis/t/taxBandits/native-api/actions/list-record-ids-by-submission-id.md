# List Record IDs by Submission ID with TaxBandits

Retrieves record IDs for a submission in TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/GetRecordIdBySubmissionId`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List Record IDs by Submission ID](https://developer.taxbandits.com/docs/utility/getrecordidbysubmissionid/)
