# List 1099 Transactions with TaxBandits

Retrieves 1099 transactions from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Form1099Transactions`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List 1099 Transactions](https://developer.taxbandits.com/docs/form1099transactions/get/)
