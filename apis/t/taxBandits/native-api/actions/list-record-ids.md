# List Record IDs with TaxBandits

Retrieves record IDs from TaxBandits.

## Endpoint

- **Method:** `GET`
- **Path:** `Utility/GetRecordIds`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [List Record IDs](https://developer.taxbandits.com/docs/utility/getrecordids/)
