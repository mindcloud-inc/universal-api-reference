# Request W-9 by URL with TaxBandits

Creates a W-9 request URL in TaxBandits.

## Endpoint

- **Method:** `POST`
- **Path:** `FormW9/RequestByUrl`
- **Base URL:** `https://testapi.taxbandits.com/v1.7.3/`
- **Official documentation:** [Request W-9 by URL](https://developer.taxbandits.com/docs/formw9/requestbyurl/)
