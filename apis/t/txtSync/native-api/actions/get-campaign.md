# Get Campaign with TxtSync

Retrieves a specific campaign from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Get Campaign](https://docs.txtsync.com/#get-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
