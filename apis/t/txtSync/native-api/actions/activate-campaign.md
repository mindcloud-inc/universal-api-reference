# Activate Campaign with TxtSync

Activates an existing campaign in TxtSync.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:id/activate`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Activate Campaign](https://docs.txtsync.com/#activate-campaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
