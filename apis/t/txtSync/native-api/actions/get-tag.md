# Get Tag with TxtSync

Retrieves a specific tag from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Get Tag](https://docs.txtsync.com/#get-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tag identifier. |
