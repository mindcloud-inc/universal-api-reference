# Delete Contact with TxtSync

Deletes an existing contact from TxtSync.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Delete Contact](https://docs.txtsync.com/#delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact identifier. |
