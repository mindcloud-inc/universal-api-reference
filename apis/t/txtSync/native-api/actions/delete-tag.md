# Delete Tag with TxtSync

Deletes an existing tag from TxtSync.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Delete Tag](https://docs.txtsync.com/#delete-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tag identifier. |
