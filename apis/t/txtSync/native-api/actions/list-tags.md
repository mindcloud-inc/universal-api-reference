# List Tags with TxtSync

Retrieves tags from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [List Tags](https://docs.txtsync.com/#bulk-get-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
