# Get Campaign Report with TxtSync

Retrieves a campaign report from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id/report`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Get Campaign Report](https://docs.txtsync.com/#campaign-reporting)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
