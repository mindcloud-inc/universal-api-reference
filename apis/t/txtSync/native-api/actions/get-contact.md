# Get Contact with TxtSync

Retrieves a specific contact from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [Get Contact](https://docs.txtsync.com/#get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact identifier. |
