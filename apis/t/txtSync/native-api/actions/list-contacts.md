# List Contacts with TxtSync

Retrieves contacts from TxtSync.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.txtsync.com`
- **Official documentation:** [List Contacts](https://docs.txtsync.com/#bulk-get-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
