# Delete Synonym Set with Typesense

Deletes a synonym set from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/synonym_sets/{{synonymSetName}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Synonym Set](https://typesense.org/docs/30.0/api/synonyms.html#delete-a-synonym-set)
