# List Synonym Items with Typesense

Retrieves synonyms from a Typesense synonym set.

## Endpoint

- **Method:** `GET`
- **Path:** `/synonym_sets/{{synonymSetName}}/items`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [List Synonym Items](https://typesense.org/docs/30.0/api/synonyms.html#list-synonyms-in-a-set)
