# Upsert Synonym Set with Typesense

Creates or updates a synonym set in Typesense.

## Endpoint

- **Method:** `PUT`
- **Path:** `/synonym_sets/{{synonymSetName}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Upsert Synonym Set](https://typesense.org/docs/30.0/api/synonyms.html#create-or-update-a-synonym-set)
