# Get Curation Set with Typesense

Retrieves a curation set from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/curation_sets/{{name}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Curation Set](https://typesense.org/docs/30.0/api/curation.html#retrieve-a-curation-set)
