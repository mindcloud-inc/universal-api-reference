# Get Analytics Rule with Typesense

Retrieves an analytics rule from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/rules/{{name}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Analytics Rule](https://typesense.org/docs/30.0/api/analytics-query-suggestions.html#create-analytics-rules)
