# Delete Stemming Dictionary with Typesense

Deletes a stemming dictionary from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/stemming/dictionaries/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Stemming Dictionary](https://typesense.org/docs/30.0/api/api-keys.html#stemming-dictionary-operations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Stemming dictionary ID. |
