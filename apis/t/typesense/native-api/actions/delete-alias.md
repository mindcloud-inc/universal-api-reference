# Delete Alias with Typesense

Deletes a collection alias from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/aliases/{{alias}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Alias](https://typesense.org/docs/30.0/api/collection-alias.html#delete-an-alias)
