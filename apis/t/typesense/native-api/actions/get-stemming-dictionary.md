# Get Stemming Dictionary with Typesense

Retrieves a stemming dictionary from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/stemming/dictionaries/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Stemming Dictionary](https://typesense.org/docs/30.0/api/stemming.html#managing-dictionaries)
