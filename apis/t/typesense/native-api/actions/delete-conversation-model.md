# Delete Conversation Model with Typesense

Deletes a conversation model from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversations/models/{{modelId}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Conversation Model](https://typesense.org/docs/30.0/api/conversational-search-rag.html#managing-conversation-models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `string` | yes | Conversation model ID. |
