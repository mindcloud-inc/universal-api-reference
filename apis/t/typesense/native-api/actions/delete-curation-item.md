# Delete Curation Item with Typesense

Deletes a specific curation from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/curation_sets/{{name}}/items/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Curation Item](https://typesense.org/docs/30.0/api/curation.html#delete-a-curation)
