# Delete All Documents with Typesense

Deletes all documents from a Typesense collection.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collections/{{collection}}/documents`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete All Documents](https://typesense.org/docs/30.0/api/documents.html#delete-all-documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name. |
