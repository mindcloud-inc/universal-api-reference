# Delete Synonym Item with Typesense

Deletes a specific synonym from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/synonym_sets/{{synonymSetName}}/items/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Synonym Item](https://typesense.org/docs/30.0/api/synonyms.html#delete-a-synonym)
