# Get Synonym Item with Typesense

Retrieves a synonym from a Typesense synonym set.

## Endpoint

- **Method:** `GET`
- **Path:** `/synonym_sets/{{synonymSetName}}/items/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Synonym Item](https://typesense.org/docs/30.0/api/synonyms.html#retrieve-a-synonym)
