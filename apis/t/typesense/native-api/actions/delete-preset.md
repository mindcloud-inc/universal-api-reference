# Delete Preset with Typesense

Deletes a search preset from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/presets/{{presetName}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Preset](https://typesense.org/docs/30.0/api/api-keys.html#preset-operations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `presetName` | path | `string` | yes | Preset name. |
