# Upsert Alias with Typesense

Creates or updates a collection alias in Typesense.

## Endpoint

- **Method:** `PUT`
- **Path:** `/aliases/{{alias}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Upsert Alias](https://typesense.org/docs/30.0/api/collection-alias.html#create-or-update-an-alias)
