# Get Natural Language Search Model with Typesense

Retrieves a natural language search model from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/nl_search_models/{{modelId}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Natural Language Search Model](https://typesense.org/docs/30.0/api/natural-language-search.html#get-model-details)
