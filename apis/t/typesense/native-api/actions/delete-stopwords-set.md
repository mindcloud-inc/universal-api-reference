# Delete Stopwords Set with Typesense

Deletes a stopwords set from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/stopwords/{{setId}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Stopwords Set](https://typesense.org/docs/30.0/api/api-keys.html#stopwords-actions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `setId` | path | `string` | yes | Stopwords set ID. |
