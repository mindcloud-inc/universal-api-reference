# Export Documents with Typesense

Exports documents from a Typesense collection.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/{{collection}}/documents/export`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Export Documents](https://typesense.org/docs/30.0/api/documents.html#export-documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name. |
