# Get Conversation Model with Typesense

Retrieves a conversation model from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/models/{{modelId}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Conversation Model](https://typesense.org/docs/30.0/api/conversational-search-rag.html#retrieve-a-single-model)
