# Update Collection Schema with Typesense

Updates a collection schema in Typesense.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/collections/{{collection}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Update Collection Schema](https://typesense.org/docs/30.0/api/collections.html#alter-a-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name. |
