# Voice Multi Search with Typesense

Finds results in Typesense using voice query search.

## Endpoint

- **Method:** `POST`
- **Path:** `/multi_search`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Voice Multi Search](https://typesense.org/docs/30.0/api/voice-search.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searches` | body | `object` | yes | Voice multi-search request body. |
