# Create Document with Typesense

Creates a new document in Typesense.

## Endpoint

- **Method:** `POST`
- **Path:** `/collections/{{collection}}/documents`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Create Document](https://typesense.org/docs/30.0/api/documents.html#index-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name. |
