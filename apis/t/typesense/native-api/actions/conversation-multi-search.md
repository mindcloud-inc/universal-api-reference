# Conversation Multi Search with Typesense

Finds results in Typesense using conversational multi search.

## Endpoint

- **Method:** `POST`
- **Path:** `/multi_search`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Conversation Multi Search](https://typesense.org/docs/30.0/api/conversational-search-rag.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searches` | body | `object` | yes | Conversation multi-search request body. |
