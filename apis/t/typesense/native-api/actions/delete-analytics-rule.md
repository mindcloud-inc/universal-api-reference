# Delete Analytics Rule with Typesense

Deletes an analytics rule from Typesense.

- **Method:** `DELETE`
- **Path:** `/analytics/rules/{{name}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Analytics Rule](https://typesense.org/docs/30.0/api/analytics-query-suggestions.html#remove-a-rule)
