# Upsert Synonym Item with Typesense

Creates or updates a synonym in Typesense.

## Endpoint

- **Method:** `PUT`
- **Path:** `/synonym_sets/{{synonymSetName}}/items/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Upsert Synonym Item](https://typesense.org/docs/30.0/api/synonyms.html#create-or-update-a-synonym)
