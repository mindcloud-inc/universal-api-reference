# Delete Collection with Typesense

Deletes a specific collection from Typesense.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collections/{{collection}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Delete Collection](https://typesense.org/docs/30.0/api/collections.html#drop-a-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection` | path | `string` | yes | Collection name. |
