# List Curation Items with Typesense

Retrieves curations from a Typesense curation set.

## Endpoint

- **Method:** `GET`
- **Path:** `/curation_sets/{{name}}/items`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [List Curation Items](https://typesense.org/docs/30.0/api/curation.html#list-curations-in-a-set)
