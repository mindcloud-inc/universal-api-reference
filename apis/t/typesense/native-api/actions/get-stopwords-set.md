# Get Stopwords Set with Typesense

Retrieves a stopwords set from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/stopwords/{{setId}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Stopwords Set](https://typesense.org/docs/30.0/api/stopwords.html#get-a-specific-stopwords-set)
