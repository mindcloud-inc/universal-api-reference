# Get Alias with Typesense

Retrieves a collection alias from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/aliases/{{alias}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Alias](https://typesense.org/docs/30.0/api/collection-alias.html#retrieve-an-alias)
