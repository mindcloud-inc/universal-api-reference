# Get Synonym Set with Typesense

Retrieves a synonym set from Typesense.

## Endpoint

- **Method:** `GET`
- **Path:** `/synonym_sets/{{synonymSetName}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Synonym Set](https://typesense.org/docs/30.0/api/synonyms.html#retrieve-a-synonym-set)
