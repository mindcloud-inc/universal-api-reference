# Get Curation Item with Typesense

Retrieves a curation from a Typesense curation set.

## Endpoint

- **Method:** `GET`
- **Path:** `/curation_sets/{{name}}/items/{{id}}`
- **Base URL:** `https://5brh8vz1lictf0jop-1.a2.typesense.net`
- **Official documentation:** [Get Curation Item](https://typesense.org/docs/30.0/api/curation.html#retrieve-a-curation)
