# Get webhooks with Tellephant

Retrieves current webhook settings from Tellephant.

## Endpoint

- **Method:** `POST`
- **Path:** `https://app.tellephant.com/api/v2/user/webhook`
- **Base URL:** `https://api.tellephant.com`
- **Official documentation:** [Get webhooks](https://app.tellephant.com/api-documentation#get-webhooks)
