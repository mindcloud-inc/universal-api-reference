# Get Current Plan with TestDome

Retrieves the current plan from TestDome.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/current/plan`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Get Current Plan](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)
