# Archive Test with TestDome

Archives a test in TestDome.

## Endpoint

- **Method:** `POST`
- **Path:** `/tests/:testId/archive`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Archive Test](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
