# Delete Test with TestDome

Deletes an existing test from TestDome.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tests/:testId`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Delete Test](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
