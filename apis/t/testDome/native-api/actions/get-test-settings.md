# Get Test Settings with TestDome

Retrieves test settings from TestDome.

## Endpoint

- **Method:** `GET`
- **Path:** `/tests/:testId/settings`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Get Test Settings](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
