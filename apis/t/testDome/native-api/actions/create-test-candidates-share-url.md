# Create Test Candidates Share URL with TestDome

Creates a share URL for test candidates in TestDome.

## Endpoint

- **Method:** `POST`
- **Path:** `/tests/:testId/candidates/share-url`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Create Test Candidates Share URL](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
