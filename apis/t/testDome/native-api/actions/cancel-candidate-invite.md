# Cancel Candidate Invite with TestDome

Cancels a candidate invite in TestDome.

## Endpoint

- **Method:** `POST`
- **Path:** `/candidates/:candidateId/cancel-invite`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Cancel Candidate Invite](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `candidateId` | path | `number` | yes |
