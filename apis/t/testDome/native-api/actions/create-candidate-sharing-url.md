# Create Candidate Sharing URL with TestDome

Creates a candidate sharing URL in TestDome.

## Endpoint

- **Method:** `POST`
- **Path:** `/candidates/:candidateId/sharing-url`
- **Base URL:** `https://api.staging.testdome.com/v3`
- **Official documentation:** [Create Candidate Sharing URL](https://api.testdome.com/openapi-ui/index/index.html?urls.primaryName=v3%20Docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `candidateId` | path | `number` | yes |
