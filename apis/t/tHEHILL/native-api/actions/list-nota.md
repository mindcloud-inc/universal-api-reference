# List Nota with THE HILL

Retrieves Nota posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/nota`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Nota](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
