# List Navigation with THE HILL

Retrieves navigation items from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/navigation`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Navigation](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
