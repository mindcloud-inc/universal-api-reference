# Get Tag with THE HILL

Retrieves a specific tag from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/tags/{id}`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Get Tag](https://developer.wordpress.org/rest-api/reference/tags/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | WordPress tag ID. |
