# List Alerts with THE HILL

Retrieves alert posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/alerts`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Alerts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
