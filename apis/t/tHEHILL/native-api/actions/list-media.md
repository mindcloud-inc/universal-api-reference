# List Media with THE HILL

Retrieves media items from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/media`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Media](https://developer.wordpress.org/rest-api/reference/media/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
