# List Videos with THE HILL

Retrieves video posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/video`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Videos](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
