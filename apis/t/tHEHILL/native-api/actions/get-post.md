# Get Post with THE HILL

Retrieves a specific post from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/posts/{id}`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Get Post](https://developer.wordpress.org/rest-api/reference/posts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | WordPress post ID. |
