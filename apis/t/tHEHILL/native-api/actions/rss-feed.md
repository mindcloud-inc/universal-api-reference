# RSS Feed with THE HILL

Retrieves The Hill's news RSS feed.

## Endpoint

- **Method:** `GET`
- **Path:** `/feed/`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [RSS Feed](https://thehill.com/feed/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `feed` | query | `string` | no | RSS feed name to load. |
| `format` | query | `string` | no | Feed format to request. |
