# List Events Facts Tags with THE HILL

Retrieves events facts tags from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/events_facts_tags`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Events Facts Tags](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
