# Get Category with THE HILL

Retrieves a specific category from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/categories/{id}`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Get Category](https://developer.wordpress.org/rest-api/reference/categories/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | WordPress category ID. |
