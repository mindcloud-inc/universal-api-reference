# List Email Newsletters with THE HILL

Retrieves email newsletters from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/email_newsletter`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Email Newsletters](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
