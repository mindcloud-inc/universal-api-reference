# List Vertical Posts with THE HILL

Retrieves vertical posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/vertical_post`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Vertical Posts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
