# Get Page with THE HILL

Retrieves a specific page from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/pages/{id}`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Get Page](https://developer.wordpress.org/rest-api/reference/pages/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | WordPress page ID. |
