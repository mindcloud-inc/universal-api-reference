# List Events with THE HILL

Retrieves event posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/event`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Events](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
