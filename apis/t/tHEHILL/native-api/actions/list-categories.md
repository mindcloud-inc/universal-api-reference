# List Categories with THE HILL

Retrieves content categories from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/categories`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Categories](https://developer.wordpress.org/rest-api/reference/categories/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
