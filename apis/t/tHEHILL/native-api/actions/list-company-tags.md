# List Company Tags with THE HILL

Retrieves company tags from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/company_tags`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Company Tags](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
