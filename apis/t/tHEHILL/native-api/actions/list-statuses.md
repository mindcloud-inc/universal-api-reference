# List Statuses with THE HILL

Retrieves content statuses from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/statuses`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Statuses](https://developer.wordpress.org/rest-api/reference/statuses/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
