# Search Content with THE HILL

Finds content in The Hill by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/search`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Search Content](https://developer.wordpress.org/rest-api/reference/search-results/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
