# List Tags with THE HILL

Retrieves content tags from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/tags`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Tags](https://developer.wordpress.org/rest-api/reference/tags/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
