# List Future America Posts with THE HILL

Retrieves Future America posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/future_america_post`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Future America Posts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
