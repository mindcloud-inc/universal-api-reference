# List Galleries with THE HILL

Retrieves gallery posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/galleries`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Galleries](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
