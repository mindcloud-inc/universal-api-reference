# Get Media with THE HILL

Retrieves a specific media item from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/media/{id}`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [Get Media](https://developer.wordpress.org/rest-api/reference/media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | WordPress media ID. |
