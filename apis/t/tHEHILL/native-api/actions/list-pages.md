# List Pages with THE HILL

Retrieves published pages from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/pages`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Pages](https://developer.wordpress.org/rest-api/reference/pages/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
