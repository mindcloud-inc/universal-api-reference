# List Feed Posts with THE HILL

Retrieves feed posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/feed-posts`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Feed Posts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
