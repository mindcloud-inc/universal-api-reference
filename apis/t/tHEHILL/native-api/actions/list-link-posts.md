# List Link Posts with THE HILL

Retrieves link posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/link-posts`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List Link Posts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
