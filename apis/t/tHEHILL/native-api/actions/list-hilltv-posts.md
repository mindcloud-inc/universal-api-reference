# List HillTV Posts with THE HILL

Retrieves HillTV posts from The Hill.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/hilltv_post`
- **Base URL:** `https://thehill.com/wp-json/`
- **Official documentation:** [List HillTV Posts](https://developer.wordpress.org/rest-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
