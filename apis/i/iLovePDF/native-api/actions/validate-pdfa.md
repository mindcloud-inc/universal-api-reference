# Validate PDF/A with iLovePDF

Validates a PDF/A file in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Validate PDF/A](https://www.iloveapi.com/docs/api-reference#validatepdfa-extra-parameters)
