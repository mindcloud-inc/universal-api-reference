# Increase Expiration Days with iLovePDF

Extends signature request expiration in iLovePDF.

## Endpoint

- **Method:** `PUT`
- **Path:** `https://:server/v1/signature/increase-expiration-days/:tokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Increase Expiration Days](https://www.iloveapi.com/docs/api-reference#signature-increase-expiration-days)
