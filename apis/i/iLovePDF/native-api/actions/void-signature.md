# Void Signature with iLovePDF

Voids a signature request in iLovePDF.

## Endpoint

- **Method:** `PUT`
- **Path:** `https://:server/v1/signature/void/:tokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Void Signature](https://www.iloveapi.com/docs/api-reference#signature-void)
