# JPG to PDF with iLovePDF

Creates a PDF from JPG files in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [JPG to PDF](https://www.iloveapi.com/docs/api-reference#imagepdf-extra-parameters)
