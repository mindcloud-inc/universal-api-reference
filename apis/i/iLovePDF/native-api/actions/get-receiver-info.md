# Get Receiver Info with iLovePDF

Retrieves signer info from an iLovePDF signature request.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/signature/receiver/info/:receiverTokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Get Receiver Info](https://www.iloveapi.com/docs/api-reference#get-signer)
