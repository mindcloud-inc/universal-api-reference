# Fix Receiver Email with iLovePDF

Updates a signer email in an iLovePDF signature request.

## Endpoint

- **Method:** `PUT`
- **Path:** `https://:server/v1/signature/signer/fix-email/:receiverTokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Fix Receiver Email](https://www.iloveapi.com/docs/api-reference#fix-signer-email)
