# Get Signature Server and Task ID with iLovePDF

Creates a signature task and server assignment in iLovePDF.

## Endpoint

- **Method:** `GET`
- **Path:** `/start/sign`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Get Signature Server and Task ID](https://www.iloveapi.com/docs/api-reference#start)
