# Fix Signer Phone with iLovePDF

Updates a signer phone number in an iLovePDF signature request.

## Endpoint

- **Method:** `PUT`
- **Path:** `https://:server/v1/signature/signer/fix-phone/:signerTokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Fix Signer Phone](https://www.iloveapi.com/docs/api-reference#fix-signer-phone)
