# Page Numbers with iLovePDF

Adds page numbers to a PDF in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Page Numbers](https://www.iloveapi.com/docs/api-reference#pagenumber-extra-parameters)
