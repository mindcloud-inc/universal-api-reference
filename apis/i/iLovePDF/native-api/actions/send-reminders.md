# Send Reminders with iLovePDF

Sends signature reminders in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/signature/sendReminder/:tokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Send Reminders](https://www.iloveapi.com/docs/api-reference#send-reminders)
