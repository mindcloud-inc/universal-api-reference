# Download Original Files with iLovePDF

Retrieves original files from an iLovePDF signature request.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/signature/:tokenRequester/download-original`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Download Original Files](https://www.iloveapi.com/docs/api-reference#download-original)
