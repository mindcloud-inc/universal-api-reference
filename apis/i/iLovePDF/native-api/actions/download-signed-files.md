# Download Signed Files with iLovePDF

Retrieves signed files from an iLovePDF signature request.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/signature/:tokenRequester/download-signed`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Download Signed Files](https://www.iloveapi.com/docs/api-reference#download-signed)
