# Get Signature Status with iLovePDF

Retrieves a signature request from iLovePDF.

## Endpoint

- **Method:** `GET`
- **Path:** `/signature/requesterview/:tokenRequester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Get Signature Status](https://www.iloveapi.com/docs/api-reference#get-signature)
