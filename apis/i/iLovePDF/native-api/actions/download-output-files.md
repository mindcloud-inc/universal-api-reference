# Download Output Files with iLovePDF

Retrieves processed output files from iLovePDF.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/download/:task`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Download Output Files](https://www.iloveapi.com/docs/api-reference#download)
