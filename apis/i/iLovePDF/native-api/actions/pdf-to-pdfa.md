# PDF to PDF/A with iLovePDF

Converts a PDF to PDF/A in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [PDF to PDF/A](https://www.iloveapi.com/docs/api-reference#pdfa-extra-parameters)
