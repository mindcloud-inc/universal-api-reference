# Compress PDF with iLovePDF

Creates a compressed PDF in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Compress PDF](https://www.iloveapi.com/docs/api-reference#compress-extra-parameters)
