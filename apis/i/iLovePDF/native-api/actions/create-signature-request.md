# Create Signature Request with iLovePDF

Creates a signature request in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/signature`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Create Signature Request](https://www.iloveapi.com/docs/api-reference#create-signature)
