# Remove Uploaded File with iLovePDF

Deletes an uploaded file from iLovePDF.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://:server/v1/upload/:task/:serverFilename`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Remove Uploaded File](https://www.iloveapi.com/docs/api-reference#upload)
