# Watermark PDF with iLovePDF

Adds a watermark to a PDF in iLovePDF.

## Endpoint

- **Method:** `POST`
- **Path:** `https://:server/v1/process`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Watermark PDF](https://www.iloveapi.com/docs/api-reference#watermark-extra-parameters)
