# List Signatures with iLovePDF

Retrieves signature requests from iLovePDF.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/signature/list`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [List Signatures](https://www.iloveapi.com/docs/api-reference#list-signatures)
