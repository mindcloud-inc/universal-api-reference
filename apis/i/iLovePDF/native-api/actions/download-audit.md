# Download Audit with iLovePDF

Retrieves an audit file from iLovePDF.

## Endpoint

- **Method:** `GET`
- **Path:** `https://:server/v1/signature/:tokenRequester/download-audit`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Download Audit](https://www.iloveapi.com/docs/api-reference#download-audit)
