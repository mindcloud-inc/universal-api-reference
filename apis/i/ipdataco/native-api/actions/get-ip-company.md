# Get IP Company with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Company](https://docs.ipdata.co/docs/ip-to-company-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
