# Get IP Basic ASN with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip/asn`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Basic ASN](https://docs.ipdata.co/docs/asn-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
