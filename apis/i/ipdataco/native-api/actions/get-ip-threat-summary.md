# Get IP Threat Summary with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip/threat`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Threat Summary](https://docs.ipdata.co/docs/proxy-tor-and-threat-detection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
