# Get IP Details with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Details](https://docs.ipdata.co/docs/getting-started)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
| `fields` | query | `string` | no | Comma-separated response fields to return. |
