# Get IP Carrier with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip/carrier`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Carrier](https://docs.ipdata.co/docs/mobile-carrier-detection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
