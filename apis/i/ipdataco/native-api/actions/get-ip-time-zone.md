# Get IP Time Zone with ipdata.co

## Endpoint

- **Method:** `GET`
- **Path:** `/:ip/time_zone`
- **Base URL:** `https://api.ipdata.co`
- **Official documentation:** [Get IP Time Zone](https://docs.ipdata.co/docs/all-response-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | no | The IP address to look up. |
