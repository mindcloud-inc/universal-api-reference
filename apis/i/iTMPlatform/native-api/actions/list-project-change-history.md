# List Project Change History with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/Projects/{ProjectId}/changeHistory`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Project Change History](https://developers.itmplatform.com/documentation/#/operations/changeHistory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
