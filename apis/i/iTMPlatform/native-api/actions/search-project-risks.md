# Search Project Risks with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Risks/Search`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Search Project Risks](https://developers.itmplatform.com/documentation/#/operations/getProjectRisksSearchV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
