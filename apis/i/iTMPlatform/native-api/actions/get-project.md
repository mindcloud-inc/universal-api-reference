# Get Project with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/{ProjectId}`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Project](https://developers.itmplatform.com/documentation/#/operations/getAProjectV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
