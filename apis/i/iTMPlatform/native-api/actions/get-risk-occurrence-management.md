# Get Risk Occurrence Management with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/Issue/{IssueId}/riskoccurencemanagement`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Risk Occurrence Management](https://developers.itmplatform.com/documentation/#/operations/getRiskOccurrenceManagement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `IssueId` | path | `string` | yes | The ITM Platform issue ID. |
