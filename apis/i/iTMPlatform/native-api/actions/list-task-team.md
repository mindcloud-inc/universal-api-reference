# List Task Team with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/task/{TaskId}/team//`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Task Team](https://developers.itmplatform.com/documentation/#/operations/getATaskTeam)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `TaskId` | path | `string` | yes | The ITM Platform task ID. |
