# Get Project Sprint with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Sprints/{SprintId}`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Project Sprint](https://developers.itmplatform.com/documentation/#/operations/getProjectSprint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `SprintId` | path | `string` | yes | The ITM Platform sprint ID. |
