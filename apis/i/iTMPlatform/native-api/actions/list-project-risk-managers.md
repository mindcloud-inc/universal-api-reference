# List Project Risk Managers with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/riskmanagers`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Project Risk Managers](https://developers.itmplatform.com/documentation/#/operations/getProjectRiskManagers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
