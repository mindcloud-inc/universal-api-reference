# Get Project Risk with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Risks/{RiskId}`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Project Risk](https://developers.itmplatform.com/documentation/#/operations/getAProjectRiskV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `RiskId` | path | `string` | yes | The ITM Platform risk ID. |
