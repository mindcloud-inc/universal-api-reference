# List Project Issues with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Issues`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Project Issues](https://developers.itmplatform.com/documentation/#/operations/getProjectIssuesV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
