# Search Project Issues with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Issues/Search`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Search Project Issues](https://developers.itmplatform.com/documentation/#/operations/getProjectIssuesSearchV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
