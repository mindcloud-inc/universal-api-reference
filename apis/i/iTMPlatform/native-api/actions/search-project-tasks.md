# Search Project Tasks with ITM Platform

## Endpoint

- **Method:** `POST`
- **Path:** `/Projects/{ProjectId}/Tasks/Search`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Search Project Tasks](https://developers.itmplatform.com/documentation/#/operations/getProjectTasksSearch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
