# Search Project Sprints with ITM Platform

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/Projects/{ProjectId}/Sprints/Search`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Search Project Sprints](https://developers.itmplatform.com/documentation/#/operations/getProjectSprintSearch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
