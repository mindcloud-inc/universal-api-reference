# List Agile Task Statuses with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/GetKanbanTaskStatus`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Agile Task Statuses](https://developers.itmplatform.com/documentation/#/operations/getAgileTaskStatusesV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
