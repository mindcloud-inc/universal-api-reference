# Get Task with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/Projects/{ProjectId}/Tasks/{TaskId}`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Task](https://developers.itmplatform.com/documentation/#/operations/getATask)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `TaskId` | path | `string` | yes | The ITM Platform task ID. |
