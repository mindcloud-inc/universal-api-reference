# Get Project Issue with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/Projects/{ProjectId}/Issues/{IssueId}`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Project Issue](https://developers.itmplatform.com/documentation/#/operations/getAProjectIssueV2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
| `IssueId` | path | `string` | yes | The ITM Platform issue ID. |
