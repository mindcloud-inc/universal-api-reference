# List Project Team with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/team`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Project Team](https://developers.itmplatform.com/documentation/#/operations/getAProjectTeam)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
