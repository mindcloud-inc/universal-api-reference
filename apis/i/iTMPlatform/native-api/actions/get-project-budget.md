# Get Project Budget with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/budget`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [Get Project Budget](https://developers.itmplatform.com/documentation/#/operations/getAProjectBudget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
