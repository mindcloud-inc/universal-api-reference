# List Project Progress Reports with ITM Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/project/{ProjectId}/progress/`
- **Base URL:** `https://api.itmplatform.com/{company}`
- **Official documentation:** [List Project Progress Reports](https://developers.itmplatform.com/documentation/#/operations/getProjectProgressReport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProjectId` | path | `string` | yes | The ITM Platform project ID. |
