# Delete Profile File with Instafill

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/profiles/:profileId/files/:fileId`
- **Base URL:** `https://api.instafill.ai`
- **Official documentation:** [Delete Profile File](https://api.instafill.ai/swagger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `profileId` | path | `string` | yes |
| `fileId` | path | `string` | yes |
