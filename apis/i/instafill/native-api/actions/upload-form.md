# Upload Form with Instafill

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/forms/upload`
- **Base URL:** `https://api.instafill.ai`
- **Official documentation:** [Upload Form](https://docs.instafill.ai/docs/api/forms/create-a-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
| `payload` | body | `object` | no |
