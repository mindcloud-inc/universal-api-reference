# List Profiles with Instafill

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/profiles`
- **Base URL:** `https://api.instafill.ai`
- **Official documentation:** [List Profiles](https://api.instafill.ai/swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | — |
| `status` | query | `string` | no | Filter profiles by status. |
| `name` | query | `string` | no | — |
| `name` | query | `string` | no | Filter profiles by name. |
| `page` | query | `number` | no | — |
| `page` | query | `number` | no | Page number to fetch. |
| `size` | query | `number` | no | — |
| `size` | query | `number` | no | Number of profiles per page. |
