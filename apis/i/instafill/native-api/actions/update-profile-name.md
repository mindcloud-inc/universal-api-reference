# Update Profile Name with Instafill

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/profiles/:profileId/name`
- **Base URL:** `https://api.instafill.ai`
- **Official documentation:** [Update Profile Name](https://api.instafill.ai/swagger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `profileId` | path | `string` | yes |
| `name` | body | `string` | no |
