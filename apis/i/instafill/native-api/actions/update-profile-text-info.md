# Update Profile Text Info with Instafill

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/profiles/:profileId`
- **Base URL:** `https://api.instafill.ai`
- **Official documentation:** [Update Profile Text Info](https://api.instafill.ai/swagger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `profileId` | path | `string` | yes |
| `text_info` | body | `string` | no |
