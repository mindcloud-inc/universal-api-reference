# Load Template into Inspection with InventoryBase

Updates an inspection in InventoryBase by loading a template.

## Endpoint

- **Method:** `PUT`
- **Path:** `/inspections/:inspectionId/templates/:templateId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Load Template into Inspection](https://developer.inventorybase.com/#loading-an-template)
