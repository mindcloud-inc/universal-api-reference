# List Properties with InventoryBase

Retrieves all property records from InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Properties](https://developer.inventorybase.com/#list-all-properties)

## Capabilities

This operation supports [pagination](../README.md#pagination).
