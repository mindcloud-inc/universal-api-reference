# List Property Meters with InventoryBase

Retrieves all meters for a property in InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/:propertyId/meters`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Property Meters](https://developer.inventorybase.com/#list-all-meters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `number` | yes | The ID of the property |
