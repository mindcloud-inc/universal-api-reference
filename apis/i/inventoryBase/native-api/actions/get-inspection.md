# Get Inspection with InventoryBase

Retrieves an inspection from InventoryBase by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/:inspectionId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Inspection](https://developer.inventorybase.com/#get-an-inspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
