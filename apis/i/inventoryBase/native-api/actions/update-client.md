# Update Client with InventoryBase

Updates an existing client in InventoryBase.

## Endpoint

- **Method:** `PUT`
- **Path:** `/clients/:clientId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Update Client](https://developer.inventorybase.com/#update-a-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `number` | yes | The InventoryBase client ID. |
