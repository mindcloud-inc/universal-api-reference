# Get Staff Member with InventoryBase

Retrieves a staff member from InventoryBase by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/staff/:staffId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Staff Member](https://developer.inventorybase.com/#get-a-single-staff-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `staffId` | path | `number` | yes | The InventoryBase staff member ID. |
