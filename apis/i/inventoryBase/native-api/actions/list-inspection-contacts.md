# List Inspection Contacts with InventoryBase

Retrieves all contacts for an inspection in InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/:inspectionId/contacts`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Inspection Contacts](https://developer.inventorybase.com/#list-contacts-for-an-inspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
