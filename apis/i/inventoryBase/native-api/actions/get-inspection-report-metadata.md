# Get Inspection Report Metadata with InventoryBase

Retrieves inspection report metadata from InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/:inspectionId/report/metadata`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Inspection Report Metadata](https://developer.inventorybase.com/#retrieve-inspection-metadata-meters-alarms-keys-manuals)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
