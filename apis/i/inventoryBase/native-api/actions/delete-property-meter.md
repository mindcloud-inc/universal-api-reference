# Delete Property Meter with InventoryBase

Deletes an existing property meter from InventoryBase.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/properties/:propertyId/meters/:meterId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Delete Property Meter](https://developer.inventorybase.com/#delete-a-meter)
