# List Action Reports by Inspection with InventoryBase

Retrieves action reports for an inspection in InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/:inspectionId/action-reports`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Action Reports by Inspection](https://developer.inventorybase.com/#list-action-reports-by-inspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
