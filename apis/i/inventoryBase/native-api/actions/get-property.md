# Get Property with InventoryBase

Retrieves a property record from InventoryBase by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/:propertyId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Property](https://developer.inventorybase.com/#get-a-single-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `number` | yes | The InventoryBase property ID. |
