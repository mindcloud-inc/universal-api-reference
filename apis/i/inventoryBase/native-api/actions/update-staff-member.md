# Update Staff Member with InventoryBase

Updates an existing staff member in InventoryBase.

## Endpoint

- **Method:** `PUT`
- **Path:** `/staff/:staffId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Update Staff Member](https://developer.inventorybase.com/#update-a-staff-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `staffId` | path | `number` | yes | The InventoryBase staff member ID. |
