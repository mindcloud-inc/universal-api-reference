# Update Property with InventoryBase

Updates an existing property record in InventoryBase.

## Endpoint

- **Method:** `PUT`
- **Path:** `/properties/:propertyId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Update Property](https://developer.inventorybase.com/#update-a-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `number` | yes | The InventoryBase property ID. |
