# Create Property Meter with InventoryBase

Creates a new property meter in InventoryBase.

## Endpoint

- **Method:** `POST`
- **Path:** `/properties/:propertyId/meters`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Create Property Meter](https://developer.inventorybase.com/#create-a-meter)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `number` | yes | The ID of the property |
