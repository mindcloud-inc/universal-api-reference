# Update Inspection with InventoryBase

Updates an existing inspection in InventoryBase.

## Endpoint

- **Method:** `PUT`
- **Path:** `/inspections/:inspectionId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Update Inspection](https://developer.inventorybase.com/#update-an-inspection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
