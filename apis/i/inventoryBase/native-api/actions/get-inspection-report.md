# Get Inspection Report with InventoryBase

Retrieves an inspection report from InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections/:inspectionId/report`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Inspection Report](https://developer.inventorybase.com/#retrieve-inspection-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inspectionId` | path | `number` | yes | The ID of the inspection |
