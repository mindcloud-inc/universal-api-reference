# Get Client with InventoryBase

Retrieves a client from InventoryBase by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Get Client](https://developer.inventorybase.com/#get-a-single-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `number` | yes | The InventoryBase client ID. |
