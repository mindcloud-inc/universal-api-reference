# Delete Webhook Listener with InventoryBase

Deletes an existing webhook listener from InventoryBase.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [Delete Webhook Listener](https://developer.inventorybase.com/#delete-a-webhook-listener)
