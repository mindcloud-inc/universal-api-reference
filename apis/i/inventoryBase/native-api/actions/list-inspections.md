# List Inspections with InventoryBase

Retrieves all inspection records from InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/inspections`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Inspections](https://developer.inventorybase.com/#list-all-inspections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
