# List Property Contacts with InventoryBase

Retrieves all contacts for a property in InventoryBase.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/:propertyId/contacts`
- **Base URL:** `https://api.inventorybase.com`
- **Official documentation:** [List Property Contacts](https://developer.inventorybase.com/#list-contacts-for-a-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `number` | yes | The InventoryBase property ID. |
