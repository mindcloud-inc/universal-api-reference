# List Card Templates with InstantCard

Retrieves available card templates from InstantCard.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/organizations/:organizationId/card_templates`
- **Base URL:** `https://core.instantcard.net`
- **Official documentation:** [List Card Templates](https://instantcard.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID from InstantCard. |
