# List Shipping Providers with InstantCard

Retrieves available shipping providers from InstantCard.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/organizations/:organizationId/shipping_providers`
- **Base URL:** `https://core.instantcard.net`
- **Official documentation:** [List Shipping Providers](https://instantcard.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID from InstantCard. |
