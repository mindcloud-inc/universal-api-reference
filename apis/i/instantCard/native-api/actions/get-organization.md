# Get Organization with InstantCard

Retrieves an organization from InstantCard by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/organizations/:organizationId`
- **Base URL:** `https://core.instantcard.net`
- **Official documentation:** [Get Organization](https://instantcard.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID from InstantCard. |
