# List Note Directories with Iris Dfir

## Endpoint

- **Method:** `GET`
- **Path:** `/case/notes/directories/filter`
- **Base URL:** `https://v200.beta.dfir-iris.org`
- **Official documentation:** [List Note Directories](https://docs.dfir-iris.org/2.4.20/_static/iris_api_reference_v2.0.4.html#tag/Case-notes/operation/case_notes_directories_filter_get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
