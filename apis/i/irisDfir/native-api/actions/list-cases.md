# List Cases with Iris Dfir

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/cases`
- **Base URL:** `https://v200.beta.dfir-iris.org`
- **Official documentation:** [List Cases](https://docs.dfir-iris.org/latest/_static/iris_api_reference_v2.1.0.html#tag/Cases/operation/api_v2_cases_get)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
