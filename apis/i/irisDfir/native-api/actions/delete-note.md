# Delete Note with Iris Dfir

## Endpoint

- **Method:** `POST`
- **Path:** `/case/notes/delete/:identifier`
- **Base URL:** `https://v200.beta.dfir-iris.org`
- **Official documentation:** [Delete Note](https://docs.dfir-iris.org/2.4.20/_static/iris_api_reference_v2.0.4.html#tag/Case-notes/operation/case_notes_delete_(note_id)_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `number` | yes | IRIS note identifier. |
