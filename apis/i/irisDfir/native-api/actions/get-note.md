# Get Note with Iris Dfir

## Endpoint

- **Method:** `GET`
- **Path:** `/case/notes/:identifier`
- **Base URL:** `https://v200.beta.dfir-iris.org`
- **Official documentation:** [Get Note](https://docs.dfir-iris.org/2.4.20/_static/iris_api_reference_v2.0.4.html#tag/Case-notes/operation/case_notes_(note_id)_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `number` | yes | IRIS note identifier. |
