# Render Image with Imejis.io

Creates a rendered image in Imejis.io by design ID.

## Endpoint

- **Method:** `POST`
- **Path:** `:design_id`
- **Base URL:** `https://render.imejis.io/v1`
- **Official documentation:** [Render Image](https://www.imejis.io/apis/curl)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `design_id` | path | `string` | yes | The Imejis.io template design identifier to render. |
