# Delete Background with Intelliprint

## Endpoint

- **Method:** `DELETE`
- **Path:** `/backgrounds/:id`
- **Base URL:** `https://api.intelliprint.net/v1`
- **Official documentation:** [Delete Background](https://docs.intelliprint.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intelliprint background ID. |
