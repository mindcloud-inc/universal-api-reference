# Delete Mailing List with Intelliprint

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mailing_lists/:id`
- **Base URL:** `https://api.intelliprint.net/v1`
- **Official documentation:** [Delete Mailing List](https://docs.intelliprint.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intelliprint mailing list ID. |
