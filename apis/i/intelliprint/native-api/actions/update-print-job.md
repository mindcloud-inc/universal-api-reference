# Update Print Job with Intelliprint

## Endpoint

- **Method:** `POST`
- **Path:** `/prints/:id`
- **Base URL:** `https://api.intelliprint.net/v1`
- **Official documentation:** [Update Print Job](https://docs.intelliprint.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intelliprint print job ID. |
