# List Mailing Lists with Intelliprint

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing_lists`
- **Base URL:** `https://api.intelliprint.net/v1`
- **Official documentation:** [List Mailing Lists](https://docs.intelliprint.net/api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
