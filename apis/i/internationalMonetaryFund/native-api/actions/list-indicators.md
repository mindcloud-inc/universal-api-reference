# List Indicators with International Monetary Fund

Retrieves available indicators from the IMF DataMapper API.

## Endpoint

- **Method:** `GET`
- **Path:** `/indicators`
- **Base URL:** `https://www.imf.org/external/datamapper/api/v1`
- **Official documentation:** [List Indicators](https://www.imf.org/external/datamapper/api/)
