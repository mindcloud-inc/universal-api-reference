# List Analytical Groups with International Monetary Fund

Retrieves defined analytical groups from the IMF DataMapper API.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://www.imf.org/external/datamapper/api/v1`
- **Official documentation:** [List Analytical Groups](https://www.imf.org/external/datamapper/api/)
