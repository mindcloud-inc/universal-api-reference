# List Regions with International Monetary Fund

Retrieves defined regions from the IMF DataMapper API.

## Endpoint

- **Method:** `GET`
- **Path:** `/regions`
- **Base URL:** `https://www.imf.org/external/datamapper/api/v1`
- **Official documentation:** [List Regions](https://www.imf.org/external/datamapper/api/)
