# Get Employee with Insightful

Retrieves an employee from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Get Employee](https://developers.insightful.io/#9658df96-d8e0-49c9-a5dc-685b555e5307)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The employee ID. |
