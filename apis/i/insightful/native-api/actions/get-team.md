# Get Team with Insightful

Retrieves a team from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Get Team](https://developers.insightful.io/#1c552e5f-fd75-4160-8262-5622c5f022d7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The team ID. |
