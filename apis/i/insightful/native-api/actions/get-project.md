# Get Project with Insightful

Retrieves a project from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Get Project](https://developers.insightful.io/#27bce92b-9d4b-41d2-90da-a6fe2574904e)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project ID. |
