# Delete Project with Insightful

Deletes a project from your Insightful account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Delete Project](https://developers.insightful.io/#79a6fd9e-9bae-4df9-b8af-1c1c09d2b822)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project ID to delete. |
