# List Projects with Insightful

Retrieves projects from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/project`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [List Projects](https://developers.insightful.io/#8b5efd55-f8ef-4a01-9239-fe2fad79c60c)
