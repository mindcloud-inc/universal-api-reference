# List Shared Settings with Insightful

Retrieves shared settings from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shared-settings`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [List Shared Settings](https://developers.insightful.io/#1d9a2170-11e8-49c8-b4a0-2c6c0be88b05)
