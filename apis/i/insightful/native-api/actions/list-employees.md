# List Employees with Insightful

Retrieves employees from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [List Employees](https://developers.insightful.io/#8d5b35bb-b93e-424b-8e65-83e88e671cf0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `select` | query | `string` | no | Comma-separated employee fields to return. |
