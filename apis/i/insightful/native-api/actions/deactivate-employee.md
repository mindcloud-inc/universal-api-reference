# Deactivate Employee with Insightful

Deactivates an employee in your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee/deactivate/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Deactivate Employee](https://developers.insightful.io/#00bba9e5-2acf-495f-91a2-4e2537fdc088)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The employee ID to deactivate. |
