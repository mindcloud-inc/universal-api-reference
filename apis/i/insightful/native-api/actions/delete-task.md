# Delete Task with Insightful

Deletes a task from your Insightful account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/task/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Delete Task](https://developers.insightful.io/#31b7d0ba-a56f-44fd-b152-4aa4f734b8fb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The task ID to delete. |
