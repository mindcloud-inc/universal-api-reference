# Get Shared Setting with Insightful

Retrieves a shared setting from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shared-settings/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Get Shared Setting](https://developers.insightful.io/#c0c6f6d0-0017-4114-a61a-56d46140a7ec)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The shared setting ID. |
