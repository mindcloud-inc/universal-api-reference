# Delete Team with Insightful

Deletes a team from your Insightful account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/team/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Delete Team](https://developers.insightful.io/#4fffc1b6-9f90-4558-b214-8118e525cd2d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The team ID to delete. |
