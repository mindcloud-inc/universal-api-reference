# Get Task with Insightful

Retrieves a task from your Insightful account.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:id`
- **Base URL:** `https://app.insightful.io/api/v1`
- **Official documentation:** [Get Task](https://developers.insightful.io/#2b7c9227-7292-4b62-86be-2119de8e811d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The task ID. |
