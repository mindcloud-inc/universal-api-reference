- **Path:** `/api/public/v2/webhooks`
- **Base URL:** `https://api.indyforms.com`
- **Official documentation:** [List Webhooks](https://api.indyforms.com/swagger/index.html?urls.primaryName=Indyforms+Public+Api+v2)
