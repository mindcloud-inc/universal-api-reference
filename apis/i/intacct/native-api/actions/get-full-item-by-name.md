# Get Full Item By Name with Sage Intacct

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.intacct.com/ia/xml/xmlgw.phtml`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemType` | body | `string` | yes |
| `itemName` | body | `string` | yes |
