# Read Bank Deposits with Sage Intacct

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.intacct.com/ia/xml/xmlgw.phtml`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object` | path | `string` | no |
| `fields` | path | `string` | no |
| `query` | path | `string` | no |
| `pageSize` | path | `number` | no |
