# Delete Folder with Instapaper

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1/folders/delete`
- **Base URL:** `https://www.instapaper.com`
- **Official documentation:** [Delete Folder](https://www.instapaper.com/developers/v1/full-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | body | `string` | yes | The folder to delete. |
