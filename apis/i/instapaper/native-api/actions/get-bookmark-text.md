# Get Bookmark Text with Instapaper

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1/bookmarks/get_text`
- **Base URL:** `https://www.instapaper.com`
- **Official documentation:** [Get Bookmark Text](https://www.instapaper.com/developers/v1/full-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookmark_id` | body | `string` | yes | The bookmark whose text view you want to retrieve. |
