# List Bookmark Highlights with Instapaper

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.1/bookmarks/:bookmarkId/highlights`
- **Base URL:** `https://www.instapaper.com`
- **Official documentation:** [List Bookmark Highlights](https://www.instapaper.com/developers/v1/full-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookmarkId` | path | `string` | yes | The bookmark whose highlights you want to list. |
