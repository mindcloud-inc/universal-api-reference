# Delete Highlight with Instapaper

## Endpoint

- **Method:** `POST`
- **Path:** `/api/1.1/highlights/:highlightId/delete`
- **Base URL:** `https://www.instapaper.com`
- **Official documentation:** [Delete Highlight](https://www.instapaper.com/developers/v1/full-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `highlightId` | path | `string` | yes | The highlight to delete. |
