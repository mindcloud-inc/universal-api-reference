# List Audience Brand Categories with Influencers.club

Retrieves audience brand categories from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/audience-brand-categories/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Audience Brand Categories](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_audience_brand_categories_list)
