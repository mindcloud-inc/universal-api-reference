# Retrieve Account Credits And Usage with Influencers.club

Retrieves account credits and usage details from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/accounts/credits/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [Retrieve Account Credits And Usage](https://docs.influencers.club/openapi/account-credits-and-usage/account_credits_usage_retrieve)
