# List Discovery Languages with Influencers.club

Retrieves supported discovery languages from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/languages/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Discovery Languages](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_languages_list)
