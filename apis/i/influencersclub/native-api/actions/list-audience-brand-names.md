# List Audience Brand Names with Influencers.club

Retrieves audience brand names from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/audience-brand-names/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Audience Brand Names](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_audience_brand_names_list)
