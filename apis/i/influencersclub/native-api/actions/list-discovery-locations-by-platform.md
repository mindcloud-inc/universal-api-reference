# List Discovery Locations By Platform with Influencers.club

Retrieves discovery locations for a platform from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/locations/:platform/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Discovery Locations By Platform](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_locations_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `platform` | path | `string` | yes | Platform slug (for example: instagram, tiktok, youtube). |
