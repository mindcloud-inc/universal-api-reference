# List Discovery Brands with Influencers.club

Retrieves discovery brand filters from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/brands/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Discovery Brands](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_brands_list)
