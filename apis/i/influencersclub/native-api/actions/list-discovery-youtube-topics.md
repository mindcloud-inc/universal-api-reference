# List Discovery YouTube Topics with Influencers.club

Retrieves YouTube discovery topics from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/yt-topics/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Discovery YouTube Topics](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_yt_topics_list)
