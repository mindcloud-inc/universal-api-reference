# List Audience Locations with Influencers.club

Retrieves audience locations from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/audience-locations/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Audience Locations](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_audience_locations_list)
