# List Discovery Games with Influencers.club

Retrieves Twitch game filters from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/games/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Discovery Games](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_games_list)
