# List Audience Interests with Influencers.club

Retrieves audience interests from Influencers.club.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/discovery/classifier/audience-interests/`
- **Base URL:** `https://api-dashboard.influencers.club`
- **Official documentation:** [List Audience Interests](https://docs.influencers.club/openapi/dictionary/public_v1_discovery_classifier_audience_interests_list)
