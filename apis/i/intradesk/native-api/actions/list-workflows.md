# List Workflows with Intradesk

Retrieves workflows from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/Workflows`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Workflows](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/Workflows/get_api_Workflows)
