# Create Tag with Intradesk

Creates a new tag in Intradesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/changes/v1/Tag`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Create Tag](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Tag/post_v1_Tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | NamedModel JSON object request body documented by Intradesk Changes API. |
