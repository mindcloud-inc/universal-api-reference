# List Priorities with Intradesk

Retrieves priorities from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/Priorities`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Priorities](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/Priorities/get_api_Priorities)
