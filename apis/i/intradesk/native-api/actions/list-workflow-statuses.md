# List Workflow Statuses with Intradesk

Retrieves workflow statuses from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/Workflows/{id}/statuses`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Workflow Statuses](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/Workflows/get_api_Workflows__id__statuses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workflow identifier from Intradesk TaskForm API path. |
