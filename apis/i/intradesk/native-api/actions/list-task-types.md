# List Task Types with Intradesk

Retrieves task types from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/TaskTypes`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Task Types](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/TaskTypes/get_api_TaskTypes)
