# List Tasks with Intradesk

Retrieves tasks from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasklist/odata/v3/Tasks`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Tasks](https://apigw.intradesk.ru/tasklist_docs/swagger/index.html#/Tasks/get_odata_v3_Tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
