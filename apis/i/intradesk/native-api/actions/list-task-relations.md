# List Task Relations with Intradesk

Retrieves task relations from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/TaskRelations/{taskNumber}`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Task Relations](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/TaskRelations/get_api_TaskRelations__taskNumber_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskNumber` | path | `string` | yes | Task number from Intradesk TaskForm API path. |
