# Get Knowledge Base Article with Intradesk

Retrieves a knowledge base article from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/knowledgebase/api/v1/Kb/{id}`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Get Knowledge Base Article](https://apigw.intradesk.ru/knowledgebase_docs/swagger/index.html#/Kb/get_api_v1_Kb__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Knowledge base article identifier from Intradesk Knowledgebase API path. |
