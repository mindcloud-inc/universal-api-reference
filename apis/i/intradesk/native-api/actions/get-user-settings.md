# Get User Settings with Intradesk

Retrieves user settings from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/api/v1/UserSettings`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Get User Settings](https://apigw.intradesk.ru/users_docs/swagger/index.html#/UserSettings/get_api_v1_UserSettings)
