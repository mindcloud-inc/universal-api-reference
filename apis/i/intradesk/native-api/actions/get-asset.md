# Get Asset with Intradesk

Retrieves an asset from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/api/v1/Assets/{id}`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Get Asset](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Assets/get_api_v1_Assets__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Asset identifier from Intradesk Settings API path. |
