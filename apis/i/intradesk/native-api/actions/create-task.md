# Create Task with Intradesk

Creates a new task in Intradesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/changes/v3/Tasks`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Create Task](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Tasks/post_v3_Tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | TaskFormCreateModel JSON object request body documented by Intradesk Changes API. |
