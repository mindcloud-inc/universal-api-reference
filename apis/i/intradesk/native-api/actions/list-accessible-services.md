# List Accessible Services with Intradesk

Retrieves accessible services from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/changes/api/Services`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Accessible Services](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Services/get_api_Services)
