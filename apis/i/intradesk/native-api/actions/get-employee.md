# Get Employee with Intradesk

Retrieves an employee from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/api/v1/Employees/{id}`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Get Employee](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Employees/get_api_v1_Employees__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Employee identifier from Intradesk Settings API path. |
