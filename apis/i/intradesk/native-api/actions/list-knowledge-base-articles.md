# List Knowledge Base Articles with Intradesk

Retrieves knowledge base articles from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/knowledgebase/odata/v1/Kb`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Knowledge Base Articles](https://apigw.intradesk.ru/knowledgebase_docs/swagger/index.html#/Kb/get_odata_v1_Kb)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
