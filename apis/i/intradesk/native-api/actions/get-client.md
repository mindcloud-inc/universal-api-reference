# Get Client with Intradesk

Retrieves a client from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/api/v1/clients/{id}`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Get Client](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Clients/get_api_v1_clients__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client identifier from Intradesk Settings API path. |
