# Archive Task with Intradesk

Archives an existing task in Intradesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/changes/v3/Tasks`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Archive Task](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Tasks/delete_v3_Tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | TaskFormDeleteModel JSON object request body documented by Intradesk Changes API. |
