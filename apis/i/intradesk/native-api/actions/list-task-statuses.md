# List Task Statuses with Intradesk

Retrieves task statuses from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/taskform/api/Statuses`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Task Statuses](https://apigw.intradesk.ru/taskform_docs/swagger/index.html#/Statuses/get_api_Statuses)
