# Update Task with Intradesk

Updates an existing task in Intradesk.

## Endpoint

- **Method:** `PUT`
- **Path:** `/changes/v3/Tasks`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Update Task](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Tasks/put_v3_Tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | TaskFormSubmitModel JSON object request body documented by Intradesk Changes API. |
