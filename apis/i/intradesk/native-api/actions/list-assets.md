# List Assets with Intradesk

Retrieves assets from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/odata/v1/Assets`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Assets](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Assets/get_odata_v1_Assets)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
