# Create Task Relation with Intradesk

Creates a task relation in Intradesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/changes/v1/TaskRelations`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [Create Task Relation](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/TaskRelations/post_v1_TaskRelations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | TaskRelationsSimpleRequestModel JSON object request body documented by Intradesk Changes API. |
