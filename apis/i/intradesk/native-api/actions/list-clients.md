# List Clients with Intradesk

Retrieves clients from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/odata/v2/Clients`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Clients](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Clients/get_odata_v2_Clients)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
