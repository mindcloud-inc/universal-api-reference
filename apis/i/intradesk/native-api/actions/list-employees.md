# List Employees with Intradesk

Retrieves employees from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/odata/v2/Employees`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Employees](https://apigw.intradesk.ru/settings_docs/swagger/index.html#/Employees/get_odata_v2_Employees)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
