# List Asset Services with Intradesk

Retrieves services with assets from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/changes/api/Services/WithAssetsOnly`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Asset Services](https://apigw.intradesk.ru/changes_docs/swagger/index.html#/Services/get_api_Services_WithAssetsOnly)
