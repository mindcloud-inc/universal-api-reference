# List Dashboard Tickets with Intradesk

Retrieves dashboard tickets from Intradesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasklist/odata/Dashboard`
- **Base URL:** `https://apigw.intradesk.ru`
- **Official documentation:** [List Dashboard Tickets](https://apigw.intradesk.ru/tasklist_docs/swagger/index.html#/Dashboard/get_odata_Dashboard)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
