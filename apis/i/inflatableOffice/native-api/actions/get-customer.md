# Get Customer with InflatableOffice

Retrieves a customer from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Get Customer](https://rental.software/support/knowledge-base/article/api-customers-retrieve-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `string` | no |
