# Create Payment with InflatableOffice

Creates a payment in InflatableOffice.

## Endpoint

- **Method:** `POST`
- **Path:** `/handle_payment`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Create Payment](https://rental.software/support/knowledge-base/article/api-payments-create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `leadid` | body | `string` | no |
| `manual` | body | `string` | no |
| `orderid` | body | `string` | no |
| `payamt` | body | `string` | no |
| `paystat` | body | `string` | no |
| `processor` | body | `string` | no |
| `reasoncode` | body | `string` | no |
| `surcharge` | body | `string` | no |
| `time` | body | `string` | no |
| `tip` | body | `string` | no |
| `type` | body | `string` | no |
