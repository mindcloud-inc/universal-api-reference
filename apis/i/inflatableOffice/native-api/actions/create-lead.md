# Create Lead with InflatableOffice

Creates a new lead in InflatableOffice.

## Endpoint

- **Method:** `POST`
- **Path:** `/leads`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Create Lead](https://rental.software/support/knowledge-base/article/api-leads)
