# Get Lead with InflatableOffice

Retrieves a lead from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Get Lead](https://rental.software/support/knowledge-base/article/api-leads-retrieve-lead)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `leadId` | path | `string` | no |
