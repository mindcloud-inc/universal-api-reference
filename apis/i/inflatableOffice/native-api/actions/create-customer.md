# Create Customer with InflatableOffice

Creates a new customer in InflatableOffice.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Create Customer](https://rental.software/support/knowledge-base/article/api-customers)
