# List Categories with InflatableOffice

Retrieves categories from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories_list`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [List Categories](https://rental.software/support/knowledge-base/article/api-categories-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
