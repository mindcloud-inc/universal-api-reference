# Create Task with InflatableOffice

Creates a new task in InflatableOffice.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Create Task](https://rental.software/support/knowledge-base/article/api-tasks-create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_assignedid` | body | `string` | no |
| `task_assignedto` | body | `string` | no |
| `task_badge` | body | `string` | no |
| `task_calendar` | body | `string` | no |
| `task_desc` | body | `string` | no |
| `task_email` | body | `string` | no |
| `task_flag` | body | `string` | no |
| `task_linkid` | body | `string` | no |
| `task_linkto` | body | `string` | no |
| `task_linktype` | body | `string` | no |
| `task_read` | body | `string` | no |
| `task_recurring` | body | `string` | no |
| `task_reminddate` | body | `string` | no |
| `task_status` | body | `string` | no |
