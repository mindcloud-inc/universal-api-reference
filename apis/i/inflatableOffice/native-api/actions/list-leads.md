# List Leads with InflatableOffice

Retrieves leads from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [List Leads](https://rental.software/support/knowledge-base/article/api-leads-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
