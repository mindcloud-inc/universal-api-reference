# List Customers with InflatableOffice

Retrieves customers from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [List Customers](https://rental.software/support/knowledge-base/article/api-customers-retrieve-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `_body` | query | `boolean` | no | When true, returns more customer details. |
