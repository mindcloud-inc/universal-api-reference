# List Detailed Customers with InflatableOffice

Retrieves customers with detailed fields from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [List Detailed Customers](https://rental.software/support/knowledge-base/article/api-customers-retrieve-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
