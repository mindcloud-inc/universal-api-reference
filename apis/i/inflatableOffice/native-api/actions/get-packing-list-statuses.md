# Get Packing List Statuses with InflatableOffice

Retrieves packing list statuses from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/packinglists`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Get Packing List Statuses](https://rental.software/support/knowledge-base/article/api-packing-lists-retrieve-details-or-update)
