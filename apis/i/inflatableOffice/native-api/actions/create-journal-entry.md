# Create Journal Entry with InflatableOffice

Creates a new journal entry in InflatableOffice.

## Endpoint

- **Method:** `POST`
- **Path:** `/journals`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Create Journal Entry](https://rental.software/support/knowledge-base/article/api-journal-create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `assignedtoid` | body | `string` | no |
| `crmstatus` | body | `string` | no |
| `cust` | body | `string` | no |
| `desc` | body | `string` | no |
| `lead` | body | `string` | no |
| `org` | body | `string` | no |
| `read` | body | `string` | no |
| `thisLeadOnly` | body | `string` | no |
