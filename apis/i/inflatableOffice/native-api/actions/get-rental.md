# Get Rental with InflatableOffice

Retrieves a rental from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/rentals/:rentalId`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Get Rental](https://rental.software/support/knowledge-base/article/api-rentals-retrieve-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rentalId` | path | `string` | yes | ID of the rental to retrieve. |
