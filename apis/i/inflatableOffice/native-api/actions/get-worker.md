# Get Worker with InflatableOffice

Retrieves a worker from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/workers/:workerId`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [Get Worker](https://rental.software/support/knowledge-base/article/api-workers-retrieve-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workerId` | path | `number` | yes | Worker ID to retrieve. |
