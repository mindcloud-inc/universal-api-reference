# List Rentals With Price Details with InflatableOffice

Retrieves rentals with price details from InflatableOffice.

## Endpoint

- **Method:** `GET`
- **Path:** `/rentals`
- **Base URL:** `https://rental.software/api6`
- **Official documentation:** [List Rentals With Price Details](https://rental.software/support/knowledge-base/article/api-rentals-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
