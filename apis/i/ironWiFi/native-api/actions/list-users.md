# List Users with IronWiFi

Retrieves users from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Users](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
