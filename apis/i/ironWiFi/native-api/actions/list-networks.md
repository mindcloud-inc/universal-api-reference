# List Networks with IronWiFi

Retrieves networks from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/networks`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Networks](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
