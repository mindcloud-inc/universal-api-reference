# List Vehicles with IronWiFi

Retrieves vehicles from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/vehicles`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Vehicles](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
