# List Organization Units with IronWiFi

Retrieves organization units from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgunits`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Organization Units](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
