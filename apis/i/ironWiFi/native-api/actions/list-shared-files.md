# List Shared Files with IronWiFi

Retrieves shared files from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/shared-files`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Shared Files](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
