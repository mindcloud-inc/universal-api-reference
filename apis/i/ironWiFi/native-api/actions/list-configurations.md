# List Configurations with IronWiFi

Retrieves configurations from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/configurations`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Configurations](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
