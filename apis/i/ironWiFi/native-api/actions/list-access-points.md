# List Access Points with IronWiFi

Retrieves access points from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/nodes`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Access Points](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
