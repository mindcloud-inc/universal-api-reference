# List Org Unit Group Mappings with IronWiFi

Retrieves organization unit group mappings from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/org-units-groups`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Org Unit Group Mappings](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
