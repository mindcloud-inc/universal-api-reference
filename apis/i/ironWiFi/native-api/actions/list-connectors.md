# List Connectors with IronWiFi

Retrieves connectors from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/connectors`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Connectors](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
