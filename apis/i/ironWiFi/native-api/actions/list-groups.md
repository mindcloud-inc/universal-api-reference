# List Groups with IronWiFi

Retrieves groups from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Groups](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
