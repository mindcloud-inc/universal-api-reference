# List Tariffs with IronWiFi

Retrieves tariffs from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/tariffs`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Tariffs](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
