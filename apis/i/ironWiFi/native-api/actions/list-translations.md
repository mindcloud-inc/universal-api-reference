# List Translations with IronWiFi

Retrieves translations from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/translations`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Translations](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
