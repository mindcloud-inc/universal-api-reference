# List Vouchers with IronWiFi

Retrieves vouchers from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/vouchers`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Vouchers](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
