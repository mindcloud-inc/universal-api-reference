# List Fleets with IronWiFi

Retrieves fleets from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/fleets`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Fleets](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
