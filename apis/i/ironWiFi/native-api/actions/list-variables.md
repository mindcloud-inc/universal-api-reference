# List Variables with IronWiFi

Retrieves variables from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/variables`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Variables](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
