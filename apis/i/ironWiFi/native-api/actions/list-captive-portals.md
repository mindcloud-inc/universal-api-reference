# List Captive Portals with IronWiFi

Retrieves captive portals from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/captive-portals`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Captive Portals](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
