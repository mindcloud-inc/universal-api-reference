# List Venues with IronWiFi

Retrieves venues from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/venues`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Venues](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
