# List Tariff Groups with IronWiFi

Retrieves tariff groups from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/tariff-groups`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Tariff Groups](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
