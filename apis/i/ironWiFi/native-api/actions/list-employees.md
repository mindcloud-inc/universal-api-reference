# List Employees with IronWiFi

Retrieves employees from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Employees](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
