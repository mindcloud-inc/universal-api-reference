# List Devices with IronWiFi

Retrieves devices from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Devices](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
