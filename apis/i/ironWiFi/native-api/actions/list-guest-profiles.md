# List Guest Profiles with IronWiFi

Retrieves guest profiles from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/guest-profiles`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Guest Profiles](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
