# List Guests with IronWiFi

Retrieves guests from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/guests`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Guests](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
