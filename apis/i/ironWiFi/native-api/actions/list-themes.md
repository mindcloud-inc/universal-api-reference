# List Themes with IronWiFi

Retrieves themes from IronWiFi.

## Endpoint

- **Method:** `GET`
- **Path:** `/themes`
- **Base URL:** `https://console.ironwifi.com/api`
- **Official documentation:** [List Themes](https://api.ironwifi.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
