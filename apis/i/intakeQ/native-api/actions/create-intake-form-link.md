# Create Intake Form Link with IntakeQ

Creates an intake form link in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/intakes/create`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Create Intake Form Link](https://support.intakeq.com/article/433-intakeq-partner-api)
