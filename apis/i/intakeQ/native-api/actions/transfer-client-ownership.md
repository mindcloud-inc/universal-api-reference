# Transfer Client Ownership with IntakeQ

Transfers client ownership in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/practitioners/{sourcePractitionerId}/transferClientOwnership/{destinationPractitionerId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Transfer Client Ownership](https://support.intakeq.com/article/433-intakeq-partner-api)
