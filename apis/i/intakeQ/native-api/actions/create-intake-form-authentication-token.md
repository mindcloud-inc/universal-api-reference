# Create Intake Form Authentication Token with IntakeQ

Creates an intake form token in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/intakes/{id}/token`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Create Intake Form Authentication Token](https://support.intakeq.com/article/433-intakeq-partner-api)
