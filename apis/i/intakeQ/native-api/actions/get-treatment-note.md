# Get Treatment Note with IntakeQ

Retrieves a treatment note from IntakeQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/{noteId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Get Treatment Note](https://support.intakeq.com/article/342-intakeq-notes-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The IntakeQ treatment note ID. |
