# Disable Practitioner with IntakeQ

Disables a practitioner in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/practitioners/{practitionerId}/disable`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Disable Practitioner](https://support.intakeq.com/article/433-intakeq-partner-api)
