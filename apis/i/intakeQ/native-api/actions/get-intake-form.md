# Get Intake Form with IntakeQ

Retrieves an intake form from IntakeQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/intakes/{intakeId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Get Intake Form](https://support.intakeq.com/article/31-intakeq-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `intakeId` | path | `string` | yes | The IntakeQ intake form ID. |
