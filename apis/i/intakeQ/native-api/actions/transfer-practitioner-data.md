# Transfer Practitioner Data with IntakeQ

Transfers practitioner data in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/practitioners/{sourcePractitionerId}/transferData/{destinationPractitionerId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Transfer Practitioner Data](https://support.intakeq.com/article/433-intakeq-partner-api)
