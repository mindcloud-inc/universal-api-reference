# Enable Practitioner with IntakeQ

Enables a practitioner in IntakeQ.

## Endpoint

- **Method:** `POST`
- **Path:** `/practitioners/{practitionerId}/enable`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Enable Practitioner](https://support.intakeq.com/article/433-intakeq-partner-api)
