# Get Appointment with IntakeQ

Retrieves an appointment from IntakeQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/{appointmentId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Get Appointment](https://support.intakeq.com/article/204-intakeq-appointments-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appointmentId` | path | `string` | yes | The IntakeQ appointment ID. |
