# Delete Practitioner with IntakeQ

Deletes a practitioner from IntakeQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/practitioners/{practitionerId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Delete Practitioner](https://support.intakeq.com/article/433-intakeq-partner-api)
