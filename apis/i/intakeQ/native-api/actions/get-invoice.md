# Get Invoice with IntakeQ

Retrieves an invoice from IntakeQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/{invoiceId}`
- **Base URL:** `https://intakeq.com/api/v1`
- **Official documentation:** [Get Invoice](https://support.intakeq.com/article/385-intakeq-invoice-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | path | `string` | yes | The IntakeQ invoice ID. |
