# Get Activity Pace Curve with Intervals.icu

Retrieves an activity pace curve from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/pace-curve:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Pace Curve](https://intervals.icu/api/v1/docs)
