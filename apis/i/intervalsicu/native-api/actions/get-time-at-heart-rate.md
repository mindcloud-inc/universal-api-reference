# Get Time at Heart Rate with Intervals.icu

Retrieves time at heart rate data from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/time-at-hr`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Time at Heart Rate](https://intervals.icu/api/v1/docs)
