# Get Activity with Intervals.icu

Retrieves an activity from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity](https://intervals.icu/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The activity identifier. |
