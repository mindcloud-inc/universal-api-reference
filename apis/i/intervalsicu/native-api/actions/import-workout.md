# Import Workout with Intervals.icu

Creates a workout in Intervals.icu from an imported file.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/athlete/:id/folders/:folderId/import-workout`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Import Workout](https://intervals.icu/api/v1/docs)
