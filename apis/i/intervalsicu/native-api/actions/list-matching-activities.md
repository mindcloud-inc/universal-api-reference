# List Matching Activities with Intervals.icu

Retrieves activities matching sport settings from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:athleteId/sport-settings/:id/matching-activities`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Matching Activities](https://intervals.icu/api/v1/docs)
