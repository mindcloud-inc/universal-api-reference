# Get Athlete Summary with Intervals.icu

Retrieves athlete summary information from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/athlete-summary:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Athlete Summary](https://intervals.icu/api/v1/docs)
