# Download Workouts ZIP with Intervals.icu

Downloads workout files from Intervals.icu as a ZIP.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/workouts.zip`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Download Workouts ZIP](https://intervals.icu/api/v1/docs)
