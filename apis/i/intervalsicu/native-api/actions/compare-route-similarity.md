# Compare Route Similarity with Intervals.icu

Compares route similarity in Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/routes/:route_id/similarity/:other_id`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Compare Route Similarity](https://intervals.icu/api/v1/docs)
