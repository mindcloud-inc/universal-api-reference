# Get Activity Power Spike Model with Intervals.icu

Retrieves an activity power spike model from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/power-spike-model`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Power Spike Model](https://intervals.icu/api/v1/docs)
