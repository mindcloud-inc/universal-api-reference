# Apply Sport Settings with Intervals.icu

Applies sport settings to activities in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:athleteId/sport-settings/:id/apply`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Apply Sport Settings](https://intervals.icu/api/v1/docs)
