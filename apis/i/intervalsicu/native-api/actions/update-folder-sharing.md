# Update Folder Sharing with Intervals.icu

Updates folder sharing in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/folders/:folderId/shared-with`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Update Folder Sharing](https://intervals.icu/api/v1/docs)
