# List Heart Rate Curves with Intervals.icu

Retrieves athlete heart rate curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/hr-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Heart Rate Curves](https://intervals.icu/api/v1/docs)
