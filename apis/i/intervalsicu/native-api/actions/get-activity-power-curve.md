# Get Activity Power Curve with Intervals.icu

Retrieves an activity power curve from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/power-curve:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Power Curve](https://intervals.icu/api/v1/docs)
