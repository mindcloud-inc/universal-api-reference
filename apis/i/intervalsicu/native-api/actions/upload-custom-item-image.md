# Upload Custom Item Image with Intervals.icu

Uploads a custom item image to Intervals.icu.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/athlete/:id/custom-item/:itemId/image`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Upload Custom Item Image](https://intervals.icu/api/v1/docs)
