# Get Athlete with Intervals.icu

Retrieves an athlete from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Athlete](https://intervals.icu/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intervals.icu athlete identifier, for example i555296. |
