# Download Activity GPX File with Intervals.icu

Downloads an activity GPX file from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/gpx-file`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Download Activity GPX File](https://intervals.icu/api/v1/docs)
