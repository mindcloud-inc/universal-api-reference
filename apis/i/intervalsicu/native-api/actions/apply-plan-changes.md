# Apply Plan Changes with Intervals.icu

Applies plan changes to an athlete calendar in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/apply-plan-changes`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Apply Plan Changes](https://intervals.icu/api/v1/docs)
