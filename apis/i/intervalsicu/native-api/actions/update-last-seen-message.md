# Update Last Seen Message with Intervals.icu

Updates a chat last seen message in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/chats/:id/messages/:msgId/seen`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Update Last Seen Message](https://intervals.icu/api/v1/docs)
