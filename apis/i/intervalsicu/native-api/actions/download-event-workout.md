# Download Event Workout with Intervals.icu

Downloads a planned workout from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/events/:eventId/download:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Download Event Workout](https://intervals.icu/api/v1/docs)
