# Get Activity Heart Rate Curve with Intervals.icu

Retrieves an activity heart rate curve from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/hr-curve:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Heart Rate Curve](https://intervals.icu/api/v1/docs)
