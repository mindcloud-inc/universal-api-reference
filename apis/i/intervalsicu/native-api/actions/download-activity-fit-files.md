# Download Activity FIT Files with Intervals.icu

Downloads activity FIT files from Intervals.icu as a ZIP.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/athlete/:id/download-fit-files`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Download Activity FIT Files](https://intervals.icu/api/v1/docs)
