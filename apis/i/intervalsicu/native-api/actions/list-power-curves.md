# List Power Curves with Intervals.icu

Retrieves athlete power curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/power-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Power Curves](https://intervals.icu/api/v1/docs)
