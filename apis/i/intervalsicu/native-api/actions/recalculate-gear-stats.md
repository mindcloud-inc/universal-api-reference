# Recalculate Gear Stats with Intervals.icu

Recalculates gear stats in Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/gear/:gearId/calc`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Recalculate Gear Stats](https://intervals.icu/api/v1/docs)
