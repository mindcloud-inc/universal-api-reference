# List Shared Folder Athletes with Intervals.icu

Retrieves athletes sharing a folder in Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/folders/:folderId/shared-with`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Shared Folder Athletes](https://intervals.icu/api/v1/docs)
