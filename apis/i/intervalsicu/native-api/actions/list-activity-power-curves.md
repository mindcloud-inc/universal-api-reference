# List Activity Power Curves with Intervals.icu

Retrieves activity power curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/power-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Activity Power Curves](https://intervals.icu/api/v1/docs)
