# Get Heart Rate Training Load Model with Intervals.icu

Retrieves a heart rate training load model from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/hr-load-model`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Heart Rate Training Load Model](https://intervals.icu/api/v1/docs)
