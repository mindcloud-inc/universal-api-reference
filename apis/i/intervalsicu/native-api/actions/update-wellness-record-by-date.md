# Update Wellness Record by Date with Intervals.icu

Updates a wellness record in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/wellness/:date`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Update Wellness Record by Date](https://intervals.icu/api/v1/docs)
