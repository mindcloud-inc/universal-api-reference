# Get Activity Pace Curves with Intervals.icu

Retrieves matching activity pace curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/activity-pace-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Pace Curves](https://intervals.icu/api/v1/docs)
