# Create Gear Reminder with Intervals.icu

Creates a gear reminder in Intervals.icu.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/athlete/:id/gear/:gearId/reminder`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Create Gear Reminder](https://intervals.icu/api/v1/docs)
