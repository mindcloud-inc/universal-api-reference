# Find Activities by Intervals with Intervals.icu

Finds activities in Intervals.icu by matching intervals.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/activities/interval-search`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Find Activities by Intervals](https://intervals.icu/api/v1/docs)
