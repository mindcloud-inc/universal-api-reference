# Update Plan Workouts with Intervals.icu

Updates plan workouts in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/folders/:folderId/workouts`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Update Plan Workouts](https://intervals.icu/api/v1/docs)
