# Update Gear Reminder with Intervals.icu

Updates a gear reminder in Intervals.icu.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/gear/:gearId/reminder/:reminderId`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Update Gear Reminder](https://intervals.icu/api/v1/docs)
