# List Fitness Model Events with Intervals.icu

Retrieves fitness model events from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/fitness-model-events`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Fitness Model Events](https://intervals.icu/api/v1/docs)
