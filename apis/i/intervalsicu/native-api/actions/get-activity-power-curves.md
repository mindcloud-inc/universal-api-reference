# Get Activity Power Curves with Intervals.icu

Retrieves matching activity power curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/activity-power-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Power Curves](https://intervals.icu/api/v1/docs)
