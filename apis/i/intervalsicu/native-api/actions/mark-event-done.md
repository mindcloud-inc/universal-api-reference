# Mark Event Done with Intervals.icu

Creates a manual activity from a planned event in Intervals.icu.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/athlete/:id/events/:eventId/mark-done`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Mark Event Done](https://intervals.icu/api/v1/docs)
