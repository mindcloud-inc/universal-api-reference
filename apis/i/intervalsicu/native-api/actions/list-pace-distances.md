# List Pace Distances with Intervals.icu

Retrieves pace distances from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:athleteId/sport-settings/:id/pace_distances`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [List Pace Distances](https://intervals.icu/api/v1/docs)
