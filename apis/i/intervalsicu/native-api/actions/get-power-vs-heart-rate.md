# Get Power vs Heart Rate with Intervals.icu

Retrieves power versus heart rate data from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/power-vs-hr:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Power vs Heart Rate](https://intervals.icu/api/v1/docs)
