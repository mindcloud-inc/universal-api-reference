# Search Full Activities with Intervals.icu

Finds full activities in Intervals.icu by name or tag.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/activities/search-full`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Search Full Activities](https://intervals.icu/api/v1/docs)
