# Bulk Delete Events with Intervals.icu

Deletes calendar events in Intervals.icu by ID or external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/athlete/:id/events/bulk-delete`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Bulk Delete Events](https://intervals.icu/api/v1/docs)
