# Get Activity Heart Rate Curves with Intervals.icu

Retrieves matching activity heart rate curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/activity-hr-curves:ext`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Activity Heart Rate Curves](https://intervals.icu/api/v1/docs)
