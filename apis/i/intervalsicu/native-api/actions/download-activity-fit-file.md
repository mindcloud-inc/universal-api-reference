# Download Activity FIT File with Intervals.icu

Downloads an activity FIT file from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/fit-file`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Download Activity FIT File](https://intervals.icu/api/v1/docs)
