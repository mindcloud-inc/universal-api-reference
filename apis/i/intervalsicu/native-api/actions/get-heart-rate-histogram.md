# Get Heart Rate Histogram with Intervals.icu

Retrieves a heart rate histogram from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/activity/:id/hr-histogram`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Heart Rate Histogram](https://intervals.icu/api/v1/docs)
