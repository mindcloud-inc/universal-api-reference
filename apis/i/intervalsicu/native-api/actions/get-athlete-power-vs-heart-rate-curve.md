# Get Athlete Power vs Heart Rate Curve with Intervals.icu

Retrieves power versus heart rate curves from Intervals.icu.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/athlete/:id/power-hr-curve`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Get Athlete Power vs Heart Rate Curve](https://intervals.icu/api/v1/docs)
