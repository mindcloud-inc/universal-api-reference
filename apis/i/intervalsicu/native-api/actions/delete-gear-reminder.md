# Delete Gear Reminder with Intervals.icu

Deletes a gear reminder from Intervals.icu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/athlete/:id/gear/:gearId/reminder/:reminderId`
- **Base URL:** `https://intervals.icu`
- **Official documentation:** [Delete Gear Reminder](https://intervals.icu/api/v1/docs)
