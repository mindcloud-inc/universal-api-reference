# Delete Location with Infoplus

Deletes an existing location from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/location/{locationId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Location](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
