# Update ASN with Infoplus

Updates an existing ASN in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/asn`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update ASN](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
