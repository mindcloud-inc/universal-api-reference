# Update Zone with Infoplus

Updates an existing zone in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/zone`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Zone](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
