# Create Inventory Storage Activity with Infoplus

Creates a new inventory storage activity in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/inventoryStorageActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Inventory Storage Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
