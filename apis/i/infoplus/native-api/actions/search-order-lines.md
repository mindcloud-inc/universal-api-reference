# Search Order Lines with Infoplus

Finds matching order lines in Infoplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/orderLine/search`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Search Order Lines](https://developer.infopluscommerce.com/api/reference/v3.0/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
