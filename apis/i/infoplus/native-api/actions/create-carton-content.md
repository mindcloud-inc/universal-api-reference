# Create Carton Content with Infoplus

Creates a new carton content in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/cartonContent`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Carton Content](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
