# Create Customer with Infoplus

Creates a new customer in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/customer`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Customer](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
