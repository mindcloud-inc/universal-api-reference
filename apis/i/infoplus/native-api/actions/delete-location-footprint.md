# Delete Location Footprint with Infoplus

Deletes an existing location footprint from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/locationFootprint/{locationFootprintId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Location Footprint](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
