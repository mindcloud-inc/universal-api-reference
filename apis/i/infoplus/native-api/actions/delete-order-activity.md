# Delete Order Activity with Infoplus

Deletes an existing order activity from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orderActivity/{orderActivityId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Order Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
