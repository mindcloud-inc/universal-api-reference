# Update Kit with Infoplus

Updates an existing kit in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/kit`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Kit](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
