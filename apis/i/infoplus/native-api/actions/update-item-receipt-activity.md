# Update Item Receipt Activity with Infoplus

Updates an existing item receipt activity in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/itemReceiptActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Item Receipt Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
