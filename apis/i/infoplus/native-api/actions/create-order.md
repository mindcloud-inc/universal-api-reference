# Create Order with Infoplus

Creates a new order in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/order`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Order](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
