# Create Fulfillment Plan with Infoplus

Creates a new fulfillment plan in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/fulfillmentPlan`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Fulfillment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
