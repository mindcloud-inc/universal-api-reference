# Update Item Receipt with Infoplus

Updates an existing item receipt in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/itemReceipt`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Item Receipt](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
