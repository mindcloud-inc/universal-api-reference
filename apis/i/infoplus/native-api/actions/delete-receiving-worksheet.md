# Delete Receiving Worksheet with Infoplus

Deletes an existing receiving worksheet from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/receivingWorksheet/{receivingWorksheetId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Receiving Worksheet](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
