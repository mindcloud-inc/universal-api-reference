# Create Building with Infoplus

Creates a new building in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/building`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Building](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
