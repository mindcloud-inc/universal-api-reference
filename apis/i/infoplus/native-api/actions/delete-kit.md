# Delete Kit with Infoplus

Deletes an existing kit from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/kit/{kitId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Kit](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
