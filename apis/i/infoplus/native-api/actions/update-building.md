# Update Building with Infoplus

Updates an existing building in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/building`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Building](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
