# Delete Carton with Infoplus

Deletes an existing carton from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/carton/{cartonId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Carton](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
