# Update Vendor with Infoplus

Updates an existing vendor in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/vendor`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Vendor](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
