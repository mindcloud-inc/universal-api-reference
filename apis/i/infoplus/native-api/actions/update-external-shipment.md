# Update External Shipment with Infoplus

Updates an existing external shipment in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/externalShipment`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update External Shipment](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
