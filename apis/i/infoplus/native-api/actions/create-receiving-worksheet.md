# Create Receiving Worksheet with Infoplus

Creates a new receiving worksheet in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/receivingWorksheet`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Receiving Worksheet](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
