# Delete Replenishment Plan with Infoplus

Deletes an existing replenishment plan from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/replenishmentPlan/{replenishmentPlanId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Replenishment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
