# Delete Customer with Infoplus

Deletes an existing customer from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customer/{customerId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Customer](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
