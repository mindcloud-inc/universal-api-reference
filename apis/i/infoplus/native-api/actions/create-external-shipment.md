# Create External Shipment with Infoplus

Creates a new external shipment in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/externalShipment`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create External Shipment](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
