# Delete ASN with Infoplus

Deletes an existing ASN from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/asn/{asnId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete ASN](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
