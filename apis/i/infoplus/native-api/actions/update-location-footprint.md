# Update Location Footprint with Infoplus

Updates an existing location footprint in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/locationFootprint`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Location Footprint](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
