# Create Carton Activity with Infoplus

Creates a new carton activity in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/cartonActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Carton Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
