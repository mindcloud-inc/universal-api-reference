# Search Return Shipments with Infoplus

Finds matching return shipments in Infoplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/returnShipment/search`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Search Return Shipments](https://developer.infopluscommerce.com/api/reference/v3.0/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
