# Delete Bill of Lading with Infoplus

Deletes an existing bill of lading from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/billOfLading/{billOfLadingId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Bill of Lading](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
