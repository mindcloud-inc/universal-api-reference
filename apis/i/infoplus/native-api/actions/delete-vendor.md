# Delete Vendor with Infoplus

Deletes an existing vendor from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vendor/{vendorId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Vendor](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
