# Update Order Activity with Infoplus

Updates an existing order activity in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orderActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Order Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
