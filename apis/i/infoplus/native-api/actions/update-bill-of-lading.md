# Update Bill of Lading with Infoplus

Updates an existing bill of lading in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/billOfLading`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Bill of Lading](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
