# Update Carton Activity with Infoplus

Updates an existing carton activity in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/cartonActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Carton Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
