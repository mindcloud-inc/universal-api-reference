# Delete Carton Activity with Infoplus

Deletes an existing carton activity from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cartonActivity/{cartonActivityId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Carton Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
