# Update Inventory Storage Activity with Infoplus

Updates an existing inventory storage activity in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/inventoryStorageActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Inventory Storage Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
