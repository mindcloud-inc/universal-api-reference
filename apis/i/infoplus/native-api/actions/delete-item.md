# Delete Item with Infoplus

Deletes an existing item from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/item/{itemId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Item](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
