# Update Order with Infoplus

Updates an existing order in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/order`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Order](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
