# Create Bill of Lading with Infoplus

Creates a new bill of lading in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/billOfLading`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Bill of Lading](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
