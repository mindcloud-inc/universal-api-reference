# Create Zone with Infoplus

Creates a new zone in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/zone`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Zone](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
