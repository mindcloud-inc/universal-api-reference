# Create Carton with Infoplus

Creates a new carton in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/carton`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Carton](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
