# Update Receiving Worksheet with Infoplus

Updates an existing receiving worksheet in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/receivingWorksheet`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Receiving Worksheet](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
