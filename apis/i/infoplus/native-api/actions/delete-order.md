# Delete Order with Infoplus

Deletes an existing order from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/order/{orderId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Order](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
