# Create Vendor with Infoplus

Creates a new vendor in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Vendor](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
