# Delete Item Receipt Activity with Infoplus

Deletes an existing item receipt activity from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/itemReceiptActivity/{itemReceiptActivityId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Item Receipt Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
