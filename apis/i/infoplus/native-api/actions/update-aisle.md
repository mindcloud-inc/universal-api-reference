# Update Aisle with Infoplus

Updates an existing aisle in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/aisle`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Aisle](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
