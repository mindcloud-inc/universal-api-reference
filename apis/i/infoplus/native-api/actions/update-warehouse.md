# Update Warehouse with Infoplus

Updates an existing warehouse in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/warehouse`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Warehouse](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
