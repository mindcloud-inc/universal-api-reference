# Delete Inventory Storage Activity with Infoplus

Deletes an existing inventory storage activity from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inventoryStorageActivity/{inventoryStorageActivityId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Inventory Storage Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
