# Delete Carton Content with Infoplus

Deletes an existing carton content from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cartonContent/{cartonContentId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Carton Content](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
