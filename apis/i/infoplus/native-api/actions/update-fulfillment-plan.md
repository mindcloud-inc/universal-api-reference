# Update Fulfillment Plan with Infoplus

Updates an existing fulfillment plan in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/fulfillmentPlan`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Fulfillment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
