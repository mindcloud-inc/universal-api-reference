# Create Location with Infoplus

Creates a new location in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/location`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Location](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
