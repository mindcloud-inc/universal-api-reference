# Create Order Source with Infoplus

Creates a new order source in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/orderSource`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Order Source](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
