# Create Item Receipt Activity with Infoplus

Creates a new item receipt activity in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/itemReceiptActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Item Receipt Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
