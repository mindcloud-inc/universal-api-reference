# Update Item with Infoplus

Updates an existing item in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/item`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Item](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
