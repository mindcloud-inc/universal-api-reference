# Search Receiving Processes with Infoplus

Finds matching receiving processes in Infoplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/receivingProcess/search`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Search Receiving Processes](https://developer.infopluscommerce.com/api/reference/v3.0/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
