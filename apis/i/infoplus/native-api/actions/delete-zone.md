# Delete Zone with Infoplus

Deletes an existing zone from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/zone/{zoneId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Zone](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
