# Update Location with Infoplus

Updates an existing location in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/location`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Location](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
