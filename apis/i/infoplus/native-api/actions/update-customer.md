# Update Customer with Infoplus

Updates an existing customer in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customer`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Customer](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
