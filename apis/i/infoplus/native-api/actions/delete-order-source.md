# Delete Order Source with Infoplus

Deletes an existing order source from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orderSource/{orderSourceId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Order Source](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
