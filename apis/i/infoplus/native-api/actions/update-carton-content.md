# Update Carton Content with Infoplus

Updates an existing carton content in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/cartonContent`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Carton Content](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
