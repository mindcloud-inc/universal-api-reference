# Delete External Shipment with Infoplus

Deletes an existing external shipment from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externalShipment/{externalShipmentId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete External Shipment](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
