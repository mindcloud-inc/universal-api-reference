# Search Parcel Invoices with Infoplus

Finds matching parcel invoices in Infoplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/parcelInvoice/search`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Search Parcel Invoices](https://developer.infopluscommerce.com/api/reference/v3.0/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
