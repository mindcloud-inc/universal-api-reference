# Update Carton with Infoplus

Updates an existing carton in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/carton`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Carton](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
