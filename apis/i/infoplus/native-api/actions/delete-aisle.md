# Delete Aisle with Infoplus

Deletes an existing aisle from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/aisle/{aisleId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Aisle](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
