# Create Order Activity with Infoplus

Creates a new order activity in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/orderActivity`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Order Activity](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
