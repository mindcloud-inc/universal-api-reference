# Update Order Source with Infoplus

Updates an existing order source in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orderSource`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Order Source](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
