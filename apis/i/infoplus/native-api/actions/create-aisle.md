# Create Aisle with Infoplus

Creates a new aisle in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/aisle`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Aisle](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
