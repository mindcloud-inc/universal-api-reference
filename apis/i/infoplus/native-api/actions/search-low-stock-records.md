# Search Low Stock Records with Infoplus

Finds matching low stock records in Infoplus.

## Endpoint

- **Method:** `GET`
- **Path:** `/lowStock/search`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Search Low Stock Records](https://developer.infopluscommerce.com/api/reference/v3.0/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
