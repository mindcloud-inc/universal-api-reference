# Update Replenishment Plan with Infoplus

Updates an existing replenishment plan in Infoplus.

## Endpoint

- **Method:** `PUT`
- **Path:** `/replenishmentPlan`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Update Replenishment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
