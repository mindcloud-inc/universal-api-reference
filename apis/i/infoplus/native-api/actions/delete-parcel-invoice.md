# Delete Parcel Invoice with Infoplus

Deletes an existing parcel invoice from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/parcelInvoice/{parcelInvoiceId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Parcel Invoice](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
