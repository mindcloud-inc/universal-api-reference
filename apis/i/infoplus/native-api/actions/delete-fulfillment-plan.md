# Delete Fulfillment Plan with Infoplus

Deletes an existing fulfillment plan from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fulfillmentPlan/{fulfillmentPlanId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Fulfillment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
