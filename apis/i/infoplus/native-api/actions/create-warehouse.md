# Create Warehouse with Infoplus

Creates a new warehouse in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/warehouse`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Warehouse](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
