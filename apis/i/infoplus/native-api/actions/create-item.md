# Create Item with Infoplus

Creates a new item in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/item`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Item](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
