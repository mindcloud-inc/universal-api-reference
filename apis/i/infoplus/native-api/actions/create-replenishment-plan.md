# Create Replenishment Plan with Infoplus

Creates a new replenishment plan in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/replenishmentPlan`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Replenishment Plan](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
