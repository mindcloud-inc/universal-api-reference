# Create Location Footprint with Infoplus

Creates a new location footprint in Infoplus.

## Endpoint

- **Method:** `POST`
- **Path:** `/locationFootprint`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Create Location Footprint](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
