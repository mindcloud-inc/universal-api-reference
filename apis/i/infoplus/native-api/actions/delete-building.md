# Delete Building with Infoplus

Deletes an existing building from Infoplus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/building/{buildingId}`
- **Base URL:** `https://luxomo.infopluswms.com/infoplus-wms/api/v3.0`
- **Official documentation:** [Delete Building](https://developer.infopluscommerce.com/api/reference/v3.0/swagger.json)
