# List Template Elements and Their Basic Properties with Imagior

Retrieves basic template element properties from Imagior.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{templateId}/elements/basic`
- **Base URL:** `https://api.imagior.com`
- **Official documentation:** [List Template Elements and Their Basic Properties](https://docs.imagior.com/api-reference/retrieve-basic-template-elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The ID of the design template. |
