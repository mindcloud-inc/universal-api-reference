# List Template Elements with Imagior

Retrieves template elements from Imagior.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{templateId}/elements`
- **Base URL:** `https://api.imagior.com`
- **Official documentation:** [List Template Elements](https://docs.imagior.com/api-reference/retrieve-template-elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The ID of the design template. |
