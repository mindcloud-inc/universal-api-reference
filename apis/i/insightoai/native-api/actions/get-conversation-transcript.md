# Get Transcript Of A Conversation with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/conversation/:conversation_id/transcript`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get Transcript Of A Conversation](https://docs.insighto.ai/api-reference/conversation/get-transcript-of-a-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | The UUID id of the conversation. |
