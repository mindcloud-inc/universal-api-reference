# Get Contact By Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:contact_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get Contact By Id](https://docs.insighto.ai/api-reference/contact/get-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The UUID id of the contact. |
