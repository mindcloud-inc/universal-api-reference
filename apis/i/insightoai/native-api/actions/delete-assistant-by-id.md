# Delete Assistant By Id with Insighto.ai

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assistant/:assistant_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Delete Assistant By Id](https://docs.insighto.ai/api-reference/assistant/delete-assistant-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assistant_id` | path | `string` | yes | The UUID id of the assistant. |
