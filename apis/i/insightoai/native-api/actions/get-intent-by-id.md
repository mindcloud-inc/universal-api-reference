# Get Intent By Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/intent/:intent_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get Intent By Id](https://docs.insighto.ai/api-reference/intent/get-intent-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `intent_id` | path | `string` | yes | The UUID id of the intent. |
