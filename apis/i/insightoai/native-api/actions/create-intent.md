# Create Intent with Insighto.ai

## Endpoint

- **Method:** `POST`
- **Path:** `/intent`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Create Intent](https://docs.insighto.ai/api-reference/intent/create-intent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Intent name. |
