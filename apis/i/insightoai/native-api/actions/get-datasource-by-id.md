# Get Datasource By Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/datasource/:datasource_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get Datasource By Id](https://docs.insighto.ai/api-reference/data-source/get-datasource-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasource_id` | path | `string` | yes | The UUID id of the datasource. |
