# List Data Source Files For Data Source Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/datasource/:datasource_id/data_source_files`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [List Data Source Files For Data Source Id](https://docs.insighto.ai/api-reference/data-source/get-list-of-data-source-files-for-data-source-id)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasource_id` | path | `string` | yes | The UUID id of the datasource. |
