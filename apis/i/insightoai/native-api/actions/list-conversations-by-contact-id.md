# Get List Of Conversations By Contact Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/conversation/by-contact/:contact_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get List Of Conversations By Contact Id](https://docs.insighto.ai/api-reference/conversation/get-list-of-conversations-by-contact-id)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The UUID id of the contact. |
