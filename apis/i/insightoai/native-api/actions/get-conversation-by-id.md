# Get Conversation By Id with Insighto.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/conversation/:conversation_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Get Conversation By Id](https://docs.insighto.ai/api-reference/conversation/get-conversation-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | The UUID id of the conversation. |
