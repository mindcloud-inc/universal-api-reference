# Delete Widget By Id with Insighto.ai

## Endpoint

- **Method:** `DELETE`
- **Path:** `/widget/:widget_id`
- **Base URL:** `https://api.insighto.ai/api/v1`
- **Official documentation:** [Delete Widget By Id](https://docs.insighto.ai/api-reference/widget/delete-widget-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widget_id` | path | `string` | yes | The UUID id of the widget. |
