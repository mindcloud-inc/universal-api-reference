# Get Company And Address Match Similarity Key with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getcompanyandaddressmatch`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Company And Address Match Similarity Key](https://www.interzoid.com/apis/company-and-address-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | query | `string` | yes | Company name to encode. |
| `address` | query | `string` | yes | Street address to encode. |
