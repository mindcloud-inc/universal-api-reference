# Compare Full Names with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getfullnamematchscore`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Compare Full Names](https://www.interzoid.com/apis/individual-match-score)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fullname1` | query | `string` | yes | First full name. |
| `fullname2` | query | `string` | yes | Second full name. |
