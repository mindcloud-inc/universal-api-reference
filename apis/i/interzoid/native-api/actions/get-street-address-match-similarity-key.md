# Get Street Address Match Similarity Key with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getaddressmatchadvanced`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Street Address Match Similarity Key](https://www.interzoid.com/apis/street-address-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | query | `string` | yes | Street address to encode. |
| `algorithm` | query | `string` | yes | Matching algorithm to use. |
