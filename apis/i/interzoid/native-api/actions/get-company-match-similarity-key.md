# Get Company Match Similarity Key with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getcompanymatchadvanced`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Company Match Similarity Key](https://www.interzoid.com/apis/company-name-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | query | `string` | yes | Company name to encode. |
| `algorithm` | query | `string` | yes | Matching algorithm to use. |
