# Get Full Name Match Similarity Key with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getfullnamematch`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Full Name Match Similarity Key](https://www.interzoid.com/apis/individual-name-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fullname` | query | `string` | yes | Full name to encode. |
