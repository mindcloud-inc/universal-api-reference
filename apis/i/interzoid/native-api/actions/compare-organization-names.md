# Compare Organization Names with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getorgmatchscore`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Compare Organization Names](https://www.interzoid.com/apis/organization-match-score)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org1` | query | `string` | yes | First organization name. |
| `org2` | query | `string` | yes | Second organization name. |
