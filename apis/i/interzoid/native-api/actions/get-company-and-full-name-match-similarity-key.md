# Get Company And Full Name Match Similarity Key with Interzoid

- **Method:** `GET`
- **Path:** `/getcompanyandfullnamematch`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Company And Full Name Match Similarity Key](https://www.interzoid.com/apis/company-and-fullname-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | query | `string` | yes | Company name to encode. |
