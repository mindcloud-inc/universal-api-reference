# Get Full Name And Address Match Similarity Key with Interzoid

## Endpoint

- **Method:** `GET`
- **Path:** `/getaddressandfullnamematch`
- **Base URL:** `https://api.interzoid.com`
- **Official documentation:** [Get Full Name And Address Match Similarity Key](https://www.interzoid.com/apis/address-and-fullname-matching)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | query | `string` | yes | Street address to encode. |
| `fullname` | query | `string` | yes | Full name to encode. |
