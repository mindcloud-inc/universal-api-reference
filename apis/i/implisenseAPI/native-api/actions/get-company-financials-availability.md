# Get Company Financials Availability with Implisense

Retrieves available financial years from Implisense API.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id/financials/exists`
- **Base URL:** `https://german-company-data.p.rapidapi.com`
- **Official documentation:** [Get Company Financials Availability](https://docs.implisense.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Implisense company identifier, for example DEVFCLQFW054. |
