# Get Suggestions with Implisense

Finds suggestions in Implisense API by prefix.

## Endpoint

- **Method:** `GET`
- **Path:** `/suggest/:prefix`
- **Base URL:** `https://german-company-data.p.rapidapi.com`
- **Official documentation:** [Get Suggestions](https://docs.implisense.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prefix` | path | `string` | yes | Text prefix to use for Implisense suggestions. |
