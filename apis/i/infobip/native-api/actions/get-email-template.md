# Get Email Template with Infobip

## Endpoint

- **Method:** `GET`
- **Path:** `/email/1/templates/{templateId}`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Get Email Template](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `number` | yes | Unique identifier (ID) of the email template. |
