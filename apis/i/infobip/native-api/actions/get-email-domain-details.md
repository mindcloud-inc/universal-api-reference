# Get Email Domain Details with Infobip

## Endpoint

- **Method:** `GET`
- **Path:** `/email/1/domains/{domainName}`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Get Email Domain Details](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | Domain for which the details need to be viewed. |
