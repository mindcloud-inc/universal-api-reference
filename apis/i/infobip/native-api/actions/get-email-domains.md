# Get Email Domains with Infobip

## Endpoint

- **Method:** `GET`
- **Path:** `/email/1/domains`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Get Email Domains](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `size` | query | `number` | no | Maximum number of domains to be viewed per page. Default value is 10 with a maximum of 20 records per page. |
| `page` | query | `number` | no | Page number you want to see. Default is 0. |
