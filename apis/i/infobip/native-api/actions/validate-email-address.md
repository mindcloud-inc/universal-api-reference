# Validate Email Address with Infobip

## Endpoint

- **Method:** `POST`
- **Path:** `/email/2/validation`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Validate Email Address](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `to` | body | `string` | yes | The email address to be validated. |
