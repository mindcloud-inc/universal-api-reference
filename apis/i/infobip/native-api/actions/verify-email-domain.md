# Verify Email Domain with Infobip

## Endpoint

- **Method:** `POST`
- **Path:** `/email/1/domains/{domainName}/verify`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Verify Email Domain](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | Name of the domain that has to be verified. |
