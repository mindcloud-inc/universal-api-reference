# Get Scheduled Email Statuses with Infobip

## Endpoint

- **Method:** `GET`
- **Path:** `/email/1/bulks/status`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Get Scheduled Email Statuses](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bulkId` | query | `string` | yes | The ID that uniquely identifies the sent bulk. |
