# Delete Email Domain with Infobip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email/1/domains/{domainName}`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Delete Email Domain](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainName` | path | `string` | yes | Domain name which needs to be deleted. |
