# Get Email Templates with Infobip

## Endpoint

- **Method:** `GET`
- **Path:** `/email/1/templates`
- **Base URL:** `https://rkpzwe.api.infobip.com`
- **Official documentation:** [Get Email Templates](https://www.infobip.com/docs/api/channels/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Identifies a specific page number from which to retrieve the email template details. |
| `size` | query | `number` | no | Identifies the maximum number of email templates returned in the list. |
