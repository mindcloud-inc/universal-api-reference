# Get Bot Itemized Summary Of Reply with Instabot

Retrieves an itemized bot reply summary from Instabot.

## Endpoint

- **Method:** `GET`
- **Path:** `/instabot/bots/:id/itemizedSummaryOfReply`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [Get Bot Itemized Summary Of Reply](https://docs.instabot.io/reference/get_instabot-bots-id-itemizedsummaryofreply)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Instabot bot identifier. |
