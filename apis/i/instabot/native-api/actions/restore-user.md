# Restore User with Instabot

Restores a deleted user in Instabot.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:id`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [Restore User](https://docs.instabot.io/docs/serverapi-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Instabot user object identifier. |
