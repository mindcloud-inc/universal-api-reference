# Get Display Settings with Instabot

Retrieves display settings from Instabot.

## Endpoint

- **Method:** `GET`
- **Path:** `/instabot/displaySettings`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [Get Display Settings](https://docs.instabot.io/reference/get_instabot-displaysettings)
