# Delete User with Instabot

Deletes an existing user from Instabot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [Delete User](https://docs.instabot.io/docs/serverapi-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Instabot user object identifier. |
