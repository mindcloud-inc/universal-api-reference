# List Bots with Instabot

Retrieves bots from Instabot.

## Endpoint

- **Method:** `GET`
- **Path:** `/instabot/admin/bots`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [List Bots](https://docs.instabot.io/reference/get_instabot-admin-bots)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchText` | query | `string` | no | Search text applied to bot results. |
