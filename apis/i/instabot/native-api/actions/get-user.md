# Get User with Instabot

Retrieves a user from Instabot.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [Get User](https://docs.instabot.io/docs/serverapi-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Instabot user object identifier. |
