# List Conversations with Instabot

Retrieves conversations from Instabot.

## Endpoint

- **Method:** `GET`
- **Path:** `/instabot/conversations`
- **Base URL:** `https://api.instabot.io/v1`
- **Official documentation:** [List Conversations](https://docs.instabot.io/reference/get_instabot-conversations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Conversation platform type. |
