# Get Pre-Verification Setting with IdentityCheck

## Endpoint

- **Method:** `GET`
- **Path:** `/pre-verification-settings/{id}`
- **Base URL:** `https://identity.stackgo.io/api`
- **Official documentation:** [Get Pre-Verification Setting](https://stackgo.notion.site/How-to-Generate-an-IdentityCheck-API-Key-38a12805b43249a480a96b346c491740)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | IdentityCheck pre-verification setting identifier. |
