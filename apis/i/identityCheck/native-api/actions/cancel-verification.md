# Cancel Verification with IdentityCheck

## Endpoint

- **Method:** `DELETE`
- **Path:** `/verification/cancel/{id}`
- **Base URL:** `https://identity.stackgo.io/api`
- **Official documentation:** [Cancel Verification](https://stackgo.notion.site/How-to-Generate-an-IdentityCheck-API-Key-38a12805b43249a480a96b346c491740)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | IdentityCheck verification identifier. |
