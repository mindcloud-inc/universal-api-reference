# Submit Public Onboarding Form with IdentityCheck

## Endpoint

- **Method:** `POST`
- **Path:** `/public/onboarding/{id}`
- **Base URL:** `https://identity.stackgo.io/api`
- **Official documentation:** [Submit Public Onboarding Form](https://stackgo.notion.site/How-to-Generate-an-IdentityCheck-API-Key-38a12805b43249a480a96b346c491740)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Public onboarding identifier. |
