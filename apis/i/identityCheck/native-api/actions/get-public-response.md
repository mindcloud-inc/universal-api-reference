# Get Public Response with IdentityCheck

## Endpoint

- **Method:** `GET`
- **Path:** `/public/response/{id}`
- **Base URL:** `https://identity.stackgo.io/api`
- **Official documentation:** [Get Public Response](https://stackgo.notion.site/How-to-Generate-an-IdentityCheck-API-Key-38a12805b43249a480a96b346c491740)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Public response identifier. |
