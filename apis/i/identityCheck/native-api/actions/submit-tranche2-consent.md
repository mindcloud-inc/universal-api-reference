# Submit Tranche 2 Consent with IdentityCheck

## Endpoint

- **Method:** `POST`
- **Path:** `/public/verification/{id}/tranche2/consent`
- **Base URL:** `https://identity.stackgo.io/api`
- **Official documentation:** [Submit Tranche 2 Consent](https://stackgo.notion.site/How-to-Generate-an-IdentityCheck-API-Key-38a12805b43249a480a96b346c491740)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Public verification identifier. |
