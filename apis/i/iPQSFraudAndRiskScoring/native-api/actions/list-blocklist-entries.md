# List Blocklist Entries with IPQS Fraud and Risk Scoring

Retrieves current blocklist entries from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/blocklist/list/{apiKey}`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Blocklist Entries](https://www.ipqualityscore.com/documentation/allowlist-api/blocklist-listing-entries)
