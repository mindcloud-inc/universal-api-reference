# List Allowlist Entries with IPQS Fraud and Risk Scoring

Retrieves current allowlist entries from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/allowlist/list/{apiKey}`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Allowlist Entries](https://www.ipqualityscore.com/documentation/allowlist-api/allowlist-listing-entries)
