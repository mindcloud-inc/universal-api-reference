# Get Login History with IPQS Fraud and Risk Scoring

Retrieves account login history from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/loginhistory/{apiKey}/`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [Get Login History](https://www.ipqualityscore.com/documentation/account-management/login-history)
