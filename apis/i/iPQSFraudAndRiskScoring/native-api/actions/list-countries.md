# List Countries with IPQS Fraud and Risk Scoring

Retrieves country codes and names from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/country/list`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Countries](https://www.ipqualityscore.com/documentation/countries/overview)
