# List Device Tracker Requests with IPQS Fraud and Risk Scoring

Retrieves previous device fingerprint requests from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/{apiKey}/list`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Device Tracker Requests](https://www.ipqualityscore.com/documentation/request-list/overview)
