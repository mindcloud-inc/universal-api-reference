# Get Account Credit Usage with IPQS Fraud and Risk Scoring

Retrieves account credit usage details from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/{apiKey}`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [Get Account Credit Usage](https://www.ipqualityscore.com/documentation/account-management/usage)
