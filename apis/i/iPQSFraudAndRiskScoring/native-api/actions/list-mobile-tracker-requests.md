# List Mobile Tracker Requests with IPQS Fraud and Risk Scoring

Retrieves previous mobile tracker requests from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/{apiKey}/list`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Mobile Tracker Requests](https://www.ipqualityscore.com/documentation/request-list/overview)
