# List Email Requests with IPQS Fraud and Risk Scoring

Retrieves previous email validation requests from IPQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/{apiKey}/list`
- **Base URL:** `https://www.ipqualityscore.com/api/json`
- **Official documentation:** [List Email Requests](https://www.ipqualityscore.com/documentation/request-list/overview)
