# List Inserts with IgnitePost

Retrieves available gift card inserts from IgnitePost.

## Endpoint

- **Method:** `GET`
- **Path:** `/inserts`
- **Base URL:** `https://dashboard.ignitepost.com/api/v1`
- **Official documentation:** [List Inserts](https://dashboard.ignitepost.com/api-documentation#list-inserts)
