# Retrieve Order with IgnitePost

Retrieves an existing order from IgnitePost.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://dashboard.ignitepost.com/api/v1`
- **Official documentation:** [Retrieve Order](https://dashboard.ignitepost.com/api-documentation#retrieve-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The IgnitePOST order ID to retrieve. |
