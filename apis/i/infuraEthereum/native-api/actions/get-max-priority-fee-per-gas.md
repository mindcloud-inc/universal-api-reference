# Get Max Priority Fee Per Gas with Infura Ethereum

Retrieves the max priority fee per gas from Infura Ethereum.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/:apiKey`
- **Base URL:** `https://mainnet.infura.io`
- **Official documentation:** [Get Max Priority Fee Per Gas](https://docs.metamask.io/services/reference/ethereum/json-rpc-methods/eth_maxpriorityfeepergas/)
