# Get Blob Base Fee with Infura Ethereum

Retrieves the blob base fee from Infura Ethereum.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/:apiKey`
- **Base URL:** `https://mainnet.infura.io`
- **Official documentation:** [Get Blob Base Fee](https://docs.metamask.io/services/reference/ethereum/json-rpc-methods/eth_blobbasefee/)
