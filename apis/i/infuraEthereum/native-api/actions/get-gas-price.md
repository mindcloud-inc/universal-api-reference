# Get Gas Price with Infura Ethereum

Retrieves the gas price from Infura Ethereum.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/:apiKey`
- **Base URL:** `https://mainnet.infura.io`
- **Official documentation:** [Get Gas Price](https://docs.metamask.io/services/reference/ethereum/json-rpc-methods/eth_gasprice/)
