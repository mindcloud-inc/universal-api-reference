# Get Chain ID with Infura Ethereum

Retrieves the chain ID from Infura Ethereum.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/:apiKey`
- **Base URL:** `https://mainnet.infura.io`
- **Official documentation:** [Get Chain ID](https://docs.metamask.io/services/reference/ethereum/json-rpc-methods/eth_chainid/)
