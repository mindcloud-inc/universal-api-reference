# Get Latest Block Number with Infura Ethereum

Retrieves the latest block number from Infura Ethereum.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/:apiKey`
- **Base URL:** `https://mainnet.infura.io`
- **Official documentation:** [Get Latest Block Number](https://docs.metamask.io/services/reference/ethereum/json-rpc-methods/eth_blocknumber/)
