# List Locations with inFlow Inventory

Retrieves location records from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Locations](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
