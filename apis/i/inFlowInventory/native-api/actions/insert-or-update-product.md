# Insert or Update Product with inFlow Inventory

Inserts or updates a product in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/products`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Product](https://cloudapi.inflowinventory.com/docs/index.html)
