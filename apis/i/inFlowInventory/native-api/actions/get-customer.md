# Get Customer with inFlow Inventory

Retrieves an existing customer from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Get Customer](https://cloudapi.inflowinventory.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | The inFlow customer ID. |
