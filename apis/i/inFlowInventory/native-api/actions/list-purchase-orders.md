# List Purchase Orders with inFlow Inventory

Retrieves purchase orders from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchase-orders`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Purchase Orders](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
