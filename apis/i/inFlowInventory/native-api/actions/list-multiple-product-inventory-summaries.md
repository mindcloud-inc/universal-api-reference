# List Multiple Product Inventory Summaries with inFlow Inventory

Retrieves multiple product inventory summaries from inFlow Inventory.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/summary`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Multiple Product Inventory Summaries](https://cloudapi.inflowinventory.com/docs/index.html)
