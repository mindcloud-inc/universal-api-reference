# List Products with inFlow Inventory

Retrieves product records from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Products](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
