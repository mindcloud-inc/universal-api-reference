# List Stock Adjustments with inFlow Inventory

Retrieves stock adjustments from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock-adjustments`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Stock Adjustments](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
