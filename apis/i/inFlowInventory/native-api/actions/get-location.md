# Get Location with inFlow Inventory

Retrieves an existing location from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/:locationId`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Get Location](https://cloudapi.inflowinventory.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `string` | yes | The inFlow location ID. |
