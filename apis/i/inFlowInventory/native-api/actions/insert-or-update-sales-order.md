# Insert or Update Sales Order with inFlow Inventory

Inserts or updates a sales order in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sales-orders`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Sales Order](https://cloudapi.inflowinventory.com/docs/index.html)
