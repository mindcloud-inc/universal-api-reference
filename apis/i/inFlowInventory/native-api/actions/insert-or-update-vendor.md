# Insert or Update Vendor with inFlow Inventory

Inserts or updates a vendor in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/vendors`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Vendor](https://cloudapi.inflowinventory.com/docs/index.html)
