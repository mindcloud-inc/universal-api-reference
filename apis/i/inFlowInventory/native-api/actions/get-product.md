# Get Product with inFlow Inventory

Retrieves an existing product from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:productId`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Get Product](https://cloudapi.inflowinventory.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The inFlow product ID. |
