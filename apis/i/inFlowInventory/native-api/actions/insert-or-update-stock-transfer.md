# Insert or Update Stock Transfer with inFlow Inventory

Inserts or updates a stock transfer in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/stock-transfers`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Stock Transfer](https://cloudapi.inflowinventory.com/docs/index.html)
