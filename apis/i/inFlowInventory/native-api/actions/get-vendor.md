# Get Vendor with inFlow Inventory

Retrieves an existing vendor from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendors/:vendorId`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Get Vendor](https://cloudapi.inflowinventory.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendorId` | path | `string` | yes | The inFlow vendor ID. |
