# List Stock Transfers with inFlow Inventory

Retrieves stock transfers from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock-transfers`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Stock Transfers](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
