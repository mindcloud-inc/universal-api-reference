# Insert or Update Purchase Order with inFlow Inventory

Inserts or updates a purchase order in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/purchase-orders`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Purchase Order](https://cloudapi.inflowinventory.com/docs/index.html)
