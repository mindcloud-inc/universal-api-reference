# List Sales Orders with inFlow Inventory

Retrieves sales orders from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales-orders`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Sales Orders](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
