# List Vendors with inFlow Inventory

Retrieves vendor records from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendors`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Vendors](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
