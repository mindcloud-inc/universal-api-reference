# Insert or Update Customer with inFlow Inventory

Inserts or updates a customer in inFlow Inventory.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [Insert or Update Customer](https://cloudapi.inflowinventory.com/docs/index.html)
