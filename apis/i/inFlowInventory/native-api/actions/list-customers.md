# List Customers with inFlow Inventory

Retrieves customer records from inFlow Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://cloudapi.inflowinventory.com/{companyId}`
- **Official documentation:** [List Customers](https://cloudapi.inflowinventory.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
