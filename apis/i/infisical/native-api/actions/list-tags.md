# List Tags with Infisical

Retrieves tags for a project in Infisical.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:projectId/tags`
- **Base URL:** `https://app.infisical.com`
- **Official documentation:** [List Tags](https://infisical.com/docs/api-reference/endpoints/secret-tags/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
