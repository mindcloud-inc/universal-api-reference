# Get Project By Slug with Infisical

Retrieves a project from Infisical by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/slug/:slug`
- **Base URL:** `https://app.infisical.com`
- **Official documentation:** [Get Project By Slug](https://infisical.com/docs/api-reference/endpoints/projects/get-project-by-slug)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The slug of the project to retrieve. |
