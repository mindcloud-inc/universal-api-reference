# Get Folder By ID with Infisical

Retrieves a folder from Infisical by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/folders/:id`
- **Base URL:** `https://app.infisical.com`
- **Official documentation:** [Get Folder By ID](https://infisical.com/docs/api-reference/endpoints/folders/get-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
