# Delete Project with Infisical

Deletes an existing project from Infisical.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/projects/:projectId`
- **Base URL:** `https://app.infisical.com`
- **Official documentation:** [Delete Project](https://infisical.com/docs/api-reference/endpoints/projects/delete-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
