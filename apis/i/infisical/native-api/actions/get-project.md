# Get Project with Infisical

Retrieves a project from Infisical by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:projectId`
- **Base URL:** `https://app.infisical.com`
- **Official documentation:** [Get Project](https://infisical.com/docs/api-reference/endpoints/projects/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project to retrieve. |
