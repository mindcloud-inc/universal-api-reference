# Lookup Domain WHOIS with IP2Location.io IP Geolocation

Retrieves domain WHOIS details from IP2Location.io by domain name.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.ip2whois.com/v2`
- **Base URL:** `https://api.ip2location.io`
- **Official documentation:** [Lookup Domain WHOIS](https://www.ip2location.io/ip2whois-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to look up. |
