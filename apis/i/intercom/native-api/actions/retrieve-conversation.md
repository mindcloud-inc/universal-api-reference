# Retrieve Conversation with Intercom

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversation_id`
- **Base URL:** `https://api.intercom.io`
- **Official documentation:** [Retrieve Conversation](https://developers.intercom.com/docs/references/rest-api/api.intercom.io/conversations/retrieveconversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | Intercom conversation identifier |
