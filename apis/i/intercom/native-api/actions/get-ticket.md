# Get Ticket with Intercom

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:ticket_id`
- **Base URL:** `https://api.intercom.io`
- **Official documentation:** [Get Ticket](https://developers.intercom.com/docs/references/rest-api/api.intercom.io/tickets/getticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticket_id` | path | `string` | yes | Intercom ticket identifier |
