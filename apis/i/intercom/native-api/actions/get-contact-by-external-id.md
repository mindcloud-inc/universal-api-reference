# Get Contact By External ID with Intercom

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/find_by_external_id/:external_id`
- **Base URL:** `https://api.intercom.io`
- **Official documentation:** [Get Contact By External ID](https://developers.intercom.com/docs/references/rest-api/api.intercom.io/contacts/showcontactbyexternalid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `external_id` | path | `string` | yes | External contact identifier |
