# Delete Ticket with Intercom

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tickets/:ticket_id`
- **Base URL:** `https://api.intercom.io`
- **Official documentation:** [Delete Ticket](https://developers.intercom.com/docs/references/rest-api/api.intercom.io/tickets/deleteticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticket_id` | path | `string` | yes | Intercom ticket identifier |
