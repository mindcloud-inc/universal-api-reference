# Archive Contact with Intercom

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/:contact_id/archive`
- **Base URL:** `https://api.intercom.io`
- **Official documentation:** [Archive Contact](https://developers.intercom.com/docs/references/rest-api/api.intercom.io/contacts/archivecontact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Intercom contact identifier |
