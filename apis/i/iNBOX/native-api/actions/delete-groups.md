# Delete Groups with INBOX

Deletes an existing group from INBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/groups/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Groups](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
