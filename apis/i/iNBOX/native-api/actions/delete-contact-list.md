# Delete Contact List with INBOX

Deletes an existing contact list from INBOX.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inbox/v1/contactlists/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Delete Contact List](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
