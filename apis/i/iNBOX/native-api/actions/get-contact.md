# Get Contact with INBOX

Retrieves an existing contact from INBOX.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/v1/contacts/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Get Contact](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
