# Get Newsletter with INBOX

Retrieves an existing newsletter from INBOX.

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/v1/newsletters/:id`
- **Base URL:** `https://useapi.useinbox.com`
- **Official documentation:** [Get Newsletter](https://reference.useinbox.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
