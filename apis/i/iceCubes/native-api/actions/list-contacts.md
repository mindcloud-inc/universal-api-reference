# List Contacts with IceCubes

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://icecubes.app/api/public`
- **Official documentation:** [List Contacts](https://icecubes.app/docs/api/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search contacts by name or email. |
| `domain` | query | `string` | no | Filter contacts by email domain. |
