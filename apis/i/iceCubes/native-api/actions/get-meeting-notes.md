# Get Meeting Notes with IceCubes

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings/:id/notes`
- **Base URL:** `https://icecubes.app/api/public`
- **Official documentation:** [Get Meeting Notes](https://icecubes.app/docs/api/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The meeting ID to retrieve notes for. |
