# Get Meeting Transcript with IceCubes

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings/:id/transcript`
- **Base URL:** `https://icecubes.app/api/public`
- **Official documentation:** [Get Meeting Transcript](https://icecubes.app/docs/api/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The meeting ID to retrieve the transcript for. |
