# Get Stage0 Listing Metadata with Inistate

Retrieves Stage0 listing metadata from Inistate.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/workspace/list`
- **Base URL:** `https://api.inistate.com`
- **Official documentation:** [Get Stage0 Listing Metadata](https://app.swaggerhub.com/apis-docs/Inistate/InistateAPI/1.0.0)
