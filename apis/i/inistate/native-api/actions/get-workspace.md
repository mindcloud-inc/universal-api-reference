# Get Workspace with Inistate

Retrieves a workspace from Inistate.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/workspace/:workspaceIdParam`
- **Base URL:** `https://api.inistate.com`
- **Official documentation:** [Get Workspace](https://app.swaggerhub.com/apis-docs/Inistate/InistateAPI/1.0.0)
