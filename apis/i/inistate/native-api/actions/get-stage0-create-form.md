# Get Stage0 Create Form with Inistate

Retrieves the Stage0 create form from Inistate.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/activity/form`
- **Base URL:** `https://api.inistate.com`
- **Official documentation:** [Get Stage0 Create Form](https://app.swaggerhub.com/apis-docs/Inistate/InistateAPI/1.0.0)
