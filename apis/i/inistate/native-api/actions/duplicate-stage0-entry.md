# Duplicate Stage0 Entry with Inistate

Creates a duplicated Stage0 entry in Inistate.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/activity`
- **Base URL:** `https://api.inistate.com`
- **Official documentation:** [Duplicate Stage0 Entry](https://app.swaggerhub.com/apis-docs/Inistate/InistateAPI/1.0.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entryId` | body | `number` | yes | Entry to duplicate. |
