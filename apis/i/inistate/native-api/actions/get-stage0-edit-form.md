# Get Stage0 Edit Form with Inistate

Retrieves the Stage0 edit form from Inistate.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/activity/form`
- **Base URL:** `https://api.inistate.com`
- **Official documentation:** [Get Stage0 Edit Form](https://app.swaggerhub.com/apis-docs/Inistate/InistateAPI/1.0.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entryId` | body | `number` | yes | Entry to load into the edit form. |
