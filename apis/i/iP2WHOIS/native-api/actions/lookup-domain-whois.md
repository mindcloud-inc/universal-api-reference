# Lookup Domain WHOIS with IP2WHOIS

Retrieves domain WHOIS details from IP2WHOIS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2`
- **Base URL:** `https://api.ip2whois.com`
- **Official documentation:** [Lookup Domain WHOIS](https://www.ip2location.io/ip2whois-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Domain name to look up. |
