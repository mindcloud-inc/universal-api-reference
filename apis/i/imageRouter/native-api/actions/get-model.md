# Get Model with ImageRouter

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/models/:modelId`
- **Base URL:** `https://api.imagerouter.io`
- **Official documentation:** [Get Model](https://docs.imagerouter.io/api-reference/models/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `string` | yes | The ImageRouter model ID, such as google/gemini-2.5-flash. |
