# Get Lite IP Details with IPInfo

## Endpoint

- **Method:** `GET`
- **Path:** `/lite/:ip`
- **Base URL:** `https://api.ipinfo.io`
- **Official documentation:** [Get Lite IP Details](https://ipinfo.io/developers/lite-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | yes | A single IPv4 or IPv6 IP address to look up. |
