# Get Lite My IP Field with IPInfo

## Endpoint

- **Method:** `GET`
- **Path:** `/lite/me/:field`
- **Base URL:** `https://api.ipinfo.io`
- **Official documentation:** [Get Lite My IP Field](https://ipinfo.io/developers/lite-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field` | path | `string` | yes | Lite field path to return, for example country_code or asn. |
