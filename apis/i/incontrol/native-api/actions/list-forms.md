# List Forms with Incontrol

Retrieves a list of forms from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [List Forms](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
