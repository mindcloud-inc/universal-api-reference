# List Users with Incontrol

Retrieves a list of users from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [List Users](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
