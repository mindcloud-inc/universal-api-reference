# Get Organization with Incontrol

Retrieves details for an organization from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organization/{{id}}`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [Get Organization](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The organization ID. |
