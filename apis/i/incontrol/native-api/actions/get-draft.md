# Get Draft with Incontrol

Retrieves details for a draft from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/draft/{{id}}`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [Get Draft](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The draft ID. |
