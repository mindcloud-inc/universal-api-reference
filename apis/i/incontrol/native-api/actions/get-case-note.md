# Get Case Note with Incontrol

Retrieves details for a case note from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/casenote/{{id}}`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [Get Case Note](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The case note ID. |
