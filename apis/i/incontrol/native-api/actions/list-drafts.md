# List Drafts with Incontrol

Retrieves a list of drafts from Incontrol.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/draft`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [List Drafts](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
