# Verify API Token with Incontrol

Verifies an Incontrol API token and returns its scope.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/testtoken`
- **Base URL:** `https://portal.incontrol.app`
- **Official documentation:** [Verify API Token](https://portal.incontrol.app/swagger/index.html?urls.primaryName=Public%20API%20(v1))
