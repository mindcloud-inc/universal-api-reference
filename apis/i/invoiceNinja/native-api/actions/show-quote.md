# Show Quote with Invoice Ninja

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/:id`
- **Base URL:** `https://invoicing.co/api/v1`
- **Official documentation:** [Show Quote](https://api-docs.invoicing.co/#tag/quotes/operation/showQuote)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hashed quote ID. |
