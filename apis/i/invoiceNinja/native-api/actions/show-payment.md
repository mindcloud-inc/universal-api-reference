# Show Payment with Invoice Ninja

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/:id`
- **Base URL:** `https://invoicing.co/api/v1`
- **Official documentation:** [Show Payment](https://api-docs.invoicing.co/#tag/payments/operation/showPayment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The payment identifier. |
