# Show Recurring Invoice with Invoice Ninja

## Endpoint

- **Method:** `GET`
- **Path:** `/recurring_invoices/:id`
- **Base URL:** `https://invoicing.co/api/v1`
- **Official documentation:** [Show Recurring Invoice](https://api-docs.invoicing.co/#tag/Recurring-Invoices/operation/showRecurringInvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The recurring invoice identifier. |
