# List Professional Education Institutes with InsightIQ

Finds education institutes in InsightIQ by substring.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/professional/creators/dictionary/education-institutes`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Professional Education Institutes](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | query | `string` | no | Optional substring to filter education institutes. |
