# List Webhooks with InsightIQ

Retrieves a list of webhooks from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Webhooks](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).
