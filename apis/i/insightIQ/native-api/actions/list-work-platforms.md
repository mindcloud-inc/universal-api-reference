# List Work Platforms with InsightIQ

Retrieves available work platforms from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/work-platforms`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Work Platforms](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).
