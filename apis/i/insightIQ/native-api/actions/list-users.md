# List Users with InsightIQ

Retrieves a list of users from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Users](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).
