# Get User with InsightIQ

Retrieves a single user from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get User](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | InsightIQ user identifier. |
