# Get Async Content Comments Fetch with InsightIQ

Retrieves an async content comments result from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/social/creators/async/contents/comments/fetch/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Async Content Comments Fetch](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | InsightIQ job ID for the async comments fetch request |
