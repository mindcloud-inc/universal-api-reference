# Get Async Creator Profile Analytics with InsightIQ

Retrieves an async creator analytics result from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/social/creators/async/profiles/analytics/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Async Creator Profile Analytics](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | InsightIQ job ID for the async profile analytics request |
