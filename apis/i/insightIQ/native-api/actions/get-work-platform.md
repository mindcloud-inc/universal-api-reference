# Get Work Platform with InsightIQ

Retrieves a work platform from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/work-platforms/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Work Platform](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique InsightIQ work platform identifier. |
