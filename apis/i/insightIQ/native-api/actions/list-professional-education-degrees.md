# List Professional Education Degrees with InsightIQ

Finds education degrees in InsightIQ by substring.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/professional/creators/dictionary/education-degrees`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Professional Education Degrees](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | query | `string` | no | Optional substring to filter education degrees. |
