# Get Media Safety Screening with InsightIQ

Retrieves a media safety screening from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/safety/media-screening/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Media Safety Screening](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | InsightIQ job ID for the media safety screening |
