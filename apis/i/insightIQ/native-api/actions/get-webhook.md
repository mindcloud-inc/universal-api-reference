# Get Webhook with InsightIQ

Retrieves a single webhook from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Webhook](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | InsightIQ webhook identifier. |
