# List Flagging Criteria with InsightIQ

Retrieves available flagging criteria from InsightIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/safety/flagging-criteria`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Flagging Criteria](https://docs.insightiq.ai/docs/api-reference/api/ref)

## Capabilities

This operation supports [pagination](../README.md#pagination).
