# Get Survey Stats with Informizely

## Endpoint

- **Method:** `GET`
- **Path:** `/stats`
- **Base URL:** `https://api.informizely.com/api/v1`
- **Official documentation:** [Get Survey Stats](https://www.informizely.com/help/report-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the survey whose statistics you want to retrieve. |
