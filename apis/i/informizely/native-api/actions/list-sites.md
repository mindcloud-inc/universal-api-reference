# List Sites with Informizely

## Endpoint

- **Method:** `GET`
- **Path:** `/sites`
- **Base URL:** `https://api.informizely.com/api/v1`
- **Official documentation:** [List Sites](https://www.informizely.com/help/report-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeSurveyData` | query | `boolean` | no | Set to false to exclude survey metadata from each site result. |
