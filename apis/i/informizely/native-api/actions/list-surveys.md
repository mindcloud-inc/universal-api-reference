# List Surveys with Informizely

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys`
- **Base URL:** `https://api.informizely.com/api/v1`
- **Official documentation:** [List Surveys](https://www.informizely.com/help/report-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the site whose surveys you want to retrieve. |
