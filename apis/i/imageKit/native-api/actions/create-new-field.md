# Create New Field with ImageKit.io

Creates a custom metadata field in ImageKit.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/customMetadataFields`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Create New Field](https://imagekit.io/docs/api-reference/digital-asset-management-dam/custom-metadata-fields/create-new-field)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `label` | body | `string` | no |
| `name` | body | `string` | no |
| `schema` | body | `object` | no |
