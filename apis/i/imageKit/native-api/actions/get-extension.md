# Get Extension with ImageKit.io

Retrieves a saved extension from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/saved-extensions/:extensionId`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get Extension](https://imagekit.io/docs/api-reference/digital-asset-management-dam/saved-extensions/get-extension)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `extensionId` | path | `string` | no |
