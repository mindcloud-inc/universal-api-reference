# List Extensions with ImageKit.io

Retrieves saved extensions from your ImageKit.io account.

## Endpoint

- **Method:** `GET`
- **Path:** `/saved-extensions`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [List Extensions](https://imagekit.io/docs/api-reference/digital-asset-management-dam/saved-extensions/list-extensions)
