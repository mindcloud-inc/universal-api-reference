# Delete Folder with ImageKit.io

Deletes an existing folder from ImageKit.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folder`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Delete Folder](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-folders/delete-folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderPath` | body | `string` | no |
