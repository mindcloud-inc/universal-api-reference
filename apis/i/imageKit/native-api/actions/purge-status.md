# Purge Status with ImageKit.io

Retrieves the status of a cache purge request in ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/purge/:requestId`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Purge Status](https://imagekit.io/docs/api-reference/caching/purge-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestId` | path | `string` | no |
