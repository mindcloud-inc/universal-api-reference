# Get File Details with ImageKit.io

Retrieves detailed file information from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/details`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get File Details](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-assets/get-file-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | no |
