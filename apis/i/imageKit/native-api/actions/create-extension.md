# Create Extension with ImageKit.io

Creates a saved extension in ImageKit.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/saved-extensions`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Create Extension](https://imagekit.io/docs/api-reference/digital-asset-management-dam/saved-extensions/create-extension)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `config` | body | `object` | no |
| `description` | body | `string` | no |
| `name` | body | `string` | no |
