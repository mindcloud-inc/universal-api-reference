# Create Folder with ImageKit.io

Creates a new folder in ImageKit.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/folder`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Create Folder](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-folders/create-folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderName` | body | `string` | no |
| `parentFolderPath` | body | `string` | no |
