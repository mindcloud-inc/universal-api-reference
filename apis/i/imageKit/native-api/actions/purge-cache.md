# Purge Cache with ImageKit.io

Purges cached file URLs in ImageKit.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/purge`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Purge Cache](https://imagekit.io/docs/api-reference/caching/purge-cache)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | no |
