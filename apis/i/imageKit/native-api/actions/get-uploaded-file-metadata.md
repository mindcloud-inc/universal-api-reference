# Get Uploaded File Metadata with ImageKit.io

Retrieves uploaded file metadata from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/metadata`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get Uploaded File Metadata](https://imagekit.io/docs/api-reference/file-metadata/get-uploaded-file-metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | no |
