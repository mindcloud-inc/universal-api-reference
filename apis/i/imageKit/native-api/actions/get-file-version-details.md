# Get File Version Details with ImageKit.io

Retrieves file version details from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/versions/:versionId`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get File Version Details](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-assets/get-file-version-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | no |
| `versionId` | path | `string` | no |
