# List and Search Assets with ImageKit.io

Finds files in ImageKit.io with search and filter options.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [List and Search Assets](https://imagekit.io/docs/api-reference/digital-asset-management-dam/list-and-search-assets)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
