# List All Fields with ImageKit.io

Retrieves custom metadata fields from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/customMetadataFields`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [List All Fields](https://imagekit.io/docs/api-reference/digital-asset-management-dam/custom-metadata-fields/list-all-fields)
