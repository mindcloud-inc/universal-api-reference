# List File Versions with ImageKit.io

Retrieves all file versions from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/versions`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [List File Versions](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-assets/list-file-versions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | no |
