# Bulk Job Status with ImageKit.io

Retrieves the status of a folder bulk job in ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulkJobs/:jobId`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Bulk Job Status](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-folders/bulk-job-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | no |
