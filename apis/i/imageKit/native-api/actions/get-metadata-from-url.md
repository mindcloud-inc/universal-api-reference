# Get Metadata From URL with ImageKit.io

Retrieves file metadata from a URL in ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get Metadata From URL](https://imagekit.io/docs/api-reference/file-metadata/get-metadata-from-url)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | no |
