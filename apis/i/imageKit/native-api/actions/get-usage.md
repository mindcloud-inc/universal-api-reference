# Get Usage with ImageKit.io

Retrieves account usage metrics from ImageKit.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/usage`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Get Usage](https://imagekit.io/docs/api-reference/account-management-api/get-usage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endDate` | query | `string` | no |
| `startDate` | query | `string` | no |
