# Delete File Version with ImageKit.io

Deletes a file version from ImageKit.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:fileId/versions/:versionId`
- **Base URL:** `https://api.imagekit.io/v1`
- **Official documentation:** [Delete File Version](https://imagekit.io/docs/api-reference/digital-asset-management-dam/managing-assets/delete-file-version)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | no |
| `versionId` | path | `string` | no |
