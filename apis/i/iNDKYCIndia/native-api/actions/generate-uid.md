# Generate UID with IN-D KYC India

Creates a new KYC session UID in IN-D KYC India.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/upload/uid`
- **Base URL:** `https://api.kyc.in-d.ai`
- **Official documentation:** [Generate UID](https://dev.in-d.ai/api-documentation/#operation/generate_uid_id)
