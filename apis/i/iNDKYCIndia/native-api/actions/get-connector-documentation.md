# Get Connector Documentation with IN-D KYC India

Retrieves the IN-D KYC India connector documentation.

## Endpoint

- **Method:** `GET`
- **Path:** `https://learn.microsoft.com/en-us/connectors/indkycindia/`
- **Base URL:** `https://api.kyc.in-d.ai`
- **Official documentation:** [Get Connector Documentation](https://learn.microsoft.com/en-us/connectors/indkycindia/)
