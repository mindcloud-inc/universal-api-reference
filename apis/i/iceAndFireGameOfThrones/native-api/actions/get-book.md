# Get Book with Ice and Fire (Game of Thrones)

## Endpoint

- **Method:** `GET`
- **Path:** `/books/:bookId`
- **Base URL:** `https://anapioficeandfire.com/api`
- **Official documentation:** [Get Book](https://github.com/joakimskoog/AnApiOfIceAndFire/wiki/Books)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookId` | path | `number` | yes | The numeric ID of the book to retrieve. |
