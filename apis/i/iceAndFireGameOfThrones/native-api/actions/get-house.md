# Get House with Ice and Fire (Game of Thrones)

## Endpoint

- **Method:** `GET`
- **Path:** `/houses/:houseId`
- **Base URL:** `https://anapioficeandfire.com/api`
- **Official documentation:** [Get House](https://github.com/joakimskoog/AnApiOfIceAndFire/wiki/Houses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `houseId` | path | `number` | yes | The numeric ID of the house to retrieve. |
