# Get Character with Ice and Fire (Game of Thrones)

## Endpoint

- **Method:** `GET`
- **Path:** `/characters/:characterId`
- **Base URL:** `https://anapioficeandfire.com/api`
- **Official documentation:** [Get Character](https://github.com/joakimskoog/AnApiOfIceAndFire/wiki/Characters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `characterId` | path | `number` | yes | The numeric ID of the character to retrieve. |
