# Get a saved transaction with ID Analyzer

Retrieves a saved transaction from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/:transactionId`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Get a saved transaction](https://developer.idanalyzer.com/reference/get-transaction-transactionid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | path | `string` | yes | Saved transaction ID. |
