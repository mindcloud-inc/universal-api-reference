# Get a KYC profile with ID Analyzer

Retrieves a KYC profile from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/:profileId`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Get a KYC profile](https://developer.idanalyzer.com/reference/get-profile-profileid-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | KYC profile ID. |
