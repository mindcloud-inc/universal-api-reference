# Delete a Docupass session with ID Analyzer

Deletes a Docupass session from ID Analyzer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docupass/:reference`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Delete a Docupass session](https://developer.idanalyzer.com/reference/delete-docupass-reference-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reference` | path | `string` | yes | Docupass reference. |
