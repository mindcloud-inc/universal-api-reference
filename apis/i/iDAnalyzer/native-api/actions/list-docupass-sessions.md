# List Docupass sessions with ID Analyzer

Retrieves Docupass sessions from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/docupass`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [List Docupass sessions](https://developer.idanalyzer.com/reference/get-docupass-2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
