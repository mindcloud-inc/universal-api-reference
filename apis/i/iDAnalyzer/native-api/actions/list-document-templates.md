# List document templates with ID Analyzer

Retrieves document templates from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/contract`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [List document templates](https://developer.idanalyzer.com/reference/get-contract-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
