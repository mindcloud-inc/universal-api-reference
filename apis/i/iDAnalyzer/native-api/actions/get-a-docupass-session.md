# Get a Docupass session with ID Analyzer

Retrieves a Docupass session from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/docupass/:reference`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Get a Docupass session](https://developer.idanalyzer.com/reference/get-docupass-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reference` | path | `string` | yes | Docupass reference. |
