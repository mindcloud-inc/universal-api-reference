# Delete a document template with ID Analyzer

Deletes a document template from ID Analyzer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contract/:templateId`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Delete a document template](https://developer.idanalyzer.com/reference/delete-contract-templateid-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Stored template ID. |
