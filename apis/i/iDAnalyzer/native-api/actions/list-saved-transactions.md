# List saved transactions with ID Analyzer

Retrieves saved transactions from ID Analyzer.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [List saved transactions](https://developer.idanalyzer.com/reference/get-transaction-3)

## Capabilities

This operation supports [pagination](../README.md#pagination).
