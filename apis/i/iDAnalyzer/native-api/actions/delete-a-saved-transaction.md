# Delete a saved transaction with ID Analyzer

Deletes a saved transaction from ID Analyzer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/transaction/:transactionId`
- **Base URL:** `https://api2.idanalyzer.com`
- **Official documentation:** [Delete a saved transaction](https://developer.idanalyzer.com/reference/delete-transaction-transactionid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | path | `string` | yes | Saved transaction ID. |
