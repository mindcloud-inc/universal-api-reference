# Get Signer Details with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signers/:signerId/details`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Signer Details](https://ignisign.io/docs/ignisign-api/signers/get-a-signer-with-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signerId` | path | `string` | yes | The IgniSign signer ID. |
