# List Signer Profiles with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signer-profiles`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [List Signer Profiles](https://ignisign.io/docs/ignisign-api/signer-profiles/get-signer-profiles)
