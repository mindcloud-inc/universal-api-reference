# Get Signer Profile with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signer-profiles/:signerProfileId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Signer Profile](https://ignisign.io/docs/ignisign-api/signer-profiles/get-a-signer-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signerProfileId` | path | `string` | yes | The IgniSign signer profile ID. |
