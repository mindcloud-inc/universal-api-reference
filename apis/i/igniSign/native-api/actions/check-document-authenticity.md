# Check Document Authenticity with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/documents/:documentId/check-authenticity`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Check Document Authenticity](https://ignisign.io/docs/ignisign-api/documents/check-document-authenticity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
