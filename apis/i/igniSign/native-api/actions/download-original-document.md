# Download Original Document with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/documents/:documentId/file`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Download Original Document](https://ignisign.io/docs/ignisign-api/documents/download-the-original-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
