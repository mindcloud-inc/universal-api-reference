# Delete Document with IgniSign

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/documents/:documentId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Delete Document](https://ignisign.io/docs/ignisign-api/documents/remove-a-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
