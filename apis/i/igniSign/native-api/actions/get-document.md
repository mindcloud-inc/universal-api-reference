# Get Document with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/documents/:documentId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Document](https://ignisign.io/docs/ignisign-api/documents/get-document-information)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
