# Get Signature Images with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/documents/:documentId/img-signatures`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Signature Images](https://ignisign.io/docs/ignisign-api/documents/get-signature-images-base64)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
