# Upload Document Content Data JSON with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/documents/:documentId/data-json-content`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Upload Document Content Data JSON](https://ignisign.io/docs/ignisign-api/documents/provide-document-content-data-json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
