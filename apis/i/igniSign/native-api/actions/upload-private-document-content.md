# Upload Private Document Content with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/documents/:documentId/private-content`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Upload Private Document Content](https://ignisign.io/docs/ignisign-api/documents/provide-document-content-private-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
