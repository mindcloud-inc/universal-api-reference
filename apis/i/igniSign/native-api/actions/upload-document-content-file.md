# Upload Document Content File with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/documents/:documentId/file`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Upload Document Content File](https://ignisign.io/docs/ignisign-api/documents/provide-document-content-file-or-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
