# List Webhook Endpoints with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/webhooks`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [List Webhook Endpoints](https://ignisign.io/docs/ignisign-api/webhooks/get-webhook-endpoints)
