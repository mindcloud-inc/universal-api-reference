# Get Signer Input Constraints with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signer-profiles/:signerProfileId/inputs-needed`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Signer Input Constraints](https://ignisign.io/docs/ignisign-api/signer-profiles/get-signer-input-constraints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signerProfileId` | path | `string` | yes | The IgniSign signer profile ID. |
