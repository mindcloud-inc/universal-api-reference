# Update Signer with IgniSign

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signers/:signerId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Update Signer](https://ignisign.io/docs/ignisign-api/signers/update-a-signer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signerId` | path | `string` | yes | The IgniSign signer ID. |
