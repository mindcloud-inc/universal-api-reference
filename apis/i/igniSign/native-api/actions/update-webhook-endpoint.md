# Update Webhook Endpoint with IgniSign

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/webhooks/:webhookId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Update Webhook Endpoint](https://ignisign.io/docs/ignisign-api/webhooks/update-a-webhook-endpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The IgniSign webhook ID. |
