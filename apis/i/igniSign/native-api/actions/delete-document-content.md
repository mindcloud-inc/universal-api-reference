# Delete Document Content with IgniSign

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/documents/:documentId/content`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Delete Document Content](https://ignisign.io/docs/ignisign-api/documents/remove-document-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
