# Create Webhook Endpoint with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/applications/:appId/envs/:appEnv/webhooks`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Create Webhook Endpoint](https://ignisign.io/docs/ignisign-api/webhooks/add-a-new-webhook-endpoint)
