# Get Document Context with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/documents/:documentId/context`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Document Context](https://ignisign.io/docs/ignisign-api/documents/get-a-document-context)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The IgniSign document ID. |
