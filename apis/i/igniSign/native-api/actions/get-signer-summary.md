# Get Signer Summary with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signers/:signerId`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Get Signer Summary](https://ignisign.io/docs/ignisign-api/signers/get-signer-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signerId` | path | `string` | yes | The IgniSign signer ID. |
