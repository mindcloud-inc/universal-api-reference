# Search Signers by Filters with IgniSign

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/applications/:appId/envs/:appEnv/signers-search`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [Search Signers by Filters](https://ignisign.io/docs/ignisign-api/signers/search-signers)
