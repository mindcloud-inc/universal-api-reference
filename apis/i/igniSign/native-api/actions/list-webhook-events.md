# List Webhook Events with IgniSign

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/webhooks/:webhookId/events`
- **Base URL:** `https://api.ignisign.io`
- **Official documentation:** [List Webhook Events](https://ignisign.io/docs/ignisign-api/webhooks/get-webhook-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The IgniSign webhook ID. |
