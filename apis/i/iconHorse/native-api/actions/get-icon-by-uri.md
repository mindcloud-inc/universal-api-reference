# Get Icon by URI with Icon Horse

Retrieves a website icon from Icon Horse by URI.

## Endpoint

- **Method:** `GET`
- **Path:** `/icon/:uri`
- **Base URL:** `https://icon.horse`
- **Official documentation:** [Get Icon by URI](https://icon.horse/usage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uri` | path | `string` | yes | URL-encoded full URI to resolve into an icon, such as https%3A%2F%2Fwikipedia.org. |
