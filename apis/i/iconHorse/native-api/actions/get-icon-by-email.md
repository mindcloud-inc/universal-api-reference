# Get Icon by Email with Icon Horse

Retrieves a website icon from Icon Horse by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/icon/:email`
- **Base URL:** `https://icon.horse`
- **Official documentation:** [Get Icon by Email](https://icon.horse/usage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | URL-encoded email address to resolve into an icon, such as hello%40wikipedia.org. |
