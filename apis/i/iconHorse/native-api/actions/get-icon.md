# Get Icon with Icon Horse

Retrieves a website icon from Icon Horse by hostname.

## Endpoint

- **Method:** `GET`
- **Path:** `/icon/:hostname`
- **Base URL:** `https://icon.horse`
- **Official documentation:** [Get Icon](https://icon.horse/usage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hostname` | path | `string` | yes | Fully qualified domain name such as github.com, wikipedia.org, or youtube.com. |
