# Get Custom Colors with Instructure

Retrieves custom colors from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/colors`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Custom Colors](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.get_custom_colors)
