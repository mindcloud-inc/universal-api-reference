# List User Files with Instructure

Retrieves user files from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/files`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List User Files](https://developerdocs.instructure.com/services/canvas/resources/files#method.files.api_index)
