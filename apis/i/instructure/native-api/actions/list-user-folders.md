# List User Folders with Instructure

Retrieves user folders from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/folders`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List User Folders](https://developerdocs.instructure.com/services/canvas/resources/files#method.folders.list_all_folders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
