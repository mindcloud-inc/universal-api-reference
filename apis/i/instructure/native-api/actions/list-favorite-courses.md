# List Favorite Courses with Instructure

Retrieves favorite courses from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/favorites/courses`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Favorite Courses](https://developerdocs.instructure.com/services/canvas/resources/favorites)
