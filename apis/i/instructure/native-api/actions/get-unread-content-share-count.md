# Get Unread Content Share Count with Instructure

Retrieves unread content share count from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/content_shares/unread_count`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Unread Content Share Count](https://developerdocs.instructure.com/services/canvas/resources/content_shares)
