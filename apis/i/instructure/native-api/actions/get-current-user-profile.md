# Get Current User Profile with Instructure

Retrieves the current user profile from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/profile`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Current User Profile](https://developerdocs.instructure.com/services/canvas/resources/users#method.profile.settings)
