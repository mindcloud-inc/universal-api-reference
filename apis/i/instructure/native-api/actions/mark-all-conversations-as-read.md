# Mark All Conversations As Read with Instructure

Marks all conversations as read in Instructure Canvas.

## Endpoint

- **Method:** `POST`
- **Path:** `/conversations/mark_all_as_read`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Mark All Conversations As Read](https://developerdocs.instructure.com/services/canvas/resources/conversations)
