# List Missing Submissions with Instructure

Retrieves missing submissions from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/missing_submissions`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Missing Submissions](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.missing_submissions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
