# Get Planner Override with Instructure

Retrieves a planner override from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/planner/overrides/:id`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Planner Override](https://developerdocs.instructure.com/services/canvas/resources/planner)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Canvas planner override ID. |
