# List Course Nicknames with Instructure

Retrieves course nicknames from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/course_nicknames`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Course Nicknames](https://developerdocs.instructure.com/services/canvas/resources/users)
