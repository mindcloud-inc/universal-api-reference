# List Activity Stream with Instructure

Retrieves the activity stream from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/activity_stream`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Activity Stream](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.activity_stream)

## Capabilities

This operation supports [pagination](../README.md#pagination).
