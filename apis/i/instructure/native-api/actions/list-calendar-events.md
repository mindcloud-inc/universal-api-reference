# List Calendar Events with Instructure

Retrieves calendar events from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar_events`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Calendar Events](https://developerdocs.instructure.com/services/canvas/resources/calendar_events#method.calendar_events_api.index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
