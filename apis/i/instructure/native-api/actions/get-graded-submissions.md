# Get Graded Submissions with Instructure

Retrieves graded submissions from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/graded_submissions`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Graded Submissions](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.user_graded_submissions)
