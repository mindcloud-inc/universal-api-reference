# List Courses with Instructure

Retrieves courses from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Courses](https://developerdocs.instructure.com/services/canvas/resources/courses#method.courses.index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
