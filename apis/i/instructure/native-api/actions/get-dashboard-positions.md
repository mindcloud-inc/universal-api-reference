# Get Dashboard Positions with Instructure

Retrieves dashboard positions from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/dashboard_positions`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Dashboard Positions](https://developerdocs.instructure.com/services/canvas/resources/users)
