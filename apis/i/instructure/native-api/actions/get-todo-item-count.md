# Get Todo Item Count with Instructure

Retrieves the todo item count from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/todo_item_count`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Todo Item Count](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.todo_item_count)
