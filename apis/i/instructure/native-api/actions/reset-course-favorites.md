# Reset Course Favorites with Instructure

Resets course favorites in Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/self/favorites/courses`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Reset Course Favorites](https://developerdocs.instructure.com/services/canvas/resources/favorites)
