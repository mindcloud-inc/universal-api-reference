# List Communication Channels with Instructure

Retrieves communication channels from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/communication_channels`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Communication Channels](https://developerdocs.instructure.com/services/canvas/resources/communication_channels)
