# List Favorite Groups with Instructure

Retrieves favorite groups from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/favorites/groups`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Favorite Groups](https://developerdocs.instructure.com/services/canvas/resources/favorites)
