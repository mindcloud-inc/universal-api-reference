# Get Conversation Batches with Instructure

Retrieves conversation batches from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/batches`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Conversation Batches](https://developerdocs.instructure.com/services/canvas/resources/conversations)
