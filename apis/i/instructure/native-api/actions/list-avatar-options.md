# List Avatar Options with Instructure

Retrieves avatar options from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/avatars`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Avatar Options](https://developerdocs.instructure.com/services/canvas/resources/users#method.profile.profile_pics)
