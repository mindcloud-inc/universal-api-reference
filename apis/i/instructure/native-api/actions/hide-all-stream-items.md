# Hide All Stream Items with Instructure

Hides all stream items in Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/self/activity_stream`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Hide All Stream Items](https://developerdocs.instructure.com/services/canvas/resources/users)
