# List Planner Notes with Instructure

Retrieves planner notes from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/planner_notes`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Planner Notes](https://developerdocs.instructure.com/services/canvas/resources/planner)
