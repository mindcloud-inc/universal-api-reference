# Get Activity Stream Summary with Instructure

Retrieves the activity stream summary from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/activity_stream/summary`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Activity Stream Summary](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.activity_stream_summary)
