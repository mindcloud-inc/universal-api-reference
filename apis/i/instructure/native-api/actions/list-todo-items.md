# List Todo Items with Instructure

Retrieves todo items from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/todo`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Todo Items](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.todo_items)

## Capabilities

This operation supports [pagination](../README.md#pagination).
