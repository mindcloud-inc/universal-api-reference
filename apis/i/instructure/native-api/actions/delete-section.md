# Delete Section with Instructure

Deletes a section from Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sections/:id`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Delete Section](https://developerdocs.instructure.com/services/canvas/resources/sections#method.sections.destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Canvas section ID. |
