# Clear Course Nicknames with Instructure

Clears course nicknames from Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/self/course_nicknames`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Clear Course Nicknames](https://developerdocs.instructure.com/services/canvas/resources/users)
