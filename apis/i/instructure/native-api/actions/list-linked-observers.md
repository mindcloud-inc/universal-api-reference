# List Linked Observers with Instructure

Retrieves linked observers from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/observers`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Linked Observers](https://developerdocs.instructure.com/services/canvas/resources/user_observees)
