# Delete File with Instructure

Deletes a file from Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:id`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Delete File](https://developerdocs.instructure.com/services/canvas/resources/files#method.files.destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Canvas file ID. |
