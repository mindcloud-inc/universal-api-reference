# Get Current User with Instructure

Retrieves the current user from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Current User](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.api_show)
