# List Sent Content Shares with Instructure

Retrieves sent content shares from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/content_shares/sent`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Sent Content Shares](https://developerdocs.instructure.com/services/canvas/resources/content_shares)
