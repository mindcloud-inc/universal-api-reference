# List Planner Items with Instructure

Retrieves planner items from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/planner/items`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Planner Items](https://developerdocs.instructure.com/services/canvas/resources/planner)
