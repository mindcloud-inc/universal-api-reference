# Get Folder with Instructure

Retrieves a folder from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:folder_id`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Folder](https://developerdocs.instructure.com/services/canvas/resources/files#method.folders.show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `string` | yes | The Canvas folder ID. |
