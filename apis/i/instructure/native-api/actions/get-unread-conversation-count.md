# Get Unread Conversation Count with Instructure

Retrieves unread conversation count from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/unread_count`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Unread Conversation Count](https://developerdocs.instructure.com/services/canvas/resources/conversations)
