# Get User Settings with Instructure

Retrieves user settings from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/settings`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get User Settings](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.settings)
