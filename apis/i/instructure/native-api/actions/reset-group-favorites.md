# Reset Group Favorites with Instructure

Resets group favorites in Instructure Canvas.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/self/favorites/groups`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Reset Group Favorites](https://developerdocs.instructure.com/services/canvas/resources/favorites)
