# List Bookmarks with Instructure

Retrieves bookmarks from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/bookmarks`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Bookmarks](https://developerdocs.instructure.com/services/canvas/file.all_resources/bookmarks)
