# List Upcoming Events with Instructure

Retrieves upcoming events from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/upcoming_events`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Upcoming Events](https://developerdocs.instructure.com/services/canvas/resources/users#method.users.upcoming_events)

## Capabilities

This operation supports [pagination](../README.md#pagination).
