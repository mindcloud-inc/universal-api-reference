# List Received Content Shares with Instructure

Retrieves received content shares from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/content_shares/received`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Received Content Shares](https://developerdocs.instructure.com/services/canvas/resources/content_shares)
