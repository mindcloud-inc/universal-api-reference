# List Linked Observees with Instructure

Retrieves linked observees from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/self/observees`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Linked Observees](https://developerdocs.instructure.com/services/canvas/resources/user_observees)
