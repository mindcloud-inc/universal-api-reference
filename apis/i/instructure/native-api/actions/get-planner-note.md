# Get Planner Note with Instructure

Retrieves a planner note from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/planner_notes/:id`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [Get Planner Note](https://developerdocs.instructure.com/services/canvas/resources/planner)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Canvas planner note ID. |
