# List Planner Overrides with Instructure

Retrieves planner overrides from Instructure Canvas.

## Endpoint

- **Method:** `GET`
- **Path:** `/planner/overrides`
- **Base URL:** `https://canvas.instructure.com/api/v1`
- **Official documentation:** [List Planner Overrides](https://developerdocs.instructure.com/services/canvas/resources/planner)
