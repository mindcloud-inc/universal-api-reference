# Fetch Dad Joke with icanhazdadjoke

Retrieves a specific dad joke from icanhazdadjoke.

## Endpoint

- **Method:** `GET`
- **Path:** `/j/:jokeId`
- **Base URL:** `https://icanhazdadjoke.com`
- **Official documentation:** [Fetch Dad Joke](https://icanhazdadjoke.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jokeId` | path | `string` | yes | ID of the dad joke to fetch. |
