# Delete Property with Innform

Deletes a property from Innform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/properties/{id}`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Delete Property](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Property UUID. |
