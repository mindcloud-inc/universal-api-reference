# Get Property with Innform

Retrieves a property from Innform.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/{id}`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Get Property](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Property UUID. |
