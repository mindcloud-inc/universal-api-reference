# Create Group with Innform

Creates a new group in Innform.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Create Group](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `color` | body | `string` | no | Optional hex color value. |
| `name` | body | `string` | yes | Group name. |
