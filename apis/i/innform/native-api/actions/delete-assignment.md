# Delete Assignment with Innform

Deletes an assignment from Innform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assignments/{id}`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Delete Assignment](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Assignment UUID. |
