# Delete Group with Innform

Deletes a group from Innform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/{id}`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Delete Group](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group UUID. |
