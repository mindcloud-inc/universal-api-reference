# Get Group with Innform

Retrieves a group from Innform.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{id}`
- **Base URL:** `https://api.innform.io/v1`
- **Official documentation:** [Get Group](https://innform.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group UUID. |
