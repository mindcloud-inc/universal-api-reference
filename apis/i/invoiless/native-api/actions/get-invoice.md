# Get Invoice with Invoiless

Retrieves an invoice from Invoiless.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.invoiless.com/v1`
- **Official documentation:** [Get Invoice](https://docs.invoiless.com/guide/invoices.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice id. |
