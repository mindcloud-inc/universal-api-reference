# Get Customer with Invoiless

Retrieves a customer from Invoiless.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.invoiless.com/v1`
- **Official documentation:** [Get Customer](https://docs.invoiless.com/guide/customers.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Customer id. |
