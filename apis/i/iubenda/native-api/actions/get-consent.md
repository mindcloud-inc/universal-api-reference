# Get Consent with iubenda

Retrieves a consent from iubenda.

## Endpoint

- **Method:** `GET`
- **Path:** `/consent/:id`
- **Base URL:** `https://consent.iubenda.com`
- **Official documentation:** [Get Consent](https://www.iubenda.com/en/help/6484-consent-solution-http-api-documentation/#consent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the consent event |
