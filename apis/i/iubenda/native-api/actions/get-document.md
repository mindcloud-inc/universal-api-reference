# Get Document with iubenda

Retrieves a document from iubenda.

## Endpoint

- **Method:** `GET`
- **Path:** `/beta/documents/:id`
- **Base URL:** `https://consent.iubenda.com`
- **Official documentation:** [Get Document](https://www.iubenda.com/en/help/6484-consent-solution-http-api-documentation/#document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the document |
