# Get Subject with iubenda

Retrieves a subject from iubenda.

## Endpoint

- **Method:** `GET`
- **Path:** `/subjects/:id`
- **Base URL:** `https://consent.iubenda.com`
- **Official documentation:** [Get Subject](https://www.iubenda.com/en/help/6484-consent-solution-http-api-documentation/#subjects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the subject |
