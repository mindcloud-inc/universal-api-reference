# Start Rotate Image Task with iLovePDFv2

Starts an image rotation task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/rotateimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Rotate Image Task](https://www.iloveapi.com/docs/api-reference)
