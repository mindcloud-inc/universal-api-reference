# Start Remove Image Background Task with iLovePDFv2

Starts an image background removal task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/removebackgroundimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Remove Image Background Task](https://www.iloveapi.com/docs/api-reference)
