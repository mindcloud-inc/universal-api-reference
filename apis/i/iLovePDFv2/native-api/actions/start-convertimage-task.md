# Start Convert Image Task with iLovePDFv2

Starts an image conversion task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/convertimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Convert Image Task](https://www.iloveapi.com/docs/api-reference)
