# Start Repair Image Task with iLovePDFv2

Starts an image repair task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/repairimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Repair Image Task](https://www.iloveapi.com/docs/api-reference)
