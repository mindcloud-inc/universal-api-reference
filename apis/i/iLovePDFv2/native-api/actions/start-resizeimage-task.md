# Start Resize Image Task with iLovePDFv2

Starts an image resize task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/resizeimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Resize Image Task](https://www.iloveapi.com/docs/api-reference)
