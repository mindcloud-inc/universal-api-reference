# Start Compress PDF Task with iLovePDFv2

Starts a PDF compression task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `/start/compress/:region`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Compress PDF Task](https://www.iloveapi.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `region` | path | `list` | yes | Processing region / jurisdiction. Accepted values: `0`, `1`, `2`, `3`, `4`. |
