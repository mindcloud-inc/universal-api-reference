# Get Auth Token with iLovePDFv2

Retrieves an auth token from iLovePDFv2.

## Endpoint

- **Method:** `POST`
- **Path:** `/auth`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Get Auth Token](https://www.iloveapi.com/docs/api-reference)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
