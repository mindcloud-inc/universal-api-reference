# Start Add Image Watermark Task with iLovePDFv2

Starts an image watermark task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/watermarkimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Add Image Watermark Task](https://www.iloveapi.com/docs/api-reference)
