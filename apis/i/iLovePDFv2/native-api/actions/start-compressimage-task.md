# Start Compress Image Task with iLovePDFv2

Starts an image compression task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/compressimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Compress Image Task](https://www.iloveapi.com/docs/api-reference)
