# Start Upscale Image Task with iLovePDFv2

Starts an image upscaling task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/upscaleimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Upscale Image Task](https://www.iloveapi.com/docs/api-reference)
