# Void Signature with iLovePDFv2

## Endpoint

- **Method:** `POST`
- **Path:** `/signature/void/:token_requester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Void Signature](https://www.iloveapi.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token_requester` | path | `string` | yes | Signature requester token to void. |
