# Start Crop Image Task with iLovePDFv2

Starts an image cropping task in iLovePDFv2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.iloveimg.com/v1/start/cropimage`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Start Crop Image Task](https://www.iloveapi.com/docs/api-reference)
