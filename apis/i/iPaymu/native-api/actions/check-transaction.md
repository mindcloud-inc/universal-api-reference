# Check Transaction with iPaymu

Get realtime details and status for an iPaymu transaction.

## Endpoint

- **Method:** `POST`
- **Path:** `/transaction`
- **Base URL:** `https://my.ipaymu.com/api/v2`
- **Official documentation:** [Check Transaction](https://ipaymu.com/api-collection/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | body | `number` | yes | iPaymu transaction identifier. |
