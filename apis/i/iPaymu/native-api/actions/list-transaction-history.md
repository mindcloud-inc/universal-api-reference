# List Transaction History with iPaymu

List your iPaymu transaction history.

## Endpoint

- **Method:** `POST`
- **Path:** `/history`
- **Base URL:** `https://my.ipaymu.com/api/v2`
- **Official documentation:** [List Transaction History](https://ipaymu.com/api-collection/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | body | `number` | no | Page number. |
| `limit` | body | `number` | no | Number of records to return. |
