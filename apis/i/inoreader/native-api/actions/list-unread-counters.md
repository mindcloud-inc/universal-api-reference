# List Unread Counters with Inoreader

Retrieves unread counters from Inoreader.

## Endpoint

- **Method:** `GET`
- **Path:** `/unread-count`
- **Base URL:** `https://www.inoreader.com/reader/api/0`
- **Official documentation:** [List Unread Counters](https://www.inoreader.com/developers/unread-counts)
