# Get Report with imgix

Retrieves a report from imgix.

## Endpoint

- **Method:** `GET`
- **Path:** `reports/:reportId`
- **Base URL:** `https://api.imgix.com/api/v1`
- **Official documentation:** [Get Report](https://docs.imgix.com/en-US/apis/management/reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | The imgix report id. |
