# Update Source with imgix

Updates a source in imgix.

## Endpoint

- **Method:** `PATCH`
- **Path:** `sources/:sourceId`
- **Base URL:** `https://api.imgix.com/api/v1`
- **Official documentation:** [Update Source](https://docs.imgix.com/en-US/apis/management/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `string` | yes | The imgix source_id. |
