# Get Setup Status with InfluxDB Cloud

Retrieves setup status from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/setup`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [Get Setup Status](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetSetup)
