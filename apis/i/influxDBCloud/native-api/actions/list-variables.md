# List Variables with InfluxDB Cloud

Retrieves variables from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/variables`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Variables](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetVariables)
