# Get Query Suggestions with InfluxDB Cloud

Retrieves query suggestions from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/query/suggestions`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [Get Query Suggestions](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetQuerySuggestions)
