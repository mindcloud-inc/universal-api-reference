# List Notification Endpoints with InfluxDB Cloud

Retrieves notification endpoints from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/notificationEndpoints`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Notification Endpoints](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetNotificationEndpoints)
