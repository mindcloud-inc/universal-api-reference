# List Notification Rules with InfluxDB Cloud

Retrieves notification rules from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/notificationRules`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Notification Rules](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetNotificationRules)
