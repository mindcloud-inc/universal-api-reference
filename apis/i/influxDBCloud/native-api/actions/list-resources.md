# List Resources with InfluxDB Cloud

Retrieves resources from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Resources](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetResources)
