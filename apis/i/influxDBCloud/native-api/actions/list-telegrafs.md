# List Telegrafs with InfluxDB Cloud

Retrieves Telegrafs from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/telegrafs`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Telegrafs](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetTelegrafs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of Telegraf configurations to return. |
