# Get Flags with InfluxDB Cloud

Retrieves feature flags from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/flags`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [Get Flags](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetFlags)
