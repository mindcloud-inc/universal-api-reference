# List Checks with InfluxDB Cloud

Retrieves checks from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/checks`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [List Checks](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetChecks)
