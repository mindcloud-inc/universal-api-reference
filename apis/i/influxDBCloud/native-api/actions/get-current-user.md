# Get Current User with InfluxDB Cloud

Retrieves the current user from InfluxDB Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://us-east-1-1.aws.cloud2.influxdata.com/api/v2`
- **Official documentation:** [Get Current User](https://docs.influxdata.com/influxdb/cloud/api/#operation/GetMe)
