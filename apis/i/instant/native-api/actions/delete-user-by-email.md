# Delete User by Email with Instant

Deletes a user from Instant by email.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/users`
- **Base URL:** `https://api.instantdb.com`
- **Official documentation:** [Delete User by Email](https://www.instantdb.com/docs/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | User email address to delete. |
