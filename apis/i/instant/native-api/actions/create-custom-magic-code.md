# Create Custom Magic Code with Instant

Creates a custom magic code in Instant.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/magic_code`
- **Base URL:** `https://api.instantdb.com`
- **Official documentation:** [Create Custom Magic Code](https://www.instantdb.com/docs/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | User email address to create a magic code for. |
