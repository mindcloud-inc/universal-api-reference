# Delete User by ID with Instant

Deletes a user from Instant by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/users`
- **Base URL:** `https://api.instantdb.com`
- **Official documentation:** [Delete User by ID](https://www.instantdb.com/docs/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Instant user ID to delete. |
