# Lookup ASN Route with IPLocate

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/:ip/asn.route`
- **Base URL:** `https://iplocate.io/api`
- **Official documentation:** [Lookup ASN Route](https://www.iplocate.io/docs/ip-intelligence-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | yes | IPv4 or IPv6 address to look up. |
