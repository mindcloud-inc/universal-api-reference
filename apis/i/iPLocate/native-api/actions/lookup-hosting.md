# Lookup Hosting with IPLocate

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/:ip/hosting`
- **Base URL:** `https://iplocate.io/api`
- **Official documentation:** [Lookup Hosting](https://www.iplocate.io/docs/guides/detect-hosting-traffic)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | yes | IPv4 or IPv6 address to inspect. |
