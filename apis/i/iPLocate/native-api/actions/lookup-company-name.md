# Lookup Company Name with IPLocate

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/:ip/company.name`
- **Base URL:** `https://iplocate.io/api`
- **Official documentation:** [Lookup Company Name](https://www.iplocate.io/docs/ip-intelligence-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | path | `string` | yes | IPv4 or IPv6 address to inspect. |
