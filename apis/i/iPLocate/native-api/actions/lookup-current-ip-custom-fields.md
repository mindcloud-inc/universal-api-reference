# Lookup Current IP Custom Fields with IPLocate

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/`
- **Base URL:** `https://iplocate.io/api`
- **Official documentation:** [Lookup Current IP Custom Fields](https://www.iplocate.io/docs/ip-intelligence-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | yes | Comma-separated list of fields or nested fields to return. |
