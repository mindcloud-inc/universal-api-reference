# Delete Status Page with Instatus

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/:page_id`
- **Base URL:** `https://api.instatus.com`
- **Official documentation:** [Delete Status Page](https://instatus.com/help/api/status-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | path | `string` | yes | Instatus status page ID. |
