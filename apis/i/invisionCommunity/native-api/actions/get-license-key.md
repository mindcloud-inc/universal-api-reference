# Get License Key with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/nexus/lkey/:key`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get License Key](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | License key string. |
