# Get Download Comment with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/comments/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Download Comment](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Comment identifier. |
