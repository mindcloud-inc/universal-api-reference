# Get Download Review with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/reviews/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Download Review](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Review identifier. |
