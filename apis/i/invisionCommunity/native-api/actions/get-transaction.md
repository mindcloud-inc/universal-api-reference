# Get Transaction with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/nexus/transactions/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Transaction](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Transaction identifier. |
