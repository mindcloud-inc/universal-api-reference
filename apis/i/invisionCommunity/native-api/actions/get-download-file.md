# Get Download File with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/files/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Download File](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | File identifier. |
