# Get Topic with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/forums/topics/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Topic](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The topic identifier. |
