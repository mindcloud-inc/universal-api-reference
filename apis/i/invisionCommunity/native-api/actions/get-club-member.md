# Get Club Member with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/clubs/:id/members/:member`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Club Member](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Club identifier. |
| `member` | path | `number` | yes | Member identifier. |
