# Get CMS Review with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cms/reviews/:database_id/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get CMS Review](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | path | `number` | yes | Database identifier. |
| `id` | path | `number` | yes | Review identifier. |
