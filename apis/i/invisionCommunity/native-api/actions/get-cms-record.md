# Get CMS Record with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cms/records/:database_id/:record_id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get CMS Record](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | path | `number` | yes | Database identifier. |
| `record_id` | path | `number` | yes | Record identifier. |
