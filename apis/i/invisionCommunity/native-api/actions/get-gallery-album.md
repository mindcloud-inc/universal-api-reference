# Get Gallery Album with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/albums/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Gallery Album](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The album identifier. |
