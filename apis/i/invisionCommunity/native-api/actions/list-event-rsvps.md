# List Event RSVPs with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/events/:id/rsvps`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Event RSVPs](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Event identifier. |
