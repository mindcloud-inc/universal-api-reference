# List Member Follows with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/members/:id/follows`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Member Follows](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Member identifier. |
