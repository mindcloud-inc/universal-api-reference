# Get Download Category with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/categories/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Download Category](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Category identifier. |
