# Get CMS Category with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cms/databases/:database_id/:category_id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get CMS Category](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | path | `number` | yes | Database identifier. |
| `category_id` | path | `number` | yes | Category identifier. |
