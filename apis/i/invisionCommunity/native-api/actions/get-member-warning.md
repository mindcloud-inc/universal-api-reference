# Get Member Warning with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/members/:id/warning/:warning`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Member Warning](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Member identifier. |
| `warning` | path | `number` | yes | Warning identifier. |
