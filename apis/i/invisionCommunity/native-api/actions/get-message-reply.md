# Get Message Reply with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/messages/:id/reply/:replyId`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Message Reply](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Message identifier. |
| `replyId` | path | `number` | yes | Reply identifier. |
