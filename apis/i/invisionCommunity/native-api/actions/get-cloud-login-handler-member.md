# Get Cloud Login Handler Member with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cloud/loginhandlers/:handler_id/member/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Cloud Login Handler Member](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handler_id` | path | `string` | yes | Login handler identifier. |
| `id` | path | `number` | yes | Member identifier. |
