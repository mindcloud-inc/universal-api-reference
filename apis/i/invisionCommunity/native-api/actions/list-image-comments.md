# List Image Comments with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/images/:id/comments`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Image Comments](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The image identifier. |
