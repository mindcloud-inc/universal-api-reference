# Get Gallery Review with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/reviews/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Gallery Review](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The review identifier. |
