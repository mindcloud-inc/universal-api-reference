# Get Calendar with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/calendars/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Calendar](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The calendar identifier. |
