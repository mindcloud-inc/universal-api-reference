# List Image Reviews with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/images/:id/reviews`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Image Reviews](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Image identifier. |
