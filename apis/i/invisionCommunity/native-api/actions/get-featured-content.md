# Get Featured Content with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/promotions/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Featured Content](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Featured content identifier. |
