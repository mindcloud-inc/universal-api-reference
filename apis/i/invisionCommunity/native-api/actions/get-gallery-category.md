# Get Gallery Category with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/categories/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Gallery Category](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The gallery category identifier. |
