# Get Course with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/courses/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Course](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Course identifier. |
