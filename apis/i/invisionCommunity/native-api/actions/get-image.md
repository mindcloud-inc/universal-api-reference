# Get Image with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/gallery/images/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Image](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The image identifier. |
