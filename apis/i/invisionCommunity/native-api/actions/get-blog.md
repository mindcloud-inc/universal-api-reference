# Get Blog with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/blog/blogs/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Blog](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The blog identifier. |
