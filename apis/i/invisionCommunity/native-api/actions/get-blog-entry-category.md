# Get Blog Entry Category with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/blog/entrycategories/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Blog Entry Category](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Entry category identifier. |
