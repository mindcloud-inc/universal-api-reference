# Get Withdrawal with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/nexus/withdrawals/:id`
- **Base URL:** `{communityBaseUrl}/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Withdrawal identifier. |
