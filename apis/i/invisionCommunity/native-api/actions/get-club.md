# Get Club with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/clubs/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Club](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Club identifier. |
