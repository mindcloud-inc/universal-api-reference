# List Download File Reviews with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/files/:id/reviews`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Download File Reviews](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | File identifier. |
