# List Club Members with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/clubs/:id/members`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Club Members](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Club identifier. |
