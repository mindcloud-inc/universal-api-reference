# Get CMS Database with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cms/databases/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get CMS Database](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Database identifier. |
