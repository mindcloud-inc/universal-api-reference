# Get Purchase with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/nexus/purchases/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Purchase](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Purchase identifier. |
