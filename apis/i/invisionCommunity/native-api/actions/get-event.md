# Get Event with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/events/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Event](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event identifier. |
