# Get CMS Comment with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/cms/comments/:database_id/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get CMS Comment](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | path | `number` | yes | Database identifier. |
| `id` | path | `number` | yes | Comment identifier. |
