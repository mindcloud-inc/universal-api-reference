# Get Blog Entry with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/blog/entries/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Blog Entry](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The blog entry identifier. |
