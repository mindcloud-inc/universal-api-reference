# List Download File Comments with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/downloads/files/:id/comments`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Download File Comments](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | File identifier. |
