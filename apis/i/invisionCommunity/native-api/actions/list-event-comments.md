# List Event Comments with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/events/:id/comments`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [List Event Comments](https://invisioncommunity.com/developers/rest-api/index/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event identifier. |
