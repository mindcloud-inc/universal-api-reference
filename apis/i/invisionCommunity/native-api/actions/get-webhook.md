# Get Webhook with Invision Community

## Endpoint

- **Method:** `GET`
- **Path:** `/core/webhooks/:id`
- **Base URL:** `{communityBaseUrl}/api`
- **Official documentation:** [Get Webhook](https://invisioncommunity.com/developers/rest-api/index/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Webhook identifier. |
