# Delete Target with Intruder

## Endpoint

- **Method:** `DELETE`
- **Path:** `/targets/:id/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [Delete Target](https://developers.intruder.io/reference/targets_destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intruder target identifier. |
