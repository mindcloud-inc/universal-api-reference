# Cancel Scan with Intruder

## Endpoint

- **Method:** `POST`
- **Path:** `/scans/:id/cancel/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [Cancel Scan](https://developers.intruder.io/reference/scans_cancel_create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intruder scan identifier. |
