# Delete Scan Schedule with Intruder

## Endpoint

- **Method:** `DELETE`
- **Path:** `/scans/schedules/:id/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [Delete Scan Schedule](https://developers.intruder.io/reference/scans_schedules_destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Scan schedule ID. |
