# Retrieve Scan Details with Intruder

## Endpoint

- **Method:** `GET`
- **Path:** `/scans/:id/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [Retrieve Scan Details](https://developers.intruder.io/reference/scans_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Intruder scan identifier. |
