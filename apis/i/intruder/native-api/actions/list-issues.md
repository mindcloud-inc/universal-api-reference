# List Issues with Intruder

## Endpoint

- **Method:** `GET`
- **Path:** `/issues/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [List Issues](https://developers.intruder.io/reference/issues_list-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `since` | query | `string` | no | Filter issues first detected on or after this timestamp. |
