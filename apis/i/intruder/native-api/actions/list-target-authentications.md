# List Target Authentications with Intruder

## Endpoint

- **Method:** `GET`
- **Path:** `/targets/:target_id/authentications/`
- **Base URL:** `https://api.intruder.io/v1`
- **Official documentation:** [List Target Authentications](https://developers.intruder.io/reference/targets_authentications_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `target_id` | path | `string` | yes | The Intruder target identifier. |
