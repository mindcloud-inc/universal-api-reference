# Get Mediation Groups with ironSource

Retrieves mediation groups from ironSource.

## Endpoint

- **Method:** `GET`
- **Path:** `levelPlay/groups/v4/:appKey`
- **Base URL:** `https://platform.ironsrc.com/`
- **Official documentation:** [Get Mediation Groups](https://docs.unity.com/en-us/grow/levelplay/platform/api/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appKey` | path | `string` | no | Application key as seen on the LevelPlay platform. |
