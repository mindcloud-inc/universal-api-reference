# Get Placements with ironSource

Retrieves placements from ironSource.

## Endpoint

- **Method:** `GET`
- **Path:** `partners/publisher/placements/v1`
- **Base URL:** `https://platform.ironsrc.com/`
- **Official documentation:** [Get Placements](https://docs.unity.com/en-us/grow/levelplay/platform/api/placements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appKey` | query | `string` | no | Application key as seen on the LevelPlay platform. |
