# List Accounts with Instantly

Retrieves accounts from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/accounts`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [List Accounts](https://developer.instantly.ai/api/v2/account/listaccount)

## Capabilities

This operation supports [pagination](../README.md#pagination).
