# Resume Account with Instantly

Resumes an account in Instantly.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/accounts/:email/resume`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Resume Account](https://developer.instantly.ai/api/v2/account/resumeaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email of the account to resume. |
