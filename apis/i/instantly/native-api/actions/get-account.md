# Get Account with Instantly

Retrieves an account from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/accounts/:email`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Account](https://developer.instantly.ai/api/v2/account/getaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email of the account. |
