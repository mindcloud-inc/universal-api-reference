# Get Webhook with Instantly

Retrieves a webhook from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/webhooks/:id`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Webhook](https://developer.instantly.ai/api-reference/webhook/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook UUID. |
