# Get Lead List with Instantly

Retrieves a lead list from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/lead-lists/:id`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Lead List](https://developer.instantly.ai/api/v2/leadlist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lead list ID. |
