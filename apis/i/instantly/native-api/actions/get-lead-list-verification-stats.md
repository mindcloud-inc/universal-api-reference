# Get Lead List Verification Stats with Instantly

Retrieves lead list verification stats from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/lead-lists/:id/verification-stats`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Lead List Verification Stats](https://developer.instantly.ai/api/v2/leadlist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lead list ID. |
