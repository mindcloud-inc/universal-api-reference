# Search Campaigns By Contact with Instantly

Finds campaigns in Instantly by contact.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/campaigns/search-by-contact`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Search Campaigns By Contact](https://developer.instantly.ai/api/v2/campaign/searchbycontact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | Lead email to search campaigns by. |
