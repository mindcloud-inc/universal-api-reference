# Get Daily Campaign Analytics with Instantly

Retrieves daily campaign analytics from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/campaigns/analytics/daily`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Daily Campaign Analytics](https://developer.instantly.ai/api/v2/campaign/getdailycampaignanalytics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | query | `string` | no | Campaign ID for daily analytics. |
