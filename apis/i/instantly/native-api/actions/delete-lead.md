# Delete Lead with Instantly

Deletes an existing lead from Instantly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/leads/:id`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Delete Lead](https://developer.instantly.ai/api-reference/lead/delete-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lead ID. |
