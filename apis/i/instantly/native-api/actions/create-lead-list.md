# Create Lead List with Instantly

Creates a new lead list in Instantly.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/lead-lists`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Create Lead List](https://developer.instantly.ai/api-reference/leadlist/create-lead-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the lead list. |
