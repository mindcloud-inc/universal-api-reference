# Get Campaign with Instantly

Retrieves a campaign from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/campaigns/:id`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Campaign](https://developer.instantly.ai/api/v2/campaign/getcampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID. |
