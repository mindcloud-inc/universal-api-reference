# Get Campaign Analytics Overview with Instantly

Retrieves campaign analytics overview from Instantly.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/campaigns/analytics/overview`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Get Campaign Analytics Overview](https://developer.instantly.ai/api/v2/campaign/getcampaignanalyticsoverview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Campaign ID for analytics overview. |
