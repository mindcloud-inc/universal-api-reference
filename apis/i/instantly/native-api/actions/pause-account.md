# Pause Account with Instantly

Pauses an account in Instantly.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/accounts/:email/pause`
- **Base URL:** `https://api.instantly.ai`
- **Official documentation:** [Pause Account](https://developer.instantly.ai/api/v2/account/pauseaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email of the account to pause. |
