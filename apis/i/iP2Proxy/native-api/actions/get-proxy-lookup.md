# Get Proxy Lookup with IP2Proxy

Retrieves proxy details for an IP address from IP2Proxy.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.ip2proxy.com`
- **Official documentation:** [Get Proxy Lookup](https://www.ip2location.com/web-service/ip2proxy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | query | `string` | no | Public IPv4 or IPv6 address to look up. |
| `package` | query | `string` | no | IP2Proxy package tier to query. |
