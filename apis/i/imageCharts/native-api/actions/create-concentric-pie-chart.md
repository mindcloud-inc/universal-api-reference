# Create Concentric Pie Chart with Image-Charts

Creates a concentric pie chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Concentric Pie Chart](https://documentation.image-charts.com/pie-charts/#pie)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chd` | query | `string` | no | Chart data using Image-Charts data syntax. |
| `chs` | query | `string` | no | Chart image size in pixels as widthxheight. |
