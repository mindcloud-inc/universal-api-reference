# Create GraphViz Graph with Image-Charts

Creates a GraphViz graph with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create GraphViz Graph](https://documentation.image-charts.com/graph-viz-charts/#simple-graph)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chl` | query | `string` | yes |
