# Create Multi-Color Progress Bar Chart with Image-Charts

Creates a multi-color progress bar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Multi-Color Progress Bar Chart](https://documentation.image-charts.com/progress-bar-charts/#multiple-colors)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chd` | query | `string` | yes |
