# Create Simple Progress Bar Chart with Image-Charts

Creates a simple progress bar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Simple Progress Bar Chart](https://documentation.image-charts.com/progress-bar-charts/#simple)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chd` | query | `string` | yes |
