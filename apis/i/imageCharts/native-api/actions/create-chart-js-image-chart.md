# Create Chart.js Image Chart with Image-Charts

Creates a Chart.js image chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart.js/2.8.0`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Chart.js Image Chart](https://documentation.image-charts.com/chart-js/#chart-definition)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chart` | query | `string` | yes |
