# Create GraphViz Subgraph Layout with Image-Charts

Creates a GraphViz subgraph layout with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create GraphViz Subgraph Layout](https://documentation.image-charts.com/graph-viz-charts/#subgraphs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chl` | query | `string` | yes |
