# Create QR Code SVG with Image-Charts

Creates an SVG QR code image with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create QR Code SVG](https://documentation.image-charts.com/qr-codes/#output-format)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chl` | query | `string` | yes |
