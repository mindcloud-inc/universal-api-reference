# Create Radar Chart with Image-Charts

Creates a radar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Radar Chart](https://documentation.image-charts.com/radar-charts/#chart-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chs` | query | `string` | no | Chart size in pixels as widthxheight. |
| `chd` | query | `string` | no | Chart data using Image-Charts data syntax. |
