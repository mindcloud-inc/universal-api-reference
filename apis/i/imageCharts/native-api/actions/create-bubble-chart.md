# Create Bubble Chart with Image-Charts

Creates a bubble chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Bubble Chart](https://documentation.image-charts.com/bubble-charts/#chart-types)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chd` | query | `string` | yes |
