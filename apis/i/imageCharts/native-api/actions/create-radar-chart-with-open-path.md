# Create Radar Chart With Open Path with Image-Charts

Creates an open-path radar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Radar Chart With Open Path](https://documentation.image-charts.com/radar-charts/#chart-type)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chd` | query | `string` | yes |
