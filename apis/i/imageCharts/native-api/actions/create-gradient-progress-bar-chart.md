# Create Gradient Progress Bar Chart with Image-Charts

Creates a gradient progress bar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Gradient Progress Bar Chart](https://documentation.image-charts.com/progress-bar-charts/#gradient-background)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chs` | query | `string` | yes |
| `chd` | query | `string` | yes |
