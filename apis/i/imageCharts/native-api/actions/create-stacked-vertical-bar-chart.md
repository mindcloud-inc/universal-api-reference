# Create Stacked Vertical Bar Chart with Image-Charts

Creates a stacked vertical bar chart with Image-Charts.

## Endpoint

- **Method:** `GET`
- **Path:** `/chart`
- **Base URL:** `https://image-charts.com`
- **Official documentation:** [Create Stacked Vertical Bar Chart](https://documentation.image-charts.com/bar-charts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chd` | query | `string` | no | Chart data using Image-Charts data syntax. |
| `chs` | query | `string` | no | Chart image size in pixels as widthxheight. |
