# Image-Charts: Native API Reference

A consolidated summary of Image-Charts's API configuration and 30 documented operations, with links to official documentation.

- **Official docs:** https://documentation.image-charts.com/
- **API base URL:** `https://image-charts.com`

## Authentication

### No Authentication

Public Image-Charts chart generation requires no authentication for the baseline API.

This API does not require request authentication.

[Official authentication documentation](https://documentation.image-charts.com/)
