# List Signatures with iLoveSign

## Endpoint

- **Method:** `GET`
- **Path:** `/signature/list`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [List Signatures](https://www.iloveapi.com/docs/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Zero-based results page. |
| `per-page` | query | `number` | no | Maximum number of signatures to return. |
