# Get Receiver Info with iLoveSign

## Endpoint

- **Method:** `GET`
- **Path:** `/signature/receiver/info/:receiver_token_requester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Get Receiver Info](https://www.iloveapi.com/docs/api-reference#get-signer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `receiver_token_requester` | path | `string` | yes | Receiver token requester identifier. |
