# Void Signature with iLoveSign

## Endpoint

- **Method:** `PUT`
- **Path:** `/signature/void/:token_requester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Void Signature](https://www.iloveapi.com/docs/api-reference#signature-void)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token_requester` | path | `string` | yes | Signature request token requester identifier. |
