# Send Reminder with iLoveSign

## Endpoint

- **Method:** `POST`
- **Path:** `/signature/sendReminder/:token_requester`
- **Base URL:** `https://api.ilovepdf.com/v1`
- **Official documentation:** [Send Reminder](https://www.iloveapi.com/docs/api-reference#send-reminders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token_requester` | path | `string` | yes | Signature request token requester identifier. |
