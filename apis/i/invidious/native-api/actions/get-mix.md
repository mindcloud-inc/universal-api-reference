# Get Mix with Invidious

## Endpoint

- **Method:** `GET`
- **Path:** `/mixes/:rdid`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Mix](https://docs.invidious.io/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rdid` | path | `string` | yes | Mix/radio playlist ID. |
