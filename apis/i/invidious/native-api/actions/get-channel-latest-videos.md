# Get Channel Latest Videos with Invidious

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:id/latest`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Channel Latest Videos](https://docs.invidious.io/api/channels_endpoint/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Channel UCID. |
