# Get Search Suggestions with Invidious

## Endpoint

- **Method:** `GET`
- **Path:** `/search/suggestions`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Search Suggestions](https://docs.invidious.io/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Search text for suggestions. |
