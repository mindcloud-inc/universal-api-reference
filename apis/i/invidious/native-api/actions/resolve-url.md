# Resolve URL with Invidious

## Endpoint

- **Method:** `GET`
- **Path:** `/resolveurl`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Resolve URL](https://docs.invidious.io/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | YouTube or Invidious URL to resolve. |
