# Get Auth Feed with Invidious

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/feed`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Get Auth Feed](https://docs.invidious.io/api/authenticated-endpoints/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max_results` | query | `number` | no | Maximum feed results. |
| `page` | query | `number` | no | Feed page number. |
