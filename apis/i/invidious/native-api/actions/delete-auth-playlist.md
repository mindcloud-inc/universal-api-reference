# Delete Auth Playlist with Invidious

## Endpoint

- **Method:** `DELETE`
- **Path:** `/auth/playlists/:id`
- **Base URL:** `{instanceUrl}/api/v1`
- **Official documentation:** [Delete Auth Playlist](https://docs.invidious.io/api/authenticated-endpoints/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Authenticated playlist ID. |
