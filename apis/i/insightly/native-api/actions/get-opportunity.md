# Get Opportunity with Insightly

Retrieves an opportunity from Insightly by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `{apiBaseUrl}Opportunities/:opportunityId`
- **Base URL:** `https://api.na1.insightly.com/v3.1/`
- **Official documentation:** [Get Opportunity](https://api.insightly.com/v3.1/Help#!/Opportunities/GetEntity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `opportunityId` | path | `number` | yes | The Opportunity ID. |
