# Get Contact with Insightly

Retrieves a contact from Insightly by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `{apiBaseUrl}Contacts/:contactId`
- **Base URL:** `https://api.na1.insightly.com/v3.1/`
- **Official documentation:** [Get Contact](https://api.insightly.com/v3.1/Help#!/Contacts/GetEntity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | The Contact ID. |
