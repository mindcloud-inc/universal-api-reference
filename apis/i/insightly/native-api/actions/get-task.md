# Get Task with Insightly

Retrieves a task from Insightly by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `{apiBaseUrl}Tasks/:taskId`
- **Base URL:** `https://api.na1.insightly.com/v3.1/`
- **Official documentation:** [Get Task](https://api.insightly.com/v3.1/Help#!/Tasks/GetEntity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `number` | yes | The Task ID. |
