# Get Organisation with Insightly

Retrieves an organisation from Insightly by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `{apiBaseUrl}Organisations/:organisationId`
- **Base URL:** `https://api.na1.insightly.com/v3.1/`
- **Official documentation:** [Get Organisation](https://api.insightly.com/v3.1/Help#!/Organisations/GetEntity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organisationId` | path | `number` | yes | The Organisation ID. |
