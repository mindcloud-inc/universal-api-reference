# Get Lead with Insightly

Retrieves a lead from Insightly by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `{apiBaseUrl}Leads/:leadId`
- **Base URL:** `https://api.na1.insightly.com/v3.1/`
- **Official documentation:** [Get Lead](https://api.insightly.com/v3.1/Help#!/Leads/GetEntity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `number` | yes | The Lead ID. |
