# Add Lead with Minelead

Creates a new lead in Minelead.

## Endpoint

- **Method:** `POST`
- **Path:** `/leads/`
- **Base URL:** `https://api.minelead.io/v1`
- **Official documentation:** [Add Lead](https://api.minelead.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `list<string>` | yes | Email addresses to add to your leads. |
