# Delete Lead with Minelead

Deletes an existing lead from Minelead.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/`
- **Base URL:** `https://api.minelead.io/v1`
- **Official documentation:** [Delete Lead](https://api.minelead.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `list<string>` | yes | Email addresses to remove from your leads. |
