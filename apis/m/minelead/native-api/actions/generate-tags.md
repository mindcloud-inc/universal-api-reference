# Generate Tags with Minelead

## Endpoint

- **Method:** `POST`
- **Path:** `/tags/`
- **Base URL:** `https://api.minelead.io/v1`
- **Official documentation:** [Generate Tags](https://api.minelead.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tags` | body | `list<string>` | yes | List of tags to generate. |
