# Update Lead with Minelead

Updates an existing lead in Minelead.

## Endpoint

- **Method:** `PUT`
- **Path:** `/leads/`
- **Base URL:** `https://api.minelead.io/v1`
- **Official documentation:** [Update Lead](https://api.minelead.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `list<string>` | yes | Email addresses to update in your leads. |
