# Get Team with Mailform

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id`
- **Base URL:** `https://www.mailform.io/app/api/v1`
- **Official documentation:** [Get Team](https://www.mailform.io/docs/api/#get-a-specific-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | yes | ID of the team to retrieve. |
