# Get Order with Mailform

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:order_id`
- **Base URL:** `https://www.mailform.io/app/api/v1`
- **Official documentation:** [Get Order](https://www.mailform.io/docs/api/#get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | ID of the order to retrieve. |
