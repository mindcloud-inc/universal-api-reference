# Get Campaign with ManyReach

Retrieves a campaign from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/campaigns/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Campaign](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier of the campaign to retrieve. |
