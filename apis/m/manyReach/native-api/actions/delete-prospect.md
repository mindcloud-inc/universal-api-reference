# Delete Prospect with ManyReach

Deletes an existing prospect from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/prospects/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Prospect](https://api.manyreach.com/api#v2/tag/prospect)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Prospect ID. |
