# Create Workspace with ManyReach

Creates a new workspace in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/workspaces`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Create Workspace](https://api.manyreach.com/api#v2/tag/workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Workspace title. |
