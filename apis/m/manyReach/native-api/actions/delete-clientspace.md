# Delete Clientspace with ManyReach

Deletes an existing clientspace from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/clientspaces/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Clientspace](https://api.manyreach.com/api#v2/tag/clientspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the clientspace to delete. |
