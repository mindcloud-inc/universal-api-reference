# Delete Mailing List with ManyReach

Deletes an existing mailing list from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/lists/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Mailing List](https://api.manyreach.com/api#v2/tag/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | List ID. |
