# Delete Workspace with ManyReach

Deletes an existing workspace from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/workspaces/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Workspace](https://api.manyreach.com/api#v2/tag/workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Workspace ID. |
