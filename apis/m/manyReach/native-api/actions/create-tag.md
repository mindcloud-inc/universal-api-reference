# Create Tag with ManyReach

Creates a new tag in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/tags`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Create Tag](https://api.manyreach.com/api#v2/tag/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Tag title. |
