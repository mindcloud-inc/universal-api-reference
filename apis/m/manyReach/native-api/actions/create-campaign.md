# Create Campaign with ManyReach

Creates a new campaign in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/campaigns`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Create Campaign](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Campaign name. |
