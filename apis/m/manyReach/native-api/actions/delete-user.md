# Delete User with ManyReach

Deletes an existing user from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/users/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete User](https://api.manyreach.com/api#v2/tag/user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the user to delete. |
