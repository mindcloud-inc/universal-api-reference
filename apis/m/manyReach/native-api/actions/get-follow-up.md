# Get Follow-Up with ManyReach

Retrieves a follow-up from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/followups/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Follow-Up](https://api.manyreach.com/api#v2/tag/followup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Followup ID. |
