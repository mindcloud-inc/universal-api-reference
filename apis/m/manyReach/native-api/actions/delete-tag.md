# Delete Tag with ManyReach

Deletes an existing tag from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/tags/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Tag](https://api.manyreach.com/api#v2/tag/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Tag ID. |
