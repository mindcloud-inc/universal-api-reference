# Delete Sequence with ManyReach

Deletes an existing sequence from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/sequences/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Sequence](https://api.manyreach.com/api#v2/tag/sequence)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Sequence ID. |
