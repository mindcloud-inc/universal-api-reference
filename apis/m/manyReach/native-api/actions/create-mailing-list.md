# Create Mailing List with ManyReach

Creates a new mailing list in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/lists`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Create Mailing List](https://api.manyreach.com/api#v2/tag/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | List title. |
