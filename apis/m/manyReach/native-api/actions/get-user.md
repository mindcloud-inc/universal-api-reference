# Get User with ManyReach

Retrieves a user from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/users/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get User](https://api.manyreach.com/api#v2/tag/user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | User ID. |
