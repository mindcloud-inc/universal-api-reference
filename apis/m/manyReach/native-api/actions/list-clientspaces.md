# List Clientspaces with ManyReach

Retrieves clientspaces from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/clientspaces`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Clientspaces](https://api.manyreach.com/api#v2/tag/clientspace)
