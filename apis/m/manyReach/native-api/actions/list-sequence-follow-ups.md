# List Sequence Follow-Ups with ManyReach

Retrieves follow-ups for a sequence from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/sequences/:id/followups`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Sequence Follow-Ups](https://api.manyreach.com/api#v2/tag/sequence)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Sequence ID. |
