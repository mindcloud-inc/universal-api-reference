# List Tag Prospects with ManyReach

Retrieves prospects for a tag from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/tags/:id/prospects`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Tag Prospects](https://api.manyreach.com/api#v2/tag/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Tag ID. |
