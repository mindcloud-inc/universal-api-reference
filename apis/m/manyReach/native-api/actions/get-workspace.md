# Get Workspace with ManyReach

Retrieves a workspace from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/workspaces/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Workspace](https://api.manyreach.com/api#v2/tag/workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Workspace ID. |
