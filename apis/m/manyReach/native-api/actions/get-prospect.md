# Get Prospect with ManyReach

Retrieves a prospect from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/prospects/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Prospect](https://api.manyreach.com/api#v2/tag/prospect)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Prospect ID. |
