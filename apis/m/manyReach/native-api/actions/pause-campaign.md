# Pause Campaign with ManyReach

Pauses a campaign in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/campaigns/:id/pause`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Pause Campaign](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the campaign to pause. |
