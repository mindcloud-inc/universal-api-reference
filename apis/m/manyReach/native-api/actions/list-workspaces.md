# List Workspaces with ManyReach

Retrieves workspaces from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/workspaces`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Workspaces](https://api.manyreach.com/api#v2/tag/workspace)
