# Create Campaign Copy with ManyReach

Creates a copy of a campaign in ManyReach.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.manyreach.com/api/v2/campaigns/:id/copy`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Create Campaign Copy](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Campaign ID. |
