# List Prospect Tags with ManyReach

Retrieves tags for a prospect from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/prospects/:id/tags`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Prospect Tags](https://api.manyreach.com/api#v2/tag/prospect)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Prospect ID. |
