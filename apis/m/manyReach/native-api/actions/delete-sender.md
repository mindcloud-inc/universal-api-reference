# Delete Sender with ManyReach

Deletes an existing sender from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/senders/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Sender](https://api.manyreach.com/api#v2/tag/sender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the sender to delete. |
