# Get Clientspace with ManyReach

Retrieves a clientspace from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/clientspaces/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Clientspace](https://api.manyreach.com/api#v2/tag/clientspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the clientspace to retrieve. |
