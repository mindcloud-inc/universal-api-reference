# Get Mailing List with ManyReach

Retrieves a mailing list from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/lists/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Mailing List](https://api.manyreach.com/api#v2/tag/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | List ID. |
