# Delete Campaign with ManyReach

Deletes an existing campaign from ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/campaigns/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Delete Campaign](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the campaign to delete. |
