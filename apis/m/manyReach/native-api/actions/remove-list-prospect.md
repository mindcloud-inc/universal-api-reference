# Remove List Prospect with ManyReach

Deletes a prospect from a mailing list in ManyReach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.manyreach.com/api/v2/lists/:id/prospects/:prospectId`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Remove List Prospect](https://api.manyreach.com/api#v2/tag/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | List ID. |
| `prospectId` | path | `string` | no | Prospect ID. |
