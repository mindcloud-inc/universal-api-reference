# Get Sender with ManyReach

Retrieves a sender from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/senders/:id`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [Get Sender](https://api.manyreach.com/api#v2/tag/sender)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the sender to retrieve. |
