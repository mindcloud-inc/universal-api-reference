# List Campaign Sequences with ManyReach

Retrieves sequences for a campaign from ManyReach.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.manyreach.com/api/v2/campaigns/:id/sequences`
- **Base URL:** `https://api.manyreach.com`
- **Official documentation:** [List Campaign Sequences](https://api.manyreach.com/api#v2/tag/campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Campaign ID for fetching sequences. |
