# Get Form with Moaform

Retrieves a form from your Moaform account.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId`
- **Base URL:** `https://api.moaform.com/v1`
- **Official documentation:** [Get Form](https://help.moaform.com/hc/en-us/articles/28407590441241-Fetching-Form-Details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `string` | yes | Unique ID of the form. |
