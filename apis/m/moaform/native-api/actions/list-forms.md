# List Forms with Moaform

Retrieves forms from your Moaform account.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://api.moaform.com/v1`
- **Official documentation:** [List Forms](https://help.moaform.com/hc/en-us/articles/28291726457497-Fetching-Form-List)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search forms by title. |
