# Get Project with Moskit

Retrieves a project from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:id`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [Get Project](https://moskit.stoplight.io/docs/api-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Moskit project ID. |
