# List Deals with Moskit

Retrieves deals from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `deals`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Deals](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
