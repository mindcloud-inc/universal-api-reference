# Get Company with Moskit

Retrieves a company from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:id`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [Get Company](https://moskit.stoplight.io/docs/api-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Moskit company ID. |
