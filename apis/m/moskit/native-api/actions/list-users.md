# List Users with Moskit

Retrieves users from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `users`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Users](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
