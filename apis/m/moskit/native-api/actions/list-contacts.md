# List Contacts with Moskit

Retrieves contacts from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Contacts](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
