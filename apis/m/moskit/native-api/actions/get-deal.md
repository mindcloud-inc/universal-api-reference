# Get Deal with Moskit

Retrieves a deal from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `deals/:id`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [Get Deal](https://moskit.stoplight.io/docs/api-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Moskit deal ID. |
