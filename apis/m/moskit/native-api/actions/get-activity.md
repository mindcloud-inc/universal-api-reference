# Get Activity with Moskit

Retrieves an activity from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `activities/:id`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [Get Activity](https://moskit.stoplight.io/docs/api-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Moskit activity ID. |
