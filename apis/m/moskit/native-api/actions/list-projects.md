# List Projects with Moskit

Retrieves projects from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `projects`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Projects](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
