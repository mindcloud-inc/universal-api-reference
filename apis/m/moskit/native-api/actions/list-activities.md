# List Activities with Moskit

Retrieves activities from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `activities`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Activities](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
