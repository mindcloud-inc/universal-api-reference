# List Companies with Moskit

Retrieves companies from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `companies`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [List Companies](https://moskit.stoplight.io/docs/api-v2/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
