# Get Contact with Moskit

Retrieves a contact from Moskit.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/:id`
- **Base URL:** `https://api.ms.prod.moskit.services/v2`
- **Official documentation:** [Get Contact](https://moskit.stoplight.io/docs/api-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Moskit contact ID. |
