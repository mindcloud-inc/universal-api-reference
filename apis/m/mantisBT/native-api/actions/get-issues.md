# Get Issues with MantisBT

Retrieves issues from your MantisBT workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues`
- **Base URL:** `{baseUrl}/api/rest`
- **Official documentation:** [Get Issues](https://github.com/mantisbt/mantisbt/blob/release-2.28.0/api/rest/mantisbt_openapi.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
