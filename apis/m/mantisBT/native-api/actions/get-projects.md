# Get Projects with MantisBT

Retrieves available projects from the MantisBT workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `{baseUrl}/api/rest`
- **Official documentation:** [Get Projects](https://github.com/mantisbt/mantisbt/blob/release-2.28.0/api/rest/mantisbt_openapi.yaml)
