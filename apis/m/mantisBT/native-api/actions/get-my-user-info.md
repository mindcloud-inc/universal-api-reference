# Get My User Info with MantisBT

Retrieves the current user from MantisBT.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me`
- **Base URL:** `{baseUrl}/api/rest`
- **Official documentation:** [Get My User Info](https://github.com/mantisbt/mantisbt/blob/release-2.28.0/api/rest/mantisbt_openapi.yaml)
