# Delete Search with Melo

Deletes an existing search from Melo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/searches/:id`
- **Base URL:** `https://preprod-api.notif.immo`
- **Official documentation:** [Delete Search](https://docs.melo.io/api-reference/endpoint/searches/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Search resource identifier. |
