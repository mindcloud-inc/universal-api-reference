# Get Search with Melo

Retrieves details for an existing search from Melo.

## Endpoint

- **Method:** `GET`
- **Path:** `/searches/:id`
- **Base URL:** `https://preprod-api.notif.immo`
- **Official documentation:** [Get Search](https://docs.melo.io/api-reference/endpoint/searches/get_single)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Search resource identifier. |
