# Delete E-commerce Store with Mailchimp

Deletes an existing e-commerce store from Mailchimp.

## Endpoint

- **Method:** `DELETE`
- **Path:** `ecommerce/stores/:store_id`
- **Base URL:** `https://{serverPrefix}.api.mailchimp.com/3.0/`
- **Official documentation:** [Delete E-commerce Store](https://us22.api.mailchimp.com/schema/3.0/Paths/Ecommerce/Stores/Instance.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `store_id` | path | `string` | yes |
