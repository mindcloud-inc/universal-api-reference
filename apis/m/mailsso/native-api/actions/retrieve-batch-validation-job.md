# Retrieve Batch Validation Job with mails.so

Retrieves a batch validation job from mails.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch/:id`
- **Base URL:** `https://api.mails.so/v1`
- **Official documentation:** [Retrieve Batch Validation Job](https://docs.mails.so/bulk/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Batch validation job ID |
