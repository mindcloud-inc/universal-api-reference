# Validate Email with mails.so

Retrieves email validation results from mails.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate`
- **Base URL:** `https://api.mails.so/v1`
- **Official documentation:** [Validate Email](https://docs.mails.so/single/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to validate |
