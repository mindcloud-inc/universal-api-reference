# Get Interval Types with Moodo & Moodo AIR

Retrieves interval types from Moodo & Moodo AIR.

## Endpoint

- **Method:** `GET`
- **Path:** `/interval`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Get Interval Types](https://rest.moodo.co/#/interval/get_interval_types)
