# Delete Favorite with Moodo & Moodo AIR

Deletes an existing favorite from Moodo & Moodo AIR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/favorites/:id`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Delete Favorite](https://rest.moodo.co/#/favorites/delete_favorite)
