# Search Box Favorites with Moodo & Moodo AIR

Finds favorites for a Moodo box by title.

## Endpoint

- **Method:** `GET`
- **Path:** `/favorites/:filter_my_favorites/:device_key/:search_favorite_title`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Search Box Favorites](https://rest.moodo.co/#/favorites/search_box_favorites)
