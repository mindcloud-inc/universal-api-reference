# Set Box Intensity with Moodo & Moodo AIR

Updates a Moodo box's main fan intensity.

## Endpoint

- **Method:** `POST`
- **Path:** `/intensity/:device_key`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Set Box Intensity](https://rest.moodo.co/#/intensity/set_fan_volume)
