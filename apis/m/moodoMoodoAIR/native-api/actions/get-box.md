# Get Box with Moodo & Moodo AIR

Retrieves a Moodo box by device key.

## Endpoint

- **Method:** `GET`
- **Path:** `/boxes/:device_key`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Get Box](https://rest.moodo.co/#/boxes/get_box)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `device_key` | path | `number` | yes | Moodo box device key. |
