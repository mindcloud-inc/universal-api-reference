# Delete Schedule with Moodo & Moodo AIR

Deletes an existing schedule from Moodo & Moodo AIR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schedules/:id`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Delete Schedule](https://rest.moodo.co/#/schedules/delete_schedule)
