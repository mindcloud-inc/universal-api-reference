# List Box Favorites with Moodo & Moodo AIR

Retrieves favorites for a Moodo box configuration.

## Endpoint

- **Method:** `GET`
- **Path:** `/favorites/:filter_my_favorites/:device_key`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [List Box Favorites](https://rest.moodo.co/#/favorites/get_box_favorites)
