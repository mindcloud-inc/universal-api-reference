# Switch Box Mode with Moodo & Moodo AIR

Updates a Moodo box's mode between diffuser and purifier.

## Endpoint

- **Method:** `POST`
- **Path:** `/mode/:device_key`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Switch Box Mode](https://rest.moodo.co/#/mode/switch_box_mode)
