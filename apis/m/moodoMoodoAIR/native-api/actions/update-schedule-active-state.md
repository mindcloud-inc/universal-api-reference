# Update Schedule Active State with Moodo & Moodo AIR

Updates a schedule's active state in Moodo.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/schedules/:id`
- **Base URL:** `https://rest.moodo.co/api`
- **Official documentation:** [Update Schedule Active State](https://rest.moodo.co/#/schedules/schedule_active_state)
