# List Workspace Users with Moxie

Retrieves workspace users from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/users/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Workspace Users](https://help.withmoxie.com/en/articles/8260260-list-workspace-users)
