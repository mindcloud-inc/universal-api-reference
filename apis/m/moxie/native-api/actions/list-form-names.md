# List Form Names with Moxie

Retrieves form names from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/formNames/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Form Names](https://help.withmoxie.com/en/articles/8260225-list-form-names)
