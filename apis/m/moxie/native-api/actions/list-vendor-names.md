# List Vendor Names with Moxie

Retrieves vendor names from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/vendors/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Vendor Names](https://help.withmoxie.com/en/articles/8260220-list-vendor-names)
