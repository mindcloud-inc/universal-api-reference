# List Project Task Stages with Moxie

Retrieves project task stages from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/taskStages/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Project Task Stages](https://help.withmoxie.com/en/articles/8260242-list-project-task-stages)
