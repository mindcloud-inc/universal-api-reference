# List Pipeline Stages with Moxie

Retrieves pipeline stages from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/pipelineStages/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Pipeline Stages](https://help.withmoxie.com/en/articles/8260232-list-pipeline-stages)
