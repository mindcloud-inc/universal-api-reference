# Search Projects with Moxie

Finds projects in Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/projects/search`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [Search Projects](https://help.withmoxie.com/en/articles/8260204-search-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Optional client name filter if you only want projects for a specific client. |
