# Search Contacts with Moxie

Finds contacts in Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/contacts/search`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [Search Contacts](https://help.withmoxie.com/en/articles/8259974-search-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Optional search string that can match first, last, or email. |
