# List Invoice Templates with Moxie

Retrieves invoice templates from Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/invoiceTemplates/list`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [List Invoice Templates](https://help.withmoxie.com/en/articles/8260216-list-invoice-templates)
