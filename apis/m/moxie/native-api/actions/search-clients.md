# Search Clients with Moxie

Finds clients in Moxie.

## Endpoint

- **Method:** `GET`
- **Path:** `/action/clients/search`
- **Base URL:** `https://pod01.withmoxie.com/api/public`
- **Official documentation:** [Search Clients](https://help.withmoxie.com/en/articles/8163928-search-clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search text for matching clients. |
