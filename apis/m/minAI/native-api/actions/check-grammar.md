# Check grammar with 1minAI

Checks and corrects text grammar in 1minAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/features`
- **Base URL:** `https://api.1min.ai`
- **Official documentation:** [Check grammar](https://docs.1min.ai/docs/api/ai-for-writing/grammar-checker/grammar-checker-tag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
