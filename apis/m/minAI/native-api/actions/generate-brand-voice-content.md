# Generate brand voice content with 1minAI

Creates brand voice content in 1minAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/features`
- **Base URL:** `https://api.1min.ai`
- **Official documentation:** [Generate brand voice content](https://docs.1min.ai/docs/api/ai-for-writing/content-generator/content-generator-brand-voice)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `prompt` | body | `string` | yes |
| `tone` | body | `string` | no |
| `language` | body | `string` | no |
