# Create conversation with 1minAI

Creates a new conversation in 1minAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/conversations`
- **Base URL:** `https://api.1min.ai`
- **Official documentation:** [Create conversation](https://docs.1min.ai/docs/api/chat-with-ai-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | yes |
