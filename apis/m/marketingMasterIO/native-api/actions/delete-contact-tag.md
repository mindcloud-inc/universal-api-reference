# Delete Contact Tag with Marketing Master IO

Deletes an existing contact tag from Marketing Master IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/tags/:tag`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Delete Contact Tag](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tag` | path | `string` | yes |
