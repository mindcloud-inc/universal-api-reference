# Get Contact Book with Marketing Master IO

Retrieves a contact book from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/books/:book_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Contact Book](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `book_id` | path | `string` | yes |
