# Delete Contact with Marketing Master IO

Deletes an existing contact from Marketing Master IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/list/:contact_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Delete Contact](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
