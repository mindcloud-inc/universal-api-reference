# Get Facebook Page with Marketing Master IO

Retrieves an imported Facebook page from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/facebook_pages/:page_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Facebook Page](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page_id` | path | `string` | yes |
