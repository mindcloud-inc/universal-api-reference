# Get Chat Sequence with Marketing Master IO

Retrieves a chat sequence from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/chat_sequences/:chat_sequence_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Chat Sequence](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chat_sequence_id` | path | `string` | yes |
