# Get Messenger Subscriber with Marketing Master IO

Retrieves a Messenger subscriber from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/subscriber/:subscriber_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Messenger Subscriber](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriber_id` | path | `string` | yes |
