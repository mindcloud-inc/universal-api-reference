# Create Contact Book with Marketing Master IO

Creates a new contact book in Marketing Master IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts/books`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Create Contact Book](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Contact book name. |
