# List Chat Sequences with Marketing Master IO

Retrieves chat sequences from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/chat_sequences`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [List Chat Sequences](https://developers.marketingmaster.io/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | query | `string` | no | Filter chat sequences by Facebook page ID. |
