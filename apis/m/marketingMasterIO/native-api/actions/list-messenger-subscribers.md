# List Messenger Subscribers with Marketing Master IO

Retrieves Messenger subscribers from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/subscriber`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [List Messenger Subscribers](https://developers.marketingmaster.io/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | query | `string` | no | Filter subscribers by Facebook page ID. |
