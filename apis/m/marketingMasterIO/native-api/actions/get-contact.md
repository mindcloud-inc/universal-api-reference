# Get Contact with Marketing Master IO

Retrieves a contact from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/list/:contact_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Contact](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
