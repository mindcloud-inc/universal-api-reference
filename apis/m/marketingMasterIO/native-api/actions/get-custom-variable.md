# Get Custom Variable with Marketing Master IO

Retrieves a custom variable from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/custom_variables/:variable_key`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Custom Variable](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variable_key` | path | `string` | yes |
