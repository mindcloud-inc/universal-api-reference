# Get Chatbot Flow with Marketing Master IO

Retrieves a chatbot flow from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/flows/:flow_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Chatbot Flow](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `flow_id` | path | `string` | yes |
