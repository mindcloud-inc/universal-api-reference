# Enable Facebook Page with Marketing Master IO

Enables an imported Facebook page in Marketing Master IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/facebook_pages/:page_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Enable Facebook Page](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page_id` | path | `string` | yes |
