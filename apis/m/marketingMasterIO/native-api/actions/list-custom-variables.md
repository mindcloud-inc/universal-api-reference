# List Custom Variables with Marketing Master IO

Retrieves custom variables from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/messenger/custom_variables`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [List Custom Variables](https://developers.marketingmaster.io/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
