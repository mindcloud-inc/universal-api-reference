# Get Google Sheet with Marketing Master IO

Retrieves a Google Sheet from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/google_sheets/:google_sheet_id`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [Get Google Sheet](https://developers.marketingmaster.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `google_sheet_id` | path | `string` | yes |
