# List Contact Books with Marketing Master IO

Retrieves contact books from Marketing Master IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/books`
- **Base URL:** `https://api.marketingmaster.io`
- **Official documentation:** [List Contact Books](https://developers.marketingmaster.io/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
