# Get Mobidi Folder Path with MOBIDI

Retrieves the configured MOBIDI folder path.

## Endpoint

- **Method:** `GET`
- **Path:** `/MobidiSettingsManagerHandler`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [Get Mobidi Folder Path](https://servis2.dece.com.tr/mobidisettingsmanagerhandler?op=.wsdl&loginWithGuest=1)
