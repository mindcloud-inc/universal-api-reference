# Check Sync Health with MOBIDI

Retrieves sync health details from MOBIDI.

## Endpoint

- **Method:** `GET`
- **Path:** `/MobidiServerSyncHandler?loginWithGuest=1`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [Check Sync Health](https://servis2.dece.com.tr/mobidiserversynchandler?op=.wsdl&loginWithGuest=1)
