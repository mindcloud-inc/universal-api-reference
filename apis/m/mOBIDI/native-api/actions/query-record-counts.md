# Query Record Counts with MOBIDI

Retrieves record counts for a MOBIDI query.

## Endpoint

- **Method:** `POST`
- **Path:** `/MobidiQueryManagerHandler`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [Query Record Counts](https://destek.dece.com.tr/space/PAR/1308295209/Mobidi+Server+Query+for+Record+Counts+API)
