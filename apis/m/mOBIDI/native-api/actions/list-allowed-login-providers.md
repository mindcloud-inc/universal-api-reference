# List Allowed Login Providers with MOBIDI

Retrieves allowed login providers from MOBIDI.

## Endpoint

- **Method:** `GET`
- **Path:** `/UserManagementService`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [List Allowed Login Providers](https://servis2.dece.com.tr/usermanagementservice?op=.wsdl&loginWithGuest=1)
