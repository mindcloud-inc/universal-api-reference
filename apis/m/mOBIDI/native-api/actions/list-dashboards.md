# List Dashboards with MOBIDI

Retrieves available dashboards from MOBIDI.

## Endpoint

- **Method:** `GET`
- **Path:** `/MobidiDashboardHandler`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [List Dashboards](https://servis2.dece.com.tr/mobididashboardhandler?op=.wsdl&loginWithGuest=1)
