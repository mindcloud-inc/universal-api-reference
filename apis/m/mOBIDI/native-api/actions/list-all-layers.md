# List All Layers with MOBIDI

Retrieves all layers from MOBIDI.

## Endpoint

- **Method:** `POST`
- **Path:** `/MobidiWorkspaceManagerHandler`
- **Base URL:** `https://servis2.dece.com.tr`
- **Official documentation:** [List All Layers](https://servis2.dece.com.tr/mobidiworkspacemanagerhandler?op=.wsdl&loginWithGuest=1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Token` | body | `string` | yes | MOBIDI workspace token. |
