# List Media Files with MindMe

Retrieves media files from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/AccountMedia/GetMediaLibraryByFilter`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Media Files](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1AccountMedia~1GetMediaLibraryByFilter/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `pageNumber` | query | `string` | no |
| `pageSize` | query | `string` | no |
| `userId` | query | `string` | no |
