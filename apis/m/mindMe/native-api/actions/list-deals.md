# List Deals with MindMe

Retrieves deals from MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/PipeLinesAndDeals/GetDealsGridData`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Deals](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1PipeLinesAndDeals~1GetDealsGridData/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pageNumber` | body | `string` | no |
| `pageSize` | body | `string` | no |
| `subAccountId` | body | `string` | no |
| `userId` | body | `string` | no |
