# Update Contact with MindMe

Updates an existing contact in MindMe.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/Contact/UpdateContact`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Update Contact](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1UpdateContact/put)
