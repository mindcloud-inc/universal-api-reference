# Get Access Token with MindMe

Retrieves an access token from MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Account/GetAccessToken`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Get Access Token](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Account~1GetAccessToken/post)
