# List Contact Lists with MindMe

Retrieves contact lists from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/List/GetLists`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Contact Lists](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1List~1GetLists/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
