# Create Automation with MindMe

Creates a new automation in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Automation/SaveAutomationSetting`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Automation](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Automation~1SaveAutomationSetting/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `parentAccountId` | body | `string` | no |
| `startSequenceType` | body | `string` | no |
| `status` | body | `string` | no |
| `subAccountId` | body | `string` | no |
| `userId` | body | `string` | no |
