# Upload Media File with MindMe

Uploads a media file to MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/AccountMedia/UploadMediaFile`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Upload Media File](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1AccountMedia~1UploadMediaFile/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `mediaLibrarySourceType` | query | `string` | no |
| `mediaType` | query | `string` | no |
| `userId` | query | `string` | no |
