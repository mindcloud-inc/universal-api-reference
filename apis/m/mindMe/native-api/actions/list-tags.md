# List Tags with MindMe

Retrieves tags from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Tag/GetAllTagsInSubAccounts`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Tags](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Tag~1GetAllTagsInSubAccounts/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parentAccountId` | query | `string` | no |
