# Create Deal with MindMe

Creates a new deal in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/PipeLinesAndDeals/SaveDeal`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Deal](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1PipeLinesAndDeals~1SaveDeal/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `amount` | body | `string` | no |
| `name` | body | `string` | no |
| `pipeLineId` | body | `string` | no |
| `stageId` | body | `string` | no |
| `subAccountId` | body | `string` | no |
| `userId` | body | `string` | no |
| `withContactId` | body | `string` | no |
