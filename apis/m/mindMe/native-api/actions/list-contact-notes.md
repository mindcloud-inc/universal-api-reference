# List Contact Notes with MindMe

Retrieves contact notes from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Contact/GetContactNotes`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Contact Notes](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1GetContactNotes/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | query | `string` | no |
| `subAccountId` | query | `string` | no |
| `userId` | query | `string` | no |
