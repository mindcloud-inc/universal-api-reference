# List Conversations with MindMe

Retrieves conversations from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Conversation/FilterConversations`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Conversations](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Conversation~1FilterConversations/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `inboxId` | query | `string` | no |
| `pageNumber` | query | `string` | no |
| `pageSize` | query | `string` | no |
| `parentAccountId` | query | `string` | no |
| `subAccountId` | query | `string` | no |
| `userId` | query | `string` | no |
