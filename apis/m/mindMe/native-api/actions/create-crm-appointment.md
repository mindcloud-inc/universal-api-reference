# Create CRM Appointment with MindMe

Creates a new CRM appointment in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/CRM/SaveAppointment`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create CRM Appointment](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1CRM~1SaveAppointment/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agenda` | body | `string` | no |
| `date` | body | `string` | no |
| `date` | body | `string` | no |
| `parentAccountId` | body | `string` | no |
| `subAccountId` | body | `string` | no |
| `typeId` | body | `string` | no |
| `userId` | body | `string` | no |
