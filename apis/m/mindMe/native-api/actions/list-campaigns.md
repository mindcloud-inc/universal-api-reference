# List Campaigns with MindMe

Retrieves campaigns from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Campaign/GetCampaignSummaryByFilter`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Campaigns](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Campaign~1GetCampaignSummaryByFilter/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `pageNumber` | query | `string` | no |
| `pageSize` | query | `string` | no |
