# Create CRM Task with MindMe

Creates a new CRM task in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/CRM/CreateTask`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create CRM Task](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1CRM~1CreateTask/post)
