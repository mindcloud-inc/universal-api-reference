# Get Campaign with MindMe

Retrieves a campaign from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Campaign/GetCampaignDetailByCampaignId`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Get Campaign](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Campaign~1GetCampaignDetailByCampaignId/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `campaignId` | query | `string` | no |
