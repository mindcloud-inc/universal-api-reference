# Get Contact with MindMe

Retrieves a contact from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Contact/GetContactById`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Get Contact](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1GetContactById/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `contactId` | query | `string` | no |
| `userId` | query | `string` | no |
