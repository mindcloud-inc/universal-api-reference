# Create Contact with MindMe

Creates a new contact in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Contact/CreateNewContact`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Contact](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1CreateNewContact/post)
