# Create Contact Note with MindMe

Creates a new contact note in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Contact/CreateContactNote`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Contact Note](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1CreateContactNote/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | body | `string` | no |
| `plainText` | body | `string` | no |
| `rawText` | body | `string` | no |
| `subAccountId` | body | `string` | no |
| `userId` | body | `string` | no |
