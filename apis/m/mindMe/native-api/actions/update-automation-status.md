# Update Automation Status with MindMe

Updates an automation status in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Automation/ChangeAutomationStatusById`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Update Automation Status](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Automation~1ChangeAutomationStatusById/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `automationId` | query | `string` | no |
