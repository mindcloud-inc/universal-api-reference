# List CRM Calendar Activities with MindMe

Retrieves CRM calendar activities from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/CRM/GetCRMCalendarActivities`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List CRM Calendar Activities](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1CRM~1GetCRMCalendarActivities/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parentAccountId` | query | `string` | no |
| `subAccountId` | query | `string` | no |
| `userId` | query | `string` | no |
