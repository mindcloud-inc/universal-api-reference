# Create Contact List with MindMe

Creates a new contact list in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/List/CreateList`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Contact List](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1List~1CreateList/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listName` | query | `string` | no |
| `subAccountId` | query | `string` | no |
