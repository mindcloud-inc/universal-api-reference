# Add Contacts To Sequence with MindMe

Adds contacts to a sequence in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Automation/AddContactsToSequence`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Add Contacts To Sequence](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Automation~1AddContactsToSequence/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filterId` | body | `string` | no |
| `filterType` | body | `string` | no |
| `sequenceId` | body | `string` | no |
