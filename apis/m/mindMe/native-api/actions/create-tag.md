# Create Tag with MindMe

Creates a new tag in MindMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Tag/CreateTag`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Create Tag](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Tag~1CreateTag/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subAccountId` | query | `string` | no |
| `tagName` | query | `string` | no |
