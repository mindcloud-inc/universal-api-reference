# List Custom Fields with MindMe

Retrieves custom fields from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/CustomFields/GetCustomFields`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Custom Fields](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1CustomFields~1GetCustomFields/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customFieldGroupFilter` | query | `string` | no |
| `customFieldGroupId` | query | `string` | no |
| `customFieldSearch` | query | `string` | no |
| `parentAccountId` | query | `string` | no |
| `sortColumnName` | query | `string` | no |
| `sortingDirection` | query | `string` | no |
| `subAccountId` | query | `string` | no |
| `userId` | query | `string` | no |
