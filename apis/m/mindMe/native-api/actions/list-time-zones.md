# List Time Zones with MindMe

Retrieves time zones from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/TimeZone/GetAllTimeZones`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Time Zones](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1TimeZone~1GetAllTimeZones/get)
