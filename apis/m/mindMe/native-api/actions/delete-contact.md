# Delete Contact with MindMe

Deletes an existing contact from MindMe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/Contact/DeleteContact`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [Delete Contact](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Contact~1DeleteContact/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | query | `string` | no |
| `contactId` | query | `string` | no |
| `userId` | query | `string` | no |
