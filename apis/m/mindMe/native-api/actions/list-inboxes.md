# List Inboxes with MindMe

Retrieves inboxes from MindMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Conversation/GetInboxes`
- **Base URL:** `https://prodapi.mindmemobile.com`
- **Official documentation:** [List Inboxes](https://prodapi.mindmemobile.com/swagger/v1/swagger.json#/paths/~1api~1Conversation~1GetInboxes/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `parentAccountId` | query | `string` | no |
| `subAccountId` | query | `string` | no |
| `userId` | query | `string` | no |
