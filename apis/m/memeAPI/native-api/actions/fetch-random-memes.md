# Fetch Random Memes with Meme API

## Endpoint

- **Method:** `GET`
- **Path:** `/gimme/:count`
- **Base URL:** `https://meme-api.com`
- **Official documentation:** [Fetch Random Memes](https://github.com/D3vd/Meme_Api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | path | `number` | yes | Required meme count (1-50). Maximum length: 50. |
