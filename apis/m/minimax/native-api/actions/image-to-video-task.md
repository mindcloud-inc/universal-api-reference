# Image-to-Video Task with Minimax

Creates an image-to-video task in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/video_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Image-to-Video Task](https://platform.minimax.io/docs/api-reference/video-generation-i2v)
