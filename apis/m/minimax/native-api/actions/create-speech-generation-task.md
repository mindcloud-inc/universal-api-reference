# Create Speech Generation Task with Minimax

Creates a speech generation task in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/t2a_async_v2`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Create Speech Generation Task](https://platform.minimax.io/docs/api-reference/speech-t2a-async-create)
