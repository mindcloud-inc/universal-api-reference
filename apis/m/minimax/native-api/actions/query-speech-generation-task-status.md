# Query Speech Generation Task Status with Minimax

Retrieves a speech generation task status from Minimax.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/query/t2a_async_query_v2`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Query Speech Generation Task Status](https://platform.minimax.io/docs/api-reference/speech-t2a-async-query)
