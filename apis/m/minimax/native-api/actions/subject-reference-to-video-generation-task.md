# Subject-Reference to Video Generation Task with Minimax

Creates a subject-reference video task in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/video_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Subject-Reference to Video Generation Task](https://platform.minimax.io/docs/api-reference/video-generation-s2v)
