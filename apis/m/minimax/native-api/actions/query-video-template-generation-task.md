# Query Video Template Generation Task with Minimax

Retrieves a video agent task status from Minimax.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/query/video_template_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Query Video Template Generation Task](https://platform.minimax.io/docs/api-reference/video-agent-query)
