# Query Video Generation Task Status with Minimax

Retrieves a video generation task status from Minimax.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/query/video_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Query Video Generation Task Status](https://platform.minimax.io/docs/api-reference/video-generation-query)
