# Text to Speech (T2A) HTTP with Minimax

Creates speech from text in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/t2a_v2`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Text to Speech (T2A) HTTP](https://platform.minimax.io/docs/api-reference/speech-t2a-http)
