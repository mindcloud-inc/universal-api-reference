# Create Text-to-Video Generation Task with Minimax

Creates a text-to-video generation task in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/video_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Create Text-to-Video Generation Task](https://platform.minimax.io/docs/api-reference/video-generation-t2v)
