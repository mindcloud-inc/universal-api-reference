# Create First & Last Frame Video Generation Task with Minimax

Creates a first-and-last-frame video task in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/video_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Create First & Last Frame Video Generation Task](https://platform.minimax.io/docs/api-reference/video-generation-fl2v)
