# Image-to-Image Generation with Minimax

Creates images from image input in Minimax.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/image_generation`
- **Base URL:** `https://api.minimax.io`
- **Official documentation:** [Image-to-Image Generation](https://platform.minimax.io/docs/api-reference/image-generation-i2i)
