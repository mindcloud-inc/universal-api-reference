# Delete File with Manus

Deletes a file from Manus and its stored content.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.manus.ai/v1`
- **Official documentation:** [Delete File](https://open.manus.ai/docs/v1/delete-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file to delete |
