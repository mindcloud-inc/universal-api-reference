# Delete Task with Manus

Deletes a task from Manus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:task_id`
- **Base URL:** `https://api.manus.ai/v1`
- **Official documentation:** [Delete Task](https://open.manus.ai/docs/v1/delete-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The ID of the task to delete |
