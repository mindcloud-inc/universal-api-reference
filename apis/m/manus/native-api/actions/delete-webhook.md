# Delete Webhook with Manus

Deletes a webhook from Manus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhook_id`
- **Base URL:** `https://api.manus.ai/v1`
- **Official documentation:** [Delete Webhook](https://open.manus.ai/docs/v1/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | The ID of the webhook to delete |
