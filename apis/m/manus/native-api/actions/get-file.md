# Get File with Manus

Retrieves a file from Manus by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.manus.ai/v1`
- **Official documentation:** [Get File](https://open.manus.ai/docs/v1/get-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file to retrieve |
