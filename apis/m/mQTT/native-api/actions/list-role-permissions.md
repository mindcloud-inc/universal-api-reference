# List Role Permissions with MQTT

Retrieves MQTT role permissions from HiveMQ Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/mqtt/roles/permissions`
- **Base URL:** `https://api.a03.euc1.aws.hivemq.cloud/api/v2/orgs/q1zjbn/clusters/8a3176f6-5ba5-46f8-a7be-09c8032cefcd`
- **Official documentation:** [List Role Permissions](https://docs.hivemq.com/hivemq-cloud/rest-api/specification/)
