# Delete MQTT Role with MQTT

Deletes an existing MQTT role from HiveMQ Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mqtt/roles/:roleId`
- **Base URL:** `https://api.a03.euc1.aws.hivemq.cloud/api/v2/orgs/q1zjbn/clusters/8a3176f6-5ba5-46f8-a7be-09c8032cefcd`
- **Official documentation:** [Delete MQTT Role](https://docs.hivemq.com/hivemq-cloud/rest-api/specification/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `number` | yes | Numeric role identifier |
