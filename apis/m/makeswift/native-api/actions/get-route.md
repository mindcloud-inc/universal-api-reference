# Get Route with Makeswift

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/routes/:routeIdOrPathname`
- **Base URL:** `https://api.makeswift.com`
- **Official documentation:** [Get Route](https://docs.makeswift.com/developer/reference/api/routes/get-route)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `routeIdOrPathname` | path | `string` | yes | Route ID or pathname. |
| `siteId` | query | `string` | yes | The site ID containing the route. |
