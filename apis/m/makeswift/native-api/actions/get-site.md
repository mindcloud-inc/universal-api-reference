# Get Site with Makeswift

Retrieves a site from Makeswift.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sites/:siteId`
- **Base URL:** `https://api.makeswift.com`
- **Official documentation:** [Get Site](https://docs.makeswift.com/developer/reference/api/sites/get-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | The site ID. |
