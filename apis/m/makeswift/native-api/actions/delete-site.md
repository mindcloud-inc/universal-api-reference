# Delete Site with Makeswift

Deletes an existing site from Makeswift.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/sites/:siteId`
- **Base URL:** `https://api.makeswift.com`
- **Official documentation:** [Delete Site](https://docs.makeswift.com/developer/reference/api/sites/delete-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | The site ID to delete. |
