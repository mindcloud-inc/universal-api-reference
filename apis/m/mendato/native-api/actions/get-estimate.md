## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [Get Estimate](https://developers.mendato.com/#query-estimate)

| Parameter | Location | Type | Required | Description |
