# List Operations with Mendato

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [List Operations](https://developers.mendato.com/#query-operations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | no | GraphQL variables object for the Mendato operations query. |
