# List Tickets with Mendato

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [List Tickets](https://developers.mendato.com/#query-tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | no | GraphQL variables object for the Mendato tickets query. |
