# Get Operation with Mendato

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [Get Operation](https://developers.mendato.com/#query-operation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | GraphQL variables object for the Mendato operation query. |
