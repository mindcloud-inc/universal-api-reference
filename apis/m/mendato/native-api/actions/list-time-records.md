# List Time Records with Mendato

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [List Time Records](https://developers.mendato.com/#query-timeRecords)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | no | GraphQL variables object for the Mendato time records query. |
