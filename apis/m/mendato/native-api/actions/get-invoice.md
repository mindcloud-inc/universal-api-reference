# Get Invoice with Mendato

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.mendato.com`
- **Official documentation:** [Get Invoice](https://developers.mendato.com/#query-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | GraphQL variables object for the Mendato invoice query. |
