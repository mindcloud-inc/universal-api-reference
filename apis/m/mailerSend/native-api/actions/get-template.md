# Get Template with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Template](https://developers.mailersend.com/api/v1/templates#get-a-single-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | ID of the MailerSend template. |
