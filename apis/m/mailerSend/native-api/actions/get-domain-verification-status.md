# Get Domain Verification Status with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain_id/verify`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Domain Verification Status](https://developers.mailersend.com/api/v1/domains#get-verification-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | ID of the MailerSend domain. |
