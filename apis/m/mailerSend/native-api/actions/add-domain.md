# Add Domain with MailerSend

## Endpoint

- **Method:** `POST`
- **Path:** `/domains`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Add Domain](https://developers.mailersend.com/api/v1/domains#add-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Verified sending domain name to add. |
