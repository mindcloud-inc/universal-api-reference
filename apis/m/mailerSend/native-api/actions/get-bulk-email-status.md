# Get Bulk Email Status with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk-email/:bulk_email_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Bulk Email Status](https://developers.mailersend.com/api/v1/email#get-bulk-email-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bulk_email_id` | path | `string` | yes | ID of the MailerSend bulk email job. |
