# Delete Sender Identity with MailerSend

## Endpoint

- **Method:** `DELETE`
- **Path:** `/identities/:identity_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Delete Sender Identity](https://developers.mailersend.com/api/v1/sender-identity#delete-a-sender-identity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identity_id` | path | `string` | yes | ID of the sender identity to delete. |
