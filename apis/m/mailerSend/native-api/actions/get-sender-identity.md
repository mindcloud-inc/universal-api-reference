# Get Sender Identity with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/identities/:identity_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Sender Identity](https://developers.mailersend.com/api/v1/sender-identity#get-a-single-sender-identity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identity_id` | path | `string` | yes | ID of the MailerSend sender identity. |
