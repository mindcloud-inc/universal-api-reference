# List Webhooks with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [List Webhooks](https://developers.mailersend.com/api/v1/webhooks#get-a-list-of-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | query | `string` | yes | ID of the MailerSend domain. |
