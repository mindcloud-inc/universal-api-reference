# Get Message with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:message_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Message](https://developers.mailersend.com/api/v1/messages#get-information-for-a-single-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `message_id` | path | `string` | yes | ID of the MailerSend message. |
