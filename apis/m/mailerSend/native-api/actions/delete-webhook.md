# Delete Webhook with MailerSend

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhook_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Delete Webhook](https://developers.mailersend.com/api/v1/webhooks#delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | ID of the webhook to delete. |
