# Get Domain DNS Records with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain_id/dns-records`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Domain DNS Records](https://developers.mailersend.com/api/v1/domains#get-dns-records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | ID of the MailerSend domain. |
