# Get Activity with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/activities/:activity_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Activity](https://developers.mailersend.com/api/v1/activity#get-a-single-activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity_id` | path | `string` | yes | ID of the MailerSend activity event. |
