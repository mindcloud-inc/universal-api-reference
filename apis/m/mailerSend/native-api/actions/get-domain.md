# Get Domain with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Domain](https://developers.mailersend.com/api/v1/domains#get-a-single-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | ID of the MailerSend domain. |
