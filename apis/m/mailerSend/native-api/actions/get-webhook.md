# Get Webhook with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhook_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Webhook](https://developers.mailersend.com/api/v1/webhooks#get-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | ID of the MailerSend webhook. |
