# List Sender Identities with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/identities`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [List Sender Identities](https://developers.mailersend.com/api/v1/sender-identity#get-a-list-of-sender-identities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | query | `string` | no | Optional MailerSend domain ID to filter sender identities. |
