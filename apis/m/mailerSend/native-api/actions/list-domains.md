# List Domains with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [List Domains](https://developers.mailersend.com/api/v1/domains#get-a-list-of-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
