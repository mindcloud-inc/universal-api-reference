# Delete Domain with MailerSend

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domains/:domain_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Delete Domain](https://developers.mailersend.com/api/v1/domains#delete-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | ID of the MailerSend domain to delete. |
