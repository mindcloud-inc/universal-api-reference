# Get Recipient with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/recipients/:recipient_id`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [Get Recipient](https://developers.mailersend.com/api/v1/recipients#get-a-single-recipient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipient_id` | path | `string` | yes | ID of the MailerSend recipient. |
