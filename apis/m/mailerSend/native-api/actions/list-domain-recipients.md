# List Domain Recipients with MailerSend

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain_id/recipients`
- **Base URL:** `https://api.mailersend.com/v1`
- **Official documentation:** [List Domain Recipients](https://developers.mailersend.com/api/v1/domains#get-recipients-for-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | ID of the MailerSend domain. |
