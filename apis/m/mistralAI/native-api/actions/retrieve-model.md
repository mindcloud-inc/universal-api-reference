# Retrieve Model with Mistral AI

Retrieves model details from Mistral AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model_id`
- **Base URL:** `https://api.mistral.ai`
- **Official documentation:** [Retrieve Model](https://docs.mistral.ai/api/endpoint/models#operation-retrieve_model_v1_models_model_id_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | The ID of the model to retrieve. |
