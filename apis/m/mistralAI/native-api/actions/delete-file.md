# Delete File with Mistral AI

Deletes an existing file from Mistral AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.mistral.ai`
- **Official documentation:** [Delete File](https://docs.mistral.ai/api/endpoint/files#operation-files_api_routes_delete_file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file. |
