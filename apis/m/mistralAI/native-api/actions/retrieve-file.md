# Retrieve File with Mistral AI

Retrieves file details from Mistral AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.mistral.ai`
- **Official documentation:** [Retrieve File](https://docs.mistral.ai/api/endpoint/files#operation-files_api_routes_retrieve_file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The ID of the file. |
