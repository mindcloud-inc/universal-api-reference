# Get A Queue with Moderation API

Retrieves a review queue from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/queue/:id`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Get A Queue](https://docs.moderationapi.com/api-reference/review-queues/get-a-queue)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The queue ID |
