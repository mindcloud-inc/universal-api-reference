# Get An Action with Moderation API

Retrieves a moderation action from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/:id`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Get An Action](https://docs.moderationapi.com/api-reference/actions/get-an-action)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the action to get. |
