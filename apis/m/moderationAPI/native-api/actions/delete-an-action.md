# Delete An Action with Moderation API

Deletes a moderation action from Moderation API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/actions/:id`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Delete An Action](https://docs.moderationapi.com/api-reference/actions/delete-an-action)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the action to delete. |
