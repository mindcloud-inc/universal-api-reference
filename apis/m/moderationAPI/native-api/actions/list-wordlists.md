# List Wordlists with Moderation API

Retrieves wordlists from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/wordlist`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [List Wordlists](https://docs.moderationapi.com/api-reference/wordlist/list-wordlists)
