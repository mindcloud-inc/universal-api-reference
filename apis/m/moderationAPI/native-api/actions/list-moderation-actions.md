# List Moderation Actions with Moderation API

Retrieves moderation actions from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [List Moderation Actions](https://docs.moderationapi.com/api-reference/actions/list-moderation-actions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `queueId` | query | `string` | no |
