# Delete An Author with Moderation API

Deletes an author from Moderation API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/authors/:id`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Delete An Author](https://docs.moderationapi.com/api-reference/author/delete-an-author)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
