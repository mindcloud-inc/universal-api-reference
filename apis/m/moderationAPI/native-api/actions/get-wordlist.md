# Get Wordlist with Moderation API

Retrieves a wordlist from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/wordlist/:id`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Get Wordlist](https://docs.moderationapi.com/api-reference/wordlist/get-wordlist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the wordlist to get |
