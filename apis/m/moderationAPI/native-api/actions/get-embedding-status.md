# Get Embedding Status with Moderation API

Retrieves wordlist embedding status from Moderation API.

## Endpoint

- **Method:** `GET`
- **Path:** `/wordlist/:id/embedding-status`
- **Base URL:** `https://api.moderationapi.com/v1`
- **Official documentation:** [Get Embedding Status](https://docs.moderationapi.com/api-reference/wordlist/get-embedding-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the wordlist to check embedding status for |
