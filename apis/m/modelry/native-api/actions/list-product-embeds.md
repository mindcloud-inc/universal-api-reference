# List Product Embeds with Modelry

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:product_id/embeds`
- **Base URL:** `https://api.modelry.ai/api`
- **Official documentation:** [List Product Embeds](https://files.cgtarsenal.com/api/doc/index.html#api-ProductViewers-GetProductViewers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | Modelry product ID. |
