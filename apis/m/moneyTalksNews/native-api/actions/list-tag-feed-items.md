# List Tag Feed Items with Money Talks News

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/:tagSlug/feed/`
- **Base URL:** `https://www.moneytalksnews.com`
- **Official documentation:** [List Tag Feed Items](https://www.rssboard.org/rss-specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagSlug` | path | `string` | yes | Tag slug segment used in the Money Talks News tag feed URL. |
