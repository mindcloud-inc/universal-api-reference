# List Post Comments Feed Items with Money Talks News

## Endpoint

- **Method:** `GET`
- **Path:** `/:postSlug/feed/`
- **Base URL:** `https://www.moneytalksnews.com`
- **Official documentation:** [List Post Comments Feed Items](https://www.rssboard.org/rss-specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postSlug` | path | `string` | yes | Post slug segment used in the Money Talks News post comments feed URL. |
