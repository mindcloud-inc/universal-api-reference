# List Search Feed Items with Money Talks News

## Endpoint

- **Method:** `GET`
- **Path:** `/search/:searchTerm/feed/rss2/`
- **Base URL:** `https://www.moneytalksnews.com`
- **Official documentation:** [List Search Feed Items](https://www.rssboard.org/rss-specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchTerm` | path | `string` | yes | Search term segment used in the Money Talks News RSS search feed URL. |
