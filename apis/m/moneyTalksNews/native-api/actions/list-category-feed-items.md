# List Category Feed Items with Money Talks News

## Endpoint

- **Method:** `GET`
- **Path:** `/category/:categorySlug/feed/`
- **Base URL:** `https://www.moneytalksnews.com`
- **Official documentation:** [List Category Feed Items](https://www.rssboard.org/rss-specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categorySlug` | path | `string` | yes | Category slug segment used in the Money Talks News category feed URL. |
