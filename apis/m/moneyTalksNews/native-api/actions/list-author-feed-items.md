# List Author Feed Items with Money Talks News

## Endpoint

- **Method:** `GET`
- **Path:** `/author/:authorSlug/feed/`
- **Base URL:** `https://www.moneytalksnews.com`
- **Official documentation:** [List Author Feed Items](https://www.rssboard.org/rss-specification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `authorSlug` | path | `string` | yes | Author slug segment used in the Money Talks News author feed URL. |
