# Delete Folder with Mendeley

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folders/:id`
- **Base URL:** `https://api.mendeley.com`
- **Official documentation:** [Delete Folder](https://dev.mendeley.com/methods/#deleting-a-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier of the folder. |
