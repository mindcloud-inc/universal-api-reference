# Delete Annotation with Mendeley

## Endpoint

- **Method:** `DELETE`
- **Path:** `/annotations/:id`
- **Base URL:** `https://api.mendeley.com`
- **Official documentation:** [Delete Annotation](https://dev.mendeley.com/methods/#deleting-an-annotation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier of the annotation. |
