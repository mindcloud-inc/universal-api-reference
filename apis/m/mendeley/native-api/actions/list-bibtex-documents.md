# List BibTeX Documents with Mendeley

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.mendeley.com`
- **Official documentation:** [List BibTeX Documents](https://dev.mendeley.com/methods/#retrieving-bibtex-documents)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/x-bibtex` |
