# List Files with Mendeley

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.mendeley.com`
- **Official documentation:** [List Files](https://dev.mendeley.com/methods/#retrieving-files)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/vnd.mendeley-file.1+json` |
