# Get My Profile with Mendeley

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/me`
- **Base URL:** `https://api.mendeley.com`
- **Official documentation:** [Get My Profile](https://dev.mendeley.com/methods/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/vnd.mendeley-profiles.1+json` |
