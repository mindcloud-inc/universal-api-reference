# Drop Collection Properties with Milvus Vector Store

Drops collection properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/drop_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Collection Properties](https://docs.zilliz.com/reference/restful/drop-collection-properties-v2)
