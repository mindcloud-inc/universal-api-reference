# Drop Index Properties with Milvus Vector Store

Drops index properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/indexes/drop_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Index Properties](https://docs.zilliz.com/reference/restful/drop-index-properties-v2)
