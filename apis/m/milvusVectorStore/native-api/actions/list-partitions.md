# List Partitions with Milvus Vector Store

Retrieves partitions from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/partitions/list`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [List Partitions](https://docs.zilliz.com/reference/restful/list-partitions-v2)
