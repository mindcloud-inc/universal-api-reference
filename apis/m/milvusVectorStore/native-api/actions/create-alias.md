# Create Alias with Milvus Vector Store

Creates an alias in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/aliases/create`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Create Alias](https://docs.zilliz.com/reference/restful/create-alias-v2)
