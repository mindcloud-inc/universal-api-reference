# List Indexes with Milvus Vector Store

Retrieves indexes from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/indexes/list`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [List Indexes](https://docs.zilliz.com/reference/restful/list-indexes-v2)
