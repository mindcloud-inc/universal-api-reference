# Create Partition with Milvus Vector Store

Creates a partition in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/partitions/create`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Create Partition](https://docs.zilliz.com/reference/restful/create-partition-v2)
