# Compact Collection with Milvus Vector Store

Compacts a collection in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/compact`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Compact Collection](https://docs.zilliz.com/reference/restful/compact-collection-v2)
