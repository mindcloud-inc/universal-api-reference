# Describe Collection with Milvus Vector Store

Retrieves collection details from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/describe`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Describe Collection](https://docs.zilliz.com/reference/restful/describe-collection-v2)
