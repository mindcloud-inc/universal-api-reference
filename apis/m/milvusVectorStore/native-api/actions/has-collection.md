# Has Collection with Milvus Vector Store

Checks whether a collection exists in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/has`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Has Collection](https://docs.zilliz.com/reference/restful/has-collection-v2)
