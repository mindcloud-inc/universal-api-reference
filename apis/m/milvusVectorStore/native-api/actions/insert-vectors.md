# Insert Vectors with Milvus Vector Store

Inserts vectors into Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/entities/insert`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Insert Vectors](https://docs.zilliz.com/reference/restful/insert-v2)
