# Drop Partition with Milvus Vector Store

Deletes a partition from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/partitions/drop`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Partition](https://docs.zilliz.com/reference/restful/drop-partition-v2)
