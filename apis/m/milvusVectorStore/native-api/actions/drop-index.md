# Drop Index with Milvus Vector Store

Deletes an index from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/indexes/drop`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Index](https://docs.zilliz.com/reference/restful/drop-index-v2)
