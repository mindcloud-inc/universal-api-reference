# Describe Index with Milvus Vector Store

Retrieves index details from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/indexes/describe`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Describe Index](https://docs.zilliz.com/reference/restful/describe-index-v2)
