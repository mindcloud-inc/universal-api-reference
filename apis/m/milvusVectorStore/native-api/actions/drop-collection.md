# Drop Collection with Milvus Vector Store

Deletes a collection from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/drop`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Collection](https://docs.zilliz.com/reference/restful/drop-collection-v2)
