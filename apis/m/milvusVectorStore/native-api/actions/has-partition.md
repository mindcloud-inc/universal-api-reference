# Has Partition with Milvus Vector Store

Checks whether a partition exists in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/partitions/has`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Has Partition](https://docs.zilliz.com/reference/restful/has-partition-v2)
