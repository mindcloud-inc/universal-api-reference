# Alter Alias with Milvus Vector Store

Updates an alias in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/aliases/alter`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Alter Alias](https://docs.zilliz.com/reference/restful/alter-alias-v2)
