# List Aliases with Milvus Vector Store

Retrieves aliases from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/aliases/list`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [List Aliases](https://docs.zilliz.com/reference/restful/list-aliases-v2)
