# Describe Database with Milvus Vector Store

Retrieves database details from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/databases/describe`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Describe Database](https://docs.zilliz.com/reference/restful/describe-database-v2)
