# Alter Database Properties with Milvus Vector Store

Updates database properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/databases/alter_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Alter Database Properties](https://docs.zilliz.com/reference/restful/alter-database-properties-v2)
