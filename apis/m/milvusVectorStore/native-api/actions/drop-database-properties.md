# Drop Database Properties with Milvus Vector Store

Drops database properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/databases/drop_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Database Properties](https://docs.zilliz.com/reference/restful/drop-database-properties-v2)
