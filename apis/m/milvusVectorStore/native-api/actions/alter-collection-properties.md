# Alter Collection Properties with Milvus Vector Store

Updates collection properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/alter_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Alter Collection Properties](https://docs.zilliz.com/reference/restful/alter-collection-properties-v2)
