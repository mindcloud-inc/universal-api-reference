# Load Collection with Milvus Vector Store

Loads a collection in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/load`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Load Collection](https://docs.zilliz.com/reference/restful/load-collection-v2)
