# Drop Alias with Milvus Vector Store

Deletes an alias from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/aliases/drop`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Alias](https://docs.zilliz.com/reference/restful/drop-alias-v2)
