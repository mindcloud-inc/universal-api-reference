# Get Partition Statistics with Milvus Vector Store

Retrieves partition statistics from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/partitions/get_stats`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Get Partition Statistics](https://docs.zilliz.com/reference/restful/get-partition-statistics-v2)
