# Rename Collection with Milvus Vector Store

Renames a collection in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/rename`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Rename Collection](https://docs.zilliz.com/reference/restful/rename-collection-v2)
