# Upsert Vectors with Milvus Vector Store

Upserts vectors in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/entities/upsert`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Upsert Vectors](https://docs.zilliz.com/reference/restful/upsert-v2)
