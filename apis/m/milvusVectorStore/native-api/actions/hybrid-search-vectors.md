# Hybrid Search Vectors with Milvus Vector Store

Runs a hybrid vector search in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/entities/hybrid_search`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Hybrid Search Vectors](https://docs.zilliz.com/reference/restful/hybrid-search-v2)
