# Describe Alias with Milvus Vector Store

Retrieves alias details from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/aliases/describe`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Describe Alias](https://docs.zilliz.com/reference/restful/describe-alias-v2)
