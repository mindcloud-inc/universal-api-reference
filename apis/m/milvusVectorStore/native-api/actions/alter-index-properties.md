# Alter Index Properties with Milvus Vector Store

Updates index properties in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/indexes/alter_properties`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Alter Index Properties](https://docs.zilliz.com/reference/restful/alter-index-properties-v2)
