# List Databases with Milvus Vector Store

Retrieves databases from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/databases/list`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [List Databases](https://docs.zilliz.com/reference/restful/list-databases-v2)
