# Release Collection with Milvus Vector Store

Releases a collection from memory in Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/collections/release`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Release Collection](https://docs.zilliz.com/reference/restful/release-collection-v2)
