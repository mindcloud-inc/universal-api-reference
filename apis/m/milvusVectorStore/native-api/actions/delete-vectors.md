# Delete Vectors with Milvus Vector Store

Deletes vectors from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/entities/delete`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Delete Vectors](https://docs.zilliz.com/reference/restful/delete-v2)
