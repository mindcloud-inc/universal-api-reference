# Drop Database with Milvus Vector Store

Deletes a database from Milvus Vector Store.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/vectordb/databases/drop`
- **Base URL:** `https://{clusterEndpoint}`
- **Official documentation:** [Drop Database](https://docs.zilliz.com/reference/restful/drop-database-v2)
