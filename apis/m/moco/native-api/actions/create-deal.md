# Create Deal with Moco

## Endpoint

- **Method:** `POST`
- **Path:** `/deals`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Create Deal](https://everii-group.github.io/mocoapp-api-docs/sections/deals.html#post-deals)
