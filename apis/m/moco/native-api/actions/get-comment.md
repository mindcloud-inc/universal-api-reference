# Get Comment with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Comment](https://everii-group.github.io/mocoapp-api-docs/sections/comments.html#get-commentsid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Comment ID |
