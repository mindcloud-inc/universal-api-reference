# Get User with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get User](https://everii-group.github.io/mocoapp-api-docs/sections/users.html#get-usersid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID |
