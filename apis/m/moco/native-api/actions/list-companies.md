# List Companies with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [List Companies](https://everii-group.github.io/mocoapp-api-docs/sections/companies.html#get-companies)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `custom_properties` | query | `object` | no |
| `identifier` | query | `string` | no |
| `ids` | query | `string` | no |
| `include_archived` | query | `boolean` | no |
| `tags` | query | `string` | no |
| `term` | query | `string` | no |
| `type` | query | `string` | no |
| `updated_after` | query | `date` | no |
