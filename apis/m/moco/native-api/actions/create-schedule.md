# Create Schedule with Moco

## Endpoint

- **Method:** `POST`
- **Path:** `/schedules`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Create Schedule](https://everii-group.github.io/mocoapp-api-docs/sections/schedules.html#post-schedules)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `absence_code` | body | `string` | no |
| `am` | body | `string` | no |
| `comment` | body | `string` | no |
| `date` | body | `string` | no |
| `overwrite` | body | `string` | no |
| `pm` | body | `string` | no |
| `symbol` | body | `string` | no |
| `user_id` | body | `string` | no |
