# Get Purchase with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/purchases/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Purchase](https://everii-group.github.io/mocoapp-api-docs/sections/purchases.html#get-purchasesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Purchase ID |
