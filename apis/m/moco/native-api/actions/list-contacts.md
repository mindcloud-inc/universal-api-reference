# List Contacts with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/people`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [List Contacts](https://everii-group.github.io/mocoapp-api-docs/sections/contacts.html#get-contactspeople)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `custom_properties` | query | `object` | no |
| `ids` | query | `string` | no |
| `phone` | query | `string` | no |
| `tags` | query | `string` | no |
| `term` | query | `string` | no |
| `updated_after` | query | `date` | no |
