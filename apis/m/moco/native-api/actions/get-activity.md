# Get Activity with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/activities/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Activity](https://everii-group.github.io/mocoapp-api-docs/sections/activities.html#get-activitiesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Activity ID |
