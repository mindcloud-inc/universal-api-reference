# Get Deal with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Deal](https://everii-group.github.io/mocoapp-api-docs/sections/deals.html#get-dealsid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Deal ID |
