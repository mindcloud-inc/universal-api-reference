# Create Project with Moco

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Create Project](https://everii-group.github.io/mocoapp-api-docs/sections/projects.html#post-projects)
