# Get Contact with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/people/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Contact](https://everii-group.github.io/mocoapp-api-docs/sections/contacts.html#get-contactspeopleid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID |
