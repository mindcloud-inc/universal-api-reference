# List Users with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [List Users](https://everii-group.github.io/mocoapp-api-docs/sections/users.html#get-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `custom_properties` | query | `object` | no |
| `email` | query | `string` | no |
| `ids` | query | `string` | no |
| `include_archived` | query | `boolean` | no |
| `tags` | query | `string` | no |
| `updated_after` | query | `date` | no |
