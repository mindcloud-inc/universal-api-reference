# Get Company with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Company](https://everii-group.github.io/mocoapp-api-docs/sections/companies.html#get-companiesid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Company ID |
