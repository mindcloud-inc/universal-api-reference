# Create Comment with Moco

## Endpoint

- **Method:** `POST`
- **Path:** `/comments`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Create Comment](https://everii-group.github.io/mocoapp-api-docs/sections/comments.html#post-comments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachment_content` | body | `string` | no |
| `attachment_filename` | body | `string` | no |
| `commentable_id` | body | `string` | no |
| `commentable_type` | body | `string` | no |
| `created_at` | body | `string` | no |
| `text` | body | `string` | no |
