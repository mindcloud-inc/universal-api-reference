# List Offers with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/offers`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [List Offers](https://everii-group.github.io/mocoapp-api-docs/sections/offers.html#get-offers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_id` | query | `string` | no |
| `custom_properties` | query | `object` | no |
| `deal_id` | query | `string` | no |
| `from` | query | `date` | no |
| `identifier` | query | `string` | no |
| `ids` | query | `string` | no |
| `project_id` | query | `string` | no |
| `status` | query | `string` | no |
| `to` | query | `date` | no |
| `updated_after` | query | `date` | no |
