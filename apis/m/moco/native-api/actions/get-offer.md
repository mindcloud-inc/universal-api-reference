# Get Offer with Moco

## Endpoint

- **Method:** `GET`
- **Path:** `/offers/:id`
- **Base URL:** `https://{domain}.mocoapp.com/api/v1`
- **Official documentation:** [Get Offer](https://everii-group.github.io/mocoapp-api-docs/sections/offers.html#get-offersid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Offer ID |
