# Get Task with Morgen

Retrieves a task from Morgen.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/tasks`
- **Base URL:** `https://api.morgen.so`
- **Official documentation:** [Get Task](https://docs.morgen.so/tasks#get-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Morgen task ID. |
