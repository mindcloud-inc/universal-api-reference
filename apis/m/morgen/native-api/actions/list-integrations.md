# List Integrations with Morgen

Retrieves available integrations from Morgen.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/integrations/list`
- **Base URL:** `https://api.morgen.so`
- **Official documentation:** [List Integrations](https://docs.morgen.so/integrations#how-to-list-the-available-providers)
