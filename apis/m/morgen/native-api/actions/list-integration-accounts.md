# List Integration Accounts with Morgen

Retrieves connected integration accounts from Morgen.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/integrations/accounts/list`
- **Base URL:** `https://api.morgen.so`
- **Official documentation:** [List Integration Accounts](https://docs.morgen.so/integrations#how-to-list-the-connected-accounts-of-a-user)
