# Get Current User with Mighty Networks

Retrieves the current user from Mighty Networks.

## Endpoint

- **Method:** `GET`
- **Path:** `/networks/:network_id/me`
- **Base URL:** `https://api.mn.co/admin/v1`
- **Official documentation:** [Get Current User](https://docs.mightynetworks.com/quickstart)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `network_id` | path | `string` | yes | The Mighty Networks network ID or subdomain for the request path. |
