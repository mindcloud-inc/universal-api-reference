# Set Current Organization with MailoPost

Sets the current organization in MailoPost.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/email/organizations/:id/current`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Set Current Organization](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost organization identifier. |
