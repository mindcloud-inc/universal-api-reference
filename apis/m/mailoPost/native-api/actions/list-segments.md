# List Segments with MailoPost

Retrieves segments from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/segments`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Segments](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
