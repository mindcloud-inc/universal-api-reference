# Get Email Template with MailoPost

Retrieves an email template from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/templates/:template_id`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Get Email Template](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | MailoPost template identifier. |
