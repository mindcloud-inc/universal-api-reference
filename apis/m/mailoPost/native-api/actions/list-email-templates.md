# List Email Templates with MailoPost

Retrieves email templates from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/templates`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Email Templates](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
