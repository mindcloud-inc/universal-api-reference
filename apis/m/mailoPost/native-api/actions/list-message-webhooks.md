# List Message Webhooks with MailoPost

Retrieves message webhooks from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/messages_webhooks`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Message Webhooks](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
