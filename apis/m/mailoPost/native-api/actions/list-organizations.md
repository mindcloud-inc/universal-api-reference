# List Organizations with MailoPost

Retrieves organizations from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/organizations`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Organizations](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
