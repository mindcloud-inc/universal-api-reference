# Create Recipient List with MailoPost

Creates a new recipient list in MailoPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/email/lists`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Create Recipient List](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Recipient list title. |
