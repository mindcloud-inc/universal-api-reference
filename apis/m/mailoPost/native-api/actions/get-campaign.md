# Get Campaign with MailoPost

Retrieves a campaign from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns/:id`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Get Campaign](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost campaign identifier. |
