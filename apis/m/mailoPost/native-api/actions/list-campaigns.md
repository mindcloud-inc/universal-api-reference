# List Campaigns with MailoPost

Retrieves campaigns from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/campaigns`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Campaigns](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statistic` | query | `boolean` | no | Whether to include the statistics block. |
