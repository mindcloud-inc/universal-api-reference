# Get Organization with MailoPost

Retrieves an organization from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/organizations/:id`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Get Organization](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost organization identifier. |
