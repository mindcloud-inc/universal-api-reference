# List Webhook Message Kinds with MailoPost

Retrieves message webhook kinds from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/messages_webhooks/kinds`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Webhook Message Kinds](https://mailopost.ru/api.html)
