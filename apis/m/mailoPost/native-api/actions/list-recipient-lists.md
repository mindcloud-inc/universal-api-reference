# List Recipient Lists with MailoPost

Retrieves recipient lists from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Recipient Lists](https://mailopost.ru/api.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
