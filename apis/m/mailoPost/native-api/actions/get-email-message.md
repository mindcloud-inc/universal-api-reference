# Get Email Message with MailoPost

Retrieves an email message from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/messages/:id`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Get Email Message](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost message identifier. |
