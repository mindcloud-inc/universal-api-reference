# List Recipient List Parameters with MailoPost

Retrieves recipient list parameters from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/:id/parameters`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [List Recipient List Parameters](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost recipient list identifier. |
