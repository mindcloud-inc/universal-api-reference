# Get Recipient List with MailoPost

Retrieves a recipient list from MailoPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/email/lists/:id`
- **Base URL:** `https://api.mailopost.ru/v1`
- **Official documentation:** [Get Recipient List](https://mailopost.ru/api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MailoPost recipient list identifier. |
