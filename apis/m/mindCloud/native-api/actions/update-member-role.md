# Update Member Role with MindCloud

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/members/:userId`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Update Member Role](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | body | `string` | yes | Role ID for this MindCloud v2 request. |
| `userId` | path | `string` | yes | User ID for this MindCloud v2 request. |
