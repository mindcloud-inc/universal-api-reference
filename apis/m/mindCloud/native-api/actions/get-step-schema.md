# Get Step Schema with MindCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/workflows/:workflowId/steps/:stepId/schema`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Get Step Schema](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID for this MindCloud v2 request. |
| `stepId` | path | `string` | yes | Step ID for this MindCloud v2 request. |
