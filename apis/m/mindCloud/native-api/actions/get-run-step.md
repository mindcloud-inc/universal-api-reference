# Get Run Step with MindCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/runs/:runId/steps/:stepInstanceId`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Get Run Step](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `runId` | path | `string` | yes | Run ID for this MindCloud v2 request. |
| `stepInstanceId` | path | `string` | yes | Step Instance ID for this MindCloud v2 request. |
