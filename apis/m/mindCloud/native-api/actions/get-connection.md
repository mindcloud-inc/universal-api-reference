# Get Connection with MindCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/connections/:connectionId`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Get Connection](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Connection ID for this MindCloud v2 request. |
