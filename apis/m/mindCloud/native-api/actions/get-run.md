# Get Run with MindCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/runs/:runId`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Get Run](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `runId` | path | `string` | yes | Run ID for this MindCloud v2 request. |
