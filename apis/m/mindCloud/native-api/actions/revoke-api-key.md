# Revoke API Key with MindCloud

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/api-keys/:apiKeyId`
- **Base URL:** `https://connect.mindcloud.co`
- **Official documentation:** [Revoke API Key](https://connect.mindcloud.co/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiKeyId` | path | `string` | yes | API Key ID for this MindCloud v2 request. |
