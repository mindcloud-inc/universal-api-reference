# List Scenarios with Make

Lists scenarios for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/scenarios`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Scenarios](https://developers.make.com/api-documentation/api-reference/scenarios)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team whose scenarios should be listed. |
