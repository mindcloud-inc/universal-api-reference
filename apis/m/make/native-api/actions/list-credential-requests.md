# List Credential Requests with Make

Lists credential requests for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/credential-requests/requests`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Credential Requests](https://developers.make.com/api-documentation/api-reference/credential-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team. |
