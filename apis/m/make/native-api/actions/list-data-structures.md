# List Data Structures with Make

Lists data structures for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/data-structures`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Data Structures](https://developers.make.com/api-documentation/api-reference/data-structures)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team. |
