# List Connections with Make

Lists connections for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Connections](https://developers.make.com/api-documentation/api-reference/connections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team whose connections should be listed. |
