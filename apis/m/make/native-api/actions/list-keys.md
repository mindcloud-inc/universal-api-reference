# List Keys with Make

Lists keys in the specified team's custom keychain.

## Endpoint

- **Method:** `GET`
- **Path:** `/keys`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Keys](https://developers.make.com/api-documentation/api-reference/keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team. |
