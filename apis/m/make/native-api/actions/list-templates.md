# List Templates with Make

Lists templates for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Templates](https://developers.make.com/api-documentation/api-reference/templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team. |
