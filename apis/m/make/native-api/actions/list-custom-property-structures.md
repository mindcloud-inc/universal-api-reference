# List Custom Property Structures with Make

Lists custom property structures for the specified organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-property-structures`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Custom Property Structures](https://developers.make.com/api-documentation/api-reference/custom-property-structures)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | query | `number` | yes | The ID of the Make organization. |
