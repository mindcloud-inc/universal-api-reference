# List Devices with Make

Lists devices for the specified team.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [List Devices](https://developers.make.com/api-documentation/api-reference/devices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | query | `number` | yes | The ID of the Make team. |
