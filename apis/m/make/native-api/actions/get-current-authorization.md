# Get Current Authorization with Make

Returns current authorization details for the authenticated user, including the token scopes and authentication method used.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/current-authorization`
- **Base URL:** `https://us2.make.com/api/v2`
- **Official documentation:** [Get Current Authorization](https://developers.make.com/api-documentation/api-reference/users-greater-than-me)
