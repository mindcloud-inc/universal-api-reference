# List Checkpads with MOONTO Shopping Lists - Checkpad

Retrieves a list of checkpads from Checkpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkpads/`
- **Base URL:** `https://api.moonto.app`
- **Official documentation:** [List Checkpads](https://api.moonto.app/docs#/Checkpads/get_checkpads_checkpads__get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
