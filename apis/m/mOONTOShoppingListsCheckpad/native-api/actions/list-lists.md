# List Lists with MOONTO Shopping Lists - Checkpad

Retrieves a list of shopping lists from Checkpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/`
- **Base URL:** `https://api.moonto.app`
- **Official documentation:** [List Lists](https://api.moonto.app/docs#/Lists/get_lists_lists__get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
