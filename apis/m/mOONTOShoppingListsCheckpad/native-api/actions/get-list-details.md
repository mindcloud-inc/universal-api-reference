# Get List Details with MOONTO Shopping Lists - Checkpad

Retrieves shopping list details from Checkpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/{list_id}`
- **Base URL:** `https://api.moonto.app`
- **Official documentation:** [Get List Details](https://api.moonto.app/docs#/Lists/get_list_details_lists__list_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | The ID of the MOONTO list. |
