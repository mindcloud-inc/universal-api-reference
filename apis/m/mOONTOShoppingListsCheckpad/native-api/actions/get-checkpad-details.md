# Get Checkpad Details with MOONTO Shopping Lists - Checkpad

Retrieves current checkpad details from Checkpad.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkpads/{checkpad_id}`
- **Base URL:** `https://api.moonto.app`
- **Official documentation:** [Get Checkpad Details](https://api.moonto.app/docs#/Checkpads/get_checkpad_details_checkpads__checkpad_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checkpad_id` | path | `string` | yes | The ID of the MOONTO checkpad. |
