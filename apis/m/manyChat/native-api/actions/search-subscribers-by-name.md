# Search Subscribers by Name with ManyChat

Finds subscribers in ManyChat by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/subscriber/findByName`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Search Subscribers by Name](https://api.manychat.com/swagger#/Subscriber/e5c671d1661acff9be0e8bcfdd59f1e8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
