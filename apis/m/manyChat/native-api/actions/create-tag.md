# Create Tag with ManyChat

Creates a new tag in ManyChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/fb/page/createTag`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Create Tag](https://api.manychat.com/swagger#/Page/e964547412ede512f9534970c8e3971a)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
