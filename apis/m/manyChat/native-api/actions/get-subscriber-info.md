# Get Subscriber Info with ManyChat

Retrieves a subscriber from ManyChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/subscriber/getInfo`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Get Subscriber Info](https://api.manychat.com/swagger#/Subscriber/ae51a27b65b7ecf39438af38db0f27ba)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriber_id` | query | `number` | yes |
