# Search Subscribers by System Field with ManyChat

Finds subscribers in ManyChat by system field.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/subscriber/findBySystemField`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Search Subscribers by System Field](https://api.manychat.com/swagger#/Subscriber/ef59064a933ef7464083a39c520a274b)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
| `phone` | query | `string` | no |
