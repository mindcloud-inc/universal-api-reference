# Get Subscriber Info By User Ref with ManyChat

Finds a subscriber in ManyChat by user ref.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/subscriber/getInfoByUserRef`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Get Subscriber Info By User Ref](https://api.manychat.com/swagger#/Subscriber/782cc8abe7878dc73026b6bef44f14b2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_ref` | query | `number` | yes |
