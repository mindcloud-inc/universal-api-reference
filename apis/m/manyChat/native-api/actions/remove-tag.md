# Remove Tag with ManyChat

Deletes an existing tag from ManyChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/fb/page/removeTag`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Remove Tag](https://api.manychat.com/swagger#/Page/55b1d844eb0006f3c49e2a3ac524dd4e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tag_id` | body | `number` | yes |
