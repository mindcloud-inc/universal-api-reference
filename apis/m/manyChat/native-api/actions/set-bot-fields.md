# Set Bot Fields with ManyChat

Updates multiple bot fields in ManyChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/fb/page/setBotFields`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Set Bot Fields](https://api.manychat.com/swagger#/Page/327327a53f87fecaeb9f7cd69c0433af)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields[]` | body | `array<object>` | yes |
