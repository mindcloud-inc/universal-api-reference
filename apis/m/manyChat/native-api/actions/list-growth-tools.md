# List Growth Tools with ManyChat

Retrieves growth tools from ManyChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/page/getGrowthTools`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [List Growth Tools](https://api.manychat.com/swagger#/Page/2ab4a2a91a0b2cb1d5084e91b281e48c)
