# Get Page Info with ManyChat

Retrieves connected page details from ManyChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/page/getInfo`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [Get Page Info](https://api.manychat.com/swagger#/Page/b26c074b3783eb6e888c62324b17268c)
