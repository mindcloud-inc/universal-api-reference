# List Bot Fields with ManyChat

Retrieves page bot fields from ManyChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/page/getBotFields`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [List Bot Fields](https://api.manychat.com/swagger#/Page/dbb46d786cc1323d56b27ff7de7bcc3f)
