# List Custom Fields with ManyChat

Retrieves page custom fields from ManyChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/fb/page/getCustomFields`
- **Base URL:** `https://api.manychat.com`
- **Official documentation:** [List Custom Fields](https://api.manychat.com/swagger#/Page/2bc43834222da265c4c41fbd129d1392)
