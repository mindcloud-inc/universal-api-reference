# Get Item Inventory with MarketTime

## Endpoint

- **Method:** `GET`
- **Path:** `/mtpublic/api/v1/:whoAmI/items/inventory/:itemID`
- **Base URL:** `https://publicapi.markettime.com`
- **Official documentation:** [Get Item Inventory](https://publicapi.markettime.com/swagger-ui/index.html#/Item/getSingleItemInventoryDetail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemID` | path | `number` | yes |
