# List Items by Item ID with MarketTime

## Endpoint

- **Method:** `GET`
- **Path:** `/mtpublic/api/v1/:whoAmI/items/:itemID`
- **Base URL:** `https://publicapi.markettime.com`
- **Official documentation:** [List Items by Item ID](https://publicapi.markettime.com/swagger-ui/index.html#/Item/getItemsDetailsByItemID)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemID` | path | `string` | yes |
