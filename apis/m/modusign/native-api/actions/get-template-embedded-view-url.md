# Get Template Embedded View URL with Modusign

Retrieves an embedded template view URL from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId/embedded-view`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Get Template Embedded View URL](https://developers.modusign.co.kr/docs/%EC%9E%84%EB%B2%A0%EB%94%94%EB%93%9C-%ED%85%9C%ED%94%8C%EB%A6%BF-%EC%88%98%EC%A0%95)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The Modusign template ID. |
