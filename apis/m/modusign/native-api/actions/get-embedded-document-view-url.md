# Get Embedded Document View URL with Modusign

Retrieves an embedded document view URL from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId/embedded-view`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Get Embedded Document View URL](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Modusign document ID. |
