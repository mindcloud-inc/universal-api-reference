# Update Webhook with Modusign

Updates an existing webhook in Modusign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Update Webhook](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The Modusign webhook ID. |
