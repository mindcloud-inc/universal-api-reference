# Delete Webhook with Modusign

Deletes an existing webhook from Modusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Delete Webhook](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The Modusign webhook ID. |
