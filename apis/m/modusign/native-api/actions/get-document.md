# Get Document with Modusign

Retrieves a document from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Get Document](https://developers.modusign.co.kr/reference/documentcontroller_getdocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Modusign document ID. |
