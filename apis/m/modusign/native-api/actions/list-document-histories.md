# List Document Histories with Modusign

Retrieves document history entries from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId/histories`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [List Document Histories](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Modusign document ID. |
