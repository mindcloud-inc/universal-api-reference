# Delete Label with Modusign

Deletes an existing label from Modusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Delete Label](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | The Modusign label ID. |
