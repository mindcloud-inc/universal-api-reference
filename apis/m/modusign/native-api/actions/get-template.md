# Get Template with Modusign

Retrieves a template from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Get Template](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The Modusign template ID. |
