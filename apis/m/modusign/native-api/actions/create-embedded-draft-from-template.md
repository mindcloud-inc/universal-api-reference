# Create Embedded Draft from Template with Modusign

Creates an embedded draft from a template in Modusign.

## Endpoint

- **Method:** `POST`
- **Path:** `/embedded-drafts/create-with-template`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Create Embedded Draft from Template](https://developers.modusign.co.kr/reference/api-reference)
