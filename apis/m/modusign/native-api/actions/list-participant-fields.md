# List Participant Fields with Modusign

Retrieves participant input fields from Modusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId/participant-fields`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [List Participant Fields](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Modusign document ID. |
