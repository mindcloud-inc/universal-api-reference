# Update Label with Modusign

Updates an existing label in Modusign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://api.modusign.co.kr`
- **Official documentation:** [Update Label](https://developers.modusign.co.kr/reference/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | The Modusign label ID. |
