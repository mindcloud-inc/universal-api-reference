# Get the context metrics for this game based on its current state with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/game/{gamePk}/contextMetrics`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [Get the context metrics for this game based on its current state](https://developer.stats.com/docs/read/baseball/mlb)
