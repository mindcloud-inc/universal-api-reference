# Get the last drafted player and the next 5 teams up to pick with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/draft/{year}/latest`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [Get the last drafted player and the next 5 teams up to pick](https://developer.stats.com/docs/read/baseball/mlb)
