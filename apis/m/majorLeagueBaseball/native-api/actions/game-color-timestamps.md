# Retrieve all of the color timestamps for a game with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/game/{game_pk}/feed/color/timestamps`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [Retrieve all of the color timestamps for a game](https://developer.stats.com/docs/read/baseball/mlb)
