# Retrieve all of the play timestamps for a game with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.1/game/{game_pk}/feed/live/timestamps`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [Retrieve all of the play timestamps for a game](https://developer.stats.com/docs/read/baseball/mlb)
