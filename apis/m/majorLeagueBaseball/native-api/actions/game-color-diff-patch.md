# Get game color diff patch with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/game/{gamePk}/feed/color/diffPatch`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [Get game color diff patch](https://github.com/toddrob99/MLB-StatsAPI/wiki/Endpoints)
