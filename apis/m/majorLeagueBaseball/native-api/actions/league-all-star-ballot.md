# View league all-star ballot with Major League Baseball

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/league/{leagueId}/allStarBallot`
- **Base URL:** `https://statsapi.mlb.com/api`
- **Official documentation:** [View league all-star ballot](https://github.com/toddrob99/MLB-StatsAPI/wiki/Endpoints)
