# Delete Project with mintBlue

Deletes a project from mintBlue.

## Endpoint

- **Method:** `POST`
- **Path:** `/sdk/latest`
- **Base URL:** `https://api.mintblue.com`
- **Official documentation:** [Delete Project](https://mintblue.gitlab.io/sdk/classes/Mintblue.html#destroyProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params.id` | body | `string` | yes | Project ID to delete. |
