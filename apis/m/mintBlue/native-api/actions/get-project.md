# Get Project with mintBlue

Retrieves a project from mintBlue.

## Endpoint

- **Method:** `POST`
- **Path:** `/sdk/latest`
- **Base URL:** `https://api.mintblue.com`
- **Official documentation:** [Get Project](https://mintblue.gitlab.io/sdk/classes/Mintblue.html#getProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params.id` | body | `string` | yes | Project ID to retrieve. |
