# Get Event Listener with mintBlue

Retrieves an event listener from mintBlue.

## Endpoint

- **Method:** `POST`
- **Path:** `/sdk/latest`
- **Base URL:** `https://api.mintblue.com`
- **Official documentation:** [Get Event Listener](https://mintblue.gitlab.io/sdk/classes/Mintblue.html#getEventListener)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params.id` | body | `string` | yes | Event listener ID to retrieve. |
