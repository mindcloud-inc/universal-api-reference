# Get cat facts with Meow Facts

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://meowfacts.herokuapp.com`
- **Official documentation:** [Get cat facts](https://github.com/wh-iterabb-it/meowfacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `number` | no | Optional number of cat facts to return. |
| `id` | query | `number` | no | Optional fact ID or order to retrieve. |
| `lang` | query | `string` | no | Optional documented language code for localized cat facts. |
