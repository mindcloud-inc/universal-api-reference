# Get Journal Entry with Monica CRM

Retrieves a journal entry from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/journal/:journalEntryId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Journal Entry](https://www.monicahq.com/api/journal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `journalEntryId` | path | `string` | yes |
