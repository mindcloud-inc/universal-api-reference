# Delete Contact Field Type with Monica CRM

Deletes an existing contact field type from Monica CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contactfieldtypes/:contactFieldTypeId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Delete Contact Field Type](https://www.monicahq.com/api/contactfieldtypes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactFieldTypeId` | path | `string` | yes |
