# Create Contact Field Type with Monica CRM

Creates a new contact field type in Monica CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/contactfieldtypes`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Create Contact Field Type](https://www.monicahq.com/api/contactfieldtypes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
