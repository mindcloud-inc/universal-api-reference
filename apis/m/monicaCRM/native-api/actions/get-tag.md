# Get Tag with Monica CRM

Retrieves a tag from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tagId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Tag](https://www.monicahq.com/api/tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `string` | yes |
