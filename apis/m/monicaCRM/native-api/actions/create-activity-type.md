# Create Activity Type with Monica CRM

Creates a new activity type in Monica CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/activitytypes`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Create Activity Type](https://www.monicahq.com/api/activitytypes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `activity_type_category_id` | body | `string` | yes |
| `name` | body | `string` | yes |
