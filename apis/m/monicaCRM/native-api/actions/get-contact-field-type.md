# Get Contact Field Type with Monica CRM

Retrieves a contact field type from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contactfieldtypes/:contactFieldTypeId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Contact Field Type](https://www.monicahq.com/api/contactfieldtypes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactFieldTypeId` | path | `string` | yes |
