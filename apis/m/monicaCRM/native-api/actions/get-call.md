# Get Call with Monica CRM

Retrieves a call from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:callId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Call](https://www.monicahq.com/api/calls)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
