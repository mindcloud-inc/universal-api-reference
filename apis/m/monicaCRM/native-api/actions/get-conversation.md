# Get Conversation with Monica CRM

Retrieves a conversation from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Conversation](https://www.monicahq.com/api/conversations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
