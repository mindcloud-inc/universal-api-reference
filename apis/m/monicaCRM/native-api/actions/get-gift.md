# Get Gift with Monica CRM

Retrieves a gift from Monica CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/gifts/:giftId`
- **Base URL:** `https://app.monicahq.com/api`
- **Official documentation:** [Get Gift](https://www.monicahq.com/api/gifts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `giftId` | path | `string` | yes |
