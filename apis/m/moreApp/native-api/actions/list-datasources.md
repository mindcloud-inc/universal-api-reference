# List Datasources with MoreApp

Retrieves datasources from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/customers/{{customerId}}/datasources`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Datasources](https://docs.moreapp.com/docs/developer-docs/3eb7f77868583-list-all-datasources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
