# List Roles with MoreApp

Retrieves roles from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/{{customerId}}/roles`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Roles](https://docs.moreapp.com/docs/developer-docs/41b7fc48e3872-get-roles-for-account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
