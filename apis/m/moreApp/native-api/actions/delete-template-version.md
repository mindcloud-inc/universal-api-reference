# Delete Template Version with MoreApp

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1.0/forms/customer/{{customerId}}/templates/{{formId}}/versions/{{formVersionId}}`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [Delete Template Version](https://docs.moreapp.com/docs/developer-docs/8323e40d67523-get-a-specific-version-of-a-template)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `string` | no |
| `formId` | path | `string` | no |
| `formVersionId` | path | `string` | no |
