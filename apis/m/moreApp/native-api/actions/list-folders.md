# List Folders with MoreApp

Retrieves folders from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/forms/customer/{{customerId}}/folders`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Folders](https://docs.moreapp.com/docs/developer-docs/4627bd66fda96-get-available-folders-for-customer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
