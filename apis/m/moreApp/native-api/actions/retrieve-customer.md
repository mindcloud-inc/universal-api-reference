# Retrieve Customer with MoreApp

Retrieves a customer from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/customers/{{customerId}}`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [Retrieve Customer](https://docs.moreapp.com/docs/developer-docs/97fdccb79c39d-retrieve-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
