# List Users with MoreApp

Retrieves users from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/customers/{{customerId}}/users`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Users](https://docs.moreapp.com/docs/developer-docs/1050875ee7b7d-list-all-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
