# Retrieve Role with MoreApp

Retrieves a role from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/{{customerId}}/roles/{{roleId}}`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [Retrieve Role](https://docs.moreapp.com/docs/developer-docs/2336cb776f390-retrieve-a-role)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
| `roleId` | path | `string` | yes |
