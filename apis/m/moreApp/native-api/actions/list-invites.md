# List Invites with MoreApp

Retrieves invites from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/{{customerId}}/invites`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Invites](https://docs.moreapp.com/docs/developer-docs/5e8fe257ca978-list-all-invites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
