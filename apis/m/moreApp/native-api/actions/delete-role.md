# Delete Role with MoreApp

Deletes a role from MoreApp.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/customers/{{customerId}}/roles/{{roleId}}`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [Delete Role](https://docs.moreapp.com/docs/developer-docs/a7b42a27490bf-delete-role)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
| `roleId` | path | `string` | yes |
