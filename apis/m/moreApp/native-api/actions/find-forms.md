# Find Forms with MoreApp

Finds forms in MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/forms/customer/{{customerId}}/forms`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [Find Forms](https://docs.moreapp.com/docs/developer-docs/c942f242b1b97-find-forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
