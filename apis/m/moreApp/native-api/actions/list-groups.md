# List Groups with MoreApp

Retrieves groups from MoreApp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/customers/{{customerId}}/groups`
- **Base URL:** `https://api.moreapp.com`
- **Official documentation:** [List Groups](https://docs.moreapp.com/docs/developer-docs/2734967502d3e-list-all-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | MoreApp customer identifier. |
