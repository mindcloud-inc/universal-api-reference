# Send SMS Text with Messaggio

Creates an SMS text message in Messaggio.

## Endpoint

- **Method:** `POST`
- **Path:** `/send`
- **Base URL:** `https://msg.messaggio.com/api/v1`
- **Official documentation:** [Send SMS Text](https://messaggio.com/api-docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipientPhone` | body | `string` | yes | Recipient phone number in international format without a plus sign. |
| `senderCode` | body | `string` | yes | Messaggio SMS sender code from the project sender settings. |
| `messageText` | body | `string` | yes | Plain-text SMS message content. Maximum length: 160. |
