# Validate Credentials with Messaggio

Validates stored Messaggio credentials against the bulk API.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulk.sms-online.com/`
- **Base URL:** `https://msg.messaggio.com/api/v1`
- **Official documentation:** [Validate Credentials](https://messaggio.com/messaggio_api_en.pdf)
