# Get Member with Memberstack

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:id_or_email`
- **Base URL:** `https://admin.memberstack.com`
- **Official documentation:** [Get Member](https://developers.memberstack.com/admin-rest-api/member-actions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_or_email` | path | `string` | yes | Member ID (mem_...) or URL-encoded member email. |
