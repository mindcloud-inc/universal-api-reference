# Get Data Table with Memberstack

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/data-tables/:tableKey`
- **Base URL:** `https://admin.memberstack.com`
- **Official documentation:** [Get Data Table](https://developers.memberstack.com/admin-rest-api/data-tables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableKey` | path | `string` | yes | Data table key from your Memberstack project. |
