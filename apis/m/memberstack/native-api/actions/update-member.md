# Update Member with Memberstack

## Endpoint

- **Method:** `PATCH`
- **Path:** `/members/:id`
- **Base URL:** `https://admin.memberstack.com`
- **Official documentation:** [Update Member](https://developers.memberstack.com/admin-rest-api/member-actions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Member ID (mem_...) to update. |
