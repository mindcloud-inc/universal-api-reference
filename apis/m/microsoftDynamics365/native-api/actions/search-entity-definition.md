# Search Entity Definition with Microsoft Dynamics 365

## Endpoint

- **Method:** `GET`
- **Path:** `/EntityDefinitions(LogicalName=':logicalName')`
- **Base URL:** `{baseURL}`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `$select` | query | `string` | no | Send multiple values as a array. |
| `logicalName` | path | `string` | no | — |
