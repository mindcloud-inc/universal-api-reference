# Get Custom Table Entry By Id with Microsoft Dynamics 365

## Endpoint

- **Method:** `GET`
- **Path:** `/:tableName(:id)`
- **Base URL:** `{baseURL}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tableName` | path | `string` | no |
| `id` | path | `string` | no |
