# Create Customer with Microsoft Dynamics 365

## Endpoint

- **Method:** `POST`
- **Path:** `Customers`
- **Base URL:** `{baseURL}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataAreaId` | body | `string` | no |
| `name` | body | `string` | no |
| `nameAlias` | body | `string` | no |
| `customerGroupId` | body | `string` | no |
| `salesCurrencyCode` | body | `string` | no |
| `customerAccount` | body | `string` | no |
