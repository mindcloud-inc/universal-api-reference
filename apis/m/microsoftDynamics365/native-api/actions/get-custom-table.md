# Get Custom Table with Microsoft Dynamics 365

## Endpoint

- **Method:** `GET`
- **Path:** `:tableName`
- **Base URL:** `{baseURL}`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tableName` | path | `string` | no |
| `$filter` | query | `string` | no |
| `$select` | query | `string` | no |
| `$expand` | query | `string` | no |
| `$top` | query | `string` | no |
