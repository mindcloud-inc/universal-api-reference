# Search Collections with Mem

Finds collections in Mem by search query.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/collections/search`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [Search Collections](https://docs.mem.ai/api-reference/collections/search-collections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search query text. |
