# Delete Collection with Mem

Deletes an existing collection from Mem.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/collections/:collectionId`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [Delete Collection](https://docs.mem.ai/api-reference/collections/delete-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | The ID of the collection to delete. |
