# Delete Note with Mem

Deletes an existing note from Mem.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/notes/:noteId`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [Delete Note](https://docs.mem.ai/api-reference/notes/delete-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The ID of the note to delete. |
