# List Collections with Mem

Retrieves collections from Mem.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/collections`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [List Collections](https://docs.mem.ai/api-reference/collections/list-collections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_by` | query | `string` | no | Optional collection ordering. |
