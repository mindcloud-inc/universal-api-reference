# Get Collection with Mem

Retrieves a collection from Mem.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/collections/:collectionId`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [Get Collection](https://docs.mem.ai/api-reference/collections/read-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | The ID of the collection to retrieve. |
