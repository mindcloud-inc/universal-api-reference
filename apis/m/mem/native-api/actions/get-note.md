# Get Note with Mem

Retrieves a note from Mem.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/notes/:noteId`
- **Base URL:** `https://api.mem.ai`
- **Official documentation:** [Get Note](https://docs.mem.ai/api-reference/notes/read-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The ID of the note to retrieve. |
