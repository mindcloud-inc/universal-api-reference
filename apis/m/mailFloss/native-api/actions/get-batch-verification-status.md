# Get Batch Verification Status with MailFloss

Retrieves batch email verification job status from MailFloss.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch-verify/:id/status`
- **Base URL:** `https://api.mailfloss.com`
- **Official documentation:** [Get Batch Verification Status](https://developers.mailfloss.com/9bbG-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Batch verification job ID. |
