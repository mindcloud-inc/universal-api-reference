# Cancel Batch Verification Job with MailFloss

Cancels a batch email verification job in MailFloss.

## Endpoint

- **Method:** `POST`
- **Path:** `/batch-verify/:id/cancel`
- **Base URL:** `https://api.mailfloss.com`
- **Official documentation:** [Cancel Batch Verification Job](https://developers.mailfloss.com/9bbG-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Batch verification job ID. |
