# Delete User with Microsoft Entra

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId`
- **Base URL:** `https://graph.microsoft.com/v1.0`
- **Official documentation:** [Delete User](https://learn.microsoft.com/en-us/graph/api/user-delete?view=graph-rest-1.0)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `list<string>` | yes |
