# List Organizations with Microsoft Entra

## Endpoint

- **Method:** `GET`
- **Path:** `/organization`
- **Base URL:** `https://graph.microsoft.com/v1.0`
- **Official documentation:** [List Organizations](https://learn.microsoft.com/en-us/graph/api/organization-list?view=graph-rest-1.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `$select` | query | `string` | no | Comma-separated organization properties to return. Maximum length: 0. |
