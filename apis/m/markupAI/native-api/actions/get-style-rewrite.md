# Get Style Rewrite with Markup AI

Retrieves style rewrite results from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/style/rewrites/:workflow_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Style Rewrite](https://docs.markup.ai/api-reference/style-rewrites/get-style-rewrite)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | Workflow ID for the style rewrite. |
