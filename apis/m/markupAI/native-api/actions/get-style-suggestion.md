# Get Style Suggestion with Markup AI

Retrieves style suggestion results from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/style/suggestions/:workflow_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Style Suggestion](https://docs.markup.ai/api-reference/style-suggestions/get-style-suggestion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | Workflow ID for the style suggestion. |
