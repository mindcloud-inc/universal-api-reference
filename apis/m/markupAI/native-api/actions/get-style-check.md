# Get Style Check with Markup AI

Retrieves style check results from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/style/checks/:workflow_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Style Check](https://docs.markup.ai/api-reference/style-checks/get-style-check)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `string` | yes | Workflow ID for the style check. |
