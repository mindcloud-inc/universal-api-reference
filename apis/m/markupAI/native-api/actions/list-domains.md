# List Domains with Markup AI

Retrieves terminology domains from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/terminology/domains`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [List Domains](https://docs.markup.ai/api-reference/terminology/list-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Optional name search for domains. |
