# Get Style Guide with Markup AI

Retrieves style guide details from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/style-guides/:style_guide_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Style Guide](https://docs.markup.ai/api-reference/style-guides/get-style-guide)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `style_guide_id` | path | `string` | yes | UUID of the style guide. |
