# Get Term Set with Markup AI

Retrieves term set details from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/terminology/term-sets/:term_set_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Term Set](https://docs.markup.ai/api-reference/terminology/get-term-set)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `term_set_id` | path | `string` | yes | UUID of the term set. |
