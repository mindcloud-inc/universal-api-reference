# Get Domain with Markup AI

Retrieves terminology domain details from Markup AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/terminology/domains/:domain_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Get Domain](https://docs.markup.ai/api-reference/terminology/get-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `string` | yes | UUID of the terminology domain. |
