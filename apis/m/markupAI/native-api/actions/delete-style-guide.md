# Delete Style Guide with Markup AI

Deletes an existing style guide from Markup AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/style-guides/:style_guide_id`
- **Base URL:** `https://api.markup.ai`
- **Official documentation:** [Delete Style Guide](https://docs.markup.ai/api-reference/style-guides/delete-style-guide)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `style_guide_id` | path | `string` | yes | UUID of the style guide to delete. |
