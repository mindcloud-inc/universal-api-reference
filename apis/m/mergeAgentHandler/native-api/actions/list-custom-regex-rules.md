# List Custom Regex Rules with Merge Agent Handler

Retrieves custom regex rules from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/security/custom-regex-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Custom Regex Rules](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/list-custom-regex-rules)
