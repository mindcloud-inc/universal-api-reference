# Update Registered User with Merge Agent Handler

Updates a registered user in Merge Agent Handler.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/registered-users/:registered_user_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Update Registered User](https://docs.merge.dev/merge-agent-handler/agent-handler/registered-users/partial-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `registered_user_id` | path | `string` | no | ID of the registered user. |
