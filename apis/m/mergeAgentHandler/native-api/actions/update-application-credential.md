# Update Application Credential with Merge Agent Handler

Updates an application credential in Merge Agent Handler.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/application-credentials/:id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Update Application Credential](https://docs.merge.dev/merge-agent-handler/agent-handler/application-credentials/partial-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | ID of the application credential. |
