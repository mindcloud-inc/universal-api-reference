# List Audit Logs with Merge Agent Handler

Retrieves audit log events from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/audit-log/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Audit Logs](https://docs.merge.dev/merge-agent-handler/agent-handler/audit-log/list)
