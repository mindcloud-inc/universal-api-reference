# List Tool Pack Tool Description Overrides with Merge Agent Handler

Retrieves tool pack description overrides from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool-packs/:tool_pack_id/tool-description-overrides/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Tool Pack Tool Description Overrides](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-description-overrides/list-tool-pack)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
