# List Registered Users with Merge Agent Handler

Retrieves registered users from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/registered-users/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Registered Users](https://docs.merge.dev/merge-agent-handler/agent-handler/registered-users/list)
