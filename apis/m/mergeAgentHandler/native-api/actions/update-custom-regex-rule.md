# Update Custom Regex Rule with Merge Agent Handler

Updates a custom regex rule in Merge Agent Handler.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/security/custom-regex-rules/:rule_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Update Custom Regex Rule](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/update-custom-regex-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rule_id` | path | `string` | no | ID of the custom regex rule. |
