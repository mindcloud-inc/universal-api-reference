# List Tool Packs with Merge Agent Handler

Retrieves tool packs from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool-packs/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Tool Packs](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-packs/list)
