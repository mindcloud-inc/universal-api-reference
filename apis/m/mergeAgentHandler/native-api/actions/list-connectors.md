# List Connectors with Merge Agent Handler

Retrieves connectors from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/connectors/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Connectors](https://docs.merge.dev/merge-agent-handler/agent-handler/connectors/list)
