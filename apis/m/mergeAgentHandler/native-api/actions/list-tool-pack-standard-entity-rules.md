# List Tool Pack Standard Entity Rules with Merge Agent Handler

Retrieves tool pack standard entity rules from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool-packs/:tool_pack_id/standard-entity-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Tool Pack Standard Entity Rules](https://docs.merge.dev/merge-agent-handler/agent-handler/standard-entity-rules/list-standard-entity-rules-tool-pack)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
