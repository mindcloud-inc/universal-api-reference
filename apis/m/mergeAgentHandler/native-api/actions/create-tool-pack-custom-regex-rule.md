# Create Tool Pack Custom Regex Rule with Merge Agent Handler

Creates a tool pack custom regex rule in Merge Agent Handler.

## Endpoint

- **Method:** `POST`
- **Path:** `/tool-packs/:tool_pack_id/custom-regex-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Create Tool Pack Custom Regex Rule](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/create-custom-regex-rule-tool-pack)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
