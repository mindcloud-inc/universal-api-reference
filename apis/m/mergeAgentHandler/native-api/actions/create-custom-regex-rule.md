# Create Custom Regex Rule with Merge Agent Handler

Creates a custom regex rule in Merge Agent Handler.

## Endpoint

- **Method:** `POST`
- **Path:** `/security/custom-regex-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Create Custom Regex Rule](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/create-custom-regex-rule)
