# Delete Custom Regex Rule with Merge Agent Handler

Deletes a custom regex rule from Merge Agent Handler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/security/custom-regex-rules/:rule_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Delete Custom Regex Rule](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/delete-custom-regex-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rule_id` | path | `string` | no | ID of the custom regex rule. |
