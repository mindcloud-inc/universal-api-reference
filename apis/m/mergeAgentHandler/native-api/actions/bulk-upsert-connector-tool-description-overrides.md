# Bulk Upsert Connector Tool Description Overrides with Merge Agent Handler

Upserts or deletes connector tool description overrides in Merge Agent Handler.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/connectors/tool-description-overrides/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Bulk Upsert Connector Tool Description Overrides](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-description-overrides/bulk-upsert-delete)
