# List Connector Tool Description Overrides with Merge Agent Handler

Retrieves connector tool description overrides from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/connectors/tool-description-overrides/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Connector Tool Description Overrides](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-description-overrides/list)
