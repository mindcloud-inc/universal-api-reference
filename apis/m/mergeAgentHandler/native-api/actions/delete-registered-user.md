# Delete Registered User with Merge Agent Handler

Deletes a registered user from Merge Agent Handler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/registered-users/:registered_user_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Delete Registered User](https://docs.merge.dev/merge-agent-handler/agent-handler/registered-users/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `registered_user_id` | path | `string` | no | ID of the registered user. |
