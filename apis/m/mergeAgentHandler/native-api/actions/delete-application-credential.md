# Delete Application Credential with Merge Agent Handler

Deletes an application credential from Merge Agent Handler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/application-credentials/:id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Delete Application Credential](https://docs.merge.dev/merge-agent-handler/agent-handler/application-credentials/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | ID of the application credential. |
