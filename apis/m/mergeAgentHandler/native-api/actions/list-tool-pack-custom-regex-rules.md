# List Tool Pack Custom Regex Rules with Merge Agent Handler

Retrieves tool pack custom regex rules from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool-packs/:tool_pack_id/custom-regex-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Tool Pack Custom Regex Rules](https://docs.merge.dev/merge-agent-handler/agent-handler/custom-regex-rules/list-custom-regex-rules-tool-pack)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
