# Get Connector with Merge Agent Handler

Retrieves a connector from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/connectors/:connector_slug/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Get Connector](https://docs.merge.dev/merge-agent-handler/agent-handler/connectors/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connector_slug` | path | `string` | no | Slug of the connector. |
