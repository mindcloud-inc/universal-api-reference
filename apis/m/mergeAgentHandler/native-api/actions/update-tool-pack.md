# Update Tool Pack with Merge Agent Handler

Updates a tool pack in Merge Agent Handler.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tool-packs/:tool_pack_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Update Tool Pack](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-packs/partial-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
