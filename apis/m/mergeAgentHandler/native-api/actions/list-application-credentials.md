# List Application Credentials with Merge Agent Handler

Retrieves application credentials from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/application-credentials/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Application Credentials](https://docs.merge.dev/merge-agent-handler/agent-handler/application-credentials/list)
