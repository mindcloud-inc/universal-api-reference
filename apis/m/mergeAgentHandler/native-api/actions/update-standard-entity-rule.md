# Update Standard Entity Rule with Merge Agent Handler

Updates a standard entity rule in Merge Agent Handler.

## Endpoint

- **Method:** `PUT`
- **Path:** `/security/standard-entity-rules/:entity_type/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Update Standard Entity Rule](https://docs.merge.dev/merge-agent-handler/agent-handler/standard-entity-rules/update-standard-entity-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity_type` | path | `string` | no | Entity type for the standard entity rule. |
