# List Standard Entity Rules with Merge Agent Handler

Retrieves standard entity rules from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/security/standard-entity-rules/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [List Standard Entity Rules](https://docs.merge.dev/merge-agent-handler/agent-handler/standard-entity-rules/list-standard-entity-rules)
