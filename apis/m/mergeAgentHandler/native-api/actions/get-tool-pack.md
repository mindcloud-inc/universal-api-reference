# Get Tool Pack with Merge Agent Handler

Retrieves a tool pack from Merge Agent Handler.

## Endpoint

- **Method:** `GET`
- **Path:** `/tool-packs/:tool_pack_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Get Tool Pack](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-packs/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
