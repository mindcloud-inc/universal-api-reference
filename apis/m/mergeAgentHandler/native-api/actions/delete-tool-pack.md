# Delete Tool Pack with Merge Agent Handler

Deletes a tool pack from Merge Agent Handler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tool-packs/:tool_pack_id/`
- **Base URL:** `https://ah-api.merge.dev/api/v1`
- **Official documentation:** [Delete Tool Pack](https://docs.merge.dev/merge-agent-handler/agent-handler/tool-packs/destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tool_pack_id` | path | `string` | no | ID of the tool pack. |
