# Get Content By ID with Metance

Retrieves content from Metance by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contents/{id}`
- **Base URL:** `https://api.metance.com`
- **Official documentation:** [Get Content By ID](https://api.metance.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Metance content identifier. |
