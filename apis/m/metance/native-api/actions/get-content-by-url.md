# Get Content By URL with Metance

Retrieves content from Metance by URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/contents/Url/{url}`
- **Base URL:** `https://api.metance.com`
- **Official documentation:** [Get Content By URL](https://api.metance.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | path | `string` | yes | Metance content URL slug. |
