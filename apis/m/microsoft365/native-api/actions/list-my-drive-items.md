# List My Drive Items with Microsoft 365

Retrieves items in your drive from Microsoft 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/drive/root/children`
- **Base URL:** `https://graph.microsoft.com`
- **API:** REST (skip pagination)
- **Official documentation:** [List My Drive Items](https://learn.microsoft.com/en-us/graph/api/driveitem-list-children?view=graph-rest-1.0)
