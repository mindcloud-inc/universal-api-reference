# List Task Lists with Microsoft 365

Retrieves task lists from Microsoft 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/todo/lists`
- **Base URL:** `https://graph.microsoft.com`
- **API:** REST (skip pagination)
- **Official documentation:** [List Task Lists](https://learn.microsoft.com/en-us/graph/api/todo-list-lists?view=graph-rest-1.0)
