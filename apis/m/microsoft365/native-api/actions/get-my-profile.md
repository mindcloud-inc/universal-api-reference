# Get My Profile with Microsoft 365

Retrieves your Microsoft 365 profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me`
- **Base URL:** `https://graph.microsoft.com`
- **API:** REST (skip pagination)
- **Official documentation:** [Get My Profile](https://learn.microsoft.com/en-us/graph/api/user-get?view=graph-rest-1.0)
