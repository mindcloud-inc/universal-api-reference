# Get My Drive with Microsoft 365

Retrieves your drive from Microsoft 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/drive`
- **Base URL:** `https://graph.microsoft.com`
- **API:** REST (skip pagination)
- **Official documentation:** [Get My Drive](https://learn.microsoft.com/en-us/graph/api/drive-get?view=graph-rest-1.0)
