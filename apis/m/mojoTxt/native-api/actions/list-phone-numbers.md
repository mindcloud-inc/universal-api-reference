# List Phone Numbers with MojoTxt

Retrieves phone numbers from MojoTxt.

## Endpoint

- **Method:** `GET`
- **Path:** `/phoneNumbers/list`
- **Base URL:** `https://app.mojotxt.com/api/v1`
- **Official documentation:** [List Phone Numbers](https://app.mojotxt.com/api/docs/v1/phoneNumbers-list.php)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
