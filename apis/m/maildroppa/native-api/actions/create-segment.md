# Create Segment with Maildroppa

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriber/segment`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Create Segment](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expression` | body | `string` | no | Filter expression defining the segment criteria. |
| `name` | body | `string` | no | Display name for the segment. |
