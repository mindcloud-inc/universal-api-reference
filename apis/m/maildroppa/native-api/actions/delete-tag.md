# Delete Tag with Maildroppa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tag-type/{tagId}`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Tag](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Unique identifier of the tag to remove. |
