# Update Tag with Maildroppa

## Endpoint

- **Method:** `PUT`
- **Path:** `/tag-type`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Update Tag](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | body | `string` | no | Technical tag category. |
| `id` | body | `string` | no | Unique identifier of the tag. |
| `name` | body | `string` | no | Name of the tag type. |
