# Delete Subscriber with Maildroppa

Deletes a subscriber from Maildroppa by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/{subscriberId}`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Subscriber](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriberId` | path | `string` | yes | UUID of the subscriber. |
