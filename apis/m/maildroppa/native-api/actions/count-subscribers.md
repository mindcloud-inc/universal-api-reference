# Count Subscribers with Maildroppa

Counts Maildroppa subscribers by status.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/count`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Count Subscribers](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional subscriber status to count. |
