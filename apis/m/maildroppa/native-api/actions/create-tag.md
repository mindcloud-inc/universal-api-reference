# Create Tag with Maildroppa

## Endpoint

- **Method:** `POST`
- **Path:** `/tag-type`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Create Tag](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Name of the tag type. |
