# Delete Subscribers with Maildroppa

Deletes multiple subscribers from Maildroppa by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Subscribers](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `items[]` | body | `array` | yes |
