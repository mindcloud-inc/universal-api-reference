# Get Segment with Maildroppa

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriber/segment/{segmentId}`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Get Segment](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Unique identifier of the segment. |
