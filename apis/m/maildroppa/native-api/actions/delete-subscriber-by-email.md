# Delete Subscriber By Email with Maildroppa

Deletes a subscriber from Maildroppa by email address.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/by-email/{email}`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Subscriber By Email](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | path | `string` | no |
