# Delete Subscribers By Status with Maildroppa

Deletes all Maildroppa subscribers for a selected status.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/all`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Subscribers By Status](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Subscriber status filter. |
