# Delete Segment with Maildroppa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscriber/segment/{subscriberSegmentId}`
- **Base URL:** `https://api.maildroppa.com`
- **Official documentation:** [Delete Segment](https://api.maildroppa.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriberSegmentId` | path | `string` | yes | Unique identifier of the segment to remove. |
