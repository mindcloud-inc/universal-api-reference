# List Calendars with Microsoft 365 Calendar

Retrieves calendars from Microsoft 365 Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/calendars`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [List Calendars](https://learn.microsoft.com/en-us/graph/api/user-list-calendars?view=graph-rest-1.0)
