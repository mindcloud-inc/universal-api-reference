# Resend verification email with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/users/resend-verification-link`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Resend verification email](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
