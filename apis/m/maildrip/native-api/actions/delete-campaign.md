# Delete campaign with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/campaigns/{campaignId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | ID of the campaign to delete |
