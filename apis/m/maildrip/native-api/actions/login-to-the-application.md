# Login to the application with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/users/login`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Login to the application](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
| `password` | body | `string` | no |
