# Retrieve a campaign by ID with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaigns/{campaign_id}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Retrieve a campaign by ID](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign to retrieve |
