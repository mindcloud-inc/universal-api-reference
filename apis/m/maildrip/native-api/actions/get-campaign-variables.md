# Get campaign variables with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaigns/{campaign_id}/variables`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get campaign variables](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign to get variables from |
