# Add a user to the campaign with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/campaigns/{campaign_id}/user`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Add a user to the campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign to add the user to |
