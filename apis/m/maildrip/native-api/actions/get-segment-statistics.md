# Get segment statistics with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/segments/{id}/stats`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get segment statistics](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Segment ID |
