# Retrieve data of a campaign with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaigns/{campaign_id}/get-data`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Retrieve data of a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign to retrieve data from |
