# Get contacts in a specific group or all contacts with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/group`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get contacts in a specific group or all contacts](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `string` | no |
| `page` | query | `number` | no |
| `search` | query | `string` | no |
| `groupId` | query | `string` | no |
| `attributeFilters` | query | `string` | no |
