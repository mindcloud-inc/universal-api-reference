# Delete a sending domain from Mumara with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/mumara/sending-domains/{id}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete a sending domain from Mumara](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the sending domain to delete |
