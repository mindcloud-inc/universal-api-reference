# Update subscription plan with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/payment/paystack/subscriptions/update`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update subscription plan](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `planId` | body | `string` | no |
| `callback_url` | body | `string` | no |
| `cancel_url` | body | `string` | no |
