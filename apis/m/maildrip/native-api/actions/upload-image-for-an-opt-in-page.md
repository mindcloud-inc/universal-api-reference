# Upload image for an opt-in page with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/opt-in-pages/image-upload`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Upload image for an opt-in page](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | no | Image file to upload (max 12MB) |
