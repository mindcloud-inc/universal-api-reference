# Update email content for a campaign with Maildrip

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/campaigns/{campaignId}/{emailId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update email content for a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | ID of the campaign |
| `emailId` | path | `string` | yes | ID of the email |
