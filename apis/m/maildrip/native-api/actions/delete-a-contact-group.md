# Delete a contact group with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contacts/groups/{groupId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete a contact group](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | ID of the contact group to be deleted |
