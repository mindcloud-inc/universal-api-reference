# Save email draft for a campaign with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/campaigns/{campaign_id}/save-draft`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Save email draft for a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign |
