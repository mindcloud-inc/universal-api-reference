# Google OAuth signup or login with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/oauth/google`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Google OAuth signup or login](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tokenId` | body | `string` | no |
