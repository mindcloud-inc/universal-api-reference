# Import contacts to a campaign with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/{campaignId}/contacts/import`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Import contacts to a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | ID of the campaign to import contacts to |
