# Delete instant email by ID with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/instant-emails/{emailId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete instant email by ID](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailId` | path | `string` | yes | ID of the instant email to delete |
