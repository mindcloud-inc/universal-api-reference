# Update email configuration for a campaign with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/campaigns/{campaign_id}/email-configuration`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update email configuration for a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | ID of the campaign |
