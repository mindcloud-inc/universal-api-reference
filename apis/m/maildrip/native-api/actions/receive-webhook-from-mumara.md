# Receive webhook from Mumara with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/mumara/webhook`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Receive webhook from Mumara](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `value` | body | `object` | yes |
