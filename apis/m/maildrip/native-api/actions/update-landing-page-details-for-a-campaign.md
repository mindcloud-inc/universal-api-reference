# Update landing page details for a campaign with Maildrip

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/campaigns/{campaignId}/landing-page`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update landing page details for a campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | ID of the campaign |
