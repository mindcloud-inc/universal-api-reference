# Modify contacts by adding them to specified groups and optionally to a campaign. with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts/modify/{groupId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Modify contacts by adding them to specified groups and optionally to a campaign.](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | ID of the group to modify contacts in. |
