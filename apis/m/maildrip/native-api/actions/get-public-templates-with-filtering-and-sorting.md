# Get public templates with filtering and sorting with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/templates/public`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get public templates with filtering and sorting](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Filter by template category |
| `sort` | query | `string` | no | Sort order |
| `limit` | query | `number` | no | — |
| `skip` | query | `number` | no | — |
