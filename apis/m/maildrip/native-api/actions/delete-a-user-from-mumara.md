# Delete a user from Mumara with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/mumara/users/delete/{type}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete a user from Mumara](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `type` | path | `string` | yes |
