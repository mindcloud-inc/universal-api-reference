# Delete a card with Maildrip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/payment/paystack/cards/{authorization}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Delete a card](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `authorization` | path | `string` | yes | The authorization code of the card to be deleted |
