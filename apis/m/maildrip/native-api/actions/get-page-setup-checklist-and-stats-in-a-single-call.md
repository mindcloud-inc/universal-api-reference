# Get page, setup, checklist, and stats in a single call with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/opt-in-pages/{pageId}/editor-summary`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get page, setup, checklist, and stats in a single call](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pageId` | path | `string` | yes |
