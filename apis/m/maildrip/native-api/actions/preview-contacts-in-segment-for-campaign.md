# Preview contacts in segment for campaign with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaigns/{campaignId}/segment/preview`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Preview contacts in segment for campaign](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | ID of the campaign |
