# Unpublish an opt-in page with Maildrip

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/opt-in-pages/{pageId}/unpublish`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Unpublish an opt-in page](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the opt-in page to unpublish |
