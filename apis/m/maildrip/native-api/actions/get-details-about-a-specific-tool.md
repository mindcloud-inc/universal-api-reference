# Get details about a specific tool with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mcp/tools/{toolName}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get details about a specific tool](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `toolName` | path | `string` | yes | Name of the tool to get details for |
