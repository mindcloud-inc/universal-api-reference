# Register a new user with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/users/register`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Register a new user](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
| `name` | body | `string` | no |
| `password` | body | `string` | no |
| `phone` | body | `string` | no |
| `companyRole` | body | `string` | no |
| `companyName` | body | `string` | no |
