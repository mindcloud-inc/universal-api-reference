# Clone a public template or user-owned template with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/templates/clone/{templateId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Clone a public template or user-owned template](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | ID of template to clone |
