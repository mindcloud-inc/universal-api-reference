# Update a user's subscription plan with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/payment/stripe/subscription/update`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update a user's subscription plan](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `priceId` | body | `string` | no | The ID of the new price plan |
