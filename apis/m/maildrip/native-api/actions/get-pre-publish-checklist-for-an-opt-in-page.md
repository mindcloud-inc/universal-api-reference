# Get pre-publish checklist for an opt-in page with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/opt-in-pages/{pageId}/pre-publish-check`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get pre-publish checklist for an opt-in page](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pageId` | path | `string` | yes |
