# Get landing page by ID with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/landing-page/{pageId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get landing page by ID](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the landing page to retrieve |
