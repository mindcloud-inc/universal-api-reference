# Send reset password email with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/users/forget-password`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Send reset password email](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
