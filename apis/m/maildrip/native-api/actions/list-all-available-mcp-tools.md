# List all available MCP tools with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mcp/tools`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [List all available MCP tools](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Filter tools by category |
