# Clone an instant email with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/instant-emails/clone/{emailId}`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Clone an instant email](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailId` | path | `string` | yes | ID of the email to clone |
