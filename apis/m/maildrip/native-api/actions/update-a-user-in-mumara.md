# Update a user in Mumara with Maildrip

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/mumara/users/update`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Update a user in Mumara](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `email` | body | `string` | no |
| `package_id` | body | `number` | no |
| `timezone` | body | `string` | no |
