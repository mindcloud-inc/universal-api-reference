# Create a new opt-in page with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/opt-in-pages`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Create a new opt-in page](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | Title of the opt-in page |
