# Get contact counts for an opt-in page's linked groups with Maildrip

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/opt-in-pages/{pageId}/stats`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Get contact counts for an opt-in page's linked groups](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the opt-in page |
