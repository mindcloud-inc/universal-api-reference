# Create a new contacts group with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts/groups`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Create a new contacts group](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | no |
| `description` | body | `string` | no |
