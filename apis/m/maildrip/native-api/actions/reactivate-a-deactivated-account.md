# Reactivate a deactivated account with Maildrip

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/users/reactivate-account`
- **Base URL:** `https://api.maildrip.io`
- **Official documentation:** [Reactivate a deactivated account](https://api.maildrip.io/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
