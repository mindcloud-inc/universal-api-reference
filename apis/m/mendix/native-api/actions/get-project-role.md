# Get Project Role with Mendix

Retrieves a project role from Mendix.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:roleId`
- **Base URL:** `https://projects-api.home.mendix.com/v2`
- **API:** rest
- **Official documentation:** [Get Project Role](https://docs.mendix.com/apidocs-mxsdk/apidocs/projects-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `role-id` | path | `string` | yes | The unique identifier of a project role. |
