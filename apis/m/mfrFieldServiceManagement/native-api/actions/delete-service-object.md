# Delete Service Object with mfr Field Service Management

Deletes a service object from mfr Field Service Management.

## Endpoint

- **Method:** `DELETE`
- **Path:** `ServiceObjects({{id}}L)`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [Delete Service Object](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
