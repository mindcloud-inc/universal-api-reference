# List Appointments with mfr Field Service Management

Retrieves appointments from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `Appointments`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Appointments](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
