# List Service Requests with mfr Field Service Management

Retrieves service requests from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `ServiceRequests`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Service Requests](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
