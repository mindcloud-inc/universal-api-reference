# List Service Objects with mfr Field Service Management

Retrieves service objects from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `ServiceObjects`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Service Objects](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
