# List Contacts with mfr Field Service Management

Retrieves contacts from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `Contacts`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Contacts](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
