# List Companies with mfr Field Service Management

Retrieves companies from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `Companies`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Companies](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
