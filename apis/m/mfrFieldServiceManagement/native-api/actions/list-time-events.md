# List Time Events with mfr Field Service Management

Retrieves time events from mfr Field Service Management.

## Endpoint

- **Method:** `GET`
- **Path:** `TimeEvents`
- **Base URL:** `https://portal.mobilefieldreport.com/odata`
- **Official documentation:** [List Time Events](https://documenter.getpostman.com/view/6932380/2sB3dWsn6U)

## Capabilities

This operation supports [pagination](../README.md#pagination).
