# Check If Email Can Send with MailSlurp Email Plugin

Checks whether MailSlurp can send an email.

## Endpoint

- **Method:** `POST`
- **Path:** `/emails/can-send`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Check If Email Can Send](https://api.mailslurp.com/swagger-ui/index.html#/EmailController/canSend)
