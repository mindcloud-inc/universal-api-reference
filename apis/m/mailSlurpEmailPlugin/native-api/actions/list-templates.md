# List Templates with MailSlurp Email Plugin

Retrieves templates from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Templates](https://api.mailslurp.com/swagger-ui/index.html#/TemplateController/getTemplates)
