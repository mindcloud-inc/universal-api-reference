# List Contacts with MailSlurp Email Plugin

Retrieves contacts from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Contacts](https://api.mailslurp.com/swagger-ui/index.html#/ContactController/getContacts)
