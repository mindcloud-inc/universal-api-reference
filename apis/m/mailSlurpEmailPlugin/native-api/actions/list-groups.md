# List Groups with MailSlurp Email Plugin

Retrieves groups from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Groups](https://api.mailslurp.com/swagger-ui/index.html#/GroupController/getGroups)
