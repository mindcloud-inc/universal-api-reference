# Search Emails with MailSlurp Email Plugin

Finds emails in MailSlurp by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/emails/search`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Search Emails](https://api.mailslurp.com/swagger-ui/index.html#/EmailController/searchEmails)
