# Search Inboxes with MailSlurp Email Plugin

Finds inboxes in MailSlurp by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/inboxes/search`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Search Inboxes](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/searchInboxes)
