# List Webhooks with MailSlurp Email Plugin

Retrieves webhooks from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/paginated`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Webhooks](https://api.mailslurp.com/swagger-ui/index.html#/WebhookController/getAllWebhooks)
