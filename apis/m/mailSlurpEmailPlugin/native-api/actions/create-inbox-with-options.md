# Create Inbox With Options with MailSlurp Email Plugin

Creates a new inbox in MailSlurp with custom options.

## Endpoint

- **Method:** `POST`
- **Path:** `/inboxes/withOptions`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Create Inbox With Options](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/createInboxWithOptions)
