# List Attachments with MailSlurp Email Plugin

Retrieves attachments from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Attachments](https://api.mailslurp.com/swagger-ui/index.html#/AttachmentController/getAttachments)
