# Get Email with MailSlurp Email Plugin

Retrieves a hydrated email from MailSlurp.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:emailId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Get Email](https://api.mailslurp.com/swagger-ui/index.html#/EmailController/getEmail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailId` | path | `string` | no | The MailSlurp email ID. |
