# Create Template with MailSlurp Email Plugin

Creates a new template in MailSlurp.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Create Template](https://api.mailslurp.com/swagger-ui/index.html#/TemplateController/createTemplate)
