# Upload Attachment with MailSlurp Email Plugin

Uploads an attachment to your MailSlurp account.

## Endpoint

- **Method:** `POST`
- **Path:** `/attachments`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Upload Attachment](https://api.mailslurp.com/swagger-ui/index.html#/AttachmentController/uploadAttachment)
