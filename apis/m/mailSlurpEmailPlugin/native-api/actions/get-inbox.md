# Get Inbox with MailSlurp Email Plugin

Retrieves an inbox and its details from MailSlurp.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxes/:inboxId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Get Inbox](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/getInbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | no | The MailSlurp inbox ID. |
