# Create Inbox With Defaults with MailSlurp Email Plugin

Creates a new inbox in MailSlurp with default settings.

## Endpoint

- **Method:** `POST`
- **Path:** `/inboxes/withDefaults`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Create Inbox With Defaults](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/createInboxWithDefaults)
