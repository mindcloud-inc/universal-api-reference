# List Inboxes with MailSlurp Email Plugin

Retrieves inboxes and email addresses from MailSlurp.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxes`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Inboxes](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/getInboxes)
