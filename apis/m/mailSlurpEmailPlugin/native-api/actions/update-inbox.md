# Update Inbox with MailSlurp Email Plugin

Updates an existing inbox in MailSlurp.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/inboxes/:inboxId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Update Inbox](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/updateInbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | no | The MailSlurp inbox ID. |
