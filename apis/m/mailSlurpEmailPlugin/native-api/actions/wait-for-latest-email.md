# Wait For Latest Email with MailSlurp Email Plugin

Retrieves the latest email from MailSlurp, waiting if needed.

## Endpoint

- **Method:** `GET`
- **Path:** `/waitForLatestEmail`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Wait For Latest Email](https://api.mailslurp.com/swagger-ui/index.html#/WaitForController/waitForLatestEmail)
