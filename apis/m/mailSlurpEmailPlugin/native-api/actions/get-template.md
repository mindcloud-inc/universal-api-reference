# Get Template with MailSlurp Email Plugin

Retrieves a template from your MailSlurp account.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Get Template](https://api.mailslurp.com/swagger-ui/index.html#/TemplateController/getTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | no | The MailSlurp template ID. |
