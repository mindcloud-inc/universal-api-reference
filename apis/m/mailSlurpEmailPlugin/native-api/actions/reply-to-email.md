# Reply To Email with MailSlurp Email Plugin

Replies to an email in MailSlurp.

## Endpoint

- **Method:** `PUT`
- **Path:** `/emails/:emailId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Reply To Email](https://api.mailslurp.com/swagger-ui/index.html#/EmailController/replyToEmail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailId` | path | `string` | no | The MailSlurp email ID to reply to. |
