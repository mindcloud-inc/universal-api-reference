# Delete Inbox with MailSlurp Email Plugin

Deletes an existing inbox from MailSlurp.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inboxes/:inboxId`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Delete Inbox](https://api.mailslurp.com/swagger-ui/index.html#/InboxController/deleteInbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxId` | path | `string` | no | The MailSlurp inbox ID. |
