# List Emails with MailSlurp Email Plugin

Retrieves emails across all MailSlurp inboxes.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [List Emails](https://api.mailslurp.com/swagger-ui/index.html#/EmailController/getEmailsPaginated)
