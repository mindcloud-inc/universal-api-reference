# Wait For Matching Emails with MailSlurp Email Plugin

Waits for MailSlurp emails that match the given filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/waitForMatchingEmails`
- **Base URL:** `https://api.mailslurp.com`
- **Official documentation:** [Wait For Matching Emails](https://api.mailslurp.com/swagger-ui/index.html#/WaitForController/waitForMatchingEmails)
