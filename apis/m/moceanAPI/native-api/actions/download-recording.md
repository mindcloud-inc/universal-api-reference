# Download Recording with Mocean API

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/2/voice/rec`
- **Base URL:** `https://rest.moceanapi.com`
- **Official documentation:** [Download Recording](https://moceanapi.com/docs#download-a-recording)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mocean-call-uuid` | query | `string` | yes | The call UUID for the recording. |
