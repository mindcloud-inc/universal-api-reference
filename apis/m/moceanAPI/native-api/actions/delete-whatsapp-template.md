# Delete WhatsApp Template with Mocean API

## Endpoint

- **Method:** `DELETE`
- **Path:** `/template/whatsapp/message_templates`
- **Base URL:** `https://rest.moceanapi.com`
- **Official documentation:** [Delete WhatsApp Template](https://moceanapi.com/docs#delete-whatsapp-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hsm-id` | query | `string` | no | Optional WhatsApp template ID. |
| `name` | query | `string` | no | Template name to delete. |
