# Get WhatsApp Template with Mocean API

## Endpoint

- **Method:** `GET`
- **Path:** `/template/whatsapp/:templateId`
- **Base URL:** `https://rest.moceanapi.com`
- **Official documentation:** [Get WhatsApp Template](https://moceanapi.com/docs#get-template-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | The WhatsApp template ID. |
