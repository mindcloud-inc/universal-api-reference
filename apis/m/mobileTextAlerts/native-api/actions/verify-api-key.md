# Verify API Key with Mobile Text Alerts

Retrieves API key verification details from Mobile Text Alerts.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/verify-api-key`
- **Base URL:** `https://api.mobile-text-alerts.com/v3`
- **Official documentation:** [Verify API Key](https://developers.mobile-text-alerts.com/getting-started/get-an-api-key#get-auth-verify-api-key)
