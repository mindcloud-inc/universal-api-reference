# List Templates with Mobile Text Alerts

Retrieves templates from Mobile Text Alerts.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.mobile-text-alerts.com/v3`
- **Official documentation:** [List Templates](https://developers.mobile-text-alerts.com/api-reference/templates#get-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to retrieve. |
| `pageSize` | query | `number` | no | Number of templates per page. |
