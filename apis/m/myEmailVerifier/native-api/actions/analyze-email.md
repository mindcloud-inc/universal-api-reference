# Analyze Email with MyEmailVerifier

Analyzes an email address in MyEmailVerifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-analysis/analyze/:email/{apiKey}`
- **Base URL:** `https://client.myemailverifier.com`
- **Official documentation:** [Analyze Email](https://client.myemailverifier.com/email-analysis/analyze/test@example.com/XIMjcL0QD5S7XQi0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | The email address to analyze. |
