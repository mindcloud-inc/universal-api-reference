# Get Email Analysis Status with MyEmailVerifier

Retrieves email analysis service status from MyEmailVerifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-analysis/status/{apiKey}`
- **Base URL:** `https://client.myemailverifier.com`
- **Official documentation:** [Get Email Analysis Status](https://client.myemailverifier.com/email-analysis/status/XIMjcL0QD5S7XQi0)
