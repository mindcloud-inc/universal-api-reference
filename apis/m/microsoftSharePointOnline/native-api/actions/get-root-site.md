# Get Root Site with Microsoft SharePoint Online

Retrieves the root site from Microsoft SharePoint Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/sites/root`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [Get Root Site](https://learn.microsoft.com/en-us/graph/api/site-get?view=graph-rest-1.0)
