# Get Address Summary with Mempool

Retrieves summary details for an address from Mempool.

## Endpoint

- **Method:** `GET`
- **Path:** `/address/[:address]`
- **Base URL:** `https://mempool.space/api`
- **Official documentation:** [Get Address Summary](https://mempool.space/docs/api/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | Bitcoin address to inspect. |
