# Get Lead with Myphoner

Retrieves details for a lead from Myphoner.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [Get Lead](https://www.myphoner.com/docs/api/#leads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `number` | yes | The Myphoner lead ID. |
