# Get List with Myphoner

Retrieves details for a list from Myphoner.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [Get List](https://www.myphoner.com/docs/api/#lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | The Myphoner list ID. |
