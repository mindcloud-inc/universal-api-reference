# List Columns for List with Myphoner

Retrieves column information for a list in Myphoner.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/columns`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [List Columns for List](https://www.myphoner.com/docs/api/#view-columns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | The Myphoner list ID. |
