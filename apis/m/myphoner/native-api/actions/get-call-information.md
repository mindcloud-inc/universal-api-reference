# Get Call Information with Myphoner

Retrieves details for a call from Myphoner.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:callId`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [Get Call Information](https://www.myphoner.com/docs/api/#calls)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callId` | path | `number` | yes | The Myphoner call ID. |
