# Get List Statistics with Myphoner

Retrieves lead statistics for a list in Myphoner.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/stats`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [Get List Statistics](https://www.myphoner.com/docs/api/#lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | The Myphoner list ID. |
