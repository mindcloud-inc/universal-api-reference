# Update Lead with Myphoner

Updates an existing lead in Myphoner.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://{subdomain}.myphoner.com/api/v2`
- **Official documentation:** [Update Lead](https://www.myphoner.com/docs/api/#leads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `number` | yes | The Myphoner lead ID. |
