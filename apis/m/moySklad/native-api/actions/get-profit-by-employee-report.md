# Get profit by employee report with MoySklad

Retrieves the profit by employee report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/profit/byemployee`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get profit by employee report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pribylnost)
