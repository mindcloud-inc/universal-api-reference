# List variants with MoySklad

Retrieves variants from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/variant`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List variants](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-modifikaciq-poluchit-modifikacii)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
