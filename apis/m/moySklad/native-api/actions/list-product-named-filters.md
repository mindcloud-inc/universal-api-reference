# List product named filters with MoySklad

Retrieves product named filters from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/product/namedfilter`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List product named filters](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-sohranennye-filtry)
