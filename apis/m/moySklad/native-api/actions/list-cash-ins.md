# List cash ins with MoySklad

Retrieves cash ins from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/cashin`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List cash ins](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-prihodnyi-order)
