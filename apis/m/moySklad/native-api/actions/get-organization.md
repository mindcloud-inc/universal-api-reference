# Get organization with MoySklad

Retrieves the organization from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/organization/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get organization](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-yurlico-poluchit-yurlico)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
