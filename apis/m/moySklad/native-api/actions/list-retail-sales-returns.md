# List retail sales returns with MoySklad

Retrieves retail sales returns from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/retailsalesreturn`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List retail sales returns](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-roznichnyi-wozwrat)
