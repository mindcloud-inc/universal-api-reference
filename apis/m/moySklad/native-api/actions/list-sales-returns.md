# List sales returns with MoySklad

Retrieves sales returns from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/salesreturn`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List sales returns](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wozwrat-pokupatelia)
