# List countries with MoySklad

Retrieves countries from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/country`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List countries](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-strana-poluchit-strany)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
