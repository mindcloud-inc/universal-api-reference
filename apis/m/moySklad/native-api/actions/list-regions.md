# List regions with MoySklad

Retrieves regions from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/region`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List regions](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-region-poluchit-regiony)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
