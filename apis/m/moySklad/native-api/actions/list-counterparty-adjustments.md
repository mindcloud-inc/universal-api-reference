# List counterparty adjustments with MoySklad

Retrieves counterparty adjustments from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/counterpartyadjustment`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List counterparty adjustments](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-korrektirowka-wzaimoraschetow)
