# List assortment with MoySklad

Retrieves assortment from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/assortment`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List assortment](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-assortiment)
