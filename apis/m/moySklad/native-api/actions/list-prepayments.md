# List prepayments with MoySklad

Retrieves prepayments from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/prepayment`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List prepayments](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-predoplata)
