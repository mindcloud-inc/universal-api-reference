# List demands with MoySklad

Retrieves demands from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/demand`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List demands](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-otgruzka-poluchit-otgruzki)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
