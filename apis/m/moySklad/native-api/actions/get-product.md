# Get product with MoySklad

Retrieves the product from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/product/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get product](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-towar-poluchit-towar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad product id. |
