# List supplies with MoySklad

Retrieves supplies from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/supply`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List supplies](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-priemka-poluchit-priemki)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
