# List prepayment returns with MoySklad

Retrieves prepayment returns from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/prepaymentreturn`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List prepayment returns](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wozwrat-predoplaty)
