# List cash outs with MoySklad

Retrieves cash outs from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/cashout`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List cash outs](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-rashodnyi-order)
