# Get profit by counterparty report with MoySklad

Retrieves the profit by counterparty report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/profit/bycounterparty`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get profit by counterparty report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pribylnost)
