# List sale platforms with MoySklad

Retrieves sale platforms from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/saleplatform`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List sale platforms](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-ploschadka-dlia-prodazh)
