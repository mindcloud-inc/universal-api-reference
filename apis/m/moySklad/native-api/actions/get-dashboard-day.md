# Get dashboard day with MoySklad

Retrieves the dashboard day from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/dashboard/day`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get dashboard day](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-pokazateli)
