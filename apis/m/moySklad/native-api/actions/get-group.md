# Get group with MoySklad

Retrieves the group from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/group/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get group](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-otdel-poluchit-otdel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
