# List serial numbers with MoySklad

Retrieves serial numbers from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/thing`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List serial numbers](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-seriinyi-nomer)
