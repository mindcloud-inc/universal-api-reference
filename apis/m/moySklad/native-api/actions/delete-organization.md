# Delete organization with MoySklad

Deletes an organization from MoySklad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `entity/organization/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Delete organization](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-iurlico)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad organization ID. |
