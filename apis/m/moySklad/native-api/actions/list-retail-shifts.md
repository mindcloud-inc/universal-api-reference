# List retail shifts with MoySklad

Retrieves retail shifts from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/retailshift`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List retail shifts](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-roznichnaia-smena)
