# List production tasks with MoySklad

Retrieves production tasks from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/productiontask`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List production tasks](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-proizwodstwennoe-zadanie)
