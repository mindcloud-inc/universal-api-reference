# Get audit event with MoySklad

Retrieves the audit event from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `audit/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get audit event](https://dev.moysklad.ru/doc/api/remap/1.2/audit/#audit-audit)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad audit event ID. |
