# Get counterparty report with MoySklad

Retrieves the counterparty report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/counterparty`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get counterparty report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pokazateli-kontragentow)
