# List customer orders with MoySklad

Retrieves customer orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/customerorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List customer orders](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-zakaz-pokupatelq-poluchit-zakazy-pokupatelej)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
