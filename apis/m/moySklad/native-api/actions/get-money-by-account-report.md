# Get money by account report with MoySklad

Retrieves the money by account report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/money/byaccount`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get money by account report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-dengi)
