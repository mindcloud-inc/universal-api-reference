# List webhooks with MoySklad

Retrieves webhooks from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/webhook`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List webhooks](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-vebhuki)
