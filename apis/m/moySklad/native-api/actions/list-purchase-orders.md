# List purchase orders with MoySklad

Retrieves purchase orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/purchaseorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List purchase orders](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-zakaz-postawschiku-poluchit-zakazy-postawschikam)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
