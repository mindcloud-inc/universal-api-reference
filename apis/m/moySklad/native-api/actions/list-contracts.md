# List contracts with MoySklad

Retrieves contracts from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/contract`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List contracts](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-dogowor)
