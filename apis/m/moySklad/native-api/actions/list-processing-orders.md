# List processing orders with MoySklad

Retrieves processing orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/processingorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List processing orders](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-zakaz-na-proizwodstwo)
