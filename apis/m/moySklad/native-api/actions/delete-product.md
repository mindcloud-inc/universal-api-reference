# Delete product with MoySklad

Deletes a product from MoySklad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `entity/product/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Delete product](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-towar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad product ID. |
