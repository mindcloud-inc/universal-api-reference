# List processing plan folders with MoySklad

Retrieves processing plan folders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/processingplanfolder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List processing plan folders](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-gruppa-tehkart)
