# List retail demands with MoySklad

Retrieves retail demands from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/retaildemand`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List retail demands](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-roznichnaia-prodazha)
