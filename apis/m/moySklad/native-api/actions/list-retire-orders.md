# List retire orders with MoySklad

Retrieves retire orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/retireorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List retire orders](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wywod-kodow-markirowki-iz-oborota)
