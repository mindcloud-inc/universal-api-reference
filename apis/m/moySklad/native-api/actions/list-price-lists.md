# List price lists with MoySklad

Retrieves price lists from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/pricelist`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List price lists](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-prais-list)
