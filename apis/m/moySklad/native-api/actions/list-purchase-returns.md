# List purchase returns with MoySklad

Retrieves purchase returns from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/purchasereturn`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List purchase returns](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wozwrat-postawschiku)
