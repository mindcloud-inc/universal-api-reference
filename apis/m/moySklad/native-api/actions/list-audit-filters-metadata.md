# List audit filters metadata with MoySklad

Retrieves audit filters metadata from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `audit/metadata/filters`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List audit filters metadata](https://dev.moysklad.ru/doc/api/remap/1.2/audit/#audit-audit)
