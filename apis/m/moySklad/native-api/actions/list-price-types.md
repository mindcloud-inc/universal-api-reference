# List price types with MoySklad

Retrieves price types from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `context/companysettings/pricetype`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List price types](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-tipy-cen)
