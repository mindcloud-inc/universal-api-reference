# Get dashboard month with MoySklad

Retrieves the dashboard month from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/dashboard/month`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get dashboard month](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-pokazateli)
