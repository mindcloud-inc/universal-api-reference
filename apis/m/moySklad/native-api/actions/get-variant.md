# Get variant with MoySklad

Retrieves the variant from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/variant/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get variant](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-modifikaciq-poluchit-modifikaciu)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
