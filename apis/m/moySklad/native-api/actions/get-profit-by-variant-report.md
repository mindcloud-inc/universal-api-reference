# Get profit by variant report with MoySklad

Retrieves the profit by variant report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/profit/byvariant`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get profit by variant report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pribylnost)
