# List services with MoySklad

Retrieves services from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/service`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List services](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-usluga-poluchit-uslugi)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
