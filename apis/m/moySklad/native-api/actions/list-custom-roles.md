# List custom roles with MoySklad

Retrieves custom roles from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/role`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List custom roles](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-polzowatelskie-roli)
