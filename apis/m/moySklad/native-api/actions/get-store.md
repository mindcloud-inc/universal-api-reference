# Get store with MoySklad

Retrieves the store from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/store/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get store](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-sklad-poluchit-sklad)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
