# List payments in with MoySklad

Retrieves payments in from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/paymentin`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List payments in](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-vhodqschij-platezh-poluchit-vhodqschie-platezhi)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
