# List invoices in with MoySklad

Retrieves invoices in from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/invoicein`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List invoices in](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-schet-postawschika-poluchit-scheta-postawschikow)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
