# Get turnover by operations report with MoySklad

Retrieves the turnover by operations report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/turnover/byoperations`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get turnover by operations report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-oboroty)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | yes | MoySklad filter argument. |
