# List bonus programs with MoySklad

Retrieves bonus programs from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/bonusprogram`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List bonus programs](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-bonusnaia-programma)
