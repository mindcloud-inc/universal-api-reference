# Get turnover report with MoySklad

Retrieves the turnover report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/turnover/all`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get turnover report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-oboroty)
