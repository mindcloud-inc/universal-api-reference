# List facture outs with MoySklad

Retrieves facture outs from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/factureout`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List facture outs](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-schet-faktura-wydannyi)
