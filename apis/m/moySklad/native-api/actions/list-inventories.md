# List inventories with MoySklad

Retrieves inventories from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/inventory`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List inventories](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-inventarizaciq-poluchit-inventarizacii)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
