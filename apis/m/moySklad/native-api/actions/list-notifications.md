# List notifications with MoySklad

Retrieves notifications from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `notification`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List notifications](https://dev.moysklad.ru/doc/api/remap/1.2/notification/#uwedomleniia-lenta-uwedomlenii)
