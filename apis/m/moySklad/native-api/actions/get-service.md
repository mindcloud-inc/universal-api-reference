# Get service with MoySklad

Retrieves the service from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/service/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get service](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-usluga-poluchit-uslugu)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
