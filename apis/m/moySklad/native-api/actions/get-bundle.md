# Get bundle with MoySklad

Retrieves the bundle from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/bundle/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get bundle](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-komplekt-poluchit-komplekt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
