# Get current stock by store report with MoySklad

Retrieves the current stock by store report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/stock/bystore/current`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get current stock by store report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-ostatki)
