# List production stage completions with MoySklad

Retrieves production stage completions from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/productionstagecompletion`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List production stage completions](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wypolnenie-jetapa-proizwodstwa)
