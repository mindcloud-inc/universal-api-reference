# Delete service with MoySklad

Deletes a service from MoySklad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `entity/service/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Delete service](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-usluga)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad service ID. |
