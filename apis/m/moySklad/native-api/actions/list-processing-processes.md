# List processing processes with MoySklad

Retrieves processing processes from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/processingprocess`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List processing processes](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-tehprocess)
