# Delete counterparty with MoySklad

Deletes a counterparty from MoySklad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `entity/counterparty/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Delete counterparty](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-kontragent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad counterparty ID. |
