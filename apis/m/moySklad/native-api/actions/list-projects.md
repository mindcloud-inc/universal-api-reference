# List projects with MoySklad

Retrieves projects from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/project`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List projects](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-proekt)
