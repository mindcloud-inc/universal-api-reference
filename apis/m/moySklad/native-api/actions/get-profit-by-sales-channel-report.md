# Get profit by sales channel report with MoySklad

Retrieves the profit by sales channel report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/profit/bysaleschannel`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get profit by sales channel report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pribylnost)
