# Get user settings with MoySklad

Retrieves the user settings from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `context/usersettings`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get user settings](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-nastroiki-polzowatelia)
