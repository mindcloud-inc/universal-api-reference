# Mark all notifications as read with MoySklad

Marks all notifications as read in MoySklad.

## Endpoint

- **Method:** `PUT`
- **Path:** `notification/markasreadall`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Mark all notifications as read](https://dev.moysklad.ru/doc/api/remap/1.2/notification/#uwedomleniia-uwedomlenie)
