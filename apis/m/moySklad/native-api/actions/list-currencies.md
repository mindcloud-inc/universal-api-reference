# List currencies with MoySklad

Retrieves currencies from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/currency`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List currencies](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-valuta-poluchit-valuty)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
