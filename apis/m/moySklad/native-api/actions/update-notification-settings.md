# Update notification settings with MoySklad

Updates notification settings in MoySklad.

## Endpoint

- **Method:** `PUT`
- **Path:** `notification/settings`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Update notification settings](https://dev.moysklad.ru/doc/api/remap/1.2/notification/#uwedomleniia-nastroiki-uwedomlenii)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Notification settings payload. |
