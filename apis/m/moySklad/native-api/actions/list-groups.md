# List groups with MoySklad

Retrieves groups from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/group`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List groups](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-otdel-poluchit-otdely)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
