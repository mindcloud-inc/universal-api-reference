# List moves with MoySklad

Retrieves moves from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/move`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List moves](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-peremeschenie-poluchit-peremescheniq)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
