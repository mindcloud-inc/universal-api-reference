# Get current stock report with MoySklad

Retrieves the current stock report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/stock/all/current`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get current stock report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-ostatki)
