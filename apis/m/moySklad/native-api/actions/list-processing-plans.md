# List processing plans with MoySklad

Retrieves processing plans from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/processingplan`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List processing plans](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-tehkarta)
