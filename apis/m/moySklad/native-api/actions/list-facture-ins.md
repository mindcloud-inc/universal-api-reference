# List facture ins with MoySklad

Retrieves facture ins from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/facturein`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List facture ins](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-schet-faktura-poluchennyi)
