# List payments out with MoySklad

Retrieves payments out from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/paymentout`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List payments out](https://dev.moysklad.ru/doc/api/remap/1.2/#documents-ishodqschij-platezh-poluchit-ishodqschie-platezhi)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
