# List organizations with MoySklad

Retrieves organizations from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/organization`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List organizations](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-yurlico-poluchit-yurlica)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
