# List UOMs with MoySklad

Retrieves UOMs from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/uom`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List UOMs](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-edinica-izmereniia)
