# List employees with MoySklad

Retrieves employees from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/employee`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List employees](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-sotrudnik-poluchit-sotrudnikow)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
