# List consignments with MoySklad

Retrieves consignments from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/consignment`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List consignments](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-partiia)
