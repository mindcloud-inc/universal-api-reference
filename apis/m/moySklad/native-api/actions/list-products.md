# List products with MoySklad

Retrieves products from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/product`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List products](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-towar-poluchit-towary)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
