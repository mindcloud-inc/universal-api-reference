# Get entity metadata with MoySklad

Retrieves the entity metadata from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/:entityType/metadata`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get entity metadata](https://dev.moysklad.ru/doc/api/remap/1.2/workbook/#workbook-metadannye)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityType` | path | `string` | yes | MoySklad entity type. |
