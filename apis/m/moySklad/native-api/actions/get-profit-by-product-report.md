# Get profit by product report with MoySklad

Retrieves the profit by product report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/profit/byproduct`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get profit by product report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pribylnost)
