# Get product folder with MoySklad

Retrieves the product folder from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/productfolder/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get product folder](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-gruppa-towarow-poluchit-gruppu-towarow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
