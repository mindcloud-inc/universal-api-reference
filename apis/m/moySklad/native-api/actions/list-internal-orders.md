# List internal orders with MoySklad

Retrieves internal orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/internalorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List internal orders](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-wnutrennii-zakaz)
