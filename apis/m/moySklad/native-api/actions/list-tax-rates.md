# List tax rates with MoySklad

Retrieves tax rates from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/taxrate`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List tax rates](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-stawka-nds)
