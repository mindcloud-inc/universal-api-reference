# List enters with MoySklad

Retrieves enters from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/enter`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List enters](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-oprihodowanie)
