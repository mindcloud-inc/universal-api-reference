# List discounts with MoySklad

Retrieves discounts from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/discount`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List discounts](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-skidki)
