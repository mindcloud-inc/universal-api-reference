# Get counterparty report by ID with MoySklad

Retrieves the counterparty report from MoySklad by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `report/counterparty/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get counterparty report by ID](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-pokazateli-kontragentow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad counterparty ID. |
