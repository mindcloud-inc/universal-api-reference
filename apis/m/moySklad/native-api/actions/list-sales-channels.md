# List sales channels with MoySklad

Retrieves sales channels from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/saleschannel`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List sales channels](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-kanal-prodazh)
