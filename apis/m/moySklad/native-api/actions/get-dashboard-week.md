# Get dashboard week with MoySklad

Retrieves the dashboard week from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/dashboard/week`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get dashboard week](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-pokazateli)
