# List retail stores with MoySklad

Retrieves retail stores from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/retailstore`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List retail stores](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-tochka-prodazh)
