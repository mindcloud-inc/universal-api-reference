# List product folders with MoySklad

Retrieves product folders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/productfolder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List product folders](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-gruppa-towarow-poluchit-gruppy-towarow)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
