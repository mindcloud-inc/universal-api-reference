# Create service with MoySklad

Creates a service in MoySklad.

## Endpoint

- **Method:** `POST`
- **Path:** `entity/service`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Create service](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-usluga)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Service name. |
