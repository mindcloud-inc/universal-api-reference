# Create store with MoySklad

Creates a store in MoySklad.

## Endpoint

- **Method:** `POST`
- **Path:** `entity/store`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Create store](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-sklad)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Store name. |
