# List variant characteristics with MoySklad

Retrieves variant characteristics from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/variant/metadata/characteristics`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List variant characteristics](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-harakteristiki-modifikacii)
