# List content cards with MoySklad

Retrieves content cards from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/contentcard`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List content cards](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-kartochka-kontenta)
