# Get currency with MoySklad

Retrieves the currency from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/currency/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get currency](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-valuta-poluchit-valutu)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
