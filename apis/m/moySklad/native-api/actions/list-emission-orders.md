# List emission orders with MoySklad

Retrieves emission orders from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/emissionorder`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List emission orders](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-zakaz-kodow-markirowki)
