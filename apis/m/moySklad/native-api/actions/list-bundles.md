# List bundles with MoySklad

Retrieves bundles from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/bundle`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List bundles](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-komplekt-poluchit-komplekty)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
