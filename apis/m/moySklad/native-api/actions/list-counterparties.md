# List counterparties with MoySklad

Retrieves counterparties from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/counterparty`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List counterparties](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-kontragent-poluchit-kontragentow)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
