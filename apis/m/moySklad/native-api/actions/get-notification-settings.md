# Get notification settings with MoySklad

Retrieves the notification settings from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `notification/settings`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get notification settings](https://dev.moysklad.ru/doc/api/remap/1.2/notification/#uwedomleniia-nastroiki-uwedomlenii)
