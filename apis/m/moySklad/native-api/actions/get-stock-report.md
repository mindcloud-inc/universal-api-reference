# Get stock report with MoySklad

Retrieves the stock report from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `report/stock/all`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get stock report](https://dev.moysklad.ru/doc/api/remap/1.2/reports/#otchety-otchet-ostatki)
