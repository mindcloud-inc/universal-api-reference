# Delete store with MoySklad

Deletes a store from MoySklad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `entity/store/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Delete store](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-sklad)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad store ID. |
