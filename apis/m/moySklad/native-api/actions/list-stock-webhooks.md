# List stock webhooks with MoySklad

Retrieves stock webhooks from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/webhookstock`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List stock webhooks](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-vebhuk-na-izmenenie-ostatkow)
