# Create counterparty with MoySklad

Creates a counterparty in MoySklad.

## Endpoint

- **Method:** `POST`
- **Path:** `entity/counterparty`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Create counterparty](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-kontragent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Counterparty name. |
