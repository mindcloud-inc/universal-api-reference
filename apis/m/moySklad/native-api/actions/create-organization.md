# Create organization with MoySklad

Creates an organization in MoySklad.

## Endpoint

- **Method:** `POST`
- **Path:** `entity/organization`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Create organization](https://dev.moysklad.ru/doc/api/remap/1.2/dictionaries/#suschnosti-iurlico)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Organization name. |
