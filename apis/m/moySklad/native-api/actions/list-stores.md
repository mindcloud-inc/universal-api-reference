# List stores with MoySklad

Retrieves stores from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/store`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List stores](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-sklad-poluchit-sklady)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
