# Get employee with MoySklad

Retrieves the employee from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/employee/:id`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [Get employee](https://dev.moysklad.ru/doc/api/remap/1.2/#suschnosti-sotrudnik-poluchit-sotrudnika)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | MoySklad entity id. |
