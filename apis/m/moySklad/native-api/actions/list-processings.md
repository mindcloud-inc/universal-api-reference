# List processings with MoySklad

Retrieves processings from MoySklad.

## Endpoint

- **Method:** `GET`
- **Path:** `entity/processing`
- **Base URL:** `https://api.moysklad.ru/api/remap/1.2`
- **Official documentation:** [List processings](https://dev.moysklad.ru/doc/api/remap/1.2/documents/#dokumenty-tehoperaciia)
