# Retrieve Playback ID Owner with Mux

## Endpoint

- **Method:** `GET`
- **Path:** `/video/v1/playback-ids/{PLAYBACK_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Retrieve Playback ID Owner](https://www.mux.com/docs/api-reference/video/playback-ids)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PLAYBACK_ID` | path | `string` | yes | The Mux playback ID. |
