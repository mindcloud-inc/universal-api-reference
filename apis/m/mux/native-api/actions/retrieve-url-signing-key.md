# Retrieve URL Signing Key with Mux

## Endpoint

- **Method:** `GET`
- **Path:** `/video/v1/signing-keys/{SIGNING_KEY_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Retrieve URL Signing Key](https://www.mux.com/docs/api-reference/video/signing-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SIGNING_KEY_ID` | path | `string` | yes | The URL signing key ID. |
