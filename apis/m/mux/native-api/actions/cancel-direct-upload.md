# Cancel Direct Upload with Mux

## Endpoint

- **Method:** `PUT`
- **Path:** `/video/v1/uploads/{UPLOAD_ID}/cancel`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Cancel Direct Upload](https://www.mux.com/docs/api-reference/video/direct-uploads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UPLOAD_ID` | path | `string` | yes | The upload ID. |
