# Create an Asset with Mux

## Endpoint

- **Method:** `POST`
- **Path:** `/video/v1/assets`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Create an Asset](https://www.mux.com/docs/api-reference/video/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inputs[]` | body | `array<object>` | yes | The input sources for the asset. |
