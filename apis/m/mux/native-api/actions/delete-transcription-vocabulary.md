# Delete Transcription Vocabulary with Mux

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video/v1/transcription-vocabularies/{TRANSCRIPTION_VOCABULARY_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Delete Transcription Vocabulary](https://www.mux.com/docs/api-reference/video/transcription-vocabularies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TRANSCRIPTION_VOCABULARY_ID` | path | `string` | yes | The transcription vocabulary ID. |
