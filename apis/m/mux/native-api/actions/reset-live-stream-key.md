# Reset Live Stream Key with Mux

## Endpoint

- **Method:** `POST`
- **Path:** `/video/v1/live-streams/{LIVE_STREAM_ID}/reset-stream-key`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Reset Live Stream Key](https://www.mux.com/docs/api-reference/video/live-streams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LIVE_STREAM_ID` | path | `string` | yes | The Mux live stream ID. |
