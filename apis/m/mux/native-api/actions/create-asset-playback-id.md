# Create Asset Playback ID with Mux

## Endpoint

- **Method:** `POST`
- **Path:** `/video/v1/assets/{ASSET_ID}/playback-ids`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Create Asset Playback ID](https://www.mux.com/docs/api-reference/video/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ASSET_ID` | path | `string` | yes | The Mux asset ID. |
