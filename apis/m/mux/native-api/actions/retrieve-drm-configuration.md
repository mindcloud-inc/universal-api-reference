# Retrieve DRM Configuration with Mux

## Endpoint

- **Method:** `GET`
- **Path:** `/video/v1/drm-configurations/{DRM_CONFIGURATION_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Retrieve DRM Configuration](https://www.mux.com/docs/api-reference/video/drm-configurations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `DRM_CONFIGURATION_ID` | path | `string` | yes | The DRM configuration ID. |
