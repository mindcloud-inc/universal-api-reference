# Create Direct Upload with Mux

## Endpoint

- **Method:** `POST`
- **Path:** `/video/v1/uploads`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Create Direct Upload](https://www.mux.com/docs/api-reference/video/direct-uploads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cors_origin` | body | `string` | yes | The allowed CORS origin for the upload URL. |
