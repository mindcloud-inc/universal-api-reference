# Retrieve Asset Input Info with Mux

## Endpoint

- **Method:** `GET`
- **Path:** `/video/v1/assets/{ASSET_ID}/input-info`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Retrieve Asset Input Info](https://www.mux.com/docs/api-reference/video/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ASSET_ID` | path | `string` | yes | The Mux asset ID. |
