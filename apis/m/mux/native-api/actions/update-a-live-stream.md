# Update a Live Stream with Mux

## Endpoint

- **Method:** `PATCH`
- **Path:** `/video/v1/live-streams/{LIVE_STREAM_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Update a Live Stream](https://www.mux.com/docs/api-reference/video/live-streams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LIVE_STREAM_ID` | path | `string` | yes | The Mux live stream ID. |
