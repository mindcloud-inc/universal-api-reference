# Signal Live Stream Complete with Mux

## Endpoint

- **Method:** `PUT`
- **Path:** `/video/v1/live-streams/{LIVE_STREAM_ID}/complete`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Signal Live Stream Complete](https://www.mux.com/docs/api-reference/video/live-streams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LIVE_STREAM_ID` | path | `string` | yes | The Mux live stream ID. |
