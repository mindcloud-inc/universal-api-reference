# Delete Asset Track with Mux

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video/v1/assets/{ASSET_ID}/tracks/{TRACK_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Delete Asset Track](https://www.mux.com/docs/api-reference/video/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ASSET_ID` | path | `string` | yes | The Mux asset ID. |
| `TRACK_ID` | path | `string` | yes | The Mux track ID. |
