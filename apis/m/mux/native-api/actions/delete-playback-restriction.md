# Delete Playback Restriction with Mux

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video/v1/playback-restrictions/{PLAYBACK_RESTRICTION_ID}`
- **Base URL:** `https://api.mux.com`
- **Official documentation:** [Delete Playback Restriction](https://www.mux.com/docs/api-reference/video/playback-restrictions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PLAYBACK_RESTRICTION_ID` | path | `string` | yes | The playback restriction ID. |
