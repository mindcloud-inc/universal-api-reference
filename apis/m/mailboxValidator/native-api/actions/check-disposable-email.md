# Check Disposable Email with MailboxValidator

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/email/disposable`
- **Base URL:** `https://api.mailboxvalidator.com`
- **Official documentation:** [Check Disposable Email](https://www.mailboxvalidator.com/api-email-disposable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to check. |
