# Check Free Email Provider with MailboxValidator

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/email/free`
- **Base URL:** `https://api.mailboxvalidator.com`
- **Official documentation:** [Check Free Email Provider](https://www.mailboxvalidator.com/api-email-free)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to check. |
