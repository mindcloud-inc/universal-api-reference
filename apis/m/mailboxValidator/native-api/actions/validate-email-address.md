# Validate Email Address with MailboxValidator

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/validation/single`
- **Base URL:** `https://api.mailboxvalidator.com`
- **Official documentation:** [Validate Email Address](https://www.mailboxvalidator.com/api-single-validation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to validate. |
