# Get Conversation with Missive

Retrieves a conversation from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Get Conversation](https://missiveapp.com/docs/developers/rest-api/endpoints#get-a-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conversation ID. |
