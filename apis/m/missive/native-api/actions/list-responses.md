# List Responses with Missive

Retrieves responses from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/responses`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [List Responses](https://missiveapp.com/docs/developers/rest-api/endpoints#list-responses)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization` | query | `string` | no | Organization ID. |
