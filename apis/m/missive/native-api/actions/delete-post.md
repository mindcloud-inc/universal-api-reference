# Delete Post with Missive

Deletes a post from your Missive workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/posts/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Delete Post](https://missiveapp.com/docs/developers/rest-api/endpoints#delete-a-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Post ID. |
