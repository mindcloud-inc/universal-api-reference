# List Organizations with Missive

Retrieves organizations from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [List Organizations](https://missiveapp.com/docs/developers/rest-api/endpoints#list-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
