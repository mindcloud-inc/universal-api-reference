# Get Response with Missive

Retrieves a response from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/responses/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Get Response](https://missiveapp.com/docs/developers/rest-api/endpoints#get-a-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Response ID. |
