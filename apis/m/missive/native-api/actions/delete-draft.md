# Delete Draft with Missive

Deletes a draft from your Missive workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/drafts/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Delete Draft](https://missiveapp.com/docs/developers/rest-api/endpoints#delete-a-draft)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Draft ID. |
