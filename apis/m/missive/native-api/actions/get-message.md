# Get Message with Missive

Retrieves a message from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Get Message](https://missiveapp.com/docs/developers/rest-api/endpoints#get-a-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Message ID. |
