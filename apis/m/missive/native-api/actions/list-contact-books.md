# List Contact Books with Missive

Retrieves contact books from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_books`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [List Contact Books](https://missiveapp.com/docs/developers/rest-api/endpoints#list-contact-books)

## Capabilities

This operation supports [pagination](../README.md#pagination).
