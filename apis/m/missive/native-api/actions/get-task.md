# Get Task with Missive

Retrieves a task from your Missive workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://public.missiveapp.com/v1`
- **Official documentation:** [Get Task](https://missiveapp.com/docs/developers/rest-api/endpoints#get-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task ID. |
