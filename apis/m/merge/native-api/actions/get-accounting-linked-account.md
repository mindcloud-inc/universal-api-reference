# Get Accounting Linked Account with Merge

## Endpoint

- **Method:** `GET`
- **Path:** `/api/accounting/v1/linked-accounts/{id}`
- **Base URL:** `https://api.merge.dev`
- **Official documentation:** [Get Accounting Linked Account](https://docs.merge.dev/basics/linked-accounts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Merge object ID. |
