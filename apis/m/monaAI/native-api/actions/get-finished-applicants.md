# Get Finished Applicants with Mona AI

Retrieves finished applicants from Mona AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/database/getFinishedApplicantsFromDatabase`
- **Base URL:** `https://api.mona-ai.cloud`
- **Official documentation:** [Get Finished Applicants](https://api-docs.mona-ai.cloud/)
