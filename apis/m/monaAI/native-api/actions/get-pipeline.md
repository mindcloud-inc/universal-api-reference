# Get Pipeline with Mona AI

Retrieves a pipeline from Mona AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/pipeline/get`
- **Base URL:** `https://api.mona-ai.cloud`
- **Official documentation:** [Get Pipeline](https://api-docs.mona-ai.cloud/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pipelineId` | body | `string` | yes | Pipeline identifier to retrieve. |
