# Get Site with MS SharePoint

Retrieves a SharePoint site.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/sites/{{siteId}}`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [Get Site](https://learn.microsoft.com/en-us/graph/api/site-get?view=graph-rest-1.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | Microsoft Graph SharePoint site ID. |
