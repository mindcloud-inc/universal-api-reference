# Get Drive with MS SharePoint

Retrieves a SharePoint drive.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/drives/{{driveId}}`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [Get Drive](https://learn.microsoft.com/en-us/graph/api/drive-get?view=graph-rest-1.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `driveId` | path | `string` | yes | Microsoft Graph drive ID. |
