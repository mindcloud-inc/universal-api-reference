# Get Shipment with MRPeasy

Retrieves a shipment from MRPeasy.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/{{shipmentId}}`
- **Base URL:** `https://api.mrpeasy.com/rest/v1`
- **Official documentation:** [Get Shipment](https://www.mrpeasy.com/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipment_id` | path | `number` | yes | MRPeasy shipment ID. |
