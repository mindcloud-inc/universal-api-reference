# Get Customer with MRPeasy

Retrieves a customer from MRPeasy.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{{customerId}}`
- **Base URL:** `https://api.mrpeasy.com/rest/v1`
- **Official documentation:** [Get Customer](https://www.mrpeasy.com/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | MRPeasy customer ID. |
