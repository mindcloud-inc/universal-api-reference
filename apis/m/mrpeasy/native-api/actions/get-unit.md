# Get Unit with MRPeasy

Retrieves a unit from MRPeasy.

## Endpoint

- **Method:** `GET`
- **Path:** `/units/{{unitId}}`
- **Base URL:** `https://api.mrpeasy.com/rest/v1`
- **Official documentation:** [Get Unit](https://www.mrpeasy.com/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `unit_id` | path | `number` | yes | MRPeasy unit ID. |
