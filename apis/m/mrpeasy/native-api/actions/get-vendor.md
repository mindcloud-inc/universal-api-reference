# Get Vendor with MRPeasy

Retrieves a vendor from MRPeasy.

## Endpoint

- **Method:** `GET`
- **Path:** `/vendors/{{vendorId}}`
- **Base URL:** `https://api.mrpeasy.com/rest/v1`
- **Official documentation:** [Get Vendor](https://www.mrpeasy.com/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendor_id` | path | `number` | yes | MRPeasy vendor ID. |
