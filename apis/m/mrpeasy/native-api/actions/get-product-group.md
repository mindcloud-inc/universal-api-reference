# Get Product Group with MRPeasy

Retrieves a product group from MRPeasy.

## Endpoint

- **Method:** `GET`
- **Path:** `/product-groups/{{groupId}}`
- **Base URL:** `https://api.mrpeasy.com/rest/v1`
- **Official documentation:** [Get Product Group](https://www.mrpeasy.com/resources/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `number` | yes | MRPeasy product group ID. |
