# List Project App Installations with mittwald

Retrieves project app installations from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/app-installations`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project App Installations](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
