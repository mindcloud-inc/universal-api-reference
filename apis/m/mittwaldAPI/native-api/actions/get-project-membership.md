# Get Project Membership with mittwald

Retrieves project membership from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/project-memberships/:projectMembershipId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project Membership](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectMembershipId` | path | `string` | yes | The unique identifier of the project membership. |
