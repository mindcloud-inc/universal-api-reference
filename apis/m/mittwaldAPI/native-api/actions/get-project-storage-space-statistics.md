# Get Project Storage Space Statistics with mittwald

Retrieves project storage space statistics from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/storage-space-statistics`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project Storage Space Statistics](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
