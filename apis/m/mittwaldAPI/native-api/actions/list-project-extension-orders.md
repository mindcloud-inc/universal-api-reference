# List Project Extension Orders with mittwald

Retrieves project extension orders from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/extension-orders`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Extension Orders](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
