# Get Extension with mittwald

Retrieves extension from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/extensions/:extensionId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Extension](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extensionId` | path | `string` | yes | The extension ID. |
