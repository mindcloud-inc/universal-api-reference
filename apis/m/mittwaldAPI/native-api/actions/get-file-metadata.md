# Get File Metadata with mittwald

Retrieves file metadata from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/files/:fileId/meta`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get File Metadata](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File ID |
