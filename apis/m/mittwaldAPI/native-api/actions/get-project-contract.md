# Get Project Contract with mittwald

Retrieves a project's contract from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/contract`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project Contract](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The unique identifier of the project. |
