# List Project Backup Schedules with mittwald

Retrieves project backup schedules from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/backup-schedules`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Backup Schedules](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
