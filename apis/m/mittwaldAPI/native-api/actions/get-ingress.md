# Get Ingress with mittwald

Retrieves ingress from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/ingresses/:ingressId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Ingress](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ingressId` | path | `string` | yes | Ingress ID |
