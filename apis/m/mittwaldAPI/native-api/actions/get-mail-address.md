# Get Mail Address with mittwald

Retrieves mail address from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/mail-addresses/:mailAddressId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Mail Address](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailAddressId` | path | `string` | yes | The unique identifier of the mail address. |
