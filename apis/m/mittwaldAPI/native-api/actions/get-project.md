# Get Project with mittwald

Retrieves project from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The unique identifier of the project. |
