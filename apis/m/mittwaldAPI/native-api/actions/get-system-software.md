# Get System Software with mittwald

Retrieves system software from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/system-softwares/:systemSoftwareId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get System Software](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `systemSoftwareId` | path | `string` | yes | The system software ID. |
