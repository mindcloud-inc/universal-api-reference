# Get Notification Unread Counts with mittwald

Retrieves unread notification counts from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/notifications/unread-counts`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Notification Unread Counts](https://api.mittwald.de/v2/openapi.json)
