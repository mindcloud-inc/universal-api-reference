# Get Notification Unread Counts Alias with mittwald

Retrieves unread notification counts from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/notification-unread-counts`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Notification Unread Counts Alias](https://api.mittwald.de/v2/openapi.json)
