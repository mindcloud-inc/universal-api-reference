# Get Article with mittwald

Retrieves article from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/articles/:articleId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Article](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleId` | path | `string` | yes | Article ID |
