# List Customer AI Hosting Models with mittwald

Retrieves customer AI hosting models from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customers/:customerId/ai-hosting-models`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Customer AI Hosting Models](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer ID |
