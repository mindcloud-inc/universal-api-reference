# Get TLD Contact Schemas with mittwald

Retrieves TLD contact schemas from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/domain-tlds/:tld/contact-schemas`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get TLD Contact Schemas](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tld` | path | `string` | yes | Top-level domain |
