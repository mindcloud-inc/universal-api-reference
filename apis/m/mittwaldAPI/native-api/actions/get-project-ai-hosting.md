# Get Project AI Hosting with mittwald

Retrieves project AI hosting details from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/ai-hosting`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project AI Hosting](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
