# List User Feedback with mittwald

Retrieves user feedback from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/:userId/feedback`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List User Feedback](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID |
