# Get Contributor with mittwald

Retrieves contributor from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contributors/:contributorId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Contributor](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contributorId` | path | `string` | yes | Contributor ID |
