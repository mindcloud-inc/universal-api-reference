# List Project Cronjobs with mittwald

Retrieves project cronjobs from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/cronjobs`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Cronjobs](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
