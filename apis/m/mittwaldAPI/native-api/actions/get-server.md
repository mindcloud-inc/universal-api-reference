# Get Server with mittwald

Retrieves server from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/servers/:serverId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Server](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serverId` | path | `string` | yes | The unique identifier of the server. |
