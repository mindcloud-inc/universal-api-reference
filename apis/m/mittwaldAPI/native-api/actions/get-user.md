# Get User with mittwald

Retrieves user from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/:userId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get User](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User ID |
