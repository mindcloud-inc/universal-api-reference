# Get Project JWT with mittwald

Retrieves a project JWT token from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/jwt`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project JWT](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
