# Get Customer AI Hosting with mittwald

Retrieves customer AI hosting details from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customers/:customerId/ai-hosting`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Customer AI Hosting](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer ID |
