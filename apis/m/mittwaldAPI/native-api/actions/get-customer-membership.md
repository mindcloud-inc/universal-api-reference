# Get Customer Membership with mittwald

Retrieves customer membership from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customer-memberships/:customerMembershipId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Customer Membership](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerMembershipId` | path | `string` | yes | Customer Membership ID |
