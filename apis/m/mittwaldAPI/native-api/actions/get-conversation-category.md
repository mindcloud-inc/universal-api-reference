# Get Conversation Category with mittwald

Retrieves conversation category from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/conversation-categories/:categoryId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Conversation Category](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `string` | yes | Category ID |
