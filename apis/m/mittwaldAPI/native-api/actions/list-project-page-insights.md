# List Project Page Insights with mittwald

Retrieves project page insights from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/page-insights`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Page Insights](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The unique identifier of the project. |
