# Get Password Updated At with mittwald

Retrieves your latest password change timestamp from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/self/credentials/password-updated-at`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Password Updated At](https://api.mittwald.de/v2/openapi.json)
