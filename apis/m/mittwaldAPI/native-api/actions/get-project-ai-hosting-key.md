# Get Project AI Hosting Key with mittwald

Retrieves a project AI hosting key from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/ai-hosting-keys/:keyId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Project AI Hosting Key](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyId` | path | `string` | yes | Key ID |
