# Get Customer with mittwald

Retrieves customer from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customers/:customerId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Customer](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | The unique identifier of the customer. |
