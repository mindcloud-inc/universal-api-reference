# List Project MySQL Databases with mittwald

Retrieves project MySQL databases from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/mysql-databases`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project MySQL Databases](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
