# List Domain Suggestions with mittwald

Retrieves AI-powered domain suggestions from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/domain-suggestions`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Domain Suggestions](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt` | query | `string` | yes | Suggestion prompt |
