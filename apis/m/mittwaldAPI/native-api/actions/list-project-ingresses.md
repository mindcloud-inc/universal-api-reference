# List Project Ingresses with mittwald

Retrieves project ingresses from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/ingresses`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Ingresses](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
