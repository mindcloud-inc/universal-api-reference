# List Project Memberships For Project with mittwald

Retrieves project memberships for a project from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/memberships`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Memberships For Project](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The unique identifier of the project. |
