# Get App with mittwald

Retrieves app from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/apps/:appId`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get App](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The app ID. |
