# List Project Registries with mittwald

Retrieves project registries from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/registries`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Registries](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
