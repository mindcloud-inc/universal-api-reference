# List Project Backups with mittwald

Retrieves project backups from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/backups`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project Backups](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
