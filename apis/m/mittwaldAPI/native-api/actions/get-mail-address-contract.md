# Get Mail Address Contract with mittwald

Retrieves a mail address contract from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/mail-addresses/:mailAddressId/contract`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [Get Mail Address Contract](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailAddressId` | path | `string` | yes | The unique identifier of the mail address. |
