# List Customer AI Hosting Keys with mittwald

Retrieves customer AI hosting keys from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/customers/:customerId/ai-hosting-keys`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Customer AI Hosting Keys](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer ID |
