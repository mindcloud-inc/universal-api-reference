# List Project DNS Zones with mittwald

Retrieves project DNS zones from mittwald API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:projectId/dns-zones`
- **Base URL:** `https://api.mittwald.de`
- **Official documentation:** [List Project DNS Zones](https://api.mittwald.de/v2/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID |
