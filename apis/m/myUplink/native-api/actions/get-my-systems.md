# Get My Systems with myUplink

Retrieves systems for the authenticated myUplink user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/systems/me`
- **Base URL:** `https://api.myuplink.com`
- **Official documentation:** [Get My Systems](https://dev.myuplink.com/swagger/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
