# Search Meals by Name with MealDB

## Endpoint

- **Method:** `GET`
- **Path:** `/search.php`
- **Base URL:** `https://www.themealdb.com/api/json/v1/{apiKey}`
- **Official documentation:** [Search Meals by Name](https://www.themealdb.com/api.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `s` | query | `string` | yes | Meal name search text. |
