# Preview Survey Flow with MerrenIO

## Endpoint

- **Method:** `POST`
- **Path:** `/deploy/createPreviewAndTestSurveyLink/{surveyId}`
- **Base URL:** `https://app.merren.io`
- **Official documentation:** [Preview Survey Flow](https://merren.io/api-integration/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Survey to preview and test. |
