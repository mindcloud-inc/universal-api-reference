# Generate Facebook Messenger Deploy Link with MerrenIO

## Endpoint

- **Method:** `POST`
- **Path:** `/deploy/createSurveyLink/:surveyId`
- **Base URL:** `https://app.merren.io`
- **Official documentation:** [Generate Facebook Messenger Deploy Link](https://merren.io/api-integration/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Merren survey identifier to deploy over Facebook Messenger. |
