# View Individual Table And Pie Chart Responses with MerrenIO

## Endpoint

- **Method:** `GET`
- **Path:** `/survey/getQuestionSummary/:surveyId`
- **Base URL:** `https://app.merren.io`
- **Official documentation:** [View Individual Table And Pie Chart Responses](https://merren.io/api-integration/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Survey identifier to summarize. |
