# List Charge Points with Monta

Retrieves charge points from Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge-points`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [List Charge Points](https://docs.public-api.monta.com/reference/get-charge-points)

## Capabilities

This operation supports [pagination](../README.md#pagination).
