# Get Wallet Transaction with Monta

Retrieves a wallet transaction from Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet-transactions/{transactionId}`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [Get Wallet Transaction](https://docs.public-api.monta.com/reference/get-wallet-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | path | `number` | yes | ID of the wallet transaction to retrieve. |
