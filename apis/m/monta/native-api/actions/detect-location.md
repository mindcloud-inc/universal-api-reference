# Detect Location with Monta

Detects a user's location by IP address in Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/signup/detect-location`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [Detect Location](https://docs.public-api.monta.com/reference/detect-location)
