# Get Personal Wallet with Monta

Retrieves your personal team wallet from Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallets/personal`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [Get Personal Wallet](https://docs.public-api.monta.com/reference/get-personal-wallet)
