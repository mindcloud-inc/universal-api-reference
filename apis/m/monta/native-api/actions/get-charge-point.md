# Get Charge Point with Monta

Retrieves a charge point from Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge-points/{chargePointId}`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [Get Charge Point](https://docs.public-api.monta.com/reference/get-charge-point)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chargePointId` | path | `number` | yes | ID of the Monta charge point to retrieve. |
