# Get Charge with Monta

Retrieves a charge from Monta.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges/{chargeId}`
- **Base URL:** `https://public-api.monta.com/api/v1`
- **Official documentation:** [Get Charge](https://docs.public-api.monta.com/reference/get-charge)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chargeId` | path | `number` | yes | ID of the charge to retrieve. |
