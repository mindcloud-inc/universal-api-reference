# Create Cancellation with Mercado Pago

Cancels a payment in Mercado Pago.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/payments/{payment_id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Create Cancellation](https://www.mercadopago.com.ar/developers/en/reference/chargebacks/_payments_payment_id/put)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `payment_id` | path | `number` | yes |
