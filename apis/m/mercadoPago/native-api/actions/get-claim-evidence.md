# Get Claim Evidence with Mercado Pago

Retrieves claim evidence from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/post-purchase/v1/claims/{claim_id}/evidences`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Claim Evidence](https://www.mercadopago.com.ar/developers/en/reference/claims/get-claim-evidence/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `claim_id` | path | `number` | yes |
