# Get Merchant Order with Mercado Pago

Retrieves a merchant order from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant_orders/{id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Merchant Order](https://www.mercadopago.com.ar/developers/en/reference/merchant_orders/_merchant_orders_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
