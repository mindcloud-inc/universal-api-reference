# Get Order with Mercado Pago

Retrieves an order from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/{order_id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Order](https://www.mercadopago.com.ar/developers/en/reference/orders/_orders_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_id` | path | `string` | yes |
