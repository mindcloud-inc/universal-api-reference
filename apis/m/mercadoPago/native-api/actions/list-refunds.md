# List Refunds with Mercado Pago

Retrieves refunds for a payment from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payments/{id}/refunds`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [List Refunds](https://www.mercadopago.com.ar/developers/en/reference/chargebacks/_payments_id_refunds/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
