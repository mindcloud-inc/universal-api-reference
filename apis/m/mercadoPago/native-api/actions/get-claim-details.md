# Get Claim Details with Mercado Pago

Retrieves claim details from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/post-purchase/v1/claims/{claim_id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Claim Details](https://www.mercadopago.com.ar/developers/en/reference/claims/_claims_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `claim_id` | path | `number` | yes |
