# Get Invoice Data with Mercado Pago

Retrieves invoice data from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/authorized_payments/{id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Invoice Data](https://www.mercadopago.com.ar/developers/en/reference/subscriptions/_authorized_payments_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
