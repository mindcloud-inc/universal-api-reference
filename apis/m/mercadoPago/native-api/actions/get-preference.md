# Get Preference with Mercado Pago

Retrieves a checkout preference from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/preferences/{id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Preference](https://www.mercadopago.com.ar/developers/en/reference/preferences/_checkout_preferences_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
