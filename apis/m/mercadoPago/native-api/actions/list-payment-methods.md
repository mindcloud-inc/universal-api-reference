# List Payment Methods with Mercado Pago

Retrieves payment methods from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payment_methods`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [List Payment Methods](https://www.mercadopago.com.ar/developers/en/reference/payment_methods/overview)
