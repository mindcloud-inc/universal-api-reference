# Get Payment with Mercado Pago

Retrieves a payment from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payments/{id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Payment](https://www.mercadopago.com.ar/developers/en/reference/payments/_payments_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
