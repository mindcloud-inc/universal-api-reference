# Search Subscription Plans with Mercado Pago

Finds subscription plans in Mercado Pago by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/preapproval_plan/search`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Search Subscription Plans](https://www.mercadopago.com.ar/developers/en/reference/subscriptions/_preapproval_plan_search/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `status` | query | `string` | no |
| `q` | query | `string` | no |
| `sort` | query | `string` | no |
| `criteria` | query | `string` | no |
