# Get Chargeback with Mercado Pago

Retrieves a chargeback from Mercado Pago.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/chargebacks/{id}`
- **Base URL:** `https://api.mercadopago.com`
- **Official documentation:** [Get Chargeback](https://www.mercadopago.com.ar/developers/en/reference/chargebacks/_chargebacks_id/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
