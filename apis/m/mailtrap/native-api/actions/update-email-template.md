# Update Email Template with Mailtrap

Updates an existing email template in Mailtrap.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/email_templates/{email_template_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Update Email Template](https://docs.mailtrap.io/developers/management/templates)
