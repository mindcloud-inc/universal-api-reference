# Delete Email Template with Mailtrap

Deletes an existing email template from Mailtrap.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/email_templates/{email_template_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Delete Email Template](https://docs.mailtrap.io/developers/management/templates)
