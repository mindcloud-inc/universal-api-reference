# Get Sending Domain with Mailtrap

Retrieves a sending domain from Mailtrap.

## Endpoint

- **Method:** `GET`
- **Path:** `/sending_domains/{sending_domain_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Sending Domain](https://docs.mailtrap.io/developers/management/sending-domains)
