# Delete Sending Domain with Mailtrap

Deletes an existing sending domain from Mailtrap.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sending_domains/{sending_domain_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Delete Sending Domain](https://docs.mailtrap.io/developers/management/sending-domains)
