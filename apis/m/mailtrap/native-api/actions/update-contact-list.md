# Update Contact List with Mailtrap

Updates an existing contact list in Mailtrap.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts/lists/{list_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Update Contact List](https://docs.mailtrap.io/developers/promotional/contacts/contact-lists)
