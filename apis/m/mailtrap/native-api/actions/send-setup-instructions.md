# Send Setup Instructions with Mailtrap

Sends sending domain setup instructions from Mailtrap.

## Endpoint

- **Method:** `POST`
- **Path:** `/sending_domains/{sending_domain_id}/send_setup_instructions`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Send Setup Instructions](https://docs.mailtrap.io/developers/management/sending-domains)
