# Get Sending Stats by Categories with Mailtrap

Retrieves Mailtrap sending stats by category.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/categories`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Sending Stats by Categories](https://docs.mailtrap.io/developers/management/stats)
