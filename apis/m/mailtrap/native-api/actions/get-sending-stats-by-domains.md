# Get Sending Stats by Domains with Mailtrap

Retrieves Mailtrap sending stats by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/domains`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Sending Stats by Domains](https://docs.mailtrap.io/developers/management/stats)
