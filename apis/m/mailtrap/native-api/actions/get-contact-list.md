# Get Contact List with Mailtrap

Retrieves a contact list from Mailtrap.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/lists/{list_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Contact List](https://docs.mailtrap.io/developers/promotional/contacts/contact-lists)
