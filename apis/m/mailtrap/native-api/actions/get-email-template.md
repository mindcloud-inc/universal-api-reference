# Get Email Template with Mailtrap

Retrieves an email template from Mailtrap.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_templates/{email_template_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Email Template](https://docs.mailtrap.io/developers/management/templates)
