# Get Sending Stats by Date with Mailtrap

Retrieves Mailtrap sending stats by date.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/date`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Get Sending Stats by Date](https://docs.mailtrap.io/developers/management/stats)
