# List Sending Domains with Mailtrap

Retrieves sending domains from Mailtrap.

## Endpoint

- **Method:** `GET`
- **Path:** `/sending_domains`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [List Sending Domains](https://docs.mailtrap.io/developers/management/sending-domains)
