# Delete Contact List with Mailtrap

Deletes an existing contact list from Mailtrap.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/lists/{list_id}`
- **Base URL:** `https://mailtrap.io/api/accounts/:account_id`
- **Official documentation:** [Delete Contact List](https://docs.mailtrap.io/developers/promotional/contacts/contact-lists)
