# Profiles DeleteProfileAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `DELETE`
- **Path:** `admin/profiles/[:profileId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Profiles DeleteProfileAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/profiles-delete-profile-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | The service principal profile ID |
