# Groups CapacityAssignmentStatus with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `groups/[:groupId]/CapacityAssignmentStatus`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Groups CapacityAssignmentStatus](https://learn.microsoft.com/en-us/rest/api/power-bi/capacities/groups-capacity-assignment-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The workspace ID |
