# Dataflows ExportDataflowAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/dataflows/[:dataflowId]/export`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Dataflows ExportDataflowAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/dataflows-export-dataflow-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataflowId` | path | `string` | yes | The dataflow ID |
