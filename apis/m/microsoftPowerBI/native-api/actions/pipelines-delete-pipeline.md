# Delete Pipeline with Microsoft Power BI

## Endpoint

- **Method:** `DELETE`
- **Path:** `pipelines/[:pipelineId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Delete Pipeline](https://learn.microsoft.com/en-us/rest/api/power-bi/pipelines/delete-pipeline)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pipelineId` | path | `string` | yes | The deployment pipeline ID |
