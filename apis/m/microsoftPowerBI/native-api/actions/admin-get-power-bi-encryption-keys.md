# Get Power BI Encryption Keys with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/tenantKeys`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Power BI Encryption Keys](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/get-power-bi-encryption-keys)
