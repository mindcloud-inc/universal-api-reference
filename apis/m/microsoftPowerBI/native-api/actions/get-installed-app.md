# Get Installed App with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `apps/[:appId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Installed App](https://learn.microsoft.com/en-us/rest/api/power-bi/apps/get-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The installed app ID. |
