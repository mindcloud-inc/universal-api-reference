# Capacities GetCapacityUsersAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/capacities/[:capacityId]/users`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Capacities GetCapacityUsersAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/capacities-get-capacity-users-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `capacityId` | path | `string` | yes | The capacity ID |
