# Apps GetAppUsersAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/apps/[:appId]/users`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Apps GetAppUsersAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/apps-get-app-users-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The app ID |
