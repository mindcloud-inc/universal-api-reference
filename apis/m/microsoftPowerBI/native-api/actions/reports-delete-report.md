# Delete Report with Microsoft Power BI

## Endpoint

- **Method:** `DELETE`
- **Path:** `reports/[:reportId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Delete Report](https://learn.microsoft.com/en-us/rest/api/power-bi/reports/delete-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | The report ID |
