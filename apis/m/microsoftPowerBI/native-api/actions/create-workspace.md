# Create Workspace with Microsoft Power BI

## Endpoint

- **Method:** `POST`
- **Path:** `groups`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Create Workspace](https://learn.microsoft.com/en-us/rest/api/power-bi/groups/create-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the new Power BI workspace. |
