# List Workspaces with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `groups`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [List Workspaces](https://learn.microsoft.com/en-us/rest/api/power-bi/groups/get-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `$filter` | query | `string` | no | OData filter expression for narrowing returned workspaces. |
