# List Imports in Workspace with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `groups/[:groupId]/imports`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [List Imports in Workspace](https://learn.microsoft.com/en-us/rest/api/power-bi/imports/get-imports-in-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The workspace ID. |
