# Reports GetReportSubscriptionsAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/reports/[:reportId]/subscriptions`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Reports GetReportSubscriptionsAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/reports-get-report-subscriptions-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | The report ID |
