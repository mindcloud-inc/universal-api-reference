# Datasets GetDatasourcesAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/datasets/[:datasetId]/datasources`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Datasets GetDatasourcesAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/datasets-get-datasources-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | Dataset Id. |
