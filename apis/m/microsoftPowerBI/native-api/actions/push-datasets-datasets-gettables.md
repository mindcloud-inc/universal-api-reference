# Datasets GetTables with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `datasets/[:datasetId]/tables`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Datasets GetTables](https://learn.microsoft.com/en-us/rest/api/power-bi/push-datasets/datasets-get-tables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The dataset ID |
