# Add Dashboard with Microsoft Power BI

## Endpoint

- **Method:** `POST`
- **Path:** `dashboards`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Add Dashboard](https://learn.microsoft.com/en-us/rest/api/power-bi/dashboards/add-dashboard)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the new dashboard |
