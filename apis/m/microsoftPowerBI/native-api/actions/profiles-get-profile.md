# Get Profile with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `profiles/[:profileId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Profile](https://learn.microsoft.com/en-us/rest/api/power-bi/profiles/get-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | The service principal profile ID |
