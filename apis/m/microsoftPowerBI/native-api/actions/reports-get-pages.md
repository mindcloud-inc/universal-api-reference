# Get Pages with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `reports/[:reportId]/pages`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Pages](https://learn.microsoft.com/en-us/rest/api/power-bi/reports/get-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | The report ID |
