# Get Available Feature By Name with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `availableFeatures(featureName='[:featureName]')`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Available Feature By Name](https://learn.microsoft.com/en-us/rest/api/power-bi/available-features/get-available-feature-by-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureName` | path | `string` | yes | The feature name |
