# Get Query Scale Out Sync Status with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `datasets/[:datasetId]/queryScaleOut/syncStatus`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Query Scale Out Sync Status](https://learn.microsoft.com/en-us/rest/api/power-bi/datasets/get-query-scale-out-sync-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The dataset ID |
