# Create Profile with Microsoft Power BI

## Endpoint

- **Method:** `POST`
- **Path:** `profiles`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Create Profile](https://learn.microsoft.com/en-us/rest/api/power-bi/profiles/create-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `displayName` | body | `string` | no | The service principal profile name |
