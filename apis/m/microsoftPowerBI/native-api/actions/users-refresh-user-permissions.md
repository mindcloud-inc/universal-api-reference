# Refresh User Permissions with Microsoft Power BI

## Endpoint

- **Method:** `POST`
- **Path:** `RefreshUserPermissions`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Refresh User Permissions](https://learn.microsoft.com/en-us/rest/api/power-bi/users/refresh-user-permissions)
