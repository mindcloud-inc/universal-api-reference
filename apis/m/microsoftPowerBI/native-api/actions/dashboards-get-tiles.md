# Get Tiles with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `dashboards/[:dashboardId]/tiles`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Tiles](https://learn.microsoft.com/en-us/rest/api/power-bi/dashboards/get-tiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dashboardId` | path | `string` | yes | The dashboard ID |
