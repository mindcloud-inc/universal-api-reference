# Create Temporary Upload Location In Group with Microsoft Power BI

## Endpoint

- **Method:** `POST`
- **Path:** `groups/[:groupId]/imports/createTemporaryUploadLocation`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Create Temporary Upload Location In Group](https://learn.microsoft.com/en-us/rest/api/power-bi/imports/create-temporary-upload-location-in-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The workspace ID |
