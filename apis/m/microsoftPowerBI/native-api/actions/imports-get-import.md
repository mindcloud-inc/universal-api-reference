# Get Import with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `imports/[:importId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Import](https://learn.microsoft.com/en-us/rest/api/power-bi/imports/get-import)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `importId` | path | `string` | yes | The import ID |
