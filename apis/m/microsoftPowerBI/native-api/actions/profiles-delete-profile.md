# Delete Profile with Microsoft Power BI

## Endpoint

- **Method:** `DELETE`
- **Path:** `profiles/[:profileId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Delete Profile](https://learn.microsoft.com/en-us/rest/api/power-bi/profiles/delete-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | The service principal profile ID |
