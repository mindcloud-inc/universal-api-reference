# Get Direct Query Refresh Schedule with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `datasets/[:datasetId]/directQueryRefreshSchedule`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Direct Query Refresh Schedule](https://learn.microsoft.com/en-us/rest/api/power-bi/datasets/get-direct-query-refresh-schedule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The dataset ID |
