# Dashboards GetTilesAsAdmin with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `admin/dashboards/[:dashboardId]/tiles`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Dashboards GetTilesAsAdmin](https://learn.microsoft.com/en-us/rest/api/power-bi/admin/dashboards-get-tiles-as-admin)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dashboardId` | path | `string` | yes | The dashboard ID |
