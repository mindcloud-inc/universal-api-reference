# Get Workloads with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `capacities/[:capacityId]/Workloads`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Get Workloads](https://learn.microsoft.com/en-us/rest/api/power-bi/capacities/get-workloads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `capacityId` | path | `string` | yes | The capacity ID |
