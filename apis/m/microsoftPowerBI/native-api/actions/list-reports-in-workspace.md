# List Reports in Workspace with Microsoft Power BI

## Endpoint

- **Method:** `GET`
- **Path:** `groups/[:groupId]/reports`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [List Reports in Workspace](https://learn.microsoft.com/en-us/rest/api/power-bi/reports/get-reports-in-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The workspace ID. |
