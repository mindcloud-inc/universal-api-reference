# Delete Dataset with Microsoft Power BI

## Endpoint

- **Method:** `DELETE`
- **Path:** `datasets/[:datasetId]`
- **Base URL:** `https://api.powerbi.com/v1.0/myorg`
- **Official documentation:** [Delete Dataset](https://learn.microsoft.com/en-us/rest/api/power-bi/datasets/delete-dataset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The dataset ID |
