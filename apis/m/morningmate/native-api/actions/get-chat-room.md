# Get Chat Room with Morningmate

Retrieves a chat room from Morningmate by room ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/chats/[:roomId]`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Get Chat Room](https://api.morningmate.com/docs/api/v1/chats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `number` | yes | Morningmate numeric chat room ID |
