# Get Employee with Morningmate

Retrieves an employee from Morningmate by user ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/employees/[:userId]`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Get Employee](https://api.morningmate.com/docs/api/v1/employees)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | Morningmate user ID |
