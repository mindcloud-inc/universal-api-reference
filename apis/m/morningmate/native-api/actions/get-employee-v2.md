# Get Employee v2 with Morningmate

Retrieves an employee from Morningmate's v2 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/employees/[:userId]`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Get Employee v2](https://api.morningmate.com/docs/api/v2/employees)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
