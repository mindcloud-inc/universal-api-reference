# Search Participating Projects with Morningmate

Retrieves Morningmate projects for a participant.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/participants/[:participantId]`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Search Participating Projects](https://api.morningmate.com/docs/api/v1/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `participantId` | path | `string` | yes | Morningmate participant user ID |
