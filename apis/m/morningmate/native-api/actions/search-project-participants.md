# Search Project Participants with Morningmate

Retrieves participants for a Morningmate project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/[:projectId]/participants`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Search Project Participants](https://api.morningmate.com/docs/api/v1/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Morningmate numeric project ID |
