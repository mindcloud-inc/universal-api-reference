# Search SSO Participating Projects with Morningmate

Retrieves Morningmate SSO projects for a participant.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sso/projects/participants/[:participantId]`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [Search SSO Participating Projects](https://api.morningmate.com/docs/api/v1/sso)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `participantId` | path | `string` | yes |
