# List Employees v2 with Morningmate

Retrieves employees from Morningmate's v2 API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/employees`
- **Base URL:** `https://api.morningmate.com`
- **Official documentation:** [List Employees v2](https://api.morningmate.com/docs/api/v2/employees)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cursor` | query | `number` | no |
