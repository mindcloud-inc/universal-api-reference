# Morningmate: Native API Reference

A consolidated summary of Morningmate's API configuration and 24 documented operations, with links to official documentation.

- **Official docs:** https://api.morningmate.com/docs
- **API base URL:** `https://api.morningmate.com`

## Authentication

### API Key

Use a Morningmate OpenAPI API key generated by an organization administrator.

### Credentials

- **API Key:** `apiKey` · required

Send these headers with each API request:

```http
x-flow-api-key: <apiKey>
```

[Official authentication documentation](https://api.morningmate.com/docs#authorization)

## API conventions

Request bodies use JSON.

Shared headers:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

Responses from this API use JSON.
