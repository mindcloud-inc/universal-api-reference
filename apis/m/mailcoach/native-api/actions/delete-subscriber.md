# Delete Subscriber with Mailcoach

Deletes a subscriber from Mailcoach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscribers/:uuid`
- **Base URL:** `https://mindcloud.mailcoach.app/api`
- **Official documentation:** [Delete Subscriber](https://www.mailcoach.app/api-documentation/endpoints/subscribers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the subscriber to delete. |
