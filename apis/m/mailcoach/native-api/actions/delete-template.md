# Delete Template with Mailcoach

Deletes a template from Mailcoach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:uuid`
- **Base URL:** `https://mindcloud.mailcoach.app/api`
- **Official documentation:** [Delete Template](https://www.mailcoach.app/api-documentation/endpoints/templates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the template to delete. |
