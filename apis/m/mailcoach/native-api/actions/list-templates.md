# List Templates with Mailcoach

Retrieves all templates from Mailcoach.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://mindcloud.mailcoach.app/api`
- **Official documentation:** [List Templates](https://www.mailcoach.app/api-documentation/endpoints/templates/)

## Capabilities

This operation supports [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter[search]` | query | `string` | no | Search templates by name. |
