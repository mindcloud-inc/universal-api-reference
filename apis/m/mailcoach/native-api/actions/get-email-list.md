# Get Email List with Mailcoach

Retrieves an email list from Mailcoach.

## Endpoint

- **Method:** `GET`
- **Path:** `/email-lists/:uuid`
- **Base URL:** `https://mindcloud.mailcoach.app/api`
- **Official documentation:** [Get Email List](https://www.mailcoach.app/api-documentation/endpoints/email-lists/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the email list. |
