# Get Subscriber with Mailcoach

Retrieves a subscriber from Mailcoach.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:uuid`
- **Base URL:** `https://mindcloud.mailcoach.app/api`
- **Official documentation:** [Get Subscriber](https://www.mailcoach.app/api-documentation/endpoints/subscribers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the subscriber. |
