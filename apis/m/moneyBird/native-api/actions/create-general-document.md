# Create General Document with MoneyBird

Creates a new general document in MoneyBird.

## Endpoint

- **Method:** `POST`
- **Path:** `/:administrationId/documents/general_documents.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [Create General Document](https://developer.moneybird.com/api/documents-general-documents/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
