# List Webhooks with MoneyBird

Retrieves webhooks from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/webhooks.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List Webhooks](https://developer.moneybird.com/api/webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
