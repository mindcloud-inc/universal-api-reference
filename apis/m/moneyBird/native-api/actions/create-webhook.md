# Create Webhook with MoneyBird

Creates a new webhook in MoneyBird.

## Endpoint

- **Method:** `POST`
- **Path:** `/:administrationId/webhooks.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [Create Webhook](https://developer.moneybird.com/api/webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
