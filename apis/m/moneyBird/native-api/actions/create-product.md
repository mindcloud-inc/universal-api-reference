# Create Product with MoneyBird

Creates a new product in MoneyBird.

## Endpoint

- **Method:** `POST`
- **Path:** `/:administrationId/products.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [Create Product](https://developer.moneybird.com/api/products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
