# Create Subscription with MoneyBird

Creates a new subscription in MoneyBird.

## Endpoint

- **Method:** `POST`
- **Path:** `/:administrationId/subscriptions.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [Create Subscription](https://developer.moneybird.com/integration/managing-subscriptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
