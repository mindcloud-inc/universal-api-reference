# List Sales Invoices with MoneyBird

Retrieves sales invoices from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/sales_invoices.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List Sales Invoices](https://developer.moneybird.com/api/sales-invoices/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
