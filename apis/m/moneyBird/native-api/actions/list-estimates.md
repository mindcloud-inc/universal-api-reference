# List Estimates with MoneyBird

Retrieves estimates from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/estimates.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List Estimates](https://developer.moneybird.com/api/estimates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
