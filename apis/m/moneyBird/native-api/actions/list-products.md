# List Products with MoneyBird

Retrieves products from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/products.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List Products](https://developer.moneybird.com/api/products)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
