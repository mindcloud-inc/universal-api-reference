# List General Documents with MoneyBird

Retrieves general documents from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/documents/general_documents.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List General Documents](https://developer.moneybird.com/api/documents-general-documents/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
