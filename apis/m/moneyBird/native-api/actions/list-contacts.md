# List Contacts with MoneyBird

Retrieves contacts from MoneyBird.

## Endpoint

- **Method:** `GET`
- **Path:** `/:administrationId/contacts.json`
- **Base URL:** `https://moneybird.com/api/v2`
- **Official documentation:** [List Contacts](https://developer.moneybird.com/api/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `administrationId` | path | `string` | yes | Moneybird administration ID. |
