# Get Service with Makeplans

Retrieves a service from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/:serviceId`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Service](https://developer.makeplans.com/endpoints/services/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceId` | path | `number` | yes | The Makeplans service ID. |
