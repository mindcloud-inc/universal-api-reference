# Get Booking with Makeplans

Retrieves a booking from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/:bookingId`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Booking](https://developer.makeplans.com/endpoints/bookings/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookingId` | path | `number` | yes | The Makeplans booking ID. |
