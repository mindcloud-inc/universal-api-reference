# Get Person with Makeplans

Retrieves a person from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:personId`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Person](https://developer.makeplans.com/endpoints/people/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | The Makeplans person ID. |
