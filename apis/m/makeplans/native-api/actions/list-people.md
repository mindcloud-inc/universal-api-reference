# List People with Makeplans

Retrieves people from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/people`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [List People](https://developer.makeplans.com/endpoints/people/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search by email, phone number, national ID number, or name. |
