# Get Event with Makeplans

Retrieves an event from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Event](https://developer.makeplans.com/endpoints/events/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `number` | yes | The Makeplans event ID. |
