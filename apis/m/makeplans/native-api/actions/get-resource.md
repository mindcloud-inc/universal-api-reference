# Get Resource with Makeplans

Retrieves a resource from Makeplans.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:resourceId`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Resource](https://developer.makeplans.com/endpoints/resources/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `number` | yes | The Makeplans resource ID. |
