# Test SMTP with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/smtp`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Test SMTP](https://mxtoolbox.com/diagnostic.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Mail server hostname to test with SMTP. |
