# Lookup MX Records with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/mx`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup MX Records](https://mxtoolbox.com/MXLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the MX lookup against. |
