# Lookup WHOIS with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/whois`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup WHOIS](https://mxtoolbox.com/Whois.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the WHOIS lookup against. |
