# Lookup ASN Information with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/asn`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup ASN Information](https://mxtoolbox.com/asn.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | IP address to look up in ASN data. |
