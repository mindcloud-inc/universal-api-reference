# Lookup SPF Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/spf`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup SPF Record](https://mxtoolbox.com/spf.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the SPF lookup against. |
