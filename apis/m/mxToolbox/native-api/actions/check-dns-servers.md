# Check DNS Servers with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/dns`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Check DNS Servers](https://mxtoolbox.com/DNSCheck.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to check DNS servers for. |
