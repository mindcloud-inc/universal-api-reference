# Lookup DMARC Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/dmarc`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup DMARC Record](https://mxtoolbox.com/dmarc.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the DMARC lookup against. |
