# Lookup BIMI Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/bimi`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup BIMI Record](https://mxtoolbox.com/bimi.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the BIMI lookup against. |
