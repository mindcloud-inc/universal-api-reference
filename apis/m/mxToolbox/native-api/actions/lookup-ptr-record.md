# Lookup PTR Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/ptr`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup PTR Record](https://mxtoolbox.com/ReverseLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | IP address to run the PTR lookup against. |
