# Check Blocklist with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/blocklist`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Check Blocklist](https://mxtoolbox.com/blocklists.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | IP address or hostname to check on blocklists. |
