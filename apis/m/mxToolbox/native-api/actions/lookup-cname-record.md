# Lookup CNAME Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/cname`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup CNAME Record](https://mxtoolbox.com/CnameLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Hostname to resolve a CNAME record for. |
