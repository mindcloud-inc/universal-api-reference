# Lookup HTTPS with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/https`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup HTTPS](https://mxtoolbox.com/HTTPSLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Full URL to check, including https://. |
