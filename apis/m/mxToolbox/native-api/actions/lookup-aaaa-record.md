# Lookup AAAA Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/aaaa`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup AAAA Record](https://mxtoolbox.com/IPv6.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain or hostname to resolve an AAAA record for. |
