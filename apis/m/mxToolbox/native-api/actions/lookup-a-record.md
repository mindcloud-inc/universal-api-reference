# Lookup A Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/a`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup A Record](https://mxtoolbox.com/DnsLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain or hostname to resolve an A record for. |
