# Lookup SOA Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/soa`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup SOA Record](https://mxtoolbox.com/SOALookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the SOA lookup against. |
