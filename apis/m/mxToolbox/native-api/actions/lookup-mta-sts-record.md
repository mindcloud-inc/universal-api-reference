# Lookup MTA-STS Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/mta-sts`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup MTA-STS Record](https://mxtoolbox.com/mta-sts.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the MTA-STS lookup against. |
