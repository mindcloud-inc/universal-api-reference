# Lookup TCP Port with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/tcp`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup TCP Port](https://mxtoolbox.com/TCPLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Host or IP followed by a port, for example 8.8.8.8:53. |
