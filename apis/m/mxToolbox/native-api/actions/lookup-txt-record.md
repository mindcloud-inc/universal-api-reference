# Lookup TXT Record with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/txt`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup TXT Record](https://mxtoolbox.com/TXTLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Domain to run the TXT lookup against. |
