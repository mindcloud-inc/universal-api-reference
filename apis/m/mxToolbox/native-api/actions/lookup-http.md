# Lookup HTTP with Mx Toolbox

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/http`
- **Base URL:** `https://api.mxtoolbox.com/api/v1`
- **Official documentation:** [Lookup HTTP](https://mxtoolbox.com/HTTPLookup.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `argument` | query | `string` | yes | Full URL to check, including http://. |
