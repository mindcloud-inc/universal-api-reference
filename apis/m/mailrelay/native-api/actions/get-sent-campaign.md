# Get Sent Campaign with Mailrelay

Retrieves a sent campaign from Mailrelay.

## Endpoint

- **Method:** `GET`
- **Path:** `sent_campaigns/:id`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Sent Campaign](https://apidocs.mailrelay.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Mailrelay sent campaign ID. |
