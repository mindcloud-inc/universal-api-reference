# Get Group with Mailrelay

Retrieves subscriber group details from Mailrelay.

## Endpoint

- **Method:** `GET`
- **Path:** `groups/:id`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Group](https://apidocs.mailrelay.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Mailrelay group ID. |
