# Get Subscriber with Mailrelay

Retrieves subscriber details from your Mailrelay account.

## Endpoint

- **Method:** `GET`
- **Path:** `subscribers/:id`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Subscriber](https://apidocs.mailrelay.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Mailrelay subscriber ID. |
