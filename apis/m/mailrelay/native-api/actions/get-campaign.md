# Get Campaign with Mailrelay

Retrieves campaign details from your Mailrelay account.

## Endpoint

- **Method:** `GET`
- **Path:** `campaigns/:id`
- **Base URL:** `https://{accountDomain}/api/v1`
- **Official documentation:** [Get Campaign](https://apidocs.mailrelay.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Mailrelay campaign ID. |
