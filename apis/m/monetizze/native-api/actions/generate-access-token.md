# Generate Access Token with Monetizze

Retrieves an API access token from Monetizze.

## Endpoint

- **Method:** `GET`
- **Path:** `/token`
- **Base URL:** `https://api.monetizze.com.br/2.1`
- **Official documentation:** [Generate Access Token](https://api.monetizze.com.br/2.1/apidoc/#api-Security-Token)
