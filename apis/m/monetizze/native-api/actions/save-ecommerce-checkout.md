# Save Ecommerce Checkout with Monetizze

Creates an ecommerce checkout in Monetizze.

## Endpoint

- **Method:** `POST`
- **Path:** `/ecommerce/checkout`
- **Base URL:** `https://api.monetizze.com.br/2.1`
- **Official documentation:** [Save Ecommerce Checkout](https://api.monetizze.com.br/2.1/apidoc/#api-Ecommerce-PostProdutos)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payload` | body | `object` | yes | Full Monetizze ecommerce checkout JSON object as documented for this endpoint. |
