# List Allow/Block Rules with MessageBird

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId/conversation-allowblock-rules`
- **Base URL:** `https://api.bird.com`
- **Official documentation:** [List Allow/Block Rules](https://docs.bird.com/api/conversations-api/api-reference/workspace-settings/list-allow-block-rules)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | The Bird workspace ID whose allow/block rules should be listed. |
