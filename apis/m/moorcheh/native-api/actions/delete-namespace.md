# Delete Namespace with Moorcheh

Deletes a namespace and its data from Moorcheh.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/namespaces/:namespace_name`
- **Base URL:** `https://api.moorcheh.ai/v1`
- **Official documentation:** [Delete Namespace](https://docs.moorcheh.ai/api-reference/namespaces/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `namespace_name` | path | `string` | yes | Name of the namespace to permanently delete. |
