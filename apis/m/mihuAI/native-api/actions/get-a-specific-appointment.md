# Get a Specific Appointment with Mihu AI

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/appointments/:uuid`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Get a Specific Appointment](https://developers.mihu.ai/api-reference/appointments/get-a-specific-appointment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
