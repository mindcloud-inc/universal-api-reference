# Retry a Failed Task with Mihu AI

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tasks/:uuid/retry`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Retry a Failed Task](https://developers.mihu.ai/api-reference/tasks/retry-a-failed-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
