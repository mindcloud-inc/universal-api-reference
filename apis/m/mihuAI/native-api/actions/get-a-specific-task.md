# Get a Specific Task with Mihu AI

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/:uuid`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Get a Specific Task](https://developers.mihu.ai/api-reference/tasks/get-a-specific-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
