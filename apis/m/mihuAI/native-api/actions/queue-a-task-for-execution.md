# Queue a Task for Execution with Mihu AI

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tasks/:uuid/queue`
- **Base URL:** `https://{subdomain}.mindhunters.ai`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
