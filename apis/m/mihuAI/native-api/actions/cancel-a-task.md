# Cancel a Task with Mihu AI

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tasks/:uuid/cancel`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Cancel a Task](https://developers.mihu.ai/api-reference/tasks/cancel-a-task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
