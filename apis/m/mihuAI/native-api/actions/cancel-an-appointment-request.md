# Cancel an Appointment Request with Mihu AI

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/appointment-requests/:uuid/cancel`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Cancel an Appointment Request](https://developers.mihu.ai/api-reference/appointment-requests/cancel-an-appointment-request)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
