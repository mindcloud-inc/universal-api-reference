# Get a Specific Schedule with Mihu AI

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/schedules/:uuid`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Get a Specific Schedule](https://developers.mihu.ai/api-reference/schedules/get-a-specific-schedule)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
