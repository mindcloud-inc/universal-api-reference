# Create a New Contact with Mihu AI

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://{subdomain}.mindhunters.ai`
- **Official documentation:** [Create a New Contact](https://developers.mihu.ai/api-reference/contacts/create-a-new-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `country_code` | body | `string` | no |
| `email` | body | `string` | no |
| `name` | body | `string` | no |
| `phone_number` | body | `string` | no |
| `primary_language` | body | `string` | no |
| `status` | body | `string` | no |
| `surname` | body | `string` | no |
| `timezone` | body | `string` | no |
