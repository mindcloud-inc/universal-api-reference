# Get Contact Details with Mihu AI

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/:uuid`
- **Base URL:** `https://{subdomain}.mindhunters.ai`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
