# Get User with Moblico

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username`
- **Base URL:** `https://moblico.net/services/v4`
- **API:** rest
- **Official documentation:** [Get User](https://client.moblico.net/developer/trialtpl/signup.jsp)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Moblico username to retrieve. |
