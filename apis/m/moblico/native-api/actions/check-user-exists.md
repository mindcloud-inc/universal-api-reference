# Check User Exists with Moblico

## Endpoint

- **Method:** `GET`
- **Path:** `/users/exists`
- **Base URL:** `https://moblico.net/services/v4`
- **API:** rest
- **Official documentation:** [Check User Exists](https://client.moblico.net/developer/trialtpl/signup.jsp)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | query | `string` | no | Moblico username to check. |
| `phone` | query | `string` | no | Phone number to check. |
| `email` | query | `string` | no | Email address to check. |
