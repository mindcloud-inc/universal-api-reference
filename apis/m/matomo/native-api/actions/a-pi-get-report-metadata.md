# API get Report Metadata with Matomo

## Endpoint

- **Method:** `POST`
- **Path:** `/index.php`
- **Base URL:** `https://mindcloud.matomo.cloud`
- **Official documentation:** [API get Report Metadata](https://developer.matomo.org/api-reference/reporting-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idSites` | body | `string` | no | Matomo API parameter. |
| `period` | body | `string` | no | Matomo API parameter. |
| `date` | body | `string` | no | Matomo API parameter. |
| `hideMetricsDoc` | body | `boolean` | no | Matomo API parameter. |
| `showSubtableReports` | body | `boolean` | no | Matomo API parameter. |
| `idSite` | body | `number` | no | Matomo API parameter. |
