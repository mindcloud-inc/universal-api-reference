# SitesManager get Timezone Name with Matomo

## Endpoint

- **Method:** `POST`
- **Path:** `/index.php`
- **Base URL:** `https://mindcloud.matomo.cloud`
- **Official documentation:** [SitesManager get Timezone Name](https://developer.matomo.org/api-reference/reporting-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timezone` | body | `string` | yes | Matomo API parameter. |
| `countryCode` | body | `string` | no | Matomo API parameter. |
| `multipleTimezonesInCountry` | body | `string` | no | Matomo API parameter. |
