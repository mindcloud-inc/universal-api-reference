# Get Campaign with MailerLite

Retrieves a single campaign from MailerLite.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://connect.mailerlite.com/api`
- **Official documentation:** [Get Campaign](https://developers.mailerlite.com/docs/campaigns#get-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | MailerLite campaign ID. |
