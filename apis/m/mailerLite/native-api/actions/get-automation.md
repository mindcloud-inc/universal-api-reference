# Get Automation with MailerLite

Retrieves a single automation from MailerLite.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/:automationId`
- **Base URL:** `https://connect.mailerlite.com/api`
- **Official documentation:** [Get Automation](https://developers.mailerlite.com/docs/automations#get-an-automation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `automationId` | path | `string` | yes | MailerLite automation ID. |
