# Create Group with MailerLite

Creates a new group in MailerLite.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://connect.mailerlite.com/api`
- **Official documentation:** [Create Group](https://developers.mailerlite.com/docs/groups#create-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new MailerLite group. |
