# List Webhooks with MailerLite

Retrieves all webhook endpoints from MailerLite.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://connect.mailerlite.com/api`
- **Official documentation:** [List Webhooks](https://developers.mailerlite.com/docs/webhooks#list-all-webhooks)
