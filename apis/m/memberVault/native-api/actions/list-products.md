# List Products with MemberVault

Retrieves products from your MemberVault account.

## Endpoint

- **Method:** `GET`
- **Path:** `/get_courses`
- **Base URL:** `https://{accountName}.mvsite.app/api`
- **Official documentation:** [List Products](https://intercom.help/membervault/en/articles/6869595-api-endpoints-advanced)
