# Delete Sales Invoice with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v1/deleteinvoice`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [Delete Sales Invoice](https://api.merit.ee/connecting-robots/reference-manual/sales-invoices/delete-invoice/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `string` | yes | Sales invoice ID from Merit docs. |
