# Get Recurring Invoice Details with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v2/getperinvoice`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [Get Recurring Invoice Details](https://api.merit.ee/connecting-robots/reference-manual/recurring-invoices/get-recurring-invoice-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `string` | yes | Recurring invoice ID. |
