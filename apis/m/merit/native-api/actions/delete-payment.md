# Delete Payment with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v1/deletepayment`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [Delete Payment](https://api.merit.ee/connecting-robots/reference-manual/payments/delete-payment/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Id` | body | `string` | yes |
