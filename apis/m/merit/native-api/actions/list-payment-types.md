# List Payment Types with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v2/getpaymenttypes`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [List Payment Types](https://api.merit.ee/connecting-robots/reference-manual/payments/list-of-payment-types/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Type` | body | `number` | yes |
