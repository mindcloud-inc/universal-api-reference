# Create Customer Group with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v2/sendcustomergroup`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [Create Customer Group](https://api.merit.ee/connecting-robots/reference-manual/customers/create-customergroup/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Customer group name. |
| `Code` | body | `string` | no | Customer group code. |
