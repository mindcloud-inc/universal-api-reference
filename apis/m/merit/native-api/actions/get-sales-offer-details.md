# Get Sales Offer Details with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v2/getoffer`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [Get Sales Offer Details](https://api.merit.ee/connecting-robots/reference-manual/sales-offers/get-sales-offer-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `string` | yes | Sales offer ID from Merit docs. |
