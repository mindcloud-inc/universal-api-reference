# List Items with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v1/getitems`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [List Items](https://api.merit.ee/connecting-robots/reference-manual/items/items-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Code` | body | `string` | no | Broad-match item code filter from Merit docs. |
