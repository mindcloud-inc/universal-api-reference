# List Customers with Merit

## Endpoint

- **Method:** `POST`
- **Path:** `v1/getcustomers`
- **Base URL:** `https://aktiva.merit.ee/api`
- **Official documentation:** [List Customers](https://api.merit.ee/connecting-robots/reference-manual/customers/get-customer-list/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | no | Broad-match customer name filter from Merit docs. |
