# List Customer Reviews with More Good Reviews

Retrieves reviews for a customer in More Good Reviews.

## Endpoint

- **Method:** `GET`
- **Path:** `/beacon/customers/:id/reviews`
- **Base URL:** `https://api.moregoodreviews.com`
- **Official documentation:** [List Customer Reviews](https://docs.moregoodreviews.com/platform/api-reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The customer identifier. |
