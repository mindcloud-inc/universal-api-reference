# Convert Case Study To HTML with Mythic Text

## Endpoint

- **Method:** `POST`
- **Path:** `/convert`
- **Base URL:** `https://mythictext-api.vercel.app`
- **Official documentation:** [Convert Case Study To HTML](https://mythictext.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `markdown` | body | `string` | yes | Case study Markdown content to convert. |
