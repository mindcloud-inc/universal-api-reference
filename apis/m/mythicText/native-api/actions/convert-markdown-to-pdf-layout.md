# Convert Markdown To PDF Layout with Mythic Text

## Endpoint

- **Method:** `POST`
- **Path:** `/convert`
- **Base URL:** `https://mythictext-api.vercel.app`
- **Official documentation:** [Convert Markdown To PDF Layout](https://mythictext.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `markdown` | body | `string` | yes | Markdown content to convert to PDF-ready output. |
