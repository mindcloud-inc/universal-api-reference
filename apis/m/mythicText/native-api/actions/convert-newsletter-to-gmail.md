# Convert Newsletter To Gmail with Mythic Text

## Endpoint

- **Method:** `POST`
- **Path:** `/convert`
- **Base URL:** `https://mythictext-api.vercel.app`
- **Official documentation:** [Convert Newsletter To Gmail](https://mythictext.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `markdown` | body | `string` | yes | Newsletter Markdown content to convert. |
