# Convert Knowledge Base Article To WordPress with Mythic Text

## Endpoint

- **Method:** `POST`
- **Path:** `/convert`
- **Base URL:** `https://mythictext-api.vercel.app`
- **Official documentation:** [Convert Knowledge Base Article To WordPress](https://mythictext.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `markdown` | body | `string` | yes | Knowledge base article Markdown content to convert. |
