# Create Folder with MetaSurvey

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/folder`
- **Base URL:** `https://api.getmetasurvey.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Folder name. |
