# Delete Survey with MetaSurvey

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/survey/:surveyId`
- **Base URL:** `https://api.getmetasurvey.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Survey to delete. |
