# Publish Survey with MetaSurvey

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/survey/:surveyId/publish`
- **Base URL:** `https://api.getmetasurvey.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | MetaSurvey survey identifier. |
