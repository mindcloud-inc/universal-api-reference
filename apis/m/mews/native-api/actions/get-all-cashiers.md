# Get All Cashiers with Mews

Retrieves cashiers from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/cashiers/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Cashiers](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/cashiers.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
