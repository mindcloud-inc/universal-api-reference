# Get All Exchange Rates with Mews

Retrieves exchange rates from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/exchangeRates/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Exchange Rates](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/exchangerates.md)
