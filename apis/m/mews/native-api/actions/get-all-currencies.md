# Get All Currencies with Mews

Retrieves currencies from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/currencies/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Currencies](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/currencies.md)
