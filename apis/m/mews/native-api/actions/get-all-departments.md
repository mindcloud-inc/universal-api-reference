# Get All Departments with Mews

Retrieves departments from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/departments/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Departments](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/departments.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
