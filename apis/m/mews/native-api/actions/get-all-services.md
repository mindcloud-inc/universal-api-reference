# Get All Services with Mews

Retrieves services from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/services/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Services](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/services.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
