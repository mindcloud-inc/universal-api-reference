# Get All Companies with Mews

Retrieves companies from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/companies/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Companies](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/companies.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
