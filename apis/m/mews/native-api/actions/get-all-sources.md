# Get All Sources with Mews

Retrieves reservation sources from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/sources/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Sources](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/sources.md#get-all-sources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
