# Get All Age Categories with Mews

Retrieves age categories from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/ageCategories/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Age Categories](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/agecategories.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
