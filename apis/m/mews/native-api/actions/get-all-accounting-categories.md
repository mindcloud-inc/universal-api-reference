# Get All Accounting Categories with Mews

Retrieves accounting categories from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/accountingCategories/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Accounting Categories](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/accountingcategories.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
