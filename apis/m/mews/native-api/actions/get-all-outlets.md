# Get All Outlets with Mews

Retrieves outlets from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/outlets/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Outlets](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/outlets.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
