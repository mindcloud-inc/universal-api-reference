# Get All Counters with Mews

Retrieves counters from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/counters/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Counters](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/counters.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
