# Get All Languages with Mews

Retrieves languages from Mews.

## Endpoint

- **Method:** `POST`
- **Path:** `/languages/getAll`
- **Base URL:** `{platformAddress}/api/connector/v1`
- **Official documentation:** [Get All Languages](https://github.com/MewsSystems/gitbook-connector-api/blob/master/operations/languages.md)
