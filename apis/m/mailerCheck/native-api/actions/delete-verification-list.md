# Delete Verification List with MailerCheck

Deletes a verification list from MailerCheck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:id`
- **Base URL:** `https://app.mailercheck.com/api`
- **Official documentation:** [Delete Verification List](https://developers.mailercheck.com/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Verification list identifier. |
