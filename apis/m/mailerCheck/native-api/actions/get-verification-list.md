# Get Verification List with MailerCheck

Retrieves a verification list from MailerCheck.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `https://app.mailercheck.com/api`
- **Official documentation:** [Get Verification List](https://developers.mailercheck.com/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Verification list identifier. |
