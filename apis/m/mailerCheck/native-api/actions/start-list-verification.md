# Start List Verification with MailerCheck

Starts verification for a list in MailerCheck.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lists/:id/verify`
- **Base URL:** `https://app.mailercheck.com/api`
- **Official documentation:** [Start List Verification](https://developers.mailercheck.com/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Verification list identifier. |
