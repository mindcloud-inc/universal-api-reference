# Get Timer Status with MILKEE

Retrieves the timer status from MILKEE.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:companyId/times/timer`
- **Base URL:** `https://app.milkee.ch/api/v2`
- **Official documentation:** [Get Timer Status](https://apidocs.milkee.ch/api/resources/times.html#get-timer-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | path | `string` | yes | The numeric MILKEE company ID used in the request path. |
