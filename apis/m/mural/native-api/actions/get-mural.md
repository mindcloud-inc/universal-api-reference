# Get Mural with Mural

Retrieves a mural from Mural by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/murals/:muralId`
- **Base URL:** `https://app.mural.co/api/public/v1`
- **Official documentation:** [Get Mural](https://developers.mural.co/public/reference/getmuralbyid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `muralId` | path | `string` | yes |
