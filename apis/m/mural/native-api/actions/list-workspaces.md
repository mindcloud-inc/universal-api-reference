# List Workspaces with Mural

Finds workspaces in Mural for the current user.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://app.mural.co/api/public/v1`
- **Official documentation:** [List Workspaces](https://developers.mural.co/public/reference/getworkspaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
