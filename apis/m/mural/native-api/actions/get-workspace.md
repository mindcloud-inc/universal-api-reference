# Get Workspace with Mural

Retrieves a workspace from Mural by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId`
- **Base URL:** `https://app.mural.co/api/public/v1`
- **Official documentation:** [Get Workspace](https://developers.mural.co/public/reference/getworkspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | Unique identifier of a workspace. |
