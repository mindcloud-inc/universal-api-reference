# Get Room with Mural

Retrieves a room from Mural by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://app.mural.co/api/public/v1`
- **Official documentation:** [Get Room](https://developers.mural.co/public/reference/getroominfobyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `number` | yes | Unique identifier of a room. |
