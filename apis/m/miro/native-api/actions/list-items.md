# List Items with Miro

Retrieves items from a Miro board.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:board_id/items`
- **Base URL:** `https://api.miro.com/v2`
- **Official documentation:** [List Items](https://developers.miro.com/reference/get-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | path | `string` | no | Target board ID. |
