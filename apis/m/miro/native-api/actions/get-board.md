# Get Board with Miro

Retrieves a board from Miro.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:board_id`
- **Base URL:** `https://api.miro.com/v2`
- **Official documentation:** [Get Board](https://developers.miro.com/reference/get-specific-board)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | path | `string` | yes | Target board ID. |
