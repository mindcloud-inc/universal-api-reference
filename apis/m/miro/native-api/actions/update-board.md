# Update Board with Miro

Updates an existing board in Miro.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/boards/:board_id`
- **Base URL:** `https://api.miro.com/v2`
- **Official documentation:** [Update Board](https://developers.miro.com/reference/update-board)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | path | `string` | no | Target board ID. |
