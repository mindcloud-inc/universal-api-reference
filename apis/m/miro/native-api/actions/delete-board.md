# Delete Board with Miro

Deletes an existing board from Miro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/boards/:board_id`
- **Base URL:** `https://api.miro.com/v2`
- **Official documentation:** [Delete Board](https://developers.miro.com/reference/delete-board)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | path | `string` | no | Target board ID. |
