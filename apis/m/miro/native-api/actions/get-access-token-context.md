# Get Access Token Context with Miro

Retrieves access token context from Miro.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.miro.com/v1/oauth-token`
- **Base URL:** `https://api.miro.com/v2`
- **Official documentation:** [Get Access Token Context](https://developers.miro.com/reference/get-access-token-context)
