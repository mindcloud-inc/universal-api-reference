# Get Verification File with MillionVerifier

Retrieves a verification file from MillionVerifier.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.millionverifier.com/bulkapi/v2/fileinfo`
- **Base URL:** `https://api.millionverifier.com`
- **Official documentation:** [Get Verification File](https://developer.millionverifier.com/#operation/bulk-fileinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | query | `number` | yes | The ID of the uploaded file. |
