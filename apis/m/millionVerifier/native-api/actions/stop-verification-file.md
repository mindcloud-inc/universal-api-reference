# Stop Verification File with MillionVerifier

Stops a verification file in MillionVerifier.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.millionverifier.com/bulkapi/stop`
- **Base URL:** `https://api.millionverifier.com`
- **Official documentation:** [Stop Verification File](https://developer.millionverifier.com/#operation/bulk-stop)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | query | `number` | yes | The ID of the uploaded file. |
