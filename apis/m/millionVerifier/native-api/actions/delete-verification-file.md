# Delete Verification File with MillionVerifier

Deletes a verification file from MillionVerifier.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.millionverifier.com/bulkapi/v2/delete`
- **Base URL:** `https://api.millionverifier.com`
- **Official documentation:** [Delete Verification File](https://developer.millionverifier.com/#operation/bulk-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | query | `number` | yes | The ID of the uploaded file. |
