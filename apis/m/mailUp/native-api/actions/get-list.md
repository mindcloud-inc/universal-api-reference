# Get List with MailUp

Retrieves a list from MailUp by list ID.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/List/:id_List`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [Get List](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetExistingListById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id_List` | path | `number` | yes |
