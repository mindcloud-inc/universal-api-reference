# Get Authentication Info with MailUp

Retrieves authenticated user and console info from MailUp.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/Authentication/Info`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [Get Authentication Info](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetConsoleAuthenticatedUserInfo)
