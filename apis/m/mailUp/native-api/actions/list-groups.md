# List Groups with MailUp

Retrieves groups from a MailUp list.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/List/:id_List/Groups`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [List Groups](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetConsoleGroupsByList)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id_List` | path | `number` | yes |
