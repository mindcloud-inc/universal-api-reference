# List Recipient Opt-ins with MailUp

Retrieves recipient opt-in details from a MailUp list.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/List/:id_List/Recipients/EmailOptins`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [List Recipient Opt-ins](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/EmailOptins)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id_List` | path | `number` | yes |
