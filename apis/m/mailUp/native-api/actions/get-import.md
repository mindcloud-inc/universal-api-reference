# Get Import with MailUp

Retrieves an import job from MailUp.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/Imports/:id_Import`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [Get Import](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetImportDetailsByIdImport)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id_Import` | path | `number` | yes |
