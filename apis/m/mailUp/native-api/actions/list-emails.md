# List Emails with MailUp

Retrieves email messages from a MailUp list.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/List/:id_List/Emails`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [List Emails](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetMailMessagesByList)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id_List` | path | `number` | yes |
