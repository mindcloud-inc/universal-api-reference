# Get Authentication Details with MailUp

Retrieves authenticated user and console details from MailUp.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/Authentication/Details`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [Get Authentication Details](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetConsoleAuthenticatedUserDetails)
