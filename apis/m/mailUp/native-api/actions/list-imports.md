# List Imports with MailUp

Retrieves existing import jobs from MailUp.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/Imports`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [List Imports](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetImports)
