# List Lists with MailUp

Retrieves existing mailing lists from MailUp.

## Endpoint

- **Method:** `GET`
- **Path:** `Console/List`
- **Base URL:** `https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc`
- **Official documentation:** [List Lists](https://services.mailup.com/API/v1.1/Rest/ConsoleService.svc/help/operations/GetExistingLists)
