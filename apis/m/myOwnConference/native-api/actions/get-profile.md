# Get profile with MyOwnConference

Retrieves the current MyOwnConference account profile.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mywebinar.com`
- **Official documentation:** [Get profile](https://support.myownconference.com/en/article/myownconference-public-api-o6or9a/)
