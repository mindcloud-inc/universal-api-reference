# List webinars with MyOwnConference

Retrieves scheduled webinars from MyOwnConference.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.mywebinar.com`
- **Official documentation:** [List webinars](https://support.myownconference.com/en/article/myownconference-public-api-o6or9a/)
