# Create Project Job Planning Lines ODataV4 with Microsoft Dynamics 365 BC

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}/ODataV4/Company(:company)/Job_Planning_Lines`
- **Base URL:** `https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}/api/`
- **API:** REST

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `Job_No` | body | `string` | no |
| `company` | path | `list` | no |
| `Job_Task_No` | body | `string` | no |
| `Line_No` | body | `string` | no |
| `Type` | body | `string` | no |
| `No` | body | `string` | no |
| `Line_Type` | body | `string` | no |
