# Post Credit Memo with Microsoft Dynamics 365 BC

## Endpoint

- **Method:** `POST`
- **Path:** `v2.0/companies({{companyId}})/salesCreditMemos({{creditMemoId}})/Microsoft.NAV.post`
- **Base URL:** `https://api.businesscentral.dynamics.com/v2.0/{tenantId}/{environment}/api/`
- **API:** REST

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `list` | no |
| `creditMemoId` | path | `string` | no |
