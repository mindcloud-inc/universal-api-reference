# List Destination Languages with Murf Dub

Retrieves destination languages from Murf Dub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/murfdub/list-destination-languages`
- **Base URL:** `https://api.murf.ai`
- **Official documentation:** [List Destination Languages](https://murf.ai/api/docs/api-reference/dubbing/languages/list-destination-languages)
