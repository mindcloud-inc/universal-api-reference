# List Source Languages with Murf Dub

Retrieves source languages from Murf Dub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/murfdub/list-source-languages`
- **Base URL:** `https://api.murf.ai`
- **Official documentation:** [List Source Languages](https://murf.ai/api/docs/api-reference/dubbing/languages/list-source-languages)
