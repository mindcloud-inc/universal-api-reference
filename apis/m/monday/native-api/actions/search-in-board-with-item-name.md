# Search In Board With Item Name with Monday

Finds a board item in Monday by name.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.monday.com/v2/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | body | `string` | yes |
| `itemName` | body | `string` | yes |
