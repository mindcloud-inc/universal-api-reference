# Update Multiple Column Values with Monday

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.monday.com/v2/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | body | `number` | yes |
| `boardID` | body | `number` | no |
| `value` | body | `string` | no |
