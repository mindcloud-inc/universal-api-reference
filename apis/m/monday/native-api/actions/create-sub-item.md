# Create Sub Item with Monday

Creates a new subitem in Monday.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.monday.com/v2/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemName` | body | `string` | no |
| `parentItemId` | body | `string` | no |
| `columnValues` | body | `string` | no |
