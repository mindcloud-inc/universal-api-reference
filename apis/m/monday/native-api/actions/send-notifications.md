# Send Notifications with Monday

Sends a notification to a user in Monday.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.monday.com/v2/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `text` | body | `string` | no |
| `userId` | body | `string` | no |
| `targetId` | body | `string` | no |
