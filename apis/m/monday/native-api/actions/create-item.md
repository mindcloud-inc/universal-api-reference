# Create Item with Monday

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.monday.com/v2/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | body | `number` | yes |
| `itemName` | body | `string` | yes |
| `groupId` | body | `string` | no |
| `columnValues` | body | `string` | no |
