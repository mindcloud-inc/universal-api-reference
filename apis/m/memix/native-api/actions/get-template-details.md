# Get Template Details with Memix

Retrieves full template details from Memix.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:template_slug`
- **Base URL:** `https://api.memix.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_slug` | path | `string` | yes | Memix template slug. |
