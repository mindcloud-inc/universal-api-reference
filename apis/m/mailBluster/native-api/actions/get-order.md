# Get Order with MailBluster

Retrieves an order from MailBluster.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:orderId`
- **Base URL:** `https://api.mailbluster.com/api`
- **Official documentation:** [Get Order](https://app.mailbluster.com/api-doc/orders/read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | Unique order ID to retrieve. |
