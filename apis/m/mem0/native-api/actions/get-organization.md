# Get Organization with Mem0

Retrieves an organization from Mem0.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/orgs/organizations/:org_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Get Organization](https://docs.mem0.ai/api-reference/organization/get-org)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Mem0 organization ID from the organization resource path. |
