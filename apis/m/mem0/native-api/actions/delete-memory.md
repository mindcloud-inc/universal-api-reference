# Delete Memory with Mem0

Deletes an existing memory from Mem0.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/memories/:memory_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Delete Memory](https://docs.mem0.ai/api-reference/memory/delete-memory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memory_id` | path | `string` | yes | Mem0 memory ID from the memory resource path. |
