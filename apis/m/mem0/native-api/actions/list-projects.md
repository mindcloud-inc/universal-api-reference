# List Projects with Mem0

Retrieves projects from Mem0.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/orgs/organizations/:org_id/projects/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [List Projects](https://docs.mem0.ai/api-reference/project/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Mem0 organization ID from the organization resource path. |
