# Update Webhook with Mem0

Updates an existing webhook in Mem0.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/webhooks/:webhook_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Update Webhook](https://docs.mem0.ai/api-reference/webhook/update-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | Mem0 webhook ID from the webhook resource path. |
