# Update Memory with Mem0

Updates an existing memory in Mem0.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/memories/:memory_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Update Memory](https://docs.mem0.ai/api-reference/memory/update-memory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memory_id` | path | `string` | yes | Mem0 memory ID from the memory resource path. |
