# Delete Organization with Mem0

Deletes an organization from Mem0.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/orgs/organizations/:org_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Delete Organization](https://docs.mem0.ai/api-reference/organization/delete-org)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Mem0 organization ID from the organization resource path. |
