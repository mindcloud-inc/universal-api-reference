# Get Memory History with Mem0

Retrieves a memory history from Mem0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/memories/:memory_id/history/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Get Memory History](https://docs.mem0.ai/api-reference/memory/history-memory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memory_id` | path | `string` | yes | Mem0 memory ID from the memory resource path. |
