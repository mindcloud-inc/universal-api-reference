# Get Event with Mem0

Retrieves an event from Mem0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event/:event_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Get Event](https://docs.mem0.ai/api-reference/events/get-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Mem0 event ID from the event resource path. |
