# Create Project with Mem0

Creates a new project in Mem0.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/orgs/organizations/:org_id/projects/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Create Project](https://docs.mem0.ai/api-reference/project/create-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Mem0 organization ID from the organization resource path. |
| `org_id` | path | `string` | yes | Mem0 organization ID from the organization resource path. |
