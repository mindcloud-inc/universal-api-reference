# Get Memory with Mem0

Retrieves a memory from Mem0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/memories/:memory_id/`
- **Base URL:** `https://api.mem0.ai`
- **Official documentation:** [Get Memory](https://docs.mem0.ai/api-reference/memory/get-memory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memory_id` | path | `string` | yes | Mem0 memory ID from the memory resource path. |
