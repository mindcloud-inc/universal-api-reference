# List My Plans with Microsoft 365 Planner

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/planner/plans`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [List My Plans](https://learn.microsoft.com/en-us/graph/api/planneruser-list-plans?view=graph-rest-1.0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
