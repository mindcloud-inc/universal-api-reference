# Load App with MindStudio

Retrieves app details from MindStudio.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/load`
- **Base URL:** `https://api.mindstudio.ai/developer/v2`
- **Official documentation:** [Load App](https://university.mindstudio.ai/docs/developers/api-reference#load-an-app)
