# Get Chat with Microsoft Teams

Retrieves a chat from Microsoft Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/chats/:chatId`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [Get Chat](https://learn.microsoft.com/en-us/graph/api/chat-get?view=graph-rest-1.0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | Microsoft Graph chat ID. |
