# List Joined Teams with Microsoft Teams

Retrieves teams you've joined in Microsoft Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/joinedTeams`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [List Joined Teams](https://learn.microsoft.com/en-us/graph/api/user-list-joinedteams?view=graph-rest-1.0)
