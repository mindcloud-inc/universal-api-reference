# List Chats with Microsoft Teams

Retrieves chats from Microsoft Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/chats`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [List Chats](https://learn.microsoft.com/en-us/graph/api/chat-list?view=graph-rest-1.0)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
