# Authorize Application with Microsoft Exchange

## Endpoint

- **Method:** `POST`
- **Path:** `https://login.microsoftonline.com/{tenantId}/oauth2/v2.0/token`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [Authorize Application](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-client-creds-grant-flow)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
