# Get Library with Memento Database

Retrieves a library from Memento Database.

## Endpoint

- **Method:** `GET`
- **Path:** `/libraries/[:libraryId]`
- **Base URL:** `https://api.mementodatabase.com/v1`
- **Official documentation:** [Get Library](https://mementodatabase.docs.apiary.io/#reference/0/libraries/get-a-library)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `libraryId` | path | `string` | yes | The ID of the library. |
