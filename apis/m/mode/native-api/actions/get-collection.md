# Get Collection with Mode

Get details for a specific collection in a Mode workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/[:space]`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [Get Collection](https://mode.com/developer/api-reference/management/collections/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space` | path | `string` | yes | Mode collection token. |
