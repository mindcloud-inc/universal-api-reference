# Create Group with Mode

Create a group in a Mode workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [Create Group](https://mode.com/developer/api-reference/management/groups/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_group` | body | `object` | yes | Group fields to create. |
