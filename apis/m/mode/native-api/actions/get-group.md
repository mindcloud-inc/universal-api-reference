# Get Group with Mode

Get details for a specific group in a Mode workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/[:groupToken]`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [Get Group](https://mode.com/developer/api-reference/management/groups/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupToken` | path | `string` | yes | Mode group token. |
