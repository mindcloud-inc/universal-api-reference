# Create Collection with Mode

Create a collection in a Mode workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/spaces`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [Create Collection](https://mode.com/developer/api-reference/management/collections/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space` | body | `object` | yes | Collection fields to create. |
