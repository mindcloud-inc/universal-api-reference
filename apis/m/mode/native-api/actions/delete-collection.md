# Delete Collection with Mode

Delete a collection from a Mode workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/spaces/[:space]`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [Delete Collection](https://mode.com/developer/api-reference/management/collections/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space` | path | `string` | yes | Mode collection token. |
