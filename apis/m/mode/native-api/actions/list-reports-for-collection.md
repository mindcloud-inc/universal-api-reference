# List Reports For Collection with Mode

List reports in a specific Mode collection.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/[:space]/reports`
- **Base URL:** `https://app.mode.com/api/{workspace}`
- **Official documentation:** [List Reports For Collection](https://mode.com/developer/api-reference/analytics/reports/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space` | path | `string` | yes | Mode collection token. |
