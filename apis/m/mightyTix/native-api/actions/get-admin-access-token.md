# Get Admin Access Token with Mighty Tix

Retrieves an admin access token from Mighty Tix.

## Endpoint

- **Method:** `POST`
- **Path:** `admin-api/auth/login`
- **Base URL:** `https://mindcloudmttix260403.mightytix.com`
- **Official documentation:** [Get Admin Access Token](https://mightytix.com/docs/admin-api#introduction-item-0)
