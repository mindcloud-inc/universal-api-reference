# Get Session with Mighty Tix

Retrieves a session from Mighty Tix.

## Endpoint

- **Method:** `POST`
- **Path:** `admin-api/graphql`
- **Base URL:** `https://mindcloudmttix260403.mightytix.com`
- **Official documentation:** [Get Session](https://mightytix.com/docs/admin-api#query-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | Session ID from the Mighty Tix Admin GraphQL docs. |
