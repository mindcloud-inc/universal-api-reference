# Get Venue with Mighty Tix

Retrieves a venue from Mighty Tix.

## Endpoint

- **Method:** `POST`
- **Path:** `admin-api/graphql`
- **Base URL:** `https://mindcloudmttix260403.mightytix.com`
- **Official documentation:** [Get Venue](https://mightytix.com/docs/admin-api#query-venue)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | Venue ID from the Mighty Tix Admin GraphQL docs. |
