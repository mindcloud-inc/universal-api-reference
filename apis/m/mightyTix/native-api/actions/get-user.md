# Get User with Mighty Tix

Retrieves a user from Mighty Tix.

## Endpoint

- **Method:** `POST`
- **Path:** `admin-api/graphql`
- **Base URL:** `https://mindcloudmttix260403.mightytix.com`
- **Official documentation:** [Get User](https://mightytix.com/docs/admin-api#query-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | User ID from the Mighty Tix Admin GraphQL docs. |
