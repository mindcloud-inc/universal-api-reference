# Get Session Ticket Type with Mighty Tix

Retrieves a session ticket type from Mighty Tix.

## Endpoint

- **Method:** `POST`
- **Path:** `admin-api/graphql`
- **Base URL:** `https://mindcloudmttix260403.mightytix.com`
- **Official documentation:** [Get Session Ticket Type](https://mightytix.com/docs/admin-api#query-sessionTicketType)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables.id` | body | `string` | yes | Session ticket type ID from the Mighty Tix Admin GraphQL docs. |
