# List Employee Time Off Requests For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_timeoff_requests`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Time Off Requests For Employee](https://www.postman.com/myhr-api/request/27799381-a679c7bb-278a-4ad5-9d65-935532c54f9b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
