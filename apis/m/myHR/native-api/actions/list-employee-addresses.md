# List Employee Addresses with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/employees/:employee_pid/addresses`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Addresses](https://www.postman.com/myhr-api/request/27799381-75480e3e-a6fb-4091-925f-958cfb9d51a7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
