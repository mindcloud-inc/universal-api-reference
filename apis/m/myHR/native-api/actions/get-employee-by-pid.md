# Get Employee By PID with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Employee By PID](https://www.postman.com/myhr-api/request/27799381-87c948ef-ce21-4a95-995e-ab4f46b5b0c8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
