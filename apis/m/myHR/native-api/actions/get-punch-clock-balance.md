# Get Punch Clock Balance with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/punch-clock/balance`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Punch Clock Balance](https://www.postman.com/myhr-api/request/27799381-9ccf0f16-508f-45bc-9af2-54fcec9fa3a8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
