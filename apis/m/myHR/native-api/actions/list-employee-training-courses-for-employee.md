# List Employee Training Courses For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_training_courses`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Training Courses For Employee](https://www.postman.com/myhr-api/request/27799381-d34ca02f-ef1c-4d85-abaa-27c958917ffb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
