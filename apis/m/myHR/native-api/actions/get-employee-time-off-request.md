# Get Employee Time Off Request with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_timeoff_requests/:employee_timeoff_request_pid`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Employee Time Off Request](https://www.postman.com/myhr-api/request/27799381-c4df1adb-bfc7-4a51-bca2-71cc9654ff08)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_timeoff_request_pid` | path | `string` | yes | The employee time off request PID. |
