# Get Employee Expense Note with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_expense_notes/:employee_expense_note_pid`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Employee Expense Note](https://www.postman.com/myhr-api/request/27799381-0bc4b337-a36b-4afd-8171-9dec1adf4f20)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_expense_note_pid` | path | `string` | yes | The employee expense note PID. |
