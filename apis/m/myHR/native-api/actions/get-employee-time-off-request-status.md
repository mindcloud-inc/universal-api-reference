# Get Employee Time Off Request Status with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_timeoff_requests/:employee_timeoff_request_pid/status`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Employee Time Off Request Status](https://www.postman.com/myhr-api/request/27799381-372cb166-0647-4d9d-8784-8abcea642269)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_timeoff_request_pid` | path | `string` | yes | The employee time off request PID. |
