# List Employee Skills For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_skills`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Skills For Employee](https://www.postman.com/myhr-api/request/27799381-b68a9ce5-2c6f-4820-9ebe-c222b589f26a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
