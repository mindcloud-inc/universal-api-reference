# List Time Off Request Days For Request with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_timeoff_requests/:employee_timeoff_request_pid/employee_timeoff_request_days`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Time Off Request Days For Request](https://www.postman.com/myhr-api/request/27799381-01b0fef8-cf43-4cf1-adc0-f85b99b2867a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_timeoff_request_pid` | path | `string` | yes | The employee time off request PID. |
