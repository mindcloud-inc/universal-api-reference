# List Employee Assets For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_assets`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Assets For Employee](https://www.postman.com/myhr-api/request/27799381-8009cfa9-450c-46a4-9ee6-53bda237108c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
