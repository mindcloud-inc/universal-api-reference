- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Expense Note Expenses For Expense Note](https://www.postman.com/myhr-api/request/27799381-c12795b4-22f6-4aa3-90a5-e89baa129eed)

| Parameter | Location | Type | Required | Description |
