# Get Current Employee Status with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/employees/:employee_pid/statuses/current`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [Get Current Employee Status](https://www.postman.com/myhr-api/request/27799381-99ffa193-4955-4793-9783-04605012ad03)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
