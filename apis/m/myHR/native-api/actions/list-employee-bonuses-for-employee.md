# List Employee Bonuses For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_bonuses`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Bonuses For Employee](https://www.postman.com/myhr-api/request/27799381-907b1100-8632-4091-b291-92ee8c39b299)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
