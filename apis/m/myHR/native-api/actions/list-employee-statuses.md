# List Employee Statuses with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/employees/:employee_pid/statuses`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Employee Statuses](https://www.postman.com/myhr-api/request/27799381-5f80f4d8-e644-4ca0-b838-5318c7624333)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
