# List Time Off Request Days For Employee with MyHR

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employee_pid/employee_timeoff_request_days`
- **Base URL:** `https://mindcloud.myhr.lu/api/v2`
- **Official documentation:** [List Time Off Request Days For Employee](https://www.postman.com/myhr-api/request/27799381-584ec60a-e7ad-4d34-b30a-12a55f1d225a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employee_pid` | path | `string` | yes | The employee PID. |
