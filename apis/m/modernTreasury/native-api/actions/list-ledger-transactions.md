# List Ledger Transactions with Modern Treasury

Retrieves ledger transactions from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_transactions`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Transactions](https://docs.moderntreasury.com/platform/reference/list-ledger-transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
