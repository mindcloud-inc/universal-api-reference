# List Ledger Entries with Modern Treasury

Retrieves ledger entries from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_entries`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Entries](https://docs.moderntreasury.com/platform/reference/list-ledger-entries)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
