# List Virtual Accounts with Modern Treasury

Retrieves virtual accounts from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/virtual_accounts`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Virtual Accounts](https://docs.moderntreasury.com/platform/reference/list-virtual-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
