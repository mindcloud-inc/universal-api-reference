# List Payment References with Modern Treasury

Retrieves payment references from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment_references`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Payment References](https://docs.moderntreasury.com/platform/reference/list-payment-references)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
