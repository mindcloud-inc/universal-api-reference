# List Events with Modern Treasury

Retrieves events from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Events](https://docs.moderntreasury.com/platform/reference/list-events)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
