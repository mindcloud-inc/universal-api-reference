# List Payment Orders with Modern Treasury

Retrieves payment orders from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment_orders`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Payment Orders](https://docs.moderntreasury.com/platform/reference/list-payment-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
