# List Ledger Account Settlements with Modern Treasury

Retrieves ledger account settlements from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_account_settlements`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Account Settlements](https://docs.moderntreasury.com/platform/reference/list-ledger-account-settlements)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
