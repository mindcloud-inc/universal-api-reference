# List Documents with Modern Treasury

Retrieves documents from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Documents](https://docs.moderntreasury.com/platform/reference/list-documents)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
