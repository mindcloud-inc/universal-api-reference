# List Expected Payments with Modern Treasury

Retrieves expected payments from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/expected_payments`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Expected Payments](https://docs.moderntreasury.com/platform/reference/list-expected-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
