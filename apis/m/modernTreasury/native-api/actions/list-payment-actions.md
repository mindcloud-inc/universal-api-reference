# List Payment Actions with Modern Treasury

Retrieves payment actions from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment_actions`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Payment Actions](https://docs.moderntreasury.com/platform/reference/list-payment-actions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
