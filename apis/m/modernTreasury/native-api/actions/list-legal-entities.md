# List Legal Entities with Modern Treasury

Retrieves legal entities from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/legal_entities`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Legal Entities](https://docs.moderntreasury.com/platform/reference/list-legal-entities)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
