# List Transactions with Modern Treasury

Retrieves transactions from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Transactions](https://docs.moderntreasury.com/platform/reference/list-transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
