# List Account Collection Flows with Modern Treasury

Retrieves account collection flows from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/account_collection_flows`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Account Collection Flows](https://docs.moderntreasury.com/platform/reference/list-account-collection-flows)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
