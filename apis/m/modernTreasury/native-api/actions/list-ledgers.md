# List Ledgers with Modern Treasury

Retrieves ledgers from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledgers`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledgers](https://docs.moderntreasury.com/platform/reference/list-ledgers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
