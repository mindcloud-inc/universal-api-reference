# List Transaction Line Items with Modern Treasury

Retrieves transaction line items from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction_line_items`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Transaction Line Items](https://docs.moderntreasury.com/platform/reference/list-transaction-line-items)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
