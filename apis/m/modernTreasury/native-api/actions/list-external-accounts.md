# List External Accounts with Modern Treasury

Retrieves external accounts from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/external_accounts`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List External Accounts](https://docs.moderntreasury.com/platform/reference/list-external-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
