# List Ledger Account Categories with Modern Treasury

Retrieves ledger account categories from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_account_categories`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Account Categories](https://docs.moderntreasury.com/platform/reference/list-ledger-account-categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
