# List Ledger Account Balance Monitors with Modern Treasury

Retrieves ledger account balance monitors from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_account_balance_monitors`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Account Balance Monitors](https://docs.moderntreasury.com/platform/reference/list-ledger-account-balance-monitors)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
