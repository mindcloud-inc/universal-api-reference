# List Connection Legal Entities with Modern Treasury

Retrieves connection legal entities from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/connection_legal_entities`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Connection Legal Entities](https://docs.moderntreasury.com/platform/reference/list-connection-legal-entities)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
