# List Bulk Results with Modern Treasury

Retrieves bulk results from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk_results`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Bulk Results](https://docs.moderntreasury.com/platform/reference/list-bulk-results)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
