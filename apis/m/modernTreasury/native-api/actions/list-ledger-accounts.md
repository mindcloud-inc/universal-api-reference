# List Ledger Accounts with Modern Treasury

Retrieves ledger accounts from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger_accounts`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Ledger Accounts](https://docs.moderntreasury.com/platform/reference/list-ledger-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
