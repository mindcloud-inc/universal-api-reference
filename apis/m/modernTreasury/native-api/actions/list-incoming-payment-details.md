# List Incoming Payment Details with Modern Treasury

Retrieves incoming payment details from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/incoming_payment_details`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Incoming Payment Details](https://docs.moderntreasury.com/platform/reference/list-incoming-payment-details)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
