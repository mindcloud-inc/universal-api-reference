# List Bulk Requests with Modern Treasury

Retrieves bulk requests from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk_requests`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Bulk Requests](https://docs.moderntreasury.com/platform/reference/list-bulk-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
