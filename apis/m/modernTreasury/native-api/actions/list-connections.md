# List Connections with Modern Treasury

Retrieves connections from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Connections](https://docs.moderntreasury.com/platform/reference/list-connections)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
