# List Payment Flows with Modern Treasury

Retrieves payment flows from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment_flows`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Payment Flows](https://docs.moderntreasury.com/platform/reference/list-payment-flows)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
