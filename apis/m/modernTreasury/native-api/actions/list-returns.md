# List Returns with Modern Treasury

Retrieves returns from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Returns](https://docs.moderntreasury.com/platform/reference/list-returns)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
