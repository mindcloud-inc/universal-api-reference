# List Counterparties with Modern Treasury

Retrieves counterparties from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/counterparties`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Counterparties](https://docs.moderntreasury.com/platform/reference/list-counterparties)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
