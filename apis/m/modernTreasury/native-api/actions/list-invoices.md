# List Invoices with Modern Treasury

Retrieves invoices from Modern Treasury.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://app.moderntreasury.com/api`
- **Official documentation:** [List Invoices](https://docs.moderntreasury.com/platform/reference/list-invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
