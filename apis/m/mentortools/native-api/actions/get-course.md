# Get Course with Mentortools

Retrieves a course from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/:course_id`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [Get Course](https://app.mentortools.com/public_api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `course_id` | path | `number` | yes | The course ID. |
