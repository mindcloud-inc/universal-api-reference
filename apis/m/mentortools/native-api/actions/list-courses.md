# List Courses with Mentortools

Retrieves a list of courses from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [List Courses](https://app.mentortools.com/public_api/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `archived` | query | `boolean` | no | Include archived courses. |
