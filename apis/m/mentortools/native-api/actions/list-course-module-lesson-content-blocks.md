# List Course Module Lesson Content Blocks with Mentortools

Retrieves lesson content blocks from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/lessons/:lesson_id/content_blocks`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [List Course Module Lesson Content Blocks](https://app.mentortools.com/public_api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lesson_id` | path | `number` | yes | The lesson ID. |
