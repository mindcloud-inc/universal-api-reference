# Get Course Module Info with Mentortools

Retrieves detailed course module information from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/modules/:module_id/info`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [Get Course Module Info](https://app.mentortools.com/public_api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `module_id` | path | `number` | yes | The module ID. |
