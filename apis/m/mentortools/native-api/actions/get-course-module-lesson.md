# Get Course Module Lesson with Mentortools

Retrieves a course module lesson from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/lessons/:lesson_id`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [Get Course Module Lesson](https://app.mentortools.com/public_api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lesson_id` | path | `number` | yes | The lesson ID. |
