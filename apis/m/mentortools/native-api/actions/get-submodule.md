# Get Submodule with Mentortools

Retrieves a course submodule from Mentortools.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/v1/submodules/:submodule_id`
- **Base URL:** `https://app.mentortools.com/public_api`
- **Official documentation:** [Get Submodule](https://app.mentortools.com/public_api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submodule_id` | path | `number` | yes | The submodule ID. |
