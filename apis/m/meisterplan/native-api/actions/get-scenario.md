# Get Scenario with Meisterplan

Retrieves a scenario from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/scenarios/:scenarioId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Get Scenario](https://api.us.meisterplan.com/docs/api.html#operation/GetScenarioById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scenarioId` | path | `string` | yes |
