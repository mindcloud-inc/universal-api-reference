# Delete Resource with Meisterplan

Deletes an existing resource from Meisterplan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/resources/:resourceId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Delete Resource](https://api.us.meisterplan.com/docs/api.html#operation/DeleteResource)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `resourceId` | path | `string` | yes |
