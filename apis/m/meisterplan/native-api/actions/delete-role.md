# Delete Role with Meisterplan

Deletes an existing role from Meisterplan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/roles/:roleId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Delete Role](https://api.us.meisterplan.com/docs/api.html#operation/DeleteRole)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `roleId` | path | `string` | yes |
