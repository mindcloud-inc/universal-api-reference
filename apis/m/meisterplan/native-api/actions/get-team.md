# Get Team with Meisterplan

Retrieves a team from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Get Team](https://api.us.meisterplan.com/docs/api.html#operation/GetTeamById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | path | `string` | yes |
