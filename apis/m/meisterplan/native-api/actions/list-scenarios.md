# List Scenarios with Meisterplan

Retrieves a list of scenarios from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/scenarios`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [List Scenarios](https://api.us.meisterplan.com/docs/api.html#operation/GetAllScenarios)
