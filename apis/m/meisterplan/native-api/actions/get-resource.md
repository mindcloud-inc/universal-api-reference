# Get Resource with Meisterplan

Retrieves a resource from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:resourceId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Get Resource](https://api.us.meisterplan.com/docs/api.html#operation/GetResourceById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `resourceId` | path | `string` | yes |
