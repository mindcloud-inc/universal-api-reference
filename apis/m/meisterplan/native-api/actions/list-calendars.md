# List Calendars with Meisterplan

Retrieves a list of calendars from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [List Calendars](https://api.us.meisterplan.com/docs/api.html#operation/GetAllCalendars)
