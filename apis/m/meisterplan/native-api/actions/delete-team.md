# Delete Team with Meisterplan

Deletes an existing team from Meisterplan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Delete Team](https://api.us.meisterplan.com/docs/api.html#operation/DeleteTeam)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | path | `string` | yes |
