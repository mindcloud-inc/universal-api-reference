# List Portfolios with Meisterplan

Retrieves a list of portfolios from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/portfolios`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [List Portfolios](https://api.us.meisterplan.com/docs/api.html#operation/GetAllPortfolios)
