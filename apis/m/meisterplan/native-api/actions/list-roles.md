# List Roles with Meisterplan

Retrieves a list of roles from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [List Roles](https://api.us.meisterplan.com/docs/api.html#operation/GetAllRoles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter` | query | `string` | no |
