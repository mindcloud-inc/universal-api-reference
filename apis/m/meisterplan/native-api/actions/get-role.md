# Get Role with Meisterplan

Retrieves a role from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:roleId`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [Get Role](https://api.us.meisterplan.com/docs/api.html#operation/GetRoleById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `roleId` | path | `string` | yes |
