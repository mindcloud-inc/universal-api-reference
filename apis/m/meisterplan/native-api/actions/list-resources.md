# List Resources with Meisterplan

Retrieves a list of resources from Meisterplan.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://api.us.meisterplan.com/v1`
- **Official documentation:** [List Resources](https://api.us.meisterplan.com/docs/api.html#operation/GetAllResources)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter` | query | `string` | no |
