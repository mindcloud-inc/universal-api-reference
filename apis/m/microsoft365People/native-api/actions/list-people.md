# List People with Microsoft 365 People

Retrieves relevant people from Microsoft 365 People.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.0/me/people`
- **Base URL:** `https://graph.microsoft.com`
- **Official documentation:** [List People](https://learn.microsoft.com/en-us/graph/api/user-list-people?view=graph-rest-1.0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
