# Create an agent run with Middesk

Creates an agent run in Middesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/runs`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Create an agent run](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | body | `string` | yes | Type of agent run to create. |
