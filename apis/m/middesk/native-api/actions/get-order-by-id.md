# Retrieve an order by ID with Middesk

Retrieves an order from Middesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve an order by ID](https://docs.middesk.com/reference/order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the order to retrieve. |
