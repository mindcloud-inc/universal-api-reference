# Retrieve an agent run with Middesk

Retrieves an agent run from Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve an agent run](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the agent run to retrieve. |
