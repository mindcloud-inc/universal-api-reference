# Update a webhook with Middesk

Updates a webhook in your Middesk account.

## Endpoint

- **Method:** `PUT`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Update a webhook](https://docs.middesk.com/reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the webhook to update. |
