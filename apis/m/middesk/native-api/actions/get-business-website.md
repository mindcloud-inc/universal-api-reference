# Retrieve website analysis for a business with Middesk

Retrieves website analysis for a business in Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses/:business_id/website`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve website analysis for a business](https://docs.middesk.com/reference/businesses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | path | `string` | yes | ID of the business whose website analysis you want to retrieve. |
