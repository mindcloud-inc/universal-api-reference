# List liens for a business with Middesk

Retrieves liens for a business in Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses/:business_id/liens`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [List liens for a business](https://docs.middesk.com/reference/businesses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | path | `string` | yes | ID of the business whose liens you want to list. |
