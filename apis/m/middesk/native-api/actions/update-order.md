# Update an order with Middesk

Updates an order in your Middesk account.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Update an order](https://docs.middesk.com/reference/order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the order to update. |
