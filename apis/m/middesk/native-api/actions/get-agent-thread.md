# Retrieve an agent thread with Middesk

Retrieves an agent thread from Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/threads/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve an agent thread](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the agent thread to retrieve. |
