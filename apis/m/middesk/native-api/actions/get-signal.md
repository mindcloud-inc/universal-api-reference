# Retrieve a signal with Middesk

Retrieves a signal from your Middesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/signals/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve a signal](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the signal to retrieve. |
