# Retrieve a mail item with Middesk

Retrieves a mail item from Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner/mail/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve a mail item](https://docs.middesk.com/reference/agent-mail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the mail item to retrieve. |
