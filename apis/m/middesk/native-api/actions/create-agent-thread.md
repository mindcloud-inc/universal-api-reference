# Create an agent thread with Middesk

Creates an agent thread in Middesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/threads`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Create an agent thread](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | body | `string` | yes | Type of thread to create. |
