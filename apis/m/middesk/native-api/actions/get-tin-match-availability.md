# Get TIN Match Availability with Middesk

Retrieves TIN match availability from Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/tin_match/availability`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Get TIN Match Availability](https://docs.middesk.com/reference/tin-match)
