# Delete a webhook with Middesk

Deletes a webhook from your Middesk account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Delete a webhook](https://docs.middesk.com/reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the webhook to delete. |
