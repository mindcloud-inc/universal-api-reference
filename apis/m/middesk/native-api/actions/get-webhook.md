# Retrieve a webhook with Middesk

Retrieves a webhook from your Middesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve a webhook](https://docs.middesk.com/reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the webhook to retrieve. |
