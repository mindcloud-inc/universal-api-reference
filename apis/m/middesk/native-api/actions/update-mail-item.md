# Update a mail item with Middesk

Updates a mail item in Middesk.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/partner/mail/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Update a mail item](https://docs.middesk.com/reference/agent-mail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the mail item to update. |
