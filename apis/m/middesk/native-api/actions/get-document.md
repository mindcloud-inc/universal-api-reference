# Get a document with Middesk

Retrieves a document from your Middesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Get a document](https://docs.middesk.com/reference/document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the document to retrieve. |
