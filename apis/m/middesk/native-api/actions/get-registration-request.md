# Retrieve a registration request with Middesk

Retrieves a registration request from Middesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner/registration_requests/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve a registration request](https://docs.middesk.com/docs/jurisdiction-registration-flow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the registration request to retrieve. |
