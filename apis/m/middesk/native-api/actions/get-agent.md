# Retrieve an agent with Middesk

Retrieves an agent from your Middesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:id`
- **Base URL:** `https://api.middesk.com/v1`
- **Official documentation:** [Retrieve an agent](https://docs.middesk.com/reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the agent to retrieve. |
