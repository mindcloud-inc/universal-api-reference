# Retrieve Predictor with Muna

Retrieves a predictor from Muna by tag.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/predictors/{tag}`
- **Base URL:** `https://api.muna.ai`
- **Official documentation:** [Retrieve Predictor](https://docs.muna.ai/ref/predictors/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | Predictor tag. |
