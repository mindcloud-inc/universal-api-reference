# Get Blacklist with Magileads

Retrieves a blacklist profile from Magileads.

## Endpoint

- **Method:** `GET`
- **Path:** `/blacklists/:blacklist_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Get Blacklist](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blacklist_id` | path | `number` | yes | The blacklist ID. |
