# Get PRM Contact with Magileads

Retrieves a PRM contact profile from Magileads.

## Endpoint

- **Method:** `GET`
- **Path:** `/prm/contact/:contact_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Get PRM Contact](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The PRM contact ID. |
