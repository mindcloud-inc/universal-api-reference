# Create Blacklist with Magileads

Creates a new blacklist in Magileads.

## Endpoint

- **Method:** `POST`
- **Path:** `/blacklists`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Create Blacklist](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The blacklist name. |
