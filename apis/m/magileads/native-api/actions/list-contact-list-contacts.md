# List Contact List Contacts with Magileads

Retrieves contacts from a Magileads contact list.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-lists/:contact_list_id/contacts`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [List Contact List Contacts](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_list_id` | path | `number` | yes | The contact list ID. |
