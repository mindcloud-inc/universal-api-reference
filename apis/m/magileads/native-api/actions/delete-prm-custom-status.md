# Delete PRM Custom Status with Magileads

Deletes a custom PRM status from Magileads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/prm/status/custom/:status_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Delete PRM Custom Status](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status_id` | path | `number` | yes | The custom status ID. |
