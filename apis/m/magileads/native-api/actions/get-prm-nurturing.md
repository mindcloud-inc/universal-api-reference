# Get PRM Nurturing with Magileads

Retrieves a PRM nurturing from Magileads.

## Endpoint

- **Method:** `GET`
- **Path:** `/prm/nurturing/:nurturing_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Get PRM Nurturing](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nurturing_id` | path | `number` | yes | The nurturing ID. |
