# Delete Tag with Magileads

Deletes an existing tag from Magileads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Delete Tag](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `number` | yes | The tag ID. |
