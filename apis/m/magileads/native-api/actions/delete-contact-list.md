# Delete Contact List with Magileads

Deletes an existing contact list from Magileads.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact-lists/:contact_list_id`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Delete Contact List](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_list_id` | path | `number` | yes | The contact list ID. |
