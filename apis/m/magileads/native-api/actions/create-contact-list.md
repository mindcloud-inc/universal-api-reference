# Create Contact List with Magileads

Creates a new contact list in Magileads.

## Endpoint

- **Method:** `POST`
- **Path:** `/contact-lists`
- **Base URL:** `https://app.api-magileads.net`
- **Official documentation:** [Create Contact List](https://api.magileads.net)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The contact list name. |
