# Get Location with Mapulus

Retrieves a specific location from Mapulus.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/locations/:id`
- **Base URL:** `https://api.mapulus.com`
- **Official documentation:** [Get Location](https://developer.mapulus.com/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Location ID. |
