# Delete Location with Mapulus

Deletes an existing location from Mapulus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/locations/:id`
- **Base URL:** `https://api.mapulus.com`
- **Official documentation:** [Delete Location](https://developer.mapulus.com/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Location ID. |
