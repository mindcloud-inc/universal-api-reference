# Verify Email with Mailcheck

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/verify`
- **Base URL:** `https://api.mailcheck.dev`
- **Official documentation:** [Verify Email](https://api.mailcheck.dev/docs#verify)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to verify. |
