# Get Document with Mifiel

Retrieves a document from Mifiel.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/documents/:id`
- **Base URL:** `https://app.mifiel.com`
- **Official documentation:** [Get Document](https://docs.mifiel.com/en/#tag/Document/operation/GetDocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID. |
