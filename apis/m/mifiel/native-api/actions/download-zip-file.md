# Download ZIP File with Mifiel

Retrieves a signed document ZIP archive from Mifiel.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/documents/:id/zip`
- **Base URL:** `https://app.mifiel.com`
- **Official documentation:** [Download ZIP File](https://docs.mifiel.com/en/#tag/Get-signed-document/operation/GetSignedDocumentZIP)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID. |
