# Delete Document with Mifiel

Deletes a document from Mifiel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/documents/:id`
- **Base URL:** `https://app.mifiel.com`
- **Official documentation:** [Delete Document](https://docs.mifiel.com/en/#tag/Document/operation/DeleteDocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID. |
