# Download XML with Mifiel

Retrieves a signed document XML file from Mifiel.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/documents/:id/xml`
- **Base URL:** `https://app.mifiel.com`
- **Official documentation:** [Download XML](https://docs.mifiel.com/en/#tag/Get-signed-document/operation/GetSignedDocumentXML)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID. |
