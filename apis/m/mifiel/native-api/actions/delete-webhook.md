# Delete Webhook with Mifiel

Deletes a webhook endpoint from Mifiel.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/webhooks/:id`
- **Base URL:** `https://app.mifiel.com`
- **Official documentation:** [Delete Webhook](https://docs.mifiel.com/en/#tag/Webhooks/operation/DeleteWebhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
