# Get Metaphor Paragraphs with Metaphorpsum

## Endpoint

- **Method:** `GET`
- **Path:** `/paragraphs/:paragraphCount?format=json`
- **Base URL:** `https://lorem.casjay.coffee`
- **Official documentation:** [Get Metaphor Paragraphs](https://lorum.casjay.vercel.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `paragraphCount` | path | `number` | yes | Number of paragraphs to generate (1–20). Maximum length: 20. |
