# Get Metaphor Sentences with Metaphorpsum

## Endpoint

- **Method:** `GET`
- **Path:** `/sentences/:sentenceCount?format=json`
- **Base URL:** `https://lorem.casjay.coffee`
- **Official documentation:** [Get Metaphor Sentences](https://lorum.casjay.vercel.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sentenceCount` | path | `number` | yes | Number of sentences to generate (1–50). Maximum length: 50. |
