# Get Subscriber By Id Without Mailing List Id with Moosend

Retrieves a subscriber from Moosend by ID only.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/{{SubscriberID}}.json`
- **Base URL:** `https://api.moosend.com/v3`
- **Official documentation:** [Get Subscriber By Id Without Mailing List Id](https://docs.moosend.com/api-documentation/articles/KnowledgeBase/54574-Get-subscriber-by-ID-without-mailing-list-ID?lang=en_US)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SubscriberID` | path | `string` | yes | The ID of the subscriber. |
