# List Senders with Moosend

Retrieves senders from Moosend.

## Endpoint

- **Method:** `GET`
- **Path:** `/senders/find_all.json`
- **Base URL:** `https://api.moosend.com/v3`
- **Official documentation:** [List Senders](https://docs.moosend.com/api-documentation/articles/KnowledgeBase/54594-Get-all-senders?lang=en_US)
