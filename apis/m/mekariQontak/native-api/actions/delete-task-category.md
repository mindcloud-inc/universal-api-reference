# Delete Task Category with Mekari Qontak

Deletes a task category from Mekari Qontak.

## Endpoint

- **Method:** `DELETE`
- **Path:** `qontak/crm/tasks/category/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Delete Task Category](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
