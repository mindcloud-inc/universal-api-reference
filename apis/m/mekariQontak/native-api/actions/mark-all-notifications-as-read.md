# Mark All Notifications as Read with Mekari Qontak

Marks all notifications as read in Mekari Qontak.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/notifications/mark_all_as_read`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Mark All Notifications as Read](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
