# List Notifications with Mekari Qontak

Retrieves notifications from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/notifications`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Notifications](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
