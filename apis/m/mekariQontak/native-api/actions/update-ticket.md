# Update Ticket with Mekari Qontak

Updates an existing ticket in Mekari Qontak.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/tickets/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Ticket](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
