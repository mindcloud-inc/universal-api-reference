# List Approval Rules with Mekari Qontak

Retrieves approval rules from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/approvals/rules`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Approval Rules](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
