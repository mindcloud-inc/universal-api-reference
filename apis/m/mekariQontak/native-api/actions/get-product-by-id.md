# Get Product with Mekari Qontak

Retrieves a product from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/products/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Product](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
