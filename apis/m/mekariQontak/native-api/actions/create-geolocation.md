# Create Geolocation with Mekari Qontak

Creates a new geolocation in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/geolocations`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Create Geolocation](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
