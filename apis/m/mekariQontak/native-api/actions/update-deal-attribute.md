# Update Deal Attributes with Mekari Qontak

Updates deal attributes in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/deals/update_attribute`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Deal Attributes](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
