# Mark Notification as Read with Mekari Qontak

Marks a notification as read in Mekari Qontak.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/notifications/:id/mark_as_read`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Mark Notification as Read](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
