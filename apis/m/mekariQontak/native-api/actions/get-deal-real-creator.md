# Get Deal Creator with Mekari Qontak

Retrieves a deal creator from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/deals/:id/real_creator`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Deal Creator](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
