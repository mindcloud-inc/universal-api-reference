# Delete Product Association with Mekari Qontak

Deletes a product association from Mekari Qontak.

## Endpoint

- **Method:** `DELETE`
- **Path:** `qontak/crm/products_association/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Delete Product Association](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
