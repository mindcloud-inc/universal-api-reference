# Delete Ticket with Mekari Qontak

Deletes an existing ticket from Mekari Qontak.

## Endpoint

- **Method:** `DELETE`
- **Path:** `qontak/crm/tickets/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Delete Ticket](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
