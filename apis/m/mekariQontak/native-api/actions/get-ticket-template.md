# Get Ticket Fields with Mekari Qontak

Retrieves ticket fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/tickets/info`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Ticket Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
