# Get Deal Full Fields with Mekari Qontak

Retrieves full deal fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/deals/:id/full-field`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Deal Full Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
