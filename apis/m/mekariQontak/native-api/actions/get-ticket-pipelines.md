# List Ticket Pipelines with Mekari Qontak

Retrieves ticket pipelines from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/tickets/ticket_pipelines`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Ticket Pipelines](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
