# List Deal Full Fields with Mekari Qontak

Retrieves all full deal fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/deals/full-fields`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Deal Full Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
