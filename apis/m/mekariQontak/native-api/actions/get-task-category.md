# List Task Categories with Mekari Qontak

Retrieves task categories from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/tasks/category`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Task Categories](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
