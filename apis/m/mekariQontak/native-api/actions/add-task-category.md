# Create Task Category with Mekari Qontak

Creates a task category in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/tasks/category`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Create Task Category](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
