# Send Notification with Mekari Qontak

Sends a notification in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/notifications`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Send Notification](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
