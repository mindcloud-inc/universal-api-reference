# Get Company Fields with Mekari Qontak

Retrieves company fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/companies/info`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Company Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
