# Get Deal Stage History with Mekari Qontak

Retrieves deal stage history from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/deals/:id/stage_history`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Deal Stage History](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
