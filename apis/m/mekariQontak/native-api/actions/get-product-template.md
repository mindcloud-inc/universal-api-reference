# Get Product Fields with Mekari Qontak

Retrieves product fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/products/info`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Product Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
