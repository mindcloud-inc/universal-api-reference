# Get Contact with Mekari Qontak

Retrieves a contact from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/contacts/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Contact](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
