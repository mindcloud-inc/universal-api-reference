# List Product Associations with Mekari Qontak

Retrieves product associations from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/products_association`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Product Associations](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
