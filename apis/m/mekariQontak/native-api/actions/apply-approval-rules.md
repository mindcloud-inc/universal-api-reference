# Apply Approval Rules with Mekari Qontak

Applies approval rules in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/approvals/apply_rules`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Apply Approval Rules](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
