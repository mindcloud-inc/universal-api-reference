# Toggle Approval Workflow with Mekari Qontak

Toggles a parallel approval workflow in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/approvals/toggle_workflow`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Toggle Approval Workflow](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
