# Create Product Association with Mekari Qontak

Creates a product association in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/products_association`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Create Product Association](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
