# Update Product Association with Mekari Qontak

Updates a product association in Mekari Qontak.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/products_association/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Product Association](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
