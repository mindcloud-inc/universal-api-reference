# Auto Assign Deal with Mekari Qontak

Automatically assigns deals in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/deals/auto-assign`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Auto Assign Deal](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
