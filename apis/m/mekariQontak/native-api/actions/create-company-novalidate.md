# Create Company Without Validation with Mekari Qontak

Creates a company in Mekari Qontak without validation.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/companies`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Create Company Without Validation](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
