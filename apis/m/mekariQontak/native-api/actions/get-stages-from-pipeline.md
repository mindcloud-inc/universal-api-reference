# List Pipeline Stages with Mekari Qontak

Retrieves pipeline stages from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/pipelines/:id/stages`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Pipeline Stages](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
