# Get Deal by Channel Integration Room ID with Mekari Qontak

Retrieves a deal by channel integration room ID in Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/deals/channel_integration_room/:channel_integration_room_id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Deal by Channel Integration Room ID](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `channel_integration_room_id` | path | `string` | no |
