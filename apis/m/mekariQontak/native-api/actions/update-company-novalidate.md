# Update Company Without Validation with Mekari Qontak

Updates a company in Mekari Qontak without validation.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/companies/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Company Without Validation](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
