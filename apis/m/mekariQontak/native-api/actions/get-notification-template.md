# Get Notification Fields with Mekari Qontak

Retrieves notification fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/notifications/info`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Notification Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
