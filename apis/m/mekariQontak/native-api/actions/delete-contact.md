# Delete Contact with Mekari Qontak

Deletes an existing contact from Mekari Qontak.

## Endpoint

- **Method:** `DELETE`
- **Path:** `qontak/crm/contacts/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Delete Contact](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
