# List Geolocations with Mekari Qontak

Retrieves geolocations from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/geolocations`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [List Geolocations](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
