# Get Contact Fields with Mekari Qontak

Retrieves contact fields from Mekari Qontak.

## Endpoint

- **Method:** `GET`
- **Path:** `qontak/crm/contacts/info`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Get Contact Fields](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
