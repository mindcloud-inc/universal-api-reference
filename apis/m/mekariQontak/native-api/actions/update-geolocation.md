# Update Geolocation with Mekari Qontak

Updates an existing geolocation in Mekari Qontak.

## Endpoint

- **Method:** `PUT`
- **Path:** `qontak/crm/geolocations/:id`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Geolocation](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
