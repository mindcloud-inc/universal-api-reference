# Update Deal Permissions with Mekari Qontak

Updates deal permissions in Mekari Qontak.

## Endpoint

- **Method:** `POST`
- **Path:** `qontak/crm/deals/deal_permission`
- **Base URL:** `https://api.mekari.com`
- **Official documentation:** [Update Deal Permissions](https://documenter.getpostman.com/view/22728681/2sAXxV6A5V)
