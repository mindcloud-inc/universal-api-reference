# Delete Invoice with Megaplan

## Endpoint

- **Method:** `DELETE`
- **Path:** `/invoice/:id`
- **Base URL:** `https://m60888876.megaplan.ru/api/v3`
- **Official documentation:** [Delete Invoice](https://m60888876.megaplan.ru/api/v3/docs#invoiceid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter from Megaplan RAML. |
| `id` | query | `number` | yes | Идентификатор счета для удаления |
