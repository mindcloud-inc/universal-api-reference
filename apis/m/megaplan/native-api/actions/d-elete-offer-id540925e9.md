# Delete Offer with Megaplan

## Endpoint

- **Method:** `DELETE`
- **Path:** `/offer/:id`
- **Base URL:** `https://m60888876.megaplan.ru/api/v3`
- **Official documentation:** [Delete Offer](https://m60888876.megaplan.ru/api/v3/docs#offerid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter from Megaplan RAML. |
| `id` | query | `number` | yes | Id товара, который нужно удалить |
