# Generate Face with ModelsLab

Creates a generated face image in ModelsLab.

## Endpoint

- **Method:** `POST`
- **Path:** `/v6/image_editing/face_gen`
- **Base URL:** `https://modelslab.com/api`
- **Official documentation:** [Generate Face](https://docs.modelslab.com/image-editing/face-gen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt` | body | `string` | no | Prompt describing the generated face. |
