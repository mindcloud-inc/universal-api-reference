# List Trained Models with ModelsLab

Retrieves trained models from ModelsLab.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/finetune_list`
- **Base URL:** `https://modelslab.com/api`
- **Official documentation:** [List Trained Models](https://docs.modelslab.com/image-generation/model-operation/finetune-list)
