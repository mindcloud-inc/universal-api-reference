# List Public Models with ModelsLab

Retrieves public models from ModelsLab.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/dreambooth/model_list`
- **Base URL:** `https://modelslab.com/api`
- **Official documentation:** [List Public Models](https://docs.modelslab.com/image-generation/model-operation/model-list)
