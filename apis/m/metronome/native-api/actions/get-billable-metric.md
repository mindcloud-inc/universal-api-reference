# Get Billable Metric with Metronome

Retrieves a billable metric from Metronome.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/billable-metrics/:billable_metric_id`
- **Base URL:** `https://api.metronome.com`
- **Official documentation:** [Get Billable Metric](https://docs.metronome.com/api-reference/billable-metrics/get-a-billable-metric)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `billable_metric_id` | path | `string` | yes | The billable metric ID. |
