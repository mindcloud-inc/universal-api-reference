# Set Customer Billing Provider Configurations with Metronome

Updates customer billing provider configurations in Metronome.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/setCustomerBillingProviderConfigurations`
- **Base URL:** `https://api.metronome.com`
- **Official documentation:** [Set Customer Billing Provider Configurations](https://docs.metronome.com/api-reference/customers/set-billing-provider-configurations-for-a-customer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `data[]` | body | `array<object>` | yes |
