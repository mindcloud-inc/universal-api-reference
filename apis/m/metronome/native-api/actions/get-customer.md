# Get Customer with Metronome

Retrieves a customer from Metronome.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customer_id`
- **Base URL:** `https://api.metronome.com`
- **Official documentation:** [Get Customer](https://docs.metronome.com/api-reference/customers/get-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | The customer ID. |
