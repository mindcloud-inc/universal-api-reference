# Get Bot Audio with Meetstream AI

Retrieves bot audio from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/get_audio`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Get Bot Audio](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/get-bot-audio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
