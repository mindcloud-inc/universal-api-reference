# Setup Cron with Meetstream AI

Updates calendar auto-scheduling in Meetstream AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/calendar/auto-schedule/enable`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Setup Cron](https://docs.meetstream.ai/api-reference/ap-is/calendar/setup-cron)
