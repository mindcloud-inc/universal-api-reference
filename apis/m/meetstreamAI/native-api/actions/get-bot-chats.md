# Get Bot Chats with Meetstream AI

Retrieves bot chats from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/get_chats`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Get Bot Chats](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/get-bot-chats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
