# List Google Domains with Meetstream AI

Retrieves Google domains from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/google-login-domains`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [List Google Domains](https://docs.meetstream.ai/api-reference/ap-is/google-signed-in-bots/list-google-domains)
