# Remove Bot with Meetstream AI

Deletes an active bot from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/remove_bot`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Remove Bot](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/remove-bot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
