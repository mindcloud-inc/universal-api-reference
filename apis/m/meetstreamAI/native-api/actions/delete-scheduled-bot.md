# Delete Scheduled Bot with Meetstream AI

Deletes a scheduled bot from Meetstream AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendar/scheduled_bots/:bot_id`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Delete Scheduled Bot](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/delete-scheduled-bot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The scheduled bot identifier. |
