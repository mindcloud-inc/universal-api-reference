# Get Audio Streams with Meetstream AI

Retrieves bot audio streams from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/get_audio_streams`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Get Audio Streams](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/get-audio-streams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
