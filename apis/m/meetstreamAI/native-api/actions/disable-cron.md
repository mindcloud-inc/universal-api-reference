# Disable Cron with Meetstream AI

Updates calendar auto-scheduling in Meetstream AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/calendar/auto-schedule/disable`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Disable Cron](https://docs.meetstream.ai/api-reference/ap-is/calendar/disable-cron)
