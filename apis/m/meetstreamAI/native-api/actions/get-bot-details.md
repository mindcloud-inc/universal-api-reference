# Get Bot Details with Meetstream AI

Retrieves bot details from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/detail`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Get Bot Details](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/get-bot-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
