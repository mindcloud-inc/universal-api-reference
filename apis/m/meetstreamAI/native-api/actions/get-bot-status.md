# Get Bot Status with Meetstream AI

Retrieves a bot status from Meetstream AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:bot_id/status`
- **Base URL:** `https://api.meetstream.ai/api/v1`
- **Official documentation:** [Get Bot Status](https://docs.meetstream.ai/api-reference/ap-is/bot-endpoints/get-bot-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `string` | yes | The bot identifier. |
