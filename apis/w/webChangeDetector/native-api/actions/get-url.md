# Get URL with WebChange Detector

Retrieves a URL from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/urls/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Get URL](https://api.webchangedetector.com/docs#url-GETapi-v2-urls--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
