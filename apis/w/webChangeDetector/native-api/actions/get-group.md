# Get Group with WebChange Detector

Retrieves a group from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/groups/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Get Group](https://api.webchangedetector.com/docs#group-GETapi-v2-groups--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
