# Get Account Stats with WebChange Detector

Retrieves aggregated account statistics from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/account/stats`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Get Account Stats](https://api.webchangedetector.com/docs#account-GETapi-v2-account-stats)
