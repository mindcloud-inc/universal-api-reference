# Create URL with WebChange Detector

Creates a new URL in WebChange Detector.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/urls`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Create URL](https://api.webchangedetector.com/docs#url-POSTapi-v2-urls)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | yes |
