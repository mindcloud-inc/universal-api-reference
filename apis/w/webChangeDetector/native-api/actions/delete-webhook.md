# Delete Webhook with WebChange Detector

Deletes an existing webhook from WebChange Detector.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/webhooks/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Delete Webhook](https://api.webchangedetector.com/docs#webhook-DELETEapi-v2-webhooks--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
