# Delete Group with WebChange Detector

Deletes an existing group from WebChange Detector.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/groups/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Delete Group](https://api.webchangedetector.com/docs#group-DELETEapi-v2-groups--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
