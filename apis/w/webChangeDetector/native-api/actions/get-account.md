# Get Account with WebChange Detector

Retrieves account details from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/account`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Get Account](https://api.webchangedetector.com/docs#account-GETapi-v2-account)
