# List Groups with WebChange Detector

Retrieves groups from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/groups`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [List Groups](https://api.webchangedetector.com/docs#group-GETapi-v2-groups)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `monitoring` | body | `boolean` | no |
| `per_page` | body | `number` | no |
