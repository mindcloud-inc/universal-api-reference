# Delete URL with WebChange Detector

Deletes an existing URL from WebChange Detector.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/urls/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Delete URL](https://api.webchangedetector.com/docs#url-DELETEapi-v2-urls--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
