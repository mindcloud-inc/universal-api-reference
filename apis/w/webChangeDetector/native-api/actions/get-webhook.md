# Get Webhook with WebChange Detector

Retrieves a webhook from WebChange Detector.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/webhooks/:id`
- **Base URL:** `https://api.webchangedetector.com`
- **Official documentation:** [Get Webhook](https://api.webchangedetector.com/docs#webhook-GETapi-v2-webhooks--id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
