# Get Current Organization with Whattime

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/organization`
- **Base URL:** `https://api.whattime.co.kr/v1`
- **Official documentation:** [Get Current Organization](https://developer.whattime.co.kr/swagger#/Auth/authOrganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization` | query | `string` | no | Organization uri (User 모델에 organization.uri 를 참고해 주세요) |
