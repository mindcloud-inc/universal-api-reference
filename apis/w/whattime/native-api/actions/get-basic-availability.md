# Get Basic Availability with Whattime

## Endpoint

- **Method:** `GET`
- **Path:** `/availabilities/basic`
- **Base URL:** `https://api.whattime.co.kr/v1`
- **Official documentation:** [Get Basic Availability](https://developer.whattime.co.kr/swagger#/Availability/availabilitiesBasic)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | query | `string` | no | User uri (User 모델에 uri 를 확인해 주세요) |
