# Get Current Auth User with Whattime

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/user`
- **Base URL:** `https://api.whattime.co.kr/v1`
- **Official documentation:** [Get Current Auth User](https://developer.whattime.co.kr/swagger#/Auth/authUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | query | `string` | no | User uri (User 모델에 uri 를 확인해 주세요) |
