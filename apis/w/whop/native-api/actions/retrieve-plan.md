# Retrieve Plan with Whop

Retrieves plan details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/plans/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Plan](https://docs.whop.com/api-reference/plans/retrieve-plan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the plan. |
