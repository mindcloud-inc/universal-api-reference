# List Experiences with Whop

Retrieves experiences from Whop for a company.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/experiences`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [List Experiences](https://docs.whop.com/api-reference/experiences/list-experiences)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `string` | yes | The unique identifier of the company to list experiences for. |
