# Retrieve Lead with Whop

Retrieves lead details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/leads/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Lead](https://docs.whop.com/api-reference/leads/retrieve-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the lead. |
