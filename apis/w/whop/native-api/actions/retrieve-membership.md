# Retrieve Membership with Whop

Retrieves membership details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/memberships/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Membership](https://docs.whop.com/api-reference/memberships/retrieve-membership)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the membership. |
