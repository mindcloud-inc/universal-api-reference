# Retrieve Forum with Whop

Retrieves forum details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/forums/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Forum](https://docs.whop.com/api-reference/forums/retrieve-forum)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the forum. |
