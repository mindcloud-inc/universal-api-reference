# Retrieve Invoice with Whop

Retrieves invoice details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/invoices/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Invoice](https://docs.whop.com/api-reference/invoices/retrieve-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the invoice. |
