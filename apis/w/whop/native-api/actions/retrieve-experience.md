# Retrieve Experience with Whop

Retrieves experience details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/experiences/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Experience](https://docs.whop.com/api-reference/experiences/retrieve-experience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the experience. |
