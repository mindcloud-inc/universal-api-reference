# Retrieve Product with Whop

Retrieves product details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/products/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Product](https://docs.whop.com/api-reference/products/retrieve-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the product. |
