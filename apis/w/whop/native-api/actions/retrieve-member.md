# Retrieve Member with Whop

Retrieves member details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/members/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Member](https://docs.whop.com/api-reference/members/retrieve-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the member. |
