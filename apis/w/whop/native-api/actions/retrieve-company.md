# Retrieve Company with Whop

Retrieves company details from the Whop platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/companies/:id`
- **Base URL:** `https://api.whop.com`
- **Official documentation:** [Retrieve Company](https://docs.whop.com/api-reference/companies/retrieve-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the company. |
