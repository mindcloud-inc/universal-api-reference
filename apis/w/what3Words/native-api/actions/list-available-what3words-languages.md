# List Available what3words Languages with What3Words

Lists available what3words languages for 3 word addresses.

## Endpoint

- **Method:** `GET`
- **Path:** `/available-languages`
- **Base URL:** `https://api.what3words.com/v3`
- **Official documentation:** [List Available what3words Languages](https://developer.what3words.com/public-api/docs#available-languages)
