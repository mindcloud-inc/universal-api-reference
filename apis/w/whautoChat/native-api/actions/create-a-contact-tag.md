# Create a Contact Tag with WhautoChat

Creates a new contact tag in WhautoChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contactTags`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Create a Contact Tag](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contact-tag/#2-create-a-contact-tag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `canonical` | body | `string` | no |
| `createdAt` | body | `string` | no |
| `updatedAt` | body | `date` | no |
