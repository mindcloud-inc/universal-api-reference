# Remove Tags from Contact with WhautoChat

Removes tags from a contact in WhautoChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts/{contactId}/tags/remove`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Remove Tags from Contact](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contacts/#7-remove-tags-from-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact unique ID |
