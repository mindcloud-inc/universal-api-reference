# Delete Contact by ID with WhautoChat

Deletes an existing contact from WhautoChat by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/{contactId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Delete Contact by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contacts/#5-delete-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact unique ID |
