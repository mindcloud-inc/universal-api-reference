# Get Broadcast by ID with WhautoChat

Retrieves a broadcast from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/broadcasts/{broadcastId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get Broadcast by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/broadcast/#3-get-broadcast-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `broadcastId` | path | `string` | yes | Broadcast unique ID |
