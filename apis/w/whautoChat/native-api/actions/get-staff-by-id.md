# Get Staff by ID with WhautoChat

Retrieves a staff member from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/staffs/{staffId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get Staff by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/staff/#2-get-staff-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `staffId` | path | `string` | yes | Staff unique ID |
