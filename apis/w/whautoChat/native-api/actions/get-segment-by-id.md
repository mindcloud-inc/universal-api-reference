# Get Segment by ID with WhautoChat

Retrieves a segment from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/segments/{segmentId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get Segment by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/segment/#3-get-segment-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Segment unique ID |
