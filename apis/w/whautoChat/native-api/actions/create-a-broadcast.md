# Create a Broadcast with WhautoChat

Creates a new broadcast in WhautoChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/broadcasts`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Create a Broadcast](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/broadcast/#2-create-a-broadcast)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspace.id` | body | `string` | no |
| `name` | body | `string` | no |
| `type` | body | `string` | no |
