# List WhatsApp Templates with WhautoChat

Retrieves WhatsApp templates from WhautoChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/whatsapp-templates`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [List WhatsApp Templates](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/whatsapp-templates/#1-list-whatsapp-templates)
