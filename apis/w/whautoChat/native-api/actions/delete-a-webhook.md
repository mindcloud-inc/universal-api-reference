# Delete a Webhook with WhautoChat

Deletes an existing webhook from WhautoChat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/{webhookId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Delete a Webhook](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/webhooks/#4-delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook unique ID |
