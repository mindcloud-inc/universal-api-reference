# List Workspaces with WhautoChat

Retrieves workspaces from WhautoChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspaces`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [List Workspaces](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/workspace/#1-list-workspaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchText` | query | `string` | no | Free text search |
