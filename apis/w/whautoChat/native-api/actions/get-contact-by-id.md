# Get Contact by ID with WhautoChat

Retrieves a contact from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/{contactId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get Contact by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contacts/#3-get-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact unique ID |
