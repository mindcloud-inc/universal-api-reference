# List/Search Contact Tags with WhautoChat

Finds contact tags in WhautoChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contactTags`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [List/Search Contact Tags](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contact-tag/#1-listsearch-contact-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchText` | query | `string` | no | Free text search |
