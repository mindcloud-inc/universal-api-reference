# List Webhooks with WhautoChat

Retrieves webhooks from WhautoChat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [List Webhooks](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/webhooks/#1-list-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
