# Get WhatsApp Template by ID with WhautoChat

Retrieves a WhatsApp template from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/whatsapp-templates/{templateId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get WhatsApp Template by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/whatsapp-templates/#2-get-whatsapp-template-by-id)
