# Get Contact Tag by ID with WhautoChat

Retrieves a contact tag from WhautoChat by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contactTags/{contactTagId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Get Contact Tag by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contact-tag/#3-get-contact-tag-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactTagId` | path | `string` | yes | Contact tag unique ID |
