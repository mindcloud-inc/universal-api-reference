# Add Tags to Contact with WhautoChat

Adds tags to a contact in WhautoChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts/{contactId}/tags/add`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Add Tags to Contact](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/contacts/#6-add-tags-to-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact unique ID |
