# Delete Segment by ID with WhautoChat

Deletes an existing segment from WhautoChat by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/segments/{segmentId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Delete Segment by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/segment/#4-delete-segment-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Segment unique ID |
