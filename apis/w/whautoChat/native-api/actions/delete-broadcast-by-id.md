# Delete Broadcast by ID with WhautoChat

Deletes an existing broadcast from WhautoChat by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/broadcasts/{broadcastId}`
- **Base URL:** `https://api.whauto.chat`
- **Official documentation:** [Delete Broadcast by ID](https://help.whauto.chat/cloud-version/integrations/rest-api/endpoints/broadcast/#5-delete-broadcast-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `broadcastId` | path | `string` | yes | Broadcast unique ID |
