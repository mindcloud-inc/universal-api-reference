# List Projects with Worktivity

Retrieves projects from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Project/List`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Projects](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
