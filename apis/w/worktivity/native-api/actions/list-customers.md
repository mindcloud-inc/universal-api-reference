# List Customers with Worktivity

Retrieves customers from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Project/ListCustomers`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Customers](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
