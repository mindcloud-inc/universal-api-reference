# List Screenshots with Worktivity

Retrieves screenshots from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Screenshots/List`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Screenshots](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
