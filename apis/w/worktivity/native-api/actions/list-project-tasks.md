# List Project Tasks with Worktivity

Retrieves project tasks from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Project/ListTasks`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Project Tasks](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
