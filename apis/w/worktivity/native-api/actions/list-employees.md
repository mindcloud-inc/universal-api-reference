# List Employees with Worktivity

Retrieves employees from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Employee/List`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Employees](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
