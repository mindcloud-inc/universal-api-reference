# Update Project Task Assignees with Worktivity

Updates assignees for a project task in Worktivity.

## Endpoint

- **Method:** `POST`
- **Path:** `/Project/UpdateTaskAssignees`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [Update Project Task Assignees](https://useworktivity.com/for-developers)
