# List Project Task Comments with Worktivity

Retrieves project task comments from Worktivity.

## Endpoint

- **Method:** `POST`
- **Path:** `/Project/ListComments`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Project Task Comments](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
