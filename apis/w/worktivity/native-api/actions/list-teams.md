# List Teams with Worktivity

Retrieves teams from Worktivity with optional filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/Team/List`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Teams](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
