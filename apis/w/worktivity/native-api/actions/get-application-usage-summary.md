# Get Application Usage Summary with Worktivity

Retrieves application usage summaries from Worktivity.

## Endpoint

- **Method:** `POST`
- **Path:** `/Insights/AppsSummary`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [Get Application Usage Summary](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
