# List Manual Time Entries with Worktivity

Retrieves manual time entries from Worktivity.

## Endpoint

- **Method:** `POST`
- **Path:** `/TimeEntry/List`
- **Base URL:** `https://open-api.useworktivity.com`
- **Official documentation:** [List Manual Time Entries](https://useworktivity.com/for-developers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
