# Get Version Numbers with WhatIsMyBrowser

Retrieves tracked software version numbers from WhatIsMyBrowser.

## Endpoint

- **Method:** `GET`
- **Path:** `/version_numbers`
- **Base URL:** `https://api.whatismybrowser.com/api/v3`
- **Official documentation:** [Get Version Numbers](https://developers.whatismybrowser.com/api/docs/v3/integration-guide/version-numbers/requests/)
