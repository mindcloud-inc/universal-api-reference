# Get High Impact Actions with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `actions/hits`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Get High Impact Actions](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `week` | query | `string` | yes | A date inside the requested week in YYYY-MM-DD format. |
