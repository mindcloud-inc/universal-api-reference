# Search Actions with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `actions/search`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Search Actions](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `searchText` | query | `string` | yes | Search text used to find matching actions. |
