# Get Objective Lists with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `objectives/getLists`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Get Objective Lists](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `number` | yes | The workspace to read objectives from. |
