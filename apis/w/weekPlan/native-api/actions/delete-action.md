# Delete Action with Week Plan

## Endpoint

- **Method:** `DELETE`
- **Path:** `actions/:actionId`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Delete Action](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actionId` | path | `number` | yes | The action to delete. |
