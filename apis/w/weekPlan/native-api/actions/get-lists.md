# Get Lists with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `lists/getLists`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Get Lists](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `number` | yes | The workspace to read lists from. |
