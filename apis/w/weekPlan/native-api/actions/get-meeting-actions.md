# Get Meeting Actions with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `actions/meetings`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Get Meeting Actions](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `number` | yes | The workspace to read meeting actions from. |
