# Get Action with Week Plan

## Endpoint

- **Method:** `GET`
- **Path:** `actions/:actionId`
- **Base URL:** `https://api.weekplan.net/v2`
- **Official documentation:** [Get Action](https://weekplan.net/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actionId` | path | `number` | yes | Action ID to fetch. |
