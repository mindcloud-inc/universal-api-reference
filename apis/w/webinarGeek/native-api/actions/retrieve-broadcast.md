# Retrieve Broadcast with WebinarGeek

## Endpoint

- **Method:** `GET`
- **Path:** `/broadcasts/:broadcastId`
- **Base URL:** `https://app.webinargeek.com/api/v2`
- **Official documentation:** [Retrieve Broadcast](https://static.webinargeek.com/api-documentation.html#broadcasts-get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `broadcastId` | path | `number` | yes | ID of the broadcast to retrieve |
