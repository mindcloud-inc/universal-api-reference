# List Webinars with WebinarGeek

## Endpoint

- **Method:** `GET`
- **Path:** `/webinars`
- **Base URL:** `https://app.webinargeek.com/api/v2`
- **Official documentation:** [List Webinars](https://static.webinargeek.com/api-documentation.html#webinars-get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
