# List Broadcasts with WebinarGeek

- **Method:** `GET`
- **Path:** `/broadcasts`
- **Base URL:** `https://app.webinargeek.com/api/v2`

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
