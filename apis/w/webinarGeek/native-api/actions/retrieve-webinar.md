# Retrieve Webinar with WebinarGeek

## Endpoint

- **Method:** `GET`
- **Path:** `/webinars/:webinarId`
- **Base URL:** `https://app.webinargeek.com/api/v2`
- **Official documentation:** [Retrieve Webinar](https://static.webinargeek.com/api-documentation.html#webinars-get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webinarId` | path | `number` | yes | ID of the webinar to retrieve |
