# Retrieve Subscription with WebinarGeek

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:subscriptionId`
- **Base URL:** `https://app.webinargeek.com/api/v2`
- **Official documentation:** [Retrieve Subscription](https://static.webinargeek.com/api-documentation.html#subscriptions-get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `number` | yes | ID of the subscription to retrieve |
