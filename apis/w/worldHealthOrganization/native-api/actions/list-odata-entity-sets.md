# List OData Entity Sets with World Health Organization

Retrieves OData entity sets from the World Health Organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://ghoapi.azureedge.net/api/`
- **Official documentation:** [List OData Entity Sets](https://www.who.int/data/gho/info/gho-odata-api)
