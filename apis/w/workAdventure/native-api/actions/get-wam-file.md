# Get WAM file with WorkAdventure

Retrieves a WAM file from WorkAdventure map storage.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/:wamPath`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Get WAM file](https://github.com/workadventure/workadventure/tree/develop/map-storage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `wamPath` | path | `string` | yes | Path to the WAM file, including the .wam suffix. |
