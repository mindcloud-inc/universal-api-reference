# Delete map file with WorkAdventure

Deletes a file from WorkAdventure map storage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/:filePath`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Delete map file](https://github.com/workadventure/workadventure/tree/develop/map-storage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filePath` | path | `string` | yes | Map-storage file path to delete. |
