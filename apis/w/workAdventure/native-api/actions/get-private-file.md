# Get private file with WorkAdventure

Retrieves a private file from WorkAdventure map storage.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/private/files/:filePath`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Get private file](https://docs.workadventu.re/developer/map-storage-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filePath` | path | `string` | yes | Private file path to fetch. |
