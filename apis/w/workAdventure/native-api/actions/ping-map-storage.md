# Ping map storage with WorkAdventure

Checks whether WorkAdventure map storage is reachable.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/ping`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Ping map storage](https://github.com/workadventure/workadventure/tree/develop/map-storage)
