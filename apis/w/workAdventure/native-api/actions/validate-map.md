# Validate map with WorkAdventure

Validates a map URL in WorkAdventure.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/validate`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Validate map](https://docs.workadventu.re/developer/map-storage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapUrl` | query | `string` | yes | Publicly reachable map URL to validate. |
