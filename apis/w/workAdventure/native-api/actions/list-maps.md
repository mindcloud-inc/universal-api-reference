# List maps with WorkAdventure

Retrieves the cached map inventory for a WorkAdventure world.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/maps`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [List maps](https://github.com/workadventure/workadventure/tree/develop/map-storage)
