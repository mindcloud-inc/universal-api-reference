# Get file with WorkAdventure

Retrieves a file from WorkAdventure map storage.

## Endpoint

- **Method:** `GET`
- **Path:** `https://mindcloud-34294.map-storage.workadventu.re/:filePath`
- **Base URL:** `https://admin.workadventu.re`
- **Official documentation:** [Get file](https://docs.workadventu.re/developer/map-storage-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filePath` | path | `string` | yes | Stored file path to fetch. |
