# List Task POD/POC Files with Wodely

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/taskFiles/[:taskGuid]`
- **Base URL:** `https://api.wodely.com`
- **Official documentation:** [List Task POD/POC Files](https://app.wodely.com/doc/api-documentation.html#get-task-files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskGuid` | path | `string` | yes | Task identifier returned by Wodely. |
