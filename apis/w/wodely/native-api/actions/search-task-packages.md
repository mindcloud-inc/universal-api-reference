# Search Task Packages with Wodely

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/taskPackages/search`
- **Base URL:** `https://api.wodely.com`
- **Official documentation:** [Search Task Packages](https://app.wodely.com/doc/api-documentation.html#list-task-packages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskGuid` | body | `string` | yes | Task identifier returned by Wodely. |
