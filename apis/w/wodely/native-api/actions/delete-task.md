# Delete Task with Wodely

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/tasks/[:taskGuid]`
- **Base URL:** `https://api.wodely.com`
- **Official documentation:** [Delete Task](https://app.wodely.com/doc/api-documentation.html#delete-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskGuid` | path | `string` | yes | Task identifier returned by Wodely. |
