# Get Task with Wodely

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/tasks/get`
- **Base URL:** `https://api.wodely.com`
- **Official documentation:** [Get Task](https://app.wodely.com/doc/api-documentation.html#get-single-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskGuid` | body | `string` | yes | Task identifier returned by Wodely. |
