# Delete Node with Workflowy

Deletes an existing node from Workflowy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/nodes/:id`
- **Base URL:** `https://workflowy.com/api/v1`
- **Official documentation:** [Delete Node](https://beta.workflowy.com/api-reference/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier of the node to delete. |
