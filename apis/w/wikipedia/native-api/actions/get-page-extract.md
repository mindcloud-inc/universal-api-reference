# Get Page Extract with Wikipedia

Retrieves a page extract from Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=extracts&explaintext=1&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Extract](https://www.mediawiki.org/wiki/API:Extracts)
