# Parse Page with Wikipedia

Parses a Wikipedia page into HTML content.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=parse&prop=text|categories|links&format=json`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Parse Page](https://www.mediawiki.org/wiki/API:Parsing_wikitext)
