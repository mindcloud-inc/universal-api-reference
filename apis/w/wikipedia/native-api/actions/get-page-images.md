# Get Page Images with Wikipedia

Retrieves images from a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=images&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Images](https://www.mediawiki.org/wiki/API:Images)
