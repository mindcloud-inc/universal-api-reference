# List Embedded In with Wikipedia

Lists pages in Wikipedia that embed a page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=embeddedin&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Embedded In](https://www.mediawiki.org/wiki/API:Embeddedin)
