# Get Page Coordinates with Wikipedia

Retrieves coordinates from a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=coordinates&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Coordinates](https://www.mediawiki.org/wiki/API:Coordinates)
