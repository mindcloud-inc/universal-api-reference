# List Query Page Results with Wikipedia

Lists results from a Wikipedia query page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=querypage&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Query Page Results](https://www.mediawiki.org/wiki/API:Querypage)
