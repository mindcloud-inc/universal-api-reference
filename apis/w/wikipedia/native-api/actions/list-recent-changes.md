# List Recent Changes with Wikipedia

Lists recent page changes in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=recentchanges&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Recent Changes](https://www.mediawiki.org/wiki/API:RecentChanges)
