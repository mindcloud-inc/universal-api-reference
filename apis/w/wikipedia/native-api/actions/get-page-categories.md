# Get Page Categories with Wikipedia

Retrieves categories for a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=categories&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Categories](https://www.mediawiki.org/wiki/API:Categories)
