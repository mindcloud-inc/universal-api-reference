# List All Categories with Wikipedia

Lists all article categories in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=allcategories&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List All Categories](https://www.mediawiki.org/wiki/API:Allcategories)
