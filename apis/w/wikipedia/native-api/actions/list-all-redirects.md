# List All Redirects with Wikipedia

Lists all page redirects in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=allredirects&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List All Redirects](https://www.mediawiki.org/wiki/API:Allredirects)
