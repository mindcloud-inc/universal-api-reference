# Get Page Info with Wikipedia

Retrieves detailed page metadata from Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=info&inprop=url&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Info](https://www.mediawiki.org/wiki/API:Info)
