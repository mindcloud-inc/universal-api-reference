# Geo Search Pages with Wikipedia

Finds pages in Wikipedia by nearby coordinates.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=geosearch&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Geo Search Pages](https://www.mediawiki.org/wiki/API:Geosearch)
