# Get Page Revisions with Wikipedia

Retrieves revisions for a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=revisions&rvprop=ids|timestamp|user|comment|size&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Revisions](https://www.mediawiki.org/wiki/API:Revisions)
