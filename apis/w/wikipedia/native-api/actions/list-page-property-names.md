# List Page Property Names with Wikipedia

Lists page property names in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=pagepropnames&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Page Property Names](https://www.mediawiki.org/wiki/API:Pagepropnames)
