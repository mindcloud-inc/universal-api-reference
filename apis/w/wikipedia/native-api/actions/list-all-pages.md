# List All Pages with Wikipedia

Lists pages in Wikipedia by title order.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=allpages&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List All Pages](https://www.mediawiki.org/wiki/API:Allpages)
