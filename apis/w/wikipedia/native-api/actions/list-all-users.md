# List All Users with Wikipedia

Lists all user accounts in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=allusers&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List All Users](https://www.mediawiki.org/wiki/API:Allusers)
