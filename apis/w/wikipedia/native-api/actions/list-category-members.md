# List Category Members with Wikipedia

Lists pages in a Wikipedia category.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=categorymembers&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Category Members](https://www.mediawiki.org/wiki/API:Categorymembers)
