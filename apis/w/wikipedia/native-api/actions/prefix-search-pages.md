# Prefix Search Pages with Wikipedia

Finds pages in Wikipedia by title prefix.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=prefixsearch&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Prefix Search Pages](https://www.mediawiki.org/wiki/API:Prefixsearch)
