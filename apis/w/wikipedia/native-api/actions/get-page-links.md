# Get Page Links with Wikipedia

Retrieves links from a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=links&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Links](https://www.mediawiki.org/wiki/API:Links)
