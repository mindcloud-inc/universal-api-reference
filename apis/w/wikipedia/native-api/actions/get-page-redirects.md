# Get Page Redirects with Wikipedia

Retrieves redirects for a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=redirects&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Redirects](https://www.mediawiki.org/wiki/API:Redirects)
