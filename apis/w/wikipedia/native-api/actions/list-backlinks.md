# List Backlinks with Wikipedia

Lists Wikipedia pages that link to a page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=backlinks&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Backlinks](https://www.mediawiki.org/wiki/API:Backlinks)
