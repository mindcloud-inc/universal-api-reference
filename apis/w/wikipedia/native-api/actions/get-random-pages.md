# Get Random Pages with Wikipedia

Retrieves random encyclopedia pages from Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=random&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Random Pages](https://www.mediawiki.org/wiki/API:Random)
