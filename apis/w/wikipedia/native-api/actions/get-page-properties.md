# Get Page Properties with Wikipedia

Retrieves properties from a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=pageprops&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Properties](https://www.mediawiki.org/wiki/API:Pageprops)
