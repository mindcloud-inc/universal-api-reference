# List External URL Usage with Wikipedia

Lists Wikipedia pages that use an external URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=exturlusage&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List External URL Usage](https://www.mediawiki.org/wiki/API:Exturlusage)
