# Expand Templates with Wikipedia

Expands templates in Wikipedia wikitext content.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=expandtemplates&prop=wikitext&format=json`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Expand Templates](https://www.mediawiki.org/wiki/API:Expandtemplates)
