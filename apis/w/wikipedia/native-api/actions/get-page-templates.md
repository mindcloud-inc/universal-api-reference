# Get Page Templates with Wikipedia

Retrieves templates from a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=templates&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Templates](https://www.mediawiki.org/wiki/API:Templates)
