# List Pages With Property with Wikipedia

Lists Wikipedia pages with a page property.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=pageswithprop&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List Pages With Property](https://www.mediawiki.org/wiki/API:Pageswithprop)
