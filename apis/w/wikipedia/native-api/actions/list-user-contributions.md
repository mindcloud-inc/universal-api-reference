# List User Contributions with Wikipedia

Lists contributions by a Wikipedia user.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=usercontribs&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List User Contributions](https://www.mediawiki.org/wiki/API:Usercontribs)
