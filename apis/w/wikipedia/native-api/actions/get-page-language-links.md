# Get Page Language Links with Wikipedia

Retrieves language links for a Wikipedia page.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&prop=langlinks&format=json&formatversion=2&redirects=1`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [Get Page Language Links](https://www.mediawiki.org/wiki/API:Langlinks)
