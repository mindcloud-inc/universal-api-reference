# List All Images with Wikipedia

Lists available image files in Wikipedia.

## Endpoint

- **Method:** `GET`
- **Path:** `/w/api.php?action=query&list=allimages&format=json&formatversion=2`
- **Base URL:** `https://en.wikipedia.org`
- **Official documentation:** [List All Images](https://www.mediawiki.org/wiki/API:Allimages)
