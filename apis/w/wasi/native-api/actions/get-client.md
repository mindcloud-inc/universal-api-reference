# Get Client with Wasi

Retrieves a client from Wasi.

## Endpoint

- **Method:** `GET`
- **Path:** `/client/get/:id_client`
- **Base URL:** `https://api.wasi.co/v1`
- **Official documentation:** [Get Client](https://api.wasi.co/docs/en/guide/clients.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_client` | path | `number` | yes | Wasi client ID to fetch. |
