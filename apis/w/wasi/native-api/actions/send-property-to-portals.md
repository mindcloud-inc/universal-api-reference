# Send Property To Portals with Wasi

Updates a property's portal sync in Wasi.

## Endpoint

- **Method:** `GET`
- **Path:** `/portal/send-property/:id_property`
- **Base URL:** `https://api.wasi.co/v1`
- **Official documentation:** [Send Property To Portals](https://api.wasi.co/docs/en/guide/properties.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_property` | path | `number` | yes | Wasi property ID. |
