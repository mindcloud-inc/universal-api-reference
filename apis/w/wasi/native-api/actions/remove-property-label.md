# Remove Property Label with Wasi

Removes a property label from Wasi.

## Endpoint

- **Method:** `POST`
- **Path:** `/property/remove-label/:id_property`
- **Base URL:** `https://api.wasi.co/v1`
- **Official documentation:** [Remove Property Label](https://api.wasi.co/docs/en/guide/properties.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_property` | path | `number` | yes | Wasi property ID. |
