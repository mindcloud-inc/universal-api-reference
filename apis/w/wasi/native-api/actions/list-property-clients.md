# List Property Clients with Wasi

Retrieves clients linked to a property in Wasi.

## Endpoint

- **Method:** `GET`
- **Path:** `/property/clients/:id_property`
- **Base URL:** `https://api.wasi.co/v1`
- **Official documentation:** [List Property Clients](https://api.wasi.co/docs/en/guide/properties.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_property` | path | `number` | yes | Wasi property ID. |
