# Get Property Commission with Wasi

Retrieves a property's commission details from Wasi.

## Endpoint

- **Method:** `GET`
- **Path:** `/property/get-commission/:id_property`
- **Base URL:** `https://api.wasi.co/v1`
- **Official documentation:** [Get Property Commission](https://api.wasi.co/docs/en/guide/properties.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_property` | path | `number` | yes | Wasi property ID. |
