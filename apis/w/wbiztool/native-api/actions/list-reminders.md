# List Reminders with Wbiztool

Retrieves active reminders from Wbiztool.

## Endpoint

- **Method:** `POST`
- **Path:** `/reminder/list/`
- **Base URL:** `https://wbiztool.com/api/v1`
- **Official documentation:** [List Reminders](https://wbiztool.com/docs/reminder-list-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | body | `number` | no | Results page number. |
