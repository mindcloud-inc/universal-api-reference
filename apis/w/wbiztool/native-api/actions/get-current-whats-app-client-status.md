# Get Current WhatsApp Client Status with Wbiztool

Retrieves the current WhatsApp client status from Wbiztool.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp-client/status/`
- **Base URL:** `https://wbiztool.com/api/v1`
- **Official documentation:** [Get Current WhatsApp Client Status](https://wbiztool.com/docs/whatsapp-client-status-api/)
