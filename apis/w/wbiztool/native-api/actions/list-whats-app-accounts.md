# List WhatsApp Accounts with Wbiztool

Retrieves WhatsApp client accounts from Wbiztool.

## Endpoint

- **Method:** `POST`
- **Path:** `/whatsapp/accounts/`
- **Base URL:** `https://wbiztool.com/api/v1`
- **Official documentation:** [List WhatsApp Accounts](https://wbiztool.com/docs/whatsapp-accounts-api/)
