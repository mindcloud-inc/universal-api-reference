# Get Workflow with Wrangle

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflowId`
- **Base URL:** `https://slack.wrangle.io/api/v1`
- **Official documentation:** [Get Workflow](https://wrangle.apidocumentation.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | The Wrangle workflow ID. |
