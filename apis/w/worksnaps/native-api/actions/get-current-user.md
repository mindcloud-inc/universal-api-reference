# Get Current User with Worksnaps

Retrieves the current user from Worksnaps.

## Endpoint

- **Method:** `GET`
- **Path:** `/me.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get Current User](https://api.worksnaps.com/api_docs/dist/index.html#!/User_Account_API/get_me_xml)
