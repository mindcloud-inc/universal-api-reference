# Get users (i.e., all user assignments) in a project with Worksnaps

Retrieves user assignments from a Worksnaps project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/user_assignments.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get users (i.e., all user assignments) in a project](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | ID of the target project |
