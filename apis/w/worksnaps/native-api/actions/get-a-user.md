# Get a user with Worksnaps

Retrieves a user from Worksnaps.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{user_id}.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get a user](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | no | ID of the target user |
