# Get list of projects with Worksnaps

Retrieves projects for the current user from Worksnaps.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get list of projects](https://api.worksnaps.com/api_docs/worksnaps.json)
