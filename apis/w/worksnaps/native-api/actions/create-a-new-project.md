# Create a new project with Worksnaps

Creates a new project in Worksnaps.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Create a new project](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | yes | Raw XML request body for this Worksnaps endpoint. |
