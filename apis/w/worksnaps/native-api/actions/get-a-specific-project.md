# Get a specific project with Worksnaps

Retrieves a specific project from Worksnaps.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get a specific project](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | ID of the target project that needs to be fetched |
