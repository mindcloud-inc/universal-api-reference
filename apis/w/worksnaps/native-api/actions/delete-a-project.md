# Delete a project with Worksnaps

Deletes an existing project from Worksnaps.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{project_id}.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Delete a project](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | ID of the target project to be deleted |
