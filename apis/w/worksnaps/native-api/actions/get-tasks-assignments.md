# Get tasks assignments with Worksnaps

Retrieves task assignments from a Worksnaps project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/task_assignments.xml`
- **Base URL:** `https://api.worksnaps.com/api`
- **Official documentation:** [Get tasks assignments](https://api.worksnaps.com/api_docs/worksnaps.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | ID of the target project |
