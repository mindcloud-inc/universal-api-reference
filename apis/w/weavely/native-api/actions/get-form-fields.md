# Get Form Fields with Weavely

Retrieves fields from a Weavely form.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/fields`
- **Base URL:** `https://api.weavely.ai/v1`
- **Official documentation:** [Get Form Fields](https://help.weavely.ai/developers/forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The unique identifier of the form. |
