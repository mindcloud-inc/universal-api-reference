# Get Published Form Specification with Weavely

Retrieves a published form specification from Weavely.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.weavely.ai/forms/:id/client`
- **Base URL:** `https://api.weavely.ai/v1`
- **Official documentation:** [Get Published Form Specification](https://help.weavely.ai/developers/forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the published form. |
