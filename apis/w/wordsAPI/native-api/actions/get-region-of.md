# Get Region Of with WordsAPI

Retrieves words used in a region from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/regionOf`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Region Of](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
