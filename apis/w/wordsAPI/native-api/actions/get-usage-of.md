# Get Usage Of with WordsAPI

Retrieves usage domains for a word from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/usageOf`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Usage Of](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
