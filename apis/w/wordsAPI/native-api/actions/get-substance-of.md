# Get Substance Of with WordsAPI

Retrieves substances that a word is part of from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/substanceOf`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Substance Of](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
