# Get Rhymes with WordsAPI

Retrieves rhyming words for a word from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/rhymes`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Rhymes](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to find rhymes for. |
