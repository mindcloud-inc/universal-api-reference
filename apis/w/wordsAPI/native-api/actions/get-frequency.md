# Get Frequency with WordsAPI

Retrieves frequency data for a word from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/frequency`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Frequency](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve frequency details for. |
