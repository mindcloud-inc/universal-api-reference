# Get In Region with WordsAPI

Retrieves regions where a word is used from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/inRegion`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get In Region](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
