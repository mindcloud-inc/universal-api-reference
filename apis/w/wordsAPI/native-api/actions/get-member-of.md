# Get Member Of with WordsAPI

Retrieves groups that a word belongs to from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/memberOf`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Member Of](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
