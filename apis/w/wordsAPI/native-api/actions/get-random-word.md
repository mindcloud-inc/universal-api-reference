# Get Random Word with WordsAPI

Retrieves a random word from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Random Word](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `random` | query | `string` | no | Return one random word. |
