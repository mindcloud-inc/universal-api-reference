# Get Has Usages with WordsAPI

Retrieves domain examples for a word from WordsAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/words/{word}/hasUsages`
- **Base URL:** `https://wordsapiv1.p.rapidapi.com`
- **Official documentation:** [Get Has Usages](https://www.wordsapi.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | path | `string` | yes | The word to retrieve from WordsAPI. |
