# List Subfolders with Wistia

Retrieves subfolders from a Wistia folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectId/subfolders`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [List Subfolders](https://docs.wistia.com/reference/get_projects-projectid-subfolders)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
