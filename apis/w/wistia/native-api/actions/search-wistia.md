# Search Wistia with Wistia

Finds folders, media, and webinars in Wistia.

## Endpoint

- **Method:** `GET`
- **Path:** `/modern/search`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Search Wistia](https://docs.wistia.com/reference/get_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
