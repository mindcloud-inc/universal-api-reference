# Get Folder with Wistia

Retrieves a single folder from Wistia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:id`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Get Folder](https://docs.wistia.com/reference/get_projects-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
