# Upload Or Import Media with Wistia

Uploads a media file to Wistia or imports one by URL.

## Endpoint

- **Method:** `POST`
- **Path:** `https://upload.wistia.com/`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Upload Or Import Media](https://docs.wistia.com/reference/post_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | body | `string` | no |
| `projectId` | body | `string` | no |
| `name` | body | `string` | no |
