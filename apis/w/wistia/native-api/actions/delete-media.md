# Delete Media with Wistia

Deletes an existing media item from Wistia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/modern/medias/:mediaHashedId`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Delete Media](https://docs.wistia.com/reference/delete_medias-mediahashedid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaHashedId` | path | `string` | yes |
