# Delete Subfolder with Wistia

Deletes a subfolder from a Wistia folder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:projectId/subfolders/:subfolderId`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Delete Subfolder](https://docs.wistia.com/reference/delete_projects-projectid-subfolders-subfolderid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `subfolderId` | path | `string` | yes |
