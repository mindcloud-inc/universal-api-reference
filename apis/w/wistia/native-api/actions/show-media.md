# Show Media with Wistia

Retrieves a media item from Wistia.

## Endpoint

- **Method:** `GET`
- **Path:** `/modern/medias/:mediaHashedId`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Show Media](https://docs.wistia.com/reference/get_medias-mediahashedid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaHashedId` | path | `string` | yes |
