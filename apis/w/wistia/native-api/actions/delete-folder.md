# Delete Folder with Wistia

Deletes an existing folder from Wistia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:id`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Delete Folder](https://docs.wistia.com/reference/delete_projects-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
