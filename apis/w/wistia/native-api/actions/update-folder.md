# Update Folder with Wistia

Updates an existing folder in Wistia.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/projects/:id`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Update Folder](https://docs.wistia.com/reference/put_projects-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `name` | body | `string` | no |
