# Show Background Job Status with Wistia

Retrieves the status of a Wistia background job.

## Endpoint

- **Method:** `GET`
- **Path:** `/modern/background_job_status/:backgroundJobStatusId`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Show Background Job Status](https://docs.wistia.com/reference/get_background-job-status-backgroundjobstatusid)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `backgroundJobStatusId` | path | `string` | yes |
