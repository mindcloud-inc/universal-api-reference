# List Captions by Media with Wistia

Retrieves captions for a Wistia media item.

## Endpoint

- **Method:** `GET`
- **Path:** `/modern/medias/:mediaHashedId/captions`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [List Captions by Media](https://docs.wistia.com/reference/get_medias-mediahashedid-captions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaHashedId` | path | `string` | yes |
