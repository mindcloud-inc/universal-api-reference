# Show Customizations with Wistia

Retrieves customizations for a Wistia media item.

## Endpoint

- **Method:** `GET`
- **Path:** `/modern/medias/:mediaId/customizations`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Show Customizations](https://docs.wistia.com/reference/get_medias-mediaid-customizations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaId` | path | `string` | yes |
