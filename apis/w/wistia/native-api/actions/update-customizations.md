# Update Customizations with Wistia

Updates customizations for a Wistia media item.

## Endpoint

- **Method:** `PUT`
- **Path:** `/modern/medias/:mediaId/customizations`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Update Customizations](https://docs.wistia.com/reference/put_medias-mediaid-customizations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaId` | path | `string` | yes |
