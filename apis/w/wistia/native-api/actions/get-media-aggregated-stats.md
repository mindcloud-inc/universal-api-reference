# Get Media Aggregated Stats with Wistia

Retrieves aggregated stats for a Wistia media item.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/medias/:mediaHashedId.json`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Get Media Aggregated Stats](https://docs.wistia.com/reference/get_media_stats)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mediaHashedId` | path | `string` | yes |
