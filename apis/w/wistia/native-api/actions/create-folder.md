# Create Folder with Wistia

Creates a new folder in Wistia.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/projects`
- **Base URL:** `https://api.wistia.com`
- **Official documentation:** [Create Folder](https://docs.wistia.com/reference/post_projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
