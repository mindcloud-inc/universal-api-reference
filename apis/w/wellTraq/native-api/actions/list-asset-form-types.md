# List Asset Form Types with WellTraq

Retrieves asset form types from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetFormTypes`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Asset Form Types](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetFormTypes_assetId_formTypeId)
