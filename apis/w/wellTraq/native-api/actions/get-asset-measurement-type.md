# Get Asset Measurement Type with WellTraq

Retrieves an asset measurement type from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetMeasurementTypes`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Asset Measurement Type](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetMeasurementTypes_assetMeasurementTypeId)
