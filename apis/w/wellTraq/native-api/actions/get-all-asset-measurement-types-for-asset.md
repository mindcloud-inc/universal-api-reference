# Get All Asset Measurement Types For Asset with WellTraq

Retrieves asset measurement types for an asset from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetMeasurementTypes/GetAllForAsset`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get All Asset Measurement Types For Asset](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetMeasurementTypes-GetAllForAsset_assetId)
