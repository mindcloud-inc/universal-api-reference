# Get Form File with WellTraq

Retrieves a form file from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Forms/GetFile`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Form File](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Forms-GetFile_formFieldValueId_maxWidth_maxHeight_openInBrowser)
