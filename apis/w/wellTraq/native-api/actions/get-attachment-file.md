# Get Attachment File with WellTraq

Retrieves an attachment file from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments/GetFile`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Attachment File](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Attachments-GetFile_attachmentId_openInBrowser)
