# List Attachments By Last Modified Date with WellTraq

Retrieves attachments from WellTraq by last modified date.

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments/ByLastModifiedDate`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Attachments By Last Modified Date](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Attachments-ByLastModifiedDate_assetId_beginDate_endDate_includeContent)
