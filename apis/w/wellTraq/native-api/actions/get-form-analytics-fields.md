# Get Form Analytics Fields with WellTraq

Retrieves form analytics fields from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Forms/GetAnalyticsFields`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Form Analytics Fields](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Forms-GetAnalyticsFields_formTypeName_formTypeFieldNameText_beginDate_endDate)
