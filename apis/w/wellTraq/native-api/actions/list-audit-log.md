# List Audit Log with WellTraq

Retrieves audit log entries from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AuditLog`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Audit Log](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AuditLog_tables_startDateTime_endDateTime_skip_take)
