# Get Attachment Content with WellTraq

Retrieves attachment content from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments/GetContent`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Attachment Content](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Attachments-GetContent_attachmentId_startIndex_chunkSize)
