# List Forms By Effective Date with WellTraq

Retrieves forms from WellTraq by effective date.

## Endpoint

- **Method:** `GET`
- **Path:** `/Forms/ByEffectiveDate`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Forms By Effective Date](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Forms-ByEffectiveDate_assetId_formTypeId_beginDate_endDate_includeAttachmentContent)
