# Get Attachment Category with WellTraq

Retrieves an attachment category from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AttachmentCategories`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Attachment Category](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AttachmentCategories_attachmentCategoryId)
