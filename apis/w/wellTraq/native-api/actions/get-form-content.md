# Get Form Content with WellTraq

Retrieves form content from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Forms/GetContent`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Form Content](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Forms-GetContent_formFieldValueId_startIndex_chunkSize)
