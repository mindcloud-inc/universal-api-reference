# List Asset Measurement Types with WellTraq

Retrieves asset measurement types from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetMeasurementTypes`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Asset Measurement Types](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetMeasurementTypes_assetId_measurementTypeId)
