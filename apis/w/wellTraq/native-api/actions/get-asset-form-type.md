# Get Asset Form Type with WellTraq

Retrieves an asset form type from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetFormTypes`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Asset Form Type](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetFormTypes_assetFormTypeId)
