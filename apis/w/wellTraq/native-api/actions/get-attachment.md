# Get Attachment with WellTraq

Retrieves an attachment from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Attachment](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Attachments_attachmentId)
