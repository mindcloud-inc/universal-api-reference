# List Attachments By Upload Date with WellTraq

Retrieves attachments from WellTraq by upload date.

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments/ByUploadDate`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Attachments By Upload Date](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Attachments-ByUploadDate_assetId_beginDate_endDate_includeContent)
