# Get Asset Group with WellTraq

Retrieves an asset group from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetGroups`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get Asset Group](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetGroups_assetGroupId)
