# List Asset Groups By Last Modified Date with WellTraq

Retrieves asset groups from WellTraq by last modified date.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetGroups/ByLastModifiedDate`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Asset Groups By Last Modified Date](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetGroups-ByLastModifiedDate_beginDate_endDate)
