# List Assets By Last Modified Date with WellTraq

Retrieves assets from WellTraq by last modified date.

## Endpoint

- **Method:** `GET`
- **Path:** `/Assets/ByLastModifiedDate`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [List Assets By Last Modified Date](https://www.welltraq.com/api/v1/Endpoints/Api/GET-Assets-ByLastModifiedDate_assetTypeId_beginDate_endDate)
