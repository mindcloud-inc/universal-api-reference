# Get All Asset Form Types For Asset with WellTraq

Retrieves asset form types for an asset from WellTraq.

## Endpoint

- **Method:** `GET`
- **Path:** `/AssetFormTypes/GetAllForAsset`
- **Base URL:** `https://welltraq.com/api/v1`
- **Official documentation:** [Get All Asset Form Types For Asset](https://www.welltraq.com/api/v1/Endpoints/Api/GET-AssetFormTypes-GetAllForAsset_assetId)
