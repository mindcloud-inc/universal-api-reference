# List Objective Comments with Weekdone

Lists comments for an objective in Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `objective/:objectiveId/comments`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [List Objective Comments](https://weekdone.com/developer#h-objectives)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `objectiveId` | path | `number` | yes |
