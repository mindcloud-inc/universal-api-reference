# Delete Item with Weekdone

Deletes an existing item from Weekdone.

## Endpoint

- **Method:** `DELETE`
- **Path:** `item/:itemId`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Delete Item](https://weekdone.com/developer#h-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `number` | yes |
