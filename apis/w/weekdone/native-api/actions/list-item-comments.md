# List Item Comments with Weekdone

Lists comments for an item in Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `item/:itemId/comments`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [List Item Comments](https://weekdone.com/developer#h-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `number` | yes |
