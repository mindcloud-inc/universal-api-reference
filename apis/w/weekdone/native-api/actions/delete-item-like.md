# Delete Item Like with Weekdone

Deletes a like from an item in Weekdone.

## Endpoint

- **Method:** `DELETE`
- **Path:** `item/:itemId/likes`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Delete Item Like](https://weekdone.com/developer#h-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `number` | yes |
