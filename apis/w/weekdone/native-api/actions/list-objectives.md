# List Objectives with Weekdone

Lists objectives in Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `objective`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [List Objectives](https://weekdone.com/developer#h-objectives)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `department_id` | query | `number` | no |
| `period` | query | `string` | no |
| `team_id` | query | `number` | no |
| `type` | query | `string` | no |
| `user_id` | query | `number` | no |
