# Search Items with Weekdone

Finds items in Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `items`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Search Items](https://weekdone.com/developer#h-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `period` | query | `string` | no |
| `team_id` | query | `number` | no |
| `user_id` | query | `string` | no |
