# Get Tag with Weekdone

Retrieves a specific tag from Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `tag/:tagId`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Get Tag](https://weekdone.com/developer#h-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `number` | yes |
