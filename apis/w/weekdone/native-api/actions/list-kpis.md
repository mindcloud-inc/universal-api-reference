# List KPIs with Weekdone

Lists KPIs in Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `kpi`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [List KPIs](https://weekdone.com/developer#h-kpis)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `department_id` | query | `number` | no |
| `team_id` | query | `number` | no |
