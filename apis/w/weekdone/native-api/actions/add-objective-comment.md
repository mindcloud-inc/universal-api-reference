# Add Objective Comment with Weekdone

Creates a comment on an objective in Weekdone.

## Endpoint

- **Method:** `POST`
- **Path:** `objective/:objectiveId/comments`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Add Objective Comment](https://weekdone.com/developer#h-objectives)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `objectiveId` | path | `number` | yes |
