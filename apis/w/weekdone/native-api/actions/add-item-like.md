# Add Item Like with Weekdone

Creates a like for an item in Weekdone.

## Endpoint

- **Method:** `POST`
- **Path:** `item/:itemId/likes`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Add Item Like](https://weekdone.com/developer#h-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `itemId` | path | `number` | yes |
