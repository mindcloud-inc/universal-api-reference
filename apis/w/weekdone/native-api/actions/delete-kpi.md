# Delete KPI with Weekdone

Deletes an existing KPI from Weekdone.

## Endpoint

- **Method:** `DELETE`
- **Path:** `kpi/:kpiId`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Delete KPI](https://weekdone.com/developer#h-kpis)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `kpiId` | path | `number` | yes |
