# Get Report with Weekdone

Retrieves the current report from Weekdone.

## Endpoint

- **Method:** `GET`
- **Path:** `report`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Get Report](https://weekdone.com/developer#h-report)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `period` | query | `string` | no |
| `team_id` | query | `number` | no |
| `user_id` | query | `string` | no |
