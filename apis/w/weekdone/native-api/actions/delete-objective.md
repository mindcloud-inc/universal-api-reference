# Delete Objective with Weekdone

Deletes an existing objective from Weekdone.

## Endpoint

- **Method:** `DELETE`
- **Path:** `objective/:objectiveId`
- **Base URL:** `https://api.weekdone.com/1/`
- **Official documentation:** [Delete Objective](https://weekdone.com/developer#h-objectives)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `objectiveId` | path | `number` | yes |
