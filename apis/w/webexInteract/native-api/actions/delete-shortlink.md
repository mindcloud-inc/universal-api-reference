# Delete shortlink with Webex Interact

Deletes an existing shortlink from Webex Interact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assets/v1/shortlink/{linkId}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Delete shortlink](https://docs.webexinteract.com/reference/shortlinks-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Shortlink ID to delete. |
