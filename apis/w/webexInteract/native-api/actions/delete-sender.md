# Delete sender with Webex Interact

Deletes an existing sender from Webex Interact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assets/v1/senders/{id}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Delete sender](https://docs.webexinteract.com/reference/senders-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Sender ID to delete. |
