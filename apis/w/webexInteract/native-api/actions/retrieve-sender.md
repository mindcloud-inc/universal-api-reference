# Retrieve sender with Webex Interact

Retrieves a sender from Webex Interact.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/v1/senders/{id}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Retrieve sender](https://docs.webexinteract.com/reference/senders-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Sender identifier to retrieve. |
