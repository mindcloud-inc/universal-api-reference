# Delete contact list with Webex Interact

Deletes an existing contact list from Webex Interact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/v1/lists/{uid}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Delete contact list](https://docs.webexinteract.com/reference/lists-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | Contact list UID to delete. |
