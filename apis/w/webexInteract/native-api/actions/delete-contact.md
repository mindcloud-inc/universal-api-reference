# Delete contact with Webex Interact

Deletes an existing contact from Webex Interact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/v1/contacts/{contactId}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Delete contact](https://docs.webexinteract.com/reference/contacts-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact ID to delete. |
