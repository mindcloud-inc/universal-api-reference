# Retrieve shortlink with Webex Interact

Retrieves a shortlink from Webex Interact.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/v1/shortlink/{linkId}`
- **Base URL:** `https://api.webexinteract.com`
- **Official documentation:** [Retrieve shortlink](https://docs.webexinteract.com/reference/shortlinks-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Shortlink ID to retrieve. |
