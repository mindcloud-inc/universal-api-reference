# Activate Extractor with WebAutomation.io

Activates a specific extractor for use.

## Endpoint

- **Method:** `POST`
- **Path:** `/activate_extractor/{{EXTRACTOR_ID}}/`
- **Base URL:** `https://webautomation.io/api`
- **Official documentation:** [Activate Extractor](https://webautomation.io/api/redoc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `EXTRACTOR_ID` | path | `number` | yes | The extractor ID. |
