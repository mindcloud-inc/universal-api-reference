# List Starter Links with WebAutomation.io

Lists starter links configured for a specific extractor.

## Endpoint

- **Method:** `GET`
- **Path:** `/extractors/start_urls/{{EXTRACTOR_ID}}/`
- **Base URL:** `https://webautomation.io/api`
- **Official documentation:** [List Starter Links](https://webautomation.io/api/redoc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `EXTRACTOR_ID` | path | `number` | yes | The extractor ID. |
