# List Extractors by Domain with WebAutomation.io

Lists extractors that match a specific domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/extractors/{{domain}}/`
- **Base URL:** `https://webautomation.io/api`
- **Official documentation:** [List Extractors by Domain](https://webautomation.io/api/redoc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | The extractor domain. |
