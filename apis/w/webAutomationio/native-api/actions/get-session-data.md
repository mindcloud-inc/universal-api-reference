# Get Session Data with WebAutomation.io

Gets extracted results for a specific session.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/data/{{SESSIONID}}/`
- **Base URL:** `https://webautomation.io/api`
- **Official documentation:** [Get Session Data](https://webautomation.io/api/redoc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SESSIONID` | path | `number` | yes | The session ID. |
