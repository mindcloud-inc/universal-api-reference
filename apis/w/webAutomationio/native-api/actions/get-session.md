# Get Session with WebAutomation.io

Gets details for a specific extractor session.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{{SESSIONID}}/`
- **Base URL:** `https://webautomation.io/api`
- **Official documentation:** [Get Session](https://webautomation.io/api/redoc/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SESSIONID` | path | `number` | yes | The session ID. |
