# Get Team Member with Workiz

Retrieves a team member from Workiz by user ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/get/:USER_ID/`
- **Base URL:** `https://api.workiz.com/api/v1/{apiKey}`
- **Official documentation:** [Get Team Member](https://developer.workiz.com/#/Team/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `USER_ID` | path | `string` | yes | The user's ID. |
