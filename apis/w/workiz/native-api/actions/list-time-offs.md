# List Time Offs with Workiz

Finds time off entries in Workiz.

## Endpoint

- **Method:** `GET`
- **Path:** `/TimeOff/get/`
- **Base URL:** `https://api.workiz.com/api/v1/{apiKey}`
- **Official documentation:** [List Time Offs](https://developer.workiz.com/#/Time Off/getTimeOff)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `all` | query | `boolean` | no | Get all users and company time off. |
