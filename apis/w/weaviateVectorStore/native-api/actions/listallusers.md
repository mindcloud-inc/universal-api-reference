# List all users with Weaviate Vector Store

Retrieves all users from Weaviate.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/db`
- **Base URL:** `https://tl3apaxxsoiuwhpnsdv19a.c0.us-west3.gcp.weaviate.cloud`
- **Official documentation:** [List all users](https://docs.weaviate.io/weaviate/api/rest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeLastUsedTime` | query | `string` | no | Whether to include the last time the users were utilized. |
