# List Tenants with Weaviate Vector Store

Retrieves the list of tenants from Weaviate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/schema/:className/tenants`
- **Base URL:** `https://tl3apaxxsoiuwhpnsdv19a.c0.us-west3.gcp.weaviate.cloud`
- **Official documentation:** [List Tenants](https://docs.weaviate.io/weaviate/api/rest)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `className` | path | `string` | yes |
