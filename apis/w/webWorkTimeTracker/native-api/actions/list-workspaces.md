# List Workspaces with WebWork Time Tracker

Retrieves workspaces from WebWork Time Tracker.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.webwork-tracker.com/api/v2`
- **Official documentation:** [List Workspaces](https://api-docs.webwork-tracker.com/api/workspaces/getworkspaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
