# Create Contact List with WhatsBox

Creates a new contact list in WhatsBox.

## Endpoint

- **Method:** `POST`
- **Path:** `/contact-lists`
- **Base URL:** `https://api.whatsbox.io`
- **Official documentation:** [Create Contact List](https://api.whatsbox.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the contact list. |
