# Delete Webhook Subscription with WhatsBox

Deletes an existing webhook subscription from WhatsBox.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook-subscriptions/:id`
- **Base URL:** `https://api.whatsbox.io`
- **Official documentation:** [Delete Webhook Subscription](https://api.whatsbox.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook subscription ID. |
