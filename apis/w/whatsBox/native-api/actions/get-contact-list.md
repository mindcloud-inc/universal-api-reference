# Get Contact List with WhatsBox

Retrieves a contact list from WhatsBox.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-lists/:id`
- **Base URL:** `https://api.whatsbox.io`
- **Official documentation:** [Get Contact List](https://api.whatsbox.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact list ID. |
