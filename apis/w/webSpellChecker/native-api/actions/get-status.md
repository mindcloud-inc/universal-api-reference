# Get Status with WebSpellChecker

Retrieves application engine status from WebSpellChecker.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://svc.webspellchecker.net/api`
- **Official documentation:** [Get Status](https://docs.webspellchecker.com/display/WebSpellCheckerServer55x/Installing%2BWebSpellChecker%2Bon%2BLinux%2Bwith%2BApache%2BHTTP%2BServer)
