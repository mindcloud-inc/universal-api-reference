# Get Info with WebSpellChecker

Retrieves subscription details from WebSpellChecker.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://svc.webspellchecker.net/api`
- **Official documentation:** [Get Info](https://docs.webspellchecker.com/display/WebSpellCheckerCloud/Get%2Binfo%2Bcommand)
