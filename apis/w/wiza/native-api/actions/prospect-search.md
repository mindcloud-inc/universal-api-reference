# Prospect Search with Wiza

Finds the number of matching prospects in Wiza.

## Endpoint

- **Method:** `POST`
- **Path:** `/prospects/search`
- **Base URL:** `https://wiza.co/api`
- **Official documentation:** [Prospect Search](https://docs.wiza.co/api-reference/prospect/prospect-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | Prospect search filters object. |
