# Create List with Wiza

Creates a Wiza list of people to enrich.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists`
- **Base URL:** `https://wiza.co/api`
- **Official documentation:** [Create List](https://docs.wiza.co/api-reference/lists/create-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list` | body | `object` | yes | List configuration object including items and enrichment settings. |
