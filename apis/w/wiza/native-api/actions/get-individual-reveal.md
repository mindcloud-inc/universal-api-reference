# Get Individual Reveal with Wiza

Retrieves an individual reveal from Wiza.

## Endpoint

- **Method:** `GET`
- **Path:** `/individual_reveals/:id`
- **Base URL:** `https://wiza.co/api`
- **Official documentation:** [Get Individual Reveal](https://docs.wiza.co/api-reference/individual-reveals/get-individual-reveal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the reveal to fetch. |
