# Get List with Wiza

Retrieves a Wiza list by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `https://wiza.co/api`
- **Official documentation:** [Get List](https://docs.wiza.co/api-reference/lists/get-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the list to fetch. |
