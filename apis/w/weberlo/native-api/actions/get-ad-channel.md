# Get Ad Channel with Weberlo

Retrieves an ad channel from Weberlo.

## Endpoint

- **Method:** `GET`
- **Path:** `/channel-ad/:id`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [Get Ad Channel](https://developers.weberlo.com/#tag/Ad-Channels/paths/~1channel-ad~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ad channel ID. |
