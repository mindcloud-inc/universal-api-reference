# List Channels with Weberlo

Retrieves a list of channels from Weberlo.

## Endpoint

- **Method:** `GET`
- **Path:** `/channel/list`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [List Channels](https://developers.weberlo.com/#tag/Channels/paths/~1channel~1list/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
