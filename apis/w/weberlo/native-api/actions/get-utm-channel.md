# Get UTM Channel with Weberlo

Retrieves a UTM channel from Weberlo.

## Endpoint

- **Method:** `GET`
- **Path:** `/channel-utm/:id`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [Get UTM Channel](https://developers.weberlo.com/#tag/UTM-Channel/paths/~1channel-utm~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UTM channel ID. |
