# List Websites with Weberlo

Retrieves a list of websites from Weberlo.

## Endpoint

- **Method:** `GET`
- **Path:** `/page/website/list`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [List Websites](https://developers.weberlo.com/#tag/Page/paths/~1page~1website~1list/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
