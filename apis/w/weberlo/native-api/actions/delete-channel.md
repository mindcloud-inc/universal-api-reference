# Delete Channel with Weberlo

Deletes an existing channel from Weberlo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channel/:id`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [Delete Channel](https://developers.weberlo.com/#tag/Channels/paths/~1channel~1{id}/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Channel ID. |
