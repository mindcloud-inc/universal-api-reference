# Create Channel with Weberlo

Creates a new channel in Weberlo.

## Endpoint

- **Method:** `POST`
- **Path:** `/channel`
- **Base URL:** `https://connect.weberlo.com`
- **Official documentation:** [Create Channel](https://developers.weberlo.com/#tag/Channels/paths/~1channel/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Channel name. |
| `icon` | body | `string` | yes | Channel icon URL. |
