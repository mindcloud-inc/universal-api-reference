# Get Full Results with Pod State with Wolfram Alpha

Retrieves full Wolfram Alpha query results with a pod state.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results with Pod State](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
| `podstate` | query | `string` | yes |
