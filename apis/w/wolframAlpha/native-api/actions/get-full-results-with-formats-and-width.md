# Get Full Results with Formats and Width with Wolfram Alpha

Retrieves full Wolfram Alpha query results with custom formats and width.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results with Formats and Width](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `format` | query | `string` | no |
| `input` | query | `string` | yes |
| `width` | query | `number` | no |
