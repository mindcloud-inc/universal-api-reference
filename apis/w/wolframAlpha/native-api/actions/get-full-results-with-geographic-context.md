# Get Full Results with Geographic Context with Wolfram Alpha

Retrieves full Wolfram Alpha query results with geographic context.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results with Geographic Context](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
| `location` | query | `string` | yes |
