# Get Instant Calculator Default with Wolfram Alpha

Retrieves a default instant calculator from Wolfram Alpha.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Instant Calculator Default](https://products.wolframalpha.com/instant-calculators-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
