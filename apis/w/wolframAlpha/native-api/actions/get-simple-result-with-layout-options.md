# Get Simple Result with Layout Options with Wolfram Alpha

Retrieves a simple Wolfram Alpha result image with layout options.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/simple`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Simple Result with Layout Options](https://products.wolframalpha.com/simple-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `background` | query | `string` | no |
| `foreground` | query | `string` | no |
| `i` | query | `string` | yes |
| `width` | query | `number` | no |
