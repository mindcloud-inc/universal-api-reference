# Get Full Results by Scanner with Wolfram Alpha

Retrieves Wolfram Alpha results for a specific scanner.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results by Scanner](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
| `scanner` | query | `string` | yes |
