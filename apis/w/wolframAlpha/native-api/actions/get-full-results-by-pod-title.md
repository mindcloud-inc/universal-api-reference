# Get Full Results by Pod Title with Wolfram Alpha

Retrieves Wolfram Alpha results for a specific pod title.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results by Pod Title](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
| `podtitle` | query | `string` | yes |
