# Get Full Results with Unit Preferences with Wolfram Alpha

Retrieves full Wolfram Alpha query results with unit preferences.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Full Results with Unit Preferences](https://products.wolframalpha.com/api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | query | `string` | yes |
| `units` | query | `string` | yes |
