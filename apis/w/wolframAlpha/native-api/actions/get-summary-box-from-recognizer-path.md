# Get Summary Box from Recognizer Path with Wolfram Alpha

Retrieves a Wolfram Alpha summary box from a recognizer path.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.wolframalpha.com/summaryboxes/v1/query`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Summary Box from Recognizer Path](https://products.wolframalpha.com/summary-boxes-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `path` | query | `string` | yes |
