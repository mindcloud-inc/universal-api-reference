# Get Simple Result Image Custom with Wolfram Alpha

Retrieves a custom simple result image from Wolfram Alpha.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/simple`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Simple Result Image Custom](https://products.wolframalpha.com/simple-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `background` | query | `string` | no |
| `foreground` | query | `string` | no |
| `i` | query | `string` | yes |
| `width` | query | `number` | no |
