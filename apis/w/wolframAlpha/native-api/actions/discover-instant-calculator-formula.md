# Discover Instant Calculator Formula with Wolfram Alpha

Discovers an instant calculator formula in Wolfram Alpha.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.wolframalpha.com/queryrecognizer/query.jsp`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Discover Instant Calculator Formula](https://products.wolframalpha.com/instant-calculators-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `i` | query | `string` | yes |
