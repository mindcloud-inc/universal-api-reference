# Recognize Query JSON with Wolfram Alpha

Recognizes a query in Wolfram Alpha and returns JSON.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.wolframalpha.com/queryrecognizer/query.jsp`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Recognize Query JSON](https://products.wolframalpha.com/query-recognizer/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `i` | query | `string` | yes |
