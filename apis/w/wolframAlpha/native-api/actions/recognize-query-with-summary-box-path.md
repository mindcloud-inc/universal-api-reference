# Recognize Query with Summary Box Path with Wolfram Alpha

Recognizes a query and returns a Wolfram Alpha summary box path.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.wolframalpha.com/queryrecognizer/query.jsp`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Recognize Query with Summary Box Path](https://products.wolframalpha.com/query-recognizer/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `i` | query | `string` | yes |
