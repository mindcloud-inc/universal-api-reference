# Get Short Answer Metric with Wolfram Alpha

Retrieves a short metric answer from Wolfram Alpha.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/result`
- **Base URL:** `https://api.wolframalpha.com`
- **Official documentation:** [Get Short Answer Metric](https://products.wolframalpha.com/short-answers-api/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `i` | query | `string` | yes |
