# Delete Subscriber List with WEBLUCY

Deletes an existing subscriber list from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subscriber-lists/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Subscriber List](https://websitebuilder.docs.apiary.io/#reference/subscriber-lists/single-list/delete-subscriber-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The subscriber list ID. |
