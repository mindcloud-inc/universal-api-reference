# Delete Webhook with WEBLUCY

Deletes an existing webhook from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Webhook](https://websitebuilder.docs.apiary.io/#reference/webhooks/single-webhook/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The webhook ID. |
