# Get Member with WEBLUCY

Retrieves a member from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Get Member](https://websitebuilder.docs.apiary.io/#reference/members/single-member/retrieve-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The member ID. |
