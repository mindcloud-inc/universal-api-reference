# Update Subscriber List with WEBLUCY

Updates an existing subscriber list in WEBLUCY.

## Endpoint

- **Method:** `PUT`
- **Path:** `/subscriber-lists/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Update Subscriber List](https://websitebuilder.docs.apiary.io/#reference/subscriber-lists/single-list/update-subscriber-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The subscriber list ID. |
