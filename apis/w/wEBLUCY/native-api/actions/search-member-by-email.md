# Search Member by Email with WEBLUCY

Finds members in WEBLUCY by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/search-by-email`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Search Member by Email](https://websitebuilder.docs.apiary.io/#reference/members/search-members/search-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The member email address to search for. |
