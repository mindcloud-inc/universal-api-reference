# Update Member Group with WEBLUCY

Updates an existing member group in WEBLUCY.

## Endpoint

- **Method:** `PUT`
- **Path:** `/member-groups/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Update Member Group](https://websitebuilder.docs.apiary.io/#reference/member-groups/single-member-group/update-member-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The member group ID. |
