# Search Contact by Email with WEBLUCY

Finds contacts in WEBLUCY by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/search-by-email`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Search Contact by Email](https://websitebuilder.docs.apiary.io/#reference/contacts/search-contacts/search-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The contact email address to search for. |
