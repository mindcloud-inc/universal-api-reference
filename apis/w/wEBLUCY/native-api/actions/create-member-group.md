# Create Member Group with WEBLUCY

Creates a new member group in WEBLUCY.

## Endpoint

- **Method:** `POST`
- **Path:** `/member-groups`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Create Member Group](https://websitebuilder.docs.apiary.io/#reference/member-groups/list-and-create/create-new-member-group)
