# Get Contact with WEBLUCY

Retrieves a contact from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Get Contact](https://websitebuilder.docs.apiary.io/#reference/contacts/single-contact/retrieve-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The contact ID. |
