# Get Product with WEBLUCY

Retrieves a product from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Get Product](https://websitebuilder.docs.apiary.io/#reference/products/single-product/retrieve-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID. |
