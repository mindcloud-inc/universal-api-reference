# Create Subscriber List with WEBLUCY

Creates a new subscriber list in WEBLUCY.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriber-lists`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Create Subscriber List](https://websitebuilder.docs.apiary.io/#reference/subscriber-lists/list-and-create/create-new-subscriber-list)
