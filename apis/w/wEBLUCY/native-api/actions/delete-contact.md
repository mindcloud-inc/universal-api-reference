# Delete Contact with WEBLUCY

Deletes an existing contact from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Contact](https://websitebuilder.docs.apiary.io/#reference/contacts/single-contact/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The contact ID. |
