# Start Member Session with WEBLUCY

Starts a member session in WEBLUCY.

## Endpoint

- **Method:** `POST`
- **Path:** `/members/start-session`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Start Member Session](https://websitebuilder.docs.apiary.io/#reference/members/single-sign-on/start-member-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The member email address to start a session for. |
