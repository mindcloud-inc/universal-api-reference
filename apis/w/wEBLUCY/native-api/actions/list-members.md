# List Members with WEBLUCY

Retrieves members from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/members`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [List Members](https://websitebuilder.docs.apiary.io/#reference/members/list-and-create/list-all-members)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | query | `string` | no | Filter members by group ID. |
