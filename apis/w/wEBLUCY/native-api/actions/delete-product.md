# Delete Product with WEBLUCY

Deletes an existing product from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Product](https://websitebuilder.docs.apiary.io/#reference/products/single-product/delete-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID. |
