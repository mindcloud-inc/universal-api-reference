# Delete Member with WEBLUCY

Deletes an existing member from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/members/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Member](https://websitebuilder.docs.apiary.io/#reference/members/single-member/delete-member)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The member ID. |
