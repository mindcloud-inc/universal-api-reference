# Delete Member Group with WEBLUCY

Deletes an existing member group from WEBLUCY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/member-groups/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Delete Member Group](https://websitebuilder.docs.apiary.io/#reference/member-groups/single-member-group/delete-member-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The member group ID. |
