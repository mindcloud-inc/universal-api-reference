# Update Contact with WEBLUCY

Updates an existing contact in WEBLUCY.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Update Contact](https://websitebuilder.docs.apiary.io/#reference/contacts/single-contact/update-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The contact ID. |
