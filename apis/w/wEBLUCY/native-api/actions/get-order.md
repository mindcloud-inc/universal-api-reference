# Get Order with WEBLUCY

Retrieves an order from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Get Order](https://websitebuilder.docs.apiary.io/#reference/orders/single-order/retrieve-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The order ID. |
