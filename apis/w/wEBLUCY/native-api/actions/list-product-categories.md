# List Product Categories with WEBLUCY

Retrieves product categories from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/categories`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [List Product Categories](https://websitebuilder.docs.apiary.io/#reference/products/categories/list-all-categories)
