# Update Order with WEBLUCY

Updates an existing order in WEBLUCY.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Update Order](https://websitebuilder.docs.apiary.io/#reference/orders/single-order/update-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The order ID. |
