# Create Contact with WEBLUCY

Creates a new contact in WEBLUCY.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Create Contact](https://websitebuilder.docs.apiary.io/#reference/contacts/list-and-create/create-new-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | The contact email address. |
