# List Webhooks with WEBLUCY

Retrieves webhooks from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [List Webhooks](https://websitebuilder.docs.apiary.io/#reference/webhooks/list-and-create/list-all-webhooks)
