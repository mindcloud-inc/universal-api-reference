# Get Subscriber List with WEBLUCY

Retrieves a subscriber list from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriber-lists/{id}`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [Get Subscriber List](https://websitebuilder.docs.apiary.io/#reference/subscriber-lists/single-list/retrieve-subscriber-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The subscriber list ID. |
