# List Member Groups with WEBLUCY

Retrieves member groups from WEBLUCY.

## Endpoint

- **Method:** `GET`
- **Path:** `/member-groups`
- **Base URL:** `https://apps.weblucy.com/api/site`
- **Official documentation:** [List Member Groups](https://websitebuilder.docs.apiary.io/#reference/member-groups/list-and-create/list-all-member-groups)
