# Validate WhatsApp Number with WhatsApp Number Validator

Retrieves WhatsApp number validation details from WhatsApp Number Validator.

## Endpoint

- **Method:** `GET`
- **Path:** `number+check`
- **Base URL:** `https://zylalabs.com/api/9470/whatsapp+number+validator+api/21752`
- **Official documentation:** [Validate WhatsApp Number](https://zylalabs.com/api-marketplace/communication%2B%26%2Bmessaging/whatsapp%2Bnumber%2Bvalidator%2Bapi/9470)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number` | query | `string` | yes | Phone number with country code and no leading plus sign. |
