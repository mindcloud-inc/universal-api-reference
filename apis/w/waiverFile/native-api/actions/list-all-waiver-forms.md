# List All Waiver Forms with WaiverFile

Retrieves all waiver forms from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetAllWaiverForms`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List All Waiver Forms](https://api.waiverfile.com/swagger/ui/index)
