# Delete New Waiver Subscription with WaiverFile

Deletes a new waiver subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/newwaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete New Waiver Subscription](https://api.waiverfile.com/swagger/ui/index)
