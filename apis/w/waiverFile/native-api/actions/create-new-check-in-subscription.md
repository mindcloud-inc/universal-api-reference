# Create New Check-In Subscription with WaiverFile

Creates a new check-in subscription in WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribe/newcheckin`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Create New Check-In Subscription](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `targetUrl` | query | `string` | yes |
