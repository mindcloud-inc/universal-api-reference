# Get Waiver Data Count with WaiverFile

Retrieves waiver data count from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetWaiverDataCount`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Get Waiver Data Count](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `startDate` | query | `date` | yes |
| `endDate` | query | `date` | yes |
