# List Sample Edited Waivers with WaiverFile

Retrieves sample edited waivers from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sampledata/editwaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Sample Edited Waivers](https://api.waiverfile.com/swagger/ui/index)
