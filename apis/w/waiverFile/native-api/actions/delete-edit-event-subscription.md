# Delete Edit Event Subscription with WaiverFile

Deletes an edit event subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/editevent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete Edit Event Subscription](https://api.waiverfile.com/swagger/ui/index)
