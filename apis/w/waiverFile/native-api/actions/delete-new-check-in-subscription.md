# Delete New Check-In Subscription with WaiverFile

Deletes a new check-in subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/newcheckin`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete New Check-In Subscription](https://api.waiverfile.com/swagger/ui/index)
