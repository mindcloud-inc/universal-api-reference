# Create New Event Subscription with WaiverFile

Creates a new event subscription in WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribe/newevent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Create New Event Subscription](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `targetUrl` | query | `string` | yes |
