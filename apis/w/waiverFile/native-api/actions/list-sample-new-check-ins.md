# List Sample New Check-Ins with WaiverFile

Retrieves sample new check-ins from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sampledata/newcheckin`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Sample New Check-Ins](https://api.waiverfile.com/swagger/ui/index)
