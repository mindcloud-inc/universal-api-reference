# Get Waiver with WaiverFile

Retrieves a waiver from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetWaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Get Waiver](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `waiverID` | query | `string` | yes |
