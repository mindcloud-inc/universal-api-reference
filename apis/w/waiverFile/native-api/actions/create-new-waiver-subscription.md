# Create New Waiver Subscription with WaiverFile

Creates a new waiver subscription in WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribe/newwaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Create New Waiver Subscription](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `targetUrl` | query | `string` | yes |
