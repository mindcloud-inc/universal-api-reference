# Get Waivers by Reference ID with WaiverFile

Finds waivers in WaiverFile by reference ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetWaiversByReferenceID`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Get Waivers by Reference ID](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `refID1` | query | `string` | no |
| `refID2` | query | `string` | no |
| `refID3` | query | `string` | no |
| `refIDAny` | query | `string` | no |
