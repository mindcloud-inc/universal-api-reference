# List Sample New Events with WaiverFile

Retrieves sample new events from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sampledata/newevent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Sample New Events](https://api.waiverfile.com/swagger/ui/index)
