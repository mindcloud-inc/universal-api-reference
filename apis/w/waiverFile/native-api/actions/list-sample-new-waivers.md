# List Sample New Waivers with WaiverFile

Retrieves sample new waivers from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sampledata/newwaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Sample New Waivers](https://api.waiverfile.com/swagger/ui/index)
