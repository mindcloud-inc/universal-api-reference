# Delete Edit Waiver Subscription with WaiverFile

Deletes an edit waiver subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/editwaiver`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete Edit Waiver Subscription](https://api.waiverfile.com/swagger/ui/index)
