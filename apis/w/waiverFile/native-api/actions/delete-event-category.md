# Delete Event Category with WaiverFile

Deletes an existing event category from WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/DeleteEventCategory`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete Event Category](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eventCategoryID` | query | `string` | yes |
