# Ping Event Service with WaiverFile

Checks whether WaiverFile's event service is live.

## Endpoint

- **Method:** `POST`
- **Path:** `/EvtPing`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Ping Event Service](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `val` | body | `string` | yes |
