# Create Edit Event Subscription with WaiverFile

Creates an edit event subscription in WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribe/editevent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Create Edit Event Subscription](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `targetUrl` | query | `string` | yes |
