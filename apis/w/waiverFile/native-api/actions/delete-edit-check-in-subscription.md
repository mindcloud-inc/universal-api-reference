# Delete Edit Check-In Subscription with WaiverFile

Deletes an edit check-in subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/editcheckin`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete Edit Check-In Subscription](https://api.waiverfile.com/swagger/ui/index)
