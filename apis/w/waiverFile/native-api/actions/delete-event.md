# Delete Event with WaiverFile

Deletes an existing event from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/DeleteEvent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete Event](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eventID` | query | `string` | yes |
