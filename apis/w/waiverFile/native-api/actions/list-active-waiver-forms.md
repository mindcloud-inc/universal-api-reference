# List Active Waiver Forms with WaiverFile

Retrieves active waiver forms from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetActiveWaiverForms`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Active Waiver Forms](https://api.waiverfile.com/swagger/ui/index)
