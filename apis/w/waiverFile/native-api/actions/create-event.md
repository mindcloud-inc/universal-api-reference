# Create Event with WaiverFile

Creates a new event in WaiverFile.

## Endpoint

- **Method:** `POST`
- **Path:** `/InsertEvent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Create Event](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `eventPack` | body | `object` | yes |
