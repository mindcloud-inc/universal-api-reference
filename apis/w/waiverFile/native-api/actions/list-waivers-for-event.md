# List Waivers for Event with WaiverFile

Retrieves waivers for an event from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetWaiversForEvent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Waivers for Event](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `waiverEventID` | query | `string` | yes |
