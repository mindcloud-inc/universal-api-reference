# Search Waivers with WaiverFile

Finds waivers in WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/SearchWaivers`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Search Waivers](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `terms` | query | `string` | yes |
