# List Event Categories with WaiverFile

Retrieves event categories from WaiverFile.

## Endpoint

- **Method:** `GET`
- **Path:** `/GetEventCategories`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [List Event Categories](https://api.waiverfile.com/swagger/ui/index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `includeDisabledCategories` | query | `boolean` | yes |
