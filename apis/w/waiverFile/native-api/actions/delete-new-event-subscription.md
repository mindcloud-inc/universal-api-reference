# Delete New Event Subscription with WaiverFile

Deletes a new event subscription from WaiverFile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/deletesubscribe/newevent`
- **Base URL:** `https://api.waiverfile.com/api/v1`
- **Official documentation:** [Delete New Event Subscription](https://api.waiverfile.com/swagger/ui/index)
