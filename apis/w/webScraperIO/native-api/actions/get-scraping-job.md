# Get Scraping Job with WebScraper.IO

Retrieves a specific scraping job from WebScraper.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/scraping-job/:scrapingJobId`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [Get Scraping Job](https://webscraper.io/documentation/web-scraper-cloud/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scrapingJobId` | path | `number` | yes | The Web Scraper scraping job ID. |
