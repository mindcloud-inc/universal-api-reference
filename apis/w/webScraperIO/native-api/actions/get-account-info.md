# Get Account Info with WebScraper.IO

Retrieves your WebScraper.IO account details and credits.

## Endpoint

- **Method:** `GET`
- **Path:** `/account`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [Get Account Info](https://webscraper.io/documentation/web-scraper-cloud/api)
