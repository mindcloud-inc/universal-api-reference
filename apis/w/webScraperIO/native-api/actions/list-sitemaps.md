# List Sitemaps with WebScraper.IO

Lists sitemaps in your WebScraper.IO organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/sitemaps`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [List Sitemaps](https://webscraper.io/documentation/web-scraper-cloud/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | no | Filter sitemaps by tag. |
