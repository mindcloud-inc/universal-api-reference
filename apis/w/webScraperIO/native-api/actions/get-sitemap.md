# Get Sitemap with WebScraper.IO

Retrieves a specific sitemap from WebScraper.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/sitemap/:sitemapId`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [Get Sitemap](https://webscraper.io/documentation/web-scraper-cloud/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sitemapId` | path | `number` | yes | The Web Scraper sitemap ID. |
