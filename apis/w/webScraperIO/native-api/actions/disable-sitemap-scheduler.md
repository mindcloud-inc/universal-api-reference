# Disable Sitemap Scheduler with WebScraper.IO

Disables scheduler settings for a sitemap in WebScraper.IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/sitemap/:sitemapId/disable-scheduler`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [Disable Sitemap Scheduler](https://webscraper.io/documentation/web-scraper-cloud/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sitemapId` | path | `number` | yes | The Web Scraper sitemap ID. |
