# Delete Sitemap with WebScraper.IO

Deletes an existing sitemap from WebScraper.IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sitemap/:sitemapId`
- **Base URL:** `https://api.webscraper.io/api/v1`
- **Official documentation:** [Delete Sitemap](https://webscraper.io/documentation/web-scraper-cloud/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sitemapId` | path | `number` | yes | The Web Scraper sitemap ID. |
