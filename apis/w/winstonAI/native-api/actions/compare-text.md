# Compare Text with Winston AI

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/text-compare`
- **Base URL:** `https://api.gowinston.ai`
- **Official documentation:** [Compare Text](https://docs.gowinston.ai/api-reference/v2/text-compare/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `first_text` | body | `string` | yes | The first text to compare. |
| `second_text` | body | `string` | yes | The second text to compare. |
