# Create Knowledge Base with Wikibot

Creates a new knowledge base in Wikibot.

## Endpoint

- **Method:** `POST`
- **Path:** `/bot/kb/create`
- **Base URL:** `https://api.wikibot.pro/api`
- **Official documentation:** [Create Knowledge Base](https://wikibot.pro/docs/api/kb-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Source data URL for the knowledge base. |
