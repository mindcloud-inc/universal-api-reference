# Start Application with White Swan

Starts an application for a White Swan personal plan.

## Endpoint

- **Method:** `POST`
- **Path:** `/start_application`
- **Base URL:** `https://app.whiteswan.io/api/1.1/wf`
- **Official documentation:** [Start Application](https://docs.whiteswan.io/partner-knowledge-base/api-documentation/action-calls/start-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `plan` | body | `string` | yes | White Swan personal plan ID to start an application for. |
