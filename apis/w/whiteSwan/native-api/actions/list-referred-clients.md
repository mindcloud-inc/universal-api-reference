# List Referred Clients with White Swan

Retrieves referred clients from White Swan.

## Endpoint

- **Method:** `POST`
- **Path:** `/client`
- **Base URL:** `https://app.whiteswan.io/api/1.1/wf`
- **Official documentation:** [List Referred Clients](https://docs.whiteswan.io/partner-knowledge-base/api-documentation/information-calls/referred-client-s)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_email` | body | `string` | no | Optionally return one referred client by email. |
