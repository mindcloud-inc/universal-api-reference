# Check Login Name Availability with WeBeHome

## Endpoint

- **Method:** `POST`
- **Path:** `OpenAPIservice.svc/CreateWebTokens/CheckLoginName`
- **Base URL:** `https://webehome.com/API`
- **Official documentation:** [Check Login Name Availability](https://www.webehome.com/Doc/WeBeHomeOpenAPI.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LoginName` | body | `string` | yes | Login name to check. |
