# Get Template with Wooxy

Retrieves a template from your Wooxy account.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/template/email/get`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [Get Template](https://wooxy.com/api-documentation/templates/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | body | `string` | yes | The Wooxy template ID. |
