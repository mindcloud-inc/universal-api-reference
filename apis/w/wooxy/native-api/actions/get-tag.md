# Get Tag with Wooxy

Retrieves a tag from your Wooxy account.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/tags/get`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [Get Tag](https://wooxy.com/api-documentation/tags/get-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name. |
