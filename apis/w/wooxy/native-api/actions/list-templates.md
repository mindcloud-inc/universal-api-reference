# List Templates with Wooxy

Finds templates in your Wooxy account.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/template/email/find`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [List Templates](https://wooxy.com/api-documentation/templates/find-template)

## Capabilities

This operation supports [pagination](../README.md#pagination).
