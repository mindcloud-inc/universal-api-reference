# List Domains with Wooxy

Finds domains in your Wooxy account.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/domain/find`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [List Domains](https://wooxy.com/api-documentation/domains/find-domain)

## Capabilities

This operation supports [pagination](../README.md#pagination).
