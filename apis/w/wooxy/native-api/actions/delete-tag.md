# Delete Tag with Wooxy

Deletes an existing tag from Wooxy.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/tags/remove`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [Delete Tag](https://wooxy.com/api-documentation/tags/remove-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name to delete. |
