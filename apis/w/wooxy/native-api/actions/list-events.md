# List Events with Wooxy

Finds events in your Wooxy account.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/custom-event/find`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [List Events](https://wooxy.com/api-documentation/events/find-event)

## Capabilities

This operation supports [pagination](../README.md#pagination).
