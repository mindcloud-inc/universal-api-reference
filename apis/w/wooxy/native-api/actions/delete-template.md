# Delete Template with Wooxy

Deletes an existing template from Wooxy.

## Endpoint

- **Method:** `POST`
- **Path:** `v3/template/email/remove`
- **Base URL:** `https://api.wooxy.com`
- **Official documentation:** [Delete Template](https://wooxy.com/api-documentation/templates/remove-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | body | `string` | yes | The Wooxy template ID. |
