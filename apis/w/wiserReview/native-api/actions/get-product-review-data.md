# Get Product Review Data with WiserReview

Retrieves product review data from WiserReview.

## Endpoint

- **Method:** `POST`
- **Path:** `https://rs.wiserreview.com/api/v1/getProductReviewData`
- **Base URL:** `https://api.wiserreview.com/api/v1`
- **Official documentation:** [Get Product Review Data](https://apidocs.wiserreview.com/product-review-26682568e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | body | `string` | yes | Product ID for which to retrieve review data. |
