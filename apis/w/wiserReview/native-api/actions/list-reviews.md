# List Reviews with WiserReview

Retrieves reviews from WiserReview.

## Endpoint

- **Method:** `GET`
- **Path:** `/reviews`
- **Base URL:** `https://api.wiserreview.com/api/v1`
- **Official documentation:** [List Reviews](https://apidocs.wiserreview.com/get-review-list-26190892e0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
