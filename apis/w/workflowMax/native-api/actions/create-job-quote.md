# Create Job Quote with WorkflowMax

## Endpoint

- **Method:** `POST`
- **Path:** `v2/jobs/{UUID}/quotes`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Create Job Quote](https://api-docs.workflowmax.com/quote/post-v2-jobs-uuid-quotes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax job UUID. |
