# Get Task with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/tasks/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Task](https://api-docs.workflowmax.com/task/get-v2-tasks-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax task UUID. |
