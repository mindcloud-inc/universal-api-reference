# Create Job Cost with WorkflowMax

## Endpoint

- **Method:** `POST`
- **Path:** `v2/jobs/{identifier}/costs`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Create Job Cost](https://api-docs.workflowmax.com/job-cost/post-v2-jobs-uuid-costs-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax job identifier. |
