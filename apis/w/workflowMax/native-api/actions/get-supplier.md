# Get Supplier with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/suppliers/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Supplier](https://api-docs.workflowmax.com/supplier/get-supplier-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax supplier UUID. |
