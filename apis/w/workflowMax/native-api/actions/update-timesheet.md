# Update Timesheet with WorkflowMax

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/timesheets/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Update Timesheet](https://api-docs.workflowmax.com/timesheet/put-v2-timesheets-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax timesheet UUID. |
