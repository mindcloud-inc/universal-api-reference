# Create Purchase Order Bill with WorkflowMax

## Endpoint

- **Method:** `POST`
- **Path:** `v2/purchase-orders/{identifier}/bills`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Create Purchase Order Bill](https://api-docs.workflowmax.com/po-bill-2/post-v2-purchase-orders-uuid-bills)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax purchase order identifier. |
