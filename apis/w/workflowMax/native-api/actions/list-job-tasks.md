# List Job Tasks with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/jobs/tasks`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Job Tasks](https://api-docs.workflowmax.com/job-task/get-v2-jobs-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
