# Delete Job Task with WorkflowMax

## Endpoint

- **Method:** `DELETE`
- **Path:** `v2/jobs/tasks/{jobTaskUUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Delete Job Task](https://api-docs.workflowmax.com/job-task/delete-v2-jobs-tasks-jobtaskuuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobTaskUUID` | path | `string` | yes | The WorkflowMax job task UUID. |
