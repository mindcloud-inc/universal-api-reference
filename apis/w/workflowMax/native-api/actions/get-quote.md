# Get Quote with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/quotes/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Quote](https://api-docs.workflowmax.com/quote/get-v2-quotes-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax quote UUID. |
