# Update Task with WorkflowMax

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/tasks/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Update Task](https://api-docs.workflowmax.com/task/post-tasks-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax task UUID. |
