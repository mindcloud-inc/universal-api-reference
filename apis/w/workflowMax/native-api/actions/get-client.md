# Get Client with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/clients/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Client](https://api-docs.workflowmax.com/client/get-v2-clients-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax client UUID. |
