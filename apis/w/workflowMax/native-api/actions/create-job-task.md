# Create Job Task with WorkflowMax

## Endpoint

- **Method:** `POST`
- **Path:** `v2/jobs/{identifier}/tasks`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Create Job Task](https://api-docs.workflowmax.com/job-task/post-v2-jobs-uuidtasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax job identifier. |
