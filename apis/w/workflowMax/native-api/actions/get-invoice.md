# Get Invoice with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/invoices/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Invoice](https://api-docs.workflowmax.com/invoice/get-invoice-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax invoice UUID. |
