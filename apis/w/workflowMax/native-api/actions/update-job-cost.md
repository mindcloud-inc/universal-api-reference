# Update Job Cost with WorkflowMax

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/jobs/costs/{jobCostUUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Update Job Cost](https://api-docs.workflowmax.com/job-cost/post-job-identifier-cost-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobCostUUID` | path | `string` | yes | The WorkflowMax job cost UUID. |
