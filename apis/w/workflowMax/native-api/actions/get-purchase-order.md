# Get Purchase Order with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/purchase-orders/{identifier}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Purchase Order](https://api-docs.workflowmax.com/po-2/get-v2-purchase-orders-uuid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax purchase order identifier. |
