# List Tasks with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/tasks`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Tasks](https://api-docs.workflowmax.com/task/get-v2-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
