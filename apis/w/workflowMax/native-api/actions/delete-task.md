# Delete Task with WorkflowMax

## Endpoint

- **Method:** `DELETE`
- **Path:** `v2/tasks/{UUID}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Delete Task](https://api-docs.workflowmax.com/task/delete-v2-tasks-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax task UUID. |
