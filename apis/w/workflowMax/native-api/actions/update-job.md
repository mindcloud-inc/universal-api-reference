# Update Job with WorkflowMax

## Endpoint

- **Method:** `PUT`
- **Path:** `v2/jobs/{identifier}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Update Job](https://api-docs.workflowmax.com/job-1/post-job-copy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax job identifier. |
