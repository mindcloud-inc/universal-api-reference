# List Job Costs with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/jobs/{UUID}/costs`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Job Costs](https://api-docs.workflowmax.com/job-cost/get-v2-jobs-uuid-costs)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `UUID` | path | `string` | yes | The WorkflowMax job UUID. |
