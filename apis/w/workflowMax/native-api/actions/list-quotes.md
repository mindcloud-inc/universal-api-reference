# List Quotes with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/quotes`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Quotes](https://api-docs.workflowmax.com/quote/get-v2-quotes)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
