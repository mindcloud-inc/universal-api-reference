# List Payments with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/payments`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Payments](https://api-docs.workflowmax.com/invoice/get-v2-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
