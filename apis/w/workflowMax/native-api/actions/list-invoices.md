# List Invoices with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/invoices`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [List Invoices](https://api-docs.workflowmax.com/invoice/get-invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
