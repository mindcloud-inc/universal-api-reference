# Get Job with WorkflowMax

## Endpoint

- **Method:** `GET`
- **Path:** `v2/jobs/{identifier}`
- **Base URL:** `https://api.workflowmax.com`
- **Official documentation:** [Get Job](https://api-docs.workflowmax.com/job-1/get-v2-jobs-uuid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | The WorkflowMax job identifier. |
