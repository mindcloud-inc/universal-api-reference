# List Collections with Webflow

Retrieves a list of collections from Webflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/collections`
- **Base URL:** `https://api.webflow.com/v2`
- **Official documentation:** [List Collections](https://developers.webflow.com/data/reference/cms/collections/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | yes | The unique identifier of the site. |
