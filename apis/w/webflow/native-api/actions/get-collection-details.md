# Get Collection Details with Webflow

Retrieves details for a collection from Webflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collection_id`
- **Base URL:** `https://api.webflow.com/v2`
- **Official documentation:** [Get Collection Details](https://developers.webflow.com/data/reference/cms/collections/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `string` | yes | The unique identifier of the collection. |
