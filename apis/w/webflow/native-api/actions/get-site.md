# Get Site with Webflow

Retrieves a site from Webflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api.webflow.com/v2`
- **Official documentation:** [Get Site](https://developers.webflow.com/data/reference/sites/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `string` | yes | Unique identifier for a Site. |
