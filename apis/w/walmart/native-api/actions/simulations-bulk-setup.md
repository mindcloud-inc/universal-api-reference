# Bulk Order Setup - Simulation with Walmart

Simulations: On-click API that does item setup and order setup
for sellers in the Marketplace dynamic sandbox.

## Endpoint

- **Method:** `POST`
- **Path:** `v1/simulations/bulk/orders`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
