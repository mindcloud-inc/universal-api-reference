# Get Top Recommended Catalog Items with Walmart

This API allows you to fetch a list of top recommended items from your catalog.

## Endpoint

- **Method:** `GET`
- **Path:** `v3/advertising/sem/items/recommendations`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Top Recommended Catalog Items](https://developer.walmart.com/us-marketplace/reference/getcampaigndetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | # of records to retrieve. |
