# Token API - client_credentials with Walmart

## Endpoint

- **Method:** `POST`
- **Path:** `v3/token`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Token API - client_credentials](https://developer.walmart.com/us-marketplace/reference/tokenapi)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `grant_type` | body | `string` | no |
