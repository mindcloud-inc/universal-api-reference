# Get Shipping Configurations with Walmart

Retrieve shipping configurations like Lag Time.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shippingprofile`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Shipping Configurations](https://developer.walmart.com/us-marketplace/reference/getshippingconfigurations)
