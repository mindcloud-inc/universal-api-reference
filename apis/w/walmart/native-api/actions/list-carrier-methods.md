# List Carrier Methods with Walmart

Gets the available carrier methods

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/carriers`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [List Carrier Methods](https://developer.walmart.com/us-marketplace/reference/getcarriermethods)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
