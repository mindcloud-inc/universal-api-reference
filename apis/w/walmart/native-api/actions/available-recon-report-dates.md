# Available Recon Report Dates with Walmart

Retrieves details of all orders with optional search criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/report/reconreport/availableReconFiles?reportVersion=v1`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Available Recon Report Dates](https://developer.walmart.com/global-marketplace/reference/getallorders)
