# List Supported Carriers with Walmart

Retrieves all carriers supported by Ship With Walmart.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/shipping/labels/carriers`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [List Supported Carriers](https://developer.walmart.com/us-marketplace/reference/getcarriers)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
