# List Items - Simulation with Walmart

Retrieve all items from a partner’s catalog in the Dynamic Sandbox.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/simulations/items`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST (nextCursor)
- **Official documentation:** [List Items - Simulation](https://developer.walmart.com/us-marketplace/reference/getallitems)
