# List 3PL Providers with Walmart

Get a list of all third party fulfillment providers.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/3plproviders`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [List 3PL Providers](https://developer.walmart.com/us-marketplace/reference/get3pfulfillmentproviders)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
