# Get Partner Configurations with Walmart

Retrieve partner configurations like Seller Account & feed throttling values

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/partnerprofile`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Partner Configurations](https://developer.walmart.com/us-marketplace/reference/getpartnerconfigurations)
