# Get Simplified Shipping Settings with Walmart

Fetch the Simplified Shipping Settings for a seller account and FC level configurations.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/simplifiedshippingsettings`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Simplified Shipping Settings](https://developer.walmart.com/us-marketplace/reference/getsimplifiedshippingsettings)
