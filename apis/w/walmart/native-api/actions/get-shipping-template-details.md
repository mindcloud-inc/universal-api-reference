# Get Shipping Template Details with Walmart

Get Shipping Template Details of CUSTOM, DEFAULT & 3PL-specific templates.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/templates/:templateId`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Shipping Template Details](https://developer.walmart.com/us-marketplace/reference/getshippingtemplatedetails)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateId` | path | `string` | yes |
