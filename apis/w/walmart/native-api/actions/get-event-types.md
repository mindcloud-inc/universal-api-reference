# Get Event Types with Walmart

Retrieve the list of event types and resource names available for subscription.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/webhooks/eventTypes`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Event Types](https://developer.walmart.com/us-marketplace/reference/geteventtypes)
