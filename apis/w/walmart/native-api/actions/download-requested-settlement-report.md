# Download Requested Settlement Report with Walmart

## Endpoint

- **Method:** `GET`
- **Path:** `https://marketplace.walmartapis.com/v3/reports/downloadReport`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Download Requested Settlement Report](https://developer.walmart.com/global-marketplace/reference/getallorders)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `requestId` | query | `string` | no |
