# Get Shipping Template Activation Status with Walmart

Get the Activation Status of the Shipping Templates, which are set through Walmart Seller Center.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/templates/activationStatus`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Shipping Template Activation Status](https://developer.walmart.com/us-marketplace/reference/getshippingtemplateactivationstatus)
