# List Shipping Templates with Walmart

Get all the shipping templates for a Seller.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/templates`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [List Shipping Templates](https://developer.walmart.com/us-marketplace/reference/getallshippingtemplates)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
