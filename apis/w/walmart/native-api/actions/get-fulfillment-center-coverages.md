# Get Fulfillment Center Coverages with Walmart

This API provides the list of all fullfillment centers for the seller and their coverage areas defined by Walmart based on the address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/settings/shipping/shipnodes/coverage`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Fulfillment Center Coverages](https://developer.walmart.com/us-marketplace/reference/getcoverageforfulfillmentcenters)
