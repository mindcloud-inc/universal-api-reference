# Stop Campaign with Walmart

This API allows you to stop an active Campaign.

## Endpoint

- **Method:** `PUT`
- **Path:** `v3/advertising/sem/campaigns/:campaignId`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Stop Campaign](https://developer.walmart.com/us-marketplace/reference/getcampaigndetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Campaign ID of the campaign whose details are to be retrieved. |
