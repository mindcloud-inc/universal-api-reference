# Delete Shipping Template with Walmart

Delete Existing Shipping Template.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/settings/shipping/templates/:templateId`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Delete Shipping Template](https://developer.walmart.com/us-marketplace/reference/deleteshippingtemplatedetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Shipping Template ID of the template to be deleted. |
