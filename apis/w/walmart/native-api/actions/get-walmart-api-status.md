# Get Walmart API Status with Walmart

Get all marketplace Apis status.

## Endpoint

- **Method:** `GET`
- **Path:** `v3/utilities/apiStatus`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Get Walmart API Status](https://developer.walmart.com/us-marketplace/reference/getapiplatformstatus)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `*/*` |
