# Delete Subscription with Walmart

Delete an existing webhook subscription by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v3/webhooks/subscriptions/:subscriptionId`
- **Base URL:** `https://{environment}.walmartapis.com`
- **API:** REST
- **Official documentation:** [Delete Subscription](https://developer.walmart.com/us-marketplace/reference/deletesubscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes |
