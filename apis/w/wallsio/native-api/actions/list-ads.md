# List Ads with Walls.io

Retrieves sponsored posts from Walls.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/ads`
- **Base URL:** `https://api.walls.io/v1`
- **Official documentation:** [List Ads](https://github.com/DieSocialisten/Walls.io-API-Docs/blob/master/endpoints/GET_ads.md)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
