# Get User Analytics with Walls.io

Retrieves unique user counts by network from Walls.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/users`
- **Base URL:** `https://api.walls.io/v1`
- **Official documentation:** [Get User Analytics](https://github.com/DieSocialisten/Walls.io-API-Docs/blob/master/endpoints/GET_analytics-users.md)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
