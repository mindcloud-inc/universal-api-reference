# Get Report with Webshipper

Retrieves a report from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Report](https://docs.webshipper.io/#reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The report ID. |
