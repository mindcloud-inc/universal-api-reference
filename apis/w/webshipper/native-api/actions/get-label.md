# Get Label with Webshipper

Retrieves a label from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Label](https://docs.webshipper.io/#labels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The label ID. |
