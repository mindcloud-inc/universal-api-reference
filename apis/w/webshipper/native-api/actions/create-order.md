# Create Order with Webshipper

Creates an order in Webshipper.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Create Order](https://docs.webshipper.io/#orders)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/vnd.api+json` |
| `Content-Type` | `application/vnd.api+json` |
