# List Order Returns with Webshipper

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id/returns`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [List Order Returns](https://docs.webshipper.io/#orders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order ID. |
