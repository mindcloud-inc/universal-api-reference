# Get Carrier Type with Webshipper

Retrieves a carrier type from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/carrier_types/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Carrier Type](https://docs.webshipper.io/#carrier_types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The carrier type ID. |
