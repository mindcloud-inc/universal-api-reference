# Get Return Cause with Webshipper

Retrieves a return cause from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/return_causes/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Return Cause](https://docs.webshipper.io/#return_causes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The return cause ID. |
