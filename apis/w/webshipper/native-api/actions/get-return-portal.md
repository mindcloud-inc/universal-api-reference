# Get Return Portal with Webshipper

Retrieves a return portal from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/return_portals/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Return Portal](https://docs.webshipper.io/#return_portals)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The return portal ID. |
