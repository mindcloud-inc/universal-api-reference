# Create Shipping Rate with Webshipper

Creates a shipping rate in Webshipper.

## Endpoint

- **Method:** `POST`
- **Path:** `/shipping_rates`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Create Shipping Rate](https://docs.webshipper.io/#shipping_rates)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/vnd.api+json` |
| `Content-Type` | `application/vnd.api+json` |
