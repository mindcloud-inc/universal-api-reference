# List Shipment Events with Webshipper

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:id/events`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [List Shipment Events](https://docs.webshipper.io/#shipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Shipment ID. |
