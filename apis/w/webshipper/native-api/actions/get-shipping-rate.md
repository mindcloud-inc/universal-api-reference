# Get Shipping Rate with Webshipper

Retrieves a shipping rate from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping_rates/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Shipping Rate](https://docs.webshipper.io/#shipping_rates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Shipping rate ID. |
