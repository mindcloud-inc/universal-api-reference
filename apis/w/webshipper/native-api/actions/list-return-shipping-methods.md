# List Return Shipping Methods with Webshipper

Retrieves return shipping methods from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/return_shipping_methods`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [List Return Shipping Methods](https://docs.webshipper.io/#return_shipping_methods)
