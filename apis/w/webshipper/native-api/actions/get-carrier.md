# Get Carrier with Webshipper

Retrieves a carrier from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/carriers/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Carrier](https://docs.webshipper.io/#carriers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The carrier ID. |
