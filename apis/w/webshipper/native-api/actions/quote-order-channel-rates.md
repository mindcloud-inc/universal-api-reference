# Quote Order Channel Rates with Webshipper

Creates an order channel rate quote in Webshipper.

## Endpoint

- **Method:** `POST`
- **Path:** `/rate_quotes`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Quote Order Channel Rates](https://docs.webshipper.io/#rate_quotes)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/vnd.api+json` |
| `Content-Type` | `application/vnd.api+json` |
