# Get Return Shipping Method with Webshipper

Retrieves a return shipping method from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/return_shipping_methods/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Return Shipping Method](https://docs.webshipper.io/#return_shipping_methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The return shipping method ID. |
