# Get Order Channel with Webshipper

Retrieves an order channel from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/order_channels/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Order Channel](https://docs.webshipper.io/#order_channels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order channel ID. |
