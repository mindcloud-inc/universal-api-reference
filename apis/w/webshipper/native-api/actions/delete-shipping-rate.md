# Delete Shipping Rate with Webshipper

Deletes a shipping rate from Webshipper.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shipping_rates/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Delete Shipping Rate](https://docs.webshipper.io/#shipping_rates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
