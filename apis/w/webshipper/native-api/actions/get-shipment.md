# Get Shipment with Webshipper

Retrieves a shipment from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:id`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [Get Shipment](https://docs.webshipper.io/#shipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Shipment ID. |
