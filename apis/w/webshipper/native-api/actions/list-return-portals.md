# List Return Portals with Webshipper

Retrieves return portals from Webshipper.

## Endpoint

- **Method:** `GET`
- **Path:** `/return_portals`
- **Base URL:** `https://{accountName}.api.webshipper.io/v2`
- **Official documentation:** [List Return Portals](https://docs.webshipper.io/#return_portals)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter[id]` | query | `string` | no | Filter by id. |
