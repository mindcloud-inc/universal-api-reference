# Delete Custom Rules Progress with WakaTime

Aborts applying custom rules in WakaTime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:user/custom_rules_progress`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Delete Custom Rules Progress](https://wakatime.com/developers#custom_rules_progress)
