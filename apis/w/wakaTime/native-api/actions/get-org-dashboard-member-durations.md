# Get Org Dashboard Member Durations with WakaTime

Retrieves daily durations for a WakaTime dashboard member.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/orgs/:org/dashboards/:dashboard/members/:member/durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Org Dashboard Member Durations](https://wakatime.com/developers#org_dashboard_member_durations)
