# Create External Durations Bulk with WakaTime

Creates or updates external durations in WakaTime by external ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:user/external_durations.bulk`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Create External Durations Bulk](https://wakatime.com/developers#external_durations)
