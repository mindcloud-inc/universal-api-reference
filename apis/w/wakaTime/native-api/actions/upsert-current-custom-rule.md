# Upsert Current Custom Rule with WakaTime

Updates custom rules in WakaTime.

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/current/custom_rules`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Upsert Current Custom Rule](https://wakatime.com/developers#custom_rules)
