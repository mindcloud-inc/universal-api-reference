# Get Aggregated Stats Range with WakaTime

Retrieves aggregated coding stats for a WakaTime time range.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/:range`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Aggregated Stats Range](https://wakatime.com/developers#stats_aggregated)
