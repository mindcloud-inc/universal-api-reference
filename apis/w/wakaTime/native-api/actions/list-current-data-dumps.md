# List Current Data Dumps with WakaTime

Retrieves a user's WakaTime data exports.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/data_dumps`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current Data Dumps](https://wakatime.com/developers#data_dumps)
