# List External Durations with WakaTime

Retrieves daily external durations from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/external_durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List External Durations](https://wakatime.com/developers#external_durations)
