# Delete Current Heartbeats Bulk with WakaTime

Deletes multiple heartbeats from WakaTime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/current/heartbeats.bulk`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Delete Current Heartbeats Bulk](https://wakatime.com/developers#heartbeats)
