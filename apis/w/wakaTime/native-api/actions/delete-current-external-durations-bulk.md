# Delete Current External Durations Bulk with WakaTime

Deletes multiple external durations from WakaTime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/current/external_durations.bulk`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Delete Current External Durations Bulk](https://wakatime.com/developers#external_durations)
