# Get Current Project Commit with WakaTime

Retrieves a commit from a WakaTime project.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/projects/:project/commits/:hash`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Project Commit](https://wakatime.com/developers#commit)
