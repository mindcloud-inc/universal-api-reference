# Delete Custom Rule with WakaTime

Deletes a custom rule from WakaTime.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:user/custom_rules/:rule_id`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Delete Custom Rule](https://wakatime.com/developers#custom_rules)
