# Get Current Org Dashboard Durations with WakaTime

Retrieves daily durations for a WakaTime organization dashboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/orgs/:orgs/dashboards/:dashboard/durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Org Dashboard Durations](https://wakatime.com/developers#org_dashboard_durations)
