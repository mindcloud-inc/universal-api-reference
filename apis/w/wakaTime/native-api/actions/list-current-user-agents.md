# List Current User Agents with WakaTime

Retrieves a user's WakaTime plugin user agents.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/user_agents`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current User Agents](https://wakatime.com/developers#user_agents)
