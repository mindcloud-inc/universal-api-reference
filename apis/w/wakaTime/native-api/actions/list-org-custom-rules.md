# List Org Custom Rules with WakaTime

Retrieves custom rules for a WakaTime organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/orgs/:org/custom_rules`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Org Custom Rules](https://wakatime.com/developers#org_custom_rules)
