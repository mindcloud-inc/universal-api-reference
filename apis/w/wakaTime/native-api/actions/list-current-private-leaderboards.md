# List Current Private Leaderboards with WakaTime

Retrieves private leaderboards from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/leaderboards`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current Private Leaderboards](https://wakatime.com/developers#private_leaderboards)
