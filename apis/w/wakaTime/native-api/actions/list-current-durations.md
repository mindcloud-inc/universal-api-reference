# List Current Durations with WakaTime

Retrieves daily coding durations from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current Durations](https://wakatime.com/developers#durations)
