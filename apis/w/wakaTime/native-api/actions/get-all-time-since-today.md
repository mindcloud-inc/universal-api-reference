# Get All Time Since Today with WakaTime

Retrieves total logged time since account creation from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/all_time_since_today`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get All Time Since Today](https://wakatime.com/developers#all_time_since_today)
