# Get Org Dashboard Durations with WakaTime

Retrieves daily durations for a WakaTime organization dashboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/orgs/:org/dashboards/:dashboard/durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Org Dashboard Durations](https://wakatime.com/developers#org_dashboard_durations)
