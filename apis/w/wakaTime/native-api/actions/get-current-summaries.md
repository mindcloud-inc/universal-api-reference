# Get Current Summaries with WakaTime

Retrieves daily coding summaries from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/summaries`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Summaries](https://wakatime.com/developers#summaries)
