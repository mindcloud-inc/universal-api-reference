# Create External Duration with WakaTime

Creates or updates an external duration in WakaTime by external ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:user/external_durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Create External Duration](https://wakatime.com/developers#external_durations)
