# Create Heartbeats Bulk with WakaTime

Creates multiple heartbeats in WakaTime.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:user/heartbeats.bulk`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Create Heartbeats Bulk](https://wakatime.com/developers#heartbeats)
