# List Current Org Dashboard Members with WakaTime

Retrieves members of a WakaTime organization dashboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/orgs/:org/dashboards/:dashboard/members`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current Org Dashboard Members](https://wakatime.com/developers#org_dashboard_members)
