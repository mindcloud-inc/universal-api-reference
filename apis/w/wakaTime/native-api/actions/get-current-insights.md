# Get Current Insights with WakaTime

Retrieves a coding activity insight from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/insights/:insight_type/:range`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Insights](https://wakatime.com/developers#insights)
