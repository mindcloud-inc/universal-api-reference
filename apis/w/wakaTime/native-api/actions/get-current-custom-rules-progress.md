# Get Current Custom Rules Progress with WakaTime

Retrieves custom rule application progress from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/custom_rules_progress`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Custom Rules Progress](https://wakatime.com/developers#custom_rules_progress)
