# Get Current Org Dashboard Member Durations with WakaTime

Retrieves daily durations for a WakaTime dashboard member.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/orgs/:orgs/dashboards/:dashboard/members/:member/durations`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Org Dashboard Member Durations](https://wakatime.com/developers#org_dashboard_member_durations)
