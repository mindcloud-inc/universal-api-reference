# Get Status Bar Today with WakaTime

Retrieves today's status bar summary from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/status_bar/today`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Status Bar Today](https://wakatime.com/developers#status_bar)
