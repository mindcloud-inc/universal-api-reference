# Get Current Org Dashboard Summaries with WakaTime

Retrieves daily summaries for a WakaTime organization dashboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/orgs/:org/dashboards/:dashboard/summaries`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Org Dashboard Summaries](https://wakatime.com/developers#org_dashboard_summaries)
