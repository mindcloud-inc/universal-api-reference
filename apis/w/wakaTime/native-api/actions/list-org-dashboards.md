# List Org Dashboards with WakaTime

Retrieves dashboards for a WakaTime organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/orgs/:org/dashboards`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Org Dashboards](https://wakatime.com/developers#org_dashboards)
