# Get Org Dashboard Member Summaries with WakaTime

Retrieves daily summaries for a WakaTime dashboard member.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user/orgs/:org/dashboards/:dashboard/members/:member/summaries`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Org Dashboard Member Summaries](https://wakatime.com/developers#org_dashboard_member_summaries)
