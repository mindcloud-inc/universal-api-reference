# Upsert Org Custom Rule with WakaTime

Updates custom rules for a WakaTime organization.

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:user/orgs/:org/custom_rules`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Upsert Org Custom Rule](https://wakatime.com/developers#org_custom_rules)
