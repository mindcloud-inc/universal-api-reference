# Get Current Private Leaderboard Leaders with WakaTime

Retrieves ranked users from a private WakaTime leaderboard.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/leaderboards/:board`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [Get Current Private Leaderboard Leaders](https://wakatime.com/developers#private_leaderboards_leaders)
