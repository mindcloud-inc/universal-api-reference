# List Current Heartbeats with WakaTime

Retrieves daily heartbeats from WakaTime.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current/heartbeats`
- **Base URL:** `https://api.wakatime.com/api/v1`
- **Official documentation:** [List Current Heartbeats](https://wakatime.com/developers#heartbeats)
