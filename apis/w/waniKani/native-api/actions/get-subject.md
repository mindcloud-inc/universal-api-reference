# Get Subject with WaniKani

Retrieves a subject from WaniKani.

## Endpoint

- **Method:** `GET`
- **Path:** `/subjects/:id`
- **Base URL:** `https://api.wanikani.com/v2`
- **Official documentation:** [Get Subject](https://docs.api.wanikani.com/20170710/#get-a-specific-subject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier of the subject. |
