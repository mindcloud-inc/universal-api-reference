# List Review Statistics with WaniKani

Retrieves review statistics from WaniKani.

## Endpoint

- **Method:** `GET`
- **Path:** `/review_statistics`
- **Base URL:** `https://api.wanikani.com/v2`
- **Official documentation:** [List Review Statistics](https://docs.api.wanikani.com/20170710/#get-all-review-statistics)
