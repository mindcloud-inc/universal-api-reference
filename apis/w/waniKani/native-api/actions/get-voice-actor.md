# Get Voice Actor with WaniKani

Retrieves a voice actor from WaniKani.

## Endpoint

- **Method:** `GET`
- **Path:** `/voice_actors/:id`
- **Base URL:** `https://api.wanikani.com/v2`
- **Official documentation:** [Get Voice Actor](https://docs.api.wanikani.com/20170710/#get-a-specific-voice-actor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The voice actor ID to retrieve. |
