# Get Level Progression with WaniKani

Retrieves a level progression from WaniKani.

## Endpoint

- **Method:** `GET`
- **Path:** `/level_progressions/:id`
- **Base URL:** `https://api.wanikani.com/v2`
- **Official documentation:** [Get Level Progression](https://docs.api.wanikani.com/20170710/#get-a-specific-level-progression)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The level progression ID to retrieve. |
