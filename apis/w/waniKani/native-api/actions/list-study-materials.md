# List Study Materials with WaniKani

Retrieves study materials from WaniKani.

## Endpoint

- **Method:** `GET`
- **Path:** `/study_materials`
- **Base URL:** `https://api.wanikani.com/v2`
- **Official documentation:** [List Study Materials](https://docs.api.wanikani.com/20170710/#get-all-study-materials)
