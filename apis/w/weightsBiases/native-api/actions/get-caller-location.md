# Get Caller Location with Weights & Biases

Retrieves caller location details from Weights & Biases.

## Endpoint

- **Method:** `GET`
- **Path:** `/geolocate`
- **Base URL:** `https://trace.wandb.ai`
- **Official documentation:** [Get Caller Location](https://docs.wandb.ai/weave/reference/service-api/service/get-caller-location)
