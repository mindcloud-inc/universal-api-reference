# Get Server Info with Weights & Biases

Retrieves trace server information from Weights & Biases.

## Endpoint

- **Method:** `GET`
- **Path:** `/server_info`
- **Base URL:** `https://trace.wandb.ai`
- **Official documentation:** [Get Server Info](https://docs.wandb.ai/weave/reference/service-api/service/server-info)
