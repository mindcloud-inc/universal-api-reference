# Create Tree with Woztell

Creates a tree in your Woztell workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://open.api.woztell.com/v3`
- **Official documentation:** [Create Tree](https://doc.woztell.com/open-api-reference/#mutation-createTree)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.input.name` | body | `string` | yes |
| `variables.input.description` | body | `string` | no |
