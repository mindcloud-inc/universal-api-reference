# Get Document with Webling

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:id`
- **Base URL:** `https://{instanceDomain}/api/1`
- **Official documentation:** [Get Document](https://demo.webling.ch/api/1#document-document-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Document ID to retrieve. |
