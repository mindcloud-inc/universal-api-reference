# Get Documentgroup with Webling

## Endpoint

- **Method:** `GET`
- **Path:** `/documentgroup/:id`
- **Base URL:** `https://{instanceDomain}/api/1`
- **Official documentation:** [Get Documentgroup](https://demo.webling.ch/api/1#documentgroup-documentgroup-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Document group ID to retrieve. |
