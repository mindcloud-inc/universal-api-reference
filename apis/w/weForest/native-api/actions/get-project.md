# Get project with WeForest

Retrieves a project from WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get project](https://docs.weforest.org/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Project identifier from WeForest. |
