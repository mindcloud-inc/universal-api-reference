# Get all projects customer has supported with WeForest

Retrieves all supported projects for a customer in WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id/projects`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get all projects customer has supported](https://docs.weforest.org/get-all-projects-customer-has-supported)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer identifier from WeForest. |
