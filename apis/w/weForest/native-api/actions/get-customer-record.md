# Get customer record with WeForest

Retrieves a customer record from WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get customer record](https://docs.weforest.org/get-customer-record)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer identifier from WeForest. |
