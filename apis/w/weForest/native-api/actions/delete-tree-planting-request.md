# Delete tree-planting request with WeForest

Deletes an existing tree-planting request from WeForest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/trees/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Delete tree-planting request](https://docs.weforest.org/delete-tree-planting-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tree-planting request identifier from WeForest. |
