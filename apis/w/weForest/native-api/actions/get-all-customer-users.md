# Get all customer users with WeForest

Retrieves all users for a customer in WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id/users`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get all customer users](https://docs.weforest.org/get-all-customer-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Customer identifier from WeForest. |
