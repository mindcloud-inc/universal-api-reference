# Get tree-planting request with WeForest

Retrieves a tree-planting request from WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/trees/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get tree-planting request](https://docs.weforest.org/get-tree-planting-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tree-planting request identifier from WeForest. |
