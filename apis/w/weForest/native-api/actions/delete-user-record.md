# Delete user record with WeForest

Deletes an existing user from WeForest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Delete user record](https://docs.weforest.org/delete-user-record)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User identifier from WeForest. |
