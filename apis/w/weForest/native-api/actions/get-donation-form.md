# Get donation form with WeForest

Retrieves a donation form from WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get donation form](https://docs.weforest.org/get-donation-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Donation form identifier from WeForest. |
