# Get user record with WeForest

Retrieves a user record from WeForest.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.weforest.org`
- **Official documentation:** [Get user record](https://docs.weforest.org/get-user-record)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User identifier from WeForest. |
