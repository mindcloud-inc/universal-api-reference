# List Shipping Allowed Countries with WeSupply

Retrieves shipping allowed countries from WeSupply.

## Endpoint

- **Method:** `GET`
- **Path:** `/getShippingAllowedCountries`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [List Shipping Allowed Countries](https://documenter.getpostman.com/view/11859344/T17AiAYq#63d4b10a-55bd-403e-9bc8-787de2df4a0f)
