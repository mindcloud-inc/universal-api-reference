# Get Return By Reference with WeSupply

Retrieves a return from WeSupply by reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns/grabById`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Get Return By Reference](https://documenter.getpostman.com/view/11859344/T17AiAYq#3856b919-635a-4965-a745-f3e8d9ced2a5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Reference` | query | `string` | no | The WeSupply return reference. |
