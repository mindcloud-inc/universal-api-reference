# Get Return By Customer Email with WeSupply

Retrieves a return from WeSupply by customer email.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns/grabById`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Get Return By Customer Email](https://documenter.getpostman.com/view/11859344/T17AiAYq#34a720b0-feb6-42f9-828a-b6912f00639b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerEmail` | query | `string` | no | The customer email associated with the return. |
