# Get Return By Order ID with WeSupply

Retrieves a return from WeSupply by order ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns/grabById`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Get Return By Order ID](https://documenter.getpostman.com/view/11859344/T17AiAYq#66028da2-51d7-4a8d-ba24-8920c1bed478)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `OrderID` | query | `string` | no | The platform order ID associated with the return. |
