# List Returns By Page with WeSupply

Retrieves a page of returns from WeSupply.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [List Returns By Page](https://documenter.getpostman.com/view/11859344/T17AiAYq#b9964431-81ac-48e1-89d2-42b494eb6418)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Page` | query | `string` | no | Page number for paginated return listings. |
