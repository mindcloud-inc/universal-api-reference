# Update Shipment with WeSupply

Updates a shipment in WeSupply.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/shipment-update`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Update Shipment](https://documenter.getpostman.com/view/11859344/T17AiAYq#60b62c7d-8aea-4b73-9cac-9b3725e71963)
