# Create Tracker with WeSupply

Creates a shipment tracker in WeSupply.

## Endpoint

- **Method:** `POST`
- **Path:** `/tracker/create`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Create Tracker](https://documenter.getpostman.com/view/11859344/T17AiAYq#b3766a03-cffe-467a-80cb-b19af68bc5cb)
