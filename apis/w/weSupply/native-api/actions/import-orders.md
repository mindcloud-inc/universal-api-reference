# Import Orders with WeSupply

Creates orders in WeSupply from an order JSON payload.

## Endpoint

- **Method:** `POST`
- **Path:** `/json/import`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Import Orders](https://documenter.getpostman.com/view/11859344/T17AiAYq#63058bb9-87f1-4fac-8d89-51bd37b194d9)
