# List Recent Returns with WeSupply

Retrieves recent returns from WeSupply.

## Endpoint

- **Method:** `GET`
- **Path:** `/returns/recent`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [List Recent Returns](https://documenter.getpostman.com/view/11859344/T17AiAYq#3bf52ef5-a33d-4a03-a65f-647422fd3283)
