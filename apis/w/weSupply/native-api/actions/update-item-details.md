# Update Item Details with WeSupply

Updates item details in WeSupply.

## Endpoint

- **Method:** `POST`
- **Path:** `/external/item-update`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Update Item Details](https://documenter.getpostman.com/view/11859344/T17AiAYq#05e4d154-cc63-40cf-87ef-b95cd9529cac)
