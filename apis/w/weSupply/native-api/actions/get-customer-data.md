# Get Customer Data with WeSupply

Retrieves customer data from WeSupply.

## Endpoint

- **Method:** `GET`
- **Path:** `/gdpr/get`
- **Base URL:** `https://{subdomain}.labs.wesupply.xyz/api`
- **Official documentation:** [Get Customer Data](https://documenter.getpostman.com/view/11859344/T17AiAYq#380c8688-b00d-498d-ae74-80b2fb35c552)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerEmail` | query | `string` | no | The customer email address whose data should be retrieved. |
