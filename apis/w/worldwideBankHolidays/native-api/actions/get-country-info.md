# Get Country Info with Worldwide Bank Holidays

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/CountryInfo/{{countryCode}}`
- **Base URL:** `https://date.nager.at`
- **Official documentation:** [Get Country Info](https://date.nager.at/openapi/v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `countryCode` | path | `string` | yes | ISO 3166-1 alpha-2 country code, such as US or DE. |
