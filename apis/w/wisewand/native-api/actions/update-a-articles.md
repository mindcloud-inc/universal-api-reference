# Update a articles with Wisewand

Updates an existing article in your Wisewand workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/articles/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Update a articles](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
