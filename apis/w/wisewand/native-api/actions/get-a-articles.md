# Get a articles with Wisewand

Retrieves an article from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/articles/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get a articles](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
