# Create and run a categorypages with Wisewand

Creates and runs a category page in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categorypages/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create and run a categorypages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the category page. |
