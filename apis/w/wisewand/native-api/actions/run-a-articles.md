# Run a articles with Wisewand

Runs an article job in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/articles/:id/run`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Run a articles](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
