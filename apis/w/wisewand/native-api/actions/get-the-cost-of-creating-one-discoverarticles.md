# Get the cost of creating one discoverarticles with Wisewand

Retrieves discovery article creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/discoverarticles/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating one discoverarticles](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the discover article. |
