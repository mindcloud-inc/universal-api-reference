# Get projects with Wisewand

Retrieves a project from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get projects](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
