# Get entity counts summary with Wisewand

Retrieves entity count summaries from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/entities/summary/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get entity counts summary](https://api.wisewand.ai/docs)

## Capabilities

This operation supports [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `string` | no | Wisewand query parameter `projectId`. |
