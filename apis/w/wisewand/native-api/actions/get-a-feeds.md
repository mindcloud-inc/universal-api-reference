# Get a feeds with Wisewand

Retrieves a feed from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/feeds/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get a feeds](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
