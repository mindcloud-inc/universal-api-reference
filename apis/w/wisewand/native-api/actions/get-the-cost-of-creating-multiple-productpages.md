# Get the cost of creating multiple productpages with Wisewand

Retrieves bulk product page creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/productpages/bulk/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating multiple productpages](https://api.wisewand.ai/docs)
