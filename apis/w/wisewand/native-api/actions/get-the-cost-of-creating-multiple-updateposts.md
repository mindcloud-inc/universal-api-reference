# Get the cost of creating multiple updateposts with Wisewand

Retrieves bulk update post creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/updateposts/bulk/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating multiple updateposts](https://api.wisewand.ai/docs)
