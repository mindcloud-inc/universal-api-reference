# Update a feeds with Wisewand

Updates an existing feed in your Wisewand workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/feeds/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Update a feeds](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
