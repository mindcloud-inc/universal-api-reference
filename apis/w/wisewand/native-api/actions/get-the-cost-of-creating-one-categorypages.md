# Get the cost of creating one categorypages with Wisewand

Retrieves category page creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categorypages/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating one categorypages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the category page. |
