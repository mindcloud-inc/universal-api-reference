# Create and run a updateposts with Wisewand

Creates and runs an update post in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/updateposts/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create and run a updateposts](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the article. It can also contains source URLs. |
