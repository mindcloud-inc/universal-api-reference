# Create and run a discoverarticles with Wisewand

Creates and runs a discovery article in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/discoverarticles/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create and run a discoverarticles](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the discover article. |
