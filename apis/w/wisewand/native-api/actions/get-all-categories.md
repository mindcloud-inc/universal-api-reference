# Get all categories with Wisewand

Retrieves categories from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/categories/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get all categories](https://api.wisewand.ai/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Wisewand query parameter `search`. |
