# Delete personas with Wisewand

Deletes an existing persona from your Wisewand workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/personas/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Delete personas](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
