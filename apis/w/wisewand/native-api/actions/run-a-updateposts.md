# Run a updateposts with Wisewand

Runs an update post in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/updateposts/:id/run`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Run a updateposts](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
