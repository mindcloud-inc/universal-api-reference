# Deletev1feedsbyid with Wisewand

Deletes an existing feed from your Wisewand workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/feeds/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Deletev1feedsbyid](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
