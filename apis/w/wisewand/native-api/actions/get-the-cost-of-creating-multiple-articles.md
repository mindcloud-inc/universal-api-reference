# Get the cost of creating multiple articles with Wisewand

Retrieves bulk article creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/articles/bulk/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating multiple articles](https://api.wisewand.ai/docs)
