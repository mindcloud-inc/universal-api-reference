# Create a feed with Wisewand

Creates a new feed in your Wisewand workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/feeds/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create a feed](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of the RSS feed to monitor |
