# Get the cost of creating multiple discoverarticles with Wisewand

Retrieves bulk discovery article creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/discoverarticles/bulk/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating multiple discoverarticles](https://api.wisewand.ai/docs)
