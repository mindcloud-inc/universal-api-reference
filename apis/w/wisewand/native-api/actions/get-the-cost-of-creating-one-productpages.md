# Get the cost of creating one productpages with Wisewand

Retrieves product page creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/productpages/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating one productpages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the product page. |
