# Run a categorypages with Wisewand

Runs a category page in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categorypages/:id/run`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Run a categorypages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
