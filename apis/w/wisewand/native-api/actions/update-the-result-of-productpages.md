# Update the result of productpages with Wisewand

Updates a product page result in Wisewand.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/productpages/:id/output/:outputId`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Update the result of productpages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Wisewand path parameter `id`. |
| `outputId` | path | `string` | yes | Wisewand path parameter `outputId`. |
