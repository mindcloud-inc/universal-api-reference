# Get the cost of creating one updateposts with Wisewand

Retrieves update post creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/updateposts/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating one updateposts](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the article. It can also contains source URLs. |
