# Get job status with Wisewand

Retrieves a job status from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/jobs/:id`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get job status](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The job ID |
