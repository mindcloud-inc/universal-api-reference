# Create and run a productpages with Wisewand

Creates and runs a product page in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/productpages/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create and run a productpages](https://api.wisewand.ai/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subject` | body | `string` | yes | The subject of the product page. |
