# Get all authors with Wisewand

Retrieves authors from your Wisewand workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/authors/`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get all authors](https://api.wisewand.ai/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Wisewand query parameter `search`. |
