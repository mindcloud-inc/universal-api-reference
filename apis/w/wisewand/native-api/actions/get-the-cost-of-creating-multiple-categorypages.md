# Get the cost of creating multiple categorypages with Wisewand

Retrieves bulk category page creation cost from Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categorypages/bulk/cost`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Get the cost of creating multiple categorypages](https://api.wisewand.ai/docs)
