# Create multiple discoverarticles with Wisewand

Creates multiple new discovery articles in Wisewand.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/discoverarticles/bulk`
- **Base URL:** `https://api.wisewand.ai`
- **Official documentation:** [Create multiple discoverarticles](https://api.wisewand.ai/docs)
