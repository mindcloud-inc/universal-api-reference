# Ask Questions About a Page with WebScraping.AI

## Endpoint

- **Method:** `GET`
- **Path:** `/ai/question`
- **Base URL:** `https://api.webscraping.ai`
- **Official documentation:** [Ask Questions About a Page](https://webscraping.ai/docs#ai-question)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL of the webpage to analyze |
| `question` | query | `string` | yes | Question to ask about the page content |
