# Get CastleGate Orders with Wayfair

## Endpoint

- **Method:** `POST`
- **Path:** `graphql`
- **Base URL:** `https://{environment}.com/v1/`
- **Official documentation:** [Get CastleGate Orders](https://developer.wayfair.com/docs/#castlegate-order-query)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | body | `number` | no |
| `poNumbers` | body | `string` | no |
| `hasResponse` | body | `string` | no |
| `fromDate` | body | `string` | no |
