# Register Order with Wayfair

Register purchase order items for shipment

## Endpoint

- **Method:** `POST`
- **Path:** `graphql`
- **Base URL:** `https://{environment}.com/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `string` | no |
| `variables` | body | `string` | no |
