# Get Bill of Lading with Wayfair

## Endpoint

- **Method:** `GET`
- **Path:** `bill_of_lading/:purchaseOrderNumber`
- **Base URL:** `https://{environment}.com/v1/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `purchaseOrderNumber` | path | `string` | yes |
