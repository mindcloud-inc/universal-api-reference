# List Contact Accounts with Watbot

Retrieves contact accounts from Watbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/getContactAccounts`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [List Contact Accounts](https://docs.watbot.ru/rabota-s-api/kontakty/bills)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | query | `number` | yes | ID of an existing Watbot contact. |
