# Delete List Schema with Watbot

Deletes an existing list schema from Watbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/deleteListSchema`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [Delete List Schema](https://docs.watbot.ru/rabota-s-api/spiski/spiski)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schema_id` | body | `string` | yes | ID of the list schema. |
