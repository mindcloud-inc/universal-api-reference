# Get List Schema with Watbot

Retrieves a list schema from Watbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/getListSchema`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [Get List Schema](https://docs.watbot.ru/rabota-s-api/spiski/spiski)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schema_id` | query | `string` | yes | ID of the list schema. |
