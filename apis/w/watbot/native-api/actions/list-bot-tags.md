# List Bot Tags with Watbot

Retrieves bot tags from Watbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/getBotTags`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [List Bot Tags](https://docs.watbot.ru/rabota-s-api/kontakty/tegi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | query | `number` | yes | ID бота. |
