# List Contact Variables with Watbot

Retrieves contact variables from Watbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/getContactVariables`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [List Contact Variables](https://docs.watbot.ru/rabota-s-api/kontakty/polzovatelskie-peremennye)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | query | `number` | yes | ID контакта. |
