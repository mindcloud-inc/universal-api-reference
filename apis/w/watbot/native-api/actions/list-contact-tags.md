# List Contact Tags with Watbot

Retrieves contact tags from Watbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/getContactTags`
- **Base URL:** `https://watbot.ru/api/v1`
- **Official documentation:** [List Contact Tags](https://docs.watbot.ru/rabota-s-api/kontakty/tegi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | query | `number` | yes | ID контакта. |
