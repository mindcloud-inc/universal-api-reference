# Get Tracking Waiver with WaiverForever

Retrieves a waiver from WaiverForever by tracking ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v1/waiver/tracking/:tracking_id`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Get Tracking Waiver](https://docs.waiverforever.com/#get-tracking-waiver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tracking_id` | path | `string` | yes | Tracking identifier returned by Request Waiver. |
