# List Subscriptions with WaiverForever

Retrieves webhook subscriptions from WaiverForever.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v1/webhooks/`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [List Subscriptions](https://docs.waiverforever.com/#get-all-subscriptions)
