# Get Template Prefill Schema with WaiverForever

Retrieves a template prefill schema from WaiverForever.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v2/template/:template_id/prefill/schema`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Get Template Prefill Schema](https://docs.waiverforever.com/#get-template-prefill-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | WaiverForever template identifier. |
