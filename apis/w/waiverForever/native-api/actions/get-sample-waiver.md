# Get Sample Waiver with WaiverForever

Retrieves a sample waiver from a WaiverForever template.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v1/template/:template_id/getSampleWaiver`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Get Sample Waiver](https://docs.waiverforever.com/#get-sample-waiver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | WaiverForever template identifier. |
