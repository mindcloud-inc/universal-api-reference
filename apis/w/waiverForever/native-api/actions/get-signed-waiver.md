# Get Signed Waiver with WaiverForever

Retrieves a signed waiver from WaiverForever.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v1/waiver/:waiver_id`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Get Signed Waiver](https://docs.waiverforever.com/#get-signed-waiver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `waiver_id` | path | `string` | yes | Signed waiver identifier. |
