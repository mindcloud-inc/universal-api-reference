# Get Waiver Request Prefill Schema with WaiverForever

Retrieves a waiver request prefill schema from WaiverForever.

## Endpoint

- **Method:** `GET`
- **Path:** `/openapi/v2/waiverRequest/:group_id/prefill/schema`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Get Waiver Request Prefill Schema](https://docs.waiverforever.com/#get-waiver-request-prefill-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | Waiver request group identifier. |
