# Accept Waiver with WaiverForever

Accepts a waiver in WaiverForever.

## Endpoint

- **Method:** `POST`
- **Path:** `/openapi/v2/waiver/:waiver_id/accept`
- **Base URL:** `https://api.waiverforever.com`
- **Official documentation:** [Accept Waiver](https://docs.waiverforever.com/#accept-waiver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `waiver_id` | path | `string` | yes | Signed waiver identifier. |
