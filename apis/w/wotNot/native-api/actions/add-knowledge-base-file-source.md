# Add Knowledge Base File Source with WotNot

Adds a file source to a WotNot knowledge base.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/ai/knowledge-base/:knowledge_base_id/upload/sources`
- **Base URL:** `https://api.wotnot.io`
- **Official documentation:** [Add Knowledge Base File Source](https://help.wotnot.io/build/integrations/public-apis)
