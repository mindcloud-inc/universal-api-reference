# Get Bot Flow with WotNot

Retrieves a bot flow from WotNot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/bots/:bot_id/flow`
- **Base URL:** `https://api.wotnot.io`
- **Official documentation:** [Get Bot Flow](https://help.wotnot.io/build/integrations/public-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_id` | path | `number` | yes | WotNot bot ID |
