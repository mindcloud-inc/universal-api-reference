# Delete Received Chat with WhatsBoost

Deletes a received chat from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/wa.received`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Received Chat](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Received chat ID |
