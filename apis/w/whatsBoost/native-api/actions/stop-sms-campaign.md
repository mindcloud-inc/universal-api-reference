# Stop SMS Campaign with WhatsBoost

Stops an SMS campaign in WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/remote/stop.sms`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Stop SMS Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign` | body | `number` | yes | Campaign ID |
