# Create Group with WhatsBoost

Creates a new group in WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/create/group`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Create Group](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of group. |
