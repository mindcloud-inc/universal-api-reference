# Delete Contact with WhatsBoost

Deletes an existing contact from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/contact`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Contact](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Contact ID |
