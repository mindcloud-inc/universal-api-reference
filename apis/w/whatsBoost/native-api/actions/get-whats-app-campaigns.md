# Get WhatsApp Campaigns with WhatsBoost

Retrieves WhatsApp campaigns from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/get/wa.campaigns`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Get WhatsApp Campaigns](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | Limit the number of results per page. |
| `page` | body | `number` | no | Pagination of results. |
