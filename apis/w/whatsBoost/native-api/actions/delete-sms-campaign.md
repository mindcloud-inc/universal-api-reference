# Delete SMS Campaign with WhatsBoost

Deletes an SMS campaign from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/sms.campaign`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete SMS Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Campaign ID |
