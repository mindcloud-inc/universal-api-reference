# Delete Received Message with WhatsBoost

Deletes a received message from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/sms.received`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Received Message](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Received message ID |
