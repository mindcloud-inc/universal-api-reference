# Get USSD Requests with WhatsBoost

Retrieves USSD requests from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/get/ussd`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Get USSD Requests](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | Limit the number of results per page. |
| `page` | body | `number` | no | Pagination of results. |
