# Get WhatsApp QR Image with WhatsBoost

Retrieves a WhatsApp QR image from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/get/wa.qr`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Get WhatsApp QR Image](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | body | `string` | yes | The token string you got from create WhatsApp QRCode |
