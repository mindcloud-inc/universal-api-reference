# Delete Sent Chat with WhatsBoost

Deletes a sent chat from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/wa.sent`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Sent Chat](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Sent chat ID |
