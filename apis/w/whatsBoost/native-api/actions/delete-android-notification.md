# Delete Android Notification with WhatsBoost

Deletes an Android notification from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/notification`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Android Notification](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Notification ID |
