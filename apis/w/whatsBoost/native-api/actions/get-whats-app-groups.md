# Get WhatsApp Groups with WhatsBoost

Retrieves WhatsApp groups from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/get/wa.groups`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Get WhatsApp Groups](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `unique` | body | `string` | yes | WhatsApp Unique ID |
