# Delete USSD Request with WhatsBoost

Deletes a USSD request from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/ussd`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete USSD Request](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | USSD request ID |
