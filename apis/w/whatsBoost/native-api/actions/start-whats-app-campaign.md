# Start WhatsApp Campaign with WhatsBoost

Starts a WhatsApp campaign in WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/remote/start.chats`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Start WhatsApp Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign` | body | `number` | yes | Campaign ID |
