# Delete Unsubscribed with WhatsBoost

Deletes an unsubscribed contact from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/unsubscribed`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Unsubscribed](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Contact ID |
