# Stop WhatsApp Campaign with WhatsBoost

Stops a WhatsApp campaign in WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/remote/stop.chats`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Stop WhatsApp Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign` | body | `number` | yes | Campaign ID |
