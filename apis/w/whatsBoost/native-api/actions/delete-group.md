# Delete Group with WhatsBoost

Deletes an existing group from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/group`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Group](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Contact group ID |
