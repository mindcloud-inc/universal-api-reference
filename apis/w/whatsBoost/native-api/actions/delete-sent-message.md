# Delete Sent Message with WhatsBoost

Deletes a sent message from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/sms.sent`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete Sent Message](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Sent message ID |
