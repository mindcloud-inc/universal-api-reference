# Delete WhatsApp Account with WhatsBoost

Deletes a WhatsApp account from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/wa.account`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete WhatsApp Account](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `unique` | body | `string` | yes | WhatsApp Unique ID |
