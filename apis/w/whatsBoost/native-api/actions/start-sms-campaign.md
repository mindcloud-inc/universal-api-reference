# Start SMS Campaign with WhatsBoost

Starts an SMS campaign in WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/remote/start.sms`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Start SMS Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign` | body | `number` | yes | Campaign ID |
