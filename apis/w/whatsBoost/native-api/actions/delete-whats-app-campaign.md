# Delete WhatsApp Campaign with WhatsBoost

Deletes a WhatsApp campaign from WhatsBoost.

## Endpoint

- **Method:** `POST`
- **Path:** `/delete/wa.campaign`
- **Base URL:** `https://whatsboost.net/api`
- **Official documentation:** [Delete WhatsApp Campaign](https://whatsboost.net/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Campaign ID |
