# Delete CRM Contact with WhatsScale

Deletes an existing CRM contact from WhatsScale.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/crm/contacts/:id`
- **Base URL:** `https://proxy.whatsscale.com`
- **Official documentation:** [Delete CRM Contact](https://whatsscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CRM contact ID. |
