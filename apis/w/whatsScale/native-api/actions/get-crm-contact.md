# Get CRM Contact with WhatsScale

Retrieves a CRM contact from WhatsScale.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/crm/contacts/:id`
- **Base URL:** `https://proxy.whatsscale.com`
- **Official documentation:** [Get CRM Contact](https://whatsscale.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CRM contact ID. |
