# Get Workspace with Walla Form

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace/:workspaceKey`
- **Base URL:** `https://walla-api.data-lab.workers.dev`
- **Official documentation:** [Get Workspace](https://walla-api.data-lab.workers.dev/ui)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceKey` | path | `string` | yes | The Walla workspace key. |
