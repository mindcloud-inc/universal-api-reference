# Get a Directory with WorkOS

Retrieves a directory from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/directories/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a Directory](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the Directory. |
