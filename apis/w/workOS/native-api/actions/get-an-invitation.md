# Get an invitation with WorkOS

Retrieves an invitation from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_management/invitations/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get an invitation](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the invitation. |
| `id` | path | `string` | yes | The unique ID of the invitation. |
