# Get a Directory User with WorkOS

Retrieves a directory user from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/directory_users/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a Directory User](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the Directory User. |
