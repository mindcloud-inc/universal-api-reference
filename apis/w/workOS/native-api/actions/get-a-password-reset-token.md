# Get a password reset token with WorkOS

Retrieves a password reset token from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_management/password_reset/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a password reset token](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the password reset token. |
