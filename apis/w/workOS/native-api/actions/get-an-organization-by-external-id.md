# Get an Organization by External ID with WorkOS

Retrieves an organization by external ID from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/external_id/{external_id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get an Organization by External ID](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `external_id` | path | `string` | yes | The external ID of the Organization. |
