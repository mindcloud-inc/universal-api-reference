# Get a user with WorkOS

Retrieves a user from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_management/users/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a user](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the user. |
