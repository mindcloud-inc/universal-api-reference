# Delete a Webhook Endpoint with WorkOS

Deletes a webhook endpoint from your WorkOS environment.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook_endpoints/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Delete a Webhook Endpoint](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the Webhook Endpoint. |
