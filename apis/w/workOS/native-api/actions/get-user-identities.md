# Get user identities with WorkOS

Retrieves user identities from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_management/users/{id}/identities`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get user identities](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the user. |
