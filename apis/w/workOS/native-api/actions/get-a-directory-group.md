# Get a Directory Group with WorkOS

Retrieves a directory group from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/directory_groups/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a Directory Group](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the Directory Group. |
