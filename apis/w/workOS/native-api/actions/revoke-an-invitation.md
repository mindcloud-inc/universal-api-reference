# Revoke an invitation with WorkOS

Revokes an invitation in your WorkOS environment.

## Endpoint

- **Method:** `POST`
- **Path:** `/user_management/invitations/{id}/revoke`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Revoke an invitation](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the invitation. |
