# Delete a user with WorkOS

Deletes a user from your WorkOS environment.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user_management/users/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Delete a user](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the user. |
