# Get a Connection with WorkOS

Retrieves a connection from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a Connection](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the Connection. |
| `id` | path | `string` | yes | Unique identifier for the Connection. |
