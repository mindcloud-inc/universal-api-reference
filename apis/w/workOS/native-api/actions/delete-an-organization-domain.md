# Delete an Organization Domain with WorkOS

Deletes an organization domain from your WorkOS environment.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organization_domains/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Delete an Organization Domain](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the organization domain. |
