# Get Audit Log Configuration with WorkOS

Retrieves audit log configuration from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{id}/audit_log_configuration`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get Audit Log Configuration](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the Organization. |
