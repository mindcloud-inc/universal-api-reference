# Get an Organization with WorkOS

Retrieves an organization from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{id}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get an Organization](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the Organization. |
| `id` | path | `string` | yes | Unique identifier of the Organization. |
