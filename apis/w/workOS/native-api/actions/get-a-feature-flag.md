# Get a feature flag with WorkOS

Retrieves a feature flag from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/feature-flags/{slug}`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get a feature flag](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | A unique key to reference the Feature Flag. |
