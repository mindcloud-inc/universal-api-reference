# Verify an Organization Domain with WorkOS

Verifies an organization domain in your WorkOS environment.

## Endpoint

- **Method:** `POST`
- **Path:** `/organization_domains/{id}/verify`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Verify an Organization Domain](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the organization domain. |
