# Get Retention with WorkOS

Retrieves retention from your WorkOS environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{id}/audit_logs_retention`
- **Base URL:** `https://api.workos.com`
- **Official documentation:** [Get Retention](https://workos.com/docs/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the Organization. |
