# Get Feed with Webcrawler API

Retrieves feed details and recent runs from Webcrawler API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/feed/:id`
- **Base URL:** `https://api.webcrawlerapi.com`
- **Official documentation:** [Get Feed](https://webcrawlerapi.com/docs/api/feed/feed-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Feed identifier. |
