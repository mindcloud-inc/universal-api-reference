# Resume Feed with Webcrawler API

Resumes a paused feed in Webcrawler API.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/feed/:id/resume`
- **Base URL:** `https://api.webcrawlerapi.com`
- **Official documentation:** [Resume Feed](https://webcrawlerapi.com/docs/api/feed/feed-manage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Feed identifier. |
