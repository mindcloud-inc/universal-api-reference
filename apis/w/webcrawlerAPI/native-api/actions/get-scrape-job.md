# Get Scrape Job with Webcrawler API

Retrieves scrape job status and results from Webcrawler API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/scrape/:id`
- **Base URL:** `https://api.webcrawlerapi.com`
- **Official documentation:** [Get Scrape Job](https://webcrawlerapi.com/docs/async-requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Scrape job identifier. |
