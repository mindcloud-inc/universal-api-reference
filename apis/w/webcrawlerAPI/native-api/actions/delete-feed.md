# Delete Feed with Webcrawler API

Deletes an existing feed from Webcrawler API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/feed/:id`
- **Base URL:** `https://api.webcrawlerapi.com`
- **Official documentation:** [Delete Feed](https://webcrawlerapi.com/docs/api/feed/feed-manage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Feed identifier to delete. |
