# Get Crawl Job with Webcrawler API

Retrieves crawl job status and results from Webcrawler API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/job/:id`
- **Base URL:** `https://api.webcrawlerapi.com`
- **Official documentation:** [Get Crawl Job](https://webcrawlerapi.com/docs/api/job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Crawl job ID. |
