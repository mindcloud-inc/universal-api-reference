# Webcrawler API: Get Scrape Job

Retrieves scrape job status and results from Webcrawler API.

```
GET https://connect.mindcloud.co/v1/universal/webcrawlerAPI/latest/actions/get-scrape-job
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Webcrawler API `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/webcrawlerAPI/latest/actions/get-scrape-job?connectionId=$CONNECTION_ID&id=string" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId,
  "id": "string"
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/webcrawlerAPI/latest/actions/get-scrape-job?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | yes | Scrape job identifier. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "cleanedContent": "string",
      "links": [
        "https://example.com"
      ],
      "markdown": "string",
      "pageStatusCode": 1,
      "pageTitle": "string",
      "rawContent": "string",
      "status": "string",
      "structuredData": {},
      "success": true
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `cleanedContent` | string | Cleaned content output when returned by the provider. |
| `links` | array<string> | Links discovered on the page when requested. |
| `markdown` | string | Markdown output returned by the scrape when requested. |
| `pageStatusCode` | number | HTTP status code returned for the scraped page. |
| `pageTitle` | string | Resolved page title when available. |
| `rawContent` | string | Raw page content when returned by the provider. |
| `status` | string | Current scrape job status. |
| `structuredData` | object | Structured output generated by the scrape when prompt extraction is used. |
| `success` | boolean | Whether the scrape completed successfully when returned. |

## Native endpoint

Through the native Webcrawler API API, this operation is `GET /v2/scrape/:id` (base URL `https://api.webcrawlerapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-scrape-job.md) for the provider-specific parameters and requirements.
