# Get Push Status with Webpushr

## Endpoint

- **Method:** `GET`
- **Path:** `/notification/status/id/:campaignId`
- **Base URL:** `https://api.webpushr.com/v1`
- **Official documentation:** [Get Push Status](https://www.webpushr.com/docs/check-push-notification-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The push campaign ID returned when a notification campaign is created. |
