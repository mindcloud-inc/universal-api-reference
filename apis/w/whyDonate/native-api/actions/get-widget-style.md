# Get Widget Style with WhyDonate

## Endpoint

- **Method:** `GET`
- **Path:** `/fundraiser/user/style`
- **Base URL:** `https://fundraiser.whydonate.dev`
- **Official documentation:** [Get Widget Style](https://helpdesk.whydonate.com/en/article/how-to-set-up-the-wordpress-donation-form-plugin-1n3ep8d/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shortcode` | query | `string` | yes | Widget shortcode used to fetch a saved style. |
