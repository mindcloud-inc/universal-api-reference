# Get Payment Status with WhyDonate

## Endpoint

- **Method:** `GET`
- **Path:** `/fundraiser/payment/status/`
- **Base URL:** `https://fundraiser.whydonate.dev`
- **Official documentation:** [Get Payment Status](https://helpdesk.whydonate.com/en/article/how-to-set-up-the-wordpress-donation-form-plugin-1n3ep8d/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | query | `string` | yes | Fundraiser slug used when checking payment status. |
