# Search News Sources with World News API

Finds news sources in World News API by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/search-news-sources`
- **Base URL:** `https://api.worldnewsapi.com`
- **Official documentation:** [Search News Sources](https://worldnewsapi.com/docs/search-news-sources/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Source name query to match monitored news sources. |
