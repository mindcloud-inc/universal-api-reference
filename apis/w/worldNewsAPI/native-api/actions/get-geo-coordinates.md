# Get Geo Coordinates with World News API

Retrieves geo coordinates for a location from World News API.

## Endpoint

- **Method:** `GET`
- **Path:** `/geo-coordinates`
- **Base URL:** `https://api.worldnewsapi.com`
- **Official documentation:** [Get Geo Coordinates](https://worldnewsapi.com/docs/get-geo-coordinates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `location` | query | `string` | yes | Location string to geocode into latitude and longitude. |
