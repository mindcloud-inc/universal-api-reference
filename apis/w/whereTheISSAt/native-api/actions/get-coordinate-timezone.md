# Get Coordinate Timezone with Where the ISS at

## Endpoint

- **Method:** `GET`
- **Path:** `/coordinates/:latitude,:longitude`
- **Base URL:** `https://api.wheretheiss.at/v1`
- **Official documentation:** [Get Coordinate Timezone](https://wheretheiss.at/w/developer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `latitude` | path | `number` | yes | Latitude in decimal degrees. |
| `longitude` | path | `number` | yes | Longitude in decimal degrees. |
