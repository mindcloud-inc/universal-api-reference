# Get App Records Count with Workiom

Retrieves an app's record count from Workiom.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/services/app/Data/GetAppRecordsCount`
- **Base URL:** `https://api.workiom.com`
- **Official documentation:** [Get App Records Count](https://api.workiom.com/swagger/)
