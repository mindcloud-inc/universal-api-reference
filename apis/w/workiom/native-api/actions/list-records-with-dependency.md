# List Records With Dependency with Workiom

Retrieves records with dependency data from Workiom.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/services/app/Data/AllWithDependency`
- **Base URL:** `https://api.workiom.com`
- **Official documentation:** [List Records With Dependency](https://api.workiom.com/swagger/)
