# List Accounts For All Data Sources with Windsor.ai

Retrieves connected accounts across all Windsor.ai data sources.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/common/ds-accounts`
- **Base URL:** `https://onboard.windsor.ai`
- **Official documentation:** [List Accounts For All Data Sources](https://windsor.ai/api-documentation/#tab-content36)
