# List Co-User Linked Accounts with Windsor.ai

Retrieves co-user linked accounts from Windsor.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/team/co-user-linked-accounts/`
- **Base URL:** `https://onboard.windsor.ai`
- **Official documentation:** [List Co-User Linked Accounts](https://windsor.ai/api-documentation/#tab-content30)
