# Generate Authorization Link For Any Data Source with Windsor.ai

Generates a Windsor.ai authorization link for any data source.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/team/generate-co-user-url`
- **Base URL:** `https://onboard.windsor.ai`
- **Official documentation:** [Generate Authorization Link For Any Data Source](https://windsor.ai/api-documentation/#tab-content29)
