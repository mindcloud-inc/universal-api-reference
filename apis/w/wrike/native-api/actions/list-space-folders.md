# List Space Folders with Wrike

Finds folders in a Wrike space.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/folders`
- **Base URL:** `https://{host}/api/v4`
- **Official documentation:** [List Space Folders](https://developers.wrike.com/api/v4/folders-projects/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Wrike space ID. |
