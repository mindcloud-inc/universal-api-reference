# Delete Folder with Wrike

Deletes an existing folder from Wrike.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folders/:folderId`
- **Base URL:** `https://{host}/api/v4`
- **Official documentation:** [Delete Folder](https://developers.wrike.com/api/v4/folders-projects/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Wrike folder ID. |
