# Get Space with Wrike

Retrieves a space from Wrike by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://{host}/api/v4`
- **Official documentation:** [Get Space](https://developers.wrike.com/api/v4/spaces/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Wrike space ID. |
