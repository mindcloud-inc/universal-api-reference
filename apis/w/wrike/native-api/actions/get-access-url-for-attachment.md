# Get Access URL for Attachment with Wrike

Retrieves an access URL for a Wrike attachment.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments/:attachmentId/url`
- **Base URL:** `https://{host}/api/v4`
- **Official documentation:** [Get Access URL for Attachment](https://developers.wrike.com/api/v4/attachments/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attachmentId` | path | `string` | yes | Wrike attachment ID. |
