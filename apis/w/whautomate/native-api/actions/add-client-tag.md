# Add Client Tag with Whautomate

Creates a new client tag in Whautomate.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/clientTags`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Add Client Tag](https://help.whautomate.com/product-guides/whautomate-rest-api/client-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
