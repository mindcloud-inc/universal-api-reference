# Get Client Tag with Whautomate

Retrieves a client tag from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/clientTags/{{clientTagId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Get Client Tag](https://help.whautomate.com/product-guides/whautomate-rest-api/client-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientTagId` | path | `string` | yes |
