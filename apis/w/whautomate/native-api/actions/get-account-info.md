# Get Account Info with Whautomate

Retrieves account information from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/account-info`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Get Account Info](https://help.whautomate.com/product-guides/whautomate-rest-api)
