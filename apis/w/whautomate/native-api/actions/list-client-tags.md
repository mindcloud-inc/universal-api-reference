# List Client Tags with Whautomate

Retrieves client tags from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/clientTags`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [List Client Tags](https://help.whautomate.com/product-guides/whautomate-rest-api/client-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `searchText` | query | `string` | no |
