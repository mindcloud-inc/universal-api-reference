# Delete Client with Whautomate

Deletes an existing client from Whautomate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/clients/{{clientId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Delete Client](https://help.whautomate.com/product-guides/whautomate-rest-api/clients)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
