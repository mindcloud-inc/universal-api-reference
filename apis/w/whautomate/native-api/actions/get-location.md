# Get Location with Whautomate

Retrieves a location from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations/{{locationId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Get Location](https://help.whautomate.com/product-guides/whautomate-rest-api/locations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locationId` | path | `string` | yes |
