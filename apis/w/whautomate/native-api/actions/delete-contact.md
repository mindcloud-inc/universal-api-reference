# Delete Contact with Whautomate

Deletes an existing contact from Whautomate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/{{contactId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Delete Contact](https://help.whautomate.com/product-guides/whautomate-rest-api/contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
