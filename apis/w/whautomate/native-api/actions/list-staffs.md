# List Staffs with Whautomate

Retrieves staff members from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/staffs`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [List Staffs](https://help.whautomate.com/product-guides/whautomate-rest-api/staffs)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locationId` | query | `string` | no |
| `searchText` | query | `string` | no |
