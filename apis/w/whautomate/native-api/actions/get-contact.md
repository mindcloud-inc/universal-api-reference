# Get Contact with Whautomate

Retrieves a contact from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/{{contactId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Get Contact](https://help.whautomate.com/product-guides/whautomate-rest-api/contacts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
