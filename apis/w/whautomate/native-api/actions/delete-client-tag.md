# Delete Client Tag with Whautomate

Deletes an existing client tag from Whautomate.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/clientTags/{{clientTagId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Delete Client Tag](https://help.whautomate.com/product-guides/whautomate-rest-api/client-tags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientTagId` | path | `string` | yes |
