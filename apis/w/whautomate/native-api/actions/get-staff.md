# Get Staff with Whautomate

Retrieves a staff member from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/staffs/{{staffId}}`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [Get Staff](https://help.whautomate.com/product-guides/whautomate-rest-api/staffs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `staffId` | path | `string` | yes |
