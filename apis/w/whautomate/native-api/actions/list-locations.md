# List Locations with Whautomate

Retrieves locations from Whautomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations`
- **Base URL:** `https://api.whautomate.com`
- **Official documentation:** [List Locations](https://help.whautomate.com/product-guides/whautomate-rest-api/locations)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `searchText` | query | `string` | no |
