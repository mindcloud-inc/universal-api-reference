# Get Room with Webex

Retrieves a specific room from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Room](https://developer.webex.com/messaging/docs/api/v1/rooms/get-room-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | yes | Room identifier. |
