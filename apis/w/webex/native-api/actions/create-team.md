# Create Team with Webex

Creates a new team in Webex.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Create Team](https://developer.webex.com/messaging/docs/api/v1/teams/create-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Team name. |
