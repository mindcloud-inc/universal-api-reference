# List Webhooks with Webex

Lists webhooks in your Webex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Webhooks](https://developer.webex.com/messaging/docs/api/v1/webhooks/list-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max` | query | `number` | no | Maximum number of webhooks to return. |
