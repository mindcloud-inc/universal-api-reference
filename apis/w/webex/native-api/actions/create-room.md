# Create Room with Webex

Creates a new room in Webex.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Create Room](https://developer.webex.com/messaging/docs/api/v1/rooms/create-a-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Room title. |
