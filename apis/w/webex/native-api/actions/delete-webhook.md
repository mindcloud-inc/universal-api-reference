# Delete Webhook with Webex

Deletes an existing webhook from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Webhook](https://developer.webex.com/messaging/docs/api/v1/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook identifier. |
