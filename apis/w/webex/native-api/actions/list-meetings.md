# List Meetings with Webex

Lists meetings in your Webex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Meetings](https://developer.webex.com/meeting/docs/api/v1/meetings/list-meetings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max` | query | `number` | no | Maximum number of meetings to return. |
