# Get Meeting with Webex

Retrieves a specific meeting from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Meeting](https://developer.webex.com/meeting/docs/api/v1/meetings/get-a-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | Meeting identifier. |
