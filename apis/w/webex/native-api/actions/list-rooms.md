# List Rooms with Webex

Lists messaging rooms in your Webex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Rooms](https://developer.webex.com/messaging/docs/api/v1/rooms/list-rooms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max` | query | `number` | no | Maximum number of rooms to return. |
