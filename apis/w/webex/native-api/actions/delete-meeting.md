# Delete Meeting with Webex

Deletes an existing meeting from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Meeting](https://developer.webex.com/meeting/docs/api/v1/meetings/delete-a-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | Meeting identifier. |
