# Get Membership with Webex

Retrieves a specific membership from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/memberships/:membershipId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Membership](https://developer.webex.com/messaging/docs/api/v1/memberships/get-membership-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `membershipId` | path | `string` | yes | Membership identifier. |
