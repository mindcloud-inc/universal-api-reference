# List Teams with Webex

Lists teams in your Webex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Teams](https://developer.webex.com/messaging/docs/api/v1/teams/list-teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max` | query | `number` | no | Maximum number of teams to return. |
