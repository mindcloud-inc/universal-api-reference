# Get My Own Details with Webex

Retrieves your own profile details from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/me`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get My Own Details](https://developer.webex.com/admin/docs/api/v1/people/get-my-own-details)
