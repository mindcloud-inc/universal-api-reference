# Delete Team with Webex

Deletes an existing team from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Team](https://developer.webex.com/messaging/docs/api/v1/teams/delete-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team identifier. |
