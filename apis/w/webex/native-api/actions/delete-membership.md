# Delete Membership with Webex

Deletes an existing membership from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/memberships/:membershipId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Membership](https://developer.webex.com/messaging/docs/api/v1/memberships/delete-a-membership)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `membershipId` | path | `string` | yes | Membership identifier. |
