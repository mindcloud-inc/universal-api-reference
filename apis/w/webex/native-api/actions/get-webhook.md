# Get Webhook with Webex

Retrieves a specific webhook from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Webhook](https://developer.webex.com/messaging/docs/api/v1/webhooks/get-webhook-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook identifier. |
