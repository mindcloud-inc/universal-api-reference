# Get Team with Webex

Retrieves a specific team from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Team](https://developer.webex.com/messaging/docs/api/v1/teams/get-team-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Team identifier. |
