# Delete Message with Webex

Deletes an existing message from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/messages/:messageId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Message](https://developer.webex.com/messaging/docs/api/v1/messages/delete-a-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | yes | Message identifier. |
