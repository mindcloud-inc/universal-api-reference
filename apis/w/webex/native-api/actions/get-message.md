# Get Message with Webex

Retrieves a specific message from Webex.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:messageId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Message](https://developer.webex.com/messaging/docs/api/v1/messages/get-message-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `messageId` | path | `string` | yes | Message identifier. |
