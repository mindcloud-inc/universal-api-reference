# Delete Room with Webex

Deletes an existing room from Webex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete Room](https://developer.webex.com/messaging/docs/api/v1/rooms/delete-a-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | yes | Room identifier. |
