# Update Prospects In Campaign with Woodpecker.co

Updates prospects in a Woodpecker campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v1/add_prospects_campaign`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Update Prospects In Campaign](https://developers.woodpecker.co/docs/prospects/POST-update-prospects-campaign/)
