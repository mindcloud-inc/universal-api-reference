# Generate General Statistics Report with Woodpecker.co

Generates a general campaign statistics report in Woodpecker.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/reports/campaigns`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Generate General Statistics Report](https://developers.woodpecker.co/docs/reports/General-statistics/)
