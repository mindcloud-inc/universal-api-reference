# Get Campaign Statistics with Woodpecker.co

Retrieves statistics for a Woodpecker campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v1/campaign_list`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Get Campaign Statistics](https://developers.woodpecker.co/docs/campaigns/GET-campaign-stats-v1/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Campaign ID to fetch statistics for. |
