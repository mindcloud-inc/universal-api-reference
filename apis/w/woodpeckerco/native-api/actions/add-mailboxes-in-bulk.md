# Add Mailboxes In Bulk with Woodpecker.co

Creates one or more mailboxes in Woodpecker.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/mailboxes/manual_connection/bulk`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Add Mailboxes In Bulk](https://developers.woodpecker.co/docs/mailboxes/post-mailboxes/)
