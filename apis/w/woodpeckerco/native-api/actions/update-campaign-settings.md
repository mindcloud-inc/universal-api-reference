# Update Campaign Settings with Woodpecker.co

Updates campaign-wide settings in your Woodpecker account.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/rest/v2/campaigns/[:campaign_id]`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Update Campaign Settings](https://developers.woodpecker.co/docs/campaigns/PATCH-campaign/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | Campaign ID from Woodpecker. |
