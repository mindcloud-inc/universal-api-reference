# Add Campaign Step with Woodpecker.co

Adds a campaign step in Woodpecker.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v2/campaigns/[:campaign_id]/steps`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Add Campaign Step](https://developers.woodpecker.co/docs/campaigns/POST-add-step/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | Campaign ID from Woodpecker. |
