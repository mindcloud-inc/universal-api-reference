# List Mailboxes with Woodpecker.co

Retrieves connected mailboxes from your Woodpecker account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v2/mailboxes`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [List Mailboxes](https://developers.woodpecker.co/docs/mailboxes/get-mailboxes/)
