# Get Manual Tasks with Woodpecker.co

Retrieves manual tasks from your Woodpecker account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v2/manual_tasks`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Get Manual Tasks](https://developers.woodpecker.co/docs/manual-tasks/get-manual-tasks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of manual tasks to return. |
