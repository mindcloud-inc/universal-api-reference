# Get Mailbox with Woodpecker.co

Retrieves a mailbox from your Woodpecker account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v2/mailboxes/[:id]`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Get Mailbox](https://developers.woodpecker.co/docs/mailboxes/get-mailbox/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Mailbox ID from Woodpecker. |
