# Get Campaign with Woodpecker.co

Retrieves a single campaign from Woodpecker.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/v2/campaigns/[:campaign_id]`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Get Campaign](https://developers.woodpecker.co/docs/campaigns/GET-campaign/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | Campaign ID from Woodpecker. |
