# Update Prospects In Database with Woodpecker.co

Updates prospects in the Woodpecker database.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v1/add_prospects_list`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Update Prospects In Database](https://developers.woodpecker.co/docs/prospects/POST-update-prospect-list/)
