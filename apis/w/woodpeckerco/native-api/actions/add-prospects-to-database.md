# Add Prospects To Database with Woodpecker.co

Creates prospects in the Woodpecker database.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v1/add_prospects_list`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Add Prospects To Database](https://developers.woodpecker.co/docs/prospects/POST-add-prospects-list/)
