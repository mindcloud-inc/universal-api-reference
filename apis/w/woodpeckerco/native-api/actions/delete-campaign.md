# Delete Campaign with Woodpecker.co

Deletes an existing campaign from Woodpecker.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rest/v2/campaigns/[:campaign_id]`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Delete Campaign](https://developers.woodpecker.co/docs/campaigns/DELETE-campaign/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | Campaign ID from Woodpecker. |
