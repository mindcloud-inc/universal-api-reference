# Add Prospects To Campaign with Woodpecker.co

Adds prospects to a Woodpecker campaign.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/v1/add_prospects_campaign`
- **Base URL:** `https://api.woodpecker.co`
- **Official documentation:** [Add Prospects To Campaign](https://developers.woodpecker.co/docs/prospects/POST-add-prospects-campaign/)
