# Retrieve URL Categorization with WebCategorize

## Endpoint

- **Method:** `GET`
- **Path:** `/url/{urlId}`
- **Base URL:** `https://app.webcategorize.com/api`
- **Official documentation:** [Retrieve URL Categorization](https://webcategorize.com/webcategorize.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlId` | path | `string` | yes | The ID of the URL submission. |
