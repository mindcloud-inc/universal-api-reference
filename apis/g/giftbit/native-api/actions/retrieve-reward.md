# Retrieve Reward with Giftbit

Retrieves a reward by UUID from Giftbit.

## Endpoint

- **Method:** `GET`
- **Path:** `/gifts/:uuid`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Retrieve Reward](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
