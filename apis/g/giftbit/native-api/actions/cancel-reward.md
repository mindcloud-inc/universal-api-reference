# Cancel Reward with Giftbit

Cancels an unclaimed reward in Giftbit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/gifts/:uuid`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Cancel Reward](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
