# Retrieve Order by ID with Giftbit

Retrieves a Giftbit order by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:id`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Retrieve Order by ID](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
