# Resend Reward with Giftbit

Resends a reward to its recipient in Giftbit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/gifts/:uuid`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Resend Reward](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `uuid` | path | `string` | yes |
