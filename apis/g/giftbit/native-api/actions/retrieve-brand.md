# Retrieve Brand with Giftbit

Retrieves a reward brand from Giftbit.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/:brand_code`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Retrieve Brand](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `brand_code` | path | `string` | yes |
