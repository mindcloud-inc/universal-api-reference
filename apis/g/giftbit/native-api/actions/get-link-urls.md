# Get Link URLs with Giftbit

Retrieves generated reward links for a Giftbit order.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://api-testbed.giftbit.com/papi/v1`
- **Official documentation:** [Get Link URLs](https://www.giftbit.com/api-documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
