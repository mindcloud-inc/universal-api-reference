# List Authenticated User Organizations with GitHub

Lists GitHub organizations for the authenticated user.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/orgs`
- **Base URL:** `https://api.github.com`
- **Official documentation:** [List Authenticated User Organizations](https://docs.github.com/en/rest/orgs/orgs?apiVersion=2022-11-28#list-organizations-for-the-authenticated-user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
