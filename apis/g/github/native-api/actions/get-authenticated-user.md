# Get Authenticated User with GitHub

Retrieves the authenticated user from GitHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://api.github.com`
- **Official documentation:** [Get Authenticated User](https://docs.github.com/en/rest/users/users#get-the-authenticated-user)

## Capabilities

This operation supports [pagination](../README.md#pagination).
