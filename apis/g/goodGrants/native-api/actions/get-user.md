# Get user with Good Grants

Retrieves a user from Good Grants by slug or email.

## Endpoint

- **Method:** `GET`
- **Path:** `user/:identifier`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Get user](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | User slug or email. |
