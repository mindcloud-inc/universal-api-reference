# Delete application with Good Grants

Deletes an existing application from Good Grants.

## Endpoint

- **Method:** `DELETE`
- **Path:** `application/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Delete application](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Slug of the application to delete. |
