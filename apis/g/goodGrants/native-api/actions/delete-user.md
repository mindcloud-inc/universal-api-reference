# Delete user with Good Grants

Deletes an existing user from Good Grants.

## Endpoint

- **Method:** `DELETE`
- **Path:** `user/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Delete user](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Slug of the user to delete. |
