# Get form with Good Grants

Retrieves a form from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `form/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Get form](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Form slug. |
