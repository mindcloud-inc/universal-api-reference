# Get application with Good Grants

Retrieves an application from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `application/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Get application](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Application slug. |
