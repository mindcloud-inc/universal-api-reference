# List categories with Good Grants

Retrieves categories from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `category`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [List categories](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `per_page` | query | `number` | no | Number of records to return per page. |
