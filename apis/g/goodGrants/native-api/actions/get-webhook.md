# Get webhook with Good Grants

Retrieves a webhook from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `webhook/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Get webhook](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Webhook slug. |
