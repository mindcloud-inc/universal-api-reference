# List chapters with Good Grants

Retrieves chapters from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `chapter`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [List chapters](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `per_page` | query | `number` | no | Number of records to return per page. |
