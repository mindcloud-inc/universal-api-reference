# List users with Good Grants

Retrieves users from Good Grants.

## Endpoint

- **Method:** `GET`
- **Path:** `user`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [List users](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number greater than 0. |
| `per_page` | query | `number` | no | Results per page, between 1 and 100. |
