# Delete webhook with Good Grants

Deletes an existing webhook from Good Grants.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhook/:slug`
- **Base URL:** `https://api.cr4ce.com`
- **Official documentation:** [Delete webhook](https://apidocs.goodgrants.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Slug of the webhook to delete. |
