# Remove User with Gridfox

Removes a user from a Gridfox project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.gridfox.com/`
- **Official documentation:** [Remove User](https://api.gridfox.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | Numeric Gridfox user ID from the path parameter. |
