# Search Records with Gridfox

Finds records in a Gridfox table.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/:tableName`
- **Base URL:** `https://api.gridfox.com/`
- **Official documentation:** [Search Records](https://api.gridfox.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableName` | path | `string` | yes | Gridfox table name from the path parameter. |
