# Create Record with Gridfox

Creates a new record in a Gridfox table.

## Endpoint

- **Method:** `POST`
- **Path:** `/data/:tableName`
- **Base URL:** `https://api.gridfox.com/`
- **Official documentation:** [Create Record](https://api.gridfox.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableName` | path | `string` | no | Gridfox table name from the path parameter. |
