# Enable Product with Gumroad

Enables a product in Gumroad.

## Endpoint

- **Method:** `PUT`
- **Path:** `/products/:id/enable`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Enable Product](https://gumroad.com/api#put-/products/:id/enable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID. |
