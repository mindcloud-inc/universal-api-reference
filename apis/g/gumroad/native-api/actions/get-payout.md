# Get Payout with Gumroad

Retrieves a payout from Gumroad.

## Endpoint

- **Method:** `GET`
- **Path:** `/payouts/:id`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Get Payout](https://gumroad.com/api#get-/payouts/:id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The payout ID. |
