# Disable Product with Gumroad

Disables a product in Gumroad.

## Endpoint

- **Method:** `PUT`
- **Path:** `/products/:id/disable`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Disable Product](https://gumroad.com/api#put-/products/:id/disable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID. |
