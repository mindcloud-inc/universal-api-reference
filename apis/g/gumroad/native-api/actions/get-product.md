# Get Product with Gumroad

Retrieves a product from Gumroad.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Get Product](https://gumroad.com/api#get-/products/:id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The product ID. |
