# Get Sale with Gumroad

Retrieves a sale from Gumroad.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales/:id`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Get Sale](https://gumroad.com/api#get-/sales/:id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The sale ID. |
