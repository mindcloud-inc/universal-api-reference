# Get Subscriber with Gumroad

Retrieves a subscriber from Gumroad.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:id`
- **Base URL:** `https://api.gumroad.com/v2`
- **Official documentation:** [Get Subscriber](https://gumroad.com/api#get-/subscribers/:id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The subscriber ID. |
