# Get SMS Prices with GatewayAPI SMS

Retrieves GatewayAPI SMS prices by country and prefix.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/prices/list/sms/:fileformat`
- **Base URL:** `https://gatewayapi.com`
- **Official documentation:** [Get SMS Prices](https://gatewayapi.com/docs/apis/prices-balance/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileformat` | path | `string` | yes | Output format for the SMS price list. |
