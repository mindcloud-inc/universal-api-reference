# Get Vacation Settings with Google Mail

Retrieves vacation responder settings from Gmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/vacation`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [Get Vacation Settings](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.settings/getVacation)
