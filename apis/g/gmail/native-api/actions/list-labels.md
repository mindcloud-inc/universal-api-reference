# List Labels with Google Mail

Retrieves labels from a Gmail mailbox.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [List Labels](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.labels/list)
