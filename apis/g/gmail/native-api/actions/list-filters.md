# List Filters with Google Mail

Retrieves filters from Gmail settings.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/filters`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [List Filters](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.settings.filters/list)
