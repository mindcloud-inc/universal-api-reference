# Get Label with Google Mail

Retrieves a Gmail label.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [Get Label](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.labels/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | hidden... |
