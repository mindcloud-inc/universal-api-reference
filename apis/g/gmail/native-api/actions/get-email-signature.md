# Get Email Signature with Google Mail

Retrieves a Gmail signature.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/sendAs`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [Get Email Signature](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.messages.attachments/get)
