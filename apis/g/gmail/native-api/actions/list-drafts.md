# List Drafts with Google Mail

Retrieves drafts from a Gmail mailbox.

## Endpoint

- **Method:** `GET`
- **Path:** `/drafts`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [List Drafts](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.drafts/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
