# Send Draft with Google Mail

Sends a Gmail draft.

## Endpoint

- **Method:** `POST`
- **Path:** `/drafts/send`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [Send Draft](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users.drafts/send)
