# Stop Mailbox Watch with Google Mail

Stops Gmail mailbox push notifications.

## Endpoint

- **Method:** `POST`
- **Path:** `/stop`
- **Base URL:** `https://gmail.googleapis.com/gmail/v1/users/:userId`
- **Official documentation:** [Stop Mailbox Watch](https://developers.google.com/workspace/gmail/api/reference/rest/v1/users/stop)
