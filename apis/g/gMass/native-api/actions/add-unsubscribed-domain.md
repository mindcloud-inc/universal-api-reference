# Add Unsubscribed Domain with GMass

Unsubscribes a domain from your GMass account.

## Endpoint

- **Method:** `POST`
- **Path:** `/unsubscribes/domain/:domain`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [Add Unsubscribed Domain](https://api.gmass.co/docs#tag/Unsubscribes/operation/Unsubscribes_AddUnsubscribeDomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to add to the account unsubscribe domain list. |
