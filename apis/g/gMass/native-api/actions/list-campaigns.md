# List Campaigns with GMass

Retrieves GMass campaigns and their aggregate statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Campaigns](https://api.gmass.co/docs#tag/Campaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination).
