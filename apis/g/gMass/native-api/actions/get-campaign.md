# Get Campaign with GMass

Retrieves a GMass campaign and its aggregate statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [Get Campaign](https://api.gmass.co/docs#tag/Campaigns/operation/Campaigns_GetCampaign)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `number` | yes |
