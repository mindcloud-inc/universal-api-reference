# List Sample Replies with GMass

Retrieves sample replies from your GMass account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sample/replies`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Sample Replies](https://api.gmass.co/docs#tag/Sample/operation/Sample_GetSampleReplies)
