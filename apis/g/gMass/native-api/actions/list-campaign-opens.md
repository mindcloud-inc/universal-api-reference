# List Campaign Opens with GMass

Retrieves recipients who opened a GMass campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/:campaignId/opens`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Campaign Opens](https://api.gmass.co/docs#tag/Reports/operation/Reports_Opens)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `number` | yes |
