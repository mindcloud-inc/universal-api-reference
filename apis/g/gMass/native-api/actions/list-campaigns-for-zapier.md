# List Campaigns For Zapier with GMass

Retrieves GMass campaigns available for Zapier.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/zapier`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Campaigns For Zapier](https://api.gmass.co/docs#tag/Campaigns/operation/Campaigns_Zapier)
