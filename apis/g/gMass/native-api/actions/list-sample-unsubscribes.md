# List Sample Unsubscribes with GMass

Retrieves sample unsubscribes from your GMass account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sample/unsubscribes`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Sample Unsubscribes](https://api.gmass.co/docs#tag/Sample/operation/Sample_GetSampleUnsubscribes)
