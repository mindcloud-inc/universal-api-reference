# List Unsubscribed Domains with GMass

Retrieves unsubscribed domains from your GMass account.

## Endpoint

- **Method:** `GET`
- **Path:** `/unsubscribes/domains`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Unsubscribed Domains](https://api.gmass.co/docs#tag/Unsubscribes/operation/Unsubscribes_Index)
