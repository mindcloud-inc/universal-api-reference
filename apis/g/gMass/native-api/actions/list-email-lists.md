# List Email Lists with GMass

Retrieves email lists from your GMass account.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Email Lists](https://api.gmass.co/docs#tag/Lists/operation/Lists_Lists)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | query | `string` | no |
| `q` | query | `string` | no |
