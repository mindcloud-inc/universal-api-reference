# List Sample Bounces with GMass

Retrieves sample bounces from your GMass account.

## Endpoint

- **Method:** `GET`
- **Path:** `/sample/bounces`
- **Base URL:** `https://api.gmass.co/api`
- **Official documentation:** [List Sample Bounces](https://api.gmass.co/docs#tag/Sample/operation/Sample_GetSampleBounces)
