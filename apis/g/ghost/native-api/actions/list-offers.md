# List Offers with Ghost

Retrieves offers from Ghost.

## Endpoint

- **Method:** `GET`
- **Path:** `/offers/`
- **Base URL:** `{adminDomain}/ghost/api/admin`
- **Official documentation:** [List Offers](https://docs.ghost.org/admin-api/offers/overview)

## Capabilities

This operation supports [pagination](../README.md#pagination).
