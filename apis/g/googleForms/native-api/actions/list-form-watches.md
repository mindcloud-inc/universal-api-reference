# List Form Watches with Google Forms

Retrieves form watches from Google Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/:formId/watches`
- **Base URL:** `https://forms.googleapis.com/v1/forms`
- **Official documentation:** [List Form Watches](https://developers.google.com/workspace/forms/api/reference/rest/v1/forms.watches/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The form identifier. |
