# Get Form with Google Forms

Retrieves a form from Google Forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/:formId`
- **Base URL:** `https://forms.googleapis.com/v1/forms`
- **Official documentation:** [Get Form](https://developers.google.com/workspace/forms/api/reference/rest/v1/forms/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The form identifier. |
