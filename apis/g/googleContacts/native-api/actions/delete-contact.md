# Delete Contact with Google Contacts

Deletes an existing contact from Google Contacts.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/people/:resourceName:contactAction`
- **Base URL:** `https://people.googleapis.com`
- **Official documentation:** [Delete Contact](https://developers.google.com/people/api/rest/v1/people/deleteContact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `resourceName` | path | `string` | yes |
