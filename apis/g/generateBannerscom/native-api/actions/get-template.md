# Get Template with GenerateBanners.com

Retrieves metadata for one GenerateBanners.com template.

## Endpoint

- **Method:** `GET`
- **Path:** `/{publicApiKey}/template/:id`
- **Base URL:** `https://api.generatebanners.com/api/v1`
- **Official documentation:** [Get Template](https://www.generatebanners.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the template to fetch. |
