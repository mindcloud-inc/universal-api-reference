# List Templates with GenerateBanners.com

Retrieves metadata for all GenerateBanners.com templates.

## Endpoint

- **Method:** `GET`
- **Path:** `/{publicApiKey}/template`
- **Base URL:** `https://api.generatebanners.com/api/v1`
- **Official documentation:** [List Templates](https://www.generatebanners.com/documentation/api)
