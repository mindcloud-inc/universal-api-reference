# Get Chatbot with GPT Chatbot

Retrieves a chatbot from GPT Chatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [Get Chatbot](https://docs.gptchatbot.it/api-reference/chatbots/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid. |
