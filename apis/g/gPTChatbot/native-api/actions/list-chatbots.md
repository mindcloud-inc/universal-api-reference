# List Chatbots with GPT Chatbot

Retrieves the current user's chatbots from GPT Chatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbots`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [List Chatbots](https://docs.gptchatbot.it/api-reference/chatbots/fetch_multi)
