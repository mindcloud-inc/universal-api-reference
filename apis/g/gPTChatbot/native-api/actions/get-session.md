# Get Session with GPT Chatbot

Retrieves a session from GPT Chatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/session/:uuid`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [Get Session](https://docs.gptchatbot.it/api-reference/sessions/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Session uuid. |
