# Delete Chatbot with GPT Chatbot

Deletes an existing chatbot from GPT Chatbot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/chatbot/:uuid/delete`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [Delete Chatbot](https://docs.gptchatbot.it/api-reference/chatbots/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid. |
