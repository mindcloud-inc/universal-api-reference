# List Sources with GPT Chatbot

Retrieves sources for a chatbot in GPT Chatbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid/data-sources`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [List Sources](https://docs.gptchatbot.it/api-reference/data-sources/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Chatbot uuid. |
