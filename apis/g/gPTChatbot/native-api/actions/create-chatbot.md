# Create Chatbot with GPT Chatbot

Creates a chatbot in GPT Chatbot.

## Endpoint

- **Method:** `POST`
- **Path:** `/chatbot/create`
- **Base URL:** `https://app.gptchatbot.it/api/v1`
- **Official documentation:** [Create Chatbot](https://docs.gptchatbot.it/api-reference/chatbots/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Chatbot name. |
