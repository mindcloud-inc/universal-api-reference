# List Locations with Google Cloud Document AI

Finds locations in Google Cloud Document AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectsId/locations`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [List Locations](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
