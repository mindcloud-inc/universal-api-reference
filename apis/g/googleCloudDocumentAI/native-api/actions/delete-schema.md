# Delete Schema with Google Cloud Document AI

Deletes a schema from Google Cloud Document AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/schemas/:schemasId`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [Delete Schema](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.schemas/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemasId` | path | `string` | no | Document schema ID. |
