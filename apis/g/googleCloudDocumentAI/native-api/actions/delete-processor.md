# Delete Processor with Google Cloud Document AI

Deletes a processor from Google Cloud Document AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/processors/:processorsId`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [Delete Processor](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.processors/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processorsId` | path | `string` | no | Document AI processor ID. |
