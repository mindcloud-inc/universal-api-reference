# Disable Processor with Google Cloud Document AI

Disables a processor in Google Cloud Document AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/processors/:processorsId:disable`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [Disable Processor](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.processors/disable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processorsId` | path | `string` | no | Document AI processor ID. |
