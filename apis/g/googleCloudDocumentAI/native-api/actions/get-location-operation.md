# Get Location Operation with Google Cloud Document AI

Retrieves an operation from a Google Cloud Document AI location.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/operations/:operationsId`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [Get Location Operation](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.operations/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `operationsId` | path | `string` | no | Long-running operation ID. |
