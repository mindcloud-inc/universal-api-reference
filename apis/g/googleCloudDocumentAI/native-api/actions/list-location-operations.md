# List Location Operations with Google Cloud Document AI

Finds operations in a Google Cloud Document AI location.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/operations`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [List Location Operations](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.operations/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
