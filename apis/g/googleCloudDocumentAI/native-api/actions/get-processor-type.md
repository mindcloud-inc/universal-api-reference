# Get Processor Type with Google Cloud Document AI

Retrieves a processor type from Google Cloud Document AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:projectsId/locations/:locationsId/processorTypes/:processorTypesId`
- **Base URL:** `https://documentai.googleapis.com`
- **Official documentation:** [Get Processor Type](https://cloud.google.com/document-ai/docs/reference/rest/v1/projects.locations.processorTypes/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processorTypesId` | path | `string` | no | Processor type ID. |
