# Delete Domain with Geral

Deletes a custom domain from Geral.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domains/:domain_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Delete Domain](https://ger.al/api-documentation/domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `number` | yes | The domain ID to delete. |
