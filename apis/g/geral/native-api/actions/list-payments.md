# List Payments with Geral

Retrieves account payments from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Payments](https://ger.al/api-documentation/payments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
