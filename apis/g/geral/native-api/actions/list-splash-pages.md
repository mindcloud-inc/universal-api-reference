# List Splash Pages with Geral

Retrieves splash pages from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/splash-pages/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Splash Pages](https://ger.al/api-documentation/splash-pages)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
