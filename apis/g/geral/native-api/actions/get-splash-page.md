# Get Splash Page with Geral

Retrieves a splash page from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/splash-pages/:splash_page_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Splash Page](https://ger.al/api-documentation/splash-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `splash_page_id` | path | `number` | yes | The splash page ID to retrieve. |
