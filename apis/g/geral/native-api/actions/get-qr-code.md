# Get QR Code with Geral

Retrieves a QR code from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr-codes/:qr_code_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get QR Code](https://ger.al/api-documentation/qr-codes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qr_code_id` | path | `number` | yes | The QR code ID to retrieve. |
