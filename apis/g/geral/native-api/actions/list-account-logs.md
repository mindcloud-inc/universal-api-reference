# List Account Logs with Geral

Retrieves account logs from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/logs/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Account Logs](https://ger.al/api-documentation/users-logs)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
