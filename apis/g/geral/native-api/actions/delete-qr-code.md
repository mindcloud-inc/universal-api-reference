# Delete QR Code with Geral

Deletes a QR code from Geral.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qr-codes/:qr_code_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Delete QR Code](https://ger.al/api-documentation/qr-codes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qr_code_id` | path | `number` | yes | The QR code ID to delete. |
