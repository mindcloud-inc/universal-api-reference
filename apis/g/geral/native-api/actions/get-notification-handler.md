# Get Notification Handler with Geral

Retrieves a notification handler from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/notification-handlers/:notification_handler_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Notification Handler](https://ger.al/api-documentation/notification-handlers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification_handler_id` | path | `number` | yes | The notification handler ID to retrieve. |
