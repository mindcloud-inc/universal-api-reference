# Delete Link with Geral

Deletes a link from Geral.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:link_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Delete Link](https://ger.al/api-documentation/links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link_id` | path | `number` | yes | The link ID to delete. |
