# Get Payment with Geral

Retrieves an account payment from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/:payment_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Payment](https://ger.al/api-documentation/payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payment_id` | path | `number` | yes | The payment ID to retrieve. |
