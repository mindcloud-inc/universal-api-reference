# Get Link with Geral

Retrieves a link from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:link_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Link](https://ger.al/api-documentation/links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link_id` | path | `number` | yes | The link ID to retrieve. |
