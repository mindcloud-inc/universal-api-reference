# List Links with Geral

Retrieves links from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Links](https://ger.al/api-documentation/links)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
