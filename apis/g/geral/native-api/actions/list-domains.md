# List Domains with Geral

Retrieves custom domains from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Domains](https://ger.al/api-documentation/domains)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
