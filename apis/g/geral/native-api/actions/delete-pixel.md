# Delete Pixel with Geral

Deletes a pixel from Geral.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pixels/:pixel_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Delete Pixel](https://ger.al/api-documentation/pixels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pixel_id` | path | `number` | yes | The pixel ID to delete. |
