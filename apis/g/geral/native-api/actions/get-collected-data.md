# Get Collected Data with Geral

Retrieves collected data from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/:datum_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Collected Data](https://ger.al/api-documentation/data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datum_id` | path | `number` | yes | The collected data record ID to retrieve. |
