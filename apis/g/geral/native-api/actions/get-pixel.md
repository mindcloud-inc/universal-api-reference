# Get Pixel with Geral

Retrieves a pixel from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixels/:pixel_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Pixel](https://ger.al/api-documentation/pixels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pixel_id` | path | `number` | yes | The pixel ID to retrieve. |
