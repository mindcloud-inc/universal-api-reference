# List Pixels with Geral

Retrieves pixels from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixels/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Pixels](https://ger.al/api-documentation/pixels)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
