# List Collected Data with Geral

Retrieves collected data from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Collected Data](https://ger.al/api-documentation/data)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
