# Get Domain with Geral

Retrieves a custom domain from Geral by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain_id`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [Get Domain](https://ger.al/api-documentation/domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `number` | yes | The domain ID to retrieve. |
