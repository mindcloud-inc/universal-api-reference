# List Notification Handlers with Geral

Retrieves notification handlers from Geral.

## Endpoint

- **Method:** `GET`
- **Path:** `/notification-handlers/`
- **Base URL:** `https://ger.al/api`
- **Official documentation:** [List Notification Handlers](https://ger.al/api-documentation/notification-handlers)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
