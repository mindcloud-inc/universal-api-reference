# List Donations with GiveForms

Finds donations for your organization in GiveForms.

## Endpoint

- **Method:** `GET`
- **Path:** `/donations`
- **Base URL:** `https://app.giveforms.com/api/v1`
- **Official documentation:** [List Donations](https://www.giveforms.com/support-article/rest-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
