# Delete Model with Groq

Deletes a model from Groq.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/openai/v1/models/:model`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Delete Model](https://console.groq.com/docs/api-reference#models)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `model` | path | `string` | yes |
