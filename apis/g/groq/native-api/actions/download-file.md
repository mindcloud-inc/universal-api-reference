# Download File with Groq

Downloads a file from Groq.

## Endpoint

- **Method:** `GET`
- **Path:** `/openai/v1/files/:file_id/content`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Download File](https://console.groq.com/docs/api-reference#files-download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
