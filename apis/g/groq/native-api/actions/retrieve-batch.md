# Retrieve Batch with Groq

Retrieves a batch from Groq.

## Endpoint

- **Method:** `GET`
- **Path:** `/openai/v1/batches/:batch_id`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Retrieve Batch](https://console.groq.com/docs/api-reference#batches-retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `batch_id` | path | `string` | yes |
