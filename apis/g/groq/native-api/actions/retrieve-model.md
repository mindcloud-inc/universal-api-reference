# Retrieve Model with Groq

Retrieves a model from Groq.

## Endpoint

- **Method:** `GET`
- **Path:** `/openai/v1/models/:model`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Retrieve Model](https://console.groq.com/docs/api-reference#models-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | path | `string` | yes | The Groq model identifier to retrieve. |
