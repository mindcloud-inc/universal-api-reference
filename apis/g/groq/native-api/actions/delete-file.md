# Delete File with Groq

Deletes a file from Groq.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/openai/v1/files/:file_id`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Delete File](https://console.groq.com/docs/api-reference#files-delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
