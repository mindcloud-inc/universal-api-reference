# Retrieve File with Groq

Retrieves a file from Groq.

## Endpoint

- **Method:** `GET`
- **Path:** `/openai/v1/files/:file_id`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Retrieve File](https://console.groq.com/docs/api-reference#files-retrieve)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
