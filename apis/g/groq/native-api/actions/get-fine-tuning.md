# Get Fine Tuning with Groq

Retrieves a fine-tuning job from Groq.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/fine_tunings/:id`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Get Fine Tuning](https://console.groq.com/docs/api-reference#fine-tuning-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
