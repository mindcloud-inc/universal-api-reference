# Delete Fine Tuning with Groq

Deletes a fine-tuning job from Groq.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/fine_tunings/:id`
- **Base URL:** `https://api.groq.com`
- **Official documentation:** [Delete Fine Tuning](https://console.groq.com/docs/api-reference#fine-tuning-delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
