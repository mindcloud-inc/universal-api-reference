# Get Presentation with Google Slides

Retrieves a presentation from Google Slides.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/presentations/:presentationId`
- **Base URL:** `https://slides.googleapis.com`
- **API:** rest
- **Official documentation:** [Get Presentation](https://developers.google.com/workspace/slides/api/reference/rest/v1/presentations/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `presentationId` | path | `list<string>` | yes | The ID of the presentation to retrieve. |
