# Get Current User with Google Slides

Retrieves the profile of the Google account that authorized the connection.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/userinfo`
- **Base URL:** `https://openidconnect.googleapis.com`
- **API:** Google OpenID Connect
- **Official documentation:** [Get Current User](https://developers.google.com/identity/openid-connect/openid-connect)
