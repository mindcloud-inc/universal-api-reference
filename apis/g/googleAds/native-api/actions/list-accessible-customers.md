# List Accessible Customers with Google Ads

## Endpoint

- **Method:** `GET`
- **Path:** `v23/customers:listAccessibleCustomers`
- **Base URL:** `https://googleads.googleapis.com/`
- **API:** REST
- **Official documentation:** [List Accessible Customers](https://developers.google.com/google-ads/api/docs/account-management/listing-accounts)
