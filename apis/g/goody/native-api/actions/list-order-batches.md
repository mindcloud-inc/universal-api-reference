# List Order Batches with Goody

Retrieves order batches from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/order_batches`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [List Order Batches](https://developer.ongoody.com/api-reference/order-batches/list-all-order-batches)

## Capabilities

This operation supports [pagination](../README.md#pagination).
