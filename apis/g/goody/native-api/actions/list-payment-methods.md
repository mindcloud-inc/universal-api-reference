# List Payment Methods with Goody

Retrieves payment methods from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payment_methods`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [List Payment Methods](https://developer.ongoody.com/api-reference/payment-methods/list-all-payment-methods)
