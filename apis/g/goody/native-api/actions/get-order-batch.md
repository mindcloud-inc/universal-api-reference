# Get Order Batch with Goody

Retrieves an order batch from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/order_batches/:id`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [Get Order Batch](https://developer.ongoody.com/api-reference/order-batches/retrieve-an-order-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order batch ID |
