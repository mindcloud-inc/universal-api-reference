# Get Order with Goody

Retrieves an order from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/:id`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [Get Order](https://developer.ongoody.com/api-reference/orders/retrieve-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
