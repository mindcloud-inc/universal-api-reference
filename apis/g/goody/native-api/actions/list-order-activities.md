# List Order Activities with Goody

Retrieves order activities from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/order_activities`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [List Order Activities](https://developer.ongoody.com/api-reference/order-activities/list-all-order-activities)
