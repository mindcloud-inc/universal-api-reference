# List Orders with Goody

Retrieves orders from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [List Orders](https://developer.ongoody.com/api-reference/orders/list-all-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
