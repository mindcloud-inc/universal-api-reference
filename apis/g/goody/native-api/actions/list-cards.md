# List Cards with Goody

Retrieves active cards from Goody.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cards`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [List Cards](https://developer.ongoody.com/api-reference/cards/list-all-active-cards)

## Capabilities

This operation supports [pagination](../README.md#pagination).
