# Cancel Order with Goody

Cancels an order in Goody.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/orders/:id/cancel`
- **Base URL:** `https://api.ongoody.com`
- **Official documentation:** [Cancel Order](https://developer.ongoody.com/api-reference/orders/cancel-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id |
