# Validate Phone Number (GET) with GenderAPI.io

Retrieves phone validation details from GenderAPI.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/phone`
- **Base URL:** `https://api.genderapi.io`
- **Official documentation:** [Validate Phone Number (GET)](https://www.genderapi.io/docs-phone-validation-formatter-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `number` | query | `string` | yes |
| `address` | query | `string` | no |
