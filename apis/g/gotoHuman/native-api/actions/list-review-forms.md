# List Review Forms with gotoHuman

Retrieves review templates from gotoHuman.

## Endpoint

- **Method:** `GET`
- **Path:** `/fetchReviewForms`
- **Base URL:** `https://api.gotohuman.com`
- **Official documentation:** [List Review Forms](https://github.com/gotohuman/gotohuman-mcp-server/blob/main/README.md)
