# Get Related Tag Terms with Giphy

Retrieves related tag terms from Giphy by term.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tags/related/:term`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Get Related Tag Terms](https://developers.giphy.com/docs/api/endpoint/#search-suggestions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `term` | path | `string` | yes |
