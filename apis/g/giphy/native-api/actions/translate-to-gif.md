# Translate to GIF with Giphy

Translates a phrase into a GIF in Giphy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/gifs/translate`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Translate to GIF](https://developers.giphy.com/docs/api/endpoint/#translate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rating` | query | `string` | no |
| `s` | query | `string` | yes |
