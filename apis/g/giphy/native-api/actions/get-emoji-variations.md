# Get Emoji Variations with Giphy

Retrieves emoji variations from Giphy by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/emoji/:emojiId/variations`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Get Emoji Variations](https://developers.giphy.com/docs/api/endpoint/#emoji-variations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `emojiId` | path | `string` | yes |
