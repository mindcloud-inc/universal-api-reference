# Get Content by IDs with Giphy

Retrieves GIF, sticker, or clip content from Giphy by IDs.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/content`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Get Content by IDs](https://developers.giphy.com/docs/clips/endpoint/#get-by-ids)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | query | `string` | yes |
