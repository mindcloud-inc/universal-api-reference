# Get Random Sticker with Giphy

Retrieves a random sticker from Giphy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stickers/random`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Get Random Sticker](https://developers.giphy.com/docs/api/endpoint/#random)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rating` | query | `string` | no |
| `tag` | query | `string` | no |
