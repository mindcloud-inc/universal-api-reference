# Get Content by ID with Giphy

Retrieves GIF, sticker, or clip content from Giphy by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/content/:id`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Get Content by ID](https://developers.giphy.com/docs/clips/endpoint/#get-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
