# List Emoji with Giphy

Retrieves emoji from Giphy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/emoji`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [List Emoji](https://developers.giphy.com/docs/api/endpoint/#emoji)

## Capabilities

This operation supports [pagination](../README.md#pagination).
