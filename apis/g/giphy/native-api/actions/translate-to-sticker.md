# Translate to Sticker with Giphy

Translates a phrase into a sticker in Giphy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stickers/translate`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [Translate to Sticker](https://developers.giphy.com/docs/api/endpoint/#translate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rating` | query | `string` | no |
| `s` | query | `string` | yes |
