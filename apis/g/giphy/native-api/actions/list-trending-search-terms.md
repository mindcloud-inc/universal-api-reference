# List Trending Search Terms with Giphy

Retrieves trending search terms from Giphy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/trending/searches`
- **Base URL:** `https://api.giphy.com/`
- **Official documentation:** [List Trending Search Terms](https://developers.giphy.com/docs/api/endpoint/#trending-search-terms)
