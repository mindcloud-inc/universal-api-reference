# Delete Customer with GatherUp

Deletes an existing customer from GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/customer/delete`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [Delete Customer](https://app.gatherup.com/api/doc/customer/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | body | `number` | yes | Customer id. |
