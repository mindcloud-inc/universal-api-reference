# Deactivate User with GatherUp

Deactivates an existing user in GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/deactivate`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [Deactivate User](https://app.gatherup.com/api/doc/user/deactivate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | body | `number` | yes | The user id. |
