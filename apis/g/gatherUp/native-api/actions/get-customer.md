# Get Customer with GatherUp

Retrieves detailed customer information from GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/customer/get`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [Get Customer](https://app.gatherup.com/api/doc/customer/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | body | `number` | yes | Customer id. |
