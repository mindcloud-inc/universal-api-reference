# Reactivate User with GatherUp

Reactivates an existing user in GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/reactivate`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [Reactivate User](https://app.gatherup.com/api/doc/user/reactivate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | body | `number` | yes | The user id. |
