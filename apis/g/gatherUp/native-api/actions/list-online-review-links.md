# List Online Review Links with GatherUp

Retrieves online review links from GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/business/online-review-links/get`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [List Online Review Links](https://app.gatherup.com/api/doc/business/online-review-links/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `businessId` | body | `number` | yes | Business id. |
