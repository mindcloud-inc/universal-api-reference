# List Business Types with GatherUp

Retrieves a list of business types from GatherUp.

## Endpoint

- **Method:** `POST`
- **Path:** `/business/types`
- **Base URL:** `https://app.gatherup.com/api`
- **Official documentation:** [List Business Types](https://app.gatherup.com/api/doc/business/types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | body | `string` | no | Search value |
