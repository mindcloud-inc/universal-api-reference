# Get Scan Device with GSA Site Scanning

Retrieves a scan device by device ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/scan/v2/device/:deviceId`
- **Base URL:** `https://api.sitaflex.aero`
- **Official documentation:** [Get Scan Device](https://www.developer.aero/api-catalog/flex/scan-api-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deviceId` | path | `string` | yes | Device identifier. |
