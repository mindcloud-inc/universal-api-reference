# Update Template Structure with GatherContent

Updates the structure of a template in GatherContent.

## Endpoint

- **Method:** `PUT`
- **Path:** `/templates/:template_id/structure`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Update Template Structure](https://docs.gathercontent.com/reference/updatetemplatestructure)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Template ID. |
