# Duplicate Template with GatherContent

Duplicates an existing template in GatherContent.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/:template_id/duplicate`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Duplicate Template](https://docs.gathercontent.com/reference/duplicatetemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Template ID. |
