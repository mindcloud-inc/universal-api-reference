# List Templates with GatherContent

Lists templates in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/templates`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Templates](https://docs.gathercontent.com/reference/listtemplates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
