# Delete Template with GatherContent

Deletes an existing template from GatherContent.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Delete Template](https://docs.gathercontent.com/reference/deletetemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Template ID. |
