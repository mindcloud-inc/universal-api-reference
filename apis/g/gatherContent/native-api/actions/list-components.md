# List Components with GatherContent

Lists components in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/components`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Components](https://docs.gathercontent.com/reference/listcomponents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
