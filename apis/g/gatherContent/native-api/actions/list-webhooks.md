# List Webhooks with GatherContent

Lists subscribed webhooks in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/webhooks`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Webhooks](https://docs.gathercontent.com/reference/listwebhooks-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
