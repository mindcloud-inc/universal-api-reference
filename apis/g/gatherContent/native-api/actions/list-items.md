# List Items with GatherContent

Lists items in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/items`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Items](https://docs.gathercontent.com/reference/listitems)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
