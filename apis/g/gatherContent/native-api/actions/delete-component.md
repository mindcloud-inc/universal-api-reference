# Delete Component with GatherContent

Deletes an existing component from GatherContent.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/components/:component_uuid`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Delete Component](https://docs.gathercontent.com/reference/deletecomponent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `component_uuid` | path | `string` | yes | Component UUID. |
