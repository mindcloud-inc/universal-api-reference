# Get Template with GatherContent

Retrieves a template from GatherContent.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template_id`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Get Template](https://docs.gathercontent.com/reference/gettemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Template ID. |
