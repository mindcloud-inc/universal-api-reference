# Get Item with GatherContent

Retrieves an item from GatherContent.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:item_id`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Get Item](https://docs.gathercontent.com/reference/getitem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Item ID. |
