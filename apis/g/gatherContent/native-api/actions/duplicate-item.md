# Duplicate Item with GatherContent

Duplicates an existing item in GatherContent.

## Endpoint

- **Method:** `POST`
- **Path:** `/items/:item_id/duplicate`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Duplicate Item](https://docs.gathercontent.com/reference/duplicateitem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Item ID. |
