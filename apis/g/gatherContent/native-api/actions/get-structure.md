# Get Structure with GatherContent

Retrieves a structure from GatherContent.

## Endpoint

- **Method:** `GET`
- **Path:** `/structures/:structure_uuid`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Get Structure](https://docs.gathercontent.com/reference/getstructure)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `structure_uuid` | path | `string` | yes | Structure UUID. |
