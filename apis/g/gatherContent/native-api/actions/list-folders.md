# List Folders with GatherContent

Lists folders in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/folders`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Folders](https://docs.gathercontent.com/reference/listfolders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
