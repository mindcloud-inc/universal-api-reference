# Disconnect Template From Item with GatherContent

Disconnects an item from its template in GatherContent.

## Endpoint

- **Method:** `POST`
- **Path:** `/items/:item_id/disconnect_template`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Disconnect Template From Item](https://docs.gathercontent.com/reference/disconnecttemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Item ID. |
