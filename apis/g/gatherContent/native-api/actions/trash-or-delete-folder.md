# Trash Or Delete Folder with GatherContent

Trashes or permanently deletes a folder in GatherContent.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folders/:folder_uuid`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Trash Or Delete Folder](https://docs.gathercontent.com/reference/trashordeletefolder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_uuid` | path | `string` | yes | Folder UUID. |
