# Move Item with GatherContent

Moves an existing item in GatherContent.

## Endpoint

- **Method:** `POST`
- **Path:** `/items/:item_id/move`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Move Item](https://docs.gathercontent.com/reference/moveitem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Item ID. |
