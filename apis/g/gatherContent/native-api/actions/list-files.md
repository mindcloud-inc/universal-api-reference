# List Files with GatherContent

Lists files in a GatherContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/files`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Files](https://docs.gathercontent.com/reference/listfiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
