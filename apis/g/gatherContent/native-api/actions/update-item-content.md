# Update Item Content with GatherContent

Updates content for an existing item in GatherContent.

## Endpoint

- **Method:** `POST`
- **Path:** `/items/:item_id/content`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Update Item Content](https://docs.gathercontent.com/reference/updateitemcontent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Item ID. |
