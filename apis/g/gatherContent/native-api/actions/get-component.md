# Get Component with GatherContent

Retrieves a component from GatherContent.

## Endpoint

- **Method:** `GET`
- **Path:** `/components/:component_uuid`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [Get Component](https://docs.gathercontent.com/reference/getcomponent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `component_uuid` | path | `string` | yes | Component UUID. |
