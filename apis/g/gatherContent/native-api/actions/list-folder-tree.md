# List Folder Tree with GatherContent

Lists folders in a GatherContent project tree.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/folders/tree`
- **Base URL:** `https://api.gathercontent.com`
- **Official documentation:** [List Folder Tree](https://docs.gathercontent.com/reference/listfoldersastree)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id. |
