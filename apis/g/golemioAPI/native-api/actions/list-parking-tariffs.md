# List Parking Tariffs with Golemio API

Finds parking tariffs in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/parking-tariffs`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Parking Tariffs](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
