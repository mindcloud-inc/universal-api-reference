# List Medical Institutions with Golemio API

Finds medical institutions in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/medicalinstitutions`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Medical Institutions](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
