# List Parking Locations with Golemio API

Finds parking locations in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/parking`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Parking Locations](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
