# List Parking Measurements with Golemio API

Finds parking measurements in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/parking-measurements`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Parking Measurements](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
