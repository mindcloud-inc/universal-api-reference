# List Municipal Authorities with Golemio API

Finds municipal authorities in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/municipalauthorities`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Municipal Authorities](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
