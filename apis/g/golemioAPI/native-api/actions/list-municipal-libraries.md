# List Municipal Libraries with Golemio API

Finds municipal libraries in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/municipallibraries`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Municipal Libraries](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
