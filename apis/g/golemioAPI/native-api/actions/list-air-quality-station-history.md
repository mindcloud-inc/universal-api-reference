# List Air Quality Station History with Golemio API

Finds air quality station history in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/airqualitystations/history`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Air Quality Station History](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
