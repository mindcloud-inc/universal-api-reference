# List Gardens with Golemio API

Finds gardens in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/gardens`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Gardens](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
