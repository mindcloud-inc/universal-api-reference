# List Waste Collection Stations with Golemio API

Finds waste collection stations in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sortedwastestations`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Waste Collection Stations](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
