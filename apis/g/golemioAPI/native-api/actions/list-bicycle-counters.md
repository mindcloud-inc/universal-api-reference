# List Bicycle Counters with Golemio API

Finds bicycle counters in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/bicyclecounters`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Bicycle Counters](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
