# List Municipal Police Stations with Golemio API

Finds municipal police stations in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/municipalpolicestations`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Municipal Police Stations](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
