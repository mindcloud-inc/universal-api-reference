# List Air Quality Stations with Golemio API

Finds air quality stations in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/airqualitystations`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Air Quality Stations](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
