# List City Districts with Golemio API

Finds city districts in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/citydistricts`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List City Districts](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
