# List Parking Machines with Golemio API

Finds parking machines in the Golemio API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/parking-machines`
- **Base URL:** `https://api.golemio.cz`
- **Official documentation:** [List Parking Machines](https://api.golemio.cz/docs/public-openapi/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
