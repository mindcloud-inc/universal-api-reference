# Retrieve Team with Gorgias

Retrieves a team from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Team](https://developers.gorgias.com/reference/get-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team ID. |
