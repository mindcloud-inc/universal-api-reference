# Retrieve Job with Gorgias

Retrieves a job from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Job](https://developers.gorgias.com/reference/get-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Job ID. |
