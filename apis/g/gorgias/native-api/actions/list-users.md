# List Users with Gorgias

Finds users in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Users](https://developers.gorgias.com/reference/list-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
