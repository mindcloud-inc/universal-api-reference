# List Messages with Gorgias

Finds messages in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Messages](https://developers.gorgias.com/reference/list-messages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
