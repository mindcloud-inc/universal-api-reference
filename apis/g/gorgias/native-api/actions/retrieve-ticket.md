# Retrieve Ticket with Gorgias

Retrieves a ticket from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Ticket](https://developers.gorgias.com/reference/get-ticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ticket ID. |
