# List Rules with Gorgias

Finds rules in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/rules`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Rules](https://developers.gorgias.com/reference/list-rules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
