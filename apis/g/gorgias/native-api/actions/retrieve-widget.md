# Retrieve Widget with Gorgias

Retrieves a widget from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Widget](https://developers.gorgias.com/reference/get-widget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Widget ID. |
