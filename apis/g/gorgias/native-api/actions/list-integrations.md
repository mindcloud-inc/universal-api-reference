# List Integrations with Gorgias

Finds integrations in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Integrations](https://developers.gorgias.com/reference/list-integrations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
