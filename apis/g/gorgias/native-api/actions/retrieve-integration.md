# Retrieve Integration with Gorgias

Retrieves an integration from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Integration](https://developers.gorgias.com/reference/get-integration)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Integration ID. |
