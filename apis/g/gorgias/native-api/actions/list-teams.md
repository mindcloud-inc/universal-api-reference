# List Teams with Gorgias

Finds teams in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Teams](https://developers.gorgias.com/reference/list-teams)

## Capabilities

This operation supports [pagination](../README.md#pagination).
