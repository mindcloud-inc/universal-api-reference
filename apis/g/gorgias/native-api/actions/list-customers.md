# List Customers with Gorgias

Finds customers in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Customers](https://developers.gorgias.com/reference/list-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
