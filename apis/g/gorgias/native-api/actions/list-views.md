# List Views with Gorgias

Finds views in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/views`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Views](https://developers.gorgias.com/reference/list-views)

## Capabilities

This operation supports [pagination](../README.md#pagination).
