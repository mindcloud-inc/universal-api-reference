# List Jobs with Gorgias

Finds jobs in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Jobs](https://developers.gorgias.com/reference/list-jobs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
