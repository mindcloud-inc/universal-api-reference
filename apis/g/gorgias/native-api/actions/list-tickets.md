# List Tickets with Gorgias

Finds tickets in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Tickets](https://developers.gorgias.com/reference/list-tickets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
