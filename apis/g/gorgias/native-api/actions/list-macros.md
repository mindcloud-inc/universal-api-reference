# List Macros with Gorgias

Finds macros in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/macros`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Macros](https://developers.gorgias.com/reference/list-macros)

## Capabilities

This operation supports [pagination](../README.md#pagination).
