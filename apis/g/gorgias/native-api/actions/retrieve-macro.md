# Retrieve Macro with Gorgias

Retrieves a macro from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/macros/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Macro](https://developers.gorgias.com/reference/get-macro)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Macro ID. |
