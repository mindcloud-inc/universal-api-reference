# Retrieve Custom Field with Gorgias

Retrieves a custom field from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Custom Field](https://developers.gorgias.com/reference/get-custom-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Custom field ID. |
