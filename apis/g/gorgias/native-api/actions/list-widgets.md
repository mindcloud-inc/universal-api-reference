# List Widgets with Gorgias

Finds widgets in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Widgets](https://developers.gorgias.com/reference/list-widgets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
