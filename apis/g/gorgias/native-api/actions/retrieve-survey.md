# Retrieve Survey with Gorgias

Retrieves a satisfaction survey from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Survey](https://developers.gorgias.com/reference/get-satisfaction-survey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Survey ID. |
