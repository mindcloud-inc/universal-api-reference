# List Events with Gorgias

Finds events in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Events](https://developers.gorgias.com/reference/list-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).
