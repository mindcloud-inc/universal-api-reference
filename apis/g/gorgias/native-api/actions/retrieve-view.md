# Retrieve View with Gorgias

Retrieves a view from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/views/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve View](https://developers.gorgias.com/reference/get-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | View ID. |
