# Retrieve Rule with Gorgias

Retrieves a rule from Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/rules/:id`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [Retrieve Rule](https://developers.gorgias.com/reference/get-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Rule ID. |
