# List Tags with Gorgias

Finds tags in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Tags](https://developers.gorgias.com/reference/list-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
