# List Custom Fields with Gorgias

Finds custom fields in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Custom Fields](https://developers.gorgias.com/reference/list-custom-fields)

## Capabilities

This operation supports [pagination](../README.md#pagination).
