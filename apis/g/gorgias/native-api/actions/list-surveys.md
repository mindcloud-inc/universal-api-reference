# List Surveys with Gorgias

Finds satisfaction surveys in Gorgias.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys`
- **Base URL:** `https://{subdomain}.gorgias.com/api`
- **Official documentation:** [List Surveys](https://developers.gorgias.com/reference/list-satisfaction-surveys)

## Capabilities

This operation supports [pagination](../README.md#pagination).
