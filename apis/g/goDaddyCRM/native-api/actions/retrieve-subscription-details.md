# Retrieve Subscription Details with GoDaddy CRM

Retrieves subscription details from your GoDaddy account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriptions/:subscriptionId`
- **Base URL:** `https://api.godaddy.com`
- **Official documentation:** [Retrieve Subscription Details](https://developer.godaddy.com/doc/endpoint/subscriptions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | Unique identifier of the subscription to retrieve. |
