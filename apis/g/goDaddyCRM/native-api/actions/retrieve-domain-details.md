# Retrieve Domain Details with GoDaddy CRM

Retrieves domain details from your GoDaddy account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/domains/:domain`
- **Base URL:** `https://api.godaddy.com`
- **Official documentation:** [Retrieve Domain Details](https://developer.godaddy.com/doc/endpoint/domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain name whose details should be retrieved. |
