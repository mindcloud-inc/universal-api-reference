# Delete Image with Gyazo

Deletes an existing image from Gyazo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/images/:image_id`
- **Base URL:** `https://api.gyazo.com`
- **Official documentation:** [Delete Image](https://gyazo.com/api/docs/image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | The Gyazo image ID to delete. |
