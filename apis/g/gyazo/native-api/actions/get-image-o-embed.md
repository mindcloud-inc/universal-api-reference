# Get Image OEmbed with Gyazo

Retrieves oEmbed data for a Gyazo image.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/oembed`
- **Base URL:** `https://api.gyazo.com`
- **Official documentation:** [Get Image OEmbed](https://gyazo.com/api/docs/image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The Gyazo image page URL to resolve through oEmbed. |
