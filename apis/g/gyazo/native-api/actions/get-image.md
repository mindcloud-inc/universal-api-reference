# Get Image with Gyazo

Retrieves an image from Gyazo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/images/:image_id`
- **Base URL:** `https://api.gyazo.com`
- **Official documentation:** [Get Image](https://gyazo.com/api/docs/image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | The Gyazo image ID. |
