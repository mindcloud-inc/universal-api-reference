# Download Distance Job Results with Geocodio

Retrieves completed distance job results from Geocodio.

## Endpoint

- **Method:** `GET`
- **Path:** `/distance-jobs/{identifier}/download`
- **Base URL:** `https://api.geocod.io/v1.12`
- **Official documentation:** [Download Distance Job Results](https://www.geocod.io/docs/#distance-jobs-async)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Distance job identifier. |
