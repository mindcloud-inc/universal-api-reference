# Download Geocoding List Results with Geocodio

Retrieves completed geocoding list results from Geocodio.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/{id}/download`
- **Base URL:** `https://api.geocod.io/v1.12`
- **Official documentation:** [Download Geocoding List Results](https://www.geocod.io/docs/#download-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Geocodio list ID. |
