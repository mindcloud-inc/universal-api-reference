# Delete Geocoding List with Geocodio

Deletes an existing geocoding list from Geocodio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/{id}`
- **Base URL:** `https://api.geocod.io/v1.12`
- **Official documentation:** [Delete Geocoding List](https://www.geocod.io/docs/#delete-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Geocodio list ID. |
