# Delete Distance Job with Geocodio

Deletes an asynchronous distance job from Geocodio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/distance-jobs/{identifier}`
- **Base URL:** `https://api.geocod.io/v1.12`
- **Official documentation:** [Delete Distance Job](https://www.geocod.io/docs/#distance-jobs-async)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Distance job identifier. |
