# Get Geocoding List with Geocodio

Retrieves geocoding list status from Geocodio.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/{id}`
- **Base URL:** `https://api.geocod.io/v1.12`
- **Official documentation:** [Get Geocoding List](https://www.geocod.io/docs/#see-list-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Geocodio list ID. |
