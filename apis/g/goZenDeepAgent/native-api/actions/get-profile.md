# Get Profile with GoZen DeepAgent

Retrieves your GoZen DeepAgent user profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/zapierapp/auth`
- **Base URL:** `https://api.deepbot.gozen.io`
- **Official documentation:** [Get Profile](https://docs.gozen.io/deepagent/api-docs/zapier/get-profile)
