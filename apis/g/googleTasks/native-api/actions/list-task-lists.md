# List Task Lists with Google Tasks

Finds task lists in Google Tasks.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/@me/lists`
- **Base URL:** `https://tasks.googleapis.com/tasks/v1`
- **Official documentation:** [List Task Lists](https://developers.google.com/workspace/tasks/reference/rest/v1/tasklists/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
