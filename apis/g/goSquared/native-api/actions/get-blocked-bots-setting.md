# Get Blocked Bots Setting with GoSquared

Retrieves the blocked bots setting from GoSquared.

## Endpoint

- **Method:** `GET`
- **Path:** `account/v1/blocked/bots`
- **Base URL:** `https://api.gosquared.com`
- **Official documentation:** [Get Blocked Bots Setting](https://www.gosquared.com/docs/account/blocked/)
