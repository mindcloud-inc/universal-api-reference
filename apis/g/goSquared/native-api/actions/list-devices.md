# List Devices with GoSquared

Retrieves visitor devices tracked in GoSquared.

## Endpoint

- **Method:** `GET`
- **Path:** `people/v1/devices`
- **Base URL:** `https://api.gosquared.com`
- **Official documentation:** [List Devices](https://www.gosquared.com/docs/people/devices/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
