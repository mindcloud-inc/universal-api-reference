# Get Person with GoSquared

Retrieves a person from GoSquared by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `people/v1/people/:personID`
- **Base URL:** `https://api.gosquared.com`
- **Official documentation:** [Get Person](https://www.gosquared.com/docs/people/people/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personID` | path | `string` | yes | The unique identifier of the person to retrieve. |
