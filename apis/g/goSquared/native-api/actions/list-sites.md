# List Sites with GoSquared

Retrieves sites from the connected GoSquared account.

## Endpoint

- **Method:** `GET`
- **Path:** `account/v1/sites`
- **Base URL:** `https://api.gosquared.com`
- **Official documentation:** [List Sites](https://www.gosquared.com/docs/account/sites/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `presenter` | query | `string` | no | Modifies the response data structure. |
