# Get Smart Group with GoSquared

Retrieves a smart group from GoSquared by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `people/v1/smartgroups/:groupID`
- **Base URL:** `https://api.gosquared.com`
- **Official documentation:** [Get Smart Group](https://www.gosquared.com/docs/people/smartgroups/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupID` | path | `string` | yes | The identifier of the Smart Group to retrieve. |
