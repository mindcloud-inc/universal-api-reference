# Get Instance State with GREEN-API for WhatsApp

Retrieves the WhatsApp instance state from GREEN-API.

## Endpoint

- **Method:** `GET`
- **Path:** `getStateInstance/:apiTokenInstance`
- **Base URL:** `{apiUrl}/waInstance{idInstance}/`
- **Official documentation:** [Get Instance State](https://green-api.com/en/docs/api/account/GetStateInstance/)
