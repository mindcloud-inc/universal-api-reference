# Get Branch with Gridly

Retrieves a branch from Gridly by branch ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/branches/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Get Branch](https://www.gridly.com/docs/api/#retrieve-a-branch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the branch to retrieve. |
