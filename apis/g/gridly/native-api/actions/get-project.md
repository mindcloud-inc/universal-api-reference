# Get Project with Gridly

Retrieves a project from Gridly by project ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Get Project](https://www.gridly.com/docs/api/#retrieve-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID can be found in the URL of the web application: app.gridly.com/projects/<id>. |
