# Delete View with Gridly

Deletes an existing view from Gridly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/views/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Delete View](https://www.gridly.com/docs/api/#delete-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the view to delete. |
