# Delete Grid with Gridly

Deletes an existing grid from Gridly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/grids/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Delete Grid](https://www.gridly.com/docs/api/#delete-a-grid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the grid to delete. |
