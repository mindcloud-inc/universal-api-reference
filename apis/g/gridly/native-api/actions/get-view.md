# Get View with Gridly

Retrieves a view from Gridly by view ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/views/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Get View](https://www.gridly.com/docs/api/#retrieve-a-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the view. It can be found in the API quick start right panel of your Gridly Dashboard. |
