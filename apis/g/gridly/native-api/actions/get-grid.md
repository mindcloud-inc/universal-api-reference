# Get Grid with Gridly

Retrieves a grid from Gridly by grid ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/grids/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Get Grid](https://www.gridly.com/docs/api/#retrieve-a-grid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the grid to retrieve. |
