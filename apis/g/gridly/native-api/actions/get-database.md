# Get Database with Gridly

Retrieves a database from Gridly by database ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/databases/:id`
- **Base URL:** `https://api.gridly.com/v1`
- **Official documentation:** [Get Database](https://www.gridly.com/docs/api/#retrieve-a-database)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the database to retrieve. |
