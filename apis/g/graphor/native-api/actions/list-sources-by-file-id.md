# List Sources By File ID with Graphor

Finds sources in Graphor by file ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://sources.graphorlm.com`
- **Official documentation:** [List Sources By File ID](https://docs.graphorlm.com/api-reference/sources/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_ids` | query | `string` | yes | Optional list of source file IDs to filter the results. |
