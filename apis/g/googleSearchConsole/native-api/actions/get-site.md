# Get Site with Google Search Console

## Endpoint

- **Method:** `GET`
- **Path:** `sites/:siteUrl`
- **Base URL:** `https://www.googleapis.com/webmasters/v3`
- **Official documentation:** [Get Site](https://developers.google.com/webmaster-tools/v1/sites/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteUrl` | path | `list<string>` | yes | The Search Console property URL to retrieve, such as a URL-prefix property or a sc-domain property. |
