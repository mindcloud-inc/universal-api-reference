# Delete Site with Google Search Console

## Endpoint

- **Method:** `DELETE`
- **Path:** `sites/:siteUrl`
- **Base URL:** `https://www.googleapis.com/webmasters/v3`
- **Official documentation:** [Delete Site](https://developers.google.com/webmaster-tools/v1/sites/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteUrl` | path | `list<string>` | yes | The Search Console property URL to remove, such as a URL-prefix property or a sc-domain property. |
