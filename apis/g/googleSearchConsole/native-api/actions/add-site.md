# Add Site with Google Search Console

## Endpoint

- **Method:** `PUT`
- **Path:** `sites/:siteUrl`
- **Base URL:** `https://www.googleapis.com/webmasters/v3`
- **Official documentation:** [Add Site](https://developers.google.com/webmaster-tools/v1/sites/add)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteUrl` | path | `string` | yes | The Search Console property URL to add, such as a URL-prefix property or a sc-domain property. |
