# Cancel Batch with Google AI Studio

Cancels a batch operation in Google AI Studio.

## Endpoint

- **Method:** `POST`
- **Path:** `v1beta/batches/:name`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Cancel Batch](https://ai.google.dev/api/batch-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Full batch resource name, for example `batches/1234567890`. |
