# Delete Cached Content with Google AI Studio

Deletes a cached content entry from Google AI Studio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1beta/cachedContents/:cachedContentId`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Delete Cached Content](https://ai.google.dev/api/caching#method:-cachedcontents.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cachedContentId` | path | `string` | yes | Full cached content resource name, for example `cachedContents/abc123`. |
