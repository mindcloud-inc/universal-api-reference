# Delete File with Google AI Studio

Deletes a file from Google AI Studio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1beta/files/:fileId`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Delete File](https://ai.google.dev/api/files#method:-files.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Full file resource name, for example `files/abc-123`. |
