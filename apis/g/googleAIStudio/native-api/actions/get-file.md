# Get File with Google AI Studio

Retrieves file metadata from Google AI Studio.

## Endpoint

- **Method:** `GET`
- **Path:** `v1beta/files/:fileId`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Get File](https://ai.google.dev/api/files#method:-files.get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Full file resource name, for example `files/abc-123`. |
