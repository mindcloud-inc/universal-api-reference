# Get Measurement with Globalping

Retrieves a Globalping measurement by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/measurements/:id`
- **Base URL:** `https://api.globalping.io`
- **Official documentation:** [Get Measurement](https://github.com/jsdelivr/globalping#globalping-rest-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The measurement ID returned by a create measurement action. |
