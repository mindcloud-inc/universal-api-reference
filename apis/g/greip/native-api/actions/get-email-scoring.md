# Get Email Scoring with Greip - Fraud Prevention

Retrieves email risk scoring from Greip.

## Endpoint

- **Method:** `GET`
- **Path:** `/scoring/email`
- **Base URL:** `https://greipapi.com`
- **Official documentation:** [Get Email Scoring](https://docs.greip.io/api-reference/endpoint/scoring/email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to score. |
