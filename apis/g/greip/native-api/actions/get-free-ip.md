# Get Free IP with Greip - Fraud Prevention

Retrieves a visitor's IP address from Greip.

## Endpoint

- **Method:** `GET`
- **Path:** `/ip`
- **Base URL:** `https://greipapi.com`
- **Official documentation:** [Get Free IP](https://docs.greip.io/api-reference/endpoint/data-lookup/free-get-ip-method)
