# Get Profanity Detection with Greip - Fraud Prevention

Detects profanity in text with Greip.

## Endpoint

- **Method:** `GET`
- **Path:** `/scoring/profanity`
- **Base URL:** `https://greipapi.com`
- **Official documentation:** [Get Profanity Detection](https://docs.greip.io/api-reference/endpoint/scoring/profanity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | The text to analyze for profanity or abusive language. |
