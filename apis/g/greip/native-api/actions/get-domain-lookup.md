# Get Domain Lookup with Greip - Fraud Prevention

Retrieves domain lookup data from Greip.

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/domain`
- **Base URL:** `https://greipapi.com`
- **Official documentation:** [Get Domain Lookup](https://docs.greip.io/api-reference/endpoint/data-lookup/domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | The fully qualified domain name to look up. |
