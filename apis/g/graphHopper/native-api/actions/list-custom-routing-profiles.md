# List Custom Routing Profiles with GraphHopper

Retrieves custom routing profiles from GraphHopper.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles`
- **Base URL:** `https://graphhopper.com/api/1`
- **Official documentation:** [List Custom Routing Profiles](https://docs.graphhopper.com/openapi/custom-profiles/getprofiles)
