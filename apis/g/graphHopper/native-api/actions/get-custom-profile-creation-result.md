# Get Custom Profile Creation Result with GraphHopper

Retrieves a custom profile creation result from GraphHopper.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/solution/:jobId`
- **Base URL:** `https://graphhopper.com/api/1`
- **Official documentation:** [Get Custom Profile Creation Result](https://docs.graphhopper.com/openapi/custom-profiles/getprofilessolutionjobid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Custom profile creation job ID. |
