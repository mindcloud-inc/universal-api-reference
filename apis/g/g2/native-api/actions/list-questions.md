# List Questions with G2

Retrieves questions from G2.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/questions`
- **Base URL:** `https://data.g2.com`
- **Official documentation:** [List Questions](https://data.g2.com/openapi/v2.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
