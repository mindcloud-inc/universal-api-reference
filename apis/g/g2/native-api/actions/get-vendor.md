# Get Vendor with G2

Retrieves a vendor from G2.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/vendors/:id`
- **Base URL:** `https://data.g2.com`
- **Official documentation:** [Get Vendor](https://data.g2.com/openapi/v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Vendor UUID or slug from the G2 API spec. |
