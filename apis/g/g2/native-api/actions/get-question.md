# Get Question with G2

Retrieves a question from G2.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/questions/:id`
- **Base URL:** `https://data.g2.com`
- **Official documentation:** [Get Question](https://data.g2.com/openapi/v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Question identifier from the G2 API spec. |
