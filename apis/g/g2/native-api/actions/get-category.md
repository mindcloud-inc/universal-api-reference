# Get Category with G2

Retrieves a category from G2.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/categories/:id`
- **Base URL:** `https://data.g2.com`
- **Official documentation:** [Get Category](https://data.g2.com/openapi/v2.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Category UUID or slug from the G2 API spec. |
