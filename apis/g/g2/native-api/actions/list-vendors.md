# List Vendors with G2

Retrieves vendors from G2.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/vendors`
- **Base URL:** `https://data.g2.com`
- **Official documentation:** [List Vendors](https://data.g2.com/openapi/v2.yaml)

## Capabilities

This operation supports [pagination](../README.md#pagination).
