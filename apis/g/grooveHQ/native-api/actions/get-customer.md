# Get Customer with GrooveHQ

Retrieves a customer from GrooveHQ by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerEmail`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Customer](https://doc.groovehq.com/customers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerEmail` | path | `string` | yes |
