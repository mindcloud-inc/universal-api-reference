# List Agents with GrooveHQ

Retrieves agents from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [List Agents](https://doc.groovehq.com/agents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `string` | no |
