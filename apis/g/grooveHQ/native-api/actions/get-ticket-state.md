# Get Ticket State with GrooveHQ

Retrieves a ticket's state from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:ticketNumber/state`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Ticket State](https://doc.groovehq.com/tickets)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ticketNumber` | path | `string` | yes |
