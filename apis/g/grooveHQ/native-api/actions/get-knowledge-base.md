# Get Knowledge Base with GrooveHQ

Retrieves a knowledge base from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/kb/:id`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Knowledge Base](https://doc.groovehq.com/knowledge-bases)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
