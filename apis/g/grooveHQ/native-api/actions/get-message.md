# Get Message with GrooveHQ

Retrieves a message from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Message](https://doc.groovehq.com/messages)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
