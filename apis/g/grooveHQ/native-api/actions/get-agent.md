# Get Agent with GrooveHQ

Retrieves an agent from GrooveHQ by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentEmail`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Agent](https://doc.groovehq.com/agents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentEmail` | path | `string` | yes |
