# Search Knowledge Base Categories with GrooveHQ

Searches knowledge base categories in GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/kb/:knowledgeBaseId/categories/search`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Search Knowledge Base Categories](https://doc.groovehq.com/knowledge-bases)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `keyword` | query | `string` | no |
| `knowledge_base_id` | path | `string` | no |
| `page` | query | `string` | no |
| `per_page` | query | `string` | no |
