# Get Widget with GrooveHQ

Retrieves a public widget from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/widgets/:widgetUuid`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [Get Widget](https://doc.groovehq.com/knowledge-bases)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_uuid` | path | `string` | no |
