# List Customers with GrooveHQ

Retrieves customers from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [List Customers](https://doc.groovehq.com/customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
