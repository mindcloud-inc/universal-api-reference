# List Folders with GrooveHQ

Retrieves folders from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [List Folders](https://doc.groovehq.com/folders)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailbox` | query | `string` | no |
