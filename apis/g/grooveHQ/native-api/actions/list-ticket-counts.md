# List Ticket Counts with GrooveHQ

Retrieves ticket counts by folder from GrooveHQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/count`
- **Base URL:** `https://api.groovehq.com/v1`
- **Official documentation:** [List Ticket Counts](https://doc.groovehq.com/ticket-counts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailbox` | query | `string` | no |
