# Get Location with Google Dialogflow

Retrieves a location from Google Dialogflow.

## Endpoint

- **Method:** `GET`
- **Path:** `v3/:name`
- **Base URL:** `https://dialogflow.googleapis.com`
- **Official documentation:** [Get Location](https://docs.cloud.google.com/dialogflow/cx/docs/reference/rest/v3/projects.locations/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Required Google Cloud location resource name. |
