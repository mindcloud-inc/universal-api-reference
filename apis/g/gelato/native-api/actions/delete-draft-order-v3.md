# Delete Draft Order v3 with Gelato

Deletes a draft order from Gelato v3.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/orders/{{orderId}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Delete Draft Order v3](https://dashboard.gelato.com/docs/orders/v3/delete/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | yes |
