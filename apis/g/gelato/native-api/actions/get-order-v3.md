# Get Order v3 with Gelato

Retrieves an order from Gelato v3.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/orders/{{orderId}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Get Order v3](https://dashboard.gelato.com/docs/orders/v3/get/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | yes |
