# Shipment Methods with Gelato

Finds Gelato shipment methods by destination country.

## Endpoint

- **Method:** `GET`
- **Path:** `https://shipment.gelatoapis.com/v1/shipment-methods`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Shipment Methods](https://dashboard.gelato.com/docs/shipment/methods/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `country` | query | `string` | no |
