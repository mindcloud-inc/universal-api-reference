# Get Product with Gelato

Retrieves a product from Gelato by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://product.gelatoapis.com/v3/products/{{productUid}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Get Product](https://dashboard.gelato.com/docs/products/product/get/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `productUid` | path | `string` | yes |
