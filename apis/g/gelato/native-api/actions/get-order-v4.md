# Get Order v4 with Gelato

Retrieves an order from Gelato v4.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/orders/{{orderId}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Get Order v4](https://dashboard.gelato.com/docs/orders/v4/get/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `string` | yes |
