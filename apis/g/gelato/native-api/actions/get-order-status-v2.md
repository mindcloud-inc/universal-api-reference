# Get Order Status v2 with Gelato

Retrieves order status details from Gelato v2.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.gelato.com/v2/order/status/{{orderReferenceId}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Get Order Status v2](https://dashboard.gelato.com/docs/orders/v2/status/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderReferenceId` | path | `string` | yes |
