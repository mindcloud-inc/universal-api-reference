# List Catalogs with Gelato

Finds available product catalogs in Gelato.

## Endpoint

- **Method:** `GET`
- **Path:** `https://product.gelatoapis.com/v3/catalogs`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [List Catalogs](https://dashboard.gelato.com/docs/products/catalog/list/)
