# Get Catalog with Gelato

Retrieves a product catalog from Gelato by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://product.gelatoapis.com/v3/catalogs/{{catalogUid}}`
- **Base URL:** `https://order.gelatoapis.com`
- **Official documentation:** [Get Catalog](https://dashboard.gelato.com/docs/products/catalog/get/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `catalogUid` | path | `string` | yes |
