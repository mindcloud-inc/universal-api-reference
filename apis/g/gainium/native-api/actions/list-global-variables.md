# List Global Variables with Gainium

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/user/global-vars`
- **Base URL:** `https://api.gainium.io`
- **Official documentation:** [List Global Variables](https://api.gainium.io/api/docs/v2#/User/getUserGlobalVariables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | 1-based page number. |
