# List Indicator Types with Gainium

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/discovery/indicators`
- **Base URL:** `https://api.gainium.io`
- **Official documentation:** [List Indicator Types](https://api.gainium.io/api/docs/v2#/Discovery/getDiscoveryIndicators)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action` | query | `string` | no | Filter indicator types to one supported action. |
| `exchange` | query | `string` | no | Filter indicator intervals to one exchange. |
