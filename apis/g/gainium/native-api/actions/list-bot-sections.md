# List Bot Sections with Gainium

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/discovery/bots/:botType/sections`
- **Base URL:** `https://api.gainium.io`
- **Official documentation:** [List Bot Sections](https://api.gainium.io/api/docs/v2#/Discovery/getDiscoveryBotSections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botType` | path | `list` | yes | Bot type. Accepted values: `0`, `1`, `2`. |
