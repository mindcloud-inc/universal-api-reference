# List Folders with GetTranscribe

Retrieves folders from GetTranscribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcriptions-folders`
- **Base URL:** `https://api.gettranscribe.ai`
- **Official documentation:** [List Folders](https://www.gettranscribe.ai/api-documentation/folders/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `$sort[name]` | query | `number` | no | Sort folders by name using 1 for ascending or -1 for descending. |
