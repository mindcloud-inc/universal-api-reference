# Get Transcription with GetTranscribe

Retrieves a transcription from GetTranscribe by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcriptions/:id`
- **Base URL:** `https://api.gettranscribe.ai`
- **Official documentation:** [Get Transcription](https://www.gettranscribe.ai/api-documentation/transcriptions/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the transcription to retrieve. |
