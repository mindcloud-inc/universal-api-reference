# Get User Info with GetTranscribe

Retrieves user account details from GetTranscribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.gettranscribe.ai`
- **Official documentation:** [Get User Info](https://www.gettranscribe.ai/api-documentation/user/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the user to retrieve. |
