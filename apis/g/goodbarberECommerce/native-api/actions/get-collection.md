# Get Collection with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/catalog/:webzine_id/collection/:collection_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Collection](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection_id` | path | `number` | yes | Collection Unique ID. |
