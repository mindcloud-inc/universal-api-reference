# Delete Product with Goodbarber eCommerce

## Endpoint

- **Method:** `DELETE`
- **Path:** `/publicapi/v2/general/catalog/:webzine_id/product/:product_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Delete Product](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | Product ID. |
