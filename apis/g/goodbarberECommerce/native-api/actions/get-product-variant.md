# Get Product Variant with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/catalog/:webzine_id/product/:product_id/variant/:variant_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Product Variant](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `number` | yes |
| `variant_id` | path | `number` | yes |
