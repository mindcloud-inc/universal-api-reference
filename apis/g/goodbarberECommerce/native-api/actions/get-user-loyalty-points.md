# Get User Loyalty Points with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/marketing/:webzine_id/loyalty/user/:user_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get User Loyalty Points](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Unique ID of the user. |
