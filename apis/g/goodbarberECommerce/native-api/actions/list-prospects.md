# List Prospects with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/customer/:webzine_id/prospect/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [List Prospects](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
