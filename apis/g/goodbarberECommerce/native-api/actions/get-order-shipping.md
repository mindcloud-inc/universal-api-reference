# Get Order Shipping with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/orders/:webzine_id/order/:order_id/shipping/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Order Shipping](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | yes | Unique ID of the order. |
