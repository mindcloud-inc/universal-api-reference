# Get Customer with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/customer/:webzine_id/customer/:customer_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Customer](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | Unique ID of the customer. |
