# Get Prospect with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/customer/:webzine_id/prospect/:user_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Prospect](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Unique ID of the User. |
