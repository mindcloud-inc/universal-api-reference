# Get Order with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/orders/:webzine_id/order/:order_id/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [Get Order](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | yes | Unique ID of the order. |
