# List Product Paragraphs with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/catalog/:webzine_id/product/:product_id/paragraph/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [List Product Paragraphs](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | Unique ID of the Product |
