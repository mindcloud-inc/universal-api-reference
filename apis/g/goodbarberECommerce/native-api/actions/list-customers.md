# List Customers with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/customer/:webzine_id/customer/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [List Customers](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
