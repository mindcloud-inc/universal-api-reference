# List App Global Downloads with Goodbarber eCommerce

## Endpoint

- **Method:** `GET`
- **Path:** `/publicapi/v2/general/stats/:webzine_id/downloads_global/`
- **Base URL:** `https://commerce.goodbarber.dev`
- **Official documentation:** [List App Global Downloads](https://commerce.goodbarber.dev/publicapi/v2/documentation/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `platform` | query | `string` | no | Target platform. Defaults to "all". |
