# Download Recording with Grain

Downloads a recording from Grain.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/recordings/:recording_id/download`
- **Base URL:** `https://api.grain.com/_/public-api`
- **Official documentation:** [Download Recording](https://developers.grain.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recording_id` | path | `list<string>` | yes |
