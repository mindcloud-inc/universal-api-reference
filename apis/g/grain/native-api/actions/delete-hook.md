# Delete Hook with Grain

Deletes a hook from Grain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/hooks/:hook_id`
- **Base URL:** `https://api.grain.com/_/public-api`
- **Official documentation:** [Delete Hook](https://developers.grain.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `hook_id` | path | `list<string>` | yes |
