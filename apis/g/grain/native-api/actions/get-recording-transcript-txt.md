# Get Recording Transcript TXT with Grain

Retrieves a recording transcript in TXT from Grain.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/recordings/:recording_id/transcript.txt`
- **Base URL:** `https://api.grain.com/_/public-api`
- **Official documentation:** [Get Recording Transcript TXT](https://developers.grain.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recording_id` | path | `list<string>` | yes |
