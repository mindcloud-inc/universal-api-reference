# Get Recording Transcript SRT with Grain

Retrieves a recording transcript in SRT from Grain.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/recordings/:recording_id/transcript.srt`
- **Base URL:** `https://api.grain.com/_/public-api`
- **Official documentation:** [Get Recording Transcript SRT](https://developers.grain.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recording_id` | path | `list<string>` | yes |
