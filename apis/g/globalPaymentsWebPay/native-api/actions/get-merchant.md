# Get Merchant with Global Payments WebPay

Retrieves a merchant from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchants/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Merchant](https://developer.globalpayments.com/api/merchants)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments merchant ID. |
