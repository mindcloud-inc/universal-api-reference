# Get Transaction with Global Payments WebPay

Retrieves a transaction from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Transaction](https://developer.globalpayments.com/api/transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments transaction ID. |
