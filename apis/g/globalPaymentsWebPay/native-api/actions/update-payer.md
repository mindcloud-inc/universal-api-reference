# Update Payer with Global Payments WebPay

Updates a payer in Global Payments WebPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/payers/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Update Payer](https://developer.globalpayments.com/api/payers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments payer ID. |
