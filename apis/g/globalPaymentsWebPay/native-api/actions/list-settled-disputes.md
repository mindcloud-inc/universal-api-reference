# List Settled Disputes with Global Payments WebPay

Retrieves settled disputes from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/settlement/disputes`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Settled Disputes](https://developer.globalpayments.com/api/settlement-reporting)

## Capabilities

This operation supports [pagination](../README.md#pagination).
