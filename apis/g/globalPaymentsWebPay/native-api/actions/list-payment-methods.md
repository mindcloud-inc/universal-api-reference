# List Payment Methods with Global Payments WebPay

Retrieves payment methods from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-methods`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Payment Methods](https://developer.globalpayments.com/api/payment-methods-tokenization)

## Capabilities

This operation supports [pagination](../README.md#pagination).
