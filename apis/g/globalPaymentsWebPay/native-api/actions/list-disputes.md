# List Disputes with Global Payments WebPay

Retrieves disputes from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Disputes](https://developer.globalpayments.com/api/disputes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
