# Get Link with Global Payments WebPay

Retrieves a payment link from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Link](https://developer.globalpayments.com/api/links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments link ID. |
