# List Settled Transactions with Global Payments WebPay

Retrieves settled transactions from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/settlement/transactions`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Settled Transactions](https://developer.globalpayments.com/api/settlement-reporting)

## Capabilities

This operation supports [pagination](../README.md#pagination).
