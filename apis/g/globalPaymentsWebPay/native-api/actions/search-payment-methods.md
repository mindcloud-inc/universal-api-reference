# Search Payment Methods with Global Payments WebPay

Finds payment methods in Global Payments WebPay by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/payment-methods/search`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Search Payment Methods](https://developer.globalpayments.com/api/payment-methods-tokenization)

## Capabilities

This operation supports [pagination](../README.md#pagination).
