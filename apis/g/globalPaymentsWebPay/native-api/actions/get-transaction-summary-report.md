# Get Transaction Summary Report with Global Payments WebPay

Retrieves a transaction summary report from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Transaction Summary Report](https://developer.globalpayments.com/api/reports)

## Capabilities

This operation supports [pagination](../README.md#pagination).
