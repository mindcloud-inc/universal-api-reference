# Get Settlement Deposit with Global Payments WebPay

Retrieves a settlement deposit from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/settlement/deposits/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Settlement Deposit](https://developer.globalpayments.com/api/settlement-reporting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments settlement deposit ID. |
