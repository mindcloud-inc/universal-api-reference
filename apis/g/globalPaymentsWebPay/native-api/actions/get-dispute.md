# Get Dispute with Global Payments WebPay

Retrieves a dispute from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Dispute](https://developer.globalpayments.com/api/disputes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments dispute ID. |
