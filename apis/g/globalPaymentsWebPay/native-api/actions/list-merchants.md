# List Merchants with Global Payments WebPay

Retrieves merchants from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchants`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Merchants](https://developer.globalpayments.com/api/merchants)

## Capabilities

This operation supports [pagination](../README.md#pagination).
