# Get Account with Global Payments WebPay

Retrieves an account from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Account](https://developer.globalpayments.com/api/accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments account ID. |
