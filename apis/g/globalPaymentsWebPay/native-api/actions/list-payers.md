# List Payers with Global Payments WebPay

Retrieves payers from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/payers`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Payers](https://developer.globalpayments.com/api/payers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
