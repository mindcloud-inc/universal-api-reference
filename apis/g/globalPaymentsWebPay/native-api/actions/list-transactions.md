# List Transactions with Global Payments WebPay

Retrieves transactions from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Transactions](https://developer.globalpayments.com/api/transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
