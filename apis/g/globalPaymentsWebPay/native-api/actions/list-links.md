# List Links with Global Payments WebPay

Retrieves payment links from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/links`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Links](https://developer.globalpayments.com/api/links)

## Capabilities

This operation supports [pagination](../README.md#pagination).
