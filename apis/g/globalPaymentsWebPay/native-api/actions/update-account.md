# Update Account with Global Payments WebPay

Updates an account in Global Payments WebPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/accounts/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Update Account](https://developer.globalpayments.com/api/accounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments account ID. |
