# Get Payer with Global Payments WebPay

Retrieves a payer from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/payers/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Payer](https://developer.globalpayments.com/api/payers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments payer ID. |
