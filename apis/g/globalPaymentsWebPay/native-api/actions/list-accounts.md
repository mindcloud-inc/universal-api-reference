# List Accounts with Global Payments WebPay

Retrieves accounts from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Accounts](https://developer.globalpayments.com/api/accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
