# List Settlement Deposits with Global Payments WebPay

Retrieves settlement deposits from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/settlement/deposits`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [List Settlement Deposits](https://developer.globalpayments.com/api/settlement-reporting)

## Capabilities

This operation supports [pagination](../README.md#pagination).
