# Get Payment Method with Global Payments WebPay

Retrieves a payment method from Global Payments WebPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-methods/{id}`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Get Payment Method](https://developer.globalpayments.com/api/payment-methods-tokenization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments payment method ID. |
