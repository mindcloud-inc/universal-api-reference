# Create Sale Or Refund Transaction with Global Payments WebPay

Creates a sale or refund transaction in Global Payments WebPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/transactions`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Create Sale Or Refund Transaction](https://developer.globalpayments.com/api/transactions)
