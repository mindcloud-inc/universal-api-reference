# Adjust Transaction with Global Payments WebPay

Updates a transaction by adjusting it in Global Payments WebPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/transactions/{id}/adjustment`
- **Base URL:** `https://apis.globalpay.com/ucp`
- **Official documentation:** [Adjust Transaction](https://developer.globalpayments.com/api/transactions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Global Payments transaction ID. |
