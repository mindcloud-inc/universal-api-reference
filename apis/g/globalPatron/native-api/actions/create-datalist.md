# Create Datalist with Global Patron

Creates a datalist in Global Patron.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/restricted/datalist`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [Create Datalist](https://www.globalpatron.com/developers/api/datalists/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
