# Clone Form with Global Patron

Clones a form in Global Patron.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/restricted/form/{formId}/clone`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [Clone Form](https://www.globalpatron.com/developers/api/forms/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ID of the form. |
