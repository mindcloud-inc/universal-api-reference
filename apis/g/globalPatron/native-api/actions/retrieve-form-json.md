# Retrieve Form JSON with Global Patron

Retrieves form JSON from Global Patron.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/form/{formId}`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [Retrieve Form JSON](https://www.globalpatron.com/developers/api/forms/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ID of the form. |
