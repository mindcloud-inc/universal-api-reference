# List Form Submission Webhooks with Global Patron

Lists form submission webhooks in Global Patron.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/restricted/form/{formId}/submissionwebhook`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [List Form Submission Webhooks](https://www.globalpatron.com/developers/api/webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ID of the form. |
