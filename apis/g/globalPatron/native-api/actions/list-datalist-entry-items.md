# List Datalist Entry Items with Global Patron

Lists datalist entry items in Global Patron.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/restricted/datalist/{datalistId}/entries`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [List Datalist Entry Items](https://www.globalpatron.com/developers/api/datalists/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datalistId` | path | `string` | yes | ID of the datalist. |
