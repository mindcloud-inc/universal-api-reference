# List Form User Security Settings with Global Patron

Lists form user security settings in Global Patron.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/restricted/form/{formId}/usersecurity`
- **Base URL:** `https://api.globalpatron.com`
- **Official documentation:** [List Form User Security Settings](https://www.globalpatron.com/developers/api/users/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | ID of the form. |
