# Update Contact List with GoDial

Updates an existing contact list in GoDial.

## Endpoint

- **Method:** `PUT`
- **Path:** `/externals/lists/[:id]/update`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Update Contact List](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2OQ-lists-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID. |
