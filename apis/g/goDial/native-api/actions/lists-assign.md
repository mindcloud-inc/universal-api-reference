# Assign Contact List to User with GoDial

Assigns a contact list to a user in GoDial.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/lists/assign`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Assign Contact List to User](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY3MQ-lists-assign)
