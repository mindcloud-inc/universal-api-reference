# Delete Task with GoDial

Deletes an existing task from GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/tasks/[:id]/remove`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete Task](https://godial.stoplight.io/docs/godial/b3A6NzQwMTQ0Nw-task-remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task ID. |
