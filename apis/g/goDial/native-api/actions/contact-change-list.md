# Move Contact to List with GoDial

Moves a contact to another list in GoDial.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/contact/listchange`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Move Contact to List](https://godial.stoplight.io/docs/godial/b3A6NTg1NTgyNDE3-contact-change-list)
