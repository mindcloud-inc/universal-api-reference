# Unassign Contact List from User with GoDial

Unassigns a contact list from a user in GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/lists/detach`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Unassign Contact List from User](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY3Mg-lists-detach)
