# List Call Logs with GoDial

Retrieves a list of call logs from GoDial.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/log/list`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [List Call Logs](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY3Mw-log-list)
