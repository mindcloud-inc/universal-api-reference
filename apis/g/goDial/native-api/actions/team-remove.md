# Delete Team with GoDial

Deletes an existing team from GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/team/[:id]/remove`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete Team](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1Mg-team-remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team ID. |
