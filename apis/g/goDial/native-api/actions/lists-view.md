# Get Contact List with GoDial

Retrieves a contact list from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/lists/[:id]/view`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Get Contact List](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2Nw-lists-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID. |
