# List Tasks with GoDial

Retrieves a list of tasks from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/tasks/list`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [List Tasks](https://godial.stoplight.io/docs/godial/b3A6NzQwMTQ0Mw-task-list)
