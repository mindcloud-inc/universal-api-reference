# Delete Contact with GoDial

Deletes an existing contact from GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/contact/[:id]/remove`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete Contact](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2Mw-contact-remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID. |
