# Create Contact List with GoDial

Creates a new contact list in GoDial.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/lists/add`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Create Contact List](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2OA-lists-add)
