# Update Contact with GoDial

Updates an existing contact in GoDial.

## Endpoint

- **Method:** `PUT`
- **Path:** `/externals/contact/[:id]/update`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Update Contact](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2NA-contact-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID. |
