# Get User with GoDial

Retrieves details for a user from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/accounts/[:id]/view`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Get User](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1NQ-accounts-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Account ID. |
