# Get Contact with GoDial

Retrieves details for a contact from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/contact/[:id]/view`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Get Contact](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2MQ-contact-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID. |
