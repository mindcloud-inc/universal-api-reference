# List Users with GoDial

Retrieves a list of users from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/accounts/list`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [List Users](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1NA-accounts-list)
