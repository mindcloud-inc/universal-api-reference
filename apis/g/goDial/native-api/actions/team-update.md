# Update Team with GoDial

Updates an existing team in GoDial.

## Endpoint

- **Method:** `PUT`
- **Path:** `/externals/team/[:id]/update`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Update Team](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1Mw-team-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team ID. |
