# List Contact Lists with GoDial

Retrieves a list of contact lists from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/lists/list`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [List Contact Lists](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2Ng-lists-list)
