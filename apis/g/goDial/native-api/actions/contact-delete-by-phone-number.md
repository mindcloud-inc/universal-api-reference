# Delete Contact by Phone Number with GoDial

Deletes a contact from GoDial by phone number and list ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/contact/delete-by-phone`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete Contact by Phone Number](https://godial.stoplight.io/docs/godial/b3A6NzkzMDk0NTM4-contact-delete-by-phone-number)
