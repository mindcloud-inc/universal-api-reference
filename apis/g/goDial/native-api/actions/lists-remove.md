# Delete Contact List with GoDial

Deletes an existing contact list from GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/lists/[:id]/remove`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete Contact List](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY3MA-lists-remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | List ID. |
