# Delete User with GoDial

Deletes an existing user from GoDial.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/externals/accounts/[:id]/remove`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Delete User](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1Nw-accounts-remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Account ID. |
