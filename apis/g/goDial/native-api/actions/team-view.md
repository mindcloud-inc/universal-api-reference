# Get Team with GoDial

Retrieves details for a team from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/team/[:id]/view`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Get Team](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY1MA-team-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team ID. |
