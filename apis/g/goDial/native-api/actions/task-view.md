# Get Task with GoDial

Retrieves details for a task from GoDial.

## Endpoint

- **Method:** `GET`
- **Path:** `/externals/tasks/[:id]/view`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Get Task](https://godial.stoplight.io/docs/godial/b3A6NzQwMTQ0NA-task-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task ID. |
