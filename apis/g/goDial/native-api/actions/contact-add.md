# Create Contact with GoDial

Creates a new contact in GoDial.

## Endpoint

- **Method:** `POST`
- **Path:** `/externals/contact/add`
- **Base URL:** `https://enterprise.godial.cc/meta/api`
- **Official documentation:** [Create Contact](https://godial.stoplight.io/docs/godial/b3A6MzAzMTY2Mg-contact-add)
