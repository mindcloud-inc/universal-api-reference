# Get Group with Go4Clients

Retrieves a contact group from Go4Clients.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/groupscontacts/groups/v1.0/{{groupId}}`
- **Base URL:** `https://cloud.go4clients.com:8580`
- **Official documentation:** [Get Group](https://apidoc.go4clients.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | Group ID to retrieve. |
