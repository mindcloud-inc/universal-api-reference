# Get Email Campaign with Go4Clients

Retrieves an email campaign from Go4Clients.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/campaigns/email/v1.0/{{campaignId}}`
- **Base URL:** `https://cloud.go4clients.com:8580`
- **Official documentation:** [Get Email Campaign](https://apidoc.go4clients.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Email campaign identifier. |
