# Get Document with Google Docs

Retrieves a Google Docs document by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/:documentId`
- **Base URL:** `https://docs.googleapis.com/v1/documents`
- **Official documentation:** [Get Document](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `list<string>` | yes | ID of the document |
