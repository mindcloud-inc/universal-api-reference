# Create Blank Document with Google Docs

Creates a new blank document in Google Docs.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://docs.googleapis.com/v1/documents`
- **Official documentation:** [Create Blank Document](https://developers.google.com/workspace/docs/api/reference/rest/v1/documents/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | Title of the new document |
