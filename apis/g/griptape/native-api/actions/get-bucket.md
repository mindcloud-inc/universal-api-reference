# Get Bucket with Griptape

Retrieves a bucket from Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/buckets/:bucket_id`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [Get Bucket](https://docs.griptape.ai/stable/griptape-cloud/data-lakes/data-lakes/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bucket_id` | path | `string` | yes | The bucket ID to retrieve. |
