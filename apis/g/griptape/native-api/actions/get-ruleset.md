# Get Ruleset with Griptape

Retrieves a ruleset from Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rulesets/:ruleset_id`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [Get Ruleset](https://docs.griptape.ai/stable/griptape-cloud/rules/rulesets/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleset_id` | path | `string` | yes | The Griptape ruleset ID to retrieve. |
