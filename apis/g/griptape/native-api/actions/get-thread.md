# Get Thread with Griptape

Retrieves a thread from Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/threads/:thread_id`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [Get Thread](https://docs.griptape.ai/stable/griptape-cloud/threads/threads/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `thread_id` | path | `string` | yes | The Griptape thread ID to retrieve. |
