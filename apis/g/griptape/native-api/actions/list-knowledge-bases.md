# List Knowledge Bases with Griptape

Finds knowledge bases in Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/knowledge-bases`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [List Knowledge Bases](https://docs.griptape.ai/stable/griptape-cloud/knowledge-bases/what-are-knowledge-bases/)
