# List Data Sources with Griptape

Finds data sources in Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data-connectors`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [List Data Sources](https://docs.griptape.ai/stable/griptape-cloud/data-sources/what-are-data-sources/)
