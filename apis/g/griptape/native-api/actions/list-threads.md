# List Threads with Griptape

Finds threads in Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/threads`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [List Threads](https://docs.griptape.ai/stable/griptape-cloud/threads/threads/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | query | `string` | no | Optional alias to filter the thread list. |
