# List Rulesets with Griptape

Finds rulesets in Griptape.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rulesets`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [List Rulesets](https://docs.griptape.ai/stable/griptape-cloud/rules/rulesets/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | query | `string` | no | Optional alias to filter the ruleset list. |
