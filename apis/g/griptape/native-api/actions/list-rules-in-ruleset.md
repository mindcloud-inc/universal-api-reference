# List Rules In Ruleset with Griptape

Finds rules in a Griptape ruleset.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rules`
- **Base URL:** `https://cloud.griptape.ai`
- **Official documentation:** [List Rules In Ruleset](https://docs.griptape.ai/stable/griptape-cloud/rules/rulesets/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleset_id` | query | `string` | yes | Filter rules to a specific ruleset ID. |
