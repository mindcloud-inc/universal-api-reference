# Create Spreadsheet with Google Sheets

Creates a new spreadsheet in Google Sheets.

## Endpoint

- **Method:** `POST`
- **Path:** `spreadsheets`
- **Base URL:** `https://sheets.googleapis.com/v4`
- **Official documentation:** [Create Spreadsheet](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | no |
