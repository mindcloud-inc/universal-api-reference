# Download Batch Result with Gamalogic

## Endpoint

- **Method:** `GET`
- **Path:** `/batchresult`
- **Base URL:** `https://gamalogic.com`
- **Official documentation:** [Download Batch Result](https://docs.gamalogic.com/emails/download-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchid` | query | `number` | yes | Unique batch ID for the completed batch verification request. |
