# Get Batch Status with Gamalogic

## Endpoint

- **Method:** `GET`
- **Path:** `/batchstatus`
- **Base URL:** `https://gamalogic.com`
- **Official documentation:** [Get Batch Status](https://docs.gamalogic.com/emails/status-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batchid` | query | `number` | yes | Unique batch ID returned by the batch verification request. |
