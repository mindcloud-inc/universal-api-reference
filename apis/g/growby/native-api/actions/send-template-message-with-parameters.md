# Send Template Message With Parameters with Growby

Sends a parameterized template message through Growby.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/messages`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Send Template Message With Parameters](https://www.postman.com/growby/workspace/growby/folder/29609016-3d951c54-49db-4942-ae2c-f1e767b3736c)
