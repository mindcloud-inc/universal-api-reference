# Send Media Template Message with Growby

Sends a media template message through Growby.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/messages`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Send Media Template Message](https://www.postman.com/growby-documentation/growby-api/request/t228iu6/send-media-template-message)
