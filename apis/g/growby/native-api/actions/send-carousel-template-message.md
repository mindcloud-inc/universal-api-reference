# Send Carousel Template Message with Growby

Sends a carousel template message through Growby.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/messages`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Send Carousel Template Message](https://www.postman.com/growby-documentation/growby-api/request/0wp1j1j/send-carousel-template-message)
