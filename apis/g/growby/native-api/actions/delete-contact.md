# Delete Contact with Growby

Deletes an existing contact from Growby.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/devapi/contact/:id`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Delete Contact](https://www.postman.com/growby-documentation/growby-api/documentation/i4ul9w0/growby-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Growby contact id to delete. |
