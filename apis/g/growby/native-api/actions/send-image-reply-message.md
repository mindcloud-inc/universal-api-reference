# Send Image Reply Message with Growby

Sends an image reply message through Growby.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/reply-messages`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Send Image Reply Message](https://www.postman.com/growby/workspace/growby/folder/29609016-3a876c37-d822-48be-b589-871f5fc2d7d6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `password` | body | `string` | no | Growby password for the v1 reply API. |
| `username` | body | `string` | no | Growby username for the v1 reply API. |
