# Send Interactive Template Message with Growby

Sends an interactive template message through Growby.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/messages`
- **Base URL:** `https://api.growby.net`
- **Official documentation:** [Send Interactive Template Message](https://www.postman.com/growby-documentation/growby-api/request/i5bqua7/send-interactive-template-message)
