# Get Collaborator Roles with Galileo

Retrieves project collaborator roles from Galileo.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/collaborator_roles`
- **Base URL:** `https://api.galileo.ai`
- **Official documentation:** [Get Collaborator Roles](https://docs.galileo.ai/api-reference/projects/get-collaborator-roles)
