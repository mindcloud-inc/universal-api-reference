# Get Project with Galileo

Retrieves a project from Galileo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:project_id`
- **Base URL:** `https://api.galileo.ai`
- **Official documentation:** [Get Project](https://docs.galileo.ai/api-reference/projects/get-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Galileo project UUID. |
