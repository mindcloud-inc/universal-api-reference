# List Current User Groups with Galileo

Retrieves groups for the current Galileo user.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/current_user/groups`
- **Base URL:** `https://api.galileo.ai`
- **Official documentation:** [List Current User Groups](https://docs.galileo.ai/api-reference/groups/list-current-user-groups)
