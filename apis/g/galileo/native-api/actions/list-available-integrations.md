# List Available Integrations with Galileo

Finds available integration types in Galileo.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/integrations/available`
- **Base URL:** `https://api.galileo.ai`
- **Official documentation:** [List Available Integrations](https://docs.galileo.ai/api-reference/integrations/list-available-integrations)
