# Get Dataset with Galileo

Retrieves a dataset from Galileo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:dataset_id`
- **Base URL:** `https://api.galileo.ai`
- **Official documentation:** [Get Dataset](https://docs.galileo.ai/api-reference/datasets/get-dataset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes | Galileo dataset UUID. |
