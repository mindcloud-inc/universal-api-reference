# List Customer Memberships with GoTeamup

Finds customer memberships in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer_memberships`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Customer Memberships](https://docs.goteamup.com/api-reference/endpoints/customer-memberships)
