# List Offering Types Helper with GoTeamup

Finds offering types in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/offering_types`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Offering Types Helper](https://docs.goteamup.com/api-reference/endpoints/offering-types-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
