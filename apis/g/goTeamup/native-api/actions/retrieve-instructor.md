# Retrieve Instructor with GoTeamup

Retrieves an instructor from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/instructors/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Instructor](https://docs.goteamup.com/api-reference/endpoints/instructors-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp instructor ID. |
