# List Events with GoTeamup

Finds events in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Events](https://docs.goteamup.com/api-reference/endpoints/events-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
