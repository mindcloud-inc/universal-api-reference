# Create Order with GoTeamup

Creates a new order in GoTeamup.

## Endpoint

- **Method:** `POST`
- **Path:** `/store/orders`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Create Order](https://docs.goteamup.com/api-reference/endpoints/orders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer` | body | `number` | yes | Customer ID |
