# Get Provider Entitlements with GoTeamup

Retrieves provider entitlements from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/providers/:id/entitlements`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Get Provider Entitlements](https://docs.goteamup.com/api-reference/endpoints/providers-entitlements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp provider ID. |
