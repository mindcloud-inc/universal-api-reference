# Retrieve Provider with GoTeamup

Retrieves a provider from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/providers/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Provider](https://docs.goteamup.com/api-reference/endpoints/providers-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp provider ID. |
