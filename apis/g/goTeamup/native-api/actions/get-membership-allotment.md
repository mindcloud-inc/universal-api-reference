# Get Membership Allotment with GoTeamup

Retrieves membership allotment details from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/memberships/:id/allotment`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Get Membership Allotment](https://docs.goteamup.com/api-reference/endpoints/memberships)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp membership ID |
