# Retrieve Customer Membership with GoTeamup

Retrieves a customer membership from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer_memberships/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Customer Membership](https://docs.goteamup.com/api-reference/endpoints/customer-memberships)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp customer membership ID |
