# List Venues Helper with GoTeamup

Finds venues in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/venues`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Venues Helper](https://docs.goteamup.com/api-reference/endpoints/venues-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
