# Retrieve Order with GoTeamup

Retrieves an order from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/store/orders/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Order](https://docs.goteamup.com/api-reference/endpoints/store-orders-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp order ID |
