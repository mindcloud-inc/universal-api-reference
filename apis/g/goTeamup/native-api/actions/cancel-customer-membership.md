# Cancel Customer Membership with GoTeamup

Cancels an existing customer membership in GoTeamup.

## Endpoint

- **Method:** `POST`
- **Path:** `/customer_memberships/:id/cancel`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Cancel Customer Membership](https://docs.goteamup.com/api-reference/endpoints/customer-memberships-cancel-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp customer membership ID |
