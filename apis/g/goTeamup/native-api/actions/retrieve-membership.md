# Retrieve Membership with GoTeamup

Retrieves a membership from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/memberships/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Membership](https://docs.goteamup.com/api-reference/endpoints/memberships)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp membership ID |
