# Get Customer Membership Usage with GoTeamup

Retrieves customer membership usage from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer_memberships/:id/usage`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Get Customer Membership Usage](https://docs.goteamup.com/api-reference/endpoints/customer-memberships-usage-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp customer membership ID |
