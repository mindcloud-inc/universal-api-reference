# Retrieve Customer with GoTeamup

Retrieves a customer from GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [Retrieve Customer](https://docs.goteamup.com/api-reference/endpoints/customers-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The TeamUp customer ID |
