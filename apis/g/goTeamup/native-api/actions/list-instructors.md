# List Instructors with GoTeamup

Finds instructors in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/instructors`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Instructors](https://docs.goteamup.com/api-reference/endpoints/instructors-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
