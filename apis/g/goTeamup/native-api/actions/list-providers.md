# List Providers with GoTeamup

Finds providers in GoTeamup.

## Endpoint

- **Method:** `GET`
- **Path:** `/providers`
- **Base URL:** `https://goteamup.com/api/v2`
- **Official documentation:** [List Providers](https://docs.goteamup.com/api-reference/endpoints/providers-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
