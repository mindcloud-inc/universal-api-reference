# List Sound Effect History with GAN.AI

Retrieves sound effect generation history from GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sfx/history`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [List Sound Effect History](https://developer.gan.ai/api-reference/sound-effects/history)

## Capabilities

This operation supports [pagination](../README.md#pagination).
