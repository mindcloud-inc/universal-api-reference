# Get Photo Avatar Details with GAN.AI

Retrieves details for a photo avatar in GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/photo_avatars/details`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Photo Avatar Details](https://developer.gan.ai/api-reference/photo-avatars/details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `photo_avatar_id` | query | `string` | yes |
