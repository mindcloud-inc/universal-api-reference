# Get Consent Passcode with GAN.AI

Retrieves a passcode for a GAN.AI consent video.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/consents/consent_passcode`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Consent Passcode](https://developer.gan.ai/api-reference/consent/get-consent-passcode)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `avatar_id` | query | `string` | yes |
