# Get LipSync Inference Details with GAN.AI

Retrieves details for a lip-sync inference in GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/lipsync/inference_details`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get LipSync Inference Details](https://developer.gan.ai/api-reference/lipsync/inference-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `inference_id` | query | `string` | yes |
