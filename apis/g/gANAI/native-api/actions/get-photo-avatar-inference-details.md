# Get Photo Avatar Inference Details with GAN.AI

Retrieves details for a photo avatar inference in GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/photo_avatars/inference_details`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Photo Avatar Inference Details](https://developer.gan.ai/api-reference/photo-avatars/inference-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `downloadable_link` | query | `boolean` | no |
| `photo_avatar_inference_id` | query | `string` | yes |
