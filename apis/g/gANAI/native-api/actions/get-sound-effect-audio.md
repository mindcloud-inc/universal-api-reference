# Get Sound Effect Audio with GAN.AI

Retrieves Base64 audio for a sound effect in GAN.AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/sfx/audio`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Sound Effect Audio](https://developer.gan.ai/api-reference/sound-effects/audio)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `inference_id` | body | `string` | yes |
