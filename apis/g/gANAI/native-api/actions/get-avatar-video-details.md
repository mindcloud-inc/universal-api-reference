# Get Avatar Video Details with GAN.AI

Retrieves details for an avatar video in GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars/inference_details`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Avatar Video Details](https://developer.gan.ai/api-reference/avatars/get-avatar-inference-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `inference_id` | query | `string` | yes |
