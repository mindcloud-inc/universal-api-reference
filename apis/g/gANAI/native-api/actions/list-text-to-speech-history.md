# List Text to Speech History with GAN.AI

Retrieves text-to-speech generation history from GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tts/history`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [List Text to Speech History](https://developer.gan.ai/api-reference/text-to-speech/tts-history)

## Capabilities

This operation supports [pagination](../README.md#pagination).
