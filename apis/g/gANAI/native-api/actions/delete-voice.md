# Delete Voice with GAN.AI

Deletes an existing voice from GAN.AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/voices/[:voice_id]`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Delete Voice](https://developer.gan.ai/api-reference/voices/delete-voice)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `voice_id` | path | `string` | yes |
