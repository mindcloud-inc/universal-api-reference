# Get Avatar Details with GAN.AI

Retrieves details for an avatar in GAN.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars/avatar_details`
- **Base URL:** `https://os.gan.ai`
- **Official documentation:** [Get Avatar Details](https://developer.gan.ai/api-reference/avatars/avatar-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `avatar_id` | query | `string` | yes |
