# Send CTA Template Message with Gupshup

Sends a CTA template WhatsApp message through Gupshup.

## Endpoint

- **Method:** `POST`
- **Path:** `/wa/api/v1/template/msg`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Send CTA Template Message](https://docs.gupshup.io/docs/template-messages)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
