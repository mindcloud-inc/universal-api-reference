# Get Business Profile About with Gupshup

Retrieves the business profile about text from Gupshup.

## Endpoint

- **Method:** `GET`
- **Path:** `/wa/app/{appId}/business/profile/about`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Get Business Profile About](https://docs.gupshup.io/reference/get-profile-about)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Gupshup app ID. |
