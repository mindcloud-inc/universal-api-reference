# Delete Business Profile Photo with Gupshup

Deletes the business profile photo from Gupshup.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/wa/app/{appId}/business/profile/photo`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Delete Business Profile Photo](https://docs.gupshup.io/reference/delete-profile-photo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Gupshup app ID. |
