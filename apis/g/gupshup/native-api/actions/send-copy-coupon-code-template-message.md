# Send Copy Coupon Code Template Message with Gupshup

Sends a copy coupon code template through Gupshup.

## Endpoint

- **Method:** `POST`
- **Path:** `/wa/api/v1/template/msg`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Send Copy Coupon Code Template Message](https://docs.gupshup.io/docs/copy-code)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
