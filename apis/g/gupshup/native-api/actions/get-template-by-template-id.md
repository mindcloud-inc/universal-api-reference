# Get Template By Template ID with Gupshup

Retrieves a template by template ID from Gupshup.

## Endpoint

- **Method:** `GET`
- **Path:** `/wa/app/{app_id}/template/{template_id}`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Get Template By Template ID](https://docs.gupshup.io/reference/get-template-by-template-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | Gupshup app ID. |
| `template_id` | path | `string` | yes | Gupshup template ID. |
