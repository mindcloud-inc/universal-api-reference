# Get Business Profile Details with Gupshup

Retrieves business profile details from Gupshup.

## Endpoint

- **Method:** `GET`
- **Path:** `/wa/app/{appId}/business/profile`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Get Business Profile Details](https://docs.gupshup.io/reference/get-profile-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | Gupshup app ID. |
