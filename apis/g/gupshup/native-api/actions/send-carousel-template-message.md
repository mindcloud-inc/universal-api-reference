# Send Carousel Template Message with Gupshup

Sends a carousel template WhatsApp message through Gupshup.

## Endpoint

- **Method:** `POST`
- **Path:** `/wa/api/v1/template/msg`
- **Base URL:** `https://api.gupshup.io`
- **Official documentation:** [Send Carousel Template Message](https://docs.gupshup.io/reference/sending-carousel-template-1)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
