# Get Payment with GoCardless

Retrieves a single payment from GoCardless.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/:identity`
- **Base URL:** `https://api-sandbox.gocardless.com`
- **Official documentation:** [Get Payment](https://developer.gocardless.com/api-reference/#payments-get-a-single-payment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identity` | path | `string` | yes |
