# Get Customer with GoCardless

Retrieves a single customer from GoCardless.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://api-sandbox.gocardless.com`
- **Official documentation:** [Get Customer](https://developer.gocardless.com/api-reference/#customers-get-a-single-customer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `string` | yes |
