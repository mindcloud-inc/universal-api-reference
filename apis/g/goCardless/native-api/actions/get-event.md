# Get Event with GoCardless

Retrieves a single event from GoCardless.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:identity`
- **Base URL:** `https://api-sandbox.gocardless.com`
- **Official documentation:** [Get Event](https://developer.gocardless.com/api-reference/#events-get-a-single-event)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `identity` | path | `string` | yes |
