# List Creditors with GoCardless

Finds creditors in your GoCardless account.

## Endpoint

- **Method:** `GET`
- **Path:** `/creditors`
- **Base URL:** `https://api-sandbox.gocardless.com`
- **Official documentation:** [List Creditors](https://developer.gocardless.com/api-reference/#creditors-list-creditors)

## Capabilities

This operation supports [pagination](../README.md#pagination).
