# List ACL Rules with Google Calendar

Retrieves calendar ACL rules from Google Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `calendars/:calendar/acl`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [List ACL Rules](https://developers.google.com/workspace/calendar/api/v3/reference/acl/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
