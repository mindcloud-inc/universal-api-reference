# Remove Calendar from List with Google Calendar

Removes a calendar from the Google Calendar list.

## Endpoint

- **Method:** `DELETE`
- **Path:** `users/me/calendarList/:calendar`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Remove Calendar from List](https://developers.google.com/workspace/calendar/api/v3/reference/calendarList/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
