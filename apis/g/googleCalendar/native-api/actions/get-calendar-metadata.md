# Get Calendar Metadata with Google Calendar

Retrieves calendar metadata from Google Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `calendars/:calendar`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Get Calendar Metadata](https://developers.google.com/workspace/calendar/api/v3/reference/calendars/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | yes |
