# Clear Calendar with Google Calendar

Deletes all events from a primary Google Calendar.

## Endpoint

- **Method:** `POST`
- **Path:** `calendars/:calendar/clear`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Clear Calendar](https://developers.google.com/workspace/calendar/api/v3/reference/calendars/clear)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
