# Get Setting with Google Calendar

Retrieves a calendar setting from Google Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `users/me/settings/:setting`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Get Setting](https://developers.google.com/workspace/calendar/api/v3/reference/settings/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `setting` | path | `string` | no |
