# Add Calendar to List with Google Calendar

Adds an existing calendar to the Google Calendar list.

## Endpoint

- **Method:** `POST`
- **Path:** `users/me/calendarList`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Add Calendar to List](https://developers.google.com/workspace/calendar/api/v3/reference/calendarList/insert)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
