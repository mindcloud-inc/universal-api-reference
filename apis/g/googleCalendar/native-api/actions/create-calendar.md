# Create Calendar with Google Calendar

Creates a secondary calendar in Google Calendar.

## Endpoint

- **Method:** `POST`
- **Path:** `calendars`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Create Calendar](https://developers.google.com/workspace/calendar/api/v3/reference/calendars/insert)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summary` | body | `string` | no |
| `timeZone` | body | `string` | no |
