# Delete ACL Rule with Google Calendar

Deletes an existing calendar ACL rule from Google Calendar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `calendars/:calendar/acl/:ruleId`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Delete ACL Rule](https://developers.google.com/workspace/calendar/api/v3/reference/acl/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
| `ruleId` | path | `string` | no |
