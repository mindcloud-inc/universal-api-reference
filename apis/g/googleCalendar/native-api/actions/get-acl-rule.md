# Get ACL Rule with Google Calendar

Retrieves a calendar ACL rule from Google Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `calendars/:calendar/acl/:ruleId`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Get ACL Rule](https://developers.google.com/workspace/calendar/api/v3/reference/acl/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
| `ruleId` | path | `string` | no |
