# Get Calendar List Entry with Google Calendar

Retrieves a calendar list entry from Google Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `users/me/calendarList/:calendar`
- **Base URL:** `https://www.googleapis.com/calendar/v3`
- **Official documentation:** [Get Calendar List Entry](https://developers.google.com/workspace/calendar/api/v3/reference/calendarList/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `calendar` | path | `list` | no |
