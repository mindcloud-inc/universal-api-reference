# Get Property Metadata with Google Analytics

## Endpoint

- **Method:** `GET`
- **Path:** `https://analyticsdata.googleapis.com/v1beta/properties/:propertyId/metadata`
- **Base URL:** `https://analyticsdata.googleapis.com/v1beta`
- **Official documentation:** [Get Property Metadata](https://developers.google.com/analytics/devguides/reporting/data/v1/rest/v1beta/properties/getMetadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `propertyId` | path | `string` | yes | GA4 property ID without the properties/ prefix |
