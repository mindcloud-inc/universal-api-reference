# Get Report Transaction with Gift Up

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/transactions/:id`
- **Base URL:** `https://api.giftup.app`
- **Official documentation:** [Get Report Transaction](https://developer.giftup.com/api#get-a-report-transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
