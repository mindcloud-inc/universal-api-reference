# Get Item Group by ID with Gift Up

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://api.giftup.app`
- **Official documentation:** [Get Item Group by ID](https://developer.giftup.com/api#get-an-item-group-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
