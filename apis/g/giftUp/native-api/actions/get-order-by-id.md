# Get Order by ID with Gift Up

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.giftup.app`
- **Official documentation:** [Get Order by ID](https://developer.giftup.com/api#get-an-order-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
