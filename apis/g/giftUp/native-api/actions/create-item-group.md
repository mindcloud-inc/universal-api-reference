# Create Item Group with Gift Up

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.giftup.app`
- **Official documentation:** [Create Item Group](https://developer.giftup.com/api#create-an-item-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
| `sortOrder` | body | `number` | no |
| `autoExpand` | body | `boolean` | no |
