# Get Gift Card by Code with Gift Up

## Endpoint

- **Method:** `GET`
- **Path:** `/gift-cards/:code`
- **Base URL:** `https://api.giftup.app`
- **Official documentation:** [Get Gift Card by Code](https://developer.giftup.com/api#get-a-gift-card-by-code)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `code` | path | `string` | yes |
