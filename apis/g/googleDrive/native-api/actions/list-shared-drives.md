# List Shared Drives with Google Drive

Retrieves shared drives from Google Drive.

## Endpoint

- **Method:** `GET`
- **Path:** `/drive/v3/drives`
- **Base URL:** `https://www.googleapis.com`
- **Official documentation:** [List Shared Drives](https://developers.google.com/workspace/drive/api/reference/rest/v3/drives/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields` | query | `string` | no |
| `pageSize` | query | `number` | no |
| `q` | query | `string` | no |
