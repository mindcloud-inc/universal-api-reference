# Get Space with GitBook

Retrieves a space's details from GitBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://api.gitbook.com/v1`
- **Official documentation:** [Get Space](https://gitbook.com/docs/developers/gitbook-api/api-reference/spaces)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | yes |
