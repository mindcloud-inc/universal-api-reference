# Get Collection with GitBook

Retrieves a collection's details from GitBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collectionId`
- **Base URL:** `https://api.gitbook.com/v1`
- **Official documentation:** [Get Collection](https://gitbook.com/docs/developers/gitbook-api/api-reference/collections)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `collectionId` | path | `string` | yes |
