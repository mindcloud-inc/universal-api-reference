# List Organizations with GitBook

Retrieves organizations available to the GitBook user.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs`
- **Base URL:** `https://api.gitbook.com/v1`
- **Official documentation:** [List Organizations](https://gitbook.com/docs/developers/gitbook-api/api-reference/organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
