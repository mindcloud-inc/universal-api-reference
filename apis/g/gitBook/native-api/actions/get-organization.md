# Get Organization with GitBook

Retrieves organization details from GitBook by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:organizationId`
- **Base URL:** `https://api.gitbook.com/v1`
- **Official documentation:** [Get Organization](https://gitbook.com/docs/developers/gitbook-api/api-reference/organizations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
