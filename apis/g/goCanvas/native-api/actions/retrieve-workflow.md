# Retrieve Workflow with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/workflows/:workflowId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Workflow](https://api.gocanvas.com/api/v3/docs#retrieve-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `number` | yes | Identifier of the workflow. |
