# List Form Shared Departments with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/shared_departments`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Form Shared Departments](https://api.gocanvas.com/api/v3/docs#shared-departments-for-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
