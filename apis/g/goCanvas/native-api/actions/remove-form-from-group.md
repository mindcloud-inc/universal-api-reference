# Remove Form from Group with GoCanvas

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:groupId/forms/:formId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Remove Form from Group](https://api.gocanvas.com/api/v3/docs#remove-form-from-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | yes |
| `formId` | path | `string` | yes |
