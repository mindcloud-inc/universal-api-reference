# Retrieve Reference Image with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/reference_images/:referenceImageId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Reference Image](https://api.gocanvas.com/api/v3/docs#retrieve-a-reference-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `referenceImageId` | path | `string` | yes | ID of the reference image. |
