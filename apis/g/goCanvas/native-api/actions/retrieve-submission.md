# Retrieve Submission with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Submission](https://api.gocanvas.com/api/v3/docs#retrieve-a-submission)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | Numeric submission ID or submission GUID. |
