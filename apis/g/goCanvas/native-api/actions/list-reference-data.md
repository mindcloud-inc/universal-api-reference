# List Reference Data with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/reference_data`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Reference Data](https://api.gocanvas.com/api/v3/docs#list-all-reference-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `department_id` | query | `number` | no | If omitted, GoCanvas returns reference data from the current user's default department. |
