# Remove User from Group with GoCanvas

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:groupId/users/:userId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Remove User from Group](https://api.gocanvas.com/api/v3/docs#remove-user-from-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | yes |
| `userId` | path | `string` | yes |
