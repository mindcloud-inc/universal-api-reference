# List Webhooks with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/webhooks`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Webhooks](https://api.gocanvas.com/api/v3/docs#list-all-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `number` | yes | Identifier of the form whose webhooks are listed. |
