# Retrieve Basic Form PDF with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/basic_pdf`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Basic Form PDF](https://api.gocanvas.com/api/v3/docs#retrieve-a-basic-form-pdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
