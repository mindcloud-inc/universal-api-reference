# List Submission Revisions with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId/revisions`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Submission Revisions](https://api.gocanvas.com/api/v3/docs#list-of-revisions-by-submission)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `number` | yes | The ID of the submission. |
