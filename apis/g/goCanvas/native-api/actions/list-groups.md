# List Groups with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Groups](https://api.gocanvas.com/api/v3/docs#list-all-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `department_id` | query | `number` | no | Defaults to the current user's default department when omitted. |
