# Retrieve Webhook with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/webhooks/:webhookId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Webhook](https://api.gocanvas.com/api/v3/docs#retrieve-a-webhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
| `webhookId` | path | `number` | yes |
