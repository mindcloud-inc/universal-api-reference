# List Forms with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Forms](https://api.gocanvas.com/api/v3/docs#list-all-forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assigned` | query | `boolean` | no | For users who manage forms, return only their assigned active forms. Has no effect for other users. |
