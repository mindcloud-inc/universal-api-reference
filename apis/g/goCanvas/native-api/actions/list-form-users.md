# List Form Users with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/assigned_users`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Form Users](https://api.gocanvas.com/api/v3/docs#assigned-users-for-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
