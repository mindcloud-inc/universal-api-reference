# List Binary Upload Statuses with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId/values`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Binary Upload Statuses](https://api.gocanvas.com/api/v3/docs#list-binary-upload-statuses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | Numeric submission ID or mobile submission GUID. |
