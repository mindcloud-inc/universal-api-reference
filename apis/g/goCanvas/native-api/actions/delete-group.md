- **Method:** `DELETE`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Delete Group](https://api.gocanvas.com/api/v3/docs#delete-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `groupId` | path | `string` | yes |
