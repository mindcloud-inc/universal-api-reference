# List Department Users with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/departments/:departmentId/users`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Department Users](https://api.gocanvas.com/api/v3/docs#list-all-department-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `departmentId` | path | `number` | yes |
