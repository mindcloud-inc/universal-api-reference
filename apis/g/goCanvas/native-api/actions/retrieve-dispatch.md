# Retrieve Dispatch with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/dispatches/:dispatchId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Dispatch](https://api.gocanvas.com/api/v3/docs#retrieve-a-dispatch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dispatchId` | path | `number` | yes | Identifier of the dispatch. |
