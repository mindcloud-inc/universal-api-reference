# List Form Reports with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/reports`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Form Reports](https://api.gocanvas.com/api/v3/docs#list-of-reports-by-form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `number` | yes |
