# List Users with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [List Users](https://api.gocanvas.com/api/v3/docs#list-all-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `enabled` | query | `boolean` | no | Leave unset to return both enabled and disabled users. |
