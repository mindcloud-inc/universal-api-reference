# Retrieve Default Submission PDF with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId/pdf`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Default Submission PDF](https://api.gocanvas.com/api/v3/docs#retrieve-the-default-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | ID of the submission. |
