# Retrieve Submission Value with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId/values/:valueId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Submission Value](https://api.gocanvas.com/api/v3/docs#retrieve-a-value)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | ID of the submission. |
| `valueId` | path | `string` | yes | ID of the media value. |
