# Retrieve Site with GoCanvas

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:siteId`
- **Base URL:** `https://www.gocanvas.com/api/v3`
- **Official documentation:** [Retrieve Site](https://api.gocanvas.com/api/v3/docs#retrieve-a-site)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `number` | yes |
