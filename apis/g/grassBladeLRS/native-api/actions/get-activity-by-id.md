# Get Activity By ID with GrassBlade LRS

Retrieves an activity by ID from GrassBlade LRS.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities`
- **Base URL:** `https://test.gblrs.com/xAPI`
- **Official documentation:** [Get Activity By ID](https://github.com/adlnet/xAPI-Spec/blob/xAPI-1.0.3/xAPI-Communication.md#activitiesres)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | query | `string` | yes | Activity ID to fetch. |
