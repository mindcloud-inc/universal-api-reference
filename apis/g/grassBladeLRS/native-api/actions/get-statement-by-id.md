# Get Statement By ID with GrassBlade LRS

Retrieves a statement by ID from GrassBlade LRS.

## Endpoint

- **Method:** `GET`
- **Path:** `/statements`
- **Base URL:** `https://test.gblrs.com/xAPI`
- **Official documentation:** [Get Statement By ID](https://github.com/adlnet/xAPI-Spec/blob/xAPI-1.0.3/xAPI-Communication.md#stmtresget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statementId` | query | `string` | no | ID of Statement to fetch. |
