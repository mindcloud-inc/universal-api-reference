# Get Gift Card with Goldbelly

## Endpoint

- **Method:** `GET`
- **Path:** `gift_cards/:code`
- **Base URL:** `https://api.goldbelly.com/v1/`
- **Official documentation:** [Get Gift Card](https://drive.google.com/file/d/1vH97uUnbEu3v2rs8JrZRi4oNAdp_uqWd/view?usp=sharing#gift_cards__code__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Gift card code to look up. |
