# Get Tracking with Goldbelly

## Endpoint

- **Method:** `GET`
- **Path:** `tracking/:order_id`
- **Base URL:** `https://api.goldbelly.com/v1/`
- **Official documentation:** [Get Tracking](https://drive.google.com/file/d/1vH97uUnbEu3v2rs8JrZRi4oNAdp_uqWd/view?usp=sharing#tracking__order_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | Goldbelly order ID to retrieve tracking information for. |
