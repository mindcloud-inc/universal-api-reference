# Get Document with Grist

Retrieves a document from Grist.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId`
- **Base URL:** `https://docs.getgrist.com/api`
- **Official documentation:** [Get Document](https://support.getgrist.com/api/#tag/docs/operation/describeDoc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID |
