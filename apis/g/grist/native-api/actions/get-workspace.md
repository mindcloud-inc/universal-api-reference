# Get Workspace with Grist

Retrieves a workspace from Grist.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceId`
- **Base URL:** `https://docs.getgrist.com/api`
- **Official documentation:** [Get Workspace](https://support.getgrist.com/api/#tag/workspaces/operation/describeWorkspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `list<number>` | yes | Workspace ID |
