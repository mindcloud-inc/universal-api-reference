# Delete Document with Grist

Deletes a document from Grist.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/:docId`
- **Base URL:** `https://docs.getgrist.com/api`
- **Official documentation:** [Delete Document](https://support.getgrist.com/api/#tag/docs/operation/deleteDoc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID |
