# List Tables with Grist

Finds tables in a Grist document.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/tables`
- **Base URL:** `https://docs.getgrist.com/api`
- **Official documentation:** [List Tables](https://support.getgrist.com/api/#tag/tables/operation/listTables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `docId` | path | `string` | yes | Document ID |
