# Get Organization with Grist

Retrieves an organization from Grist.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:orgId`
- **Base URL:** `https://docs.getgrist.com/api`
- **Official documentation:** [Get Organization](https://support.getgrist.com/api/#tag/orgs/operation/describeOrg)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `list<number>` | yes | Organization ID |
