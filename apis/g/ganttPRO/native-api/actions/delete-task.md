# Delete Task with GanttPRO

Deletes an existing task from GanttPRO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Delete Task](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `number` | yes | GanttPRO task identifier. |
