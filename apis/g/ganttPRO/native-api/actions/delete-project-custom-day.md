# Delete Project Custom Day with GanttPRO

Deletes a custom day from a GanttPRO project calendar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/customday/:customDayId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Delete Project Custom Day](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customDayId` | path | `number` | yes | GanttPRO custom day identifier. |
