# Delete Attachment with GanttPRO

Deletes an existing attachment from GanttPRO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attachments/:attachmentId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Delete Attachment](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attachmentId` | path | `number` | yes | GanttPRO attachment identifier. |
