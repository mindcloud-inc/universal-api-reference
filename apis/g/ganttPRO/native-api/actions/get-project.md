# Get Project with GanttPRO

Retrieves a project from your GanttPRO account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Get Project](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | GanttPRO project identifier. |
