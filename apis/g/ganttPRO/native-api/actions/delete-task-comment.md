# Delete Task Comment with GanttPRO

Deletes an existing task comment from GanttPRO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/comments/:commentId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Delete Task Comment](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `commentId` | path | `number` | yes | GanttPRO comment identifier. |
