# Get Task with GanttPRO

Retrieves a task from your GanttPRO account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [Get Task](https://developer.ganttpro.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `number` | yes | GanttPRO task identifier. |
