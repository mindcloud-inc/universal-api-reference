# List Project Calendars with GanttPRO

Retrieves project calendars from your GanttPRO account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/calendars`
- **Base URL:** `https://api.ganttpro.com/v1.0`
- **Official documentation:** [List Project Calendars](https://developer.ganttpro.com/index.html)
