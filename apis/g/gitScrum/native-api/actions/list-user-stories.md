# List User Stories with GitScrum

Retrieves a list of GitScrum user stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-stories`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List User Stories](https://docs.gitscrum.com/en/api/user-stories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
| `project_slug` | query | `string` | no |
