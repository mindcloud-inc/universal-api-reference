# List Effort Levels with GitScrum

Retrieves available effort levels from GitScrum.

## Endpoint

- **Method:** `GET`
- **Path:** `/project-templates/effort`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Effort Levels](https://docs.gitscrum.com/en/api/task-types)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
| `project_slug` | query | `string` | no |
