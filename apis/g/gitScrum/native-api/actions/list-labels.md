# List Labels with GitScrum

Retrieves a list of GitScrum labels.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects-labels`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Labels](https://docs.gitscrum.com/en/api/labels)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
