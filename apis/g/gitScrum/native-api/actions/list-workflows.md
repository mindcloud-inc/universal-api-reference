# List Workflows with GitScrum

Retrieves a list of GitScrum workflows.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects-workflows`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Workflows](https://docs.gitscrum.com/en/api/workflows)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
| `project_slug` | query | `string` | no |
