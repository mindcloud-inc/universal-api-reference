# List Projects with GitScrum

Retrieves a list of GitScrum projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Projects](https://docs.gitscrum.com/en/api/projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
