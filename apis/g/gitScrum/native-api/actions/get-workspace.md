# Get Workspace with GitScrum

Retrieves details for a specific GitScrum workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:slug`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [Get Workspace](https://docs.gitscrum.com/en/api/workspaces)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug` | path | `string` | yes |
