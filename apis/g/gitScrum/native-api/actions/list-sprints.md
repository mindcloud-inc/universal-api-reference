# List Sprints with GitScrum

Retrieves a list of GitScrum sprints.

## Endpoint

- **Method:** `GET`
- **Path:** `/sprints`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Sprints](https://docs.gitscrum.com/en/api/sprints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
| `project_slug` | query | `string` | no |
