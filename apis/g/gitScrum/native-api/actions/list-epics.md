# List Epics with GitScrum

Retrieves a list of GitScrum epics.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-story-epics`
- **Base URL:** `https://services.gitscrum.com`
- **Official documentation:** [List Epics](https://docs.gitscrum.com/en/api/epics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company_slug` | query | `string` | no |
| `project_slug` | query | `string` | no |
