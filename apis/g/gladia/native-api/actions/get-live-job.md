# Get Live Job with Gladia

Retrieves a live job's status, parameters, and result from Gladia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/live/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Get Live Job](https://docs.gladia.io/api-reference/v2/live/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia live job identifier. |
