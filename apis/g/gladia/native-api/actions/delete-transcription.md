# Delete Transcription with Gladia

Deletes a transcription job from Gladia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/transcription/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Delete Transcription](https://docs.gladia.io/api-reference/v2/transcription/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia transcription job identifier. |
