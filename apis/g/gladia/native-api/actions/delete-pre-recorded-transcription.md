# Delete Pre-recorded Transcription with Gladia

Deletes a pre-recorded transcription job from Gladia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/pre-recorded/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Delete Pre-recorded Transcription](https://docs.gladia.io/api-reference/v2/pre-recorded/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia pre-recorded job identifier. |
