# Delete Live Job with Gladia

Deletes a live job from Gladia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/live/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Delete Live Job](https://docs.gladia.io/api-reference/v2/live/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia live job identifier. |
