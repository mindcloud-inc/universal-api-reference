# Get Pre-recorded Transcription with Gladia

Retrieves a pre-recorded job's status, parameters, and result from Gladia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/pre-recorded/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Get Pre-recorded Transcription](https://docs.gladia.io/api-reference/v2/pre-recorded/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
