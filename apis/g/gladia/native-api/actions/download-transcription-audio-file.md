# Download Transcription Audio File with Gladia

Retrieves a transcription audio file from Gladia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transcription/:id/file`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Download Transcription Audio File](https://docs.gladia.io/api-reference/v2/transcription/get-audio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia transcription job identifier. |
