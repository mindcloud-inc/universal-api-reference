# Download Pre-recorded Audio File with Gladia

Retrieves a pre-recorded audio file from Gladia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/pre-recorded/:id/file`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Download Pre-recorded Audio File](https://docs.gladia.io/api-reference/v2/pre-recorded/get-audio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia pre-recorded job identifier. |
