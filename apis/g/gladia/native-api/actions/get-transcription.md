# Get Transcription with Gladia

Retrieves a transcription job's status, parameters, and result from Gladia.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transcription/:id`
- **Base URL:** `https://api.gladia.io`
- **Official documentation:** [Get Transcription](https://docs.gladia.io/api-reference/v2/transcription/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Gladia transcription job identifier. |
