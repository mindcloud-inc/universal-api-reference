# Stop Automation with GetSales.io

## Endpoint

- **Method:** `PUT`
- **Path:** `/flows/api/flows/{flowUuid}/stop`
- **Base URL:** `https://amazing.getsales.io`
- **Official documentation:** [Stop Automation](https://api.getsales.io/api/openapi/automations/stopflow.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `flowUuid` | path | `string` | yes | UUID of the automation to stop. |
