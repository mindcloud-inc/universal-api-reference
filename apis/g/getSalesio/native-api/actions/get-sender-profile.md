# Get Sender Profile with GetSales.io

## Endpoint

- **Method:** `GET`
- **Path:** `/flows/api/sender-profiles/{senderProfileUuid}`
- **Base URL:** `https://amazing.getsales.io`
- **Official documentation:** [Get Sender Profile](https://api.getsales.io/api/openapi/sender-profiles/getsenderprofile.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `senderProfileUuid` | path | `string` | yes | UUID of the sender profile to retrieve. |
