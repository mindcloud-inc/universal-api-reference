# List Library Elements with Grafana

Finds library elements in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/library-elements`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Library Elements](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/library_element/)
