# List User Organizations with Grafana

Finds organizations for the current user in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/orgs`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List User Organizations](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/user/)
