# Get Dashboard Tags with Grafana

Retrieves dashboard tags from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/tags`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get Dashboard Tags](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/dashboard/)
