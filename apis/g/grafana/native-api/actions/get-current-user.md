# Get Current User with Grafana

Retrieves the current user from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get Current User](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/user/)
