# Get Playlist with Grafana

Retrieves a playlist from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/playlists/:uid`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get Playlist](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/playlist/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The playlist UID. |
