# List Annotation Tags with Grafana

Retrieves annotation tags from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/annotations/tags`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Annotation Tags](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/annotations/)
