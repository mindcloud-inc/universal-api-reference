# Export Mute Timings with Grafana

Exports mute timings from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/mute-timings/export`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Export Mute Timings](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
