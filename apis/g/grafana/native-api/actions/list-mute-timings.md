# List Mute Timings with Grafana

Finds mute timings in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/mute-timings`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Mute Timings](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
