# Export Contact Points with Grafana

Exports contact points from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/contact-points/export`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Export Contact Points](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
