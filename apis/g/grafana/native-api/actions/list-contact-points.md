# List Contact Points with Grafana

Finds contact points in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/contact-points`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Contact Points](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
