# List User Teams with Grafana

Finds teams for the current user in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/teams`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List User Teams](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/user/)
