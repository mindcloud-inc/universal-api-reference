# Search Resources with Grafana

Finds folders and dashboards in Grafana by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Search Resources](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/folder_dashboard_search/)
