# Get Notification Policy Tree with Grafana

Retrieves the notification policy tree from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/policies`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get Notification Policy Tree](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
