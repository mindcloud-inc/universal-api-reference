# Get User Preferences with Grafana

Retrieves user preferences from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/preferences`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get User Preferences](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/preferences/)
