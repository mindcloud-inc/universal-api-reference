# List Search Sort Options with Grafana

Retrieves search sort options from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/sorting`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Search Sort Options](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/folder_dashboard_search/)
