# List Alert Rules with Grafana

Finds alert rules in Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/alert-rules`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [List Alert Rules](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
