# Export All Alert Rules with Grafana

Exports all alert rules from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/provisioning/alert-rules/export`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Export All Alert Rules](https://grafana.com/docs/grafana/latest/alerting/set-up/provision-alerting-resources/http-api-provisioning/)
