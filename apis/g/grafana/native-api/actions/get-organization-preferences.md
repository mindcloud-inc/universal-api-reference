# Get Organization Preferences with Grafana

Retrieves organization preferences from Grafana.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/preferences`
- **Base URL:** `https://apps78aa.grafana.net/api`
- **Official documentation:** [Get Organization Preferences](https://grafana.com/docs/grafana/latest/developer-resources/api-reference/http-api/preferences/)
