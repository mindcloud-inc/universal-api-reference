# Grafana: Export Contact Points

Exports contact points from Grafana.

```
GET https://connect.mindcloud.co/v1/universal/grafana/latest/actions/export-contact-points
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Grafana `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/grafana/latest/actions/export-contact-points?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/grafana/latest/actions/export-contact-points?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```



## Response

{
  "success": true,
  "data": [

## Native endpoint

Through the native Grafana API, this operation is `GET /v1/provisioning/contact-points/export` (base URL `https://apps78aa.grafana.net/api`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/export-contact-points.md) for the provider-specific parameters and requirements.
