# Create Asset Group with Geotab

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://{server}/apiv1`
- **Official documentation:** [Create Asset Group](https://developers.geotab.com/myGeotab/apiReference/methods/Add/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | body | `object` | yes | Complete Group entity to add. Include the parent group relationship required by MyGeotab. |
