# Delete Asset Group with Geotab

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://{server}/apiv1`
- **Official documentation:** [Delete Asset Group](https://developers.geotab.com/myGeotab/apiReference/methods/Remove/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | body | `object` | yes | Group entity to remove. The object must contain its id. |
