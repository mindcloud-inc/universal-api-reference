# Recalculate Order Commission with GoAffPro

Recalculates commission for an order in GoAffPro.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/orders/recalculate/:id`
- **Base URL:** `https://api.goaffpro.com/v1`
- **Official documentation:** [Recalculate Order Commission](https://api.goaffpro.com/docs/admin/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Order ID. |
