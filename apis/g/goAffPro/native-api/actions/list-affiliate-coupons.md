# List Affiliate Coupons with GoAffPro

Retrieves an affiliate's coupons from GoAffPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/affiliates/:id/coupons`
- **Base URL:** `https://api.goaffpro.com/v1`
- **Official documentation:** [List Affiliate Coupons](https://api.goaffpro.com/docs/admin/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Affiliate ID. |
