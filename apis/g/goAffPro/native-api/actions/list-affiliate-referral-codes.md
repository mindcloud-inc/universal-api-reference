# List Affiliate Referral Codes with GoAffPro

Retrieves an affiliate's referral codes from GoAffPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/affiliates/:id/referral_codes`
- **Base URL:** `https://api.goaffpro.com/v1`
- **Official documentation:** [List Affiliate Referral Codes](https://api.goaffpro.com/docs/admin/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Affiliate ID. |
