# Delete Task with GoodDay.work

Deletes an existing task from GoodDay.work.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/task/:taskId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Delete Task](https://www.goodday.work/developers/api-v2/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | GoodDay task ID. |
