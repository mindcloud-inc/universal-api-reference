# Get Project with GoodDay.work

Retrieves a single project from GoodDay.work.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:projectId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Get Project](https://www.goodday.work/developers/api-v2/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | GoodDay project ID. |
