# List User Hourly Rate History with GoodDay.work

Retrieves hourly rate history from GoodDay.work for a user.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId/hourly-rate-history`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [List User Hourly Rate History](https://www.goodday.work/developers/api-v2/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | GoodDay user ID. |
