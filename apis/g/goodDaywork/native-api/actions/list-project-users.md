# List Project Users with GoodDay.work

Finds users in a GoodDay.work project.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:projectId/users`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [List Project Users](https://www.goodday.work/developers/api-v2/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | GoodDay project ID. |
