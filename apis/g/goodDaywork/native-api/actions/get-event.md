# Get Event with GoodDay.work

Retrieves a single event from GoodDay.work.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:eventId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Get Event](https://www.goodday.work/developers/api-v2/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | GoodDay event ID. |
