# List Project History with GoodDay.work

Finds history entries for a GoodDay.work project.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:projectId/history`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [List Project History](https://www.goodday.work/developers/api-v2/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | GoodDay project ID. |
