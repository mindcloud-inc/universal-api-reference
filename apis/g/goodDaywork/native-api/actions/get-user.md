# Get User with GoodDay.work

Retrieves a single user from GoodDay.work.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Get User](https://www.goodday.work/developers/api-v2/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | GoodDay user ID. |
