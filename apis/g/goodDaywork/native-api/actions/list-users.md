# List Users with GoodDay.work

Finds users in the GoodDay.work workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [List Users](https://www.goodday.work/developers/api-v2/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deleted` | query | `boolean` | no | Set to true to include deleted company users. |
