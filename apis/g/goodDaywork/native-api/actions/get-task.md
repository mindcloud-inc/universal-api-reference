# Get Task with GoodDay.work

Retrieves a single task from GoodDay.work.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:taskId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Get Task](https://www.goodday.work/developers/api-v2/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | GoodDay task ID. |
