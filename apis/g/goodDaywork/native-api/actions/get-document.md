# Get Document with GoodDay.work

Retrieves a single document from GoodDay.work.

## Endpoint

- **Method:** `GET`
- **Path:** `/document/:documentId`
- **Base URL:** `https://api.goodday.work/2.0`
- **Official documentation:** [Get Document](https://www.goodday.work/developers/api-v2/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | GoodDay document ID. |
