# Geocode Address with Google Maps

## Endpoint

- **Method:** `GET`
- **Path:** `https://maps.googleapis.com/maps/api/geocode/json`
- **Official documentation:** [Geocode Address](https://developers.google.com/maps/documentation/geocoding/requests-geocoding)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `address` | query | `string` | no |
