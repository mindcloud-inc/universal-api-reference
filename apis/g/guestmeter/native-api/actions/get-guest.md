# Get Guest with Guestmeter

Retrieves guest details from Guestmeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/getGuest`
- **Base URL:** `https://www.guestmeter.com/api`
- **Official documentation:** [Get Guest](https://www.guestmeter.com/docs/api#get-guests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guestID` | query | `string` | yes | Guest ID in UUID format. |
