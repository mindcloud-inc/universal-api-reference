# List Guests with Guestmeter

Retrieves guests from Guestmeter.

## Endpoint

- **Method:** `GET`
- **Path:** `/getGuestList`
- **Base URL:** `https://www.guestmeter.com/api`
- **Official documentation:** [List Guests](https://www.guestmeter.com/docs/api#get-ratings)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
