# List Phone Types with GorillaDesk

Retrieves phone types from GorillaDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/phone-types`
- **Base URL:** `https://api.gorilladesk.com/v1`
- **Official documentation:** [List Phone Types](https://api.gorilladesk.com)

## Capabilities

This operation supports [pagination](../README.md#pagination).
