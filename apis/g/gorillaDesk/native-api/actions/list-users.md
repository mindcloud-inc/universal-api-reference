# List Users with GorillaDesk

Retrieves users from GorillaDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.gorilladesk.com/v1`
- **Official documentation:** [List Users](https://api.gorilladesk.com)

## Capabilities

This operation supports [pagination](../README.md#pagination).
