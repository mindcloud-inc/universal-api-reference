# Retrieve User with GorillaDesk

Retrieves a user from GorillaDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.gorilladesk.com/v1`
- **Official documentation:** [Retrieve User](https://api.gorilladesk.com)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | User Id |
