# Get Random Quotes with GoT Quotes

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/random/:count`
- **Base URL:** `https://api.gameofthronesquotes.xyz`
- **Official documentation:** [Get Random Quotes](https://github.com/shevabam/game-of-thrones-quotes-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `count` | path | `number` | yes |
