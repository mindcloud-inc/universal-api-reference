# Get Character with GoT Quotes

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/character/:slug`
- **Base URL:** `https://api.gameofthronesquotes.xyz`
- **Official documentation:** [Get Character](https://github.com/shevabam/game-of-thrones-quotes-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `slug` | path | `string` | yes |
