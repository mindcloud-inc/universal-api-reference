# Get Random Quote by Character with GoT Quotes

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/author/:character`
- **Base URL:** `https://api.gameofthronesquotes.xyz`
- **Official documentation:** [Get Random Quote by Character](https://github.com/shevabam/game-of-thrones-quotes-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `character` | path | `string` | yes |
