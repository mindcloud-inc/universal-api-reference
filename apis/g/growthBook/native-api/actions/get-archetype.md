# Get a single archetype with GrowthBook

Retrieves an archetype from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/archetypes/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single archetype](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
