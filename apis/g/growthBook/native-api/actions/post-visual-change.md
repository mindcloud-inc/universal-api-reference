# Create a visual change for a visual changeset with GrowthBook

Creates a visual change in a GrowthBook changeset.

## Endpoint

- **Method:** `POST`
- **Path:** `/visual-changesets/:id/visual-change`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Create a visual change for a visual changeset](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
