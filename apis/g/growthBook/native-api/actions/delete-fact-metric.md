# Deletes a single fact metric with GrowthBook

Deletes an existing fact metric from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/fact-metrics/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single fact metric](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
