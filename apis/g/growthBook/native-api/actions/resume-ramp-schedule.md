# Resume a paused ramp schedule with GrowthBook

Resumes a ramp schedule in GrowthBook.

## Endpoint

- **Method:** `POST`
- **Path:** `/ramp-schedules/:id/actions/resume`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Resume a paused ramp schedule](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
