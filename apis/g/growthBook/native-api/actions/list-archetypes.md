# Get the organization's archetypes with GrowthBook

Retrieves the organization's archetypes from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/archetypes`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get the organization's archetypes](https://docs.growthbook.io/api)
