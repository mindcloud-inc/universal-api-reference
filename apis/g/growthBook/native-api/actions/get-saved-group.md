# Get a single saved group with GrowthBook

Retrieves a saved group from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/saved-groups/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single saved group](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
