# Get all dashboards for an experiment with GrowthBook

Retrieves dashboards for a GrowthBook experiment.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/by-experiment/:experimentId`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get all dashboards for an experiment](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `experimentId` | path | `string` | yes |
