# Deletes a single attribute with GrowthBook

Deletes an existing attribute from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attributes/:property`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single attribute](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `property` | path | `string` | yes | The attribute property |
