# Get a single rampScheduleTemplate with GrowthBook

Retrieves a ramp schedule template from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/ramp-schedule-templates/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single rampScheduleTemplate](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
