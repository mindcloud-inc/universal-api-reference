# Get all visual changesets with GrowthBook

Retrieves visual changesets for a GrowthBook experiment.

## Endpoint

- **Method:** `GET`
- **Path:** `/experiments/:id/visual-changesets`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get all visual changesets](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The experiment id the visual changesets belong to |
