# Approve the current pending-approval step with GrowthBook

Approves the current step in a GrowthBook ramp schedule.

## Endpoint

- **Method:** `POST`
- **Path:** `/ramp-schedules/:id/actions/approve-step`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Approve the current pending-approval step](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
