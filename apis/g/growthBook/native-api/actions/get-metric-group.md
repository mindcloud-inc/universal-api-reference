# Get a single metricGroup with GrowthBook

Retrieves a metric group from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/metric-groups/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single metricGroup](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
