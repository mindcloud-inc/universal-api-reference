# Deletes a metric with GrowthBook

Deletes an existing metric from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/metrics/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a metric](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
