# Complete a ramp schedule immediately with GrowthBook

Completes a GrowthBook ramp schedule immediately.

## Endpoint

- **Method:** `POST`
- **Path:** `/ramp-schedules/:id/actions/complete`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Complete a ramp schedule immediately](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
