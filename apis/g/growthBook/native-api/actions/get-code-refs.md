# Get list of code references for a single feature id with GrowthBook

Retrieves code references for a GrowthBook feature.

## Endpoint

- **Method:** `GET`
- **Path:** `/code-refs/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get list of code references for a single feature id](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
