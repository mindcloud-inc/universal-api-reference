# Removes a single user from an organization with GrowthBook

Removes a member from your GrowthBook organization.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/members/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Removes a single user from an organization](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
