# Get a single dimension with GrowthBook

Retrieves a dimension from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/dimensions/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single dimension](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
