# Get a single fact table with GrowthBook

Retrieves a fact table from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/fact-tables/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single fact table](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
