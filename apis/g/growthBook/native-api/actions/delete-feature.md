# Deletes a single feature with GrowthBook

Deletes an existing feature from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/features/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single feature](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
