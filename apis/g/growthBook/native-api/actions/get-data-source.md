# Get a single data source with GrowthBook

Retrieves a data source from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/data-sources/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single data source](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
