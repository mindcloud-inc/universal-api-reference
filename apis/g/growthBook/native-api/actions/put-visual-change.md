# Update a visual change for a visual changeset with GrowthBook

Updates a visual change in a GrowthBook changeset.

## Endpoint

- **Method:** `PUT`
- **Path:** `/visual-changesets/:id/visual-change/:visualChangeId`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Update a visual change for a visual changeset](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
| `visualChangeId` | path | `string` | yes | Specify a specific visual change |
