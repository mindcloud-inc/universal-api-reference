# Get a single dashboard with GrowthBook

Retrieves a dashboard from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/dashboards/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single dashboard](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
