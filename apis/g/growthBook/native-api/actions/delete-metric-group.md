# Delete a single metricGroup with GrowthBook

Deletes an existing metric group from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/metric-groups/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Delete a single metricGroup](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
