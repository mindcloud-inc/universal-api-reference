# Get a single metric with GrowthBook

Retrieves a metric from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single metric](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
