# Find a single sdk connection by its key with GrowthBook

Retrieves an SDK connection by key from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/sdk-connections/lookup/:key`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Find a single sdk connection by its key](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The key of the requested sdkConnection |
