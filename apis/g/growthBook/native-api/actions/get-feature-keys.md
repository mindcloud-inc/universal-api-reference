# Get list of feature keys with GrowthBook

Retrieves feature keys from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/feature-keys`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get list of feature keys](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `string` | no | Filter by project id |
