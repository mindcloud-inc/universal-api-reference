# Deletes a single SDK connection with GrowthBook

Deletes an existing SDK connection from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sdk-connections/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single SDK connection](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
