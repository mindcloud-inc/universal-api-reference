# Get a single Information Schema Table by id with GrowthBook

Retrieves an information schema table from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/information-schema-tables/:tableId`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single Information Schema Table by id](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | path | `string` | yes | The id of the information schema table |
