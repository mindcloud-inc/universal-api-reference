# Get a single sdk connection with GrowthBook

Retrieves a SDK connection from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/sdk-connections/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single sdk connection](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
