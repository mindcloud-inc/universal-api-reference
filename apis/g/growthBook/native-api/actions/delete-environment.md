# Deletes a single environment with GrowthBook

Deletes an existing environment from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/environments/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single environment](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
