# Delete a single rampScheduleTemplate with GrowthBook

Deletes an existing ramp schedule template from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ramp-schedule-templates/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Delete a single rampScheduleTemplate](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
