# Get a Data Source's Information Schema with GrowthBook

Retrieves a data source information schema from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/data-sources/:dataSourceId/information-schema`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a Data Source's Information Schema](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataSourceId` | path | `string` | yes | The id of the data source |
