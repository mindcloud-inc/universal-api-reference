# Get a single customField with GrowthBook

Retrieves a custom field from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single customField](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
