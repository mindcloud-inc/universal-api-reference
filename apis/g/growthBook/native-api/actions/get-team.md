# Get a single team with GrowthBook

Retrieves a team from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a single team](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
