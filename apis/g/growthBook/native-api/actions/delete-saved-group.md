# Deletes a single saved group with GrowthBook

Deletes an existing saved group from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/saved-groups/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Deletes a single saved group](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the requested resource |
