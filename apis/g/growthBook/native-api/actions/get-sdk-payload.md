# Get a SDK payload with GrowthBook

Retrieves an SDK payload from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/sdk-payload/:key`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a SDK payload](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
