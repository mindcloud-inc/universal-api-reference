# Delete a single dashboard with GrowthBook

Deletes an existing dashboard from GrowthBook.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dashboards/:id`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Delete a single dashboard](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
