# Get all experimentTemplates with GrowthBook

Retrieves experimenttemplates from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/experiment-templates`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get all experimentTemplates](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | query | `string` | no |
