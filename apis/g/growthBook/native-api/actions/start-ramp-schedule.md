# Start a ramp schedule with GrowthBook

Starts a ramp schedule in GrowthBook.

## Endpoint

- **Method:** `POST`
- **Path:** `/ramp-schedules/:id/actions/start`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Start a ramp schedule](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
