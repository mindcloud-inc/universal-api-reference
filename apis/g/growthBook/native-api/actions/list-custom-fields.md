# Get all custom fields with GrowthBook

Retrieves custom fields from your GrowthBook organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get all custom fields](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | query | `string` | no |
