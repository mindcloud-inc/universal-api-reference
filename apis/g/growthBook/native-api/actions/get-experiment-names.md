# Get a list of experiments with names and ids with GrowthBook

Retrieves experiment names and IDs from GrowthBook.

## Endpoint

- **Method:** `GET`
- **Path:** `/experiment-names`
- **Base URL:** `https://api.growthbook.io/api/v1`
- **Official documentation:** [Get a list of experiments with names and ids](https://docs.growthbook.io/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `string` | no | Filter by project id |
