# Upload File Media with Gemini

Uploads a file to Gemini.

## Endpoint

- **Method:** `POST`
- **Path:** `v1beta/files`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Upload File Media](https://ai.google.dev/api/files#method:-media.upload)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `object` | yes | File metadata object for upload initialization. |
