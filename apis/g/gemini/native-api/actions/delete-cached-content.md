# Delete Cached Content with Gemini

Deletes a cached content resource from Gemini.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1beta/cachedContents/:cachedContentId`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Delete Cached Content](https://ai.google.dev/api/caching#method:-cachedcontents.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cachedContentId` | path | `string` | yes | Cached content ID segment (without `cachedContents/` prefix). |
