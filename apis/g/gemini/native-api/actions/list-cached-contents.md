# List Cached Contents with Gemini

Retrieves a list of cached content resources from Gemini.

## Endpoint

- **Method:** `GET`
- **Path:** `v1beta/cachedContents`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [List Cached Contents](https://ai.google.dev/api/caching#method:-cachedcontents.list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
