# List Models with Gemini

Retrieves a list of models from Gemini.

## Endpoint

- **Method:** `GET`
- **Path:** `v1beta/models`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [List Models](https://ai.google.dev/api/models#v1beta.models.list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
