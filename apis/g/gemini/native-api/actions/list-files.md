# List Files with Gemini

Retrieves a list of files from Gemini.

## Endpoint

- **Method:** `GET`
- **Path:** `v1beta/files`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [List Files](https://ai.google.dev/api/files#method:-files.list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
