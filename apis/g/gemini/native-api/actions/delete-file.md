# Delete File with Gemini

Deletes a file from Gemini.

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1beta/files/:fileId`
- **Base URL:** `https://generativelanguage.googleapis.com`
- **Official documentation:** [Delete File](https://ai.google.dev/api/files#method:-files.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File ID segment (without `files/` prefix). |
