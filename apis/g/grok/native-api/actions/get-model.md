# Get Model with Grok

Retrieves a specific model from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | Model identifier. |
