# Get Language Model with Grok

Retrieves a specific language model from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/language-models/:model_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get Language Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-language-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | Language model identifier. |
