# Get Processing Results of Batch with Grok

Retrieves processing results for a Grok batch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches/:batch_id/results`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get Processing Results of Batch](https://docs.x.ai/developers/rest-api-reference/inference/batches#get-processing-results-of-a-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch_id` | path | `string` | yes | Batch identifier. |
