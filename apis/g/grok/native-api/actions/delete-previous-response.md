# Delete Previous Response with Grok

Deletes a previous response from Grok.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/responses/:response_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Delete Previous Response](https://docs.x.ai/developers/rest-api-reference/inference/chat#delete-previous-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `response_id` | path | `string` | yes | Response identifier. |
