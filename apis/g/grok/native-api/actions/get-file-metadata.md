# Get File Metadata with Grok

Retrieves metadata for a specific Grok file.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get File Metadata](https://docs.x.ai/developers/rest-api-reference/files/manage#get-file-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File identifier. |
