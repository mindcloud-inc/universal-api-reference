# List Language Models with Grok

Retrieves a list of language models from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/language-models`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [List Language Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-language-models)
