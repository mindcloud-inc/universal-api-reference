# Update File with Grok

Updates a Grok file's metadata or content.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Update File](https://docs.x.ai/developers/rest-api-reference/files/manage#update-a-files-metadata-or-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File identifier. |
