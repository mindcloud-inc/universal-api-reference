# List Video Generation Models with Grok

Retrieves a list of video generation models from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/video-generation-models`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [List Video Generation Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-video-generation-models)
