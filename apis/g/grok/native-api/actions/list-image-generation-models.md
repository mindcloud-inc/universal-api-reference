# List Image Generation Models with Grok

Retrieves a list of image generation models from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/image-generation-models`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [List Image Generation Models](https://docs.x.ai/developers/rest-api-reference/inference/models#list-image-generation-models)
