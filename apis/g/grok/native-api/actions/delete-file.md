# Delete File with Grok

Deletes a specific file from Grok.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Delete File](https://docs.x.ai/developers/rest-api-reference/files/manage#delete-a-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File identifier. |
