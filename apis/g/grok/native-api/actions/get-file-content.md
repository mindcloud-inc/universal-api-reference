# Get File Content with Grok

Retrieves the content of a Grok file.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:file_id/content`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get File Content](https://docs.x.ai/developers/rest-api-reference/files/download#get-file-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | File identifier to download. |
