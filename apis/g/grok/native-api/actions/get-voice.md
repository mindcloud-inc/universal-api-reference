# Get Voice with Grok

Retrieves a specific voice from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tts/voices/:voice_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get Voice](https://docs.x.ai/developers/rest-api-reference/inference/voice#get-voice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `voice_id` | path | `string` | yes | Voice identifier. |
