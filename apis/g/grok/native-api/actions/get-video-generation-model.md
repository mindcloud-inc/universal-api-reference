# Get Video Generation Model with Grok

Retrieves a specific video generation model from Grok.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/video-generation-models/:model_id`
- **Base URL:** `https://api.x.ai`
- **Official documentation:** [Get Video Generation Model](https://docs.x.ai/developers/rest-api-reference/inference/models#get-video-generation-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | Video generation model identifier. |
