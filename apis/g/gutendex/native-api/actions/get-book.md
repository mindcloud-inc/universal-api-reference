# Get Book with Gutendex

Retrieves book details from Gutendex.

## Endpoint

- **Method:** `GET`
- **Path:** `/books/:bookId/`
- **Base URL:** `https://gutendex.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookId` | path | `number` | yes | Project Gutenberg book ID. |
