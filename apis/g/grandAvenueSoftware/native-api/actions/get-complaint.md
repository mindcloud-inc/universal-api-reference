# Get Complaint with Grand Avenue Software

Retrieves a complaint from Grand Avenue Software by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/Complaints/:id`
- **Base URL:** `{baseUrl}`
- **API:** REST

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `$select` | query | `list<string>` | no | Send multiple values as a string. |
| `$expand` | query | `list<string>` | no | Send multiple values as a string. |
| `id` | path | `string` | yes | — |
