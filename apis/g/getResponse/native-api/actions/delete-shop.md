# Delete Shop with GetResponse

Deletes an existing shop from GetResponse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shops/:shopId`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Delete Shop](https://apireference.getresponse.com/#operation/deleteShop)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shopId` | path | `string` | yes | The shop ID |
