# Get Account with GetResponse

Retrieves your current GetResponse account details.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Get Account](https://apireference.getresponse.com/#operation/getAccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of fields to return. |
