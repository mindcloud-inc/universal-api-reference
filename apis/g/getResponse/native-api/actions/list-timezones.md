# List Timezones with GetResponse

Retrieves the list of available GetResponse timezones.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/timezones`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [List Timezones](https://apireference.getresponse.com/#operation/getTimezones)
