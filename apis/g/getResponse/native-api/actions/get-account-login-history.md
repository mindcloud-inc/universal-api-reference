# Get Account Login History with GetResponse

Retrieves login history for your GetResponse account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/login-history`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Get Account Login History](https://apireference.getresponse.com/#operation/getAccountLoginHistory)

## Capabilities

This operation supports [pagination](../README.md#pagination).
