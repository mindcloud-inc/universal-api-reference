# List Industries with GetResponse

Retrieves available industry tags from GetResponse.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/industries`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [List Industries](https://apireference.getresponse.com/#operation/getIndustries)

## Capabilities

This operation supports [pagination](../README.md#pagination).
