# Get Shop with GetResponse

Retrieves a shop by ID from GetResponse.

## Endpoint

- **Method:** `GET`
- **Path:** `/shops/:shopId`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Get Shop](https://apireference.getresponse.com/#operation/getShopById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shopId` | path | `string` | yes | The shop ID |
| `fields` | query | `string` | no | Comma-separated list of fields to return |
