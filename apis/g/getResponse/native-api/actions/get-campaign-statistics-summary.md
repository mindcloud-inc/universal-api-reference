# Get Campaign Statistics Summary with GetResponse

Retrieves summary statistics for selected GetResponse campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/statistics/summary`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Get Campaign Statistics Summary](https://apireference.getresponse.com/#operation/getCampaignStatisticsSummary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query[campaignId]` | query | `string` | no | Filter statistics summary by campaign |
