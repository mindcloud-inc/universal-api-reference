# Get Sending Limits with GetResponse

Retrieves current sending limits from GetResponse.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/sending-limits`
- **Base URL:** `https://api.getresponse.com/v3`
- **Official documentation:** [Get Sending Limits](https://apireference.getresponse.com/#operation/getSendingLimits)
