# Get Document with GIRITON

Retrieves a specific document from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [Get Document](https://rest.giriton.com/apidoc/#/Documents/getDocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Document ID. |
