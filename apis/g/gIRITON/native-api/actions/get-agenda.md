# Get Agenda with GIRITON

Retrieves a specific agenda from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/agendas/:agendaId`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [Get Agenda](https://rest.giriton.com/apidoc/#/Agenda/getCatalog)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agendaId` | path | `string` | yes | Agenda ID. |
