# Get Person with GIRITON

Retrieves a specific person from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/person/:id`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [Get Person](https://rest.giriton.com/apidoc/#/Human%20Resources/getPerson)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Person ID. |
