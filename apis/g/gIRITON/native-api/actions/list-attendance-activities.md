# List Attendance Activities with GIRITON

Retrieves available attendance activities from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/attendance/attendanceActivities`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [List Attendance Activities](https://rest.giriton.com/apidoc/#/Attendance/getAttendanceActivities)
