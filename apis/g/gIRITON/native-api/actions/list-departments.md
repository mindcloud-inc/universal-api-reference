# List Departments with GIRITON

Retrieves a list of departments from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/hr/departments`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [List Departments](https://rest.giriton.com/apidoc/#/Human%20Resources/getDepartments)
