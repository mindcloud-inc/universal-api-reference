# List Agendas with GIRITON

Retrieves a list of agendas from GIRITON.

## Endpoint

- **Method:** `GET`
- **Path:** `/agendas`
- **Base URL:** `https://rest.giriton.com/system/api`
- **Official documentation:** [List Agendas](https://rest.giriton.com/apidoc/#/Agenda/getCatalogs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
