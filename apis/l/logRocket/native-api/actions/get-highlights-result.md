# Get Highlights Result with LogRocket

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:orgId/apps/:projectId/highlights/`
- **Base URL:** `https://api.logrocket.com/v1`
- **Official documentation:** [Get Highlights Result](https://docs.logrocket.com/docs/session-highlights-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The highlights request ID returned by Request User Highlights. |
