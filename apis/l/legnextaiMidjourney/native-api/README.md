# Legnext.ai-Midjourney: Native API Reference

A consolidated summary of Legnext.ai-Midjourney's API configuration, with links to official documentation.

- **Official docs:** https://docs.legnext.ai/getting-started/overview
- **API base URL:** `https://api.legnext.ai`

## Authentication

### API Key

Use your Legnext API key. Legnext requires the exact header x-api-key on every request.

### Credentials

- **API Key:** `apiKey` · required · Your Legnext API key from the Legnext dashboard.

Send these headers with each API request:

```http
x-api-key: <apiKey>
```

[Official authentication documentation](https://docs.legnext.ai/getting-started/quickstart)
