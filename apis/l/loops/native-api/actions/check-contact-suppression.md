# Check Contact Suppression with Loops

Retrieves contact suppression status from Loops.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/suppression`
- **Base URL:** `https://app.loops.so/api/v1`
- **Official documentation:** [Check Contact Suppression](https://loops.so/docs/api-reference/check-contact-suppression)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
| `userId` | query | `string` | no |
