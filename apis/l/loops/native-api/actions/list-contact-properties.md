# List Contact Properties with Loops

Retrieves contact properties from your Loops account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/properties`
- **Base URL:** `https://app.loops.so/api/v1`
- **Official documentation:** [List Contact Properties](https://loops.so/docs/api-reference/list-contact-properties)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list` | query | `list` | no | Accepted values: `all`, `custom`. |
