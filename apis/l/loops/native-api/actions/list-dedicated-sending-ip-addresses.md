# List Dedicated Sending IP Addresses with Loops

Retrieves dedicated sending IP addresses from Loops.

## Endpoint

- **Method:** `GET`
- **Path:** `/dedicated-sending-ips`
- **Base URL:** `https://app.loops.so/api/v1`
- **Official documentation:** [List Dedicated Sending IP Addresses](https://loops.so/docs/api-reference/dedicated-sending-ips)
