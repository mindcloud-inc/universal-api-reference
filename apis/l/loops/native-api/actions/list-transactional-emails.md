# List Transactional Emails with Loops

Retrieves transactional emails from your Loops account.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactional`
- **Base URL:** `https://app.loops.so/api/v1`
- **Official documentation:** [List Transactional Emails](https://loops.so/docs/api-reference/list-transactional-emails)

## Capabilities

This operation supports [pagination](../README.md#pagination).
