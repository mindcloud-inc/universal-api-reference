# Get Person with Livestorm

Retrieves a person from Livestorm.

## Endpoint

- **Method:** `GET`
- **Path:** `people/:id`
- **Base URL:** `https://api.livestorm.co/v1`
- **Official documentation:** [Get Person](https://developers.livestorm.co/reference/get_people-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | People ID |
