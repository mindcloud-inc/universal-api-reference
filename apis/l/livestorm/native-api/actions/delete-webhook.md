# Delete Webhook with Livestorm

Deletes an existing webhook from Livestorm.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/:id`
- **Base URL:** `https://api.livestorm.co/v1`
- **Official documentation:** [Delete Webhook](https://developers.livestorm.co/reference/delete_webhooks-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID |
