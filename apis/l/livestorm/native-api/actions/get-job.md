# Get Job with Livestorm

Retrieves a job from Livestorm.

## Endpoint

- **Method:** `GET`
- **Path:** `jobs/:id`
- **Base URL:** `https://api.livestorm.co/v1`
- **Official documentation:** [Get Job](https://developers.livestorm.co/reference/get_jobs-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Job ID |
