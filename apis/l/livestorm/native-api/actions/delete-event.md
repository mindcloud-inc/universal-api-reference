# Delete Event with Livestorm

Deletes an existing event from Livestorm.

## Endpoint

- **Method:** `DELETE`
- **Path:** `events/:id`
- **Base URL:** `https://api.livestorm.co/v1`
- **Official documentation:** [Delete Event](https://developers.livestorm.co/reference/delete_events-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Event ID |
