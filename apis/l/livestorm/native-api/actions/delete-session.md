# Delete Session with Livestorm

Deletes an existing session from Livestorm.

## Endpoint

- **Method:** `DELETE`
- **Path:** `sessions/:id`
- **Base URL:** `https://api.livestorm.co/v1`
- **Official documentation:** [Delete Session](https://developers.livestorm.co/reference/delete_sessions-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Session ID |
