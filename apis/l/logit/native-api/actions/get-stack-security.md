# Get Stack Security with Logit

Retrieves stack security details from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/security`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Security](https://logit.io/docs/developer-api/security-and-diagnostics/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stackId` | path | `string` | yes | The ID of a Logit stack. |
