# Get Stack Pipeline Config Validation with Logit

Retrieves stack pipeline validation status from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/pipeline-config/validation`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Pipeline Config Validation](https://logit.io/docs/developer-api/pipeline-configuration/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
