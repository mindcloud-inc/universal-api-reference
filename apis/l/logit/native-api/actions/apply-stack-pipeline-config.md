# Apply Stack Pipeline Config with Logit

Updates stack pipeline config in Logit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/stacks/:stackId/pipeline-config/apply`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Apply Stack Pipeline Config](https://logit.io/docs/developer-api/pipeline-configuration/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
