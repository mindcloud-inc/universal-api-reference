# List Stack Alerting Rules with Logit

Retrieves stack alerting rules from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/alerting/rules`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [List Stack Alerting Rules](https://logit.io/docs/developer-api/alerting-via-api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
