# Get Account Settings with Logit

Retrieves account settings from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/account/:accountId/settings`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Account Settings](https://logit.io/docs/developer-api/account-management/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The ID of a Logit account. |
