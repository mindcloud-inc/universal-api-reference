# Restart Stack Pipeline with Logit

Restarts a stack pipeline in Logit.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/stacks/:stackId/pipeline/restart`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Restart Stack Pipeline](https://logit.io/docs/developer-api/pipeline-configuration/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
