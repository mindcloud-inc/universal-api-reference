# Get Stack Ingestion Spans with Logit

Retrieves stack ingestion spans from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/ingestion/spans`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Ingestion Spans](https://logit.io/docs/developer-api/ingestion-statistics/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
