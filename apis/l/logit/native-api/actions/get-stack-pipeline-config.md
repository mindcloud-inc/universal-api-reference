# Get Stack Pipeline Config with Logit

Retrieves stack pipeline config from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/pipeline-config`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Pipeline Config](https://logit.io/docs/developer-api/pipeline-configuration/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
