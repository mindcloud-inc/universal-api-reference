# Get Stack Ingestion History with Logit

Retrieves stack ingestion history from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId/ingestion/history`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Ingestion History](https://logit.io/docs/developer-api/ingestion-statistics/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `stackId` | path | `string` | yes |
