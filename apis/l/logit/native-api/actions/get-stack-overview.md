# Get Stack Overview with Logit

Retrieves a stack overview from Logit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stacks/:stackId`
- **Base URL:** `https://dashboard.logit.io`
- **Official documentation:** [Get Stack Overview](https://logit.io/docs/developer-api/managing-stacks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stackId` | path | `string` | yes | The ID of a Logit stack. |
