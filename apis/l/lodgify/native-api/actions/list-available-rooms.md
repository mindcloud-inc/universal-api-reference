# List Available Rooms with Lodgify

Retrieves available room types from Lodgify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/properties/:id/rooms`
- **Base URL:** `https://api.lodgify.com`
- **Official documentation:** [List Available Rooms](https://docs.lodgify.com/reference/get_v2-properties-id-rooms)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
