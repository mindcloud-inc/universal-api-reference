# Get Booking with Lodgify

Retrieves details for a booking from Lodgify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reservation/booking/:id`
- **Base URL:** `https://api.lodgify.com`
- **Official documentation:** [Get Booking](https://docs.lodgify.com/reference/getbookingbyid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Reservation identifier from Lodgify. |
