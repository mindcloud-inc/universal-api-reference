# Get Property with Lodgify

Retrieves details for a property from Lodgify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/properties/:id`
- **Base URL:** `https://api.lodgify.com`
- **Official documentation:** [Get Property](https://docs.lodgify.com/reference/getpropertybyidv2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Lodgify property ID |
