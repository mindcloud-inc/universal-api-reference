# List Availability with Lodgify

Retrieves availability calendar data from Lodgify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/availability`
- **Base URL:** `https://api.lodgify.com`
- **Official documentation:** [List Availability](https://docs.lodgify.com/reference/getcalendarbyuser)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `property_id` | query | `number` | no |
| `room_type_id` | query | `number` | no |
