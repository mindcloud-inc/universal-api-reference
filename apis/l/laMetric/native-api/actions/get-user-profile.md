# Get User Profile with LaMetric

Retrieves the current user profile from LaMetric.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/users/me`
- **Base URL:** `https://developer.lametric.com`
- **Official documentation:** [Get User Profile](https://lametric-documentation.readthedocs.io/en/latest/reference-docs/cloud-users.html#get-user)
