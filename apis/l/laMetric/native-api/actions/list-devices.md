# List Devices with LaMetric

Retrieves devices from LaMetric.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/users/me/devices`
- **Base URL:** `https://developer.lametric.com`
- **Official documentation:** [List Devices](https://lametric-documentation.readthedocs.io/en/latest/reference-docs/cloud-users.html#get-devices)
