# Get User with Linear

Retrieves a user from Linear.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.linear.app/graphql/`
- **API:** REST
- **Official documentation:** [Get User](https://linear.app/developers/graphql#queries-and-mutations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.id` | body | `list` | yes |
