# Create Issue with Linear

Create Linear Issue.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.linear.app/graphql/`
- **API:** REST
- **Official documentation:** [Create Issue](https://linear.app/developers/graphql#queries-and-mutations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | body | `list` | no |
| `title` | body | `string` | no |
| `description` | body | `string` | no |
