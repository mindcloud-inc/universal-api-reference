# Query with Linear

Makes an authenticated raw GraphQL request to Linear.

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://api.linear.app/graphql/`
- **API:** REST
- **Official documentation:** [Query](https://linear.app/developers/graphql#queries-and-mutations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `string` | no |
| `variables` | body | `string` | no |
