# Get Structure with LightwaveRF Heating

Retrieves a structure from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/structure/{structureId}`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [Get Structure](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `structureId` | path | `string` | yes | The LightwaveRF structure identifier to retrieve. |
