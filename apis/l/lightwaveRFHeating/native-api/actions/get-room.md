# Get Room with LightwaveRF Heating

Retrieves a room from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/room/{roomId}`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [Get Room](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | yes | The LightwaveRF room identifier to retrieve. |
