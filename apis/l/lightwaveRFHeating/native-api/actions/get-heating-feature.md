# Get Heating Feature with LightwaveRF Heating

Retrieves a heating feature from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/feature/{featureId}`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [Get Heating Feature](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `featureId` | path | `string` | yes | The LightwaveRF heating feature identifier to retrieve. |
