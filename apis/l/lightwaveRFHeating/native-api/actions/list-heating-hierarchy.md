# List Heating Hierarchy with LightwaveRF Heating

Retrieves the heating hierarchy from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/hierarchy`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [List Heating Hierarchy](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
