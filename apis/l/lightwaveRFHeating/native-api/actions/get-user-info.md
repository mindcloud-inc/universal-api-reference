# Get User Info with LightwaveRF Heating

Retrieves the current user's account details from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/userinfo`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [Get User Info](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
