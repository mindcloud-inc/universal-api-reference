# List Structures with LightwaveRF Heating

Retrieves account structures from LightwaveRF Heating.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/structures`
- **Base URL:** `https://publicapi.lightwaverf.com`
- **Official documentation:** [List Structures](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
