# Get Gift with Loop & Tie

Retrieves a gift from Loop & Tie.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/gifts/:giftId`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [Get Gift](https://docs.loopandtie.com/reference/teamsteam_idgiftsid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `giftId` | path | `string` | no | The Loop & Tie gift ID. |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
