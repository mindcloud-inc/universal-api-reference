# List Schedulers with Loop & Tie

Retrieves schedulers for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/schedulers`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Schedulers](https://docs.loopandtie.com/reference/teamsteam_idschedulers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
