# List Messages with Loop & Tie

Retrieves gift messages for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/messages`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Messages](https://docs.loopandtie.com/reference/teamsteam_idmessages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
