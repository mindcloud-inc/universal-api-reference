# List Gifts with Loop & Tie

Retrieves gifts sent by a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/gifts`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Gifts](https://docs.loopandtie.com/reference/teamsteam_idgifts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
