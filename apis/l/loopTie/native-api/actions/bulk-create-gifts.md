# Bulk Create Gifts with Loop & Tie

Creates multiple gifts at once in Loop & Tie.

## Endpoint

- **Method:** `POST`
- **Path:** `/teams/:teamId/bulk/gifts`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [Bulk Create Gifts](https://docs.loopandtie.com/reference/teamsteam_idgifts-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
