# List Templates with Loop & Tie

Retrieves templates for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/templates`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Templates](https://docs.loopandtie.com/reference/teamsteam_idtemplates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
