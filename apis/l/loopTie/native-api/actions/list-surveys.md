# List Surveys with Loop & Tie

Retrieves surveys for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/surveys`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Surveys](https://docs.loopandtie.com/reference/teamsteam_idsurveys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
