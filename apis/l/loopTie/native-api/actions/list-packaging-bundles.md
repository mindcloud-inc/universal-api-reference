# List Packaging Bundles with Loop & Tie

Retrieves packaging bundles for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/custom-packaging-bundles`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Packaging Bundles](https://docs.loopandtie.com/reference/teamsteam_idcustom-packaging-bundles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
