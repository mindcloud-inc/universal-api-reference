# List Designs with Loop & Tie

Retrieves designs for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/designs`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Designs](https://docs.loopandtie.com/reference/teamsteam_iddesigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
