# List Webhooks with Loop & Tie

Retrieves webhook URLs for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/hooks`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Webhooks](https://docs.loopandtie.com/reference/teamsteam_idhooks-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
