# List Logos with Loop & Tie

Retrieves logos for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/logos`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Logos](https://docs.loopandtie.com/reference/teamsteam_idlogos)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
