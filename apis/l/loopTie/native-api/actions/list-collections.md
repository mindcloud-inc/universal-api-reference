# List Collections with Loop & Tie

Retrieves product collections for a Loop & Tie team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:teamId/collections`
- **Base URL:** `https://api.loopandtie.com/v1`
- **Official documentation:** [List Collections](https://docs.loopandtie.com/reference/teamsteam_idcollections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | no | The Loop & Tie team ID. |
