# Delete Post with Late

- **Method:** `DELETE`
- **Path:** `/posts/:postId`
- **Base URL:** `https://zernio.com/api/v1`
- **Official documentation:** [Delete Post](https://docs.zernio.com/posts/delete-post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `postId` | path | `string` | yes |
