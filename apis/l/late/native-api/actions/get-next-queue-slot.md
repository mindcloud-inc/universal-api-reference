# Get Next Queue Slot with Late

## Endpoint

- **Method:** `GET`
- **Path:** `/queue/next-slot`
- **Base URL:** `https://zernio.com/api/v1`
- **Official documentation:** [Get Next Queue Slot](https://docs.zernio.com/queue/get-next-available-slot)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `profileId` | query | `string` | yes |
| `queueId` | query | `string` | no |
