# Create Profile with Late

## Endpoint

- **Method:** `POST`
- **Path:** `/profiles`
- **Base URL:** `https://zernio.com/api/v1`
- **Official documentation:** [Create Profile](https://docs.zernio.com/profiles/create-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
| `color` | body | `string` | no |
