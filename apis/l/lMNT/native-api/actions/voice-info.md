# Voice Info with LMNT

Retrieves details for a specific voice from LMNT.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ai/voice/:id`
- **Base URL:** `https://api.lmnt.com`
- **Official documentation:** [Voice Info](https://docs.lmnt.com/api-reference/voice/voice-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the voice. |
