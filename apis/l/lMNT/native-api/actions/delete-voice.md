# Delete Voice with LMNT

Deletes an existing voice from LMNT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/ai/voice/:id`
- **Base URL:** `https://api.lmnt.com`
- **Official documentation:** [Delete Voice](https://docs.lmnt.com/api-reference/voice/delete-voice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the voice to delete. |
