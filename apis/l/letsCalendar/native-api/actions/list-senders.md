# List Senders with Let's Calendar

Retrieves sender emails from Let's Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `sender-emails`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [List Senders](https://panel.letscalendar.com/docs#apis-GETapi-lc-sender-emails)
