# Get Campaign Details with Let's Calendar

Retrieves campaign details from Let's Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `campaign/:campaignId/edit`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [Get Campaign Details](https://panel.letscalendar.com/docs#apis-GETapi-lc-campaign--campaign_id--edit)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The unique identifier of the campaign. |
