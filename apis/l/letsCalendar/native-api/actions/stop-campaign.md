# Stop Campaign with Let's Calendar

Stops an active campaign in Let's Calendar.

## Endpoint

- **Method:** `POST`
- **Path:** `stop-campaign`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [Stop Campaign](https://panel.letscalendar.com/docs#apis-POSTapi-lc-stop-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | body | `string` | yes | The unique identifier of the campaign. |
