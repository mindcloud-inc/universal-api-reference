# Update Campaign Invites with Let's Calendar

Updates and sends calendar invites in Let's Calendar.

## Endpoint

- **Method:** `POST`
- **Path:** `update-invite`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [Update Campaign Invites](https://panel.letscalendar.com/docs#apis-POSTapi-lc-update-invite)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | body | `string` | yes | The unique identifier of the campaign. |
