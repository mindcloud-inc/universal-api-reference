# List Campaigns with Let's Calendar

Retrieves campaign records from Let's Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `campaigns`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [List Campaigns](https://panel.letscalendar.com/docs#apis-GETapi-lc-campaigns)
