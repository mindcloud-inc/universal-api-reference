# List Timezones with Let's Calendar

Retrieves available timezones from Let's Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `timezone-list`
- **Base URL:** `https://panel.letscalendar.com/api/lc`
- **Official documentation:** [List Timezones](https://panel.letscalendar.com/docs#apis-GETapi-lc-timezone-list)
