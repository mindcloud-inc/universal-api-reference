# Mark Booking As Confirmed with LimoExpress

Marks a booking as confirmed in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/mark-booking-as-confirmed`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Mark Booking As Confirmed](https://api.limoexpress.me/api/docs/v1#/Website%20Integration/markBookingAsConfirmed)
