# List Booking Statuses with LimoExpress

Retrieves booking statuses from the LimoExpress organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/booking-statuses`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [List Booking Statuses](https://api.limoexpress.me/api/docs/v1#/Bookings/getAllBookingStatuses)
