# Update Client with LimoExpress

Updates an existing client in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/clients`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Update Client](https://api.limoexpress.me/api/docs/v1#/Clients/updateAOrganisationClient)
