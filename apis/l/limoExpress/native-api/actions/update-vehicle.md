# Update Vehicle with LimoExpress

Updates an existing vehicle in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/vehicles`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Update Vehicle](https://api.limoexpress.me/api/docs/v1#/Vehicles/updateAOrganisationVehicle)
