# Create Booking with LimoExpress

Creates a new booking in LimoExpress.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/integration/bookings`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Create Booking](https://api.limoexpress.me/api/docs/v1#/Bookings/createBooking)
