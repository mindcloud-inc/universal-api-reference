# Delete Vehicle with LimoExpress

Deletes an existing vehicle from LimoExpress.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/integration/vehicles`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Delete Vehicle](https://api.limoexpress.me/api/docs/v1#/Vehicles/deleteAOrganisationVehicle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Identifier of the vehicle to delete. |
