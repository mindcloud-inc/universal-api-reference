# Delete Client with LimoExpress

Deletes an existing client from LimoExpress.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/integration/clients`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Delete Client](https://api.limoexpress.me/api/docs/v1#/Clients/deleteAOrganisationClient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Identifier of the client to delete. |
