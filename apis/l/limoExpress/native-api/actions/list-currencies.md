# List Currencies with LimoExpress

Retrieves organization currencies from the LimoExpress platform.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/currencies`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [List Currencies](https://api.limoexpress.me/api/docs/v1#/Currencies/getAllOrganisationCurrencies)
