# Create Payment Method with LimoExpress

Creates a new payment method in LimoExpress.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/integration/payment-methods`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Create Payment Method](https://api.limoexpress.me/api/docs/v1#/Payment%20Methods/createAOrganisationPaymentMethod)
