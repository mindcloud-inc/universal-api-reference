# List Booking Types with LimoExpress

Retrieves booking types from the LimoExpress organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/integration/booking-types`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [List Booking Types](https://api.limoexpress.me/api/docs/v1#/Bookings/getAllBookingTypes)
