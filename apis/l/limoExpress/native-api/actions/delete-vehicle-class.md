# Delete Vehicle Class with LimoExpress

Deletes an existing vehicle class from LimoExpress.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/integration/vehicle-classes`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Delete Vehicle Class](https://api.limoexpress.me/api/docs/v1#/Vehicle%20Classes/deleteAOrganisationVehicleClass)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Identifier of the vehicle class to delete. |
