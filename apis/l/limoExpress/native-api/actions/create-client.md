# Create Client with LimoExpress

Creates a new client in LimoExpress.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/integration/clients`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Create Client](https://api.limoexpress.me/api/docs/v1#/Clients/createAOrganisationClient)
