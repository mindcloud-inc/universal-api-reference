# Mark Invoice As Paid with LimoExpress

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/invoices/mark-as-paid`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Mark Invoice As Paid](https://api.limoexpress.me/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Identifier of the invoice to mark as paid. |
