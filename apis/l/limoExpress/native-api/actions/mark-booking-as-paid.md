# Mark Booking As Paid with LimoExpress

Marks a booking as paid in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/mark-booking-as-paid`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Mark Booking As Paid](https://api.limoexpress.me/api/docs/v1#/Website%20Integration/markBookingAsPaid)
