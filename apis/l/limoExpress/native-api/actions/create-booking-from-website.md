# Create Booking from Website with LimoExpress

Creates a website booking in LimoExpress.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/integration/booking-with-fees`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Create Booking from Website](https://api.limoexpress.me/api/docs/v1#/Website%20Integration/createBookingFromWebsite)
