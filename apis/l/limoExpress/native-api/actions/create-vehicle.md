# Create Vehicle with LimoExpress

Creates a new vehicle in LimoExpress.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/integration/vehicles`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Create Vehicle](https://api.limoexpress.me/api/docs/v1#/Vehicles/createAOrganisationVehicle)
