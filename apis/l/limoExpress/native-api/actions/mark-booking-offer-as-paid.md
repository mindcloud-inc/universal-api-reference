# Mark Booking Offer As Paid with LimoExpress

Marks a booking offer as paid in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/booking-offers/mark-as-paid`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Mark Booking Offer As Paid](https://api.limoexpress.me/api/docs/v1#/Booking%20Offers/markBookingOfferAsPaid)
