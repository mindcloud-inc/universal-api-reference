# Update Booking with LimoExpress

Updates an existing booking in LimoExpress.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/integration/bookings`
- **Base URL:** `https://api.limoexpress.me`
- **Official documentation:** [Update Booking](https://api.limoexpress.me/api/docs/v1#/Bookings/updateBooking)
