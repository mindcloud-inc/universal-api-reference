# Verify Email Address with Listclean

Retrieves an email verification result from Listclean.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify/email/:email`
- **Base URL:** `https://api.listclean.xyz/v1`
- **Official documentation:** [Verify Email Address](https://api.listclean.xyz/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email address to verify. |
