# Update Account Profile with Listclean

Updates account profile details in Listclean.

## Endpoint

- **Method:** `POST`
- **Path:** `/account/profile/`
- **Base URL:** `https://api.listclean.xyz/v1`
- **Official documentation:** [Update Account Profile](https://api.listclean.xyz/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | body | `string` | no | Profile address. |
| `billing_address` | body | `string` | no | Billing address. |
| `billing_company_name` | body | `string` | no | Billing company name. |
| `billing_name` | body | `string` | no | Billing name. |
| `city` | body | `string` | no | Profile city. |
| `company_name` | body | `string` | no | Company name. |
| `country` | body | `string` | no | Profile country. |
| `linkedin` | body | `string` | no | LinkedIn profile. |
| `name` | body | `string` | no | First name of the user. |
| `phone_number` | body | `string` | no | Profile phone number. |
| `skype_id` | body | `string` | no | Skype ID. |
| `twitter_handle` | body | `string` | no | Twitter handle. |
| `website` | body | `string` | no | Website. |
