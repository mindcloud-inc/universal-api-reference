# Get List Information with Listclean

Retrieves verification list details from Listclean.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:list_id`
- **Base URL:** `https://api.listclean.xyz/v1`
- **Official documentation:** [Get List Information](https://api.listclean.xyz/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `number` | yes | List ID to retrieve. |
