# Delete List with Listclean

Deletes a verification list from Listclean.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:list_id`
- **Base URL:** `https://api.listclean.xyz/v1`
- **Official documentation:** [Delete List](https://api.listclean.xyz/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `number` | yes | List ID to delete. |
