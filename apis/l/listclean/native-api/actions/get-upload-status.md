# Get Upload Status with Listclean

Retrieves CSV upload status from Listclean.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/:upload_id`
- **Base URL:** `https://api.listclean.xyz/v1`
- **Official documentation:** [Get Upload Status](https://api.listclean.xyz/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `upload_id` | path | `number` | yes | Upload ID to check. |
