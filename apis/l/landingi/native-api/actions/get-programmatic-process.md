# Get Programmatic Process with Landingi

Retrieves a programmatic process from Landingi by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/landing-page/programmatic/processes/:processUuid`
- **Base URL:** `https://api.landingi.com/v2`
- **Official documentation:** [Get Programmatic Process](https://api.landingi.com/v2/docs#tag/programmatic-lp/operation/getProgrammaticLandingPageProcess)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `processUuid` | path | `string` | yes | Programmatic process UUID. |
