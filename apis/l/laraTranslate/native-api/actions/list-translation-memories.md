# List translation memories with Lara Translate

Retrieves translation memories from Lara Translate.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://mcp-v2.laratranslate.com/v1`
- **Official documentation:** [List translation memories](https://developers.laratranslate.com/docs/manage-translation-memories)
