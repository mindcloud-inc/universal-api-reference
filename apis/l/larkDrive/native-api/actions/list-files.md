# List Files with Lark Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/drive/v1/files`
- **Base URL:** `https://open.larksuite.com/open-apis`
- **Official documentation:** [List Files](https://open.larksuite.com/document/uAjLw4CM/ukTMukTMukTM/reference/drive-v1/file/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folder_token` | query | `string` | no |
| `page_size` | query | `number` | no |
| `page_token` | query | `string` | no |
