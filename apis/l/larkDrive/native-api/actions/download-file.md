# Download File with Lark Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/drive/v1/files/:file_token/download`
- **Base URL:** `https://open.larksuite.com/open-apis`
- **Official documentation:** [Download File](https://open.larksuite.com/document/uAjLw4CM/ukTMukTMukTM/reference/drive-v1/file/download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_token` | path | `string` | yes |
