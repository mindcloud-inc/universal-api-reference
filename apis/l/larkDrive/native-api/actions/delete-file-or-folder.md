# Delete File or Folder with Lark Drive

## Endpoint

- **Method:** `DELETE`
- **Path:** `/drive/v1/files/:file_token`
- **Base URL:** `https://open.larksuite.com/open-apis`
- **Official documentation:** [Delete File or Folder](https://open.larksuite.com/document/uAjLw4CM/ukTMukTMukTM/reference/drive-v1/file/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_token` | path | `string` | yes |
| `type` | query | `string` | yes |
