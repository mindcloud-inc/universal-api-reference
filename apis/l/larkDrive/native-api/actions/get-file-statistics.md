# Get File Statistics with Lark Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/drive/v1/files/:file_token/statistics`
- **Base URL:** `https://open.larksuite.com/open-apis`
- **Official documentation:** [Get File Statistics](https://open.larksuite.com/document/uAjLw4CM/ukTMukTMukTM/reference/drive-v1/file-statistics/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_token` | path | `string` | yes |
| `file_type` | query | `string` | yes |
