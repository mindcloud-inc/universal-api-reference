# Get Usage Metrics with LLMWhisperer

Retrieves account usage metrics from LLMWhisperer.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-usage-info`
- **Base URL:** `https://llmwhisperer-api.us-central.unstract.com/api/v2`
- **Official documentation:** [Get Usage Metrics](https://docs.unstract.com/llmwhisperer/llm_whisperer/apis/llm_whisperer_usage_api/)
