# Get Campaign By Name with Loopy Loyalty

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/name/:name`
- **Base URL:** `https://api.loopyloyalty.com/v1`
- **Official documentation:** [Get Campaign By Name](https://developer.loopyloyalty.com/#operation/LoopyLoyalty_getCampaignByName)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Campaign name to look up. |
