# Push Latest Campaign Changes with Loopy Loyalty

## Endpoint

- **Method:** `POST`
- **Path:** `/campaign/:id/push`
- **Base URL:** `https://api.loopyloyalty.com/v1`
- **Official documentation:** [Push Latest Campaign Changes](https://developer.loopyloyalty.com/#operation/LoopyLoyalty_pushChangesToCards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID to push updated changes to. |
