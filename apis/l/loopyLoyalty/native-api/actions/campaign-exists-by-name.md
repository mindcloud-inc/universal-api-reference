# Campaign Exists By Name with Loopy Loyalty

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/exists/:name`
- **Base URL:** `https://api.loopyloyalty.com/v1`
- **Official documentation:** [Campaign Exists By Name](https://developer.loopyloyalty.com/#operation/LoopyLoyalty_campaignExists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Campaign name to check. |
