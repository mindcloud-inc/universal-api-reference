# Delete Card By ID with Loopy Loyalty

- **Method:** `DELETE`
- **Path:** `/card/cid/:id/delete`
- **Base URL:** `https://api.loopyloyalty.com/v1`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
