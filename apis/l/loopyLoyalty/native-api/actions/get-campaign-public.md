# Get Campaign Public with Loopy Loyalty

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/public/:id`
- **Base URL:** `https://api.loopyloyalty.com/v1`
- **Official documentation:** [Get Campaign Public](https://developer.loopyloyalty.com/#operation/LoopyLoyalty_getCampaignPublic)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Published campaign ID. |
