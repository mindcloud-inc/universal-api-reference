# Re-Sync Card with Loopy Loyalty

## Endpoint

- **Method:** `PUT`
- **Path:** `/card/cid/:cid/resync`
- **Base URL:** `https://api.loopyloyalty.com/v1`
- **Official documentation:** [Re-Sync Card](https://developer.loopyloyalty.com/#operation/LoopyLoyalty_resyncCard)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cid` | path | `string` | yes |
