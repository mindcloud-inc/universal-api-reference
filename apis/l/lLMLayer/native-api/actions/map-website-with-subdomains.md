# Map Website with Subdomains with LLMLayer

Retrieves discovered website and subdomain URLs from LLMLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/map`
- **Base URL:** `https://api.llmlayer.dev`
- **Official documentation:** [Map Website with Subdomains](https://docs.llmlayer.ai/api-reference/endpoint/map)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Website URL to map. |
