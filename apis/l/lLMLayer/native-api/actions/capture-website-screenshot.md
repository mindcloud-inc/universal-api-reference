# Capture Website Screenshot with LLMLayer

Captures a website screenshot with LLMLayer.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/scrape`
- **Base URL:** `https://api.llmlayer.dev`
- **Official documentation:** [Capture Website Screenshot](https://docs.llmlayer.ai/api-reference/endpoint/scrape)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Website URL to capture. |
