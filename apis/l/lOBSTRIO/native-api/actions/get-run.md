# Get Run with LOBSTR.IO

Retrieves a run from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/runs/:run_hash`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Get Run](https://docs.lobstr.io/docs/get-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_hash` | path | `string` | yes | The unique identifier (hash) of the run. |
