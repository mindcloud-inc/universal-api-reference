# Get Account Details with LOBSTR.IO

Retrieves account details from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:account_hash`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Get Account Details](https://docs.lobstr.io/docs/get-account-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_hash` | path | `string` | yes | The unique identifier (hash) of the account. |
