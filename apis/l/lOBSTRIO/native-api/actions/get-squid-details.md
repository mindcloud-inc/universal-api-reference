# Get Squid Details with LOBSTR.IO

Retrieves squid details from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/squids/:squid_hash`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Get Squid Details](https://docs.lobstr.io/docs/get-squid-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `squid_hash` | path | `string` | yes | The unique identifier (hash) of the squid. |
