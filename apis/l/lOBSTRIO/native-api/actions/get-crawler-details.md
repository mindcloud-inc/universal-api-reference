# Get Crawler Details with LOBSTR.IO

Retrieves crawler details from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/crawlers/:crawler_hash`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Get Crawler Details](https://docs.lobstr.io/docs/get-crawler-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `crawler_hash` | path | `string` | yes | The unique identifier (hash) of the crawler. |
