# List Accounts with LOBSTR.IO

Retrieves accounts from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [List Accounts](https://docs.lobstr.io/docs/list-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
