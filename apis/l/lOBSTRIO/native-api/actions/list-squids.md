# List Squids with LOBSTR.IO

Retrieves squids from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/squids`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [List Squids](https://docs.lobstr.io/docs/list-squids)

## Capabilities

This operation supports [pagination](../README.md#pagination).
