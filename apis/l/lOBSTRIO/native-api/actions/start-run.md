# Start Run with LOBSTR.IO

Starts a new run in LOBSTR.IO.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/runs`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Start Run](https://docs.lobstr.io/docs/start-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `squid` | body | `string` | yes | The squid hash ID to run. |
