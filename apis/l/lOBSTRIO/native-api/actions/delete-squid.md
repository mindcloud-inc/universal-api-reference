# Delete Squid with LOBSTR.IO

Deletes an existing squid from LOBSTR.IO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/squids/:squid_hash`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [Delete Squid](https://docs.lobstr.io/docs/delete-squid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `squid_hash` | path | `string` | yes | The unique identifier (hash) of the squid. |
