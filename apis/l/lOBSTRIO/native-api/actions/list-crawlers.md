# List Crawlers with LOBSTR.IO

Retrieves crawlers from LOBSTR.IO.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/crawlers`
- **Base URL:** `https://api.lobstr.io`
- **Official documentation:** [List Crawlers](https://docs.lobstr.io/docs/list-crawlers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
