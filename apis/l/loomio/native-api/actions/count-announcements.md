# Count Announcements with Loomio

Counts announcements in Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/announcements/count`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Count Announcements](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/announcements_controller.rb)
