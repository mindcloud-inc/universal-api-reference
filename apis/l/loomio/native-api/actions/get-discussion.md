# Get Discussion with Loomio

Retrieves a discussion from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/discussions/:id`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Get Discussion](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/discussions_controller.rb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Loomio discussion ID. |
