# Browse Discussion Templates with Loomio

Retrieves discussion templates from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/discussion_templates/browse`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Browse Discussion Templates](https://github.com/loomio/loomio/blob/master/config/routes.rb)
