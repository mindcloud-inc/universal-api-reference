# List Announcement History with Loomio

Retrieves announcement history from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/announcements/history`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Announcement History](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/announcements_controller.rb)
