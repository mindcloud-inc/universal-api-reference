# List Discussions with Loomio

Retrieves discussions from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/discussions`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Discussions](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/discussions_controller.rb)
