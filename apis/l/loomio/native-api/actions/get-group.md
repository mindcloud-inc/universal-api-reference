# Get Group with Loomio

Retrieves a group from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Get Group](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/groups_controller.rb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The Loomio group ID. |
