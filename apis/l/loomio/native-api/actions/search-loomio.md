# Search Loomio with Loomio

Finds results in Loomio by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Search Loomio](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/search_controller.rb)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | The search query. |
