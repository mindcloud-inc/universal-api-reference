# List Profile Groups with Loomio

Retrieves profile groups from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/groups`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Profile Groups](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/profile_controller.rb)
