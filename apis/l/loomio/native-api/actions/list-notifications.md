# List Notifications with Loomio

Retrieves notifications from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Notifications](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/notifications_controller.rb)
