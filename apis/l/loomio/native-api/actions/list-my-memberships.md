# List My Memberships with Loomio

Retrieves your memberships from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/memberships/my_memberships`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List My Memberships](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/memberships_controller.rb)
