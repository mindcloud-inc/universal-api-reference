# List Direct Discussions with Loomio

Retrieves direct discussions from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/discussions/direct`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Direct Discussions](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/discussions_controller.rb)
