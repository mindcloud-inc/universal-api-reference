# List All Time Zones with Loomio

Retrieves all time zones from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/all_time_zones`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List All Time Zones](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/profile_controller.rb)
