# Browse Poll Templates with Loomio

Retrieves poll templates from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/poll_templates/browse`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [Browse Poll Templates](https://github.com/loomio/loomio/blob/master/config/routes.rb)
