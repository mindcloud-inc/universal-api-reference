# List Time Zones with Loomio

Retrieves time zones from Loomio.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile/time_zones`
- **Base URL:** `https://www.loomio.com/api/v1`
- **Official documentation:** [List Time Zones](https://github.com/loomio/loomio/blob/master/app/controllers/api/v1/profile_controller.rb)
