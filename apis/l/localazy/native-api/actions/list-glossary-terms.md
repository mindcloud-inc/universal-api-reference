# List Glossary Terms with Localazy

Retrieves glossary terms from a Localazy project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/glossary`
- **Base URL:** `https://api.localazy.com`
- **Official documentation:** [List Glossary Terms](https://localazy.com/docs/api/glossary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Localazy project id or slug. |
