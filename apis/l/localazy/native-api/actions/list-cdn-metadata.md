# List CDN Metadata with Localazy

Retrieves CDN metadata from a Localazy project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/cdn`
- **Base URL:** `https://api.localazy.com`
- **Official documentation:** [List CDN Metadata](https://localazy.com/docs/api/cdn)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Localazy project identifier or slug. |
