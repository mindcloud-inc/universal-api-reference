# List Project Files with Localazy

Retrieves project files from Localazy.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/files`
- **Base URL:** `https://api.localazy.com`
- **Official documentation:** [List Project Files](https://localazy.com/docs/api/files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Localazy project id or slug. |
