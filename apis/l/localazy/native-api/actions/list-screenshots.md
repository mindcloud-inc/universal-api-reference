# List Screenshots with Localazy

Retrieves screenshots from a Localazy project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/screenshots`
- **Base URL:** `https://api.localazy.com`
- **Official documentation:** [List Screenshots](https://localazy.com/docs/api/screenshot-management)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Localazy project identifier or slug. |
