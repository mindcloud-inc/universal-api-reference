# List Screenshot Tags with Localazy

Retrieves screenshot tags from a Localazy project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/screenshots/tags`
- **Base URL:** `https://api.localazy.com`
- **Official documentation:** [List Screenshot Tags](https://localazy.com/docs/api/screenshot-management)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Localazy project identifier or slug. |
