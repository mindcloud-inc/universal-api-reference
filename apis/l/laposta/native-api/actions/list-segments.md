# List Segments with Laposta

Retrieves segments from Laposta.

## Endpoint

- **Method:** `GET`
- **Path:** `/segment`
- **Base URL:** `https://api.laposta.nl/v2`
- **Official documentation:** [List Segments](https://api.laposta.nl/doc/index.en.php#segments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | query | `string` | yes | The ID of the list whose segments to list. |
