# Delete List with Laposta

Deletes an existing list from Laposta.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/list/:listId`
- **Base URL:** `https://api.laposta.nl/v2`
- **Official documentation:** [Delete List](https://api.laposta.nl/doc/index.en.php#lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | The ID of the list to delete. |
