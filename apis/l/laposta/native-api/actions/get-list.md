# Get List with Laposta

Retrieves a list from Laposta.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/:listId`
- **Base URL:** `https://api.laposta.nl/v2`
- **Official documentation:** [Get List](https://api.laposta.nl/doc/index.en.php#lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | The ID of the list to retrieve. |
