# List Fields with Laposta

Retrieves custom fields from Laposta.

## Endpoint

- **Method:** `GET`
- **Path:** `/field`
- **Base URL:** `https://api.laposta.nl/v2`
- **Official documentation:** [List Fields](https://api.laposta.nl/doc/index.en.php#fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | query | `string` | yes | The ID of the list whose fields to list. |
