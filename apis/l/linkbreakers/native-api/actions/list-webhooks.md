# List Webhooks with Linkbreakers

Retrieves a list of webhooks from Linkbreakers.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://api.linkbreakers.com`
- **Official documentation:** [List Webhooks](https://linkbreakers.com/help/api/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Filter webhooks by status. |
