# Delete a Link with Linkbreakers

Deletes an existing link from Linkbreakers.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/links/:id`
- **Base URL:** `https://api.linkbreakers.com`
- **Official documentation:** [Delete a Link](https://linkbreakers.com/help/api/links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the link to delete. |
