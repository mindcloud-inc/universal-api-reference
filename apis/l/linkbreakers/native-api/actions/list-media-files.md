# List Media Files with Linkbreakers

Retrieves a list of media files from Linkbreakers.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/media`
- **Base URL:** `https://api.linkbreakers.com`
- **Official documentation:** [List Media Files](https://linkbreakers.com/help/api/media)

## Capabilities

This operation supports [pagination](../README.md#pagination).
