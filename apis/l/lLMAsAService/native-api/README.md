# LLM as a Service: Native API Reference

A consolidated summary of LLM as a Service's API configuration, with links to official documentation.

- **Official docs:** https://help.llmasaservice.io/docs/category/developers/
- **API base URL:** `https://chat.llmasaservice.io`

## Authentication

### Project ID

Connect with your LLM as a Service project ID.

### Credentials

- **Project ID:** `projectId` · required · Your LLM as a Service project ID from the Integration page.

[Official authentication documentation](https://help.llmasaservice.io/docs/developers/useLLM%20React%20Hook/)

## API conventions

Request bodies use plain text.

Shared headers:

| Header | Value |
| --- | --- |
| `Content-Type` | `text/plain` |
