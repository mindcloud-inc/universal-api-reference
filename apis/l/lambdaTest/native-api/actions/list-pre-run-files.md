# List Pre-Run Files with LambdaTest

Retrieves pre-run files from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [List Pre-Run Files](https://swagger-api-support.lambdatest.com/index.html)
