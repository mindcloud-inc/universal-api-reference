# Validate Pre-Run File with LambdaTest

Checks whether a pre-run file is approved by LambdaTest.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/validate`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Validate Pre-Run File](https://swagger-api-support.lambdatest.com/index.html)
