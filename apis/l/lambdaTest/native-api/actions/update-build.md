# Update Build with LambdaTest

Updates an existing build in LambdaTest.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/builds/{build_id}`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Update Build](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `build_id` | path | `string` | yes | The LambdaTest build ID. |
