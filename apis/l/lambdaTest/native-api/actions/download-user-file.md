# Download User File with LambdaTest

Downloads a user file from LambdaTest.

## Endpoint

- **Method:** `PUT`
- **Path:** `/user-files/download`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Download User File](https://swagger-api-support.lambdatest.com/index.html)
