# Get Test Exceptions with LambdaTest

## Endpoint

- **Method:** `POST`
- **Path:** `/tests/{test_id}/exceptions`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Test Exceptions](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `test_id` | path | `string` | no | The LambdaTest test identifier. |
