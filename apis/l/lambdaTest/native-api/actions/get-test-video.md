# Get Test Video with LambdaTest

Retrieves a test video from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/test/{test_id}/video`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Test Video](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `test_id` | path | `string` | no | The LambdaTest test identifier. |
