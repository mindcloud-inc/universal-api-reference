# Get Geolocation IPs with LambdaTest

Retrieves geolocation IPs from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/geoLocation/ips`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Geolocation IPs](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `country_code` | query | `string` | no | The ISO country code to fetch LambdaTest geolocation IPs for. |
