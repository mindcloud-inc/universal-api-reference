# Get Session Selenium Logs with LambdaTest

Retrieves session selenium logs from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{session_id}/log/selenium`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Session Selenium Logs](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | no | The LambdaTest session identifier. |
