# Download Session Network HAR V2 with LambdaTest

Retrieves a session network HAR file v2 from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{session_id}/v2/log/network.har`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Download Session Network HAR V2](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | no | The LambdaTest session identifier. |
