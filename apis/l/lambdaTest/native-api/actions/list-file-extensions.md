# List File Extensions with LambdaTest

Retrieves file extensions from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/extensions`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [List File Extensions](https://swagger-api-support.lambdatest.com/index.html)
