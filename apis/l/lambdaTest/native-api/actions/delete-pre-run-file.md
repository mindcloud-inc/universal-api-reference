# Delete Pre-Run File with LambdaTest

Deletes a pre-run file from LambdaTest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/delete`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Delete Pre-Run File](https://swagger-api-support.lambdatest.com/index.html)
