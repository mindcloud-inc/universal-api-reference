# List Resolutions with LambdaTest

Retrieves platform resolutions from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/resolutions`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [List Resolutions](https://swagger-api-support.lambdatest.com/index.html)
