# Delete Tunnel with LambdaTest

Deletes an existing tunnel from LambdaTest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tunnels/{tunnel_id}`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Delete Tunnel](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tunnel_id` | path | `string` | no | The LambdaTest tunnel identifier. |
