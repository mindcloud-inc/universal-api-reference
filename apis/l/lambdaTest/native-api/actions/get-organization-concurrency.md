# Get Organization Concurrency with LambdaTest

Retrieves organization concurrency from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/concurrency`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Organization Concurrency](https://swagger-api-support.lambdatest.com/index.html)
