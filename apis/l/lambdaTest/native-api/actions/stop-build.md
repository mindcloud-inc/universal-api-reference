# Stop Build with LambdaTest

Stops a build in LambdaTest.

## Endpoint

- **Method:** `PUT`
- **Path:** `/build/stop`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Stop Build](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `build` | query | `string` | yes | The LambdaTest build ID to stop. |
