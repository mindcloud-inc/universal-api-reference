# Download Session Full HAR with LambdaTest

Retrieves a session full HAR file from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{session_id}/log/full-har`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Download Session Full HAR](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | no | The LambdaTest session identifier. |
