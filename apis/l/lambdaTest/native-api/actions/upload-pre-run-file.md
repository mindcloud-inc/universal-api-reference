# Upload Pre-Run File with LambdaTest

Uploads a pre-run file to LambdaTest.

## Endpoint

- **Method:** `POST`
- **Path:** `/files`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Upload Pre-Run File](https://swagger-api-support.lambdatest.com/index.html)
