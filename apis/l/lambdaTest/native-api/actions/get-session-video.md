# Get Session Video with LambdaTest

Retrieves a session video from LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/{session_id}/video`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Session Video](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | no | The LambdaTest session identifier. |
