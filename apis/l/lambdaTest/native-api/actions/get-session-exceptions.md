# Get Session Exceptions with LambdaTest

## Endpoint

- **Method:** `POST`
- **Path:** `/sessions/{session_id}/exceptions`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Session Exceptions](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | no | The LambdaTest session identifier. |
