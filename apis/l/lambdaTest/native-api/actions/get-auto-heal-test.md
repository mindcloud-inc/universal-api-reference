# Get Auto-Heal Test with LambdaTest

Retrieves auto-healed commands for a test in LambdaTest.

## Endpoint

- **Method:** `GET`
- **Path:** `/autoheal/test/{test_id}`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Get Auto-Heal Test](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `test_id` | path | `string` | no | The LambdaTest test identifier. |
