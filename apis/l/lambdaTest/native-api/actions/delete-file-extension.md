# Delete File Extension with LambdaTest

Deletes a file extension from LambdaTest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/extensions/delete`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Delete File Extension](https://swagger-api-support.lambdatest.com/index.html)
