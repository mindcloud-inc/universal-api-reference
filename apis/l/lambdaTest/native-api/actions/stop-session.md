# Stop Session with LambdaTest

Stops a session in LambdaTest.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sessions/{session_id}/stop`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Stop Session](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | The LambdaTest session ID. |
