# Download Pre-Run File with LambdaTest

Downloads a pre-run file from LambdaTest.

## Endpoint

- **Method:** `PUT`
- **Path:** `/files/download`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Download Pre-Run File](https://swagger-api-support.lambdatest.com/index.html)
