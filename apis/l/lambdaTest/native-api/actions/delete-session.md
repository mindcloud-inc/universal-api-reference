# Delete Session with LambdaTest

Deletes an existing session from LambdaTest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sessions/{session_id}`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Delete Session](https://swagger-api-support.lambdatest.com/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | The LambdaTest session ID. |
