# Upload File Extension with LambdaTest

Uploads a file extension to LambdaTest.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/extensions`
- **Base URL:** `https://api.lambdatest.com/automation/api/v1`
- **Official documentation:** [Upload File Extension](https://swagger-api-support.lambdatest.com/index.html)
