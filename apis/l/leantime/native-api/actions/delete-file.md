# Delete File with Leantime

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `{workspaceUrl}/api/jsonrpc`
- **Official documentation:** [Delete File](https://docs.leantime.io/api/classes/Leantime/Domain/Files/Services/Files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | body | `number` | yes | The Leantime file id to delete. |
