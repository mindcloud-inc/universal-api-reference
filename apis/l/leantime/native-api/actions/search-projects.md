# Search Projects with Leantime

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `{workspaceUrl}/api/jsonrpc`
- **Official documentation:** [Search Projects](https://docs.leantime.io/api/classes/Leantime/Domain/Projects/Services/Projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `params.term` | body | `string` | no | Project name text to search for. |
