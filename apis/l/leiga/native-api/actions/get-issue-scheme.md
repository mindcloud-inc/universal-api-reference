# Get Issue Scheme with Leiga

Retrieves an issue scheme from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/issue-scheme`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Issue Scheme](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741834.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueTypeId` | query | `number` | yes | Issue Type ID |
| `projectId` | query | `number` | yes | Project ID |
