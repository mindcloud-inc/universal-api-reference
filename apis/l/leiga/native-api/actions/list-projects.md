# List Projects with Leiga

Retrieves a list of projects from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/list`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Projects](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741813.md)
