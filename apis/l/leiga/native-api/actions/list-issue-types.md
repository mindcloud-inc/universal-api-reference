# List Issue Types with Leiga

Retrieves a list of issue types from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/type-list`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Issue Types](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741831.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `number` | yes | Project ID |
