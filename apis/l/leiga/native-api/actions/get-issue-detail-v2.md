# Get Issue Detail V2 with Leiga

Retrieves detailed issue information from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/v2/get`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Issue Detail V2](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-4820314.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Issue ID |
