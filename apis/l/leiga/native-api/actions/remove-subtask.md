# Remove Subtask with Leiga

Deletes an existing subtask from Leiga.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/issue/remove-subtask`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Remove Subtask](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741843.md)
