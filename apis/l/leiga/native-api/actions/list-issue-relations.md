# List Issue Relations with Leiga

Retrieves issue relations for an issue in Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/relationship-list`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Issue Relations](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741841.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Issue ID |
