# Update Issue with Leiga

Updates an existing issue in Leiga.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/issue/update`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Update Issue](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741832.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Issue Field Values |
| `id` | body | `number` | yes | Issue ID |
