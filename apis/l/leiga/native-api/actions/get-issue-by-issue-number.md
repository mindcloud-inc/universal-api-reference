# Get Issue by Issue Number with Leiga

Retrieves an issue from Leiga by issue number.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/get-by-issue-number`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Issue by Issue Number](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741837.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueNumber` | query | `string` | yes | Issue Number |
