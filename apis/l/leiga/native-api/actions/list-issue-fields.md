# List Issue Fields with Leiga

Retrieves a list of issue fields from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/issue-fields`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Issue Fields](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741830.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueTypeId` | query | `number` | yes | Issue Type ID |
| `projectId` | query | `number` | yes | Project ID |
