# List Project Sprints with Leiga

Retrieves sprints for a project in Leiga.

## Endpoint

- **Method:** `POST`
- **Path:** `/sprint/list-with-count`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Project Sprints](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741860.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | body | `number` | yes | Project ID |
