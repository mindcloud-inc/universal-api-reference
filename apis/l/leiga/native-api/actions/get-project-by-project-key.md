# Get Project by Project Key with Leiga

Retrieves a project from Leiga by project key.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/get-by-project-key`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Project by Project Key](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741828.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectKey` | query | `string` | yes | Project Key |
