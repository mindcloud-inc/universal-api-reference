# Search Issues V2 with Leiga

Finds issues in Leiga using structured project filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/issue/v2/page`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Search Issues V2](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-4700180.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | body | `number` | yes | Project ID |
