# Remove Issue with Leiga

Deletes an existing issue from Leiga.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/issue/remove`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Remove Issue](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741838.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Issue ID |
