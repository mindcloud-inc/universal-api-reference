# Update Subtask with Leiga

Updates an existing subtask in Leiga.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/issue/update-subtask`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Update Subtask](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741844.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Subtask Data |
| `id` | body | `number` | yes | Subtask ID |
