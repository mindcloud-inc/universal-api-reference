# Update Project with Leiga

Updates an existing project in Leiga.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/project/update`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Update Project](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741817.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Project ID |
