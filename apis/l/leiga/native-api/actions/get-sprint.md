# Get Sprint with Leiga

Retrieves detailed sprint information from Leiga.

## Endpoint

- **Method:** `GET`
- **Path:** `/sprint/get`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Sprint](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741861.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Sprint ID |
