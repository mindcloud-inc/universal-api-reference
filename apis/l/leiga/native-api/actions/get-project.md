# Get Project with Leiga

Retrieves a project from Leiga by project ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/get`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Get Project](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741827.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | query | `number` | yes | Project ID |
