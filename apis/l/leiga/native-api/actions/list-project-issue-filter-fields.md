# List Project Issue Filter Fields with Leiga

Retrieves issue filter fields for a project in Leiga.

## Endpoint

- **Method:** `POST`
- **Path:** `/issue/filter-condition-field`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [List Project Issue Filter Fields](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741840.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | body | `number` | yes | Project ID |
