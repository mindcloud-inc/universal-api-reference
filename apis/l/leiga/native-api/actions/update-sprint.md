# Update Sprint with Leiga

Updates an existing sprint in Leiga.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/sprint/update`
- **Base URL:** `https://app.leiga.com/openapi/api`
- **Official documentation:** [Update Sprint](https://share.apidog.com/5a741107-c211-410f-880c-048d1917c984/api-3741852.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Sprint Name |
| `id` | body | `number` | yes | Sprint ID |
