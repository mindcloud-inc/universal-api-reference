# List Events with LightwaveRF Events

Retrieves registered event webhook subscriptions from LightwaveRF Events.

## Endpoint

- **Method:** `GET`
- **Path:** `events`
- **Base URL:** `https://publicapi.lightwaverf.com/v1/`
- **Official documentation:** [List Events](https://support.lightwaverf.com/knowledge/link-plus-smart-series-api)
