# List Hierarchy with LightwaveRF Power

Retrieves the structure hierarchy from LightwaveRF Power.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/hierarchy`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Hierarchy](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
