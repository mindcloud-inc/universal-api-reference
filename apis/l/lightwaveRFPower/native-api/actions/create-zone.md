# Create Zone with LightwaveRF Power

Creates a new zone in LightwaveRF Power.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/zone`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [Create Zone](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the new zone. |
