# Get Favourite with LightwaveRF Power

Retrieves a favourite from LightwaveRF Power.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/favourite/{favouriteId}`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [Get Favourite](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `favouriteId` | path | `string` | yes | The LightwaveRF favourite identifier to retrieve. |
