# List Snapshots with Lokalise

Retrieves snapshots from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/snapshots`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Snapshots](https://developers.lokalise.com/reference/list-all-snapshots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
