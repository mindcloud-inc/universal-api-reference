# List Keys with Lokalise

Retrieves keys from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/keys`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Keys](https://developers.lokalise.com/reference/list-all-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
