# Download Files Async with Lokalise

Starts an asynchronous file download in Lokalise.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/files/async-download`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Download Files Async](https://developers.lokalise.com/reference/download-files-async)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
