# Update Key with Lokalise

Updates an existing key in Lokalise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/projects/:project_id/keys/:key_id`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Update Key](https://developers.lokalise.com/reference/update-a-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key_id` | path | `string` | no | Lokalise key identifier. |
| `project_id` | path | `string` | no | Lokalise project identifier. |
