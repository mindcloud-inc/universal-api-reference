# Update Project with Lokalise

Updates an existing project in Lokalise.

## Endpoint

- **Method:** `PUT`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Update Project](https://developers.lokalise.com/reference/update-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
