# Retrieve Screenshot with Lokalise

Retrieves a screenshot from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/screenshots/:screenshot_id`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Retrieve Screenshot](https://developers.lokalise.com/reference/retrieve-a-screenshot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
| `screenshot_id` | path | `string` | no | Lokalise screenshot identifier. |
