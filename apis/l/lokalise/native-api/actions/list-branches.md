# List Branches with Lokalise

Retrieves branches from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/branches`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Branches](https://developers.lokalise.com/reference/list-all-branches)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
