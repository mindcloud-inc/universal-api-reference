# Create Screenshots with Lokalise

Creates screenshots in a Lokalise project.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/screenshots`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Create Screenshots](https://developers.lokalise.com/reference/create-screenshots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
