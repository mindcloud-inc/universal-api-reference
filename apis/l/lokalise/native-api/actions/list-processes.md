# List Processes with Lokalise

Retrieves processes from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/processes`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Processes](https://developers.lokalise.com/reference/list-all-processes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
