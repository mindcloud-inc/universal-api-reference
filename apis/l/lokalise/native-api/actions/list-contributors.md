# List Contributors with Lokalise

Retrieves contributors from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/contributors`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Contributors](https://developers.lokalise.com/reference/list-all-contributors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
