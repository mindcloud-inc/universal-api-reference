# Create Snapshot with Lokalise

Creates a snapshot in a Lokalise project.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/snapshots`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Create Snapshot](https://developers.lokalise.com/reference/create-a-snapshot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
