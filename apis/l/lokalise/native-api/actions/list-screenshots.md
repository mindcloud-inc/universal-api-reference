# List Screenshots with Lokalise

Retrieves screenshots from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/screenshots`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Screenshots](https://developers.lokalise.com/reference/list-all-screenshots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
