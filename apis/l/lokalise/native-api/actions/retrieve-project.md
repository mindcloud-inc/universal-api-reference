# Retrieve Project with Lokalise

Retrieves a project from Lokalise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Retrieve Project](https://developers.lokalise.com/reference/retrieve-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
