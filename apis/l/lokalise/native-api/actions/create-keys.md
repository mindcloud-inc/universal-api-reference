# Create Keys with Lokalise

Creates keys in a Lokalise project.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/keys`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Create Keys](https://developers.lokalise.com/reference/create-keys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
