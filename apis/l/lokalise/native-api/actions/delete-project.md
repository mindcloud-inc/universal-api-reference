# Delete Project with Lokalise

Deletes an existing project from Lokalise.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Delete Project](https://developers.lokalise.com/reference/delete-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
