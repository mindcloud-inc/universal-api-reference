# List Project Languages with Lokalise

Retrieves project languages from Lokalise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/languages`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Project Languages](https://developers.lokalise.com/reference/list-project-languages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
