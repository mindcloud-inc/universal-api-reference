# Create Contributors with Lokalise

Creates contributors in a Lokalise project.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/contributors`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [Create Contributors](https://developers.lokalise.com/reference/create-contributors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Lokalise project identifier. |
