# List Translations with Lokalise

Retrieves translations from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/translations`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Translations](https://developers.lokalise.com/reference/list-all-translations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
