# List Tasks with Lokalise

Retrieves tasks from a Lokalise project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/tasks`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Tasks](https://developers.lokalise.com/reference/list-all-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Lokalise project identifier. |
