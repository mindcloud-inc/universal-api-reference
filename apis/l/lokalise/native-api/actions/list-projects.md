# List Projects with Lokalise

Retrieves projects from Lokalise.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.lokalise.com/api2`
- **Official documentation:** [List Projects](https://developers.lokalise.com/reference/list-all-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
