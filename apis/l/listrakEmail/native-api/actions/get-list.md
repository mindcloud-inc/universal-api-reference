- **Method:** `GET`

- **Base URL:** `https://api.listrak.com/email`
- **Official documentation:** [Get List](https://api.listrak.com/email#tag/List)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listID` | path | `string` | yes |
