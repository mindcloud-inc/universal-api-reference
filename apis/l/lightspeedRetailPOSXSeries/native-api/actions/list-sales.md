# List Sales with Lightspeed Retail POS (X-Series)

Retrieves sales from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/sales`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Sales](https://x-series-api.lightspeedhq.com/reference/listsales)
