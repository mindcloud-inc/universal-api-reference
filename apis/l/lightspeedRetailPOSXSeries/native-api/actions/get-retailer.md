# Get Retailer with Lightspeed Retail POS (X-Series)

Retrieves retailer information from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2026-04/retailer`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Get Retailer](https://x-series-api.lightspeedhq.com/reference/getretailer)
