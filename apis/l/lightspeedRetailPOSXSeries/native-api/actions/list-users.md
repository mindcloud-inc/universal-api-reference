# List Users with Lightspeed Retail POS (X-Series)

Retrieves users from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/users`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Users](https://x-series-api.lightspeedhq.com/reference/listusers)
