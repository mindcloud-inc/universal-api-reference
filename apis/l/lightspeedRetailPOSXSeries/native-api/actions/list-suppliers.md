# List Suppliers with Lightspeed Retail POS (X-Series)

Retrieves suppliers from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/suppliers`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Suppliers](https://x-series-api.lightspeedhq.com/reference/listsuppliers)
