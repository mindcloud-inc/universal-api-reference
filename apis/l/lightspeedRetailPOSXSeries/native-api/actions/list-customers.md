# List Customers with Lightspeed Retail POS (X-Series)

Retrieves customers from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/customers`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Customers](https://x-series-api.lightspeedhq.com/reference/listcustomers)
