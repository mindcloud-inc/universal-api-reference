# Get Current User with Lightspeed Retail POS (X-Series)

Retrieves the current user from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/user`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Get Current User](https://x-series-api.lightspeedhq.com/reference/getuser)
