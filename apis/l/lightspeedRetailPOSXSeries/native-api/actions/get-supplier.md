# Get Supplier with Lightspeed Retail POS (X-Series)

Retrieves a supplier from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/suppliers/:supplier_id`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Get Supplier](https://x-series-api.lightspeedhq.com/reference/getsupplierbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplier_id` | path | `string` | yes | The supplier ID. |
