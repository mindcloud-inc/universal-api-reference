# List Outlets with Lightspeed Retail POS (X-Series)

Retrieves outlets from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/outlets`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Outlets](https://x-series-api.lightspeedhq.com/reference/listoutlets)
