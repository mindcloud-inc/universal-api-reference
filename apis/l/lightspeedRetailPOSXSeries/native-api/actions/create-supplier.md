# Create Supplier with Lightspeed Retail POS (X-Series)

Creates a new supplier in Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `POST`
- **Path:** `/api/2.0/suppliers`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Create Supplier](https://x-series-api.lightspeedhq.com/reference/createsupplier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The supplier name. |
