# Get Webhook with Lightspeed Retail POS (X-Series)

Retrieves a webhook from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/webhooks/:webhookId`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Get Webhook](https://x-series-api.lightspeedhq.com/reference/get-webhooks-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The webhook ID. |
