# List Products with Lightspeed Retail POS (X-Series)

Retrieves products from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/products`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Products](https://x-series-api.lightspeedhq.com/reference/listproducts)
