# List Webhooks with Lightspeed Retail POS (X-Series)

Retrieves webhooks from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/webhooks`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Webhooks](https://x-series-api.lightspeedhq.com/reference/get-webhooks)
