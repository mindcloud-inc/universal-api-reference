# List Registers with Lightspeed Retail POS (X-Series)

Retrieves registers from Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `GET`
- **Path:** `/api/2.0/registers`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [List Registers](https://x-series-api.lightspeedhq.com/reference/listregisters)
