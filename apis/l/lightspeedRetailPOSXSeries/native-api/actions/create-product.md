# Create Product with Lightspeed Retail POS (X-Series)

Creates a new product in Lightspeed Retail POS (X-Series).

## Endpoint

- **Method:** `POST`
- **Path:** `/api/2.0/products`
- **Base URL:** `https://{domain_prefix}.retail.lightspeed.app`
- **Official documentation:** [Create Product](https://x-series-api.lightspeedhq.com/reference/createproduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The product name. |
