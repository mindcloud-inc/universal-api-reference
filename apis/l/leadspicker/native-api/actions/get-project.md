# Get Project with Leadspicker

Retrieves a project from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/projects/:project_id`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Project](https://app.leadspicker.com/app/sb/api/docs#/Project/apps_salesbooster_api_project_detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | Leadspicker project identifier. |
