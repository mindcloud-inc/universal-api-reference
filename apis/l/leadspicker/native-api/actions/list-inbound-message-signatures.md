# List Inbound Message Signatures with Leadspicker

Retrieves inbound message signatures from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/inbound-messages/signatures`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Inbound Message Signatures](https://app.leadspicker.com/app/sb/api/docs#/Replies/apps_salesbooster_api_inbound_message_signatures)
