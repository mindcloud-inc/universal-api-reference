# Get Current User Info with Leadspicker

Retrieves current user information from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/auth/me`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Current User Info](https://app.leadspicker.com/app/sb/api/docs#/Auth/apps_salesbooster_api_me)
