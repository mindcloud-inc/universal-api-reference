# List Webhooks with Leadspicker

Retrieves webhooks from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/webhooks`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Webhooks](https://app.leadspicker.com/app/sb/api/docs#/Notifications/apps_salesbooster_api_webhook_list)
