# List API Changelog Entries with Leadspicker

Retrieves API changelog entries from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/api-changelog`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List API Changelog Entries](https://app.leadspicker.com/app/sb/api/docs#/API%20Changelog/apps_salesbooster_api_list_api_changelog)
