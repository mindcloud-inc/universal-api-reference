# List Sequence Templates with Leadspicker

Retrieves sequence templates from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/sequence/templates`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Sequence Templates](https://app.leadspicker.com/app/sb/api/docs#/Email%20Sequence/apps_salesbooster_api_sequence_template_list)
