# List LinkedIn Accounts with Leadspicker

Retrieves LinkedIn accounts from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/linkedin-accounts`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List LinkedIn Accounts](https://app.leadspicker.com/app/sb/api/docs#/Outreach%20Accounts/apps_salesbooster_api_linkedin_accounts)
