# Get Person Communication with Leadspicker

Retrieves communication for a person in Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/persons/:person_id/communication`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Person Communication](https://app.leadspicker.com/app/sb/api/docs#/Communication/apps_salesbooster_api_person_communication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `number` | yes | Leadspicker person identifier. |
