# List Sequence Messages with Leadspicker

Retrieves sequence messages from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/sequence`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Sequence Messages](https://app.leadspicker.com/app/sb/api/docs#/Email%20Sequence/apps_salesbooster_api_sequence_list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | query | `number` | no | Optional project identifier for sequence messages. |
