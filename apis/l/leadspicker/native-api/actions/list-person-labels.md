# List Person Labels with Leadspicker

Retrieves person labels from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/person-labels`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Person Labels](https://app.leadspicker.com/app/sb/api/docs#/Person%20Labels/apps_salesbooster_api_person_labels)
