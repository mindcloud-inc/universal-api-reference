# List Notifications with Leadspicker

Retrieves notifications from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/notifications`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Notifications](https://app.leadspicker.com/app/sb/api/docs#/Notifications/apps_salesbooster_api_notifications_list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum notifications to return. |
| `offset` | query | `number` | no | Number of notifications to skip. |
