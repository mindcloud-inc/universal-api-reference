# Get Person Summary with Leadspicker

Retrieves a simplified person record from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/persons-simple/:person_id`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Person Summary](https://app.leadspicker.com/app/sb/api/docs#/Person/apps_salesbooster_api_persons_simple_detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `number` | yes | Leadspicker person identifier. |
