# Get Person with Leadspicker

Retrieves a person from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/persons/:person_id`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Person](https://app.leadspicker.com/app/sb/api/docs#/Person/apps_salesbooster_api_person_detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `number` | yes | Leadspicker person identifier. |
