# Get Sequence Message with Leadspicker

Retrieves a sequence message from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/sequence/:sequence_id`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [Get Sequence Message](https://app.leadspicker.com/app/sb/api/docs#/Email%20Sequence/apps_salesbooster_api_sequence_detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sequence_id` | path | `number` | yes | Leadspicker sequence message identifier. |
