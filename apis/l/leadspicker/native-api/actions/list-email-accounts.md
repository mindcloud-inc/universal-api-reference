# List Email Accounts with Leadspicker

Retrieves email accounts from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/email-accounts`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Email Accounts](https://app.leadspicker.com/app/sb/api/docs#/Outreach%20Accounts/apps_salesbooster_api_email_accounts)
