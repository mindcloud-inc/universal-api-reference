# List Dashboard Event Types with Leadspicker

Retrieves dashboard timeline event types from Leadspicker.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/sb/api/dashboard/event-types`
- **Base URL:** `https://app.leadspicker.com`
- **Official documentation:** [List Dashboard Event Types](https://app.leadspicker.com/app/sb/api/docs#/Dashboard/apps_salesbooster_api_dashboard_event_types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `time_frame` | query | `string` | no | Dashboard event-type time frame filter. |
