# Get Template with LaunchNotes

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://app.launchnotes.io`
- **Official documentation:** [Get Template](https://developer.launchnotes.com/index.html#query-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Template identifier. |
