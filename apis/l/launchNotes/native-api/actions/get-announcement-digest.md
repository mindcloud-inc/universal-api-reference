# Get Announcement Digest with LaunchNotes

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://app.launchnotes.io`
- **Official documentation:** [Get Announcement Digest](https://developer.launchnotes.com/index.html#query-announcementDigest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Announcement digest identifier. |
