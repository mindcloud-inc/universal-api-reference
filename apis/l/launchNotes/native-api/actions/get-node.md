# Get Node with LaunchNotes

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://app.launchnotes.io`
- **Official documentation:** [Get Node](https://developer.launchnotes.com/index.html#query-node)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Node identifier. |
