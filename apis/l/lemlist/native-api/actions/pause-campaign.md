# Pause Campaign with lemlist

Pauses an existing campaign in lemlist.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:campaignId/pause`
- **Base URL:** `https://api.lemlist.com/api`
- **Official documentation:** [Pause Campaign](https://developer.lemlist.com/api-reference/endpoints/campaigns/pause-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The ID of the campaign to pause. |
