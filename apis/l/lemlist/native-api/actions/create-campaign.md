# Create Campaign with lemlist

Creates a new campaign in lemlist.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns`
- **Base URL:** `https://api.lemlist.com/api`
- **Official documentation:** [Create Campaign](https://developer.lemlist.com/api-reference/endpoints/campaigns/create-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The name of the campaign to create. |
