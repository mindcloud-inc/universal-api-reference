# Start Campaign with lemlist

Starts an existing campaign in lemlist.

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:campaignId/start`
- **Base URL:** `https://api.lemlist.com/api`
- **Official documentation:** [Start Campaign](https://developer.lemlist.com/api-reference/endpoints/campaigns/start-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The ID of the campaign to start. |
