# List Collections with LinkTwin

Retrieves your saved collections from LinkTwin.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [List Collections](https://linktw.in/developers#list-collections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Per page data result. |
| `page` | query | `number` | no | Current page request. |
