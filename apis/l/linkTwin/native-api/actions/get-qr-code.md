# Get QR Code with LinkTwin

Retrieves a QR code from LinkTwin.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr/:id`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Get QR Code](https://linktw.in/developers#get-a-single-qr-code)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
