# Create Pixel with LinkTwin

Creates a new tracking pixel in LinkTwin.

## Endpoint

- **Method:** `POST`
- **Path:** `/pixel/add`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Create Pixel](https://linktw.in/developers#create-a-pixel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `type` | body | `string` | yes |
| `name` | body | `string` | yes |
| `tag` | body | `string` | yes |
