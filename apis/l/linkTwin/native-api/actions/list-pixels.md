# List Pixels with LinkTwin

Retrieves your tracking pixels from LinkTwin.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixels`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [List Pixels](https://linktw.in/developers#list-pixels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
