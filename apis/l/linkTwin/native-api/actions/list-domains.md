# List Domains with LinkTwin

Retrieves standard and branded domains from LinkTwin.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [List Domains](https://linktw.in/developers#list-all-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
