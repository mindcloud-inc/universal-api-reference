# Delete Link with LinkTwin

Deletes an existing link from LinkTwin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/url/:id/delete`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Delete Link](https://linktw.in/developers#delete-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Link ID. |
