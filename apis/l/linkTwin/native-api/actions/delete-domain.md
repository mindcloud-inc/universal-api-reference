# Delete Domain with LinkTwin

Deletes an existing branded domain from LinkTwin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domain/:id/delete`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Delete Domain](https://linktw.in/developers#delete-domain)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
