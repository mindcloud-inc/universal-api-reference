# Get Pixel with LinkTwin

Retrieves a pixel and its assigned links from LinkTwin.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixel/:id`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Get Pixel](https://linktw.in/developers#get-single-pixel)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
