# Delete Pixel with LinkTwin

Deletes an existing pixel from LinkTwin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pixel/:id/delete`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Delete Pixel](https://linktw.in/developers#delete-pixel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
