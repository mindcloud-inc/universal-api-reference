# Delete QR Code with LinkTwin

Deletes an existing QR code from LinkTwin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qr/:id/delete`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Delete QR Code](https://linktw.in/developers#delete-a-qr-code)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
