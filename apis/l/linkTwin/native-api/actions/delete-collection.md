# Delete Collection with LinkTwin

Deletes an existing collection from LinkTwin and unassigns its items.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collection/:id/delete`
- **Base URL:** `https://linktw.in/api`
- **Official documentation:** [Delete Collection](https://linktw.in/developers#delete-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Collection ID. |
