# Get Referral Info with LessonBuddy

Retrieves referral bonus information for a family in LessonBuddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/family/families/referral-info/:familyId`
- **Base URL:** `https://api.lessonbuddy.com`
- **Official documentation:** [Get Referral Info](https://www.postman.com/bigblueswimschool/documentation/4169241-f58a8184-3099-4d87-9da8-9bd2639880a8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `familyId` | path | `number` | yes | LessonBuddy family ID. |
