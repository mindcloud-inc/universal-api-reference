# Get Active Campaign with LessonBuddy

Retrieves the active campaign for a location in LessonBuddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/campaign/campaigns/location/:locationId/active`
- **Base URL:** `https://api.lessonbuddy.com`
- **Official documentation:** [Get Active Campaign](https://www.postman.com/bigblueswimschool/documentation/4169241-f58a8184-3099-4d87-9da8-9bd2639880a8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `number` | yes | LessonBuddy location ID. |
