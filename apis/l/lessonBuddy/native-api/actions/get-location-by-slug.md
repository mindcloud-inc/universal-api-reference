# Get Location By Slug with LessonBuddy

Retrieves a location from LessonBuddy by slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/location/locations/slug/:slug`
- **Base URL:** `https://api.lessonbuddy.com`
- **Official documentation:** [Get Location By Slug](https://www.postman.com/bigblueswimschool/documentation/4169241-f58a8184-3099-4d87-9da8-9bd2639880a8)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | LessonBuddy location slug. |
