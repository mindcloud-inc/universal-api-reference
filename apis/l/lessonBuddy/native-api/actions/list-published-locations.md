# List Published Locations with LessonBuddy

Retrieves published locations from LessonBuddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/location/locations/published`
- **Base URL:** `https://api.lessonbuddy.com`
- **Official documentation:** [List Published Locations](https://www.postman.com/bigblueswimschool/documentation/4169241-f58a8184-3099-4d87-9da8-9bd2639880a8)
