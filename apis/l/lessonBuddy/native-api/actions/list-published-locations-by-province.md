# List Published Locations By Province with LessonBuddy

Retrieves published locations grouped by province in LessonBuddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/location/locations/published/by-province`
- **Base URL:** `https://api.lessonbuddy.com`
- **Official documentation:** [List Published Locations By Province](https://www.postman.com/bigblueswimschool/documentation/4169241-f58a8184-3099-4d87-9da8-9bd2639880a8)
