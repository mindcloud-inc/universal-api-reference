# List Inbox Webhooks with LaGrowthMachine

Retrieves inbox webhooks from LaGrowthMachine.

## Endpoint

- **Method:** `GET`
- **Path:** `/inboxWebhooks`
- **Base URL:** `https://apiv2.lagrowthmachine.com/flow`
- **Official documentation:** [List Inbox Webhooks](https://documenter.getpostman.com/view/2071164/TVCmSkH2)
