# Get Campaign Stats with LaGrowthMachine

Retrieves campaign stats from LaGrowthMachine.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/stats`
- **Base URL:** `https://apiv2.lagrowthmachine.com/flow`
- **Official documentation:** [Get Campaign Stats](https://documenter.getpostman.com/view/2071164/TVCmSkH2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Campaign ID. |
