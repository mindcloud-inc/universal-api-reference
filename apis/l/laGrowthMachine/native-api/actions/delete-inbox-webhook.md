# Delete Inbox Webhook with LaGrowthMachine

Deletes an inbox webhook from LaGrowthMachine.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inboxWebhooks/:webhookId`
- **Base URL:** `https://apiv2.lagrowthmachine.com/flow`
- **Official documentation:** [Delete Inbox Webhook](https://documenter.getpostman.com/view/2071164/TVCmSkH2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Inbox webhook ID. |
