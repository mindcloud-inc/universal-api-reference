# Search Leads with LaGrowthMachine

Finds leads in LaGrowthMachine.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/search`
- **Base URL:** `https://apiv2.lagrowthmachine.com/flow`
- **Official documentation:** [Search Leads](https://documenter.getpostman.com/view/2071164/TVCmSkH2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyName` | query | `string` | no | Filter by company name. |
| `companyUrl` | query | `string` | no | Filter by company website URL. |
| `email` | query | `string` | no | Filter by lead email. |
| `firstname` | query | `string` | no | Filter by lead first name. |
| `lastname` | query | `string` | no | Filter by lead last name. |
| `leadId` | query | `string` | no | Filter by lead ID. |
| `linkedinUrl` | query | `string` | no | Filter by lead LinkedIn profile URL. |
