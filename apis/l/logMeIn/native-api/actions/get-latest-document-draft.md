# Get Latest Document Draft with LogMeIn

Retrieves the latest document draft from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/resolve/knowledge-base/v2/documents/:documentId/draft`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Get Latest Document Draft](https://developer.goto.com/LogMeInResolve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Required document ID. |
