# Get Ticketing Services with LogMeIn

Retrieves available ticketing services from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/goto-resolve-ticketing/v1/services`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Get Ticketing Services](https://developer.goto.com/LogMeInResolve/)
