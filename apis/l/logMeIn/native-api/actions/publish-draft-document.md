# Publish Draft Document with LogMeIn

Publishes a draft document in LogMeIn.

## Endpoint

- **Method:** `POST`
- **Path:** `/resolve/knowledge-base/v2/drafts/:draftId/publish`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Publish Draft Document](https://developer.goto.com/LogMeInResolve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `draftId` | path | `string` | yes | Required draft ID to publish. |
