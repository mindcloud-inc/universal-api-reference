# List Alert Subscriptions with LogMeIn

Retrieves alert webhook subscriptions from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/goto-resolve-alerts/v1/subscriptions`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [List Alert Subscriptions](https://developer.goto.com/LogMeInResolve/)
