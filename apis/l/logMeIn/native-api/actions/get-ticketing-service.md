# Get Ticketing Service with LogMeIn

Retrieves a ticketing service from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/goto-resolve-ticketing/v1/services/:id`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Get Ticketing Service](https://developer.goto.com/LogMeInResolve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required service identifier. |
