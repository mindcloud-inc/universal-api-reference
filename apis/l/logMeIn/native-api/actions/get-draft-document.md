# Get Draft Document with LogMeIn

Retrieves a draft document from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/resolve/knowledge-base/v2/drafts/:draftId`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Get Draft Document](https://developer.goto.com/LogMeInResolve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `draftId` | path | `string` | yes | Required draft ID. |
