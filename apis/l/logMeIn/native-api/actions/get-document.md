# Get Document with LogMeIn

Retrieves a knowledge base document from LogMeIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/resolve/knowledge-base/v2/documents/:documentId`
- **Base URL:** `https://api.goto.com`
- **Official documentation:** [Get Document](https://developer.goto.com/LogMeInResolve/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Required document ID. |
