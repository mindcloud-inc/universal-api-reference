# Detect Language with Linguin AI

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/detect/language`
- **Base URL:** `https://api.linguin.ai`
- **Official documentation:** [Detect Language](https://linguin.ai/api-docs/v2/#single-language-detection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | body | `string` | yes | The text to analyze for language detection. |
