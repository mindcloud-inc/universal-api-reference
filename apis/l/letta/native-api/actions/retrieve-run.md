# Retrieve Run with Letta

Retrieves an existing run from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/runs/:run_id`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [Retrieve Run](https://docs.letta.com/api/resources/runs/methods/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | The Letta run ID. |
