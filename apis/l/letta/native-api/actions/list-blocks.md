# List Blocks with Letta

Retrieves a list of blocks from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/blocks/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Blocks](https://docs.letta.com/api/resources/blocks/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
