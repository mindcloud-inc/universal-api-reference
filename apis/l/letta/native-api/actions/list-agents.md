# List Agents with Letta

Retrieves a list of agents from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Agents](https://docs.letta.com/api/resources/agents/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
