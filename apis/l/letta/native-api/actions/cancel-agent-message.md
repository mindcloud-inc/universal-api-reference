# Cancel Agent Message with Letta

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/agents/:agent_id/messages/cancel`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [Cancel Agent Message](https://docs.letta.com/api/resources/agents/subresources/messages/methods/cancel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Letta agent ID. |
