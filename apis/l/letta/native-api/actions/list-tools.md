# List Tools with Letta

Retrieves a list of tools from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tools/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Tools](https://docs.letta.com/api/resources/tools/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
