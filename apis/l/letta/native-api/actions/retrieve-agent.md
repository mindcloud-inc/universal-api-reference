# Retrieve Agent with Letta

Retrieves an existing agent from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:agent_id`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [Retrieve Agent](https://docs.letta.com/api/resources/agents/methods/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Letta agent ID. |
