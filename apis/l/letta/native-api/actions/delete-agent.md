# Delete Agent with Letta

Deletes an existing agent from Letta.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/agents/:agent_id`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [Delete Agent](https://docs.letta.com/api/resources/agents/methods/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The Letta agent ID. |
