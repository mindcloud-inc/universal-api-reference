# List Runs with Letta

Retrieves a list of runs from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/runs/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Runs](https://docs.letta.com/api/resources/runs/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
