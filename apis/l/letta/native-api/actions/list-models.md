# List Models with Letta

Retrieves available LLM models from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Models](https://docs.letta.com/api/resources/models/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
