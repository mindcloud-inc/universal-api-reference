# List Conversations with Letta

Retrieves a list of conversations from Letta.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/conversations/`
- **Base URL:** `https://api.letta.com`
- **Official documentation:** [List Conversations](https://docs.letta.com/api/resources/conversations/methods/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
