# Unarchive Customer with Landbot

Unarchives a customer in Landbot.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/customers/:customer_id/unarchive/`
- **Base URL:** `https://api.landbot.io`
- **Official documentation:** [Unarchive Customer](https://api.landbot.io/#api-Customers-PutHttpsApiLandbotIoV1CustomersCustomer_idUnarchive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | Customer ID to unarchive. |
