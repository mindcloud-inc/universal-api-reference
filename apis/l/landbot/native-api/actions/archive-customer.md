# Archive Customer with Landbot

Archives a customer in Landbot.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/customers/:customer_id/archive/`
- **Base URL:** `https://api.landbot.io`
- **Official documentation:** [Archive Customer](https://api.landbot.io/#api-Customers-PutHttpsApiLandbotIoV1CustomersCustomer_idArchive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | Customer ID to archive. |
