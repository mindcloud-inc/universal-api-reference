# Get Channel with Landbot

Retrieves a channel from Landbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/channels/:channel_id/`
- **Base URL:** `https://api.landbot.io`
- **Official documentation:** [Get Channel](https://api.landbot.io/#api-Channels-GetHttpsApiLandbotIoV1ChannelsChannel_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_id` | path | `number` | yes | Channel ID to retrieve. |
