# Get Customer with Landbot

Retrieves a customer from Landbot.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customer_id/`
- **Base URL:** `https://api.landbot.io`
- **Official documentation:** [Get Customer](https://api.landbot.io/#api-Customers-GetHttpsApiLandbotIoV1CustomersCustomer_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | Customer ID to retrieve. |
