# Unblock Customer with Landbot

Unblocks a customer in Landbot.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/customers/:customer_id/unblock/`
- **Base URL:** `https://api.landbot.io`
- **Official documentation:** [Unblock Customer](https://api.landbot.io/#api-Customers-PutHttpsApiLandbotIoV1CustomersCustomer_idUnblock)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | Customer ID to unblock. |
