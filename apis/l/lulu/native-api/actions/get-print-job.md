# Get Print Job with Lulu

Retrieves a print job from Lulu.

## Endpoint

- **Method:** `GET`
- **Path:** `/print-jobs/{id}/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Print Job](https://api.lulu.com/docs/#tag/Print-Jobs/operation/Print-Jobs_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lulu print job ID. |
