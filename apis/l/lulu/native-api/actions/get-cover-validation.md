# Get Cover Validation with Lulu

Retrieves a cover validation record from Lulu.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate-cover/{id}/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Cover Validation](https://api.lulu.com/docs/#tag/Validate-Cover/operation/Validate-Cover_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Cover validation record ID. |
