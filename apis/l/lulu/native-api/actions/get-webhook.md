# Get Webhook with Lulu

Retrieves a webhook from Lulu.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{id}/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Webhook](https://api.lulu.com/docs/#tag/Webhooks/operation/retrieve-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lulu webhook ID. |
