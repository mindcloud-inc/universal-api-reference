# Get Print Job Costs with Lulu

Retrieves costs for a print job from Lulu.

## Endpoint

- **Method:** `GET`
- **Path:** `/print-jobs/{id}/costs/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Print Job Costs](https://api.lulu.com/docs/#tag/Print-Jobs/operation/Print-Jobs_costs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lulu print job ID. |
