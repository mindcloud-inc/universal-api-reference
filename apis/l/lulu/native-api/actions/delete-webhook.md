# Delete Webhook with Lulu

Deletes an existing webhook from Lulu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{id}/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Delete Webhook](https://api.lulu.com/docs/#tag/Webhooks/operation/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Lulu webhook ID. |
