# Get Interior Validation with Lulu

Retrieves an interior validation record from Lulu.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate-interior/{id}/`
- **Base URL:** `{apiBaseUrl}`
- **Official documentation:** [Get Interior Validation](https://api.lulu.com/docs/#tag/Validate-Interior/operation/Validate-Interior_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Interior validation record ID. |
