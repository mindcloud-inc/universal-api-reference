# List OTP Environments with LabsMobile

Retrieves OTP environments from LabsMobile.

## Endpoint

- **Method:** `GET`
- **Path:** `/otp/getEnvList`
- **Base URL:** `https://api.labsmobile.com`
- **Official documentation:** [List OTP Environments](https://www.labsmobile.com/en/sms-api/api-versions/sms-otp)
