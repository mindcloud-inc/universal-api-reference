# Get Global Price List with LabsMobile

Retrieves the global SMS price list from LabsMobile.

## Endpoint

- **Method:** `POST`
- **Path:** `/json/prices`
- **Base URL:** `https://api.labsmobile.com`
- **Official documentation:** [Get Global Price List](https://www.labsmobile.com/en/sms-api/api-versions/http-rest-post-json)
