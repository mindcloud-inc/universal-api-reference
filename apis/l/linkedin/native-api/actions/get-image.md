# Get Image with LinkedIn

Retrieves an image from LinkedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/images/:imageUrn`
- **Base URL:** `https://api.linkedin.com`
- **Official documentation:** [Get Image](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/images-api?view=li-lms-2026-01)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `imageUrn` | path | `string` | yes |
