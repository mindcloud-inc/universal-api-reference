# Get User Info with LinkedIn

Retrieves the authenticated user's profile from LinkedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/userinfo`
- **Base URL:** `https://api.linkedin.com`
- **Official documentation:** [Get User Info](https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/sign-in-with-linkedin)
