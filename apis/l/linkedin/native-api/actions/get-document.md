# Get Document with LinkedIn

Retrieves a document from LinkedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/documents/:documentUrn`
- **Base URL:** `https://api.linkedin.com`
- **Official documentation:** [Get Document](https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/documents-api?view=li-lms-2026-02)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentUrn` | path | `string` | yes |
