# Retrieve Access Token Information with LoginRadius

Retrieves access token details from LoginRadius.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/v2/auth/access_token`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Retrieve Access Token Information](https://www.loginradius.com/docs/api/openapi/get-access-token/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accessToken` | query | `string` | yes | Bearer access token to inspect. |
