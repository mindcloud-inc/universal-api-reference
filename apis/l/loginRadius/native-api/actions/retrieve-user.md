# Retrieve User with LoginRadius

Retrieves a user profile from LoginRadius.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/v2/auth/account`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Retrieve User](https://www.loginradius.com/docs/api/openapi/get-account-details/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accessToken` | query | `string` | yes | Access token for the logged-in user. |
