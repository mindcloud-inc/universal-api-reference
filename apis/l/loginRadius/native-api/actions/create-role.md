# Create Role with LoginRadius

Creates a new role in LoginRadius.

## Endpoint

- **Method:** `POST`
- **Path:** `/identity/v2/manage/role`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Create Role](https://www.loginradius.com/docs/api/openapi/create-role/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Role name to create. |
