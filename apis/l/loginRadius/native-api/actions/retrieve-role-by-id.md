# Retrieve Role by ID with LoginRadius

Retrieves a role from LoginRadius by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/manage/roles/:id`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Retrieve Role by ID](https://www.loginradius.com/docs/api/openapi/get-role-by-id/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Role ID to retrieve. |
