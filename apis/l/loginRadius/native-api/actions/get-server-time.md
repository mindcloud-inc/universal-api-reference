# Get Server Time with LoginRadius

Retrieves current server time from LoginRadius.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/v2/serverinfo`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Get Server Time](https://www.loginradius.com/docs/api/v2/customer-identity-api/configuration/get-server-time/)
