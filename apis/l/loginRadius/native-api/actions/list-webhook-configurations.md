# List Webhook Configurations with LoginRadius

Retrieves webhook configurations from your LoginRadius tenant.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/manage/webhooks`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [List Webhook Configurations](https://www.loginradius.com/docs/api/openapi/get-all-webhooks-configurations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accessToken` | query | `string` | yes | Bearer access token authorized to list webhook configurations. |
