# Retrieve Organization Details with LoginRadius

Retrieves organization details from your LoginRadius tenant.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/manage/organizations/:orgId`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Retrieve Organization Details](https://www.loginradius.com/docs/api/openapi/get-organization/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | Organization ID to retrieve. |
