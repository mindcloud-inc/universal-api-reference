# Create Organization with LoginRadius

Creates a new organization in LoginRadius.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/manage/organizations`
- **Base URL:** `https://api.loginradius.com`
- **Official documentation:** [Create Organization](https://www.loginradius.com/docs/api/openapi/create-organization/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Organization name. |
