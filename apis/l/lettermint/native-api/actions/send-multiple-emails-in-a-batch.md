# Send Multiple Emails in a Batch with Lettermint

Sends multiple emails in a batch through Lettermint.

## Endpoint

- **Method:** `POST`
- **Path:** `/send/batch`
- **Base URL:** `https://api.lettermint.co/v1`
- **Official documentation:** [Send Multiple Emails in a Batch](https://lettermint.co/docs/api-reference/sending/send#send-multiple-emails-in-a-batch)
