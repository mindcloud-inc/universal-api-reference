# Ping API with Lettermint

Retrieves Lettermint API status and authentication check results.

## Endpoint

- **Method:** `GET`
- **Path:** `/ping`
- **Base URL:** `https://api.lettermint.co/v1`
- **Official documentation:** [Ping API](https://lettermint.co/docs/api-reference/sending/generic#ping-the-api)
