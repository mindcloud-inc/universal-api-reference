# Search Links with LinkAce

Finds matching bookmark links in LinkAce.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/links`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Search Links](https://api-docs.linkace.org/#tag/Search/operation/get-api-v2-search-links)
