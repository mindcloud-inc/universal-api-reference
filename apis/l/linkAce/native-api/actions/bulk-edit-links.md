# Bulk Edit Links with LinkAce

Updates multiple bookmark links in LinkAce.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/bulk/links`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Bulk Edit Links](https://api-docs.linkace.org/#tag/Bulk/operation/patch-api-v2-bulk-links)
