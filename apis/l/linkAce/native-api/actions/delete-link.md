# Delete Link with LinkAce

Deletes an existing link from LinkAce.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/{link_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Delete Link](https://api-docs.linkace.org/#tag/Links/operation/delete-api-v2-links-link_id)
