# Delete List with LinkAce

Deletes an existing list from LinkAce.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/{list_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Delete List](https://api-docs.linkace.org/#tag/Lists/operation/delete-api-v2-lists-list_id)
