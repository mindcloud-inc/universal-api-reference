# Restore Trash Entry with LinkAce

Restores a trashed entry in LinkAce.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/trash/restore`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Restore Trash Entry](https://api-docs.linkace.org/#tag/Trash/operation/patch-api-v2-trash-restore)
