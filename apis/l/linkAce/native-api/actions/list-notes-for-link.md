# List Notes for Link with LinkAce

Retrieves notes for a specific link in LinkAce.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/{link_id}/notes`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [List Notes for Link](https://api-docs.linkace.org/#tag/Notes/operation/get-api-v2-links-link_id-notes)
