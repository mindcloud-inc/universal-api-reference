# Update List with LinkAce

Updates an existing list in LinkAce.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/lists/{list_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Update List](https://api-docs.linkace.org/#tag/Lists/operation/patch-api-v2-lists-list_id)
