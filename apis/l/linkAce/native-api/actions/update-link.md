# Update Link with LinkAce

Updates an existing link in LinkAce.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/links/{link_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Update Link](https://api-docs.linkace.org/#tag/Links/operation/patch-api-v2-links-link_id)
