# Search Lists with LinkAce

Finds lists in LinkAce for link editing.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/lists`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Search Lists](https://api-docs.linkace.org/#tag/Search/operation/get-api-v2-search-lists)
