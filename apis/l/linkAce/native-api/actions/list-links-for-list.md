# List Links for List with LinkAce

Retrieves links from a specific list in LinkAce.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/{list_id}/links`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [List Links for List](https://api-docs.linkace.org/#tag/Lists/operation/get-api-v2-lists-list_id-links)
