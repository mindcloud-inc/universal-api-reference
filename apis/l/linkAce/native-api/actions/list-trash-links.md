# List Trash Links with LinkAce

Retrieves trashed bookmark links from LinkAce.

## Endpoint

- **Method:** `GET`
- **Path:** `/trash/links`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [List Trash Links](https://api-docs.linkace.org/#tag/Trash/operation/get-api-v2-trash-links)
