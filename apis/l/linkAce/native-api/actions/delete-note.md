# Delete Note with LinkAce

Deletes an existing note from LinkAce.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/notes/{note_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Delete Note](https://api-docs.linkace.org/#tag/Notes/operation/delete-api-v2-notes-note_id)
