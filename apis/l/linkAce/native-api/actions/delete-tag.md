# Delete Tag with LinkAce

Deletes an existing tag from LinkAce.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/{tag_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Delete Tag](https://api-docs.linkace.org/#tag/Tags/operation/delete-api-v2-tags-tag_id)
