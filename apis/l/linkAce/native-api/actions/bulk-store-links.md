# Bulk Store Links with LinkAce

Creates multiple bookmark links in LinkAce.

## Endpoint

- **Method:** `POST`
- **Path:** `/bulk/links`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Bulk Store Links](https://api-docs.linkace.org/#tag/Bulk/operation/post-api-v2-bulk-links)
