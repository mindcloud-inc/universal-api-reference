# Clear Trash with LinkAce

Deletes trashed entries from LinkAce for a specific model.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/trash/clear`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Clear Trash](https://api-docs.linkace.org/#tag/Trash/operation/delete-api-v2-trash-clear)
