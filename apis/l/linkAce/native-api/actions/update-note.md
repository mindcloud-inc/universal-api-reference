# Update Note with LinkAce

Updates an existing note in LinkAce.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/notes/{note_id}`
- **Base URL:** `https://demo.linkace.org/api/v2`
- **Official documentation:** [Update Note](https://api-docs.linkace.org/#tag/Notes/operation/patch-api-v2-notes-note_id)
