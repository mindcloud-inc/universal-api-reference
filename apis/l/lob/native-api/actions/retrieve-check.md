# Retrieve Check with Lob

## Endpoint

- **Method:** `GET`
- **Path:** `/checks/:chk_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Retrieve Check](https://docs.lob.com/#tag/Checks/operation/check_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chk_id` | path | `string` | yes | The Lob check ID to retrieve. |
