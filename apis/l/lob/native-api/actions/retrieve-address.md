# Retrieve Address with Lob

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses/:adr_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Retrieve Address](https://docs.lob.com/#tag/Addresses/operation/address_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adr_id` | path | `string` | yes | The Lob address ID to retrieve. |
