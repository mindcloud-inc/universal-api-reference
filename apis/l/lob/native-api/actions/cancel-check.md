# Cancel Check with Lob

## Endpoint

- **Method:** `DELETE`
- **Path:** `/checks/:chk_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Cancel Check](https://docs.lob.com/#tag/Checks/operation/check_cancel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chk_id` | path | `string` | yes | The Lob check ID to delete. |
