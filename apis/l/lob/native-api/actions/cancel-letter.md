# Cancel Letter with Lob

## Endpoint

- **Method:** `DELETE`
- **Path:** `/letters/:ltr_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Cancel Letter](https://docs.lob.com/#tag/Letters/operation/letter_cancel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ltr_id` | path | `string` | yes | The Lob letter ID to delete. |
