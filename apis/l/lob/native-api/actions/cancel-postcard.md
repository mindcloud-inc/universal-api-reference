# Cancel Postcard with Lob

## Endpoint

- **Method:** `DELETE`
- **Path:** `/postcards/:psc_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Cancel Postcard](https://docs.lob.com/#tag/Postcards/operation/postcard_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `psc_id` | path | `string` | yes | The Lob postcard ID to delete. |
