# Retrieve Bank Account with Lob

## Endpoint

- **Method:** `GET`
- **Path:** `/bank_accounts/:bank_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Retrieve Bank Account](https://docs.lob.com/#tag/Bank-Accounts/operation/bank_account_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bank_id` | path | `string` | yes | Bank account ID. |
