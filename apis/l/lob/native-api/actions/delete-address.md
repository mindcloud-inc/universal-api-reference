# Delete Address with Lob

## Endpoint

- **Method:** `DELETE`
- **Path:** `/addresses/:adr_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Delete Address](https://docs.lob.com/#tag/Addresses/operation/address_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `adr_id` | path | `string` | yes | The Lob address ID to delete. |
