# Retrieve Postcard with Lob

## Endpoint

- **Method:** `GET`
- **Path:** `/postcards/:psc_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Retrieve Postcard](https://docs.lob.com/#tag/Postcards/operation/postcard_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `psc_id` | path | `string` | yes | The Lob postcard ID to retrieve. |
