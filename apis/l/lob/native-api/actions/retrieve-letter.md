# Retrieve Letter with Lob

## Endpoint

- **Method:** `GET`
- **Path:** `/letters/:ltr_id`
- **Base URL:** `https://api.lob.com/v1`
- **Official documentation:** [Retrieve Letter](https://docs.lob.com/#tag/Letters/operation/letter_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ltr_id` | path | `string` | yes | The Lob letter ID to retrieve. |
