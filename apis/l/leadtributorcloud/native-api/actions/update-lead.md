# Update Lead with leadtributor.cloud

Updates an existing lead in leadtributor.cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.leadtributor.cloud`
- **Official documentation:** [Update Lead](https://developer.leadtributor.cloud/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | ID of the lead to update. |
