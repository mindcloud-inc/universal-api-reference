# Get Lead with leadtributor.cloud

Retrieves a lead from leadtributor.cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.leadtributor.cloud`
- **Official documentation:** [Get Lead](https://developer.leadtributor.cloud/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | ID of the lead to retrieve. |
