# List Lead Notes with leadtributor.cloud

Retrieves notes for a lead in leadtributor.cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId/notes`
- **Base URL:** `https://api.leadtributor.cloud`
- **Official documentation:** [List Lead Notes](https://developer.leadtributor.cloud/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | ID of the lead whose notes to list. |
