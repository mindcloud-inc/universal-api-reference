# List Widgets with LiveWebinar

Retrieves widgets from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [List Widgets](https://docs.archiebot.com/?version=latest#4e9e6299-a0c1-46c6-afbb-fd5efbf039e2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scope` | query | `string` | no |
