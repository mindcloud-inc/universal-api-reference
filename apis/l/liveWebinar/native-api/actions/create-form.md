# Create Form with LiveWebinar

Creates a new form in LiveWebinar.

## Endpoint

- **Method:** `POST`
- **Path:** `api/forms`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Create Form](https://docs.archiebot.com/?version=latest#534d2dc7-def5-41c6-af8c-df87e2c8c9d9)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `description` | body | `string` | no |
| `name` | body | `string` | yes |
| `type` | body | `string` | yes |
