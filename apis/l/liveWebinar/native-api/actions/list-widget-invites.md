# List Widget Invites with LiveWebinar

Retrieves widget invites from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets/:widget_id/invites`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [List Widget Invites](https://docs.archiebot.com/?version=latest#2844041d-d819-4a9a-bb89-92ce4015843a)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
