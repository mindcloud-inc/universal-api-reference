# Get Widget with LiveWebinar

Retrieves a widget from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets/:widget_id`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Get Widget](https://docs.archiebot.com/?version=latest#8d7727a4-b209-41ab-957b-73096c7fb2fd)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
