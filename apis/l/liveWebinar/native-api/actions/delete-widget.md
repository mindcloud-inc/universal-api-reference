# Delete Widget with LiveWebinar

Deletes an existing widget from LiveWebinar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/widgets/:widget_id`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Delete Widget](https://docs.archiebot.com/?version=latest#c396a1bd-1a6b-41c2-be05-b040039b6772)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
