# List Widget Registrants with LiveWebinar

Retrieves widget registrants from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets/:widget_id/registrants`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [List Widget Registrants](https://docs.archiebot.com/?version=latest#bcc8b4af-2ba7-42ee-a23b-422b13bddbc3)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
