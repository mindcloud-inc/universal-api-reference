# Get User with LiveWebinar

Retrieves a user from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/users/:user_id`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Get User](https://docs.archiebot.com/?version=latest#bf5891d0-4cbe-4881-9c47-57908db911e8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
