# Enable User with LiveWebinar

Enables a user in LiveWebinar.

## Endpoint

- **Method:** `PUT`
- **Path:** `api/users/:user_id/enable`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Enable User](https://docs.archiebot.com/?version=latest#4ba74735-17cf-4cf9-ba39-5d5ef57bbf57)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
