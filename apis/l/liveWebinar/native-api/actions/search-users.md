# Search Users with LiveWebinar

Finds users in LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/users/search`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Search Users](https://docs.archiebot.com/?version=latest#97e7bfe0-8160-4760-8d3a-05219ed4ba4b)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phrase` | query | `string` | no |
