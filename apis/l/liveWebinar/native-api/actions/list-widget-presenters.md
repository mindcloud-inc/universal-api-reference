# List Widget Presenters with LiveWebinar

Retrieves widget presenters from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets/:widget_id/presenters`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [List Widget Presenters](https://docs.archiebot.com/?version=latest#a58dfbb8-391f-4dd1-bb5a-3d6488949d54)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
