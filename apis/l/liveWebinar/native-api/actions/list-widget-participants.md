# List Widget Participants with LiveWebinar

Retrieves widget participants from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/widgets/:widget_id/participants`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [List Widget Participants](https://docs.archiebot.com/?version=latest#8ceca65c-bb33-4443-841d-ee1a72258fe9)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | path | `string` | yes |
