# Disable User with LiveWebinar

Disables a user in LiveWebinar.

## Endpoint

- **Method:** `PUT`
- **Path:** `api/users/:user_id/disable`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Disable User](https://docs.archiebot.com/?version=latest#3adc1168-5ce6-4ce0-8225-02216700836e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `string` | yes |
