# Get Form with LiveWebinar

Retrieves a form from LiveWebinar.

## Endpoint

- **Method:** `GET`
- **Path:** `api/forms/:form_id`
- **Base URL:** `https://api.archiebot.com`
- **Official documentation:** [Get Form](https://docs.archiebot.com/?version=latest#c2c06c06-0299-4a1c-b657-db92bdfd734b)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `form_id` | path | `string` | yes |
