# Delete Link with Linkly

Deletes an existing link from Linkly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspace/:workspace_id/links/:id`
- **Base URL:** `https://app.linklyhq.com/api/v1`
- **Official documentation:** [Delete Link](https://linklyhq.com/support/link-shortening-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the Link. |
