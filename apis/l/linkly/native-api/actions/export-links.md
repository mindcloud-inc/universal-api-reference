# Export Links with Linkly

Retrieves a link export from Linkly.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace/:workspace_id/links/export`
- **Base URL:** `https://app.linklyhq.com/api/v1`
- **Official documentation:** [Export Links](https://linklyhq.com/support/link-shortening-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search query to filter links. |
