# Get Link with Linkly

Retrieves a link from Linkly.

## Endpoint

- **Method:** `GET`
- **Path:** `/link/:id`
- **Base URL:** `https://app.linklyhq.com/api/v1`
- **Official documentation:** [Get Link](https://linklyhq.com/support/link-shortening-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The id of the Link. |
