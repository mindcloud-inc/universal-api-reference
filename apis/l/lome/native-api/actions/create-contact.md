# Create Contact with Lome

Creates a new contact in Lome.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts`
- **Base URL:** `https://grow.withlome.com/api`
- **Official documentation:** [Create Contact](https://grow.withlome.com/articles/lome/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Contact name. |
| `email` | body | `string` | no | Contact email address. |
| `phone` | body | `string` | no | Contact phone number. |
