# List Recent Responses with Lome

Retrieves sign up form responses from the last 24 hours in Lome.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhook/new-response/recent`
- **Base URL:** `https://grow.withlome.com/api`
- **Official documentation:** [List Recent Responses](https://grow.withlome.com/articles/lome/api)
