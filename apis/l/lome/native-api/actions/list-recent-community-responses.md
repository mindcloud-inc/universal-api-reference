# List Recent Community Responses with Lome

Retrieves recent responses for a specific Lome community.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/new-community-responses/recent`
- **Base URL:** `https://grow.withlome.com/api`
- **Official documentation:** [List Recent Community Responses](https://grow.withlome.com/articles/lome/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | query | `string` | yes | The Lome community board ID. |
