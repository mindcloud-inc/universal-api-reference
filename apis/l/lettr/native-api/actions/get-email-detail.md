# Get Email Detail with Lettr

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:requestId`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Get Email Detail](https://docs.lettr.com/api-reference/emails/get-email-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | no | Email request identifier. |
