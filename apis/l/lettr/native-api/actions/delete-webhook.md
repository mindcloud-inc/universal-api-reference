# Delete Webhook with Lettr

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Delete Webhook](https://docs.lettr.com/api-reference/webhooks/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook identifier. |
