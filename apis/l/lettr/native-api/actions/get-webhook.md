# Get Webhook with Lettr

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Get Webhook](https://docs.lettr.com/api-reference/webhooks/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook identifier. |
