# Get Scheduled Email with Lettr

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/scheduled/:transmissionId`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Get Scheduled Email](https://docs.lettr.com/api-reference/emails/get-scheduled-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transmissionId` | path | `string` | no | Scheduled transmission identifier. |
