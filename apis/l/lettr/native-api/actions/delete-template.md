# Delete Template with Lettr

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:slug`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Delete Template](https://docs.lettr.com/api-reference/templates/delete-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Template slug. |
