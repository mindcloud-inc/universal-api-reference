# Create Domain with Lettr

## Endpoint

- **Method:** `POST`
- **Path:** `/domains`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Create Domain](https://docs.lettr.com/api-reference/domains/create-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Sending domain to register. |
