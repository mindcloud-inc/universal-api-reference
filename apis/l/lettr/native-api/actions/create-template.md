# Create Template with Lettr

## Endpoint

- **Method:** `POST`
- **Path:** `/templates`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Create Template](https://docs.lettr.com/api-reference/templates/create-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `html` | body | `string` | yes | HTML content for the template. |
| `name` | body | `string` | yes | Template name. |
