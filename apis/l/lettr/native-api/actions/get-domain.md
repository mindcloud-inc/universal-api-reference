# Get Domain with Lettr

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Get Domain](https://docs.lettr.com/api-reference/domains/get-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Sending domain name. |
