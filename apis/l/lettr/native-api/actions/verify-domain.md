# Verify Domain with Lettr

## Endpoint

- **Method:** `POST`
- **Path:** `/domains/:domain/verify`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Verify Domain](https://docs.lettr.com/api-reference/domains/verify-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Sending domain name. |
