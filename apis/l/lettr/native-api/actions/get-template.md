# Get Template with Lettr

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:slug`
- **Base URL:** `https://app.lettr.com/api/`
- **Official documentation:** [Get Template](https://docs.lettr.com/api-reference/templates/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Template slug. |
