# Lookup UK Government Data By Postcode with Loqate

Retrieves UK government data from Loqate by postcode.

## Endpoint

- **Method:** `GET`
- **Path:** `/GovernmentData/Postzon/RetrieveByPostcode/v1.50/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Lookup UK Government Data By Postcode](https://docs.loqate.com/api-reference/geocode/governmentdata/postzon-retrievebypostcode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Postcode` | query | `string` | yes | The postcode to search with. |
