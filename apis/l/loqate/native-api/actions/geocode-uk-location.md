# Geocode UK Location with Loqate

Geocodes a UK location with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Geocoding/UK/Geocode/v2.10/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Geocode UK Location](https://docs.loqate.com/api-reference/geocode/geocoding/uk-geocode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Location` | query | `string` | yes | The UK location to geocode. |
