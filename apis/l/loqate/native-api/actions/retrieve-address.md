# Retrieve Address with Loqate

Retrieves an address from Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Capture/Interactive/Retrieve/v1.30/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Retrieve Address](https://docs.loqate.com/api-reference/address-capture/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | query | `string` | yes | The address ID returned by Find. |
