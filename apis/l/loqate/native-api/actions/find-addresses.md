# Find Addresses with Loqate

Finds addresses in Loqate by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/Capture/Interactive/Find/v1.20/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Find Addresses](https://docs.loqate.com/api-reference/address-capture/find)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Text` | query | `string` | yes | Search text used to find matching addresses and places. |
