# Get Country From Coordinates with Loqate

Retrieves a country from coordinates with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Geocoding/International/PositionToCountry/v1.00/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Get Country From Coordinates](https://docs.loqate.com/api-reference/geocode/geocoding/international-positiontocountry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Latitude` | query | `number` | yes | The latitude to search against. |
| `Longitude` | query | `number` | yes | The longitude to search against. |
