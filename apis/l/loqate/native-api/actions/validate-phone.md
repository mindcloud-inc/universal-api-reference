# Validate Phone with Loqate

Validates a phone number with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/PhoneNumberValidation/Interactive/Validate/v2.20/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Validate Phone](https://docs.loqate.com/api-reference/phone-validation/individual-validate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Phone` | query | `string` | yes | The phone number to validate. |
