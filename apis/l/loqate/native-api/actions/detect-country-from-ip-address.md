# Detect Country From IP Address with Loqate

Detects a country from an IP address with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Extras/Web/Ip2Country/v1.10/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Detect Country From IP Address](https://docs.loqate.com/api-reference/geocode/ip2country/ip2country)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IpAddress` | query | `string` | no | The IP address to check. |
