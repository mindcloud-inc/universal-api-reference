# Find UK Location with Loqate

Finds a UK location with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Geocoding/UK/Find/v2.00/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Find UK Location](https://docs.loqate.com/api-reference/geocode/geocoding/uk-find)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Location` | query | `string` | yes | The UK location to find. |
