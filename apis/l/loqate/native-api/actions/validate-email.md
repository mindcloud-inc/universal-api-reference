# Validate Email with Loqate

Validates an email address with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/EmailValidation/Interactive/Validate/v2.00/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Validate Email](https://docs.loqate.com/api-reference/email-validation/individual)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Email` | query | `string` | yes | The email address to verify. |
