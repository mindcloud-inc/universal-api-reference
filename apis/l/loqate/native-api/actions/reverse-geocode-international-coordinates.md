# Reverse Geocode International Coordinates with Loqate

Reverse geocodes international coordinates with Loqate.

## Endpoint

- **Method:** `GET`
- **Path:** `/Geocoding/International/ReverseGeocode/v2.00/json6.ws`
- **Base URL:** `https://api.addressy.com`
- **Official documentation:** [Reverse Geocode International Coordinates](https://docs.loqate.com/api-reference/geocode/geocoding/international-reversegeocode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Latitude` | query | `number` | yes | The latitude for the reverse geocode. |
| `Longitude` | query | `number` | yes | The longitude for the reverse geocode. |
