# Get Customer with LiveChat

Retrieves detailed customer information from LiveChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/get_customer`
- **Base URL:** `https://api.livechatinc.com/v3.6/agent/action`
- **Official documentation:** [Get Customer](https://platform.text.com/docs/messaging/agent-chat-api#get-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The customer ID. |
