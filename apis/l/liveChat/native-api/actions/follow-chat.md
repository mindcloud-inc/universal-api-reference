# Follow Chat with LiveChat

Updates a chat by following it in LiveChat.

## Endpoint

- **Method:** `POST`
- **Path:** `/follow_chat`
- **Base URL:** `https://api.livechatinc.com/v3.6/agent/action`
- **Official documentation:** [Follow Chat](https://platform.text.com/docs/messaging/agent-chat-api#follow-chat)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The chat ID. |
