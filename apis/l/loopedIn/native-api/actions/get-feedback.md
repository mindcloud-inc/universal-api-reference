# Get Feedback with LoopedIn

Retrieves a feedback item from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Feedback](https://docs.loopedin.io/#get-feedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn feedback ID. |
