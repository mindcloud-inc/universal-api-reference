# Delete Roadmap Card with LoopedIn

Deletes an existing roadmap card from LoopedIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/roadmap-cards/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Delete Roadmap Card](https://docs.loopedin.io/#roadmap-cards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn roadmap card ID. |
