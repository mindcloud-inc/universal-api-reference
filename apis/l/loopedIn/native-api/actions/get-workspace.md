# Get Workspace with LoopedIn

Retrieves a workspace from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Workspace](https://docs.loopedin.io/#get-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn workspace ID. |
