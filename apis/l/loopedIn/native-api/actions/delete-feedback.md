# Delete Feedback with LoopedIn

Deletes an existing feedback item from LoopedIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/feedback/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Delete Feedback](https://docs.loopedin.io/#feedback)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn feedback ID. |
