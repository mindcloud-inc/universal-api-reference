# Get Feedback Board with LoopedIn

Retrieves a feedback board from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-boards/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Feedback Board](https://docs.loopedin.io/#get-feedback-board)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn feedback board ID. |
