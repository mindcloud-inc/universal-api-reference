# Get Update with LoopedIn

Retrieves an update from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/updates/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Update](https://docs.loopedin.io/#get-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn update ID. |
