# Get Roadmap Card with LoopedIn

Retrieves a roadmap card from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmap-cards/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Roadmap Card](https://docs.loopedin.io/#get-roadmap-card)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn roadmap card ID. |
