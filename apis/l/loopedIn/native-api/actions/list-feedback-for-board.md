# List Feedback for Board with LoopedIn

Retrieves feedback for a feedback board in LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-boards/:id/feedback`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [List Feedback for Board](https://docs.loopedin.io/#get-all-feedback-for-a-given-feedback-board)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn feedback board ID. |
