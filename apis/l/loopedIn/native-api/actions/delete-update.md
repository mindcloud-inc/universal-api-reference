# Delete Update with LoopedIn

Deletes an existing update from LoopedIn.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/updates/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Delete Update](https://docs.loopedin.io/#delete-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn update ID. |
