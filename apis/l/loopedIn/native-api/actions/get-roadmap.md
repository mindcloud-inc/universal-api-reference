# Get Roadmap with LoopedIn

Retrieves a roadmap from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmaps/:id`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [Get Roadmap](https://docs.loopedin.io/#get-roadmap)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The LoopedIn roadmap ID. |
