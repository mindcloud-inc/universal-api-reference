# List Completed Roadmap Cards with LoopedIn

Retrieves completed roadmap cards from LoopedIn.

## Endpoint

- **Method:** `GET`
- **Path:** `/roadmap-cards`
- **Base URL:** `https://api.loopedin.io/v1`
- **Official documentation:** [List Completed Roadmap Cards](https://docs.loopedin.io/#get-all-roadmap-cards)
