# List Payment Methods with Leap

Retrieves available payment methods from Leap.

## Endpoint

- **Method:** `GET`
- **Path:** `/company/payment_types`
- **Base URL:** `https://api.jobprogress.com/api/v3`
- **Official documentation:** [List Payment Methods](https://docs.api.jobprogress.com/#/GET-company-payment_types)
