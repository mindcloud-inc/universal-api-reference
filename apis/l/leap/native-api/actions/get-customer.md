# Get Customer with Leap

Retrieves a customer from Leap.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/[:customerId]`
- **Base URL:** `https://api.jobprogress.com/api/v3`
- **Official documentation:** [Get Customer](https://docs.api.jobprogress.com/api/customer.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | Leap customer ID. |
