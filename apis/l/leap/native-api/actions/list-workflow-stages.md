# List Workflow Stages with Leap

Retrieves workflow stage records from Leap.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow/stages`
- **Base URL:** `https://api.jobprogress.com/api/v3`
- **Official documentation:** [List Workflow Stages](https://docs.api.jobprogress.com/#/GET-workflow-stages)
