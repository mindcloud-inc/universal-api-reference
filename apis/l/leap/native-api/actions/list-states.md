# List States with Leap

Retrieves states for a country from Leap.

## Endpoint

- **Method:** `GET`
- **Path:** `/countries/[:countryId]/states`
- **Base URL:** `https://api.jobprogress.com/api/v3`
- **Official documentation:** [List States](https://docs.api.jobprogress.com/#/GET-countries-countryId-states)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `countryId` | path | `list` | yes | Country to fetch states for. |
