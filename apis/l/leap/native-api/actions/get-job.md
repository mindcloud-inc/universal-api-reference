# Get Job with Leap

Retrieves a job from Leap.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/[:jobId]`
- **Base URL:** `https://api.jobprogress.com/api/v3`
- **Official documentation:** [Get Job](https://docs.api.jobprogress.com/api/job.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `number` | yes | Leap job ID. |
