# List Allowance Types with Leave Dates

Retrieves allowance types for a company in Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/allowance-types`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [List Allowance Types](https://api.leavedates.com/documentation#/Company/get_allowance-types)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company` | query | `string` | yes |
