# List Leave Types with Leave Dates

Retrieves leave types for a company in Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/leave-types`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [List Leave Types](https://api.leavedates.com/documentation#/Company/get_leave-types)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company` | query | `string` | yes |
