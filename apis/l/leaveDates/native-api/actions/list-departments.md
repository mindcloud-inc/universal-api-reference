# List Departments with Leave Dates

Retrieves departments for a company in Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/departments`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [List Departments](https://api.leavedates.com/documentation#/Company/get_departments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company` | query | `string` | yes |
