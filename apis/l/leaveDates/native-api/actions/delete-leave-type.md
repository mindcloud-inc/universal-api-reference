# Delete Leave Type with Leave Dates

Deletes an existing leave type from Leave Dates.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leave-types/:id`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [Delete Leave Type](https://api.leavedates.com/documentation#/Company/delete_leave-types__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `company_id` | body | `string` | yes |
