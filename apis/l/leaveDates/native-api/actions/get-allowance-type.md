# Get Allowance Type with Leave Dates

Retrieves an allowance type from Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/allowance-types/:id`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [Get Allowance Type](https://api.leavedates.com/documentation#/Company/get_allowance-types__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `company` | query | `string` | yes |
