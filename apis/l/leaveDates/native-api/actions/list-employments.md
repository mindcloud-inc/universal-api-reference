# List Employments with Leave Dates

Retrieves employment records for a company in Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/employments`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [List Employments](https://api.leavedates.com/documentation#/Employment/get_employments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `company` | query | `string` | yes |
| `department_id` | query | `string` | no |
