# Delete Allowance Type with Leave Dates

Deletes an existing allowance type from Leave Dates.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/allowance-types/:id`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [Delete Allowance Type](https://api.leavedates.com/documentation#/Company/delete_allowance-types__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `company_id` | body | `string` | yes |
