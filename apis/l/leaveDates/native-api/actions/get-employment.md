# Get Employment with Leave Dates

Retrieves employment details from Leave Dates.

## Endpoint

- **Method:** `GET`
- **Path:** `/employments/:id`
- **Base URL:** `https://api.leavedates.com`
- **Official documentation:** [Get Employment](https://api.leavedates.com/documentation#/Employment/get_employments__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `company` | query | `string` | yes |
