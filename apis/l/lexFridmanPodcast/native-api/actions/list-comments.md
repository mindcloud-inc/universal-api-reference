# List Comments with Lex Fridman Podcast

Retrieves comments from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/comments`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Comments](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
