# List Posts with Lex Fridman Podcast

Retrieves posts from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/posts`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Posts](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
