# Get Page with Lex Fridman Podcast

Retrieves a page from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pages/:id`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Page](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The page ID. |
