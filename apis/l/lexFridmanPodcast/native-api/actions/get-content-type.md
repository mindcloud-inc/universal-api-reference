# Get Content Type with Lex Fridman Podcast

Retrieves a content type from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/types/:type`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Content Type](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | The content type slug. |
