# List Blocks with Lex Fridman Podcast

Retrieves blocks from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/blocks`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Blocks](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
