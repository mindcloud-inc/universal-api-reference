# Get Status with Lex Fridman Podcast

Retrieves a content status from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/statuses/:status`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Status](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | path | `string` | yes | The post status slug. |
