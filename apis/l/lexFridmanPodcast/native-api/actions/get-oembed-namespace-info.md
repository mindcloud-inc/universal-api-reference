# Get OEmbed Namespace Info with Lex Fridman Podcast

Retrieves oEmbed namespace details from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/oembed/1.0`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get OEmbed Namespace Info](https://lexfridman.com/wp-json/)
