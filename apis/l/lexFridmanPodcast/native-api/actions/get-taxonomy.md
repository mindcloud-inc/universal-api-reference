# Get Taxonomy with Lex Fridman Podcast

Retrieves a taxonomy from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/taxonomies/:taxonomy`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Taxonomy](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taxonomy` | path | `string` | yes | The taxonomy slug. |
