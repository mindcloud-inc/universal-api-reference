# List Pattern Categories with Lex Fridman Podcast

Retrieves pattern categories from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/wp_pattern_category`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Pattern Categories](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
