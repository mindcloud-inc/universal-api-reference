# Get Media with Lex Fridman Podcast

Retrieves a media item from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/media/:id`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Media](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The media ID. |
