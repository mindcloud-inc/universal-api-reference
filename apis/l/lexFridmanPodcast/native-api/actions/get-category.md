# Get Category with Lex Fridman Podcast

Retrieves a category from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/categories/:id`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Category](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The category ID. |
