# Get OEmbed Embed with Lex Fridman Podcast

Retrieves oEmbed data for a URL from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/oembed/1.0/embed`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get OEmbed Embed](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The resource URL to embed. |
