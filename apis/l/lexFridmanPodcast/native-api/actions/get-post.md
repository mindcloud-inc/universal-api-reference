# Get Post with Lex Fridman Podcast

Retrieves a post from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/posts/:id`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get Post](https://lexfridman.com/wp-json/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The post ID. |
