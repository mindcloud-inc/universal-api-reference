# List Users with Lex Fridman Podcast

Retrieves users from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/users`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Users](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
