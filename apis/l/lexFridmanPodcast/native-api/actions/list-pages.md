# List Pages with Lex Fridman Podcast

Retrieves pages from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pages`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Pages](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
