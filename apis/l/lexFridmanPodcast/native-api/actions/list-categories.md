# List Categories with Lex Fridman Podcast

Retrieves categories from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/categories`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Categories](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
