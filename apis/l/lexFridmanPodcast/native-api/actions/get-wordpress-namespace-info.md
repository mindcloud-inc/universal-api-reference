# Get WordPress Namespace Info with Lex Fridman Podcast

Retrieves WordPress namespace details from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [Get WordPress Namespace Info](https://lexfridman.com/wp-json/)
