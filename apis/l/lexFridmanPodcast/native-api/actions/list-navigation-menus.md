# List Navigation Menus with Lex Fridman Podcast

Retrieves navigation menus from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/navigation`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Navigation Menus](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
