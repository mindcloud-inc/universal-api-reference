# List Media with Lex Fridman Podcast

Retrieves media items from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/media`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Media](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
