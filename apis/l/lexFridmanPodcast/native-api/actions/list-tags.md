# List Tags with Lex Fridman Podcast

Retrieves tags from Lex Fridman Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/tags`
- **Base URL:** `https://lexfridman.com`
- **Official documentation:** [List Tags](https://lexfridman.com/wp-json/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
