# List Pipeline Statuses with Less Annoying CRM

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.lessannoyingcrm.com/v2`
- **Official documentation:** [List Pipeline Statuses](https://account.lessannoyingcrm.com/api_docs/v2/Settings_Functions/Pipeline_Statuses#Goto-GetPipelineStatuses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PipelineId` | body | `string` | no | Optional pipeline Id to restrict statuses to one pipeline. |
