# Retrieve Total Lead Count with LeadDyno

Retrieves the total number of leads in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/count`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Total Lead Count](https://app.theneo.io/leaddyno/leaddyno-rest-api/leads/get-leads-count)
