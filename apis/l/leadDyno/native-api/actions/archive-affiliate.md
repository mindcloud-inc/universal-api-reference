# Archive Affiliate with LeadDyno

Archives an affiliate account in LeadDyno.

## Endpoint

- **Method:** `POST`
- **Path:** `/affiliates/:id/archive`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Archive Affiliate](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/post-affiliates-id-archive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
