# Approve Affiliate with LeadDyno

Approves an affiliate account in LeadDyno.

## Endpoint

- **Method:** `POST`
- **Path:** `/affiliates/:id/approve`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Approve Affiliate](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/post-affiliates-id-approve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
