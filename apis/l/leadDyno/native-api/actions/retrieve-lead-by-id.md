# Retrieve Lead By ID with LeadDyno

Retrieves a lead from LeadDyno by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:id`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Lead By ID](https://app.theneo.io/leaddyno/leaddyno-rest-api/leads/retrieve-a-lead-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The lead ID. |
