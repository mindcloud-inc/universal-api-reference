# Retrieve Affiliate By Code with LeadDyno

Retrieves an affiliate from LeadDyno by affiliate code.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/by_affiliate_code`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate By Code](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates-by-affiliate-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `affiliate_code` | query | `string` | yes | The affiliate coupon or discount code. |
