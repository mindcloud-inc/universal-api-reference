# Retrieve Campaign By ID with LeadDyno

Retrieves a campaign from LeadDyno by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:id`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Campaign By ID](https://app.theneo.io/leaddyno/leaddyno-rest-api/campaigns/get-campaigns-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The campaign ID. |
