# Retrieve Affiliate By Email with LeadDyno

Retrieves an affiliate from LeadDyno by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/by_email`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate By Email](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address of the affiliate to retrieve. |
