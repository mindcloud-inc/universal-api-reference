# Retrieve Total Purchase Count with LeadDyno

Retrieves the total number of purchases in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchases/count`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Total Purchase Count](https://app.theneo.io/leaddyno/leaddyno-rest-api/purchases/get-purchases-count)
