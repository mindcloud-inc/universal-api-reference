# List Visitors with LeadDyno

Retrieves visitors from your LeadDyno account.

## Endpoint

- **Method:** `GET`
- **Path:** `/visitors`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [List Visitors](https://app.theneo.io/leaddyno/leaddyno-rest-api/visitors/list-all-visitors)
