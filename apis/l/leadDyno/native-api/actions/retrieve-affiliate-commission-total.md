# Retrieve Affiliate Commission Total with LeadDyno

Retrieves commission totals for a specific affiliate in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/:id/commissions_total`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate Commission Total](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/retrieve-total-commissions-for-a-specific-affiliate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
