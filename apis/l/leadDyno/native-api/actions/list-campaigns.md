# List Campaigns with LeadDyno

Retrieves campaigns from your LeadDyno account.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [List Campaigns](https://app.theneo.io/leaddyno/leaddyno-rest-api/campaigns/get-campaigns)
