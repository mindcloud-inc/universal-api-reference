# List Commissions with LeadDyno

Retrieves commissions from your LeadDyno account.

## Endpoint

- **Method:** `GET`
- **Path:** `/commissions`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [List Commissions](https://app.theneo.io/leaddyno/leaddyno-rest-api/commissions/get-commissions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
