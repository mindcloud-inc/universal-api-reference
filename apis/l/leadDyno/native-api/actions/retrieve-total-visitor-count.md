# Retrieve Total Visitor Count with LeadDyno

Retrieves the total number of visitors in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/visitors/count`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Total Visitor Count](https://app.theneo.io/leaddyno/leaddyno-rest-api/visitors/retrieve-total-visitor-count)
