# Retrieve Affiliate Leads with LeadDyno

Retrieves leads for a specific affiliate in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/:id/leads`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate Leads](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates-id-leads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
