# Retrieve Affiliate Commissions with LeadDyno

Retrieves commissions for a specific affiliate in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/:id/commissions`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate Commissions](https://app.theneo.io/leaddyno/leaddyno-rest-api/commissions/get-affiliates-id-commissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
