# Retrieve Affiliate Purchases with LeadDyno

Retrieves purchases for a specific affiliate in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/:id/purchases`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate Purchases](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates-id-purchases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
