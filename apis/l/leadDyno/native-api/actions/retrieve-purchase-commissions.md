# Retrieve Purchase Commissions with LeadDyno

Retrieves commissions for a specific purchase in LeadDyno.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchases/:id/commissions`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Purchase Commissions](https://app.theneo.io/leaddyno/leaddyno-rest-api/purchases/get-purchases-id-commissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The purchase ID. |
