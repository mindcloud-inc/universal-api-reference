# Create Visitor with LeadDyno

Creates a new visitor in LeadDyno.

## Endpoint

- **Method:** `POST`
- **Path:** `/visitors`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Create Visitor](https://app.theneo.io/leaddyno/leaddyno-rest-api/visitors/create-a-visitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tracking_code` | body | `string` | yes | The tracking code assigned to the visitor. |
