# List Affiliates with LeadDyno

Retrieves affiliates from your LeadDyno account.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [List Affiliates](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Find affiliates by first name, last name, or email. |
