# Retrieve Affiliate By ID with LeadDyno

Retrieves an affiliate from LeadDyno by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/affiliates/:id`
- **Base URL:** `https://api.leaddyno.com/v1`
- **Official documentation:** [Retrieve Affiliate By ID](https://app.theneo.io/leaddyno/leaddyno-rest-api/affiliates/get-affiliates-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The affiliate ID. |
