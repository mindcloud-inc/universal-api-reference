# Delete Segment with Leadboxer

Deletes an existing segment from Leadboxer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/segments/{{segmentId}}`
- **Base URL:** `https://data.leadboxer.com`
- **Official documentation:** [Delete Segment](https://developers.leadboxer.com/reference/deletesegment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `number` | yes | The segment ID. |
