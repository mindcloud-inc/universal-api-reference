# Update Segment User with Leadboxer

Updates segment access for a user in Leadboxer.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/segments/user`
- **Base URL:** `https://data.leadboxer.com`
- **Official documentation:** [Update Segment User](https://developers.leadboxer.com/reference/updatesegmentuser)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | body | `number` | yes |
| `userId` | body | `number` | yes |
