# Retrieve Order Confirmation with Lexware Office

Retrieves an order confirmation from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/order-confirmations/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Order Confirmation](https://developers.lexware.io/docs/#order-confirmations-endpoint-retrieve-an-order-confirmation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware order confirmation ID. |
