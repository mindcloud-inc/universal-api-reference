# Retrieve Voucher with Lexware Office

Retrieves a voucher from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/vouchers/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Voucher](https://developers.lexware.io/docs/#vouchers-endpoint-retrieve-a-voucher)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Voucher ID from Lexware. |
