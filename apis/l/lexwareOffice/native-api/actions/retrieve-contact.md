# Retrieve Contact with Lexware Office

Retrieves a contact from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Contact](https://developers.lexware.io/docs/#contacts-endpoint-retrieve-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware contact ID. |
