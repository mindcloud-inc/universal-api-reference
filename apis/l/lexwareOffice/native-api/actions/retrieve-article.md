# Retrieve Article with Lexware Office

Retrieves an article from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/articles/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Article](https://developers.lexware.io/docs/#articles-endpoint-retrieve-an-article)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware article ID. |
