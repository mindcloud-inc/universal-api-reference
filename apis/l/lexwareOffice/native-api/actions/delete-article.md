# Delete Article with Lexware Office

Deletes an existing article from Lexware Office.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/articles/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Delete Article](https://developers.lexware.io/docs/#articles-endpoint-delete-an-article)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware article ID to delete. |
