# Retrieve Quotation with Lexware Office

Retrieves a quotation from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/quotations/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Quotation](https://developers.lexware.io/docs/#quotations-endpoint-retrieve-a-quotation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware quotation ID. |
