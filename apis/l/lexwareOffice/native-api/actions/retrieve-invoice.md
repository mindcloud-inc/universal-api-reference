# Retrieve Invoice with Lexware Office

Retrieves an invoice from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoices/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Invoice](https://developers.lexware.io/docs/#invoices-endpoint-retrieve-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware invoice ID. |
