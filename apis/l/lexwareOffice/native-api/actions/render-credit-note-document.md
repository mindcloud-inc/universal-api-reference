# Render Credit Note Document with Lexware Office

Retrieves a rendered credit note PDF from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credit-notes/:id/document`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Render Credit Note Document](https://developers.lexware.io/docs/#credit-notes-endpoint-render-a-credit-note-document-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware credit note ID. |
