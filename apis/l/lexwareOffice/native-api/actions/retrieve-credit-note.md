# Retrieve Credit Note with Lexware Office

Retrieves a credit note from Lexware Office.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/credit-notes/:id`
- **Base URL:** `https://api.lexware.io`
- **Official documentation:** [Retrieve Credit Note](https://developers.lexware.io/docs/#credit-notes-endpoint-retrieve-a-credit-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Lexware credit note ID. |
