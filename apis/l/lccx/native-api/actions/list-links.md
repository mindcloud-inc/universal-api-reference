# List Links with lc.cx

Retrieves the latest short links from lc.cx.

## Endpoint

- **Method:** `GET`
- **Path:** `/links`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [List Links](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offset` | query | `number` | no | Skip this many links before returning results. |
