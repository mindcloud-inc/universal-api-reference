# Get Link with lc.cx

Retrieves a short link from lc.cx.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Get Link](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the link to retrieve. |
