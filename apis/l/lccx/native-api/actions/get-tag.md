# Get Tag with lc.cx

Retrieves a tag from lc.cx.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Get Tag](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to retrieve. |
