# Get Domain with lc.cx

Retrieves a branded domain from lc.cx.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:id`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Get Domain](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the domain to retrieve. |
