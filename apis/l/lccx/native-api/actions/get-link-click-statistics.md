# Get Link Click Statistics with lc.cx

Retrieves click statistics for a short link in lc.cx.

## Endpoint

- **Method:** `GET`
- **Path:** `/statistics/links/:id/clicks`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Get Link Click Statistics](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the link whose click statistics you want. |
