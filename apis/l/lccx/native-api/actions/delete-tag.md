# Delete Tag with lc.cx

Deletes an existing tag from lc.cx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/delete/:id`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Delete Tag](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to delete. |
