# Delete Link with lc.cx

Deletes an existing short link from lc.cx.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/delete/:id`
- **Base URL:** `https://api.lc.cx/v1`
- **Official documentation:** [Delete Link](https://dev.lc.cx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the link to delete. |
