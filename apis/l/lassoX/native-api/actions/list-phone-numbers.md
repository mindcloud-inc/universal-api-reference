# List Phone Numbers with Lasso X

Retrieves phone numbers for a Lasso X entity.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/teledata/:lassoId/phonenumbers`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [List Phone Numbers](https://docs.lassox.com/data-apis/teledata/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
