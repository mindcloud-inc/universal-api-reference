# Analyze Financial Report with Lasso X

Retrieves a financial report analysis from Lasso X.

## Endpoint

- **Method:** `POST`
- **Path:** `/modules/reportanalysis/:lassoId`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [Analyze Financial Report](https://docs.lassox.com/module-apis/financial-analysis/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
