# List Reports with Lasso X

Retrieves reports for a CVR entity from Lasso X.

## Endpoint

- **Method:** `GET`
- **Path:** `/:lassoId/reports`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [List Reports](https://docs.lassox.com/data-apis/cvr/#reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
