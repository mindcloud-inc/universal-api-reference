# List Reporting Batches with Lasso X

Retrieves reporting batches from Lasso X.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/reporting/batches`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [List Reporting Batches](https://docs.lassox.com/module-apis/reporting/#retrieve-reports)
