# Get Network with Lasso X

Retrieves a person's professional network from Lasso X.

## Endpoint

- **Method:** `GET`
- **Path:** `/modules/network/:lassoId`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [Get Network](https://docs.lassox.com/module-apis/cvrnetwork/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
