# Get Paqle Entity with Lasso X

Retrieves Paqle entity details from Lasso X by Lasso ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/paqle/:lassoId/entity`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [Get Paqle Entity](https://docs.lassox.com/data-apis/paqle/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
