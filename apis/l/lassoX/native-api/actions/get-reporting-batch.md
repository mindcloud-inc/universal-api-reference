# Get Reporting Batch with Lasso X

Retrieves a reporting batch from Lasso X by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/reporting/batches/:id`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [Get Reporting Batch](https://docs.lassox.com/module-apis/reporting/#retrieve-reports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Reporting batch ID. |
