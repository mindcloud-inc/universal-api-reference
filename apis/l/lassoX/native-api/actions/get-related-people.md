# Get Related People with Lasso X

Retrieves related people for a CVR entity from Lasso X.

## Endpoint

- **Method:** `GET`
- **Path:** `/:lassoId/related/person`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [Get Related People](https://docs.lassox.com/data-apis/cvr/#related-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
