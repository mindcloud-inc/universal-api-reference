# List Paqle News with Lasso X

Retrieves Paqle news for a Lasso X entity.

## Endpoint

- **Method:** `GET`
- **Path:** `/data/paqle/:lassoId/news`
- **Base URL:** `https://api.lassox.com`
- **Official documentation:** [List Paqle News](https://docs.lassox.com/data-apis/paqle/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lassoId` | path | `string` | yes | Lasso ID, for example CVR-1-34580820. |
