# List Projects with LaunchDarkly

Retrieves projects from LaunchDarkly.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://app.launchdarkly.com/api/v2`
- **Official documentation:** [List Projects](https://launchdarkly.com/docs/api/projects/get-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
