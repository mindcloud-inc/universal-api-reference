# List Members with LaunchDarkly

Retrieves account members from LaunchDarkly.

## Endpoint

- **Method:** `GET`
- **Path:** `/members`
- **Base URL:** `https://app.launchdarkly.com/api/v2`
- **Official documentation:** [List Members](https://launchdarkly.com/docs/api/account-members/get-members)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
