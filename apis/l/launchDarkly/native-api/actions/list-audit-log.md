# List Audit Log with LaunchDarkly

Retrieves audit log entries from LaunchDarkly.

## Endpoint

- **Method:** `GET`
- **Path:** `/auditlog`
- **Base URL:** `https://app.launchdarkly.com/api/v2`
- **Official documentation:** [List Audit Log](https://launchdarkly.com/docs/api/audit-log/get-audit-log-entries)
