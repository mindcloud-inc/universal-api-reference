# Get Category with Longreads

Retrieves a Longreads category by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/categories/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Category](https://longreads.com/wp-json/wp/v2/categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The category ID to retrieve. |
