# Get Yoast Head Metadata with Longreads

Retrieves Longreads Yoast head metadata for a URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/yoast/v1/get_head`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Yoast Head Metadata](https://longreads.com/wp-json/yoast/v1/get_head)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The public URL whose Yoast metadata should be returned. |
