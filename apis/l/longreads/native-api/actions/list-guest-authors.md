# List Guest Authors with Longreads

Retrieves guest author profiles from Longreads.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/guest-author`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Guest Authors](https://longreads.com/wp-json/wp/v2/guest-author)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
