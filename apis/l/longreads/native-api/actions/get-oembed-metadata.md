# Get OEmbed Metadata with Longreads

Retrieves Longreads oEmbed metadata for a URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/oembed/1.0/embed`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get OEmbed Metadata](https://longreads.com/wp-json/oembed/1.0/embed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The public URL to generate oEmbed metadata for. |
