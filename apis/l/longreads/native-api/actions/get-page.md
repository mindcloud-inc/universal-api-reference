# Get Page with Longreads

Retrieves a Longreads page by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/pages/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Page](https://longreads.com/wp-json/wp/v2/pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The WordPress page ID to retrieve. |
