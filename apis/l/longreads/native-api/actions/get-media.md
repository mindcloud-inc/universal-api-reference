# Get Media with Longreads

Retrieves a Longreads media item by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/media/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Media](https://longreads.com/wp-json/wp/v2/media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The media item ID to retrieve. |
