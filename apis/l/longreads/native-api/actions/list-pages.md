# List Pages with Longreads

Retrieves pages from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/pages`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Pages](https://longreads.com/wp-json/wp/v2/pages)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
