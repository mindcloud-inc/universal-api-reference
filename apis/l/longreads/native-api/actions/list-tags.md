# List Tags with Longreads

Retrieves tags from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/tags`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Tags](https://longreads.com/wp-json/wp/v2/tags)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
