# List Comments with Longreads

Retrieves comments from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/comments`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Comments](https://longreads.com/wp-json/wp/v2/comments)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
