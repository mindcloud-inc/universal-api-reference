# Get Tag with Longreads

Retrieves a Longreads tag by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/tags/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Tag](https://longreads.com/wp-json/wp/v2/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The tag ID to retrieve. |
