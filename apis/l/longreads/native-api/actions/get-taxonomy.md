# Get Taxonomy with Longreads

Retrieves a taxonomy definition from Longreads.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/taxonomies/{taxonomy}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Taxonomy](https://longreads.com/wp-json/wp/v2/taxonomies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taxonomy` | path | `string` | yes | The taxonomy slug to retrieve, such as category. |
