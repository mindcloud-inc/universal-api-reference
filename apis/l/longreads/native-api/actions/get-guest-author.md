# Get Guest Author with Longreads

Retrieves a Longreads guest author by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/guest-author/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Guest Author](https://longreads.com/wp-json/wp/v2/guest-author)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The guest author ID to retrieve. |
