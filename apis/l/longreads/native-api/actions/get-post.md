# Get Post with Longreads

Retrieves a Longreads post by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/posts/{id}`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Post](https://longreads.com/wp-json/wp/v2/posts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The WordPress post ID to retrieve. |
