# List Categories with Longreads

Retrieves categories from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/categories`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Categories](https://longreads.com/wp-json/wp/v2/categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
