# Get Web App Manifest with Longreads

Retrieves the Longreads web app manifest.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/web-app-manifest`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Web App Manifest](https://longreads.com/wp-json/wp/v2/web-app-manifest)
