# List Media with Longreads

Retrieves media items from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/media`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [List Media](https://longreads.com/wp-json/wp/v2/media)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
