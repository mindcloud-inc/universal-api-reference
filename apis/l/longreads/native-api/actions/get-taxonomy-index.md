# Get Taxonomy Index with Longreads

Retrieves taxonomy definitions from the Longreads site.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp/v2/taxonomies`
- **Base URL:** `https://longreads.com/wp-json`
- **Official documentation:** [Get Taxonomy Index](https://longreads.com/wp-json/wp/v2/taxonomies)
