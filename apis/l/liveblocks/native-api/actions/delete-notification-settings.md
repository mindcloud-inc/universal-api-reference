# Delete Notification Settings with Liveblocks

Deletes notification settings from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId/notification-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Notification Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-notification-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
