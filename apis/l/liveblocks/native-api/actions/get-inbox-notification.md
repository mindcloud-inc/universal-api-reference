# Get Inbox Notification with Liveblocks

Retrieves an inbox notification from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/inbox-notifications/:inboxNotificationId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Inbox Notification](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-inbox-notification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
