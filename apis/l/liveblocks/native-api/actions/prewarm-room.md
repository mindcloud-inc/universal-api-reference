# Prewarm Room with Liveblocks

Prewarms a room in Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/prewarm`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Prewarm Room](https://liveblocks.io/docs/api-reference/rest-api-endpoints#prewarm-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
