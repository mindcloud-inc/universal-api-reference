# Mark Inbox Notification As Read with Liveblocks

Marks an inbox notification as read in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/inbox-notifications/:inboxNotificationId/read`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Mark Inbox Notification As Read](https://liveblocks.io/docs/api-reference/rest-api-endpoints#mark-inbox-notification-as-read)
