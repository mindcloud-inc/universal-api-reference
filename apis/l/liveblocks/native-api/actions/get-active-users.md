# Get Active Users with Liveblocks

Retrieves active users from a Liveblocks room.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/active_users`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Active Users](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-active-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
