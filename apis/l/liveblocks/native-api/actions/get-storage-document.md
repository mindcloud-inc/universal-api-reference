# Get Storage Document with Liveblocks

Retrieves a storage document from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/storage`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Storage Document](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-storage-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
