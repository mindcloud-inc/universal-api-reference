# Delete All Inbox Notifications with Liveblocks

Deletes all inbox notifications from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId/inbox-notifications`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete All Inbox Notifications](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-all-inbox-notifications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
