# Set Ephemeral Presence with Liveblocks

Updates ephemeral presence in a Liveblocks room.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/presence`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Set Ephemeral Presence](https://liveblocks.io/docs/api-reference/rest-api-endpoints#set-ephemeral-presence)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
