# Update Room Organization ID with Liveblocks

Updates a room organization ID in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/update-organization-id`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Update Room Organization ID](https://liveblocks.io/docs/api-reference/rest-api-endpoints#update-room-organization-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
