# Update Room Subscription Settings with Liveblocks

Updates room subscription settings in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/users/:userId/subscription-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Update Room Subscription Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#update-room-subscription-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
