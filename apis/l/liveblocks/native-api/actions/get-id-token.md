# Get ID Token with Liveblocks

Creates an ID token in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/identify-user`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get ID Token](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-id-token-with-secret-key)
