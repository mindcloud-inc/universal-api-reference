# Delete Group with Liveblocks

Deletes an existing group from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Group](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | no | ID of the group. |
