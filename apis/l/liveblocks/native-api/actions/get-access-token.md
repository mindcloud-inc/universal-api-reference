# Get Access Token with Liveblocks

Creates an access token in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/authorize-user`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Access Token](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-access-token-with-secret-key)
