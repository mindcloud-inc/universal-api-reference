# Initialize Storage Document with Liveblocks

Creates a storage document in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/storage`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Initialize Storage Document](https://liveblocks.io/docs/api-reference/rest-api-endpoints#initialize-storage-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
