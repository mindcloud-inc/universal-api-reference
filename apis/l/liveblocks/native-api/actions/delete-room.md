# Delete Room with Liveblocks

Deletes an existing room from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Room](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
