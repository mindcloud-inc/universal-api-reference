# Get Room Threads with Liveblocks

Retrieves threads from a Liveblocks room.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/threads`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Room Threads](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-room-threads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
