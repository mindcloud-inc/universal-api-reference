# Get Room with Liveblocks

Retrieves a room from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Room](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
