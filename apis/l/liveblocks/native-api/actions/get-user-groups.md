# Get User Groups with Liveblocks

Retrieves groups for a user in Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/groups`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get User Groups](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-user-groups)
