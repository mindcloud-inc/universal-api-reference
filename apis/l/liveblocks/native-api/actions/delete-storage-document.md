# Delete Storage Document with Liveblocks

Deletes a storage document from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:roomId/storage`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Storage Document](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-storage-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
