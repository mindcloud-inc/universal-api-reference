# Update Room ID with Liveblocks

Updates a room ID in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/update-room-id`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Update Room ID](https://liveblocks.io/docs/api-reference/rest-api-endpoints#update-room-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
