# Get All Inbox Notifications with Liveblocks

Retrieves all inbox notifications from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/inbox-notifications`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get All Inbox Notifications](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-all-inbox-notifications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
