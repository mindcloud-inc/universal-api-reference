# Broadcast Event To Room with Liveblocks

Broadcasts an event to a Liveblocks room.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/broadcast_event`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Broadcast Event To Room](https://liveblocks.io/docs/api-reference/rest-api-endpoints#broadcast-event-to-a-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
