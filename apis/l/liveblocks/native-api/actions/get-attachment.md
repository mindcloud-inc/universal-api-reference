# Get Attachment with Liveblocks

Retrieves an attachment from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/attachments/:attachmentId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Attachment](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-attachment)
