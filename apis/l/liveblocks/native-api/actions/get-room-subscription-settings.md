# Get Room Subscription Settings with Liveblocks

Retrieves room subscription settings from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/users/:userId/subscription-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Room Subscription Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-room-subscription-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
