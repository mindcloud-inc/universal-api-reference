# Get Thread Inbox Notifications with Liveblocks

Retrieves thread inbox notifications from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:roomId/threads/:threadId/inbox-notifications`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Thread Inbox Notifications](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-thread-inbox-notifications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `threadId` | path | `string` | no | ID of the thread. |
