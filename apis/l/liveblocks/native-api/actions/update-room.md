# Update Room with Liveblocks

Updates an existing room in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Update Room](https://liveblocks.io/docs/api-reference/rest-api-endpoints#update-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
