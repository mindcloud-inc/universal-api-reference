# Delete Thread with Liveblocks

Deletes an existing thread from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:roomId/threads/:threadId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Thread](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-thread)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
| `threadId` | path | `string` | no | ID of the thread. |
