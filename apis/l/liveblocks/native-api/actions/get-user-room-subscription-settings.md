# Get User Room Subscription Settings with Liveblocks

Retrieves user room subscription settings from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/room-subscription-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get User Room Subscription Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-user-room-subscription-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
