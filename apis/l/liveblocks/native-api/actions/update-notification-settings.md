# Update Notification Settings with Liveblocks

Updates notification settings in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:userId/notification-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Update Notification Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#update-notification-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
