# Create Thread with Liveblocks

Creates a new thread in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:roomId/threads`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Create Thread](https://liveblocks.io/docs/api-reference/rest-api-endpoints#create-thread)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
