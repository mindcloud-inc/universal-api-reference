# Trigger Inbox Notification with Liveblocks

Creates an inbox notification in Liveblocks.

## Endpoint

- **Method:** `POST`
- **Path:** `/inbox-notifications/trigger`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Trigger Inbox Notification](https://liveblocks.io/docs/api-reference/rest-api-endpoints#trigger-inbox-notification)
