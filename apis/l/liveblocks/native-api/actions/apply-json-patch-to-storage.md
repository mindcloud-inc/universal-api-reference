# Apply JSON Patch To Storage with Liveblocks

Updates Liveblocks storage with a JSON patch.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/rooms/:roomId/storage/json-patch`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Apply JSON Patch To Storage](https://liveblocks.io/docs/api-reference/rest-api-endpoints#apply-json-patch-to-storage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | no | ID of the room. |
