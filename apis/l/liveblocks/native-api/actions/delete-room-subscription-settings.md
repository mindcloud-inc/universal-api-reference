# Delete Room Subscription Settings with Liveblocks

Deletes room subscription settings from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:roomId/users/:userId/subscription-settings`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Room Subscription Settings](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-room-subscription-settings)
