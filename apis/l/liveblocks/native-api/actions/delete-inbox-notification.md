# Delete Inbox Notification with Liveblocks

Deletes an inbox notification from Liveblocks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId/inbox-notifications/:inboxNotificationId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Delete Inbox Notification](https://liveblocks.io/docs/api-reference/rest-api-endpoints#delete-inbox-notification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | ID of the user. |
