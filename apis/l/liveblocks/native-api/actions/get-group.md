# Get Group with Liveblocks

Retrieves a group from Liveblocks.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://api.liveblocks.io/v2`
- **Official documentation:** [Get Group](https://liveblocks.io/docs/api-reference/rest-api-endpoints#get-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | no | ID of the group. |
