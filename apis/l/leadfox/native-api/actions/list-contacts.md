# List Contacts with Leadfox

## Endpoint

- **Method:** `POST`
- **Path:** `/contact/getlist/`
- **Base URL:** `https://app.leadfox.co/service`
- **Official documentation:** [List Contacts](https://cdn.leadfox.co/upload/7/api_leadfox_12_12-2017.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list` | body | `string` | no | Optional Leadfox list identifier to restrict contacts. |
