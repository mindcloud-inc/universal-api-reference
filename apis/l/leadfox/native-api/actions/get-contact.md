# Get Contact with Leadfox

## Endpoint

- **Method:** `POST`
- **Path:** `/contact/get/`
- **Base URL:** `https://app.leadfox.co/service`
- **Official documentation:** [Get Contact](https://cdn.leadfox.co/upload/7/api_leadfox_12_12-2017.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Contact email address (mandatory). |
