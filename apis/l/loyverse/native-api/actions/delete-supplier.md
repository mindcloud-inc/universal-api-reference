# Delete Supplier with Loyverse

Deletes an existing supplier from Loyverse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/suppliers/:supplier_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Delete Supplier](https://developer.loyverse.com/docs/#tag/Suppliers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `supplier_id` | path | `string` | yes |
