# Get Shift with Loyverse

Retrieves a shift record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/shifts/:shift_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Shift](https://developer.loyverse.com/docs/#tag/Shifts)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shift_id` | path | `string` | yes |
