# Delete Customer with Loyverse

Deletes an existing customer from Loyverse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:customer_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Delete Customer](https://developer.loyverse.com/docs/#tag/Customers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | yes |
