# Get Category with Loyverse

Retrieves a category record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:category_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Category](https://developer.loyverse.com/docs/#tag/Categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `category_id` | path | `string` | yes |
