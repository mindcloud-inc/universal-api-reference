# Get Item with Loyverse

Retrieves an item record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:item_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Item](https://developer.loyverse.com/docs/#tag/Items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `item_id` | path | `string` | yes |
