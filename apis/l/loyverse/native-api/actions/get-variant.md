# Get Variant with Loyverse

Retrieves a product variant from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/variants/:variant_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Variant](https://developer.loyverse.com/docs/#tag/Items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variant_id` | path | `string` | yes |
