# Get Customer with Loyverse

Retrieves a customer record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customer_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Customer](https://developer.loyverse.com/docs/#tag/Customers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customer_id` | path | `string` | yes |
