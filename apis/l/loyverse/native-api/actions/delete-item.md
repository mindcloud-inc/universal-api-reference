# Delete Item with Loyverse

Deletes an existing item from Loyverse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/items/:item_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Delete Item](https://developer.loyverse.com/docs/#tag/Items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `item_id` | path | `string` | yes |
