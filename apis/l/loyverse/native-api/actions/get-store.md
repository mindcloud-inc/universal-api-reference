# Get Store with Loyverse

Retrieves a store record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/stores/:store_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Store](https://developer.loyverse.com/docs/#tag/Stores)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `store_id` | path | `string` | yes |
