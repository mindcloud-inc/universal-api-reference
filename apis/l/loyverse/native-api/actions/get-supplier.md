# Get Supplier with Loyverse

Retrieves a supplier record from Loyverse.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppliers/:supplier_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Get Supplier](https://developer.loyverse.com/docs/#tag/Suppliers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `supplier_id` | path | `string` | yes |
