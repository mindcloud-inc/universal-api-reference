# Delete Category with Loyverse

Deletes an existing category from Loyverse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:category_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Delete Category](https://developer.loyverse.com/docs/#tag/Categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `category_id` | path | `string` | yes |
