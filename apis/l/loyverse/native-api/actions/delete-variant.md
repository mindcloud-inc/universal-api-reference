# Delete Variant with Loyverse

Deletes an existing product variant from Loyverse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/variants/:variant_id`
- **Base URL:** `https://api.loyverse.com/v1.0`
- **Official documentation:** [Delete Variant](https://developer.loyverse.com/docs/#tag/Items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variant_id` | path | `string` | yes |
