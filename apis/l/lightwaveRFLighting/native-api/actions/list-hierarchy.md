# List Hierarchy with LightwaveRF Lighting

Retrieves hierarchy data from LightwaveRF Lighting.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/hierarchy`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Hierarchy](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
