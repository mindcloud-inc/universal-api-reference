# List Zones with LightwaveRF Lighting

Retrieves available zones from LightwaveRF Lighting.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/zones`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Zones](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
