# List Favourites with LightwaveRF Lighting

Retrieves configured favourites from LightwaveRF Lighting.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/favourites`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Favourites](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
