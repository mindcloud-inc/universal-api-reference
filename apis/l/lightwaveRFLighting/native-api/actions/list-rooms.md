# List Rooms with LightwaveRF Lighting

Retrieves available rooms from LightwaveRF Lighting.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/rooms`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Rooms](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
