# List Webhooks with LightwaveRF Lighting

Retrieves configured webhooks from LightwaveRF Lighting.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/events`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [List Webhooks](https://jsapi.apiary.io/apis/linkpluspublicapi.html)
