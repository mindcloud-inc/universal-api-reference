# Delete Room with LightwaveRF Lighting

Deletes an existing room from LightwaveRF Lighting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/room/{roomId}`
- **Base URL:** `https://publicapi.lightwaverf.com/`
- **Official documentation:** [Delete Room](https://jsapi.apiary.io/apis/linkpluspublicapi.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roomId` | path | `string` | yes | The LightwaveRF room identifier to delete. |
