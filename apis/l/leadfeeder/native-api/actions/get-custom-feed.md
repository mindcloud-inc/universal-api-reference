# Get Custom Feed with Leadfeeder

Retrieves a specific custom feed from Leadfeeder.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/custom-feeds/:customFeedId`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Custom Feed](https://docs.leadfeeder.com/api/#get-a-specific-custom-feed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customFeedId` | path | `string` | yes |
