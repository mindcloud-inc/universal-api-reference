# Get Accounts with Leadfeeder

Retrieves accounts the user can access in Leadfeeder.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Accounts](https://docs.leadfeeder.com/api/#get-accounts-the-user-has-access-to)
