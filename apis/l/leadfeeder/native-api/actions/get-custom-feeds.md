# Get Custom Feeds with Leadfeeder

Retrieves custom feeds for an account in Leadfeeder.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/custom-feeds`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Custom Feeds](https://docs.leadfeeder.com/api/#get-custom-feeds-list-for-an-account)
