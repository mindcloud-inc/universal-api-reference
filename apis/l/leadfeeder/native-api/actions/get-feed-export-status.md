# Get Feed Export Status with Leadfeeder

Retrieves the status of a feed export in Leadfeeder.

## Endpoint

- **Method:** `GET`
- **Path:** `/export-requests/:exportRequestId`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Feed Export Status](https://docs.leadfeeder.com/api/#feed-export-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `exportRequestId` | path | `string` | yes |
