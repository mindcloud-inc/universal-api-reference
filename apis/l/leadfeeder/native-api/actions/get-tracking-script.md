# Get Tracking Script with Leadfeeder

Retrieves an account tracking script from Leadfeeder.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/website-tracking-script`
- **Base URL:** `https://api.leadfeeder.com`
- **Official documentation:** [Get Tracking Script](https://docs.leadfeeder.com/api/#get-tracking-script-for-a-given-account)
