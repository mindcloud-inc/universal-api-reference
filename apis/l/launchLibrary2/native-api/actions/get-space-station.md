# Get Space Station with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `space_stations/{{id}}/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [Get Space Station](https://ll.thespacedevs.com/2.3.0/space_stations/?format=api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Space station ID from Launch Library 2. |
