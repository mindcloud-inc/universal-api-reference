# Get Event with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `events/{{id}}/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [Get Event](https://ll.thespacedevs.com/2.3.0/events/?format=api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Event ID from Launch Library 2. |
