# List Expeditions with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `expeditions/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Expeditions](https://ll.thespacedevs.com/2.3.0/expeditions/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
