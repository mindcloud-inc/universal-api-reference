# List Space Stations with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `space_stations/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Space Stations](https://ll.thespacedevs.com/2.3.0/space_stations/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
