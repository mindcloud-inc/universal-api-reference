# List Locations with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `locations/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Locations](https://ll.thespacedevs.com/2.3.0/locations/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
