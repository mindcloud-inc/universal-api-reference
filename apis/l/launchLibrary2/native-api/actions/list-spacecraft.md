# List Spacecraft with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `spacecraft/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Spacecraft](https://ll.thespacedevs.com/2.3.0/spacecraft/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
