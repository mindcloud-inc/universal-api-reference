# List Payloads with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `payloads/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Payloads](https://ll.thespacedevs.com/2.3.0/payloads/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
