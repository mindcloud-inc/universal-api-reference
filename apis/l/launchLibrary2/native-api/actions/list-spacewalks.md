# List Spacewalks with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `spacewalks/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Spacewalks](https://ll.thespacedevs.com/2.3.0/spacewalks/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
