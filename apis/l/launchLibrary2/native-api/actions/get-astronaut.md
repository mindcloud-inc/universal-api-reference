# Get Astronaut with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `astronauts/{{id}}/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [Get Astronaut](https://ll.thespacedevs.com/2.3.0/astronauts/?format=api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Astronaut ID from Launch Library 2. |
