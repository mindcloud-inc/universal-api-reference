# Get Launch with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `launches/{{id}}/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [Get Launch](https://ll.thespacedevs.com/2.3.0/launches/e3df2ecd-c239-472f-95e4-2b89b4f75800/?format=api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Launch UUID from Launch Library 2. |
