# List Docking Events with Launch Library 2

- **Method:** `GET`
- **Path:** `docking_events/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Docking Events](https://ll.thespacedevs.com/2.3.0/docking_events/?format=api)
