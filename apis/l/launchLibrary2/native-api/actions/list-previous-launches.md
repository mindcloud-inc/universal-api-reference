# List Previous Launches with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `launches/previous/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Previous Launches](https://ll.thespacedevs.com/2.3.0/launches/previous/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
