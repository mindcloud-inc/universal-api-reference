# List Previous Events with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `events/previous/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [List Previous Events](https://ll.thespacedevs.com/2.3.0/events/previous/?format=api)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
