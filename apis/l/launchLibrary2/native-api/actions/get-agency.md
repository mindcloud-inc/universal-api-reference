# Get Agency with Launch Library 2

## Endpoint

- **Method:** `GET`
- **Path:** `agencies/{{id}}/`
- **Base URL:** `https://ll.thespacedevs.com/2.3.0/`
- **Official documentation:** [Get Agency](https://ll.thespacedevs.com/2.3.0/agencies/?format=api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agency ID from Launch Library 2. |
