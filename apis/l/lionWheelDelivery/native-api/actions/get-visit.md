# Get Visit with LionWheel Delivery

Retrieves a visit from LionWheel Delivery.

## Endpoint

- **Method:** `GET`
- **Path:** `/visits/:visit_id`
- **Base URL:** `https://test.lionwheel.com/api/v1`
- **Official documentation:** [Get Visit](https://github.com/lionwheel/api#receiving-visit)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `visit_id` | path | `string` | yes | The LionWheel visit ID. |
