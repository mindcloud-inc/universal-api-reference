# Get Task with LionWheel Delivery

Retrieves a task from LionWheel Delivery.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/show/:task_id`
- **Base URL:** `https://test.lionwheel.com/api/v1`
- **Official documentation:** [Get Task](https://github.com/lionwheel/api#receiving-delivery)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The LionWheel task ID. |
