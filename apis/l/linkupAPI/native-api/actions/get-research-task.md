# Get Research Task with LinkupAPI

Retrieves research task details from LinkupAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/research/:id`
- **Base URL:** `https://api.linkup.so/v1`
- **Official documentation:** [Get Research Task](https://docs.linkup.so/pages/documentation/api-reference/endpoint/get-research-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the research task to retrieve. |
