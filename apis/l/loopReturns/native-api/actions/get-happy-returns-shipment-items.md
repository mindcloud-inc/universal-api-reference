# Get Happy Returns Shipment Items with Loop Returns

## Endpoint

- **Method:** `GET`
- **Path:** `/happy-returns/shipments/:shipmentId/items`
- **Base URL:** `https://api.loopreturns.com/api/v1`
- **Official documentation:** [Get Happy Returns Shipment Items](https://docs.loopreturns.com/api-reference/latest/happy-returns-shipment-items/get-shipment-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `shipmentId` | path | `number` | yes |
