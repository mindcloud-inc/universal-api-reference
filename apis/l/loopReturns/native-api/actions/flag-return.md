# Flag Return with Loop Returns

Flag a return in Loop for review.

## Endpoint

- **Method:** `POST`
- **Path:** `https://api.loopreturns.com/api/v1/warehouse/return/{{return_id}}/flag`
- **Base URL:** `https://api.loopreturns.com/api/v1`
- **Official documentation:** [Flag Return](https://docs.loopreturns.com/api-reference/latest/return-actions/flag-return)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `return_id` | path | `string` | yes |
