# Get Happy Returns Shipments with Loop Returns

## Endpoint

- **Method:** `GET`
- **Path:** `/happy-returns/shipments`
- **Base URL:** `https://api.loopreturns.com/api/v1`
- **Official documentation:** [Get Happy Returns Shipments](https://docs.loopreturns.com/api-reference/latest/happy-returns-shipment/get-shipments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `from` | query | `string` | no |
| `to` | query | `string` | no |
| `page` | query | `number` | no |
