# List Locations with Logiwa Legacy WMS

## Endpoint

- **Method:** `POST`
- **Path:** `en/api/IntegrationApi/LocationSearch`
- **Base URL:** `https://{uRL}.logiwa.com/`
- **Official documentation:** [List Locations](https://developer.logiwa.com/?id=63b437efe6466c3cdcb7321a)
