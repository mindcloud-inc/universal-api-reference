# Get a Product ID with Logiwa Legacy WMS

## Endpoint

- **Method:** `POST`
- **Path:** `/en/api/IntegrationApi/InventoryItemGetID`
- **Base URL:** `https://{uRL}.logiwa.com/`
- **Official documentation:** [Get a Product ID](https://developer.logiwa.com/?id=5df0dab3e6466c2eec992f45#!#requestContent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Code` | body | `string` | no | product ID/description |
| `DepositorID` | body | `number` | no | — |
