# Delete Traces with Langfuse

Deletes multiple traces from Langfuse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/traces`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Delete Traces](https://api.reference.langfuse.com/#tag/Trace/DELETE/api/public/traces)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `traceIds` | body | `string` | no |
