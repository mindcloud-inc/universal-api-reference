# Get Session with Langfuse

Retrieves a session from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:sessionId`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Session](https://api.reference.langfuse.com/#tag/Sessions/GET/api/public/sessions/{sessionId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sessionId` | path | `string` | yes |
