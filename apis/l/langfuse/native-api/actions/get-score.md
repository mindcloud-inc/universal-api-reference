# Get Score with Langfuse

Retrieves a score from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/scores/:scoreId`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Score](https://api.reference.langfuse.com/#tag/Scores/GET/api/public/v2/scores/{scoreId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scoreId` | path | `string` | no |
