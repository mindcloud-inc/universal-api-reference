# List Models with Langfuse

Retrieves models from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/models`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [List Models](https://api.reference.langfuse.com/#tag/Models/GET/api/public/models)

## Capabilities

This operation supports [pagination](../README.md#pagination).
