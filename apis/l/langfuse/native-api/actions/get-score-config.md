# Get Score Config with Langfuse

Retrieves a score config from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/score-configs/:configId`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Score Config](https://api.reference.langfuse.com/#tag/ScoreConfigs/GET/api/public/score-configs/{configId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `configId` | path | `string` | no |
