# Get Dataset with Langfuse

Retrieves a dataset from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets/:datasetName`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Dataset](https://api.reference.langfuse.com/#tag/Datasets/GET/api/public/v2/datasets/{datasetName})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datasetName` | path | `string` | no |
