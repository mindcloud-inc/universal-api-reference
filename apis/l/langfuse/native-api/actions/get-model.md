# Get Model with Langfuse

Retrieves a model from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/models/:id`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Model](https://api.reference.langfuse.com/#tag/Models/GET/api/public/models/{id})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
