# Get Annotation Queue with Langfuse

Retrieves an annotation queue from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/annotation-queues/:queueId`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Annotation Queue](https://api.reference.langfuse.com/#tag/AnnotationQueues/GET/api/public/annotation-queues/{queueId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `queueId` | path | `string` | no |
