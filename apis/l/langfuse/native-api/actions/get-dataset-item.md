# Get Dataset Item with Langfuse

Retrieves a dataset item from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/dataset-items/:id`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Dataset Item](https://api.reference.langfuse.com/#tag/DatasetItems/GET/api/public/dataset-items/{id})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
