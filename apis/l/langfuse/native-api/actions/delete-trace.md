# Delete Trace with Langfuse

Deletes a trace from Langfuse.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/traces/:traceId`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Delete Trace](https://api.reference.langfuse.com/#tag/Trace/DELETE/api/public/traces/{traceId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `traceId` | path | `string` | no |
