# Query Metrics with Langfuse

Retrieves project metrics from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/metrics`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Query Metrics](https://api.reference.langfuse.com/#tag/Metrics/GET/api/public/v2/metrics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | query | `string` | no |
