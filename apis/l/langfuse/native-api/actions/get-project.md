# Get Project with Langfuse

Retrieves the project associated with your Langfuse API key.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [Get Project](https://api.reference.langfuse.com/#tag/Projects/GET/api/public/projects)
