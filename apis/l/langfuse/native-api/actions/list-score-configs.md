# List Score Configs with Langfuse

Retrieves score configs from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/score-configs`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [List Score Configs](https://api.reference.langfuse.com/#tag/ScoreConfigs/GET/api/public/score-configs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
