# List Datasets with Langfuse

Retrieves datasets from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/datasets`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [List Datasets](https://api.reference.langfuse.com/#tag/Datasets/GET/api/public/v2/datasets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
