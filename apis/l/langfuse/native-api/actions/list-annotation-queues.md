# List Annotation Queues with Langfuse

Retrieves annotation queues from Langfuse.

## Endpoint

- **Method:** `GET`
- **Path:** `/annotation-queues`
- **Base URL:** `https://cloud.langfuse.com/api/public`
- **Official documentation:** [List Annotation Queues](https://api.reference.langfuse.com/#tag/AnnotationQueues/GET/api/public/annotation-queues)

## Capabilities

This operation supports [pagination](../README.md#pagination).
