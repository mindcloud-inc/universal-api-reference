# Get Workflow Run with Leap AI

Retrieves a workflow run from Leap AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/runs/:workflowRunId`
- **Base URL:** `https://api.workflows.tryleap.ai`
- **Official documentation:** [Get Workflow Run](https://docs.tryleap.ai/api-reference/get-workflow-run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowRunId` | path | `string` | yes | The runv2_ identifier of the workflow run to retrieve. |
