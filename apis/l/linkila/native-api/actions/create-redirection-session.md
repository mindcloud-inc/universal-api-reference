# Create Redirection Session with Linkila

Creates a redirection session in Linkila.

## Endpoint

- **Method:** `POST`
- **Path:** `/createRedirectionSession`
- **Base URL:** `https://app.linkila.com/integrations/api/v1`
- **Official documentation:** [Create Redirection Session](https://app.linkila.com/integrations/api/v1/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shortURLId` | body | `string` | yes | Required Linkila short URL identifier for the redirection session. |
