# List Domains with Linkila

Retrieves configured link domains from Linkila.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://app.linkila.com/integrations/api/v1`
- **Official documentation:** [List Domains](https://app.linkila.com/integrations/api/v1/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cursor` | query | `string` | no | Cursor for pagination. Use the cursor returned in pageInfo from a previous response. |
