# Describe Company with Logo.dev

Retrieves company details from Logo.dev by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/describe/:domain`
- **Base URL:** `https://api.logo.dev`
- **Official documentation:** [Describe Company](https://www.logo.dev/docs/describe/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Company domain to describe. |
