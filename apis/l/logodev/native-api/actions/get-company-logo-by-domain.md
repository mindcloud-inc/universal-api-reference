# Get Company Logo by Domain with Logo.dev

Retrieves a company logo from Logo.dev by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `https://img.logo.dev/:domain`
- **Base URL:** `https://api.logo.dev`
- **Official documentation:** [Get Company Logo by Domain](https://www.logo.dev/docs/logo-images/domain-logos)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Company domain to fetch a logo for. |
