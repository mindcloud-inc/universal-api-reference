# Delete Group with Level

Deletes an existing group from Level.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Delete Group](https://levelapi.readme.io/reference/deletegroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the group to delete. |
