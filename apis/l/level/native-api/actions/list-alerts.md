# List Alerts with Level

Retrieves a list of alerts from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [List Alerts](https://levelapi.readme.io/reference/listalerts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
