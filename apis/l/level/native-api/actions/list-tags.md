# List Tags with Level

Retrieves a list of tags from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [List Tags](https://levelapi.readme.io/reference/listtags)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
