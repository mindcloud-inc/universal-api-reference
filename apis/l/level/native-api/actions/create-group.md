# Create Group with Level

Creates a new group in Level.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Create Group](https://levelapi.readme.io/reference/creategroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the group. |
