# Update Group with Level

Updates an existing group in Level.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/groups/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Update Group](https://levelapi.readme.io/reference/updategroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the group to update. |
