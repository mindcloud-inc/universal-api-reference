# Delete Custom Field with Level

Deletes an existing custom field from Level.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/custom_fields/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Delete Custom Field](https://levelapi.readme.io/reference/deletecustomfield)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the custom field. |
