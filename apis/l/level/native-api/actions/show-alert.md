# Show Alert with Level

Retrieves an existing alert from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Show Alert](https://levelapi.readme.io/reference/showalert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the alert to retrieve. |
