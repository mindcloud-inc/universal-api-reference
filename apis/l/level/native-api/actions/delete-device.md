# Delete Device with Level

Deletes an existing device from Level.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/devices/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Delete Device](https://levelapi.readme.io/reference/deletedevice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the device to delete. |
