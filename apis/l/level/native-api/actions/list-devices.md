# List Devices with Level

Retrieves a list of devices from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [List Devices](https://levelapi.readme.io/reference/listdevices)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
