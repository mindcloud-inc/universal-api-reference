# Show Custom Field with Level

Retrieves an existing custom field from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_fields/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Show Custom Field](https://levelapi.readme.io/reference/showcustomfield)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the custom field. |
