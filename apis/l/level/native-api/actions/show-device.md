# Show Device with Level

Retrieves an existing device from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Show Device](https://levelapi.readme.io/reference/showdevice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the device to retrieve. |
