# Show Tag with Level

Retrieves an existing tag from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Show Tag](https://levelapi.readme.io/reference/showtag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to retrieve. |
