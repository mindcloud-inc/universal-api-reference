# Create Tag with Level

Creates a new tag in Level.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Create Tag](https://levelapi.readme.io/reference/createtag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The tag name. |
