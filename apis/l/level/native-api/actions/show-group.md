# Show Group with Level

Retrieves an existing group from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Show Group](https://levelapi.readme.io/reference/showgroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the group to retrieve. |
