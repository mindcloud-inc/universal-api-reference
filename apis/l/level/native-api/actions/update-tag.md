# Update Tag with Level

Updates an existing tag in Level.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tags/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Update Tag](https://levelapi.readme.io/reference/updatetag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to update. |
