# Delete Tag with Level

Deletes an existing tag from Level.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Delete Tag](https://levelapi.readme.io/reference/deletetag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to delete. |
