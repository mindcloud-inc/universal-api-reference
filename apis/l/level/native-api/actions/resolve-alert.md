# Resolve Alert with Level

Resolves an active alert in Level.

## Endpoint

- **Method:** `POST`
- **Path:** `/alerts/{id}/resolve`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Resolve Alert](https://levelapi.readme.io/reference/resolvealert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the alert to resolve. |
