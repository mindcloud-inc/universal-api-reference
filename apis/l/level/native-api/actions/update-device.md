# Update Device with Level

Updates an existing device in Level.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/devices/{id}`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [Update Device](https://levelapi.readme.io/reference/updatedevice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the device to update. |
