# List Custom Fields with Level

Retrieves a list of custom fields from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_fields`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [List Custom Fields](https://levelapi.readme.io/reference/custom-fields)

## Capabilities

This operation supports [pagination](../README.md#pagination).
