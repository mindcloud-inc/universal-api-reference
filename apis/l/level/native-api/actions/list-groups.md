# List Groups with Level

Retrieves a list of groups from Level.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.level.io/v2`
- **Official documentation:** [List Groups](https://levelapi.readme.io/reference/listgroups)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
