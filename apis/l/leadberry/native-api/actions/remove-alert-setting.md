# Remove Alert Setting with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/removeAlertSetting`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Remove Alert Setting](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | no | Leadberry alert setting ID to remove. |
