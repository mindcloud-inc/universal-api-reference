# Get CRM Additional Info with Leadberry

## Endpoint

- **Method:** `GET`
- **Path:** `/data/getCRMAdditionalInfo`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Get CRM Additional Info](https://www.leadberry.com/integrations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiKey` | query | `string` | no | External CRM API key or oauth sentinel value. |
| `crmId` | query | `string` | no | Leadberry CRM integration type ID, such as pipedrive or zohocrmnew. |
