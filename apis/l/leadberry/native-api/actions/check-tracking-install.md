# Check Tracking Install with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/checkInstall`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Check Tracking Install](https://www.leadberry.com/install-leadberry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackerId` | body | `string` | no | Leadberry tracker ID from the installed tracking snippet. |
