# Remove CRM Connection with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/removeCRM`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Remove CRM Connection](https://www.leadberry.com/integrations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `crmId` | body | `string` | no | Leadberry CRM connection ID to remove. |
