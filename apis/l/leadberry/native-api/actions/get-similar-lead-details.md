# Get Similar Lead Details with Leadberry

## Endpoint

- **Method:** `GET`
- **Path:** `/data/getLBSimilarDetailsData`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Get Similar Lead Details](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Identifier returned by Leadberry similar-company results. |
