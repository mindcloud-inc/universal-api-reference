# Save Pabbly Webhook with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/pabbly/save-webhook`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Save Pabbly Webhook](https://www.leadberry.com/pabbly)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | no | Pabbly webhook URL to save in Leadberry. |
