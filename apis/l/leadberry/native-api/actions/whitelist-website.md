# Whitelist Website with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/whiteListSite`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Whitelist Website](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `isp` | body | `string` | no |
| `token` | body | `string` | no |
