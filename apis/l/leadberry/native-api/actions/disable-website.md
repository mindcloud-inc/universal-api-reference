# Disable Website with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/disableSite`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Disable Website](https://www.leadberry.com/install-leadberry)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dataProviderId` | body | `string` | no |
| `isp` | body | `string` | no |
| `token` | body | `string` | no |
| `type` | body | `string` | no |
