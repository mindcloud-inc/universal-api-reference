# Add Tracking Website with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/addTrackingWebsite`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Add Tracking Website](https://www.leadberry.com/install-leadberry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Website URL to add for Leadberry tracking. |
