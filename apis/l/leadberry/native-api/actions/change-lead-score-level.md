# Change Lead Score Level with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/changeLeadScoreLevel`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Change Lead Score Level](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | yes | Lead score level value from 1-4. |
