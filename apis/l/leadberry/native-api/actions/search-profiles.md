# Search Profiles with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/queryProfiles`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Search Profiles](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)
