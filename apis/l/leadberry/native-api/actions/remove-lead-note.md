# Remove Lead Note with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/removeNote`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Remove Lead Note](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Leadberry note ID to remove. |
