# Remove Pabbly Webhook with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/pabbly/remove-webhook`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Remove Pabbly Webhook](https://www.leadberry.com/pabbly)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | no | Leadberry Pabbly webhook ID to remove. |
