# List Added Profiles with Leadberry

## Endpoint

- **Method:** `GET`
- **Path:** `/data/getAddedProfiles`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [List Added Profiles](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | query | `string` | yes | Leadberry token value read from the app session context. |
