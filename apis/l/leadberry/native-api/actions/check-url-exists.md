# Check URL Exists with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/checkUrlExists`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Check URL Exists](https://www.leadberry.com/install-leadberry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | no | Website URL to check in Leadberry. |
