# List Leads with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/getLeads`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [List Leads](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Capabilities

This operation supports [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bannedLeads` | body | `string` | no |
| `endDate` | body | `string` | no |
| `flaggedAsImportant` | body | `string` | no |
| `search` | body | `string` | no |
| `startDate` | body | `string` | no |
