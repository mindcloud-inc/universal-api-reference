# Download Email Addresses with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/downloadEmailAddresses`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Download Email Addresses](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `emails` | body | `string` | no |
