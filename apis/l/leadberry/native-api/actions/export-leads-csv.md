# Export Leads CSV with Leadberry

## Endpoint

- **Method:** `POST`
- **Path:** `/data/exportCSV`
- **Base URL:** `https://app.leadberry.com`
- **Official documentation:** [Export Leads CSV](https://app.leadberry.com/js/dist/all.min.js?ver=20221103_1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `aid` | body | `string` | no |
| `exportFrom` | body | `string` | no |
| `exportTo` | body | `string` | no |
| `options` | body | `string` | no |
| `pid` | body | `string` | no |
| `wid` | body | `string` | no |
