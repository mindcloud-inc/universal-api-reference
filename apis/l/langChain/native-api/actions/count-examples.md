# Count Examples with LangChain

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/examples/count`
- **Base URL:** `https://api.smith.langchain.com`
- **Official documentation:** [Count Examples](https://api.smith.langchain.com/redoc#tag/examples/operation/count_examples_api_v1_examples_count_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset` | query | `string` | yes | Dataset identifier used to scope example count. |
