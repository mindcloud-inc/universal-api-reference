# Update Dataset with LangChain

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/datasets/:datasetId`
- **Base URL:** `https://api.smith.langchain.com`
- **Official documentation:** [Update Dataset](https://api.smith.langchain.com/redoc#tag/datasets/operation/update_dataset_api_v1_datasets__dataset_id__patch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes | Dataset identifier. |
