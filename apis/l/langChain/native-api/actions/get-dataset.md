# Get Dataset with LangChain

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datasets/:datasetId`
- **Base URL:** `https://api.smith.langchain.com`
- **Official documentation:** [Get Dataset](https://api.smith.langchain.com/redoc#tag/datasets/operation/read_dataset_api_v1_datasets__dataset_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | path | `string` | yes | Dataset identifier. |
