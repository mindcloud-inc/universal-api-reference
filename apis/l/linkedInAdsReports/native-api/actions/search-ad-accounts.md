# Search Ad Accounts with LinkedIn Ads Reports

Finds ad accounts in LinkedIn Ads Reports.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/adAccounts`
- **Base URL:** `https://api.linkedin.com`
- **Official documentation:** [Search Ad Accounts](https://learn.microsoft.com/en-us/linkedin/marketing/integrations/ads/account-structure/create-and-manage-accounts?view=li-lms-2026-01)

## Capabilities

This operation supports [pagination](../README.md#pagination).
