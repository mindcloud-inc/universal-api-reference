# Update multiple transactions with Lunch Money

## Endpoint

- **Method:** `PUT`
- **Path:** `/transactions`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Update multiple transactions](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transactions[]` | body | `array<object>` | yes |
