# Delete a file attachment with Lunch Money

## Endpoint

- **Method:** `DELETE`
- **Path:** `/transactions/attachments/:file_id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Delete a file attachment](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `number` | yes |
