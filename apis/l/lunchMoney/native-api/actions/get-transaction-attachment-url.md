# Get transaction attachment download URL with Lunch Money

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/attachments/:file_id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Get transaction attachment download URL](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `number` | yes |
