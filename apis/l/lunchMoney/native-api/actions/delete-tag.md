# Delete a tag with Lunch Money

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Delete a tag](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `force` | query | `boolean` | no |
