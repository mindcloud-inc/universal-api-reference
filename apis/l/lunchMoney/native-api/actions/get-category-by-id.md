# Get a single category with Lunch Money

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Get a single category](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
