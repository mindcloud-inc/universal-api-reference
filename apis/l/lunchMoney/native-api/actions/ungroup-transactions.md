# Delete a transaction group with Lunch Money

## Endpoint

- **Method:** `DELETE`
- **Path:** `/transactions/group/:id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Delete a transaction group](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
