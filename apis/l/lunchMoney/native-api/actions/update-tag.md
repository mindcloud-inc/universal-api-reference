# Update an existing tag with Lunch Money

## Endpoint

- **Method:** `PUT`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Update an existing tag](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `description` | body | `string` | no |
