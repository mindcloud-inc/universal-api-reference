# Get all categories with Lunch Money

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Get all categories](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `format` | query | `string` | no |
