# Delete a category or category group with Lunch Money

## Endpoint

- **Method:** `DELETE`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.lunchmoney.dev/v2`
- **Official documentation:** [Delete a category or category group](https://alpha.lunchmoney.dev/v2/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
| `force` | query | `boolean` | no |
