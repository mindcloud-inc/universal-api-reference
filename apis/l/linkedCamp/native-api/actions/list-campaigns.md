# List Campaigns with LinkedCamp

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [List Campaigns](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional campaign status filter. |
