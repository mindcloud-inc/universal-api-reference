# Resume Sub-Account with LinkedCamp

## Endpoint

- **Method:** `POST`
- **Path:** `/users/resume`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [Resume Sub-Account](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Sub-account email address. |
