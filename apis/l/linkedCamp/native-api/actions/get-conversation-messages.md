# Get Conversation Messages with LinkedCamp

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [Get Conversation Messages](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Conversation identifier. |
