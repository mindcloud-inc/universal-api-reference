# Get Account API Token with LinkedCamp

## Endpoint

- **Method:** `GET`
- **Path:** `/tokens`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [Get Account API Token](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountEmail` | query | `string` | yes | Account email to retrieve an API token for. |
