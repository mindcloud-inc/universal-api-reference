# List Blacklist Entries with LinkedCamp

## Endpoint

- **Method:** `GET`
- **Path:** `/blacklists`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [List Blacklist Entries](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Optional blacklist type filter: PROFILE_URL, KEYWORD, or JOB_TITLE. |
