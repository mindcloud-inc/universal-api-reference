# Create Tag with LinkedCamp

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [Create Tag](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Tag name. |
| `color` | body | `string` | no | Tag color. |
