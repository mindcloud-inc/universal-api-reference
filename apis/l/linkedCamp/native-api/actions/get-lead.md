# Get Lead with LinkedCamp

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.linkedcamp.com`
- **Official documentation:** [Get Lead](https://api.linkedcamp.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Lead identifier. |
