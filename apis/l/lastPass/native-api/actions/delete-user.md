# Delete User with LastPass

Deletes an existing user from LastPass.

## Endpoint

- **Method:** `POST`
- **Path:** `/enterpriseapi.php`
- **Base URL:** `https://lastpass.com`
- **Official documentation:** [Delete User](https://support.lastpass.com/help/use-the-lastpass-enterprise-api-postman-collection)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | yes |
