# Get Detailed Shared Folder Data with LastPass

Retrieves detailed shared folder data from LastPass.

## Endpoint

- **Method:** `POST`
- **Path:** `/enterpriseapi.php`
- **Base URL:** `https://lastpass.com`
- **Official documentation:** [Get Detailed Shared Folder Data](https://support.lastpass.com/help/use-the-lastpass-enterprise-api-postman-collection)
