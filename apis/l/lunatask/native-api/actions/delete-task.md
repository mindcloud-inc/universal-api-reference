# Delete Task with Lunatask

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.lunatask.app/v1`
- **Official documentation:** [Delete Task](https://lunatask.app/api/tasks-api/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the task to delete |
