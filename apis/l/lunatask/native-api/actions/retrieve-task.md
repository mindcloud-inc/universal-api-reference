# Retrieve Task with Lunatask

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.lunatask.app/v1`
- **Official documentation:** [Retrieve Task](https://lunatask.app/api/tasks-api/show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the task to retrieve |
