# Delete Note with Lunatask

## Endpoint

- **Method:** `DELETE`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.lunatask.app/v1`
- **Official documentation:** [Delete Note](https://lunatask.app/api/notes-api/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the note to delete |
