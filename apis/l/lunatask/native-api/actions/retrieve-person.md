# Retrieve Person with Lunatask

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:id`
- **Base URL:** `https://api.lunatask.app/v1`
- **Official documentation:** [Retrieve Person](https://lunatask.app/api/people-api/show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the person to retrieve |
