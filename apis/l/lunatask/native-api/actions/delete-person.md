# Delete Person with Lunatask

## Endpoint

- **Method:** `DELETE`
- **Path:** `/people/:id`
- **Base URL:** `https://api.lunatask.app/v1`
- **Official documentation:** [Delete Person](https://lunatask.app/api/people-api/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the person to delete |
