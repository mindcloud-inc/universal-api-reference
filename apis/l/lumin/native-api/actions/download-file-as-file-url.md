# Download File As File URL with Lumin

## Endpoint

- **Method:** `GET`
- **Path:** `/signature_request/files_as_file_url/:signature_request_id`
- **Base URL:** `https://api.luminpdf.com/v1`
- **Official documentation:** [Download File As File URL](https://developers.luminpdf.com/api/download-file-as-file-url/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signature_request_id` | path | `string` | yes | ID of the signature request. |
