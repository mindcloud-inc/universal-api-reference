# Download File with Lumin

## Endpoint

- **Method:** `GET`
- **Path:** `/signature_request/files/:signature_request_id`
- **Base URL:** `https://api.luminpdf.com/v1`
- **Official documentation:** [Download File](https://developers.luminpdf.com/api/download-file/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `signature_request_id` | path | `string` | yes | ID of the signature request. |
