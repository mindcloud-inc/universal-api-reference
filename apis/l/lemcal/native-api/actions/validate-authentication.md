# Validate Authentication with Lemcal

Retrieves the authenticated user from Lemcal.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.lemcal.com/api/lemcal`
- **Official documentation:** [Validate Authentication](https://developer.lemcal.com/#authentication)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
