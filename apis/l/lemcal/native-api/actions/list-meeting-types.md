# List Meeting Types with Lemcal

Retrieves your meeting types from Lemcal.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetingTypes`
- **Base URL:** `https://api.lemcal.com/api/lemcal`
- **Official documentation:** [List Meeting Types](https://developer.lemcal.com/#list-meeting-types)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
