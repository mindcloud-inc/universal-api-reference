# Delete Note with Locu

Deletes an existing note from Locu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Delete Note](https://locu.app/api/docs#tag/notes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Note ID |
