# Delete Project with Locu

Deletes an existing project from Locu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Delete Project](https://locu.app/api/docs#tag/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID |
