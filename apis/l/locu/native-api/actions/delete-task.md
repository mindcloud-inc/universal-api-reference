# Delete Task with Locu

Deletes an existing task from Locu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Delete Task](https://locu.app/api/docs#tag/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task ID |
