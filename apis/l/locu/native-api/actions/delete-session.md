# Delete Session with Locu

Deletes an existing session from Locu.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sessions/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Delete Session](https://locu.app/api/docs#tag/sessions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Session ID to delete. |
