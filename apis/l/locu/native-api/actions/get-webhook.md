# Get Webhook with Locu

Retrieves a single webhook by ID from Locu.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Get Webhook](https://locu.app/api/docs#tag/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Webhook ID to retrieve. |
