# Get Note with Locu

Retrieves a single note by ID from Locu.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Get Note](https://locu.app/api/docs#tag/notes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Note ID |
