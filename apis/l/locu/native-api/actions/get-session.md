# Get Session with Locu

Retrieves a single session by ID from Locu.

## Endpoint

- **Method:** `GET`
- **Path:** `/sessions/:id`
- **Base URL:** `https://api.locu.app/api/v1`
- **Official documentation:** [Get Session](https://locu.app/api/docs#tag/sessions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
