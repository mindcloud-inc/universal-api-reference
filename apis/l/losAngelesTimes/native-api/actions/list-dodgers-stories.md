# List Dodgers Stories with Los Angeles Times

Retrieves Los Angeles Times Dodgers stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/sports/dodgers/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Dodgers Stories](https://www.latimes.com/sports/dodgers/rss2.0.xml)
