# List Autos Stories with Los Angeles Times

Retrieves Los Angeles Times autos stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/business/autos/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Autos Stories](https://www.latimes.com/business/autos/rss2.0.xml)
