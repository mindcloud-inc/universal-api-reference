# List Books Stories with Los Angeles Times

Retrieves Los Angeles Times books stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/entertainment-arts/books/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Books Stories](https://www.latimes.com/entertainment-arts/books/rss2.0.xml)
