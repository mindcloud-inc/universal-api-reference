# List Awards Stories with Los Angeles Times

Retrieves Los Angeles Times awards stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/entertainment-arts/awards/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Awards Stories](https://www.latimes.com/entertainment-arts/awards/rss2.0.xml)
