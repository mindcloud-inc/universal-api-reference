# List Movies Stories with Los Angeles Times

Retrieves Los Angeles Times movies stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/entertainment-arts/movies/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Movies Stories](https://www.latimes.com/entertainment-arts/movies/rss2.0.xml)
