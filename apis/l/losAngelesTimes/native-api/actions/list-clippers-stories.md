# List Clippers Stories with Los Angeles Times

Retrieves Los Angeles Times Clippers stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/sports/clippers/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Clippers Stories](https://www.latimes.com/sports/clippers/rss2.0.xml)
