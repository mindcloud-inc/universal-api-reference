# List TV Stories with Los Angeles Times

Retrieves Los Angeles Times TV stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/entertainment-arts/tv/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List TV Stories](https://www.latimes.com/entertainment-arts/tv/rss2.0.xml)
