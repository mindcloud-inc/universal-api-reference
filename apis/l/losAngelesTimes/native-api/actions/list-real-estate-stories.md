# List Real Estate Stories with Los Angeles Times

Retrieves Los Angeles Times real estate stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/business/real-estate/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Real Estate Stories](https://www.latimes.com/business/real-estate/rss2.0.xml)
