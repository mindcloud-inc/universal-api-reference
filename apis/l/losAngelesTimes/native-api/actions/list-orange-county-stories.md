# List Orange County Stories with Los Angeles Times

Retrieves Los Angeles Times Orange County stories.

## Endpoint

- **Method:** `GET`
- **Path:** `/california/orange-county/rss2.0.xml`
- **Base URL:** `https://www.latimes.com`
- **Official documentation:** [List Orange County Stories](https://www.latimes.com/california/orange-county/rss2.0.xml)
