# Los Angeles Times: Native API Reference

A consolidated summary of Los Angeles Times's API configuration and 30 documented operations, with links to official documentation.

- **Official docs:** https://www.latimes.com/feeds
- **API base URL:** `https://www.latimes.com`

## Authentication

### No Authentication

Public Los Angeles Times RSS feeds do not require credentials.

This API does not require request authentication.

[Official authentication documentation](https://www.latimes.com/feeds)

## API conventions

Responses from this API use XML. Response data is read from `rss.channel.item`.
