# List Memory Documents with Langbase

## Endpoint

- **Method:** `GET`
- **Path:** `v1/memory/:memoryName/documents`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [List Memory Documents](https://langbase.com/docs/api-reference/memory/document-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memoryName` | path | `string` | yes | Memory name to list documents for. |
