# Delete Thread with Langbase

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/threads/:threadId`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [Delete Thread](https://langbase.com/docs/api-reference/threads/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `threadId` | path | `string` | yes | Thread ID to delete. |
