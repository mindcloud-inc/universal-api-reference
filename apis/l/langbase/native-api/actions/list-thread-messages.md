# List Thread Messages with Langbase

## Endpoint

- **Method:** `GET`
- **Path:** `v1/threads/:threadId/messages`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [List Thread Messages](https://langbase.com/docs/api-reference/threads/list-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `threadId` | path | `string` | yes | Thread ID to list messages for. |
