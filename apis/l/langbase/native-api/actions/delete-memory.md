# Delete Memory with Langbase

## Endpoint

- **Method:** `DELETE`
- **Path:** `v1/memory/:memoryName`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [Delete Memory](https://langbase.com/docs/api-reference/memory/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memoryName` | path | `string` | yes | Memory name to delete. |
