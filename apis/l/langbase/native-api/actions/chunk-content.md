# Chunk Content with Langbase

## Endpoint

- **Method:** `POST`
- **Path:** `v1/chunker`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [Chunk Content](https://langbase.com/docs/api-reference/chunker)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content` | body | `string` | yes | Text content to chunk. |
