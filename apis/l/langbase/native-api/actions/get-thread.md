# Get Thread with Langbase

## Endpoint

- **Method:** `GET`
- **Path:** `v1/threads/:threadId`
- **Base URL:** `https://api.langbase.com`
- **Official documentation:** [Get Thread](https://langbase.com/docs/api-reference/threads/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `threadId` | path | `string` | yes | Thread ID to fetch. |
