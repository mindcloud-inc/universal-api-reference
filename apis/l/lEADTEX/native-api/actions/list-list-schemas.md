# List List Schemas with LEADTEX

Retrieves list schemas from your LEADTEX account.

## Endpoint

- **Method:** `GET`
- **Path:** `/getListSchemas?api_token={apiKey}`
- **Base URL:** `https://app.leadteh.ru/api/v1`
- **Official documentation:** [List List Schemas](https://docs.leadteh.ru/rabota-s-api/spiski/schema-spiska/)
