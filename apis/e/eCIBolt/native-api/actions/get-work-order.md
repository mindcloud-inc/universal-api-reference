# Get Work Order with ECI Bolt

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/work_orders/:id`
- **Base URL:** `https://app.bolttech.net`
- **Official documentation:** [Get Work Order](https://app.bolttech.net/api-docs/index.html#/Work_Orders/get_open_v1_work_orders__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Id of the work order. |
