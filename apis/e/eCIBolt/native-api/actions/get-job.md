# Get Job with ECI Bolt

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/jobs/:id`
- **Base URL:** `https://app.bolttech.net`
- **Official documentation:** [Get Job](https://app.bolttech.net/api-docs/index.html#/Jobs/get_open_v1_jobs__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Id of the job. |
