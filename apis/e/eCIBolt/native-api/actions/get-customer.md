# Get Customer with ECI Bolt

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/customers/:id`
- **Base URL:** `https://app.bolttech.net`
- **Official documentation:** [Get Customer](https://app.bolttech.net/api-docs/index.html#/Customers/get_open_v1_customers__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Id of the customer. |
