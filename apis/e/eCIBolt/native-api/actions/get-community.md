# Get Community with ECI Bolt

## Endpoint

- **Method:** `GET`
- **Path:** `/open/v1/communities/:id`
- **Base URL:** `https://app.bolttech.net`
- **Official documentation:** [Get Community](https://app.bolttech.net/api-docs/index.html#/Communities/get_open_v1_communities__id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Id of the community. |
