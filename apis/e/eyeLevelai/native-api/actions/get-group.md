# Get Group with EyeLevel.ai

Retrieves a group from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/group/:groupId`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [Get Group](https://docs.eyelevel.ai/reference/api-reference/groups/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | The groupId of the group to look up. |
