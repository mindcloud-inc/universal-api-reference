# List Ingest Processes with EyeLevel.ai

Retrieves ingest processes from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [List Ingest Processes](https://docs.eyelevel.ai/reference/api-reference/documents/get-processes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `n` | query | `number` | no | The maximum number of returned processes. |
