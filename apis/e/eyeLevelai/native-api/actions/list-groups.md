# List Groups with EyeLevel.ai

Retrieves groups from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/group`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [List Groups](https://docs.eyelevel.ai/reference/api-reference/groups/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `n` | query | `number` | no | The maximum number of returned groups. |
