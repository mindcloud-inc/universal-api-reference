# Create Bucket with EyeLevel.ai

Creates a new bucket in EyeLevel.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/bucket`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [Create Bucket](https://docs.eyelevel.ai/reference/api-reference/buckets/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the bucket being created. |
