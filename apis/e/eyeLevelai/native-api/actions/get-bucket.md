# Get Bucket with EyeLevel.ai

Retrieves a bucket from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/bucket/:bucketId`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [Get Bucket](https://docs.eyelevel.ai/reference/api-reference/buckets/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bucketId` | path | `number` | yes | The bucketId of the bucket to look up. |
