# List Documents with EyeLevel.ai

Retrieves documents from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/ingest/documents`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [List Documents](https://docs.eyelevel.ai/reference/api-reference/documents/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `n` | query | `number` | no | The maximum number of returned documents. |
