# List Health Statuses with EyeLevel.ai

Retrieves health statuses from EyeLevel.ai.

- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [List Health Statuses](https://docs.eyelevel.ai/reference/api-reference/health/list)
