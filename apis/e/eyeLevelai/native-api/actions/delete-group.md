# Delete Group with EyeLevel.ai

Deletes an existing group from EyeLevel.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group/:groupId`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [Delete Group](https://docs.eyelevel.ai/reference/api-reference/groups/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | The groupId of the group to delete. |
