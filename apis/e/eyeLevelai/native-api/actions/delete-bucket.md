# Delete Bucket with EyeLevel.ai

Deletes an existing bucket from EyeLevel.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bucket/:bucketId`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [Delete Bucket](https://docs.eyelevel.ai/reference/api-reference/buckets/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bucketId` | path | `number` | yes | The bucketId of the bucket to delete. |
