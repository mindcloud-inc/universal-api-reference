# List Buckets with EyeLevel.ai

Retrieves buckets from EyeLevel.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/bucket`
- **Base URL:** `https://api.groundx.ai/api/v1`
- **Official documentation:** [List Buckets](https://docs.eyelevel.ai/reference/api-reference/buckets/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `n` | query | `number` | no | The maximum number of returned buckets. |
