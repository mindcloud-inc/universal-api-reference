# Get Event with EONET

Retrieves an event from EONET.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId`
- **Base URL:** `https://eonet.gsfc.nasa.gov/api/v3`
- **Official documentation:** [Get Event](https://eonet.gsfc.nasa.gov/docs/v3#events-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Unique EONET event ID. |
