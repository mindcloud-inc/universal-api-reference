# Get User Subscription with ElevenLabs

Retrieves a user subscription from ElevenLabs.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/subscription`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Get User Subscription](https://elevenlabs.io/docs/api-reference/user/subscription/get)
