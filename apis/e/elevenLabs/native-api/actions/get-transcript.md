# Get Transcript with ElevenLabs

Retrieves a transcript from ElevenLabs.

## Endpoint

- **Method:** `GET`
- **Path:** `/speech-to-text/transcripts/:transcription_id`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Get Transcript](https://elevenlabs.io/docs/api-reference/speech-to-text/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcription_id` | path | `string` | yes | The transcript identifier. |
