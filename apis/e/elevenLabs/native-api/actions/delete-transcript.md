# Delete Transcript with ElevenLabs

Deletes an existing transcript from ElevenLabs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/speech-to-text/transcripts/:transcription_id`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Delete Transcript](https://elevenlabs.io/docs/api-reference/speech-to-text/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transcription_id` | path | `string` | yes | The transcript identifier. |
