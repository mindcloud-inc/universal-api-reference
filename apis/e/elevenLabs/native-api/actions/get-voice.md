# Get Voice with ElevenLabs

Retrieves a voice from ElevenLabs.

## Endpoint

- **Method:** `GET`
- **Path:** `/voices/:voice_id`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Get Voice](https://elevenlabs.io/docs/api-reference/voices/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `voice_id` | path | `string` | yes | The unique identifier of the voice. |
