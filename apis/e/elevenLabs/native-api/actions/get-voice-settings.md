# Get Voice Settings with ElevenLabs

Retrieves voice settings from ElevenLabs.

## Endpoint

- **Method:** `GET`
- **Path:** `/voices/:voice_id/settings`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Get Voice Settings](https://elevenlabs.io/docs/api-reference/voices/settings/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `voice_id` | path | `string` | yes | The unique identifier of the voice. |
