# Get History Item with ElevenLabs

Retrieves a generated audio item from ElevenLabs.

## Endpoint

- **Method:** `GET`
- **Path:** `/history/:history_item_id`
- **Base URL:** `https://api.elevenlabs.io/v1`
- **Official documentation:** [Get History Item](https://elevenlabs.io/docs/api-reference/history/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `history_item_id` | path | `string` | yes | The history item identifier. |
