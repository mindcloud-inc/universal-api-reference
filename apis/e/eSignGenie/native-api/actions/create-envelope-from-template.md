# Create Envelope from Template with eSign Genie

Creates a new envelope from a template in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/createFolder`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Create Envelope from Template](https://docs.developer-api.foxit.com/)
