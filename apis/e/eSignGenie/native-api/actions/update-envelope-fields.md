# Update Envelope Fields with eSign Genie

Updates envelope fields in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/updateEnvelopeFields`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Update Envelope Fields](https://docs.developer-api.foxit.com/)
