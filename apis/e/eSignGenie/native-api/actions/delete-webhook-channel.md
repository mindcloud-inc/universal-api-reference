# Delete Webhook Channel with eSign Genie

Deletes a webhook channel from eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhook/deletechannels`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Delete Webhook Channel](https://docs.developer-api.foxit.com/)
