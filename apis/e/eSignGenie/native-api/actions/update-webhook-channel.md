# Update Webhook Channel with eSign Genie

Updates an existing webhook channel in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhook/updatewebhookchannel`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Update Webhook Channel](https://docs.developer-api.foxit.com/)
