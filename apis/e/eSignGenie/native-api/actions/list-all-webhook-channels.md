# List All Webhook Channels with eSign Genie

Retrieves webhook channels from eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/channellist`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [List All Webhook Channels](https://docs.developer-api.foxit.com/)
