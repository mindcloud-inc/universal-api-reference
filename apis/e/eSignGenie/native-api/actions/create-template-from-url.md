# Create Template from URL with eSign Genie

Creates a new template from document URLs in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/createtemplate`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Create Template from URL](https://docs.developer-api.foxit.com/)
