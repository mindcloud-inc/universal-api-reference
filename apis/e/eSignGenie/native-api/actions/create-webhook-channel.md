# Create Webhook Channel with eSign Genie

Creates a new webhook channel in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhook/createwebhookchannel`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Create Webhook Channel](https://docs.developer-api.foxit.com/)
