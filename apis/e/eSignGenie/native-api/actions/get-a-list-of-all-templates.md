# Get a List of All Templates with eSign Genie

Retrieves templates from eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/list`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Get a List of All Templates](https://docs.developer-api.foxit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | query | `number` | no | Optional template ID filter supported by the Foxit example request. |
