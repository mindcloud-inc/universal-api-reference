# Get Envelope Details with eSign Genie

Retrieves envelope details from eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/myfolder`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Get Envelope Details](https://docs.developer-api.foxit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | query | `number` | yes | The Foxit eSign envelope ID to retrieve. |
