# Move Envelopes to Recycle Bin with eSign Genie

Moves envelopes to the recycle bin in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/movetorecyclebin`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Move Envelopes to Recycle Bin](https://docs.developer-api.foxit.com/)
