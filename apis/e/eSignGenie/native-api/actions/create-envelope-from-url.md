# Create Envelope from URL with eSign Genie

Creates a new envelope from document URLs in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/createfolder`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Create Envelope from URL](https://docs.developer-api.foxit.com/)
