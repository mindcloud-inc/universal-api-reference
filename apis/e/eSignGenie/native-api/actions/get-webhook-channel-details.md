# Get Webhook Channel Details with eSign Genie

Retrieves webhook channel details from eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/mychannel`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Get Webhook Channel Details](https://docs.developer-api.foxit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | query | `number` | yes | The Foxit eSign webhook channel ID to retrieve. |
