# Get Template Details with eSign Genie

Retrieves template details from eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/mytemplate`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Get Template Details](https://docs.developer-api.foxit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | query | `number` | yes | The Foxit eSign template ID to retrieve. |
