# Get Templates by Template IDs with eSign Genie

Retrieves templates from eSign Genie by template ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/templateDetails`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Get Templates by Template IDs](https://docs.developer-api.foxit.com/)
