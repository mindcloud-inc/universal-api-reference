# Reactivate Webhook Channel with eSign Genie

Reactivates a webhook channel in eSign Genie.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/channelreactivate`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Reactivate Webhook Channel](https://docs.developer-api.foxit.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | query | `number` | yes | The Foxit eSign webhook channel ID to reactivate. |
