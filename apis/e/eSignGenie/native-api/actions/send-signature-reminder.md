# Send Signature Reminder with eSign Genie

Sends a signature reminder from eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/signaturereminder`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Send Signature Reminder](https://docs.developer-api.foxit.com/)
