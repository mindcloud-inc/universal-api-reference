# Modify Shared Envelope with eSign Genie

Updates a shared envelope in eSign Genie.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/modifySharedFolder`
- **Base URL:** `https://na1.foxitesign.foxit.com/api`
- **Official documentation:** [Modify Shared Envelope](https://docs.developer-api.foxit.com/)
