# Delete Time Record with Everhour

Deletes an existing time record from Everhour.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/time/:timeId`
- **Base URL:** `https://api.everhour.com`
- **Official documentation:** [Delete Time Record](https://everhour.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timeId` | path | `number` | yes | Everhour time record ID. |
