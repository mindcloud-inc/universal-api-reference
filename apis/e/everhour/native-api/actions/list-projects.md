# List Projects with Everhour

Retrieves projects from Everhour.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.everhour.com`
- **Official documentation:** [List Projects](https://everhour.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of records to return. |
| `query` | query | `string` | no | Filter projects by name or search term. |
