# Delete Task with Everhour

Deletes an existing task from Everhour.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.everhour.com`
- **Official documentation:** [Delete Task](https://everhour.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Everhour task ID. |
