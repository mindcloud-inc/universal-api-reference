# Get Current User with Everhour

Retrieves the current user from Everhour.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me`
- **Base URL:** `https://api.everhour.com`
- **Official documentation:** [Get Current User](https://everhour.docs.apiary.io/reference/0/users/your-profile)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |
