# Get Task with Everhour

Retrieves a specific task from Everhour.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://api.everhour.com`
- **Official documentation:** [Get Task](https://everhour.docs.apiary.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | Everhour task ID. |
