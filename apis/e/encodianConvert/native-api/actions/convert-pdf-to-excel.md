# Convert - PDF to Excel with Encodian - Convert

Creates an Excel file from a PDF in Encodian - Convert.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Conversion/ConvertPdfToExcel`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Convert - PDF to Excel](https://support.encodian.com/hc/en-gb/articles/17011591184284)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `file` | yes | The file content of the source PDF file. |
