# Convert - HEIC to PDF with Encodian - Convert

Creates a PDF file from a HEIC image in Encodian - Convert.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Conversion/ConvertHeicToPdf`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Convert - HEIC to PDF](https://support.encodian.com/hc/en-gb/articles/18068082274716-Convert-HEIC-to-PDF)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `file` | yes | The file content of the source HEIC file. |
