# Get an Operation Status with Encodian - Convert

Retrieves an operation status from Encodian - Convert.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/Conversion/GetOperationStatus`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Get an Operation Status](https://api.apps-encodian.com/swagger/Conversion/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `operationId` | query | `string` | yes | Retrieve the operation status for the Operation ID provided. |
