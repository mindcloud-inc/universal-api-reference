# Get Subscription Status with Encodian

Retrieves subscription status from Encodian.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/General/GetSubscriptionStatus`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Get Subscription Status](https://support.encodian.com/hc/en-gb/articles/360010176717-Get-Subscription-Status)
