# List Products with E-junkie

Retrieves product details from an E-junkie catalog.

## Endpoint

- **Method:** `POST`
- **Path:** `/{clientId}/`
- **Base URL:** `https://api.e-junkie.com/api`
- **Official documentation:** [List Products](https://www.e-junkie.com/wiki/help-products-api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
