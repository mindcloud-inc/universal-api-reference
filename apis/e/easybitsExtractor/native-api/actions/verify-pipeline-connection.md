# Verify Pipeline Connection with easybits Extractor

Verifies a pipeline connection in easybits Extractor.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/:pipelineId/test`
- **Base URL:** `https://extractor.easybits.tech/api`
- **Official documentation:** [Verify Pipeline Connection](https://extractor.easybits.tech/documentation/integration)
