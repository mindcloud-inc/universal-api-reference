# Download Email List with EmailListVerify

Downloads a finished email list from EmailListVerify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/maillists/:id`
- **Base URL:** `https://api.emaillistverify.com`
- **Official documentation:** [Download Email List](https://api.emaillistverify.com/api-doc#/Verification%20Endpoints/downloadMaillist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Finished email list ID to download. |
