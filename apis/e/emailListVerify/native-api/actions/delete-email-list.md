# Delete Email List with EmailListVerify

Deletes a finished email list from EmailListVerify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/maillists/:id`
- **Base URL:** `https://api.emaillistverify.com`
- **Official documentation:** [Delete Email List](https://api.emaillistverify.com/api-doc#/Verification%20Endpoints/deleteMaillist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Finished email list ID to delete. |
