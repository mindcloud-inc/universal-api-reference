# Get Email List Progress with EmailListVerify

Retrieves email list verification progress from EmailListVerify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/maillists/:id/progress`
- **Base URL:** `https://api.emaillistverify.com`
- **Official documentation:** [Get Email List Progress](https://api.emaillistverify.com/api-doc#/Verification%20Endpoints/maillistProgress)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Uploaded email list ID. |
