# Get Inbox Placement Test with EmailListVerify

Retrieves inbox placement test status and results from EmailListVerify.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/inboxPlacementTests/:code`
- **Base URL:** `https://api.emaillistverify.com`
- **Official documentation:** [Get Inbox Placement Test](https://api.emaillistverify.com/api-doc#/Inbox%20Placement%20Test%20Endpoints/getPlacementTest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Inbox placement test tracking code. |
