# Create Order with EasyPost

Creates a new order in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Order](https://docs.easypost.com/docs/orders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order` | body | `object` | yes | Order object to create. |
