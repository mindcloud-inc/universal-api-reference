# Get Customs Item with EasyPost

Retrieves details for a customs item from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/customs_items/:id`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Get Customs Item](https://docs.easypost.com/docs/customs-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EasyPost CustomsItem ID, beginning with cstitem_. |
