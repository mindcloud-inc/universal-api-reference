# Get Batch with EasyPost

Retrieves details for a batch from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/batches/:id`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Get Batch](https://docs.easypost.com/docs/batches)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EasyPost Batch ID, beginning with batch_. |
