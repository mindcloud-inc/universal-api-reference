# List Pickups with EasyPost

Retrieves a list of pickups from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/pickups`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Pickups](https://docs.easypost.com/docs/pickups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
