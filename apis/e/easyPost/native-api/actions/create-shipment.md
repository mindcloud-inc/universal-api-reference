# Create Shipment with EasyPost

Creates a new shipment in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/shipments`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Shipment](https://docs.easypost.com/docs/shipments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipment` | body | `object` | yes | Shipment object to create. |
