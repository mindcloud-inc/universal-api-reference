# List Trackers with EasyPost

Retrieves a list of trackers from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackers`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Trackers](https://docs.easypost.com/docs/trackers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
