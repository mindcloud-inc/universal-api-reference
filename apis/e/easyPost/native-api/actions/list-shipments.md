# List Shipments with EasyPost

Retrieves a list of shipments from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Shipments](https://docs.easypost.com/docs/shipments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
