# Create Refund with EasyPost

Creates a new refund in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/refunds`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Refund](https://docs.easypost.com/docs/refunds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `refund` | body | `object` | yes | Refund request object to create. |
