# Create Address with EasyPost

Creates a new address in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/addresses`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Address](https://docs.easypost.com/docs/addresses)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | body | `object` | yes | Address object to create. |
