# Create Tracker with EasyPost

Creates a new tracker in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/trackers`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Tracker](https://docs.easypost.com/docs/trackers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tracker` | body | `object` | yes | Tracker object to create. |
