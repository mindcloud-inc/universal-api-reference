# List Batches with EasyPost

Retrieves a list of batches from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/batches`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Batches](https://docs.easypost.com/docs/batches)

## Capabilities

This operation supports [pagination](../README.md#pagination).
