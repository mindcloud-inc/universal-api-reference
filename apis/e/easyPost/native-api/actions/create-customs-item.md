# Create Customs Item with EasyPost

Creates a new customs item in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/customs_items`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Customs Item](https://docs.easypost.com/docs/customs-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customs_item` | body | `object` | yes | CustomsItem object to create. |
