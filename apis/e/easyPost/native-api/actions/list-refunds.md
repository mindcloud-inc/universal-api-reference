# List Refunds with EasyPost

Retrieves a list of refunds from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/refunds`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Refunds](https://docs.easypost.com/docs/refunds)

## Capabilities

This operation supports [pagination](../README.md#pagination).
