# Get Customs Info with EasyPost

Retrieves details for customs info from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/customs_infos/:id`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Get Customs Info](https://docs.easypost.com/docs/customs-infos)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EasyPost CustomsInfo ID, beginning with cstinfo_. |
