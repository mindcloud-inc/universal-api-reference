# List Addresses with EasyPost

Retrieves a list of addresses from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [List Addresses](https://docs.easypost.com/docs/addresses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
