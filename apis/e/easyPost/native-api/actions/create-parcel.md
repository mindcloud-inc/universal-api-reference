# Create Parcel with EasyPost

Creates a new parcel in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/parcels`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Parcel](https://docs.easypost.com/docs/parcels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `parcel` | body | `object` | yes | Parcel object to create. |
