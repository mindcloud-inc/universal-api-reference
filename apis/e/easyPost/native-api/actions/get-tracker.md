# Get Tracker with EasyPost

Retrieves details for a tracker from EasyPost.

## Endpoint

- **Method:** `GET`
- **Path:** `/trackers/:id`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Get Tracker](https://docs.easypost.com/docs/trackers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EasyPost Tracker ID, beginning with trk_. |
