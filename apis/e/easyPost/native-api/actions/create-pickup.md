# Create Pickup with EasyPost

Creates a new pickup in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/pickups`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Pickup](https://docs.easypost.com/docs/pickups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pickup` | body | `object` | yes | Pickup object to create. |
