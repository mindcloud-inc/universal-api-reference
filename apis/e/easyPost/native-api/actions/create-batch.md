# Create Batch with EasyPost

Creates a new batch in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/batches`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Batch](https://docs.easypost.com/docs/batches)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `batch` | body | `object` | yes | Batch object to create. |
