# Create Customs Info with EasyPost

Creates new customs info in EasyPost.

## Endpoint

- **Method:** `POST`
- **Path:** `/customs_infos`
- **Base URL:** `https://api.easypost.com/v2`
- **Official documentation:** [Create Customs Info](https://docs.easypost.com/docs/customs-infos)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customs_info` | body | `object` | yes | CustomsInfo object to create. |
