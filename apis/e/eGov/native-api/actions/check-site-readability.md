# Check Site Readability with e-Gov

Checks whether the e-Gov site is readable.

## Endpoint

- **Method:** `GET`
- **Path:** `/site_read`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [Check Site Readability](https://data.e-gov.go.jp/data/api/3/action/help_show?name=site_read)
