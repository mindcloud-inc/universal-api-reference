# Get Action Help with e-Gov

Retrieves API action help from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/help_show`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [Get Action Help](https://data.e-gov.go.jp/data/api/3/action/help_show?name=help_show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
