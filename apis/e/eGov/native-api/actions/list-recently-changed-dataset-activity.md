# List Recently Changed Dataset Activity with e-Gov

Retrieves recently changed dataset activity from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/recently_changed_packages_activity_list`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Recently Changed Dataset Activity](https://data.e-gov.go.jp/data/api/3/action/help_show?name=recently_changed_packages_activity_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
