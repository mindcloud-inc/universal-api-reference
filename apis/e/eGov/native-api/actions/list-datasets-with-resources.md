# List Datasets With Resources with e-Gov

Retrieves datasets with resources from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/current_package_list_with_resources`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Datasets With Resources](https://data.e-gov.go.jp/data/api/3/action/help_show?name=current_package_list_with_resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
