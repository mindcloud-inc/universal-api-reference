# List Tag Vocabularies with e-Gov

Retrieves tag vocabularies from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/vocabulary_list`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Tag Vocabularies](https://data.e-gov.go.jp/data/api/3/action/help_show?name=vocabulary_list)
