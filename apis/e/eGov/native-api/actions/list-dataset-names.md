# List Dataset Names with e-Gov

Retrieves dataset names from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/package_list`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Dataset Names](https://data.e-gov.go.jp/data/api/3/action/help_show?name=package_list)
