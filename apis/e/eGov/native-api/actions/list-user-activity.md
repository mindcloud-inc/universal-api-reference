# List User Activity with e-Gov

Retrieves user activity from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_activity_list`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List User Activity](https://data.e-gov.go.jp/data/api/3/action/help_show?name=user_activity_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
