# List Licenses with e-Gov

Retrieves dataset licenses from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/license_list`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Licenses](https://data.e-gov.go.jp/data/api/3/action/help_show?name=license_list)
