# Get Site Status with e-Gov

Retrieves site status from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/status_show`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [Get Site Status](https://data.e-gov.go.jp/data/api/3/action/help_show?name=status_show)
