# Get Resource with e-Gov

Retrieves resource metadata from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource_show`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [Get Resource](https://data.e-gov.go.jp/data/api/3/action/help_show?name=resource_show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
