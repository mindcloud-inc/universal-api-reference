# List Group Datasets with e-Gov

Retrieves datasets in a group from e-Gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/group_package_show`
- **Base URL:** `https://data.e-gov.go.jp/data/api/action`
- **Official documentation:** [List Group Datasets](https://data.e-gov.go.jp/data/api/3/action/help_show?name=group_package_show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | yes |
