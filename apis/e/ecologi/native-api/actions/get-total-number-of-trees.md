# Get Total Number of Trees with Ecologi

Retrieves total trees planted from Ecologi.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username/trees`
- **Base URL:** `https://public.ecologi.com`
- **Official documentation:** [Get Total Number of Trees](https://docs.ecologi.com/docs/public-api-docs/2531efb510c5b-get-total-number-of-trees)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Your Ecologi username. |
