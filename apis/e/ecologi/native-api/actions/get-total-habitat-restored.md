# Get Total Habitat Restored with Ecologi

Retrieves total habitat restored from Ecologi.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username/habitat-restoration`
- **Base URL:** `https://public.ecologi.com`
- **Official documentation:** [Get Total Habitat Restored](https://docs.ecologi.com/docs/public-api-docs/3c74a892cdd4c-get-total-habitat-restored)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Your Ecologi username. |
