# Get Total Tonnes of CO2e Removed with Ecologi

Retrieves total CO2e removed from Ecologi.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username/carbon-removal`
- **Base URL:** `https://public.ecologi.com`
- **Official documentation:** [Get Total Tonnes of CO2e Removed](https://docs.ecologi.com/docs/public-api-docs/71d944cfdd8cd-get-total-tonnes-of-co-e-removed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Your Ecologi username. |
