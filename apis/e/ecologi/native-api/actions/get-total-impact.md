# Get Total Impact with Ecologi

Retrieves total impact from Ecologi.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:username/impact`
- **Base URL:** `https://public.ecologi.com`
- **Official documentation:** [Get Total Impact](https://docs.ecologi.com/docs/public-api-docs/0eb5caf374377-get-total-impact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Your Ecologi username. |
