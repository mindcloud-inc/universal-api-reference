# List Users with Eventzilla

Retrieves users from Eventzilla.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://www.eventzillaapi.net/api/v2`
- **Official documentation:** [List Users](https://developer.eventzilla.net/docs/#users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
