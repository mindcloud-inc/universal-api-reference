# Get Event with Eventzilla

Retrieves an event from Eventzilla.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventid`
- **Base URL:** `https://www.eventzillaapi.net/api/v2`
- **Official documentation:** [Get Event](https://developer.eventzilla.net/docs/#events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventid` | path | `number` | yes | The Eventzilla event identifier. |
