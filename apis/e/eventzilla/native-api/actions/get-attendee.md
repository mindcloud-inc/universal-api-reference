# Get Attendee with Eventzilla

Retrieves an attendee from Eventzilla.

## Endpoint

- **Method:** `GET`
- **Path:** `/attendees/:attendeeid`
- **Base URL:** `https://www.eventzillaapi.net/api/v2`
- **Official documentation:** [Get Attendee](https://developer.eventzilla.net/docs/#attendees)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attendeeid` | path | `number` | yes | The attendee identifier. |
