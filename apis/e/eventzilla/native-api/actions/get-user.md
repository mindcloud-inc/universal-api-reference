# Get User with Eventzilla

Retrieves a user from Eventzilla.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userid`
- **Base URL:** `https://www.eventzillaapi.net/api/v2`
- **Official documentation:** [Get User](https://developer.eventzilla.net/docs/#users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userid` | path | `number` | yes | The Eventzilla user identifier. |
