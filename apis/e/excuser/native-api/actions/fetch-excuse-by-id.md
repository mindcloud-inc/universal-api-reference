# Fetch Excuse By ID with Excuser

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/excuse/id/:id`
- **Base URL:** `https://excuser-three.vercel.app`
- **Official documentation:** [Fetch Excuse By ID](https://excuser-three.vercel.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric excuse ID from the provider's documented category ID ranges. |
