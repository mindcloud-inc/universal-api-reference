# Fetch Random Excuses with Excuser

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/excuse/:count`
- **Base URL:** `https://excuser-three.vercel.app`
- **Official documentation:** [Fetch Random Excuses](https://excuser-three.vercel.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | path | `number` | yes | Number of random excuses to return. |
