# Create Event with Evenium

Creates a new event in Evenium.

## Endpoint

- **Method:** `POST`
- **Path:** `https://evenium.com/api/2/member/events`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Create Event](https://static.evenium.com/api-docs/organizer/index-json.html#_create_events)
