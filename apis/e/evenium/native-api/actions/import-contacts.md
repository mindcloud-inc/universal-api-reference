# Import Contacts with Evenium

Imports contacts into Evenium.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Import Contacts](https://static.evenium.com/api-docs/organizer/index-json.html#_import_contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contacts` | body | `string` | no | Contacts payload for bulk import. |
