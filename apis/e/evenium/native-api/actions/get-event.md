# Get Event with Evenium

Retrieves an event from Evenium.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Get Event](https://static.evenium.com/api-docs/organizer/index-json.html#_get_event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `number` | yes | The Evenium event ID. |
