# Get Contact by Custom ID with Evenium

Retrieves a contact from Evenium by custom ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/customId/:customId`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Get Contact by Custom ID](https://static.evenium.com/api-docs/organizer/index-json.html#_get_contact_by_custom_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customId` | path | `string` | yes | The Evenium Custom ID. |
