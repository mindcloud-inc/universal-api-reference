# List Hotels with Evenium

Retrieves hotels from Evenium.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId/hotels`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [List Hotels](https://static.evenium.com/api-docs/organizer/index-json.html#_get_hotels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `number` | yes | The Evenium event ID. |
