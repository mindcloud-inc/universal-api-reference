# Get Contact with Evenium

Retrieves a contact from Evenium.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Get Contact](https://static.evenium.com/api-docs/organizer/index-json.html#_get_contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | The Evenium Contact ID. |
