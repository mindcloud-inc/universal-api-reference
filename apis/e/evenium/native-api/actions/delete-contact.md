# Delete Contact with Evenium

Deletes an existing contact from Evenium.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://evenium.com/api/1`
- **Official documentation:** [Delete Contact](https://static.evenium.com/api-docs/organizer/index-json.html#_remove_contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | The Evenium Contact ID. |
