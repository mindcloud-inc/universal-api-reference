# Get Catalog with Emporix Commerce Engine

Retrieves a catalog from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/{tenantId}/catalogs/:catalogId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Catalog](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/catalog/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `catalogId` | path | `string` | yes | The unique ID of the catalog. |
