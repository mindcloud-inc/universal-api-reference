# List Brands with Emporix Commerce Engine

Retrieves brands from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/brands`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Brands](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/brand-service/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
