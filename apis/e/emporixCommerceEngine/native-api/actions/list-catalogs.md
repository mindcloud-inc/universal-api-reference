# List Catalogs with Emporix Commerce Engine

Retrieves catalogs from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/{tenantId}/catalogs`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Catalogs](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/catalog/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
