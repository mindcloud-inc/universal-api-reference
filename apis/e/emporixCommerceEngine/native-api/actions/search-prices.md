# Search Prices with Emporix Commerce Engine

Finds prices in Emporix Commerce Engine by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/price/{tenantId}/prices/search`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Search Prices](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/prices-and-taxes/price-service/api-reference/api.yml)
