# Match Prices with Emporix Commerce Engine

Finds matching prices in Emporix Commerce Engine.

## Endpoint

- **Method:** `POST`
- **Path:** `/price/{tenantId}/match-prices`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Match Prices](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/prices-and-taxes/price-service/api-reference/api.yml)
