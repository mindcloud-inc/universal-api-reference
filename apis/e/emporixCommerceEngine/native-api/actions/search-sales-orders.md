# Search Sales Orders with Emporix Commerce Engine

Finds sales orders in Emporix Commerce Engine by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/order-v2/{tenantId}/salesorders/search`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Search Sales Orders](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/orders/order/api-reference/api.yml)
