# List Category Trees with Emporix Commerce Engine

Retrieves category trees from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/{tenantId}/category-trees`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Category Trees](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/category-tree/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
