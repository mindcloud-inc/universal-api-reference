# List Products with Emporix Commerce Engine

Retrieves products from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/{tenantId}/products`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Products](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/product-service/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
