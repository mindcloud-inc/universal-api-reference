# Get Brand with Emporix Commerce Engine

Retrieves a brand from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/brand/brands/:brandId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Brand](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/brand-service/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brandId` | path | `string` | yes | The unique ID of the brand to retrieve. |
