# Create Cart with Emporix Commerce Engine

Creates a new cart in Emporix Commerce Engine.

## Endpoint

- **Method:** `POST`
- **Path:** `/cart/{tenantId}/carts`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Create Cart](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/checkout/cart/api-reference/api.yml)
