# Create Catalog with Emporix Commerce Engine

Creates a new catalog in Emporix Commerce Engine.

## Endpoint

- **Method:** `POST`
- **Path:** `/catalog/{tenantId}/catalogs`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Create Catalog](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/catalog/api-reference/api.yml)
