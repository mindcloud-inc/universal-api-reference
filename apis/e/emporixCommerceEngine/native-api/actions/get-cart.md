# Get Cart with Emporix Commerce Engine

Retrieves a cart from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/cart/{tenantId}/carts/:cartId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Cart](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/checkout/cart/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cartId` | path | `string` | yes | The unique ID of the cart. |
