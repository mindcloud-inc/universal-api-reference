# Get Price List with Emporix Commerce Engine

Retrieves a price list from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/price/{tenantId}/price-lists/:priceListId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Price List](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/prices-and-taxes/price-service/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `priceListId` | path | `string` | yes | The unique ID of the price list. |
