# Create Product with Emporix Commerce Engine

Creates a new product in Emporix Commerce Engine.

## Endpoint

- **Method:** `POST`
- **Path:** `/product/{tenantId}/products`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Create Product](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/product-service/api-reference/api.yml)
