# Get Label with Emporix Commerce Engine

Retrieves a label from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Label](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/label-service/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | The unique ID of the label. |
