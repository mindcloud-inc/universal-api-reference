# List Labels with Emporix Commerce Engine

Retrieves labels from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Labels](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/label-service/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
