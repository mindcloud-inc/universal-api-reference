# Search Categories with Emporix Commerce Engine

Finds categories in Emporix Commerce Engine by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/category/{tenantId}/categories/search`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Search Categories](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/category-tree/api-reference/api.yml)
