# List Prices with Emporix Commerce Engine

Retrieves prices from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/price/{tenantId}/prices`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Prices](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/prices-and-taxes/price-service/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
