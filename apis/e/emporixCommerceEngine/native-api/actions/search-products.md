# Search Products with Emporix Commerce Engine

Finds products in Emporix Commerce Engine by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/product/{tenantId}/products/search`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Search Products](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/products-labels-and-brands/product-service/api-reference/api.yml)
