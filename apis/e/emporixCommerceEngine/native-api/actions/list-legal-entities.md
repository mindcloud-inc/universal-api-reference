# List Legal Entities with Emporix Commerce Engine

Retrieves legal entities from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer-management/{tenantId}/legal-entities`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Legal Entities](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/companies-and-customers/client-management/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
