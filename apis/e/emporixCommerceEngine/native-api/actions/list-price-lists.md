# List Price Lists with Emporix Commerce Engine

Retrieves price lists from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/price/{tenantId}/price-lists`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Price Lists](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/prices-and-taxes/price-service/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
