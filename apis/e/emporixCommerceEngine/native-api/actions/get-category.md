# Get Category with Emporix Commerce Engine

Retrieves a category from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/{tenantId}/categories/:categoryId`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Get Category](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/catalogs-and-categories/category-tree/api-reference/api.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `string` | yes | The unique ID of the category. |
