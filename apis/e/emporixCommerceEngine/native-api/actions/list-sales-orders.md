# List Sales Orders with Emporix Commerce Engine

Retrieves sales orders from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/order-v2/{tenantId}/salesorders`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Sales Orders](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/orders/order/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
