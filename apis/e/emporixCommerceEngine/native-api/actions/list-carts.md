# List Carts with Emporix Commerce Engine

Retrieves carts from Emporix Commerce Engine.

## Endpoint

- **Method:** `GET`
- **Path:** `/cart/{tenantId}/carts`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [List Carts](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/checkout/cart/api-reference/api.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
