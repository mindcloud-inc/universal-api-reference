# Search Carts with Emporix Commerce Engine

Finds carts in Emporix Commerce Engine by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/cart/{tenantId}/carts/search`
- **Base URL:** `https://api.emporix.io`
- **Official documentation:** [Search Carts](https://raw.githubusercontent.com/emporix/api-references/refs/heads/main/checkout/cart/api-reference/api.yml)
