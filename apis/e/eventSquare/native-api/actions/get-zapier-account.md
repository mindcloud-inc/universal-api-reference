# Get Zapier Account with EventSquare

Retrieves the connected Zapier account from EventSquare.

## Endpoint

- **Method:** `GET`
- **Path:** `/1.0/integrations/zapier/test`
- **Base URL:** `https://api.eventsquare.io`
- **Official documentation:** [Get Zapier Account](https://api.eventsquare.io/docs)
