# Get Campaign Report: Opened with EmailOctopus

Retrieves the opened report for an EmailOctopus campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/report/opened`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get Campaign Report: Opened](https://emailoctopus.com/api-documentation/campaigns/report/get-opened)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique ID of the campaign. |
