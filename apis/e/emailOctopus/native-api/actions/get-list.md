# Get List with EmailOctopus

Retrieves a list from EmailOctopus by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get List](https://emailoctopus.com/api-documentation/lists/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | The unique ID of the list. |
