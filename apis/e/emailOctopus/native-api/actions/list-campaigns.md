# List Campaigns with EmailOctopus

Retrieves campaigns from EmailOctopus.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [List Campaigns](https://emailoctopus.com/api-documentation/campaigns/get-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
