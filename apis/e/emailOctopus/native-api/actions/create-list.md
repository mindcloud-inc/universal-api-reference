# Create List with EmailOctopus

Creates a new list in EmailOctopus.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Create List](https://emailoctopus.com/api-documentation/lists/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the list. |
