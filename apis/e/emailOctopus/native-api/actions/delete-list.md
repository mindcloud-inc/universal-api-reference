# Delete List with EmailOctopus

Deletes an existing list from EmailOctopus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:listId`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Delete List](https://emailoctopus.com/api-documentation/lists/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | The unique ID of the list. |
