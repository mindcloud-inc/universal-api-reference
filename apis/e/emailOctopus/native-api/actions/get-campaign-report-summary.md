# Get Campaign Report: Summary with EmailOctopus

Retrieves the summary report for an EmailOctopus campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/report/summary`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get Campaign Report: Summary](https://emailoctopus.com/api-documentation/campaigns/report/get-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique ID of the campaign. |
