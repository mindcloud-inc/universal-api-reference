# Get Campaign Report: Clicked with EmailOctopus

Retrieves the clicked report for an EmailOctopus campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/report/clicked`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get Campaign Report: Clicked](https://emailoctopus.com/api-documentation/campaigns/report/get-clicked)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique ID of the campaign. |
