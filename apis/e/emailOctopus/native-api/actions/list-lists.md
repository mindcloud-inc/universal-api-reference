# List Lists with EmailOctopus

Retrieves lists from EmailOctopus.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [List Lists](https://emailoctopus.com/api-documentation/lists/get-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
