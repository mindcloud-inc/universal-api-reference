# Get Campaign with EmailOctopus

Retrieves a campaign from EmailOctopus by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get Campaign](https://emailoctopus.com/api-documentation/campaigns/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique ID of the campaign. |
