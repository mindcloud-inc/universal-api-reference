# Get Campaign Report: Links with EmailOctopus

Retrieves the links report for an EmailOctopus campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/report/links`
- **Base URL:** `https://emailoctopus.com/api/1.6`
- **Official documentation:** [Get Campaign Report: Links](https://emailoctopus.com/api-documentation/campaigns/report/get-links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The unique ID of the campaign. |
