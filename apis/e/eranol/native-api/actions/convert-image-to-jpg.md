# Convert Image To JPG with Eranol

Creates a JPG conversion job in Eranol.

## Endpoint

- **Method:** `POST`
- **Path:** `/ffmpeg/convert/image/to/jpg`
- **Base URL:** `https://eranol.com/api/v1`
- **Official documentation:** [Convert Image To JPG](https://www.eranol.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Image file URL to convert to JPG. |
