# Convert Audio To MP3 with Eranol

Creates an MP3 conversion job in Eranol.

## Endpoint

- **Method:** `POST`
- **Path:** `/ffmpeg/convert/audio/to/mp3`
- **Base URL:** `https://eranol.com/api/v1`
- **Official documentation:** [Convert Audio To MP3](https://www.eranol.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Audio file URL to convert to MP3. |
