# Convert Video To MP4 with Eranol

Creates an MP4 conversion job in Eranol.

## Endpoint

- **Method:** `POST`
- **Path:** `/ffmpeg/convert/video/to/mp4`
- **Base URL:** `https://eranol.com/api/v1`
- **Official documentation:** [Convert Video To MP4](https://www.eranol.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Video file URL to convert to MP4. |
