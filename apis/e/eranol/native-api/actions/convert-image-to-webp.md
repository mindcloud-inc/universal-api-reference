# Convert Image To WebP with Eranol

Creates a WebP conversion job in Eranol.

## Endpoint

- **Method:** `POST`
- **Path:** `/ffmpeg/convert/image/to/webp`
- **Base URL:** `https://eranol.com/api/v1`
- **Official documentation:** [Convert Image To WebP](https://www.eranol.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Image file URL to convert to WebP. |
