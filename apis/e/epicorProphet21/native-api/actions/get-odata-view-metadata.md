# Get OData View Metadata with Epicor Prophet 21

## Endpoint

- **Method:** `GET`
- **Path:** `/odataservice/odata/view/$metadata`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [Get OData View Metadata](https://mrwuss.github.io/p21-api-documentation/html/02-OData-API.html#endpoints)

Send these additional headers for this operation:
