# Create Calendar with ECAL

Creates a new calendar in ECAL.

## Endpoint

- **Method:** `POST`
- **Path:** `/calendar/`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Create Calendar](https://docs.ecal.com/reference/apiv2/calendar.html#post-apiv2calendar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `object` | yes | JSON object matching ECAL's create calendar payload. |
