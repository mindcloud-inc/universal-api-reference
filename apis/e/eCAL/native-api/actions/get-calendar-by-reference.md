# Get Calendar By Reference with ECAL

Retrieves a calendar from ECAL by reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/:reference`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Get Calendar By Reference](https://docs.ecal.com/reference/apiv2/calendar.html#get-apiv2calendarreference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reference` | path | `string` | yes | ECAL calendar reference value. |
