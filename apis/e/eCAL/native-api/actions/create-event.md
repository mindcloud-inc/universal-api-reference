# Create Event with ECAL

Creates a new event in ECAL.

## Endpoint

- **Method:** `POST`
- **Path:** `/event/`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Create Event](https://docs.ecal.com/reference/apiv2/event.html#post-apiv2event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestBody` | body | `object` | yes | JSON object matching ECAL's create event payload. |
