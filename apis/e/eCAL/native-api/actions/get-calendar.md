# Get Calendar with ECAL

Retrieves a calendar from ECAL by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/:calendarId`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Get Calendar](https://docs.ecal.com/reference/apiv2/calendar.html#get-apiv2calendarid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarId` | path | `string` | yes | ECAL calendar ID. |
