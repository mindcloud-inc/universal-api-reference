# Delete Calendar with ECAL

Deletes an existing calendar from ECAL.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendar/:calendarId`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Delete Calendar](https://docs.ecal.com/reference/apiv2/calendar.html#delete-apiv2calendarid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarId` | path | `string` | yes | ECAL calendar ID to delete. |
