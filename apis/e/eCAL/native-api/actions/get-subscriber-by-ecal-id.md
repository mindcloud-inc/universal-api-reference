# Get Subscriber By ECAL ID with ECAL

Retrieves an ECAL subscriber by ECAL ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriber/:ecalId`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Get Subscriber By ECAL ID](https://docs.ecal.com/reference/apiv2/subscriber.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ecalId` | path | `string` | yes | Subscriber ecal_id value. |
