# Get Event with ECAL

Retrieves an event from ECAL by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:eventId`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Get Event](https://docs.ecal.com/reference/apiv2/event.html#get-apiv2eventid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | ECAL event ID. |
