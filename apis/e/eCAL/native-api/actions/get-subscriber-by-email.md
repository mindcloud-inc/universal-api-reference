# Get Subscriber By Email with ECAL

Retrieves an ECAL subscriber by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriber/:emailAddress`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [Get Subscriber By Email](https://docs.ecal.com/reference/apiv2/subscriber.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailAddress` | path | `string` | yes | Subscriber email address. |
