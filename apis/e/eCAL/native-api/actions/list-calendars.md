# List Calendars with ECAL

Retrieves calendars from ECAL.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/`
- **Base URL:** `https://api.ecal.com/apiv2`
- **Official documentation:** [List Calendars](https://docs.ecal.com/reference/apiv2/calendar.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `showDraft` | query | `boolean` | no | Whether to include draft calendars. |
