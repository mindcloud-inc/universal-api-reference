# Search Categories with Ecwid

Finds categories in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/categories`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Categories](https://docs.ecwid.com/api-reference/rest-api/categories/search-categories)

## Capabilities

This operation supports [pagination](../README.md#pagination).
