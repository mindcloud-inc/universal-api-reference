# Search Customers with Ecwid

Finds customers in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/customers`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Customers](https://docs.ecwid.com/api-reference/rest-api/customers/search-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
