# Search Shipping Options with Ecwid

Finds shipping options in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/profile/shippingOptions`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Shipping Options](https://docs.ecwid.com/api-reference/rest-api/shipping-options/search-shipping-options)
