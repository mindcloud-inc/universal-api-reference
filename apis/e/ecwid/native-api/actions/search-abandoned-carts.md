# Search Abandoned Carts with Ecwid

Finds abandoned carts in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/carts`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Abandoned Carts](https://docs.ecwid.com/api-reference/rest-api/orders/abandonned-carts/search-abandoned-carts)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
