# Get Category with Ecwid

Retrieves a category from Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/categories/:categoryId`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Get Category](https://docs.ecwid.com/api-reference/rest-api/categories/get-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | path | `number` | yes | Ecwid category ID. |
