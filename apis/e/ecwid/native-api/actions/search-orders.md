# Search Orders with Ecwid

Finds orders in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/orders`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Orders](https://docs.ecwid.com/api-reference/rest-api/orders/search-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
