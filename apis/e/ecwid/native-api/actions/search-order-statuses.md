# Search Order Statuses with Ecwid

Finds order statuses in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/profile/order_statuses`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Order Statuses](https://docs.ecwid.com/api-reference/rest-api/orders/order-statuses/search-order-statuses)
