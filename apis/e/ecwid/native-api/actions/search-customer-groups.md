# Search Customer Groups with Ecwid

Finds customer groups in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/customer_groups`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Customer Groups](https://docs.ecwid.com/api-reference/rest-api/customers/customer-groups/search-customer-groups)
