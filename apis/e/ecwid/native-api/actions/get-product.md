# Get Product with Ecwid

Retrieves a product from Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/products/:productId`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Get Product](https://docs.ecwid.com/api-reference/rest-api/products/get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `number` | yes | Ecwid product ID. |
