# Search Product Brands with Ecwid

Finds product brands in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/brands`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Product Brands](https://docs.ecwid.com/api-reference/rest-api/products/search-product-brands)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
