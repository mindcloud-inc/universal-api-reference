# Search Discount Coupons with Ecwid

Finds discount coupons in Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/discount_coupons`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Search Discount Coupons](https://docs.ecwid.com/api-reference/rest-api/discounts/discount-coupons/search-discount-coupons)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
