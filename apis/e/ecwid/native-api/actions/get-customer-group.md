# Get Customer Group with Ecwid

Retrieves a customer group from Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/customer_groups/:groupId`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Get Customer Group](https://docs.ecwid.com/api-reference/rest-api/customers/customer-groups/get-customer-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `number` | yes | Ecwid customer group ID. |
