# Get Customer with Ecwid

Retrieves a customer from Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/customers/:customerId`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Get Customer](https://docs.ecwid.com/api-reference/rest-api/customers/get-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | Ecwid customer ID. |
