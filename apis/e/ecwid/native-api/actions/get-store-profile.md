# Get Store Profile with Ecwid

Retrieves a store profile from Ecwid.

## Endpoint

- **Method:** `GET`
- **Path:** `/:storeId/profile`
- **Base URL:** `https://app.ecwid.com/api/v3`
- **Official documentation:** [Get Store Profile](https://docs.ecwid.com/api-reference/rest-api/store-profile/get-store-profile)
