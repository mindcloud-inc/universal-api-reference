# Get a specific Ticket Type with Eventix

Retrieves a specific ticket type from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/ticket/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific Ticket Type](https://docs.weeztix.com/api/dashboard/get-ticket-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Ticket Type. |
