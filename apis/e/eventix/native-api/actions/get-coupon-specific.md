# Get a specific Coupon with Eventix

Retrieves a specific coupon from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/coupon/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific Coupon](https://docs.weeztix.com/api/dashboard/get-coupon-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Coupon. |
