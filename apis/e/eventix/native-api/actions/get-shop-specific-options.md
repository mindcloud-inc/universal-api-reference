# Get a specific Shop's options with Eventix

Retrieves options for an Eventix shop.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid/options`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific Shop's options](https://docs.weeztix.com/api/dashboard/get-shop-specific-options)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
