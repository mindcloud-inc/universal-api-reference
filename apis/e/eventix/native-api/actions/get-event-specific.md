# Get a specific Event with Eventix

Retrieves a specific event from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/event/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific Event](https://docs.weeztix.com/api/dashboard/get-event-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Event. |
