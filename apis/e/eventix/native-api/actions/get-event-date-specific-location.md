# Retrieve the Location of an EventDate with Eventix

Retrieves the location of an Eventix event date.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/eventdate/:guid/location`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Retrieve the Location of an EventDate](https://docs.weeztix.com/api/dashboard/get-event-date-specific-location)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the EventDate. |
