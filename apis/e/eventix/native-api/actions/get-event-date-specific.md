# Get a specific EventDate with Eventix

Retrieves a specific event date from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/eventdate/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific EventDate](https://docs.weeztix.com/api/dashboard/get-event-date-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the EventDate. |
