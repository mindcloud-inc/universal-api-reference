# Get analysis of an Event with Eventix

Retrieves analysis for an Eventix event.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/event/:guid/analysis`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get analysis of an Event](https://docs.weeztix.com/api/dashboard/get-event-specific-analysis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Event. |
