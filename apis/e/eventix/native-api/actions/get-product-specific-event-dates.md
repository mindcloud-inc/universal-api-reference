# Get attached EventDates of Product Type with Eventix

Retrieves event dates for an Eventix product type.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/product/:guid/dates`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get attached EventDates of Product Type](https://docs.weeztix.com/api/dashboard/get-product-specific-event-dates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Product Type. |
