# Get Location of Event with Eventix

Retrieves the location of an Eventix event.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/event/:guid/location`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get Location of Event](https://docs.weeztix.com/api/dashboard/get-event-specific-event-location)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Event. |
