# Get a specific Shop with Eventix

Retrieves a specific shop from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get a specific Shop](https://docs.weeztix.com/api/dashboard/get-shop-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
