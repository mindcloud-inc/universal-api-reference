# Get Ticket Types for Event with Shops with Eventix

Retrieves ticket types with shops for an Eventix event.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/event/:guid/ticket/shops`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get Ticket Types for Event with Shops](https://docs.weeztix.com/api/dashboard/get-event-tickets-with-shops)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Event. |
