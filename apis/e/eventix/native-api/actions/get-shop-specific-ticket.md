# Get attached Ticket Types of Shop with Eventix

Retrieves ticket types for an Eventix shop.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid/tickets`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get attached Ticket Types of Shop](https://docs.weeztix.com/api/dashboard/get-shop-specific-ticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
