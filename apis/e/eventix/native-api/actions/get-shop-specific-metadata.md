# Get attached Metadata of Shop with Eventix

Retrieves metadata for an Eventix shop.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid/metadata`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get attached Metadata of Shop](https://docs.weeztix.com/api/dashboard/get-shop-specific-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
