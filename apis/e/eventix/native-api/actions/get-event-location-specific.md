# Retrieve a specific Location with Eventix

Retrieves a specific location from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/location/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Retrieve a specific Location](https://docs.weeztix.com/api/dashboard/get-event-location-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Location. |
