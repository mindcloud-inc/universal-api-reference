# Get attached PaymentMethods of Shop with Eventix

Retrieves payment methods for an Eventix shop.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid/payment_methods`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get attached PaymentMethods of Shop](https://docs.weeztix.com/api/dashboard/get-shop-specific-payment-methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
