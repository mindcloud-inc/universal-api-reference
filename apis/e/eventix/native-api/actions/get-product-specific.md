# Get specific Product Type with Eventix

Retrieves a specific product type from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/product/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get specific Product Type](https://docs.weeztix.com/api/dashboard/get-product-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Product Type. |
