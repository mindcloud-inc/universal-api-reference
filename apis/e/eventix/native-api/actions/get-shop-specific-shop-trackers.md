# Get attached ShopTrackers of Shop with Eventix

Retrieves shop trackers for an Eventix shop.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/shop/:guid/trackers`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get attached ShopTrackers of Shop](https://docs.weeztix.com/api/dashboard/get-shop-specific-shop-trackers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Shop. |
