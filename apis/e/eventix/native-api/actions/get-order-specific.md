# Get an entire specific Order with Eventix

Retrieves a specific order from Eventix.

## Endpoint

- **Method:** `GET`
- **Path:** `/3.0.0/order/:guid`
- **Base URL:** `https://api.weeztix.com`
- **Official documentation:** [Get an entire specific Order](https://docs.weeztix.com/api/dashboard/get-order-specific)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `guid` | path | `string` | yes | The guid of the Order. |
