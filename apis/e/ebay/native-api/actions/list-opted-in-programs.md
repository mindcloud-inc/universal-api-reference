# List Opted-In Programs with eBay

Retrieve a list of the seller programs that the authenticated seller has opted-in to.

## Endpoint

- **Method:** `GET`
- **Path:** `sell/account/v1/program/get_opted_in_programs`
- **Base URL:** `https://api.ebay.com/`
- **API:** REST
- **Official documentation:** [List Opted-In Programs](https://developer.ebay.com/api-docs/sell/account/resources/program/methods/getOptedInPrograms)
