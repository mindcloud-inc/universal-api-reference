# List Inventory Locations with eBay

Retrieves all defined details for every inventory location associated with the authenticated seller's account.

## Endpoint

- **Method:** `GET`
- **Path:** `sell/inventory/v1/location`
- **Base URL:** `https://api.ebay.com/`
- **API:** REST
- **Official documentation:** [List Inventory Locations](https://developer.ebay.com/api-docs/sell/inventory/resources/location/methods/getInventoryLocations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
