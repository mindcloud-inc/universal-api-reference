# Delete Offer with eBay

## Endpoint

- **Method:** `DELETE`
- **Path:** `sell/inventory/v1/offer/:offerId`
- **Base URL:** `https://api.ebay.com/`
- **API:** REST
- **Official documentation:** [Delete Offer](https://developer.ebay.com/api-docs/sell/inventory/resources/offer/methods/deleteOffer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offerId` | path | `string` | yes | The unique identifier of the offer being deleted. |
