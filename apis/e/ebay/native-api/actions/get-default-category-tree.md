# Get Default Category Tree with eBay

## Endpoint

- **Method:** `GET`
- **Path:** `commerce/taxonomy/v1/get_default_category_tree_id`
- **Base URL:** `https://api.ebay.com/`
- **API:** REST
- **Official documentation:** [Get Default Category Tree](https://developer.ebay.com/api-docs/commerce/taxonomy/resources/category_tree/methods/getDefaultCategoryTreeId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `marketplace_id` | query | `string` | no | The unique identifier of the eBay marketplace for which the category tree ID is requested. For a list of supported marketplace IDs, see Marketplaces with Default Category Trees. |
