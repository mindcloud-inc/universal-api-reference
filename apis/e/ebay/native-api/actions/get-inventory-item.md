# Get Inventory Item with eBay

## Endpoint

- **Method:** `GET`
- **Path:** `sell/inventory/v1/inventory_item/:sku`
- **Base URL:** `https://api.ebay.com/`
- **API:** REST
- **Official documentation:** [Get Inventory Item](https://developer.ebay.com/api-docs/sell/inventory/resources/inventory_item/methods/getInventoryItem)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sku` | path | `string` | no |
