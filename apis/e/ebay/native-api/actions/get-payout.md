# Get Payout with eBay

## Endpoint

- **Method:** `GET`
- **Path:** `/payout/:payoutId`
- **Base URL:** `https://apiz.ebay.com/sell/finances/v1`
- **API:** Sell Finances
- **Official documentation:** [Get Payout](https://developer.ebay.com/develop/api/sell/finances_api/payout/getPayout)

## Requirements

- **OAuth scopes:** `https://api.ebay.com/oauth/api_scope/sell.finances`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `payoutId` | path | `string` | yes |
