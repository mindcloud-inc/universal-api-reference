# List Contact Types with Expiration Reminder

Retrieves contact types from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacttypes`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Contact Types](https://developers.expirationreminder.com/api-reference/contact-types-get-all-contact-types)
