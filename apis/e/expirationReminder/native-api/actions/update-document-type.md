# Update Document Type with Expiration Reminder

Updates an existing document type in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/categories/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Document Type](https://developers.expirationreminder.com/api-reference/document-types-update-a-document-type)
