# Renew Expiration Item with Expiration Reminder

Renews an expiration item in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/expirationitems/:id/renew`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Renew Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-renew-an-expiration-item)
