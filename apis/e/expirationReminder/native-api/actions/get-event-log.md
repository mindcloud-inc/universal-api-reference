# Get Event Log with Expiration Reminder

Retrieves an event log from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/eventlogs/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Event Log](https://developers.expirationreminder.com/api-reference/event-log-get-an-event-log)
