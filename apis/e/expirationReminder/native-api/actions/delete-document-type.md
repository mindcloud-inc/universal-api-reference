# Delete Document Type with Expiration Reminder

Deletes a document type from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/categories/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Document Type](https://developers.expirationreminder.com/api-reference/document-types-delete-a-document-type)
