# List Event Logs with Expiration Reminder

Retrieves event logs from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/eventlogs`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Event Logs](https://developers.expirationreminder.com/api-reference/event-log-get-all-event-logs)

## Capabilities

This operation supports [sorting](../README.md#sorting).
