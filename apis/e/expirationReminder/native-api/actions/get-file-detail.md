# Get File Detail with Expiration Reminder

Retrieves a file detail from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/attachments/expirationitem/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get File Detail](https://developers.expirationreminder.com/api-reference/files-get-a-file%27s-detail)
