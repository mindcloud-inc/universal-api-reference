# Delete Location with Expiration Reminder

Deletes a location from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Location](https://developers.expirationreminder.com/api-reference/locations-delete-a-location)
