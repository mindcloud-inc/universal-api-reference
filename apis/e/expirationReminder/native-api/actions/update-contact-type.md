# Update Contact Type with Expiration Reminder

Updates an existing contact type in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/contacttypes/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Contact Type](https://developers.expirationreminder.com/api-reference/contact-types-update-a-contact-type)
