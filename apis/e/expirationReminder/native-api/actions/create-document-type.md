# Create Document Type with Expiration Reminder

Creates a new document type in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categories`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Create Document Type](https://developers.expirationreminder.com/api-reference/document-types-create-a-document-type)
