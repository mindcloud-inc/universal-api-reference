# List Workspaces with Expiration Reminder

Retrieves workspaces from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Workspaces](https://developers.expirationreminder.com/api-reference/workspaces-get-all-workspaces)
