# Update Location with Expiration Reminder

Updates an existing location in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Location](https://developers.expirationreminder.com/api-reference/locations-update-a-location)
