# Delete Expiration Item with Expiration Reminder

Deletes an expiration item from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/expirationitems/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-delete-an-expiration-item)
