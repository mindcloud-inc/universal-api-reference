# List Document Types with Expiration Reminder

Retrieves document types from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/categories`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Document Types](https://developers.expirationreminder.com/api-reference/document-types-get-all-document-types)
