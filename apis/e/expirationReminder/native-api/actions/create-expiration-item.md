# Create Expiration Item with Expiration Reminder

Creates a new expiration item in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/expirationitems`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Create Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-create-an-expiration-item)
