# Update Workspace with Expiration Reminder

Updates an existing workspace in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/teams/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Workspace](https://developers.expirationreminder.com/api-reference/workspaces-update-a-workspace)
