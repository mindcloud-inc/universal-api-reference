# List Locations with Expiration Reminder

Retrieves locations from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Locations](https://developers.expirationreminder.com/api-reference/locations-get-all-locations)

## Capabilities

This operation supports [sorting](../README.md#sorting).
