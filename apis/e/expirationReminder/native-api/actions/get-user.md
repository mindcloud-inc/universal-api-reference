# Get User with Expiration Reminder

Retrieves a user from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get User](https://developers.expirationreminder.com/api-reference/users-get-a-user)
