# Get Contact Type with Expiration Reminder

Retrieves a contact type from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacttypes/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Contact Type](https://developers.expirationreminder.com/api-reference/contact-types-get-a-contact-type)
