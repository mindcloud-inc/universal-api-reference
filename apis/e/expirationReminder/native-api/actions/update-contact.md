# Update Contact with Expiration Reminder

Updates an existing contact in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/contacts/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Contact](https://developers.expirationreminder.com/api-reference/contacts-update-a-contact)
