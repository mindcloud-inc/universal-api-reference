# Get Location with Expiration Reminder

Retrieves a location from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Location](https://developers.expirationreminder.com/api-reference/locations-get-a-location)
