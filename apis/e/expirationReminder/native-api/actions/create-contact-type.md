# Create Contact Type with Expiration Reminder

Creates a new contact type in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacttypes`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Create Contact Type](https://developers.expirationreminder.com/api-reference/contact-types-create-a-contact-type)
