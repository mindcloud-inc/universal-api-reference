# List Expiration Items with Expiration Reminder

Retrieves expiration items from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/expirationitems`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Expiration Items](https://developers.expirationreminder.com/api-reference/expiration-items-get-all-expiration-items)

## Capabilities

This operation supports [sorting](../README.md#sorting).
