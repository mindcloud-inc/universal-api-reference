# Delete Workspace with Expiration Reminder

Deletes a workspace from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/teams/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Workspace](https://developers.expirationreminder.com/api-reference/workspaces-delete-a-workspace)
