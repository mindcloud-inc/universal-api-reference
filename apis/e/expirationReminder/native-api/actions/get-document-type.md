# Get Document Type with Expiration Reminder

Retrieves a document type from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/categories/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Document Type](https://developers.expirationreminder.com/api-reference/document-types-get-a-document-type)
