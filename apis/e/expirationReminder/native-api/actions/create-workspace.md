# Create Workspace with Expiration Reminder

Creates a new workspace in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/teams`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Create Workspace](https://developers.expirationreminder.com/api-reference/workspaces-create-a-workspace)
