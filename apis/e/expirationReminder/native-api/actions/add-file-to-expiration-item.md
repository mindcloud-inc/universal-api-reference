# Add File to Expiration Item with Expiration Reminder

Adds a file to an expiration item in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/expirationitems/:id/attachment`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Add File to Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-add-a-file-to-an-expiration-item)
