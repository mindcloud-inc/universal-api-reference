# Get Contact with Expiration Reminder

Retrieves a contact from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Contact](https://developers.expirationreminder.com/api-reference/contacts-get-a-contact)
