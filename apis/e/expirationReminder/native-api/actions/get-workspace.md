# Get Workspace with Expiration Reminder

Retrieves a workspace from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Workspace](https://developers.expirationreminder.com/api-reference/workspaces-get-a-workspace)
