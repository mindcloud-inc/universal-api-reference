# Update Expiration Item with Expiration Reminder

Updates an existing expiration item in Expiration Reminder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/expirationitems/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-update-an-expiration-item)
