# List Files Related to Expiration Items with Expiration Reminder

Retrieves files for expiration items from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/attachments/expirationitem`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Files Related to Expiration Items](https://developers.expirationreminder.com/api-reference/files-get-all-files-related-to-expiration-items)
