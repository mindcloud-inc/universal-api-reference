# Get Expiration Item with Expiration Reminder

Retrieves an expiration item from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/expirationitems/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Get Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-get-an-expiration-item)
