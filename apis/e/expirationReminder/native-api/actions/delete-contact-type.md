# Delete Contact Type with Expiration Reminder

Deletes a contact type from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacttypes/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Contact Type](https://developers.expirationreminder.com/api-reference/contact-types-delete-a-contact-type)
