# Delete Contact with Expiration Reminder

Deletes a contact from Expiration Reminder.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Delete Contact](https://developers.expirationreminder.com/api-reference/contacts-delete-a-contact)
