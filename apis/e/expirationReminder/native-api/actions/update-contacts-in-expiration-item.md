# Update Contacts in Expiration Item with Expiration Reminder

Updates contacts on an expiration item in Expiration Reminder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/expirationitems/:id/contacts`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [Update Contacts in Expiration Item](https://developers.expirationreminder.com/api-reference/expiration-items-update-contacts-in-an-expiration-item)
