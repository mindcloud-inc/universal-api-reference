# List Expiration Items for Contact with Expiration Reminder

Retrieves expiration items for a contact from Expiration Reminder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/expirationitems/contact/:id`
- **Base URL:** `https://api.expirationreminder.net`
- **Official documentation:** [List Expiration Items for Contact](https://developers.expirationreminder.com/api-reference/expiration-items-get-all-expiration-items-for-a-contact)
