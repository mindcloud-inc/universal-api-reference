# Get Default Asset For Playground with Erase.bg

Retrieves the default playground asset from Erase.bg.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/assets/v1.0/playground/default`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Default Asset For Playground](https://www.pixelbin.io/docs/playground/)
