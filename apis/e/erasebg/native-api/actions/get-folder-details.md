# Get Folder Details with Erase.bg

Retrieves folder details from Erase.bg storage.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/assets/v1.0/folders`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Folder Details](https://www.pixelbin.io/docs/storage/miscellaneous/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Folder name to inspect. |
| `path` | query | `string` | no | Folder path to inspect. |
