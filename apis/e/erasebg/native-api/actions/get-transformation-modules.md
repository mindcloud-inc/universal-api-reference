# Get Transformation Modules with Erase.bg

Retrieves transformation modules from Erase.bg.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/platform/assets/v1.0/playground/plugins`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Get Transformation Modules](https://www.pixelbin.io/docs/playground/)
