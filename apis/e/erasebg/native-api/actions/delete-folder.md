# Delete Folder with Erase.bg

Deletes a folder from Erase.bg storage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service/platform/assets/v1.0/folders/:_id`
- **Base URL:** `https://api.pixelbin.io`
- **Official documentation:** [Delete Folder](https://www.pixelbin.io/docs/storage/delete-files/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `_id` | path | `string` | yes | Folder _id to delete. |
