# Get Delivery with EenvoudigFactureren

Retrieves a delivery from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/deliveries/:delivery_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Delivery](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381991-api-leveringsbonnen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `delivery_id` | path | `string` | yes | EenvoudigFactureren delivery ID. |
