# List Projects with EenvoudigFactureren

Retrieves projects from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Projects](https://help.eenvoudigfactureren.be/support/solutions/articles/101000507047-api-projecten)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
