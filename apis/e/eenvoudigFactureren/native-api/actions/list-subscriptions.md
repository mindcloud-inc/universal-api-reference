# List Subscriptions with EenvoudigFactureren

Retrieves subscriptions from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Subscriptions](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381992-api-abonnementen)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
