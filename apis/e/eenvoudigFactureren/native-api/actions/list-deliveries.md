# List Deliveries with EenvoudigFactureren

Retrieves deliveries from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/deliveries`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Deliveries](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381991-api-leveringsbonnen)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
