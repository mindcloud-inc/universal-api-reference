# List Quotes with EenvoudigFactureren

Retrieves quotes from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Quotes](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381985-api-offertes)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
