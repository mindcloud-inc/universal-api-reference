# Get Project with EenvoudigFactureren

Retrieves a project from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Project](https://help.eenvoudigfactureren.be/support/solutions/articles/101000507047-api-projecten)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | EenvoudigFactureren project ID. |
