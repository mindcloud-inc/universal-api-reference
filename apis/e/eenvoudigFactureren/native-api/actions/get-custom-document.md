# Get Custom Document with EenvoudigFactureren

Retrieves a custom document from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/customdocuments/:customdocument_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Custom Document](https://help.eenvoudigfactureren.be/support/solutions/articles/101000448910-api-vrije-documenten)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customdocument_id` | path | `string` | yes | EenvoudigFactureren custom document ID. |
