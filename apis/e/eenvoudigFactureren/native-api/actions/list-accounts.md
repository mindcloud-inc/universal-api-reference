# List Accounts with EenvoudigFactureren

Retrieves accounts from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Accounts](https://help.eenvoudigfactureren.be/support/solutions/articles/101000502769-api-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
