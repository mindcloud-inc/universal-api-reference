# Update Order with EenvoudigFactureren

Updates an existing order in EenvoudigFactureren.

## Endpoint

- **Method:** `PUT`
- **Path:** `/orders/:order_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Update Order](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381990-api-bestelbonnen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | EenvoudigFactureren order ID. |
