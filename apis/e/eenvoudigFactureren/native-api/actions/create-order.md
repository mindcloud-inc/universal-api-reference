# Create Order with EenvoudigFactureren

Creates a new order in EenvoudigFactureren.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Create Order](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381990-api-bestelbonnen)
