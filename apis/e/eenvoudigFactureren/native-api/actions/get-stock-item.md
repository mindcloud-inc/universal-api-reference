# Get Stock Item with EenvoudigFactureren

Retrieves a stock item from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/stockitems/:stockitem_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Stock Item](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381994-api-artikelen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stockitem_id` | path | `string` | yes | EenvoudigFactureren stock item ID. |
