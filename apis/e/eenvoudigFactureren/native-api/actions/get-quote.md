# Get Quote with EenvoudigFactureren

Retrieves a quote from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/:quote_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Quote](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381985-api-offertes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quote_id` | path | `string` | yes | EenvoudigFactureren quote ID. |
