# List Clients with EenvoudigFactureren

Retrieves clients from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Clients](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381976-api-klanten)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
