# Create Client with EenvoudigFactureren

Creates a new client in EenvoudigFactureren.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Create Client](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381976-api-klanten)
