# List Suppliers with EenvoudigFactureren

Retrieves suppliers from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppliers`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Suppliers](https://help.eenvoudigfactureren.be/support/solutions/articles/101000532901-api-leveranciers)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
