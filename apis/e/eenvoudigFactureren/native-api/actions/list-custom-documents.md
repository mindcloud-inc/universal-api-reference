# List Custom Documents with EenvoudigFactureren

Retrieves custom documents from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/customdocuments`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Custom Documents](https://help.eenvoudigfactureren.be/support/solutions/articles/101000448910-api-vrije-documenten)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
