# Get Order with EenvoudigFactureren

Retrieves an order from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:order_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Order](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381990-api-bestelbonnen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | EenvoudigFactureren order ID. |
