# Get Client with EenvoudigFactureren

Retrieves a client from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:client_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Client](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381976-api-klanten)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | EenvoudigFactureren client ID. |
