# List Purchases with EenvoudigFactureren

Retrieves purchases from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchases`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Purchases](https://help.eenvoudigfactureren.be/support/solutions/articles/101000532894-api-aankoopdocumenten)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
