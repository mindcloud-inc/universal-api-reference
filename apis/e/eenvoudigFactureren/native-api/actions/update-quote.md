# Update Quote with EenvoudigFactureren

Updates an existing quote in EenvoudigFactureren.

## Endpoint

- **Method:** `PUT`
- **Path:** `/quotes/:quote_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Update Quote](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381985-api-offertes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quote_id` | path | `string` | yes | EenvoudigFactureren quote ID. |
