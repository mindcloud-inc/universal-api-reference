# List Invoices with EenvoudigFactureren

Retrieves invoices from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Invoices](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381977-api-facturen)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
