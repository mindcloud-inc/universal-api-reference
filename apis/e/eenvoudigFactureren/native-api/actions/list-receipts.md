# List Receipts with EenvoudigFactureren

Retrieves receipts from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Receipts](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381980-api-kasticketten)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
