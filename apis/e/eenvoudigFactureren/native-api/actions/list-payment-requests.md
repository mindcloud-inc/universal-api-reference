# List Payment Requests with EenvoudigFactureren

Retrieves payment requests from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentrequests`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Payment Requests](https://help.eenvoudigfactureren.be/support/solutions/articles/101000448907-api-betaalverzoeken)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
