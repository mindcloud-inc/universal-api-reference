# Create Invoice with EenvoudigFactureren

Creates a new invoice in EenvoudigFactureren.

## Endpoint

- **Method:** `POST`
- **Path:** `/invoices`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Create Invoice](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381977-api-facturen)
