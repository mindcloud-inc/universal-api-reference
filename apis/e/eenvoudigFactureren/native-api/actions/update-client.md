# Update Client with EenvoudigFactureren

Updates an existing client in EenvoudigFactureren.

## Endpoint

- **Method:** `PUT`
- **Path:** `/clients/:client_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Update Client](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381976-api-klanten)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | EenvoudigFactureren client ID. |
