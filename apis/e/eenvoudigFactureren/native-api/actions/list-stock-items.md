# List Stock Items with EenvoudigFactureren

Retrieves stock items from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/stockitems`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [List Stock Items](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381994-api-artikelen)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
