# Get Subscription with EenvoudigFactureren

Retrieves a subscription from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:subscription_id`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Subscription](https://help.eenvoudigfactureren.be/support/solutions/articles/101000381992-api-abonnementen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | EenvoudigFactureren subscription ID. |
