# Get Current Account with EenvoudigFactureren

Retrieves the current account from EenvoudigFactureren.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/current`
- **Base URL:** `https://eenvoudigfactureren.be/api/v1`
- **Official documentation:** [Get Current Account](https://help.eenvoudigfactureren.be/support/solutions/articles/101000502769-api-accounts)
