# Generate Insult (Text) with Evil Insult

## Endpoint

- **Method:** `GET`
- **Path:** `/generate_insult.php`
- **Base URL:** `https://evilinsult.com`
- **Official documentation:** [Generate Insult (Text)](https://evilinsult.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lang` | query | `list` | no | Language for the intentionally insulting/offensive provider output. Defaults to English when omitted. Accepted values: `cn`, `de`, `el`, `en`, `es`, `fr`, `ru`, `sw`. |
