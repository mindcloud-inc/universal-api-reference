# List Event Types with EMnify

Retrieves available event types from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/type`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List Event Types](https://docs.emnify.com/developers/api/events/event-type-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
