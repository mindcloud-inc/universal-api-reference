# List Endpoint Statuses with EMnify

Retrieves available endpoint statuses from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/endpoint/status`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List Endpoint Statuses](https://docs.emnify.com/developers/api/endpoint/endpoint-status-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
