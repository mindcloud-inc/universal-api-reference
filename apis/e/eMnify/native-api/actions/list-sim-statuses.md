# List SIM Statuses with EMnify

Retrieves available SIM statuses from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/sim/status`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List SIM Statuses](https://docs.emnify.com/developers/api/sim/sim-status-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
