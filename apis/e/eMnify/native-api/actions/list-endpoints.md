# List Endpoints with EMnify

Retrieves a list of endpoints from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/endpoint`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List Endpoints](https://docs.emnify.com/developers/api/endpoint/get-endpoints)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
