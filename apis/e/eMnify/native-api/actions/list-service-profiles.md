# List Service Profiles with EMnify

Retrieves a list of service profiles from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/service_profile`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List Service Profiles](https://docs.emnify.com/developers/api/service-profiles/service-profile-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
