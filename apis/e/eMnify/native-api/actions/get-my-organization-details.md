# Get My Organization Details with EMnify

Retrieves your organization details from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/organisation/my`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [Get My Organization Details](https://docs.emnify.com/developers/api/organization/my-organisation-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
