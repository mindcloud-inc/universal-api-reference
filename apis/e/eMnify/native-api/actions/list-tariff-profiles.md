# List Tariff Profiles with EMnify

Retrieves a list of tariff profiles from EMnify.

## Endpoint

- **Method:** `GET`
- **Path:** `/tariff_profile`
- **Base URL:** `https://cdn.emnify.net/api/v1`
- **Official documentation:** [List Tariff Profiles](https://docs.emnify.com/developers/api/tariff-profiles/tariff-profile-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth_token` | body | `string` | yes | Auth token from Retrieve Authentication Token. |
