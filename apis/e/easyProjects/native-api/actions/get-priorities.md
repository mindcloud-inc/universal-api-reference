# Get Priorities with Easy Projects

Retrieves task priorities from Easy Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/priorities`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Priorities](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
