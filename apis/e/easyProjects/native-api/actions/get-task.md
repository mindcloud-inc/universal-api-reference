# Get Task with Easy Projects

Retrieves a task from Easy Projects by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/:id`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Task](https://api.go.easyprojects.net/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Birdview task ID. |
