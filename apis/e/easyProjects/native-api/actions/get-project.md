# Get Project with Easy Projects

Retrieves a project from Easy Projects by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects/:id`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Project](https://api.go.easyprojects.net/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Birdview project ID. |
