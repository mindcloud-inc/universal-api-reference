# Get My Active Tasks with Easy Projects

Retrieves the current user's active Easy Projects tasks.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/my/active`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get My Active Tasks](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
