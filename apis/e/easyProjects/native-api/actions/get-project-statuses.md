# Get Project Statuses with Easy Projects

Retrieves project statuses from Easy Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project-statuses`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Project Statuses](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
