# Get My In Progress Tasks with Easy Projects

Retrieves the current user's in-progress Easy Projects tasks.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/my/in-progress`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get My In Progress Tasks](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
