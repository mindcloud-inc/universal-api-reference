# Create Task with Easy Projects

Creates a new task in Easy Projects.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tasks`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Create Task](https://api.go.easyprojects.net/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | body | `object` | yes | Task creation model. |
