# Get Task Types with Easy Projects

Retrieves task types from Easy Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/task-types`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Task Types](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
