# Get Customers with Easy Projects

Retrieves customers visible to the current Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/customers`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Customers](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
