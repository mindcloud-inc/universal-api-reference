# Get All Projects with Easy Projects

Retrieves projects visible to the current Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/projects`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get All Projects](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
