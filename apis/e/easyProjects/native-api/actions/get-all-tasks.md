# Get All Tasks with Easy Projects

Retrieves tasks visible to the current Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get All Tasks](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
