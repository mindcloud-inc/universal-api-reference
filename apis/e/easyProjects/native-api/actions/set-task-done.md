# Set Task Done with Easy Projects

Marks an Easy Projects task as done.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/tasks/:id/done`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Set Task Done](https://api.go.easyprojects.net/api/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Birdview task ID. |
