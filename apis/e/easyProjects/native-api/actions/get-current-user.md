# Get Current User with Easy Projects

Retrieves the currently signed-in Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/current`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Current User](https://api.go.easyprojects.net/api/v1)
