# Get Tasks By Projects with Easy Projects

Retrieves tasks grouped by project in Easy Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/by-projects`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get Tasks By Projects](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
