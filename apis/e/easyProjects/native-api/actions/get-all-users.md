# Get All Users with Easy Projects

Retrieves users visible to the current Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get All Users](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
