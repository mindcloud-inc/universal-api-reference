# Get All Teams with Easy Projects

Retrieves teams visible to the current Easy Projects user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/teams`
- **Base URL:** `https://api.go.easyprojects.net/api/`
- **Official documentation:** [Get All Teams](https://api.go.easyprojects.net/api/v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
