# Get Brief with EasyContent

Retrieves a brief from EasyContent by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/briefs/:briefId`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [Get Brief](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `briefId` | path | `number` | yes |
