# Get Content Item with EasyContent

Retrieves a content item from EasyContent by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/content-items/:contentItemId`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [Get Content Item](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contentItemId` | path | `number` | yes |
