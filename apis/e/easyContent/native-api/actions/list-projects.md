# List Projects with EasyContent

Retrieves projects available to the connected EasyContent account.

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/resources/projects`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [List Projects](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `per_page` | query | `number` | no |
