# Get Template with EasyContent

Retrieves a template structure from EasyContent by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/templates/:templateId`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [Get Template](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateId` | path | `number` | yes |
