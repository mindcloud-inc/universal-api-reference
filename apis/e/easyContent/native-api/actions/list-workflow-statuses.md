# List Workflow Statuses with EasyContent

Retrieves workflow statuses from a selected EasyContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/zapier/resources/statuses`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [List Workflow Statuses](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | query | `number` | yes |
