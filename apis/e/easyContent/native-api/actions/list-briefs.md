# List Briefs with EasyContent

Retrieves briefs from the connected EasyContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/briefs`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [List Briefs](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `per-page` | query | `number` | no |
