# Get Category with EasyContent

Retrieves a category from EasyContent by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/categories/:categoryId`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [Get Category](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `categoryId` | path | `number` | yes |
