# List Content Items with EasyContent

Retrieves content items from the connected EasyContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/content-items`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [List Content Items](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `per-page` | query | `number` | no |
