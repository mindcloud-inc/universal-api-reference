# List Templates with EasyContent

Retrieves active templates from the connected EasyContent project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/content/templates`
- **Base URL:** `https://easycontent.io/api`
- **Official documentation:** [List Templates](https://easycontent.io/content-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `per-page` | query | `number` | no |
