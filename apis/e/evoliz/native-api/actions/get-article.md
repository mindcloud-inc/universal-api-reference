# Get Article with Evoliz

Retrieves an article from Evoliz.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/articles/:articleid`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [Get Article](https://evoliz.io/documentation#tag/Article/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1articles~1%7Barticleid%7D/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleid` | path | `number` | yes | The Evoliz article ID. |
