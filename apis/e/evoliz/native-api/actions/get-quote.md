# Get Quote with Evoliz

Retrieves a quote from Evoliz.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/quotes/:quoteid`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [Get Quote](https://evoliz.io/documentation#tag/Quote/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1quotes~1%7Bquoteid%7D/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quoteid` | path | `number` | yes | The Evoliz quote ID. |
