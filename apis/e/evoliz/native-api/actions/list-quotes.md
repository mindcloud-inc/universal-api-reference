# List Quotes with Evoliz

Retrieves quotes from Evoliz.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/quotes`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [List Quotes](https://evoliz.io/documentation#tag/Quote/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1quotes/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientid` | query | `number` | no | Optional filter for one client. |
