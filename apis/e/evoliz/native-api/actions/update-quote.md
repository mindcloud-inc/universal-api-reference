# Update Quote with Evoliz

Updates an existing quote in Evoliz.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/quotes/:quoteid`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [Update Quote](https://evoliz.io/documentation#tag/Quote/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1quotes~1%7Bquoteid%7D/put)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `quoteid` | path | `number` | yes | The Evoliz quote ID. |
