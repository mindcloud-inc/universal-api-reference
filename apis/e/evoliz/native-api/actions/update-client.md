# Update Client with Evoliz

Updates an existing client in Evoliz.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/clients/:clientid`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [Update Client](https://evoliz.io/documentation#tag/Client/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1clients~1%7Bclientid%7D/patch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientid` | path | `number` | yes | The Evoliz client ID. |
