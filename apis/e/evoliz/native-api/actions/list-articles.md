# List Articles with Evoliz

Retrieves articles from Evoliz.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/articles`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [List Articles](https://evoliz.io/documentation#tag/Article/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1articles/get)
