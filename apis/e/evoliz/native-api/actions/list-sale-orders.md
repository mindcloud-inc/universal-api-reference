# List Sale Orders with Evoliz

Retrieves sale orders from Evoliz.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/sale-orders`
- **Base URL:** `https://www.evoliz.io`
- **Official documentation:** [List Sale Orders](https://evoliz.io/documentation#tag/Sale%20order/paths/~1api~1v1~1companies~1%7Bcompanyid%7D~1sale-orders/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientid` | query | `number` | no | Optional filter for one client. |
