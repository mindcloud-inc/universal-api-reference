# Close Project with Easy Redmine

Closes an existing project in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:id/close.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Close Project](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the project to close. |
