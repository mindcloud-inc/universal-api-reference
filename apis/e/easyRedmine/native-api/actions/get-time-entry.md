# Get Time Entry with Easy Redmine

Retrieves a time entry from Easy Redmine.

## Endpoint

- **Method:** `GET`
- **Path:** `/time_entries/:id.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Get Time Entry](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the time entry to retrieve. |
