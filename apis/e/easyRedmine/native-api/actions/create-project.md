# Create Project with Easy Redmine

Creates a new project in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Create Project](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | body | `object` | yes | Project payload to create. |
