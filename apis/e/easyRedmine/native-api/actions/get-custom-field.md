# Get Custom Field with Easy Redmine

Retrieves a custom field from Easy Redmine.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_fields/:id.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Get Custom Field](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the custom field to retrieve. |
