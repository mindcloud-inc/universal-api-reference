# Get Issue with Easy Redmine

Retrieves an issue from Easy Redmine.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues/:id.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Get Issue](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the issue to retrieve. |
