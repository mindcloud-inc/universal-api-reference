# Remove Issue From Favorites with Easy Redmine

Removes an issue from favorites in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/easy_issues/:id/unfavorite.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Remove Issue From Favorites](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the issue to remove from favorites. |
