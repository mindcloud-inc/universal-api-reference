# Reopen Project with Easy Redmine

Reopens an existing project in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:id/reopen.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Reopen Project](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the project to reopen. |
