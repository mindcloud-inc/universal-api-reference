# Delete Project with Easy Redmine

Deletes an existing project from Easy Redmine.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Delete Project](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the project to delete. |
