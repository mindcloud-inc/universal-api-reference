# Remove Project From Favorites with Easy Redmine

Removes a project from favorites in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:id/unfavorite.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Remove Project From Favorites](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the project to remove from favorites. |
