# Delete Time Entry with Easy Redmine

Deletes an existing time entry from Easy Redmine.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/time_entries/:id.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Delete Time Entry](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the time entry to delete. |
