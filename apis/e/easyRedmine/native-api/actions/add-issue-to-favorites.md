# Add Issue To Favorites with Easy Redmine

Adds an issue to favorites in Easy Redmine.

## Endpoint

- **Method:** `POST`
- **Path:** `/easy_issues/:id/favorite.json`
- **Base URL:** `https://3f73561b8b.bigus-e5.easy8.com`
- **Official documentation:** [Add Issue To Favorites](https://3f73561b8b.bigus-e5.easy8.com/easy_swagger.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the issue to add to favorites. |
