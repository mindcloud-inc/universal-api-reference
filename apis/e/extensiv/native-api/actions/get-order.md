# Get Order with Extensiv Order Manager

Retrieves an order from Extensiv Order Manager.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.1/orders/:orderId`
- **Base URL:** `https://api.skubana.com`
- **Official documentation:** [Get Order](https://documentation.skubana.com/pages/order-manager.html#tag/Order/operation/getOrderUsingGET_1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderId` | path | `number` | no |
