# Get Allowed Warehouses with ERPLY Books

Retrieves allowed warehouses from ERPLY Books.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://{customerCode}.erply.com/api`
- **Official documentation:** [Get Allowed Warehouses](https://learn-api.erply.com/requests/getallowedwarehouses)
