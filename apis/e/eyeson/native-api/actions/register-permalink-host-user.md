# Register Permalink Host User with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/permalink/:permalinkId/users`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Register Permalink Host User](https://docs.eyeson.com/docs/rest/references/permalink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `permalinkId` | path | `string` | no |
