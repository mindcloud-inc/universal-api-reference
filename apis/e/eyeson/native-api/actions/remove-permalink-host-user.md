# Remove Permalink Host User with Eyeson

## Endpoint

- **Method:** `DELETE`
- **Path:** `/permalink/:permalinkId/users/:userToken`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Remove Permalink Host User](https://docs.eyeson.com/docs/rest/references/permalink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `permalinkId` | path | `string` | no |
| `userToken` | path | `string` | no |
