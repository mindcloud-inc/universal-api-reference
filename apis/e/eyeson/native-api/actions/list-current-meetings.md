# List Current Meetings with Eyeson

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [List Current Meetings](https://docs.eyeson.com/docs/rest/references/meeting-room)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | 1-based result page to fetch. Eyeson returns up to 25 rooms per page. |
