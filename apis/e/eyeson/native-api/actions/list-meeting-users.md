# List Meeting Users with Eyeson

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:accessKey/users`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [List Meeting Users](https://docs.eyeson.com/docs/rest/references/user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
