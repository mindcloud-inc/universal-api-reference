# Start Permalink Meeting with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/permalink/:userToken`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Start Permalink Meeting](https://docs.eyeson.com/docs/rest/references/permalink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userToken` | path | `string` | no |
