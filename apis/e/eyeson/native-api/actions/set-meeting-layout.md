# Set Meeting Layout with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:accessKey/layout`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Set Meeting Layout](https://docs.eyeson.com/docs/rest/references/meeting-layout)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
