# Start Meeting Playback with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:accessKey/playbacks`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Start Meeting Playback](https://docs.eyeson.com/docs/rest/references/playbacks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
