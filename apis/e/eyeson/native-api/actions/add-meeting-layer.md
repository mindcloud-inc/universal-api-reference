# Add Meeting Layer with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:accessKey/layers`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Add Meeting Layer](https://docs.eyeson.com/docs/rest/references/layers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
