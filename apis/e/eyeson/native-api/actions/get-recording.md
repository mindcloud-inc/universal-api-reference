# Get Recording with Eyeson

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recordingId`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Get Recording](https://docs.eyeson.com/docs/rest/references/recording)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `recordingId` | path | `string` | no |
