# Register Guest User with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/guests/:guestToken`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Register Guest User](https://docs.eyeson.com/docs/rest/references/user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `guestToken` | path | `string` | no |
