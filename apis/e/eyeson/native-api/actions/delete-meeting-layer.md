# Delete Meeting Layer with Eyeson

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:accessKey/layers/:index`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Delete Meeting Layer](https://docs.eyeson.com/docs/rest/references/layers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
| `index` | path | `string` | no |
