# Remove Meeting User with Eyeson

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:accessKey/users/:userId`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Remove Meeting User](https://docs.eyeson.com/docs/rest/references/user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
| `userId` | path | `string` | no |
