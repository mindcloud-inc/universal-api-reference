# Send Meeting Message with Eyeson

## Endpoint

- **Method:** `POST`
- **Path:** `/rooms/:accessKey/messages`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Send Meeting Message](https://docs.eyeson.com/docs/rest/references/messages)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
