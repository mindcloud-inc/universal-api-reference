- **Path:** `/rooms/:accessKey/broadcasts`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Update Broadcast Player URL](https://docs.eyeson.com/docs/rest/references/broadcast)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
