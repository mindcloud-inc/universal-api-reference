# Stop Meeting Playback with Eyeson

## Endpoint

- **Method:** `DELETE`
- **Path:** `/rooms/:accessKey/playbacks/:playId`
- **Base URL:** `https://api.eyeson.team`
- **Official documentation:** [Stop Meeting Playback](https://docs.eyeson.com/docs/rest/references/playbacks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accessKey` | path | `string` | no |
| `playId` | path | `string` | no |
