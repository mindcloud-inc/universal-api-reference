# List Current Measurements with Epion

Retrieves current device measurements from Epion.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/current`
- **Base URL:** `https://api.epion.nl`
- **Official documentation:** [List Current Measurements](https://epion.nl/integraties)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `User-Agent` | `MindCloud-Epion/1.0` |
