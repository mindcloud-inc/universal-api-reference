# Check Domain with Email Domain Checker

## Endpoint

- **Method:** `GET`
- **Path:** `/checkDomain/`
- **Base URL:** `https://api.mightora.io/emailDomainChecker`
- **Official documentation:** [Check Domain](https://learn.microsoft.com/en-gb/connectors/emaildomainchecker/#check-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Email address or email domain to check. Defaults to mightora.io for a reliable scaffold test. |
