# Get Envelope Evidence Document with edatalia Sign Online

Retrieves an envelope evidence document from edatalia Sign Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/PSC/v40/DocumentSet/Evidences/:documentSetId`
- **Base URL:** `https://restapi.firmar.online`
- **Official documentation:** [Get Envelope Evidence Document](https://restapi.firmar.online/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentSetId` | path | `string` | yes | Identifier of the envelope whose evidence document should be retrieved. |
