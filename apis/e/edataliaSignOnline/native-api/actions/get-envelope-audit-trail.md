# Get Envelope Audit Trail with edatalia Sign Online

Retrieves an envelope audit trail from edatalia Sign Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/PSC/v40/DocumentSet/AuditTrail/:documentSetId`
- **Base URL:** `https://restapi.firmar.online`
- **Official documentation:** [Get Envelope Audit Trail](https://restapi.firmar.online/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentSetId` | path | `string` | yes | Identifier of the envelope whose audit trail should be retrieved. |
