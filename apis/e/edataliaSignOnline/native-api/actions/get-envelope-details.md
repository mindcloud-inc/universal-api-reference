# Get Envelope Details with edatalia Sign Online

Retrieves envelope details from edatalia Sign Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/PSC/v40/DocumentSet/:documentSetId`
- **Base URL:** `https://restapi.firmar.online`
- **Official documentation:** [Get Envelope Details](https://restapi.firmar.online/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentSetId` | path | `string` | yes | Identifier of the envelope to retrieve. |
