# Get Envelope Status with edatalia Sign Online

Retrieves an envelope's status from edatalia Sign Online.

## Endpoint

- **Method:** `GET`
- **Path:** `/PSC/v40/DocumentSet/Status/:documentSetId`
- **Base URL:** `https://restapi.firmar.online`
- **Official documentation:** [Get Envelope Status](https://restapi.firmar.online/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentSetId` | path | `string` | yes | Identifier of the envelope to check. |
