# Delete Estimation with Envoice

Deletes an existing estimation from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `estimation/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Estimation](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Estimation identifier to delete. |
