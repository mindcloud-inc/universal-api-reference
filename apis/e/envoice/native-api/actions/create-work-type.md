# Create Work Type with Envoice

Creates a new work type in Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `worktype/new`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Create Work Type](https://github.com/EmitKnowledge/Envoice/blob/master/work-type.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Title` | body | `string` | yes | Work type title. |
