# Delete Client with Envoice

Deletes an existing client from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `client/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Client](https://github.com/EmitKnowledge/Envoice/blob/master/client.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Client ID. |
