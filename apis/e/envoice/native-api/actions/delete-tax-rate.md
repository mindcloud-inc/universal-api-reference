# Delete Tax Rate with Envoice

Deletes an existing tax rate from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `tax/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Tax Rate](https://github.com/EmitKnowledge/Envoice/blob/master/tax.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Tax rate ID. |
