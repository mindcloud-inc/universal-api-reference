# Get Estimation Share URI with Envoice

Retrieves a shared estimation URL from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `estimation/uri`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Estimation Share URI](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Estimation identifier. |
