# Delete Invoice with Envoice

Deletes an existing invoice from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `invoice/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Invoice](https://github.com/EmitKnowledge/Envoice/blob/master/invoice.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Invoice ID. |
