# Get Payment Link URI with Envoice

Retrieves a payment link URL from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `paymentlink/uri`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Payment Link URI](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Payment link identifier. |
