# Get Estimation Details with Envoice

Retrieves estimation details from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `estimation/details`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Estimation Details](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Estimation identifier. |
