# Get Estimation Status with Envoice

Retrieves an estimation status from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `estimation/status`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Estimation Status](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Estimation identifier. |
