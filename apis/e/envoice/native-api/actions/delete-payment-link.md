# Delete Payment Link with Envoice

Deletes an existing payment link from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `paymentlink/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Payment Link](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Payment link identifier to delete. |
