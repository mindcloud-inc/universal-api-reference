# List Invoice Categories with Envoice

Retrieves invoice categories from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `invoice/allcategories`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [List Invoice Categories](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Invoice category search query. |
