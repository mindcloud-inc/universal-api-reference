# Send Invoice to Accountant with Envoice

Sends an invoice to an accountant in Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `invoice/sendtoaccountant`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Send Invoice to Accountant](https://github.com/EmitKnowledge/Envoice/blob/master/invoice.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Invoice ID. |
