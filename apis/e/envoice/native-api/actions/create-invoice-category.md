# Create Invoice Category with Envoice

Creates a new invoice category in Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `invoice/newcategory`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Create Invoice Category](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Name` | body | `string` | yes | Invoice category name. |
