# List UI Languages with Envoice

Retrieves supported UI languages from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `general/uilanguages`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [List UI Languages](https://github.com/EmitKnowledge/Envoice/blob/master/general.md)
