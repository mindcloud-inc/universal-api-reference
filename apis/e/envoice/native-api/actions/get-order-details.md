# Get Order Details with Envoice

Retrieves order details from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `order/details`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Order Details](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Order identifier. |
