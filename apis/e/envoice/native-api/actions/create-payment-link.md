# Create Payment Link with Envoice

Creates a new payment link in Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `paymentlink/new`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Create Payment Link](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Payload` | body | `string` | no | Payment link creation payload accepted by Envoice. The OpenAPI operation does not publish a request schema. |
