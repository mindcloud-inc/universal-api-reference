# List Orders with Envoice

Retrieves orders from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `order/all`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [List Orders](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queryOptions.page` | query | `number` | no | Result page number. |
| `queryOptions.pageSize` | query | `number` | no | Number of results per page. |
