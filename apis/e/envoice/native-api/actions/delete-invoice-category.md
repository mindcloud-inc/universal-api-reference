# Delete Invoice Category with Envoice

Deletes an existing invoice category from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `invoice/deletecategory`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Invoice Category](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Invoice category identifier to delete. |
