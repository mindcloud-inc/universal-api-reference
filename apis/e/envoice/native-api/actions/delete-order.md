# Delete Order with Envoice

Deletes an existing order from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `order/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Order](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Order identifier to delete. |
