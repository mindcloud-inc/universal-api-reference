# List Currencies with Envoice

Retrieves supported currencies from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `general/currencies`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [List Currencies](https://github.com/EmitKnowledge/Envoice/blob/master/general.md)
