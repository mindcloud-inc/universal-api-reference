# Delete Work Type with Envoice

Deletes an existing work type from Envoice.

## Endpoint

- **Method:** `POST`
- **Path:** `worktype/delete`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Delete Work Type](https://github.com/EmitKnowledge/Envoice/blob/master/work-type.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | body | `number` | yes | Work type ID. |
