# Get Client Details with Envoice

Retrieves client details from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `client/details`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Client Details](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Client identifier. |
