# List Supported Payment Providers with Envoice

Retrieves supported payment providers from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `payment/supported`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [List Supported Payment Providers](https://github.com/EmitKnowledge/Envoice/blob/master/payment.md)
