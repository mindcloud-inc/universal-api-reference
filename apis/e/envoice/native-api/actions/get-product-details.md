# Get Product Details with Envoice

Retrieves product details from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `product/details`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Product Details](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Product identifier. |
