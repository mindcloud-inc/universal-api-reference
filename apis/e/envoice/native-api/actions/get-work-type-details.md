# Get Work Type Details with Envoice

Retrieves work type details from Envoice.

## Endpoint

- **Method:** `GET`
- **Path:** `worktype/details`
- **Base URL:** `https://www.envoice.in/api`
- **Official documentation:** [Get Work Type Details](https://www.envoice.in/reference/api/docs/v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workTypeId` | query | `number` | yes | Work type identifier. |
