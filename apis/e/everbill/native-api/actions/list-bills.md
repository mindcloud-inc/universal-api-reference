# List Bills with Everbill

Retrieves bills from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/bills/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Bills](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1bills~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
