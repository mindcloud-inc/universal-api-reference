# List Projects with Everbill

Retrieves projects from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Projects](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1projects~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
