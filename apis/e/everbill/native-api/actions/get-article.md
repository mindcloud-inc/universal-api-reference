# Get Article with Everbill

Retrieves an article from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles/view/:id`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [Get Article](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1articles~1view~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Everbill record ID. |
