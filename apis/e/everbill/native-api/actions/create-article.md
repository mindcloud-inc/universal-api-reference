# Create Article with Everbill

Creates a new article in Everbill.

## Endpoint

- **Method:** `POST`
- **Path:** `/articles/add`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [Create Article](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1articles~1add/post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Article` | body | `object` | yes | Article object for the request body. |
