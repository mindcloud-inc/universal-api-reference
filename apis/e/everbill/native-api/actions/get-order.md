# Get Order with Everbill

Retrieves an order from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/view/:id`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [Get Order](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1orders~1view~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Everbill record ID. |
