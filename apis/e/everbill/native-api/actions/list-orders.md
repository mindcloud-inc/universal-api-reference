# List Orders with Everbill

Retrieves orders from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Orders](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1orders~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
