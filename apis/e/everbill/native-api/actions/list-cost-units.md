# List Cost Units with Everbill

Retrieves cost units from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/cost_units/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Cost Units](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1cost_units~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
