# List Customers with Everbill

Retrieves customers from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Customers](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1customers~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
