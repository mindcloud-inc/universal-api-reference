# List Distributors with Everbill

Retrieves distributors from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/distributors/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Distributors](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1distributors~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
