# Get Cost Unit with Everbill

Retrieves a cost unit from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/cost_units/view/:id`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [Get Cost Unit](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1cost_units~1view~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Everbill record ID. |
