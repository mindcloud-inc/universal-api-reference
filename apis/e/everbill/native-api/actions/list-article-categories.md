# List Article Categories with Everbill

Retrieves article categories from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/article_categories/threaded`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Article Categories](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1article_categories~1threaded/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
