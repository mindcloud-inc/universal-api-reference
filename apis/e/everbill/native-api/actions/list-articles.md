# List Articles with Everbill

Retrieves articles from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/articles/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Articles](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
