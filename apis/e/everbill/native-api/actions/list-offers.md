# List Offers with Everbill

Retrieves offers from Everbill.

## Endpoint

- **Method:** `GET`
- **Path:** `/offers/index`
- **Base URL:** `https://api.everbill.eu`
- **Official documentation:** [List Offers](https://api.swaggerhub.com/apis/everbill1/everbill/1.10/swagger.json#/paths/~1offers~1index/get)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
