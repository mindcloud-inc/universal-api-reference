# Verify Email (MORE V3 JSON) with Email Hippo

Verifies an email address with Email Hippo MORE V3 JSON.

## Endpoint

- **Method:** `GET`
- **Path:** `v3/more/json/{apiKey}/:emailAddress`
- **Base URL:** `https://api.hippoapi.com`
- **Official documentation:** [Verify Email (MORE V3 JSON)](https://docs.emailhippo.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailAddress` | path | `string` | yes | The email address to verify. |
