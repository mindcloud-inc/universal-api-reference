# Get Venue with Eventbrite

Retrieves a venue from Eventbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/venues/:venueId/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [Get Venue](https://www.eventbrite.com/platform/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `venueId` | path | `string` | yes | Venue identifier. |
