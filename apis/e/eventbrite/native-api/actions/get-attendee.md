# Get Attendee with Eventbrite

Retrieves an attendee from Eventbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/attendees/:attendeeId/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [Get Attendee](https://www.eventbrite.com/platform/docs/attendees)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attendeeId` | path | `string` | yes | Attendee identifier. |
