# Copy Event with Eventbrite

Copies an event in Eventbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/events/:eventId/copy/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [Copy Event](https://www.eventbrite.com/platform/docs/create-events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Event identifier. |
