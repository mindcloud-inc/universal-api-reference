# Get Event with Eventbrite

Retrieves an event from Eventbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [Get Event](https://www.eventbrite.com/platform/api#/reference/event/retrieve-an-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Event identifier. |
