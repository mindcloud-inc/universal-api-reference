# List Organization Organizers with Eventbrite

Retrieves organization organizers from Eventbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/organizers/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [List Organization Organizers](https://www.eventbrite.com/platform/docs/organizations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | Organization identifier. |
