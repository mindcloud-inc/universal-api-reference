# List My Organizations with Eventbrite

Retrieves your organizations from Eventbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/organizations/`
- **Base URL:** `https://www.eventbriteapi.com/v3`
- **Official documentation:** [List My Organizations](https://www.eventbrite.com/platform/api#/reference/organization/list-your-organizations/list-your-organizations)
