# Delete Volume with E2B

Deletes a team volume from E2B.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/volumes/{volumeID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Delete Volume](https://e2b.dev/docs/api-reference/volumes/delete-volumes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `volumeID` | path | `string` | yes | Identifier of the volume. |
