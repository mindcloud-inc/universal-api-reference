# Update Template with E2B

Updates an existing template in E2B.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/templates/{templateID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Update Template](https://e2b.dev/docs/api-reference/templates/update-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | path | `string` | yes | Identifier of the template. |
