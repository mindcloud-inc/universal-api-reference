# Rebuild Template with E2B

Rebuilds a template in E2B.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates/{templateID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Rebuild Template](https://e2b.dev/docs/api-reference/templates/rebuild-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | path | `string` | yes | Identifier of the template. |
