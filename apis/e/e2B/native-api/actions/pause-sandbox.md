# Pause Sandbox with E2B

Pauses a sandbox in E2B.

## Endpoint

- **Method:** `POST`
- **Path:** `/sandboxes/{sandboxID}/pause`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Pause Sandbox](https://e2b.dev/docs/api-reference/sandboxes/pause-sandbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | `string` | yes | Identifier of the sandbox. |
