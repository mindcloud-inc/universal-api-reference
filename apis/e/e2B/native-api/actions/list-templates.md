# List Templates with E2B

Retrieves a list of templates from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [List Templates](https://e2b.dev/docs/api-reference/templates/list-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamID` | query | `string` | no | Identifier of the team. |
