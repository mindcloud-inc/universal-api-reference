# Get Sandbox Metrics with E2B

Retrieves metrics for a sandbox from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/sandboxes/{sandboxID}/metrics`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Sandbox Metrics](https://e2b.dev/docs/api-reference/sandboxes/get-sandbox-metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | `string` | yes | Identifier of the sandbox. |
