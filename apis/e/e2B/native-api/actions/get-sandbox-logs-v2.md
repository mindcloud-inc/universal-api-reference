# Get Sandbox Logs V2 with E2B

Retrieves logs for a sandbox from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/sandboxes/{sandboxID}/logs`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Sandbox Logs V2](https://e2b.dev/docs/api-reference/sandboxes/get-sandbox-logs-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | `string` | yes | Identifier of the sandbox. |
