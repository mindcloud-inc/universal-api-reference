# Delete Sandbox with E2B

Deletes a sandbox from E2B.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sandboxes/{sandboxID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Delete Sandbox](https://e2b.dev/docs/api-reference/sandboxes/delete-sandbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | `string` | yes | Identifier of the sandbox. |
