# Get Template By Alias with E2B

Finds a template in E2B by alias.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/aliases/{alias}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Template By Alias](https://e2b.dev/docs/api-reference/templates/get-template-by-alias)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | path | `string` | yes | Template alias to check. |
