# List Template Tags with E2B

Retrieves a list of template tags from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{templateID}/tags`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [List Template Tags](https://e2b.dev/docs/api-reference/tags/list-template-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | path | `string` | yes | Identifier of the template. |
