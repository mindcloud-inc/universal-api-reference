# Get Volume with E2B

Retrieves a team volume from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/volumes/{volumeID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Volume](https://e2b.dev/docs/api-reference/volumes/get-volumes-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `volumeID` | path | `string` | yes | Identifier of the volume. |
