# Get Sandbox with E2B

Retrieves details for a sandbox from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/sandboxes/{sandboxID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Sandbox](https://e2b.dev/docs/api-reference/sandboxes/get-sandbox)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sandboxID` | path | `string` | yes | Identifier of the sandbox. |
