# Get Template with E2B

Retrieves a template from E2B.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{templateID}`
- **Base URL:** `https://api.e2b.app`
- **Official documentation:** [Get Template](https://e2b.dev/docs/api-reference/templates/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | path | `string` | yes | Identifier of the template. |
