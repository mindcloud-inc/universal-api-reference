# View Classification with Extracta.ai

Retrieves a classification from Extracta.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/documentClassification/viewClassification`
- **Base URL:** `https://api.extracta.ai/api/v1`
- **Official documentation:** [View Classification](https://docs.extracta.ai/document-classification-api/api-endpoints-document-classification/2.-view-classification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `classificationId` | body | `string` | yes | Unique identifier for the classification. |
