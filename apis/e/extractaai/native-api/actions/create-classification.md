# Create Classification with Extracta.ai

Creates a new classification in Extracta.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/documentClassification/createClassification`
- **Base URL:** `https://api.extracta.ai/api/v1`
- **Official documentation:** [Create Classification](https://docs.extracta.ai/document-classification-api/api-endpoints-document-classification/1.-create-classification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `classificationDetails` | body | `object` | yes | Object containing the classification configuration. |
