# View Extraction with Extracta.ai

Retrieves an extraction from Extracta.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/viewExtraction`
- **Base URL:** `https://api.extracta.ai/api/v1`
- **Official documentation:** [View Extraction](https://docs.extracta.ai/data-extraction-api/api-endpoints-data-extraction/2.-view-extraction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extractionId` | body | `string` | yes | Unique identifier for the extraction. |
