# Create Extraction with Extracta.ai

Creates a new extraction in Extracta.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/createExtraction`
- **Base URL:** `https://api.extracta.ai/api/v1`
- **Official documentation:** [Create Extraction](https://docs.extracta.ai/data-extraction-api/api-endpoints-data-extraction/1.-create-extraction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `extractionDetails` | body | `object` | yes | Object containing the extraction configuration. |
