# Delete Classification with Extracta.ai

Deletes an existing classification from Extracta.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documentClassification/deleteClassification`
- **Base URL:** `https://api.extracta.ai/api/v1`
- **Official documentation:** [Delete Classification](https://docs.extracta.ai/document-classification-api/api-endpoints-document-classification/4.-delete-data/4.1-delete-classification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `classificationId` | body | `string` | yes | Unique identifier for the classification. |
