# Get Position Discount with easybill

Retrieves a position discount from easybill by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts/position/{id}`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [Get Position Discount](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
