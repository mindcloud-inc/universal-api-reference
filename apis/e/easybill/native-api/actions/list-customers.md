# List Customers with easybill

Retrieves customers from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Customers](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
