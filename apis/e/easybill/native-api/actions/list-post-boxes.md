# List Post Boxes with easybill

Retrieves post boxes from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/post-boxes`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Post Boxes](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
