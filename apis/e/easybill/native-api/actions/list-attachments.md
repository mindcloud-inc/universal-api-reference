# List Attachments with easybill

Retrieves attachments from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachments`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Attachments](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
