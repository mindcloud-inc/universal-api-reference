# List Position Groups with easybill

Retrieves position groups from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/position-groups`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Position Groups](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
