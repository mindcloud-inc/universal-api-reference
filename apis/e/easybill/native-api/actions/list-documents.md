# List Documents with easybill

Retrieves documents from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Documents](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
