# List Positions with easybill

Retrieves positions from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/positions`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Positions](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
