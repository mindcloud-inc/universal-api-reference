# List Stocks with easybill

Retrieves stock entries from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/stocks`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Stocks](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
