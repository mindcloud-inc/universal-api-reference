# List WebHooks with easybill

Retrieves webhooks from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List WebHooks](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
