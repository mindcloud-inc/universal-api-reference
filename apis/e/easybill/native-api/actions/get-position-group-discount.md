# Get Position Group Discount with easybill

Retrieves a position group discount from easybill by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts/position-group/{id}`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [Get Position Group Discount](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
