# List Projects with easybill

Retrieves projects from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Projects](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
