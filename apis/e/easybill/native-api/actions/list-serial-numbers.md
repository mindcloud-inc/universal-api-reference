# List Serial Numbers with easybill

Retrieves serial numbers from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/serial-numbers`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Serial Numbers](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
