# List PDF Templates with easybill

Retrieves PDF templates from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/pdf-templates`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List PDF Templates](https://www.easybill.de/api/)

## Capabilities

This operation supports [filtering](../README.md#filtering).
