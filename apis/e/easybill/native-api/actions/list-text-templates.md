# List Text Templates with easybill

Retrieves text templates from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/text-templates`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Text Templates](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
