# List Position Discounts with easybill

Retrieves position discounts from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts/position`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Position Discounts](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
