# List Time Trackings with easybill

Retrieves time trackings from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/time-trackings`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Time Trackings](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
