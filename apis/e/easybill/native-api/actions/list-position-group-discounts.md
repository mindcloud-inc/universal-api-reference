# List Position Group Discounts with easybill

Retrieves position group discounts from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts/position-group`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Position Group Discounts](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
