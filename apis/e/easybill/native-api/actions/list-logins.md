# List Logins with easybill

Retrieves logins from easybill.

## Endpoint

- **Method:** `GET`
- **Path:** `/logins`
- **Base URL:** `https://api.easybill.de/rest/v1`
- **Official documentation:** [List Logins](https://www.easybill.de/api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
