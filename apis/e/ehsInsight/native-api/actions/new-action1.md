# Get Entity Schema with EHS Insight

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/entity/:entityName/schema`
- **Base URL:** `https://{companyName}.ehsinsight.com/api`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entityName` | path | `string` | yes |
