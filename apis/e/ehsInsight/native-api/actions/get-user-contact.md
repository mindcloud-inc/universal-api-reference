# Get User Contact with EHS Insight

## Endpoint

- **Method:** `GET`
- **Path:** `/v6/entity/UserContact/fetch/:rowUid`
- **Base URL:** `https://{companyName}.ehsinsight.com/api`
- **Official documentation:** [Get User Contact](https://qxobptest.ehsinsight.com/site#/apidocumentation/v6/apidoc_entityapi_fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowUid` | path | `string` | yes | The RowUID of the user or contact. |
