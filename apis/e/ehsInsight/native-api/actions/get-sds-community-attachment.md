# Get SDS Community Attachment with EHS Insight

## Endpoint

- **Method:** `GET`
- **Path:** `/v6/sdscommunity/attachment/fetch/:rowUid`
- **Base URL:** `https://{companyName}.ehsinsight.com/api`
- **Official documentation:** [Get SDS Community Attachment](https://qxobptest.ehsinsight.com/site#/apidocumentation/v6/apidoc_sdscommunityapi_attachment_fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowUid` | path | `string` | yes | Identifier of the SDS Community attachment to download. SDS means safety data sheet. |
