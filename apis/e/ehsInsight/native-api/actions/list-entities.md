# List Entities with EHS Insight

## Endpoint

- **Method:** `GET`
- **Path:** `/v6/entity/list?:customparams`
- **Base URL:** `https://{companyName}.ehsinsight.com/api`
- **Official documentation:** [List Entities](https://equixinctest.ehsinsight.com/openapi/viewer?version=6&category=entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customparams` | path | `string` | no | Optional provider-specific query string segment appended after the list route. |
