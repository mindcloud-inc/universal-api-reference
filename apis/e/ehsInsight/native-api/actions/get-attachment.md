# Get Attachment with EHS Insight

## Endpoint

- **Method:** `GET`
- **Path:** `/v6/attachment/fetch/:rowUid`
- **Base URL:** `https://{companyName}.ehsinsight.com/api`
- **Official documentation:** [Get Attachment](https://qxobptest.ehsinsight.com/site#/apidocumentation/v6/apidoc_attachmentapi_attachment_fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rowUid` | path | `string` | yes | Identifier of the attachment to download. |
