# Create Log with elmah.io

Creates a new log in elmah.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/logs`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Create Log](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the new log. |
