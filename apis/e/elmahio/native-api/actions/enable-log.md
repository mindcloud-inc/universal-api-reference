# Enable Log with elmah.io

Enables a log in elmah.io.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/logs/:id/_enable`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Enable Log](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The ID of the log to enable. |
