# Delete Log with elmah.io

Deletes an existing log from elmah.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/logs/:id`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Delete Log](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The ID of the log to delete. |
