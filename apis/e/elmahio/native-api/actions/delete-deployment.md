# Delete Deployment with elmah.io

Deletes an existing deployment from elmah.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/deployments/:id`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Delete Deployment](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the deployment to delete. |
