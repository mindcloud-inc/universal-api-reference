# Get Log with elmah.io

Retrieves a log from elmah.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/logs/:id`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Get Log](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the log to fetch. |
