# Get Deployment with elmah.io

Retrieves a deployment from elmah.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/deployments/:id`
- **Base URL:** `https://api.elmah.io`
- **Official documentation:** [Get Deployment](https://docs.elmah.io/using-the-rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the deployment to fetch. |
