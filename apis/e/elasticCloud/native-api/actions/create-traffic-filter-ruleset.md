# Create Traffic Filter Ruleset with Elastic Cloud

Creates a new traffic filter ruleset in Elastic Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/deployments/traffic-filter/rulesets`
- **Base URL:** `https://api.elastic-cloud.com/api/v1`
- **Official documentation:** [Create Traffic Filter Ruleset](https://www.elastic.co/docs/api/doc/cloud/operation/operation-create-traffic-filter-ruleset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The specification for the traffic filter ruleset. |
