# Create Extension with Elastic Cloud

Creates a new extension in Elastic Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/deployments/extensions`
- **Base URL:** `https://api.elastic-cloud.com/api/v1`
- **Official documentation:** [Create Extension](https://www.elastic.co/docs/api/doc/cloud/operation/operation-create-extension)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The data that creates the extension. |
