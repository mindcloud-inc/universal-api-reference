# List Deployments with Elastic Cloud

Retrieves deployments from Elastic Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/deployments`
- **Base URL:** `https://api.elastic-cloud.com/api/v1`
- **Official documentation:** [List Deployments](https://www.elastic.co/docs/api/doc/cloud/operation/operation-list-deployments)
