# Get Deployment Certificate Authority with Elastic Cloud

Retrieves a deployment certificate authority from Elastic Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/deployments/:deployment_id/certificate-authority`
- **Base URL:** `https://api.elastic-cloud.com/api/v1`
- **Official documentation:** [Get Deployment Certificate Authority](https://www.elastic.co/docs/api/doc/cloud/operation/operation-get-deployment-certificate-authority)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deployment_id` | path | `string` | yes | Identifier for the deployment. |
