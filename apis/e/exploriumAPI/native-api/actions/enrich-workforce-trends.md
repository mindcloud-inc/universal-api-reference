# Enrich Workforce Trends with Explorium

Enriches businesses with workforce trends in Explorium API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/businesses/workforce_trends/enrich`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Enrich Workforce Trends](https://developers.explorium.ai/reference/businesses/enrichments/workforce_trends)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | body | `string` | yes | The Explorium business identifier to enrich. |
