# Autocomplete Businesses with Explorium

Retrieves business autocomplete results from Explorium API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/businesses/autocomplete`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Autocomplete Businesses](https://developers.explorium.ai/reference/businesses/autocomplete/businesses_autocomplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field` | query | `string` | yes | The autocomplete field to query. |
