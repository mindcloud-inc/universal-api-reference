# Autocomplete Prospects with Explorium

Retrieves prospect autocomplete results from Explorium API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/prospects/autocomplete`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Autocomplete Prospects](https://developers.explorium.ai/reference/prospects/prospects_autocomplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field` | query | `string` | yes | The autocomplete field to query. |
