# Enrich Website Content Changes with Explorium

Enriches businesses with website content changes in Explorium API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/businesses/website_changes/enrich`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Enrich Website Content Changes](https://developers.explorium.ai/reference/businesses/enrichments/company_website_content_changes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | body | `string` | yes | The Explorium business identifier to enrich. |
