# Get Prospects Statistics with Explorium

Retrieves prospect statistics from Explorium API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/prospects/stats`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Get Prospects Statistics](https://developers.explorium.ai/reference/prospects/prospects_stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filters` | body | `object` | yes | The filters object that scopes the prospect statistics request. |
