# Enrich Firmographics with Explorium

Enriches businesses with firmographics in Explorium API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/businesses/firmographics/enrich`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Enrich Firmographics](https://developers.explorium.ai/reference/businesses/enrichments/firmographics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | body | `string` | yes | The Explorium business identifier to enrich. |
