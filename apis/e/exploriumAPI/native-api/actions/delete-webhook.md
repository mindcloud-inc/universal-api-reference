# Delete Webhook with Explorium

Deletes a webhook from Explorium API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/{{partner_id}}`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Delete Webhook](https://developers.explorium.ai/reference/webhooks/delete_webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `partner_id` | path | `string` | yes | Webhook partner identifier. |
