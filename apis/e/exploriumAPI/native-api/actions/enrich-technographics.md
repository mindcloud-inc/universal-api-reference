# Enrich Technographics with Explorium

Enriches businesses with technographics in Explorium API.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/businesses/technographics/enrich`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Enrich Technographics](https://developers.explorium.ai/reference/businesses/enrichments/technographics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `business_id` | body | `string` | yes | The Explorium business identifier to enrich. |
