# Get Webhook with Explorium

Retrieves a webhook from Explorium API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/{{partner_id}}`
- **Base URL:** `https://api.explorium.ai`
- **Official documentation:** [Get Webhook](https://developers.explorium.ai/reference/webhooks/get_webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `partner_id` | path | `string` | yes | Webhook partner identifier. |
