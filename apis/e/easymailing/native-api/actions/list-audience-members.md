# List Audience Members with Easymailing

Retrieves audience members from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/members`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Audience Members](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
