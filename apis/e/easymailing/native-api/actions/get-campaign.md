# Get Campaign with Easymailing

Retrieves a campaign from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/{{uuid}}`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Get Campaign](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Campaign UUID. |
