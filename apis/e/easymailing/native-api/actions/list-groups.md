# List Groups with Easymailing

Retrieves groups from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/groups`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Groups](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
