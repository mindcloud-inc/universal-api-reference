# Get Template with Easymailing

Retrieves a template from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/{{uuid}}`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Get Template](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Template UUID. |
