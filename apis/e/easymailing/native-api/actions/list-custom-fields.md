# List Custom Fields with Easymailing

Retrieves custom fields from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/list_fields`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Custom Fields](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
