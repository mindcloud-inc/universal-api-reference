# Search Members with Easymailing

Finds members in Easymailing by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/search`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Search Members](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Member email address to search. |
