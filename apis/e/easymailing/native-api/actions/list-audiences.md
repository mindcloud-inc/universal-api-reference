# List Audiences with Easymailing

Retrieves audiences from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Audiences](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemsPerPage` | query | `string` | no | Number of records to return per page. |
| `page` | query | `string` | no | Page number to return. |
