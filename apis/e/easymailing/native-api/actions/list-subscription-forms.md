# List Subscription Forms with Easymailing

Retrieves subscription forms from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/suscription_forms`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Subscription Forms](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
