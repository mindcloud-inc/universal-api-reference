# List Condition Fields with Easymailing

Retrieves condition fields from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/condition_fields`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Condition Fields](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
