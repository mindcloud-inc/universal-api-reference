# List Segments with Easymailing

Retrieves segments from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{audienceUuid}}/list_segments`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [List Segments](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `audienceUuid` | path | `string` | yes | Audience UUID. |
