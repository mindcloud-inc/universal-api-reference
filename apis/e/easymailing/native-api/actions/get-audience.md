# Get Audience with Easymailing

Retrieves an audience from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/{{uuid}}`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Get Audience](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Audience UUID. |
