# Get Invoice with Easymailing

Retrieves an invoice from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/{{uuid}}`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Get Invoice](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Invoice UUID. |
