# Get Automation with Easymailing

Retrieves an automation from Easymailing.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/{{uuid}}`
- **Base URL:** `https://api.easymailing.com`
- **Official documentation:** [Get Automation](https://developers.easymailing.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Automation UUID. |
