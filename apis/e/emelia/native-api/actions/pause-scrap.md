# Pause Scrap with Emelia

Pauses a segmented scrap in Emelia.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://graphql.emelia.io`
- **Official documentation:** [Pause Scrap](https://docs-old.emelia.io/#operation-pause_a_scrap-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Scrap identifier |
