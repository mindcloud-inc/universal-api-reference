# Get Campaign with Emelia

Retrieves a campaign from Emelia by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://graphql.emelia.io`
- **Official documentation:** [Get Campaign](https://docs-old.emelia.io/#operation-get_a_campaign-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Campaign identifier |
