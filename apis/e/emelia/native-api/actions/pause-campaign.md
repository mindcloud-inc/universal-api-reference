# Pause Campaign with Emelia

Pauses a campaign in Emelia.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://graphql.emelia.io`
- **Official documentation:** [Pause Campaign](https://docs-old.emelia.io/#operation-pause_a_campaign-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Campaign identifier |
