# Delete Course with EducateMe

Deletes an existing course from EducateMe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/courses/:id`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Delete Course](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#a99cebcdd43a4eb6926170e867b728d1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Course ID. |
