# List Tags with EducateMe

Lists tags in EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [List Tags](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#2bf447e2efaa804f80dace3d8594cd9b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Optional tag category filter. Accepted values: `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`. |
