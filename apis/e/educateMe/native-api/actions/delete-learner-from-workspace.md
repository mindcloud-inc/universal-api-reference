# Delete Learner from Workspace with EducateMe

Deletes an existing learner from EducateMe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/students/:email`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Delete Learner from Workspace](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#80d7f753e1924f21bbb71b07d91d75d4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Learner email. |
