# Delete Activity with EducateMe

Deletes an existing activity from EducateMe.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/activities/:id`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Delete Activity](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#04859b6ad052427dadcf6cca518b49da)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
