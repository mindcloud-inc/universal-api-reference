# List Courses with EducateMe

Lists courses in EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [List Courses](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `isFinished` | query | `boolean` | no | Filter courses by finished status. Docs testing example uses false. |
