# Export Feedback Notes with EducateMe

Exports feedback notes from EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/feedback`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Export Feedback Notes](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#145447e2efaa8008bdd7fecd0400844e)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `periodStart` | query | `string` | no |
| `periodEnd` | query | `string` | no |
| `courseIds` | query | `string` | no |
