# Submit Assignment for Learner with EducateMe

Submits an assignment for a learner in EducateMe.

## Endpoint

- **Method:** `POST`
- **Path:** `/assignments/submit`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Submit Assignment for Learner](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#34c4ce8f275a4e838f299f911157f351)
