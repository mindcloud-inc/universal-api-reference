# List Course Activities with EducateMe

Lists course activities in EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/:id/lessons`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [List Course Activities](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#e2515ce4dfd240caa2f9cf31bf60f093)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `activityId` | query | `string` | no |
