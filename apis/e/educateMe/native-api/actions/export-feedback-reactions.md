# Export Feedback Reactions with EducateMe

Exports feedback reactions from EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/feedback_reactions`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [Export Feedback Reactions](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#233447e2efaa80bfbd30f5247be406a6)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `periodStart` | query | `string` | no |
| `periodEnd` | query | `string` | no |
| `courseIds` | query | `string` | no |
