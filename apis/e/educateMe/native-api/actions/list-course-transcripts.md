# List Course Transcripts with EducateMe

Lists course transcripts in EducateMe.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/:id/transcripts`
- **Base URL:** `https://api.educate-me.co`
- **Official documentation:** [List Course Transcripts](https://edme.notion.site/API-integration-v0-2-ef33641eb7f24fa9a6efb969c1f2928f#249447e2efaa80328f2eedc53a2698ed)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `activityId` | query | `string` | no |
