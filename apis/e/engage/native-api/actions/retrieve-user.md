# Retrieve User with Engage

Retrieves a user from Engage by user ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:uid`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [Retrieve User](https://docs.engage.so/en-us/a/62bbdd015bfea4dca4834042-users#retrieve-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The user ID from your application. |
