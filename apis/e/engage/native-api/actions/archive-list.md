# Archive List with Engage

Archives an existing list in Engage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:id`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [Archive List](https://docs.engage.so/en-us/a/62bbdd2e5bfea4dca4834045-lists#archive-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Engage list ID. |
