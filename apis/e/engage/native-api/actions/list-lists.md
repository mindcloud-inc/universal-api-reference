# List Lists with Engage

Retrieves user lists from Engage with pagination.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [List Lists](https://docs.engage.so/en-us/a/62bbdd2e5bfea4dca4834045-lists#get-all-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
