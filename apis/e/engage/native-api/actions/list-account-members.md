# List Account Members with Engage

Retrieves members of an account from Engage.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:uid/members`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [List Account Members](https://docs.engage.so/en-us/a/62bbdd015bfea4dca4834042-users#get-account-members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The account user ID from your application. |
