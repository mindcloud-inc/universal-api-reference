# Get List with Engage

Retrieves a list from Engage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:id`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [Get List](https://docs.engage.so/en-us/a/62bbdd2e5bfea4dca4834045-lists#get-a-list-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Engage list ID. |
