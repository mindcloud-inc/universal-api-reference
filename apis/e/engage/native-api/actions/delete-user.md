# Delete User with Engage

Deletes a customer or account from Engage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:uid`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [Delete User](https://docs.engage.so/en-us/a/62bbdd015bfea4dca4834042-users#delete-customer-or-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The user ID from your application. |
