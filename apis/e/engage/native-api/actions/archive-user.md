# Archive User with Engage

Archives a customer or account in Engage.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/:uid/archive`
- **Base URL:** `https://api.engage.so/v1`
- **Official documentation:** [Archive User](https://docs.engage.so/en-us/a/62bbdd015bfea4dca4834042-users#archive-a-customer-or-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The user ID from your application. |
