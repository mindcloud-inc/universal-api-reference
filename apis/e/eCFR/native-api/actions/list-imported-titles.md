# List Imported Titles with eCFR

Retrieves a list of imported titles from eCFR.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/versioner-import/v1/titles`
- **Base URL:** `https://www.ecfr.gov`
- **Official documentation:** [List Imported Titles](https://www.ecfr.gov/developers/documentation/api/v1)
