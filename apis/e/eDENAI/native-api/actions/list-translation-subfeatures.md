# List Translation Subfeatures with EDEN AI

Retrieves available translation subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/translation`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Translation Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
