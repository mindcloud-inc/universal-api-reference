# Get Financial Parser Info with EDEN AI

Retrieves feature information for financial parsing in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/financial_parser`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Financial Parser Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
