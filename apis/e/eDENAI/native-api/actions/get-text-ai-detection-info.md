# Get Text AI Detection Info with EDEN AI

Retrieves feature information for text AI detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/ai_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Text AI Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
