# Get OCR Multipage Info with EDEN AI

Retrieves feature information for multipage OCR in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/ocr_async`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get OCR Multipage Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
