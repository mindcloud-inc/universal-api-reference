# Get Logo Detection Info with EDEN AI

Retrieves feature information for logo detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/logo_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Logo Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
