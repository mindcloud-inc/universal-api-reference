# Get Image Anonymization Info with EDEN AI

Retrieves feature information for image anonymization in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/anonymization`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Image Anonymization Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
