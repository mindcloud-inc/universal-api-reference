# List Async Jobs with EDEN AI

Retrieves asynchronous jobs from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/universal-ai/async`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Async Jobs](https://docs.edenai.co/api-reference/universal-ai/list-async-jobs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
