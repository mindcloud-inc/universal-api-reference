# Get Named Entity Recognition Info with EDEN AI

Retrieves feature information for named entity recognition in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/named_entity_recognition`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Named Entity Recognition Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
