# Get Face Compare Info with EDEN AI

Retrieves feature information for face comparison in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/face_compare`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Face Compare Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
