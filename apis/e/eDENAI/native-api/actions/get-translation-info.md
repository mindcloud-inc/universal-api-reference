# Get Translation Info with EDEN AI

Retrieves feature information for translation in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/translation/automatic_translation`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Translation Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
