# Get Plagiarism Detection Info with EDEN AI

Retrieves feature information for plagiarism detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/plagia_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Plagiarism Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
