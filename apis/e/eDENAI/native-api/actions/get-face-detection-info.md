# Get Face Detection Info with EDEN AI

Retrieves feature information for face detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/face_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Face Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
