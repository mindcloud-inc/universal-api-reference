# List Image Subfeatures with EDEN AI

Retrieves available image subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Image Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
