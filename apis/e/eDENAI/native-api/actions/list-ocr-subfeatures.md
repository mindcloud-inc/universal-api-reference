# List OCR Subfeatures with EDEN AI

Retrieves available OCR subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List OCR Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
