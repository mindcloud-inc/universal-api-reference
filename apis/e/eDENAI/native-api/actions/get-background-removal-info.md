# Get Background Removal Info with EDEN AI

Retrieves feature information for background removal in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/background_removal`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Background Removal Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
