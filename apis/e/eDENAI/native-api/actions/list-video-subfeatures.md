# List Video Subfeatures with EDEN AI

Retrieves available video subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/video`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Video Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
