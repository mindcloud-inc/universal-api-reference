# Get Credits with EDEN AI

Retrieves your available credits from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.edenai.run/v2/cost_management/credits/`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Credits](https://docs.edenai.co/api-reference/cost-monitoring/my-credits)
