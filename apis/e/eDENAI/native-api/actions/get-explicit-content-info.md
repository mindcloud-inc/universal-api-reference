# Get Explicit Content Info with EDEN AI

Retrieves feature information for explicit content in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/explicit_content`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Explicit Content Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
