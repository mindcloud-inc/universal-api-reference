# Get Topic Extraction Info with EDEN AI

Retrieves feature information for topic extraction in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/topic_extraction`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Topic Extraction Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
