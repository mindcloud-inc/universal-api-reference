# Get Image AI Detection Info with EDEN AI

Retrieves feature information for image AI detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/ai_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Image AI Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
