# Get Text Moderation Info with EDEN AI

Retrieves feature information for text moderation in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/moderation`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Text Moderation Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
