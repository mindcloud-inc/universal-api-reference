# Get Speech To Text Info with EDEN AI

Retrieves feature information for speech-to-text in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/audio/speech_to_text_async`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Speech To Text Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
