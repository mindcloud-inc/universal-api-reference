# List Features with EDEN AI

Retrieves available features from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Features](https://docs.edenai.co/api-reference/universal-ai-info/list-features)
