# Get Spell Check Info with EDEN AI

Retrieves feature information for spell check in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text/spell_check`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Spell Check Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
