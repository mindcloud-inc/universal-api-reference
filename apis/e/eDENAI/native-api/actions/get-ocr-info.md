# Get OCR Info with EDEN AI

Retrieves feature information for OCR in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/ocr`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get OCR Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
