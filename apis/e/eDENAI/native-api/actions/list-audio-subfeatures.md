# List Audio Subfeatures with EDEN AI

Retrieves available audio subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/audio`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Audio Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
