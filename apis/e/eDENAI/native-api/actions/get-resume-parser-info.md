# Get Resume Parser Info with EDEN AI

Retrieves feature information for resume parsing in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/resume_parser`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Resume Parser Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
