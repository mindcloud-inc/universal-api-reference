# List Text Subfeatures with EDEN AI

Retrieves available text subfeatures from EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/text`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [List Text Subfeatures](https://docs.edenai.co/api-reference/universal-ai-info/list-subfeatures)
