# Get Identity Parser Info with EDEN AI

Retrieves feature information for identity parsing in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/identity_parser`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Identity Parser Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
