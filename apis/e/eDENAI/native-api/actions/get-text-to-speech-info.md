# Get Text To Speech Info with EDEN AI

Retrieves feature information for text-to-speech in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/audio/tts`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Text To Speech Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
