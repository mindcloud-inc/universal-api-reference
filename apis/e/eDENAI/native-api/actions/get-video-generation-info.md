# Get Video Generation Info with EDEN AI

Retrieves feature information for video generation in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/video/generation_async`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Video Generation Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
