# Get OCR Tables Info with EDEN AI

Retrieves feature information for OCR tables in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/ocr/ocr_tables_async`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get OCR Tables Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
