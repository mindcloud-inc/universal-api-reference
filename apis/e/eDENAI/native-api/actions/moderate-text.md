# Moderate Text with EDEN AI

Creates a text moderation request in EDEN AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/universal-ai`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Moderate Text](https://docs.edenai.co/api-reference/universal-ai/universal-ai)
