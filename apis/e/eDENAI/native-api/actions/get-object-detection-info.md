# Get Object Detection Info with EDEN AI

Retrieves feature information for object detection in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/object_detection`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Object Detection Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
