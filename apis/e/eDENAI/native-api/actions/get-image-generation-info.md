# Get Image Generation Info with EDEN AI

Retrieves feature information for image generation in EDEN AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/info/image/generation`
- **Base URL:** `https://api.edenai.run/v3`
- **API:** rest
- **Official documentation:** [Get Image Generation Info](https://docs.edenai.co/api-reference/universal-ai-info/get-feature-info)
