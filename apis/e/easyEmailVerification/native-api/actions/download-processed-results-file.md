# Download Processed Results File with Easy Email Verification

Retrieves a processed bulk results file from Easy Email Verification.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk/download/:id`
- **Base URL:** `https://api.easyemailverification.com/v1`
- **Official documentation:** [Download Processed Results File](https://eev.stoplight.io/docs/eev/823978d9ab42a-download-the-processed-results-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bulk verification job ID. |
