# Delete Bulk Verification Job with Easy Email Verification

Deletes a bulk verification job from Easy Email Verification.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bulk/:id`
- **Base URL:** `https://api.easyemailverification.com/v1`
- **Official documentation:** [Delete Bulk Verification Job](https://eev.stoplight.io/docs/eev/c463fbf875570-delete-a-bulk-verification-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bulk verification job ID. |
