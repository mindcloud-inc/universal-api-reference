# List Bulk Jobs with Easy Email Verification

Retrieves all bulk job statuses from Easy Email Verification.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk/status`
- **Base URL:** `https://api.easyemailverification.com/v1`
- **Official documentation:** [List Bulk Jobs](https://eev.stoplight.io/docs/eev/bb53ca38a5019-get-the-status-of-all-bulk-jobs)
