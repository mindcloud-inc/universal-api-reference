# Verify Email with Easy Email Verification

Retrieves an email verification result from Easy Email Verification.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify`
- **Base URL:** `https://api.easyemailverification.com/v1`
- **Official documentation:** [Verify Email](https://eev.stoplight.io/docs/eev/dfdcc20c7d4e9-lookup-a-single-email-you-can-verify-an-email-to-check-its-validity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to verify. |
