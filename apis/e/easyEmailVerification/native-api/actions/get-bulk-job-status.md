# Get Bulk Job Status with Easy Email Verification

Retrieves a bulk job status from Easy Email Verification.

## Endpoint

- **Method:** `GET`
- **Path:** `/bulk/status/:id`
- **Base URL:** `https://api.easyemailverification.com/v1`
- **Official documentation:** [Get Bulk Job Status](https://eev.stoplight.io/docs/eev/42dd46bb7b21a-get-the-status-of-a-specific-bulk-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Bulk verification job ID. |
