# Switch Current Home with eWeLink

Updates the current home in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/family/current`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Switch Current Home](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
