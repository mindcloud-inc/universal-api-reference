# Add WiFi Device with eWeLink

Creates a new Wi-Fi device in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/add`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Add WiFi Device](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
