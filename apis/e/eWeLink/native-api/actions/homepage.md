# HomePage with eWeLink

Retrieves homepage device data from eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/homepage`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [HomePage](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
