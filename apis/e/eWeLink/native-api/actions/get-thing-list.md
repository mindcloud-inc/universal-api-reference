# Get Thing List with eWeLink

Retrieves things from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/device/thing`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Thing List](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
