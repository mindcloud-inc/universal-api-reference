# Cancel Sharing with eWeLink

Deletes a sharing permission from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/device/share`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Cancel Sharing](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
