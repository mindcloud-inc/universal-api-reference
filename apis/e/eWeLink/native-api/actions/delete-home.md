# Delete Home with eWeLink

Deletes an existing home from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/family`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Delete Home](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
