# Change Sharing Permission with eWeLink

Updates a sharing permission in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/share/permit`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Sharing Permission](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
