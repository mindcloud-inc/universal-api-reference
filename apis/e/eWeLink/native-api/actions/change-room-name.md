# Change Room Name with eWeLink

Updates a room name in eWeLink.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/family/room`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Room Name](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
