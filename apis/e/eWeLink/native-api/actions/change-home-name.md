# Change Home Name with eWeLink

Updates a home name in eWeLink.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/family`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Home Name](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
