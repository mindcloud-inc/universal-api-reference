# Get Device Or Group Status with eWeLink

Retrieves device or group status from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/device/thing/status`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Device Or Group Status](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
