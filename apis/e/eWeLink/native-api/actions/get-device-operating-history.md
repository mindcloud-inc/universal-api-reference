# Get Device Operating History with eWeLink

Retrieves device operating history from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/device/history`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Device Operating History](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
