# Update Group Device List with eWeLink

Updates a group device list in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/group/update`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Update Group Device List](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
