# Logout with eWeLink

Ends the current user session in eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/user/logout`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Logout](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
