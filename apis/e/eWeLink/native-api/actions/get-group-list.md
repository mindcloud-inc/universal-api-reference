# Get Group List with eWeLink

Retrieves groups from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/device/group`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Group List](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
