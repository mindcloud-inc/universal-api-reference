# Clean Device Operating History with eWeLink

Deletes device operating history from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/device/history`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Clean Device Operating History](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
