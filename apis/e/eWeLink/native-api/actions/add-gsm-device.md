# Add GSM Device with eWeLink

Creates a new GSM device in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/add-gsm`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Add GSM Device](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
