# Update Device Or Group Status with eWeLink

Updates device or group status in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/thing/status`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Update Device Or Group Status](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
