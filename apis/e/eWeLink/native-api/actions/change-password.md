# Change Password with eWeLink

Updates the user password in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/user/change-pwd`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Password](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
