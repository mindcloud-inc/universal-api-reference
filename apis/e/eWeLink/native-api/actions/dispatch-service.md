# Dispatch Service with eWeLink

Retrieves dispatch service information from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `https://{region}-dispa.coolkit.cc/dispatch/app`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Dispatch Service](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
