# Change Group Status with eWeLink

Updates group status in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/group/status`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Group Status](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
