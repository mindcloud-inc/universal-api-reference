# Update User Information with eWeLink

Updates user information in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/user/profile`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Update User Information](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
