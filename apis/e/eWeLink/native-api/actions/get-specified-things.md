# Get Specified Things with eWeLink

Retrieves specified things from eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/thing`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Specified Things](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
