# Get Device OTA Update Information with eWeLink

Retrieves device OTA update information from eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/ota/query`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Device OTA Update Information](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
