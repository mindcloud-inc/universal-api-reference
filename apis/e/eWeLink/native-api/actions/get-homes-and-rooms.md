# Get Homes And Rooms with eWeLink

Retrieves homes and rooms from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/family`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Homes And Rooms](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
