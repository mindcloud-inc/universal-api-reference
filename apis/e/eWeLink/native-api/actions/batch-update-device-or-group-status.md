# Batch Update Device Or Group Status with eWeLink

Updates device or group statuses in batch in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/thing/batch-status`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Batch Update Device Or Group Status](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
