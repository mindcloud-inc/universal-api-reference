# Sort Rooms with eWeLink

Updates room order in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/family/room/index`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Sort Rooms](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
