# Get Messages with eWeLink

Retrieves messages from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/message/read`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get Messages](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
