# Update Device Name Or Room with eWeLink

Updates a device name or room in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/update-info`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Update Device Name Or Room](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
