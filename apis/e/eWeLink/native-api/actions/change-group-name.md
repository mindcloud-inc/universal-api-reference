# Change Group Name with eWeLink

Updates a group name in eWeLink.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/device/group`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Group Name](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
