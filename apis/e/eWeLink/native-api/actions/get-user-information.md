# Get User Information with eWeLink

Retrieves user information from eWeLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user/profile`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Get User Information](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
