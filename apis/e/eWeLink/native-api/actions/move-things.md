# Move Things with eWeLink

Updates room assignments for things in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/family/room/thing`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Move Things](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
