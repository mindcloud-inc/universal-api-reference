# Change Device Tags with eWeLink

Updates device tags in eWeLink.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/device/tags`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Change Device Tags](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
