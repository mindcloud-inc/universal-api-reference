# Delete Group with eWeLink

Deletes an existing group from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/device/group`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Delete Group](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
