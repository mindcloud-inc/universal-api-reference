# Delete Device with eWeLink

Deletes an existing device from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/device`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Delete Device](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
