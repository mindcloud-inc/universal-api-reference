# Delete Room with eWeLink

Deletes an existing room from eWeLink.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/family/room`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Delete Room](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
