# Sort Things In Home with eWeLink

Updates thing order in an eWeLink home.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/family/thing/sort`
- **Base URL:** `https://{region}-apia.coolkit.cc`
- **Official documentation:** [Sort Things In Home](https://github.com/CoolKit-Technologies/eWeLink-API/blob/main/en/APICenterV2.md)
