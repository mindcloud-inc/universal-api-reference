# List Calendar Absences with eTermin

Retrieves calendar absences from eTermin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/calendarsnonworkingtimes`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [List Calendar Absences](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/CalendarsNonWorkingTimes/get_api_calendarsnonworkingtimes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarid` | query | `number` | yes | ID of the calendar. |
