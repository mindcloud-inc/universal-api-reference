# Create Calendar with eTermin

Creates a new calendar in eTermin.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/calendar`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [Create Calendar](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/Calendar/post_api_calendar)
