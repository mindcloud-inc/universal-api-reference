# List Calendar Return Times with eTermin

Retrieves calendar return times from eTermin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/calendarreturntime`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [List Calendar Return Times](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/CalendarReturnTime/get_api_calendarreturntime)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarid` | query | `number` | yes | ID of the calendar. |
