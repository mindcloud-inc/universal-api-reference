# Delete Calendar with eTermin

Deletes an existing calendar from eTermin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/calendar`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [Delete Calendar](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/Calendar/delete_api_calendar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of the calendar |
