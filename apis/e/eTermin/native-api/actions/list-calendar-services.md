# List Calendar Services with eTermin

Retrieves services assigned to a calendar in eTermin.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/calendarservice`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [List Calendar Services](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/CalendarService/get_api_calendarservice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendarid` | query | `string` | no | ID of the calendar you want the service assignments |
