# Delete Service with eTermin

Deletes an existing service from eTermin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/service`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [Delete Service](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/Service/delete_api_service)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | ID of the service |
