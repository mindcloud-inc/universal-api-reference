# Delete Service Group with eTermin

Deletes an existing service group from eTermin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/servicegroup`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [Delete Service Group](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/Servicegroup/delete_api_servicegroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `servicegroupid` | query | `number` | yes | ID of the servicegroup that you want information on |
