# Delete Calendar Absence with eTermin

Deletes an existing calendar absence from eTermin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/calendarsnonworkingtimes`
- **Base URL:** `https://www.etermin.net`
- **Official documentation:** [Delete Calendar Absence](https://app.swaggerhub.com/apis-docs/etermin.net/eTermin-API/1.0.0#/CalendarsNonWorkingTimes/delete_api_calendarsnonworkingtimes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | ID of the absence. |
