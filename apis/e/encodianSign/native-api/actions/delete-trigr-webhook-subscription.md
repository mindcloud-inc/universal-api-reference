# Delete Trigr Webhook Subscription with Encodian - Sign

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/Trigr/ManageWebHook/:tenantWebHookId`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Delete Trigr Webhook Subscription](https://api.apps-encodian.com/swagger/Sign/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tenantWebHookId` | path | `number` | yes | ID of the Encodian Trigr webhook subscription to delete. |
