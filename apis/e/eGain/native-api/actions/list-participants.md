# List Participants with eGain

Retrieves a list of participants from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/participants`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Participants](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/participant/getallparticipant.md)
