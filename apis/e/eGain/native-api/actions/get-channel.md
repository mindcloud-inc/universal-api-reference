# Get Channel with eGain

Retrieves a channel from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Channel](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/channel/getchannel.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Channel ID. |
