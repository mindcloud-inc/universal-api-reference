# List Channels with eGain

Retrieves a list of channels from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Channels](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/channel/getallchannels.md)
