# Get Participant with eGain

Retrieves a participant from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/participants/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Participant](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/participant/getparticipant.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Participant ID. |
