# Get Client Application with eGain

Retrieves a client application from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/clientapplications/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Client Application](https://apidev.egain.com/api-catalog/conversation-conversationmgr/api-bundled/operation/getClientApplication/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client application ID. |
