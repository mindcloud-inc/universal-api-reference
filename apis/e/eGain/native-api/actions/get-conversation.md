# Get Conversation with eGain

Retrieves a conversation from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Conversation](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/conversation/fetchconversation.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conversation ID. |
