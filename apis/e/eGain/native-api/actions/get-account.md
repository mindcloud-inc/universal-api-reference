# Get Account with eGain

Retrieves an account from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Account](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/account/getaccount.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Account ID. |
