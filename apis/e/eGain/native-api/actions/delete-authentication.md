# Delete Authentication with eGain

Deletes an existing authentication from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/authentications/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Authentication](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/authentication/deleteauthentication.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Authentication ID. |
