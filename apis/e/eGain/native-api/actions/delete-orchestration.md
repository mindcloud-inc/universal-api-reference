# Delete Orchestration with eGain

Deletes an existing orchestration from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orchestrations/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Orchestration](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/orchestration/deleteorchestration.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Orchestration ID. |
