# Delete Participant with eGain

Deletes an existing participant from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/participants/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Participant](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/participant/deleteparticipant.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Participant ID. |
