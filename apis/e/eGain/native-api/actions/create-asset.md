# Create Asset with eGain

Creates an asset upload URL in eGain.

## Endpoint

- **Method:** `POST`
- **Path:** `/assets`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Create Asset](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/assets/createasset.md)
