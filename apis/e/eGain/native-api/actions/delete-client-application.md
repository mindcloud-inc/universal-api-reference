# Delete Client Application with eGain

Deletes an existing client application from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clientapplications/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Client Application](https://apidev.egain.com/api-catalog/conversation-conversationmgr/api-bundled/operation/deleteClientApplication/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client application ID. |
