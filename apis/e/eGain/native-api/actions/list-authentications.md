# List Authentications with eGain

Retrieves a list of authentications from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/authentications`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Authentications](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/authentication/getallauthentication.md)
