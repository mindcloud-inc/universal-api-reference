# Delete Asset with eGain

Deletes an existing asset from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/assets/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Asset](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/assets/deleteasset.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Asset ID. |
