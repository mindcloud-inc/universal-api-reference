# List Accounts with eGain

Retrieves a list of accounts from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Accounts](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/account/getallaccounts.md)
