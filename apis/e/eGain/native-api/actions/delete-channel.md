# Delete Channel with eGain

Deletes an existing channel from eGain.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channels/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Delete Channel](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/channel/deletechannel.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Channel ID. |
