# Get Asset with eGain

Retrieves an asset download URL from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Asset](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/assets/getasset.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Asset ID. |
