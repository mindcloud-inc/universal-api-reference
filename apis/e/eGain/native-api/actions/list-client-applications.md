# List Client Applications with eGain

Retrieves a list of client applications from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/clientapplications`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Client Applications](https://apidev.egain.com/api-catalog/conversation-conversationmgr/api-bundled/operation/getAllClientApplication/)
