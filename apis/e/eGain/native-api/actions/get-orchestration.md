# Get Orchestration with eGain

Retrieves an orchestration from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/orchestrations/:id`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [Get Orchestration](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/orchestration/getorchestration.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Orchestration ID. |
