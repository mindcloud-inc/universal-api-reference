# List Orchestrations with eGain

Retrieves a list of orchestrations from eGain.

## Endpoint

- **Method:** `GET`
- **Path:** `/orchestrations`
- **Base URL:** `https://api.ai.egain.cloud/conversation/conversationmgr/v3`
- **Official documentation:** [List Orchestrations](https://apidev.egain.com/apis/v3/conversation/conversationmgr/api-bundled/orchestration/getallorchestration.md)
