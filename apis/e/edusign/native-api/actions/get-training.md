# Get Training with Edusign

Retrieves a training from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/trainings/:trainingId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Training](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trainingId` | path | `string` | yes | Training ID |
