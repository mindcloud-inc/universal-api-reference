# List Students by IDs with Edusign

Retrieves students from Edusign by ID list.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/student/by-ids`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [List Students by IDs](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `studentIds[]` | body | `array<string>` | yes |
| `studentIds[]` | body | `array<string>` | yes |
