# Get Course By ID with Edusign

Retrieves a course from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/course/:id`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Course By ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Course id |
