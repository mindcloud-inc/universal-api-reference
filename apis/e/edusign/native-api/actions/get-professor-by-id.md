# Get Professor By ID with Edusign

Retrieves a professor from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/professor/:professorId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Professor By ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `professorId` | path | `string` | yes | Professor ID |
