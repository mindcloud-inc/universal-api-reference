# Get Student By ID with Edusign

Retrieves a student from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/student/:studentId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Student By ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `studentId` | path | `string` | yes | Student ID |
