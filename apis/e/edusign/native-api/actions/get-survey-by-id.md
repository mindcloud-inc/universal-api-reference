# Get Survey By ID with Edusign

Retrieves a survey from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/surveys/:surveyId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Survey By ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `string` | yes | Survey ID |
