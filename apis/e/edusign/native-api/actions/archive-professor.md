# Archive Professor with Edusign

Archives an existing professor in Edusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/professor/:professorId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Archive Professor](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `professorId` | path | `string` | yes | Professor ID |
