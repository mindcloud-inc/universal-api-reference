# Get Course Timestamps with Edusign

Retrieves course timestamps from Edusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/course/timestamps/:courseId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Course Timestamps](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | yes | Id of the course |
