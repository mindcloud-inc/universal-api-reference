# Get Professor ID By API ID with Edusign

Retrieves a professor ID from Edusign by API ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/professor/get-id/:apiId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Professor ID By API ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `apiId` | path | `string` | yes |
