# Archive Training with Edusign

Archives an existing training in Edusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/trainings/:trainingId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Archive Training](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trainingId` | path | `string` | yes | Training ID |
