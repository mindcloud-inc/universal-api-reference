# Delete Course with Edusign

Deletes an existing course from Edusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/course/:id`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Delete Course](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Course ID |
