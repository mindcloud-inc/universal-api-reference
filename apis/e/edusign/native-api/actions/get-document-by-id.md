# Get Document By ID with Edusign

Retrieves a document from Edusign by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/documents/:documentId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Document By ID](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Document ID |
