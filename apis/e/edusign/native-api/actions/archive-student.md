# Archive Student with Edusign

Archives an existing student in Edusign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/student/:studentId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Archive Student](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `studentId` | path | `string` | yes | Student ID |
