# Get Student By Email with Edusign

Finds a student in Edusign by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/student/by-email/:email`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Student By Email](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Student email |
