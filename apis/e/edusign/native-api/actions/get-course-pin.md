# Get Course PIN with Edusign

Retrieves a course PIN from Edusign.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/course/pin/:courseId`
- **Base URL:** `https://ext.edusign.fr`
- **Official documentation:** [Get Course PIN](https://developers.edusign.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | yes | Id of the course |
