# Get API Key with EbulkSMS

Retrieves your EbulkSMS API key.

## Endpoint

- **Method:** `POST`
- **Path:** `/getapikey.json`
- **Base URL:** `https://api.ebulksms.com`
- **Official documentation:** [Get API Key](https://www.ebulksms.com/files/uploads/docs/ebulksms-api.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `auth.password` | body | `string` | yes | Your EbulkSMS account password. |
