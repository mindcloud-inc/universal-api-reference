# List Discovery Tasks with Extruct AI

Retrieves discovery tasks from Extruct AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/discovery_tasks`
- **Base URL:** `https://api.extruct.ai`
- **Official documentation:** [List Discovery Tasks](https://docs.extruct.ai/api-reference/discover/list-company-discovery-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
