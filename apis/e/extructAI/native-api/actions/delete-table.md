# Delete Table with Extruct AI

Deletes a table from Extruct AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/tables/:table_id`
- **Base URL:** `https://api.extruct.ai`
- **Official documentation:** [Delete Table](https://docs.extruct.ai/api-reference/tables/delete-table)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `table_id` | path | `string` | yes | Target table identifier. |
