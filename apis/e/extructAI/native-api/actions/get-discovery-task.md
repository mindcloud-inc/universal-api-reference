# Get Discovery Task with Extruct AI

Retrieves a discovery task from Extruct AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/discovery_tasks/:task_id`
- **Base URL:** `https://api.extruct.ai`
- **Official documentation:** [Get Discovery Task](https://docs.extruct.ai/api-reference/discover/get-company-discovery-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | Deep Search task identifier. |
