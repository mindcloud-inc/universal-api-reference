# Get Table with Extruct AI

Retrieves a table from Extruct AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tables/:table_id`
- **Base URL:** `https://api.extruct.ai`
- **Official documentation:** [Get Table](https://docs.extruct.ai/api-reference/tables/get-table)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `table_id` | path | `string` | yes | Target table identifier. |
