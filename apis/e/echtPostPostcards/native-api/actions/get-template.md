# Get Template with EchtPost Postcards

Retrieves a saved template from EchtPost Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.echtpost.de/v1`
- **Official documentation:** [Get Template](https://api.echtpost.de/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The EchtPost template ID. |
