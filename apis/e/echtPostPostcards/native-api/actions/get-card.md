# Get Card with EchtPost Postcards

Retrieves a saved postcard from EchtPost Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:id`
- **Base URL:** `https://api.echtpost.de/v1`
- **Official documentation:** [Get Card](https://api.echtpost.de/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The EchtPost card ID. |
