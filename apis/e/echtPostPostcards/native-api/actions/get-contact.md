# Get Contact with EchtPost Postcards

Retrieves a saved contact from EchtPost Postcards.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.echtpost.de/v1`
- **Official documentation:** [Get Contact](https://api.echtpost.de/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The EchtPost contact ID. |
