# Add Credits with EchtPost Postcards

Adds postcard credits to your EchtPost Postcards account.

## Endpoint

- **Method:** `POST`
- **Path:** `/credits`
- **Base URL:** `https://api.echtpost.de/v1`
- **Official documentation:** [Add Credits](https://api.echtpost.de/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `number_cards` | body | `number` | yes | How many domestic postcards to add credit for. |
