# Delete Card with EchtPost Postcards

Deletes a saved postcard from EchtPost Postcards.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cards/:id`
- **Base URL:** `https://api.echtpost.de/v1`
- **Official documentation:** [Delete Card](https://api.echtpost.de/api-docs/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The EchtPost card ID. |
