# List Websets with Exa

Retrieves websets from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/websets`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [List Websets](https://exa.ai/docs/websets/api/websets/list-all-websets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
