# Delete Monitor with Exa

Deletes an existing monitor from Exa.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/monitors/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Delete Monitor](https://exa.ai/docs/websets/api/monitors/delete-monitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Monitor identifier. |
