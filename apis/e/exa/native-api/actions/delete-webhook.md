# Delete Webhook with Exa

Deletes an existing webhook from Exa.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/websets/v0/webhooks/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Delete Webhook](https://exa.ai/docs/websets/api/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook identifier. |
