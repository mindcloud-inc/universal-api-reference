# Get Import with Exa

Retrieves an import from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/imports/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Get Import](https://exa.ai/docs/websets/api/imports/get-import)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Import identifier. |
