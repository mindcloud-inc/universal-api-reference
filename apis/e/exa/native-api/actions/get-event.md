# Get Event with Exa

Retrieves an event from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/events/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Get Event](https://exa.ai/docs/websets/api/events/get-an-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the event to retrieve. |
