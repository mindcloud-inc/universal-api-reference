# Delete Webset with Exa

Deletes an existing webset from Exa.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/websets/v0/websets/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Delete Webset](https://exa.ai/docs/websets/api/websets/delete-a-webset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id or externalId of the Webset |
