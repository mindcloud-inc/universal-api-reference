# List Webhooks with Exa

Retrieves webhooks from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/webhooks`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [List Webhooks](https://exa.ai/docs/websets/api/webhooks/list-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
