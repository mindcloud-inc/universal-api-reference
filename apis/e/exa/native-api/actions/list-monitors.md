# List Monitors with Exa

Retrieves monitors from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/monitors`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [List Monitors](https://exa.ai/docs/websets/api/monitors/list-monitors)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional monitor status filter. |
