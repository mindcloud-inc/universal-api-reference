# Preview Webset with Exa

Retrieves a webset preview from Exa.

## Endpoint

- **Method:** `POST`
- **Path:** `/websets/v0/websets/preview`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Preview Webset](https://exa.ai/docs/websets/api/websets/preview-a-webset)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `search` | body | `object` | yes |
