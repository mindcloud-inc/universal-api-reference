# List Imports with Exa

Retrieves imports from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/imports`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [List Imports](https://exa.ai/docs/websets/api/imports/list-imports)

## Capabilities

This operation supports [pagination](../README.md#pagination).
