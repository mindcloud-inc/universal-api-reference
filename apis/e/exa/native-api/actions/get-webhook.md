# Get Webhook with Exa

Retrieves a webhook from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/websets/v0/webhooks/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Get Webhook](https://exa.ai/docs/websets/api/webhooks/get-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook identifier. |
