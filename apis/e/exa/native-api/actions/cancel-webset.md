# Cancel Webset with Exa

Cancels a running webset in Exa.

## Endpoint

- **Method:** `POST`
- **Path:** `/websets/v0/websets/:id/cancel`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Cancel Webset](https://exa.ai/docs/websets/api/websets/cancel-a-running-webset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id or externalId of the Webset |
