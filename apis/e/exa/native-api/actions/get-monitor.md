# Get Monitor with Exa

Retrieves a monitor from Exa.

## Endpoint

- **Method:** `GET`
- **Path:** `/monitors/:id`
- **Base URL:** `https://api.exa.ai`
- **Official documentation:** [Get Monitor](https://exa.ai/docs/websets/api/monitors/get-monitor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Monitor identifier. |
