# List Presets with Easy-Peasy.AI

Retrieves text generation presets from Easy-Peasy.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/presets`
- **Base URL:** `https://easy-peasy.ai`
- **API:** rest
- **Official documentation:** [List Presets](https://docs.easy-peasy.ai/api-reference/endpoint/list-presets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Optional preset category filter documented by Easy-Peasy.AI. |
