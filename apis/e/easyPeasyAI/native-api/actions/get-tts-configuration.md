# Get TTS Configuration with Easy-Peasy.AI

Retrieves TTS voice configuration from Easy-Peasy.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get-text-to-speech-config`
- **Base URL:** `https://easy-peasy.ai`
- **API:** rest
- **Official documentation:** [Get TTS Configuration](https://docs.easy-peasy.ai/api-reference/endpoint/get-tts-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | query | `string` | no | Optional language code used to scope TTS configuration. |
