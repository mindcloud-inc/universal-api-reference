# Delete User with Edoobox

Deletes an existing user from Edoobox.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/:user_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Delete User](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The edoobox user id. |
