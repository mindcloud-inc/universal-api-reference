# Get Vat with Edoobox

Retrieves details for a VAT rate from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/vat/:vat_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Vat](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vat_id` | path | `string` | yes | The edoobox VAT ID. |
