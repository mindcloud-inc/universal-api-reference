# Get Offer with Edoobox

Retrieves details for an offer from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/offer/:offer_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Offer](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offer_id` | path | `string` | yes | The edoobox offer ID to retrieve. |
