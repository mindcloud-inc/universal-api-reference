# Get Category with Edoobox

Retrieves details for a category from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/:category_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Category](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | path | `string` | yes | edoobox category ID. |
