# Get User with Edoobox

Retrieves details for a user from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get User](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | edoobox user ID. |
