# Get User Dashboard with Edoobox

Retrieves a user dashboard from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id/dashboard`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get User Dashboard](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The edoobox user id. |
