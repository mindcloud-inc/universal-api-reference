# Get Booking with Edoobox

Retrieves details for a booking from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking/:booking_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Booking](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `booking_id` | path | `string` | yes | edoobox booking ID. |
