# Get Invoice with Edoobox

Retrieves details for an invoice from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Invoice](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | edoobox invoice ID. |
