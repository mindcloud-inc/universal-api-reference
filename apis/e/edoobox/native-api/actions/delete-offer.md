# Delete Offer with Edoobox

Deletes an existing offer from Edoobox.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/offer/:offer_id`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Delete Offer](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offer_id` | path | `string` | yes | edoobox offer ID. |
