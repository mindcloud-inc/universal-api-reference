# Get Category Dashboard with Edoobox

Retrieves a category dashboard from Edoobox.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/:category_id/dashboard`
- **Base URL:** `https://app2.edoobox.com/v2`
- **Official documentation:** [Get Category Dashboard](https://api.docs.edoobox.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | path | `string` | yes | The edoobox category ID. |
