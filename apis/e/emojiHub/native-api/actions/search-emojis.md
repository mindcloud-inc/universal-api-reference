# Search Emojis with EmojiHub

Searches EmojiHub emojis by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://emojihub.yurace.pro/api`
- **Official documentation:** [Search Emojis](https://github.com/cheatsnake/emojihub)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Text used to search emoji names. |
