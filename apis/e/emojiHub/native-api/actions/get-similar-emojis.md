# Get Similar Emojis with EmojiHub

Retrieves emojis similar to a selected emoji name.

## Endpoint

- **Method:** `GET`
- **Path:** `/similar/:name`
- **Base URL:** `https://emojihub.yurace.pro/api`
- **Official documentation:** [Get Similar Emojis](https://github.com/cheatsnake/emojihub)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Emoji name used to find similar matches. |
