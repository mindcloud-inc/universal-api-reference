# Portal Self with ESRI

Retrieves the current ArcGIS portal view.

## Endpoint

- **Method:** `GET`
- **Path:** `https://www.arcgis.com/sharing/rest/portals/self`
- **Base URL:** `https://www.arcgis.com/sharing/rest`
- **Official documentation:** [Portal Self](https://developers.arcgis.com/rest/users-groups-and-items/portal-self/)
