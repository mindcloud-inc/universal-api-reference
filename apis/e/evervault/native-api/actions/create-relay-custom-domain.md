# Create Relay Custom Domain with Evervault

Creates a relay custom domain in Evervault.

## Endpoint

- **Method:** `POST`
- **Path:** `/relays/{relay_id}/custom-domains`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Create Relay Custom Domain](https://docs.evervault.com/api#createCustomDomain)
