# Delete Relay Custom Domain with Evervault

Deletes an existing relay custom domain from Evervault.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/relays/{relay_id}/custom-domains/{id}`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Delete Relay Custom Domain](https://docs.evervault.com/api#deleteCustomDomain)
