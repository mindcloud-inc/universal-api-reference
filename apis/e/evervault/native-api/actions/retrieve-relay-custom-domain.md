# Retrieve Relay Custom Domain with Evervault

Retrieves a relay custom domain from Evervault.

## Endpoint

- **Method:** `GET`
- **Path:** `/relays/{relay_id}/custom-domains/{id}`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Retrieve Relay Custom Domain](https://docs.evervault.com/api#retrieveCustomDomain)
