# Retrieve Webhook Endpoint with Evervault

Retrieves a webhook endpoint from Evervault.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-endpoints/{webhook_endpoint_id}`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Retrieve Webhook Endpoint](https://docs.evervault.com/api#getWebhookEndpoint)
