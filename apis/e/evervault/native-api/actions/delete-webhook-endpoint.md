# Delete Webhook Endpoint with Evervault

Deletes an existing webhook endpoint from Evervault.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook-endpoints/{webhook_endpoint_id}`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Delete Webhook Endpoint](https://docs.evervault.com/api#deleteWebhookEndpoint)
