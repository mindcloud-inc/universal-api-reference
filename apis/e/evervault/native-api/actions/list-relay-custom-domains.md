# List Relay Custom Domains with Evervault

Retrieves relay custom domains from Evervault.

## Endpoint

- **Method:** `GET`
- **Path:** `/relays/{relay_id}/custom-domains`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [List Relay Custom Domains](https://docs.evervault.com/api#fetchCustomDomainsForRelay)
