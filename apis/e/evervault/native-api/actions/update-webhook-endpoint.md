# Update Webhook Endpoint with Evervault

Updates an existing webhook endpoint in Evervault.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/webhook-endpoints/{webhook_endpoint_id}`
- **Base URL:** `https://api.evervault.com`
- **Official documentation:** [Update Webhook Endpoint](https://docs.evervault.com/api#updateWebhookEndpoint)
