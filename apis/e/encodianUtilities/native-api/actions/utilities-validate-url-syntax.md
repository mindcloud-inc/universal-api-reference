# Utilities - Validate URL Syntax with Encodian - Utilities

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Utilities/ValidateUrlSyntax`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Utilities - Validate URL Syntax](https://support.encodian.com/hc/en-gb/articles/9601816944413)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | The URL syntax to validate, please include https:// or http:// in your request |
