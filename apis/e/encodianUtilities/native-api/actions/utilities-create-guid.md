# Utilities - Create GUID with Encodian - Utilities

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/Utilities/CreateGuid`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Utilities - Create GUID](https://support.encodian.com/hc/en-gb/articles/9563119917597)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `case` | body | `string` | yes | Set the case of the GUID (Lower or Upper) Accepted values: `0`, `1`. |
