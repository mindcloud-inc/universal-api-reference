# Membership Members Details with Explara

Retrieves membership member details from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/cm/api/membership/members-details`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Membership Members Details](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | query | `string` | yes | Explara membership order number. |
