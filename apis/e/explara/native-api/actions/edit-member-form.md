# Edit Member Form with Explara

Retrieves an edit member form from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/cm/api/publisher/edit-membership-form`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Edit Member Form](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | query | `string` | yes | Explara membership order number. |
