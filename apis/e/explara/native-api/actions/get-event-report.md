# Get Event Report with Explara

Retrieves an event report from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/e/get-report`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Get Event Report](https://developers.explara.com/developers-api#10-get-event-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | body | `string` | yes | Explara event identifier. |
