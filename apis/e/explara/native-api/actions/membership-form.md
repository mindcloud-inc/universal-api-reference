# Membership Form with Explara

Retrieves a membership form from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/cm/api/membership/membership-form`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Membership Form](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | body | `string` | yes | Explara membership order number. |
