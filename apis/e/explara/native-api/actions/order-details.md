# Order Details with Explara

Retrieves order details from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/publisher/order-details`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Order Details](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | body | `string` | yes | Explara order number. |
