# List Tickets with Explara

Retrieves tickets from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/publisher/ticket-details`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [List Tickets](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | body | `string` | yes | Explara event identifier. |
