# Membership Order Details with Explara

Retrieves membership order details from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/cm/api/membership/order-details`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Membership Order Details](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | body | `string` | yes | Explara membership order number. |
