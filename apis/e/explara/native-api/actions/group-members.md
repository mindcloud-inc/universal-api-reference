# Group Members with Explara

Retrieves group members from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/cm/api/publisher/members`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Group Members](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | body | `string` | yes | Explara group identifier. |
