# Get Event Details with Explara

Retrieves event details from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/resource/event-detail`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Get Event Details](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | body | `string` | yes | Explara event identifier. |
