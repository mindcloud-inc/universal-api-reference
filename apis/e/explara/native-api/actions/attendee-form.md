# Attendee Form with Explara

Retrieves an attendee form from Explara.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/publisher/attendee-form`
- **Base URL:** `https://www.explara.com`
- **Official documentation:** [Attendee Form](https://apidocs.explara.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderNo` | body | `string` | yes | Explara order number. |
