# Create Media File with EZ Texting

Creates a media file in EZ Texting.

## Endpoint

- **Method:** `POST`
- **Path:** `/media-files`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Create Media File](https://developers.eztexting.com/reference/create_2-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaUrl` | body | `string` | yes | Public media URL |
