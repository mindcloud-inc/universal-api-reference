# Get Media File with EZ Texting

Retrieves a media file from EZ Texting.

## Endpoint

- **Method:** `GET`
- **Path:** `/media-files/:id`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Get Media File](https://developers.eztexting.com/reference/get_3-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Media file ID |
