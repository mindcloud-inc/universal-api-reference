# Get Contact with EZ Texting

Retrieves a contact from EZ Texting by phone number.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:phoneNumber`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Get Contact](https://developers.eztexting.com/reference/get-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phoneNumber` | path | `string` | yes | Phone number |
