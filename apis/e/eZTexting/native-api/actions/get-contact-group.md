# Get Contact Group with EZ Texting

Retrieves a contact group from EZ Texting.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-groups/:id`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Get Contact Group](https://developers.eztexting.com/reference/get_1-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact group ID |
