# Delete Contact with EZ Texting

Deletes a contact from EZ Texting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:phoneNumber`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Delete Contact](https://developers.eztexting.com/reference/delete-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phoneNumber` | path | `string` | yes | Phone number |
