# Delete Webhook with EZ Texting

Deletes a webhook from EZ Texting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/subscriptions/:id`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Delete Webhook](https://developers.eztexting.com/reference/delete_6-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID |
