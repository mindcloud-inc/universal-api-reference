# Delete Contact Group with EZ Texting

Deletes a contact group from EZ Texting.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact-groups/:id`
- **Base URL:** `https://a.eztexting.com/v1`
- **Official documentation:** [Delete Contact Group](https://developers.eztexting.com/reference/delete_2-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact group ID |
