# eth_blockNumber with Etherscan

Retrieves the latest block number from Etherscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/api`
- **Base URL:** `https://api.etherscan.io`
- **Official documentation:** [eth_blockNumber](https://docs.etherscan.io/api-reference/endpoint/ethblocknumber)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chainid` | query | `string` | no |
