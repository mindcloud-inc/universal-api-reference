# Get Ether Last Price with Etherscan

Retrieves the latest Ether price from Etherscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/api`
- **Base URL:** `https://api.etherscan.io`
- **Official documentation:** [Get Ether Last Price](https://docs.etherscan.io/api-reference/endpoint/ethprice)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chainid` | query | `string` | no |
