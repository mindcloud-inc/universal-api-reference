# eth_gasPrice with Etherscan

Retrieves the current gas price from Etherscan.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/api`
- **Base URL:** `https://api.etherscan.io`
- **Official documentation:** [eth_gasPrice](https://docs.etherscan.io/api-reference/endpoint/ethgasprice)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chainid` | query | `string` | no |
