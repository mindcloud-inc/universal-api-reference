# Check Balance with ExpertTexting

Retrieves account balance from ExpertTexting.

## Endpoint

- **Method:** `GET`
- **Path:** `/ExptRestApi/sms/json/Account/Balance`
- **Base URL:** `https://www.experttexting.com`
- **Official documentation:** [Check Balance](https://www.experttexting.com/appv2/Documentation/Balance)
