# List Unread Inbox Messages with ExpertTexting

Retrieves unread inbox messages from ExpertTexting.

## Endpoint

- **Method:** `GET`
- **Path:** `/ExptRestApi/sms/json/Message/UnreadInbox`
- **Base URL:** `https://www.experttexting.com`
- **Official documentation:** [List Unread Inbox Messages](https://www.experttexting.com/appv2/Documentation/UnreadInbox)
