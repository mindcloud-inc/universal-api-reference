# Get Joined Rooms with Element

Retrieves joined rooms from Element.

## Endpoint

- **Method:** `GET`
- **Path:** `/_matrix/client/v3/joined_rooms`
- **Base URL:** `{homeserverUrl}`
- **Official documentation:** [Get Joined Rooms](https://spec.matrix.org/latest/client-server-api/#get_matrixclientv3joined_rooms)
