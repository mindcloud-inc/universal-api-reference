# Get Pushers with Element

Retrieves push notification pushers from Element.

## Endpoint

- **Method:** `GET`
- **Path:** `/_matrix/client/v3/pushers`
- **Base URL:** `{homeserverUrl}`
- **Official documentation:** [Get Pushers](https://spec.matrix.org/latest/client-server-api/#get_matrixclientv3pushers)
