# Get Current User with Element

Retrieves the current user from Element.

## Endpoint

- **Method:** `GET`
- **Path:** `/_matrix/client/v3/account/whoami`
- **Base URL:** `{homeserverUrl}`
- **Official documentation:** [Get Current User](https://spec.matrix.org/latest/client-server-api/#get_matrixclientv3accountwhoami)
