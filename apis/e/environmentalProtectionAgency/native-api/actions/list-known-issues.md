# List Known Issues with Environmental Protection Agency

Retrieves known issues from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/metaData/issues`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [List Known Issues](https://aqs.epa.gov/aqsweb/documents/data_api.html#metadata)
