# List Parameter Classes with Environmental Protection Agency

Retrieves parameter classes from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/classes`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [List Parameter Classes](https://aqs.epa.gov/aqsweb/documents/data_api.html#lists)
