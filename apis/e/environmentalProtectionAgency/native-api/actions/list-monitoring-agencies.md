# List Monitoring Agencies with Environmental Protection Agency

Retrieves monitoring agencies from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/mas`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [List Monitoring Agencies](https://aqs.epa.gov/aqsweb/documents/data_api.html#lists)
