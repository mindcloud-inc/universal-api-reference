# List PQAOs with Environmental Protection Agency

Retrieves primary quality assurance organizations from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/list/pqaos`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [List PQAOs](https://aqs.epa.gov/aqsweb/documents/data_api.html#lists)
