# List Revision History with Environmental Protection Agency

Retrieves revision history from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/metaData/revisionHistory`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [List Revision History](https://aqs.epa.gov/aqsweb/documents/data_api.html#metadata)
