# Check API Availability with Environmental Protection Agency

Retrieves API availability status from EPA AQS.

## Endpoint

- **Method:** `GET`
- **Path:** `/metaData/isAvailable`
- **Base URL:** `https://aqs.epa.gov/data/api`
- **Official documentation:** [Check API Availability](https://aqs.epa.gov/aqsweb/documents/data_api.html#metadata)
