# Find Claim Assignments with Encircle

Retrieves claim assignments from Encircle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/property_claims/:property_claim_id/assignments`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Find Claim Assignments](https://encircleinc.github.io/public-api/#/paths/~1v1~1property_claims~1{property_claim_id}~1assignments/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `property_claim_id` | path | `number` | yes |
