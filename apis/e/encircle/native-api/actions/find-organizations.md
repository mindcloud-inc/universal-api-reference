# Find Organizations with Encircle

Retrieves organizations from Encircle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Find Organizations](https://encircleinc.github.io/public-api/#/paths/~1v1~1organizations/get)
