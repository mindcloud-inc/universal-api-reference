# Get Property Claim with Encircle

Retrieves a property claim from Encircle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/property_claims/:property_claim_id`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Get Property Claim](https://encircleinc.github.io/public-api/#/paths/~1v1~1property_claims~1{property_claim_id}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `property_claim_id` | path | `number` | yes |
