# Find Inspection Assignments with Encircle

Retrieves inspection assignments from Encircle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/property_inspections/:property_inspection_id/assignments`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Find Inspection Assignments](https://encircleinc.github.io/public-api/#/paths/~1v1~1property_inspections~1{property_inspection_id}~1assignments/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `property_inspection_id` | path | `number` | yes |
