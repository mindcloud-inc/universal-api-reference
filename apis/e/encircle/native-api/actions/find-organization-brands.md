# Find Organization Brands with Encircle

Retrieves organization brands from Encircle.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/:organization_id/brands`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Find Organization Brands](https://encircleinc.github.io/public-api/#/paths/~1v1~1organizations~1{organization_id}~1brands/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organization_id` | path | `string` | yes |
