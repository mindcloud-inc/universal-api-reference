# Get Property Inspection with Encircle

Retrieves a property inspection from Encircle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/property_inspections/:property_inspection_id`
- **Base URL:** `https://api.encircleapp.com`
- **Official documentation:** [Get Property Inspection](https://encircleinc.github.io/public-api/#/paths/~1v1~1property_inspections~1{property_inspection_id}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `property_inspection_id` | path | `number` | yes |
