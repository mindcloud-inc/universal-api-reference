# List Supported Forex Pairs with EODHD

Retrieves supported forex pairs from EODHD API.

## Endpoint

- **Method:** `GET`
- **Path:** `/exchange-symbol-list/{exchangeCode}`
- **Base URL:** `https://eodhd.com/api`
- **Official documentation:** [List Supported Forex Pairs](https://eodhd.com/financial-apis/list-supported-forex-currencies/)
