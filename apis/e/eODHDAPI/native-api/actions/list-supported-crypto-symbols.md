# List Supported Crypto Symbols with EODHD

Retrieves supported cryptocurrency symbols from EODHD API.

## Endpoint

- **Method:** `GET`
- **Path:** `/exchange-symbol-list/{exchangeCode}`
- **Base URL:** `https://eodhd.com/api`
- **Official documentation:** [List Supported Crypto Symbols](https://eodhd.com/financial-apis/list-supported-crypto-currencies/)
