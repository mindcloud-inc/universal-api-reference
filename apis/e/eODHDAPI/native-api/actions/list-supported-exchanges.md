# List Supported Exchanges with EODHD

Retrieves supported exchanges from EODHD API.

## Endpoint

- **Method:** `GET`
- **Path:** `/exchanges-list/`
- **Base URL:** `https://eodhd.com/api`
- **Official documentation:** [List Supported Exchanges](https://eodhd.com/financial-apis/exchanges-api-list-of-tickers-and-trading-hours/)
