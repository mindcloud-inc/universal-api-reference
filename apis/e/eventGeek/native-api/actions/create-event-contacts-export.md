# Create Event Contacts Export with EventGeek

Creates an event contacts export in EventGeek.

## Endpoint

- **Method:** `POST`
- **Path:** `/events/:event_id/contacts/exports`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Create Event Contacts Export](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Circa event identifier. |
