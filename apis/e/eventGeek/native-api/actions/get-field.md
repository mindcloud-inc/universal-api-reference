# Get Field with EventGeek

Retrieves a custom field from EventGeek by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/fields/:field_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Get Field](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | path | `string` | yes | Circa field identifier. |
