# Update Company with EventGeek

Updates an existing company in EventGeek.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Update Company](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Circa company identifier. |
