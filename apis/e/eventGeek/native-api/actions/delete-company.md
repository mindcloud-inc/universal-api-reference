# Delete Company with EventGeek

Deletes an existing company from EventGeek.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Delete Company](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Circa company identifier. |
