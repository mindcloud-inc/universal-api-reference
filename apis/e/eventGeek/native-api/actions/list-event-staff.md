# List Event Staff with EventGeek

Retrieves event staff records from EventGeek.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:event_id/staff`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [List Event Staff](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Circa event identifier. |
