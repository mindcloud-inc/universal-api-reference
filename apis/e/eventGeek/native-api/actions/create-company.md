# Create Company with EventGeek

Creates a new company in EventGeek.

## Endpoint

- **Method:** `POST`
- **Path:** `/companies`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Create Company](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Company name. |
