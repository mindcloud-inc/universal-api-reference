# Get Team with EventGeek

Retrieves a team from EventGeek by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Get Team](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `string` | yes | Circa team identifier. |
