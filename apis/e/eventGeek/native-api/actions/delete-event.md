# Delete Event with EventGeek

Deletes an existing event from EventGeek.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/:event_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Delete Event](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Circa event identifier. |
