# Update Event with EventGeek

Updates an existing event in EventGeek.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/events/:event_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Update Event](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Circa event identifier. |
