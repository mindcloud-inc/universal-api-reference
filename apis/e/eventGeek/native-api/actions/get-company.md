# Get Company with EventGeek

Retrieves a company from EventGeek by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Get Company](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Circa company identifier. |
