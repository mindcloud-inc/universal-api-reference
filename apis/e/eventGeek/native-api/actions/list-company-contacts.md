# List Company Contacts with EventGeek

Retrieves company contact records from EventGeek.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:company_id/contacts`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [List Company Contacts](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Circa company identifier. |
