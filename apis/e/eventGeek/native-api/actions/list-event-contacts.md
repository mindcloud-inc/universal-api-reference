# List Event Contacts with EventGeek

Retrieves contacts for an event in EventGeek.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:event_id/contacts`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [List Event Contacts](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Circa event identifier. |
