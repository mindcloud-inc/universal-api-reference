# Get Contact with EventGeek

Retrieves a contact from EventGeek by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://app.circa.co/api/v1`
- **Official documentation:** [Get Contact](https://docs.circa.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Circa contact identifier. |
