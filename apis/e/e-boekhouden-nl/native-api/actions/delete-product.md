# Delete Product with e-Boekhouden.nl

Deletes a product from e-Boekhouden.nl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/product/:id`
- **Base URL:** `https://api.e-boekhouden.nl`
- **API:** rest
- **Official documentation:** [Delete Product](https://api.e-boekhouden.nl/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
