# Delete Cost Center with e-Boekhouden.nl

Deletes a cost center from e-Boekhouden.nl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/costcenter/:id`
- **Base URL:** `https://api.e-boekhouden.nl`
- **API:** rest
- **Official documentation:** [Delete Cost Center](https://api.e-boekhouden.nl/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
