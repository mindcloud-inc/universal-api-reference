# List Product Groups with e-Boekhouden.nl

Retrieves product groups from e-Boekhouden.nl.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/product/groups`
- **Base URL:** `https://api.e-boekhouden.nl`
- **API:** rest
- **Official documentation:** [List Product Groups](https://api.e-boekhouden.nl/swagger/index.html)
