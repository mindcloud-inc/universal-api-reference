# Get Invoice with e-Boekhouden.nl

Retrieves an invoice from e-Boekhouden.nl.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoice/:id`
- **Base URL:** `https://api.e-boekhouden.nl`
- **API:** rest
- **Official documentation:** [Get Invoice](https://api.e-boekhouden.nl/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
