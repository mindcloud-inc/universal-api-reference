# List Campaigns with Emailchaser

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.emailchaser.com/r`
- **Official documentation:** [List Campaigns](https://run.emailchaser.com/api-reference/campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Filter campaigns by status. |
| `folderId` | query | `number` | no | Filter campaigns by folder ID. |
