# Get Pix Charge with eGestor

Retrieves details for a Pix charge from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/pix/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Pix Charge](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L4839)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do Pix. |
