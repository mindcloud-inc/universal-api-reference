# Delete Service with eGestor

Deletes an existing service from eGestor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/servicos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Delete Service](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L1536)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do serviço. |
