# Get Contact with eGestor

Retrieves details for a contact from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/contatos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Contact](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L384)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do contato. |
