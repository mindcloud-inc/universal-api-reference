# Get Payable with eGestor

Retrieves details for a payable from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/pagamentos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Payable](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L2882)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `codigo` | path | `number` | yes |
