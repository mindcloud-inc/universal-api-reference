# Get Service with eGestor

Retrieves details for a service from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/servicos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Service](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L1416)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do serviço. |
