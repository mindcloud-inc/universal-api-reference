# Get Purchase with eGestor

Retrieves details for a purchase from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/compras/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Purchase](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L3284)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código da compra. |
