# Delete Contact with eGestor

Deletes an existing contact from eGestor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contatos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Delete Contact](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L582)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do contato. |
