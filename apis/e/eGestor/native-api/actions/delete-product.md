# Delete Product with eGestor

Deletes an existing product from eGestor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/produtos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Delete Product](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L1094)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do produto. |
