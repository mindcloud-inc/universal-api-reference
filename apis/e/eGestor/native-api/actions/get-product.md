# Get Product with eGestor

Retrieves details for a product from eGestor.

## Endpoint

- **Method:** `GET`
- **Path:** `/produtos/:codigo`
- **Base URL:** `https://api.egestor.com.br/api/v1`
- **Official documentation:** [Get Product](https://github.com/eGestor/documentacao-api/blob/master/apiary.apib#L946)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `codigo` | path | `number` | yes | Código do produto. |
