# List Transactions with Escrow.com

Retrieves transaction records from Escrow.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction`
- **Base URL:** `https://api.escrow-sandbox.com/2017-09-01`
- **Official documentation:** [List Transactions](https://www.escrow.com/api/docs/reference)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
