# List Shipments with Easyship

Retrieves a list of shipments from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [List Shipments](https://developers.easyship.com/reference/shipments_index)
