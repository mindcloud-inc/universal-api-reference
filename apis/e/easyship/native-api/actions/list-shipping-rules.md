# List Shipping Rules with Easyship

Retrieves a list of shipping rules from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping_rules`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [List Shipping Rules](https://developers.easyship.com/reference/shipping_rules_index)
