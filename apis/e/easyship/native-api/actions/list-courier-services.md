# List Courier Services with Easyship

Retrieves a list of courier services from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/courier_services`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [List Courier Services](https://developers.easyship.com/reference/courier_services_index)
