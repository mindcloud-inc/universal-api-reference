# List Shipment Trackings with Easyship

Retrieves shipment tracking history from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/trackings`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [List Shipment Trackings](https://developers.easyship.com/reference/shipments_trackings_index)
