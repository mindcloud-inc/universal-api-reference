# Get Shipment with Easyship

Retrieves a shipment from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:shipment_id`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [Get Shipment](https://developers.easyship.com/reference/shipments_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipment_id` | path | `string` | yes | The Easyship shipment ID. |
