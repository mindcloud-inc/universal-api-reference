# Get Shipping Rule with Easyship

Retrieves a shipping rule from Easyship.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipping_rules/:shipping_rule_id`
- **Base URL:** `https://public-api.easyship.com/2024-09`
- **Official documentation:** [Get Shipping Rule](https://developers.easyship.com/reference/shipping_rules_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipping_rule_id` | path | `string` | yes | The Easyship shipping rule ID. |
