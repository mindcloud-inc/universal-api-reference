# AI Process Credit Card with Encodian - General

Extracts credit card data from images with Encodian AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/General/AIProcessCreditCard`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [AI Process Credit Card](https://support.encodian.com/hc/en-gb/articles/19807871170460)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `string` | yes | Base64-encoded source file content. |
