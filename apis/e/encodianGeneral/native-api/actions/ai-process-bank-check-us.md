# AI Process Bank Check US with Encodian - General

Extracts US bank check data with Encodian AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/General/AIProcessBankCheckUS`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [AI Process Bank Check US](https://support.encodian.com/hc/en-gb/articles/19806562595484)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `string` | yes | Base64-encoded source file content. |
