# AI Process Bank Statement US with Encodian - General

Extracts US bank statement data with Encodian AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/General/AIProcessBankStatementUS`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [AI Process Bank Statement US](https://support.encodian.com/hc/en-gb/articles/19807728511516)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `string` | yes | Base64-encoded source file content. |
