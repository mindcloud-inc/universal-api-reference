# Subscription Flowr And Vertr Status with Encodian - General

Retrieves Flowr and Vertr subscription status from Encodian.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/General/GetSubscriptionStatus`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [Subscription Flowr And Vertr Status](https://support.encodian.com/hc/en-gb/articles/360010176717-Get-Subscription-Status)
