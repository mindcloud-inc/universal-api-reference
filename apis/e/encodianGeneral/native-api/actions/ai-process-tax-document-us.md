# AI Process Tax Document US with Encodian - General

Extracts US tax document data with Encodian AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/General/AIProcessTaxUS`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [AI Process Tax Document US](https://support.encodian.com/hc/en-gb/articles/19808162127644)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `string` | yes | Base64-encoded source file content. |
