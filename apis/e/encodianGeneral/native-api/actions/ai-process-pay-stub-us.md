# AI Process Pay Stub US with Encodian - General

Extracts US pay stub data with Encodian AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/General/AIProcessPayStubUS`
- **Base URL:** `https://api.apps-encodian.com`
- **Official documentation:** [AI Process Pay Stub US](https://support.encodian.com/hc/en-gb/articles/19808015461916)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileContent` | body | `string` | yes | Base64-encoded source file content. |
