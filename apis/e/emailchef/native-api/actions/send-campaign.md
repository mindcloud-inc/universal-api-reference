# Send Campaign with Emailchef

Sends a campaign in Emailchef.

## Endpoint

- **Method:** `PUT`
- **Path:** `campaigns/:id/send`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Send Campaign](https://emailchef.com/integration/#/Campaigns/sendCampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Emailchef campaign ID. |
