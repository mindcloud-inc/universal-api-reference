# Get Contact with Emailchef

Retrieves a contact from Emailchef.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts/:contact_id`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Get Contact](https://emailchef.com/integration/#/Contacts/getContact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The Emailchef contact ID. |
| `list_id` | query | `string` | yes | — |
