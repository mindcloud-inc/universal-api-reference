# Delete List with Emailchef

Deletes an existing mailing list from Emailchef.

## Endpoint

- **Method:** `DELETE`
- **Path:** `lists/:list_id`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Delete List](https://emailchef.com/integration/#/Lists/deleteList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | The Emailchef list ID. |
