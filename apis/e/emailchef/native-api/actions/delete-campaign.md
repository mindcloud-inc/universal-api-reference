# Delete Campaign with Emailchef

Deletes an existing campaign from Emailchef.

## Endpoint

- **Method:** `DELETE`
- **Path:** `campaigns/:id`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Delete Campaign](https://emailchef.com/integration/#/Campaigns/deleteCampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Emailchef campaign ID. |
