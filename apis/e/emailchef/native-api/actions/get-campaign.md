# Get Campaign with Emailchef

Retrieves a campaign from Emailchef.

## Endpoint

- **Method:** `GET`
- **Path:** `campaigns/:id`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Get Campaign](https://emailchef.com/integration/#/Campaigns/getCampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Emailchef campaign ID. |
