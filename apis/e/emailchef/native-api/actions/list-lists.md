# List Lists with Emailchef

Retrieves all mailing lists from Emailchef.

## Endpoint

- **Method:** `GET`
- **Path:** `lists`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [List Lists](https://emailchef.com/integration/#/Lists/getLists)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
