# Get List with Emailchef

Retrieves a mailing list from Emailchef.

## Endpoint

- **Method:** `GET`
- **Path:** `lists/:list_id`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Get List](https://emailchef.com/integration/#/Lists/getList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | The Emailchef list ID. |
