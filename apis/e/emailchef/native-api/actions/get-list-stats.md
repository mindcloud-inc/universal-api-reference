# Get List Stats with Emailchef

Retrieves mailing list statistics from Emailchef.

## Endpoint

- **Method:** `GET`
- **Path:** `lists/:list_id/stats`
- **Base URL:** `https://app.emailchef.com/apps/api/v1`
- **Official documentation:** [Get List Stats](https://emailchef.com/integration/#/Lists/getListStats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | The Emailchef list ID. |
