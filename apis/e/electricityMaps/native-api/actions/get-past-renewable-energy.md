# Get Past Renewable Energy with Electricity Maps

## Endpoint

- **Method:** `GET`
- **Path:** `/renewable-energy/past`
- **Base URL:** `https://api.electricitymaps.com/v4`
- **Official documentation:** [Get Past Renewable Energy](https://app.electricitymaps.com/developer-hub/api/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `zone` | query | `string` | yes |
| `datetime` | query | `string` | yes |
