# Get Updated Since with Electricity Maps

## Endpoint

- **Method:** `GET`
- **Path:** `/updated-since`
- **Base URL:** `https://api.electricitymaps.com/v4`
- **Official documentation:** [Get Updated Since](https://app.electricitymaps.com/developer-hub/api/reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `zone` | query | `string` | yes |
| `since` | query | `string` | yes |
| `start` | query | `string` | yes |
| `end` | query | `string` | yes |
