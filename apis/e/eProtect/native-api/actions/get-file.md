# Get File with 3E Protect

Retrieves a file from the https://3eonline.com/ImageServer/ImageViewer.aspx URL

## Endpoint

- **Method:** `GET`
- **URL:** `https://3eonline.com/ImageServer/ImageViewer.aspx`
- **API:** rest

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `*/*` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The id to be added to the image URL. E.g. https://3eonline.com/ImageServer/ImageViewer.aspx?id={id} |
