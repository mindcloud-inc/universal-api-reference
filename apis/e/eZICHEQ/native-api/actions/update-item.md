# Update Item with EZICHEQ

Updates an item in EZICHEQ.

## Endpoint

- **Method:** `PUT`
- **Path:** `/item/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Update Item](https://developer.ezicheq.com/docs/endpoints)
