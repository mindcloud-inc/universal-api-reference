# Get Check with EZICHEQ

Retrieves a certified check from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/check/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Check](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `id` | path | `string` | no |
