# Delete Webhook with EZICHEQ

Deletes a webhook from EZICHEQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Delete Webhook](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
