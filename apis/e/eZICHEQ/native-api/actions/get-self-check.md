# Get Self Check with EZICHEQ

Retrieves a self check from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/selfcheck/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Self Check](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
