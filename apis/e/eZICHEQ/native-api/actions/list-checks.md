# List Checks with EZICHEQ

Retrieves certified checks from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/check/v1`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [List Checks](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `after` | query | `date` | no |
| `after` | query | `string` | no |
| `created_after` | query | `string` | no |
| `page` | query | `string` | no |
| `created_after` | query | `date` | no |
| `page` | query | `number` | no |
