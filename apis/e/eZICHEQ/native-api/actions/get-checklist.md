# Get Checklist with EZICHEQ

Retrieves a checklist from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/checklist/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Checklist](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `id` | path | `string` | no |
