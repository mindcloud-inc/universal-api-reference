# List Items with EZICHEQ

Retrieves items from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/item/v1`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [List Items](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `after` | query | `date` | no |
| `after` | query | `string` | no |
| `created_after` | query | `string` | no |
| `page` | query | `string` | no |
| `created_after` | query | `date` | no |
| `page` | query | `number` | no |
