# Get User with EZICHEQ

Retrieves a user from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/v1/:username`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get User](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `username` | path | `string` | yes |
