# Get Label with EZICHEQ

Retrieves a label from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/label/v1/:labelNumber`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Label](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `label_number` | path | `string` | yes |
| `label_number` | path | `string` | no |
