# Get Webhook with EZICHEQ

Retrieves a webhook from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Webhook](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
