# Get Item Type with EZICHEQ

Retrieves an item type from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/item_type/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Get Item Type](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `id` | path | `string` | no |
