# List Self Checks with EZICHEQ

Retrieves self checks from EZICHEQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/selfcheck/v1`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [List Self Checks](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `after` | query | `date` | no |
| `created_after` | query | `date` | no |
| `page` | query | `number` | no |
