# Delete Item with EZICHEQ

Deletes an item from EZICHEQ.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/item/v1/:id`
- **Base URL:** `https://api.ezicheq.com`
- **Official documentation:** [Delete Item](https://developer.ezicheq.com/docs/endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `id` | path | `string` | no |
