# Get Credit Balance with Enrich.so

Retrieves credit balance from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallets/balance`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Get Credit Balance](https://doc.enrich.so/get-your-credit-balance-27483207e0.md)
