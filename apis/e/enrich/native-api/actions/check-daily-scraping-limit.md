# Check Daily Scraping Limit with Enrich.so

Retrieves daily scraping limits from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/company-follower/limit`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Check Daily Scraping Limit](https://doc.enrich.so/check-daily-scraping-limit-27814759e0.md)
