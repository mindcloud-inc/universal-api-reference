# List Reveal Or Enrich Jobs with Enrich.so

Retrieves reveal or enrich jobs from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead-finder/reveal-jobs`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [List Reveal Or Enrich Jobs](https://doc.enrich.so/list-revealenrich-jobs-29163792e0.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional job status filter. |
