# List Team Members with Enrich.so

Retrieves team members from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{teamId}/members`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [List Team Members](https://doc.enrich.so/list-team-members-27483209e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Enrich team ID. |
