# Get Filter Options with Enrich.so

Retrieves lead filter options from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead-finder/filter-options`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Get Filter Options](https://doc.enrich.so/get-filter-options-28165862e0.md)
