# Look Up a Professional Profile by Email with Enrich.so

Retrieves a professional profile by email from Enrich.so.

## Endpoint

- **Method:** `POST`
- **Path:** `/reverse-lookup/lookup`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Look Up a Professional Profile by Email](https://doc.enrich.so/look-up-a-professional-profile-by-email-27483203e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to look up. |
