# Validate a Single Email with Enrich.so

Validates an email address in Enrich.so.

## Endpoint

- **Method:** `POST`
- **Path:** `/email-validation`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Validate a Single Email](https://doc.enrich.so/validate-a-single-email-27483191e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to validate. |
