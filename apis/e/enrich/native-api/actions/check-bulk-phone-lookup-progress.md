# Check Bulk Phone Lookup Progress with Enrich.so

Retrieves bulk phone lookup progress from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/reverse-lookup/phones/bulk/{jobId}`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Check Bulk Phone Lookup Progress](https://doc.enrich.so/check-bulk-phone-lookup-progress-27483201e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Bulk phone lookup job ID. |
