# Get Bulk Phone Lookup Results with Enrich.so

Retrieves bulk phone lookup results from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/reverse-lookup/phones/bulk/{jobId}/results`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [Get Bulk Phone Lookup Results](https://doc.enrich.so/get-bulk-phone-lookup-results-27483202e0.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Bulk phone lookup job ID. |
