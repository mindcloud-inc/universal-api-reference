# List Pending Invitations with Enrich.so

Retrieves pending team invitations from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/{teamId}/invitations`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [List Pending Invitations](https://doc.enrich.so/list-pending-invitations-27483211e0.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | Enrich team ID. |
