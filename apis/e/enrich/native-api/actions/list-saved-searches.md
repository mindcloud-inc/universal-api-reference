# List Saved Searches with Enrich.so

Retrieves saved searches from Enrich.so.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead-finder/saved`
- **Base URL:** `https://dev.enrich.so/api/v3`
- **Official documentation:** [List Saved Searches](https://doc.enrich.so/list-saved-searches-28165859e0.md)
