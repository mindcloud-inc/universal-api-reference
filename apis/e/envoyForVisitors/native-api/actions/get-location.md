# Get Location with Envoy for Visitors

Retrieves a location from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Location](https://developers.envoy.com/hub/reference/location)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
