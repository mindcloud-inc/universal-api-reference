# Get Recurring Invite with Envoy for Visitors

Retrieves a recurring invite from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/recurring-invites/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Recurring Invite](https://developers.envoy.com/hub/reference/recurringinvite)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
