# Get Entry with Envoy for Visitors

Retrieves an entry from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/entries/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Entry](https://developers.envoy.com/hub/reference/entry)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
