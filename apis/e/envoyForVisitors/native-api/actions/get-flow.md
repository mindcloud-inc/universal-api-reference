# Get Flow with Envoy for Visitors

Retrieves a flow from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/flows/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Flow](https://developers.envoy.com/hub/reference/flow)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
