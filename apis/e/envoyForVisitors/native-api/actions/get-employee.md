# Get Employee with Envoy for Visitors

Retrieves an employee from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Employee](https://developers.envoy.com/hub/reference/employee)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
