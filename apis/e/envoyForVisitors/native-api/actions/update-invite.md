# Update Invite with Envoy for Visitors

Updates an existing invite in Envoy for Visitors.

## Endpoint

- **Method:** `POST`
- **Path:** `/invites/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Update Invite](https://developers.envoy.com/hub/reference/updateinvite)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
