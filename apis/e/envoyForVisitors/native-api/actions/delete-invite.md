# Delete Invite with Envoy for Visitors

Deletes an existing invite from Envoy for Visitors.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/invites/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Delete Invite](https://developers.envoy.com/hub/reference/deleteinvite)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
