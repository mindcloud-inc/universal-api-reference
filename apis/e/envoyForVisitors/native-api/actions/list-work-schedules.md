# List Work Schedules with Envoy for Visitors

Retrieves work schedules from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/work-schedules`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [List Work Schedules](https://developers.envoy.com/hub/reference/workschedules-1)
