# Update Recurring Invite with Envoy for Visitors

Updates an existing recurring invite in Envoy for Visitors.

## Endpoint

- **Method:** `POST`
- **Path:** `/recurring-invites/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Update Recurring Invite](https://developers.envoy.com/hub/reference/updaterecurringinvite)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
