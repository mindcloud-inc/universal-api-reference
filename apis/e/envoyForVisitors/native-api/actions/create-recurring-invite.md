# Create Recurring Invite with Envoy for Visitors

Creates a new recurring invite in Envoy for Visitors.

## Endpoint

- **Method:** `POST`
- **Path:** `/recurring-invites`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Create Recurring Invite](https://developers.envoy.com/hub/reference/createrecurringinvite)
