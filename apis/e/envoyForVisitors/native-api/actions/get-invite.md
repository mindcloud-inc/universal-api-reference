# Get Invite with Envoy for Visitors

Retrieves an invite from Envoy for Visitors.

## Endpoint

- **Method:** `GET`
- **Path:** `/invites/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Get Invite](https://developers.envoy.com/hub/reference/invite)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
