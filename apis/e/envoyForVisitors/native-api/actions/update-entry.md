# Update Entry with Envoy for Visitors

Updates an existing entry in Envoy for Visitors.

## Endpoint

- **Method:** `POST`
- **Path:** `/entries/:id`
- **Base URL:** `https://api.envoy.com/v1`
- **Official documentation:** [Update Entry](https://developers.envoy.com/hub/reference/updateentry)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
