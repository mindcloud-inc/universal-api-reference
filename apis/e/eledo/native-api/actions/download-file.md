# Download File with Eledo

Downloads a PDF file from Eledo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Download/:file_id`
- **Base URL:** `https://eledo.online/api/RESTv1`
- **Official documentation:** [Download File](https://eledo.online/documentation/api_reference/download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
