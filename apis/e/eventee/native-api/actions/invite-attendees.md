# Invite Attendees with Eventee

Creates attendee invitations in Eventee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/attendee/invite`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Invite Attendees](https://publiceventeeapi.docs.apiary.io/#reference/participants/invite-attendees/invite)
