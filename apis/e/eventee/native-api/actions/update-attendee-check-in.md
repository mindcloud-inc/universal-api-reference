# Update Attendee Check-In with Eventee

Updates attendee check-in status in Eventee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/attendee/{id}/checkin`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Attendee Check-In](https://publiceventeeapi.docs.apiary.io/#reference/participants/update-check-in/update-check-in)
