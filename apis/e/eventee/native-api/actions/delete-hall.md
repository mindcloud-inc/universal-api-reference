# Delete Hall with Eventee

Deletes an existing hall from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hall/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Hall](https://publiceventeeapi.docs.apiary.io/#reference/halls/update-or-delete-hall/delete)
