# Update Hall with Eventee

Updates an existing hall in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/hall/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Hall](https://publiceventeeapi.docs.apiary.io/#reference/halls/update-or-delete-hall/update)
