# Delete Attendee with Eventee

Deletes an attendee from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attendee`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Attendee](https://publiceventeeapi.docs.apiary.io/#reference/participants/remove-attendee/remove)
