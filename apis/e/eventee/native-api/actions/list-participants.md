# List Participants with Eventee

Retrieves participants from Eventee.

## Endpoint

- **Method:** `GET`
- **Path:** `/participants`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [List Participants](https://publiceventeeapi.docs.apiary.io/#reference/participants/get-all-participants/get-all)
