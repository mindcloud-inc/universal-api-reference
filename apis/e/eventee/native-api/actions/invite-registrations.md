# Invite Registrations with Eventee

Creates registration invitations in Eventee.

## Endpoint

- **Method:** `PUT`
- **Path:** `/registration/invite`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Invite Registrations](https://publiceventeeapi.docs.apiary.io/#reference/registrations/invite-registrations/invite)
