# Update Track with Eventee

Updates an existing track in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/label/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Track](https://publiceventeeapi.docs.apiary.io/#reference/tracks/update-or-delete-track/update)
