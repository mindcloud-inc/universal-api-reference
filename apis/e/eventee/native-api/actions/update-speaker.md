# Update Speaker with Eventee

Updates an existing speaker in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/speaker/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Speaker](https://publiceventeeapi.docs.apiary.io/#reference/speakers/update-or-delete-speaker/update)
