# Update Partner with Eventee

Updates an existing partner in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/partner/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Partner](https://publiceventeeapi.docs.apiary.io/#reference/partners/update-or-delete-partner/update)
