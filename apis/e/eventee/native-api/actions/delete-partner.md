# Delete Partner with Eventee

Deletes an existing partner from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/partner/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Partner](https://publiceventeeapi.docs.apiary.io/#reference/partners/update-or-delete-partner/delete)
