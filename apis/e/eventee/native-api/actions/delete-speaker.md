# Delete Speaker with Eventee

Deletes an existing speaker from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/speaker/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Speaker](https://publiceventeeapi.docs.apiary.io/#reference/speakers/update-or-delete-speaker/delete)
