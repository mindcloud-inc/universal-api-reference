# Update Lecture with Eventee

Updates an existing lecture in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/lecture/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Lecture](https://publiceventeeapi.docs.apiary.io/#reference/lectures/update-or-delete-lecture/update)
