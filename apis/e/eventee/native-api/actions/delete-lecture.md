# Delete Lecture with Eventee

Deletes an existing lecture from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lecture/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Lecture](https://publiceventeeapi.docs.apiary.io/#reference/lectures/update-or-delete-lecture/delete)
