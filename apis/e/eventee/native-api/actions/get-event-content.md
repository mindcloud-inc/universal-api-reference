# Get Event Content with Eventee

Retrieves event content from Eventee.

## Endpoint

- **Method:** `GET`
- **Path:** `/content`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Get Event Content](https://publiceventeeapi.docs.apiary.io/#reference/content/get-all-content/get)
