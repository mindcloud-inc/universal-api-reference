# Update Pause with Eventee

Updates an existing pause in Eventee.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/pause/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Update Pause](https://publiceventeeapi.docs.apiary.io/#reference/pauses/update-or-delete-pause/update)
