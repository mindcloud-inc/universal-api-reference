# Delete Pause with Eventee

Deletes an existing pause from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pause/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Pause](https://publiceventeeapi.docs.apiary.io/#reference/pauses/update-or-delete-pause/delete)
