# List Registrations with Eventee

Retrieves registrations from Eventee.

## Endpoint

- **Method:** `GET`
- **Path:** `/registrations`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [List Registrations](https://publiceventeeapi.docs.apiary.io/#reference/registrations/get-all-registrations/get-all)
