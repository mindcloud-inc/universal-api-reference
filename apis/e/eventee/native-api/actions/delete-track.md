# Delete Track with Eventee

Deletes an existing track from Eventee.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/label/{id}`
- **Base URL:** `https://api.eventee.com/public/v1`
- **Official documentation:** [Delete Track](https://publiceventeeapi.docs.apiary.io/#reference/tracks/update-or-delete-track/delete)
