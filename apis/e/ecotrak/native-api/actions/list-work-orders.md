# List Work Orders with Ecotrak

Retrieves work orders updated today from Ecotrak.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workorders`
- **Base URL:** `https://api.ecotrak.com`
- **Official documentation:** [List Work Orders](https://documenter.getpostman.com/view/19394488/2sAYk8u3FF#customer-work-order-work-orders)
