# List Users with Ecotrak

Retrieves a list of users from Ecotrak.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/user`
- **Base URL:** `https://api.ecotrak.com`
- **Official documentation:** [List Users](https://api-docs.ecotrak.com/#d030c2de-800e-438b-b1a5-8d651045c202)

## Capabilities

This operation supports [pagination](../README.md#pagination).
