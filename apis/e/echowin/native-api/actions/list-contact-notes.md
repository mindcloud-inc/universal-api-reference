# List Contact Notes with echowin

Retrieves contact notes from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/notes`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [List Contact Notes](https://echo.win/api-docs/contacts#list-notes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
