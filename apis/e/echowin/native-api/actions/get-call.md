# Get Call with echowin

Retrieves a call from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:callId`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Get Call](https://echo.win/api-docs/calls#get-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
