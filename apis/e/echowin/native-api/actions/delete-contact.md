# Delete Contact with echowin

Deletes a contact from echowin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Delete Contact](https://echo.win/api-docs/contacts#delete-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
