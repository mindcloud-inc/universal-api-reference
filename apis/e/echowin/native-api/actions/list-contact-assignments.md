# List Contact Assignments with echowin

Retrieves contact assignments from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/assignments`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [List Contact Assignments](https://echo.win/api-docs/contacts#list-assignments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
