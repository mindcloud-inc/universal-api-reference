# Get Contact with echowin

Retrieves a contact from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Get Contact](https://echo.win/api-docs/contacts#get-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
