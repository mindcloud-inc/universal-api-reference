# Get Agent Instructions with echowin

Retrieves agent instructions from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId/instructions`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Get Agent Instructions](https://echo.win/api-docs/agents#get-instructions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
