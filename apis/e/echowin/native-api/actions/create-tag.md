# Create Tag with echowin

Creates a tag in echowin.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Create Tag](https://echo.win/api-docs/contacts#create-tag)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `color` | body | `string` | no |
