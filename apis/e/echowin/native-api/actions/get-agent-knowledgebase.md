# Get Agent Knowledgebase with echowin

Retrieves an agent knowledge base from echowin.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId/knowledgebase`
- **Base URL:** `https://echo.win/api/v1`
- **Official documentation:** [Get Agent Knowledgebase](https://echo.win/api-docs/knowledgebase#agent-knowledgebase)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
