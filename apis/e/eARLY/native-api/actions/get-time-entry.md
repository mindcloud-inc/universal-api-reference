# Get Time Entry with EARLY

Retrieves a time entry from EARLY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Time Entry](https://developers.early.app/#73ff0de6-42ba-4386-986c-5f83f7ef1372)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes | Time entry ID. |
