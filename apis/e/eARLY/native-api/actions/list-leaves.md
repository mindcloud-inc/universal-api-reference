# List Leaves with EARLY

Retrieves leaves from EARLY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/leaves`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List Leaves](https://developers.early.app/#1b9995fe-89e4-41aa-9e74-cbb41e360eb3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `start` | query | `string` | yes | Range start date in YYYY-MM-DD format. |
| `end` | query | `string` | yes | Range end date in YYYY-MM-DD format. |
