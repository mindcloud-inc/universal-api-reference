# Get Folder Member with EARLY

Retrieves a folder member from EARLY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/folders/:folderId/members/:memberId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Folder Member](https://developers.early.app/#20a5dd57-d697-4d85-ad19-04b47a500eee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Folder ID. |
| `memberId` | path | `string` | yes | Folder member ID. |
