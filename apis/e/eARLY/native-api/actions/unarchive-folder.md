# Unarchive Folder with EARLY

Unarchives a folder in EARLY.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/folders/:folderId/unarchive`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Unarchive Folder](https://developers.early.app/#c71538c6-d899-48ef-a38b-3c5a8c2699f4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Folder ID. |
