# Get Current Tracking with EARLY

Retrieves the current tracking session from EARLY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/tracking`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Get Current Tracking](https://developers.early.app/#2ff32590-05f3-42f4-91dc-df6b6e32c135)
