# Archive Activity with EARLY

Archives an activity in EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/activities/:activityId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Archive Activity](https://developers.early.app/#be926b1a-5aaa-403f-b8b0-576b8772538f)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | path | `string` | yes | Activity ID. |
