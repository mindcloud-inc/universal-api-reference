# Delete Leave with EARLY

Deletes a leave from EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/leaves/:leaveId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Leave](https://developers.early.app/#f7989f80-9e76-4838-a273-dc31fd0e7288)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leaveId` | path | `string` | yes | Leave ID. |
