# Unarchive Activity with EARLY

Unarchives an activity in EARLY.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/activities/:activityId/unarchive`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Unarchive Activity](https://developers.early.app/#6f5b8cb5-dc7a-4258-a855-3d160203a893)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | path | `string` | yes | Archived activity ID. |
