# Deny Leave with EARLY

Denies a leave in EARLY.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/leaves/:leaveId/deny`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Deny Leave](https://developers.early.app/#e4256be7-7d98-4f32-a0ed-2cb26c551074)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leaveId` | path | `string` | yes | Leave ID. |
