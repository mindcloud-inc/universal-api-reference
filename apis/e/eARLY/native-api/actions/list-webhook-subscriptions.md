# List Webhook Subscriptions with EARLY

Retrieves webhook subscriptions from EARLY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v4/webhooks/subscription`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [List Webhook Subscriptions](https://developers.early.app/#f6353878-4147-462e-b702-a3fc97a0926f)
