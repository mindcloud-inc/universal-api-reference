# Delete Webhook Subscription with EARLY

Deletes a webhook subscription from EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/webhooks/subscription/:subscriptionId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Webhook Subscription](https://developers.early.app/#ad4c3dd7-bb28-447f-a6bc-147928d230e4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscriptionId` | path | `string` | yes | Webhook subscription ID. |
