# Delete Time Entry with EARLY

Deletes a time entry from EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/time-entries/:timeEntryId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Time Entry](https://developers.early.app/#ad0986b6-aae6-4b25-acc2-333b6822b6e6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timeEntryId` | path | `string` | yes | Time entry ID. |
