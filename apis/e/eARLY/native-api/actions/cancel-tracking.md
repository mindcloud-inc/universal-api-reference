# Cancel Tracking with EARLY

Cancels the current tracking session in EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/tracking`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Cancel Tracking](https://developers.early.app/#344a5b26-cbf5-49a7-a7f1-0bbfe4b03766)
