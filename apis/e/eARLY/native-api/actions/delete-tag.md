# Delete Tag with EARLY

Deletes a tag from EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/tags/:tagId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Tag](https://developers.early.app/#ac8eba90-6107-46c4-89e3-7babdaeefc9d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | Tag ID. |
