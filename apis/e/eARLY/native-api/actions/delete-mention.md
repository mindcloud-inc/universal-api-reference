# Delete Mention with EARLY

Deletes a mention from EARLY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v4/mentions/:mentionId`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Delete Mention](https://developers.early.app/#27d62d2f-97f0-49bf-bfa5-e7292ff1d421)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mentionId` | path | `string` | yes | Mention ID. |
