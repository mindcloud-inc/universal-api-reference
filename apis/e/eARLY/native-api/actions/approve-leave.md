# Approve Leave with EARLY

Approves a leave in EARLY.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v4/leaves/:leaveId/approve`
- **Base URL:** `https://api.early.app`
- **Official documentation:** [Approve Leave](https://developers.early.app/#cdcda8e5-030d-42e7-8dee-84c4954a589a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leaveId` | path | `string` | yes | Leave ID. |
