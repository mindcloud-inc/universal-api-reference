# Generate Blank CSV with Eversign

Downloads a blank bulk-send CSV from Eversign.

## Endpoint

- **Method:** `GET`
- **Path:** `/template/:templateHash/bulk/csv/blank`
- **Base URL:** `https://api.eversign.com`
- **Official documentation:** [Generate Blank CSV](https://eversign.com/api/documentation/methods)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `templateHash` | path | `string` | yes |
