# Get Template with Eversign

Retrieves a template from Eversign by hash.

## Endpoint

- **Method:** `GET`
- **Path:** `/document`
- **Base URL:** `https://api.eversign.com`
- **Official documentation:** [Get Template](https://eversign.com/api/documentation/methods)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_hash` | query | `string` | yes |
