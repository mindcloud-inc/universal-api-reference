# Download Document PDF with Eversign

Downloads a document PDF from Eversign.

## Endpoint

- **Method:** `GET`
- **Path:** `/download_raw_document`
- **Base URL:** `https://api.eversign.com`
- **Official documentation:** [Download Document PDF](https://eversign.com/api/documentation/methods)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_hash` | query | `string` | yes |
