# List Questionnaire Webhooks with Evalandgo

Retrieves webhooks for a questionnaire from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/questionnaires/:questionnaireId/webhooks`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [List Questionnaire Webhooks](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1questionnaires~1{questionnaireId}~1webhooks/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `questionnaireId` | path | `string` | yes |
