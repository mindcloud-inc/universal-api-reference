# Retrieve Contact with Evalandgo

Retrieves a contact from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/contacts/:id`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Retrieve Contact](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1contacts~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact identifier |
