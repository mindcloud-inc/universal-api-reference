# Retrieve Questionnaire with Evalandgo

Retrieves a questionnaire from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/questionnaires/:id`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Retrieve Questionnaire](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1questionnaires~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Questionnaire identifier |
