# Create Contact with Evalandgo

Creates a new contact in Evalandgo.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/contacts`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Create Contact](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1contacts/post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
| `firstName` | body | `string` | no |
| `lastName` | body | `string` | no |
| `phone` | body | `string` | no |
| `username` | body | `string` | no |
| `password` | body | `string` | no |
