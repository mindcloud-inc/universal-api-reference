# Retrieve Group with Evalandgo

Retrieves a group from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/groups/:id`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Retrieve Group](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1groups~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group identifier |
