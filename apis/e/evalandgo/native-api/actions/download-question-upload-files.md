# Download Question Upload Files with Evalandgo

Retrieves uploaded files for a question from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/questions/upload/:id/download`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Download Question Upload Files](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1questions~1upload~1{id}~1download/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
