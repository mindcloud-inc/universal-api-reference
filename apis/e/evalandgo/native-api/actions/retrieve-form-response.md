# Retrieve Form Response with Evalandgo

Retrieves a form response from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/responses/form/:id`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Retrieve Form Response](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1responses~1form~1{id}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
