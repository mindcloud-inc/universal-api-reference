# List Tags with Evalandgo

Retrieves tags from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/tags`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [List Tags](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1tags/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | no |
