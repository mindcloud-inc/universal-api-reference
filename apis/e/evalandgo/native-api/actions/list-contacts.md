# List Contacts with Evalandgo

Retrieves contacts from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/contacts`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [List Contacts](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1contacts/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | no |
| `username` | query | `string` | no |
| `firstName` | query | `string` | no |
| `lastName` | query | `string` | no |
| `phone` | query | `string` | no |
