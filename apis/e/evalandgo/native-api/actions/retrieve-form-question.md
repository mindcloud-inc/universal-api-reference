# Retrieve Form Question with Evalandgo

Retrieves a form question from Evalandgo.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/questions/form/:id`
- **Base URL:** `https://app.evalandgo.com`
- **Official documentation:** [Retrieve Form Question](https://app.evalandgo.com/api/docs/v3?format=json#/paths/~1api~1v3~1questions~1form~1{id}/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Question form identifier |
