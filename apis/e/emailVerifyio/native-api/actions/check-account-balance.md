# Check Account Balance with EmailVerify.io

Retrieves account balance details from EmailVerify.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/check-account-balance/`
- **Base URL:** `https://app.emailverify.io/api/v1`
- **Official documentation:** [Check Account Balance](https://www.emailverify.io/api/docs/#verifier)
