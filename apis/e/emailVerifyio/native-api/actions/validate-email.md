# Validate Email with EmailVerify.io

Validates an email address with EmailVerify.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate`
- **Base URL:** `https://app.emailverify.io/api/v1`
- **Official documentation:** [Validate Email](https://www.emailverify.io/api/docs/#verifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to validate with EmailVerify.io. |
