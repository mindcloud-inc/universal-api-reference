# Get Assignee with Ellipsend

Retrieves an assignee from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/assignee/[:assignee_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Assignee](https://api.ellipsend.com/v1/docs#/Assignee/get_assignee__assignee_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assignee_id` | path | `number` | yes | The assignee ID. |
