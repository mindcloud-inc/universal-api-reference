# Get Activity Type with Ellipsend

Retrieves an activity type from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.ellipsend.com/v1/activity-type/[:activity_type_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Activity Type](https://api.ellipsend.com/v1/docs#/Activity%20Type/get_v1_activity_type__activity_type_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity_type_id` | path | `number` | yes | The activity type ID. |
