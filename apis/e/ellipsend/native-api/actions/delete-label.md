# Delete Label with Ellipsend

Deletes an existing label from Ellipsend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/label/[:label_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Delete Label](https://api.ellipsend.com/v1/docs#/Label/delete_label__label_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label_id` | path | `number` | yes | The label ID. |
