# Get Activity with Ellipsend

Retrieves an activity from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.ellipsend.com/v1/activity/[:activity_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Activity](https://api.ellipsend.com/v1/docs#/Activity/get_v1_activity__activity_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity_id` | path | `string` | yes | The activity ID. |
