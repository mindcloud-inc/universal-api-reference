# Get Product with Ellipsend

Retrieves a product from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/[:product_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Product](https://api.ellipsend.com/v1/docs#/Product/get_v1_product__product_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | The product ID. |
