# Create Label with Ellipsend

Creates a new label in Ellipsend.

## Endpoint

- **Method:** `POST`
- **Path:** `/label`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Create Label](https://api.ellipsend.com/v1/docs#/Label/post_label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label` | body | `string` | yes | The label name to create. |
