# List Activity Types with Ellipsend

Retrieves activity types from Ellipsend.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.ellipsend.com/v1/activity-type`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [List Activity Types](https://api.ellipsend.com/v1/docs#/Activity%20Type/get_v1_activity_type)
