# Get Label with Ellipsend

Retrieves a label from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/label/[:label_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Label](https://api.ellipsend.com/v1/docs#/Label/get_label__label_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label_id` | path | `number` | yes | The label ID. |
