# Get Status with Ellipsend

Retrieves a status from Ellipsend by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/status/[:status_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Get Status](https://api.ellipsend.com/v1/docs#/Status/get_status__status_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status_id` | path | `number` | yes | The status ID. |
