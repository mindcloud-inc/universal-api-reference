# Delete Status with Ellipsend

Deletes an existing status from Ellipsend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/status/[:status_id]`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Delete Status](https://api.ellipsend.com/v1/docs#/Status/delete_status__status_id_)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status_id` | path | `number` | yes | The status ID. |
