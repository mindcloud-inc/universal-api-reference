# Create Status with Ellipsend

Creates a new status in Ellipsend.

## Endpoint

- **Method:** `POST`
- **Path:** `/status`
- **Base URL:** `https://api.ellipsend.com/v1`
- **Official documentation:** [Create Status](https://api.ellipsend.com/v1/docs#/Status/post_status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | body | `string` | yes | The status name to create. |
