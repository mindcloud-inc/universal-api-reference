# Get Nonprofit with Every.org

Retrieves details about a nonprofit from Every.org.

## Endpoint

- **Method:** `GET`
- **Path:** `/nonprofit/:identifier`
- **Base URL:** `https://partners.every.org/v0.2`
- **Official documentation:** [Get Nonprofit](https://docs.every.org/docs/endpoints/nonprofit-search#get-v02nonprofitidentifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | A nonprofit slug, EIN, or nonprofit ID. |
