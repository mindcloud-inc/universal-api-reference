# Verify Email Address with Email List Validation

## Endpoint

- **Method:** `GET`
- **Path:** `/api/verifEmail`
- **Base URL:** `https://app.emaillistvalidation.com`
- **Official documentation:** [Verify Email Address](https://help.emaillistvalidation.com/en/article/25-api-authentication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to verify. |
