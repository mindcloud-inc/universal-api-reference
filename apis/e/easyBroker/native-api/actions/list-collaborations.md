# List Collaborations with EasyBroker

Retrieves collaborations from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/collaborations`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Collaborations](https://dev.easybroker.com/reference/get_collaborations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
