# List Contact Requests with EasyBroker

Retrieves contact requests from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_requests`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Contact Requests](https://dev.easybroker.com/reference/get_contact-requests)

## Capabilities

This operation supports [pagination](../README.md#pagination).
