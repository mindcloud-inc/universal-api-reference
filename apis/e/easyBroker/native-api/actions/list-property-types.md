# List Property Types with EasyBroker

Retrieves property types from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/property_types`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Property Types](https://dev.easybroker.com/reference/get_property-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locale` | query | `string` | no | Locale for the returned property type names. |
