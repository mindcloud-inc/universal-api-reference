# List Agencies with EasyBroker

Retrieves active partner agencies from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration_partners/agencies`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Agencies](https://dev.easybroker.com/reference/get_agencies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
