# Retrieve Agent with EasyBroker

Retrieves an agent from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration_partners/agents/:agent_id`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [Retrieve Agent](https://dev.easybroker.com/reference/get_agents-agent-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | The EasyBroker agent ID. |
