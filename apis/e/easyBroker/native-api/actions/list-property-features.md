# List Property Features with EasyBroker

Retrieves property features from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/features`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Property Features](https://dev.easybroker.com/reference/get_features)

## Capabilities

This operation supports [pagination](../README.md#pagination).
