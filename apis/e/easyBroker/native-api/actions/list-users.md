# List Users with EasyBroker

Retrieves active users from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Users](https://dev.easybroker.com/reference/get_users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
