# List Property Listing Statuses with EasyBroker

Retrieves property listing statuses from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/listing_statuses`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Property Listing Statuses](https://dev.easybroker.com/reference/get_listing-statuses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
