# Retrieve Contact with EasyBroker

Retrieves a contact from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [Retrieve Contact](https://dev.easybroker.com/reference/get_contacts-contact-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | EasyBroker contact ID. |
