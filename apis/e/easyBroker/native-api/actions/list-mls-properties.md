# List MLS Properties with EasyBroker

Retrieves MLS properties from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/mls_properties`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List MLS Properties](https://dev.easybroker.com/reference/get_mls-properties)

## Capabilities

This operation supports [pagination](../README.md#pagination).
