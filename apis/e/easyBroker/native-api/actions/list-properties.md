# List Properties with EasyBroker

Retrieves properties from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Properties](https://dev.easybroker.com/reference/get_properties)

## Capabilities

This operation supports [pagination](../README.md#pagination).
