# Retrieve Property with EasyBroker

Retrieves a property from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/{property_id}`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [Retrieve Property](https://dev.easybroker.com/reference/get_properties-property-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `property_id` | path | `string` | yes | Internal or EasyBroker property ID. |
