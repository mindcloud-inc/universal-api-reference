# List Contacts with EasyBroker

Retrieves contacts from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [List Contacts](https://dev.easybroker.com/reference/get_contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
