# Retrieve Agency with EasyBroker

Retrieves a connected agency from EasyBroker.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration_partners/agencies/:agency_id`
- **Base URL:** `https://api.easybroker.com/v1`
- **Official documentation:** [Retrieve Agency](https://dev.easybroker.com/reference/get_agencies-agency-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agency_id` | path | `string` | yes | The EasyBroker agency ID. |
