# Get Webhook Event Sample with Eduzz

Retrieves a sample payload for an Eduzz webhook event.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/v1/origin/sample/:event`
- **Base URL:** `https://api.eduzz.com`
- **Official documentation:** [Get Webhook Event Sample](https://developers.eduzz.com/reference/api/get-webhook-v1-origin-sample-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event` | path | `string` | yes | Nome do evento. |
