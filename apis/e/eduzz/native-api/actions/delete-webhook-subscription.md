# Delete Webhook Subscription with Eduzz

Deletes an existing webhook subscription from Eduzz.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook/v1/subscription/:id`
- **Base URL:** `https://api.eduzz.com`
- **Official documentation:** [Delete Webhook Subscription](https://developers.eduzz.com/reference/api/delete-webhook-v1-subscription-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id da inscrição. |
