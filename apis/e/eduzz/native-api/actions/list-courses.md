# List Courses with Eduzz

Retrieves courses from Eduzz using the provided filters.

## Endpoint

- **Method:** `GET`
- **Path:** `/nutror/v1/courses`
- **Base URL:** `https://api.eduzz.com`
- **Official documentation:** [List Courses](https://developers.eduzz.com/reference/api/get-nutror-v1-courses)
