# List Products with Eduzz

Retrieves the producer's products from Eduzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/myeduzz/v1/products`
- **Base URL:** `https://api.eduzz.com`
- **Official documentation:** [List Products](https://developers.eduzz.com/reference/api/get-myeduzz-v1-products)

## Capabilities

This operation supports [pagination](../README.md#pagination).
