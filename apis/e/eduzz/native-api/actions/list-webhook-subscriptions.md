# List Webhook Subscriptions with Eduzz

Retrieves all webhook subscriptions from Eduzz.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/v1/subscription`
- **Base URL:** `https://api.eduzz.com`
- **Official documentation:** [List Webhook Subscriptions](https://developers.eduzz.com/reference/api/get-webhook-v1-subscription)
