# Delete Account with EnvelopeBudget

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/:budget_id/delete/:account_id`
- **Base URL:** `https://envelopebudget.com/api`
- **Official documentation:** [Delete Account](https://envelopebudget.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `budget_id` | path | `string` | yes |
| `account_id` | path | `string` | yes |
