# List Categories with EnvelopeBudget

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:budget_id`
- **Base URL:** `https://envelopebudget.com/api`
- **Official documentation:** [List Categories](https://envelopebudget.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `budget_id` | path | `string` | yes |
