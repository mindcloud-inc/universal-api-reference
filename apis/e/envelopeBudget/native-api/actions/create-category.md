# Create Category with EnvelopeBudget

## Endpoint

- **Method:** `POST`
- **Path:** `/categories/:budget_id`
- **Base URL:** `https://envelopebudget.com/api`
- **Official documentation:** [Create Category](https://envelopebudget.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `budget_id` | path | `string` | yes |
| `name` | body | `string` | yes |
