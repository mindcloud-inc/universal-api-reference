# Retrieve Reminder with Zoho Cliq

Retrieves a reminder from Zoho Cliq by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/reminders/:reminderId`
- **Base URL:** `https://cliq.zoho.com/api/v2`
- **Official documentation:** [Retrieve Reminder](https://www.zoho.com/cliq/help/restapi/v2/#get_reminder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reminderId` | path | `string` | yes | The ID of the reminder to retrieve. |
