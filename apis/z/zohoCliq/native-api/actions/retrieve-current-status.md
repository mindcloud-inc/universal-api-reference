# Retrieve Current Status with Zoho Cliq

Retrieves the current user status from Zoho Cliq.

## Endpoint

- **Method:** `GET`
- **Path:** `/statuses/current`
- **Base URL:** `https://cliq.zoho.com/api/v2`
- **Official documentation:** [Retrieve Current Status](https://www.zoho.com/cliq/help/restapi/v2/#retrieve-current-status)
