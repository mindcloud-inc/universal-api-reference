# Join Channel with Zoho Cliq

Joins a channel in Zoho Cliq.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/join`
- **Base URL:** `https://cliq.zoho.com/api/v2`
- **Official documentation:** [Join Channel](https://www.zoho.com/cliq/help/restapi/v2/#Channels_Join_a_Channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The ID of the channel to join. |
