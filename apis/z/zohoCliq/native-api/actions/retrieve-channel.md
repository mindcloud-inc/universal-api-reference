# Retrieve Channel with Zoho Cliq

Retrieves a channel from Zoho Cliq by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:channelId`
- **Base URL:** `https://cliq.zoho.com/api/v2`
- **Official documentation:** [Retrieve Channel](https://www.zoho.com/cliq/help/restapi/v2/#Channels_Retrieve_a_channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The ID of the channel to retrieve. |
