# Leave Channel with Zoho Cliq

Leaves a channel in Zoho Cliq.

## Endpoint

- **Method:** `POST`
- **Path:** `/channels/:channelId/leave`
- **Base URL:** `https://cliq.zoho.com/api/v2`
- **Official documentation:** [Leave Channel](https://www.zoho.com/cliq/help/restapi/v2/#Channels_Leave_a_Channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The ID of the channel to leave. |
