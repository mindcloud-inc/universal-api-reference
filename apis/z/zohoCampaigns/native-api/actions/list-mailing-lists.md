# List Mailing Lists with Zoho Campaigns

Retrieves mailing lists from Zoho Campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/getmailinglists`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [List Mailing Lists](https://www.zoho.com/campaigns/help/developers/get-mailing-lists.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort` | query | `list` | no | Sort direction for the returned mailing lists. Accepted values: `asc`, `desc`. |
