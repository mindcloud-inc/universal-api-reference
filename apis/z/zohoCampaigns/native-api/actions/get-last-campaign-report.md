# Get Last Campaign Report with Zoho Campaigns

Retrieves the last campaign report from Zoho Campaigns.

## Endpoint

- **Method:** `POST`
- **Path:** `/getlastcampaignreport`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [Get Last Campaign Report](https://www.zoho.com/campaigns/help/developers/last-campaign-report.html)
