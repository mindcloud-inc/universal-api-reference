# List Contact Fields with Zoho Campaigns

Retrieves all contact fields from Zoho Campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/allfields`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [List Contact Fields](https://www.zoho.com/campaigns/help/developers/get-contact-fields.html)
