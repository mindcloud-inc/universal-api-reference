# List Campaign Reports with Zoho Campaigns

Retrieves campaign reports from Zoho Campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaignreports`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [List Campaign Reports](https://www.zoho.com/campaigns/help/developers/campaign-reports.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignkey` | query | `string` | yes | Campaign key from a recent-campaign response. |
