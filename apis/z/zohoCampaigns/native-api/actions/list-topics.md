# List Topics with Zoho Campaigns

Retrieves marketing topics from Zoho Campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/topics`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [List Topics](https://www.zoho.com/campaigns/help/developers/get-topics.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `details` | query | `string` | no |
