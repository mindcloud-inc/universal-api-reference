# List Recently Sent Campaigns with Zoho Campaigns

Retrieves recently sent campaigns from Zoho Campaigns.

## Endpoint

- **Method:** `GET`
- **Path:** `/recentsentcampaigns`
- **Base URL:** `https://campaigns.zoho.com/api/v1.1`
- **Official documentation:** [List Recently Sent Campaigns](https://www.zoho.com/campaigns/help/developers/)
