# Get All Labels of the User with Zoho WorkDrive

Retrieves labels for a Zoho WorkDrive user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/:teamMemberId/labels`
- **Base URL:** `{api_domain}/workdrive`
- **Official documentation:** [Get All Labels of the User](https://workdrive.zoho.com/apidocs/v1/labels/getalllabelsoftheuser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamMemberId` | path | `string` | yes | The team member ID. |
