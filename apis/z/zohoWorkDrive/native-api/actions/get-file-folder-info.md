# Get File/Folder Info with Zoho WorkDrive

Retrieves file or folder details from Zoho WorkDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/files/:resourceId`
- **Base URL:** `{api_domain}/workdrive`
- **Official documentation:** [Get File/Folder Info](https://workdrive.zoho.com/apidocs/v1/filesfolders/getfilefolderinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | The file or folder resource ID. |
