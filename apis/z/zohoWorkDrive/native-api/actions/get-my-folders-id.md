# Get My Folders Id with Zoho WorkDrive

Retrieves private-space folder details from Zoho WorkDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/:teamMemberId/privatespace`
- **Base URL:** `{api_domain}/workdrive`
- **Official documentation:** [Get My Folders Id](https://workdrive.zoho.com/apidocs/v1/teammemberfiles/getmyfoldersid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamMemberId` | path | `string` | yes | The team member ID. |
