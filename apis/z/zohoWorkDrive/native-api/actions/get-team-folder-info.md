# Get Team Folder Info with Zoho WorkDrive

Retrieves team folder details from Zoho WorkDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/teamfolders/:teamfolderId`
- **Base URL:** `{api_domain}/workdrive`
- **Official documentation:** [Get Team Folder Info](https://workdrive.zoho.com/apidocs/v1/teamfolder/getteamfolderinfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamfolderId` | path | `string` | yes | The team folder ID. |
