# Get Team Info with Zoho WorkDrive

Retrieves team details from Zoho WorkDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/teams/:teamId`
- **Base URL:** `{api_domain}/workdrive`
- **Official documentation:** [Get Team Info](https://workdrive.zoho.com/apidocs/v1/teams/getteaminfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | The WorkDrive team ID. |
