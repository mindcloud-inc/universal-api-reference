# List Labels with Zoho Mail

Retrieves all labels from Zoho Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/labels`
- **Base URL:** `https://mail.zoho.com/api`
- **Official documentation:** [List Labels](https://www.zoho.com/mail/help/api/get-all-label-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Account identifier returned by List Accounts. |
