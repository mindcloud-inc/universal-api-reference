# Get Account Details with Zoho Mail

Retrieves account details from Zoho Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId`
- **Base URL:** `https://mail.zoho.com/api`
- **Official documentation:** [Get Account Details](https://www.zoho.com/mail/help/api/get-user-account-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Account identifier returned by List Accounts. |
