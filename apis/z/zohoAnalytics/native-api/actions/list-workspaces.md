# List Workspaces with Zoho Analytics

Retrieves accessible workspaces from Zoho Analytics.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://analyticsapi.zoho.com/restapi/v2`
- **Official documentation:** [List Workspaces](https://raw.githubusercontent.com/zoho/analytics-oas/main/v2.0/metadata-api.json)
