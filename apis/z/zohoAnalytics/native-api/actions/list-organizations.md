# List Organizations with Zoho Analytics

Retrieves available organizations from Zoho Analytics.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs`
- **Base URL:** `https://analyticsapi.zoho.com/restapi/v2`
- **Official documentation:** [List Organizations](https://www.zoho.com/analytics/api/v2/metadata-api/get-org.html)
