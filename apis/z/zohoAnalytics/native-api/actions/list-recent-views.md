# List Recent Views with Zoho Analytics

Retrieves recently accessed views from Zoho Analytics.

## Endpoint

- **Method:** `GET`
- **Path:** `/recentviews`
- **Base URL:** `https://analyticsapi.zoho.com/restapi/v2`
- **Official documentation:** [List Recent Views](https://raw.githubusercontent.com/zoho/analytics-oas/main/v2.0/metadata-api.json)
