# Delete Document with Zoho Sign

Deletes a document from Zoho Sign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/requests/:requestId/delete`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Delete Document](https://www.zoho.com/sign/api/document-managment/delete-document.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
