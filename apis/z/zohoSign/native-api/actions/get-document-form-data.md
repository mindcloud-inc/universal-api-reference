# Get Document Form Data with Zoho Sign

Retrieves document form data from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/:requestId/fielddata`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Get Document Form Data](https://www.zoho.com/sign/api/document-managment/get-document-form-data.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
