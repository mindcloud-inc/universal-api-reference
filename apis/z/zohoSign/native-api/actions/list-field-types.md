# List Field Types with Zoho Sign

Retrieves field types from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/fieldtypes`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [List Field Types](https://www.zoho.com/sign/api/document-managment/retrieve-field-type.html)
