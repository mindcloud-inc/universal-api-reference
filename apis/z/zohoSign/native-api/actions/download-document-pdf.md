# Download Document PDF with Zoho Sign

Downloads a document PDF from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/:requestId/pdf`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Download Document PDF](https://www.zoho.com/sign/api/document-managment/download-pdf.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
