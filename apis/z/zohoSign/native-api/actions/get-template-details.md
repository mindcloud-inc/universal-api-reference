# Get Template Details with Zoho Sign

Retrieves template details from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:templateId`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Get Template Details](https://www.zoho.com/sign/api/template-managment/get-template-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Zoho Sign template identifier. |
