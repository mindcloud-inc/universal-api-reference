# Correct Document with Zoho Sign

Marks a document for correction in Zoho Sign.

## Endpoint

- **Method:** `POST`
- **Path:** `/requests/:requestId/markforcorrection`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Correct Document](https://www.zoho.com/sign/api/document-managment/correct-document.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
