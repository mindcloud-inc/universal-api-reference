# Get Document Details with Zoho Sign

Retrieves document details from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/:requestId`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Get Document Details](https://www.zoho.com/sign/api/document-managment/get-details-of-a-particular-document.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
