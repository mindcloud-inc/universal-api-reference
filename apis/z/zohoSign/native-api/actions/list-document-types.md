# List Document Types with Zoho Sign

Retrieves document types from Zoho Sign.

## Endpoint

- **Method:** `GET`
- **Path:** `/requesttypes`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [List Document Types](https://www.zoho.com/sign/api/document-managment/get-document-type.html)
