# Delete Template with Zoho Sign

Deletes a template from Zoho Sign.

## Endpoint

- **Method:** `PUT`
- **Path:** `/templates/:templateId/delete`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Delete Template](https://www.zoho.com/sign/api/template-managment/delete-template.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Zoho Sign template identifier. |
