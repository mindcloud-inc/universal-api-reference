# Recall Document with Zoho Sign

Recalls a document in Zoho Sign.

## Endpoint

- **Method:** `POST`
- **Path:** `/requests/:requestId/recall`
- **Base URL:** `https://sign.zoho.com/api/v1`
- **Official documentation:** [Recall Document](https://www.zoho.com/sign/api/document-managment/recall-document.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `requestId` | path | `string` | yes | Zoho Sign request identifier. |
