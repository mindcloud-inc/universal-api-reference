# Get Organization Details with Zoho CRM

Retrieves organization details from Zoho CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/org`
- **Base URL:** `{api_domain}/crm/v8`
- **Official documentation:** [Get Organization Details](https://www.zoho.com/crm/developer/docs/api/v8/get-org-data.html)
