# Get Opportunity Group with Zoho CRM

Retrieves an Opportunity Group from Zoho CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Opportunity_Groups/:opportunityGroupId`
- **Base URL:** `{api_domain}/crm/v8`
- **Official documentation:** [Get Opportunity Group](https://www.zoho.com/crm/developer/docs/api/v8/get-records.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `opportunityGroupId` | path | `string` | yes |
