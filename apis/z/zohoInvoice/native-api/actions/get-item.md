# Get Item with Zoho Invoice

Retrieves an item from Zoho Invoice.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:item_id`
- **Base URL:** `https://www.zohoapis.com/invoice/v3`
- **Official documentation:** [Get Item](https://www.zoho.com/invoice/api/v3/items/#retrieve-an-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Unique identifier of the item. |
