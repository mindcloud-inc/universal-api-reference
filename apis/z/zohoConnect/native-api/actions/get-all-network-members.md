# Get All Network Members with Zoho Connect

Retrieves all network members from Zoho Connect.

## Endpoint

- **Method:** `GET`
- **Path:** `/pulse/api/orgMembers`
- **Base URL:** `https://connect.zoho.com`
- **Official documentation:** [Get All Network Members](https://www.zoho.com/connect/api/get-all-network-members.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scopeID` | query | `string` | yes | Network ID. |
