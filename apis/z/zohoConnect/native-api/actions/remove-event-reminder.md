# Remove Event Reminder with Zoho Connect

Removes a reminder from a Zoho Connect event.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pulse/api/deleteEventReminder`
- **Base URL:** `https://connect.zoho.com`
- **Official documentation:** [Remove Event Reminder](https://www.zoho.com/connect/api/remove-event-reminder.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `scopeID` | query | `string` | yes |
| `streamId` | query | `string` | yes |
