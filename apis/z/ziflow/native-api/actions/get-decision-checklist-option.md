# Get Decision Checklist Option with Ziflow

Retrieves a decision checklist option from Ziflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/decision-checklist/options/:optionId`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Decision Checklist Option](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `option_id` | path | `string` | yes | Option ID. |
