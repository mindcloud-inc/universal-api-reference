# List Intake Forms with Ziflow

Retrieves intake forms from your Ziflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/intake-forms`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Intake Forms](https://api-docs.ziflow.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
