# Get Comment Label with Ziflow

Retrieves a comment label from Ziflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/comment-labels/:labelId`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Comment Label](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label_id` | path | `string` | yes | Comment label ID. |
