# Get Proof with Ziflow

Retrieves a proof from Ziflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs/:id`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Proof](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The proof ID. |
