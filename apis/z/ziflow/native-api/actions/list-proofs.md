# List Proofs with Ziflow

Retrieves proofs from your Ziflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Proofs](https://api-docs.ziflow.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
