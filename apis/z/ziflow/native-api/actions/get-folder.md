# Get Folder with Ziflow

Retrieves subfolders in a Ziflow folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:id`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Folder](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The folder ID. |
