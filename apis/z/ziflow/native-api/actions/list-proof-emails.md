# List Proof Emails with Ziflow

Retrieves proof emails from Ziflow by proof ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs/:id/emails`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Proof Emails](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The proof ID. |
