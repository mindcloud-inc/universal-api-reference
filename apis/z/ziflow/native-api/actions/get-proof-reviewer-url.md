# Get Proof Reviewer URL with Ziflow

Retrieves a reviewer's proof URL from Ziflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs/:id/proof-url`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Proof Reviewer URL](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The proof ID. |
