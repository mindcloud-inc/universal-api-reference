# List Proof Activities with Ziflow

Retrieves proof activities from Ziflow by proof ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs/:id/activities`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Proof Activities](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The proof ID. |
