# Export Proof Summary PDF with Ziflow

Exports a proof summary to PDF from Ziflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/proofs/:id/summary/pdf`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Export Proof Summary PDF](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The proof ID. |
