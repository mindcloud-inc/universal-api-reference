# Get Workflow Template with Ziflow

Retrieves a workflow template from Ziflow by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workflowtemplates/:templateId`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Workflow Template](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Workflow template ID. |
