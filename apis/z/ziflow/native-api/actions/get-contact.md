# Get Contact with Ziflow

Retrieves a contact from Ziflow by ID or email.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:identifier`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Get Contact](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Contact identifier (ID or email). |
