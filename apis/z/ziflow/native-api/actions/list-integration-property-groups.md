# List Integration Property Groups with Ziflow

Retrieves integration property groups from Ziflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:applicationKey/property-groups`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Integration Property Groups](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application_key` | path | `string` | yes | Integration application key. |
