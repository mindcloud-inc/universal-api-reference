# Generate Folder URL with Ziflow

Retrieves a folder URL from Ziflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:id/folder-url`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [Generate Folder URL](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The folder ID. |
