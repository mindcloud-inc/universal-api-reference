# List Contacts with Ziflow

Retrieves contacts from your Ziflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Contacts](https://api-docs.ziflow.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
