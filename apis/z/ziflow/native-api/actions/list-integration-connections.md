# List Integration Connections with Ziflow

Retrieves integration connections for a Ziflow app.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:applicationKey/connections`
- **Base URL:** `https://api.ziflow.io/v1`
- **Official documentation:** [List Integration Connections](https://api-docs.ziflow.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application_key` | path | `string` | yes | Integration application key. |
