# Get data systems with Zillow MLS Data

Retrieves data systems from Zillow MLS Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/OData/DataSystem`
- **Base URL:** `https://api.bridgedataoutput.com/api/v2`
- **Official documentation:** [Get data systems](https://bridgedataoutput.com/docs/platform)
