# Get Applications with Zoho Creator

Retrieves accessible applications from Zoho Creator.

## Endpoint

- **Method:** `GET`
- **Path:** `/meta/applications`
- **Base URL:** `https://www.zohoapis.com/creator/v2.1`
- **Official documentation:** [Get Applications](https://www.zoho.com/creator/help/api/v2.1/get-workspace-applications.html)
