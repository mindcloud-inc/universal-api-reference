# Get Applications by Workspace with Zoho Creator

Retrieves workspace applications from Zoho Creator.

## Endpoint

- **Method:** `GET`
- **Path:** `/meta/:account_owner_name/applications`
- **Base URL:** `https://www.zohoapis.com/creator/v2.1`
- **Official documentation:** [Get Applications by Workspace](https://www.zoho.com/creator/help/api/v2.1/get-applications.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_owner_name` | path | `string` | yes | Zoho Creator account owner name. |
