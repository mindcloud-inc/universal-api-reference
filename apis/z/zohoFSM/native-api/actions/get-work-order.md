# Get Work Order with Zoho FSM

Retrieves work order details from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Work_Orders/:recordId`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [Get Work Order](https://www.zoho.com/fsm/developer/help/api/get-a-work-order.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | The Zoho FSM record ID. |
