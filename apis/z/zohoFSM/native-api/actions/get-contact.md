# Get Contact with Zoho FSM

Retrieves contact details from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts/:recordId`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [Get Contact](https://www.zoho.com/fsm/developer/help/api/get-a-contact.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | The Zoho FSM record ID. |
