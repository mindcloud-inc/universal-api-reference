# Get Estimate with Zoho FSM

Retrieves estimate details from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Estimates/:recordId`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [Get Estimate](https://www.zoho.com/fsm/developer/help/api/get-an-estimate.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | The Zoho FSM record ID. |
