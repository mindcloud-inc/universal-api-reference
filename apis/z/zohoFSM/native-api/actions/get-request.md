# Get Request with Zoho FSM

Retrieves request details from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Requests/:recordId`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [Get Request](https://www.zoho.com/fsm/developer/help/api/get-a-request.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | The Zoho FSM record ID. |
