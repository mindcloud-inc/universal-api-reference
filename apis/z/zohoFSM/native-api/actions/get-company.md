# Get Company with Zoho FSM

Retrieves company details from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Companies/:recordId`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [Get Company](https://www.zoho.com/fsm/developer/help/api/get-a-company.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | The Zoho FSM record ID. |
