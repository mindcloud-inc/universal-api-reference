# List Service Appointments with Zoho FSM

Retrieves service appointments from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Service_Appointments`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [List Service Appointments](https://www.zoho.com/fsm/developer/help/api/get-service-appointments.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to fetch. |
| `per_page` | query | `number` | no | Number of records per page. |
