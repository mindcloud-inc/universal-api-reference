# List Contacts with Zoho FSM

Retrieves contacts from Zoho FSM.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contacts`
- **Base URL:** `{api_domain}/fsm/v1`
- **Official documentation:** [List Contacts](https://www.zoho.com/fsm/developer/help/api/get-contacts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to fetch. |
| `per_page` | query | `number` | no | Number of records per page. |
