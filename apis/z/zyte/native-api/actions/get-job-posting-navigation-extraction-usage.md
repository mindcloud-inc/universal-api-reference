# Get Job Posting Navigation Extraction Usage with Zyte

Retrieves job posting navigation extraction usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Job Posting Navigation Extraction Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
