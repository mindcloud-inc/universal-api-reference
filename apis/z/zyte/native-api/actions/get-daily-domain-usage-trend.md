# Get Daily Domain Usage Trend with Zyte

Retrieves daily usage trends grouped by domain from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Daily Domain Usage Trend](https://docs.zyte.com/zyte-api/usage/stats.html)
