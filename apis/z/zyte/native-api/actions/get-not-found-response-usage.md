# Get Not Found Response Usage with Zyte

Retrieves 404 response usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Not Found Response Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
