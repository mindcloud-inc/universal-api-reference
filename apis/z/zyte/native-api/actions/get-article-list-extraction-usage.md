# Get Article List Extraction Usage with Zyte

Retrieves article list extraction usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Article List Extraction Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
