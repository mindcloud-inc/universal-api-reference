# Get Session Context Feature Usage with Zyte

Retrieves session context feature usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Session Context Feature Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
