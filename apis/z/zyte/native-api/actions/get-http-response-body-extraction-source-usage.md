# Get HTTP Response Body Extraction Source Usage with Zyte

Retrieves article extraction usage metrics from HTTP response body in Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get HTTP Response Body Extraction Source Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
