# Get Browser HTML Extraction Source Usage with Zyte

Retrieves article extraction usage metrics from Browser HTML in Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Browser HTML Extraction Source Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
