# Get Browser HTML Feature Usage with Zyte

Retrieves Browser HTML feature usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Browser HTML Feature Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
