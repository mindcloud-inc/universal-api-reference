# Get Successful Response Usage with Zyte

Retrieves 200 response usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Successful Response Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
