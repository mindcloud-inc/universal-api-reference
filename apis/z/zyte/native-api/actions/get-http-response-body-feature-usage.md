# Get HTTP Response Body Feature Usage with Zyte

Retrieves HTTP response body feature usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get HTTP Response Body Feature Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
