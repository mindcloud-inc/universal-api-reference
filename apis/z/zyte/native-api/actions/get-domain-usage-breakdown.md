# Get Domain Usage Breakdown with Zyte

Retrieves usage metrics grouped by domain from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Domain Usage Breakdown](https://docs.zyte.com/zyte-api/usage/stats.html)
