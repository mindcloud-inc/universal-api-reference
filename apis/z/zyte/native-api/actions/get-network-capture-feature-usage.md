# Get Network Capture Feature Usage with Zyte

Retrieves network capture feature usage metrics from Zyte.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/stats`
- **Base URL:** `https://zyte-api-stats.zyte.com`
- **Official documentation:** [Get Network Capture Feature Usage](https://docs.zyte.com/zyte-api/usage/stats.html)
