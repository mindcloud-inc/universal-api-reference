# Update Subscription with Zoho Billing

## Endpoint

- **Method:** `PUT`
- **Path:** `/subscriptions/:subscription_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Update Subscription](https://www.zoho.com/billing/api/v1/subscription/#update-a-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | Unique identifier of the subscription. |
