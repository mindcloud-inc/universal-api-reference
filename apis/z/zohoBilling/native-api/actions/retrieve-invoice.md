# Retrieve Invoice with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Retrieve Invoice](https://www.zoho.com/billing/api/v1/invoices/#retrieve-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes | Unique identifier of the invoice. |
