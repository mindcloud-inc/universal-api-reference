# Retrieve Subscription with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:subscription_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Retrieve Subscription](https://www.zoho.com/billing/api/v1/subscription/#retrieve-a-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | Unique identifier of the subscription. |
