# Update Customer with Zoho Billing

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers/:customer_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Update Customer](https://www.zoho.com/billing/api/v1/customers/#update-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Unique identifier of the customer. |
