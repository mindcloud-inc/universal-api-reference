# Reactivate Subscription with Zoho Billing

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriptions/:subscription_id/reactivate`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Reactivate Subscription](https://www.zoho.com/billing/api/v1/subscription/#reactivate-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | Unique identifier of the subscription. |
