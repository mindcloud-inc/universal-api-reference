# Retrieve Plan with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/plans/:plan_code`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Retrieve Plan](https://www.zoho.com/billing/api/v1/plans/#retrieve-a-plan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `plan_code` | path | `string` | yes | Unique code of the plan. |
