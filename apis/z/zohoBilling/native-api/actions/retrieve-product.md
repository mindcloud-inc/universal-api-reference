# Retrieve Product with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Retrieve Product](https://www.zoho.com/billing/api/v1/products/#retrieve-a-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | yes | Unique identifier of the product. |
