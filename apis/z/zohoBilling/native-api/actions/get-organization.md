# Get Organization with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organization_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Get Organization](https://www.zoho.com/billing/api/v1/organizations/#get-an-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Unique identifier of the organization. |
