# Update Product with Zoho Billing

## Endpoint

- **Method:** `PUT`
- **Path:** `/products/:product_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Update Product](https://www.zoho.com/billing/api/v1/products/#update-a-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | yes | Unique identifier of the product. |
