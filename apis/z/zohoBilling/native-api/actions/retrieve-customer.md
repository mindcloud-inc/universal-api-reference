# Retrieve Customer with Zoho Billing

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customer_id`
- **Base URL:** `{api_domain}/billing/v1`
- **Official documentation:** [Retrieve Customer](https://www.zoho.com/billing/api/v1/customers/#retrieve-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Unique identifier of the customer. |
