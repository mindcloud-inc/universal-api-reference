# List Workflows with Zahara

Retrieves workflows from a Zahara business unit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{businessUnitApiKey}/Process/GetAll`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [List Workflows](https://ask.zaharasoftware.com/api-docs/get-all-workflows)
