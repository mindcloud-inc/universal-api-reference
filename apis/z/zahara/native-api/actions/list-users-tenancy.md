# List Users (Tenancy) with Zahara

Retrieves users from a Zahara tenancy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{tenancyApiKey}/User/GetAll`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [List Users (Tenancy)](https://ask.zaharasoftware.com/api-docs/get-all-users)
