# List Users (Business Unit) with Zahara

Retrieves users from a Zahara business unit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{businessUnitApiKey}/User/GetAll`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [List Users (Business Unit)](https://ask.zaharasoftware.com/api-docs/get-all-users)
