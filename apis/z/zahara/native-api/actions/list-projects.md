# List Projects with Zahara

Retrieves projects from a Zahara business unit.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{businessUnitApiKey}/Project/GetAll`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [List Projects](https://ask.zaharasoftware.com/api-docs/get-all-projects)
