# List Currencies with Zahara

Retrieves available currencies from the Zahara tenancy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{tenancyApiKey}/Currencies`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [List Currencies](https://ask.zaharasoftware.com/api-docs/currencies)
