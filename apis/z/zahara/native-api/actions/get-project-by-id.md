# Get Project By ID with Zahara

Retrieves a project by ID from Zahara.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/{businessUnitApiKey}/Project/Get/{{projectId}}`
- **Base URL:** `https://api.myzahara.net`
- **Official documentation:** [Get Project By ID](https://ask.zaharasoftware.com/api-docs/get-project-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The Zahara project ID. |
