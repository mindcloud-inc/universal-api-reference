# List Available Webhooks with Zenvoices

Retrieves available webhook event names from Zenvoices.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/webhookSubscription/get-available-webhooks`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Available Webhooks](https://app.zenvoices.com/swagger/public-v1/swagger.json)
