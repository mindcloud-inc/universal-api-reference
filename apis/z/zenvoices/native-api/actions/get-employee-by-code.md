# Get Employee By Code with Zenvoices

Retrieves an employee from Zenvoices by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/employees`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Employee By Code](https://app.zenvoices.com/swagger/public-v1/swagger.json)
