# Get Product By Code with Zenvoices

Retrieves a product from Zenvoices by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/product`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Product By Code](https://app.zenvoices.com/swagger/public-v1/swagger.json)
