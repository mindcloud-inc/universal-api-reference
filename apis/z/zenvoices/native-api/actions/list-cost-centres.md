# List Cost Centres with Zenvoices

Retrieves cost centres from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/costCentres/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Cost Centres](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
