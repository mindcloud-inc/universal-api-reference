# Get Purchase Order with Zenvoices

Retrieves a purchase order from Zenvoices by purchase order number.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/purchaseOrders`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Purchase Order](https://app.zenvoices.com/swagger/public-v1/swagger.json)
