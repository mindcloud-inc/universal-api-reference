# Get Financial Transaction with Zenvoices

Retrieves a financial transaction from your Zenvoices workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/financialTransaction/{financialTransactionId}`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Financial Transaction](https://app.zenvoices.com/swagger/public-v1/swagger.json)
