# List Ledger Accounts with Zenvoices

Retrieves ledger accounts from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/ledgerAccounts/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Ledger Accounts](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
