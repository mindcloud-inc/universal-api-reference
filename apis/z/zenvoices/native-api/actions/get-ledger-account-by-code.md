# Get Ledger Account By Code with Zenvoices

Retrieves a ledger account from Zenvoices by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/ledgerAccounts`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Ledger Account By Code](https://app.zenvoices.com/swagger/public-v1/swagger.json)
