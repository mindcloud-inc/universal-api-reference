# Get Project By Code with Zenvoices

Retrieves a project from Zenvoices by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/projects`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Project By Code](https://app.zenvoices.com/swagger/public-v1/swagger.json)
