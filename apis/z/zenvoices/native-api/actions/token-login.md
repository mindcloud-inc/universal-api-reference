# Token Login with Zenvoices

Retrieves an access token from Zenvoices.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/TokenAuth/TokenLogin`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Token Login](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
