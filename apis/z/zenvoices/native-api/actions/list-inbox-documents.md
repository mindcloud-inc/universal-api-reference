# List Inbox Documents with Zenvoices

Retrieves inbox documents from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/inbox/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Inbox Documents](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
