# List Cost Units with Zenvoices

Retrieves cost units from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/costUnits/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Cost Units](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
