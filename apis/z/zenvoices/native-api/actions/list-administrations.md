# List Administrations with Zenvoices

Retrieves administrations from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/administration/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Administrations](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
