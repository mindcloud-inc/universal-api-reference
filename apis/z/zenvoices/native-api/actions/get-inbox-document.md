# Get Inbox Document with Zenvoices

Retrieves an inbox document from your Zenvoices workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/inbox/details`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Inbox Document](https://app.zenvoices.com/swagger/public-v1/swagger.json)
