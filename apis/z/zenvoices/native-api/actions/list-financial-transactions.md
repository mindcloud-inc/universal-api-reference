# List Financial Transactions with Zenvoices

Retrieves financial transactions from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/financialTransaction/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Financial Transactions](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
