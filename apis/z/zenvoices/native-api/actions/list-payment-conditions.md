# List Payment Conditions with Zenvoices

Retrieves payment conditions from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/paymentConditions/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Payment Conditions](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
