# Get Administration with Zenvoices

Retrieves an administration from your Zenvoices workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/administration/{administrationId}`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Administration](https://app.zenvoices.com/swagger/public-v1/swagger.json)
