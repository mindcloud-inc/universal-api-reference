# Get Account By External ID with Zenvoices

Retrieves an account from Zenvoices by external ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/accounts/externalId`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Account By External ID](https://app.zenvoices.com/swagger/public-v1/swagger.json)
