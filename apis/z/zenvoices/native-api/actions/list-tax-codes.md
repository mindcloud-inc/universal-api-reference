# List Tax Codes with Zenvoices

Retrieves tax codes from your Zenvoices workspace.

## Endpoint

- **Method:** `POST`
- **Path:** `/public-api/v1/taxCodes/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Tax Codes](https://app.zenvoices.com/swagger/public-v1/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
