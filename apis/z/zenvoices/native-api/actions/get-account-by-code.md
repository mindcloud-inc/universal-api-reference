# Get Account By Code with Zenvoices

Retrieves an account from Zenvoices by code.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/accounts`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [Get Account By Code](https://app.zenvoices.com/swagger/public-v1/swagger.json)
