# List Webhook Subscriptions with Zenvoices

Retrieves webhook subscriptions from your Zenvoices workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/public-api/v1/webhookSubscription/list`
- **Base URL:** `https://app.zenvoices.com`
- **Official documentation:** [List Webhook Subscriptions](https://app.zenvoices.com/swagger/public-v1/swagger.json)
