# Retrieve Composition Cart Info with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/compositions/{id}/cartinfo`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Retrieve Composition Cart Info](https://docs.zakeke.com/docs/API/compositions-API#5-get-the-necessary-data-to-add-a-configured-product-to-the-shopping-cart)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique configuration identifier provided by Zakeke. |
