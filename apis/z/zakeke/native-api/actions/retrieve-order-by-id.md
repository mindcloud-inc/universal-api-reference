# Retrieve Order By ID with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/{order}`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Retrieve Order By ID](https://docs.zakeke.com/docs/API/orders-API#6-retrieve-an-order-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order` | path | `string` | yes | Unique Zakeke order identifier. |
