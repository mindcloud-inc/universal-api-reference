# Retrieve Print-Ready ZIP with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/designs/{designID}/outputfiles/zip`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Retrieve Print-Ready ZIP](https://docs.zakeke.com/docs/API/designs-API#7-retrieve-the-zip-with-all-print-ready-files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | yes | Unique design identifier provided by Zakeke. |
