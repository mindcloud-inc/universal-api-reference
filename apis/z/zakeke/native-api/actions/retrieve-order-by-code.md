# Retrieve Order By Code with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/order/{orderCode}`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Retrieve Order By Code](https://docs.zakeke.com/docs/API/orders-API#5-retrieve-an-order-by-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderCode` | path | `string` | yes | Unique order identifier on the ecommerce. |
