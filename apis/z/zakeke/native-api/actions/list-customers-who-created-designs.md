# List Customers Who Created Designs with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/designs/seller/customers`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [List Customers Who Created Designs](https://docs.zakeke.com/docs/API/designs-API#11-customers-who-created-designs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `onlyDraftDesigns` | query | `boolean` | no | When true, return only customers who saved draft designs. |
