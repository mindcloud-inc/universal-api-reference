# List Customers Who Created Compositions with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/compositions/seller/customers`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [List Customers Who Created Compositions](https://docs.zakeke.com/docs/API/compositions-API#7-customers-who-created-compositions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `onlyDraftDesigns` | query | `boolean` | no | When true, returns only customers who created draft compositions. |
