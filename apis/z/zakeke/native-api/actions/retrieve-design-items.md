# Retrieve Design Items with Zakeke

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/designs/{designID}/items`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Retrieve Design Items](https://docs.zakeke.com/docs/API/designs-API#6-retrieve-design-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | yes | Unique design identifier provided by Zakeke. |
