# Duplicate Design with Zakeke

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/designs/{designID}`
- **Base URL:** `https://api.zakeke.com`
- **Official documentation:** [Duplicate Design](https://docs.zakeke.com/docs/API/designs-API#5-duplicate-a-design)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designID` | path | `string` | yes | Unique design identifier provided by Zakeke. |
