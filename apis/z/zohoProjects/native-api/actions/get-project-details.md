# Get Project Details with Zoho Projects

Retrieves project details from Zoho Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/portal/[:PORTALID]/projects/[:PROJECTID]`
- **Base URL:** `https://projectsapi.zoho.com/api/v3`
- **Official documentation:** [Get Project Details](https://projectsapi.zoho.com/api-docs#projects_get-project-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PORTALID` | path | `string` | yes | Zoho Projects portal ID. |
| `PROJECTID` | path | `string` | yes | Zoho Projects project ID. |
