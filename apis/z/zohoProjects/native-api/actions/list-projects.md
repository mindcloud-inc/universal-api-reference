# List Projects with Zoho Projects

Retrieves projects from a Zoho Projects portal.

## Endpoint

- **Method:** `GET`
- **Path:** `/portal/[:PORTALID]/projects`
- **Base URL:** `https://projectsapi.zoho.com/api/v3`
- **Official documentation:** [List Projects](https://projectsapi.zoho.com/api-docs#projects_get-all-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PORTALID` | path | `string` | yes | Zoho Projects portal ID. |
