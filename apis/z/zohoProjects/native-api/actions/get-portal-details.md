# Get Portal Details with Zoho Projects

Retrieves portal details from Zoho Projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/portal/[:PORTALID]`
- **Base URL:** `https://projectsapi.zoho.com/api/v3`
- **Official documentation:** [Get Portal Details](https://projectsapi.zoho.com/api-docs#portals_get-portal-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PORTALID` | path | `string` | yes | Zoho Projects portal ID. |
