# Get My Profile with Zoho Desk

Retrieve the configuration details and permissions defined for the profile of the currently logged in user.

## Endpoint

- **Method:** `GET`
- **Path:** `myProfile`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [Get My Profile](https://desk.zoho.com/DeskAPIDocument#Profiles_Getmyprofiledetails)
