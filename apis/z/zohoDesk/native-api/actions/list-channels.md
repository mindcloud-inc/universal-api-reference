# List Channels with Zoho Desk

Retrieve currently installed channels including `System`, `Channel Integration` and `Instant Messaging` channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [List Channels](https://desk.zoho.com/DeskAPIDocument#Channels#Channels_Listconfiguredchannels)
