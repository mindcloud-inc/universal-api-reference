# Create Account with Zoho Desk

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [Create Account](https://github.com/zoho/zohodesk-oas/blob/master/v1.0/Account.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountName` | body | `string` | yes | Name of the new account. |
