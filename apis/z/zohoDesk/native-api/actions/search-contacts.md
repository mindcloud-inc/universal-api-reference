# Search Contacts with Zoho Desk

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/search`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [Search Contacts](https://github.com/zoho/zohodesk-oas/blob/master/v1.0/Search.json)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | Search for an exact Zoho Desk contact ID. |
