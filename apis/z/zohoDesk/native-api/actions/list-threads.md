# List Threads with Zoho Desk

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/[:ticketId]/threads`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [List Threads](https://github.com/zoho/zohodesk-oas/blob/master/v1.0/Thread.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | path | `string` | yes | The Zoho Desk ticket ID. |
