# Get Department with Zoho Desk

## Endpoint

- **Method:** `GET`
- **Path:** `/departments/[:departmentId]`
- **Base URL:** `https://desk.zoho.com/api/v1`
- **Official documentation:** [Get Department](https://github.com/zoho/zohodesk-oas/blob/master/v1.0/Department.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `string` | yes | The Zoho Desk department ID. |
