# Enrich Technology with Zoominfo

Enriches technology details with ZoomInfo data.

## Endpoint

- **Method:** `POST`
- **Path:** `enrich/tech`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Enrich Technology](https://api-docs.zoominfo.com/#9fc40c02-fe95-448f-a6f4-e903c85c81a9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | body | `string` | no | The id of the company for which you want to view technologies |
