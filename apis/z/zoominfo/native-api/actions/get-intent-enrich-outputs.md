# Get Intent Enrich Outputs with Zoominfo

Retrieves intent enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/intent/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Intent Enrich Outputs](https://api-docs.zoominfo.com/#fc4083cf-6179-4f0f-8b9b-80aedc2e3e67)
