# Get Hierarchy Code with Zoominfo

Retrieves hierarchy codes from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/hierarchy-code`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Hierarchy Code](https://api-docs.zoominfo.com/#43513c41-3f30-4419-9b47-472b46bb5f9c)
