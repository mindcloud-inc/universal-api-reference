# Get Tech Categories with Zoominfo

Retrieves tech categories from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/tech/category`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Tech Categories](https://api-docs.zoominfo.com/#b73c7096-268f-4bcd-b6a9-cb764f40a29e)
