# Get Buying Groups with Zoominfo

Retrieves buying groups from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/buyinggroups`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Buying Groups](https://api-docs.zoominfo.com/#595ddead-d5b6-461f-ae4a-d3952c7776f6)
