# Get News Search Inputs with Zoominfo

Retrieves news search input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/news/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get News Search Inputs](https://api-docs.zoominfo.com/#90bfb6fb-2754-478b-b42d-f8c507ffffb2)
