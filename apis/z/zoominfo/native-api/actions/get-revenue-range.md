# Get Revenue Range with Zoominfo

Retrieves revenue ranges from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/revenuerange`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Revenue Range](https://api-docs.zoominfo.com/#77fedfbc-c8df-4e4e-afc2-37112caa97be)
