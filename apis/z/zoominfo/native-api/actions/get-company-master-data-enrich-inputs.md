# Get Company Master Data Enrich Inputs with Zoominfo

Retrieves company master data enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/company-master/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Master Data Enrich Inputs](https://api-docs.zoominfo.com/#d305402c-33d1-488c-8b8f-b5b079868a61)
