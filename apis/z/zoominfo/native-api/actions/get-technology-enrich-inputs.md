# Get Technology Enrich Inputs with Zoominfo

Retrieves technology enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/tech/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Technology Enrich Inputs](https://api-docs.zoominfo.com/#2cc6abbc-e782-4ab4-80e8-ce29ed17ee4e)
