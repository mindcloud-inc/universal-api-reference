# Get Intent Search Outputs with Zoominfo

Retrieves intent search output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/intent/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Intent Search Outputs](https://api-docs.zoominfo.com/#8f3540ee-4093-48e4-aebb-97133a864912)
