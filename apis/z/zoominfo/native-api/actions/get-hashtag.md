# Get Hashtag with Zoominfo

Retrieves hashtag values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/hashtag`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Hashtag](https://api-docs.zoominfo.com/#fca6515f-0ef5-4f6a-885d-9c80aef81f14)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `vendor` | query | `string` | no |
| `parentCategory` | query | `string` | no |
| `category` | query | `string` | no |
