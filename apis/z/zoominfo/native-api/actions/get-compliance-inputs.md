# Get Compliance Inputs with Zoominfo

Retrieves compliance enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/compliance/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Compliance Inputs](https://api-docs.zoominfo.com/#b45d0781-0844-4c51-bb2e-f2656e1af919)
