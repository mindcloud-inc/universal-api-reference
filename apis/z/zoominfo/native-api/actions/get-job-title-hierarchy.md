# Get Job Title Hierarchy with Zoominfo

Retrieves job title hierarchy values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/jobtitlehierarchy`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Job Title Hierarchy](https://api-docs.zoominfo.com/#abe7fe05-05e7-414a-95a5-46fc5cc70512)
