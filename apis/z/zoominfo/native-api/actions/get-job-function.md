# Get Job Function with Zoominfo

Retrieves job function values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/jobfunction`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Job Function](https://api-docs.zoominfo.com/#dd9e9fa4-33aa-495a-ab40-f97339784cf1)
