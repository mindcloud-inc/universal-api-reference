# Get Hashtag Enrich Inputs with Zoominfo

Retrieves hashtag enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/hashtag/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Hashtag Enrich Inputs](https://api-docs.zoominfo.com/#a7bea20a-f496-431b-9403-337231c4a22e)
