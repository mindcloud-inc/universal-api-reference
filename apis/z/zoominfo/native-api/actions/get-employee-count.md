# Get Employee Count with Zoominfo

Retrieves employee count ranges from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/employeecount`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Employee Count](https://api-docs.zoominfo.com/#4632ac8d-d96b-4672-ba84-8314ba1bb146)
