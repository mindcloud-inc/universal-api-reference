# Get Contact Search Inputs with Zoominfo

Retrieves contact search input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/contact/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Contact Search Inputs](https://api-docs.zoominfo.com/#74630827-dd25-4b6a-bf72-f7cfeffd6c41)
