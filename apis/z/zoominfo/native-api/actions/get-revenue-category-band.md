# Get Revenue Category Band with Zoominfo

Retrieves revenue category bands from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/revenue-category-band`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Revenue Category Band](https://api-docs.zoominfo.com/#370c8c31-d225-463c-bc05-3af2e904ae40)
