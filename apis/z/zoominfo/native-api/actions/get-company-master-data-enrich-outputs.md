# Get Company Master Data Enrich Outputs with Zoominfo

Retrieves company master data enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/company-master/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Master Data Enrich Outputs](https://api-docs.zoominfo.com/#58b47522-753a-4104-a0c6-454adf4b6a1d)
