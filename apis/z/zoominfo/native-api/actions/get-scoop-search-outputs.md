# Get Scoop Search Outputs with Zoominfo

Retrieves scoop search output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/scoop/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Search Outputs](https://api-docs.zoominfo.com/#185aa18e-02fa-440e-a691-b8e2c391a456)
