# Get IP Enrich Inputs with Zoominfo

Retrieves IP enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/ip/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get IP Enrich Inputs](https://api-docs.zoominfo.com/#12a5c22b-cba1-4b40-a8c6-45f564cf0c2a)
