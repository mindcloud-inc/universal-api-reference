# Get Contact Enrich Outputs with Zoominfo

Retrieves contact enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/contact/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Contact Enrich Outputs](https://api-docs.zoominfo.com/#28b47784-3186-4fc4-af91-12e6bc6fb31a)
