# Get Org Chart Enrich Inputs with Zoominfo

Retrieves org chart enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/orgchart/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Org Chart Enrich Inputs](https://api-docs.zoominfo.com/#751a9156-1867-4033-a115-a44aa0ecbfad)
