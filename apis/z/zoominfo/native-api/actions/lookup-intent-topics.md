# Lookup Intent Topics with Zoominfo

Retrieves intent topics from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/intent/topics`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Lookup Intent Topics](https://api-docs.zoominfo.com/#7d3e2352-9099-4207-815e-6129c95a2f16)
