# Get Company Search Inputs with Zoominfo

Retrieves company search input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/company/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Search Inputs](https://api-docs.zoominfo.com/#ffd4ccc6-09d1-4026-8c4f-863d02fd703e)
