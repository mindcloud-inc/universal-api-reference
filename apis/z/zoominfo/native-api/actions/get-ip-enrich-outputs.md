# Get IP Enrich Outputs with Zoominfo

Retrieves IP enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/ip/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get IP Enrich Outputs](https://api-docs.zoominfo.com/#ca8c2c2f-c731-4310-ae0d-dfba2fb756d7)
