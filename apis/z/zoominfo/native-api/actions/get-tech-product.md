# Get Tech Product with Zoominfo

Retrieves tech product values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/tech/product`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Tech Product](https://api-docs.zoominfo.com/#9551cace-281d-43d0-8685-dd39c82780cc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `vendor` | query | `string` | no |
| `parentCategory` | query | `string` | no |
| `category` | query | `string` | no |
