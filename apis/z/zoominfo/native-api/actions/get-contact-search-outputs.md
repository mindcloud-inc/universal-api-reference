# Get Contact Search Outputs with Zoominfo

Retrieves contact search output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/contact/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Contact Search Outputs](https://api-docs.zoominfo.com/#5ed629a9-f24a-41a3-bc66-89f3f09f051c)
