# Get Company Search Outputs with Zoominfo

Retrieves company search output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/company/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Search Outputs](https://api-docs.zoominfo.com/#3dd35354-8523-4a8c-935a-97ed56d059a6)
