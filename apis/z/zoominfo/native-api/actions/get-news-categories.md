# Get News Categories with Zoominfo

Retrieves news categories from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/news/categories`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get News Categories](https://api-docs.zoominfo.com/#b9f5ee4a-3287-414c-b244-ddd6f3c0e3fe)
