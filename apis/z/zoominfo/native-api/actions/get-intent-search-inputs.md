# Get Intent Search Inputs with Zoominfo

Retrieves intent search input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/intent/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Intent Search Inputs](https://api-docs.zoominfo.com/#14669274-88b8-4762-8d61-57d2fd5abf12)
