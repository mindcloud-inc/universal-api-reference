# Get Scoop Search Inputs with Zoominfo

Retrieves scoop search input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/scoop/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Search Inputs](https://api-docs.zoominfo.com/#1888a5e1-6a96-4cc2-910b-70e574370996)
