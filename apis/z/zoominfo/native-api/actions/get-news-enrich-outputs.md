# Get News Enrich Outputs with Zoominfo

Retrieves news enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/news/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get News Enrich Outputs](https://api-docs.zoominfo.com/#254b86e3-e51b-450d-8704-95e4da168874)
