# Get Company Type with Zoominfo

Retrieves company types from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/companytype`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Type](https://api-docs.zoominfo.com/#c1c18376-e740-4412-9d86-dbd1145429c8)
