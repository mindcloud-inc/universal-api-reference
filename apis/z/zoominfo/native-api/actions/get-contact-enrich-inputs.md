# Get Contact Enrich Inputs with Zoominfo

Retrieves contact enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/contact/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Contact Enrich Inputs](https://api-docs.zoominfo.com/#dbaf31cd-0f7a-4bf3-b6c1-077f3c31f2df)
