# Get Company Enrich Inputs with Zoominfo

Retrieves company enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/company/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Enrich Inputs](https://api-docs.zoominfo.com/#7a915792-e8cd-4e3a-9f0e-c19b850be536)
