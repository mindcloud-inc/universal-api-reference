# Get Company Enrich Outputs with Zoominfo

Retrieves company enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/company/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Enrich Outputs](https://api-docs.zoominfo.com/#d05239c3-2597-45f8-9384-f2dbd3518cfc)
