# Get Location Enrich Outputs with Zoominfo

Retrieves location enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/location/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Location Enrich Outputs](https://api-docs.zoominfo.com/#d1fbccf4-2224-4ba8-b72c-5b15e250c2f7)
