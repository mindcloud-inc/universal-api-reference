# Get Scoop Enrich Inputs with Zoominfo

Retrieves scoop enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/scoop/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Enrich Inputs](https://api-docs.zoominfo.com/#4ebf5d05-d819-4336-977f-2fe72dc6ac19)
