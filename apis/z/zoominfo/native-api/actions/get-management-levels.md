# Get Management Levels with Zoominfo

Retrieves management levels from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/managementLevel`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Management Levels](https://api-docs.zoominfo.com/#239048f1-a720-46b1-a907-3a9ca243ede2)
