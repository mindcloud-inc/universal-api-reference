# Get Sub Unit Type with Zoominfo

Retrieves sub-unit types from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/subunittypes`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Sub Unit Type](https://api-docs.zoominfo.com/#e7dd47c9-bfa4-4dfd-8547-3334377fef17)
