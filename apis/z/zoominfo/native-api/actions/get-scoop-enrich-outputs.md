# Get Scoop Enrich Outputs with Zoominfo

Retrieves scoop enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/scoop/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Enrich Outputs](https://api-docs.zoominfo.com/#3af4b7ad-e694-4202-81c4-20b7bab73946)
