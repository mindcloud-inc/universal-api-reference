# Get Location Enrich Inputs with Zoominfo

Retrieves location enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/location/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Location Enrich Inputs](https://api-docs.zoominfo.com/#5517cdb0-18c9-40ad-9d80-bdee7872d9e0)
