# Get Industry Codes with Zoominfo

Retrieves industry codes from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/industry`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Industry Codes](https://api-docs.zoominfo.com/#e1f93c82-43bc-4bdc-9600-03242ef873ca)
