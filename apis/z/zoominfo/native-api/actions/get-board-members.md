# Get Board Members with Zoominfo

Retrieves board member values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/boardMember`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Board Members](https://api-docs.zoominfo.com/#993c5474-f201-4de8-9e64-f87c2045a084)
