# Get Compliance Outputs with Zoominfo

Retrieves compliance enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/compliance/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Compliance Outputs](https://api-docs.zoominfo.com/#0c06b63c-9d07-40e3-a4ea-6f2e3fd10222)
