# Get Scoop Topics with Zoominfo

Retrieves scoop topics from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/scooptopic`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Topics](https://api-docs.zoominfo.com/#c9aadb87-22ca-4feb-94cc-a73e4540ac94)
