# Get Intent Enrich Inputs with Zoominfo

Retrieves intent enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/intent/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Intent Enrich Inputs](https://api-docs.zoominfo.com/#2dcbe844-7f1f-45f3-ae32-2598ccec5be4)
