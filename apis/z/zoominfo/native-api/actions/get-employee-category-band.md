# Get Employee Category Band with Zoominfo

Retrieves employee category bands from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/employee-category-band`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Employee Category Band](https://api-docs.zoominfo.com/#1949fef9-edee-4079-a6de-5acff2b07f44)
