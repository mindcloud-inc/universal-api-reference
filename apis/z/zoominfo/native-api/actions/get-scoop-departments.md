# Get Scoop Departments with Zoominfo

Retrieves scoop departments from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/scoopdepartment`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Scoop Departments](https://api-docs.zoominfo.com/#1649ad68-8e03-4d1f-90ff-ec221d53caa0)
