# Authenticate with Zoominfo

Creates an authentication token in ZoomInfo.

## Endpoint

- **Method:** `POST`
- **Path:** `authenticate`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Authenticate](https://api-docs.zoominfo.com/#477888fc-8308-4645-81ca-ca7a6d7ba3d1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `username` | body | `string` | yes |
