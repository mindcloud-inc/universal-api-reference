# Get Company Ranking with Zoominfo

Retrieves company ranking values from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/companyranking`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Company Ranking](https://api-docs.zoominfo.com/#217297b2-9743-47b5-a2be-adf5be3bdd47)
