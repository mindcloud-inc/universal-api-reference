# Get News Enrich Inputs with Zoominfo

Retrieves news enrich input fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/inputfields/news/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get News Enrich Inputs](https://api-docs.zoominfo.com/#d58425e5-a4a4-4af0-ad01-fa7bbf91ca84)
