# Get Contact Departments with Zoominfo

Retrieves contact departments from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/department`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Contact Departments](https://api-docs.zoominfo.com/#015c9e39-dc39-41dc-ab33-5f07a802fd99)
