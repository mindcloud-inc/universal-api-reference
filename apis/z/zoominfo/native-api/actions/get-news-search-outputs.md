# Get News Search Outputs with Zoominfo

Retrieves news search output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/news/search`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get News Search Outputs](https://api-docs.zoominfo.com/#354f6240-e3d3-4c8c-9684-86569fd71581)
