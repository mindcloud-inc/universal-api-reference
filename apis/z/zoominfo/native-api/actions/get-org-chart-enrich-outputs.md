# Get Org Chart Enrich Outputs with Zoominfo

Retrieves org chart enrich output fields from ZoomInfo.

## Endpoint

- **Method:** `GET`
- **Path:** `lookup/outputfields/orgchart/enrich`
- **Base URL:** `https://api.zoominfo.com/`
- **Official documentation:** [Get Org Chart Enrich Outputs](https://api-docs.zoominfo.com/#b2c219d2-df68-4ccd-9914-c7c58218f768)
