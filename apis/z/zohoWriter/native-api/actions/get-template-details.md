# Get Template Details with Zoho Writer

Retrieves template details from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:template_id`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Get Template Details](https://www.zoho.com/writer/help/api/v1/get-template-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | Unique ID of the Writer template. |
