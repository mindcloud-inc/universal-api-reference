# Get Document Metrics with Zoho Writer

Retrieves document metrics from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents/:document_id/metrics`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Get Document Metrics](https://www.zoho.com/writer/help/api/v1/get-document-metrics.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Unique ID of the Writer document. |
