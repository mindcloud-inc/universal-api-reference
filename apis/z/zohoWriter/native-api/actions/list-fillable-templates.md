# List Fillable Templates with Zoho Writer

Retrieves fillable templates from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [List Fillable Templates](https://www.zoho.com/writer/help/api/v1/get-fillable-templates.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
