# List Documents with Zoho Writer

Retrieves documents from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [List Documents](https://www.zoho.com/writer/help/api/v1/get-list-of-documents.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
