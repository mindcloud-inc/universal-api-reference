# Delete Document Permanently with Zoho Writer

Deletes a document permanently from Zoho Writer.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/documents/:document_id/delete`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Delete Document Permanently](https://www.zoho.com/writer/help/api/v1/delete-document-permanently.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique ID of the Zoho Writer document. |
