# Create Template with Zoho Writer

Creates a template in Zoho Writer.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/templates`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Create Template](https://www.zoho.com/writer/help/api/v1/create-template.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Name for the new Writer template. |
