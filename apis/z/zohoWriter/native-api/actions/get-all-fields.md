# Get All Fields with Zoho Writer

Retrieves all fields from a Zoho Writer document.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents/:document_id/fields`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Get All Fields](https://www.zoho.com/writer/help/api/v1/get-all-fields.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique ID of the Zoho Writer document. |
