# List Folders with Zoho Writer

Retrieves folders from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/folders`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [List Folders](https://www.zoho.com/writer/help/api/v1/get-list-of-folders.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Folder category to list. |
