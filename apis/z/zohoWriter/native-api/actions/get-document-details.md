# Get Document Details with Zoho Writer

Retrieves document details from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents/:document_id`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Get Document Details](https://www.zoho.com/writer/help/api/v1/get-document-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique ID of the Zoho Writer document. |
