# Download Document with Zoho Writer

Downloads a document from Zoho Writer.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/download/:document_id`
- **Base URL:** `{api_domain}/writer/api`
- **Official documentation:** [Download Document](https://www.zoho.com/writer/help/api/v1/download-document.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique ID of the Zoho Writer document. |
