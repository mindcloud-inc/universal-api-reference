# List Scheduled Sends with ZAP POST

Retrieves scheduled sends from ZAP POST.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ScheduledSends`
- **Base URL:** `https://api.zappost.com`
- **Official documentation:** [List Scheduled Sends](https://apidocumentation.zappost.com/api-endpoints/scheduledsends)
