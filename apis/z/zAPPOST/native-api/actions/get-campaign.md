# Get Campaign with ZAP POST

Retrieves a specific campaign from ZAP POST.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaign/:campaignId`
- **Base URL:** `https://api.zappost.com`
- **Official documentation:** [Get Campaign](https://apidocumentation.zappost.com/api-endpoints/campaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | The campaign UUID to retrieve. |
