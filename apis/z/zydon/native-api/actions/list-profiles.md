# List Profiles with Zydon

Retrieves profile records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Profiles](https://docs.zydon.com.br/cadastros-gerais/profiles)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
