# List Variations with Zydon

Retrieves variation records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/variations`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Variations](https://docs.zydon.com.br/produtos/variations)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
