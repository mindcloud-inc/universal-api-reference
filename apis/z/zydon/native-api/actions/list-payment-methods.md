# List Payment Methods with Zydon

Retrieves payment methods from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-methods`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Payment Methods](https://docs.zydon.com.br/pedidos/payment-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
