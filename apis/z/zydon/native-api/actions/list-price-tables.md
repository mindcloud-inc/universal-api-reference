# List Price Tables with Zydon

Retrieves price tables from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/price-tables`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Price Tables](https://docs.zydon.com.br/produtos/price-tables)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
