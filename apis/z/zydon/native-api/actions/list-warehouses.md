# List Warehouses with Zydon

Retrieves warehouse records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/warehouses`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Warehouses](https://docs.zydon.com.br/produtos/warehouses)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
