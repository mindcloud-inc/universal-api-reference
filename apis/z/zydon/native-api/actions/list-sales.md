# List Sales with Zydon

Retrieves sales records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Sales](https://docs.zydon.com.br/pedidos/sales)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
