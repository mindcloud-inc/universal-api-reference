# List Measure Units with Zydon

Retrieves measure units from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/measure-units`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Measure Units](https://docs.zydon.com.br/produtos/measure-units)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
