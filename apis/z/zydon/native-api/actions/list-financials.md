# List Financials with Zydon

Retrieves financial records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/financials`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Financials](https://docs.zydon.com.br/financeiro/financials)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
