# Get Payment Method with Zydon

Retrieves payment method details from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-methods/{id}`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [Get Payment Method](https://docs.zydon.com.br/pedidos/payment-methods)
