# List Partners with Zydon

Retrieves partner records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/partners`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Partners](https://docs.zydon.com.br/cadastros-gerais/partners)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
