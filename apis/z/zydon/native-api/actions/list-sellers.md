# List Sellers with Zydon

Retrieves seller records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/sellers`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Sellers](https://docs.zydon.com.br/cadastros-gerais/sellers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
