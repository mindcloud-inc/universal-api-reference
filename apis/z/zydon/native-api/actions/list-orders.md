# List Orders with Zydon

Retrieves order records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Orders](https://docs.zydon.com.br/pedidos/orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
