# List Categories with Zydon

Retrieves category records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Categories](https://docs.zydon.com.br/produtos/categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
