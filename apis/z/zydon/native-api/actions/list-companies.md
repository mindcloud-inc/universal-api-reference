# List Companies with Zydon

Retrieves company records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Companies](https://docs.zydon.com.br/cadastros-gerais/companies)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
