# List Brands with Zydon

Retrieves brand records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Brands](https://docs.zydon.com.br/produtos/brands)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
