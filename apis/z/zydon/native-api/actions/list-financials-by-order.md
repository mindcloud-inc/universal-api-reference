# List Financials By Order with Zydon

Retrieves financial records for an order from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/financials/order/{orderId}`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Financials By Order](https://docs.zydon.com.br/financeiro/financials/order)
