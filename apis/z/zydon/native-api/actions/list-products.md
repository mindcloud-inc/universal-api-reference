# List Products with Zydon

Retrieves product records from Zydon.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.zydon.com.br/api/sales`
- **Official documentation:** [List Products](https://docs.zydon.com.br/produtos/products)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
