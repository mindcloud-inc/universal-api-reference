# Create Shipment Order with Zoho Inventory

Creates a new shipment order in Zoho Inventory.

## Endpoint

- **Method:** `POST`
- **Path:** `/shipmentorders`
- **Base URL:** `{api_domain}/inventory/v1`
- **Official documentation:** [Create Shipment Order](https://www.zoho.com/inventory/api/v1/shipmentorders/#create-a-shipment-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | query | `string` | yes | Zoho Inventory organization ID to run this request against. |
| `package_ids` | query | `string<string>` | no | Comma-separated package IDs to ship. |
| `salesorder_id` | query | `string` | yes | Unique ID generated by the server for the Sales Order. This is required when creating a shipment order. |
| `shipment_number` | body | `string` | yes | — |
| `date` | body | `string` | yes | — |
| `reference_number` | body | `string` | no | — |
| `contact_persons[]` | body | `array<string>` | no | Array of contact person IDs. |
| `delivery_method` | body | `string` | yes | — |
| `tracking_number` | body | `string` | yes | — |
| `shipping_charge` | body | `number` | no | — |
| `notes` | body | `string` | no | — |
