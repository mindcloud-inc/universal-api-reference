# List Contacts with Zoho Inventory

Retrieves contacts from Zoho Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `{api_domain}/inventory/v1`
- **Official documentation:** [List Contacts](https://www.zoho.com/inventory/api/v1/contacts/#list-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | query | `string` | yes | The Zoho Inventory organization_id for the request. |
