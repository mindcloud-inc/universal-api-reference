# List Items with Zoho Inventory

Retrieves items from Zoho Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/items`
- **Base URL:** `{api_domain}/inventory/v1`
- **Official documentation:** [List Items](https://www.zoho.com/inventory/api/v1/items/#list-all-the-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | query | `string` | yes | Zoho Inventory organization ID to run this request against. |
