# List Packages with Zoho Inventory

Retrieves packages from Zoho Inventory.

## Endpoint

- **Method:** `GET`
- **Path:** `/packages`
- **Base URL:** `{api_domain}/inventory/v1`
- **Official documentation:** [List Packages](https://www.zoho.com/inventory/api/v1/packages/#list-all-packages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | query | `string` | yes | Zoho Inventory organization ID to run this request against. |
