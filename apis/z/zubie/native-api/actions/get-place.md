# Get Place with Zubie

Retrieves a place from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/place/{place_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Place](https://developer.zubie.com/reference/places)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `place_key` | path | `string` | yes | Unique place key. |
