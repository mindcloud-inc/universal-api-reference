# Create Group with Zubie

Creates a group in Zubie.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Create Group](https://developer.zubie.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The group name. |
