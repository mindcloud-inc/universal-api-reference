# Update Vehicle with Zubie

Updates an existing vehicle in Zubie.

## Endpoint

- **Method:** `POST`
- **Path:** `/vehicle/{vehicle_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Update Vehicle](https://developer.zubie.com/reference/vehicles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicle_key` | path | `string` | yes | Unique vehicle key. |
