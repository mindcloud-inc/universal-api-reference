# Update User with Zubie

Updates an existing user in Zubie.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/{user_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Update User](https://developer.zubie.com/reference/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_key` | path | `string` | yes | Unique user key. |
