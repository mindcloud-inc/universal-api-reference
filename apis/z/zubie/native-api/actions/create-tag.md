# Create Tag with Zubie

Creates a tag in Zubie.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Create Tag](https://developer.zubie.com/reference/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | yes | Tag label value. |
