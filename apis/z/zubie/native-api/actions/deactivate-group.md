# Deactivate Group with Zubie

Deactivates a group in Zubie.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/group/{group_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Deactivate Group](https://developer.zubie.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_key` | path | `string` | yes | Unique group key. |
