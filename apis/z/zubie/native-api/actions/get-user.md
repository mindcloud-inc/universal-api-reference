# Get User with Zubie

Retrieves a user from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/{user_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get User](https://developer.zubie.com/reference/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_key` | path | `string` | yes | Unique user key. |
