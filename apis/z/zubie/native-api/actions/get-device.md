# Get Device with Zubie

Retrieves a device from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/device/{key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Device](https://developer.zubie.com/reference/devices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | Unique device key. |
