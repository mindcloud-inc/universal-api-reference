# List Events By Type with Zubie

Retrieves events by type from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [List Events By Type](https://developer.zubie.com/reference/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event` | query | `string` | yes | Event type to filter. |
