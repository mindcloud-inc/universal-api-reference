# Fetch Media File with Zubie

Retrieves a media file from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/{media_key}/fetch`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Fetch Media File](https://developer.zubie.com/reference/media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `media_key` | path | `string` | yes | Unique media entity key. |
