# Get Group with Zubie

Retrieves a group from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/group/{group_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Group](https://developer.zubie.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_key` | path | `string` | yes | Unique group key. |
