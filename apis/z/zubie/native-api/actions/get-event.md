# Get Event with Zubie

Retrieves an event from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/{event_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Event](https://developer.zubie.com/reference/events)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_key` | path | `string` | yes | Unique event key. |
