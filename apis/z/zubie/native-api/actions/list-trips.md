# List Trips with Zubie

Retrieves trips from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/trips`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [List Trips](https://developer.zubie.com/reference/trips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicle_key` | query | `string` | no | Filter results to a single vehicle. |
