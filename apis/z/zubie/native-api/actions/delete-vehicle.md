# Delete Vehicle with Zubie

Deletes a vehicle from Zubie.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/vehicle/{vehicle_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Delete Vehicle](https://developer.zubie.com/reference/vehicles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicle_key` | path | `string` | yes | Unique vehicle key. |
