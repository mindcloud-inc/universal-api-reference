# Get Tag with Zubie

Retrieves a tag from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/{tag_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Tag](https://developer.zubie.com/reference/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_key` | path | `string` | yes | Unique tag key. |
