# Get Media Metadata with Zubie

Retrieves media metadata from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/{media_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Media Metadata](https://developer.zubie.com/reference/media)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `media_key` | path | `string` | yes | Unique media entity key. |
