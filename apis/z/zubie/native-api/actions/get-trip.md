# Get Trip with Zubie

Retrieves a trip from Zubie.

## Endpoint

- **Method:** `GET`
- **Path:** `/trip/{trip_key}`
- **Base URL:** `https://api.zubiecar.com/api/v2/zinc`
- **Official documentation:** [Get Trip](https://developer.zubie.com/reference/trips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trip_key` | path | `string` | yes | Unique trip key. |
