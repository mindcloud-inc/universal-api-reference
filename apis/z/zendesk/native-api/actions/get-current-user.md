# Get Current User with Zendesk

Retrieves the current user from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [Get Current User](https://developer.zendesk.com/api-reference/ticketing/users/users/#show-self)
