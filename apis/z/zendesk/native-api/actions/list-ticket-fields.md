# List Ticket Fields with Zendesk

Retrieves a list of Zendesk ticket fields.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_fields.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Ticket Fields](https://developer.zendesk.com/api-reference/ticketing/tickets/ticket_fields/#list-ticket-fields)

## Capabilities

This operation supports [pagination](../README.md#pagination).
