# List Views with Zendesk

Retrieves a list of views from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/views.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Views](https://developer.zendesk.com/api-reference/ticketing/business-rules/views/#list-views)

## Capabilities

This operation supports [pagination](../README.md#pagination).
