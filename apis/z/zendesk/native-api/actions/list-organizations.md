# List Organizations with Zendesk

Retrieves a list of organizations from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Organizations](https://developer.zendesk.com/api-reference/ticketing/organizations/organizations/#list-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
