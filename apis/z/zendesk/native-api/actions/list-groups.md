# List Groups with Zendesk

Retrieves a list of groups from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Groups](https://developer.zendesk.com/api-reference/ticketing/groups/groups/#list-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
