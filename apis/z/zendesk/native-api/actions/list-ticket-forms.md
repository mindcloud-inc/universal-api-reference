# List Ticket Forms with Zendesk

Retrieves a list of Zendesk ticket forms.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_forms.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Ticket Forms](https://developer.zendesk.com/api-reference/ticketing/tickets/ticket_forms/#list-ticket-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination).
