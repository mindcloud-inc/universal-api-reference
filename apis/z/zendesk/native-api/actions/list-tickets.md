# List Tickets with Zendesk

Retrieves a list of tickets from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Tickets](https://developer.zendesk.com/api-reference/ticketing/tickets/tickets/#list-tickets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
