# List Users with Zendesk

Retrieves a list of users from Zendesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/users.json`
- **Base URL:** `https://{subdomain}.zendesk.com/api/v2`
- **Official documentation:** [List Users](https://developer.zendesk.com/api-reference/ticketing/users/users/#show-many-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
