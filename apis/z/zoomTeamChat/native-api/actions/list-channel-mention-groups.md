# List Channel Mention Groups with Zoom Team Chat

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/channels/:channelId/mention_group`
- **Base URL:** `https://api.zoom.us/v2`
- **Official documentation:** [List Channel Mention Groups](https://developers.zoom.us/docs/api/rest/reference/chat/methods/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The channel ID. |
