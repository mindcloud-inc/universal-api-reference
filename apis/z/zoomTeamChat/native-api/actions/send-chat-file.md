# Send Chat File with Zoom Team Chat

## Endpoint

- **Method:** `POST`
- **Path:** `https://file.zoom.us/v2/chat/users/:userId/messages/files`
- **Base URL:** `https://api.zoom.us/v2`
- **Official documentation:** [Send Chat File](https://developers.zoom.us/docs/api/rest/reference/chat/methods/#operation/sendChatFile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user's ID. |
