# List Shared Spaces with Zoom Team Chat

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/spaces`
- **Base URL:** `https://api.zoom.us/v2`
- **Official documentation:** [List Shared Spaces](https://developers.zoom.us/docs/api/rest/reference/chat/methods/#operation/listSharedSpaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | query | `string` | no | The user ID or email address of the user. |
