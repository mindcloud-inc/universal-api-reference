# Create Shared Space with Zoom Team Chat

## Endpoint

- **Method:** `POST`
- **Path:** `/chat/spaces`
- **Base URL:** `https://api.zoom.us/v2`
- **Official documentation:** [Create Shared Space](https://developers.zoom.us/docs/api/rest/reference/chat/methods/#operation/createSpace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The shared space name. |
