# Get Shared Space with Zoom Team Chat

## Endpoint

- **Method:** `GET`
- **Path:** `/chat/spaces/:spaceId`
- **Base URL:** `https://api.zoom.us/v2`
- **Official documentation:** [Get Shared Space](https://developers.zoom.us/docs/api/rest/reference/chat/methods/#operation/getASharedSpace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | The space's ID. |
