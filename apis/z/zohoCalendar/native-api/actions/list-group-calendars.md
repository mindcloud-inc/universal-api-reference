# List Group Calendars with Zoho Calendar

Retrieves group calendars from Zoho Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [List Group Calendars](https://www.zoho.com/calendar/help/api/get-group-calendar-list.html)
