# Update Notification Details with Zoho Calendar

Updates notification details in Zoho Calendar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notification`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Update Notification Details](https://www.zoho.com/calendar/help/api/put-update-notification-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification` | query | `object` | yes | Notification payload object with the notification settings to update. |
