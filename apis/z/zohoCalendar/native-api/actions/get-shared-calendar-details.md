# Get Shared Calendar Details with Zoho Calendar

Retrieves details for a shared calendar in Zoho Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:calendaruid/share`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Get Shared Calendar Details](https://www.zoho.com/calendar/help/api/get-shared-calendar-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendaruid` | path | `string` | yes | Calendar unique identifier for the shared calendar. |
