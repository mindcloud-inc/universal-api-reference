# Delete Calendar with Zoho Calendar

Deletes an existing calendar from Zoho Calendar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendars/:calendaruid`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Delete Calendar](https://www.zoho.com/calendar/help/api/delete-calendar.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendaruid` | path | `string` | yes | Calendar unique identifier. |
