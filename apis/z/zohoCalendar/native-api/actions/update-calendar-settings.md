# Update Calendar Settings with Zoho Calendar

Updates calendar settings in Zoho Calendar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/settings`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Update Calendar Settings](https://www.zoho.com/calendar/help/api/put-update-calendar-settings.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settingsdata` | query | `object` | yes | Settings payload object with the calendar settings to update. |
