# Get Calendar Details with Zoho Calendar

Retrieves details for a calendar in Zoho Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:calendaruid`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Get Calendar Details](https://www.zoho.com/calendar/help/api/get-calendar-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `calendaruid` | path | `string` | yes | Calendar unique identifier. You can also use default or primary. |
