# Get Notification Details with Zoho Calendar

Retrieves notification details from Zoho Calendar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notification`
- **Base URL:** `https://calendar.zoho.com/api/v1`
- **Official documentation:** [Get Notification Details](https://www.zoho.com/calendar/help/api/get-notification-details.html)
