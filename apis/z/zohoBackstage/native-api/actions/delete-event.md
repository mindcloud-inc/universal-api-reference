# Delete Event with Zoho Backstage

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/portals/:portal_id/events/:event_id`
- **Base URL:** `https://zohoapis.com/backstage`
- **Official documentation:** [Delete Event](https://www.zoho.com/backstage/api/v3/delete-an-event.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portal_id` | path | `string` | yes | The Zoho Backstage portal ID. |
| `event_id` | path | `string` | yes | The Zoho Backstage event ID. |
