# Get Database by ID with Zite

Retrieves a specific database from Zite by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/bases/:databaseId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Get Database by ID](https://fillout.com/help/database/get-database-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `databaseId` | path | `string` | yes |
