# Delete Webhook with Zite

Deletes an existing webhook from a Zite database.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bases/:databaseId/webhooks/:webhookId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Delete Webhook](https://fillout.com/help/database/delete-webhook)
