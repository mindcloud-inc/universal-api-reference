# Delete Field with Zite

Deletes an existing field from a Zite table.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bases/:databaseId/tables/:tableId/fields/:fieldId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Delete Field](https://fillout.com/help/database/delete-field)
