# Update Record with Zite

Updates an existing record in a Zite table.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/bases/:databaseId/tables/:tableId/records/:recordId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Update Record](https://fillout.com/help/database/update-record)
