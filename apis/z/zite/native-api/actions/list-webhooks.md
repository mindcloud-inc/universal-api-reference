# List Webhooks with Zite

Retrieves webhook subscriptions for a Zite database.

## Endpoint

- **Method:** `GET`
- **Path:** `/bases/:databaseId/webhooks`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [List Webhooks](https://fillout.com/help/database/list-webhooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `databaseId` | path | `string` | yes |
