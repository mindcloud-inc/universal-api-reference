# Update Field with Zite

Updates an existing field in a Zite table.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/bases/:databaseId/tables/:tableId/fields/:fieldId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Update Field](https://fillout.com/help/database/update-field)
