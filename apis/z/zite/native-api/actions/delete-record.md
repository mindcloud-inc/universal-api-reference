# Delete Record with Zite

Deletes an existing record from a Zite table.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bases/:databaseId/tables/:tableId/records/:recordId`
- **Base URL:** `https://tables.fillout.com/api/v1`
- **Official documentation:** [Delete Record](https://fillout.com/help/database/delete-record)
