# Get OAuth User Info with Zoho Survey

Retrieves connected Zoho account user info for Zoho Survey.

## Endpoint

- **Method:** `GET`
- **Path:** `{{credentials.authorizeRequest.["accounts-server"]}}/oauth/user/info`
- **Base URL:** `https://survey.zoho.com/api/v1/external-private`
- **Official documentation:** [Get OAuth User Info](https://www.zoho.com/accounts/protocol/oauth/use-access-token.html)
