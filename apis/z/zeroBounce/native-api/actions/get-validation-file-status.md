# Get Validation File Status with ZeroBounce

Retrieves a bulk validation file status from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/v2/filestatus`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Get Validation File Status](https://www.zerobounce.net/docs/email-validation-api-quickstart/v2-file-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
