# Bulk Find Email Get File with ZeroBounce

Retrieves a bulk email finder file from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/email-finder/getfile`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Bulk Find Email Get File](https://www.zerobounce.net/docs/email-finder-api/bulk-email-finder-api/bulk-get-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
