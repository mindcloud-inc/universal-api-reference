# Bulk Domain Search File Status with ZeroBounce

Retrieves a bulk domain search file status from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/domain-search/filestatus`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Bulk Domain Search File Status](https://www.zerobounce.net/docs/domain-search-api/bulk-domain-search-api/file-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
