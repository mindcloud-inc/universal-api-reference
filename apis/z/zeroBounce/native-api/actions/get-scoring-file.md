# Get Scoring File with ZeroBounce

Retrieves a bulk scoring file from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/v2/scoring/getfile`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Get Scoring File](https://www.zerobounce.net/docs/ai-scoring-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
