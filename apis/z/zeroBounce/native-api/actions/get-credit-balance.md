# Get Credit Balance with ZeroBounce

Retrieves credit balance details from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/getcredits`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Get Credit Balance](https://www.zerobounce.net/docs/email-validation-api-quickstart/v2-credit-balance)
