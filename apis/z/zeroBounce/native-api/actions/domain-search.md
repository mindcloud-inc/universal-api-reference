# Domain Search with ZeroBounce

Finds company email patterns in ZeroBounce by domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/guessformat`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Domain Search](https://www.zerobounce.net/docs/domain-search-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | no |
| `company_name` | query | `string` | no |
