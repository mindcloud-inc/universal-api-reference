# Bulk Domain Search Get File with ZeroBounce

Retrieves a bulk domain search file from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/domain-search/getfile`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Bulk Domain Search Get File](https://www.zerobounce.net/docs/domain-search-api/bulk-domain-search-api/get-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
