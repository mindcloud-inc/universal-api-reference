# Get Evaluated List Status with ZeroBounce

Retrieves a list evaluation status from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/v2/listevaluator/:file_id/`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Get Evaluated List Status](https://www.zerobounce.net/docs/list-evaluator-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
