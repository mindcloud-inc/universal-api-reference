# Bulk Find Email File Status with ZeroBounce

Retrieves a bulk email finder file status from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `https://bulkapi.zerobounce.net/email-finder/filestatus`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Bulk Find Email File Status](https://www.zerobounce.net/docs/email-finder-api/bulk-email-finder-api/bulk-file-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | query | `string` | yes |
