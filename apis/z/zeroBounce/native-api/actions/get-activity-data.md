# Get Activity Data with ZeroBounce

Retrieves activity data for an email from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/activity`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Get Activity Data](https://www.zerobounce.net/docs/activity-data-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
