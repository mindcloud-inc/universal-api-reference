# Score Email with ZeroBounce

Retrieves an email score from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/scoring`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [Score Email](https://www.zerobounce.net/docs/ai-scoring-api/single-email-scoring)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | query | `string` | yes |
