# List Validation Filters with ZeroBounce

Retrieves custom validation filters from ZeroBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/filters/list`
- **Base URL:** `https://api.zerobounce.net`
- **Official documentation:** [List Validation Filters](https://www.zerobounce.net/docs/email-validation-api-quickstart/v2-allowlist-and-blocklist)
