# Get Guest Details with Zenoti

## Endpoint

- **Method:** `GET`
- **Path:** `guests/:guestId`
- **Base URL:** `https://api.zenoti.com/v1/`
- **Official documentation:** [Get Guest Details](https://docs.zenoti.com/reference/retrieve-guest-details)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `guestId` | path | `string` | yes |
