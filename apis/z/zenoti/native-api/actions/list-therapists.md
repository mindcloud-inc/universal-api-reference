# List Therapists with Zenoti

## Endpoint

- **Method:** `GET`
- **Path:** `centers/:centerId/therapists`
- **Base URL:** `https://api.zenoti.com/v1/`
- **Official documentation:** [List Therapists](https://docs.zenoti.com/reference/list-all-therapists-of-a-center)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `centerId` | path | `list` | no |
