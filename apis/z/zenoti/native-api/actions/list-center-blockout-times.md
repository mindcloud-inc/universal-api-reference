# List Center Blockout Times with Zenoti

## Endpoint

- **Method:** `GET`
- **Path:** `centers/:centerId/blockouttimes`
- **Base URL:** `https://api.zenoti.com/v1/`
- **Official documentation:** [List Center Blockout Times](https://docs.zenoti.com/reference/list-all-blockout-times-of-a-center)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `start_date` | query | `date` | no |
| `end_date` | query | `date` | no |
| `centerId` | path | `list` | no |
