# Get Invoice with Zoho Books

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://www.zohoapis.com/books/v3`
- **Official documentation:** [Get Invoice](https://www.zoho.com/books/api/v3/invoices/#get-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes | Unique identifier of the invoice. |
