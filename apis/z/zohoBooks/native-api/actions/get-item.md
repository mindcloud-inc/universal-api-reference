# Get Item with Zoho Books

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:item_id`
- **Base URL:** `https://www.zohoapis.com/books/v3`
- **Official documentation:** [Get Item](https://www.zoho.com/books/api/v3/items/#get-an-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `list<string>` | yes | Unique identifier of the item. |
| `organization_id` | query | `list<string>` | yes | ID of the organization. |
