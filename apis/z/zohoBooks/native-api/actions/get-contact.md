# Get Contact with Zoho Books

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://www.zohoapis.com/books/v3`
- **Official documentation:** [Get Contact](https://www.zoho.com/books/api/v3/contacts/#get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Unique identifier of the contact. |
