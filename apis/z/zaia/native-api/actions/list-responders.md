# List Responders with Zaia

Retrieves responder identities from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/super-identities/responders`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Responders](https://docs.zaia.app/documentation/api-reference-alpha/reference/super-identities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
