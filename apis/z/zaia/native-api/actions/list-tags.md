# List Tags with Zaia

Retrieves tags from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tags`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Tags](https://docs.zaia.app/documentation/api-reference-alpha/reference/tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
