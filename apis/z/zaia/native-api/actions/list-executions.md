# List Executions with Zaia

Retrieves executions from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/executions`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Executions](https://docs.zaia.app/documentation/api-reference-alpha/reference/executions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
