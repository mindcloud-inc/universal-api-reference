# List Datagrids with Zaia

Retrieves datagrids from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datagrids`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Datagrids](https://docs.zaia.app/documentation/api-reference-alpha/reference/datagrids)

## Capabilities

This operation supports [pagination](../README.md#pagination).
