# Delete Tag with Zaia

Deletes an existing tag from Zaia.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/tags/:id`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [Delete Tag](https://docs.zaia.app/documentation/api-reference-alpha/reference/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The UUID of the tag to remove. |
