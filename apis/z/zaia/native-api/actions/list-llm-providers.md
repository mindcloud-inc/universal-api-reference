# List LLM Providers with Zaia

Retrieves LLM providers from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/llm-providers`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List LLM Providers](https://docs.zaia.app/documentation/api-reference-alpha/reference/llm-providers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
