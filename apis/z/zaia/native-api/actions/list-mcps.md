# List MCPs with Zaia

Retrieves MCPs from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mcps`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List MCPs](https://docs.zaia.app/documentation/api-reference-alpha/reference/mcps)

## Capabilities

This operation supports [pagination](../README.md#pagination).
