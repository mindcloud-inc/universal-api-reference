# List LLM Provider Options with Zaia

Retrieves LLM provider options from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/llm-providers/options`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List LLM Provider Options](https://docs.zaia.app/documentation/api-reference-alpha/reference/llm-providers)
