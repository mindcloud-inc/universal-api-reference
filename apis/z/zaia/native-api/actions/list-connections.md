# List Connections with Zaia

Retrieves connections from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/connections`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Connections](https://docs.zaia.app/documentation/api-reference-alpha/reference/connections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
