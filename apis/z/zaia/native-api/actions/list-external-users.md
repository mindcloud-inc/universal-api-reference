# List External Users with Zaia

Retrieves external users from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/external-users`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List External Users](https://docs.zaia.app/documentation/api-reference-alpha/reference/external-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
