# List MCP Options with Zaia

Retrieves MCP options from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/mcps/options`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List MCP Options](https://docs.zaia.app/documentation/api-reference-alpha/reference/mcps)
