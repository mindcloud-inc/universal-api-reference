# List Squads with Zaia

Retrieves squads from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/squads`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Squads](https://docs.zaia.app/documentation/api-reference-alpha/reference/squads)

## Capabilities

This operation supports [pagination](../README.md#pagination).
