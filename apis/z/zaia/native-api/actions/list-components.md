# List Components with Zaia

Retrieves components from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/components`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Components](https://docs.zaia.app/documentation/api-reference-alpha/reference/components)

## Capabilities

This operation supports [pagination](../README.md#pagination).
