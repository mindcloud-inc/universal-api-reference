# List Datasets with Zaia

Retrieves datasets from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/datasets`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Datasets](https://docs.zaia.app/documentation/api-reference-alpha/reference/datasets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
