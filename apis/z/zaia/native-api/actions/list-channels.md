# List Channels with Zaia

Retrieves channels from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/channels`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Channels](https://docs.zaia.app/documentation/api-reference-alpha/reference/channels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
