# Get Tag with Zaia

Retrieves a tag from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tags/:id`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [Get Tag](https://docs.zaia.app/documentation/api-reference-alpha/reference/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The UUID of the tag to retrieve. |
