# List Ticketing Teams with Zaia

Retrieves ticketing teams from your Zaia workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ticketing-teams`
- **Base URL:** `https://api.endless.zaia.app`
- **Official documentation:** [List Ticketing Teams](https://docs.zaia.app/documentation/api-reference-alpha/reference/ticketing-teams)

## Capabilities

This operation supports [pagination](../README.md#pagination).
