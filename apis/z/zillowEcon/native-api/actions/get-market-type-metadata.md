# Get market type metadata with Zillow Econ

Retrieves market type metadata from Zillow Econ.

## Endpoint

- **Method:** `GET`
- **Path:** `/zgecon/type`
- **Base URL:** `https://api.bridgedataoutput.com/api/v2`
- **Official documentation:** [Get market type metadata](https://bridgedataoutput.com/docs/explorer/zillow-group-econ-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | query | `string` | yes | Metric type key used to retrieve economic metadata for a report metric. |
