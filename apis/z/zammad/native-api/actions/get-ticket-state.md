# Get Ticket State with Zammad

Retrieves a ticket state from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_states/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Get Ticket State](https://docs.zammad.org/en/latest/api/ticket/states.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Ticket state identifier. |
