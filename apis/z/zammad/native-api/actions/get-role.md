# Get Role with Zammad

Retrieves a role from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Get Role](https://docs.zammad.org/en/latest/api/role.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Role ID. |
