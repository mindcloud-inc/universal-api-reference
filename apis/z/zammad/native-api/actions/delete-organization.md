# Delete Organization with Zammad

Deletes an existing organization from Zammad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organizations/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Delete Organization](https://docs.zammad.org/en/latest/api/organization.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Organization ID. |
