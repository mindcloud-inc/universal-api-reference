# Get Ticket Priority with Zammad

Retrieves a ticket priority from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_priorities/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Get Ticket Priority](https://docs.zammad.org/en/latest/api/ticket/priorities.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Ticket priority identifier. |
