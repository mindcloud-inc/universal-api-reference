# Delete Group with Zammad

Deletes an existing group from Zammad.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Delete Group](https://docs.zammad.org/en/latest/api/group.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group ID. |
