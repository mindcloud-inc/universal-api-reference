# Create Group with Zammad

Creates a new group in Zammad.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Create Group](https://docs.zammad.org/en/latest/api/group.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Group name. |
