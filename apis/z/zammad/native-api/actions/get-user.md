# Get User with Zammad

Retrieves a user from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Get User](https://docs.zammad.org/en/latest/api/user.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
