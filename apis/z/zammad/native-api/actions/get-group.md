# Get Group with Zammad

Retrieves a group from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Get Group](https://docs.zammad.org/en/latest/api/group.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group ID. |
