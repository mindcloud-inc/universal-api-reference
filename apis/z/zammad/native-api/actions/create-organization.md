# Create Organization with Zammad

Creates a new organization in Zammad.

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Create Organization](https://docs.zammad.org/en/latest/api/organization.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Organization name. |
