# Create Role with Zammad

Creates a new role in Zammad.

## Endpoint

- **Method:** `POST`
- **Path:** `/roles`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [Create Role](https://docs.zammad.org/en/latest/api/role.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Role name. |
