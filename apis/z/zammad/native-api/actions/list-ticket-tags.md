# List Ticket Tags with Zammad

Retrieves ticket tags from Zammad.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `{baseUrl}/api/v1`
- **Official documentation:** [List Ticket Tags](https://docs.zammad.org/en/latest/api/ticket/tags.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `o_id` | query | `number` | yes | Ticket identifier. |
