# Delete File with zipBoard

Deletes an existing file from zipBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:id`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Delete File](https://help.zipboard.co/article/179-api-for-files-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | File record ID to delete. |
