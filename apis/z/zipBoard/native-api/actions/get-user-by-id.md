# Get User by ID with zipBoard

Retrieves a user by ID from zipBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:id`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Get User by ID](https://docs.zipboard.co/#tag/Users/paths/~1api~1v1~1user~1{id}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `projectid` | query | `string` | no |
