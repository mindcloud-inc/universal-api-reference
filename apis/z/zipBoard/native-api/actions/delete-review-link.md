# Delete Review Link with zipBoard

Deletes an existing review link from zipBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shareurl/:id`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Delete Review Link](https://help.zipboard.co/article/180-api-for-review-links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Review link token ID to delete. |
