# Get User with zipBoard

Retrieves user details from zipBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Get User](https://docs.zipboard.co/#tag/Users/paths/~1api~1v1~1user/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectid` | query | `string` | no |
