# Get Project Collaborators with zipBoard

Retrieves project collaborators from zipBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id/collaborators`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Get Project Collaborators](https://docs.zipboard.co/#tag/Collaborators/paths/~1api~1v1~1project~1{id}~1collaborators/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
