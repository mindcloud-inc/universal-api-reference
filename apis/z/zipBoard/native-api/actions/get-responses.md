# Get Responses with zipBoard

Retrieves responses from zipBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues/responses`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Get Responses](https://docs.zipboard.co/#tag/Responses/paths/~1api~1v1~1issues~1responses/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `route` | query | `string` | no |
| `taskid` | query | `string` | yes |
