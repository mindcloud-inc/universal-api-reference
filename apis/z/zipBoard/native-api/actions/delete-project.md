# Delete Project with zipBoard

Deletes an existing project from zipBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Delete Project](https://help.zipboard.co/article/178-api-for-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project record ID to delete. |
