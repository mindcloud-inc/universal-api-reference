# Delete Response with zipBoard

Deletes an existing response from zipBoard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/issues/responses/:id`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Delete Response](https://docs.zipboard.co/#tag/Responses/paths/~1api~1v1~1issues~1responses~1{id}/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
