# Get Organizations with zipBoard

Retrieves organizations from zipBoard.

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs`
- **Base URL:** `https://app.zipboard.co/api/v1`
- **Official documentation:** [Get Organizations](https://help.zipboard.co/article/237-api-for-organization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orgId` | query | `string` | no |
