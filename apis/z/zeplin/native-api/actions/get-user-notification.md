# Get User Notification with Zeplin

Retrieves an user notification from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/notifications/{notification_id}`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get User Notification](https://docs.zeplin.dev/reference/getusernotification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `notification_id` | path | `string` | yes | Notification id |
