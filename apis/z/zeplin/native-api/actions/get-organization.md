# Get Organization with Zeplin

Retrieves an organization from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get Organization](https://docs.zeplin.dev/reference/getorganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Organization id |
