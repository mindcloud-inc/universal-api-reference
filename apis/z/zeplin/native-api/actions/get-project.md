# Get Project with Zeplin

Retrieves a project from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get Project](https://docs.zeplin.dev/reference/getproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id |
