# Get Organization Billing with Zeplin

Retrieves organization billing details from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/billing`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get Organization Billing](https://docs.zeplin.dev/reference/getorganizationbilling)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Organization id |
