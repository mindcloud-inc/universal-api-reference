# List Organization Aliens with Zeplin

Retrieves a list of organization aliens from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{organization_id}/aliens`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [List Organization Aliens](https://docs.zeplin.dev/reference/getorganizationaliens)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Organization id |
