# Get Screen Section with Zeplin

Retrieves a screen section from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/screen_sections/{section_id}`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get Screen Section](https://docs.zeplin.dev/reference/getscreensection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id |
| `section_id` | path | `string` | yes | Screen section id |
