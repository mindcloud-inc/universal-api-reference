# Get Screen Variant with Zeplin

Retrieves a screen variant from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/screen_variants/{variant_id}`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [Get Screen Variant](https://docs.zeplin.dev/reference/getscreenvariant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id |
| `variant_id` | path | `string` | yes | Screen variant id |
