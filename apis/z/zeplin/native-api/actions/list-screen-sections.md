# List Screen Sections with Zeplin

Retrieves a list of screen sections from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/screen_sections`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [List Screen Sections](https://docs.zeplin.dev/reference/getscreensections)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id |
