# List Screen Annotation Note Types with Zeplin

Retrieves screen annotation note types from Zeplin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/annotations/note_types`
- **Base URL:** `https://api.zeplin.dev/v1`
- **Official documentation:** [List Screen Annotation Note Types](https://docs.zeplin.dev/reference/getscreenannotationsnotetypes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Project id |
