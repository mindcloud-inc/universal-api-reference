# List Exports with Zoho ZeptoMail

Retrieves log exports from Zoho ZeptoMail.

## Endpoint

- **Method:** `GET`
- **Path:** `:exportType/exports`
- **Base URL:** `https://api.zeptomail.com/v1.1`
- **Official documentation:** [List Exports](https://www.zoho.com/zeptomail/help/api/fetch-exports.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `exportType` | path | `string` | yes | Export category to list. |
