# Verify Domain with Zoho ZeptoMail

Verifies an existing domain in Zoho ZeptoMail.

## Endpoint

- **Method:** `PUT`
- **Path:** `domains/:domainKey/verify`
- **Base URL:** `https://api.zeptomail.com/v1.1`
- **Official documentation:** [Verify Domain](https://www.zoho.com/zeptomail/help/api/verify-domain.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainKey` | path | `string` | yes | Domain key from ZeptoMail. |
