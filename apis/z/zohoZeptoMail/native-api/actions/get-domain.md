# Get Domain with Zoho ZeptoMail

Retrieves domain details from Zoho ZeptoMail.

## Endpoint

- **Method:** `GET`
- **Path:** `domains/:domainKey`
- **Base URL:** `https://api.zeptomail.com/v1.1`
- **Official documentation:** [Get Domain](https://www.zoho.com/zeptomail/help/api/get-specific-domain.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domainKey` | path | `string` | yes | Domain key from ZeptoMail. |
