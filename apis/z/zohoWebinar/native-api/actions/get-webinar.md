# Get Webinar with Zoho Webinar

Retrieves webinar details from Zoho Webinar.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/:organizationId/webinar/:webinarKey.json`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [Get Webinar](https://www.zoho.com/webinar/api/webinar-api/get-webinar-details.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
| `webinarKey` | path | `string` | yes |
