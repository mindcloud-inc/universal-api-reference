# Delete Webinar with Zoho Webinar

Deletes an existing webinar from Zoho Webinar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/:organizationId/webinar/:webinarKey.json`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [Delete Webinar](https://www.zoho.com/webinar/api/webinar-api/delete-webinar.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
| `webinarKey` | path | `string` | yes |
