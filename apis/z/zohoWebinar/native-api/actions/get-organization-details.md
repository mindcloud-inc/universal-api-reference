# Get Organization Details with Zoho Webinar

Retrieves organization and user details from Zoho Webinar.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/user.json`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [Get Organization Details](https://www.zoho.com/webinar/api/organization-id.html)
