# List Time Zones with Zoho Webinar

Retrieves time zones from Zoho Webinar.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/timezone`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [List Time Zones](https://www.zoho.com/webinar/api/miscellaneous-api/list-of-time-zones.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `languageCode` | query | `string` | no |
