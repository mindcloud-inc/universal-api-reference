# List Recordings with Zoho Webinar

Retrieves recordings from Zoho Webinar by session type.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/:organizationId/recordings.json`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [List Recordings](https://www.zoho.com/webinar/api/recording-api/get-all-recordings.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
