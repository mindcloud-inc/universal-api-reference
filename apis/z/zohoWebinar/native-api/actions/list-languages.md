# List Languages with Zoho Webinar

Retrieves languages from Zoho Webinar.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/language`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [List Languages](https://www.zoho.com/webinar/api/miscellaneous-api/list-of-languages.html)
