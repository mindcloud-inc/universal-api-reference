# Get User with Zoho Webinar

Retrieves user details from Zoho Webinar.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/:organizationId/user/:userId`
- **Base URL:** `https://webinar.zoho.com`
- **Official documentation:** [Get User](https://www.zoho.com/webinar/api/user-api/get-user-details.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
| `userId` | path | `string` | yes |
