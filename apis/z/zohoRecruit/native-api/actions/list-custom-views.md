# List Custom Views with Zoho Recruit

Retrieves custom views from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/custom_views`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [List Custom Views](https://www.zoho.com/recruit/developer-guide/apiv2/custom-view-meta.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `module` | query | `string` | yes | The Zoho Recruit module API name whose custom views you want to list. |
