# Create Notes with Zoho Recruit

Creates new notes in Zoho Recruit.

## Endpoint

- **Method:** `POST`
- **Path:** `/Notes`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [Create Notes](https://www.zoho.com/recruit/developer-guide/apiv2/create-notes.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `list<object>` | yes | An array of note objects to create. |
