# Delete Note with Zoho Recruit

Deletes a note from Zoho Recruit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Notes/:noteId`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [Delete Note](https://www.zoho.com/recruit/developer-guide/apiv2/delete-notes.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The unique ID of the note. |
