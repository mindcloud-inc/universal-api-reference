# List Fields with Zoho Recruit

Retrieves field metadata from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/fields`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [List Fields](https://www.zoho.com/recruit/developer-guide/apiv2/field-meta.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `module` | query | `string` | yes | The Zoho Recruit module API name whose fields you want to list. |
