# Get Bulk Read Job Details with Zoho Recruit

Retrieves bulk read job details from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `https://recruit.zoho.com/recruit/bulk/v2/read/:jobId`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [Get Bulk Read Job Details](https://www.zoho.com/recruit/developer-guide/apiv2/bulk-read/job-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The unique ID of the bulk-read job. |
