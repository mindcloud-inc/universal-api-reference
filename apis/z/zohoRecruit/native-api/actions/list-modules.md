# List Modules with Zoho Recruit

Retrieves all modules from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/modules`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [List Modules](https://www.zoho.com/recruit/developer-guide/apiv2/modules-api.html)
