# Download Bulk Read Result with Zoho Recruit

Downloads a bulk read result from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `https://recruit.zoho.com/recruit/bulk/v2/read/:jobId/result`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [Download Bulk Read Result](https://www.zoho.com/recruit/developer-guide/apiv2/bulk-read/download-result.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The unique ID of the bulk-read job. |
