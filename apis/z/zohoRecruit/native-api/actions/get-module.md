# Get Module with Zoho Recruit

Retrieves a module from Zoho Recruit.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/modules/:moduleApiName`
- **Base URL:** `https://recruit.zoho.com/recruit/v2`
- **Official documentation:** [Get Module](https://www.zoho.com/recruit/developer-guide/apiv2/modules-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `moduleApiName` | path | `string` | yes | The Zoho Recruit module API name, for example Candidates or Job_Openings. |
