# List reviews with Zillow Agent Reviews

Retrieves agent reviews from Zillow Agent Reviews.

## Endpoint

- **Method:** `GET`
- **Path:** `/OData/reviews/Reviews`
- **Base URL:** `https://api.bridgedataoutput.com/api/v2`
- **Official documentation:** [List reviews](https://www.zillowgroup.com/developers/api/agents/agent-reviews/)
