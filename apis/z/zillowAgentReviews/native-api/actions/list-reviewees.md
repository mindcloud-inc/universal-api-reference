# List reviewees with Zillow Agent Reviews

Retrieves reviewees from Zillow Agent Reviews.

## Endpoint

- **Method:** `GET`
- **Path:** `/OData/reviews/Reviewees`
- **Base URL:** `https://api.bridgedataoutput.com/api/v2`
- **Official documentation:** [List reviewees](https://www.zillowgroup.com/developers/api/agents/agent-reviews/)
