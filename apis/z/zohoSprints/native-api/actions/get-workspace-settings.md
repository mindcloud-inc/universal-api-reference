# Get Workspace Settings with Zoho Sprints

Retrieves workspace settings from Zoho Sprints.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/:teamId/settings/`
- **Base URL:** `https://sprintsapi.zoho.com/zsapi`
- **Official documentation:** [Get Workspace Settings](https://sprints.zoho.com/apidoc.html#Getworkspacesettings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | path | `string` | yes |
