# Get Project Details with Zoho Sprints

Retrieves project details from Zoho Sprints.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/:teamId/projects/:projectId/`
- **Base URL:** `https://sprintsapi.zoho.com/zsapi`
- **Official documentation:** [Get Project Details](https://sprints.zoho.com/apidoc.html#Getprojectdetails)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | path | `string` | yes |
| `projectId` | path | `string` | yes |
