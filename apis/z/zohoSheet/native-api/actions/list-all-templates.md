# List All Templates with Zoho Sheet

Retrieves all templates from Zoho Sheet.

## Endpoint

- **Method:** `POST`
- **Path:** `/templates`
- **Base URL:** `https://sheet.zoho.com/api/v2/`
- **Official documentation:** [List All Templates](https://www.zoho.com/sheet/help/api/v2/#WORKBOOK-List-all-templates)
