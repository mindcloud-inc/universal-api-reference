# Get Current User Details with Zoho Meeting

Retrieves current user details from Zoho Meeting.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/user.json`
- **Base URL:** `https://meeting.zoho.com`
- **Official documentation:** [Get Current User Details](https://www.zoho.com/meeting/api-integration/organization-id.html)
