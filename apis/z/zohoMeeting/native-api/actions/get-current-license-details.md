# Get Current License Details with Zoho Meeting

Retrieves current license details from Zoho Meeting.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/:organizationId/license`
- **Base URL:** `https://meeting.zoho.com`
- **Official documentation:** [Get Current License Details](https://www.zoho.com/meeting/api-integration/license-api/get-license-details.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | Organization ID (zsoid) from Get Current User Details. |
