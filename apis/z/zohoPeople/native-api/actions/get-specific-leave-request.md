# Get Specific Leave Request with Zoho People

Retrieves a leave request from Zoho People.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/leave-tracker/leaves/:recordId`
- **Base URL:** `https://people.zoho.com`
- **Official documentation:** [Get Specific Leave Request](https://www.zoho.com/people/api/v3/leave-tracker/specificleave.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | Leave request record ID. |
