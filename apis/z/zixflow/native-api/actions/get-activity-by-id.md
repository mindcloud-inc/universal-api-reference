# Get Activity By ID with Zixflow

Retrieves an activity from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collection-records/activity-list/:activityId`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get Activity By ID](https://docs.zixflow.com/api-reference/activity-list/get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activityId` | path | `string` | yes | Activity identifier. |
