# Get List By ID with Zixflow

Retrieves a list from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get List By ID](https://docs.zixflow.com/api-reference/list/get-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | List identifier. |
