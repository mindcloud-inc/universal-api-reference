# Get Workspace Member By ID with Zixflow

Retrieves a workspace member from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace-members/:memberId`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get Workspace Member By ID](https://docs.zixflow.com/api-reference/workspace-members/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memberId` | path | `string` | yes | Workspace member identifier. |
