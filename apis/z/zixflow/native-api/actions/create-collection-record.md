# Create Collection Record with Zixflow

Creates a new collection record in Zixflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/collection-records/:collectionId`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Create Collection Record](https://docs.zixflow.com/api-reference/records/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Collection identifier. |
