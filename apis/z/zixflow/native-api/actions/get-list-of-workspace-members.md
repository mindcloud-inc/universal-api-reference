# Get List of Workspace Members with Zixflow

Retrieves workspace members from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace-members`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get List of Workspace Members](https://docs.zixflow.com/api-reference/workspace-members/get-list-of-members)
