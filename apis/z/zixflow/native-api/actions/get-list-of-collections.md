# Get List of Collections with Zixflow

Retrieves collections from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get List of Collections](https://docs.zixflow.com/api-reference/collection/get-list-of-collections)
