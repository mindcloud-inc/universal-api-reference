# Get Collection By ID with Zixflow

Retrieves a collection from Zixflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collectionId`
- **Base URL:** `https://api.zixflow.com/api/v1`
- **Official documentation:** [Get Collection By ID](https://docs.zixflow.com/api-reference/collection/get-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Collection identifier. |
