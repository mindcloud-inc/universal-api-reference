# List Tables with Zoho Tables

Retrieves all tables from Zoho Tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/tables`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [List Tables](https://tables.zoho.com/help/api/v1#TABLES-List-Tables)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `base_id` | query | `string` | yes |
