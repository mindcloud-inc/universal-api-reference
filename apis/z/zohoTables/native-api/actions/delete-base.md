# Delete Base with Zoho Tables

Deletes an existing base from Zoho Tables.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bases`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [Delete Base](https://tables.zoho.com/help/api/v1#BASES-Delete-Base)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `portal_id` | query | `number` | yes |
| `base_id` | query | `string` | yes |
