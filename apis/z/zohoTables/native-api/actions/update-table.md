# Update Table with Zoho Tables

Updates an existing table in Zoho Tables.

## Endpoint

- **Method:** `PUT`
- **Path:** `/tables`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [Update Table](https://tables.zoho.com/help/api/v1#TABLES-Update-Table)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `base_id` | query | `string` | yes |
| `table_id` | query | `string` | yes |
| `table_name` | query | `string` | no |
