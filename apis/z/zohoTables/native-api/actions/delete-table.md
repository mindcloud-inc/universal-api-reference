# Delete Table with Zoho Tables

Deletes an existing table from Zoho Tables.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tables`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [Delete Table](https://tables.zoho.com/help/api/v1#TABLES-Delete-Table)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `base_id` | query | `string` | yes |
| `table_id` | query | `string` | yes |
