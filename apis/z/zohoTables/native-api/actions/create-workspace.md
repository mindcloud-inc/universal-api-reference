# Create Workspace with Zoho Tables

Creates a new workspace in Zoho Tables.

## Endpoint

- **Method:** `POST`
- **Path:** `/workspaces`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [Create Workspace](https://tables.zoho.com/help/api/v1#WORKSPACES-Create-Workspace)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `portal_id` | query | `number` | yes |
| `workspace_name` | query | `string` | no |
