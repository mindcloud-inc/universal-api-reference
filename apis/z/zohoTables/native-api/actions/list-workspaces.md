# List Workspaces with Zoho Tables

Retrieves all workspaces from Zoho Tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [List Workspaces](https://tables.zoho.com/help/api/v1#WORKSPACES-List-Workspaces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portal_id` | query | `number` | yes | Portal ID |
