# List Base with Zoho Tables

Retrieves all bases from Zoho Tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/bases`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [List Base](https://tables.zoho.com/help/api/v1#BASES-List-Bases)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `portal_id` | query | `number` | yes | Portal ID |
| `workspace_id` | query | `string` | yes | Workspace ID |
