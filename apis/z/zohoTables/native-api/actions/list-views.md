# List Views with Zoho Tables

Retrieves all views from Zoho Tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/views`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [List Views](https://tables.zoho.com/help/api/v1#VIEWS-List-Views)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `base_id` | query | `string` | yes |
| `table_id` | query | `string` | yes |
