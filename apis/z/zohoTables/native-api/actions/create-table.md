# Create Table with Zoho Tables

Creates a new table in Zoho Tables.

## Endpoint

- **Method:** `POST`
- **Path:** `/tables`
- **Base URL:** `https://tables.zoho.com/api/v1`
- **Official documentation:** [Create Table](https://tables.zoho.com/help/api/v1#TABLES-Create-Table)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `base_id` | query | `string` | yes |
| `table_name` | query | `string` | no |
