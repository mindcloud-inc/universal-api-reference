# Get Workspace with Zenkit

Retrieves a workspace from Zenkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceAllId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Workspace](https://app.zenkit.com/docs/api/workspaces/get-api-v1-workspaces-workspaceallid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceAllId` | path | `string` | yes | The workspace AllID. |
