# Edit List Properties with Zenkit

Updates an existing list in Zenkit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lists/:listAllId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Edit List Properties](https://app.zenkit.com/docs/api/lists/put-api-v1-lists-listallid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listAllId` | path | `string` | yes | The list all id |
