# Get Users For List with Zenkit

Retrieves users for a Zenkit list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listAllId/users`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Users For List](https://app.zenkit.com/docs/api/lists/get-api-v1-lists-listallid-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listAllId` | path | `string` | yes | The list all id |
