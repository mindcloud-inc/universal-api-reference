# Update Workspace Details with Zenkit

Updates an existing workspace in Zenkit.

## Endpoint

- **Method:** `PUT`
- **Path:** `/workspaces/:workspaceAllId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Update Workspace Details](https://app.zenkit.com/docs/api/workspaces/put-api-v1-workspaces-workspaceallid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceAllId` | path | `string` | yes | The workspace all id. |
