# Get List with Zenkit

Retrieves a list from Zenkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listShortId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get List](https://app.zenkit.com/docs/api/lists/get-api-v1-lists-listshortid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listShortId` | path | `string` | yes | The list ShortID. |
