# Create Entry with Zenkit

Creates a new item in Zenkit.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/:listId/entries`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Create Entry](https://app.zenkit.com/docs/api/entries/post-api-v1-lists-listid-entries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | The list id |
