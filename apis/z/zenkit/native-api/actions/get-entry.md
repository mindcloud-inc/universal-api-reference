# Get Entry with Zenkit

Retrieves an item from Zenkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listAllId/entries/:listEntryAllId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Entry](https://app.zenkit.com/docs/api/entries/get-api-v1-lists-listallid-entries-listentryallid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listAllId` | path | `string` | yes | The list all id |
| `listEntryAllId` | path | `string` | yes | The list entry all id |
