# Deprecate Workspace with Zenkit

Deprecates an existing workspace in Zenkit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/:workspaceAllId`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Deprecate Workspace](https://app.zenkit.com/docs/api/workspaces/delete-api-v1-workspaces-workspaceallid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceAllId` | path | `string` | yes | The workspace all id. |
