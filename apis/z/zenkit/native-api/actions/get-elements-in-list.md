# Get Elements In List with Zenkit

Retrieves custom fields from a Zenkit list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listAllId/elements`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Elements In List](https://app.zenkit.com/docs/api/elements/get-api-v1-lists-listallid-elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listAllId` | path | `string` | yes | The list all id |
