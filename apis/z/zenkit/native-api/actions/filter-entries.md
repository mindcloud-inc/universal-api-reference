# Filter Entries with Zenkit

Retrieves filtered items from a Zenkit list.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/:listShortId/entries/filter`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Filter Entries](https://app.zenkit.com/docs/api/entries/post-api-v1-lists-listshortid-entries-filter)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listShortId` | path | `string` | yes | The list short id |
