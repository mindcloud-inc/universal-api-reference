# Get Workspaces And Lists with Zenkit

Retrieves workspaces and lists from Zenkit.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/workspacesWithLists`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Workspaces And Lists](https://app.zenkit.com/docs/api/workspaces/get-api-v1-users-me-workspaceswithlists)
