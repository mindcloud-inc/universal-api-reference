# Get Filtered Entries For List View with Zenkit

Retrieves filtered items for a Zenkit list view.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/:listShortId/entries/filter/list`
- **Base URL:** `https://zenkit.com/api/v1`
- **Official documentation:** [Get Filtered Entries For List View](https://app.zenkit.com/docs/api/entries/post-api-v1-lists-listshortid-entries-filter-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listShortId` | path | `string` | yes | The list short id |
