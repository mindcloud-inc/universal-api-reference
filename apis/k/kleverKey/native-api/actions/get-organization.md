# Get Organization with KleverKey

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organizations/:organizationId`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [Get Organization](https://portal.kleverkey.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID |
