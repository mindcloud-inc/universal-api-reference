# Get Invitation with KleverKey

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organizations/:organizationId/invitations/:id`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [Get Invitation](https://portal.kleverkey.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `number` | yes |
| `id` | path | `number` | yes |
