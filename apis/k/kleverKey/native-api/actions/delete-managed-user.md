# Delete Managed User with KleverKey

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/organizations/:organizationId/users/managed/:userId`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [Delete Managed User](https://portal.kleverkey.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `number` | yes |
| `userId` | path | `number` | yes |
