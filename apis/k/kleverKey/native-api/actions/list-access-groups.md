# List Access Groups with KleverKey

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organizations/:organizationId/access-groups`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [List Access Groups](https://portal.kleverkey.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID |
