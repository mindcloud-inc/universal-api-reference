# List Permissions with KleverKey

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organizations/:organizationId/permissions`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [List Permissions](https://portal.kleverkey.com/documentation/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | Organization ID |
