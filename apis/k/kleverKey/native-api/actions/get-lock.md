# Get Lock with KleverKey

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/organizations/:organizationId/locks/:lockId`
- **Base URL:** `https://api.kleverkey.com`
- **Official documentation:** [Get Lock](https://portal.kleverkey.com/documentation/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `number` | yes |
| `lockId` | path | `number` | yes |
