# Get Field with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_field`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Get Field](https://docs.koncile.ai/api-setup/fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | query | `string` | yes | The field identifier to fetch. |
