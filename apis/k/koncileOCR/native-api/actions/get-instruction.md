# Get Instruction with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_instruction`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Get Instruction](https://docs.koncile.ai/api-setup/instructions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instruction_id` | query | `string` | yes | The instruction identifier to fetch. |
