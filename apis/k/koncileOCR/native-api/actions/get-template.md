# Get Template with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_template`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Get Template](https://docs.koncile.ai/api-setup/templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | query | `string` | yes | The template identifier to fetch. |
