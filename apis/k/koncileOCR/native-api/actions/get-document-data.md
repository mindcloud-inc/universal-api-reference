# Get Document Data with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_document_data`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Get Document Data](https://docs.koncile.ai/api-setup/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | query | `string` | yes | The document identifier to fetch. |
