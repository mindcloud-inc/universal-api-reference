- **Path:** `/delete_field`
- **Base URL:** `https://api.koncile.ai/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | query | `string` | yes | The field identifier to delete. |
