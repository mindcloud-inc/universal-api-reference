- **Method:** `DELETE`
- **Path:** `/delete_instruction`
- **Base URL:** `https://api.koncile.ai/v1`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instruction_id` | query | `string` | yes | The instruction identifier to delete. |
