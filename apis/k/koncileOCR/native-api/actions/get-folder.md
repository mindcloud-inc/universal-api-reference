# Get Folder with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_folder`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Get Folder](https://docs.koncile.ai/api-setup/folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | query | `string` | yes | The ID of the folder to fetch. |
