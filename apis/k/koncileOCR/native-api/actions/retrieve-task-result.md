# Retrieve Task Result with Koncile OCR

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch_tasks_results`
- **Base URL:** `https://api.koncile.ai/v1`
- **Official documentation:** [Retrieve Task Result](https://docs.koncile.ai/api-setup/task-retrieval)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | query | `string` | yes | The task identifier to retrieve. |
