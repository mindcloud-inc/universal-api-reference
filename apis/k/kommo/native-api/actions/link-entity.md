# Link Entity with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/:entity/:entity_id/link`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Link Entity](https://developers.kommo.com/reference/l-in-ke-nt-it-y)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | no | Required path parameter for Link Entity. |
| `entity_id` | path | `string` | no | Required path parameter for Link Entity. |
