# Get Pipeline with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/pipelines/:id`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Get Pipeline](https://developers.kommo.com/reference/get-pipeline-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The pipeline identifier. |
