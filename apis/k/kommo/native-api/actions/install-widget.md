# Install Widget with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/widgets/:widget_code`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Install Widget](https://developers.kommo.com/reference/i-ns-ta-ll-wi-dg-et)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widget_code` | path | `string` | no | Required path parameter for Install Widget. |
