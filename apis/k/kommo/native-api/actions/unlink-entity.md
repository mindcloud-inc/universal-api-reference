# Unlink Entity with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/:entity/:entity_id/unlink`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Unlink Entity](https://developers.kommo.com/reference/u-nl-in-ke-nt-it-y)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | no | Required path parameter for Unlink Entity. |
| `entity_id` | path | `string` | no | Required path parameter for Unlink Entity. |
