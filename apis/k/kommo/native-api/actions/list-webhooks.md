# List Webhooks with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [List Webhooks](https://developers.kommo.com/reference/list-webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter[destination]` | query | `string` | no | Filter by the webhook URL. |
