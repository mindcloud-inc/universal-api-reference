# Attach Entity File with Kommo

## Endpoint

- **Method:** `PUT`
- **Path:** `/:entity/:entity_id/files`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Attach Entity File](https://developers.kommo.com/reference/a-tt-ac-he-nt-it-yf-il-e)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | no | Required path parameter for Attach Entity File. |
| `entity_id` | path | `string` | no | Required path parameter for Attach Entity File. |
