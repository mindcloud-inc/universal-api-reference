# List Entity Files with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/:entity/:entity_id/files`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [List Entity Files](https://developers.kommo.com/reference/l-is-te-nt-it-yf-il-es)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity` | path | `string` | no | Required path parameter for List Entity Files. |
| `entity_id` | path | `string` | no | Required path parameter for List Entity Files. |
