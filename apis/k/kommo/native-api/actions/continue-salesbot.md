# Continue Salesbot with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/:bot/:bot_id/continue/:continue_id`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Continue Salesbot](https://developers.kommo.com/reference/c-on-ti-nu-es-al-es-bo-t)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot` | path | `string` | no | Required path parameter for Continue Salesbot. |
| `bot_id` | path | `string` | no | Required path parameter for Continue Salesbot. |
| `continue_id` | path | `string` | no | Required path parameter for Continue Salesbot. |
