# List Custom Fields with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/:entity_type/custom_fields`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [List Custom Fields](https://developers.kommo.com/reference/custom-field-by-entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity_type` | path | `string` | yes | The entity type segment used in the path. |
| `entity_type` | path | `string` | no | Required path parameter for List Custom Fields. |
