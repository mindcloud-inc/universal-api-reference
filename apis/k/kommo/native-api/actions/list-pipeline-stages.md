# List Pipeline Stages with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/pipelines/:pipeline_id/statuses`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [List Pipeline Stages](https://developers.kommo.com/reference/stages-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pipeline_id` | path | `number` | yes | The pipeline identifier. |
| `pipeline_id` | path | `string` | no | Required path parameter for List Pipeline Stages. |
