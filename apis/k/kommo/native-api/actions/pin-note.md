# Pin Note with Kommo

- **Method:** `POST`
- **Path:** `/:entity_type/notes/:id/pin`
- **Base URL:** `https://{referer}/api/v4`

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entity_type` | path | `string` | no | Required path parameter for Pin Note. |
| `id` | path | `string` | no | Required path parameter for Pin Note. |
