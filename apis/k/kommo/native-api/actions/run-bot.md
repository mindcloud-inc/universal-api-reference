# Run Bot with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/bots/:id/run`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Run Bot](https://developers.kommo.com/reference/r-un-bo-t)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Required path parameter for Run Bot. |
