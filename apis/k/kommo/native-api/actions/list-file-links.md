# List File Links with Kommo

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_uuid/links`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [List File Links](https://developers.kommo.com/reference/l-is-tf-il-el-in-ks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_uuid` | path | `string` | no | Required path parameter for List File Links. |
