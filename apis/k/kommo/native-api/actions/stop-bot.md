# Stop Bot with Kommo

## Endpoint

- **Method:** `POST`
- **Path:** `/bots/:id/stop`
- **Base URL:** `https://{referer}/api/v4`
- **Official documentation:** [Stop Bot](https://developers.kommo.com/reference/s-to-pb-ot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Required path parameter for Stop Bot. |
