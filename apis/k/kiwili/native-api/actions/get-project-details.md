# Get Project Details with Kiwili

Retrieves details for a project in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:project_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Project Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Kiwili project ID. |
