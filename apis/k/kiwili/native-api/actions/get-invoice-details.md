# Get Invoice Details with Kiwili

Retrieves details for an invoice in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:invoice_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Invoice Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | The Kiwili invoice ID. |
