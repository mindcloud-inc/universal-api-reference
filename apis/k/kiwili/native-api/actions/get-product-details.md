# Get Product Details with Kiwili

Retrieves details for a product in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/product/:product_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Product Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | The Kiwili product ID. |
