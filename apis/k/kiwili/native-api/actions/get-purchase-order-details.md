# Get Purchase Order Details with Kiwili

Retrieves details for a purchase order in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchaseorder/:purchase_order_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Purchase Order Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchase_order_id` | path | `number` | yes | The Kiwili purchase order ID. |
