# Delete Enterprise with Kiwili

Deletes an existing enterprise from Kiwili.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/enterprise/:enterprise_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Delete Enterprise](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `enterprise_id` | path | `number` | yes | The Kiwili enterprise ID to delete. |
