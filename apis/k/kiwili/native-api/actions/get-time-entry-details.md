# Get Time Entry Details with Kiwili

Retrieves details for a time entry in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeentry/:time_entry_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Time Entry Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `time_entry_id` | path | `number` | yes | The Kiwili time entry ID. |
