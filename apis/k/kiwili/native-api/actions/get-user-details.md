# Get User Details with Kiwili

Retrieves details for a user in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get User Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | The Kiwili user ID. |
