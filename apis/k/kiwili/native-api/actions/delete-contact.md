# Delete Contact with Kiwili

Deletes an existing contact from Kiwili.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact/:contact_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Delete Contact](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The Kiwili contact ID to delete. |
