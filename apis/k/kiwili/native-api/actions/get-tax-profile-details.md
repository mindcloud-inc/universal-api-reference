# Get Tax Profile Details with Kiwili

Retrieves details for a tax profile in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/taxprofile/:tax_profile_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Tax Profile Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tax_profile_id` | path | `string` | yes | The Kiwili tax profile ID to retrieve. |
