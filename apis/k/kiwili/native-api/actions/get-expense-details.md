# Get Expense Details with Kiwili

Retrieves details for an expense in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/expense/:expense_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Expense Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expense_id` | path | `number` | yes | The Kiwili expense ID. |
