# Delete Product with Kiwili

Deletes an existing product from Kiwili.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/product/:product_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Delete Product](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | The Kiwili product ID to delete. |
