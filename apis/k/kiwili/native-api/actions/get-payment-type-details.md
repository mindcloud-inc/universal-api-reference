# Get Payment Type Details with Kiwili

Retrieves details for a payment type in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymenttype/:payment_type_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Payment Type Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payment_type_id` | path | `string` | yes | The Kiwili payment type ID to retrieve. |
