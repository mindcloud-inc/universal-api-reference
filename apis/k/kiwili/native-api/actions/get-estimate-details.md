# Get Estimate Details with Kiwili

Retrieves details for an estimate in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/estimate/:estimate_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Estimate Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `estimate_id` | path | `number` | yes | The Kiwili estimate ID. |
