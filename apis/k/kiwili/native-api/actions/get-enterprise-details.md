# Get Enterprise Details with Kiwili

Retrieves details for an enterprise in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/enterprise/:enterprise_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Enterprise Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `enterprise_id` | path | `number` | yes | The Kiwili enterprise ID. |
