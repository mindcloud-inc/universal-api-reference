# Delete Service with Kiwili

Deletes an existing service from Kiwili.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service/:service_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Delete Service](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_id` | path | `number` | yes | The Kiwili service ID to delete. |
