# Get Task Details with Kiwili

Retrieves details for a task in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:task_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Task Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | The Kiwili task ID. |
