# Get Contact Details with Kiwili

Retrieves details for a contact in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:contact_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Contact Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The Kiwili contact ID. |
