# Get Invoice Payment Details with Kiwili

Retrieves details for an invoice payment in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoicepayment/:invoice_payment_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Invoice Payment Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_payment_id` | path | `number` | yes | The Kiwili invoice payment ID. |
