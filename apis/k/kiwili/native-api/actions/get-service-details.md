# Get Service Details with Kiwili

Retrieves details for a service in Kiwili.

## Endpoint

- **Method:** `GET`
- **Path:** `/service/:service_id`
- **Base URL:** `https://mindcloud.kiwili.com/api`
- **Official documentation:** [Get Service Details](https://api.kiwili.com/api/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_id` | path | `number` | yes | The Kiwili service ID. |
