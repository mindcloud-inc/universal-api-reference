# Get Project with Kelloo

Retrieves a project record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Project`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Project](https://documenter.getpostman.com/view/14463756/UzBgtpF8#6b1c9a18-96a9-4337-bd36-fac7f40ca1b7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Kelloo project ID to retrieve. |
