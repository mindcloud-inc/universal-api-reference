# Get All Products with Kelloo

Retrieves all product records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Product`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Products](https://documenter.getpostman.com/view/14463756/UzBgtpF8#8f7f798a-dfc4-45a2-a383-e64e349b4859)
