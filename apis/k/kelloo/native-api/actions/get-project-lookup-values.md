# Get Project Lookup Values with Kelloo

Retrieves values for a Kelloo project lookup.

## Endpoint

- **Method:** `GET`
- **Path:** `/ProjectLookup`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Project Lookup Values](https://documenter.getpostman.com/view/14463756/UzBgtpF8#3b6c0e86-fa52-4171-9008-b09112f1b51c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The project lookup field identifier, such as `priority_id`. |
