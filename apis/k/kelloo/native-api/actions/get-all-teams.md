# Get All Teams with Kelloo

Retrieves all team records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Team`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Teams](https://documenter.getpostman.com/view/14463756/UzBgtpF8#5691ee11-7b2d-4334-81f3-f85bc7a60263)
