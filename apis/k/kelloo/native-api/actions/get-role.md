# Get Role with Kelloo

Retrieves a role record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Role`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Role](https://documenter.getpostman.com/view/14463756/UzBgtpF8#c3075640-9b02-48ba-83a3-1eb7bc0e3f5b)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | query | `string` | yes | The Kelloo role ID to retrieve. |
