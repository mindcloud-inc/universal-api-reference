# Get All Resources with Kelloo

Retrieves all resource records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Resource`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Resources](https://documenter.getpostman.com/view/14463756/UzBgtpF8#73e5aa10-3839-45e0-a388-731202e6d954)
