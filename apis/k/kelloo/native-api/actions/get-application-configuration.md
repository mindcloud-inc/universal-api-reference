# Get Application Configuration with Kelloo

Retrieves application configuration details from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/ApplicationConfig`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Application Configuration](https://documenter.getpostman.com/view/14463756/UzBgtpF8#50064719-3321-4111-b3d7-303c2fe0fdcc)
