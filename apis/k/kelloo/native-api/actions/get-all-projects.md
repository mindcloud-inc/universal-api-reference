# Get All Projects with Kelloo

Retrieves all project records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Project`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Projects](https://documenter.getpostman.com/view/14463756/UzBgtpF8#5efd9710-d8df-415b-ba7d-5034f86041b7)
