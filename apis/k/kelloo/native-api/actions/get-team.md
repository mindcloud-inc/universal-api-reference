# Get Team with Kelloo

Retrieves a team record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Team`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Team](https://documenter.getpostman.com/view/14463756/UzBgtpF8#7278fd36-4489-4d1f-95c1-9d31626b97b0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Kelloo team ID to retrieve. |
