# Get All Scenarios with Kelloo

Retrieves all scenario records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Scenario`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Scenarios](https://documenter.getpostman.com/view/14463756/UzBgtpF8#4076ec9c-1231-49c1-a6d0-565b72f360bf)
