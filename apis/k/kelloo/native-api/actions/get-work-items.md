# Get Work Items with Kelloo

Retrieves work items from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/WorkItem`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Work Items](https://documenter.getpostman.com/view/14463756/UzBgtpF8#1c287bc7-c331-4281-8f14-0931483bd577)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scenario_id` | query | `string` | yes | The Kelloo scenario ID whose work items should be returned. |
