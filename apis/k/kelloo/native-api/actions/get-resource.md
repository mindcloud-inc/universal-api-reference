# Get Resource with Kelloo

Retrieves a resource record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Resource`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Resource](https://documenter.getpostman.com/view/14463756/UzBgtpF8#4ad85043-cdfb-48e8-926e-12fc1d5f00d3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Kelloo resource ID to retrieve. |
