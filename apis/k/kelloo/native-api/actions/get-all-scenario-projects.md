# Get All Scenario Projects with Kelloo

Retrieves all scenario projects from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/ScenarioProject`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Scenario Projects](https://documenter.getpostman.com/view/14463756/UzBgtpF8#06233451-781b-4ed8-8211-50fcb92626b0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scenario_id` | query | `string` | yes | The Kelloo scenario ID whose projects should be returned. |
