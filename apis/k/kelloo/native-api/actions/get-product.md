# Get Product with Kelloo

Retrieves a product record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Product`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Product](https://documenter.getpostman.com/view/14463756/UzBgtpF8#92d7a745-2779-4cf6-a382-f7586d43b0b9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Kelloo product ID to retrieve. |
