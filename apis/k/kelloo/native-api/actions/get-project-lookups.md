# Get Project Lookups with Kelloo

Retrieves project lookup definitions from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/ProjectLookup`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Project Lookups](https://documenter.getpostman.com/view/14463756/UzBgtpF8#a69c647c-0456-4fa5-9e18-0693c01c88ba)
