# Get Scenario with Kelloo

Retrieves a scenario record from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Scenario`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Scenario](https://documenter.getpostman.com/view/14463756/UzBgtpF8#96ad5405-feea-4916-a048-35f522a81115)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Kelloo scenario ID to retrieve. |
