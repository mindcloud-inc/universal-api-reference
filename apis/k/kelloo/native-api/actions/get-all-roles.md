# Get All Roles with Kelloo

Retrieves all role records from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/Role`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get All Roles](https://documenter.getpostman.com/view/14463756/UzBgtpF8#81bcfc6e-9ed9-4709-b46c-da799b30bcab)
