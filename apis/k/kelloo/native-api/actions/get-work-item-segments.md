# Get Work Item Segments with Kelloo

Retrieves work item segments from Kelloo.

## Endpoint

- **Method:** `GET`
- **Path:** `/WorkSegment`
- **Base URL:** `https://plan.kelloo.com/api`
- **Official documentation:** [Get Work Item Segments](https://documenter.getpostman.com/view/14463756/UzBgtpF8#f99f241a-c448-4033-9547-744effb257bc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `work_id` | query | `string` | yes | The Kelloo work item ID whose segments should be returned. |
