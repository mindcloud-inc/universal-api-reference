# Update Tag with KnowledgeOwl

## Endpoint

- **Method:** `PUT`
- **Path:** `/tag/:id.json`
- **Base URL:** `https://app.knowledgeowl.com/api/head`
- **Official documentation:** [Update Tag](https://support.knowledgeowl.com/help/api-endpoint-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `name` | body | `string` | no |
| `status` | body | `string` | no |
