# Create File with KnowledgeOwl

## Endpoint

- **Method:** `POST`
- **Path:** `/file.json`
- **Base URL:** `https://app.knowledgeowl.com/api/head`
- **Official documentation:** [Create File](https://support.knowledgeowl.com/help/api-endpoint-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | body | `string` | yes |
| `name` | body | `string` | yes |
| `status` | body | `string` | yes |
| `file` | body | `string` | yes |
