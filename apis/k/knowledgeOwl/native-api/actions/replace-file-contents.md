# Replace File Contents with KnowledgeOwl

## Endpoint

- **Method:** `POST`
- **Path:** `/file/:id.json`
- **Base URL:** `https://app.knowledgeowl.com/api/head`
- **Official documentation:** [Replace File Contents](https://support.knowledgeowl.com/help/api-endpoint-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `file` | body | `string` | yes |
