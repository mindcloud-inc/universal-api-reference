# Create Category with KnowledgeOwl

## Endpoint

- **Method:** `POST`
- **Path:** `/category.json`
- **Base URL:** `https://app.knowledgeowl.com/api/head`
- **Official documentation:** [Create Category](https://support.knowledgeowl.com/help/api-endpoint-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `type` | body | `string` | yes |
| `project_id` | body | `string` | yes |
| `url_hash` | body | `string` | yes |
| `name.en` | body | `string` | yes |
| `visibility` | body | `string` | yes |
| `status` | body | `string` | yes |
