# List Tables with KIS

Retrieves all data table structures from KIS.

## Endpoint

- **Method:** `GET`
- **Path:** `/api_token_access/collections`
- **Base URL:** `https://api.getkis.io/api/v1`
- **Official documentation:** [List Tables](https://doc.getkis.io/documentation/documentation-api/tables-de-donnees/lister-les-tables-de-donnees)
