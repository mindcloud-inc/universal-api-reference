# Get My API Data with KickFire

Retrieves MyAPI custom account attributes from KickFire.

## Endpoint

- **Method:** `GET`
- **Path:** `/my`
- **Base URL:** `https://api.kickfire.com`
- **Official documentation:** [Get My API Data](https://foundryco.com/developers/#myapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyField` | query | `string` | yes | Lookup value accepted by the MyAPI endpoint. |
