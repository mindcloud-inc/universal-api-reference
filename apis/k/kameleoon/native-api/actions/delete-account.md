# Delete account with Kameleoon

## Endpoint

- **Method:** `DELETE`
- **Path:** `accounts/:accountId`
- **Base URL:** `https://api.kameleoon.com`
- **Official documentation:** [Delete account](https://developers.kameleoon.com/apis/automation-api-rest/all-endpoints/delete-account/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Account identifier from Kameleoon. |
