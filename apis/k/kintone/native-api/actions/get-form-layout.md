# Get Form Layout with Kintone

Retrieves an app form layout from Kintone.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/form/layout.json`
- **Base URL:** `{baseUrl}/k/v1`
- **Official documentation:** [Get Form Layout](https://kintone.dev/en/docs/kintone/rest-api/apps/form/get-form-layout/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app` | query | `number` | yes | The Kintone app ID. |
