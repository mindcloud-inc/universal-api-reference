# Get App with Kintone

Retrieves an app from Kintone.

## Endpoint

- **Method:** `GET`
- **Path:** `/app.json`
- **Base URL:** `{baseUrl}/k/v1`
- **Official documentation:** [Get App](https://kintone.dev/en/docs/kintone/rest-api/apps/get-app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | The Kintone app ID. |
