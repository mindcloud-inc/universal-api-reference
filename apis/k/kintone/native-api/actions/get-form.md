# Get Form with Kintone

Retrieves an app form from Kintone.

## Endpoint

- **Method:** `GET`
- **Path:** `/form.json`
- **Base URL:** `{baseUrl}/k/v1`
- **Official documentation:** [Get Form](https://kintone.dev/en/docs/kintone/rest-api/apps/get-form/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app` | query | `number` | yes | The Kintone app ID. |
