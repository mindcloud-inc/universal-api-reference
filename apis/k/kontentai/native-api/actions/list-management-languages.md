# List management languages with Kontent.ai

Retrieves languages from your Kontent.ai environment.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/languages`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [List management languages](https://kontent.ai/learn/docs/apis/management-api-v2/languages)
