# Retrieve custom app with Kontent.ai

Retrieves a custom app from Kontent.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/custom-apps/:custom_app_identifier`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [Retrieve custom app](https://kontent.ai/learn/docs/apis/management-api-v2/custom-apps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custom_app_identifier` | path | `string` | yes | Kontent.ai custom app identifier. |
