# List management taxonomy groups with Kontent.ai

Retrieves taxonomy groups from your Kontent.ai environment.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/taxonomies`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [List management taxonomy groups](https://kontent.ai/learn/docs/apis/management-api-v2/taxonomy-groups)
