# Add management asset with Kontent.ai

Creates a new asset in Kontent.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/assets`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [Add management asset](https://kontent.ai/learn/docs/apis/management-api-v2/assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Kontent.ai management asset. |
