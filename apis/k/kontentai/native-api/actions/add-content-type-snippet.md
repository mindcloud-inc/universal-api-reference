# Add content type snippet with Kontent.ai

Creates a new content type snippet in Kontent.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/snippets`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [Add content type snippet](https://kontent.ai/learn/docs/apis/management-api-v2/content-type-snippets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Kontent.ai content type snippet. |
