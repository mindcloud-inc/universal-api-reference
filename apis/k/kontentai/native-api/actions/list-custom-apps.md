# List custom apps with Kontent.ai

Retrieves custom apps from your Kontent.ai environment.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/custom-apps`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [List custom apps](https://kontent.ai/learn/docs/apis/management-api-v2/custom-apps)
