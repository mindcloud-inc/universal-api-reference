# Add management language with Kontent.ai

Creates a new language in Kontent.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/languages`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [Add management language](https://kontent.ai/learn/docs/apis/management-api-v2/languages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Kontent.ai language. |
