# List content type snippets with Kontent.ai

Retrieves content type snippets from Kontent.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/snippets`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [List content type snippets](https://kontent.ai/learn/docs/apis/management-api-v2/content-type-snippets)
