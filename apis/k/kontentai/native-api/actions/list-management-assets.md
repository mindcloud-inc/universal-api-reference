# List management assets with Kontent.ai

Retrieves assets from your Kontent.ai environment.

## Endpoint

- **Method:** `GET`
- **Path:** `https://manage.kontent.ai/v2/projects/:environment_id/assets`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [List management assets](https://kontent.ai/learn/docs/apis/management-api-v2/assets)
