# Enumerate content items with Kontent.ai

Enumerates all content items from Kontent.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/:environment_id/items-feed`
- **Base URL:** `https://deliver.kontent.ai`
- **Official documentation:** [Enumerate content items](https://kontent.ai/learn/docs/apis/delivery-api/content-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment_id` | path | `string` | yes | Kontent.ai project environment identifier. |
