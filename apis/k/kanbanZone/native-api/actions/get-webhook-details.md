# Get Webhook Details with Kanban Zone

Retrieves a webhook from Kanban Zone.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://integrations.kanbanzone.io/v1`
- **Official documentation:** [Get Webhook Details](https://docs.kanbanzone.io/apiReference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique ID of the webhook |
