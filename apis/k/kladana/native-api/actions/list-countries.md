# List Countries with Kladana

Lists countries in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/country`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Countries](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-country-get-countries)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
