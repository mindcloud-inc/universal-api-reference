# List Assortment with Kladana

Lists assortment items in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/assortment`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Assortment](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-assortment-get-assortment)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
