# List Employees with Kladana

Lists employees in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/employee`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Employees](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-employee-get-employees)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
