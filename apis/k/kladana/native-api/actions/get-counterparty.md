# Get Counterparty with Kladana

Retrieves a counterparty record from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/counterparty/{id}`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Counterparty](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-counterparty-get-counterparty)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Kladana counterparty ID from the Counterparty resource URL. |
