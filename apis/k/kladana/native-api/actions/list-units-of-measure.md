# List Units Of Measure with Kladana

Lists units of measure in Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/uom`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Units Of Measure](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-unit-of-measure-get-units-of-measure)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
