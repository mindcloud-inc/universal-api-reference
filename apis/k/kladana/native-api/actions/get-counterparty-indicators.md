# Get Counterparty Indicators with Kladana

Retrieves counterparty indicators report from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/counterparty`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Counterparty Indicators](https://dev.kladana.com/doc/api/remap/1.2/reports/#reports-report-indicators-of-counterparties-get-indicators-of-counterparties)
