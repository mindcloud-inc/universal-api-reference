# List Outgoing Payments with Kladana

Lists outgoing payments in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/paymentout`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Outgoing Payments](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-outgoing-payment-get-outgoing-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
