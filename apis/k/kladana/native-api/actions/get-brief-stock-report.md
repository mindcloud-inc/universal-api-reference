# Get Brief Stock Report with Kladana

Retrieves the brief stock report from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/stock/all/current`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Brief Stock Report](https://dev.kladana.com/doc/api/remap/1.2/reports/#reports-stock-report-get-the-brief-stock-report)
