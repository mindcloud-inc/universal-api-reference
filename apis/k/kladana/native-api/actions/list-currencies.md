# List Currencies with Kladana

Lists currencies in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/currency/`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Currencies](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-currency-get-currencies)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
