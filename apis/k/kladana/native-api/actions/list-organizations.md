# List Organizations with Kladana

Lists organizations in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/organization`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Organizations](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-entity-get-a-list-of-legal-entities)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
