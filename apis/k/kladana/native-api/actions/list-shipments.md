# List Shipments with Kladana

Lists shipments in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/demand`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Shipments](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-shipment-get-a-list-of-shipments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
