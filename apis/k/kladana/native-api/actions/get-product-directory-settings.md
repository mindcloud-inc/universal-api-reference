# Get Product Directory Settings with Kladana

Retrieves product directory settings from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/assortment/settings`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Product Directory Settings](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-assortment-get-product-directory-settings)
