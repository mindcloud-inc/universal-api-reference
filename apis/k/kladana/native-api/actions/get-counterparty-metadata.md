# Get Counterparty Metadata with Kladana

Retrieves counterparty metadata details from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/counterparty/metadata`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Counterparty Metadata](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-counterparty-metadata-of-counterparties)
