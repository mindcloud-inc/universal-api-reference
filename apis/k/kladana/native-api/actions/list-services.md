# List Services with Kladana

Lists services in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/service`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Services](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-service-get-a-list-of-services)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
