# Get Product Variant Metadata with Kladana

Retrieves product variant metadata from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/variant/metadata`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Product Variant Metadata](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-product-variant-product-variant-metadata)
