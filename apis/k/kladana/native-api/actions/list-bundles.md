# List Bundles with Kladana

Lists bundles in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/bundle`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Bundles](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-bundle-get-the-list-of-bundles)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
