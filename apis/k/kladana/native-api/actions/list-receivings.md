# List Receivings with Kladana

Lists receivings in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/supply`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Receivings](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-receiving-get-list-of-receivings)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
