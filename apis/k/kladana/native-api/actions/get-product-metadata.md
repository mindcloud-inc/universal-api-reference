# Get Product Metadata with Kladana

Retrieves product metadata details from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/product/metadata`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Product Metadata](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-product-item-metadata)
