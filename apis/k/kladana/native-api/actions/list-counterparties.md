# List Counterparties with Kladana

Lists counterparties in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/counterparty`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Counterparties](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-counterparty-get-a-list-of-counterparties)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
