# List Product Groups with Kladana

Lists product groups in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/productfolder`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Product Groups](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-product-group-get-a-list-of-product-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
