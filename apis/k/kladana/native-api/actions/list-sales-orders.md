# List Sales Orders with Kladana

Lists sales orders in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/customerorder`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Sales Orders](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-sales-order-get-the-list-of-sales-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
