# Get Current Employee Context with Kladana

Retrieves current employee context from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/context/employee`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Current Employee Context](https://dev.kladana.com/doc/api/remap/1.2/#employee-request-context)
