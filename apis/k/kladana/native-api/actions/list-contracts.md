# List Contracts with Kladana

Lists contracts in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/contract`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Contracts](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-contract-get-a-list-of-contracts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
