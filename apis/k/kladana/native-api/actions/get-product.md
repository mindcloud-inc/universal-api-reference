# Get Product with Kladana

Retrieves a product record from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/product/{id}`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Product](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-product-get-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Kladana product ID from the Product resource URL. |
