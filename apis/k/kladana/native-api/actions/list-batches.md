# List Batches with Kladana

Lists batches in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/consignment`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Batches](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-batch-get-a-list-of-batches)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
