# List Inventory Counts with Kladana

Lists inventory counts in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/inventory`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Inventory Counts](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-inventory-count-get-inventory-counts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
