# Get Advanced Stock Report with Kladana

Retrieves the advanced stock report from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/stock/all`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Advanced Stock Report](https://dev.kladana.com/doc/api/remap/1.2/reports/#reports-stock-report-get-advanced-stock-report)
