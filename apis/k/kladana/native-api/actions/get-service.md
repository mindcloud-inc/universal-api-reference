# Get Service with Kladana

Retrieves a service record from Kladana.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/service/{id}`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [Get Service](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-service-get-service)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Kladana service ID from the Service resource URL. |
