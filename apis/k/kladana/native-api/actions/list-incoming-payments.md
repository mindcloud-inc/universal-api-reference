# List Incoming Payments with Kladana

Lists incoming payments in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/paymentin`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Incoming Payments](https://dev.kladana.com/doc/api/remap/1.2/documents/#transactions-incoming-payment-get-incoming-payments)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
