# List Projects with Kladana

Lists projects in your Kladana account.

## Endpoint

- **Method:** `GET`
- **Path:** `/entity/project`
- **Base URL:** `https://api.kladana.com/api/remap/1.2`
- **Official documentation:** [List Projects](https://dev.kladana.com/doc/api/remap/1.2/dictionaries/#entities-project-get-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
