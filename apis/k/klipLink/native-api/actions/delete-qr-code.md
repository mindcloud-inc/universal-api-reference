# Delete QR Code with KlipLink

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/qrcodes/:short_url`
- **Base URL:** `https://api.klipl.ink`
- **Official documentation:** [Delete QR Code](https://docs.klipl.ink/api/qrcodes/delete-qrcode)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `short_url` | path | `string` | yes | The short URL identifier, for example klipl.ink/example. |
