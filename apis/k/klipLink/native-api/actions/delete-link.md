# Delete Link with KlipLink

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/links/:short_url`
- **Base URL:** `https://api.klipl.ink`
- **Official documentation:** [Delete Link](https://docs.klipl.ink/api/links/delete-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `short_url` | path | `string` | yes | The short URL identifier, for example klipl.ink/example. |
