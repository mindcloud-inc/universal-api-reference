# Get Role with Klipfolio

Retrieves a role from Klipfolio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:roleId`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Role](https://apidocs.klipfolio.com/reference/roles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | no | The Klipfolio role ID. |
