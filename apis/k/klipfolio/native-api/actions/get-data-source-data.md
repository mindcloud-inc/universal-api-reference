# Get Data Source Data with Klipfolio

Retrieves data for a Klipfolio data source.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources/:datasourceId/data`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Data Source Data](https://apidocs.klipfolio.com/reference/data-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasourceId` | path | `string` | no | The Klipfolio datasource ID. |
