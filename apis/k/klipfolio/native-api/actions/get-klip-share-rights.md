# Get Klip Share Rights with Klipfolio

Retrieves share rights for a Klip in Klipfolio.

## Endpoint

- **Method:** `GET`
- **Path:** `/klips/:klipId/share-rights`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Klip Share Rights](https://apidocs.klipfolio.com/reference/klips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `klipId` | path | `string` | no | The Klipfolio klip ID. |
