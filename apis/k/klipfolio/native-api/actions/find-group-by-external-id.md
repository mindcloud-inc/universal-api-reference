# Find Group By External ID with Klipfolio

Finds a Klipfolio group by external ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Find Group By External ID](https://apidocs.klipfolio.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `external_id` | query | `string` | no | Filter groups by external ID. |
