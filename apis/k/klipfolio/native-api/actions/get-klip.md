# Get Klip with Klipfolio

Retrieves a Klip from Klipfolio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/klips/:klipId`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Klip](https://apidocs.klipfolio.com/reference/klips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `klipId` | path | `string` | no | The Klipfolio klip ID. |
