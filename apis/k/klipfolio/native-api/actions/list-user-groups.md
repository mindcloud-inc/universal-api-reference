# List User Groups with Klipfolio

Retrieves groups assigned to a Klipfolio user.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/groups`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List User Groups](https://apidocs.klipfolio.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | The Klipfolio user ID. |
