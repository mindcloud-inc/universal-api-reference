# Get Data Source with Klipfolio

Retrieves a data source from Klipfolio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources/:datasourceId`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Data Source](https://apidocs.klipfolio.com/reference/data-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasourceId` | path | `string` | no | The Klipfolio datasource ID. |
