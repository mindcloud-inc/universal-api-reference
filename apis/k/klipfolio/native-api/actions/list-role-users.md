# List Role Users with Klipfolio

Retrieves users assigned to a Klipfolio role.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:roleId/users`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Role Users](https://apidocs.klipfolio.com/reference/roles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | no | The Klipfolio role ID. |
