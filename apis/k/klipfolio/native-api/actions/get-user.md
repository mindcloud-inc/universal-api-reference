# Get User with Klipfolio

Retrieves a user from Klipfolio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get User](https://apidocs.klipfolio.com/reference/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | The Klipfolio user ID. |
