# List Group Users with Klipfolio

Retrieves users assigned to a Klipfolio group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId/users`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Group Users](https://apidocs.klipfolio.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | no | The Klipfolio group ID. |
