# Get Data Source Instance Data with Klipfolio

Retrieves data for a Klipfolio data source instance.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasource-instances/:instanceId/data`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Data Source Instance Data](https://apidocs.klipfolio.com/reference/data-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `instanceId` | path | `string` | no | The Klipfolio datasource instance ID. |
