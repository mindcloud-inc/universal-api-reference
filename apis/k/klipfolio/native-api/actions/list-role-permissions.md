# List Role Permissions with Klipfolio

Retrieves permissions for a Klipfolio role.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles/:roleId/permissions`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Role Permissions](https://apidocs.klipfolio.com/reference/permissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | no | The Klipfolio role ID. |
