# List Group Default Tabs with Klipfolio

Retrieves default tabs for a Klipfolio group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId/default-tabs`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Group Default Tabs](https://apidocs.klipfolio.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | no | The Klipfolio group ID. |
