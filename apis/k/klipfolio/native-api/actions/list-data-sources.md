# List Data Sources with Klipfolio

Retrieves a list of data sources from Klipfolio.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Data Sources](https://apidocs.klipfolio.com/reference/data-sources)
