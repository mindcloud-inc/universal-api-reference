# Get Group with Klipfolio

Retrieves a group from Klipfolio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [Get Group](https://apidocs.klipfolio.com/reference/groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | no | The Klipfolio group ID. |
