# List Klips By Data Source with Klipfolio

Retrieves Klips from Klipfolio by data source ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/klips`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List Klips By Data Source](https://apidocs.klipfolio.com/reference/klips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasource_id` | query | `string` | no | Filter klips by datasource ID. |
