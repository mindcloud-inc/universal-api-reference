# List User Roles with Klipfolio

Retrieves roles assigned to a Klipfolio user.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/roles`
- **Base URL:** `https://app.klipfolio.com/api/1.0`
- **Official documentation:** [List User Roles](https://apidocs.klipfolio.com/reference/user-roles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | The Klipfolio user ID. |
