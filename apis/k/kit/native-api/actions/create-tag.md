# Create Tag with Kit

Creates a new tag in Kit.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.kit.com/v4`
- **Official documentation:** [Create Tag](https://developers.kit.com/api-reference/tags/create-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the tag to create. |
