# Get Subscriber with Kit

Retrieves a subscriber record from Kit.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscribers/:id`
- **Base URL:** `https://api.kit.com/v4`
- **Official documentation:** [Get Subscriber](https://developers.kit.com/api-reference/subscribers/get-a-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Subscriber ID. |
