# Unsubscribe Subscriber with Kit

Unsubscribes an existing subscriber in Kit.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscribers/:id/unsubscribe`
- **Base URL:** `https://api.kit.com/v4`
- **Official documentation:** [Unsubscribe Subscriber](https://developers.kit.com/api-reference/subscribers/unsubscribe-subscriber)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Subscriber ID from the path parameter. |
