# Get Broadcast with Kit

Retrieves a broadcast record from Kit.

## Endpoint

- **Method:** `GET`
- **Path:** `/broadcasts/:id`
- **Base URL:** `https://api.kit.com/v4`
- **Official documentation:** [Get Broadcast](https://developers.kit.com/api-reference/broadcasts/get-a-broadcast)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Broadcast ID. |
