# Create Custom Field with Kit

Creates a new custom field in Kit.

## Endpoint

- **Method:** `POST`
- **Path:** `/custom_fields`
- **Base URL:** `https://api.kit.com/v4`
- **Official documentation:** [Create Custom Field](https://developers.kit.com/api-reference/custom-fields/create-a-custom-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label` | body | `string` | yes | Unique custom field label to create in Kit. |
