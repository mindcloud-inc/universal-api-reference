# Retrieve Sales Order with Katana

Retrieves a sales order by ID from Katana.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales_orders/:id`
- **Base URL:** `https://api.katanamrp.com/v1`
- **Official documentation:** [Retrieve Sales Order](https://developer.katanamrp.com/reference/retrieve-sales-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Sales order id |
