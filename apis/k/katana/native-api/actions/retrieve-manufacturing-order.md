# Retrieve Manufacturing Order with Katana

Retrieves a manufacturing order by ID from Katana.

## Endpoint

- **Method:** `GET`
- **Path:** `/manufacturing_orders/:id`
- **Base URL:** `https://api.katanamrp.com/v1`
- **Official documentation:** [Retrieve Manufacturing Order](https://developer.katanamrp.com/reference/getmanufacturingorder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Manufacturing order id |
