# Receive Purchase Order with Katana

Marks a purchase order as received in Katana.

## Endpoint

- **Method:** `POST`
- **Path:** `/purchase_order_receive`
- **Base URL:** `https://api.katanamrp.com/v1`
- **Official documentation:** [Receive Purchase Order](https://developer.katanamrp.com/reference/receivepurchaseorder)
