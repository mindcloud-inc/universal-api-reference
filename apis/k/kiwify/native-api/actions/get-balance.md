# Get Balance with Kiwify

Retrieves a balance from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/balance/:legal_entity_id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Balance](https://docs.kiwify.com.br/api-reference/finance/balance/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `legal_entity_id` | path | `string` | yes |
