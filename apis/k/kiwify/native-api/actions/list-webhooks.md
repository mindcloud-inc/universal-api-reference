# List Webhooks with Kiwify

Retrieves webhooks from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [List Webhooks](https://docs.kiwify.com.br/api-reference/webhooks/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page_size` | query | `string` | no |
| `page_number` | query | `string` | no |
| `product_id` | query | `string` | no |
| `search` | query | `string` | no |
