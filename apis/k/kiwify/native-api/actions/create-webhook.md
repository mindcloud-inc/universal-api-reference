# Create Webhook with Kiwify

Creates a webhook in Kiwify.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Create Webhook](https://docs.kiwify.com.br/api-reference/webhooks/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `url` | body | `string` | no |
| `products` | body | `string` | no |
| `token` | body | `string` | no |
