# Get Account Details with Kiwify

Retrieves account details from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/account-details`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Account Details](https://docs.kiwify.com.br/api-reference/account/account-details)
