# Get Affiliate with Kiwify

Retrieves an affiliate from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/affiliates/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Affiliate](https://docs.kiwify.com.br/api-reference/affiliates/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
