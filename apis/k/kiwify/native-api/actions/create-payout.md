# Create Payout with Kiwify

Creates a payout in Kiwify.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/payouts/`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Create Payout](https://docs.kiwify.com.br/api-reference/finance/payouts/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `amount` | body | `number` | no |
