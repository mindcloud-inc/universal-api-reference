# Get Webhook with Kiwify

Retrieves a webhook from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Webhook](https://docs.kiwify.com.br/api-reference/webhooks/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
