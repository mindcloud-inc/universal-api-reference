# Get Sales Stats with Kiwify

Retrieves sales statistics from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Sales Stats](https://docs.kiwify.com.br/api-reference/sales/stats)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | query | `string` | no |
| `start_date` | query | `string` | no |
| `end_date` | query | `string` | no |
