# List Payouts with Kiwify

Retrieves payouts from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payouts`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [List Payouts](https://docs.kiwify.com.br/api-reference/finance/payouts/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `legal_entity_id` | query | `string` | no |
| `page_size` | query | `string` | no |
| `page_number` | query | `string` | no |
