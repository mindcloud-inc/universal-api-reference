# List Affiliates with Kiwify

Retrieves affiliates from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/affiliates`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [List Affiliates](https://docs.kiwify.com.br/api-reference/affiliates/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page_size` | query | `string` | no |
| `page_number` | query | `string` | no |
| `status` | query | `string` | no |
| `product_id` | query | `string` | no |
| `search` | query | `string` | no |
