# List Products with Kiwify

Retrieves products from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [List Products](https://docs.kiwify.com.br/api-reference/products/list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page_size` | query | `string` | no |
| `page_number` | query | `string` | no |
