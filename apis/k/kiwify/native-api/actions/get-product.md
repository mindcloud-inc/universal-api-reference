# Get Product with Kiwify

Retrieves a product from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Product](https://docs.kiwify.com.br/api-reference/products/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
