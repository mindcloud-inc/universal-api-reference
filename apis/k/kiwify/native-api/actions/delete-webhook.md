# Delete Webhook with Kiwify

Deletes an existing webhook from Kiwify.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Delete Webhook](https://docs.kiwify.com.br/api-reference/webhooks/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
