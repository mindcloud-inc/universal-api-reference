# Get Payout with Kiwify

Retrieves a payout from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payouts/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Payout](https://docs.kiwify.com.br/api-reference/finance/payouts/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
