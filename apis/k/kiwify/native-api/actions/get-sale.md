# Get Sale with Kiwify

Retrieves a sale from Kiwify.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sales/:id`
- **Base URL:** `https://public-api.kiwify.com`
- **Official documentation:** [Get Sale](https://docs.kiwify.com.br/api-reference/sales/single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
