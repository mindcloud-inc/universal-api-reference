# Get Place Details with KeyVox

Retrieves place details from your KeyVox account.

## Endpoint

- **Method:** `POST`
- **Path:** `/place/detail`
- **Base URL:** `https://eco.blockchainlock.io/api/eagle-pms`
- **Official documentation:** [Get Place Details](https://developers.keyvox.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `placeId` | body | `string` | no | 場所ID |
