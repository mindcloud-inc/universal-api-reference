# Get Project Data with KiteSuite

Retrieves all project data from KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/all/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Project Data](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID. |
