# Get Project with KiteSuite

Retrieves a project from KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Project](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID. |
