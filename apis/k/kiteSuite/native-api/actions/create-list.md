# Create List with KiteSuite

Creates a new list in KiteSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/list`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Create List](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listName` | body | `string` | yes | List name. |
| `projectID` | body | `string` | yes | Project ID. |
