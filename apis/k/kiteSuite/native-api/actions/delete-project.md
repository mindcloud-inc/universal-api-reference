# Delete Project with KiteSuite

Deletes an existing project from KiteSuite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Project](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID. |
