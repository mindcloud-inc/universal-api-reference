# Get Workspace Project Data with KiteSuite

Retrieves projects, lists, sprints, and epics for a workspace in KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/workspace/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Workspace Project Data](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workspace ID. |
