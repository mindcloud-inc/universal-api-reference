# Get Workspace with KiteSuite

Retrieves a workspace from KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/workspace/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Workspace](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workspace ID. |
