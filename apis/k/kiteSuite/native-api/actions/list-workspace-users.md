# List Workspace Users with KiteSuite

Retrieves workspace users from KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/workspace/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [List Workspace Users](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Workspace ID. |
