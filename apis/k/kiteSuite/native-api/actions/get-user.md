# Get User with KiteSuite

Retrieves a user from KiteSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/user/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get User](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User ID. |
