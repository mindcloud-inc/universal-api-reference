# Retrieve List of Tags with Kaiten

Retrieves tags from Kaiten.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve List of Tags](https://developers.kaiten.ru/tags/retrieve-list-of-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
