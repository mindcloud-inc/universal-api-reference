# Retrieve List of Card Members with Kaiten

Retrieves members for a Kaiten card.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId/members`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve List of Card Members](https://developers.kaiten.ru/cards/{card_id}/members)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `number` | yes | The Kaiten card ID. |
