# Delete Card with Kaiten

Deletes an existing card from Kaiten.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Delete Card](https://developers.kaiten.ru/cards/{card_id})

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `number` | yes | The Kaiten card ID. |
