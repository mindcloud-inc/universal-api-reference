# Retrieve List of Users with Kaiten

Retrieves users from Kaiten.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve List of Users](https://developers.kaiten.ru/users/retrieve-list-of-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
