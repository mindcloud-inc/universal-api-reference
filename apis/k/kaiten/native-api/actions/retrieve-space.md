# Retrieve Space with Kaiten

Retrieves a space from Kaiten.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve Space](https://developers.kaiten.ru/spaces/get-space)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `number` | yes | The Kaiten space ID. |
