# Retrieve Card with Kaiten

Retrieves a card from Kaiten.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve Card](https://developers.kaiten.ru/cards/get-card)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `number` | yes | The Kaiten card ID. |
