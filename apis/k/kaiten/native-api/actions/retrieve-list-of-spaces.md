# Retrieve List of Spaces with Kaiten

Retrieves spaces from Kaiten.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve List of Spaces](https://developers.kaiten.ru/spaces/get-list-of-spaces)
