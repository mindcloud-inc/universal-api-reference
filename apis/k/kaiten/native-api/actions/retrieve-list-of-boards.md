# Retrieve List of Boards with Kaiten

Retrieves boards from a Kaiten space.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/boards`
- **Base URL:** `https://{companyDomain}.kaiten.ru/api/latest`
- **Official documentation:** [Retrieve List of Boards](https://developers.kaiten.ru/space-boards/get-list-of-boards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `number` | yes | The Kaiten space ID. |
