# Lookup Contacts with Kylas CRM

## Endpoint

- **Method:** `GET`
- **Path:** `/search/contact/lookup`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Lookup Contacts](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Lookup query such as firstName:Alex. |
