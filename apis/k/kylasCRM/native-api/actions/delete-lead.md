# Delete Lead with Kylas CRM

Deletes an existing lead from Kylas CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/{leadId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Delete Lead](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | no | The Kylas lead ID. |
