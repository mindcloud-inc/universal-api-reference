# Get Lead with Kylas CRM

Retrieves a lead from Kylas CRM by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/{leadId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Get Lead](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | no | The Kylas lead ID. |
