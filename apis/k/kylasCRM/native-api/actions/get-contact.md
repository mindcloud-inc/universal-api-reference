# Get Contact with Kylas CRM

Retrieves a contact from Kylas CRM by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{contactId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Get Contact](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The Kylas contact ID. |
