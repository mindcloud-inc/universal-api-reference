# Search Deals with Kylas CRM

Finds deals in Kylas CRM by search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/search/deal?page=0&size=10&sort=updatedAt,desc`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Search Deals](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
