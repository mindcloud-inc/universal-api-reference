# Get Task Create Layout with Kylas CRM

Retrieves task form fields from Kylas CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/ui/layouts/CREATE/TASK`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Get Task Create Layout](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
