# Check Lead Duplicates with Kylas CRM

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/{leadId}/has-duplicates`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Check Lead Duplicates](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | no | The Kylas lead ID. |
