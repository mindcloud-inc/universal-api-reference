# Lookup Deal Pipelines with Kylas CRM

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/lookup?entityType=DEAL`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Lookup Deal Pipelines](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Lookup query such as name:Pipeline. |
