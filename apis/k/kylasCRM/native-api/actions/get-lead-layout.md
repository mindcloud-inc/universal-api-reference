# Get Lead Layout with Kylas CRM

Retrieves lead form fields from Kylas CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/ui/layouts/CREATE/LEAD`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Get Lead Layout](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
