# Search Pipelines with Kylas CRM

## Endpoint

- **Method:** `POST`
- **Path:** `/pipelines/search?sort=updatedAt,desc&page=0&size=100`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Search Pipelines](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
