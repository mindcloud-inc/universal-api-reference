# Lookup Deals with Kylas CRM

## Endpoint

- **Method:** `GET`
- **Path:** `/search/deal/lookup`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Lookup Deals](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Lookup query such as name:Deal. |
