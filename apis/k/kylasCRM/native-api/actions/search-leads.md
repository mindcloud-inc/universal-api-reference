# Search Leads with Kylas CRM

Finds leads in Kylas CRM by search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/search/lead?page=0&size=10&sort=updatedAt,desc`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Search Leads](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
