# Update Contact with Kylas CRM

Updates an existing contact in Kylas CRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/{contactId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Update Contact](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The Kylas contact ID. |
