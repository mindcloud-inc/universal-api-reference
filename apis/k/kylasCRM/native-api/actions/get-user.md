# Get User with Kylas CRM

Retrieves a user from Kylas CRM by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{userId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Get User](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | no | The Kylas user ID. |
