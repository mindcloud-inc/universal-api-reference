# Search Contacts with Kylas CRM

Finds contacts in Kylas CRM by search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/search/contact?page=0&size=10&sort=updatedAt,desc`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Search Contacts](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)
