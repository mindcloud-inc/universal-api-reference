# Delete Contact with Kylas CRM

Deletes an existing contact from Kylas CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{contactId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Delete Contact](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The Kylas contact ID. |
