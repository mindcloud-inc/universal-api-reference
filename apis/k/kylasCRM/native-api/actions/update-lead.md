# Update Lead with Kylas CRM

Updates an existing lead in Kylas CRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/leads/{leadId}`
- **Base URL:** `https://api.kylas.io/v1`
- **Official documentation:** [Update Lead](https://www.postman.com/kylasqa/kylas-apis/documentation/awdync1/kylas-apis-public)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | no | The Kylas lead ID. |
