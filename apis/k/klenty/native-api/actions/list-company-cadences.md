# List Company Cadences with Klenty

Retrieves company cadences from Klenty.

## Endpoint

- **Method:** `GET`
- **Path:** `/cadences`
- **Base URL:** `https://api.klenty.com/apis/v1/user/{username}`
- **Official documentation:** [List Company Cadences](https://support.klenty.com/en/articles/8193357-klenty-s-get-api-s#h_2256ed3433)
