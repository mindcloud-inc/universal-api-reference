# Get Prospect With Custom Fields with Klenty

Retrieves a prospect with custom fields from Klenty.

## Endpoint

- **Method:** `GET`
- **Path:** `/prospects`
- **Base URL:** `https://api.klenty.com/apis/v1/user/{username}`
- **Official documentation:** [Get Prospect With Custom Fields](https://support.klenty.com/en/articles/8193357-klenty-s-get-api-s#h_08b0294b78)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Email` | query | `string` | yes | Prospect email address. |
