# Get Prospect By Email with Klenty

Retrieves a prospect from Klenty by email.

## Endpoint

- **Method:** `GET`
- **Path:** `/prospects`
- **Base URL:** `https://api.klenty.com/apis/v1/user/{username}`
- **Official documentation:** [Get Prospect By Email](https://support.klenty.com/en/articles/8193357-klenty-s-get-api-s#h_b03c6d8d4d)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Email` | query | `string` | yes | Prospect email address. |
