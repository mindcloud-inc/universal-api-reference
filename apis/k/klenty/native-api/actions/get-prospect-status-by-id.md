# Get Prospect Status By ID with Klenty

Retrieves prospect status from Klenty by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/prospects/{{id}}/status`
- **Base URL:** `https://api.klenty.com/apis/v1/user/{username}`
- **Official documentation:** [Get Prospect Status By ID](https://support.klenty.com/en/articles/8193357-klenty-s-get-api-s#h_3e316f9dcc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Klenty prospect ID. |
