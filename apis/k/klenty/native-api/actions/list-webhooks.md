# List Webhooks with Klenty

Retrieves webhooks from Klenty.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/getall`
- **Base URL:** `https://api.klenty.com/apis/v1/user/{username}`
- **Official documentation:** [List Webhooks](https://support.klenty.com/en/articles/8193357-klenty-s-get-api-s#h_d11c1fa847)
