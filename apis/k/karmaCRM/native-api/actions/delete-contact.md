# Delete Contact with Karma CRM

Deletes an existing contact from Karma CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/contacts/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Delete Contact](https://docs.karmacrm.com/#delete-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the contact to delete. |
