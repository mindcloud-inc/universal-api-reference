# Create Deal with Karma CRM

Creates a new deal in Karma CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/deals.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Create Deal](https://docs.karmacrm.com/#create-a-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deal` | body | `object` | yes | Deal payload object exactly as documented by Karma CRM. |
