# List Companies with Karma CRM

Retrieves a list of companies from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/companies.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [List Companies](https://docs.karmacrm.com/#get-all-companies)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to retrieve. |
