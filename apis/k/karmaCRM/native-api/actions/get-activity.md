# Get Activity with Karma CRM

Retrieves a specific activity from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/activities/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Get Activity](https://docs.karmacrm.com/#get-a-specific-activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the activity to retrieve. |
