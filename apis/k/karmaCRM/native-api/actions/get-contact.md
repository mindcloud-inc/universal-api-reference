# Get Contact with Karma CRM

Retrieves a specific contact from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/contacts/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Get Contact](https://docs.karmacrm.com/#get-a-specific-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the contact to retrieve. |
