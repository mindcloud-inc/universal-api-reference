# Delete Activity with Karma CRM

Deletes an existing activity from Karma CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/activities/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Delete Activity](https://docs.karmacrm.com/#delete-a-activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the activity to delete. |
