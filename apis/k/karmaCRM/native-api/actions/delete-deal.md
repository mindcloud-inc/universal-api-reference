# Delete Deal with Karma CRM

Deletes an existing deal from Karma CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/deals/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Delete Deal](https://docs.karmacrm.com/#delete-a-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the deal to delete. |
