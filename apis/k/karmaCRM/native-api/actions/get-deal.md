# Get Deal with Karma CRM

Retrieves a specific deal from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/deals/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Get Deal](https://docs.karmacrm.com/#get-a-specific-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the deal to retrieve. |
