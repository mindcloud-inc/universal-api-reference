# Get Company with Karma CRM

Retrieves a specific company from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/companies/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Get Company](https://docs.karmacrm.com/#get-a-specific-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the company to retrieve. |
