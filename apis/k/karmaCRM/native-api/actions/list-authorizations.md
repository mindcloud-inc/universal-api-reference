# List Authorizations with Karma CRM

Retrieves integration authorizations from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/settings/integrations.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [List Authorizations](https://docs.karmacrm.com/#get-all-authorizations)
