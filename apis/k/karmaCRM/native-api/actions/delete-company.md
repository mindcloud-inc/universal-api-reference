# Delete Company with Karma CRM

Deletes an existing company from Karma CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/companies/:id.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Delete Company](https://docs.karmacrm.com/#delete-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the company to delete. |
