# List Social Account Types with Karma CRM

Retrieves social account types from Karma CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/settings/social_account_types.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [List Social Account Types](https://docs.karmacrm.com/#get-all-social-account-types)
