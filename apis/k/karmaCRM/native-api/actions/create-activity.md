# Create Activity with Karma CRM

Creates a new activity in Karma CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/activities.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Create Activity](https://docs.karmacrm.com/#create-an-activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity` | body | `object` | yes | Activity payload object exactly as documented by Karma CRM. |
