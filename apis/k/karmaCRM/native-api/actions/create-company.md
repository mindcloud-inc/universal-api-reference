# Create Company with Karma CRM

Creates a new company in Karma CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v3/companies.json`
- **Base URL:** `https://app.karmacrm.com`
- **Official documentation:** [Create Company](https://docs.karmacrm.com/#create-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company` | body | `object` | yes | Company payload object exactly as documented by Karma CRM. |
