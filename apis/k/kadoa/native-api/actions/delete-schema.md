# Delete Schema with Kadoa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/schemas/:schemaId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Delete Schema](https://docs.kadoa.com/api-reference/schemas/delete-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemaId` | path | `string` | yes | Schema ID |
