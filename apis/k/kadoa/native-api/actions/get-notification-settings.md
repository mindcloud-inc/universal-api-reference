# Get Notification Settings with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/notifications/settings/:settingsId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Notification Settings](https://docs.kadoa.com/api-reference/notifications/get-notification-setting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settingsId` | path | `string` | yes | Settings ID |
