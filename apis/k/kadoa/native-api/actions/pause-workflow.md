# Pause Workflow with Kadoa

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/workflows/:workflowId/pause`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Pause Workflow](https://docs.kadoa.com/api-reference/workflows/pause-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
