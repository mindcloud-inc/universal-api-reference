# Get Change with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/changes/:changeId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Change](https://docs.kadoa.com/api-reference/monitoring/get-change-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `changeId` | path | `string` | yes | Change ID |
