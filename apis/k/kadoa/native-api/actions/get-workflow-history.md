# Get Workflow History with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/workflows/:workflowId/history`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Workflow History](https://docs.kadoa.com/api-reference/workflows/get-the-workflow-history)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
