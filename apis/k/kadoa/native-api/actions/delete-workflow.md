# Delete Workflow with Kadoa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/workflows/:workflowId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Delete Workflow](https://docs.kadoa.com/api-reference/workflows/delete-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
