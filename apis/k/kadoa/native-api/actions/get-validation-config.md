# Get Validation Config with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/data-validation/workflows/:workflowId/validation/config`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Validation Config](https://docs.kadoa.com/api-reference/data-validation/validation-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
