# Get Workflow with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/workflows/:workflowId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Workflow](https://docs.kadoa.com/api-reference/workflows/get-workflow-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
