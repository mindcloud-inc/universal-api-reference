# Delete Notification Channel with Kadoa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v5/notifications/channels/:channelId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Delete Notification Channel](https://docs.kadoa.com/api-reference/notifications/delete-notification-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Channel ID |
