# List Changes with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/changes`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [List Changes](https://docs.kadoa.com/api-reference/monitoring/get-all-changes)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
