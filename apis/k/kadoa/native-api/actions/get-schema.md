# Get Schema with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/schemas/:schemaId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Schema](https://docs.kadoa.com/api-reference/schemas/get-schema-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemaId` | path | `string` | yes | Schema ID |
