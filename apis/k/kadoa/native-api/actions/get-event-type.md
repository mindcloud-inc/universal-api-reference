# Get Event Type with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/notifications/event-types/:eventType`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Event Type](https://docs.kadoa.com/api-reference/notifications/get-event-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventType` | path | `string` | yes | Event type name |
