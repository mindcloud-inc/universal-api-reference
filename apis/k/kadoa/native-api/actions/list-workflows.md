# List Workflows with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/workflows`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [List Workflows](https://docs.kadoa.com/api-reference/workflows/get-all-workflows)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `format` | query | `list` | no | Response format. Accepted values: json, csv. Accepted values: `csv`, `json`. |
