# Delete Notification Settings with Kadoa

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v5/notifications/settings/:settingsId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Delete Notification Settings](https://docs.kadoa.com/api-reference/notifications/delete-notification-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settingsId` | path | `string` | yes | Settings ID |
