# Resume Workflow with Kadoa

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/workflows/:workflowId/resume`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Resume Workflow](https://docs.kadoa.com/api-reference/workflows/resume-a-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | Workflow ID |
