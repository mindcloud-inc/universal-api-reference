# Get Notification Channel with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/notifications/channels/:channelId`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Notification Channel](https://docs.kadoa.com/api-reference/notifications/get-notification-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | Channel ID |
| `includeConfigurations` | query | `boolean` | no | Include linked configs |
