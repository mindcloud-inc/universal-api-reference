# Get Crawl Status with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/crawl/:sessionId/status`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [Get Crawl Status](https://docs.kadoa.com/api-reference/crawling/crawling-session-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | Crawl session ID |
