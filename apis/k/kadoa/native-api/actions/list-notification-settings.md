# List Notification Settings with Kadoa

## Endpoint

- **Method:** `GET`
- **Path:** `/v5/notifications/settings`
- **Base URL:** `https://api.kadoa.com`
- **Official documentation:** [List Notification Settings](https://docs.kadoa.com/api-reference/notifications/get-notification-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | query | `string` | no | Filter by workflow ID |
| `eventType` | query | `string` | no | Filter by event type |
