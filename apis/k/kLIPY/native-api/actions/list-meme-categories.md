# List Meme Categories with KLIPY

Retrieves available meme categories from KLIPY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/static-memes/categories`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [List Meme Categories](https://docs.klipy.com/memes-api/memes-categories-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locale` | query | `string` | no |
