# List AI Emoji Categories with KLIPY

Retrieves available AI emoji categories from KLIPY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/emojis/categories`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [List AI Emoji Categories](https://docs.klipy.com/emojis-api/emojis-categories-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locale` | query | `string` | no |
