# List GIF Categories with KLIPY

Retrieves available GIF categories from KLIPY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/gifs/categories`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [List GIF Categories](https://docs.klipy.com/gifs-api/gifs-categories-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locale` | query | `string` | no | Optional country code used to localize GIF categories. |
