# Get Sticker Items with KLIPY

Retrieves stickers from KLIPY by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/stickers/items`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [Get Sticker Items](https://docs.klipy.com/stickers-api/stickers-items-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | query | `string` | no |
| `slugs` | query | `string` | no |
