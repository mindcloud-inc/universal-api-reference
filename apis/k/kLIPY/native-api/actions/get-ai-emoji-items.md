# Get AI Emoji Items with KLIPY

Retrieves AI emojis from KLIPY by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/emojis/items`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [Get AI Emoji Items](https://docs.klipy.com/emojis-api/emojis-items-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | query | `string` | no |
| `slugs` | query | `string` | no |
