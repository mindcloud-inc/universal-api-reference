# List Sticker Categories with KLIPY

Retrieves available sticker categories from KLIPY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/stickers/categories`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [List Sticker Categories](https://docs.klipy.com/stickers-api/stickers-categories-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locale` | query | `string` | no |
