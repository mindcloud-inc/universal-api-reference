# Get Clip Items with KLIPY

Retrieves clips from KLIPY by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/clips/items`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [Get Clip Items](https://docs.klipy.com/clips-api/clips-items-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | query | `string` | no |
| `slugs` | query | `string` | no |
