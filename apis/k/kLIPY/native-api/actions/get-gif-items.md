# Get GIF Items with KLIPY

Retrieves GIFs from KLIPY by ID or slug.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/gifs/items`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [Get GIF Items](https://docs.klipy.com/gifs-api/gifs-items-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids` | query | `string` | no |
| `slugs` | query | `string` | no |
