# List Clip Categories with KLIPY

Retrieves available clip categories from KLIPY.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/:app_key/clips/categories`
- **Base URL:** `https://api.klipy.com`
- **Official documentation:** [List Clip Categories](https://docs.klipy.com/clips-api/clips-categories-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locale` | query | `string` | no |
