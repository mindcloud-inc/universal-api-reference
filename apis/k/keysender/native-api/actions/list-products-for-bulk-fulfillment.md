# List Products For Bulk Fulfillment with Keysender

Retrieves products from Keysender for bulk fulfillment.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products For Bulk Fulfillment](https://panel.keysender.co.uk/api)
