# List Products By Price Range with Keysender

Retrieves products from Keysender within a price range.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Price Range](https://panel.keysender.co.uk/api)
