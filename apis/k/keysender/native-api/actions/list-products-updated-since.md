# List Products Updated Since with Keysender

Retrieves products updated since a date from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products Updated Since](https://panel.keysender.co.uk/api)
