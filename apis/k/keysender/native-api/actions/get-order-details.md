# Get Order Details with Keysender

Retrieves order details from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/order`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Get Order Details](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_id` | query | `string` | no |
