# List Products By Region with Keysender

Retrieves products from Keysender for a region.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Region](https://panel.keysender.co.uk/api)
