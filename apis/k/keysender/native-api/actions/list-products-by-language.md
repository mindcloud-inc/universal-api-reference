# List Products By Language with Keysender

Retrieves products from Keysender for a language.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Language](https://panel.keysender.co.uk/api)
