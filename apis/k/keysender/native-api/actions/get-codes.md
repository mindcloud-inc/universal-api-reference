# Get Codes with Keysender

Retrieves codes from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/codes`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Get Codes](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `database_id` | query | `string` | no |
