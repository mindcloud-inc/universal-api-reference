# List Products Sorted By Price Descending with Keysender

Retrieves products from Keysender sorted by descending price.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products Sorted By Price Descending](https://panel.keysender.co.uk/api)
