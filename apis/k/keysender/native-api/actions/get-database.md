# Get Database with Keysender

Retrieves a database from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/database`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Get Database](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `string` | no |
