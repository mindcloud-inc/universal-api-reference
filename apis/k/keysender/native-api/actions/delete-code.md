# Delete Code with Keysender

Deletes an existing code from Keysender.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/code`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Delete Code](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
