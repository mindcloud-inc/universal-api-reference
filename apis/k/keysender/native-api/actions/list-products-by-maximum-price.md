# List Products By Maximum Price with Keysender

Retrieves products from Keysender below a maximum price.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Maximum Price](https://panel.keysender.co.uk/api)
