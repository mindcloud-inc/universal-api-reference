# List Products By Region And Language with Keysender

Retrieves products from Keysender for a region and language.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Region And Language](https://panel.keysender.co.uk/api)
