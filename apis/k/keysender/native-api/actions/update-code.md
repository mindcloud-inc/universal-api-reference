# Update Code with Keysender

Updates an existing code in Keysender.

## Endpoint

- **Method:** `PUT`
- **Path:** `/code`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Update Code](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `sendfirst` | body | `string` | no |
| `status` | body | `string` | no |
