# List Discounted Products with Keysender

Retrieves discounted products from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Discounted Products](https://panel.keysender.co.uk/api)
