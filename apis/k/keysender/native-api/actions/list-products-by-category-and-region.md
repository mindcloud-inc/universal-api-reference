# List Products By Category And Region with Keysender

Retrieves products from Keysender for a category and region.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Category And Region](https://panel.keysender.co.uk/api)
