# List Products By Minimum Price with Keysender

Retrieves products from Keysender above a minimum price.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Minimum Price](https://panel.keysender.co.uk/api)
