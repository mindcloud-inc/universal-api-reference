# List Products With Additional Information with Keysender

Retrieves products with additional information from Keysender.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products With Additional Information](https://panel.keysender.co.uk/api)
