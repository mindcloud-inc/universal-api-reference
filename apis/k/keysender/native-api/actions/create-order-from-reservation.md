# Create Order From Reservation with Keysender

Creates an order from a Keysender reservation.

## Endpoint

- **Method:** `POST`
- **Path:** `/catalog/order`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Create Order From Reservation](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reservation_id` | body | `string` | no |
