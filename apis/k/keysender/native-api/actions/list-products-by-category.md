# List Products By Category with Keysender

Retrieves products from Keysender in a category.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalog/products`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [List Products By Category](https://panel.keysender.co.uk/api)
