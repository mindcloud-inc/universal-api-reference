# Add Custom Transaction with Keysender

Creates a custom transaction in Keysender.

## Endpoint

- **Method:** `POST`
- **Path:** `/transaction/addcustom`
- **Base URL:** `https://panel.keysender.co.uk/api/v1.0`
- **Official documentation:** [Add Custom Transaction](https://panel.keysender.co.uk/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `amount` | body | `string` | no |
| `currency` | body | `string` | no |
| `database_id` | body | `string` | no |
| `name` | body | `string` | no |
| `payer` | body | `string` | no |
| `quantity` | body | `string` | no |
