# Delete Subtask with Kanban Tool

## Endpoint

- **Method:** `DELETE`
- **Path:** `/subtasks/:subtask_id.json`
- **Base URL:** `https://{domain}.kanbantool.com/api/v3`
- **Official documentation:** [Delete Subtask](https://kanbantool.com/developer/api-v3#deleting-subtasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subtask_id` | path | `number` | yes | Kanban Tool subtask ID. |
