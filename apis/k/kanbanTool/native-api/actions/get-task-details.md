# Get Task Details with Kanban Tool

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:task_id.json`
- **Base URL:** `https://{domain}.kanbantool.com/api/v3`
- **Official documentation:** [Get Task Details](https://kanbantool.com/developer/api-v3#fetching-tasks-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | Kanban Tool task ID. |
