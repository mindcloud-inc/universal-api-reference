# Get Board Details with Kanban Tool

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:board_id.json`
- **Base URL:** `https://{domain}.kanbantool.com/api/v3`
- **Official documentation:** [Get Board Details](https://kanbantool.com/developer/api-v3#fetching-boards-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | path | `number` | yes | Kanban Tool board ID. |
