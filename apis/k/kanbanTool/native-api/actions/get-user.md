# Get User with Kanban Tool

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id.json`
- **Base URL:** `https://{domain}.kanbantool.com/api/v3`
- **Official documentation:** [Get User](https://kanbantool.com/developer/api-v3#fetching-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Kanban Tool user ID. |
