# Delete Time Tracker with Kanban Tool

## Endpoint

- **Method:** `DELETE`
- **Path:** `/time_trackers/:time_tracker_id.json`
- **Base URL:** `https://{domain}.kanbantool.com/api/v3`
- **Official documentation:** [Delete Time Tracker](https://kanbantool.com/developer/api-v3#deleting-time-trackers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `time_tracker_id` | path | `number` | yes | Kanban Tool time tracker ID. |
