# Create workspace with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/workspace`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Create workspace](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `type` | body | `string` | no |
| `key` | body | `string` | no |
