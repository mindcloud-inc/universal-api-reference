# Get all conversations media with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/media/conversation/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get all conversations media](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Conversation ID |
