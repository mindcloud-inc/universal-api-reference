# Track email open status through a tracking pixel. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/communication/email/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Track email open status through a tracking pixel.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the communication to track. |
