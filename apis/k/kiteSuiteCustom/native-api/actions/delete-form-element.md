# Delete form element with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/form/element/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete form element](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Form Element ID |
