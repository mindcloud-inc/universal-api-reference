# Delete a sequence by ID with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/campaign/sequence/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete a sequence by ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the sequence to delete. |
