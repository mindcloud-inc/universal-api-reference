# Check project key to workspace. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/key/exist`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Check project key to workspace.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | query | `string` | no |
