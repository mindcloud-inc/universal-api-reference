- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete WhiteBoard](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | WhiteBoard ID |
