# Get Form Element by ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form/element/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Form Element by ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the form element to retrieve. |
