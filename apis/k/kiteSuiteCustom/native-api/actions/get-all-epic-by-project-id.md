# Get All epic by projectID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/epic/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get All epic by projectID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | project ID |
