# Get notification by user Id with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/notification/user/:id?limit=5`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get notification by user Id](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | user Id |
| `limit` | query | `string` | no | — |
