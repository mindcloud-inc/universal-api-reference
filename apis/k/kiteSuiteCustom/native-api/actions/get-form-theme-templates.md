# Get Form Theme Templates with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form-theme`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Form Theme Templates](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `layout` | query | `string` | yes | Layout type to filter templates |
