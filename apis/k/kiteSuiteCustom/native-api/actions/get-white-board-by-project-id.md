# Get WhiteBoard by project Id with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/white-board/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get WhiteBoard by project Id](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID |
