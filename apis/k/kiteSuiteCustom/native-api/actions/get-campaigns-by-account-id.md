# Get campaigns by account ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaign/account/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get campaigns by account ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Email account ID. |
