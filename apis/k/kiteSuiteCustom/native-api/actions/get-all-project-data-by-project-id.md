# Get all project data by project Id with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/project/all/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get all project data by project Id](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
