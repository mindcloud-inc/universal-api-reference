# Get Whiteboard Public URL with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/white-board/public/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Whiteboard Public URL](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the whiteboard. |
