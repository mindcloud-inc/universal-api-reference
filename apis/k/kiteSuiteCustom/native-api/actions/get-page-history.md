# Get page history with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/history/page/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get page history](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Page ID |
