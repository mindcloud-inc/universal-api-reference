# Update predefined Field with Kite Suite

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/predefined-field/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Update predefined Field](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | custom field ID |
