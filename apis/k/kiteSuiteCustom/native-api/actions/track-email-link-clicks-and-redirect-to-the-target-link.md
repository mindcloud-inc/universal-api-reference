# Track email link clicks and redirect to the target link. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/communication/link/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Track email link clicks and redirect to the target link.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the link to track. |
