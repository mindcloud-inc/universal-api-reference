# Import from CSV (Import Endpoint) with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/import-export/import/csv`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Import from CSV (Import Endpoint)](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tasks[]` | body | `array` | no |
| `projectID` | body | `string` | no |
