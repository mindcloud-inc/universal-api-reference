# Update User Avatar By ID with Kite Suite

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/user/avatar/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Update User Avatar By ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | user ID |
| `avatar` | body | `string` | no | — |
