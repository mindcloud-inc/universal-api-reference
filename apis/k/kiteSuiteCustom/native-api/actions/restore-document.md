# Restore document with Kite Suite

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/document/restore/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Restore document](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID |
