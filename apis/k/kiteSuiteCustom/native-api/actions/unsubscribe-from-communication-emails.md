# Unsubscribe from communication emails. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/communication/unsubscribe/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Unsubscribe from communication emails.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the communication to unsubscribe from. |
