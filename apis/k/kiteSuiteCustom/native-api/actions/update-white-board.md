# Update WhiteBoard with Kite Suite

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v1/white-board/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Update WhiteBoard](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | WhiteBoard ID |
| `body` | body | `object` | yes | Request body |
