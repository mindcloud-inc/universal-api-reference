# Api to delete conversation from worksapce with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/conversation/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Api to delete conversation from worksapce](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Conversation Id |
