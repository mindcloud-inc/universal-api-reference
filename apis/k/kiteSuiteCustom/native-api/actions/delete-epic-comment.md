# Delete Epic comment with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/epic/comment/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Epic comment](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Comment Id |
