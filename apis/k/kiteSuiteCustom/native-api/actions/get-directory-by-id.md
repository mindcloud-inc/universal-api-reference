# Get Directory by Id with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/directory/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Directory by Id](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Directory ID |
