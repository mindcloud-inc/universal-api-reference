# Get form by form ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get form by form ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Form ID |
