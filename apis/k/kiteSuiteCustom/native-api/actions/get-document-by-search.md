# Get document by search with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/document/search/query`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get document by search](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | search text |
