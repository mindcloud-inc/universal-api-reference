# Update communication with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/communication/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Update communication](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Update field ID |
