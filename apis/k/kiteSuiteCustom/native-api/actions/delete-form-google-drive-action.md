# Delete Form Google Drive Action with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/form/integration/google-drive/actions/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Form Google Drive Action](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Google Drive action to delete. |
