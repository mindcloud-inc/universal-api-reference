# Get Team by Id with Kite Suite

- **Method:** `GET`
- **Path:** `/api/v1/team/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Team by Id](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team ID |
