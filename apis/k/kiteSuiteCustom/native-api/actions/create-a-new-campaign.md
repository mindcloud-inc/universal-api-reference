# Create a new campaign with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/campaign`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Create a new campaign](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Request body |
| `name` | body | `string` | yes | Name of the campaign. |
