# Get Public Document by ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/document/public/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Public Document by ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the document. |
