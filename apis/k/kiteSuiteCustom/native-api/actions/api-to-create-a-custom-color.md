# Api to create a custom color with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/custom-color`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Api to create a custom color](https://api.kitesuite.com/swagger/)

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Request body |
