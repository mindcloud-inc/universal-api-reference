# Get documents by project ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/document/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get documents by project ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID |
