- **Path:** `/api/v1/page/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete page](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Page ID |
