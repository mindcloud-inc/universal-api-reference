# Upload Attachment with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/media/upload`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Upload Attachment](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | query | `string` | no |
| `folder` | query | `string` | no |
| `attachment` | body | `string` | no |
