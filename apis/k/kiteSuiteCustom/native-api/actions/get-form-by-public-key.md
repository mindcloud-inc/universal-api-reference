# Get form by public key with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form/public/:publicKey`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get form by public key](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `publicKey` | path | `string` | yes | Form public Key |
