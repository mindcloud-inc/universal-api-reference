# Get task by serial number. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/task/sn/:sn?key=`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get task by serial number.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sn` | path | `string` | yes | serial number |
| `key` | query | `string` | yes | project key |
