# Get messages based on pagination with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/chat/conversation/:id?limit=10?page=1`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get messages based on pagination](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | — |
| `page` | query | `number` | no | — |
| `id` | path | `string` | no | Project ID |
