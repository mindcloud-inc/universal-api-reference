# Get campaign by ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaign/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get campaign by ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Campaign ID. |
