# Api to delete message from group with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/chat/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Api to delete message from group](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Message Id |
