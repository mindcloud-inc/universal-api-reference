# update form submission with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/form/public/submission/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [update form submission](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Form submission ID |
| `body` | body | `object` | yes | Request body |
