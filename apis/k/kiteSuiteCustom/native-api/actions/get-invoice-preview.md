# Get Invoice Preview with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form/invoice/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Invoice Preview](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the form element. |
