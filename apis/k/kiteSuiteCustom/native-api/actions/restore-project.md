# Restore project with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/project/restore`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Restore project](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectID` | body | `string` | no |
