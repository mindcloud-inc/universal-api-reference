# Delete a campaign by its ID with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/campaign/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete a campaign by its ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the campaign to delete. |
