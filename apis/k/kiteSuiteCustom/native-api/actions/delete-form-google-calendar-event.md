# Delete Form Google Calendar Event with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/form/integration/google-calendar/events/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Form Google Calendar Event](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Google Calendar event to delete. |
