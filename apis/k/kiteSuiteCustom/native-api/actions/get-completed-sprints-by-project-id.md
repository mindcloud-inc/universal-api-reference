- **Method:** `GET`

- **Official documentation:** [Get completed sprints by projectID.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectID` | path | `string` | no |
