# Delete Form Theme with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/form/theme/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Form Theme](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Form Theme ID to delete |
