# Download document by document ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/document/all/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Download document by document ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID |
