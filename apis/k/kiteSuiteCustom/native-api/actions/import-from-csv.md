# Import from CSV with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/import-export/csv`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Import from CSV](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `csv` | body | `string` | no |
| `projectID` | body | `string` | no |
