# Delete Epic with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/epic/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete Epic](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Epic ID |
