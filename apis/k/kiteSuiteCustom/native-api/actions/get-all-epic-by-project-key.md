# Get All epic by project key with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/epic/project/key/:key`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get All epic by project key](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | project key |
