# Get Form Integrations by Form ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/form/integrations/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Form Integrations by Form ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the form to retrieve integrations for. |
