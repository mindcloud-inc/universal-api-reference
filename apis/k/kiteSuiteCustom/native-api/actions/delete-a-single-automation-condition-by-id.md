# Delete a single automation condition by ID with Kite Suite

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/automation/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Delete a single automation condition by ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The automation condition ID |
