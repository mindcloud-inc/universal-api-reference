# Upload Epic Attachment with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/epic/upload`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Upload Epic Attachment](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `attachment` | body | `string` | no |
| `projectID` | body | `string` | no |
