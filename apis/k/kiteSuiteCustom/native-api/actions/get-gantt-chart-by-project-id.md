# Get Gantt chart by project ID with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/gantt/project/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get Gantt chart by project ID](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the project associated with the Gantt chart |
