# Get communications of a specific thread. with Kite Suite

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/communication/email/thread/:id`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Get communications of a specific thread.](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | thread ID |
