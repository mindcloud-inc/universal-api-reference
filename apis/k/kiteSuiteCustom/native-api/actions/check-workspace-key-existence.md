# Check Workspace Key Existence with Kite Suite

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/workspace/key-exists`
- **Base URL:** `https://api.kitesuite.com`
- **Official documentation:** [Check Workspace Key Existence](https://api.kitesuite.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | Request body |
| `key` | body | `string` | yes | Workspace key to check. |
