# List Records with Knack

## Endpoint

- **Method:** `GET`
- **Path:** `/objects/:object_key/records`
- **Base URL:** `https://api.knack.com/v1`
- **Official documentation:** [List Records](https://docs.knack.com/v3/reference/retrieving-records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object_key` | path | `string` | yes | Knack object key from the Builder URL, such as object_3. |
