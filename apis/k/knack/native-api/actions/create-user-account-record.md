# Create User Account Record with Knack

## Endpoint

- **Method:** `POST`
- **Path:** `/objects/:object_key/records`
- **Base URL:** `https://api.knack.com/v1`
- **Official documentation:** [Create User Account Record](https://docs.knack.com/v3/docs/managing-user-records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object_key` | path | `string` | yes | User object key, such as object_1. |
