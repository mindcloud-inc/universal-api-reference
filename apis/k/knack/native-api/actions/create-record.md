# Create Record with Knack

## Endpoint

- **Method:** `POST`
- **Path:** `/objects/:object_key/records`
- **Base URL:** `https://api.knack.com/v1`
- **Official documentation:** [Create Record](https://docs.knack.com/reference/object-based-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `object_key` | path | `string` | yes | Knack object key from the Builder URL, such as object_3. |
