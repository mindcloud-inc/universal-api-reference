# Get Transform Job Metrics with Kazm

Retrieves transform job metrics from Kazm.

## Endpoint

- **Method:** `GET`
- **Path:** `/transform-jobs/:jobId/metrics`
- **Base URL:** `https://api.lightningrod.ai/api/public/v1`
- **Official documentation:** [Get Transform Job Metrics](https://docs.lightningrod.ai/rest-api/datasets)
