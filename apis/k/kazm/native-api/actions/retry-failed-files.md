# Retry Failed Files with Kazm

Retries failed files in a Kazm file set.

## Endpoint

- **Method:** `POST`
- **Path:** `/filesets/:fileSetId/retry-failed`
- **Base URL:** `https://api.lightningrod.ai/api/public/v1`
- **Official documentation:** [Retry Failed Files](https://docs.lightningrod.ai/rest-api)
