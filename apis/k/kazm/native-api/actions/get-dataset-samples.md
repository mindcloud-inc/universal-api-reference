# Get Dataset Samples with Kazm

Retrieves dataset samples from Kazm.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets/:datasetId/samples`
- **Base URL:** `https://api.lightningrod.ai/api/public/v1`
- **Official documentation:** [Get Dataset Samples](https://docs.lightningrod.ai/rest-api/training-jobs)
