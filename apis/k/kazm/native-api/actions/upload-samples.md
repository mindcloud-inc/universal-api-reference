# Upload Samples with Kazm

Uploads samples to a Kazm dataset.

## Endpoint

- **Method:** `POST`
- **Path:** `/datasets/:datasetId/samples`
- **Base URL:** `https://api.lightningrod.ai/api/public/v1`
- **Official documentation:** [Upload Samples](https://docs.lightningrod.ai/rest-api/training-jobs)
