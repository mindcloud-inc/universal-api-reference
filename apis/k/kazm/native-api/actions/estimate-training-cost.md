# Estimate Training Cost with Kazm

Retrieves a training cost estimate from Kazm.

## Endpoint

- **Method:** `POST`
- **Path:** `/training-jobs/cost-estimation`
- **Base URL:** `https://api.lightningrod.ai/api/public/v1`
- **Official documentation:** [Estimate Training Cost](https://docs.lightningrod.ai/rest-api/evaluations)
