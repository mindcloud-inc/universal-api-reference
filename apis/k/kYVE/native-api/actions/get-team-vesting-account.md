# Get Team Vesting Account with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/team/v1beta1/team_vesting_account/{id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Team Vesting Account](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team vesting account ID. |
