# Get Finalized Bundle with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/v1/bundles/{pool_id}/{id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Finalized Bundle](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pool_id` | path | `string` | yes | Pool ID for the finalized bundle. |
| `id` | path | `string` | yes | Finalized bundle ID. |
