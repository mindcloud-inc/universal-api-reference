# Get Tokenize Share Record Rewards with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/liquid/v1beta1/{owner_address}/tokenize_share_record_rewards`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Tokenize Share Record Rewards](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `owner_address` | path | `string` | yes | Owner address to query tokenize share record rewards for. |
