# Get Funder with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/funder/{address}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Funder](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | KYVE funder address. |
