# List Fundings By Funder with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/fundings_by_funder/{address}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [List Fundings By Funder](https://api.kyve.network/static/openapi.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | KYVE funder address. |
