# List Fundings By Pool with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/fundings_by_pool/{pool_id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [List Fundings By Pool](https://api.kyve.network/static/openapi.yml)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pool_id` | path | `string` | yes | Pool ID to list fundings for. |
