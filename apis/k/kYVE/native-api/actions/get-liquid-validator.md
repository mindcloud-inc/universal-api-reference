# Get Liquid Validator with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/liquid/v1beta1/liquid_validator/{validator_addr}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Liquid Validator](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `validator_addr` | path | `string` | yes | Liquid validator address. |
