# Get Current Vote Status with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/current_vote_status/{pool_id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Current Vote Status](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pool_id` | path | `string` | yes | Pool ID to query current vote status for. |
