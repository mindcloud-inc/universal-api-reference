# Get Staker with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1/staker/{address}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Staker](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | KYVE account or staker address. |
