# Get Pool with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/pool/{id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Pool](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique ID of the KYVE pool. |
