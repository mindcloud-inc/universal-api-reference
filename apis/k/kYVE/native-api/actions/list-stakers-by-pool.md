# List Stakers By Pool with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1/stakers_by_pool/{pool_id}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [List Stakers By Pool](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pool_id` | path | `string` | yes | Pool ID to list active stakers for. |
