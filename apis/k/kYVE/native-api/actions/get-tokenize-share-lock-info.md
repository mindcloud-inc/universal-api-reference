# Get Tokenize Share Lock Info with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/liquid/v1beta1/tokenize_share_lock_info/{address}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [Get Tokenize Share Lock Info](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | Address to query tokenize share lock status for. |
