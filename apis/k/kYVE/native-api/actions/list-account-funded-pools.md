# List Account Funded Pools with KYVE

## Endpoint

- **Method:** `GET`
- **Path:** `/kyve/query/v1beta1/account_funded_list/{address}`
- **Base URL:** `https://api.kyve.network`
- **Official documentation:** [List Account Funded Pools](https://api.kyve.network/static/openapi.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | path | `string` | yes | KYVE account address. |
