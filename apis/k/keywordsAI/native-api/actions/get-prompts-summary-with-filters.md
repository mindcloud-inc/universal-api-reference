# Get Prompts Summary With Filters with Keywords AI

Retrieves filtered prompt summary statistics from Keywords AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/prompts/summary/`
- **Base URL:** `https://api.respan.ai`
- **Official documentation:** [Get Prompts Summary With Filters](https://www.respan.ai/docs/apis/prompts/get-prompts-summary-with-filters)
