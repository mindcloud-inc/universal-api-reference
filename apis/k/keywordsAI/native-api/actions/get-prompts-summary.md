# Get Prompts Summary with Keywords AI

Retrieves prompt summary statistics from Keywords AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/prompts/summary/`
- **Base URL:** `https://api.respan.ai`
- **Official documentation:** [Get Prompts Summary](https://www.respan.ai/docs/apis/prompts/get-prompts-summary)
