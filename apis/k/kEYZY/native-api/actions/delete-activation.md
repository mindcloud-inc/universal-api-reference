# Delete Activation with KEYZY

Deletes a license activation from KEYZY.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/activations/:id`
- **Base URL:** `https://api.keyzy.io/v2`
- **Official documentation:** [Delete Activation](https://www.keyzy.io/docs/developers/rest-api/activations-delete/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the activation object. |
