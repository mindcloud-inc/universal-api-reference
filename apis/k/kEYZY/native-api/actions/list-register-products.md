# List Register Products with KEYZY

Checks serial eligibility and previews registered products in KEYZY.

## Endpoint

- **Method:** `GET`
- **Path:** `/register-products/:serial`
- **Base URL:** `https://api.keyzy.io/v2`
- **Official documentation:** [List Register Products](https://www.keyzy.io/docs/developers/rest-api/licenses-register-products/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serial` | path | `string` | yes | A license serial number. |
