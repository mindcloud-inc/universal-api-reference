# List License Products with KEYZY

Retrieves products related to a KEYZY license.

## Endpoint

- **Method:** `POST`
- **Path:** `/licenses/products`
- **Base URL:** `https://api.keyzy.io/v2`
- **Official documentation:** [List License Products](https://www.keyzy.io/docs/developers/rest-api/licenses-products/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serial` | body | `string` | yes | Serial number of the customer. |
