# Get License with KEYZY

Retrieves details for a specific KEYZY license.

## Endpoint

- **Method:** `GET`
- **Path:** `/licenses/show-license/:serial`
- **Base URL:** `https://api.keyzy.io/v2`
- **Official documentation:** [Get License](https://www.keyzy.io/docs/developers/rest-api/licenses-show-license/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serial` | path | `string` | yes | A license serial number. |
