# Delete Contact with Keap

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/{contact_id}`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Delete Contact](https://developer.keap.com/docs/restv2/#tag/Contact/operation/deleteContact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | The unique identifier of the contact. |
