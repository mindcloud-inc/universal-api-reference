# Get Opportunity with Keap

## Endpoint

- **Method:** `GET`
- **Path:** `/opportunities/:opportunity_id`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Get Opportunity](https://developer.keap.com/docs/restv2/#tag/Opportunity/operation/getOpportunity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `opportunity_id` | path | `string` | yes | The unique identifier of the opportunity. |
