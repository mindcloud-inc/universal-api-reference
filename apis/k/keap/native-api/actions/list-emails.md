# List Emails with Keap

## Endpoint

- **Method:** `GET`
- **Path:** `/emails`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [List Emails](https://developer.keap.com/docs/restv2/#tag/Email/operation/listEmails)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
