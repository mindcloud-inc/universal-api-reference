- **Method:** `GET`
- **Path:** `/companies/:company_id`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Get Company](https://developer.keap.com/docs/restv2/#tag/Company/operation/getCompany)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | The unique identifier of the company. |
| `fields` | query | `string` | no | — |
