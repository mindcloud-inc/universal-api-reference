# Get File with Keap

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:file_id`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Get File](https://developer.keap.com/docs/restv2/#tag/File/operation/getFile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | The unique identifier of the file. |
