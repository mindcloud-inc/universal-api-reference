# Get Task with Keap

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:task_id`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Get Task](https://developer.keap.com/docs/restv2/#tag/Task/operation/getTask)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The unique identifier of the task. |
