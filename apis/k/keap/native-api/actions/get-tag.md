# Get Tag with Keap

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://api.infusionsoft.com/crm/rest/v2`
- **Official documentation:** [Get Tag](https://developer.keap.com/docs/restv2/#tag/Tag/operation/getTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `string` | yes | The unique identifier of the tag. |
