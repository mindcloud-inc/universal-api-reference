# Retrieve a Note with Histre

Retrieves a note from Histre.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/note/`
- **Base URL:** `https://histre.com`
- **Official documentation:** [Retrieve a Note](https://histre.com/features/api/notes/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL whose Histre note should be retrieved. |
