# List All Collections with Histre

Retrieves collections from Histre.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/collections/`
- **Base URL:** `https://histre.com`
- **Official documentation:** [List All Collections](https://histre.com/features/api/collections/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Optional page number for paginated collection results. |
