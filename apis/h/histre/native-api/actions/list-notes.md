# List Notes with Histre

Retrieves notes from Histre.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/note/`
- **Base URL:** `https://histre.com`
- **Official documentation:** [List Notes](https://histre.com/features/api/notes/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Optional page number for paginated Histre note results. |
