# Delete Highlight with Histre

Deletes a highlight from Histre.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/highlight/`
- **Base URL:** `https://histre.com`
- **Official documentation:** [Delete Highlight](https://histre.com/features/api/highlights/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `highlight_id` | body | `string` | yes | Identifier of the highlight to delete. |
