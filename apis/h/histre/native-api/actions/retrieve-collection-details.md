# Retrieve Collection Details with Histre

Retrieves collection details from Histre.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/collections/[:book_id]/`
- **Base URL:** `https://histre.com`
- **Official documentation:** [Retrieve Collection Details](https://histre.com/features/api/collections/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `book_id` | path | `string` | yes | Identifier of the Histre collection to retrieve. |
