# Get Reminder with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/reminder/:reminderID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Reminder](https://developer.hrpartner.io/#get-a-specific-reminder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reminderID` | path | `string` | yes | Reminder ID from HR Partner. |
