# List Expense Claims with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [List Expense Claims](https://developer.hrpartner.io/#get-all-expense-claims)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `report_type` | query | `string` | yes | Expense report type: detailed, summary, or transaction. |
