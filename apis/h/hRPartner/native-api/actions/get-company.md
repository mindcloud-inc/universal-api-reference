# Get Company with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/company`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Company](https://developer.hrpartner.io/#company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custom_fields` | query | `boolean` | no | Include all employee custom fields in the company response. |
| `active_modules` | query | `boolean` | no | Include the list of active HR Partner modules in the company response. |
