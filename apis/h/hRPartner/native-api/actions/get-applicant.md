# Get Applicant with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/applicant/:applicantID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Applicant](https://developer.hrpartner.io/#get-a-specific-applicant)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `applicantID` | path | `string` | yes | Applicant ID from HR Partner. |
