# Get Employee with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/employee/:employeeCode`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Employee](https://developer.hrpartner.io/#get-a-specific-employee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employeeCode` | path | `string` | yes | Employee code from HR Partner. |
