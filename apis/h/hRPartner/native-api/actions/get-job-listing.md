# Get Job Listing with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/job/:jobID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Job Listing](https://developer.hrpartner.io/#get-a-specific-job-listing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobID` | path | `string` | yes | Job listing ID from HR Partner. |
