# Get Application with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/application/:applicationID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Application](https://developer.hrpartner.io/#get-a-specific-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `applicationID` | path | `string` | yes | Application ID from HR Partner. |
