# Update Reminder with HR Partner

## Endpoint

- **Method:** `POST`
- **Path:** `/reminder/:reminderID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Update Reminder](https://developer.hrpartner.io/#update-a-reminder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reminderID` | path | `string` | yes | Reminder ID from HR Partner. |
