# Get Leave Request with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/leave_request/:leaverequestID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [Get Leave Request](https://developer.hrpartner.io/#get-a-specific-leave-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leaverequestID` | path | `string` | yes | Leave request ID from HR Partner. |
