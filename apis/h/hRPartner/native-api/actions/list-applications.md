# List Applications with HR Partner

## Endpoint

- **Method:** `GET`
- **Path:** `/applications/:jobID`
- **Base URL:** `https://api.hrpartner.io`
- **Official documentation:** [List Applications](https://developer.hrpartner.io/#get-all-applications)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobID` | path | `string` | yes | Job listing ID from HR Partner. |
