# Retrieve Component with Harvestr.io

## Endpoint

- **Method:** `GET`
- **Path:** `/component/{id}`
- **Base URL:** `https://rest.harvestr.io/v1`
- **Official documentation:** [Retrieve Component](https://developers.harvestr.io/api/retrieve-a-component/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier (id or clientId) |
