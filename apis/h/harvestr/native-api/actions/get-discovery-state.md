# Get Discovery State with Harvestr.io

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery/{id}/discovery-state`
- **Base URL:** `https://rest.harvestr.io/v1`
- **Official documentation:** [Get Discovery State](https://developers.harvestr.io/api/get-discoverys-discovery-state/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier (id or clientId) |
