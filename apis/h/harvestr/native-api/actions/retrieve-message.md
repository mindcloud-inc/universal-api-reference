# Retrieve Message with Harvestr.io

## Endpoint

- **Method:** `GET`
- **Path:** `/message/{id}`
- **Base URL:** `https://rest.harvestr.io/v1`
- **Official documentation:** [Retrieve Message](https://developers.harvestr.io/api/retrieve-a-message/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier (id or clientId) |
