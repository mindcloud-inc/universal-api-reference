# Retrieve Discovery State with Harvestr.io

## Endpoint

- **Method:** `GET`
- **Path:** `/discovery-state/{id}`
- **Base URL:** `https://rest.harvestr.io/v1`
- **Official documentation:** [Retrieve Discovery State](https://developers.harvestr.io/api/retrieve-discovery-state/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier (id or clientId) |
