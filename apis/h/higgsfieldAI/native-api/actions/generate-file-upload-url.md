# Generate File Upload URL with Higgsfield AI

## Endpoint

- **Method:** `POST`
- **Path:** `/files/generate-upload-url`
- **Base URL:** `https://platform.higgsfield.ai`
- **Official documentation:** [Generate File Upload URL](https://docs.higgsfield.ai/how-to/sdk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content_type` | body | `string` | no | MIME type for the file to upload, for example image/jpeg. |
