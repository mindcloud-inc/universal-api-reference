# Download Shareholders List Document with Handelsregister AI

Retrieves a shareholders list document from Handelsregister AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/fetch-document`
- **Base URL:** `https://handelsregister.ai/api/v1`
- **Official documentation:** [Download Shareholders List Document](https://handelsregister.ai/en/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `string` | yes | Unique company entity ID from search results. |
