# Get Performance Analytics with Hamsa

Retrieves voice agent performance analytics from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agent-analytics/performance`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Performance Analytics](https://docs.tryhamsa.com/api-reference/endpoint/get-performance-analytics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endPeriod` | query | `string` | no |
| `period` | query | `string` | no |
| `startPeriod` | query | `string` | no |
| `timeDifference` | query | `string` | no |
| `voiceAgentId` | query | `string` | no |
