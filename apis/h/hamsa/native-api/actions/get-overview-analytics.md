# Get Overview Analytics with Hamsa

Retrieves voice agent overview analytics from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agent-analytics/overview`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Overview Analytics](https://docs.tryhamsa.com/api-reference/endpoint/get-overview-analytics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endPeriod` | query | `string` | no |
| `period` | query | `string` | no |
| `startPeriod` | query | `string` | no |
| `timeDifference` | query | `string` | no |
| `voiceAgentId` | query | `string` | no |
