# Get Satisfaction and Outcome Analytics with Hamsa

Retrieves voice agent satisfaction and outcome analytics from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agent-analytics/satisfaction`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Satisfaction and Outcome Analytics](https://docs.tryhamsa.com/api-reference/endpoint/get-satisfaction-analytics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endPeriod` | query | `string` | no |
| `period` | query | `string` | no |
| `startPeriod` | query | `string` | no |
| `timeDifference` | query | `string` | no |
| `voiceAgentId` | query | `string` | no |
