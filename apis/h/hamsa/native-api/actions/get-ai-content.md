# Get AI Content with Hamsa

Retrieves AI content from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/jobs/ai-content`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get AI Content](https://docs.tryhamsa.com/api-reference/endpoint/get-ai-content)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | query | `string` | yes |
