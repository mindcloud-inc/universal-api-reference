# Get Phone Number by its ID with Hamsa

Retrieves a phone number from Hamsa by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/voice-agents/phone-number`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Phone Number by its ID](https://docs.tryhamsa.com/api-reference/endpoint/get-phone-number)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pid` | query | `string` | yes |
| `pid` | query | `string` | yes |
