# Get a web tool by ID with Hamsa

Retrieves a web tool from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/voice-agents/web-tool/{id}`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get a web tool by ID](https://docs.tryhamsa.com/api-reference/get-a-web-tool-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
