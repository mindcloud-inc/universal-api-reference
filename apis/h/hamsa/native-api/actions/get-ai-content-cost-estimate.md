# Get AI Content Cost Estimate with Hamsa

Retrieves an AI content cost estimate from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/jobs/ai-content/estimate`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get AI Content Cost Estimate](https://docs.tryhamsa.com/api-reference/endpoint/get-ai-content-cost-estimate)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | query | `string` | yes |
