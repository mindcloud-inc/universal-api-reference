# Get Project By API Key with Hamsa

Retrieves a project from Hamsa by API key.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/by-api-key`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Project By API Key](https://docs.tryhamsa.com/api-reference/endpoint/get-project-by-api-key)
