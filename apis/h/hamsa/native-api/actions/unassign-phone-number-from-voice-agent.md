# Unassign Phone Number from Voice Agent with Hamsa

Unassigns a phone number from a Hamsa voice agent.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/voice-agents/unassign`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Unassign Phone Number from Voice Agent](https://docs.tryhamsa.com/api-reference/endpoint/unassign-phone-number)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phoneNumber` | body | `string` | yes |
