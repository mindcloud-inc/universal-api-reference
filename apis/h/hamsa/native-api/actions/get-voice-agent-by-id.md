# Get Voice Agent By Id with Hamsa

Retrieves a voice agent from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/voice-agents/:voiceAgentId`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [Get Voice Agent By Id](https://docs.tryhamsa.com/api-reference/endpoint/get-voice-agent-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `voiceAgentId` | path | `string` | yes |
