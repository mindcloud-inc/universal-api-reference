# List User Phone Numbers with Hamsa

Retrieves your phone numbers from Hamsa.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/voice-agents/phone-number/list`
- **Base URL:** `https://api.tryhamsa.com`
- **Official documentation:** [List User Phone Numbers](https://docs.tryhamsa.com/api-reference/endpoint/list-phone-numbers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `provider` | query | `string` | no |
| `skip` | query | `number` | no |
| `take` | query | `number` | no |
| `voiceAgentId` | query | `string` | no |
