# List Stock Transfers with Hiboutik

Retrieves stock transfers from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock_transfer/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Stock Transfers](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
