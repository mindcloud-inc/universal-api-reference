# List Pending Credit Notes with Hiboutik

Retrieves pending credit notes for a store in Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/credit_notes/:store_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Pending Credit Notes](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store_id` | path | `string` | no | The Hiboutik store id. |
