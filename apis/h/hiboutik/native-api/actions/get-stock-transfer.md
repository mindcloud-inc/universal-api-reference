# Get Stock Transfer with Hiboutik

Retrieves a stock transfer from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock_transfer/:transfer_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Stock Transfer](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
