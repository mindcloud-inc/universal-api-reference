# Get Product with Hiboutik

Retrieves a product from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Product](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | no | The Hiboutik product id. |
