# List Stock Transfer Details with Hiboutik

Retrieves stock transfer details from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock_transfer_details/:transfer_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Stock Transfer Details](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
