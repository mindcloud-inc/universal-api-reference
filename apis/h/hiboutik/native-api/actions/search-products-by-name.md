# Search Products By Name with Hiboutik

Finds products in Hiboutik by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/search/name/:q`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Search Products By Name](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | path | `string` | no | The product name search term. |
