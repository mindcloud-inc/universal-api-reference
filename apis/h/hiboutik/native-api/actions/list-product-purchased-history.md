# List Product Purchased History with Hiboutik

Retrieves purchased product history from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/product_purchased_history/:product_id/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Product Purchased History](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `string` | no | The Hiboutik product id. |
