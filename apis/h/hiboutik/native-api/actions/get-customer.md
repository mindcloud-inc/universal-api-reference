# Get Customer with Hiboutik

Retrieves a customer from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:customers_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Customer](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customers_id` | path | `string` | no | The Hiboutik customer id. |
