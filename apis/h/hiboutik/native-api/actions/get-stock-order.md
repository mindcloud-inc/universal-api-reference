# Get Stock Order with Hiboutik

Retrieves a stock order from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory_inputs/:inventory_input_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Stock Order](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
