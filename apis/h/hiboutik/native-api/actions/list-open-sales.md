# List Open Sales with Hiboutik

Retrieves open sales for a store in Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/open_sales/:store_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Open Sales](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store_id` | path | `string` | no | The Hiboutik store id. |
