# List Kitchen Open Tables with Hiboutik

Retrieves pending kitchen sales from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/kitchen/open_tables`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Kitchen Open Tables](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
