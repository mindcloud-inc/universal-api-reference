# List Categories with Hiboutik

Retrieves product categories from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Categories](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
