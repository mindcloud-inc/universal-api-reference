# Get Calendar Event with Hiboutik

Retrieves a calendar event from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar/event/:event_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Calendar Event](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
