# List Payment Types with Hiboutik

Retrieves payment types for a store in Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment_types/:store_id/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Payment Types](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store_id` | path | `string` | no | The Hiboutik store id. |
