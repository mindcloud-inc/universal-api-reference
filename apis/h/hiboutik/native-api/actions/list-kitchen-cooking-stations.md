# List Kitchen Cooking Stations with Hiboutik

Retrieves kitchen cooking stations from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/kitchen/cooking_stations`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Kitchen Cooking Stations](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
