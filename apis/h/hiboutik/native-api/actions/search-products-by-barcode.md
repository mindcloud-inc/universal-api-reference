# Search Products By Barcode with Hiboutik

Finds products in Hiboutik by barcode.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/search/barcode/:q/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Search Products By Barcode](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | path | `string` | no | The product barcode search term. |
