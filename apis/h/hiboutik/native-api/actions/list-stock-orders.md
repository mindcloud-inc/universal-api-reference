# List Stock Orders with Hiboutik

Retrieves stock orders from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory_inputs/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Stock Orders](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
