# Get First Closed Sale with Hiboutik

Retrieves the first closed sale for a store in Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/first_closed_sale/:store_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get First Closed Sale](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store_id` | path | `string` | no | The Hiboutik store id. |
