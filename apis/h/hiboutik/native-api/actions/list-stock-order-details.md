# List Stock Order Details with Hiboutik

Retrieves stock order details from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory_input_details/:inventory_input_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Stock Order Details](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
