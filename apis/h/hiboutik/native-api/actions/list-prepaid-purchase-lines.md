# List Prepaid Purchase Lines with Hiboutik

Retrieves prepaid purchase lines from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/prepaid_purchases/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Prepaid Purchase Lines](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)
