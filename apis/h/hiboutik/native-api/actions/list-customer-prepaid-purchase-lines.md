# List Customer Prepaid Purchase Lines with Hiboutik

Retrieves prepaid purchase lines for a customer in Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/prepaid_purchases/:customers_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [List Customer Prepaid Purchase Lines](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customers_id` | path | `string` | no | The Hiboutik customer id. |
