# List Stock Order Details on Hold with Hiboutik

Retrieves on-hold stock order details from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory_inputs_on_hold/`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
