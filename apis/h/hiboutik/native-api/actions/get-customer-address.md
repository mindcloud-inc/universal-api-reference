# Get Customer Address with Hiboutik

Retrieves a customer address from Hiboutik.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers_addresses/:address_id`
- **Base URL:** `https://mindcloudhiboutik20260402.hiboutik.com/api`
- **Official documentation:** [Get Customer Address](https://mindcloudhiboutik20260402.hiboutik.com/docapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address_id` | path | `string` | no | The Hiboutik customer address id. |
