# List Articles with HelpDocs

Retrieves articles from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/article`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [List Articles](https://apidocs.helpdocs.io/article/OqvaxRMHgN-getting-articles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
