# Delete Clip with HelpDocs

Deletes an existing clip from HelpDocs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clip/:clip_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Delete Clip](https://apidocs.helpdocs.io/category/n1i20sex9q-clips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clip_id` | path | `string` | yes | Clip ID to delete. |
