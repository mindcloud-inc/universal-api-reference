# Get Article with HelpDocs

Retrieves an article from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/article/:article_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Get Article](https://apidocs.helpdocs.io/category/Z83io6YtSs-articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `article_id` | path | `string` | yes | Article ID to fetch. |
