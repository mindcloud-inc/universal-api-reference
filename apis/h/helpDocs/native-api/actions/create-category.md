# Create Category with HelpDocs

Creates a new category in HelpDocs.

## Endpoint

- **Method:** `POST`
- **Path:** `/category`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Create Category](https://apidocs.helpdocs.io/category/9UJDUIt9h0-categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `description` | body | `string` | no | Category description. |
| `title` | body | `string` | yes | Category title. |
