# Delete Group with HelpDocs

Deletes an existing group from HelpDocs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/account/group/:group_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Delete Group](https://apidocs.helpdocs.io/article/5z6h2zwa29-deleting-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | Group ID to delete. |
