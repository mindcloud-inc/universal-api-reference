# Generate Chatbot Source Page with HelpDocs

Generates a chatbot source page from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/article`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Generate Chatbot Source Page](https://apidocs.helpdocs.io/article/4xha228dwf-generating-a-chatbot-source-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_domain` | query | `string` | no | Account domain for permissioned content. |
| `hd_jwt` | query | `string` | no | JWT for permissioned content. |
