# Get Clip with HelpDocs

Retrieves a clip from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/clip/:clip_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Get Clip](https://apidocs.helpdocs.io/category/n1i20sex9q-clips)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clip_id` | path | `string` | yes | Clip ID to fetch. |
