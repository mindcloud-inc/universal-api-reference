# Create Clip with HelpDocs

Creates a new clip in HelpDocs.

## Endpoint

- **Method:** `POST`
- **Path:** `/clip`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Create Clip](https://apidocs.helpdocs.io/article/jpaw9kp9wg-creating-a-clip)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Clip title. |
| `content` | body | `string` | yes | Clip content. |
