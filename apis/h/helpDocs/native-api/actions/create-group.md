# Create Group with HelpDocs

Creates a new group in HelpDocs.

## Endpoint

- **Method:** `POST`
- **Path:** `/account/group`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Create Group](https://apidocs.helpdocs.io/article/b80vu2xkz6-creating-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Permission group name. |
