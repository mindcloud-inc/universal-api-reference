# Delete Category with HelpDocs

Deletes an existing category from HelpDocs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/category/:category_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Delete Category](https://apidocs.helpdocs.io/article/Hw8fVbXt1V-deleting-a-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | path | `string` | yes | Category ID to delete. |
