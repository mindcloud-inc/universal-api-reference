# Get Category with HelpDocs

Retrieves a category from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/category/:category_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Get Category](https://apidocs.helpdocs.io/category/9UJDUIt9h0-categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | path | `string` | yes | Category ID to fetch. |
