# Delete Article with HelpDocs

Deletes an existing article from HelpDocs.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/article/:article_id`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Delete Article](https://apidocs.helpdocs.io/article/0iyvUUh7py-deleting-an-article)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `article_id` | path | `string` | yes | Article ID to delete. |
