# Get Aggregate Time Series Data with HelpDocs

Retrieves aggregate time series data from HelpDocs.

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/graph`
- **Base URL:** `https://api.helpdocs.io/v1`
- **Official documentation:** [Get Aggregate Time Series Data](https://apidocs.helpdocs.io/article/tt4hqtxwss-aggregate-time-series-data)
