# Get Website Booking with HirePOS

Retrieves a website booking from HirePOS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/WebsiteBookings`
- **Base URL:** `https://api.hirepos.com`
- **Official documentation:** [Get Website Booking](https://docs.hirepos.com/en/articles/2314369)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | query | `string` | yes | Website booking identifier to retrieve. |
