# Update Session Metadata with Hoops

## Endpoint

- **Method:** `PATCH`
- **Path:** `/sessions/{session_id}/metadata`
- **Base URL:** `https://use.hoop.dev/api`
- **Official documentation:** [Update Session Metadata](https://use.hoop.dev/api/openapiv3.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `session_id` | path | `string` | yes |
