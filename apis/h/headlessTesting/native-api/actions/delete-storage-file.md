# Delete Storage File with Headless Testing

Deletes a storage file from Headless Testing.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/storage/:app_url`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Delete Storage File](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_url` | path | `string` | yes | The storage app_url identifier. |
