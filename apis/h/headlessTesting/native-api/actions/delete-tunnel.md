# Delete Tunnel with Headless Testing

Deletes a tunnel from Headless Testing.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tunnel/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Delete Tunnel](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tunnel identifier from the path. |
