# Run Codeless Test with Headless Testing

Runs a codeless test in Headless Testing.

## Endpoint

- **Method:** `POST`
- **Path:** `/lab/:id/trigger`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Run Codeless Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
