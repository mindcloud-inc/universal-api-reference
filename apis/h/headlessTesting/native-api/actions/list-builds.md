# List Builds with Headless Testing

Retrieves builds from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/builds`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Builds](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
