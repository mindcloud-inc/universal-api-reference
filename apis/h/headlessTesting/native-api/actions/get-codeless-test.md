# Get Codeless Test with Headless Testing

Retrieves a codeless test from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/lab/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Codeless Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
