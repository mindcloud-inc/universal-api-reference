# Get Build with Headless Testing

Retrieves a build from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/builds/:buildId`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Build](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `buildId` | path | `string` | yes | Build identifier from the path. |
