# Get Codeless Suite with Headless Testing

Retrieves a codeless suite from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/labsuites/:suiteId`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Codeless Suite](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `suiteId` | path | `string` | yes | The codeless suite identifier. |
