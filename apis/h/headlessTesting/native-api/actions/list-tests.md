# List Tests with Headless Testing

Retrieves tests from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/tests`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Tests](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
