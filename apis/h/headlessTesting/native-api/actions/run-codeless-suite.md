# Run Codeless Suite with Headless Testing

Runs a codeless suite in Headless Testing.

## Endpoint

- **Method:** `POST`
- **Path:** `/labsuites/:suiteId/trigger`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Run Codeless Suite](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `suiteId` | path | `string` | yes | The codeless suite identifier. |
