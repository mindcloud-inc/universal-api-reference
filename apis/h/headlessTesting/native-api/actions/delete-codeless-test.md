# Delete Codeless Test with Headless Testing

Deletes a codeless test from Headless Testing.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lab/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Delete Codeless Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
