# Get Screenshot with Headless Testing

Retrieves a screenshot job from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/screenshots/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Screenshot](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Screenshot identifier from the path. |
