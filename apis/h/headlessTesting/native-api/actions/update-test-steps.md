# Update Test Steps with Headless Testing

Updates steps for a codeless test in Headless Testing.

## Endpoint

- **Method:** `POST`
- **Path:** `/lab/:id/steps`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Update Test Steps](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
