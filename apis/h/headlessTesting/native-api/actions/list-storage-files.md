# List Storage Files with Headless Testing

Retrieves storage files from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/storage`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Storage Files](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
