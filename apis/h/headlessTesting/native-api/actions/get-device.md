# Get Device with Headless Testing

Retrieves a device from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Device](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Device identifier from the path. |
