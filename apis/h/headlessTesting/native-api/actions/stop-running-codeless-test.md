# Stop Running Codeless Test with Headless Testing

Stops a running codeless test in Headless Testing.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lab/:id/stop`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Stop Running Codeless Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
