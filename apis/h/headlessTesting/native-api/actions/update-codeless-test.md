# Update Codeless Test with Headless Testing

Updates a codeless test in Headless Testing.

## Endpoint

- **Method:** `PUT`
- **Path:** `/lab/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Update Codeless Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
