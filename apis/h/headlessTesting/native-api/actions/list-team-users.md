# List Team Users with Headless Testing

Retrieves team users from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/team-management/users`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Team Users](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
