# List Screenshots with Headless Testing

Retrieves screenshot jobs from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/screenshots`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Screenshots](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
