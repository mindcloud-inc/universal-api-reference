# List Test Steps with Headless Testing

Retrieves steps for a codeless test from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/lab/:id/steps`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Test Steps](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
