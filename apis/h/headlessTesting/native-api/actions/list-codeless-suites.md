# List Codeless Suites with Headless Testing

Retrieves codeless suites from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/labsuites`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Codeless Suites](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
