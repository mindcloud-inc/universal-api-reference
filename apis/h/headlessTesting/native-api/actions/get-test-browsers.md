# Get Test Browsers with Headless Testing

Retrieves browser assignments for a codeless test from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/lab/:id/browsers`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Test Browsers](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The codeless test identifier. |
