# List Codeless Tests with Headless Testing

Retrieves codeless tests from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/lab`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [List Codeless Tests](https://testingbot.com/support/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
