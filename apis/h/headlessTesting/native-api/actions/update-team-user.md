# Update Team User with Headless Testing

Updates a team user in Headless Testing.

## Endpoint

- **Method:** `PUT`
- **Path:** `/team-management/users/:id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Update Team User](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team user identifier from the path. |
