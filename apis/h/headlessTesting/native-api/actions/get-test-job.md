# Get Test Job with Headless Testing

Retrieves a test job from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Test Job](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The job identifier. |
