# Get Test with Headless Testing

Retrieves a test from Headless Testing.

## Endpoint

- **Method:** `GET`
- **Path:** `/tests/:webdriver_session_id`
- **Base URL:** `https://api.testingbot.com/v1`
- **Official documentation:** [Get Test](https://testingbot.com/support/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webdriver_session_id` | path | `string` | yes | WebDriver session identifier from the path. |
