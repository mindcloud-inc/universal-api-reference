# Update User Settings with HRBLADE

## Endpoint

- **Method:** `POST`
- **Path:** `/user/settings`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Update User Settings](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agency_name` | body | `string` | no | Agency name value. |
| `avatar` | body | `string` | no | Avatar file upload or URL. |
| `email` | body | `string` | no | User email address. |
| `phone` | body | `string` | no | User phone number. |
| `recruiting_owner` | body | `string` | no | Recruiting owner value. |
