# Create Company with HRBLADE

## Endpoint

- **Method:** `POST`
- **Path:** `/company/create`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Create Company](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `industry_id` | body | `string` | no | Industry identifier. |
| `name` | body | `string` | yes | Company name. |
