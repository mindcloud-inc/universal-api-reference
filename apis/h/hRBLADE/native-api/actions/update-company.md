# Update Company with HRBLADE

## Endpoint

- **Method:** `POST`
- **Path:** `/company/update`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Update Company](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | body | `number` | yes | Company identifier. |
| `name` | body | `string` | no | Company name. |
