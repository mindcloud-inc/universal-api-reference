# Get Job with HRBLADE

## Endpoint

- **Method:** `GET`
- **Path:** `/job/get/:id`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Get Job](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Job identifier. |
