# Remove Job with HRBLADE

## Endpoint

- **Method:** `POST`
- **Path:** `/job/remove/:id`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Remove Job](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Job identifier to remove. |
