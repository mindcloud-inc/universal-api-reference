# Update Response Rating with HRBLADE

## Endpoint

- **Method:** `POST`
- **Path:** `/response/add/rating`
- **Base URL:** `https://api.hrblade.com/api`
- **Official documentation:** [Update Response Rating](https://documenter.getpostman.com/view/15055534/TzCFgWPB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rating` | body | `number` | yes | Rating value. |
| `response_id` | body | `number` | yes | Response identifier. |
