# Get Datapoints with HoneyHive

Retrieves a list of datapoints from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/datapoints`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Datapoints](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | Project name to filter datapoints. |
