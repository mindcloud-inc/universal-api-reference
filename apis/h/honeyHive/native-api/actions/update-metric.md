# Update Metric with HoneyHive

Updates an existing metric in HoneyHive.

## Endpoint

- **Method:** `PUT`
- **Path:** `/metrics`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Update Metric](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metric_id` | body | `string` | yes | Metric ID to update. |
