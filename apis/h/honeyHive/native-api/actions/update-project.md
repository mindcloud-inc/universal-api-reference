# Update Project with HoneyHive

Updates an existing project in HoneyHive.

## Endpoint

- **Method:** `PUT`
- **Path:** `/projects`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Update Project](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | body | `string` | yes | Project ID to update. |
