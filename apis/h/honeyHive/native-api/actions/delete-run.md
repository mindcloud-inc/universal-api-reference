# Delete Run with HoneyHive

Deletes an evaluation run from HoneyHive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/runs/{run_id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Delete Run](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `run_id` | path | `string` | yes | Run ID. |
