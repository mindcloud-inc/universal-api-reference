# Update Event with HoneyHive

Updates an existing event in HoneyHive.

## Endpoint

- **Method:** `PUT`
- **Path:** `/events`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Update Event](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | body | `string` | yes | Event ID to update. |
