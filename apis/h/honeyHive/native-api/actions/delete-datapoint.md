# Delete Datapoint with HoneyHive

Deletes an existing datapoint from HoneyHive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datapoints/{id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Delete Datapoint](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Datapoint ID. |
