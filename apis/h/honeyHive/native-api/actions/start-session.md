# Start Session with HoneyHive

Creates a new session in HoneyHive.

## Endpoint

- **Method:** `POST`
- **Path:** `/session/start`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Start Session](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session` | body | `object` | yes | Session payload. |
