# Get Runs with HoneyHive

Retrieves a list of evaluation runs from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/runs`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Runs](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | no | Project name. |
