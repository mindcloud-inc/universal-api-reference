# Get Datapoint with HoneyHive

Retrieves a datapoint record from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/datapoints/{id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Datapoint](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Datapoint ID. |
