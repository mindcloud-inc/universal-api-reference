# Create Model Event with HoneyHive

Creates a new model event in HoneyHive.

## Endpoint

- **Method:** `POST`
- **Path:** `/events/model`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Create Model Event](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_event` | body | `object` | yes | Model event payload. |
