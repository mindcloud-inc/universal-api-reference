# Get Datasets with HoneyHive

Retrieves a list of datasets from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasets`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Datasets](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | Project name associated with datasets. |
