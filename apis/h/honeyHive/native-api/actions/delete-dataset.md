# Delete Dataset with HoneyHive

Deletes an existing dataset from HoneyHive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datasets`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Delete Dataset](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | query | `string` | yes | Dataset ID to delete. |
