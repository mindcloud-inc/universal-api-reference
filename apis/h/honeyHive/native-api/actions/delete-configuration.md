# Delete Configuration with HoneyHive

Deletes an existing configuration from HoneyHive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/configurations/{id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Delete Configuration](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Configuration ID. |
