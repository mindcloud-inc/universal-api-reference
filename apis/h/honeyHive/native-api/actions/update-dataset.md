# Update Dataset with HoneyHive

Updates an existing dataset in HoneyHive.

## Endpoint

- **Method:** `PUT`
- **Path:** `/datasets`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Update Dataset](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dataset_id` | body | `string` | yes | Dataset ID to update. |
