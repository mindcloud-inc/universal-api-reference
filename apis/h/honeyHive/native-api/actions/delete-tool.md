# Delete Tool with HoneyHive

Deletes an existing tool from HoneyHive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Delete Tool](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `function_id` | query | `string` | yes | Function ID to delete. |
