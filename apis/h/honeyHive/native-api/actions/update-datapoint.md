# Update Datapoint with HoneyHive

Updates an existing datapoint in HoneyHive.

## Endpoint

- **Method:** `PUT`
- **Path:** `/datapoints/{id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Update Datapoint](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Datapoint ID. |
