# Create Event with HoneyHive

Creates a new event in HoneyHive.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Create Event](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event` | body | `object` | yes | Event payload. |
