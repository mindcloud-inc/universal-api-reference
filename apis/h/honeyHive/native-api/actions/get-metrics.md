# Get Metrics with HoneyHive

Retrieves a list of metrics from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Metrics](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_name` | query | `string` | yes | Project name associated with metrics. |
