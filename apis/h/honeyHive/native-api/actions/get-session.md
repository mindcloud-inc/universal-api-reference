# Get Session with HoneyHive

Retrieves an existing session from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/session/{session_id}`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Session](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | path | `string` | yes | Session ID. |
