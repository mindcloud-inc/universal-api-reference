# Get Configurations with HoneyHive

Retrieves a list of configurations from HoneyHive.

## Endpoint

- **Method:** `GET`
- **Path:** `/configurations`
- **Base URL:** `https://api.honeyhive.ai`
- **Official documentation:** [Get Configurations](https://github.com/honeyhiveai/typescript-sdk/blob/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | query | `string` | yes | Project name for configuration. |
