# Fetch Web Page with Hyperbrowser

## Endpoint

- **Method:** `POST`
- **Path:** `/api/web/fetch`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Fetch Web Page](https://www.hyperbrowser.ai/docs/api-reference/fetch-a-web-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL of the page to fetch. |
