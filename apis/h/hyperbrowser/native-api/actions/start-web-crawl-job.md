# Start Web Crawl Job with Hyperbrowser

## Endpoint

- **Method:** `POST`
- **Path:** `/api/web/crawl`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Start Web Crawl Job](https://www.hyperbrowser.ai/docs/api-reference/start-a-web-crawl-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL to crawl. |
