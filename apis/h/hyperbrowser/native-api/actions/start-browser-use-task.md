# Start Browser Use Task with Hyperbrowser

## Endpoint

- **Method:** `POST`
- **Path:** `/api/task/browser-use`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Start Browser Use Task](https://www.hyperbrowser.ai/docs/api-reference/start-a-browser-use-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task` | body | `string` | yes | Instruction for the browser use task. |
