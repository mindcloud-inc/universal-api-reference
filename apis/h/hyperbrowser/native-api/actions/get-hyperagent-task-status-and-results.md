# Get HyperAgent Task Status and Results with Hyperbrowser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/task/hyper-agent/:id`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Get HyperAgent Task Status and Results](https://www.hyperbrowser.ai/docs/api-reference/get-hyperagent-task-status-and-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HyperAgent task identifier. |
