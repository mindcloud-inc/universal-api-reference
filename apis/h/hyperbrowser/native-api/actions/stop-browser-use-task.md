# Stop Browser Use Task with Hyperbrowser

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/task/browser-use/:id/stop`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Stop Browser Use Task](https://www.hyperbrowser.ai/docs/api-reference/stop-a-browser-use-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Browser Use task identifier. |
