# Search the Web with Hyperbrowser

## Endpoint

- **Method:** `POST`
- **Path:** `/api/web/search`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Search the Web](https://www.hyperbrowser.ai/docs/api-reference/search-the-web)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Search query to run. |
