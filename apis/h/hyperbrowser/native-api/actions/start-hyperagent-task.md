# Start HyperAgent Task with Hyperbrowser

## Endpoint

- **Method:** `POST`
- **Path:** `/api/task/hyper-agent`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Start HyperAgent Task](https://www.hyperbrowser.ai/docs/api-reference/start-a-hyperagent-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task` | body | `string` | yes | Instruction for the HyperAgent task. |
