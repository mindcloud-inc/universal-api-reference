# Get Session with Hyperbrowser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/session/:id`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Get Session](https://www.hyperbrowser.ai/docs/api-reference/get-session-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Session identifier. |
