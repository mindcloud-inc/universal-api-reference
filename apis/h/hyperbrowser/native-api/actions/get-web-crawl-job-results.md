# Get Web Crawl Job Results with Hyperbrowser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/web/crawl/:id`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Get Web Crawl Job Results](https://www.hyperbrowser.ai/docs/api-reference/get-web-crawl-job-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Web crawl job identifier. |
