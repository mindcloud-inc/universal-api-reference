# Stop HyperAgent Task with Hyperbrowser

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/task/hyper-agent/:id/stop`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Stop HyperAgent Task](https://www.hyperbrowser.ai/docs/api-reference/stop-a-hyperagent-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HyperAgent task identifier. |
