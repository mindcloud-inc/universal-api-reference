# Stop Session with Hyperbrowser

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/session/:id/stop`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Stop Session](https://www.hyperbrowser.ai/docs/api-reference/stop-a-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Session identifier. |
