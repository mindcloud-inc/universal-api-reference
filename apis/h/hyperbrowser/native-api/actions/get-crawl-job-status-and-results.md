# Get Crawl Job Status and Results with Hyperbrowser

## Endpoint

- **Method:** `GET`
- **Path:** `/api/crawl/:id`
- **Base URL:** `https://api.hyperbrowser.ai`
- **Official documentation:** [Get Crawl Job Status and Results](https://www.hyperbrowser.ai/docs/api-reference/get-crawl-job-status-and-results)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Crawl job identifier. |
