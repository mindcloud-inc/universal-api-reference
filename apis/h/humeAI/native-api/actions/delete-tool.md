# Delete Tool with Hume AI

Deletes an existing EVI tool from Hume AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v0/evi/tools/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Delete Tool](https://dev.hume.ai/reference/speech-to-speech-evi/tools/delete-tool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tool ID. |
