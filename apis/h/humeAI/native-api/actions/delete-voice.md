# Delete Voice with Hume AI

Deletes an existing custom voice from Hume AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v0/tts/voices`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Delete Voice](https://dev.hume.ai/reference/voices/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of the voice to delete. |
