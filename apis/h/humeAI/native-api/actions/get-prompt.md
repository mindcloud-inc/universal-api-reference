# Get Prompt with Hume AI

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/prompts/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Get Prompt](https://dev.hume.ai/reference/speech-to-speech-evi/prompts/get-prompt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Prompt ID. |
