# List Voices with Hume AI

Retrieves voices from Hume AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/tts/voices`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [List Voices](https://dev.hume.ai/reference/voices/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider` | query | `string` | yes | Voice provider to list. |
