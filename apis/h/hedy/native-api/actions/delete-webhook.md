# Delete Webhook with Hedy

Deletes a webhook from Hedy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.hedy.bot/webhooks/:webhookId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Delete Webhook](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Unique identifier of the webhook. |
