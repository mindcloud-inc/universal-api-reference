# List Highlights with Hedy

Retrieves highlight records from Hedy.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/highlights`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [List Highlights](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `format` | query | `string` | no | Set to zapier to receive a flat array response suitable for Zapier triggers. |
