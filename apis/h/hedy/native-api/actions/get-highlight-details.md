# Get Highlight Details with Hedy

Retrieves a highlight from Hedy.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/highlights/:highlightId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Get Highlight Details](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `highlightId` | path | `string` | yes | Unique identifier of the highlight. |
