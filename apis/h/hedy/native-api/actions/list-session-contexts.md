# List Session Contexts with Hedy

Retrieves session context records from Hedy.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/contexts`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [List Session Contexts](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `format` | query | `string` | no | Set to zapier to receive a flat response. |
