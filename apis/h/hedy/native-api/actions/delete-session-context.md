# Delete Session Context with Hedy

Deletes a session context from Hedy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.hedy.bot/contexts/:contextId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Delete Session Context](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contextId` | path | `string` | yes | Unique identifier of the session context. |
