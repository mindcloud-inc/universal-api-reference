# Get Session Details with Hedy

Retrieves a session from Hedy.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/sessions/:sessionId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Get Session Details](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | Unique identifier of the session. |
