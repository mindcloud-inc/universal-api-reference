# Delete Topic with Hedy

Deletes a topic from Hedy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://api.hedy.bot/topics/:topicId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Delete Topic](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | Unique identifier of the topic. |
