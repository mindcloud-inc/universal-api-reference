# List Topic Sessions with Hedy

Retrieves sessions for a Hedy topic.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/topics/:topicId/sessions`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [List Topic Sessions](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | Unique identifier of the topic. |
