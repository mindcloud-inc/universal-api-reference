# Get Topic Details with Hedy

Retrieves a topic from Hedy.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.hedy.bot/topics/:topicId`
- **Base URL:** `https://api.hedy.bot`
- **Official documentation:** [Get Topic Details](https://app.swaggerhub.com/apis-docs/HedyAI/hedy-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `topicId` | path | `string` | yes | Unique identifier of the topic. |
