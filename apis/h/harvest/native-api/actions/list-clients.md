# List Clients with Harvest

Retrieves clients from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/clients`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Clients](https://help.getharvest.com/api-v2/clients-api/clients/clients/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
