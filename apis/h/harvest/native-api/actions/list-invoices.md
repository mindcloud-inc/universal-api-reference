# List Invoices with Harvest

Retrieves invoices from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/invoices`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Invoices](https://help.getharvest.com/api-v2/invoices-api/invoices/invoices/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
