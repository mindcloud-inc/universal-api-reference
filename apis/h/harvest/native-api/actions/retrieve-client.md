# Retrieve Client with Harvest

Retrieves a client from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/clients/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Retrieve Client](https://help.getharvest.com/api-v2/clients-api/clients/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
