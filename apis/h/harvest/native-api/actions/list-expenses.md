# List Expenses with Harvest

Retrieves expenses from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/expenses`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Expenses](https://help.getharvest.com/api-v2/expenses-api/expenses/expenses/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
