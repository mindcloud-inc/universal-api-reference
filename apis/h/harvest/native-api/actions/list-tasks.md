# List Tasks with Harvest

Retrieves tasks from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tasks`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Tasks](https://help.getharvest.com/api-v2/tasks-api/tasks/tasks/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
