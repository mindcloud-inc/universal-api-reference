# List Users with Harvest

Retrieves users from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Users](https://help.getharvest.com/api-v2/users-api/users/users/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
