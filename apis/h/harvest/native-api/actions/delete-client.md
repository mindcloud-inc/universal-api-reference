# Delete client with Harvest

Deletes an existing client from Harvest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/clients/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Delete client](https://help.getharvest.com/api-v2/clients-api/clients/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
