# List Projects with Harvest

Retrieves projects from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Projects](https://help.getharvest.com/api-v2/projects-api/projects/projects/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
