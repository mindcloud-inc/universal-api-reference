# Retrieve Time Entry with Harvest

Retrieves a time entry from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/time_entries/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Retrieve Time Entry](https://help.getharvest.com/api-v2/timesheets-api/timesheets/time-entries/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
