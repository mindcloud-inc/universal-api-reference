# Retrieve Project with Harvest

Retrieves a project from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/projects/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Retrieve Project](https://help.getharvest.com/api-v2/projects-api/projects/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
