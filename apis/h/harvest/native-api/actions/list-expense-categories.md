# List Expense Categories with Harvest

Retrieves expense categories from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/expense_categories`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Expense Categories](https://help.getharvest.com/api-v2/expenses-api/expenses/expense-categories/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
