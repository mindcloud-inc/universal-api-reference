# Retrieve Task with Harvest

Retrieves a task from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tasks/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Retrieve Task](https://help.getharvest.com/api-v2/tasks-api/tasks/tasks/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
