# Delete invoice with Harvest

Deletes an existing invoice from Harvest.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/invoices/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Delete invoice](https://help.getharvest.com/api-v2/invoices-api/invoices/invoices/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
