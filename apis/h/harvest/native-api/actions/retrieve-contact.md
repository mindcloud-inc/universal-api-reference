# Retrieve Contact with Harvest

Retrieves a contact from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/:id`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [Retrieve Contact](https://help.getharvest.com/api-v2/clients-api/clients/contacts/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
