# List Contacts with Harvest

Retrieves contacts from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Contacts](https://help.getharvest.com/api-v2/clients-api/clients/contacts/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
