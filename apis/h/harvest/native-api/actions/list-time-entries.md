# List Time Entries with Harvest

Retrieves time entries from Harvest.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/time_entries`
- **Base URL:** `https://api.harvestapp.com`
- **Official documentation:** [List Time Entries](https://help.getharvest.com/api-v2/timesheets-api/timesheets/time-entries/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
