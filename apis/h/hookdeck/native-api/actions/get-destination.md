# Get Destination with Hookdeck

Retrieves a destination from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Destination](https://hookdeck.com/docs/api/destinations.md#retrieve-a-destination)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck destination ID from the `id` path parameter. |
