# Create Connection with Hookdeck

Creates a new connection in Hookdeck.

## Endpoint

- **Method:** `POST`
- **Path:** `/connections`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Create Connection](https://hookdeck.com/docs/api/connections.md#create-a-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Hookdeck connection. Use the documented connection create schema. |
