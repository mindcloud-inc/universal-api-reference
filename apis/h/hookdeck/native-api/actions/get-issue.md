# Get Issue with Hookdeck

Retrieves an issue from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Issue](https://hookdeck.com/docs/api/inspect.md#issues)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck issue ID from the `id` path parameter. |
