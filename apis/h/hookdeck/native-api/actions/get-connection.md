# Get Connection with Hookdeck

Retrieves a connection from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Connection](https://hookdeck.com/docs/api/connections.md#retrieve-a-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck connection ID from the `id` path parameter. |
