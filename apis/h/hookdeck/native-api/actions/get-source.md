# Get Source with Hookdeck

Retrieves a source from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Source](https://hookdeck.com/docs/api/sources.md#retrieve-a-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck source ID from the `id` path parameter. |
