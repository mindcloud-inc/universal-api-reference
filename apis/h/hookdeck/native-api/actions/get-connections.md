# Get Connections with Hookdeck

Retrieves connections from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/connections`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Connections](https://hookdeck.com/docs/api/connections.md#retrieve-all-connections)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
