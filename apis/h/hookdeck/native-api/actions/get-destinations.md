# Get Destinations with Hookdeck

Retrieves destinations from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Destinations](https://hookdeck.com/docs/api/destinations.md#retrieve-all-destinations)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
