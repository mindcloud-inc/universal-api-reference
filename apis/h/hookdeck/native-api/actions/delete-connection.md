# Delete Connection with Hookdeck

Deletes an existing connection from Hookdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/connections/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Delete Connection](https://hookdeck.com/docs/api/connections.md#delete-a-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Connection ID to delete. |
