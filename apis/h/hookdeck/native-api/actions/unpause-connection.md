# Unpause Connection with Hookdeck

Unpauses a connection in Hookdeck.

## Endpoint

- **Method:** `PUT`
- **Path:** `/connections/:id/unpause`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Unpause Connection](https://hookdeck.com/docs/api/connections.md#unpause-a-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck connection ID from the `id` path parameter. |
