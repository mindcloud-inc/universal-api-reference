# Get Request with Hookdeck

Retrieves a request from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Request](https://hookdeck.com/docs/api/inspect.md#requests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hookdeck request ID from the `id` path parameter. |
