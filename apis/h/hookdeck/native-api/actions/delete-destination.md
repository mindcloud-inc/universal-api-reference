# Delete Destination with Hookdeck

Deletes an existing destination from Hookdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/destinations/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Delete Destination](https://hookdeck.com/docs/api/destinations.md#delete-a-destination)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Destination ID to delete. |
