# Create Destination with Hookdeck

Creates a new destination in Hookdeck.

## Endpoint

- **Method:** `POST`
- **Path:** `/destinations`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Create Destination](https://hookdeck.com/docs/api/destinations.md#create-a-destination)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Hookdeck destination. Use the documented destination create schema. |
