# Delete Source with Hookdeck

Deletes an existing source from Hookdeck.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sources/:id`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Delete Source](https://hookdeck.com/docs/api/sources.md#delete-a-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Source ID to delete. |
