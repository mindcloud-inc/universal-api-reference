# Get Sources with Hookdeck

Retrieves sources from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Sources](https://hookdeck.com/docs/api/sources.md#retrieve-all-sources)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
