# Get Requests with Hookdeck

Retrieves requests from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/requests`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Requests](https://hookdeck.com/docs/api/inspect.md#requests)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
