# Get Events with Hookdeck

Retrieves events from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Events](https://hookdeck.com/docs/api/inspect.md#events)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
