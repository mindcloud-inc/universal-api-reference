# Create Source with Hookdeck

Creates a new source in Hookdeck.

## Endpoint

- **Method:** `POST`
- **Path:** `/sources`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Create Source](https://hookdeck.com/docs/api/sources.md#create-a-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | JSON request body for creating a Hookdeck source. Use the documented source create schema. |
