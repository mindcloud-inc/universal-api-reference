# Get Issues with Hookdeck

Retrieves issues from Hookdeck.

## Endpoint

- **Method:** `GET`
- **Path:** `/issues`
- **Base URL:** `https://api.hookdeck.com/2025-07-01`
- **Official documentation:** [Get Issues](https://hookdeck.com/docs/api/inspect.md#issues)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
