# List Share Uploads with HiDrive

Retrieves share uploads from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/shareupload`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [List Share Uploads](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/shareupload_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated share upload fields to include. |
| `id` | query | `string` | no | Share upload ID to retrieve. |
