# Delete Share Link with HiDrive

Deletes a share link from HiDrive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sharelink`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Delete Share Link](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/sharelink_DELETE)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Share link ID to delete. |
