# Get Unique Identifier with HiDrive

Retrieves a unique identifier from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/unique`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Unique Identifier](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/unique_GET)
