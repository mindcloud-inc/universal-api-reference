# Get Share Info with HiDrive

Retrieves share information from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/share/info`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Share Info](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/share/info_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Share ID to inspect. |
