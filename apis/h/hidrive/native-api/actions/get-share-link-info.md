# Get Share Link Info with HiDrive

Retrieves share link information from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharelink/info`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Share Link Info](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/sharelink/info_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Public share link ID to inspect. |
