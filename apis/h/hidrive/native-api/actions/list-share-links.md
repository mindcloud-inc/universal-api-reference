# List Share Links with HiDrive

Retrieves share links from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharelink`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [List Share Links](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/sharelink_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated share link fields to include. |
| `id` | query | `string` | no | Share link ID to retrieve. |
