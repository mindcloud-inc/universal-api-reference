# Get Current User with HiDrive

Retrieves the current user from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/me`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Current User](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/user/me_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated user fields to include. |
