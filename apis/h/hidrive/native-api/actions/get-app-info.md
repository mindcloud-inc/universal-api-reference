# Get App Info with HiDrive

Retrieves app information from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/app/me`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get App Info](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/app/me_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated app information fields to include. |
