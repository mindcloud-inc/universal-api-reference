# Get Disabled Status with HiDrive

Retrieves the disabled status from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/status/disabled`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Disabled Status](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/status/disabled_GET)
