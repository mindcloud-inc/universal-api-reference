# Get Features with HiDrive

Retrieves feature information from HiDrive.

## Endpoint

- **Method:** `GET`
- **Path:** `/features`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Get Features](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/features_GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated feature fields to include. |
