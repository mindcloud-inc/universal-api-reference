# Delete Share with HiDrive

Deletes a share from HiDrive.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/share`
- **Base URL:** `https://api.hidrive.strato.com/2.1`
- **Official documentation:** [Delete Share](https://api.hidrive.strato.com/2.1/static/apidoc/index.html#/2.1/share_DELETE)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Share ID to delete. |
