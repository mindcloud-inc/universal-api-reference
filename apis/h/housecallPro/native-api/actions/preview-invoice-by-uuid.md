# Preview Invoice by UUID with Housecall Pro

## Endpoint

- **Method:** `GET`
- **Path:** `/api/invoices/:uuid/preview`
- **Base URL:** `https://api.housecallpro.com`
- **Official documentation:** [Preview Invoice by UUID](https://docs.housecallpro.com/docs/housecall-public-api/ae40a9286ba7c)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the invoice to preview. |
