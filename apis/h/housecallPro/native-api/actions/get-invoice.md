# Get Invoice with Housecall Pro

## Endpoint

- **Method:** `GET`
- **Path:** `/api/invoices/:uuid`
- **Base URL:** `https://api.housecallpro.com`
- **Official documentation:** [Get Invoice](https://docs.housecallpro.com/docs/housecall-public-api/0ae16219c3e58)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The UUID of the invoice to retrieve. |
