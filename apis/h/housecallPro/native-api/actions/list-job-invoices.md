# List Job Invoices with Housecall Pro

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id/invoices`
- **Base URL:** `https://api.housecallpro.com`
- **Official documentation:** [List Job Invoices](https://docs.housecallpro.com/docs/housecall-public-api/eb1f5b5f17290)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | yes | The job whose invoices should be listed. |
