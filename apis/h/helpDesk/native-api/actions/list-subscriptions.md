# List Subscriptions with HelpDesk

Retrieves subscriptions from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriptions`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Subscriptions](https://api.helpdesk.com/docs#tag/Subscriptions/operation/subscriptionsList)
