# List Canned Responses with HelpDesk

Retrieves canned responses from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cannedResponses`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Canned Responses](https://api.helpdesk.com/docs#tag/Canned-responses/operation/cannedResponsesList)
