# Get Ticket Rating Report with HelpDesk

Retrieves the ticket rating report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/rating`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Ticket Rating Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportRating)
