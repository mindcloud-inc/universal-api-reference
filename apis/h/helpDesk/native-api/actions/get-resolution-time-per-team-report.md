# Get Resolution Time Per Team Report with HelpDesk

Retrieves the resolution time per team report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/resolutionTimePerTeam`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Resolution Time Per Team Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResolutionTimePerTeam)
