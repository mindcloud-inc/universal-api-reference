# Get Custom Field with HelpDesk

Retrieves a custom field from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customFields/:customFieldID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Custom Field](https://api.helpdesk.com/docs#tag/Custom-fields/operation/customFieldsRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customFieldID` | path | `string` | yes | The HelpDesk custom field ID. |
