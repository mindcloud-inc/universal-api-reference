# Get Resolution Time Per Agent Report with HelpDesk

Retrieves the resolution time per agent report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/resolutionTimePerAgent`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Resolution Time Per Agent Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResolutionTimePerAgent)
