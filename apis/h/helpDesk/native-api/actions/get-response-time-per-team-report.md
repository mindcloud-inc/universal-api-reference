# Get Response Time Per Team Report with HelpDesk

Retrieves the response time per team report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/responseTimePerTeam`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Response Time Per Team Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResponseTimePerTeam)
