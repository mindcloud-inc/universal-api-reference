# Get Macro with HelpDesk

Retrieves a macro from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/macros/:macroID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Macro](https://api.helpdesk.com/docs#tag/Macros/operation/macroRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `macroID` | path | `string` | yes | The HelpDesk macro ID. |
