# Get View with HelpDesk

Retrieves a view from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/views/:viewID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get View](https://api.helpdesk.com/docs#tag/Views/operation/viewRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `viewID` | path | `string` | yes | The HelpDesk view ID. |
