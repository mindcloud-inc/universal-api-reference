# Get Response Time 24h Distribution Report with HelpDesk

Retrieves the 24-hour response time distribution from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/responseTime24`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Response Time 24h Distribution Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResponseTime24)
