# Get Resolution Time 24h Distribution Report with HelpDesk

Retrieves the 24-hour resolution time distribution from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/resolutionTime24`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Resolution Time 24h Distribution Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResolutionTime24)
