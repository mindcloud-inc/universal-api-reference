# Get Rule with HelpDesk

Retrieves a rule from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/rules/:ruleID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Rule](https://api.helpdesk.com/docs#tag/Rules/operation/ruleRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleID` | path | `string` | yes | The HelpDesk rule ID. |
