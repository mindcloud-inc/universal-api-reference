# Get Ticket Sources 24h Distribution Report with HelpDesk

Retrieves the 24-hour ticket sources distribution from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/ticketSources24`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Ticket Sources 24h Distribution Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportTicketSources24)
