# Get Ticket Rating 24h Distribution Report with HelpDesk

Retrieves the 24-hour ticket rating distribution from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/rating24`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Ticket Rating 24h Distribution Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportRating24)
