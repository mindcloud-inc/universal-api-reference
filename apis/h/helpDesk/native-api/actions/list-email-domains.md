# List Email Domains with HelpDesk

Retrieves email domains from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/emailDomains`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Email Domains](https://api.helpdesk.com/docs#tag/Email-domains/operation/emailDomainsList)
