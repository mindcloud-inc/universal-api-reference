# List Trusted Emails with HelpDesk

Retrieves trusted emails from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/trustedEmails`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Trusted Emails](https://api.helpdesk.com/docs#tag/Spam-management/operation/trustedList)
