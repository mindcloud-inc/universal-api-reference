# Get Resolution Time Report with HelpDesk

Retrieves the resolution time report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/resolutionTime`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Resolution Time Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResolutionTime)
