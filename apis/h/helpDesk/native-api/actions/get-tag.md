# Get Tag with HelpDesk

Retrieves a tag from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tags/:tagID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Tag](https://api.helpdesk.com/docs#tag/Tags/operation/tagRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagID` | path | `string` | yes | Unique HelpDesk tag ID. |
