# Get Response Time Per Agent Report with HelpDesk

Retrieves the response time per agent report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/responseTimePerAgent`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Response Time Per Agent Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResponseTimePerAgent)
