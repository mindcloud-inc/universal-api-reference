# Get New Tickets Report with HelpDesk

Retrieves the new tickets report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/newTickets`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get New Tickets Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportNewTickets)
