# Get Team with HelpDesk

Retrieves a team from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/:teamID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Team](https://api.helpdesk.com/docs#tag/Teams/operation/teamRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamID` | path | `string` | yes | Unique HelpDesk team ID. |
