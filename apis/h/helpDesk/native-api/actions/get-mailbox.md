# Get Mailbox with HelpDesk

Retrieves a mailbox from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/mailboxes/:mailboxID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Mailbox](https://api.helpdesk.com/docs#tag/Mailboxes-(inboxes)/operation/mailboxRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailboxID` | path | `string` | yes | The HelpDesk mailbox ID. |
