# Get New Tickets 24h Distribution Report with HelpDesk

Retrieves the 24-hour new tickets distribution from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/newTickets24`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get New Tickets 24h Distribution Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportNewTickets24)
