# List Reply Addresses with HelpDesk

Retrieves reply addresses from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/replyAddresses`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Reply Addresses](https://api.helpdesk.com/docs#tag/Reply-addresses/operation/replyAddressesList)
