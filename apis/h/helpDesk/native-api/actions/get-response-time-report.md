# Get Response Time Report with HelpDesk

Retrieves the response time report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/responseTime`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Response Time Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportResponseTime)
