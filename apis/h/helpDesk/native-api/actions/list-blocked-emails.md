# List Blocked Emails with HelpDesk

Retrieves blocked emails from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/blockedEmails`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [List Blocked Emails](https://api.helpdesk.com/docs#tag/Spam-management/operation/blockedEmailsList)
