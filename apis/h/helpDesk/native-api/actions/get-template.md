# Get Template with HelpDesk

Retrieves a template from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:templateID`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Template](https://api.helpdesk.com/docs#tag/Templates/operation/templateRead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateID` | path | `string` | yes | The HelpDesk template ID. |
