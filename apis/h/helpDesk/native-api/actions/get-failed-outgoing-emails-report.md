# Get Failed Outgoing Emails Report with HelpDesk

Retrieves the failed outgoing emails report from HelpDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reports/failedEmails`
- **Base URL:** `https://api.helpdesk.com`
- **Official documentation:** [Get Failed Outgoing Emails Report](https://api.helpdesk.com/docs#tag/Reports/operation/reportFailedEmails)
