# Create Project with Hex

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://app.hex.tech/api/v1`
- **Official documentation:** [Create Project](https://learn.hex.tech/docs/api-integrations/api/reference#operation/CreateProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `description` | body | `string` | no | Project description. |
| `title` | body | `string` | yes | Project title. |
