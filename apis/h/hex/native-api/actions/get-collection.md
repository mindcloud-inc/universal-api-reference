# Get Collection with Hex

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/{collectionId}`
- **Base URL:** `https://app.hex.tech/api/v1`
- **Official documentation:** [Get Collection](https://learn.hex.tech/docs/api-integrations/api/reference#operation/GetCollection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Unique ID for a collection. |
