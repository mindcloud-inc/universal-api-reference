# Publish Asset with Hygraph

Publishes an asset to content stages in Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Publish Asset](https://hygraph.com/docs/api-reference/assets/publishing-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: id. Optional: to. |
