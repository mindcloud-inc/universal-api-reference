# Unpublish Asset with Hygraph

Unpublishes an asset from content stages in Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Unpublish Asset](https://hygraph.com/docs/api-reference/assets/publishing-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: id. Optional: from, to. |
