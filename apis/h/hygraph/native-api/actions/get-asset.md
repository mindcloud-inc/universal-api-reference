# Get Asset with Hygraph

Retrieves an asset from Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Get Asset](https://hygraph.com/docs/api-reference/assets/fetching-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: id. Optional: stage. |
