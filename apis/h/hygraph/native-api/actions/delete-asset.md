# Delete Asset with Hygraph

Deletes an existing asset from Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Delete Asset](https://hygraph.com/docs/api-reference/assets/deleting-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: id. |
