# List Assets with Hygraph

Retrieves assets from Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [List Assets](https://hygraph.com/docs/api-reference/assets/fetching-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | no | Optional variables: first, skip, stage. |
