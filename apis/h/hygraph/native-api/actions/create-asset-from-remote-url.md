# Create Asset From Remote URL with Hygraph

Creates a new asset from a remote URL in Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Create Asset From Remote URL](https://hygraph.com/docs/api-reference/assets/uploading-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: uploadUrl. Optional: fileName. |
