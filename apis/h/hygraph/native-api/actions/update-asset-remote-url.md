# Update Asset Remote URL with Hygraph

Updates an existing asset from a remote URL in Hygraph.

## Endpoint

- **Method:** `POST`
- **Base URL:** `{endpoint}`
- **Official documentation:** [Update Asset Remote URL](https://hygraph.com/docs/api-reference/assets/updating-assets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `variables` | body | `object` | yes | Required variables: id, uploadUrl. |
