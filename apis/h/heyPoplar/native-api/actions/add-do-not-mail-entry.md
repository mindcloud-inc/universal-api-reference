# Add Do Not Mail Entry with HeyPoplar

Creates a do-not-mail entry in HeyPoplar.

## Endpoint

- **Method:** `POST`
- **Path:** `/do-not-mail`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [Add Do Not Mail Entry](https://docs.heypoplar.com/api/endpoints/do-not-mail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to add to the do not mail list. |
