# Get Current Organization with HeyPoplar

Retrieves the current organization from HeyPoplar.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [Get Current Organization](https://docs.heypoplar.com/api/endpoints/other-endpoints#fetch-current-organization)
