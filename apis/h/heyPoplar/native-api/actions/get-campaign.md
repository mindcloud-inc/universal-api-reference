# Get Campaign with HeyPoplar

Retrieves a campaign from HeyPoplar.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:id`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [Get Campaign](https://docs.heypoplar.com/api/endpoints/other-endpoints#fetch-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the campaign to fetch. |
