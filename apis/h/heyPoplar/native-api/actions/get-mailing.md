# Get Mailing with HeyPoplar

Retrieves a mailing from HeyPoplar.

## Endpoint

- **Method:** `GET`
- **Path:** `/mailing/:mailing_id`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [Get Mailing](https://docs.heypoplar.com/api/endpoints/mailing#fetch-mailing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mailing_id` | path | `string` | yes | ID of the mailing to fetch. |
