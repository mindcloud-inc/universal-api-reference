# List Active Campaigns with HeyPoplar

Retrieves active campaigns from HeyPoplar.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [List Active Campaigns](https://docs.heypoplar.com/api/endpoints/other-endpoints#fetch-active-campaigns)
