# Delete Order with HeyPoplar

Deletes an order from HeyPoplar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/order/:order_id`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [Delete Order](https://docs.heypoplar.com/api/endpoints/orders#delete-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `string` | yes | The ID of the order to delete. |
