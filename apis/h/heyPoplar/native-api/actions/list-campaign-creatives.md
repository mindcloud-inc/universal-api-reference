# List Campaign Creatives with HeyPoplar

Retrieves creatives for a HeyPoplar campaign.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaign/:id/creatives`
- **Base URL:** `https://api.heypoplar.com/v1`
- **Official documentation:** [List Campaign Creatives](https://docs.heypoplar.com/api/endpoints/other-endpoints#fetch-campaign-creatives)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the campaign whose creatives should be returned. |
