# List Customers with HotspotSystem

Retrieves the resource owner's customers from HotspotSystem.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.hotspotsystem.com/v2.0`
- **Official documentation:** [List Customers](https://www.hotspotsystem.com/apidocs/api/reference/#operation-getcustomers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of response properties to include. |
