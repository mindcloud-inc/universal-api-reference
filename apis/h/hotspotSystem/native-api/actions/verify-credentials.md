# Verify Credentials with HotspotSystem

Verifies HotspotSystem credentials and retrieves owner details.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.hotspotsystem.com/v2.0`
- **Official documentation:** [Verify Credentials](https://www.hotspotsystem.com/apidocs/api/reference/#operation-getme)
