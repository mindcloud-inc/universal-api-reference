# List Location Options with HotspotSystem

Retrieves the resource owner's locations as options from HotspotSystem.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/options`
- **Base URL:** `https://api.hotspotsystem.com/v2.0`
- **Official documentation:** [List Location Options](https://www.hotspotsystem.com/apidocs/api/reference/#operation-getlocationsasoptions)
