# List MAC Transactions with HotspotSystem

Retrieves the resource owner's MAC transactions from HotspotSystem.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/mac`
- **Base URL:** `https://api.hotspotsystem.com/v2.0`
- **Official documentation:** [List MAC Transactions](https://www.hotspotsystem.com/apidocs/api/reference/#operation-getmactransactions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of response properties to include. |
