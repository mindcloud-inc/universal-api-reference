# List Voucher Transactions with HotspotSystem

Retrieves the resource owner's voucher transactions from HotspotSystem.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/voucher`
- **Base URL:** `https://api.hotspotsystem.com/v2.0`
- **Official documentation:** [List Voucher Transactions](https://www.hotspotsystem.com/apidocs/api/reference/#operation-getvouchertransactions)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated list of response properties to include. |
