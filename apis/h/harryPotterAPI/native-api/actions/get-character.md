# Get Character with Harry Potter API

## Endpoint

- **Method:** `GET`
- **Path:** `/api/character/:id`
- **Base URL:** `https://hp-api.onrender.com`
- **Official documentation:** [Get Character](https://hp-api.onrender.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Character UUID. |
