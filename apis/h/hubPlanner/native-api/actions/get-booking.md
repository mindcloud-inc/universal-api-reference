# Get Booking with Hub Planner

Retrieves a booking from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Booking](https://github.com/hubplanner/API/blob/master/Sections/bookings.md#get-specific-booking)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner booking ID from the _id field. |
