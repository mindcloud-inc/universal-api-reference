# List Events with Hub Planner

Retrieves events from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/event`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Events](https://github.com/hubplanner/API/blob/master/Sections/events.md#add-events-to-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
