# List Booking Categories with Hub Planner

Retrieves booking categories from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Booking Categories](https://github.com/hubplanner/API/blob/master/Sections/booking-categories.md#get-all-booking-categories)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
