# Search Holidays with Hub Planner

Finds holidays in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/holiday/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Holidays](https://github.com/hubplanner/API/blob/master/Sections/holidays.md#search-holidays)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
