# Search Billing Rates with Hub Planner

Finds billing rates in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/billingRate/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Billing Rates](https://github.com/hubplanner/API/blob/master/Sections/billingrate.md#search-billing-rates)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
