# Search Bookings with Hub Planner

Finds bookings in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/booking/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Bookings](https://github.com/hubplanner/API/blob/master/Sections/bookings.md#search-bookings)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
