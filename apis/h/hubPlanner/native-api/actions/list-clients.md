# List Clients with Hub Planner

Retrieves clients from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/client`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Clients](https://github.com/hubplanner/API/blob/master/Sections/clients.md#get-all-clients)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
