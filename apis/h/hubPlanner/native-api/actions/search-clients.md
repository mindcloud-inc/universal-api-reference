# Search Clients with Hub Planner

Finds clients in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/client/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Clients](https://github.com/hubplanner/API/blob/master/Sections/clients.md#search-clients)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
