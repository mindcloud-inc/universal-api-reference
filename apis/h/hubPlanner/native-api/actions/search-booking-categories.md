# Search Booking Categories with Hub Planner

Finds booking categories in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/categories/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Booking Categories](https://github.com/hubplanner/API/blob/master/Sections/booking-categories.md#search-a-booking-category)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
