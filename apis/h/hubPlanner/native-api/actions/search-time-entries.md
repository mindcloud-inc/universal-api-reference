# Search Time Entries with Hub Planner

Finds time entries in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/timeentry/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Time Entries](https://github.com/hubplanner/API/blob/master/Sections/timesheets.md#search-timeentry)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
