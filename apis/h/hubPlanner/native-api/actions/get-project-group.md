# Get Project Group with Hub Planner

Retrieves a project group from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/projectgroup/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Project Group](https://github.com/hubplanner/API/blob/master/Sections/groups.md#get-specific-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner project group ID from the _id field. |
