# List Holidays with Hub Planner

Retrieves holidays from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/holiday`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Holidays](https://github.com/hubplanner/API/blob/master/Sections/holidays.md#get-all-holidays)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
