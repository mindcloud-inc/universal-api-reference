# List Resources with Hub Planner

Retrieves resources from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Resources](https://github.com/hubplanner/API/blob/master/Sections/resource.md#get-all-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
