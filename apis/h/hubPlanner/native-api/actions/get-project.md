# Get Project with Hub Planner

Retrieves a project from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Project](https://github.com/hubplanner/API/blob/master/Sections/project.md#get-specific-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner project ID from the _id field. |
