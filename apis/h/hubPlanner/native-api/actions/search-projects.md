# Search Projects with Hub Planner

Finds projects in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/project/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Projects](https://github.com/hubplanner/API/blob/master/Sections/project.md#search-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
