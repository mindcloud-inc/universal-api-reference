# Get Event with Hub Planner

Retrieves an event from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/event/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Event](https://github.com/hubplanner/API/blob/master/Sections/events.md#get-specific-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner event ID from the _id field. |
