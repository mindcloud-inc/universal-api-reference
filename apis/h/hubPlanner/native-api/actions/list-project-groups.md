# List Project Groups with Hub Planner

Retrieves project groups from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/projectgroup`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Project Groups](https://github.com/hubplanner/API/blob/master/Sections/groups.md#get-all-project-or-resource-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
