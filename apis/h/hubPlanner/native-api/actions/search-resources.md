# Search Resources with Hub Planner

Finds resources in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/resource/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Resources](https://github.com/hubplanner/API/blob/master/Sections/resource.md#search-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
