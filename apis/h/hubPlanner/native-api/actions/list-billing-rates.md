# List Billing Rates with Hub Planner

Retrieves billing rates from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/billingRate`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Billing Rates](https://github.com/hubplanner/API/blob/master/Sections/billingrate.md#get-all-billing-rates)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
