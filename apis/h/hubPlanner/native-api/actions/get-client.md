# Get Client with Hub Planner

Retrieves a client from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/client/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Client](https://github.com/hubplanner/API/blob/master/Sections/clients.md#get-an-existing-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner client ID from the _id field. |
