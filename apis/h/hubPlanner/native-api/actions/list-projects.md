# List Projects with Hub Planner

Retrieves projects from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/project`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Projects](https://github.com/hubplanner/API/blob/master/Sections/project.md#get-all-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
