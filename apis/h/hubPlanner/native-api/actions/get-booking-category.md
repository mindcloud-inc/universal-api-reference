# Get Booking Category with Hub Planner

Retrieves a booking category from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Booking Category](https://github.com/hubplanner/API/blob/master/Sections/booking-categories.md#get-a-booking-category-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner booking category ID from the _id field. |
