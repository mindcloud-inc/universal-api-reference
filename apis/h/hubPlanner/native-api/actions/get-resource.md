# Get Resource with Hub Planner

Retrieves a resource from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Resource](https://github.com/hubplanner/API/blob/master/Sections/resource.md#get-specific-resource)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner resource ID from the _id field. |
