# Get Billing Rate with Hub Planner

Retrieves a billing rate from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/billingRate/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Billing Rate](https://github.com/hubplanner/API/blob/master/Sections/billingrate.md#get-specific-billing-rate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner billing rate ID from the _id field. |
