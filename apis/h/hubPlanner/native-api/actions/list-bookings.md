# List Bookings with Hub Planner

Retrieves bookings from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [List Bookings](https://github.com/hubplanner/API/blob/master/Sections/bookings.md#get-all-bookings)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
