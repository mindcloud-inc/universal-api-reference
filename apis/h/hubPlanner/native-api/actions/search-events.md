# Search Events with Hub Planner

Finds events in Hub Planner by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/event/search`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Search Events](https://github.com/hubplanner/API/blob/master/Sections/events.md#search-events)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
