# Get Holiday with Hub Planner

Retrieves a holiday from Hub Planner.

## Endpoint

- **Method:** `GET`
- **Path:** `/holiday/:id`
- **Base URL:** `https://api.hubplanner.com/v1`
- **Official documentation:** [Get Holiday](https://github.com/hubplanner/API/blob/master/Sections/holidays.md#get-specific-holidays)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Hub Planner holiday ID from the _id field. |
