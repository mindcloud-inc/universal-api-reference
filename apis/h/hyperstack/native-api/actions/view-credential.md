# View Credential with Hyperstack Certificates

## Endpoint

- **Method:** `GET`
- **Path:** `/credential/:document_id/view`
- **Base URL:** `https://api.thehyperstack.com/v1`
- **Official documentation:** [View Credential](https://thehyperstack.com/docs/api-guide/view-credential)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The credential document identifier. |
