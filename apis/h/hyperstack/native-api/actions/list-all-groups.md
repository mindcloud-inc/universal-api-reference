# List All Groups with Hyperstack Certificates

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/all`
- **Base URL:** `https://api.thehyperstack.com/v1`
- **Official documentation:** [List All Groups](https://thehyperstack.com/docs/api-guide/list-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | body | `number` | yes | The page number for pagination. |
| `page_size` | body | `number` | yes | The number of groups to return per page. |
