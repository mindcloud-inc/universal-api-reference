# List All Credentials with Hyperstack Certificates

## Endpoint

- **Method:** `POST`
- **Path:** `/credentials/all`
- **Base URL:** `https://api.thehyperstack.com/v1`
- **Official documentation:** [List All Credentials](https://thehyperstack.com/docs/api-guide/list-credentials)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | body | `number` | yes | The page number for pagination. |
| `page_size` | body | `number` | yes | The number of credentials to return per page. |
