# View Credential Group with Hyperstack Certificates

## Endpoint

- **Method:** `GET`
- **Path:** `/group/view/:group_key`
- **Base URL:** `https://api.thehyperstack.com/v1`
- **Official documentation:** [View Credential Group](https://thehyperstack.com/docs/api-guide/view-credential-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_key` | path | `string` | yes | The unique key of the credential group to view. |
