# Delete prompt with Hume

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v0/evi/prompts/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Delete prompt](https://dev.hume.ai/reference/speech-to-speech-evi/prompts/delete-prompt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI prompt identifier. |
