# List prompt versions with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/prompts/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [List prompt versions](https://dev.hume.ai/reference/speech-to-speech-evi/prompts/list-prompt-versions)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI prompt identifier. |
