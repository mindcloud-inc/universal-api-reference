# List chat events with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/chats/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [List chat events](https://dev.hume.ai/reference/speech-to-speech-evi/chats/list-chat-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI chat identifier. |
