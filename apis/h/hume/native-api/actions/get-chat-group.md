# Get chat group with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/chat_groups/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Get chat group](https://dev.hume.ai/reference/speech-to-speech-evi/chat-groups/get-chat-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI chat group identifier. |
