# Delete tool with Hume

- **Method:** `DELETE`
- **Path:** `/v0/evi/tools/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Delete tool](https://dev.hume.ai/reference/speech-to-speech-evi/tools/delete-tool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI tool identifier. |
