# Get job details with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/batch/jobs/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Get job details](https://dev.hume.ai/reference/expression-measurement-api/batch/get-job-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Expression Measurement job identifier. |
