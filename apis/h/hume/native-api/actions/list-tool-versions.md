# List tool versions with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/tools/:id`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [List tool versions](https://dev.hume.ai/reference/speech-to-speech-evi/tools/list-tool-versions)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI tool identifier. |
