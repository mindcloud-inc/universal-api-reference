# Get chat group audio with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/chat_groups/:id/audio`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Get chat group audio](https://dev.hume.ai/reference/speech-to-speech-evi/chat-groups/get-audio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI chat group identifier. |
