# Get chat audio with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/chats/:id/audio`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [Get chat audio](https://dev.hume.ai/reference/speech-to-speech-evi/chats/get-audio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI chat identifier. |
