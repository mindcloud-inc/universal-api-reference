# List chat group events with Hume

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/evi/chat_groups/:id/events`
- **Base URL:** `https://api.hume.ai`
- **Official documentation:** [List chat group events](https://dev.hume.ai/reference/speech-to-speech-evi/chat-groups/list-chat-group-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | EVI chat group identifier. |
