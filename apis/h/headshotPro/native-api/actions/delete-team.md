# Delete Team with HeadshotPro

Deletes an existing team from HeadshotPro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organization/teams/:teamId`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [Delete Team](https://www.headshotpro.com/api/teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `string` | yes | ID of the team to delete. |
