# List Pending Team Members with HeadshotPro

Retrieves pending team members from HeadshotPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/team/pending`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [List Pending Team Members](https://www.headshotpro.com/api/team-members)
