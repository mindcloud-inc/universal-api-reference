# List Finished Team Members with HeadshotPro

Retrieves finished team members from HeadshotPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/team/finished`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [List Finished Team Members](https://www.headshotpro.com/api/team-members)
