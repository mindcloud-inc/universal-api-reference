# Get Model with HeadshotPro

Retrieves a model from HeadshotPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/models/:modelId`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [Get Model](https://www.headshotpro.com/api/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `string` | yes | ID of the model to retrieve. |
