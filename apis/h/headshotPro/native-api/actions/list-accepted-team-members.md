# List Accepted Team Members with HeadshotPro

Retrieves accepted team members from HeadshotPro.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/team/accepted`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [List Accepted Team Members](https://www.headshotpro.com/api/team-members)
