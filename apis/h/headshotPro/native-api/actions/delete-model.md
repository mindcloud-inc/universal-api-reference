# Delete Model with HeadshotPro

Deletes an existing model from HeadshotPro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/organization/models/:modelId`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [Delete Model](https://www.headshotpro.com/api/models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `string` | yes | ID of the model to delete. |
