# Create Team with HeadshotPro

Creates a new team in HeadshotPro.

## Endpoint

- **Method:** `POST`
- **Path:** `/organization/teams`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [Create Team](https://www.headshotpro.com/api/teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Unique name for the new team. |
