# Get Invite By Email with HeadshotPro

Finds an invite in HeadshotPro by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/invites/:email`
- **Base URL:** `https://server.headshotpro.com/api/v2`
- **Official documentation:** [Get Invite By Email](https://www.headshotpro.com/api/invites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Email address of the invite to inspect. |
