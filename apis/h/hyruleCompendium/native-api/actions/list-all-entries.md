# List All Entries with Hyrule Compendium

## Endpoint

- **Method:** `GET`
- **Path:** `/compendium/all`
- **Base URL:** `https://api.hyrule-compendium.com/v3`
- **Official documentation:** [List All Entries](https://gadhagod.github.io/Hyrule-Compendium-API/#/compendium-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `game` | query | `list` | no | Supported game; defaults to Breath of the Wild. Accepted values: `0`, `1`. |
