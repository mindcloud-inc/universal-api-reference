# Get Client with Harpoon

Retrieves a client from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Get Client](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Client ID. |
