# Delete Time Entry with Harpoon

Deletes an existing time entry from Harpoon.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/time_entries/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Delete Time Entry](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
