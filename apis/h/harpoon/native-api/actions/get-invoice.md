# Get Invoice with Harpoon

Retrieves an invoice from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Get Invoice](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
