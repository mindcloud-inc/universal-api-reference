# Clone Time Entry with Harpoon

Clones a time entry in Harpoon with zero hours.

## Endpoint

- **Method:** `POST`
- **Path:** `/time_entries/:id/clone`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Clone Time Entry](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
