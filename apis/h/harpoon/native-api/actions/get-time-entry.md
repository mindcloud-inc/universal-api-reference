# Get Time Entry with Harpoon

Retrieves a time entry from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/time_entries/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Get Time Entry](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
