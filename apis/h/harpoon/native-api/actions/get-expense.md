# Get Expense with Harpoon

Retrieves an expense from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Get Expense](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
