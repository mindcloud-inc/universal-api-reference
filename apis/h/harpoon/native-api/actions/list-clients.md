# List Clients with Harpoon

Retrieves clients from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [List Clients](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `select` | query | `string` | no | If present, returns simplified data for dropdown usage. |
