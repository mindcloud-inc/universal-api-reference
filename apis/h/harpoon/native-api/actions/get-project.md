# Get Project with Harpoon

Retrieves a project from Harpoon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.harpoonapp.com/api`
- **Official documentation:** [Get Project](https://app.harpoonapp.com/api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
