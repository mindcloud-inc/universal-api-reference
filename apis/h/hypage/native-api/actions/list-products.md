# List Products with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/products`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [List Products](https://platform.hyax.com/api-docs/products-list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
