# List People with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/people`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [List People](https://platform.hyax.com/api-docs/people-list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
