# Unsubscribe Person with Hy.page

## Endpoint

- **Method:** `POST`
- **Path:** `/hyax-api/v1/people/unsubscribe`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Unsubscribe Person](https://platform.hyax.com/api-docs/people-unsubscribe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Person email address to unsubscribe. |
