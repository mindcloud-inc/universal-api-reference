# Delete Person with Hy.page

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hyax-api/v1/people/:id`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Delete Person](https://platform.hyax.com/api-docs/people-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Person ID to delete. |
