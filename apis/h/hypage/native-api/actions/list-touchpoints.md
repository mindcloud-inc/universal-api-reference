# List Touchpoints with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/people/:id/touchpoints`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [List Touchpoints](https://platform.hyax.com/api-docs/people-touchpoints)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Person ID whose touchpoints should be listed. |
