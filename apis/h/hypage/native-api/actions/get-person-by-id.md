# Get Person by ID with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/people/:id`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Get Person by ID](https://platform.hyax.com/api-docs/people-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Person ID. |
