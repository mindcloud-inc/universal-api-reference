# Get Post Creation Job Status with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/posts/jobs/:id`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Get Post Creation Job Status](https://platform.hyax.com/api-docs/post-job-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Post creation job ID. |
