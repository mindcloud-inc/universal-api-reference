# Get Product with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/products/:id`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Get Product](https://platform.hyax.com/api-docs/product-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID. |
