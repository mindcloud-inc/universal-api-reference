# Archive Post with Hy.page

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hyax-api/v1/posts/:id`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Archive Post](https://platform.hyax.com/api-docs/post-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Post ID to archive. |
