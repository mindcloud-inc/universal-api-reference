# List Posts with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/posts`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [List Posts](https://platform.hyax.com/api-docs/posts-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Post status filter. |
| `postType` | query | `string` | no | Post type filter. |
