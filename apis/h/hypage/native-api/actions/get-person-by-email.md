# Get Person by Email with Hy.page

## Endpoint

- **Method:** `GET`
- **Path:** `/hyax-api/v1/people/by-email`
- **Base URL:** `https://platform.hyax.com`
- **Official documentation:** [Get Person by Email](https://platform.hyax.com/api-docs/people-by-email)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Person email address. |
