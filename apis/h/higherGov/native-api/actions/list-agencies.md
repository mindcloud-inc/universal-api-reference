# List Agencies with HigherGov

Retrieves agencies from HigherGov.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-external/agency/`
- **Base URL:** `https://www.highergov.com`
- **Official documentation:** [List Agencies](https://www.highergov.com/api-external/docs/#/api-external/api_external_agency_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agency_key` | query | `string` | no | HigherGov Agency key |
