# List PSC Codes with HigherGov

Retrieves PSC codes from HigherGov.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-external/psc/`
- **Base URL:** `https://www.highergov.com`
- **Official documentation:** [List PSC Codes](https://www.highergov.com/api-external/docs/#/api-external/api_external_psc_list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `psc_code` | query | `string` | no | PSC code |
