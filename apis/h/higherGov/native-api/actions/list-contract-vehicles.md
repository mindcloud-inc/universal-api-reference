# List Contract Vehicles with HigherGov

Retrieves contract vehicles from HigherGov.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-external/vehicle/`
- **Base URL:** `https://www.highergov.com`
- **Official documentation:** [List Contract Vehicles](https://www.highergov.com/api-external/docs/#/api-external/api_external_vehicle_list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicle_key` | query | `string` | no | HigherGov Vehicle key |
