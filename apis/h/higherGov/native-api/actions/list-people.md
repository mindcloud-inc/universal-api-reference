# List People with HigherGov

Retrieves people from HigherGov.

## Endpoint

- **Method:** `GET`
- **Path:** `/api-external/people/`
- **Base URL:** `https://www.highergov.com`
- **Official documentation:** [List People](https://www.highergov.com/api-external/docs/#/api-external/api_external_people_list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_email` | query | `string` | no | Email address |
