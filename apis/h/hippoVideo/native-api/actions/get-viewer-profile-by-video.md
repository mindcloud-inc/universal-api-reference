# Get Viewer Profile by Video with Hippo Video

Retrieves viewer profiles for a Hippo Video video.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/video/viewer_profile`
- **Base URL:** `https://www.hippovideo.io`
- **Official documentation:** [Get Viewer Profile by Video](https://help.hippovideo.io/support/solutions/articles/19000095984-video-reports-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | query | `number` | yes | ID of the video |
