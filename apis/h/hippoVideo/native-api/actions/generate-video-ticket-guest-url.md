# Generate Video Ticket Guest URL with Hippo Video

Retrieves a guest URL for Hippo Video ticket recording.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/video/guest_url/`
- **Base URL:** `https://www.hippovideo.io`
- **Official documentation:** [Generate Video Ticket Guest URL](https://help.hippovideo.io/support/solutions/articles/19000116131-video-tickets-api)
