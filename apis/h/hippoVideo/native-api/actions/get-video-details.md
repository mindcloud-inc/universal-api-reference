# Get Video Details with Hippo Video

Retrieves details for a Hippo Video video.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/video/:video_id`
- **Base URL:** `https://www.hippovideo.io`
- **Official documentation:** [Get Video Details](https://help.hippovideo.io/support/solutions/articles/19000095982-video-details-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `number` | yes | ID of the video |
