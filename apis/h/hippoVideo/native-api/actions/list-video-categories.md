# List Video Categories with Hippo Video

Retrieves video categories from Hippo Video.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/video/categories`
- **Base URL:** `https://www.hippovideo.io`
- **Official documentation:** [List Video Categories](https://help.hippovideo.io/support/solutions/articles/19000095979-categories-api)
