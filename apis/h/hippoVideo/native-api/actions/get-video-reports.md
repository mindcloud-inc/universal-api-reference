# Get Video Reports with Hippo Video

Retrieves reports for a Hippo Video video.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/me/video/reports/:video_id`
- **Base URL:** `https://www.hippovideo.io`
- **Official documentation:** [Get Video Reports](https://help.hippovideo.io/support/solutions/articles/19000095984-video-reports-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `number` | yes | ID of the video |
