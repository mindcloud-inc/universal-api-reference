# Delete Leads List with Hunter

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads_lists/:leadsListId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Delete Leads List](https://hunter.io/api-documentation/v2#delete-leads-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadsListId` | path | `string` | yes | Identifier of the leads list. |
