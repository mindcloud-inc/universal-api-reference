# Start Sequence with Hunter

## Endpoint

- **Method:** `POST`
- **Path:** `/campaigns/:campaignId/start`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Start Sequence](https://hunter.io/api-documentation/v2#start-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Identifier of the sequence. |
