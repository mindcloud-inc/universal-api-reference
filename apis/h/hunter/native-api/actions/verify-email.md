# Verify Email with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/email-verifier`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Verify Email](https://hunter.io/api-documentation/v2#email-verifier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to verify. |
