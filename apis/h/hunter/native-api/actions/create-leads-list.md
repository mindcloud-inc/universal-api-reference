# Create Leads List with Hunter

## Endpoint

- **Method:** `POST`
- **Path:** `/leads_lists`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Create Leads List](https://hunter.io/api-documentation/v2#create-leads-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the leads list. |
