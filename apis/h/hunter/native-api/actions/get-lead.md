# Get Lead with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Get Lead](https://hunter.io/api-documentation/v2#get-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Identifier of the lead. |
