# Update Leads List with Hunter

## Endpoint

- **Method:** `PUT`
- **Path:** `/leads_lists/:leadsListId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Update Leads List](https://hunter.io/api-documentation/v2#update-leads-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadsListId` | path | `string` | yes | Identifier of the leads list. |
| `name` | body | `string` | yes | — |
