# Delete Lead with Hunter

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/:leadId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Delete Lead](https://hunter.io/api-documentation/v2#delete-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Identifier of the lead. |
