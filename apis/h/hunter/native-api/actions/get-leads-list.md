# Get Leads List with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/leads_lists/:leadsListId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Get Leads List](https://hunter.io/api-documentation/v2#get-leads-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadsListId` | path | `string` | yes | Identifier of the leads list. |
| `limit` | query | `number` | no | — |
| `offset` | query | `number` | no | — |
