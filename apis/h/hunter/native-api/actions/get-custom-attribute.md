# Get Custom Attribute with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/leads_custom_attributes/:customAttributeId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Get Custom Attribute](https://hunter.io/api-documentation/v2#get-custom-attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customAttributeId` | path | `string` | yes | Identifier of the custom attribute. |
