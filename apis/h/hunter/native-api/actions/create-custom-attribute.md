# Create Custom Attribute with Hunter

## Endpoint

- **Method:** `POST`
- **Path:** `/leads_custom_attributes`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Create Custom Attribute](https://hunter.io/api-documentation/v2#create-custom-attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `label` | body | `string` | yes | Label for the custom attribute. |
