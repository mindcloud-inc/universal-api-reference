# List Sequences with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [List Sequences](https://hunter.io/api-documentation/v2#list-campaigns)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `started` | query | `boolean` | no |
| `archived` | query | `boolean` | no |
| `limit` | query | `number` | no |
| `offset` | query | `number` | no |
