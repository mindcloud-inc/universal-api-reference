# Get Combined Enrichment with Hunter

## Endpoint

- **Method:** `GET`
- **Path:** `/combined/find`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Get Combined Enrichment](https://hunter.io/api-documentation/v2#combined-enrichment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to enrich. |
| `clearbit_format` | query | `boolean` | no | — |
