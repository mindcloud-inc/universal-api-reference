# Delete Custom Attribute with Hunter

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads_custom_attributes/:customAttributeId`
- **Base URL:** `https://api.hunter.io/v2`
- **Official documentation:** [Delete Custom Attribute](https://hunter.io/api-documentation/v2#custom-attributes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customAttributeId` | path | `string` | yes | Identifier of the custom attribute. |
