# Delete Image with HTML/CSS to Image app

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/image/:imageId`
- **Base URL:** `https://hcti.io`
- **Official documentation:** [Delete Image](https://docs.htmlcsstoimage.com/getting-started/using-the-api/#deleting-an-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageId` | path | `string` | yes | Identifier of the image to delete. |
