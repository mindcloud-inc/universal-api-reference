# List Template Versions with HTML/CSS to Image app

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/template/:templateId`
- **Base URL:** `https://hcti.io`
- **Official documentation:** [List Template Versions](https://docs.htmlcsstoimage.com/getting-started/templates/#listing-your-template-versions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateId` | path | `string` | yes | Identifier of the template whose versions you want to list. |
