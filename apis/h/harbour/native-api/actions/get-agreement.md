# Get Agreement with Harbour

Retrieves a specific agreement from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/agreements/:agreement_id`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Get Agreement](https://developers.harbourshare.com/#get-agreement-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agreement_id` | path | `string` | yes | Unique Harbour agreement identifier. |
