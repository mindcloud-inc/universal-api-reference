# Get Brand with Harbour

Retrieves a specific brand from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/organizations/brands/:brand_id`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Get Brand](https://developers.harbourshare.com/#get-brand-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brand_id` | path | `string` | yes | Unique Harbour brand identifier. |
