# Download Agreement with Harbour

Retrieves downloadable agreement files from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/agreements/:agreement_id/download`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Download Agreement](https://developers.harbourshare.com/#download-agreement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agreement_id` | path | `string` | yes | Unique Harbour agreement identifier. |
