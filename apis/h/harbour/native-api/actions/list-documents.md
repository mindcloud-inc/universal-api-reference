# List Documents with Harbour

Retrieves a list of documents from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [List Documents](https://developers.harbourshare.com/v2#list-documents)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `state` | query | `string` | no | Filter documents by state. |
