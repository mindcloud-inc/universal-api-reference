# Get Item with Harbour

Retrieves a specific item from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/items/:item_id`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Get Item](https://developers.harbourshare.com/#get-item-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | Unique Harbour item identifier. |
