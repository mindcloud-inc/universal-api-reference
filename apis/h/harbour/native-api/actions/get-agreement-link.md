# Get Agreement Link with Harbour

Retrieves a specific agreement link from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/agreement_links/:agreement_link_id`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Get Agreement Link](https://developers.harbourshare.com/#get-agreement-link-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agreement_link_id` | path | `string` | yes | Unique Harbour agreement link identifier. |
