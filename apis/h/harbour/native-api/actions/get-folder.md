# Get Folder with Harbour

Retrieves a specific folder from Harbour.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.harbourshare.com/v1/folders/:folder_id`
- **Base URL:** `https://api.myharbourshare.com/v2`
- **Official documentation:** [Get Folder](https://developers.harbourshare.com/#get-folder-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `string` | yes | Unique Harbour folder identifier. |
