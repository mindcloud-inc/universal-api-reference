# Get Character By ID with Harry Potter

Retrieves a Harry Potter character by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/character/:id`
- **Base URL:** `https://hp-api.onrender.com`
- **Official documentation:** [Get Character By ID](https://hp-api.onrender.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique character ID returned by character list actions. |
