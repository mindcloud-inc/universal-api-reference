# Harry Potter: Native API Reference

A consolidated summary of Harry Potter's API configuration and 6 documented operations, with links to official documentation.

- **Official docs:** https://hp-api.onrender.com/
- **API base URL:** `https://hp-api.onrender.com`

## Authentication

### None

No authentication required. The Harry Potter API is publicly accessible.

This API does not require request authentication.

[Official authentication documentation](https://hp-api.onrender.com/)
