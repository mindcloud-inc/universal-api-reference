# Get Client with Halo Service Solutions

Retrieves a client from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Client/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Client](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Client ID. |
