# List Actions with Halo Service Solutions

Retrieves actions from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Actions`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Actions](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticket_id` | query | `number` | no | The ticket id to get actions for. |
| `count` | query | `number` | no | Number of actions to return. |
