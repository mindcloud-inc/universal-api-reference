# Get Ticket with Halo Service Solutions

Retrieves a ticket from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tickets/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Ticket](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Ticket ID. |
