# Get Project with Halo Service Solutions

Retrieves a project from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Projects/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Project](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Project ID. |
