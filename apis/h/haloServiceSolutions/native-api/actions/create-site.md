# Create Site with Halo Service Solutions

Creates a new site in Halo Service Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/Site`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Create Site](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `client_id` | body | `number` | yes |
