# Create Project with Halo Service Solutions

Creates a new project in Halo Service Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/Projects`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Create Project](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summary` | body | `string` | yes |
