# List Users with Halo Service Solutions

Retrieves users from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Users`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Users](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | query | `number` | no | Filter users by site id. |
| `count` | query | `number` | no | Number of users to return. |
