# List Tickets with Halo Service Solutions

Retrieves tickets from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Tickets`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Tickets](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `number` | no | Number of tickets to return. |
