# Get User with Halo Service Solutions

Retrieves a user from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Users/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get User](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
