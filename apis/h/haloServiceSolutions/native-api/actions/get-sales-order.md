# Get Sales Order with Halo Service Solutions

Retrieves a sales order from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/SalesOrder/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Sales Order](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Sales order ID. |
