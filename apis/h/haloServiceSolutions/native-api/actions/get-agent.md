# Get Agent with Halo Service Solutions

Retrieves an agent from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Agent/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Agent](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Agent ID. |
