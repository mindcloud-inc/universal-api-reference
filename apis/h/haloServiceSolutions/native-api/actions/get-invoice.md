# Get Invoice with Halo Service Solutions

Retrieves an invoice from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Invoice/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Invoice](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Invoice ID. |
