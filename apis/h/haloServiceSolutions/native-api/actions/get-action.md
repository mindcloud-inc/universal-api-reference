# Get Action with Halo Service Solutions

Retrieves an action from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Actions/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Action](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Action ID. |
| `ticket_id` | query | `number` | yes | The ticket id to get the action for. |
