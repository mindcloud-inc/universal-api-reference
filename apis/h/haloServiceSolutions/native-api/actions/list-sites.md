# List Sites with Halo Service Solutions

Retrieves sites from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Site`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Sites](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | query | `number` | no | Filter sites by client id. |
| `count` | query | `number` | no | Number of sites to return. |
