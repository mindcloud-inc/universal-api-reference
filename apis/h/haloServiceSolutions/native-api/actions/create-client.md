# Create Client with Halo Service Solutions

Creates a new client in Halo Service Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/Client`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Create Client](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
