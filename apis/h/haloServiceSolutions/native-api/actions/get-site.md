# Get Site with Halo Service Solutions

Retrieves a site from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Site/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Site](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Site ID. |
