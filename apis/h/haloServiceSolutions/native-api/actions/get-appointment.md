# Get Appointment with Halo Service Solutions

Retrieves an appointment from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Appointment/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Appointment](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Appointment ID. |
