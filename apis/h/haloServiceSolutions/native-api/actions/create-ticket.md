# Create Ticket with Halo Service Solutions

Creates a new ticket in Halo Service Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/Tickets`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Create Ticket](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `summary` | body | `string` | yes |
| `details` | body | `string` | no |
