# Create Agent with Halo Service Solutions

Creates a new agent in Halo Service Solutions.

## Endpoint

- **Method:** `POST`
- **Path:** `/Agent`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Create Agent](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `firstname` | body | `string` | no |
| `surname` | body | `string` | no |
| `email` | body | `string` | no |
