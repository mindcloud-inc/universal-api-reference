# List Clients with Halo Service Solutions

Retrieves clients from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Client`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Clients](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `number` | no | Number of clients to return. |
| `search` | query | `string` | no | Filter clients by search string. |
