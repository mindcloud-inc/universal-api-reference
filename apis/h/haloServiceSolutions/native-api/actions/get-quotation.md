# Get Quotation with Halo Service Solutions

Retrieves a quotation from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Quotation/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Quotation](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
