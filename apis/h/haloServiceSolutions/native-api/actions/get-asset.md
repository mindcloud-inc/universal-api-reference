# Get Asset with Halo Service Solutions

Retrieves an asset from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Asset/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Asset](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Asset ID. |
