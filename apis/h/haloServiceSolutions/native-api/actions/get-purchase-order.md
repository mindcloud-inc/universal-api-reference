# Get Purchase Order with Halo Service Solutions

Retrieves a purchase order from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/PurchaseOrder/:id`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [Get Purchase Order](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Purchase order ID. |
