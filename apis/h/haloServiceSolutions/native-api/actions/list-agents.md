# List Agents with Halo Service Solutions

Retrieves agents from Halo Service Solutions.

## Endpoint

- **Method:** `GET`
- **Path:** `/Agent`
- **Base URL:** `https://mindcloud.halopsa.com/api`
- **Official documentation:** [List Agents](https://usehalo.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter agents by search string. |
| `count` | query | `number` | no | Number of agents to return. |
