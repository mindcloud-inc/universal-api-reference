# List External Leave Types with HoorayHR

Retrieves external leave types from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/external-leave-types`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [List External Leave Types](https://api.hoorayhr.io/documentation/#/external-leave-types/findExternalLeaveTypes)
