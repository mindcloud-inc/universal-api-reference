# Get User with HoorayHR

Retrieves an employee record from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get User](https://api.hoorayhr.io/documentation/#/users/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The user ID to retrieve. |
