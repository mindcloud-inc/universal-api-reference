# List Users with HoorayHR

Retrieves employee records from the HoorayHR directory.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [List Users](https://api.hoorayhr.io/documentation/#/users/findUsers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `includeExtraFields` | query | `boolean` | no | Whether to include user extra fields in the response. |
