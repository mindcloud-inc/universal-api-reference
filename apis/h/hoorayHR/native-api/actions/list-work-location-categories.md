# List Work Location Categories with HoorayHR

Retrieves work location categories from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/work-location-categories`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [List Work Location Categories](https://api.hoorayhr.io/documentation/#/work-location-categories/findWorkLocationCategories)
