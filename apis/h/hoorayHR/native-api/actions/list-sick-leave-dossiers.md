# List Sick Leave Dossiers with HoorayHR

Retrieves sick leave dossiers from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/sick-leave-dossiers`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [List Sick Leave Dossiers](https://api.hoorayhr.io/documentation/#/sick-leave-dossiers/findSickLeaveDossiers)
