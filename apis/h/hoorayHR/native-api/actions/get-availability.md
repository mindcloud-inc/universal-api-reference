# Get Availability with HoorayHR

Retrieves an availability record from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/availability/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Availability](https://api.hoorayhr.io/documentation/#/availability/getAvailability)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The availability ID to retrieve. |
