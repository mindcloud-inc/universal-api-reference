# Get Contract with HoorayHR

Retrieves an employment contract from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/contracts/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Contract](https://api.hoorayhr.io/documentation/#/contracts/getContract)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The contract ID to retrieve. |
