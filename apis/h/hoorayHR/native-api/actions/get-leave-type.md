# Get Leave Type with HoorayHR

Retrieves a leave type from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/leave-types/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Leave Type](https://api.hoorayhr.io/documentation/#/leave-types/getLeaveType)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The leave type ID to retrieve. |
