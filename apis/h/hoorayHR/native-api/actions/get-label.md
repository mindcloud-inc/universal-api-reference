# Get Label with HoorayHR

Retrieves a label record from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/labels/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Label](https://api.hoorayhr.io/documentation/#/labels/getLabel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The label ID to retrieve. |
