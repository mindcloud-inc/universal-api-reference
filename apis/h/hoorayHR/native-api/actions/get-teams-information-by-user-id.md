# Get Teams Information by User ID with HoorayHR

Retrieves team information for a user from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams-information/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Teams Information by User ID](https://api.hoorayhr.io/documentation/#/teams-information/getTeamsInformation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The user ID to retrieve team membership details for. |
