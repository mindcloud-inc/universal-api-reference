# List Time Off with HoorayHR

Retrieves time off records from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/time-off`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [List Time Off](https://api.hoorayhr.io/documentation/#/time-off/findTimeOff)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timeOffType` | query | `string` | no | Optional filter for a specific time off type. |
