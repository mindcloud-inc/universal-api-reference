# Get Employment Term with HoorayHR

Retrieves an employment term from HoorayHR.

## Endpoint

- **Method:** `GET`
- **Path:** `/employment-terms/:id`
- **Base URL:** `https://api.hoorayhr.io`
- **Official documentation:** [Get Employment Term](https://api.hoorayhr.io/documentation/#/employment-terms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The employment term ID to retrieve. |
