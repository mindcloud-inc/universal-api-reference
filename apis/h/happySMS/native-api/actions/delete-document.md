# Delete Document with Happy SMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/protected/domain/custom-data/documents/:id`
- **Base URL:** `https://www.api.nc`
- **Official documentation:** [Delete Document](https://www.happy.nc/docs/sms.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique document identifier. |
