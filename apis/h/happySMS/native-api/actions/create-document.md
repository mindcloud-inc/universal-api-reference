# Create Document with Happy SMS

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/protected/domain/custom-data/documents`
- **Base URL:** `https://www.api.nc`
- **Official documentation:** [Create Document](https://www.happy.nc/docs/sms.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resource[]` | body | `array<object>` | yes | Array of document property objects to create. |
