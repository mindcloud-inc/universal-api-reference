# Pop Messages with Happy SMS

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/protected/domain/sms/messages/pop`
- **Base URL:** `https://www.api.nc`
- **Official documentation:** [Pop Messages](https://www.happy.nc/docs/sms.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of recently modified messages to pop. |
