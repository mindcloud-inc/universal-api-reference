# Delete Message with Happy SMS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/protected/domain/sms/messages/:id`
- **Base URL:** `https://www.api.nc`
- **Official documentation:** [Delete Message](https://www.happy.nc/docs/sms.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique SMS identifier. |
