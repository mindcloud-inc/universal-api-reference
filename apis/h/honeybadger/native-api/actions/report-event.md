# Report Event with Honeybadger

Reports monitoring events to Honeybadger Insights.

## Endpoint

- **Method:** `POST`
- **Path:** `/events`
- **Base URL:** `https://api.honeybadger.io/v1`
- **Official documentation:** [Report Event](https://docs.honeybadger.io/api/reporting-events/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
