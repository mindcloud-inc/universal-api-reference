# Get Batch Scrape Job with HasData

Retrieves a batch scrape job from HasData.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape/batch/web/:jobId`
- **Base URL:** `https://api.hasdata.com`
- **Official documentation:** [Get Batch Scrape Job](https://docs.hasdata.com/apis/web-scraping-api/batch-scrape)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Batch scrape job ID. |
