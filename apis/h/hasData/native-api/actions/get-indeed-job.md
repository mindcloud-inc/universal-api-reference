# Get Indeed Job with HasData

Retrieves an Indeed job from HasData.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape/indeed/job`
- **Base URL:** `https://api.hasdata.com`
- **Official documentation:** [Get Indeed Job](https://docs.hasdata.com/apis/indeed/job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Indeed job URL. |
