# Get Redfin Property with HasData

Retrieves a Redfin property from HasData.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape/redfin/property`
- **Base URL:** `https://api.hasdata.com`
- **Official documentation:** [Get Redfin Property](https://docs.hasdata.com/apis/redfin/property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Redfin property URL. |
