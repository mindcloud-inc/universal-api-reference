# Get Airbnb Property with HasData

Retrieves an Airbnb property from HasData.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape/airbnb/property`
- **Base URL:** `https://api.hasdata.com`
- **Official documentation:** [Get Airbnb Property](https://docs.hasdata.com/apis/airbnb/property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | Airbnb listing URL. |
