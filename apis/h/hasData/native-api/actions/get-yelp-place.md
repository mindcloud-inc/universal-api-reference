# Get Yelp Place with HasData

Retrieves a Yelp place from HasData.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrape/yelp/place`
- **Base URL:** `https://api.hasdata.com`
- **Official documentation:** [Get Yelp Place](https://docs.hasdata.com/apis/yelp/place)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `placeId` | query | `string` | yes | Yelp business ID or alias. |
