# List Certificate Action Links with 4HSE

Retrieves certificate-action links from 4HSE.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/certificate-action/index`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [List Certificate Action Links](https://docs.4hse.com/en/api/certificateaction/#operation-indexCertificateAction-post)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
