# View Action with 4HSE

Retrieves an action from 4HSE.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/action/view/:id`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [View Action](https://docs.4hse.com/en/api/action/#operation-viewAction-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The action_id to view. |
