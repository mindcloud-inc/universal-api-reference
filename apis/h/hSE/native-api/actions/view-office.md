# View Office with 4HSE

Retrieves an office from 4HSE.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/office/view/:id`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [View Office](https://docs.4hse.com/en/api/office/#operation-viewOffice-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The office_id to retrieve. |
