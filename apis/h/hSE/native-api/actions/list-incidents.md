# List Incidents with 4HSE

Retrieves incidents from 4HSE.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/incident/index`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [List Incidents](https://docs.4hse.com/en/api/incident/#operation-indexIncident-post)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
