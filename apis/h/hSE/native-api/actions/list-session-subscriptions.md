# List Session Subscriptions with 4HSE

Retrieves session subscriptions from 4HSE.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/action-session-subscription/index`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [List Session Subscriptions](https://docs.4hse.com/en/api/actionsessionsubscription/#operation-indexActionSessionSubscription-post)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
