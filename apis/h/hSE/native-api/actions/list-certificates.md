# List Certificates with 4HSE

Retrieves certificates from 4HSE.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/certificate/index`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [List Certificates](https://docs.4hse.com/en/api/certificate/#operation-indexCertificate-post)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
