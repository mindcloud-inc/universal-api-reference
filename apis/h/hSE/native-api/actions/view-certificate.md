# View Certificate with 4HSE

Retrieves a certificate from 4HSE.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/certificate/view/:id`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [View Certificate](https://docs.4hse.com/en/api/certificate/#operation-viewCertificate-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The certificate to view. |
