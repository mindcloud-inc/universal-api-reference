# List Action Sessions with 4HSE

Retrieves action sessions from 4HSE.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/action-session/index`
- **Base URL:** `https://service.4hse.com`
- **Official documentation:** [List Action Sessions](https://docs.4hse.com/en/api/actionsession/#operation-indexActionSession-post)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
