# List Events with Humanitix

Retrieves events from Humanitix for the connected account.

## Endpoint

- **Method:** `GET`
- **Path:** `/events`
- **Base URL:** `https://api.humanitix.com/v1`
- **Official documentation:** [List Events](https://humanitix.stoplight.io/docs/humanitix-public-api/476881e4b5d55-get-events)

## Capabilities

This operation supports [pagination](../README.md#pagination).
