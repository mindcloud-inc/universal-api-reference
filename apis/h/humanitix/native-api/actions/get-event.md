# Get Event with Humanitix

Retrieves an event from Humanitix by event ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:eventId`
- **Base URL:** `https://api.humanitix.com/v1`
- **Official documentation:** [Get Event](https://humanitix.stoplight.io/docs/humanitix-public-api/970584136120e-get-event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The Humanitix event ID. |
