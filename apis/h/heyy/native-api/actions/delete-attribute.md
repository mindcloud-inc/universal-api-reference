# Delete Attribute with Heyy

Deletes an existing attribute from Heyy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attributes/:attributeId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Delete Attribute](https://docs.heyy.io/api-reference/delete-attribute)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `attributeId` | path | `string` | yes | The Heyy attribute ID. |
