# List Message Templates with Heyy

Retrieves message templates from a Heyy workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/message_templates`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [List Message Templates](https://docs.heyy.io/api-reference/get-message-templates)
