# Get Contact by ID with Heyy

Retrieves a contact by ID from Heyy.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Get Contact by ID](https://docs.heyy.io/api-reference/get-contact-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Heyy contact ID. |
