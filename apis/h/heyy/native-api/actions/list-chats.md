# List Chats with Heyy

Retrieves chats from a Heyy channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:channelId]/chats`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [List Chats](https://docs.heyy.io/api-reference/get-chats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The Heyy channel ID. |
