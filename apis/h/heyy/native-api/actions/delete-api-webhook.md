# Delete API Webhook with Heyy

Deletes an existing API webhook from Heyy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api_webhooks/:webhookId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Delete API Webhook](https://docs.heyy.io/api-reference/delete-api-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The Heyy webhook ID. |
