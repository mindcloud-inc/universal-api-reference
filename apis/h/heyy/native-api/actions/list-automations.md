# List Automations with Heyy

Retrieves automations from a Heyy channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:channelId]/workflows`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [List Automations](https://docs.heyy.io/api-reference/get-automations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The Heyy channel ID. |
