# Delete Contact with Heyy

Deletes an existing contact from Heyy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Delete Contact](https://docs.heyy.io/api-reference/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The Heyy contact ID. |
