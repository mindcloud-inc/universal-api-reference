# Delete Label with Heyy

Deletes an existing label from Heyy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/labels/:labelId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Delete Label](https://docs.heyy.io/api-reference/delete-label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | The Heyy label ID. |
