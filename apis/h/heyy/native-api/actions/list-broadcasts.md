# List Broadcasts with Heyy

Retrieves broadcasts from a Heyy channel.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:channelId]/broadcasts`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [List Broadcasts](https://docs.heyy.io/api-reference/get-broadcasts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The Heyy channel ID. |
