# Get Channel by ID with Heyy

Retrieves a channel by ID from Heyy.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:channelId`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Get Channel by ID](https://docs.heyy.io/api-reference/get-channel-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | yes | The Heyy channel ID. |
