# Create Label with Heyy

Creates a new label in Heyy.

## Endpoint

- **Method:** `POST`
- **Path:** `/labels`
- **Base URL:** `https://api.heyy.io/api/v2.0/`
- **Official documentation:** [Create Label](https://docs.heyy.io/api-reference/create-label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The label name. |
