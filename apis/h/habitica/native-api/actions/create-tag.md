# Create Tag with Habitica

Creates a new tag in Habitica.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Create Tag](https://habitica.com/apidoc/#api-Tag-CreateTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The tag name. |
