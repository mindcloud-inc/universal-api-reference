# Delete Tag with Habitica

Deletes an existing tag from Habitica.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tagId`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Delete Tag](https://habitica.com/apidoc/#api-Tag-DeleteTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | The Habitica tag ID. |
