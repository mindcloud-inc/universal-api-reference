# Get Member with Habitica

Retrieves a member from Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/members/:memberId`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Get Member](https://habitica.com/apidoc/#api-Member-GetMember)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memberId` | path | `string` | yes | The Habitica member ID. |
