# Get Tag with Habitica

Retrieves a tag from Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tagId`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Get Tag](https://habitica.com/apidoc/#api-Tag-GetTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | The Habitica tag ID. |
