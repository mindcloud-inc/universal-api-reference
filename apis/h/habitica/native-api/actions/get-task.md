# Get Task with Habitica

Retrieves a task from Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:taskId`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Get Task](https://habitica.com/apidoc/#api-Task-GetTask)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The Habitica task ID. |
