# Get Inventory Buy List with Habitica

Retrieves items available for purchase in Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/inventory/buy`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Get Inventory Buy List](https://habitica.com/apidoc/#api-User-UserGetBuyList)
