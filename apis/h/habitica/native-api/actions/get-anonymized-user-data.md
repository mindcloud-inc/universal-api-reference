# Get Anonymized User Data with Habitica

Retrieves anonymized user data from Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/anonymized`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [Get Anonymized User Data](https://habitica.com/apidoc/#api-User-UserGetAnonymized)
