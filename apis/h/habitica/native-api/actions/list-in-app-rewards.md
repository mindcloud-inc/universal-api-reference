# List In-App Rewards with Habitica

Retrieves in-app rewards from Habitica.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/in-app-rewards`
- **Base URL:** `https://habitica.com/api/v3`
- **Official documentation:** [List In-App Rewards](https://habitica.com/apidoc/#api-User-UserGetInAppRewards)
