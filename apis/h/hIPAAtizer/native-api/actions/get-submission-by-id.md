# Get Submission By ID with HIPAAtizer

Retrieves a submission by ID from HIPAAtizer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api_key/submissions/:submissionId`
- **Base URL:** `https://app.hipaatizer.com`
- **Official documentation:** [Get Submission By ID](https://github.com/HIPAAtizer/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | Submission identifier. |
