# List All Locations with HIPAAtizer

Retrieves all account locations from HIPAAtizer.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/api_key/locations/all`
- **Base URL:** `https://app.hipaatizer.com`
- **Official documentation:** [List All Locations](https://github.com/HIPAAtizer/api-docs)
