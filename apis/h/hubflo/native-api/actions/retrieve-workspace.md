# Retrieve Workspace with Hubflo

Retrieves a workspace from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Workspace](https://hubflo.readme.io/reference/get_api-v2-workspaces-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
