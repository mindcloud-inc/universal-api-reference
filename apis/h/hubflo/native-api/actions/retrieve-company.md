# Retrieve Company with Hubflo

Retrieves a company from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Company](https://hubflo.readme.io/reference/get_api-v2-companies-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
