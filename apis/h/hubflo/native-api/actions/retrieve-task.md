# Retrieve Task with Hubflo

Retrieves a task from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Task](https://hubflo.readme.io/reference/get_api-v2-tasks-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
