# Retrieve Proposal with Hubflo

Retrieves a proposal from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/proposals/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Proposal](https://hubflo.readme.io/reference/get_api-v2-proposals-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
