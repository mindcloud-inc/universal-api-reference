# Retrieve Contact with Hubflo

Retrieves a contact from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Contact](https://hubflo.readme.io/reference/get_api-v2-contacts-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
