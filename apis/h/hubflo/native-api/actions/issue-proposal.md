# Issue Proposal with Hubflo

Issues a draft proposal in Hubflo.

## Endpoint

- **Method:** `POST`
- **Path:** `/proposals/:proposal_id/issuances`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Issue Proposal](https://hubflo.readme.io/reference/post_api-v2-proposals-proposal-id-issuances)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `proposal_id` | path | `string` | yes |
