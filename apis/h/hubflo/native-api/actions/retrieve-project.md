# Retrieve Project with Hubflo

Retrieves a project from Hubflo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://app.hubflo.com/api/v2`
- **Official documentation:** [Retrieve Project](https://hubflo.readme.io/reference/get_api-v2-projects-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
