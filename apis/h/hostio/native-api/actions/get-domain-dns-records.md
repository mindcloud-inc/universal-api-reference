# Get Domain DNS Records with Host.io

Retrieves DNS records for a domain from Host.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/dns/:domain`
- **Base URL:** `https://host.io/api`
- **Official documentation:** [Get Domain DNS Records](https://host.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to retrieve DNS records for. |
