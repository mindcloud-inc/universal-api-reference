# Get Domain Web Metadata with Host.io

Retrieves web metadata for a domain from Host.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/web/:domain`
- **Base URL:** `https://host.io/api`
- **Official documentation:** [Get Domain Web Metadata](https://host.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to retrieve homepage metadata for. |
