# Get Domain Full Details with Host.io

Retrieves full domain details from Host.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/full/:domain`
- **Base URL:** `https://host.io/api`
- **Official documentation:** [Get Domain Full Details](https://host.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to look up with Host.io full domain details. |
