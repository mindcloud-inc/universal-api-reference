# List Domains by Instagram Handle with Host.io

Finds domains in Host.io by Instagram handle.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/instagram/:value`
- **Base URL:** `https://host.io/api`
- **Official documentation:** [List Domains by Instagram Handle](https://host.io/docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | path | `string` | yes | Instagram handle to search for. |
