# Get Related Domain Counts with Host.io

Retrieves related domain counts from Host.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/related/:domain`
- **Base URL:** `https://host.io/api`
- **Official documentation:** [Get Related Domain Counts](https://host.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain to retrieve related-domain counts for. |
