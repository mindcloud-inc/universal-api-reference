# Retrieve Transcription with HappyScribe

Retrieves a transcription from HappyScribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/transcriptions/:id`
- **Base URL:** `https://www.happyscribe.com/api/v1`
- **Official documentation:** [Retrieve Transcription](https://dev.happyscribe.com/sections/product/#transcriptions-retrieve-a-transcription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The transcription identifier. |
