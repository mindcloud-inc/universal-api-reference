# Confirm Order with HappyScribe

Confirms an order in HappyScribe.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders/:id/confirm`
- **Base URL:** `https://www.happyscribe.com/api/v1`
- **Official documentation:** [Confirm Order](https://dev.happyscribe.com/sections/product/#orders-confirm-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The order identifier. |
