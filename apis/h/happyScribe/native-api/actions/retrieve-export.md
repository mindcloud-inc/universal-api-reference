# Retrieve Export with HappyScribe

Retrieves an export from HappyScribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/exports/:id`
- **Base URL:** `https://www.happyscribe.com/api/v1`
- **Official documentation:** [Retrieve Export](https://dev.happyscribe.com/sections/product/#exports-retrieve-an-export)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The export identifier. |
