# Retrieve Order with HappyScribe

Retrieves an order from HappyScribe.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://www.happyscribe.com/api/v1`
- **Official documentation:** [Retrieve Order](https://dev.happyscribe.com/sections/product/#orders-retrieve-an-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The order identifier. |
