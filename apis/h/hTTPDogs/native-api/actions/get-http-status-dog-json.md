# Get HTTP Status Dog JSON with HTTP Dogs

## Endpoint

- **Method:** `GET`
- **Path:** `/:statusCode.json`
- **Base URL:** `https://http.dog`
- **Official documentation:** [Get HTTP Status Dog JSON](https://http.dog/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `statusCode` | path | `number` | yes | Required three-digit HTTP response status code. |
