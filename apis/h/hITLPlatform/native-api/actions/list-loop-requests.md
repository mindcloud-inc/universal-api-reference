# List Loop Requests with HITL Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/api/loops/:loopId/requests`
- **Base URL:** `https://api.hitl.sh/v1`
- **Official documentation:** [List Loop Requests](https://docs.hitl.sh/api-reference/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `loopId` | path | `string` | yes | The loop whose requests should be listed. |
