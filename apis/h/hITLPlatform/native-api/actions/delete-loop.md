# Delete Loop with HITL Platform

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/loops/:id`
- **Base URL:** `https://api.hitl.sh/v1`
- **Official documentation:** [Delete Loop](https://docs.hitl.sh/api-reference/loops/delete-loop)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the loop. |
