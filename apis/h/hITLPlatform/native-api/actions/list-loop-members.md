# List Loop Members with HITL Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/api/loops/:id/members`
- **Base URL:** `https://api.hitl.sh/v1`
- **Official documentation:** [List Loop Members](https://docs.hitl.sh/concepts/loops)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the loop. |
