# Cancel Request with HITL Platform

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/requests/:id`
- **Base URL:** `https://api.hitl.sh/v1`
- **Official documentation:** [Cancel Request](https://docs.hitl.sh/api-reference/requests/cancel-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the request to cancel. |
