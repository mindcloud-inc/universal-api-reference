# Get Request with HITL Platform

## Endpoint

- **Method:** `GET`
- **Path:** `/api/requests/:id`
- **Base URL:** `https://api.hitl.sh/v1`
- **Official documentation:** [Get Request](https://docs.hitl.sh/api-reference/requests/get-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the request. |
