# Delete Connector with Harness

Deletes a connector from Harness.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ng/api/connectors/:identifier`
- **Base URL:** `https://app.harness.io/gateway`
- **Official documentation:** [Delete Connector](https://apidocs.harness.io/connectors/deleteconnector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Connector identifier. |
