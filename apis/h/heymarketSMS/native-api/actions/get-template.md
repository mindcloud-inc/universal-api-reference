# Get Template with Heymarket SMS

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/template/:id`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [Get Template](https://heymarket.docs.apiary.io/api-description-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier of the template. |
