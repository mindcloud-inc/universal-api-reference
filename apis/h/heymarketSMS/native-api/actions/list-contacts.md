# List Contacts with Heymarket SMS

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contacts`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [List Contacts](https://heymarket.docs.apiary.io/api-description-document)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | body | `date` | no | Last timestamp cursor in RFC 3339 format. |
