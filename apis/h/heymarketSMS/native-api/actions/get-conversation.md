# Get Conversation with Heymarket SMS

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/conversations/:id`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [Get Conversation](https://heymarket.docs.apiary.io/api-description-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique identifier of the conversation. |
