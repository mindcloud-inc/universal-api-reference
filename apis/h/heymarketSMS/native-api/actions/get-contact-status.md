# Get Contact Status with Heymarket SMS

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/contact/status`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [Get Contact Status](https://heymarket.docs.apiary.io/api-description-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | no | Heymarket contact id to check. |
| `phone` | body | `string` | no | Contact phone number to check. |
