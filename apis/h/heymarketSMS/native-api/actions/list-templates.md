# List Templates with Heymarket SMS

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/templates`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [List Templates](https://heymarket.docs.apiary.io/api-description-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | body | `string` | no | Last updated cursor in RFC 3339 format. |
