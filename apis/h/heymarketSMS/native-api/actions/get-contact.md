# Get Contact with Heymarket SMS

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contact/:id`
- **Base URL:** `https://api.heymarket.com`
- **Official documentation:** [Get Contact](https://heymarket.docs.apiary.io/api-description-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact id to fetch. |
