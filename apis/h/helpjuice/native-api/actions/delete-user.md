# Delete User with Helpjuice

Deletes an existing user from Helpjuice.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Delete User](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice user id. |
