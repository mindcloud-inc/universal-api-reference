# Upvote Article with Helpjuice

Upvotes an article in Helpjuice.

## Endpoint

- **Method:** `PUT`
- **Path:** `/articles/:id/upvote`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Upvote Article](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice article id. |
