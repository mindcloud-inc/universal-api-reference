# Toggle Webhook with Helpjuice

Toggles a webhook in Helpjuice.

## Endpoint

- **Method:** `PUT`
- **Path:** `/webhooks/:id/toggle`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Toggle Webhook](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice webhook id. |
