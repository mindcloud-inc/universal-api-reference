# Delete Article with Helpjuice

Deletes an existing article from Helpjuice.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/articles/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Delete Article](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice article ID to delete. |
