# Delete Webhook with Helpjuice

Deletes an existing webhook from Helpjuice.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Delete Webhook](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The webhook ID to delete. |
