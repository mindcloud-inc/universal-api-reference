# Get Webhook with Helpjuice

Retrieves a webhook from Helpjuice.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Webhook](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice webhook id. |
