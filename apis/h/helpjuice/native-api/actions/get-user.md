# Get User with Helpjuice

Retrieves a user from Helpjuice.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get User](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice user id. |
