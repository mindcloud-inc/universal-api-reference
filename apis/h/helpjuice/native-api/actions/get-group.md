# Get Group with Helpjuice

Retrieves a group from Helpjuice.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Group](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice group id. |
