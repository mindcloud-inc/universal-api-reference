# Get Activity with Helpjuice

Retrieves an activity from Helpjuice.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Activity](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice activity id. |
