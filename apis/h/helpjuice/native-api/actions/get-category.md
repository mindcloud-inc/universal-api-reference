# Get Category with Helpjuice

Retrieves a category from Helpjuice.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories/:id`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Get Category](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice category id. |
