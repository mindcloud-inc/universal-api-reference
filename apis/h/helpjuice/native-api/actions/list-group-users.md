# List Group Users with Helpjuice

Retrieves users in a Helpjuice group.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id/users`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Group Users](https://help.helpjuice.com/api-v3/using-api-v3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Helpjuice group id. |
