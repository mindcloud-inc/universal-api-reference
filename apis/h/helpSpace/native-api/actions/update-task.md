# Update Task with HelpSpace

Updates an existing task in HelpSpace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/scrum/tasks/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Update Task](https://documentation.helpspace.com/api-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace task identifier. |
