# List Docs Categories with HelpSpace

Retrieves docs categories from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/categories`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Docs Categories](https://documentation.helpspace.com/api-docs-categories)

## Capabilities

This operation supports [pagination](../README.md#pagination).
