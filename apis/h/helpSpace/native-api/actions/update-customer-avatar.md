# Update Customer Avatar with HelpSpace

Updates a customer avatar in HelpSpace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/customers/{id}/avatar`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Update Customer Avatar](https://documentation.helpspace.com/api-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace customer identifier. |
