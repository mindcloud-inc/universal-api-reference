# List Tickets with HelpSpace

Retrieves tickets from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Tickets](https://documentation.helpspace.com/api-tickets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
