# List Docs Articles with HelpSpace

Retrieves docs articles from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/articles`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Docs Articles](https://documentation.helpspace.com/api-docs-articles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
