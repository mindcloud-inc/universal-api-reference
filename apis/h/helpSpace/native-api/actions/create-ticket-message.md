# Create Ticket Message with HelpSpace

Creates a ticket message in HelpSpace.

## Endpoint

- **Method:** `POST`
- **Path:** `/tickets/{id}/messages`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Create Ticket Message](https://documentation.helpspace.com/api-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace ticket identifier. |
