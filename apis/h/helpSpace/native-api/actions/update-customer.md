# Update Customer with HelpSpace

Updates an existing customer in HelpSpace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Update Customer](https://documentation.helpspace.com/api-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace customer identifier. |
