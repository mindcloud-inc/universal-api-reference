# Get Attachment Media with HelpSpace

Retrieves attachment media from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/media/attachment/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Attachment Media](https://documentation.helpspace.com/api-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace attachment identifier. |
