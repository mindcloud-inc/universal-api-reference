# List Tags with HelpSpace

Retrieves tags from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Tags](https://documentation.helpspace.com/api-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
