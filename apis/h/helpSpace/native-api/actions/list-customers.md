# List Customers with HelpSpace

Retrieves customers from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Customers](https://documentation.helpspace.com/api-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
