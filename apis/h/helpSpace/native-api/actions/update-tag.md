# Update Tag with HelpSpace

Updates an existing tag in HelpSpace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tags/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Update Tag](https://documentation.helpspace.com/api-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace tag identifier. |
