# Get Customer Avatar with HelpSpace

Retrieves a customer avatar from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}/avatar`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Customer Avatar](https://documentation.helpspace.com/api-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace customer identifier. |
