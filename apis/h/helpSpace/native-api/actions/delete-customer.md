# Delete Customer with HelpSpace

Deletes a customer from HelpSpace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Delete Customer](https://documentation.helpspace.com/api-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace customer identifier. |
