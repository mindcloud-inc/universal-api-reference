# Delete Task with HelpSpace

Deletes a task from HelpSpace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/scrum/tasks/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Delete Task](https://documentation.helpspace.com/api-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace task identifier. |
