# Update Ticket with HelpSpace

Updates an existing ticket in HelpSpace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tickets/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Update Ticket](https://documentation.helpspace.com/api-tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace ticket identifier. |
