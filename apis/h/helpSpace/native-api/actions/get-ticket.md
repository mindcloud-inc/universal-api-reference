# Get Ticket with HelpSpace

Retrieves a ticket from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Ticket](https://documentation.helpspace.com/api-tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace ticket identifier. |
