# Get Tag with HelpSpace

Retrieves a tag from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Tag](https://documentation.helpspace.com/api-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace tag identifier. |
