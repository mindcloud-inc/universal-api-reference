# List Docs Sites with HelpSpace

Retrieves docs sites from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/sites`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Docs Sites](https://documentation.helpspace.com/api-docs-sites)

## Capabilities

This operation supports [pagination](../README.md#pagination).
