# Get Docs Article with HelpSpace

Retrieves a docs article from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/articles/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Docs Article](https://documentation.helpspace.com/api-docs-articles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace docs article identifier. |
