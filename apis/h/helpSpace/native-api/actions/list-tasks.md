# List Tasks with HelpSpace

Retrieves tasks from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/scrum/tasks`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [List Tasks](https://documentation.helpspace.com/api-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
