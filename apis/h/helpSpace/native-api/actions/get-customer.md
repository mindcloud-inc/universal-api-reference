# Get Customer with HelpSpace

Retrieves a customer from HelpSpace.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.helpspace.com/api/v1`
- **Official documentation:** [Get Customer](https://documentation.helpspace.com/api-customers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | HelpSpace customer identifier. |
