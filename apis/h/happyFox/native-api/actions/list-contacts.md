# List Contacts with HappyFox

Retrieves contacts from HappyFox.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/`
- **Base URL:** `https://{accountDomain}/api/1.1/json`
- **Official documentation:** [List Contacts](https://support.happyfox.com/kb/article/1092-contacts-and-contact-groups-api-endpoints/)
