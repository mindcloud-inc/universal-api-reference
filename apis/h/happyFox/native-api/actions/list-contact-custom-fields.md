# List Contact Custom Fields with HappyFox

Retrieves contact custom fields from HappyFox.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_custom_fields/`
- **Base URL:** `https://{accountDomain}/api/1.1/json`
- **Official documentation:** [List Contact Custom Fields](https://support.happyfox.com/kb/article/360-api-for-happyfox/)
