# List Ticket Custom Fields with HappyFox

Retrieves ticket custom fields from HappyFox.

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket_custom_fields/`
- **Base URL:** `https://{accountDomain}/api/1.1/json`
- **Official documentation:** [List Ticket Custom Fields](https://support.happyfox.com/kb/article/360-api-for-happyfox/)
