# List Contact Groups with HappyFox

Retrieves contact groups from HappyFox.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_groups/`
- **Base URL:** `https://{accountDomain}/api/1.1/json`
- **Official documentation:** [List Contact Groups](https://support.happyfox.com/kb/article/1092-contacts-and-contact-groups-api-endpoints/)
