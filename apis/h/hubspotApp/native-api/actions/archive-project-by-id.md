# Archive Project by ID with HubSpot

## Endpoint

- **Method:** `DELETE`
- **Path:** `crm/objects/2026-03/projects/:projectId`
- **Base URL:** `https://api.hubapi.com`
- **API:** REST - Query Pagination
- **Official documentation:** [Archive Project by ID](https://developers.hubspot.com/docs/api-reference/latest/crm/objects/projects/guide)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
