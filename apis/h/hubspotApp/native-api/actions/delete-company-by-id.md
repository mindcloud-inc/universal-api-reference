# Delete Company by ID with HubSpot

Deletes an existing company from HubSpot.

## Endpoint

- **Method:** `DELETE`
- **Path:** `crm/v3/objects/companies/:companyId`
- **Base URL:** `https://api.hubapi.com`
- **API:** REST - Query Pagination
- **Official documentation:** [Delete Company by ID](https://developers.hubspot.com/docs/api-reference/crm-companies-v3/basic/delete-crm-v3-objects-companies-companyId)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `string` | yes |
