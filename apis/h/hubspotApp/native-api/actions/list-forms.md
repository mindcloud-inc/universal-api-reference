# List Forms with HubSpot

Retrieves forms from HubSpot.

## Endpoint

- **Method:** `GET`
- **Path:** `forms/v2/forms`
- **Base URL:** `https://api.hubapi.com`
- **API:** REST - Query Pagination
- **Official documentation:** [List Forms](https://developers.hubspot.com/docs/api-reference/legacy/forms-v2/forms/get-forms-v2-forms)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of forms to return. |
| `offset` | query | `number` | no | Pagination offset for forms. |
