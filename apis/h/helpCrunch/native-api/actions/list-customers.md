# List Customers with HelpCrunch

Retrieves a list of customers from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [List Customers](https://docs.helpcrunch.com/en/rest-api-v1/get-customers-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
