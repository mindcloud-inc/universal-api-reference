# List Departments with HelpCrunch

Retrieves a list of departments from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/departments`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [List Departments](https://docs.helpcrunch.com/en/rest-api-v1/get-departments-v1)
