# List Chats with HelpCrunch

Retrieves a list of chats from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [List Chats](https://docs.helpcrunch.com/en/rest-api-v1/get-chats-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
