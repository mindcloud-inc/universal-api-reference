# Get Team Availability Status with HelpCrunch

Retrieves team availability status from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Get Team Availability Status](https://docs.helpcrunch.com/en/rest-api-v1/get-organization-v1)
