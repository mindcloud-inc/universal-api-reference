# Unsubscribe Team Member with HelpCrunch

Unsubscribes a team member in HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId/unsubscribe`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Unsubscribe Team Member](https://docs.helpcrunch.com/en/rest-api-v1/unsubscribe-agent-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `number` | yes |
