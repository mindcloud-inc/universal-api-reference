# Get Chat with HelpCrunch

Retrieves a single chat from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/chats/:chatId`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Get Chat](https://docs.helpcrunch.com/en/rest-api-v1/get-chat-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chatId` | path | `number` | yes |
