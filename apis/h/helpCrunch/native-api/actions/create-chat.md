# Create Chat with HelpCrunch

Creates a new chat in HelpCrunch.

## Endpoint

- **Method:** `POST`
- **Path:** `/chats`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Create Chat](https://docs.helpcrunch.com/en/rest-api-v1/create-chat-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `application` | body | `number` | yes |
| `customer` | body | `number` | yes |
