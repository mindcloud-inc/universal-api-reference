# Delete Customer with HelpCrunch

Deletes an existing customer from HelpCrunch.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Delete Customer](https://docs.helpcrunch.com/en/rest-api-v1/delete-customer-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
