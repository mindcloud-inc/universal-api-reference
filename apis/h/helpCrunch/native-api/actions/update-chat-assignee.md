# Update Chat Assignee with HelpCrunch

Updates a chat's assignee in HelpCrunch.

## Endpoint

- **Method:** `PUT`
- **Path:** `/chats/assignee`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Update Chat Assignee](https://docs.helpcrunch.com/en/rest-api-v1/update-chat-assignee-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `assignee` | body | `number` | yes |
| `id` | body | `number` | yes |
