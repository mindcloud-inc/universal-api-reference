# Update Chat Department with HelpCrunch

Updates a chat's department in HelpCrunch.

## Endpoint

- **Method:** `PUT`
- **Path:** `/chats/department`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Update Chat Department](https://docs.helpcrunch.com/en/rest-api-v1/update-chat-department-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `department` | body | `number` | yes |
| `id` | body | `number` | yes |
