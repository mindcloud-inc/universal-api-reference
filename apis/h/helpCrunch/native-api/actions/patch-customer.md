# Patch Customer with HelpCrunch

Updates an existing customer in HelpCrunch.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Patch Customer](https://docs.helpcrunch.com/en/rest-api-v1/update-customer-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
