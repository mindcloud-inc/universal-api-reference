# Search Customers with HelpCrunch

Finds customers in HelpCrunch using search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers/search`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Search Customers](https://docs.helpcrunch.com/en/rest-api-v1/search-customers-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
