# Search Chats with HelpCrunch

Finds chats in HelpCrunch using search filters.

## Endpoint

- **Method:** `POST`
- **Path:** `/chats/search`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Search Chats](https://docs.helpcrunch.com/en/rest-api-v1/search-chats-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
