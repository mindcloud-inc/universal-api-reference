# List Applications with HelpCrunch

Retrieves a list of applications from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/applications`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [List Applications](https://docs.helpcrunch.com/en/rest-api-v1/get-applications-v1)
