# Batch Update Customers with HelpCrunch

Updates multiple customer records in HelpCrunch.

## Endpoint

- **Method:** `PUT`
- **Path:** `/customers/batch`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Batch Update Customers](https://docs.helpcrunch.com/en/rest-api-v1/batch-update-customers-v1)
