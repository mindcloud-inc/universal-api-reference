# Get Customer with HelpCrunch

Retrieves a single customer from HelpCrunch.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://api.helpcrunch.com/v1`
- **Official documentation:** [Get Customer](https://docs.helpcrunch.com/en/rest-api-v1/get-customer-v1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `customerId` | path | `number` | yes |
