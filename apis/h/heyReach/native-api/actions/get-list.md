# Get List with Hey Reach

Retrieves a lead or company list from Hey Reach.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/list/GetById`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Get List](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | query | `number` | yes |
