# Get Conversation with Hey Reach

Retrieves a LinkedIn conversation from Hey Reach.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/inbox/GetChatroom/:accountId/:conversationId`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Get Conversation](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `number` | yes |
| `conversationId` | path | `string` | yes |
