# List Lists For Lead with Hey Reach

Retrieves lists for a lead in Hey Reach.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/list/GetListsForLead`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [List Lists For Lead](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
| `linkedinId` | body | `string` | no |
| `profileUrl` | body | `string` | no |
| `offset` | body | `number` | no |
| `limit` | body | `number` | no |
