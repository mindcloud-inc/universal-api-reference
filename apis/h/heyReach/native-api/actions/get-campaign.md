# Get Campaign with Hey Reach

Retrieves a campaign from Hey Reach.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/campaign/GetById`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Get Campaign](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | query | `number` | yes |
