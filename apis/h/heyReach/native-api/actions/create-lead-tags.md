# Create Lead Tags with Hey Reach

Creates lead tags in Hey Reach.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/lead_tags/CreateTags`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Create Lead Tags](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tags[]` | body | `array<object>` | yes |
