# Create Empty List with Hey Reach

Creates an empty lead or company list in Hey Reach.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/list/CreateEmptyList`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Create Empty List](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `type` | body | `string` | yes |
