# Resume Campaign with Hey Reach

Resumes a campaign in Hey Reach.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/campaign/Resume`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Resume Campaign](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | query | `number` | yes |
