# Get Webhook with Hey Reach

Retrieves a webhook from Hey Reach.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/webhooks/GetWebhookById`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Get Webhook](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhookId` | query | `string` | yes |
