# Delete Webhook with Hey Reach

Deletes an existing webhook from Hey Reach.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/public/webhooks/DeleteWebhook`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Delete Webhook](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhookId` | query | `string` | yes |
