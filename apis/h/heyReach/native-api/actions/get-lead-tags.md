# Get Lead Tags with Hey Reach

Retrieves tags for a lead in Hey Reach.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/lead/GetTags`
- **Base URL:** `https://api.heyreach.io`
- **Official documentation:** [Get Lead Tags](https://documenter.getpostman.com/view/23808049/2sA2xb5F75)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `profileUrl` | body | `string` | yes |
