# Retrieve Product Label with Hyperzod

Retrieves a product label from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v1/catalog/product-label/view`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Retrieve Product Label](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-MgJxhn35hDnURsHquxlg8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
| `merchant_id` | body | `string` | yes |
