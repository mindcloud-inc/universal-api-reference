# List Product Categories with Hyperzod

Retrieves a list of product categories from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v1/catalog/product-category/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Product Categories](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-pgmdT8W6mKye0Px5WC5NV)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `merchant_id` | body | `string` | yes |
