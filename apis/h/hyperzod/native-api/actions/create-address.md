# Create Address with Hyperzod

Creates a new address in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/address/create`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Create Address](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-osZ5KYwLg5Bs0GbS5wOjT)
