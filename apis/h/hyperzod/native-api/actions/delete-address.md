# Delete Address with Hyperzod

Deletes an existing address from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/address/delete`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Address](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-4Zo8r_efKh--Yb5UqyJSG)
