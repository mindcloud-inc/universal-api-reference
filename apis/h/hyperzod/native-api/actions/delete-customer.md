# Delete Customer with Hyperzod

Deletes an existing customer from Hyperzod.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/v1/auth/user/:id`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Customer](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-y6JfiU3Pwjiae-dQuT73V)
