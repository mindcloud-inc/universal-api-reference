# Retrieve Order with Hyperzod

Retrieves an order from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/order`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Retrieve Order](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-sWc9Fu9lKhKcpfgKZPXUx)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_id` | body | `number` | yes |
