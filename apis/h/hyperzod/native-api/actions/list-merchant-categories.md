# List Merchant Categories with Hyperzod

Retrieves a list of merchant categories from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/merchant/merchant-categories/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Merchant Categories](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-9Sx1ZjzhNJF8Yi39Dvalf)
