# Delete Product Category with Hyperzod

Deletes an existing product category from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/merchant/v1/catalog/product-category/delete`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Product Category](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-SVz3RrjDBtkusDuJ4QkYP)
