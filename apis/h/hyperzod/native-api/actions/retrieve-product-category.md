# Retrieve Product Category with Hyperzod

Retrieves a product category from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v1/catalog/product-category/view`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Retrieve Product Category](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-JQ5hMcuUbjjxFMefX858u)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
| `merchant_id` | body | `string` | yes |
