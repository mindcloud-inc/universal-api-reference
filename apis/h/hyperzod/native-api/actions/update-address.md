# Update Address with Hyperzod

Updates an existing address in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/address/update`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Update Address](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-KG0rKChyrCJA7G9fu3b_S)
