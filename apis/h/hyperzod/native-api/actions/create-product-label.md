# Create Product Label with Hyperzod

Creates a new product label in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/merchant/v1/catalog/product-label/create`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Create Product Label](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-x7XuWpAwpBT60Y4iG1yiP)
