# List Scheduled Orders with Hyperzod

Retrieves a list of scheduled orders from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/order/scheduled`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Scheduled Orders](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-OrHsa256mQFS3lktJgihe)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `merchant_id` | body | `string` | yes |
