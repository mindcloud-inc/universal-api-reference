# Retrieve Order Scheduling Slots with Hyperzod

Retrieves order scheduling slots from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/order/scheduling-slots`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Retrieve Order Scheduling Slots](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-QTyB-HCSAlDNi24wprTG7)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `merchant_id` | body | `string` | yes |
