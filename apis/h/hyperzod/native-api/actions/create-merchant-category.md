# Create Merchant Category with Hyperzod

Creates a new merchant category in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/merchant/merchant-categories/create`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Create Merchant Category](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-0Ja4wdYw4I7nhjrla7UGO)
