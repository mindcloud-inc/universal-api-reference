# Bulk Update Product Inventory with Hyperzod

Updates product inventory counts in bulk in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/merchant/v1/catalog/product/stock/updateCountBulk`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Bulk Update Product Inventory](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-pTZC-McWO7Rr2uAhvZZLY)
