# Delete Merchant Category with Hyperzod

Deletes an existing merchant category from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/merchant-categories/delete`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Merchant Category](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-1Gf9cap7ofRS0uHRQQbMk)
