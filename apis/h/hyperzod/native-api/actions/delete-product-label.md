# Delete Product Label with Hyperzod

Deletes an existing product label from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/merchant/v1/catalog/product-label/delete`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Product Label](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-F5-j1wjKz58x3AsDiYo2U)
