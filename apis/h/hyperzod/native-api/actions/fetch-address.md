# Fetch Address with Hyperzod

Retrieves an address from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/address/fetch`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Fetch Address](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-jz1N_H9B8YfTljOQQk3fU)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
