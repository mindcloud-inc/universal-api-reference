# List Merchants with Hyperzod

Retrieves a list of merchants from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/merchant/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Merchants](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-4pbBOT8J6pFZ1Sl6VcuS5)
