# Update Product Label with Hyperzod

Updates an existing product label in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/merchant/v1/catalog/product-label/update`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Update Product Label](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-oTgu4mt1AKd1aNLjvxXb3)
