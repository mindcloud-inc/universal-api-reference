# Create Merchant with Hyperzod

Creates a new merchant in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/merchant/create`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Create Merchant](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-m0a9hfOaR8z9rC5nrVTc6)
