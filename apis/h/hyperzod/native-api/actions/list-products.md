# List Products with Hyperzod

Retrieves a list of products from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v1/catalog/product/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Products](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-GNe3ocH78iV2b9SRTvjQ_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `merchant_id` | body | `string` | yes |
