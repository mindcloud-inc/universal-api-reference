# Update Merchant Category with Hyperzod

Updates an existing merchant category in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/merchant/merchant-categories/update`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Update Merchant Category](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-qabiAz0RiOTUS_iAettkK)
