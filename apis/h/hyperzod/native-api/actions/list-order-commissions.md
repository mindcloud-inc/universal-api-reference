# List Order Commissions with Hyperzod

Retrieves a list of order commissions from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/v1/order/commission`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Order Commissions](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-9ka5javifQ0-gmmWuhhh-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `type` | body | `string` | yes |
| `ref_id` | body | `string` | yes |
