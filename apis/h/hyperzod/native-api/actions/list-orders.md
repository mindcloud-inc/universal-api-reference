# List Orders with Hyperzod

Retrieves a list of orders from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/order/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Orders](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-KDJ690JUWLldCtw-_Tvic)
