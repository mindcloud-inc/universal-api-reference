# List Product Labels with Hyperzod

Retrieves a list of product labels from Hyperzod.

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v1/catalog/product-label/list`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [List Product Labels](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-vogztZSTAP4SN1hzhDPfZ)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `merchant_id` | body | `string` | yes |
