# Create Order Note with Hyperzod

Creates a new note on an order in Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/order/addNote`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Create Order Note](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-YrCGQpnkzPj9BRqyD7tqz)
