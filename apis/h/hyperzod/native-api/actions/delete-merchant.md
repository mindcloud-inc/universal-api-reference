# Delete Merchant with Hyperzod

Deletes an existing merchant from Hyperzod.

## Endpoint

- **Method:** `POST`
- **Path:** `/admin/v1/merchant/delete`
- **Base URL:** `https://api.hyperzod.app`
- **Official documentation:** [Delete Merchant](https://app.archbee.com/public/PREVIEW-TSX59B-ftH01Uoa0aU550/PREVIEW-KPhZyN7aLBWzzEqRq6_r0)
