# Get Destination with Hightouch

Retrieves a destination from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations/{destinationId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Destination](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `destinationId` | path | `number` | yes | The destination ID. |
