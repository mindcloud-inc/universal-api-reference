# Get Source with Hightouch

Retrieves a source from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/{sourceId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Source](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `number` | yes | The source ID. |
