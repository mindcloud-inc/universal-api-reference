# Get Sync Sequence Run with Hightouch

Retrieves a sync sequence run from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/sync-sequences/runs/{syncSequenceRunId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Sync Sequence Run](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `syncSequenceRunId` | path | `string` | yes | The sync sequence run ID. |
