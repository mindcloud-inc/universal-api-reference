# Get Decision Engine Flow with Hightouch

Retrieves a decision engine flow from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/decision-engine/flow/{flowId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Decision Engine Flow](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `flowId` | path | `string` | yes | The Decision Engine flow ID. |
