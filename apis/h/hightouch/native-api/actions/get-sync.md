# Get Sync with Hightouch

Retrieves a sync from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/syncs/{syncId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Sync](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `syncId` | path | `number` | yes | The sync ID. |
