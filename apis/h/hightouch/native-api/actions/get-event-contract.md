# Get Event Contract with Hightouch

Retrieves an event contract from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/contracts/{contractId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Event Contract](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contractId` | path | `string` | yes | The event contract ID. |
