# List Decision Engine Flows with Hightouch

Retrieves decision engine flows from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/decision-engine/flows`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [List Decision Engine Flows](https://api.hightouch.io/api/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Filter flows by name. |
