# List Event Contracts with Hightouch

Retrieves event contracts from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/contracts`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [List Event Contracts](https://api.hightouch.io/api/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Filter event contracts by name. |
