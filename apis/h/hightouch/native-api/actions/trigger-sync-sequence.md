# Trigger Sync Sequence with Hightouch

Triggers a sync sequence in Hightouch.

## Endpoint

- **Method:** `POST`
- **Path:** `/sync-sequences/{syncSequenceId}/trigger`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Trigger Sync Sequence](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `syncSequenceId` | path | `string` | yes | The sync sequence ID. |
