# Get Model with Hightouch

Retrieves a model from Hightouch.

## Endpoint

- **Method:** `GET`
- **Path:** `/models/{modelId}`
- **Base URL:** `https://api.hightouch.com/api/v1`
- **Official documentation:** [Get Model](https://api.hightouch.io/api/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `modelId` | path | `number` | yes | The model ID. |
