# List Short Links with Hyperise

Retrieves short links from Hyperise.

## Endpoint

- **Method:** `GET`
- **Path:** `/short-links`
- **Base URL:** `https://app.hyperise.io/api/v1/regular`
- **Official documentation:** [List Short Links](https://hyperise.customerly.help/en/articles/9434-Personalised-Short-Links-API)
