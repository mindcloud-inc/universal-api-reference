# Delete Business with Hyperise

Deletes an existing business from Hyperise.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/businesses/:businessId`
- **Base URL:** `https://app.hyperise.io/api/v1/regular`
- **Official documentation:** [Delete Business](https://hyperise.customerly.help/en/articles/9938-Prospect-Data-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `businessId` | path | `string` | yes | The Hyperise business record ID. |
