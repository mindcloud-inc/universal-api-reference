# List Image Templates with Hyperise

Retrieves image templates from Hyperise.

## Endpoint

- **Method:** `GET`
- **Path:** `/image-templates`
- **Base URL:** `https://app.hyperise.io/api/v1/regular`
- **Official documentation:** [List Image Templates](https://hyperise.customerly.help/en/articles/9935-List-Image-Templates-API)
