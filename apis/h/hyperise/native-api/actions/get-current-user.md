# Get Current User with Hyperise

Retrieves the current user from Hyperise.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/current`
- **Base URL:** `https://app.hyperise.io/api/v1/regular`
- **Official documentation:** [Get Current User](https://hyperise.customerly.help/en/articles/9940-User-Authentication-API)
