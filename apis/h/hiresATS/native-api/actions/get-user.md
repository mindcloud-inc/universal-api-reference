# Get User with 100Hires ATS

Retrieves a user from 100Hires ATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.100hires.com/v2`
- **Official documentation:** [Get User](https://100hires.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the user to retrieve. |
