# List Users with 100Hires ATS

Lists the users in 100Hires ATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.100hires.com/v2`
- **Official documentation:** [List Users](https://100hires.com/api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
