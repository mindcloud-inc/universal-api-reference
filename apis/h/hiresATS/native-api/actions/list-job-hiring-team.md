# List Job Hiring Team with 100Hires ATS

Lists a job's hiring team in 100Hires ATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:id/hiring-team`
- **Base URL:** `https://api.100hires.com/v2`
- **Official documentation:** [List Job Hiring Team](https://100hires.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Job ID or alias whose hiring team to retrieve. |
