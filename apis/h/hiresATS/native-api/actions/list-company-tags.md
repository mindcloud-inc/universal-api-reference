# List Company Tags with 100Hires ATS

Lists the company tags in 100Hires ATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.100hires.com/v2`
- **Official documentation:** [List Company Tags](https://100hires.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | query | `number` | no | Optional target company ID. Defaults to the authenticated company. |
