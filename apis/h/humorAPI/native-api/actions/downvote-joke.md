# Downvote Joke with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/jokes/:id/downvote`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Downvote Joke](https://humorapi.com/docs/#Downvote-Joke)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | ID of the joke to downvote. |
