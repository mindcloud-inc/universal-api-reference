# Analyze Joke with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/jokes/analyze`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Analyze Joke](https://humorapi.com/docs/#Analyze-Joke)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jokeText` | body | `string` | no | The joke text to analyze. |
