# Downvote Meme with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/memes/{id}/downvote`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Downvote Meme](https://humorapi.com/docs/#Downvote-Meme)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | ID of the meme to downvote. |
