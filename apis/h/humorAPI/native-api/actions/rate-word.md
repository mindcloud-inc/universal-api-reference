# Rate Word with Humor API

## Endpoint

- **Method:** `GET`
- **Path:** `/words/rate`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Rate Word](https://humorapi.com/docs/#Rate-Word)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `word` | query | `string` | no | Word to rate by funniness. |
