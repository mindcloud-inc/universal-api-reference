# Insult with Humor API

## Endpoint

- **Method:** `GET`
- **Path:** `/insult`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Insult](https://humorapi.com/docs/#Insult)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Name of the person to insult. |
| `reason` | query | `string` | no | Reason the person is insulted for. |
