# Search Gifs with Humor API

## Endpoint

- **Method:** `GET`
- **Path:** `/gif/search`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Search Gifs](https://humorapi.com/docs/#Search-Gifs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | no | Search query for matching GIFs. |
