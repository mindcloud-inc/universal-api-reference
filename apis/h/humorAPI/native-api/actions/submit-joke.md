# Submit Joke with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/jokes`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Submit Joke](https://humorapi.com/docs/#Submit-Joke)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jokeText` | body | `string` | no | The joke text to submit. |
