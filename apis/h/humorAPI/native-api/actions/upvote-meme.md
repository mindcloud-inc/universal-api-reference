# Upvote Meme with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/memes/:id/upvote`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Upvote Meme](https://humorapi.com/docs/#Upvote-Meme)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | ID of the meme to upvote. |
