# Praise with Humor API

## Endpoint

- **Method:** `GET`
- **Path:** `/praise`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Praise](https://humorapi.com/docs/#Praise)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Name of the person to praise. |
| `reason` | query | `string` | no | Reason the person is praised for. |
