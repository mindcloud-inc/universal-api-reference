# Upvote Joke with Humor API

## Endpoint

- **Method:** `POST`
- **Path:** `/jokes/:id/upvote`
- **Base URL:** `https://api.humorapi.com`
- **Official documentation:** [Upvote Joke](https://humorapi.com/docs/#Upvote-Joke)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | ID of the joke to upvote. |
