# Get New Story IDs with Hacker News

Retrieves new story IDs from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/newstories.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get New Story IDs](https://github.com/HackerNews/API#new-top-and-best-stories)
