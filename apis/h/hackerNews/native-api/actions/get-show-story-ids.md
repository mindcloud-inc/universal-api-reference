# Get Show Story IDs with Hacker News

Retrieves Show HN story IDs from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/showstories.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get Show Story IDs](https://github.com/HackerNews/API#ask-show-and-job-stories)
