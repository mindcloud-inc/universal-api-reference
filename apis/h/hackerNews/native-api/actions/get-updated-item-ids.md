# Get Updated Item IDs with Hacker News

Retrieves updated item IDs from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/updates/items.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get Updated Item IDs](https://github.com/HackerNews/API#changed-items-and-profiles)
