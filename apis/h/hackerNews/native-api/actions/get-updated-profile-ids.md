# Get Updated Profile IDs with Hacker News

Retrieves updated profile IDs from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/updates/profiles.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get Updated Profile IDs](https://github.com/HackerNews/API#changed-items-and-profiles)
