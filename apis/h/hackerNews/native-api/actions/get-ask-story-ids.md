# Get Ask Story IDs with Hacker News

Retrieves Ask HN story IDs from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/askstories.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get Ask Story IDs](https://github.com/HackerNews/API#ask-show-and-job-stories)
