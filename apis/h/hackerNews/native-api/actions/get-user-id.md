# Get User ID with Hacker News

Retrieves a user ID from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:id/id.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get User ID](https://github.com/HackerNews/API#users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Hacker News user ID. |
