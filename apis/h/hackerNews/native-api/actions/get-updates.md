# Get Updates with Hacker News

Retrieves item and profile updates from Hacker News.

## Endpoint

- **Method:** `GET`
- **Path:** `/updates.json`
- **Base URL:** `https://hacker-news.firebaseio.com/v0`
- **Official documentation:** [Get Updates](https://github.com/HackerNews/API#changed-items-and-profiles)
