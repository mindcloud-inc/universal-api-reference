# List Products with Quaderno

Retrieves product records from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/items`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [List Products](https://developers.quaderno.io/api/#tag/Products/operation/listProducts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Filter products by product name or code. |
