# List Tax IDs with Quaderno

Retrieves registered tax IDs from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/tax_ids`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [List Tax IDs](https://developers.quaderno.io/api/#tag/Registered-Jurisdictions/operation/listTaxIDs)
