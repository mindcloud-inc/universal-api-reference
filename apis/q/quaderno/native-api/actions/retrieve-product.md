# Retrieve Product with Quaderno

Retrieves a product record from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:id`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [Retrieve Product](https://developers.quaderno.io/api/#tag/Products/operation/retrieveProduct)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the desired product. |
