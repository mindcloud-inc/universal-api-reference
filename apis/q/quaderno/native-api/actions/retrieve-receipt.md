# Retrieve Receipt with Quaderno

Retrieves a receipt from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/:id`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [Retrieve Receipt](https://developers.quaderno.io/api/#tag/Receipts/operation/retrieveReceipt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the desired receipt. |
