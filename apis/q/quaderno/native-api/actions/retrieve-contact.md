# Retrieve Contact with Quaderno

Retrieves a contact record from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [Retrieve Contact](https://developers.quaderno.io/api/#tag/Contacts/operation/retrieveContact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the desired contact. |
