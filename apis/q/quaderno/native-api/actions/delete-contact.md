# Delete Contact with Quaderno

Deletes an existing contact from Quaderno.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [Delete Contact](https://developers.quaderno.io/api/#tag/Contacts/operation/deleteContact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the contact to delete. |
