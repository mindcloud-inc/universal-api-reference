# Retrieve Invoice with Quaderno

Retrieves an invoice from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [Retrieve Invoice](https://developers.quaderno.io/api/#tag/Invoices/operation/retrieveInvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the desired invoice. |
