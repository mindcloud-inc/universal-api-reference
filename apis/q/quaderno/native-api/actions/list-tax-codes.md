# List Tax Codes with Quaderno

Retrieves supported tax codes from Quaderno.

## Endpoint

- **Method:** `GET`
- **Path:** `/tax_codes`
- **Base URL:** `https://sandbox-quadernoapp.com/api`
- **Official documentation:** [List Tax Codes](https://developers.quaderno.io/api/#tag/Tax-Codes/operation/listTaxCodes)
