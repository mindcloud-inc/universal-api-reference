# Delete Task with Quire

Deletes an existing task from Quire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `task/:oid`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [Delete Task](https://quire.io/dev/api/#operation--task--oid--delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `oid` | path | `string` | yes | The Quire task OID. |
