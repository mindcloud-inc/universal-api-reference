# Get Tag with Quire

Retrieves a tag from Quire.

## Endpoint

- **Method:** `GET`
- **Path:** `tag/:oid`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [Get Tag](https://quire.io/dev/api/#operation--tag--oid--get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `oid` | path | `string` | yes | The Quire tag OID. |
