# Delete Tag with Quire

Deletes an existing tag from Quire.

## Endpoint

- **Method:** `DELETE`
- **Path:** `tag/:oid`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [Delete Tag](https://quire.io/dev/api/#operation--tag--oid--delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `oid` | path | `string` | yes | The Quire tag OID. |
