# List Statuses with Quire

Retrieves statuses from a Quire project.

## Endpoint

- **Method:** `GET`
- **Path:** `status/list/id/:projectId`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [List Statuses](https://quire.io/dev/api/#operation--status-list-id--projectId--get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID. |
