# Get Project with Quire

Retrieves a project from Quire.

## Endpoint

- **Method:** `GET`
- **Path:** `project/id/:id`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [Get Project](https://quire.io/dev/api/#operation--project-id--id--get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project ID. |
