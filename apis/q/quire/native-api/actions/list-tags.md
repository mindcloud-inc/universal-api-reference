# List Tags with Quire

Retrieves tags from a Quire project.

## Endpoint

- **Method:** `GET`
- **Path:** `tag/list/:projectOid`
- **Base URL:** `https://quire.io/api`
- **Official documentation:** [List Tags](https://quire.io/dev/api/#operation--tag-list--projectOid--get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectOid` | path | `string` | yes | The project OID, for example 0N~8HZT-lM-DQSzj7mkvmhfN. |
