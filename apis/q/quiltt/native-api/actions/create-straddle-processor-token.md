# Create Straddle Processor Token with Quiltt

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/accounts/:accountId/processor_tokens`
- **Base URL:** `https://api.quiltt.io`
- **Official documentation:** [Create Straddle Processor Token](https://www.quiltt.dev/integrations/payments/straddle)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Quiltt account ID. |
