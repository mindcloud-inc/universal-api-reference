# Delete All Records with QuintaDB

Deletes all records from a QuintaDB form.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dtypes/:app_id/delete_all/:entity_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Delete All Records](https://quintadb.com/api/index#delete_all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
| `entity_id` | path | `string` | yes |
