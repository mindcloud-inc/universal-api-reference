# Get Form with QuintaDB

Retrieves a form from QuintaDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_id/entities/:entity_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Form](https://quintadb.com/api/index#get_form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
| `entity_id` | path | `string` | yes |
