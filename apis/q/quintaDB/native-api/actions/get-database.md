# Get Database with QuintaDB

Retrieves a database from QuintaDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Database](https://quintadb.com/api/index#get_database)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
