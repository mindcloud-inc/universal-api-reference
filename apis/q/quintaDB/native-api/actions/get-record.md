# Get Record with QuintaDB

Retrieves a record from QuintaDB by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_id/dtypes/:dtype_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Record](https://quintadb.com/api/index#get_record)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
| `dtype_id` | path | `string` | yes |
