# List Forms with QuintaDB

Retrieves all forms from a QuintaDB database.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_id/entities.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [List Forms](https://quintadb.com/api/index#get_forms)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
