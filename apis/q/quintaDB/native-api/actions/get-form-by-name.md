# Get Form By Name with QuintaDB

Finds a form in QuintaDB by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/search/entities/search.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Form By Name](https://quintadb.com/api/index#get_form_by_name)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `database_name` | query | `string` | yes |
| `form_name` | query | `string` | yes |
