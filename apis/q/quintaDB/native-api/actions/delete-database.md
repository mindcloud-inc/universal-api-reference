# Delete Database with QuintaDB

Deletes an existing database from QuintaDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/:app_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Delete Database](https://quintadb.com/api/index#delete_database)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | path | `string` | yes | Identifier of the QuintaDB database to delete. |
