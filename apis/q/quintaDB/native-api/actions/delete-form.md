# Delete Form with QuintaDB

Deletes an existing form from QuintaDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/:app_id/entities/:entity_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Delete Form](https://quintadb.com/api/index#delete_form)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
| `entity_id` | path | `string` | yes |
