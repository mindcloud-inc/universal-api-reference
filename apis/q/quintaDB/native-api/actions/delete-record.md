# Delete Record with QuintaDB

Deletes an existing record from QuintaDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/apps/:app_id/dtypes/:dtype_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Delete Record](https://quintadb.com/api/index#delete_record)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `app_id` | path | `string` | yes |
| `dtype_id` | path | `string` | yes |
