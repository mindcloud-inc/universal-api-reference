# Get Relation Field ID with QuintaDB

Retrieves a relation field ID from QuintaDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entity_id/get_rel_id/:property_id.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Relation Field ID](https://quintadb.com/api/index#rels)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_id` | path | `string` | yes |
| `property_id` | path | `string` | yes |
