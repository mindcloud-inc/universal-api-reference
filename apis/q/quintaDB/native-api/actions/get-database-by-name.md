# Get Database By Name with QuintaDB

Finds a database in QuintaDB by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/search.json`
- **Base URL:** `https://quintadb.com`
- **Official documentation:** [Get Database By Name](https://quintadb.com/api/index#get_database_by_name)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | yes |
