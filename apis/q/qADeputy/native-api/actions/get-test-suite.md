# Get Test Suite with QADeputy

Retrieves a test suite from QADeputy.

## Endpoint

- **Method:** `GET`
- **Path:** `/test-suites/:testSuiteId`
- **Base URL:** `https://app.qadeputy.com/api/v1`
- **Official documentation:** [Get Test Suite](https://apidocs.qadeputy.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `testSuiteId` | path | `number` | yes | Required QADeputy test_suite_id. |
