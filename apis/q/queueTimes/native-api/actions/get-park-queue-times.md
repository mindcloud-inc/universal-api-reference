# Get Park Queue Times with Queue Times

## Endpoint

- **Method:** `GET`
- **Path:** `/parks/:id/queue_times.json`
- **Base URL:** `https://queue-times.com`
- **Official documentation:** [Get Park Queue Times](https://queue-times.com/pages/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric park ID. |
