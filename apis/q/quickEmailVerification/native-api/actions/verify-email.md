# Verify Email with QuickEmailVerification

Retrieves an email verification result from QuickEmailVerification.

## Endpoint

- **Method:** `GET`
- **Path:** `/verify`
- **Base URL:** `https://api.quickemailverification.com/v1`
- **Official documentation:** [Verify Email](https://docs.quickemailverification.com/email-verification-api/verify-an-email-address)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to verify. |
