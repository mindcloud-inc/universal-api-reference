# Get Item with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/item/:itemId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Item](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/item#read-an-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | yes | QuickBooks Item Id. |
| `query` | query | `string` | no | — |
