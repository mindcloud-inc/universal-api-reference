# Get Purchase Order with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/purchaseorder/:purchaseOrderId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Purchase Order](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/purchaseorder#read-a-purchaseorder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchaseOrderId` | path | `string` | yes | QuickBooks PurchaseOrder Id. |
