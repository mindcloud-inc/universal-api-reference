# Get Invoice with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice/:invoiceId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Invoice](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/invoice#read-an-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | path | `string` | yes | QuickBooks Invoice Id. |
