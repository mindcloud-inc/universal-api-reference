# List Budgets with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/query`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [List Budgets](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/budget)

## Capabilities

This operation supports [pagination](../README.md#pagination).
