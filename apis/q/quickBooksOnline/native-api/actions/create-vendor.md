# Create Vendor with QuickBooks Online

## Endpoint

- **Method:** `POST`
- **Path:** `/vendor`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Create Vendor](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/vendor#create-a-vendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `DisplayName` | body | `string` | yes | Vendor display name. |
