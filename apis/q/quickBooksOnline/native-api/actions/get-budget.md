# Get Budget with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/budget/:budgetId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Budget](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/budget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `budgetId` | path | `string` | yes | QuickBooks budget ID. |
