# Get Bill with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/bill/:billId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Bill](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/bill#read-a-bill)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `billId` | path | `string` | yes | QuickBooks Bill Id. |
