# Get Vendor with QuickBooks Online

## Endpoint

- **Method:** `GET`
- **Path:** `/vendor/:vendorId`
- **Base URL:** `https://:quickbooksEnvironment/v3/company/:realmId`
- **Official documentation:** [Get Vendor](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/vendor#read-a-vendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vendorId` | path | `string` | yes | QuickBooks Vendor Id. |
