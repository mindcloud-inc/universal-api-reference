# Get Product with Quizell

Retrieves a product from Quizell by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id/show`
- **Base URL:** `https://api.quizell.com/api/v1`
- **Official documentation:** [Get Product](https://docs.quizell.com/product-apis#get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | path | `number` | yes | The ID of the product to retrieve. |
