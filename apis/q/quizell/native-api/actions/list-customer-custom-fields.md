# List Customer Custom Fields with Quizell

Retrieves customer custom fields from Quizell.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/custom_fields/list`
- **Base URL:** `https://api.quizell.com/api/v1`
- **Official documentation:** [List Customer Custom Fields](https://docs.quizell.com/customer-apis#customers-custom-fields-list)
