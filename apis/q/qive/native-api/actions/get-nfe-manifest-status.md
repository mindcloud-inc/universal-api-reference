# Get NFe Manifest Status with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfe/manifest/status`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get NFe Manifest Status](https://developers.qive.com.br/docs/get/v1/nfe/manifest/status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_key[]` | query | `string` | no | NFe access keys to check manifest status for. |
| `request_id[]` | query | `string` | no | Manifest request IDs to check status for. |
