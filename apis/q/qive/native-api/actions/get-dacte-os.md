# Get DACTe-OS with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cte-os/dacteos`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get DACTe-OS](https://developers.qive.com.br/docs/get/v1/cte-os/dacteos)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_key` | query | `string` | yes | CTe-OS access key for the DACTe-OS PDF. |
