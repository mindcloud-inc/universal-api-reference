# Get DANFSe with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfse/danfse`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get DANFSe](https://developers.qive.com.br/docs/get/v1/nfse/danfse)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | NFSe identifier for the DANFSe PDF. |
