# Get CTe Upload Status with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cte/upload/status`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get CTe Upload Status](https://developers.qive.com.br/docs/get/v1/cte/upload/status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | query | `string` | yes | Upload request ID returned by the CTe upload endpoint. |
