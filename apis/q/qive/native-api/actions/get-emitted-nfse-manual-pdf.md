# Get Emitted NFSe Manual PDF with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfse/emitted/manual/pdf`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get Emitted NFSe Manual PDF](https://developers.qive.com.br/docs/get/v1/nfse/emitted/manual/pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | NFSe identifier for the original emitted manual PDF. |
| `cnpj` | query | `string` | yes | Owner CNPJ for the original emitted manual PDF. |
