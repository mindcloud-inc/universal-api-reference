# Get DACTe with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cte/dacte`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get DACTe](https://developers.qive.com.br/docs/get/v1/cte/dacte)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_key` | query | `string` | yes | CTe access key for the DACTe PDF. |
