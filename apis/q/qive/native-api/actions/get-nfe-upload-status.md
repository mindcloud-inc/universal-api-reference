# Get NFe Upload Status with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfe/upload/status`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get NFe Upload Status](https://developers.qive.com.br/docs/get/v1/nfe/upload/status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | query | `string` | yes | Upload request ID returned by the NFe upload endpoint. |
