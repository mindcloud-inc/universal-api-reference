# List CTe-OS Events with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cte-os/events`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [List CTe-OS Events](https://developers.qive.com.br/docs/get/v1/cte-os/events)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_key` | query | `string` | yes | CTe-OS access key whose events should be returned. |
