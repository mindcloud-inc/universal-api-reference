# Get DANFe with Qive

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/nfe/danfe`
- **Base URL:** `https://sandbox-api.arquivei.com.br`
- **Official documentation:** [Get DANFe](https://developers.qive.com.br/docs/get/v1/nfe/danfe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_key` | query | `string` | yes | NFe access key for the DANFe PDF. |
