# Get Invoice with QuickFile

## Endpoint

- **Method:** `POST`
- **Path:** `/invoice/get`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [Get Invoice](https://api.quickfile.co.uk/d/v1_2/Invoice_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `InvoiceID` | body | `number` | yes | The QuickFile InvoiceID to retrieve. |
