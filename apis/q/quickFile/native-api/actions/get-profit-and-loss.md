# Get Profit And Loss with QuickFile

- **Method:** `POST`
- **Path:** `/report/profitandloss`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [Get Profit And Loss](https://api.quickfile.co.uk/d/v1_2/Report_ProfitAndLoss)
