# List Payment Methods with QuickFile

## Endpoint

- **Method:** `POST`
- **Path:** `/payment/getpaymethods`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [List Payment Methods](https://api.quickfile.co.uk/d/v1_2/Payment_GetPayMethods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `IncludeIconPaths` | body | `boolean` | no | Include QuickFile icon image paths in the returned payment method records. |
