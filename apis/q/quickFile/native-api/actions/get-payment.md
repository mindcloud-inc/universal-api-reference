# Get Payment with QuickFile

## Endpoint

- **Method:** `POST`
- **Path:** `/payment/get`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [Get Payment](https://api.quickfile.co.uk/d/v1_2/Payment_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PaymentID` | body | `number` | yes | The QuickFile PaymentID to retrieve. |
