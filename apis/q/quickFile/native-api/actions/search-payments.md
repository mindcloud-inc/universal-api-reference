# Search Payments with QuickFile

## Endpoint

- **Method:** `POST`
- **Path:** `/payment/search`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [Search Payments](https://api.quickfile.co.uk/d/v1_2/Payment_Search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ReturnCount` | body | `number` | no |
| `Offset` | body | `number` | no |
| `DateFrom` | body | `date` | no |
| `DateTo` | body | `date` | no |
