# Get Journal with QuickFile

## Endpoint

- **Method:** `POST`
- **Path:** `/journal/get`
- **Base URL:** `https://api.quickfile.co.uk/1_2`
- **Official documentation:** [Get Journal](https://api.quickfile.co.uk/d/v1_2/Journal_Get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `JournalReference` | body | `string` | yes | The QuickFile journal reference to retrieve. |
