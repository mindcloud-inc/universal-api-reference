# Get Appointment with Quilia

## Endpoint

- **Method:** `GET`
- **Path:** `appointments/:id`
- **Base URL:** `https://api.quilia.dev/v2`
- **Official documentation:** [Get Appointment](https://api.quilia.dev/v2#tag/appointments/GET/appointments/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the appointment to retrieve |
