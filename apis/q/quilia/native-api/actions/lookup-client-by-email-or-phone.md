# Lookup Client By Email Or Phone with Quilia

## Endpoint

- **Method:** `GET`
- **Path:** `clients/lookup`
- **Base URL:** `https://api.quilia.dev/v2`
- **Official documentation:** [Lookup Client By Email Or Phone](https://api.quilia.dev/v2#tag/clients/GET/clients/lookup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Client email address |
| `phone` | query | `string` | no | Client phone number |
