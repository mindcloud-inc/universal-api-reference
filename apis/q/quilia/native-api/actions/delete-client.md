# Delete Client with Quilia

## Endpoint

- **Method:** `DELETE`
- **Path:** `clients/:id`
- **Base URL:** `https://api.quilia.dev/v2`
- **Official documentation:** [Delete Client](https://api.quilia.dev/v2#tag/clients/DELETE/clients/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the client to delete |
