# Get Case with Quilia

## Endpoint

- **Method:** `GET`
- **Path:** `cases/:id`
- **Base URL:** `https://api.quilia.dev/v2`
- **Official documentation:** [Get Case](https://api.quilia.dev/v2#tag/cases/GET/cases/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the case to retrieve |
