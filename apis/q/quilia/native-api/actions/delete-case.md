# Delete Case with Quilia

## Endpoint

- **Method:** `DELETE`
- **Path:** `cases/:id`
- **Base URL:** `https://api.quilia.dev/v2`
- **Official documentation:** [Delete Case](https://api.quilia.dev/v2#tag/cases/DELETE/cases/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier of the case to delete |
