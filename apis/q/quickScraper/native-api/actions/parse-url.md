# Parse URL with Quick Scraper

Retrieves scraped page content from Quick Scraper.

## Endpoint

- **Method:** `GET`
- **Path:** `/parse`
- **Base URL:** `https://api.quickscraper.co`
- **Official documentation:** [Parse URL](https://quickscraper.co/docs/#basic-usage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The public page URL Quick Scraper should fetch and return. |
