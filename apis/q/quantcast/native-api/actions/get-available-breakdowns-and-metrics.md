# Get Available Breakdowns And Metrics with Quantcast

Retrieves available breakdowns and metrics from Quantcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/graphql`
- **Base URL:** `https://developers.quantcast.com`
- **Official documentation:** [Get Available Breakdowns And Metrics](https://developers.quantcast.com/docs/graphql-api/reference/queries/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | body | `number` | yes | Quantcast account ID to inspect. |
