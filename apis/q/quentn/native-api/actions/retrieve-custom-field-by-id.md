# Retrieve Custom Field by ID with Quentn

## Endpoint

- **Method:** `GET`
- **Path:** `/custom-fields/:field_id`
- **Base URL:** `https://tbg6y3.us-1.quentn.com/public/api/v1`
- **Official documentation:** [Retrieve Custom Field by ID](https://help.quentn.com/hc/en-150/articles/4518070370577-Custom-fields-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | path | `number` | yes | The numeric Quentn custom field id to retrieve. |
