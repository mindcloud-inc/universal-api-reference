# List Contact Terms with Quentn

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:contact_id/terms`
- **Base URL:** `https://tbg6y3.us-1.quentn.com/public/api/v1`
- **Official documentation:** [List Contact Terms](https://help.quentn.com/hc/en-150/articles/4517835330961-Contact-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `number` | yes | The numeric Quentn contact id whose terms you want to list. |
