# Retrieve Contacts by Mail with Quentn

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:contact_mail`
- **Base URL:** `https://tbg6y3.us-1.quentn.com/public/api/v1`
- **Official documentation:** [Retrieve Contacts by Mail](https://help.quentn.com/hc/en-150/articles/4517835330961-Contact-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_mail` | path | `string` | yes | The contact email address to look up in Quentn. |
