# Retrieve Email with Quentn

## Endpoint

- **Method:** `GET`
- **Path:** `/mail/:email_id`
- **Base URL:** `https://tbg6y3.us-1.quentn.com/public/api/v1`
- **Official documentation:** [Retrieve Email](https://help.quentn.com/hc/en-150/articles/4518209942289-Mail-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email_id` | path | `number` | yes | The numeric Quentn email id to retrieve. |
