# Get Survey Block with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `surveys/:surveyId/blocks/:blockId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Survey Block](https://www.questionpro.com/api/get-survey-block.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The QuestionPro survey ID. |
| `blockId` | path | `number` | yes | The QuestionPro survey block ID. |
