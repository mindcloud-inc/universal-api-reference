# Get Image with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `images/:imageId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Image](https://www.questionpro.com/api/get-image.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageId` | path | `number` | yes | The QuestionPro image ID. |
