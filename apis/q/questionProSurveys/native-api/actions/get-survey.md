# Get Survey with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `surveys/:surveyId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Survey](https://www.questionpro.com/api/get-survey.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The QuestionPro survey ID. |
