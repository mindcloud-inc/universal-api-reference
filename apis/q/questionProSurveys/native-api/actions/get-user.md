# Get User with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get User](https://www.questionpro.com/api/get-user.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | The QuestionPro user ID. |
