# Get Folders with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId/folders`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Folders](https://www.questionpro.com/api/get-folders.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | The QuestionPro user ID. |
