# Get User Image with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId/images/:imageId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get User Image](https://www.questionpro.com/api/get-user-image.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | QuestionPro user ID. |
| `imageId` | path | `number` | yes | QuestionPro image ID. |
