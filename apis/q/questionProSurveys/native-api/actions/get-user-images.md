# Get User Images with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `users/:userId/images`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get User Images](https://www.questionpro.com/api/get-user-images.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | QuestionPro user ID. |
