# Get Survey Statistics with QuestionPro Surveys

## Endpoint

- **Method:** `POST`
- **Path:** `surveys/:surveyId/analytics`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Survey Statistics](https://www.questionpro.com/api/get-survey-statistics.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The QuestionPro survey ID. |
