# Get Survey Blocks with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `surveys/:surveyId/blocks`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Survey Blocks](https://www.questionpro.com/api/get-survey-blocks.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `surveyId` | path | `number` | yes | The QuestionPro survey ID. |
