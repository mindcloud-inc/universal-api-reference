# Get Organization with QuestionPro Surveys

## Endpoint

- **Method:** `GET`
- **Path:** `organizations/:organizationId`
- **Base URL:** `https://api.questionpro.com/a/api/v2`
- **Official documentation:** [Get Organization](https://www.questionpro.com/api/get-organization.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `number` | yes | The QuestionPro organization ID. |
