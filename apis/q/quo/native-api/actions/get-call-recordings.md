# Get Call Recordings with Quo

Retrieves recordings for a Quo call.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-recordings/:callId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Call Recordings](https://www.quo.com/docs/mdx/api-reference/calls/get-recordings-for-a-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
