# Delete Contact with Quo

Deletes an existing contact from Quo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Delete Contact](https://www.quo.com/docs/mdx/api-reference/contacts/delete-a-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
