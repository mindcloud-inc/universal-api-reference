# Get Message By ID with Quo

Retrieves a message from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Message By ID](https://www.quo.com/docs/mdx/api-reference/messages/get-a-message-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
