# Get Contact By ID with Quo

Retrieves a contact from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Contact By ID](https://www.quo.com/docs/mdx/api-reference/contacts/get-a-contact-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
