# Get Call Voicemail with Quo

Retrieves a voicemail for a Quo call.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-voicemails/:callId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Call Voicemail](https://www.quo.com/docs/mdx/api-reference/calls/get-a-voicemail-for-a-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
