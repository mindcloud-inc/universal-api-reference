# Get Call By ID with Quo

Retrieves a call from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:callId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Call By ID](https://www.quo.com/docs/mdx/api-reference/calls/get-a-call-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
