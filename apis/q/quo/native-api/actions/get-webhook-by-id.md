# Get Webhook By ID with Quo

Retrieves a webhook from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Webhook By ID](https://www.quo.com/docs/mdx/api-reference/webhooks/get-a-webhook-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
