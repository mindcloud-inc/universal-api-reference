# List Phone Numbers with Quo

Retrieves all phone numbers from Quo.

## Endpoint

- **Method:** `GET`
- **Path:** `/phone-numbers`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [List Phone Numbers](https://www.quo.com/docs/mdx/api-reference/phone-numbers/list-phone-numbers)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | query | `string` | no |
