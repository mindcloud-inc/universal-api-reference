# List Users with Quo

Retrieves all users from Quo.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [List Users](https://www.quo.com/docs/mdx/api-reference/users/list-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
