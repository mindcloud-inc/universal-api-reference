# Get Call Summary with Quo

Retrieves a summary for a Quo call.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-summaries/:callId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Call Summary](https://www.quo.com/docs/mdx/api-reference/calls/get-a-summary-for-a-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `callId` | path | `string` | yes |
