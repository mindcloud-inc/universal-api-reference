# Get Call Transcript with Quo

Retrieves a transcription for a Quo call.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-transcripts/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Call Transcript](https://www.quo.com/docs/mdx/api-reference/calls/get-a-transcription-for-a-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
