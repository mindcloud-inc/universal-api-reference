# Delete Webhook By ID with Quo

Deletes an existing webhook from Quo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Delete Webhook By ID](https://www.quo.com/docs/mdx/api-reference/webhooks/delete-a-webhook-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
