# Get Contact Custom Fields with Quo

Retrieves contact custom fields from Quo.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact-custom-fields`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Contact Custom Fields](https://www.quo.com/docs/mdx/api-reference/contact-custom-fields/get-contact-custom-fields)
