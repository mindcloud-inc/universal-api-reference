# Get User By ID with Quo

Retrieves a user from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get User By ID](https://www.quo.com/docs/mdx/api-reference/users/get-a-user-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
