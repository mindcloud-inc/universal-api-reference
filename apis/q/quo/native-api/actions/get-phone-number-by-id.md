# Get Phone Number By ID with Quo

Retrieves a phone number from Quo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/phone-numbers/:phoneNumberId`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [Get Phone Number By ID](https://www.quo.com/docs/mdx/api-reference/phone-numbers/get-a-phone-number-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phoneNumberId` | path | `string` | yes |
