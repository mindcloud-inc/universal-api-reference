# List Webhooks with Quo

Retrieves all webhooks from Quo.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.openphone.com/v1`
- **Official documentation:** [List Webhooks](https://www.quo.com/docs/mdx/api-reference/webhooks/lists-all-webhooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | query | `string` | no |
