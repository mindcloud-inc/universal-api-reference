# Delete Task with Queue

Deletes an existing task from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `tasks/:task_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Task](https://docs.usequeue.com/api-reference/tasks/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
