# Get Invoice with Queue

Retrieves an invoice from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `invoices/:invoice_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Invoice](https://docs.usequeue.com/api-reference/invoices/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes |
