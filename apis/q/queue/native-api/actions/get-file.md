# Get File with Queue

Retrieves a file from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `files/:file_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get File](https://docs.usequeue.com/api-reference/files/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
