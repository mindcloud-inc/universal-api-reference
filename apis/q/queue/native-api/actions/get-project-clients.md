# Get Project Clients with Queue

Retrieves clients for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/clients`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Clients](https://docs.usequeue.com/api-reference/clients/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
