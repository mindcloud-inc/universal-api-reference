# Delete Project with Queue

Deletes an existing project from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:project_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Project](https://docs.usequeue.com/api-reference/projects/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
