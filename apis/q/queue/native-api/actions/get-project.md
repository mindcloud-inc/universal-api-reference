# Get Project with Queue

Retrieves a project from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project](https://docs.usequeue.com/api-reference/projects/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
