# Get Project Invoices with Queue

Retrieves invoices for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/invoices`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Invoices](https://docs.usequeue.com/api-reference/invoices/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
