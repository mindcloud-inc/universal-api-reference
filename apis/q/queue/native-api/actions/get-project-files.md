# Get Project Files with Queue

Retrieves files for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/files`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Files](https://docs.usequeue.com/api-reference/files/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
