# Get Project Service Checkouts with Queue

Retrieves service checkouts for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/service_checkouts`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Service Checkouts](https://docs.usequeue.com/api-reference/service_checkouts/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
