# Get Client with Queue

Retrieves a client from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `clients/:client_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Client](https://docs.usequeue.com/api-reference/clients/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `client_id` | path | `string` | yes |
