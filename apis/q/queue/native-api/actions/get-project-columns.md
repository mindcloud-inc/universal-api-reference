# Get Project Columns with Queue

Retrieves columns for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/columns`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Columns](https://docs.usequeue.com/api-reference/columns/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Required path parameter from projects/:project_id/columns. |
