# Create Project Client with Queue

Creates a new client for a Queue project.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:project_id/clients`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Create Project Client](https://docs.usequeue.com/api-reference/clients/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
