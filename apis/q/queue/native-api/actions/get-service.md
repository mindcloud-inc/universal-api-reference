# Get Service with Queue

Retrieves a service from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `services/:service_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Service](https://docs.usequeue.com/api-reference/services/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `service_id` | path | `string` | yes |
