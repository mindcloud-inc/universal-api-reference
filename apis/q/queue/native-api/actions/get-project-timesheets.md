# Get Project Timesheets with Queue

Retrieves timesheets for a Queue project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:project_id/timesheets`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Project Timesheets](https://docs.usequeue.com/api-reference/timesheets/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
