# Delete Column with Queue

Deletes an existing column from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `columns/:column_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Column](https://docs.usequeue.com/api-reference/columns/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `column_id` | path | `string` | yes | Required path parameter from columns/:column_id. |
