# Delete Invoice with Queue

Deletes an existing invoice from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `invoices/:invoice_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Invoice](https://docs.usequeue.com/api-reference/invoices/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes |
