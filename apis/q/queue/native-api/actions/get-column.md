# Get Column with Queue

Retrieves a column from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `columns/:column_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Column](https://docs.usequeue.com/api-reference/columns/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `column_id` | path | `string` | yes |
