# Pause Service Checkout with Queue

Pauses a service checkout subscription in Queue.

## Endpoint

- **Method:** `POST`
- **Path:** `service_checkouts/:service_checkout_id/pause`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Pause Service Checkout](https://docs.usequeue.com/api-reference/service_checkouts/pause)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `service_checkout_id` | path | `string` | yes |
