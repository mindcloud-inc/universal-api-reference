# Delete File with Queue

Deletes an existing file from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `files/:file_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete File](https://docs.usequeue.com/api-reference/files/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file_id` | path | `string` | yes |
