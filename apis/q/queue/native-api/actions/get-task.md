# Get Task with Queue

Retrieves a task from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `tasks/:task_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Task](https://docs.usequeue.com/api-reference/tasks/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
