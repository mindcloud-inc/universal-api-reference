# Update Invoice with Queue

Updates an existing invoice in Queue.

## Endpoint

- **Method:** `PATCH`
- **Path:** `invoices/:invoice_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Update Invoice](https://docs.usequeue.com/api-reference/invoices/put)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes |
