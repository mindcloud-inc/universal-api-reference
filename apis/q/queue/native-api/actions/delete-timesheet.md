# Delete Timesheet with Queue

Deletes an existing timesheet from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `timesheets/:timesheet_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Timesheet](https://docs.usequeue.com/api-reference/timesheets/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timesheet_id` | path | `string` | yes |
