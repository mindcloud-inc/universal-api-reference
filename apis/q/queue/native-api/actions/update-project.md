# Update Project with Queue

Updates an existing project in Queue.

## Endpoint

- **Method:** `PATCH`
- **Path:** `projects/:project_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Update Project](https://docs.usequeue.com/api-reference/projects/put)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
| `title` | query | `string` | no |
