# Get Service Checkout with Queue

Retrieves a service checkout from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `service_checkouts/:service_checkout_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Service Checkout](https://docs.usequeue.com/api-reference/service_checkouts/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `service_checkout_id` | path | `string` | yes |
