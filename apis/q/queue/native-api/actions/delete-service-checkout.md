# Delete Service Checkout with Queue

Deletes an existing service checkout from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `service_checkouts/:service_checkout_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Service Checkout](https://docs.usequeue.com/api-reference/service_checkouts/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `service_checkout_id` | path | `string` | yes |
