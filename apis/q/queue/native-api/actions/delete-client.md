# Delete Client with Queue

Deletes an existing client from Queue.

## Endpoint

- **Method:** `DELETE`
- **Path:** `clients/:client_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Delete Client](https://docs.usequeue.com/api-reference/clients/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `client_id` | path | `string` | yes |
