# Get Timesheet with Queue

Retrieves a timesheet from Queue.

## Endpoint

- **Method:** `GET`
- **Path:** `timesheets/:timesheet_id`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Get Timesheet](https://docs.usequeue.com/api-reference/timesheets/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `timesheet_id` | path | `string` | yes |
