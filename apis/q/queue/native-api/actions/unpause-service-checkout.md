# Unpause Service Checkout with Queue

Unpauses a service checkout subscription in Queue.

## Endpoint

- **Method:** `POST`
- **Path:** `service_checkouts/:service_checkout_id/unpause`
- **Base URL:** `https://app.usequeue.com/api/v1`
- **Official documentation:** [Unpause Service Checkout](https://docs.usequeue.com/api-reference/service_checkouts/unpause)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `service_checkout_id` | path | `string` | yes |
