# Get QR Code Status with Qryptal

## Endpoint

- **Method:** `GET`
- **Path:** `:uid/`
- **Base URL:** `https://api2test.qryptal.com/v2/Vqodes/v2/Vqodes/`
- **Official documentation:** [Get QR Code Status](https://dash2.qryptal.com/docs/api2-api/#created-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | Unique Qryptal identifier returned when the QR code was created. |
