# Get URL Group with QStash

Retrieves a URL Group from QStash by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/topics/:urlGroupName`
- **Base URL:** `https://qstash-eu-central-1.upstash.io`
- **Official documentation:** [Get URL Group](https://upstash.com/docs/qstash/api-refence/url-groups/get-a-url-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlGroupName` | path | `string` | yes | Name of the URL Group to retrieve. |
