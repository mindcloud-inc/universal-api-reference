# List Schedules with QStash

Retrieves all existing schedules from QStash.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/schedules`
- **Base URL:** `https://qstash-eu-central-1.upstash.io`
- **Official documentation:** [List Schedules](https://upstash.com/docs/qstash/api-refence/schedules/list-schedules)
