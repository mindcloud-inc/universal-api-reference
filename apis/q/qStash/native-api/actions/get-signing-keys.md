# Get Signing Keys with QStash

Retrieves the current signing keys from QStash.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/keys`
- **Base URL:** `https://qstash-eu-central-1.upstash.io`
- **Official documentation:** [Get Signing Keys](https://upstash.com/docs/qstash/api-refence/signing-keys/get-signing-keys)
