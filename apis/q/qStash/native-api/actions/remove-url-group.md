# Remove URL Group with QStash

Deletes a URL Group from QStash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/topics/:urlGroupName`
- **Base URL:** `https://qstash-eu-central-1.upstash.io`
- **Official documentation:** [Remove URL Group](https://upstash.com/docs/qstash/api/url-groups/remove)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `urlGroupName` | path | `string` | yes | Name of the URL Group to remove. |
