# Get a specific shared parameter with Qase

Retrieves a shared parameter from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/shared_parameter/:id`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get a specific shared parameter](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier. |
