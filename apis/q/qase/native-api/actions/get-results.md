# Get all test run results with Qase

Retrieves test run results from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/result/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all test run results](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
