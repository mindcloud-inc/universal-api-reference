# Get Custom Field with Qase

Retrieves a custom field from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_field/:id`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get Custom Field](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier. |
