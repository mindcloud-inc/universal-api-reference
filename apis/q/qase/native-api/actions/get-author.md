# Get a specific author with Qase

Retrieves an author from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/author/:id`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get a specific author](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier. |
