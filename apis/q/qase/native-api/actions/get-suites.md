# Get all test suites with Qase

Retrieves test suites from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/suite/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all test suites](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
