# Get all shared steps with Qase

Retrieves shared steps from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/shared_step/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all shared steps](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
