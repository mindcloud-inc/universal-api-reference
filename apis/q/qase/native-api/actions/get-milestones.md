# Get all milestones with Qase

Retrieves milestones from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/milestone/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all milestones](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
