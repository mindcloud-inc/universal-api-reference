# Search entities by Qase Query Language (QQL) with Qase

Finds entities in Qase using Qase Query Language.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Search entities by Qase Query Language (QQL)](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Expression in Qase Query Language. |
