# Delete milestone with Qase

Deletes a milestone from Qase.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/milestone/:code/:id`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Delete milestone](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
| `id` | path | `number` | yes | Identifier. |
