# Get all test cases with Qase

Retrieves test cases from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/case/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all test cases](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
