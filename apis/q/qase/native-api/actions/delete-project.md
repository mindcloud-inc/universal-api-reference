# Delete Project by code with Qase

Deletes a project from Qase by code.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Delete Project by code](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
