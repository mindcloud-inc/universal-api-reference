# Get attachment by Hash with Qase

Retrieves an attachment from Qase by hash.

## Endpoint

- **Method:** `GET`
- **Path:** `/attachment/:hash`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get attachment by Hash](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hash` | path | `string` | yes | Hash. |
