# Delete shared step with Qase

Deletes a shared step from Qase.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/shared_step/:code/:hash`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Delete shared step](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
| `hash` | path | `string` | yes | Hash. |
