# Remove attachment by Hash with Qase

Deletes an attachment from Qase by hash.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/attachment/:hash`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Remove attachment by Hash](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hash` | path | `string` | yes | Hash. |
