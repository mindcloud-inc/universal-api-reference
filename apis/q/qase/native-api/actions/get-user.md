# Get a specific user with Qase

Retrieves a user from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:id`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get a specific user](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier. |
