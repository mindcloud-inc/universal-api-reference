# Get all configuration groups with configurations with Qase

Retrieves configuration groups and configurations from Qase.

## Endpoint

- **Method:** `GET`
- **Path:** `/configuration/:code`
- **Base URL:** `https://api.qase.io/v1`
- **Official documentation:** [Get all configuration groups with configurations](https://developers.qase.io/reference/get-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Code of project, where to search entities. |
