# Create Knowledge Base with QWIC

Creates a new knowledge base in QWIC.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/ai/knowledge-base`
- **Base URL:** `https://app.qwic.ai`
- **Official documentation:** [Create Knowledge Base](https://qwic-1.gitbook.io/help/building-agents/integrations/public-apis#create-a-knowledge-base)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Knowledge base name. |
