# Get Form Details with Qntrl

Retrieves form details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/layout/[:layout_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Form Details](https://core.qntrl.com/apidoc.html#getServiceDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `layout_id` | path | `string` | no | Qntrl form ID. |
| `org_id` | path | `string` | no | Qntrl organization ID. |
