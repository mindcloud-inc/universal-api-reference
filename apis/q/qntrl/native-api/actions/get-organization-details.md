# Get Organization Details with Qntrl

Retrieves organization details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/[:org_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Organization Details](https://core.qntrl.com/apidoc.html#GetOrgDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
