# Get Stage Details with Qntrl

Retrieves stage details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/stage/[:stage_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Stage Details](https://core.qntrl.com/apidoc.html#GetStage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
| `stage_id` | path | `string` | no | Qntrl stage ID. |
