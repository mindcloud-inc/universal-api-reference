# List User Dropdown Values with Qntrl

Retrieves user dropdown values from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/user/userpickvalues`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List User Dropdown Values](https://core.qntrl.com/apidoc.html#userpickvalues)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
