# Get Role Details with Qntrl

Retrieves role details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/role/[:role_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Role Details](https://core.qntrl.com/apidoc.html#getRole)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
| `role_id` | path | `string` | no | Qntrl role ID. |
