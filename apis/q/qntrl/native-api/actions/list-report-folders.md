# List Report Folders with Qntrl

Retrieves report folders from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/reportfolder`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Report Folders](https://core.qntrl.com/apidoc.html#GetAllFolders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
