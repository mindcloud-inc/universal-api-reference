# List Profiles with Qntrl

Retrieves profiles from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/profile`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Profiles](https://core.qntrl.com/apidoc.html#GetAllProfiles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
