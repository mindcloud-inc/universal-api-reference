# Get Profile Details with Qntrl

Retrieves profile details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/profile/[:profile_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Profile Details](https://core.qntrl.com/apidoc.html#GetProfileDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
| `profile_id` | path | `string` | no | Qntrl profile ID. |
