# List Tables with Qntrl

Retrieves tables from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/table`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Tables](https://core.qntrl.com/apidoc.html#GetAllTables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
