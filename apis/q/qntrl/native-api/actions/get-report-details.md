# Get Report Details with Qntrl

Retrieves report details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/reports/[:report_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Report Details](https://core.qntrl.com/apidoc.html#GetReport)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
| `report_id` | path | `string` | no | Qntrl report ID. |
