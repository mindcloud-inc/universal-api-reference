# List Roles with Qntrl

Retrieves roles from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/role`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Roles](https://core.qntrl.com/apidoc.html#getRoles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
