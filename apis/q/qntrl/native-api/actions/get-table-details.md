# Get Table Details with Qntrl

Retrieves table details from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/table/[:table_id]`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Get Table Details](https://core.qntrl.com/apidoc.html#GetTable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
| `table_id` | path | `string` | no | Qntrl table ID. |
