# List Reports with Qntrl

Retrieves reports from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/reports`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Reports](https://core.qntrl.com/apidoc.html#GetAllCustomReports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
