# List Users with Qntrl

Retrieves a list of users from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/user`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Users](https://core.qntrl.com/apidoc.html#getusers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
