# List Forms with Qntrl

Retrieves a list of forms from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/layout`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [List Forms](https://core.qntrl.com/apidoc.html#getServices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
