# Export Users with Qntrl

Retrieves an exported user list from Qntrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/[:org_id]/user/export`
- **Base URL:** `https://coreapi.qntrl.com/blueprint/api`
- **Official documentation:** [Export Users](https://core.qntrl.com/apidoc.html#Download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | no | Qntrl organization ID. |
