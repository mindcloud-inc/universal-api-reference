# List Collections with Qlik

Retrieves collections from your Qlik tenant.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/collections`
- **Base URL:** `https://{tenantHost}`
- **Official documentation:** [List Collections](https://qlik.dev/apis/rest/collections/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
