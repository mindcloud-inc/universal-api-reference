# Sign Up with Quantum Digital

## Endpoint

- **Method:** `POST`
- **Path:** `/devplatform/signup`
- **Base URL:** `https://api.quantumdigital.com`
- **Official documentation:** [Sign Up](https://developer.quantumdigital.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountName` | body | `string` | yes | — |
| `email` | body | `string` | yes | — |
| `recaptchaToken` | body | `string` | yes | Sensitive value. |
