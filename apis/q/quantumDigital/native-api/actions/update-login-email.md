- **Method:** `PUT`
- **Path:** `/devplatform/accounts/:dashboardAccountId/email`
- **Base URL:** `https://api.quantumdigital.com`
- **Official documentation:** [Update Login Email](https://developer.quantumdigital.com/docs)
