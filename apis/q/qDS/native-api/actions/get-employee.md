# Get Employee with QDS

Retrieves an employee from QDS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/employees/:employeeId`
- **Base URL:** `https://qdsapp.com/api/v1`
- **Official documentation:** [Get Employee](https://qdsapp.com/api/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employeeId` | path | `number` | yes | The QDS employee ID. |
