# Get Reports for a Table with Quickbase

Retrieves all reports for a Quickbase table.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/reports`
- **Base URL:** `https://api.quickbase.com`
- **Official documentation:** [Get Reports for a Table](https://developer.quickbase.com/operation/getTableReports)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | query | `string` | yes | The Quickbase table identifier. |
