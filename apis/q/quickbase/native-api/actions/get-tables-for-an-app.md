# Get Tables for an App with Quickbase

Retrieves all tables in a Quickbase app.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/tables`
- **Base URL:** `https://api.quickbase.com`
- **Official documentation:** [Get Tables for an App](https://developer.quickbase.com/operation/getAppTables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | query | `string` | yes | The Quickbase app identifier. |
