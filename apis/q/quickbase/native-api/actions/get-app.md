# Get App with Quickbase

Retrieves a Quickbase app by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/apps/:appId`
- **Base URL:** `https://api.quickbase.com`
- **Official documentation:** [Get App](https://developer.quickbase.com/operation/getApp)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The Quickbase app identifier. |
