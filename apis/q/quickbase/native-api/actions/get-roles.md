# Get Roles with Quickbase

Retrieves all roles in a Quickbase app.

## Endpoint

- **Method:** `GET`
- **Path:** `v1/apps/:appId/roles`
- **Base URL:** `https://api.quickbase.com`
- **Official documentation:** [Get Roles](https://developer.quickbase.com/operation/getRoles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | yes | The Quickbase app identifier. |
