# Retrieve Candidate with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/public/[:id]`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [Retrieve Candidate](https://developers.jaicob.ai/reference/retrieve_candidate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Candidate identifier. |
