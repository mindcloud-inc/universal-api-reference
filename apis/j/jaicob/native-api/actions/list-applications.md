# List Applications with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/applications/public`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [List Applications](https://developers.jaicob.ai/reference/list_applications)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | query | `string` | no | Optional client filter. |
| `locationId` | query | `string` | no | Optional location filter. |
