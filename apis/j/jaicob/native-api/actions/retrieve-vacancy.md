# Retrieve Vacancy with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/vacancies/public/[:id]`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [Retrieve Vacancy](https://developers.jaicob.ai/reference/retrieve_vacancy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Vacancy identifier. |
