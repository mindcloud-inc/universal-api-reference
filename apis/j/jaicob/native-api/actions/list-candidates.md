# List Candidates with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/public`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [List Candidates](https://developers.jaicob.ai/reference/list_candidates)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | query | `string` | no | Filter candidates by client ID. |
| `locationId` | query | `string` | no | Filter candidates by location ID. |
