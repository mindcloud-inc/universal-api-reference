# Retrieve Location with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/public/[:id]`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [Retrieve Location](https://developers.jaicob.ai/reference/retrieve_location)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Location identifier. |
