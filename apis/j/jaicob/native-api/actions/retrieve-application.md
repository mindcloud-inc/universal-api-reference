# Retrieve Application with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/applications/public/[:id]`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [Retrieve Application](https://developers.jaicob.ai/reference/retrieve_application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Application identifier. |
