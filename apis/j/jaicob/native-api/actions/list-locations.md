# List Locations with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/public`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [List Locations](https://developers.jaicob.ai/reference/list_locations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | query | `string` | no | Optional location filter by client. |
