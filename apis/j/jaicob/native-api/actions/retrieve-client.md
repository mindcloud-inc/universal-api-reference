# Retrieve Client with Jaicob

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/public/[:id]`
- **Base URL:** `https://api.jaicob.ai`
- **Official documentation:** [Retrieve Client](https://developers.jaicob.ai/reference/retrieve_client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client identifier. |
