# Delete Submission with Jotform

Deletes an existing submission from Jotform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/submission/:submissionId`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Delete Submission](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | Submission ID |
