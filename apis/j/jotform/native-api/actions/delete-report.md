# Delete Report with Jotform

Deletes an existing report from Jotform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/report/:reportId`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Delete Report](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | Report ID |
