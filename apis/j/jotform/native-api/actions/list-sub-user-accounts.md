# List Sub-User Accounts with Jotform

Retrieves sub-user accounts from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/subusers`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List Sub-User Accounts](https://api.jotform.com/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
