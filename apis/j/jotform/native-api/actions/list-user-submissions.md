# List User Submissions with Jotform

Retrieves user submissions from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/submissions`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List User Submissions](https://api.jotform.com/docs/#user-id-get-user-submissions)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
