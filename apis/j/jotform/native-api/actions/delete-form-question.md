# Delete Form Question with Jotform

Deletes an existing form question from Jotform.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/form/:formId/question/:questionId`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Delete Form Question](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Form ID |
| `questionId` | path | `string` | yes | Question ID |
