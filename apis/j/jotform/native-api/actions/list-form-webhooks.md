# List Form Webhooks with Jotform

Retrieves webhooks for a Jotform form.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/:formId/webhooks`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List Form Webhooks](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Form ID |
