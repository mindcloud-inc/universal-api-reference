# Update User Settings with Jotform

Updates existing user settings in Jotform.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/settings`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Update User Settings](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settings` | body | `object` | yes | Settings object to save for the user. |
