# Get System Plan with Jotform

Retrieves a system plan from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/system/plan/:planName`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Get System Plan](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `planName` | path | `string` | yes | Plan name |
