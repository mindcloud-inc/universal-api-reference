# List User Reports with Jotform

Retrieves reports for the current Jotform user.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/reports`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List User Reports](https://api.jotform.com/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
