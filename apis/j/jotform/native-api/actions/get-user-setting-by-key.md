# Get User Setting By Key with Jotform

Retrieves a user setting from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/settings/:settingsKey`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Get User Setting By Key](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settingsKey` | path | `string` | yes | Settings key |
