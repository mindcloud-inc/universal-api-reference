# Get Submission with Jotform

Retrieves a submission from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/submission/:submissionId`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Get Submission](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | Submission ID |
