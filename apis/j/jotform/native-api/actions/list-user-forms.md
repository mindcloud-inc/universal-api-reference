# List User Forms with Jotform

Retrieves forms for the current Jotform user.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/forms`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List User Forms](https://api.jotform.com/docs/#user-id-get-user-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
