# Create Form with Jotform

Creates a form in Jotform.

## Endpoint

- **Method:** `POST`
- **Path:** `/user/forms`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Create Form](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `properties` | body | `object` | no | Form properties payload. |
| `questions` | body | `object` | no | Form questions payload. |
