# Get Report with Jotform

Retrieves a report from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/:reportId`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [Get Report](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | Report ID |
