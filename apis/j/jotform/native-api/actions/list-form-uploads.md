# List Form Uploads with Jotform

Retrieves uploaded files for a Jotform form.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/:formId/files`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List Form Uploads](https://api.jotform.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | Form ID |
