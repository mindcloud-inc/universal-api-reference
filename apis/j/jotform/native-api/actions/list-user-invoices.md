# List User Invoices with Jotform

Retrieves user invoice records from Jotform.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/invoices`
- **Base URL:** `https://api.jotform.com`
- **Official documentation:** [List User Invoices](https://api.jotform.com/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
