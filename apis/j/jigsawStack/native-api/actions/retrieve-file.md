# Retrieve File with JigsawStack

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/store/file/read/{key}`
- **Base URL:** `https://api.jigsawstack.com`
- **Official documentation:** [Retrieve File](https://jigsawstack.com/docs/api-reference/store/file/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
