# Run Saved Prompt with JigsawStack

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/prompt_engine/{id}`
- **Base URL:** `https://api.jigsawstack.com`
- **Official documentation:** [Run Saved Prompt](https://jigsawstack.com/docs/api-reference/prompt-engine/run)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
