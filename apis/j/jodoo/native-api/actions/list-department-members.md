# List Department Members with Jodoo

## Endpoint

- **Method:** `POST`
- **Path:** `/corp/department/user/list`
- **Base URL:** `https://api.jodoo.com/api/v5`
- **Official documentation:** [List Department Members](https://help.jodoo.com/en/articles/9992441-member-retrieval-recursively-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dept_no` | body | `number` | yes | Department number to retrieve members from recursively. |
