# Get Member with Jodoo

## Endpoint

- **Method:** `POST`
- **Path:** `/corp/user/get`
- **Base URL:** `https://api.jodoo.com/api/v5`
- **Official documentation:** [Get Member](https://help.jodoo.com/en/articles/9992455-member-information-query-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | body | `string` | yes | Jodoo username to retrieve. |
