# List Apps with Jodoo

## Endpoint

- **Method:** `POST`
- **Path:** `/app/list`
- **Base URL:** `https://api.jodoo.com/api/v5`
- **Official documentation:** [List Apps](https://help.jodoo.com/en/articles/9992363-user-app-query-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | body | `number` | no | Number of apps to return. |
| `skip` | body | `number` | no | Number of apps to skip before returning results. |
