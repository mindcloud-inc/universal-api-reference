# Add Domain with jo4.io

## Endpoint

- **Method:** `POST`
- **Path:** `/protected/domains`
- **Base URL:** `https://jo4-api.jo4.io/api/v1`
- **Official documentation:** [Add Domain](https://jo4-api.jo4.io/swagger-ui/index.html#/custom-domain-controller/addDomain)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | body | `string` | yes |
