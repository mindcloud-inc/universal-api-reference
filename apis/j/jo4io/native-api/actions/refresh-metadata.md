# Refresh URL Metadata with jo4.io

## Endpoint

- **Method:** `POST`
- **Path:** `/protected/url/:id/refresh-metadata`
- **Base URL:** `https://jo4-api.jo4.io/api/v1`
- **Official documentation:** [Refresh URL Metadata](https://jo4-api.jo4.io/swagger-ui/index.html#/url-controller/refreshMetadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
