# Get Person with JustSift

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:idOrEmail`
- **Base URL:** `https://api.justsift.com/v1`
- **Official documentation:** [Get Person](https://developers.justsift.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `idOrEmail` | path | `string` | yes | The person's Sift id or email address. |
