# List Channels with JmpTo

Retrieves channels from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List Channels](https://jmpto.net/developers#list-channels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
