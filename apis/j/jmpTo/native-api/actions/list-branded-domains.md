# List Branded Domains with JmpTo

Retrieves branded domains from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List Branded Domains](https://jmpto.net/developers#list-branded-domains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
