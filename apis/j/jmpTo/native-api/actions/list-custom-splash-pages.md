# List Custom Splash Pages with JmpTo

Retrieves custom splash pages from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/splash`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List Custom Splash Pages](https://jmpto.net/developers#list-custom-splash)

## Capabilities

This operation supports [pagination](../README.md#pagination).
