# Delete Link with JmpTo

Deletes an existing link from JmpTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/url/:id/delete`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Delete Link](https://jmpto.net/developers#delete-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Link ID to delete. |
