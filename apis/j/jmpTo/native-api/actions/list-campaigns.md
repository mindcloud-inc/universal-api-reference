# List Campaigns with JmpTo

Retrieves campaigns from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List Campaigns](https://jmpto.net/developers#list-campaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination).
