# Delete Channel with JmpTo

Deletes an existing channel from JmpTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channel/:id/delete`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Delete Channel](https://jmpto.net/developers#delete-channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Channel ID to delete. |
