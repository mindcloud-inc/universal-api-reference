# List CTA Overlays with JmpTo

Retrieves CTA overlays from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/overlay`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List CTA Overlays](https://jmpto.net/developers#list-cta-overlays)

## Capabilities

This operation supports [pagination](../README.md#pagination).
