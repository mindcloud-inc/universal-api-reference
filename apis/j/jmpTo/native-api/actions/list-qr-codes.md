# List QR Codes with JmpTo

Retrieves QR codes from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List QR Codes](https://jmpto.net/developers#list-qr-codes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
