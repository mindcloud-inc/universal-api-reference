# Delete Pixel with JmpTo

Deletes an existing pixel from JmpTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pixel/:id/delete`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Delete Pixel](https://jmpto.net/developers#delete-pixel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Pixel ID to delete. |
