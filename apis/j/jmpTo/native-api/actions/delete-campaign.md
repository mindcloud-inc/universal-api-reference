# Delete Campaign with JmpTo

Deletes an existing campaign from JmpTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaign/:id/delete`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Delete Campaign](https://jmpto.net/developers#delete-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Campaign ID to delete. |
