# List Pixels with JmpTo

Retrieves pixels from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/pixels`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [List Pixels](https://jmpto.net/developers#list-pixels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
