# Get Link with JmpTo

Retrieves a link from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/url/:id`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Get Link](https://jmpto.net/developers#get-a-single-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Link ID to retrieve. |
