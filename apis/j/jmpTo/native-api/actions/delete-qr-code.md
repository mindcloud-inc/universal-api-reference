# Delete QR Code with JmpTo

Deletes an existing QR code from JmpTo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qr/:id/delete`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Delete QR Code](https://jmpto.net/developers#delete-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | QR code ID to delete. |
