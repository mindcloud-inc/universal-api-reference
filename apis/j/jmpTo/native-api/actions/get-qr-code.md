# Get QR Code with JmpTo

Retrieves a QR code from JmpTo.

## Endpoint

- **Method:** `GET`
- **Path:** `/qr/:id`
- **Base URL:** `https://jmpto.net/api`
- **Official documentation:** [Get QR Code](https://jmpto.net/developers#get-a-single-qr-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | QR code ID to retrieve. |
