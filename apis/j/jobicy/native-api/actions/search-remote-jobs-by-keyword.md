# Search Remote Jobs by Keyword with Jobicy

## Endpoint

- **Method:** `GET`
- **Path:** `/remote-jobs`
- **Base URL:** `https://jobicy.com/api/v2`
- **Official documentation:** [Search Remote Jobs by Keyword](https://jobicy.com/jobs-rss-feed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | query | `string` | yes | Keyword to search across the job title and description. |
