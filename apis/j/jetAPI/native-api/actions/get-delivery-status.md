# Get Delivery Status with JetAPI

Retrieves delivery status from JetAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/delivery/:id`
- **Base URL:** `https://api.jetapi.io`
- **Official documentation:** [Get Delivery Status](https://docs.jetapi.io/#7b1aa4db-cbfe-4335-b0f1-17e9f3d4c490)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JetAPI delivery identifier. |
