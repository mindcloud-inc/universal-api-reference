# Delete Webhook with JetAPI

Deletes an existing webhook from JetAPI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/webhooks/:id`
- **Base URL:** `https://api.jetapi.io`
- **Official documentation:** [Delete Webhook](https://docs.jetapi.io/#4b696871-b1f5-4118-898e-d6802502fec9)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JetAPI webhook identifier. |
