# Get Webhook with JetAPI

Retrieves a webhook from JetAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/webhooks/:id`
- **Base URL:** `https://api.jetapi.io`
- **Official documentation:** [Get Webhook](https://docs.jetapi.io/#97ff61cd-dbae-4da5-8e5b-b2c46e4aaf70)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JetAPI webhook identifier. |
