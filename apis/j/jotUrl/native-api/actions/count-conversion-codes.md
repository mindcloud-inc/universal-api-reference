# Count Conversion Codes with JotUrl

Retrieves the number of conversion codes in JotUrl.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversions/codes/count`
- **Base URL:** `https://joturl.com/a/i1`
- **Official documentation:** [Count Conversion Codes](https://i1.joturl.com/#conversions-codes-count)
