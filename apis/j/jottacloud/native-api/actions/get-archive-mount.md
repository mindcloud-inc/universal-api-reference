# Get Archive Mount with Jottacloud

## Endpoint

- **Method:** `GET`
- **Path:** `https://jfs.jottacloud.com/jfs/{{username}}/Jotta/Archive`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `username` | path | `string` | yes | Jottacloud account username used in the JFS path. |
