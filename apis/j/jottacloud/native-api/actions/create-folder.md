# Create Folder with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/files/v2/create_folder`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical folder path to create. |
