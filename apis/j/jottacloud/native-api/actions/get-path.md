# Get Path with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/files/v2/get_path`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical Jottacloud path such as Archive, /Archive, Sync, or Photos. |
