# List Revisions with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/files/v2/list_revisions`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical file path whose revisions should be listed. |
