# Enable Public Share with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/shares/v2/public_enable`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical path to enable public sharing for. |
