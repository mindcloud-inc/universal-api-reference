# Restore Path with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/files/v2/restore`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical path to restore from trash. |
