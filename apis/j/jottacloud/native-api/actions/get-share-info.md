# Get Share Info with Jottacloud

## Endpoint

- **Method:** `POST`
- **Path:** `/shares/v2/share_info`
- **Base URL:** `https://api.jotta.cloud`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | body | `string` | yes | Logical path or share target whose public share info should be returned. |
