# Get a User with JustCall

Retrieves a user from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/users/:id`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get a User](https://developer.justcall.io/reference/users_get_v21)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JustCall user ID. |
