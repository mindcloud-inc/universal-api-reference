# Delete Contact with JustCall

Deletes an existing contact from JustCall.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2.1/contacts`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Delete Contact](https://developer.justcall.io/reference/delete_contact_v21)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | no | The JustCall contact ID to delete. |
