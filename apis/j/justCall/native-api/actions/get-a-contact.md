# Get a Contact with JustCall

Retrieves a contact from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/contacts/:id`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get a Contact](https://developer.justcall.io/reference/contact_get_v21)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JustCall contact ID. |
