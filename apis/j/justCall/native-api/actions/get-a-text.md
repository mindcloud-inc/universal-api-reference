# Get a Text with JustCall

Retrieves a text from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/texts/:id`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get a Text](https://developer.justcall.io/reference/texts_get_v21)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
