# Get a Phone Number with JustCall

Retrieves a phone number from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/phone-numbers/:id`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get a Phone Number](https://developer.justcall.io/reference/phone_number_get_v21)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The JustCall phone number ID. |
