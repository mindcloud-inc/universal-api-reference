# List All Contacts with JustCall

Retrieves contacts from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/contacts`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [List All Contacts](https://developer.justcall.io/reference/contacts_list_v21)

## Capabilities

This operation supports [pagination](../README.md#pagination).
