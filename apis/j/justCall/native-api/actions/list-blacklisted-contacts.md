# List Blacklisted Contacts with JustCall

Retrieves blacklisted contacts from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/contacts/blacklist`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [List Blacklisted Contacts](https://developer.justcall.io/reference/list_blacklist_contacts_v21)

## Capabilities

This operation supports [pagination](../README.md#pagination).
