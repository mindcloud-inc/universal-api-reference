# Get Call Journey with JustCall

Retrieves a call journey from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/calls/:id/journey`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get Call Journey](https://developer.justcall.io/reference/call_get_journey_v21)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
