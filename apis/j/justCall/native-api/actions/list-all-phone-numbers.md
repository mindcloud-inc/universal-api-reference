# List All Phone Numbers with JustCall

Retrieves phone numbers from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/phone-numbers`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [List All Phone Numbers](https://developer.justcall.io/reference/phone_number_list_v21)

## Capabilities

This operation supports [pagination](../README.md#pagination).
