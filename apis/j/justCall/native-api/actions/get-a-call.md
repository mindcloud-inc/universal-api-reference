# Get a Call with JustCall

Retrieves a call from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/calls/:id`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Get a Call](https://developer.justcall.io/reference/call_get_v21)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The JustCall call ID or SID. |
