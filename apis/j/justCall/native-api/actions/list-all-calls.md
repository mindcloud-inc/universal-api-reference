# List All Calls with JustCall

Retrieves calls from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/calls`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [List All Calls](https://developer.justcall.io/reference/call_list_v21)

## Capabilities

This operation supports [pagination](../README.md#pagination).
