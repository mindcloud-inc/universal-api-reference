# Download Call Recording with JustCall

Downloads a call recording from JustCall.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2.1/calls/:id/recording/download`
- **Base URL:** `https://api.justcall.io`
- **Official documentation:** [Download Call Recording](https://developer.justcall.io/reference/call_recording_download_v21)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
