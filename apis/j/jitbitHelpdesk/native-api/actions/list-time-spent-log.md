# List Time Spent Log with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/TimeSpentLog`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Time Spent Log](https://www.jitbit.com/docs/api/#time-spent-log-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | query | `number` | yes | Jitbit ticket ID to inspect time spent log for. |
