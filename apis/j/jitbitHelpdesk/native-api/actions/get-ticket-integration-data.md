# Get Ticket Integration Data with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/TicketIntegrationData`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [Get Ticket Integration Data](https://www.jitbit.com/docs/api/#ticket-integration-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID. |
