# List Techs for Category with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/TechsForCategory`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Techs for Category](https://www.jitbit.com/docs/api/#techs-for-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit category ID. |
