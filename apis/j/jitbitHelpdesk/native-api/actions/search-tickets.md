# Search Tickets with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/Search`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [Search Tickets](https://www.jitbit.com/docs/api/#search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search text for Jitbit ticket search. |
