# List Attachments with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/Attachments`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Attachments](https://www.jitbit.com/docs/api/#attachments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list attachments for. |
