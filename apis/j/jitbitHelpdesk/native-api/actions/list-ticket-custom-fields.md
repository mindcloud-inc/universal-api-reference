# List Ticket Custom Fields with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/TicketCustomFields`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Ticket Custom Fields](https://www.jitbit.com/docs/api/#ticket-custom-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list custom fields for. |
