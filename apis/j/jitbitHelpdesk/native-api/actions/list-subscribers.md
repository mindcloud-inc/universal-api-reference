# List Subscribers with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/Subscribers`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Subscribers](https://www.jitbit.com/docs/api/#subscribers-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list subscribers for. |
