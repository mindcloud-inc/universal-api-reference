# List Subtickets with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/SubTickets`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Subtickets](https://www.jitbit.com/docs/api/#sub-tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list subtickets for. |
