# Get Ticket with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/ticket`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [Get Ticket](https://www.jitbit.com/docs/api/#ticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID. |
