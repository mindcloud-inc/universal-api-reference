# List Comments with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/comments`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Comments](https://www.jitbit.com/docs/api/#comments-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list comments for. |
