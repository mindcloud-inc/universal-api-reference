# Get User with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/User`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [Get User](https://www.jitbit.com/docs/api/#user-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | query | `number` | yes | Jitbit user ID. |
