# List Linked Tickets with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/LinkedTickets`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Linked Tickets](https://www.jitbit.com/docs/api/#linked-tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit ticket ID to list linked tickets for. |
