# Get Attachment with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/attachment`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [Get Attachment](https://www.jitbit.com/docs/api/#attachment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Jitbit attachment identifier. |
