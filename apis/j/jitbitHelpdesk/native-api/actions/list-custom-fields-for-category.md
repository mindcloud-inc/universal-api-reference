# List Custom Fields for Category with Jitbit Helpdesk

## Endpoint

- **Method:** `GET`
- **Path:** `/CustomFieldsForCategory`
- **Base URL:** `{helpdeskBaseUrl}/api`
- **Official documentation:** [List Custom Fields for Category](https://www.jitbit.com/docs/api/#custom-fields-for-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `categoryId` | query | `number` | yes | Jitbit category ID. |
