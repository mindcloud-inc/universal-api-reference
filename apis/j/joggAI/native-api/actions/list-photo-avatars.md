# List Photo Avatars with JoggAI

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/avatars/photo_avatars`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [List Photo Avatars](https://docs.jogg.ai/api-reference/v2/Avatar/PhotoAvatarsGet)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `page` | query | `number` | no |
| `page_size` | query | `number` | no |
| `name` | query | `string` | no |
| `status` | query | `string` | no |
