# Get Translation Status with JoggAI

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/video_translate/{videoTranslateId}`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [Get Translation Status](https://docs.jogg.ai/api-reference/v2/API%20Documentation/VideoTranslation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoTranslateId` | path | `string` | yes | The translation task ID returned when a video translation is submitted. |
