# Delete Webhook Endpoint with JoggAI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/endpoint/{endpointId}`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [Delete Webhook Endpoint](https://docs.jogg.ai/api-reference/v2/Webhook/DeleteWebhookEndpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endpoint_id` | path | `string` | yes | Webhook endpoint ID to delete. |
