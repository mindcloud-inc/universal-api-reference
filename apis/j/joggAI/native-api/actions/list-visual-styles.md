# List Visual Styles with JoggAI

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/visual_styles`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [List Visual Styles](https://docs.jogg.ai/api-reference/v2/Asset/GetVisualStyles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `aspect_ratio` | query | `string` | no | Filter visual styles for a specific aspect ratio. |
