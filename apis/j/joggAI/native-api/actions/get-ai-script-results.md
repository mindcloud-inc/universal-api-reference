# Get AI Script Results with JoggAI

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/ai_scripts/results/{taskId}`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [Get AI Script Results](https://docs.jogg.ai/api-reference/v2/Asset/GetAIScriptResult)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | AI script generation task identifier |
