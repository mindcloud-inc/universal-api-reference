# Get Avatar Video Status with JoggAI

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/avatar_video/{videoId}`
- **Base URL:** `https://api.jogg.ai`
- **Official documentation:** [Get Avatar Video Status](https://docs.jogg.ai/api-reference/v2/Video/AvatarVideoGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | path | `string` | yes | The avatar video ID returned when a video is created. |
