# Get Tracking Snippet with Journy.io

## Endpoint

- **Method:** `GET`
- **Path:** `/tracking/snippet`
- **Base URL:** `https://api.journy.io`
- **Official documentation:** [Get Tracking Snippet](https://developers.journy.io/#operation/getTrackingSnippet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | The domain you want to receive a snippet for. |
