# Delete Company with Joiin

Deletes an existing company from Joiin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/companies/:id`
- **Base URL:** `https://app-api.joiin.co`
- **Official documentation:** [Delete Company](https://app.joiin.co/reference/delete_company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Joiin company ID. |
