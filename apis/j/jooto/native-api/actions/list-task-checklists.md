# List Task Checklists with Jooto

Retrieves checklists for a specific task in Jooto.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/:task_id/checklists`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Task Checklists](https://www.jooto.com/api/reference/request/)
