# List Public Board Tasks with Jooto

Retrieves tasks from a public Jooto project board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/:board_id/tasks`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Board Tasks](https://www.jooto.com/api/reference/request/)
