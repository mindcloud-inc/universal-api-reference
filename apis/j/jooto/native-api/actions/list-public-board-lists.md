# List Public Board Lists with Jooto

Retrieves lists from a public Jooto project board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/:board_id/lists`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Board Lists](https://www.jooto.com/api/reference/request/)
