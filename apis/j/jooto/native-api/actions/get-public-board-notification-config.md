# Get Public Board Notification Config with Jooto

Retrieves notification settings for a public Jooto board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/:id/notification_config`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [Get Public Board Notification Config](https://www.jooto.com/api/reference/request/)
