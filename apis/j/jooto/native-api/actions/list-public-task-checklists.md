# List Public Task Checklists with Jooto

Retrieves checklists for a public task in Jooto.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/tasks/:task_id/checklists`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Task Checklists](https://www.jooto.com/api/reference/request/)
