# List Public Task Comments with Jooto

Retrieves comments for a public task in Jooto.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/tasks/:task_id/comments`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Task Comments](https://www.jooto.com/api/reference/request/)
