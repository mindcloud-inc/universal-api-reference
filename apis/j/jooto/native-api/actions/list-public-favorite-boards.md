# List Public Favorite Boards with Jooto

Retrieves favorite boards from Jooto's public API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/favorites`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Favorite Boards](https://www.jooto.com/api/reference/request/)
