# List Public Board Users with Jooto

Retrieves users from a public Jooto project board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/:board_id/users`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Board Users](https://www.jooto.com/api/reference/request/)
