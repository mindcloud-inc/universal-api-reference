# List Public Board Attachments with Jooto

Retrieves attachments from a public Jooto project board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/boards/:id/attachments`
- **Base URL:** `https://app.jooto.com`
- **Official documentation:** [List Public Board Attachments](https://www.jooto.com/api/reference/request/)
