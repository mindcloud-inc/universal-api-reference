# Get Project Items with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/items`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get Project Items](https://api.jetbuilt.com/customers?shell--json#project-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
