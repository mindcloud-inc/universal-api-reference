# Get Labor Presets with Jetbuilt

Retrieves all labor presets for your company.

## Endpoint

- **Method:** `GET`
- **Path:** `labor_presets/:laborPresetID`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get Labor Presets](https://api.jetbuilt.com/customers?shell--json#labor-presets)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `laborPresetID` | path | `string` | no |
