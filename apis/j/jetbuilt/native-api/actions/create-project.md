# Create Project with Jetbuilt

## Endpoint

- **Method:** `POST`
- **Path:** `projects`
- **Base URL:** `https://app.jetbuilt.com/api/`

| `paid_to_date` | body | `string` | no |

| `short_description` | body | `string` | no |
| `state` | body | `string` | no |
| `street_address` | body | `string` | no |
| `tax` | body | `string` | no |
| `user_id` | body | `string` | yes |
