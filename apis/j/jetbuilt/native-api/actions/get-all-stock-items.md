# Get All Stock Items with Jetbuilt

Retrieves all of your stock items.

## Endpoint

- **Method:** `GET`
- **Path:** `stock/items`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get All Stock Items](https://api.jetbuilt.com/customers?shell--json#get-all-stock-items)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | no |
