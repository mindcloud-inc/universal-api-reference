# Get a Product with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `product_databases/:databaseId/products/:id`
- **Base URL:** `https://app.jetbuilt.com/api/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | no |
| `databaseId` | path | `number` | no |
