# Get Purchase Order with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `purchase_orders/[:id]`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get Purchase Order](https://api.jetbuilt.com/customers#get-a-purchase-order)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `project_id` | query | `string` | no |
