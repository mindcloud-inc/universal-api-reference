# Get Proposals with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/proposals`
- **Base URL:** `https://app.jetbuilt.com/api/`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | — |
| `expiry_public_link` | query | `boolean` | no | Format: `toggle`. |
