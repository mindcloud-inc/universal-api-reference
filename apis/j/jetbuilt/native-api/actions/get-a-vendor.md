# Get a Vendor with Jetbuilt

This endpoint retrieves a vendor by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `product_databases/:databaseID/vendors/:vendorId`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get a Vendor](https://api.jetbuilt.com/customers#get-a-vendor)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `vendorId` | path | `string` | no |
| `databaseID` | path | `string` | no |
