# List Vendors with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `product_databases/:dbId/vendors`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [List Vendors](https://api.jetbuilt.com/customers#get-all-vendors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dbId` | path | `string` | no | — |
| `page` | query | `string` | no | Only use this for debugging purposes |
