# Get Project Options with Jetbuilt

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/options/[:optionId]`
- **Base URL:** `https://app.jetbuilt.com/api/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `optionId` | path | `string` | no |
