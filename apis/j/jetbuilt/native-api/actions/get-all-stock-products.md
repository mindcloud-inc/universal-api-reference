# Get All Stock Products with Jetbuilt

Retrieves all of your stock products.

## Endpoint

- **Method:** `GET`
- **Path:** `stock/products`
- **Base URL:** `https://app.jetbuilt.com/api/`
- **Official documentation:** [Get All Stock Products](https://api.jetbuilt.com/customers?shell--json#get-all-stock-products)
