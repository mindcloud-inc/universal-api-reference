# Get SMS Details with Joonto

## Endpoint

- **Method:** `GET`
- **Path:** `/api/SMS/Get/:id`
- **Base URL:** `https://api.joonto.com`
- **Official documentation:** [Get SMS Details](https://api.joonto.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
