# Get User Details with Joonto

## Endpoint

- **Method:** `GET`
- **Path:** `/api/Users/Get/:id`
- **Base URL:** `https://api.joonto.com`
- **Official documentation:** [Get User Details](https://api.joonto.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
