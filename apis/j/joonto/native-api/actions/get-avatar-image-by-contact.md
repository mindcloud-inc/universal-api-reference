- **Method:** `GET`
- **Path:** `/api/Images/GetByContact`
- **Base URL:** `https://api.joonto.com`
- **Official documentation:** [Get Avatar Image By Contact](https://api.joonto.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |

| `contact` | query | `string` | no |
