# List SMS Contacts with Joonto

## Endpoint

- **Method:** `POST`
- **Path:** `/api/Users/GetSmsContacts`
- **Base URL:** `https://api.joonto.com`
- **Official documentation:** [List SMS Contacts](https://api.joonto.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `skip` | query | `number` | no |
| `take` | query | `number` | no |
