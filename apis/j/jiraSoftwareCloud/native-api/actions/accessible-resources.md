# Accessible Resources with Jira Software Cloud

Retrieves accessible Jira Software Cloud sites for this token.

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth/token/accessible-resources`
- **Base URL:** `https://api.atlassian.com`
- **Official documentation:** [Accessible Resources](https://developer.atlassian.com/cloud/jira/platform/oauth-2-3lo-apps/)
