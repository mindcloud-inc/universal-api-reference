# Add Text Watermark to PDF with ConvertAPI

Adds a text watermark to a PDF with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/pdf/to/text-watermark`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Add Text Watermark to PDF](https://www.convertapi.com/pdf-to-text-watermark)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Password` | body | `string` | no | Sets the password to open protected documents. |
| `Text` | body | `string` | yes | Specifies the text to use as watermark. The list of supported variables: * ```%PAGE%``` - current page number * ```%PAGES%``` - total number of pages * ```%FILENAME%``` - name of the file * ```%WEEKDAY%``` - full weekday name * ```%WEEKDAY_SHORT%``` - abbreviated weekday name * ```%MONTH%``` - month number (1-12) * ```%MONTHNAME%``` - full month name * ```%MONTHNAME_SHORT%``` - abbreviated month name * ```%YEAR%``` - year with century (YYYY) * ```%YEAR_SHORT%``` - year without century (YY) * ```%DAY%``` - day of month * ```%DAY_YEAR%``` - day of the year (1 -366) * ```%HOUR%``` - hour (01- 12) * ```%HOURS%``` - hour (00-23) * ```%MINUTES%``` - minutes (00-59) * ```%SECONDS%``` - seconds (00-59) * ```%AMPM%``` - AM PM * ```%DATE%``` - local date representation * ```%TIME%``` - local time representation * ```%DATETIME%``` - local date and time * ```%AUTHOR%``` - document Author * ```%TITLE%``` - document Title * ```%SUBJECT%``` - document Subject * ```%KEYWORDS%``` - document Keywords * ```%N%``` - new line |
| `Style` | body | `list<string>` | no | Specifies watermark style, stamp or watermark. The stamp is placed over page content and watermark under page content. Accepted values: `stamp`, `watermark`. |
| `FontSize` | body | `number` | no | Specifies the watermark font size. |
| `TextRenderingMode` | body | `list<string>` | no | Specifies the text rendering mode. Accepted values: `fillstroke`, `filltext`, `invisible`, `stroketext`. |
| `FontColor` | body | `string` | no | Specifies the watermark font color. |
| `StrokeColor` | body | `string` | no | Specifies font stroke color. |
| `StrokeWidth` | body | `number` | no | Specifies the stroke width. |
| `FontName` | body | `list<string>` | no | Specifies the watermark font name. Contact us if you are looking for a specific font for a watermark that is missing from the list. Accepted values: `arial`, `bahnschrift`, `calibri`, `cambria`, `consolas`, `constantia`, `courierNew`, `georgia`, `tahoma`, `timesNewRoman`, `verdana`. |
| `Rotate` | body | `number` | no | Specifies the watermark rotation angle in degrees. |
| `Opacity` | body | `number` | no | Specifies watermark opacity level. |
| `GoToLink` | body | `string` | no | Specifies the web address to go when the watermark is clicked. |
| `GoToPage` | body | `string` | no | Specifies the page number to go when the watermark is clicked. |
| `PageBox` | body | `list<string>` | no | Specifies the PDF page box used as the reference area for applying the watermark. Accepted values: `bleedbox`, `cropbox`, `mediabox`, `trimbox`. |
| `HorizontalAlignment` | body | `list<string>` | no | Specifies the horizontal watermark alignment. Accepted values: `center`, `left`, `right`. |
| `VerticalAlignment` | body | `list<string>` | no | Specifies the vertical watermark alignment. Accepted values: `bottom`, `center`, `top`. |
| `MeasurementUnit` | body | `list<string>` | no | Measurement unit for position and size parameters. Accepted values: `cm`, `in`, `mm`, `pt`. |
| `OffsetX` | body | `number` | no | Specifies the watermark offset along the X-axis. Positive values move the watermark to the right, while negative values move it to the left, using the selected `MeasurementUnit`. |
| `OffsetY` | body | `number` | no | Specifies the watermark offset along the Y-axis. Positive values move the watermark downward, while negative values move it upward, using the selected `MeasurementUnit`. |
| `Width` | body | `number` | no | Specifies the width of the watermark text box in the selected `MeasurementUnit`. A value of `0` means the width is unspecified. |
| `Height` | body | `number` | no | Specifies the height of the watermark text box in the selected `MeasurementUnit`. A value of `0` means the height is unspecified. |
| `LineSpacing` | body | `number` | no | Specifies the watermark text line spacing. |
| `PageRange` | body | `string` | no | Set page range. Example 1-10 or 1,2,5. |
| `FontEmbed` | body | `boolean` | no | Specifies whether fonts should be embedded. |
| `FontSubset` | body | `boolean` | no | Specifies whether fonts should be subset. |
