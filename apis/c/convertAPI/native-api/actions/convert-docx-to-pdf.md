# Convert DOCX to PDF with ConvertAPI

Converts a DOCX file to PDF with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/docx/to/pdf`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Convert DOCX to PDF](https://www.convertapi.com/docx-to-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Password` | body | `string` | no | Sets the password to open protected documents. |
| `PageRange` | body | `string` | no | Set page range. Example 1-10. |
| `ConvertMarkups` | body | `boolean` | no | Convert document markups like revisions and comments. |
| `ConvertTags` | body | `boolean` | no | Convert document structure tags for accessibility. |
| `ConvertMetadata` | body | `boolean` | no | Convert document metadata like Title, Author, Keywords to PDF metadata. |
| `ConvertHeadings` | body | `boolean` | no | Convert Word headings to PDF bookmarks. |
| `ConvertBookmarks` | body | `boolean` | no | Convert Word bookmarks to PDF bookmarks. |
| `UpdateToc` | body | `boolean` | no | Update all tables of content in the document. |
| `Pdfa` | body | `boolean` | no | Create PDF/A-3a compliant document. |
