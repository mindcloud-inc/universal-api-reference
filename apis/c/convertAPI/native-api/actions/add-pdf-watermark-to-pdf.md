# Add PDF Watermark to PDF with ConvertAPI

Adds a PDF watermark to a PDF with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/pdf/to/pdf-watermark`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Add PDF Watermark to PDF](https://www.convertapi.com/pdf-to-pdf-watermark)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Password` | body | `string` | no | Sets the password to open protected documents. |
| `OverlayFile` | body | `file` | yes | Specifies the PDF file to use as overlay. Value can be URL or file content. |
| `OverlayPage` | body | `number` | no | Specifies the page to use as overlay from the OverlayFile file. |
| `Scale` | body | `number` | no | Specifies the watermark scale in percent. |
| `PageRange` | body | `string` | no | Set page range. Example 1-10 or 1,2,5. |
| `Opacity` | body | `number` | no | Specifies watermark opacity level. |
| `Style` | body | `list<string>` | no | Specifies watermark style, stamp or watermark. The stamp is placed over page content and watermark under page content. Accepted values: `stamp`, `watermark`. |
| `GoToLink` | body | `string` | no | Specifies the web address to go when the watermark is clicked. |
| `GoToPage` | body | `string` | no | Specifies the page number to go when the watermark is clicked. |
| `PageRotation` | body | `boolean` | no | Specifies whether the watermark should respect the PDF page rotation. When enabled, the watermark is rotated together with the page. When disabled, the watermark is placed ignoring page rotation. |
| `PageBox` | body | `list<string>` | no | Specifies the PDF page box used as the reference area for applying the watermark. Accepted values: `bleedbox`, `cropbox`, `mediabox`, `trimbox`. |
| `MeasurementUnit` | body | `list<string>` | no | Measurement unit for position and size parameters. Accepted values: `cm`, `in`, `mm`, `pt`. |
| `OffsetX` | body | `number` | no | Specifies the watermark offset along the X-axis. Positive values move the watermark to the right, while negative values move it to the left, using the selected `MeasurementUnit`. |
| `OffsetY` | body | `number` | no | Specifies the watermark offset along the Y-axis. Positive values move the watermark downward, while negative values move it upward, using the selected `MeasurementUnit`. |
| `HorizontalAlignment` | body | `list<string>` | no | Specifies the horizontal watermark alignment. Accepted values: `center`, `left`, `right`. |
| `VerticalAlignment` | body | `list<string>` | no | Specifies the vertical watermark alignment. Accepted values: `bottom`, `center`, `top`. |
