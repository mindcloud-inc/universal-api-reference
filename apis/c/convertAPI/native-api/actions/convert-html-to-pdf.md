# Convert HTML to PDF with ConvertAPI

Converts HTML content to PDF with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/html/to/pdf`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Convert HTML to PDF](https://www.convertapi.com/html-to-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `ConversionDelay` | body | `number` | no | Delay in seconds before page load and PDF creation. Sometimes useful to let web page fully load. |
| `Version` | body | `list<string>` | no | Specify a particular version of the Chromium engine to render the web page. Accepted values: `117`, `126`, `130`, `140`, `145`, `latest`. |
| `AuthUsername` | body | `string` | no | HTTP authentication username. Could be used if conversion web page is protected with HTTP authentication. |
| `AuthPassword` | body | `string` | no | HTTP authentication password. Could be used if conversion web page is protected with HTTP authentication. |
| `AdBlock` | body | `boolean` | no | Block ads in converting page. |
| `CookieConsentBlock` | body | `boolean` | no | Tries to remove EU regulation required cookie warnings from web pages. |
| `Cookies` | body | `string` | no | Set additional cookies for the page request. Example: cookiename1=cookievalue1; cookiename2=cookievalue2; cookiename3=cookievalue3 |
| `JavaScript` | body | `boolean` | no | Allow web pages to run JavaScript. |
| `WaitElement` | body | `string` | no | Element selector string of the DOM element. Converter will wait for this element to appear in DOM before conversion begins. |
| `UserJs` | body | `string` | no | Execute provided JavaScript before conversion begins. |
| `UserCss` | body | `string` | no | Apply additional CSS before conversion begins. |
| `HideElements` | body | `string` | no | Element selector string of the DOM elements that needs to be hidden during conversion. |
| `CssMediaType` | body | `string` | no | Use CSS media type in conversion process. The default screen and print media types are supported but not limited to these. The custom media type, like convertapi can be used too. |
| `Headers` | body | `string` | no | Set custom HTTP headers to include in the request. Format: `Header1:Value1\|Header2:Value2\|Header3:Value3` - Each header is separated by `\|`. - Each name/value pair is separated by `:`. |
| `LoadLazyContent` | body | `boolean` | no | Load page images that loads only when they are visible. |
| `ViewportWidth` | body | `number` | no | Sets browser viewport width. |
| `ViewportHeight` | body | `number` | no | Sets browser viewport height. |
| `RespectViewport` | body | `boolean` | no | If true, the converter will generate PDF as the content looks like in the browser. If is set to false, the converter acts like Chrome print to PDF function. |
| `Scale` | body | `number` | no | Set web page scale value in percentage. |
| `PageOrientation` | body | `list<string>` | no | PDF page orientation. Accepted values: `landscape`, `portrait`. |
| `PageSize` | body | `list<string>` | no | PDF page size. Accepted values: `a0`, `a1`, `a2`, `a3`, `a4`, `a5`, `a6`, `a7`, `a8`, `a9`, `b0`, `b1`, `b2`, `b3`, `b4`, `b5`, `ledger`, `legal`, `letter`. |
| `PageWidth` | body | `number` | no | Custom page width in millimeters (mm). This option override PageSize option. |
| `PageHeight` | body | `number` | no | Custom page height in millimeters (mm). This option override PageSize option. |
| `MarginTop` | body | `number` | no | Set the page top margin in millimeters (mm). |
| `MarginRight` | body | `number` | no | Set the page right margin in millimeters (mm). |
| `MarginBottom` | body | `number` | no | Set the page bottom margin in millimeters (mm). |
| `MarginLeft` | body | `number` | no | Set the page left margin in millimeters (mm). |
| `PageRange` | body | `string` | no | Set page range. Example 1-10 or 1,2,5. |
| `Background` | body | `boolean` | no | Convert web page background. |
| `FixedElements` | body | `list<string>` | no | Change fixed elements CSS 'position' property to adapt page for conversion. Accepted values: `absolute`, `fixed`, `hide`, `relative`. |
| `Header` | body | `string` | no | This property will insert an HTML header into each page. HTML tags containing the classes `pageNumber`, `totalPages`, `title`, and `date` will be filled in with the metadata relevant to each individual page. Inline CSS could be utilized to style the HTML provided. ```html <style> .right { float: right; } .left { float: left; } </style> <span class='left'> page number <span class='pageNumber'></span> </span> <span class='right'> date <span class='date'></span> </span> ``` |
| `Footer` | body | `string` | no | This property will insert an HTML footer into each page. HTML tags containing the classes `pageNumber`, `totalPages`, `title`, and `date` will be filled in with the metadata relevant to each individual page. Inline CSS could be utilized to style the HTML provided. ```html <style> .right { float: right; } .left { float: left; } </style> <span class='left'> page number <span class='pageNumber'></span> </span> <span class='right'> date <span class='date'></span> </span> ``` |
| `ShowElements` | body | `string` | no | Element selector string of the DOM elements that should be visible during conversion. Other elements will be hidden. |
| `AvoidBreakElements` | body | `string` | no | CSS selector for the elements that pages should not break. |
| `BreakBeforeElements` | body | `string` | no | CSS selector for the elements that should apply page break before it. |
| `BreakAfterElements` | body | `string` | no | CSS selector for the elements that should apply page break after it. |
