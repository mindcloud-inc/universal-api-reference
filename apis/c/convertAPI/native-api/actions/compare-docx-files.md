# Compare DOCX Files with ConvertAPI

Compares DOCX files and highlights differences in ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/docx/to/compare`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Compare DOCX Files](https://www.convertapi.com/docx-to-compare)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `CompareFile` | body | `file` | yes | Specifies the Word document with which the specified document is compared. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Password` | body | `string` | no | Sets the password to open protected documents. |
| `CompareLevel` | body | `list<string>` | no | The property defines the granularity of comparisons between documents or text segments. It determines the precision of the comparison process, allowing users to specify whether differences are identified based on larger text blocks, such as words or sentences, or at a more detailed level, such as characters or formatting. Accepted values: `Character`, `Word`. |
| `CompareFormatting` | body | `boolean` | no | Determines whether to indicate variations in formatting between the two documents. |
| `CompareCaseChanges` | body | `boolean` | no | Determines whether to highlight discrepancies in capitalization between the two documents. |
| `CompareWhitespace` | body | `boolean` | no | Determines whether to identify dissimilarities in whitespace, such as gaps or paragraphs, between the two documents. |
| `CompareTables` | body | `boolean` | no | Determines whether to evaluate variations in the information presented within tables between the two documents. |
| `CompareHeaders` | body | `boolean` | no | Determines whether to contrast divergences in headers and footers between the two documents. |
| `CompareFootnotes` | body | `boolean` | no | Determines whether to compare differences in footnotes and endnotes between the two documents. |
| `CompareTextboxes` | body | `boolean` | no | Determines whether to assess differences in the information presented within text boxes between the two documents. |
| `CompareFields` | body | `boolean` | no | Determines whether to detect disparities in fields between the two documents. |
| `CompareComments` | body | `boolean` | no | Determines whether to evaluate distinctions in comments between the two documents. |
| `CompareMoves` | body | `boolean` | no | Indicates the name of the individual to credit for modifications when comparing the two documents. |
| `AcceptRevisions` | body | `boolean` | no | Specifies whether to accept revisions before document comparison. |
| `RevisionAuthor` | body | `string` | no | Author name who made revision. |
