# Convert JPG to PDF with ConvertAPI

Converts a JPG file to PDF with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/jpg/to/pdf`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Convert JPG to PDF](https://www.convertapi.com/jpg-to-pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Rotate` | body | `number` | no | Rotate the image by a specified degree. For automatic rotation using EXIF data in TIFF and JPEG images, leave this property empty. |
| `ColorSpace` | body | `list<string>` | no | Set image color space. Accepted values: `cmyk`, `default`, `gray`, `rgb`, `srgb`. |
| `ColorProfile` | body | `list<string>` | no | Set image color profile. Some profiles will override the ColorSpace property. Accepted values: `default`, `isocoatedv2`. |
| `MarginHorizontal` | body | `number` | no | Set the page horizontal margin in millimeters (mm). |
| `MarginVertical` | body | `number` | no | Set the page vertical margin in millimeters (mm). |
| `PageSize` | body | `list<string>` | no | The property scales each image to fit a given page size. Accepted values: `a0`, `a1`, `a10`, `a2`, `a3`, `a4`, `a5`, `a6`, `a7`, `a8`, `a9`, `default`, `legal`, `letter`. |
| `PageOrientation` | body | `list<string>` | no | Set page orientation. Works only with the PageSize property when it is set to a value other than the Image size. Accepted values: `default`, `landscape`, `portrait`. |
| `Pdfa` | body | `boolean` | no | Create PDF/A-1b compliant document. |
