# Convert PDF to TXT with ConvertAPI

Converts a PDF file to TXT with ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/pdf/to/txt`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Convert PDF to TXT](https://www.convertapi.com/pdf-to-txt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `Password` | body | `string` | no | Sets the password to open protected documents. |
| `PageRange` | body | `string` | no | Set page range. Example 1-10 or 1,2,5. |
| `OcrMode` | body | `list<string>` | no | Defines how OCR is applied during conversion. `Auto` performs OCR only when needed. `Force` applies OCR to all pages. `Never` disables OCR entirely. Accepted values: `auto`, `force`, `never`. |
| `OcrLanguage` | body | `list<string>` | no | Configure the OCR language for text recognition. If auto-detection fails, manually specify the language. Accepted values: `ar`, `auto`, `ca`, `da`, `de`, `el`, `en`, `es`, `fi`, `fr`, `it`, `ja`, `ko`, `nl`, `no`, `pl`, `pt`, `ro`, `ru`, `sl`, `sv`, `th`, `tr`, `ua`, `zh`. |
| `IncludeFormatting` | body | `boolean` | no | Persist formatting while extracting text. Only works when RemoveHeadersFooters and RemoveFootnotes properties are disabled. |
| `SplitPages` | body | `boolean` | no | Split each page to different result file. |
| `RemoveHeadersFooters` | body | `boolean` | no | Remove headers and footers from the document. |
| `RemoveFootnotes` | body | `boolean` | no | Remove footnotes from the document. |
| `RemoveTables` | body | `boolean` | no | Remove tables from the document. |
