# Compress PDF with ConvertAPI

Compresses a PDF to reduce file size in ConvertAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/convert/pdf/to/compress`
- **Base URL:** `https://v2.convertapi.com`
- **Official documentation:** [Compress PDF](https://www.convertapi.com/pdf-to-compress)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `File` | body | `file` | yes | File to be converted. Value can be URL or file content. |
| `Timeout` | body | `number` | no | Conversion timeout in seconds. |
| `FileName` | body | `string` | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |
| `Password` | body | `string` | no | Sets the password to open protected PDF. |
| `Preset` | body | `list<string>` | no | Choose a compression level from the available presets. If a preset is selected, all other compression options will be ignored. These presets are optimized for various use cases, such as balancing file size and quality. Accepted values: `archive`, `ebook`, `lossless`, `none`, `printer`, `text`, `web`. |
| `ImageResolution` | body | `number` | no | Set the maximum image resolution in DPI. |
| `ImageQuality` | body | `number` | no | Set image quality in percentage. |
| `UnembedBaseFonts` | body | `boolean` | no | Specifies whether to remove the base fonts from the PDF file. |
| `SubsetEmbeddedFonts` | body | `boolean` | no | Output PDF should only contain font characters utilized in the original document, and any unused glyphs from all fonts in the document should be removed. |
| `RemoveForms` | body | `boolean` | no | Remove PDF forms from the PDF file. |
| `RemoveDuplicates` | body | `boolean` | no | Remove duplicate fonts and color profiles from the PDF file. |
| `Optimize` | body | `boolean` | no | Optimize page content streams in the PDF file. |
| `RemovePieceInformation` | body | `boolean` | no | Remove piece information dictionaries like Adobe Illustrator or Photoshop private data. |
| `RemoveEmbeddedFiles` | body | `boolean` | no | Remove embedded/attachments files from the PDF file. |
| `RemoveStructureInformation` | body | `boolean` | no | Remove all structure information from the PDF document. |
| `RemoveMetadata` | body | `boolean` | no | Detach the XMP metadata embedded in the document from its catalog, clear all properties in all schemas, and remove metadata from marked content. |
| `RemoveUnusedResources` | body | `boolean` | no | Remove references to resources such as fonts, images, patterns. |
| `Linearize` | body | `boolean` | no | Linearize PDF file and optimize for fast Web View. |
| `PreservePdfa` | body | `boolean` | no | Preserve the PDF/A standard in the PDF file. |
