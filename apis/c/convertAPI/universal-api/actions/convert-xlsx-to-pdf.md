# ConvertAPI: Convert XLSX to PDF

Converts an XLSX file to PDF with ConvertAPI.

```
POST https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-xlsx-to-pdf
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ConvertAPI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-xlsx-to-pdf" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "file": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-xlsx-to-pdf', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "file": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | file | yes | File to be converted. Value can be URL or file content. |
| `timeout` | number | no | Conversion timeout in seconds. Default: `900`. |
| `fileName` | string | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `password` | string | no | Sets the password to open protected documents. |
| `worksheetActive` | boolean | no | Set to convert active worksheet. If value is set False all worksheet will be converted. Default: `false`. |
| `worksheetIndex` | number | no | Set worksheet index(number) to convert. If value is not set all worksheet will be converted. |
| `worksheetName` | string | no | Set worksheet name to convert. If value is not set all worksheet will be converted. |
| `convertMetadata` | boolean | no | Convert document metadata like Title, Author, Keywords to PDF metadata. Default: `true`. |
| `pageOrientation` | list<string> | no | Page orientation. One of: `default`, `landscape`, `portrait`. Default: `default`. |
| `pageSize` | list<string> | no | Page size. One of: `a3`, `a4`, `a4small`, `a5`, `b4`, `b5`, `default`, `executive`, `ledger`, `legal`, `letter`, `lettersmall`, `statement`, `tabloid`. Default: `default`. |
| `autoColumnFit` | boolean | no | Auto fit columns to reduce unnecessary empty space in table. Default: `false`. |
| `autoPageFit` | boolean | no | Automatically enlarges page size, switches to landscape when needed, trims margins, and finally scales the sheet to one-page width. If `PageSize` or `PageOrientation` are chosen, those choices are left unchanged. Default: `false`. |
| `clearPrintArea` | boolean | no | Clear the print area in the converting document. Default: `false`. |
| `scale` | number | no | Set content scale value in percentage. |
| `headerOnEachPage` | boolean | no | Ensures the header row is repeated on all pages when the sheet's content spans multiple pages in the PDF output. If a table is detected in the sheet, its header row is used; otherwise, the first row with data is treated as the header. Default: `false`. |
| `thousandsSeparator` | string | no | Thousands separator. Default: `,`. |
| `decimalSeparator` | string | no | Decimal separator. Default: `.`. |
| `dateFormat` | list<string> | no | Sets the date format for output document, overriding the default US locale (M/d/yyyy) to ensure consistency regardless of regional Excel settings. One of: `eu`, `german`, `iso`, `japanese`, `us`. Default: `us`. |
| `pdfa` | boolean | no | Create PDF/A-1b compliant document. Default: `false`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "fileExt": "string",
      "fileId": "string",
      "fileName": "Ava Chen",
      "fileSize": 1,
      "url": "https://example.com"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `fileExt` | string | Generated output file extension. |
| `fileId` | string | ConvertAPI file identifier for the generated output. |
| `fileName` | string | Generated output file name. |
| `fileSize` | number | Generated output file size in bytes. |
| `url` | string | Temporary secure download URL for the generated output file. |

## Native endpoint

Through the native ConvertAPI API, this operation is `POST /convert/xlsx/to/pdf` (base URL `https://v2.convertapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/convert-xlsx-to-pdf.md) for the provider-specific parameters and requirements.
