# ConvertAPI: Add Text Watermark to PDF

Adds a text watermark to a PDF with ConvertAPI.

```
POST https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/add-text-watermark-to-pdf
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ConvertAPI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/add-text-watermark-to-pdf" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "file": "string",
  "text": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/add-text-watermark-to-pdf', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "file": "string",
    "text": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | file | yes | File to be converted. Value can be URL or file content. |
| `timeout` | number | no | Conversion timeout in seconds. Default: `900`. |
| `fileName` | string | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `password` | string | no | Sets the password to open protected documents. |
| `text` | string | yes | Specifies the text to use as watermark. The list of supported variables: * ```%PAGE%``` - current page number * ```%PAGES%``` - total number of pages * ```%FILENAME%``` - name of the file * ```%WEEKDAY%``` - full weekday name * ```%WEEKDAY_SHORT%``` - abbreviated weekday name * ```%MONTH%``` - month number (1-12) * ```%MONTHNAME%``` - full month name * ```%MONTHNAME_SHORT%``` - abbreviated month name * ```%YEAR%``` - year with century (YYYY) * ```%YEAR_SHORT%``` - year without century (YY) * ```%DAY%``` - day of month * ```%DAY_YEAR%``` - day of the year (1 -366) * ```%HOUR%``` - hour (01- 12) * ```%HOURS%``` - hour (00-23) * ```%MINUTES%``` - minutes (00-59) * ```%SECONDS%``` - seconds (00-59) * ```%AMPM%``` - AM PM * ```%DATE%``` - local date representation * ```%TIME%``` - local time representation * ```%DATETIME%``` - local date and time * ```%AUTHOR%``` - document Author * ```%TITLE%``` - document Title * ```%SUBJECT%``` - document Subject * ```%KEYWORDS%``` - document Keywords * ```%N%``` - new line |
| `style` | list<string> | no | Specifies watermark style, stamp or watermark. The stamp is placed over page content and watermark under page content. One of: `stamp`, `watermark`. Default: `stamp`. |
| `fontSize` | number | no | Specifies the watermark font size. Default: `40`. |
| `textRenderingMode` | list<string> | no | Specifies the text rendering mode. One of: `fillstroke`, `filltext`, `invisible`, `stroketext`. Default: `fillstroke`. |
| `fontColor` | string | no | Specifies the watermark font color. |
| `strokeColor` | string | no | Specifies font stroke color. |
| `strokeWidth` | number | no | Specifies the stroke width. Default: `1`. |
| `fontName` | list<string> | no | Specifies the watermark font name. Contact us if you are looking for a specific font for a watermark that is missing from the list. One of: `arial`, `bahnschrift`, `calibri`, `cambria`, `consolas`, `constantia`, `courierNew`, `georgia`, `tahoma`, `timesNewRoman`, `verdana`. Default: `arial`. |
| `rotate` | number | no | Specifies the watermark rotation angle in degrees. Default: `0`. |
| `opacity` | number | no | Specifies watermark opacity level. Default: `100`. |
| `goToLink` | string | no | Specifies the web address to go when the watermark is clicked. |
| `goToPage` | string | no | Specifies the page number to go when the watermark is clicked. |
| `pageBox` | list<string> | no | Specifies the PDF page box used as the reference area for applying the watermark. One of: `bleedbox`, `cropbox`, `mediabox`, `trimbox`. Default: `mediabox`. |
| `horizontalAlignment` | list<string> | no | Specifies the horizontal watermark alignment. One of: `center`, `left`, `right`. Default: `center`. |
| `verticalAlignment` | list<string> | no | Specifies the vertical watermark alignment. One of: `bottom`, `center`, `top`. Default: `center`. |
| `measurementUnit` | list<string> | no | Measurement unit for position and size parameters. One of: `cm`, `in`, `mm`, `pt`. Default: `pt`. |
| `offsetX` | number | no | Specifies the watermark offset along the X-axis. Positive values move the watermark to the right, while negative values move it to the left, using the selected `MeasurementUnit`. |
| `offsetY` | number | no | Specifies the watermark offset along the Y-axis. Positive values move the watermark downward, while negative values move it upward, using the selected `MeasurementUnit`. |
| `width` | number | no | Specifies the width of the watermark text box in the selected `MeasurementUnit`. A value of `0` means the width is unspecified. Default: `0`. |
| `height` | number | no | Specifies the height of the watermark text box in the selected `MeasurementUnit`. A value of `0` means the height is unspecified. Default: `0`. |
| `lineSpacing` | number | no | Specifies the watermark text line spacing. Default: `0`. |
| `pageRange` | string | no | Set page range. Example 1-10 or 1,2,5. Default: `1-2000`. |
| `fontEmbed` | boolean | no | Specifies whether fonts should be embedded. Default: `true`. |
| `fontSubset` | boolean | no | Specifies whether fonts should be subset. Default: `true`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "fileExt": "string",
      "fileId": "string",
      "fileName": "Ava Chen",
      "fileSize": 1,
      "url": "https://example.com"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `fileExt` | string | Generated output file extension. |
| `fileId` | string | ConvertAPI file identifier for the generated output. |
| `fileName` | string | Generated output file name. |
| `fileSize` | number | Generated output file size in bytes. |
| `url` | string | Temporary secure download URL for the generated output file. |

## Native endpoint

Through the native ConvertAPI API, this operation is `POST /convert/pdf/to/text-watermark` (base URL `https://v2.convertapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/add-text-watermark-to-pdf.md) for the provider-specific parameters and requirements.
