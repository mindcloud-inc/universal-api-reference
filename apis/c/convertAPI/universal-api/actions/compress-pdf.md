# ConvertAPI: Compress PDF

Compresses a PDF to reduce file size in ConvertAPI.

```
POST https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compress-pdf
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ConvertAPI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compress-pdf" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "file": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compress-pdf', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "file": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | file | yes | File to be converted. Value can be URL or file content. |
| `timeout` | number | no | Conversion timeout in seconds. Default: `900`. |
| `fileName` | string | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `password` | string | no | Sets the password to open protected PDF. |
| `preset` | list<string> | no | Choose a compression level from the available presets. If a preset is selected, all other compression options will be ignored. These presets are optimized for various use cases, such as balancing file size and quality. One of: `archive`, `ebook`, `lossless`, `none`, `printer`, `text`, `web`. Default: `none`. |
| `imageResolution` | number | no | Set the maximum image resolution in DPI. Default: `150`. |
| `imageQuality` | number | no | Set image quality in percentage. Default: `80`. |
| `unembedBaseFonts` | boolean | no | Specifies whether to remove the base fonts from the PDF file. Default: `false`. |
| `subsetEmbeddedFonts` | boolean | no | Output PDF should only contain font characters utilized in the original document, and any unused glyphs from all fonts in the document should be removed. Default: `false`. |
| `removeForms` | boolean | no | Remove PDF forms from the PDF file. Default: `false`. |
| `removeDuplicates` | boolean | no | Remove duplicate fonts and color profiles from the PDF file. Default: `true`. |
| `optimize` | boolean | no | Optimize page content streams in the PDF file. Default: `true`. |
| `removePieceInformation` | boolean | no | Remove piece information dictionaries like Adobe Illustrator or Photoshop private data. Default: `true`. |
| `removeEmbeddedFiles` | boolean | no | Remove embedded/attachments files from the PDF file. Default: `true`. |
| `removeStructureInformation` | boolean | no | Remove all structure information from the PDF document. Default: `true`. |
| `removeMetadata` | boolean | no | Detach the XMP metadata embedded in the document from its catalog, clear all properties in all schemas, and remove metadata from marked content. Default: `true`. |
| `removeUnusedResources` | boolean | no | Remove references to resources such as fonts, images, patterns. Default: `true`. |
| `linearize` | boolean | no | Linearize PDF file and optimize for fast Web View. Default: `false`. |
| `preservePdfa` | boolean | no | Preserve the PDF/A standard in the PDF file. Default: `false`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "fileExt": "string",
      "fileId": "string",
      "fileName": "Ava Chen",
      "fileSize": 1,
      "url": "https://example.com"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `fileExt` | string | Generated output file extension. |
| `fileId` | string | ConvertAPI file identifier for the generated output. |
| `fileName` | string | Generated output file name. |
| `fileSize` | number | Generated output file size in bytes. |
| `url` | string | Temporary secure download URL for the generated output file. |

## Native endpoint

Through the native ConvertAPI API, this operation is `POST /convert/pdf/to/compress` (base URL `https://v2.convertapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/compress-pdf.md) for the provider-specific parameters and requirements.
