# ConvertAPI: Convert MSG to PDF

Converts an MSG email to PDF in ConvertAPI.

```
POST https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-msg-to-pdf
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ConvertAPI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-msg-to-pdf" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "file": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/convert-msg-to-pdf', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "file": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | file | yes | File to be converted. Value can be URL or file content. |
| `timeout` | number | no | Conversion timeout in seconds. Default: `900`. |
| `fileName` | string | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `convertHeader` | boolean | no | This property controls the inclusion of email header in the PDF conversion process. When set to `true`, the converter will incorporate the email's header information, such as **From**, **To**, **Subject**, **Date**, etc., into the generated PDF file. Default: `true`. |
| `convertAttachments` | boolean | no | Convert email attachments. Default: `false`. |
| `ignoreAttachmentErrors` | boolean | no | When enabled, attachment conversion errors are ignored and the email is still converted. This parameter is only used when `ConvertAttachments` is enabled. Default: `false`. |
| `merge` | boolean | no | Merge email body with attachments during the conversion process. Only works when `ConvertAttachments` property enabled. Default: `true`. |
| `pageOrientation` | list<string> | no | PDF page orientation. One of: `landscape`, `portrait`. Default: `portrait`. |
| `pageSize` | list<string> | no | PDF page size. One of: `a0`, `a1`, `a2`, `a3`, `a4`, `a5`, `a6`, `a7`, `a8`, `a9`, `b0`, `b1`, `b2`, `b3`, `b4`, `b5`, `ledger`, `legal`, `letter`. Default: `a4`. |
| `marginTop` | number | no | Set the page top margin in millimeters (mm). Default: `5`. |
| `marginRight` | number | no | Set the page right margin in millimeters (mm). Default: `5`. |
| `marginBottom` | number | no | Set the page bottom margin in millimeters (mm). Default: `5`. |
| `marginLeft` | number | no | Set the page left margin in millimeters (mm). Default: `5`. |
| `pdfa` | boolean | no | Create PDF/A-1b compliant document. Default: `false`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "fileExt": "string",
      "fileId": "string",
      "fileName": "Ava Chen",
      "fileSize": 1,
      "url": "https://example.com"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `fileExt` | string | Generated output file extension. |
| `fileId` | string | ConvertAPI file identifier for the generated output. |
| `fileName` | string | Generated output file name. |
| `fileSize` | number | Generated output file size in bytes. |
| `url` | string | Temporary secure download URL for the generated output file. |

## Native endpoint

Through the native ConvertAPI API, this operation is `POST /convert/msg/to/pdf` (base URL `https://v2.convertapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/convert-msg-to-pdf.md) for the provider-specific parameters and requirements.
