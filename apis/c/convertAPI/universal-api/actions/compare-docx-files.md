# ConvertAPI: Compare DOCX Files

Compares DOCX files and highlights differences in ConvertAPI.

```
POST https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compare-docx-files
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a ConvertAPI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compare-docx-files" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "file": "string",
  "compareFile": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/convertAPI/latest/actions/compare-docx-files', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "file": "string",
    "compareFile": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `file` | file | yes | File to be converted. Value can be URL or file content. |
| `timeout` | number | no | Conversion timeout in seconds. Default: `900`. |
| `compareFile` | file | yes | Specifies the Word document with which the specified document is compared. |
| `fileName` | string | no | The `FileName` property defines the name of the output file(s) generated by the file conversion API, ensuring safe and unique file naming. It sanitizes input filenames to remove potentially harmful characters, automatically appends the correct file extension based on the target format, and includes an indexing feature to distinguish multiple output files from a single input. For example, converting `report.docx` to PDF format might result in `report.pdf` for a single file, or `report_0.pdf`, `report_1.pdf` for multiple files, ensuring each output file is uniquely identifiable. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `password` | string | no | Sets the password to open protected documents. |
| `compareLevel` | list<string> | no | The property defines the granularity of comparisons between documents or text segments. It determines the precision of the comparison process, allowing users to specify whether differences are identified based on larger text blocks, such as words or sentences, or at a more detailed level, such as characters or formatting. One of: `Character`, `Word`. Default: `Word`. |
| `compareFormatting` | boolean | no | Determines whether to indicate variations in formatting between the two documents. Default: `true`. |
| `compareCaseChanges` | boolean | no | Determines whether to highlight discrepancies in capitalization between the two documents. Default: `true`. |
| `compareWhitespace` | boolean | no | Determines whether to identify dissimilarities in whitespace, such as gaps or paragraphs, between the two documents. Default: `true`. |
| `compareTables` | boolean | no | Determines whether to evaluate variations in the information presented within tables between the two documents. Default: `true`. |
| `compareHeaders` | boolean | no | Determines whether to contrast divergences in headers and footers between the two documents. Default: `true`. |
| `compareFootnotes` | boolean | no | Determines whether to compare differences in footnotes and endnotes between the two documents. Default: `true`. |
| `compareTextboxes` | boolean | no | Determines whether to assess differences in the information presented within text boxes between the two documents. Default: `true`. |
| `compareFields` | boolean | no | Determines whether to detect disparities in fields between the two documents. Default: `true`. |
| `compareComments` | boolean | no | Determines whether to evaluate distinctions in comments between the two documents. Default: `true`. |
| `compareMoves` | boolean | no | Indicates the name of the individual to credit for modifications when comparing the two documents. Default: `true`. |
| `acceptRevisions` | boolean | no | Specifies whether to accept revisions before document comparison. Default: `false`. |
| `revisionAuthor` | string | no | Author name who made revision. Default: `Compared using ConvertAPI`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "fileExt": "string",
      "fileId": "string",
      "fileName": "Ava Chen",
      "fileSize": 1,
      "url": "https://example.com"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `fileExt` | string | Generated output file extension. |
| `fileId` | string | ConvertAPI file identifier for the generated output. |
| `fileName` | string | Generated output file name. |
| `fileSize` | number | Generated output file size in bytes. |
| `url` | string | Temporary secure download URL for the generated output file. |

## Native endpoint

Through the native ConvertAPI API, this operation is `POST /convert/docx/to/compare` (base URL `https://v2.convertapi.com`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/compare-docx-files.md) for the provider-specific parameters and requirements.
