# Delete Segment with Campaign Monitor

Deletes an existing segment from Campaign Monitor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segments/:segmentId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete Segment](https://www.campaignmonitor.com/api/v3-3/segments/#deleting-a-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Campaign Monitor segment identifier. |
