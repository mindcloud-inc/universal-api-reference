# Get Client Details with Campaign Monitor

Retrieves details for a Campaign Monitor client.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get Client Details](https://www.campaignmonitor.com/api/v3-3/clients/#getting-clients-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | Campaign Monitor client identifier. |
