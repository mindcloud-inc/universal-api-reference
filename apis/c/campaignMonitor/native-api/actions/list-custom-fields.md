# List Custom Fields with Campaign Monitor

Retrieves custom fields for a Campaign Monitor list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/customfields.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Custom Fields](https://www.campaignmonitor.com/api/v3-3/lists/#list-custom-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Campaign Monitor list identifier. |
