# Get List Stats with Campaign Monitor

Retrieves statistics for a Campaign Monitor list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/stats.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get List Stats](https://www.campaignmonitor.com/api/v3-3/lists/#list-stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Campaign Monitor list identifier. |
