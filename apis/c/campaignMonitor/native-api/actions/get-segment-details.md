# Get Segment Details with Campaign Monitor

Retrieves details for a Campaign Monitor segment.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:segmentId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get Segment Details](https://www.campaignmonitor.com/api/v3-3/segments/#getting-segments-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segmentId` | path | `string` | yes | Campaign Monitor segment identifier. |
