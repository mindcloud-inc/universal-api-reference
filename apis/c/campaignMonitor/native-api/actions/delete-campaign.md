# Delete Campaign with Campaign Monitor

Deletes an existing campaign from Campaign Monitor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/:campaignId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete Campaign](https://www.campaignmonitor.com/api/v3-3/campaigns/#deleting-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | yes | Campaign Monitor campaign identifier. |
