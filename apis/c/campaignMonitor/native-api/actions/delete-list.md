# Delete List with Campaign Monitor

Deletes an existing list from Campaign Monitor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:listId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete List](https://www.campaignmonitor.com/api/v3-3/lists/#deleting-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Campaign Monitor list identifier. |
