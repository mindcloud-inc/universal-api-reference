# List Deleted Subscribers with Campaign Monitor

Retrieves deleted subscribers from a Campaign Monitor list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/deleted.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Deleted Subscribers](https://www.campaignmonitor.com/api/v3-3/lists/#deleted-subscribers-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Campaign Monitor list identifier. |
