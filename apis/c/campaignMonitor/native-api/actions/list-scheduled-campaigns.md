# List Scheduled Campaigns with Campaign Monitor

Retrieves scheduled campaigns for a Campaign Monitor client.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/scheduled.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Scheduled Campaigns](https://www.campaignmonitor.com/api/v3-3/clients/#getting-scheduled-campaigns-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | Campaign Monitor client identifier. |
