# List Templates with Campaign Monitor

Retrieves templates for a Campaign Monitor client.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/templates.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Templates](https://www.campaignmonitor.com/api/v3-3/clients/#getting-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | Campaign Monitor client identifier. |
