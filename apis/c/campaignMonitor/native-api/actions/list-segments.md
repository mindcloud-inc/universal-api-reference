# List Segments with Campaign Monitor

Retrieves segments for a Campaign Monitor client.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/segments.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Segments](https://www.campaignmonitor.com/api/v3-3/clients/#getting-segments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | Campaign Monitor client identifier. |
