# Get List Details with Campaign Monitor

Retrieves details for a Campaign Monitor list.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get List Details](https://www.campaignmonitor.com/api/v3-3/lists/#list-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `string` | yes | Campaign Monitor list identifier. |
