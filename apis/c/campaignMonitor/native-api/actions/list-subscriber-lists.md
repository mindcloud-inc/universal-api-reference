# List Subscriber Lists with Campaign Monitor

Retrieves subscriber lists for a Campaign Monitor client.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/lists.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Subscriber Lists](https://www.campaignmonitor.com/api/v3-3/clients/#getting-subscriber-lists)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | yes | Campaign Monitor client identifier. |
