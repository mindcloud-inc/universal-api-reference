# Get Current User with CalendarLink

Retrieves the current user from CalendarLink.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://my.calendarlink.com/api/v1`
- **Official documentation:** [Get Current User](https://api.swaggerhub.com/apis/Calendarlink/calendarlink/1.0.3)
