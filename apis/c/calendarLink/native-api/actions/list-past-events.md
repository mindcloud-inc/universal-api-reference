# List Past Events with CalendarLink

Retrieves past events from a CalendarLink organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/:organisation/event/past`
- **Base URL:** `https://my.calendarlink.com/api/v1`
- **Official documentation:** [List Past Events](https://api.swaggerhub.com/apis/Calendarlink/calendarlink/1.0.3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organisation` | path | `string` | yes | CalendarLink organization ID. |
