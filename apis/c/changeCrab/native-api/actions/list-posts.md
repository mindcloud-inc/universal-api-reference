# List Posts with ChangeCrab

Retrieves posts for a changelog from ChangeCrab.

## Endpoint

- **Method:** `GET`
- **Path:** `/changelogs/:id/posts`
- **Base URL:** `https://changecrab.com/api`
- **Official documentation:** [List Posts](https://changecrab.com/knowledge-base/integrations/api-manage-posts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ChangeCrab changelog access ID. |
