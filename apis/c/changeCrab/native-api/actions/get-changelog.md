# Get Changelog with ChangeCrab

Retrieves a changelog from ChangeCrab.

## Endpoint

- **Method:** `GET`
- **Path:** `/changelogs/:id`
- **Base URL:** `https://changecrab.com/api`
- **Official documentation:** [Get Changelog](https://changecrab.com/knowledge-base/integrations/api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ChangeCrab changelog access ID. |
