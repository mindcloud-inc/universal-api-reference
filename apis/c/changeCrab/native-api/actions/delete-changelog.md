# Delete Changelog with ChangeCrab

Deletes an existing changelog from ChangeCrab.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/changelogs/:id`
- **Base URL:** `https://changecrab.com/api`
- **Official documentation:** [Delete Changelog](https://changecrab.com/knowledge-base/integrations/api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ChangeCrab changelog access ID. |
