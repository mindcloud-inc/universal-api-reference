# Update Changelog with ChangeCrab

Updates an existing changelog in ChangeCrab.

## Endpoint

- **Method:** `PUT`
- **Path:** `/changelogs/:id`
- **Base URL:** `https://changecrab.com/api`
- **Official documentation:** [Update Changelog](https://changecrab.com/knowledge-base/integrations/api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ChangeCrab changelog access ID. |
