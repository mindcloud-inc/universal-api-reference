# Get AI Edit Generation Result with Claid AI

Retrieves an AI image edit result from Claid AI.

## Endpoint

- **Method:** `GET`
- **Path:** `image/ai-edit/:ai_edit_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Get AI Edit Generation Result](https://docs.claid.ai/image-ai-edit-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ai_edit_id` | path | `number` | yes |
