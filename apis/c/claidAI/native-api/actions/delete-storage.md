# Delete Storage with Claid AI

Deletes a storage connector from Claid AI by storage ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `storage/storages/:storage_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Delete Storage](https://docs.claid.ai/storage-connectors/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `storage_id` | path | `number` | yes |
