# Get Batch Image Edit Results with Claid AI

Retrieves batch image edit results from Claid AI.

## Endpoint

- **Method:** `GET`
- **Path:** `image/edit/batch/:task_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Get Batch Image Edit Results](https://docs.claid.ai/image-editing-api/batch-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `number` | yes |
