# Create Scene with Claid AI

Creates a scene in Claid AI.

## Endpoint

- **Method:** `POST`
- **Path:** `scene/create`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Create Scene](https://docs.claid.ai/ai-background-api/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `object` | body | `object` | yes |
| `output` | body | `string` | no |
| `scene` | body | `object` | yes |
