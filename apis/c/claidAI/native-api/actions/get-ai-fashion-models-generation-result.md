# Get AI Fashion Models Generation Result with Claid AI

Retrieves an AI fashion model result from Claid AI.

## Endpoint

- **Method:** `GET`
- **Path:** `image/ai-fashion-models/:processing_request_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Get AI Fashion Models Generation Result](https://docs.claid.ai/ai-fashion-models-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `processing_request_id` | path | `number` | yes |
