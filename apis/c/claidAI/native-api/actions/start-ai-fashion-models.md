# Start AI Fashion Models with Claid AI

Starts AI fashion model generation in Claid AI.

## Endpoint

- **Method:** `POST`
- **Path:** `image/ai-fashion-models`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Start AI Fashion Models](https://docs.claid.ai/ai-fashion-models-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | body | `object` | yes |
| `options` | body | `object` | yes |
| `output` | body | `string` | no |
