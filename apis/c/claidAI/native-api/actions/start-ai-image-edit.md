# Start AI Image Edit with Claid AI

Starts an AI image edit in Claid AI.

## Endpoint

- **Method:** `POST`
- **Path:** `image/ai-edit`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Start AI Image Edit](https://docs.claid.ai/image-ai-edit-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | body | `string` | yes |
| `options` | body | `object` | yes |
| `output` | body | `string` | no |
