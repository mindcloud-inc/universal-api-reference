# Get Video Generation Status with Claid AI

Retrieves a video generation result from Claid AI.

## Endpoint

- **Method:** `GET`
- **Path:** `video/generate/:animation_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Get Video Generation Status](https://docs.claid.ai/image-to-video-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `animation_id` | path | `number` | yes |
