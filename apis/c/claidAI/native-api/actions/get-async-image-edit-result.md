# Get Async Image Edit Result with Claid AI

Retrieves an asynchronous image edit result from Claid AI.

## Endpoint

- **Method:** `GET`
- **Path:** `image/edit/async/:task_id`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Get Async Image Edit Result](https://docs.claid.ai/image-editing-api/async-api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `number` | yes |
