# Generate Image with Claid AI

Creates a generated image in Claid AI.

## Endpoint

- **Method:** `POST`
- **Path:** `image/generate`
- **Base URL:** `https://api.claid.ai/v1`
- **Official documentation:** [Generate Image](https://docs.claid.ai/image-generation-api/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `input` | body | `string` | yes |
| `options` | body | `object` | no |
| `output` | body | `string` | no |
