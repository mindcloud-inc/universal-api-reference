# Get Inventory Model with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/inventory_models/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Inventory Model](https://docs.commercelayer.io/core-api-reference/inventory_models/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the inventory model to retrieve. |
