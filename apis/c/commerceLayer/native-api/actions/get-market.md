# Get Market with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/markets/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Market](https://docs.commercelayer.io/core-api-reference/markets/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the market to retrieve. |
