# Get Tax Category with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tax_categories/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Tax Category](https://docs.commercelayer.io/core-api-reference/tax_categories/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tax category ID to retrieve. |
