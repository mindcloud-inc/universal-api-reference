# Get Merchant with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/merchants/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Merchant](https://docs.commercelayer.io/core-api-reference/merchants/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the merchant to retrieve. |
