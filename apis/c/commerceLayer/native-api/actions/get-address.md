# Get Address with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/addresses/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Address](https://docs.commercelayer.io/core-api-reference/addresses/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the address to retrieve. |
