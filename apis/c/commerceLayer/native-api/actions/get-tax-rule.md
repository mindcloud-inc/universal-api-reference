# Get Tax Rule with Commerce Layer

- **Method:** `GET`
- **Path:** `/api/tax_rules/:id`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tax rule ID to retrieve. |
