# Get Price List with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/price_lists/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Price List](https://docs.commercelayer.io/core-api-reference/price_lists/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the price list to retrieve. |
