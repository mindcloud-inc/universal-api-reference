# Delete Merchant with Commerce Layer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/merchants/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Delete Merchant](https://docs.commercelayer.io/core-api-reference/merchants/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The merchant ID to delete. |
