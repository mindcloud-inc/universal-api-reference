# Delete Market with Commerce Layer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/markets/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Delete Market](https://docs.commercelayer.io/core-api-reference/markets/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The market ID to delete. |
