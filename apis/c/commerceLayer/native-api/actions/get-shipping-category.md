# Get Shipping Category with Commerce Layer

## Endpoint

- **Method:** `GET`
- **Path:** `/api/shipping_categories/:id`
- **Base URL:** `{coreApiEndpoint}`
- **Official documentation:** [Get Shipping Category](https://docs.commercelayer.io/core-api-reference/shipping_categories/retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The shipping category ID to retrieve. |
