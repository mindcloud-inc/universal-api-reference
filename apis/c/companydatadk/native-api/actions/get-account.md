# Get Account with companydata.dk

Retrieves API key account details from companydata.dk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/account`
- **Base URL:** `https://api.companydata.dk`
- **Official documentation:** [Get Account](https://api.companydata.dk/v1/docs#tag/Account/operation/get_account_v1_account_get)
