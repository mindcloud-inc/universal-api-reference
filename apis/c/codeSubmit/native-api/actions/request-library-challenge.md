# Request Library Challenge with CodeSubmit

- **Path:** `/api/external/library_templates/request_challenge`
- **Base URL:** `https://app.codesubmit.io`
- **Official documentation:** [Request Library Challenge](https://www.codesubmit.io/integrations/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content` | body | `string` | no | Requested challenge description |
