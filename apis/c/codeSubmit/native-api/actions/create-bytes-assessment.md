# Create Bytes Assessment with CodeSubmit

## Endpoint

- **Method:** `POST`
- **Path:** `/api/external/tests/byte`
- **Base URL:** `https://app.codesubmit.io`
- **Official documentation:** [Create Bytes Assessment](https://www.codesubmit.io/integrations/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | body | `string` | no | Programming language |
| `name` | body | `string` | no | Bytes assessment name |
| `role` | body | `string` | no | Bytes assessment role |
