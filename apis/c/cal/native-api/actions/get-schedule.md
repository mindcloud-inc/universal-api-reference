# Get Schedule with Cal.com

Retrieves a schedule from Cal.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/:scheduleId`
- **Base URL:** `https://api.cal.com/v2`
- **Official documentation:** [Get Schedule](https://cal.com/docs/api-reference/v2/schedules/get-a-schedule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scheduleId` | path | `list` | yes | Schedule identifier from Cal.com path parameter. |
