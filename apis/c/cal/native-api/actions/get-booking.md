# Get Booking with Cal.com

Retrieves a booking from Cal.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/:bookingUid`
- **Base URL:** `https://api.cal.com/v2`
- **Official documentation:** [Get Booking](https://cal.com/docs/api-reference/v2/bookings/get-a-booking)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bookingUid` | path | `list` | yes | Booking identifier from Cal.com path parameter. |
