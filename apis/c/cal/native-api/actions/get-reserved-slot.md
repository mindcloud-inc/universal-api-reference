# Get Reserved Slot with Cal.com

Retrieves a reserved slot from Cal.com.

## Endpoint

- **Method:** `GET`
- **Path:** `/slots/reservations/:uid`
- **Base URL:** `https://api.cal.com/v2`
- **Official documentation:** [Get Reserved Slot](https://cal.com/docs/api-reference/v2/slots/get-reserved-slot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | Reservation UID from Cal.com path parameter. |
