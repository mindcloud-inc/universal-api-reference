# Delete Schedule with Cal.com

Deletes a schedule from Cal.com.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schedules/:scheduleId`
- **Base URL:** `https://api.cal.com/v2`
- **Official documentation:** [Delete Schedule](https://cal.com/docs/api-reference/v2/schedules/delete-a-schedule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scheduleId` | path | `list` | yes | Schedule identifier from Cal.com path parameter. |
