# Delete Event Type with Cal.com

Deletes an event type from Cal.com.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/event-types/:eventTypeId`
- **Base URL:** `https://api.cal.com/v2`
- **Official documentation:** [Delete Event Type](https://cal.com/docs/api-reference/v2/event-types/delete-an-event-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventTypeId` | path | `list` | yes | Event type identifier from Cal.com path parameter. |
