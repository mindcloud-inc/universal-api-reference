# Basic Next Working Day with Calculate Working Day

Retrieves the next Monday-to-Friday working day.

## Endpoint

- **Method:** `GET`
- **Path:** `/basicNextWorkingDay/`
- **Base URL:** `https://api.mightora.io/calculate-working-day`
- **Official documentation:** [Basic Next Working Day](https://learn.microsoft.com/en-gb/connectors/calculateworkingday/#basic-next-working-day)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | query | `date` | yes | Input date in YYYY-MM-DD format. |
