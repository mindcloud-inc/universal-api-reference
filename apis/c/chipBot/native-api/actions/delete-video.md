# Delete Video with ChipBot

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/connect/accounts/:accountId/domains/:domainId/video-exp/:videoExpId`
- **Base URL:** `https://getchipbot.com`
- **Official documentation:** [Delete Video](https://getchipbot.com/api-docs/video-exp/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoExpId` | path | `string` | yes | The video experience identifier, for example videxp_xxx. |
