# Get Detailed Unique Hits Report with ChipBot

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/connect/accounts/:accountId/domains/:domainId/reporting/analytics/unique-hits/detailed`
- **Base URL:** `https://getchipbot.com`
- **Official documentation:** [Get Detailed Unique Hits Report](https://getchipbot.com/api-docs/general/unique-hits-report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `endDate` | query | `string` | yes | The report end date in YYYY-MM-DD format. |
| `startDate` | query | `string` | yes | The report start date in YYYY-MM-DD format. |
