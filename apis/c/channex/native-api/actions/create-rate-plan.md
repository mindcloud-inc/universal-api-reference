# Create Rate Plan with Channex

Creates a rate plan in Channex.

## Endpoint

- **Method:** `POST`
- **Path:** `/rate_plans`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Create Rate Plan](https://docs.channex.io/api-v.1-documentation/rate-plans-collection#create-rate-plan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rate_plan` | body | `object` | yes | Top-level rate_plan payload object documented by Channex for rate plan creation. |
