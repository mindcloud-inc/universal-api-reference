# Get Property with Channex

Retrieves an existing property from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Get Property](https://docs.channex.io/api-v.1-documentation/hotels-collection#get-property-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the property to retrieve. |
