# List Webhooks with Channex

Retrieves webhooks from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Webhooks](https://docs.channex.io/api-v.1-documentation/webhook-collection#webhooks-list)
