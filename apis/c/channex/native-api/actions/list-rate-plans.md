# List Rate Plans with Channex

Retrieves rate plans from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/rate_plans`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Rate Plans](https://docs.channex.io/api-v.1-documentation/rate-plans-collection#rate-plans-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
