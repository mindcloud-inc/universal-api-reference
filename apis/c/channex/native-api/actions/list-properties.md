# List Properties with Channex

Retrieves properties from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Properties](https://docs.channex.io/api-v.1-documentation/hotels-collection#properties-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
