# Create Property with Channex

Creates a new property in Channex.

## Endpoint

- **Method:** `POST`
- **Path:** `/properties`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Create Property](https://docs.channex.io/api-v.1-documentation/hotels-collection#create-property)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `property` | body | `object` | yes | Top-level property payload object documented by Channex for property creation. |
