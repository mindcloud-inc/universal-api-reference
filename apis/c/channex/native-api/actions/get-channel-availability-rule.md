# Get Channel Availability Rule with Channex

Retrieves a channel availability rule from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/channel_availability_rules/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Get Channel Availability Rule](https://docs.channex.io/api-v.1-documentation/availability-rules-collection#get-availability-rule-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the channel availability rule to retrieve. |
