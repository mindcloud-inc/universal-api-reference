# List Property Options with Channex

Retrieves property options from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/options`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Property Options](https://docs.channex.io/api-v.1-documentation/hotels-collection#property-options)
