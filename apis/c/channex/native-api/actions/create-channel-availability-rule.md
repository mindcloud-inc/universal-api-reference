# Create Channel Availability Rule with Channex

Creates a channel availability rule in Channex.

## Endpoint

- **Method:** `POST`
- **Path:** `/channel_availability_rules`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Create Channel Availability Rule](https://docs.channex.io/api-v.1-documentation/availability-rules-collection#create-availability-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_availability_rule` | body | `object` | yes | Top-level channel_availability_rule payload object documented by Channex for rule creation. |
