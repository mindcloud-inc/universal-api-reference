# Get Rate Plan with Channex

Retrieves a rate plan from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/rate_plans/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Get Rate Plan](https://docs.channex.io/api-v.1-documentation/rate-plans-collection#get-rate-plan-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the rate plan to retrieve. |
