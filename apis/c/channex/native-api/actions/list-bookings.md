# List Bookings with Channex

Retrieves bookings from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Bookings](https://docs.channex.io/api-v.1-documentation/bookings-collection#bookings-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
