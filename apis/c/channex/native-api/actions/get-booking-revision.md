# Get Booking Revision with Channex

Retrieves a booking revision from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking_revisions/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Get Booking Revision](https://docs.channex.io/api-v.1-documentation/bookings-collection#get-booking-revision-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the booking revision to retrieve. |
