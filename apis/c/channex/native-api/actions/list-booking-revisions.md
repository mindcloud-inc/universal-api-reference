# List Booking Revisions with Channex

Retrieves booking revisions from your Channex account.

## Endpoint

- **Method:** `GET`
- **Path:** `/booking_revisions`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Booking Revisions](https://docs.channex.io/api-v.1-documentation/bookings-collection#booking-revisions-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
