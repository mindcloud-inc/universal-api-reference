# List Room Type Options with Channex

Retrieves room type options from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/room_types/options`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [List Room Type Options](https://docs.channex.io/api-v.1-documentation/room-types-collection#room-type-options)
