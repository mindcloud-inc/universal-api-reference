# Get Room Type with Channex

Retrieves a room type from Channex.

## Endpoint

- **Method:** `GET`
- **Path:** `/room_types/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Get Room Type](https://docs.channex.io/api-v.1-documentation/room-types-collection#get-room-type-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the room type to retrieve. |
