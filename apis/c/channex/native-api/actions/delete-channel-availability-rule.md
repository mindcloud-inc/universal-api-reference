# Delete Channel Availability Rule with Channex

Deletes a channel availability rule from Channex.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/channel_availability_rules/:id`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Delete Channel Availability Rule](https://docs.channex.io/api-v.1-documentation/availability-rules-collection#remove-availability-rule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the channel availability rule to delete. |
