# Create Room Type with Channex

Creates a room type in Channex.

## Endpoint

- **Method:** `POST`
- **Path:** `/room_types`
- **Base URL:** `https://staging.channex.io/api/v1`
- **Official documentation:** [Create Room Type](https://docs.channex.io/api-v.1-documentation/room-types-collection#create-room-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room_type` | body | `object` | yes | Top-level room_type payload object documented by Channex for room type creation. |
