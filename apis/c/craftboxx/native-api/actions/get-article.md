# Get Article with Craftboxx

Returns a specific article from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `articles/:articleId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Article](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `articleId` | path | `number` | yes | The Craftboxx article ID. |
