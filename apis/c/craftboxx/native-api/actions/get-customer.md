# Get Customer with Craftboxx

Returns a specific customer from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `customers/:customerId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Customer](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | The Craftboxx customer ID. |
