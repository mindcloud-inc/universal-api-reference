# List Employees with Craftboxx

Returns employees from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `employees`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Employees](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search employees by a broad Craftboxx query string. |
