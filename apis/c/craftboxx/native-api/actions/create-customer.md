# Create Customer with Craftboxx

Creates a customer in Craftboxx.

## Endpoint

- **Method:** `POST`
- **Path:** `customers`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Create Customer](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The customer name. |
