# Get Employee with Craftboxx

Returns a specific employee from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `employees/:employeeId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Employee](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employeeId` | path | `number` | yes | The Craftboxx employee ID. |
