# List Articles with Craftboxx

Returns articles from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `articles`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Articles](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search articles by a broad Craftboxx query string. |
