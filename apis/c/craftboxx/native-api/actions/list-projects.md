# List Projects with Craftboxx

Returns projects from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `projects`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Projects](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search projects by a broad Craftboxx query string. |
