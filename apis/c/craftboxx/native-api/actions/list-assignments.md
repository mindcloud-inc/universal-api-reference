# List Assignments with Craftboxx

Returns assignments from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `assignments`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Assignments](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search assignments by a broad Craftboxx query string. |
