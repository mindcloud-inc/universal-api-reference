# List Timesheets with Craftboxx

Returns timesheets from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `timesheets`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Timesheets](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
