# Get Project with Craftboxx

Returns a specific project from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Project](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The Craftboxx project ID. |
