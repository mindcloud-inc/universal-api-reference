# Get Assignment with Craftboxx

Returns a specific assignment from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `assignments/:assignmentId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Assignment](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assignmentId` | path | `number` | yes | The Craftboxx assignment ID. |
