# Create Access Token with Craftboxx

Creates and returns a Craftboxx access token.

## Endpoint

- **Method:** `POST`
- **Path:** `auth/create-token`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Create Access Token](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Craftboxx employee email address. |
