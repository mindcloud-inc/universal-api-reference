# Get Timesheet with Craftboxx

Returns a specific timesheet from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `timesheets/:timesheetId`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [Get Timesheet](https://api.craftboxx.de/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `timesheetId` | path | `number` | yes | The Craftboxx timesheet ID. |
