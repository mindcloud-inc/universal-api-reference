# List Customers with Craftboxx

Returns customers from Craftboxx.

## Endpoint

- **Method:** `GET`
- **Path:** `customers`
- **Base URL:** `https://api.craftboxx.de`
- **Official documentation:** [List Customers](https://api.craftboxx.de/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search customers by a broad Craftboxx query string. |
