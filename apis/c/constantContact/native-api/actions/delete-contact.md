# Delete Contact with Constant Contact

Deletes a contact from Constant Contact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Delete Contact](https://developer.constantcontact.com/api_guide/contacts_delete.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Unique ID of the contact to delete. |
