# Delete Contact List with Constant Contact

Deletes a contact list from Constant Contact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact_lists/:list_id`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Delete Contact List](https://developer.constantcontact.com/api_guide/lists_delete.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | Unique ID of the list to delete. |
