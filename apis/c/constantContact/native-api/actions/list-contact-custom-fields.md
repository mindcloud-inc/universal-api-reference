# List Contact Custom Fields with Constant Contact

Retrieves contact custom fields from Constant Contact.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact_custom_fields`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [List Contact Custom Fields](https://developer.constantcontact.com/api_guide/get_custom_fields.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Number of results per page (1-100). |
