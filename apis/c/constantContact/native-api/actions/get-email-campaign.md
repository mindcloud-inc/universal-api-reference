# Get Email Campaign with Constant Contact

Retrieves an email campaign from Constant Contact.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:campaign_id`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Get Email Campaign](https://developer.constantcontact.com/api_guide/email_campaign_id.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The UUID that uniquely identifies the email campaign. |
