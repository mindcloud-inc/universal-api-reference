# Get Email Campaign Summary Report with Constant Contact

Retrieves an email campaign summary report from Constant Contact.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/summary_reports/email_campaign_summaries`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Get Email Campaign Summary Report](https://developer.constantcontact.com/api_guide/email_bulk_campaign_summary_report.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Number of summary records per page (max 500). |
