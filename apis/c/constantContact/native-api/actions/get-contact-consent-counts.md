# Get Contact Consent Counts with Constant Contact

Retrieves contact consent counts from Constant Contact.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/counts`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Get Contact Consent Counts](https://developer.constantcontact.com/api_guide/contacts_counts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Include optional count detail (for example `new_subscriber`). |
