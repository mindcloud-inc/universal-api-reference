# Delete Email Campaign with Constant Contact

Deletes an email campaign from Constant Contact.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/emails/:campaign_id`
- **Base URL:** `https://api.cc.email/v3`
- **Official documentation:** [Delete Email Campaign](https://developer.constantcontact.com/api_guide/email_campaigns_delete.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | The unique identifier for the email campaign to delete. |
