# Get File with Cognito Forms

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/entries/:entryId/files/:fileId`
- **Base URL:** `https://www.cognitoforms.com/api`
- **Official documentation:** [Get File](https://www.cognitoforms.com/support/476/data-integration/cognito-forms-api/rest-api-reference#tag/entries/get/forms/{formId}/entries/{entryId}/files/{fileId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
| `entryId` | path | `string` | yes |
| `fileId` | path | `string` | yes |
