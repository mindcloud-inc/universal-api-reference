# Get Import Status with Cognito Forms

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/import-status/:importId`
- **Base URL:** `https://www.cognitoforms.com/api`
- **Official documentation:** [Get Import Status](https://www.cognitoforms.com/support/476/data-integration/cognito-forms-api/rest-api-reference#tag/entries/get/forms/{formId}/import-status/{importId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
| `importId` | path | `string` | yes |
