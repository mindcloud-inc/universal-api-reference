# Get Document with Cognito Forms

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/entries/:entryId/documents/:templateId`
- **Base URL:** `https://www.cognitoforms.com/api`
- **Official documentation:** [Get Document](https://www.cognitoforms.com/support/476/data-integration/cognito-forms-api/rest-api-reference#tag/entries/get/forms/{formId}/entries/{entryId}/documents/{templateId})

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `string` | yes |
| `entryId` | path | `string` | yes |
| `templateId` | path | `string` | yes |
