# Create Segment with ChatBot

Creates a new user segment in ChatBot.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/segments`
- **Base URL:** `https://api.chatbot.com`
- **Official documentation:** [Create Segment](https://www.chatbot.com/docs/users-segments/#create-segment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Segment name. |
