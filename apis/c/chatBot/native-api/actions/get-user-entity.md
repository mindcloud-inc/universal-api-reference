# Get User Entity with ChatBot

Retrieves user entity details from ChatBot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:ID`
- **Base URL:** `https://api.chatbot.com`
- **Official documentation:** [Get User Entity](https://www.chatbot.com/docs/user-entities/#get-single-entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ID` | path | `string` | yes | ChatBot entity id. |
