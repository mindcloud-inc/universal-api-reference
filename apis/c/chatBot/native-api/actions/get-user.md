# Get User with ChatBot

Retrieves user details from ChatBot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.chatbot.com`
- **Official documentation:** [Get User](https://www.chatbot.com/docs/users/#list-single-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The required ChatBot user ID from the request path. |
