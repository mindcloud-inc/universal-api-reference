# Get Story with ChatBot

Retrieves chatbot story details from ChatBot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/stories/:storyId`
- **Base URL:** `https://api.chatbot.com`
- **Official documentation:** [Get Story](https://www.chatbot.com/docs/stories/#list-single-story)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `storyId` | path | `string` | yes | The required ChatBot story ID from the request path. |
