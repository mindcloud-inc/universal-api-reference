# Get Chat with ChatBot

Retrieves chat details from ChatBot API.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/chats/:chatId`
- **Base URL:** `https://api.chatbot.com`
- **Official documentation:** [Get Chat](https://www.chatbot.com/docs/archives/#get-single-chat)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | The required ChatBot chat ID from the request path. |
