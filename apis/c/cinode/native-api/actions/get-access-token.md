# Get Access Token with Cinode

Retrieves an access token from Cinode.

## Endpoint

- **Method:** `GET`
- **Path:** `/token`
- **Base URL:** `https://api.cinode.com`
- **Official documentation:** [Get Access Token](https://support.cinode.com/en/articles/91483-rest-api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
