# List Tag Types with Cinode

Retrieves company tag types from Cinode.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0.2/companies/:companyId/tag-types`
- **Base URL:** `https://api.cinode.com`
- **Official documentation:** [List Tag Types](https://api.cinode.com/docs/index.html#/TagTypes/GetTagTypes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Cinode company identifier. |
