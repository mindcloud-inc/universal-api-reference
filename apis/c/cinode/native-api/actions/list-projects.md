# List Projects with Cinode

Retrieves won projects for a company in Cinode.

## Endpoint

- **Method:** `GET`
- **Path:** `/v0.1/companies/:companyId/projects`
- **Base URL:** `https://api.cinode.com`
- **Official documentation:** [List Projects](https://api.cinode.com/docs/index.html#/Projects/Projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `number` | yes | Cinode company ID. |
