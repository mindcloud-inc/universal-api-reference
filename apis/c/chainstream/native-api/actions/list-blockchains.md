# List Blockchains with Chainstream

Retrieves supported blockchains from Chainstream.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/blockchain`
- **Base URL:** `https://api.chainstream.io`
- **Official documentation:** [List Blockchains](https://docs.chainstream.io/en/api-reference/endpoint/blockchain/v1/blockchain-get)
