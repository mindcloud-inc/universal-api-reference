# Get Webhook Endpoint with Chainstream

Retrieves a webhook endpoint from Chainstream.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/webhook/endpoint/:id`
- **Base URL:** `https://api.chainstream.io`
- **Official documentation:** [Get Webhook Endpoint](https://docs.chainstream.io/en/api-reference/endpoint/data/webhook/v2/webhook-endpoint-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint ID |
