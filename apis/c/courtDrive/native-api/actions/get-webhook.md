# Get Webhook with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{webhook_id}`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get Webhook](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | Webhook identifier for the target webhook. |
