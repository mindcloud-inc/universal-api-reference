# Get Async Request Progress with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/progress/{task_id}`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get Async Request Progress](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | Async task identifier returned by CourtAPI. |
