# Set PACER Credentials with Court Drive

## Endpoint

- **Method:** `POST`
- **Path:** `/pacer/credentials`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Set PACER Credentials](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pacer_user` | body | `string` | yes | PACER username to store in CourtAPI. |
