# Get Case Root Menu by UUID with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/cases/pacer/by-uuid/{case_uuid}`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get Case Root Menu by UUID](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `case_uuid` | path | `string` | yes | CourtAPI case UUID. |
