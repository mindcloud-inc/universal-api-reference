# Get PACER Region with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/regions/pacer/{region_code}`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get PACER Region](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `region_code` | path | `string` | yes | PACER region code to look up. |
