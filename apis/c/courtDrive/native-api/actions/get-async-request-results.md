# Get Async Request Results with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/async/{task_id}/results`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get Async Request Results](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | Async task identifier returned by CourtAPI. |
