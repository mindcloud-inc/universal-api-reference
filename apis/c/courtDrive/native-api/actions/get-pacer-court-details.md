# Get PACER Court Details with Court Drive

## Endpoint

- **Method:** `GET`
- **Path:** `/courts/pacer/{court_code}`
- **Base URL:** `https://v1.courtapi.com`
- **Official documentation:** [Get PACER Court Details](https://www.courtapi.com/docs/playground)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `court_code` | path | `string` | yes | PACER court code for the target court. |
