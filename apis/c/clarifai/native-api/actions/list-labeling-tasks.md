# List Labeling Tasks with Clarifai

Retrieves labeling tasks from Clarifai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/tasks`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [List Labeling Tasks](https://docs.clarifai.com/create/labeling/api/tasks/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `appId` | path | `string` | no |
