# List Annotations with Clarifai

Retrieves annotations from Clarifai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/annotations`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [List Annotations](https://docs.clarifai.com/create/labeling/api/annotations-list/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `appId` | path | `string` | no |
