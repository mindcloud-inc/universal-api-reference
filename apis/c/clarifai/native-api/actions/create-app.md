# Create App with Clarifai

Creates a new app in Clarifai.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/users/{userId}/apps`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Create App](https://docs.clarifai.com/create/applications/create/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `appId` | path | `string` | no |
