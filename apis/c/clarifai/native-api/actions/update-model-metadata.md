# Update Model Metadata with Clarifai

Updates existing model metadata in Clarifai.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/models`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Update Model Metadata](https://docs.clarifai.com/create/models/manage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Clarifai app ID. |
