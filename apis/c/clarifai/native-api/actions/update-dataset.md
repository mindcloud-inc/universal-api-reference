# Update Dataset with Clarifai

Updates an existing dataset in Clarifai.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/datasets`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Update Dataset](https://docs.clarifai.com/create/datasets/manage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Clarifai app ID. |
