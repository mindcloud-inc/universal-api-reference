# Create Visual Classifier Model with Clarifai

Creates a visual classifier model in Clarifai.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/models`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Create Visual Classifier Model](https://docs.clarifai.com/create/models/deep-fine-tuning/visual-classifier/)
