# List Public Models with Clarifai

Retrieves public models from Clarifai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/clarifai/apps/main/models`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [List Public Models](https://docs.clarifai.com/create/models/manage/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
