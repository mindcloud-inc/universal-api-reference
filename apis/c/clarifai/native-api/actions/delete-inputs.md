# Delete Inputs with Clarifai

Deletes existing inputs from Clarifai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/inputs`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Delete Inputs](https://docs.clarifai.com/create/inputs/manage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Clarifai app ID. |
