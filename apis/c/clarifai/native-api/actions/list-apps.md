# List Apps with Clarifai

Retrieves apps from Clarifai.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/users/{userId}/apps`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [List Apps](https://docs.clarifai.com/create/applications/manage/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
