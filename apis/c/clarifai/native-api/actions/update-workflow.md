# Update Workflow with Clarifai

Updates an existing workflow in Clarifai.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/users/{userId}/apps/{{appId}}/workflows`
- **Base URL:** `https://api.clarifai.com`
- **Official documentation:** [Update Workflow](https://docs.clarifai.com/create/workflows/manage/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `string` | no | Clarifai app ID. |
