# Stop Snapshot with Crazy Egg

## Endpoint

- **Method:** `PUT`
- **Path:** `/snapshot/:id/stop.json`
- **Base URL:** `https://app.crazyegg.com/api/v2`
- **Official documentation:** [Stop Snapshot](https://support.crazyegg.com/knowledge-base/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
