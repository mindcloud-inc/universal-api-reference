# Get Snapshot with Crazy Egg

## Endpoint

- **Method:** `GET`
- **Path:** `/snapshot/:id.json`
- **Base URL:** `https://app.crazyegg.com/api/v2`
- **Official documentation:** [Get Snapshot](https://support.crazyegg.com/knowledge-base/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
