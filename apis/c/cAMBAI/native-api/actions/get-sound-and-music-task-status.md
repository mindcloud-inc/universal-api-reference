# Get Sound and Music Task Status with CAMB.AI

Retrieves sound and music task status from CAMB.AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/text-to-sound/:task_id`
- **Base URL:** `https://client.camb.ai/apis`
- **Official documentation:** [Get Sound and Music Task Status](https://docs.camb.ai/api-reference/endpoint/get-text-to-sound-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | Task identifier returned by Create Sound and Music. |
