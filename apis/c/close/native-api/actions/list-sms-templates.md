# List SMS Templates with Close

Retrieves SMS templates from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms_template/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [List SMS Templates](https://developer.close.com/resources/sms-templates/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
