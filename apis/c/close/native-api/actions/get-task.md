# Get Task with Close

Retrieves a task from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Task](https://developer.close.com/resources/tasks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Task ID. |
