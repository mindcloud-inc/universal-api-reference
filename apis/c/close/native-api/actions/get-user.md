# Get User with Close

Retrieves a user from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get User](https://developer.close.com/resources/users/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique User ID. |
