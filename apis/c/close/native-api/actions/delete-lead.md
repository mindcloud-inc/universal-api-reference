# Delete Lead with Close

Deletes an existing lead from Close.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lead/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Delete Lead](https://developer.close.com/resources/leads/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Lead ID. |
