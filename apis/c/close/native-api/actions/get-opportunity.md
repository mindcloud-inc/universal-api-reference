# Get Opportunity with Close

Retrieves an opportunity from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/opportunity/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Opportunity](https://developer.close.com/resources/opportunities/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Opportunity ID. |
