# Get Contact with Close

Retrieves a contact from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Contact](https://developer.close.com/resources/contacts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Contact ID. |
