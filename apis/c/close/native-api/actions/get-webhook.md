# Get Webhook with Close

Retrieves a webhook subscription from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Webhook](https://developer.close.com/resources/webhooks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Webhook ID. |
