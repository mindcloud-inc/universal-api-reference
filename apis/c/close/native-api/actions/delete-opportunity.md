# Delete Opportunity with Close

Deletes an existing opportunity from Close.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/opportunity/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Delete Opportunity](https://developer.close.com/resources/opportunities/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Opportunity ID. |
