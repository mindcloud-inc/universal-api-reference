# Get SMS Template with Close

Retrieves an SMS template from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms_template/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get SMS Template](https://developer.close.com/resources/sms-templates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique SMS Template ID. |
