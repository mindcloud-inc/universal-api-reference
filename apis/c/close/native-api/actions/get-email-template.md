# Get Email Template with Close

Retrieves an email template from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_template/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Email Template](https://developer.close.com/resources/email-templates/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Email Template ID. |
