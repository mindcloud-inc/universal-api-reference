# Get Lead with Close

Retrieves a lead from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/lead/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Get Lead](https://developer.close.com/resources/leads/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Lead ID. |
