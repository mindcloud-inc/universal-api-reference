# List Smart Views with Close

Retrieves smart views from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/saved_search/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [List Smart Views](https://developer.close.com/resources/smart-views/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Smart view object type. |
