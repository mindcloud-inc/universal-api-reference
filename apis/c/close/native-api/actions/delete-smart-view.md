# Delete Smart View with Close

Deletes an existing smart view from Close.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/saved_search/:id/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [Delete Smart View](https://developer.close.com/resources/smart-views/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Smart View ID. |
