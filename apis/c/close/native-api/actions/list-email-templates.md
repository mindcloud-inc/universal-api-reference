# List Email Templates with Close

Retrieves email templates from Close.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_template/`
- **Base URL:** `https://api.close.com/api/v1`
- **Official documentation:** [List Email Templates](https://developer.close.com/resources/email-templates/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `is_archived` | query | `boolean` | no | Filter archived templates. |
