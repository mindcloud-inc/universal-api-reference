# Get Order with Cratejoy

Retrieves an order from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/:orderId/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [Get Order](https://docs.cratejoy.com/reference/order-methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `number` | yes | The Cratejoy order ID. |
