# List Shipments with Cratejoy

Retrieves shipments from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/shipments/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Shipments](https://docs.cratejoy.com/reference/shipment-methods-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
