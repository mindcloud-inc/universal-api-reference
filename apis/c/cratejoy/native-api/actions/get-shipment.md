# Get Shipment with Cratejoy

Retrieves a shipment from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/shipments/:shipId/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [Get Shipment](https://docs.cratejoy.com/reference/shipment-methods-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipId` | path | `number` | yes | The Cratejoy shipment ID. |
