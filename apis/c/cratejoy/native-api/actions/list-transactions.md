# List Transactions with Cratejoy

Retrieves transactions from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactions/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Transactions](https://docs.cratejoy.com/reference/transaction-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination).
