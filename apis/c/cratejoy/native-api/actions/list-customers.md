# List Customers with Cratejoy

Retrieves customers from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Customers](https://docs.cratejoy.com/reference/methods-customer)

## Capabilities

This operation supports [pagination](../README.md#pagination).
