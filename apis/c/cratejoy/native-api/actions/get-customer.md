# Get Customer with Cratejoy

Retrieves a customer from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customerId/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [Get Customer](https://docs.cratejoy.com/reference/methods-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `number` | yes | The Cratejoy customer ID. |
