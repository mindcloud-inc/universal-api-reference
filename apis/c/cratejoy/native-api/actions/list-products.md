# List Products with Cratejoy

Retrieves products from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Products](https://docs.cratejoy.com/reference/product-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination).
