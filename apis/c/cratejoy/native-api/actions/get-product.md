# Get Product with Cratejoy

Retrieves a product from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:productId/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [Get Product](https://docs.cratejoy.com/reference/product-methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `number` | yes | The Cratejoy product ID. |
