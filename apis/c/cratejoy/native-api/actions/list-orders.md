# List Orders with Cratejoy

Retrieves orders from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Orders](https://docs.cratejoy.com/reference/order-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination).
