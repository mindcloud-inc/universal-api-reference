# List Subscriptions with Cratejoy

Retrieves subscriptions from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscriptions/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Subscriptions](https://docs.cratejoy.com/reference/subscription-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination).
