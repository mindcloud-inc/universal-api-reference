# List Inventory Levels with Cratejoy

Retrieves inventory levels from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/inventory/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [List Inventory Levels](https://docs.cratejoy.com/reference/inventory-methods)

## Capabilities

This operation supports [pagination](../README.md#pagination).
