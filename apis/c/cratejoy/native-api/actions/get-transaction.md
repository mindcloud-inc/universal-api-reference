# Get Transaction with Cratejoy

Retrieves a transaction from Cratejoy.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactions/:transactionId/`
- **Base URL:** `https://api.cratejoy.com`
- **Official documentation:** [Get Transaction](https://docs.cratejoy.com/reference/transaction-methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactionId` | path | `number` | yes | The Cratejoy transaction ID. |
