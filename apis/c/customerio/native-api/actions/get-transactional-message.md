# Get Transactional Message with Customer.io

Retrieves a transactional message from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactional/:transactional_id`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [Get Transactional Message](https://docs.customer.io/integrations/api/app/#tag/Transactional/operation/getTransactional)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `transactional_id` | path | `number` | yes | The identifier of your transactional message. |
