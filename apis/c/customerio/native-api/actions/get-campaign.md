# Get Campaign with Customer.io

Retrieves a campaign from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/campaigns/:campaign_id`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [Get Campaign](https://docs.customer.io/integrations/api/app/#tag/Campaigns/operation/getCampaigns)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `number` | yes | The numeric ID of the campaign you want to retrieve. |
