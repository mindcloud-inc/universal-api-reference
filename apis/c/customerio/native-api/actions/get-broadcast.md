# Get Broadcast with Customer.io

Retrieves a broadcast from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/broadcasts/:broadcast_id`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [Get Broadcast](https://docs.customer.io/integrations/api/app/#tag/Broadcasts/operation/getBroadcast)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `broadcast_id` | path | `number` | yes | The numeric ID of the broadcast you want to retrieve. |
