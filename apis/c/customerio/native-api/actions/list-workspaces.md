# List Workspaces with Customer.io

Retrieves workspaces from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspaces`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [List Workspaces](https://docs.customer.io/integrations/api/app/#tag/Workspaces/operation/listWorkspaces)
