# List Subscription Topics with Customer.io

Retrieves subscription topics from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscription_topics`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [List Subscription Topics](https://docs.customer.io/integrations/api/app/#tag/Subscription%20Center/operation/getTopics)
