# Get Segment with Customer.io

Retrieves a segment from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/segments/:segment_id`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [Get Segment](https://docs.customer.io/integrations/api/app/#tag/Segments/operation/getSegment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segment_id` | path | `list<number>` | yes | The identifier for the segment to inspect. |
