# List Transactional Messages with Customer.io

Retrieves transactional messages from Customer.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/transactional`
- **Base URL:** `https://api.customer.io`
- **Official documentation:** [List Transactional Messages](https://docs.customer.io/integrations/api/app/#tag/Transactional/operation/listTransactional)
