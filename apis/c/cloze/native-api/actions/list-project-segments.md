# List Project Segments with Cloze

Retrieves project segments from Cloze.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user/segments/projects`
- **Base URL:** `https://api.cloze.com`
- **Official documentation:** [List Project Segments](https://api.cloze.com/api-docs/#/paths/v1-user-segments-projects/get)
