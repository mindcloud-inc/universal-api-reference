# List Contact Segments with Cloze

Retrieves contact segments from Cloze.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user/segments/people`
- **Base URL:** `https://api.cloze.com`
- **Official documentation:** [List Contact Segments](https://api.cloze.com/api-docs/#/paths/v1-user-segments-people/get)
