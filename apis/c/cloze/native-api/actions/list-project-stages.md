# List Project Stages with Cloze

Retrieves project stages from Cloze.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/user/stages/projects`
- **Base URL:** `https://api.cloze.com`
- **Official documentation:** [List Project Stages](https://api.cloze.com/api-docs/#/paths/v1-user-stages-projects/get)
