# Delete Contact List with Conexteo

Deletes an existing contact list from Conexteo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contactlists/:id`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Delete Contact List](https://developers.conexteo.com/suppression-dune-liste-de-contacts-24126520e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Conexteo contact-list identifier. |
