# List Message Replies with Conexteo

Finds message replies in Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/replies`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [List Message Replies](https://developers.conexteo.com/r%C3%A9ponses-pagination-24126505e0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
