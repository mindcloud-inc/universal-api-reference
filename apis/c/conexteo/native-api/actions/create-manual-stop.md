# Create Manual Stop with Conexteo

Creates a manual stop in Conexteo.

## Endpoint

- **Method:** `POST`
- **Path:** `/stops`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Create Manual Stop](https://developers.conexteo.com/ajout-dun-stop-manuel-24126513e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recipient` | body | `string` | yes | Phone number to add to the stop list. |
