# List Contact Lists with Conexteo

Finds contact lists in Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/contactlists`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [List Contact Lists](https://developers.conexteo.com/liste-des-listes-de-contacts-24126517e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter contact lists by search term. |
