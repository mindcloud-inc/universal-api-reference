# Get Contact List with Conexteo

Retrieves a contact list from Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/contactlists/:id`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Get Contact List](https://developers.conexteo.com/d%C3%A9tail-dune-liste-de-contacts-24126519e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier of the contact list to retrieve. |
