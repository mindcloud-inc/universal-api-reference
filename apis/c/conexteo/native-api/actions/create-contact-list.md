# Create Contact List with Conexteo

Creates a contact list in Conexteo.

## Endpoint

- **Method:** `POST`
- **Path:** `/contactlists`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Create Contact List](https://developers.conexteo.com/cr%C3%A9er-une-liste-de-contacts-24126516e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Name of the contact list. |
