# Delete Stop with Conexteo

Deletes an existing stop from Conexteo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/stops/:id`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Delete Stop](https://developers.conexteo.com/suppression-dun-stop-24126515e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Conexteo stop identifier. |
