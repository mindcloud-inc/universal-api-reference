# List Stops with Conexteo

Finds stopped subscribers in Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/stops/all`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [List Stops](https://developers.conexteo.com/liste-des-stops-24126512e0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
