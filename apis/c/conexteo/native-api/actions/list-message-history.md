# List Message History with Conexteo

Finds message history in Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [List Message History](https://developers.conexteo.com/historique-des-messages-24126499e0)

## Capabilities

This operation supports [pagination](../README.md#pagination).
