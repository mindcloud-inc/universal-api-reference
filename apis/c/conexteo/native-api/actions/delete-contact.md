# Delete Contact with Conexteo

Deletes an existing contact from Conexteo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Delete Contact](https://developers.conexteo.com/suppression-dun-contact-24126527e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Conexteo contact identifier. |
