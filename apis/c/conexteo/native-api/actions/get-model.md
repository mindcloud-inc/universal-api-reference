# Get Model with Conexteo

Retrieves a message template from Conexteo.

## Endpoint

- **Method:** `GET`
- **Path:** `/models/:id`
- **Base URL:** `https://api.conexteo.com`
- **Official documentation:** [Get Model](https://developers.conexteo.com/d%C3%A9tail-du-mod%C3%A8le-24126532e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Identifier of the model to retrieve. |
