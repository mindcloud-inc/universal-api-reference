# PDF to HTML with ComIDP

Creates a ComIDP job to convert a PDF to HTML.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/html`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to HTML](https://api.compdf.com/api-reference/pdf-to-html)
