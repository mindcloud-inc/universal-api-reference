# Stamp Detection with ComIDP

Creates a ComIDP job to detect stamps in documents.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/stampDetection`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Stamp Detection](https://api.compdf.com/api-reference/stamp-detection)
