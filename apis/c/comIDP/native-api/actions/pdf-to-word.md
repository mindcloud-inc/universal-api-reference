# PDF to Word with ComIDP

Creates a ComIDP job to convert a PDF to Word.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/docx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to Word](https://api.compdf.com/api-reference/pdf-to-word)
