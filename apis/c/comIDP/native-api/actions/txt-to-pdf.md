# TXT to PDF with ComIDP

Creates a ComIDP job to convert a text file to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/txt/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [TXT to PDF](https://api.compdf.com/api-reference/txt-to-pdf)
