# Word to PDF with ComIDP

Creates a ComIDP job to convert a Word document to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/docx/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Word to PDF](https://api.compdf.com/api-reference/word-to-pdf)
