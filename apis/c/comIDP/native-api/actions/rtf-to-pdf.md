# RTF to PDF with ComIDP

Creates a ComIDP job to convert an RTF file to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/rtf/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [RTF to PDF](https://api.compdf.com/api-reference/rtf-to-pdf)
