# Table Extraction with ComIDP

Creates a ComIDP job to extract tables from documents.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/tableExtraction`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Table Extraction](https://api.compdf.com/api-reference/table-extraction)
