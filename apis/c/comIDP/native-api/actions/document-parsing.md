# Document Parsing with ComIDP

Creates a ComIDP job to parse document content.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/documentParsing`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Document Parsing](https://api.compdf.com/api-reference/documentParsing)
