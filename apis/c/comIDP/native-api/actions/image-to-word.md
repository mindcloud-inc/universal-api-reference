# Image to Word with ComIDP

Creates a ComIDP job to convert an image to a Word document.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/image/docx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image to Word](https://api.compdf.com/api-reference/image-to-word)
