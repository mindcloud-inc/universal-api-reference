# HTML to PDF with ComIDP

Creates a ComIDP job to convert HTML content to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/html/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [HTML to PDF](https://api.compdf.com/api-reference/html-to-pdf)
