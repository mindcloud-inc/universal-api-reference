# PDF to PPT with ComIDP

Creates a ComIDP job to convert a PDF to PowerPoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/pptx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to PPT](https://api.compdf.com/api-reference/pdf-to-ppt)
