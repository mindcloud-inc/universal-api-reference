# Document Extraction with ComIDP

Creates a ComIDP job to extract structured data from documents.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/documentExtract`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Document Extraction](https://api.compdf.com/api-reference/documentExtract)
