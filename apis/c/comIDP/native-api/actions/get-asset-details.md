# Get Asset Details with ComIDP

Retrieves processed asset details from ComIDP.

## Endpoint

- **Method:** `GET`
- **Path:** `/server/v2/asset/info`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Get Asset Details](https://api.compdf.com/api-reference/api-list)
