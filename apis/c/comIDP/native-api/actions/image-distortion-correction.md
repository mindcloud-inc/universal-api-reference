# Image Distortion Correction with ComIDP

Creates a ComIDP job to correct image distortion.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/imageDistortionCorrection`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image Distortion Correction](https://api.compdf.com/api-reference/image-distortion-correction)
