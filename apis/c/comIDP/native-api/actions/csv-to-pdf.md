# CSV to PDF with ComIDP

Creates a ComIDP job to convert a CSV file to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/csv/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [CSV to PDF](https://api.compdf.com/api-reference/csv-to-pdf)
