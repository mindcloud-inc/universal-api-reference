# PDF to Image with ComIDP

Creates a ComIDP job to convert a PDF to images.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/jpg`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to Image](https://api.compdf.com/api-reference/pdf-to-image)
