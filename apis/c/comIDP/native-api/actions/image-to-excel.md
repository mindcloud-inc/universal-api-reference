# Image to Excel with ComIDP

Creates a ComIDP job to convert an image to an Excel workbook.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/image/xlsx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image to Excel](https://api.compdf.com/api-reference/image-to-excel)
