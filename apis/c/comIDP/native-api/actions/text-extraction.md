# Text Extraction with ComIDP

Creates a ComIDP job to extract text from documents.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/textExtraction`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Text Extraction](https://api.compdf.com/api-reference/text-extraction)
