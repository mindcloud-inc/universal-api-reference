# PDF to TXT with ComIDP

Creates a ComIDP job to convert a PDF to plain text.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/txt`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to TXT](https://api.compdf.com/api-reference/pdf-to-txt)
