# PDF to Excel with ComIDP

Creates a ComIDP job to convert a PDF to Excel.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/xlsx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to Excel](https://api.compdf.com/api-reference/excel-to-pdf)
