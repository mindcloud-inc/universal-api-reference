# PPT to PDF with ComIDP

Creates a ComIDP job to convert a PowerPoint presentation to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pptx/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PPT to PDF](https://api.compdf.com/api-reference/ppt-to-pdf)
