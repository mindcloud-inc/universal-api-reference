# Image Enhancement with ComIDP

Creates a ComIDP job to enhance document images.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/idp/imageEnhancement`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image Enhancement](https://api.compdf.com/api-reference/image-enhancement)
