# PDF to Markdown with ComIDP

Creates a ComIDP job to convert a PDF to Markdown.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/markdown`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [PDF to Markdown](https://api.compdf.com/api-reference/pdf-to-markdown)
