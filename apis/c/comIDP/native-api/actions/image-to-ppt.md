# Image to PPT with ComIDP

Creates a ComIDP job to convert an image to PowerPoint.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/image/pptx`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image to PPT](https://api.compdf.com/api-reference/image-to-ppt)
