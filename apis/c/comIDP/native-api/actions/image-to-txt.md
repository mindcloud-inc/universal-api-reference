# Image to TXT with ComIDP

Creates a ComIDP job to convert an image to plain text.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/image/txt`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Image to TXT](https://api.compdf.com/api-reference/image-to-txt)
