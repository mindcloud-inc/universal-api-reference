# Excel to PDF with ComIDP

Creates a ComIDP job to convert an Excel workbook to PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/xlsx/pdf`
- **Base URL:** `https://api-server.compdf.com/server/v2`
- **Official documentation:** [Excel to PDF](https://api.compdf.com/api-reference/excel-to-pdf)
