# Get Bulk Email Verification Batch Status with Clearout

Retrieves bulk email verification batch status from Clearout.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_verify/bulk/progress_status`
- **Base URL:** `https://api.clearout.io/v2`
- **Official documentation:** [Get Bulk Email Verification Batch Status](https://docs.clearout.io/developers/api/email-verify)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `list_id` | query | `string` | yes |
