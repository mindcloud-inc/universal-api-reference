# Get Bulk Email Finder Batch Status with Clearout

Retrieves bulk email finder batch status from Clearout.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_finder/bulk/progress_status`
- **Base URL:** `https://api.clearout.io/v2`
- **Official documentation:** [Get Bulk Email Finder Batch Status](https://docs.clearout.io/developers/api/email-finder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `list_id` | query | `string` | yes |
