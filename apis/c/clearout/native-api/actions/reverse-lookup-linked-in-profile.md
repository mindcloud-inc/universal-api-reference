# Reverse Lookup LinkedIn Profile with Clearout

Retrieves lead information from Clearout by LinkedIn profile URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/reverse_lookup/linkedin`
- **Base URL:** `https://api.clearout.io/v2`
- **Official documentation:** [Reverse Lookup LinkedIn Profile](https://docs.clearout.io/developers/api/reverse-lookup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | LinkedIn profile URL to lookup |
