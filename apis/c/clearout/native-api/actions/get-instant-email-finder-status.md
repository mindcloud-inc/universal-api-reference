# Get Instant Email Finder Status with Clearout

Retrieves instant email finder queue status from Clearout.

## Endpoint

- **Method:** `GET`
- **Path:** `/email_finder/instant/queue_status`
- **Base URL:** `https://api.clearout.io/v2`
- **Official documentation:** [Get Instant Email Finder Status](https://docs.clearout.io/developers/api/email-finder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `qid` | query | `string` | yes |
