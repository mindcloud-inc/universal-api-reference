# List Conversations with CustomGPT.ai

Retrieves conversations from a CustomGPT.ai agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/conversations`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [List Conversations](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid-conversations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID whose conversations should be listed. |
