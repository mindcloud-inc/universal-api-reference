# Get Agent Statistics with CustomGPT.ai

Retrieves detailed agent statistics from CustomGPT.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/stats`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [Get Agent Statistics](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid-stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID of the agent to inspect. |
