# Get Agent Settings with CustomGPT.ai

Retrieves current agent settings from CustomGPT.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/settings`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [Get Agent Settings](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid-settings-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID of the agent to inspect. |
