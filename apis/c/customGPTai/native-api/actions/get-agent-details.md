# Get Agent Details with CustomGPT.ai

Retrieves detailed agent information from CustomGPT.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [Get Agent Details](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID of the agent to retrieve. |
