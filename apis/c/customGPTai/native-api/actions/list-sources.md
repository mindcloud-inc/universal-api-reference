# List Sources with CustomGPT.ai

Retrieves sources from a CustomGPT.ai agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/sources`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [List Sources](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid-sources-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID whose sources should be listed. |
