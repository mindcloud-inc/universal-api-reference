# Get Current User Profile with CustomGPT.ai

Retrieves the current user profile from CustomGPT.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [Get Current User Profile](https://docs.customgpt.ai/reference/get_api-v1-user)
