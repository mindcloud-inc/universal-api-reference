# List Documents with CustomGPT.ai

Retrieves documents from a CustomGPT.ai agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/pages`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [List Documents](https://docs.customgpt.ai/reference/get_api-v1-projects-projectid-pages-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | The project ID whose documents should be listed. |
