# Delete Agent with CustomGPT.ai

Deletes an existing agent from CustomGPT.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://app.customgpt.ai/api/v1`
- **Official documentation:** [Delete Agent](https://docs.customgpt.ai/reference/delete_api-v1-projects-projectid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | ID of the temporary agent to delete after verification. |
