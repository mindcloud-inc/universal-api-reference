# List Associated Persons with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entity_id/associated-persons`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [List Associated Persons](https://column.com/docs/api/#entity/get-associated-persons)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_id` | path | `string` | yes |
