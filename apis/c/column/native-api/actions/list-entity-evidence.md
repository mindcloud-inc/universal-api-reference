# List Entity Evidence with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entity_id/evidence`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [List Entity Evidence](https://column.com/docs/api/#entity/get-entity-evidence)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_id` | path | `string` | yes |
