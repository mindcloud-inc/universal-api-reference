# List Account Numbers with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/bank-accounts/:bank_account_id/account-numbers`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [List Account Numbers](https://column.com/docs/api/#account-number/list-all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bank_account_id` | path | `string` | yes |
