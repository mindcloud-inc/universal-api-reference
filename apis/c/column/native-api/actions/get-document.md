# Get Document with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document_id`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get Document](https://column.com/docs/api/#documents/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `document_id` | path | `string` | yes |
