# Get Entity Compliance with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/entities/:entity_id/compliance`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get Entity Compliance](https://column.com/docs/api/#entity/get-entity-compliance)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_id` | path | `string` | yes |
