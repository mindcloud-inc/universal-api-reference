# Get Financial Institution with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/institutions/:routing_number`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get Financial Institution](https://column.com/docs/api/#counterparty/get-institution)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `routing_number` | path | `string` | yes |
