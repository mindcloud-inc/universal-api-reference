# Get Bank Account with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/bank-accounts/:bank_account_id`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get Bank Account](https://column.com/docs/api/#bank-account/get-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `bank_account_id` | path | `string` | yes |
