# Get ACH Transfer with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/transfers/ach/:ach_transfer_id`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get ACH Transfer](https://column.com/docs/api/#ach-transfer/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ach_transfer_id` | path | `string` | yes | ID of the ACH transfer to retrieve. |
