# Submit Additional Requirements with Column

## Endpoint

- **Method:** `POST`
- **Path:** `/entities/:entity_id/additional-requirements`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Submit Additional Requirements](https://column.com/docs/api/#entity/submit-additional-requirements)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_id` | path | `string` | yes |
