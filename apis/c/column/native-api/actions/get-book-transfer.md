# Get Book Transfer with Column

## Endpoint

- **Method:** `GET`
- **Path:** `/transfers/book/:book_transfer_id`
- **Base URL:** `https://api.column.com`
- **Official documentation:** [Get Book Transfer](https://column.com/docs/api/#book-transfer/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `book_transfer_id` | path | `string` | yes | ID of the book transfer to retrieve. |
