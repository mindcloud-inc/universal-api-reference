- **Path:** `/counterparties/:counterparty_id`

- **Official documentation:** [Get Counterparty](https://column.com/docs/api/#counterparty/get-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `counterparty_id` | path | `string` | yes |
