# List Notification Connectors with Coralogix

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/notification-center/v1/connectors`
- **Base URL:** `https://api.eu2.coralogix.com/mgmt/openapi/latest`
- **Official documentation:** [List Notification Connectors](https://docs.coralogix.com/api-reference/latest/connectors-service/list-connectors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connector_type` | query | `string` | no | Optional connector_type query parameter supported by the Coralogix OpenAPI endpoint. |
| `supported_by_entity_type` | query | `string` | no | Optional supported_by_entity_type query parameter supported by the Coralogix OpenAPI endpoint. |
