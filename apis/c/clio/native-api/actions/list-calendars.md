# List Calendars with Clio Manage

Retrieves calendars from your Clio Manage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Calendars](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Calendars/operation/Calendar%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
