# Get Note with Clio Manage

Retrieves a note from Clio Manage by note ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Note](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Notes/operation/Note%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio note ID. |
