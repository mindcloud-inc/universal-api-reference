# Get Calendar with Clio Manage

Retrieves a calendar from Clio Manage by calendar ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendars/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Calendar](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Calendars/operation/Calendar%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio calendar ID. |
