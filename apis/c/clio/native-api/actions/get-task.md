# Get Task with Clio Manage

Retrieves a task from Clio Manage by task ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Task](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Tasks/operation/Task%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio task ID. |
