# List Calendar Entries with Clio Manage

Retrieves calendar entries from Clio Manage.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar_entries.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Calendar Entries](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Calendar%20Entries/operation/CalendarEntry%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
