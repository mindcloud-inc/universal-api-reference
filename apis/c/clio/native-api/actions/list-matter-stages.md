# List Matter Stages with Clio Manage

Retrieves matter stages from Clio Manage.

## Endpoint

- **Method:** `GET`
- **Path:** `/matter_stages.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Matter Stages](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Matter%20Stages/operation/MatterStage%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
