# Get Activity Rate with Clio Manage

Retrieves an activity rate from Clio Manage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/activity_rates/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Activity Rate](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activity%20Rates/operation/ActivityRate%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio activity rate ID. |
