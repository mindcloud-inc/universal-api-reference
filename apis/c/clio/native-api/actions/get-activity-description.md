# Get Activity Description with Clio Manage

Retrieves an activity description from Clio Manage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/activity_descriptions/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Activity Description](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activity%20Descriptions/operation/ActivityDescription%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio activity description ID. |
