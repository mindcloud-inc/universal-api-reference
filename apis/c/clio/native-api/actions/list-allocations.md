# List Allocations with Clio Manage

Retrieves allocations from your Clio Manage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/allocations.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Allocations](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Allocations/operation/Allocation%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
