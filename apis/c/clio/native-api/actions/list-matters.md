# List Matters with Clio Manage

Retrieves matters from your Clio Manage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Matters](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Matters/operation/Matter%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
