# List Activity Descriptions with Clio Manage

Retrieves activity descriptions from Clio Manage.

## Endpoint

- **Method:** `GET`
- **Path:** `/activity_descriptions.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Activity Descriptions](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activity%20Descriptions/operation/ActivityDescription%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
