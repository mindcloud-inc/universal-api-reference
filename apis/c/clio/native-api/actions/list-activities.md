# List Activities with Clio Manage

Retrieves activities from your Clio Manage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Activities](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activities/operation/Activity%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
