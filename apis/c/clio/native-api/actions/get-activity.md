# Get Activity with Clio Manage

Retrieves an activity from Clio Manage by activity ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Activity](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activities/operation/Activity%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio activity ID. |
