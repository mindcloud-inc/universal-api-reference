# Get Contact with Clio Manage

Retrieves a contact from Clio Manage by contact ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Contact](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Contacts/operation/Contact%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio contact ID. |
