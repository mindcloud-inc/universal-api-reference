# List Tasks with Clio Manage

Retrieves tasks from your Clio Manage account.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Tasks](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Tasks/operation/Task%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
