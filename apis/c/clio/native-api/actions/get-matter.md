# Get Matter with Clio Manage

Retrieves a matter from Clio Manage by matter ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Matter](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Matters/operation/Matter%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio matter ID. |
