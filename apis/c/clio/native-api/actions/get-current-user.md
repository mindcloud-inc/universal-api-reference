# Get Current User with Clio Manage

Retrieves the current user from Clio Manage.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/who_am_i.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Current User](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Users/operation/User%23who_am_i)
