# List Activity Rates with Clio Manage

Retrieves activity rates from Clio Manage.

## Endpoint

- **Method:** `GET`
- **Path:** `/activity_rates.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [List Activity Rates](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Activity%20Rates/operation/ActivityRate%23index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
