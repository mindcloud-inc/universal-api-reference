# Get Calendar Entry with Clio Manage

Retrieves a calendar entry from Clio Manage by entry ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar_entries/:id.json`
- **Base URL:** `https://app.clio.com/api/v4`
- **Official documentation:** [Get Calendar Entry](https://docs.developers.clio.com/clio-manage/api-reference/#tag/Calendar%20Entries/operation/CalendarEntry%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Clio calendar entry ID. |
