# Query 2020 Detailed Demographic and Housing Characteristics File A with Census Bureau

Queries Census Bureau 2020 detailed demographic and housing characteristics File A.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/ddhca`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Detailed Demographic and Housing Characteristics File A](https://api.census.gov/data/2020/dec/ddhca.html)
