# Query 2024 Geography Information with Census Bureau

Queries Census Bureau 2024 geography information.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/geoinfo`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 Geography Information](https://api.census.gov/data/2024/geoinfo.html)
