# Query 2020 Census Final Self-Response and Return Rates with Census Bureau

Queries Census Bureau 2020 final self-response and return rates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/selfresponserate`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Census Final Self-Response and Return Rates](https://api.census.gov/data/2020/dec/selfresponserate.html)
