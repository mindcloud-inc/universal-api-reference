# Query 2023 Community Resilience Estimates with Census Bureau

Queries Census Bureau 2023 community resilience estimates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2023/cre`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2023 Community Resilience Estimates](https://api.census.gov/data/2023/cre.html)
