# Query 2020 Decennial Self-Response Rate with Census Bureau

Queries Census Bureau 2020 decennial self-response rate data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/responserate`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Decennial Self-Response Rate](https://api.census.gov/data/2020/dec/responserate.html)
