# Query 2024 ACS 5-Year Detailed Tables with Census Bureau

Queries Census Bureau 2024 ACS 5-Year detailed tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs5`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 5-Year Detailed Tables](https://api.census.gov/data/2024/acs/acs5.html)
