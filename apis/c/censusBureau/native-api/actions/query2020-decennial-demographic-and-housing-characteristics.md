# Query 2020 Decennial Demographic and Housing Characteristics with Census Bureau

Queries Census Bureau 2020 decennial demographic and housing characteristics.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/dhc`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Decennial Demographic and Housing Characteristics](https://api.census.gov/data/2020/dec/dhc.html)
