# Query 2024 ACS 1-Year Selected Population Profiles with Census Bureau

Queries Census Bureau 2024 ACS 1-Year selected population profiles.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs1/spp`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 1-Year Selected Population Profiles](https://api.census.gov/data/2024/acs/acs1/spp.html)
