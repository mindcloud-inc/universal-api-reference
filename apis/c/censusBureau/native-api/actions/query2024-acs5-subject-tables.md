# Query 2024 ACS 5-Year Subject Tables with Census Bureau

Queries Census Bureau 2024 ACS 5-Year subject tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs5/subject`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 5-Year Subject Tables](https://api.census.gov/data/2024/acs/acs5/subject.html)
