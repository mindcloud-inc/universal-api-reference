# Query 2023 Nonemployer Statistics with Census Bureau

Queries Census Bureau 2023 nonemployer statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/2023/nonemp`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2023 Nonemployer Statistics](https://api.census.gov/data/2023/nonemp.html)
