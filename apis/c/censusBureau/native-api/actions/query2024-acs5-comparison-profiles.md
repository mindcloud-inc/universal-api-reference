# Query 2024 ACS 5-Year Comparison Profiles with Census Bureau

Queries Census Bureau 2024 ACS 5-Year comparison profiles.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs5/cprofile`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 5-Year Comparison Profiles](https://api.census.gov/data/2024/acs/acs5/cprofile.html)
