# Query 2024 ACS 1-Year Data Profiles with Census Bureau

Queries Census Bureau 2024 ACS 1-Year data profiles.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs1/profile`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 1-Year Data Profiles](https://api.census.gov/data/2024/acs/acs1/profile.html)
