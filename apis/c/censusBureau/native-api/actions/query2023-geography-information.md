# Query 2023 Geography Information with Census Bureau

Queries Census Bureau 2023 geography information.

## Endpoint

- **Method:** `GET`
- **Path:** `/2023/geoinfo`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2023 Geography Information](https://api.census.gov/data/2023/geoinfo.html)
