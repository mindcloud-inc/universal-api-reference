# Query 2024 Planning Database Tracts with Census Bureau

Queries Census Bureau 2024 planning database tracts.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/pdb/tract`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 Planning Database Tracts](https://api.census.gov/data/2024/pdb/tract.html)
