# Query 2023 Community Resilience Estimates Puerto Rico with Census Bureau

Queries Census Bureau 2023 Puerto Rico community resilience estimates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2023/crepuertorico`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2023 Community Resilience Estimates Puerto Rico](https://api.census.gov/data/2023/crepuertorico.html)
