# Query 2022 Economic Census Basic Summary Statistics with Census Bureau

Queries Census Bureau 2022 economic census basic summary statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022/ecnbasic`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2022 Economic Census Basic Summary Statistics](https://api.census.gov/data/2022/ecnbasic.html)
