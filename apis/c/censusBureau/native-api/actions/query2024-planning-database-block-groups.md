# Query 2024 Planning Database Block Groups with Census Bureau

Queries Census Bureau 2024 planning database block groups.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/pdb/blockgroup`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 Planning Database Block Groups](https://api.census.gov/data/2024/pdb/blockgroup.html)
