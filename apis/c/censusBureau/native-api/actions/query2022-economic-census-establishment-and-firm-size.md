# Query 2022 Economic Census Establishment and Firm Size with Census Bureau

Queries Census Bureau 2022 economic census establishment and firm size data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022/ecnsize`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2022 Economic Census Establishment and Firm Size](https://api.census.gov/data/2022/ecnsize.html)
