# Query 2020 Census 119th Congressional District with Census Bureau

Queries Census Bureau 2020 119th congressional district data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/cd119`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Census 119th Congressional District](https://api.census.gov/data/2020/dec/cd119.html)
