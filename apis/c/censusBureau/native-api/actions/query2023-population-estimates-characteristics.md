# Query 2023 Population Estimates Characteristics with Census Bureau

Queries Census Bureau 2023 population estimates characteristics.

## Endpoint

- **Method:** `GET`
- **Path:** `/2023/pep/charv`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2023 Population Estimates Characteristics](https://api.census.gov/data/2023/pep/charv.html)
