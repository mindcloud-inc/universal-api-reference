# Query 2024 ACS 1-Year Detailed Tables with Census Bureau

Queries Census Bureau 2024 ACS 1-Year detailed tables.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acs1`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 1-Year Detailed Tables](https://api.census.gov/data/2024/acs/acs1.html)
