# Query 2021 Population Estimates with Census Bureau

Queries Census Bureau 2021 population estimates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2021/pep/population`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2021 Population Estimates](https://api.census.gov/data/2021/pep/population.html)
