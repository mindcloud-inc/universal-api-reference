# Query 2020 Decennial Demographic Profile with Census Bureau

Queries Census Bureau 2020 decennial demographic profile data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/dp`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Decennial Demographic Profile](https://api.census.gov/data/2020/dec/dp.html)
