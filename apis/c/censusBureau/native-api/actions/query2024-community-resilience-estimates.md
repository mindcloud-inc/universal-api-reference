# Query 2024 Community Resilience Estimates with Census Bureau

Queries Census Bureau 2024 community resilience estimates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/cre`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 Community Resilience Estimates](https://api.census.gov/data/2024/cre.html)
