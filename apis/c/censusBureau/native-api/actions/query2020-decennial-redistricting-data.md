# Query 2020 Decennial Redistricting Data with Census Bureau

Queries Census Bureau 2020 decennial redistricting data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/pl`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Decennial Redistricting Data](https://api.census.gov/data/2020/dec/pl.html)
