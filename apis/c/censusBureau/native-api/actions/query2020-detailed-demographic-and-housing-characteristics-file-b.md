# Query 2020 Detailed Demographic and Housing Characteristics File B with Census Bureau

Queries Census Bureau 2020 detailed demographic and housing characteristics File B.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/ddhcb`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Detailed Demographic and Housing Characteristics File B](https://api.census.gov/data/2020/dec/ddhcb.html)
