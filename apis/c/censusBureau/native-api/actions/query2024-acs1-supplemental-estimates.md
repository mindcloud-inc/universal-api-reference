# Query 2024 ACS 1-Year Supplemental Estimates with Census Bureau

Queries Census Bureau 2024 ACS 1-Year supplemental estimates.

## Endpoint

- **Method:** `GET`
- **Path:** `/2024/acs/acsse`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2024 ACS 1-Year Supplemental Estimates](https://api.census.gov/data/2024/acs/acsse.html)
