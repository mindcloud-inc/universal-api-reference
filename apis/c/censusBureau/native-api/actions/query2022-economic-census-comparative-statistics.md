# Query 2022 Economic Census Comparative Statistics with Census Bureau

Queries Census Bureau 2022 economic census comparative statistics.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022/ecncomp`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2022 Economic Census Comparative Statistics](https://api.census.gov/data/2022/ecncomp.html)
