# Query 2020 Decennial Post-Enumeration Survey with Census Bureau

Queries Census Bureau 2020 decennial post-enumeration survey data.

## Endpoint

- **Method:** `GET`
- **Path:** `/2020/dec/pes`
- **Base URL:** `https://api.census.gov/data`
- **Official documentation:** [Query 2020 Decennial Post-Enumeration Survey](https://api.census.gov/data/2020/dec/pes.html)
