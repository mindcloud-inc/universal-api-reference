# Count storage items with CRM in Cloud

Retrieves the number of storage items in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Storage/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count storage items](https://app.crmincloud.it/api/v1/Docs/en/Controller/Storage#/Count)
