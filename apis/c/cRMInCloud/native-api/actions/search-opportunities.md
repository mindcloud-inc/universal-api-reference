# Search opportunities with CRM in Cloud

Finds opportunities in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Opportunity/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search opportunities](https://app.crmincloud.it/api/v1/Docs/en/Controller/Opportunity#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
