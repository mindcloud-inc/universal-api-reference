# Search leads with CRM in Cloud

Finds leads in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Lead/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search leads](https://app.crmincloud.it/api/v1/Docs/en/Controller/Lead#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
