# Search storage items with CRM in Cloud

Finds storage items in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Storage/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search storage items](https://app.crmincloud.it/api/v1/Docs/en/Controller/Storage#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
