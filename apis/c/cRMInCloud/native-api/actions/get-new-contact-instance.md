# Get new contact instance with CRM in Cloud

Retrieves a new contact template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new contact instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Contact#/GetNewInstance)
