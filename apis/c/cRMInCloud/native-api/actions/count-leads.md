# Count leads with CRM in Cloud

Retrieves the number of leads in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Lead/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count leads](https://app.crmincloud.it/api/v1/Docs/en/Controller/Lead#/Count)
