# Count companies with CRM in Cloud

Retrieves the number of companies in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Company/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count companies](https://app.crmincloud.it/api/v1/Docs/en/Controller/Company#/Count)
