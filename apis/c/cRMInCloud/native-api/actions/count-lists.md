# Count lists with CRM in Cloud

Retrieves the number of lists in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/List/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count lists](https://app.crmincloud.it/api/v1/Docs/en/Controller/List#/Count)
