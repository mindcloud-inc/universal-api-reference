# Search companies with CRM in Cloud

Finds companies in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Company/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search companies](https://app.crmincloud.it/api/v1/Docs/en/Controller/Company#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
