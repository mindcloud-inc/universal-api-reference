# Get new opportunity instance with CRM in Cloud

Retrieves a new opportunity template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Opportunity/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new opportunity instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Opportunity#/GetNewInstance)
