# Count activities with CRM in Cloud

Retrieves the number of activities in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Activity/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count activities](https://app.crmincloud.it/api/v1/Docs/en/Controller/Activity#/Count)
