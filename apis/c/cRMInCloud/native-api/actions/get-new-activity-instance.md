# Get new activity instance with CRM in Cloud

Retrieves a new activity template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Activity/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new activity instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Activity#/GetNewInstance)
