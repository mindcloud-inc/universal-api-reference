# Get new list instance with CRM in Cloud

Retrieves a new list template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/List/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new list instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/List#/GetNewInstance)
