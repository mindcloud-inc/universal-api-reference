# Search contacts with CRM in Cloud

Finds contacts in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search contacts](https://app.crmincloud.it/api/v1/Docs/en/Controller/Contact#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
