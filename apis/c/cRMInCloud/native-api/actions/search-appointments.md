# Search appointments with CRM in Cloud

Finds appointments in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Appointment/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search appointments](https://app.crmincloud.it/api/v1/Docs/en/Controller/Appointment#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
