# Count appointments with CRM in Cloud

Retrieves the number of appointments in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Appointment/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count appointments](https://app.crmincloud.it/api/v1/Docs/en/Controller/Appointment#/Count)
