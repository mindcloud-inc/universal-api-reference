# Get new company instance with CRM in Cloud

Retrieves a new company template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Company/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new company instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Company#/GetNewInstance)
