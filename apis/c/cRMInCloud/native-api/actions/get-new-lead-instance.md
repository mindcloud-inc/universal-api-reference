# Get new lead instance with CRM in Cloud

Retrieves a new lead template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Lead/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new lead instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Lead#/GetNewInstance)
