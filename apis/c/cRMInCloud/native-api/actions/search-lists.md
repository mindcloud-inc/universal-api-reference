# Search lists with CRM in Cloud

Finds lists in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/List/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search lists](https://app.crmincloud.it/api/v1/Docs/en/Controller/List#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
