# Count contacts with CRM in Cloud

Retrieves the number of contacts in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Contact/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count contacts](https://app.crmincloud.it/api/v1/Docs/en/Controller/Contact#/Count)
