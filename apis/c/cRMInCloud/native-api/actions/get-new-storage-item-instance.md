# Get new storage item instance with CRM in Cloud

Retrieves a new storage item template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Storage/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new storage item instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Storage#/GetNewInstance)
