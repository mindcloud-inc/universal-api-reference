# Get new appointment instance with CRM in Cloud

Retrieves a new appointment template from CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Appointment/GetNewInstance`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Get new appointment instance](https://app.crmincloud.it/api/v1/Docs/en/Controller/Appointment#/GetNewInstance)
