# Search activities with CRM in Cloud

Finds activities in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Activity/Search`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Search activities](https://app.crmincloud.it/api/v1/Docs/en/Controller/Activity#/Search)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
