# Count opportunities with CRM in Cloud

Retrieves the number of opportunities in CRM in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/Opportunity/Count`
- **Base URL:** `https://app.crmincloud.it/api/latest`
- **Official documentation:** [Count opportunities](https://app.crmincloud.it/api/v1/Docs/en/Controller/Opportunity#/Count)
