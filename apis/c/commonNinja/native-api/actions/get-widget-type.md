# Get Widget Type with Common Ninja

Retrieves a widget type from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/widget-types/:id`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Widget Type](https://developers.commoninja.com/docs/api/widget-types/widget-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The widget type ID. |
