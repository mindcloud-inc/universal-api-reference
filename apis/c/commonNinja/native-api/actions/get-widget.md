# Get Widget with Common Ninja

Retrieves a widget from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/:id`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Widget](https://developers.commoninja.com/docs/api/widgets/widget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The widget ID. |
