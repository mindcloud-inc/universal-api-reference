# Get Widget Type Schema with Common Ninja

Retrieves a widget type schema from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/widget-types/:id/schema`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Widget Type Schema](https://developers.commoninja.com/docs/api/widget-types/widget-type-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The widget type ID. |
