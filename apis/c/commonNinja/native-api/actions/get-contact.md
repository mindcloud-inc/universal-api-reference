# Get Contact with Common Ninja

Retrieves a project contact from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/contacts/:contactId`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Contact](https://developers.commoninja.com/docs/api/crm/contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The project ID. |
| `contactId` | path | `string` | yes | The contact ID. |
