# Get Widget Editor URL with Common Ninja

Retrieves a widget editor URL from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/:id/editor`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Widget Editor URL](https://developers.commoninja.com/docs/api/widgets/widget-editor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The widget ID. |
