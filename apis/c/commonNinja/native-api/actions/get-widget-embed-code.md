# Get Widget Embed Code with Common Ninja

Retrieves a widget embed code from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/:id/embed-code`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [Get Widget Embed Code](https://developers.commoninja.com/docs/api/widgets/widget-embed-code)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The widget ID. |
