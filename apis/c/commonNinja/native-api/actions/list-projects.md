# List Projects with Common Ninja

Retrieves user projects from Common Ninja.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.commoninja.com/platform/api/v1`
- **Official documentation:** [List Projects](https://developers.commoninja.com/docs/api/projects/projects-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of projects to return. |
