# Accessibility Score Details with Cypress

Retrieves accessibility score details from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Accessibility Score Details](https://docs.cypress.io/cloud/integrations/data-extract-api#Accessibility-score-details)
