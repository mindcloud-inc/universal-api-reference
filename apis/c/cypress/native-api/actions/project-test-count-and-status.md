# Project Test Count And Status with Cypress

Retrieves project test counts and statuses from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Project Test Count And Status](https://docs.cypress.io/cloud/integrations/data-extract-api#Project-test-count-and-status)
