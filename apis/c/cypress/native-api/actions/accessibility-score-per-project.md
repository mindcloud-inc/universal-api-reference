# Accessibility Score Per Project with Cypress

Retrieves accessibility scores per project from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Accessibility Score Per Project](https://docs.cypress.io/cloud/integrations/data-extract-api#Accessibility-score-per-project)
