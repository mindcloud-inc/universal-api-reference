# Average Run Duration Over Time with Cypress

Retrieves average run durations over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Average Run Duration Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Average-run-duration-over-time)
