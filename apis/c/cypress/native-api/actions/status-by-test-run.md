# Status By Test Run with Cypress

Retrieves individual test status rates from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Status By Test Run](https://docs.cypress.io/cloud/integrations/data-extract-api#Status-by-test-run)
