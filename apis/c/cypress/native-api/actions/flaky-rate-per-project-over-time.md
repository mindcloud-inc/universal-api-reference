# Flaky Rate Per Project Over Time with Cypress

Retrieves flaky rates per project over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Flaky Rate Per Project Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Flaky-rate-per-project-over-time)
