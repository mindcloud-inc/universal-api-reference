# UI Coverage Per Project Over Time with Cypress

Retrieves UI coverage per project over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [UI Coverage Per Project Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#UI-Coverage-per-project-over-time)
