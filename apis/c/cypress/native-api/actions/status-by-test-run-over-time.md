# Status By Test Run Over Time with Cypress

Retrieves individual test status rates over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Status By Test Run Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Status-by-test-run-over-time)
