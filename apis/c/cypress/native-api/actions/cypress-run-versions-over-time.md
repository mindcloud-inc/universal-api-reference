# Cypress Run Versions Over Time with Cypress

Retrieves Cypress run versions over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Cypress Run Versions Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Cypress-run-versions-over-time)
