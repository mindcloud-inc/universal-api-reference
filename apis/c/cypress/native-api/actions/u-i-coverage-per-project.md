# UI Coverage Per Project with Cypress

Retrieves UI coverage per project from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [UI Coverage Per Project](https://docs.cypress.io/cloud/integrations/data-extract-api#UI-Coverage-per-project)
