# Browser Versions Tested with Cypress

Retrieves tested browser versions from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Browser Versions Tested](https://docs.cypress.io/cloud/integrations/data-extract-api#Browser-versions-tested)
