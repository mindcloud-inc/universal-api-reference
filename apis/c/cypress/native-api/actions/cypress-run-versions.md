# Cypress Run Versions with Cypress

Retrieves Cypress run versions from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Cypress Run Versions](https://docs.cypress.io/cloud/integrations/data-extract-api#Cypress-run-versions)
