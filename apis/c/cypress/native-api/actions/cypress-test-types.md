# Cypress Test Types with Cypress

Retrieves Cypress test type adoption data from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Cypress Test Types](https://docs.cypress.io/cloud/integrations/data-extract-api#Cypress-test-types)
