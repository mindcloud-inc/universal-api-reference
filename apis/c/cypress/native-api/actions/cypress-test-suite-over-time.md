# Cypress Test Suite Over Time with Cypress

Retrieves Cypress test suite growth over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Cypress Test Suite Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Cypress-test-suite-over-time)
