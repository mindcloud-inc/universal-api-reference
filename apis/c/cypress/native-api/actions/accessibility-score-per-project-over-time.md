# Accessibility Score Per Project Over Time with Cypress

Retrieves accessibility scores per project over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Accessibility Score Per Project Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Accessibility-score-per-project-over-time)
