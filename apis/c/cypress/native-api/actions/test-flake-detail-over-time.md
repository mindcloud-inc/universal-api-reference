# Test Flake Detail Over Time with Cypress

Retrieves test flake details over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Test Flake Detail Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Test-flake-detail-over-time)
