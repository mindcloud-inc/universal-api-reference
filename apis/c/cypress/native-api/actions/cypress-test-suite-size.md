# Cypress Test Suite Size with Cypress

Retrieves Cypress test suite size data from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Cypress Test Suite Size](https://docs.cypress.io/cloud/integrations/data-extract-api#Cypress-test-suite-size)
