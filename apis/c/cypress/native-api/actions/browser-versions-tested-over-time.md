# Browser Versions Tested Over Time with Cypress

Retrieves tested browser versions over time from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Browser Versions Tested Over Time](https://docs.cypress.io/cloud/integrations/data-extract-api#Browser-versions-tested-over-time)
