# Flaky Rate Per Project with Cypress

Retrieves flaky rates per project from Cypress Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://cloud.cypress.io/enterprise-reporting/report`
- **Official documentation:** [Flaky Rate Per Project](https://docs.cypress.io/cloud/integrations/data-extract-api#Flaky-rate-per-project)
