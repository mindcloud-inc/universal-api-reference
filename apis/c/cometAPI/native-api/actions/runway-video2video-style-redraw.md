# Runway Video2Video Style Redraw with CometAPI

Creates a Runway video style transfer in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runway/pro/video2video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Video2Video Style Redraw](https://apidoc.cometapi.com/api/video/runway/reverse-format/video-to-video-style-redraw)
