# Bria Edit Image with CometAPI

Creates a Bria image edit in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/bria/image/edit/:action`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Bria Edit Image](https://apidoc.cometapi.com/api/image/bria/image-editing)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `action` | path | `string` | yes | Bria image edit operation. |
