# Flux Get Result with CometAPI

Retrieves a Flux image result from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/flux/v1/get_result`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Flux Get Result](https://apidoc.cometapi.com/api/image/flux/flux-query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Flux task identifier. |
