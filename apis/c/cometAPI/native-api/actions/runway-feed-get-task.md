# Runway Feed Get Task with CometAPI

Retrieves a Runway feed task from CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runway/feed`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Feed Get Task](https://apidoc.cometapi.com/api/video/runway/reverse-format/feed-get-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | body | `string` | yes | Runway task identifier. |
