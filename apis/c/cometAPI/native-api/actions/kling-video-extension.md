# Kling Video Extension with CometAPI

Creates a Kling video extension in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/video-extend`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Video Extension](https://apidoc.cometapi.com/api/video/kling/video-extension)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | body | `string` | yes | Source video identifier. |
