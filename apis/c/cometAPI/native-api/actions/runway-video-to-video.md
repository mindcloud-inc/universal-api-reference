# Runway Video To Video with CometAPI

Creates a Runway video-to-video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runwayml/v1/video_to_video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Video To Video](https://apidoc.cometapi.com/api/video/runway/official-format/generate-a-video-from-a-video)
