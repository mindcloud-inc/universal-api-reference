# Kling Clear Video Selection with CometAPI

Clears a Kling video selection in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/multi-elements/clear-selection`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Clear Video Selection](https://apidoc.cometapi.com/api/video/kling/multimodal-video-editing/clear-video-selection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | body | `string` | yes | Session identifier. |
