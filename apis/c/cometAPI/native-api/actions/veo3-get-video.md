# Veo3 Get Video with CometAPI

Retrieves a Veo 3 video task from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/:video_id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Veo3 Get Video](https://apidoc.cometapi.com/api/video/veo3/self-developed/veo3-retrive)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | Video identifier. |
