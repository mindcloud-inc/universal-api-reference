# Runway Generate with CometAPI

Creates a Runway text-to-video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runway/pro/generate`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Generate](https://apidoc.cometapi.com/api/video/runway/reverse-format/generate)
