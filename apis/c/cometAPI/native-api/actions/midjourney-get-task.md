# Midjourney Get Task with CometAPI

Retrieves a Midjourney task from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/mj/task/:id/fetch`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Midjourney Get Task](https://apidoc.cometapi.com/api/image/midjourney/task-fetching-api/fetch-single-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task identifier. |
