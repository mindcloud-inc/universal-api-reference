# Create Moderation with CometAPI

Creates a moderation in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/moderations`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Create Moderation](https://www.cometapi.com/how-to-use-cometapi-a-beginners-guide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | Input text or content to moderate. |
