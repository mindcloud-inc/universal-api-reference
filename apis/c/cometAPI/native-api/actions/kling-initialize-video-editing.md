# Kling Initialize Video Editing with CometAPI

Initializes Kling video editing in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/multi-elements/init-selection`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Initialize Video Editing](https://apidoc.cometapi.com/api/video/kling/multimodal-video-editing/initialize-video-for-editing)
