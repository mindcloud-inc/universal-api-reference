# Bria Get Request with CometAPI

Retrieves a Bria request from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/bria/:request_id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Bria Get Request](https://apidoc.cometapi.com/api/image/bria/query-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `request_id` | path | `string` | yes | Bria request identifier. |
