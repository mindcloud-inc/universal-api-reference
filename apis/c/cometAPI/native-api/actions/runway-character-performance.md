# Runway Character Performance with CometAPI

Creates a Runway character performance task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runwayml/v1/character_performance`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Character Performance](https://apidoc.cometapi.com/api/video/runway/official-format/control-a-character)
