# Runway Get Task with CometAPI

Retrieves a Runway task from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/runwayml/v1/tasks/:id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Get Task](https://apidoc.cometapi.com/api/video/runway/official-format/runway-to-get-task-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Runway task identifier. |
