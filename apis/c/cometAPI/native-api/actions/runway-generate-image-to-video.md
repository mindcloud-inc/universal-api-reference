# Runway Generate Image To Video with CometAPI

Creates a Runway image-to-video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runway/pro/generate`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Generate Image To Video](https://apidoc.cometapi.com/api/video/runway/reverse-format/image-to-video)
