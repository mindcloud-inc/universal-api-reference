# Midjourney Modal with CometAPI

Creates a Midjourney modal task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/mj/submit/modal`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Midjourney Modal](https://apidoc.cometapi.com/api/image/midjourney/modal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | body | `string` | yes | Midjourney task identifier. |
