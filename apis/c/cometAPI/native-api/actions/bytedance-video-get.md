# Bytedance Video Get with CometAPI

Retrieves a ByteDance video task from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/volc/v3/contents/generations/tasks/:id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Bytedance Video Get](https://apidoc.cometapi.com/api/video/bytedance/bytedance-video-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task identifier. |
