# Create Translation with CometAPI

Creates an audio translation in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/audio/translations`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Create Translation](https://www.cometapi.com/how-to-use-cometapi-a-beginners-guide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | body | `string` | yes | Translation model ID. |
