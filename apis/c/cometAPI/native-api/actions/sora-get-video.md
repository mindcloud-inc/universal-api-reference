# Sora Get Video with CometAPI

Retrieves a Sora video task from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/:video_id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Sora Get Video](https://apidoc.cometapi.com/api/video/sora-2/official/retrieve-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | Video identifier. |
