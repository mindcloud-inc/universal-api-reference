# Kling Omni Video with CometAPI

Creates a Kling Omni video in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/omni-video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Omni Video](https://apidoc.cometapi.com/api/video/kling/omni-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `prompt` | body | `string` | yes | Omni video prompt. |
