# Veo3 Create Video with CometAPI

Creates a Veo 3 video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/videos`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Veo3 Create Video](https://apidoc.cometapi.com/api/video/veo3/self-developed/veo3-async-generation)
