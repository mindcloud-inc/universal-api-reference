# Kling Image Recognize with CometAPI

Recognizes an image with Kling in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/image-recognize`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Image Recognize](https://apidoc.cometapi.com/api/video/kling/image-recognize)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | Image input. |
