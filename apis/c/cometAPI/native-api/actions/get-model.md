# Get Model with CometAPI

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:model_id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Get Model](https://www.cometapi.com/how-to-use-cometapi-a-beginners-guide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model_id` | path | `string` | yes | Model ID to retrieve. |
