# Runway Image To Video with CometAPI

Creates a Runway image-to-video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/runwayml/v1/image_to_video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Runway Image To Video](https://apidoc.cometapi.com/api/video/runway/official-format/runway-images-raw-video)
