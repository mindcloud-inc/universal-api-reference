# Kling Delete Video Selection with CometAPI

Deletes a Kling video selection in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/multi-elements/delete-selection`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Delete Video Selection](https://apidoc.cometapi.com/api/video/kling/multimodal-video-editing/delete-video-selection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | body | `string` | yes | Session identifier. |
