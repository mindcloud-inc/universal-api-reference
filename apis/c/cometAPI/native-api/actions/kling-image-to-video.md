# Kling Image To Video with CometAPI

Creates a Kling image-to-video task in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/image2video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Image To Video](https://apidoc.cometapi.com/api/video/kling/image-to-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | Image input. |
