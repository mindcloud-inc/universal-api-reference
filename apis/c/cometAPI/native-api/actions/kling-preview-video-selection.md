# Kling Preview Video Selection with CometAPI

Retrieves a Kling video selection preview in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/multi-elements/preview-selection`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Preview Video Selection](https://apidoc.cometapi.com/api/video/kling/multimodal-video-editing/preview-selected-video-area)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `session_id` | body | `string` | yes | Session identifier. |
