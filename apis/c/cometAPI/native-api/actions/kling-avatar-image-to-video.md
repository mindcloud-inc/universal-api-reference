# Kling Avatar Image To Video with CometAPI

Creates a Kling avatar video in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/kling/v1/videos/avatar/image2video`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Kling Avatar Image To Video](https://apidoc.cometapi.com/api/video/kling/avatar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | body | `string` | yes | Avatar source image. |
