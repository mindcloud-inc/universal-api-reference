# Bytedance Image Edit with CometAPI

Creates a ByteDance image edit in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/images/edits`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Bytedance Image Edit](https://apidoc.cometapi.com/api/image/seededit-seedream/bytedance-image-editing)
