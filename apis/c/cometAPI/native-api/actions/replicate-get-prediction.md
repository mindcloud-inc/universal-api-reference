# Replicate Get Prediction with CometAPI

Retrieves a Replicate prediction from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/replicate/v1/predictions/:id`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Replicate Get Prediction](https://apidoc.cometapi.com/api/image/replicate/replicate-query)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Prediction identifier. |
