# Create Transcription with CometAPI

Creates a transcription in CometAPI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/audio/transcriptions`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Create Transcription](https://www.cometapi.com/how-to-use-cometapi-a-beginners-guide/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | body | `string` | yes | Transcription model ID. |
