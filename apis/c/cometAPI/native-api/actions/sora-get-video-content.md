# Sora Get Video Content with CometAPI

Retrieves Sora video content from CometAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/:video_id/content`
- **Base URL:** `https://api.cometapi.com`
- **Official documentation:** [Sora Get Video Content](https://apidoc.cometapi.com/api/video/sora-2/official/retrieve-video-content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | Video identifier. |
