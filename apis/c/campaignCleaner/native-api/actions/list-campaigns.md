# List Campaigns with Campaign Cleaner

Retrieves campaigns from Campaign Cleaner.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/get_campaign_list`
- **Base URL:** `https://api.campaigncleaner.com`
- **Official documentation:** [List Campaigns](https://docs.campaigncleaner.com/api-reference/endpoint/get-campaign-list)
