# List Protocols with CentralStationCRM

Retrieves all available protocols from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/protocols`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Protocols](https://api.centralstationcrm.net/api-docs/index.html#/Protocol/get_api_protocols)

## Capabilities

This operation supports [pagination](../README.md#pagination).
