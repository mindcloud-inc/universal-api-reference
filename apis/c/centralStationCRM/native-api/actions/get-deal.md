# Get Deal with CentralStationCRM

Retrieves a single deal from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/deals/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Deal](https://api.centralstationcrm.net/api-docs/index.html#/Deal/get_api_deals__id_)
