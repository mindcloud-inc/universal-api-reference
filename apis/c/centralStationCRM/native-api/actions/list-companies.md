# List Companies with CentralStationCRM

Retrieves all available companies from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/companies`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Companies](https://api.centralstationcrm.net/api-docs/index.html#/Company/get_api_companies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
