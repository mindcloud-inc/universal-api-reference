# Search People with CentralStationCRM

Finds people in CentralStationCRM by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/people/search`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Search People](https://api.centralstationcrm.net/api-docs/index.html#/Person/get_api_people_search)

## Capabilities

This operation supports [pagination](../README.md#pagination).
