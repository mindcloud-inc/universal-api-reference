# Get Protocol with CentralStationCRM

Retrieves a single protocol from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/protocols/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Protocol](https://api.centralstationcrm.net/api-docs/index.html#/Protocol/get_api_protocols__id_)
