# Count Companies with CentralStationCRM

Retrieves the companies count from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/companies/count`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Count Companies](https://api.centralstationcrm.net/api-docs/index.html#/Company/get_api_companies_count)
