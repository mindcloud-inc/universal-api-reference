# Merge Companies with CentralStationCRM

Merges duplicate company records in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/companies/:id/merge`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Merge Companies](https://api.centralstationcrm.net/api-docs/index.html#/Company/post_api_companies__id__merge)
