# Delete Company with CentralStationCRM

Deletes an existing company from CentralStationCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/companies/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Delete Company](https://api.centralstationcrm.net/api-docs/index.html#/Company/delete_api_companies__id_)
