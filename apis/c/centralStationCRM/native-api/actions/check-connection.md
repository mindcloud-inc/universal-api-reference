# Check Connection with CentralStationCRM

Checks the current CentralStationCRM API connection.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/check_connection`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Check Connection](https://api.centralstationcrm.net/api-docs/index.html#/default/get_api_check_connection)
