# Get Current User with CentralStationCRM

Retrieves the current user from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/user`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Current User](https://api.centralstationcrm.net/api-docs/index.html#/default/get_api_user)
