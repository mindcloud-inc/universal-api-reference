# Update Person with CentralStationCRM

Updates an existing person in CentralStationCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/people/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Update Person](https://api.centralstationcrm.net/api-docs/index.html#/Person/put_api_people__id_)
