# Create Company with CentralStationCRM

Creates a new company in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/companies`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Company](https://api.centralstationcrm.net/api-docs/index.html#/Company/post_api_companies)
