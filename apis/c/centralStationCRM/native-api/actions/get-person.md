# Get Person with CentralStationCRM

Retrieves a single person from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/people/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Person](https://api.centralstationcrm.net/api-docs/index.html#/Person/get_api_people__id_)
