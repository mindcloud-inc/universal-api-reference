# Get Task with CentralStationCRM

Retrieves a single task from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tasks/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Task](https://api.centralstationcrm.net/api-docs/index.html#/Task/get_api_tasks__id_)
