# Create Project with CentralStationCRM

Creates a new project in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/projects`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Project](https://api.centralstationcrm.net/api-docs/index.html#/Project/post_api_projects)
