# Create Person with CentralStationCRM

Creates a new person in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/people`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Person](https://api.centralstationcrm.net/api-docs/index.html#/Person/post_api_people)
