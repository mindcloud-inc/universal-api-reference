# Merge People with CentralStationCRM

Merges duplicate people records in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/people/:id/merge`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Merge People](https://api.centralstationcrm.net/api-docs/index.html#/Person/post_api_people__id__merge)
