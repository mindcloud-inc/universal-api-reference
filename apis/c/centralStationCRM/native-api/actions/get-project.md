# Get Project with CentralStationCRM

Retrieves a single project from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/projects/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Project](https://api.centralstationcrm.net/api-docs/index.html#/Project/get_api_projects__id_)
