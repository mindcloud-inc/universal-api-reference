# Update Deal with CentralStationCRM

Updates an existing deal in CentralStationCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/deals/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Update Deal](https://api.centralstationcrm.net/api-docs/index.html#/Deal/put_api_deals__id_)
