# Get Company with CentralStationCRM

Retrieves a single company from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/companies/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get Company](https://api.centralstationcrm.net/api-docs/index.html#/Company/get_api_companies__id_)
