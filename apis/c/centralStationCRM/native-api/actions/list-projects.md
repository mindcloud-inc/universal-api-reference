# List Projects with CentralStationCRM

Retrieves all available projects from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/projects`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Projects](https://api.centralstationcrm.net/api-docs/index.html#/Project/get_api_projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
