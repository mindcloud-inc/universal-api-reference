# Get User with CentralStationCRM

Retrieves a single user from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Get User](https://api.centralstationcrm.net/api-docs/index.html#/User/get_api_users__id_)
