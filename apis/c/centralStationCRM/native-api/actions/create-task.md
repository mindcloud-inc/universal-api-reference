# Create Task with CentralStationCRM

Creates a new task in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/tasks`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Task](https://api.centralstationcrm.net/api-docs/index.html#/Task/post_api_tasks)
