# Search Companies with CentralStationCRM

Finds companies in CentralStationCRM by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/companies/search`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Search Companies](https://api.centralstationcrm.net/api-docs/index.html#/Company/get_api_companies_search)

## Capabilities

This operation supports [pagination](../README.md#pagination).
