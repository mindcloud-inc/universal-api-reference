# List People with CentralStationCRM

Retrieves all available people from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/people`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List People](https://api.centralstationcrm.net/api-docs/index.html#/Person/get_api_people)

## Capabilities

This operation supports [pagination](../README.md#pagination).
