# Update Project with CentralStationCRM

Updates an existing project in CentralStationCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/projects/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Update Project](https://api.centralstationcrm.net/api-docs/index.html#/Project/put_api_projects__id_)
