# Delete Task with CentralStationCRM

Deletes an existing task from CentralStationCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/tasks/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Delete Task](https://api.centralstationcrm.net/api-docs/index.html#/Task/delete_api_tasks__id_)
