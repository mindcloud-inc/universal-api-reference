# Delete Person with CentralStationCRM

Deletes an existing person from CentralStationCRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/people/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Delete Person](https://api.centralstationcrm.net/api-docs/index.html#/Person/delete_api_people__id_)
