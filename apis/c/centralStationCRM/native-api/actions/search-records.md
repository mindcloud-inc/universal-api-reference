# Search Records with CentralStationCRM

Finds matching records in CentralStationCRM by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/search`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Search Records](https://api.centralstationcrm.net/api-docs/index.html#/Search/get_api_search)
