# Update Task with CentralStationCRM

Updates an existing task in CentralStationCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/tasks/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Update Task](https://api.centralstationcrm.net/api-docs/index.html#/Task/put_api_tasks__id_)
