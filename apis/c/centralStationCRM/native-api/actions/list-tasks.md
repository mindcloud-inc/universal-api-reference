# List Tasks with CentralStationCRM

Retrieves all available tasks from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tasks`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Tasks](https://api.centralstationcrm.net/api-docs/index.html#/Task/get_api_tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
