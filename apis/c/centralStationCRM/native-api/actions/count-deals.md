# Count Deals with CentralStationCRM

Retrieves the deals count from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/deals/count`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Count Deals](https://api.centralstationcrm.net/api-docs/index.html#/Deal/get_api_deals_count)
