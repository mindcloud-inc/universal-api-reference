# Search Users with CentralStationCRM

Finds users in CentralStationCRM by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users/search`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Search Users](https://api.centralstationcrm.net/api-docs/index.html#/User/get_api_users_search)

## Capabilities

This operation supports [pagination](../README.md#pagination).
