# Count People with CentralStationCRM

Retrieves the people count from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/people/count`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Count People](https://api.centralstationcrm.net/api-docs/index.html#/Person/get_api_people_count)
