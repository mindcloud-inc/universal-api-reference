# Update Company with CentralStationCRM

Updates an existing company in CentralStationCRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/companies/:id`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Update Company](https://api.centralstationcrm.net/api-docs/index.html#/Company/put_api_companies__id_)
