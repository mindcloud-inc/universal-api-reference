# List Users with CentralStationCRM

Retrieves all available users from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Users](https://api.centralstationcrm.net/api-docs/index.html#/User/get_api_users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
