# List Deals with CentralStationCRM

Retrieves all available deals from CentralStationCRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/deals`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [List Deals](https://api.centralstationcrm.net/api-docs/index.html#/Deal/get_api_deals)

## Capabilities

This operation supports [pagination](../README.md#pagination).
