# Create Protocol with CentralStationCRM

Creates a new protocol in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/protocols`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Protocol](https://api.centralstationcrm.net/api-docs/index.html#/Protocol/post_api_protocols)
