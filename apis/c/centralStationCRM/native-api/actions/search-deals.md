# Search Deals with CentralStationCRM

Finds deals in CentralStationCRM by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/deals/search`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Search Deals](https://api.centralstationcrm.net/api-docs/index.html#/Deal/get_api_deals_search)

## Capabilities

This operation supports [pagination](../README.md#pagination).
