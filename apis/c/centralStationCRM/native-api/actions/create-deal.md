# Create Deal with CentralStationCRM

Creates a new deal in CentralStationCRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/deals`
- **Base URL:** `https://api.centralstationcrm.net`
- **Official documentation:** [Create Deal](https://api.centralstationcrm.net/api-docs/index.html#/Deal/post_api_deals)
