# Get Account Tag with Chatrace

Retrieves an account tag from Chatrace.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/tags/:tag_id`
- **Base URL:** `https://api.chatrace.com`
- **Official documentation:** [Get Account Tag](https://api.chatrace.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `string` | no | The Chatrace tag ID. |
