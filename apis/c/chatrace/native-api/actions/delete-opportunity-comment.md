# Delete Opportunity Comment with Chatrace

Deletes a comment from a Chatrace opportunity.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pipelines/:pipeline_id/opportunities/:opportunity_id/comments/:comment_id`
- **Base URL:** `https://api.chatrace.com`
- **Official documentation:** [Delete Opportunity Comment](https://api.chatrace.com/swagger/)
