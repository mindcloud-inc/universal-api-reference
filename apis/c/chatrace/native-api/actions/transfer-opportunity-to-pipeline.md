# Transfer Opportunity To Pipeline with Chatrace

Transfers an opportunity to another Chatrace pipeline.

## Endpoint

- **Method:** `POST`
- **Path:** `/pipelines/:pipeline_id/opportunities/:opportunity_id/transfer-to-pipeline`
- **Base URL:** `https://api.chatrace.com`
- **Official documentation:** [Transfer Opportunity To Pipeline](https://api.chatrace.com/swagger/)
