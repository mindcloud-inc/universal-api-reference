# Get Account Custom Field By Name with Chatrace

Finds an account custom field in Chatrace by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/custom_fields/name/:custom_field_name`
- **Base URL:** `https://api.chatrace.com`
- **Official documentation:** [Get Account Custom Field By Name](https://api.chatrace.com/swagger/)
