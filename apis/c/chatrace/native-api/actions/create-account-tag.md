# Create Account Tag with Chatrace

Creates a new account tag in Chatrace.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/tags`
- **Base URL:** `https://api.chatrace.com`
- **Official documentation:** [Create Account Tag](https://api.chatrace.com/swagger/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The name of the tag to create. |
