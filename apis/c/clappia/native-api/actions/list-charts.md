# List Charts with Clappia

Retrieves app chart records from Clappia.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics/getAppCharts`
- **Base URL:** `https://api-public-v4.clappia.com`
- **Official documentation:** [List Charts](https://developer.clappia.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | query | `string` | yes | Clappia app ID. |
