# Create List with ClickSend SMS

Creates a new contact list in ClickSend SMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/lists`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Create List](https://developers.clicksend.com/docs/contacts/lists/other/create-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_name` | body | `string` | yes | Name for the contact list. |
