# List Inbound SMS with ClickSend SMS

Retrieves inbound SMS messages from ClickSend SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/sms/inbound`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [List Inbound SMS](https://developers.clicksend.com/docs/messaging/sms/inbound-sms/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Optional search query for inbound SMS records. |
