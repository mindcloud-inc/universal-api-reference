# Get SMS Template with ClickSend SMS

Retrieves an SMS template from ClickSend SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/sms/templates/:template_id`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Get SMS Template](https://developers.clicksend.com/docs/messaging/sms/other/view-a-specific-sms-template/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
