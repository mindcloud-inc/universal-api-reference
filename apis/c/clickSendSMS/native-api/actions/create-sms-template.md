# Create SMS Template with ClickSend SMS

Creates a new SMS template in ClickSend SMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/sms/templates`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Create SMS Template](https://developers.clicksend.com/docs/messaging/sms/other/create-sms-template/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_name` | body | `string` | no |
| `body` | body | `string` | no |
