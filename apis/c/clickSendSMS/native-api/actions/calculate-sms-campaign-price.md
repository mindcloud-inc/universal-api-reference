# Calculate SMS Campaign Price with ClickSend SMS

Calculates SMS campaign pricing in ClickSend SMS.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/sms-campaigns/price`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Calculate SMS Campaign Price](https://developers.clicksend.com/docs/messaging/sms-campaigns/calculate-sms-campaign-price/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `list_id` | body | `string` | no |
| `name` | body | `string` | no |
| `from` | body | `string` | no |
| `body` | body | `string` | no |
