# Get SMS Campaign with ClickSend SMS

Retrieves an SMS campaign from ClickSend SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/sms-campaigns/:sms_campaign_id`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Get SMS Campaign](https://developers.clicksend.com/docs/messaging/sms-campaigns/view-a-specific-sms-campaign/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sms_campaign_id` | path | `string` | yes |
