# List Contact Lists with ClickSend SMS

Retrieves contact lists from ClickSend SMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/lists`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [List Contact Lists](https://developers.clicksend.com/docs/contacts/lists/other/create-list)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
| `limit` | query | `number` | no | Items per page. |
