# Delete SMS Template with ClickSend SMS

Deletes an existing SMS template from ClickSend SMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v3/sms/templates/:template_id`
- **Base URL:** `https://rest.clicksend.com`
- **Official documentation:** [Delete SMS Template](https://developers.clicksend.com/docs/messaging/sms/other/delete-sms-template/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | path | `string` | yes |
