# Get Ingredient Details with CocktailDB

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup.php`
- **Base URL:** `https://www.thecocktaildb.com/api/json/v1/{apiKey}`
- **Official documentation:** [Get Ingredient Details](https://www.thecocktaildb.com/api.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `iid` | query | `number` | yes | Return details for this ingredient ID. |
