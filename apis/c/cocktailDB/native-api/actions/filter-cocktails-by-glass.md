# Filter Cocktails by Glass with CocktailDB

- **Method:** `GET`
- **Path:** `/filter.php`
- **Base URL:** `https://www.thecocktaildb.com/api/json/v1/{apiKey}`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `g` | query | `string` | yes | Filter cocktails by glass type. |
