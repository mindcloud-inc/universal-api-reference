# Get Cocktail Details with CocktailDB

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup.php`
- **Base URL:** `https://www.thecocktaildb.com/api/json/v1/{apiKey}`
- **Official documentation:** [Get Cocktail Details](https://www.thecocktaildb.com/api.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `i` | query | `number` | yes | Return full details for this cocktail ID. |
