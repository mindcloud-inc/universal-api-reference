# Set Member Role with Cirra

Updates a Cirra member role by user ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/members/:userId`
- **Base URL:** `http://api-public:9801`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `list` | yes |
| `roleId` | body | `list` | yes |
