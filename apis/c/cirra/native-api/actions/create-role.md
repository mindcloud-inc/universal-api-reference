# Create Role with Cirra

Creates a new role in Cirra.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/cirra/roles`
- **Base URL:** `http://api-public:9801`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | no |
