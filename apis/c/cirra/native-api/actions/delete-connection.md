# Delete Connection with Cirra

Deletes a Cirra connection by credential ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/cirra/connections/:credentialId`
- **Base URL:** `http://api-public:9801`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `credentialId` | path | `list` | yes | The connection credential ID to delete. |
