# Delete Role with Cirra

Deletes a role from Cirra by role ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/cirra/roles/:roleId`
- **Base URL:** `http://api-public:9801`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `roleId` | path | `list` | yes |
