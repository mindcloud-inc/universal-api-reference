# Retrieve Custom Domain with condoo

Retrieves a custom domain from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/{domain_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Custom Domain](https://trk.condoo.systems/en/api-documentation/domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `number` | yes | Required custom domain ID. |
