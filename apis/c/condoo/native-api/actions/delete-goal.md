# Delete Goal with condoo

Deletes an existing goal from condoo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/goals/{goal_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Delete Goal](https://trk.condoo.systems/en/api-documentation/goals)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `goal_id` | path | `number` | yes | Required goal ID. |
