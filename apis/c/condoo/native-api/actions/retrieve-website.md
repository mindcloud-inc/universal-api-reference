# Retrieve Website with condoo

Retrieves a website from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/websites/{website_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Website](https://trk.condoo.systems/en/api-documentation/websites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `number` | yes | Required website ID. |
