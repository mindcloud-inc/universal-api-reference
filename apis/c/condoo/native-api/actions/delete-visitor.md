# Delete Visitor with condoo

Deletes an existing visitor from condoo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/visitors/{visitor_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Delete Visitor](https://trk.condoo.systems/en/api-documentation/visitors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `visitor_id` | path | `string` | yes | Required visitor ID or visitor UUID. |
