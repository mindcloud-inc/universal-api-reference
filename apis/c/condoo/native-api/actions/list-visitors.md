# List Visitors with condoo

Retrieves visitors from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/visitors/`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [List Visitors](https://trk.condoo.systems/en/api-documentation/visitors)

## Capabilities

This operation supports [pagination](../README.md#pagination).
