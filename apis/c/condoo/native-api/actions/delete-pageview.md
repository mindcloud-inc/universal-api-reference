# Delete Pageview with condoo

Deletes an existing pageview from condoo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/pageviews-lightweight/{event_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Delete Pageview](https://trk.condoo.systems/en/api-documentation/pageviews-lightweight)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `number` | yes | Required pageview event ID. |
