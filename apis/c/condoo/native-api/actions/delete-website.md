# Delete Website with condoo

Deletes an existing website from condoo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/websites/{website_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Delete Website](https://trk.condoo.systems/en/api-documentation/websites)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `number` | yes | Required website ID. |
