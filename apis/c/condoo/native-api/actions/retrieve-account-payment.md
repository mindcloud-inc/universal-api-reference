# Retrieve Account Payment with condoo

Retrieves an account payment from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/payments/{payment_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Account Payment](https://trk.condoo.systems/en/api-documentation/payments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `payment_id` | path | `number` | yes | Required payment ID. |
