# Retrieve Pageview with condoo

Retrieves a pageview from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/pageviews-lightweight/{event_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Pageview](https://trk.condoo.systems/en/api-documentation/pageviews-lightweight)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `number` | yes | Required pageview event ID. |
