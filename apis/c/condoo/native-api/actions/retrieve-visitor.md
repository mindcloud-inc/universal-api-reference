# Retrieve Visitor with condoo

Retrieves a visitor from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/visitors/{visitor_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Visitor](https://trk.condoo.systems/en/api-documentation/visitors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `visitor_id` | path | `string` | yes | Required visitor ID or visitor UUID. |
