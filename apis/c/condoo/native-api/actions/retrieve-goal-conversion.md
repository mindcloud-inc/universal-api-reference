# Retrieve Goal Conversion with condoo

Retrieves a goal conversion from condoo.

## Endpoint

- **Method:** `GET`
- **Path:** `/goals-conversions/{conversion_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Retrieve Goal Conversion](https://trk.condoo.systems/en/api-documentation/goals-conversions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversion_id` | path | `number` | yes | Required goal conversion ID. |
