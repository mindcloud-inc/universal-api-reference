# Delete Custom Domain with condoo

Deletes an existing custom domain from condoo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domains/{domain_id}`
- **Base URL:** `https://trk.condoo.systems/api`
- **Official documentation:** [Delete Custom Domain](https://trk.condoo.systems/en/api-documentation/domains)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | path | `number` | yes | Required custom domain ID. |
