# Get Tags with Campaign Refinery

Retrieves all tags from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/get-tags`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Tags](https://developers.campaignrefinery.com/reference/get-tags)

## Capabilities

This operation supports [sorting](../README.md#sorting).
