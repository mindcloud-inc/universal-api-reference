# Get Broadcast Stats with Campaign Refinery

Retrieves broadcast stats from Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/broadcasts/get_broadcast_stats`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Broadcast Stats](https://developers.campaignrefinery.com/reference/get-broadcast-stats)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `broadcast_uuid` | body | `string` | yes | The unique ID of the broadcast. |
