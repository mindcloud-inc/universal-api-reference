# Get Attribute Groups with Campaign Refinery

Retrieves attribute groups from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/attributes/get-attribute-groups`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Attribute Groups](https://developers.campaignrefinery.com/reference/get-attribute-groups)

## Capabilities

This operation supports [sorting](../README.md#sorting).
