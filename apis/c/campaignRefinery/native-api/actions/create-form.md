# Create Form with Campaign Refinery

Creates a new form in Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/forms/create-form`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Create Form](https://developers.campaignrefinery.com/reference/create-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The form's name. |
