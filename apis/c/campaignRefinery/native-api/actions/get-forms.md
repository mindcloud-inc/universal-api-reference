# Get Forms with Campaign Refinery

Retrieves all forms from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/get-forms`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Forms](https://developers.campaignrefinery.com/reference/get-forms)

## Capabilities

This operation supports [sorting](../README.md#sorting).
