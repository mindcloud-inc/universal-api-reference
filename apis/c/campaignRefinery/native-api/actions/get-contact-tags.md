# Get Contact Tags with Campaign Refinery

Retrieves tags for a contact from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/get-contact-tags`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Contact Tags](https://developers.campaignrefinery.com/reference/get-contact-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Campaign Refinery contact ID. |
