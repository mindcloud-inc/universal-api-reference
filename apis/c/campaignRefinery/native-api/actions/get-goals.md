# Get Goals with Campaign Refinery

Retrieves all goals from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/goals/get-goals`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Goals](https://developers.campaignrefinery.com/reference/get-goals)

## Capabilities

This operation supports [sorting](../README.md#sorting).
