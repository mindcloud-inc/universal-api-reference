# Get Top Ranked Contacts with Campaign Refinery

Retrieves top ranked contacts from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/gamification/get-ranked-balance`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Top Ranked Contacts](https://developers.campaignrefinery.com/reference/get-top-ranked-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of ranked contacts to return. |
