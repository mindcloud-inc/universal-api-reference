# Get Tag by Name with Campaign Refinery

Retrieves a tag by name from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/get-tag`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Tag by Name](https://developers.campaignrefinery.com/reference/get-tag-by-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Campaign Refinery tag name. |
