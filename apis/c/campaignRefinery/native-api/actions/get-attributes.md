# Get Attributes with Campaign Refinery

Retrieves all attributes from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/attributes/get-attributes`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Attributes](https://developers.campaignrefinery.com/reference/get-attributes)

## Capabilities

This operation supports [sorting](../README.md#sorting).
