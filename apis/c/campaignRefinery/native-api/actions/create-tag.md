# Create Tag with Campaign Refinery

Creates a new tag in Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags/create-tag`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Create Tag](https://developers.campaignrefinery.com/reference/create-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The tag's name. |
