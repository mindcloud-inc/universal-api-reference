# Get Goal by ID with Campaign Refinery

Retrieves a goal by ID from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/goals/get-goal`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Goal by ID](https://developers.campaignrefinery.com/reference/get-goal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Campaign Refinery goal ID. |
