# Create Attribute Group with Campaign Refinery

Creates a new attribute group in Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/attributes/create-group`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Create Attribute Group](https://developers.campaignrefinery.com/reference/create-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The group name. |
