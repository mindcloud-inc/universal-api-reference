# Export Points Balance CSV with Campaign Refinery

Retrieves the points balance CSV from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/gamification/get-points-balance`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Export Points Balance CSV](https://developers.campaignrefinery.com/reference/csv-with-overall-points-balance-for-all-contacts)
