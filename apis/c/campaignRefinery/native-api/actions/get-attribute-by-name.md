# Get Attribute by Name with Campaign Refinery

Retrieves an attribute by name from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/attributes/get-attribute`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Attribute by Name](https://developers.campaignrefinery.com/reference/get-attribute-by-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key_name` | query | `string` | yes | Campaign Refinery attribute key/name. |
