# Get Daily Points with Campaign Refinery

Retrieves daily points from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/gamification/get-daily-points`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Daily Points](https://developers.campaignrefinery.com/reference/get-the-daily-in-and-out-of-points)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | query | `date` | yes | Date for daily point movement. |
