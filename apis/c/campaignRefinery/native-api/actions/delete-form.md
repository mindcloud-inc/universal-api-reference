# Delete Form with Campaign Refinery

Deletes an existing form from Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/forms/delete-form`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Delete Form](https://developers.campaignrefinery.com/reference/delete-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The form's ID. |
