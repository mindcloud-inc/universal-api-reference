# Get Goal by Name with Campaign Refinery

Retrieves a goal by name from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/goals/get-goal`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Goal by Name](https://developers.campaignrefinery.com/reference/get-goal-by-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Campaign Refinery goal name. |
