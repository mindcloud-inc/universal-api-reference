# Create Goal with Campaign Refinery

Creates a new goal in Campaign Refinery.

## Endpoint

- **Method:** `POST`
- **Path:** `/goals/create-goal`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Create Goal](https://developers.campaignrefinery.com/reference/create-goal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | The goal's name. |
