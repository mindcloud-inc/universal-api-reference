# Get Form by Name with Campaign Refinery

Retrieves a form by name from Campaign Refinery.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/get-form`
- **Base URL:** `https://app.campaignrefinery.com/rest`
- **Official documentation:** [Get Form by Name](https://developers.campaignrefinery.com/reference/get-form-by-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Campaign Refinery form name. |
