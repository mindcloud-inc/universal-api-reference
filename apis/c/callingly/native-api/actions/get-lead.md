# Get Lead with Callingly

Retrieves a lead from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/leads/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Get Lead](https://help.callingly.com/article/38-callingly-api-documentation#Get-Lead-vwwS6)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly lead ID to retrieve. |
