# List Team Agents with Callingly

Retrieves team agents from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/{{id}}/agents`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [List Team Agents](https://help.callingly.com/article/38-callingly-api-documentation#list-team-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
