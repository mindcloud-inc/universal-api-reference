# Get Team with Callingly

Retrieves a team from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/teams/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Get Team](https://help.callingly.com/article/38-callingly-api-documentation#get-team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
