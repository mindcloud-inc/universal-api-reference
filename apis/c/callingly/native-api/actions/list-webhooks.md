# List Webhooks with Callingly

Retrieves webhooks from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [List Webhooks](https://help.callingly.com/article/38-callingly-api-documentation#List-All-Webhooks-vkO9i)
