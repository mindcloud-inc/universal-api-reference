# Delete Lead with Callingly

Deletes a lead from Callingly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/leads/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Delete Lead](https://help.callingly.com/article/38-callingly-api-documentation#Delete-Lead-WgweT)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly lead ID to delete. |
