# Get Agent Schedule with Callingly

Retrieves an agent schedule from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/{{id}}/schedule`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Get Agent Schedule](https://help.callingly.com/article/38-callingly-api-documentation#get-agent-schedule)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
