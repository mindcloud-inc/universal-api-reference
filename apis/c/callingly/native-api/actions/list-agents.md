# List Agents with Callingly

Retrieves agents from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [List Agents](https://help.callingly.com/article/38-callingly-api-documentation#list-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | query | `string` | no |
