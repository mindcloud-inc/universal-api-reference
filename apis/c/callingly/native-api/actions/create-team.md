# Create Team with Callingly

Creates a team in Callingly.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/teams`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Create Team](https://help.callingly.com/article/38-callingly-api-documentation#create-team)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | body | `string` | no |
| `name` | body | `string` | yes |
