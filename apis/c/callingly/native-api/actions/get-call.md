# Get Call with Callingly

Retrieves a call from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/calls/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Get Call](https://help.callingly.com/article/38-callingly-api-documentation#Get-Call-JlDGl)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly call ID to retrieve. |
