# Delete Client with Callingly

Deletes a client from Callingly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/clients/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Delete Client](https://help.callingly.com/article/38-callingly-api-documentation#delete-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly client ID to delete. |
