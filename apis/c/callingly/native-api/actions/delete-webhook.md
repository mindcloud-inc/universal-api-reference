# Delete Webhook with Callingly

Deletes a webhook from Callingly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Delete Webhook](https://help.callingly.com/article/38-callingly-api-documentation#Delete-a-Webhook-GyGhB)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly webhook ID to delete. |
