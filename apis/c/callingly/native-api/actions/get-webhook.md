# Get Webhook with Callingly

Retrieves a webhook from Callingly.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/{{id}}`
- **Base URL:** `https://api.callingly.com`
- **Official documentation:** [Get Webhook](https://help.callingly.com/article/38-callingly-api-documentation#Get-a-Webhook-iB9fR)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Callingly webhook ID to retrieve. |
