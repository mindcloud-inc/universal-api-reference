# List Rates with CoinCap

Retrieves conversion rates from CoinCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/rates`
- **Base URL:** `https://rest.coincap.io/v3`
- **Official documentation:** [List Rates](https://pro.coincap.io/api-docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | no | Comma-separated rate IDs to include. |
