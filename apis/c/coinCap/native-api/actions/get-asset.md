# Get Asset with CoinCap

Retrieves an asset from CoinCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:slug`
- **Base URL:** `https://rest.coincap.io/v3`
- **Official documentation:** [Get Asset](https://pro.coincap.io/api-docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The asset slug to retrieve. |
