# List Exchanges with CoinCap

Retrieves exchanges from CoinCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/exchanges`
- **Base URL:** `https://rest.coincap.io/v3`
- **Official documentation:** [List Exchanges](https://pro.coincap.io/api-docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
