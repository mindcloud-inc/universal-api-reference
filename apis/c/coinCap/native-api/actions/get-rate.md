# Get Rate with CoinCap

Retrieves a conversion rate from CoinCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/rates/:slug`
- **Base URL:** `https://rest.coincap.io/v3`
- **Official documentation:** [Get Rate](https://pro.coincap.io/api-docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The rate slug to retrieve. |
