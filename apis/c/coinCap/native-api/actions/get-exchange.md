# Get Exchange with CoinCap

Retrieves an exchange from CoinCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/exchanges/:exchange`
- **Base URL:** `https://rest.coincap.io/v3`
- **Official documentation:** [Get Exchange](https://pro.coincap.io/api-docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `exchange` | path | `string` | yes | The exchange ID to retrieve. |
