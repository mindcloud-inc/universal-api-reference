# List Pull Request Reviews with Calibre

Retrieves pull request reviews from Calibre.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.calibreapp.com`
- **Official documentation:** [List Pull Request Reviews](https://calibreapp.com/docs/automation/pull-request-reviews#list-pull-request-reviews)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `variables.site` | body | `string` | yes |
