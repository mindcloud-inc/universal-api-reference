# Search Recording Videos with ClassDo

Finds recording videos in ClassDo by search criteria.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.classdo.com`
- **Official documentation:** [Search Recording Videos](https://developer.classdo.com/schema/viewer.doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | GraphQL query payload. |
