# Get Viewer with ClassDo

Retrieves the current viewer from ClassDo.

## Endpoint

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://api.classdo.com`
- **Official documentation:** [Get Viewer](https://developer.classdo.com/schema/viewer.doc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | GraphQL query payload. |
