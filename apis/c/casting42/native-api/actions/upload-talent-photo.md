# Upload Talent Photo with Casting42

Uploads a photo for a Casting42 talent.

## Endpoint

- **Method:** `POST`
- **Path:** `/talents/upload-photo`
- **Base URL:** `https://casting42.com`
- **Official documentation:** [Upload Talent Photo](https://documenter.getpostman.com/view/24607394/2s9YR6buRP)
