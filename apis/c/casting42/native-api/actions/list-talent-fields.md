# List Talent Fields with Casting42

Retrieves available talent fields from Casting42.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/settings/fields`
- **Base URL:** `https://casting42.com`
- **Official documentation:** [List Talent Fields](https://documenter.getpostman.com/view/24607394/2s9YR6buRP)
