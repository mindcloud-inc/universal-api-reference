# Get environment alias with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environment_aliases/:environmentAliasId`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get environment alias](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environment-aliases)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentAliasId` | path | `string` | no |
| `spaceId` | path | `string` | no |
