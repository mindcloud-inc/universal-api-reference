# List assets with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environments/:environmentId/assets`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List assets](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/assets)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentId` | path | `string` | no |
| `spaceId` | path | `string` | no |
