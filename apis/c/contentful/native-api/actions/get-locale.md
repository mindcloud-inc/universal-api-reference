# Get locale with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environments/:environmentId/locales/:localeId`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get locale](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/locales)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentId` | path | `string` | no |
| `localeId` | path | `string` | no |
| `spaceId` | path | `string` | no |
