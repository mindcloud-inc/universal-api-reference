# List environments with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environments`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List environments](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environments)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
