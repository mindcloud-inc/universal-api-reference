# List environment aliases with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environment_aliases`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List environment aliases](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environment-aliases)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
