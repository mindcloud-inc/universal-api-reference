# Get environment with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environments/:environmentId`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get environment](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environments)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentId` | path | `string` | no |
| `spaceId` | path | `string` | no |
