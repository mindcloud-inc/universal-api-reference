# List locales with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/environments/:environmentId/locales`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List locales](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/locales)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `environmentId` | path | `string` | no |
| `spaceId` | path | `string` | no |
