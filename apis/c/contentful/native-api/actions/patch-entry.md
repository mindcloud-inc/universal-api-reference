# Patch entry with Contentful

## Endpoint

- **Method:** `PATCH`
- **Path:** `/spaces/:spaceId/environments/:environmentId/entries/:entryId`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Patch entry](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/entries)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entryId` | path | `string` | no |
| `environmentId` | path | `string` | no |
| `spaceId` | path | `string` | no |
