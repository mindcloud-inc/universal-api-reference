# Get space with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get space](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/spaces)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
