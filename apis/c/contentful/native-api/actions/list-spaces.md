# List spaces with Contentful

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List spaces](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/spaces)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
