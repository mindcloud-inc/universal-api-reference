# Delete Contact with CalendarHero

Deletes a contact from CalendarHero.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact/{id}`
- **Base URL:** `https://api.calendarhero.com`
- **Official documentation:** [Delete Contact](https://api.calendarhero.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The contact ID. |
