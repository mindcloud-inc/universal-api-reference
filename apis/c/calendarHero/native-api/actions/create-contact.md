# Create Contact with CalendarHero

Creates a contact in CalendarHero.

## Endpoint

- **Method:** `POST`
- **Path:** `/contact`
- **Base URL:** `https://api.calendarhero.com`
- **Official documentation:** [Create Contact](https://api.calendarhero.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | no | Contact payload to create. |
