# Update Contact with CalendarHero

Updates a contact in CalendarHero.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contact/{id}`
- **Base URL:** `https://api.calendarhero.com`
- **Official documentation:** [Update Contact](https://api.calendarhero.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `string` | no | Contact fields to update. |
| `id` | query | `string` | no | The contact ID. |
