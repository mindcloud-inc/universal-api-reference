# Get Contact with CalendarHero

Retrieves a contact from CalendarHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/{id}`
- **Base URL:** `https://api.calendarhero.com`
- **Official documentation:** [Get Contact](https://api.calendarhero.com/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `basic` | query | `string` | no | Return the basic contact view only. |
| `id` | path | `string` | no | The contact ID. |
