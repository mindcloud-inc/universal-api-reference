# Get Domain Billing Summary with Crexendo

Retrieves a domain billing summary from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain/billing`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [Get Domain Billing Summary](https://docs.ns-api.com/reference/domainbilling)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain identifier, for example apps.mindcloud.co. |
