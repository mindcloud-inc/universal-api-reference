# Get Domain with Crexendo

Retrieves a domain from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [Get Domain](https://docs.ns-api.com/reference/getdomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain identifier, for example apps.mindcloud.co. |
