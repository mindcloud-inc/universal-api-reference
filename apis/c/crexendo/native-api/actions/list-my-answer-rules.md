# List My Answer Rules with Crexendo

Retrieves your answer rules from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/~/users/~/answerrules`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [List My Answer Rules](https://docs.ns-api.com/reference/get_domains-users-answerrules)

## Capabilities

This operation supports [pagination](../README.md#pagination).
