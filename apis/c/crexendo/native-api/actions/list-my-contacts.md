# List My Contacts with Crexendo

Retrieves your contacts from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/~/users/~/contacts`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [List My Contacts](https://docs.ns-api.com/reference/get_domains-users-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
