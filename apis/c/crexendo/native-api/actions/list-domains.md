# List Domains with Crexendo

Retrieves domains from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [List Domains](https://docs.ns-api.com/reference/getdomains)

## Capabilities

This operation supports [pagination](../README.md#pagination).
