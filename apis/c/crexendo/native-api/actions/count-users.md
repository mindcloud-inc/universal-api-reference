# Count Users with Crexendo

Retrieves a user count for a domain in Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain/users/count`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [Count Users](https://docs.ns-api.com/reference/countusers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain identifier, for example apps.mindcloud.co. |
