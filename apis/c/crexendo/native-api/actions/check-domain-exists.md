# Check Domain Exists with Crexendo

Checks whether a domain exists in Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain/count`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [Check Domain Exists](https://docs.ns-api.com/reference/countdomain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain identifier, for example apps.mindcloud.co. |
