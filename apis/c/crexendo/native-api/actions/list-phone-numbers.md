# List Phone Numbers with Crexendo

Retrieves phone numbers from Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonenumbers`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [List Phone Numbers](https://docs.ns-api.com/reference/getphonenumbers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
