# Count Domain Active Calls with Crexendo

Retrieves an active call count for a domain in Crexendo.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:domain/calls/count`
- **Base URL:** `https://ns-api.com/ns-api/v2`
- **Official documentation:** [Count Domain Active Calls](https://docs.ns-api.com/reference/get_domains-domain-calls-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | path | `string` | yes | Domain identifier, for example apps.mindcloud.co. |
