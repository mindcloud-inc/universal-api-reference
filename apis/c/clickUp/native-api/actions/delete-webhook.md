# Delete Webhook with ClickUp

Delete a configured webhook in ClickUp.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhook/:webhook_id`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [Delete Webhook](https://developer.clickup.com/reference/getwebhooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes |
