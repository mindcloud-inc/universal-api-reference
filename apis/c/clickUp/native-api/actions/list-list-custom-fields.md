# List List Custom Fields with ClickUp

View the Custom Fields in a specific List.

## Endpoint

- **Method:** `GET`
- **Path:** `list/:list_id/field`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [List List Custom Fields](https://developer.clickup.com/reference/getaccessiblecustomfields)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `list_id` | path | `string` | yes |
