# List Authorized Workspaces with ClickUp

View the Workspaces available to the authenticated user.

## Endpoint

- **Method:** `GET`
- **Path:** `team`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [List Authorized Workspaces](https://developer.clickup.com/reference/getauthorizedteams)
