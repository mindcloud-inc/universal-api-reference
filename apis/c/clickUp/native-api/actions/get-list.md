# Get List with ClickUp

Retrieves details for a List from ClickUp.

## Endpoint

- **Method:** `GET`
- **Path:** `list/:list_id`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [Get List](https://developer.clickup.com/reference/getlist)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `list_id` | path | `string` | yes |
