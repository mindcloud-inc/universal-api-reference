# List Webhook with ClickUp

Lists a team webhooks in ClickUp for selected events.

## Endpoint

- **Method:** `GET`
- **Path:** `team/:team_id/webhook`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [List Webhook](https://developer.clickup.com/reference/getwebhooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `list` | yes |
