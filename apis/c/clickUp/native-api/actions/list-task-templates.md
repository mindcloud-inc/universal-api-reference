# List Task Templates with ClickUp

## Endpoint

- **Method:** `GET`
- **Path:** `team/:team_id/taskTemplate`
- **Base URL:** `https://api.clickup.com/api/v2/`
- **Official documentation:** [List Task Templates](https://developer.clickup.com/reference/gettasktemplates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | path | `list` | yes |
