# List Available Currencies with Cloudmersive Currency

Retrieves available currencies from Cloudmersive Currency.

## Endpoint

- **Method:** `POST`
- **Path:** `/currency/exchange-rates/list-available`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [List Available Currencies](https://api.cloudmersive.com/docs/currency.asp#operation--currency-exchange-rates-list-available-post)
