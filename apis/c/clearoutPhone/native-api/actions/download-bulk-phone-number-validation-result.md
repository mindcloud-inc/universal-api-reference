# Download Bulk Phone Number Validation Result with ClearoutPhone

Retrieves the result of a bulk validation job from ClearoutPhone.

## Endpoint

- **Method:** `POST`
- **Path:** `/download/result`
- **Base URL:** `https://api.clearoutphone.io/v1`
- **Official documentation:** [Download Bulk Phone Number Validation Result](https://docs.clearoutphone.io/#api-Phone_Number_Validation_API-Result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | body | `string` | yes | Bulk validation list identifier |
