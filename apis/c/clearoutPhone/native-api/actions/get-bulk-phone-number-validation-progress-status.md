# Get Bulk Phone Number Validation Progress Status with ClearoutPhone

Retrieves the progress status of a bulk validation job in ClearoutPhone.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonenumber/bulk/progress_status`
- **Base URL:** `https://api.clearoutphone.io/v1`
- **Official documentation:** [Get Bulk Phone Number Validation Progress Status](https://docs.clearoutphone.io/#api-Phone_Number_Validation_API-ProgressStatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | query | `string` | yes | Bulk validation list identifier |
