# Get Available Credits with ClearoutPhone

Retrieves the available credits from ClearoutPhone.

## Endpoint

- **Method:** `GET`
- **Path:** `/phonenumber/getcredits`
- **Base URL:** `https://api.clearoutphone.io/v1`
- **Official documentation:** [Get Available Credits](https://docs.clearoutphone.io/#api-Phone_Number_Validation_API-GetCredits)
