# Get Media Information with Cloudmersive Video and Media

Retrieves media information from Cloudmersive Video and Media.

## Endpoint

- **Method:** `POST`
- **Path:** `/video/convert/get-info`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Media Information](https://api.cloudmersive.com/docs/video.asp#operation--video-convert-get-info-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileUrl` | body | `string` | no | URL of a video or audio file to inspect. |
| `inputFile` | body | `file` | no | Input video or audio file to inspect. |
