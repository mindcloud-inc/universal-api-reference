# Get Regional Carbon Intensity By Postcode with Carbon Intensity

Retrieves current regional carbon intensity for a postcode.

## Endpoint

- **Method:** `GET`
- **Path:** `/regional/postcode/:postcode`
- **Base URL:** `https://api.carbonintensity.org.uk`
- **Official documentation:** [Get Regional Carbon Intensity By Postcode](https://api.carbonintensity.org.uk/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postcode` | path | `string` | yes | Valid outward postcode such as SW1A, EH1, M1, or BS1. |
