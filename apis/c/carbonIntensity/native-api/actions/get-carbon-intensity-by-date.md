# Get Carbon Intensity By Date with Carbon Intensity

Retrieves carbon intensity for a specific date.

## Endpoint

- **Method:** `GET`
- **Path:** `/intensity/date/:date`
- **Base URL:** `https://api.carbonintensity.org.uk`
- **Official documentation:** [Get Carbon Intensity By Date](https://api.carbonintensity.org.uk/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `date` | path | `string` | yes | Date in YYYY-MM-DD format exactly as required by the API path. |
