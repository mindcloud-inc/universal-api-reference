# Get Receipt Process with CommercioNetwork

Retrieves a receipt process from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/process/:process_id`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Receipt Process](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#sent-receipt-message-specific-process-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `process_id` | path | `string` | yes | The receipt process ID. |
