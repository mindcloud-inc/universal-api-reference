# List Received Documents with CommercioNetwork

Retrieves received shared documents from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharedoc/received`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Received Documents](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#received-sharedoc)
