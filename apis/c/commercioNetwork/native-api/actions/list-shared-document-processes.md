# List Shared Document Processes with CommercioNetwork

Retrieves shared document processes from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharedoc/process`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Shared Document Processes](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#sent-processes)
