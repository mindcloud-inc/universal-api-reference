# Get Shared Document Process with CommercioNetwork

Retrieves a shared document process from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharedoc/process/:process_id`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Shared Document Process](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#specific-sent-process-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `process_id` | path | `string` | yes | The shared document process ID. |
