# List Sent Documents with CommercioNetwork

Retrieves sent shared documents from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharedoc/sent`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Sent Documents](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#sent-sharedoc)
