# Get Wallet Address with CommercioNetwork

Retrieves your wallet address from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet/address`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Wallet Address](https://docs.commercio.network/app_developers/commercioapi-wallet.html#get-your-wallet-address-and-balance)
