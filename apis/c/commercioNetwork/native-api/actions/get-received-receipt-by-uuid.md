# Get Received Receipt by UUID with CommercioNetwork

Retrieves a received receipt from CommercioNetwork by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/received/:uuid`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Received Receipt by UUID](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#received-receipt-message)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The received receipt UUID. |
