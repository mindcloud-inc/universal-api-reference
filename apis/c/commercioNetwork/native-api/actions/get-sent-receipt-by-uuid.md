# Get Sent Receipt by UUID with CommercioNetwork

Retrieves a sent receipt from CommercioNetwork by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/sent/:uuid`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Sent Receipt by UUID](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#receipt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | The sent receipt UUID. |
