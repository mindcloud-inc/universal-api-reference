# List Receipt Processes with CommercioNetwork

Retrieves receipt processes from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/process`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Receipt Processes](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#sent-receipts-processes)
