# List Wallet Transfer Processes with CommercioNetwork

Retrieves wallet transfer processes from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet/transfers/process`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Wallet Transfer Processes](https://docs.commercio.network/app_developers/commercioapi-wallet.html#sent-token-process-list)
