# Get Shared Document by UUID with CommercioNetwork

Retrieves a shared document from CommercioNetwork by UUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sharedoc/:document_uuid`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Shared Document by UUID](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_uuid` | path | `string` | yes | The shared document UUID. |
