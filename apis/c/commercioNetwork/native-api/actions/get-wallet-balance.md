# Get Wallet Balance with CommercioNetwork

Retrieves your wallet balance from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/wallet/balance`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [Get Wallet Balance](https://docs.commercio.network/app_developers/commercioapi-wallet.html#get-wallet-balance)
