# List Received Receipts with CommercioNetwork

Retrieves received receipts from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/received`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Received Receipts](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#received-receipt-message)
