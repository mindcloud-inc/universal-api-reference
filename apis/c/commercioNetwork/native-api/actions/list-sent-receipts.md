# List Sent Receipts with CommercioNetwork

Retrieves sent receipts from CommercioNetwork.

## Endpoint

- **Method:** `GET`
- **Path:** `/receipts/sent`
- **Base URL:** `https://dev-api.commercio.app/v1`
- **Official documentation:** [List Sent Receipts](https://docs.commercio.network/app_developers/commercioapi-sharedoc.html#receipt)
