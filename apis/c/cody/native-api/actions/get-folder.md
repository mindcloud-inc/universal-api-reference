# Get Folder with Cody

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:id`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Get Folder](https://developers.meetcody.ai/operation/operation-get-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id of the folder. |
