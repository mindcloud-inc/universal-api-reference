# Get Document with Cody

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Get Document](https://developers.meetcody.ai/operation/operation-get-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id of the document. |
