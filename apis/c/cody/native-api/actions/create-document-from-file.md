# Create Document from File with Cody

## Endpoint

- **Method:** `POST`
- **Path:** `/documents/file`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Create Document from File](https://developers.meetcody.ai/operation/operation-create-document-from-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | body | `string` | no | Id of the folder to create the document in. |
| `key` | body | `string` | no | The key you receive after uploading a file with Get Upload URL. |
