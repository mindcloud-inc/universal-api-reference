# List Folders with Cody

## Endpoint

- **Method:** `GET`
- **Path:** `/folders`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [List Folders](https://developers.meetcody.ai/operation/operation-list-folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | no | Keyword to filter the list to folders that partially match the name. |
