# Create Folder with Cody

## Endpoint

- **Method:** `POST`
- **Path:** `/folders`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Create Folder](https://developers.meetcody.ai/operation/operation-create-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Name of the folder. |
