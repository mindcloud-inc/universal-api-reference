# Update Folder with Cody

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/:id`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Update Folder](https://developers.meetcody.ai/operation/operation-update-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id of the folder. |
| `name` | body | `string` | no | Folder name. |
