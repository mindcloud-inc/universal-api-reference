# List Bots with Cody

## Endpoint

- **Method:** `GET`
- **Path:** `/bots`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [List Bots](https://developers.meetcody.ai/operation/operation-list-bots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyword` | query | `string` | no | Keyword to filter the list of bots to only those that at least partially match the bot name. |
