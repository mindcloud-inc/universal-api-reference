# Delete Conversation with Cody

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversations/:id`
- **Base URL:** `https://getcody.ai/api/v1`
- **Official documentation:** [Delete Conversation](https://developers.meetcody.ai/operation/operation-delete-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id of the conversation. |
