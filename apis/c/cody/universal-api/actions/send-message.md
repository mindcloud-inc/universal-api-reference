# Cody: Send Message



```
POST https://connect.mindcloud.co/v1/universal/cody/latest/actions/send-message
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Cody `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X POST "https://connect.mindcloud.co/v1/universal/cody/latest/actions/send-message" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "content": "string",
  "conversationId": "string"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/cody/latest/actions/send-message', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "content": "string",
    "conversationId": "string"
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `content` | string | yes | Message content, up to 2000 characters. |
| `conversationId` | string | yes | Id of the conversation to send the message to. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "content": "string",
      "conversationId": "string",
      "createdAt": "2026-05-07T12:00:00.000Z",
      "failedResponding": true,
      "flagged": true,
      "id": "string",
      "machine": true
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `content` | string | Message content. |
| `conversationId` | string | Parent conversation identifier. |
| `createdAt` | date | Message creation timestamp. |
| `failedResponding` | boolean | Whether Cody failed while responding. |
| `flagged` | boolean | Whether the message was flagged. |
| `id` | string | Message identifier. |
| `machine` | boolean | Whether the message was generated by Cody. |

## Native endpoint

Through the native Cody API, this operation is `POST /messages` (base URL `https://getcody.ai/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/send-message.md) for the provider-specific parameters and requirements.
