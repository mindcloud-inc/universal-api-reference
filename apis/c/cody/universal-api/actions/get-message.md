# Cody: Get Message



```
GET https://connect.mindcloud.co/v1/universal/cody/latest/actions/get-message
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Cody `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/cody/latest/actions/get-message?connectionId=$CONNECTION_ID&id=string" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId,
  "id": "string"
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/cody/latest/actions/get-message?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | yes | Id of the message. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `includes` | list<string> | no | Extra message attributes to include in the response. One of: `sources`, `usage`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "content": "string",
      "conversationId": "string",
      "createdAt": "2026-05-07T12:00:00.000Z",
      "failedResponding": true,
      "flagged": true,
      "id": "string",
      "machine": true
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `content` | string | Message content. |
| `conversationId` | string | Parent conversation identifier. |
| `createdAt` | date | Message creation timestamp. |
| `failedResponding` | boolean | Whether Cody failed while responding. |
| `flagged` | boolean | Whether the message was flagged. |
| `id` | string | Message identifier. |
| `machine` | boolean | Whether the message was generated by Cody. |

## Native endpoint

Through the native Cody API, this operation is `GET /messages/:id` (base URL `https://getcody.ai/api/v1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-message.md) for the provider-specific parameters and requirements.
