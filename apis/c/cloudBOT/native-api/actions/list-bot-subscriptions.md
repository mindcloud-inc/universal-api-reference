# List Bot Subscriptions with Cloud BOT

Retrieves bot subscriptions from Cloud BOT.

## Endpoint

- **Method:** `GET`
- **Path:** `/:public_id/bots/:bot_id/subscriptions`
- **Base URL:** `https://api.c-bot.pro`
- **Official documentation:** [List Bot Subscriptions](https://docs.c-bot.pro/wp-content/uploads/2023/09/api-v5-en.html#operation/get-public_id-bots-bot_id-subscriptions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `public_id` | path | `string` | yes |
| `bot_id` | path | `string` | yes |
