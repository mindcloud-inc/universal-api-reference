# Get Job with Cloud BOT

Retrieves a job from Cloud BOT.

## Endpoint

- **Method:** `GET`
- **Path:** `/:public_id/jobs/:job_id`
- **Base URL:** `https://api.c-bot.pro`
- **Official documentation:** [Get Job](https://docs.c-bot.pro/wp-content/uploads/2023/09/api-v5-en.html#operation/get-public_id-jobs-job_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `public_id` | path | `string` | yes | Public ID of API |
| `job_id` | path | `string` | yes | JOB ID |
