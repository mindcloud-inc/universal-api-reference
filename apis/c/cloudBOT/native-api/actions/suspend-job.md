# Suspend Job with Cloud BOT

Deletes a job from Cloud BOT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/:public_id/jobs/:job_id`
- **Base URL:** `https://api.c-bot.pro`
- **Official documentation:** [Suspend Job](https://docs.c-bot.pro/wp-content/uploads/2023/09/api-v5-en.html#operation/delete-public_id-jobs-job_id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `public_id` | path | `string` | yes |
| `job_id` | path | `string` | yes |
