# List Contracts with Cloud BOT

Retrieves contracts from Cloud BOT.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/contracts`
- **Base URL:** `https://api.c-bot.pro`
- **Official documentation:** [List Contracts](https://docs.c-bot.pro/wp-content/uploads/2023/09/api-v5-en.html#operation/get-services-contracts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `properties` | query | `string` | no | Comma-separated list of additional contract properties to include, such as plan or owner. |
