# Get Routing Form with Calendly

Retrieves a routing form from Calendly.

## Endpoint

- **Method:** `GET`
- **Path:** `/routing_forms/:routing_form_uuid`
- **Base URL:** `https://api.calendly.com`
- **Official documentation:** [Get Routing Form](https://developer.calendly.com/api-docs/20e016678903c-routing-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `routing_form_uuid` | path | `string` | yes | Routing form UUID. |
