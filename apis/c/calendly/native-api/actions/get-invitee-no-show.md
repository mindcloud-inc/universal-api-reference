# Get Invitee No Show with Calendly

Retrieves an invitee no-show from Calendly.

## Endpoint

- **Method:** `GET`
- **Path:** `/invitee_no_shows/:invitee_no_show_uuid`
- **Base URL:** `https://api.calendly.com`
- **Official documentation:** [Get Invitee No Show](https://developer.calendly.com/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invitee_no_show_uuid` | path | `string` | yes | Invitee no-show UUID. |
