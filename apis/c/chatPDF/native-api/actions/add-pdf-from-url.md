# Add PDF From URL with ChatPDF

## Endpoint

- **Method:** `POST`
- **Path:** `/sources/add-url`
- **Base URL:** `https://api.chatpdf.com/v1`
- **Official documentation:** [Add PDF From URL](https://www.chatpdf.com/docs/api/backend)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Publicly accessible URL of the PDF file to add. |
