# Get User with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/users/:id`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Get User](https://docs.cronly.app/api/cron-job-monitor-5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the user to view. |
