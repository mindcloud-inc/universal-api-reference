# Get Job Monitor with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/monitors/:id`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Get Job Monitor](https://docs.cronly.app/api/cron-job-monitor-2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the job monitor to view. |
