# Delete Project with Cronly

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/projects/:id`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Delete Project](https://docs.cronly.app/api/cron-job-monitor-3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the project to delete. |
