# Get SSL Certificate Monitor with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/certificates/:id`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Get SSL Certificate Monitor](https://docs.cronly.app/api/cron-job-monitor-4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the SSL certificate monitor to view. |
