# Create Project with Cronly

## Endpoint

- **Method:** `POST`
- **Path:** `/api/projects`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Create Project](https://docs.cronly.app/api/cron-job-monitor-3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the project. |
