# List Notifications with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/notifications`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [List Notifications](https://docs.cronly.app/api/cron-job-monitor-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
| `per_page` | query | `number` | no | Number of notifications per page. |
