# Send Monitor Pulse with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/monitors/pulse/:token`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Send Monitor Pulse](https://docs.cronly.app/api/how-to-use-the-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | The monitor pulse token. |
