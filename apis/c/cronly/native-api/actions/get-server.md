# Get Server with Cronly

## Endpoint

- **Method:** `GET`
- **Path:** `/api/servers/:id`
- **Base URL:** `https://cronly.app`
- **Official documentation:** [Get Server](https://docs.cronly.app/api/servers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the server to view. |
