# List Charge Definitions with Cerbo

Retrieves charge definitions from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge_master`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Charge Definitions](https://docs.cer.bo/#tag/Charges/operation/listCharges)

## Capabilities

This operation supports [pagination](../README.md#pagination).
