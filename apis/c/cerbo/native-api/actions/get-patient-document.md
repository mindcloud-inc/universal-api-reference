# Get Patient Document with Cerbo

Retrieves patient document details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Patient Document](https://docs.cer.bo/#tag/Patient-Documents/operation/showPatientDocument)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `number` | no | ID of document |
