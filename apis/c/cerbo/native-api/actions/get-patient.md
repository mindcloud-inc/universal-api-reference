# Get Patient with Cerbo

Retrieves patient details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/patients/:patient_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Patient](https://docs.cer.bo/#tag/Patients/operation/showPatient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `patient_id` | path | `number` | no | ID of patient |
