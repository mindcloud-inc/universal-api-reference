# Get Task with Cerbo

Retrieves task details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/task/:task_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Task](https://docs.cer.bo/#tag/Tasks/operation/showTask)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | ID of the task |
