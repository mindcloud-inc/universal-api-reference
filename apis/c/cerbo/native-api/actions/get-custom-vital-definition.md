# Get Custom Vital Definition with Cerbo

Retrieves custom vital definition details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/vitals/:vital_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Custom Vital Definition](https://docs.cer.bo/#tag/Vitals/operation/getVital)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `vital_id` | path | `number` | no |
