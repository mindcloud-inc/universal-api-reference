# Delete Tag with Cerbo

Deletes an existing tag from Cerbo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tag_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Delete Tag](https://docs.cer.bo/#tag/Tags/operation/deleteTag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `number` | yes | ID of tag to delete |
