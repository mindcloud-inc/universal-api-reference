# Get Appointment with Cerbo

Retrieves appointment details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/:appointment_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Appointment](https://docs.cer.bo/#tag/Appointments/operation/showAppointment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appointment_id` | path | `number` | yes | Appointment identifier. |
