# Get Charge Definition with Cerbo

Retrieves charge definition details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/charge_master/:charge_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Charge Definition](https://docs.cer.bo/#tag/Charges/operation/showCharge)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `charge_id` | path | `number` | yes |
