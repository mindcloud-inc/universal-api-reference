# Get Supplement with Cerbo

Retrieves supplement details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/supplements/:supplement_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Supplement](https://docs.cer.bo/#tag/Supplements/operation/showSupplement)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `supplement_id` | path | `number` | no |
