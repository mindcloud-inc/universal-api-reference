# List Patient Vaccines with Cerbo

Retrieves patient vaccines from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/patients/:patient_id/vaccines`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Patient Vaccines](https://docs.cer.bo/#tag/Patient-Vaccines/operation/listPatientVaccines)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `patient_id` | path | `number` | no |
