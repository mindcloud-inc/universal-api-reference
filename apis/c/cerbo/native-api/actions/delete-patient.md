# Delete Patient with Cerbo

Deletes an existing patient from Cerbo.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/patients/:patient_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Delete Patient](https://docs.cer.bo/#tag/Patients/operation/deletePatient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `patient_id` | path | `number` | no | ID of patient |
