# List Patient Supplements with Cerbo

Retrieves patient supplements from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/patients/:patient_id/supplements`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Patient Supplements](https://docs.cer.bo/#tag/Patient-Supplements/operation/listPatientSupplements)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `patient_id` | path | `number` | no |
