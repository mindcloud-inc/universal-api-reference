# List Patient Note Types with Cerbo

Retrieves patient note types from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/pt_notes`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Patient Note Types](https://docs.cer.bo/#tag/Patient-Free-Text-Notes/operation/listPatientNotes)
