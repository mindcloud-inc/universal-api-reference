# Get Partner App Order with Cerbo

Retrieves Quest order details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/partners/quest/orders/:order_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Partner App Order](https://docs.cer.bo/#tag/Partner-Applications/operation/showPartnerAppOrder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | no | ID of order to show |
