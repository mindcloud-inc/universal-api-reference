# List Vitals Tag Groups with Cerbo

Retrieves vitals tag groups from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/vitals_tag_groups`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Vitals Tag Groups](https://docs.cer.bo/#tag/Vitals/operation/listVitalsTagGroups)
