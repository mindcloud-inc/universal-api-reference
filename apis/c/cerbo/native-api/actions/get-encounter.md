# Get Encounter with Cerbo

Retrieves encounter details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/encounters/:encounter_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Encounter](https://docs.cer.bo/#tag/Encounters/operation/showEncounter)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `encounter_id` | path | `number` | yes | The ID of the encounter note. |
