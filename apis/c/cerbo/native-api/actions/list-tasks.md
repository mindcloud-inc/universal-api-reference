# List Tasks with Cerbo

Retrieves task records from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/task`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Tasks](https://docs.cer.bo/#tag/Tasks/operation/listTasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
