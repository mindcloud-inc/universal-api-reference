# Get Drug with Cerbo

Retrieves drug details from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/drugs/:drug_id`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [Get Drug](https://docs.cer.bo/#tag/Drugs/operation/showDrug)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `drug_id` | path | `number` | no | ID of drug |
