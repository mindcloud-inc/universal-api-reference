# List Drug Frequencies with Cerbo

Retrieves drug frequency definitions from Cerbo.

## Endpoint

- **Method:** `GET`
- **Path:** `/drugs/frequencies`
- **Base URL:** `https://{tenant}.md-hq.com/api/v1`
- **Official documentation:** [List Drug Frequencies](https://docs.cer.bo/#tag/Drugs/operation/listDrugFrequencies)
