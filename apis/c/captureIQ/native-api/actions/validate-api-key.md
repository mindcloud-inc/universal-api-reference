# Validate API Key with CaptureIQ

Retrieves API key validation status from CaptureIQ.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/validateApiKey`
- **Base URL:** `https://www.app.captureiq.ai`
- **Official documentation:** [Validate API Key](https://help.captureiq.ai/api-reference/validate-api-key)
