# List Amendments with Congress.gov

Retrieves amendments from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/amendment`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Amendments](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/AmendmentEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
