# List Hearings with Congress.gov

Retrieves hearings from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/hearing`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Hearings](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/HearingEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
