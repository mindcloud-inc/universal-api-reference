# List Committee Reports with Congress.gov

Retrieves committee reports from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/committee-report`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Committee Reports](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/CommitteeReportEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
