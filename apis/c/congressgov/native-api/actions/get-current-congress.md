# Get Current Congress with Congress.gov

Retrieves the current Congress from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/congress/current`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [Get Current Congress](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/CongressEndpoint.md)
