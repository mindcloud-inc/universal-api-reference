# List Summaries with Congress.gov

Retrieves bill summaries from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/summaries`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Summaries](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/SummariesEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
