# List Committee Meetings with Congress.gov

Retrieves committee meetings from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/committee-meeting`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Committee Meetings](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/CommitteeMeetingEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
