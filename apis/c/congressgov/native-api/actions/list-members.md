# List Members with Congress.gov

Retrieves members from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/member`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Members](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/MemberEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
