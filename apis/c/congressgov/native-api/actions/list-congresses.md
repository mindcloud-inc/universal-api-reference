# List Congresses with Congress.gov

Retrieves Congress sessions from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/congress`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Congresses](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/CongressEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
