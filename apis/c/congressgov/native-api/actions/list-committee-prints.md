# List Committee Prints with Congress.gov

Retrieves committee prints from Congress.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/committee-print`
- **Base URL:** `https://api.congress.gov/v3`
- **Official documentation:** [List Committee Prints](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/CommitteePrintEndpoint.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).
