# Get Prepay Balance with CastingWords

Retrieves prepay balance from CastingWords.

## Endpoint

- **Method:** `GET`
- **Path:** `prepay_balance`
- **Base URL:** `https://castingwords.com/store/API4`
- **Official documentation:** [Get Prepay Balance](https://castingwords.com/docs/developer/SimpleAPI.html#prepay_balance)
