# Send Refund Issued Webhook Test with CastingWords

Sends a refund issued webhook test from CastingWords.

## Endpoint

- **Method:** `POST`
- **Path:** `webhook/test/REFUND_ISSUED`
- **Base URL:** `https://castingwords.com/store/API4`
- **Official documentation:** [Send Refund Issued Webhook Test](https://castingwords.com/docs/developer/SimpleAPI.html#receive-a-webhook-call)
