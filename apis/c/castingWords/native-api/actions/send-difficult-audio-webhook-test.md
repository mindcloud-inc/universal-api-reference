# Send Difficult Audio Webhook Test with CastingWords

Sends a difficult audio webhook test from CastingWords.

## Endpoint

- **Method:** `POST`
- **Path:** `webhook/test/DIFFICULT_AUDIO`
- **Base URL:** `https://castingwords.com/store/API4`
- **Official documentation:** [Send Difficult Audio Webhook Test](https://castingwords.com/docs/developer/SimpleAPI.html#receive-a-webhook-call)
