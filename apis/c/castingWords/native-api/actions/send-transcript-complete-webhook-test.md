# Send Transcript Complete Webhook Test with CastingWords

Sends a transcript complete webhook test from CastingWords.

## Endpoint

- **Method:** `POST`
- **Path:** `webhook/test/TRANSCRIPT_COMPLETE`
- **Base URL:** `https://castingwords.com/store/API4`
- **Official documentation:** [Send Transcript Complete Webhook Test](https://castingwords.com/docs/developer/SimpleAPI.html#receive-a-webhook-call)
