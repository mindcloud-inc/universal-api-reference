# List Organizations with CDC Content Services

Retrieves organizations from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/organizations`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Organizations](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
