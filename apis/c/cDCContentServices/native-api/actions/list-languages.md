# List Languages with CDC Content Services

Retrieves languages from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/languages`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Languages](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
