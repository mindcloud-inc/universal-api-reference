# List Organization Types with CDC Content Services

Retrieves organization types from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/organizationtypes`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Organization Types](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
