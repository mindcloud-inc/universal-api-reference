# List Media Types with CDC Content Services

Retrieves media types from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/mediatypes`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Media Types](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
