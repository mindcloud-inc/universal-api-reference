# List Tag Types with CDC Content Services

Retrieves tag types from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/tagtypes`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Tag Types](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
