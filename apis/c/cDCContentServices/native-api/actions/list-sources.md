# List Sources with CDC Content Services

Retrieves sources from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/sources`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [List Sources](https://tools.cdc.gov/api/docs/info.aspx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
