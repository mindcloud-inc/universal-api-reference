# Get Role with Comm100

Retrieves a role from Comm100 settings.

## Endpoint

- **Method:** `GET`
- **Path:** `global/roles/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Role](https://developer.comm100.com/docs/server-api-global-setting-role)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 role ID. |
