# Get Campaign Installation with Comm100

Retrieves campaign installation details from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `livechat/campaigns/{{id}}/installation`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Campaign Installation](https://developer.comm100.com/docs/server-api-livechat-installation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 campaign ID. |
