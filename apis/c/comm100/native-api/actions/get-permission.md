# Get Permission with Comm100

Retrieves a permission from Comm100 settings.

## Endpoint

- **Method:** `GET`
- **Path:** `global/permissions/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Permission](https://developer.comm100.com/docs/server-api-global-setting-permission)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The Comm100 permission ID. |
