# Get Public Canned Message Category with Comm100

Retrieves a public canned message category from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `global/publicCannedMessageCategories/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Public Canned Message Category](https://developer.comm100.com/docs/server-api-global-setting-public-canned-message-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 public canned message category ID. |
