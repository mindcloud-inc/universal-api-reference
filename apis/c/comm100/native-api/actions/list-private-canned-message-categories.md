# List Private Canned Message Categories with Comm100

Retrieves private canned message categories from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `global/privateCannedMessageCategories`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [List Private Canned Message Categories](https://developer.comm100.com/docs/server-api-global-setting-private-canned-message-category)
