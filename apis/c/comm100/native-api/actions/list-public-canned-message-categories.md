# List Public Canned Message Categories with Comm100

Retrieves public canned message categories from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `global/publicCannedMessageCategories`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [List Public Canned Message Categories](https://developer.comm100.com/docs/server-api-global-setting-public-canned-message-category)
