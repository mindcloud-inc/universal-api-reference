# Get Campaign with Comm100

Retrieves a live chat campaign from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `livechat/campaigns/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Campaign](https://developer.comm100.com/docs/server-api-livechat-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 campaign ID. |
