# Get Campaign Pre-Chat with Comm100

Retrieves a campaign pre-chat form from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `livechat/campaigns/{{id}}/preChat`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Campaign Pre-Chat](https://developer.comm100.com/docs/server-api-livechat-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 campaign ID. |
