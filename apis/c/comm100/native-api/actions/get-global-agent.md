# Get Global Agent with Comm100

Retrieves a global agent from Comm100 settings.

## Endpoint

- **Method:** `GET`
- **Path:** `global/agents/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Global Agent](https://developer.comm100.com/docs/server-api-global-setting-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 agent ID. |
