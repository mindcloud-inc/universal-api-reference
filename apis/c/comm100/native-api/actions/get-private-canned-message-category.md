# Get Private Canned Message Category with Comm100

Retrieves a private canned message category from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `global/privateCannedMessageCategories/{{id}}`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Private Canned Message Category](https://developer.comm100.com/docs/server-api-global-setting-private-canned-message-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Comm100 private canned message category ID. |
