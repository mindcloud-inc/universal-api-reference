# Get Site Profile with Comm100

Retrieves the site profile from Comm100 settings.

## Endpoint

- **Method:** `GET`
- **Path:** `global/site`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [Get Site Profile](https://developer.comm100.com/docs/server-api-global-setting-site-profile)
