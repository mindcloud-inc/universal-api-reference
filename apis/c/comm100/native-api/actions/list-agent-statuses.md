# List Agent Statuses with Comm100

Retrieves live chat agent statuses from Comm100.

## Endpoint

- **Method:** `GET`
- **Path:** `livechat/agents`
- **Base URL:** `https://api17.comm100.io/v4`
- **Official documentation:** [List Agent Statuses](https://developer.comm100.com/docs/server-api-livechat-chat-server)
