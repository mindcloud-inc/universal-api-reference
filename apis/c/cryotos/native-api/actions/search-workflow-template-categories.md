# Search Workflow Template Categories with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/publicTemplateCategories/_search/:text`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [Search Workflow Template Categories](https://www.cryotos.com/cmms/features/workflow-automation-software)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | path | `string` | yes | The workflow template category search text. |
