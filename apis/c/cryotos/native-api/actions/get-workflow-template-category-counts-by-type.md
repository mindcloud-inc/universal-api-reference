# Get Workflow Template Category Counts By Type with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/publicTemplateCategories/template-count/list-by-type/:type`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [Get Workflow Template Category Counts By Type](https://www.cryotos.com/cmms/features/workflow-automation-software)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | The workflow type to summarize. |
