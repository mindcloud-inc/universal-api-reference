# Search Email Templates with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/dropdown/emailTemplate/_autocomplete/:text`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [Search Email Templates](https://www.cryotos.com/cmms/features/email-and-whatsapp-builder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | path | `string` | yes | The email template search text. |
