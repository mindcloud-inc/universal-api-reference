# List Template Histories By Workflow ID with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/template-histories/findByWorkflowId/:workflowId`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [List Template Histories By Workflow ID](https://www.cryotos.com/cmms/features/workflow-automation-software)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | The workflow ID. |
