# Get Template with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/templates/:id`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [Get Template](https://www.cryotos.com/cmms/features/workflow-automation-software)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template ID. |
