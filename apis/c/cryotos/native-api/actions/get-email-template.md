# Get Email Template with Cryotos

## Endpoint

- **Method:** `GET`
- **Path:** `/api/email_template/:id`
- **Base URL:** `https://app.cryotos.com`
- **Official documentation:** [Get Email Template](https://www.cryotos.com/cmms/features/email-and-whatsapp-builder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The email template ID. |
