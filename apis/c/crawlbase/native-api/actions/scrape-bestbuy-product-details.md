# Scrape BestBuy Product Details with Crawlbase

Retrieves Best Buy product details from Crawlbase.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.crawlbase.com`
- **Official documentation:** [Scrape BestBuy Product Details](https://crawlbase.com/docs/crawling-api/scrapers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to scrape with the bestbuy-product-details Crawlbase data scraper. |
