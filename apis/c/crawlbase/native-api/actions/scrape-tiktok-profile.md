# Scrape TikTok Profile with Crawlbase

Retrieves a TikTok profile from Crawlbase.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.crawlbase.com`
- **Official documentation:** [Scrape TikTok Profile](https://crawlbase.com/docs/crawling-api/scrapers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to scrape with the tiktok-profile Crawlbase data scraper. |
