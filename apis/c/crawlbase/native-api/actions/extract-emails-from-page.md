# Extract Emails From Page with Crawlbase

Retrieves email addresses from a page with Crawlbase.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.crawlbase.com`
- **Official documentation:** [Extract Emails From Page](https://crawlbase.com/docs/crawling-api/scrapers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to scrape with the email-extractor Crawlbase data scraper. |
