# Scrape Amazon Best Sellers with Crawlbase

Retrieves Amazon best-seller listings from Crawlbase.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.crawlbase.com`
- **Official documentation:** [Scrape Amazon Best Sellers](https://crawlbase.com/docs/crawling-api/scrapers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to scrape with the amazon-best-sellers Crawlbase data scraper. |
