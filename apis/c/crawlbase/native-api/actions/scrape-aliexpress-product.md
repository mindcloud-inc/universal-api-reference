# Scrape AliExpress Product with Crawlbase

Retrieves AliExpress product data from Crawlbase.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://api.crawlbase.com`
- **Official documentation:** [Scrape AliExpress Product](https://crawlbase.com/docs/crawling-api/scrapers/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to scrape with the aliexpress-product Crawlbase data scraper. |
