# List Workspaces with Clockify

Lists all available workspaces in Clockify.

## Endpoint

- **Method:** `GET`
- **Path:** `workspaces`
- **Base URL:** `https://api.clockify.me/api/v1`
- **Official documentation:** [List Workspaces](https://docs.developer.clockify.me/#tag/Workspace/operation/getWorkspacesOfUser)
