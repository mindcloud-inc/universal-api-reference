# Get Invoice Settings with Clockify

Retrieves workspace invoice settings from Clockify.

## Endpoint

- **Method:** `GET`
- **Path:** `workspaces/:workspaceId/invoices/settings`
- **Base URL:** `https://api.clockify.me/api/v1`
- **Official documentation:** [Get Invoice Settings](https://docs.developer.clockify.me/#tag/Invoice/operation/getInvoiceSettings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `workspaceId` | path | `list<string>` | yes |
