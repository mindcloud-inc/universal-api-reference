# Get Workspace with Clockify

Retrieves a specific workspace from Clockify.

## Endpoint

- **Method:** `GET`
- **Path:** `workspaces/:workspaceId`
- **Base URL:** `https://api.clockify.me/api/v1`
- **Official documentation:** [Get Workspace](https://docs.developer.clockify.me/#tag/Workspace/operation/getWorkspaceOfUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `list<string>` | yes | Workspace identifier from Clockify. |
