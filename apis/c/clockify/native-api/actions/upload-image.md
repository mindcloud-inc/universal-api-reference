# Upload Image with Clockify

Uploads a user image to Clockify.

## Endpoint

- **Method:** `POST`
- **Path:** `file/image`
- **Base URL:** `https://api.clockify.me/api/v1`
- **Official documentation:** [Upload Image](https://docs.developer.clockify.me/#tag/User/operation/uploadImage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
