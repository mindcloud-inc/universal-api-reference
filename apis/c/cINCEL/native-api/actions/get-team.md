# Get Team with CINCEL

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:uuid`
- **Base URL:** `https://api.cincel.digital/v3`
- **Official documentation:** [Get Team](https://docs.cincel.digital/v3/digital-signature#get-/teams/-uuid-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | UUID of the team to retrieve. |
