# Download Document Evidence ZIP with CINCEL

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document.zip`
- **Base URL:** `https://api.cincel.digital/v3`
- **Official documentation:** [Download Document Evidence ZIP](https://docs.cincel.digital/v3/digital-signature#get-/documents/-document-.zip)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | yes | Document UUID from the path. |
