# Download Signed Document PDF with CINCEL

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/signed-document.pdf`
- **Base URL:** `https://api.cincel.digital/v3`
- **Official documentation:** [Download Signed Document PDF](https://docs.cincel.digital/v3/digital-signature#get-/documents/-document-/signed-document.pdf)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | yes | Document UUID from the path. |
