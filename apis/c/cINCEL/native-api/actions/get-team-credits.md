# Get Team Credits with CINCEL

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team/credits`
- **Base URL:** `https://api.cincel.digital/v3`
- **Official documentation:** [Get Team Credits](https://docs.cincel.digital/v3/digital-signature#get-/teams/-team-/credits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team` | path | `string` | yes | UUID of the team whose credits should be retrieved. |
