# Create Tag with CheckFlow

## Endpoint

- **Method:** `POST`
- **Path:** `/api/tag`
- **Base URL:** `https://app.checkflow.io`
- **Official documentation:** [Create Tag](https://docs.checkflow.io/docs/api/tags#create-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | The name of the tag to create |
