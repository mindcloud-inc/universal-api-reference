# Delete Task Assignments with CheckFlow

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/task/assignments`
- **Base URL:** `https://app.checkflow.io`
- **Official documentation:** [Delete Task Assignments](https://docs.checkflow.io/docs/api/tasks#delete-task-assignments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | query | `number` | yes | The ID of the task. |
