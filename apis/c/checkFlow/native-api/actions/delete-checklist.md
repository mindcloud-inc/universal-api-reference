# Delete Checklist with CheckFlow

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/checklist`
- **Base URL:** `https://app.checkflow.io`
- **Official documentation:** [Delete Checklist](https://docs.checkflow.io/docs/api/checklists#delete-checklist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checklistId` | query | `number` | yes | The ID of the checklist to delete. |
