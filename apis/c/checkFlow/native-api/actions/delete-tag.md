# Delete Tag with CheckFlow

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/tag`
- **Base URL:** `https://app.checkflow.io`
- **Official documentation:** [Delete Tag](https://docs.checkflow.io/docs/api/tags#delete-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagKey` | query | `string` | yes | The key of the tag to delete. |
