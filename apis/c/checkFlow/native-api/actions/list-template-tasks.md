# List Template Tasks with CheckFlow

## Endpoint

- **Method:** `GET`
- **Path:** `/api/template/tasks`
- **Base URL:** `https://app.checkflow.io`
- **Official documentation:** [List Template Tasks](https://docs.checkflow.io/docs/api/templates#list-template-tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `templateKey` | query | `string` | yes | The key of the template. Use List Templates to find the key. |
