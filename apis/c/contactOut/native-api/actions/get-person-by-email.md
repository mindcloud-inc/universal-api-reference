# Get Person By Email with ContactOut

Retrieves a LinkedIn profile from an email address in ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/person`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Get Person By Email](https://api.contactout.com/#email-to-linkedin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to look up. |
