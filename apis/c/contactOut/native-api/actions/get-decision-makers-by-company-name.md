# Get Decision Makers By Company Name with ContactOut

Retrieves decision makers by company name from ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/decision-makers`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Get Decision Makers By Company Name](https://api.contactout.com/#decision-makers-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Company name to inspect for decision makers. |
