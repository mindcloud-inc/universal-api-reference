# Get Decision Makers By Domain with ContactOut

Retrieves decision makers by company domain from ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/decision-makers`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Get Decision Makers By Domain](https://api.contactout.com/#decision-makers-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | yes | Company domain to inspect for decision makers. |
