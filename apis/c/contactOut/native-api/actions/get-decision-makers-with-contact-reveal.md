# Get Decision Makers With Contact Reveal with ContactOut

Retrieves decision makers with revealed contact information from ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/decision-makers`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Get Decision Makers With Contact Reveal](https://api.contactout.com/#decision-makers-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedin_url` | query | `string` | yes | LinkedIn company URL to inspect for decision makers. |
