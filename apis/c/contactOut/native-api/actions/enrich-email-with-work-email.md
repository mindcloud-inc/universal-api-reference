# Enrich Email With Work Email with ContactOut

Retrieves profile details and work email from ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/email/enrich`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Enrich Email With Work Email](https://api.contactout.com/#from-email-address)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to enrich. |
