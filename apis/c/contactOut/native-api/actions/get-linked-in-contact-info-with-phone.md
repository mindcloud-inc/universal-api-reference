# Get LinkedIn Contact Info With Phone with ContactOut

Retrieves contact details and phone for a LinkedIn profile from ContactOut.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/linkedin`
- **Base URL:** `https://api.contactout.com`
- **Official documentation:** [Get LinkedIn Contact Info With Phone](https://api.contactout.com/#from-linkedin-profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profile` | query | `string` | yes | The full LinkedIn profile URL. |
