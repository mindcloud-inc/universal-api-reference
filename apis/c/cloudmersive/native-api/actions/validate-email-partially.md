# Validate Email Partially with Cloudmersive

Partially validates an email address in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/email/address/servers`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Email Partially](https://api.cloudmersive.com/docs/validate.asp#operation--validate-email-address-servers-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | Email address to check against mail servers. |
