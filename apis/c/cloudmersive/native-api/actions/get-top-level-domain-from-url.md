# Get Top-Level Domain From URL with Cloudmersive

Retrieves a top-level domain from a URL in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/url/get-top-level-domain`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Top-Level Domain From URL](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-url-get-top-level-domain-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `URL` | body | `string` | no | URL to inspect. |
