# Get Domain WHOIS with Cloudmersive

Retrieves WHOIS data for a domain in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/whois`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Domain WHOIS](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-whois-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | no | Domain name for the WHOIS lookup. |
