# Get Country Region with Cloudmersive

Retrieves a country's region from Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/address/country/get-region`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Country Region](https://api.cloudmersive.com/docs/validate.asp#operation--validate-address-country-get-region-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `RawCountryInput` | body | `string` | no | Country code or country name to evaluate. |
