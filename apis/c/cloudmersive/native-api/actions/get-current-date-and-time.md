# Get Current Date and Time with Cloudmersive

Retrieves the current date and time from Cloudmersive.

## Endpoint

- **Method:** `GET`
- **Path:** `/validate/date-time/get/now`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Current Date and Time](https://api.cloudmersive.com/docs/validate.asp#operation--validate-date-time-get-now-get)
