# Check Country EU Membership with Cloudmersive

Checks EU membership for a country in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/address/country/check-eu-membership`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Check Country EU Membership](https://api.cloudmersive.com/docs/validate.asp#operation--validate-address-country-check-eu-membership-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `RawCountryInput` | body | `string` | no | Country code or country name to evaluate. |
