# Check URL for Phishing Threats with Cloudmersive

Checks a URL for phishing threats in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/url/phishing-threat-check`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Check URL for Phishing Threats](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-url-phishing-threat-check-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `URL` | body | `string` | no | URL to scan for phishing threats. |
