# Get Domain Quality Score with Cloudmersive

Retrieves a domain quality score from Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/quality-score`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Domain Quality Score](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-quality-score-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | no | Domain name to score. |
