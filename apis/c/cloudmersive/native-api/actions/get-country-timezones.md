# Get Country Timezones with Cloudmersive

Retrieves country time zones from Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/address/country/get-timezones`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get Country Timezones](https://api.cloudmersive.com/docs/validate.asp#operation--validate-address-country-get-timezones-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CountryCodeOrName` | body | `string` | no | Country code or country name to evaluate. |
