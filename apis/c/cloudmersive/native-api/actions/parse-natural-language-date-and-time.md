# Parse Natural Language Date and Time with Cloudmersive

Parses a natural language date and time in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/date-time/parse/date-time/natural-language`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Parse Natural Language Date and Time](https://api.cloudmersive.com/docs/validate.asp#operation--validate-date-time-parse-date-time-natural-language-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `RawDateTimeInput` | body | `string` | no | Natural language date-time string to parse. |
