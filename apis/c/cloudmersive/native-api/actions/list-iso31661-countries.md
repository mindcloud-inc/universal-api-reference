# List ISO 3166-1 Countries with Cloudmersive

Retrieves ISO 3166-1 countries from Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/address/country/list`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [List ISO 3166-1 Countries](https://api.cloudmersive.com/docs/validate.asp#operation--validate-address-country-list-post)
