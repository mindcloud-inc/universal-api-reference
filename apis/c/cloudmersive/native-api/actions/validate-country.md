# Validate Country with Cloudmersive

Validates country information in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/address/country`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Country](https://api.cloudmersive.com/docs/validate.asp#operation--validate-address-country-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `RawCountryInput` | body | `string` | no | Country code or country name to validate. |
