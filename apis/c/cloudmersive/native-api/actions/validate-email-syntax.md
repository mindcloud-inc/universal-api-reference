# Validate Email Syntax with Cloudmersive

Validates an email address syntactically in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/email/address/syntaxOnly`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Email Syntax](https://api.cloudmersive.com/docs/validate.asp#operation--validate-email-address-syntaxOnly-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | no | Email address to validate syntactically. |
