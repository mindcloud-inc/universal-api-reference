# Validate Domain with Cloudmersive

Validates a domain in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/check`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Domain](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-check-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | no | Domain name to validate. |
