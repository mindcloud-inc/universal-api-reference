# Validate URL Syntax with Cloudmersive

Validates a URL syntactically in Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/domain/url/syntax-only`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate URL Syntax](https://api.cloudmersive.com/docs/validate.asp#operation--validate-domain-url-syntax-only-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `URL` | body | `string` | no | URL to validate syntactically. |
