# Get IP Intelligence with Cloudmersive

Retrieves IP intelligence from Cloudmersive.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/ip/intelligence`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Get IP Intelligence](https://api.cloudmersive.com/docs/validate.asp#operation--validate-ip-intelligence-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | no | IP address to inspect. |
