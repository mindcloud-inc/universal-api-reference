# Create Card Application with ConnectPay

Creates a new card application in ConnectPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/baas/ob/clients/:baasClientId/cards`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Create Card Application](https://docs.connectpay.com/docs/#tag/BaaS-Card-creation-and-details/operation/createCardApplication)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baasClientId` | path | `string` | no | BaaS client ID. |
