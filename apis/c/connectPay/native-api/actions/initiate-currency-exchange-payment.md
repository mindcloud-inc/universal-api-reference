# Initiate Currency Exchange Payment with ConnectPay

Initiates a currency exchange payment in ConnectPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/ob/currencyexchangepayments`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Initiate Currency Exchange Payment](https://docs.connectpay.com/docs/#tag/BaaS-FX-payments/operation/InitiateCurrencyExchangePayment)
