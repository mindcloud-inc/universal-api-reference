# Update Card Renewal Settings with ConnectPay

Enables or disables card renewal in ConnectPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/baas/ob/cards/:cardId/automaticrenewal`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Update Card Renewal Settings](https://docs.connectpay.com/docs/#tag/BaaS-Card-management/operation/updateCardRenewalSettings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
