# Open Account with ConnectPay

Opens a new IBAN account in ConnectPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/baas/ob/accounts`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Open Account](https://docs.connectpay.com/docs/#tag/BaaS-Accounts/operation/openIBANAccount)
