# Get BaaS Client Cards with ConnectPay

Retrieves a BaaS client's cards from ConnectPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/baas/ob/baas/clients/:baasClientId/cards`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get BaaS Client Cards](https://docs.connectpay.com/docs/#tag/BaaS-Card-creation-and-details/operation/getBaaSClientCards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baasClientId` | path | `string` | no | BaaS client ID. |
