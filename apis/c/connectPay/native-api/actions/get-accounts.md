# Get Accounts with ConnectPay

Retrieves bank accounts from ConnectPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/ob/accounts`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get Accounts](https://docs.connectpay.com/docs/#tag/Accounts/operation/getAccounts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `withBalance` | query | `string` | no | If true, returns accounts with balances. |
