# Update Card Limits with ConnectPay

Updates an existing card's limits in ConnectPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/baas/ob/cards/:cardId/limits`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Update Card Limits](https://docs.connectpay.com/docs/#tag/BaaS-Card-management/operation/updateCardLimitsByCardId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
