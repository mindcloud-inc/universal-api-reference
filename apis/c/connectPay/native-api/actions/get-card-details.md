# Get Card Details with ConnectPay

Retrieves payment card details from ConnectPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/baas/ob/cards/:cardId`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get Card Details](https://docs.connectpay.com/docs/#tag/BaaS-Card-creation-and-details/operation/getCardDetailsByCardId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
