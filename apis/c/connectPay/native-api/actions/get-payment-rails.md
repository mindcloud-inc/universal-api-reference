# Get Payment Rails with ConnectPay

Retrieves payment rails from ConnectPay.

## Endpoint

- **Method:** `POST`
- **Path:** `/ob/paymentrails`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get Payment Rails](https://docs.connectpay.com/docs/#tag/BaaS-Standard-payments/operation/GetPaymentRails)
