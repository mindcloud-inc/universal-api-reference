# Get BaaS Merchant Recurrence Details with ConnectPay

Retrieves BaaS merchant recurrence details from ConnectPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/baas/merchant/recurrences/:recurrenceId`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get BaaS Merchant Recurrence Details](https://docs.connectpay.com/docs/#tag/BaaS-Merchant-recurrences/operation/GetRecurrencesDetailsById)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recurrenceId` | path | `string` | no | Merchant recurrence ID. |
