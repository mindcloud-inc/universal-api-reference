# Update Card Delivery Address with ConnectPay

Updates a ChipAndPin card delivery address in ConnectPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/baas/ob/cards/:cardId/deliveryaddress`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Update Card Delivery Address](https://docs.connectpay.com/docs/#tag/BaaS-Card-management/operation/updateCardDeliveryAddress)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
