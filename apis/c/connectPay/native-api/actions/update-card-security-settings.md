# Update Card Security Settings with ConnectPay

Updates card security settings in ConnectPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/baas/ob/cards/:cardId/security`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Update Card Security Settings](https://docs.connectpay.com/docs/#tag/BaaS-Card-management/operation/updateCardSecurity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
