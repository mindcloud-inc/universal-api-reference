# Get BaaS Merchant Payment Details with ConnectPay

Retrieves BaaS merchant payment details from ConnectPay.

## Endpoint

- **Method:** `GET`
- **Path:** `/baas/merchant/payments/:paymentId`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Get BaaS Merchant Payment Details](https://docs.connectpay.com/docs/#tag/BaaS-Merchant-payments-and-providers/operation/GetPaymentDetailsById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `paymentId` | path | `string` | no | Merchant payment ID. |
