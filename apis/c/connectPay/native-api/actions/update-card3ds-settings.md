# Update Card 3DS Settings with ConnectPay

Updates card 3DS security settings in ConnectPay.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/baas/ob/cards/:cardId/update3ds`
- **Base URL:** `https://api-stage.connectpay.com`
- **Official documentation:** [Update Card 3DS Settings](https://docs.connectpay.com/docs/#tag/BaaS-Card-management/operation/updateCard3DSecureSettings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | no | Card ID. |
