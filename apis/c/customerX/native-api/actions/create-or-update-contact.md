# Create Or Update Contact with CustomerX

Creates or updates a contact in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts/create_or_update`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Or Update Contact](https://doc.api.customerx.com.br/?version=latest#79f51667-25ec-4b21-947b-b01e21594cd8)
