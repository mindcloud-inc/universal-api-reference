# Create Contract Additive with CustomerX

Creates a new contract additive in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contract_additives`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Contract Additive](https://doc.api.customerx.com.br/?version=latest#c6d28cfd-1162-4719-b5db-ff32800a8737)
