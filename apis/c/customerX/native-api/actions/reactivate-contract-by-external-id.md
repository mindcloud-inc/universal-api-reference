# Reactivate Contract By External ID with CustomerX

Reactivates an existing contract in CustomerX by external ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contracts/reactivate_contract`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Reactivate Contract By External ID](https://doc.api.customerx.com.br/?version=latest#95e39292-3eb1-42a1-8a59-0271ff6e19c8)
