# Add Customer Journey with CustomerX

Creates a customer journey link in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/clients/journeys_clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Add Customer Journey](https://doc.api.customerx.com.br/?version=latest#c2eef5dc-a3a4-4398-b513-5857368f117d)
