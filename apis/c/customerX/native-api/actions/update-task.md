# Update Task with CustomerX

Updates an existing task in CustomerX.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/tasks/[:id]`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Task](https://doc.api.customerx.com.br/?version=latest#cd91ab7e-b37b-4348-8041-93b9ea600352)
