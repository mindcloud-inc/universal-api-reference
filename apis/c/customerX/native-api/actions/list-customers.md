# List Customers with CustomerX

Retrieves a list of customers from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Customers](https://doc.api.customerx.com.br/?version=latest#276f1af5-fadd-4b44-82b5-236af1738c8c)
