# Create Or Update Customer with CustomerX

Creates or updates a customer in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/clients/create_or_update`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Or Update Customer](https://doc.api.customerx.com.br/?version=latest#88a2b895-968c-4854-9506-1a421278d99b)
