# Create Ticket with CustomerX

Creates a new ticket in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tickets`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Ticket](https://doc.api.customerx.com.br/?version=latest#5feeb028-28d0-437e-955c-3e42f34e47e4)
