# Create Contact with CustomerX

Creates a new contact in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Contact](https://doc.api.customerx.com.br/?version=latest#ba01accb-8fef-4499-999d-13b0520fdaad)
