# Cancel Contract with CustomerX

Cancels an existing contract in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/cancel_contracts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Cancel Contract](https://doc.api.customerx.com.br/?version=latest#52aade67-7950-4e6e-b824-afbca2ede9e1)
