# Get Contract Plan with CustomerX

Retrieves contract plan details from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contract_plans/[:id]`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Get Contract Plan](https://doc.api.customerx.com.br/?version=latest#48a2d107-7190-4c6a-b4ec-e8715b7ba459)
