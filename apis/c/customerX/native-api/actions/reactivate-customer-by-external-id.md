# Reactivate Customer By External ID with CustomerX

Reactivates an existing customer in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/clients/[:external_id_client]/reactivate`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Reactivate Customer By External ID](https://doc.api.customerx.com.br/?version=latest#4a4dc59a-848b-4888-82f4-c914362ea427)
