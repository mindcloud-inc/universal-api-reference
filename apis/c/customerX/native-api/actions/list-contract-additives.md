# List Contract Additives with CustomerX

Retrieves a list of contract additives from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contract_additives`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Contract Additives](https://doc.api.customerx.com.br/?version=latest#10315419-0e90-4955-af33-7a7fe3fe149a)
