# Create Or Update Ticket with CustomerX

Creates or updates a ticket in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/tickets/create_or_update`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Or Update Ticket](https://doc.api.customerx.com.br/?version=latest#a310538c-c0a0-42ac-af8e-44e2b62451af)
