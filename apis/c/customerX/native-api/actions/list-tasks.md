# List Tasks with CustomerX

Retrieves a list of tasks from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Tasks](https://doc.api.customerx.com.br/?version=latest#aae07b23-f390-4040-9df4-7ad0a0ff09bf)
