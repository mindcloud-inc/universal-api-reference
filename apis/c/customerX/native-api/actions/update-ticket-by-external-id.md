# Update Ticket By External ID with CustomerX

Updates an existing ticket in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/tickets`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Ticket By External ID](https://doc.api.customerx.com.br/?version=latest#3d4d2e08-5f56-444d-ab3d-0da076b32b98)
