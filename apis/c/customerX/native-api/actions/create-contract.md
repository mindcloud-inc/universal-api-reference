# Create Contract with CustomerX

Creates a new contract in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contracts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Contract](https://doc.api.customerx.com.br/?version=latest#2fc28bcd-97a4-429f-8079-f70e7854031a)
