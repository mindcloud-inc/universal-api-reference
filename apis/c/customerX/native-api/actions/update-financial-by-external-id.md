# Update Financial By External ID with CustomerX

Updates an existing financial record in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/financials`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Financial By External ID](https://doc.api.customerx.com.br/?version=latest#eb0b3d64-4889-486d-87a9-929db6894e95)
