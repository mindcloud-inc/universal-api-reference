# Delete Financial By External ID with CustomerX

Deletes an existing financial record from CustomerX by external ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/financials`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Delete Financial By External ID](https://doc.api.customerx.com.br/?version=latest#1f6a86d4-1e22-42bb-8fc3-728609c30154)
