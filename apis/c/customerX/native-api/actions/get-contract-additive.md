# Get Contract Additive with CustomerX

Retrieves contract additive details from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contract_additives/[:id]`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Get Contract Additive](https://doc.api.customerx.com.br/?version=latest#546e6c53-6d11-418c-8df5-ceb79e66ca45)
