# List Customer Journeys with CustomerX

Retrieves linked customer journeys from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/clients/journeys_clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Customer Journeys](https://doc.api.customerx.com.br/?version=latest#13c6f240-c8d5-4e92-b3fb-bfebbcaf5b8e)
