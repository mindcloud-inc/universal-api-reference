# List Contract Plans with CustomerX

Retrieves a list of contract plans from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contract_plans`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Contract Plans](https://doc.api.customerx.com.br/?version=latest#42dcf0e4-b950-4bb4-a2d1-164944455693)
