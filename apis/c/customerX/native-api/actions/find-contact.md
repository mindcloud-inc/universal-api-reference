# Find Contact with CustomerX

Finds a contact in CustomerX by search filters.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/find`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Find Contact](https://doc.api.customerx.com.br/?version=latest#3f4634f8-faaf-4319-b397-1673585fc66b)
