# Update Contract Plan By External ID with CustomerX

Updates an existing contract plan in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/contract_plans`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Contract Plan By External ID](https://doc.api.customerx.com.br/?version=latest#db3db56d-5716-408c-8885-fadd34380117)
