# Update Contract Additive By External ID with CustomerX

Updates an existing contract additive in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/contract_additives`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Contract Additive By External ID](https://doc.api.customerx.com.br/?version=latest#52561a54-9340-4d7e-8218-fc76b10c5895)
