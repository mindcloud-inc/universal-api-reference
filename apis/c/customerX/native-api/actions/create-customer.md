# Create Customer with CustomerX

Creates a new customer in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Customer](https://doc.api.customerx.com.br/?version=latest#75ce15f7-1214-46e3-bf5b-f12f07f4ed7f)
