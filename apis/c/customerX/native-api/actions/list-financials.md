# List Financials with CustomerX

Retrieves a list of financial records from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/financials`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Financials](https://doc.api.customerx.com.br/?version=latest#9003e023-03af-4ea5-92b9-11906313e48e)
