# Update Contact By External ID with CustomerX

Updates an existing contact in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Contact By External ID](https://doc.api.customerx.com.br/?version=latest#2d21e78d-d34b-46c4-be5c-7e9b9d556ad1)
