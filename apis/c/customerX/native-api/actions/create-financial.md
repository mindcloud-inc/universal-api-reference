# Create Financial with CustomerX

Creates a new financial record in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/financials`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Financial](https://doc.api.customerx.com.br/?version=latest#8fa1b02a-69f7-4957-a498-50c33bec567e)
