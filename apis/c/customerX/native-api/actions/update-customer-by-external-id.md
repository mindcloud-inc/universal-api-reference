# Update Customer By External ID with CustomerX

Updates an existing customer in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Customer By External ID](https://doc.api.customerx.com.br/?version=latest#1251a72c-b705-427a-8fe9-def1fdb96cab)
