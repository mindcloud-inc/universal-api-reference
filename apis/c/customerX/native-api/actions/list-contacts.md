# List Contacts with CustomerX

Retrieves a list of contacts from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Contacts](https://doc.api.customerx.com.br/?version=latest#c6dddf3e-13a3-4d2d-bd0d-81c1bdf1a5c3)
