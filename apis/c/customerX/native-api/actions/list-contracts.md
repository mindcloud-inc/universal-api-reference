# List Contracts with CustomerX

Retrieves a list of contracts from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contracts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Contracts](https://doc.api.customerx.com.br/?version=latest#1d520661-8731-49c8-bd9b-9a22d6859461)
