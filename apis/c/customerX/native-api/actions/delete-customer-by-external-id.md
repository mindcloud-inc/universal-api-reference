# Delete Customer By External ID with CustomerX

Deletes an existing customer from CustomerX by external ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/clients`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Delete Customer By External ID](https://doc.api.customerx.com.br/?version=latest#1fb8307a-3885-4476-8459-acfaa77cb877)
