# Update Contract By External ID with CustomerX

Updates an existing contract in CustomerX by external ID.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/contracts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Update Contract By External ID](https://doc.api.customerx.com.br/?version=latest#5c518577-8c42-4e40-8475-09ae7a0f0888)
