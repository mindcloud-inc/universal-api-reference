# Create Contract Plan with CustomerX

Creates a new contract plan in CustomerX.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contract_plans`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Create Contract Plan](https://doc.api.customerx.com.br/?version=latest#3161c013-fdb2-4954-b7cb-e5b2e20ee24d)
