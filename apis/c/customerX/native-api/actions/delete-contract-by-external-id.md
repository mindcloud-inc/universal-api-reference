# Delete Contract By External ID with CustomerX

Deletes an existing contract from CustomerX by external ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contracts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Delete Contract By External ID](https://doc.api.customerx.com.br/?version=latest#15a58fe7-b5cb-4c24-a058-f92900f19ff9)
