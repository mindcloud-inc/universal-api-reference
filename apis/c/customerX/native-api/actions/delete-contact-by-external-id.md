# Delete Contact By External ID with CustomerX

Deletes an existing contact from CustomerX by external ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [Delete Contact By External ID](https://doc.api.customerx.com.br/?version=latest#73e29b9f-7240-400c-b40d-6d7c7099a899)
