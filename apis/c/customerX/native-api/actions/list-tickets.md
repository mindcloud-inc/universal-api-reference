# List Tickets with CustomerX

Retrieves a list of tickets from CustomerX.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tickets`
- **Base URL:** `https://sandbox.api.customerx.com.br`
- **Official documentation:** [List Tickets](https://doc.api.customerx.com.br/?version=latest#2833a454-fb40-46b7-9e11-4a780af88e02)
