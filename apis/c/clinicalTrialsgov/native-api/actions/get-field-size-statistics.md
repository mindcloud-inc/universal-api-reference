# Get Field Size Statistics with ClinicalTrials.gov

## Endpoint

- **Method:** `GET`
- **Path:** `/stats/field/sizes`
- **Base URL:** `https://clinicaltrials.gov/api/v2`
- **Official documentation:** [Get Field Size Statistics](https://clinicaltrials.gov/data-api/about-api/study-data-structure)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | One or more data fields or pieces to analyze for value size distributions. |
