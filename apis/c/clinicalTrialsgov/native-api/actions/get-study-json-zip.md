# Get Study JSON ZIP with ClinicalTrials.gov

## Endpoint

- **Method:** `GET`
- **Path:** `/studies/:nctId`
- **Base URL:** `https://clinicaltrials.gov/api/v2`
- **Official documentation:** [Get Study JSON ZIP](https://clinicaltrials.gov/data-api/how-download-study-records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nctId` | path | `string` | yes | ClinicalTrials.gov study identifier. |
