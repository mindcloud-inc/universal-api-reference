# Get Job with Connecteam

Retrieve a single job information by its unique ID

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/v1/jobs/:jobId`
- **Base URL:** `https://api.connecteam.com`
- **Official documentation:** [Get Job](https://developer.connecteam.com/reference/get_job_jobs_v1_jobs__jobId__get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
