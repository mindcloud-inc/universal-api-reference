# List Task Boards with Connecteam

Retrieve a list of task boards associated with the account

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/v1/taskboards`
- **Base URL:** `https://api.connecteam.com`
- **Official documentation:** [List Task Boards](https://developer.connecteam.com/reference/get_tasks_boards_tasks_v1_taskboards_get)
