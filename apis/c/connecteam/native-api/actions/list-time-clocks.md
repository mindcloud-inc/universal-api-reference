# List Time Clocks with Connecteam

Retrieve a list of time clocks associated with the account

## Endpoint

- **Method:** `GET`
- **Path:** `/time-clock/v1/time-clocks`
- **Base URL:** `https://api.connecteam.com`
- **Official documentation:** [List Time Clocks](https://developer.connecteam.com/reference/get_time_clocks_time_clock_v1_time_clocks_get)
