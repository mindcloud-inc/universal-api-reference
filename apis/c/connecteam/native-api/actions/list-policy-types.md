# List Policy Types with Connecteam

Retrieve a list of policy types associated with the account

## Endpoint

- **Method:** `GET`
- **Path:** `/time-off/v1/policy-types`
- **Base URL:** `https://api.connecteam.com`
- **Official documentation:** [List Policy Types](https://developer.connecteam.com/reference/get_policy_groups_time_off_v1_policy_types_get)
