# Get Audio Download URL with CRUSH

## Endpoint

- **Method:** `GET`
- **Path:** `/aws/audio`
- **Base URL:** `https://app.crushthememory.com/api`
- **Official documentation:** [Get Audio Download URL](https://app.crushthememory.com/dashboard)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | query | `string` | yes | The CRUSH note ID whose audio download URL should be returned. |
