# Delete Category with Chatvolt AI

Deletes a category from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/artifact-categories/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Category](https://docs.chatvolt.ai/api-reference/endpoint/artifacts/categories/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
