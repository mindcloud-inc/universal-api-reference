# Get Artifact with Chatvolt AI

Retrieves an artifact from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/artifacts/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Artifact](https://docs.chatvolt.ai/api-reference/endpoint/artifacts/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
