# Delete a Contact List with Chatvolt AI

Deletes a contact list from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dispatches/contacts/lists`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete a Contact List](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/contacts/lists/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the contact list to delete. |
