# List CRM Scenarios with Chatvolt AI

Retrieves CRM scenarios from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/scenario`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [List CRM Scenarios](https://docs.chatvolt.ai/api-reference/endpoint/crm/scenario/list-scenarios)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | query | `string` | no | Filter scenarios by a specific Agent ID. |
