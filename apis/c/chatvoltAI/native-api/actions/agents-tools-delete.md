# Delete Tool with Chatvolt AI

Deletes a tool from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/agents/{agentId}/tools/{toolId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Tool](https://docs.chatvolt.ai/api-reference/endpoint/agents/tools/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
| `toolId` | path | `string` | yes |
