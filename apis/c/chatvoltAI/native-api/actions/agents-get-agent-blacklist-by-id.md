# Get Agent Blacklist by Agent ID with Chatvolt AI

Retrieves agent blacklist entries from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent-blacklist/{agentId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Agent Blacklist by Agent ID](https://docs.chatvolt.ai/api-reference/endpoint/agents/get-agent-blacklist-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The ID of the agent. |
