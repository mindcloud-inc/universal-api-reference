# Delete CRM Step with Chatvolt AI

Deletes an existing CRM step from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crm/step`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete CRM Step](https://docs.chatvolt.ai/api-reference/endpoint/crm/step/delete-step)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The ID of the CRM step to delete. |
