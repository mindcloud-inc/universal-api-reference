# Delete CRM Conversation Log with Chatvolt AI

Deletes an existing CRM conversation log from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crm/conversationLog/{logId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete CRM Conversation Log](https://docs.chatvolt.ai/api-reference/endpoint/crm/conversation-log/delete-crm-conversation-log)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `logId` | path | `string` | yes | The ID of the CRM conversation log to delete. |
