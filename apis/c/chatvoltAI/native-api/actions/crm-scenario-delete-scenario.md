# Delete CRM Scenario with Chatvolt AI

Deletes an existing CRM scenario from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crm/scenario`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete CRM Scenario](https://docs.chatvolt.ai/api-reference/endpoint/crm/scenario/delete-scenario)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | The ID of the CRM scenario to delete. |
