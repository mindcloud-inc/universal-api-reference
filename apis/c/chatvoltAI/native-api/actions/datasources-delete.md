# Delete Datasource with Chatvolt AI

Deletes a datasource from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datasources/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Datasource](https://docs.chatvolt.ai/api-reference/endpoint/datasources/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the datasource to be deleted. |
