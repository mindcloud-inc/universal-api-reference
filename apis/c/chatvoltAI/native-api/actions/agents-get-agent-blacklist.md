# Get All Blacklist Entries with Chatvolt AI

Retrieves agent blacklist entries from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent-blacklist`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get All Blacklist Entries](https://docs.chatvolt.ai/api-reference/endpoint/agents/get-agent-blacklist)
