# Delete Datastore with Chatvolt AI

Deletes a datastore from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datastores/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Datastore](https://docs.chatvolt.ai/api-reference/endpoint/datastores/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Datastore |
