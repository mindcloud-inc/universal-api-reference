# Delete Scheduled Dispatch with Chatvolt AI

Deletes a scheduled Dispatch from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dispatches`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Scheduled Dispatch](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The ID of the dispatch to delete. |
