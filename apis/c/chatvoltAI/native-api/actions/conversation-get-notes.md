# Get Notes with Chatvolt AI

Retrieves notes from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/{conversationId}/notes`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Notes](https://docs.chatvolt.ai/api-reference/endpoint/conversation/get-notes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | ID of the conversation to get notes for. |
