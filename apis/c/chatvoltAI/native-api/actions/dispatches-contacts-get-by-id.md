# Get Contact by ID with Chatvolt AI

Retrieves a contact from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/dispatches/contacts/{contactId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Contact by ID](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/contacts/get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The ID of the contact to retrieve. |
