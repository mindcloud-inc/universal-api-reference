# Get All Custom Variables with Chatvolt AI

Retrieves custom variables from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/variables/{conversationId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get All Custom Variables](https://docs.chatvolt.ai/api-reference/endpoint/conversation/get-variables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Conversation ID. |
