# Get Contact Links with Chatvolt AI

Retrieves contact links from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/dispatches/contacts/link`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Contact Links](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/contacts/link/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dispatchId` | query | `string` | no | Dispatch Id filter. |
| `contactListId` | query | `string` | no | Contact List Id filter. |
