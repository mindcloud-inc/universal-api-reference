# Create Category with Chatvolt AI

Creates a category in Chatvolt AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/artifact-categories`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Create Category](https://docs.chatvolt.ai/api-reference/endpoint/artifacts/categories/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for application/json requests. |
| `description` | body | `string` | no | Description for application/json requests. |
| `parentId` | body | `string` | no | ParentId for application/json requests. |
