# Get Conversation By Id with Chatvolt AI

Retrieves a conversation from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversation/{conversationId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Conversation By Id](https://docs.chatvolt.ai/api-reference/endpoint/conversation/get-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | ID of the conversation to be retrieved. |
