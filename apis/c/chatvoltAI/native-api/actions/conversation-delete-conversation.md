# Delete Conversation with Chatvolt AI

Deletes a conversation from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversation/{conversationId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Conversation](https://docs.chatvolt.ai/api-reference/endpoint/conversation/delete-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | ID of the conversation to be deleted. |
