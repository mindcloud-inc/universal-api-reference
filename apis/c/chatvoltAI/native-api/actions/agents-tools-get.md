# Get Tools with Chatvolt AI

Retrieves tools from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/agents/{agentId}/tools`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Tools](https://docs.chatvolt.ai/api-reference/endpoint/agents/tools/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
