# List Datastores with Chatvolt AI

Retrieves datastores from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/datastores/list`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [List Datastores](https://docs.chatvolt.ai/api-reference/endpoint/datastores/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `offset` | query | `number` | no | Number of items to skip. |
| `limit` | query | `number` | no | Maximum number of items to return. |
