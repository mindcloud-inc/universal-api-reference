# List Meta Templates with Chatvolt AI

Retrieves meta Templates from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/whatsapp/templates`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [List Meta Templates](https://docs.chatvolt.ai/api-reference/endpoint/whatsapp/list-templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | query | `string` | yes | ID of the agent with WhatsApp configured. |
