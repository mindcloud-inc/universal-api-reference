# Populate Dispatch Queue with Chatvolt AI

Populates a dispatch queue in Chatvolt AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/dispatches/{id}/populate-queue`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Populate Dispatch Queue](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/populate-queue)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the dispatch to populate. |
