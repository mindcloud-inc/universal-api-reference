# Delete Agent with Chatvolt AI

Deletes an agent from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agents/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Agent](https://docs.chatvolt.ai/api-reference/endpoint/agents/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the agent to be deleted. |
