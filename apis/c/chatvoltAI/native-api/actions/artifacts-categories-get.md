# Get Category with Chatvolt AI

Retrieves a category from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/artifact-categories/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Category](https://docs.chatvolt.ai/api-reference/endpoint/artifacts/categories/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
