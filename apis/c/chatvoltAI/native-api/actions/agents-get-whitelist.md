# Get Whitelist Numbers with Chatvolt AI

Retrieves whitelist numbers from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent-whitelist-whatsapp/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get Whitelist Numbers](https://docs.chatvolt.ai/api-reference/endpoint/agents/getWhitelist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the agent. |
