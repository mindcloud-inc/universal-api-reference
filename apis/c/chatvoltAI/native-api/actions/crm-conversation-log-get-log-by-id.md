# Get CRM Conversation Log by ID with Chatvolt AI

Retrieves a CRM conversation log from Chatvolt AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/conversationLog/{logId}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Get CRM Conversation Log by ID](https://docs.chatvolt.ai/api-reference/endpoint/crm/conversation-log/get-log-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `logId` | path | `string` | yes | The ID of the CRM conversation log to retrieve. |
