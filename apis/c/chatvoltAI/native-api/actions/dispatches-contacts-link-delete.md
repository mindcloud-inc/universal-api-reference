# Unlink Contact from Dispatch with Chatvolt AI

Unlinks a contact from a dispatch in Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/dispatches/contacts/link`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Unlink Contact from Dispatch](https://docs.chatvolt.ai/api-reference/endpoint/dispatches/contacts/link/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dispatchId` | query | `string` | no | Dispatch Id filter. |
| `contactListId` | query | `string` | no | Contact List Id filter. |
