# Delete Media with Chatvolt AI

Deletes a media from Chatvolt AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/artifacts/media/{id}`
- **Base URL:** `https://api.chatvolt.ai`
- **Official documentation:** [Delete Media](https://docs.chatvolt.ai/api-reference/endpoint/artifacts/media/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
