# PDF to PNG with ComPDFKit PDF Editor

Creates a PDF-to-PNG conversion task in ComPDFKit PDF Editor.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/png`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [PDF to PNG](https://api.compdf.com/api-reference/conversion-guides)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
