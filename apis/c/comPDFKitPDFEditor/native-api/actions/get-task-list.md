# Get Task List with ComPDFKit PDF Editor

Retrieves file transfer tasks from ComPDFKit PDF Editor.

## Endpoint

- **Method:** `GET`
- **Path:** `/server/v2/task/list`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [Get Task List](https://api.compdf.com/api-reference/api-list)
