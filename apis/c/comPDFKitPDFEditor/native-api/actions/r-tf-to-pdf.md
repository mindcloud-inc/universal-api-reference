# RTF to PDF with ComPDFKit PDF Editor

Creates an RTF-to-PDF conversion task in ComPDFKit PDF Editor.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/rtf/pdf`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [RTF to PDF](https://api.compdf.com/api-reference/conversion-guides)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
