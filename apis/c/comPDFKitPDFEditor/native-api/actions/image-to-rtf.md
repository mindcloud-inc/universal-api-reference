# Image to RTF with ComPDFKit PDF Editor

Creates an image-to-RTF conversion task in ComPDFKit PDF Editor.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/img/rtf`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [Image to RTF](https://api.compdf.com/api-reference/conversion-guides)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
