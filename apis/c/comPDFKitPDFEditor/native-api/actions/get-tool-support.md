# Get Tool Support with ComPDFKit PDF Editor

Retrieves supported PDF tools from ComPDFKit PDF Editor.

## Endpoint

- **Method:** `GET`
- **Path:** `/server/v2/tool/support`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [Get Tool Support](https://api.compdf.com/api-reference/api-list)
