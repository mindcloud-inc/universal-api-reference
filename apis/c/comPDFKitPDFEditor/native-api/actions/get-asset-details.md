# Get Asset Details with ComPDFKit PDF Editor

Retrieves remaining asset balances from ComPDFKit PDF Editor.

## Endpoint

- **Method:** `GET`
- **Path:** `/server/v2/asset/info`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [Get Asset Details](https://api.compdf.com/api-reference/api-list-presigned)
