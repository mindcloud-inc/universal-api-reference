# PDF to JPG with ComPDFKit PDF Editor

Creates a PDF-to-JPG conversion task in ComPDFKit PDF Editor.

## Endpoint

- **Method:** `POST`
- **Path:** `/server/v2/process/pdf/jpg`
- **Base URL:** `https://api-server.compdf.com`
- **Official documentation:** [PDF to JPG](https://api.compdf.com/api-reference/conversion-guides)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
