# Get Task Status with Cloro

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/async/task/:taskId`
- **Base URL:** `https://api.cloro.dev`
- **Official documentation:** [Get Task Status](https://docs.cloro.dev/api-reference/endpoint/get-task-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The Cloro async task ID to retrieve. |
