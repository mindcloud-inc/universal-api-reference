# List Countries with Cloro

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/countries`
- **Base URL:** `https://api.cloro.dev`
- **Official documentation:** [List Countries](https://docs.cloro.dev/api-reference/endpoint/countries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `model` | query | `string` | no | Filter countries available for a specific Cloro model. |
