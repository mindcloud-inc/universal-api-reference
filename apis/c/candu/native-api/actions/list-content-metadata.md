# List Content Metadata with Candu

Retrieves content metadata records from Candu.

## Endpoint

- **Method:** `GET`
- **Path:** `/contentMetadata`
- **Base URL:** `https://api.candu.ai/api`
- **Official documentation:** [List Content Metadata](https://developers.candu.ai/docs/get-data-into-candu-via-the-rest-api)
