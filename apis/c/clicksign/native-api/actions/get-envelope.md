# Get Envelope with Clicksign

Retrieves an envelope from Clicksign.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelopes/:envelope_id`
- **Base URL:** `https://app.clicksign.com/api/v3`
- **Official documentation:** [Get Envelope](https://developers.clicksign.com/reference/api-detalhes-do-envelope)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `envelope_id` | path | `string` | yes | The UUID of the envelope. |
