# List Envelopes with Clicksign

Retrieves envelopes from Clicksign.

## Endpoint

- **Method:** `GET`
- **Path:** `/envelopes`
- **Base URL:** `https://app.clicksign.com/api/v3`
- **Official documentation:** [List Envelopes](https://developers.clicksign.com/reference/api-listar-envelopes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
