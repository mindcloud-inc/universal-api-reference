# Delete Envelope with Clicksign

Deletes an existing envelope from Clicksign.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/envelopes/:envelope_id`
- **Base URL:** `https://app.clicksign.com/api/v3`
- **Official documentation:** [Delete Envelope](https://developers.clicksign.com/reference/api-excluir-envelope)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `envelope_id` | path | `string` | yes | The UUID of the envelope. |
