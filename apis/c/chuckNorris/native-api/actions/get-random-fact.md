# Get Random Fact with Chuck Norris

## Endpoint

- **Method:** `GET`
- **Path:** `/jokes/random`
- **Base URL:** `https://api.chucknorris.io`
- **Official documentation:** [Get Random Fact](https://github.com/chucknorris-io/chuck-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | query | `string` | no | Optional category or comma-separated categories returned by List Fact Categories. |
| `name` | query | `string` | no | Optional name used to personalize the returned fact. |
