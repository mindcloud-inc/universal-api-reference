# Search Facts with Chuck Norris

## Endpoint

- **Method:** `GET`
- **Path:** `/jokes/search`
- **Base URL:** `https://api.chucknorris.io`
- **Official documentation:** [Search Facts](https://github.com/chucknorris-io/chuck-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Free-text search query. |
