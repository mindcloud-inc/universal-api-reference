# Get a Design with ChurchStamp

Retrieves design details from ChurchStamp by design ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-a-design`
- **Base URL:** `https://v2.churchstamp.com/api/1.1/wf`
- **Official documentation:** [Get a Design](https://churchstampapi.docs.apiary.io/reference/designs/get-a-design)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `design_id` | query | `string` | yes | Unique identifier for the design. |
