# Get Designs with ChurchStamp

Retrieves a collection of designs from ChurchStamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-designs`
- **Base URL:** `https://v2.churchstamp.com/api/1.1/wf`
- **Official documentation:** [Get Designs](https://churchstampapi.docs.apiary.io/reference/designs/get-designs)
