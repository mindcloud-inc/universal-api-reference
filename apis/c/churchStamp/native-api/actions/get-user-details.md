# Get User Details with ChurchStamp

Retrieves authenticated user details from ChurchStamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-user`
- **Base URL:** `https://v2.churchstamp.com/api/1.1/wf`
- **Official documentation:** [Get User Details](https://churchstampapi.docs.apiary.io/reference/account/get-user-details)
