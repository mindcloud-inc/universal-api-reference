# Get a Campaign with ChurchStamp

Retrieves campaign details from ChurchStamp by campaign ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-a-campaigns`
- **Base URL:** `https://v2.churchstamp.com/api/1.1/wf`
- **Official documentation:** [Get a Campaign](https://churchstampapi.docs.apiary.io/reference/campaigns/get-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | query | `string` | yes | Unique identifier for the campaign. |
