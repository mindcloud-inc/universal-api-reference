# Get Campaigns with ChurchStamp

Retrieves a list of campaigns from ChurchStamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-campaigns`
- **Base URL:** `https://v2.churchstamp.com/api/1.1/wf`
- **Official documentation:** [Get Campaigns](https://churchstampapi.docs.apiary.io/reference/campaigns/get-campaigns)
