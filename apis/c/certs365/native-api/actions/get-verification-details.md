# Get Verification Details with Certs 365

Retrieves course-wise verification details from Certs 365.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/get-verification-details`
- **Base URL:** `https://api1.certs365.io`
- **Official documentation:** [Get Verification Details](https://help.certs365.io/documentation/fetching-upload-request-details/get-verification-details-of-issuer-course-wise/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Provide a valid issuer email. |
