# Check Balance with Certs 365

Retrieves the MATIC balance from Certs 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/check-balance`
- **Base URL:** `https://api1.certs365.io`
- **Official documentation:** [Check Balance](https://help.certs365.io/documentation/blockchain/check-balance-matic/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `address` | query | `string` | yes | Ethereum address to check the balance for. |
