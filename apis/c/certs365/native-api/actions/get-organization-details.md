# Get Organization Details with Certs 365

Retrieves organization details from Certs 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get-organization-details`
- **Base URL:** `https://api1.certs365.io`
- **Official documentation:** [Get Organization Details](https://help.certs365.io/documentation/fetching-upload-request-details/get-organizations-details-unique-list-for-mobile-application/)
