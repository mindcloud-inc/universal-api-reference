# Get Issuer By Email with Certs 365

Retrieves issuer details from Certs 365 by email.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/get-issuer-by-email`
- **Base URL:** `https://api1.certs365.io`
- **Official documentation:** [Get Issuer By Email](https://help.certs365.io/documentation/fetching-upload-request-details/get-issuer-details-by-email/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Issuer email address. |
