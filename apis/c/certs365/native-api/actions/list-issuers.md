# List Issuers with Certs 365

Retrieves issuer details from Certs 365.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/get-all-issuers/`
- **Base URL:** `https://api1.certs365.io`
- **Official documentation:** [List Issuers](https://help.certs365.io/documentation/fetching-upload-request-details/get-details-of-issuers-unapproved/)
