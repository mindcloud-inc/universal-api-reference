# Delete Source with Curator

Deletes an existing source from Curator.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/sources/:SOURCE_ID`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [Delete Source](https://curator.io/docs/api/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SOURCE_ID` | path | `string` | yes | ID of the source to delete. |
