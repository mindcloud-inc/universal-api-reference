# Delete Feed with Curator

Deletes an existing feed from Curator.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/feeds/:FEED_ID`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [Delete Feed](https://curator.io/docs/api/feeds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `FEED_ID` | path | `string` | yes | ID of the feed to delete. |
