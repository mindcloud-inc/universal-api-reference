# List Sources with Curator

Retrieves sources from Curator.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sources`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [List Sources](https://curator.io/docs/api/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `feed_id` | query | `string` | no | Optional feed filter. |
