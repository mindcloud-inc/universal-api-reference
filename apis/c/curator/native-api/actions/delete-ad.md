# Delete Ad with Curator

Deletes an existing ad or custom post from Curator.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1.2/ads/:AD_ID`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [Delete Ad](https://curator.io/docs/api/ads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `AD_ID` | path | `string` | yes | ID of the ad to delete. |
