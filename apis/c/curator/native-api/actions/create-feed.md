# Create Feed with Curator

Creates a feed in Curator.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/feeds`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [Create Feed](https://curator.io/docs/api/feeds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the feed. |
