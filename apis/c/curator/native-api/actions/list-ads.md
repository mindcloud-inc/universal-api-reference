# List Ads with Curator

Retrieves ads and custom posts from Curator.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1.2/ads`
- **Base URL:** `https://api.curator.io`
- **Official documentation:** [List Ads](https://curator.io/docs/api/ads)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `feed_id` | query | `string` | no | Optional feed filter. |
