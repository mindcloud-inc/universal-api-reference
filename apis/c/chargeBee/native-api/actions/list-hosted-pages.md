# List Hosted Pages with ChargeBee

Retrieves hosted pages from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `hosted_pages`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Hosted Pages](https://apidocs.chargebee.com/docs/api/hosted-pages/list-hosted-pages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
