# List Business Entities with ChargeBee

Retrieves business entities from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `business_entities`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Business Entities](https://apidocs.chargebee.com/docs/api/business-entities/list-business-entities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
