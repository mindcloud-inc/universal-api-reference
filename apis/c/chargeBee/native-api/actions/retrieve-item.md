# Retrieve Item with ChargeBee

Retrieves an item from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `items/:item_id`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [Retrieve Item](https://apidocs.chargebee.com/docs/api/items/retrieve-an-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `string` | yes | The Chargebee item identifier. |
