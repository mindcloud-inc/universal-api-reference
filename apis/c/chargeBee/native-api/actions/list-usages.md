# List Usages with ChargeBee

Retrieves usages from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `usages`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Usages](https://apidocs.chargebee.com/docs/api/usages/list-usages)

## Capabilities

This operation supports [pagination](../README.md#pagination).
