# Retrieve Credit Note with ChargeBee

Retrieves a credit note from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `credit_notes/:credit_note_id`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [Retrieve Credit Note](https://apidocs.chargebee.com/docs/api/credit-notes/retrieve-a-credit-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `credit_note_id` | path | `string` | yes | The Chargebee credit note identifier. |
