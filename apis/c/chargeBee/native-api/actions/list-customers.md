# List Customers with ChargeBee

Retrieves customers from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `customers`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Customers](https://apidocs.chargebee.com/docs/api/customers/list-customers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
