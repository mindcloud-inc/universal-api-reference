# List Transactions with ChargeBee

Retrieves transactions from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `transactions`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Transactions](https://apidocs.chargebee.com/docs/api/transactions/list-transactions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
