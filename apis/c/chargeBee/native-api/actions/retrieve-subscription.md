# Retrieve Subscription with ChargeBee

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions/:subscription_id`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [Retrieve Subscription](https://apidocs.chargebee.com/docs/api/subscriptions/retrieve-a-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes | The unique identifier of the Chargebee subscription to retrieve. |
