# List Payment Sources with ChargeBee

Retrieves payment sources from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `payment_sources`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Payment Sources](https://apidocs.chargebee.com/docs/api/payment-sources/list-payment-sources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
