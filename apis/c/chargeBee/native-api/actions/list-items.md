# List Items with ChargeBee

Retrieves items from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `items`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Items](https://apidocs.chargebee.com/docs/api/items/list-items)

## Capabilities

This operation supports [pagination](../README.md#pagination).
