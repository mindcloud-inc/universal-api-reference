# Retrieve Customer with ChargeBee

## Endpoint

- **Method:** `GET`
- **Path:** `customers/:customer_id`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [Retrieve Customer](https://apidocs.chargebee.com/docs/api/customers/retrieve-a-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | The unique identifier of the Chargebee customer to retrieve. |
