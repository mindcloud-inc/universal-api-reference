# List Orders with ChargeBee

Retrieves orders from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `orders`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Orders](https://apidocs.chargebee.com/docs/api/orders/list-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
