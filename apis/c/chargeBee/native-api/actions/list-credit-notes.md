# List Credit Notes with ChargeBee

Retrieves credit notes from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `credit_notes`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Credit Notes](https://apidocs.chargebee.com/docs/api/credit-notes/list-credit-notes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
