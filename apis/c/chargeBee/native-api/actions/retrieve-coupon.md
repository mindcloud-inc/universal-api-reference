# Retrieve Coupon with ChargeBee

Retrieves a coupon from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `coupons/:coupon_id`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [Retrieve Coupon](https://apidocs.chargebee.com/docs/api/coupons/retrieve-a-coupon)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coupon_id` | path | `string` | yes | The Chargebee coupon identifier. |
