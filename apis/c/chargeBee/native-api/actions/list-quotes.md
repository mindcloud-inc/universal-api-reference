# List Quotes with ChargeBee

Retrieves quotes from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `quotes`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Quotes](https://apidocs.chargebee.com/docs/api/quotes/list-quotes)

## Capabilities

This operation supports [pagination](../README.md#pagination).
