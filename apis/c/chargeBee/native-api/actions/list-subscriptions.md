# List Subscriptions with ChargeBee

Retrieves subscriptions from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Subscriptions](https://apidocs.chargebee.com/docs/api/subscriptions/list-subscriptions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
