# List Item Prices with ChargeBee

Retrieves item prices from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `item_prices`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Item Prices](https://apidocs.chargebee.com/docs/api/item-prices/list-item-prices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
