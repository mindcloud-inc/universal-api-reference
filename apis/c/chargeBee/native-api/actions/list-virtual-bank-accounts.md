# List Virtual Bank Accounts with ChargeBee

Retrieves virtual bank accounts from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `virtual_bank_accounts`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Virtual Bank Accounts](https://apidocs.chargebee.com/docs/api/virtual-bank-accounts/list-virtual-bank-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
