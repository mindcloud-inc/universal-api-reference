# List Invoices with ChargeBee

Retrieves invoices from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `invoices`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Invoices](https://apidocs.chargebee.com/docs/api/invoices/list-invoices)

## Capabilities

This operation supports [pagination](../README.md#pagination).
