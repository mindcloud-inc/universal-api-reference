# List Promotional Credits with ChargeBee

Retrieves promotional credits from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `promotional_credits`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Promotional Credits](https://apidocs.chargebee.com/docs/api/promotional-credits/list-promotional-credits)

## Capabilities

This operation supports [pagination](../README.md#pagination).
