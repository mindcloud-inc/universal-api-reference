# List Coupons with ChargeBee

Retrieves coupons from ChargeBee.

## Endpoint

- **Method:** `GET`
- **Path:** `coupons`
- **Base URL:** `https://{baseUrl}.chargebee.com/api/v2/`
- **Official documentation:** [List Coupons](https://apidocs.chargebee.com/docs/api/coupons/list-coupons)

## Capabilities

This operation supports [pagination](../README.md#pagination).
