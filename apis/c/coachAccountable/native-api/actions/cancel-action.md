# Cancel Action with CoachAccountable

Cancels an action in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Cancel Action](https://www.coachaccountable.com/APIDocs#Action.cancel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActionID` | body | `number` | yes |
