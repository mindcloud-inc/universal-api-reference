# Delete Agreement with CoachAccountable

Deletes an agreement from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Agreement](https://www.coachaccountable.com/APIDocs#Agreement.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `AgreementID` | body | `number` | yes |
