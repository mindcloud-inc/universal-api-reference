# Delete Appointment with CoachAccountable

Deletes an appointment from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Appointment](https://www.coachaccountable.com/APIDocs#Appointment.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `AppointmentID` | body | `number` | yes |
