# Delete Worksheet with CoachAccountable

Deletes a worksheet from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Worksheet](https://www.coachaccountable.com/APIDocs#Worksheet.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `WorksheetID` | body | `number` | yes |
