# Unmark Metric Complete with CoachAccountable

Unmarks a metric complete in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Unmark Metric Complete](https://www.coachaccountable.com/APIDocs#Metric.unmarkComplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `MetricID` | body | `number` | yes | ID of the Metric to be unmarked complete. |
