# Deactivate Group Client Member with CoachAccountable

Deactivates a group client member in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Deactivate Group Client Member](https://www.coachaccountable.com/APIDocs#Group.deactivateClientMember)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `GroupClientID` | body | `number` | yes |
