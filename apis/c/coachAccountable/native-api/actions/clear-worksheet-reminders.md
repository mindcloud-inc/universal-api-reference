# Clear Worksheet Reminders with CoachAccountable

Clears worksheet reminders in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Clear Worksheet Reminders](https://www.coachaccountable.com/APIDocs#Worksheet.clearReminders)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `WorksheetID` | body | `number` | yes |
