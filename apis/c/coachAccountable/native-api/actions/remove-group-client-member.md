# Remove Group Client Member with CoachAccountable

Removes a group client member from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Remove Group Client Member](https://www.coachaccountable.com/APIDocs#Group.removeClientMember)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `GroupClientID` | body | `number` | yes | The ID of the Group Client Member to be removed. |
