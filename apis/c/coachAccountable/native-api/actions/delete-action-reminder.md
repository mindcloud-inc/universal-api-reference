# Delete Action Reminder with CoachAccountable

Deletes an action reminder from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Action Reminder](https://www.coachaccountable.com/APIDocs#Action.deleteReminder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ReminderID` | body | `number` | yes |
