# Delete Invoice Payment with CoachAccountable

Deletes an invoice payment from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Invoice Payment](https://www.coachaccountable.com/APIDocs#Invoice.deletePayment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PaymentID` | body | `number` | yes | The ID of the Invoice Payment which is to be deleted. |
