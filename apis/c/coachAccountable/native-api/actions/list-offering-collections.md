# List Offering Collections with CoachAccountable

- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [List Offering Collections](https://www.coachaccountable.com/APIDocs#OfferingCollection.getAll)
