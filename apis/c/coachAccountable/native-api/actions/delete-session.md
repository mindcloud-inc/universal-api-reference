# Delete Session with CoachAccountable

Deletes a session from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Session](https://www.coachaccountable.com/APIDocs#Session.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `SessionID` | body | `number` | yes |
