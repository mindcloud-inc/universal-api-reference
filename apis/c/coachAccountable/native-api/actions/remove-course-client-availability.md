# Remove Course Client Availability with CoachAccountable

Removes course client availability from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Remove Course Client Availability](https://www.coachaccountable.com/APIDocs#Course.removeClientAvailability)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CourseAvailabilityID` | body | `number` | yes | The ID of the Course Availability to be removed. |
