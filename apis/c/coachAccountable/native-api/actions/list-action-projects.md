# List Action Projects with CoachAccountable

Retrieves action projects from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [List Action Projects](https://www.coachaccountable.com/APIDocs#Action.getAllProjects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ClientID` | body | `number` | yes |
