# Reopen Engagement with CoachAccountable

Reopens an engagement in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Reopen Engagement](https://www.coachaccountable.com/APIDocs#Engagement.reopen)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `EngagementID` | body | `number` | yes |
