# Delete Engagement with CoachAccountable

Deletes an engagement from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Engagement](https://www.coachaccountable.com/APIDocs#Engagement.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `EngagementID` | body | `number` | yes |
