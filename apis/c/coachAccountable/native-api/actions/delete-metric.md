# Delete Metric with CoachAccountable

Deletes a metric from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Metric](https://www.coachaccountable.com/APIDocs#Metric.delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `MetricID` | body | `number` | yes | ID of the Metric to be deleted. |
