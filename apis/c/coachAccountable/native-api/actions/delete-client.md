# Delete Client with CoachAccountable

Deletes a client from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Client](https://www.coachaccountable.com/APIDocs#Client.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ClientID` | body | `number` | yes |
