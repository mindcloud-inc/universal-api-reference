# Mark Metric Complete with CoachAccountable

Marks a metric complete in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Mark Metric Complete](https://www.coachaccountable.com/APIDocs#Metric.markComplete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `MetricID` | body | `number` | yes | ID of the Metric to be marked complete. |
