# Delete Action with CoachAccountable

Deletes an action from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Action](https://www.coachaccountable.com/APIDocs#Action.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActionID` | body | `number` | yes |
