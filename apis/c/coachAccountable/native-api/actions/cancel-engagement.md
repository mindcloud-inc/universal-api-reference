# Cancel Engagement with CoachAccountable

Cancels an engagement in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Cancel Engagement](https://www.coachaccountable.com/APIDocs#Engagement.cancel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `EngagementID` | body | `number` | yes |
