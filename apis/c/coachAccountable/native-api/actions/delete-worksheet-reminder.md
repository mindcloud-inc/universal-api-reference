# Delete Worksheet Reminder with CoachAccountable

Deletes a worksheet reminder from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Delete Worksheet Reminder](https://www.coachaccountable.com/APIDocs#Worksheet.deleteReminder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ReminderID` | body | `number` | yes |
