# Unmark Action Done with CoachAccountable

Unmarks an action done in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Unmark Action Done](https://www.coachaccountable.com/APIDocs#Action.unmarkDone)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActionID` | body | `number` | yes |
