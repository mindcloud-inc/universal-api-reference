# Uncancel Action with CoachAccountable

Uncancels an action in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Uncancel Action](https://www.coachaccountable.com/APIDocs#Action.uncancel)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActionID` | body | `number` | yes |
