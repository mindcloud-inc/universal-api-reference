# Activate Group Client Member with CoachAccountable

Activates a group client member in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Activate Group Client Member](https://www.coachaccountable.com/APIDocs#Group.activateClientMember)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `GroupClientID` | body | `number` | yes |
