# Clear Action Reminders with CoachAccountable

Clears action reminders in CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Clear Action Reminders](https://www.coachaccountable.com/APIDocs#Action.clearReminders)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ActionID` | body | `number` | yes |
