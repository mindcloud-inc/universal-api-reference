# Get Client Appointment Settings with CoachAccountable

Retrieves client appointment settings from CoachAccountable.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://www.coachaccountable.com/API`
- **Official documentation:** [Get Client Appointment Settings](https://www.coachaccountable.com/APIDocs#Client.getAppointmentSettings)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ClientID` | body | `number` | yes |
