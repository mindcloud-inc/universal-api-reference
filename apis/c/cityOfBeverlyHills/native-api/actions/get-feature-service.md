# Get Feature Service with City of Beverly Hills

Retrieves feature service details from City of Beverly Hills.

## Endpoint

- **Method:** `GET`
- **Path:** `:serviceName/FeatureServer`
- **Base URL:** `https://services5.arcgis.com/7CXE3aevo18HlHBC/arcgis/rest/services`
- **Official documentation:** [Get Feature Service](https://developers.arcgis.com/rest/services-reference/enterprise/feature-service/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceName` | path | `string` | yes | ArcGIS service folder or service name. |
