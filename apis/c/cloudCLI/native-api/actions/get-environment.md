# Get Environment with Cloud CLI

Retrieves an environment from Cloud CLI.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments/:id`
- **Base URL:** `https://cloudcli.ai/api/v1`
- **Official documentation:** [Get Environment](https://developer.cloudcli.ai/get-environment-3998769e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Environment ID. |
