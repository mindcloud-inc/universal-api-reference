# Stop Environment with Cloud CLI

Stops an existing environment in Cloud CLI.

## Endpoint

- **Method:** `POST`
- **Path:** `/environments/:id/stop`
- **Base URL:** `https://cloudcli.ai/api/v1`
- **Official documentation:** [Stop Environment](https://developer.cloudcli.ai/stop-environment-3998772e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Environment ID. |
