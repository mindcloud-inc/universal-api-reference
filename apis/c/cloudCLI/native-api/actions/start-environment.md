# Start Environment with Cloud CLI

Starts an existing environment in Cloud CLI.

## Endpoint

- **Method:** `POST`
- **Path:** `/environments/:id/start`
- **Base URL:** `https://cloudcli.ai/api/v1`
- **Official documentation:** [Start Environment](https://developer.cloudcli.ai/start-environment-3998771e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Environment ID. |
