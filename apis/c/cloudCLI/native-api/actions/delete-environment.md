# Delete Environment with Cloud CLI

Deletes an existing environment from Cloud CLI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/environments/:id`
- **Base URL:** `https://cloudcli.ai/api/v1`
- **Official documentation:** [Delete Environment](https://developer.cloudcli.ai/delete-environment-3998770e0)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Environment ID. |
