# List Users with CodeREADr

Retrieves authorized app users from CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [List Users](https://secure.codereadr.com/apidocs/Users.md#retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | body | `string` | no | Optional user IDs to filter the list. |
