# Clear Database with CodeREADr

Clears all values from a validation database in CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [Clear Database](https://secure.codereadr.com/apidocs/Databases.md#clear)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | body | `string` | yes | Database to clear. |
