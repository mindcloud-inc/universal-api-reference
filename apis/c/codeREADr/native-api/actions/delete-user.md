# Delete User with CodeREADr

Deletes an existing app user from CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [Delete User](https://secure.codereadr.com/apidocs/Users.md#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | body | `string` | yes | CodeREADr user ID. |
