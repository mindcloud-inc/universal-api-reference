# List Questions with CodeREADr

Retrieves data collection questions from CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [List Questions](https://secure.codereadr.com/apidocs/Questions.md#retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `question_id` | body | `string` | no | Optional question IDs to filter the list. |
