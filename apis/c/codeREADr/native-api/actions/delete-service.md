# Delete Service with CodeREADr

Deletes an existing scanning service from CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [Delete Service](https://secure.codereadr.com/apidocs/Services.md#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_id` | body | `string` | yes | Service or services to delete. |
