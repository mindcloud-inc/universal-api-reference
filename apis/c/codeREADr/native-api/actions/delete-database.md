# Delete Database with CodeREADr

Deletes an existing validation database from CodeREADr.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/`
- **Base URL:** `https://api.codereadr.com`
- **Official documentation:** [Delete Database](https://secure.codereadr.com/apidocs/Databases.md#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `database_id` | body | `string` | yes | Database to delete. |
