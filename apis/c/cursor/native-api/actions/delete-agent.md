# Delete Agent with Cursor

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v0/agents/{{id}}`
- **Base URL:** `https://api.cursor.com`
- **Official documentation:** [Delete Agent](https://cursor.com/docs/cloud-agent/api/endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the cloud agent to delete. |
