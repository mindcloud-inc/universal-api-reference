# Get Agent Conversation with Cursor

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/agents/{{id}}/conversation`
- **Base URL:** `https://api.cursor.com`
- **Official documentation:** [Get Agent Conversation](https://cursor.com/docs/cloud-agent/api/endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the cloud agent conversation to retrieve. |
