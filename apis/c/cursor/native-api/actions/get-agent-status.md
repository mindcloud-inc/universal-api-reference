# Get Agent Status with Cursor

## Endpoint

- **Method:** `GET`
- **Path:** `/v0/agents/{{id}}`
- **Base URL:** `https://api.cursor.com`
- **Official documentation:** [Get Agent Status](https://cursor.com/docs/cloud-agent/api/endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the cloud agent, for example `bc_abc123`. |
