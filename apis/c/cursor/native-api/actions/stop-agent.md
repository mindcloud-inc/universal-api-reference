# Stop Agent with Cursor

## Endpoint

- **Method:** `POST`
- **Path:** `/v0/agents/{{id}}/stop`
- **Base URL:** `https://api.cursor.com`
- **Official documentation:** [Stop Agent](https://cursor.com/docs/cloud-agent/api/endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the cloud agent to stop. |
