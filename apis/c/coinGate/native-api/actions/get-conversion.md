# Get Conversion with CoinGate

Retrieves a currency conversion from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/conversions/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Conversion](https://developer.coingate.com/reference/get-conversion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate conversion ID. |
