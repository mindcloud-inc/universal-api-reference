# List Conversion Rates with CoinGate

Retrieves supported conversion rates from CoinGate.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/conversions/rates`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Conversion Rates](https://developer.coingate.com/reference/conversion-rates)
