# List Supported Deposit Currencies with CoinGate

Retrieves supported deposit currencies and platforms from CoinGate.

## Endpoint

- **Method:** `GET`
- **Path:** `/deposits/supported-currencies`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Supported Deposit Currencies](https://developer.coingate.com/reference/deposit-supported-currencies)
