# Get Send Request with CoinGate

Retrieves a send request from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/send_requests/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Send Request](https://developer.coingate.com/reference/get-send)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate send request ID. |
