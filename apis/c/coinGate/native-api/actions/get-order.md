# Get Order with CoinGate

Retrieves an order from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Order](https://developer.coingate.com/reference/get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | CoinGate order ID. |
