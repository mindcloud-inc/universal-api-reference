# Get Billing Product with CoinGate

Retrieves a billing product from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/products/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Billing Product](https://developer.coingate.com/reference/get-billing-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate billing product ID. |
