# List Billing Contacts with CoinGate

Retrieves billing contacts from your CoinGate account.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/contacts`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Billing Contacts](https://developer.coingate.com/reference/list-billing-contacts)
