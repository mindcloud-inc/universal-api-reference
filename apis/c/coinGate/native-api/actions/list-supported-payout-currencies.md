# List Supported Payout Currencies with CoinGate

Retrieves supported payout currencies and platforms from CoinGate.

## Endpoint

- **Method:** `GET`
- **Path:** `/send_requests/supported-currencies`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Supported Payout Currencies](https://developer.coingate.com/reference/supported-payout-currencies-and-crypto-platforms)
