# List Beneficiaries with CoinGate

Retrieves beneficiaries from your CoinGate account.

## Endpoint

- **Method:** `GET`
- **Path:** `/beneficiaries`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Beneficiaries](https://developer.coingate.com/reference/list-beneficiaries)
