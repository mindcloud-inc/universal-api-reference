# List Refund Supported Currencies with CoinGate

Retrieves supported refund currencies and platforms from CoinGate.

## Endpoint

- **Method:** `GET`
- **Path:** `/refunds/supported-currencies`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Refund Supported Currencies](https://developer.coingate.com/reference/refund-supported-currencies)
