# Get Ledger Transaction with CoinGate

Retrieves a ledger transaction from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/transactions/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Ledger Transaction](https://developer.coingate.com/reference/get-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate ledger transaction ID. |
