# Get Withdrawal with CoinGate

Retrieves a withdrawal from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/withdrawals/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Withdrawal](https://developer.coingate.com/reference/get-withdrawal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | CoinGate withdrawal ID. |
