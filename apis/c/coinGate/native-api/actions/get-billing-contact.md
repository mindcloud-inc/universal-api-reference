# Get Billing Contact with CoinGate

Retrieves a billing contact from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/contacts/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Billing Contact](https://developer.coingate.com/reference/get-billing-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate billing contact ID. |
