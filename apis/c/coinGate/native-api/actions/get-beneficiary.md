# Get Beneficiary with CoinGate

Retrieves a beneficiary from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/beneficiaries/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Beneficiary](https://developer.coingate.com/reference/get-beneficiary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate beneficiary ID. |
