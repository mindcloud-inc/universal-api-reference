# List Ledger Transactions with CoinGate

Retrieves ledger transactions from your CoinGate account.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/transactions`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Ledger Transactions](https://developer.coingate.com/reference/list-transactions)
