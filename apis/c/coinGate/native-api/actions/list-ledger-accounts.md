# List Ledger Accounts with CoinGate

Retrieves ledger accounts from your CoinGate account.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/accounts`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [List Ledger Accounts](https://developer.coingate.com/reference/ledger-accounts)
