# Get Billing Request with CoinGate

Retrieves a billing request from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/billing/requests/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Billing Request](https://developer.coingate.com/reference/get-billing-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate billing request ID. |
