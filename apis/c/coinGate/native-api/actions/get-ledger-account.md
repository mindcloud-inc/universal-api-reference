# Get Ledger Account with CoinGate

Retrieves a ledger account from CoinGate by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/ledger/accounts/:id`
- **Base URL:** `https://api.coingate.com/api/v2`
- **Official documentation:** [Get Ledger Account](https://developer.coingate.com/reference/get-ledger-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CoinGate ledger account ID. |
