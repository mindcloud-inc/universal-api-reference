# Get Contact with Channels

Retrieves a contact from Channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/{contactId}`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Get Contact](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Contact ID. |
