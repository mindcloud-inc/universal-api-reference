# Enable User with Channels

Enables a user in Channels.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/users/{userId}/enable`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Enable User](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | User ID to enable. |
