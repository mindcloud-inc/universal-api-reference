# Import Contact with Channels

Imports a contact into Channels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Import Contact](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `details` | body | `object` | yes | Contact details object matching your Channels contact structure. |
