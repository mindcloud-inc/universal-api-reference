# Check User Exists with Channels

Finds whether a user exists in Channels by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/users/exists`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Check User Exists](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | User email address to check for existence. |
