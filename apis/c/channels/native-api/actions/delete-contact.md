# Delete Contact with Channels

Deletes an existing contact from Channels.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contacts/{contactId}`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Delete Contact](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Contact ID to delete. |
