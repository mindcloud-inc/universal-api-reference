# Get Call with Channels

Retrieves a call from Channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/calls/{id}`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Get Call](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Call ID. |
