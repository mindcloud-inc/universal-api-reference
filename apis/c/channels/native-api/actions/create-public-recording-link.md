# Create Public Recording Link with Channels

Creates a public recording link in Channels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/recordings`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Create Public Recording Link](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callId` | body | `number` | yes | Call ID that belongs to the recording. |
