# Delete Public Recording Link with Channels

Deletes a public recording link from Channels.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/recordings/{token}`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Delete Public Recording Link](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | path | `string` | yes | Public recording link token to delete. |
