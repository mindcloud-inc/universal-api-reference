# Disable User with Channels

Disables a user in Channels.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/users/{userId}/disable`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Disable User](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | User ID to disable. |
