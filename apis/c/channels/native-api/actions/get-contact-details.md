# Get Contact Details with Channels

Retrieves contact details from Channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/{contactId}/details`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Get Contact Details](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Contact ID whose details should be returned. |
