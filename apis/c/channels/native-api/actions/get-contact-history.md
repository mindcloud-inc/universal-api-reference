# Get Contact History with Channels

Retrieves contact history from Channels.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/{contactId}/history`
- **Base URL:** `https://api.channels.app`
- **Official documentation:** [Get Contact History](https://developers.channels.app/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `number` | yes | Contact ID whose history should be returned. |
