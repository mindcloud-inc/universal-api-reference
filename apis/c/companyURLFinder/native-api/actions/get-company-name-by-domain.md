# Get Company Name by Domain with Company URL Finder

Finds a company name in Company URL Finder by domain.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/services/domain_to_name`
- **Base URL:** `https://api.companyurlfinder.com`
- **Official documentation:** [Get Company Name by Domain](https://apidocs.companyurlfinder.com/apis/company-domain-to-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | body | `string` | yes | Company domain. |
