# Company Query to LinkedIn URL with Company URL Finder

Finds a company's LinkedIn URL in Company URL Finder.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/services/name_to_linkedin`
- **Base URL:** `https://api.companyurlfinder.com`
- **Official documentation:** [Company Query to LinkedIn URL](https://apidocs.companyurlfinder.com/apis/linkedin-company-url-finder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Lookup query passed to Company URL Finder. |
