# List Webhook Subscriptions with CallerAPI

Retrieves webhook subscriptions from CallerAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhooks/complaints/subscriptions`
- **Base URL:** `https://api.callerapi.com`
- **Official documentation:** [List Webhook Subscriptions](https://docs.callerapi.com/list-webhook-subscriptions-22518650e0)
