# List Contact Tags with Cakemail

Retrieves all contact tags from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [List Contact Tags](https://cakemail.dev/en/api/tags#list-contact-tags)

## Capabilities

This operation supports [pagination](../README.md#pagination).
