# List Campaigns with Cakemail

Retrieves all email campaigns from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [List Campaigns](https://cakemail.dev/en/api/campaign#show-all-campaigns)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
