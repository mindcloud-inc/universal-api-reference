# List Lists with Cakemail

Retrieves all mailing lists from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [List Lists](https://cakemail.dev/en/api/list#show-all-lists)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
