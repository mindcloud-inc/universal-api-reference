# Get List with Cakemail

Retrieves a list from Cakemail by list ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Get List](https://cakemail.dev/en/api/list#show-a-list-parameters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | Cakemail list ID. |
