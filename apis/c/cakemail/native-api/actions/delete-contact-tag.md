# Delete Contact Tag with Cakemail

Deletes a contact tag from Cakemail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:tag`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Delete Contact Tag](https://cakemail.dev/en/api/tags#delete-a-contact-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | Contact tag name to delete. |
