# Validate Domains with Cakemail

Validates the default sending domains in Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/default/domains/default/validate`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Validate Domains](https://cakemail.dev/en/api/domain#validate-domains)
