# List Senders with Cakemail

Retrieves all sender identities from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/default/senders`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [List Senders](https://cakemail.dev/en/api/sender#show-all-senders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
