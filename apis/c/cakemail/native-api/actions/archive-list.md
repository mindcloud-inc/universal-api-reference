# Archive List with Cakemail

Archives an existing list in Cakemail.

## Endpoint

- **Method:** `POST`
- **Path:** `/lists/:listId/archive`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Archive List](https://cakemail.dev/en/api/list#archive-a-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | Cakemail list ID to archive. |
