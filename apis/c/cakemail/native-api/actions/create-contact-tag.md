# Create Contact Tag with Cakemail

Creates a new contact tag in Cakemail.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Create Contact Tag](https://cakemail.dev/en/api/tags#create-a-contact-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | body | `string` | yes | Contact tag name to create. |
