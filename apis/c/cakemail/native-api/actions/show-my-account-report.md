# Show My Account Report with Cakemail

Retrieves the current account report from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/accounts/self`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Show My Account Report](https://cakemail.dev/en/api/report#show-my-account-report)
