# Show Contact Tag with Cakemail

Retrieves a contact tag from Cakemail.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag`
- **Base URL:** `https://api.cakemail.dev`
- **Official documentation:** [Show Contact Tag](https://cakemail.dev/en/api/tags#show-a-contact-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | Contact tag name. |
