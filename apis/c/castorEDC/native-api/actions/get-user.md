# Get User with Castor EDC

Retrieves a user from Castor EDC by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id`
- **Base URL:** `https://us.castoredc.com/api`
- **Official documentation:** [Get User](https://us.castoredc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The ID of the user to retrieve |
