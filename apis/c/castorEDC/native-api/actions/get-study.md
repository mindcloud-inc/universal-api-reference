# Get Study with Castor EDC

Retrieves a study from Castor EDC by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/study/:study_id`
- **Base URL:** `https://us.castoredc.com/api`
- **Official documentation:** [Get Study](https://us.castoredc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `study_id` | path | `string` | yes | The ID of the study for which this call should be made |
