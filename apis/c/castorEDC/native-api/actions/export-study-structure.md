# Export Study Structure with Castor EDC

Exports study structure from Castor EDC as a dataset.

## Endpoint

- **Method:** `GET`
- **Path:** `/study/:study_id/export/structure`
- **Base URL:** `https://us.castoredc.com/api`
- **Official documentation:** [Export Study Structure](https://us.castoredc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `study_id` | path | `string` | yes | The ID of the study for which this call should be made |
