# Get Study Statistics with Castor EDC

Retrieves study statistics from Castor EDC by study ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/study/:study_id/statistics`
- **Base URL:** `https://us.castoredc.com/api`
- **Official documentation:** [Get Study Statistics](https://us.castoredc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `study_id` | path | `string` | yes | The ID of the study for which this call should be made |
