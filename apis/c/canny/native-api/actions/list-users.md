# List Users with Canny

Retrieves all available users from Canny.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/users/list`
- **Base URL:** `https://canny.io/api`
- **Official documentation:** [List Users](https://developers.canny.io/api-reference#list_users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | body | `number` | no |
| `cursor` | body | `string` | no |
