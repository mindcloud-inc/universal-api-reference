# List Categories with Canny

Retrieves all available categories from Canny.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/categories/list`
- **Base URL:** `https://canny.io/api`
- **Official documentation:** [List Categories](https://developers.canny.io/api-reference#list_categories)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardID` | body | `string` | no |
| `limit` | body | `number` | no |
| `skip` | body | `number` | no |
