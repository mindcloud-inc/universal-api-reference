# Retrieve Board with Canny

Retrieves a single board from Canny.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/boards/retrieve`
- **Base URL:** `https://canny.io/api`
- **Official documentation:** [Retrieve Board](https://developers.canny.io/api-reference#retrieve_board)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | yes |
