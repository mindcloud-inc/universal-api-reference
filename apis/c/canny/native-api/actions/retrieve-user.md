# Retrieve User with Canny

Retrieves a single user from Canny.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/retrieve`
- **Base URL:** `https://canny.io/api`
- **Official documentation:** [Retrieve User](https://developers.canny.io/api-reference#retrieve_user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | body | `string` | no |
| `id` | body | `string` | no |
| `userID` | body | `string` | no |
