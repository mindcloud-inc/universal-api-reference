# Retrieve Post with Canny

Retrieves a single post from Canny.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/posts/retrieve`
- **Base URL:** `https://canny.io/api`
- **Official documentation:** [Retrieve Post](https://developers.canny.io/api-reference#retrieve_post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `urlName` | body | `string` | no |
| `boardID` | body | `string` | no |
