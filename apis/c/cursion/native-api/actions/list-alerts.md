# List Alerts with Cursion

Retrieves a list of alerts from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/alert`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Alerts](https://docs.cursion.dev/api/alert)

## Capabilities

This operation supports [pagination](../README.md#pagination).
