# Create Scan with Cursion

Creates a new scan in Cursion.

## Endpoint

- **Method:** `POST`
- **Path:** `/scan`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Create Scan](https://docs.cursion.dev/api/scan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | body | `string` | yes | The page identifier to scan. |
