# Get Schedule with Cursion

Retrieves an existing schedule from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedule/{{scheduleId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Get Schedule](https://docs.cursion.dev/api/schedule)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scheduleId` | path | `string` | yes | The schedule identifier. |
