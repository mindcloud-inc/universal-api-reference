# Create Report with Cursion

## Endpoint

- **Method:** `POST`
- **Path:** `/report`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Create Report](https://docs.cursion.dev/api/report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | body | `string` | yes | The page identifier to report on. |
