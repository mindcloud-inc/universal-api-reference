# Create Site with Cursion

Creates a new site in Cursion.

## Endpoint

- **Method:** `POST`
- **Path:** `/site`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Create Site](https://docs.cursion.dev/api/site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_url` | body | `string` | yes | The site URL to monitor. |
