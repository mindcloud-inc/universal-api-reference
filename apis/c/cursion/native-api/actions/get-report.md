# Get Report with Cursion

Retrieves an existing report from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/report/{{reportId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Get Report](https://docs.cursion.dev/api/report)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportId` | path | `string` | yes | The report identifier. |
