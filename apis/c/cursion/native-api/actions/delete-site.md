# Delete Site with Cursion

Deletes an existing site from Cursion.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/site/{{siteId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Delete Site](https://docs.cursion.dev/api/site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | The site identifier. |
