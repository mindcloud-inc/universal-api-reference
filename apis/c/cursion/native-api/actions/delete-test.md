# Delete Test with Cursion

Deletes an existing test from Cursion.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/test/{{testId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Delete Test](https://docs.cursion.dev/api/test)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `testId` | path | `string` | yes | The test identifier. |
