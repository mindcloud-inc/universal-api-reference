# List Schedules with Cursion

Retrieves a list of schedules from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/schedule`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Schedules](https://docs.cursion.dev/api/schedule)

## Capabilities

This operation supports [pagination](../README.md#pagination).
