# Get Issue with Cursion

Retrieves an existing issue from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue/{{issueId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Get Issue](https://docs.cursion.dev/api/issue)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueId` | path | `string` | yes | The issue identifier. |
