# Get Scan with Cursion

Retrieves an existing scan from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/scan/{{scanId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Get Scan](https://docs.cursion.dev/api/scan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scanId` | path | `string` | yes | The scan identifier. |
