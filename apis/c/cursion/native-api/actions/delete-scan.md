# Delete Scan with Cursion

Deletes an existing scan from Cursion.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/scan/{{scanId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Delete Scan](https://docs.cursion.dev/api/scan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scanId` | path | `string` | yes | The scan identifier. |
