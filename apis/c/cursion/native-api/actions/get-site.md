# Get Site with Cursion

Retrieves an existing site from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/site/{{siteId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Get Site](https://docs.cursion.dev/api/site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | The site identifier. |
