# List Issues with Cursion

Retrieves a list of issues from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/issue`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Issues](https://docs.cursion.dev/api/issue)

## Capabilities

This operation supports [pagination](../README.md#pagination).
