# Delete Issue with Cursion

Deletes an existing issue from Cursion.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/issue/{{issueId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Delete Issue](https://docs.cursion.dev/api/issue)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueId` | path | `string` | yes | The issue identifier. |
