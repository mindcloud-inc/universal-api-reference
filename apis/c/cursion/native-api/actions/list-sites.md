# List Sites with Cursion

Retrieves a list of sites from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/site`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Sites](https://docs.cursion.dev/api/site)

## Capabilities

This operation supports [pagination](../README.md#pagination).
