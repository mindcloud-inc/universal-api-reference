# List Reports with Cursion

Retrieves a list of reports from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/report`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Reports](https://docs.cursion.dev/api/report)

## Capabilities

This operation supports [pagination](../README.md#pagination).
