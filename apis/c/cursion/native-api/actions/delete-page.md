# Delete Page with Cursion

Deletes an existing page from Cursion.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/page/{{pageId}}`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Delete Page](https://docs.cursion.dev/api/page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | The page identifier. |
