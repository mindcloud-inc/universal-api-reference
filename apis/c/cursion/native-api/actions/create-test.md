# Create Test with Cursion

Creates a new test in Cursion.

## Endpoint

- **Method:** `POST`
- **Path:** `/test`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [Create Test](https://docs.cursion.dev/api/test)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | body | `string` | yes | The page identifier to test. |
