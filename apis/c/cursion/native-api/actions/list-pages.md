# List Pages with Cursion

Retrieves a list of pages from Cursion.

## Endpoint

- **Method:** `GET`
- **Path:** `/page`
- **Base URL:** `https://api.cursion.dev/v1/ops`
- **Official documentation:** [List Pages](https://docs.cursion.dev/api/page)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | query | `string` | yes | The site ID to list pages for. |
