# Create Folder with Cloudinary

Creates a folder in your Cloudinary account.

## Endpoint

- **Method:** `POST`
- **Path:** `/folders/:folder`
- **Base URL:** `https://api.cloudinary.com/v1_1/{cloudName}`
- **Official documentation:** [Create Folder](https://cloudinary.com/documentation/admin_api#folders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder` | path | `string` | yes | The folder path to create. |
