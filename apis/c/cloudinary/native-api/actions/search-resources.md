# Search Resources with Cloudinary

Finds resources in Cloudinary by search expression.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/search`
- **Base URL:** `https://api.cloudinary.com/v1_1/{cloudName}`
- **Official documentation:** [Search Resources](https://cloudinary.com/documentation/admin_api#search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expression` | query | `string` | yes | The search expression to run. |
