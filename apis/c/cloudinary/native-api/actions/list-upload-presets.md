# List Upload Presets with Cloudinary

Retrieves upload presets from your Cloudinary account.

## Endpoint

- **Method:** `GET`
- **Path:** `/upload_presets`
- **Base URL:** `https://api.cloudinary.com/v1_1/{cloudName}`
- **Official documentation:** [List Upload Presets](https://cloudinary.com/documentation/admin_api#upload_presets)
