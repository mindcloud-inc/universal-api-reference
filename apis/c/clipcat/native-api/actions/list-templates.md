# List Templates with Clipcat

Retrieves available video templates from Clipcat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates`
- **Base URL:** `https://api.clipcat.com`
- **Official documentation:** [List Templates](https://developers.clipcat.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | The page number of template results to retrieve. |
