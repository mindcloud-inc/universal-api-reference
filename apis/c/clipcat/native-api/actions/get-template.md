# Get Template with Clipcat

Retrieves a video template from Clipcat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:uid`
- **Base URL:** `https://api.clipcat.com`
- **Official documentation:** [Get Template](https://developers.clipcat.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The template UID to retrieve. |
