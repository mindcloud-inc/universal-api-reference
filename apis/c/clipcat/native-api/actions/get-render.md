# Get Render with Clipcat

Retrieves a video render from Clipcat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/renders/:uid`
- **Base URL:** `https://api.clipcat.com`
- **Official documentation:** [Get Render](https://developers.clipcat.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uid` | path | `string` | yes | The render UID to retrieve. |
