# List Page Templates with Content Snare

Retrieves page templates from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/page_templates`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Page Templates](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
