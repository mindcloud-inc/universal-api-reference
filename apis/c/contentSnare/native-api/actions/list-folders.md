# List Folders with Content Snare

Retrieves folders from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/folders`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Folders](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
