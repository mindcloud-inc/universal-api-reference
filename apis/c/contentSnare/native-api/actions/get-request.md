# Get Request with Content Snare

Retrieves a request from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/requests/{id}`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Get Request](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Request ID. |
