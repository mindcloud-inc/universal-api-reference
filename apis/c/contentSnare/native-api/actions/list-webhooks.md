# List Webhooks with Content Snare

Retrieves webhooks from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/webhooks`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Webhooks](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
