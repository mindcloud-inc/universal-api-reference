# Run Integration Actions with Content Snare

Runs integration actions for a request in Content Snare.

## Endpoint

- **Method:** `PUT`
- **Path:** `/partner_api/v1/requests/{id}/run_integration_actions`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Run Integration Actions](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Request ID. |
