# Delete Webhook with Content Snare

Deletes a webhook from Content Snare.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/partner_api/v1/webhooks/{id}`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Delete Webhook](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID. |
