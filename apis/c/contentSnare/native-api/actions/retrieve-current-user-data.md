# Retrieve Current User Data with Content Snare

Retrieves current user data from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/me`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Retrieve Current User Data](https://api.contentsnare.com/partner_api/v1/documentation)
