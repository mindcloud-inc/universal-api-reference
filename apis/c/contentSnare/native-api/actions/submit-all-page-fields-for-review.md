# Submit All Page Fields For Review with Content Snare

Submits all page fields for review in Content Snare.

## Endpoint

- **Method:** `PUT`
- **Path:** `/partner_api/v1/pages/{id}/submit_all_fields`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Submit All Page Fields For Review](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Page ID. |
