# List Communications Schedules with Content Snare

Retrieves communications schedules from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/communication_templates`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Communications Schedules](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
