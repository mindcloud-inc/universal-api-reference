# Delete Client with Content Snare

Deletes a client from Content Snare.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/partner_api/v1/clients/{id}`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Delete Client](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client ID. |
