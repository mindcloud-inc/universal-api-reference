# Approve All Submitted Section Fields with Content Snare

Approves all submitted fields for a section in Content Snare.

## Endpoint

- **Method:** `PUT`
- **Path:** `/partner_api/v1/sections/{id}/approve_all_submitted_fields`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Approve All Submitted Section Fields](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Section ID. |
