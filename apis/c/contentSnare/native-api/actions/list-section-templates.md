# List Section Templates with Content Snare

Retrieves section templates from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/section_templates`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Section Templates](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
