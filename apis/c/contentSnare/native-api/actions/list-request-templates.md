# List Request Templates with Content Snare

Retrieves request templates from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/request_templates`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [List Request Templates](https://api.contentsnare.com/partner_api/v1/documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
