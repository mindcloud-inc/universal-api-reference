# Approve All Submitted Fields with Content Snare

Approves all submitted fields for a request in Content Snare.

## Endpoint

- **Method:** `PUT`
- **Path:** `/partner_api/v1/requests/{id}/approve_all_submitted_fields`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Approve All Submitted Fields](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Request ID. |
