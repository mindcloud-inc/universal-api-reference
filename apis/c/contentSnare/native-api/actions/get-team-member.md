# Get Team Member with Content Snare

Retrieves a team member from Content Snare.

## Endpoint

- **Method:** `GET`
- **Path:** `/partner_api/v1/team_members/{id}`
- **Base URL:** `https://api.contentsnare.com`
- **Official documentation:** [Get Team Member](https://api.contentsnare.com/partner_api/v1/documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Team Member ID. |
