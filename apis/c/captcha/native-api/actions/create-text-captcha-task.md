# Create Text Captcha Task with 2Captcha

Creates a text captcha task in 2Captcha.

## Endpoint

- **Method:** `POST`
- **Path:** `/createTask`
- **Base URL:** `https://api.2captcha.com`
- **Official documentation:** [Create Text Captcha Task](https://2captcha.com/api-docs/text)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task.comment` | body | `string` | yes |
