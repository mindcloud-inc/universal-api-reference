# Create Prosopo Procaptcha Task Proxyless with 2Captcha

Creates a proxyless Prosopo Procaptcha task in 2Captcha.

## Endpoint

- **Method:** `POST`
- **Path:** `/createTask`
- **Base URL:** `https://api.2captcha.com`
- **Official documentation:** [Create Prosopo Procaptcha Task Proxyless](https://2captcha.com/api-docs/prosopo-procaptcha)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task.websiteURL` | body | `string` | yes |
| `task.websiteKey` | body | `string` | yes |
