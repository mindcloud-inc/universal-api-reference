# Search Jobs with CATS

Finds jobs in CATS by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/search`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Search Jobs](https://docs.catsone.com/api/v3/#jobs-search-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The string to search within jobs for. |
