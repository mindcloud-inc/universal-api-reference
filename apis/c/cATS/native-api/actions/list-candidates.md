# List Candidates with CATS

Retrieves candidates from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Candidates](https://docs.catsone.com/api/v3/#candidates-list-all-candidates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
