# List Job Statuses with CATS

Retrieves available job statuses from CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/statuses`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Job Statuses](https://docs.catsone.com/api/v3/#jobs-list-job-statuses)

## Capabilities

This operation supports [pagination](../README.md#pagination).
