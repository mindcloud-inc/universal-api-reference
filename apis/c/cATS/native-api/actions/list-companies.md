# List Companies with CATS

Retrieves companies from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Companies](https://docs.catsone.com/api/v3/#companies-list-all-companies)

## Capabilities

This operation supports [pagination](../README.md#pagination).
