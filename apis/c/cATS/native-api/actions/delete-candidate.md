# Delete Candidate with CATS

Deletes an existing candidate from CATS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/candidates/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Delete Candidate](https://docs.catsone.com/api/v3/#candidates-delete-a-candidate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the candidate to delete. |
