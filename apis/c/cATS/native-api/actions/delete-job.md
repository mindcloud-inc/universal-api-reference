# Delete Job with CATS

Deletes an existing job from CATS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Delete Job](https://docs.catsone.com/api/v3/#jobs-delete-a-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the job to delete. |
