# Get Contact with CATS

Retrieves details for a contact in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Contact](https://docs.catsone.com/api/v3/#contacts-get-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the contact to return. |
