# Get Job with CATS

Retrieves details for a job in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Job](https://docs.catsone.com/api/v3/#jobs-get-a-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the job to return. |
