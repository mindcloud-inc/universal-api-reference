# Delete Contact with CATS

Deletes an existing contact from CATS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Delete Contact](https://docs.catsone.com/api/v3/#contacts-delete-a-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the contact to delete. |
