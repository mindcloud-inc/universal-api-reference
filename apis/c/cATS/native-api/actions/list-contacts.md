# List Contacts with CATS

Retrieves contacts from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Contacts](https://docs.catsone.com/api/v3/#contacts-list-all-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
