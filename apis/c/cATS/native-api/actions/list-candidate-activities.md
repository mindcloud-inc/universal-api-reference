# List Candidate Activities with CATS

Retrieves activities for a candidate in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/:id/activities`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Candidate Activities](https://docs.catsone.com/api/v3/#candidates-list-candidate-activities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the candidate to return activities for. |
