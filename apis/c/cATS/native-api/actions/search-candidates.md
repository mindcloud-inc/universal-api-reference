# Search Candidates with CATS

Finds candidates in CATS by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/search`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Search Candidates](https://docs.catsone.com/api/v3/#candidates-search-candidates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The string to search within candidates for. |
