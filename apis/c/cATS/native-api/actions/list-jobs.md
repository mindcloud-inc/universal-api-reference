# List Jobs with CATS

Retrieves jobs from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Jobs](https://docs.catsone.com/api/v3/#jobs-list-all-jobs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
