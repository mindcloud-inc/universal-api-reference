# Get Job Application with CATS

Retrieves a job application from CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/applications/:application_id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Job Application](https://docs.catsone.com/api/v3/#jobs-get-a-job-application)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `application_id` | path | `number` | yes | The ID of the job application to return. |
