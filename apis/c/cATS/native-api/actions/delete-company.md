# Delete Company with CATS

Deletes an existing company from CATS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Delete Company](https://docs.catsone.com/api/v3/#companies-delete-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the company to delete. |
