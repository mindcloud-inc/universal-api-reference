# Get Company with CATS

Retrieves details for a company in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Company](https://docs.catsone.com/api/v3/#companies-get-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the company to return. |
