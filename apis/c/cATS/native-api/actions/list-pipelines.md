# List Pipelines with CATS

Retrieves pipelines from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Pipelines](https://docs.catsone.com/api/v3/#pipelines-list-all-pipelines)

## Capabilities

This operation supports [pagination](../README.md#pagination).
