# Get Candidate with CATS

Retrieves details for a candidate in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/candidates/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Candidate](https://docs.catsone.com/api/v3/#candidates-get-a-candidate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the candidate to return. |
