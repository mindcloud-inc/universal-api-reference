# List Users with CATS

Retrieves users from the CATS account.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [List Users](https://docs.catsone.com/api/v3/#users-list-all-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
