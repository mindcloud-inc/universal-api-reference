# Get Pipeline with CATS

Retrieves details for a pipeline in CATS.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/:id`
- **Base URL:** `https://api.catsone.com/v3`
- **Official documentation:** [Get Pipeline](https://docs.catsone.com/api/v3/#pipelines-get-a-pipeline)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the pipeline to return. |
