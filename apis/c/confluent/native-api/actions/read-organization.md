# Read Organization with Confluent

Retrieves an organization from your Confluent Cloud account.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/v2/organizations/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Read Organization](https://docs.confluent.io/cloud/current/api.html#tag/Organizations-(orgv2)/operation/getOrgV2Organization)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
