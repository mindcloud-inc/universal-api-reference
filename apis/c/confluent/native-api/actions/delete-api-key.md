# Delete API Key with Confluent

Deletes an existing API key from Confluent Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/iam/v2/api-keys/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Delete API Key](https://docs.confluent.io/cloud/current/api.html#tag/API-Keys-(iamv2)/operation/deleteIamV2ApiKey)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
