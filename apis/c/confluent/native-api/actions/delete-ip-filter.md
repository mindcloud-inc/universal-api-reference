# Delete IP Filter with Confluent

Deletes an existing IP filter from Confluent Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/iam/v2/ip-filters/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Delete IP Filter](https://docs.confluent.io/cloud/current/api.html#tag/IP-Filters-(iamv2)/operation/deleteIamV2IpFilter)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
