# List Users with Confluent

Retrieves users from your Confluent Cloud organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2/users`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [List Users](https://docs.confluent.io/cloud/current/api.html#tag/Users-(iamv2)/operation/listIamV2Users)
