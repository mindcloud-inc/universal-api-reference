# Read Environment with Confluent

Retrieves an environment from Confluent Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/v2/environments/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Read Environment](https://docs.confluent.io/cloud/current/api.html#tag/Environments-(orgv2)/operation/getOrgV2Environment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
