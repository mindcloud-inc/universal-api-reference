# Delete Environment with Confluent

Deletes an existing environment from Confluent Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/org/v2/environments/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Delete Environment](https://docs.confluent.io/cloud/current/api.html#tag/Environments-(orgv2)/operation/deleteOrgV2Environment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
