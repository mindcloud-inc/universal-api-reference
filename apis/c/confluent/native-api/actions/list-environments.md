# List Environments with Confluent

Retrieves environments from your Confluent Cloud organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/v2/environments`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [List Environments](https://docs.confluent.io/cloud/current/api.html#tag/Environments-(orgv2)/operation/listOrgV2Environments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
