# Read IP Group with Confluent

Retrieves an IP group from Confluent Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2/ip-groups/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Read IP Group](https://docs.confluent.io/cloud/current/api.html#tag/IP-Groups-(iamv2)/operation/getIamV2IpGroup)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
