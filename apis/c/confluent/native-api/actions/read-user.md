# Read User with Confluent

Retrieves a user from Confluent Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2/users/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Read User](https://docs.confluent.io/cloud/current/api.html#tag/Users-(iamv2)/operation/getIamV2User)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
