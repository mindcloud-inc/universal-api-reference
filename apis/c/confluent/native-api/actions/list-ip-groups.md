# List IP Groups with Confluent

Retrieves IP groups from Confluent Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2/ip-groups`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [List IP Groups](https://docs.confluent.io/cloud/current/api.html#tag/IP-Groups-(iamv2)/operation/listIamV2IpGroups)
