# List Organizations with Confluent

Retrieves organizations from your Confluent Cloud account.

## Endpoint

- **Method:** `GET`
- **Path:** `/org/v2/organizations`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [List Organizations](https://docs.confluent.io/cloud/current/api.html#tag/Organizations-(orgv2)/operation/listOrgV2Organizations)
