# Read IP Filter with Confluent

Retrieves an IP filter from Confluent Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/iam/v2/ip-filters/:id`
- **Base URL:** `https://api.confluent.cloud`
- **Official documentation:** [Read IP Filter](https://docs.confluent.io/cloud/current/api.html#tag/IP-Filters-(iamv2)/operation/getIamV2IpFilter)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
