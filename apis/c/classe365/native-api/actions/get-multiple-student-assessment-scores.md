# Get Multiple Student Assessment Scores with Classe365

Retrieves assessment scores for multiple students from Classe365.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/studentsScore`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [Get Multiple Student Assessment Scores](https://speca.io/classe365/academics#get-assessments-score-for-students)
