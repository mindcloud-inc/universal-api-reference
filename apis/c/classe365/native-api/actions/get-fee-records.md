# Get Fee Records with Classe365

Retrieves fee, invoice, or payment records from Classe365.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/feesInfo`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [Get Fee Records](https://speca.io/classe365/academics#get-fees-data-for-all-fess-particular-fees-particular-invoice-and-particular-payment)
