# List Tasks with Classe365

Retrieves a list of tasks from Classe365.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/tasksData`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [List Tasks](https://speca.io/classe365/academics#get-tasks-data)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | no | JSON string filter for tasks. |
