# Upsert Form Submission with Classe365

Creates or updates a form submission in Classe365.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/formSubmit`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [Upsert Form Submission](https://speca.io/classe365/academics#add-or-update-form-submission)
