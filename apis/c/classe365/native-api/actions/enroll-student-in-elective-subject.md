# Enroll Student in Elective Subject with Classe365

Enrolls a student in an elective subject in Classe365.

## Endpoint

- **Method:** `POST`
- **Path:** `/rest/electiveSubjectsAllocation`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [Enroll Student in Elective Subject](https://speca.io/classe365/academics#manage-elective-subject-allocation)
