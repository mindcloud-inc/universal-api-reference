# List Ledger Accounts with Classe365

Retrieves a list of ledger accounts from Classe365.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/ledgerAccounts`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [List Ledger Accounts](https://speca.io/classe365/academics#ledger-accounts)
