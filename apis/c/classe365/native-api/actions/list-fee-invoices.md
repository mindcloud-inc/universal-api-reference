# List Fee Invoices with Classe365

Retrieves a list of fee invoices from Classe365.

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/feeInvoicesData`
- **Base URL:** `https://{username}.classe365.com`
- **Official documentation:** [List Fee Invoices](https://speca.io/classe365/academics#get-invoice-data)
