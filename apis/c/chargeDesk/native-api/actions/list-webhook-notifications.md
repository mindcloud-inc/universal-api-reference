# List Webhook Notifications with ChargeDesk

Retrieves webhook notifications from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/notifications`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Webhook Notifications](https://chargedesk.com/api-docs#webhooks-notifications)
