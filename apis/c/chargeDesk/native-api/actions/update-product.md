# Update Product with ChargeDesk

Updates an existing product in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/:PRODUCT_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Update Product](https://chargedesk.com/api-docs#products-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PRODUCT_ID` | path | `string` | yes | Product ID to update. |
