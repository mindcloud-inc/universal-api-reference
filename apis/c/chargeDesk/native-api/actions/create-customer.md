# Create Customer with ChargeDesk

Creates a new customer in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Create Customer](https://chargedesk.com/api-docs#customers-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | body | `string` | yes | Unique customer identifier. |
