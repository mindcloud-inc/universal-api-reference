# List Subscription Cancellations with ChargeDesk

Retrieves subscription cancellations from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/log/cancellations`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Subscription Cancellations](https://chargedesk.com/api-docs#logs-subscription-cancellations)

## Capabilities

This operation supports [pagination](../README.md#pagination).
