# Retrieve Charge with ChargeDesk

Retrieves a charge from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges/:CHARGE_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Retrieve Charge](https://chargedesk.com/api-docs#charges-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CHARGE_ID` | path | `string` | yes | Charge ID to retrieve. |
