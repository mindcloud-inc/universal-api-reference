# Update Subscription with ChargeDesk

Updates an existing subscription in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/subscriptions/:SUBSCRIPTION_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Update Subscription](https://chargedesk.com/api-docs#subscriptions-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SUBSCRIPTION_ID` | path | `string` | yes | Subscription ID to update. |
