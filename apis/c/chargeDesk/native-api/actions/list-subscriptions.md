# List Subscriptions with ChargeDesk

Retrieves subscriptions from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Subscriptions](https://chargedesk.com/api-docs#subscriptions-list-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
