# Retrieve Subscription with ChargeDesk

Retrieves a subscription from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:SUBSCRIPTION_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Retrieve Subscription](https://chargedesk.com/api-docs#subscriptions-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `SUBSCRIPTION_ID` | path | `string` | yes | Subscription ID to retrieve. |
