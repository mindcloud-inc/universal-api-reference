# List Products with ChargeDesk

Retrieves products from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Products](https://chargedesk.com/api-docs#products-list-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
