# Retrieve Product with ChargeDesk

Retrieves a product from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:PRODUCT_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Retrieve Product](https://chargedesk.com/api-docs#products-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `PRODUCT_ID` | path | `string` | yes | Product ID to retrieve. |
