# List Agent Activity with ChargeDesk

Retrieves agent activity logs from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/log/activity`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Agent Activity](https://chargedesk.com/api-docs#logs-agent-activity)

## Capabilities

This operation supports [pagination](../README.md#pagination).
