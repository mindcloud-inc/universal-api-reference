# Update Charge with ChargeDesk

Updates an existing charge in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/charges/:CHARGE_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Update Charge](https://chargedesk.com/api-docs#charges-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CHARGE_ID` | path | `string` | yes | Charge ID to update. |
