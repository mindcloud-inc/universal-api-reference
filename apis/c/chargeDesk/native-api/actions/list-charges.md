# List Charges with ChargeDesk

Retrieves charges from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/charges`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Charges](https://chargedesk.com/api-docs#charges-list-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
