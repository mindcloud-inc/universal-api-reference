# Update Customer with ChargeDesk

Updates an existing customer in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/customers/:CUSTOMER_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Update Customer](https://chargedesk.com/api-docs#customers-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CUSTOMER_ID` | path | `string` | yes | Customer ID to update. |
