# Retrieve Customer with ChargeDesk

Retrieves a customer from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:CUSTOMER_ID`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Retrieve Customer](https://chargedesk.com/api-docs#customers-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CUSTOMER_ID` | path | `string` | yes | Customer ID to retrieve. |
