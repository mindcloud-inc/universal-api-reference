# List Customers with ChargeDesk

Retrieves customers from ChargeDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [List Customers](https://chargedesk.com/api-docs#customers-list-all)

## Capabilities

This operation supports [pagination](../README.md#pagination).
