# Create Product with ChargeDesk

Creates a new product in ChargeDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/products`
- **Base URL:** `https://api.chargedesk.com/v1`
- **Official documentation:** [Create Product](https://chargedesk.com/api-docs#products-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product_id` | body | `string` | yes | Unique product identifier. |
