# Retrieve Contact with ContactDrive

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.contactdrive.app/api/v1`
- **Official documentation:** [Retrieve Contact](https://help.contactdrive.io/article/16-api-v1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The unique ID for the contact you would like to retrieve |
