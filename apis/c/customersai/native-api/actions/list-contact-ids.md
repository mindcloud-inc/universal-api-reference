# List Contact IDs with Customers.ai

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/ids`
- **Base URL:** `https://api.mobilemonkey.com/public`
- **Official documentation:** [List Contact IDs](https://customers.ai/help/l/en/category/doq3ewxla3-public-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Filter contacts by email address. |
| `first_name` | query | `string` | no | Filter contacts by first name. |
| `last_name` | query | `string` | no | Filter contacts by last name. |
