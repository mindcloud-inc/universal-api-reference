# Get Discount with Cartloom

Retrieves a discount record from Cartloom by ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/discounts/get/format/json`
- **Base URL:** `https://mindcloudstage0424.cartloom.com/api`
- **Official documentation:** [Get Discount](https://support.cartloom.com/hc/en-us/articles/115000936228-Get-Discount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Internal discount ID. |
