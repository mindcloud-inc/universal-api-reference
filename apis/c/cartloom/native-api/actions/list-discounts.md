# List Discounts with Cartloom

Retrieves multiple discount records from Cartloom.

## Endpoint

- **Method:** `POST`
- **Path:** `/discounts/list/format/json`
- **Base URL:** `https://mindcloudstage0424.cartloom.com/api`
- **Official documentation:** [List Discounts](https://support.cartloom.com/hc/en-us/articles/115000936208-List-Discounts)
