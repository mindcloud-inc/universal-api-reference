# Delete Custom Source with Chat Aid

Deletes an existing custom source from Chat Aid.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/external/sources/custom/:id`
- **Base URL:** `https://api.chataid.com`
- **Official documentation:** [Delete Custom Source](https://docs.chataid.com/api-guide/custom-sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Custom source ID to delete. |
