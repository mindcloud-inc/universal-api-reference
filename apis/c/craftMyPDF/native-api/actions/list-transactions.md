# List transactions with CraftMyPDF

Retrieves transactions from your CraftMyPDF account.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-transactions`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [List transactions](https://craftmypdf.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).
