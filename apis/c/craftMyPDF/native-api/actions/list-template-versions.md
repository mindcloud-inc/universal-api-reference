# List template versions with CraftMyPDF

Retrieves template versions from your CraftMyPDF account.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-template-versions`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [List template versions](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | query | `string` | no |
