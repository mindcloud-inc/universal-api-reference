# Get template with CraftMyPDF

Retrieves a template record from CraftMyPDF.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-template`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [Get template](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | query | `string` | no |
| `version` | query | `string` | no |
