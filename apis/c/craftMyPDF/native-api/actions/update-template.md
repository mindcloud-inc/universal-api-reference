# Update template with CraftMyPDF

Updates an existing template in CraftMyPDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/update-template`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [Update template](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | body | `string` | yes |
| `name` | body | `string` | no |
| `json` | body | `string` | no |
| `body` | body | `string` | no |
