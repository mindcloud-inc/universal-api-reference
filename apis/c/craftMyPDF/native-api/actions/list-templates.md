# List templates with CraftMyPDF

Retrieves templates from your CraftMyPDF account.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-templates`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [List templates](https://craftmypdf.com/docs/index.html)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_name` | query | `string` | no |
