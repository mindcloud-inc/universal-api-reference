# Delete template with CraftMyPDF

Deletes a template record from CraftMyPDF.

## Endpoint

- **Method:** `GET`
- **Path:** `/delete-template`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [Delete template](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `template_id` | query | `string` | yes |
