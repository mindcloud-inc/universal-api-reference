# Deactivate editor session with CraftMyPDF

Deactivates an editor session in CraftMyPDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/deactivate-editor-session`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [Deactivate editor session](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token_uuid` | body | `string` | yes |
