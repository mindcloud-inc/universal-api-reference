# Get PDF Information with CraftMyPDF

Retrieves PDF file information from CraftMyPDF.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-pdf-info`
- **Base URL:** `https://api.craftmypdf.com/v1`
- **Official documentation:** [Get PDF Information](https://craftmypdf.com/docs/index.html)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `url` | query | `string` | yes |
