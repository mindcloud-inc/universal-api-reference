# List Tags with CallRail

Retrieves tags from CallRail.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/a/:account_id/tags.json`
- **Base URL:** `https://api.callrail.com`
- **Official documentation:** [List Tags](https://apidocs.callrail.com/#retrieving-all-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | yes | The CallRail account ID. |
