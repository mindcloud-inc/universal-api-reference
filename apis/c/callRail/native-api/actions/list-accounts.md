# List Accounts with CallRail

Retrieves accounts from CallRail.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/a.json`
- **Base URL:** `https://api.callrail.com`
- **Official documentation:** [List Accounts](https://apidocs.callrail.com/#listing-all-accounts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Comma-separated additional account fields to include in the response. |
