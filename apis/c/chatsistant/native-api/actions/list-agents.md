# List Agents with Chatsistant

Retrieves chatbot agent records from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid/agents`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [List Agents](https://docs.chatsistant.com/api-reference/agents/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
