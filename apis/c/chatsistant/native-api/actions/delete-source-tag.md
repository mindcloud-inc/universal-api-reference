# Delete Source Tag with Chatsistant

Deletes an existing source tag from Chatsistant.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/source-tag/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Source Tag](https://docs.chatsistant.com/api-reference/source-tags/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The tag UUID. |
