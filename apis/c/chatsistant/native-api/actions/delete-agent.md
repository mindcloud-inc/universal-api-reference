# Delete Agent with Chatsistant

Deletes an existing chatbot agent from Chatsistant.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agent/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Agent](https://docs.chatsistant.com/api-reference/agents/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The agent UUID. |
