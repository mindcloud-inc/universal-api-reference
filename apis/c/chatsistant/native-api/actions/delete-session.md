# Delete Session with Chatsistant

Deletes an existing chatbot session from Chatsistant.

## Endpoint

- **Method:** `POST`
- **Path:** `/session/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Session](https://docs.chatsistant.com/api-reference/sessions/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The session UUID. |
