# Delete Chatbot with Chatsistant

Deletes an existing chatbot from Chatsistant.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/chatbot/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Chatbot](https://docs.chatsistant.com/api-reference/chatbots/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
