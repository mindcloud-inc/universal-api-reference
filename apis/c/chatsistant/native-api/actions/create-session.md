# Create Session with Chatsistant

Creates a new chatbot session in Chatsistant.

## Endpoint

- **Method:** `POST`
- **Path:** `/chatbot/:uuid/session/create`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Create Session](https://docs.chatsistant.com/api-reference/sessions/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
