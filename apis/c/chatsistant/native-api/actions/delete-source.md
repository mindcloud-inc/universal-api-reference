# Delete Source with Chatsistant

Deletes an existing source from Chatsistant.

## Endpoint

- **Method:** `POST`
- **Path:** `/data-source/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Source](https://docs.chatsistant.com/api-reference/data-sources/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The source UUID. |
