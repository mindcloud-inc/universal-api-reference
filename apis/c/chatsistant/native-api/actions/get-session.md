# Get Session with Chatsistant

Retrieves chatbot session details from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/session/:uuid`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Get Session](https://docs.chatsistant.com/api-reference/sessions/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The session UUID. |
