# List Chatbots with Chatsistant

Retrieves chatbot records from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbots`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [List Chatbots](https://docs.chatsistant.com/api-reference/chatbots/fetch_multi)
