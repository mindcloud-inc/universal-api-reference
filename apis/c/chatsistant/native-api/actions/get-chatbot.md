# Get Chatbot with Chatsistant

Retrieves chatbot details from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Get Chatbot](https://docs.chatsistant.com/api-reference/chatbots/fetch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
