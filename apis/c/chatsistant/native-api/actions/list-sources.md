# List Sources with Chatsistant

Retrieves data source records from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid/data-sources`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [List Sources](https://docs.chatsistant.com/api-reference/data-sources/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
