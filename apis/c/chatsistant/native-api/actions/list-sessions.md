# List Sessions with Chatsistant

Retrieves chatbot session records from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid/sessions`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [List Sessions](https://docs.chatsistant.com/api-reference/sessions/fetch_multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
