# List Source Tags with Chatsistant

Retrieves source tag records from Chatsistant.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot/:uuid/source-tags`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [List Source Tags](https://docs.chatsistant.com/api-reference/source-tags/fetch-multi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The chatbot UUID. |
