# Delete Message with Chatsistant

Deletes an existing message from Chatsistant.

## Endpoint

- **Method:** `POST`
- **Path:** `/message/:uuid/delete`
- **Base URL:** `https://app.chatsistant.com/api/v1`
- **Official documentation:** [Delete Message](https://docs.chatsistant.com/api-reference/messages/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | no | The message UUID. |
