# Get Call with CallPage

Retrieves a single call from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `https://core.callpage.io/api/v3/external/calls/{call_id}`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Get Call](https://callpage.github.io/documentation-rest/#get-single-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `number` | yes | The call identifier. |
