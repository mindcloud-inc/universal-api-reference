# Get Manager with CallPage

Retrieves a single manager from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/managers/get`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Get Manager](https://callpage.github.io/documentation-rest/#get-manager)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | query | `number` | yes |
| `widget_id` | query | `number` | yes |
