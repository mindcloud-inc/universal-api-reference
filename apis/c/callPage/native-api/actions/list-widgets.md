# List Widgets with CallPage

Retrieves all available widgets from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/all`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [List Widgets](https://callpage.github.io/documentation-rest/#get-all-widgets)

## Capabilities

This operation supports [pagination](../README.md#pagination).
