# Get Widget with CallPage

Retrieves a single widget from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/get`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Get Widget](https://callpage.github.io/documentation-rest/#get-widget)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | query | `number` | yes |
