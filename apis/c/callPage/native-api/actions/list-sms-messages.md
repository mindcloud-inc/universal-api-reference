# List SMS Messages with CallPage

Retrieves all SMS messages from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/all`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [List SMS Messages](https://callpage.github.io/documentation-rest/#get-all-smss)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widget_id` | query | `number` | yes | The widget identifier. |
