# Delete Manager with CallPage

Deletes an existing manager from CallPage.

## Endpoint

- **Method:** `POST`
- **Path:** `/managers/delete`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Delete Manager](https://callpage.github.io/documentation-rest/#delete-manager)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | body | `number` | yes |
| `widget_id` | body | `number` | yes |
