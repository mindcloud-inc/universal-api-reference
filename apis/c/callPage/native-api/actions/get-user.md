# Get User with CallPage

Retrieves a single user from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/get`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Get User](https://callpage.github.io/documentation-rest/#get-user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | query | `number` | no |
| `email` | query | `string` | no |
