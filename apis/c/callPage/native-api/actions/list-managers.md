# List Managers with CallPage

Retrieves all available managers from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/managers/all`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [List Managers](https://callpage.github.io/documentation-rest/#get-all-managers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `widget_id` | query | `number` | yes |
