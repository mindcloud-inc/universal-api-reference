# Delete User with CallPage

Deletes an existing user from CallPage.

## Endpoint

- **Method:** `POST`
- **Path:** `/users/delete`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Delete User](https://callpage.github.io/documentation-rest/#delete-user)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
