# List Users with CallPage

Retrieves all available users from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/all`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [List Users](https://callpage.github.io/documentation-rest/#get-all-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
