# List Voice Messages with CallPage

Retrieves all voice messages from CallPage.

## Endpoint

- **Method:** `GET`
- **Path:** `/voice/all`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [List Voice Messages](https://callpage.github.io/documentation-rest/#get-all-voice-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widget_id` | query | `number` | yes | The widget identifier. |
