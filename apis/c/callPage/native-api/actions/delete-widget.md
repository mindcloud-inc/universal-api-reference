# Delete Widget with CallPage

Deletes an existing widget from CallPage.

## Endpoint

- **Method:** `POST`
- **Path:** `/widgets/delete`
- **Base URL:** `https://core.callpage.io/api/v1/external`
- **Official documentation:** [Delete Widget](https://callpage.github.io/documentation-rest/#delete-widget)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `number` | yes |
