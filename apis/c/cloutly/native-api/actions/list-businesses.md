# List Businesses with Cloutly

Retrieves businesses connected to your Cloutly account.

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses`
- **Base URL:** `https://app.cloutly.com/api/v1`
- **API:** rest
- **Official documentation:** [List Businesses](https://docs.cloutly.com/reviews-sdk-for-marketplace-websites/rest-api/review-summary)
