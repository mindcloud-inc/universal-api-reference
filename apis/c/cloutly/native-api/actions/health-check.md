# Health Check with Cloutly

Verifies Cloutly API key authentication setup.

## Endpoint

- **Method:** `GET`
- **Path:** `/ping`
- **Base URL:** `https://app.cloutly.com/api/v1`
- **API:** rest
- **Official documentation:** [Health Check](https://docs.cloutly.com/reviews-sdk-for-marketplace-websites/introduction/ping)
