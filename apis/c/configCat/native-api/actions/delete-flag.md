# Delete Flag with ConfigCat

Deletes an existing flag from ConfigCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/settings/:settingId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Delete Flag](https://configcat.com/docs/api/reference/delete-setting/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `settingId` | path | `string` | yes | The identifier of the Flag. |
