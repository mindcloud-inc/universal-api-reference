# Delete Config with ConfigCat

Deletes an existing config from ConfigCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/configs/:configId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Delete Config](https://configcat.com/docs/api/reference/delete-config/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `configId` | path | `string` | yes | The identifier of the Config. |
