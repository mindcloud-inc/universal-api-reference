# Get Product with ConfigCat

Retrieves an existing product from ConfigCat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/products/:productId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Get Product](https://configcat.com/docs/api/reference/get-product/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The identifier of the Product. |
