# Get Config with ConfigCat

Retrieves an existing config from ConfigCat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/configs/:configId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Get Config](https://configcat.com/docs/api/reference/get-config/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `configId` | path | `string` | yes | The identifier of the Config. |
