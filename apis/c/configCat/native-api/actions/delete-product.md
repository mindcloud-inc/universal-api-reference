# Delete Product with ConfigCat

Deletes an existing product from ConfigCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/products/:productId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Delete Product](https://configcat.com/docs/api/reference/delete-product/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The identifier of the Product. |
