# Get Environment with ConfigCat

Retrieves an existing environment from ConfigCat.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/environments/:environmentId`
- **Base URL:** `https://api.configcat.com`
- **Official documentation:** [Get Environment](https://configcat.com/docs/api/reference/get-environment/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environmentId` | path | `string` | yes | The identifier of the Environment. |
