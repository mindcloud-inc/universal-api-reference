# Heartbeat with Chroma Vector Store

Retrieves the current nanosecond timestamp from Chroma.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/heartbeat`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Heartbeat](https://docs.trychroma.com/reference/chroma-api/system/heartbeat)
