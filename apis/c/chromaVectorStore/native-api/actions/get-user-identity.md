# Get User Identity with Chroma Vector Store

Retrieves user identity details from Chroma.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/auth/identity`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Get User Identity](https://docs.trychroma.com/reference/chroma-api/authentication/get-user-identity)
