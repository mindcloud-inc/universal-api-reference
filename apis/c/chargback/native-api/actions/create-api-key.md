# Create API Key with Chargback

Creates a new API key in Chargback.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/public/v1/api-keys/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Create API Key](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `platform` | body | `string` | yes |
