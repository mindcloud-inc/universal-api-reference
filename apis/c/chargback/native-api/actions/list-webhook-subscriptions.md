# List Webhook Subscriptions with Chargback

Retrieves webhook subscription records from Chargback.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhook/subscriptions/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [List Webhook Subscriptions](https://api.chargeback.io/api/public/docs/)
