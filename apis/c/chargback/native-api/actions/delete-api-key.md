# Delete API Key with Chargback

Deletes an existing API key from Chargback.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/public/v1/api-keys/delete/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Delete API Key](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `platform` | body | `string` | yes |
