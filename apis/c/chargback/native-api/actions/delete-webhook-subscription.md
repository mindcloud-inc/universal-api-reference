# Delete Webhook Subscription with Chargback

Deletes an existing webhook subscription from Chargback.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/webhook/subscriptions/:id/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Delete Webhook Subscription](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
