# Get Alert with Chargback

Retrieves detailed alert records from Chargback.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/alerts/:external_id/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Get Alert](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `external_id` | path | `string` | yes |
