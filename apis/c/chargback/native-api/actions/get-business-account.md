# Get Business Account with Chargback

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/business_accounts/:external_id/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Get Business Account](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `external_id` | path | `string` | yes |
