# Regenerate API Key with Chargback

Regenerates an existing API key in Chargback.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/public/v1/api-keys/regenerate/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Regenerate API Key](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `platform` | body | `string` | yes |
