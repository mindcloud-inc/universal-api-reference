# Get Webhook Subscription with Chargback

Retrieves webhook subscription details from Chargback.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/webhook/subscriptions/:id/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [Get Webhook Subscription](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
