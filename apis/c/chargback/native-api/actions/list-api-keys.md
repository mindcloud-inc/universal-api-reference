# List API Keys with Chargback

Retrieves API key records from Chargback.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/public/v1/api-keys/`
- **Base URL:** `https://api.chargeback.io`
- **Official documentation:** [List API Keys](https://api.chargeback.io/api/public/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `platform` | query | `string` | no |
