# Get Collection with City of Tampa, Florida

Retrieves a data collection from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `https://city-tampa.opendata.arcgis.com/api/search/v1/collections/:collectionId`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [Get Collection](https://city-tampa.opendata.arcgis.com/api/search/definition/?f=json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Search API collection identifier, for example dataset. |
