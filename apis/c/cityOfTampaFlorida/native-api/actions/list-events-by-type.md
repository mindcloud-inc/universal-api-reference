# List Events By Type with City of Tampa, Florida

Retrieves events by type from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `/mobile-feeds/events/:typeId`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [List Events By Type](https://www.tampa.gov/info/rss-feeds)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `typeId` | path | `string` | yes | Calendar type ID or all. |
