# List Construction Project News Feed Items with City of Tampa, Florida

Retrieves construction project news feed items from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `/news/feed/cpb`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [List Construction Project News Feed Items](https://www.tampa.gov/info/rss-feeds)
