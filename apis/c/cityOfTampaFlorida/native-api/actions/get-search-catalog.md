# Get Search Catalog with City of Tampa, Florida

Retrieves the search catalog from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `https://city-tampa.opendata.arcgis.com/api/search/v1/catalog`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [Get Search Catalog](https://city-tampa.opendata.arcgis.com/api/search/definition/?f=json)
