# Get Search API Conformance with City of Tampa, Florida

Retrieves Search API conformance details from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `https://city-tampa.opendata.arcgis.com/api/search/v1/conformance`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [Get Search API Conformance](https://city-tampa.opendata.arcgis.com/api/search/definition/?f=json)
