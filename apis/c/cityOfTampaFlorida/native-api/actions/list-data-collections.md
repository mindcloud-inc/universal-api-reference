# List Data Collections with City of Tampa, Florida

Retrieves data collections from City of Tampa, Florida.

## Endpoint

- **Method:** `GET`
- **Path:** `https://city-tampa.opendata.arcgis.com/api/search/v1/collections`
- **Base URL:** `https://www.tampa.gov`
- **Official documentation:** [List Data Collections](https://city-tampa.opendata.arcgis.com/api/search/definition/?f=json)
