# List Account Addresses with Click2Mail

Retrieves a list of account addresses from Click2Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/molpro/account/addresses`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [List Account Addresses](https://developers.click2mail.com/reference/getaccountaddresses)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `addressType` | query | `string` | yes |
| `name` | query | `string` | no |
