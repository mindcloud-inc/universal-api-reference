# Create Address List with Click2Mail

Creates a new address list in Click2Mail.

## Endpoint

- **Method:** `POST`
- **Path:** `/molpro/addressLists`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Create Address List](https://developers.click2mail.com/reference/createaddresslist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `RAW_BODY` | body | `string` | no | XML Body |
