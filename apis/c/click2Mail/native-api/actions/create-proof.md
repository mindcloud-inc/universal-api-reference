# Create Proof with Click2Mail

Creates a proof for a Click2Mail job.

## Endpoint

- **Method:** `POST`
- **Path:** `/molpro/jobs/{id}/proof`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Create Proof](https://developers.click2mail.com/reference/createproof)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | job id |
