# Get Document Variable Data with Click2Mail

Retrieves variable data for a Click2Mail document.

## Endpoint

- **Method:** `GET`
- **Path:** `/molpro/documents/variableData/{id}`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Get Document Variable Data](https://developers.click2mail.com/reference/getvariabledatabydocumentid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | document id |
