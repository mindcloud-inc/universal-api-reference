# List Address Books with Click2Mail

Retrieves a list of address books from Click2Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/molpro/addressBook`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [List Address Books](https://developers.click2mail.com/reference/getaddressbooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `numberOfAddressBooks` | query | `number` | no |
| `offset` | query | `number` | no |
