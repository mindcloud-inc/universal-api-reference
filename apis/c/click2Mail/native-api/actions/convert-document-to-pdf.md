# Convert Document To PDF with Click2Mail

Creates a PDF document in Click2Mail.

## Endpoint

- **Method:** `POST`
- **Path:** `/molpro/documents/convertToPdf`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Convert Document To PDF](https://developers.click2mail.com/reference/wordtopdf)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `string` | no |
