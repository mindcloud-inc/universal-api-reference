# Check Document Name with Click2Mail

Checks whether a document name is available in Click2Mail.

## Endpoint

- **Method:** `POST`
- **Path:** `/molpro/documents/checkName`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Check Document Name](https://developers.click2mail.com/reference/checkdocumentname)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentName` | query | `string` | yes | Document name as it will be stored in your account |
