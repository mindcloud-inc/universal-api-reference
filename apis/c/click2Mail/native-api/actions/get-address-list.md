# Get Address List with Click2Mail

Retrieves an address list from Click2Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/molpro/addressLists/{id}`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Get Address List](https://developers.click2mail.com/reference/getaddressliststatus)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | base address list id |
