# Delete Address Book with Click2Mail

Deletes an address book from Click2Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/molpro/addressBook/{id}`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Delete Address Book](https://developers.click2mail.com/reference/deleteaddressbook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Address Book id |
