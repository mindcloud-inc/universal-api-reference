# Create Address Book with Click2Mail

Creates a new address book in Click2Mail.

## Endpoint

- **Method:** `POST`
- **Path:** `/molpro/addressBook`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Create Address Book](https://developers.click2mail.com/reference/createaddressbook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `addressBookName` | query | `string` | yes |
