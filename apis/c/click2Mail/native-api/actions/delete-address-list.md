# Delete Address List with Click2Mail

Deletes an address list from Click2Mail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/molpro/addressLists/{id}`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Delete Address List](https://developers.click2mail.com/reference/deleteaddresslist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | address list id |
