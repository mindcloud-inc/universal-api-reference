# Get Job with Click2Mail

Retrieves a job record from Click2Mail.

## Endpoint

- **Method:** `GET`
- **Path:** `/molpro/jobs/{id}`
- **Base URL:** `https://stage-rest.click2mail.com`
- **Official documentation:** [Get Job](https://developers.click2mail.com/reference/getjob)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | job id |
