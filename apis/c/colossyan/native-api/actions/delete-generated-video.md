# Delete Generated Video with Colossyan

Deletes a generated video from Colossyan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/generated-videos/:videoId`
- **Base URL:** `https://app.colossyan.com/api/v1`
- **Official documentation:** [Delete Generated Video](https://docs.colossyan.com/video-generation/generated-videos/delete-a-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | path | `string` | yes | ID of the generated video to delete. |
