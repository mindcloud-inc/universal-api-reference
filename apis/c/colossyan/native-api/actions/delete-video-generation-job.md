# Delete Video Generation Job with Colossyan

Deletes a video generation job from Colossyan.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video-generation-jobs/:videoGenerationJobId`
- **Base URL:** `https://app.colossyan.com/api/v1`
- **Official documentation:** [Delete Video Generation Job](https://docs.colossyan.com/video-generation/video-generation-job/delete-video-generation-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoGenerationJobId` | path | `string` | yes | ID of the video generation job to delete. |
