# Retrieve Video Generation Job with Colossyan

Retrieves a video generation job from Colossyan.

## Endpoint

- **Method:** `GET`
- **Path:** `/video-generation-jobs/:videoGenerationJobId`
- **Base URL:** `https://app.colossyan.com/api/v1`
- **Official documentation:** [Retrieve Video Generation Job](https://docs.colossyan.com/video-generation/video-generation-job/retrieve-video-generation-job)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoGenerationJobId` | path | `string` | yes | ID of the video generation job to retrieve. |
