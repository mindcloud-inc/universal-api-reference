# Retrieve Generated Video with Colossyan

Retrieves a generated video from Colossyan.

## Endpoint

- **Method:** `GET`
- **Path:** `/generated-videos/:videoId`
- **Base URL:** `https://app.colossyan.com/api/v1`
- **Official documentation:** [Retrieve Generated Video](https://docs.colossyan.com/video-generation/generated-videos/retrieve-a-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `videoId` | path | `string` | yes | ID of the generated video to retrieve. |
