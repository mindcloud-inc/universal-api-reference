# CircleCI: Rerun Workflow



```
PUT https://connect.mindcloud.co/v1/universal/circleCI/latest/actions/rerun-workflow
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a CircleCI `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X PUT "https://connect.mindcloud.co/v1/universal/circleCI/latest/actions/rerun-workflow" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID"
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/circleCI/latest/actions/rerun-workflow', {
  method: 'PUT',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `enable_ssh` | string | no | Enable SSH for rerun jobs. |
| `from_failed` | string | no | Rerun only failed jobs when true. |
| `id` | string | no | Opaque workflow identifier. |
| `jobs` | string | no | Subset of jobs to rerun. |
| `sparse_tree` | string | no | Rerun only selected jobs when true. |

## Response

```json
{
  "success": true,
  "data": [

      "id": "string",
      "message": "string"
    }
  ],
  "meta": {}

```

## Native endpoint

Through the native CircleCI API, this operation is `POST /workflow/:id/rerun` (base URL `https://circleci.com/api/v2`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/rerun-workflow.md) for the provider-specific parameters and requirements.
