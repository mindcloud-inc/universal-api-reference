# Get Workflow with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/workflow/:id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Workflow](https://circleci.com/docs/api/v2/#tag/Workflow/operation/getWorkflowById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Opaque workflow identifier. |
