# Get Job with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:job_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Job](https://circleci.com/docs/api/v2/#tag/Job/operation/getJob)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | path | `string` | no | Opaque job identifier. |
