# List URL Orb Allow List Entries with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/:org_slug_or_id/url-orb-allow-list`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [List URL Orb Allow List Entries](https://circleci.com/docs/api/v2/#tag/Organization/operation/listURLOrbAllowListEntries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_slug_or_id` | path | `string` | yes | The CircleCI organization slug or ID. |
