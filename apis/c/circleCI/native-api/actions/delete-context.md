# Delete Context with CircleCI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/context/:context_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Delete Context](https://circleci.com/docs/api/v2/#tag/Context/operation/deleteContext)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `context_id` | path | `string` | no | The CircleCI context UUID. |
