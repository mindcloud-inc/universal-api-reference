# Get Deploy Component with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/deploy/components/:component_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Deploy Component](https://circleci.com/docs/api/v2/#tag/Deploy/operation/getComponent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `component_id` | path | `string` | no | The deploy component ID. |
