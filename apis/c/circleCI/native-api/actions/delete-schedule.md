# Delete Schedule with CircleCI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schedule/:schedule_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Delete Schedule](https://circleci.com/docs/api/v2/#tag/Schedule/operation/deleteScheduleById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schedule_id` | path | `string` | no | Opaque schedule identifier. |
