# Get User with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get User](https://circleci.com/docs/api/v2/#tag/User/operation/getUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The CircleCI user ID. |
