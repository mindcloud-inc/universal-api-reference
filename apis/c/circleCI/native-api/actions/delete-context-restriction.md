# Delete Context Restriction with CircleCI

## Endpoint

- **Method:** `DELETE`
- **Path:** `/context/:context_id/restrictions/:restriction_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Delete Context Restriction](https://circleci.com/docs/api/v2/#tag/Context-Restrictions/operation/deleteContextRestriction)
