# Get Schedule with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/schedule/:schedule_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Schedule](https://circleci.com/docs/api/v2/#tag/Schedule/operation/getScheduleById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schedule_id` | path | `string` | no | Opaque schedule identifier. |
