# Get Context with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/context/:context_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Context](https://circleci.com/docs/api/v2/#tag/Context/operation/getContext)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `context_id` | path | `string` | yes | The CircleCI context ID. |
