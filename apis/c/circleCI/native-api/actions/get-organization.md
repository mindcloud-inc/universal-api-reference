# Get Organization with CircleCI

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/:org_slug_or_id`
- **Base URL:** `https://circleci.com/api/v2`
- **Official documentation:** [Get Organization](https://circleci.com/docs/api/v2/#tag/Organization/operation/getOrganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_slug_or_id` | path | `string` | yes | The CircleCI organization slug or ID. |
