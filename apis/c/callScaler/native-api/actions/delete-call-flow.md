# Delete Call Flow with CallScaler

Deletes a call flow from CallScaler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/call-flows/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Delete Call Flow](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
