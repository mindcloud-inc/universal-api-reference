# List Call Flow Versions with CallScaler

Retrieves call flow versions from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-flows/:id/versions`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Call Flow Versions](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
