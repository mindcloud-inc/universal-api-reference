# Get Call Transcription with CallScaler

Retrieves a call transcription from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:id/transcription`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Get Call Transcription](https://callscaler.com/docs/api-calls)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
