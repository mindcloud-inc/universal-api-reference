# Get Number Group Bulk Stats with CallScaler

Retrieves number group bulk stats from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/number-groups/bulk-stats`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Get Number Group Bulk Stats](https://callscaler.com/docs/api-resources)
