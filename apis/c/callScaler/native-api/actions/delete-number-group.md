# Delete Number Group with CallScaler

Deletes a number group from CallScaler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/number-groups/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Delete Number Group](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
