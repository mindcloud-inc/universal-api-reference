# Create Number Group with CallScaler

Creates a number group in CallScaler.

## Endpoint

- **Method:** `POST`
- **Path:** `/number-groups`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Create Number Group](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
