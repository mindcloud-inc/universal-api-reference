# List Number Pools with CallScaler

Retrieves number pools from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/number-pools`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Number Pools](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
