# List Number Group Members with CallScaler

Retrieves number group members from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/number-groups/:id/members`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Number Group Members](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
