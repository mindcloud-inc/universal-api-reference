# Get Number Pool with CallScaler

Retrieves a number pool from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/number-pools/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Get Number Pool](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
