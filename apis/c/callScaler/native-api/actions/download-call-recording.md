# Download Call Recording with CallScaler

Downloads a call recording from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:id/recording`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Download Call Recording](https://callscaler.com/docs/api-calls)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
