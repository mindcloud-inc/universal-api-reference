# Release Number with CallScaler

Deletes a number from CallScaler.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/numbers/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Release Number](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
