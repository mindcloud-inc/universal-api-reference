# List Numbers with CallScaler

Retrieves numbers from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Numbers](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
