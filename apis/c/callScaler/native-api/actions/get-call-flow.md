# Get Call Flow with CallScaler

Retrieves a call flow from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-flows/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Get Call Flow](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
