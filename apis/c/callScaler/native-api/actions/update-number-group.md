# Update Number Group with CallScaler

Updates a number group in CallScaler.

## Endpoint

- **Method:** `PUT`
- **Path:** `/number-groups/:id`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Update Number Group](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `name` | body | `string` | no |
