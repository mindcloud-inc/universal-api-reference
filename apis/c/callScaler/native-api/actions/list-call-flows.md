# List Call Flows with CallScaler

Retrieves call flows from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/call-flows`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Call Flows](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
