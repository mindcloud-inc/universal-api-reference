# List Number Groups with CallScaler

Retrieves number groups from CallScaler.

## Endpoint

- **Method:** `GET`
- **Path:** `/number-groups`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [List Number Groups](https://callscaler.com/docs/api-resources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
