# Search Available Numbers with CallScaler

Finds available numbers in CallScaler.

## Endpoint

- **Method:** `POST`
- **Path:** `/numbers/search`
- **Base URL:** `https://callscaler.com/api/v1`
- **Official documentation:** [Search Available Numbers](https://callscaler.com/docs/api-resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `area_code` | body | `string` | yes |
