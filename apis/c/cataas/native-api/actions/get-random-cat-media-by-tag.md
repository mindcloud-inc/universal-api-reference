# Get Random Cat Media By Tag with Cataas

## Endpoint

- **Method:** `GET`
- **Path:** `/cat/:tag`
- **Base URL:** `https://cataas.com`
- **Official documentation:** [Get Random Cat Media By Tag](https://cataas.com/doc.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | Return a random cat matching this tag. |
