# Get Cat Media By ID with Cataas

## Endpoint

- **Method:** `GET`
- **Path:** `/cat/:catId`
- **Base URL:** `https://cataas.com`
- **Official documentation:** [Get Cat Media By ID](https://cataas.com/doc.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `catId` | path | `string` | yes | The ID of the cat media to retrieve. |
