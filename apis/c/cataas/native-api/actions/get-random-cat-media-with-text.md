# Get Random Cat Media With Text with Cataas

## Endpoint

- **Method:** `GET`
- **Path:** `/cat/says/:text`
- **Base URL:** `https://cataas.com`
- **Official documentation:** [Get Random Cat Media With Text](https://cataas.com/doc.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | path | `string` | yes | Text to render over the random cat image. |
