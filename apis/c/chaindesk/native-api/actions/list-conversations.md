# List Conversations with Chaindesk

Retrieves conversations from your Chaindesk workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [List Conversations](https://docs.chaindesk.ai/api-reference/endpoint/conversations/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `take` | query | `number` | no |
