# Get Mail Inbox with Chaindesk

Retrieves a mail inbox from Chaindesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/mail-inboxes/:mailInboxId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Get Mail Inbox](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailInboxId` | path | `string` | yes |
