# Delete Datastore with Chaindesk

Deletes an existing datastore from Chaindesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/datastores/:datastoreId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Delete Datastore](https://docs.chaindesk.ai/api-reference/endpoint/datastores/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datastoreId` | path | `string` | yes |
