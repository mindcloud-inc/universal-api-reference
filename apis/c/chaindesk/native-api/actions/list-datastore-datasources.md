# List Datastore Datasources with Chaindesk

Retrieves datasources for a datastore in Chaindesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [List Datastore Datasources](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datastoreId` | query | `string` | yes |
