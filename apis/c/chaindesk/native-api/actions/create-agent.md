# Create Agent with Chaindesk

Creates a new agent in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/agents`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create Agent](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `description` | body | `string` | yes |
