# Delete Agent with Chaindesk

Deletes an existing agent from Chaindesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agents/:agentId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Delete Agent](https://docs.chaindesk.ai/api-reference/endpoint/agents/delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
