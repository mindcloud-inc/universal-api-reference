# List Agents with Chaindesk

Retrieves agents from your Chaindesk workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [List Agents](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
