# Create Mail Inbox with Chaindesk

Creates a mail inbox in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/mail-inboxes`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create Mail Inbox](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
| `alias` | body | `string` | no |
