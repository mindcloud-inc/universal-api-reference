# Delete Mail Inbox with Chaindesk

Deletes a mail inbox from Chaindesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/mail-inboxes/:mailInboxId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Delete Mail Inbox](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mailInboxId` | path | `string` | yes |
