# Create Contact with Chaindesk

Creates a new contact in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create Contact](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `draftConfig` | body | `object<object>` | yes |
