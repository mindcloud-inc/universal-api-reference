# Get Conversation Messages with Chaindesk

Retrieves messages from a Chaindesk conversation.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId/messages`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Get Conversation Messages](https://docs.chaindesk.ai/api-reference/endpoint/conversations/messages)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversationId` | path | `string` | yes |
