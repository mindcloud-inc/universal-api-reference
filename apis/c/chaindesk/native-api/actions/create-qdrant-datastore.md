# Create Qdrant Datastore with Chaindesk

Creates a Qdrant datastore in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/datastores`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create Qdrant Datastore](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
