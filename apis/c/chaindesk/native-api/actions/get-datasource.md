# Get Datasource with Chaindesk

Retrieves an existing datasource from Chaindesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/datasources/:datasourceId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Get Datasource](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datasourceId` | path | `string` | yes |
