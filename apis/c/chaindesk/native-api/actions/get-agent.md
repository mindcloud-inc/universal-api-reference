# Get Agent with Chaindesk

Retrieves an existing agent from Chaindesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Get Agent](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
