# Create S3 Datastore with Chaindesk

Creates an S3 datastore in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/datastores`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create S3 Datastore](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
