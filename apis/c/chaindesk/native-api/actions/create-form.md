# Create Form with Chaindesk

Creates a new form in Chaindesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/forms`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Create Form](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `draftConfig` | body | `object<object>` | yes |
