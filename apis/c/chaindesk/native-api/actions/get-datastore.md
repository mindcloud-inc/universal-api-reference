# Get Datastore with Chaindesk

Retrieves an existing datastore from Chaindesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/datastores/:datastoreId`
- **Base URL:** `https://app.chaindesk.ai/api`
- **Official documentation:** [Get Datastore](https://docs.chaindesk.ai/api-reference)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `datastoreId` | path | `string` | yes |
