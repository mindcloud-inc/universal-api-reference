# Get View with Caspio

Retrieves a single view from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/views/{viewName}`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Get View](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Views/GetView)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `viewName` | path | `string` | yes | Target view name. |
