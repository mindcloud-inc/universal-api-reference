# List Table Fields with Caspio

Retrieves all table fields from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/tables/{tableName}/fields`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [List Table Fields](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Tables/ListTableFields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableName` | path | `string` | yes | Target table name. |
