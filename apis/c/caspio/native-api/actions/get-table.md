# Get Table with Caspio

Retrieves a single table from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/tables/{tableName}`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Get Table](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Tables/GetTable)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableName` | path | `string` | yes | Target table name. |
