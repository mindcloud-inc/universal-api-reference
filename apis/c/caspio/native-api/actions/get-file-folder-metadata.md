# Get File Folder Metadata with Caspio

Retrieves file folder metadata from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/files/folders/{externalKey}`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Get File Folder Metadata](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Files/GetFilesFolderMetadataByKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalKey` | path | `string` | yes | Folder ID. |
