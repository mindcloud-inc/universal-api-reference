# Get View Field with Caspio

Retrieves a view field from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/views/{viewName}/fields/{fieldName}`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Get View Field](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Views/GetViewField)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `viewName` | path | `string` | yes | Target view name. |
| `fieldName` | path | `string` | yes | Target field name. |
