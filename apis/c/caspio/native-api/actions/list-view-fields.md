# List View Fields with Caspio

Retrieves all view fields from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/views/{viewName}/fields`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [List View Fields](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Views/ListViewFields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `viewName` | path | `string` | yes | Target view name. |
