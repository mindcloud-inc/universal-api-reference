# Get File Metadata with Caspio

Retrieves detailed file metadata from Caspio.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/files/{externalKey}/fileInfo`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Get File Metadata](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Files/GetFileMetadataByKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalKey` | path | `string` | yes | File ID. |
