# List Views with Caspio

Retrieves all available views from Caspio.

- **Method:** `GET`
- **Path:** `/v3/views`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [List Views](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Views/ListViews)
