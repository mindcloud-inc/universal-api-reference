# Create View Record with Caspio

Creates a new view record in Caspio.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/views/{viewName}/records`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Create View Record](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Views/CreateViewRecord)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `viewName` | path | `string` | yes | Target view name. |
