# Create Table Record with Caspio

Creates a new table record in Caspio.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/tables/{tableName}/records`
- **Base URL:** `https://d2hbw900.caspio.com/integrations/rest`
- **Official documentation:** [Create Table Record](https://d2hbw900.caspio.com/integrations/rest/swagger/index.html#/Tables/CreateTableRecord)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableName` | path | `string` | yes | Target table name. |
