# Delete List with CreateSend

Deletes an existing list from CreateSend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/lists/:listId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete List](https://www.campaignmonitor.com/api/lists/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
