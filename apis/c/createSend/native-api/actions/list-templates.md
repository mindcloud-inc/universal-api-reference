# List Templates with CreateSend

Retrieves templates for a client in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/templates.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Templates](https://www.campaignmonitor.com/api/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
