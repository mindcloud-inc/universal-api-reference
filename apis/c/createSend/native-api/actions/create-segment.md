# Create Segment with CreateSend

Creates a new segment in CreateSend.

## Endpoint

- **Method:** `POST`
- **Path:** `/segments/:listId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Create Segment](https://www.campaignmonitor.com/api/segments/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
| `Title` | body | `string` | yes |
