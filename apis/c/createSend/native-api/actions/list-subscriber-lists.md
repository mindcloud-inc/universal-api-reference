# List Subscriber Lists with CreateSend

Retrieves subscriber lists for a client in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/lists.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Subscriber Lists](https://www.campaignmonitor.com/api/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
