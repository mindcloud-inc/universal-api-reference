# Delete Segment with CreateSend

Deletes an existing segment from CreateSend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/segments/:segmentId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete Segment](https://www.campaignmonitor.com/api/v3-3/segments/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | path | `string` | yes |
