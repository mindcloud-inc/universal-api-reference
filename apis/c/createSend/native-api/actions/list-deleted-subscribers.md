# List Deleted Subscribers with CreateSend

Retrieves deleted subscribers for a list in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/deleted.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Deleted Subscribers](https://www.campaignmonitor.com/api/v3-3/lists/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
