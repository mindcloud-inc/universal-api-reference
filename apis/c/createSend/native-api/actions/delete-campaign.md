# Delete Campaign with CreateSend

Deletes an existing campaign from CreateSend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/campaigns/:campaignId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Delete Campaign](https://www.campaignmonitor.com/api/v3-3/campaigns/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
