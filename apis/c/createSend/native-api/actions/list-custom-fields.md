# List Custom Fields with CreateSend

Retrieves custom fields for a list in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/customfields.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Custom Fields](https://www.campaignmonitor.com/api/v3-3/lists/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
