# Get Client Details with CreateSend

Retrieves client details from CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get Client Details](https://www.campaignmonitor.com/api/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
