# List Scheduled Campaigns with CreateSend

Retrieves scheduled campaigns for a client in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:clientId/scheduled.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Scheduled Campaigns](https://www.campaignmonitor.com/api/clients/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
