# Get Campaign Summary with CreateSend

Retrieves a campaign summary from CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:campaignId/summary.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get Campaign Summary](https://www.campaignmonitor.com/api/v3-3/campaigns/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `campaignId` | path | `string` | yes |
