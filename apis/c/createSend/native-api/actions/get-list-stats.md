# Get List Stats with CreateSend

Retrieves list stats from CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/stats.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get List Stats](https://www.campaignmonitor.com/api/v3-3/lists/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
