# Update Segment with CreateSend

Updates an existing segment in CreateSend.

## Endpoint

- **Method:** `PUT`
- **Path:** `/segments/:segmentId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Update Segment](https://www.campaignmonitor.com/api/v3-3/segments/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | path | `string` | yes |
| `Title` | body | `string` | yes |
