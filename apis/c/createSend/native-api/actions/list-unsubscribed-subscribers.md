# List Unsubscribed Subscribers with CreateSend

Retrieves unsubscribed subscribers for a list in CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:listId/unsubscribed.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [List Unsubscribed Subscribers](https://www.campaignmonitor.com/api/v3-3/lists/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `listId` | path | `string` | yes |
