# Get Segment Details with CreateSend

Retrieves segment details from CreateSend.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments/:segmentId.json`
- **Base URL:** `https://api.createsend.com/api/v3.3`
- **Official documentation:** [Get Segment Details](https://www.campaignmonitor.com/api/segments/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `segmentId` | path | `string` | yes |
