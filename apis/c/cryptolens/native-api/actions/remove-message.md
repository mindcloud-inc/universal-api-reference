# Remove Message with Cryptolens

Deletes an existing message from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/message/RemoveMessage`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Remove Message](https://app.cryptolens.io/docs/api/v3/RemoveMessage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Id` | query | `number` | yes | The message id. |
