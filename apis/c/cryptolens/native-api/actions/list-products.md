# List Products with Cryptolens

Retrieves products from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/product/GetProducts`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [List Products](https://app.cryptolens.io/docs/api/v3/GetProducts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `v` | query | `string` | no | Method version. |
