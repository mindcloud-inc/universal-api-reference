# Get Reseller Customers with Cryptolens

Retrieves customers for a reseller from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/reseller/GetResellerCustomers`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Get Reseller Customers](https://app.cryptolens.io/docs/api/v3/GetResellerCustomers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ResellerId` | query | `number` | yes | The reseller id. |
