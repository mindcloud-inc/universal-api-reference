# Upload Values with Cryptolens

Uploads log values to data objects in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/UploadValuesToKey`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Upload Values](https://app.cryptolens.io/docs/api/v3/UploadValues)
