# Edit Reseller with Cryptolens

Updates an existing reseller in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/reseller/EditReseller`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Edit Reseller](https://app.cryptolens.io/docs/api/v3/EditReseller)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ResellerId` | query | `number` | yes | The reseller id. |
