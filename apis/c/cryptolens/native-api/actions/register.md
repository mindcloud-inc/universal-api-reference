# Register with Cryptolens

Creates a new user in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/userauth/Register`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Register](https://app.cryptolens.io/docs/api/v3/Register)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Username` | query | `string` | yes | The username. |
| `Password` | query | `string` | yes | The password. |
