# Remove Reseller with Cryptolens

Deletes an existing reseller from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/reseller/RemoveReseller`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Remove Reseller](https://app.cryptolens.io/docs/api/v3/RemoveReseller)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ResellerId` | query | `number` | yes | The reseller id. |
