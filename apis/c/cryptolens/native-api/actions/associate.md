# Associate with Cryptolens

Associates a user with a customer in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/userauth/Associate`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Associate](https://app.cryptolens.io/docs/api/v3/Associate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Username` | query | `string` | yes | The username to associate. |
