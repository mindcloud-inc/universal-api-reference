# Remove Customer with Cryptolens

Deletes an existing customer from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/customer/RemoveCustomer`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Remove Customer](https://app.cryptolens.io/docs/api/v3/RemoveCustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerId` | query | `number` | yes | The customer id. |
