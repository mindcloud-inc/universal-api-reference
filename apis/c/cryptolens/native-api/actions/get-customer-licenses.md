# Get Customer Licenses with Cryptolens

Retrieves license keys for a customer from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/customer/GetCustomerLicenses`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Get Customer Licenses](https://app.cryptolens.io/docs/api/v3/GetCustomerLicenses)
