# Login with Cryptolens

Logs a user in to Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/userauth/Login`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Login](https://app.cryptolens.io/docs/api/v3/Login)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Username` | query | `string` | yes | The username. |
| `Password` | query | `string` | yes | The password. |
