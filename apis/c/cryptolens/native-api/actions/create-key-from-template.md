# Create Key From Template with Cryptolens

Creates a license key from a template in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/key/CreateKeyFromTemplate`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Create Key From Template](https://app.cryptolens.io/docs/api/v3/CreateKeyFromTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LicenseTemplateId` | query | `number` | yes | The license template id. |
