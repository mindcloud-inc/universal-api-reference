# Remove Data Object with Cryptolens

Deletes an existing data object from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/RemoveDataObject`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Remove Data Object](https://app.cryptolens.io/docs/api/v3/RemoveDataObject)
