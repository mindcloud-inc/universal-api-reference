# Edit Customer with Cryptolens

Updates an existing customer in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/customer/EditCustomer`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Edit Customer](https://app.cryptolens.io/docs/api/v3/EditCustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `CustomerId` | query | `number` | yes | The customer id. |
