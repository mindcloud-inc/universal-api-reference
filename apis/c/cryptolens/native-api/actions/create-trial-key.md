# Create Trial Key with Cryptolens

Creates a new trial key in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/key/CreateTrialKey`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Create Trial Key](https://app.cryptolens.io/docs/api/v3/CreateTrialKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProductId` | query | `number` | yes | The product id. |
