# Dissociate with Cryptolens

Dissociates a user from a customer in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/userauth/Dissociate`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Dissociate](https://app.cryptolens.io/docs/api/v3/Dissociate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Username` | query | `string` | yes | The username. |
