# Decrement Int Value with Cryptolens

Decrements a data object integer value in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/DecrementIntValue`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Decrement Int Value](https://app.cryptolens.io/docs/api/v3/DecrementIntValue)
