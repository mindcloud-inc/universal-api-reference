# Create Key with Cryptolens

Creates a new license key in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/key/CreateKey`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Create Key](https://app.cryptolens.io/docs/api/v3/CreateKey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProductId` | query | `number` | yes | The product id. |
