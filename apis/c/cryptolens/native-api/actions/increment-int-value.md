# Increment Int Value with Cryptolens

Increments a data object integer value in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/data/IncrementIntValue`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Increment Int Value](https://app.cryptolens.io/docs/api/v3/IncrementIntValue)
