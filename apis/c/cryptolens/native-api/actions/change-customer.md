# Change Customer with Cryptolens

Updates the customer on a license in Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/key/ChangeCustomer`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Change Customer](https://app.cryptolens.io/docs/api/v3/ChangeCustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ProductId` | query | `number` | yes | The product id. |
| `Key` | query | `string` | yes | The serial key string. |
