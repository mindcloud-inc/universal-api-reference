# Remove User with Cryptolens

Deletes an existing user from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/userauth/RemoveUser`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Remove User](https://app.cryptolens.io/docs/api/v3/RemoveUser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Username` | query | `string` | yes | The username. |
