# Get License Templates with Cryptolens

Retrieves license templates from Cryptolens.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/licensetemplate/GetLicenseTemplates`
- **Base URL:** `https://api.cryptolens.io`
- **Official documentation:** [Get License Templates](https://app.cryptolens.io/docs/api/v3/GetLicenseTemplates)
