# Corporate Buzzword Generator: Generate Corporate Buzzword

Retrieves a random corporate buzzword phrase from Corporate Buzzword Generator.

```
GET https://connect.mindcloud.co/v1/universal/corporateBuzzwordGenerator/latest/actions/generate-corporate-buzzword
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Corporate Buzzword Generator `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/corporateBuzzwordGenerator/latest/actions/generate-corporate-buzzword?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/corporateBuzzwordGenerator/latest/actions/generate-corporate-buzzword?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```



## Response

```json
{
  "success": true,
  "data": [
    {
      "phrase": "string"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `phrase` | string | Random corporate buzzword phrase generated by the API. |

## Native endpoint

Through the native Corporate Buzzword Generator API, this operation is `GET /` (base URL `https://corporatebs-generator.sameerkumar.website`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/generate-corporate-buzzword.md) for the provider-specific parameters and requirements.
