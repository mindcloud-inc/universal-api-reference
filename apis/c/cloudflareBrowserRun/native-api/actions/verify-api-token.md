# Verify API Token with Cloudflare Browser Run

Verifies whether a Cloudflare API token works.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/tokens/verify`
- **Base URL:** `https://api.cloudflare.com/client/v4`
- **Official documentation:** [Verify API Token](https://developers.cloudflare.com/api/resources/accounts/subresources/tokens/methods/verify/)
