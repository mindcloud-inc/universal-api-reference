# Get Item with ChargeOver

Retrieves detailed item records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/item/:item_id`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [Get Item](https://developer.chargeover.com/docs/api/get-a-specific-item/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `item_id` | path | `number` | yes | The ChargeOver item ID. |
