# List Items with ChargeOver

Retrieves catalog item records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/item`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [List Items](https://developer.chargeover.com/docs/api/querying-for-items/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
