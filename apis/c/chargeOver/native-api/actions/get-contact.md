# Get Contact with ChargeOver

Retrieves detailed contact records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:user_id`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [Get Contact](https://developer.chargeover.com/docs/api/get-a-specific-contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | The ChargeOver contact ID. |
