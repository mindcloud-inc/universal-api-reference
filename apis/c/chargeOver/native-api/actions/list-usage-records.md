# List Usage Records with ChargeOver

Retrieves metered usage records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/usage`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [List Usage Records](https://developer.chargeover.com/docs/api/query-for-usage-metered-data/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
