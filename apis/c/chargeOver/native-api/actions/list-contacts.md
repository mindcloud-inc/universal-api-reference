# List Contacts with ChargeOver

Retrieves customer contact records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [List Contacts](https://developer.chargeover.com/docs/api/query-for-contacts/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
