# Get Customer with ChargeOver

Retrieves detailed customer records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer/:customer_id`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [Get Customer](https://developer.chargeover.com/docs/api/get-a-specific-customer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `number` | yes | The ChargeOver customer ID. |
