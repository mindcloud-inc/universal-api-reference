# List Transactions with ChargeOver

Retrieves billing transaction records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [List Transactions](https://developer.chargeover.com/docs/api/query-for-transactions/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
