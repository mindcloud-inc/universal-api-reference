# List Customers with ChargeOver

Retrieves customer account records from ChargeOver.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer`
- **Base URL:** `https://{siteName}.chargeover.com/api/v3`
- **Official documentation:** [List Customers](https://developer.chargeover.com/docs/api/query-for-customers/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
