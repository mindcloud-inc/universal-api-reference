# List Open Authorization Requests with Conveyor

Retrieves open authorization requests from Conveyor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/exchange/authorization_request_queue`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [List Open Authorization Requests](https://docs.conveyor.com/reference/get-authorization-requests-queue)
