# Delete Document with Conveyor

Deletes a document from the Conveyor exchange.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/exchange/documents/:document_id`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [Delete Document](https://docs.conveyor.com/reference/delete-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | Document identifier. |
