# Create Folder with Conveyor

Creates a folder in the Conveyor exchange.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/exchange/folders`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [Create Folder](https://docs.conveyor.com/reference/post-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Folder name. |
