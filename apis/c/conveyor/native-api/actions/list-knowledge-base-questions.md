# List Knowledge Base Questions with Conveyor

Retrieves knowledge base questions from Conveyor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/knowledge_base/questions`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [List Knowledge Base Questions](https://docs.conveyor.com/reference/get-knowledge-base-questions)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Knowledge base question verification status. |
