# Delete Folder with Conveyor

Deletes a folder from the Conveyor exchange.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/exchange/folders/:folder_id`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [Delete Folder](https://docs.conveyor.com/reference/delete-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder_id` | path | `string` | yes | Folder identifier. |
