# Get Authorization Request with Conveyor

Retrieves an authorization request from Conveyor.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/exchange/authorization_requests/:authorization_request_id`
- **Base URL:** `https://api.conveyor.com/api`
- **Official documentation:** [Get Authorization Request](https://docs.conveyor.com/reference/get-authorization-request)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `authorization_request_id` | path | `string` | yes | Authorization request identifier. |
