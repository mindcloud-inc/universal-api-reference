# Ping Connection with Celigo

## Endpoint

- **Method:** `GET`
- **Path:** `/connections/:connectionId/ping`
- **Base URL:** `https://{apiHost}/v1`
- **Official documentation:** [Ping Connection](https://developer.celigo.com/api/api-reference/connections-and-http-connectors/connections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `list<string>` | yes | Connection. Pick from List Connections. |
