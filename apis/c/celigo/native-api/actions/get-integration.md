# Get Integration with Celigo

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:integrationId`
- **Base URL:** `https://{apiHost}/v1`
- **Official documentation:** [Get Integration](https://developer.celigo.com/api/api-reference/integrations-and-flows/integrations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `list<string>` | yes | Integration to get. |
