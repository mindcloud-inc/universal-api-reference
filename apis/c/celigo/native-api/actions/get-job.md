# Get Job with Celigo

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://{apiHost}/v1`
- **Official documentation:** [Get Job](https://developer.celigo.com/api/api-reference/monitoring/jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Job ID (the id of a job from List Jobs or List Latest Flow Jobs). |
