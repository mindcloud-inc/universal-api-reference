# Update Client Campaign with CloudContactAI

## Endpoint

- **Method:** `PUT`
- **Path:** `api/clients/:clientId/campaigns/:campaignId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Update Client Campaign](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
| `clientId` | path | `string` | no | The client ID. |
