# List Messages by Campaign with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/messages/campaign/:campaignId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [List Messages by Campaign](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
