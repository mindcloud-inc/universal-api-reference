# Get Message by ID with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/messages/:id`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Message by ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The message ID. |
