# List Messages by Contact with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/messages/contact/:contactId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [List Messages by Contact](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The contact ID. |
