# Get Campaign Contact Message with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/messages/campaign/:campaignId/contact/:contactId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Campaign Contact Message](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
| `contactId` | path | `string` | no | The contact ID. |
