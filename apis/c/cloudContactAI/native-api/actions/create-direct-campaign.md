# Create Direct Campaign with CloudContactAI

## Endpoint

- **Method:** `POST`
- **Path:** `api/clients/:clientId/campaigns/direct`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Create Direct Campaign](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientId` | path | `string` | no | The client ID. |
