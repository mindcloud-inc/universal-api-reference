# Delete Campaign by ID with CloudContactAI

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/campaigns/:campaignId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Delete Campaign by ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
