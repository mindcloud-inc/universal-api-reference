# Get Campaign Message Stats with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/messages/campaign/:campaignId/stats`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Campaign Message Stats](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
