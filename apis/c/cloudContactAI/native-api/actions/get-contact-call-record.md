# Get Contact Call Record with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/contacts/:id/callRecord`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Contact Call Record](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The contact ID. |
