# Update Contact by ID with CloudContactAI

## Endpoint

- **Method:** `PUT`
- **Path:** `api/v1/contacts/:contact_id`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Update Contact by ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | no | The contact ID. |
