# Update Client by ID with CloudContactAI

## Endpoint

- **Method:** `PUT`
- **Path:** `api/clients/:id`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Update Client by ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The client ID. |
