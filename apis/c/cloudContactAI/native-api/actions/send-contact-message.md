# Send Contact Message with CloudContactAI

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/messages/contact/:contactId/send`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Send Contact Message](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | no | The contact ID. |
