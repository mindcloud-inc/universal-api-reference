# Get Contact by ID with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/contacts/:id`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Contact by ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The contact ID. |
