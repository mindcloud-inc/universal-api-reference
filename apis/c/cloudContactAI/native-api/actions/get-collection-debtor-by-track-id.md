# Get Collection Debtor by Track ID with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/collection/debtor/:trackId`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Get Collection Debtor by Track ID](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trackId` | path | `string` | no | The debtor track ID. |
