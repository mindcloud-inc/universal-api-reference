# List Client Campaigns with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/clients/:id/campaigns`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [List Client Campaigns](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | The client ID. |
