# List Campaigns with CloudContactAI

## Endpoint

- **Method:** `GET`
- **Path:** `api/v2/campaigns`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [List Campaigns](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageNumber` | query | `number` | no | The page number. |
| `pageSize` | query | `number` | no | The page size. |
| `term` | query | `string` | no | Optional search term. |
| `offset` | query | `number` | no | Optional result offset. |
