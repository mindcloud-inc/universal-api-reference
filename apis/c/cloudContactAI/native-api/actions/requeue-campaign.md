# Requeue Campaign with CloudContactAI

## Endpoint

- **Method:** `POST`
- **Path:** `api/v2/campaigns/:campaignId/requeue`
- **Base URL:** `https://core.cloudcontactai.com`
- **Official documentation:** [Requeue Campaign](https://developer.cloudcontactai.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `string` | no | The campaign ID. |
