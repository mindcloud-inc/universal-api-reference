# Get Tag with Centers for Disease Control and Prevention

Retrieves a tag from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/tags/:tagId`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [Get Tag](https://tools.cdc.gov/api/docs/info.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `number` | yes | The identifier of the tag to retrieve. |
