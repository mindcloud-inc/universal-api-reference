# Get Media Embed Code with Centers for Disease Control and Prevention

Retrieves media embed code from CDC Content Services.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/media/:mediaId/embed`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [Get Media Embed Code](https://tools.cdc.gov/api/docs/info.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `number` | yes | The identifier of the media. |
