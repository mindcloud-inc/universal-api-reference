# Get Media with Centers for Disease Control and Prevention

Retrieves media from CDC Content Services by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/media/:mediaId`
- **Base URL:** `https://tools.cdc.gov/api`
- **Official documentation:** [Get Media](https://tools.cdc.gov/api/docs/info.aspx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mediaId` | path | `number` | yes | The identifier of the media to retrieve. |
