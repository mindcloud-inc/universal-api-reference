# List Shipping Levels with Cloudprinter.com

Retrieves shipping levels from Cloudprinter.com.

## Endpoint

- **Method:** `POST`
- **Path:** `/cloudcore/1.0/shipping/levels`
- **Base URL:** `https://api.cloudprinter.com`
- **Official documentation:** [List Shipping Levels](https://docs.cloudprinter.com/client/cloudprinter-core-api-v1-0#list-shipping-levels)
