# List Shipping Countries with Cloudprinter.com

Retrieves shipping countries from Cloudprinter.com.

## Endpoint

- **Method:** `POST`
- **Path:** `/cloudcore/1.0/shipping/countries`
- **Base URL:** `https://api.cloudprinter.com`
- **Official documentation:** [List Shipping Countries](https://docs.cloudprinter.com/client/cloudprinter-core-api-v1-0#list-shipping-countries)
