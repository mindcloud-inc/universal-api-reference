# List Orders with Cloudprinter.com

Retrieves orders from Cloudprinter.com.

## Endpoint

- **Method:** `POST`
- **Path:** `/cloudcore/1.0/orders/`
- **Base URL:** `https://api.cloudprinter.com`
- **Official documentation:** [List Orders](https://docs.cloudprinter.com/client/cloudprinter-core-api-v1-0#list-all-orders)
