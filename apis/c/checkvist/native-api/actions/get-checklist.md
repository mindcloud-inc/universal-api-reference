# Get Checklist with Checkvist

Retrieves a checklist from Checkvist.

## Endpoint

- **Method:** `GET`
- **Path:** `/checklists/:checklistId.json`
- **Base URL:** `https://checkvist.com`
- **Official documentation:** [Get Checklist](https://checkvist.com/auth/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `checklistId` | path | `number` | yes | The checklist ID. |
