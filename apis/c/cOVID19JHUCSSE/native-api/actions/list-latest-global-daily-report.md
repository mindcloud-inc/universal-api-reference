# List Latest Global Daily Report with COVID-19 JHU CSSE

Retrieves the latest archived global COVID-19 daily report rows.

## Endpoint

- **Method:** `GET`
- **Path:** `/csse_covid_19_daily_reports/03-09-2023.csv`
- **Base URL:** `https://raw.githubusercontent.com/CSSEGISandData/COVID-19/master/csse_covid_19_data`
- **Official documentation:** [List Latest Global Daily Report](https://github.com/CSSEGISandData/COVID-19/tree/master/csse_covid_19_data/csse_covid_19_daily_reports)
