# List US Confirmed Time Series with COVID-19 JHU CSSE

Retrieves United States confirmed COVID-19 time series rows.

## Endpoint

- **Method:** `GET`
- **Path:** `/csse_covid_19_time_series/time_series_covid19_confirmed_US.csv`
- **Base URL:** `https://raw.githubusercontent.com/CSSEGISandData/COVID-19/master/csse_covid_19_data`
- **Official documentation:** [List US Confirmed Time Series](https://github.com/CSSEGISandData/COVID-19/tree/master/csse_covid_19_data/csse_covid_19_time_series)
