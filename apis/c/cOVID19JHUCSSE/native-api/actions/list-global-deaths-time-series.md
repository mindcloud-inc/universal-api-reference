# List Global Deaths Time Series with COVID-19 JHU CSSE

Retrieves global COVID-19 death time series rows.

## Endpoint

- **Method:** `GET`
- **Path:** `/csse_covid_19_time_series/time_series_covid19_deaths_global.csv`
- **Base URL:** `https://raw.githubusercontent.com/CSSEGISandData/COVID-19/master/csse_covid_19_data`
- **Official documentation:** [List Global Deaths Time Series](https://github.com/CSSEGISandData/COVID-19/tree/master/csse_covid_19_data/csse_covid_19_time_series)
