# List Time Series Errata with COVID-19 JHU CSSE

Retrieves COVID-19 time series errata rows.

## Endpoint

- **Method:** `GET`
- **Path:** `/csse_covid_19_time_series/Errata.csv`
- **Base URL:** `https://raw.githubusercontent.com/CSSEGISandData/COVID-19/master/csse_covid_19_data`
- **Official documentation:** [List Time Series Errata](https://github.com/CSSEGISandData/COVID-19/blob/master/csse_covid_19_data/csse_covid_19_time_series/Errata.csv)
