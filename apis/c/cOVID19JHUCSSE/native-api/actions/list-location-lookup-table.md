# List Location Lookup Table with COVID-19 JHU CSSE

Retrieves the COVID-19 location lookup rows.

## Endpoint

- **Method:** `GET`
- **Path:** `/UID_ISO_FIPS_LookUp_Table.csv`
- **Base URL:** `https://raw.githubusercontent.com/CSSEGISandData/COVID-19/master/csse_covid_19_data`
- **Official documentation:** [List Location Lookup Table](https://github.com/CSSEGISandData/COVID-19/blob/master/csse_covid_19_data/UID_ISO_FIPS_LookUp_Table.csv)
