# Get Campaign with Charidy

Retrieves a campaign from Charidy.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/campaign/:campaignId`
- **Base URL:** `https://api.charidy.com`
- **Official documentation:** [Get Campaign](https://documenter.getpostman.com/view/1118680/S1a4WS4g)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | The campaign ID to retrieve. |
