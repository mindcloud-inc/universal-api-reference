# List Taxonomies with Crime Junkie Podcast

Retrieves taxonomies from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/taxonomies`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Taxonomies](https://developer.wordpress.org/rest-api/reference/taxonomies/)
