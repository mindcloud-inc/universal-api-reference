# List Comments with Crime Junkie Podcast

Retrieves comments from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/comments`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Comments](https://developer.wordpress.org/rest-api/reference/comments/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
