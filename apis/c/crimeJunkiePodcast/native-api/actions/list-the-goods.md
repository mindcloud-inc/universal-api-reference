# List The Goods with Crime Junkie Podcast

Retrieves entries from The Goods in Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/the-good`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List The Goods](https://crimejunkiepodcast.com/wp-json/wp/v2/the-good)

## Capabilities

This operation supports [pagination](../README.md#pagination).
