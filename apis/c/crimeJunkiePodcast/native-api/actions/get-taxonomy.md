# Get Taxonomy with Crime Junkie Podcast

Retrieves a taxonomy from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/taxonomies/:taxonomy`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Taxonomy](https://developer.wordpress.org/rest-api/reference/taxonomies/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taxonomy` | path | `string` | yes | The WordPress taxonomy slug. |
