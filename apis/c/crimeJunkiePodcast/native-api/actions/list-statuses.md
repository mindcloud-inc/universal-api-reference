# List Statuses with Crime Junkie Podcast

Retrieves statuses from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/statuses`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Statuses](https://developer.wordpress.org/rest-api/reference/post-statuses/)
