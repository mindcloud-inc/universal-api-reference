# Get Dipi Media Category with Crime Junkie Podcast

Retrieves a Dipi media category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_media_category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Dipi Media Category](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_media_category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Dipi media category id. |
