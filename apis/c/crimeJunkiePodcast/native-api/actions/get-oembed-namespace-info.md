# Get OEmbed Namespace Info with Crime Junkie Podcast

Retrieves oEmbed namespace information from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/oembed/1.0`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get OEmbed Namespace Info](https://crimejunkiepodcast.com/wp-json/oembed/1.0)
