# List Project Tags with Crime Junkie Podcast

Retrieves project tags from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project_tag`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Project Tags](https://crimejunkiepodcast.com/wp-json/wp/v2/project_tag)

## Capabilities

This operation supports [pagination](../README.md#pagination).
