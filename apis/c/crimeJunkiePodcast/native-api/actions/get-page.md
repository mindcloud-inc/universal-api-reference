# Get Page with Crime Junkie Podcast

Retrieves a page from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pages/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Page](https://developer.wordpress.org/rest-api/reference/pages/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress page id. |
