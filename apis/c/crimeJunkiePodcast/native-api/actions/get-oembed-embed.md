# Get OEmbed Embed with Crime Junkie Podcast

Retrieves oEmbed embed data from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/oembed/1.0/embed`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get OEmbed Embed](https://crimejunkiepodcast.com/wp-json/oembed/1.0/embed)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | The public Crime Junkie Podcast URL to resolve as oEmbed data. |
