# Get Popup Maker with Crime Junkie Podcast

Retrieves a popup maker from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_popup_maker/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Popup Maker](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_popup_maker)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress popup maker id. |
