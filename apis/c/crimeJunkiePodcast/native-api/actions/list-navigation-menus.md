# List Navigation Menus with Crime Junkie Podcast

Retrieves navigation menus from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/navigation`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Navigation Menus](https://crimejunkiepodcast.com/wp-json/wp/v2/navigation)

## Capabilities

This operation supports [pagination](../README.md#pagination).
