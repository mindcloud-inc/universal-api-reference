# Get Navigation Menu with Crime Junkie Podcast

Retrieves a navigation menu from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/navigation/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Navigation Menu](https://crimejunkiepodcast.com/wp-json/wp/v2/navigation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress navigation id. |
