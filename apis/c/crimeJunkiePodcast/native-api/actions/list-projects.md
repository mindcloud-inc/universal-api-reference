# List Projects with Crime Junkie Podcast

Retrieves projects from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Projects](https://crimejunkiepodcast.com/wp-json/wp/v2/project)

## Capabilities

This operation supports [pagination](../README.md#pagination).
