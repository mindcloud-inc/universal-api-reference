# Get The Good with Crime Junkie Podcast

Retrieves an entry from The Goods in Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/the-good/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get The Good](https://crimejunkiepodcast.com/wp-json/wp/v2/the-good)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress The Good record id. |
