# List Content Types with Crime Junkie Podcast

Retrieves content types from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/types`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Content Types](https://developer.wordpress.org/rest-api/reference/post-types/)
