# Get Comment with Crime Junkie Podcast

Retrieves a comment from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/comments/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Comment](https://developer.wordpress.org/rest-api/reference/comments/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The comment id. |
