# List Blocks with Crime Junkie Podcast

Retrieves blocks from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/blocks`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Blocks](https://developer.wordpress.org/rest-api/reference/blocks/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
