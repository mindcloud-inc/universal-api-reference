# Get Pattern Category with Crime Junkie Podcast

Retrieves a pattern category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/wp_pattern_category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Pattern Category](https://crimejunkiepodcast.com/wp-json/wp/v2/wp_pattern_category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The pattern category id. |
