# List Categories with Crime Junkie Podcast

Retrieves categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/categories`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Categories](https://developer.wordpress.org/rest-api/reference/categories/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
