# Get Attachment Category with Crime Junkie Podcast

Retrieves an attachment category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/attachment-category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Attachment Category](https://crimejunkiepodcast.com/wp-json/wp/v2/attachment-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The attachment category id. |
