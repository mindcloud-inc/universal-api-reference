# List Fan Club Tiers with Crime Junkie Podcast

Retrieves fan club tiers from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/fan_club_tier`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Fan Club Tiers](https://crimejunkiepodcast.com/wp-json/wp/v2/fan_club_tier)

## Capabilities

This operation supports [pagination](../README.md#pagination).
