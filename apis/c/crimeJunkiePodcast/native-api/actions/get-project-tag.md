# Get Project Tag with Crime Junkie Podcast

Retrieves a project tag from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project_tag/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Project Tag](https://crimejunkiepodcast.com/wp-json/wp/v2/project_tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project tag id. |
