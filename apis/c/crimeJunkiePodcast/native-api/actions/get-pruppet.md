# Get Pruppet with Crime Junkie Podcast

Retrieves a pruppet from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pruppet-of-the-month/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Pruppet](https://crimejunkiepodcast.com/wp-json/wp/v2/pruppet-of-the-month)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress pruppet id. |
