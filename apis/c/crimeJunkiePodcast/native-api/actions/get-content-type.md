# Get Content Type with Crime Junkie Podcast

Retrieves a content type from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/types/:type`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Content Type](https://developer.wordpress.org/rest-api/reference/post-types/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | path | `string` | yes | The WordPress content type slug. |
