# List Dipi Content Categories with Crime Junkie Podcast

Retrieves Dipi content categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_cpt_category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Dipi Content Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_cpt_category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
