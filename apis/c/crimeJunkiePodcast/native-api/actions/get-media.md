# Get Media with Crime Junkie Podcast

Retrieves a media item from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/media/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Media](https://developer.wordpress.org/rest-api/reference/media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress media id. |
