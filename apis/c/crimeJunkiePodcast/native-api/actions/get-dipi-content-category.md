# Get Dipi Content Category with Crime Junkie Podcast

Retrieves a Dipi content category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_cpt_category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Dipi Content Category](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_cpt_category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Dipi content category id. |
