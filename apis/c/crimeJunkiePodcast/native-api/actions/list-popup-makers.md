# List Popup Makers with Crime Junkie Podcast

Retrieves popup makers from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_popup_maker`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Popup Makers](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_popup_maker)

## Capabilities

This operation supports [pagination](../README.md#pagination).
