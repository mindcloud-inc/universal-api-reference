# Get Fan Club Episode with Crime Junkie Podcast

Retrieves a fan club episode from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/fan-club/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Fan Club Episode](https://crimejunkiepodcast.com/wp-json/wp/v2/fan-club)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress fan club episode id. |
