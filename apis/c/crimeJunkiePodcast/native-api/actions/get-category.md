# Get Category with Crime Junkie Podcast

Retrieves a category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/categories/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Category](https://developer.wordpress.org/rest-api/reference/categories/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The category id. |
