# Search Content with Crime Junkie Podcast

Searches content in Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/search`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Search Content](https://developer.wordpress.org/rest-api/reference/search-results/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
