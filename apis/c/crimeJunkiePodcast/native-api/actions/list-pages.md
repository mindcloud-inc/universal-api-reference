# List Pages with Crime Junkie Podcast

Retrieves pages from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pages`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Pages](https://developer.wordpress.org/rest-api/reference/pages/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
