# Get Tag with Crime Junkie Podcast

Retrieves a tag from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/tags/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Tag](https://developer.wordpress.org/rest-api/reference/tags/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tag id. |
