# Get WordPress Namespace Info with Crime Junkie Podcast

Retrieves WordPress namespace information from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get WordPress Namespace Info](https://developer.wordpress.org/rest-api/reference/)
