# Get Post with Crime Junkie Podcast

Retrieves a post from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/posts/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Post](https://developer.wordpress.org/rest-api/reference/posts/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress post id. |
