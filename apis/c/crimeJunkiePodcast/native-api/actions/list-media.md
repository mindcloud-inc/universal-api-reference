# List Media with Crime Junkie Podcast

Retrieves media from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/media`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Media](https://developer.wordpress.org/rest-api/reference/media/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
