# List Pruppet Categories with Crime Junkie Podcast

Retrieves pruppet categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pruppet_category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Pruppet Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/pruppet_category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
