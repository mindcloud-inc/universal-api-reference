# List Project Categories with Crime Junkie Podcast

Retrieves project categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project_category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Project Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/project_category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
