# Get Block with Crime Junkie Podcast

Retrieves a block from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/blocks/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Block](https://developer.wordpress.org/rest-api/reference/blocks/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress block id. |
