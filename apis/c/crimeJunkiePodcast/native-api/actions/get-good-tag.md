# Get Good Tag with Crime Junkie Podcast

Retrieves a good tag from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/good/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Good Tag](https://crimejunkiepodcast.com/wp-json/wp/v2/good)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Good taxonomy term id. |
