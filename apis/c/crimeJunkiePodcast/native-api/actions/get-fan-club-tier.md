# Get Fan Club Tier with Crime Junkie Podcast

Retrieves a fan club tier from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/fan_club_tier/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Fan Club Tier](https://crimejunkiepodcast.com/wp-json/wp/v2/fan_club_tier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The fan club tier id. |
