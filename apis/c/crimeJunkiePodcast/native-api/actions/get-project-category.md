# Get Project Category with Crime Junkie Podcast

Retrieves a project category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project_category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Project Category](https://crimejunkiepodcast.com/wp-json/wp/v2/project_category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project category id. |
