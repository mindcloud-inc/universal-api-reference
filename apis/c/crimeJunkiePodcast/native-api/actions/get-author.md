# Get Author with Crime Junkie Podcast

Retrieves an author from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/users/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Author](https://developer.wordpress.org/rest-api/reference/users/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The author id. |
