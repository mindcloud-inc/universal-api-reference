# List Posts with Crime Junkie Podcast

Retrieves posts from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/posts`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Posts](https://developer.wordpress.org/rest-api/reference/posts/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
