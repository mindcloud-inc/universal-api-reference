# Get Pruppet Category with Crime Junkie Podcast

Retrieves a pruppet category from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pruppet_category/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Pruppet Category](https://crimejunkiepodcast.com/wp-json/wp/v2/pruppet_category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The pruppet category id. |
