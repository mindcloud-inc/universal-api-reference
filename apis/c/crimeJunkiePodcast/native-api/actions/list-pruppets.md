# List Pruppets with Crime Junkie Podcast

Retrieves pruppets from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/pruppet-of-the-month`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Pruppets](https://crimejunkiepodcast.com/wp-json/wp/v2/pruppet-of-the-month)

## Capabilities

This operation supports [pagination](../README.md#pagination).
