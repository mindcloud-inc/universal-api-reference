# Get Status with Crime Junkie Podcast

Retrieves a status from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/statuses/:status`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Status](https://developer.wordpress.org/rest-api/reference/post-statuses/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | path | `string` | yes | The WordPress status slug. |
