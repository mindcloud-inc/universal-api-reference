# Get Project with Crime Junkie Podcast

Retrieves a project from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/project/:id`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [Get Project](https://crimejunkiepodcast.com/wp-json/wp/v2/project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The WordPress project id. |
