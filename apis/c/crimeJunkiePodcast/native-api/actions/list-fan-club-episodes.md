# List Fan Club Episodes with Crime Junkie Podcast

Retrieves fan club episodes from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/fan-club`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Fan Club Episodes](https://crimejunkiepodcast.com/wp-json/wp/v2/fan-club)

## Capabilities

This operation supports [pagination](../README.md#pagination).
