# List Dipi Media Categories with Crime Junkie Podcast

Retrieves Dipi media categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/dipi_media_category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Dipi Media Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/dipi_media_category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
