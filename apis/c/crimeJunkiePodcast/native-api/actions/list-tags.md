# List Tags with Crime Junkie Podcast

Retrieves tags from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/tags`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Tags](https://developer.wordpress.org/rest-api/reference/tags/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
