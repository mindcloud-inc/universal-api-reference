# List Attachment Categories with Crime Junkie Podcast

Retrieves attachment categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/attachment-category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Attachment Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/attachment-category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
