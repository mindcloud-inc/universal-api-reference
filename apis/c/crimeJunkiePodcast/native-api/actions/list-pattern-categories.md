# List Pattern Categories with Crime Junkie Podcast

Retrieves pattern categories from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/wp_pattern_category`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Pattern Categories](https://crimejunkiepodcast.com/wp-json/wp/v2/wp_pattern_category)

## Capabilities

This operation supports [pagination](../README.md#pagination).
