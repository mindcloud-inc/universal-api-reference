# List Authors with Crime Junkie Podcast

Retrieves authors from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/users`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Authors](https://developer.wordpress.org/rest-api/reference/users/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
