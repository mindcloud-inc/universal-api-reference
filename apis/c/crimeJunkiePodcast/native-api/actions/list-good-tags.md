# List Good Tags with Crime Junkie Podcast

Retrieves good tags from Crime Junkie Podcast.

## Endpoint

- **Method:** `GET`
- **Path:** `/wp-json/wp/v2/good`
- **Base URL:** `https://crimejunkiepodcast.com`
- **Official documentation:** [List Good Tags](https://crimejunkiepodcast.com/wp-json/wp/v2/good)

## Capabilities

This operation supports [pagination](../README.md#pagination).
