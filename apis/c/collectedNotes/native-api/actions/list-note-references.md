# List Note References with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:siteId/notes/:noteId/references.json`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [List Note References](https://collectednotes.com/blog/api#note-references)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `number` | yes |
| `noteId` | path | `number` | yes |
