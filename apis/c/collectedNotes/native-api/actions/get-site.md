# Get Site with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/:sitePath`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [Get Site](https://collectednotes.com/blog/api#fetch-a-site)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sitePath` | path | `string` | yes |
