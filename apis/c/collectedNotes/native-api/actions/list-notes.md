# List Notes with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:siteId/notes`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [List Notes](https://collectednotes.com/blog/api#fetch-latest-notes-from-a-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `number` | yes | The Collected Notes site ID. |
