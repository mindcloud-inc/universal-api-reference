# Get Site RSS Feed with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/:sitePath.rss`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [Get Site RSS Feed](https://collectednotes.com/blog/api#fetch-your-sites)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sitePath` | path | `string` | yes |
