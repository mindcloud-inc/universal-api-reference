# Get Note JSON with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/:sitePath/:notePath.json`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [Get Note JSON](https://collectednotes.com/blog/api#you-can-get-a-note-in-different-formats)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sitePath` | path | `string` | yes |
| `notePath` | path | `string` | yes |
