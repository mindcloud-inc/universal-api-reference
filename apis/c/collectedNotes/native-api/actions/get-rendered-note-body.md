# Get Rendered Note Body with Collected Notes

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:siteId/notes/:noteId/body`
- **Base URL:** `https://collectednotes.com`
- **Official documentation:** [Get Rendered Note Body](https://collectednotes.com/blog/api#get-the-rendered-body-of-a-note)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `number` | yes |
| `noteId` | path | `number` | yes |
