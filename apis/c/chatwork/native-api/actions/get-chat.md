# Get Chat with Chatwork

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:room_id`
- **Base URL:** `https://api.chatwork.com/v2`
- **Official documentation:** [Get Chat](https://developer.chatwork.com/reference/get-rooms-room_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room_id` | path | `number` | yes | Room ID. |
