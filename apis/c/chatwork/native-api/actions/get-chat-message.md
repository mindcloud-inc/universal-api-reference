# Get Chat Message with Chatwork

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:room_id/messages/:message_id`
- **Base URL:** `https://api.chatwork.com/v2`
- **Official documentation:** [Get Chat Message](https://developer.chatwork.com/reference/get-rooms-room_id-messages-message_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room_id` | path | `number` | yes | Room ID |
| `message_id` | path | `string` | yes | Message ID |
