# Get Chat Task with Chatwork

## Endpoint

- **Method:** `GET`
- **Path:** `/rooms/:room_id/tasks/:task_id`
- **Base URL:** `https://api.chatwork.com/v2`
- **Official documentation:** [Get Chat Task](https://developer.chatwork.com/reference/get-rooms-room_id-tasks-task_id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room_id` | path | `number` | yes | Room ID. |
| `task_id` | path | `number` | yes | Task ID. |
