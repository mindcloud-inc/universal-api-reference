# Mark Messages Read with Chatwork

## Endpoint

- **Method:** `PUT`
- **Path:** `/rooms/:room_id/messages/read`
- **Base URL:** `https://api.chatwork.com/v2`
- **Official documentation:** [Mark Messages Read](https://developer.chatwork.com/reference/put-rooms-room_id-messages-read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `room_id` | path | `number` | yes | Room ID. |
