# List F B S Teams with College Football Data

Retrieves FBS teams from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/fbs`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [List F B S Teams](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | no | Year or season |
