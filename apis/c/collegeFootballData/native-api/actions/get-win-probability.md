# List Win Probability with College Football Data

Retrieves play win probabilities from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/metrics/wp`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [List Win Probability](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `gameId` | query | `number` | yes | Required game ID filter |
