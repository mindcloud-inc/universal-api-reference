# List Talent with College Football Data

Retrieves team talent composite data from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/talent`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [List Talent](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | Year filter |
