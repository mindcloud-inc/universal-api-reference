# Get Live Plays with College Football Data

Retrieves live play-by-play data from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/live/plays`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [Get Live Plays](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `gameId` | query | `number` | yes | Game Id filter |
