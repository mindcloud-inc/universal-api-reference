# List Transfer Portal with College Football Data

Retrieves transfer portal entries from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/player/portal`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [List Transfer Portal](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | Required year filter |
