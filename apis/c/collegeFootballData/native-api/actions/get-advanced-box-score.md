# Get Advanced Box Score with College Football Data

Retrieves an advanced box score from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/game/box/advanced`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [Get Advanced Box Score](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `number` | yes | Required game id filter |
