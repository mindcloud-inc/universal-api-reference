# List Calendar with College Football Data

Retrieves season calendar information from College Football Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/calendar`
- **Base URL:** `https://api.collegefootballdata.com`
- **Official documentation:** [List Calendar](https://api.collegefootballdata.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `year` | query | `number` | yes | Required year filter |
