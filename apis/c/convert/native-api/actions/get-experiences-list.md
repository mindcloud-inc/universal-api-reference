# List Experiences with Convert

Retrieves experiences from a Convert project.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/:account_id/projects/:project_id/experiences`
- **Base URL:** `https://api.convert.com/api/v2`
- **Official documentation:** [List Experiences](https://api.convert.com/doc/v2/#tag/Experiences/operation/getExperiencesList)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Convert project ID. |
