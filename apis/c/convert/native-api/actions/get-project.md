# Get Project with Convert

Retrieves a project from a Convert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/projects/:project_id`
- **Base URL:** `https://api.convert.com/api/v2`
- **Official documentation:** [Get Project](https://api.convert.com/doc/v2/#tag/Projects/operation/getProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Convert project ID. |
