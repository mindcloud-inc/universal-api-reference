# List API Keys with Convert

Retrieves API keys from Convert for an account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/api-keys`
- **Base URL:** `https://api.convert.com/api/v2`
- **Official documentation:** [List API Keys](https://api.convert.com/doc/v2/#tag/API-Keys/operation/listAPIKeys)
