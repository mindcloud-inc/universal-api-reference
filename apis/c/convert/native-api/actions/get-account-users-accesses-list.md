# List Account User Accesses with Convert

Retrieves user access entries for a Convert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/users-accesses`
- **Base URL:** `https://api.convert.com/api/v2`
- **Official documentation:** [List Account User Accesses](https://api.convert.com/doc/v2/#tag/Collaborators/operation/getAccountUsersAccessesList)
