# Get Project Live Data with Convert

Retrieves live data for a Convert project.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/:account_id/projects/:project_id/livedata`
- **Base URL:** `https://api.convert.com/api/v2`
- **Official documentation:** [Get Project Live Data](https://api.convert.com/doc/v2/#tag/Projects/operation/getProjectLiveData)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Convert project ID. |
