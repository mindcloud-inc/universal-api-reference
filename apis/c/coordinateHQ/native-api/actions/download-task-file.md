# Download Task File with CoordinateHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/task/:task_id/file/:file_id`
- **Base URL:** `https://app.coordinatehq.com/api/v1`
- **Official documentation:** [Download Task File](https://app.coordinatehq.com/static/API_Documentation.html#tasks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `string` | yes |
| `task_id` | path | `string` | yes |
| `file_id` | path | `string` | yes |
