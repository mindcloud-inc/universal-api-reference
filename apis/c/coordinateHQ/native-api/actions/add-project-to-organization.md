# Add Project to Organization with CoordinateHQ

## Endpoint

- **Method:** `POST`
- **Path:** `/organizations/:organizationId/projects`
- **Base URL:** `https://app.coordinatehq.com/api/v1`
- **Official documentation:** [Add Project to Organization](https://app.coordinatehq.com/static/API_Documentation.html#organizations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
| `project_id` | body | `string` | no |
