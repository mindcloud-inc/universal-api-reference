# Get Task with CoordinateHQ

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/task/:task_id`
- **Base URL:** `https://app.coordinatehq.com/api/v1`
- **Official documentation:** [Get Task](https://app.coordinatehq.com/static/API_Documentation.html#project-pages)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
| `project_id` | path | `string` | yes |
