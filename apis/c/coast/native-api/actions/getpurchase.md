# Get Purchase By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/transactions/purchases/:purchaseId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Purchase By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchaseId` | path | `string` | yes | Coast purchase ID of the purchase to retrieve. |
