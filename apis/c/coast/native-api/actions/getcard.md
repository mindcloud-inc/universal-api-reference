# Get Card By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/cards/:cardId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Card By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | Coast card ID of the card to retrieve. |
