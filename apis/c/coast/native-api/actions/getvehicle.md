# Get Vehicle By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/vehicles/:vehicleId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Vehicle By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicleId` | path | `string` | yes | Coast vehicle ID of the vehicle to retrieve. |
