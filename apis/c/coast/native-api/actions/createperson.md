# Create Person with Coast

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/people`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Create Person](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `city` | body | `string` | no | — |
| `name` | body | `string` | yes | Name for person |
| `state` | body | `string` | no | — |
| `streetAddress` | body | `string` | no | — |
| `streetAddress2` | body | `string` | no | — |
| `zip` | body | `string` | no | — |
