# Get Role By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/roles/:roleId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Role By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `roleId` | path | `string` | yes | Coast role ID of the role to retrieve. |
