# Delete Department By ID with Coast

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/departments/:departmentId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Delete Department By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `string` | yes | Coast department ID of the department to delete. |
