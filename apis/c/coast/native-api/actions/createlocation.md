# Create Location with Coast

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/locations`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Create Location](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `city` | body | `string` | no | — |
| `name` | body | `string` | yes | Name for location |
| `state` | body | `string` | no | — |
| `streetAddress` | body | `string` | no | — |
| `streetAddress2` | body | `string` | no | — |
| `zip` | body | `string` | no | — |
