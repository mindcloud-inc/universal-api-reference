# Update My Account Settings with Coast

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/account/settings`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Update My Account Settings](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `vehicleIdentificationMethod` | body | `object` | no | The method of vehicle identification used by this account for users to sign into a card. |
