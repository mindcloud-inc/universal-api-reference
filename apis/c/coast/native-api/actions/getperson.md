# Get Person By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/people/:personId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Person By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | Coast person ID of the person to retrieve. |
