# Get Policy By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/policies/:policyId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Policy By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `policyId` | path | `string` | yes | Coast policy ID of the policy to retrieve. |
