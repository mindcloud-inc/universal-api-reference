# Get Location By ID with Coast

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/locations/:locationId`
- **Base URL:** `https://public.coastpay.com`
- **Official documentation:** [Get Location By ID](https://coastpay.com/integrations/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `string` | yes | Coast location ID of the location to retrieve. |
