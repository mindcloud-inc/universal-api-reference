# Search Officers with Companies House

Finds officers in Companies House.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/officers`
- **Base URL:** `https://api.company-information.service.gov.uk`
- **Official documentation:** [Search Officers](https://developer-specs.company-information.service.gov.uk/companies-house-public-data-api/reference/search-officers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | The search term. |
