# Get Disqualified Corporate Officer with Companies House

Retrieves a disqualified corporate officer from Companies House.

## Endpoint

- **Method:** `GET`
- **Path:** `/disqualified-officers/corporate/:officer_id`
- **Base URL:** `https://api.company-information.service.gov.uk`
- **Official documentation:** [Get Disqualified Corporate Officer](https://developer-specs.company-information.service.gov.uk/companies-house-public-data-api/reference/disqualified-officer-corporate/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `officer_id` | path | `string` | yes | The disqualified corporate officer ID. |
