# List HTML Pages with CustomJS

Retrieves hosted HTML pages from CustomJS.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.app.customjs.io/pages/api/page`
- **Base URL:** `https://e.customjs.io`
- **API:** rest
- **Official documentation:** [List HTML Pages](https://www.customjs.space/integration/native-api/documentation/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
