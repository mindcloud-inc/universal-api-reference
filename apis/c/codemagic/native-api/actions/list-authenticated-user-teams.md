# List Authenticated User Teams with Codemagic

Retrieves teams for the authenticated Codemagic user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/user/teams`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [List Authenticated User Teams](https://codemagic.io/api/v3/schema#tag/Teams/operation/ApiV3UserTeamsGetTeams)

## Capabilities

This operation supports [pagination](../README.md#pagination).
