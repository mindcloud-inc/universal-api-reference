# Get OTA Account Info with Codemagic

Retrieves over-the-air update account information from Codemagic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/over-the-air-updates`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [Get OTA Account Info](https://codemagic.io/api/v3/schema#tag/Over-the-air%20Updates/operation/ApiV3OverTheAirUpdatesGetAccountInfo)
