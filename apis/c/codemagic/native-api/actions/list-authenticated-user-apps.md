# List Authenticated User Apps with Codemagic

Retrieves apps for the authenticated Codemagic user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/user/apps`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [List Authenticated User Apps](https://codemagic.io/api/v3/schema#tag/Applications/operation/ApiV3UserAppsGetApps)

## Capabilities

This operation supports [pagination](../README.md#pagination).
