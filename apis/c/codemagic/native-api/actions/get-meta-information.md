# Get Meta Information with Codemagic

Retrieves Codemagic meta information and public IP addresses.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/meta`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [Get Meta Information](https://codemagic.io/api/v3/schema#tag/Meta/operation/ApiV3MetaGetMeta)
