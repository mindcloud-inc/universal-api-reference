# List User Notifications with Codemagic

Retrieves notifications for the authenticated Codemagic user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/user/notifications`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [List User Notifications](https://codemagic.io/api/v3/schema#tag/Users/operation/ApiV3UserNotificationsGetNotifications)

## Capabilities

This operation supports [pagination](../README.md#pagination).
