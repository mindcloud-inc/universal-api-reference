# Get User Preferences with Codemagic

Retrieves preferences for the authenticated Codemagic user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/user/preferences`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [Get User Preferences](https://codemagic.io/api/v3/schema#tag/Users/operation/ApiV3UserPreferencesGetPreferences)
