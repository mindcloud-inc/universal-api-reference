# Get Shorebird Metadata with Codemagic

Retrieves Shorebird integration information from Codemagic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/meta/shorebird`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [Get Shorebird Metadata](https://codemagic.io/api/v3/schema#tag/Meta/operation/ApiV3MetaShorebirdGetShorebirdMeta)
