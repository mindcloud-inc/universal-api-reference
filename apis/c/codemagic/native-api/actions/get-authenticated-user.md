# Get Authenticated User with Codemagic

Retrieves the authenticated user from Codemagic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/user`
- **Base URL:** `https://codemagic.io`
- **Official documentation:** [Get Authenticated User](https://codemagic.io/api/v3/schema#tag/Users/operation/ApiV3UserGetUser)
