# Fetch Descriptors with Chargeblast

Retrieves descriptors from Chargeblast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/descriptors`
- **Base URL:** `https://api.chargeblast.com`
- **Official documentation:** [Fetch Descriptors](https://docs.chargeblast.com/api-reference/enrollment/fetch-descriptors)
