# Fetch Deflection Logs with Chargeblast

Retrieves deflection logs from Chargeblast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/deflections/logs`
- **Base URL:** `https://api.chargeblast.com`
- **Official documentation:** [Fetch Deflection Logs](https://docs.chargeblast.com/api-reference/deflections/logs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
