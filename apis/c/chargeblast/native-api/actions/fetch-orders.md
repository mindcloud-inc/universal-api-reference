# Fetch Orders with Chargeblast

Retrieves orders from Chargeblast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orders`
- **Base URL:** `https://api.chargeblast.com`
- **Official documentation:** [Fetch Orders](https://docs.chargeblast.com/api-reference/sync-data/get-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination).
