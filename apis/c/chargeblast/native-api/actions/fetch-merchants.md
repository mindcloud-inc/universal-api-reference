# Fetch Merchants with Chargeblast

Retrieves merchants from Chargeblast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/merchants`
- **Base URL:** `https://api.chargeblast.com`
- **Official documentation:** [Fetch Merchants](https://docs.chargeblast.com/api-reference/enrollment/fetch-merchants)

## Capabilities

This operation supports [pagination](../README.md#pagination).
