# Fetch Alerts with Chargeblast

Retrieves alerts from Chargeblast.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/alerts`
- **Base URL:** `https://api.chargeblast.com`
- **Official documentation:** [Fetch Alerts](https://docs.chargeblast.com/api-reference/alerts/fetch-alerts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
