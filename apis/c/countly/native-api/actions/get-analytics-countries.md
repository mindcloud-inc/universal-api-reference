# Get Analytics Countries with Countly

Retrieves all country analytics from Countly.

## Endpoint

- **Method:** `GET`
- **Path:** `/o/analytics/countries`
- **Base URL:** `https://mindcloud-fe49f15890040.flex.countly.com`
- **Official documentation:** [Get Analytics Countries](https://api.count.ly/reference/oanalyticscountries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | query | `string` | yes | Countly app ID to query analytics for. |
