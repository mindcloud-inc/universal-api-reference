# List Campaigns with Countly

Retrieves all campaigns from Countly.

## Endpoint

- **Method:** `GET`
- **Path:** `/o/campaign`
- **Base URL:** `https://mindcloud-fe49f15890040.flex.countly.com`
- **Official documentation:** [List Campaigns](https://api.count.ly/reference/ocampaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | query | `string` | yes | Countly app ID to list campaigns for. |
