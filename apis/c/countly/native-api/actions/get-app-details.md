# Get App Details with Countly

Retrieves application details from Countly.

## Endpoint

- **Method:** `GET`
- **Path:** `/o/apps/details`
- **Base URL:** `https://mindcloud-fe49f15890040.flex.countly.com`
- **Official documentation:** [Get App Details](https://api.count.ly/reference/oappsdetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | query | `string` | yes | Countly app ID to fetch details for. |
