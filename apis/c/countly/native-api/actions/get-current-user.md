# Get Current User with Countly

Retrieves the current user from Countly.

## Endpoint

- **Method:** `GET`
- **Path:** `/o/users/me`
- **Base URL:** `https://mindcloud-fe49f15890040.flex.countly.com`
- **Official documentation:** [Get Current User](https://api.count.ly/reference/ousersmeapi_keyapi_key)
