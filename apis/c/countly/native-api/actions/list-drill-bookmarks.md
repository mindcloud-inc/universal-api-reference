# List Drill Bookmarks with Countly

Retrieves all drill bookmarks from Countly.

## Endpoint

- **Method:** `GET`
- **Path:** `/o`
- **Base URL:** `https://mindcloud-fe49f15890040.flex.countly.com`
- **Official documentation:** [List Drill Bookmarks](https://api.count.ly/reference/omethoddrill_bookmarks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_id` | query | `string` | yes | Countly app ID to query drill bookmarks for. |
