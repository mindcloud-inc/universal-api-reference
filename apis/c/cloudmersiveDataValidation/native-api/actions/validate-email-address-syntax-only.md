# Validate Email Address Syntax Only with Cloudmersive Data Validation

Validates email address syntax with Cloudmersive Data Validation.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/email/address/syntaxOnly`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Email Address Syntax Only](https://api.cloudmersive.com/docs/validate.asp)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `string` | yes | Email address to validate syntactically. |
