# Validate Phone Number with Cloudmersive Data Validation

Validates a phone number with Cloudmersive Data Validation.

## Endpoint

- **Method:** `POST`
- **Path:** `/validate/phonenumber/basic`
- **Base URL:** `https://api.cloudmersive.com`
- **Official documentation:** [Validate Phone Number](https://api.cloudmersive.com/docs/validate.asp)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `value` | body | `object` | yes | Phone number validation request object. |
