# Update Settings with Chatling

Updates project settings in Chatling.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/project/settings`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [Update Settings](https://docs.chatling.ai/api-reference/v2/project/update-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The project name. |
