# List Chatbot Templates with Chatling

Retrieves chatbot templates from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbot-templates`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [List Chatbot Templates](https://docs.chatling.ai/api-reference/v2/chatbots/list-chatbot-templates)
