# Get User Seats Usage with Chatling

Retrieves user seats usage from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/usage/user-seats`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [Get User Seats Usage](https://docs.chatling.ai/api-reference/v2/usage/user-seats)
