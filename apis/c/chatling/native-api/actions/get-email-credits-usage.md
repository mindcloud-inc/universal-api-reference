# Get Email Credits Usage with Chatling

Retrieves email credits usage from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/usage/email-credits`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [Get Email Credits Usage](https://docs.chatling.ai/api-reference/v2/usage/email-credits)
