# Get AI Credits Usage with Chatling

Retrieves AI credits usage from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/usage/ai-credits`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [Get AI Credits Usage](https://docs.chatling.ai/api-reference/v2/usage/ai-credits)
