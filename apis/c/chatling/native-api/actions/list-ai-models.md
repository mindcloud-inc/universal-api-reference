# List AI Models with Chatling

Retrieves AI models from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatbots/:chatbotId/ai/kb/models`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [List AI Models](https://docs.chatling.ai/api-reference/v2/ai-kb/list-ai-models)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatbotId` | path | `string` | yes | The chatbot ID. |
