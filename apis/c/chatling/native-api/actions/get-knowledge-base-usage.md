# Get Knowledge Base Usage with Chatling

Retrieves knowledge base usage from Chatling.

## Endpoint

- **Method:** `GET`
- **Path:** `/usage/knowledge-base`
- **Base URL:** `https://api.chatling.ai/v2`
- **Official documentation:** [Get Knowledge Base Usage](https://docs.chatling.ai/api-reference/v2/usage/knowledge-base)
