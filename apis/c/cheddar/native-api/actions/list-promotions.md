# List Promotions with Cheddar

Retrieves promotion coupon records from Cheddar.

## Endpoint

- **Method:** `GET`
- **Path:** `/promotions/get/productCode/{productCode}`
- **Base URL:** `https://getcheddar.com/xml`
- **Official documentation:** [List Promotions](https://docs.getcheddar.com/#get-all-promotions)
