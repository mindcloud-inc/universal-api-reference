# List Pricing Plans with Cheddar

Retrieves pricing plan records from Cheddar.

## Endpoint

- **Method:** `GET`
- **Path:** `/plans/get/productCode/{productCode}`
- **Base URL:** `https://getcheddar.com/xml`
- **Official documentation:** [List Pricing Plans](https://docs.getcheddar.com/#get-all-pricing-plans)
