# Get Article with Charla

Retrieves an article from Charla.

## Endpoint

- **Method:** `GET`
- **Path:** `/kb/articles/:id`
- **Base URL:** `https://api.charla.com/v1`
- **Official documentation:** [Get Article](https://charla.com/public-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The article ID to retrieve. |
