# Delete Article with Charla

Deletes an existing article from Charla.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/kb/article/:id`
- **Base URL:** `https://api.charla.com/v1`
- **Official documentation:** [Delete Article](https://charla.com/public-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The article ID to delete. |
