# Get Contact with Charla

Retrieves a contact from Charla.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.charla.com/v1`
- **Official documentation:** [Get Contact](https://charla.com/public-api.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The contact ID to retrieve. |
