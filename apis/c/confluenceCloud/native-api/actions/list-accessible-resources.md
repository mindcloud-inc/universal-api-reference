# List Accessible Resources with Confluence

Retrieves accessible Confluence sites for an OAuth app.

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth/token/accessible-resources`
- **Base URL:** `https://api.atlassian.com`
- **Official documentation:** [List Accessible Resources](https://developer.atlassian.com/cloud/confluence/oauth-2-3lo-apps/#siteaccess)
