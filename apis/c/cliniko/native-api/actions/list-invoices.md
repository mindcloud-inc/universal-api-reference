# List Invoices with Cliniko

Retrieves invoices from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Invoices](https://docs.api.cliniko.com/openapi/invoice)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
