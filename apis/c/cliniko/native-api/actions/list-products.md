# List Products with Cliniko

Retrieves products from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Products](https://docs.api.cliniko.com/openapi/product)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
