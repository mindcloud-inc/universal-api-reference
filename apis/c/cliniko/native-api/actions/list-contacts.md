# List Contacts with Cliniko

Retrieves contacts from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Contacts](https://docs.api.cliniko.com/openapi/contact)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
