# List Practitioners with Cliniko

Retrieves practitioners from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/practitioners`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Practitioners](https://docs.api.cliniko.com/openapi/practitioner)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
