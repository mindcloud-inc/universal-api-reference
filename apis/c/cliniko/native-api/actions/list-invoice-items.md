# List Invoice Items with Cliniko

Retrieves invoice items from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoice_items`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Invoice Items](https://docs.api.cliniko.com/openapi/invoice_item)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
