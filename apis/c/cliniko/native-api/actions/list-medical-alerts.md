# List Medical Alerts with Cliniko

Retrieves medical alerts from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/medical_alerts`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Medical Alerts](https://docs.api.cliniko.com/openapi/medical_alert)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
