# Get Invoice with Cliniko

Retrieves an invoice from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Invoice](https://docs.api.cliniko.com/openapi/invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko invoice ID. |
