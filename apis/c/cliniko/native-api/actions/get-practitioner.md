# Get Practitioner with Cliniko

Retrieves a practitioner from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/practitioners/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Practitioner](https://docs.api.cliniko.com/openapi/practitioner)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko practitioner ID. |
