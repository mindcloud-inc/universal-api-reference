# List Appointment Types with Cliniko

Retrieves appointment types from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointment_types`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Appointment Types](https://docs.api.cliniko.com/openapi/appointment_type)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
