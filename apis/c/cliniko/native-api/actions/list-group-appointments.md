# List Group Appointments with Cliniko

Retrieves group appointments from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/group_appointments`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Group Appointments](https://docs.api.cliniko.com/openapi/group_appointment)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
