# List Businesses with Cliniko

Retrieves businesses from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Businesses](https://docs.api.cliniko.com/openapi/business)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
