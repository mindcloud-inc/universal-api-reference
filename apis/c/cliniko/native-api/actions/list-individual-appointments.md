# List Individual Appointments with Cliniko

Retrieves individual appointments from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/individual_appointments`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Individual Appointments](https://docs.api.cliniko.com/openapi/individual_appointment)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
