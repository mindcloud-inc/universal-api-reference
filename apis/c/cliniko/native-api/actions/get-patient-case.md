# Get Patient Case with Cliniko

Retrieves a patient case from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/patient_cases/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Patient Case](https://docs.api.cliniko.com/openapi/patient_case)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko patient case ID. |
