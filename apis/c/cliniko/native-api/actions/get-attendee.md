# Get Attendee with Cliniko

Retrieves an attendee from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/attendees/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Attendee](https://docs.api.cliniko.com/openapi/attendee)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko attendee ID. |
