# Get Individual Appointment with Cliniko

Retrieves an individual appointment from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/individual_appointments/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Individual Appointment](https://docs.api.cliniko.com/openapi/individual_appointment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko individual appointment ID. |
