# List Attendees with Cliniko

Retrieves attendees from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/attendees`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Attendees](https://docs.api.cliniko.com/openapi/attendee)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
