# List Patient Cases with Cliniko

Retrieves patient cases from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/patient_cases`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Patient Cases](https://docs.api.cliniko.com/openapi/patient_case)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
