# Get Appointment Type with Cliniko

Retrieves an appointment type from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointment_types/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Appointment Type](https://docs.api.cliniko.com/openapi/appointment_type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko appointment type ID. |
