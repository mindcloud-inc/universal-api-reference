# List Billable Items with Cliniko

Retrieves billable items from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/billable_items`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Billable Items](https://docs.api.cliniko.com/openapi/billable_item)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
