# Get Patient with Cliniko

Retrieves a patient record from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/patients/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Patient](https://docs.api.cliniko.com/openapi/patient)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko patient ID. |
