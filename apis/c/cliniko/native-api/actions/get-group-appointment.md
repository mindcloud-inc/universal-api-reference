# Get Group Appointment with Cliniko

Retrieves a group appointment from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/group_appointments/:id`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [Get Group Appointment](https://docs.api.cliniko.com/openapi/group_appointment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cliniko group appointment ID. |
