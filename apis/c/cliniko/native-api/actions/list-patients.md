# List Patients with Cliniko

Retrieves patient records from your Cliniko account.

## Endpoint

- **Method:** `GET`
- **Path:** `/patients`
- **Base URL:** `https://api.au5.cliniko.com/v1`
- **Official documentation:** [List Patients](https://docs.api.cliniko.com/openapi/patient)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
