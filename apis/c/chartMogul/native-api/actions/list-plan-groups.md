# List Plan Groups with ChartMogul

Retrieves plan groups from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/plan_groups`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Plan Groups](https://dev.chartmogul.com/reference/plan-groups/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
