# List Notes and Call Logs with ChartMogul

Retrieves notes and call logs from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/customer_notes`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Notes and Call Logs](https://dev.chartmogul.com/reference/notes-and-call-logs/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
