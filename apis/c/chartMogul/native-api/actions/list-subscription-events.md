# List Subscription Events with ChartMogul

Retrieves subscription events from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscription_events`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Subscription Events](https://dev.chartmogul.com/reference/subscription-events/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
