# List Invoices with ChartMogul

Retrieves invoices from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Invoices](https://dev.chartmogul.com/reference/invoices/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
