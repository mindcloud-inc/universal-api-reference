# List Plans with ChartMogul

Retrieves plans from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/plans`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Plans](https://dev.chartmogul.com/reference/plans/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
