# List Contacts with ChartMogul

Retrieves contacts from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Contacts](https://dev.chartmogul.com/reference/contacts/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
