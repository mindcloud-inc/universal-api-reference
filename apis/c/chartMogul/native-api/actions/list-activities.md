# List Activities with ChartMogul

Retrieves activities from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/activities`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Activities](https://dev.chartmogul.com/reference/activities/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
