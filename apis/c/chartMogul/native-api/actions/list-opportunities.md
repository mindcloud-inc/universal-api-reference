# List Opportunities with ChartMogul

Retrieves opportunities from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/opportunities`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Opportunities](https://dev.chartmogul.com/reference/opportunities/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
