# List Tasks with ChartMogul

Retrieves tasks from ChartMogul.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks`
- **Base URL:** `https://api.chartmogul.com/v1`
- **Official documentation:** [List Tasks](https://dev.chartmogul.com/reference/tasks/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
