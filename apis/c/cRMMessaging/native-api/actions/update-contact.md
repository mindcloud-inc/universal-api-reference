# Update Contact with CRM Messaging

Updates an existing contact in CRM Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/index.php/Api/updateContact`
- **Base URL:** `https://app.crm-messaging.cloud`
- **Official documentation:** [Update Contact](https://crm-messaging.cloud/docs/update-contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone` | body | `string` | yes | Contact phone number. |
| `fname` | body | `string` | no | — |
| `lname` | body | `string` | no | — |
| `email` | body | `string` | no | — |
| `group_name` | body | `string` | no | — |
| `custom1` | body | `string` | no | — |
| `custom2` | body | `string` | no | — |
| `custom3` | body | `string` | no | — |
| `custom4` | body | `string` | no | — |
| `custom5` | body | `string` | no | — |
