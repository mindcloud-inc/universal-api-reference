# List Messages with CRM Messaging

Retrieves messages from CRM Messaging.

## Endpoint

- **Method:** `GET`
- **Path:** `/index.php/Api/messageHistory`
- **Base URL:** `https://app.crm-messaging.cloud`
- **Official documentation:** [List Messages](https://crm-messaging.cloud/docs/message-history-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
