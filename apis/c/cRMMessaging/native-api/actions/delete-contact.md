# Delete Contact with CRM Messaging

Deletes an existing contact from CRM Messaging.

## Endpoint

- **Method:** `POST`
- **Path:** `/index.php/Api/deleteContact`
- **Base URL:** `https://app.crm-messaging.cloud`
- **Official documentation:** [Delete Contact](https://crm-messaging.cloud/docs/delete-contact-crm-messaging-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone` | body | `string` | yes | Contact phone number. |
