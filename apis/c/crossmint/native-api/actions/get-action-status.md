# Get Action Status with Crossmint

Retrieves action status from Crossmint.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022-06-09/actions/:actionId`
- **Base URL:** `https://staging.crossmint.com/api`
- **Official documentation:** [Get Action Status](https://docs.crossmint.com/api-reference/common/get-action-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `actionId` | path | `string` | yes | Asynchronous action identifier. |
