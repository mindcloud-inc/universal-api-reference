# Get Collection Info with Crossmint

Retrieves collection information from Crossmint.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022-06-09/collections/:collectionId`
- **Base URL:** `https://staging.crossmint.com/api`
- **Official documentation:** [Get Collection Info](https://docs.crossmint.com/api-reference/minting/collection/get-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | Collection identifier. |
