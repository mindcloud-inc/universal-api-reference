# List Collections with Crossmint

Retrieves collections from Crossmint.

## Endpoint

- **Method:** `GET`
- **Path:** `/2022-06-09/collections`
- **Base URL:** `https://staging.crossmint.com/api`
- **Official documentation:** [List Collections](https://docs.crossmint.com/api-reference/minting/collection/get-all-collections)
