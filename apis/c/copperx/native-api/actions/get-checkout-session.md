# Get Checkout Session with Copperx

Retrieves a checkout session from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/sessions/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Checkout Session](https://copperx.readme.io/reference/sessionscontroller_findone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Checkout session ID path parameter. |
