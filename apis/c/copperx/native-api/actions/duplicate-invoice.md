# Duplicate Invoice with Copperx

Duplicates an existing invoice in Copperx.

## Endpoint

- **Method:** `POST`
- **Path:** `/invoices/{id}/duplicate`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Duplicate Invoice](https://copperx.readme.io/reference/invoicecontroller_duplicateinvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice ID path parameter. |
