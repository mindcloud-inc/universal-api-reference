# Get Invoice with Copperx

Retrieves invoice record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Invoice](https://copperx.readme.io/reference/invoicecontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice ID path parameter. |
