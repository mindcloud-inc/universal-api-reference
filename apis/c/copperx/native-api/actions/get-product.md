# Get Product with Copperx

Retrieves product record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Product](https://copperx.readme.io/reference/productcontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID path parameter. |
