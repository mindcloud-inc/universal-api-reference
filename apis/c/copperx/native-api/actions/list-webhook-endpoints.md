# List Webhook Endpoints with Copperx

Retrieves all webhook endpoints from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-endpoints`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [List Webhook Endpoints](https://copperx.readme.io/reference/webhookendpointcontroller_getall)
