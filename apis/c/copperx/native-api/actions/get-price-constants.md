# Get Price Constants with Copperx

Retrieves pricing constant values from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/constants/prices`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Price Constants](https://copperx.readme.io/reference/constantscontroller_getprices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `currency` | query | `string` | yes | Currency to fetch price constants for. |
