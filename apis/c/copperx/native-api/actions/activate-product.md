# Activate Product with Copperx

Activates an existing product in Copperx.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/{id}/activate`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Activate Product](https://copperx.readme.io/reference/productcontroller_activate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID path parameter. |
