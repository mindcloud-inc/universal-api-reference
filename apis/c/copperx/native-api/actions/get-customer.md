# Get Customer with Copperx

Retrieves customer record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Customer](https://copperx.readme.io/reference/customercontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Customer ID path parameter. |
