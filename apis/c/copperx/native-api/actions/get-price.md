# Get Price with Copperx

Retrieves price record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/prices/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Price](https://copperx.readme.io/reference/pricecontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Price ID path parameter. |
