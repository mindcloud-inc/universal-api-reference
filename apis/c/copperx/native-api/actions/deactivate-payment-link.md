# Deactivate Payment Link with Copperx

Deactivates a payment link in Copperx.

## Endpoint

- **Method:** `POST`
- **Path:** `/payment-links/{linkId}/deactivate`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Deactivate Payment Link](https://copperx.readme.io/reference/paymentlinkcontroller_deactivate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Payment link ID path parameter. |
