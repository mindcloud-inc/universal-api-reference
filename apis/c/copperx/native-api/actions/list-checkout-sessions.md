# List Checkout Sessions with Copperx

Retrieves all checkout sessions from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/checkout/sessions`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [List Checkout Sessions](https://copperx.readme.io/reference/sessionscontroller_findall)
