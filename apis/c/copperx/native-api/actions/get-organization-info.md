# Get Organization Info with Copperx

Retrieves organization record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Organization Info](https://copperx.readme.io/reference/organizationcontroller_getorganizationinfo)
