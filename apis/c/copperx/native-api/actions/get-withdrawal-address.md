# Get Withdrawal Address with Copperx

Retrieves a withdrawal address from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/withdrawal-addresses/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Withdrawal Address](https://copperx.readme.io/reference/withdrawaladdresscontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Withdrawal address ID path parameter. |
