# Get Payment Link with Copperx

Retrieves a payment link from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-links/{linkId}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Payment Link](https://copperx.readme.io/reference/paymentlinkcontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | Payment link ID path parameter. |
