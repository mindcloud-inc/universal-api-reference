# Get Tax Rate with Copperx

Retrieves a tax rate from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/tax-rates/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Tax Rate](https://copperx.readme.io/reference/taxratecontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tax rate ID path parameter. |
