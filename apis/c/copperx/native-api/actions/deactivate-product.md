# Deactivate Product with Copperx

Deactivates an existing product in Copperx.

## Endpoint

- **Method:** `POST`
- **Path:** `/products/{id}/deactivate`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Deactivate Product](https://copperx.readme.io/reference/productcontroller_deactivate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Product ID path parameter. |
