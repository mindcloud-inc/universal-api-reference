# List Withdrawal Addresses with Copperx

Retrieves all withdrawal addresses from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/withdrawal-addresses`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [List Withdrawal Addresses](https://copperx.readme.io/reference/withdrawaladdresscontroller_getall)
