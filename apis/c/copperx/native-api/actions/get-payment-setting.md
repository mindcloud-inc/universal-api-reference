# Get Payment Setting with Copperx

Retrieves organization payment settings from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/organization/payment-setting`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Payment Setting](https://copperx.readme.io/reference/paymentsettingcontroller_get)
