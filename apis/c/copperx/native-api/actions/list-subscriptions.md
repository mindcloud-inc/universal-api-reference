# List Subscriptions with Copperx

Retrieves all subscription records from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [List Subscriptions](https://copperx.readme.io/reference/subscriptioncontroller_findall)
