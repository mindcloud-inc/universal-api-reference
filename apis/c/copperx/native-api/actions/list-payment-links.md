# List Payment Links with Copperx

Retrieves all payment links from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/payment-links`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [List Payment Links](https://copperx.readme.io/reference/paymentlinkcontroller_findall)
