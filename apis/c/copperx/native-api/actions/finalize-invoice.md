# Finalize Invoice with Copperx

Finalizes an existing invoice in Copperx.

## Endpoint

- **Method:** `POST`
- **Path:** `/invoices/{id}/finalize`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Finalize Invoice](https://copperx.readme.io/reference/invoicecontroller_finalizeinvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice ID path parameter. |
