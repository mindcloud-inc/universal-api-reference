# Get Webhook Endpoint with Copperx

Retrieves a webhook endpoint from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook-endpoints/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Webhook Endpoint](https://copperx.readme.io/reference/webhookendpointcontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint ID path parameter. |
