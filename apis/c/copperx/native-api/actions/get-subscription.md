# Get Subscription with Copperx

Retrieves subscription record details from Copperx.

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/{id}`
- **Base URL:** `https://api.copperx.dev/api/v1`
- **Official documentation:** [Get Subscription](https://copperx.readme.io/reference/subscriptioncontroller_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Subscription ID path parameter. |
