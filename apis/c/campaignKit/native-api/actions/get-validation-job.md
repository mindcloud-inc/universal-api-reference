# Get Validation Job with CampaignKit

Retrieves a validation job from CampaignKit by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/email/validate/job/{{id}}`
- **Base URL:** `https://api.campaignkit.cc`
- **Official documentation:** [Get Validation Job](https://campaignkit.cc/docs/api/validation-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Validation job ID. |
