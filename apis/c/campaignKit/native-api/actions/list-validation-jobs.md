# List Validation Jobs with CampaignKit

Retrieves bulk email validation jobs from CampaignKit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/email/validate/job`
- **Base URL:** `https://api.campaignkit.cc`
- **Official documentation:** [List Validation Jobs](https://campaignkit.cc/docs/api/validation-jobs)
