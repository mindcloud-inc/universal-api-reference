# Delete Validation Job with CampaignKit

Deletes an existing validation job from CampaignKit.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/email/validate/job/{{id}}`
- **Base URL:** `https://api.campaignkit.cc`
- **Official documentation:** [Delete Validation Job](https://campaignkit.cc/docs/api/validation-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Validation job ID. |
