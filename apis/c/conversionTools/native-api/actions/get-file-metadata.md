# Get File Metadata with Conversion Tools

Retrieves file metadata from Conversion Tools.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/info`
- **Base URL:** `https://api.conversiontools.io/v1`
- **Official documentation:** [Get File Metadata](https://api.conversiontools.io/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The file ID to inspect. |
