# Download File with Conversion Tools

Downloads a file from Conversion Tools.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId`
- **Base URL:** `https://api.conversiontools.io/v1`
- **Official documentation:** [Download File](https://conversiontools.io/api-documentation#download-result-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The file ID returned by upload or task completion. |
