# List Service Groups with Checkmk

Retrieves service group records from Checkmk.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-types/service_group_config/collections/all`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Service Groups](https://github.com/Checkmk/checkmk/tree/master/cmk/gui/openapi/endpoints/service_group_config)
