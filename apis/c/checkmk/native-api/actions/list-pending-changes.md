# List Pending Changes with Checkmk

Retrieves pending change records from Checkmk.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-types/activation_run/collections/pending_changes`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Pending Changes](https://docs.checkmk.com/latest/en/rest_api.html)
