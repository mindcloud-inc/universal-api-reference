# List Downtimes with Checkmk

Retrieves scheduled downtime records from Checkmk.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-types/downtime/collections/all`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Downtimes](https://github.com/Checkmk/checkmk/tree/master/cmk/gui/openapi/endpoints/downtime)
