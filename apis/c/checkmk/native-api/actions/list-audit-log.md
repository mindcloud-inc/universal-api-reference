# List Audit Log with Checkmk

Retrieves audit log entries from Checkmk.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-types/audit_log/collections/all`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Audit Log](https://github.com/Checkmk/checkmk/tree/master/cmk/gui/openapi/endpoints/audit_log)
