# List Host Groups with Checkmk

Retrieves host group records from Checkmk.

## Endpoint

- **Method:** `GET`
- **Path:** `/domain-types/host_group_config/collections/all`
- **Base URL:** `{apiUrl}`
- **Official documentation:** [List Host Groups](https://github.com/Checkmk/checkmk/tree/master/cmk/gui/openapi/endpoints/host_group_config)
