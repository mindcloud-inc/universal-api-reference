# Get Asset Details with ComPDFKit PDF Converter

Retrieves processed asset details from ComPDFKit PDF Converter.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/asset/info`
- **Base URL:** `https://api-server.compdf.com/server`
- **Official documentation:** [Get Asset Details](https://api.compdf.com/api-reference/api-list)
