# PDF to JSON with ComPDFKit PDF Converter

Creates a JSON file from a PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/process/pdf/json`
- **Base URL:** `https://api-server.compdf.com/server`
- **Official documentation:** [PDF to JSON](https://api.compdf.com/api-reference/conversion-guides)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
