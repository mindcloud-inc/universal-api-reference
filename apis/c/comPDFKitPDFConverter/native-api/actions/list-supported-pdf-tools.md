# List Supported PDF Tools with ComPDFKit PDF Converter

Retrieves supported PDF tools from ComPDFKit PDF Converter.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tool/support`
- **Base URL:** `https://api-server.compdf.com/server`
- **Official documentation:** [List Supported PDF Tools](https://api.compdf.com/api-reference/api-list)
