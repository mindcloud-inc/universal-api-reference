# Get Batch with Cohere

Retrieves a batch from Cohere.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/batches/:id`
- **Base URL:** `https://api.cohere.com`
- **Official documentation:** [Get Batch](https://docs.cohere.com/reference/get-batch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Cohere batch ID to retrieve. |
