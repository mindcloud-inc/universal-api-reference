# List Webhooks with CallTrackingMetrics

Retrieves webhooks for an account from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/webhooks`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Webhooks](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/b989srn/list-of-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
