# Get Agency Information with CallTrackingMetrics

Retrieves agency information details from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/agency.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Get Agency Information](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/yo3mrw8/agency-information)
