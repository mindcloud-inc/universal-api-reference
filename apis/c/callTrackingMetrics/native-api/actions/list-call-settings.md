# List Call Settings with CallTrackingMetrics

Retrieves call settings for an account from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/call_settings.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Call Settings](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/oo7uk5g/set-default-call-setting)

## Capabilities

This operation supports [pagination](../README.md#pagination).
