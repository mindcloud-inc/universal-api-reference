# Get User Details with CallTrackingMetrics

Retrieves detailed user information from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/users/:userId.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Get User Details](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/64saoo4/user-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The CallTrackingMetrics user ID. |
