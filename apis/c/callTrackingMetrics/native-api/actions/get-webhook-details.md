# Get Webhook Details with CallTrackingMetrics

Retrieves detailed webhook information from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/webhooks/:webhookId`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Get Webhook Details](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/v9or8sj/webhook-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The CallTrackingMetrics webhook ID. |
