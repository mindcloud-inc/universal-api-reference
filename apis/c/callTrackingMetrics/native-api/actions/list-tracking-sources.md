# List Tracking Sources with CallTrackingMetrics

Retrieves tracking sources for an account from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/sources.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Tracking Sources](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/p7vym5s/tracking-source-details)

## Capabilities

This operation supports [pagination](../README.md#pagination).
