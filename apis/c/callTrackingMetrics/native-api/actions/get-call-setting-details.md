# Get Call Setting Details with CallTrackingMetrics

Retrieves call setting details from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/call_settings/:callSettingId.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Get Call Setting Details](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/70ot7jk/list-details-of-a-call-setting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callSettingId` | path | `string` | yes | The CallTrackingMetrics call setting ID. |
