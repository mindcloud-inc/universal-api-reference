# List Accounts with CallTrackingMetrics

Retrieves all available accounts from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Accounts](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/0ygaqwq/ctm-api/list-of-accounts)
