# List Activities with CallTrackingMetrics

Retrieves account activity records from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/calls.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Activities](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/uzx7unw/list-of-activities-calls-texts-chats-forms)

## Capabilities

This operation supports [pagination](../README.md#pagination).
