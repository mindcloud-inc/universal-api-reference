# List Active Account IDs And Names with CallTrackingMetrics

Retrieves active account IDs and names from CallTrackingMetrics.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts.json`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [List Active Account IDs And Names](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/s1xvu1l/list-of-active-account-ids-and-names)
