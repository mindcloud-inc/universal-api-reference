# Set Default Call Setting with CallTrackingMetrics

Sets a default call setting in CallTrackingMetrics.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/accounts/:accountId/call_settings/:callSettingId/set_default`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Set Default Call Setting](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/t1mhehd/list-of-call-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callSettingId` | path | `string` | yes | The CallTrackingMetrics call setting ID. |
