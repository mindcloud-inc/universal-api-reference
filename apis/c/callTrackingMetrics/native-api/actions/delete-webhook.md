# Delete Webhook with CallTrackingMetrics

Deletes an existing webhook from CallTrackingMetrics.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounts/:accountId/webhooks/:webhookId`
- **Base URL:** `https://api.calltrackingmetrics.com/api/v1`
- **Official documentation:** [Delete Webhook](https://www.postman.com/ctm-8695/calltrackingmetrics-s-public-workspace/request/ktu88w2/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The CallTrackingMetrics webhook ID. |
