# Archive Project with CompanyCam

## Endpoint

- **Method:** `PATCH`
- **Path:** `projects/:id/archive`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Archive Project](https://docs.companycam.com/reference/archiveproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project Id |
