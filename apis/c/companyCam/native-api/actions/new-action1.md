# Delete Project with CompanyCam

Deletes an existing project from CompanyCam.

## Endpoint

- **Method:** `DELETE`
- **URL:** `https://api.companycam.com/v2/projects/:id`
- **Official documentation:** [Delete Project](https://docs.companycam.com/reference/deleteproject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
