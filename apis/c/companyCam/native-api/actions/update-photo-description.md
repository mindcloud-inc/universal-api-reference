# Update Photo Description with CompanyCam

## Endpoint

- **Method:** `POST`
- **Path:** `photos/:id/descriptions`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Update Photo Description](https://docs.companycam.com/reference/updatephotodescription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Photo |
| `description` | body | `string` | no | — |
