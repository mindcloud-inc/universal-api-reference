# Get Project with CompanyCam

Retrieves an existing project from CompanyCam.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get Project](https://docs.companycam.com/reference/getproject)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
