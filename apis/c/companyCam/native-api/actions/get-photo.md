# Get Photo with CompanyCam

## Endpoint

- **Method:** `GET`
- **Path:** `photos/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get Photo](https://docs.companycam.com/reference/getphoto)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Photo |
