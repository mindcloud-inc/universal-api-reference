# Get Webhook with CompanyCam

Retrieves an existing webhook from CompanyCam.

## Endpoint

- **Method:** `GET`
- **Path:** `webhooks/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get Webhook](https://docs.companycam.com/reference/getwebhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
