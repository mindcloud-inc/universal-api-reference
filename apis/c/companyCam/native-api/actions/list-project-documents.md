# List Project Documents with CompanyCam

Retrieves documents from a CompanyCam project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/documents`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [List Project Documents](https://docs.companycam.com/reference/listprojectdocuments)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
