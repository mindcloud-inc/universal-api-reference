# Get Video with CompanyCam

Returns details for a single video.

## Endpoint

- **Method:** `GET`
- **Path:** `videos/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get Video](https://docs.companycam.com/reference/getvideo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Video |
