# Delete Photo with CompanyCam

## Endpoint

- **Method:** `DELETE`
- **Path:** `photos/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Delete Photo](https://docs.companycam.com/reference/updatephotodescription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Photo |
