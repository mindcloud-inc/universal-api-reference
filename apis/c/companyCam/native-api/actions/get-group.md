# Get Group with CompanyCam

## Endpoint

- **Method:** `GET`
- **Path:** `groups/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get Group](https://docs.companycam.com/reference/getgroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the Group |
