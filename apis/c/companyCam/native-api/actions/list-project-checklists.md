# List Project Checklists with CompanyCam

Retrieve all checklists for a CompanyCam project.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/checklists`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [List Project Checklists](https://docs.companycam.com/reference/listprojectchecklists)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
