# Delete Webhook with CompanyCam

Deletes an existing webhook from CompanyCam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Delete Webhook](https://docs.companycam.com/reference/deletewebhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
