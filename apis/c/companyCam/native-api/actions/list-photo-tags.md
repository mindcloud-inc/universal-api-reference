# List Photo Tags with CompanyCam

## Endpoint

- **Method:** `GET`
- **Path:** `photos/:id/tags`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [List Photo Tags](https://docs.companycam.com/reference/listphototags)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
