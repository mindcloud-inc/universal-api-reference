# Delete Project Label with CompanyCam

Delete a label from a project by id.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:id/labels/:labelId`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Delete Project Label](https://docs.companycam.com/reference/listprojectlabels)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `labelId` | path | `string` | yes |
