# Delete User with CompanyCam

Delete an existing user from CompanyCam.

## Endpoint

- **Method:** `DELETE`
- **Path:** `users/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Delete User](https://docs.companycam.com/reference/getuser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the User. |
