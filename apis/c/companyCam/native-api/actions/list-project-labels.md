# List Project Labels with CompanyCam

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:id/labels`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [List Project Labels](https://docs.companycam.com/reference/listprojectlabels)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
