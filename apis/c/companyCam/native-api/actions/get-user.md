# Get User with CompanyCam

Retrieves an existing user from CompanyCam.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:id`
- **Base URL:** `https://api.companycam.com/v2/`
- **Official documentation:** [Get User](https://docs.companycam.com/reference/getuser)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the User. |
