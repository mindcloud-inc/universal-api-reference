# Get PDF Details with CloudFill

Retrieves PDF metadata and field details from CloudFill.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/meta/pdf/{pdfKey}`
- **Base URL:** `https://api.cloudfill.io`
- **Official documentation:** [Get PDF Details](https://api.swaggerhub.com/apis/hpoul/CloudFill/1.3)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pdfKey` | path | `string` | yes | CloudFill PDF template key. |
