# List Catalogs with Catalog Machine

Retrieves all catalogs from Catalog Machine.

## Endpoint

- **Method:** `GET`
- **Path:** `/catalogs`
- **Base URL:** `https://www.catalogmachine.com/api/v1`
- **Official documentation:** [List Catalogs](https://help.catalogmachine.com/en/articles/3667421-rest-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Optional catalog status filter (for example New). |
