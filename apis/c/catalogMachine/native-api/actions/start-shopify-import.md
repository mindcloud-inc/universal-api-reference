# Start Shopify Import with Catalog Machine

Starts a Shopify import job in Catalog Machine.

## Endpoint

- **Method:** `GET`
- **Path:** `/import/shopify/sync`
- **Base URL:** `https://www.catalogmachine.com/api/v1`
- **Official documentation:** [Start Shopify Import](https://help.catalogmachine.com/en/articles/3667421-rest-api)
