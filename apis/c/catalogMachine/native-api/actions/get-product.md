# Get Product with Catalog Machine

Retrieves a product by code from Catalog Machine.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:code`
- **Base URL:** `https://www.catalogmachine.com/api/v1`
- **Official documentation:** [Get Product](https://help.catalogmachine.com/en/articles/3667421-rest-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | Unique product code. |
