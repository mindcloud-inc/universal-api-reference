# Get Namespace with Cloudsmith

## Endpoint

- **Method:** `GET`
- **Path:** `/namespaces/:slug/`
- **Base URL:** `https://api.cloudsmith.io`
- **Official documentation:** [Get Namespace](https://help.cloudsmith.io/reference/namespaces_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Namespace slug. |
