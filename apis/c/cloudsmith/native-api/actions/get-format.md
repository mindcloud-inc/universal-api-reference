# Get Format with Cloudsmith

## Endpoint

- **Method:** `GET`
- **Path:** `/formats/:slug/`
- **Base URL:** `https://api.cloudsmith.io`
- **Official documentation:** [Get Format](https://help.cloudsmith.io/reference/formats_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Format slug. |
