# Get Distro with Cloudsmith

## Endpoint

- **Method:** `GET`
- **Path:** `/distros/:slug/`
- **Base URL:** `https://api.cloudsmith.io`
- **Official documentation:** [Get Distro](https://help.cloudsmith.io/reference/distros_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Distribution slug. |
