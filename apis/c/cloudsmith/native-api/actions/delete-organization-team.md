# Delete Organization Team with Cloudsmith

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orgs/:org/teams/:team/`
- **Base URL:** `https://api.cloudsmith.io`
- **Official documentation:** [Delete Organization Team](https://help.cloudsmith.io/reference/orgs_teams_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org` | path | `string` | yes | Organization slug. |
| `team` | path | `string` | yes | Team slug. |
