# Get Organization with Cloudsmith

## Endpoint

- **Method:** `GET`
- **Path:** `/orgs/:org/`
- **Base URL:** `https://api.cloudsmith.io`
- **Official documentation:** [Get Organization](https://help.cloudsmith.io/reference/orgs_read)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org` | path | `string` | yes | Organization slug. |
