# Delete Project with Clockodo

Deletes a project from your Clockodo account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Delete Project](https://www.clockodo.com/en/api/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
