# Get Service with Clockodo

Retrieves a service from your Clockodo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Get Service](https://www.clockodo.com/en/api/services/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
