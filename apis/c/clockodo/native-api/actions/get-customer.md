# Get Customer with Clockodo

Retrieves a customer from your Clockodo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Get Customer](https://www.clockodo.com/en/api/customers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
