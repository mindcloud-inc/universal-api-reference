# Get Project with Clockodo

Retrieves a project from your Clockodo account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Get Project](https://www.clockodo.com/en/api/projects/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
