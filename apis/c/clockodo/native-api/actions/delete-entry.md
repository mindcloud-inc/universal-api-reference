# Delete Entry with Clockodo

Deletes a time entry from your Clockodo account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/entries/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Delete Entry](https://www.clockodo.com/en/api/entries/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Clockodo entry ID. |
