# Delete Customer with Clockodo

Deletes a customer from your Clockodo account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/customers/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Delete Customer](https://www.clockodo.com/en/api/customers/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
