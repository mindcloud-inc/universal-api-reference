# Stop Clock with Clockodo

Stops the clock in your Clockodo account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clock/:id`
- **Base URL:** `https://my.clockodo.com/api/v2`
- **Official documentation:** [Stop Clock](https://www.clockodo.com/en/api/clock/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Clockodo running entry ID. |
| `users_id` | body | `string` | no | — |
