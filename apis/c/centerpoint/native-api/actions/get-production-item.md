# Get Production Item with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `production_items/:PRODUCTION_ITEM_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Production Item](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/production_items/PRODUCTION_ITEM_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `PRODUCTION_ITEM_ID` | path | `number` | yes |
| `include` | query | `string` | no |
