# Get Single File with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `files/:fileId`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Single File](https://api.centerpointconnect.io/centerpoint/files)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
