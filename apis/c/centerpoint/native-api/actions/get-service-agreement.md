# Get Service Agreement with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `service_agreements/:SERVICE_AGREEMENT_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Service Agreement](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/service_agreements/SERVICE_AGREEMENT_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `SERVICE_AGREEMENT_ID` | path | `number` | yes |
| `fields[companies]` | query | `string` | no |
| `fields[properties]` | query | `string` | no |
| `include` | query | `string` | no |
