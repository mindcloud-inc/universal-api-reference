# Get Building Division with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `building_divisions/:BUILDING_DIVISIONS_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Building Division](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/building_divisions/BUILDING_DIVISIONS_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `BUILDING_DIVISIONS_ID` | path | `number` | yes |
| `fields[products]` | query | `string` | no |
| `include` | query | `string` | no |
