# Get Single Company with Centerpoint

- **Method:** `GET`
- **Path:** `companies/:COMPANY_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Single Company](https://api-portal.centerpointconnect.io/portal/catalogue-products/premium-access-product-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/companiesGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `COMPANY_ID` | path | `string` | yes |
