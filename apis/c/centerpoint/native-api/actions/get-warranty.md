# Get Warranty with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `warranties/:WARRANTY_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Warranty](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/warranties/WARRANTY_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `WARRANTY_ID` | path | `number` | yes |
| `fields[companies]` | query | `string` | no |
| `fields[properties]` | query | `string` | no |
| `include` | query | `string` | no |
