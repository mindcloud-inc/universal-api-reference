# List Services with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `services`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [List Services](https://api-portal.centerpointconnect.io/portal/catalogue-products/premium-access-product-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/servicesGET)
