# List Materials with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `materials`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [List Materials](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/materialsGET)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields[materials]` | query | `string` | no | Optional fields materials query parameter. |
| `include` | query | `string` | no | Optional include query parameter. |
