# Get Tax Code with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `tax_codes/:TAX_CODE_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Tax Code](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/tax_codes/{TAX_CODE_ID}GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `TAX_CODE_ID` | path | `string` | yes | The tax code id to retrieve. |
