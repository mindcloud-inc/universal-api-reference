# Get Product with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `products/:PRODUCT_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Product](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/products/PRODUCT_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `PRODUCT_ID` | path | `number` | yes |
| `fields[productions]` | query | `string` | no |
| `fields[products]` | query | `string` | no |
| `fields[properties]` | query | `string` | no |
| `include` | query | `string` | no |
