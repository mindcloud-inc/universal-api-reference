# Get Product Template with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `product_templates/:PRODUCT_TEMPLATE_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Product Template](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/product_templates/PRODUCT_TEMPLATE_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `PRODUCT_TEMPLATE_ID` | path | `string` | yes |
| `include` | query | `string` | no |
