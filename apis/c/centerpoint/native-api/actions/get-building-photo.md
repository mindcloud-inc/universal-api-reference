# Get Building Photo with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `building_photos/:BUILDING_PHOTO_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Building Photo](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/building_photos/BUILDING_PHOTO_IDGET)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `BUILDING_PHOTO_ID` | path | `number` | yes |
| `include` | query | `string` | no |
