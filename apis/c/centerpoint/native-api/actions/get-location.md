# Get Location with Centerpoint

## Endpoint

- **Method:** `GET`
- **Path:** `locations/:LOCATION_ID`
- **Base URL:** `https://api.centerpointconnect.io/centerpoint/`
- **Official documentation:** [Get Location](https://api-portal.centerpointconnect.io/portal/catalogue-products/centerpoint-api-1/3dea94894ff94ee0588950e6f813f214/docs#/operations/locations/{LOCATION_ID}GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `LOCATION_ID` | path | `string` | yes | The location id to retrieve. |
| `fields[locations]` | query | `string` | no | Optional fields locations query parameter. |
