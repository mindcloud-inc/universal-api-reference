# Get WhatsApp Number with 2Chat

Retrieves a WhatsApp number from 2Chat.

## Endpoint

- **Method:** `GET`
- **Path:** `/whatsapp/channel/:channel_uuid`
- **Base URL:** `https://api.p.2chat.io/open`
- **Official documentation:** [Get WhatsApp Number](https://developers.2chat.co/docs/API/WhatsApp/Web/get-number)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel_uuid` | path | `string` | yes | The UUID of the WhatsApp channel connected to 2Chat. |
