# Get Contact with 2Chat

Retrieves a contact from 2Chat.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactUuid`
- **Base URL:** `https://api.p.2chat.io/open`
- **Official documentation:** [Get Contact](https://developers.2chat.co/docs/API/Contacts/get-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactUuid` | path | `string` | yes |
