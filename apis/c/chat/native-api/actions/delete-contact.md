# Delete Contact with 2Chat

Deletes an existing contact from 2Chat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactUuid`
- **Base URL:** `https://api.p.2chat.io/open`
- **Official documentation:** [Delete Contact](https://developers.2chat.co/docs/API/Contacts/delete-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactUuid` | path | `string` | yes |
