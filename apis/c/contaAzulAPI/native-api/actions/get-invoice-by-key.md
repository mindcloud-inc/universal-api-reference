# Get Invoice By Key with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/notas-fiscais/{chave}`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Invoice By Key](https://developers.contaazul.com/open-api-docs/open-api-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chave` | path | `string` | yes | Conta Azul invoice key from the path. |
