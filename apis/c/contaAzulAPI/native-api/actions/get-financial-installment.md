# Get Financial Installment with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/financeiro/eventos-financeiros/parcelas/{id}`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Financial Installment](https://developers.contaazul.com/open-api-docs/financial-apis-openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conta Azul installment identifier from the path. |
