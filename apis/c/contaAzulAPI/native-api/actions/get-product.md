# Get Product with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/produtos/{id}`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Product](https://developers.contaazul.com/open-api-docs/open-api-inventory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conta Azul product identifier from the path. |
