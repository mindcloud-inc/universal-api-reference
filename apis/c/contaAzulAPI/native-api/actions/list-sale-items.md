# List Sale Items with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/venda/{id_venda}/itens`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [List Sale Items](https://developers.contaazul.com/open-api-docs/sales-apis-openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id_venda` | path | `string` | yes | Conta Azul sale identifier from the path. |
