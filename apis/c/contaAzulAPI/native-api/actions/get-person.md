# Get Person with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pessoas/{id}`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Person](https://developers.contaazul.com/open-api-docs/open-api-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conta Azul person identifier from the path. |
