# Get Acquittance with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/financeiro/eventos-financeiros/parcelas/baixa/{baixa_id}`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Acquittance](https://developers.contaazul.com/open-api-docs/acquittance-apis-openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baixa_id` | path | `string` | yes | Conta Azul acquittance identifier from the path. |
