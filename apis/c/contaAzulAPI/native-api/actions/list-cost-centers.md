# List Cost Centers with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/centro-de-custo`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [List Cost Centers](https://developers.contaazul.com/open-api-docs/financial-apis-openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pagina` | query | `number` | yes | Page number required by Conta Azul. |
| `tamanho_pagina` | query | `number` | yes | Page size required by Conta Azul. |
