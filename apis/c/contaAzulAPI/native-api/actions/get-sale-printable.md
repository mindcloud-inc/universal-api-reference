# Get Sale Printable with Conta Azul

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/venda/{id}/imprimir`
- **Base URL:** `https://api-v2.contaazul.com`
- **Official documentation:** [Get Sale Printable](https://developers.contaazul.com/open-api-docs/sales-apis-openapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conta Azul sale identifier from the path. |
