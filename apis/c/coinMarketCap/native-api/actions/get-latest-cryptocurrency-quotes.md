# Get Latest Cryptocurrency Quotes with CoinMarketCap

Retrieves latest cryptocurrency quotes from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/cryptocurrency/quotes/latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest Cryptocurrency Quotes](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-crypto)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | CoinMarketCap cryptocurrency ID, for example 1. |
