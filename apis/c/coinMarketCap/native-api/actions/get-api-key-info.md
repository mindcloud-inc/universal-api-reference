# Get API Key Info with CoinMarketCap

Retrieves API key usage and plan details from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/key/info`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get API Key Info](https://coinmarketcap.com/api/documentation/guides/authentication)
