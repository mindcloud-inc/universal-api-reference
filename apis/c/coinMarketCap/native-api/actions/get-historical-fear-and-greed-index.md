# Get Historical Fear and Greed Index with CoinMarketCap

Retrieves historical fear and greed index values from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/fear-and-greed/historical`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Historical Fear and Greed Index](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-market)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Number of historical fear and greed records to return. |
