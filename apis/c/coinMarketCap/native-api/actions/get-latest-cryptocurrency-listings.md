# Get Latest Cryptocurrency Listings with CoinMarketCap

Retrieves latest cryptocurrency listings from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/cryptocurrency/listings/latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest Cryptocurrency Listings](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-crypto)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of listings to return. |
