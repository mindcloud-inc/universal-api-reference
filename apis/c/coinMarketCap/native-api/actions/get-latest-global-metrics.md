# Get Latest Global Metrics with CoinMarketCap

Retrieves latest global crypto market metrics from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/global-metrics/quotes/latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest Global Metrics](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-market)
