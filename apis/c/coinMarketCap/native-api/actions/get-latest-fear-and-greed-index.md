# Get Latest Fear and Greed Index with CoinMarketCap

Retrieves the latest fear and greed index from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/fear-and-greed/latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest Fear and Greed Index](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-market)
