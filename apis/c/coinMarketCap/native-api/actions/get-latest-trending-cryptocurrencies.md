# Get Latest Trending Cryptocurrencies with CoinMarketCap

Retrieves latest trending cryptocurrencies from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cryptocurrency/trending/latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest Trending Cryptocurrencies](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-crypto)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of trending cryptocurrencies to return. |
