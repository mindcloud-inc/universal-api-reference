# Get Latest CMC100 Index with CoinMarketCap

Retrieves the latest CMC100 index value from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/index/cmc100-latest`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Latest CMC100 Index](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-market)
