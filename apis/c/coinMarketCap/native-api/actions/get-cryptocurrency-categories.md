# Get Cryptocurrency Categories with CoinMarketCap

Retrieves cryptocurrency categories from CoinMarketCap.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/cryptocurrency/categories`
- **Base URL:** `https://pro-api.coinmarketcap.com`
- **Official documentation:** [Get Cryptocurrency Categories](https://pro.coinmarketcap.com/api/documentation/ai-agent-hub/skills/cmc-api-crypto)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of categories to return. |
