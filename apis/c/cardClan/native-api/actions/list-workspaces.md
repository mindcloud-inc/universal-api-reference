# List Workspaces with CardClan

Retrieves workspaces accessible to the CardClan integration.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/workspaces`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [List Workspaces](https://docs.cardclan.io/api-reference/integration/data/get-workspaces)
