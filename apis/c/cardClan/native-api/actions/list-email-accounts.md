# List Email Accounts with CardClan

Retrieves email accounts configured in CardClan workspaces.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/email-accounts`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [List Email Accounts](https://docs.cardclan.io/api-reference/integration/data/get-email-accounts)
