# List Cards With Workflows with CardClan

Retrieves CardClan cards with active integration workflows.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/workflow-cards`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [List Cards With Workflows](https://docs.cardclan.io/api-reference/integration/workflow/workflow-cards)
