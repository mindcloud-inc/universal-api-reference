# Get Card Details with CardClan

Retrieves details for a CardClan card.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/card-details/:cardId`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [Get Card Details](https://docs.cardclan.io/api-reference/integration/overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | Card ID used in the request path. |
