# Get Integration Configuration with CardClan

Retrieves a CardClan integration configuration by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/config`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [Get Integration Configuration](https://docs.cardclan.io/api-reference/integration/config/get-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | query | `string` | yes | Integration configuration ID. |
