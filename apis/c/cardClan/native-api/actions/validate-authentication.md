# Validate Authentication with CardClan

Retrieves user details for a valid CardClan integration key.

## Endpoint

- **Method:** `GET`
- **Path:** `/integration/auth/validate`
- **Base URL:** `https://app.cardclan.io/api`
- **Official documentation:** [Validate Authentication](https://docs.cardclan.io/api-reference/integration/authentication/validate-token)
