# Get Current Hour Average with ComEd

Retrieves the current hour average price from ComEd.

## Endpoint

- **Method:** `GET`
- **Path:** `/api?type=currenthouraverage&format=json`
- **Base URL:** `https://hourlypricing.comed.com`
- **Official documentation:** [Get Current Hour Average](https://hourlypricing.comed.com/hp-api/)
