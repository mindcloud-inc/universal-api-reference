# Get Latest 5-Minute Prices with ComEd

Retrieves the latest 5-minute prices from ComEd.

## Endpoint

- **Method:** `GET`
- **Path:** `/api?type=5minutefeed&format=json`
- **Base URL:** `https://hourlypricing.comed.com`
- **Official documentation:** [Get Latest 5-Minute Prices](https://hourlypricing.comed.com/hp-api/)
