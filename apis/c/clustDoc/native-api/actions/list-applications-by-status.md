# List Applications By Status with ClustDoc

## Endpoint

- **Method:** `GET`
- **Path:** `/dossiers`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [List Applications By Status](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | yes | Application status value, for example 0_not_started. |
