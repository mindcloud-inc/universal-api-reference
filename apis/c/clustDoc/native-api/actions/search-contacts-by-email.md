# Search Contacts By Email with ClustDoc

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [Search Contacts By Email](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Contact email address to match. |
