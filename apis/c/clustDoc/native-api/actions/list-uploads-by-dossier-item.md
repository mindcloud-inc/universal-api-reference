# List Uploads By Dossier Item with ClustDoc

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [List Uploads By Dossier Item](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `dossier_item_id` | query | `string` | yes | Return uploads for a specific dossier item. |
