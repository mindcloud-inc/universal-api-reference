# Create Contact with ClustDoc

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [Create Contact](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Contact email address. |
| `firstname` | body | `string` | yes | Contact first name. |
| `lastname` | body | `string` | yes | Contact last name. |
