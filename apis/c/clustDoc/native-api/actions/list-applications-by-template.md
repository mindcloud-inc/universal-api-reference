- **Method:** `GET`

- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [List Applications By Template](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
