# Search Teams with ClustDoc

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [Search Teams](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | yes | Search text for team names. |
