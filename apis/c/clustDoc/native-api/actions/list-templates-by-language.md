# List Templates By Language with ClustDoc

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [List Templates By Language](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | query | `string` | yes | Template language code, for example pt. |
