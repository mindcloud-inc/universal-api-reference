- **Method:** `POST`
- **Path:** `/templates`
- **Base URL:** `https://api.clustdoc.com/api`
- **Official documentation:** [Create Template](https://clustdoc.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Template title. |
