# Delete Domain with CodeQR - Link and QR Analytics

Deletes a domain from CodeQR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domains/:slug`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Delete Domain](https://docs.codeqr.io/api-reference/endpoint/delete-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | The domain name. |
