# List Projects with CodeQR - Link and QR Analytics

Retrieves projects from CodeQR.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [List Projects](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)
