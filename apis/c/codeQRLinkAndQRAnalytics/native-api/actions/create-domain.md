# Create Domain with CodeQR - Link and QR Analytics

Creates a domain in CodeQR.

## Endpoint

- **Method:** `POST`
- **Path:** `/domains`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Create Domain](https://docs.codeqr.io/api-reference/endpoint/create-a-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | body | `string` | yes | Name of the domain. |
