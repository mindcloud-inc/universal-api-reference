# Delete Tag with CodeQR - Link and QR Analytics

Deletes a tag from CodeQR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Delete Tag](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the tag to delete. |
