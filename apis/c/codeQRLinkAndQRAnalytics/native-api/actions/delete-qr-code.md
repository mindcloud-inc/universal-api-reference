# Delete QR Code with CodeQR - Link and QR Analytics

Deletes a QR code from CodeQR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/qrcodes/:qrcodeId`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Delete QR Code](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `qrcodeId` | path | `string` | yes | The ID of the QR code to delete. |
