# Retrieve Analytics with CodeQR - Link and QR Analytics

Retrieves analytics from CodeQR.

## Endpoint

- **Method:** `GET`
- **Path:** `/analytics`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Retrieve Analytics](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `interval` | query | `string` | no | The interval to retrieve analytics for. |
| `event` | query | `string` | no | The event type to retrieve analytics for. |
