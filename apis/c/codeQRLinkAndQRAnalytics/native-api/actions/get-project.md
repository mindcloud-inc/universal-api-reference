# Get Project with CodeQR - Link and QR Analytics

Retrieves a project from CodeQR.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectSlug`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Get Project](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectSlug` | path | `string` | yes | The slug for the project to retrieve. |
