# Delete Link with CodeQR - Link and QR Analytics

Deletes a link from CodeQR.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:linkId`
- **Base URL:** `https://api.codeqr.io`
- **Official documentation:** [Delete Link](https://app.stainless.com/api/spec/documented/codeqr/openapi.documented.yml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkId` | path | `string` | yes | The ID of the link to delete. |
