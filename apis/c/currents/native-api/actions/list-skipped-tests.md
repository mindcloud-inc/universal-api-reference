# List Skipped Tests with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/tests`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [List Skipped Tests](https://docs.currents.dev/api/resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `date_end` | query | `string` | yes |
| `date_start` | query | `string` | yes |
| `projectId` | query | `string` | yes |
