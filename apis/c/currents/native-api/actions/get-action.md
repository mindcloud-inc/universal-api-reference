# Get Action with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/actions/:actionId`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [Get Action](https://docs.currents.dev/api/resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `actionId` | path | `string` | yes |
