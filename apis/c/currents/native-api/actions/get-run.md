# Get Run with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/runs/:runId`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [Get Run](https://docs.currents.dev/resources/api/api-resources/runs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `runId` | path | `string` | no |
