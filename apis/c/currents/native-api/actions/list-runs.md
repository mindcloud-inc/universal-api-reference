# List Runs with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId/runs`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [List Runs](https://docs.currents.dev/resources/api/api-resources/runs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ending_before` | query | `string` | no |
| `limit` | query | `string` | no |
| `projectId` | path | `string` | no |
| `starting_after` | query | `string` | no |
