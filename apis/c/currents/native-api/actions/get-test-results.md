# Get Test Results with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/test-results/:signature`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [Get Test Results](https://docs.currents.dev/api/resources)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `date_end` | query | `string` | yes |
| `date_start` | query | `string` | yes |
| `signature` | path | `string` | yes |
