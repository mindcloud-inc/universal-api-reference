# Get Project with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [Get Project](https://docs.currents.dev/resources/api/api-resources/projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | no |
