# Get Instance with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/instances/:instanceId`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [Get Instance](https://docs.currents.dev/resources/api/api-resources/instances)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `instanceId` | path | `string` | no |
