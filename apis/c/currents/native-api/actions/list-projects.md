# List Projects with Currents

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.currents.dev/v1`
- **Official documentation:** [List Projects](https://docs.currents.dev/resources/api/api-resources/projects)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ending_before` | query | `string` | no |
| `limit` | query | `string` | no |
| `starting_after` | query | `string` | no |
