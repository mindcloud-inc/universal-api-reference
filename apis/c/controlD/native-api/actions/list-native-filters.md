# List Native Filters with Control D

Retrieves native filters for a profile from Control D.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/:profileId/filters`
- **Base URL:** `https://api.controld.com`
- **Official documentation:** [List Native Filters](https://docs.controld.com/reference/get_profiles-profile-id-filters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | Primary key (PK) of the profile |
