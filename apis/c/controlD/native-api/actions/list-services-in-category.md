# List Services In Category with Control D

Retrieves services in a category from Control D.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/categories/:category`
- **Base URL:** `https://api.controld.com`
- **Official documentation:** [List Services In Category](https://docs.controld.com/reference/get_services-categories-category)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | path | `string` | yes | Category name |
