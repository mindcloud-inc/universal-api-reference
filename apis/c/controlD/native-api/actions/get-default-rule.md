# Get Default Rule with Control D

Retrieves the default rule from Control D.

## Endpoint

- **Method:** `GET`
- **Path:** `/profiles/:profileId/default`
- **Base URL:** `https://api.controld.com`
- **Official documentation:** [Get Default Rule](https://docs.controld.com/reference/get_profiles-profile-id-default)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `profileId` | path | `string` | yes | Primary key (PK) of the profile |
