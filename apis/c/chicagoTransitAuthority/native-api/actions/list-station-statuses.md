# List Station Statuses with Chicago Transit Authority

Retrieves station statuses in Chicago Transit Authority.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [List Station Statuses](https://www.transitchicago.com/assets/1/6/cta_Customer_Alerts_API_Developer_Guide_and_Documentation_20160929.pdf)
