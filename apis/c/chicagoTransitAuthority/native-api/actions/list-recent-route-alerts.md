# List Recent Route Alerts with Chicago Transit Authority

Finds recent alerts in Chicago Transit Authority by route ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [List Recent Route Alerts](https://www.transitchicago.com/assets/1/6/cta_Customer_Alerts_API_Developer_Guide_and_Documentation_20160929.pdf)
