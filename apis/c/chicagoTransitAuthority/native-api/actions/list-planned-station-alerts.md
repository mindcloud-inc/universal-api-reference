# List Planned Station Alerts with Chicago Transit Authority

Finds planned alerts in Chicago Transit Authority by station ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [List Planned Station Alerts](https://www.transitchicago.com/assets/1/6/cta_Customer_Alerts_API_Developer_Guide_and_Documentation_20160929.pdf)
