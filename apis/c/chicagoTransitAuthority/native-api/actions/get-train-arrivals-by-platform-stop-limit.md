# Get Train Arrivals by Platform Stop Limit with Chicago Transit Authority

Retrieves limited train arrival predictions in Chicago Transit Authority by platform stop.

## Endpoint

- **Method:** `GET`
- **Path:** `/ttarrivals.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [Get Train Arrivals by Platform Stop Limit](https://www.transitchicago.com/developers/ttdocs/default.aspx)
