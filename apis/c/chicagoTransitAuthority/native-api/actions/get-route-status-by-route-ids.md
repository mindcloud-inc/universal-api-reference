# Get Route Status by Route IDs with Chicago Transit Authority

Finds route statuses in Chicago Transit Authority by route ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [Get Route Status by Route IDs](https://www.transitchicago.com/assets/1/6/cta_Customer_Alerts_API_Developer_Guide_and_Documentation_20160929.pdf)
