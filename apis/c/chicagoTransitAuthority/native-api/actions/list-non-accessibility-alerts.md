# List Non-Accessibility Alerts with Chicago Transit Authority

Retrieves non-accessibility alerts in Chicago Transit Authority.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts.aspx`
- **Base URL:** `https://lapi.transitchicago.com/api/1.0`
- **Official documentation:** [List Non-Accessibility Alerts](https://www.transitchicago.com/assets/1/6/cta_Customer_Alerts_API_Developer_Guide_and_Documentation_20160929.pdf)
