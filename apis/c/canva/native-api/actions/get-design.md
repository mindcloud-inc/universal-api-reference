# Get Design with Canva

Retrieves details for a Canva design.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/designs/:designId`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get Design](https://www.canva.dev/docs/connect/api-reference/designs/get-design/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `designId` | path | `string` | yes | The Canva design ID. |
