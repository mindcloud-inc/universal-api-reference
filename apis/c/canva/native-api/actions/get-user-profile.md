# Get User Profile with Canva

Retrieves the current Canva user's profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/me/profile`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get User Profile](https://www.canva.dev/docs/connect/api-reference/users/users-profile/)
