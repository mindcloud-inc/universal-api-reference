# Get Design Export Job with Canva

Retrieves a Canva design export job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/exports/:exportId`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get Design Export Job](https://www.canva.dev/docs/connect/api-reference/exports/get-design-export-job/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `exportId` | path | `string` | yes | The export job ID. |
