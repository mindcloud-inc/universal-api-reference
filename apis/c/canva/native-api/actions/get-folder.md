# Get Folder with Canva

Retrieves details for a Canva folder.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/folders/:folderId`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get Folder](https://www.canva.dev/docs/connect/api-reference/folders/get-folder/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Maximum length: 50. |
