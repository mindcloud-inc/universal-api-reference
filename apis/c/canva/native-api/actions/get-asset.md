# Get Asset with Canva

Retrieves details for a Canva asset.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/assets/:assetId`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get Asset](https://www.canva.dev/docs/connect/api-reference/assets/get-asset/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `string` | yes | The ID of the asset. Maximum length: 50. |
