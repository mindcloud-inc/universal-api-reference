# Get User Capabilities with Canva

Retrieves the current Canva user's capabilities.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/me/capabilities`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get User Capabilities](https://www.canva.dev/docs/connect/api-reference/users/get-user-capabilities/)
