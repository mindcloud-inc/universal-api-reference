# Get URL Import Job with Canva

Retrieves a Canva URL import job.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/url-imports/:jobId`
- **Base URL:** `https://api.canva.com/rest`
- **Official documentation:** [Get URL Import Job](https://www.canva.dev/docs/connect/api-reference/design-imports/get-url-import-job/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The URL import job ID. |
