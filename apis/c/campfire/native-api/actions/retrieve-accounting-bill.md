# Retrieve Accounting Bill with Campfire

Retrieves an accounting bill from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/bill/:id/`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Accounting Bill](https://docs.campfire.ai/api-reference/accounts-payable/retrieve-accounting-bill)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The accounting bill ID to retrieve. |
