# Retrieve Bank Account with Campfire

Retrieves a bank account from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/ca/api/account/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Bank Account](https://docs.campfire.ai/api-reference/cash-management/retrieve-bank-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The bank account ID to retrieve. |
