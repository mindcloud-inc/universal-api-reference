# Retrieve Budget with Campfire

Retrieves a budget from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/budgets/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Budget](https://docs.campfire.ai/api-reference/core-accounting/retrieve-budget)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The budget ID to retrieve. |
