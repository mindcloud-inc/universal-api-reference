# Retrieve Chart Entity with Campfire

Retrieves a chart entity from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/entity/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Chart Entity](https://docs.campfire.ai/api-reference/settings/retrieve-chart-entity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The chart entity ID to retrieve. |
