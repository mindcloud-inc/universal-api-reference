# Retrieve Journal Entry with Campfire

Retrieves a journal entry from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/journal_entry/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Journal Entry](https://docs.campfire.ai/api-reference/core-accounting/retrieve-journal-entry)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The journal entry ID to retrieve. |
