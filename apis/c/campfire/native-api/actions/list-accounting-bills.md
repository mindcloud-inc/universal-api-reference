# List Accounting Bills with Campfire

Retrieves accounting bills from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/bill/`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Accounting Bills](https://docs.campfire.ai/api-reference/accounts-payable/list-accounting-bills)
