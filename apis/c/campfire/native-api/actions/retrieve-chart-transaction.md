# Retrieve Chart Transaction with Campfire

Retrieves a chart transaction from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/transaction/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Chart Transaction](https://docs.campfire.ai/api-reference/core-accounting/retrieve-chart-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The chart transaction ID to retrieve. |
