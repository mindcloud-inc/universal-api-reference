# List Credit Memos with Campfire

Retrieves credit memos from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/credit-memo`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Credit Memos](https://docs.campfire.ai/api-reference/accounts-receivable/list-credit-memos)
