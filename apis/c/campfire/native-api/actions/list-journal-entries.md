# List Journal Entries with Campfire

Retrieves journal entries from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/journal_entry`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Journal Entries](https://docs.campfire.ai/api-reference/core-accounting/list-journal-entries)
