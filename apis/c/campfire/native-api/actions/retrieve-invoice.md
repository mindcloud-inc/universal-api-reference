# Retrieve Invoice with Campfire

Retrieves an invoice from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/invoice/:id/`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Invoice](https://docs.campfire.ai/api-reference/accounts-receivable/retrieve-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The invoice ID to retrieve. |
