# List Fixed Assets with Campfire

Retrieves fixed assets from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/fixed-asset`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Fixed Assets](https://docs.campfire.ai/api-reference/core-accounting/list-fixed-assets)
