# Retrieve Vendor with Campfire

Retrieves a vendor from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/vendor/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Vendor](https://docs.campfire.ai/api-reference/company-objects/retrieve-vendor)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The vendor ID to retrieve. |
