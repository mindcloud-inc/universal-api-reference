# List Invoices with Campfire

Retrieves invoices from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/invoice/`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Invoices](https://docs.campfire.ai/api-reference/accounts-receivable/list-invoices)
