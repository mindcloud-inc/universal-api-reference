# Retrieve Bank Transaction with Campfire

Retrieves a bank transaction from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/ca/api/transaction/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Bank Transaction](https://docs.campfire.ai/api-reference/cash-management/retrieve-bank-transaction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The bank transaction ID to retrieve. |
