# Retrieve Credit Memo with Campfire

Retrieves a credit memo from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/v1/credit-memo/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Credit Memo](https://docs.campfire.ai/api-reference/accounts-receivable/retrieve-credit-memo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The credit memo ID to retrieve. |
