# List Chart Transactions with Campfire

Retrieves chart transactions from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/transaction`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [List Chart Transactions](https://docs.campfire.ai/api-reference/core-accounting/list-chart-transactions)
