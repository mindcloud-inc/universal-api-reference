# Retrieve Fixed Asset with Campfire

Retrieves a fixed asset from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/fixed-asset/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Fixed Asset](https://docs.campfire.ai/api-reference/core-accounting/retrieve-fixed-asset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The fixed asset ID to retrieve. |
