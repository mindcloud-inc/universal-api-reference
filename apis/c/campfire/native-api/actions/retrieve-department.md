# Retrieve Department with Campfire

Retrieves a department from Campfire.

## Endpoint

- **Method:** `GET`
- **Path:** `/coa/api/department/:id`
- **Base URL:** `https://api.meetcampfire.com`
- **Official documentation:** [Retrieve Department](https://docs.campfire.ai/api-reference/company-objects/retrieve-department)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The department ID to retrieve. |
