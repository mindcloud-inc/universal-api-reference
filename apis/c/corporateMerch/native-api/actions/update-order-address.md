# Update Order Address with Corporate Merch

Updates an order address in Corporate Merch.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v2/orders/{id}/update_address`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Update Order Address](https://corporatemerch.readme.io/reference/update-an-order-address)
