# Get Catalog Estimated Ship Date with Corporate Merch

Retrieves a catalog product's estimated ship date from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/catalog/{id}/estimated-ship-date`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Catalog Estimated Ship Date](https://corporatemerch.readme.io/reference/get-a-catalogs-estimated-ship-date)
