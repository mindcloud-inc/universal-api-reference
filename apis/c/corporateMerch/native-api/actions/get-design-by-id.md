# Get Design By Id with Corporate Merch

Retrieves a design from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/designs/{id}`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Design By Id](https://corporatemerch.readme.io/reference/get-design-by-id)
