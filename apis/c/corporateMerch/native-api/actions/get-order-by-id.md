# Get Order By Id with Corporate Merch

Retrieves an order from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/{id}`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Order By Id](https://corporatemerch.readme.io/reference/get-order-by-id)
