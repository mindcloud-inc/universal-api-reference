# Customize Product Async with Corporate Merch

Creates a customized product design asynchronously in Corporate Merch.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/designs/customize_async`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Customize Product Async](https://corporatemerch.readme.io/reference/customize-a-product-async)
