# Update Customized Product with Corporate Merch

Updates a customized product design in Corporate Merch.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/designs/customize/{id}`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Update Customized Product](https://corporatemerch.readme.io/reference/update-customized-product)
