# Get Design Estimated Ship Date with Corporate Merch

Retrieves a design's estimated ship date from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/designs/{id}/estimated-ship-date`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Design Estimated Ship Date](https://corporatemerch.readme.io/reference/get-designs-estimated-ship-date)
