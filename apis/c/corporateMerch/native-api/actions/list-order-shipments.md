# List Order Shipments with Corporate Merch

Retrieves shipments for an order in Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/{id}/shipments`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [List Order Shipments](https://corporatemerch.readme.io/reference/list-order-shipments)
