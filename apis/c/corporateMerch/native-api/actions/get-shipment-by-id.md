# Get Shipment By Id with Corporate Merch

Retrieves a shipment from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/orders/{order_id}/shipments/{shipment_id}`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Shipment By Id](https://corporatemerch.readme.io/reference/get-shipment-by-id)
