# Get Catalog By Id with Corporate Merch

Retrieves a catalog product from Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/catalog/{id}`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [Get Catalog By Id](https://corporatemerch.readme.io/reference/get-catalog-by-id)
