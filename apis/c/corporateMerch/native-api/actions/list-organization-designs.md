# List Organization Designs with Corporate Merch

Retrieves designs for an organization in Corporate Merch.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/organizations/{organization}/designs`
- **Base URL:** `https://api.corporatemerch.com`
- **Official documentation:** [List Organization Designs](https://corporatemerch.readme.io/reference/retreive-list-of-designs-for-given-organization)
