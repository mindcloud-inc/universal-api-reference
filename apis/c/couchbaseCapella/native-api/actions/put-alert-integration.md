# Update Alert Integration with Couchbase Capella

Updates an alert integration in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrations/:alertIntegrationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Alert Integration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/putAlertIntegration)
