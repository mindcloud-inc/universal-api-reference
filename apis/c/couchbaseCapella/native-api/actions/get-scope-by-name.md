# Get Scope with Couchbase Capella

Retrieves a scope from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes/:scopeName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Scope](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/getScopeByName)
