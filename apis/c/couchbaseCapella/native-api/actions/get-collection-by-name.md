# Get Collection with Couchbase Capella

Retrieves a collection from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes/:scopeName/collections/:collectionName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Collection](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/getCollectionByName)
