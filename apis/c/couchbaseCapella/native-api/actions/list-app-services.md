# List AppServices with Couchbase Capella

Retrieves AppServices from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/appservices`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List AppServices](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/listAppServices)
