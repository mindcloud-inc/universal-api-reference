# List Cluster Audit Log Export Jobs with Couchbase Capella

Retrieves cluster audit log export jobs from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLogExports`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cluster Audit Log Export Jobs](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/listAuditLogExports)
