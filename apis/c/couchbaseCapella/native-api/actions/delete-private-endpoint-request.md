# Delete Private Endpoint Request with Couchbase Capella

Deletes a private endpoint request from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/privateEndpointService/endpoints/:endpointId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Private Endpoint Request](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Private Endpoints/operation/deletePrivateEndpointRequest)
