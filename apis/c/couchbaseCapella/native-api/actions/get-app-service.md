# Get App Service with Couchbase Capella

Retrieves an app service from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/getAppService)
