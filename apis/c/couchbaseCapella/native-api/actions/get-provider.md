# Get provider with Couchbase Capella

Retrieves a provider from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/providers/:providerId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Services Providers/operation/getProvider)
