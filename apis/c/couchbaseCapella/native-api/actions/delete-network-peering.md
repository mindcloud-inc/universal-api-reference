# Delete Network Peering with Couchbase Capella

Deletes a network peering from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/networkPeers/:peerId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Network Peering](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Network Peers/operation/deleteNetworkPeering)
