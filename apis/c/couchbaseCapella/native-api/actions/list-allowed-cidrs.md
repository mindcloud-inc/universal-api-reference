# List Allowed CIDRs with Couchbase Capella

Retrieves allowed CIDRs from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/allowedcidrs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Allowed CIDRs](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Allowed CIDRs (Cluster)/operation/listAllowedCidrs)
