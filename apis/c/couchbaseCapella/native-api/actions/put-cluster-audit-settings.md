# Update Cluster Audit Log Configuration with Couchbase Capella

Updates a cluster audit log configuration in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLog`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Cluster Audit Log Configuration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/putClusterAuditSettings)
