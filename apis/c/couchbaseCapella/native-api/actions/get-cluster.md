# Get Cluster with Couchbase Capella

Retrieves a cluster from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/getCluster)
