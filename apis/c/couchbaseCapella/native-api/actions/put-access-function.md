# Upsert custom Access Control and Validation function with Couchbase Capella

Upserts a custom access control and validation function in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointKeyspace/accessControlFunction`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Upsert custom Access Control and Validation function](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/putAccessFunction)
