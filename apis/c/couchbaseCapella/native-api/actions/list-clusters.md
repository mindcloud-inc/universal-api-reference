# List Clusters with Couchbase Capella

Retrieves clusters from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Clusters](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/listClusters)
