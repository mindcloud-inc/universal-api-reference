# Create provider with Couchbase Capella

Creates a provider in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/aiServices/providers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Services Providers/operation/createProvider)
