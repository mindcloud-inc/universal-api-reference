# Get App Service Audit Log Streaming State with Couchbase Capella

Retrieves an app service audit log streaming state from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service Audit Log Streaming State](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/getAppServiceAuditLogStreaming)
