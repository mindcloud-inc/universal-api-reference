# Create Cluster Audit Log Export job with Couchbase Capella

Creates a cluster audit log export job in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLogExports`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Cluster Audit Log Export job](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/postAuditLogExport)
