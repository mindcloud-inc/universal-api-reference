# Update Database Credentials with Couchbase Capella

Updates a database credentials in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Database Credentials](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Database Credentials/operation/putDatabaseCredential)
