# Disable Private Endpoint Service with Couchbase Capella

Disables a private endpoint service in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Disable Private Endpoint Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/disablePrivateEndpointService)
