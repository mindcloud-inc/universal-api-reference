# Delete provider with Couchbase Capella

Deletes a provider from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/aiServices/providers/:providerId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Services Providers/operation/deleteProvider)
