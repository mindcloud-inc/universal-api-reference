# Create Network Peering with Couchbase Capella

Creates a network peering in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/networkPeers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Network Peering](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Network Peers/operation/postNetworkPeering)
