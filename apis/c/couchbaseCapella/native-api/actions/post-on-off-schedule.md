# Create Cluster On/Off schedule with Couchbase Capella

Creates a cluster on/off schedule in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/onOffSchedule`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Cluster On/Off schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/On/Off Schedule/operation/postOnOffSchedule)
