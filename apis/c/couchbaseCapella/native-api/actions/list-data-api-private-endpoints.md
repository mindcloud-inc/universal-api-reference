# List Data API Private Endpoints with Couchbase Capella

Retrieves Data API private endpoints from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI/privateEndpoints`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Data API Private Endpoints](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/listDataAPIPrivateEndpoints)
