# List Key Rotation History with Couchbase Capella

Retrieves key rotation history from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/cmek/:cmekId/history`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Key Rotation History](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/listCMEKHistory)
