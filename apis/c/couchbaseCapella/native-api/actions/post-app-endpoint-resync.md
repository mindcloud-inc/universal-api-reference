# Start Resync with Couchbase Capella

Starts a resync in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/resync`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Start Resync](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/postAppEndpointResync)
