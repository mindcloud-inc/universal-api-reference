# Delete App Service Admin User with Couchbase Capella

Deletes an app service admin user from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/adminUsers/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete App Service Admin User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/DeleteAppServiceAdminUser)
