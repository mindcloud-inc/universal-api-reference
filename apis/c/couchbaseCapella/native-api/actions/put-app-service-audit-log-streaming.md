# Configure App Service Audit Log Streaming with Couchbase Capella

Configures an app service audit log streaming in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Configure App Service Audit Log Streaming](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/putAppServiceAuditLogStreaming)
