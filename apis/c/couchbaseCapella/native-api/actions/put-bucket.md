# Update Bucket with Couchbase Capella

Updates a bucket in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/putBucket)
