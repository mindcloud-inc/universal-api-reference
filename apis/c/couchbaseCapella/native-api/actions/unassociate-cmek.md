# Unassociate Key from Cluster with Couchbase Capella

Unassociates a key from cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cmek/:cmekId/unassociate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Unassociate Key from Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/UnassociateCMEK)
