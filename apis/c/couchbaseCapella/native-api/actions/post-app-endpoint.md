# Create App Endpoint with Couchbase Capella

Creates an app endpoint in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create App Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/postAppEndpoint)
