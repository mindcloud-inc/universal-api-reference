# Get Cluster Audit Log Configuration with Couchbase Capella

Retrieves a cluster audit log configuration from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLog`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Cluster Audit Log Configuration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/getClusterAuditSettings)
