# Get App Endpoint with Couchbase Capella

Retrieves an app endpoint from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/getAppEndpoint)
