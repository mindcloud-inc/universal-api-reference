# List Sample Data Import Buckets with Couchbase Capella

Retrieves sample data import buckets from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/sampleBuckets`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Sample Data Import Buckets](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Sample Bucket/operation/listSampleBuckets)
