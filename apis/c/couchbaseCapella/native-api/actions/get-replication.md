# Get replication details with Couchbase Capella

Retrieves a replication details from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/:replicationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get replication details](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/getReplication)
