# Resume or Bring an App Endpoint online with Couchbase Capella

Resumes an or bring an app endpoint online in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/activationStatus`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Resume or Bring an App Endpoint online](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/postAppEndpointActivationStatus)
