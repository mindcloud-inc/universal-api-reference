# List Audit Log Export Jobs with Couchbase Capella

Retrieves audit log export jobs from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogExports`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Audit Log Export Jobs](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/listAppServiceAuditLogExports)
