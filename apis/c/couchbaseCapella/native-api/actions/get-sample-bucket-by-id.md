# Get Sample Import Bucket with Couchbase Capella

Retrieves a sample import bucket from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/sampleBuckets/:bucketId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Sample Import Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Sample Bucket/operation/getSampleBucketById)
