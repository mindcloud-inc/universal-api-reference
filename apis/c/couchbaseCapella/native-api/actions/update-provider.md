# Update provider with Couchbase Capella

Updates a provider in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/aiServices/providers/:providerId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Services Providers/operation/updateProvider)
