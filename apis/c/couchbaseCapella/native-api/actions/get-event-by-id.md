# Get Event with Couchbase Capella

Retrieves an event from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/events/:eventId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Event](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Events/operation/getEventByID)
