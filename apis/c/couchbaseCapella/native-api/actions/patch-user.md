# Update User with Couchbase Capella

Updates a user in Couchbase Capella.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v4/organizations/:organizationId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Users/operation/patchUser)
