# Get Public Certificate for App Service with Couchbase Capella

Retrieves a public certificate for app service from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/certificates`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Public Certificate for App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/getAppServiceCertificate)
