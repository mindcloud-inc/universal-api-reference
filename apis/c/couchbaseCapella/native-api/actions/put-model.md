# Update Model with Couchbase Capella

Updates a model in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Model](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/putModel)
