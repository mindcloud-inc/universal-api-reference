# Disassociate Data API Private Endpoint with Couchbase Capella

Disassociates a data API private endpoint in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI/privateEndpoints/:endpointId/unassociate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Disassociate Data API Private Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/disassociateDataAPIPrivateEndpoint)
