# Turn On Cluster with Couchbase Capella

Turns on a cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn On Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/clusterOn)
