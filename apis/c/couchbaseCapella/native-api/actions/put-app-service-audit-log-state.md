# Enable or Disable App Service Audit Logging with Couchbase Capella

Enables an or disable app service audit logging in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLog`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Enable or Disable App Service Audit Logging](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/putAppServiceAuditLogState)
