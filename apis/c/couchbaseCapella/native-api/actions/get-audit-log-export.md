# Get Cluster Audit Log Export with Couchbase Capella

Retrieves a cluster audit log export from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLogExports/:auditLogExportId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Cluster Audit Log Export](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/getAuditLogExport)
