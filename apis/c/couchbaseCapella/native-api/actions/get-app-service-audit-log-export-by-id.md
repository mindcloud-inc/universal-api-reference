# Get Audit Log Export Job with Couchbase Capella

Retrieves an audit log export job from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogExports/:auditLogExportId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Audit Log Export Job](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/getAppServiceAuditLogExportById)
