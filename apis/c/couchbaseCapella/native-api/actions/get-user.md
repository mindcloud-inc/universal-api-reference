# Get User with Couchbase Capella

Retrieves a user from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Users/operation/getUser)
