# Update Data API with Couchbase Capella

Updates a data API in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Data API](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/updateDataApiAndPeering)
