# List Azure Key Metadata For Project with Couchbase Capella

Retrieves Azure key metadata for project from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmek`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Azure Key Metadata For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/getAzureKeyMetadataListForProject)
