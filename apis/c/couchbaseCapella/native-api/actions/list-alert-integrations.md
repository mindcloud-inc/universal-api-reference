# List Alert Integrations with Couchbase Capella

Retrieves alert integrations from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrations`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Alert Integrations](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/listAlertIntegrations)
