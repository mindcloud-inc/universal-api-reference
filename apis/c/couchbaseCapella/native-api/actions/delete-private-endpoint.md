# Reject or disassociate Private Endpoint with Couchbase Capella

Rejects an or disassociate private endpoint in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService/endpoints/:endpointId/unassociate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Reject or disassociate Private Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/deletePrivateEndpoint)
