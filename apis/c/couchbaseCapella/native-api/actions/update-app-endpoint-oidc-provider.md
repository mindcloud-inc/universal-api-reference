# Update App Endpoint OpenID Connect (OIDC) Provider with Couchbase Capella

Updates an app endpoint OpenID connect (OIDC) provider in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/oidcProviders/:OIDCProviderId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Endpoint OpenID Connect (OIDC) Provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/updateAppEndpointOIDCProvider)
