# Get API Key with Couchbase Capella

Retrieves an API key from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/apikeys/:ApiKeyId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get API Key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Api Keys/operation/getOrganizationAPIKeyByAccessKey)
