# List Users with Couchbase Capella

Retrieves users from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/users`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Users](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Users/operation/listUsers)
