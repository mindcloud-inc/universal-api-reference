# Create Key Metadata with Couchbase Capella

Creates a key metadata in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/cmek`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Key Metadata](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/postCMEKMetadata)
