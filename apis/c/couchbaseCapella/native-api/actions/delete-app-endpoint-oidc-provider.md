# Delete App Endpoint OpenID Connect (OIDC) Provider with Couchbase Capella

Deletes an app endpoint OpenID connect (OIDC) provider from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/oidcProviders/:OIDCProviderId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete App Endpoint OpenID Connect (OIDC) Provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteAppEndpointOIDCProvider)
