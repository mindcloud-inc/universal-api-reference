# Stop Resync with Couchbase Capella

Stops a resync in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/resync`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Stop Resync](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteAppEndpointResync)
