# Turn Off Model with Couchbase Capella

Turns off a model in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn Off Model](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/modelOff)
