# Delete Scope with Couchbase Capella

Deletes a scope from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes/:scopeName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Scope](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/deleteScopeByName)
