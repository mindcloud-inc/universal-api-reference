# Create Project with Couchbase Capella

Creates a project in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Projects/operation/postProject)
