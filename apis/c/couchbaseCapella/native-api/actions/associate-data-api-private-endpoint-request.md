# Accept Data API Private Endpoint Connection with Couchbase Capella

Accepts a data API private endpoint connection in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI/privateEndpoints/:endpointId/associate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Accept Data API Private Endpoint Connection](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/associateDataAPIPrivateEndpointRequest)
