# Accept Private Endpoint Request with Couchbase Capella

Accepts a private endpoint request in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService/endpoints/:endpointId/associate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Accept Private Endpoint Request](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/acceptPrivateEndpoint)
