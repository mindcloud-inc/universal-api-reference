# Upsert Backup Schedule with Couchbase Capella

Upserts a backup schedule in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackupschedule`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Upsert Backup Schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups Schedule/operation/upsertCloudSnapshotBackupSchedule)
