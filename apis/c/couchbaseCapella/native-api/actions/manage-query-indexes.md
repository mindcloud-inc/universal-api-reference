# Manage Query Indexes with Couchbase Capella

Manages a query indexes in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/queryService/indexes`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Manage Query Indexes](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Query Indexes/operation/manageQueryIndexes)
