# Enable Azure CMEK For Project with Couchbase Capella

Enables an Azure CMEK for project in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmek/providers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Enable Azure CMEK For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/enableCMEKAzureProject)
