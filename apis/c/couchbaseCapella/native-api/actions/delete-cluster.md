# Delete Cluster with Couchbase Capella

Deletes a cluster from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/deleteCluster)
