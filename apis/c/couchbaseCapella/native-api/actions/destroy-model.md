# Delete Model with Couchbase Capella

Deletes a model from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Model](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/destroyModel)
