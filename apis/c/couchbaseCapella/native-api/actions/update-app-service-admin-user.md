# Update App Service Admin User with Couchbase Capella

Updates an app service admin user in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/adminUsers/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Service Admin User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/UpdateAppServiceAdminUser)
