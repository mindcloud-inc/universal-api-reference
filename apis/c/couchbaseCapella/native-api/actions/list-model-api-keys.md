# List API keys with Couchbase Capella

Retrieves API keys from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/apiKeys`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List API keys](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Model Services API Keys (AI Services)/operation/listModelAPIKeys)
