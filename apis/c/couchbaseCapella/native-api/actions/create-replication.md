# Create a new replication with Couchbase Capella

Creates a new replication in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create a new replication](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/createReplication)
