# List Organizations with Couchbase Capella

Retrieves organizations from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Organizations](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Organizations/operation/listOrganizations)
