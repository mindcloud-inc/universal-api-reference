# Get App Service Private Endpoints State with Couchbase Capella

Retrieves an app service private endpoints state from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service Private Endpoints State](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Private Endpoints/operation/getAppServicePrivateEndpoints)
