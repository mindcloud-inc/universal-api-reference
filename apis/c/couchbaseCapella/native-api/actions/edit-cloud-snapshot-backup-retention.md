# Edit Backup Retention with Couchbase Capella

Edits a backup retention in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups/:backupId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Edit Backup Retention](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/editCloudSnapshotBackupRetention)
