# Create Azure Key Metadata For Project with Couchbase Capella

Creates an Azure key metadata for project in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmek`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Azure Key Metadata For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/postCMEKAzureMetadataForProject)
