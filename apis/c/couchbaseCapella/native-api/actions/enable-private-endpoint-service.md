# Enable Private Endpoint Service with Couchbase Capella

Enables a private endpoint service in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Enable Private Endpoint Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/enablePrivateEndpointService)
