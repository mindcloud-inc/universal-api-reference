# Migrate Buckets with Couchbase Capella

Migrates a buckets in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/bucketStorageMigration`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Migrate Buckets](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/putBucketStorageBackend)
