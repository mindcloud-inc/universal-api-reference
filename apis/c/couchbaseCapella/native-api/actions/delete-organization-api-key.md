# Delete API Key with Couchbase Capella

Deletes an API key from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/apikeys/:ApiKeyId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete API Key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Api Keys/operation/deleteOrganizationAPIKey)
