# Get Azure VNET Peering CLI Command with Couchbase Capella

Retrieves an Azure VNET peering CLI command from Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/networkPeers/networkPeerCommand`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Azure VNET Peering CLI Command](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Network Peers/operation/getAzureVnetPeeringCommand)
