# List Cloud Accounts with Couchbase Capella

Retrieves cloud accounts from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/cloudAccounts`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cloud Accounts](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud-Accounts/operation/listCloudAccounts)
