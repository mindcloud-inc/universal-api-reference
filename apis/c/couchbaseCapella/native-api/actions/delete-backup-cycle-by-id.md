# Delete Backup Cycle with Couchbase Capella

Deletes a backup cycle from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/backups/:backupId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Backup Cycle](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backups & Restore (Bucket)/operation/deleteBackupCycleByID)
