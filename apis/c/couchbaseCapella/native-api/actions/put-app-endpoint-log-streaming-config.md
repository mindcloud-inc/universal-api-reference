# Update App Endpoint Log Streaming Config with Couchbase Capella

Updates an app endpoint log streaming config in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/logStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Endpoint Log Streaming Config](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Log Streaming/operation/putAppEndpointLogStreamingConfig)
