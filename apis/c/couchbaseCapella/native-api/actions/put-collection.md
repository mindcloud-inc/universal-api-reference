# Update Collection with Couchbase Capella

Updates a collection in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes/:scopeName/collections/:collectionName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Collection](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/putCollection)
