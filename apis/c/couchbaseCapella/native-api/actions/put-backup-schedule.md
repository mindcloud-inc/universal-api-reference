# Update Backup Schedule with Couchbase Capella

Updates a backup schedule in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/backup/schedules`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Backup Schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backup Schedule (Bucket)/operation/putBackupSchedule)
