# Pause App Service Log Streaming with Couchbase Capella

Pauses an app service log streaming in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/logStreaming/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Pause App Service Log Streaming](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Log Streaming/operation/pauseAppServiceLogStreaming)
