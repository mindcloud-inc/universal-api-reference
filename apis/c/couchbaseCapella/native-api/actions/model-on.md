# Turn On Model with Couchbase Capella

Turns on a model in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn On Model](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/modelOn)
