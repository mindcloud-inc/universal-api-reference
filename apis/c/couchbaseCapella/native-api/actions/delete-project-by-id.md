# Delete Project with Couchbase Capella

Deletes a project from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Projects/operation/deleteProjectByID)
