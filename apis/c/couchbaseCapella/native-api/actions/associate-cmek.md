# Associate Key with Cluster with Couchbase Capella

Associates a key with cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cmek/:cmekId/associate`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Associate Key with Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/AssociateCMEK)
