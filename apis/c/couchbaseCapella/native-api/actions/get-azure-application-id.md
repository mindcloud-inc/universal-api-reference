# Get Azure Application ID with Couchbase Capella

Retrieves an Azure application ID from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/cmekAzureApplication`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Azure Application ID](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/getAzureApplicationID)
