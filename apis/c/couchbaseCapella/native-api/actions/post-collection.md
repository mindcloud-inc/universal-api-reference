# Create Collection with Couchbase Capella

Creates a collection in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes/:scopeName/collections`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Collection](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/postCollection)
