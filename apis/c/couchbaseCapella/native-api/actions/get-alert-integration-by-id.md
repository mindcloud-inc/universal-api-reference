# Get Alert Integration with Couchbase Capella

Retrieves an alert integration from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrations/:alertIntegrationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Alert Integration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/getAlertIntegrationByID)
