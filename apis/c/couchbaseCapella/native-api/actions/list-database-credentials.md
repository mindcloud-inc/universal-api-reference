# List Database Credentials with Couchbase Capella

Retrieves database credentials from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/users`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Database Credentials](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Database Credentials/operation/listDatabaseCredentials)
