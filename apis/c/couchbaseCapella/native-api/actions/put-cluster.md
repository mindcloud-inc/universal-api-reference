# Update Cluster with Couchbase Capella

Updates a cluster in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/putCluster)
