# Upsert Import Filter with Couchbase Capella

Upserts an import filter in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointKeyspace/importFilter`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Upsert Import Filter](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/putImportFilter)
