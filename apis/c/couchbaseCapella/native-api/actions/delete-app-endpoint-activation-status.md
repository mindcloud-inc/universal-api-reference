# Pause or Take an App Endpoint offline with Couchbase Capella

Pauses an or take an app endpoint offline in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/activationStatus`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Pause or Take an App Endpoint offline](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteAppEndpointActivationStatus)
