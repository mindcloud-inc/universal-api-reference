# Update App Service with Couchbase Capella

Updates an app service in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/putAppService)
