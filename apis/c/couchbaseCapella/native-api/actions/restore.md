# Restore Backup with Couchbase Capella

Restores a backup in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups/:backupId/restore`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Restore Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/restore)
