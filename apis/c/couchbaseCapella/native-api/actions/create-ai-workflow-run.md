# Run an AI Workflow with Couchbase Capella

Runs an AI workflow in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows/:workflowId/runs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Run an AI Workflow](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/createAiWorkflowRun)
