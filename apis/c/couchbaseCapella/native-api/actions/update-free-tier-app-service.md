# Update Free Tier App Service with Couchbase Capella

Updates a free tier app service in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/freeTier/:appServiceId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Free Tier App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/updateFreeTierAppService)
