# List Allowed CIDRs for an App Service with Couchbase Capella

Retrieves allowed CIDRs for an app service from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/allowedcidrs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Allowed CIDRs for an App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Allowed CIDRs (App Services)/operation/listAppServiceAllowedCidrs)
