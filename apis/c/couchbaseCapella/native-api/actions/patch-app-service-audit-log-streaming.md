# Start or Resume Audit Log Streaming with Couchbase Capella

Starts an or resume audit log streaming in Couchbase Capella.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Start or Resume Audit Log Streaming](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/patchAppServiceAuditLogStreaming)
