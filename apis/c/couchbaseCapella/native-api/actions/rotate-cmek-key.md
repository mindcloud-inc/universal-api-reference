# Rotate Key with Couchbase Capella

Rotates a key in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/cmek/:cmekId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Rotate Key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/rotateCMEKKey)
