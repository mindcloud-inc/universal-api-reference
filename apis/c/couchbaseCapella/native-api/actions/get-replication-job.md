# Get replication job details with Couchbase Capella

Retrieves a replication job details from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/jobs/:jobId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get replication job details](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/getReplicationJob)
