# Create Alert Integration with Couchbase Capella

Creates an alert integration in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrations`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Alert Integration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/postAlertIntegration)
