# List App Service Private Endpoints with Couchbase Capella

Retrieves app service private endpoints from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/privateEndpointService/endpoints`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List App Service Private Endpoints](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Private Endpoints/operation/listAppServicePrivateEndpoints)
