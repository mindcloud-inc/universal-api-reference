# Update App Endpoint Default OIDC Provider with Couchbase Capella

Updates an app endpoint default OIDC provider in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/oidcProviders/defaultProvider`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Endpoint Default OIDC Provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/updateAppEndpointOIDCDefaultProvider)
