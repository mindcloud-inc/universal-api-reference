# Get Project with Couchbase Capella

Retrieves a project from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Projects/operation/getProjectByID)
