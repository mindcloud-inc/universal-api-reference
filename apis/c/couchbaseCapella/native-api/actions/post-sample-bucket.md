# Load Sample Data with Couchbase Capella

Loads a sample data in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/sampleBuckets`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Load Sample Data](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Sample Bucket/operation/postSampleBucket)
