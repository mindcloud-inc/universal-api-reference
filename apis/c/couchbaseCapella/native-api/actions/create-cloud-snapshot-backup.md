# Create Cloud Snapshot Backup with Couchbase Capella

Creates a cloud snapshot backup in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Cloud Snapshot Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/createCloudSnapshotBackup)
