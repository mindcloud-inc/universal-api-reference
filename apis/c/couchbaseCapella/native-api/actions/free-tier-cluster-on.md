# Turn On Free Tier Cluster with Couchbase Capella

Turns on a free tier cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/freeTier/:clusterId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn On Free Tier Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/freeTierClusterOn)
