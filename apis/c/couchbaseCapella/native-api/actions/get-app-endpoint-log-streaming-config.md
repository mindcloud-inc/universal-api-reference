# Get App Endpoint Log Streaming Config with Couchbase Capella

Retrieves an app endpoint log streaming config from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/logStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Endpoint Log Streaming Config](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Log Streaming/operation/getAppEndpointLogStreamingConfig)
