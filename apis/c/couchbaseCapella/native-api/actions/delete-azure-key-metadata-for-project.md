# Delete Azure Key Metadata For Project with Couchbase Capella

Deletes an Azure key metadata for project from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmek/:cmekId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Azure Key Metadata For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/deleteAzureKeyMetadataForProject)
