# Get Backup Schedule with Couchbase Capella

Retrieves a backup schedule from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackupschedule`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Backup Schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups Schedule/operation/getCloudSnapshotBackupSchedule)
