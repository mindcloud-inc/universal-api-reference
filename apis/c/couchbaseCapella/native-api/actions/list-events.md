# List Events with Couchbase Capella

Retrieves events from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/events`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Events](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Events/operation/listEvents)
