# Update Free Tier Bucket with Couchbase Capella

Updates a free tier bucket in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/freeTier/:bucketId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Free Tier Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/updateFreeTierBucket)
