# Create Scope with Couchbase Capella

Creates a scope in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/scopes`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Scope](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/postScope)
