# Get Cluster On/Off schedule with Couchbase Capella

Retrieves a cluster on/off schedule from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/onOffSchedule`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Cluster On/Off schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/On/Off Schedule/operation/getOnOffSchedule)
