# Get Project Event with Couchbase Capella

Retrieves a project event from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/events/:eventId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Project Event](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Events/operation/getProjectEventByID)
