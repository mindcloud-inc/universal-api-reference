# Update Organization Configuration with Couchbase Capella

Updates an organization configuration in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/configuration`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Organization Configuration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Organizations/operation/putOrganizationConfiguration)
