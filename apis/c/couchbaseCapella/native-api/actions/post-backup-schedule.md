# Create Backup Schedule with Couchbase Capella

Creates a backup schedule in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/backup/schedules`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Backup Schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backup Schedule (Bucket)/operation/postBackupSchedule)
