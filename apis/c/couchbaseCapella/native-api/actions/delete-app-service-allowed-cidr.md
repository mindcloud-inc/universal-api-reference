# Delete App Service Allowed CIDR with Couchbase Capella

Deletes an app service allowed CIDR from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/allowedcidrs/:allowedCidrId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete App Service Allowed CIDR](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Allowed CIDRs (App Services)/operation/deleteAppServiceAllowedCidr)
