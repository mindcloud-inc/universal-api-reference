# Create Free Tier Cluster with Couchbase Capella

Creates a free tier cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/freeTier`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Free Tier Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/createFreeTierCluster)
