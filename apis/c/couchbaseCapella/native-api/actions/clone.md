# Clone Cluster Backup with Couchbase Capella

Clones a cluster backup in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cloudsnapshotbackups/:backupId/clone`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Clone Cluster Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/clone)
