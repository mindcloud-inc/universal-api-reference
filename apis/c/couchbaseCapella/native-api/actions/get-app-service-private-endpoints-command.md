# Get App Service Private Endpoints Command with Couchbase Capella

Retrieves an app service private endpoints command from Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/privateEndpointService/privateEndpointCommand`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service Private Endpoints Command](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Private Endpoints/operation/getAppServicePrivateEndpointsCommand)
