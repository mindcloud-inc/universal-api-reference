# Delete Import Filter with Couchbase Capella

Deletes an import filter from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointKeyspace/importFilter`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Import Filter](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteImportFilter)
