# List AI Workflow Runs with Couchbase Capella

Retrieves AI workflow runs from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows/:workflowId/runs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List AI Workflow Runs](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/listAiWorkflowRuns)
