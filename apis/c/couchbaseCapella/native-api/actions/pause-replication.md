# Pause a replication with Couchbase Capella

Pauses a replication in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/:replicationId/activationStatus`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Pause a replication](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/pauseReplication)
