# Update an existing replication with Couchbase Capella

Updates an existing replication in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/:replicationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update an existing replication](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/updateReplication)
