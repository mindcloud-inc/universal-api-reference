# Update Project with Couchbase Capella

Updates a project in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Projects/operation/putProject)
