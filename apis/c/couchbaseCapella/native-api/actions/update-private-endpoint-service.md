# Update Private Endpoint Service Configuration with Couchbase Capella

Updates a private endpoint service configuration in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Private Endpoint Service Configuration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/updatePrivateEndpointService)
