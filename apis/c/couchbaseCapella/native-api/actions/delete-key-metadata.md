# Delete Key Metadata with Couchbase Capella

Deletes a key metadata from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/cmek/:cmekId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Key Metadata](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/deleteKeyMetadata)
