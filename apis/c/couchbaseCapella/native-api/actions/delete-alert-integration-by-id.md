# Delete Alert Integration with Couchbase Capella

Deletes an alert integration from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrations/:alertIntegrationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Alert Integration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/deleteAlertIntegrationByID)
