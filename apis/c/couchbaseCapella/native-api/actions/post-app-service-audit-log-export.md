# Initiate Audit Log Export with Couchbase Capella

Initiates an audit log export in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLogExports`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Initiate Audit Log Export](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/postAppServiceAuditLogExport)
