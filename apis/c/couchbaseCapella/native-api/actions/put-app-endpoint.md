# Update App Endpoint with Couchbase Capella

Updates an app endpoint in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/putAppEndpoint)
