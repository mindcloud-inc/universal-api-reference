# Create API Key with Couchbase Capella

Creates an API key in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/apiKeys`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create API Key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Model Services API Keys (AI Services)/operation/createModelAPIKey)
