# Flush Bucket Data with Couchbase Capella

Flushes a bucket data in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/flush`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Flush Bucket Data](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/FlushBucket)
