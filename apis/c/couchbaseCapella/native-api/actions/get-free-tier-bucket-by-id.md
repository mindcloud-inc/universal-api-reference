# Get Free Tier Bucket with Couchbase Capella

Retrieves a free tier bucket from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/freeTier/:bucketId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Free Tier Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/getFreeTierBucketByID)
