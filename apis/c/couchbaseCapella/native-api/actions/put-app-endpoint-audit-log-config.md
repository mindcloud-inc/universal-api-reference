# Update App Endpoint Audit Logging Config with Couchbase Capella

Updates an app endpoint audit logging config in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName/auditLog`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update App Endpoint Audit Logging Config](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/putAppEndpointAuditLogConfig)
