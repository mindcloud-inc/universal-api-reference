# Get Certificate with Couchbase Capella

Retrieves a certificate from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/certificates`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Certificate](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Certificates/operation/getCertificate)
