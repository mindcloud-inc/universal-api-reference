# Pause Cluster On/Off Schedule with Couchbase Capella

Pauses a cluster on/off schedule in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/onOffSchedule/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Pause Cluster On/Off Schedule](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/On/Off Schedule/operation/pauseClusterOnOffSchedule)
