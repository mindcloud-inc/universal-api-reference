# Get Key Metadata with Couchbase Capella

Retrieves a key metadata from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/cmek/:cmekId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Key Metadata](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/getKeyMetadata)
