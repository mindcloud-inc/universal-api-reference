# Get Database Credentials with Couchbase Capella

Retrieves a database credentials from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Database Credentials](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Database Credentials/operation/getDatabaseCredential)
