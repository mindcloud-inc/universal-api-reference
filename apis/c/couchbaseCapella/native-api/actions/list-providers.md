# List providers with Couchbase Capella

Retrieves providers from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/providers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List providers](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Services Providers/operation/listProviders)
