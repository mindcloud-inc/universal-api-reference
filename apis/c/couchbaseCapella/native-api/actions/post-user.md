# Create User with Couchbase Capella

Creates a user in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/users`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Users/operation/postUser)
