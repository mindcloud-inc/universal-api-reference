# Get Private Endpoint Service Status with Couchbase Capella

Retrieves a private endpoint service status from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Private Endpoint Service Status](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/getPrivateEndpointServiceStatus)
