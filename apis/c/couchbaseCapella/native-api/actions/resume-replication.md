# Resume a replication with Couchbase Capella

Resumes a replication in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/:replicationId/activationStatus`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Resume a replication](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/resumeReplication)
