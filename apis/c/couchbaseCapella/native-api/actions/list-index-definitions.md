# Get List Of Index Definitions with Couchbase Capella

Retrieves a list of index definitions from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/queryService/indexes`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get List Of Index Definitions](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Query Indexes/operation/listIndexDefinitions)
