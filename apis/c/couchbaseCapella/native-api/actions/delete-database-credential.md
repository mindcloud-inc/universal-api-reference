# Delete Database Credentials with Couchbase Capella

Deletes a database credentials from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Database Credentials](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Database Credentials/operation/deleteDatabaseCredential)
