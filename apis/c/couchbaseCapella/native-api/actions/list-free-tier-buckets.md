# List Free Tier Buckets with Couchbase Capella

Retrieves free tier buckets from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/freeTier`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Free Tier Buckets](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/listFreeTierBuckets)
