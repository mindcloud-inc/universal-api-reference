# Stop AI Workflow Run with Couchbase Capella

Stops an AI workflow run in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows/:workflowId/runs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Stop AI Workflow Run](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/stopAiWorkflowRun)
