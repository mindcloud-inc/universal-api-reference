# List AI Workflows with Couchbase Capella

Retrieves AI workflows from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List AI Workflows](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/listAiWorkflows)
