# Delete Allowed CIDR with Couchbase Capella

Deletes an allowed CIDR from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/allowedcidrs/:allowedCidrId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Allowed CIDR](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Allowed CIDRs (Cluster)/operation/deleteAllowedCidrByID)
