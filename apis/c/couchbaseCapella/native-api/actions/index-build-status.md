# Get Index Build Status with Couchbase Capella

Retrieves an index build status from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/queryService/indexBuildStatus/:indexName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Index Build Status](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Query Indexes/operation/indexBuildStatus)
