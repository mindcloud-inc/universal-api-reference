# List replications for a given cluster with Couchbase Capella

Retrieves replications for a given cluster from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List replications for a given cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/listClusterReplications)
