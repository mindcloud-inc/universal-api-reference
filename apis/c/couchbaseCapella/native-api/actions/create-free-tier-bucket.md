# Create Free Tier Bucket with Couchbase Capella

Creates a free tier bucket in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/freeTier`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Free Tier Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/createFreeTierBucket)
