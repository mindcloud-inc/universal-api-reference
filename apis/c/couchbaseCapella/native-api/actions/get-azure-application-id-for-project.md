# Get Azure Application ID For Project with Couchbase Capella

Retrieves an Azure application ID for a project from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmekAzureApplication`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Azure Application ID For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/getAzureApplicationIDForProject)
