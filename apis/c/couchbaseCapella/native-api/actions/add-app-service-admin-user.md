# Create App Service Admin User with Couchbase Capella

Creates an app service admin user in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/adminUsers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create App Service Admin User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/AddAppServiceAdminUser)
