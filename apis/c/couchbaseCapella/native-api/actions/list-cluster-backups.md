# List Cluster Backups with Couchbase Capella

Retrieves cluster backups from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/backups`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cluster Backups](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backups & Restore (Bucket)/operation/listClusterBackups)
