# Delete a replication with Couchbase Capella

Deletes a replication from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/replications/:replicationId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete a replication](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/deleteReplication)
