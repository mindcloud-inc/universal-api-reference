# Enable App Service Private Endpoints with Couchbase Capella

Enables an app service private endpoints in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/privateEndpointService`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Enable App Service Private Endpoints](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Private Endpoints/operation/postAppServicePrivateEndpoints)
