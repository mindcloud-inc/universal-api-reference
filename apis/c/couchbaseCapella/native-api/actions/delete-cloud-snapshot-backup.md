# Delete Backup with Couchbase Capella

Deletes a backup from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups/:backupId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/deleteCloudSnapshotBackup)
