# Delete User with Couchbase Capella

Deletes a user from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/users/:userId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete User](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Users/operation/deleteUser)
