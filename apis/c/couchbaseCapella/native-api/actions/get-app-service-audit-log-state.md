# Get App Service Audit Log State with Couchbase Capella

Retrieves an app service audit log state from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/auditLog`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service Audit Log State](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Audit Logging/operation/getAppServiceAuditLogState)
