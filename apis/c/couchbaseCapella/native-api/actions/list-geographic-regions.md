# List Available Geographic Regions for Cross-region Operations with Couchbase Capella

Retrieves available geographic regions for cross-region operations from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups/regions`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Available Geographic Regions for Cross-region Operations](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/ListGeographicRegions)
