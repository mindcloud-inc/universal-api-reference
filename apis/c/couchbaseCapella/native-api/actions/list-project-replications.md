# List replications for a given project with Couchbase Capella

Retrieves replications for a given project from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/replications`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List replications for a given project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Replications/operation/listProjectReplications)
