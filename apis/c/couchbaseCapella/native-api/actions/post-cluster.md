# Create Cluster with Couchbase Capella

Creates a cluster in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/postCluster)
