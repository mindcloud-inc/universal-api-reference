# Turn Off Cluster with Couchbase Capella

Turns off a cluster in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn Off Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/clusterOff)
