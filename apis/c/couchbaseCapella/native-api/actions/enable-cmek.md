# Enable CMEK For Cloud Services Provider with Couchbase Capella

Enables a CMEK for cloud services provider in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/cmek/providers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Enable CMEK For Cloud Services Provider](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/enableCMEK)
