# Get CLI Commands For Setting Up Private Endpoint Connection with Couchbase Capella

Retrieves CLI commands for a private endpoint connection from Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI/privateEndpointCommand`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get CLI Commands For Setting Up Private Endpoint Connection](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/getDataAPIPrivateEndpointCommand)
