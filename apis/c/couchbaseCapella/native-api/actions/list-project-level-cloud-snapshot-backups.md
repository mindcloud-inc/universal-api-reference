# List Cloud Snapshot Backups at the Project Level with Couchbase Capella

Retrieves cloud snapshot backups at the project level from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cloudsnapshotbackups`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cloud Snapshot Backups at the Project Level](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/listProjectLevelCloudSnapshotBackups)
