# Update Free Tier Cluster with Couchbase Capella

Updates a free tier cluster in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/freeTier/:clusterId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Update Free Tier Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/updateFreeTierCluster)
