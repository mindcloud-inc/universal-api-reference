# Delete AI Workflow with Couchbase Capella

Deletes an AI workflow from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows/:workflowId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete AI Workflow](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/deleteAiWorkflow)
