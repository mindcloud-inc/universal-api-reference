# Create Database Credentials with Couchbase Capella

Creates a database credentials in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/users`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Database Credentials](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Database Credentials/operation/postDatabaseCredential)
