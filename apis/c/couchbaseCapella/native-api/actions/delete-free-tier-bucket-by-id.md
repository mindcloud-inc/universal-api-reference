# Delete Free Tier Bucket with Couchbase Capella

Deletes a free tier bucket from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/freeTier/:bucketId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Free Tier Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/deleteFreeTierBucketByID)
