# List App Service Admin Users with Couchbase Capella

Retrieves app service admin users from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/adminUsers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List App Service Admin Users](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/ListAppServiceAdminUsers)
