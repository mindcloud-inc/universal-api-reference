# Create Bucket with Couchbase Capella

Creates a bucket in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Bucket](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Buckets, Scopes, & Collections/operation/postBucket)
