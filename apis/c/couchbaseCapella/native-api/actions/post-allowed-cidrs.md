# Create Allowed CIDR with Couchbase Capella

Creates an allowed CIDR in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/allowedcidrs`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Allowed CIDR](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Allowed CIDRs (Cluster)/operation/postAllowedCidrs)
