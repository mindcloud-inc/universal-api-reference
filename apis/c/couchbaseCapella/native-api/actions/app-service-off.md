# Turn Off App Service with Couchbase Capella

Turns off an app service in Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Turn Off App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/appServiceOff)
