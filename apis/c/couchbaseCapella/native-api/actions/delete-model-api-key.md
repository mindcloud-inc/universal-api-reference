# Delete API key with Couchbase Capella

Deletes an API key from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/apiKeys/:apiKeyId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete API key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Model Services API Keys (AI Services)/operation/deleteModelAPIKey)
