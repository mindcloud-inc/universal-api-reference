# List Filterable Audit Log Events with Couchbase Capella

Retrieves filterable audit log events from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/auditLogEvents`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Filterable Audit Log Events](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Audit Logs/operation/getAuditLogEventIDs)
