# Delete App Service with Couchbase Capella

Deletes an app service from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services/operation/deleteAppService)
