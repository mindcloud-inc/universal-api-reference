# Test Alert Integration with Couchbase Capella

Tests an alert integration in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/alertIntegrationTest`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Test Alert Integration](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Alert Integration/operation/postTestAlertIntegration)
