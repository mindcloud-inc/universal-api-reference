# Resume App Service Log Streaming with Couchbase Capella

Resumes an app service log streaming in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/logStreaming/activationState`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Resume App Service Log Streaming](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Log Streaming/operation/resumeAppServiceLogStreaming)
