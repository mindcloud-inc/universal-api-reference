# Get Cluster Capacity Statistics with Couchbase Capella

Retrieves a cluster capacity statistics from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/stats`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Cluster Capacity Statistics](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Clusters/operation/getClusterStats)
