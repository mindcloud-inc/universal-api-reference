# Rotate Azure Key For Project with Couchbase Capella

Rotates an Azure key for project in Couchbase Capella.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/cmek/:cmekId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Rotate Azure Key For Project](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/rotateAzureKeyMetadataForProject)
