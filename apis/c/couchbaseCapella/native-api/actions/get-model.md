# Get Model with Couchbase Capella

Retrieves a model from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Model](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/getModel)
