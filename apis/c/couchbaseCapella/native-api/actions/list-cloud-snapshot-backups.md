# List Cloud Snapshot Backups with Couchbase Capella

Retrieves cloud snapshot backups from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cloud Snapshot Backups](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/listCloudSnapshotBackups)
