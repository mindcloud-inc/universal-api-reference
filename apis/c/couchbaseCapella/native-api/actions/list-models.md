# List Models with Couchbase Capella

Retrieves models from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/models`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Models](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/listModels)
