# Get Data API Status with Couchbase Capella

Retrieves Data API status from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/dataAPI`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Data API Status](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Data API/operation/getDataAPIStatus)
