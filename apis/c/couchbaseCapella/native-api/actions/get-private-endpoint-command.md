# Get Private Endpoint CLI Command required to setup private endpoint for specific CSP with Couchbase Capella

Retrieves a private endpoint CLI command from Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/privateEndpointService/endpointCommand`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Private Endpoint CLI Command required to setup private endpoint for specific CSP](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Private Endpoint Service/operation/getPrivateEndpointCommand)
