# Get Model Connection String with Couchbase Capella

Retrieves a model connection string from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/:modelId/connectionString`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Model Connection String](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Models (AI Services)/operation/getConnectionString)
