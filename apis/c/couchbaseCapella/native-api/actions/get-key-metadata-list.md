# List Key Metadata with Couchbase Capella

Retrieves key metadata from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/cmek`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Key Metadata](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/CMEK/operation/getKeyMetadataList)
