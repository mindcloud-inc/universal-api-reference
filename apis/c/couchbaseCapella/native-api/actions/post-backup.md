# Create Backup with Couchbase Capella

Creates a backup in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/backups`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backups & Restore (Bucket)/operation/postBackup)
