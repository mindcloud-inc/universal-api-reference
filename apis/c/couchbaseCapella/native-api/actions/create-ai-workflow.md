# Create AI Workflow with Couchbase Capella

Creates an AI workflow in Couchbase Capella.

## Endpoint

- **Method:** `POST`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Create AI Workflow](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/createAiWorkflow)
