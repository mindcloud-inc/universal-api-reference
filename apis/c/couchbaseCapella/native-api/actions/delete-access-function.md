# Delete Access Control and Validation function with Couchbase Capella

Deletes an access control and validation function from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointKeyspace/accessControlFunction`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Access Control and Validation function](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteAccessFunction)
