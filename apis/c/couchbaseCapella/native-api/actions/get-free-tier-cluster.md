# Get Free Tier Cluster with Couchbase Capella

Retrieves a free tier cluster from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/freeTier/:clusterId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Free Tier Cluster](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/getFreeTierCluster)
