# Get Backup with Couchbase Capella

Retrieves a backup from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/backups/:backupId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Backup](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backups & Restore (Bucket)/operation/getBackupByID)
