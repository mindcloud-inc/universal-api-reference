# List Network Peering Records with Couchbase Capella

Retrieves network peering records from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/networkPeers`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Network Peering Records](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Network Peers/operation/listNetworkPeeringRecords)
