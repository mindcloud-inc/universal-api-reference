# Get Index Properties with Couchbase Capella

Retrieves an index properties from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/queryService/indexes/:indexName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get Index Properties](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Query Indexes/operation/indexDefinition)
