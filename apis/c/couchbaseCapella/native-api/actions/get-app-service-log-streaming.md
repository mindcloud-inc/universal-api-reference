# Get App Service Log Streaming Configuration and State with Couchbase Capella

Retrieves an app service log streaming configuration and state from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/logStreaming`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get App Service Log Streaming Configuration and State](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Services Log Streaming/operation/getAppServiceLogStreaming)
