# Delete App Endpoint with Couchbase Capella

Deletes an app endpoint from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints/:appEndpointName`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete App Endpoint](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/deleteAppEndpoint)
