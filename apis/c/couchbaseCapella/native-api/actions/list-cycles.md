# List Cycles with Couchbase Capella

Retrieves cycles from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/buckets/:bucketId/backup/cycles`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cycles](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Backup Schedule (Bucket)/operation/listCycles)
