# Get AI Workflow Run Processed Files with Couchbase Capella

Retrieves an AI workflow run processed files from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/aiServices/workflows/:workflowId/runs/:runId/processedFiles`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get AI Workflow Run Processed Files](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/AI Workflows/operation/getAiWorkflowRunProcessedFiles)
