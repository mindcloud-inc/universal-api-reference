# Delete Free Tier App Service with Couchbase Capella

Deletes a free tier app service from Couchbase Capella.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/freeTier/:appServiceId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Delete Free Tier App Service](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Free Tier/operation/deleteFreeTierAppService)
