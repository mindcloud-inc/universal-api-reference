# Get API Key with Couchbase Capella

Retrieves an API key from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/aiServices/models/apiKeys/:apiKeyId`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [Get API Key](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Model Services API Keys (AI Services)/operation/getModelAPIKey)
