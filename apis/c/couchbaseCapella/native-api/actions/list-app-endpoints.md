# List App Endpoints with Couchbase Capella

Retrieves app endpoints from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/appservices/:appServiceId/appEndpoints`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List App Endpoints](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/App Endpoints/operation/listAppEndpoints)
