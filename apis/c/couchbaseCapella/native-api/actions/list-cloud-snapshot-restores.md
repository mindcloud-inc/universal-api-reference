# List Cloud Snapshot Restores with Couchbase Capella

Retrieves cloud snapshot restores from Couchbase Capella.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/organizations/:organizationId/projects/:projectId/clusters/:clusterId/cloudsnapshotbackups/restores`
- **Base URL:** `https://cloudapi.cloud.couchbase.com`
- **Official documentation:** [List Cloud Snapshot Restores](https://docs.couchbase.com/cloud/management-api-reference/index.html#tag/Cloud Snapshot Backups & Restore/operation/listCloudSnapshotRestores)
