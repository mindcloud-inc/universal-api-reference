# Download Graph Image with Columns AI

Downloads a graph image from Columns AI by visual ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sdk/image/:id`
- **Base URL:** `https://columns.ai/api`
- **Official documentation:** [Download Graph Image](https://github.com/varchar-io/vaas/blob/main/src/index.ts#L310-L329)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Columns visual ID whose image should be downloaded. |
