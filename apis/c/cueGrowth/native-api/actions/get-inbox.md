# Get Inbox with CueGrowth

## Endpoint

- **Method:** `GET`
- **Path:** `/inbox/{inbox_id}`
- **Base URL:** `https://api.cuegrowth.ai/public/api`
- **Official documentation:** [Get Inbox](https://cuegrowth.ai/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inbox_id` | path | `string` | yes | ID of the inbox. |
