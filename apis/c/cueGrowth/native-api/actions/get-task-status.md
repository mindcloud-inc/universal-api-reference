# Get Task Status with CueGrowth

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/{id}/status`
- **Base URL:** `https://api.cuegrowth.ai/public/api`
- **Official documentation:** [Get Task Status](https://cuegrowth.ai/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the task. |
