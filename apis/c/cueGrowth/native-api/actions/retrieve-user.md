# Retrieve User with CueGrowth

## Endpoint

- **Method:** `GET`
- **Path:** `/users/retrieve`
- **Base URL:** `https://api.cuegrowth.ai/public/api`
- **Official documentation:** [Retrieve User](https://cuegrowth.ai/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Email of the user. |
| `id` | query | `number` | no | ID of the user. |
