# List Campaigns by Receiver with CueGrowth

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/get_all_by_receiver/{receiver_id}`
- **Base URL:** `https://api.cuegrowth.ai/public/api`
- **Official documentation:** [List Campaigns by Receiver](https://cuegrowth.ai/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `receiver_id` | path | `string` | yes | ID of the receiver. |
