# Retrieve Receiver with CueGrowth

## Endpoint

- **Method:** `GET`
- **Path:** `/receivers/retrieve`
- **Base URL:** `https://api.cuegrowth.ai/public/api`
- **Official documentation:** [Retrieve Receiver](https://cuegrowth.ai/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `receiver_id` | query | `number` | no | ID of the receiver. |
| `username` | query | `string` | no | LinkedIn username of the receiver. |
