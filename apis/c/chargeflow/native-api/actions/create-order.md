# Create Order with Chargeflow

Creates a new dispute order in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/{disputeId}/order`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Create Order](https://docs.chargeflow.io/reference/post_public-2025-04-01-disputeid-order-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | The Chargeflow dispute ID. |
