# Verify Access Key with Chargeflow

Verifies a Chargeflow API access key.

## Endpoint

- **Method:** `GET`
- **Path:** `/health-check/access-key`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Verify Access Key](https://docs.chargeflow.io/reference/get_public-2025-04-01-health-check-access-key-1)
