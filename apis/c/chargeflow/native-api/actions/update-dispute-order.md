# Update Dispute Order with Chargeflow

Updates dispute order details in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/disputes/{disputeId}/order`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Update Dispute Order](https://docs.chargeflow.io/reference/post_public-2025-04-01-disputes-disputeid-order-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | The Chargeflow dispute ID. |
