# Generate Evidence with Chargeflow

Generates evidence for an existing dispute in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/evidence`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Generate Evidence](https://docs.chargeflow.io/reference/post_public-2025-04-01-evidence)
