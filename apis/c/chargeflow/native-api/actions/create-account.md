# Create Account with Chargeflow

Creates a new Chargeflow Connect account.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Create Account](https://docs.chargeflow.io/reference/post_public-2025-04-01-accounts-1)
