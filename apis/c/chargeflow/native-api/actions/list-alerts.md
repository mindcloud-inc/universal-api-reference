# List Alerts with Chargeflow

Retrieves alerts from your Chargeflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [List Alerts](https://docs.chargeflow.io/reference/get_public-2025-04-01-alerts-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of records to return. |
