# Revoke Integration Access with Chargeflow

Revokes access for an existing Chargeflow integration.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/integrations/{integrationId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Revoke Integration Access](https://docs.chargeflow.io/reference/delete_public-2025-04-01-integrations-integrationid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `string` | yes | The Chargeflow integration ID. |
