# Create User Event Log with Chargeflow

Creates a user event log in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/disputes/{disputeId}/user_events_log`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Create User Event Log](https://docs.chargeflow.io/reference/post_public-2025-04-01-disputes-disputeid-user-events-log-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | The Chargeflow dispute ID. |
