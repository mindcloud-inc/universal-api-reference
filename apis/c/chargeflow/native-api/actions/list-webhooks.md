# List Webhooks with Chargeflow

Retrieves webhooks from your Chargeflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [List Webhooks](https://docs.chargeflow.io/reference/get_public-2025-04-01-webhooks-1)
