# Get Evidence By ID with Chargeflow

Retrieves existing dispute evidence from Chargeflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/evidence/{evidenceId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Get Evidence By ID](https://docs.chargeflow.io/reference/get_public-2025-04-01-evidence-evidenceid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `evidenceId` | path | `string` | yes | The Chargeflow evidence ID. |
