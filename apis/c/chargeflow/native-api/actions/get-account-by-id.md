# Get Account By ID with Chargeflow

Retrieves an existing Chargeflow Connect account.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/{accountId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Get Account By ID](https://docs.chargeflow.io/reference/get_public-2025-04-01-accounts-accountid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The Chargeflow account ID. |
