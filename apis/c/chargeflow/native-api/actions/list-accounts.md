# List Accounts with Chargeflow

Retrieves Chargeflow Connect accounts from your workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [List Accounts](https://docs.chargeflow.io/reference/get_public-2025-04-01-accounts-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of records to return. |
