# Delete Webhook with Chargeflow

Deletes an existing webhook from Chargeflow.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{id}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Delete Webhook](https://docs.chargeflow.io/reference/delete_public-2025-04-01-webhooks-id-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Chargeflow webhook ID. |
