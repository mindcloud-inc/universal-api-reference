# Update Alert Outcome with Chargeflow

Updates an existing alert outcome in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/alerts/{alertId}/outcome`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Update Alert Outcome](https://docs.chargeflow.io/reference/post_public-2025-04-01-alerts-alertid-outcome)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `string` | yes | The Chargeflow alert ID. |
