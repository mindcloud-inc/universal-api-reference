# Get Dispute By ID with Chargeflow

Retrieves an existing dispute from Chargeflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/disputes/{disputeId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Get Dispute By ID](https://docs.chargeflow.io/reference/get_public-2025-04-01-disputes-disputeid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | The Chargeflow dispute ID. |
