# Create Subscription with Chargeflow

Creates a new dispute subscription in Chargeflow.

## Endpoint

- **Method:** `POST`
- **Path:** `/disputes/{disputeId}/subscription`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Create Subscription](https://docs.chargeflow.io/reference/post_public-2025-04-01-disputes-disputeid-subscription-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `disputeId` | path | `string` | yes | The Chargeflow dispute ID. |
