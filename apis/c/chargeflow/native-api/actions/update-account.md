# Update Account with Chargeflow

Updates an existing Chargeflow Connect account.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/accounts/{accountId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Update Account](https://docs.chargeflow.io/reference/patch_public-2025-04-01-accounts-accountid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | The Chargeflow account ID. |
