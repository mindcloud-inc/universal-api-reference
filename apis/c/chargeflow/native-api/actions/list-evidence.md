# List Evidence with Chargeflow

Retrieves dispute evidence from your Chargeflow account.

## Endpoint

- **Method:** `GET`
- **Path:** `/evidence`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [List Evidence](https://docs.chargeflow.io/reference/get_public-2025-04-01-evidence)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `number` | no | Maximum number of records to return. |
