# Update Integration with Chargeflow

Updates an existing integration in Chargeflow.

## Endpoint

- **Method:** `PUT`
- **Path:** `/integrations/{integrationId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Update Integration](https://docs.chargeflow.io/reference/put_public-2025-04-01-integrations-integrationid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `string` | yes | The Chargeflow integration ID. |
