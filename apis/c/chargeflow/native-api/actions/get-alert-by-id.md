# Get Alert By ID with Chargeflow

Retrieves an existing alert from Chargeflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/{alertId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Get Alert By ID](https://docs.chargeflow.io/reference/get_public-2025-04-01-alerts-alertid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alertId` | path | `string` | yes | The Chargeflow alert ID. |
