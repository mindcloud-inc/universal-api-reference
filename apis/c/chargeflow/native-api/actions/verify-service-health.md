# Verify Service Health with Chargeflow

Checks the current Chargeflow service health status.

## Endpoint

- **Method:** `GET`
- **Path:** `/health-check`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Verify Service Health](https://docs.chargeflow.io/reference/get_public-2025-04-01-health-check-1)
