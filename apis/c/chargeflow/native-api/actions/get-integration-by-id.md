# Get Integration By ID with Chargeflow

Retrieves an existing integration from Chargeflow.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/{integrationId}`
- **Base URL:** `https://api.chargeflow.io/public/2025-04-01`
- **Official documentation:** [Get Integration By ID](https://docs.chargeflow.io/reference/put_public-2025-04-01-integrations-integrationid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `integrationId` | path | `string` | yes | The Chargeflow integration ID. |
