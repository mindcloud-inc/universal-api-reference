# Update a Meeting with Cisco Webex Meetings

Updates an existing meeting in Cisco Webex Meetings.

## Endpoint

- **Method:** `PUT`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Update a Meeting](https://developer.webex.com/docs/api/v1/meetings/update-a-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | Unique identifier for the meeting to update. |
