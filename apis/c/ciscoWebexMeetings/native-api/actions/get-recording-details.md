# Get Recording Details with Cisco Webex Meetings

Retrieves recording details from Cisco Webex Meetings.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recordingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get Recording Details](https://developer.webex.com/docs/api/v1/recordings/get-recording-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordingId` | path | `string` | yes | Unique identifier for the recording. |
