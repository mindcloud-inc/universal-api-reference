# List Meeting Transcripts with Cisco Webex Meetings

Retrieves meeting transcripts from Cisco Webex Meetings.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetingTranscripts`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Meeting Transcripts](https://developer.webex.com/docs/api/v1/meeting-transcripts/list-meeting-transcripts)
