# Get a Meeting with Cisco Webex Meetings

Retrieves a meeting from Cisco Webex Meetings.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Get a Meeting](https://developer.webex.com/meeting/docs/api/v1/meetings/get-a-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | Unique identifier for the meeting being requested. |
