# Delete a Recording with Cisco Webex Meetings

Deletes an existing recording from Cisco Webex Meetings.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/recordings/:recordingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete a Recording](https://developer.webex.com/docs/api/v1/recordings/delete-a-recording)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordingId` | path | `string` | yes | Unique identifier for the recording to delete. |
