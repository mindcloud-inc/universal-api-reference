# Create a Meeting with Cisco Webex Meetings

Creates a new meeting in Cisco Webex Meetings.

## Endpoint

- **Method:** `POST`
- **Path:** `/meetings`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Create a Meeting](https://developer.webex.com/docs/api/v1/meetings/create-a-meeting)
