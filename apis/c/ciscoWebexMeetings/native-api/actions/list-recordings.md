# List Recordings with Cisco Webex Meetings

Retrieves recordings from Cisco Webex Meetings.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [List Recordings](https://developer.webex.com/meeting/docs/api/v1/recordings/list-recordings)
