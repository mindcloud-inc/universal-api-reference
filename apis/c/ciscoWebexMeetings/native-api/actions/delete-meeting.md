# Delete a Meeting with Cisco Webex Meetings

Deletes an existing meeting from Cisco Webex Meetings.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/meetings/:meetingId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete a Meeting](https://developer.webex.com/docs/api/v1/meetings/delete-a-meeting)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `meetingId` | path | `string` | yes | Unique identifier for the meeting to delete. |
