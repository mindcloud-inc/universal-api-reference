# Delete a Summary with Cisco Webex Meetings

Deletes an existing meeting summary from Cisco Webex Meetings.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/meetingSummaries/:summaryId`
- **Base URL:** `https://webexapis.com/v1`
- **Official documentation:** [Delete a Summary](https://developer.webex.com/docs/api/v1/meeting-summaries/delete-a-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `summaryId` | path | `string` | yes | Unique identifier for the summary to delete. |
