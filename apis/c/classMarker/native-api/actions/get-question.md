# Get Question with ClassMarker

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/questions/{question_id}.json`
- **Base URL:** `https://api.classmarker.com`
- **Official documentation:** [Get Question](https://www.classmarker.com/online-testing/docs/api/#get-question)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `question_id` | path | `number` | yes | Numeric ClassMarker question ID. |
