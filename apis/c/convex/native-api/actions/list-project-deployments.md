# List Project Deployments with Convex

Retrieves deployments from a Convex project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/list_deployments`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Project Deployments](https://docs.convex.dev/management-api/list-deployments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Convex project ID. |
