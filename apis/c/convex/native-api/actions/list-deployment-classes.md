# List Deployment Classes with Convex

Retrieves deployment classes from a Convex team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id/list_deployment_classes`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Deployment Classes](https://docs.convex.dev/management-api/list-deployment-classes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `number` | yes | The Convex team ID. |
