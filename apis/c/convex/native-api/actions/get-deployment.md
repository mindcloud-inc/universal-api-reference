# Get Deployment with Convex

Retrieves a Convex deployment by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/deployments/:deployment_name`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [Get Deployment](https://docs.convex.dev/management-api/platform-get-deployment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deployment_name` | path | `string` | yes | The Convex deployment name. |
