# List Default Environment Variables with Convex

Retrieves default environment variables from a Convex project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/list_default_environment_variables`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Default Environment Variables](https://docs.convex.dev/production/environment-variables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Convex project ID. |
