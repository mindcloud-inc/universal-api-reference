# Delete Project with Convex

Deletes an existing project from Convex.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/delete`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [Delete Project](https://docs.convex.dev/management-api/delete-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Convex project ID. |
