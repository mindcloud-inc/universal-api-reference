# List Projects with Convex

Retrieves projects from a Convex team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id/list_projects`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Projects](https://docs.convex.dev/management-api/list-projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `number` | yes | The Convex team ID. |
