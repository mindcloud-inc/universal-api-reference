# List Local Deployments with Convex

Retrieves local deployments from a Convex team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id/list_local_deployments`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Local Deployments](https://docs.convex.dev/management-api/list-local-deployments-for-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `number` | yes | The Convex team ID. |
