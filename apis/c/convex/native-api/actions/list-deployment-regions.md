# List Deployment Regions with Convex

Retrieves deployment regions from a Convex team.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:team_id/list_deployment_regions`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [List Deployment Regions](https://docs.convex.dev/management-api/list-deployment-regions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | path | `number` | yes | The Convex team ID. |
