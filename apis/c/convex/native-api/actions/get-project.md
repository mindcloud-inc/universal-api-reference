# Get Project with Convex

Retrieves a project from Convex by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.convex.dev/v1`
- **Official documentation:** [Get Project](https://docs.convex.dev/management-api/get-project-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The Convex project ID. |
