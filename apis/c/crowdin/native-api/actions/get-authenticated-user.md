# Get Authenticated User with Crowdin

Retrieves the authenticated user from Crowdin.

## Endpoint

- **Method:** `GET`
- **Path:** `/user`
- **Base URL:** `https://api.crowdin.com/api/v2`
- **Official documentation:** [Get Authenticated User](https://support.crowdin.com/developer/api/v2/#operation/api.user.get)
