# Get Project with Crowdin

Retrieves a project from Crowdin.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://api.crowdin.com/api/v2`
- **Official documentation:** [Get Project](https://support.crowdin.com/developer/api/v2/#operation/api.projects.get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `number` | yes |
