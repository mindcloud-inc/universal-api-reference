# List Supported Languages with Crowdin

Retrieves supported languages from Crowdin.

## Endpoint

- **Method:** `GET`
- **Path:** `/languages`
- **Base URL:** `https://api.crowdin.com/api/v2`
- **Official documentation:** [List Supported Languages](https://support.crowdin.com/developer/api/v2/#operation/api.languages.getMany)

## Capabilities

This operation supports [pagination](../README.md#pagination).
