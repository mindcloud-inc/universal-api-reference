# Get Format Conversions with ConvertHub

Retrieves supported target formats for a source format in ConvertHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/formats/:format/conversions`
- **Base URL:** `https://api.converthub.com/v2`
- **Official documentation:** [Get Format Conversions](https://converthub.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `format` | path | `string` | yes |
