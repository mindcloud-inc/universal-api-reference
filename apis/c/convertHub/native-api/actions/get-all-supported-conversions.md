# Get All Supported Conversions with ConvertHub

Retrieves all supported conversion mappings from ConvertHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/formats/supported-conversions`
- **Base URL:** `https://api.converthub.com/v2`
- **Official documentation:** [Get All Supported Conversions](https://converthub.com/api/docs)
