# Delete Conversion File with ConvertHub

Deletes a completed conversion file from ConvertHub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/jobs/:jobId/destroy`
- **Base URL:** `https://api.converthub.com/v2`
- **Official documentation:** [Delete Conversion File](https://converthub.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
