# Cancel Job with ConvertHub

Cancels an active conversion job in ConvertHub.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/jobs/:jobId`
- **Base URL:** `https://api.converthub.com/v2`
- **Official documentation:** [Cancel Job](https://converthub.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
