# Get Job Status with ConvertHub

Retrieves a conversion job's status from ConvertHub.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/jobs/:jobId`
- **Base URL:** `https://api.converthub.com/v2`
- **Official documentation:** [Get Job Status](https://converthub.com/api/docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `string` | yes |
