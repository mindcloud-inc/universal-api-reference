# Get Vehicle Positions Feed with Caltrain

Retrieves the Caltrain vehicle positions feed.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/rt/vehiclepositions/CT.json`
- **Base URL:** `https://www.caltrain.com`
- **Official documentation:** [Get Vehicle Positions Feed](https://www.caltrain.com/developer-resources)
