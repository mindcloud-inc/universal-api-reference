# <img src="https://images.mindcloud.co/apps/icons/unnamed_1776181153014.png" alt="Corrently logo" width="28" height="28"> Corrently: Universal API

Corrently provides public energy APIs for GrünstromIndex forecasts, CO2 electricity advice, market prices, renewable dispatch, photovoltaic generation forecasts, schedules, and related German energy analytics.

- **Category:** Business Intelligence / Analytics & BI
