# Delete Field with Calculoid

## Endpoint

- **Method:** `POST`
- **Path:** `/calculator/deleteField/:fieldId`
- **Base URL:** `https://api.calculoid.com`
- **Official documentation:** [Delete Field](https://www.calculoid.com/documentation-new)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldId` | path | `string` | yes | Calculoid field ID to delete. |
