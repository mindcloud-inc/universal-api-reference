# Get Result with Calculoid

## Endpoint

- **Method:** `GET`
- **Path:** `/result/:resultId`
- **Base URL:** `https://api.calculoid.com`
- **Official documentation:** [Get Result](https://www.calculoid.com/documentation-new)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resultId` | path | `string` | yes | Calculoid result ID. |
