# Delete Field Option with Calculoid

## Endpoint

- **Method:** `POST`
- **Path:** `/option/delete/:optionId`
- **Base URL:** `https://api.calculoid.com`
- **Official documentation:** [Delete Field Option](https://www.calculoid.com/documentation-new)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `optionId` | path | `string` | yes | Calculoid option ID to delete. |
