# Create Field Option with Calculoid

## Endpoint

- **Method:** `POST`
- **Path:** `/option/create`
- **Base URL:** `https://api.calculoid.com`
- **Official documentation:** [Create Field Option](https://www.calculoid.com/documentation-new)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fieldId` | query | `string` | yes | Calculoid field ID to add an option to. |
