# Get Coupon with Cituro

Retrieves a coupon record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons/:couponId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Coupon](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `couponId` | path | `string` | yes | Cituro coupon identifier from the coupon resource path. |
