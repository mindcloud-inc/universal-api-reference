# Get Service with Cituro

Retrieves a service record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/:serviceId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Service](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `serviceId` | path | `string` | yes | Cituro service identifier from the service resource path. |
