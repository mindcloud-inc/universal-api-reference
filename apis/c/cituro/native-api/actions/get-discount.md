# Get Discount with Cituro

Retrieves a discount record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts/:discountId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Discount](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `discountId` | path | `string` | yes | Cituro discount identifier from the discount resource path. |
