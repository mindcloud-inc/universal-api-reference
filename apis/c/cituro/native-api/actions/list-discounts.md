# List Discounts with Cituro

Retrieves a list of discounts from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/discounts`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Discounts](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of discounts to return. |
