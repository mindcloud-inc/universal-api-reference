# List Coupons with Cituro

Retrieves a list of coupons from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/coupons`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Coupons](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of coupons to return. |
