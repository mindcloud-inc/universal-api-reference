# List Appointments with Cituro

Retrieves a list of appointments from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Appointments](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of appointments to return. |
