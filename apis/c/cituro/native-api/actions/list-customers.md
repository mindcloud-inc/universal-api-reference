# List Customers with Cituro

Retrieves a list of customers from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Customers](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of customers to return. |
