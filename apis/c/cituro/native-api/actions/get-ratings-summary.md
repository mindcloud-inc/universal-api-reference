# Get Ratings Summary with Cituro

Retrieves the ratings summary from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/ratings/:accountNumber/summary`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Ratings Summary](https://www.cituro.com/help/bewertungen-auf-webseite-einbinden)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountNumber` | path | `string` | yes | The Cituro account number used in the ratings endpoint path. |
