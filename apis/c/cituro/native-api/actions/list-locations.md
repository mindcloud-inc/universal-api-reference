# List Locations with Cituro

Retrieves a list of locations from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Locations](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of locations to return. |
