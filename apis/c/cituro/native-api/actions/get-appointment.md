# Get Appointment with Cituro

Retrieves an appointment record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/:appointmentId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Appointment](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appointmentId` | path | `string` | yes | Cituro appointment identifier from the appointment resource path. |
