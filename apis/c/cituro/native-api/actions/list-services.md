# List Services with Cituro

Retrieves a list of services from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/services`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Services](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of services to return. |
