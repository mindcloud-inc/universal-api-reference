# Get Location with Cituro

Retrieves a location record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/:locationId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Location](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `locationId` | path | `string` | yes | Cituro location identifier from the location resource path. |
