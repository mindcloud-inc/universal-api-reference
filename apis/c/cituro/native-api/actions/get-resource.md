# Get Resource with Cituro

Retrieves a resource record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:resourceId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Resource](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | Cituro resource identifier from the resource path. |
