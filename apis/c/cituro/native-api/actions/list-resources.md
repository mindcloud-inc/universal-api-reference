# List Resources with Cituro

Retrieves a list of resources from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [List Resources](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of resources to return. |
