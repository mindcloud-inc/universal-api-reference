# Get Customer with Cituro

Retrieves a customer record from Cituro.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://app.cituro.com/api`
- **Official documentation:** [Get Customer](https://www.cituro.com/help/developers-corner/schnittstellen)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Cituro customer identifier from the customer resource path. |
