# Delete Job with CloudConvert

Deletes a job from your CloudConvert account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Delete Job](https://cloudconvert.com/docs/api-reference/jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CloudConvert job ID. |
