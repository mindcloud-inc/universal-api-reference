# Delete Webhook with CloudConvert

Deletes a webhook from your CloudConvert account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Delete Webhook](https://cloudconvert.com/docs/api-reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CloudConvert webhook ID. |
