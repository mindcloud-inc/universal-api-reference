# Create Upload Task with CloudConvert

Creates an upload task in CloudConvert.

## Endpoint

- **Method:** `POST`
- **Path:** `/import/upload`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Create Upload Task](https://cloudconvert.com/docs/import-export/import-files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `redirect` | body | `string` | no | Optional redirect URL after the upload has finished. |
