# Get Job with CloudConvert

Retrieves a job from your CloudConvert account.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:id`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Get Job](https://cloudconvert.com/docs/api-reference/jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CloudConvert job ID. |
