# Cancel Task with CloudConvert

Cancels a task in your CloudConvert account.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks/:id/cancel`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Cancel Task](https://cloudconvert.com/docs/api-reference/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CloudConvert task ID. |
