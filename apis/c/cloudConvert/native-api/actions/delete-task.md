# Delete Task with CloudConvert

Deletes a task from your CloudConvert account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.cloudconvert.com/v2`
- **Official documentation:** [Delete Task](https://cloudconvert.com/docs/api-reference/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CloudConvert task ID. |
