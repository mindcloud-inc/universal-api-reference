# Get Doc with Coda

Retrieves details for a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Get Doc](https://coda.io/developers/apis/v1#tag/Docs/operation/getDoc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
