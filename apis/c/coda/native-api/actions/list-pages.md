# List Pages with Coda

Retrieves pages from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/pages`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [List Pages](https://coda.io/developers/apis/v1#tag/Pages/operation/listPages)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
