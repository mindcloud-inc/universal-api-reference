# Get Control with Coda

Retrieves control details from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/controls/:controlIdOrName`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Get Control](https://coda.io/developers/apis/v1#tag/Controls/operation/getControl)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
| `controlIdOrName` | path | `list` | yes |
