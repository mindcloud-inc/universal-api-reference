# Delete Page with Coda

Deletes a page from a Coda doc.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/:docId/pages/:pageIdOrName`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Delete Page](https://coda.io/developers/apis/v1#tag/Pages/operation/deletePage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
| `pageIdOrName` | path | `list` | yes |
