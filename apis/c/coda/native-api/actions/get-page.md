# Get Page with Coda

Retrieves page details from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/pages/:pageIdOrName`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Get Page](https://coda.io/developers/apis/v1#tag/Pages/operation/getPage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
| `pageIdOrName` | path | `list` | yes |
