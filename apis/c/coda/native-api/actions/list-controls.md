# List Controls with Coda

Retrieves controls from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/controls`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [List Controls](https://coda.io/developers/apis/v1#tag/Controls/operation/listControls)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
