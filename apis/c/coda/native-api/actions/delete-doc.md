# Delete Doc with Coda

Deletes a doc from a Coda workspace.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/docs/:docId`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Delete Doc](https://coda.io/developers/apis/v1#tag/Docs/operation/deleteDoc)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
