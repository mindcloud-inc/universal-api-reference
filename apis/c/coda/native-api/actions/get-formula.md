# Get Formula with Coda

Retrieves formula details from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/formulas/:formulaIdOrName`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [Get Formula](https://coda.io/developers/apis/v1#tag/Formulas/operation/getFormula)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
| `formulaIdOrName` | path | `list` | yes |
