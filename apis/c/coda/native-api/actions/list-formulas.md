# List Formulas with Coda

Retrieves formulas from a Coda doc.

## Endpoint

- **Method:** `GET`
- **Path:** `/docs/:docId/formulas`
- **Base URL:** `https://coda.io/apis/v1`
- **Official documentation:** [List Formulas](https://coda.io/developers/apis/v1#tag/Formulas/operation/listFormulas)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `docId` | path | `list` | yes |
