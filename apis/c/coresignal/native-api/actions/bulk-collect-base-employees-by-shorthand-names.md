# Bulk Collect Base Employees By Shorthand Names with Coresignal

Creates a bulk base employee shorthand-name request in Coresignal.

## Endpoint

- **Method:** `POST`
- **Path:** `/data_requests/employee_base/shorthand_names`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Bulk Collect Base Employees By Shorthand Names](https://docs.coresignal.com/employee-api/base-employee-api)
