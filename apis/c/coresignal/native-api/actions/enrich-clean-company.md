# Enrich Clean Company with Coresignal

Enriches a clean company in Coresignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/company_clean/enrich`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Enrich Clean Company](https://docs.coresignal.com/company-api/clean-company-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website` | query | `string` | yes | Company website URL to enrich. |
