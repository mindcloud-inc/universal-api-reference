# Collect Multi-source Employee By ID with Coresignal

Collects a multi-source employee from Coresignal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_multi_source/collect/:employeeId`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Multi-source Employee By ID](https://docs.coresignal.com/employee-api/multi-source-employee-api/endpoints/collect-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeId` | path | `number` | yes |
