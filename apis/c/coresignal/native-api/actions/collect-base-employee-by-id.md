# Collect Base Employee By ID with Coresignal

Collects a base employee from Coresignal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_base/collect/:employeeId`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Base Employee By ID](https://docs.coresignal.com/employee-api/base-employee-api/endpoints/collect-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeId` | path | `number` | yes |
