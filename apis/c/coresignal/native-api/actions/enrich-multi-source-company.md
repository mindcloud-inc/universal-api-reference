# Enrich Multi-source Company with Coresignal

Enriches a multi-source company in Coresignal.

## Endpoint

- **Method:** `GET`
- **Path:** `/company_multi_source/enrich`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Enrich Multi-source Company](https://docs.coresignal.com/company-api/multi-source-company-api/enrich)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website` | query | `string` | yes | Company website URL to enrich. |
