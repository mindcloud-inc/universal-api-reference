# Collect Clean Employee By Identifier with Coresignal

Collects a clean employee from Coresignal by identifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_clean/collect/:employeeIdentifier`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Clean Employee By Identifier](https://docs.coresignal.com/employee-api/clean-employee-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeIdentifier` | path | `string` | yes |
