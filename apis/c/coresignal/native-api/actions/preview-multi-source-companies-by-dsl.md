# Preview Multi-source Companies By DSL with Coresignal

Previews multi-source companies in Coresignal from an Elasticsearch DSL query.

## Endpoint

- **Method:** `POST`
- **Path:** `/company_multi_source/search/es_dsl/preview`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Preview Multi-source Companies By DSL](https://docs.coresignal.com/company-api/multi-source-company-api/endpoints/preview-companies)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `object` | yes |
