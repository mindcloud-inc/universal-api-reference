# Bulk Collect Base Jobs By Filters with Coresignal

Creates a bulk base job collection request in Coresignal.

## Endpoint

- **Method:** `POST`
- **Path:** `/data_requests/job_base/filter`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Bulk Collect Base Jobs By Filters](https://docs.coresignal.com/job-api/base-job-api/endpoints/bulk-collect-jobs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filters` | body | `object` | yes |
