# Preview Base Employees By DSL with Coresignal

Previews base employees in Coresignal from an Elasticsearch DSL query.

## Endpoint

- **Method:** `POST`
- **Path:** `/employee_base/search/es_dsl/preview`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Preview Base Employees By DSL](https://docs.coresignal.com/employee-api/base-employee-api/endpoints/preview-profiles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `object` | yes |
