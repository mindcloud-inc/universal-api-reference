# Preview Multi-source Employees By DSL with Coresignal

Previews multi-source employees in Coresignal from an Elasticsearch DSL query.

## Endpoint

- **Method:** `POST`
- **Path:** `/employee_multi_source/search/es_dsl/preview`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Preview Multi-source Employees By DSL](https://docs.coresignal.com/employee-api/multi-source-employee-api/endpoints/preview-profiles)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | body | `object` | yes |
