# Collect Base Job By ID with Coresignal

Collects a base job from Coresignal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/job_base/collect/:jobId`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Base Job By ID](https://docs.coresignal.com/job-api/base-job-api/endpoints/collect-job)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `jobId` | path | `number` | yes |
