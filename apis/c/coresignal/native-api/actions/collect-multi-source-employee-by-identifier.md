# Collect Multi-source Employee By Identifier with Coresignal

Collects a multi-source employee from Coresignal by identifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_multi_source/collect/:employeeIdentifier`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Multi-source Employee By Identifier](https://docs.coresignal.com/employee-api/multi-source-employee-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeIdentifier` | path | `string` | yes |
