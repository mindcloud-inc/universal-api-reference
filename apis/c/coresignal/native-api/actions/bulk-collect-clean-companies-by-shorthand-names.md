# Bulk Collect Clean Companies By Shorthand Names with Coresignal

Creates a bulk clean company shorthand-name request in Coresignal.

## Endpoint

- **Method:** `POST`
- **Path:** `/data_requests/company_clean/shorthand_names`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Bulk Collect Clean Companies By Shorthand Names](https://docs.coresignal.com/company-api/clean-company-api)
