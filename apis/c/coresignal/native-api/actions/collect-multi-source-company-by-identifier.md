# Collect Multi-source Company By Identifier with Coresignal

Collects a multi-source company from Coresignal by identifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/company_multi_source/collect/:companyIdentifier`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Multi-source Company By Identifier](https://docs.coresignal.com/company-api/multi-source-company-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyIdentifier` | path | `string` | yes |
