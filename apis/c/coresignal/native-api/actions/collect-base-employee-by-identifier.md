# Collect Base Employee By Identifier with Coresignal

Collects a base employee from Coresignal by identifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_base/collect/:employeeIdentifier`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Base Employee By Identifier](https://docs.coresignal.com/employee-api/base-employee-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeIdentifier` | path | `string` | yes |
