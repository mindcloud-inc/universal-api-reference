# Collect Multi-source Company By ID with Coresignal

Collects a multi-source company from Coresignal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/company_multi_source/collect/:companyId`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Multi-source Company By ID](https://docs.coresignal.com/company-api/multi-source-company-api/endpoints/collect-company)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `companyId` | path | `number` | yes |
