# Collect Clean Employee By ID with Coresignal

Collects a clean employee from Coresignal by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee_clean/collect/:employeeId`
- **Base URL:** `https://api.coresignal.com/cdapi/v2`
- **Official documentation:** [Collect Clean Employee By ID](https://docs.coresignal.com/employee-api/clean-employee-api/endpoints/collect-profile)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `employeeId` | path | `number` | yes |
