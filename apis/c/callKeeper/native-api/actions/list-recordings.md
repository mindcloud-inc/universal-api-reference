# List Recordings with CallKeeper

Retrieves recordings from the current CallKeeper account.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [List Recordings](https://api.callkeeper.ai/docs#/Recordings/list_recordings_recordings_get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
