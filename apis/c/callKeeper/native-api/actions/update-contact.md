# Update Contact with CallKeeper

Updates an existing contact in CallKeeper.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Update Contact](https://api.callkeeper.ai/docs#/Contacts/update_contact_contacts__contact_id__put)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact ID. |
