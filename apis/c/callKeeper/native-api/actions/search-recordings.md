# Search Recordings with CallKeeper

Finds recordings in CallKeeper by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/search`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Search Recordings](https://api.callkeeper.ai/docs#/Recordings/search_recordings_recordings_search_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query. |
