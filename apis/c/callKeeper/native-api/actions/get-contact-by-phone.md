# Get Contact By Phone with CallKeeper

Finds a contact in CallKeeper by phone number.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/by-phone/:phone`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Contact By Phone](https://api.callkeeper.ai/docs#/Contacts/get_contact_by_phone_contacts_by_phone__phone__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone` | path | `string` | yes | Phone number. |
