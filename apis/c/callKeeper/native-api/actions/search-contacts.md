# Search Contacts with CallKeeper

Finds contacts in CallKeeper by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/search`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Search Contacts](https://api.callkeeper.ai/docs#/Contacts/search_contacts_contacts_search_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query. |
