# Initiate Record Me Call with CallKeeper

Initiates a new record-me call in CallKeeper.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/record-me`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Initiate Record Me Call](https://api.callkeeper.ai/docs#/Calls/initiate_record_me_call_calls_record_me_post)
