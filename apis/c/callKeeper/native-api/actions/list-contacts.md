# List Contacts with CallKeeper

Retrieves contacts from the current CallKeeper account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [List Contacts](https://api.callkeeper.ai/docs#/Contacts/list_contacts_contacts_get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
