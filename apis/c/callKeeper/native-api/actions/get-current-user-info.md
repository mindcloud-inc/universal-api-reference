# Get Current User Info with CallKeeper

Retrieves current user information from CallKeeper.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/me`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Current User Info](https://api.callkeeper.ai/docs#/Authentication/get_current_user_info_auth_me_get)
