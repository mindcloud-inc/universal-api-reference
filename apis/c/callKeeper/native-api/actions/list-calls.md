# List Calls with CallKeeper

Retrieves calls from the current CallKeeper account.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [List Calls](https://api.callkeeper.ai/docs#/Calls/list_calls_calls_get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
