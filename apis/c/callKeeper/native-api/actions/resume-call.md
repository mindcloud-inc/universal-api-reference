# Resume Call with CallKeeper

Updates a call in CallKeeper by resuming it.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/:call_id/resume`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Resume Call](https://api.callkeeper.ai/docs#/Calls/resume_call_calls__call_id__resume_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | Call ID. |
