# Delete Contact Avatar with CallKeeper

Deletes a contact avatar from CallKeeper.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id/avatar`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Delete Contact Avatar](https://api.callkeeper.ai/docs#/Contacts/delete_contact_avatar_contacts__contact_id__avatar_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact ID. |
