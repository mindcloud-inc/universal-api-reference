# Add Party To Call with CallKeeper

Updates a call in CallKeeper by adding a party.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/:call_id/add-party`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Add Party To Call](https://api.callkeeper.ai/docs#/Calls/add_party_to_call_calls__call_id__add_party_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | Call ID. |
