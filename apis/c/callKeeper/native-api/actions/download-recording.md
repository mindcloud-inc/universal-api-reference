# Download Recording with CallKeeper

Retrieves downloadable recording content from CallKeeper.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recording_id/download`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Download Recording](https://api.callkeeper.ai/docs#/Recordings/download_recording_recordings__recording_id__download_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording_id` | path | `string` | yes | Recording identifier. |
