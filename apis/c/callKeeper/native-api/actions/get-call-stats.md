# Get Call Stats with CallKeeper

Retrieves call statistics from the current CallKeeper account.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/stats`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Call Stats](https://api.callkeeper.ai/docs#/Calls/get_call_stats_calls_stats_get)
