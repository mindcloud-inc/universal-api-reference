# List Favorite Contacts with CallKeeper

Retrieves favorite contacts from the current CallKeeper account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/favorites`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [List Favorite Contacts](https://api.callkeeper.ai/docs#/Contacts/list_favorite_contacts_contacts_favorites_get)
