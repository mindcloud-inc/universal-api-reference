# Delete Contact with CallKeeper

Deletes an existing contact from CallKeeper.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Delete Contact](https://api.callkeeper.ai/docs#/Contacts/delete_contact_contacts__contact_id__delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact ID. |
