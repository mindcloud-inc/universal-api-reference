# Sync Google Contacts with CallKeeper

Syncs Google contacts into the current CallKeeper account.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/sync/google`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Sync Google Contacts](https://api.callkeeper.ai/docs#/Contacts/sync_google_contacts_contacts_sync_google_post)
