# Get Contact with CallKeeper

Retrieves a specific contact from CallKeeper.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Contact](https://api.callkeeper.ai/docs#/Contacts/get_contact_contacts__contact_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Contact ID. |
