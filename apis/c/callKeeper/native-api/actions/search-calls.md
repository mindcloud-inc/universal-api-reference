# Search Calls with CallKeeper

Finds calls in CallKeeper by search query.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/search`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Search Calls](https://api.callkeeper.ai/docs#/Calls/search_calls_calls_search_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Search query. |
