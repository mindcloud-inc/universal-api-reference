# Transfer Call with CallKeeper

Updates a call in CallKeeper by transferring it.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/:call_id/transfer`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Transfer Call](https://api.callkeeper.ai/docs#/Calls/transfer_call_calls__call_id__transfer_post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | Call ID. |
