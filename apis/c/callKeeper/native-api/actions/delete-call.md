# Delete Call with CallKeeper

Deletes an existing call from CallKeeper.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calls/:call_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Delete Call](https://api.callkeeper.ai/docs#/Calls/delete_call_calls__call_id__delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | Call ID. |
