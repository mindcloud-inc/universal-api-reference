# Get Recording with CallKeeper

Retrieves a specific recording from CallKeeper.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recording_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Recording](https://api.callkeeper.ai/docs#/Recordings/get_recording_recordings__recording_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording_id` | path | `string` | yes | Recording identifier. |
