# Get Call with CallKeeper

Retrieves a specific call from CallKeeper.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls/:call_id`
- **Base URL:** `https://api.callkeeper.ai`
- **Official documentation:** [Get Call](https://api.callkeeper.ai/docs#/Calls/get_call_calls__call_id__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `call_id` | path | `string` | yes | Call ID. |
