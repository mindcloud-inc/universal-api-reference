# Get Conversation with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Get Conversation](https://developers.cliengo.com/reference/conversations-getbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Identifier of the Cliengo conversation. |
