# List Contact Notes with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/notes`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [List Contact Notes](https://developers.cliengo.com/reference/contactcontactidnotes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Identifier of the Cliengo contact. |
