# Get User with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Get User](https://developers.cliengo.com/reference/usersuserid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | Identifier of the Cliengo user. |
