# Count Site Conversations with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:websiteId/count`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Count Site Conversations](https://developers.cliengo.com/reference/conversations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `websiteId` | path | `string` | yes | Identifier of the Cliengo website. |
