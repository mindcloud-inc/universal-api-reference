# List Contact Messages with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/messages`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [List Contact Messages](https://developers.cliengo.com/reference/contactcontactidmessages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Identifier of the Cliengo contact. |
