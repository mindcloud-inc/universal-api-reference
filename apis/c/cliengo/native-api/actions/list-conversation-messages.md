# List Conversation Messages with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversationId/messages`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [List Conversation Messages](https://developers.cliengo.com/reference/conversations-id-messages-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | Identifier of the Cliengo conversation. |
