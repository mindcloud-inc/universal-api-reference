# Get Contact History with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/history`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Get Contact History](https://developers.cliengo.com/reference/contactscontactidhistory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Identifier of the Cliengo contact. |
