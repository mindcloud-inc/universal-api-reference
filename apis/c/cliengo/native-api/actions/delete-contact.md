# Delete Contact with Cliengo

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contactId`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Delete Contact](https://developers.cliengo.com/reference/contactscontactid-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Identifier of the Cliengo contact. |
