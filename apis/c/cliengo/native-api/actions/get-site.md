# Get Site with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:id`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Get Site](https://developers.cliengo.com/reference/websiteswebsiteid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier of the Cliengo site. |
