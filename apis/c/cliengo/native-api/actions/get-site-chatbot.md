# Get Site Chatbot with Cliengo

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:id/chatbot`
- **Base URL:** `https://api.cliengo.com/1.0`
- **Official documentation:** [Get Site Chatbot](https://developers.cliengo.com/reference/chatbots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Identifier of the Cliengo site. |
