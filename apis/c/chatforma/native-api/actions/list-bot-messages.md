# List Bot Messages with Chatforma

Retrieves bot message records from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/messages`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Bot Messages](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `number` | yes |
