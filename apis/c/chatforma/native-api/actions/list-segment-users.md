# List Segment Users with Chatforma

Retrieves users in a Chatforma segment.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/segments/:segmentId/users`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Segment Users](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `number` | yes |
| `segmentId` | path | `number` | yes |
