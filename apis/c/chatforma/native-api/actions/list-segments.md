# List Segments with Chatforma

Retrieves audience segment records from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/segments`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Segments](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `number` | yes |
