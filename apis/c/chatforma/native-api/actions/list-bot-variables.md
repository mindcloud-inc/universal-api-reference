# List Bot Variables with Chatforma

Retrieves bot variable records from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/variables`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Bot Variables](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | path | `number` | yes | Bot ID that owns the variables |
