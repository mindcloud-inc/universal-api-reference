# List Open Dialog Users with Chatforma

Retrieves users with open dialogs from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/bots/:botId/dialogs/users`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Open Dialog Users](https://docs.chatforma.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `botId` | path | `number` | yes |
