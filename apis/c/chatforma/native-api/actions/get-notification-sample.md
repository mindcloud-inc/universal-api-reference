# Get Notification Sample with Chatforma

Retrieves notification sample fields from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/notification-sample`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [Get Notification Sample](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | query | `number` | yes | Bot ID to get a notification sample for |
| `formId` | query | `string` | yes | Form ID to get a notification sample for |
