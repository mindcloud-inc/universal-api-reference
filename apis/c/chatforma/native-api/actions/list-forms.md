# List Forms with Chatforma

Retrieves submitted form records from Chatforma.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://api.pro.chatforma.com/public/v1`
- **Official documentation:** [List Forms](https://docs.chatforma.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | query | `number` | yes | Bot ID to list forms for |
