# Get Conversion Status with Convertio

Retrieves a conversion status from Convertio.

## Endpoint

- **Method:** `GET`
- **Path:** `/convert/:id/status`
- **Base URL:** `https://api.convertio.co`
- **Official documentation:** [Get Conversion Status](https://developers.convertio.co/api/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conversion ID returned by Start Conversion. |
