# Delete Conversion with Convertio

Deletes or cancels a conversion from Convertio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/convert/:id`
- **Base URL:** `https://api.convertio.co`
- **Official documentation:** [Delete Conversion](https://developers.convertio.co/api/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Conversion ID returned by Start Conversion. |
