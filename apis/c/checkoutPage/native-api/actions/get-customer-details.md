# Get Customer Details with Checkout Page

Retrieves customer details from Checkout Page.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customers/:customerId`
- **Base URL:** `https://api.checkoutpage.com`
- **Official documentation:** [Get Customer Details](https://checkoutpage.com/docs/api/v1/customers/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Get customer details |
