# Get Checkout Page with Checkout Page

Retrieves a checkout page from Checkout Page.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/checkout-pages/:pageId`
- **Base URL:** `https://api.checkoutpage.com`
- **Official documentation:** [Get Checkout Page](https://checkoutpage.com/docs/api/v1/checkout-pages/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | Unique identifier. Must be in BSON ObjectId format. |
