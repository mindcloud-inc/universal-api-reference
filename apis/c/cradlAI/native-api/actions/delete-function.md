# Delete Function with Cradl AI

Deletes an existing function from Cradl AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/functions/:functionId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Delete Function](https://docs.cradl.ai/api-reference/delete-functions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Identifier of the function to delete. |
