# Get Document with Cradl AI

Retrieves a document from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Get Document](https://docs.cradl.ai/api-reference/get-documents-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Identifier of the document. |
