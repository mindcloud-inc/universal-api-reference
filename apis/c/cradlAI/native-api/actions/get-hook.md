# Get Hook with Cradl AI

Retrieves a hook from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/hooks/:hookId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Get Hook](https://docs.cradl.ai/api-reference/get-hooks-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hookId` | path | `string` | yes | Identifier of the hook. |
