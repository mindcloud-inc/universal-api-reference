# Delete Document with Cradl AI

Deletes an existing document from Cradl AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Delete Document](https://docs.cradl.ai/api-reference/delete-documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | Identifier of the document to delete. |
