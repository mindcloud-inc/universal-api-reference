# Get Function with Cradl AI

Retrieves a function from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/:functionId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Get Function](https://docs.cradl.ai/api-reference/get-functions-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | Identifier of the function. |
