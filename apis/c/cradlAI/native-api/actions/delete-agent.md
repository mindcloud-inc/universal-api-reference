# Delete Agent with Cradl AI

Deletes an existing agent from Cradl AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agents/:agentId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Delete Agent](https://docs.cradl.ai/api-reference/delete-agents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | Identifier of the agent to delete. |
