# List Agents with Cradl AI

Retrieves all agents from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [List Agents](https://docs.cradl.ai/api-reference/get-agents)

## Capabilities

This operation supports [pagination](../README.md#pagination).
