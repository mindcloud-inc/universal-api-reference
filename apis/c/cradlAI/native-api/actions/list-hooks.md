# List Hooks with Cradl AI

Retrieves all hooks from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/hooks`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [List Hooks](https://docs.cradl.ai/api-reference/get-hooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
