# Delete Hook with Cradl AI

Deletes an existing hook from Cradl AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/hooks/:hookId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Delete Hook](https://docs.cradl.ai/api-reference/delete-hooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `hookId` | path | `string` | yes | Identifier of the hook to delete. |
