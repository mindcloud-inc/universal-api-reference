# Get Agent with Cradl AI

Retrieves an agent from Cradl AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId`
- **Base URL:** `https://api.cradl.ai/v1`
- **Official documentation:** [Get Agent](https://docs.cradl.ai/api-reference/get-agents-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | Identifier of the agent to fetch. |
