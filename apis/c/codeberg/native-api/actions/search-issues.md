# Search Issues with Codeberg

## Endpoint

- **Method:** `GET`
- **Path:** `/repos/issues/search`
- **Base URL:** `https://codeberg.org/api/v1`
- **Official documentation:** [Search Issues](https://codeberg.org/api/swagger#/issue/issueSearchIssues)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
