# Search Repositories with Codeberg

## Endpoint

- **Method:** `GET`
- **Path:** `/repos/search`
- **Base URL:** `https://codeberg.org/api/v1`
- **Official documentation:** [Search Repositories](https://codeberg.org/api/swagger#/repository/repoSearch)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
