# List Carriers with Cin7 Core

## Endpoint

- **Method:** `GET`
- **Path:** `ref/carrier`
- **Base URL:** `https://inventory.dearsystems.com/externalapi/v2/`
- **Official documentation:** [List Carriers](https://dearinventory.docs.apiary.io/#reference/sale/sale-fulfilment/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `CarrierID` | query | `string` | no |
| `Description` | query | `string` | no |
