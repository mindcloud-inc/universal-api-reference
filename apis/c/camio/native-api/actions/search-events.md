# Search Events with Camio

Finds video events in Camio by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://camio.com/api`
- **Official documentation:** [Search Events](https://api.camio.com/#search-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | The Camio search text to run. |
