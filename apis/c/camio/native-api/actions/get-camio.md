# Get Camio with Camio

Retrieves a Camio from Camio.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/camios`
- **Base URL:** `https://camio.com/api`
- **Official documentation:** [Get Camio](https://api.camio.com/#get-a-camio)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The Camio id to fetch. |
