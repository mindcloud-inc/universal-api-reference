# Search Cameras with Camio

Finds cameras in Camio by search text.

## Endpoint

- **Method:** `GET`
- **Path:** `/search/cameras`
- **Base URL:** `https://camio.com/api`
- **Official documentation:** [Search Cameras](https://api.camio.com/#search-cameras)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | no | Optional text that narrows camera search results. |
