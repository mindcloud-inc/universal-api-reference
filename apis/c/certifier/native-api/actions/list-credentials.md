# List Credentials with Certifier

Retrieves all available credentials from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [List Credentials](https://developers.certifier.io/docs/api-reference/credentials/list-credentials)

## Capabilities

This operation supports [pagination](../README.md#pagination).
