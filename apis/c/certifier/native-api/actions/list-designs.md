# List Designs with Certifier

Retrieves all available designs from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/designs`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [List Designs](https://developers.certifier.io/docs/api-reference/designs/list-designs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
