# Delete Credential with Certifier

Deletes an existing credential from Certifier.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/credentials/:id`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Delete Credential](https://developers.certifier.io/docs/api-reference/credentials/list-credentials)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
