# List Groups with Certifier

Retrieves all available groups from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [List Groups](https://developers.certifier.io/docs/api-reference/groups/list-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
