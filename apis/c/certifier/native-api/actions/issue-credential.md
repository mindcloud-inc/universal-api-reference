# Issue Credential with Certifier

Issues an existing credential in Certifier.

## Endpoint

- **Method:** `POST`
- **Path:** `/credentials/:id/issue`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Issue Credential](https://developers.certifier.io/docs/api-reference/credentials/issue-a-credential)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
