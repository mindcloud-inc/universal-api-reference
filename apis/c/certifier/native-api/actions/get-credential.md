# Get Credential with Certifier

Retrieves detailed credential information from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials/:id`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Get Credential](https://developers.certifier.io/docs/api-reference/credentials/get-a-credential)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
