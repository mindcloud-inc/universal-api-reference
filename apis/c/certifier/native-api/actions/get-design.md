# Get Design with Certifier

Retrieves detailed design information from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/designs/:id`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Get Design](https://developers.certifier.io/docs/api-reference/designs/get-a-design)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
