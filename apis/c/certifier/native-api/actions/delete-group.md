# Delete Group with Certifier

Deletes an existing group from Certifier.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:id`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Delete Group](https://developers.certifier.io/docs/api-reference/groups/delete-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required path ID inferred from the documented /groups/{id} endpoint. |
