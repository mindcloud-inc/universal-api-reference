# List Credential Interactions with Certifier

Retrieves all credential interactions from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/credential-interactions`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [List Credential Interactions](https://developers.certifier.io/docs/api-reference/credential-interactions/list-credential-interactions)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `credentialId` | query | `string` | no |
