# List Credential Designs with Certifier

Retrieves all credential-specific designs from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/credentials/:id/designs`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [List Credential Designs](https://developers.certifier.io/docs/api-reference/credentials/get-credential-designs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
