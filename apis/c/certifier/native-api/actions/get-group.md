# Get Group with Certifier

Retrieves detailed group information from Certifier.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `https://api.certifier.io/v1`
- **Official documentation:** [Get Group](https://developers.certifier.io/docs/api-reference/groups/get-a-group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
