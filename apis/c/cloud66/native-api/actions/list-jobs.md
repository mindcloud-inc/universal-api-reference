# List Jobs with Cloud 66

Retrieves jobs from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/jobs`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List Jobs](https://developers.cloud66.com/v3/endpoints/jobs/#list-jobs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | The stack UID |
