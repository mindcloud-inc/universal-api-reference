# List Stack Settings with Cloud 66

Retrieves stack settings from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/settings`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List Stack Settings](https://developers.cloud66.com/v3/endpoints/stack-settings/#list-stack-settings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | The stack UID |
