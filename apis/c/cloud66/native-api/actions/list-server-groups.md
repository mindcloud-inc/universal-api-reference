# List Server Groups with Cloud 66

Retrieves server groups from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/server_groups`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List Server Groups](https://developers.cloud66.com/v3/endpoints/server-groups/#list-server-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | The stack UID |
