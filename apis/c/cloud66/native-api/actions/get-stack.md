# Get Stack with Cloud 66

Retrieves a stack from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:id`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [Get Stack](https://developers.cloud66.com/v3/endpoints/stacks/#get-stack)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the stack. |
