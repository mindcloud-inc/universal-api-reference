# List Servers with Cloud 66

Retrieves servers from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/servers`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List Servers](https://developers.cloud66.com/v3/endpoints/servers/#list-servers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | The stack UID |
