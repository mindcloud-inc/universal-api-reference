# List Services with Cloud 66

Retrieves services from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/services`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List Services](https://developers.cloud66.com/v3/endpoints/services/#list-services)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | The stack UID |
