# List SSL Certificates with Cloud 66

Retrieves SSL certificates from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/stacks/:stack_id/ssl_certificates`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [List SSL Certificates](https://developers.cloud66.com/v3/endpoints/stacks/#ssl-certificates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stack_id` | path | `string` | yes | Unique identifier of the stack |
