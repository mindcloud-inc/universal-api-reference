# Get Authenticated User with Cloud 66

Retrieves the authenticated user from your Cloud 66 account.

## Endpoint

- **Method:** `GET`
- **Path:** `/ping/auth`
- **Base URL:** `https://app.cloud66.com/api/3`
- **Official documentation:** [Get Authenticated User](https://developers.cloud66.com/v3/endpoints/ping/#authenticated-ping)
