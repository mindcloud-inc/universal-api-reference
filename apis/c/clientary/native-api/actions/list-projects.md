# List Projects with Clientary

Retrieves projects from your Clientary account.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [List Projects](https://www.clientary.com/api/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | no | Set to all to include completed projects. |
