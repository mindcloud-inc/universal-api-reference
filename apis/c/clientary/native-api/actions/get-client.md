# Get Client with Clientary

Retrieves a client from Clientary by client ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [Get Client](https://www.clientary.com/api/clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Clientary client ID. |
