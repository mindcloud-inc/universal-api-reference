# Get Project with Clientary

Retrieves a project from Clientary by project ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [Get Project](https://www.clientary.com/api/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Clientary project ID. |
