# Get Estimate with Clientary

Retrieves an estimate from Clientary by estimate ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates/:id`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [Get Estimate](https://www.clientary.com/api/estimates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Clientary estimate ID. |
