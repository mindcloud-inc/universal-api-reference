# Get Task with Clientary

Retrieves a task from Clientary by task ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [Get Task](https://www.clientary.com/api/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Clientary task ID. |
