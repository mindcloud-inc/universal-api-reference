# List Contacts with Clientary

Retrieves contacts from your Clientary account.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://{subdomain}.clientary.com/api/v2`
- **Official documentation:** [List Contacts](https://www.clientary.com/api/contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
