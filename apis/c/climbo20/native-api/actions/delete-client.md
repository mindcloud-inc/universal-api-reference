# Delete Client with Climbo 2.0

Deletes a client from Climbo 2.0.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/client/{client_id}`
- **Base URL:** `https://api.climbo.com`
- **Official documentation:** [Delete Client](https://climbo.readme.io/reference/delete-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | yes | ID of your customer. |
