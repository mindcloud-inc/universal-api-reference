# Get Plan with Climbo 2.0

Retrieves a subscription plan from Climbo 2.0.

## Endpoint

- **Method:** `GET`
- **Path:** `/plan/{plan_id}`
- **Base URL:** `https://api.climbo.com`
- **Official documentation:** [Get Plan](https://climbo.readme.io/reference/get-plan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `plan_id` | path | `string` | yes | Plan ID. |
