# List Plans with Climbo 2.0

Retrieves subscription plans from Climbo 2.0.

## Endpoint

- **Method:** `GET`
- **Path:** `/plans`
- **Base URL:** `https://api.climbo.com`
- **Official documentation:** [List Plans](https://climbo.readme.io/reference/list-plans)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `string` | no | If not set returns the first page. |
