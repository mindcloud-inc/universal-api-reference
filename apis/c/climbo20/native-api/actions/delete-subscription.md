# Delete Subscription with Climbo 2.0

Deletes a webhook subscription from Climbo 2.0.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhook/unsubscribe/{webhook_id}`
- **Base URL:** `https://api.climbo.com`
- **Official documentation:** [Delete Subscription](https://climbo.readme.io/reference/delete-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_id` | path | `string` | yes | Webhook subscription ID. |
