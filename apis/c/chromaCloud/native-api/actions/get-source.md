# Get source with Chroma Cloud

Retrieves a source from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `https://sync.trychroma.com/api/v1/sources/:source_id`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Get source](https://docs.trychroma.com/reference/sync-api/source/get-source)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `source_id` | path | `string` | yes |
