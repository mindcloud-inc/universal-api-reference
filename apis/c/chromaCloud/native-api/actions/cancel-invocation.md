# Cancel invocation with Chroma Cloud

Cancels an invocation in Chroma Cloud.

## Endpoint

- **Method:** `PUT`
- **Path:** `https://sync.trychroma.com/api/v1/invocations/:invocation_id`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Cancel invocation](https://docs.trychroma.com/reference/sync-api/invocation/cancel-invocation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invocation_id` | path | `string` | yes |
