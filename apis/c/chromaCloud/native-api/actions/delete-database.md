# Delete database with Chroma Cloud

Deletes a database from Chroma Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/tenants/:tenant/databases/:database`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Delete database](https://docs.trychroma.com/reference/chroma-api/database/delete-database)
