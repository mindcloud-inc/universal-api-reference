# Update tenant with Chroma Cloud

Updates a tenant in Chroma Cloud.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/tenants/:tenant`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Update tenant](https://docs.trychroma.com/reference/chroma-api/tenant/update-tenant)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `resource_name` | body | `string` | yes |
