# List collections with Chroma Cloud

Retrieves collections from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tenants/:tenant/databases/:database/collections`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [List collections](https://docs.trychroma.com/reference/chroma-api/collection/list-collections)

## Capabilities

This operation supports [pagination](../README.md#pagination).
