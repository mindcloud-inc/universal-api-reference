# Get invocation with Chroma Cloud

Retrieves an invocation from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `https://sync.trychroma.com/api/v1/invocations/:invocation_id`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Get invocation](https://docs.trychroma.com/reference/sync-api/invocation/get-invocation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invocation_id` | path | `string` | yes |
