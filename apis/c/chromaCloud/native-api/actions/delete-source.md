# Delete source with Chroma Cloud

Deletes a source from Chroma Cloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://sync.trychroma.com/api/v1/sources/:source_id`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Delete source](https://docs.trychroma.com/reference/sync-api/source/delete-source)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `source_id` | path | `string` | yes |
