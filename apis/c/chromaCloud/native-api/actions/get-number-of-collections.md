# Get number of collections with Chroma Cloud

Retrieves a collection count from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tenants/:tenant/databases/:database/collections_count`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Get number of collections](https://docs.trychroma.com/reference/chroma-api/collection/get-number-of-collections)
