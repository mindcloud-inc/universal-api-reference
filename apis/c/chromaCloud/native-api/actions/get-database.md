# Get database with Chroma Cloud

Retrieves a database from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/tenants/:tenant/databases/:database`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Get database](https://docs.trychroma.com/reference/chroma-api/database/get-database)
