# Create tenant with Chroma Cloud

Creates a tenant in Chroma Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/tenants`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Create tenant](https://docs.trychroma.com/reference/chroma-api/tenant/create-tenant)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
