# Pre-flight checks with Chroma Cloud

Retrieves pre-flight checks from Chroma Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/pre-flight-checks`
- **Base URL:** `https://api.trychroma.com`
- **Official documentation:** [Pre-flight checks](https://docs.trychroma.com/reference/chroma-api/system/pre-flight-checks)
