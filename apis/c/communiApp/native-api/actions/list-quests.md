# List Quests with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/quest`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Quests](https://api.communiapp.de/docs#/Quest/get_rest_quest)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `number` | yes |
| `search` | query | `string` | no |
