# List Groups with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/group`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Groups](https://api.communiapp.de/docs#/Group/get_rest_group)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `communiApp` | query | `number` | yes |
| `search` | query | `string` | no |
