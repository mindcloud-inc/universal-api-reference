# Get Conversation with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/conversation/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Conversation](https://api.communiapp.de/docs#/Conversation/get_rest_conversation__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
