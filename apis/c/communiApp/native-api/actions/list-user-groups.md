# List User Groups with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/userGroup`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List User Groups](https://api.communiapp.de/docs#/UserGroup/get_rest_userGroup)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user` | query | `number` | no |
| `group` | query | `number` | no |
| `communiApp` | query | `number` | no |
