# List Custom Pages with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/customPage`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Custom Pages](https://api.communiapp.de/docs#/CustomPage/get_rest_customPage)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `communiApp` | query | `number` | no |
| `category` | query | `number` | no |
