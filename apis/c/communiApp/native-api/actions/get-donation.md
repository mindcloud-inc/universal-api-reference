# Get Donation with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/donation/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Donation](https://api.communiapp.de/docs#/Donation/get_rest_donation__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
