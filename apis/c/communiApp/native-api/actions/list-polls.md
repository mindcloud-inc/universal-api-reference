# List Polls with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/poll`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Polls](https://api.communiapp.de/docs#/Poll/get_rest_poll)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `number` | yes |
| `search` | query | `string` | no |
| `communiApp` | query | `number` | no |
