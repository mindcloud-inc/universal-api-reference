- **Method:** `GET`
- **Path:** `/rest/user/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get User](https://api.communiapp.de/docs#/User/get_rest_user__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
