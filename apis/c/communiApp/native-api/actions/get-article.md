# Get Article with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/article/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Article](https://api.communiapp.de/docs#/Article/get_rest_article__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
