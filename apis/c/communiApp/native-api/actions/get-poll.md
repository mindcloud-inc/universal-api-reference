# Get Poll with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/poll/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Poll](https://api.communiapp.de/docs#/Poll/get_rest_poll__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
