# Get Recommendation with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/recommendation/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Recommendation](https://api.communiapp.de/docs#/Recommendation/get_rest_recommendation__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
