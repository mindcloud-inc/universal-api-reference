# List Recommendations with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/recommendation`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Recommendations](https://api.communiapp.de/docs#/Recommendation/get_rest_recommendation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `number` | yes |
| `search` | query | `string` | no |
