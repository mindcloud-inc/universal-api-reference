# List Messages with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/message`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Messages](https://api.communiapp.de/docs#/Message/get_rest_message)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversation` | query | `number` | yes |
