# List User Poll Answers with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/userPollAnswer`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List User Poll Answers](https://api.communiapp.de/docs#/UserPollAnswer/get_rest_userPollAnswer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `poll` | query | `number` | no |
| `user` | query | `number` | no |
| `answerId` | query | `number` | no |
| `isSelected` | query | `number` | no |
