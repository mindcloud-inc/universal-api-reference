# List Offers with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/offer`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Offers](https://api.communiapp.de/docs#/Offer/get_rest_offer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `number` | yes |
| `search` | query | `string` | no |
