# List Articles with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/article`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [List Articles](https://api.communiapp.de/docs#/Article/get_rest_article)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group` | query | `number` | yes |
| `search` | query | `string` | no |
