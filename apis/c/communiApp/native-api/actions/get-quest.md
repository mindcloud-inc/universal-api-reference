# Get Quest with Communi App

- **Method:** `GET`
- **Path:** `/rest/quest/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Quest](https://api.communiapp.de/docs#/Quest/get_rest_quest__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
