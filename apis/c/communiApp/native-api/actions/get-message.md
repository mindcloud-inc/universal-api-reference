- **Method:** `GET`

- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Message](https://api.communiapp.de/docs#/Message/get_rest_message__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
