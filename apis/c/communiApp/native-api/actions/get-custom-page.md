# Get Custom Page with Communi App

## Endpoint

- **Method:** `GET`
- **Path:** `/rest/customPage/:id`
- **Base URL:** `https://api.communiapp.de`
- **Official documentation:** [Get Custom Page](https://api.communiapp.de/docs#/CustomPage/get_rest_customPage__id_)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
