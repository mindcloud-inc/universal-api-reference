# Get Connect Endpoints with Crisp

Retrieves connect endpoints from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/connect/endpoints`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Get Connect Endpoints](https://docs.crisp.chat/references/rest-api/v1/#get-connect-endpoints)
