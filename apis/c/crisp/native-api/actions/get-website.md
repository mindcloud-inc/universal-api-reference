# Get Website with Crisp

Retrieves a website from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Get Website](https://docs.crisp.chat/references/rest-api/v1/#get-a-website)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier. |
