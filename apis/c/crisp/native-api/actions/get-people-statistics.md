# Get People Statistics with Crisp

Retrieves people statistics from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id/people/stats`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Get People Statistics](https://docs.crisp.chat/references/rest-api/v1/#get-people-statistics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier. |
