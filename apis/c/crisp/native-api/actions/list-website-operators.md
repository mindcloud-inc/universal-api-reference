# List Website Operators with Crisp

Retrieves website operators from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id/operators/list`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [List Website Operators](https://docs.crisp.chat/references/rest-api/v1/#list-website-operators)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier |
