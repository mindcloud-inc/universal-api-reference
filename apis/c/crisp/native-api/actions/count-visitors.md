# Count Visitors with Crisp

Retrieves a visitor count from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id/visitors/count`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Count Visitors](https://docs.crisp.chat/references/rest-api/v1/#count-visitors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier. |
