# Get Plugin Account with Crisp

Retrieves your plugin account from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/plugin/connect/account`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Get Plugin Account](https://docs.crisp.chat/references/rest-api/v1/#get-connect-account)
