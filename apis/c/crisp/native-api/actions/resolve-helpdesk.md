# Resolve Helpdesk with Crisp

Retrieves helpdesk information for a website in Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id/helpdesk`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Resolve Helpdesk](https://docs.crisp.chat/references/rest-api/v1/#resolve-helpdesk)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier. |
