# Create New Conversation with Crisp

Creates a new conversation in Crisp.

## Endpoint

- **Method:** `POST`
- **Path:** `/website/:website_id/conversation`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Create New Conversation](https://docs.crisp.chat/references/rest-api/v1/#create-a-new-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier |
