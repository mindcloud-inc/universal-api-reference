# Get Website Availability Status with Crisp

Retrieves website availability status from Crisp.

## Endpoint

- **Method:** `GET`
- **Path:** `/website/:website_id/availability/status`
- **Base URL:** `https://api.crisp.chat/v1`
- **Official documentation:** [Get Website Availability Status](https://docs.crisp.chat/references/rest-api/v1/#get-website-availability-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_id` | path | `string` | yes | The website identifier. |
