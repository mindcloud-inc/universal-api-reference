# Get Random Fact with Cat Facts

## Endpoint

- **Method:** `GET`
- **Path:** `/fact`
- **Base URL:** `https://catfact.ninja`
- **Official documentation:** [Get Random Fact](https://catfact.ninja/docs?api-docs.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max_length` | query | `number` | no | Maximum length of the returned fact. |
