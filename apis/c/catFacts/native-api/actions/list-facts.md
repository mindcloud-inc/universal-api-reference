# List Facts with Cat Facts

## Endpoint

- **Method:** `GET`
- **Path:** `/facts`
- **Base URL:** `https://catfact.ninja`
- **Official documentation:** [List Facts](https://catfact.ninja/docs?api-docs.json)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `max_length` | query | `number` | no | Maximum length of each returned fact. |
