# List Spaces with Circle

Retrieves space records from your Circle community.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/spaces`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Spaces](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
