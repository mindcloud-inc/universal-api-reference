# Create Access Group with Circle

Creates a new access group in Circle.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/v2/access_groups`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Create Access Group](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `access_group` | body | `object` | yes | Access group payload object |
