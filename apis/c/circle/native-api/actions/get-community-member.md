# Get Community Member with Circle

Retrieves community member details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/community_members/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Community Member](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Community member ID |
