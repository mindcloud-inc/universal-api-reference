# Get Basic Post with Circle

Retrieves basic post details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/posts/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Basic Post](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Post ID |
