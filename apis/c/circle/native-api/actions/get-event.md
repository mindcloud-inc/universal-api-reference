# Get Event with Circle

Retrieves event details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/events/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Event](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Event ID |
