# List Events with Circle

Retrieves event records from your Circle community.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/events`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Events](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
