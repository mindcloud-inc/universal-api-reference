# List Community Members with Circle

Retrieves community member records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/community_members`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Community Members](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
