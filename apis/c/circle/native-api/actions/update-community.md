# Update Community with Circle

Updates current community details in Circle.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/admin/v2/community`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Update Community](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `community` | body | `object` | yes | Community update payload |
