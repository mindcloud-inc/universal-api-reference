# List Community Segments with Circle

Retrieves community segment records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/community_segments`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Community Segments](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
