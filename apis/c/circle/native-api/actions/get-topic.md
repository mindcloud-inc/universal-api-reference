# Get Topic with Circle

Retrieves topic details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/topics/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Topic](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Topic ID |
