# List Profile Fields with Circle

Retrieves profile field records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/profile_fields`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Profile Fields](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
