# List Comments with Circle

Retrieves comment records from your Circle community.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/comments`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Comments](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
