# List Community Member Spaces with Circle

Retrieves community member space memberships from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/community_member_spaces`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Community Member Spaces](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
