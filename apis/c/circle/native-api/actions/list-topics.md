# List Topics with Circle

Retrieves topic records from your Circle community.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/topics`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Topics](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
