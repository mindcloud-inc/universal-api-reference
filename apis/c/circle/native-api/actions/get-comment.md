# Get Comment with Circle

Retrieves comment details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/comments/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Comment](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Comment ID |
