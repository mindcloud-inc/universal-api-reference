# Get Member Tag with Circle

Retrieves member tag details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/member_tags/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Member Tag](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Member tag ID |
