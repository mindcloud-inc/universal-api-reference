# List Access Groups with Circle

Retrieves access group records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/access_groups`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Access Groups](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination).
