# List Basic Posts with Circle

Retrieves basic post records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/posts`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Basic Posts](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
