# Create Topic with Circle

Creates a new topic in Circle.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/admin/v2/topics`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Create Topic](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Topic name |
