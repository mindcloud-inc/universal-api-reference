# Get Space with Circle

Retrieves space details from Circle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/spaces/[:id]`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [Get Space](https://api.circle.so/apis/admin-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Space ID |
