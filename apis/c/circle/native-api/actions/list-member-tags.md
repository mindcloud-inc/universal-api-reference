# List Member Tags with Circle

Retrieves member tag records from Circle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/admin/v2/member_tags`
- **Base URL:** `https://{subdomain}.circle.so`
- **Official documentation:** [List Member Tags](https://api.circle.so/apis/admin-api)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
