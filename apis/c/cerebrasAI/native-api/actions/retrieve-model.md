# Retrieve Model with Cerebras AI

Retrieves a model from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/models/:modelId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve Model](https://inference-docs.cerebras.ai/api-reference/models/retrieve-model)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `modelId` | path | `string` | yes |
