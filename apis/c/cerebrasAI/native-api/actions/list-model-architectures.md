# List Model Architectures with Cerebras AI

Retrieves model architectures from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/v1/orgs/:orgName/models`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [List Model Architectures](https://inference-docs.cerebras.ai/api-reference/customer_management_api/list-model-architectures)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orgName` | path | `string` | yes |
