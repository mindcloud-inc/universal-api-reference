# Delete File with Cerebras AI

Deletes a file from Cerebras AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/files/:fileId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Delete File](https://inference-docs.cerebras.ai/api-reference/file/delete-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
