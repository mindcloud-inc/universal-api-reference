# Retrieve Endpoint Status with Cerebras AI

Retrieves endpoint status from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/v1/endpoints/:endpointId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve Endpoint Status](https://inference-docs.cerebras.ai/api-reference/customer_management_api/retrieve-endpoint-status)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `endpointId` | path | `string` | yes |
