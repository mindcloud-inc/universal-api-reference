# List Endpoints with Cerebras AI

Retrieves endpoints from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/v1/orgs/:orgName/endpoints`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [List Endpoints](https://inference-docs.cerebras.ai/api-reference/customer_management_api/list-endpoints)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orgName` | path | `string` | yes |
