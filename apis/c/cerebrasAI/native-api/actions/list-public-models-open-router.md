# List Public Models (OpenRouter) with Cerebras AI

Retrieves OpenRouter-formatted public models from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/models`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [List Public Models (OpenRouter)](https://inference-docs.cerebras.ai/api-reference/models/public-models)
