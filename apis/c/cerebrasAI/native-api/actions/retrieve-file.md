# Retrieve File with Cerebras AI

Retrieves a file from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:fileId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve File](https://inference-docs.cerebras.ai/api-reference/file/retrieve-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
