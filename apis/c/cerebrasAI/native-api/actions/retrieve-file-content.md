# Retrieve File Content with Cerebras AI

Retrieves file content from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:fileId/content`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve File Content](https://inference-docs.cerebras.ai/api-reference/file/retrieve-file-content)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
