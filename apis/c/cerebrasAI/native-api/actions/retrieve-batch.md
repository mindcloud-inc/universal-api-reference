# Retrieve Batch with Cerebras AI

Retrieves a batch from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches/:batchId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve Batch](https://inference-docs.cerebras.ai/api-reference/batch/retrieve-batch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `batchId` | path | `string` | yes |
