# Cancel Batch with Cerebras AI

Deletes a batch in Cerebras AI by cancelling it.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/batches/:batchId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Cancel Batch](https://inference-docs.cerebras.ai/api-reference/batch/cancel-batch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `batchId` | path | `string` | yes |
