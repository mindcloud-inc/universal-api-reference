# Retrieve Batch Results with Cerebras AI

Retrieves batch results from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/batches/:batchId/results`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve Batch Results](https://inference-docs.cerebras.ai/api-reference/batch/retrieve-batch-results)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `batchId` | path | `string` | yes |
