# List Public Models (HuggingFace) with Cerebras AI

Retrieves HuggingFace-formatted public models from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/models`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [List Public Models (HuggingFace)](https://inference-docs.cerebras.ai/api-reference/models/public-models)
