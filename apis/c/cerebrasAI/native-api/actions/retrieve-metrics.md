# Retrieve Metrics with Cerebras AI

Retrieves metrics from Cerebras AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud.cerebras.ai/api/v1/metrics/organizations/:organizationId`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [Retrieve Metrics](https://inference-docs.cerebras.ai/api-reference/metrics/retrieve-metrics)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `organizationId` | path | `string` | yes |
