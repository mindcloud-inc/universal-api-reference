# List Public Models (Generic Format) with Cerebras AI

Retrieves public models from Cerebras AI by format.

## Endpoint

- **Method:** `GET`
- **Path:** `/public/v1/models`
- **Base URL:** `https://api.cerebras.ai`
- **Official documentation:** [List Public Models (Generic Format)](https://inference-docs.cerebras.ai/api-reference/models/public-models)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `format` | query | `string` | no |
