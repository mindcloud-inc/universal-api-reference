# Create Tag with ChatDaddy

Creates a new tag in ChatDaddy.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Create Tag](https://chatdaddy.stoplight.io/docs/openapi/5ccbb3b027800-create-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of the tag to create. |
