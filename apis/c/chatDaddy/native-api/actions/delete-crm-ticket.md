# Delete CRM Ticket with ChatDaddy

Deletes an existing CRM ticket from ChatDaddy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crm/tickets/{id}`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Delete CRM Ticket](https://chatdaddy.stoplight.io/docs/openapi/26376a43d5d42-delete-a-crm-ticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | CRM ticket identifier to delete. |
