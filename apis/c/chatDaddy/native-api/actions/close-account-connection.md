# Close Account Connection with ChatDaddy

Closes a connection to a ChatDaddy account.

## Endpoint

- **Method:** `POST`
- **Path:** `/accounts/{accountId}/close`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Close Account Connection](https://chatdaddy.stoplight.io/docs/openapi/2d9772dc79135-close-connection-to-the-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Account identifier to close. |
