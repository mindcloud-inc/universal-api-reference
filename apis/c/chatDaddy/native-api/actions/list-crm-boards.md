# List CRM Boards with ChatDaddy

Retrieves CRM board records from ChatDaddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/boards`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [List CRM Boards](https://chatdaddy.stoplight.io/docs/openapi/349d52b45fce4-get-all-crm-boards-for-the-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `string` | no | Number of CRM boards to return when supported. |
