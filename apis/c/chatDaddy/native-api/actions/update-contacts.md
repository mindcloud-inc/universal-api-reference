# Update Contacts with ChatDaddy

Updates one or more existing contacts in ChatDaddy.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/contacts`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Update Contacts](https://chatdaddy.stoplight.io/docs/openapi/e5072e0b9e942-update-contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `patch` | body | `object` | yes | Patch instructions for updating contacts. |
