# Update Tag with ChatDaddy

Updates an existing tag in ChatDaddy.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/tags`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Update Tag](https://chatdaddy.stoplight.io/docs/openapi/26bd392155c0c-modify-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of the tag to modify. |
