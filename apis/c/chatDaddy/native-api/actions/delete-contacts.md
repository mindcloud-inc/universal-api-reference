# Delete Contacts with ChatDaddy

Deletes one or more existing contacts from ChatDaddy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Delete Contacts](https://chatdaddy.stoplight.io/docs/openapi/2470d0f1cdf51-delete-contacts)
