# List Accounts with ChatDaddy

Retrieves connected account records from ChatDaddy.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [List Accounts](https://chatdaddy.stoplight.io/docs/openapi/9b7cad02ca629-get-the-list-of-all-accounts)
