# Delete Tag with ChatDaddy

Deletes an existing tag from ChatDaddy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Delete Tag](https://chatdaddy.stoplight.io/docs/openapi/9d77df923356c-delete-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Name of the tag to delete. |
