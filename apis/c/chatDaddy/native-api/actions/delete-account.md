# Delete Account with ChatDaddy

Enqueues deletion of an account in ChatDaddy.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounts/{accountId}`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Delete Account](https://chatdaddy.stoplight.io/docs/openapi/c23e7da63b08f-enqueues-a-task-to-delete-the-account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `accountId` | path | `string` | yes | Account identifier to delete. |
