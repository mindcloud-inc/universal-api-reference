# Search Messages with ChatDaddy

Finds message records in your ChatDaddy account.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/search`
- **Base URL:** `https://api.chatdaddy.tech/im`
- **Official documentation:** [Search Messages](https://chatdaddy.stoplight.io/docs/openapi/c393f706dbd77-search-messages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search messages by text. |
