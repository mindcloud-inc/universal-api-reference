# Download File with ClickMeeting

Downloads a file from ClickMeeting by file ID.

## Endpoint

- **Method:** `GET`
- **Path:** `file-library/{{file_id}}/download`
- **Base URL:** `https://api.clickmeeting.com/v1`
- **Official documentation:** [Download File](https://dev.clickmeeting.com/api-doc/#get_file_library_download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `number` | yes | File identifier. |
