# Delete File with ClickMeeting

Deletes a file from ClickMeeting by file ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `file-library/{{file_id}}`
- **Base URL:** `https://api.clickmeeting.com/v1`
- **Official documentation:** [Delete File](https://dev.clickmeeting.com/api-doc/#delete_file_library)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `number` | yes | File identifier. |
