# List Time Zones with ClickMeeting

Retrieves available time zones from ClickMeeting.

## Endpoint

- **Method:** `GET`
- **Path:** `time_zone_list`
- **Base URL:** `https://api.clickmeeting.com/v1`
- **Official documentation:** [List Time Zones](https://dev.clickmeeting.com/api-doc/#get_time_zone_list)
