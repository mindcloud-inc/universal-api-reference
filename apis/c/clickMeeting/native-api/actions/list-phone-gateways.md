# List Phone Gateways with ClickMeeting

Retrieves available phone gateways from ClickMeeting.

## Endpoint

- **Method:** `GET`
- **Path:** `phone_gateways`
- **Base URL:** `https://api.clickmeeting.com/v1`
- **Official documentation:** [List Phone Gateways](https://dev.clickmeeting.com/api-doc/#get_phone_gateway)
