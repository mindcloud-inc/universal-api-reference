# Get File with ClickMeeting

Retrieves a file from ClickMeeting by file ID.

## Endpoint

- **Method:** `GET`
- **Path:** `file-library/{{file_id}}`
- **Base URL:** `https://api.clickmeeting.com/v1`
- **Official documentation:** [Get File](https://dev.clickmeeting.com/api-doc/#get_file_library_file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `number` | yes | File identifier. |
