# Fetch Contact with ChatBotKit

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/{contactId}/fetch`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Fetch Contact](https://chatbotkit.com/manuals/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The ID of the contact to retrieve |
