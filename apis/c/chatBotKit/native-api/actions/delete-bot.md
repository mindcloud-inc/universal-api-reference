# Delete Bot with ChatBotKit

## Endpoint

- **Method:** `POST`
- **Path:** `/bot/{botId}/delete`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Delete Bot](https://chatbotkit.com/manuals/bots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | path | `string` | yes | The ID of the bot to delete |
