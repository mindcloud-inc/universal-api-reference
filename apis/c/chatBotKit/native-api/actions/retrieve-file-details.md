# Retrieve File Details with ChatBotKit

## Endpoint

- **Method:** `GET`
- **Path:** `/file/{fileId}/fetch`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Retrieve File Details](https://chatbotkit.com/manuals/files)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The ID of the file to retrieve |
