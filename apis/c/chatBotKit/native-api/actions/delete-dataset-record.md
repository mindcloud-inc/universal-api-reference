# Delete Dataset Record with ChatBotKit

## Endpoint

- **Method:** `POST`
- **Path:** `/dataset/{datasetId}/record/{recordId}/delete`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Delete Dataset Record](https://chatbotkit.com/manuals/dataset-records)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset |
| `recordId` | path | `string` | yes | The ID of the dataset record to delete |
