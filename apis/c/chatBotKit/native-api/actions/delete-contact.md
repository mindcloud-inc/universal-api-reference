# Delete Contact with ChatBotKit

## Endpoint

- **Method:** `POST`
- **Path:** `/contact/{contactId}/delete`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Delete Contact](https://chatbotkit.com/manuals/contacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The ID of the contact to delete |
