# Fetch Bot with ChatBotKit

## Endpoint

- **Method:** `GET`
- **Path:** `/bot/{botId}/fetch`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Fetch Bot](https://chatbotkit.com/manuals/bots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `botId` | path | `string` | yes | The ID of the bot to retrieve |
