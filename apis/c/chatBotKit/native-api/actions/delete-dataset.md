# Delete Dataset with ChatBotKit

## Endpoint

- **Method:** `POST`
- **Path:** `/dataset/{datasetId}/delete`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Delete Dataset](https://chatbotkit.com/manuals/datasets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset to delete |
