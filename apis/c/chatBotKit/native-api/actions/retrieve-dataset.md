# Retrieve Dataset with ChatBotKit

## Endpoint

- **Method:** `GET`
- **Path:** `/dataset/{datasetId}/fetch`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Retrieve Dataset](https://chatbotkit.com/manuals/datasets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `datasetId` | path | `string` | yes | The ID of the dataset to retrieve |
