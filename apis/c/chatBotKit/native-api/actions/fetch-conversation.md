# Fetch Conversation with ChatBotKit

## Endpoint

- **Method:** `GET`
- **Path:** `/conversation/{conversationId}/fetch`
- **Base URL:** `https://api.chatbotkit.com/v1`
- **Official documentation:** [Fetch Conversation](https://chatbotkit.com/manuals/conversations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | The ID of the conversation to retrieve |
