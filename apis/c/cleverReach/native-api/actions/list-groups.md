# List Groups with CleverReach

Retrieves receiver groups from your CleverReach account.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Groups](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order` | query | `string` | no | order by statement (created ASC or DESC, changed ASC or DESC). |
