# Get Blacklist Entry with CleverReach

Retrieves a blacklist entry from CleverReach by email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/blacklist.json/:email`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Blacklist Entry](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/blacklist-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | email. |
