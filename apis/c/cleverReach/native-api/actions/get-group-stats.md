# Get Group Stats with CleverReach

Retrieves statistics for a group in CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:id/stats`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Group Stats](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Group ID. |
