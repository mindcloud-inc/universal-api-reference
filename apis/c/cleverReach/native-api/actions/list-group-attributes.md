# List Group Attributes with CleverReach

Retrieves local group attributes from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:groupId/attributes`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Group Attributes](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | ID of the group. |
