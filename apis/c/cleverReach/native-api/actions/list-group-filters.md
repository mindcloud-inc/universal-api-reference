# List Group Filters with CleverReach

Retrieves saved group filters from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:groupId/filters`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Group Filters](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | no |
