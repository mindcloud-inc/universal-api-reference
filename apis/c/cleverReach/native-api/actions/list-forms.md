# List Forms with CleverReach

Retrieves deprecated signup forms from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/forms.json`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Forms](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/forms-v3.json)
