# Get Group with CleverReach

Retrieves a group from CleverReach by group ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:id`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Group](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | group id. |
