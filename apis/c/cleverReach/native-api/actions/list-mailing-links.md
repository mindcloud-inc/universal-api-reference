# List Mailing Links with CleverReach

Retrieves links for a mailing in CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mailings.json/:id/links`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Mailing Links](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/mailings-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | mailing id. |
