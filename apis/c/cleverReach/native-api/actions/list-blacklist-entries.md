# List Blacklist Entries with CleverReach

Retrieves blacklisted email entries from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/blacklist.json`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Blacklist Entries](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/blacklist-v3.json)
