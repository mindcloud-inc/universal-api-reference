# Get Group Filter with CleverReach

Retrieves a group filter from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:groupId/filters/:filterId`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Group Filter](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | no | Group ID. |
| `filter_id` | path | `string` | no | Filter ID. |
