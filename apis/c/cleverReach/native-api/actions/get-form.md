# Get Form with CleverReach

Retrieves a deprecated form from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/forms.json/:id`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Form](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/forms-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | id. |
