# Get Attribute Limits with CleverReach

Retrieves account attribute limits from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/attributes/limits.json`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Attribute Limits](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/attributes-v3.json)
