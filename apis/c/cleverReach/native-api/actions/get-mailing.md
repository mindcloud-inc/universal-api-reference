# Get Mailing with CleverReach

Retrieves a mailing from CleverReach by mailing ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/mailings.json/:id`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Mailing](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/mailings-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | mailing id. |
