# List Bounces with CleverReach

Retrieves account bounce records from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/bounces.json`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Bounces](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/bounces-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pagesize` | query | `number` | no | max amount of entries per query. |
| `page` | query | `number` | no | page. |
