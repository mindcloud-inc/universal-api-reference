# List Group Forms with CleverReach

Retrieves deprecated group forms from CleverReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/groups.json/:id/forms`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [List Group Forms](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/groups-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Group ID. |
