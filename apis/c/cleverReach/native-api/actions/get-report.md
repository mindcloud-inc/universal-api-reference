# Get Report with CleverReach

Retrieves a report from CleverReach by report ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/reports.json/:id`
- **Base URL:** `https://rest.cleverreach.com`
- **Official documentation:** [Get Report](https://rest.cleverreach.com/explorer/v3/?url=https://rest.cleverreach.com/v3/resources/reports-v3.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Report ID/Mailing ID. |
