# Get Template By ID with Creatomate

Retrieves a template from Creatomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/templates/:template_id`
- **Base URL:** `https://api.creatomate.com`
- **Official documentation:** [Get Template By ID](https://creatomate.com/docs/api/reference/get-a-template-by-its-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template_id` | path | `string` | yes | The ID of the template to retrieve. |
