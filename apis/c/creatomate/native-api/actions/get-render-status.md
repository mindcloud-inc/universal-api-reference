# Get Render Status with Creatomate

Retrieves a render's status from Creatomate.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/renders/:render_id`
- **Base URL:** `https://api.creatomate.com`
- **Official documentation:** [Get Render Status](https://creatomate.com/docs/api/reference/get-the-status-of-a-render)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `render_id` | path | `string` | yes | The ID of the render to retrieve. |
