# Get License with Cryptlex

Retrieves a license from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/licenses/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get License](https://api.cryptlex.com/v3/docs#tag/Licenses/operation/get/v3/licenses/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the license. |
