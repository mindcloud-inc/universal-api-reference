# Get Webhook with Cryptlex

Retrieves a webhook from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/webhooks/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get Webhook](https://api.cryptlex.com/v3/docs#tag/Webhooks/operation/get/v3/webhooks/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the webhook. |
