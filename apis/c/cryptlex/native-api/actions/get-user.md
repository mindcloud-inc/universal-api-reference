# Get User with Cryptlex

Retrieves a user from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/users/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get User](https://api.cryptlex.com/v3/docs#tag/Users/operation/get/v3/users/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the user. |
