# Publish Release with Cryptlex

Publishes a release in Cryptlex.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/releases/:id/publish`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Publish Release](https://api.cryptlex.com/v3/docs#tag/Releases/operation/post/v3/releases/%7Bid%7D/publish)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the release. |
