# Renew License with Cryptlex

Renews a license in Cryptlex.

## Endpoint

- **Method:** `POST`
- **Path:** `/v3/licenses/:id/renew`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Renew License](https://api.cryptlex.com/v3/docs#tag/Licenses/operation/post/v3/licenses/%7Bid%7D/renew)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the license. |
