# Get Activation with Cryptlex

Retrieves an activation from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/activations/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get Activation](https://api.cryptlex.com/v3/docs#tag/Activations/operation/get/v3/activations/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the activation. |
