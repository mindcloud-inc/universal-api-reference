# Get Release with Cryptlex

Retrieves a release from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/releases/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get Release](https://api.cryptlex.com/v3/docs#tag/Releases/operation/get/v3/releases/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the release. |
