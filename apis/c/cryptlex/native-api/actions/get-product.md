# Get Product with Cryptlex

Retrieves a product from Cryptlex.

## Endpoint

- **Method:** `GET`
- **Path:** `/v3/products/:id`
- **Base URL:** `https://api.cryptlex.com`
- **Official documentation:** [Get Product](https://api.cryptlex.com/v3/docs#tag/Products/operation/get/v3/products/%7Bid%7D)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier for the product. |
