# Delete Customer with CrowdPower

Deletes an existing customer from CrowdPower.

## Endpoint

- **Method:** `DELETE`
- **Path:** `customers/:customer_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Delete Customer](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Customer identifier. |
