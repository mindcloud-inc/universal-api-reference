# Get Segment with CrowdPower

Retrieves a segment from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `segments/:segment_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Segment](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `segment_id` | path | `string` | yes | Segment identifier. |
