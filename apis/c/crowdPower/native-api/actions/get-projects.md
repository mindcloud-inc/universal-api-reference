# Get Projects with CrowdPower

Retrieves projects for a company in CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `companies/:company_id/projects`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Projects](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `string` | yes | Company identifier. |
