# Get Members with CrowdPower

Retrieves campaign members from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `campaigns/:campaign_id/members`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Members](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | Campaign identifier. |
