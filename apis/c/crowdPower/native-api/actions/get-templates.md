# Get Templates with CrowdPower

Retrieves templates from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/templates`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Templates](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for templates. |
