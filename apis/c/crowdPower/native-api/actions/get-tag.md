# Get Tag with CrowdPower

Retrieves a tag from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `tags/:tag_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Tag](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `string` | yes | Tag identifier. |
