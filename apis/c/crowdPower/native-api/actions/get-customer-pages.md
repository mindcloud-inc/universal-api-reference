# Get Customer Pages with CrowdPower

Retrieves pages for a customer in CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `customers/:customer_id/pages`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Customer Pages](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Customer identifier. |
