# Get Automations with CrowdPower

Retrieves automations from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/campaigns`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Automations](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for automations. |
