# Get Customers with CrowdPower

Retrieves customers from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/customers`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Customers](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for customers. |
