# Update Project with CrowdPower

Updates an existing project in CrowdPower.

## Endpoint

- **Method:** `PUT`
- **Path:** `projects/{projectId}`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Update Project](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Project name. |
| `website` | body | `string` | no | Project website URL. |
