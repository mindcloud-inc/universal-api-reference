# Update Project Theme with CrowdPower

Updates a project theme in CrowdPower.

## Endpoint

- **Method:** `PUT`
- **Path:** `projects/{projectId}/theme`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Update Project Theme](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `color_primary` | body | `string` | no | Primary theme color as a hex code. |
| `color_sidebar` | body | `string` | no | Sidebar theme color as a hex code. |
