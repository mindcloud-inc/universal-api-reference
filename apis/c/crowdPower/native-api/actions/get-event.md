# Get Event with CrowdPower

Retrieves an event from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `events/:event_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Event](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `event_id` | path | `string` | yes | Event identifier. |
