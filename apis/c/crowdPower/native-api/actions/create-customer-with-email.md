# Create Customer with Email with CrowdPower

Creates a customer in CrowdPower with an email address.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/{projectId}/customers`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Create Customer with Email](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Customer email address. |
