# Get Tags with CrowdPower

Retrieves tags from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/tags`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Tags](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for tags. |
