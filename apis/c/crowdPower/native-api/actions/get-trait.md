# Get Trait with CrowdPower

Retrieves a trait from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `traits/:trait_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Trait](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | yes | Trait identifier. |
