# Get Customer Charges with CrowdPower

Retrieves charges for a customer in CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `customers/:customer_id/charges`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Customer Charges](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Customer identifier. |
