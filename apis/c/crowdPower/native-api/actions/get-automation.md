# Get Automation with CrowdPower

Retrieves an automation from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `campaigns/:campaign_id`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Automation](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaign_id` | path | `string` | yes | Campaign identifier. |
