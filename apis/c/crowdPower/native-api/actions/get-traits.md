# Get Traits with CrowdPower

Retrieves traits from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/traits`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Traits](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for traits. |
| `type` | query | `string` | no | Trait type selector. |
