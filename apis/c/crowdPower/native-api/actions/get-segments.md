# Get Segments with CrowdPower

Retrieves segments from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/segments`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Segments](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for segments. |
