# Unsubscribe from All Emails with CrowdPower

Unsubscribes a customer from all emails in CrowdPower.

## Endpoint

- **Method:** `PUT`
- **Path:** `customers/:customer_id/unsubscribe`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Unsubscribe from All Emails](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customer_id` | path | `string` | yes | Customer identifier. |
