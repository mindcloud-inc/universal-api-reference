# Get Events with CrowdPower

Retrieves events from CrowdPower.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/{projectId}/events`
- **Base URL:** `https://api.crowdpower.io/v1`
- **Official documentation:** [Get Events](https://documenter.getpostman.com/view/17896162/UV5TFKbh)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Search query for events. |
