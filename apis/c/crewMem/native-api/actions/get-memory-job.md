# Get Memory Job with CrewMem

## Endpoint

- **Method:** `GET`
- **Path:** `/api/memory/jobs/:id`
- **Base URL:** `https://crewmem.com`
- **Official documentation:** [Get Memory Job](https://crewmem.com/docs/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Memory job ID |
