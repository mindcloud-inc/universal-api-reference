# Get Channel with Callbell

Retrieves a specific channel from Callbell.

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:uuid`
- **Base URL:** `https://api.callbell.eu/v1`
- **Official documentation:** [Get Channel](https://docs.callbell.eu/api/reference/channels_api/get_channel/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique identifier of the channel. |
