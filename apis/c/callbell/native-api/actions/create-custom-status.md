# Create Custom Status with Callbell

Creates a new custom status in Callbell.

## Endpoint

- **Method:** `POST`
- **Path:** `/custom_statuses`
- **Base URL:** `https://api.callbell.eu/v1`
- **Official documentation:** [Create Custom Status](https://docs.callbell.eu/api/reference/custom_status_api/post_custom_status/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the custom status. |
