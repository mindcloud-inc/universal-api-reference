# Delete Custom Status with Callbell

Deletes an existing custom status from Callbell.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/custom_statuses/:uuid`
- **Base URL:** `https://api.callbell.eu/v1`
- **Official documentation:** [Delete Custom Status](https://docs.callbell.eu/api/reference/custom_status_api/delete_custom_status/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique identifier of the custom status to delete. |
