# List Custom Statuses with Callbell

Retrieves custom statuses for the current Callbell account.

## Endpoint

- **Method:** `GET`
- **Path:** `/custom_statuses`
- **Base URL:** `https://api.callbell.eu/v1`
- **Official documentation:** [List Custom Statuses](https://docs.callbell.eu/api/reference/custom_status_api/get_custom_statuses/)
