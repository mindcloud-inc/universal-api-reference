# Delete Contact with Callbell

Deletes an existing contact from Callbell.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:uuid`
- **Base URL:** `https://api.callbell.eu/v1`
- **Official documentation:** [Delete Contact](https://docs.callbell.eu/api/reference/contacts_api/delete_contact/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Unique identifier of the contact to delete. |
