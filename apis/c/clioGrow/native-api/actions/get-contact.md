- **Method:** `GET`
- **Path:** `/contacts/{id}`

- **Official documentation:** [Get Contact](https://docs.developers.clio.com/clio-grow/api-reference/#tag/Contacts/operation/Contact%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the contact. |
