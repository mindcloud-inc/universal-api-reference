# Get Matter with Clio Grow

## Endpoint

- **Method:** `GET`
- **Path:** `/matters/{id}`
- **Base URL:** `https://api.clio.com/grow`
- **Official documentation:** [Get Matter](https://docs.developers.clio.com/clio-grow/api-reference/#tag/Matters/operation/Matter%23show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The unique identifier for the matter. |
