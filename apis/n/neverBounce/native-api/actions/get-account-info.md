# Get Account Info with NeverBounce

Retrieves account details and usage information from NeverBounce.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/info`
- **Base URL:** `https://api.neverbounce.com/v4.2`
- **Official documentation:** [Get Account Info](https://developers.neverbounce.com/reference/account-info)
