# Get Job Status with NeverBounce

Retrieves the current status of a NeverBounce job.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/status`
- **Base URL:** `https://api.neverbounce.com/v4.2`
- **Official documentation:** [Get Job Status](https://developers.neverbounce.com/reference/jobs-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `job_id` | query | `number` | yes | NeverBounce job identifier. |
