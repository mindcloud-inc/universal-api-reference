# Get Current User with NextBrain

Retrieves the current user from NextBrain.

## Endpoint

- **Method:** `POST`
- **Path:** `/login/nextbrain-token`
- **Base URL:** `https://api.nextbrain.ai`
- **Official documentation:** [Get Current User](https://api.nextbrain.ai/docs)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
