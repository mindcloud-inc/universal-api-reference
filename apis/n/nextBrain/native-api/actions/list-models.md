# List Models with NextBrain

Retrieves available model IDs from NextBrain.

## Endpoint

- **Method:** `POST`
- **Path:** `/model/model_ids_token`
- **Base URL:** `https://api.nextbrain.ai`
- **Official documentation:** [List Models](https://api.nextbrain.ai/docs)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
