# Delete Site with Netlify

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api.netlify.com/api/v1`
- **Official documentation:** [Delete Site](https://open-api.netlify.com/#operation/deleteSite)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<string>` | yes | The Netlify site ID. |
