# List Site Forms with Netlify

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/forms`
- **Base URL:** `https://api.netlify.com/api/v1`
- **Official documentation:** [List Site Forms](https://open-api.netlify.com/#operation/listSiteForms)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `site_id` | path | `string` | yes |
