# Get Site with Netlify

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id`
- **Base URL:** `https://api.netlify.com/api/v1`
- **Official documentation:** [Get Site](https://open-api.netlify.com/#operation/getSite)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site_id` | path | `list<string>` | yes | The Netlify site ID. |
