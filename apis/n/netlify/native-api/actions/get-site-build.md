# Get Site Build with Netlify

## Endpoint

- **Method:** `GET`
- **Path:** `/builds/:build_id`
- **Base URL:** `https://api.netlify.com/api/v1`
- **Official documentation:** [Get Site Build](https://open-api.netlify.com/#operation/getSiteBuild)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `build_id` | path | `string` | yes |
