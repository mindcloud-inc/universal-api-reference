# List Site Build Hooks with Netlify

## Endpoint

- **Method:** `GET`
- **Path:** `/sites/:site_id/build_hooks`
- **Base URL:** `https://api.netlify.com/api/v1`
- **Official documentation:** [List Site Build Hooks](https://open-api.netlify.com/#operation/listSiteBuildHooks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `site_id` | path | `list<string>` | yes |
