# Fetch Person Newsfeed with Nyne AI

Retrieves social media posts for a person from Nyne AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/person/newsfeed`
- **Base URL:** `https://api.nyne.ai`
- **Official documentation:** [Fetch Person Newsfeed](https://api.nyne.ai/documentation/person/newsfeed)
