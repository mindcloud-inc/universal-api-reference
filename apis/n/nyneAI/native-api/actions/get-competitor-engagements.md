# Get Competitor Engagements with Nyne AI

Retrieves competitor engagements for people from Nyne AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/person/competitor-engagements`
- **Base URL:** `https://api.nyne.ai`
- **Official documentation:** [Get Competitor Engagements](https://api.nyne.ai/documentation/person/competitor-engagements)
