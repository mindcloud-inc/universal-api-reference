# Find Single Social Profile with Nyne AI

Retrieves one social profile for a person from Nyne AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/person/single-social-lookup`
- **Base URL:** `https://api.nyne.ai`
- **Official documentation:** [Find Single Social Profile](https://api.nyne.ai/documentation/person/single-social-lookup)
