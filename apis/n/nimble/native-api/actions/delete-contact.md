# Delete Contact with Nimble

Deletes an existing contact from Nimble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contact/:contact_id`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [Delete Contact](https://www.nimble.com/developers/docs/#tag/Contacts/operation/delete-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Nimble contact_id path parameter. |
