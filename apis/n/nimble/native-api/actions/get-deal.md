# Get Deal with Nimble

Retrieves a deal from Nimble by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/deals/:deal_id`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [Get Deal](https://www.nimble.com/developers/docs/#tag/Deals/operation/get-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deal_id` | path | `string` | yes | Nimble deal_id path parameter. |
