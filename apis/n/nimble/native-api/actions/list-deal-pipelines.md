# List Deal Pipelines with Nimble

Retrieves available deal pipelines from Nimble.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/deals/pipelines`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [List Deal Pipelines](https://www.nimble.com/developers/docs/#tag/Deals-Pipelines/operation/list-deals-pipelines)
