# Delete Contact Note with Nimble

Deletes an existing contact note from Nimble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/contacts/notes/:note_id`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [Delete Contact Note](https://www.nimble.com/developers/docs/#tag/Contacts/operation/delete-contact-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `note_id` | path | `string` | yes | Nimble note_id path parameter. |
