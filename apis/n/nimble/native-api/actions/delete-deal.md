# Delete Deal with Nimble

Deletes an existing deal from Nimble.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/deals/:deal_id`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [Delete Deal](https://www.nimble.com/developers/docs/#tag/Deals/operation/delete-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `deal_id` | path | `string` | yes | Nimble deal_id path parameter. |
