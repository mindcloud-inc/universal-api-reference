# Get Contact with Nimble

Retrieves a contact from Nimble by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contact/:contact_id`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [Get Contact](https://www.nimble.com/developers/docs/#tag/Contacts/operation/get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contact_id` | path | `string` | yes | Nimble contact_id path parameter. |
