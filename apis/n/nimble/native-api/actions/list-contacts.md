# List Contacts with Nimble

Retrieves a filtered list of contacts from Nimble.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [List Contacts](https://www.nimble.com/developers/docs/#tag/Contacts/operation/list-contacts)
