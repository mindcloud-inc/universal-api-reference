# List Contact Pipelines with Nimble

Retrieves available contact pipelines from Nimble.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/contacts/pipelines`
- **Base URL:** `https://app.nimble.com`
- **Official documentation:** [List Contact Pipelines](https://www.nimble.com/developers/docs/#tag/Contacts-Pipelines/operation/list-available-contacts-pipelines)
