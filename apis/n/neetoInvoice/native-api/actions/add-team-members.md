# Add Team Members with NeetoInvoice

Adds new team members in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/team_members`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Add Team Members](https://apidocs.neetoinvoice.com/api-reference/team-members/add)
