# Update Team Member with NeetoInvoice

Updates an existing team member in NeetoInvoice.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/team_members/{team_member_id}`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Update Team Member](https://apidocs.neetoinvoice.com/api-reference/team-members/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_member_id` | path | `string` | no | Team member identifier. |
