# Update Project User with NeetoInvoice

Updates a project user in NeetoInvoice.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/projects/{project_id}/project_users/{project_user_id}`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Update Project User](https://apidocs.neetoinvoice.com/api-reference/project-users/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Project identifier. |
| `project_user_id` | path | `string` | no | Project user identifier. |
