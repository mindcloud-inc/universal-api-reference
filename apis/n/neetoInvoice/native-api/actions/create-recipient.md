# Create Recipient with NeetoInvoice

Creates a new recipient in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients/{client_id}/recipients`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Create Recipient](https://apidocs.neetoinvoice.com/api-reference/recipients/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | no | Parent client identifier. |
