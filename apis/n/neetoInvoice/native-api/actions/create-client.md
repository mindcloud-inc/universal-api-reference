# Create Client with NeetoInvoice

Creates a new client in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Create Client](https://apidocs.neetoinvoice.com/api-reference/clients/create)
