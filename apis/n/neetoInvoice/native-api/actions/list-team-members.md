# List Team Members with NeetoInvoice

Retrieves all team members from NeetoInvoice.

## Endpoint

- **Method:** `GET`
- **Path:** `/team_members`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [List Team Members](https://apidocs.neetoinvoice.com/api-reference/team-members/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
