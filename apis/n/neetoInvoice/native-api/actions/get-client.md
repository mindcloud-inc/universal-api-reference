# Get Client with NeetoInvoice

Retrieves details for a client from NeetoInvoice.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/{client_id}`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Get Client](https://apidocs.neetoinvoice.com/api-reference/clients/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | no | Client identifier. |
