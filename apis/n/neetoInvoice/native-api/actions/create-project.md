# Create Project with NeetoInvoice

Creates a new project in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Create Project](https://apidocs.neetoinvoice.com/api-reference/projects/create)
