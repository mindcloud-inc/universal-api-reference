# Create Time Entry with NeetoInvoice

Creates a new time entry in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/time_entry`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Create Time Entry](https://apidocs.neetoinvoice.com/api-reference/time-entry/create)
