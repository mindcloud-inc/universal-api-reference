# List Project Users with NeetoInvoice

Retrieves all project users from NeetoInvoice.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}/project_users`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [List Project Users](https://apidocs.neetoinvoice.com/api-reference/project-users/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Project identifier. |
