# Add Project User with NeetoInvoice

Adds a user to a project in NeetoInvoice.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/{project_id}/project_users`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Add Project User](https://apidocs.neetoinvoice.com/api-reference/project-users/add)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Project identifier. |
