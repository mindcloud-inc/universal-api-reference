# Get Project with NeetoInvoice

Retrieves details for a project from NeetoInvoice.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{project_id}`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Get Project](https://apidocs.neetoinvoice.com/api-reference/projects/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | no | Project identifier. |
