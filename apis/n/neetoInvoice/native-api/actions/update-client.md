# Update Client with NeetoInvoice

Updates an existing client in NeetoInvoice.

## Endpoint

- **Method:** `PUT`
- **Path:** `/clients/{client_id}`
- **Base URL:** `https://{workspaceSubdomain}.neetoinvoice.com/api/external/v1`
- **Official documentation:** [Update Client](https://apidocs.neetoinvoice.com/api-reference/clients/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client_id` | path | `string` | no | Client identifier. |
