# Get Payment Method with NetLicensing

Retrieves a payment method from NetLicensing.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentmethod/{paymentMethodNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Get Payment Method](https://netlicensing.io/wiki/payment-method-services)
