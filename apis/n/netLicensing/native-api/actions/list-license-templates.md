# List License Templates with NetLicensing

Finds license templates in NetLicensing by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/licensetemplate`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [List License Templates](https://netlicensing.io/wiki/license-template-services)
