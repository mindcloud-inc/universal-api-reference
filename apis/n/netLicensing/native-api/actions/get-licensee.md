# Get Licensee with NetLicensing

Retrieves a licensee from NetLicensing.

## Endpoint

- **Method:** `GET`
- **Path:** `/licensee/{licenseeNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Get Licensee](https://netlicensing.io/wiki/licensee-services)
