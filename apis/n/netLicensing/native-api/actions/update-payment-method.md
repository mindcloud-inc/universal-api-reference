# Update Payment Method with NetLicensing

Updates an existing payment method in NetLicensing.

## Endpoint

- **Method:** `POST`
- **Path:** `/paymentmethod/{paymentMethodNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Update Payment Method](https://netlicensing.io/wiki/payment-method-services)
