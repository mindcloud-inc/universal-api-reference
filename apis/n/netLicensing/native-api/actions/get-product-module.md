# Get Product Module with NetLicensing

Retrieves a product module from NetLicensing.

## Endpoint

- **Method:** `GET`
- **Path:** `/productmodule/{productModuleNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Get Product Module](https://netlicensing.io/wiki/product-module-services)
