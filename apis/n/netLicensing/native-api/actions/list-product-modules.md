# List Product Modules with NetLicensing

Finds product modules in NetLicensing by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/productmodule`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [List Product Modules](https://netlicensing.io/wiki/product-module-services)
