# List Licensing Models with NetLicensing

Retrieves licensing models from NetLicensing.

## Endpoint

- **Method:** `GET`
- **Path:** `/utility/licensingModels`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [List Licensing Models](https://netlicensing.io/wiki/utility-services)
