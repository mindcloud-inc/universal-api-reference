# List Payment Methods with NetLicensing

Finds payment methods in NetLicensing by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/paymentmethod`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [List Payment Methods](https://netlicensing.io/wiki/payment-method-services)
