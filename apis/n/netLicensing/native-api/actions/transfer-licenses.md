# Transfer Licenses with NetLicensing

Transfers licenses between licensees in NetLicensing.

## Endpoint

- **Method:** `POST`
- **Path:** `/licensee/{licenseeNumber}/transfer`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Transfer Licenses](https://netlicensing.io/wiki/licensee-services)
