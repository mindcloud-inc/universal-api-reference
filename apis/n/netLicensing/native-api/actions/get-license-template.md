# Get License Template with NetLicensing

Retrieves a license template from NetLicensing.

## Endpoint

- **Method:** `GET`
- **Path:** `/licensetemplate/{licenseTemplateNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Get License Template](https://netlicensing.io/wiki/license-template-services)
