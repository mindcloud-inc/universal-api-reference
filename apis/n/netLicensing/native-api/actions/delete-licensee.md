# Delete Licensee with NetLicensing

Deletes an existing licensee from NetLicensing.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/licensee/{licenseeNumber}`
- **Base URL:** `https://go.netlicensing.io/core/v2/rest`
- **Official documentation:** [Delete Licensee](https://netlicensing.io/wiki/licensee-services)
