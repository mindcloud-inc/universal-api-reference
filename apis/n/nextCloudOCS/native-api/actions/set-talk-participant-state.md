# Set Talk Participant State with Next Cloud OCS

Sets a talk participant state in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants/state`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Participant State](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
