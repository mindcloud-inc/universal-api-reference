# Set Talk Mention Permissions with Next Cloud OCS

Sets talk mention permissions in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/mention-permissions`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Mention Permissions](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-mention-permissions)
