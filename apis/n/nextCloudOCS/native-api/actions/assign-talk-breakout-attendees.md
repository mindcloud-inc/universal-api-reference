# Assign Talk Breakout Attendees with Next Cloud OCS

Assigns attendees to talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/attendees`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Assign Talk Breakout Attendees](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
