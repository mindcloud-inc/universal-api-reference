# Add Talk Bot Reaction with Next Cloud OCS

Adds a talk bot reaction in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/{{token}}/reaction/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Add Talk Bot Reaction](https://nextcloud-talk.readthedocs.io/en/stable/bots/)
