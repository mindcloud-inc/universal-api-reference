# Open Direct Editing File with Next Cloud OCS

Opens a direct editing file in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/directEditing/open`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Open Direct Editing File](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#capabilities-api)
