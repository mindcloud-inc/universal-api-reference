# Set Talk Permissions with Next Cloud OCS

Sets talk permissions in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/permissions/{{mode}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Permissions](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-default-or-call-permissions-for-a-conversation)
