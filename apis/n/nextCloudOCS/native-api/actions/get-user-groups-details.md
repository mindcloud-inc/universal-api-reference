# Get User Groups Details with Next Cloud OCS

Retrieves user groups details from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/users/{{userId}}/groups/details`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get User Groups Details](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
