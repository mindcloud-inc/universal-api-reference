# List File Templates with Next Cloud OCS

Retrieves file templates from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files/api/v1/templates`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List File Templates](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
