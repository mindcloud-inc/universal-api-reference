# Delete Talk Recording Notification with Next Cloud OCS

Deletes a talk recording notification from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/recording/{{token}}/notification`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Recording Notification](https://nextcloud-talk.readthedocs.io/en/stable/recording/)
