# Vote Talk Poll with Next Cloud OCS

Votes on a talk poll in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/poll/{{token}}/{{pollId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Vote Talk Poll](https://nextcloud-talk.readthedocs.io/en/stable/poll/)
