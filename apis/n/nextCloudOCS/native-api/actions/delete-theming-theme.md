# Delete Theming Theme with Next Cloud OCS

Deletes a theming theme from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/theming/api/v1/theme/{{themeId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Theming Theme](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
