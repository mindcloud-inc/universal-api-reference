# Get Cloud Shared Secret with Next Cloud OCS

Retrieves cloud shared secret from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/shared-secret`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Cloud Shared Secret](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
