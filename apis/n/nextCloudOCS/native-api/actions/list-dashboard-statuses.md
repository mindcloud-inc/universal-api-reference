# List Dashboard Statuses with Next Cloud OCS

Retrieves dashboard statuses from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v3/statuses`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Dashboard Statuses](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
