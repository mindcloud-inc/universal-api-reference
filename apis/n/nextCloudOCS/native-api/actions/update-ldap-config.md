# Update LDAP Config with Next Cloud OCS

Updates a LDAP config in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/user_ldap/api/v1/config/{{configID}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update LDAP Config](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
