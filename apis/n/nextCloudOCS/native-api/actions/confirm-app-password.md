# Confirm App Password with Next Cloud OCS

Confirms an app password in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/core/apppassword/confirm`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Confirm App Password](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
