# Set Reference Provider with Next Cloud OCS

Sets a reference provider in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/references/provider/{{providerId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Reference Provider](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
