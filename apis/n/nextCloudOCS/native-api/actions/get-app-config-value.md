# Get App Config Value with Next Cloud OCS

Retrieves app config value from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/provisioning_api/api/v1/config/apps/{{app}}/{{key}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get App Config Value](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
