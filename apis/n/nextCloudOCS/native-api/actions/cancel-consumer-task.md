# Cancel Consumer Task with Next Cloud OCS

Cancels a consumer task in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_consumer/tasks/{{taskId}}/cancel`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Cancel Consumer Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
