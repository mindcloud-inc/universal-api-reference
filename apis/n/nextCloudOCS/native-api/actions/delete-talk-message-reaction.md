# Delete Talk Message Reaction with Next Cloud OCS

Deletes a talk message reaction from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/reaction/{{token}}/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Message Reaction](https://nextcloud-talk.readthedocs.io/en/stable/reaction/)
