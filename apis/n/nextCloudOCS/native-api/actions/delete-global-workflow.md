# Delete Global Workflow with Next Cloud OCS

Deletes a global workflow from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/workflowengine/api/v1/workflows/global/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Global Workflow](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
