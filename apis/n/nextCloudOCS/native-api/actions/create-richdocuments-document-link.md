# Create Richdocuments Document Link with Next Cloud OCS

Creates a new richdocuments document link in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/richdocuments/api/v1/document`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Richdocuments Document Link](https://collabora-online-for-nextcloud.readthedocs.io/en/latest/mobile_editor/)
