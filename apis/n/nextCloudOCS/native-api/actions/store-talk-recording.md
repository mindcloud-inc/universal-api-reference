# Store Talk Recording with Next Cloud OCS

Stores a talk recording in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/recording/{{token}}/store`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Store Talk Recording](https://nextcloud-talk.readthedocs.io/en/stable/recording/)
