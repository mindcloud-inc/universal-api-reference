# Get Task Processing Task with Next Cloud OCS

Retrieves task processing task from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/task/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Task Processing Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
