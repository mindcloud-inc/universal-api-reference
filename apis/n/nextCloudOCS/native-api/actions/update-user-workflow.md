# Update User Workflow with Next Cloud OCS

Updates a user workflow in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/workflowengine/api/v1/workflows/user/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update User Workflow](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
