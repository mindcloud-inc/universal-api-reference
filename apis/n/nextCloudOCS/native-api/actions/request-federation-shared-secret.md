# Request Federation Shared Secret with Next Cloud OCS

Requests a federation shared secret from Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/federation/api/v1/request-shared-secret`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Request Federation Shared Secret](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
