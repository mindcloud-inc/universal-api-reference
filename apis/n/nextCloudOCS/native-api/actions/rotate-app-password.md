# Rotate App Password with Next Cloud OCS

Rotates an app password in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/core/apppassword/rotate`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Rotate App Password](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
