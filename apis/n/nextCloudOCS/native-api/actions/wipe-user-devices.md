# Wipe User Devices with Next Cloud OCS

Wipes user devices in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/users/{{userId}}/wipe`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Wipe User Devices](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
