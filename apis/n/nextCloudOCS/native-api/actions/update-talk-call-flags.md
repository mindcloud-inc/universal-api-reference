# Update Talk Call Flags with Next Cloud OCS

Updates talk call flags in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Talk Call Flags](https://nextcloud-talk.readthedocs.io/en/stable/call/)
