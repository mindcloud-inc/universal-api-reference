# Extract Public References with Next Cloud OCS

Extracts public references in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/references/extractPublic`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Extract Public References](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
