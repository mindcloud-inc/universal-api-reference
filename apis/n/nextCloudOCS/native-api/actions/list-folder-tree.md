# List Folder Tree with Next Cloud OCS

Retrieves folder tree from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files/api/v1/folder-tree`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Folder Tree](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
