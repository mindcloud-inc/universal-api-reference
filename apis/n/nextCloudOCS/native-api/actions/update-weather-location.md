# Update Weather Location with Next Cloud OCS

Updates a weather location in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/location`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Weather Location](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
