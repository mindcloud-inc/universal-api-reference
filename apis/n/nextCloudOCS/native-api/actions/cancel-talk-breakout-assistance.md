# Cancel Talk Breakout Assistance with Next Cloud OCS

Cancels a talk breakout assistance in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/request-assistance`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Cancel Talk Breakout Assistance](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
