# List Activity with Next Cloud OCS

Retrieves activity from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/activity/api/v2/activity`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Activity](https://github.com/nextcloud/activity/blob/master/docs/endpoint-v2.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `since` | query | `number` | no |
