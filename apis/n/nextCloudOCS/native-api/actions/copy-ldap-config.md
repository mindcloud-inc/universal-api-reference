# Copy LDAP Config with Next Cloud OCS

Copies a LDAP config in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/user_ldap/api/v1/config/{{configID}}/copy`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Copy LDAP Config](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
