# Create Trusted Server with Next Cloud OCS

Creates a new trusted server in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/federation/trusted-servers`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Trusted Server](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
