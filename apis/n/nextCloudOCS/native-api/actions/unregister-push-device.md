# Unregister Push Device with Next Cloud OCS

Unregisters a push device from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/push`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Unregister Push Device](https://github.com/nextcloud/notifications/blob/master/docs/push-v2.md)
