# List App Config Keys with Next Cloud OCS

Retrieves app config keys from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/provisioning_api/api/v1/config/apps/{{app}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List App Config Keys](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
