# Set Talk Webinar Lobby with Next Cloud OCS

Sets a talk webinar lobby in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/webinar/lobby`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Webinar Lobby](https://nextcloud-talk.readthedocs.io/en/stable/webinar/)
