# Get Talk Poll with Next Cloud OCS

Retrieves talk poll from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/poll/{{token}}/{{pollId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Poll](https://nextcloud-talk.readthedocs.io/en/stable/poll/)
