# List Talk Chat Messages with Next Cloud OCS

Retrieves talk chat messages from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Chat Messages](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
