# Remove Active Talk Participant with Next Cloud OCS

Removes an active talk participant from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants/active`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Remove Active Talk Participant](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
