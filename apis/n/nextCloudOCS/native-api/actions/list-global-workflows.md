# List Global Workflows with Next Cloud OCS

Retrieves global workflows from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/workflowengine/api/v1/workflows/global`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Global Workflows](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
