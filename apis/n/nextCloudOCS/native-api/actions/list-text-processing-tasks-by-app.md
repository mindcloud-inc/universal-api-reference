# List Text Processing Tasks By App with Next Cloud OCS

Retrieves text processing tasks by app from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/textprocessing/tasks/app/{{appId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Text Processing Tasks By App](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
