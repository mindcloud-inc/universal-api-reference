# Get One Time App Password with Next Cloud OCS

Retrieves one time app password from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/core/getapppassword-onetime`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get One Time App Password](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
