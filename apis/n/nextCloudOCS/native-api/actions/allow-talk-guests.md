# Allow Talk Guests with Next Cloud OCS

Allows talk guests in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/public`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Allow Talk Guests](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#allow-guests-in-a-conversation-public-conversation)
