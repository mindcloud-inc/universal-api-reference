# Set App Config Value with Next Cloud OCS

Sets an app config value in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/provisioning_api/api/v1/config/apps/{{app}}/{{key}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set App Config Value](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
