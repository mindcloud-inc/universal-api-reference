# List Reference Providers with Next Cloud OCS

Retrieves reference providers from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/references/providers`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Reference Providers](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
