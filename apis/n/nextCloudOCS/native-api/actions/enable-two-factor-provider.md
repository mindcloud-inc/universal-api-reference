# Enable Two Factor Provider with Next Cloud OCS

Enables a two factor provider in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/twofactor/enable`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Enable Two Factor Provider](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
