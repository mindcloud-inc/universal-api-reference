# Delete Talk Bot Reaction with Next Cloud OCS

Deletes a talk bot reaction from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/{{token}}/reaction/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Bot Reaction](https://nextcloud-talk.readthedocs.io/en/stable/bots/)
