# Import Contacts File with Next Cloud OCS

Imports a contacts file into Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/contacts/api/v1/import/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Import Contacts File](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/ClientIntegration/index.html)
