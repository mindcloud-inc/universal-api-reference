# Register Push Device with Next Cloud OCS

Registers a push device in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/push`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Register Push Device](https://github.com/nextcloud/notifications/blob/master/docs/push-v2.md)
