# Set Talk Listable Scope with Next Cloud OCS

Sets a talk listable scope in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/listable`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Listable Scope](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#open-a-conversation)
