# Send Test Notification To Self with Next Cloud OCS

Sends test notification to self in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v3/test/self`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Send Test Notification To Self](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
