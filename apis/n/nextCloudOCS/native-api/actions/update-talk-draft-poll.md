# Update Talk Draft Poll with Next Cloud OCS

Updates a talk draft poll in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/poll/{{token}}/draft/{{pollId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Talk Draft Poll](https://nextcloud-talk.readthedocs.io/en/stable/poll/)
