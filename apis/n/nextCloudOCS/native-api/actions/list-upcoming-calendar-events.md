# List Upcoming Calendar Events with Next Cloud OCS

Retrieves the upcoming calendar events from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/dav/api/v1/events/upcoming`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Upcoming Calendar Events](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
