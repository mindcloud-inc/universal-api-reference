# List Group Users with Next Cloud OCS

Retrieves group users from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/groups/{{groupId}}/users`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Group Users](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html)
