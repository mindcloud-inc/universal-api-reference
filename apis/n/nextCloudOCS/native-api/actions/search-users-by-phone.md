# Search Users By Phone with Next Cloud OCS

Finds users in Next Cloud OCS by phone number.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/users/search/by-phone`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Search Users By Phone](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
