# Get Talk Conversation Avatar with Next Cloud OCS

Retrieves talk conversation avatar from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/avatar`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Conversation Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
