# Delete Consumer Task with Next Cloud OCS

Deletes a consumer task from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_consumer/task/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Consumer Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
