# List Talk Shared Items with Next Cloud OCS

Retrieves talk shared items from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/share`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Shared Items](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
