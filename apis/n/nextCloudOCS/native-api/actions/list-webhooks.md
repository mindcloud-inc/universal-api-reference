# List Webhooks with Next Cloud OCS

Retrieves webhooks from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/webhook_listeners/api/v1/webhooks`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Webhooks](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
