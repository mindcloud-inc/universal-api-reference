# Update Dashboard Statuses with Next Cloud OCS

Updates dashboard statuses in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v3/statuses`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Dashboard Statuses](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
