# Accept File Ownership Transfer with Next Cloud OCS

Accepts a file ownership transfer in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/transferownership/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Accept File Ownership Transfer](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
