# Disable User with Next Cloud OCS

Disables a user in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}/disable`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Disable User](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
