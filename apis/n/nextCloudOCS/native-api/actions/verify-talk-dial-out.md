# Verify Talk Dial Out with Next Cloud OCS

Verifies talk dial-out details in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/verify-dialout`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Verify Talk Dial Out](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
