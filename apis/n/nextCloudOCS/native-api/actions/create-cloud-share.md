# Create Cloud Share with Next Cloud OCS

Creates a new cloud share in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/shares`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Cloud Share](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
