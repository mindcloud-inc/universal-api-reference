# Create User with Next Cloud OCS

Creates a new user in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v1.php/cloud/users`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create User](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
