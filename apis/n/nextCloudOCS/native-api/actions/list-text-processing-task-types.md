# List Text Processing Task Types with Next Cloud OCS

Retrieves text processing task types from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/textprocessing/tasktypes`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Text Processing Task Types](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
