# Get Task Processing Queue Stats with Next Cloud OCS

Retrieves task processing queue stats from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/queue_stats`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Task Processing Queue Stats](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
