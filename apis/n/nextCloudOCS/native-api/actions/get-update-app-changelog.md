# Get Update App Changelog with Next Cloud OCS

Retrieves update app changelog from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/updatenotification/api/{{apiVersion}}/changelog/{{appId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Update App Changelog](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
