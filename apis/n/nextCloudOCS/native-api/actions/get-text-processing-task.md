# Get Text Processing Task with Next Cloud OCS

Retrieves text processing task from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/textprocessing/task/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Text Processing Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
