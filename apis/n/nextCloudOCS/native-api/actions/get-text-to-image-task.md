# Get Text To Image Task with Next Cloud OCS

Retrieves text to image task from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/text2image/task/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Text To Image Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
