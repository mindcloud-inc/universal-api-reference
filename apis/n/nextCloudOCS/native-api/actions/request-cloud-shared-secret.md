# Request Cloud Shared Secret with Next Cloud OCS

Requests a cloud shared secret from Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/shared-secret`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Request Cloud Shared Secret](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
