# Set Talk Webinar Sip with Next Cloud OCS

Sets a talk webinar sip in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/webinar/sip`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Webinar Sip](https://nextcloud-talk.readthedocs.io/en/stable/webinar/)
