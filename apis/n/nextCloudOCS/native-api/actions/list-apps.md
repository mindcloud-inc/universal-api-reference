# List Apps with Next Cloud OCS

Retrieves apps from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/apps`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Apps](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_apps.html#get-list-of-apps)
