# List Talk Message Reactions with Next Cloud OCS

Retrieves talk message reactions from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/reaction/{{token}}/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Message Reactions](https://nextcloud-talk.readthedocs.io/en/stable/reaction/)
