# Get Cloud Capabilities V2 with Next Cloud OCS

Retrieves cloud capabilities from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/capabilities`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Cloud Capabilities V2](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
