# Convert File with Next Cloud OCS

Converts a file in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/convert`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Convert File](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
