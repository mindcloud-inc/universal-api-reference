# List Predefined Statuses with Next Cloud OCS

Retrieves predefined statuses from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/predefined_statuses`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Predefined Statuses](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html#fetch-the-list-of-predefined-statuses)
