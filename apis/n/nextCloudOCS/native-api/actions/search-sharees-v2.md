# Search Sharees V2 with Next Cloud OCS

Finds sharees in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files_sharing/api/v1/sharees`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Search Sharees V2](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
