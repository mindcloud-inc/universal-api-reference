# Send User Status Heartbeat with Next Cloud OCS

Sends a user status heartbeat in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/heartbeat`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Send User Status Heartbeat](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html)
