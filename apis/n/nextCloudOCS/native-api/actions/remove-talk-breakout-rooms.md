# Remove Talk Breakout Rooms with Next Cloud OCS

Removes talk breakout rooms from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Remove Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
