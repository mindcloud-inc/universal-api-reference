# List Weather Favorites with Next Cloud OCS

Retrieves weather favorites from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/favorites`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Weather Favorites](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
