# Get Talk Note To Self Conversation with Next Cloud OCS

Retrieves talk note-to-self conversation from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/note-to-self`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Note To Self Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#get-note-to-self-conversation)
