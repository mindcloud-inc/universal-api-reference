# Stop Talk Recording with Next Cloud OCS

Stops a talk recording in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/recording/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Stop Talk Recording](https://nextcloud-talk.readthedocs.io/en/stable/recording/)
