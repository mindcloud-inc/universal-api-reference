# Create Global Workflow with Next Cloud OCS

Creates a new global workflow in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/workflowengine/api/v1/workflows/global`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Global Workflow](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
