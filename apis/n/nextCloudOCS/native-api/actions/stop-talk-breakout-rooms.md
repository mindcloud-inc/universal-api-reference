# Stop Talk Breakout Rooms with Next Cloud OCS

Stops talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/rooms`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Stop Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
