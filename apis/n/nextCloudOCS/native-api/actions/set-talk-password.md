# Set Talk Password with Next Cloud OCS

Sets a talk password in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/password`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Password](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-password-for-a-conversation)
