# Delete Webhook with Next Cloud OCS

Deletes a webhook from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/webhook_listeners/api/v1/webhooks/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Webhook](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
