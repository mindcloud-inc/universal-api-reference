# Schedule Text Processing Task with Next Cloud OCS

Schedules a text processing task in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/textprocessing/schedule`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Schedule Text Processing Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
