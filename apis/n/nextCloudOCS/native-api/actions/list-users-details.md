# List Users Details with Next Cloud OCS

Retrieves users details from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/users/details`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Users Details](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
