# List Activity By Filter with Next Cloud OCS

Retrieves activity by filter from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/activity/api/v2/activity/{{filter}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Activity By Filter](https://github.com/nextcloud/activity/blob/master/docs/endpoint-v2.md)
