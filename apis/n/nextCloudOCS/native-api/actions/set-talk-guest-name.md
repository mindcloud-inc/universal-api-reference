# Set Talk Guest Name with Next Cloud OCS

Sets a talk guest name in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/guest/{{token}}/name`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Guest Name](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
