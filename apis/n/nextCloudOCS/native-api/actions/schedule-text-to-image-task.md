# Schedule Text To Image Task with Next Cloud OCS

Schedules text to image task in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/text2image/schedule`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Schedule Text To Image Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
