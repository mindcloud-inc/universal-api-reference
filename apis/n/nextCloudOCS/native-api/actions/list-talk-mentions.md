# List Talk Mentions with Next Cloud OCS

Retrieves talk mentions from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/mentions`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Mentions](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
