# Set Sensitive Declarative Setting Value with Next Cloud OCS

Sets a sensitive declarative setting value in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/settings/api/declarative/value-sensitive`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Sensitive Declarative Setting Value](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
