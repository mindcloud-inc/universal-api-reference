# Disallow Talk Guests with Next Cloud OCS

Disallows talk guests in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/public`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Disallow Talk Guests](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#disallow-guests-in-a-conversation-group-conversation)
