# Check Notifications Exist with Next Cloud OCS

Checks whether notifications exist in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/notifications/exists`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Check Notifications Exist](https://github.com/nextcloud/notifications/blob/master/docs/ocs-endpoint-v2.md)
