# Delete Notification with Next Cloud OCS

Deletes a notification from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/notifications/{{notificationId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Notification](https://github.com/nextcloud/notifications/blob/master/docs/ocs-endpoint-v1.md)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `notificationId` | path | `string` | yes |
