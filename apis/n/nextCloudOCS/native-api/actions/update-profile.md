# Update Profile with Next Cloud OCS

Updates a profile in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/profile/{{targetUserId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Profile](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
