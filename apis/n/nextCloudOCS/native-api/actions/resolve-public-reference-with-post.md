# Resolve Public Reference With Post with Next Cloud OCS

Resolves a public reference in Next Cloud OCS using POST input.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/references/resolvePublic`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Resolve Public Reference With Post](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
