# Favorite Talk Conversation with Next Cloud OCS

Marks a talk conversation as favorite in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/favorite`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Favorite Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#add-conversation-to-favorites)
