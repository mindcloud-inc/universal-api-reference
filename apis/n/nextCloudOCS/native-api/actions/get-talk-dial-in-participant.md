# Get Talk Dial In Participant with Next Cloud OCS

Retrieves talk dial-in participant from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/pin/{{pin}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Dial In Participant](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
