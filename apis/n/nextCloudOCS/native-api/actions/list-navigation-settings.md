# List Navigation Settings with Next Cloud OCS

Retrieves navigation settings from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/core/navigation/settings`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Navigation Settings](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
