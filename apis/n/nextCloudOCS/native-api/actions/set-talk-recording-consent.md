# Set Talk Recording Consent with Next Cloud OCS

Sets a talk recording consent in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/recording-consent`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Recording Consent](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-recording-consent)
