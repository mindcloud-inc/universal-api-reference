# Clear Talk Chat History with Next Cloud OCS

Clears a talk chat history in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Clear Talk Chat History](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
