# List Talk Participants with Next Cloud OCS

Retrieves talk participants from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Participants](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
