# Request Talk Breakout Assistance with Next Cloud OCS

Requests a talk breakout assistance from Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/request-assistance`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Request Talk Breakout Assistance](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
