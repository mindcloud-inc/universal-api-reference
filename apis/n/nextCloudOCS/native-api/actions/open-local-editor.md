# Open Local Editor with Next Cloud OCS

Opens a local editor in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/openlocaleditor`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Open Local Editor](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
