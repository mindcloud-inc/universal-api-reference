# Rename Talk Conversation with Next Cloud OCS

Renames a talk conversation in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Rename Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#rename-a-conversation)
