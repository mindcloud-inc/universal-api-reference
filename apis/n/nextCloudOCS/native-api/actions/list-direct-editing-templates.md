# List Direct Editing Templates with Next Cloud OCS

Retrieves direct editing templates from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files/api/v1/directEditing/templates/{{editorId}}/{{creatorId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Direct Editing Templates](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
