# List Navigation Apps with Next Cloud OCS

Retrieves navigation apps from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/core/navigation/apps`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Navigation Apps](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
