# Get Talk File Integration with Next Cloud OCS

Retrieves talk file integration from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/file/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk File Integration](https://nextcloud-talk.readthedocs.io/en/stable/integration/)
