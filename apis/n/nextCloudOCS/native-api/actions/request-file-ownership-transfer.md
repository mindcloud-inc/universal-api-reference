# Request File Ownership Transfer with Next Cloud OCS

Requests a file ownership transfer from Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/transferownership`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Request File Ownership Transfer](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
