# Set Talk Call Notification Level with Next Cloud OCS

Sets a talk call notification level in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/notify-calls`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Call Notification Level](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-notification-level-for-calls)
