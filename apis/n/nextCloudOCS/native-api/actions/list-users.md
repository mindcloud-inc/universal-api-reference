# List Users with Next Cloud OCS

Retrieves users from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/users`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Users](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html#search-get-users)
