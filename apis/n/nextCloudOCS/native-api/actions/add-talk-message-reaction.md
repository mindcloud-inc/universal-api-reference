# Add Talk Message Reaction with Next Cloud OCS

Adds a talk message reaction in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/reaction/{{token}}/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Add Talk Message Reaction](https://nextcloud-talk.readthedocs.io/en/stable/reaction/)
