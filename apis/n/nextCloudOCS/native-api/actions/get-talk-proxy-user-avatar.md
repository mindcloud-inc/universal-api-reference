# Get Talk Proxy User Avatar with Next Cloud OCS

Retrieves talk proxy user avatar from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/proxy/{{token}}/user-avatar/{{size}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Proxy User Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
