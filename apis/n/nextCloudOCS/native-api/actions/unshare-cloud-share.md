# Unshare Cloud Share with Next Cloud OCS

Unshares a cloud share in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/shares/{{id}}/unshare`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Unshare Cloud Share](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
