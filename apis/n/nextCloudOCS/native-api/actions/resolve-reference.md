# Resolve Reference with Next Cloud OCS

Resolves a reference in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/references/resolve`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Resolve Reference](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
