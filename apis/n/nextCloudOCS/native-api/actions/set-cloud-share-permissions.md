# Set Cloud Share Permissions with Next Cloud OCS

Sets cloud share permissions in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/shares/{{id}}/permissions`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Cloud Share Permissions](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
