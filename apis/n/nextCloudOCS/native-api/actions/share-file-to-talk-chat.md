# Share File To Talk Chat with Next Cloud OCS

Shares a file to talk chat in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/share`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Share File To Talk Chat](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
