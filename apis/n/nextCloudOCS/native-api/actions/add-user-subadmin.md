# Add User Subadmin with Next Cloud OCS

Adds a user subadmin in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}/subadmins`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Add User Subadmin](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
