# Create Admin Notification V3 with Next Cloud OCS

Creates an new admin notification in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v3/admin_notifications/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Admin Notification V3](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
