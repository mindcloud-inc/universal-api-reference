# Cancel Task Processing Task with Next Cloud OCS

Cancels a task processing task in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/taskprocessing/tasks/{{taskId}}/cancel`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Cancel Task Processing Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
