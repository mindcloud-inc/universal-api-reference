# Search Collaboration Collections with Next Cloud OCS

Finds collaboration collections in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/collaboration/resources/collections/search/{{filter}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Search Collaboration Collections](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
