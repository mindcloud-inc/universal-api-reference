# Remove Talk Attendee with Next Cloud OCS

Removes a talk attendee from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/attendees`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Remove Talk Attendee](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
