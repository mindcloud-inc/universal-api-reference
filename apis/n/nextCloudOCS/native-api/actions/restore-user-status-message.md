# Restore User Status Message with Next Cloud OCS

Restores a user status message in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/user_status/revert/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Restore User Status Message](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html)
