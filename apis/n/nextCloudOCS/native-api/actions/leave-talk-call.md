# Leave Talk Call with Next Cloud OCS

Leaves a talk call in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Leave Talk Call](https://nextcloud-talk.readthedocs.io/en/stable/call/)
