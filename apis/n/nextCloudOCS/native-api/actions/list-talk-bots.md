# List Talk Bots with Next Cloud OCS

Retrieves talk bots from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Bots](https://nextcloud-talk.readthedocs.io/en/stable/bot-management/)
