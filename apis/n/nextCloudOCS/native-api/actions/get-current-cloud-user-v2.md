# Get Current Cloud User V2 with Next Cloud OCS

Retrieves the current cloud user from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/user`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Current Cloud User V2](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
