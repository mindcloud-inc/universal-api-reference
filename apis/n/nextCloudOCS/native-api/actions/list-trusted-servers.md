# List Trusted Servers with Next Cloud OCS

Retrieves trusted servers from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/federation/trusted-servers`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Trusted Servers](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
