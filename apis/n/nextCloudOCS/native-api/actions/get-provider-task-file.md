# Get Provider Task File with Next Cloud OCS

Retrieves provider task file from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_provider/{{taskId}}/file/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Provider Task File](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
