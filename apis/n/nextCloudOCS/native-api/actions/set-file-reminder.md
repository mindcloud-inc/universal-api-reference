# Set File Reminder with Next Cloud OCS

Sets a file reminder in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/files_reminders/api/v{{version}}/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set File Reminder](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
