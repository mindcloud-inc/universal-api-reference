# List Activity Filters with Next Cloud OCS

Retrieves activity filters from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/activity/api/v2/activity/filters`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Activity Filters](https://github.com/nextcloud/activity/blob/master/docs/endpoint-v2.md)
