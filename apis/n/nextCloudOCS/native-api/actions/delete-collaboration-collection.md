# Delete Collaboration Collection with Next Cloud OCS

Deletes a collaboration collection from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/collaboration/resources/collections/{{collectionId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Collaboration Collection](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
