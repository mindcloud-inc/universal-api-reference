# Get LDAP Config with Next Cloud OCS

Retrieves LDAP config from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/user_ldap/api/v1/config/{{configID}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get LDAP Config](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
