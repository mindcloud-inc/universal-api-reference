# Update Cloud User V2 with Next Cloud OCS

Updates a cloud user in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/cloud/users/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Cloud User V2](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
