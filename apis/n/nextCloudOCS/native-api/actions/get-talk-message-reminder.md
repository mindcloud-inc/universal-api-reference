# Get Talk Message Reminder with Next Cloud OCS

Retrieves talk message reminder from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}/reminder`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Message Reminder](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
