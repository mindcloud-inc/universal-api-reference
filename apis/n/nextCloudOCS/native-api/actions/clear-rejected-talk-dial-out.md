# Clear Rejected Talk Dial Out with Next Cloud OCS

Clears a rejected talk dial-out in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/rejected-dialout`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Clear Rejected Talk Dial Out](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
