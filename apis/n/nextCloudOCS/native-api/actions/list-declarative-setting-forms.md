# List Declarative Setting Forms with Next Cloud OCS

Retrieves declarative setting forms from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/settings/api/declarative/forms`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Declarative Setting Forms](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
