# Verify Talk Dial In with Next Cloud OCS

Verifies talk dial-in details in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/verify-dialin`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Verify Talk Dial In](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
