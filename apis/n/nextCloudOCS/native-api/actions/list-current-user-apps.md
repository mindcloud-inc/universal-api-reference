# List Current User Apps with Next Cloud OCS

Retrieves the current user apps from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/user/apps`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Current User Apps](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
