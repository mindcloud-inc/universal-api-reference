# Get All Recommendations with Next Cloud OCS

Retrieves all recommendations from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/recommendations/api/v1/recommendations/always`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get All Recommendations](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-recommendations-api.html#fetch-user-setting-and-recommendations)
