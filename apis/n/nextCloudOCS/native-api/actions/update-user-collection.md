# Update User Collection with Next Cloud OCS

Updates a user collection in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/cloud/users/{{userId}}/{{collectionName}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update User Collection](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
