# Delete Talk Conversation Avatar with Next Cloud OCS

Deletes a talk conversation avatar from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/avatar`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Conversation Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
