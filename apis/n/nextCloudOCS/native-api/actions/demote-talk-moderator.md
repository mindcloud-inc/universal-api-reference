# Demote Talk Moderator with Next Cloud OCS

Demotes a talk moderator in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/moderators`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Demote Talk Moderator](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
