# Clear LDAP Wizard Mappings with Next Cloud OCS

Clears LDAP wizard mappings in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/user_ldap/api/v1/wizard/clearMappings`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Clear LDAP Wizard Mappings](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
