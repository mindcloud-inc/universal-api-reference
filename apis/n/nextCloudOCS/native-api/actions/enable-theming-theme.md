# Enable Theming Theme with Next Cloud OCS

Enables a theming theme in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/theming/api/v1/theme/{{themeId}}/enable`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Enable Theming Theme](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
