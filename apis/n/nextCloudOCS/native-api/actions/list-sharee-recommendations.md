# List Sharee Recommendations with Next Cloud OCS

Retrieves sharee recommendations from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/apps/files_sharing/api/v1/sharees_recommended`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Sharee Recommendations](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-sharee-api.html#sharee-recommendations)
