# Update Dashboard Layout with Next Cloud OCS

Updates a dashboard layout in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v3/layout`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Dashboard Layout](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
