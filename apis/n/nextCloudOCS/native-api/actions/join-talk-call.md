# Join Talk Call with Next Cloud OCS

Joins a talk call in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Join Talk Call](https://nextcloud-talk.readthedocs.io/en/stable/call/)
