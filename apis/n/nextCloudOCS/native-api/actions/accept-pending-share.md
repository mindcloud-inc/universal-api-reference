# Accept Pending Share with Next Cloud OCS

Accepts a pending share in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files_sharing/api/v1/shares/pending/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Accept Pending Share](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-share-api.html)
