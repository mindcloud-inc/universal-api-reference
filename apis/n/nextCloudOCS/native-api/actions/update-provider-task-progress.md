# Update Provider Task Progress with Next Cloud OCS

Updates a provider task progress in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_provider/{{taskId}}/progress`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Provider Task Progress](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
