# List Disabled Users with Next Cloud OCS

Retrieves disabled users from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/users/disabled`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Disabled Users](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
