# Delete Trusted Server with Next Cloud OCS

Deletes a trusted server from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/federation/trusted-servers/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Trusted Server](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
