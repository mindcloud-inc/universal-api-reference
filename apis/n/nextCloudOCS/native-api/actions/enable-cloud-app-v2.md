# Enable Cloud App V2 with Next Cloud OCS

Enables a cloud app in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/apps/{{app}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Enable Cloud App V2](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_apps.html)
