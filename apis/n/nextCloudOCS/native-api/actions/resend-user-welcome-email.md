# Resend User Welcome Email with Next Cloud OCS

Resends a user welcome email in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}/welcome`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Resend User Welcome Email](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
