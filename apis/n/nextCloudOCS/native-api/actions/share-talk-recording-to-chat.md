# Share Talk Recording To Chat with Next Cloud OCS

Shares talk recording to chat in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/recording/{{token}}/share-chat`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Share Talk Recording To Chat](https://nextcloud-talk.readthedocs.io/en/stable/recording/)
