# Update Webhook with Next Cloud OCS

Updates a webhook in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/webhook_listeners/api/v1/webhooks/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Webhook](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
