# Ring Talk Call Attendee with Next Cloud OCS

Rings a talk call attendee in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}/ring/{{attendeeId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Ring Talk Call Attendee](https://nextcloud-talk.readthedocs.io/en/stable/call/)
