# Set Talk Conversation Emoji Avatar with Next Cloud OCS

Sets a talk conversation emoji avatar in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/avatar/emoji`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Conversation Emoji Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
