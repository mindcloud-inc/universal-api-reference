# Add Resource To Collaboration Collection with Next Cloud OCS

Adds resource to collaboration collection in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/collaboration/resources/collections/{{collectionId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Add Resource To Collaboration Collection](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
