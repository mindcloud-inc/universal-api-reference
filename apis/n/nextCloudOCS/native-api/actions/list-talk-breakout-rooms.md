# List Talk Breakout Rooms with Next Cloud OCS

Retrieves talk breakout rooms from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/breakout-rooms`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#get-breakout-rooms)
