# Update Weather Mode with Next Cloud OCS

Updates a weather mode in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/mode`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Weather Mode](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
