# Delete App Password with Next Cloud OCS

Deletes an app password from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/core/apppassword`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete App Password](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
