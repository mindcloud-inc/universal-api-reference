# Get Recommendations with Next Cloud OCS

Retrieves recommendations from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/recommendations/api/v1/recommendations`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Recommendations](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-recommendations-api.html#fetch-user-controlled-recommendations)
