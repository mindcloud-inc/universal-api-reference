# Resend Talk Invitations with Next Cloud OCS

Resends talk invitations in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants/resend-invitations`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Resend Talk Invitations](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
