# Authenticate Talk Public Share with Next Cloud OCS

Authenticates a talk public share in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/publicshareauth`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Authenticate Talk Public Share](https://nextcloud-talk.readthedocs.io/en/stable/integration/)
