# Set Declarative Setting Value with Next Cloud OCS

Sets a declarative setting value in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/settings/api/declarative/value`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Declarative Setting Value](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
