# Update Talk User Settings with Next Cloud OCS

Updates a talk user settings in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/settings/user`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Talk User Settings](https://nextcloud-talk.readthedocs.io/en/stable/settings/)
