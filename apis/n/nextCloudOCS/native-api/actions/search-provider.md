# Search Provider with Next Cloud OCS

Finds provider in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/search/providers/{{providerId}}/search`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Search Provider](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
