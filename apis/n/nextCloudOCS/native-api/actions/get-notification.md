# Get Notification with Next Cloud OCS

Retrieves notification from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/notifications/{{notificationId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Notification](https://github.com/nextcloud/notifications/blob/master/docs/ocs-endpoint-v2.md)
