# Create Cloud Group V2 with Next Cloud OCS

Creates a new cloud group in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/cloud/groups`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Cloud Group V2](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html)
