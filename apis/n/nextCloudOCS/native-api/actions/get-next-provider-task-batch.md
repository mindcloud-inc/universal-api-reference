# Get Next Provider Task Batch with Next Cloud OCS

Retrieves next provider task batch from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_provider/next_batch`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Next Provider Task Batch](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
