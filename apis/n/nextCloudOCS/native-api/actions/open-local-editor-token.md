# Open Local Editor Token with Next Cloud OCS

Opens a local editor token in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/openlocaleditor/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Open Local Editor Token](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
