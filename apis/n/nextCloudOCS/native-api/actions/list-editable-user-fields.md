# List Editable User Fields with Next Cloud OCS

Retrieves editable user fields from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/user/fields`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Editable User Fields](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html#list-of-editable-data-fields)
