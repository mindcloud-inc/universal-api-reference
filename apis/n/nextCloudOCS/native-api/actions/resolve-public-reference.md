# Resolve Public Reference with Next Cloud OCS

Resolves a public reference in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/references/resolvePublic`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Resolve Public Reference](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
