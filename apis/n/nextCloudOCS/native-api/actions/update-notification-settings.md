# Update Notification Settings with Next Cloud OCS

Updates a notification settings in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/settings`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Notification Settings](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
