# Unfavorite Talk Conversation with Next Cloud OCS

Removes a talk conversation from favorites in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/favorite`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Unfavorite Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#remove-conversation-from-favorites)
