# Get Dark Talk Conversation Avatar with Next Cloud OCS

Retrieves the dark talk conversation avatar from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/avatar/dark`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Dark Talk Conversation Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
