# Start Talk Dial Out with Next Cloud OCS

Starts a talk dial-out in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}/dialout/{{attendeeId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Start Talk Dial Out](https://nextcloud-talk.readthedocs.io/en/stable/call/)
