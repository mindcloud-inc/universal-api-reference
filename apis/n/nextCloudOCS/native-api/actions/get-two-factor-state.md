# Get Two Factor State with Next Cloud OCS

Retrieves two factor state from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/twofactor/state`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Two Factor State](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
