# Get Capabilities with Next Cloud OCS

Retrieves capabilities from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/capabilities`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Capabilities](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#capabilities-api)
