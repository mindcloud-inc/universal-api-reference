# Get Task Processing Task File with Next Cloud OCS

Retrieves task processing task file from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/tasks/{{taskId}}/file/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Task Processing Task File](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
