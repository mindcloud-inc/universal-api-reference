# Delete Talk Conversation with Next Cloud OCS

Deletes a talk conversation from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#delete-a-conversation)
