# Check Text To Image Availability with Next Cloud OCS

Checks text-to-image availability in Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/text2image/is_available`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Check Text To Image Availability](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
