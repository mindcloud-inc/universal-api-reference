# Extract References with Next Cloud OCS

Extracts references in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/references/extract`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Extract References](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
