# Activate Web Push Device with Next Cloud OCS

Activates a web push device in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/webpush/activate`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Activate Web Push Device](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
