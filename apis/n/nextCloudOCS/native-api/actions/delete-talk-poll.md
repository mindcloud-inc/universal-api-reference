# Delete Talk Poll with Next Cloud OCS

Deletes a talk poll from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/poll/{{token}}/{{pollId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Poll](https://nextcloud-talk.readthedocs.io/en/stable/poll/)
