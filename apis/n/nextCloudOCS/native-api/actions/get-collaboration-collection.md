# Get Collaboration Collection with Next Cloud OCS

Retrieves collaboration collection from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/collaboration/resources/collections/{{collectionId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Collaboration Collection](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
