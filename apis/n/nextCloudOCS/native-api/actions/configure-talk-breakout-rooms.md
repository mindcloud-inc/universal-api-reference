# Configure Talk Breakout Rooms with Next Cloud OCS

Configures talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Configure Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
