# Get Direct Editing Capabilities with Next Cloud OCS

Retrieves direct editing capabilities from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files/api/v1/directEditing`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Direct Editing Capabilities](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#capabilities-api)
