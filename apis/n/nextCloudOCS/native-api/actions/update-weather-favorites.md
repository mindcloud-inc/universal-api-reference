# Update Weather Favorites with Next Cloud OCS

Updates weather favorites in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/favorites`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Weather Favorites](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
