# Get Current User with Next Cloud OCS

Retrieves the current user from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/user`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Current User](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#user-metadata)
