# Restore Deleted Share with Next Cloud OCS

Restores a deleted share in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files_sharing/api/v1/deletedshares/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Restore Deleted Share](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-share-api.html)
