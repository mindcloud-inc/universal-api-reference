# List App Config Apps with Next Cloud OCS

Retrieves app config apps from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/provisioning_api/api/v1/config/apps`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List App Config Apps](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
