# Get User Editable Fields with Next Cloud OCS

Retrieves user editable fields from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/user/fields/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get User Editable Fields](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
