# List Dashboard Widgets with Next Cloud OCS

Retrieves dashboard widgets from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v1/widgets`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Dashboard Widgets](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
