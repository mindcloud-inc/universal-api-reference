# Update Group with Next Cloud OCS

Updates a group in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/cloud/groups/{{groupId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Group](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html)
