# Set Talk Conversation Description with Next Cloud OCS

Sets a talk conversation description in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/description`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Conversation Description](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-description-for-a-conversation)
