# Get Templates Path with Next Cloud OCS

Retrieves templates path from Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/templates/path`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Templates Path](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
