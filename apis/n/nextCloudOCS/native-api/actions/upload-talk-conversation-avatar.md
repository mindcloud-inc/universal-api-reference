# Upload Talk Conversation Avatar with Next Cloud OCS

Uploads a talk conversation avatar to Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/avatar`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Upload Talk Conversation Avatar](https://nextcloud-talk.readthedocs.io/en/stable/avatar/)
