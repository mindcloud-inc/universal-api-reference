# List Search Providers with Next Cloud OCS

Retrieves search providers from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/search/providers`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Search Providers](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
