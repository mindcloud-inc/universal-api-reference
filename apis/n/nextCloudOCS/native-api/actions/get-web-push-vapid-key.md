# Get Web Push Vapid Key with Next Cloud OCS

Retrieves web push vapid key from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/webpush/vapid`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Web Push Vapid Key](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
