# Mark Talk Chat Unread with Next Cloud OCS

Marks talk chat as unread in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/read`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Mark Talk Chat Unread](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
