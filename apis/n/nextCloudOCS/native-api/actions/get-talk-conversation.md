# Get Talk Conversation with Next Cloud OCS

Retrieves talk conversation from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#get-single-conversation-also-for-guests)
