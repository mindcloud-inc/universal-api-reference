# Disable Two Factor Provider with Next Cloud OCS

Disables a two factor provider in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/twofactor/disable`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Disable Two Factor Provider](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
