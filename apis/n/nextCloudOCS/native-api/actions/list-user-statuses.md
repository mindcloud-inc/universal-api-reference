# List User Statuses with Next Cloud OCS

Retrieves user statuses from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/statuses`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List User Statuses](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html#fetch-a-list-of-all-set-user-statuses)
