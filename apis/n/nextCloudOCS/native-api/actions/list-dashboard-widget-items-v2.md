# List Dashboard Widget Items V2 with Next Cloud OCS

Retrieves dashboard widget items from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v2/widget-items`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Dashboard Widget Items V2](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
