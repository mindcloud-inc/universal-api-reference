# Get Talk Conversation Capabilities with Next Cloud OCS

Retrieves talk conversation capabilities from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/capabilities`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Conversation Capabilities](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#get-conversation-capabilities)
