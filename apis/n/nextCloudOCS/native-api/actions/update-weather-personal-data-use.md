# Update Weather Personal Data Use with Next Cloud OCS

Updates a weather personal data use in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/use-personal`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Weather Personal Data Use](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
