# Delete Task Processing Task with Next Cloud OCS

Deletes a task processing task from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/taskprocessing/task/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Task Processing Task](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
