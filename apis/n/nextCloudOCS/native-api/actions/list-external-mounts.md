# List External Mounts with Next Cloud OCS

Retrieves external mounts from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files_external/api/v1/mounts`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List External Mounts](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
