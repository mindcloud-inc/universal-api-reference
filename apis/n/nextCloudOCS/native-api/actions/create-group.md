# Create Group with Next Cloud OCS

Creates a new group in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v1.php/cloud/groups`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Group](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html#create-a-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupid` | body | `string` | yes | New group ID. |
