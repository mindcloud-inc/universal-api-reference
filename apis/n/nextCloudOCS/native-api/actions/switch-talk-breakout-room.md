# Switch Talk Breakout Room with Next Cloud OCS

Switches talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/switch`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Switch Talk Breakout Room](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
