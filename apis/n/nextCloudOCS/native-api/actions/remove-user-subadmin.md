# Remove User Subadmin with Next Cloud OCS

Removes a user subadmin from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}/subadmins`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Remove User Subadmin](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
