# Send Talk Chat Message with Next Cloud OCS

Sends a talk chat message in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Send Talk Chat Message](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
