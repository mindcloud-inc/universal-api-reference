# List Group Subadmins with Next Cloud OCS

Retrieves group subadmins from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/groups/{{groupId}}/subadmins`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Group Subadmins](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html)
