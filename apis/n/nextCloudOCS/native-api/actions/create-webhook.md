# Create Webhook with Next Cloud OCS

Creates a new webhook in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/webhook_listeners/api/v1/webhooks`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Webhook](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
