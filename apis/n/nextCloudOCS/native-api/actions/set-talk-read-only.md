# Set Talk Read Only with Next Cloud OCS

Sets talk read-only mode in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/read-only`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Read Only](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-read-only-for-a-conversation)
