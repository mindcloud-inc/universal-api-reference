# Get Weather Location with Next Cloud OCS

Retrieves weather location from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/location`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Weather Location](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#capabilities-api)
