# List Team Resources with Next Cloud OCS

Retrieves team resources from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/teams/{{teamId}}/resources`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Team Resources](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
