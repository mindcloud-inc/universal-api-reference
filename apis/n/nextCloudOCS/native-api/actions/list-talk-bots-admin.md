# List Talk Bots Admin with Next Cloud OCS

Retrieves talk bots admin from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/admin`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Bots Admin](https://nextcloud-talk.readthedocs.io/en/stable/bot-management/)
