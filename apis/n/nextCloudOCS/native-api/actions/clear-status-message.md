# Clear Status Message with Next Cloud OCS

Clears a status message in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/user_status/message`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Clear Status Message](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html#clear-message)
