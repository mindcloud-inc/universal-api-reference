# Run LDAP Wizard Action with Next Cloud OCS

Runs a LDAP wizard action in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/user_ldap/api/v1/wizard/{{configID}}/{{wizardAction}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Run LDAP Wizard Action](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
