# Enable Talk Bot with Next Cloud OCS

Enables a talk bot in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/{{token}}/{{botId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Enable Talk Bot](https://nextcloud-talk.readthedocs.io/en/stable/bot-management/)
