# Create File From Template with Next Cloud OCS

Creates new file from template in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/templates/create`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create File From Template](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
