# Get Talk Chat Message Context with Next Cloud OCS

Retrieves talk chat message context from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}/context`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Chat Message Context](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
