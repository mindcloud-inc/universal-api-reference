# List Groups with Next Cloud OCS

Retrieves groups from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/groups`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Groups](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html#search-get-groups)
