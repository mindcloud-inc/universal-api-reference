# Edit Talk Chat Message with Next Cloud OCS

Edits a talk chat message in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Edit Talk Chat Message](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
