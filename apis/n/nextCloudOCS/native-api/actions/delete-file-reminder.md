# Delete File Reminder with Next Cloud OCS

Deletes a file reminder from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/files_reminders/api/v{{version}}/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete File Reminder](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
