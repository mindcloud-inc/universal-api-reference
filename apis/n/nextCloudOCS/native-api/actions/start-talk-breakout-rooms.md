# Start Talk Breakout Rooms with Next Cloud OCS

Starts talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/rooms`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Start Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
