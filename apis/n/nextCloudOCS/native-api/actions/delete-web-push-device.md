# Delete Web Push Device with Next Cloud OCS

Deletes a web push device from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/webpush`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Web Push Device](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
