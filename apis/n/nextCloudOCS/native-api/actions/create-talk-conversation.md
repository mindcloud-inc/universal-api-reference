# Create Talk Conversation with Next Cloud OCS

Creates a new talk conversation in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#creating-a-new-conversation)
