# Get Hovercard with Next Cloud OCS

Retrieves hovercard from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/hovercard/v1/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Hovercard](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
