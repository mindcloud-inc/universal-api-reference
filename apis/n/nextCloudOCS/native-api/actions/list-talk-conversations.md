# List Talk Conversations with Next Cloud OCS

Retrieves talk conversations from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Conversations](https://nextcloud-talk.readthedocs.io/en/stable/conversation/)
