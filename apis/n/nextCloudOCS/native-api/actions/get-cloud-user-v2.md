# Get Cloud User V2 with Next Cloud OCS

Retrieves cloud user from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/users/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Cloud User V2](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
