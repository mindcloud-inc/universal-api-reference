# Delete Talk Message Reminder with Next Cloud OCS

Deletes a talk message reminder from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}/reminder`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Message Reminder](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
