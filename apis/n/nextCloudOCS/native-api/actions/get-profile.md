# Get Profile with Next Cloud OCS

Retrieves profile from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/profile/{{targetUserId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Profile](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
