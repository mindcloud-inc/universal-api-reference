# List Consumer Task Types with Next Cloud OCS

Retrieves consumer task types from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_consumer/tasktypes`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Consumer Task Types](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
