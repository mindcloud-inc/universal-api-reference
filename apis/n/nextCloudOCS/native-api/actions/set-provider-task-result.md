# Set Provider Task Result with Next Cloud OCS

Sets a provider task result in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_provider/{{taskId}}/result`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Provider Task Result](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
