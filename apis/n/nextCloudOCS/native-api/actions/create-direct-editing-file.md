# Create Direct Editing File with Next Cloud OCS

Creates a new direct editing file in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/files/api/v1/directEditing/create`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Direct Editing File](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-api-overview.html#capabilities-api)
