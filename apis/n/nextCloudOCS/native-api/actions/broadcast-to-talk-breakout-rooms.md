# Broadcast To Talk Breakout Rooms with Next Cloud OCS

Broadcasts to talk breakout rooms in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/breakout-rooms/{{token}}/broadcast`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Broadcast To Talk Breakout Rooms](https://nextcloud-talk.readthedocs.io/en/stable/breakout-rooms/)
