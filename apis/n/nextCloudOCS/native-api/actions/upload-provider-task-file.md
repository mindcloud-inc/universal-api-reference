# Upload Provider Task File with Next Cloud OCS

Uploads a provider task file to Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/taskprocessing/tasks_provider/{{taskId}}/file`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Upload Provider Task File](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
