# Update Collaboration Collection with Next Cloud OCS

Updates a collaboration collection in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/collaboration/resources/collections/{{collectionId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Collaboration Collection](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
