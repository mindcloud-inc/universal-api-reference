# Create Richdocuments Share Link with Next Cloud OCS

Creates a new richdocuments share link in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/richdocuments/api/v1/share`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Richdocuments Share Link](https://collabora-online-for-nextcloud.readthedocs.io/en/latest/mobile_editor/)
