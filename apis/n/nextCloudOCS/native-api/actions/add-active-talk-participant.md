# Add Active Talk Participant with Next Cloud OCS

Adds an active talk participant in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants/active`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Add Active Talk Participant](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
