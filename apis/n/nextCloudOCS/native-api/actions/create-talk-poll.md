# Create Talk Poll with Next Cloud OCS

Creates a new talk poll in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/poll/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Talk Poll](https://nextcloud-talk.readthedocs.io/en/stable/poll/)
