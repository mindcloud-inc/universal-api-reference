# Get Dashboard Layout with Next Cloud OCS

Retrieves dashboard layout from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/dashboard/api/v3/layout`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Dashboard Layout](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
