# Get Talk Public Share Integration with Next Cloud OCS

Retrieves talk public share integration from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/publicshare/{{shareToken}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Talk Public Share Integration](https://nextcloud-talk.readthedocs.io/en/stable/integration/)
