# Get File Template Fields with Next Cloud OCS

Retrieves file template fields from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/files/api/v1/templates/fields/{{fileId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get File Template Fields](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
