# Delete All Notifications with Next Cloud OCS

Deletes all notifications from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/notifications`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete All Notifications](https://github.com/nextcloud/notifications/blob/master/docs/ocs-endpoint-v2.md)
