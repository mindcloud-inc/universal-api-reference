# Get Federation Shared Secret with Next Cloud OCS

Retrieves federation shared secret from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/federation/api/v1/shared-secret`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Federation Shared Secret](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
