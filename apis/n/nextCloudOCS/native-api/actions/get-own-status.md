# Get Own Status with Next Cloud OCS

Retrieves your status from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/user_status/api/v1/user_status`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Own Status](https://docs.nextcloud.com/server/latest/developer_manual/client_apis/OCS/ocs-status-api.html#fetch-your-own-status)
