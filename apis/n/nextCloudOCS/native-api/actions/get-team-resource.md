# Get Team Resource with Next Cloud OCS

Retrieves team resource from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/teams/resources/{{providerId}}/{{resourceId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Team Resource](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
