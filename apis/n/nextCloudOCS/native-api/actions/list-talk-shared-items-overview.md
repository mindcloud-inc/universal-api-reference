# List Talk Shared Items Overview with Next Cloud OCS

Retrieves talk shared items overview from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/share/overview`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Shared Items Overview](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
