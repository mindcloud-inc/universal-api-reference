# Set Talk Message Expiration with Next Cloud OCS

Sets a talk message expiration in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/message-expiration`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set Talk Message Expiration](https://nextcloud-talk.readthedocs.io/en/stable/conversation/#set-message-expiration)
