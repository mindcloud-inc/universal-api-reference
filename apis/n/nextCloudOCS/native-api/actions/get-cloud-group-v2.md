# Get Cloud Group V2 with Next Cloud OCS

Retrieves cloud group from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/cloud/groups/{{groupId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Cloud Group V2](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_groups.html)
