# Register Web Push Device with Next Cloud OCS

Registers a web push device in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/webpush`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Register Web Push Device](https://github.com/nextcloud/notifications/blob/master/openapi-full.json)
