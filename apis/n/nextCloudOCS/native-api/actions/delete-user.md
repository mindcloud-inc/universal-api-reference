# Delete User with Next Cloud OCS

Deletes a user from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete User](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
