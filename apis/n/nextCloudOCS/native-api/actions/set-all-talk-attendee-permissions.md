# Set All Talk Attendee Permissions with Next Cloud OCS

Sets all talk attendee permissions in Next Cloud OCS.

## Endpoint

- **Method:** `PUT`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/attendees/permissions/all`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Set All Talk Attendee Permissions](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
