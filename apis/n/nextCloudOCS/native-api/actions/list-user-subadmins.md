# List User Subadmins with Next Cloud OCS

Retrieves user subadmins from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v1.php/cloud/users/{{userId}}/subadmins`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List User Subadmins](https://docs.nextcloud.com/server/latest/admin_manual/configuration_user/instruction_set_for_users.html)
