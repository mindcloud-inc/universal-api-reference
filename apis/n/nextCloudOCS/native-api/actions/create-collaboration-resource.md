# Create Collaboration Resource with Next Cloud OCS

Creates a new collaboration resource in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/collaboration/resources/{{baseResourceType}}/{{baseResourceId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Collaboration Resource](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
