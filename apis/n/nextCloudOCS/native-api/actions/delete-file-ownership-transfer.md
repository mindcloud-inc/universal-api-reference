# Delete File Ownership Transfer with Next Cloud OCS

Deletes a file ownership transfer from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/files/api/v1/transferownership/{{id}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete File Ownership Transfer](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
