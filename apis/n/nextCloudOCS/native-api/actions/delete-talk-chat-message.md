# Delete Talk Chat Message with Next Cloud OCS

Deletes a talk chat message from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete Talk Chat Message](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
