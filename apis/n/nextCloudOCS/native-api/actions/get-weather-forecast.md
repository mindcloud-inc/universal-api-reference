# Get Weather Forecast with Next Cloud OCS

Retrieves weather forecast from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/weather_status/api/v1/forecast`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Weather Forecast](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
