# Create Talk Message Reminder with Next Cloud OCS

Creates a new talk message reminder in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/{{messageId}}/reminder`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Create Talk Message Reminder](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
