# Get Update App List with Next Cloud OCS

Retrieves update app list from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/updatenotification/api/{{apiVersion}}/applist/{{newVersion}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Update App List](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
