# Mark Talk Chat Read with Next Cloud OCS

Marks talk chat as read in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/chat/{{token}}/read`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Mark Talk Chat Read](https://nextcloud-talk.readthedocs.io/en/stable/chat/)
