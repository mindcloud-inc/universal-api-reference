# List Task Processing Tasks with Next Cloud OCS

Retrieves task processing tasks from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/taskprocessing/tasks`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Task Processing Tasks](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
