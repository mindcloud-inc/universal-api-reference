# List Translation Languages with Next Cloud OCS

Retrieves translation languages from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/translation/languages`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Translation Languages](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
