# Register Talk Recording Backend with Next Cloud OCS

Registers a talk recording backend in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/recording/backend`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Register Talk Recording Backend](https://nextcloud-talk.readthedocs.io/en/stable/recording/)
