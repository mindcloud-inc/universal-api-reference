# Send Talk Bot Message with Next Cloud OCS

Sends a talk bot message in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/bot/{{token}}/message`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Send Talk Bot Message](https://nextcloud-talk.readthedocs.io/en/stable/bots/)
