# List Notifications with Next Cloud OCS

Retrieves notifications from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/notifications/api/v2/notifications`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Notifications](https://github.com/nextcloud/notifications/blob/master/docs/ocs-endpoint-v1.md)
