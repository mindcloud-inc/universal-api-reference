# Translate Text with Next Cloud OCS

Translates a text in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/translation/translate`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Translate Text](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
