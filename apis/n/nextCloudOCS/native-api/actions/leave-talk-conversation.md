# Leave Talk Conversation with Next Cloud OCS

Leaves a talk conversation in Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/room/{{token}}/participants/self`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Leave Talk Conversation](https://nextcloud-talk.readthedocs.io/en/stable/participant/)
