# List Talk Call Participants with Next Cloud OCS

Retrieves talk call participants from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/call/{{token}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [List Talk Call Participants](https://nextcloud-talk.readthedocs.io/en/stable/call/)
