# Delete App Webhooks with Next Cloud OCS

Deletes app webhooks from Next Cloud OCS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ocs/v2.php/apps/webhook_listeners/api/v1/webhooks/byappid/{{appid}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Delete App Webhooks](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
