# Get Text To Image Result Image with Next Cloud OCS

Retrieves text to image result image from Next Cloud OCS.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocs/v2.php/text2image/task/{{id}}/image/{{index}}`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Get Text To Image Result Image](https://docs.nextcloud.com/server/latest/developer_manual/_static/openapi.html)
