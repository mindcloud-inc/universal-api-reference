# Update Talk Sip Settings with Next Cloud OCS

Updates a talk sip settings in Next Cloud OCS.

## Endpoint

- **Method:** `POST`
- **Path:** `/ocs/v2.php/apps/spreed/api/v4/settings/sip`
- **Base URL:** `https://demo2.nextcloud.com`
- **Official documentation:** [Update Talk Sip Settings](https://nextcloud-talk.readthedocs.io/en/stable/settings/)
