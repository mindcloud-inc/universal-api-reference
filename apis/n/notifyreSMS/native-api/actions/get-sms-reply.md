# Get SMS Reply with Notifyre SMS

Retrieves an SMS reply from Notifyre.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/received/:replyId`
- **Base URL:** `https://api.notifyre.com/20220711`
- **Official documentation:** [Get SMS Reply](https://docs.notifyre.com/api/sms-received)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `replyId` | path | `string` | yes | Reply identifier. |
