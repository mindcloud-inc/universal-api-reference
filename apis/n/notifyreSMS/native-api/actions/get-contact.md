# Get Contact with Notifyre SMS

Retrieves a contact from Notifyre address book.

## Endpoint

- **Method:** `GET`
- **Path:** `/addressbook/contacts/:contactId`
- **Base URL:** `https://api.notifyre.com/20220711`
- **Official documentation:** [Get Contact](https://docs.notifyre.com/api/address-book-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | Contact identifier. |
