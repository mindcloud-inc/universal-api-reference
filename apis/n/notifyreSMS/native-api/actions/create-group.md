# Create Group with Notifyre SMS

Creates a new group in Notifyre.

## Endpoint

- **Method:** `POST`
- **Path:** `/addressbook/groups`
- **Base URL:** `https://api.notifyre.com/20220711`
- **Official documentation:** [Create Group](https://docs.notifyre.com/api/address-book-group-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Group name. |
