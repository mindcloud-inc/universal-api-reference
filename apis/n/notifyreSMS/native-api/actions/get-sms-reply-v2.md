# Get SMS Reply V2 with Notifyre SMS

Retrieves an SMS reply from Notifyre with V2 fields.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms/received/:replyId/v2`
- **Base URL:** `https://api.notifyre.com/20220711`
- **Official documentation:** [Get SMS Reply V2](https://docs.notifyre.com/api/introduction)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `replyId` | path | `string` | yes | Reply identifier. |
