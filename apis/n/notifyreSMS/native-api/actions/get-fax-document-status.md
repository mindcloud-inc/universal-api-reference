# Get Fax Document Status with Notifyre SMS

Retrieves fax document status from Notifyre.

## Endpoint

- **Method:** `GET`
- **Path:** `/fax/send/conversion/:fileName`
- **Base URL:** `https://api.notifyre.com/20220711`
- **Official documentation:** [Get Fax Document Status](https://docs.notifyre.com/api/fax-document-status-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileName` | path | `string` | yes | Converted document file name. |
