# List SIGMETs And AIRMETs with National Weather Service

Retrieves SIGMETs and AIRMETs from National Weather Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/aviation/sigmets`
- **Base URL:** `https://api.weather.gov`
- **Official documentation:** [List SIGMETs And AIRMETs](https://api.weather.gov/openapi.json#/paths/~1aviation~1sigmets/get)
