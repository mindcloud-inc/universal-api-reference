# Query Alerts with National Weather Service

Retrieves alerts from National Weather Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts`
- **Base URL:** `https://api.weather.gov`
- **Official documentation:** [Query Alerts](https://api.weather.gov/openapi.json#/paths/~1alerts/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
