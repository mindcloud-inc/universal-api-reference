# Count Active Alerts with National Weather Service

Retrieves active alert counts from National Weather Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/active/count`
- **Base URL:** `https://api.weather.gov`
- **Official documentation:** [Count Active Alerts](https://api.weather.gov/openapi.json#/paths/~1alerts~1active~1count/get)
