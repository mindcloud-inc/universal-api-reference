# Extract PDF Structured Text with Nutrient - Extract from PDF

Extracts structured text from a PDF with Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/build`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Extract PDF Structured Text](https://www.nutrient.io/api/extract-text-from-pdf-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | body | `file` | yes | PDF file to extract structured text from. |
