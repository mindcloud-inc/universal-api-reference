# Extract PDF Tables as JSON with Nutrient - Extract from PDF

Extracts tables from a PDF as JSON with Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/build`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Extract PDF Tables as JSON](https://www.nutrient.io/api/pdf-to-json-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | body | `file` | yes | PDF file to extract tables from. |
