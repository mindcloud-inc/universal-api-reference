# Convert PDF to Markdown with Nutrient - Extract from PDF

Converts a PDF to Markdown with Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/build`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Convert PDF to Markdown](https://www.nutrient.io/api/pdf-to-md-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | body | `file` | yes | PDF file to convert to Markdown. |
