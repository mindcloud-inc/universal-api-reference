# Get Collection Details with Needle

Retrieves details for a collection from Needle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/collections/:collectionId`
- **Base URL:** `https://needle.app`
- **Official documentation:** [Get Collection Details](https://docs.needle.app/docs/api-reference/get-collection/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | ID of the collection to retrieve |
