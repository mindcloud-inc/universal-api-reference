# Get Collection Stats with Needle

Retrieves statistics for a collection from Needle.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/collections/:collectionId/stats`
- **Base URL:** `https://needle.app`
- **Official documentation:** [Get Collection Stats](https://docs.needle.app/docs/api-reference/get-collection-stats/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | ID of the collection to retrieve statistics for |
