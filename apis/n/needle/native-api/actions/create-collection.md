# Create Collection with Needle

Creates a new collection in Needle.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/collections`
- **Base URL:** `https://needle.app`
- **Official documentation:** [Create Collection](https://docs.needle.app/docs/api-reference/create-collection/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the collection to create |
