# Delete Booking Form Field with Novacal

Deletes an existing booking form field from Novacal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/event-types/:eventType/booking-forms/:field`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [Delete Booking Form Field](https://docs.novacal.io/api-reference/v1/booking-forms/delete)
