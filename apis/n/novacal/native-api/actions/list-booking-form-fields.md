# List Booking Form Fields with Novacal

Retrieves booking form fields from Novacal.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event-types/:eventType/booking-forms`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [List Booking Form Fields](https://docs.novacal.io/api-reference/v1/booking-forms/get)
