# Update Booking Form Field Order with Novacal

Updates booking form field order in Novacal.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/event-types/:eventType/booking-forms/update-order`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [Update Booking Form Field Order](https://docs.novacal.io/api-reference/v1/booking-forms/update-order)
