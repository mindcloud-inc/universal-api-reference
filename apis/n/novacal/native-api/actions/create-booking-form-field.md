# Create Booking Form Field with Novacal

Creates a new booking form field in Novacal.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/event-types/:eventType/booking-forms`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [Create Booking Form Field](https://docs.novacal.io/api-reference/v1/booking-forms/create)
