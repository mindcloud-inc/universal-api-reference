# Delete Event Type with Novacal

Deletes an existing event type from Novacal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/event-types/:id`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [Delete Event Type](https://docs.novacal.io/api-reference/v1/event-types/delete)
