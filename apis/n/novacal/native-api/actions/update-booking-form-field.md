# Update Booking Form Field with Novacal

Updates an existing booking form field in Novacal.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/event-types/:eventType/booking-forms/:field`
- **Base URL:** `https://api.novacal.io`
- **Official documentation:** [Update Booking Form Field](https://docs.novacal.io/api-reference/v1/booking-forms/update)
