# Subscribe Multiple Topics SSE Stream with ntfy

Subscribes to multiple ntfy topics as an SSE stream.

## Endpoint

- **Method:** `GET`
- **Path:** `/:topics/sse`
- **Base URL:** `https://ntfy.sh`
- **Official documentation:** [Subscribe Multiple Topics SSE Stream](https://docs.ntfy.sh/subscribe/api/#subscribe-to-multiple-topics)
