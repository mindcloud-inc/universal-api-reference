# Publish Alertmanager Template Notification with ntfy

Publishes an ntfy notification from the Alertmanager template.

## Endpoint

- **Method:** `POST`
- **Path:** `/:topic`
- **Base URL:** `https://ntfy.sh`
- **Official documentation:** [Publish Alertmanager Template Notification](https://docs.ntfy.sh/publish/#pre-defined-templates)
