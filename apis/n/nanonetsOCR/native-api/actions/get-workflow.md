# Get Workflow with Nanonets OCR

- **Method:** `GET`
- **Path:** `/workflows/:workflow_id`
- **Base URL:** `https://app.nanonets.com/api/v4`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflow_id` | path | `list` | yes | Workflow identifier. |
