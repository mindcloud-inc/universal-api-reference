# List Project Membership Packages with Nucleus One

Retrieves project memberships from a Nucleus One organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/projectMembershipPackages`
- **Base URL:** `https://client-api.nucleus.one/api/v1`
- **Official documentation:** [List Project Membership Packages](https://client-api.nucleus.one/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | ID of the organization |
