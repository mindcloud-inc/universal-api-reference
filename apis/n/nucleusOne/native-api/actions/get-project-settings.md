# Get Project Settings with Nucleus One

Retrieves project settings from Nucleus One.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/projects/:projectId/settings`
- **Base URL:** `https://client-api.nucleus.one/api/v1`
- **Official documentation:** [Get Project Settings](https://client-api.nucleus.one/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | Organization ID |
| `projectId` | path | `string` | yes | Project ID |
