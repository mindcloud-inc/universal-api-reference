# Get Organization Membership Package with Nucleus One

Retrieves organization membership details from Nucleus One.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizationMembershipPackages/:organizationId`
- **Base URL:** `https://client-api.nucleus.one/api/v1`
- **Official documentation:** [Get Organization Membership Package](https://client-api.nucleus.one/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | ID of the organization |
