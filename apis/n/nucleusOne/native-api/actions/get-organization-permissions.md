# Get Organization Permissions with Nucleus One

Retrieves organization permissions from Nucleus One.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/permissions`
- **Base URL:** `https://client-api.nucleus.one/api/v1`
- **Official documentation:** [Get Organization Permissions](https://client-api.nucleus.one/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | ID of the organization |
