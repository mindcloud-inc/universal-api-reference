# List Document Filter Sort Fields with Nucleus One

Retrieves document filter and sort fields from Nucleus One.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/projects/:projectId/documentFilterSortFields`
- **Base URL:** `https://client-api.nucleus.one/api/v1`
- **Official documentation:** [List Document Filter Sort Fields](https://client-api.nucleus.one/api/v1/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | organizationId path parameter. |
| `projectId` | path | `string` | yes | projectId path parameter. |
