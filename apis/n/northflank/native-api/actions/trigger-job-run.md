# Trigger job run with Northflank

Starts a new job run in Northflank.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/{projectId}/jobs/{jobId}/runs`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Trigger job run](https://northflank.com/docs/v1/api/use-the-api)
