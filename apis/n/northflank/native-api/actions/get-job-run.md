# Get job run with Northflank

Retrieves a Northflank job run by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/jobs/{jobId}/runs/{runId}`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Get job run](https://northflank.com/docs/v1/api/use-the-api)
