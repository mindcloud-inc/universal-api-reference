# Get service with Northflank

Retrieves a service from Northflank by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/services/{serviceId}`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Get service](https://northflank.com/docs/v1/api/use-the-api)
