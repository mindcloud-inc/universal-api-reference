# Service metrics with Northflank

Retrieves metrics for a Northflank service.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/services/{serviceId}/metrics`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Service metrics](https://northflank.com/docs/v1/api/use-the-api)
