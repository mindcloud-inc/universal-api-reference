# Build service with Northflank

Starts a new build for a Northflank service.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/{projectId}/services/{serviceId}/build`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Build service](https://northflank.com/docs/v1/api/use-the-api)
