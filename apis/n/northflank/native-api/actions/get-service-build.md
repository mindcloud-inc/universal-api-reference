# Get service build with Northflank

Retrieves a build for a Northflank service.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/services/{serviceId}/build/{buildId}`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Get service build](https://northflank.com/docs/v1/api/use-the-api)
