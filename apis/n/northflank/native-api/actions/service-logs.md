# Service logs with Northflank

Retrieves logs for a Northflank service.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/services/{serviceId}/logs`
- **Base URL:** `https://api.northflank.com/v1`
- **Official documentation:** [Service logs](https://northflank.com/docs/v1/api/use-the-api)
