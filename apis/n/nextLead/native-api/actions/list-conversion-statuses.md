# List Conversion Statuses with NextLead

Retrieves available conversion statuses from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/contact/get-conversion`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Conversion Statuses](https://dashboard.nextlead.app/en/api-documentation#receive-contact-getConversion)
