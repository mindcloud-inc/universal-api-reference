# List Custom Fields with NextLead

Retrieves available contact custom fields from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/contact/get-custom-fields`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Custom Fields](https://dashboard.nextlead.app/en/api-documentation#receive-contact-getCustomFields)
