# List Lists with NextLead

Retrieves audience lists with details from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/lists/get-lists`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Lists](https://dashboard.nextlead.app/en/api-documentation#receive-list-getLists)
