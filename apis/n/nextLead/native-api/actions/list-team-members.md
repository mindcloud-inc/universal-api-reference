# List Team Members with NextLead

Retrieves your organization's team members from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/contact/get-team`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Team Members](https://dashboard.nextlead.app/en/api-documentation#receive-contact-getTeam)
