# Get Form with NextLead

Retrieves a form from NextLead by list ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/forms/get-form`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [Get Form](https://dashboard.nextlead.app/en/api-documentation#receive-form-getForm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | query | `string` | yes | Audience list identifier for the form. |
