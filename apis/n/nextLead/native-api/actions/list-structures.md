# List Structures with NextLead

Retrieves all organization structures from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/structure/get-structures`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Structures](https://dashboard.nextlead.app/en/api-documentation#receive-structure-getStructures)
