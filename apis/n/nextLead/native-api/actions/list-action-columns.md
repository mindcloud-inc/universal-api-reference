# List Action Columns with NextLead

Retrieves action stage columns from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/actions/get-columns`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Action Columns](https://dashboard.nextlead.app/en/api-documentation#receive-action-getColumns)
