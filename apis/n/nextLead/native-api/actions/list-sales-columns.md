# List Sales Columns with NextLead

Retrieves sales stage columns from NextLead.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/receive/sales/get-columns`
- **Base URL:** `https://dashboard.nextlead.app`
- **Official documentation:** [List Sales Columns](https://dashboard.nextlead.app/en/api-documentation#receive-sale-getColumns)
