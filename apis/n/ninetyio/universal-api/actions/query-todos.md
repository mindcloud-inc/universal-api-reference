# Ninety.io: Query To-Dos

Retrieves to-dos from Ninety.io with optional filters.

```
GET https://connect.mindcloud.co/v1/universal/ninetyio/latest/actions/query-todos
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Ninety.io `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/ninetyio/latest/actions/query-todos?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/ninetyio/latest/actions/query-todos?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `teamId` | string | no | Filter results to a specific team Id |
| `sort` | string | no | The field to sort results by |
| `order` | string | no | Sort direction |
| `page` | number | no | Page number (1-based) |
| `pageSize` | number | no | Number of results per page |
| `isPersonal` | boolean | no | Filter to personal To-Dos only |
| `completed` | boolean | no | Filter by completed status |
| `archived` | boolean | no | Filter by archived status |
| `searchText` | string | no | Search text to match against To-Do title and description |
| `title` | string | no | Filter by exact title match |

## Native endpoint

Through the native Ninety.io API, this operation is `POST /v1/todos/query` (base URL `https://api.public.ninety.io`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/query-todos.md) for the provider-specific parameters and requirements.
