# Delete Issue with Ninety.io

Deletes an existing issue from Ninety.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/issues/:issueId`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Delete Issue](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueId` | path | `string` | yes | The Issue Id |
