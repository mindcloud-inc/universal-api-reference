# Delete To-Do with Ninety.io

Deletes an existing to-do from Ninety.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/todos/:id`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Delete To-Do](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The To-Do Id |
