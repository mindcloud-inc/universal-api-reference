# Get Issue by Id with Ninety.io

Retrieves an issue from Ninety.io by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/issues/:issueId`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Get Issue by Id](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `issueId` | path | `string` | yes | The Issue Id |
