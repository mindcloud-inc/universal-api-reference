# Delete Rock with Ninety.io

Soft-deletes an existing rock in Ninety.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/rocks/:id`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Delete Rock](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
