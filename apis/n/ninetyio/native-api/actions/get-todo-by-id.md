# Get To-Do by Id with Ninety.io

Retrieves a to-do from Ninety.io by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/todos/:id`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Get To-Do by Id](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The To-Do Id |
