# Get Rock by Id with Ninety.io

Retrieves a rock from Ninety.io by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/rocks/:id`
- **Base URL:** `https://api.public.ninety.io`
- **Official documentation:** [Get Rock by Id](https://api.public.ninety.io/v1/swagger)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
