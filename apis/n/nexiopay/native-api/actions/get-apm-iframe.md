# Get APM iframe with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/apm/v3`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [Get APM iframe](https://docs.nexiopay.com/reference/getapmiframe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | query | `string` | yes | APM one-time-use token returned by the APM token endpoint. |
