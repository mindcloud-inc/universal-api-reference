# Run card transaction with iframe with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/pay/v3`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [Run card transaction with iframe](https://docs.nexiopay.com/reference/runcardtransactioniframe)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | query | `string` | yes | One-time-use token returned by the token endpoint. |
