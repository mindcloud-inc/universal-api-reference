# Save card token with iframe with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/pay/v3/saveCard`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [Save card token with iframe](https://docs.nexiopay.com/reference/savecardtokeniframe-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `token` | query | `string` | yes | One-time-use token returned by the token endpoint. |
