# Pair terminal with Nexiopay

## Endpoint

- **Method:** `POST`
- **Path:** `/pay/v3/pairTerminal`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [Pair terminal](https://docs.nexiopay.com/reference/pairterminal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `merchantId` | body | `string` | yes | Nexio merchant ID to associate with the terminal. |
