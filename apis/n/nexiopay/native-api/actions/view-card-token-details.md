# View card token details with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/pay/v3/vault/card/{cardToken}`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View card token details](https://docs.nexiopay.com/reference/viewcardtokendetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardToken` | path | `string` | yes | Saved card token to retrieve. |
