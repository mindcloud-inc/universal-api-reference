# View merchants by ID with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/merchant/v3`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View merchants by ID](https://docs.nexiopay.com/reference/viewmerchantsbyid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `merchantIds` | query | `string` | no | Comma-separated Nexio merchant IDs to retrieve. |
