# View echeck token details with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/pay/v3/vault/echeck/{echeckToken}`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View echeck token details](https://docs.nexiopay.com/reference/viewechecktokendetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `echeckToken` | path | `string` | yes | Saved echeck token to retrieve. |
