# View card tokens with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/card/v3`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View card tokens](https://docs.nexiopay.com/reference/viewcardtokens)

## Capabilities

This operation supports [pagination](../README.md#pagination).
