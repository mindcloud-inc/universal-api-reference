# View recipients with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/payout/v3/recipient`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View recipients](https://docs.nexiopay.com/reference/viewrecipients)

This operation supports [pagination](../README.md#pagination).
