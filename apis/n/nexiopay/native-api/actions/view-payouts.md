# View payouts with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/payout/v3`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View payouts](https://docs.nexiopay.com/reference/viewpayouts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
