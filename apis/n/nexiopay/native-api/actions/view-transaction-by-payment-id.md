# View transaction by payment ID with Nexiopay

## Endpoint

- **Method:** `GET`
- **Path:** `/transaction/v3/paymentId/{paymentId}`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [View transaction by payment ID](https://docs.nexiopay.com/reference/viewtransactionbypaymentid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `paymentId` | path | `string` | yes | Nexio payment ID to retrieve. |
