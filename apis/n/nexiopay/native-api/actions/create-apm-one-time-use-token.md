# Create APM one-time-use token with Nexiopay

## Endpoint

- **Method:** `POST`
- **Path:** `/apm/v3/token`
- **Base URL:** `https://api.nexiopaysandbox.com`
- **Official documentation:** [Create APM one-time-use token](https://docs.nexiopay.com/reference/createapmonetimeusetoken)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | APM transaction data object documented by Nexio. |
