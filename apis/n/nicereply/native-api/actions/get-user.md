# Get User with Nicereply

Retrieves details for a user from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get User](https://cdn.nicereply.com/s/api/latest/reference/users/view/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nicereply user ID. |
