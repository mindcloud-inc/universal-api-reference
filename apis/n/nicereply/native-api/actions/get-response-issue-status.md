# Get Response Issue Status with Nicereply

Retrieves a response issue status from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/responses/:id/issue-status`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Response Issue Status](https://cdn.nicereply.com/s/api/latest/reference/responses/issue-status/view/)
