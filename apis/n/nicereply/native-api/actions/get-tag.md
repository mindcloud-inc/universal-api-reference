# Get Tag with Nicereply

Retrieves details for a tag from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Tag](https://cdn.nicereply.com/s/api/latest/reference/tags/view/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nicereply tag ID. |
