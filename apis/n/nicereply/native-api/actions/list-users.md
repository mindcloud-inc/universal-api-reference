# List Users with Nicereply

Retrieves a list of users from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Users](https://cdn.nicereply.com/s/api/latest/reference/users/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_order` | query | `string` | no | Sort users by created_at using asc or desc. |
