# Create Tag with Nicereply

Creates a new tag in Nicereply.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Create Tag](https://cdn.nicereply.com/s/api/latest/reference/tags/create/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Unique name of the tag. |
