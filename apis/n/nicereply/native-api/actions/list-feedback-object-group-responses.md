# List Feedback Object Group Responses with Nicereply

Retrieves responses for a feedback object group in Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-object-groups/:id/responses`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Feedback Object Group Responses](https://cdn.nicereply.com/s/api/latest/reference/feedback-object-groups/responses/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
