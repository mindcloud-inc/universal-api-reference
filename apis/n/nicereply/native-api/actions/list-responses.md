# List Responses with Nicereply

Retrieves a list of responses from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/responses`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Responses](https://cdn.nicereply.com/s/api/latest/reference/responses/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
