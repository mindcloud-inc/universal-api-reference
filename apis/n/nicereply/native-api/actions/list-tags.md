# List Tags with Nicereply

Retrieves a list of tags from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Tags](https://cdn.nicereply.com/s/api/latest/reference/tags/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_order` | query | `string` | no | Sort tags by created_at using asc or desc. |
