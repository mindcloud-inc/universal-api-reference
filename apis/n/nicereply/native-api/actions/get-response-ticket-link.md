# Get Response Ticket Link with Nicereply

Retrieves a response ticket link from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/responses/:id/ticket-link`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Response Ticket Link](https://cdn.nicereply.com/s/api/latest/reference/responses/ticket_link/)
