# Resolve Response Issue Status with Nicereply

Resolves a response issue in Nicereply.

## Endpoint

- **Method:** `POST`
- **Path:** `/responses/:id/issue-status/resolve`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Resolve Response Issue Status](https://cdn.nicereply.com/s/api/latest/reference/responses/issue-status/resolve/)
