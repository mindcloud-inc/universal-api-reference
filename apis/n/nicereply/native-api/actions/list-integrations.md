# List Integrations with Nicereply

Retrieves a list of integrations from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Integrations](https://cdn.nicereply.com/s/api/latest/reference/integrations/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
