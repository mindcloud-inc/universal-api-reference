# Assign Response Tags with Nicereply

Assigns a tag to a response in Nicereply.

## Endpoint

- **Method:** `POST`
- **Path:** `/responses/:responseId/tags/:tagId`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Assign Response Tags](https://cdn.nicereply.com/s/api/latest/reference/responses/tags/assign/)
