# List Survey Responses with Nicereply

Retrieves responses for a survey in Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/:id/responses`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Survey Responses](https://cdn.nicereply.com/s/api/latest/reference/surveys/responses/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
