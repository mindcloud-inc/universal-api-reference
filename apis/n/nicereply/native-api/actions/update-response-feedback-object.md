# Update Response Feedback Object with Nicereply

Updates a response's feedback object in Nicereply.

## Endpoint

- **Method:** `PUT`
- **Path:** `/responses/:id/feedback-object`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Update Response Feedback Object](https://cdn.nicereply.com/s/api/latest/reference/responses/update_feedback_object/)
