# Unassign Response Tags with Nicereply

Unassigns a tag from a response in Nicereply.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/responses/:responseId/tags/:tagId`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Unassign Response Tags](https://cdn.nicereply.com/s/api/latest/reference/responses/tags/unassign/)
