# Ignore Response Issue Status with Nicereply

Ignores a response issue in Nicereply.

## Endpoint

- **Method:** `POST`
- **Path:** `/responses/:id/issue-status/ignore`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Ignore Response Issue Status](https://cdn.nicereply.com/s/api/latest/reference/responses/issue-status/ignore/)
