# View Survey Distribution with Nicereply

Retrieves survey distribution settings from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys/:id/distribution`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [View Survey Distribution](https://cdn.nicereply.com/s/api/latest/reference/surveys/view-distribution/)
