# Get Feedback Object with Nicereply

Retrieves a feedback object from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-objects/:id`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Feedback Object](https://cdn.nicereply.com/s/api/latest/reference/feedback-objects/view/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nicereply feedback object ID. |
