# List Feedback Object Groups with Nicereply

Retrieves feedback object groups from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-object-groups`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Feedback Object Groups](https://cdn.nicereply.com/s/api/latest/reference/feedback-object-groups/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
