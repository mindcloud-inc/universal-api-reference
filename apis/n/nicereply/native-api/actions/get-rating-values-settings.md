# Get Rating Values Settings with Nicereply

Retrieves rating value settings from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/rating-values`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Rating Values Settings](https://cdn.nicereply.com/s/api/latest/reference/rating-values/settings)
