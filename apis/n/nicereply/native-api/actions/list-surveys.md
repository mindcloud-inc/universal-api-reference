# List Surveys with Nicereply

Retrieves a list of surveys from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/surveys`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Surveys](https://cdn.nicereply.com/s/api/latest/reference/surveys/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
