# Get Feedback Object Group with Nicereply

Retrieves a feedback object group from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/feedback-object-groups/:id`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [Get Feedback Object Group](https://cdn.nicereply.com/s/api/latest/reference/feedback-object-groups/view/)
