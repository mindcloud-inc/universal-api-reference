# List Customers with Nicereply

Retrieves a list of customers from Nicereply.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers`
- **Base URL:** `https://api.nicereply.com`
- **Official documentation:** [List Customers](https://cdn.nicereply.com/s/api/latest/reference/customers/list/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
