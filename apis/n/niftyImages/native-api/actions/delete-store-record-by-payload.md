# Delete Store Record By Payload with NiftyImages

Deletes a data store record from NiftyImages by payload.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Store/DeleteRecord`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Delete Store Record By Payload](https://api.niftyimages.com/)
