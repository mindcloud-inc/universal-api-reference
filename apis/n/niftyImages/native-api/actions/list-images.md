# List Images with NiftyImages

Retrieves images from NiftyImages.

## Endpoint

- **Method:** `GET`
- **Path:** `/Images`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [List Images](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageSize` | query | `number` | no | Number of records to return. |
| `pageNumber` | query | `number` | no | Page number to fetch. |
