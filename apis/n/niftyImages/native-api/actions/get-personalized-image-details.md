# Get Personalized Image Details with NiftyImages

Retrieves personalized image details from NiftyImages.

## Endpoint

- **Method:** `GET`
- **Path:** `/Personalized`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Get Personalized Image Details](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | NiftyImages image URL. |
