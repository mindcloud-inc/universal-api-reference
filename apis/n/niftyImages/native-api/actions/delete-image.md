# Delete Image with NiftyImages

Deletes an image from NiftyImages.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Image`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Delete Image](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | NiftyImages image URL. |
