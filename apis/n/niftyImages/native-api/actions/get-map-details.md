# Get Map Details with NiftyImages

Retrieves map details from NiftyImages.

## Endpoint

- **Method:** `GET`
- **Path:** `/Maps/Details`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Get Map Details](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | NiftyImages map URL. |
