# Delete Store Record By ID with NiftyImages

Deletes a data store record from NiftyImages by record ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/Store/DeleteID`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Delete Store Record By ID](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Record ID to delete. |
