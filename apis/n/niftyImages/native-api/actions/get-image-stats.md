# Get Aggregated Image Stats with NiftyImages

Retrieves aggregated image stats from NiftyImages.

## Endpoint

- **Method:** `GET`
- **Path:** `/Images/AllStats`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Get Aggregated Image Stats](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `startDate` | query | `string` | no | Start date in ISO 8601 format. |
| `endDate` | query | `string` | no | End date in ISO 8601 format. |
