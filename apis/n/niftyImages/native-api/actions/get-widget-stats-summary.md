# Get Widget Stats Summary with NiftyImages

Retrieves widget stats summary from NiftyImages.

## Endpoint

- **Method:** `GET`
- **Path:** `/Widgets/AllStats`
- **Base URL:** `https://api.niftyimages.com/v1`
- **Official documentation:** [Get Widget Stats Summary](https://api.niftyimages.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `startDate` | query | `string` | no | Start date in ISO 8601 format. |
| `endDate` | query | `string` | no | End date in ISO 8601 format. |
