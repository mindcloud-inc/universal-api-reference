# Genderize Full Name with Namsor

Retrieves the likely gender for a full name in Namsor.

## Endpoint

- **Method:** `GET`
- **Path:** `/api2/json/genderFull/:fullName`
- **Base URL:** `https://v2.namsor.com/NamSorAPIv2`
- **Official documentation:** [Genderize Full Name](https://namsor.app/api-documentation/gender-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fullName` | path | `string` | yes | Full personal name. |
