# Query AI Task Result with NeroBot AI

Retrieves an AI task result from NeroBot AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/biz/api/task`
- **Base URL:** `https://api.nero.com`
- **Official documentation:** [Query AI Task Result](https://ai.nero.com/ai-api/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | query | `string` | yes | Task ID returned by Create AI Task. |
