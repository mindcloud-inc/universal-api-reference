# Generate Background (Brick) with NeroBot AI

Creates a brick background generation task in NeroBot AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/biz/api/task`
- **Base URL:** `https://api.nero.com`
- **Official documentation:** [Generate Background (Brick)](https://ai.nero.com/ai-api/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image` | body | `string` | yes |
