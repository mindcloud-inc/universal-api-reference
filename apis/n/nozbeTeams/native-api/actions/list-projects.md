# List Projects with Nozbe Teams

Retrieves accessible projects from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [List Projects](https://api4.nozbe.com/v1/api#/projects/getProjects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_id` | query | `string` | no | Return only projects from this team. |
