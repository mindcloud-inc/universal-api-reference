# Poll Updated Tasks with Nozbe Teams

Retrieves updated tasks since the last call in Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/poll/tasks/updated`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Poll Updated Tasks](https://api4.nozbe.com/v1/api#/other/pollTasksUpdated)
