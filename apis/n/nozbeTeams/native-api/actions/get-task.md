# Get Task with Nozbe Teams

Retrieves a task from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Task](https://api4.nozbe.com/v1/api#/tasks/getTaskById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nozbe task ID. |
