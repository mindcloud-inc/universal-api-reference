# List Project Sections with Nozbe Teams

Retrieves accessible project sections from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/project_sections`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [List Project Sections](https://api4.nozbe.com/v1/api#/project_sections/getProjectSections)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | query | `string` | no | Return only sections for this project. |
