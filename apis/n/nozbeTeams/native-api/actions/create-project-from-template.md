# Create Project From Template with Nozbe Teams

Creates a new project from a template in Nozbe Teams.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/from_template/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Create Project From Template](https://api4.nozbe.com/v1/api#/projects/postProjectFromTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The template project to copy. |
