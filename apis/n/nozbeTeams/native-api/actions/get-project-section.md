# Get Project Section with Nozbe Teams

Retrieves a project section from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/project_sections/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Project Section](https://api4.nozbe.com/v1/api#/project_sections/getProjectSectionById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project section to retrieve. |
