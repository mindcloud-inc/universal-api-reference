# Get Team with Nozbe Teams

Retrieves a team from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Team](https://api4.nozbe.com/v1/api#/teams/getTeamById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nozbe team ID. |
