# Delete Project with Nozbe Teams

Deletes an existing project from Nozbe Teams.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Project](https://api4.nozbe.com/v1/api#/projects/deleteProjectById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The project to delete. |
