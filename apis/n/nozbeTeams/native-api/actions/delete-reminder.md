# Delete Reminder with Nozbe Teams

Deletes an existing reminder from Nozbe Teams.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/reminders/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Reminder](https://api4.nozbe.com/v1/api#/reminders/deleteReminderById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The reminder to delete. |
