# Get Task Event with Nozbe Teams

Retrieves a task event from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_events/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Task Event](https://api4.nozbe.com/v1/api#/task_events/getTaskEventById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The task event to retrieve. |
