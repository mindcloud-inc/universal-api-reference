# Get Reminder with Nozbe Teams

Retrieves a reminder from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/reminders/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Reminder](https://api4.nozbe.com/v1/api#/reminders/getReminderById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The reminder to retrieve. |
