# Poll New Tasks with Nozbe Teams

Retrieves new tasks since the last call in Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/poll/tasks/new`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Poll New Tasks](https://api4.nozbe.com/v1/api#/other/pollTasksNew)
