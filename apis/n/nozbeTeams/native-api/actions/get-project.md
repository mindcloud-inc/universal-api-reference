# Get Project with Nozbe Teams

Retrieves a project from Nozbe Teams.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Get Project](https://api4.nozbe.com/v1/api#/projects/getProjectById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nozbe project ID. |
