# Generate Token Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/file/:fileId/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Token Token](https://api.netexplorer.fr/v3/#token.post.file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
| `type` | path | `string` | yes |
