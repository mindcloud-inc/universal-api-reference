# Get File Timeline with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:fileId/timeline`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get File Timeline](https://api.netexplorer.fr/v3/#files.get.timeline)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
