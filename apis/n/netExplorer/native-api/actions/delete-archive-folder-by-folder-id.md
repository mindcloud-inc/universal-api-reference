# Delete Folder with NetExplorer

- **Official documentation:** [Delete Folder](https://api.netexplorer.fr/v3/#archive.delete.delete-folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
