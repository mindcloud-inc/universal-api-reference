# Send Upload Link SMS with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/ulink/key/:ulinkKey/sms`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Send Upload Link SMS](https://api.netexplorer.fr/v3/#ulinks.post.ulink-sms-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ulinkKey` | path | `string` | yes |
