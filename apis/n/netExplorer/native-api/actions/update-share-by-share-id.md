# Update Share with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/share/:shareId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update Share](https://api.netexplorer.fr/v3/#shares.put.share)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareId` | path | `string` | yes |
