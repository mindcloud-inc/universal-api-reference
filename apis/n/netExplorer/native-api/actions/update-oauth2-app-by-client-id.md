# Update App with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/oauth2/app/:clientId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update App](https://api.netexplorer.fr/v3/#oauth2.put.oauth2-put-app)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
