# Get Email with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/sharelink/email/:sharelinkEmailId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Email](https://api.netexplorer.fr/v3/#sharelinks-email.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkEmailId` | path | `string` | yes |
