# Delete Share with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/share/:shareId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete Share](https://api.netexplorer.fr/v3/#shares.delete.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareId` | path | `string` | yes |
