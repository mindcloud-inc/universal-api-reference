# Create Remind with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/signatures/:signatureId/actors/remind`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create Remind](https://api.netexplorer.fr/v3/#signature.post.remind all actors)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
