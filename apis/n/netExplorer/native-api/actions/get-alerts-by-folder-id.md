# List Alerts with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Alerts](https://api.netexplorer.fr/v3/#alerts.get.fetch-all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
