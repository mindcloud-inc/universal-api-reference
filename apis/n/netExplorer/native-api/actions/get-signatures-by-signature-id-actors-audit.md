# Get Audit with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/signatures/:signatureId/actors/audit`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Audit](https://api.netexplorer.fr/v3/#signature.get.download all audit trail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
