# Get Portal Root with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/root/portal/:filter`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Portal Root](https://api.netexplorer.fr/v3/#roots.get.index)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter` | path | `string` | yes |
