# Get Activity with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/email/:shareEmailId/activity`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Activity](https://api.netexplorer.fr/v3/#shares-email.get.share-email-activity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareEmailId` | path | `string` | yes |
