# Download File By File ID with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:fileId/download`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Download File By File ID](https://api.netexplorer.fr/v3/#files.get.download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
