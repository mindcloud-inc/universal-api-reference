# Get Activity with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/:shareId/activity`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Activity](https://api.netexplorer.fr/v3/#shares.get.share-activity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareId` | path | `string` | yes |
