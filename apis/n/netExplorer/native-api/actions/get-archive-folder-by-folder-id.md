# Get Folder with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/archive/folder/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Folder](https://api.netexplorer.fr/v3/#archive.get.fetch-folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
