# Generate Token Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/share/:guId/:type/:key`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Token Token](https://api.netexplorer.fr/v3/#token.post.share-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `guid` | path | `string` | yes |
| `type` | path | `string` | yes |
| `key` | path | `string` | yes |
