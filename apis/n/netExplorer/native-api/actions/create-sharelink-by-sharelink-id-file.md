# Create File with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/sharelink/:sharelinkId/file`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create File](https://api.netexplorer.fr/v3/#sharelinks.post.add-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
