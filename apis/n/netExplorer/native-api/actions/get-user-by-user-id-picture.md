# Get User Picture with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId/picture`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get User Picture](https://api.netexplorer.fr/v3/#users.get.picture)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
