# Get Folder Timeline with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/folder/:folderId/timeline`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Folder Timeline](https://api.netexplorer.fr/v3/#folders.get.timeline)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
