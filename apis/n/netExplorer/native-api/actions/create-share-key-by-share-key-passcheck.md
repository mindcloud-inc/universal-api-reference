# Validate Sharelink Password with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/share/key/:shareKey/passcheck`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Validate Sharelink Password](https://api.netexplorer.fr/v3/#shares.post.shares-passcheck-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareKey` | path | `string` | yes |
