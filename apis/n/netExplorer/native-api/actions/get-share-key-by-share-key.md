# Get Key with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/key/:shareKey`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Key](https://api.netexplorer.fr/v3/#shares.get.fetch-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareKey` | path | `string` | yes |
