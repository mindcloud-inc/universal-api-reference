# Delete App with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/oauth2/app/:clientId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete App](https://api.netexplorer.fr/v3/#oauth2.delete.oauth2-delete-app)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
