# Delete Sharelink with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sharelink/:sharelinkId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete Sharelink](https://api.netexplorer.fr/v3/#sharelinks.delete.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
