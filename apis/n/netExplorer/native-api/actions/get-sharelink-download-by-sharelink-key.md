# Download Sharelink By Sharelink Key with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/sharelink/download/:sharelinkKey`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Download Sharelink By Sharelink Key](https://api.netexplorer.fr/v3/#sharelinks.get.fetch-download)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkKey` | path | `string` | yes |
