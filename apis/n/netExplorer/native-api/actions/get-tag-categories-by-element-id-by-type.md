# Get Category with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/categories/:elementId/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Category](https://api.netexplorer.fr/v3/#tags.get.fetchAllCategoriesFromElement)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `elementId` | path | `string` | yes |
| `type` | path | `string` | yes |
