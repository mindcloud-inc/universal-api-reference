# Update User Picture with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/user/:userId/picture`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update User Picture](https://api.netexplorer.fr/v3/#users.post.picture)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `userId` | path | `string` | yes |
