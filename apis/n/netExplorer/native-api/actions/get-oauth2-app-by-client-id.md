# Get App with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth2/app/:clientId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get App](https://api.netexplorer.fr/v3/#oauth2.get.oauth2-single)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
