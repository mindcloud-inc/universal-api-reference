# Update Folder with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/folder/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update Folder](https://api.netexplorer.fr/v3/#folders.put.update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
