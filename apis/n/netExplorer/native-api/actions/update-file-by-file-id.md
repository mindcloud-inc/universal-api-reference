# Update File with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/file/:fileId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update File](https://api.netexplorer.fr/v3/#files.put.update)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
