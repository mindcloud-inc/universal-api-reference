# List File Activity with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/activity/file/:fileId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List File Activity](https://api.netexplorer.fr/v3/#activity.get.activity_file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
