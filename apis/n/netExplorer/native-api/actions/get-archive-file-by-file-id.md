# Get File with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/archive/file/:fileId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get File](https://api.netexplorer.fr/v3/#archive.get.fetch-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
