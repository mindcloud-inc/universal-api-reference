# Create Tag with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/tag/:tagId/:elementId/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create Tag](https://api.netexplorer.fr/v3/#tags.post.addTagOnElement)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tagId` | path | `string` | yes |
| `elementId` | path | `string` | yes |
| `type` | path | `string` | yes |
