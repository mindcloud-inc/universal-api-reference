# Get Trash By Trash ID with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/trash/:trashId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Trash By Trash ID](https://api.netexplorer.fr/v3/#trash.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trashId` | path | `string` | yes |
