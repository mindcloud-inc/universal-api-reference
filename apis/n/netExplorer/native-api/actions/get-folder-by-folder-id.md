# Get Folder By Folder ID with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/folder/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Folder By Folder ID](https://api.netexplorer.fr/v3/#folders.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
