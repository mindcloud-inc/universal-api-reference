# List Folder Activity with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/activity/folder/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Folder Activity](https://api.netexplorer.fr/v3/#activity.get.activity_folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
