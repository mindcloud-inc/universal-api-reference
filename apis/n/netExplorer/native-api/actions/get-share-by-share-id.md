# Get Share By Share ID with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/:shareId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Share By Share ID](https://api.netexplorer.fr/v3/#shares.get.fetch-share)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareId` | path | `string` | yes |
