# Generate Sharelink Download Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/sharelink/:key/download`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Sharelink Download Token](https://api.netexplorer.fr/v3/#token.post.sharelink)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
