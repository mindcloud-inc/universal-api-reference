# Get Share Content with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/content/:shareKey/[:folderId]`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Share Content](https://api.netexplorer.fr/v3/#shares.get.fetch-content-share)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareKey` | path | `string` | yes |
| `folderId` | path | `string` | no |
