# Delete Folder with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/folder/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete Folder](https://api.netexplorer.fr/v3/#folders.delete.delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
