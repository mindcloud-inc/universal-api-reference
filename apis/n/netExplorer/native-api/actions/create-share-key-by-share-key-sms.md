# Send Share SMS with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/share/key/:shareKey/sms`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Send Share SMS](https://api.netexplorer.fr/v3/#shares.post.shares-sms-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareKey` | path | `string` | yes |
