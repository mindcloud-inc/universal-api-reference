# List Invites with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/invites/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Invites](https://api.netexplorer.fr/v3/#invitations.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
