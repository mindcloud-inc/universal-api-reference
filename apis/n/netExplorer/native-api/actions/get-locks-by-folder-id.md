# List Locks with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/locks/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Locks](https://api.netexplorer.fr/v3/#locks.get.fetch-all)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
