# Get Icon with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth2/app/:clientId/icon`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Icon](https://api.netexplorer.fr/v3/#oauth2.get.oauth2-single-icon)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
