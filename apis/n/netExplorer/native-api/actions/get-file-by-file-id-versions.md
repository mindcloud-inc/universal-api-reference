# List File Versions with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:fileId/versions`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List File Versions](https://api.netexplorer.fr/v3/#files.get.versions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
