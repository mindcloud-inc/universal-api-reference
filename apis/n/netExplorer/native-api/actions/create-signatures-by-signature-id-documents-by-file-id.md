# Create Document with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/signatures/:signatureId/documents/:fileId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create Document](https://api.netexplorer.fr/v3/#signature.post.add document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
| `fileId` | path | `string` | yes |
