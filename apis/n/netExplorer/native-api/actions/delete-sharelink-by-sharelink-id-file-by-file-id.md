# Delete File with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sharelink/:sharelinkId/file/:fileId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete File](https://api.netexplorer.fr/v3/#sharelinks.delete.delete-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
| `fileId` | path | `string` | yes |
