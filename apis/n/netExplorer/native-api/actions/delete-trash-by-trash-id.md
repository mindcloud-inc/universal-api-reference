# Delete Trash with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/trash/:trashId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete Trash](https://api.netexplorer.fr/v3/#trash.delete.destroy)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trashId` | path | `string` | yes |
