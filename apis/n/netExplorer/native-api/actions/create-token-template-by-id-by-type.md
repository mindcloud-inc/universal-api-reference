# Generate Token Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/template/:id/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Token Token](https://api.netexplorer.fr/v3/#token.post.template-file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `type` | path | `string` | yes |
