# List Annotations with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/annotations/:targetId/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Annotations](https://api.netexplorer.fr/v3/#annotations.get.fetch-all-target)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `targetId` | path | `string` | yes |
| `type` | path | `string` | yes |
