# Get Share with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/zip/share/:shareKey`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Share](https://api.netexplorer.fr/v3/#shares.get.download-share)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareKey` | path | `string` | yes |
