# Create Folder with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/sharelink/:sharelinkId/folder`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create Folder](https://api.netexplorer.fr/v3/#sharelinks.post.add-folder)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
