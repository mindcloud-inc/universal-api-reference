# Update Trash with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/trash/:trashId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update Trash](https://api.netexplorer.fr/v3/#trash.put.restore)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `trashId` | path | `string` | yes |
