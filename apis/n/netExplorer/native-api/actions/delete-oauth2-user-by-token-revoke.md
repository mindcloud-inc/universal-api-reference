# Revoke User with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/oauth2/user/:token/revoke`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Revoke User](https://api.netexplorer.fr/v3/#oauth2.delete.oauth2-revoke-user-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token` | path | `string` | yes |
