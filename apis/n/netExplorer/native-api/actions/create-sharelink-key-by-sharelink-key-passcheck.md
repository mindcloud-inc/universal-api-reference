# Validate Sharelink Password with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/sharelink/key/:sharelinkKey/passcheck`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Validate Sharelink Password](https://api.netexplorer.fr/v3/#sharelinks.post.passcheck-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkKey` | path | `string` | yes |
