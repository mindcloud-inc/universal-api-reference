# Update Document with NetExplorer

## Endpoint

- **Method:** `PATCH`
- **Path:** `/signatures/:signatureId/documents/:documentId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update Document](https://api.netexplorer.fr/v3/#signature.patch.update document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
| `documentId` | path | `string` | yes |
