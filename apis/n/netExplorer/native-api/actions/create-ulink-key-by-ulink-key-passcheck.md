# Validate Sharelink Password with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/ulink/key/:ulinkKey/passcheck`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Validate Sharelink Password](https://api.netexplorer.fr/v3/#ulinks.post.ulink-passcheck-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ulinkKey` | path | `string` | yes |
