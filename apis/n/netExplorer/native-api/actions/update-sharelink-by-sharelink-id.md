# Update Sharelink with NetExplorer

## Endpoint

- **Method:** `PUT`
- **Path:** `/sharelink/:sharelinkId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Update Sharelink](https://api.netexplorer.fr/v3/#sharelinks.put.edit)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
