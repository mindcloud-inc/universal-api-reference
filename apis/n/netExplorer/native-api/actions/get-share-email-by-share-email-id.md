# Get Email with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/share/email/:shareEmailId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Email](https://api.netexplorer.fr/v3/#shares-email.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `shareEmailId` | path | `string` | yes |
