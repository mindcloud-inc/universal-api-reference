# Get Signed with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/signatures/:signatureId/documents/signed`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Signed](https://api.netexplorer.fr/v3/#signature.get.download all signed document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
