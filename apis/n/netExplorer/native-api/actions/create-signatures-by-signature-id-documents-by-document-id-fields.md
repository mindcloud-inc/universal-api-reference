# Create Field with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/signatures/:signatureId/documents/:documentId/fields`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Create Field](https://api.netexplorer.fr/v3/#signature.post.create field)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
| `documentId` | path | `string` | yes |
