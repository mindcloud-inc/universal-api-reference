# Revoke App with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/oauth2/app/:token/revoke`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Revoke App](https://api.netexplorer.fr/v3/#oauth2.delete.oauth2-revoke-app-token)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `token` | path | `string` | yes |
