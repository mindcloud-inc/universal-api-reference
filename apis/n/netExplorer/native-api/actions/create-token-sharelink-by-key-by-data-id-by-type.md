# Generate Token Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/sharelink/:key/:dataId/:type`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Token Token](https://api.netexplorer.fr/v3/#token.post.sharelink_file)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
| `dataId` | path | `string` | yes |
| `type` | path | `string` | yes |
