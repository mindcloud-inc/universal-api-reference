# Delete Document with NetExplorer

## Endpoint

- **Method:** `DELETE`
- **Path:** `/signatures/:signatureId/documents/:documentId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Delete Document](https://api.netexplorer.fr/v3/#signature.delete.delete document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
| `documentId` | path | `string` | yes |
