# Generate Share Download Token with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/token/share/download/:key`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Generate Share Download Token](https://api.netexplorer.fr/v3/#token.post.share)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `key` | path | `string` | yes |
