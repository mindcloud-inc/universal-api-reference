# Get File Info with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:fileId/infos`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get File Info](https://api.netexplorer.fr/v3/#files.get.infos)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fileId` | path | `string` | yes |
