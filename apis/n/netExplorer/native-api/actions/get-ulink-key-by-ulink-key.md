# Get Key with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/ulink/key/:ulinkKey`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Key](https://api.netexplorer.fr/v3/#ulinks.get.fetch-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ulinkKey` | path | `string` | yes |
