# Reset App Secret with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/oauth2/app/:clientId/reset`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Reset App Secret](https://api.netexplorer.fr/v3/#oauth2.post.oauth2-post-app-reset)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
