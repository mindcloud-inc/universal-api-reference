# List Template Files with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/template/files/:folderId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Template Files](https://api.netexplorer.fr/v3/#template-files.get.files)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `folderId` | path | `string` | yes |
