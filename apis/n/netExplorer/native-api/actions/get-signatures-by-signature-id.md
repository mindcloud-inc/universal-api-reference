# List Signatures with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/signatures/:signatureId`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [List Signatures](https://api.netexplorer.fr/v3/#signature.get.fetch)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `signatureId` | path | `string` | yes |
