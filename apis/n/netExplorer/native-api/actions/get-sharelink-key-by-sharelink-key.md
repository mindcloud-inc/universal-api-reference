# Get Key with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/sharelink/key/:sharelinkKey`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Key](https://api.netexplorer.fr/v3/#sharelinks.get.fetch-key)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkKey` | path | `string` | yes |
