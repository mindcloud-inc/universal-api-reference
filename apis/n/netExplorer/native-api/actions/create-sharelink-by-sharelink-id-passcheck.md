# Validate Sharelink Password with NetExplorer

## Endpoint

- **Method:** `POST`
- **Path:** `/sharelink/:sharelinkId/passcheck`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Validate Sharelink Password](https://api.netexplorer.fr/v3/#sharelinks.post.passcheck)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sharelinkId` | path | `string` | yes |
