# Get Token with NetExplorer

## Endpoint

- **Method:** `GET`
- **Path:** `/oauth2/app/:clientId/tokens`
- **Base URL:** `{platformBaseUrl}/api`
- **Official documentation:** [Get Token](https://api.netexplorer.fr/v3/#oauth2.get.oauth2-app-tokens)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientId` | path | `string` | yes |
