# Get Integration with Notificações Inteligentes

Retrieves an integration from Notificações Inteligentes by store ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations/:store`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Get Integration](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
