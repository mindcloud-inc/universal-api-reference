# Send Billet Printed Event with Notificações Inteligentes

Creates a billet printed event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/billet-printed`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Billet Printed Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
