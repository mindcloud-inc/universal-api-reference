# Get Lead with Notificações Inteligentes

Retrieves a lead from Notificações Inteligentes by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:lead`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Get Lead](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `lead` | path | `string` | yes | The lead identifier. |
