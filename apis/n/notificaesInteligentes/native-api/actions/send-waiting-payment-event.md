# Send Waiting Payment Event with Notificações Inteligentes

Creates a waiting payment event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/waiting-payment`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Waiting Payment Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
