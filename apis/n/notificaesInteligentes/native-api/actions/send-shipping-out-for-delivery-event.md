# Send Shipping Out For Delivery Event with Notificações Inteligentes

Creates a shipping out-for-delivery event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/shipping-out-for-delivery`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Shipping Out For Delivery Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
