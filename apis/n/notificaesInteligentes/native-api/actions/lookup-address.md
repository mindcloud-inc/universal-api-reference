# Lookup Address with Notificações Inteligentes

Retrieves an address from Notificações Inteligentes by postal code.

## Endpoint

- **Method:** `GET`
- **Path:** `/addresses/:postalCode`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Lookup Address](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `postalCode` | path | `string` | yes | The postal code to look up. |
