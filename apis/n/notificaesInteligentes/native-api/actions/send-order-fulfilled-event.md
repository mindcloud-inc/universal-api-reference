# Send Order Fulfilled Event with Notificações Inteligentes

Creates an order fulfilled event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/order-fulfilled`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Order Fulfilled Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
