# Send Abandoned Cart Event with Notificações Inteligentes

Creates an abandoned cart event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/abandoned-cart`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Abandoned Cart Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
