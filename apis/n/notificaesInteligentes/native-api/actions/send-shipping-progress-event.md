# Send Shipping Progress Event with Notificações Inteligentes

Creates a shipping progress event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/shipping-progress`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Shipping Progress Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
