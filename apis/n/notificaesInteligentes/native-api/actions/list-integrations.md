# List Integrations with Notificações Inteligentes

Retrieves integrations from Notificações Inteligentes.

## Endpoint

- **Method:** `GET`
- **Path:** `/integrations`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [List Integrations](https://docs.notificacoesinteligentes.com/)
