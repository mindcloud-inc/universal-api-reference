# Get Tag with Notificações Inteligentes

Retrieves a tag from Notificações Inteligentes by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:tag`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Get Tag](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag` | path | `string` | yes | The tag identifier. |
