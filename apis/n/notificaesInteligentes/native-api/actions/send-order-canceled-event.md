# Send Order Canceled Event with Notificações Inteligentes

Creates an order canceled event in Notificações Inteligentes.

## Endpoint

- **Method:** `POST`
- **Path:** `/integrations/:store/events/order-canceled`
- **Base URL:** `https://api.notificacoesinteligentes.com`
- **Official documentation:** [Send Order Canceled Event](https://docs.notificacoesinteligentes.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `store` | path | `string` | yes | The integration store identifier. |
