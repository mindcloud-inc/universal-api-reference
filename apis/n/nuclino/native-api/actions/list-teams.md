# List teams with Nuclino

Retrieves a list of teams from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [List teams](https://help.nuclino.com/b72e5fdd-teams)

## Capabilities

This operation supports [pagination](../README.md#pagination).
