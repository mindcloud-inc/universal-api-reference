# Get workspace with Nuclino

Retrieves a workspace's details from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:id`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [Get workspace](https://help.nuclino.com/702467a8-workspaces)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
