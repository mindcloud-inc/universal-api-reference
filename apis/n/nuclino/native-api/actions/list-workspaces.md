# List workspaces with Nuclino

Retrieves a list of workspaces from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [List workspaces](https://help.nuclino.com/702467a8-workspaces)

## Capabilities

This operation supports [pagination](../README.md#pagination).
