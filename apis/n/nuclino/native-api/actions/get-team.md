# Get team with Nuclino

Retrieves a team's details from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [Get team](https://help.nuclino.com/b72e5fdd-teams)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
