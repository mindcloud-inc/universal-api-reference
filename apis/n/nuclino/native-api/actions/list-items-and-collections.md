# List items and collections with Nuclino

Retrieves items and collections from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/items`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [List items and collections](https://help.nuclino.com/fa38d15f-items-and-collections)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `teamId` | query | `string` | no |
| `workspaceId` | query | `string` | no |
