# Get file with Nuclino

Retrieves a file's details from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:id`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [Get file](https://help.nuclino.com/9a737add-files)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
