# Get user with Nuclino

Retrieves a user's details from Nuclino.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.nuclino.com/v0`
- **Official documentation:** [Get user](https://help.nuclino.com/f76dc920-users)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
