# List Vehicle Variables with NHTSA vPIC

Retrieves vehicle variables from NHTSA vPIC.

## Endpoint

- **Method:** `GET`
- **Path:** `vehicles/GetVehicleVariableList`
- **Base URL:** `https://vpic.nhtsa.dot.gov/api`
- **Official documentation:** [List Vehicle Variables](https://vpic.nhtsa.dot.gov/api/Home/Index)
