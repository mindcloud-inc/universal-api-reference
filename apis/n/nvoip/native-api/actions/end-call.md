# End Call with Nvoip

## Endpoint

- **Method:** `GET`
- **Path:** `/endcall`
- **Base URL:** `https://api.nvoip.com.br/v2`
- **Official documentation:** [End Call](https://github.com/Nvoip/nvoip-integrationAPI/blob/main/calls.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `callId` | query | `string` | yes | Unique Nvoip call identifier. |
