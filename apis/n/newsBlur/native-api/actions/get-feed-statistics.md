# Get Feed Statistics with NewsBlur

Retrieves feed statistics from NewsBlur.

## Endpoint

- **Method:** `GET`
- **Path:** `/rss_feeds/statistics/:id`
- **Base URL:** `https://www.newsblur.com`
- **Official documentation:** [Get Feed Statistics](https://newsblur.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feed ID for statistics. |
