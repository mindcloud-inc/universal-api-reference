# Get Feed Page with NewsBlur

Retrieves a feed page from NewsBlur.

## Endpoint

- **Method:** `GET`
- **Path:** `/reader/page/:id`
- **Base URL:** `https://www.newsblur.com`
- **Official documentation:** [Get Feed Page](https://newsblur.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feed ID for the original page. |
