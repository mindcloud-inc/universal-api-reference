# Log In with NewsBlur

Creates a session in NewsBlur.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/login`
- **Base URL:** `https://www.newsblur.com`
- **Official documentation:** [Log In](https://newsblur.com/api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
