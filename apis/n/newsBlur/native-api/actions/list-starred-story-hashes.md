# List Starred Story Hashes with NewsBlur

Retrieves starred story hashes from NewsBlur.

## Endpoint

- **Method:** `GET`
- **Path:** `/reader/starred_story_hashes`
- **Base URL:** `https://www.newsblur.com`
- **Official documentation:** [List Starred Story Hashes](https://newsblur.com/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_timestamps` | query | `boolean` | no | Include timestamps for starred dates. |
