# Get Ticket with NeetoDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:ticket_id`
- **Base URL:** `https://{workspaceSubdomain}.neetodesk.com/api/external/v2`
- **Official documentation:** [Get Ticket](https://apidocs.neetodesk.com/api-reference/tickets/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticket_id` | path | `string` | yes | Identifier of the ticket. |
