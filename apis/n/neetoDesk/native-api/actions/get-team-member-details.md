# Get Team Member Details with NeetoDesk

## Endpoint

- **Method:** `GET`
- **Path:** `/team-members/:team_member_id`
- **Base URL:** `https://{workspaceSubdomain}.neetodesk.com/api/external/v2`
- **Official documentation:** [Get Team Member Details](https://apidocs.neetodesk.com/api-reference/team-members/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_member_id` | path | `string` | yes | Identifier of the team member. |
