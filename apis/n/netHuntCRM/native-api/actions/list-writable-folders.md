# List Writable Folders with NetHunt CRM

Retrieves writable folders from NetHunt CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/triggers/writable-folder`
- **Base URL:** `https://nethunt.com/api/v1/zapier`
- **Official documentation:** [List Writable Folders](https://nethunt.com/integration-api#writable-folder)
