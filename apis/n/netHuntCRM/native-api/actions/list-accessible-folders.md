# List Accessible Folders with NetHunt CRM

Retrieves accessible folders from NetHunt CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/triggers/readable-folder`
- **Base URL:** `https://nethunt.com/api/v1/zapier`
- **Official documentation:** [List Accessible Folders](https://nethunt.com/integration-api#readable-folder)
