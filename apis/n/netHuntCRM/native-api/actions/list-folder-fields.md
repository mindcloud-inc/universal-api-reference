# List Folder Fields with NetHunt CRM

Retrieves folder fields from NetHunt CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/triggers/folder-field/:folderId`
- **Base URL:** `https://nethunt.com/api/v1/zapier`
- **Official documentation:** [List Folder Fields](https://nethunt.com/integration-api#folder-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Folder ID to list fields for. |
