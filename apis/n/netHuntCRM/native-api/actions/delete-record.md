# Delete Record with NetHunt CRM

Deletes an existing record from NetHunt CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/actions/delete-record/:recordId`
- **Base URL:** `https://nethunt.com/api/v1/zapier`
- **Official documentation:** [Delete Record](https://nethunt.com/integration-api#delete-record)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recordId` | path | `string` | yes | Record ID to delete. |
