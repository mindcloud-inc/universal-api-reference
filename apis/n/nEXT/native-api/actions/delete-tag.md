# Delete Tag with NEXT

Deletes an existing tag from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete Tag](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The NEXT tag ID. |
