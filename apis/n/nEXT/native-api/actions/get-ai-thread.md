# Get AI Thread with NEXT

Retrieves an AI thread from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai-threads/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Get AI Thread](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI thread ID. |
