# List Accounts with NEXT

Retrieves accounts from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [List Accounts](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nextToken` | query | `string` | no | Pagination token from the previous response. |
