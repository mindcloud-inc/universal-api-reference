# Get Account with NEXT

Retrieves an account from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Get Account](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The NEXT account ID. |
