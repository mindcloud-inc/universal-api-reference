# Create Tag with NEXT

Creates a new tag in NEXT.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Create Tag](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The tag name. |
