# Create AI Thread with NEXT

Creates a new AI thread in NEXT.

## Endpoint

- **Method:** `POST`
- **Path:** `/ai-threads`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Create AI Thread](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The AI thread name. |
