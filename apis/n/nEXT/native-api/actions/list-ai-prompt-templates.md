# List AI Prompt Templates with NEXT

Retrieves AI prompt templates from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai-prompt-templates`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [List AI Prompt Templates](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `nextToken` | query | `string` | no | Pagination token from the previous response. |
