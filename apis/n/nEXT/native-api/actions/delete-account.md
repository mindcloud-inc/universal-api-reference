# Delete Account with NEXT

Deletes an existing account from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounts/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete Account](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The NEXT account ID. |
