# Delete AI Thread with NEXT

Deletes an existing AI thread from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ai-threads/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete AI Thread](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI thread ID. |
