# Delete AI Rule with NEXT

Deletes an existing AI rule from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ai-rules/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete AI Rule](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI rule ID. |
