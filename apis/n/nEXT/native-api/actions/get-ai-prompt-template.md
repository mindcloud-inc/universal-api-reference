# Get AI Prompt Template with NEXT

Retrieves an AI prompt template from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai-prompt-templates/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Get AI Prompt Template](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI prompt template ID. |
