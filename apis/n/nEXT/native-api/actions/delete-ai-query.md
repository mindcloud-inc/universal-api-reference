# Delete AI Query with NEXT

Deletes an existing AI query from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ai-queries/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete AI Query](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI query ID. |
