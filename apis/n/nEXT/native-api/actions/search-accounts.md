# Search Accounts with NEXT

Finds accounts in NEXT by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/search-accounts`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Search Accounts](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search_term` | query | `string` | yes | Search text for matching accounts. |
