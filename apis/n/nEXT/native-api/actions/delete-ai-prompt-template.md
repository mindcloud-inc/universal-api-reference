# Delete AI Prompt Template with NEXT

Deletes an existing AI prompt template from NEXT.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/ai-prompt-templates/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Delete AI Prompt Template](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI prompt template ID. |
