# Get AI Query with NEXT

Retrieves an AI query from NEXT.

## Endpoint

- **Method:** `GET`
- **Path:** `/ai-queries/:id`
- **Base URL:** `https://rest.eu-west-1.nextapp.co/v1`
- **Official documentation:** [Get AI Query](https://developer.nextapp.co/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The AI query ID. |
