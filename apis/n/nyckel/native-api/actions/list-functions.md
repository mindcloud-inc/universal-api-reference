# List Functions with Nyckel

Retrieves functions from Nyckel.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions`
- **Base URL:** `https://www.nyckel.com/v1`
- **Official documentation:** [List Functions](https://www.nyckel.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `number` | no | Maximum number of functions to return. |
| `startIndex` | query | `number` | no | Zero-based function offset for pagination. |
