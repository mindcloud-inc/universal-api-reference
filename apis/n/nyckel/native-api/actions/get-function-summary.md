# Get Function Summary with Nyckel

Retrieves a function summary from Nyckel.

## Endpoint

- **Method:** `GET`
- **Path:** `/functions/:functionId/summary`
- **Base URL:** `https://www.nyckel.com/v1`
- **Official documentation:** [Get Function Summary](https://www.nyckel.com/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `functionId` | path | `string` | yes | The Nyckel function ID. |
