# List Bookings with NeetoCal

Finds bookings in NeetoCal by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://{subdomain}.neetocal.com/api/external/v2`
- **Official documentation:** [List Bookings](https://neetocal-apis.mintlify.app/api-reference/bookings/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
