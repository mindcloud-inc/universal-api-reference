# Get Team Member with NeetoCal

Retrieves a team member from NeetoCal.

## Endpoint

- **Method:** `GET`
- **Path:** `/team-members/:team_member_id`
- **Base URL:** `https://{subdomain}.neetocal.com/api/external/v2`
- **Official documentation:** [Get Team Member](https://apidocs.neetocal.com/api-reference/team-members/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `team_member_id` | path | `string` | yes | The NeetoCal team member ID. |
