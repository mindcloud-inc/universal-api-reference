# List Scheduling Links with NeetoCal

Finds scheduling links in NeetoCal by filter criteria.

## Endpoint

- **Method:** `GET`
- **Path:** `/meetings`
- **Base URL:** `https://{subdomain}.neetocal.com/api/external/v2`
- **Official documentation:** [List Scheduling Links](https://apidocs.neetocal.com/api-reference/scheduling-links/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
