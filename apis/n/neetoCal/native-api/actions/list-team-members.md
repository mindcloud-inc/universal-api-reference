# List Team Members with NeetoCal

Retrieves team members from NeetoCal.

## Endpoint

- **Method:** `GET`
- **Path:** `/team-members`
- **Base URL:** `https://{subdomain}.neetocal.com/api/external/v2`
- **Official documentation:** [List Team Members](https://apidocs.neetocal.com/api-reference/team-members/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
