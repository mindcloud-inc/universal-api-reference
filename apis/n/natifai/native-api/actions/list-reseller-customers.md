# List Reseller Customers with Natif.ai

Retrieves reseller customer records from Natif.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/reseller/customers`
- **Base URL:** `https://api.natif.ai`
- **Official documentation:** [List Reseller Customers](https://api.natif.ai/docs#/Reseller%20User%20Management/get_customer_list_reseller_customers_get)
