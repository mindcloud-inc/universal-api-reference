# List Document Share Tokens with Natif.ai

Retrieves document sharing tokens from Natif.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/share-tokens/documents`
- **Base URL:** `https://api.natif.ai`
- **Official documentation:** [List Document Share Tokens](https://api.natif.ai/docs#/Document%20Capturing/list_team_document_sharing_tokens_share_tokens_documents_get)
