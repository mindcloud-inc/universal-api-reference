# List User Management Users with Natif.ai

Retrieves users from Natif.ai user management.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-management/users`
- **Base URL:** `https://api.natif.ai`
- **Official documentation:** [List User Management Users](https://api.natif.ai/docs#/User%20Management/get_users_user_management_users_get)
