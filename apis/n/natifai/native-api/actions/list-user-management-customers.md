# List User Management Customers with Natif.ai

Retrieves customers from Natif.ai user management.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-management/customers`
- **Base URL:** `https://api.natif.ai`
- **Official documentation:** [List User Management Customers](https://api.natif.ai/docs#/User%20Management/get_customer_list_user_management_customers_get)
