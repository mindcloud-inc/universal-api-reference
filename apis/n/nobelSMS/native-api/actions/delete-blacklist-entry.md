# Delete Blacklist Entry with NobelSMS

Deletes a blacklist entry from NobelSMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/black_list/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Delete Blacklist Entry](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Blacklist entry ID. |
