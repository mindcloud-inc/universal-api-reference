# Delete Tag with NobelSMS

Deletes an existing tag from NobelSMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tag/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Delete Tag](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tag ID. |
