# Get Balance with NobelSMS

Retrieves a balance from NobelSMS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/balance/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Get Balance](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Account ID. |
