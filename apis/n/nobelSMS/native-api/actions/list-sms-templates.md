# List SMS Templates with NobelSMS

Retrieves SMS templates from NobelSMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms_template`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [List SMS Templates](https://api.nobelsms.com/rest/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination).
