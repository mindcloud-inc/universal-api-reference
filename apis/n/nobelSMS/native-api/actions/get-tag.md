# Get Tag with NobelSMS

Retrieves a tag from NobelSMS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Get Tag](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Tag ID. |
