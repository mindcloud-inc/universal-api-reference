# Delete Contact with NobelSMS

Deletes an existing contact from NobelSMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contact/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Delete Contact](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID. |
