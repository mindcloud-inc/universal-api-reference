# Get Contact with NobelSMS

Retrieves a contact from NobelSMS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/contact/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Get Contact](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID. |
