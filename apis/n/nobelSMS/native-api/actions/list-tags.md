# List Tags with NobelSMS

Retrieves tags from NobelSMS.

## Endpoint

- **Method:** `GET`
- **Path:** `/tag`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [List Tags](https://api.nobelsms.com/rest/swagger.json)

## Capabilities

This operation supports [pagination](../README.md#pagination).
