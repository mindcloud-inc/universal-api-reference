# Delete SMS Template with NobelSMS

Deletes an existing SMS template from NobelSMS.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sms_template/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Delete SMS Template](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Template ID. |
