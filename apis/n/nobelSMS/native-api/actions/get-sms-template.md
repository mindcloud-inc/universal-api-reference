# Get SMS Template with NobelSMS

Retrieves an SMS template from NobelSMS by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/sms_template/:id`
- **Base URL:** `https://api.nobelsms.com/rest`
- **Official documentation:** [Get SMS Template](https://api.nobelsms.com/rest/swagger.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Template ID. |
