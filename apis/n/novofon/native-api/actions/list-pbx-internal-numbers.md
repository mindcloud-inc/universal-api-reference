# List PBX Internal Numbers with Novofon

Retrieves PBX internal numbers from Novofon.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pbx/internal/`
- **Base URL:** `https://api.novofon.com`
- **Official documentation:** [List PBX Internal Numbers](https://novofon.com/instructions/api/#pbx_internal)
