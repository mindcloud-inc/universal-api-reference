# List Direct Number Countries with Novofon

Retrieves direct number countries from Novofon.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/direct_numbers/countries/`
- **Base URL:** `https://api.novofon.com`
- **Official documentation:** [List Direct Number Countries](https://novofon.com/instructions/api/#direct_numbers_countries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | query | `string` | no | Optional response language. If omitted, Novofon uses the account language. |
