# List Work Orders with NetSuite - Basic

Retrieves a list of work orders from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/workOrder`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Work Orders](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/workOrder)

## Capabilities

This operation supports [pagination](../README.md#pagination).
