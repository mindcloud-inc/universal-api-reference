# List Time Bills with NetSuite - Basic

Retrieves a list of time bills from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/timeBill`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Time Bills](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/timeBill)

## Capabilities

This operation supports [pagination](../README.md#pagination).
