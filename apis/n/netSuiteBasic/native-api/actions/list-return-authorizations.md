# List Return Authorizations with NetSuite - Basic

Retrieves a list of return authorizations from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/returnAuthorization`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Return Authorizations](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/returnAuthorization)

## Capabilities

This operation supports [pagination](../README.md#pagination).
