# Create Term with NetSuite - Basic

Creates a new term in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/term`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Term](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/term)
