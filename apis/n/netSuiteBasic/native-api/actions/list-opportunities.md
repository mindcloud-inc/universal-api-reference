# List Opportunities with NetSuite - Basic

Retrieves a list of opportunities from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/opportunity`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Opportunities](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/opportunity)

## Capabilities

This operation supports [pagination](../README.md#pagination).
