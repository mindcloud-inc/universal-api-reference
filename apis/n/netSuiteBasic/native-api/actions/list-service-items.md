# List Service Items with NetSuite - Basic

Retrieves a list of service items from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/serviceSaleItem`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Service Items](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/serviceSaleItem)

## Capabilities

This operation supports [pagination](../README.md#pagination).
