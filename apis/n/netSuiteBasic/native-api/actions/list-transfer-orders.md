# List Transfer Orders with NetSuite - Basic

Retrieves a list of transfer orders from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/transferOrder`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Transfer Orders](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/transferOrder)

## Capabilities

This operation supports [pagination](../README.md#pagination).
