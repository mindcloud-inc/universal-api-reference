# Create Purchase Order with NetSuite - Basic

Creates a new purchase order in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/purchaseOrder`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Purchase Order](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/purchaseOrder)
