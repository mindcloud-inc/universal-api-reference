# List Vendor Return Authorizations with NetSuite - Basic

Retrieves a list of vendor return authorizations from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/vendorReturnAuthorization`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Vendor Return Authorizations](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/vendorReturnAuthorization)

## Capabilities

This operation supports [pagination](../README.md#pagination).
