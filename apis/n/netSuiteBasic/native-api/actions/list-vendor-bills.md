# List Vendor Bills with NetSuite - Basic

Retrieves a list of vendor bills from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/vendorBill`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Vendor Bills](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/vendorBill)

## Capabilities

This operation supports [pagination](../README.md#pagination).
