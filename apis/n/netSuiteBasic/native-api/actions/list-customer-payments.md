# List Customer Payments with NetSuite - Basic

Retrieves a list of customer payments from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/customerPayment`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Customer Payments](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/customerPayment)

## Capabilities

This operation supports [pagination](../README.md#pagination).
