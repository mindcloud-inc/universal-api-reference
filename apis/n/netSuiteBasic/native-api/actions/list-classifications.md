# List Classifications with NetSuite - Basic

Retrieves a list of classifications from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/classification`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Classifications](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/classification)

## Capabilities

This operation supports [pagination](../README.md#pagination).
