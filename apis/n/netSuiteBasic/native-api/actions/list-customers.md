# List Customers with NetSuite - Basic

Retrieves a list of customers from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/customer`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Customers](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/customer)

## Capabilities

This operation supports [pagination](../README.md#pagination).
