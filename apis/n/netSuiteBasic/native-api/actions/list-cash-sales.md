# List Cash Sales with NetSuite - Basic

Retrieves a list of cash sales from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/cashSale`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Cash Sales](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/cashSale)

## Capabilities

This operation supports [pagination](../README.md#pagination).
