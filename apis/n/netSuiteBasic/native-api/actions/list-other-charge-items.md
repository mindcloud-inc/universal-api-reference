# List Other Charge Items with NetSuite - Basic

Retrieves a list of other charge items from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/otherChargeSaleItem`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Other Charge Items](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/otherChargeSaleItem)

## Capabilities

This operation supports [pagination](../README.md#pagination).
