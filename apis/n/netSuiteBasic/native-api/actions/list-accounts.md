# List Accounts with NetSuite - Basic

Retrieves a list of accounts from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/account`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Accounts](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/account)

## Capabilities

This operation supports [pagination](../README.md#pagination).
