# List Inventory Adjustments with NetSuite - Basic

Retrieves a list of inventory adjustments from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/inventoryAdjustment`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Inventory Adjustments](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/inventoryAdjustment)

## Capabilities

This operation supports [pagination](../README.md#pagination).
