# List Shipping Items with NetSuite - Basic

Retrieves a list of shipping items from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/shipItem`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Shipping Items](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/shipItem)

## Capabilities

This operation supports [pagination](../README.md#pagination).
