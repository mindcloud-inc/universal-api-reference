# List Customer Refunds with NetSuite - Basic

Retrieves a list of customer refunds from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/customerRefund`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Customer Refunds](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/customerRefund)

## Capabilities

This operation supports [pagination](../README.md#pagination).
