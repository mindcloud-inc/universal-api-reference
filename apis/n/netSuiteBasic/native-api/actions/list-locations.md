# List Locations with NetSuite - Basic

Retrieves a list of locations from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/location`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Locations](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/location)

## Capabilities

This operation supports [pagination](../README.md#pagination).
