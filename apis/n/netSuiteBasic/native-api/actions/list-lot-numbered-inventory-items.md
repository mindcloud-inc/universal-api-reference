# List Lot Numbered Inventory Items with NetSuite - Basic

Retrieves a list of lot numbered inventory items from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/lotNumberedInventoryItem`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Lot Numbered Inventory Items](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/lotNumberedInventoryItem)

## Capabilities

This operation supports [pagination](../README.md#pagination).
