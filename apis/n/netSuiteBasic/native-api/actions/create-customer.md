# Create Customer with NetSuite - Basic

Creates a new customer in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/customer`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Customer](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/customer)
