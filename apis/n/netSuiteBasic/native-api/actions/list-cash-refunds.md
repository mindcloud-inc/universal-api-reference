# List Cash Refunds with NetSuite - Basic

Retrieves a list of cash refunds from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/cashRefund`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Cash Refunds](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/cashRefund)

## Capabilities

This operation supports [pagination](../README.md#pagination).
