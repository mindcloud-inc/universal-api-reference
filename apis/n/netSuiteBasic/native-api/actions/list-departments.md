# List Departments with NetSuite - Basic

Retrieves a list of departments from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/department`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Departments](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/department)

## Capabilities

This operation supports [pagination](../README.md#pagination).
