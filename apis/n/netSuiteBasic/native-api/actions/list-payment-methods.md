# List Payment Methods with NetSuite - Basic

Retrieves a list of payment methods from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/paymentMethod`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Payment Methods](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/paymentMethod)

## Capabilities

This operation supports [pagination](../README.md#pagination).
