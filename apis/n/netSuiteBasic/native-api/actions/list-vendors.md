# List Vendors with NetSuite - Basic

Retrieves a list of vendors from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/vendor`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Vendors](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/vendor)

## Capabilities

This operation supports [pagination](../README.md#pagination).
