# List Employees with NetSuite - Basic

Retrieves a list of employees from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/employee`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Employees](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/employee)

## Capabilities

This operation supports [pagination](../README.md#pagination).
