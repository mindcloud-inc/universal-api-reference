# List Promotion Codes with NetSuite - Basic

Retrieves a list of promotion codes from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/promotionCode`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Promotion Codes](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/promotionCode)

## Capabilities

This operation supports [pagination](../README.md#pagination).
