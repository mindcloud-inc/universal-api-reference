# List Credit Memos with NetSuite - Basic

Retrieves a list of credit memos from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/creditMemo`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Credit Memos](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/creditMemo)

## Capabilities

This operation supports [pagination](../README.md#pagination).
