# Create Employee with NetSuite - Basic

Creates a new employee in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/employee`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Employee](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/employee)
