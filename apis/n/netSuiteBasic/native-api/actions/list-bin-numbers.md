# List Bin Numbers with NetSuite - Basic

Retrieves a list of bin numbers from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/bin`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Bin Numbers](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/bin)

## Capabilities

This operation supports [pagination](../README.md#pagination).
