# List Contacts with NetSuite - Basic

Retrieves a list of contacts from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/contact`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Contacts](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/contact)

## Capabilities

This operation supports [pagination](../README.md#pagination).
