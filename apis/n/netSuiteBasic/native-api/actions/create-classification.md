# Create Classification with NetSuite - Basic

Creates a new classification in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/classification`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Classification](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558962745.html)
