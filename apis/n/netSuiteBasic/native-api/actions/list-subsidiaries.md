# List Subsidiaries with NetSuite - Basic

Retrieves a list of subsidiaries from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/subsidiary`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Subsidiaries](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/subsidiary)

## Capabilities

This operation supports [pagination](../README.md#pagination).
