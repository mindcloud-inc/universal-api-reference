# Create Vendor Bill with NetSuite - Basic

Creates a new vendor bill in NetSuite.

## Endpoint

- **Method:** `POST`
- **Path:** `/record/v1/vendorBill`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [Create Vendor Bill](https://docs.oracle.com/en/cloud/saas/netsuite/ns-online-help/chapter_1558962745.html)
