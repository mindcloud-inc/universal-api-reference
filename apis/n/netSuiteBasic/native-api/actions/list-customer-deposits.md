# List Customer Deposits with NetSuite - Basic

Retrieves a list of customer deposits from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/customerDeposit`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Customer Deposits](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/customerDeposit)

## Capabilities

This operation supports [pagination](../README.md#pagination).
