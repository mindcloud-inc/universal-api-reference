# List Inventory Numbers with NetSuite - Basic

Retrieves a list of inventory numbers from NetSuite.

## Endpoint

- **Method:** `GET`
- **Path:** `/record/v1/inventoryNumber`
- **Base URL:** `https://{accountDomain}.suitetalk.api.netsuite.com/services/rest`
- **Official documentation:** [List Inventory Numbers](https://system.netsuite.com/help/helpcenter/en_US/APIs/REST_API_Browser/record/v1/2025.2/index.html#/definitions/inventoryNumber)

## Capabilities

This operation supports [pagination](../README.md#pagination).
