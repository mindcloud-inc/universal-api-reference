# List Fields with noCRM.io

Retrieves fields from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/fields`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [List Fields](https://www.nocrm.io/api#list-the-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `type` | query | `string` | no | Restrict fields to lead or client. |
