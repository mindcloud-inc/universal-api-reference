# Retrieve Client Folder with noCRM.io

Retrieves client folder details from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Retrieve Client Folder](https://www.nocrm.io/api#retrieve-a-client-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client folder ID. |
