# List Categories with noCRM.io

Retrieves categories from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/categories`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [List Categories](https://www.nocrm.io/api#list-the-categories)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include_tags` | query | `boolean` | no | Include tags under each category. |
