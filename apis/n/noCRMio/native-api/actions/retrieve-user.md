# Retrieve User with noCRM.io

Retrieves user details from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Retrieve User](https://www.nocrm.io/api#retrieve-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User ID or email address. |
