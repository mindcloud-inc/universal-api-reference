# Retrieve Step with noCRM.io

Retrieves step details from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/steps/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Retrieve Step](https://www.nocrm.io/api#retrieve-a-step)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Step ID or name. |
