# Delete Client Folder with noCRM.io

Deletes an existing client folder from noCRM.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/clients/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Delete Client Folder](https://www.nocrm.io/api#delete-a-client-folder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Client folder ID. |
