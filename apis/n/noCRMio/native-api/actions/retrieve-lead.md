# Retrieve Lead with noCRM.io

Retrieves lead details from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Retrieve Lead](https://www.nocrm.io/api#retrieve-a-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier of the lead. |
