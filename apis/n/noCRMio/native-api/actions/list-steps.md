# List Steps with noCRM.io

Retrieves steps from noCRM.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/steps`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [List Steps](https://www.nocrm.io/api#list-the-steps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `direction` | query | `string` | no | Sort direction for returned steps. |
