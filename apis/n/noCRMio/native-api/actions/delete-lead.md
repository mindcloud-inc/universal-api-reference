# Delete Lead with noCRM.io

Deletes an existing lead from noCRM.io.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/leads/:id`
- **Base URL:** `{baseUrl}/api/v2`
- **Official documentation:** [Delete Lead](https://www.nocrm.io/api#delete-a-lead)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The identifier of the lead. |
