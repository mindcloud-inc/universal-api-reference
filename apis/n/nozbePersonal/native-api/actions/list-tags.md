# List Tags with Nozbe Personal

Retrieves accessible tags from Nozbe Personal.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [List Tags](https://api4.nozbe.com/v1/api#/tags/getTags)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `team_id` | query | `string` | no |
| `is_favorite` | query | `boolean` | no |
| `fields` | query | `string` | no |
| `sortBy` | query | `string` | no |
