# Delete Reminder with Nozbe Personal

Deletes an existing reminder from Nozbe Personal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/reminders/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Reminder](https://api4.nozbe.com/v1/api#/reminders/deleteReminderById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
