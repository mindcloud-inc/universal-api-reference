# List Project Sections with Nozbe Personal

Retrieves accessible project sections from Nozbe Personal.

## Endpoint

- **Method:** `GET`
- **Path:** `/project_sections`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [List Project Sections](https://api4.nozbe.com/v1/api#/project_sections/getProjectSections)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | query | `string` | no |
| `fields` | query | `string` | no |
| `sortBy` | query | `string` | no |
