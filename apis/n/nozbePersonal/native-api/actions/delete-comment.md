# Delete Comment with Nozbe Personal

Deletes an existing comment from Nozbe Personal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/comments/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Comment](https://api4.nozbe.com/v1/api#/comments/deleteCommentById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Comment ID to delete. |
