# Delete Project Section with Nozbe Personal

Deletes an existing project section from Nozbe Personal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project_sections/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Project Section](https://api4.nozbe.com/v1/api#/project_sections/deleteProjectSectionById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
