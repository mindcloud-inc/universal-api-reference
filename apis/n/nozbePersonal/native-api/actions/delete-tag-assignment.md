# Delete Tag Assignment with Nozbe Personal

Deletes an existing tag assignment from Nozbe Personal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tag_assignments/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Tag Assignment](https://api4.nozbe.com/v1/api#/tag_assignments/deleteTagAssignmentById)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
