# Delete Task with Nozbe Personal

Deletes an existing task from Nozbe Personal.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Delete Task](https://api4.nozbe.com/v1/api#/tasks/deleteTaskById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task ID to delete. |
