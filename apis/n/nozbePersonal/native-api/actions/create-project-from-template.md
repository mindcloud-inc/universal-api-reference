# Create Project From Template with Nozbe Personal

Creates a new project from a Nozbe Personal template.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/from_template/:id`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [Create Project From Template](https://api4.nozbe.com/v1/api#/projects/postProjectFromTemplate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Project template ID to clone. |
