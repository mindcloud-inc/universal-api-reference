# List Teams with Nozbe Personal

Retrieves accessible teams from Nozbe Personal.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams`
- **Base URL:** `https://api4.nozbe.com/v1/api`
- **Official documentation:** [List Teams](https://api4.nozbe.com/v1/api#/teams/getTeams)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
