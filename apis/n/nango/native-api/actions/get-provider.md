# Get Provider with Nango

## Endpoint

- **Method:** `GET`
- **Path:** `/providers/:provider`
- **Base URL:** `https://api.nango.dev`
- **Official documentation:** [Get Provider](https://nango.dev/docs/reference/api/providers/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `provider` | path | `string` | yes | Provider slug to retrieve. |
