# Delete Integration (Config) with Nango

## Endpoint

- **Method:** `DELETE`
- **Path:** `/config/:providerConfigKey`
- **Base URL:** `https://api.nango.dev`
- **Official documentation:** [Delete Integration (Config)](https://raw.githubusercontent.com/speakeasy-sdks/nango-typescript-sdk/main/openapi.yaml)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `providerConfigKey` | path | `string` | yes | The provider configuration key for the integration. |
