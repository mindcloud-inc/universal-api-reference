# List Nautical Orders with Nautical

Retrieves a list of Nautical orders.

## Endpoint

- **Method:** `POST`
- **Path:** `graphql/`
- **Base URL:** `https://api.mpconsole.com`
- **Official documentation:** [List Nautical Orders](https://guide.thetraide.com/docs/api/operations/queries/nautical-orders/)
