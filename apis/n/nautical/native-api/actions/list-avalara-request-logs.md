# List Avalara Request Logs with Nautical

Retrieves a list of Avalara request logs from Nautical.

## Endpoint

- **Method:** `POST`
- **Path:** `graphql/`
- **Base URL:** `https://api.mpconsole.com`
- **Official documentation:** [List Avalara Request Logs](https://guide.thetraide.com/docs/api/operations/queries/avalara-request-logs/)
