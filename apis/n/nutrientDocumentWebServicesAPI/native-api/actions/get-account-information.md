# Get Account Information with Nutrient Document Web Services

Retrieves account information from Nutrient Document Web Services API.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/info`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Get Account Information](https://www.nutrient.io/api/reference/public/#tag/Account/operation/get-account-info)
