# Get Year Fact with Numbers API

## Endpoint

- **Method:** `GET`
- **Path:** `/:year/year`
- **Base URL:** `http://numbersapi.com`
- **Official documentation:** [Get Year Fact](http://numbersapi.com/#api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `year` | path | `number` | yes |
| `fragment` | query | `boolean` | no |
| `notfound` | query | `string` | no |
