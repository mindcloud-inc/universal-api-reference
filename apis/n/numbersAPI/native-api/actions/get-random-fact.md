# Get Random Fact with Numbers API

## Endpoint

- **Method:** `GET`
- **Path:** `/random/:type`
- **Base URL:** `http://numbersapi.com`
- **Official documentation:** [Get Random Fact](http://numbersapi.com/#api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `type` | path | `string` | yes |
| `min` | query | `number` | no |
| `max` | query | `number` | no |
| `fragment` | query | `boolean` | no |
| `notfound` | query | `string` | no |
