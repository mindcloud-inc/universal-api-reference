# Get Number Trivia with Numbers API

## Endpoint

- **Method:** `GET`
- **Path:** `/:number/trivia`
- **Base URL:** `http://numbersapi.com`
- **Official documentation:** [Get Number Trivia](http://numbersapi.com/#api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `number` | path | `number` | yes |
| `fragment` | query | `boolean` | no |
| `notfound` | query | `string` | no |
