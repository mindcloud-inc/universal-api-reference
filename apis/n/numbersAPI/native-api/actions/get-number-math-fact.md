# Get Number Math Fact with Numbers API

## Endpoint

- **Method:** `GET`
- **Path:** `/:number/math`
- **Base URL:** `http://numbersapi.com`
- **Official documentation:** [Get Number Math Fact](http://numbersapi.com/#api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `number` | path | `number` | yes |
| `fragment` | query | `boolean` | no |
| `notfound` | query | `string` | no |
