# Get Date Fact with Numbers API

## Endpoint

- **Method:** `GET`
- **Path:** `/:month/:day/date`
- **Base URL:** `http://numbersapi.com`
- **Official documentation:** [Get Date Fact](http://numbersapi.com/#api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `month` | path | `number` | yes |
| `day` | path | `number` | yes |
| `fragment` | query | `boolean` | no |
| `notfound` | query | `string` | no |
