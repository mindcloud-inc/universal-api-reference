# Get User Detail with Navigatr

Retrieves user details from Navigatr.

## Endpoint

- **Method:** `GET`
- **Path:** `/user_detail/:user_id`
- **Base URL:** `https://api.navigatr.app/v1`
- **Official documentation:** [Get User Detail](https://api.navigatr.app/docs#/User%20Detail/user_detail_read_user_detail)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `user_id` | path | `number` | yes |
