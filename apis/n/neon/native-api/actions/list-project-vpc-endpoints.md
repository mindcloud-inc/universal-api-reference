# List VPC endpoint restrictions with Neon

Retrieves VPC endpoint restrictions from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/vpc_endpoints`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List VPC endpoint restrictions](https://api-docs.neon.tech/reference/listprojectvpcendpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
