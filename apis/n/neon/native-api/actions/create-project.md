# Create project with Neon

Creates a project in Neon.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Create project](https://api-docs.neon.tech/reference/createproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project` | body | `object` | yes | Neon API parameter project |
