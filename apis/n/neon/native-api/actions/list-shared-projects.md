# List shared projects with Neon

Retrieves shared projects from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/shared`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List shared projects](https://api-docs.neon.tech/reference/listsharedprojects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Neon API parameter search |
| `timeout` | query | `number` | no | Neon API parameter timeout |
