# Retrieve organization details with Neon

Retrieves organization details from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org_id`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Retrieve organization details](https://api-docs.neon.tech/reference/getorganization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Neon API parameter org_id |
