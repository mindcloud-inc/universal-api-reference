# List project access with Neon

Retrieves project access from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/permissions`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List project access](https://api-docs.neon.tech/reference/listprojectpermissions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
