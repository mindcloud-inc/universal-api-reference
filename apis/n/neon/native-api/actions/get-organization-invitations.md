# Retrieve organization invitation details with Neon

Retrieves organization invitations from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org_id/invitations`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Retrieve organization invitation details](https://api-docs.neon.tech/reference/getorganizationinvitations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Neon API parameter org_id |
