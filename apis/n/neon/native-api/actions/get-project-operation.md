# Retrieve operation details with Neon

Retrieves operation details from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/operations/:operation_id`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Retrieve operation details](https://api-docs.neon.tech/reference/getprojectoperation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
| `operation_id` | path | `string` | yes | Neon API parameter operation_id |
