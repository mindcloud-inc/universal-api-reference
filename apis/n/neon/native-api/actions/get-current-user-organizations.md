# Retrieve current user organizations list with Neon

Retrieves organizations for the current user from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/me/organizations`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Retrieve current user organizations list](https://api-docs.neon.tech/reference/getcurrentuserorganizations)
