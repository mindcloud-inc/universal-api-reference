# List organization API keys with Neon

Retrieves organization API keys from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:org_id/api_keys`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List organization API keys](https://api-docs.neon.tech/reference/listorgapikeys)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | path | `string` | yes | Neon API parameter org_id |
