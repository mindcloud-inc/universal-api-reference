# Retrieve project details with Neon

Retrieves project details from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Retrieve project details](https://api-docs.neon.tech/reference/getproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
