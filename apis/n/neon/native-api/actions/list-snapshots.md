# List project snapshots with Neon

Retrieves project snapshots from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/snapshots`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List project snapshots](https://api-docs.neon.tech/reference/listsnapshots)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
