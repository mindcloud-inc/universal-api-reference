# Recover a deleted project with Neon

Recovers a deleted project in Neon.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:project_id/recover`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Recover a deleted project](https://api-docs.neon.tech/reference/recoverproject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
