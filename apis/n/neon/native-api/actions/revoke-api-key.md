# Revoke API key with Neon

Revokes an API key from Neon.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api_keys/:key_id`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Revoke API key](https://api-docs.neon.tech/reference/revokeapikey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key_id` | path | `number` | yes | Neon API parameter key_id |
