# List supported regions with Neon

Retrieves supported regions from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/regions`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List supported regions](https://api-docs.neon.tech/reference/getactiveregions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `org_id` | query | `string` | no | Neon API parameter org_id |
