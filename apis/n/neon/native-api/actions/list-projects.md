# List projects with Neon

Retrieves projects from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List projects](https://api-docs.neon.tech/reference/listprojects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Neon API parameter search |
| `org_id` | query | `string` | no | Neon API parameter org_id |
| `timeout` | query | `number` | no | Neon API parameter timeout |
| `recoverable` | query | `boolean` | no | Neon API parameter recoverable |
