# Return available shared preload libraries with Neon

Retrieves available shared preload libraries from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/available_preload_libraries`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Return available shared preload libraries](https://api-docs.neon.tech/reference/getavailablepreloadlibraries)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
