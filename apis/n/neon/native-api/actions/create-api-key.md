# Create API key with Neon

Creates an API key in Neon.

## Endpoint

- **Method:** `POST`
- **Path:** `/api_keys`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Create API key](https://api-docs.neon.tech/reference/createapikey)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key_name` | body | `string` | yes | Neon API parameter key_name |
