# Get email server configuration with Neon

Retrieves email server configuration from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/auth/email_server`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [Get email server configuration](https://api-docs.neon.tech/reference/getneonauthemailserver)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
