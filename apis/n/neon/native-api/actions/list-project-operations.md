# List operations with Neon

Retrieves operations from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/operations`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List operations](https://api-docs.neon.tech/reference/listprojectoperations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
