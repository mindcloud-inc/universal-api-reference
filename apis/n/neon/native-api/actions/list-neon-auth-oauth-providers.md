# List OAuth providers with Neon

Retrieves OAuth providers from Neon.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id/auth/oauth_providers`
- **Base URL:** `https://console.neon.tech/api/v2`
- **Official documentation:** [List OAuth providers](https://api-docs.neon.tech/reference/listneonauthoauthproviders)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `string` | yes | Neon API parameter project_id |
