# Get Base with NocoDB

Retrieves details for a base from NocoDB.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/meta/bases/:baseId`
- **Base URL:** `https://app.nocodb.com`
- **Official documentation:** [Get Base](https://nocodb.com/apis/v3/meta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baseId` | path | `string` | yes | Base identifier. |
