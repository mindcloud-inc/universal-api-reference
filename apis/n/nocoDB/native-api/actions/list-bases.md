# List Bases with NocoDB

Retrieves bases in a NocoDB workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/meta/workspaces/:workspaceId/bases`
- **Base URL:** `https://app.nocodb.com`
- **Official documentation:** [List Bases](https://nocodb.com/apis/v3/meta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | path | `string` | yes | Workspace identifier. |
