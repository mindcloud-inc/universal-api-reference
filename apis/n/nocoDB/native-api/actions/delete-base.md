# Delete Base with NocoDB

Deletes an existing base from NocoDB.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/meta/bases/:baseId`
- **Base URL:** `https://app.nocodb.com`
- **Official documentation:** [Delete Base](https://nocodb.com/apis/v3/meta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baseId` | path | `string` | yes | Base identifier. |
