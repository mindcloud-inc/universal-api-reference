# List Tables with NocoDB

Retrieves tables in a NocoDB base.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v3/meta/bases/:baseId/tables`
- **Base URL:** `https://app.nocodb.com`
- **Official documentation:** [List Tables](https://nocodb.com/apis/v3/meta)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `baseId` | path | `string` | yes | Base identifier. |
