# List GitHub Repositories with Nightfall.ai

Retrieves GitHub repositories from Nightfall.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/v1/github/repositories`
- **Base URL:** `https://api.nightfall.ai`
- **Official documentation:** [List GitHub Repositories](https://help.nightfall.ai/developer-api/nightfall_apis/saas-app-and-device-management-apis)

## Capabilities

This operation supports [pagination](../README.md#pagination).
