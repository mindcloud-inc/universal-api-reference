# Get Annotation with Nightfall.ai

Retrieves an annotation from Nightfall.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/dlp/v1/annotations/:annotationId`
- **Base URL:** `https://api.nightfall.ai`
- **Official documentation:** [Get Annotation](https://help.nightfall.ai/developer-api/nightfall_apis/saas)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `annotationId` | path | `string` | yes | The UUID of the annotation to fetch. |
