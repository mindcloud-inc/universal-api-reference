# List Posture Events with Nightfall.ai

Retrieves posture events from Nightfall.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/posture/v1/events`
- **Base URL:** `https://api.nightfall.ai`
- **Official documentation:** [List Posture Events](https://help.nightfall.ai/developer-api/nightfall_apis/posture-management-apis)

## Capabilities

This operation supports [pagination](../README.md#pagination).
