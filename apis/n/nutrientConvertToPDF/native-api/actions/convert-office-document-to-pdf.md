# Convert Office Document to PDF with Nutrient - Convert to PDF

Creates a PDF document from an Office file in Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/processor/convert_to_pdf`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Convert Office Document to PDF](https://www.nutrient.io/api/office-to-pdf-api/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/vnd.openxmlformats-officedocument.wordprocessingml.document` |
