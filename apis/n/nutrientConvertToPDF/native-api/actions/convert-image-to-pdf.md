# Convert Image to PDF with Nutrient - Convert to PDF

Creates a PDF document from an image in Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/processor/convert_to_pdf`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Convert Image to PDF](https://www.nutrient.io/api/image-to-pdf-api/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `image/png` |
