# Convert HTML File to PDF with Nutrient - Convert to PDF

Creates a PDF document from an HTML file in Nutrient.

## Endpoint

- **Method:** `POST`
- **Path:** `/processor/generate_pdf`
- **Base URL:** `https://api.nutrient.io`
- **Official documentation:** [Convert HTML File to PDF](https://www.nutrient.io/api/html-to-pdf-api/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |
