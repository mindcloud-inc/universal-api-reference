# List Appointments with Néctar CRM

Retrieves appointments from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/compromissos/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Appointments](https://nectarcrm.docs.apiary.io/#reference/0/compromissos/listar)

## Capabilities

This operation supports [pagination](../README.md#pagination).
