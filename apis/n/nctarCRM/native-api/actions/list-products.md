# List Products with Néctar CRM

Retrieves products from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/produto/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Products](https://nectarcrm.docs.apiary.io/#reference/0/produtos/listar)

## Capabilities

This operation supports [pagination](../README.md#pagination).
