# List Opportunities with Néctar CRM

Retrieves opportunities from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/oportunidades/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Opportunities](https://nectarcrm.docs.apiary.io/#reference/0/oportunidades/listar)

## Capabilities

This operation supports [pagination](../README.md#pagination).
