# Get Appointment with Néctar CRM

Retrieves an appointment from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/compromissos/:id`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [Get Appointment](https://nectarcrm.docs.apiary.io/#reference/0/compromissos/consultar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Appointment ID. |
