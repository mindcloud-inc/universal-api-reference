# List Tasks with Néctar CRM

Retrieves tasks from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/tarefas/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Tasks](https://nectarcrm.docs.apiary.io/#reference/0/tarefas/listar)

## Capabilities

This operation supports [pagination](../README.md#pagination).
