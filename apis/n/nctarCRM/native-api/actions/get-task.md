# Get Task with Néctar CRM

Retrieves a task from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/tarefas/:id`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [Get Task](https://nectarcrm.docs.apiary.io/#reference/0/tarefas/consultar)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Task ID. |
