# List Qualifications with Néctar CRM

Retrieves qualifications from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/qualificacoes/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Qualifications](https://nectarcrm.docs.apiary.io/#reference/0/qualificacoes/listar)

## Capabilities

This operation supports [pagination](../README.md#pagination).
