# Get Contact with Néctar CRM

Retrieves a contact from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contatos/:id`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [Get Contact](https://nectarcrm.docs.apiary.io/#reference/0/contatos/consultar-por-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Contact ID. |
