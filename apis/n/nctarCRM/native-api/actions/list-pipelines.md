# List Pipelines with Néctar CRM

Retrieves pipelines from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipeline/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Pipelines](https://nectarcrm.docs.apiary.io/#reference/0/pipeline/listar-funil)
