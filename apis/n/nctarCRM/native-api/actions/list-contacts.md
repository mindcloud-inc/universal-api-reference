# List Contacts with Néctar CRM

Retrieves contacts from Néctar CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contatos/`
- **Base URL:** `https://app.nectarcrm.com.br/crm/api/1`
- **Official documentation:** [List Contacts](https://nectarcrm.docs.apiary.io/#reference/0/contatos/listar-contatos)

## Capabilities

This operation supports [pagination](../README.md#pagination).
