# Create Chat Completion (mistralai/mistral-large-2-instruct) with NVIDIA

Creates a chat completion in NVIDIA using mistralai/mistral-large-2-instruct.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://integrate.api.nvidia.com`
- **Official documentation:** [Create Chat Completion (mistralai/mistral-large-2-instruct)](https://docs.api.nvidia.com/nim/reference/llm-apis)
