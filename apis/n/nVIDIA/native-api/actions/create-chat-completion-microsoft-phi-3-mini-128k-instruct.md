# Create Chat Completion (microsoft/phi-3-mini-128k-instruct) with NVIDIA

Creates a chat completion in NVIDIA using microsoft/phi-3-mini-128k-instruct.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://integrate.api.nvidia.com`
- **Official documentation:** [Create Chat Completion (microsoft/phi-3-mini-128k-instruct)](https://docs.api.nvidia.com/nim/reference/llm-apis)
