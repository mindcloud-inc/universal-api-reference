# Create Chat Completion (google/shieldgemma-9b) with NVIDIA

Creates a chat completion in NVIDIA using google/shieldgemma-9b.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://integrate.api.nvidia.com`
- **Official documentation:** [Create Chat Completion (google/shieldgemma-9b)](https://docs.api.nvidia.com/nim/reference/llm-apis)
