# Create Chat Completion (deepseek-ai/deepseek-v3.2) with NVIDIA

Creates a chat completion in NVIDIA using deepseek-ai/deepseek-v3.2.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://integrate.api.nvidia.com`
- **Official documentation:** [Create Chat Completion (deepseek-ai/deepseek-v3.2)](https://docs.api.nvidia.com/nim/reference/llm-apis)
