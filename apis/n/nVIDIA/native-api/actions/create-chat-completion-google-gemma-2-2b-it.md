# Create Chat Completion (google/gemma-2-2b-it) with NVIDIA

Creates a chat completion in NVIDIA using google/gemma-2-2b-it.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/chat/completions`
- **Base URL:** `https://integrate.api.nvidia.com`
- **Official documentation:** [Create Chat Completion (google/gemma-2-2b-it)](https://docs.api.nvidia.com/nim/reference/llm-apis)
