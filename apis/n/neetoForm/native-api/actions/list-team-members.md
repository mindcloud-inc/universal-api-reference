# List Team Members with NeetoForm

Retrieves team members from a NeetoForm workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/team_members`
- **Base URL:** `https://{workspaceSubdomain}.neetoform.com/api/external/v1`
- **Official documentation:** [List Team Members](https://apidocs.neetoform.com/api-reference/team-members/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
