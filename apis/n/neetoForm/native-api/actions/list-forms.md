# List Forms with NeetoForm

Retrieves forms from a NeetoForm workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://{workspaceSubdomain}.neetoform.com/api/external/v1`
- **Official documentation:** [List Forms](https://apidocs.neetoform.com/api-reference/forms/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
