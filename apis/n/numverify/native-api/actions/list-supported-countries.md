# List Supported Countries with Numverify

Retrieves supported countries and dialing codes from Numverify.

## Endpoint

- **Method:** `GET`
- **Path:** `/countries`
- **Base URL:** `https://apilayer.net/api`
- **Official documentation:** [List Supported Countries](https://docs.apilayer.com/numverify/docs/numverify-api-v-1-0-0)
