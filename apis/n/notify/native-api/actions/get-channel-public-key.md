# Get Channel Public Key with Notify

Retrieves the channel public key from Notify.

## Endpoint

- **Method:** `GET`
- **Path:** `/:channelId/json`
- **Base URL:** `https://notify.run`
- **Official documentation:** [Get Channel Public Key](https://notify.run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | no | A Notify channel token or ID. |
