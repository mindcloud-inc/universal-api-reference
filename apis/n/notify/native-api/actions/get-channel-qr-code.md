# Get Channel QR Code with Notify

Retrieves the channel QR code from Notify.

## Endpoint

- **Method:** `GET`
- **Path:** `/:channelId/qr.svg`
- **Base URL:** `https://notify.run`
- **Official documentation:** [Get Channel QR Code](https://notify.run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | no | A Notify channel token or ID. |
