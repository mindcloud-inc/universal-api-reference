# List Channel Messages with Notify

Retrieves channel messages from Notify.

## Endpoint

- **Method:** `GET`
- **Path:** `/:channelId/json`
- **Base URL:** `https://notify.run`
- **Official documentation:** [List Channel Messages](https://notify.run)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `string` | no | A Notify channel token or ID. |
