# List Route Configs with NextBus

Retrieves route configurations from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [List Route Configs](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=8)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
