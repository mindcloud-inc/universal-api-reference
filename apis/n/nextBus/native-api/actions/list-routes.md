# List Routes with NextBus

Retrieves routes for an agency from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [List Routes](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `a` | query | `string` | yes | Agency tag from List Agencies. |
