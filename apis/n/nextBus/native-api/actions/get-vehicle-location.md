# Get Vehicle Location with NextBus

Retrieves a vehicle location from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [Get Vehicle Location](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=21)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
| `v` | query | `string` | yes |
