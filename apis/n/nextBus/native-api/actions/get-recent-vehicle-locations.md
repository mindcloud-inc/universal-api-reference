# Get Recent Vehicle Locations with NextBus

Retrieves recent vehicle locations from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [Get Recent Vehicle Locations](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=20)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
| `r` | query | `string` | yes |
