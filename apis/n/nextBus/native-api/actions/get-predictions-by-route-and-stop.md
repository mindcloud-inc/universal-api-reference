# Get Predictions By Route And Stop with NextBus

Retrieves stop predictions from NextBus by route and stop.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [Get Predictions By Route And Stop](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=14)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
| `r` | query | `string` | yes |
| `s` | query | `string` | yes |
