# Get Route Schedule with NextBus

Retrieves a route schedule from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [Get Route Schedule](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=16)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
| `r` | query | `string` | yes |
