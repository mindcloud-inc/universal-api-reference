# List Active Messages For Route with NextBus

Retrieves active route messages from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [List Active Messages For Route](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=18)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
| `r` | query | `string` | yes |
