# List Active Messages with NextBus

Retrieves active messages from NextBus.

## Endpoint

- **Method:** `GET`
- **Path:** `/publicXMLFeed`
- **Base URL:** `https://retro.umoiq.com/service`
- **Official documentation:** [List Active Messages](https://retro.umoiq.com/xmlFeedDocs/NextBusXMLFeed.pdf#page=18)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `a` | query | `string` | yes |
