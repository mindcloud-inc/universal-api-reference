# Retrieve Block with Notion

Retrieves details for a block from Notion.

## Endpoint

- **Method:** `GET`
- **Path:** `/blocks/:block_id`
- **Base URL:** `https://api.notion.com/v1`
- **Official documentation:** [Retrieve Block](https://developers.notion.com/reference/retrieve-a-block)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `block_id` | path | `string` | yes | ID of the block to retrieve. |
