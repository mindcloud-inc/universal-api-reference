# Get Workspace with Ninox

Retrieves a workspace from Ninox.

## Endpoint

- **Method:** `GET`
- **Path:** `teams/:teamid`
- **Base URL:** `https://api.ninox.com/v1`
- **Official documentation:** [Get Workspace](https://forum.ninox.com/t/35yzp89/api-endpoints-for-public-cloud)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamid` | path | `string` | yes | Workspace ID from the List Workspaces action. |
