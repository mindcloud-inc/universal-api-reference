# List Webhooks with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/webhook_definitions`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List Webhooks](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/webhooks/webhooks-collection)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Contentful space ID. |
