# Get Asset with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:space_id/environments/:environment_id/assets/:asset_id`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get Asset](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/assets/asset)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `string` | yes | Contentful space ID. |
| `environment_id` | path | `string` | yes | Contentful environment ID. |
| `asset_id` | path | `string` | yes | Contentful asset ID. |
