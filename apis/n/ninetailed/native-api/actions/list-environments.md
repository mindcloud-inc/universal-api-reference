# List Environments with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:space_id/environments`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List Environments](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environments/environment-collection)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `string` | yes | Contentful space ID. |
