# List Roles with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/roles`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List Roles](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/roles/roles-collection)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Contentful space ID. |
