# Get Organization with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organization_id`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get Organization](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/organizations/organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `string` | yes | Contentful organization ID. |
