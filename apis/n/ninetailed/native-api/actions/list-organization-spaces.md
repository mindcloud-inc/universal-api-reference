# List Organization Spaces with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:organizationId/spaces`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List Organization Spaces](https://www.contentful.com/developers/docs/references/content-management-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organizationId` | path | `string` | yes | Contentful organization ID whose spaces should be listed. |
