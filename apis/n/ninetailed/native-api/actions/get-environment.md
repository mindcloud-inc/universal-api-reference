# Get Environment with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:space_id/environments/:environment_id`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get Environment](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/environments/environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `string` | yes | Contentful space ID. |
| `environment_id` | path | `string` | yes | Contentful environment ID or alias. |
