# Get Space with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:space_id`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [Get Space](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/spaces/space)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `string` | yes | Contentful space ID. |
