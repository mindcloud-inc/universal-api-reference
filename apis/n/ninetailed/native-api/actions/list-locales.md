# List Locales with Ninetailed

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:space_id/environments/:environment_id/locales`
- **Base URL:** `https://api.contentful.com`
- **Official documentation:** [List Locales](https://www.contentful.com/developers/docs/references/content-management-api/#/reference/locales/locale-collection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `space_id` | path | `string` | yes | Contentful space ID. |
| `environment_id` | path | `string` | yes | Contentful environment ID. |
