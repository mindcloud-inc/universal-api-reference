# Get Contact with Nutshell

Retrieves a contact from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [Get Contact](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell contact ID. |
