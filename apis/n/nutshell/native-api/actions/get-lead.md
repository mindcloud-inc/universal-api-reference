# Get Lead with Nutshell

Retrieves a lead from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:id`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [Get Lead](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell lead ID. |
