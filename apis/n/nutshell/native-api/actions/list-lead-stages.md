# List Lead Stages with Nutshell

Retrieves a lead's stages from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/leads/:id/stages`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [List Lead Stages](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell lead ID. |
