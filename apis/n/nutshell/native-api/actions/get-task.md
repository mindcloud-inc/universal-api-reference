# Get Task with Nutshell

Retrieves a task from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [Get Task](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell task ID. |
