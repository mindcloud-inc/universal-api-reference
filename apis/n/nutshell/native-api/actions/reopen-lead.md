# Reopen Lead with Nutshell

Reopens a closed lead in Nutshell.

## Endpoint

- **Method:** `POST`
- **Path:** `/leads/:id/reopen`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [Reopen Lead](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell lead ID to reopen. |
