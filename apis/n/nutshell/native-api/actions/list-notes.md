# List Notes with Nutshell

Retrieves notes from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/notes`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [List Notes](https://developers.nutshell.com/reference)

## Capabilities

This operation supports [pagination](../README.md#pagination).
