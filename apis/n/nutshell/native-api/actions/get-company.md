# Get Company with Nutshell

Retrieves a company from Nutshell.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:id`
- **Base URL:** `https://app.nutshell.com/rest`
- **Official documentation:** [Get Company](https://developers.nutshell.com/reference)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Nutshell account ID. |
