# List Browser Applications with New Relic

Retrieves browser applications from New Relic.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser_applications.json`
- **Base URL:** `https://api.newrelic.com/v2`
- **Official documentation:** [List Browser Applications](https://docs.newrelic.com/docs/apis/rest-api-v2/browser-examples-v2/add-or-list-browser-apps-api-v2/)
