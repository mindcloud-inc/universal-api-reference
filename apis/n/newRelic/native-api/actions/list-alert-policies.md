# List Alert Policies with New Relic

Retrieves alert policies from New Relic.

## Endpoint

- **Method:** `GET`
- **Path:** `/alerts_policies.json`
- **Base URL:** `https://api.newrelic.com/v2`
- **Official documentation:** [List Alert Policies](https://docs.newrelic.com/docs/alerts/scale-automate/rest-api/rest-api-calls-alerts/)
