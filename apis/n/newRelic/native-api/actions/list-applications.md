# List Applications with New Relic

Retrieves applications from New Relic.

## Endpoint

- **Method:** `GET`
- **Path:** `/applications.json`
- **Base URL:** `https://api.newrelic.com/v2`
- **Official documentation:** [List Applications](https://docs.newrelic.com/docs/apis/rest-api-v2/application-examples-v2/list-your-app-id-metric-timeslice-data-v2/)
