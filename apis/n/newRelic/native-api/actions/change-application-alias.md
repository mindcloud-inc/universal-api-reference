# Change Application Alias with New Relic

Updates an application alias in New Relic.

## Endpoint

- **Method:** `PUT`
- **Path:** `/applications/:appId.json`
- **Base URL:** `https://api.newrelic.com/v2`
- **Official documentation:** [Change Application Alias](https://docs.newrelic.com/docs/apis/rest-api-v2/application-examples-v2/change-alias-your-application-v2/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appId` | path | `number` | yes | New Relic application ID. |
