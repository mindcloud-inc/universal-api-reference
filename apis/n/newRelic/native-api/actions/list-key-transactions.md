# List Key Transactions with New Relic

Retrieves key transactions from New Relic.

## Endpoint

- **Method:** `GET`
- **Path:** `/key_transactions.json`
- **Base URL:** `https://api.newrelic.com/v2`
- **Official documentation:** [List Key Transactions](https://docs.newrelic.com/docs/apis/rest-api-v2/application-examples-v2/summary-data-examples-v2/)
