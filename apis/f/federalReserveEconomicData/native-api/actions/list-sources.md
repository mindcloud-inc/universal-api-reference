# List Sources with Federal Reserve Economic Data

Retrieves sources from Federal Reserve Economic Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/fred/sources`
- **Base URL:** `https://api.stlouisfed.org`
- **Official documentation:** [List Sources](https://fred.stlouisfed.org/docs/api/fred/sources.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
