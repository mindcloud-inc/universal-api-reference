# List Releases with Federal Reserve Economic Data

Retrieves releases from Federal Reserve Economic Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/fred/releases`
- **Base URL:** `https://api.stlouisfed.org`
- **Official documentation:** [List Releases](https://fred.stlouisfed.org/docs/api/fred/releases.html)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
