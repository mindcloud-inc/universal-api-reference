# List Category Children with Federal Reserve Economic Data

Retrieves child categories from Federal Reserve Economic Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/fred/category/children`
- **Base URL:** `https://api.stlouisfed.org`
- **Official documentation:** [List Category Children](https://fred.stlouisfed.org/docs/api/fred/category_children.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | query | `number` | no | The id for a category. |
