# Get Category with Federal Reserve Economic Data

Retrieves a category from Federal Reserve Economic Data.

## Endpoint

- **Method:** `GET`
- **Path:** `/fred/category`
- **Base URL:** `https://api.stlouisfed.org`
- **Official documentation:** [Get Category](https://fred.stlouisfed.org/docs/api/fred/category.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | query | `number` | no | The id for a category. |
