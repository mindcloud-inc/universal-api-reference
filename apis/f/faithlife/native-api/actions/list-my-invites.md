# List My Invites with Faithlife

Retrieves the current user's invites from Faithlife.

## Endpoint

- **Method:** `GET`
- **Path:** `/invites`
- **Base URL:** `https://accountsapi.logos.com/v2`
- **Official documentation:** [List My Invites](https://developer.faithlife.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
