# Search Groups with Faithlife

Finds groups in Faithlife.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://accountsapi.logos.com/v2`
- **Official documentation:** [Search Groups](https://developer.faithlife.com/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Search text used to find groups. |
