# Delete Membership with Faithlife

Deletes a group membership from Faithlife.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/memberships/:membershipId`
- **Base URL:** `https://accountsapi.logos.com/v2`
- **Official documentation:** [Delete Membership](https://developer.faithlife.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `membershipId` | path | `string` | yes | The Faithlife membership ID to delete. |
