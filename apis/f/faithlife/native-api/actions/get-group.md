# Get Group with Faithlife

Retrieves a group from Faithlife.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://accountsapi.logos.com/v2`
- **Official documentation:** [Get Group](https://developer.faithlife.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The Faithlife group ID or token to retrieve. |
