# Get User with Faithlife

Retrieves a user from Faithlife.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://accountsapi.logos.com/v2`
- **Official documentation:** [Get User](https://developer.faithlife.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The Faithlife user ID or token to retrieve. |
