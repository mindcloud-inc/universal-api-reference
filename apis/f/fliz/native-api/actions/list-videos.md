# List videos with Fliz

Retrieves videos from your Fliz account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/videos`
- **Base URL:** `https://app.fliz.ai`
- **Official documentation:** [List videos](https://app.fliz.ai/api-docs)

## Capabilities

This operation supports [pagination](../README.md#pagination).
