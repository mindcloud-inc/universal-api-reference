# Get video with Fliz

Retrieves a video from your Fliz account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/rest/videos/:id`
- **Base URL:** `https://app.fliz.ai`
- **Official documentation:** [Get video](https://app.fliz.ai/api-docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The UUID of the video to retrieve. |
