# Get Component with Figma

Retrieves a component from Figma by key.

## Endpoint

- **Method:** `GET`
- **Path:** `/components/:key`
- **Base URL:** `https://api.figma.com/v1`
- **Official documentation:** [Get Component](https://developers.figma.com/docs/rest-api/component-endpoints/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | The unique key of the component. |
