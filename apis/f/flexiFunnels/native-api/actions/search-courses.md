# Search Courses with FlexiFunnels

Searches courses in FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/searchcourselist`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Search Courses](https://bridge.flexifunnels.com/docs#course-endpoints-POSTapi-searchcourselist)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search_name` | body | `string` | yes | Course search string. |
