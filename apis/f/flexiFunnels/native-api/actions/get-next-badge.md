# Get Next Badge with FlexiFunnels

Retrieves the next badge from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/get-next-badge`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Next Badge](https://bridge.flexifunnels.com/docs#gamification-endpoints-POSTapi-get-next-badge)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `funnel_page_id` | body | `number` | yes |
| `course_id` | body | `number` | yes |
| `lesson_id` | body | `number` | yes |
