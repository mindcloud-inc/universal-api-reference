# Get Custom Script with FlexiFunnels

Retrieves custom script content from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/customscript`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Custom Script](https://bridge.flexifunnels.com/docs#auth-user-endpoints-POSTapi-customscript)
