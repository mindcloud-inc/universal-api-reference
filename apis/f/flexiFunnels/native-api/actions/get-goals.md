# Get Goals with FlexiFunnels

Retrieves goals from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/goallist`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Goals](https://bridge.flexifunnels.com/docs#gamification-endpoints-POSTapi-goallist)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `funnel_page_id` | body | `number` | yes |
| `course_id` | body | `number` | yes |
| `lesson_id` | body | `number` | yes |
