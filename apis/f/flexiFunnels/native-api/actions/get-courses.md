# Get Courses with FlexiFunnels

Retrieves courses from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/courselist`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Courses](https://bridge.flexifunnels.com/docs#course-endpoints-POSTapi-courselist)
