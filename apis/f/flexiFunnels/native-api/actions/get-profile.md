# Get Profile with FlexiFunnels

Retrieves the authenticated member profile from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/profile`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Profile](https://bridge.flexifunnels.com/docs#auth-user-endpoints-POSTapi-profile)
