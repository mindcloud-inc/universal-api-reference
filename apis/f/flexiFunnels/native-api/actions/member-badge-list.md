# Member Badge List with FlexiFunnels

Retrieves member badges from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/member-badge-list`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Member Badge List](https://bridge.flexifunnels.com/docs#gamification-endpoints-POSTapi-member-badge-list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `funnel_page_id` | body | `number` | yes |
| `course_id` | body | `number` | yes |
| `lesson_id` | body | `number` | yes |
