# Get Footer with FlexiFunnels

Retrieves footer content from FlexiFunnels.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/get-footer`
- **Base URL:** `https://bridge.flexifunnels.com`
- **Official documentation:** [Get Footer](https://bridge.flexifunnels.com/docs#auth-user-endpoints-POSTapi-get-footer)
