# Get Root Folder Meta with Feishu Drive

Retrieves root folder metadata from Feishu Drive.

## Endpoint

- **Method:** `GET`
- **Path:** `/drive/explorer/v2/root_folder/meta`
- **Base URL:** `https://open.feishu.cn/open-apis`
- **Official documentation:** [Get Root Folder Meta](https://open.feishu.cn/document/ukTMukTMukTM/ugTNzUjL4UzM14CO1MTN/get-root-folder-meta)
