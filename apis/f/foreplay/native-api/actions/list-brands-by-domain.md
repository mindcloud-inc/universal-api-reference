# List Brands by Domain with Foreplay

Finds Foreplay brands by advertising domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/brand/getBrandsByDomain`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Brands by Domain](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain` | query | `string` | no | The domain to look up brands for. |
