# List Brand Ads by Brand ID with Foreplay

Retrieves ads for one or more Foreplay brand IDs.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/brand/getAdsByBrandId`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Brand Ads by Brand ID](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brand_ids` | query | `string` | no | One or more brand IDs to retrieve ads for. |
