# Discover Brands by Ads with Foreplay

Finds brands in Foreplay by ad characteristics.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/discovery/brands/explore`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Discover Brands by Ads](https://public.api.foreplay.co/openapi.json)
