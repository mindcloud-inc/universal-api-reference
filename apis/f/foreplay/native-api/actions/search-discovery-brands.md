# Search Discovery Brands with Foreplay

Finds brands in Foreplay's discovery index.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/discovery/brands`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Search Discovery Brands](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | The brand search query. |
