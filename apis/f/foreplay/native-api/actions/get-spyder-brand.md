# Get Spyder Brand with Foreplay

Retrieves a tracked Spyder brand from Foreplay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/spyder/brand`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Get Spyder Brand](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brand_id` | query | `string` | no | The brand ID to retrieve. |
