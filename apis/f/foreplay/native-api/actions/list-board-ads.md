# List Board Ads with Foreplay

Retrieves ads from a specific Foreplay board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/board/ads`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Board Ads](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | query | `string` | no | Board ID to search for. |
