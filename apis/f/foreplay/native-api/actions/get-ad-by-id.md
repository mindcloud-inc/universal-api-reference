# Get Ad by ID with Foreplay

Retrieves a Foreplay ad by internal ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ad/{ad_id}`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Get Ad by ID](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ad_id` | path | `string` | no | The ad ID to retrieve. |
