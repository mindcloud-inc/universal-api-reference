# Get Ad with Foreplay

Retrieves a Foreplay ad by public ad ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ad`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Get Ad](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ad_id` | query | `string` | no | The ad ID to retrieve. |
