# List Ad Duplicates with Foreplay

Retrieves ads in Foreplay sharing an ad's creative.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/ad/duplicates/{ad_id}`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Ad Duplicates](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ad_id` | path | `string` | no | The ad ID to retrieve duplicates for. |
