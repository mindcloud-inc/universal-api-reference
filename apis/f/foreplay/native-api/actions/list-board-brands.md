# List Board Brands with Foreplay

Retrieves brands from a specific Foreplay board.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/board/brands`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Board Brands](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `board_id` | query | `string` | no | The ID of the board to retrieve brands from. |
