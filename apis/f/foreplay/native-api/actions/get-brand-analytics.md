# Get Brand Analytics with Foreplay

Retrieves brand analytics data from Foreplay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/brand/analytics`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [Get Brand Analytics](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The brand or page identifier to analyze. |
