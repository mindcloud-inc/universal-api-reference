# List Spyder Brand Ads with Foreplay

Retrieves ads for a tracked Spyder brand in Foreplay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/spyder/brand/ads`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Spyder Brand Ads](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `brand_id` | query | `string` | no | The brand ID to retrieve ads for. |
