# List Brand Ads by Page ID with Foreplay

Retrieves ads for a Facebook page ID in Foreplay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/brand/getAdsByPageId`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Brand Ads by Page ID](https://public.api.foreplay.co/openapi.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page_id` | query | `string` | no | The page ID to retrieve ads for. |
