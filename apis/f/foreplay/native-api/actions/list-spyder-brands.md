# List Spyder Brands with Foreplay

Retrieves your tracked Spyder brands from Foreplay.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/spyder/brands`
- **Base URL:** `https://public.api.foreplay.co`
- **Official documentation:** [List Spyder Brands](https://public.api.foreplay.co/openapi.json)
