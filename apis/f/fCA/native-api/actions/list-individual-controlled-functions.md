# List individual controlled functions with FCA

## Endpoint

- **Method:** `GET`
- **Path:** `/Individuals/:irn/CF`
- **Base URL:** `https://register.fca.org.uk/services/V0.1`
- **Official documentation:** [List individual controlled functions](https://register.fca.org.uk/Developer/s/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `irn` | path | `string` | yes | FCA individual reference number. |
