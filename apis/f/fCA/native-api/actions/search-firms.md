# Search firms with FCA

## Endpoint

- **Method:** `GET`
- **Path:** `/Search`
- **Base URL:** `https://register.fca.org.uk/services/V0.1`
- **Official documentation:** [Search firms](https://register.fca.org.uk/Developer/s/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | yes | Firm name or firm name fragment to search for. |
