# List firm requirements with FCA

## Endpoint

- **Method:** `GET`
- **Path:** `/Firm/:frn/Requirements`
- **Base URL:** `https://register.fca.org.uk/services/V0.1`
- **Official documentation:** [List firm requirements](https://register.fca.org.uk/Developer/s/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `frn` | path | `string` | yes | FCA firm reference number. |
