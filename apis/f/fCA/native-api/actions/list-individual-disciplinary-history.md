# List individual disciplinary history with FCA

## Endpoint

- **Method:** `GET`
- **Path:** `/Individuals/:irn/DisciplinaryHistory`
- **Base URL:** `https://register.fca.org.uk/services/V0.1`
- **Official documentation:** [List individual disciplinary history](https://register.fca.org.uk/Developer/s/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `irn` | path | `string` | yes | FCA individual reference number. |
