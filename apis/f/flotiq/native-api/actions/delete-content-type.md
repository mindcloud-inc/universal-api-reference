# Delete Content Type with Flotiq

Deletes an existing content type from Flotiq.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/internal/contenttype/{{id}}`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Delete Content Type](https://flotiq.com/docs/API/content-types/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Flotiq content type ID. |
