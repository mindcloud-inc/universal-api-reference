# Get GraphQL Schema with Flotiq

Retrieves the GraphQL schema from Flotiq.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.flotiq.com/api/v2/graphql/schema`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Get GraphQL Schema](https://flotiq.com/docs/API/graph-ql/)
