# Get Auth Context with Flotiq

Retrieves your current Flotiq authentication context.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.flotiq.com/api/auth-context`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Get Auth Context](https://flotiq.com/docs/API/get-started/)
