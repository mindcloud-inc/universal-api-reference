# Batch Patch Media Objects with Flotiq

Updates multiple media objects in Flotiq.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/content/_media/batch`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Batch Patch Media Objects](https://flotiq.com/docs/API/media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The batch patch payload for media objects. |
