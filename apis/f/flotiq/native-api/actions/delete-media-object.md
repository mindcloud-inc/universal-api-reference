# Delete Media Object with Flotiq

Deletes an existing media object from Flotiq.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/content/_media/{{id}}`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Delete Media Object](https://flotiq.com/docs/API/media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Flotiq media object ID. |
