# Create Content Type with Flotiq

Creates a new content type in Flotiq.

## Endpoint

- **Method:** `POST`
- **Path:** `/internal/contenttype`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Create Content Type](https://flotiq.com/docs/API/content-types/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The content type definition payload. |
