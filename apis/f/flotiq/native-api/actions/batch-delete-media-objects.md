# Batch Delete Media Objects with Flotiq

Deletes multiple media objects from Flotiq.

## Endpoint

- **Method:** `POST`
- **Path:** `/content/_media/batch-delete`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [Batch Delete Media Objects](https://flotiq.com/docs/API/media/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | yes | The batch delete payload for media objects. |
