# List Media Objects with Flotiq

Retrieves media objects from your Flotiq project.

## Endpoint

- **Method:** `GET`
- **Path:** `/content/_media`
- **Base URL:** `https://api.flotiq.com/api/v1`
- **Official documentation:** [List Media Objects](https://flotiq.com/docs/API/media/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
