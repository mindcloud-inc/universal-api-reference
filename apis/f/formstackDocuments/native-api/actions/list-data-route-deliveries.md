# List Data Route Deliveries with Formstack Documents

Retrieves data route deliveries from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes/:id/deliveries`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [List Data Route Deliveries](https://www.webmerge.me/developers/routes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the data route to list deliveries for |
