# List Data Route Fields with Formstack Documents

Retrieves data route fields from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes/:id/fields`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [List Data Route Fields](https://www.webmerge.me/developers/routes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The data route ID. |
