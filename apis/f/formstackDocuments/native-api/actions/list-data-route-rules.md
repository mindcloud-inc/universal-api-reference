# List Data Route Rules with Formstack Documents

Retrieves data route rules from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes/:id/rules`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [List Data Route Rules](https://www.webmerge.me/developers/routes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The data route ID. |
