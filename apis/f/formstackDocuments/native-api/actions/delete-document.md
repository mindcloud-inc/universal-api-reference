# Delete Document with Formstack Documents

Deletes an existing document from Formstack Documents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:id`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [Delete Document](https://www.webmerge.me/developers/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the document to delete |
