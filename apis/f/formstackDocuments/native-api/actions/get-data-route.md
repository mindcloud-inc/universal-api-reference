# Get Data Route with Formstack Documents

Retrieves data route details from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/routes/:id`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [Get Data Route](https://www.webmerge.me/developers/routes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The data route ID. |
