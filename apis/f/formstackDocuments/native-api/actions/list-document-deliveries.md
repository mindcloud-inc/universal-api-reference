# List Document Deliveries with Formstack Documents

Retrieves document deliveries from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/deliveries`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [List Document Deliveries](https://www.webmerge.me/developers/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The document ID. |
