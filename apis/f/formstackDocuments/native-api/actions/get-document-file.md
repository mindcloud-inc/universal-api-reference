# Get Document File with Formstack Documents

Retrieves a document file from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id/file`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [Get Document File](https://www.webmerge.me/developers/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The document ID. |
