# Delete Data Route with Formstack Documents

Deletes an existing data route from Formstack Documents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/routes/:id`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [Delete Data Route](https://www.webmerge.me/developers/routes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | ID of the data route to delete |
