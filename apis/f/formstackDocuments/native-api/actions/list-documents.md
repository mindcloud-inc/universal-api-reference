# List Documents with Formstack Documents

Retrieves a list of documents from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [List Documents](https://www.webmerge.me/developers/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folder` | query | `string` | no | Return documents in this folder name. |
| `search` | query | `string` | no | Return documents matching this search term. |
