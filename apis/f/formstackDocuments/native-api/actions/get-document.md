# Get Document with Formstack Documents

Retrieves document details from Formstack Documents.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://www.webmerge.me/api`
- **Official documentation:** [Get Document](https://www.webmerge.me/developers/documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The document ID. |
