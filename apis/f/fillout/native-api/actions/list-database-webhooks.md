# List Database Webhooks with Fillout

Retrieves database webhooks from Fillout.

## Endpoint

- **Method:** `GET`
- **Path:** `https://tables.fillout.com/api/v1/bases/:databaseId/webhooks`
- **Base URL:** `https://api.fillout.com/v1/api`
- **Official documentation:** [List Database Webhooks](https://fillout.com/help/database/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The database identifier. |
