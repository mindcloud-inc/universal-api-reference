# Get Database By Id with Fillout

Retrieves a database from Fillout by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `https://tables.fillout.com/api/v1/bases/:databaseId`
- **Base URL:** `https://api.fillout.com/v1/api`
- **Official documentation:** [Get Database By Id](https://fillout.com/help/database/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The database identifier. |
