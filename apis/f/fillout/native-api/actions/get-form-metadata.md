# Get Form Metadata with Fillout

Retrieves form metadata from Fillout.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId`
- **Base URL:** `https://api.fillout.com/v1/api`
- **Official documentation:** [Get Form Metadata](https://fillout.com/help/api-reference/get-form-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The public identifier of the form. |
