# Delete Database with Fillout

Deletes a database from Fillout.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://tables.fillout.com/api/v1/bases/:databaseId`
- **Base URL:** `https://api.fillout.com/v1/api`
- **Official documentation:** [Delete Database](https://fillout.com/help/database/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The database identifier. |
