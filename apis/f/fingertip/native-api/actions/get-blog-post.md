# Get Blog Post with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/blog-posts/:blogPostId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Blog Post](https://docs.fingertip.com/openapi-specs/get-blog-post.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `blogPostId` | path | `string` | yes | ID of the blog post to retrieve. |
