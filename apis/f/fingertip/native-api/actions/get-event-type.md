# Get Event Type with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event-types/:eventTypeId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Event Type](https://docs.fingertip.com/openapi-specs/get-event-type.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventTypeId` | path | `string` | yes | ID of the event type to retrieve. |
