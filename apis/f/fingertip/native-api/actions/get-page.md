# Get Page with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pages/:pageId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Page](https://docs.fingertip.com/openapi-specs/get-page)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the page to retrieve |
