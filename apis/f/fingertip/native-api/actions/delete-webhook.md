# Delete Webhook with Fingertip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Delete Webhook](https://docs.fingertip.com/openapi-specs/delete-webhook.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | ID of the webhook to delete. |
