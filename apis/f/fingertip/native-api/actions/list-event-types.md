# List Event Types with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/event-types`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Event Types](https://docs.fingertip.com/openapi-specs/list-event-types.md)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | query | `string` | yes | ID of the site to list event types for. |
