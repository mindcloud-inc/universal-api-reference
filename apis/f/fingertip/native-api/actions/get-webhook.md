# Get Webhook with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Webhook](https://docs.fingertip.com/openapi-specs/get-webhook.md)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | Webhook ID. |
