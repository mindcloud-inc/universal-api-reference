# List Site Memberships with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sites/:siteId/memberships`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Site Memberships](https://docs.fingertip.com/openapi-specs/list-site-memberships.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | ID of the site to list memberships for. |
