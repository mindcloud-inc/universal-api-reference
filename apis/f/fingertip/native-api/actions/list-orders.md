# List Orders with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/orders`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Orders](https://docs.fingertip.com/openapi-specs/list-orders.md)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `site` | query | `string` | yes | ID of the site to list orders for. |
