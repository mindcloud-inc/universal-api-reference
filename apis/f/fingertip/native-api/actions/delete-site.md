# Delete Site with Fingertip

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/sites/:siteId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Delete Site](https://docs.fingertip.com/openapi-specs/delete-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | ID of the site to delete |
