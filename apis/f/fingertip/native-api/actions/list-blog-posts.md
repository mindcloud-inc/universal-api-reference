# List Blog Posts with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/blog-posts`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Blog Posts](https://docs.fingertip.com/openapi-specs/list-blog-posts.md)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | query | `string` | yes | ID of the site to list blog posts for. |
