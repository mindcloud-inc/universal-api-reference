# List Blocks with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pages/:pageId/blocks`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Blocks](https://docs.fingertip.com/openapi-specs/list-blocks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the page to retrieve blocks for |
