# List Pages with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sites/:siteId/pages`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [List Pages](https://docs.fingertip.com/openapi-specs/list-pages)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | ID of the site to retrieve pages for |
