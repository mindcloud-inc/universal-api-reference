# Get Site with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sites/:siteId`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Site](https://docs.fingertip.com/openapi-specs/get-site)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `siteId` | path | `string` | yes | ID of the site to retrieve |
