# Get Page Theme with Fingertip

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/pages/:pageId/theme`
- **Base URL:** `https://api.fingertip.com`
- **Official documentation:** [Get Page Theme](https://docs.fingertip.com/openapi-specs/get-page-theme)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | ID of the page to retrieve the theme for |
