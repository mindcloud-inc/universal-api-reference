# List Chats with FuseDesk

Retrieves active chats from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/chats`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Chats](https://documenter.getpostman.com/view/11014835/SztBc8ix#28be6359-388d-4743-8d2c-f0009cb627ac)
