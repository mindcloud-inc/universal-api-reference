# Get Case with FuseDesk

Retrieves a case and its history from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/cases/:caseId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Case](https://documenter.getpostman.com/view/11014835/SztBc8ix#7fab000b-8f38-440c-bfa9-c9630e9af8c2)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `caseId` | path | `number` | yes |
