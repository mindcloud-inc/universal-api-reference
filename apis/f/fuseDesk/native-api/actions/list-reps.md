# List Reps with FuseDesk

Retrieves active and disabled reps from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/reps`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Reps](https://documenter.getpostman.com/view/11014835/SztBc8ix#c90bfd4d-9356-4f30-926d-38df875f1fab)
