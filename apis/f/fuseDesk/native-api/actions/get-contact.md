# Get Contact with FuseDesk

Retrieves a contact record from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/contacts/:contactId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Contact](https://documenter.getpostman.com/view/11014835/SztBc8ix#bd3381b3-f9e7-47eb-a516-f30756c55473)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contactId` | path | `string` | yes | The FuseDesk contact ID or UUID. |
