# List Archived Departments with FuseDesk

Retrieves archived departments from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/departments/archived`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Archived Departments](https://documenter.getpostman.com/view/11014835/SztBc8ix#05e66073-09b6-48ac-a341-89c2122b0002)
