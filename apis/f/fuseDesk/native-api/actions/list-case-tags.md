# List Case Tags with FuseDesk

Retrieves case tags from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/casetags`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Case Tags](https://documenter.getpostman.com/view/11014835/SztBc8ix#11e964aa-3203-4a83-92cb-42c79a682380)
