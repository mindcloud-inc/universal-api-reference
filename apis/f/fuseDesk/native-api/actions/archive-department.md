# Archive Department with FuseDesk

Archives an existing department in FuseDesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/departments/:departmentId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Archive Department](https://documenter.getpostman.com/view/11014835/SztBc8ix#8f716acb-8b49-422e-831b-57f39e737f86)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `number` | yes | The FuseDesk department ID. |
