# List Active Departments with FuseDesk

Retrieves active departments from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/departments`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Active Departments](https://documenter.getpostman.com/view/11014835/SztBc8ix#0c956f60-09e1-4cce-9a74-8ed477a786e2)
