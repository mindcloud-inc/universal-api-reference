# Get Email with FuseDesk

Retrieves an email record from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/emails/:emailId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Email](https://documenter.getpostman.com/view/11014835/SztBc8ix#7ad42157-6c3f-4962-bf2e-8aebbb4bb5bc)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailId` | path | `string` | yes | The FuseDesk email ID. |
