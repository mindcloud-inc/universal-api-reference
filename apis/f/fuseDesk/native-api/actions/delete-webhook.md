# Delete Webhook with FuseDesk

Deletes an existing webhook from FuseDesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/webhooks/:webhookId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Delete Webhook](https://documenter.getpostman.com/view/11014835/SztBc8ix#35aa02a4-9eaa-4194-a092-32959f5462e5)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The FuseDesk webhook ID. |
