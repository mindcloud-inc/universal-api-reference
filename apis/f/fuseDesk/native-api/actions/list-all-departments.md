# List All Departments with FuseDesk

Retrieves all departments from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/departments/all`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List All Departments](https://documenter.getpostman.com/view/11014835/SztBc8ix#6ce5c727-d6c9-470a-b9c7-179ee85e123f)
