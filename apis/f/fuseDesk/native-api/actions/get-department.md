# Get Department with FuseDesk

Retrieves a department record from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/departments/:departmentId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Department](https://documenter.getpostman.com/view/11014835/SztBc8ix#5f33b697-31eb-4ee1-8172-e8469a98a5d7)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `departmentId` | path | `number` | yes | The FuseDesk department ID. |
