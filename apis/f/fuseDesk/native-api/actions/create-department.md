# Create Department with FuseDesk

Creates a new department in FuseDesk.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/departments`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Create Department](https://documenter.getpostman.com/view/11014835/SztBc8ix#3d38c890-4ef6-4de7-8dc1-92395a3ed813)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Department name. |
