# Get Chat with FuseDesk

Retrieves a chat and its message history from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/chats/:chatId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Chat](https://documenter.getpostman.com/view/11014835/SztBc8ix#b5ca8abc-a274-4bae-9ca3-f04735e0fe72)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `chatId` | path | `string` | yes | The FuseDesk chat ID. |
