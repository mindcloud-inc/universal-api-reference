# List Webhooks with FuseDesk

Retrieves webhooks from your FuseDesk account.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/webhooks`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [List Webhooks](https://documenter.getpostman.com/view/11014835/SztBc8ix#e9fb9adb-726f-4af1-9f77-ad06f344c82a)
