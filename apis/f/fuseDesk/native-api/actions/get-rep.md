# Get Rep with FuseDesk

Retrieves a rep profile from FuseDesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/reps/:userId`
- **Base URL:** `https://{appName}.fusedesk.com`
- **Official documentation:** [Get Rep](https://documenter.getpostman.com/view/11014835/SztBc8ix#dd2745a5-1205-4043-b00a-324d7aff1b4f)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | The FuseDesk rep user ID. |
