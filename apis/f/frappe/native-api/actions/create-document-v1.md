# Create Document V1 with Frappe

Creates a new document in a Frappe DocType.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/resource/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Create Document V1](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/manipulating_documents)
