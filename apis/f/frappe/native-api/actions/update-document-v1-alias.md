# Update Document V1 Alias with Frappe

Updates a document in a Frappe DocType.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v1/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Update Document V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
