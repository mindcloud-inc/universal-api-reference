# Call Whitelisted Method V2 (GET) with Frappe

Calls a whitelisted Frappe method with GET.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/method/{{arguments.methodPath}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Call Whitelisted Method V2 (GET)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
