# Update Document V1 with Frappe

Updates a document in a Frappe DocType.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Update Document V1](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/manipulating_documents)
