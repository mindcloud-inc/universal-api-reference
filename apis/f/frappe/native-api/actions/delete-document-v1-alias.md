# Delete Document V1 Alias with Frappe

Deletes a document from a Frappe DocType.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Delete Document V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
