# Delete Document V1 with Frappe

Deletes a document from a Frappe DocType.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Delete Document V1](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/manipulating_documents)
