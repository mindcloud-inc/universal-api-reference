# List Documents V1 with Frappe

Lists documents from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/resource/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [List Documents V1](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/listing_documents)
