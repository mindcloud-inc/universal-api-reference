# Call DocType Controller Method V2 (GET) with Frappe

Calls a Frappe DocType controller method with GET.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/method/{{arguments.doctype}}/{{arguments.methodName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Call DocType Controller Method V2 (GET)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
