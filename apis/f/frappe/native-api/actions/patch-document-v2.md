# Patch Document V2 with Frappe

Updates a document in Frappe with PATCH.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Patch Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
