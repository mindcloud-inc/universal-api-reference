# Rename Document V2 with Frappe

Renames a document in a Frappe DocType.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/method/rename`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Rename Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
