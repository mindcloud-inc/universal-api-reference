# Run Document Method V2 (POST) with Frappe

Runs a method on a Frappe document with POST.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/method/{{arguments.methodName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Run Document Method V2 (POST)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
