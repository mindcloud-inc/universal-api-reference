# Run Doc Method RPC V2 with Frappe

Runs a whitelisted method on a Frappe document.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/method/run_doc_method`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Run Doc Method RPC V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
