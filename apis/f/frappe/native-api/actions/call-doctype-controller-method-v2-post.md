# Call DocType Controller Method V2 (POST) with Frappe

Calls a Frappe DocType controller method with POST.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/method/{{arguments.doctype}}/{{arguments.methodName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Call DocType Controller Method V2 (POST)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
