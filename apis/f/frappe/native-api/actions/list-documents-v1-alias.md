# List Documents V1 Alias with Frappe

Lists documents from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [List Documents V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
