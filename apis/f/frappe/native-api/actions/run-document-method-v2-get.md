# Run Document Method V2 (GET) with Frappe

Runs a method on a Frappe document with GET.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/method/{{arguments.methodName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Run Document Method V2 (GET)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
