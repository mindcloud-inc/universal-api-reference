# Get Document V1 Alias with Frappe

Retrieves a document from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get Document V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
