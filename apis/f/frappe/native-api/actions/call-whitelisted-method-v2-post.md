# Call Whitelisted Method V2 (POST) with Frappe

Calls a whitelisted Frappe method with POST.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/method/{{arguments.methodPath}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Call Whitelisted Method V2 (POST)](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
