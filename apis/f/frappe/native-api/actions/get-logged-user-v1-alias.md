# Get Logged User V1 Alias with Frappe

Retrieves the logged-in user from Frappe.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/method/frappe.auth.get_logged_user`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get Logged User V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
