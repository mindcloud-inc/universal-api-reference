# Put Document V2 with Frappe

Updates a document in Frappe with PUT.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Put Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
