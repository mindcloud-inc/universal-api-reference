# Create Document V2 with Frappe

Creates a new document in a Frappe DocType.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/document/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Create Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
