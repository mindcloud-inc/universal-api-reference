# Get DocType Metadata V2 with Frappe

Retrieves metadata for a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/doctype/{{arguments.doctype}}/meta`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get DocType Metadata V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
