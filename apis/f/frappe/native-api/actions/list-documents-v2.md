# List Documents V2 with Frappe

Lists documents from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/document/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [List Documents V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
