# Create Document V1 Alias with Frappe

Creates a new document in a Frappe DocType.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/resource/{{arguments.doctype}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Create Document V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
