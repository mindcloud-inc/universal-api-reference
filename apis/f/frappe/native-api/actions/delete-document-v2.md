# Delete Document V2 with Frappe

Deletes a document from a Frappe DocType.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Delete Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
