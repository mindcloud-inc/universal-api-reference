# Add Comment To Document V2 with Frappe

Adds a comment to a Frappe document.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/method/add_comment`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Add Comment To Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
