# Copy Document V2 with Frappe

Retrieves a clean copy of a Frappe document.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/copy`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Copy Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
