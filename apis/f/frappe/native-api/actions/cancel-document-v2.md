# Cancel Document V2 with Frappe

Cancels a document in a Frappe DocType.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/method/cancel`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Cancel Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
