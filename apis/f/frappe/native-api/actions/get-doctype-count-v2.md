# Get DocType Count V2 with Frappe

Retrieves the document count for a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/doctype/{{arguments.doctype}}/count`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get DocType Count V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
