# Get Document V2 with Frappe

Retrieves a document from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/document/{{arguments.doctype}}/{{arguments.documentName}}/`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get Document V2](https://docs.frappe.io/framework/user/en/guides/integration/rest_api)
