# Logout V1 Alias with Frappe

Logs out the current Frappe user.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/method/logout`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Logout V1 Alias](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/simple_authentication)
