# Get Document V1 with Frappe

Retrieves a document from a Frappe DocType.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/resource/{{arguments.doctype}}/{{arguments.documentName}}`
- **Base URL:** `{siteUrl}`
- **Official documentation:** [Get Document V1](https://docs.frappe.io/framework/user/en/guides/integration/rest_api/manipulating_documents)
