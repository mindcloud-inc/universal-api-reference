# List Shipments with Flexport

Retrieves shipments from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [List Shipments](https://apidocs.flexport.com/2023-07-01/tag/Shipment#operation/shipment_index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
