# Retrieve Booking with Flexport

Retrieves a booking from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [Retrieve Booking](https://apidocs.flexport.com/2023-07-01/tag/Booking#operation/bookings_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Flexport booking ID to retrieve. |
