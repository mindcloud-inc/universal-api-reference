# Retrieve Shipment with Flexport

Retrieves a shipment from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/shipments/:id`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [Retrieve Shipment](https://apidocs.flexport.com/2023-07-01/tag/Shipment#operation/shipment_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Flexport shipment ID to retrieve. |
