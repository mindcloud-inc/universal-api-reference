# List Bookings with Flexport

Retrieves bookings from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/bookings`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [List Bookings](https://apidocs.flexport.com/2023-07-01/tag/Booking#operation/bookings_index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
