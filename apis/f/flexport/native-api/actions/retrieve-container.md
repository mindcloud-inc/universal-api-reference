# Retrieve Container with Flexport

Retrieves a container from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocean/shipment_containers/:id`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [Retrieve Container](https://apidocs.flexport.com/2023-07-01/tag/Container#operation/container_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Flexport ocean shipment container ID to retrieve. |
