# List Products with Flexport

Retrieves products for a client from Flexport.

## Endpoint

- **Method:** `GET`
- **Path:** `/products`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [List Products](https://apidocs.flexport.com/2023-07-01/tag/Product#operation/products_index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
