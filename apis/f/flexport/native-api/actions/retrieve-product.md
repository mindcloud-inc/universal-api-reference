# Retrieve Product with Flexport

Retrieves a product from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:id`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [Retrieve Product](https://apidocs.flexport.com/2023-07-01/tag/Product#operation/products_show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique Flexport product ID to retrieve. |
