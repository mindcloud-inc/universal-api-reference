# List Containers with Flexport

Retrieves containers from your Flexport account.

## Endpoint

- **Method:** `GET`
- **Path:** `/ocean/shipment_containers`
- **Base URL:** `https://api.flexport.com`
- **Official documentation:** [List Containers](https://apidocs.flexport.com/2023-07-01/tag/Container#operation/container_list)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
