# List User Companies with Fatture in Cloud

Retrieves the user's companies from Fatture in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/companies`
- **Base URL:** `https://api-v2.fattureincloud.it`
- **Official documentation:** [List User Companies](https://developers.fattureincloud.it/api-reference/#operation/listUserCompanies)
