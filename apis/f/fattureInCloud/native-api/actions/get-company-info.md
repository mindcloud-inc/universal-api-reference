# Get Company Info with Fatture in Cloud

Retrieves company info from Fatture in Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/c/:company_id/company/info`
- **Base URL:** `https://api-v2.fattureincloud.it`
- **Official documentation:** [Get Company Info](https://developers.fattureincloud.it/api-reference/#operation/getCompanyInfo)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `company_id` | path | `number` | yes | The ID of the company. |
