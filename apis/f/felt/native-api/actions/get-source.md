# Get Source with Felt

Retrieves a data source from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/:sourceId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Get Source](https://developers.felt.com/rest-api/api-reference/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `string` | yes | Source ID to retrieve. |
