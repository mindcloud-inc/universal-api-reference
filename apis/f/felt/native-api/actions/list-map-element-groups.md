# List Map Element Groups with Felt

Retrieves map element groups from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/:mapId/element_groups`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Map Element Groups](https://developers.felt.com/rest-api/api-reference/elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | The ID of the map to list groups from. |
