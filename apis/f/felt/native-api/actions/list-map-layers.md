# List Map Layers with Felt

Retrieves map layers from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/:mapId/layers`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Map Layers](https://developers.felt.com/rest-api/api-reference/layers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | The Felt map ID. |
