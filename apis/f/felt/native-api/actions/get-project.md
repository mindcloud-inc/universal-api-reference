# Get Project with Felt

Retrieves a project from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Get Project](https://developers.felt.com/rest-api/api-reference/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project ID to retrieve. |
