# List Projects with Felt

Retrieves projects from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Projects](https://developers.felt.com/rest-api/api-reference/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | query | `string` | no | Optional workspace ID, only needed for plugin contexts. |
