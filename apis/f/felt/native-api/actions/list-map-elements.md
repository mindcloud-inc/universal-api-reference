# List Map Elements with Felt

Retrieves map elements from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/:mapId/elements`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Map Elements](https://developers.felt.com/rest-api/api-reference/elements)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | The ID of the map to list elements from. |
