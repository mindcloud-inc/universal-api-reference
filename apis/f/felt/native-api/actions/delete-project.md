# Delete Project with Felt

Deletes an existing project from Felt.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:projectId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Delete Project](https://developers.felt.com/rest-api/api-reference/projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the project to delete. |
