# List Map Layer Groups with Felt

Retrieves map layer groups from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/:mapId/layer_groups`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Map Layer Groups](https://developers.felt.com/rest-api/api-reference/layers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | The Felt map ID. |
