# Delete Source with Felt

Deletes an existing data source from Felt.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/sources/:sourceId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Delete Source](https://developers.felt.com/rest-api/api-reference/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `string` | yes | The Felt source ID. |
