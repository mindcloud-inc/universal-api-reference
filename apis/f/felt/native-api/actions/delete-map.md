# Delete Map with Felt

Deletes an existing map from Felt.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/maps/:mapId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Delete Map](https://developers.felt.com/rest-api/api-reference/maps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | The ID of the map to delete. |
