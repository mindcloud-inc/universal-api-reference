# Get Map with Felt

Retrieves a map from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/:mapId`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Get Map](https://developers.felt.com/rest-api/api-reference/maps)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `mapId` | path | `string` | yes | Map ID to retrieve. |
