# Sync Source with Felt

Syncs a data source in Felt.

## Endpoint

- **Method:** `POST`
- **Path:** `/sources/:sourceId/sync`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [Sync Source](https://developers.felt.com/rest-api/api-reference/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sourceId` | path | `string` | yes | The Felt source ID. |
