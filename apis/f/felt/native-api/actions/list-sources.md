# List Sources with Felt

Retrieves data sources from Felt.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources`
- **Base URL:** `https://felt.com/api/v2`
- **Official documentation:** [List Sources](https://developers.felt.com/rest-api/api-reference/sources)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspace_id` | query | `string` | no | Optional workspace ID, only needed for plugin contexts. |
