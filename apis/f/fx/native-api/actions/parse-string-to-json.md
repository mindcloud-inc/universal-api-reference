# Parse String to JSON with 1001fx

Parses a string into a JSON object.

## Endpoint

- **Method:** `POST`
- **Path:** `/data/parsestring2json`
- **Base URL:** `https://api.1001fx.com`
- **Official documentation:** [Parse String to JSON](https://1001fx.com/functions/parsestring2json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `string` | body | `string` | yes | String value to parse as JSON. |
