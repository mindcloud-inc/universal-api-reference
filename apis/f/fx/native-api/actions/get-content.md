# Get Content with 1001fx

Retrieves structured content from a URL in 1001fx.

## Endpoint

- **Method:** `POST`
- **Path:** `/data/getcontent`
- **Base URL:** `https://api.1001fx.com`
- **Official documentation:** [Get Content](https://1001fx.com/functions/getcontent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | URL to fetch content from. |
