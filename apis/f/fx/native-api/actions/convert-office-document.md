# Convert Office Document with 1001fx

Converts an office document into a PDF.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/convertofficedocument`
- **Base URL:** `https://api.1001fx.com`
- **Official documentation:** [Convert Office Document](https://1001fx.com/functions/convertofficedocument)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `multipart/form-data` |

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `file` | body | `file` | yes |
