# Get Company with folk

Retrieves a specific company from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/companies/:companyId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get Company](https://developer.folk.app/api-reference/companies/get-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The ID of the company to retrieve. |
