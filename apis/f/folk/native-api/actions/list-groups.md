# List Groups with folk

Retrieves a list of groups from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/groups`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [List Groups](https://developer.folk.app/api-reference/groups/list-groups)

## Capabilities

This operation supports [pagination](../README.md#pagination).
