# Delete Webhook with folk

Deletes an existing webhook from folk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Delete Webhook](https://developer.folk.app/api-reference/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The ID of the webhook to delete. |
