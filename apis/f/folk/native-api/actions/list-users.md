# List Users with folk

Retrieves a list of users from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [List Users](https://developer.folk.app/api-reference/users/list-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
