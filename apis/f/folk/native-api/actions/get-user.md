# Get User with folk

Retrieves a specific user from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:userId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get User](https://developer.folk.app/api-reference/users/get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The ID of the user to retrieve. |
