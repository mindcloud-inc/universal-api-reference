# Delete Company with folk

Deletes an existing company from folk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/companies/:companyId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Delete Company](https://developer.folk.app/api-reference/companies/delete-a-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | The ID of the company to delete. |
