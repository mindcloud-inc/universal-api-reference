# Delete Reminder with folk

Deletes an existing reminder from folk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/reminders/:reminderId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Delete Reminder](https://developer.folk.app/api-reference/reminders/delete-a-reminder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reminderId` | path | `string` | yes | The ID of the reminder to delete. |
