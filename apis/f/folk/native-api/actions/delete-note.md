# Delete Note with folk

Deletes an existing note from folk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/notes/:noteId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Delete Note](https://developer.folk.app/api-reference/notes/delete-a-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The ID of the note to delete. |
