# Get Note with folk

Retrieves a specific note from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/notes/:noteId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get Note](https://developer.folk.app/api-reference/notes/get-a-note)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `noteId` | path | `string` | yes | The ID of the note to retrieve. |
