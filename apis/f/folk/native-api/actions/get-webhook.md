# Get Webhook with folk

Retrieves a specific webhook from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhooks/:webhookId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get Webhook](https://developer.folk.app/api-reference/webhooks/get-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The ID of the webhook to retrieve. |
