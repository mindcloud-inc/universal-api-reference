# Delete Person with folk

Deletes an existing person from folk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/people/:personId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Delete Person](https://developer.folk.app/api-reference/people/delete-a-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | The ID of the person to delete. |
