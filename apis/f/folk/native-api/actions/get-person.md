# Get Person with folk

Retrieves a specific person from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/:personId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get Person](https://developer.folk.app/api-reference/people/get-a-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | The ID of the person to retrieve. |
