# Get Reminder with folk

Retrieves a specific reminder from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/reminders/:reminderId`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [Get Reminder](https://developer.folk.app/api-reference/reminders/get-a-reminder)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reminderId` | path | `string` | yes | The ID of the reminder to retrieve. |
