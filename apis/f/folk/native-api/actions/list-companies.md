# List Companies with folk

Retrieves a list of companies from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/companies`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [List Companies](https://developer.folk.app/api-reference/companies/list-companies)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
