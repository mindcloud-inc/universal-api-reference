# List People with folk

Retrieves a list of people from folk.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people`
- **Base URL:** `https://api.folk.app`
- **Official documentation:** [List People](https://developer.folk.app/api-reference/people/list-people)

## Capabilities

This operation supports [pagination](../README.md#pagination).
