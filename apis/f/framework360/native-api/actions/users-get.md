# Get User with Framework360

## Endpoint

- **Method:** `GET`
- **Path:** `users/get`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [Get User](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | User email address. |
| `id` | query | `string` | no | Numeric or global user ID. |
