# Get Customer with Framework360

## Endpoint

- **Method:** `GET`
- **Path:** `customers/get`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [Get Customer](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Customer email address. |
| `id` | query | `string` | no | Customer ID. |
