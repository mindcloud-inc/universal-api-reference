# Login User with Framework360

## Endpoint

- **Method:** `POST`
- **Path:** `users/login`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [Login User](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Backoffice user email. |
| `password` | body | `string` | yes | Backoffice user password. |
