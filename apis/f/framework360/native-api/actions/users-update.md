# Update User with Framework360

## Endpoint

- **Method:** `POST`
- **Path:** `users/update`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [Update User](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `citta` | body | `string` | no | User city. |
| `cognome` | body | `string` | no | User last name. |
| `email` | body | `string` | no | User email address. |
| `id` | body | `string` | no | User ID to update. |
| `indirizzo` | body | `string` | no | User address. |
| `marketing_list` | body | `string` | no | Marketing subscription flag. |
| `nome` | body | `string` | no | User first name. |
| `password` | body | `string` | no | New user password. |
| `stato` | body | `string` | no | User country. |
| `telefono` | body | `string` | no | User phone number. |
