# List User with Framework360

## Endpoint

- **Method:** `GET`
- **Path:** `users/list`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [List User](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `string` | no | List of user IDs to include. |
| `limit` | query | `string` | no | Maximum users per page. |
| `page` | query | `string` | no | Results page number. |
| `query` | query | `string` | no | Free-text user search. |
| `role` | query | `string` | no | Filter users by role. |
| `sort` | query | `string` | no | Sort mode, for example id ASC. |
