# List Chat with Framework360

## Endpoint

- **Method:** `GET`
- **Path:** `chat/list`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [List Chat](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `boolean` | no | Conversation status filter. |
| `page` | query | `number` | no | Results page number. |
| `limit` | query | `number` | no | Maximum number of conversations per page. |
| `query` | query | `string` | no | Free-text search term. |
| `type` | query | `string` | no | Conversation type filter. |
