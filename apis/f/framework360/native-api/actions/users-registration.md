# Register User with Framework360

## Endpoint

- **Method:** `POST`
- **Path:** `users/registration`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [Register User](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cognome` | body | `string` | no | User last name. |
| `email` | body | `string` | no | User email address. |
| `nome` | body | `string` | no | User first name. |
| `password` | body | `string` | no | User password. |
