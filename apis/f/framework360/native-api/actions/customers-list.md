# List Customer with Framework360

## Endpoint

- **Method:** `GET`
- **Path:** `customers/list`
- **Base URL:** `https://mindcloudstage0.framework360.site/m/api`
- **Official documentation:** [List Customer](https://mindcloudstage0.myframework360.com/modules/integrazione/developer/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum customers per page. |
| `page` | query | `string` | no | Results page number. |
| `query` | query | `string` | no | Free-text customer search. |
