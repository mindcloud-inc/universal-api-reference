# Create Group with Fivetran

Creates a new group in your Fivetran account.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [Create Group](https://fivetran.com/docs/rest-api/api-reference/group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The name of the group within your account. |
