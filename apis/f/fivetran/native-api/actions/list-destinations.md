# List Destinations with Fivetran

Retrieves destinations from your Fivetran account.

## Endpoint

- **Method:** `GET`
- **Path:** `/destinations`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [List Destinations](https://fivetran.com/docs/rest-api/api-reference/destination)

## Capabilities

This operation supports [pagination](../README.md#pagination).
