# List Webhooks with Fivetran

Retrieves webhooks from your Fivetran account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [List Webhooks](https://fivetran.com/docs/rest-api/api-reference/webhook)

## Capabilities

This operation supports [pagination](../README.md#pagination).
