# List Transformation Projects with Fivetran

Retrieves transformation projects from your Fivetran account.

## Endpoint

- **Method:** `GET`
- **Path:** `/transformation-projects`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [List Transformation Projects](https://fivetran.com/docs/rest-api/api-reference/transformation-project)

## Capabilities

This operation supports [pagination](../README.md#pagination).
