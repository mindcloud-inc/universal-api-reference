# Get Account Info with Fivetran

Retrieves account details for your Fivetran account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/info`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [Get Account Info](https://fivetran.com/docs/rest-api/api-reference/account)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
