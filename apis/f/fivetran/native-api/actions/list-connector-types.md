# List Connector Types with Fivetran

Retrieves available connector types from Fivetran.

## Endpoint

- **Method:** `GET`
- **Path:** `/metadata/connector-types`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [List Connector Types](https://fivetran.com/docs/rest-api/api-reference/connector-metadata)

## Capabilities

This operation supports [pagination](../README.md#pagination).
