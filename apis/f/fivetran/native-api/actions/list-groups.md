# List Groups with Fivetran

Retrieves groups from your Fivetran account.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.fivetran.com/v1`
- **Official documentation:** [List Groups](https://fivetran.com/docs/rest-api/api-reference/group)

## Capabilities

This operation supports [pagination](../README.md#pagination).
