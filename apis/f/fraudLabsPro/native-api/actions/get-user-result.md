# Get User Result with FraudLabs Pro

Retrieves a user result from FraudLabs Pro.

## Endpoint

- **Method:** `GET`
- **Path:** `v2/user/result`
- **Base URL:** `https://api.fraudlabspro.com/`
- **Official documentation:** [Get User Result](https://www.fraudlabspro.com/developer/api/user-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The FraudLabs Pro user transaction ID or merchant user ID. |
