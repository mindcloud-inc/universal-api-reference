# Get Order Result with FraudLabs Pro

Retrieves an order result from FraudLabs Pro.

## Endpoint

- **Method:** `GET`
- **Path:** `v2/order/result`
- **Base URL:** `https://api.fraudlabspro.com/`
- **Official documentation:** [Get Order Result](https://www.fraudlabspro.com/developer/api/order-result)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | The FraudLabs Pro transaction ID to look up. |
