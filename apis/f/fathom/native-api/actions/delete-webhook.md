# Delete Webhook with Fathom

Deletes an existing webhook from Fathom.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.fathom.ai/external/v1`
- **Official documentation:** [Delete Webhook](https://developers.fathom.ai/api-reference/webhooks/delete-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook ID to delete. |
