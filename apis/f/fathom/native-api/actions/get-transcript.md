# Get Transcript with Fathom

Retrieves a transcript from Fathom.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recording_id/transcript`
- **Base URL:** `https://api.fathom.ai/external/v1`
- **Official documentation:** [Get Transcript](https://developers.fathom.ai/api-reference/recordings/get-transcript)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording_id` | path | `number` | yes | The Fathom recording ID. |
