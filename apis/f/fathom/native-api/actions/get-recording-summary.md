# Get Recording Summary with Fathom

Retrieves a recording summary from Fathom.

## Endpoint

- **Method:** `GET`
- **Path:** `/recordings/:recording_id/summary`
- **Base URL:** `https://api.fathom.ai/external/v1`
- **Official documentation:** [Get Recording Summary](https://developers.fathom.ai/api-reference/recordings/get-summary)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `recording_id` | path | `number` | yes | The Fathom recording ID. |
