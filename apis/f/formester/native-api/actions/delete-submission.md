# Delete Submission with Formester

Deletes an existing submission from Formester.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/submissions/:id`
- **Base URL:** `https://app.formester.com/api/v2`
- **Official documentation:** [Delete Submission](https://docs.formester.com/formester-api-v2#delete-submission)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Submission UUID. |
