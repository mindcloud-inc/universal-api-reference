# Get Submission with Formester

Retrieves submission details from Formester.

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:id`
- **Base URL:** `https://app.formester.com/api/v2`
- **Official documentation:** [Get Submission](https://docs.formester.com/formester-api-v2#get-submission)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Submission UUID. |
