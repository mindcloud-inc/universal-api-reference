# Get Submission PDF with FillFaster

Retrieves a submission PDF from FillFaster by submission ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/getSubmissionPDF/:submissionId`
- **Base URL:** `https://api.fillfaster.com`
- **Official documentation:** [Get Submission PDF](https://documenter.getpostman.com/view/18912453/2s8ZDVZ3UJ#2e94561c-78c4-4d02-95ef-f52fc554e898)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | FillFaster submission identifier. |
