# Get Form Settings with FillFaster

Retrieves form settings from FillFaster by form ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/form/:formId/settings`
- **Base URL:** `https://api.fillfaster.com`
- **Official documentation:** [Get Form Settings](https://documenter.getpostman.com/view/18912453/2s8ZDVZ3UJ#af7f3880-3f36-4bcf-b5a6-fd92e546006a)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | FillFaster form identifier. |
