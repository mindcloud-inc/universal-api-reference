# Get Submission Status with FillFaster

Retrieves submission status from FillFaster by submission ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/getSubmissionStatus/:submissionId`
- **Base URL:** `https://api.fillfaster.com`
- **Official documentation:** [Get Submission Status](https://documenter.getpostman.com/view/18912453/2s8ZDVZ3UJ#b66ea34b-0a2d-4d0c-ac18-1a17f6300d44)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | FillFaster submission identifier. |
