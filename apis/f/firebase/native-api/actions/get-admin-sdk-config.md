# Get Admin SDK Config with Firebase

Retrieves Admin SDK config for a Firebase project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta1/projects/[:projectId]/adminSdkConfig`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [Get Admin SDK Config](https://firebase.google.com/docs/reference/firebase-management/rest/v1beta1/projects/getAdminSdkConfig)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Firebase project ID. |
