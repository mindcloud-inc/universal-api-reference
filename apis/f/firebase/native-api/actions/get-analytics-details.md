# Get Analytics Details with Firebase

Retrieves Google Analytics details for a Firebase project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta1/projects/[:projectId]/analyticsDetails`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [Get Analytics Details](https://firebase.google.com/docs/reference/firebase-management/rest/v1beta1/projects/getAnalyticsDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Firebase project ID. |
