# Get Operation with Firebase

Retrieves an operation from Firebase.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta1/operations/[:operationId]`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [Get Operation](https://firebase.google.com/docs/reference/firebase-management/rest/v1beta1/operations/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `operationId` | path | `string` | yes | Long-running operation identifier. |
