# List Firebase Projects with Firebase

Retrieves Firebase projects.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta1/projects`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [List Firebase Projects](https://firebase.google.com/docs/reference/firebase-management/rest/v1beta1/projects/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
