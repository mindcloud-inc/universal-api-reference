# Get Firebase Project with Firebase

Retrieves a Firebase project.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1beta1/projects/[:projectId]`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [Get Firebase Project](https://firebase.google.com/docs/reference/firebase-management/rest/v1beta1/projects/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Firebase project ID. |
