# Get Access Token with Firebase

Creates an access token for Firebase.

## Endpoint

- **Method:** `POST`
- **Path:** `https://oauth2.googleapis.com/token`
- **Base URL:** `https://firebase.googleapis.com`
- **Official documentation:** [Get Access Token](https://developers.google.com/identity/protocols/oauth2/service-account#httprest)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
