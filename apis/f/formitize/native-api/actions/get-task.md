# Get Task with Formitize

Retrieves a task from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/task/:id`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Get Task](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Formitize task ID. |
