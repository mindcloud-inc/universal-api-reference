# Add Contact with Formitize

Creates a new contact in Formitize.

## Endpoint

- **Method:** `POST`
- **Path:** `/crm/client/:clientID/contact/`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Add Contact](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientID` | path | `string` | no | Formitize client ID. |
