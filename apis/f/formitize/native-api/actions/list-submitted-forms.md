# List Submitted Forms with Formitize

Retrieves submitted forms from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/submit/list`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [List Submitted Forms](https://mitechnologies.github.io/Formitize-NET-API/)
