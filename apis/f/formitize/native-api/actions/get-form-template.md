# Get Form Template with Formitize

Retrieves a form template from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/:id`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Get Form Template](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Form template ID. |
