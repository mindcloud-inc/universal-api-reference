# Delete Task with Formitize

Soft deletes an existing task in Formitize.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crm/task/:id`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Delete Task](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Formitize task ID. |
