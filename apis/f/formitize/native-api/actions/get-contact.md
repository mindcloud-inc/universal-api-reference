# Get Contact with Formitize

Retrieves a contact from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/crm/client/:clientID/contact/:contactID`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Get Contact](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientID` | path | `string` | no | Formitize client ID. |
| `contactID` | path | `string` | no | Formitize contact ID. |
