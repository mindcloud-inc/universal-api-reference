# Get Submitted Form with Formitize

Retrieves a submitted form from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/submit/:id`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Get Submitted Form](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Formitize submitted form ID. |
