# Get Job History with Formitize

Retrieves a job's history from Formitize.

## Endpoint

- **Method:** `GET`
- **Path:** `/job/:id/history`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Get Job History](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Formitize job ID. |
