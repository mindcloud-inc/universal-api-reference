# Edit Client with Formitize

Updates an existing client in Formitize.

## Endpoint

- **Method:** `POST`
- **Path:** `/crm/client/:clientID`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Edit Client](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientID` | path | `string` | no | Formitize client ID. |
