# Edit Job with Formitize

Updates an existing job in Formitize.

## Endpoint

- **Method:** `POST`
- **Path:** `/job/:id`
- **Base URL:** `https://service.formitize.com/api/rest/v2`
- **Official documentation:** [Edit Job](https://mitechnologies.github.io/Formitize-NET-API/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Formitize job ID. |
