# Get Supported File Formats with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves supported file formats for the File source.

## Endpoint

- **Method:** `GET`
- **Path:** `/oss_registry.json`
- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [Get Supported File Formats](https://docs.airbyte.com/integrations/sources/file#file-formats)
