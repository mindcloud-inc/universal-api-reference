# Get File Connector Metadata with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves metadata for the File source connector.

## Endpoint

- **Method:** `GET`
- **Path:** `/oss_registry.json`
- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [Get File Connector Metadata](https://docs.airbyte.com/integrations/sources/file)
