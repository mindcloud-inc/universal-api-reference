# Validate File Source Configuration with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves validation requirements for a file source configuration.

- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [Validate File Source Configuration](https://docs.airbyte.com/integrations/sources/file#prerequisites)
