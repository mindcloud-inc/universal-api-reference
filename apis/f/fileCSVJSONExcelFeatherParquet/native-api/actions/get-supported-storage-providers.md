# Get Supported Storage Providers with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves supported storage providers for the File source.

## Endpoint

- **Method:** `GET`
- **Path:** `/oss_registry.json`
- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [Get Supported Storage Providers](https://docs.airbyte.com/integrations/sources/file#storage-providers)
