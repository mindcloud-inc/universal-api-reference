# List Available Streams with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves available streams for a file source.

## Endpoint

- **Method:** `GET`
- **Path:** `/oss_registry.json`
- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [List Available Streams](https://airbyte.com/pyairbyte/file-python)
