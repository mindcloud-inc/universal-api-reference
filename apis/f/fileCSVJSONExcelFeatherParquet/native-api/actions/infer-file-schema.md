# Infer File Schema with File (CSV, JSON, Excel, Feather, Parquet)

Retrieves an inferred schema for a file source.

## Endpoint

- **Method:** `GET`
- **Path:** `/oss_registry.json`
- **Base URL:** `https://connectors.airbyte.com/files/registries/v0`
- **Official documentation:** [Infer File Schema](https://docs.airbyte.com/integrations/sources/file#step-3-complete-the-connector-setup)
