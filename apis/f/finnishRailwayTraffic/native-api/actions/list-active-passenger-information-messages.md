# List active passenger information messages with Finnish Railway Traffic

Retrieves active passenger information messages from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/passenger-information/active`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List active passenger information messages](https://rata.digitraffic.fi/swagger/openapi.json)
