# List traffic restriction notifications as GeoJSON with Finnish Railway Traffic

Retrieves traffic restriction notifications as GeoJSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trafficrestriction-notifications.geojson`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List traffic restriction notifications as GeoJSON](https://rata.digitraffic.fi/swagger/openapi.json)
