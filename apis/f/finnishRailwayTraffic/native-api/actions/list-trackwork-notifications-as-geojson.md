# List trackwork notifications as GeoJSON with Finnish Railway Traffic

Retrieves trackwork notifications as GeoJSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trackwork-notifications.geojson`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List trackwork notifications as GeoJSON](https://rata.digitraffic.fi/swagger/openapi.json)
