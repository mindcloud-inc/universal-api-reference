# List routesets updated after version with Finnish Railway Traffic

Retrieves routesets updated after a version in Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/routesets`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List routesets updated after version](https://rata.digitraffic.fi/swagger/openapi.json)
