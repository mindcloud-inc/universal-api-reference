# List trackwork notification status with Finnish Railway Traffic

Retrieves trackwork notification versions from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trackwork-notifications/status`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List trackwork notification status](https://rata.digitraffic.fi/swagger/openapi.json)
