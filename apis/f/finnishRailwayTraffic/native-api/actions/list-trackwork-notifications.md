# List trackwork notifications with Finnish Railway Traffic

Retrieves trackwork notifications in JSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trackwork-notifications.json`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List trackwork notifications](https://rata.digitraffic.fi/swagger/openapi.json)
