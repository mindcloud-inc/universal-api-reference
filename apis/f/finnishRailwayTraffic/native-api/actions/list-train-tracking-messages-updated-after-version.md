# List train tracking messages updated after version with Finnish Railway Traffic

Retrieves train tracking messages updated after a version in Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/train-tracking/`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List train tracking messages updated after version](https://rata.digitraffic.fi/swagger/openapi.json)
