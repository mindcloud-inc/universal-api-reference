# List latest train locations with Finnish Railway Traffic

Retrieves latest train locations from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/train-locations/latest`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List latest train locations](https://rata.digitraffic.fi/swagger/openapi.json)
