# List timetable periods with Finnish Railway Traffic

Retrieves timetable periods from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/time-table-periods`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List timetable periods](https://rata.digitraffic.fi/swagger/openapi.json)
