# List stations as GeoJSON with Finnish Railway Traffic

Retrieves stations as GeoJSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/stations.geojson`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List stations as GeoJSON](https://rata.digitraffic.fi/swagger/openapi.json)
