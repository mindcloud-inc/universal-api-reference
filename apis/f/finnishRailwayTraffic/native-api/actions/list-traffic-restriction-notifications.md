# List traffic restriction notifications with Finnish Railway Traffic

Retrieves traffic restriction notifications in JSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trafficrestriction-notifications.json`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List traffic restriction notifications](https://rata.digitraffic.fi/swagger/openapi.json)
