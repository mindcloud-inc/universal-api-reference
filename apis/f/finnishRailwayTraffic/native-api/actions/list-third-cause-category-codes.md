# List third cause category codes with Finnish Railway Traffic

Retrieves third cause category codes from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/third-cause-category-codes`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List third cause category codes](https://rata.digitraffic.fi/swagger/openapi.json)
