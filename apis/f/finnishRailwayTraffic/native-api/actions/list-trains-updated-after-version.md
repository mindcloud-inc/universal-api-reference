# List trains updated after version with Finnish Railway Traffic

Retrieves trains updated after a version in Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trains`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List trains updated after version](https://rata.digitraffic.fi/swagger/openapi.json)
