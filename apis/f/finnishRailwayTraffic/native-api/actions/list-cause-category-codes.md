# List cause category codes with Finnish Railway Traffic

Retrieves cause category codes from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/cause-category-codes`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List cause category codes](https://rata.digitraffic.fi/swagger/openapi.json)
