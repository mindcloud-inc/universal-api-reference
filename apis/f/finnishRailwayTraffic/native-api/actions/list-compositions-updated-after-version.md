# List compositions updated after version with Finnish Railway Traffic

Retrieves compositions updated after a version in Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/compositions`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List compositions updated after version](https://rata.digitraffic.fi/swagger/openapi.json)
