# List train running message rules with Finnish Railway Traffic

Retrieves train running message rules from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/train-running-message-rules`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List train running message rules](https://rata.digitraffic.fi/swagger/openapi.json)
