# List latest train locations as GeoJSON with Finnish Railway Traffic

Retrieves latest train locations as GeoJSON from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/train-locations.geojson/latest`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List latest train locations as GeoJSON](https://rata.digitraffic.fi/swagger/openapi.json)
