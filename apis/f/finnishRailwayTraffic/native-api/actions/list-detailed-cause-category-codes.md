# List detailed cause category codes with Finnish Railway Traffic

Retrieves detailed cause category codes from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/metadata/detailed-cause-category-codes`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List detailed cause category codes](https://rata.digitraffic.fi/swagger/openapi.json)
