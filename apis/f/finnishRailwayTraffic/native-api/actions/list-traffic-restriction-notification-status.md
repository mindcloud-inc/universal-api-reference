# List traffic restriction notification status with Finnish Railway Traffic

Retrieves traffic restriction notification versions from Finnish Railway Traffic.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/trafficrestriction-notifications/status`
- **Base URL:** `https://rata.digitraffic.fi`
- **Official documentation:** [List traffic restriction notification status](https://rata.digitraffic.fi/swagger/openapi.json)
