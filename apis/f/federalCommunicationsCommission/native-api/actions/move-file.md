# Move File with Federal Communications Commission

Moves an FCC OPIF file to a new folder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/manager/file/move.{format}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Move File](https://publicfiles.fcc.gov/json/opif-file-manager.json)
