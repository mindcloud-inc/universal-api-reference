# Update DBS Licensee Address with Federal Communications Commission

Updates an FCC DBS licensee address.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/service/dbs/licenseeAddress/update`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Update DBS Licensee Address](https://publicfiles.fcc.gov/json/opif-cdbs.json)
