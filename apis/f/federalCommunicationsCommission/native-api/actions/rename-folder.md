# Rename Folder with Federal Communications Commission

Updates the name of an FCC OPIF folder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/manager/folder/rename.{format}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Rename Folder](https://publicfiles.fcc.gov/json/opif-file-manager.json)
