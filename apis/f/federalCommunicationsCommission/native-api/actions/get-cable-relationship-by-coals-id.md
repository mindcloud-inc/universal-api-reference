# Get Cable Relationship by COALS ID with Federal Communications Commission

Retrieves FCC cable relationships by COALS ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/service/cable/relationship/username/{COALSID}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Get Cable Relationship by COALS ID](https://publicfiles.fcc.gov/json/opif-cdbs.json)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `COALSID` | path | `string` | no | COALS username or ID. |
