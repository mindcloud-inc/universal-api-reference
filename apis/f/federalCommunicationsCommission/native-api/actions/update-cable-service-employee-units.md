# Update Cable Service Employee Units with Federal Communications Commission

Updates FCC cable service employee units.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/service/cable/empunitid/update`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Update Cable Service Employee Units](https://publicfiles.fcc.gov/json/opif-cdbs.json)
