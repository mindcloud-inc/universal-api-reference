# Restore Folder with Federal Communications Commission

Restores an FCC OPIF folder.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/manager/folder/restore.{format}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Restore Folder](https://publicfiles.fcc.gov/json/opif-file-manager.json)
