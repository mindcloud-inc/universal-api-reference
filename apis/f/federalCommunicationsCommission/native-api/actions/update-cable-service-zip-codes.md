# Update Cable Service Zip Codes with Federal Communications Commission

Updates FCC cable service ZIP codes.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/service/cable/serviceZipcodes/update`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Update Cable Service Zip Codes](https://publicfiles.fcc.gov/json/opif-cdbs.json)
