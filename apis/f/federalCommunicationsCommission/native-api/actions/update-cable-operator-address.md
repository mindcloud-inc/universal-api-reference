# Update Cable Operator Address with Federal Communications Commission

Updates an FCC cable operator address.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/service/cable/operatorAddress/update`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Update Cable Operator Address](https://publicfiles.fcc.gov/json/opif-cdbs.json)
