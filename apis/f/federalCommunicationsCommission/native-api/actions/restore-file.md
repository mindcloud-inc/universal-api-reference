# Restore File with Federal Communications Commission

Restores an FCC OPIF file.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/manager/file/restore.{format}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Restore File](https://publicfiles.fcc.gov/json/opif-file-manager.json)
