# Rename File with Federal Communications Commission

Updates the name of an FCC OPIF file.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/manager/file/rename.{format}`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Rename File](https://publicfiles.fcc.gov/json/opif-file-manager.json)
