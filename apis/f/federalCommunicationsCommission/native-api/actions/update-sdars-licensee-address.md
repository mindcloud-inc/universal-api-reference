# Update SDARS Licensee Address with Federal Communications Commission

Updates an FCC SDARS licensee address.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/service/sdars/licenseeAddress/update`
- **Base URL:** `https://publicfiles.fcc.gov`
- **Official documentation:** [Update SDARS Licensee Address](https://publicfiles.fcc.gov/json/opif-cdbs.json)
