# Cancel Agent with Firecrawl

Cancels an agent job in Firecrawl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agent/:jobId`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Cancel Agent](https://docs.firecrawl.dev/api-reference/endpoint/agent-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The ID of the agent job |
