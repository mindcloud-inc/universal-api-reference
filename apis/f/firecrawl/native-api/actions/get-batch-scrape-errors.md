# Get Batch Scrape Errors with Firecrawl

Retrieves batch scrape errors from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch/scrape/:id/errors`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Batch Scrape Errors](https://docs.firecrawl.dev/api-reference/endpoint/batch-scrape-get-errors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the batch scrape job |
