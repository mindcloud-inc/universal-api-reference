# Get Batch Scrape Status with Firecrawl

Retrieves batch scrape job status from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/batch/scrape/:id`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Batch Scrape Status](https://docs.firecrawl.dev/api-reference/endpoint/batch-scrape-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the batch scrape job |
