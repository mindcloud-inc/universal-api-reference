# Cancel Batch Scrape with Firecrawl

Cancels a batch scrape job in Firecrawl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/batch/scrape/:id`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Cancel Batch Scrape](https://docs.firecrawl.dev/api-reference/endpoint/batch-scrape-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the batch scrape job |
