# Get Agent Status with Firecrawl

Retrieves agent job status from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent/:jobId`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Agent Status](https://docs.firecrawl.dev/api-reference/endpoint/agent-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The ID of the agent job |
