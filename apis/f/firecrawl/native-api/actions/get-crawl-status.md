# Get Crawl Status with Firecrawl

Retrieves crawl job status from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/crawl/:id`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Crawl Status](https://docs.firecrawl.dev/api-reference/endpoint/crawl-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the crawl job |
