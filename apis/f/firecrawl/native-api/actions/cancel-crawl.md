# Cancel Crawl with Firecrawl

Cancels a crawl job in Firecrawl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/crawl/:id`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Cancel Crawl](https://docs.firecrawl.dev/api-reference/endpoint/crawl-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the crawl job |
