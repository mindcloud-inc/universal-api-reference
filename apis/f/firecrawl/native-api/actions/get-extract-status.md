# Get Extract Status with Firecrawl

Retrieves extraction job status from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/extract/:id`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Extract Status](https://docs.firecrawl.dev/api-reference/endpoint/extract-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the extract job |
