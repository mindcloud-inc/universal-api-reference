# Get Queue Status with Firecrawl

Retrieves queue status from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/queue-status`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Queue Status](https://docs.firecrawl.dev/api-reference/endpoint/queue-status)
