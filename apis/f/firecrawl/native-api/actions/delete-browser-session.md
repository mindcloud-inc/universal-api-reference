# Delete Browser Session with Firecrawl

Deletes a browser session from Firecrawl.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/browser/:sessionId`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Delete Browser Session](https://docs.firecrawl.dev/api-reference/endpoint/browser-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionId` | path | `string` | yes | The browser session ID |
