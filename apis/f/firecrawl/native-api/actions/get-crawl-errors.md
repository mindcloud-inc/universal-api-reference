# Get Crawl Errors with Firecrawl

Retrieves crawl errors from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/crawl/:id/errors`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Crawl Errors](https://docs.firecrawl.dev/api-reference/endpoint/crawl-get-errors)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the crawl job |
