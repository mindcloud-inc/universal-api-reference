# List Browser Sessions with Firecrawl

Retrieves browser sessions from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/browser`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [List Browser Sessions](https://docs.firecrawl.dev/api-reference/endpoint/browser-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `status` | query | `string` | no | Filter sessions by status |
