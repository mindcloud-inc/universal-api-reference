# Get Credit Usage with Firecrawl

Retrieves credit usage from Firecrawl.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/credit-usage`
- **Base URL:** `https://api.firecrawl.dev/v2`
- **Official documentation:** [Get Credit Usage](https://docs.firecrawl.dev/api-reference/endpoint/credit-usage)
