# Delete Variable with FlowiseAI

Deletes an existing variable from FlowiseAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/variables/{id}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Delete Variable](https://docs.flowiseai.com/api-reference/variables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Variable ID to delete. |
