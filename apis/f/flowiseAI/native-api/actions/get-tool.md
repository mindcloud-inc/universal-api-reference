# Get Tool with FlowiseAI

Retrieves a specific tool from FlowiseAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/tools/{id}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Get Tool](https://docs.flowiseai.com/api-reference/tools)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tool ID. |
