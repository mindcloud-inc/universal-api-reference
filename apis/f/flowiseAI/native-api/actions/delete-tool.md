# Delete Tool with FlowiseAI

Deletes an existing tool from FlowiseAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools/{id}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Delete Tool](https://docs.flowiseai.com/api-reference/tools)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Tool ID to delete. |
