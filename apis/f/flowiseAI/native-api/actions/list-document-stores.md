# List Document Stores with FlowiseAI

Retrieves all document stores from FlowiseAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/document-store/store`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [List Document Stores](https://docs.flowiseai.com/api-reference/document-store)
