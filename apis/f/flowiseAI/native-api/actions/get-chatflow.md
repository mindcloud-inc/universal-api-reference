# Get Chatflow with FlowiseAI

Retrieves a specific chatflow from FlowiseAI.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatflows/{id}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Get Chatflow](https://docs.flowiseai.com/api-reference/chatflows)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Chatflow ID from the Flowise chatflows API. |
