# Create Variable with FlowiseAI

Creates a new variable in FlowiseAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/variables`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Create Variable](https://docs.flowiseai.com/api-reference/variables)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | no | JSON body with documented Flowise variable fields. |
