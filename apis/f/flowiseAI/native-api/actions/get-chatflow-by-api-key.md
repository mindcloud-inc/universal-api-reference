# Get Chatflow by API Key with FlowiseAI

Retrieves a FlowiseAI chatflow by API key.

## Endpoint

- **Method:** `GET`
- **Path:** `/chatflows/apikey/{apikey}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Get Chatflow by API Key](https://docs.flowiseai.com/api-reference/chatflows)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apikey` | path | `string` | yes | API key associated with the Flowise chatflow. |
