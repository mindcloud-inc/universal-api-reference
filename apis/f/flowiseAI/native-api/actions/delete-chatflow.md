# Delete Chatflow with FlowiseAI

Deletes an existing chatflow from FlowiseAI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/chatflows/{id}`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Delete Chatflow](https://docs.flowiseai.com/api-reference/chatflows)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Chatflow ID to delete. |
