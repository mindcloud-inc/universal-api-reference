# Create Tool with FlowiseAI

Creates a new tool in FlowiseAI.

## Endpoint

- **Method:** `POST`
- **Path:** `/tools`
- **Base URL:** `https://cloud.flowiseai.com/api/v1`
- **Official documentation:** [Create Tool](https://docs.flowiseai.com/api-reference/tools)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `body` | body | `object` | no | JSON body with documented Flowise tool fields. |
