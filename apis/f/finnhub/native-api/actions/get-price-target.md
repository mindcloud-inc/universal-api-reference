# Get Price Target with Finnhub

Retrieves a price target from Finnhub.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock/price-target`
- **Base URL:** `https://finnhub.io/api/v1`
- **Official documentation:** [Get Price Target](https://finnhub.io/docs/api#price-target)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Company symbol, such as AAPL. |
