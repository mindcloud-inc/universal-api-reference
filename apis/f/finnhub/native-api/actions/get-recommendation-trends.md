# Get Recommendation Trends with Finnhub

Retrieves recommendation trends from Finnhub.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock/recommendation`
- **Base URL:** `https://finnhub.io/api/v1`
- **Official documentation:** [Get Recommendation Trends](https://finnhub.io/docs/api#recommendation-trends)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Company symbol, such as AAPL. |
