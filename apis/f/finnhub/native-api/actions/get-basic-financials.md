# Get Basic Financials with Finnhub

Retrieves basic financials from Finnhub.

## Endpoint

- **Method:** `GET`
- **Path:** `/stock/metric`
- **Base URL:** `https://finnhub.io/api/v1`
- **Official documentation:** [Get Basic Financials](https://finnhub.io/docs/api#company-basic-financials)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Company symbol, such as AAPL. |
