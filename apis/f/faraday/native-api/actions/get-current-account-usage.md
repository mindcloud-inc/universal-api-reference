# Get Current Account Usage with Faraday

Retrieves current account usage metrics from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/current/usage`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Current Account Usage](https://faraday.ai/docs/reference/getaccountcurrentusage)
