# Get Current Account Billing with Faraday

Retrieves current account billing details from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/current/billing`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Current Account Billing](https://faraday.ai/docs/reference/getcurrentaccountbilling)
