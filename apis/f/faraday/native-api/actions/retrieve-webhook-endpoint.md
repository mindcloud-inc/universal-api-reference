# Retrieve Webhook Endpoint with Faraday

Retrieves a webhook endpoint from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook_endpoints/:webhook_endpoint_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Retrieve Webhook Endpoint](https://faraday.ai/docs/reference/getwebhookendpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_endpoint_id` | path | `string` | no | Faraday webhook endpoint ID. |
