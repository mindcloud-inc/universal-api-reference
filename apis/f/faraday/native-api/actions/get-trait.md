# Get Trait with Faraday

Retrieves a trait from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/traits/:trait_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Trait](https://faraday.ai/docs/reference/gettrait)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
