# Update Trait with Faraday

Updates an existing trait in Faraday.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/traits/:trait_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Update Trait](https://faraday.ai/docs/reference/updatetrait)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
