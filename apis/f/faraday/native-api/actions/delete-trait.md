# Delete Trait with Faraday

Deletes an existing trait from Faraday.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/traits/:trait_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Delete Trait](https://faraday.ai/docs/reference/deletetrait)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
