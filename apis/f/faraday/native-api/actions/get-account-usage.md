# Get Account Usage with Faraday

Retrieves account usage metrics from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/usage`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Account Usage](https://faraday.ai/docs/reference/getaccountusage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | no | Faraday account ID. |
