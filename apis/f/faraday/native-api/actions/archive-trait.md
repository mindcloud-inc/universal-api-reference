# Archive Trait with Faraday

Archives an existing trait in Faraday.

## Endpoint

- **Method:** `POST`
- **Path:** `/traits/:trait_id/archive`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Archive Trait](https://faraday.ai/docs/reference/archivetrait)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
