# Update Webhook Endpoint with Faraday

Updates an existing webhook endpoint in Faraday.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/webhook_endpoints/:webhook_endpoint_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Update Webhook Endpoint](https://faraday.ai/docs/reference/updatewebhookendpoint)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhook_endpoint_id` | path | `string` | no | Faraday webhook endpoint ID. |
