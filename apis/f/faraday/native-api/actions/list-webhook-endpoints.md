# List Webhook Endpoints with Faraday

Retrieves a list of webhook endpoints from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhook_endpoints`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [List Webhook Endpoints](https://faraday.ai/docs/reference/getwebhookendpoints)
