# Get Stream with Faraday

Retrieves a stream from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/streams/:stream_id_or_name`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Stream](https://faraday.ai/docs/reference/getstream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stream_id_or_name` | path | `string` | no | Faraday stream ID or name. |
