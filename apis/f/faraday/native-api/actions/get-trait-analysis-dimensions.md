# Get Trait Analysis Dimensions with Faraday

Retrieves trait analysis dimensions from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/traits/:trait_id/analysis/dimensions`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Get Trait Analysis Dimensions](https://faraday.ai/docs/reference/gettraitanalysisdimensions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
