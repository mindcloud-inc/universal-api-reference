# Delete Stream with Faraday

Deletes an existing stream from Faraday.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/streams/:stream_id_or_name`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Delete Stream](https://faraday.ai/docs/reference/deletestream)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stream_id_or_name` | path | `string` | no | Faraday stream ID or name. |
