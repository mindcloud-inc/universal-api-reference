# Retrieve Account with Faraday

Retrieves a specific account from Faraday.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Retrieve Account](https://faraday.ai/docs/reference/getaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | no | Faraday account ID. |
