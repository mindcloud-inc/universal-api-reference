# Update Account with Faraday

Updates an existing account in Faraday.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/accounts/:account_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Update Account](https://faraday.ai/docs/reference/updateaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | no | Faraday account ID. |
