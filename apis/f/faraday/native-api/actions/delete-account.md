# Delete Account with Faraday

Requests deletion of an existing account from Faraday.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/accounts/:account_id`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Delete Account](https://faraday.ai/docs/reference/deleteaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `account_id` | path | `string` | no | Faraday account ID. |
