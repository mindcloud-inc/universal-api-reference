# Unarchive Trait with Faraday

Unarchives an existing trait in Faraday.

## Endpoint

- **Method:** `POST`
- **Path:** `/traits/:trait_id/unarchive`
- **Base URL:** `https://api.faraday.ai/v1`
- **Official documentation:** [Unarchive Trait](https://faraday.ai/docs/reference/unarchivetrait)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `trait_id` | path | `string` | no | Faraday trait ID. |
