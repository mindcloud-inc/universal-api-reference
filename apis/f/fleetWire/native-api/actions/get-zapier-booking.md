# Get Zapier Booking with FleetWire

Retrieves a Zapier booking from FleetWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/zapier/bookings/:b_id`
- **Base URL:** `https://api.fleetwire.io`
- **Official documentation:** [Get Zapier Booking](https://documenter.getpostman.com/view/263138/Tz5p6dWS)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `b_id` | path | `string` | yes | The FleetWire booking identifier. |
