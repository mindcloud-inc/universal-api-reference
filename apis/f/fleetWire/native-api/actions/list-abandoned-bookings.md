# List Abandoned Bookings with FleetWire

Retrieves abandoned bookings from FleetWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/zapier/abandoned-bookings`
- **Base URL:** `https://api.fleetwire.io`
- **Official documentation:** [List Abandoned Bookings](https://documenter.getpostman.com/view/263138/Tz5p6dWS)
