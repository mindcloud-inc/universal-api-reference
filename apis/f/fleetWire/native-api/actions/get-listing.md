# Get Listing with FleetWire

Retrieves a listing from FleetWire.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/listings/:l_id`
- **Base URL:** `https://api.fleetwire.io`
- **Official documentation:** [Get Listing](https://documenter.getpostman.com/view/263138/Tz5p6dWS)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `l_id` | path | `string` | no | The FleetWire listing identifier. |
