# Get fruit by ID with Fruityvice

## Endpoint

- **Method:** `GET`
- **Path:** `/api/fruit/:id`
- **Base URL:** `https://www.fruityvice.com`
- **Official documentation:** [Get fruit by ID](https://www.fruityvice.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Fruityvice fruit ID. |
