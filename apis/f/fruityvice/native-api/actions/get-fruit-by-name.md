# Get fruit by name with Fruityvice

## Endpoint

- **Method:** `GET`
- **Path:** `/api/fruit/:name`
- **Base URL:** `https://www.fruityvice.com`
- **Official documentation:** [Get fruit by name](https://www.fruityvice.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Fruityvice fruit name. |
