# List Vehicles with Fleetio

Retrieves a list of vehicles from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `vehicles`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Vehicles](https://developer.fleetio.com/docs/api/vehicles-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
