# Retrieve Vendor with Fleetio

Retrieves a specific vendor from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `vendors/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Retrieve Vendor](https://developer.fleetio.com/docs/api/vendors-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
