# List Vendors with Fleetio

Retrieves a list of vendors from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `vendors`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Vendors](https://developer.fleetio.com/docs/api/vendors-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
