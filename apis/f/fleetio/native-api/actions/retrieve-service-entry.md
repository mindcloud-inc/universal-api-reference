# Retrieve Service Entry with Fleetio

Retrieves a specific service entry from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `service_entries/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Retrieve Service Entry](https://developer.fleetio.com/docs/api/service-entries-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
