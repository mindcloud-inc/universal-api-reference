# List Work Orders with Fleetio

Retrieves a list of work orders from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `work_orders`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Work Orders](https://developer.fleetio.com/docs/api/work-orders-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
