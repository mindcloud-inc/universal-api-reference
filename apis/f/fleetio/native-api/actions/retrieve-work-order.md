# Retrieve Work Order with Fleetio

Retrieves a specific work order from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `work_orders/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Retrieve Work Order](https://developer.fleetio.com/docs/api/work-orders-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
