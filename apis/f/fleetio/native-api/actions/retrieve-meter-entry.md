# Retrieve Meter Entry with Fleetio

Retrieves a specific meter entry from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `meter_entries/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Retrieve Meter Entry](https://developer.fleetio.com/docs/api/meter-entries-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
