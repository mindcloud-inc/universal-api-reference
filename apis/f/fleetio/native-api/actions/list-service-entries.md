# List Service Entries with Fleetio

Retrieves a list of service entries from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `service_entries`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Service Entries](https://developer.fleetio.com/docs/api/service-entries-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
