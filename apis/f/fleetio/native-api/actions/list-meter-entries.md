# List Meter Entries with Fleetio

Retrieves a list of meter entries from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `meter_entries`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Meter Entries](https://developer.fleetio.com/docs/api/meter-entries-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
