# Delete Vendor with Fleetio

Deletes an existing vendor from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `vendors/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Vendor](https://developer.fleetio.com/docs/api/vendors-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
