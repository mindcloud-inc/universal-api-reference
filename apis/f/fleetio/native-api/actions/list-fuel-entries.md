# List Fuel Entries with Fleetio

Retrieves a list of fuel entries from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `fuel_entries`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Fuel Entries](https://developer.fleetio.com/docs/api/fuel-entries-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
