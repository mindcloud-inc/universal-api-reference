# Delete Issue with Fleetio

Deletes an existing issue from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `issues/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Issue](https://developer.fleetio.com/docs/api/issues-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
