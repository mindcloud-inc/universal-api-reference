# List Issues with Fleetio

Retrieves a list of issues from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `issues`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Issues](https://developer.fleetio.com/docs/api/issues-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
