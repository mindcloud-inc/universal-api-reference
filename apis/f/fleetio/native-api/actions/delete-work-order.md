# Delete Work Order with Fleetio

Deletes an existing work order from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `work_orders/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Work Order](https://developer.fleetio.com/docs/api/work-orders-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
