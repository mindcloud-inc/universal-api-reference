# Delete Contact with Fleetio

Deletes an existing contact from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `contacts/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Contact](https://developer.fleetio.com/docs/api/contacts-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
