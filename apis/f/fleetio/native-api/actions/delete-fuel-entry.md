# Delete Fuel Entry with Fleetio

Deletes an existing fuel entry from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `fuel_entries/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Fuel Entry](https://developer.fleetio.com/docs/api/fuel-entries-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
