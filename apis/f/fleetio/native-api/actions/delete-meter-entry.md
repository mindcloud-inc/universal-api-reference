# Delete Meter Entry with Fleetio

Deletes an existing meter entry from Fleetio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `meter_entries/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Delete Meter Entry](https://developer.fleetio.com/docs/api/meter-entries-destroy)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
