# Retrieve Fuel Entry with Fleetio

Retrieves a specific fuel entry from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `fuel_entries/:id`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [Retrieve Fuel Entry](https://developer.fleetio.com/docs/api/fuel-entries-show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The id of the relevant record |
