# List Contacts with Fleetio

Retrieves a list of contacts from Fleetio.

## Endpoint

- **Method:** `GET`
- **Path:** `contacts`
- **Base URL:** `https://secure.fleetio.com/api/`
- **Official documentation:** [List Contacts](https://developer.fleetio.com/docs/api/contacts-index)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
