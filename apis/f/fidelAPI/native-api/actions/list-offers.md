# List Offers with Fidel API

Retrieves offers from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/offers`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [List Offers](https://reference.fidel.uk/reference/list-offers)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
