# Create Program with Fidel API

Creates a new program in Fidel API.

## Endpoint

- **Method:** `POST`
- **Path:** `/programs`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Create Program](https://reference.fidel.uk/reference/create-program)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
