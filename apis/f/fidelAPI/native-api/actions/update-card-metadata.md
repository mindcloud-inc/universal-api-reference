# Update Card Metadata with Fidel API

Updates metadata for a Fidel card.

## Endpoint

- **Method:** `PUT`
- **Path:** `/cards/:cardId/metadata`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Update Card Metadata](https://reference.fidel.uk/reference/update-card-metadata)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | yes |
