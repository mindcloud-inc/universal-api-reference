# Get Location with Fidel API

Retrieves a location from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/locations/:locationId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Location](https://reference.fidel.uk/reference/get-location)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `locationId` | path | `string` | yes |
