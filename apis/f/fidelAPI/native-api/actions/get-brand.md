# Get Brand with Fidel API

Retrieves a brand from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands/:brandId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Brand](https://reference.fidel.uk/reference/get-brand)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `brandId` | path | `string` | yes |
