# Get Transaction with Fidel API

Retrieves a transaction from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/:transactionId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Transaction](https://reference.fidel.uk/reference/get-transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transactionId` | path | `string` | yes |
