# Create Brand with Fidel API

Creates a new brand in Fidel API.

## Endpoint

- **Method:** `POST`
- **Path:** `/brands`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Create Brand](https://reference.fidel.uk/reference/create-brand)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
