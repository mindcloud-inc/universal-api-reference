# Get Card with Fidel API

Retrieves a card from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Card](https://reference.fidel.uk/reference/get-card)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | yes |
