# Get Program with Fidel API

Retrieves a program from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/programs/:programId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Program](https://reference.fidel.uk/reference/get-program)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `programId` | path | `string` | yes |
