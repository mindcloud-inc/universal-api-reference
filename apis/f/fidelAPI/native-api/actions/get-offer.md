# Get Offer with Fidel API

Retrieves an offer from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/offers/:offerId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Offer](https://reference.fidel.uk/reference/get-offer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `offerId` | path | `string` | yes |
