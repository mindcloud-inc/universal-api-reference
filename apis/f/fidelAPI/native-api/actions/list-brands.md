# List Brands with Fidel API

Retrieves brands from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/brands`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [List Brands](https://reference.fidel.uk/reference/list-brands)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | query | `string` | no |
