# Delete Offer with Fidel API

Deletes an existing offer from Fidel API.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/offers/:offerId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Delete Offer](https://reference.fidel.uk/reference/delete-offer)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `offerId` | path | `string` | yes |
