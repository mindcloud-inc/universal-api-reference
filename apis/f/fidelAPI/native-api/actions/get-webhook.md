# Get Webhook with Fidel API

Retrieves a webhook from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/hooks/:hookId`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [Get Webhook](https://reference.fidel.uk/reference/get-webhook)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `hookId` | path | `string` | yes |
