# List Programs with Fidel API

Retrieves programs from Fidel API.

## Endpoint

- **Method:** `GET`
- **Path:** `/programs`
- **Base URL:** `https://api.fidel.uk/v1`
- **Official documentation:** [List Programs](https://reference.fidel.uk/reference/list-programs)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
