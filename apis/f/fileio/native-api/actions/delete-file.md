# Delete File with File.io

Deletes a file from File.io by key.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/{{key}}`
- **Base URL:** `https://file.io`
- **Official documentation:** [Delete File](https://www.file.io/developers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | File.io file key to delete. |
