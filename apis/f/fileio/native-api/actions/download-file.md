# Download File with File.io

Downloads a file from File.io by key.

## Endpoint

- **Method:** `GET`
- **Path:** `/{{key}}`
- **Base URL:** `https://file.io`
- **Official documentation:** [Download File](https://www.file.io/developers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `key` | path | `string` | yes | File.io file key to download. |
