# List Pages with Facebook

List pages you manage/own

## Endpoint

- **Method:** `GET`
- **Path:** `me/accounts`
- **Base URL:** `https://graph.facebook.com/v25.0`
- **Official documentation:** [List Pages](https://developers.facebook.com/docs/graph-api/reference/user/accounts/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
