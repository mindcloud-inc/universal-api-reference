# Get Page Ratings with Facebook

## Endpoint

- **Method:** `GET`
- **Path:** `:pageId/ratings`
- **Base URL:** `https://graph.facebook.com/v23.0/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pageId` | path | `string` | no |
| `access_token` | query | `string` | yes |
