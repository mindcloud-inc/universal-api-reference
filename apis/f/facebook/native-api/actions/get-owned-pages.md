# Get Owned Pages with Facebook

## Endpoint

- **Method:** `GET`
- **Path:** `:businessId/owned_pages?fields=id,name,access_token`
- **Base URL:** `https://graph.facebook.com/v23.0/`

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `businessId` | path | `string` | yes |
