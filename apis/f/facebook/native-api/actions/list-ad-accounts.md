# List Ad Accounts with Facebook

Retrieve a list of the advertising accounts to which the authenticated user has access.

## Endpoint

- **Method:** `GET`
- **Path:** `me/adaccounts`
- **Base URL:** `https://graph.facebook.com/v25.0`
- **Official documentation:** [List Ad Accounts](https://developers.facebook.com/docs/graph-api/reference/user/adaccounts/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fields` | query | `string` | no |
