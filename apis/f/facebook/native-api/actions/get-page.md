# Get Page with Facebook

## Endpoint

- **Method:** `GET`
- **Path:** `:pageId`
- **Base URL:** `https://graph.facebook.com/v25.0`
- **Official documentation:** [Get Page](https://developers.facebook.com/docs/graph-api/reference/page/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `pageId` | path | `string` | yes | The Facebook Page ID. |
| `fields` | query | `string` | no | Fields returned for the Page. Send multiple values as a string. |
