# List Businesses with Facebook

Retrieve a list of the business accounts to which the authenticated user has access.

## Endpoint

- **Method:** `GET`
- **Path:** `/me/businesses`
- **Base URL:** `https://graph.facebook.com/v25.0`
- **Official documentation:** [List Businesses](https://developers.facebook.com/docs/graph-api/reference/user/businesses/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fields` | query | `string` | no | Send multiple values as a string. |
