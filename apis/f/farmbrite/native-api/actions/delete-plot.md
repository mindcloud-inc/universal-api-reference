# Delete plot with Farmbrite

Deletes an existing plot from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/plots/:plot_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete plot](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `plot_id` | path | `string` | yes |
