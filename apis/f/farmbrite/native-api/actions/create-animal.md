# Create animal with Farmbrite

Creates a new animal in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/animals`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create animal](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
