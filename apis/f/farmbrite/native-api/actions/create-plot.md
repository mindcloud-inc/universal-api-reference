# Create plot with Farmbrite

Creates a new plot in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/plots`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create plot](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | yes |
| `type` | body | `string` | yes |
