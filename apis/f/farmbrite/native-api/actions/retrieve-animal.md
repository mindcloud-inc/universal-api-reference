# Retrieve animal with Farmbrite

Retrieves a specific animal from Farmbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/animals/:animal_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Retrieve animal](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `animal_id` | path | `string` | yes |
