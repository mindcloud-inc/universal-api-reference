# Delete order with Farmbrite

Deletes an existing order from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/orders/:order_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete order](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `order_id` | path | `string` | yes |
