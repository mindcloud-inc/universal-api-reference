# Create task with Farmbrite

Creates a new task in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create task](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | yes |
| `description` | body | `string` | no |
