# Create product with Farmbrite

Creates a new product in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/products`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create product](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `title` | body | `string` | yes |
| `price` | body | `number` | yes |
