# Retrieve task with Farmbrite

Retrieves a specific task from Farmbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:task_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Retrieve task](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `task_id` | path | `string` | yes |
