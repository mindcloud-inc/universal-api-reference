# Retrieve contact with Farmbrite

Retrieves a specific contact from Farmbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Retrieve contact](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
