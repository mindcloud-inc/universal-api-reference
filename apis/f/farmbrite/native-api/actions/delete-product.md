# Delete product with Farmbrite

Deletes an existing product from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products/:product_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete product](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
