# Retrieve product with Farmbrite

Retrieves a specific product from Farmbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/products/:product_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Retrieve product](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `product_id` | path | `string` | yes |
