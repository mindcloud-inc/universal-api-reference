# Retrieve transaction with Farmbrite

Retrieves a specific transaction from Farmbrite.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/:transaction_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Retrieve transaction](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transaction_id` | path | `string` | yes |
