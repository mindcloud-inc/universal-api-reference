# Delete animal with Farmbrite

Deletes an existing animal from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/animals/:animal_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete animal](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `animal_id` | path | `string` | yes |
