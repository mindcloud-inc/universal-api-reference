# Delete tool with Farmbrite

Deletes an existing tool from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tools/:tool_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete tool](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `tool_id` | path | `string` | yes |
