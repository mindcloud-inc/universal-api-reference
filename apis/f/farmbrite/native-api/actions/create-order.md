# Create order with Farmbrite

Creates a new order in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/orders`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create order](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `first_name` | body | `string` | yes |
| `last_name` | body | `string` | yes |
| `email` | body | `string` | yes |
