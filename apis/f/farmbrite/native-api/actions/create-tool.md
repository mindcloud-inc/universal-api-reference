# Create tool with Farmbrite

Creates a new tool in Farmbrite.

## Endpoint

- **Method:** `POST`
- **Path:** `/tools`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Create tool](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | yes |
| `type` | body | `string` | yes |
