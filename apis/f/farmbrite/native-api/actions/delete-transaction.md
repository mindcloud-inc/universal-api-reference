# Delete transaction with Farmbrite

Deletes an existing transaction from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/transactions/:transaction_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete transaction](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transaction_id` | path | `string` | yes |
