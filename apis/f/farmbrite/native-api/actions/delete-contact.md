# Delete contact with Farmbrite

Deletes an existing contact from Farmbrite.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:contact_id`
- **Base URL:** `https://api.farmbrite.com/v1`
- **Official documentation:** [Delete contact](https://developers.farmbrite.com/docs/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contact_id` | path | `string` | yes |
