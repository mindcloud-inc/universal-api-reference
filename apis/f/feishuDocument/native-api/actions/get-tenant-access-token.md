# Get Tenant Access Token with Feishu Document

Retrieves a tenant access token from Feishu.

## Endpoint

- **Method:** `POST`
- **Path:** `/open-apis/auth/v3/tenant_access_token/internal`
- **Base URL:** `https://open.larksuite.com`
- **Official documentation:** [Get Tenant Access Token](https://open.larksuite.com/document/server-docs/authentication-management/access-token/tenant_access_token_internal)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
