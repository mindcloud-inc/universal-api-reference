# Get Raw Document Content with Feishu Document

Retrieves raw text content from a Feishu document.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-apis/docx/v1/documents/:document_id/raw_content`
- **Base URL:** `https://open.larksuite.com`
- **Official documentation:** [Get Raw Document Content](https://open.larksuite.com/document/server-docs/docs/docs/docx-v1/document/raw_content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique document token. |
