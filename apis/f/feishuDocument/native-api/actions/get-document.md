# Get Document with Feishu Document

Retrieves document details from Feishu Docs.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-apis/docx/v1/documents/:document_id`
- **Base URL:** `https://open.larksuite.com`
- **Official documentation:** [Get Document](https://open.larksuite.com/document/server-docs/docs/docs/docx-v1/document/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document_id` | path | `string` | yes | The unique document token. |
