# Compare Dates with Formatting

Compares two dates in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Compare Dates](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/compare-dates/compare-dates.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `startDate` | body | `string` | yes | The first date to compare. |
| `endDate` | body | `string` | yes | The second date to compare. |
