# Encode URL with Formatting

Encodes a URL string in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Encode URL](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/url-encode/url-encode.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The URL string to encode. |
