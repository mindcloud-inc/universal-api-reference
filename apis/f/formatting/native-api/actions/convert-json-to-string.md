# Convert JSON to String with Formatting

Converts JSON to a string in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Convert JSON to String](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/json-stringify/json-stringify.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `object` | yes | The JSON value to stringify. |
