# Trim Whitespace with Formatting

Trims whitespace from text in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Trim Whitespace](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/trim-whitespace/trim-whitespace.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The text to trim. |
