# Extract URL with Formatting

Extracts a URL in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Extract URL](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/extract-url/extract-url.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The text to inspect for a URL. |
