# Extract Email Address with Formatting

Extracts an email address in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Extract Email Address](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/extract-email-address/extract-email-address.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The text to inspect for an email address. |
