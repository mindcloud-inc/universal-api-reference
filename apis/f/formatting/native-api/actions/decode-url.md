# Decode URL with Formatting

Decodes a URL string in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Decode URL](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/url-decode/url-decode.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The URL string to decode. |
