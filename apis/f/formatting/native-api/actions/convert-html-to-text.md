# Convert HTML to Text with Formatting

Converts HTML to text in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Convert HTML to Text](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/html-to-text/html-to-text.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The HTML content to convert. |
