# Convert Markdown to HTML with Formatting

Converts Markdown to HTML in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Convert Markdown to HTML](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/markdown-to-html/markdown-to-html.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The Markdown content to convert. |
