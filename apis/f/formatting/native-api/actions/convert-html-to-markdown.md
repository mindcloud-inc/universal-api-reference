# Convert HTML to Markdown with Formatting

Converts HTML to Markdown in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Convert HTML to Markdown](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/html-to-markdown/html-to-markdown.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The HTML content to convert. |
