# Parse JSON with Formatting

Parses a JSON string in the Formatting app.

## Endpoint

- **Method:** `POST`
- **Path:** `/post`
- **Base URL:** `https://postman-echo.com`
- **Official documentation:** [Parse JSON](https://github.com/PipedreamHQ/pipedream/blob/master/components/formatting/actions/parse-json/parse-json.ts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `input` | body | `string` | yes | The JSON string to parse. |
