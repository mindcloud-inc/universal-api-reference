# Get Workspace with Files.com

Finds a workspace in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Workspace](https://developers.files.com/rest/resources/user-accounts/workspaces#show-workspace)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric workspace ID. |
