# Get User with Files.com

Finds a user in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get User](https://developers.files.com/rest/resources/user-accounts/users#show-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric user ID. |
