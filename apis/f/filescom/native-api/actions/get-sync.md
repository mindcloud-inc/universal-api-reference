# Get Sync with Files.com

Finds a sync in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/syncs/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Sync](https://developers.files.com/rest/resources/integrations/syncs#show-sync)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric sync ID. |
