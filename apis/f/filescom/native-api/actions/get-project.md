# Get Project with Files.com

Finds a project in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Project](https://developers.files.com/rest/resources/file-system/project-management/projects#show-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric project ID. |
