# Get Bundle with Files.com

Finds a share link in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/bundles/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Bundle](https://developers.files.com/rest/resources/sharing/share-links/bundles#show-share-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric bundle ID. |
