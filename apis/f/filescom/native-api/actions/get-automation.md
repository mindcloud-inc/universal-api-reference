# Get Automation with Files.com

Finds an automation in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/automations/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Automation](https://developers.files.com/rest/resources/automations/automations#show-automation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric automation ID. |
