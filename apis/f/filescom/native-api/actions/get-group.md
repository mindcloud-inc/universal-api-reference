# Get Group with Files.com

Finds a group in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Group](https://developers.files.com/rest/resources/user-accounts/groups#show-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric group ID. |
