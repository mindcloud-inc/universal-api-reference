# Get Notification with Files.com

Finds a notification in Files.com by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/:id`
- **Base URL:** `{siteUrl}/api/rest/v1`
- **Official documentation:** [Get Notification](https://developers.files.com/rest/resources/notifications/notifications/#show-notification)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric notification ID. |
