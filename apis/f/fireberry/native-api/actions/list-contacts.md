# List Contacts with Fireberry

Retrieves all contact records from Fireberry.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/record/contact`
- **Base URL:** `https://api.fireberry.com`
- **Official documentation:** [List Contacts](https://developers.fireberry.com/reference/get-all-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
