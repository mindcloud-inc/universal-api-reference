# Get Resource with Freepik

Retrieves detailed resource information from Freepik.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/resources/{{resource-id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Resource](https://docs.freepik.com/api-reference/resources/images-and-templates-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resource-id` | path | `number` | yes | Freepik resource identifier. |
