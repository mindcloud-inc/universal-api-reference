# Get Workflow App with Freepik

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/ai/apps/{{app-id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Workflow App](https://docs.freepik.com/api-reference/apps/get-app)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app-id` | path | `string` | yes | Freepik workflow app identifier. |
