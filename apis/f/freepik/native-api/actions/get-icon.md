# Get Icon with Freepik

Retrieves detailed icon information from Freepik.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/icons/{{id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Icon](https://docs.freepik.com/api-reference/icons/get-one-icon-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Freepik icon identifier. |
