# Download Sound Effect with Freepik

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sound-effects/{{sfx-id}}/download`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Download Sound Effect](https://docs.freepik.com/api-reference/sound-effects/download-sound-effect)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sfx-id` | path | `number` | yes | Freepik sound effect identifier to download. |
