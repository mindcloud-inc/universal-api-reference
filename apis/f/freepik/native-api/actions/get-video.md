# Get Video with Freepik

Retrieves detailed video information from Freepik.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/{{id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Video](https://docs.freepik.com/api-reference/videos/videos-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Freepik video identifier. |
