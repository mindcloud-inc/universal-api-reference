# Get Music with Freepik

Retrieves detailed music information from Freepik.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/music/{{music-id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Music](https://docs.freepik.com/api-reference/music/get-music-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `music-id` | path | `number` | yes | Freepik music track identifier. |
