# Search Sound Effects with Freepik

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sound-effects`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Search Sound Effects](https://docs.freepik.com/api-reference/sound-effects/search-sound-effects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | Sound effect search query. |
| `limit` | query | `number` | no | Maximum number of sound effects to return. |
| `offset` | query | `number` | no | Zero-based sound effect result offset. |
