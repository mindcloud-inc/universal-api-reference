# Get Sound Effect with Freepik

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/sound-effects/{{sfx-id}}`
- **Base URL:** `https://api.freepik.com`
- **Official documentation:** [Get Sound Effect](https://docs.freepik.com/api-reference/sound-effects/get-sound-effect-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sfx-id` | path | `number` | yes | Freepik sound effect identifier. |
