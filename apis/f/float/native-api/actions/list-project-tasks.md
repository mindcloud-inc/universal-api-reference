# List Project Tasks with Float

Retrieves project tasks from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/project-tasks`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Project Tasks](https://developer.float.com/api_reference.html#Project_Tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
