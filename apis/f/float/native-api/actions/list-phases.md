# List Phases with Float

Retrieves phases from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/phases`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Phases](https://developer.float.com/api_reference.html#Phases)

## Capabilities

This operation supports [pagination](../README.md#pagination).
