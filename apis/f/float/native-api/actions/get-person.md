# Get Person with Float

Retrieves person details from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/people/:people_id`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [Get Person](https://developer.float.com/api_reference.html#People)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `people_id` | path | `number` | yes | The person's id |
