# Create Client with Float

Creates a new client in Float.

## Endpoint

- **Method:** `POST`
- **Path:** `/clients`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [Create Client](https://developer.float.com/api_reference.html#Clients)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the client |
