# Get Project with Float

Retrieves project details from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:project_id`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [Get Project](https://developer.float.com/api_reference.html#Projects)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | The project's ID |
