# List Milestones with Float

Retrieves milestones from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/milestones`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Milestones](https://developer.float.com/api_reference.html#Milestones)

## Capabilities

This operation supports [pagination](../README.md#pagination).
