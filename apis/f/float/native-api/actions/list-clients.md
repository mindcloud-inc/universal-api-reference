# List Clients with Float

Retrieves clients from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Clients](https://developer.float.com/api_reference.html#Clients)

## Capabilities

This operation supports [pagination](../README.md#pagination).
