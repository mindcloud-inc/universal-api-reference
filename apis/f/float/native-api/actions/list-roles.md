# List Roles with Float

Retrieves roles from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/roles`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Roles](https://developer.float.com/api_reference.html#Roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
