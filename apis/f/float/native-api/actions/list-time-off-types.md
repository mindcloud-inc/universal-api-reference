# List Time Off Types with Float

Retrieves time off types from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/timeoff-types`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [List Time Off Types](https://developer.float.com/api_reference.html#Time_Off_Types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `active` | query | `number` | no | Filter only on active or inactive time off types |
