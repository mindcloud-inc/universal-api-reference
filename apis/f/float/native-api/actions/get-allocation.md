# Get Allocation with Float

Retrieves allocation details from Float.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:task_id`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [Get Allocation](https://developer.float.com/api_reference.html#Allocations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `number` | yes | The allocation as a task ID |
