# Create Person with Float

Creates a new person in Float.

## Endpoint

- **Method:** `POST`
- **Path:** `/people`
- **Base URL:** `https://api.float.com/v3`
- **Official documentation:** [Create Person](https://developer.float.com/api_reference.html#People)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The person's full name |
