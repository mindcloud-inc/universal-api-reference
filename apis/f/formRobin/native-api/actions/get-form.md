# Get Form with FormRobin

Retrieves a form from FormRobin.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{{id}}`
- **Base URL:** `https://formrobin.com/api/v1`
- **Official documentation:** [Get Form](https://formrobin.com/developer/docs/#tag/Forms/paths/~1forms~1{id}/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
