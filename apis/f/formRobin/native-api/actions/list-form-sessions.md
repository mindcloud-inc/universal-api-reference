# List Form Sessions with FormRobin

Retrieves form sessions for a specific form in FormRobin.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{{id}}/sessions`
- **Base URL:** `https://formrobin.com/api/v1`
- **Official documentation:** [List Form Sessions](https://formrobin.com/developer/docs/#tag/Forms/paths/~1forms~1{id}~1sessions/get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
