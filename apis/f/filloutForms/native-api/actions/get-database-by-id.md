# Get Database by ID with Fillout Forms

Retrieves a database by ID from Fillout.

## Endpoint

- **Method:** `GET`
- **Path:** `https://tables.fillout.com/api/v1/bases/:databaseId`
- **Base URL:** `https://api.fillout.com/v1/api`
- **API:** rest
- **Official documentation:** [Get Database by ID](https://www.fillout.com/help/database/get-database-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `databaseId` | path | `string` | yes | The unique identifier of the database |
