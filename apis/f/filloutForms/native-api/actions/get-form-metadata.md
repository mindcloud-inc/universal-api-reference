# Get Form Metadata with Fillout Forms

Retrieves metadata for a Fillout form.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId`
- **Base URL:** `https://api.fillout.com/v1/api`
- **API:** rest
- **Official documentation:** [Get Form Metadata](https://www.fillout.com/help/api-reference/get-form-metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The form ID to retrieve metadata for. |
