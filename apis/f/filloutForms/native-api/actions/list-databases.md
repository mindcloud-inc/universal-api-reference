# List Databases with Fillout Forms

Retrieves databases from Fillout.

## Endpoint

- **Method:** `GET`
- **Path:** `https://tables.fillout.com/api/v1/bases`
- **Base URL:** `https://api.fillout.com/v1/api`
- **API:** rest
- **Official documentation:** [List Databases](https://www.fillout.com/help/database/get-databases)
