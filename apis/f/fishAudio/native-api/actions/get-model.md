# Get Model with Fish Audio

Finds a voice model in Fish Audio by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/model/:id`
- **Base URL:** `https://api.fish.audio`
- **Official documentation:** [Get Model](https://docs.fish.audio/api-reference/endpoint/model/get-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Fish Audio model ID. |
