# Delete Model with Fish Audio

Deletes an existing voice model from Fish Audio.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/model/:id`
- **Base URL:** `https://api.fish.audio`
- **Official documentation:** [Delete Model](https://docs.fish.audio/api-reference/endpoint/model/delete-model)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Fish Audio model ID. |
