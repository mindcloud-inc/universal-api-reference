# Download File with Fibery

Retrieves a file from Fibery.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:secret`
- **Base URL:** `https://{account}.fibery.io/api`
- **Official documentation:** [Download File](https://the.fibery.io/@public/User_Guide/Guide/File-API-265)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `secret` | path | `string` | yes | File secret used in /api/files/:secret. |
