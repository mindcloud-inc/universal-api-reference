# Get Schema with Fibery

Retrieves a schema from Fibery.

## Endpoint

- **Method:** `POST`
- **Path:** `/commands`
- **Base URL:** `https://{account}.fibery.io/api`
- **Official documentation:** [Get Schema](https://the.fibery.io/@public/User_Guide/Guide/Schema-API-261)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `args.with-description?` | body | `boolean` | no | Include type descriptions in the schema response. |
