# List GraphQL Endpoints with Fibery

Retrieves GraphQL endpoint details from Fibery.

## Endpoint

- **Method:** `GET`
- **Path:** `/graphql`
- **Base URL:** `https://{account}.fibery.io/api`
- **Official documentation:** [List GraphQL Endpoints](https://the.fibery.io/@public/User_Guide/Guide/GraphQL-API-254)
