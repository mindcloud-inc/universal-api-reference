# Get Teammate with Front

Retrieves detailed teammate information from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/teammates/:teammate_id`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [Get Teammate](https://dev.frontapp.com/reference/get-teammate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teammate_id` | path | `string` | yes | The teammate ID. Front also accepts a teammate email as a resource alias. |
