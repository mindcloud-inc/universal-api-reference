# Get Message with Front

Retrieves detailed message information from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/messages/:message_id`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [Get Message](https://dev.frontapp.com/reference/get-message)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `message_id` | path | `string` | yes |
