# List Conversation Comments with Front

Retrieves a list of conversation comments from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversation_id/comments`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [List Conversation Comments](https://dev.frontapp.com/reference/list-conversation-comments)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | The conversation ID. |
