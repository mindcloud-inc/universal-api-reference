# List Conversation Followers with Front

Retrieves a list of conversation followers from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversation_id/followers`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [List Conversation Followers](https://dev.frontapp.com/reference/list-conversation-followers)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes | The conversation ID. |
