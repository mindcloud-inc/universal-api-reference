# List Contact Conversations with Front

Retrieves a list of contact conversations from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/conversations`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [List Contact Conversations](https://dev.frontapp.com/reference/list-contact-conversations)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
