# List Contacts with Front

Retrieves a list of contacts from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [List Contacts](https://dev.frontapp.com/reference/list-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
