# Search Conversations with Front

Finds conversations in Front by query.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/search/:query`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [Search Conversations](https://dev.frontapp.com/reference/search-conversations)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `query` | path | `string` | yes |
