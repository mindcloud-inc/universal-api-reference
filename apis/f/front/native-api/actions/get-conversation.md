# Get Conversation with Front

Retrieves detailed conversation information from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:conversation_id`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [Get Conversation](https://dev.frontapp.com/reference/get-conversation-by-id)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `conversation_id` | path | `string` | yes |
