# List Contact Notes with Front

Retrieves a list of contact notes from Front.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:contactId/notes`
- **Base URL:** `https://api2.frontapp.com`
- **Official documentation:** [List Contact Notes](https://dev.frontapp.com/reference/list-notes)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `contactId` | path | `string` | yes |
