# List Wanted Records with FBI Most Wanted

Retrieves wanted records from FBI Most Wanted.

## Endpoint

- **Method:** `GET`
- **Path:** `/list`
- **Base URL:** `https://api.fbi.gov/wanted/v1`
- **Official documentation:** [List Wanted Records](https://www.fbi.gov/wanted/api)

## Capabilities

This operation supports [filtering](../README.md#filtering).
