# Back Off with FOAAS

## Endpoint

- **Method:** `GET`
- **Path:** `/back/:name/:from`
- **Base URL:** `https://foaas.io`
- **Official documentation:** [Back Off](https://foaas.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | path | `string` | yes |
| `from` | path | `string` | yes |
