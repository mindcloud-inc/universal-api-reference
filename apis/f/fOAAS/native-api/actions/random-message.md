# Random Message with FOAAS

## Endpoint

- **Method:** `GET`
- **Path:** `/random/:from`
- **Base URL:** `https://foaas.io`
- **Official documentation:** [Random Message](https://foaas.io/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `from` | path | `string` | yes |
