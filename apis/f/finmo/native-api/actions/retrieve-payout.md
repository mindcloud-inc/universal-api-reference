# Retrieve Payout with Finmo

Finds a payout in Finmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/payout/:payout_id`
- **Base URL:** `https://api.finmo.net/v1/`
- **Official documentation:** [Retrieve Payout](https://docs.finmo.net/reference/retrievepayout-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `payout_id` | path | `string` | yes |
