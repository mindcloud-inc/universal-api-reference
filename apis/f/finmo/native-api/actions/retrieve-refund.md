# Retrieve Refund with Finmo

Finds a refund in Finmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/refund/:refund_id`
- **Base URL:** `https://api.finmo.net/v1/`
- **Official documentation:** [Retrieve Refund](https://docs.finmo.net/reference/retrieverefund-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `refund_id` | path | `string` | yes |
