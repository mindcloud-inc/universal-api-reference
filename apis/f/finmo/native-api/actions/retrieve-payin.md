# Retrieve Payin with Finmo

Finds a payin in Finmo by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/payin/:payin_id`
- **Base URL:** `https://api.finmo.net/v1/`
- **Official documentation:** [Retrieve Payin](https://docs.finmo.net/reference/retrievepayin-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `payin_id` | path | `string` | yes |
