# List a single Order with Faire

## Endpoint

- **Method:** `GET`
- **Path:** `orders/:id`
- **Base URL:** `https://www.faire.com/external-api/v2/`
- **Official documentation:** [List a single Order](https://faire.github.io/external-api-docs/#get-all-orders)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
