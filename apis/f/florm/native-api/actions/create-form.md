# Create Form with Florm

Creates a new form in Florm.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/forms/`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Create Form](https://api.florm.io/docs#/default/create_form_v1_forms__post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | yes | Title for the new Florm form. |
