# Get Form with Florm

Retrieves a specific form from Florm.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/forms/:form_guid`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Get Form](https://api.florm.io/docs#/default/get_form_v1_forms__form_guid__get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_guid` | path | `string` | yes | GUID of the Florm form. |
