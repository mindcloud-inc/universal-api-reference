# List Public Design Themes with Florm

Retrieves public design themes from Florm.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/design-themes/`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [List Public Design Themes](https://api.florm.io/docs#/default/get_all_public_v1_design_themes__get)
