# Get Healthcheck with Florm

Retrieves the current Florm healthcheck status.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/healthcheck/`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Get Healthcheck](https://api.florm.io/docs#/default/perform_healthcheck_v1_healthcheck__get)
