# Get My Workspace with Florm

Retrieves your private workspace from Florm.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/workspaces/my`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Get My Workspace](https://api.florm.io/docs#/default/get_private_workspace_v1_workspaces_my_get)
