# Refresh Access Token with Florm

Refreshes an access token in Florm.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/auth/refresh-token`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Refresh Access Token](https://api.florm.io/docs#/default/refresh_token_v1_auth_refresh_token_post)
