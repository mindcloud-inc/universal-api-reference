# Get Demo Token with Florm

Retrieves a demo access token from Florm.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/auth/magic-links/demo`
- **Base URL:** `https://api.florm.io`
- **Official documentation:** [Get Demo Token](https://api.florm.io/docs#/default/get_demo_token_v1_auth_magic_links_demo_put)
