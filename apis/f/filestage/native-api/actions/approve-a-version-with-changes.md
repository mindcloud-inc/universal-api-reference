# Approve a Version With Changes with Filestage

Approves a Filestage review version with changes.

## Endpoint

- **Method:** `POST`
- **Path:** `/reviews/{reviewId}/approve-with-changes`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Approve a Version With Changes](https://developers.filestage.io/docs/api/esma0fr0ql07c-approve-a-version-with-changes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
