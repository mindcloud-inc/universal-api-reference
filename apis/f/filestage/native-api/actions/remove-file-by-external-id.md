# Remove File by External ID with Filestage

Deletes a Filestage file by external ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove File by External ID](https://developers.filestage.io/docs/api/oh7eqeplqtm9s-remove-file-by-external-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalId` | query | `string` | yes | `externalId` of the file |
