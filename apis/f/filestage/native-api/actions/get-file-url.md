# Get File URL with Filestage

Retrieves a file URL from Filestage by version.

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/{versionId}/fileDatas/url`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get File URL](https://developers.filestage.io/docs/api/yvzft64lktvar-get-file-url)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Version id |
