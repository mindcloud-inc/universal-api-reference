# Get Folder by ID with Filestage

Retrieves a folder from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/{folderId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Folder by ID](https://developers.filestage.io/docs/api/edi8abom371wf-get-folder-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `string` | yes | Folder Id |
