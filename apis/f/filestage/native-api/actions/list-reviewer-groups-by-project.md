# List Reviewer Groups by Project with Filestage

Retrieves reviewer groups from a Filestage project.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}/steps`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Reviewer Groups by Project](https://developers.filestage.io/docs/api/pojhx8u6q36m6-get-reviewer-groups-by-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | filter by project |
