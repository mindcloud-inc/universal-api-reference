# List Project Templates with Filestage

Retrieves project templates from Filestage.

## Endpoint

- **Method:** `GET`
- **Path:** `/project-templates`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Project Templates](https://developers.filestage.io/docs/api/j7p98elyaunwp-get-project-templates)
