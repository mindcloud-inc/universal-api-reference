# Remove Comment with Filestage

Deletes a comment from Filestage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/comments/{commentId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Comment](https://developers.filestage.io/docs/api/99do8o0x8cv8d-remove-comment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `commentId` | path | `string` | yes |
