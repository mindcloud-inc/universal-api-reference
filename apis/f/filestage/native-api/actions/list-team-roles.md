# List Team Roles with Filestage

Retrieves team roles from Filestage.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/roles`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Team Roles](https://developers.filestage.io/docs/api/flp2tp0jr8urf-get-team-roles)
