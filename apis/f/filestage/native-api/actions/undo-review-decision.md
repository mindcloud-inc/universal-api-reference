# Undo Review Decision with Filestage

Deletes a review decision from Filestage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/reviews/{reviewId}/decision`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Undo Review Decision](https://developers.filestage.io/docs/api/i26y66fo0yywp-undo-review-decision)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `reviewId` | path | `string` | yes |
