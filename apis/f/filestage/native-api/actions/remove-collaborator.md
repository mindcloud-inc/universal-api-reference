# Remove Collaborator with Filestage

Deletes a collaborator from a Filestage project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{projectId}/collaborators/{collaboratorId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Collaborator](https://developers.filestage.io/docs/api/zrnm39e80f9pl-remove-collaborator)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | path | `string` | yes |
| `collaboratorId` | path | `string` | yes |
