# Reject a Version with Filestage

Rejects a Filestage review version.

## Endpoint

- **Method:** `POST`
- **Path:** `/reviews/{reviewId}/reject`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Reject a Version](https://developers.filestage.io/docs/api/a6lulqg6zfp12-reject-a-version)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
