# Approve a Version with Filestage

Approves a Filestage review version.

## Endpoint

- **Method:** `POST`
- **Path:** `/reviews/{reviewId}/approve`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Approve a Version](https://developers.filestage.io/docs/api/bl3h108vb7qfj-approve-a-version)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
