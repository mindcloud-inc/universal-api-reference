# Remove Project by ID with Filestage

Deletes a project from Filestage by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{projectId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Project by ID](https://developers.filestage.io/docs/api/hmd9lnnpmf79o-remove-project-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project Id |
