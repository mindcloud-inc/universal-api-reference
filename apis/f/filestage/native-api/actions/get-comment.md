# Get Comment with Filestage

Retrieves a comment from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/comments/{commentId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Comment](https://developers.filestage.io/docs/api/svpjaocu9js3z-get-comment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `commentId` | path | `string` | yes |
