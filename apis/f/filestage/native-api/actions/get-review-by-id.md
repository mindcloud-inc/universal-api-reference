# Get Review by ID with Filestage

Retrieves a review from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/reviews/{reviewId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Review by ID](https://developers.filestage.io/docs/api/idzslehyfp37z-get-review-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
