# List Files by Parameters with Filestage

Finds Filestage files by external ID or form answer.

## Endpoint

- **Method:** `GET`
- **Path:** `/files`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Files by Parameters](https://developers.filestage.io/docs/api/9za81gw5tvkc3-get-files-by-parameters)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `externalId` | query | `string` | yes | `externalId` of the file |
