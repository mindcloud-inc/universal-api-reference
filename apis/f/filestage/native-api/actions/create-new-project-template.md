# Create New Project Template with Filestage

Creates a new project template in Filestage.

## Endpoint

- **Method:** `POST`
- **Path:** `/project-templates`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Create New Project Template](https://developers.filestage.io/docs/api/gbp5tkhkneye5-create-new-project-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the project template. |
