# Remove Project Template with Filestage

Deletes a project template from Filestage.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/project-templates/{projectTemplateId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Project Template](https://developers.filestage.io/docs/api/n61dfggl3druf-remove-project-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectTemplateId` | path | `string` | yes | ID of the project template |
