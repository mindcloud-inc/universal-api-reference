# Start a Review with Filestage

Starts a review in Filestage.

## Endpoint

- **Method:** `POST`
- **Path:** `/reviews`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Start a Review](https://developers.filestage.io/docs/api/fv1oow7b8r46b-start-a-review)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `versionId` | body | `string` | yes |
| `stepId` | body | `string` | yes |
