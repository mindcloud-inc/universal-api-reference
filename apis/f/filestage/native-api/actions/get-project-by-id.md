# Get Project by ID with Filestage

Retrieves a project from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/{projectId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Project by ID](https://developers.filestage.io/docs/api/sfo3vv07mr128-get-project-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project Id |
