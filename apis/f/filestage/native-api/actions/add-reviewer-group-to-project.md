# Add Reviewer Group to Project with Filestage

Creates a reviewer group in a Filestage project.

## Endpoint

- **Method:** `POST`
- **Path:** `/steps`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Add Reviewer Group to Project](https://developers.filestage.io/docs/api/d6pww0n8354za-add-reviewer-group-to-project)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `projectId` | body | `string` | yes |
| `name` | body | `string` | yes |
