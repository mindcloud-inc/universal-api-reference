# Request Changes with Filestage

Requests changes for a Filestage review version.

## Endpoint

- **Method:** `POST`
- **Path:** `/reviews/{reviewId}/request-changes`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Request Changes](https://developers.filestage.io/docs/api/koplrg8gcmlde-request-changes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
