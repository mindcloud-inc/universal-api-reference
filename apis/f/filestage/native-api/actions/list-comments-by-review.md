# List Comments by Review with Filestage

Retrieves comments from a Filestage review.

## Endpoint

- **Method:** `GET`
- **Path:** `/reviews/{reviewId}/comments`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Comments by Review](https://developers.filestage.io/docs/api/l2twb6d5i18my-get-comments-by-review)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
