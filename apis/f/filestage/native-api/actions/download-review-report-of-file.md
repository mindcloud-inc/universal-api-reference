# Download Review Report of File with Filestage

Downloads a review report for a Filestage file.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}/report`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Download Review Report of File](https://developers.filestage.io/docs/api/8f7a68yac21ff-download-review-report-of-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id |
