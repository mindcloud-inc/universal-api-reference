# Get File by ID with Filestage

Retrieves a file from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get File by ID](https://developers.filestage.io/docs/api/t6rimdwbnx4rt-get-file-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id |
