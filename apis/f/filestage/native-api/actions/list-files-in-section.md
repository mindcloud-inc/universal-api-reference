# List Files in Section with Filestage

Retrieves files from a Filestage section.

## Endpoint

- **Method:** `GET`
- **Path:** `/sections/{sectionId}/files`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Files in Section](https://developers.filestage.io/docs/api/bb86bv2rotkox-get-files-in-section)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sectionId` | path | `string` | yes | Section Id |
