# Download Review Report of Review with Filestage

Downloads a review report for a Filestage review.

## Endpoint

- **Method:** `GET`
- **Path:** `/reviews/{reviewId}/report`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Download Review Report of Review](https://developers.filestage.io/docs/api/wwjic2o2f4m2r-download-review-report-of-review)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reviewId` | path | `string` | yes | Review Id |
