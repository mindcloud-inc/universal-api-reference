# Download File Version with Filestage

Downloads a file version from Filestage.

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/{versionId}/contents`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Download File Version](https://developers.filestage.io/docs/api/zjznxwryl60f7-download-file-version)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `versionId` | path | `string` | yes | Version Id |
