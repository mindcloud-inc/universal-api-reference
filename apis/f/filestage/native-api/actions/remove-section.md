# Remove Section with Filestage

Deletes a section from a Filestage project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/{projectId}/sections/{sectionId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Section](https://developers.filestage.io/docs/api/fotiebmtuj7xt-remove-section)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | Project Id |
| `sectionId` | path | `string` | yes | Section Id |
