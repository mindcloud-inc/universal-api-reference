# Get Review Decision Count with Filestage

Retrieves review decision counts from a Filestage section.

## Endpoint

- **Method:** `GET`
- **Path:** `/sections/{sectionId}/reviews/status/count`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Review Decision Count](https://developers.filestage.io/docs/api/tfo8lt6wpzuxk-number-of-review-decisions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sectionId` | path | `string` | yes | Section Id |
