# Remove File with Filestage

Deletes a file from Filestage by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/{fileId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove File](https://developers.filestage.io/docs/api/1oshr8x026hcw-remove-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | File Id |
