# Get Reviewer Group by ID with Filestage

Retrieves a reviewer group from Filestage by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/steps/{stepId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Get Reviewer Group by ID](https://developers.filestage.io/docs/api/el174yzb9c3um-get-reviewer-group-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `stepId` | path | `string` | yes | Step Id |
