# List Team Members with Filestage

Retrieves team members from Filestage.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/members`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [List Team Members](https://developers.filestage.io/docs/api/ry33j5vt8rpcs-get-team-members)
