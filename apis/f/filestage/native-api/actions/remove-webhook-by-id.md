# Remove Webhook by ID with Filestage

Deletes a webhook from Filestage by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{webhookId}`
- **Base URL:** `https://api.filestage.io/ext/v2`
- **Official documentation:** [Remove Webhook by ID](https://developers.filestage.io/docs/api/9chghs3azv2lg-remove-webhook-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The ID of the webhook |
