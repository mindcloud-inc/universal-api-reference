# Get Order with Fourthwall

Retrieves an order from Fourthwall by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/order/:orderId`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Order](https://docs.fourthwall.com/api-reference/platform/orders/get-order)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orderId` | path | `string` | yes | The order ID. |
