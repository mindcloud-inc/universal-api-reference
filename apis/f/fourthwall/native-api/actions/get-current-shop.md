# Get Current Shop with Fourthwall

Retrieves the current shop from Fourthwall.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/shops/current`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Current Shop](https://docs.fourthwall.com/api-reference/platform/shop/get-current-shop)
