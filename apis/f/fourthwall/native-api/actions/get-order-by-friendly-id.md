# Get Order By Friendly ID with Fourthwall

Retrieves an order from Fourthwall by friendly ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/order/by-friendly-id/:friendlyId`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Order By Friendly ID](https://docs.fourthwall.com/api-reference/platform/orders/get-order-by-friendly-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `friendlyId` | path | `string` | yes | The order friendly ID. |
