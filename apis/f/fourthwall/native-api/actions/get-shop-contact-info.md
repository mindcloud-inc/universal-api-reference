# Get Shop Contact Info with Fourthwall

Retrieves current shop contact info from Fourthwall.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/shops/current/contact-info`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Shop Contact Info](https://docs.fourthwall.com/api-reference/platform/shop/get-shop-contact-info)
