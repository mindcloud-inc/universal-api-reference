# List Promotions with Fourthwall

Retrieves a list of promotions from Fourthwall.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/promotions`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [List Promotions](https://docs.fourthwall.com/api-reference/platform/promotions/list-promotions)

## Capabilities

This operation supports [pagination](../README.md#pagination).
