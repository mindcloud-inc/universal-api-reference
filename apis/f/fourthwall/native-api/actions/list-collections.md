# List Collections with Fourthwall

Retrieves a paginated list of collections from Fourthwall.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/collections`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [List Collections](https://docs.fourthwall.com/api-reference/platform/collections/list-collections)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Search collections by keyword. |
