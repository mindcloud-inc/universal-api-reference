# Get Product Inventory with Fourthwall

Retrieves product inventory from Fourthwall by product ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/products/:productId/inventory`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Product Inventory](https://docs.fourthwall.com/api-reference/platform/products/get-product-inventory)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The product ID. |
