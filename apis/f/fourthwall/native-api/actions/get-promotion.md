# Get Promotion with Fourthwall

Retrieves a promotion from Fourthwall by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/promotions/:promotionId`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Promotion](https://docs.fourthwall.com/api-reference/platform/promotions/get-promotion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `promotionId` | path | `string` | yes | The promotion ID. |
