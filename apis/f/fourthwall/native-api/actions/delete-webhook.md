# Delete Webhook with Fourthwall

Deletes an existing webhook from Fourthwall.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/open-api/v1.0/webhooks/:webhookConfigurationId`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Delete Webhook](https://docs.fourthwall.com/api-reference/platform/webhooks/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookConfigurationId` | path | `string` | yes | The webhook configuration ID. |
