# Get Product with Fourthwall

Retrieves a product from Fourthwall by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/products/:productId`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [Get Product](https://docs.fourthwall.com/api-reference/platform/products/get-product)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | The product ID. |
