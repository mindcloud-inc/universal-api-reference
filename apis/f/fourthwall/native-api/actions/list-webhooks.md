# List Webhooks with Fourthwall

Retrieves a list of webhooks from Fourthwall.

## Endpoint

- **Method:** `GET`
- **Path:** `/open-api/v1.0/webhooks`
- **Base URL:** `https://api.fourthwall.com`
- **Official documentation:** [List Webhooks](https://docs.fourthwall.com/api-reference/platform/webhooks/list-webhooks)
