# Translate to Yoda with Fun Translations

## Endpoint

- **Method:** `POST`
- **Path:** `/yodish`
- **Base URL:** `https://api.funtranslations.com/translate`
- **Official documentation:** [Translate to Yoda](https://funtranslations.com/api/yodish)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | body | `string` | yes | Required text to translate. |
