# List Form Fields with Formstack

Retrieves fields for a form from Formstack.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/fields`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [List Form Fields](https://developers.formstack.com/reference/getformfields-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `number` | yes | The ID of the form. |
