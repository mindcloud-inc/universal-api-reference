# Get Submission with Formstack

Retrieves details for a submission from Formstack.

## Endpoint

- **Method:** `GET`
- **Path:** `/submissions/:submissionId`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [Get Submission](https://developers.formstack.com/reference/getsubmissiondetails-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `number` | yes | The unique identifier of the submission to retrieve. |
