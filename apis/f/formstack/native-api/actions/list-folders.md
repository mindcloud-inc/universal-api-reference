# List Folders with Formstack

Retrieves folders and subfolders from Formstack.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [List Folders](https://developers.formstack.com/reference/listfolders-1)

## Capabilities

This operation supports [pagination](../README.md#pagination).
