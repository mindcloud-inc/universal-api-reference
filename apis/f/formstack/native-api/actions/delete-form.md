# Delete Form with Formstack

Deletes a form from Formstack by marking it as deleted.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/forms/:formId`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [Delete Form](https://developers.formstack.com/reference/deleteform-1)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `formId` | path | `list<number>` | yes |
