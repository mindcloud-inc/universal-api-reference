# Get Form HTML with Formstack

Retrieves HTML markup for a form from Formstack.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:formId/html`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [Get Form HTML](https://developers.formstack.com/reference/getformhtml-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `list<number>` | yes | The ID of the form. |
