# Get Folder with Formstack

Retrieves details for a folder from Formstack.

## Endpoint

- **Method:** `GET`
- **Path:** `/folders/:folderId`
- **Base URL:** `https://www.formstack.com/api/v2025`
- **Official documentation:** [Get Folder](https://developers.formstack.com/reference/getfolder-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `folderId` | path | `number` | yes | The ID of the folder. |
