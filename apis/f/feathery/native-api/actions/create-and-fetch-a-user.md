# Create and Fetch a User with Feathery

## Endpoint

- **Method:** `POST`
- **Path:** `/api/user/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Create and Fetch a User](https://api-docs.feathery.io/#create-and-fetch-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `string` | yes | Your unique user ID. |
