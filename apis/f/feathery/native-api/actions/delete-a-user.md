# Delete a User with Feathery

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/user/:id/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Delete a User](https://api-docs.feathery.io/#delete-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the user to delete. |
