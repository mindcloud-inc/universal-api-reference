# Retrieve Form Schema with Feathery

## Endpoint

- **Method:** `GET`
- **Path:** `/api/form/:form_id/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Retrieve Form Schema](https://api-docs.feathery.io/#retrieve-a-form-schema)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `string` | yes | The ID of the form to retrieve. |
