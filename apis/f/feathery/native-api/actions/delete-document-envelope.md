# Delete Document Envelope with Feathery

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/document/envelope/:envelope_id/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Delete Document Envelope](https://api-docs.feathery.io/#delete-document-envelope)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `envelope_id` | path | `string` | yes | The ID of the envelope to delete. |
