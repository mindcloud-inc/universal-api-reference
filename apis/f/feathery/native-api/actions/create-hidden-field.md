# Create Hidden Field with Feathery

## Endpoint

- **Method:** `POST`
- **Path:** `/api/form/hidden_field/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Create Hidden Field](https://api-docs.feathery.io/#create-hidden-field)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `field_id` | body | `string` | yes | A new unique ID for the hidden field to create. |
