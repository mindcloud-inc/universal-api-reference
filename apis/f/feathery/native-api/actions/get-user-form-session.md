# Get User Form Session with Feathery

## Endpoint

- **Method:** `GET`
- **Path:** `/api/user/:user_id/session/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [Get User Form Session](https://api-docs.feathery.io/#get-user-form-session)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | The user ID whose form session you want to retrieve. |
