# List All Data for a User with Feathery

## Endpoint

- **Method:** `GET`
- **Path:** `/api/field/`
- **Base URL:** `https://api.feathery.io`
- **Official documentation:** [List All Data for a User](https://api-docs.feathery.io/#list-all-data-for-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | no | The user ID whose submitted field data you want to list. |
