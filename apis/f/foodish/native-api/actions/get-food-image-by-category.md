# Get Food Image by Category with Foodish

## Endpoint

- **Method:** `GET`
- **Path:** `/api/images/:category`
- **Base URL:** `https://foodish-api.com`
- **Official documentation:** [Get Food Image by Category](https://github.com/surhud004/Foodish)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category` | path | `string` | yes | Foodish food category. The provider documents category availability on its demo site. |
