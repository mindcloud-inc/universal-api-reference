# List Milestones with Freedcamp

Retrieves a list of milestones from Freedcamp.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/milestones`
- **Base URL:** `https://freedcamp.com`
- **Official documentation:** [List Milestones](https://freedcamp.com/help_/tutorials/wiki/wiki_public/view/DFaab)
