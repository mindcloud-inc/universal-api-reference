# Get Task with Freedcamp

Retrieves a task from Freedcamp by task ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/tasks/:taskId`
- **Base URL:** `https://freedcamp.com`
- **Official documentation:** [Get Task](https://freedcamp.com/help_/tutorials/wiki/wiki_public/view/DFaab)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The Freedcamp task ID. |
