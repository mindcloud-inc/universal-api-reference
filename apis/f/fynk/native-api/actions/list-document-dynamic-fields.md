# List Document Dynamic Fields with fynk

Retrieves dynamic fields for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/dynamic-fields`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Document Dynamic Fields](https://app.fynk.com/v1/docs#/operations/v1.documents.dynamic-fields.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
