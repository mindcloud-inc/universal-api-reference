# Create Document PDF Upload URL with fynk

Creates a document PDF upload URL in fynk.

## Endpoint

- **Method:** `POST`
- **Path:** `/file-uploads/document-pdf`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Create Document PDF Upload URL](https://app.fynk.com/v1/docs#/operations/v1.file-uploads.document-pdf.create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content_type` | body | `string` | no | The MIME content type for the PDF upload. |
