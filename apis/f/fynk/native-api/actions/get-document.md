# Get Document with fynk

Retrieves detailed information for a document from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Get Document](https://app.fynk.com/v1/docs#/operations/v1.documents.show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
