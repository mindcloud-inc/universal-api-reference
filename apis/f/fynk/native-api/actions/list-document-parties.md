# List Document Parties with fynk

Retrieves parties for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/parties`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Document Parties](https://app.fynk.com/v1/docs#/operations/v1.documents.parties.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
