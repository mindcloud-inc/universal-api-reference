# List Document Metadata Values with fynk

Retrieves metadata values for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/metadata-values`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Document Metadata Values](https://app.fynk.com/v1/docs#/operations/v1.documents.metadata-values.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | yes | The document UUID. |
