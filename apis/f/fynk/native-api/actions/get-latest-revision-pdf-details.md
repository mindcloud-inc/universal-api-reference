# Get Latest Revision PDF Details with fynk

Retrieves the latest revision PDF details from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/revisions/latest/pdf`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Get Latest Revision PDF Details](https://app.fynk.com/v1/docs#/operations/v1.documents.revisions.latest.pdf.show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
