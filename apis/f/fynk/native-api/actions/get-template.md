# Get Template with fynk

Retrieves detailed template information from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:template`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Get Template](https://app.fynk.com/v1/docs#/operations/v1.templates.show)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `template` | path | `string` | yes | The template UUID. |
