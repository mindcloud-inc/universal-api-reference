# List Document Signatories with fynk

Retrieves signatories for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/signatories`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Document Signatories](https://app.fynk.com/v1/docs#/operations/v1.documents.signatories.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
