# List Document Comments with fynk

Retrieves comments for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/comments`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Document Comments](https://app.fynk.com/v1/docs#/operations/v1.documents.comments.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
