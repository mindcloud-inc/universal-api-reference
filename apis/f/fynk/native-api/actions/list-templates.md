# List Templates with fynk

Retrieves a list of templates from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Templates](https://app.fynk.com/v1/docs#/operations/v1.templates.index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
