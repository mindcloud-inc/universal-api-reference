# List Tags with fynk

Retrieves a list of tags from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Tags](https://app.fynk.com/v1/docs#/operations/v1.tags.index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
