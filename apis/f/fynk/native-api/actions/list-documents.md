# List Documents with fynk

Retrieves a list of documents from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Documents](https://app.fynk.com/v1/docs#/operations/v1.documents.index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
