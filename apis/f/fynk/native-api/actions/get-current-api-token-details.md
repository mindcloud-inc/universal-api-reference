# Get Current API Token Details with fynk

Retrieves the current API token details from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Get Current API Token Details](https://app.fynk.com/v1/docs#/operations/v1.api-tokens.show-me)
