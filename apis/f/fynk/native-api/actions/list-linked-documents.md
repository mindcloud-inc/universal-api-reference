# List Linked Documents with fynk

Retrieves linked documents for a document in fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/linked-documents`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [List Linked Documents](https://app.fynk.com/v1/docs#/operations/v1.documents.linked-documents.index)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
