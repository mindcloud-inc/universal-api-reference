# Create Document File Storage Upload URL with fynk

Creates a document file storage upload URL in fynk.

## Endpoint

- **Method:** `POST`
- **Path:** `/file-uploads/document-file-storage`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Create Document File Storage Upload URL](https://app.fynk.com/v1/docs#/operations/v1.file-uploads.document-file-storage.create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `content_type` | body | `string` | no | MIME type for the file storage upload URL request. |
