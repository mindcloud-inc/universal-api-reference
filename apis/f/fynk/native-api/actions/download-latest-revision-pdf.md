# Download Latest Revision PDF with fynk

Retrieves the latest revision PDF from fynk.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:document/revisions/latest/pdf/download`
- **Base URL:** `https://app.fynk.com/v1/api`
- **Official documentation:** [Download Latest Revision PDF](https://app.fynk.com/v1/docs#/operations/v1.documents.revisions.latest.pdf.download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `document` | path | `string` | no | Document UUID. |
