# Get Form with 123FormBuild

Retrieves a form from 123FormBuilder.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{form_id}`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [Get Form](https://www.123formbuilder.com/developer/api-v2-forms/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `number` | yes | The ID of the form |
