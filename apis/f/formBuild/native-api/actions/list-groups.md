# List Groups with 123FormBuild

Retrieves groups from your 123FormBuilder account.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [List Groups](https://www.123formbuilder.com/developer/api-v2-groups/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
