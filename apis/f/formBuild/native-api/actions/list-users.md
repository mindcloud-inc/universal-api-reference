# List Users with 123FormBuild

Retrieves the master user and subusers from 123FormBuilder.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [List Users](https://www.123formbuilder.com/developer/api-v2-users/)

## Capabilities

This operation supports [pagination](../README.md#pagination).
