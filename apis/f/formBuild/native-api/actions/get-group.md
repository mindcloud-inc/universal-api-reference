# Get Group with 123FormBuild

Retrieves a group from 123FormBuilder.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{group_id}`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [Get Group](https://www.123formbuilder.com/developer/api-v2-groups/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `number` | yes | The ID of the group |
