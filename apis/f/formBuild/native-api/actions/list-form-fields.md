# List Form Fields with 123FormBuild

Retrieves form fields from a form in 123FormBuilder.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/{form_id}/fields`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [List Form Fields](https://www.123formbuilder.com/developer/api-v2-forms/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_id` | path | `number` | yes | The ID of the form |
