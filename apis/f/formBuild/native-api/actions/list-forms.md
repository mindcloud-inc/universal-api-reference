# List Forms with 123FormBuild

Retrieves forms from your 123FormBuilder account.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [List Forms](https://www.123formbuilder.com/developer/api-v2-forms/)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | Filter form name |
