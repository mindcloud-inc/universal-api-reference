# List Group Forms with 123FormBuild

Retrieves forms from a group in 123FormBuilder.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/{group_id}/forms`
- **Base URL:** `https://api.123formbuilder.com/v2`
- **Official documentation:** [List Group Forms](https://www.123formbuilder.com/developer/api-v2-groups/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `number` | yes | The ID of the group |
