# Get User with Flexopus

Retrieves a specific user from Flexopus.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `{tenantBaseUrl}/api/v1`
- **Official documentation:** [Get User](https://flexopus.com/api/docs/#endpoints-GETapi-v1-users--id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the user. |
