# Get Event with Flexopus

Retrieves a specific event from Flexopus.

## Endpoint

- **Method:** `GET`
- **Path:** `/events/:id`
- **Base URL:** `{tenantBaseUrl}/api/v1`
- **Official documentation:** [Get Event](https://flexopus.com/api/docs/#endpoints-GETapi-v1-events--id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the event. |
