# Delete Booking with Flexopus

Deletes an existing booking from Flexopus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings/:id`
- **Base URL:** `{tenantBaseUrl}/api/v1`
- **Official documentation:** [Delete Booking](https://flexopus.com/api/docs/#endpoints-DELETEapi-v1-bookings--id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the booking. |
