# Delete Event with Flexopus

Deletes an existing event from Flexopus.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/events/:id`
- **Base URL:** `{tenantBaseUrl}/api/v1`
- **Official documentation:** [Delete Event](https://flexopus.com/api/docs/#endpoints-DELETEapi-v1-events--id-)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The ID of the event. |
