# Get Revenue Geographic Segmentation with Financial Modeling Prep

Retrieves revenue segmentation by geography from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/revenue-geographic-segmentation`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Revenue Geographic Segmentation](https://site.financialmodelingprep.com/developer/docs/stable/revenue-geographic-segmentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
