# Get Short Stock Quote with Financial Modeling Prep

Retrieves a short stock quote from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/quote-short`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Short Stock Quote](https://site.financialmodelingprep.com/developer/docs/stable/quote-short)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
