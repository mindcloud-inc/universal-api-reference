# Get Earnings with Financial Modeling Prep

Retrieves earnings from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/earnings`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Earnings](https://site.financialmodelingprep.com/developer/docs/stable/earnings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
