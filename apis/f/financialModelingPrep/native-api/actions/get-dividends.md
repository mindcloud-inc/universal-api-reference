# Get Dividends with Financial Modeling Prep

Retrieves dividends from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/dividends`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Dividends](https://site.financialmodelingprep.com/developer/docs/stable/dividends)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
