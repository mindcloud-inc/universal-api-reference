# Get Company Notes with Financial Modeling Prep

Retrieves company notes from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/company-notes`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Company Notes](https://site.financialmodelingprep.com/developer/docs/stable/company-notes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
