# Get Owner Earnings with Financial Modeling Prep

Retrieves owner earnings from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/owner-earnings`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Owner Earnings](https://site.financialmodelingprep.com/developer/docs/stable/owner-earnings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
