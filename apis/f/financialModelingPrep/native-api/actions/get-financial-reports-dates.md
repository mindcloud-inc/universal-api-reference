# Get Financial Reports Dates with Financial Modeling Prep

Retrieves financial report dates from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-reports-dates`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Financial Reports Dates](https://site.financialmodelingprep.com/developer/docs/stable/financial-reports-dates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
