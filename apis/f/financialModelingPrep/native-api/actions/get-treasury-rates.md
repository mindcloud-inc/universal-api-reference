# Get Treasury Rates with Financial Modeling Prep

Retrieves treasury rates from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/treasury-rates`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Treasury Rates](https://site.financialmodelingprep.com/developer/docs/stable/treasury-rates)
