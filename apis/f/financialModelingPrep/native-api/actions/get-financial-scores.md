# Get Financial Scores with Financial Modeling Prep

Retrieves financial scores from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-scores`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Financial Scores](https://site.financialmodelingprep.com/developer/docs/stable/financial-scores)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
