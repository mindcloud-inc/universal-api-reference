# Get As Reported Income Statement with Financial Modeling Prep

Retrieves as-reported income statements from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/income-statement-as-reported`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get As Reported Income Statement](https://site.financialmodelingprep.com/developer/docs/stable/income-statement-as-reported)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
