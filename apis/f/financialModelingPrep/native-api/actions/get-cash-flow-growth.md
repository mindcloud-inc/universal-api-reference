# Get Cash Flow Growth with Financial Modeling Prep

Retrieves cash flow growth data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/cash-flow-statement-growth`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Cash Flow Growth](https://site.financialmodelingprep.com/developer/docs/stable/cash-flow-statement-growth)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
