# Get Financial Ratios with Financial Modeling Prep

Retrieves financial ratios from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/ratios`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Financial Ratios](https://site.financialmodelingprep.com/developer/docs/stable/ratios)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
