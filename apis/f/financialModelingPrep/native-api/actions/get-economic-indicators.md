# Get Economic Indicators with Financial Modeling Prep

Retrieves economic indicators from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/economic-indicators`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Economic Indicators](https://site.financialmodelingprep.com/developer/docs/stable/economic-indicators)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Economic indicator name, such as GDP. |
