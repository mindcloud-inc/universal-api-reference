# Get Financial Ratios TTM with Financial Modeling Prep

Retrieves trailing twelve-month financial ratios from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/ratios-ttm`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Financial Ratios TTM](https://site.financialmodelingprep.com/developer/docs/stable/ratios-ttm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
