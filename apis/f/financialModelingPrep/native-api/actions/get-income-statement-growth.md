# Get Income Statement Growth with Financial Modeling Prep

Retrieves income statement growth data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/income-statement-growth`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Income Statement Growth](https://site.financialmodelingprep.com/developer/docs/stable/income-statement-growth)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
