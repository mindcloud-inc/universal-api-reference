# Search Companies By Name with Financial Modeling Prep

Finds companies in Financial Modeling Prep by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/search-name`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Search Companies By Name](https://site.financialmodelingprep.com/developer/docs/stable/search-name)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | query | `string` | yes | Company or asset name to search for, such as Apple. |
