# Get Historical Market Capitalization with Financial Modeling Prep

Retrieves historical market capitalization from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/historical-market-capitalization`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Historical Market Capitalization](https://site.financialmodelingprep.com/developer/docs/stable/historical-market-capitalization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
