# Get Balance Sheet Statement with Financial Modeling Prep

Retrieves balance sheet statements from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/balance-sheet-statement`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Balance Sheet Statement](https://site.financialmodelingprep.com/developer/docs/stable/balance-sheet-statement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
