# Get Market Capitalization with Financial Modeling Prep

Retrieves market capitalization data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/market-capitalization`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Market Capitalization](https://site.financialmodelingprep.com/developer/docs/stable/market-capitalization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
