# Get Stock Splits with Financial Modeling Prep

Retrieves stock splits from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/splits`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Stock Splits](https://site.financialmodelingprep.com/developer/docs/stable/splits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
