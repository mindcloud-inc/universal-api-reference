# Get Balance Sheet Growth with Financial Modeling Prep

Retrieves balance sheet growth data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/balance-sheet-statement-growth`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Balance Sheet Growth](https://site.financialmodelingprep.com/developer/docs/stable/balance-sheet-statement-growth)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
