# Get Key Metrics TTM with Financial Modeling Prep

Retrieves trailing twelve-month key metrics from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/key-metrics-ttm`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Key Metrics TTM](https://site.financialmodelingprep.com/developer/docs/stable/key-metrics-ttm)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
