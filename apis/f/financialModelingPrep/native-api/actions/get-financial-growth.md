# Get Financial Growth with Financial Modeling Prep

Retrieves financial growth data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/financial-growth`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Financial Growth](https://site.financialmodelingprep.com/developer/docs/stable/financial-growth)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
