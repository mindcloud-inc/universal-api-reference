# Get Key Metrics with Financial Modeling Prep

Retrieves key metrics from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/key-metrics`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Key Metrics](https://site.financialmodelingprep.com/developer/docs/stable/key-metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
