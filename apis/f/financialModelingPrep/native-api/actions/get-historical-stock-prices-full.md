# Get Historical Stock Prices Full with Financial Modeling Prep

Retrieves full historical stock prices from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/historical-price-eod/full`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Historical Stock Prices Full](https://site.financialmodelingprep.com/developer/docs/stable/historical-price-eod-full)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
