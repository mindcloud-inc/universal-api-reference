# Get Shares Float with Financial Modeling Prep

Retrieves shares float data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/shares-float`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Shares Float](https://site.financialmodelingprep.com/developer/docs/stable/shares-float)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
