# Get Ratings Snapshot with Financial Modeling Prep

Retrieves a ratings snapshot from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/ratings-snapshot`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Ratings Snapshot](https://site.financialmodelingprep.com/developer/docs/stable/ratings-snapshot)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
