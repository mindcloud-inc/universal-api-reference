# Get Earnings Calendar with Financial Modeling Prep

Retrieves an earnings calendar from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/earnings-calendar`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Earnings Calendar](https://site.financialmodelingprep.com/developer/docs/stable/earnings-calendar)
