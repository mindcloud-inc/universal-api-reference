# Get Company Profile with Financial Modeling Prep

Retrieves a company profile from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/profile`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Company Profile](https://site.financialmodelingprep.com/developer/docs/stable/profile)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
