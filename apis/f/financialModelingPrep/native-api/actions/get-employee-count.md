# Get Employee Count with Financial Modeling Prep

Retrieves employee count data from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/employee-count`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Employee Count](https://site.financialmodelingprep.com/developer/docs/stable/employee-count)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
