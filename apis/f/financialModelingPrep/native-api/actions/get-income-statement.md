# Get Income Statement with Financial Modeling Prep

Retrieves income statements from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/income-statement`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Income Statement](https://site.financialmodelingprep.com/developer/docs/stable/income-statement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
