# Get As Reported Cash Flow Statement with Financial Modeling Prep

Retrieves as-reported cash flow statements from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/cash-flow-statement-as-reported`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get As Reported Cash Flow Statement](https://site.financialmodelingprep.com/developer/docs/stable/cash-flow-statement-as-reported)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
