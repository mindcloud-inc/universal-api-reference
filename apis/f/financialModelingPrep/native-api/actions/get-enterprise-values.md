# Get Enterprise Values with Financial Modeling Prep

Retrieves enterprise values from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/enterprise-values`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get Enterprise Values](https://site.financialmodelingprep.com/developer/docs/stable/enterprise-values)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
