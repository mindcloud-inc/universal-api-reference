# Get As Reported Balance Sheet with Financial Modeling Prep

Retrieves as-reported balance sheet statements from Financial Modeling Prep.

## Endpoint

- **Method:** `GET`
- **Path:** `/balance-sheet-statement-as-reported`
- **Base URL:** `https://financialmodelingprep.com/stable`
- **Official documentation:** [Get As Reported Balance Sheet](https://site.financialmodelingprep.com/developer/docs/stable/balance-sheet-statement-as-reported)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `symbol` | query | `string` | yes | Stock ticker symbol, such as AAPL. |
