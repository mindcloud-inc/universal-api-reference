# Get Incident with FireHydrant

Retrieves an incident from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/incidents/:incident_id`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [Get Incident](https://docs.firehydrant.com/reference/get_incident)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `incident_id` | path | `string` | yes | The FireHydrant incident ID. |
