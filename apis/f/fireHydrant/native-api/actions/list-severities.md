# List Severities with FireHydrant

Retrieves incident severities from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/severities`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [List Severities](https://docs.firehydrant.com/reference/list_severities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
