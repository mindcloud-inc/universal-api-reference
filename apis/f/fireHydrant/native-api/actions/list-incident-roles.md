# List Incident Roles with FireHydrant

Retrieves incident roles from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/incident_roles`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [List Incident Roles](https://docs.firehydrant.com/reference/list_incident_roles)

## Capabilities

This operation supports [pagination](../README.md#pagination).
