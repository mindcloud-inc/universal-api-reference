# Get Service with FireHydrant

Retrieves a service from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/services/:service_id`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [Get Service](https://docs.firehydrant.com/reference/get_service)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `service_id` | path | `string` | yes | The FireHydrant service ID. |
