# Get Environment with FireHydrant

Retrieves an environment from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/environments/:environment_id`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [Get Environment](https://docs.firehydrant.com/reference/get_environment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `environment_id` | path | `string` | yes | The FireHydrant environment ID. |
