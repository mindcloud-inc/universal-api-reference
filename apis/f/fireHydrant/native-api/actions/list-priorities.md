# List Priorities with FireHydrant

Retrieves incident priorities from FireHydrant.

## Endpoint

- **Method:** `GET`
- **Path:** `/priorities`
- **Base URL:** `https://api.firehydrant.io/v1`
- **Official documentation:** [List Priorities](https://docs.firehydrant.com/reference/list_priorities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
