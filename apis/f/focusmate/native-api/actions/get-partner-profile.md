# Get Partner Profile with Focusmate

Retrieves a user's public Focusmate profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.focusmate.com/v1`
- **Official documentation:** [Get Partner Profile](https://apidocs.focusmate.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | Focusmate user ID to retrieve public profile data for. |
