# Get File Metadata with Filestack

Retrieves file metadata from Filestack.

## Endpoint

- **Method:** `GET`
- **Path:** `/file/:handle/metadata`
- **Base URL:** `https://www.filestackapi.com/api`
- **Official documentation:** [Get File Metadata](https://www.filestack.com/docs/api/file/#metadata)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | The Filestack file handle, for example itnd50g6QzehEsWjDGij. |
