# Delete File with Filestack

Deletes an existing file from Filestack.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/file/:handle`
- **Base URL:** `https://www.filestackapi.com/api`
- **Official documentation:** [Delete File](https://www.filestack.com/docs/api/file/#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | The Filestack file handle to delete. |
| `policy` | query | `string` | yes | Security policy generated by your backend for the delete request. |
| `signature` | query | `string` | yes | Signature generated by your backend for the delete request. |
