# Get Workflow Status with Filestack

Retrieves workflow status from Filestack.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cdn.filestackcontent.com/{apiKey}/security=p\:{{policy}},s\:{{signature}}/workflow_status=job_id\:{{jobId}}`
- **Base URL:** `https://www.filestackapi.com/api`
- **Official documentation:** [Get Workflow Status](https://www.filestack.com/docs/api/workflows_api/#workflow-status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The workflow job ID returned when you start a Filestack workflow run. |
| `policy` | path | `string` | yes | The Filestack security policy generated by your backend for this workflow status call. |
| `signature` | path | `string` | yes | The signature for the supplied Filestack security policy. |
