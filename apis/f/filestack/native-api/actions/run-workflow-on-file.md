# Run Workflow On File with Filestack

Runs a workflow on a file in Filestack.

## Endpoint

- **Method:** `GET`
- **Path:** `https://cdn.filestackcontent.com/security=p\:{{policy}},s\:{{signature}}/run_workflow=id\:{{workflowId}}/{{handle}}`
- **Base URL:** `https://www.filestackapi.com/api`
- **Official documentation:** [Run Workflow On File](https://www.filestack.com/docs/api/workflows_api/#run-workflow)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workflowId` | path | `string` | yes | The Filestack workflow ID from the developer portal. |
| `handle` | path | `string` | yes | The Filestack file handle to send into the workflow. |
| `policy` | path | `string` | yes | The Filestack security policy generated by your backend for this workflow call. |
| `signature` | path | `string` | yes | The signature for the supplied Filestack security policy. |
