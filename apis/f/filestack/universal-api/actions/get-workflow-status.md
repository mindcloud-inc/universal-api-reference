# Filestack: Get Workflow Status

Retrieves workflow status from Filestack.

```
GET https://connect.mindcloud.co/v1/universal/filestack/latest/actions/get-workflow-status
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Filestack `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/filestack/latest/actions/get-workflow-status?connectionId=$CONNECTION_ID&jobId=5aef4e90-4c6c-4779-ac8b-289cff108792&policy=eyJleHBpcnkiOjE3MDAwMDAwMDB9&signature=428c3b32063f2081ec1ee3a703d05ce19883849adb4c90224367fe9707b3d808" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId,
  "jobId": "5aef4e90-4c6c-4779-ac8b-289cff108792",
  "policy": "eyJleHBpcnkiOjE3MDAwMDAwMDB9",
  "signature": "428c3b32063f2081ec1ee3a703d05ce19883849adb4c90224367fe9707b3d808"
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/filestack/latest/actions/get-workflow-status?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as query string parameters ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `jobId` | string | yes | The workflow job ID returned when you start a Filestack workflow run. Example: `5aef4e90-4c6c-4779-ac8b-289cff108792`. |

### Advanced

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `policy` | string | yes | The Filestack security policy generated by your backend for this workflow status call. Example: `eyJleHBpcnkiOjE3MDAwMDAwMDB9`. |
| `signature` | string | yes | The signature for the supplied Filestack security policy. Example: `428c3b32063f2081ec1ee3a703d05ce19883849adb4c90224367fe9707b3d808`. |

## Response

```json
{
  "success": true,
  "data": [
    {
      "createdAt": "2026-05-07T12:00:00.000Z",
      "jobid": "string",
      "results": {},
      "sources": [
        "string"
      ],
      "status": "string",
      "ttl": 1,
      "updatedAt": "2026-05-07T12:00:00.000Z",
      "workflow": "string"
    }
  ],
  "meta": {}
}
```

### Response fields

| Key | Type | Description |
| --- | --- | --- |
| `createdAt` | date | The time when the workflow job was created. |
| `jobid` | string | The ID of the workflow job processing your file. |
| `results` | object | The JSON-formatted result payload returned by the workflow. |
| `sources` | array<string> | The file handles or URLs submitted to the workflow. |
| `status` | string | The current workflow job status. |
| `ttl` | number | The number of seconds the workflow result remains available in the Filestack network. |
| `updatedAt` | date | The last time the workflow job status changed. |
| `workflow` | string | The workflow ID from the Filestack developer portal. |

## Native endpoint

Through the native Filestack API, this operation is `GET https://cdn.filestackcontent.com/{{credentials.apiKey}}/security=p\:{{policy}},s\:{{signature}}/workflow_status=job_id\:{{jobId}}` (base URL `https://www.filestackapi.com/api`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-workflow-status.md) for the provider-specific parameters and requirements.
