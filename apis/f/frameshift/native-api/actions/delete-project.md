# Delete Project with Frameshift

Deletes an existing project from Frameshift.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/projects/:project_id`
- **Base URL:** `https://mosaic.frameshift.io/api`
- **Official documentation:** [Delete Project](https://mosaic.frameshift.io/api/#api-Collections-DeleteProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | Resource identifier for the project to access |
