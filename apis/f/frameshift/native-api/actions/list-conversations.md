# List Conversations with Frameshift

Retrieves a list of conversations from Frameshift.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/conversations`
- **Base URL:** `https://mosaic.frameshift.io/api`
- **Official documentation:** [List Conversations](https://mosaic.frameshift.io/api/#api-Project_Conversations-GetConversations)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
