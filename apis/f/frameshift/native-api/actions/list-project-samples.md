# List Project Samples with Frameshift

Retrieves a list of project samples from Frameshift.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/samples`
- **Base URL:** `https://mosaic.frameshift.io/api`
- **Official documentation:** [List Project Samples](https://mosaic.frameshift.io/api/#api-Samples-GetProjectSamples)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
