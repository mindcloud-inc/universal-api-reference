# Get Project with Frameshift

Retrieves detailed project information from Frameshift.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id`
- **Base URL:** `https://mosaic.frameshift.io/api`
- **Official documentation:** [Get Project](https://mosaic.frameshift.io/api/#api-Projects-GetProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | path | `number` | yes | Resource identifier for the project to access |
