# List Project Tasks with Frameshift

Retrieves a list of project tasks from Frameshift.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/projects/:project_id/tasks`
- **Base URL:** `https://mosaic.frameshift.io/api`
- **Official documentation:** [List Project Tasks](https://mosaic.frameshift.io/api/#api-Tasks-getProjectTasks)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `project_id` | path | `number` | yes |
