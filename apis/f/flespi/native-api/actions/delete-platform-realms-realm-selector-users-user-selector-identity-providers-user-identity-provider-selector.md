# Unlink identity provider accounts from user with Flespi

## Endpoint

- **Method:** `DELETE`
- **Path:** `/platform/realms/{realm-selector}/users/{user-selector}/identity-providers/{user-identity-provider-selector}`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Unlink identity provider accounts from user](https://flespi.io/docs/)
