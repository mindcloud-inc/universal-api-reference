# Modify the binding of Identity Provider to realms with Flespi

## Endpoint

- **Method:** `PUT`
- **Path:** `/platform/realms/{realm-selector}/identity-providers/{realm-identity-provider-selector}`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Modify the binding of Identity Provider to realms](https://flespi.io/docs/)
