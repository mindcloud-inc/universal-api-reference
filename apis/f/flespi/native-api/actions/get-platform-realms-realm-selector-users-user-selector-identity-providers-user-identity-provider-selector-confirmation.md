# Get confirmation link for third-party Identity Provider account binding with Flespi

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/realms/{realm-selector}/users/{user-selector}/identity-providers/{user-identity-provider-selector}/confirmation`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Get confirmation link for third-party Identity Provider account binding](https://flespi.io/docs/)
