# Attach custom parameters to calculated device interval with Flespi

## Endpoint

- **Method:** `PUT`
- **Path:** `/gw/calcs/{calcs.selector}/devices/{calc.devices.selector}/intervals/{calc.device.intervals.selector.put}`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Attach custom parameters to calculated device interval](https://flespi.io/docs/)
