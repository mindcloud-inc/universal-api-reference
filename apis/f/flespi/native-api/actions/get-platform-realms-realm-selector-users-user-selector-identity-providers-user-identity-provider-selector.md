# Get linked identity provider accounts to user with Flespi

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/realms/{realm-selector}/users/{user-selector}/identity-providers/{user-identity-provider-selector}`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Get linked identity provider accounts to user](https://flespi.io/docs/)
