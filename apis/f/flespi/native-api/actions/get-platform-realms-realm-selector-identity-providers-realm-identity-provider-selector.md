# Retrieve Identity Providers binded to realms with Flespi

## Endpoint

- **Method:** `GET`
- **Path:** `/platform/realms/{realm-selector}/identity-providers/{realm-identity-provider-selector}`
- **Base URL:** `https://flespi.io`
- **Official documentation:** [Retrieve Identity Providers binded to realms](https://flespi.io/docs/)
