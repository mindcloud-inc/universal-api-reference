# Create Site Category with Fluxguard

Creates a new site category in Fluxguard.

## Endpoint

- **Method:** `POST`
- **Path:** `/account/category`
- **Base URL:** `https://api.fluxguard.com`
- **Official documentation:** [Create Site Category](https://fluxguard.com/how-to-guides/use-our-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name for the new site category. |
