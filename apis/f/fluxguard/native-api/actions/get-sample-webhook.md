# Get Sample Webhook with Fluxguard

Retrieves a sample webhook payload from Fluxguard.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/webhook/sample`
- **Base URL:** `https://api.fluxguard.com`
- **Official documentation:** [Get Sample Webhook](https://fluxguard.com/how-to-guides/use-our-api/)
