# Delete Site with Fluxguard

Deletes a site and its monitoring data from Fluxguard.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/site/:siteId`
- **Base URL:** `https://api.fluxguard.com`
- **Official documentation:** [Delete Site](https://fluxguard.com/how-to-guides/use-our-api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `siteId` | path | `string` | yes |
