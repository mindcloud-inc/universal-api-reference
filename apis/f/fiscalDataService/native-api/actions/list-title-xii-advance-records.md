# List Title XII Advance Records with Fiscal Data Service

Retrieves Title XII advance records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/title_xii`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Title XII Advance Records](https://fiscaldata.treasury.gov/datasets/ssa-title-xii-advance-activities/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
