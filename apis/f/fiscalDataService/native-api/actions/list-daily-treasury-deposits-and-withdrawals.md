# List Daily Treasury Deposits and Withdrawals with Fiscal Data Service

Retrieves daily Treasury deposits and withdrawals from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/dts/deposits_withdrawals_operating_cash`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Daily Treasury Deposits and Withdrawals](https://fiscaldata.treasury.gov/datasets/daily-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
