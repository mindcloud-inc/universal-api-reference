# List SLGS Security Records with Fiscal Data Service

Retrieves SLGS security records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/od/slgs_securities`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List SLGS Security Records](https://fiscaldata.treasury.gov/datasets/slgs-securities/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
