# List Public Debt Interest Expense Records with Fiscal Data Service

Retrieves public debt interest expense records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/interest_expense`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Public Debt Interest Expense Records](https://fiscaldata.treasury.gov/datasets/interest-expense-debt-outstanding/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
