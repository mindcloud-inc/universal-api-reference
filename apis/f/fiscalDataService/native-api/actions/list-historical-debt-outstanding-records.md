# List Historical Debt Outstanding Records with Fiscal Data Service

Retrieves historical debt outstanding records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/debt_outstanding`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Historical Debt Outstanding Records](https://fiscaldata.treasury.gov/datasets/historical-debt-outstanding/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
