# List Daily Federal Tax Deposit Records with Fiscal Data Service

Retrieves daily federal tax deposit records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/dts/federal_tax_deposits`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Daily Federal Tax Deposit Records](https://fiscaldata.treasury.gov/datasets/daily-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
