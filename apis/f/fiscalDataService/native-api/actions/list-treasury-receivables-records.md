# List Treasury Receivables Records with Fiscal Data Service

Retrieves Treasury receivables records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/debt/tror`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Treasury Receivables Records](https://fiscaldata.treasury.gov/datasets/treasury-report-on-receivables/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
