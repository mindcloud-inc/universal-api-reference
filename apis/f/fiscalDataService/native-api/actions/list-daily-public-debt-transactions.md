# List Daily Public Debt Transactions with Fiscal Data Service

Retrieves daily public debt transactions from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/dts/public_debt_transactions`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Daily Public Debt Transactions](https://fiscaldata.treasury.gov/datasets/daily-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
