# List Debt to the Penny Records with Fiscal Data Service

Retrieves Debt to the Penny records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/debt_to_penny`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Debt to the Penny Records](https://fiscaldata.treasury.gov/datasets/debt-to-the-penny/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
