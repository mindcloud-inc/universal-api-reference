# List Monthly Statutory Debt Limit Records with Fiscal Data Service

Retrieves monthly statutory debt limit records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/debt/mspd/mspd_table_2`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Monthly Statutory Debt Limit Records](https://fiscaldata.treasury.gov/datasets/monthly-statement-public-debt/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
