# List Average Interest Rate Records with Fiscal Data Service

Retrieves average interest rate records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/avg_interest_rates`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Average Interest Rate Records](https://fiscaldata.treasury.gov/datasets/average-interest-rates-treasury-securities/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
