# List Daily Treasury Operating Cash Balances with Fiscal Data Service

Retrieves daily Treasury operating cash balances from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/dts/operating_cash_balance`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Daily Treasury Operating Cash Balances](https://fiscaldata.treasury.gov/datasets/daily-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
