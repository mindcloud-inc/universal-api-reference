# List Monthly Treasury Statement Summary Records with Fiscal Data Service

Retrieves monthly Treasury statement summary records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/mts/mts_table_1`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Monthly Treasury Statement Summary Records](https://fiscaldata.treasury.gov/datasets/monthly-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
