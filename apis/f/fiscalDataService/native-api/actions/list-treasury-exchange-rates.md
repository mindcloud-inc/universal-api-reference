# List Treasury Exchange Rates with Fiscal Data Service

Retrieves Treasury exchange rates from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/od/rates_of_exchange`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Treasury Exchange Rates](https://fiscaldata.treasury.gov/datasets/treasury-reporting-rates-exchange/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
