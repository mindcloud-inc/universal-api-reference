# List Monthly Treasury Security Detail Records with Fiscal Data Service

Retrieves monthly Treasury security detail records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/debt/mspd/mspd_table_3`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Monthly Treasury Security Detail Records](https://fiscaldata.treasury.gov/datasets/monthly-statement-public-debt/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
