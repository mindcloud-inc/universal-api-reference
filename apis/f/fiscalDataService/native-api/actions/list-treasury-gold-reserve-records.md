# List Treasury Gold Reserve Records with Fiscal Data Service

Retrieves Treasury gold reserve records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/gold_reserve`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Treasury Gold Reserve Records](https://fiscaldata.treasury.gov/datasets/status-report-government-gold-reserve/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
