# List Daily Debt Subject to Limit Records with Fiscal Data Service

Retrieves daily debt subject to limit records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/dts/debt_subject_to_limit`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Daily Debt Subject to Limit Records](https://fiscaldata.treasury.gov/datasets/daily-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
