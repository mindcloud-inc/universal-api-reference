# List Monthly Treasury Receipts with Fiscal Data Service

Retrieves monthly Treasury receipts from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/mts/mts_table_4`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Monthly Treasury Receipts](https://fiscaldata.treasury.gov/datasets/monthly-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
