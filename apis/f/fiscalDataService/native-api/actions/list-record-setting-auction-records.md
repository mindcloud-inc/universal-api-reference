# List Record Setting Auction Records with Fiscal Data Service

Retrieves record-setting auction records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/accounting/od/record_setting_auction`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Record Setting Auction Records](https://fiscaldata.treasury.gov/datasets/record-setting-auction-data/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
