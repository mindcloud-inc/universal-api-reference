# List Monthly Receipts Outlays Deficit Surplus with Fiscal Data Service

Retrieves monthly receipts and outlays records from Fiscal Data Service.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounting/mts/mts_receipts_outlays_deficit_surplus`
- **Base URL:** `https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- **Official documentation:** [List Monthly Receipts Outlays Deficit Surplus](https://fiscaldata.treasury.gov/datasets/monthly-treasury-statement/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
