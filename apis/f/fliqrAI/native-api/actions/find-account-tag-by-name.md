# Find Account Tag By Name with Fliqr AI

Finds an account tag in Fliqr AI by name.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/tags/name/:tag_name`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [Find Account Tag By Name](https://docs.fliqr.ai/api-reference/accounts/get-accountstagsname)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_name` | path | `string` | yes | Tag name. |
