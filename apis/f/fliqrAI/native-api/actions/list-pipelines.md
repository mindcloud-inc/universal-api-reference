# List Pipelines with Fliqr AI

Retrieves pipelines from Fliqr AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [List Pipelines](https://docs.fliqr.ai/api-reference/pipelines/get-pipelines)

## Capabilities

This operation supports [pagination](../README.md#pagination).
