# List Contact Tags with Fliqr AI

Retrieves contact tags from Fliqr AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id/tags`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [List Contact Tags](https://docs.fliqr.ai/api-reference/users/get-users-tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Fliqr contact user ID. |
