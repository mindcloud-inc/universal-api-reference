# Get Contact with Fliqr AI

Retrieves a contact from Fliqr AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [Get Contact](https://docs.fliqr.ai/api-reference/users/get-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Fliqr contact user ID. |
