# Get Bot Field Value with Fliqr AI

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/bot_fields/:bot_field_id`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [Get Bot Field Value](https://docs.fliqr.ai/api-reference/accounts/get-accountsbot-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `bot_field_id` | path | `number` | yes | Bot field ID. |
