# List Contact Custom Fields with Fliqr AI

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id/custom_fields`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [List Contact Custom Fields](https://docs.fliqr.ai/api-reference/users/get-users-custom-fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `number` | yes | Fliqr contact user ID. |
