# Get Account Tag with Fliqr AI

Retrieves an account tag from Fliqr AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/tags/:tag_id`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [Get Account Tag](https://docs.fliqr.ai/api-reference/accounts/get-accountstags-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tag_id` | path | `number` | yes | Tag ID. |
