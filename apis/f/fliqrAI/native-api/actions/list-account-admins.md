# List Account Admins with Fliqr AI

Retrieves account admins from Fliqr AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/admins`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [List Account Admins](https://docs.fliqr.ai/api-reference/accounts/get-accountsadmins)
