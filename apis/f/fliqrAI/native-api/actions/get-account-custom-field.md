# Get Account Custom Field with Fliqr AI

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/custom_fields/:custom_field_id`
- **Base URL:** `https://app.fliqr.ai/api/`
- **Official documentation:** [Get Account Custom Field](https://docs.fliqr.ai/api-reference/accounts/get-accountscustom-fields-1)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `custom_field_id` | path | `number` | yes | Custom field ID. |
