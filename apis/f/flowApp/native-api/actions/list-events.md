# List Events with Flow App

## Endpoint

- **Method:** `GET`
- **Path:** `/events/sessions`
- **Base URL:** `https://prod.flowapp.com/api/v1`
- **Official documentation:** [List Events](https://support.flowapp.com/support/solutions/articles/12000076814-flow-api-0-0-4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `period` | query | `string` | no | Return events from one time bucket: current, past, or future. |
