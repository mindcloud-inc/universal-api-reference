# Get Event with Flow App

## Endpoint

- **Method:** `GET`
- **Path:** `/events/sessions/:sessionToken`
- **Base URL:** `https://prod.flowapp.com/api/v1`
- **Official documentation:** [Get Event](https://support.flowapp.com/support/solutions/articles/12000076814-flow-api-0-0-4)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sessionToken` | path | `string` | yes | The unique identifier for the event session you want to look up. |
