# Validate Sheet with Flatfile

Runs validation on a sheet in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/sheets/:sheetId/validate`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Validate Sheet](https://reference.flatfile.com/api-reference/sheets/validate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
