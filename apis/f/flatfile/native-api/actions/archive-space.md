# Archive Space with Flatfile

Archives an existing space in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/spaces/:spaceId/archive`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Archive Space](https://reference.flatfile.com/api-reference/spaces/archive-space)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Flatfile space ID. |
