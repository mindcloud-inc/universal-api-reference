# Get File with Flatfile

Retrieves a specific file from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get File](https://reference.flatfile.com/api-reference/files/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Flatfile file identifier. |
