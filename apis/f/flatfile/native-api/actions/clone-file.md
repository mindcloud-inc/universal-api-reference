# Clone File with Flatfile

Creates a copy of a file in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/files/:fileId/clone`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Clone File](https://reference.flatfile.com/api-reference/files/clone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Flatfile file identifier. |
