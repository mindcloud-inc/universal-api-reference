# Get Records with Flatfile

Retrieves records from a sheet in Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sheets/:sheetId/records`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Records](https://reference.flatfile.com/api-reference/records/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
