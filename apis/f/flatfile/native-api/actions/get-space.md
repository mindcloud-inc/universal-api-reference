# Get Space with Flatfile

Retrieves a specific space from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Space](https://reference.flatfile.com/api-reference/spaces/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Flatfile space ID. |
