# Unarchive Space with Flatfile

Unarchives an existing space in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/spaces/:spaceId/unarchive`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Unarchive Space](https://reference.flatfile.com/api-reference/spaces/unarchive-space)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Flatfile space ID. |
