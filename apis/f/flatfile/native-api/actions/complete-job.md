# Complete Job with Flatfile

Completes a specific job in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/jobs/:jobId/complete`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Complete Job](https://reference.flatfile.com/api-reference/jobs/complete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Flatfile job identifier. |
