# Get Record Counts with Flatfile

Retrieves record counts for a Flatfile sheet.

## Endpoint

- **Method:** `GET`
- **Path:** `/sheets/:sheetId/counts`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Record Counts](https://reference.flatfile.com/api-reference/sheets/get-record-counts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
