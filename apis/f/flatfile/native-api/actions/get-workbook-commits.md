# Get Workbook Commits with Flatfile

Retrieves commits for a workbook in Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/workbooks/:workbookId/commits`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Workbook Commits](https://reference.flatfile.com/api-reference/workbooks/get-workbook-commits)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workbookId` | path | `string` | yes | Flatfile workbook ID. |
