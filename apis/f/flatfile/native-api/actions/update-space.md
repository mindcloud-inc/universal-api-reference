# Update Space with Flatfile

Updates an existing space in Flatfile.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Update Space](https://reference.flatfile.com/api-reference/spaces/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Flatfile space ID. |
