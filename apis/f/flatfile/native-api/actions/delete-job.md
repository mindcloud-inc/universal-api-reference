# Delete Job with Flatfile

Deletes an existing job from Flatfile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Delete Job](https://reference.flatfile.com/api-reference/jobs/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Flatfile job identifier. |
