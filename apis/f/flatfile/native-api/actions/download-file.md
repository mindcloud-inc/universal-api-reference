# Download File with Flatfile

Downloads a specific file from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:fileId/download`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Download File](https://reference.flatfile.com/api-reference/files/download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Flatfile file identifier. |
