# Get Job Execution Plan with Flatfile

Retrieves a job execution plan from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId/plan`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Job Execution Plan](https://reference.flatfile.com/api-reference/jobs/get-execution-plan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Flatfile job identifier. |
