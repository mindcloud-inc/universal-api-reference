# Get Job with Flatfile

Retrieves a specific job from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Job](https://reference.flatfile.com/api-reference/jobs/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Flatfile job identifier. |
