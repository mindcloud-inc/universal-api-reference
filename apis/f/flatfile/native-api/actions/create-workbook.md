# Create Workbook with Flatfile

Creates a new workbook in Flatfile.

## Endpoint

- **Method:** `POST`
- **Path:** `/workbooks`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Create Workbook](https://reference.flatfile.com/api-reference/workbooks/create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Workbook name. |
