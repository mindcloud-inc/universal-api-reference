# Update File with Flatfile

Updates an existing file in Flatfile.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/files/:fileId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Update File](https://reference.flatfile.com/api-reference/files/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Flatfile file identifier. |
