# Update Job with Flatfile

Updates an existing job in Flatfile.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/jobs/:jobId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Update Job](https://reference.flatfile.com/api-reference/jobs/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | Flatfile job identifier. |
