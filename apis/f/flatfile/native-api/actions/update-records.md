# Update Records with Flatfile

Updates existing records in a Flatfile sheet.

## Endpoint

- **Method:** `PUT`
- **Path:** `/sheets/:sheetId/records`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Update Records](https://reference.flatfile.com/api-reference/records/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
