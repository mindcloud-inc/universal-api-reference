# Delete Space with Flatfile

Deletes an existing space from Flatfile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Delete Space](https://reference.flatfile.com/api-reference/spaces/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | Flatfile space ID. |
