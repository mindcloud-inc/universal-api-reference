# Delete File with Flatfile

Deletes an existing file from Flatfile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/files/:fileId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Delete File](https://reference.flatfile.com/api-reference/files/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | Flatfile file identifier. |
