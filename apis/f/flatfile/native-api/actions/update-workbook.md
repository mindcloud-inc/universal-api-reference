# Update Workbook with Flatfile

Updates an existing workbook in Flatfile.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/workbooks/:workbookId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Update Workbook](https://reference.flatfile.com/api-reference/workbooks/update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workbookId` | path | `string` | yes | Flatfile workbook ID. |
