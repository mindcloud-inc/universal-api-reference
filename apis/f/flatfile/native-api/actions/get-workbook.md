# Get Workbook with Flatfile

Retrieves a specific workbook from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/workbooks/:workbookId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Workbook](https://reference.flatfile.com/api-reference/workbooks/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workbookId` | path | `string` | yes | Flatfile workbook ID. |
