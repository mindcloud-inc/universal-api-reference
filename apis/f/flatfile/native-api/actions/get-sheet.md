# Get Sheet with Flatfile

Retrieves a specific sheet from Flatfile.

## Endpoint

- **Method:** `GET`
- **Path:** `/sheets/:sheetId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Get Sheet](https://reference.flatfile.com/api-reference/sheets/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
