# Insert Records with Flatfile

Creates new records in a Flatfile sheet.

## Endpoint

- **Method:** `POST`
- **Path:** `/sheets/:sheetId/records`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Insert Records](https://reference.flatfile.com/api-reference/records/insert)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sheetId` | path | `string` | yes | Flatfile sheet ID. |
