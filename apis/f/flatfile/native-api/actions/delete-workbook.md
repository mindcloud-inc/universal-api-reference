# Delete Workbook with Flatfile

Deletes an existing workbook from Flatfile.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workbooks/:workbookId`
- **Base URL:** `https://api.x.flatfile.com/v1`
- **Official documentation:** [Delete Workbook](https://reference.flatfile.com/api-reference/workbooks/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workbookId` | path | `string` | yes | Flatfile workbook ID. |
