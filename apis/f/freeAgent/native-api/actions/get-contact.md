# Get Contact with FreeAgent

Retrieves detailed contact information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Contact](https://dev.freeagent.com/docs/contacts#get-a-single-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent contact ID. |
