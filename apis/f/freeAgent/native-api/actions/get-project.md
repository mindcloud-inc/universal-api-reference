# Get Project with FreeAgent

Retrieves detailed project information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Project](https://dev.freeagent.com/docs/projects#get-a-single-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent project ID. |
