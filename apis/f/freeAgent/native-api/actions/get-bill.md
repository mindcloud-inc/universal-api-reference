# Get Bill with FreeAgent

Retrieves detailed bill information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/bills/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Bill](https://dev.freeagent.com/docs/bills#get-a-single-bill)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent bill ID. |
