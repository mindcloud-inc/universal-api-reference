# Get Expense with FreeAgent

Retrieves detailed expense information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/expenses/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Expense](https://dev.freeagent.com/docs/expenses#get-a-single-expense)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent expense ID. |
