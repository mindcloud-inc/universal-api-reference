# Get Invoice with FreeAgent

Retrieves detailed invoice information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Invoice](https://dev.freeagent.com/docs/invoices#get-a-single-invoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent invoice ID. |
