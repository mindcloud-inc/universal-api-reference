# Get Estimate with FreeAgent

Retrieves detailed estimate information from FreeAgent.

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates/:id`
- **Base URL:** `https://api.freeagent.com/v2`
- **Official documentation:** [Get Estimate](https://dev.freeagent.com/docs/estimates#get-a-single-estimate)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | FreeAgent estimate ID. |
