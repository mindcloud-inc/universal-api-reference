# Delete Opportunity with ForceManager

Deletes an existing opportunity from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/opportunities`
- **Official documentation:** [Delete Opportunity](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the opportunity. |
