# Delete View with ForceManager

Deletes an existing view from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/views`
- **Official documentation:** [Delete View](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the view. |
