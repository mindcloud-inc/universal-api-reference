# Delete Calendar with ForceManager

Deletes an existing calendar from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calendars`
- **Official documentation:** [Delete Calendar](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the calendar. |
