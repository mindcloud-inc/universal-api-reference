# Delete Company with ForceManager

Deletes an existing company from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies`
- **Official documentation:** [Delete Company](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the account. |
