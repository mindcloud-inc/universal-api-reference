# Update Product with ForceManager

Updates an existing product in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/products`
- **Official documentation:** [Update Product](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the product. |
