# Create Calendar with ForceManager

Creates a new calendar in ForceManager.

## Endpoint

- **Method:** `POST`
- **Path:** `/calendars`
- **Official documentation:** [Create Calendar](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `activity_type_id` | body | `number` | yes | ID of the activity type related to the calendar. |
