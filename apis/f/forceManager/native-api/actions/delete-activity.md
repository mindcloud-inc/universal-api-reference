# Delete Activity with ForceManager

Deletes an existing activity from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/activities`
- **Official documentation:** [Delete Activity](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the activity. |
