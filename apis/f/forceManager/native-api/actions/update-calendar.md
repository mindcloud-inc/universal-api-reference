# Update Calendar with ForceManager

Updates an existing calendar in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/calendars`
- **Official documentation:** [Update Calendar](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the calendar. |
