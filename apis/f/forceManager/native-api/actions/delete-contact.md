# Delete Contact with ForceManager

Deletes an existing contact from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts`
- **Official documentation:** [Delete Contact](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the contact. |
