# Update Company with ForceManager

Updates an existing company in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/companies`
- **Official documentation:** [Update Company](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the account. |
