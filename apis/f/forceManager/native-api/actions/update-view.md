# Update View with ForceManager

Updates an existing view in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/views`
- **Official documentation:** [Update View](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the view. |
