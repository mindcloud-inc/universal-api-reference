# Update Activity with ForceManager

Updates an existing activity in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/activities`
- **Official documentation:** [Update Activity](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the activity. |
