# Update Contact with ForceManager

Updates an existing contact in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/contacts`
- **Official documentation:** [Update Contact](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the contact. |
