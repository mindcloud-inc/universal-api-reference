# Create Company with ForceManager

Creates a new company in ForceManager.

## Endpoint

- **Method:** `POST`
- **Path:** `/companies`
- **Official documentation:** [Create Company](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the account. |
