# Delete Product with ForceManager

Deletes an existing product from ForceManager.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/products`
- **Official documentation:** [Delete Product](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the product. |
