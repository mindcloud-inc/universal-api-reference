# Update Opportunity with ForceManager

Updates an existing opportunity in ForceManager.

## Endpoint

- **Method:** `PUT`
- **Path:** `/opportunities`
- **Official documentation:** [Update Opportunity](https://support.forcemanager.net/en/articles/8613478-entity-types)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Unique identifier for the opportunity. |
