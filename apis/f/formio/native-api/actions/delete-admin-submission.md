# Delete Admin Submission with Form.io

Deletes an existing admin submission from your Form.io project.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/admin/submission/:submissionId`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [Delete Admin Submission](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | The submission ID. |
