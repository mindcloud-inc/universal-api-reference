# Get Tag with Form.io

Retrieves a tag from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/tag/:tagId`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [Get Tag](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tagId` | path | `string` | yes | The tag ID. |
