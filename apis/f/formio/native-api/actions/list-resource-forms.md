# List Resource Forms with Form.io

Retrieves resource forms from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/form`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [List Resource Forms](https://help.form.io/developers/introduction/api-documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of resource forms to return. |
| `skip` | query | `string` | no | Number of resource forms to skip before returning results. |
