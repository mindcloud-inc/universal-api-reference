# Get User Submission with Form.io

Retrieves a user submission from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/submission/:submissionId`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [Get User Submission](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | The submission ID. |
