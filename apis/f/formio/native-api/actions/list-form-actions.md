# List Form Actions with Form.io

Retrieves actions for a form in Form.io.

## Endpoint

- **Method:** `GET`
- **Path:** `/form/:formId/action`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [List Form Actions](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The form ID to list actions for. |
