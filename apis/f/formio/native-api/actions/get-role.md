# Get Role with Form.io

Retrieves a role from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/role/:id`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [Get Role](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Form.io role ID. |
