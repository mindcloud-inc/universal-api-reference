# Get Admin Submission with Form.io

Retrieves an admin submission from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/submission/:submissionId`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [Get Admin Submission](https://help.form.io/developers/introduction/api-documentation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `submissionId` | path | `string` | yes | The submission ID. |
