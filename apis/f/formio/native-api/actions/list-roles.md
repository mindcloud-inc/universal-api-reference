# List Roles with Form.io

Retrieves roles from your Form.io project.

## Endpoint

- **Method:** `GET`
- **Path:** `/role`
- **Base URL:** `https://neabnzbnvbushtk.form.io`
- **Official documentation:** [List Roles](https://help.form.io/developers/introduction/api-documentation)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | `string` | no | Maximum number of roles to return. |
| `skip` | query | `string` | no | Number of roles to skip before returning results. |
