# Delete Delayed Job with FTrack

Deletes a delayed job from FTrack.

## Endpoint

- **Method:** `POST`
- **Path:** `/api`
- **Base URL:** `{serverUrl}`
- **Official documentation:** [Delete Delayed Job](https://developer.ftrack.com/api/operations/delayed-job-api-delayed-job-deletedelayedjob-post/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `data` | body | `object` | yes | Delayed job data payload. |
