# Get Tenant Access Token with Feishu Base

Retrieves a Feishu tenant access token.

## Endpoint

- **Method:** `POST`
- **Path:** `https://open.feishu.cn/open-apis/auth/v3/tenant_access_token/internal`
- **Base URL:** `https://open.feishu.cn/open-apis/bitable/v1`
- **Official documentation:** [Get Tenant Access Token](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/json; charset=utf-8` |
