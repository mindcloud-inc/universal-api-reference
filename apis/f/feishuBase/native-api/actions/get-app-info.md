# Get App Info with Feishu Base

Retrieves metadata for a Feishu Base app.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/:app_token`
- **Base URL:** `https://open.feishu.cn/open-apis/bitable/v1`
- **Official documentation:** [Get App Info](https://open.feishu.cn/document/server-docs/docs/bitable-v1/app/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `app_token` | path | `string` | yes | Unique identifier of the Feishu Base app. |
