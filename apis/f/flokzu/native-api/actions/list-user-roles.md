# List User Roles with Flokzu

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/management/user/roles`
- **Base URL:** `https://app.flokzu.com/flokzuopenapi/api`
- **Official documentation:** [List User Roles](https://flokzu.docs.apiary.io/reference/users-management/roles/get-user-roles)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address of the user whose roles should be returned. |
