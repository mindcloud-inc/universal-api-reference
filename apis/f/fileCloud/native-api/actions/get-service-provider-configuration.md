# Get Service Provider Configuration with FileCloud

Retrieves service provider configuration from FileCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/scim/ServiceProviderConfig`
- **Base URL:** `https://mindcloud.filecloudtrial.com/api/v1`
- **Official documentation:** [Get Service Provider Configuration](https://fcapi-v1.filecloud.com/#/scim/getServiceProviderConfig)
