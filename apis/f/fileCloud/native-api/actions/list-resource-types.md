# List Resource Types with FileCloud

Retrieves resource types from FileCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/scim/ResourceTypes`
- **Base URL:** `https://mindcloud.filecloudtrial.com/api/v1`
- **Official documentation:** [List Resource Types](https://fcapi-v1.filecloud.com/#/scim/getResourceTypes)
