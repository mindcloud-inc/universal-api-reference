# Get Group by ID with FileCloud

Retrieves a group from FileCloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/scim/Groups/:id`
- **Base URL:** `https://mindcloud.filecloudtrial.com/api/v1`
- **Official documentation:** [Get Group by ID](https://fcapi-v1.filecloud.com/#/scim/getScimGroupById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID. |
