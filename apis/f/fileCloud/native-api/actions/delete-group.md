# Delete Group with FileCloud

Deletes an existing group from FileCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/scim/Groups/:id`
- **Base URL:** `https://mindcloud.filecloudtrial.com/api/v1`
- **Official documentation:** [Delete Group](https://fcapi-v1.filecloud.com/#/scim/deleteScimGroup)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Group ID. |
