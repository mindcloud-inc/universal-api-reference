# Get User by ID with FileCloud

Retrieves a user from FileCloud by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/scim/Users/:id`
- **Base URL:** `https://mindcloud.filecloudtrial.com/api/v1`
- **Official documentation:** [Get User by ID](https://fcapi-v1.filecloud.com/#/scim/getScimUserById)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User ID. |
