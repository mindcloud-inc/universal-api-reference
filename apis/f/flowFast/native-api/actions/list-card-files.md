# List Card Files with FlowFast

Retrieves files from a card in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId/files`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Card Files](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
