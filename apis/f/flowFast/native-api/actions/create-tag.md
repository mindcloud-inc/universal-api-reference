# Create Tag with FlowFast

Creates a new tag in FlowFast.

## Endpoint

- **Method:** `POST`
- **Path:** `/tags`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Create Tag](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `name` | body | `string` | no |
