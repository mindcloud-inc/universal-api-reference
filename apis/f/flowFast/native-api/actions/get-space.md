# Get Space with FlowFast

Retrieves space details from FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Get Space](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
