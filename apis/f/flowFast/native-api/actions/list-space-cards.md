# List Space Cards with FlowFast

Retrieves cards from a space in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/cards`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Space Cards](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
