# Update Card with FlowFast

Updates an existing card in FlowFast.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Update Card](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
| `title` | body | `string` | no |
