# Get Card with FlowFast

Retrieves card details from FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Get Card](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
