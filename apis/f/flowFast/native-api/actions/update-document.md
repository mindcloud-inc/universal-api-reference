# Update Document with FlowFast

Updates an existing document in FlowFast.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Update Document](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentId` | path | `string` | no |
| `title` | body | `string` | no |
