# Delete Column with FlowFast

Deletes an existing column from FlowFast.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/boards/:boardId/columns/:columnId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Delete Column](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | path | `string` | no |
| `columnId` | path | `string` | no |
