# List Board Columns with FlowFast

Retrieves columns from a board in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:boardId/columns`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Board Columns](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | path | `string` | no |
