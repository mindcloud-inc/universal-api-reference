# Get Document with FlowFast

Retrieves document details from FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Get Document](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentId` | path | `string` | no |
