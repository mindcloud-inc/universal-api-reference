# Get Board with FlowFast

Retrieves board details from FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:boardId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Get Board](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | path | `string` | no |
