# List Card Comments with FlowFast

Retrieves comments from a card in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId/comments`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Card Comments](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
