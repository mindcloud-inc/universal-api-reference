# List Board Lanes with FlowFast

Retrieves lanes from a board in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/boards/:boardId/lanes`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Board Lanes](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | path | `string` | no |
