# Create Board with FlowFast

Creates a new board in FlowFast.

## Endpoint

- **Method:** `POST`
- **Path:** `/spaces/:spaceId/boards`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Create Board](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
| `title` | body | `string` | no |
