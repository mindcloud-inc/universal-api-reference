# Delete Card with FlowFast

Deletes an existing card from FlowFast.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Delete Card](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
