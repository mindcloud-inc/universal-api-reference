# Create Column with FlowFast

Creates a new column in FlowFast.

## Endpoint

- **Method:** `POST`
- **Path:** `/boards/:boardId/columns`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Create Column](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `boardId` | path | `string` | no |
| `title` | body | `string` | no |
