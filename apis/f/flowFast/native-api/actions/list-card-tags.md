# List Card Tags with FlowFast

Retrieves tags from a card in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId/tags`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Card Tags](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `cardId` | path | `string` | no |
