# Delete Document with FlowFast

Deletes an existing document from FlowFast.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:documentId`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Delete Document](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentId` | path | `string` | no |
