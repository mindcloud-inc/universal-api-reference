# Create Card with FlowFast

Creates a new card in FlowFast.

## Endpoint

- **Method:** `POST`
- **Path:** `/cards`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Create Card](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `board_id` | body | `string` | no |
| `column_id` | body | `string` | no |
| `lane_id` | body | `string` | no |
| `title` | body | `string` | no |
