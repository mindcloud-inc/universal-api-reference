# Create Document with FlowFast

Creates a new document in FlowFast.

## Endpoint

- **Method:** `POST`
- **Path:** `/documents`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [Create Document](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `sort_order` | body | `string` | no |
| `title` | body | `string` | no |
