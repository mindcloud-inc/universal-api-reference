# List Space Boards with FlowFast

Retrieves boards from a space in FlowFast.

## Endpoint

- **Method:** `GET`
- **Path:** `/spaces/:spaceId/boards`
- **Base URL:** `https://apps.flowfast.io/api/latest/`
- **Official documentation:** [List Space Boards](https://apps.flowfast.io)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `spaceId` | path | `string` | no |
