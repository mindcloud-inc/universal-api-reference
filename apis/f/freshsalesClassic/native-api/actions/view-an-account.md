# View an Account with Freshsales Classic

Retrieves an account from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales_accounts/:id`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [View an Account](https://developers.freshworks.com/crm/api/#view_account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The account ID. |
