# View a Sales Activity with Freshsales Classic

Retrieves a sales activity from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales_activities/:salesActivityId`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [View a Sales Activity](https://developers.freshworks.com/crm/api/#view_a_sales_activity)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `salesActivityId` | path | `number` | yes | The sales activity ID. |
