# List All Sales Activities with Freshsales Classic

Retrieves sales activities from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/sales_activities`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List All Sales Activities](https://developers.freshworks.com/crm/api/#list_all_sales_activities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number to return. |
