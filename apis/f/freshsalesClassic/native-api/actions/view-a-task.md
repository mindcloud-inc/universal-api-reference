# View a Task with Freshsales Classic

Retrieves a task from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [View a Task](https://developers.freshworks.com/crm/api/#view_task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The task ID. |
