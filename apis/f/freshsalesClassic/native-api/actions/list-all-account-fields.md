# List All Account Fields with Freshsales Classic

Retrieves account fields from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/sales_accounts/fields`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List All Account Fields](https://developers.freshworks.com/crm/api/#list_all_account_fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Optional related data to include, for example field_group. |
