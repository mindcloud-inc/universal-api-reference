# List All Deal Fields with Freshsales Classic

Retrieves deal fields from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/deals/fields`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List All Deal Fields](https://developers.freshworks.com/crm/api/#list_all_deal_fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Optional related data to include, for example field_group. |
