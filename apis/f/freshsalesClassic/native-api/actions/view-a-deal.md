# View a Deal with Freshsales Classic

Retrieves a deal from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/:id`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [View a Deal](https://developers.freshworks.com/crm/api/#view_a_deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The deal ID. |
