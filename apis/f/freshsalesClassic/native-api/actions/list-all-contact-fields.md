# List All Contact Fields with Freshsales Classic

Retrieves contact fields from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/contacts/fields`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List All Contact Fields](https://developers.freshworks.com/crm/api/#list_all_contact_fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Optional related data to include, for example field_group. |
