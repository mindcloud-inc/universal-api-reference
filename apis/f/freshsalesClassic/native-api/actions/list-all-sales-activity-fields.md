# List All Sales Activity Fields with Freshsales Classic

Retrieves sales activity fields from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/sales_activities/fields`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List All Sales Activity Fields](https://developers.freshworks.com/crm/api/#list_all_sales_activity_fields)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `include` | query | `string` | no | Optional related data to include, for example field_group. |
