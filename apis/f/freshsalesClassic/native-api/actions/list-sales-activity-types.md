# List Sales Activity Types with Freshsales Classic

Retrieves sales activity types from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/selector/sales_activity_types`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List Sales Activity Types](https://developers.freshworks.com/crm/api/#admin_configuration)
