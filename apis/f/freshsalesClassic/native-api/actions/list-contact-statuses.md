# List Contact Statuses with Freshsales Classic

Retrieves contact statuses from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/selector/contact_statuses`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List Contact Statuses](https://developers.freshworks.com/crm/api/#admin_configuration)
