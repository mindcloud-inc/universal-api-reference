# View an Appointment with Freshsales Classic

Retrieves an appointment from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/:appointmentId`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [View an Appointment](https://developers.freshworks.com/crm/api/#view_an_appointment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `appointmentId` | path | `number` | yes | The appointment ID. |
