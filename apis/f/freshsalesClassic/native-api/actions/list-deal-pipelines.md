# List Deal Pipelines with Freshsales Classic

Retrieves deal pipelines from Freshsales Classic.

## Endpoint

- **Method:** `GET`
- **Path:** `/selector/deal_pipelines`
- **Base URL:** `https://{bundleAlias}/api`
- **Official documentation:** [List Deal Pipelines](https://developers.freshworks.com/crm/api/#admin_configuration)
