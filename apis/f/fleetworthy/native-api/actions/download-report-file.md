# Download Report File with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/reporting/report-download/:cpFileId`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Download Report File](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-reporting-report-download-cpfileid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cpFileId` | path | `string` | yes | The UUID corresponding to a report run file. |
