# Get Asset Document with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/documents/:documentId`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Get Asset Document](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-assets-documents-documentid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The primary key of the document. |
