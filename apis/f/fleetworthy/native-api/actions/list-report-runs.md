# List Report Runs with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/reporting/report-runs/:reportDisplayId`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [List Report Runs](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-reporting-report-runs-reportdisplayid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reportDisplayId` | path | `string` | yes | The display identifier for the report smart tile on the user's dashboard. |
