# Get People Client Metadata with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/people/client-metadata/{clientIdOrDisplayId}`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Get People Client Metadata](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-people-client-metadata-clientidordisplayid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `clientIdOrDisplayId` | path | `string` | yes | The Fleetworthy client UUID or display identifier. |
