# Get Asset File Info with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/file-info`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Get Asset File Info](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-assets-file-info)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | query | `string` | yes | The unique identifier of the asset to find file information for. |
