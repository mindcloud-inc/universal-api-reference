# Download Asset File with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/files/:cpFileId/download`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Download Asset File](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-assets-files-cpfileid-download)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cpFileId` | path | `string` | yes | The unique identifier of the file to download. |
