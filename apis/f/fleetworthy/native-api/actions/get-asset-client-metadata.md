- **Official documentation:** [Get Asset Client Metadata](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-assets-client-metadata-clientidordisplayid)

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `clientIdOrDisplayId` | path | `string` | yes |
