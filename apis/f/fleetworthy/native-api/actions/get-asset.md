# Get Asset with Fleetworthy

## Endpoint

- **Method:** `GET`
- **Path:** `/assets/:assetId`
- **Base URL:** `https://apis.fleetworthy.com/compliance-api/v1`
- **Official documentation:** [Get Asset](https://developer.fleetworthy.com/api-details#api=prod-compliance-v1&operation=get-assets-assetid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `assetId` | path | `string` | yes | The unique identifier of the asset. |
