# List Accounts with Frame.io v4

Retrieves accounts from Frame.io v4.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts`
- **Base URL:** `https://api.frame.io/v4`
- **Official documentation:** [List Accounts](https://next.developer.frame.io/platform/api-reference/accounts/index)

## Capabilities

This operation supports [pagination](../README.md#pagination).
