# Get Share with Frame.io v4

Retrieves a share from Frame.io v4.

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:accountId/shares/:shareId`
- **Base URL:** `https://api.frame.io/v4`
- **Official documentation:** [Get Share](https://next.developer.frame.io/platform/api-reference/shares/show)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | yes |
| `share_id` | path | `string` | yes |
