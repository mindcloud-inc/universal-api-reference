# List HMA Mitigated Properties with FEMA

Retrieves HMA mitigated properties from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/HazardMitigationAssistanceMitigatedProperties`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMA Mitigated Properties](https://www.fema.gov/openfema-data-page/hazard-mitigation-assistance-mitigated-properties-v4)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
