# List HMA Subapplications by NFIP CRS Communities with FEMA

Retrieves HMA subapplications for NFIP CRS communities.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/HmaSubapplicationsByNfipCrsCommunities`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMA Subapplications by NFIP CRS Communities](https://www.fema.gov/openfema-data-page/hma-subapplications-nfip-crs-communities-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
