# List Public Assistance Funded Project Details with FEMA

Retrieves public assistance funded project details from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/PublicAssistanceFundedProjectsDetails`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Funded Project Details](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-details-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
