# List NFIP Community Status Book with FEMA

Retrieves the NFIP Community Status Book from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/NfipCommunityStatusBook`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List NFIP Community Status Book](https://www.fema.gov/openfema-data-page/nfip-community-status-book-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
