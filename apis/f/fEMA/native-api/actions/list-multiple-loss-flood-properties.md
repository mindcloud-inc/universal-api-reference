# List Multiple Loss Flood Properties with FEMA

Retrieves multiple loss flood properties from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/IndividualAssistanceMultipleLossFloodProperties`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Multiple Loss Flood Properties](https://www.fema.gov/openfema-data-page/Individual-Assistance-Multiple-Loss-Flood-Properties-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
