# List HMA Subapplication Financial Transactions with FEMA

Retrieves HMA subapplication financial transactions from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/HmaSubapplicationsFinancialTransactions`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMA Subapplication Financial Transactions](https://www.fema.gov/openfema-data-page/HMA-Subapplications-Financial-Transactions-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
