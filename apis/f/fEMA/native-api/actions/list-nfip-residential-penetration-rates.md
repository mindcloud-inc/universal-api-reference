# List NFIP Residential Penetration Rates with FEMA

Retrieves NFIP residential penetration rates from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/NfipResidentialPenetrationRates`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List NFIP Residential Penetration Rates](https://www.fema.gov/openfema-data-page/nfip-residential-penetration-rates-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
