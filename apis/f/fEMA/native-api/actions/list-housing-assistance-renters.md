# List Housing Assistance Renters with FEMA

Retrieves housing assistance renter records from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/HousingAssistanceRenters`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Housing Assistance Renters](https://www.fema.gov/openfema-data-page/housing-assistance-program-data-renters-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
