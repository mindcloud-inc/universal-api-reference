# List Public Assistance Grant Award Activities with FEMA

Retrieves public assistance grant award activities from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/PublicAssistanceGrantAwardActivities`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Grant Award Activities](https://www.fema.gov/openfema-data-page/public-assistance-grant-award-activities-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
