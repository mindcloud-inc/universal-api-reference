# List NFIP Multiple Loss Properties with FEMA

Retrieves NFIP multiple loss properties from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/NfipMultipleLossProperties`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List NFIP Multiple Loss Properties](https://www.fema.gov/openfema-data-page/NFIP-Multiple-Loss-Properties-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
