# List FEMA Regions with FEMA

Retrieves FEMA regions.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/FemaRegions`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List FEMA Regions](https://www.fema.gov/openfema-data-page/fema-regions-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
