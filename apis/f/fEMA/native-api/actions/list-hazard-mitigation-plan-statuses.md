# List Hazard Mitigation Plan Statuses with FEMA

Retrieves hazard mitigation plan statuses from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/HazardMitigationPlanStatuses`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Hazard Mitigation Plan Statuses](https://www.fema.gov/openfema-data-page/hazard-mitigation-plan-statuses-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
