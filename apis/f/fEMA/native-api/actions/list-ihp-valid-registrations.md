# List IHP Valid Registrations with FEMA

Retrieves IHP valid registrations from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/IndividualsAndHouseholdsProgramValidRegistrations`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List IHP Valid Registrations](https://www.fema.gov/openfema-data-page/individuals-and-households-program-valid-registrations-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
