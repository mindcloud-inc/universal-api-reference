# List Public Assistance Funded Project Summaries with FEMA

Retrieves public assistance funded project summaries from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/PublicAssistanceFundedProjectsSummaries`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Funded Project Summaries](https://www.fema.gov/openfema-data-page/public-assistance-funded-projects-summaries-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
