# List FEMA Web Disaster Summaries with FEMA

Retrieves FEMA web disaster summaries.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/FemaWebDisasterSummaries`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List FEMA Web Disaster Summaries](https://www.fema.gov/openfema-data-page/fema-web-disaster-summaries-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
