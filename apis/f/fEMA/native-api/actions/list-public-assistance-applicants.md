# List Public Assistance Applicants with FEMA

Retrieves public assistance applicants from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/PublicAssistanceApplicants`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Applicants](https://www.fema.gov/openfema-data-page/public-assistance-applicants-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
