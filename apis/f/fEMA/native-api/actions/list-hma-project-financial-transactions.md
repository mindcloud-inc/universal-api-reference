# List HMA Project Financial Transactions with FEMA

Retrieves HMA project financial transactions from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/HazardMitigationAssistanceProjectsFinancialTransactions`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMA Project Financial Transactions](https://www.fema.gov/openfema-data-page/hazard-mitigation-assistance-projects-financial-transactions-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
