# List Public Assistance Program Deliveries with FEMA

Retrieves public assistance program deliveries from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/PublicAssistanceApplicantsProgramDeliveries`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Program Deliveries](https://www.fema.gov/openfema-data-page/public-assistance-applicants-program-deliveries-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
