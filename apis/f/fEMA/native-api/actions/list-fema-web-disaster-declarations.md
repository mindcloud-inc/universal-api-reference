# List FEMA Web Disaster Declarations with FEMA

Retrieves FEMA web disaster declarations.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/FemaWebDisasterDeclarations`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List FEMA Web Disaster Declarations](https://www.fema.gov/openfema-data-page/fema-web-disaster-declarations-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
