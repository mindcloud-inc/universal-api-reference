# List Housing Assistance Owners with FEMA

Retrieves housing assistance owner records from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/HousingAssistanceOwners`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Housing Assistance Owners](https://www.fema.gov/openfema-data-page/housing-assistance-program-data-owners-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
