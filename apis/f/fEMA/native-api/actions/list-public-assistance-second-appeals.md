# List Public Assistance Second Appeals with FEMA

Retrieves public assistance second appeals from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/PublicAssistanceSecondAppealsTracker`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Public Assistance Second Appeals](https://www.fema.gov/openfema-data-page/public-assistance-second-appeals-tracker-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
