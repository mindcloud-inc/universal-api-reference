# List HMA Subapplications with FEMA

Retrieves HMA subapplications from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/HmaSubapplications`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMA Subapplications](https://www.fema.gov/openfema-data-page/HMA-Subapplications-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
