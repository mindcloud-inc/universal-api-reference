# List Training Class Schedule with FEMA

Retrieves the FEMA training class schedule.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/TrainingClassSchedule`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Training Class Schedule](https://www.fema.gov/openfema-data-page/training-class-schedule-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
