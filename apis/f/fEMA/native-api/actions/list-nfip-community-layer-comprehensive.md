# List NFIP Community Layer Comprehensive with FEMA

Retrieves NFIP community layer records from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/NfipCommunityLayerComprehensive`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List NFIP Community Layer Comprehensive](https://www.fema.gov/openfema-data-page/nfip-community-layer-comprehensive-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
