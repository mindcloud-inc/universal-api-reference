# List Training Course Catalog with FEMA

Retrieves FEMA training course catalog entries.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/TrainingCourseCatalog`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Training Course Catalog](https://www.fema.gov/openfema-data-page/training-course-catalog-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
