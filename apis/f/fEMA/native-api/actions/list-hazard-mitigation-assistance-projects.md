# List Hazard Mitigation Assistance Projects with FEMA

Retrieves hazard mitigation assistance projects from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v4/HazardMitigationAssistanceProjects`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Hazard Mitigation Assistance Projects](https://www.fema.gov/openfema-data-page/hazard-mitigation-assistance-projects-v4)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
