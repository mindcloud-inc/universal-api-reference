# List Emergency Management Performance Grants with FEMA

Retrieves emergency management performance grants from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/EmergencyManagementPerformanceGrants`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Emergency Management Performance Grants](https://www.fema.gov/openfema-data-page/emergency-management-performance-grants-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
