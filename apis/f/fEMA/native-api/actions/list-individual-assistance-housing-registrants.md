# List Individual Assistance Housing Registrants with FEMA

Retrieves individual assistance housing registrants from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/IndividualAssistanceHousingRegistrantsLargeDisasters`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Individual Assistance Housing Registrants](https://www.fema.gov/openfema-data-page/individual-assistance-housing-registrants-large-disasters-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
