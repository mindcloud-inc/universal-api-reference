# List Declaration Denials with FEMA

Retrieves declaration denials from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/DeclarationDenials`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Declaration Denials](https://www.fema.gov/openfema-data-page/declaration-denials-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
