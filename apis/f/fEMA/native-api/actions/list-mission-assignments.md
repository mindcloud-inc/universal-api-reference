# List Mission Assignments with FEMA

Retrieves mission assignments from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/MissionAssignments`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Mission Assignments](https://www.fema.gov/openfema-data-page/mission-assignments-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
