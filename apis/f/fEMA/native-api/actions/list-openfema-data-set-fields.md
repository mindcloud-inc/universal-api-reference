# List OpenFEMA Data Set Fields with FEMA

Retrieves OpenFEMA data set fields from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/DataSetFields`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List OpenFEMA Data Set Fields](https://www.fema.gov/openfema-data-page/openfema-data-set-fields-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
