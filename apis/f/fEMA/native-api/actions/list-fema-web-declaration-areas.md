# List FEMA Web Declaration Areas with FEMA

Retrieves FEMA web declaration areas.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/FemaWebDeclarationAreas`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List FEMA Web Declaration Areas](https://www.fema.gov/openfema-data-page/fema-web-declaration-areas-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
