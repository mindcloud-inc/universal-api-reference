# List Non-Disaster Firefighter Grants with FEMA

Retrieves non-disaster firefighter grants from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/NonDisasterAssistanceFirefighterGrants`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Non-Disaster Firefighter Grants](https://www.fema.gov/openfema-data-page/non-disaster-and-assistance-firefighter-grants-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
