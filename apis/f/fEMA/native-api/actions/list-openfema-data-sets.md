# List OpenFEMA Data Sets with FEMA

Retrieves OpenFEMA data sets from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/DataSets`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List OpenFEMA Data Sets](https://www.fema.gov/openfema-data-page/openfema-data-sets-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
