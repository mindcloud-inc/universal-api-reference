# List NFIP Claims with FEMA

Retrieves NFIP claims from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/FimaNfipClaims`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List NFIP Claims](https://www.fema.gov/openfema-data-page/fima-nfip-redacted-claims-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
