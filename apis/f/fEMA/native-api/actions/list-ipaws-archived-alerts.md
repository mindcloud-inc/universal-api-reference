# List IPAWS Archived Alerts with FEMA

Retrieves IPAWS archived alerts from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/IpawsArchivedAlerts`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List IPAWS Archived Alerts](https://www.fema.gov/openfema-data-page/ipaws-archived-alerts-v1)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
