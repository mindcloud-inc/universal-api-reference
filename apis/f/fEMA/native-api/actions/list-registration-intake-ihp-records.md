# List Registration Intake IHP Records with FEMA

Retrieves registration intake IHP records from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/RegistrationIntakeIndividualsHouseholdPrograms`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List Registration Intake IHP Records](https://www.fema.gov/openfema-data-page/registration-intake-and-individuals-household-program-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
