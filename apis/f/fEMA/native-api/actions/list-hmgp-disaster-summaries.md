# List HMGP Disaster Summaries with FEMA

Retrieves HMGP disaster summaries from FEMA.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/HazardMitigationGrantProgramDisasterSummaries`
- **Base URL:** `https://www.fema.gov/api/open`
- **Official documentation:** [List HMGP Disaster Summaries](https://www.fema.gov/openfema-data-page/hazard-mitigation-grant-program-disaster-summaries-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
