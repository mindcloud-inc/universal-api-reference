# Forget Document with Freshworks CRM

Permanently deletes a document from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/cpq/cpq_documents/:id/forget`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Forget Document](https://developers.freshworks.com/crm/api/#forget_a_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
