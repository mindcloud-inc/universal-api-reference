# Forget Deal with Freshworks CRM

Permanently deletes a deal from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/deals/:id/forget`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Forget Deal](https://developers.freshworks.com/crm/api/#forget_a_deal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
