# Get Product with Freshworks CRM

Retrieves a product from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/cpq/products/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Product](https://developers.freshworks.com/crm/api/#view_a_product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
