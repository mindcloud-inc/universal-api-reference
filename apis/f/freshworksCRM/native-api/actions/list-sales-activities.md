# List Sales Activities with Freshworks CRM

Retrieves sales activities from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `api/sales_activities`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Sales Activities](https://developers.freshworks.com/crm/api/#list_all_sales_activities)

## Capabilities

This operation supports [pagination](../README.md#pagination).
