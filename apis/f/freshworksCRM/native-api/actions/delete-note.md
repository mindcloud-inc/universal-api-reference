# Delete Note with Freshworks CRM

Deletes an existing note from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/notes/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Note](https://developers.freshworks.com/crm/api/#delete_a_note)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
