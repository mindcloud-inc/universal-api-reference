# Get Task with Freshworks CRM

Retrieves a task from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tasks/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Task](https://developers.freshworks.com/crm/api/#view_task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
