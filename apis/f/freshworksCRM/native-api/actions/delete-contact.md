# Delete Contact with Freshworks CRM

Deletes an existing contact from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/contacts/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Contact](https://developers.freshworks.com/crm/api/#delete_a_contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique contact identifier. |
