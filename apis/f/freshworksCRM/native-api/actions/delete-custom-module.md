# Delete Custom Module with Freshworks CRM

Deletes a custom module from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/settings/module_customizations/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Custom Module](https://developers.freshworks.com/crm/api/#delete_custom_module)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
