# Create List with Freshworks CRM

Creates a new list in Freshworks CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/lists`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Create List](https://developers.freshworks.com/crm/api/#create_list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | List name |
