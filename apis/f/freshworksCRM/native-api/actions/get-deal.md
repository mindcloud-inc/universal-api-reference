# Get Deal with Freshworks CRM

Retrieves a deal from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `api/deals/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Deal](https://developers.freshworks.com/crm/api/#view_a_deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique deal identifier. |
