# Get Contact with Freshworks CRM

Retrieves a contact from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `api/contacts/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Contact](https://developers.freshworks.com/crm/api/#view_a_contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique contact identifier. |
