# Delete Product with Freshworks CRM

Deletes an existing product from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/cpq/products/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Product](https://developers.freshworks.com/crm/api/#delete_a_product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
