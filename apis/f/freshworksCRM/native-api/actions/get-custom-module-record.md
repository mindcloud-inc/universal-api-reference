# Get Custom Module Record with Freshworks CRM

Retrieves a custom module record from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/custom_module/:entity_name/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Custom Module Record](https://developers.freshworks.com/crm/api/#get_list_of_all_records_in_custom_module)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_name` | path | `string` | yes |
| `id` | path | `string` | yes |
