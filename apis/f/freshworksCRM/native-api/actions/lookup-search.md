# Lookup Search with Freshworks CRM

Finds matching lookup records in Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/lookup`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Lookup Search](https://developers.freshworks.com/crm/api/#lookup_search)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `q` | query | `string` | yes |
