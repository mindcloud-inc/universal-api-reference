# Get Appointment with Freshworks CRM

Retrieves a appointment from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/appointments/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Appointment](https://developers.freshworks.com/crm/api/#view_an_appointment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
