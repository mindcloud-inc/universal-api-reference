# Delete Appointment with Freshworks CRM

Deletes an existing appointment from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/appointments/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Appointment](https://developers.freshworks.com/crm/api/#delete_an_appointment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
