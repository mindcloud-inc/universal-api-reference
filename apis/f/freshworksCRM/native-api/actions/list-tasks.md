# List Tasks with Freshworks CRM

Retrieves all tasks from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/tasks`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Tasks](https://developers.freshworks.com/crm/api/#list_all_task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter` | query | `string` | no |
