# Get Related Products with Freshworks CRM

Retrieves related products from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/cpq/cpq_documents/:id/related_products`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Related Products](https://developers.freshworks.com/crm/api/#related_products)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
