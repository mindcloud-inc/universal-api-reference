# Restore Product with Freshworks CRM

Restores a product in Freshworks CRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/cpq/products/:id/restore`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Restore Product](https://developers.freshworks.com/crm/api/#restore_a_product)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
