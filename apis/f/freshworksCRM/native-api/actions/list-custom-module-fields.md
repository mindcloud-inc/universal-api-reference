# List Custom Module Fields with Freshworks CRM

Retrieves custom module fields from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/settings/:entity_type/forms`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Custom Module Fields](https://developers.freshworks.com/crm/api/#list_of_all_fields_in_your_custom_module)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_type` | path | `string` | yes |
