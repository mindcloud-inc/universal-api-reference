# Delete Task with Freshworks CRM

Deletes an existing task from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/tasks/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Task](https://developers.freshworks.com/crm/api/#delete_task)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
