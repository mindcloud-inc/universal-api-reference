# List Sales Activity Fields with Freshworks CRM

Retrieves sales activity fields from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/settings/sales_activities/fields`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Sales Activity Fields](https://developers.freshworks.com/crm/api/#list_all_sales_activity_fields)
