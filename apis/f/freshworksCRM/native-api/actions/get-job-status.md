# Get Job Status with Freshworks CRM

Retrieves job status from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/job_statuses/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Job Status](https://developers.freshworks.com/crm/api/#job_status_api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
