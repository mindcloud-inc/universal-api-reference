# Get Document with Freshworks CRM

Retrieves a document from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/cpq/cpq_documents/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Document](https://developers.freshworks.com/crm/api/#view_a_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
