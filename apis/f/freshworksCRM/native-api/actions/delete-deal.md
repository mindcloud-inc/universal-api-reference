# Delete Deal with Freshworks CRM

Deletes an existing deal from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/deals/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Deal](https://developers.freshworks.com/crm/api/#delete_a_deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique deal identifier. |
