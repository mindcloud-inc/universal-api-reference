# Update Custom Module Record with Freshworks CRM

Updates a custom module record in Freshworks CRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/custom_module/:entity_name/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Update Custom Module Record](https://developers.freshworks.com/crm/api/#update_record_in_custom_module)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_name` | path | `string` | yes |
| `id` | path | `string` | yes |
