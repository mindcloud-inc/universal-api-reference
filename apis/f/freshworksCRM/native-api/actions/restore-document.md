# Restore Document with Freshworks CRM

Restores a document in Freshworks CRM.

## Endpoint

- **Method:** `PUT`
- **Path:** `/api/cpq/cpq_documents/:id/restore`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Restore Document](https://developers.freshworks.com/crm/api/#restore_a_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
