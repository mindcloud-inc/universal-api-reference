# Get Sales Account with Freshworks CRM

Retrieves a sales account from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `api/sales_accounts/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Sales Account](https://developers.freshworks.com/crm/api/#view_account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique sales account identifier. |
