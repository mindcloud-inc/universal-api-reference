# Clone Deal with Freshworks CRM

Creates a deal by cloning one in Freshworks CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/deals/:id/clone`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Clone Deal](https://developers.freshworks.com/crm/api/#clone_a_deal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
