# List Contacts In List with Freshworks CRM

Retrieves contacts from a list in Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/lists/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Contacts In List](https://developers.freshworks.com/crm/api/#fetch_all_contacts_from_list)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
