# Delete Sales Account with Freshworks CRM

Deletes an existing sales account from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `api/sales_accounts/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Sales Account](https://developers.freshworks.com/crm/api/#delete_account)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | no | Unique sales account identifier. |
