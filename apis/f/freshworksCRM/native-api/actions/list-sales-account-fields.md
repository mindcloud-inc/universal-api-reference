# List Sales Account Fields with Freshworks CRM

Retrieves sales account fields from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `api/settings/sales_accounts/fields`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Sales Account Fields](https://developers.freshworks.com/crm/api/#list_all_account_fields)
