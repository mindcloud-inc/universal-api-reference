# Forget Account with Freshworks CRM

Permanently deletes a sales account from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/sales_accounts/:id/forget`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Forget Account](https://developers.freshworks.com/crm/api/#forget_account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
