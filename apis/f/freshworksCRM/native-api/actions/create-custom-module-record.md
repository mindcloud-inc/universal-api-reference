# Create Custom Module Record with Freshworks CRM

Creates a custom module record in Freshworks CRM.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/custom_module/:entity_name`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Create Custom Module Record](https://developers.freshworks.com/crm/api/#create_record_in_custom_module)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `entity_name` | path | `string` | yes |
