# Delete Document with Freshworks CRM

Deletes an existing document from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/cpq/cpq_documents/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Document](https://developers.freshworks.com/crm/api/#delete_a_document)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
