# Forget Contact with Freshworks CRM

Permanently deletes a contact from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/contacts/:id/forget`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Forget Contact](https://developers.freshworks.com/crm/api/#forget_a_contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
