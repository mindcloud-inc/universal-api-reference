# Get Sales Activity with Freshworks CRM

Retrieves a sales activity from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/sales_activities/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Sales Activity](https://developers.freshworks.com/crm/api/#view_a_sales_activity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
