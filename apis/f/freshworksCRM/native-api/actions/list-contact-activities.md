# List Contact Activities with Freshworks CRM

Retrieves activities for a contact in Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/:id/activities`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Contact Activities](https://developers.freshworks.com/crm/api/#list_all_contact_activities)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
