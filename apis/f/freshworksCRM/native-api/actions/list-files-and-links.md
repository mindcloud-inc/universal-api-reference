# List Files And Links with Freshworks CRM

Retrieves files and links for a contact in Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/contacts/:id/document_associations`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Files And Links](https://developers.freshworks.com/crm/api/#list_files)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
