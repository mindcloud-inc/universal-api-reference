# Get Custom Module with Freshworks CRM

Retrieves a custom module from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/settings/module_customizations/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Get Custom Module](https://developers.freshworks.com/crm/api/#get_list_of_custom_modules)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
