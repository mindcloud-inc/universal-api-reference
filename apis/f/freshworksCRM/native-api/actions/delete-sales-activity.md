# Delete Sales Activity with Freshworks CRM

Deletes an existing sales activity from Freshworks CRM.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/sales_activities/:id`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [Delete Sales Activity](https://developers.freshworks.com/crm/api/#delete_a_sales_activity)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
