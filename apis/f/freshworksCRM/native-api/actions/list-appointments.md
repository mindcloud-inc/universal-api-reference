# List Appointments with Freshworks CRM

Retrieves all appointments from Freshworks CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/appointments`
- **Base URL:** `https://{bundleAlias}`
- **Official documentation:** [List Appointments](https://developers.freshworks.com/crm/api/#list_all_appointment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `filter` | query | `string` | no |
