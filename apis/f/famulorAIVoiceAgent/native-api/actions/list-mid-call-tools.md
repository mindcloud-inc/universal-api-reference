# List Mid Call Tools with Famulor AI - Voice Agent

Retrieves mid-call tools from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/tools`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Mid Call Tools](https://docs.famulor.io/en/api-reference/mid-call-tools/get-tools)
