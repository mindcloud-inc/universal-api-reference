# List Leads with Famulor AI - Voice Agent

Retrieves leads from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/leads`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Leads](https://docs.famulor.io/en/api-reference/leads/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
