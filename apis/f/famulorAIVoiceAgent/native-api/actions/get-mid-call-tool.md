# Get Mid Call Tool with Famulor AI - Voice Agent

Retrieves mid-call tool details from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/tools/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get Mid Call Tool](https://docs.famulor.io/en/api-reference/mid-call-tools/get-tool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor mid-call tool ID. |
