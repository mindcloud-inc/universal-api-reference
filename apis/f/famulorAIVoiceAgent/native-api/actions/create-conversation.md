# Create Conversation with Famulor AI - Voice Agent

Creates a new conversation in Famulor.

## Endpoint

- **Method:** `POST`
- **Path:** `/conversations`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Create Conversation](https://docs.famulor.io/en/api-reference/ai-chatbot/create-conversation)
