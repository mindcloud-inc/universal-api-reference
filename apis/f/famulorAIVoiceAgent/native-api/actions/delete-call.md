# Delete Call with Famulor AI - Voice Agent

Deletes an existing call from Famulor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/calls/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Delete Call](https://docs.famulor.io/en/api-reference/calls/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor call ID. |
