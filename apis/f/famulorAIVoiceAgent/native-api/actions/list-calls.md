# List Calls with Famulor AI - Voice Agent

Retrieves calls from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/calls`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Calls](https://docs.famulor.io/en/api-reference/calls/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
