# Delete Mid Call Tool with Famulor AI - Voice Agent

Deletes an existing mid-call tool from Famulor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/tools/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Delete Mid Call Tool](https://docs.famulor.io/en/api-reference/mid-call-tools/delete-tool)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor mid-call tool ID. |
