# Get User Information with Famulor AI - Voice Agent

Retrieves the authenticated user's account details from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/me`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get User Information](https://docs.famulor.io/en/api-reference/user/me)
