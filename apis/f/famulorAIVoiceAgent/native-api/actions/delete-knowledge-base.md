# Delete Knowledge Base with Famulor AI - Voice Agent

Deletes an existing knowledge base from Famulor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/knowledgebases/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Delete Knowledge Base](https://docs.famulor.io/en/api-reference/knowledgebases/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor knowledge base ID. |
