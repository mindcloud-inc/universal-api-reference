# Retrieve Available Models with Famulor AI - Voice Agent

Retrieves available assistant AI models from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/models`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Retrieve Available Models](https://docs.famulor.io/en/api-reference/assistants/models)
