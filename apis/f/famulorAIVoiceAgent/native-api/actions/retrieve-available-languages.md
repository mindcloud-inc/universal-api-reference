# Retrieve Available Languages with Famulor AI - Voice Agent

Retrieves available assistant languages from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/languages`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Retrieve Available Languages](https://docs.famulor.io/en/api-reference/assistants/languages)
