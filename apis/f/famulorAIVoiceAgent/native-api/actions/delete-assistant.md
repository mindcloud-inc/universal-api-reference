# Delete Assistant with Famulor AI - Voice Agent

Deletes an existing AI assistant from Famulor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/assistant/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Delete Assistant](https://docs.famulor.io/en/api-reference/assistants/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor assistant ID. |
