# Delete Lead with Famulor AI - Voice Agent

Deletes an existing lead from Famulor.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/leads/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Delete Lead](https://docs.famulor.io/en/api-reference/leads/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor lead ID. |
