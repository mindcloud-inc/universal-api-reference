# Get Call with Famulor AI - Voice Agent

Retrieves call details from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/calls/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get Call](https://docs.famulor.io/en/api-reference/user/calls/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor call ID. |
