# Get Conversation with Famulor AI - Voice Agent

Retrieves conversation history from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:uuid`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get Conversation](https://docs.famulor.io/en/api-reference/ai-chatbot/get-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | Conversation UUID. |
