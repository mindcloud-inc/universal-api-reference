# Retrieve Available Phone Numbers with Famulor AI - Voice Agent

Retrieves available phone numbers from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/phone-numbers`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Retrieve Available Phone Numbers](https://docs.famulor.io/en/api-reference/assistants/phone-numbers)
