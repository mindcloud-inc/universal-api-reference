# Get Outbound Assistants with Famulor AI - Voice Agent

Retrieves outbound assistants from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/outbound`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get Outbound Assistants](https://docs.famulor.io/en/api-reference/assistants/outbound)
