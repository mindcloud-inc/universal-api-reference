# Retrieve Available Voices with Famulor AI - Voice Agent

Retrieves available assistant voices from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/voices`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Retrieve Available Voices](https://docs.famulor.io/en/api-reference/assistants/voices)
