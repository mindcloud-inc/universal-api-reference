# List Knowledge Bases with Famulor AI - Voice Agent

Retrieves knowledge bases from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/knowledgebases`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Knowledge Bases](https://docs.famulor.io/en/api-reference/knowledgebases/list)
