# Get Knowledge Base with Famulor AI - Voice Agent

Retrieves knowledge base details from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/knowledgebases/:id`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [Get Knowledge Base](https://docs.famulor.io/en/api-reference/knowledgebases/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Famulor knowledge base ID. |
