# List Knowledge Base Documents with Famulor AI - Voice Agent

Retrieves documents from a Famulor knowledge base.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/knowledgebases/:knowledgebaseId/documents`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Knowledge Base Documents](https://docs.famulor.io/en/api-reference/knowledgebases/list-documents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `knowledgebaseId` | path | `number` | yes | Famulor knowledge base ID. |
