# List Assistants with Famulor AI - Voice Agent

Retrieves assistants from Famulor.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/assistants/get`
- **Base URL:** `https://app.famulor.de/api`
- **Official documentation:** [List Assistants](https://docs.famulor.io/en/api-reference/assistants/list)

## Capabilities

This operation supports [pagination](../README.md#pagination).
