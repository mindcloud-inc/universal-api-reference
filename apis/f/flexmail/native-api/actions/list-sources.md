# List Sources with Flexmail

Retrieves available contact sources from Flexmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [List Sources](https://api.flexmail.eu/documentation/#get-/sources)

## Capabilities

This operation supports [pagination](../README.md#pagination).
