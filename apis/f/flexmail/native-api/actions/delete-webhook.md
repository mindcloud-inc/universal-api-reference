# Delete Webhook with Flexmail

Deletes a webhook endpoint from Flexmail.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/{id}`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Delete Webhook](https://api.flexmail.eu/documentation/#delete-/webhooks/-id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
