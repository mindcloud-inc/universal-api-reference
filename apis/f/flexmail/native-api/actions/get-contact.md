# Get Contact with Flexmail

Retrieves a contact record from Flexmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{id}`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Get Contact](https://api.flexmail.eu/documentation/#get-/contacts/-id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
