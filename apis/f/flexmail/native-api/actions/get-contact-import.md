# Get Contact Import with Flexmail

Retrieves a contact import from Flexmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/imports/{id}`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Get Contact Import](https://api.flexmail.eu/documentation/#get-/contacts/imports/-id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
