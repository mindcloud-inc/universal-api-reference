# List Contact Interest Subscriptions with Flexmail

Retrieves interest subscriptions for a contact from Flexmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/{id}/interest-subscriptions`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [List Contact Interest Subscriptions](https://api.flexmail.eu/documentation/#get-/contacts/-id-/interest-subscriptions)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
