# Create Contact Import with Flexmail

Creates a new contact import in Flexmail.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/imports`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Create Contact Import](https://api.flexmail.eu/documentation/#post-/contacts/imports)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
