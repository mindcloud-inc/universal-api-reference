# Get Webhook with Flexmail

Retrieves a webhook endpoint from Flexmail.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/{id}`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Get Webhook](https://api.flexmail.eu/documentation/#get-/webhooks/-id-)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
