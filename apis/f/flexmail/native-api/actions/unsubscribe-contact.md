# Unsubscribe Contact with Flexmail

Unsubscribes an existing contact from Flexmail communications.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/{id}/unsubscribe`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Unsubscribe Contact](https://api.flexmail.eu/documentation/#post-/contacts/-id-/unsubscribe)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
