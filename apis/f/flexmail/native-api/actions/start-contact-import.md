# Start Contact Import with Flexmail

Starts a contact import in Flexmail.

## Endpoint

- **Method:** `POST`
- **Path:** `/contacts/imports/{id}/start`
- **Base URL:** `https://api.flexmail.eu`
- **Official documentation:** [Start Contact Import](https://api.flexmail.eu/documentation/#post-/contacts/imports/-id-/start)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
