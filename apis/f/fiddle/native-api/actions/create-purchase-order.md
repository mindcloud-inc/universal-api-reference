# Create Purchase Order with Fiddle

Creates a new purchase order in Fiddle.

## Endpoint

- **Method:** `POST`
- **Path:** `/purchase-orders`
- **Base URL:** `https://fiddle.io/rest/api/v2`
- **Official documentation:** [Create Purchase Order](https://fiddle.io/rest/api/v2/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | body | `string` | yes | Supplier ID from Fiddle |
