# List Quarantined Lots with Fiddle

Retrieves quarantined inventory lots from Fiddle.

## Endpoint

- **Method:** `GET`
- **Path:** `/inventory-lots/quarantine`
- **Base URL:** `https://fiddle.io/rest/api/v2`
- **Official documentation:** [List Quarantined Lots](https://fiddle.io/rest/api/v2/docs/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
