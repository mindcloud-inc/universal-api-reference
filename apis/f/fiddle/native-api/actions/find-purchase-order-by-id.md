# Find Purchase Order by ID with Fiddle

Finds a purchase order in Fiddle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/purchase-orders/:purchaseOrderId`
- **Base URL:** `https://fiddle.io/rest/api/v2`
- **Official documentation:** [Find Purchase Order by ID](https://fiddle.io/rest/api/v2/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `purchaseOrderId` | path | `string` | yes | Purchase order ID |
