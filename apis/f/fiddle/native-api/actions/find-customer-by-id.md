# Find Customer by ID with Fiddle

Finds a customer in Fiddle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/customers/:customerId`
- **Base URL:** `https://fiddle.io/rest/api/v2`
- **Official documentation:** [Find Customer by ID](https://fiddle.io/rest/api/v2/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | Customer ID |
