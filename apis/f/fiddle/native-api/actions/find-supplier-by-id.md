# Find Supplier by ID with Fiddle

Finds a supplier in Fiddle by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/suppliers/:supplierId`
- **Base URL:** `https://fiddle.io/rest/api/v2`
- **Official documentation:** [Find Supplier by ID](https://fiddle.io/rest/api/v2/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | path | `string` | yes | Supplier ID |
