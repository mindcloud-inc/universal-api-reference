# List All Projects with Freelo

Retrieves all accessible projects from Freelo.

## Endpoint

- **Method:** `GET`
- **Path:** `/all-projects`
- **Base URL:** `https://api.freelo.io/v1`
- **Official documentation:** [List All Projects](https://api.freelo.io/docs/v1/freelo-api)

## Capabilities

This operation supports [sorting](../README.md#sorting).
