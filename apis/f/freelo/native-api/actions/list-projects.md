# List Projects with Freelo

Retrieves own active projects from Freelo.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://api.freelo.io/v1`
- **Official documentation:** [List Projects](https://api.freelo.io/docs/v1/freelo-api)

## Capabilities

This operation supports [sorting](../README.md#sorting).
