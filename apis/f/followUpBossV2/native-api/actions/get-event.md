# Get Event with Follow Up Boss

Retrieves an event from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `events/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get Event](https://docs.followupboss.com/reference/events-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The event ID. |
