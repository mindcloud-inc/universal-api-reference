# Get Note with Follow Up Boss

Retrieves a note from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `notes/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get Note](https://docs.followupboss.com/reference/notes-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The note ID. |
