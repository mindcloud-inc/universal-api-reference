# Update Note with Follow Up Boss

Updates an existing note in Follow Up Boss.

## Endpoint

- **Method:** `PUT`
- **Path:** `notes/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Update Note](https://docs.followupboss.com/reference/notes-id-put)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The note ID. |
| `body` | body | `string` | no | — |
