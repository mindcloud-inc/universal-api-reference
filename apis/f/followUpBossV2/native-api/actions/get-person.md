# Get Person with Follow Up Boss

Retrieves a person from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `people/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get Person](https://docs.followupboss.com/reference/people-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The person ID. |
