# Get User with Follow Up Boss

Retrieves a user from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `users/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get User](https://docs.followupboss.com/reference/users-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The user ID. |
