# Get Appointment with Follow Up Boss

Retrieves an appointment from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `appointments/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get Appointment](https://docs.followupboss.com/reference/appointments-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The appointment ID. |
