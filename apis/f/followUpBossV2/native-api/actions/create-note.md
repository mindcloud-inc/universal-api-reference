# Create Note with Follow Up Boss

Creates a new note in Follow Up Boss.

## Endpoint

- **Method:** `POST`
- **Path:** `notes`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Create Note](https://docs.followupboss.com/reference/notes-post)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `personId` | body | `number` | no |
| `body` | body | `string` | no |
