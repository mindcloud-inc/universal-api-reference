# List Unclaimed People with Follow Up Boss

Retrieves unclaimed people from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `people/unclaimed`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [List Unclaimed People](https://docs.followupboss.com/reference/peopleunclaimed)
