# Get Task with Follow Up Boss

Retrieves a task from Follow Up Boss.

## Endpoint

- **Method:** `GET`
- **Path:** `tasks/:id`
- **Base URL:** `https://api.followupboss.com/v1/`
- **Official documentation:** [Get Task](https://docs.followupboss.com/reference/tasks-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The task ID. |
