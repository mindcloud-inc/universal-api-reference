# Get EVM Client Version with Flow Blockchain

Retrieves the EVM client version from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Client Version](https://developers.flow.com/build/evm/networks)
