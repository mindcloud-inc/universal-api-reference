# Get EVM Network ID with Flow Blockchain

Retrieves the EVM network ID from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Network ID](https://developers.flow.com/build/evm/networks)
