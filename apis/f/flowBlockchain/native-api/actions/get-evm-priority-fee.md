# Get EVM Priority Fee with Flow Blockchain

Retrieves the EVM priority fee from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Priority Fee](https://developers.flow.com/build/evm/networks)
