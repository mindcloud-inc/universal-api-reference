# Get Execution Result with Flow Blockchain

Retrieves an execution result from Flow Blockchain.

## Endpoint

- **Method:** `GET`
- **Path:** `/execution_results/{id}`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get Execution Result](https://developers.flow.com/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Execution result ID to fetch. |
