# Get EVM Sync Status with Flow Blockchain

Retrieves EVM sync status from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Sync Status](https://developers.flow.com/build/evm/networks)
