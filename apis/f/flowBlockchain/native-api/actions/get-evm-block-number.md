# Get EVM Block Number with Flow Blockchain

Retrieves the latest EVM block number from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Block Number](https://developers.flow.com/build/evm/networks)
