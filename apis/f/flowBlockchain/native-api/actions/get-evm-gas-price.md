# Get EVM Gas Price with Flow Blockchain

Retrieves the EVM gas price from Flow Blockchain.

## Endpoint

- **Method:** `POST`
- **Path:** `https://mainnet.evm.nodes.onflow.org`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get EVM Gas Price](https://developers.flow.com/build/evm/networks)
