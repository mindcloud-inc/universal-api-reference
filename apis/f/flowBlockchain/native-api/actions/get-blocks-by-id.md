# Get Blocks by ID with Flow Blockchain

Retrieves blocks from Flow Blockchain by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/blocks/{id}`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get Blocks by ID](https://developers.flow.com/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Block ID to fetch. |
