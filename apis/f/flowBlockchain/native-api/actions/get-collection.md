# Get Collection with Flow Blockchain

Retrieves a collection from Flow Blockchain.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/{id}`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get Collection](https://developers.flow.com/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Collection ID to fetch. |
