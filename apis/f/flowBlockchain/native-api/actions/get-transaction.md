# Get Transaction with Flow Blockchain

Retrieves a transaction from Flow Blockchain.

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/{id}`
- **Base URL:** `https://rest-mainnet.onflow.org/v1`
- **API:** rest
- **Official documentation:** [Get Transaction](https://developers.flow.com/http-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Transaction ID to fetch. |
