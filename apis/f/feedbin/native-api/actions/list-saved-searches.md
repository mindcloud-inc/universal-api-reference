# List Saved Searches with Feedbin

Retrieves a list of saved searches from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `saved_searches.json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [List Saved Searches](https://github.com/feedbin/feedbin-api/blob/master/content/saved-searches.md#get-saved-searches)
