# Delete Tagging with Feedbin

Deletes an existing tagging from Feedbin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `taggings/[:id].json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [Delete Tagging](https://github.com/feedbin/feedbin-api/blob/master/content/taggings.md#delete-tagging)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedbin tagging ID. |
