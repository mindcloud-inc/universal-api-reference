# Delete Subscription with Feedbin

Deletes an existing subscription from Feedbin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `subscriptions/[:id].json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [Delete Subscription](https://github.com/feedbin/feedbin-api/blob/master/content/subscriptions.md#delete-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedbin subscription ID. |
