# List Feed Icons with Feedbin

Retrieves feed icons for subscriptions from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `icons.json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [List Feed Icons](https://github.com/feedbin/feedbin-api/blob/master/content/icons.md#get-v2iconsjson)
