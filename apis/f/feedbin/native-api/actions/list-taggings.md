# List Taggings with Feedbin

Retrieves a list of taggings from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `taggings.json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [List Taggings](https://github.com/feedbin/feedbin-api/blob/master/content/taggings.md#get-taggings)
