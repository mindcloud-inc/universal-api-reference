# List Unread Entry IDs with Feedbin

Retrieves unread entry IDs from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `unread_entries.json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [List Unread Entry IDs](https://github.com/feedbin/feedbin-api/blob/master/content/unread-entries.md#get-unread-entries)
