# Get Tagging with Feedbin

Retrieves a single tagging from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `taggings/[:id].json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [Get Tagging](https://github.com/feedbin/feedbin-api/blob/master/content/taggings.md#get-tagging)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedbin tagging ID. |
