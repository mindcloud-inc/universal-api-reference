# Get Subscription with Feedbin

Retrieves a single subscription from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `subscriptions/[:id].json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [Get Subscription](https://github.com/feedbin/feedbin-api/blob/master/content/subscriptions.md#get-subscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedbin subscription ID. |
