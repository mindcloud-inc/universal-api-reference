# List Starred Entry IDs with Feedbin

Retrieves starred entry IDs from Feedbin.

## Endpoint

- **Method:** `GET`
- **Path:** `starred_entries.json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [List Starred Entry IDs](https://github.com/feedbin/feedbin-api/blob/master/content/starred-entries.md#get-starred-entries)
