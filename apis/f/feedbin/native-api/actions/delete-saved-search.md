# Delete Saved Search with Feedbin

Deletes an existing saved search from Feedbin.

## Endpoint

- **Method:** `DELETE`
- **Path:** `saved_searches/[:id].json`
- **Base URL:** `https://api.feedbin.com/v2`
- **Official documentation:** [Delete Saved Search](https://github.com/feedbin/feedbin-api/blob/master/content/saved-searches.md#delete-saved-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Feedbin saved search ID. |
