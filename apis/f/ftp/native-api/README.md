### Credentials

- **Host:** `host` · required
- **Port:** `port` · optional
- **Username:** `username` · optional
- **Password:** `password` · optional
- **Passive:** `passive` · optional
- **Secure:** `secure` · optional
- **Reject Unauthorized:** `rejectUnauthorized` · optional
- **Use SFTP:** `useSftp` · optional
- **Private Key:** `privateKey` · optional · SSH private key to be used with SFTP connections
