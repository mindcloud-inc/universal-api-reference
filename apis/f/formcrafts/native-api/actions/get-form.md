# Get Form with Formcrafts

Retrieves a specific form from Formcrafts.

## Endpoint

- **Method:** `GET`
- **Path:** `/forms/:id`
- **Base URL:** `https://api.formcrafts.com/v2`
- **Official documentation:** [Get Form](https://formcrafts.com/help/developers/api-docs-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Formcrafts form ID. |
