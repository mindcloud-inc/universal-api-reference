# Get File Content with Formcrafts

Retrieves the content of an uploaded file from Formcrafts.

## Endpoint

- **Method:** `GET`
- **Path:** `/files/:id/content`
- **Base URL:** `https://api.formcrafts.com/v2`
- **Official documentation:** [Get File Content](https://formcrafts.com/help/developers/api-docs-v2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The Formcrafts file ID. |
