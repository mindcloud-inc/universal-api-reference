# Get MFA Configuration with Frontegg

Retrieves MFA configuration for your Frontegg environment.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/resources/configurations/v1/mfa`
- **Base URL:** `https://api.frontegg.com`
- **Official documentation:** [Get MFA Configuration](https://developers.frontegg.com/ciam/api/identity/mfa-configuration)
