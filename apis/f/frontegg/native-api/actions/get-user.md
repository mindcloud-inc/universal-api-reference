# Get User with Frontegg

Retrieves a user from Frontegg by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/resources/users/v1/:id`
- **Base URL:** `https://api.frontegg.com`
- **Official documentation:** [Get User](https://developers.frontegg.com/ciam/api/identity/users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The user ID to retrieve. |
