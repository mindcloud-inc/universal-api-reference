# Get Domain Restrictions with Frontegg

Retrieves domain restrictions for a Frontegg account.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/resources/configurations/restrictions/v1/email-domain`
- **Base URL:** `https://api.frontegg.com`
- **Official documentation:** [Get Domain Restrictions](https://developers.frontegg.com/ciam/api/identity/domain-restrictions)
