# Get Captcha Policy with Frontegg

Retrieves the CAPTCHA policy from Frontegg.

## Endpoint

- **Method:** `GET`
- **Path:** `/identity/resources/configurations/v1/captcha-policy`
- **Base URL:** `https://api.frontegg.com`
- **Official documentation:** [Get Captcha Policy](https://developers.frontegg.com/ciam/api/identity/core-settings)
