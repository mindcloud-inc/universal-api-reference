# Find Phone Number with FindyMail

Finds a phone number in FindyMail.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/search/phone`
- **Base URL:** `https://app.findymail.com`
- **Official documentation:** [Find Phone Number](https://www.findymail.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `linkedin_url` | body | `string` | yes | LinkedIn profile URL for the person whose direct phone number should be found. |
