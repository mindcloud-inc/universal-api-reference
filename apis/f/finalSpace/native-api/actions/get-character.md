# Get Character with Final Space

## Endpoint

- **Method:** `GET`
- **Path:** `/character/:id`
- **Base URL:** `https://finalspaceapi.com/api/v0`
- **Official documentation:** [Get Character](https://github.com/lelouchB/final-space-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Character ID. |
