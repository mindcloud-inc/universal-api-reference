# Get Episode with Final Space

## Endpoint

- **Method:** `GET`
- **Path:** `/episode/:id`
- **Base URL:** `https://finalspaceapi.com/api/v0`
- **Official documentation:** [Get Episode](https://github.com/lelouchB/final-space-api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Episode ID. |
