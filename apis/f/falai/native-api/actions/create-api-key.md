# Create API Key with fal.ai

Creates an API key in fal.ai.

## Endpoint

- **Method:** `POST`
- **Path:** `/keys`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Create API Key](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `alias` | body | `string` | yes | Human-readable API key alias. |
