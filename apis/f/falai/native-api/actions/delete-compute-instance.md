# Delete Compute Instance with fal.ai

Deletes a compute instance from fal.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/compute/instances/:id`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Delete Compute Instance](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Compute instance identifier. |
