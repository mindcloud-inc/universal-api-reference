# Delete API Key with fal.ai

Deletes an API key from fal.ai.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/keys/:keyId`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Delete API Key](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `keyId` | path | `string` | yes | API key identifier to delete. |
