# Get Model Access Controls with fal.ai

Retrieves a model access controls report from fal.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/model-access-controls`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Get Model Access Controls](https://fal.ai/docs/api-reference/platform-apis)
