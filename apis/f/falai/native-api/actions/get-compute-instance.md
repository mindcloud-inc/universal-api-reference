# Get Compute Instance with fal.ai

Retrieves compute instance details from fal.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/compute/instances/:id`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Get Compute Instance](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Compute instance identifier. |
