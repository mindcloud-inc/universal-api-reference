# Get FOCUS Report with fal.ai

Retrieves a FOCUS billing report from fal.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/account/focus`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Get FOCUS Report](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source` | query | `string` | yes | FOCUS report source value required by fal.ai. |
