# Get Serverless Metrics with fal.ai

Retrieves Prometheus-compatible serverless metrics from fal.ai.

## Endpoint

- **Method:** `GET`
- **Path:** `/serverless/metrics`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Get Serverless Metrics](https://fal.ai/docs/api-reference/platform-apis)
