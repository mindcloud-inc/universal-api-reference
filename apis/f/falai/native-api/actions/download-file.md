# Download File with fal.ai

Retrieves a file from fal.ai storage.

## Endpoint

- **Method:** `GET`
- **Path:** `/serverless/files/file/:file`
- **Base URL:** `https://api.fal.ai/v1`
- **Official documentation:** [Download File](https://fal.ai/docs/api-reference/platform-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file` | path | `string` | yes | Serverless file path to download. |
