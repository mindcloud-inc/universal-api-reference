# My User Permission's with Five9

Retrieves your user permissions from Five9.

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.prod.us.five9.net/acl/v1/domains/130744/my-ui-permissions`
- **Base URL:** `https://api.prod.us.five9.net/acl/v1/`
- **Official documentation:** [My User Permission's](https://documentation.five9.com/bundle/admin-console/page/admin-console/domain/_ch-user-settings.htm)
