# Campaign Settings with Five9

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.prod.us.five9.net/acl/v1/domains/:domainID/permissions/campaignmgmt.ani-settings.view`
- **Base URL:** `https://api.prod.us.five9.net/acl/v1/`
- **Official documentation:** [Campaign Settings](https://documentation.five9.com/bundle/admin-console/page/admin-console/landing-admin-console.htm)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domainID` | path | `string` | yes |
