# Get Current User Profile with FreshBooks

Retrieves the current user profile from FreshBooks.

## Endpoint

- **Method:** `GET`
- **Path:** `/auth/api/v1/users/me`
- **Base URL:** `https://api.freshbooks.com`
- **Official documentation:** [Get Current User Profile](https://www.freshbooks.com/api/identity_model)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Api-Version` | `alpha` |
