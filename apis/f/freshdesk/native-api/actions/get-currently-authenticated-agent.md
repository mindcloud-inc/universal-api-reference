# Get Currently Authenticated Agent with Freshdesk

Retrieves the currently authenticated agent from Freshdesk.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/me`
- **Base URL:** `https://{subdomain}.freshdesk.com/api/v2`
- **Official documentation:** [Get Currently Authenticated Agent](https://developers.freshdesk.com/api/#me)
