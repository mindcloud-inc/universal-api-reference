# Delete Company with Freshdesk

Deletes an existing company from Freshdesk.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/companies/:id`
- **Base URL:** `https://{subdomain}.freshdesk.com/api/v2`
- **Official documentation:** [Delete Company](https://developers.freshdesk.com/api/#delete_company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<number>` | yes | Freshdesk company ID. |
