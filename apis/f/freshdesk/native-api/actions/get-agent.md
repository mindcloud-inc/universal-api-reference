# Get Agent with Freshdesk

Retrieves an agent from Freshdesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:id`
- **Base URL:** `https://{subdomain}.freshdesk.com/api/v2`
- **Official documentation:** [Get Agent](https://developers.freshdesk.com/api/#view_agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<number>` | yes | Freshdesk agent ID. |
