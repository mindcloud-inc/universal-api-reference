# Get Ticket with Freshdesk

Retrieves a ticket from Freshdesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/tickets/:id`
- **Base URL:** `https://{subdomain}.freshdesk.com/api/v2`
- **Official documentation:** [Get Ticket](https://developers.freshdesk.com/api/#view_a_ticket)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<number>` | yes | Freshdesk ticket ID. |
