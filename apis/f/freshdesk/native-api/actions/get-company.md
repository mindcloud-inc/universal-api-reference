# Get Company with Freshdesk

Retrieves a company from Freshdesk by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/companies/:id`
- **Base URL:** `https://{subdomain}.freshdesk.com/api/v2`
- **Official documentation:** [Get Company](https://developers.freshdesk.com/api/#view_company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<number>` | yes | Freshdesk company ID. |
