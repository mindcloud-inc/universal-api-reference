# Get Annotate Detail with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotation-queues/:queueId/items/:itemId/annotate-detail/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Annotate Detail](https://docs.futureagi.com/docs/api/annotations/items/get-annotate-detail)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `string` | no | Item ID. |
| `queueId` | path | `string` | no | Queue ID. |
