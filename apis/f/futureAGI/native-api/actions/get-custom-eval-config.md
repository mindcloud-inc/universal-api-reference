# Get Custom Eval Config with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/tracer/custom-eval-config/:id/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Custom Eval Config](https://docs.futureagi.com/docs/api/custom-eval-configs/get-custom-eval-config)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Custom eval config ID. |
