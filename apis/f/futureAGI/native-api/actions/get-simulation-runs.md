# Get Simulation Runs with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/sdk/api/v1/simulation/runs/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Simulation Runs](https://docs.futureagi.com/docs/api/simulation-analytics/runs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `execution_id` | query | `string` | no | Execution ID. |
| `run_test_name` | query | `string` | no | Run test name. |
