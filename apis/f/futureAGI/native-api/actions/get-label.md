# Get Label with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotations-labels/:id/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Label](https://docs.futureagi.com/docs/api/annotations/labels/get-label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Label ID. |
