# Export Queue with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotation-queues/:id/export/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Export Queue](https://docs.futureagi.com/docs/api/annotations/queues/export)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Queue ID. |
