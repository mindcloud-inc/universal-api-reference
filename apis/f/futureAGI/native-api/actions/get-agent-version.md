# Get Agent Version with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/simulate/agent-definitions/:agentId/versions/:versionId/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Agent Version](https://docs.futureagi.com/docs/api/agent-versions/getagentversion)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | no | Agent definition ID. |
| `versionId` | path | `string` | no | Agent version ID. |
