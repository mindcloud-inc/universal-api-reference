# Get Queue Analytics with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotation-queues/:id/analytics/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Queue Analytics](https://docs.futureagi.com/docs/api/annotations/queues/get-analytics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Queue ID. |
