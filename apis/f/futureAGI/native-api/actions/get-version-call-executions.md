# Get Version Call Executions with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/simulate/agent-definitions/:agentId/versions/:versionId/call-executions/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Version Call Executions](https://docs.futureagi.com/docs/api/agent-versions/getversioncallexecutions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | no | Agent definition ID. |
| `versionId` | path | `string` | no | Agent version ID. |
