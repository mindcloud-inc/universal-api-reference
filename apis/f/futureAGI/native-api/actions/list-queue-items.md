# List Queue Items with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotation-queues/:queueId/items/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [List Queue Items](https://docs.futureagi.com/docs/api/annotations/items/list-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queueId` | path | `string` | no | Queue ID. |
