# Get Agent Definition with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/simulate/agent-definitions/:agentId/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Agent Definition](https://docs.futureagi.com/docs/api/agent-definitions/getagentdefinition)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | no | Agent definition ID. |
