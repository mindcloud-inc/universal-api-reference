# Get Next Queue Item with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/model-hub/annotation-queues/:queueId/items/next-item/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Next Queue Item](https://docs.futureagi.com/docs/api/annotations/items/get-next-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `queueId` | path | `string` | no | Queue ID. |
