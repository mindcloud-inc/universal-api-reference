# Get Scenario Details with FutureAGI

## Endpoint

- **Method:** `GET`
- **Path:** `/simulate/scenarios/:scenarioId/`
- **Base URL:** `https://api.futureagi.com`
- **Official documentation:** [Get Scenario Details](https://docs.futureagi.com/docs/api/scenarios/getscenario)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `scenarioId` | path | `string` | no | Scenario ID. |
