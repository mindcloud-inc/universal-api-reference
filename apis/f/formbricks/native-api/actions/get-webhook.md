# Get Webhook with Formbricks

Retrieves a webhook from Formbricks.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/webhooks/:id`
- **Base URL:** `https://app.formbricks.com/api/v2`
- **Official documentation:** [Get Webhook](https://formbricks.com/docs/api-v2-reference/management-api--webhooks/get-a-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the webhook. |
