# Get Response with Formbricks

Retrieves a response from Formbricks.

## Endpoint

- **Method:** `GET`
- **Path:** `/management/responses/:id`
- **Base URL:** `https://app.formbricks.com/api/v2`
- **Official documentation:** [Get Response](https://formbricks.com/docs/api-v2-reference/management-api--responses/get-a-response)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The ID of the response. |
