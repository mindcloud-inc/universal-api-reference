# Get IP Risk with FraudSentinel

## Endpoint

- **Method:** `POST`
- **Path:** `/api/sentinel.json`
- **Base URL:** `https://api.clickfreeze.io`
- **Official documentation:** [Get IP Risk](https://www.clickfreeze.io/restapi)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ip` | body | `string` | yes | IP address to evaluate for fraud risk. |
