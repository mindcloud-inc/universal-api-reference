# Get Widget with Favro

Retrieves a widget from Favro by widget ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/widgets/:widgetCommonId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get Widget](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widgetCommonId` | path | `string` | yes | The Favro widget common ID to retrieve. |
