# Get All Collections with Favro

Retrieves collections from Favro.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get All Collections](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `archived` | query | `boolean` | no | Return archived collections when true. |
