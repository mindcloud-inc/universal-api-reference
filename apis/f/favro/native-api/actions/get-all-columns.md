# Get All Columns with Favro

Retrieves columns from Favro.

## Endpoint

- **Method:** `GET`
- **Path:** `/columns`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get All Columns](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `widgetCommonId` | query | `string` | yes | The widget common ID whose columns should be listed. |
