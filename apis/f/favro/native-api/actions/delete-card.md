# Delete Card with Favro

Deletes an existing card from Favro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Delete Card](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | The card ID to delete. |
