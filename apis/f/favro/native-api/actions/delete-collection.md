# Delete Collection with Favro

Deletes an existing collection from Favro.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collections/:collectionId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Delete Collection](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | The Favro collection ID to delete. |
