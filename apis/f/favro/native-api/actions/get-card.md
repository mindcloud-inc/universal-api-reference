# Get Card with Favro

Retrieves a card from Favro by card ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/cards/:cardId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get Card](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `cardId` | path | `string` | yes | The Favro card ID to retrieve. |
