# Create Collection with Favro

Creates a new collection in Favro.

## Endpoint

- **Method:** `POST`
- **Path:** `/collections`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Create Collection](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The name of the collection to create. Maximum length: 48. |
