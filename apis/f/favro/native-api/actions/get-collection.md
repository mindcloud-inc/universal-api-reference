# Get Collection with Favro

Retrieves a collection from Favro by collection ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/:collectionId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get Collection](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | yes | The Favro collection ID to retrieve. |
