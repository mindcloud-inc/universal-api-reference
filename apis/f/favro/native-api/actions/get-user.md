# Get User with Favro

Retrieves a user from Favro by user ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get User](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The Favro user ID to retrieve. |
