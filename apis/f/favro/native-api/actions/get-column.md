# Get Column with Favro

Retrieves a column from Favro by column ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/columns/:columnId`
- **Base URL:** `https://favro.com/api/v1`
- **Official documentation:** [Get Column](https://favro.com/developer/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `columnId` | path | `string` | yes | The Favro column ID to retrieve. |
