# Get Resource with Fabric

Retrieves a resource from Fabric.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resources/{resourceId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Get Resource](https://developers.fabric.so/api-reference/tag/resources/get/v2/resources/resourceId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | The Fabric resource ID. |
