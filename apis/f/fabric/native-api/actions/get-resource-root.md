# Get Resource Root with Fabric

Retrieves a resource root from Fabric.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/resource-roots/{resourceRootId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Get Resource Root](https://developers.fabric.so/api-reference/tag/resource-roots/get/v2/resource-roots/resourceRootId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceRootId` | path | `string` | yes | The Fabric resource root ID. |
