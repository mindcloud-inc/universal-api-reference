# Get Notepad Content with Fabric

Retrieves notepad content from Fabric.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/notepads/{resourceId}/content`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Get Notepad Content](https://developers.fabric.so/api-reference/tag/notepads/get/v2/notepads/resourceId/content)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | The notepad resource ID. |
