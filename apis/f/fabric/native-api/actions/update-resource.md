# Update Resource with Fabric

Updates an existing resource in Fabric.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/resources/{resourceId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Update Resource](https://developers.fabric.so/api-reference/tag/resources/patch/v2/resources/resourceId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `resourceId` | path | `string` | yes | The Fabric resource ID. |
