# Delete Space with Fabric

Deletes a space from Fabric.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/spaces/{spaceId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Delete Space](https://developers.fabric.so/api-reference/tag/spaces/delete/v2/spaces/spaceId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `spaceId` | path | `string` | yes | ID of the space to delete. |
