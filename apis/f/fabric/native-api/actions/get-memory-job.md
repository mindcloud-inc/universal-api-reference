# Get Memory Job with Fabric

Retrieves a memory job from Fabric.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/memories/jobs/{jobId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Get Memory Job](https://developers.fabric.so/api-reference/tag/memories/get/v2/memories/jobs/jobId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The Fabric memory job ID. |
