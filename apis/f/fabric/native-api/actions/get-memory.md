# Get Memory with Fabric

Retrieves a memory from Fabric.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/memories/{memoryId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Get Memory](https://developers.fabric.so/api-reference/tag/memories/get/v2/memories/memoryId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memoryId` | path | `string` | yes | The Fabric memory ID. |
