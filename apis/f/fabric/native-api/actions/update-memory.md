# Update Memory with Fabric

Updates an existing memory in Fabric.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v2/memories/{memoryId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Update Memory](https://developers.fabric.so/api-reference/tag/memories/patch/v2/memories/memoryId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memoryId` | path | `string` | yes | The Fabric memory ID. |
