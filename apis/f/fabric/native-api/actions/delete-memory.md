# Delete Memory with Fabric

Deletes a memory from Fabric.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/memories/{memoryId}`
- **Base URL:** `https://api.fabric.so`
- **Official documentation:** [Delete Memory](https://developers.fabric.so/api-reference/tag/memories/delete/v2/memories/memoryId)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `memoryId` | path | `string` | yes | The Fabric memory ID. |
