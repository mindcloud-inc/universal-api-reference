# Update Number with Fluents

Updates an existing phone number in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/numbers/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Number](https://docs.fluents.ai/api-reference/numbers/update-number)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents phone number ID. |
