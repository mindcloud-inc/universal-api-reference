# Get Action with Fluents

Retrieves an action from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/actions`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Action](https://docs.fluents.ai/api-reference/actions/get-action)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents action ID. |
