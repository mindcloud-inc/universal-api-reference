# Delete Webhook with Fluents

Deletes an existing webhook from Fluents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/delete`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Delete Webhook](https://docs.fluents.ai/api-reference/webhooks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents webhook ID. |
