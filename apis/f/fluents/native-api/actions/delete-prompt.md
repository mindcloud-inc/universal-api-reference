# Delete Prompt with Fluents

Deletes an existing prompt from Fluents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/prompts/delete`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Delete Prompt](https://docs.fluents.ai/api-reference/prompts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents prompt ID. |
