# Get Webhook with Fluents

Retrieves a webhook from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Webhook](https://docs.fluents.ai/api-reference/webhooks/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents webhook ID. |
