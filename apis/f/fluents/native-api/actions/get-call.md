# Get Call with Fluents

Retrieves a call from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/calls`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Call](https://docs.fluents.ai/api-reference/calls/get-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents call ID. |
