# Update Voice with Fluents

Updates an existing voice in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/voices/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Voice](https://docs.fluents.ai/api-reference/voices/update-voice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents voice ID. |
