# Detach Number with Fluents

Detaches a phone number in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/numbers/detach`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Detach Number](https://docs.fluents.ai/api-reference/numbers/detach-number)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents phone number ID to detach. |
