# Get Agent with Fluents

Retrieves an agent from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/agents`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Agent](https://docs.fluents.ai/api-reference/agents/get-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents agent ID. |
