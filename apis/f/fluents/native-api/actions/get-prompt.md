# Get Prompt with Fluents

Retrieves a prompt from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/prompts`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Prompt](https://docs.fluents.ai/api-reference/prompts/get-prompt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents prompt ID. |
