# Delete Action with Fluents

Deletes an existing action from Fluents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/actions/delete`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Delete Action](https://docs.fluents.ai/api-reference/actions)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents action ID. |
