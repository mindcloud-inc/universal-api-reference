# Update Account Connection with Fluents

Updates an existing account connection in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/account_connections/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Account Connection](https://docs.fluents.ai/api-reference/account_connections/update-account-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents account connection ID. |
