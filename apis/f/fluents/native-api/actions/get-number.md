# Get Number with Fluents

Retrieves a phone number from Fluents.

## Endpoint

- **Method:** `GET`
- **Path:** `/numbers`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Number](https://docs.fluents.ai/api-reference/numbers/get-number)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phone_number` | query | `string` | yes | E.164 phone number to retrieve. |
