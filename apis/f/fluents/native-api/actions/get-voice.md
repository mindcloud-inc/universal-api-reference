# Get Voice with Fluents

Retrieves a voice from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/voices`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Voice](https://docs.fluents.ai/api-reference/voices/get-voice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents voice ID. |
