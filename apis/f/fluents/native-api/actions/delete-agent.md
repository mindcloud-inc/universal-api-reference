# Delete Agent with Fluents

Deletes an existing agent from Fluents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agents/delete`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Delete Agent](https://docs.fluents.ai/api-reference/agents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents agent ID. |
