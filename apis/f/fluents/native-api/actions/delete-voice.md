# Delete Voice with Fluents

Deletes an existing voice from Fluents.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/voices/delete`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Delete Voice](https://docs.fluents.ai/api-reference/voices)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents voice ID. |
