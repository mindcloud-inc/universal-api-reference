# Update Prompt with Fluents

Updates an existing prompt in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/prompts/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Prompt](https://docs.fluents.ai/api-reference/prompts/update-prompt)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents prompt ID. |
