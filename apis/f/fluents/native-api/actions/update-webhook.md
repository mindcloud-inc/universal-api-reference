# Update Webhook with Fluents

Updates an existing webhook in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/webhooks/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Webhook](https://docs.fluents.ai/api-reference/webhooks/update-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents webhook ID. |
