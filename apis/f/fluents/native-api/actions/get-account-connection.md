# Get Account Connection with Fluents

Retrieves an account connection from Fluents.

## Endpoint

- **Method:** `GET`
- **Path:** `/account_connections`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Get Account Connection](https://docs.fluents.ai/api-reference/account_connections/get-account-connection)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents account connection ID. |
