# Update Agent with Fluents

Updates an existing agent in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Agent](https://docs.fluents.ai/api-reference/agents/update-agent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents agent ID. |
