# End Call with Fluents

Ends an active call in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/calls/end`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [End Call](https://docs.fluents.ai/api-reference/calls/end-call)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents call ID to end. |
