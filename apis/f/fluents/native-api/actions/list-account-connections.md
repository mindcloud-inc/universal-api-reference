# List Account Connections with Fluents

Retrieves account connections from your Fluents account.

## Endpoint

- **Method:** `GET`
- **Path:** `/account_connections/list`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [List Account Connections](https://docs.fluents.ai/api-reference/account_connections/list-account-connections)
