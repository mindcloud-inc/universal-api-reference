# Update Action with Fluents

Updates an existing action in Fluents.

## Endpoint

- **Method:** `POST`
- **Path:** `/actions/update`
- **Base URL:** `https://api.fluents.ai/v1`
- **Official documentation:** [Update Action](https://docs.fluents.ai/api-reference/actions/update-action)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | query | `string` | yes | Fluents action ID. |
