# List Unmatched Settlements with Fiserv

Retrieves unmatched settlements for a partner from Fiserv.

## Endpoint

- **Method:** `GET`
- **Path:** `/unmatched_settlements`
- **Base URL:** `https://bankinghub-cert.fiservapis.com`
- **Official documentation:** [List Unmatched Settlements](https://isvportal.fiserv.com/docs/payments-api#operation/getPartnerUnmatched)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/json` |
