# Get Banking Hub Access Token with Fiserv

Retrieves a Banking Hub access token from Fiserv.

## Endpoint

- **Method:** `POST`
- **Path:** `https://bankinghub-cert.fiservapis.com/fts-apim/oauth2/v2`
- **Base URL:** `https://bankinghub-cert.fiservapis.com`
- **Official documentation:** [Get Banking Hub Access Token](https://developer.fiserv.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
| `Content-Type` | `application/x-www-form-urlencoded` |
