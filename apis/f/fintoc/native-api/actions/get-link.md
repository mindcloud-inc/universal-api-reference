# Get Link with Fintoc

Retrieves a link from Fintoc.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/links/:link_token`
- **Base URL:** `https://api.fintoc.com`
- **Official documentation:** [Get Link](https://docs.fintoc.com/reference/links-retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link_token` | path | `string` | yes | Fintoc link token (for example `lin_...`). |
