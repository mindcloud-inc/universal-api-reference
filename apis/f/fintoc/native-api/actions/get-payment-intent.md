# Get Payment Intent with Fintoc

Retrieves a payment intent from Fintoc.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payment_intents/:id`
- **Base URL:** `https://api.fintoc.com`
- **Official documentation:** [Get Payment Intent](https://docs.fintoc.com/reference/get-payment-intent)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Payment intent identifier. |
