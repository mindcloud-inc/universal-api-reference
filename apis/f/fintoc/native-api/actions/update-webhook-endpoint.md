# Update Webhook Endpoint with Fintoc

Updates a webhook endpoint in Fintoc.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/webhook_endpoints/:id`
- **Base URL:** `https://api.fintoc.com`
- **Official documentation:** [Update Webhook Endpoint](https://docs.fintoc.com/reference/webhook-endpoints-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint identifier. |
