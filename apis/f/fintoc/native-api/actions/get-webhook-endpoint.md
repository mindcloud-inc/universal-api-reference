# Get Webhook Endpoint with Fintoc

Retrieves a webhook endpoint from Fintoc.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/webhook_endpoints/:id`
- **Base URL:** `https://api.fintoc.com`
- **Official documentation:** [Get Webhook Endpoint](https://docs.fintoc.com/reference/get-webhook-endpoints)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Webhook endpoint identifier. |
