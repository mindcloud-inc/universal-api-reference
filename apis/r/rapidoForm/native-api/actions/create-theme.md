# Create Theme with RapidoForm

Creates a new theme in RapidoForm.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/theme`
- **Base URL:** `https://www.rapidoform.com/be`
- **Official documentation:** [Create Theme](https://www.rapidoform.com/developers/docs/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `backgroundColor` | body | `string` | no |
| `bottomLineColor` | body | `string` | no |
| `btnBackgroundColor` | body | `string` | no |
| `btnTextColor` | body | `string` | no |
| `fontFamily` | body | `string` | no |
| `questionColor` | body | `string` | no |
| `questionTypeColor` | body | `string` | no |
| `textAlignment` | body | `string` | no |
| `themeName` | body | `string` | no |
