# Create Form with RapidoForm

Creates a new form in RapidoForm.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/survey/create`
- **Base URL:** `https://www.rapidoform.com/be`
- **Official documentation:** [Create Form](https://www.rapidoform.com/developers/docs/create)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `surveyName` | body | `string` | yes |
