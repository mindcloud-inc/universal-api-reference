# List List Rewards with ReferralHero

Retrieves rewards for a list in ReferralHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:uuid/bonuses`
- **Base URL:** `https://app.referralhero.com/api/v2`
- **Official documentation:** [List List Rewards](https://support.referralhero.com/integrate/rest-api/endpoint-reference-v2#get-list-rewards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | ReferralHero list UUID. |
