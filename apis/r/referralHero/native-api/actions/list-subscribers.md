# List Subscribers with ReferralHero

Retrieves subscribers from a list in ReferralHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists/:uuid/subscribers`
- **Base URL:** `https://app.referralhero.com/api/v2`
- **Official documentation:** [List Subscribers](https://support.referralhero.com/integrate/rest-api/endpoint-reference-v2#retrieve-all-coupon-groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uuid` | path | `string` | yes | ReferralHero list UUID. |
