# List Lists with ReferralHero

Retrieves lists from ReferralHero.

## Endpoint

- **Method:** `GET`
- **Path:** `/lists`
- **Base URL:** `https://app.referralhero.com/api/v2`
- **Official documentation:** [List Lists](https://support.referralhero.com/integrate/rest-api/endpoint-reference-v2#retrieve-all-lists)
