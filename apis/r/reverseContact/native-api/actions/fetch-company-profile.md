# Fetch Company Profile with Reverse Contact

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/fetch/companies`
- **Base URL:** `https://api.reversecontact.com`
- **Official documentation:** [Fetch Company Profile](https://app.reversecontact.com/docs/endpoints/fetch-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public Social company URL to fetch. |
