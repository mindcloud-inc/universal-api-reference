# Check Company Profile Status with Reverse Contact

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/fetch/companies/check`
- **Base URL:** `https://api.reversecontact.com`
- **Official documentation:** [Check Company Profile Status](https://app.reversecontact.com/docs/endpoints/check-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public Social company URL to check. |
