# Check Person Profile Status with Reverse Contact

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/fetch/persons/check`
- **Base URL:** `https://api.reversecontact.com`
- **Official documentation:** [Check Person Profile Status](https://app.reversecontact.com/docs/endpoints/check-person)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | body | `string` | yes | Public Social profile URL to check. |
