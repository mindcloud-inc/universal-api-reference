# Get all layers and tables with RUIAN

Retrieves layers and tables from RUIAN API.

## Endpoint

- **Method:** `GET`
- **Path:** `/layers`
- **Base URL:** `https://ags.cuzk.gov.cz/arcgis/rest/services/RUIAN/MapServer`
- **Official documentation:** [Get all layers and tables](https://developers.arcgis.com/rest/services-reference/enterprise/all-layers-and-tables/)
