# Get service details with RUIAN

Retrieves service details from RUIAN API.

## Endpoint

- **Method:** `GET`
- **Path:** `/`
- **Base URL:** `https://ags.cuzk.gov.cz/arcgis/rest/services/RUIAN/MapServer`
- **Official documentation:** [Get service details](https://developers.arcgis.com/rest/services-reference/enterprise/get-started-with-the-services-directory/)
