# Get Invoice with Refrens

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses/:urlKey/invoices/:invoiceId`
- **Base URL:** `https://api.refrens.com`
- **Official documentation:** [Get Invoice](https://www.refrens.com/api/docs/invoices/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoiceId` | path | `string` | yes | Refrens invoice ID. |
