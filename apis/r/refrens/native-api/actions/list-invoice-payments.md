# List Invoice Payments with Refrens

## Endpoint

- **Method:** `GET`
- **Path:** `/businesses/:urlKey/invoices/:invoice/payments`
- **Base URL:** `https://api.refrens.com`
- **Official documentation:** [List Invoice Payments](https://www.refrens.com/api/docs/payment-updates/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice` | path | `string` | yes |
