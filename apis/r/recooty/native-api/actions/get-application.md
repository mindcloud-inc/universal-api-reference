# Get Application with Recooty

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/applications/{{applicationId}}`
- **Base URL:** `https://standaloneapi.recooty.app/api`
- **Official documentation:** [Get Application](https://api.recooty.com/)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `applicationId` | path | `string` | yes | The Recooty application ID. |
