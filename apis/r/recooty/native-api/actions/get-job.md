# Get Job with Recooty

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/jobs/{jobListingKey}/{{jobId}}`
- **Base URL:** `https://standaloneapi.recooty.app/api`
- **Official documentation:** [Get Job](https://api.recooty.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `jobId` | path | `string` | yes | The Recooty job ID. |
