# Unarchive Virtual Currency with RevenueCat

Unarchives a virtual currency in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/virtual_currencies/:virtualCurrencyCode/actions/unarchive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Unarchive Virtual Currency](https://www.revenuecat.com/docs/api-v2)
