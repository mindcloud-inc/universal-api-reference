# List Customer Invoices with RevenueCat

Retrieves a customer's invoices from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/invoices`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Customer Invoices](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
