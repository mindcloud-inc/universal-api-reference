# Get Virtual Currency with RevenueCat

Retrieves a virtual currency from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/virtual_currencies/:virtualCurrencyCode`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Virtual Currency](https://www.revenuecat.com/docs/api-v2)
