# Grant Customer Entitlement with RevenueCat

Grants an entitlement to a RevenueCat customer.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/actions/grant_entitlement`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Grant Customer Entitlement](https://www.revenuecat.com/docs/api-v2)
