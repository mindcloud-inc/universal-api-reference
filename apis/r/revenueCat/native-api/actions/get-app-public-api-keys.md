# Get App Public API Keys with RevenueCat

Retrieves app public API keys from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/apps/:appId/public_api_keys`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get App Public API Keys](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
