# Cancel Subscription with RevenueCat

Cancels an active Web Billing subscription in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId/actions/cancel`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Cancel Subscription](https://www.revenuecat.com/docs/api-v2)
