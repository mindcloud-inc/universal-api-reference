# Unarchive Product with RevenueCat

Unarchives a product in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/products/:productId/actions/unarchive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Unarchive Product](https://www.revenuecat.com/docs/api-v2)
