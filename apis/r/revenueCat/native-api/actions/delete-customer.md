# Delete Customer with RevenueCat

Deletes an existing customer from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/customers/:customerId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Customer](https://www.revenuecat.com/docs/api-v2)
