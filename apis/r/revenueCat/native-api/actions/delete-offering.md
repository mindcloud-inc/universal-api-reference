# Delete Offering with RevenueCat

Deletes an offering and packages from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/offerings/:offeringId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Offering](https://www.revenuecat.com/docs/api-v2)
