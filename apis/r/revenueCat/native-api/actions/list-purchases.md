# List Purchases with RevenueCat

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/purchases`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Purchases](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
