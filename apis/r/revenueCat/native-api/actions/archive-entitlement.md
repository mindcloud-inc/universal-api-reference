# Archive Entitlement with RevenueCat

Archives an entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements/:entitlementId/actions/archive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Archive Entitlement](https://www.revenuecat.com/docs/api-v2)
