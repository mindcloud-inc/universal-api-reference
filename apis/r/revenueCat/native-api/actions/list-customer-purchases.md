# List Customer Purchases with RevenueCat

Retrieves a customer's purchases from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/purchases`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Customer Purchases](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
