# Get Overview Metrics with RevenueCat

Retrieves overview metrics from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/metrics/overview`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Overview Metrics](https://www.revenuecat.com/docs/api-v2#tag/Charts-and-Metrics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | RevenueCat project ID. |
