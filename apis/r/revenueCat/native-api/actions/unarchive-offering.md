# Unarchive Offering with RevenueCat

Unarchives an offering in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/offerings/:offeringId/actions/unarchive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Unarchive Offering](https://www.revenuecat.com/docs/api-v2)
