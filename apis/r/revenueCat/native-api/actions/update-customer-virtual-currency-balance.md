# Update Customer Virtual Currency Balance with RevenueCat

Updates a virtual currency balance in RevenueCat without a transaction.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/virtual_currencies/update_balance`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Update Customer Virtual Currency Balance](https://www.revenuecat.com/docs/api-v2)
