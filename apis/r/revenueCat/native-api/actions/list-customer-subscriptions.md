# List Customer Subscriptions with RevenueCat

Retrieves a customer's subscriptions from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/subscriptions`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Customer Subscriptions](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
