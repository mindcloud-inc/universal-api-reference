# Archive Offering with RevenueCat

Archives an offering in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/offerings/:offeringId/actions/archive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Archive Offering](https://www.revenuecat.com/docs/api-v2)
