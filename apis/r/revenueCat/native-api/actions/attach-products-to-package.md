# Attach Products To Package with RevenueCat

Attaches products to a package in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/packages/:packageId/actions/attach_products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Attach Products To Package](https://www.revenuecat.com/docs/api-v2)
