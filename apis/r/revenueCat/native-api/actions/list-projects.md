# List Projects with RevenueCat

Retrieves projects from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Projects](https://www.revenuecat.com/docs/api-v2#tag/Project/operation/list-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
