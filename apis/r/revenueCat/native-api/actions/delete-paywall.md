# Delete Paywall with RevenueCat

Deletes an existing paywall from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/paywalls/:paywallId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Paywall](https://www.revenuecat.com/docs/api-v2)
