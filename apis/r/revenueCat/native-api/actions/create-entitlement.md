# Create Entitlement with RevenueCat

Creates a new entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Create Entitlement](https://www.revenuecat.com/docs/api-v2)
