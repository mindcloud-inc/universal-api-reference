# List Collaborators with RevenueCat

Retrieves collaborators from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/collaborators`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Collaborators](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
