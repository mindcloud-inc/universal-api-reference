# List Offerings with RevenueCat

Retrieves offerings from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/offerings`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Offerings](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
