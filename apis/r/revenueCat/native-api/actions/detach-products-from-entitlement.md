# Detach Products From Entitlement with RevenueCat

Detaches products from an entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements/:entitlementId/actions/detach_products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Detach Products From Entitlement](https://www.revenuecat.com/docs/api-v2)
