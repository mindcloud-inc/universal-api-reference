# List Entitlement Products with RevenueCat

Retrieves products attached to an entitlement in RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/entitlements/:entitlementId/products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Entitlement Products](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
