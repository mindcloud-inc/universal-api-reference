# Get Chart Options with RevenueCat

Retrieves chart options from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/charts/:chartName/options`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Chart Options](https://www.revenuecat.com/docs/api-v2)
