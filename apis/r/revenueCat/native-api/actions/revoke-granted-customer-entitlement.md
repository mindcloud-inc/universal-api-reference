# Revoke Granted Customer Entitlement with RevenueCat

Revokes a granted customer entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/actions/revoke_granted_entitlement`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Revoke Granted Customer Entitlement](https://www.revenuecat.com/docs/api-v2)
