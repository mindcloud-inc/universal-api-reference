# List Offering Packages with RevenueCat

Retrieves packages attached to an offering in RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/offerings/:offeringId/packages`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Offering Packages](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
