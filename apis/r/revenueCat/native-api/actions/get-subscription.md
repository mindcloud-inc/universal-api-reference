# Get Subscription with RevenueCat

Retrieves a subscription from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Subscription](https://www.revenuecat.com/docs/api-v2)
