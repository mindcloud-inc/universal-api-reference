# Update Virtual Currency with RevenueCat

Updates an existing virtual currency in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/virtual_currencies/:virtualCurrencyCode`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Update Virtual Currency](https://www.revenuecat.com/docs/api-v2)
