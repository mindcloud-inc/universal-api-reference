# Get Customer Active Entitlements with RevenueCat

Retrieves a customer's active entitlements from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/active_entitlements`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Customer Active Entitlements](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
