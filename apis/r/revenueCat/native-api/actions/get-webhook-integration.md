# Get Webhook Integration with RevenueCat

Retrieves a webhook integration from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/integrations/webhooks/:webhookIntegrationId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Webhook Integration](https://www.revenuecat.com/docs/api-v2)
