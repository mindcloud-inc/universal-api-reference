# List Webhook Integrations with RevenueCat

Retrieves webhook integrations from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/integrations/webhooks`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Webhook Integrations](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
