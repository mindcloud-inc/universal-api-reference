# Detach Products From Package with RevenueCat

Detaches products from a package in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/packages/:packageId/actions/detach_products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Detach Products From Package](https://www.revenuecat.com/docs/api-v2)
