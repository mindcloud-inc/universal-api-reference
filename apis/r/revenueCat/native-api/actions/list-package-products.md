# List Package Products with RevenueCat

Retrieves products attached to a package in RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/packages/:packageId/products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Package Products](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
