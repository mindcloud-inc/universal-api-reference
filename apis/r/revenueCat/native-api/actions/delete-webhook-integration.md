# Delete Webhook Integration with RevenueCat

Deletes an existing webhook integration from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/integrations/webhooks/:webhookIntegrationId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Webhook Integration](https://www.revenuecat.com/docs/api-v2)
