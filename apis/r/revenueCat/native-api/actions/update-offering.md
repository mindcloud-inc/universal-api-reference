# Update Offering with RevenueCat

Updates an existing offering in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/offerings/:offeringId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Update Offering](https://www.revenuecat.com/docs/api-v2)
