# List Entitlements with RevenueCat

Retrieves entitlements from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/entitlements`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Entitlements](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
