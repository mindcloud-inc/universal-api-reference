# List Apps with RevenueCat

Retrieves apps from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/apps`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Apps](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | RevenueCat project ID. |
