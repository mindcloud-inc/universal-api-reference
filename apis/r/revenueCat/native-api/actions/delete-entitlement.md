# Delete Entitlement with RevenueCat

Deletes an existing entitlement from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/entitlements/:entitlementId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Entitlement](https://www.revenuecat.com/docs/api-v2)
