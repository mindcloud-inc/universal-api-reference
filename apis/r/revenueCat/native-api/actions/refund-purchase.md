# Refund Purchase with RevenueCat

Refunds a Web Billing purchase in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/purchases/:purchaseId/actions/refund`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Refund Purchase](https://www.revenuecat.com/docs/api-v2)
