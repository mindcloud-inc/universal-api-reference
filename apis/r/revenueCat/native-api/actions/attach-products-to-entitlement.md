# Attach Products To Entitlement with RevenueCat

Attaches products to an entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements/:entitlementId/actions/attach_products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Attach Products To Entitlement](https://www.revenuecat.com/docs/api-v2)
