# Get Subscription Authenticated Management URL with RevenueCat

Retrieves an authenticated subscription management URL from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId/authenticated_management_url`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Subscription Authenticated Management URL](https://www.revenuecat.com/docs/api-v2)
