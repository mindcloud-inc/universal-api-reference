# Restore Customer Purchase By Order ID with RevenueCat

Restores a Google Play purchase by order ID in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/actions/restore_purchase_by_order_id`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Restore Customer Purchase By Order ID](https://www.revenuecat.com/docs/api-v2)
