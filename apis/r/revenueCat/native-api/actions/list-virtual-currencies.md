# List Virtual Currencies with RevenueCat

Retrieves virtual currencies from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/virtual_currencies`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Virtual Currencies](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
