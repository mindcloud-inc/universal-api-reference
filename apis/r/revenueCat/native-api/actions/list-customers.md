# List Customers with RevenueCat

Retrieves customers from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Customers](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
