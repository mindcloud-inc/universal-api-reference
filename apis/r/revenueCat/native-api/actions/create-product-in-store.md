# Create Product In Store with RevenueCat

Pushes a product to the App Store in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/products/:productId/create_in_store`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Create Product In Store](https://www.revenuecat.com/docs/api-v2)
