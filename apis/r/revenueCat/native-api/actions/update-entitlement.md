# Update Entitlement with RevenueCat

Updates an existing entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements/:entitlementId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Update Entitlement](https://www.revenuecat.com/docs/api-v2)
