# Create Webhook Integration with RevenueCat

Creates a new webhook integration in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/integrations/webhooks`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Create Webhook Integration](https://www.revenuecat.com/docs/api-v2)
