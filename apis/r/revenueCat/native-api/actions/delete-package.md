# Delete Package with RevenueCat

Deletes an existing package from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/packages/:packageId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Package](https://www.revenuecat.com/docs/api-v2)
