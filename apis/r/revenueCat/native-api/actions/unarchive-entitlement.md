# Unarchive Entitlement with RevenueCat

Unarchives an entitlement in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/entitlements/:entitlementId/actions/unarchive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Unarchive Entitlement](https://www.revenuecat.com/docs/api-v2)
