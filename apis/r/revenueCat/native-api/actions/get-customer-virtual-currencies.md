# Get Customer Virtual Currencies with RevenueCat

Retrieves a customer's virtual currency balances from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/virtual_currencies`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Customer Virtual Currencies](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
