# Set Customer Attributes with RevenueCat

Updates a customer's attributes in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/attributes`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Set Customer Attributes](https://www.revenuecat.com/docs/api-v2)
