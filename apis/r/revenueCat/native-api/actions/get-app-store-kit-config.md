# Get App StoreKit Config with RevenueCat

Retrieves an app StoreKit configuration from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/apps/:appId/store_kit_config`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get App StoreKit Config](https://www.revenuecat.com/docs/api-v2)
