# Refund Subscription with RevenueCat

Refunds an active Web Billing subscription in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId/actions/refund`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Refund Subscription](https://www.revenuecat.com/docs/api-v2)
