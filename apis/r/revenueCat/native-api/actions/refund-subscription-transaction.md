# Refund Subscription Transaction with RevenueCat

Refunds a Play Store or Galaxy subscription transaction in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId/transactions/:transactionId/actions/refund`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Refund Subscription Transaction](https://www.revenuecat.com/docs/api-v2)
