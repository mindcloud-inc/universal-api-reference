# List Paywalls with RevenueCat

Retrieves paywalls from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/paywalls`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Paywalls](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
