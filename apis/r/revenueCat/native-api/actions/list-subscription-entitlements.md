# List Subscription Entitlements with RevenueCat

Retrieves entitlements for a subscription in RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/subscriptions/:subscriptionId/entitlements`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Subscription Entitlements](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
