# Create Customer Virtual Currency Transaction with RevenueCat

Creates a virtual currency transaction in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/customers/:customerId/virtual_currencies/transactions`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Create Customer Virtual Currency Transaction](https://www.revenuecat.com/docs/api-v2)
