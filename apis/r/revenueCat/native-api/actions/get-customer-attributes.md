# Get Customer Attributes with RevenueCat

Retrieves a customer's attributes from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/attributes`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Customer Attributes](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
