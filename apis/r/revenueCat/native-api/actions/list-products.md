# List Products with RevenueCat

Retrieves products from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/products`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [List Products](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
