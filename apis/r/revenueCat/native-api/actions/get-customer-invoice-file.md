# Get Customer Invoice File with RevenueCat

Retrieves a customer invoice file from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/invoices/:invoiceId/file`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Customer Invoice File](https://www.revenuecat.com/docs/api-v2)
