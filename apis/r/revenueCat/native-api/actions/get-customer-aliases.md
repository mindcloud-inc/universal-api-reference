# Get Customer Aliases with RevenueCat

Retrieves a customer's aliases from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/customers/:customerId/aliases`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Customer Aliases](https://www.revenuecat.com/docs/api-v2)

## Capabilities

This operation supports [pagination](../README.md#pagination).
