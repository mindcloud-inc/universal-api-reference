# Archive Virtual Currency with RevenueCat

Archives a virtual currency in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/virtual_currencies/:virtualCurrencyCode/actions/archive`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Archive Virtual Currency](https://www.revenuecat.com/docs/api-v2)
