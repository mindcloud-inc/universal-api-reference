# Get Entitlement with RevenueCat

Retrieves an entitlement from RevenueCat.

## Endpoint

- **Method:** `GET`
- **Path:** `projects/:projectId/entitlements/:entitlementId`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Get Entitlement](https://www.revenuecat.com/docs/api-v2)
