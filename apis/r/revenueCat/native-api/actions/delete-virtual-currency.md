# Delete Virtual Currency with RevenueCat

Deletes an existing virtual currency from RevenueCat.

## Endpoint

- **Method:** `DELETE`
- **Path:** `projects/:projectId/virtual_currencies/:virtualCurrencyCode`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Delete Virtual Currency](https://www.revenuecat.com/docs/api-v2)
