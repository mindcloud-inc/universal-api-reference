# Create Virtual Currency with RevenueCat

Creates a new virtual currency in RevenueCat.

## Endpoint

- **Method:** `POST`
- **Path:** `projects/:projectId/virtual_currencies`
- **Base URL:** `https://api.revenuecat.com/v2`
- **Official documentation:** [Create Virtual Currency](https://www.revenuecat.com/docs/api-v2)
