# Get Webhook Public Key As String with Ragic

Retrieves the Ragic webhook public key as a string.

## Endpoint

- **Method:** `GET`
- **Path:** `{serverUrl}/api/http/getWebhookSignaturePublicKey.jsp`
- **Base URL:** `{serverUrl}/mindcloud`
- **Official documentation:** [Get Webhook Public Key As String](https://www.ragic.com/docs/api/en/#tag/webhooks-signature/Get-Public-Key)
