# List Webhooks with Resend

Retrieves webhooks from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Webhooks](https://resend.com/docs/api-reference/webhooks/list-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).
