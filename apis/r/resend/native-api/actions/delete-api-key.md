# Delete API Key with Resend

Deletes an existing API key from Resend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api-keys/:api_key_id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Delete API Key](https://resend.com/docs/api-reference/api-keys/delete-api-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key_id` | path | `list<string>` | no | Maximum length: 0. |
