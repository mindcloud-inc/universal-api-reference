# List Received Emails with Resend

Retrieves received emails from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/receiving`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Received Emails](https://resend.com/docs/api-reference/emails/list-received-emails)

## Capabilities

This operation supports [pagination](../README.md#pagination).
