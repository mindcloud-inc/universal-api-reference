# Get Template with Resend

Retrieves a template from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Get Template](https://resend.com/docs/api-reference/templates/get-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template identifier or alias. |
