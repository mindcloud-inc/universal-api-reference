# Retrieve Contact with Resend

Retrieves a contact from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Retrieve Contact](https://resend.com/docs/api-reference/contacts/get-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
| `email` | path | `list` | no |
