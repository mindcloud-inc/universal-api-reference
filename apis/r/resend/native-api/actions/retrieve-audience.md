# Retrieve Audience with Resend

Retrieves an audience from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Retrieve Audience](https://resend.com/docs/api-reference/audiences/get-audience)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `list<string>` | no |
