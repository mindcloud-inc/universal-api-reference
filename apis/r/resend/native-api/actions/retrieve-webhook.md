# Retrieve Webhook with Resend

Retrieves a webhook from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Retrieve Webhook](https://resend.com/docs/api-reference/webhooks/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `list<string>` | yes | The unique identifier of the webhook to retrieve |
