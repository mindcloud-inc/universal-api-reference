# List Templates with Resend

Retrieves templates from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/templates`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Templates](https://resend.com/docs/api-reference/templates/list-templates)

## Capabilities

This operation supports [pagination](../README.md#pagination).
