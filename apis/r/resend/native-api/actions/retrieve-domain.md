# Retrieve Domain with Resend

Retrieves a domain from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Retrieve Domain](https://resend.com/docs/api-reference/domains/get-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string<string>` | yes | The domain ID to retrieve |
