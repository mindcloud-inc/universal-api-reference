# Create Audience with Resend

Creates a new audience in Resend.

## Endpoint

- **Method:** `POST`
- **Path:** `/audiences`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Create Audience](https://resend.com/docs/api-reference/audiences/create-audience)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | The name of the audience to create |
