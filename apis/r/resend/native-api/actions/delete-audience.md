# Delete Audience with Resend

Deletes an existing audience from Resend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audiences/:audience_id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Delete Audience](https://resend.com/docs/api-reference/audiences/delete-audience)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `audience_id` | path | `list<string>` | no |
