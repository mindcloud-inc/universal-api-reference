# List Broadcasts with Resend

Retrieves broadcasts from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/broadcasts`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Broadcasts](https://resend.com/docs/api-reference/broadcasts/list-broadcasts)

## Capabilities

This operation supports [pagination](../README.md#pagination).
