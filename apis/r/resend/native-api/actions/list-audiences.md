# List Audiences with Resend

Retrieves audiences from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/audiences`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Audiences](https://resend.com/docs/api-reference/audiences/list-audiences)

## Capabilities

This operation supports [pagination](../README.md#pagination).
