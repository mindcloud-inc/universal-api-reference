# List Sent Emails with Resend

Retrieves sent emails from Resend.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [List Sent Emails](https://resend.com/docs/api-reference/emails/list-emails)

## Capabilities

This operation supports [pagination](../README.md#pagination).
