# Delete Template with Resend

Deletes an existing template from Resend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/templates/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Delete Template](https://resend.com/docs/api-reference/templates/delete-template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Template identifier or alias. |
