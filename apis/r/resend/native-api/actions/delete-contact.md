# Delete Contact with Resend

Deletes an existing contact from Resend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Delete Contact](https://resend.com/docs/api-reference/contacts/delete-contact)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `email` | path | `string` | no |
| `id` | path | `string` | yes |
