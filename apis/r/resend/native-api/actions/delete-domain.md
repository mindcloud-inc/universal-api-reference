# Delete Domain with Resend

Deletes an existing domain from Resend.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/domains/:id`
- **Base URL:** `https://api.resend.com`
- **Official documentation:** [Delete Domain](https://resend.com/docs/api-reference/domains/delete-domain)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string<string>` | yes | The Domain ID (UUID) |
