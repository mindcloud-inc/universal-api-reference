# Create Conversation with ReplyCX

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/conversations`
- **Base URL:** `https://api.reply.cx`
- **Official documentation:** [Create Conversation](https://help.reply.cx/integrations/public-apis)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `assignee` | body | `string` | no |
| `channel` | body | `string` | no |
| `from` | body | `string` | no |
| `message.data.template` | body | `string` | no |
| `message.text` | body | `string` | no |
| `message.type` | body | `string` | no |
| `to.email` | body | `string` | no |
| `to.name` | body | `string` | no |
| `to.phone` | body | `string` | no |
