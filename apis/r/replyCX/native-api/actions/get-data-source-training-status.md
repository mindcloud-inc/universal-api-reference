# Get Data Source Training Status with ReplyCX

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/ai/status/sources`
- **Base URL:** `https://api.reply.cx`
- **Official documentation:** [Get Data Source Training Status](https://help.reply.cx/integrations/public-apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `source_ids` | query | `string` | yes | Comma-separated list of ReplyCX data source IDs. |
