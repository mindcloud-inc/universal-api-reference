# Retrieve Campaign with Referral Factory

Retrieves a campaign from Referral Factory.

## Endpoint

- **Method:** `GET`
- **Path:** `/campaigns/:identifier`
- **Base URL:** `https://referral-factory.com/api/v2`
- **Official documentation:** [Retrieve Campaign](https://developers.referral-factory.com/reference/retrieve-a-campaign)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | path | `string` | yes | Unique identifier [ code or id ] of the campaign. |
