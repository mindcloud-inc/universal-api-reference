# Search Rewards with Referral Factory

Finds rewards in Referral Factory by metric.

## Endpoint

- **Method:** `POST`
- **Path:** `/rewards/dashboard/:metric/search`
- **Base URL:** `https://referral-factory.com/api/v2`
- **Official documentation:** [Search Rewards](https://developers.referral-factory.com/reference/search-rewards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metric` | path | `string` | yes | Reward dashboard metric to search. |
