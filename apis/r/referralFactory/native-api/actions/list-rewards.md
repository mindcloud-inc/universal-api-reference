# List Rewards with Referral Factory

Retrieves rewards from Referral Factory by metric.

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards/dashboard/:metric`
- **Base URL:** `https://referral-factory.com/api/v2`
- **Official documentation:** [List Rewards](https://developers.referral-factory.com/reference/list-all-rewards)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `metric` | path | `string` | yes | Reward dashboard metric to retrieve. |
