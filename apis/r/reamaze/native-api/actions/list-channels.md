# List Channels with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/channels`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [List Channels](https://www.reamaze.com/api/get_channels)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channel` | query | `string` | no | `channel` with `email`, `facebook`, `twitter`, or `chat` will show only channels by the respective types. |
| `email` | query | `string` | no | `channel` with `email`, `facebook`, `twitter`, or `chat` will show only channels by the respective types. |
| `facebook` | query | `string` | no | `channel` with `email`, `facebook`, `twitter`, or `chat` will show only channels by the respective types. |
| `twitter` | query | `string` | no | `channel` with `email`, `facebook`, `twitter`, or `chat` will show only channels by the respective types. |
| `chat` | query | `string` | no | `channel` with `email`, `facebook`, `twitter`, or `chat` will show only channels by the respective types. |
