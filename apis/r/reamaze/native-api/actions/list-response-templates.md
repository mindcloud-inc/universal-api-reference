# List Response Templates with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/response_templates`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [List Response Templates](https://www.reamaze.com/api/get_response_templates)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `q` | query | `string` | no | `q` with any string will search over response templates by keywords. |
