# Get Volume Report with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/volume`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [Get Volume Report](https://www.reamaze.com/api/get_reports_volume)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `start_date` | query | `string` | no | The `start_date` value can used to choose the start of the report. |
