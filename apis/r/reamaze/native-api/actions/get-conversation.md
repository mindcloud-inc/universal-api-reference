# Get Conversation with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:slug`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [Get Conversation](https://www.reamaze.com/api/get_conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | no | Path parameter for slug. |
