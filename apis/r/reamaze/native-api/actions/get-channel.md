# Get Channel with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/channels/:slug`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [Get Channel](https://www.reamaze.com/api/get_channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `slug` | path | `string` | yes | Path parameter for slug. |
