# Get Response Template with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/response_templates/:id`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [Get Response Template](https://www.reamaze.com/api/get_response_template)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Path parameter for id. |
