# Get Response Time Report with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/response_time`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [Get Response Time Report](https://www.reamaze.com/api/get_reports_response_time)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `start_date` | query | `date` | no | The `start_date` value can used to choose the start of the report. |
| `end_date` | query | `date` | no | The `end_date` value can used to choose the end of the report. |
