# List Contact Identities with Reamaze

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:email/identities`
- **Base URL:** `https://{brand}.reamaze.io/api/v1`
- **Official documentation:** [List Contact Identities](https://www.reamaze.com/api/get_identities)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | path | `string` | yes | Path parameter for email. |
