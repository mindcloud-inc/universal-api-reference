# Apply Automatic DNS with redirect.pizza

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/domains/{id}/automatic-dns`
- **Base URL:** `https://redirect.pizza`
- **Official documentation:** [Apply Automatic DNS](https://redirect.pizza/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the domain to configure. |
