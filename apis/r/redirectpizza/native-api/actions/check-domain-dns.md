# Check Domain DNS with redirect.pizza

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/domains/{id}/check-dns`
- **Base URL:** `https://redirect.pizza`
- **Official documentation:** [Check Domain DNS](https://redirect.pizza/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | ID of the domain to check. |
