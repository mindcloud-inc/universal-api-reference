# List Rewards with Reward Sciences

## Endpoint

- **Method:** `GET`
- **Path:** `/rewards`
- **Base URL:** `https://api.rewardsciences.com`

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `category_id` | query | `string` | no | Optional reward category filter. |
