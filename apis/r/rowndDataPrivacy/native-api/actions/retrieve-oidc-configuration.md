# Retrieve OIDC Configuration with Rownd Data Privacy

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.rownd.io/hub/auth/.well-known/oauth-authorization-server`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Retrieve OIDC Configuration](https://docs.rownd.io/api-reference/authentication/retrieve-oidc)
