# Update Group with Rownd Data Privacy

## Endpoint

- **Method:** `PUT`
- **Path:** `/groups/:group`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Update Group](https://docs.rownd.io/api-reference/groups/platform/group-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `string` | yes | Rownd group identifier. |
