# Delete User Profile with Rownd Data Privacy

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:user/data`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Delete User Profile](https://docs.rownd.io/api-reference/user-profiles/app/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | path | `string` | yes | Rownd user identifier. |
