# Insert or Update User Profile Data with Rownd Data Privacy

## Endpoint

- **Method:** `PUT`
- **Path:** `/users/:user/data`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Insert or Update User Profile Data](https://docs.rownd.io/api-reference/user-profiles/app/insert-update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user` | path | `string` | yes | Rownd user identifier. |
