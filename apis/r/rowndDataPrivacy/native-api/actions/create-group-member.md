# Create Group Member with Rownd Data Privacy

## Endpoint

- **Method:** `POST`
- **Path:** `/groups/:group/members`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Create Group Member](https://docs.rownd.io/api-reference/groups/platform/members/member-create)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `string` | yes | Rownd group identifier. |
