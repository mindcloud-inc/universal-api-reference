# Delete OIDC Client with Rownd Data Privacy

## Endpoint

- **Method:** `DELETE`
- **Path:** `/oidc-clients/:client`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [Delete OIDC Client](https://docs.rownd.io/api-reference/oidc/clients/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `client` | path | `string` | yes | Rownd OIDC client identifier. |
