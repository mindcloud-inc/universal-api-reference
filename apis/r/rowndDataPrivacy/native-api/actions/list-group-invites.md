# List Group Invites with Rownd Data Privacy

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:group/invites`
- **Base URL:** `https://api.rownd.io/applications/{appId}`
- **Official documentation:** [List Group Invites](https://docs.rownd.io/api-reference/groups/platform/invites/invite-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group` | path | `string` | yes | Rownd group identifier. |
