# Retrieve Annotation with Rossum

Retrieves an annotation from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/annotations/:annotationID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Annotation](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `annotationID` | path | `number` | yes | ID of the annotation to retrieve. |
