# Retrieve Upload with Rossum

Retrieves an upload from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/uploads/:uploadID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Upload](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `uploadID` | path | `string` | no | Rossum upload ID. |
