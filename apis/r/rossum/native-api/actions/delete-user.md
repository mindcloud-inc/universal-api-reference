# Delete User with Rossum

Deletes a user from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete User](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userID` | path | `string` | no | Rossum user ID. |
