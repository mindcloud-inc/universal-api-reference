# Delete Workspace with Rossum

Deletes a workspace from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/workspaces/:workspaceID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Workspace](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceID` | path | `string` | no | Rossum workspace ID. |
