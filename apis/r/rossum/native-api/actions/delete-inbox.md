# Delete Inbox with Rossum

Deletes an inbox from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/inboxes/:inboxID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Inbox](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inboxID` | path | `string` | no | Rossum inbox ID. |
