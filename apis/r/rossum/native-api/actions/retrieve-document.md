# Retrieve Document with Rossum

Retrieves a document from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:documentID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Document](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentID` | path | `number` | yes | ID of the document to retrieve. |
