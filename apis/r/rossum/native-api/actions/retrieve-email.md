# Retrieve Email with Rossum

Retrieves an email from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/emails/:emailID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Email](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `emailID` | path | `number` | yes | ID of the email to retrieve. |
