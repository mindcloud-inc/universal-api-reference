# Postpone Annotation with Rossum

Postpones an annotation in Rossum.

## Endpoint

- **Method:** `POST`
- **Path:** `/annotations/:annotationID/postpone`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Postpone Annotation](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `annotationID` | path | `number` | yes | Rossum annotation ID. |
