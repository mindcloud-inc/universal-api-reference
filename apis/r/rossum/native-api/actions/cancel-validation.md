# Cancel Validation with Rossum

Cancels validation for an annotation in Rossum.

## Endpoint

- **Method:** `POST`
- **Path:** `/annotations/:annotationID/cancel`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Cancel Validation](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `annotationID` | path | `number` | yes | Rossum annotation ID. |
