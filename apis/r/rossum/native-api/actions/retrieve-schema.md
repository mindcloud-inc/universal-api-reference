# Retrieve Schema with Rossum

Retrieves a schema from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/schemas/:schemaID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Schema](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemaID` | path | `number` | yes | ID of the schema to retrieve. |
