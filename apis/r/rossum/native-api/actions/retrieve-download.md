# Retrieve Download with Rossum

Retrieves a document download from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/downloads/:documentsDownloadID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Download](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentsDownloadID` | path | `number` | yes | ID of the Rossum download to retrieve. |
