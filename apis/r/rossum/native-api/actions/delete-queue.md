# Delete Queue with Rossum

Deletes a queue from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/queues/:id`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Queue](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Rossum queue ID. |
