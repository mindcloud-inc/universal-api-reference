# Delete Label with Rossum

Deletes a label from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/labels/:labelID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Label](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelID` | path | `string` | no | Rossum label ID. |
