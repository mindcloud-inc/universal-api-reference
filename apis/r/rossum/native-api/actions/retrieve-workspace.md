# Retrieve Workspace with Rossum

Retrieves a workspace from Rossum.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspaces/:workspaceID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Retrieve Workspace](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceID` | path | `number` | yes | Rossum workspace ID. |
