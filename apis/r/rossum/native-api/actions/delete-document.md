# Delete Document with Rossum

Deletes a document from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/documents/:documentID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Document](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `documentID` | path | `number` | yes |
