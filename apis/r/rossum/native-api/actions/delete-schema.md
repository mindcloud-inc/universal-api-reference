# Delete Schema with Rossum

Deletes a schema from Rossum.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/schemas/:schemaID`
- **Base URL:** `https://mindcloud.rossum.app/api/v1`
- **Official documentation:** [Delete Schema](https://rossum.app/api/docs/openapi/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `schemaID` | path | `string` | no | Rossum schema ID. |
