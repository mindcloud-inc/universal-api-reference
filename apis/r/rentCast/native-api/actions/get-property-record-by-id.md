# Get Property Record by ID with RentCast

Retrieves a property record from RentCast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/properties/:id`
- **Base URL:** `https://api.rentcast.io/v1`
- **Official documentation:** [Get Property Record by ID](https://developers.rentcast.io/reference/property-record-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RentCast property record ID to retrieve. |
