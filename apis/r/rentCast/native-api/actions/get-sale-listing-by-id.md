# Get Sale Listing by ID with RentCast

Retrieves a sale listing from RentCast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/listings/sale/:id`
- **Base URL:** `https://api.rentcast.io/v1`
- **Official documentation:** [Get Sale Listing by ID](https://developers.rentcast.io/reference/sale-listing-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RentCast sale listing ID to retrieve. |
