# Get Rental Listing by ID with RentCast

Retrieves a rental listing from RentCast by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/listings/rental/long-term/:id`
- **Base URL:** `https://api.rentcast.io/v1`
- **Official documentation:** [Get Rental Listing by ID](https://developers.rentcast.io/reference/rental-listing-long-term-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RentCast rental listing ID to retrieve. |
