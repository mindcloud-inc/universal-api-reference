# Get Random Foxes with RandomFox

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/getfoxes/`
- **Base URL:** `https://randomfox.ca`
- **Official documentation:** [Get Random Foxes](https://github.com/xinitrc-dev/randomfox.ca/blob/master/api/v1/getfoxes/index.php)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | query | `number` | yes | Number of unique foxes to return (1–20). |
