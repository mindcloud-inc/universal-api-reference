# List School Holidays with Rijksoverheid

Lists all school holidays from Rijksoverheid.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/infotypes/schoolholidays`
- **Base URL:** `https://opendata.rijksoverheid.nl`
- **Official documentation:** [List School Holidays](https://www.rijksoverheid.nl/opendata/schoolvakanties)
