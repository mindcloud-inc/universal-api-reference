# List Candidate Notes with Recruitee ATS

## Endpoint

- **Method:** `GET`
- **Path:** `/c/:company_id/candidates/:id/notes`
- **Base URL:** `https://api.recruitee.com`
- **Official documentation:** [List Candidate Notes](https://docs.recruitee.com/reference/candidatesidnotes)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Candidate ID. |
