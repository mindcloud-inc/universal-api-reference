# Delete Offer with Recruitee ATS

## Endpoint

- **Method:** `DELETE`
- **Path:** `/c/:company_id/offers/:id`
- **Base URL:** `https://api.recruitee.com`
- **Official documentation:** [Delete Offer](https://docs.recruitee.com/reference/offersid-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Offer ID. |
