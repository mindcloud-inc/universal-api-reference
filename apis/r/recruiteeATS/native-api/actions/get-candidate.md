# Get Candidate with Recruitee ATS

## Endpoint

- **Method:** `GET`
- **Path:** `/c/:company_id/candidates/:id`
- **Base URL:** `https://api.recruitee.com`
- **Official documentation:** [Get Candidate](https://docs.recruitee.com/reference/candidatesid-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Candidate ID. |
