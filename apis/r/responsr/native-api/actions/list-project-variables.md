# List Project Variables with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/projects/:projectId/variables`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [List Project Variables](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | no | Responsr project ID. |
