# Get Default Project Variable with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/projects/:projectId/variables/default`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get Default Project Variable](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | no | Responsr project ID. |
