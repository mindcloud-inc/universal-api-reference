# Get User Group with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/usergroups/:id`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get User Group](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Responsr user group ID. |
