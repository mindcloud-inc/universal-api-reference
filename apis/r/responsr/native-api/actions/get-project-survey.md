# Get Project Survey with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/projects/:projectId/surveys/:id`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get Project Survey](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Responsr survey ID. |
| `projectId` | path | `string` | no | Responsr project ID. |
