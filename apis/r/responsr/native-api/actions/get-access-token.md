# Get Access Token with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/personalaccesstokens/:id`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get Access Token](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Responsr personal access token ID. |
