# Get Async Task with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/asynctasks/:id`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get Async Task](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Responsr async task ID. |
