# Get Language with Responsr

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1.0/languages/:id`
- **Base URL:** `https://app.responsr.io`
- **Official documentation:** [Get Language](https://app.responsr.io/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Responsr language ID. |
