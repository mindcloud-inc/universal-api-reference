# List App Keys with RapidAPI

Retrieves app keys from RapidAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/apps/{projectId}/keys`
- **Base URL:** `{baseUrlRest}`
- **Official documentation:** [List App Keys](https://docs.rapidapi.com/docs/example-obtaining-apps-and-keys-for-users-and-teams)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | RapidAPI app project ID. |
