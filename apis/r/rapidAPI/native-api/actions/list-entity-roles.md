# List Entity Roles with RapidAPI

Retrieves roles for an entity in RapidAPI.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/entities/{entityId}/roles`
- **Base URL:** `{baseUrlRest}`
- **Official documentation:** [List Entity Roles](https://docs.rapidapi.com/docs/platform-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `entityId` | path | `string` | yes | RapidAPI entity ID. |
