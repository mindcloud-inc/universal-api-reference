# List Organization Teams with RapidAPI

Retrieves teams for a RapidAPI organization.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/{orgId}/teams`
- **Base URL:** `{baseUrlRest}`
- **Official documentation:** [List Organization Teams](https://docs.rapidapi.com/docs/platform-api-overview)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgId` | path | `string` | yes | RapidAPI organization ID. |
