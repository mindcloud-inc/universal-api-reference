# List User Teams with RapidAPI

Retrieves teams for a RapidAPI user.

## Endpoint

- **Method:** `GET`
- **Path:** `/admin/users/{userId}/teams`
- **Base URL:** `{baseUrlRest}`
- **Official documentation:** [List User Teams](https://docs.rapidapi.com/docs/on-behalf-of)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | RapidAPI user ID. |
