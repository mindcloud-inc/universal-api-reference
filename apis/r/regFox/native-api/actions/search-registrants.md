# Search Registrants with RegFox

Finds matching registrants in the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/registrants`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Search Registrants](https://docs.webconnex.io/api/v2/#search-registrants)
