# Get Transaction with RegFox

Retrieves transaction details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/transactions/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Transaction](https://docs.webconnex.io/api/v2/#view-transaction-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox transaction ID. |
