# Get Ticket with RegFox

Retrieves ticket details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/tickets/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Ticket](https://docs.webconnex.io/api/v2/#view-ticket-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox ticket ID. |
