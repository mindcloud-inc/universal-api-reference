# Search Subscriptions with RegFox

Finds matching subscriptions in the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/subscriptions`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Search Subscriptions](https://docs.webconnex.io/api/v2/#search-subscriptions)
