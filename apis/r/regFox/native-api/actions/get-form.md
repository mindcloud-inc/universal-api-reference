# Get Form with RegFox

Retrieves form details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `forms/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Form](https://docs.webconnex.io/api/v2/#view-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox form ID. |
