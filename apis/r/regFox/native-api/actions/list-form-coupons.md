# List Form Coupons with RegFox

Retrieves coupons for a RegFox form.

## Endpoint

- **Method:** `GET`
- **Path:** `coupons/forms/{formId}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [List Form Coupons](https://docs.webconnex.io/api/v2/#list-form-coupons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The RegFox form ID. |
