# Get Customer with RegFox

Retrieves customer details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/customers/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Customer](https://docs.webconnex.io/api/v2/#view-customer-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox customer ID. |
