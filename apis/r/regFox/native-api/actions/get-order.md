# Get Order with RegFox

Retrieves order details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/orders/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Order](https://docs.webconnex.io/api/v2/#view-order-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox order ID. |
