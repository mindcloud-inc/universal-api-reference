# Get Coupon with RegFox

Retrieves coupon details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `coupons/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Coupon](https://docs.webconnex.io/api/v2/#view-coupon-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox coupon ID. |
