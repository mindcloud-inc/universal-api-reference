# Update Webhook with RegFox

Updates an existing webhook in the RegFox account.

## Endpoint

- **Method:** `PUT`
- **Path:** `webhooks/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Update Webhook](https://docs.webconnex.io/api/v2/#update)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox webhook ID. |
