# Get Registrant with RegFox

Retrieves registrant details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/registrants/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Registrant](https://docs.webconnex.io/api/v2/#view-registrant-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox registrant ID. |
