# List Form Inventory with RegFox

Retrieves inventory items for a RegFox form.

## Endpoint

- **Method:** `GET`
- **Path:** `forms/{formId}/inventory`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [List Form Inventory](https://docs.webconnex.io/api/v2/#view-for-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `formId` | path | `string` | yes | The RegFox form ID. |
