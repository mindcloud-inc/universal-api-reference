# Get Webhook with RegFox

Retrieves webhook details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `webhooks/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Webhook](https://docs.webconnex.io/api/v2/#view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox webhook ID. |
