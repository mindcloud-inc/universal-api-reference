# Get Subscription with RegFox

Retrieves subscription details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/subscriptions/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Subscription](https://docs.webconnex.io/api/v2/#view-subscription-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox subscription ID. |
