# Get Membership with RegFox

Retrieves membership details from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/memberships/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Get Membership](https://docs.webconnex.io/api/v2/#view-membership-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox membership ID. |
