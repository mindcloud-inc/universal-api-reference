# Check In Registrant with RegFox

Checks in a registrant in the RegFox account.

## Endpoint

- **Method:** `POST`
- **Path:** `registrant/check-in`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Check In Registrant](https://docs.webconnex.io/api/v2/#check-in-by-id)
