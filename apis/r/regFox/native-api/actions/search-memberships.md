# Search Memberships with RegFox

Finds matching memberships in the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `search/memberships`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Search Memberships](https://docs.webconnex.io/api/v2/#search-memberships)
