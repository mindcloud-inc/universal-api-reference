# Delete Webhook with RegFox

Deletes an existing webhook from the RegFox account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `webhooks/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Delete Webhook](https://docs.webconnex.io/api/v2/#delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox webhook ID. |
