# Delete Coupon with RegFox

Deletes an existing coupon from the RegFox account.

## Endpoint

- **Method:** `DELETE`
- **Path:** `coupons/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Delete Coupon](https://docs.webconnex.io/api/v2/#delete-coupon)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox coupon ID. |
