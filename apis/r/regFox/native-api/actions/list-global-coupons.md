# List Global Coupons with RegFox

Retrieves global coupons from the RegFox account.

## Endpoint

- **Method:** `GET`
- **Path:** `coupons/global`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [List Global Coupons](https://docs.webconnex.io/api/v2/#list-global-coupons)
