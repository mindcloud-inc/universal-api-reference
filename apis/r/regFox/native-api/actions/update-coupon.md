# Update Coupon with RegFox

Updates an existing coupon in the RegFox account.

## Endpoint

- **Method:** `PUT`
- **Path:** `coupons/{id}`
- **Base URL:** `https://api.webconnex.com/v2/public`
- **Official documentation:** [Update Coupon](https://docs.webconnex.io/api/v2/#edit-coupon)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The RegFox coupon ID. |
