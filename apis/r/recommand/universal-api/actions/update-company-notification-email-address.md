# Recommand: Update Company Notification Email Address

Updates a company notification email address in Recommand.

```
PUT https://connect.mindcloud.co/v1/universal/recommand/latest/actions/update-company-notification-email-address
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Recommand `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X PUT "https://connect.mindcloud.co/v1/universal/recommand/latest/actions/update-company-notification-email-address" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "connectionId": "$CONNECTION_ID",
  "companyid": "string",
  "email": "ava@example.com",
  "notificationemailaddressid": "ava@example.com",
  "notifyincoming": true,
  "notifyoutgoing": true
}'
```

```js
const response = await fetch('https://connect.mindcloud.co/v1/universal/recommand/latest/actions/update-company-notification-email-address', {
  method: 'PUT',
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    connectionId,
    "companyid": "string",
    "email": "ava@example.com",
    "notificationemailaddressid": "ava@example.com",
    "notifyincoming": true,
    "notifyoutgoing": true
  })
});

const { success, data } = await response.json();
```

## Inputs

Arguments are sent as JSON body fields ([conventions](../arguments.md)).

| Key | Type | Required | Description |
| --- | --- | --- | --- |
| `companyid` | string | yes | companyId parameter. |
| `email` | string | yes | The email address to update |
| `includeautogeneratedpdfincoming` | boolean | no | Whether to include the auto-generated PDF attachment for incoming document notifications |
| `includeautogeneratedpdfoutgoing` | boolean | no | Whether to include the auto-generated PDF attachment for outgoing document notifications |
| `includedocumentjsonincoming` | boolean | no | Whether to include the document.json attachment for incoming document notifications |
| `includedocumentjsonoutgoing` | boolean | no | Whether to include the document.json attachment for outgoing document notifications |
| `notificationemailaddressid` | string | yes | notificationEmailAddressId parameter. |
| `notifyincoming` | boolean | yes | Whether to notify on incoming documents |
| `notifyoutgoing` | boolean | yes | Whether to notify on outgoing documents |

## Native endpoint

Through the native Recommand API, this operation is `PUT /api/v1/companies/:companyId/notification-email-addresses/:notificationEmailAddressId` (base URL `https://app.recommand.eu`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/update-company-notification-email-address.md) for the provider-specific parameters and requirements.
