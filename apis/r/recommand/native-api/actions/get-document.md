# Get Document with Recommand

Retrieves a document record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/documents/:documentId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Document](https://recommand.eu/en/reference/documents/get-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | documentId parameter. |
