# Get Label with Recommand

Retrieves a label record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/labels/:labelId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Label](https://recommand.eu/en/reference/labels/get-label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | labelId parameter. |
