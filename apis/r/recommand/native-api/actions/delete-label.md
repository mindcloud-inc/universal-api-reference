# Delete Label with Recommand

Deletes an existing label from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/labels/:labelId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Label](https://recommand.eu/en/reference/labels/delete-label)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `labelId` | path | `string` | yes | labelId parameter. |
