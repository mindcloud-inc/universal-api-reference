# Verify Company with Recommand

Verifies a company profile in Recommand.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/companies/:companyId/verify`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Verify Company](https://recommand.eu/en/reference/companies/verify-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
