# Delete Customer with Recommand

Deletes an existing customer from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/customers/:customerId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Customer](https://recommand.eu/en/reference/customers/delete-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | customerId parameter. |
