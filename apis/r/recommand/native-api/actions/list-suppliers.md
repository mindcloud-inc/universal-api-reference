# List Suppliers with Recommand

Retrieves supplier records from the Recommand API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/suppliers`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [List Suppliers](https://recommand.eu/en/reference/suppliers/list-suppliers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | search parameter. |
