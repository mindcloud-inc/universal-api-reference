# Delete Supplier with Recommand

Deletes an existing supplier from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/suppliers/:supplierId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Supplier](https://recommand.eu/en/reference/suppliers/delete-supplier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | path | `string` | yes | supplierId parameter. |
