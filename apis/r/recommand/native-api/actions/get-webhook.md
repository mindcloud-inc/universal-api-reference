# Get Webhook with Recommand

Retrieves a webhook record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/webhooks/:webhookId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Webhook](https://recommand.eu/en/reference/webhooks/get-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | webhookId parameter. |
