# Delete Company with Recommand

Deletes an existing company from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/companies/:companyId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Company](https://recommand.eu/en/reference/companies/delete-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
