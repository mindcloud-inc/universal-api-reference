# Get Company with Recommand

Retrieves a company record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/companies/:companyId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Company](https://recommand.eu/en/reference/companies/get-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
