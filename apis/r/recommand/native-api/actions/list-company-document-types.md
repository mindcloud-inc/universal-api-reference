# List Company Document Types with Recommand

Retrieves company document types from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/companies/:companyId/document-types`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [List Company Document Types](https://recommand.eu/en/reference/company-document-types/list-company-document-types)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
