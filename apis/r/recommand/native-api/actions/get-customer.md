# Get Customer with Recommand

Retrieves a customer record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/customers/:customerId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Customer](https://recommand.eu/en/reference/customers/get-customer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `customerId` | path | `string` | yes | customerId parameter. |
