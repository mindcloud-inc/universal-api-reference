# Get Company Document Type with Recommand

Retrieves a company document type from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/companies/:companyId/document-types/:documentTypeId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Company Document Type](https://recommand.eu/en/reference/company-document-types/get-company-document-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
| `documentTypeId` | path | `string` | yes | documentTypeId parameter. |
