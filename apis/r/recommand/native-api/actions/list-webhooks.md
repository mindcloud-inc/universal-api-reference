# List Webhooks with Recommand

Retrieves webhook records from the Recommand API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/webhooks`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [List Webhooks](https://recommand.eu/en/reference/webhooks/list-webhooks)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | query | `string` | no | companyId parameter. |
