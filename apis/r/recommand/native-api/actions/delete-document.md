# Delete Document with Recommand

Deletes an existing document from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/documents/:documentId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Document](https://recommand.eu/en/reference/documents/delete-document)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | documentId parameter. |
