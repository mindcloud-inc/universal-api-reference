# List Labels with Recommand

Retrieves label records from the Recommand API.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/labels`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [List Labels](https://recommand.eu/en/reference/labels/list-labels)

## Capabilities

This operation supports [pagination](../README.md#pagination).
