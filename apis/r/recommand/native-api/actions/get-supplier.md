# Get Supplier with Recommand

Retrieves a supplier record from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/suppliers/:supplierId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Get Supplier](https://recommand.eu/en/reference/suppliers/get-supplier)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `supplierId` | path | `string` | yes | supplierId parameter. |
