# Delete Webhook with Recommand

Deletes an existing webhook from Recommand.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v1/webhooks/:webhookId`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Delete Webhook](https://recommand.eu/en/reference/webhooks/delete-webhook)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | webhookId parameter. |
