# Create Company Notification Email Address with Recommand

Creates a company notification email address in Recommand.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/companies/:companyId/notification-email-addresses`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [Create Company Notification Email Address](https://recommand.eu/en/reference/company-notification-email-addresses/create-company-notification-email-address)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
| `email` | body | `string` | yes | The email address to create |
| `includeAutoGeneratedPdfIncoming` | body | `boolean` | no | Whether to include the auto-generated PDF attachment for incoming document notifications |
| `includeAutoGeneratedPdfOutgoing` | body | `boolean` | no | Whether to include the auto-generated PDF attachment for outgoing document notifications |
| `includeDocumentJsonIncoming` | body | `boolean` | no | Whether to include the document.json attachment for incoming document notifications |
| `includeDocumentJsonOutgoing` | body | `boolean` | no | Whether to include the document.json attachment for outgoing document notifications |
| `notifyIncoming` | body | `boolean` | yes | Whether to notify on incoming documents |
| `notifyOutgoing` | body | `boolean` | yes | Whether to notify on outgoing documents |
