# List Company Notification Email Addresses with Recommand

Retrieves company notification email addresses from Recommand.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/companies/:companyId/notification-email-addresses`
- **Base URL:** `https://app.recommand.eu`
- **Official documentation:** [List Company Notification Email Addresses](https://recommand.eu/en/reference/company-notification-email-addresses/list-company-notification-email-addresses)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | companyId parameter. |
