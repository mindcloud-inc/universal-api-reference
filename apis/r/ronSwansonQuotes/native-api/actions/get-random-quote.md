# Get Random Quote with Ron Swanson Quotes

Retrieves a random Ron Swanson quote.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes`
- **Base URL:** `https://ron-swanson-quotes.herokuapp.com/v2`
- **Official documentation:** [Get Random Quote](https://github.com/jamesseanwright/ron-swanson-quotes#apis)
