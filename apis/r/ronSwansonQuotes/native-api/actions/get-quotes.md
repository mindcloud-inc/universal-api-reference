# Get Quotes with Ron Swanson Quotes

Retrieves multiple Ron Swanson quotes.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/:count`
- **Base URL:** `https://ron-swanson-quotes.herokuapp.com/v2`
- **Official documentation:** [Get Quotes](https://github.com/jamesseanwright/ron-swanson-quotes#apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `count` | path | `number` | yes | Number of random Ron Swanson quotes to return. |
