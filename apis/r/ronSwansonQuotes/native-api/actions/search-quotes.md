# Search Quotes with Ron Swanson Quotes

Finds Ron Swanson quotes by search term.

## Endpoint

- **Method:** `GET`
- **Path:** `/quotes/search/:term`
- **Base URL:** `https://ron-swanson-quotes.herokuapp.com/v2`
- **Official documentation:** [Search Quotes](https://github.com/jamesseanwright/ron-swanson-quotes#apis)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `term` | path | `string` | yes | Case-insensitive term to search for in Ron Swanson quotes. |
