# Download Payment Image with Rillion Prime

## Endpoint

- **Method:** `GET`
- **Path:** `/payment/images/download`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [Download Payment Image](https://prime-2-uat-14-ue.rillionprime.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `imageUrl` | query | `string` | yes | Optional query value for ImageUrl. |
