# List Group Types with Rillion Prime

## Endpoint

- **Method:** `GET`
- **Path:** `/groupType`
- **Base URL:** `{baseUrl}`
- **Official documentation:** [List Group Types](https://prime-2-uat-14-ue.rillionprime.com/swagger/index.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `Template` | query | `string` | yes | Template value used to list visible group types, for example Invoice. |
