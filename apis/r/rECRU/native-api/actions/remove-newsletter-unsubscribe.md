# Remove Newsletter Unsubscribe with RECRU

## Endpoint

- **Method:** `POST`
- **Base URL:** `https://mindclo.recru.eu/api/json-rpc`
- **Official documentation:** [Remove Newsletter Unsubscribe](https://mindclo.recru.eu/api/index/documentation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `params.email` | body | `string` | yes |
