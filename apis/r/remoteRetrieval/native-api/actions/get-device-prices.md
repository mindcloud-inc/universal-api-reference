# Get Device Prices with Remote Retrieval

Retrieves device prices from Remote Retrieval.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/get-device-prices`
- **Base URL:** `https://www.remoteretrieval.com`
- **Official documentation:** [Get Device Prices](https://www.remoteretrieval.com/api-integration)
