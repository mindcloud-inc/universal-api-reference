# Create List with Reply

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/people/lists`
- **Base URL:** `https://api.reply.io`
- **Official documentation:** [Create List](https://apidocs.reply.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Unique Reply list name. |
