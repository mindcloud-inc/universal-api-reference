# Pause Campaign with Reply

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/campaigns/:campaignId/pause`
- **Base URL:** `https://api.reply.io`
- **Official documentation:** [Pause Campaign](https://apidocs.reply.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `campaignId` | path | `number` | yes | Reply campaign identifier. |
