# Update Contact By Email with Reply

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/people`
- **Base URL:** `https://api.reply.io`
- **Official documentation:** [Update Contact By Email](https://apidocs.reply.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Contact email address. |
| `firstName` | body | `string` | yes | Contact first name. |
