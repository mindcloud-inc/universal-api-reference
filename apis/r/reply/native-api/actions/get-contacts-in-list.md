# Get Contacts In List with Reply

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/people/list/:listId`
- **Base URL:** `https://api.reply.io`
- **Official documentation:** [Get Contacts In List](https://apidocs.reply.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `listId` | path | `number` | yes | Reply list identifier. |
