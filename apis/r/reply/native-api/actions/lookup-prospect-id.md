# Lookup Prospect Id with Reply

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/people/lookup`
- **Base URL:** `https://api.reply.io`
- **Official documentation:** [Lookup Prospect Id](https://apidocs.reply.io/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | no | Contact email address for prospect lookup. |
| `linkedin` | body | `string` | no | LinkedIn profile URL for prospect lookup. |
