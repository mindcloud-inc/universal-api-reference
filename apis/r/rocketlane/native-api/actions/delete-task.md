# Delete Task with Rocketlane

Deletes a task from Rocketlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/1.0/tasks/:taskId`
- **Base URL:** `https://api.rocketlane.com/api`
- **Official documentation:** [Delete Task](https://developer.rocketlane.com/reference/delete-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `number` | yes | The ID of the task object |
