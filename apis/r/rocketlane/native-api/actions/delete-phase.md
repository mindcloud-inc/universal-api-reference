# Delete Phase with Rocketlane

Deletes a phase from Rocketlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/1.0/phases/:phaseId`
- **Base URL:** `https://api.rocketlane.com/api`
- **Official documentation:** [Delete Phase](https://developer.rocketlane.com/reference/delete-phase)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `phaseId` | path | `number` | yes | The `identifier` of the phase is generated by the system and can be used to identify the phase globally. |
