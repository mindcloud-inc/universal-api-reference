# Delete Comment with Rocketlane

Deletes a comment from Rocketlane.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/1.0/comments/:commentId`
- **Base URL:** `https://api.rocketlane.com/api`
- **Official documentation:** [Delete Comment](https://developer.rocketlane.com/reference/delete-comment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `commentId` | path | `number` | yes | The ID of the message object |
