# Remove Conversation Members with Rocketlane

Removes members from a conversation in Rocketlane.

## Endpoint

- **Method:** `POST`
- **Path:** `/1.0/conversations/:conversationId/remove-members`
- **Base URL:** `https://api.rocketlane.com/api`
- **Official documentation:** [Remove Conversation Members](https://developer.rocketlane.com/reference/remove-members-from-conversation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `number` | yes | The ID of the conversation object |
