# Publish Virtual Tour with RICOH360 Tours

- **Method:** `POST`
- **Path:** `/graphql`
- **Base URL:** `https://bbomwcm27nhalfwjvwzy6qbrim.appsync-api.us-west-2.amazonaws.com`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `contentId` | query | `string` | no | Content ID to publish. |
| `teamId` | query | `string` | no | Team ID that owns the published content. |
