# List Agents with Release0

Retrieves agents in a Release0 workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [List Agents](https://docs.release0.com/api-reference/agent/list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `string` | yes | The workspace ID to list agents from. |
