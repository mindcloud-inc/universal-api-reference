# Get Agent Analytics Stats with Release0

Retrieves analytics stats for a Release0 agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:agentId/analytics/stats`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [Get Agent Analytics Stats](https://docs.release0.com/submission/analytics)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The agent ID. |
