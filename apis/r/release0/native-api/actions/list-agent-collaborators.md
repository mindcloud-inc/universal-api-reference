# List Agent Collaborators with Release0

Retrieves collaborators for a Release0 agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:agentId/collaborators`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [List Agent Collaborators](https://docs.release0.com/workspace/add-members-and-guests)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The agent ID. |
