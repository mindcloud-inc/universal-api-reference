# Get Agent with Release0

Retrieves an agent from Release0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:agentId`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [Get Agent](https://docs.release0.com/api-reference/agent/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The agent ID. |
