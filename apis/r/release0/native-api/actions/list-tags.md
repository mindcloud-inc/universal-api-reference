# List Tags with Release0

Retrieves tags from a Release0 workspace.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tags`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [List Tags](https://docs.release0.com/workspace/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workspaceId` | query | `string` | yes | The workspace ID to list tags for. |
