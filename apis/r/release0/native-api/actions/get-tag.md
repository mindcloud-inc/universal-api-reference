# Get Tag with Release0

Retrieves a tag from Release0.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/tags/:id`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [Get Tag](https://docs.release0.com/workspace/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The tag ID. |
