# Get Published Agent with Release0

Retrieves the published version of a Release0 agent.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agents/:agentId/publishedAgent`
- **Base URL:** `https://release0.com/api`
- **Official documentation:** [Get Published Agent](https://docs.release0.com/editor/agent-settings/publish)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The agent ID. |
