# Delete Highlight with Readwise

Deletes an existing highlight from Readwise.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v2/highlights/:highlightId/`
- **Base URL:** `https://readwise.io`
- **Official documentation:** [Delete Highlight](https://readwise.io/api_deets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `highlightId` | path | `number` | yes | The Readwise highlight ID to delete. |
