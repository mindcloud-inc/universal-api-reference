# Get Highlight with Readwise

Retrieves a highlight from the Readwise library.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/highlights/:highlight_id/`
- **Base URL:** `https://readwise.io`
- **Official documentation:** [Get Highlight](https://readwise.io/api_deets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `highlight_id` | path | `number` | yes | The unique id of the highlight to retrieve. |
