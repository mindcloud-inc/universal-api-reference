# Delete Reader Document with Readwise

Deletes an existing document from Readwise Reader.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/api/v3/delete/:documentId/`
- **Base URL:** `https://readwise.io`
- **Official documentation:** [Delete Reader Document](https://readwise.io/reader_api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | path | `string` | yes | The Readwise Reader document ID to delete. |
