# List FFmpeg Commands with Rendi

Retrieves submitted FFmpeg commands from Rendi.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/commands`
- **Base URL:** `https://api.rendi.dev`
- **Official documentation:** [List FFmpeg Commands](https://docs.rendi.dev/api-reference/endpoint/list-commands)

## Capabilities

This operation supports [pagination](../README.md#pagination).
