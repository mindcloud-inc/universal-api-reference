# List Stored Files with Rendi

Retrieves stored account files from Rendi.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files`
- **Base URL:** `https://api.rendi.dev`
- **Official documentation:** [List Stored Files](https://docs.rendi.dev/api-reference/endpoint/list-files)

## Capabilities

This operation supports [pagination](../README.md#pagination).
