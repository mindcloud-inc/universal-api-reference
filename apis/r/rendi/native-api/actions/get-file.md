# Get File with Rendi

Retrieves a stored file from Rendi.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/:file_id`
- **Base URL:** `https://api.rendi.dev`
- **Official documentation:** [Get File](https://docs.rendi.dev/api-reference/endpoint/get-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `file_id` | path | `string` | yes | UUID of the stored file. |
