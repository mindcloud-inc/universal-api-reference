# Update Single Inventory with Rithum DSCO

Updates a single inventory record in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `inventory/singleItem`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Update Single Inventory](https://api.dsco.io/doc/v3/reference/#tag/Inventory/operation/singleItem)
