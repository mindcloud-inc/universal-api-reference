# Create Shipment with Rithum DSCO

Creates a shipment in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `order/singleShipment`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Create Shipment](https://api.dsco.io/doc/v3/reference/#tag/Order/operation/singleShipment)
