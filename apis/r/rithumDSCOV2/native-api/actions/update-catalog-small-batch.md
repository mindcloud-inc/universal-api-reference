# Update Catalog Small Batch with Rithum DSCO

Updates catalog items in a small batch in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `catalog/batch/small`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Update Catalog Small Batch](https://api.dsco.io/doc/v3/reference/#tag/Catalog/operation/updateCatalogSmallBatch)
