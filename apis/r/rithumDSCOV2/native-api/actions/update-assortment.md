# Update Assortment with Rithum DSCO

Updates an assortment in Rithum DSCO.

## Endpoint

- **Method:** `PUT`
- **Path:** `assortment/:id`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Update Assortment](https://api.dsco.io/doc/v3/reference/#tag/Assortment/operation/updateAssortment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required DSCO assortment ID. |
