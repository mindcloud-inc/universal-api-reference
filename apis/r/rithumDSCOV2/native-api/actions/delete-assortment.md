# Delete Assortment with Rithum DSCO

Deletes an assortment from Rithum DSCO.

## Endpoint

- **Method:** `DELETE`
- **Path:** `assortment/:id`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Delete Assortment](https://api.dsco.io/doc/v3/reference/#tag/Assortment/operation/deleteAssortment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required DSCO assortment ID. |
