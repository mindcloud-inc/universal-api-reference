# Acknowledge Orders with Rithum DSCO

Acknowledges orders in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `order/acknowledge`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Acknowledge Orders](https://api.dsco.io/doc/v3/reference/#tag/Order/operation/acknowledgeOrders)
