# Cancel Order Item with Rithum DSCO

Cancels an order item in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `order/item/cancel`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Cancel Order Item](https://api.dsco.io/doc/v3/reference/#tag/Order/operation/cancelOrderItem)
