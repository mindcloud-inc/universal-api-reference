# Create Assortment with Rithum DSCO

Creates an assortment in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `assortment`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Create Assortment](https://api.dsco.io/doc/v3/reference/#tag/Assortment/operation/createAssortment)
