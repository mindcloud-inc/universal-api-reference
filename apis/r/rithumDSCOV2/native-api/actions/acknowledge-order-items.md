# Acknowledge Order Items with Rithum DSCO

Acknowledges order items in Rithum DSCO.

## Endpoint

- **Method:** `POST`
- **Path:** `order/acknowledge/items`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Acknowledge Order Items](https://api.dsco.io/doc/v3/reference/#tag/Order/operation/acknowledgeOrderItems)
