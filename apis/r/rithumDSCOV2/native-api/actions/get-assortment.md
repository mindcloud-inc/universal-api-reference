# Get Assortment with Rithum DSCO

Retrieves an assortment from Rithum DSCO.

## Endpoint

- **Method:** `GET`
- **Path:** `assortment/:id`
- **Base URL:** `https://api.dsco.io/api/v3`
- **Official documentation:** [Get Assortment](https://api.dsco.io/doc/v3/reference/#tag/Assortment/operation/getAssortment)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Required DSCO assortment ID. |
