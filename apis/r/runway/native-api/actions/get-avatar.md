# Get Avatar with Runway

Retrieves an avatar from Runway.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars/[:id]`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [Get Avatar](https://docs.dev.runwayml.com/api#tag/Avatars/paths/~1v1~1avatars~1%7Bid%7D/get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the avatar to retrieve. |
