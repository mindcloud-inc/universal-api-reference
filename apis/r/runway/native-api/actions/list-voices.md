# List Voices with Runway

Retrieves voices from Runway.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/voices`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [List Voices](https://docs.dev.runwayml.com/api#tag/Voices/paths/~1v1~1voices/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
