# Delete Avatar with Runway

Deletes an avatar from Runway.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/avatars/[:id]`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [Delete Avatar](https://docs.dev.runwayml.com/api#tag/Avatars/paths/~1v1~1avatars~1%7Bid%7D/delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | UUID of the avatar to delete. |
