# List Avatars with Runway

Retrieves avatars from Runway.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/avatars`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [List Avatars](https://docs.dev.runwayml.com/api#tag/Avatars/paths/~1v1~1avatars/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
