# Get Organization Information with Runway

Retrieves organization information from Runway.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organization`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [Get Organization Information](https://docs.dev.runwayml.com/api#tag/Organization/paths/~1v1~1organization/get)
