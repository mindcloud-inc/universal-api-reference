# List Documents with Runway

Retrieves documents from Runway.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents`
- **Base URL:** `https://api.dev.runwayml.com`
- **Official documentation:** [List Documents](https://docs.dev.runwayml.com/api#tag/Knowledge/paths/~1v1~1documents/get)

## Capabilities

This operation supports [pagination](../README.md#pagination).
