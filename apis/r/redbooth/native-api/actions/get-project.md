# Get Project with Redbooth

Retrieves a project from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Get Project](https://redbooth.com/api/api-docs/#page:projects,header:projects-project-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth project ID |
