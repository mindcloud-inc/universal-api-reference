# Get Task List with Redbooth

Retrieves a task list from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_lists/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Get Task List](https://redbooth.com/api/api-docs/#page:tasklists,header:tasklists-tasklist-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth task list ID |
