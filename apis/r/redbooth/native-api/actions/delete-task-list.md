# Delete Task List with Redbooth

Deletes an existing task list from Redbooth.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/task_lists/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Delete Task List](https://redbooth.com/api/api-docs/#page:tasklists,header:tasklists-tasklist-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth task list ID |
