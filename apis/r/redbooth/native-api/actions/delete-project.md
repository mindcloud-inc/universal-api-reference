# Delete Project with Redbooth

Deletes an existing project from Redbooth.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/projects/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Delete Project](https://redbooth.com/api/api-docs/#page:projects,header:projects-project-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth project ID |
