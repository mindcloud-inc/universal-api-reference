# List Conversations with Redbooth

Retrieves conversations from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [List Conversations](https://redbooth.com/api/api-docs/#page:conversations,header:conversations-conversation-list-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `project_id` | query | `number` | no | Filter by project |
