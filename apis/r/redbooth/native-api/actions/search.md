# Search with Redbooth

Finds matching records in your Redbooth account.

## Endpoint

- **Method:** `GET`
- **Path:** `/search`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Search](https://redbooth.com/api/api-docs/#page:search,header:search-search-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `term` | query | `string` | yes | Search term |
