# Get User Information with Redbooth

Retrieves the current user's information from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Get User Information](https://redbooth.com/api/api-docs/#page:user-information,header:user-information-user-information-get)
