# List Task Lists with Redbooth

Retrieves task lists from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_lists`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [List Task Lists](https://redbooth.com/api/api-docs/#page:tasklists,header:tasklists-tasklist-list-get)
