# Delete Task with Redbooth

Deletes an existing task from Redbooth.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tasks/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Delete Task](https://redbooth.com/api/api-docs/#page:tasks,header:tasks-task-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth task ID |
