# Get Conversation with Redbooth

Retrieves a conversation from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/conversations/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Get Conversation](https://redbooth.com/api/api-docs/#page:conversations,header:conversations-conversation-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth conversation ID |
