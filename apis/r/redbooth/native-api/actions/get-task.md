# Get Task with Redbooth

Retrieves a task from Redbooth.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Get Task](https://redbooth.com/api/api-docs/#page:tasks,header:tasks-task-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth task ID |
