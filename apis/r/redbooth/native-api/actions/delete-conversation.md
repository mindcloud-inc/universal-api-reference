# Delete Conversation with Redbooth

Deletes an existing conversation from Redbooth.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/conversations/:id`
- **Base URL:** `https://redbooth.com/api/3`
- **Official documentation:** [Delete Conversation](https://redbooth.com/api/api-docs/#page:conversations,header:conversations-conversation-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Redbooth conversation ID |
