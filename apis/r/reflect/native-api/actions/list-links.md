# List Links with Reflect

Retrieves links from a graph in Reflect.

## Endpoint

- **Method:** `GET`
- **Path:** `/graphs/:graphId/links`
- **Base URL:** `https://reflect.app/api`
- **Official documentation:** [List Links](https://openpm.ai/packages/reflect#/graphs/{graphId}/links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `graphId` | path | `list<string>` | yes | Your graph identifier |
