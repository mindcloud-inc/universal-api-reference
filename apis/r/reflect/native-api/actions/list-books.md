# List Books with Reflect

Retrieves books from a graph in Reflect.

## Endpoint

- **Method:** `GET`
- **Path:** `/graphs/:graphId/books`
- **Base URL:** `https://reflect.app/api`
- **Official documentation:** [List Books](https://openpm.ai/packages/reflect#/graphs/{graphId}/books)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `graphId` | path | `list<string>` | yes | Your graph identifier |
