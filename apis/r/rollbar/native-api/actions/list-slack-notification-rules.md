# List Slack Notification Rules with Rollbar

Retrieves Slack notification rules from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/slack/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [List Slack Notification Rules](https://docs.rollbar.com/reference/get_api-1-notifications-slack-rules)
