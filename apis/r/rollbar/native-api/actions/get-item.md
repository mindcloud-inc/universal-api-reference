# Get Item with Rollbar

Retrieves an item from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/item/:itemId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Item](https://docs.rollbar.com/reference/get-an-item-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `number` | yes | Rollbar item identifier. |
