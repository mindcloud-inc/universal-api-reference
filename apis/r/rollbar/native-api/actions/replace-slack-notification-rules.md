# Replace Slack Notification Rules with Rollbar

Updates Slack notification rules in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/slack/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Replace Slack Notification Rules](https://docs.rollbar.com/reference/put_api-1-notifications-slack-rules)
