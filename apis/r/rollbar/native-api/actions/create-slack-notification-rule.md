# Create Slack Notification Rule with Rollbar

Creates a Slack notification rule in Rollbar.

## Endpoint

- **Method:** `POST`
- **Path:** `/notifications/slack/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Create Slack Notification Rule](https://docs.rollbar.com/reference/post_api-1-notifications-slack-rules)
