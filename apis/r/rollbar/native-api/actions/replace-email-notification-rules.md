# Replace Email Notification Rules with Rollbar

Updates email notification rules in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/email/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Replace Email Notification Rules](https://docs.rollbar.com/reference/put_api-1-notifications-email-rules)
