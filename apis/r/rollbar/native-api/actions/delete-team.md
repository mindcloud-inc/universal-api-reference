# Delete Team with Rollbar

Deletes an existing team from Rollbar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/team/:teamId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Delete Team](https://docs.rollbar.com/reference/delete-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `number` | yes | Rollbar team identifier. |
