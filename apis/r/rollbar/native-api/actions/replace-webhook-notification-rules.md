# Replace Webhook Notification Rules with Rollbar

Updates webhook notification rules in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/webhook/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Replace Webhook Notification Rules](https://docs.rollbar.com/reference/put_api-1-notifications-webhook-rules)
