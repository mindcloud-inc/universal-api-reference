# Get Team with Rollbar

Retrieves a team from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/team/:teamId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Team](https://docs.rollbar.com/reference/get-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `teamId` | path | `number` | yes | Rollbar team identifier. |
