# Get Activated Item Counts with Rollbar

Retrieves activated item counts from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/activated_counts`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Activated Item Counts](https://docs.rollbar.com/reference/get-activated-item-counts)
