# Update Email Notification Rule with Rollbar

Updates an email notification rule in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/email/rule/:ruleId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Update Email Notification Rule](https://docs.rollbar.com/reference/put_api-1-notifications-email-rule-rule-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleId` | path | `number` | yes | Notification rule identifier |
