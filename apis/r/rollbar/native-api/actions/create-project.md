# Create Project with Rollbar

Creates a new project in Rollbar.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Create Project](https://docs.rollbar.com/reference/create-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Name of the project. |
