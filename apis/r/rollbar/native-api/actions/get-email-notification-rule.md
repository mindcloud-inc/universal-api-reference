# Get Email Notification Rule with Rollbar

Retrieves an email notification rule from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/email/rule/:ruleId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Email Notification Rule](https://docs.rollbar.com/reference/get_api-1-notifications-email-rule-rule-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleId` | path | `number` | yes | Notification rule identifier |
