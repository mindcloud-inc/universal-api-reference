# Create PagerDuty Notification Rule with Rollbar

Creates a PagerDuty notification rule in Rollbar.

## Endpoint

- **Method:** `POST`
- **Path:** `/notifications/pagerduty`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Create PagerDuty Notification Rule](https://docs.rollbar.com/reference/post_api-1-notifications-pagerduty-rules)
