# Get Invitation with Rollbar

Retrieves a team invitation from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/invite/:inviteId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Invitation](https://docs.rollbar.com/reference/get-an-invitation)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `inviteId` | path | `number` | yes | Team invitation identifier |
