# Update Service Link with Rollbar

Updates an existing service link in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/service_links/:id`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Update Service Link](https://docs.rollbar.com/reference/put_api-1-service-links-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Rollbar service link identifier. |
