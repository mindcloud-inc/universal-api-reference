# List Webhook Notification Rules with Rollbar

Retrieves webhook notification rules from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/webhook/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [List Webhook Notification Rules](https://docs.rollbar.com/reference/get_api-1-notifications-webhook-rules)
