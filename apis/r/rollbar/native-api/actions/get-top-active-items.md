# Get Top Active Items with Rollbar

Retrieves top active items from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/top_active_items`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Top Active Items](https://docs.rollbar.com/reference/get-top-active-items)
