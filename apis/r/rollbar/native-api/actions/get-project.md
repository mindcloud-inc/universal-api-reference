# Get Project with Rollbar

Retrieves a project from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/project/:projectId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Project](https://docs.rollbar.com/reference/get-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `number` | yes | Rollbar project identifier. |
