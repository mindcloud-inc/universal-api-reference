# Update Item with Rollbar

Updates an existing item in Rollbar.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/item/:itemId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Update Item](https://docs.rollbar.com/reference/update-an-item)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `itemId` | path | `number` | yes | Rollbar item identifier |
