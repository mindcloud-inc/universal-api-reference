# Get Service Link with Rollbar

Retrieves a service link from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/service_links/:id`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Service Link](https://docs.rollbar.com/reference/get_api-1-service-links-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Rollbar service link identifier. |
