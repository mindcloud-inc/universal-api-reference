# Get Version Details with Rollbar

Retrieves version details from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/versions/:version`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get Version Details](https://docs.rollbar.com/reference/get_api-1-versions-version)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `version` | path | `string` | yes | Code version string |
