# List PagerDuty Notification Rules with Rollbar

Retrieves PagerDuty notification rules from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/pagerduty/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [List PagerDuty Notification Rules](https://docs.rollbar.com/reference/get_api-1-notifications-pagerduty-rules)
