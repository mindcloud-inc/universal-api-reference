# Create Email Notification Rule with Rollbar

Creates an email notification rule in Rollbar.

## Endpoint

- **Method:** `POST`
- **Path:** `/notifications/email/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Create Email Notification Rule](https://docs.rollbar.com/reference/post_api-1-notifications-email-rules)
