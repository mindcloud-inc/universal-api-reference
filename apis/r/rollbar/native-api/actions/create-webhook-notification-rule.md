# Create Webhook Notification Rule with Rollbar

Creates a webhook notification rule in Rollbar.

## Endpoint

- **Method:** `POST`
- **Path:** `/notifications/webhook/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Create Webhook Notification Rule](https://docs.rollbar.com/reference/post_api-1-notifications-webhook-rules)
