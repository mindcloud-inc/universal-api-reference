# Replace PagerDuty Notification Rules with Rollbar

Updates PagerDuty notification rules in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/pagerduty/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Replace PagerDuty Notification Rules](https://docs.rollbar.com/reference/put_api-1-notifications-pagerduty-rules)
