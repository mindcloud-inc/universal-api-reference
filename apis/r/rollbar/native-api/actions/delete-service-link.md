# Delete Service Link with Rollbar

Deletes an existing service link from Rollbar.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/service_links/:id`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Delete Service Link](https://docs.rollbar.com/reference/delete_api-1-service-links-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Rollbar service link identifier. |
