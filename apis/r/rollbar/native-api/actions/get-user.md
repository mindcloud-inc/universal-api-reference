# Get User with Rollbar

Retrieves a user from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/:userId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Get User](https://docs.rollbar.com/reference/get-a-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `number` | yes | Rollbar user identifier. |
