# Update Webhook Notification Rule with Rollbar

Updates a webhook notification rule in Rollbar.

## Endpoint

- **Method:** `PUT`
- **Path:** `/notifications/webhook/rule/:ruleId`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [Update Webhook Notification Rule](https://docs.rollbar.com/reference/put_api-1-notifications-webhook-rule-rule-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ruleId` | path | `number` | yes | Notification rule identifier |
