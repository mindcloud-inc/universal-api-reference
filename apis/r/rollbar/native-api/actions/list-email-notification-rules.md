# List Email Notification Rules with Rollbar

Retrieves email notification rules from Rollbar.

## Endpoint

- **Method:** `GET`
- **Path:** `/notifications/email/rules`
- **Base URL:** `https://api.rollbar.com/api/1`
- **Official documentation:** [List Email Notification Rules](https://docs.rollbar.com/reference/get_api-1-notifications-email-rules)
