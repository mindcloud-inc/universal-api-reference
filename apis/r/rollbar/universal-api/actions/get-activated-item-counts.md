# Rollbar: Get Activated Item Counts

Retrieves activated item counts from Rollbar.

```
GET https://connect.mindcloud.co/v1/universal/rollbar/latest/actions/get-activated-item-counts
```

Authenticate with `Authorization: Bearer $MINDCLOUD_API_KEY` and pass a Rollbar `connectionId` ([setup](../authentication.md)).

## Example request

```bash
curl -X GET "https://connect.mindcloud.co/v1/universal/rollbar/latest/actions/get-activated-item-counts?connectionId=$CONNECTION_ID" \
  -H "Authorization: Bearer $MINDCLOUD_API_KEY"
```

```js
const params = new URLSearchParams({
  connectionId
});

const response = await fetch(`https://connect.mindcloud.co/v1/universal/rollbar/latest/actions/get-activated-item-counts?${params}`, {
  headers: {
    Authorization: `Bearer ${process.env.MINDCLOUD_API_KEY}`
  }
});

const { success, data } = await response.json();
```



## Response

## Native endpoint

Through the native Rollbar API, this operation is `GET /reports/activated_counts` (base URL `https://api.rollbar.com/api/1`). The Universal API call above is translated to it by MindCloud, including authentication. See the [native action reference](../../native-api/actions/get-activated-item-counts.md) for the provider-specific parameters and requirements.
