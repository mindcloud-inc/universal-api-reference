# List Chat with Retell AI

Retrieves chats from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-chat`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [List Chat](https://docs.retellai.com/api-references/list-chat)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_order` | query | `string` | no | Allowed values: ascending, descending. |
