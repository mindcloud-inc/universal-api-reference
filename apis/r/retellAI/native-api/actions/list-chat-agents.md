# List Chat Agents with Retell AI

Retrieves chat agents from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-chat-agents`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [List Chat Agents](https://docs.retellai.com/api-references/list-chat-agents)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pagination_key_version` | query | `number` | no |
