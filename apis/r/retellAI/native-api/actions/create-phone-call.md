# Create Phone Call with Retell AI

Creates a phone call in Retell AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/create-phone-call`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Create Phone Call](https://docs.retellai.com/api-references/create-phone-call)
