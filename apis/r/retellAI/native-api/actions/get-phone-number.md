# Get Phone Number with Retell AI

Retrieves a phone number from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-phone-number/{phone_number}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Phone Number](https://docs.retellai.com/api-references/get-phone-number)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `phone_number` | path | `string` | yes |
