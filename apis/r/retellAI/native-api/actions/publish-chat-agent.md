# Publish Chat Agent with Retell AI

Publishes a chat agent in Retell AI.

## Endpoint

- **Method:** `POST`
- **Path:** `/publish-chat-agent/{agent_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Publish Chat Agent](https://docs.retellai.com/api-references/publish-chat-agent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
