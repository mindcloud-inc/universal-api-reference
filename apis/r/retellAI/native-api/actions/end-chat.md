# End Chat with Retell AI

Ends an ongoing chat in Retell AI.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/end-chat/{chat_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [End Chat](https://docs.retellai.com/api-references/end-chat)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chat_id` | path | `string` | yes |
