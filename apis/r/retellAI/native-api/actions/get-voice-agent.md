# Get Voice Agent with Retell AI

Retrieves a voice agent from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-agent/{agent_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Voice Agent](https://docs.retellai.com/api-references/get-agent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | path | `string` | yes |
| `version` | query | `number` | no |
