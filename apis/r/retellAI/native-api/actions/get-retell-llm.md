# Get Retell LLM with Retell AI

Retrieves a Retell LLM from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-retell-llm/{llm_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Retell LLM](https://docs.retellai.com/api-references/get-retell-llm)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `llm_id` | path | `string` | yes |
| `version` | query | `number` | no |
