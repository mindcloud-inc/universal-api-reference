# List Phone Numbers with Retell AI

Retrieves phone numbers from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/list-phone-numbers`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [List Phone Numbers](https://docs.retellai.com/api-references/list-phone-numbers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `sort_order` | query | `string` | no | Allowed values: ascending, descending. |
