# Get Call with Retell AI

Retrieves a call from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/get-call/{call_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Call](https://docs.retellai.com/api-references/get-call)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `call_id` | path | `string` | yes |
