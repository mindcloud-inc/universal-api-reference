# Get Knowledge Base with Retell AI

Retrieves a knowledge base from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-knowledge-base/{knowledge_base_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Knowledge Base](https://docs.retellai.com/api-references/get-knowledge-base)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `knowledge_base_id` | path | `string` | yes |
