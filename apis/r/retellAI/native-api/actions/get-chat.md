# Get Chat with Retell AI

Retrieves a chat from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/get-chat/{chat_id}`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [Get Chat](https://docs.retellai.com/api-references/get-chat)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `chat_id` | path | `string` | yes |
