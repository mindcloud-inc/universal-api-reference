# List Retell LLMs with Retell AI

Retrieves Retell LLMs from Retell AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/list-retell-llms`
- **Base URL:** `https://api.retellai.com`
- **Official documentation:** [List Retell LLMs](https://docs.retellai.com/api-references/list-retell-llms)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `pagination_key_version` | query | `number` | no |
