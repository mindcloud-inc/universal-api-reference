# List Themes with Rebrickable

Retrieves LEGO theme records from Rebrickable.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/themes/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [List Themes](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
