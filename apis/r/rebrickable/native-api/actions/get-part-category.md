# Get Part Category with Rebrickable

Retrieves a LEGO part category from Rebrickable by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/part_categories/:id/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [Get Part Category](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Rebrickable part category ID. |
