# List Badges with Rebrickable

Retrieves badges from Rebrickable user profiles.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/badges/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [List Badges](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
