# Get Badge with Rebrickable

Retrieves a badge from Rebrickable by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/badges/:id/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [Get Badge](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Rebrickable badge ID. |
