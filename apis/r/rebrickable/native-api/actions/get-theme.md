# Get Theme with Rebrickable

Retrieves a LEGO theme from Rebrickable by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/themes/:id/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [Get Theme](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Rebrickable theme ID. |
