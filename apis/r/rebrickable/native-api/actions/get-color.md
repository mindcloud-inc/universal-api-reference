# Get Color with Rebrickable

Retrieves a LEGO color from Rebrickable by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/colors/:id/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [Get Color](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Rebrickable color ID. |
