# List Part Categories with Rebrickable

Retrieves LEGO part categories from Rebrickable.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/part_categories/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [List Part Categories](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
