# List Colors with Rebrickable

Retrieves LEGO color records from Rebrickable.

## Endpoint

- **Method:** `GET`
- **Path:** `/lego/colors/`
- **Base URL:** `https://rebrickable.com/api/v3`
- **Official documentation:** [List Colors](https://rebrickable.com/api/v3/docs/?key=xxxxxxxxxx)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
