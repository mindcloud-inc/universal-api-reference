# Get Learning Path with Reach360

Retrieves a learning path from Reach360 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/learning-paths/:learningPathId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Learning Path](https://www.articulatesupport.com/article/Reach-360-Learning-Paths-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `learningPathId` | path | `string` | yes | The learning path ID. |
