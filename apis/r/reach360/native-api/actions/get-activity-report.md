# Get Activity Report with Reach360

Retrieves the activity report from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/activity`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Activity Report](https://www.articulatesupport.com/article/Reach-360-Reports-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).
