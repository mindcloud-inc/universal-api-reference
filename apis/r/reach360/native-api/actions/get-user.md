# Get User with Reach360

Retrieves a user from Reach360 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get User](https://www.articulatesupport.com/article/Reach-360-Users-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
