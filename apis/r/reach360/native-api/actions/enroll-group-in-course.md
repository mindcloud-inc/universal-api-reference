# Enroll Group In Course with Reach360

Enrolls a group in a Reach360 course.

## Endpoint

- **Method:** `PUT`
- **Path:** `/courses/:courseId/groups/:groupId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Enroll Group In Course](https://www.articulatesupport.com/article/Reach-360-Course-Enrollments-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | yes | The course ID. |
| `groupId` | path | `string` | yes | The group ID. |
