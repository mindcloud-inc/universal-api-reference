# Get Group with Reach360

Retrieves a group from Reach360 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Group](https://www.articulatesupport.com/article/Reach-360-Groups-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The group ID. |
