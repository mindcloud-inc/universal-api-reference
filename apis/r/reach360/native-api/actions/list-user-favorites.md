# List User Favorites with Reach360

Retrieves a user's favorite items from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:userId/favorites`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List User Favorites](https://www.articulatesupport.com/article/Reach-360-Favorites-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
