# Get Course with Reach360

Retrieves a course from Reach360 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses/:courseId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Course](https://www.articulatesupport.com/article/Reach-360-Courses-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | no | The course ID. |
