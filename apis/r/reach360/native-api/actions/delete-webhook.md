# Delete Webhook with Reach360

Deletes an existing webhook from Reach360.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Delete Webhook](https://www.articulatesupport.com/article/Reach-360-Webhooks-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The webhook ID. |
