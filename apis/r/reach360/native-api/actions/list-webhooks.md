# List Webhooks with Reach360

Retrieves all webhooks from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Webhooks](https://www.articulatesupport.com/article/Reach-360-Webhooks-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).
