# Get Course Report with Reach360

Retrieves a course report from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/courses/:courseId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Course Report](https://www.articulatesupport.com/article/Reach-360-Reports-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `courseId` | path | `string` | yes | The course ID. |
