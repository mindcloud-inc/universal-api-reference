# Get Learner Report with Reach360

Retrieves a learner report from Reach360 by user.

## Endpoint

- **Method:** `GET`
- **Path:** `/reports/learners/:userId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Learner Report](https://www.articulatesupport.com/article/Reach-360-Reports-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
