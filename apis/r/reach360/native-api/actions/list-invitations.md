# List Invitations with Reach360

Retrieves all invitations from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/invitations`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Invitations](https://www.articulatesupport.com/article/Reach-360-Invitations-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Only return invitations with this email address. |
