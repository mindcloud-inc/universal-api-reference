# List Courses with Reach360

Retrieves all courses from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/courses`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Courses](https://www.articulatesupport.com/article/Reach-360-Courses-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).
