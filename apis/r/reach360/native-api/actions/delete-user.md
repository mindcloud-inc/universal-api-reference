# Delete User with Reach360

Deletes an existing user from Reach360.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/users/:userId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Delete User](https://www.articulatesupport.com/article/Reach-360-Users-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The user ID. |
