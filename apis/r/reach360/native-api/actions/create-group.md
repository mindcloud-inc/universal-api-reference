# Create Group with Reach360

Creates a new group in Reach360.

## Endpoint

- **Method:** `POST`
- **Path:** `/groups`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Create Group](https://www.articulatesupport.com/article/Reach-360-Groups-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | The group name. |
