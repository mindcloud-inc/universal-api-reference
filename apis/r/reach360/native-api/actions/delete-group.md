# Delete Group with Reach360

Deletes an existing group from Reach360.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/groups/:groupId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Delete Group](https://www.articulatesupport.com/article/Reach-360-Groups-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The group ID. |
