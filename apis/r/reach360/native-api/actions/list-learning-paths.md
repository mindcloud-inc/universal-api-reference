# List Learning Paths with Reach360

Retrieves all learning paths from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/learning-paths`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Learning Paths](https://www.articulatesupport.com/article/Reach-360-Learning-Paths-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).
