# List Groups with Reach360

Retrieves all groups from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/groups`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Groups](https://www.articulatesupport.com/article/Reach-360-Groups-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | no | Return groups with the specified name. |
