# Enroll Group In Learning Path with Reach360

Enrolls a group in a Reach360 learning path.

## Endpoint

- **Method:** `PUT`
- **Path:** `/learning-paths/:learningPathId/groups/:groupId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Enroll Group In Learning Path](https://www.articulatesupport.com/article/Reach-360-Learning-Path-Enrollments-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `learningPathId` | path | `string` | yes | The learning path ID. |
| `groupId` | path | `string` | yes | The group ID. |
