# Get Webhook with Reach360

Retrieves a webhook from Reach360 by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/webhooks/:webhookId`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [Get Webhook](https://www.articulatesupport.com/article/Reach-360-Webhooks-API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `webhookId` | path | `string` | yes | The webhook ID. |
