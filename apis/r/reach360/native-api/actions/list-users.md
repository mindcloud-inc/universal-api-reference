# List Users with Reach360

Retrieves all users from Reach360.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.reach360.com`
- **Official documentation:** [List Users](https://www.articulatesupport.com/article/Reach-360-Users-API)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | no | Only return users with this email address. |
