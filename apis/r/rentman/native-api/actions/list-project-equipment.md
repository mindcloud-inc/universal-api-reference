# List Project Equipment with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id/projectequipment`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [List Project Equipment](https://api.rentman.net/#operation/getProjectProjectEquipmentCollection)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman project identifier. |
