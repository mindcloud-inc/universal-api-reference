# Get Appointment with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Appointment](https://api.rentman.net/#operation/getAppointmentItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman appointment ID. |
