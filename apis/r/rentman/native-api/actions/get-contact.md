# Get Contact with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Contact](https://api.rentman.net/#operation/getContactItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman contact ID. |
