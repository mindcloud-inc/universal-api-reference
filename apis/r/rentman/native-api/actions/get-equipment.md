# Get Equipment with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/equipment/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Equipment](https://api.rentman.net/#operation/getEquipmentItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman equipment identifier. |
