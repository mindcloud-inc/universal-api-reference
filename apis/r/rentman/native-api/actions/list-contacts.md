# List Contacts with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [List Contacts](https://api.rentman.net/#operation/getContactCollection)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
