# Create Project with Rentman

## Endpoint

- **Method:** `POST`
- **Path:** `/projects`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Create Project](https://api.rentman.net/#operation/createProject)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | no | Project name. |
| `reference` | body | `string` | no | Project reference. |
| `number` | body | `string` | no | Project number. |
