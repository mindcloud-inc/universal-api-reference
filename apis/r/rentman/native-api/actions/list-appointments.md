# List Appointments with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/appointments`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [List Appointments](https://api.rentman.net/#operation/getAppointmentCollection)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
