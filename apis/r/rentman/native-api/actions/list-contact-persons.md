# List Contact Persons with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id/contactpersons`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [List Contact Persons](https://api.rentman.net/#operation/getContactContactPersonCollection)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman contact identifier. |
