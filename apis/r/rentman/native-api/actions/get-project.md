# Get Project with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Project](https://api.rentman.net/#operation/getProjectItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman project identifier. |
