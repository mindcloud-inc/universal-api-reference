# Get Crew with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/crew/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Crew](https://api.rentman.net/#operation/getCrewItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman crew identifier. |
