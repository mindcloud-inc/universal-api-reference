# Get Invoice with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:id`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [Get Invoice](https://api.rentman.net/#operation/getFactuurItem)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Numeric Rentman invoice ID. |
