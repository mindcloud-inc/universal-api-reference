# List Vehicles with Rentman

## Endpoint

- **Method:** `GET`
- **Path:** `/vehicles`
- **Base URL:** `https://api.rentman.net`
- **Official documentation:** [List Vehicles](https://api.rentman.net/#operation/getVehicleCollection)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
