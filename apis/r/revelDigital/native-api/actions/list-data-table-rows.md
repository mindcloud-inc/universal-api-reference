# List Data Table Rows with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/datatables/:tableId/rows`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [List Data Table Rows](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | path | `string` | yes | Unique identifier of the data table. |
