# Get Schedule with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/schedules/:id`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Get Schedule](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the schedule. |
