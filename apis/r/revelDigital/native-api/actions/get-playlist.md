# Get Playlist with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/playlists/:id`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Get Playlist](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the playlist. |
