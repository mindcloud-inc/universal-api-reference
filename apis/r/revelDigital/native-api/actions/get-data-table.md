# Get Data Table with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/datatables/:tableId`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Get Data Table](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | path | `string` | yes | Unique identifier of the data table. |
