# Create Data Table Row with Revel Digital

## Endpoint

- **Method:** `POST`
- **Path:** `/datatables/:tableId/rows`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Create Data Table Row](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tableId` | path | `string` | yes | Unique identifier of the data table. |
