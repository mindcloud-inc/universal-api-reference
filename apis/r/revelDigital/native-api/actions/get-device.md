# Get Device with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/devices/:id`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Get Device](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the device. |
