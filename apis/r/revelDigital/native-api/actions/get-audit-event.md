# Get Audit Event with Revel Digital

## Endpoint

- **Method:** `GET`
- **Path:** `/account/auditevents/:eventId`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Get Audit Event](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | Unique identifier of the audit event. |
