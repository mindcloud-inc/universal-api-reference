# Update Alert with Revel Digital

## Endpoint

- **Method:** `PUT`
- **Path:** `/alerts/:id`
- **Base URL:** `https://api.reveldigital.com`
- **Official documentation:** [Update Alert](https://developer.reveldigital.com/rest-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Encrypted alert identifier. |
