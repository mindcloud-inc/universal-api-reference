# List Company Phone Numbers with RingCentral

Retrieves company phone numbers from RingCentral.

## Endpoint

- **Method:** `GET`
- **Path:** `restapi/v1.0/account/:accountId/phone-number`
- **Base URL:** `https://platform.ringcentral.com/`
- **Official documentation:** [List Company Phone Numbers](https://developers.ringcentral.com/api-reference/Phone-Numbers/listAccountPhoneNumbers)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
