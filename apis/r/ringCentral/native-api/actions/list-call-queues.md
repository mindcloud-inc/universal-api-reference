# List Call Queues with RingCentral

Retrieves call queues from a RingCentral account.

## Endpoint

- **Method:** `GET`
- **Path:** `restapi/v1.0/account/:accountId/call-queues`
- **Base URL:** `https://platform.ringcentral.com/`
- **Official documentation:** [List Call Queues](https://developers.ringcentral.com/api-reference/Call-Queues/listCallQueues)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
