# Get Extension with RingCentral

Retrieves an extension from a RingCentral account.

## Endpoint

- **Method:** `GET`
- **Path:** `restapi/v1.0/account/:accountId/extension/:extensionId`
- **Base URL:** `https://platform.ringcentral.com/`
- **Official documentation:** [Get Extension](https://developers.ringcentral.com/api-reference/User-Settings/readExtension)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `accountId` | path | `string` | yes |
| `extensionId` | path | `string` | yes |
