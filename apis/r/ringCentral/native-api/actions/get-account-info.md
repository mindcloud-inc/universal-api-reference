# Get Account Info with RingCentral

Retrieves the current RingCentral account information.

## Endpoint

- **Method:** `GET`
- **Path:** `restapi/v1.0/account/~`
- **Base URL:** `https://platform.ringcentral.com/`
- **Official documentation:** [Get Account Info](https://developers.ringcentral.com/api-reference/Company/getAccountInfoV2)
