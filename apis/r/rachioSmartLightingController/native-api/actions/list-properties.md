# List Properties with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud-rest.rach.io/property/listProperties/:userId`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [List Properties](https://rachio.readme.io/reference/propertyservice_listproperties)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The person ID returned by Get Current Person ID. |
