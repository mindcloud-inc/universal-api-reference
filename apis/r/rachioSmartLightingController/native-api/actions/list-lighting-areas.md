# List Lighting Areas with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `GET`
- **Path:** `https://cloud-rest.rach.io/lighting/listLightingAreas/:userId`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [List Lighting Areas](https://rachio.readme.io/reference/lightingservice_listlightingareas)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The person ID returned by Get Current Person ID. |
