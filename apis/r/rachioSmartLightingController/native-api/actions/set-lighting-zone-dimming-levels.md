# Set Lighting Zone Dimming Levels with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/setLightingZoneDimmingLevels`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Set Lighting Zone Dimming Levels](https://rachio.readme.io/reference/lightingservice_setlightingzonedimminglevels)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dimming_percent` | body | `string` | no |
| `id` | body | `string` | no |
