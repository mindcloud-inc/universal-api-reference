# Deactivate Lighting Scene with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/deactivateLightingScene/:id`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Deactivate Lighting Scene](https://rachio.readme.io/reference/lightingservice_deactivatelightingscene)
