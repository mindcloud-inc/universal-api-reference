# Update Lighting Zone with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/updateLightingZone`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Update Lighting Zone](https://rachio.readme.io/reference/lightingservice_updatelightingzone)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dimmable` | body | `string` | no |
| `enabled` | body | `string` | no |
| `id` | body | `string` | no |
| `max_output` | body | `string` | no |
| `name` | body | `string` | no |
