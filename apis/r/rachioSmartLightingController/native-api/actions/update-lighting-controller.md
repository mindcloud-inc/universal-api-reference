# Update Lighting Controller with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/updateLightingController`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Update Lighting Controller](https://rachio.readme.io/reference/lightingservice_updatelightingcontroller)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `name` | body | `string` | no |
