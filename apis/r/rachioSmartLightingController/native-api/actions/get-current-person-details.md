# Get Current Person Details with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `GET`
- **Path:** `https://api.rach.io/1/public/person/:id`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Get Current Person Details](https://rachio.readme.io/reference/publicpersonid)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The person ID returned by Get Current Person ID. |
