# Activate Lighting Scene with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/activateLightingScene/:id`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Activate Lighting Scene](https://rachio.readme.io/reference/lightingservice_activatelightingscene)
