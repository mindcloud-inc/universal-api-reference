# Set Lighting Zone States with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `PUT`
- **Path:** `https://cloud-rest.rach.io/lighting/setLightingZoneStates`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Set Lighting Zone States](https://rachio.readme.io/reference/lightingservice_setlightingzonestates)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | body | `string` | no |
| `state` | body | `string` | no |
