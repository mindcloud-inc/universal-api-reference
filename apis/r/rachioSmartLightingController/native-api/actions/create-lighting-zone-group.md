# Create Lighting Zone Group with Rachio Smart Lighting Controller

## Endpoint

- **Method:** `POST`
- **Path:** `https://cloud-rest.rach.io/lighting/createLightingZoneGroup`
- **Base URL:** `https://cloud-rest.rach.io`
- **Official documentation:** [Create Lighting Zone Group](https://rachio.readme.io/reference/lightingservice_createlightingzonegroup)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `lighting_area_id` | body | `string` | no |
| `lighting_zone_ids` | body | `string` | no |
| `name` | body | `string` | no |
