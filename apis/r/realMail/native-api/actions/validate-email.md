# Validate Email with RealMail

Validates an email address with RealMail.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/validate`
- **Base URL:** `https://api.realmail.dev`
- **Official documentation:** [Validate Email](https://www.realmail.dev/docs)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | body | `string` | yes | Email address to validate. |
