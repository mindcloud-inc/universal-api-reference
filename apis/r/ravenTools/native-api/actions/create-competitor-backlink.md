# Create Competitor Backlink with Raven Tools

Creates a new competitor backlink in Raven Tools.

## Endpoint

- **Method:** `GET`
- **Path:** `/api`
- **Base URL:** `https://api.raventools.com`
- **Official documentation:** [Create Competitor Backlink](https://api.raventools.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link` | query | `string` | yes | JSON-encoded string for one competitor-backlink Raven link record. |
