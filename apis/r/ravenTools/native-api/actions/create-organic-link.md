# Create Organic Link with Raven Tools

Creates a new organic link in Raven Tools.

## Endpoint

- **Method:** `GET`
- **Path:** `/api`
- **Base URL:** `https://api.raventools.com`
- **Official documentation:** [Create Organic Link](https://api.raventools.com/docs/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `link` | query | `string` | yes | JSON-encoded string for one organic Raven link record. |
