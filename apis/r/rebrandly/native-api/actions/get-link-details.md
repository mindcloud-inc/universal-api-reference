# Get Link Details with Rebrandly

Retrieves details for a link in Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Get Link Details](https://developers.rebrandly.com/docs/get-link-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the branded short link. |
