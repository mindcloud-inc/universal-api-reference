# Get Domain Details with Rebrandly

Retrieves details for a domain in Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/domains/:id`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Get Domain Details](https://developers.rebrandly.com/docs/getting-single-domain-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the branded domain. |
