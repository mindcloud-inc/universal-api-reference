# Delete Tag with Rebrandly

Deletes an existing tag from Rebrandly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Delete Tag](https://developers.rebrandly.com/docs/deleting-a-tag)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the tag to permanently delete. |
