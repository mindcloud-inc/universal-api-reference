# List Traffic Rules with Rebrandly

Retrieves traffic rules for a link in Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id/rules`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [List Traffic Rules](https://developers.rebrandly.com/docs/advanced-link-options)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the branded short link. |
