# List Scripts with Rebrandly

Retrieves scripts from Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/scripts`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [List Scripts](https://developers.rebrandly.com/docs/listing-your-scripts)

## Capabilities

This operation supports [sorting](../README.md#sorting).
