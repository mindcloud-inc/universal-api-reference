# Get Tag Details with Rebrandly

Retrieves details for a tag in Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:id`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Get Tag Details](https://developers.rebrandly.com/docs/getting-tag-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the tag. |
