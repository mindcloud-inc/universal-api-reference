# Get Link OpenGraph with Rebrandly

Retrieves OpenGraph metadata for a link in Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `/links/:id/opengraph`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Get Link OpenGraph](https://developers.rebrandly.com/docs/managing-opengraph-metadata-for-links)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the branded short link. |
