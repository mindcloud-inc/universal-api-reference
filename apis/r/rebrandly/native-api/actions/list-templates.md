# List Templates with Rebrandly

Retrieves query string templates from Rebrandly.

## Endpoint

- **Method:** `GET`
- **Path:** `https://templating.rebrandly.com/v1/url/querystring/templates`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [List Templates](https://developers.rebrandly.com/docs/templates)
