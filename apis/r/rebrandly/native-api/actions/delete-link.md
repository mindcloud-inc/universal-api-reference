# Delete Link with Rebrandly

Deletes an existing link from Rebrandly.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/links/:id`
- **Base URL:** `https://api.rebrandly.com/v1`
- **Official documentation:** [Delete Link](https://developers.rebrandly.com/docs/delete-a-link)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Unique identifier of the branded short link to delete. |
