# GraphQL Query with Rasayel

Makes an authenticated raw GraphQL request to Rasayel.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.rasayel.io/api/graphql`
- **Official documentation:** [GraphQL Query](https://developers.rasayel.io/graphql/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Enter a Rasayel GraphQL query. |
