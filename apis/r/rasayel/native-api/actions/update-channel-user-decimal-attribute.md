# Update Channel User Decimal Attribute with Rasayel

Updates a decimal attribute on a Rasayel channel user.

## Endpoint

- **Method:** `POST`
- **Path:** `/`
- **Base URL:** `https://api.rasayel.io/api/graphql`
- **Official documentation:** [Update Channel User Decimal Attribute](https://developers.rasayel.io/graphql/api)
