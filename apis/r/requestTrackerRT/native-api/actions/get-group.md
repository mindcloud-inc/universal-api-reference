# Get Group with Request Tracker (RT)

Retrieves a group from Request Tracker.

## Endpoint

- **Method:** `GET`
- **Path:** `group/:groupId`
- **Base URL:** `https://try.requesttracker.io/sufongepl_57381/REST/2.0/`
- **Official documentation:** [Get Group](https://docs.bestpractical.com/rt/6.0.2/RT/REST2.html#Groups)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `groupId` | path | `string` | yes | The RT group ID. |
