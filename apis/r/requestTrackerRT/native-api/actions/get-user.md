# Get User with Request Tracker (RT)

Retrieves a user from Request Tracker.

## Endpoint

- **Method:** `GET`
- **Path:** `user/:userId`
- **Base URL:** `https://try.requesttracker.io/sufongepl_57381/REST/2.0/`
- **Official documentation:** [Get User](https://docs.bestpractical.com/rt/6.0.2/RT/REST2.html#Users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `userId` | path | `string` | yes | The RT user ID or username. |
