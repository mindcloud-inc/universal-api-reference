# Get Ticket with Request Tracker (RT)

Retrieves a ticket from Request Tracker.

## Endpoint

- **Method:** `GET`
- **Path:** `ticket/:ticketId`
- **Base URL:** `https://try.requesttracker.io/sufongepl_57381/REST/2.0/`
- **Official documentation:** [Get Ticket](https://docs.bestpractical.com/rt/6.0.2/RT/REST2.html#Tickets)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ticketId` | path | `string` | yes | The numeric RT ticket ID. |
