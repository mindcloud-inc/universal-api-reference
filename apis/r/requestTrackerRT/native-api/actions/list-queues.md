# List Queues with Request Tracker (RT)

Retrieves queues from Request Tracker.

## Endpoint

- **Method:** `GET`
- **Path:** `queues/all`
- **Base URL:** `https://try.requesttracker.io/sufongepl_57381/REST/2.0/`
- **Official documentation:** [List Queues](https://docs.bestpractical.com/rt/6.0.2/RT/REST2.html#Queues)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
