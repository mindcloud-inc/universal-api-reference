# List Connection Users with Rocketadmin

## Endpoint

- **Method:** `GET`
- **Path:** `/connection/users/:connectionId`
- **Base URL:** `https://app.rocketadmin.com/api`
- **Official documentation:** [List Connection Users](https://docs.rocketadmin.com/api-reference/connection-controller-find-all-users)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Rocketadmin connection identifier from the path. |
