# Get Connection with Rocketadmin

## Endpoint

- **Method:** `GET`
- **Path:** `/connection/one/:connectionId`
- **Base URL:** `https://app.rocketadmin.com/api`
- **Official documentation:** [Get Connection](https://docs.rocketadmin.com/api-reference/connection-controller-find-one)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Rocketadmin connection identifier from the path. |
