# Get API Key with Rocketadmin

## Endpoint

- **Method:** `GET`
- **Path:** `/apikey/:apiKeyId`
- **Base URL:** `https://app.rocketadmin.com/api`
- **Official documentation:** [Get API Key](https://docs.rocketadmin.com/api-reference/api-key-controller-get-api-key)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `apiKeyId` | path | `string` | yes | Rocketadmin API key identifier from the path. |
