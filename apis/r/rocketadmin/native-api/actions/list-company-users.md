# List Company Users with Rocketadmin

## Endpoint

- **Method:** `GET`
- **Path:** `/company/users/:companyId`
- **Base URL:** `https://app.rocketadmin.com/api`
- **Official documentation:** [List Company Users](https://docs.rocketadmin.com/api-reference/company-info-controller-get-users-in-company)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Rocketadmin company identifier from the path. |
