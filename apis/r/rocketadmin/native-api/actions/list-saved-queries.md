# List Saved Queries with Rocketadmin

## Endpoint

- **Method:** `GET`
- **Path:** `/connection/:connectionId/saved-queries`
- **Base URL:** `https://app.rocketadmin.com/api`
- **Official documentation:** [List Saved Queries](https://docs.rocketadmin.com/api-reference/saved-db-query-controller-find-all)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `connectionId` | path | `string` | yes | Rocketadmin connection identifier from the path. |
