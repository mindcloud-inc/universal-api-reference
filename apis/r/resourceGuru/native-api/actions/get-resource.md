# Get Resource with Resource Guru

Retrieves a resource from Resource Guru.

## Endpoint

- **Method:** `GET`
- **Path:** `/resources/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Get Resource](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Resource ID. |
