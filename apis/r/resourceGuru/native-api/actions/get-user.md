# Get User with Resource Guru

Retrieves a user from Resource Guru.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/{id}`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Get User](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
