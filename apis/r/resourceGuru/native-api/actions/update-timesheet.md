# Update Timesheet with Resource Guru

Updates an existing timesheet in Resource Guru.

## Endpoint

- **Method:** `PUT`
- **Path:** `/timesheets/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Update Timesheet](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Timesheet ID. |
