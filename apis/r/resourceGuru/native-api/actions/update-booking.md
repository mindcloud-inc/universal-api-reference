# Update Booking with Resource Guru

Updates an existing booking in Resource Guru.

## Endpoint

- **Method:** `PUT`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Update Booking](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Booking ID. |
