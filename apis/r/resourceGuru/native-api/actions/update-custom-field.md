# Update Custom Field with Resource Guru

Updates an existing custom field in Resource Guru.

## Endpoint

- **Method:** `PUT`
- **Path:** `/custom_fields/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Update Custom Field](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Custom field ID. |
