# Update Resource with Resource Guru

Updates an existing resource in Resource Guru.

## Endpoint

- **Method:** `PUT`
- **Path:** `/resources/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Update Resource](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Resource ID. |
