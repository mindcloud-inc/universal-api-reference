# Invite Resource with Resource Guru

Invites a resource in Resource Guru.

## Endpoint

- **Method:** `POST`
- **Path:** `/resources/:id/invite`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Invite Resource](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Resource ID. |
