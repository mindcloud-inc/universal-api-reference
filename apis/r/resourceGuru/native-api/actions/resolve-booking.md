# Resolve Booking with Resource Guru

Resolves a booking in Resource Guru.

## Endpoint

- **Method:** `POST`
- **Path:** `/bookings/:id/resolve`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Resolve Booking](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Booking ID. |
