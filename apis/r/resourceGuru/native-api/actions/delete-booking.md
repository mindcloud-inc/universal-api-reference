# Delete Booking with Resource Guru

Deletes an existing booking from Resource Guru.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/bookings/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Delete Booking](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Booking ID. |
