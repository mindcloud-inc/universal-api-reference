# Delete Custom Field with Resource Guru

Deletes an existing custom field from Resource Guru.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/custom_fields/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Delete Custom Field](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Custom field ID. |
