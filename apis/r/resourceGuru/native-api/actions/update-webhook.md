# Update Webhook with Resource Guru

Updates an existing webhook in Resource Guru.

## Endpoint

- **Method:** `PUT`
- **Path:** `/webhooks/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Update Webhook](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Webhook ID. |
