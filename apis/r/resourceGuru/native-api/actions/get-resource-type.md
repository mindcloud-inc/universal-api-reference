# Get Resource Type with Resource Guru

Retrieves a resource type from Resource Guru.

## Endpoint

- **Method:** `GET`
- **Path:** `/resource_types/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Get Resource Type](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Resource type ID. |
