# Get Client with Resource Guru

Retrieves a client from Resource Guru.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Get Client](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Client ID. |
