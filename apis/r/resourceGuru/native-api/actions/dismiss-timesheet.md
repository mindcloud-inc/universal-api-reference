# Dismiss Timesheet with Resource Guru

Dismisses a timesheet in Resource Guru.

## Endpoint

- **Method:** `POST`
- **Path:** `/timesheets/:id/dismiss`
- **Base URL:** `https://api.resourceguruapp.com/v1/{accountId}`
- **Official documentation:** [Dismiss Timesheet](https://resourceguruapp.com/docs/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Timesheet ID. |
