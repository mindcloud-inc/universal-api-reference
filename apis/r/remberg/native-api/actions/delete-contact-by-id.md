# Delete Contact By Id with remberg

Deletes a contact from remberg by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/contacts/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Contact By Id](https://developers.remberg.de/reference/contactscfacontroller_deleteone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID. |
