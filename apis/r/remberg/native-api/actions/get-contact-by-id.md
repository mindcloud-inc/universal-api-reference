# Get Contact By Id with remberg

Retrieves a contact from remberg by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/contacts/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Contact By Id](https://developers.remberg.de/reference/contactscfacontroller_findone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact ID. |
