# Delete Work Request By External Reference with remberg

Deletes a work request from remberg by external reference.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/work-requests/erp/{externalReference}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Work Request By External Reference](https://developers.remberg.de/reference/v1work-requestserpexternalreference_delete)
