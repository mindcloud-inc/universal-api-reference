# Delete Asset By Number with remberg

Deletes an asset from remberg by asset number.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/assets/number/{assetNumber}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Asset By Number](https://developers.remberg.de/reference/v2assetsnumberassetnumber_delete)
