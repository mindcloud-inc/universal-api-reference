# Get File By Id with remberg

Retrieves file metadata from remberg by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/files/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get File By Id](https://developers.remberg.de/reference/v1filesid_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | File ID. |
