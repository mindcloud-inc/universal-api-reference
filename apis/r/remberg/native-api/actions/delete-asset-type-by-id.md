# Delete Asset Type By Id with remberg

Deletes an asset type from remberg by internal ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/assets/types/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Asset Type By Id](https://developers.remberg.de/reference/v2assetstypesid_delete)
