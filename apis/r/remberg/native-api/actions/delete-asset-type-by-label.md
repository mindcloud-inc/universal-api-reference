# Delete Asset Type By Label with remberg

Deletes an asset type from remberg by label.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/assets/types/label/{assetTypeLabel}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Asset Type By Label](https://developers.remberg.de/reference/v2assetstypeslabelassettypelabel_delete)
