# Approve Work Request By External Reference with remberg

Approves a work request in remberg by external reference.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/work-requests/erp/{externalReference}/approve`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Approve Work Request By External Reference](https://developers.remberg.de/reference/v1work-requestserpexternalreferenceapprove_patch)
