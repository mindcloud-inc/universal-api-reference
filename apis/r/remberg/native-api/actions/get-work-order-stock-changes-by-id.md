# Get Work Order Stock Changes By Id with remberg

Retrieves stock changes for a remberg work order by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/work-orders/{id}/stock-changes`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Order Stock Changes By Id](https://developers.remberg.de/reference/v2work-ordersidstock-changes_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Work order ID. |
