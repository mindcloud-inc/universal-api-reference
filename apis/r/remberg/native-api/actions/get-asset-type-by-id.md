# Get Asset Type By Id with remberg

Retrieves an asset type from remberg by internal ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/assets/types/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Asset Type By Id](https://developers.remberg.de/reference/v2assetstypesid_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Resource ID. |
