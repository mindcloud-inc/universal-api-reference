# Decline Work Request By External Reference with remberg

Declines a work request in remberg by external reference.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/work-requests/erp/{externalReference}/decline`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Decline Work Request By External Reference](https://developers.remberg.de/reference/v1work-requestserpexternalreferencedecline_patch)
