# Approve Work Request By Id with remberg

Approves a work request in remberg by internal ID.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/work-requests/{id}/approve`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Approve Work Request By Id](https://developers.remberg.de/reference/v1work-requestsidapprove_patch)
