# Get Ticket By Id with remberg

Retrieves a ticket from remberg by internal ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tickets/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Ticket By Id](https://developers.remberg.de/reference/v2ticketsid_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ticket ID. |
