# Decline Work Request By Id with remberg

Declines a work request in remberg by internal ID.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/v1/work-requests/{id}/decline`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Decline Work Request By Id](https://developers.remberg.de/reference/v1work-requestsiddecline_patch)
