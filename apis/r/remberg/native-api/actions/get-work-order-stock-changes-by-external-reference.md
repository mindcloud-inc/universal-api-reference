# Get Work Order Stock Changes By External Reference with remberg

Retrieves stock changes for a remberg work order by external reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/work-orders/erp/{externalReference}/stock-changes`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Order Stock Changes By External Reference](https://developers.remberg.de/reference/v2work-orderserpexternalreferencestock-changes_get)
