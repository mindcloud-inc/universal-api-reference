# Get Work Order By External Reference with remberg

Retrieves a work order from remberg by external reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/work-orders/erp/{externalReference}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Order By External Reference](https://developers.remberg.de/reference/v2work-orderserpexternalreference_get)
