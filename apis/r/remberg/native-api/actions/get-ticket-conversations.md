# Get Ticket Conversations with remberg

Retrieves conversations for a remberg ticket.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/tickets/{id}/conversations`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Ticket Conversations](https://developers.remberg.de/reference/v2ticketsidconversations_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ticket ID. |
