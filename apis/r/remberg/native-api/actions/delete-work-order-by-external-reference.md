# Delete Work Order By External Reference with remberg

Deletes a work order from remberg by external reference.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/work-orders/erp/{externalReference}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Work Order By External Reference](https://developers.remberg.de/reference/v2work-orderserpexternalreference_delete)
