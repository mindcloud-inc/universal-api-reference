# Get Work Order By Id with remberg

Retrieves a work order from remberg by internal ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/work-orders/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Order By Id](https://developers.remberg.de/reference/v2work-ordersid_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Work order ID. |
