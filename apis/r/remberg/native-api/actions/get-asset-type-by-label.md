# Get Asset Type By Label with remberg

Retrieves an asset type from remberg by label.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/assets/types/label/{assetTypeLabel}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Asset Type By Label](https://developers.remberg.de/reference/v2assetstypeslabelassettypelabel_get)
