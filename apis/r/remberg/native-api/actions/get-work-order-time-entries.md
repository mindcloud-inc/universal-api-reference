# Get Work Order Time Entries with remberg

Retrieves time entries for a remberg work order.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/work-orders/{id}/times`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Order Time Entries](https://developers.remberg.de/reference/v2work-ordersidtimes_get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Work order ID. |
