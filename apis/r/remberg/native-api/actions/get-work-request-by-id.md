# Get Work Request By Id with remberg

Retrieves a work request from remberg by internal ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/work-requests/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Request By Id](https://developers.remberg.de/reference/v1work-requestsid_get)
