# Get Work Request By External Reference with remberg

Retrieves a work request from remberg by external reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/work-requests/erp/{externalReference}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Work Request By External Reference](https://developers.remberg.de/reference/v1work-requestserpexternalreference_get)
