# Get Asset By Number with remberg

Retrieves an asset from remberg by asset number.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/assets/number/{assetNumber}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Asset By Number](https://developers.remberg.de/reference/v2assetsnumberassetnumber_get)
