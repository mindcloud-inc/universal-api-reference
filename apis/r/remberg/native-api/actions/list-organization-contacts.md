# List Organization Contacts with remberg

Retrieves contacts for an organization from remberg.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/{id}/contacts`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [List Organization Contacts](https://developers.remberg.de/reference/organizationscfacontroller_findmanycontacts)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Organization ID. |
