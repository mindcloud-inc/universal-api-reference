# Delete Organization By Id with remberg

Deletes an organization from remberg by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/organizations/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Organization By Id](https://developers.remberg.de/reference/organizationscfacontroller_deleteone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Organization ID. |
