# Delete Ticket By Id with remberg

Deletes a ticket from remberg by internal ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/tickets/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Ticket By Id](https://developers.remberg.de/reference/v2ticketsid_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Ticket ID. |
