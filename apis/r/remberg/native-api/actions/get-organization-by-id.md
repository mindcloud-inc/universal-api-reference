# Get Organization By Id with remberg

Retrieves an organization from remberg by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/organizations/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Get Organization By Id](https://developers.remberg.de/reference/organizationscfacontroller_findone)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Organization ID. |
