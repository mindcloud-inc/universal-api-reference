# Delete Work Order By Id with remberg

Deletes a work order from remberg by internal ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/work-orders/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Work Order By Id](https://developers.remberg.de/reference/v2work-ordersid_delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Work order ID. |
