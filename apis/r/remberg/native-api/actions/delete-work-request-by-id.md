# Delete Work Request By Id with remberg

Deletes a work request from remberg by internal ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/work-requests/{id}`
- **Base URL:** `https://api.remberg.de`
- **Official documentation:** [Delete Work Request By Id](https://developers.remberg.de/reference/v1work-requestsid_delete)
