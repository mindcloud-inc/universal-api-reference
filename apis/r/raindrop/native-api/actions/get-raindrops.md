# Get Raindrops with Raindrop

## Endpoint

- **Method:** `GET`
- **Path:** `/raindrops/:collectionId`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Get Raindrops](https://developer.raindrop.io/v1/raindrops/multiple)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | no | Collection ID. Use 0 for all raindrops except Trash. |
