# Get Tags with Raindrop

## Endpoint

- **Method:** `GET`
- **Path:** `/tags/:collectionId`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Get Tags](https://developer.raindrop.io/v1/tags)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | no | Collection ID. Use 0 for all raindrops except Trash. |
