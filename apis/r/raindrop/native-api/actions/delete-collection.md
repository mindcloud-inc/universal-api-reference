# Delete Collection with Raindrop

## Endpoint

- **Method:** `DELETE`
- **Path:** `/collection/:id`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Delete Collection](https://developer.raindrop.io/v1/collections/methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Existing collection ID. |
