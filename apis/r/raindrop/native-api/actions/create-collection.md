# Create Collection with Raindrop

## Endpoint

- **Method:** `POST`
- **Path:** `/collection`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Create Collection](https://developer.raindrop.io/v1/collections/methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | `string` | no | Name of the collection. |
