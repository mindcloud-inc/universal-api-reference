# Get Raindrop with Raindrop

## Endpoint

- **Method:** `GET`
- **Path:** `/raindrop/:id`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Get Raindrop](https://developer.raindrop.io/v1/raindrops/single)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | no | Existing raindrop ID. |
