# Set Collections Expanded State with Raindrop

## Endpoint

- **Method:** `PUT`
- **Path:** `/collections`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Set Collections Expanded State](https://developer.raindrop.io/v1/collections/methods)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `expanded` | body | `boolean` | yes | Set true to expand all collections and false to collapse them. |
