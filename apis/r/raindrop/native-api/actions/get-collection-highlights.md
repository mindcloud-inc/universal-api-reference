# Get Collection Highlights with Raindrop

## Endpoint

- **Method:** `GET`
- **Path:** `/highlights/:collectionId`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Get Collection Highlights](https://developer.raindrop.io/v1/highlights)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collectionId` | path | `string` | no | Collection ID to list highlights from. |
