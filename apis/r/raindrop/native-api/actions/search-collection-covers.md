# Search Collection Covers with Raindrop

## Endpoint

- **Method:** `GET`
- **Path:** `/collections/covers/:text`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Search Collection Covers](https://developer.raindrop.io/v1/collections/covers-icons)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | path | `string` | no | The text prompt used to search collection covers. |
