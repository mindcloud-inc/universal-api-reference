# Create Raindrop with Raindrop

## Endpoint

- **Method:** `POST`
- **Path:** `/raindrop`
- **Base URL:** `https://api.raindrop.io/rest/v1`
- **Official documentation:** [Create Raindrop](https://developer.raindrop.io/v1/raindrops/single)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `collection.$id` | body | `string` | no | Destination collection ID. |
| `link` | body | `string` | no | Bookmark URL. |
| `title` | body | `string` | no | Bookmark title. |
