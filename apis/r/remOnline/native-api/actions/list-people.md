# List People with RemOnline

Retrieves a list of people from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/people`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List People](https://roappua.readme.io/reference/get-people)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
