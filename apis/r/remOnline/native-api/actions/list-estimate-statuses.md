# List Estimate Statuses with RemOnline

Retrieves a list of estimate statuses from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates/statuses`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List Estimate Statuses](https://roappua.readme.io/reference/get-estimate-statuses)
