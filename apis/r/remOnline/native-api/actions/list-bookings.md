# List Bookings with RemOnline

Retrieves a list of bookings from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/bookings`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List Bookings](https://roappua.readme.io/reference/get-bookings)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
