# Get Person By ID with RemOnline

Retrieves a person from RemOnline by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/people/:person_id`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [Get Person By ID](https://roappua.readme.io/reference/get-person-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `number` | yes | ID of the person. |
