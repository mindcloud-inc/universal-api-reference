# List Estimates with RemOnline

Retrieves a list of estimates from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List Estimates](https://roappua.readme.io/reference/get-estimates)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
