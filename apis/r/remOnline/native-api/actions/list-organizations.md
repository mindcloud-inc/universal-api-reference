# List Organizations with RemOnline

Retrieves a list of organizations from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/contacts/organizations`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List Organizations](https://roappua.readme.io/reference/get-organizations)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
