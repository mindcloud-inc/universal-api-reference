# List Orders with RemOnline

Retrieves a list of orders from RemOnline.

## Endpoint

- **Method:** `GET`
- **Path:** `/orders`
- **Base URL:** `https://api.roapp.io`
- **Official documentation:** [List Orders](https://roappua.readme.io/reference/get-orders)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [sorting](../README.md#sorting).
