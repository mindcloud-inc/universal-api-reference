# Delete Video (V2) with Reka Vision

Deletes a video from Reka Vision.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/videos/:videoId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Delete Video (V2)](https://docs.reka.ai/vision/api-reference/v-2/delete-video-v-2-videos-video-id-delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `video_id` | path | `string` | yes |
