# Get Feature Catalog (V2) with Reka Vision

Retrieves the feature catalog from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/features`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Get Feature Catalog (V2)](https://docs.reka.ai/vision/api-reference/v-2/get-feature-catalog-v-2-features-get)
