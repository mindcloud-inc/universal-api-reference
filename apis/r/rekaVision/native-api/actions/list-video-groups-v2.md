# List Video Groups (V2) with Reka Vision

Retrieves video groups from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/video-groups`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Video Groups (V2)](https://docs.reka.ai/vision/api-reference/v-2/list-video-groups-v-2-video-groups-get)
