# List Reels (V1) with Reka Vision

Retrieves reel generations from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/clips`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Reels (V1)](https://docs.reka.ai/vision/api-reference/v-1/list-reels-v-1-clips-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `offset` | query | `number` | no |
| `limit` | query | `number` | no |
| `status` | query | `string` | no |
