# List Images (V1) with Reka Vision

Retrieves images from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/images`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Images (V1)](https://docs.reka.ai/vision/api-reference/v-1/get-images)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `limit` | query | `number` | no |
| `offset` | query | `number` | no |
