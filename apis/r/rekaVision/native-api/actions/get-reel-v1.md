# Get Reel (V1) with Reka Vision

Retrieves a reel generation status from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/clips/:id`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Get Reel (V1)](https://docs.reka.ai/vision/api-reference/v-1/get-reel-v-1-clips-id-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
