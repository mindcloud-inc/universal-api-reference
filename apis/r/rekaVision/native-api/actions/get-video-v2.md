# Get Video (V2) with Reka Vision

Retrieves video details from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/videos/:videoId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Get Video (V2)](https://docs.reka.ai/vision/api-reference/v-2/get-video-v-2-videos-video-id-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `video_id` | path | `string` | yes |
