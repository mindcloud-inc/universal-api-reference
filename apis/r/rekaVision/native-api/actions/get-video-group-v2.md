# Get Video Group (V2) with Reka Vision

Retrieves a video group from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/video-groups/:groupId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Get Video Group (V2)](https://docs.reka.ai/vision/api-reference/v-2/get-video-group-v-2-video-groups-group-id-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | yes |
