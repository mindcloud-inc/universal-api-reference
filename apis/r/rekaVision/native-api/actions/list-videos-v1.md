# List Videos (V1) with Reka Vision

Retrieves videos from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Videos (V1)](https://docs.reka.ai/vision/api-reference/v-1/get-videos)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids[]` | query | `array<string>` | no |
