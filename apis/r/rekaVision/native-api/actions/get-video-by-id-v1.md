# Get Video By Id (V1) with Reka Vision

Retrieves a video from Reka Vision by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/videos/:videoId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Get Video By Id (V1)](https://docs.reka.ai/vision/api-reference/v-1/get-video)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `video_id` | path | `string` | yes |
