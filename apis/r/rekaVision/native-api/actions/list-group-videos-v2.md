# List Group Videos (V2) with Reka Vision

Retrieves videos from a Reka Vision group.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/video-groups/:groupId/videos`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Group Videos (V2)](https://docs.reka.ai/vision/api-reference/v-2/list-group-videos-v-2-video-groups-group-id-videos-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | yes |
