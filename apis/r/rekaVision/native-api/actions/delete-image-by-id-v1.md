# Delete Image By Id (V1) with Reka Vision

Deletes an image from Reka Vision by ID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/images/:imageId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Delete Image By Id (V1)](https://docs.reka.ai/vision/api-reference/v-1/delete-image)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `image_id` | path | `string` | yes |
