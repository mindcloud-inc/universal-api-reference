# Delete Video Group (V2) with Reka Vision

Deletes an existing video group from Reka Vision.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v2/video-groups/:groupId`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [Delete Video Group (V2)](https://docs.reka.ai/vision/api-reference/v-2/delete-video-group-v-2-video-groups-group-id-delete)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `group_id` | path | `string` | yes |
