# List Videos (V2) with Reka Vision

Retrieves videos from Reka Vision.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/videos`
- **Base URL:** `https://vision-agent.api.reka.ai`
- **Official documentation:** [List Videos (V2)](https://docs.reka.ai/vision/api-reference/v-2/list-videos-v-2-videos-get)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `ids[]` | query | `array<string>` | no |
