# Get OAI Record with Rijksmuseum

## Endpoint

- **Method:** `GET`
- **Path:** `/oai`
- **Base URL:** `https://data.rijksmuseum.nl`
- **Official documentation:** [Get OAI Record](https://data.rijksmuseum.nl/docs/oai-pmh/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `identifier` | query | `string` | yes | Full OAI-PMH object identifier URI, such as https://id.rijksmuseum.nl/200107928. |
