# Get Contact with RD Station CRM

Retrieves contact details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Contact](https://developers.rdstation.com/reference/crm-v2-get-contact)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Contact identifier. |
