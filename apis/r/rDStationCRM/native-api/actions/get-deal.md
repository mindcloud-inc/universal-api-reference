# Get Deal with RD Station CRM

Retrieves deal details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Deal](https://developers.rdstation.com/reference/crm-v2-get-deal)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Deal identifier. |
