# Get Organization with RD Station CRM

Retrieves organization details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Organization](https://developers.rdstation.com/reference/crm-v2-get-organization)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Organization identifier. |
