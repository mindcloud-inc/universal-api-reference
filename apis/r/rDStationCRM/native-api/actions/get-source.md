# Get Source with RD Station CRM

Retrieves a deal source from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Source](https://developers.rdstation.com/reference/crm-v2-get-source)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Source identifier. |
