# Get Task with RD Station CRM

Retrieves task details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Task](https://developers.rdstation.com/reference/crm-v2-get-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Task identifier. |
