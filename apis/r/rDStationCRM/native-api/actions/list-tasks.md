# List Tasks with RD Station CRM

Retrieves tasks from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Tasks](https://developers.rdstation.com/reference/crm-v2-list-tasks)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
