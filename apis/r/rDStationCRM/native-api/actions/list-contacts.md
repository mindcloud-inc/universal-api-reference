# List Contacts with RD Station CRM

Retrieves contacts from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Contacts](https://developers.rdstation.com/reference/crm-v2-list-contacts)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
