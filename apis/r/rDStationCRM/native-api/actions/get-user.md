# Get User with RD Station CRM

Retrieves user details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get User](https://developers.rdstation.com/reference/crm-v2-get-user)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | User identifier. |
