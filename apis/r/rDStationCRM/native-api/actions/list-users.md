# List Users with RD Station CRM

Retrieves users from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Users](https://developers.rdstation.com/reference/crm-v2-list-users)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
