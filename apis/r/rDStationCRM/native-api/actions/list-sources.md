# List Sources with RD Station CRM

Retrieves deal sources from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/sources`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Sources](https://developers.rdstation.com/reference/crm-v2-list-sources)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
