# List Organizations with RD Station CRM

Retrieves organizations from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/organizations`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Organizations](https://developers.rdstation.com/reference/crm-v2-list-organizations)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
