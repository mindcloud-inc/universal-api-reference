# Get Pipeline with RD Station CRM

Retrieves sales pipeline details from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/pipelines/:id`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [Get Pipeline](https://developers.rdstation.com/reference/crm-v2-get-pipeline)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Pipeline identifier. |
