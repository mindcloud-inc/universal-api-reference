# List Deals with RD Station CRM

Retrieves deals from RD Station CRM.

## Endpoint

- **Method:** `GET`
- **Path:** `/deals`
- **Base URL:** `https://api.rd.services/crm/v2`
- **Official documentation:** [List Deals](https://developers.rdstation.com/reference/crm-v2-list-deals)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
