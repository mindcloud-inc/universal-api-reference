# Get Project with Runrun.it

Retrieves a project from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get Project](https://runrun.it/api/documentation#projects-show-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
