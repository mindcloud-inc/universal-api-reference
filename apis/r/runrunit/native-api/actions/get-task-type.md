# Get Task Type with Runrun.it

Retrieves a task type from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/task_types/:id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get Task Type](https://runrun.it/api/documentation#tasktype-show-a-task-type)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
