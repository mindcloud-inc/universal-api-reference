# List Users with Runrun.it

Retrieves users from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/users`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [List Users](https://runrun.it/api/documentation#users-list-all-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
