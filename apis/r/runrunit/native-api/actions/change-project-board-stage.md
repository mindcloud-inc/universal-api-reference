# Change Project Board Stage with Runrun.it

Updates a project's board stage in Runrun.it.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:id/change_board_stage`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Change Project Board Stage](https://runrun.it/api/documentation#projects-change-a-project-board-stage)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
