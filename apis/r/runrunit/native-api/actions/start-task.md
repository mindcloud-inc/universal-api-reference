# Start Task with Runrun.it

Starts a task in Runrun.it.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks/:id/play`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Start Task](https://runrun.it/api/documentation#tasks-play-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
