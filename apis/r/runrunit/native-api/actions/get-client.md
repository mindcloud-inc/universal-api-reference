# Get Client with Runrun.it

Retrieves a client from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/clients/:id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get Client](https://runrun.it/api/documentation#clients-show-a-client)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
