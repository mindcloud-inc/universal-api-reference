# List Project Users with Runrun.it

Retrieves users related to a project in Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects/:id/related_users`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [List Project Users](https://runrun.it/api/documentation#projects-list-users-related-in-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
