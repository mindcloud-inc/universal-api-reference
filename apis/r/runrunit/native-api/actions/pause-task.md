# Pause Task with Runrun.it

Pauses a task in Runrun.it.

## Endpoint

- **Method:** `POST`
- **Path:** `/tasks/:id/pause`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Pause Task](https://runrun.it/api/documentation#tasks-pause-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
