# Get Task with Runrun.it

Retrieves a task from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/tasks/:id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get Task](https://runrun.it/api/documentation#tasks-show-a-task)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
