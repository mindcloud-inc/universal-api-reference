# Get User with Runrun.it

Retrieves a user from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/users/:user_id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get User](https://runrun.it/api/documentation#users-get-a-user-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `user_id` | path | `string` | yes | User Id path parameter. |
