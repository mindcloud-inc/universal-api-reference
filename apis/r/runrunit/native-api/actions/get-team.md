# Get Team with Runrun.it

Retrieves a team from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/teams/:id`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Get Team](https://runrun.it/api/documentation#teams-show-a-team)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
