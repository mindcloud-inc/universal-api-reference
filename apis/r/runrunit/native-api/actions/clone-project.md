# Clone Project with Runrun.it

Creates a new project by cloning a Runrun.it project.

## Endpoint

- **Method:** `POST`
- **Path:** `/projects/:id/clone`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [Clone Project](https://runrun.it/api/documentation#projects-clone-a-project)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id path parameter. |
