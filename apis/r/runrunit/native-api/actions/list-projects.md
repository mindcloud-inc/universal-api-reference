# List Projects with Runrun.it

Retrieves projects from Runrun.it.

## Endpoint

- **Method:** `GET`
- **Path:** `/projects`
- **Base URL:** `https://runrun.it/api/v1.0`
- **Official documentation:** [List Projects](https://runrun.it/api/documentation#projects-list-all-projects)

## Capabilities

This operation supports [pagination](../README.md#pagination).
