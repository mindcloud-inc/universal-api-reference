# Get CDP Plus User List Sizes by Segment and Date with RollWorks

Retrieves CDP Plus user list sizes in RollWorks by segment and date.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-lists/api/v1/userlists/segment/cdp_plus`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get CDP Plus User List Sizes by Segment and Date](https://apidocs.nextroll.com/user-lists-api/reference.html#get--user-lists-api-v1-userlists-segment-cdp_plus)
