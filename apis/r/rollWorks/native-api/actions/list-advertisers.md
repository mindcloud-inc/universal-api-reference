# List Advertisers with RollWorks

Retrieves advertisers from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/advertisers`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Advertisers](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-advertisers)
