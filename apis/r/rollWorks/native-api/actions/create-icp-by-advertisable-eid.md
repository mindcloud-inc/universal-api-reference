# Create ICP by Advertisable EID with RollWorks

Creates an ideal customer profile in RollWorks by advertisable EID.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/ideal_customer_profile`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Create ICP by Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-ideal_customer_profile)
