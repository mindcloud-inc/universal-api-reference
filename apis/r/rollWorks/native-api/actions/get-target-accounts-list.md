# Get Target Accounts List with RollWorks

Retrieves a target account list from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/:tal_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Target Accounts List](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-(tal_eid))
