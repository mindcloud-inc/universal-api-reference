# List Valid and Invalid Segments for Crosschannel LAL Targeting with RollWorks

Retrieves valid and invalid segments for RollWorks crosschannel LAL targeting.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/crosschannel_lal_segments/valid-segments`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Valid and Invalid Segments for Crosschannel LAL Targeting](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-crosschannel_lal_segments-valid-segments)
