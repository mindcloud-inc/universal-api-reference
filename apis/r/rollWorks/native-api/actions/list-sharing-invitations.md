# List Sharing Invitations with RollWorks

Retrieves sharing invitations from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/sharing/invitation`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Sharing Invitations](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-sharing-invitation)
