# Get Source Segment for Sharing Invitation with RollWorks

Retrieves the source segment for a RollWorks sharing invitation.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/sharing/get_source_segment`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Source Segment for Sharing Invitation](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-sharing-get_source_segment)
