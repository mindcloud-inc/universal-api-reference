# Get Target Accounts Tier with RollWorks

Retrieves a target account tier from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers/:ta_tier_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Target Accounts Tier](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-(tal_eid)-tiers-(ta_tier_eid))
