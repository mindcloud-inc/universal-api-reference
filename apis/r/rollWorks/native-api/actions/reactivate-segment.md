# Reactivate Segment with RollWorks

Reactivates a segment in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/segments/:segment_id/reactivate`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Reactivate Segment](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-segments-(segment_id)-reactivate)
