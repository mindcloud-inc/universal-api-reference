# Update Target Accounts List Items with RollWorks

Updates target account list items in RollWorks.

## Endpoint

- **Method:** `PUT`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers/:ta_tier_eid/items`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Update Target Accounts List Items](https://apidocs.nextroll.com/audience-api/reference.html#put--audience-v1-target_accounts-(tal_eid)-tiers-(ta_tier_eid)-items)
