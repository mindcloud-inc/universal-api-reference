# Delete Segment with RollWorks

Deletes a segment from RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/segments/:segment_id`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Delete Segment](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-segments-(segment_id))
