# List Target Accounts Items with RollWorks

Retrieves target account items from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers/:ta_tier_eid/items`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Target Accounts Items](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-(tal_eid)-tiers-(ta_tier_eid)-items)
