# Create Target Accounts Tier with RollWorks

Creates a target account tier in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Create Target Accounts Tier](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-target_accounts-(tal_eid)-tiers)
