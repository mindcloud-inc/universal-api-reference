# List User Attributes by Advertisable with RollWorks

Retrieves user attributes from RollWorks by advertisable.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/user_attribute_names/:advertisable_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List User Attributes by Advertisable](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-user_attribute_names-(advertisable_eid))
