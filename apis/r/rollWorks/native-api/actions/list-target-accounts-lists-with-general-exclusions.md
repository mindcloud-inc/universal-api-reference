# List Target Accounts Lists with General Exclusions with RollWorks

Retrieves target account lists with general exclusions from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/general_exclusions`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Target Accounts Lists with General Exclusions](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-general_exclusions)
