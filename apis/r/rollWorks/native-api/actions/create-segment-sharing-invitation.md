# Create Segment Sharing Invitation with RollWorks

Creates a segment sharing invitation in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/sharing/invitation`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Create Segment Sharing Invitation](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-sharing-invitation)
