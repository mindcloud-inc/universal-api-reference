# List User Attribute Segments by TAL Reference with RollWorks

Retrieves user attribute segments in RollWorks by TAL reference.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/segments/tal_references`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List User Attribute Segments by TAL Reference](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-segments-tal_references)
