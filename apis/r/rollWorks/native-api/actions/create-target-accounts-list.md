# Create Target Accounts List with RollWorks

Creates a target account list in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/target_accounts`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Create Target Accounts List](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-target_accounts)
