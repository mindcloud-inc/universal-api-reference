# List Domains in Target Account Lists with RollWorks

Retrieves domains in RollWorks target account lists.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/domains`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Domains in Target Account Lists](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-domains)
