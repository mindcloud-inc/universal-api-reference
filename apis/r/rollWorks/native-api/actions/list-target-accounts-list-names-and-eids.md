# List Target Accounts List Names and EIDs with RollWorks

Retrieves target account list names and EIDs from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/names`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Target Accounts List Names and EIDs](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-names)
