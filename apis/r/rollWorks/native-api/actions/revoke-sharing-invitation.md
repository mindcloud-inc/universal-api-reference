# Revoke Sharing Invitation with RollWorks

Revokes a sharing invitation in RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/sharing/invitation`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Revoke Sharing Invitation](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-sharing-invitation)
