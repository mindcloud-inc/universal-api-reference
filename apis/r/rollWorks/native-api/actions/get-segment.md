# Get Segment with RollWorks

Retrieves a segment from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/segments/:segment_id`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Segment](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-segments-(segment_id))
