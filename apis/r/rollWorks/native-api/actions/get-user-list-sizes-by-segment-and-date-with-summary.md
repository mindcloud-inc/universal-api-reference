# Get User List Sizes by Segment and Date with Summary with RollWorks

Retrieves user list sizes in RollWorks by segment and date.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-lists/api/v1/userlists/segment`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get User List Sizes by Segment and Date with Summary](https://apidocs.nextroll.com/user-lists-api/reference.html#get--user-lists-api-v1-userlists-segment)
