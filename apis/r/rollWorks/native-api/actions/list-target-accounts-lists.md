# List Target Accounts Lists with RollWorks

Retrieves target account lists from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Target Accounts Lists](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts)
