# List Scores by TAL EID and Advertisable EID with RollWorks

Retrieves ICP scores in RollWorks by TAL and advertisable EID.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/ideal_customer_profile/all_scores`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Scores by TAL EID and Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-ideal_customer_profile-all_scores)
