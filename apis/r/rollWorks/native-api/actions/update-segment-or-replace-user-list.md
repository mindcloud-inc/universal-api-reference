# Update Segment or Replace User List with RollWorks

Updates a segment or replaces its user list in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/segments/:segment_id`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Update Segment or Replace User List](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-segments-(segment_id))
