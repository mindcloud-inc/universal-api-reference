# Get User List Sizes by Ad and Date with RollWorks

Retrieves user list sizes in RollWorks by ad and date.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-lists/api/v1/userlists/ad`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get User List Sizes by Ad and Date](https://apidocs.nextroll.com/user-lists-api/reference.html#get--user-lists-api-v1-userlists-ad)
