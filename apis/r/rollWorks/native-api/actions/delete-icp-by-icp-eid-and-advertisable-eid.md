# Delete ICP by ICP EID and Advertisable EID with RollWorks

Deletes an ideal customer profile from RollWorks by ICP and advertisable EID.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/ideal_customer_profile/:icp_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Delete ICP by ICP EID and Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-ideal_customer_profile-(icp_eid))
