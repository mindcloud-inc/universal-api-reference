# Get Exact User Counts by Date and Metric with RollWorks

Retrieves exact user counts in RollWorks by date and metric.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-lists/api/v1/userlists/segment/exact`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Exact User Counts by Date and Metric](https://apidocs.nextroll.com/user-lists-api/reference.html#get--user-lists-api-v1-userlists-segment-exact)
