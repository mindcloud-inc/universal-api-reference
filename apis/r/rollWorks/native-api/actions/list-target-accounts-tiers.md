# List Target Accounts Tiers with RollWorks

Retrieves target account tiers from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Target Accounts Tiers](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-target_accounts-(tal_eid)-tiers)
