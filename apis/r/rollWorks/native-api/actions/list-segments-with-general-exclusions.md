# List Segments with General Exclusions with RollWorks

Retrieves segments with general exclusions from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/segments/general_exclusions`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Segments with General Exclusions](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-segments-general_exclusions)
