# Delete Target Accounts List Items by Delete Route with RollWorks

Deletes target account list items from RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers/:ta_tier_eid/items`
- **Base URL:** `https://services.adroll.com`
