# Update ICP by ICP EID and Advertisable EID with RollWorks

Updates an ideal customer profile in RollWorks by ICP and advertisable EID.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/ideal_customer_profile/:icp_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Update ICP by ICP EID and Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-ideal_customer_profile-(icp_eid))
