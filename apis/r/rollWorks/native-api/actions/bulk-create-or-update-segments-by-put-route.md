# Bulk Create Or Update Segments by Put Route with RollWorks

Creates or updates segments in bulk in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/segments_bulk/put`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Bulk Create Or Update Segments by Put Route](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-segments_bulk-put)
