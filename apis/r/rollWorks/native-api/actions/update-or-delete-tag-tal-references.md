# Update Or Delete TAG TAL References with RollWorks

Updates or deletes TAG TAL references in RollWorks.

## Endpoint

- **Method:** `PUT`
- **Path:** `/audience/v1/segments/tal_references`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Update Or Delete TAG TAL References](https://apidocs.nextroll.com/audience-api/reference.html#put--audience-v1-segments-tal_references)
