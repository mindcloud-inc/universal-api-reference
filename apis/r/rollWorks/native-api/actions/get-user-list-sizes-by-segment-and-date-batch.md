# Get User List Sizes by Segment and Date Batch with RollWorks

Retrieves user list sizes in RollWorks by segment and date batch.

## Endpoint

- **Method:** `POST`
- **Path:** `/user-lists/api/v1/userlists/segment`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get User List Sizes by Segment and Date Batch](https://apidocs.nextroll.com/user-lists-api/reference.html#post--user-lists-api-v1-userlists-segment)
