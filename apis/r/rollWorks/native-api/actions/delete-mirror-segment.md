# Delete Mirror Segment with RollWorks

Deletes a mirror segment from RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/sharing/segment`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Delete Mirror Segment](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-sharing-segment)
