# Create Segment with RollWorks

Creates a new segment in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/segments`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Create Segment](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-segments)
