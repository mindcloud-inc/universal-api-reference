# Get User Attribute Counts by Name and Value with RollWorks

Retrieves user attribute counts in RollWorks by name and value.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/user_attribute_counts`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get User Attribute Counts by Name and Value](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-user_attribute_counts)
