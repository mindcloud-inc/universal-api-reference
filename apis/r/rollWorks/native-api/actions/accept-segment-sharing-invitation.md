# Accept Segment Sharing Invitation with RollWorks

Accepts a segment sharing invitation in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/sharing/segment`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Accept Segment Sharing Invitation](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-sharing-segment)
