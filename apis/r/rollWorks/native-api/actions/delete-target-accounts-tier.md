# Delete Target Accounts Tier with RollWorks

Deletes a target account tier from RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/target_accounts/:tal_eid/tiers/:ta_tier_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Delete Target Accounts Tier](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-target_accounts-(tal_eid)-tiers-(ta_tier_eid))
