# Update Target Accounts List with RollWorks

Updates a target account list in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/target_accounts/:tal_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Update Target Accounts List](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-target_accounts-(tal_eid))
