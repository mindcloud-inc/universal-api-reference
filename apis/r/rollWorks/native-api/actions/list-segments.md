# List Segments with RollWorks

Retrieves segments from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/segments`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List Segments](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-segments)
