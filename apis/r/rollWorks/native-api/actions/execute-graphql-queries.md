# Execute GraphQL queries with RollWorks

Executes a GraphQL query in RollWorks.

## Endpoint

- **Method:** `POST`
- **Path:** `/reporting/api/v1/query`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Execute GraphQL queries](https://apidocs.nextroll.com/graphql-reporting-api/reference.html#post--reporting-api-v1-query)
