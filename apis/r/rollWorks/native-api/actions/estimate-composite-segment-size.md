# Estimate Composite Segment Size with RollWorks

Retrieves a composite segment size estimate from RollWorks.

## Endpoint

- **Method:** `GET`
- **Path:** `/user-lists/api/v1/userlists/audience_preview`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Estimate Composite Segment Size](https://apidocs.nextroll.com/user-lists-api/reference.html#get--user-lists-api-v1-userlists-audience_preview)
