# List ICPs by Advertisable EID with RollWorks

Retrieves ideal customer profiles in RollWorks by advertisable EID.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/ideal_customer_profile`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List ICPs by Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-ideal_customer_profile)
