# Get Domain References with RollWorks

Retrieves domain references from RollWorks target account lists.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/target_accounts/domain_references`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get Domain References](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-target_accounts-domain_references)
