# Get ICP by ICP EID and Advertisable EID with RollWorks

Retrieves an ideal customer profile from RollWorks by ICP and advertisable EID.

## Endpoint

- **Method:** `GET`
- **Path:** `/audience/v1/ideal_customer_profile/:icp_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Get ICP by ICP EID and Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#get--audience-v1-ideal_customer_profile-(icp_eid))
