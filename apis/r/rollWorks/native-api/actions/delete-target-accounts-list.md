# Delete Target Accounts List with RollWorks

Deletes a target account list from RollWorks.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/audience/v1/target_accounts/:tal_eid`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [Delete Target Accounts List](https://apidocs.nextroll.com/audience-api/reference.html#delete--audience-v1-target_accounts-(tal_eid))
