# List ICP Accounts by Advertisable EID with RollWorks

Retrieves ICP accounts in RollWorks by advertisable EID.

## Endpoint

- **Method:** `POST`
- **Path:** `/audience/v1/ideal_customer_profile/accounts`
- **Base URL:** `https://services.adroll.com`
- **Official documentation:** [List ICP Accounts by Advertisable EID](https://apidocs.nextroll.com/audience-api/reference.html#post--audience-v1-ideal_customer_profile-accounts)
