# Get Rec Area with Recreation.gov

Retrieves a recreation area from Recreation.gov.

## Endpoint

- **Method:** `GET`
- **Path:** `/recareas/{id}`
- **Base URL:** `https://ridb.recreation.gov/api/v1`
- **Official documentation:** [Get Rec Area](https://ridb.recreation.gov/shared/swagger/ridb.yaml)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
