# Create Facility with Recreation.gov

Creates a new facility in Recreation.gov.

## Endpoint

- **Method:** `POST`
- **Path:** `/facilities`
- **Base URL:** `https://ridb.recreation.gov/api/v1`
- **Official documentation:** [Create Facility](https://ridb.recreation.gov/shared/swagger/dataSteward.yaml)
