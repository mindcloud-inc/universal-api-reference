# List Studio QR Codes with Restream

Retrieves studio QR codes from Restream.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/studio/qr-codes`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [List Studio QR Codes](https://developers.restream.io/studio/studio-qr-codes)
