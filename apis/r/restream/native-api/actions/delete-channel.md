# Delete Channel with Restream

Deletes a streaming channel from Restream.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/user/channels/:channelId`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [Delete Channel](https://developers.restream.io/channels/channel-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `number` | yes | The ID of the channel to delete. |
