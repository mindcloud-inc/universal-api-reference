# Get Clip Project with Restream

Retrieves a clip project from Restream by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/clips/projects/:projectId`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [Get Clip Project](https://developers.restream.io/clips/clips-project-details)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `projectId` | path | `string` | yes | The ID of the clip project to retrieve. |
