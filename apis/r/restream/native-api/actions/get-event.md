# Get Event with Restream

Retrieves an event from Restream by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/events/:eventId`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [Get Event](https://developers.restream.io/events/event)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `eventId` | path | `string` | yes | The UUID of the event to retrieve. |
