# Get Channel with Restream

Retrieves a streaming channel from Restream by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/channels/:channelId`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [Get Channel](https://developers.restream.io/channels/channel)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `channelId` | path | `number` | yes | The ID of the channel to retrieve. |
