# Get Storage File with Restream

Retrieves a video storage file from Restream.

## Endpoint

- **Method:** `GET`
- **Path:** `/user/storage/files/:fileId`
- **Base URL:** `https://api.restream.io/v2`
- **Official documentation:** [Get Storage File](https://developers.restream.io/storage/storage-file)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `fileId` | path | `string` | yes | The ID of the storage file to retrieve. |
