# List Leads with RoboAuditor

## Endpoint

- **Method:** `GET`
- **Path:** `/leads`
- **Base URL:** `https://app.siteauditor.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `page` | query | `number` | no | Page number. |
| `limit` | query | `number` | no | Number of leads per page. |
| `sort_by` | query | `string` | no | Sort field. |
| `sort_desc` | query | `boolean` | no | Sort descending flag. |
