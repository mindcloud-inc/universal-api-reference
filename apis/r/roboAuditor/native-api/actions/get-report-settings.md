# Get Report Settings with RoboAuditor

## Endpoint

- **Method:** `GET`
- **Path:** `/settings/report`
- **Base URL:** `https://app.siteauditor.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `domain_id` | query | `string` | no | Domain identifier for report settings. |
