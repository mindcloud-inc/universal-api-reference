# Check URL Exists with RoboAuditor

## Endpoint

- **Method:** `GET`
- **Path:** `/urlExist`
- **Base URL:** `https://app.siteauditor.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_url` | query | `string` | yes | Website URL to validate. |
