# Generate Report with RoboAuditor

## Endpoint

- **Method:** `POST`
- **Path:** `/report`
- **Base URL:** `https://app.siteauditor.com/api`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `website_url` | query | `string` | yes | Website URL to audit. |
