# List Social Inbox Threads Grouped by Post with Robopost

Retrieves social inbox threads grouped by post from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/social_inbox_items/threads`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [List Social Inbox Threads Grouped by Post](https://robopost.app/docs/robopost-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
