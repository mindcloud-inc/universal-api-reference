# Delete Video Series with Robopost

Deletes an existing video series from Robopost.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/video-series/{series_id}`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Delete Video Series](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `series_id` | path | `string` | yes | The video series ID to delete. |
