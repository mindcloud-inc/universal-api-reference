# List Aggregated Analytics with Robopost

Retrieves aggregated analytics from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregated_posts_analytics/`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [List Aggregated Analytics](https://robopost.app/docs/robopost-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination) and [filtering](../README.md#filtering).
