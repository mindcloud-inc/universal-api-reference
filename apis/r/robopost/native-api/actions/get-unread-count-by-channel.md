# Get Unread Count by Channel with Robopost

Retrieves unread inbox counts by channel from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/social_inbox_items/unread/by_channel`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Unread Count by Channel](https://robopost.app/docs/robopost-api/)
