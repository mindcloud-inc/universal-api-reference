# List Social Inbox Items with Robopost

Retrieves social inbox items from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/social_inbox_items/`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [List Social Inbox Items](https://robopost.app/docs/robopost-api/)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
