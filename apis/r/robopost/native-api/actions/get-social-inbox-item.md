# Get Social Inbox Item with Robopost

Retrieves a social inbox item from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/social_inbox_items/{id}`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Social Inbox Item](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The social inbox item ID. |
