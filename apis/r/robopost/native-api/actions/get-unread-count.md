# Get Unread Count with Robopost

Retrieves the unread inbox count from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/social_inbox_items/unread/count`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Unread Count](https://robopost.app/docs/robopost-api/)
