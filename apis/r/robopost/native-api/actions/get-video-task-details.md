# Get Video Task Details with Robopost

Retrieves video task details from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/video-tasks/{task_id}/details`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Video Task Details](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The video task ID. |
