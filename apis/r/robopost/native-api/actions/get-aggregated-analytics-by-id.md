# Get Aggregated Analytics by ID with Robopost

Retrieves aggregated analytics from Robopost by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/aggregated_posts_analytics/{id}`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Aggregated Analytics by ID](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The aggregated analytics record ID. |
