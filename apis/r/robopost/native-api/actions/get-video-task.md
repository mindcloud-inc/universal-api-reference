# Get Video Task with Robopost

Retrieves a video task from Robopost.

## Endpoint

- **Method:** `GET`
- **Path:** `/video-tasks/{task_id}`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Get Video Task](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | path | `string` | yes | The video task ID. |
