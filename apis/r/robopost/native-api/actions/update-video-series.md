# Update Video Series with Robopost

Updates an existing video series in Robopost.

## Endpoint

- **Method:** `PUT`
- **Path:** `/video-series/{series_id}`
- **Base URL:** `https://public-api.robopost.app/v1`
- **Official documentation:** [Update Video Series](https://robopost.app/docs/robopost-api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `series_id` | path | `string` | yes | The video series ID to update. |
