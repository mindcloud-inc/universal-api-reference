# Get Event Start Time with RunSignup

## Endpoint

- **Method:** `GET`
- **Path:** `/race/:race_id/results/start-time`
- **Base URL:** `https://api.runsignup.com/rest`
- **Official documentation:** [Get Event Start Time](https://runsignup.com/API/race/:race_id/results/start-time/GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `race_id` | path | `string` | yes | Path parameter: race_id |
| `event_id` | query | `number` | yes | ID of event. |
