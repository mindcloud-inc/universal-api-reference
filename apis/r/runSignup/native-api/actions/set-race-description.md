# Set Race Description with RunSignup

- **Method:** `POST`
- **Path:** `/race/:race_id/race-description`
- **Base URL:** `https://api.runsignup.com/rest`
- **Official documentation:** [Set Race Description](https://runsignup.com/API/race/:race_id/race-description/POST)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `race_id` | path | `string` | yes | Path parameter: race_id |
| `description` | body | `string` | yes | — |
