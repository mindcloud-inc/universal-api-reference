# List Race Division Groupings with RunSignup

## Endpoint

- **Method:** `GET`
- **Path:** `/race/:race_id/divisions/division-grouping`
- **Base URL:** `https://api.runsignup.com/rest`
- **Official documentation:** [List Race Division Groupings](https://runsignup.com/API/race/:race_id/divisions/division-grouping/GET)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `race_id` | path | `string` | yes | Path parameter: race_id |
| `event_id` | query | `number` | yes | ID of event. |
