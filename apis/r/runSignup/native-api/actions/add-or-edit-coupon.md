# Add or Edit Coupon with RunSignup

- **Method:** `POST`
- **Path:** `/race/:race_id/coupons`
- **Base URL:** `https://api.runsignup.com/rest`
- **Official documentation:** [Add or Edit Coupon](https://runsignup.com/API/race/:race_id/coupons/POST)
