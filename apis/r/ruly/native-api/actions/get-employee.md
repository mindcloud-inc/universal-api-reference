# Get Employee with Ruly

## Endpoint

- **Method:** `GET`
- **Path:** `data/employee/:employeeId`
- **Base URL:** `https://mindcloud.api.rulyapp.com`
- **Official documentation:** [Get Employee](https://rulyapp.com/quick-tips-using-ruly-api-in-postman-video/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `employeeId` | path | `string` | yes | Employee record identifier from the path. |
