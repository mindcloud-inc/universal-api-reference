# List Reusable Template Tags with RightSignature

Retrieves tags for a RightSignature reusable template.

## Endpoint

- **Method:** `GET`
- **Path:** `/reusable_templates/:reusable_template_id/tags`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [List Reusable Template Tags](https://api.rightsignature.com/documentation/resources/v2/reusable_template_tags/show.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `reusable_template_id` | path | `string` | yes | Reusable Template Id value |
