# Get Sending Request with RightSignature

Retrieves a RightSignature sending request status.

## Endpoint

- **Method:** `GET`
- **Path:** `/sending_requests/:id`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Get Sending Request](https://api.rightsignature.com/documentation/resources/v2/sending_requests/show.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Sending Request id |
