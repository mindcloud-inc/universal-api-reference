# Get Reusable Template with RightSignature

Retrieves a specific reusable template from RightSignature.

## Endpoint

- **Method:** `GET`
- **Path:** `/reusable_templates/:id`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Get Reusable Template](https://api.rightsignature.com/documentation/resources/v2/reusable_templates/show.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Reusable Template ID |
