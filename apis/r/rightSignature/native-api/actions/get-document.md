# Get Document with RightSignature

Retrieves a specific document from RightSignature.

## Endpoint

- **Method:** `GET`
- **Path:** `/documents/:id`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Get Document](https://api.rightsignature.com/documentation/resources/v2/documents/show.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Document ID |
