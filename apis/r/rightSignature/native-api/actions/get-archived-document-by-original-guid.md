# Get Archived Document By Original GUID with RightSignature

Retrieves an archived RightSignature document by original GUID.

## Endpoint

- **Method:** `GET`
- **Path:** `/archived_documents_by_original_guid/:original_guid`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Get Archived Document By Original GUID](https://api.rightsignature.com/documentation/resources/v2/archived_documents/find_by_original_guid.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `original_guid` | path | `string` | yes | Archived Document Original GUID |
