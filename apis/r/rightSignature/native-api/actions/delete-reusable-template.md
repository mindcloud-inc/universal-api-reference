# Delete Reusable Template with RightSignature

Deletes a reusable template from RightSignature.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/reusable_templates/:id`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Delete Reusable Template](https://api.rightsignature.com/documentation/resources/v2/reusable_templates/destroy.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Reusable Template ID |
