# Get Me with RightSignature

Retrieves the authenticated RightSignature user profile.

## Endpoint

- **Method:** `GET`
- **Path:** `/me`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Get Me](https://api.rightsignature.com/documentation/resources/v2/users/me.en.html)
