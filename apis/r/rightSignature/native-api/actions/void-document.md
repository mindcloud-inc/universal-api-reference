# Void Document with RightSignature

Voids an existing document in RightSignature.

## Endpoint

- **Method:** `POST`
- **Path:** `/documents/:id/void`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [Void Document](https://api.rightsignature.com/documentation/resources/v2/documents/void.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Id value |
