# List Reusable Templates with RightSignature

Retrieves reusable templates from your RightSignature account.

## Endpoint

- **Method:** `GET`
- **Path:** `/reusable_templates`
- **Base URL:** `https://api.rightsignature.com/public/v2`
- **Official documentation:** [List Reusable Templates](https://api.rightsignature.com/documentation/resources/v2/reusable_templates/index.en.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `search` | query | `string` | no | A search token. |
