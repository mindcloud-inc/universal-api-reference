# List Remote Jobs with Remote OK

Retrieves remote job postings from Remote OK.

## Endpoint

- **Method:** `GET`
- **Path:** `/api`
- **Base URL:** `https://remoteok.com`
- **Official documentation:** [List Remote Jobs](https://remoteok.com/json)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json,text/plain,*/*` |
| `User-Agent` | `Mozilla/5.0 (compatible; MindCloud/1.0; +https://mindcloud.co)` |
