# Get HTTP Status Duck with Random Duck

## Endpoint

- **Method:** `GET`
- **Path:** `/http/:code`
- **Base URL:** `https://random-d.uk/api/v2`
- **Official documentation:** [Get HTTP Status Duck](https://random-d.uk/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `number` | yes | Required HTTP status code represented by the duck image. |
