# Get Duck GIF by Number with Random Duck

## Endpoint

- **Method:** `GET`
- **Path:** `/:num.gif`
- **Base URL:** `https://random-d.uk/api/v2`
- **Official documentation:** [Get Duck GIF by Number](https://random-d.uk/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `num` | path | `number` | yes | Required numeric duck GIF filename stem. |
