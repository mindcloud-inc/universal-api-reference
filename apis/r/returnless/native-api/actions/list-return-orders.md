# List Return Orders with Returnless

Retrieves return orders from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/return-orders`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [List Return Orders](https://docs.returnless.com/docs/api-rest-reference/0640e3c064cdc)

## Capabilities

This operation supports [filtering](../README.md#filtering) and [sorting](../README.md#sorting).
