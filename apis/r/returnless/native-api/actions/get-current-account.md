# Get Current Account with Returnless

Retrieves the current account from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/account`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [Get Current Account](https://docs.returnless.com/docs/api-rest-reference/0f01a727c340d)
