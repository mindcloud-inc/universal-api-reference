# Get Return Order with Returnless

Retrieves a return order from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/return-orders/{returnOrder}`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [Get Return Order](https://docs.returnless.com/docs/api-rest-reference/f670282943eae)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `returnOrder` | path | `string` | yes | The unique identifier of the return order. |
