# Get Shipment with Returnless

Retrieves a shipment from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/shipments/{shipment}`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [Get Shipment](https://docs.returnless.com/docs/api-rest-reference/8add0ab769032)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `shipment` | path | `string` | yes | The unique identifier of the shipment. |
