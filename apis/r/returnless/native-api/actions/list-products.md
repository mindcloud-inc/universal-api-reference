# List Products with Returnless

Retrieves products from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/products`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [List Products](https://docs.returnless.com/docs/api-rest-reference/d064e56094cd6)
