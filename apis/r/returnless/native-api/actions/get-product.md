# Get Product with Returnless

Retrieves a product from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/products/{product}`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [Get Product](https://docs.returnless.com/docs/api-rest-reference/94c4ade905c79)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `product` | path | `string` | yes | The unique identifier of the product. |
