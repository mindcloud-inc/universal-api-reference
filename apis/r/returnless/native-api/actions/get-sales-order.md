# Get Sales Order with Returnless

Retrieves a sales order from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/sales-orders/{salesOrder}`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [Get Sales Order](https://docs.returnless.com/docs/api-rest-reference/4a6a8fe812c44)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `salesOrder` | path | `string` | yes | The unique identifier of the sales order. |
