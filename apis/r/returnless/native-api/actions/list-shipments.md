# List Shipments with Returnless

Retrieves shipments from Returnless.

## Endpoint

- **Method:** `GET`
- **Path:** `/2025-01/shipments`
- **Base URL:** `https://api-v2.returnless.com`
- **Official documentation:** [List Shipments](https://docs.returnless.com/docs/api-rest-reference/7daf3fa2c9bf9)

## Capabilities

This operation supports [filtering](../README.md#filtering).
