# Get Statement Details with Receipt Bot

Retrieves statement details from Receipt Bot by document ID.

## Endpoint

- **Method:** `POST`
- **Path:** `/StatementDetails`
- **Base URL:** `https://api.receipt-bot.com`
- **Official documentation:** [Get Statement Details](https://documenter.getpostman.com/view/14388213/2sA3kYjLPj)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `documentId` | body | `number` | yes | Receipt Bot document identifier. |
