# Reactivate Subscription with Recurly

## Endpoint

- **Method:** `PUT`
- **Path:** `/subscriptions/:subscription_id/reactivate`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Reactivate Subscription](https://recurly.com/developers/api/v2021-02-25/#operation/reactivate_subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes |
