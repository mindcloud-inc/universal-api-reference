# Fetch Plan with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/plans/:plan_id`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Plan](https://recurly.com/developers/api/v2021-02-25/#operation/get_plan)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `plan_id` | path | `string` | yes |
