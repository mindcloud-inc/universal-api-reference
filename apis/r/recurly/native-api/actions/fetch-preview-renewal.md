# Fetch Preview Renewal with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:subscription_id/preview_renewal`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Preview Renewal](https://recurly.com/developers/api/v2021-02-25/#operation/get_preview_renewal)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes |
