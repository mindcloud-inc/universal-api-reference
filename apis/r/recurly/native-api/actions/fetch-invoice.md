# Fetch Invoice with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Invoice](https://recurly.com/developers/api/v2021-02-25/#operation/get_invoice)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `invoice_id` | path | `string` | yes |
