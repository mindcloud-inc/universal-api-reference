# Fetch Transaction with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/transactions/:transaction_id`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Transaction](https://recurly.com/developers/api/v2021-02-25/#operation/get_transaction)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `transaction_id` | path | `string` | yes |
