# Fetch Subscription with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/subscriptions/:subscription_id`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Subscription](https://recurly.com/developers/api/v2021-02-25/#operation/get_subscription)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subscription_id` | path | `string` | yes |
