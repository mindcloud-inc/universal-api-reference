# Fetch Account Balance with Recurly

## Endpoint

- **Method:** `GET`
- **Path:** `/accounts/:account_id/balance`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Fetch Account Balance](https://recurly.com/developers/api/v2021-02-25/#operation/get_account_balance)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | yes |
