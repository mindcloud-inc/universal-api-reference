# Reactivate Account with Recurly

## Endpoint

- **Method:** `PUT`
- **Path:** `/accounts/:account_id/reactivate`
- **Base URL:** `https://v3.recurly.com`
- **Official documentation:** [Reactivate Account](https://recurly.com/developers/api/v2021-02-25/#operation/reactivate_account)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `account_id` | path | `string` | yes |
