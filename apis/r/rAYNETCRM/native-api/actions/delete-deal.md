# Delete Deal with RAYNET CRM

## Endpoint

- **Method:** `DELETE`
- **Path:** `businessCase/:businessCaseId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Delete Deal](https://app.raynetcrm.com/api/doc/index-en.html#tag/Deals/operation/businessCaseDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `businessCaseId` | path | `string` | yes | Raynet deal identifier. |
