# Get Contact with RAYNET CRM

## Endpoint

- **Method:** `GET`
- **Path:** `person/:personId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Get Contact](https://app.raynetcrm.com/api/doc/index-en.html#tag/Contacts/operation/personDetailGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `number` | yes | The Raynet contact identifier from the /person/{personId}/ path. |
