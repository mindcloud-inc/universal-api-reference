# Get Lead with RAYNET CRM

## Endpoint

- **Method:** `GET`
- **Path:** `lead/:leadId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Get Lead](https://app.raynetcrm.com/api/doc/index-en.html#tag/Leads/operation/leadDetailGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Raynet lead identifier. |
