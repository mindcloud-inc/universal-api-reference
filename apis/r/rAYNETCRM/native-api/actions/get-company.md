# Get Company with RAYNET CRM

## Endpoint

- **Method:** `GET`
- **Path:** `company/:companyId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Get Company](https://app.raynetcrm.com/api/doc/index-en.html#tag/Accounts/operation/companyDetailGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `companyId` | path | `string` | yes | Raynet company identifier. |
