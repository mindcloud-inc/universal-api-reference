# List Contacts with RAYNET CRM

## Endpoint

- **Method:** `GET`
- **Path:** `person/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [List Contacts](https://app.raynetcrm.com/api/doc/index-en.html#tag/Contacts/operation/personGet)

## Capabilities

This operation supports [pagination](../README.md#pagination), [filtering](../README.md#filtering), and [sorting](../README.md#sorting).
