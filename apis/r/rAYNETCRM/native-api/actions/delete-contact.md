# Delete Contact with RAYNET CRM

## Endpoint

- **Method:** `DELETE`
- **Path:** `person/:personId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Delete Contact](https://app.raynetcrm.com/api/doc/index-en.html#tag/Contacts/operation/personDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `personId` | path | `string` | yes | contact ID |
