# Delete Lead with RAYNET CRM

## Endpoint

- **Method:** `DELETE`
- **Path:** `lead/:leadId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Delete Lead](https://app.raynetcrm.com/api/doc/index-en.html#tag/Leads/operation/leadDelete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `leadId` | path | `string` | yes | Raynet lead identifier. |
