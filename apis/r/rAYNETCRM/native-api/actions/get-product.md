# Get Product with RAYNET CRM

## Endpoint

- **Method:** `GET`
- **Path:** `product/:productId/`
- **Base URL:** `https://app.raynetcrm.com/api/v2/`
- **Official documentation:** [Get Product](https://app.raynetcrm.com/api/doc/index-en.html#tag/Products/operation/productDetailGet)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `productId` | path | `string` | yes | Raynet product identifier. |
