# Get Record with Rubitime

Retrieves a record from Rubitime.

## Endpoint

- **Method:** `POST`
- **Path:** `/get-record`
- **Base URL:** `https://rubitime.ru/api2`
- **Official documentation:** [Get Record](https://rubitime.ru/faq/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Rubitime record ID. |
