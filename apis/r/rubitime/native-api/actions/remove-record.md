# Remove Record with Rubitime

Deletes an existing record from Rubitime.

## Endpoint

- **Method:** `POST`
- **Path:** `/remove-record`
- **Base URL:** `https://rubitime.ru/api2`
- **Official documentation:** [Remove Record](https://rubitime.ru/faq/api)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | body | `number` | yes | Rubitime record ID to delete. |
