# Delete Customer with Reepay

Deletes an existing customer from Reepay.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/customer/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Delete Customer](https://docs.frisbii.com/reference/deletecustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Customer handle from Reepay. |
