# Get Current Plan with Reepay

Retrieves the current plan from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/plan/:handle/current`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Current Plan](https://docs.frisbii.com/reference/getcurrentplan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Plan handle from Reepay. |
