# Delete Gateway Agreement with Reepay

Deletes a gateway agreement from Reepay.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/agreement/:id`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Delete Gateway Agreement](https://docs.frisbii.com/reference/deletegatewayagreement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agreement id from Reepay. |
