# Delete Payment Method with Reepay

Deletes a payment method from Reepay.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/payment_method/:id`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Delete Payment Method](https://docs.frisbii.com/reference/deletepaymentmethodv2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Payment method identifier from Reepay. |
