# Get Gateway Agreement with Reepay

Retrieves a gateway agreement from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/agreement/:id`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Gateway Agreement](https://docs.frisbii.com/reference/getgatewayagreement)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Agreement id from Reepay. |
