# Get Invoice with Reepay

Retrieves an invoice from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/invoice/:id`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Invoice](https://docs.frisbii.com/reference/getinvoice)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Invoice identifier from Reepay. |
