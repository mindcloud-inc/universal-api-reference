# Delete Pending Subscription with Reepay

Deletes a pending subscription from Reepay.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/subscription/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Delete Pending Subscription](https://docs.frisbii.com/reference/deletepending)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle from Reepay. |
