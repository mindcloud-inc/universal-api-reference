# Get Payment Method with Reepay

Retrieves a payment method from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/payment_method/:id`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Payment Method](https://docs.frisbii.com/reference/getpaymentmethodv2)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Payment method identifier from Reepay. |
