# Update Subscription with Reepay

Updates an existing subscription in Reepay.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/subscription/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Update Subscription](https://docs.frisbii.com/reference/changesubscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle from Reepay. |
