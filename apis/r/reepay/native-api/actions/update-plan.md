# Update Plan with Reepay

Updates an existing plan in Reepay.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/plan/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Update Plan](https://docs.frisbii.com/reference/updateplanjson)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Plan handle from Reepay. |
