# Get Charge with Reepay

Retrieves a charge from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/charge/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Charge](https://docs.frisbii.com/reference/getcharge)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Charge handle from Reepay. |
