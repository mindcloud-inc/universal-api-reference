# List Payment Methods with Reepay

Retrieves payment methods from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/list/payment_method`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [List Payment Methods](https://docs.frisbii.com/reference/getpaymentmethodlist)

## Capabilities

This operation supports [pagination](../README.md#pagination).
