# List Plans with Reepay

Retrieves plans from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/list/plan`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [List Plans](https://docs.frisbii.com/reference/getplanlist)

## Capabilities

This operation supports [pagination](../README.md#pagination).
