# Delete Plan with Reepay

Deletes an existing plan from Reepay.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/plan/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Delete Plan](https://docs.frisbii.com/reference/deleteplan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Plan handle from Reepay. |
