# List Subscriptions with Reepay

Retrieves subscriptions from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/list/subscription`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [List Subscriptions](https://docs.frisbii.com/reference/getsubscriptionlist)

## Capabilities

This operation supports [pagination](../README.md#pagination).
