# Update Customer with Reepay

Updates an existing customer in Reepay.

## Endpoint

- **Method:** `PUT`
- **Path:** `/v1/customer/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Update Customer](https://docs.frisbii.com/reference/updatecustomerjson)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Customer handle from Reepay. |
