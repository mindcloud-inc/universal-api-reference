# Get Subscription with Reepay

Retrieves a subscription from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/subscription/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Subscription](https://docs.frisbii.com/reference/getsubscription)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Subscription handle from Reepay. |
