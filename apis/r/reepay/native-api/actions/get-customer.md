# Get Customer with Reepay

Retrieves a customer from Reepay.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/customer/:handle`
- **Base URL:** `https://api.frisbii.com`
- **Official documentation:** [Get Customer](https://docs.frisbii.com/reference/getcustomer)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `handle` | path | `string` | yes | Customer handle from Reepay. |
