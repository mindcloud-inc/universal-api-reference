# Get Workspace Numbers with Ringg AI

Retrieves workspace numbers from Ringg AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace/numbers`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Get Workspace Numbers](https://docs.ringg.ai/api-reference/endpoint/numbers/get-workspace-numbers)

## Capabilities

This operation supports [pagination](../README.md#pagination).
