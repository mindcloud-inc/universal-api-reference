# Delete Assistant with Ringg AI

Archives an assistant in Ringg AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/agent/:agent_id`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | (Required) ID of the assistant to delete. |
