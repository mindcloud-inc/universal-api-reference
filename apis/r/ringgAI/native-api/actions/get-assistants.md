# Get Assistants with Ringg AI

Retrieves assistants from Ringg AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent/all`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Get Assistants](https://docs.ringg.ai/api-reference/endpoint/assistant/get-assistants)

## Capabilities

This operation supports [pagination](../README.md#pagination).
