# Get Assistant By ID with Ringg AI

Retrieves an assistant from Ringg AI by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/agent/:agent_id`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Get Assistant By ID](https://docs.ringg.ai/api-reference/endpoint/assistant/get-assistant-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agent_id` | path | `string` | yes | (Required) ID of the assistant to retrieve. |
