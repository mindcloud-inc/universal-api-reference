# Delete Knowledge Base with Ringg AI

Deletes a knowledge base from Ringg AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/external/kb/:kb_id`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Delete Knowledge Base](https://docs.ringg.ai/api-reference/endpoint/kb/delete-knowledge-base)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kb_id` | path | `string` | yes | (Required) ID of the knowledge base to delete |
