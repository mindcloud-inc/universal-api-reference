# List Workspace Users with Ringg AI

Retrieves workspace users from Ringg AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace/users`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [List Workspace Users](https://docs.ringg.ai/api-reference/endpoint/workspace/list-workspace-users)

## Capabilities

This operation supports [pagination](../README.md#pagination).
