# Get Workspace Info with Ringg AI

Retrieves workspace information from Ringg AI.

## Endpoint

- **Method:** `GET`
- **Path:** `/workspace`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Get Workspace Info](https://docs.ringg.ai/api-reference/endpoint/workspace/get-workspace-info)
