# Get Knowledge Base by ID with Ringg AI

Retrieves a knowledge base from Ringg AI by ID.

## Endpoint

- **Method:** `GET`
- **Path:** `/external/kb/:kb_id`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Get Knowledge Base by ID](https://docs.ringg.ai/api-reference/endpoint/kb/get-knowledge-base-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `kb_id` | path | `string` | yes | (Required) ID of the knowledge base |
