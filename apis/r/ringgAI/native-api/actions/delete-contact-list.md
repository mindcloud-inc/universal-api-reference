# Delete Contact List with Ringg AI

Deletes a contact list from Ringg AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/calling/contact/:list_id`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Delete Contact List](https://docs.ringg.ai/api-reference/endpoint/contact/delete-contact-list)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `list_id` | path | `string` | yes | (Required) The unique identifier of the contact list to delete. |
