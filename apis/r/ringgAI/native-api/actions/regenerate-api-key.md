# Regenerate API Key with Ringg AI

Regenerates the API key for a Ringg AI workspace.

## Endpoint

- **Method:** `PATCH`
- **Path:** `/workspace/api-key`
- **Base URL:** `https://prod-api.ringg.ai/ca/api/v0`
- **Official documentation:** [Regenerate API Key](https://docs.ringg.ai/api-reference/endpoint/workspace/regenerate-api-key)
