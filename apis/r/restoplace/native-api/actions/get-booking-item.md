# Get Booking Item with Restoplace

Retrieves a booking item from Restoplace.

## Endpoint

- **Method:** `GET`
- **Path:** `/items/:id`
- **Base URL:** `https://api.restoplace.cc`
- **Official documentation:** [Get Booking Item](https://restoplace.cc/help/API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Restoplace booking item ID. |
