# Get Reservation with Restoplace

Retrieves a reservation from Restoplace.

## Endpoint

- **Method:** `GET`
- **Path:** `/reserves/:id`
- **Base URL:** `https://api.restoplace.cc`
- **Official documentation:** [Get Reservation](https://restoplace.cc/help/API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Restoplace reservation ID from the list or create actions. |
