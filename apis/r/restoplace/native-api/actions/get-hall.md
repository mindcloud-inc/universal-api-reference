# Get Hall with Restoplace

Retrieves a hall from Restoplace.

## Endpoint

- **Method:** `GET`
- **Path:** `/halls/:id`
- **Base URL:** `https://api.restoplace.cc`
- **Official documentation:** [Get Hall](https://restoplace.cc/help/API)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Unique Restoplace hall ID. |
