# List Brands with RapidReg

Retrieves brands from RapidReg.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/get/brands`
- **Base URL:** `https://rapidreg.com`
- **Official documentation:** [List Brands](https://rapidreg.com/developers#dev-brands)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
