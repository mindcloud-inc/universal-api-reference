# Get Account with RapidReg

Retrieves account details from RapidReg.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v1/get/account`
- **Base URL:** `https://rapidreg.com`
- **Official documentation:** [Get Account](https://rapidreg.com/developers#dev-account)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
