# List Products with Rithum for Brands

## Endpoint

- **Method:** `GET`
- **Path:** `Products`
- **Base URL:** `https://api.channeladvisor.com/v1/`
- **Official documentation:** [List Products](https://knowledge.channeladvisor.com/kc?id=kb_article_view&sys_kb_id=21dcd3491bd5d1d42d9eea40604bcbdf)

## Capabilities

This operation supports [pagination](../README.md#pagination).

| Parameter | Location | Type | Required |

| `sku` | query | `string` | no |
| `dateModifiedAfter` | query | `date` | no |
| `dateModifiedBefore` | query | `date` | no |
| `$expand` | query | `string` | no |
