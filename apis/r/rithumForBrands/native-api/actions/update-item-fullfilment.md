# Update Item Fullfilment with Rithum for Brands

Update Item fullfilment

## Endpoint

- **Method:** `PATCH`
- **Path:** `Fulfillments(:fullfilmentID)`
- **Base URL:** `https://api.channeladvisor.com/v1/`
- **Official documentation:** [Update Item Fullfilment](https://knowledge.channeladvisor.com/kc?id=kb_article_view&sys_kb_id=13fcdf491bd5d1d42d9eea40604bcb65)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `fullfilmentID` | path | `number` | no |
| `deliveryStatus` | body | `string` | no |
| `TrackingNumber` | body | `string` | no |
| `shippingCarrier` | body | `string` | no |
| `shippingClass` | body | `string` | no |
