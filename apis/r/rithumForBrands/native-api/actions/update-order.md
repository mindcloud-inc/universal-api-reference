# Update Order with Rithum for Brands

Update an Order

## Endpoint

- **Method:** `PATCH`
- **Path:** `Orders(:id)`
- **Base URL:** `https://api.channeladvisor.com/v1/`
- **Official documentation:** [Update Order](https://knowledge.channeladvisor.com/kc?id=kb_article_view&sys_kb_id=981a17a187001e10712797d83cbb3550)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | no |
| `shippingStatus` | body | `string` | no |
| `SellerOrderID` | body | `string` | no |
