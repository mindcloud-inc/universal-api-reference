# Mark Order Not Exported with Rithum for Brands

Mark an order as not exported.

## Endpoint

- **Method:** `DELETE`
- **Path:** `Orders(:orderID)/Export`
- **Base URL:** `https://api.channeladvisor.com/v1/`
- **Official documentation:** [Mark Order Not Exported](https://knowledge.channeladvisor.com/kc?id=kb_article_view&sys_id=f00d5fc52fd15994cffb5ff62799b68f)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `orderID` | path | `string` | yes |
