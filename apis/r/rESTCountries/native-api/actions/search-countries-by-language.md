# Search Countries by Language with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `lang/:language`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Language](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `language` | path | `string` | yes | Language name or ISO 639 code. |
