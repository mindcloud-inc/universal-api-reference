# List Countries by Region with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `region/:region`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [List Countries by Region](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `region` | path | `string` | yes | Region such as Europe or Africa. |
