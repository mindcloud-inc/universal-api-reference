# Get Country by Code with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `alpha/:code`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Get Country by Code](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | ISO 3166-1 alpha-2 or alpha-3 country code. |
