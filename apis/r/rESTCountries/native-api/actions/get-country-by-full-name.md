# Get Country by Full Name with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `name/:name`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Get Country by Full Name](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Full country name to match exactly. |
