# Get Country Currencies by Code with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `alpha/:code?fields=name,currencies`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Get Country Currencies by Code](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `code` | path | `string` | yes | ISO 3166-1 alpha-2 or alpha-3 country code. |
