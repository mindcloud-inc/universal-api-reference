# Search Countries by Demonym with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `demonym/:demonym`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Demonym](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `demonym` | path | `string` | yes | Country demonym such as Colombian or Japanese. |
