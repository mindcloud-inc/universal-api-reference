# Search Countries by Translation with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `translation/:translation`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Translation](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `translation` | path | `string` | yes | Translated country name. |
