# List Countries by Subregion with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `subregion/:subregion`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [List Countries by Subregion](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `subregion` | path | `string` | yes | Subregion such as Northern Europe or South America. |
