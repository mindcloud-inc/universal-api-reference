# Search Countries by Currency with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `currency/:currency`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Currency](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `currency` | path | `string` | yes | Currency code such as EUR or USD. |
