# Search Countries by Capital with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `capital/:capital`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Capital](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `capital` | path | `string` | yes | Capital city name. |
