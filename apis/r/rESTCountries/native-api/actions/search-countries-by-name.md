# Search Countries by Name with REST Countries

## Endpoint

- **Method:** `GET`
- **Path:** `name/:name`
- **Base URL:** `https://restcountries.com/v3.1`
- **Official documentation:** [Search Countries by Name](https://restcountries.com/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | path | `string` | yes | Country common or official name to search for. |
