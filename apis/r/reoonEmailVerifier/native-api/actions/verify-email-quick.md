# Verify Email Quick with Reoon Email Verifier

## Endpoint

- **Method:** `GET`
- **Path:** `/verify`
- **Base URL:** `https://emailverifier.reoon.com/api/v1`
- **Official documentation:** [Verify Email Quick](https://www.reoon.com/articles/api-documentation-of-reoon-email-verifier/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | The email address to verify in quick mode. |
