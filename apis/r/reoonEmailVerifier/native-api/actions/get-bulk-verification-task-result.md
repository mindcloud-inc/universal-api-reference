# Get Bulk Verification Task Result with Reoon Email Verifier

## Endpoint

- **Method:** `GET`
- **Path:** `/get-result-bulk-verification-task/`
- **Base URL:** `https://emailverifier.reoon.com/api/v1`
- **Official documentation:** [Get Bulk Verification Task Result](https://www.reoon.com/articles/api-documentation-of-reoon-email-verifier/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `task_id` | query | `number` | yes | The bulk verification task id returned by Reoon. |
