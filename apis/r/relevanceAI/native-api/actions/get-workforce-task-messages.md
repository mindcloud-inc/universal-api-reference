# Get Workforce Task Messages with Relevance AI

## Endpoint

- **Method:** `POST`
- **Path:** `/workforce/items/:workforceId/tasks/:taskId/messages`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Workforce Task Messages](https://relevanceai.com/docs/build/workforces/workforce-features/workforce-task-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workforceId` | path | `string` | yes | The workforce id. |
| `taskId` | path | `string` | yes | The workforce task id. |
