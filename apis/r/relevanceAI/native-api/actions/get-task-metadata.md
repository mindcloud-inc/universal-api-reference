# Get Task Metadata with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/knowledge/sets/:conversationId/get_metadata`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Task Metadata](https://sdk.relevanceai.com/concepts/10_1/tasks)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `conversationId` | path | `string` | yes | The task conversation id. |
