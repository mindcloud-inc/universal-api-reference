# Delete Agent with Relevance AI

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/:agentId/delete`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Delete Agent](https://sdk.relevanceai.com/concepts/10_1/agents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | path | `string` | yes |
