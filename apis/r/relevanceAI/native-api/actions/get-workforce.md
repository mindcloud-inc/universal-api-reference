# Get Workforce with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/workforce/items/:workforceId`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Workforce](https://relevanceai.com/docs/get-started/core-concepts/workforces)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workforceId` | path | `string` | yes | The Relevance AI workforce id to retrieve. |
