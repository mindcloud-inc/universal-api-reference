# List Workforce Tasks with Relevance AI

## Endpoint

- **Method:** `POST`
- **Path:** `/workforce/tasks/list`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [List Workforce Tasks](https://relevanceai.com/docs/build/workforces/workforce-features/workforce-task-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `workforce_id` | body | `string` | yes | The workforce id to list tasks for. |
