# Get Tool with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/studios/:toolId/get`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Tool](https://sdk.relevanceai.com/concepts/10_1/tools)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `toolId` | path | `string` | yes | The Relevance AI tool id to retrieve. |
