# List Agent Tools with Relevance AI

## Endpoint

- **Method:** `POST`
- **Path:** `/agents/tools/list`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [List Agent Tools](https://sdk.relevanceai.com/concepts/10_1/agents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agentId` | body | `string` | yes |
