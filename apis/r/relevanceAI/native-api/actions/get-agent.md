# Get Agent with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/:agentId/get`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Agent](https://sdk.relevanceai.com/concepts/10_1/agents)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `agentId` | path | `string` | yes | The Relevance AI agent id to retrieve. |
