# Get Workforce Task Metadata with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/workforce/tasks/:taskId/metadata`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Workforce Task Metadata](https://relevanceai.com/docs/build/workforces/workforce-features/workforce-task-view)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `taskId` | path | `string` | yes | The workforce task id. |
