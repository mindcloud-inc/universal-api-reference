# Get Task Output Preview with Relevance AI

## Endpoint

- **Method:** `GET`
- **Path:** `/agents/conversations/studios/list`
- **Base URL:** `https://api-{region}.stack.tryrelevance.com/latest`
- **Official documentation:** [Get Task Output Preview](https://sdk.relevanceai.com/concepts/10_1/agents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `agent_id` | query | `string` | yes |
| `conversation_id` | query | `string` | yes |
