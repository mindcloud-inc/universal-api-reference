# Get Invoice with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [Get Invoice](https://roapp.readme.io/reference/get-invoice-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID |
