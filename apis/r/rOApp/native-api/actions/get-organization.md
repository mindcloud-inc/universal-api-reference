# Get Organization with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/organizations/:organization_id`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [Get Organization](https://roapp.readme.io/reference/get-organization-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organization_id` | path | `number` | yes | Organization ID |
