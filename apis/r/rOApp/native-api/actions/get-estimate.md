# Get Estimate with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates/:estimate_id`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [Get Estimate](https://roapp.readme.io/reference/get-estimate-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `estimate_id` | path | `number` | yes | Estimate ID |
