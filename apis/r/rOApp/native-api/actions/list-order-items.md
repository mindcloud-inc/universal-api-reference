# List Order Items with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:order_id/items`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [List Order Items](https://roapp.readme.io/reference/get-order-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | yes | Order ID |
