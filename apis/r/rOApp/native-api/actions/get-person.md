# Get Person with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/contacts/people/:person_id`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [Get Person](https://roapp.readme.io/reference/get-person-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `person_id` | path | `number` | yes | Person ID |
