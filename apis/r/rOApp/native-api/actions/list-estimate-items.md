# List Estimate Items with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/estimates/:estimate_id/items`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [List Estimate Items](https://roapp.readme.io/reference/get-estimate-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `estimate_id` | path | `number` | yes | Estimate ID |
