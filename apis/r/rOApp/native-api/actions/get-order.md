# Get Order with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/orders/:order_id`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [Get Order](https://roapp.readme.io/reference/get-order-by-id)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `order_id` | path | `number` | yes | Order ID |
