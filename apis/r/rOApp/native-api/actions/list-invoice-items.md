# List Invoice Items with RO App

## Endpoint

- **Method:** `GET`
- **Path:** `/invoices/:invoice_id/items`
- **Base URL:** `https://api.roapp.io/v2`
- **Official documentation:** [List Invoice Items](https://roapp.readme.io/reference/get-invoice-items)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `invoice_id` | path | `number` | yes | Invoice ID |
