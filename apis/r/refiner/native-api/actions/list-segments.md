# List Segments with Refiner

Retrieves segments from your Refiner account.

## Endpoint

- **Method:** `GET`
- **Path:** `/segments`
- **Base URL:** `https://api.refiner.io/v1`
- **Official documentation:** [List Segments](https://refiner.io/docs/api/#get-segments)

## Capabilities

This operation supports [pagination](../README.md#pagination).
