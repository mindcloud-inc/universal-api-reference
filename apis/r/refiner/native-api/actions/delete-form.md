# Delete Form with Refiner

Archives an existing form in Refiner.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/forms`
- **Base URL:** `https://api.refiner.io/v1`
- **Official documentation:** [Delete Form](https://refiner.io/docs/api/#delete-form)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `form_uuid` | query | `string` | yes | The form UUID to archive. |
