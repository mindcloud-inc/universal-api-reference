# Get Payment with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/payments/:id`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Payment](https://api.raklet.com/swagger/ui/index#/AdminPayments/AdminPayments_GetAdminPayment)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
