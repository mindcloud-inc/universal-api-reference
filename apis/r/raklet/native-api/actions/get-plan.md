# Get Plan with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/plans/:id`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Plan](https://api.raklet.com/swagger/ui/index#/AdminPlans/AdminPlans_GetPlan)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Plan identifier in Raklet. |
