# List Events with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/app/organisations/:organisationId/events`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [List Events](https://api.raklet.com/swagger/ui/index#/Events/Events_GetEvents)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `startDate` | query | `date` | yes |
| `endDate` | query | `date` | yes |
