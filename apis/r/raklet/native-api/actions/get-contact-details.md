# Get Contact Details with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/contacts/:organisationMembershipId/details`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Contact Details](https://api.raklet.com/swagger/ui/index#/Contact/Contact_GetDetails)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `organisationMembershipId` | path | `string` | yes | Contact membership identifier in Raklet. |
