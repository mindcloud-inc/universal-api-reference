# Authenticate with Raklet

## Endpoint

- **Method:** `POST`
- **Path:** `/token`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Authenticate](https://help.raklet.com/en/articles/11728820-how-to-authenticate-with-the-raklet-api)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Content-Type` | `application/x-www-form-urlencoded` |
