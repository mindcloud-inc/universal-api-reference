# Get Donation with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/donations/:id`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Donation](https://api.raklet.com/swagger/ui/index#/AdminDonations/AdminDonations_GetDonation)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
