# List Posts with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/posts`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [List Posts](https://api.raklet.com/swagger/ui/index#/Posts/Posts_GetPosts)

## Capabilities

This operation supports [pagination](../README.md#pagination).

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `searchText` | query | `string` | no |
