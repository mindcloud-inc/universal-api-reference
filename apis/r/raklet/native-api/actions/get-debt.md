# Get Debt with Raklet

## Endpoint

- **Method:** `GET`
- **Path:** `/organisations/:organisationId/debts/:id`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Debt](https://api.raklet.com/swagger/ui/index#/AdminDebts/AdminDebts_GetDebt)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
