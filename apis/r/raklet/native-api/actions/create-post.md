# Create Post with Raklet

## Endpoint

- **Method:** `POST`
- **Path:** `/organisations/:organisationId/posts`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Create Post](https://api.raklet.com/swagger/ui/index#/Posts/Posts_CreatePost)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `subject` | body | `string` | yes |
| `description` | body | `string` | no |
