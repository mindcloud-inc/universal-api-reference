- **Method:** `GET`
- **Path:** `/app/organisations/:organisationId/events/:id`
- **Base URL:** `https://api.raklet.com`
- **Official documentation:** [Get Event](https://api.raklet.com/swagger/ui/index#/Events/Events_GetEvent)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `string` | yes |
