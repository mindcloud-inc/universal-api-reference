# List Transcript with Reka AI

Retrieves a transcript from a Reka AI video.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v2/videos/:video_id/transcript`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [List Transcript](https://docs.reka.ai/vision/api-reference/v-2/list-transcript-v-2-videos-video-id-transcript-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The video identifier whose transcript to list. |
