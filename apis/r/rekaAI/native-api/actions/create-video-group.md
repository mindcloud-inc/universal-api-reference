# Create Video Group with Reka AI

Creates a video group in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v2/video-groups`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Create Video Group](https://docs.reka.ai/vision/api-reference/v-2/create-video-group-v-2-video-groups-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Video group name |
