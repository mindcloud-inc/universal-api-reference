# Ask Video QA with Reka AI

Creates a video QA response in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/qa/chat`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Ask Video QA](https://docs.reka.ai/vision/api-reference/video-qa/chat-v-1-qa-chat-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | body | `string` | yes | Video identifier |
