# Get Legacy Video Group with Reka AI

Retrieves a legacy video group from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Legacy Video Group](https://docs.reka.ai/vision/api-reference/video-groups/get-video-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The legacy video group identifier to retrieve. |
