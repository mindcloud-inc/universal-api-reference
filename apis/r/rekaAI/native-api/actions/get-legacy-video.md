# Get Legacy Video with Reka AI

Retrieves a legacy video from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/videos/:video_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Legacy Video](https://docs.reka.ai/vision/api-reference/video-management/get-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The legacy video identifier to retrieve. |
