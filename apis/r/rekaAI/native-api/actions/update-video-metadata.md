# Update Video Metadata with Reka AI

Updates video metadata in Reka AI.

## Endpoint

- **Method:** `PATCH`
- **Path:** `https://vision-agent.api.reka.ai/v2/videos/:video_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Update Video Metadata](https://docs.reka.ai/vision/api-reference/v-2/update-video-metadata-v-2-videos-video-id-patch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The video identifier to update. |
