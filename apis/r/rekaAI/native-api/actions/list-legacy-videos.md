# List Legacy Videos with Reka AI

Retrieves legacy videos from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/videos`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [List Legacy Videos](https://docs.reka.ai/vision/api-reference/video-management/get-videos)
