# Update Video Group with Reka AI

Updates an existing video group in Reka AI.

## Endpoint

- **Method:** `PATCH`
- **Path:** `https://vision-agent.api.reka.ai/v2/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Update Video Group](https://docs.reka.ai/vision/api-reference/v-2/update-video-group-v-2-video-groups-group-id-patch)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The video group identifier to update. |
