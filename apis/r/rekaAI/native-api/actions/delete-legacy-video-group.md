# Delete Legacy Video Group with Reka AI

Deletes an existing legacy video group from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v1/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Legacy Video Group](https://docs.reka.ai/vision/api-reference/video-groups/delete-video-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The legacy video group identifier to delete. |
