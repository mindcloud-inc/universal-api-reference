# Delete Reel with Reka AI

Deletes an existing reel from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v1/clips/:id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Reel](https://docs.reka.ai/vision/api-reference/clip-generation/delete-reel-v-1-clips-id-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The reel identifier to delete. |
