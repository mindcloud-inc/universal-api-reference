# Get Image with Reka AI

Retrieves an image from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/images/:image_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Image](https://docs.reka.ai/vision/api-reference/image-management/get-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | The image identifier to retrieve. |
