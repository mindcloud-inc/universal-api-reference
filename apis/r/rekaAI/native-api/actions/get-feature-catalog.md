# Get Feature Catalog with Reka AI

Retrieves the feature catalog from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v2/features`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Feature Catalog](https://docs.reka.ai/vision/api-reference/v-2/get-feature-catalog-v-2-features-get)
