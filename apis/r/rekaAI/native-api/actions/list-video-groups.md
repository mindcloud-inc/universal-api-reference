# List Video Groups with Reka AI

Retrieves video groups from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v2/video-groups`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [List Video Groups](https://docs.reka.ai/vision/api-reference/v-2/list-video-groups-v-2-video-groups-get)
