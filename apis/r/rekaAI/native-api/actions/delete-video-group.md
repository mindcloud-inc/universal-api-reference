# Delete Video Group with Reka AI

Deletes an existing video group from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v2/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Video Group](https://docs.reka.ai/vision/api-reference/v-2/delete-video-group-v-2-video-groups-group-id-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The video group identifier to delete. |
