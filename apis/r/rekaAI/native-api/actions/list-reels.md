# List Reels with Reka AI

Retrieves reels from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/clips`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [List Reels](https://docs.reka.ai/vision/api-reference/clip-api/list-reels-v-1-clips-get)
