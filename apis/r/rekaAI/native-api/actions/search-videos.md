# Search Videos with Reka AI

Finds videos in Reka AI by query.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/videos/search`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Search Videos](https://docs.reka.ai/vision/api-reference/video-search/post-embedding-search)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Video search query |
