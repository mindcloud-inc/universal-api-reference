# Update Legacy Video Group with Reka AI

Updates an existing legacy video group in Reka AI.

## Endpoint

- **Method:** `PATCH`
- **Path:** `https://vision-agent.api.reka.ai/v1/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Update Legacy Video Group](https://docs.reka.ai/vision/api-reference/video-groups/patch-update-video-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The legacy video group identifier to update. |
