# Delete Legacy Video with Reka AI

Deletes an existing legacy video from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v1/videos/:video_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Legacy Video](https://docs.reka.ai/vision/api-reference/video-management/delete-video)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The legacy video identifier to delete. |
