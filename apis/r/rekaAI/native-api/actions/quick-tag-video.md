# Quick Tag Video with Reka AI

Creates quick tags for a video in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/qa/quicktag`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Quick Tag Video](https://docs.reka.ai/vision/api-reference/metadata-tagging/quick-tag-v-1-qa-quicktag-post)
