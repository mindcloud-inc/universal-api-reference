# Get Video Group with Reka AI

Retrieves a video group from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v2/video-groups/:group_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Video Group](https://docs.reka.ai/vision/api-reference/v-2/get-video-group-v-2-video-groups-group-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `group_id` | path | `string` | yes | The video group identifier to retrieve. |
