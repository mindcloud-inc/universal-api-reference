# List Legacy Video Groups with Reka AI

Retrieves legacy video groups from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/video-groups`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [List Legacy Video Groups](https://docs.reka.ai/vision/api-reference/video-groups/get-list-video-groups)
