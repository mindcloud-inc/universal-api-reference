# Get Video with Reka AI

Retrieves a video from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v2/videos/:video_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Video](https://docs.reka.ai/vision/api-reference/v-2/get-video-v-2-videos-video-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The video identifier to retrieve. |
