# Get Reel with Reka AI

Retrieves a reel from Reka AI.

## Endpoint

- **Method:** `GET`
- **Path:** `https://vision-agent.api.reka.ai/v1/clips/:id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Get Reel](https://docs.reka.ai/vision/api-reference/clip-generation/get-reel-v-1-clips-id-get)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | The reel identifier to retrieve. |
