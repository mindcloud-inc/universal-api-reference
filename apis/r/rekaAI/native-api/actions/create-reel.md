# Create Reel with Reka AI

Creates a reel in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/clips`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Create Reel](https://docs.reka.ai/vision/api-reference/clip-generation/create-reel-v-1-clips-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_urls` | body | `string` | yes | Source video URLs |
