# Delete Image with Reka AI

Deletes an existing image from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v1/images/:image_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Image](https://docs.reka.ai/vision/api-reference/image-management/delete-image)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image_id` | path | `string` | yes | The image identifier to delete. |
