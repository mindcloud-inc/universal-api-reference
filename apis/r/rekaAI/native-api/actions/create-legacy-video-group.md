# Create Legacy Video Group with Reka AI

Creates a legacy video group in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/video-groups`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Create Legacy Video Group](https://docs.reka.ai/vision/api-reference/video-groups/post-create-video-group)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Video group name |
