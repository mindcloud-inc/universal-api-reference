# Delete Video with Reka AI

Deletes an existing video from Reka AI.

## Endpoint

- **Method:** `DELETE`
- **Path:** `https://vision-agent.api.reka.ai/v2/videos/:video_id`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Delete Video](https://docs.reka.ai/vision/api-reference/v-2/delete-video-v-2-videos-video-id-delete)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | path | `string` | yes | The video identifier to delete. |
