# Indexed Tag Video with Reka AI

Creates indexed tags for a video in Reka AI.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/qa/indexedtag`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Indexed Tag Video](https://docs.reka.ai/vision/api-reference/metadata-tagging/indexed-tag-v-1-qa-indexedtag-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `video_id` | body | `string` | yes | Video identifier |
