# Search Images with Reka AI

Finds images in Reka AI by query.

## Endpoint

- **Method:** `POST`
- **Path:** `https://vision-agent.api.reka.ai/v1/images/search`
- **Base URL:** `https://api.reka.ai`
- **Official documentation:** [Search Images](https://docs.reka.ai/vision/api-reference/image-search/search-images-v-1-images-search-post)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `query` | body | `string` | yes | Image search query |
