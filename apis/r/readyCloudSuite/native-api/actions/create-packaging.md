# Create Packaging with ReadyCloud Suite

Creates a new packaging record in ReadyCloud Suite.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/orgs/:orgPk/packaging/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [Create Packaging](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-09-packaging.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgPk` | path | `string` | yes | ReadyCloud organization identifier. |
