# List Orders with ReadyCloud Suite

Retrieves orders from ReadyCloud Suite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgPk/orders/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [List Orders](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-02-orders.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgPk` | path | `string` | yes | ReadyCloud organization identifier. |
