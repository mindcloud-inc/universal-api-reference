# List Organizations with ReadyCloud Suite

Retrieves organizations from ReadyCloud Suite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [List Organizations](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-01-organizations.html)
