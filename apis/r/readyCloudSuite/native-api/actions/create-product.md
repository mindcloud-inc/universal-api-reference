# Create Product with ReadyCloud Suite

Creates a new product in ReadyCloud Suite.

## Endpoint

- **Method:** `POST`
- **Path:** `/api/v2/orgs/:orgPk/products/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [Create Product](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-11-products.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgPk` | path | `string` | yes | ReadyCloud organization identifier. |
