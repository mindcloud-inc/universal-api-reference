# List Contacts with ReadyCloud Suite

Retrieves contacts from ReadyCloud Suite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgPk/contacts/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [List Contacts](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-12-contacts.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgPk` | path | `string` | yes | ReadyCloud organization identifier. |
