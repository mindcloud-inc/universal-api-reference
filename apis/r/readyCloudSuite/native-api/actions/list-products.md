# List Products with ReadyCloud Suite

Retrieves products from ReadyCloud Suite.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/orgs/:orgPk/products/`
- **Base URL:** `https://www.readycloud.com`
- **Official documentation:** [List Products](https://www.readycloud.com/static/api-doc/v2/02-apireference-v2-11-products.html)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `orgPk` | path | `string` | yes | ReadyCloud organization identifier. |
