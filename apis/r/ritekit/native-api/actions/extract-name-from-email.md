# Extract Name From Email with Ritekit

Extracts a likely name from an email address.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/person-insights/name-from-email-address`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Extract Name From Email](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to extract a likely name from. |
