# Clean Banned Instagram Hashtags with Ritekit

Removes banned Instagram hashtags with Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/instagram/hashtags-cleaner`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Clean Banned Instagram Hashtags](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `post` | query | `string` | yes | Hashtag string to clean for banned Instagram hashtags. |
