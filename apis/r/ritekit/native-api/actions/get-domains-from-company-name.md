# Get Domains From Company Name with Ritekit

Retrieves likely domains for a company name.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/company-insights/name-to-domain`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Domains From Company Name](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | query | `string` | yes | Company name to resolve into likely domains. |
