# Extract Top Image From URL with Ritekit

Retrieves the top image from a URL with Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/image/extract-image`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Extract Top Image From URL](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to extract the top image from. |
