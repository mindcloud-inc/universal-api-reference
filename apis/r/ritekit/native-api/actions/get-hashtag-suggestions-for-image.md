# Get Hashtag Suggestions For Image with Ritekit

Retrieves Ritekit hashtag suggestions for an image.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats/hashtag-suggestions-image`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Hashtag Suggestions For Image](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `image` | query | `string` | yes | Public image URL to analyze for hashtag suggestions. |
