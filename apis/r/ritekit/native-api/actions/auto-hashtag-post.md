# Auto-Hashtag Post with Ritekit

Retrieves auto-hashtagged text from Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats/auto-hashtag`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Auto-Hashtag Post](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `post` | query | `string` | yes | Post text to auto-hashtag. |
