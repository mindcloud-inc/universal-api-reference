# Detect Disposable Email with Ritekit

Detects whether an email address is disposable.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/person-insights/disposable-email-detection`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Detect Disposable Email](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to check for disposability. |
