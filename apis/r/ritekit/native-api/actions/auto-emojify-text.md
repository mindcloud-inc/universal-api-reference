# Auto-Emojify Text with Ritekit

Retrieves auto-emojified text from Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/emoji/auto-emojify`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Auto-Emojify Text](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | Text to auto-emojify. |
