# Suggest Email Typo Fixes with Ritekit

Retrieves likely typo fixes for an email domain.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/person-insights/email-typo`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Suggest Email Typo Fixes](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to check for likely typos. |
