# Get Hashtag Stats with Ritekit

Retrieves real-time stats for Ritekit hashtags.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats/multiple-hashtags`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Hashtag Stats](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `tags` | query | `string` | yes | Comma-separated hashtags to analyze. |
