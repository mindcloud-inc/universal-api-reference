# Get Emoji Suggestions with Ritekit

Retrieves emoji suggestions from Ritekit for text.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/emoji/suggestions`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Emoji Suggestions](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | Text to analyze for emoji suggestions. |
