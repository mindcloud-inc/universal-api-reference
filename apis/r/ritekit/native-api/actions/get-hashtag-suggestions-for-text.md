# Get Hashtag Suggestions For Text with Ritekit

Retrieves Ritekit hashtag suggestions for text.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/stats/hashtag-suggestions`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Hashtag Suggestions For Text](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `text` | query | `string` | yes | Text to analyze for hashtag suggestions. |
