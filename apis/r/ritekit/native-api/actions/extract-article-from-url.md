# Extract Article From URL with Ritekit

Extracts article text from a URL with Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/text/extract-article`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Extract Article From URL](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to extract article content from. |
