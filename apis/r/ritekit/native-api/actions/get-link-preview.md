# Get Link Preview with Ritekit

Retrieves a link preview from Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/text/link-preview`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Link Preview](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to generate a link preview for. |
