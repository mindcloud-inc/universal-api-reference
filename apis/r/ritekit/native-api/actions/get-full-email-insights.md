# Get Full Email Insights with Ritekit

Retrieves full email insights from Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/person-insights/full-email-insights`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Full Email Insights](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `email` | query | `string` | yes | Email address to analyze for person insights. |
