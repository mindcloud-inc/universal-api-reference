# Get Hashtag Suggestions For URL with Ritekit

Retrieves Ritekit hashtag suggestions for a URL.

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/stats/hashtags-for-url`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [Get Hashtag Suggestions For URL](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `url` | query | `string` | yes | URL to analyze for hashtag suggestions. |
