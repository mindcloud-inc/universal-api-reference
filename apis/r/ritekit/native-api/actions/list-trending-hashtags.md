# List Trending Hashtags with Ritekit

Retrieves trending hashtags from Ritekit.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/search/trending`
- **Base URL:** `https://api.ritekit.com`
- **Official documentation:** [List Trending Hashtags](https://documenter.getpostman.com/view/2010712/SzS7Qku5?version=latest)
