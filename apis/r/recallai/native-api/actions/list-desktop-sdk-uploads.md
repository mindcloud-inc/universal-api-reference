# List Desktop SDK Uploads with Recallai

Retrieves desktop SDK uploads from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/sdk_upload/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [List Desktop SDK Uploads](https://docs.recall.ai/reference/sdk_upload_list)
