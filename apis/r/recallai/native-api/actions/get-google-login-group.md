# Get Google Login Group with Recallai

Retrieves a Google login group from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/google-login-groups/:id/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [Get Google Login Group](https://docs.recall.ai/reference/google_login_groups_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | A UUID string identifying this google login group. |
