# List Zoom OAuth Apps with Recallai

Retrieves Zoom OAuth apps from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/zoom-oauth-apps/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [List Zoom OAuth Apps](https://docs.recall.ai/reference/zoom_oauth_apps_list)
