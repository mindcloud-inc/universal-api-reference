# List Google Logins with Recallai

Retrieves Google logins from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/google-logins/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [List Google Logins](https://docs.recall.ai/reference/google_logins_list)
