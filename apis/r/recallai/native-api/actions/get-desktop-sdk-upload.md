# Get Desktop SDK Upload with Recallai

Retrieves a desktop SDK upload from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v1/sdk_upload/:id/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [Get Desktop SDK Upload](https://docs.recall.ai/reference/sdk_upload_retrieve)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `string` | yes | Desktop SDK Upload ID |
