# List Google Login Groups with Recallai

Retrieves Google login groups from Recallai.

## Endpoint

- **Method:** `GET`
- **Path:** `/api/v2/google-login-groups/`
- **Base URL:** `https://{workspaceRegion}.recall.ai`
- **Official documentation:** [List Google Login Groups](https://docs.recall.ai/reference/google_login_groups_list)
