# Get Random Dog Media with random.dog

## Endpoint

- **Method:** `GET`
- **Path:** `/woof.json`
- **Base URL:** `https://random.dog`
- **Official documentation:** [Get Random Dog Media](https://github.com/AdenFlorian/random.dog)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `filter` | query | `string` | no | Comma-separated media file extensions to exclude. |
| `include` | query | `string` | no | Comma-separated media file extensions to include. |
