# Delete Record with Resco Cloud

Deletes a record from Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/Delete`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Delete Record](https://docs.resco.net/wiki/Resco_CRM_Connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rawBody` | body | `string` | yes | XML Entity body for the Resco Delete request. |
