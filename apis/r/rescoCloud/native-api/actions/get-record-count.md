# Get Record Count with Resco Cloud

Retrieves entity record counts from Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/GetRecordCount`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Get Record Count](https://docs.resco.net/wiki/Resco_CRM_Connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rawBody` | body | `string` | yes | XML body for the Resco REST request. |
