# List Questionnaire Templates with Resco Cloud

Retrieves questionnaire templates from Resco Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `https://{organization}.rescocrm.com/odata/questionnaires/v4/`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [List Questionnaire Templates](https://docs.resco.net/wiki/Questionnaire_OData_service)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
