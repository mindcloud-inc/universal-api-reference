# List OData Entity Sets with Resco Cloud

Retrieves OData entity sets from Resco Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `https://{organization}.rescocrm.com/odata/v4/`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [List OData Entity Sets](https://docs.resco.net/wiki/OData_service)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/json` |
