# Create Record with Resco Cloud

Creates a record in Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/Create`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Create Record](https://docs.resco.net/wiki/Resco_CRM_Connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rawBody` | body | `string` | yes | XML Entity body for the Resco Create request. |
