# Get Max Row Version with Resco Cloud

Retrieves the maximum database row version from Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/GetMaxRowVersion`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Get Max Row Version](https://docs.resco.net/wiki/Resco_CRM_Connector)
