# Export Organization Data with Resco Cloud

Exports organization data and metadata from Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/Export`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Export Organization Data](https://docs.resco.net/wiki/Resco_CRM_Connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rawBody` | body | `string` | no | Optional XML body for the Resco Export request. |
