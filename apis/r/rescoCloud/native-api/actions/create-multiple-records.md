# Create Multiple Records with Resco Cloud

Creates multiple records in Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/CreateMultiple`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Create Multiple Records](https://docs.resco.net/wiki/Resco_CRM_Connector)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `rawBody` | body | `string` | yes | XML Entities body for the Resco CreateMultiple request. |
