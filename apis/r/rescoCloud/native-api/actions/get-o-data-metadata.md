# Get OData Metadata with Resco Cloud

Retrieves OData metadata from Resco Cloud.

## Endpoint

- **Method:** `GET`
- **Path:** `https://{organization}.rescocrm.com/odata/v4/$metadata`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Get OData Metadata](https://docs.resco.net/wiki/OData_service)

## Headers

Send these additional headers for this operation:

| Header | Value |
| --- | --- |
| `Accept` | `application/xml` |
