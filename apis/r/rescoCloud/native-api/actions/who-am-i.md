# Who Am I with Resco Cloud

Retrieves the current organization and user IDs from Resco Cloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/WhoAmI`
- **Base URL:** `https://{organization}.app.resco.net/rest/v1/data`
- **API:** rest
- **Official documentation:** [Who Am I](https://docs.resco.net/wiki/Resco_CRM_Connector)
