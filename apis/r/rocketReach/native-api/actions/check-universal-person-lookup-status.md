# Check Universal Person Lookup Status with RocketReach

Retrieves Universal person lookup status from RocketReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/universal/person/check_status`
- **Base URL:** `https://api.rocketreach.co/api/v2`
- **Official documentation:** [Check Universal Person Lookup Status](https://docs.rocketreach.co/reference/check_universal_person_lookup_status)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `ids` | query | `list<number>` | no | List of RocketReach profile IDs to check. |
