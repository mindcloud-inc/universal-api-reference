# Create API Key with RocketReach

Creates a RocketReach API key.

## Endpoint

- **Method:** `POST`
- **Path:** `/account/key/`
- **Base URL:** `https://api.rocketreach.co/api/v2`
- **Official documentation:** [Create API Key](https://docs.rocketreach.co/reference/rocketreach-api-account-newaccount)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `api_key` | body | `string` | no | API key value for the account action request, as documented by RocketReach. |
