# Lookup Company with RocketReach

Retrieves a company from RocketReach.

## Endpoint

- **Method:** `GET`
- **Path:** `/company/lookup/`
- **Base URL:** `https://api.rocketreach.co/api/v2`
- **Official documentation:** [Lookup Company](https://docs.rocketreach.co/reference/company-lookup-api)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `domain` | query | `string` | no |
| `id` | query | `number` | no |
| `linkedin_url` | query | `string` | no |
| `name` | query | `string` | no |
| `ticker` | query | `string` | no |
