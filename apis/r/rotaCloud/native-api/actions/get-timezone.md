# Get Timezone with RotaCloud

Retrieves a timezone from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/timezones/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Timezone](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The timezone identifier to retrieve. |
