# Get Terminal with RotaCloud

Retrieves a terminal from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/terminals/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Terminal](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The terminal identifier to retrieve. |
