# Get Attendance Record with RotaCloud

Retrieves an attendance record from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/attendance/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Attendance Record](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The attendance record identifier to retrieve. |
