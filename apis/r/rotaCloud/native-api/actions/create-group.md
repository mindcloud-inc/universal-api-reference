# Create Group with RotaCloud

Creates a group in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/groups`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Create Group](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Group name. |
