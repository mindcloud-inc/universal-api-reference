# List Invoices with RotaCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v2/invoices`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [List Invoices](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `dateFrom` | query | `string` | no |
| `dateTo` | query | `string` | no |
| `maxTotal` | query | `number` | no |
| `minTotal` | query | `number` | no |
| `status` | query | `string` | no |
