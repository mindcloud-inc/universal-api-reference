# Close Terminal with RotaCloud

Closes a terminal in RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/terminals/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Close Terminal](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Terminal ID. |
