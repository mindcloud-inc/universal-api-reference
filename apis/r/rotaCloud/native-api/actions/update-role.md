# Update Role with RotaCloud

Updates a role in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/roles/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Role](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Role ID. |
