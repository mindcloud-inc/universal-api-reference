# Delete Group with RotaCloud

Deletes a group from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/groups/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Group](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group ID. |
