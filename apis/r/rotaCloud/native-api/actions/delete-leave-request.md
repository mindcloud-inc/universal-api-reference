# Delete Leave Request with RotaCloud

Deletes a leave request from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/leave_requests/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Leave Request](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave request ID. |
