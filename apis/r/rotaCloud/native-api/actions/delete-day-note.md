# Delete Day Note with RotaCloud

Deletes a day note from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/day_notes/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Day Note](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Day note ID. |
