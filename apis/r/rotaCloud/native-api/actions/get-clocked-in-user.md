# Get Clocked In User with RotaCloud

Retrieves a clocked in user from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users_clocked_in/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Clocked In User](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
