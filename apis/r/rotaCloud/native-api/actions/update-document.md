# Update Document with RotaCloud

Updates a document in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/documents/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Document](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Document ID. |
