# Get Location with RotaCloud

Retrieves a location from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Location](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The location identifier to retrieve. |
