# Update Group with RotaCloud

Updates a group in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/groups/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Group](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Group ID. |
