# Get Day Note with RotaCloud

Retrieves a day note from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/day_notes/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Day Note](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The day note identifier to retrieve. |
