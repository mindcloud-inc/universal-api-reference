# Delete Leave Entry with RotaCloud

Deletes a leave record from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/leave/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Leave Entry](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave entry ID. |
