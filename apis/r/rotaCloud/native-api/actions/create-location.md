# Create Location with RotaCloud

Creates a location in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/locations`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Create Location](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Location name. |
