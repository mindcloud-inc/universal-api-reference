# Create Role with RotaCloud

Creates a role in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/roles`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Create Role](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `name` | body | `string` | yes | Role name. |
