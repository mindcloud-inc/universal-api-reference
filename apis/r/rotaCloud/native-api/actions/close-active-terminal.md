# Close Active Terminal with RotaCloud

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/terminals_active/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Close Active Terminal](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Active terminal ID. |
