# Update Attendance Record with RotaCloud

Updates an attendance record in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/attendance/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Attendance Record](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Attendance record ID. |
