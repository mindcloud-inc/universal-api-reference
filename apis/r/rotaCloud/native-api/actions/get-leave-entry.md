# Get Leave Entry with RotaCloud

Retrieves a leave record from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/leave/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Leave Entry](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The leave entry identifier to retrieve. |
