# Delete Attendance Record with RotaCloud

Deletes an attendance record from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/attendance/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Attendance Record](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Attendance record ID. |
