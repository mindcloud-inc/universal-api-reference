# Get Group with RotaCloud

Retrieves a group from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/groups/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Group](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The group identifier to retrieve. |
