# Get Leave Request with RotaCloud

Retrieves a leave request from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/leave_requests/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Leave Request](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The leave request identifier to retrieve. |
