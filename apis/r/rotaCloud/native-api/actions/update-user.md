# Update User with RotaCloud

Updates a user in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update User](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
