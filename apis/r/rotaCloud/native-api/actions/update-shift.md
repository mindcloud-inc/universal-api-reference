# Update Shift with RotaCloud

Updates a shift in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/shifts/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Shift](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Shift ID. |
