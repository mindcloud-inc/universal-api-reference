# Delete Location with RotaCloud

Deletes a location from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Location](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Location ID. |
