# Get User with RotaCloud

Retrieves a user from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/users/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get User](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The user identifier to retrieve. |
