# Delete Document with RotaCloud

Deletes a document from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/documents/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Document](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Document ID. |
