# List Toil Accruals with RotaCloud

Lists toil accruals in RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/toil_accruals`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [List Toil Accruals](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `users` | query | `number` | no | Send multiple values as a string separated by `,`. |
| `year` | query | `number` | no | — |
