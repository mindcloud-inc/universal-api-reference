# Get Role with RotaCloud

Retrieves a role from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/roles/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Role](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The role identifier to retrieve. |
