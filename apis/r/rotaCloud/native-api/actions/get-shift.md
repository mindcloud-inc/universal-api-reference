# Get Shift with RotaCloud

Retrieves a shift from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/shifts/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Shift](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The shift identifier to retrieve. |
