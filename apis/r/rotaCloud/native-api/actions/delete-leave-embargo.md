# Delete Leave Embargo with RotaCloud

Deletes a leave embargo from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/leave_embargoes/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Leave Embargo](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave embargo ID. |
