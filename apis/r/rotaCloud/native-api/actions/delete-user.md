# Delete User with RotaCloud

Deletes a user from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/users/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete User](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | User ID. |
