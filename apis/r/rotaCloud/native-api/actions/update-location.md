# Update Location with RotaCloud

Updates a location in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/locations/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Location](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Location ID. |
