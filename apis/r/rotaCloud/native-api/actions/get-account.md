# Get Account with RotaCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/accounts/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Account](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The account identifier to retrieve. |
