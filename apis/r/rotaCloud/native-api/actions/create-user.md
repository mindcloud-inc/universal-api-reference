# Create User with RotaCloud

Creates a user in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/users`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Create User](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `first_name` | body | `string` | yes | User first name. |
| `last_name` | body | `string` | yes | User last name. |
