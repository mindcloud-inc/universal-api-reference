# Get Leave Embargo with RotaCloud

Retrieves a leave embargo from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/leave_embargoes/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Leave Embargo](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The leave embargo identifier to retrieve. |
