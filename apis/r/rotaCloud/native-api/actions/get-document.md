# Get Document with RotaCloud

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/documents/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Document](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | The document identifier to retrieve. |
