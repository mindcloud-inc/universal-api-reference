# Resend Onboarding Link with RotaCloud

## Endpoint

- **Method:** `POST`
- **Path:** `/v2/users/onboard/:id/resend`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Resend Onboarding Link](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Onboarding user ID. |
