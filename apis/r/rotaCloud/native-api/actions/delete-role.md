# Delete Role with RotaCloud

Deletes a role from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/roles/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Role](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Role ID. |
