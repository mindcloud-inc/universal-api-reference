# Update Leave Embargo with RotaCloud

Updates a leave embargo in RotaCloud.

## Endpoint

- **Method:** `POST`
- **Path:** `/v1/leave_embargoes/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Update Leave Embargo](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Leave embargo ID. |
