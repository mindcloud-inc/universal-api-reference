# Delete Shift with RotaCloud

Deletes a shift from RotaCloud.

## Endpoint

- **Method:** `DELETE`
- **Path:** `/v1/shifts/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Delete Shift](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `id` | path | `number` | yes | Shift ID. |
