# Get Toil Accrual with RotaCloud

Retrieves a toil accrual record from RotaCloud.

## Endpoint

- **Method:** `GET`
- **Path:** `/v1/toil_accruals/:id`
- **Base URL:** `https://api.rotacloud.com`
- **Official documentation:** [Get Toil Accrual](https://rotacloud.com/api/)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `id` | path | `number` | yes |
