# Get Variant By RS ID with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/variants/:rsId`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Variant By RS ID](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rsId` | path | `string` | yes |
