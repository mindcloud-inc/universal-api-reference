# Get Species Maps Lookup with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/lookup/maps/:speciesTypeKey`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Species Maps Lookup](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `speciesTypeKey` | path | `number` | yes |
