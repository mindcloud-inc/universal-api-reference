# Get Strains By Search Term with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/strains/search/:term`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Strains By Search Term](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `term` | path | `string` | yes |
