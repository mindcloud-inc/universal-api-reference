# Get QTL By RGD ID with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/qtls/:rgdId`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get QTL By RGD ID](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `rgdId` | path | `number` | yes |
