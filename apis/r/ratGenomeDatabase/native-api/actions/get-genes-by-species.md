# Get Genes By Species with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/genes/species/:speciesTypeKey`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Genes By Species](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `speciesTypeKey` | path | `number` | yes |
