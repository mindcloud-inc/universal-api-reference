# Get Chromosomes By Assembly with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/maps/chr/:mapKey`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Chromosomes By Assembly](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `mapKey` | path | `number` | yes |
