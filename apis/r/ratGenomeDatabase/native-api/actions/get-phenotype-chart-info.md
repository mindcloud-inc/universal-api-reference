# Get Phenotype Chart Info with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/phenotype/phenominer/chart/:speciesTypeKey/:termString`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Get Phenotype Chart Info](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `speciesTypeKey` | path | `number` | yes |
| `termString` | path | `string` | yes |
