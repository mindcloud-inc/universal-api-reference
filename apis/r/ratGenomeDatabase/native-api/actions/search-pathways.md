# Search Pathways with Rat Genome Database

## Endpoint

- **Method:** `GET`
- **Path:** `/pathways/diagrams/search/:searchString`
- **Base URL:** `https://rest.rgd.mcw.edu/rgdws`
- **Official documentation:** [Search Pathways](https://rest.rgd.mcw.edu/rgdws/rgd-api-docs)

## Parameters

| Parameter | Location | Type | Required |
| --- | --- | --- | --- |
| `searchString` | path | `string` | yes |
